## 题目描述

在新西兰的这次电力危机中，政府制定了一个公平的停电方案。国家被划分为 $N$ 个区域（奥克兰是区域 $1$，惠灵顿是区域 $13$）。随机选择一个数字 $m$，首先关闭区域 $1$ 的电力，然后每隔 $m$ 个区域关闭一个，循环进行直到所有区域都被关闭。例如，当 $N = 17$，$m = 5$ 时，关闭顺序为：$1,6,11,16,5,12,2,9,17,10,4,15,14,3,8,13,7$。

问题是：惠灵顿（区域 $13$）应该最后一个被关闭（因为那里是电力总部所在地）。对于给定的 $N$，需要找到一个最小的 $m$，使得区域 $13$ 成为最后一个被选中的区域。

## 输入格式

输入包含多行，每行有一个整数 $N$（$13 \leq N < 100$），以 $0$ 作为输入结束标志。

## 输出格式

对于每个输入的 $N$，输出对应的最小 $m$ 值。

## 样例分析

输入：
```
17
0
```
输出：
```
7
```

## 题目分析与解题思路

### 问题本质

这是一个经典的约瑟夫环（$\texttt{Josephus Problem}$）变体问题。在原约瑟夫问题中，从第一个人开始报数，数到 $m$ 的人出局，然后从下一个人继续报数。本题与标准约瑟夫问题的区别在于：

1. 标准约瑟夫问题从第 $1$ 个人开始数 $1$，数到 $m$ 的人出局；本题中，第一个被关闭的区域固定为 $1$ 号区域
2. 本题要求区域 $13$ 必须是最后一个被选中的区域
3. 需要找到满足条件的最小 $m$

### 约瑟夫环问题回顾

在经典约瑟夫环问题中，有 $n$ 个人（编号 $0$ 到 $n-1$），每次数到 $m$ 的人出局，下一个从出局者的下一位开始重新计数。最后幸存者的编号可以通过递推公式求解：
$$
f(1) = 0
$$
$$
f(i) = (f(i-1) + m) \% i, \quad 其中 \; i \geq 2
$$

$f(n)$ 表示在 $n$ 个人的情况下，最后幸存者的编号（从 $0$ 开始编号）。

### 问题转换

由于第一个被关闭的区域固定为 $1$ 号区域，我们可以重新定义编号：将 $1$ 号区域视为 $0$ 号，$2$ 号区域视为 $1$ 号，以此类推。那么区域 $13$ 对应新编号中的 $12$ 号（因为 $13 - 1 = 12$）。

在新的编号系统中：
- 初始位置：第一个被关闭的是 $0$ 号
- 每次步长为 $m$（跳过 $m-1$ 个未关闭的区域，关闭第 $m$ 个）
- 要求最后一个被关闭的区域是 $12$ 号

### 解题思路

对于每个 $m$ 值，模拟关闭过程，检查区域 $13$ 是否为最后一个被关闭的区域。由于 $N < 100$，我们可以枚举 $m$ 从 $1$ 开始递增，直到找到满足条件的最小 $m$。

**模拟步骤**：
1. 初始化一个数组 $\texttt{region}[0..n-1]$，存储区域编号 $1$ 到 $n$
2. 当前指针指向 $0$ 号（即 $1$ 号区域）
3. 当剩余区域数量 $> 1$ 时：
   - 如果当前区域编号为 $13$（即 $\texttt{region[blacked]} == 13$），则说明 $13$ 号区域不是最后一个被关闭的，当前 $m$ 不满足条件
   - 否则，将当前区域标记为已关闭，剩余区域数量减 $1$
   - 移动指针到下一个位置：先移动到下一个位置（$\texttt{(blacked + 1) \% n}$），然后从这个位置开始数 $m$ 个未关闭的区域
4. 当循环结束时，检查剩余最后一个区域是否是 $13$ 号

### 代码实现分析

代码使用了两层循环：
- 外层循环枚举 $m$ 从 $1$ 开始递增
- 内层循环模拟关闭过程

关键函数：
- $\texttt{findCW}$：从当前位置开始，顺时针方向找到第 $\texttt{count}$ 个未关闭的区域
- $\texttt{findRegion}$：查找最后剩余的区域编号

### 算法复杂度

对于每个 $N$，最坏情况下需要枚举 $m$ 直到找到解。每次模拟过程的时间复杂度为 $O(N \times m)$，但由于 $N < 100$，即使枚举到较大的 $m$ 也能在可接受时间内完成。

### 优化思路

可以利用约瑟夫环的递推公式进行优化。设 $J(n)$ 为最后幸存者的新编号，则有：
$$
J(1) = 0
$$
$$
J(i) = (J(i-1) + m) \% i, \quad i \geq 2
$$

我们需要找到最小的 $m$，使得 $J(N) = 12$（对应原编号 $13$）。这样无需模拟，直接计算即可。

## 参考代码

```cpp
// Power Crisis
// UVa ID: 151
// Verdict: Accepted
// Submission Date: 2016-02-02
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int n, region[101];

int findCW(int index, int count) {
    for (int i = index; i < n; i++)
        if (region[i] > 0 && ((--count) == 0))
            return i;
    while (true) {
        for (int i = 0; i < n; i++)
            if (region[i] > 0 && ((--count) == 0))
                return i;
    }
}

int findRegion() {
    for (int i = 0; i < n; i++)
        if (region[i] > 0)
            return region[i];
}

int main() {
    while (cin >> n, n) {
        int m = 0;
        while (true) {
            for (int i = 1; i <= n; i++)
                region[i - 1] = i;
            int total = n, blacked = 0;
            bool found = true;
            m++;
            while (total > 1) {
                if (region[blacked] == 13) {
                    found = false;
                    break;
                }
                region[blacked] = 0;
                total--;
                blacked = (blacked + 1) % n;
                blacked = findCW(blacked, m);
            }
            if (found) break;
        }
        cout << m << endl;
    }
    return 0;
}
```

## 总结

本题是约瑟夫环问题的经典应用，通过模拟或递推求解。关键在于理解问题与约瑟夫环的联系，并将区域 $13$ 转换为新编号下的 $12$ 号。虽然 $N$ 的范围较小可以直接模拟，但理解约瑟夫环的递推公式有助于解决更大规模的问题。
