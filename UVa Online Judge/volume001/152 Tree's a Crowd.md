## 题目分析

一位植物心理学家发明了一种树木分类系统，每棵树通过三个测量值 $(x, y, z)$ 来表示，每个测量值的范围是 $[0, 255]$，因此每棵树可以看作是三维空间中的一个点。

**核心要求**：对于最多 $5000$ 棵树，需要统计每棵树的最近邻居距离，并按照距离区间生成直方图。距离区间定义为：

- 第 $0$ 区间：最近邻居距离 $< 1$
- 第 $1$ 区间：$1 \leq$ 最近邻居距离 $< 2$
- 第 $2$ 区间：$2 \leq$ 最近邻居距离 $< 3$
- ...
- 第 $9$ 区间：$9 \leq$ 最近邻居距离 $< 10$

如果某棵树的最近邻居距离 $d_i$ 满足 $j \leq d_i < j+1$（其中 $j$ 为整数），则该树对应第 $j$ 个区间计数加 $1$。

**输入格式**：多行数据，每行包含三个整数，表示一棵树的坐标。输入以三个 $0$ 结束。

**输出格式**：一行输出 $10$ 个整数，每个数占 $4$ 个字符宽度，右对齐。

## 解题思路

### 1. 问题本质

本题本质上是一个**三维空间中的最近邻搜索问题**。对于 $N$ 个点，需要找出每个点的最近邻距离，然后统计这些距离落在 $10$ 个不同区间中的数量。

### 2. 数据规模分析

题目说明最多有 $5000$ 棵树，这是一个关键信息。对于 $5000$ 个点，如果采用最直接的 **暴力法**（每个点与其他所有点计算距离），时间复杂度为 $O(N^2) = 25 \times 10^6$ 次距离计算。每次距离计算涉及三次减法和三次乘法（或者三次平方运算），在一般的评测系统中，这样的计算量是可以接受的。UVa 的评测环境通常可以在 $1$ 秒内完成约 $10^7$ 次基本运算，因此暴力法可行。

### 3. 距离计算优化

在计算欧氏距离时，实际使用的是平方距离进行比较：

$$d^2 = (x_1 - x_2)^2 + (y_1 - y_2)^2 + (z_1 - z_2)^2$$

使用平方距离有以下好处：
- 避免开方运算，提高计算效率
- 避免浮点数精度问题

由于比较的是距离平方，距离区间判断需要进行相应转换。对于区间 $[j, j+1)$，对应的平方距离区间为 $[j^2, (j+1)^2)$。

### 4. 算法步骤

1. **数据读入**：逐行读取三个整数，存储到结构体数组中，直到遇到 $(0, 0, 0)$。
2. **最近邻搜索**：对于每个点 $i$，遍历所有其他点 $j$（$j \neq i$），计算平方距离，记录最小值。
3. **直方图统计**：根据最小平方距离判断所属区间，对应计数加 $1$。
4. **格式化输出**：使用 $\texttt{setw(4)}$ 控制输出格式。

### 5. 复杂度分析

- **时间复杂度**：$O(N^2)$，其中 $N$ 为树的个数，最坏情况下 $N=5000$，总计算量约为 $25 \times 10^6$ 次距离计算。
- **空间复杂度**：$O(N)$，用于存储树的坐标。

### 6. 注意事项

- 输入结束标志为 $(0, 0, 0)$，但该行不参与计算。
- 距离区间判断时，需注意边界条件：当最小距离恰好等于 $j$ 时，应归入区间 $j$。
- 输出格式要求严格，每个数字占 $4$ 个字符宽度，右对齐。

## 代码实现

```cpp
// Tree's a Crowd
// UVa ID: 152
// Verdict: Accepted
// Submission Date: 2016-02-02
// UVa Run Time: 0.046s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

struct tree
{
    int x, y, z;
};

int n;
tree trees[6000];

inline int pow(int x) {
    return x * x;
}

inline int squareOfDistance(tree near, tree far) {
    return pow(near.x - far.x) + pow(near.y - far.y) + pow(near.z - far.z);
}

void find() {
    int distance[10] = {0};
    for (int i = 0; i < n; i++) {
        int min = 255 * 255;
        for (int j = 0; j < n; j++) {
            if (i == j) continue;
            if (squareOfDistance(trees[i], trees[j]) < min) 
                min = squareOfDistance(trees[i], trees[j]);
        }
        for (int top = 0; top < 10; top++)
            if (top * top <= min && min < (top + 1) * (top + 1)) {
                distance[top]++;
                break;
            }
    }
    for (int i = 0; i < 10; i++)
        cout << setw(4) << right << distance[i];
    cout << endl;
}

int main() {
    cin.tie(0);
    cout.sync_with_stdio(false);
    int x, y, z;
    n = 0;
    while (cin >> x >> y >> z, x || y || z) trees[n++] = (tree){x, y, z};
    find();
	return 0;
}
```

## 总结

本题是一个典型的最近邻问题，虽然数据规模允许使用 $O(N^2)$ 的暴力算法，但代码中仍然进行了适当优化：
- 使用平方距离避免开方运算
- 使用内联函数减少函数调用开销
- 使用整数运算避免浮点数精度问题

对于更大的数据规模，可能需要使用更高效的算法，如 $k$-d 树或空间分割技术。但在本题的限制下，暴力算法简洁有效。
