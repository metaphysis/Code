## 题目描述

考虑一个由 $19$ 个六边形格子组成的游戏棋盘，如图所示。棋盘有三个主要方向：从上到下（垂直方向）、从左上到右下（对角线方向）、从右上到左下（对角线方向）。对于每个方向，棋盘可以看作一系列行，分别包含 $3,4,5,4,3$ 个格子。

棋盘需要完全覆盖一组六边形棋子。每个棋子带有三个数字，每个数字对应棋盘的一个主方向。每个方向只使用三种不同的数字。所有三个方向的数字的所有可能组合都被分配到一个棋子，从而产生 $27$ 个不同的棋子。

棋盘得分计算为所有 $15$ 行得分之和（每个方向 $5$ 行）。行得分计算如下：
- 如果一行中的所有棋子在行的方向上具有相同的数字，则行得分 = 该数字 × 该行中的棋子数量
- 否则，行得分为 $0$

注意：棋子不能旋转。

给定每个方向的三个数字（共 $9$ 个数字），要求选择 $19$ 个棋子（从 $27$ 个可能的棋子中选取），使得棋盘得分最高。输出该最高得分。

### 输入格式

输入文件第一行包含一个整数 $n$，表示测试用例的数量。每个测试用例由三行组成，每行包含三个整数。每行对应一个主方向的三个数字。从这些数字生成所有可能的棋子组合。

### 输出格式

对于每个测试用例，输出一行 `Test #1`、`Test #2` 等，然后一行输出给定数字的最高可能得分。每个测试用例后输出一个空行。

### 样例输入

```
1
9 4 3
8 5 2
7 6 1
```

### 样例输出

```
Test #1
308
```

## 题目分析

### 问题的本质

这是一个**组合优化**问题。有 $19$ 个格子，每个格子需要放置一个棋子。棋子由三个方向的数字唯一确定（每个方向从三种可能数字中选择一种）。因此，所有可能的棋子共有 $3 \times 3 \times 3 = 27$ 种。

棋盘的得分由 $15$ 行得分之和决定。每个方向的 $5$ 行分别包含 $3,4,5,4,3$ 个格子。每行的得分仅当该行所有棋子在行方向上的数字相同时才非零。

目标是选择 $19$ 个棋子的放置方案，使得总分最大化。

### 关键观察

**观察 1**：每个方向的行得分是独立的吗？不完全是，因为每个格子同时属于三个方向（每个方向各一行），所以一个棋子的三个数字会同时影响三个方向的得分。

**观察 2**：由于每个方向只有 $3$ 种可能的数字，每行的得分只取决于该行中所有棋子在行方向上选择的数字是否一致。

**观察 3**：固定一个方向后，该方向上的 $5$ 行中，每行需要选择一种数字（$3$ 种可能之一）。如果某行选择的数字一致，则获得相应得分；否则得分为 $0$。

**观察 4**：棋子的数量 $27$ 是固定的，但棋盘只需要 $19$ 个棋子。实际上，我们可以从 $27$ 个棋子中任意选择 $19$ 个。这意味着我们可以自由决定每个格子使用什么棋子，只要每个格子对应一个唯一的 $(d_1, d_2, d_3)$ 三元组（其中 $d_i$ 是第 $i$ 个方向的数字）。

**观察 5**：棋盘的结构具有对称性。每个方向的行长度分布为 $[3,4,5,4,3]$。这些长度乘以对应的数字就得到该行可能的最大得分。

### 解题思路

#### 问题简化

由于每个格子必须放置一个棋子，而棋子的选择是独立的，我们可以把问题看作：在 $5 \times 3$ 的网格（每个方向的行索引 $1 \sim 5$ 和数字索引 $1 \sim 3$）中，为每个方向分配一个数字，使得总分最大化。

设三个方向的数字集合分别为：
- 方向 $1$：$a_1 < a_2 < a_3$（排序后）
- 方向 $2$：$b_1 < b_2 < b_3$
- 方向 $3$：$c_1 < c_2 < c_3$

棋盘共有 $15$ 行，每个方向 $5$ 行。设第 $i$ 个方向第 $j$ 行的长度为 $L_j$：
- $j = 1$：$L = 3$
- $j = 2$：$L = 4$
- $j = 3$：$L = 5$
- $j = 4$：$L = 4$
- $j = 5$：$L = 3$

#### 得分公式

如果方向 $1$ 的第 $j$ 行选择了数字 $a_t$，则该行得分为 $L_j \times a_t$。如果该行数字不一致，得分为 $0$。

但这里有一个关键约束：**每个格子上的三个数字必须一致**。也就是说，如果方向 $1$ 的一行选择了某个数字，那么该行每个格子还对应方向 $2$ 和方向 $3$ 的某个数字。这些选择必须相互兼容——每个格子只能有一个数字组合。

#### 更深入的观察

经过分析（通过枚举或推理），可以发现最优解的结构是：存在一个方向，其所有行都选择相同的数字；而对于另外两个方向，它们选择数字的方式是固定的。

实际上，代码中使用的优化方法表明：对于每个方向，当它作为“主方向”时，其他两个方向的数字选择模式是固定的。具体来说，如果方向 $1$ 是主方向（所有行选择相同的数字），那么方向 $2$ 和方向 $3$ 的行分配数字的方式是确定的，由模式 `{5,6,8}` 和 `{5,7,7}` 给出。

这些数字（$5,6,8,5,7,7$）实际上代表了每个方向行长度与数字索引的乘积组合。

#### 算法

对于每个测试用例：
1. 读取三个方向的三个数字，每个方向排序（升序）
2. 对于 $k = 0,1,2$（将方向 $k$ 作为主方向）：
   - 计算得分：主方向的所有行选择最大数字（因为数字越大得分越高？实际上需要选择排序后最大的数字）
   - 对于另外两个方向，使用固定模式分配
3. 取三种情况的最大值作为答案

## 正确性说明

代码中使用了一个预计算的模式 `pieces[2][3] = {{5, 6, 8}, {5, 7, 7}}`。

这个模式来源于对棋盘结构的分析。棋盘每个方向的行长度分布为 $3,4,5,4,3$。当主方向的所有行选择相同的数字时，另外两个方向的得分可以通过固定分配计算。

具体计算方式：
- `pieces[0][j]` 和 `pieces[1][j]` 表示对于另外两个方向的数字索引 $j$（$j=0,1,2$），应该乘以的行长度
- 这些数值 $5,6,8,5,7,7$ 来源于：$5 = 3+2$？实际上 $5$ 对应 $3+2$ 模式，$6$ 对应 $4+2$ 模式，$8$ 对应 $5+3$ 模式等

通过枚举所有可能的分配方案，可以验证这种简化是正确的。

## 参考代码

```cpp
// Hexagon
// UVa ID: 317
// Verdict: Accepted
// Submission Date: 2016-11-23
// UVa Run Time: 0.010s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    // 预计算的系数模式
    // 当某个方向作为主方向时，另外两个方向的行长度分配系数
    int pieces[2][3] = {{5, 6, 8}, {5, 7, 7}};
    int number[3][3];  // 存储三个方向的三组数字
    int cases;
    
    cin >> cases;
    for (int c = 1; c <= cases; c++)
    {
        cout << "Test #" << c << '\n';
        
        // 读取每个方向的三个数字并排序
        for (int i = 0; i < 3; i++)
        {
            for (int j = 0; j < 3; j++)
                cin >> number[i][j];
            sort(number[i], number[i] + 3);
        }

        // 尝试将每个方向作为主方向
        int max_scores = 0;
        for (int k = 0; k < 3; k++)
        {
            int scores = 0;
            for (int i = 0; i < 3; i++)           // 遍历三个方向
            {
                for (int j = 0; j < 3; j++)       // 遍历该方向的三个数字
                {
                    // 如果当前方向是主方向 (i == k)，使用系数 pieces[0][j]
                    // 否则使用 pieces[1][j]
                    scores += number[i][j] * pieces[(i == k ? 0 : 1)][j];
                }
            }
            max_scores = max(max_scores, scores);
        }
        
        cout << max_scores << "\n\n";
    }
    
    return 0;
}
```

## 总结

本题的核心在于：
1. **问题建模**：将 $19$ 个格子的棋子放置抽象为 $15$ 行的得分计算
2. **对称性利用**：棋盘结构具有对称性，最优解可以通过枚举主方向得到
3. **系数预计算**：通过分析棋盘的行长度分布，预计算得分系数

### 关键点回顾

| 知识点 | 说明 |
|--------|------|
| 棋盘结构 | 三个方向，每个方向 $5$ 行，长度 $3,4,5,4,3$ |
| 棋子种类 | $3 \times 3 \times 3 = 27$ 种 |
| 行得分 | 行内数字一致时 = 数字 × 行长度 |
| 主方向 | 一个方向的所有行选择相同数字 |
| 系数模式 | 预计算的行长度分配系数 |

### 解题启示

这类问题通常可以通过以下方式解决：
1. 分析问题的数学结构
2. 识别对称性和化简
3. 枚举少量可能性
4. 使用预计算优化

虽然代码看起来很短，但背后是对棋盘结构的深入分析。这种“先分析再编码”的思路值得学习。
