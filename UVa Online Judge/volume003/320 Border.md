## 题目描述

你需要编写一个程序，在位图上绘制围绕闭合路径的边界，如图所示。路径是闭合的，沿着网格线运行（即在网格方块之间）。路径以**逆时针**方向运行，因此如果沿着路径前进被认为是“向前”移动，那么边界像素始终在路径的“右侧”。位图始终覆盖 $32 \times 32$ 个方格，其左下角位于 $(0,0)$。你可以安全地假设路径永远不会触碰位图的边界矩形，也永远不会触碰或交叉自身。

注意：如果一个位位于路径所包围区域的外部，并且其至少有一条边属于路径，则该位被设置为 $1$，但如果只有其一个角在路径上，则不设置。

### 输入格式

输入文件的第一行包含测试用例的数量。每个测试用例由两行组成：
- 第一行包含两个整数 $x$ 和 $y$，指定路径的起点坐标
- 第二行包含一个可变长度的字符串，字符串中的每个字母表示沿着网格移动一步，长度为 $1$。字符串中只出现字母 $\texttt{W}$（西）、$\texttt{E}$（东）、$\texttt{N}$（北）、$\texttt{S}$（南）和 $\texttt{.}$（路径结束，无移动）。结束字符 $\texttt{.}$ 后紧跟行尾。

### 输出格式

对于每个测试用例，输出一行用例编号（如 $\texttt{Bitmap \#1}$、$\texttt{Bitmap \#2}$ 等）。然后对于从顶部到底部的每一行位图（共 $32$ 行），打印一行，从左到右打印该行中每个位的字符。设置位打印大写 $\texttt{X}$，未设置位打印句点 $\texttt{.}$。每个位图后输出一个空行。

## 题目分析

### 问题的本质

这是一个**网格路径边界绘制**问题。给定一条沿着网格线移动的逆时针闭合路径，需要标记出路径“右侧”的像素（即 $32 \times 32$ 位图中被路径包围区域外部的边界像素）。

关键要点：
- 路径是逆时针方向
- 边界像素在路径的右侧
- 位图大小为 $32 \times 32$，左下角为 $(0,0)$，但输出时从顶部行开始
- 路径不会触碰边界，也不会自交
- 如果像素的至少一条边属于路径，且该像素在路径外部，则设置该位

### 路径与像素的关系

位图中的每个像素对应于一个 $1 \times 1$ 的正方形。路径沿着网格线移动，即位于像素之间的边界上。

在逆时针路径中，“右侧”是指路径所包围区域的**外部**。因此，我们需要标记路径外部的边界像素。

### 直接标记法

由于路径的每个移动步骤都是沿着网格线进行，我们可以直接根据移动方向标记右侧的像素。

考虑从点 $P$ 移动到点 $Q$ 的每一步。根据移动方向，可以确定路径右侧的像素：

- 向东移动（$\texttt{E}$）：从 $(x,y)$ 到 $(x+1,y)$，右侧是向南的方向，因此标记前进方向右侧的像素（也就是网格下方），像素的坐标是 $(x+1, y)$。这里需要注意，像素的起始坐标也位于左下角，只不过其起始坐标为$(1,1)$。

- 其他方向可以依此类推。

### 坐标系统

位图有 $32 \times 32$ 个像素，左下角为 $(0,0)$，右上角为 $(31,31)$。路径的起点坐标 $(x,y)$ 是网格点的坐标，范围是 $0 \leq x,y \leq 32$。

当向东移动时，$x$ 增加 $1$；向西移动时，$x$ 减少 $1$；向北移动时，$y$ 增加 $1$；向南移动时，$y$ 减少 $1$。

## 解题思路
### 步骤一：初始化位图

使用一个 $32 \times 32$ 的字符数组存储位图，初始所有位置为 `'.'`。

### 步骤二：解析路径

路径字符串以 `'.'` 结束，该字符不表示移动。因此，只需要处理字符串中除了最后一个字符之外的所有字符。

### 步骤三：标记右侧像素

对于每个移动步骤，根据移动方向标记对应的像素：

```cpp
if (path[j] == 'E') {
    x += 1;
    bitmap[x][y] = 'X';
} else if (path[j] == 'N') {
    y += 1;
    bitmap[x + 1][y] = 'X';
} else if (path[j] == 'W') {
    x -= 1;
    bitmap[x + 1][y + 1] = 'X';
} else if (path[j] == 'S') {
    y -= 1;
    bitmap[x][y + 1] = 'X';
}
```

这个标记规则来源于对“右侧像素”的几何分析：
- 向东移动：路径经过 $(x,y) \to (x+1,y)$，右侧是南方，像素 $(x+1, y)$ 是边界。
- 向北移动：路径经过 $(x,y) \to (x,y+1)$，右侧是东方，像素 $(x+1, y+1)$ 是边界。
- 向西移动：路径经过 $(x,y) \to (x-1,y)$，右侧是南方，像素 $(x, y+1)$ 是边界。
- 向南移动：路径经过 $(x,y) \to (x,y-1)$，右侧是西方，像素 $(x, y)$ 是边界。

这里需要注意，像素的起始坐标在左下角，为$(1,1)$。
### 步骤四：输出位图

输出时，第一行对应位图的最顶部（$y = 32$），最后一行对应底部（$y = 1$）。因此，需要从 $y = 32$ 向下遍历到 $y = 1$。

## 参考代码

```cpp
// Border
// UVa ID: 320
// Verdict: Accepted
// Submission Date: 2016-06-28
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    char bitmap[40][40];  // 位图数组，索引从1开始
    int cases;
    cin >> cases;
    for (int i = 1; i <= cases; i++) {
        // 初始化位图为全部未设置
        for (int m = 1; m <= 32; m++)
            for (int n = 1; n <= 32; n++)
                bitmap[m][n] = '.';
        cout << "Bitmap #" << i << endl;
        int x, y;
        cin >> x >> y;
        string path;
        cin >> path;
        // 处理每个移动步骤（最后一个字符是 '.'，不处理）
        for (int j = 0; j < path.length() - 1; j++) {
            if (path[j] == 'E')      // 向东移动
            {
                x += 1;              // 移动后位置
                bitmap[x][y] = 'X';  // 标记右侧（南方）的像素
            }
            else if (path[j] == 'N') // 向北移动
            {
                y += 1;
                bitmap[x + 1][y] = 'X';
            }
            else if (path[j] == 'W') // 向西移动
            {
                x -= 1;
                bitmap[x + 1][y + 1] = 'X';
            }
            else if (path[j] == 'S') // 向南移动
            {
                y -= 1;
                bitmap[x][y + 1] = 'X';
            }
        }
        
        // 输出位图：从顶部（y=32）到底部（y=1）
        for (int m = 32; m >= 1; m--) {
            for (int n = 1; n <= 32; n++)
                cout << bitmap[n][m];
            cout << endl;
        }
        
        cout << endl;  // 每个测试用例后空行
    }
    
    return 0;
}
```
