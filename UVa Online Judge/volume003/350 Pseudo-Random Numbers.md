## 题目描述

计算机通常无法生成真正的随机数，但经常用于生成伪随机数序列。这些数由某种算法生成，但在实际应用中看起来是随机的。随机数用于许多应用，包括模拟。

一种常见的伪随机数生成技术称为**线性同余法**（$\texttt{linear congruential method}$）。如果上一个生成的伪随机数是 $L$，则下一个数通过计算 $(Z \times L + I) \bmod M$ 生成，其中 $Z$ 是常数乘数，$I$ 是常数增量，$M$ 是常数模数。

例如，取 $Z = 7$，$I = 5$，$M = 12$。如果种子（第一个随机数）是 $4$，则后续几个伪随机数如下：

| 上一个随机数 $L$ | $Z \times L + I$ | 下一个随机数 $(Z \times L + I) \bmod M$ |
|---|---|---|
| $4$ | $33$ | $9$ |
| $9$ | $68$ | $8$ |
| $8$ | $61$ | $1$ |
| $1$ | $12$ | $0$ |
| $0$ | $5$ | $5$ |
| $5$ | $40$ | $4$ |

可以看出，该技术生成的伪随机数序列在 $6$ 个数后重复。显然，使用此技术可生成的最长序列受模数 $M$ 限制。

在本题中，给定 $Z$、$I$、$M$ 和种子 $L$ 的值（每个值不超过 $4$ 位数字）。对于每组值，需要确定生成的伪随机数序列的循环长度。注意：循环可能不是从种子开始的！

### 输入格式

每行包含四个整数，依次为 $Z$、$I$、$M$ 和 $L$。最后一行包含四个 $0$，表示输入结束。$L$ 小于 $M$。

### 输出格式

对于每个输入行，输出用例编号（从 $1$ 开始）和序列重复前的长度。

### 样例输入

```
7 5 12 4
5173 3849 3279 1511
9111 5309 6000 1234
1079 2136 9999 1237
0 0 0 0
```

### 样例输出

```
Case 1: 6
Case 2: 546
Case 3: 500
Case 4: 220
```

## 题目分析

### 问题的本质

这是一个**检测循环周期**的问题。给定一个确定性映射 $f(x) = (Z \times x + I) \bmod M$，从种子 $L$ 开始迭代生成序列。由于值域有限（$0 \sim M-1$），序列必然进入循环。需要计算从种子开始到首次重复的序列长度。

### 关键区别

- **循环可能不从种子开始**：种子可能位于循环的“尾巴”部分，然后才进入循环
- 需要计算的是**序列重复前的总长度**（即从种子到首次出现重复元素之间的距离）

### 示例分析

以 $Z=7, I=5, M=12, L=4$ 为例：
- 序列：$4, 9, 8, 1, 0, 5, 4, \dots$
- 首次重复发生在第 $7$ 个元素（再次出现 $4$）
- 重复前的长度为 $6$（从 $4$ 到 $5$，共 $6$ 个不同元素）

### 算法思路

使用哈希表记录每个数字第一次出现的位置索引。当遇到一个已经出现过的数字时，当前索引减去该数字首次出现的索引，即为循环长度。
## 参考代码

```cpp
// Pseudo-Random Number
// UVa ID: 350
// Verdict: Accepted
// Submission Date: 2016-06-25
// UVa Run Time: 0.030s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int Z, I, M, L, cases = 0;
    while (cin >> Z >> I >> M >> L, Z) {
        map<int, int> number;  // 数字 -> 首次出现的位置索引
        // 迭代直到遇到重复数字
        while (number.find(L) == number.end()) {
            number[L] = number.size();        // 记录当前位置
            L = (Z * L + I) % M;             // 生成下一个数
        }
        // 循环长度 = 当前总个数 - 重复数字首次出现的位置
        cout << "Case " << ++cases << ": " << (number.size() - number[L]) << endl;
    }
    return 0;
}
```
