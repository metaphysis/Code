## 题目描述

$\texttt{Postscript}$ 题目模拟了一个早期的激光打印机驱动程序。输出页面是一个 $60 \times 60$ 的字符网格，初始时每个位置都是句点（`.`），表示空白。驱动程序读取一系列格式化命令，将文本放置到网格上。网格中的每个位置可以包含以下字符：大写字母 $\texttt{A} \sim \texttt{Z}$、句点（`.`）和星号（`*`）。

系统支持两种字体：
- **$\texttt{C1}$ 字体**：包含大写字母和空格，每个字符占据 $1 \times 1$ 的网格。
- **$\texttt{C5}$ 字体**：是一种放大的字体，每个字符由 $5$ 行 $\times 6$ 列的网格定义，网格中包含星号（`*`）或句点（`.`）。每个字符的第 $6$ 列全是句点，用于自然间距。$\texttt{C5}$ 字体支持大写字母和空格。

命令格式如下：

| 命令 | 参数 $1$（字体） | 参数 $2$（行 $R$） | 参数 $3$（列 $C$） | 参数 $4$（字符串 $S$） | 说明 |
|------|---------------|-----------------|-----------------|---------------------|------|
| `.P` | $\texttt{C1}$ 或 $\texttt{C5}$ | $1$ 到 $60$ | $1$ 到 $60$ | 是 | 将字符串的左上角放置在 $(R, C)$ 位置，向右水平排列 |
| `.L` | $\texttt{C1}$ 或 $\texttt{C5}$ | $1$ 到 $60$ | 无 | 是 | 将字符串左对齐，即左上角在 $(R, 1)$，向右排列 |
| `.R` | $\texttt{C1}$ 或 $\texttt{C5}$ | $1$ 到 $60$ | 无 | 是 | 将字符串右对齐，即右上角在 $(R, 60)$，向左排列 |
| `.C` | $\texttt{C1}$ 或 $\texttt{C5}$ | $1$ 到 $60$ | 无 | 是 | 将字符串水平居中，顶部行在 $R$ 行 |
| `.EOP` | 无 | 无 | 无 | 无 | 表示页面结束，输出当前页面并清空网格 |

**重要规则**：
- $\texttt{C1}$ 字体中的空格和 $\texttt{C5}$ 字体中的句点（即空白部分）**不会覆盖**网格中原有的内容。
- 如果格式化内容超出网格边界（右侧、左侧或底部），超出的部分被直接截断。
- 对于居中命令（`.C`）：如果字符串占据的宽度不能恰好居中（即宽度为奇数），则字符串应尽可能居中于第 $31$ 列的两侧（即第 $31$ 列作为中心参考）。

## 输入格式

输入由若干行组成，每行包含一个命令及其参数。命令以句点开头，位于行首。参数之间由至少一个空格分隔。输入保证最后一个命令是 `.EOP`。

命令格式严格遵循上表，参数数量正确且取值范围合法。字符串由竖线 `|` 分隔，例如 `|ACM|`。

## 输出格式

对于每个 `.EOP` 命令，输出当前页面的 $60 \times 60$ 网格，每行 $60$ 个字符。在每页输出之后，先输出一个空行，再输出一行恰好 $60$ 个短横线 `-`，然后再输出一个空行。

## 题目分析

本题的核心是实现一个二维字符网格的渲染系统，需要处理两种不同字体、四种不同的对齐方式，并考虑边界截断和空白不覆盖的规则。

### 字体特性

**$\texttt{C1}$ 字体**：
- 每个字符占据 $1 \times 1$ 网格。
- 字符直接写入网格，空格不写入（即不覆盖原有内容）。
- 字符串中的每个字符按顺序放置，位置连续递增。

**$\texttt{C5}$ 字体**：
- 每个字符由 $5 \times 6$ 的像素矩阵定义，第 $6$ 列全是句点。
- 题目提供了从 `A` 到 `Z` 以及空格的字符模板，每个模板是一个长度为 $30$ 的字符串（$5 \times 6 = 30$），按行主序排列。
- 渲染时，将模板中为 `*` 的位置绘制到网格对应位置；为 `.` 的位置不覆盖网格原有内容。
- 字符之间自然间隔 $6$ 列（因为第 $6$ 列是空列）。

### 对齐方式的实现

1. **`.P`（绝对位置）** ：给定左上角坐标 $(R, C)$，第一个字符的左上角在该位置，后续字符向右依次排列。$\texttt{C1}$ 字体每个字符占 $1$ 列，$\texttt{C5}$ 字体每个字符占 $6$ 列。

2. **`.L`（左对齐）** ：左上角在 $(R, 1)$，相当于 `.P` 命令的 $C = 1$。

3. **`.R`（右对齐）** ：右上角在 $(R, 60)$，最后一个字符的右上角在该位置，整个字符串向左排列。需要逆向渲染字符串。

4. **`.C`（居中）** ：需要计算字符串的总宽度，然后确定起始列，使得字符串在 $1$ 到 $60$ 列之间居中。对于 $\texttt{C5}$ 字体，宽度为 $6 \times \textit{len}$；对于 $\texttt{C1}$ 字体，宽度为 $\textit{len}$。

   居中的具体规则：
   - 如果总宽度为偶数，中心线在第 $30.5$ 列（即第 $30$ 列和第 $31$ 列之间），字符串两侧各占一半宽度。
   - 如果总宽度为奇数，中心线在第 $31$ 列，字符串向两侧均匀分布（左半部分比右半部分少 $1$ 列或相等？根据题目描述“尽可能居中于第 $31$ 列的两侧”，结合参考代码的实现，对于奇数宽度的情况，字符串被分成左右两半，左边一半从 $27$ 列开始，右边一半从 $30$ 列开始，详细分析见解题思路部分。

### 覆盖规则

- $\texttt{C1}$ 字体中的空格：不覆盖任何内容。
- $\texttt{C5}$ 字体中的句点：不覆盖任何内容。
- $\texttt{C5}$ 字体中的星号：覆盖网格内容（将网格对应位置设为 `*`）。
- $\texttt{C1}$ 字体中的字母：覆盖网格内容（将网格对应位置设为该字母）。

这意味着渲染时，只有当新字符的对应位置非空（$\texttt{C1}$ 非空格，$\texttt{C5}$ 非句点）时，才更新网格。

### 边界截断

渲染时，对于超出 $0 \le \textit{row} < 60$ 或 $0 \le \textit{col} < 60$ 的格子，直接跳过，不进行任何操作。

## 解题思路

### 步骤一：存储 $\texttt{C5}$ 字体模板

使用 $\texttt{map<char, string>}$ 存储每个字符对应的 $30$ 字符模板。模板按行主序排列，即前 $6$ 个字符对应第 $1$ 行，接下来 $6$ 个字符对应第 $2$ 行，依此类推。

### 步骤二：解析命令

每行命令以句点开头，需要按顺序解析：
1. 命令（如 `.P`、`.L`、`.C`、`.R`、`.EOP`）。
2. 字体（$\texttt{C1}$ 或 $\texttt{C5}$）。
3. 行号 $R$（字符串转换为整数后减 $1$，因为网格索引从 $0$ 开始）。
4. 对于 `.P` 命令，还有列号 $C$（同样减 $1$）。
5. 字符串 $S$：位于两个竖线之间，需要提取出来。

字符串可能包含空格，提取时注意保留空格。

### 步骤三：实现渲染函数

由于需要支持正向渲染（向右）和逆向渲染（向左），可以封装两个函数：
- `render_to_right(int r, int c, string font, string text)`：从 $(r, c)$ 开始向右渲染。
- `render_to_left(int r, int c, string font, string text)`：从 $(r, c)$ 开始向左渲染。对于 `.R` 命令，$c = 59$（最后一列），且需要逆向处理字符串顺序。

### 步骤四：处理居中命令

居中的关键是要找到合适的起始列。设字符串长度为 $L$，$\texttt{C1}$ 字体总宽度 $w = L$，$\texttt{C5}$ 字体总宽度 $w = 6L$。

**规则解析**（结合参考代码）：
- 如果 $w$ 为偶数：字符串关于第 $30$ 列和第 $31$ 列之间的中线对称。左半部分宽度为 $w/2$，右半部分宽度为 $w/2$。起始列 $c = 30 - w/2$（因为第 $30$ 列是中线左侧的最后一列，索引从 $0$ 开始，第 $30$ 列对应实际第 $31$ 列）。参考代码中，当 $w$ 为偶数时，将字符串分成两半，右半部分从第 $30$ 列开始渲染，左半部分从第 $29$ 列开始向左渲染。
- 如果 $w$ 为奇数：字符串中心在第 $31$ 列（索引 $30$）。左半部分宽度为 $w/2$（向下取整），右半部分宽度为 $w/2$（向上取整）。参考代码中，对于 $\texttt{C5}$ 字体且 $L$ 为奇数（即 $w$ 为奇数），右半部分从第 $30$ 列开始，左半部分从第 $27$ 列开始，以保证中心在第 $31$ 列。

具体实现时，可以将字符串分成左右两半，分别调用 `render_to_right` 和 `render_to_left`。

### 步骤五：输出页面

遇到 `.EOP` 命令时：
1. 输出当前 $60 \times 60$ 网格，每行 $60$ 个字符。
2. 输出一个空行。
3. 输出一行 $60$ 个短横线 `-`。
4. 再输出一个空行。
5. 将网格重置为全句点（用于下一页）。

### 复杂度分析

- 每个命令最多渲染 $60$ 个字符，每个 $\texttt{C5}$ 字符最多更新 $5 \times 6 = 30$ 个格子，单次渲染复杂度 $O(\text{字符数} \times 30)$。
- 总命令数由输入决定，但网格固定为 $60 \times 60$，总体复杂度可接受。

void flushing()
{
    for (int i = 0; i < 60; i++)
    {
        for (int j = 0; j < 60; j++)
            cout << grid[i][j];
        cout << '\n';
    }
    cout << '\n';
        
    for (int i = 0; i < 60; i++)
        cout << '-';
    cout << "\n\n";
}

void render_to_right(int r, int c, string font, string text)
{
    if (font == "C1")
    {
        for (int i = 0; i < text.length(); i++)
        {
            if (text[i] != ' ' && r >= 0 && r < 60 && c >= 0 && c < 60)
                grid[r][c] = text[i];
            c++;
        }
    }
    else
    {
        for (int i = 0; i < text.length(); i++)
        {
            for (int j = 0; j < 5; j++)
                for (int k = 0; k < 6; k++)
                {
                    int rr = r + j, cc = c + k;
                    if (letter[text[i]][j * 6 + k] != '.' && rr >= 0 && rr < 60 && cc >= 0 && cc < 60)
                        grid[rr][cc] = letter[text[i]][j * 6 + k];
                }
            c += 6;
        }
    }
}

void render_to_left(int r, int c, string font, string text)
{
    if (font == "C1")
    {
        for (int i = text.length() - 1; i >= 0; i--)
        {
            if (text[i] != ' ' && r >= 0 && r < 60 && c >= 0 && c < 60)
                grid[r][c] = text[i];
            c--;
        }
    }
    else
    {
        c -= 5;
        for (int i = text.length() - 1; i >= 0; i--)
        {
            for (int j = 0; j < 5; j++)
                for (int k = 0; k < 6; k++)
                {
                    int rr = r + j, cc = c + k;
                    if (letter[text[i]][j * 6 + k] != '.' && rr >= 0 && rr < 60 && cc >= 0 && cc < 60)
                        grid[rr][cc] = letter[text[i]][j * 6 + k];
                }
            c -= 6;
        }
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    while (getline(cin, line))
    {
        memset(grid, '.', sizeof(grid));

        do
        {
            // 去除行首尾空白
            while (isblank(line.front()))
                line.erase(line.begin());
            while (isblank(line.back()))
                line.erase(line.end() - 1);
            
            if (line == ".EOP")
            {
                flushing();
                break;
            }
            
            string command, font, row, column, text;
            // 解析命令
            while (!isblank(line.front()))
            {
                command += line.front();
                line.erase(line.begin());
            }
            
            while (isblank(line.front()))
                line.erase(line.begin());
                
            while (!isblank(line.front()))
            {
                font += line.front();
                line.erase(line.begin());
            }
            
            while (isblank(line.front()))
                line.erase(line.begin());
            while (!isblank(line.front()))
            {
                row += line.front();
                line.erase(line.begin());
            }
            
            if (command == ".P")
            {
                while (isblank(line.front()))
                    line.erase(line.begin());
                while (!isblank(line.front()))
                {
                    column += line.front();
                    line.erase(line.begin());
                }
            }
            while (isblank(line.front())) line.erase(line.begin());
            // 提取竖线内的字符串
            text = line.substr(1, line.length() - 2);
            
            int r = stoi(row) - 1, c;
            if (command == ".P" || command == ".L")
            {
                if (command == ".L")
                    c = 0;
                else
                    c = stoi(column) - 1;

                render_to_right(r, c, font, text);
            }
            else if (command == ".C")
            {
                if (font == "C5" && text.length() % 2 == 1)
                {
                    render_to_right(r, 27, font, text.substr(text.length() / 2));
                    render_to_left(r, 26, font, text.substr(0, text.length() / 2));
                }
                else
                {
                    render_to_right(r, 30, font, text.substr(text.length() / 2));
                    render_to_left(r, 29, font, text.substr(0, text.length() / 2));
                }
            }
            else if (command == ".R")
                render_to_left(r, 59, font, text);
        } while (getline(cin, line));
    }

    return 0;
}

## 总结

本题是一道复杂的模拟题，主要考察以下知识点：

1. **二维网格的渲染**：需要正确实现两种字体的渲染逻辑，包括字符模板的存储和逐像素绘制。
2. **多种对齐方式**：左对齐、右对齐、居中对齐，每种对齐方式需要计算正确的起始位置。
3. **边界截断**：渲染时检查坐标是否在 $0 \le \textit{row} < 60$、$0 \le \textit{col} < 60$ 范围内。
4. **覆盖规则**：$\texttt{C1}$ 的空格和 $\texttt{C5}$ 的句点不覆盖已有内容，这是题目中容易忽略的细节。
5. **命令解析**：需要从每行中正确提取命令、字体、行号、列号（如果有）和字符串。

本题的易错点在于：
- 居中对齐时，奇数宽度字符串的起始列计算。参考代码的实现是：对于 $\texttt{C5}$ 字体且字符串长度为奇数，右半部分从第 $27$ 列（索引 $27$，即实际第 $28$ 列）开始，左半部分从第 $26$ 列（索引 $26$）向左。这个数值需要根据网格坐标仔细推导。
- 字符串可能包含空格，在 $\texttt{C5}$ 字体中空格对应全句点的模板，不会覆盖任何内容。
- 输出格式要求每页后有两个空行（一个空行 + 短横线行 + 另一个空行），注意不要遗漏。

本题虽然逻辑复杂，但只要分模块实现（字体渲染、对齐计算、边界检查），并仔细验证坐标计算，就能正确完成。
