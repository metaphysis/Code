## 题目描述

题目要求分析整数序列中的“上升序列”和“下降序列”。定义如下：

- **上升序列（$\texttt{Up sequence}$）** ：连续的一段序列，其中每个数据值不小于前一个数据值。当遇到一个小于前一个数据值的数时，当前上升序列终止。
- **下降序列（$\texttt{Down sequence}$）** ：连续的一段序列，其中每个数据值不大于前一个数据值。当遇到一个大于前一个数据值的数时，当前下降序列终止。

上升序列和下降序列可以交替出现。当下降序列终止时，新的上升序列开始（此时新序列的长度为 $1$，包含终止下降序列的最后一个值），反之亦然。所有初始数据值都参与上升序列（如果第一个偏差是上升）或下降序列（如果第一个偏差是下降）。如果序列中的数据值无法分类为上升或下降（例如所有值相等），则认为既没有上升序列也没有下降序列。

对于每组输入序列，需要计算所有上升序列的平均长度和所有下降序列的平均长度。

## 输入格式

输入包含多行，每行代表一个待分析的序列。每行包含若干个无符号非零整数（最多 $30$ 个），整数之间用单个空格分隔，每行以一个单独的 $0$ 作为序列结束标志（该 $0$ 不属于序列）。整个输入以单独一行的一个 $0$ 作为结束标志。

## 输出格式

对于每个序列，输出一行，格式为：
```
Nr values = N:  average_up  average_down
```
其中 $N$ 是序列中整数的个数，$\textit{average\_up}$ 是上升序列的平均长度，$\textit{average\_down}$ 是下降序列的平均长度。两个平均值保留 $6$ 位小数。

## 题目分析

本题的核心是在一个整数序列中识别出所有的上升序列和下降序列，并计算它们的平均长度。需要注意序列长度定义为序列包含的数据值个数，且相邻序列共享边界数据值。

### 序列的识别规则

设序列为 $a_1, a_2, \ldots, a_n$。从第一个数开始，观察第二个数与第一个数的关系：
- 如果 $a_2 > a_1$，则初始方向为上升，所有初始数据值参与上升序列。
- 如果 $a_2 < a_1$，则初始方向为下降，所有初始数据值参与下降序列。
- 如果 $a_2 = a_1$，则无法确定初始方向，需要继续向后寻找第一个非相等的关系。如果一直相等直到结束，则整个序列既无上升也无下降序列。

### 序列的边界处理

当一个上升序列（或下降序列）终止时，终止的那个数据值同时是下一个序列的起始值。例如序列 $1, 2, 3, 2, 1$：
- 上升序列：$1, 2, 3$（长度 $3$）
- 下降序列：$3, 2, 1$（长度 $3$）
此处 $3$ 同时是两个序列的边界，在两个序列中都被计入。

### 实现方法

可以采用双指针或状态机的方法扫描序列：
1. 初始化 $\textit{upCount} = 0$（上升序列个数），$\textit{upLength} = 0$（上升序列长度总和），$\textit{downCount}$ 和 $\textit{downLength}$ 类似。
2. 扫描序列，记录当前序列的类型（上升、下降或未定）和当前序列的长度。
3. 当类型发生变化时，将当前序列的长度（减 $1$？注意边界值重复计入的处理）累加到对应计数器中，然后开始新序列。
4. 扫描结束后，处理最后一个序列。

更简洁的方法是：将序列视为一系列“转折点”。每个上升序列的长度等于从上升开始到下一个下降开始之间的数据值个数，下降序列同理。

参考代码的实现方式为：使用两个向量 $\textit{up}$ 和 $\textit{down}$ 分别暂存当前正在构建的上升序列和下降序列。每次读入一个新数：
- 如果该数不小于 $\textit{up}$ 的最后一个数，则将其加入 $\textit{up}$；否则，说明上升序列结束，将当前 $\textit{up}$ 的长度计入上升统计，然后清空 $\textit{up}$，并将上一个数和当前数作为新的下降序列的起点。
- 下降序列的处理对称。

### 边界情况

- 如果序列中所有数相等，则既没有上升也没有下降序列，平均值均为 $0$。
- 如果序列长度 $n = 1$，无法形成任何序列，平均值均为 $0$。
- 如果序列单调递增，则只有一个上升序列，长度为 $n$，下降序列数为 $0$。
- 如果序列单调递减，则只有一个下降序列，长度为 $n$，上升序列数为 $0$。

### 复杂度分析

每组数据只需要一次线性扫描，时间复杂度 $O(n)$，$n \le 30$，完全可接受。

```cpp
// Up and Down Sequences

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    cout.precision(6);
    
    while (true)
    {
        vector<int> up, down;
        int number, numberCounter = 0;
        int up_length = 0, down_length = 0, up_sequence = 0, down_sequence = 0;
        
        while (cin >> number, number)
        {
            numberCounter++;
            
            if (up.size() == 0 || number >= up.back()) up.push_back(number);
            else if (up.size() > 1 && up.back() > up.front())
            {
                up_sequence += 1;
                up_length += up.size() - 1;
                
                down.clear();
                down.push_back(up.back());
                down.push_back(number);
                up.clear();
                continue;
            }
            
            if (down.size() == 0 || number <= down.back()) down.push_back(number);
            else if (down.size() > 1 && down.back() < down.front())
            {
                down_sequence += 1;
                down_length += down.size() - 1;
                
                up.clear();
                up.push_back(down.back());
                up.push_back(number);
                down.clear();
            }
        }

        if (up.size() > 1 && up.back() > up.front())
        {
            up_sequence += 1;
            up_length += up.size() - 1;
        }
        
        if (down.size() > 1 && down.back() < down.front())
        {
            down_sequence += 1;
            down_length += down.size() - 1;
        }
        
        if (numberCounter == 0)
            break;
        
        cout << "Nr values = " << numberCounter << ":  ";
        cout << fixed << (up_sequence > 0 ? ((double)up_length / (double)up_sequence) : 0.0);
        cout << ' ';
        cout << fixed << (down_sequence > 0 ? ((double)down_length / (double)down_sequence) : 0.0);
        cout << '\n';
    }
    
    return 0;
}
```
