[UVa 414 Machined Surfaces](https://blog.csdn.net/metaphysis/article/details/161762833)

## 题目描述

题目描述了一个由字符 `X` 和空格组成的数字图像。图像总是有 $25$ 列，行数 $N$ 可变。第 $1$ 列始终是 `X`，属于左侧表面；第 $25$ 列始终是 `X`，属于右侧表面。每行中，左侧表面是从第 $1$ 列开始连续的一段 `X`，右侧表面是从第 $25$ 列开始向左连续的一段 `X`，中间有零个或多个空格。将左表面和右表面水平向中间移动，直到某一行中左表面的最右侧 `X` 恰好位于右表面最左侧 `X` 的左侧相邻位置。移动过程中，表面保持刚性，只做水平平移。要求计算移动后所有行中剩余的空格总数（即“空隙”）。

## 输入格式

输入包含多组图像数据。每组数据格式如下：
- 第一行一个无符号整数 $N$（$0 < N < 13$），表示图像的行数。
- 接下来 $N$ 行，每行恰好 $25$ 个字符：一个或多个 `X`，然后零个或多个空格，然后一个或多个 `X`。
- 输入以单独一行的一个 $0$ 作为结束标志。

## 输出格式

对于每组图像数据，输出一个整数，表示移动后剩余的空格总数。

## 样例

输入

```
4
XXXXBBBBBBBBBBBBBBBBXXXXX
XXXBBBBBBBBBBBBBBBXXXXXXX
XXXXXBBBBBBBBBBBBBBBBXXXX
XXBBBBBBBBBBBBBBBBBXXXXXX
2
XXXXXXXXXXXXXXXXXXXXXXXXX
XXXXXXXXXXXXXXXXXXXXXXXXX
1
XXXXXXXXXBBBBBBBBBBBBBBXX
0
```

（注：样例中的 `B` 实际为空格字符）

输出

```
4
0
0
```

## 题目分析

本题的核心是计算将左表面和右表面水平相向移动至接触后，所有行中剩余的空格总数。

### 问题转化

每行由左表面的 `X`、中间的空格、右表面的 `X` 组成。设第 $i$ 行的空格数为 $\textit{space}[i]$。当两表面移动接触时，所有行的左表面和右表面会同时移动。移动的距离由某一行中中间空隙最小的行决定（因为该行最先接触）。设最小空格数为 $m = \min(\textit{space}[1], \textit{space}[2], \ldots, \textit{space}[N])$。移动后，原本有 $m$ 个空格的行会变成 $0$ 个空格（两表面刚好接触），而原本空格数大于 $m$ 的行，剩余空格数为 $\textit{space}[i] - m$。

因此，移动后剩余的空格总数为：
$$
\textit{total} = \sum_{i=1}^{N} (\textit{space}[i] - m) = \left( \sum_{i=1}^{N} \textit{space}[i] \right) - N \times m
$$

### 实现步骤

1. 读取 $N$，若 $N = 0$ 则结束。
2. 读取 $N$ 行字符串，每行长度固定为 $25$。
3. 统计每行中空格的个数，存入数组。
4. 找出空格数的最小值 $m$。
5. 计算总和减去 $N \times m$，输出结果。

### 边界情况

- 如果某行没有空格（即左右表面已经接触或重叠），则该行空格数为 $0$。
- 如果所有行都没有空格，则 $m = 0$，总空隙为 $0$。
- 输入保证每行的格式为：`X`...（若干）空格...`X`...，不会出现其他情况。

### 复杂度分析

每组数据需要扫描 $N$ 行，每行 $25$ 个字符，时间复杂度 $O(25N)$，$N < 13$，完全可接受。

```cpp
// Machined Surfaces

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    ios::sync_with_stdio(false);

    string line;
    int N;
    while (cin >> N, N)
    {
        cin.ignore(1024, '\n');
        vector<int> spaces;
        for (int i = 1; i <= N; i++)
        {
            getline(cin, line);
            spaces.push_back(count(line.begin(), line.end(), ' '));
        }
        
        int minimum = *min_element(spaces.begin(), spaces.end()), total = 0;
        total = accumulate(spaces.begin(), spaces.end(), total) - minimum * spaces.size();

        cout << total << endl;
    }
    
    return 0;
}
```
