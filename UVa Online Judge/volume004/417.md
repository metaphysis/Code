## 题目描述

题目定义了一类特殊单词：单词中的字母必须严格递增（即后一个字母在字母表中的位置必须大于前一个字母）。例如 $\texttt{abc}$、$\texttt{aep}$、$\texttt{gwz}$ 都是有效的三字母单词，而 $\texttt{aab}$、$\texttt{are}$、$\texttt{cat}$ 不是。所有有效单词按字典序排列，每个单词对应一个序号。例如：

- $\texttt{a} \rightarrow 1$
- $\texttt{b} \rightarrow 2$
- $\texttt{z} \rightarrow 26$
- $\texttt{ab} \rightarrow 27$
- $\texttt{ac} \rightarrow 28$
- $\texttt{az} \rightarrow 51$
- $\texttt{bc} \rightarrow 52$
- $\texttt{vwxyz} \rightarrow 83681$

对于每个输入的单词，判断其是否有效。若无效则输出 $0$；若有效则输出其在列表中的序号。

## 输入格式

输入包含多行，每行一个单词。单词由小写字母组成，长度至少为 $1$，最多为 $5$。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每个输入的单词，输出一行一个整数，表示该单词的序号（若无效则为 $0$）。

## 样例

输入

```
z
a
cat
vwxyz
```

输出

```
26
1
0
83681
```

## 题目分析

本题的核心是计算给定有效单词在严格递增字母序列中的字典序序号。

### 问题规模

由于单词长度最多为 $5$，所有有效单词的总数为：
$$
\sum_{k=1}^{5} \binom{26}{k}
$$
这是因为从 $26$ 个字母中任选 $k$ 个不同的字母，按升序排列唯一对应一个有效单词。计算得：
$$
\binom{26}{1} + \binom{26}{2} + \binom{26}{3} + \binom{26}{4} + \binom{26}{5} = 26 + 325 + 2600 + 14950 + 65780 = 83681
$$
因此最大序号为 $83681$。

### 方法一：预处理所有有效单词

由于总数不超过 $10^5$，可以预先生成所有有效单词并建立从单词到序号的映射。生成方法：
- 从单个字母开始（$\texttt{a}$ 到 $\texttt{z}$），序号从 $1$ 开始。
- 使用广度优先搜索（$\texttt{BFS}$）或递归生成：对于当前单词，在其末尾添加一个比最后一个字母大的字母，形成新单词。
- 将生成的新单词存入映射，序号递增。
- 生成所有长度不超过 $5$ 的单词后，对于每个输入单词，直接查表输出。

### 方法二：组合数直接计算

对于有效单词 $s = s_1 s_2 \ldots s_k$，其序号等于：
1. 所有长度小于 $k$ 的有效单词总数。
2. 加上长度等于 $k$ 且字典序小于 $s$ 的有效单词数。

长度小于 $k$ 的总数为：
$$
\sum_{i=1}^{k-1} \binom{26}{i}
$$

对于长度等于 $k$ 且字典序小于 $s$ 的单词，可以按位计算：
- 对于第 $1$ 位，可以从 $\texttt{a}$ 开始枚举到 $s_1 - 1$，每个选择的字母 $c$ 对应从剩余字母中选 $k-1$ 个的排列数。
- 对于第 $2$ 位，固定第 $1$ 位为 $s_1$，枚举第 $2$ 位从 $s_1 + 1$ 到 $s_2 - 1$，每个选择对应从剩余字母中选 $k-2$ 个的排列数。
- 依此类推。

参考代码采用了第一种方法（预处理），实现简单且直观。

### 有效性判断

输入单词需要先判断是否严格递增（即每个字符大于前一个字符）。若不满足，直接输出 $0$。

### 复杂度分析

预处理生成所有有效单词：最多生成 $83681$ 个单词，每个单词通过 $\texttt{BFS}$ 扩展最多 $26$ 次，总操作数约 $2 \times 10^6$，完全可接受。查询为 $O(1)$。

## 代码实现

```cpp
// Word Index
// UVa ID: 417
// Verdict: Accepted
// Submission Date: 2016-07-15
// UVa Run Time: 0.020s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

map<string, int> indexer;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string letters = "abcdefghijklmnopqrstuvwxyz";
    int counter = 1;
    queue<string> generator;
    
    for (int i = 0; i < letters.length(); i++)
    {
        generator.push(string(1, letters[i]));
        indexer[string(1, letters[i])] = counter++;
    }
    
    while (!generator.empty())
    {
        string current = generator.front();
        generator.pop();
        
        if (current.length() == 5) continue;
        
        for (int i = 0; i < letters.length(); i++)
        {
            if (letters[i] > current.back())
            {
                generator.push(current + letters[i]);
                indexer[current + letters[i]] = counter++;
            }
        }
    }
    
    string line;
    while (cin >> line)
    {
        bool valid = true;
        for (int i = 0; i < line.length() - 1; i++)
            if (line[i] >= line[i + 1])
            {
                valid = false;
                break;
            }
            
        if (!valid)
        {
            cout << "0" << endl;
            continue;
        }
        
        cout << indexer[line] << endl;
    }
    
    return 0;
}
```
