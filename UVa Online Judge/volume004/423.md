## 题目描述

题目要求计算从第一个处理器向所有其他处理器广播消息所需的最短时间。给定 $n$ 个处理器之间的通信延迟（以邻接矩阵形式给出），消息可以通过中间处理器转发，且每个处理器可以同时向多个其他处理器发送消息。需要找出从处理器 $1$ 到所有其他处理器的最短路径中的最大值（即广播完成所需的最短时间）。

## 输入格式

第一行一个整数 $n$（$1 \le n \le 100$），表示处理器的数量。  
接下来若干行，输入邻接矩阵的下三角部分（不含对角线）。具体格式为：
- 第 $2$ 行包含 $A_{2,1}$
- 第 $3$ 行包含 $A_{3,1}$ 和 $A_{3,2}$
- 第 $4$ 行包含 $A_{4,1}$、$A_{4,2}$ 和 $A_{4,3}$
- 依此类推，直到第 $n$ 行包含 $A_{n,1}$ 到 $A_{n,n-1}$

每个条目为一个整数（表示通信延迟）或字符 `x`（表示不能直接通信）。输入保证网络是无向的，即 $A_{i,j} = A_{j,i}$，且 $A_{i,i} = 0$。

## 输出格式

输出一个整数，表示从处理器 $1$ 向所有其他处理器广播消息所需的最短时间。

## 样例

输入

```
5
50
30 5
100 20 50
10 x x 10
```

输出

```
35
```

## 题目分析

本题的核心是计算从源节点（处理器 $1$）到所有其他节点的最短路径，然后取这些路径长度的最大值。由于消息可以同时沿多条路径转发，广播完成的时间取决于最慢的那条路径。

### 问题转化

给定 $n$ 个节点的无向图，每条边有权重（通信延迟），节点 $i$ 到节点 $j$ 不可达时权重视为无穷大。需要计算：
$$
\text{answer} = \max_{2 \le j \le n} \text{dist}(1, j)
$$
其中 $\text{dist}(1, j)$ 为节点 $1$ 到节点 $j$ 的最短路径长度。

### 算法选择

由于 $n \le 100$，可以使用 $\texttt{Floyd-Warshall}$ 算法（$O(n^3)$）计算所有节点对之间的最短路径，然后取第一行的最大值。也可以使用 $\texttt{Dijkstra}$ 算法（$O(n^2)$ 或 $O((n + m) \log n)$）从源节点计算单源最短路径。考虑到输入规模较小，两种方法均可。

### 输入解析

输入只给出了邻接矩阵的下三角部分。需要正确读取这些值并构建对称的邻接矩阵：
- 对于 $i > j$，读取值 $A_{i,j}$。
- 若值为 `x`，则 $A_{i,j} = A_{j,i} = \infty$（不可达）。
- 否则，$A_{i,j} = A_{j,i} = \text{读入的整数}$。
- 对角线元素 $A_{i,i} = 0$。

### 最短路径计算

使用 $\texttt{Floyd-Warshall}$ 算法：
- 初始化 $\textit{dist}[i][j] = \infty$，$\textit{dist}[i][i] = 0$。
- 对于每条边 $(u, v, w)$，设置 $\textit{dist}[u][v] = \textit{dist}[v][u] = w$。
- 三重循环更新：$\textit{dist}[i][j] = \min(\textit{dist}[i][j], \textit{dist}[i][k] + \textit{dist}[k][j])$。

计算完成后，$\textit{dist}[1][j]$ 即为节点 $1$ 到节点 $j$ 的最短距离。

### 结果

输出 $\max_{j=1}^{n} \textit{dist}[1][j]$（$\textit{dist}[1][1] = 0$，不影响最大值）。

### 复杂度分析

$\texttt{Floyd-Warshall}$ 时间复杂度 $O(n^3) = 10^6$，$n \le 100$ 时完全可接受。

```cpp
// MPI Maelstrom

#include <bits/stdc++.h>

using namespace std;

const long long MAX_TIMES = numeric_limits<int>::max();

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    long long n, times[110][110];
    
    while (cin >> n)
    {
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                times[i][j] = MAX_TIMES;
        
        string digits;
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= i - 1; j++)
            {
                cin >> digits;
                if (digits == "x") continue;
                else
                {
                    times[i][j] = stoll(digits);
                    times[j][i] = times[i][j];
                }
            }
            
        for (int i = 1; i <= n; i++)
            times[i][i] = 0;
            
        for (int k = 1; k <= n; k++)
            for (int i = 1; i <= n; i++)
                for (int j = 1; j <= n; j++)
                    if (times[i][j] > times[i][k] + times[k][j])
                        times[i][j] = times[i][k] + times[k][j];
        
        // from THE first node to another NODE                
        long long max_delay = 0;
        for (int j = 1; j <= n; j++)
            max_delay = max(max_delay, times[1][j]);

        cout << max_delay << '\n';
    }
    
    return 0;
}
```
