[UVa 427 FlatLand Piano Movers](https://blog.csdn.net/metaphysis/article/details/161788268)

## 题目描述

题目要求判断给定尺寸的矩形钢琴能否绕过直角转弯的走廊。钢琴只能以其较短的边作为前进方向（即只能推或拉较短边），且钢琴的宽度小于走廊宽度。每个转弯由两个走廊宽度描述：进入转弯前的走廊宽度 $a$ 和转过弯后的走廊宽度 $b$。需要为每个转弯输出 `Y`（能通过）或 `N`（不能通过）。

## 输入格式

输入包含多行，每行最多 $80$ 个字符。每行由若干数对组成，数对之间用至少一个空格分隔。第一个数对表示钢琴的尺寸（长度和宽度），后续数对表示每个转弯的走廊宽度（进入宽度和离开宽度）。数对内的两个数字用逗号分隔。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每个钢琴（即每行输入），输出一行，包含与该钢琴对应的每个转弯的判断结果（`Y` 或 `N`），按输入顺序排列。

## 样例

输入

```
600,200 300,500 837,500 350,350
137,1200 600,500 600,400
```

输出

```
YYN
YN
```

## 题目分析

本题的核心是判断一个矩形能否绕过直角转弯。这是一个经典的几何优化问题。

### 问题建模

设钢琴的长度为 $l$，宽度为 $w$，且 $l \ge w$。走廊转弯前宽度为 $a$，转弯后宽度为 $b$。钢琴在转弯过程中，其较长边 $l$ 会倾斜，较短边 $w$ 始终保持与走廊墙壁平行（因为只能推或拉较短边）。需要判断是否存在一个倾斜角度，使得钢琴能够同时通过两个走廊。

### 几何推导

建立坐标系：将转弯的内角点设为原点，两条走廊的墙壁分别沿 $x$ 轴正方向和 $y$ 轴正方向。走廊宽度 $a$ 对应 $x$ 方向（转弯前），$b$ 对应 $y$ 方向（转弯后）。钢琴在转弯时，其较长边与 $x$ 轴夹角为 $\theta$，较短边与 $y$ 轴平行。钢琴的四个顶点中，最靠近原点的点坐标决定了是否能通过。

经过推导，钢琴能通过转弯的条件等价于存在 $x \in [0, l]$ 使得：
$$
\sqrt{l^2 - x^2} \cdot (a - x) + b \cdot x \ge l \cdot w
$$
其中 $x$ 为钢琴较长边在 $x$ 轴上的投影长度。

更常见的形式是：定义函数 $f(x) = (a - x) \cdot \sqrt{l^2 - x^2} + b \cdot x - l \cdot w$，若能找到 $x \in [0, l]$ 使得 $f(x) \ge 0$，则钢琴能通过。实际上，需要检查 $f(x)$ 的最大值是否 $\ge 0$。

### 函数性质

$f(x)$ 在区间 $[0, l]$ 上是单峰函数（先增后减），因此可以使用三分搜索（$\texttt{ternary search}$）求最大值。若最大值 $\ge 0$，则能通过；否则不能。

### 算法步骤

1. 读取一行输入，解析第一个数对作为钢琴尺寸 $l$ 和 $w$，确保 $l \ge w$。
2. 对于后续每个数对 $(a, b)$：
   - 在区间 $[0, l]$ 上使用三分搜索求 $f(x)$ 的最大值。
   - 若最大值 $\ge 0$，输出 `Y`；否则输出 `N`。
3. 输出换行。

### 三分搜索实现

三分搜索用于在单峰函数上寻找极值点：
- 初始化 $\textit{left} = 0$，$\textit{right} = l$。
- 当 $\textit{right} - \textit{left} > \epsilon$ 时：
  - 计算 $\textit{mid} = (\textit{left} + \textit{right}) / 2$，$\textit{midmid} = (\textit{mid} + \textit{right}) / 2$。
  - 若 $f(\textit{mid}) > f(\textit{midmid})$，则最大值在 $[\textit{left}, \textit{midmid}]$ 内，令 $\textit{right} = \textit{midmid}$。
  - 否则，最大值在 $[\textit{mid}, \textit{right}]$ 内，令 $\textit{left} = \textit{mid}$。
- 结束后，$f(\textit{left})$ 即为最大值。

### 复杂度分析

每个转弯使用 $O(\log(l / \epsilon))$ 次函数求值，$l \le 10^4$ 量级，$\epsilon = 10^{-6}$，次数约为 $50$，完全可接受。

## 代码实现

```cpp
// FlatLand Piano Movers
// UVa ID: 427

// Submission Date: 2016-08-01
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const double EPSILON = 1e-6;

double l, w, a, b;
char comma;

double f(double x)
{
    return sqrt(l * l - x * x) * (a - x) + b * x - l * w;
}

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    while (getline(cin, line))
    {
        istringstream iss(line);

        iss >> l >> comma >> w;

        if (l < w) swap(l, w);

        while (iss >> a >> comma >> b)
        {
            double left = 0, right = l;
            do
            {
                double mid = (left + right) / 2, midmid = (right + mid) / 2;

                if (f(mid) > f(midmid))
                    left = mid;
                else
                    right = midmid;
            } while (fabs(left - right) > EPSILON);
            
            cout << (f(left) >= 0 ? 'Y' : 'N');
        }
        cout << '\n';
    }
    
    return 0;
}
```
