## 题目描述

题目要求计算每个沼泽（投票者）的 $\texttt{Banzhaf}$ 权力指数。给定通过一项法令所需的最低票数（$\textit{majority}$）以及每个沼泽持有的票数，$\texttt{Banzhaf}$ 权力指数定义为该沼泽能够改变投票结果（即从失败变为通过）的次数。具体来说，对于每个沼泽 $i$，考虑所有不包括 $i$ 的投票子集，若这些子集的票数和 $S$ 满足 $S < \textit{majority}$ 但 $S + \textit{votes}[i] \ge \textit{majority}$，则该子集计为一次关键投票。权力指数即为这样的关键投票子集的数量。

## 输入格式

输入包含多行，每行最多 $80$ 个字符。每行第一个整数为 $\textit{majority}$（通过所需的最低票数），后续若干个整数为每个沼泽持有的票数。沼泽数量不超过 $27$。

## 输出格式

对于每个测试用例（每行输入），输出一行，包含每个沼泽的 $\texttt{Banzhaf}$ 权力指数，按输入顺序排列，之间用单个空格分隔。

## 题目分析

本题的核心是计算每个投票者的 $\texttt{Banzhaf}$ 权力指数，即统计所有不含该投票者的子集中，票数和小于 $majority$ 但加上该投票者后大于等于 $majority$ 的子集个数。

### 问题转化

设总共有 $n$ 个投票者，票数数组为 $v[0..n-1]$，通过所需票数为 $M$。对于投票者 $k$，定义：
$$
power(k) = \left| \left\{ S \subseteq \{0,\ldots,n-1\} \setminus \{k\} \;\middle|\; \sum_{i \in S} v[i] < M \le \sum_{i \in S} v[i] + v[k] \right\} \right|
$$
即所有不含 $k$ 的子集中，满足上述条件的个数。

### 动态规划方法

对于每个 $k$，我们需要统计所有不含 $k$ 的子集的票数和分布。这可以通过 $\texttt{0/1}$ 背包问题实现：

- 定义 $dp[s]$ 表示不考虑 $k$ 时，子集和为 $s$ 的方案数。
- 初始化 $dp[0] = 1$。
- 遍历所有 $i \ne k$，对于每个 $i$，从大到小更新 $dp$：$dp[j] += dp[j - v[i]]$。
- 计算完成后，$power(k) = \sum_{j = \max(0, M - v[k])}^{M-1} dp[j]$。

### 复杂度分析

对于每个 $k$，需要运行一次 $\texttt{0/1}$ 背包，时间复杂度 $O(n \times sum)$，其中 $sum$ 为总票数和。由于 $n \le 27$，票数可能较大（但总和有限），直接使用大小为 $sum+1$ 的数组即可。若总和过大，可优化只计算到 $M$ 附近，但题目数据范围下直接运行可接受。

### 实现细节

- 使用 `memset` 或 `fill` 初始化 $dp$ 数组。
- 注意 $dp[0] = 1$ 表示空子集。
- 在累加 $power(k)$ 时，注意下界 $\max(0, M - v[k])$ 和上界 $M-1$。
- 输出时按输入顺序输出每个 $power(k)$。

## 代码实现

```cpp
// Swamp County Supervisors
// UVa ID: 430
// Verdict: Accepted
// Submission Date: 2018-03-19
// UVa Run Time: 0.000s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 10010;

int dp[MAXN];
int votes[30], majority = 0, members = 0, cnt = 0;
        
int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    while (getline(cin, line))
    {
        // Read input.
        istringstream iss(line);
        iss >> majority;
        cnt = 0;
        while (iss >> members)
            votes[cnt++] = members;
        
        // DP, knapsack, count of different subset sum.
        for (int k = 0; k < cnt; k++)
        {
            memset(dp, 0, sizeof(dp));
            dp[0] = 1;
            for (int i = 0; i < cnt; i++)
            {
                if (i == k) continue;
                for (int j = majority; j >= votes[i]; j--)
                    if (dp[j - votes[i]])
                        dp[j] += dp[j - votes[i]];
            }

            // Print.
            int powerIndex = 0;
            for (int i = max(0, majority - votes[k]); i < majority; i++)
                powerIndex += dp[i];
            if (k) cout << ' ';
            cout << powerIndex;
        }
        cout << '\n';
    }
    
    return 0;
}
```
