## 题目描述

题目要求根据给定的绘画标题 $T_{p,q}$ 和顶部三角形的顶点坐标 $(x, y)$，按照 $\texttt{Mel}$ 的绘制顺序输出所有线段的起点和终点坐标。绘画由一系列等边三角形组成，绘制规则如下：

- $T_{0,0}$ 是一个单独的三角形。
- $T_{1,1}$ 是在 $T_{0,0}$ 内部放置一个倒置的小三角形，将原三角形分成四个小三角形。
- 若 $p > 0$ 且 $q > 1$，则 $T_{p,q}$ 是在 $T_{p,q-1}$ 的右下角三角形内部放置一个倒置的小三角形，将该三角形分成四个更小的三角形。
- 若 $p > 1$ 且 $q > 0$，则 $T_{p,q}$ 是在 $T_{p-1,q}$ 的左下角三角形内部放置一个倒置的小三角形，将该三角形分成四个更小的三角形。
- 其他 $p, q$ 值为无效标题（但输入保证有效）。

绘制时，$\texttt{Mel}$ 从顶部三角形的顶点开始，按特定顺序遍历所有三角形的边，形成一条不间断的路径。

## 输入格式

第一行一个整数 $N$，表示测试用例的数量。接下来 $N$ 行，每行四个非负整数 $p, q, x, y$，其中 $T_{p,q}$ 为绘画标题，$(x, y)$ 为顶部三角形的顶点坐标。$p, q \le 10$，$x, y < 32768$。

## 输出格式

对于每个测试用例，输出若干行，每行格式为 `(startX,startY)(endX,endY)`，表示一条线段的起点和终点坐标。按绘制顺序输出。每个测试用例的输出后跟一个空行。

输入

```
2
0 0 1 1

```

输出

(1,1)(0,0)
(0,0)(2,0)

## 题目分析

本题的核心是生成 $T_{p,q}$ 的顶点序列，并按绘制顺序输出线段。

### 几何结构

$T_{p,q}$ 的几何结构可以通过递归生成。观察发现，$T_{p,q}$ 可以看作是在一个大的等边三角形内部进行递归细分。每个三角形被倒置的小三角形分割成四个小三角形。顶点坐标可以根据基础三角形的顶点坐标和细分层次计算。

### 顶点生成方法

参考代码采用了一种简洁的方法：先生成 $T_{10,10}$ 的完整顶点序列（按某种顺序），然后根据 $p$ 和 $q$ 截取所需部分。

具体来说：
1. 初始化一个包含 $T_{0,0}$ 四个顶点的序列（按绘制顺序）：顶部顶点 $(x, 0)$、左下顶点 $(x/2, y/2)$、右下顶点 $(x + x/2, y/2)$，然后回到顶部顶点。
2. 对于层次 $j = 2$ 到 $10$，每次在序列的前端和后端各插入 $4$ 个顶点，以扩展三角形的细分。
3. 经过 $10$ 次扩展后，得到 $T_{10,10}$ 的完整顶点序列。
4. 根据 $p$ 和 $q$ 的值，从序列前端删除 $4 \times (10 - p)$ 个顶点，从序列后端删除 $4 \times (10 - q)$ 个顶点，得到 $T_{p,q}$ 的顶点序列。
5. 在序列的最前端插入 $(0, 0)$ 和 $(x, y)$，在最后端插入 $(2x, 0)$ 和 $(x, y)$，得到最终的顶点路径。
6. 依次输出相邻顶点对作为线段。

### 绘制顺序

参考代码生成的顶点序列已经按照 $\texttt{Mel}$ 的绘制顺序排列，因此直接输出相邻顶点对即可。

### 坐标计算

注意输入中的 $(x, y)$ 是顶部三角形的顶点坐标，底部边位于 $y = 0$ 上。所有坐标均为整数，且三角形为非退化的。

### 复杂度分析

生成 $T_{10,10}$ 的顶点序列需要 $O(4 \times 10)$ 次操作，顶点数约为 $4 \times 10 + 4 = 44$，非常小。每个测试用例只需常数时间。

## 代码实现

```cpp
// Modern Art
// UVa ID: 432

// UVa Run Time: 0.010s

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int cases, p, q, x, y;;
    cin >> cases;

    for (int i = 1; i <= cases; i++)
    {
        cin >> p >> q >> x >> y;

        vector<pair<int, int>> Tpq;
        Tpq.push_back(make_pair(x, 0));
        Tpq.push_back(make_pair(x / 2, y / 2));
        Tpq.push_back(make_pair(x + x / 2, y / 2));
        Tpq.push_back(make_pair(x, 0));
        
        for (int j = 2; j <= 10; j++)
        {
            int xx = Tpq[0].first, yy = Tpq[1].second;
    
            Tpq.insert(Tpq.begin(), make_pair(xx / 2, 0));
            Tpq.insert(Tpq.begin(), make_pair(3 * xx / 4, yy / 2));
            Tpq.insert(Tpq.begin(), make_pair(xx / 4, yy / 2));
            Tpq.insert(Tpq.begin(), make_pair(xx / 2, 0));
            
            Tpq.push_back(make_pair(2 * x - xx / 2, 0));
            Tpq.push_back(make_pair(2 * x - 3 * xx / 4, yy / 2));
            Tpq.push_back(make_pair(2 * x - xx / 4, yy / 2));
            Tpq.push_back(make_pair(2 * x - xx / 2, 0));
        }
        
        for (int i = 1; i <= 4 * (10 - p); i++)
            Tpq.erase(Tpq.begin());
            
        for (int i = 1; i <= 4 * (10 - q) && Tpq.size() > 0; i++)
            Tpq.erase(Tpq.end() - 1);

        Tpq.insert(Tpq.begin(), make_pair(0, 0));
        Tpq.insert(Tpq.begin(), make_pair(x, y));
        Tpq.push_back(make_pair(2 * x, 0));
        Tpq.push_back(make_pair(x, y));
        
        for (int i = 0; i < Tpq.size() - 1; i++)
        {
            cout << '(' << Tpq[i].first << ',' << Tpq[i].second << ')';
            cout << '(' << Tpq[i + 1].first << ',' << Tpq[i + 1].second << ')';
            cout << '\n';
        }
        cout << '\n';
    }
    
    return 0;
}
```
