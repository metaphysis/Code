[UVa 434 Matty's Blocks](https://blog.csdn.net/metaphysis/article/details/161819346)

## 题目描述

题目要求根据建筑物的前视图和右视图，确定重建该建筑物所需的最少积木数量 $N$，以及在不改变前后视图的情况下最多可以额外添加的积木数量 $M$。建筑物由 $K \times K$ 个格子组成（$K = 8$ 为最大尺寸），每个格子上堆叠 $0$ 到 $8$ 个积木。前视图给出了每列的最大高度，右视图给出了每行的最大高度。需要找到：
- 最少积木数 $N$：使得存在一种积木放置方式，其前视图和右视图与给定视图一致。
- 最多可添加积木数 $M$：在保持视图不变的前提下，从最少积木数出发最多还能添加多少积木。

## 输入格式

第一行一个整数 $T$，表示测试用例的数量。每个测试用例：
- 第一行一个整数 $K$，表示表格的宽度（即视图的长度）。
- 第二行 $K$ 个整数，表示前视图（从左到右每列的最大高度）。
- 第三行 $K$ 个整数，表示右视图（从前到后每行的最大高度，顺序对应前视图的列？实际右视图中第 $i$ 个数字对应第 $i$ 行的最大高度）。

## 输出格式

对于每个测试用例，输出一行：
```
Matty needs at least N blocks, and can add at most M extra blocks.
```

## 样例

输入

```
2
4
2 0 3 1
1 1 2 3
1
1
1
```

输出

```
Matty needs at least 7 blocks, and can add at most 10 extra blocks.
Matty needs at least 1 blocks, and can add at most 0 extra blocks.
```

## 题目分析

本题的核心是根据前视图和右视图，确定积木放置的最小可能总数和最大可能总数。

### 最大积木数 $N + M$

在保持前视图和右视图不变的前提下，每个位置 $(i, j)$（第 $i$ 行第 $j$ 列）可以放置的积木数量上限为：
$$
maxBlocks[i][j] = \min(frontView[j], rightView[i])
$$
这是因为该位置的高度不能超过其所在列的前视图高度，也不能超过其所在行的右视图高度。将所有位置的最大值相加，即得到可能的最大积木总数：
$$
maxTotal = \sum_{i=1}^{K} \sum_{j=1}^{K} \min(frontView[j], rightView[i])
$$

### 最小积木数 $N$

为了达到最少积木数，应尽可能让一个积木同时满足前视图和右视图的贡献。具体策略：
1. 对于每个前视图高度 $h_f$，尝试在右视图中找到一个相同高度的 $h_r$，将这两个视图的贡献用一个积木塔来满足。一个 $h$ 高度的塔同时满足前视图中该列需要至少 $h$ 和右视图中该行需要至少 $h$。
2. 因此，对每个高度值，匹配尽可能多的前视图列和右视图行。一旦匹配成功，该高度 $h$ 贡献 $h$ 个积木，并消除对应的前视图和右视图需求。
3. 未匹配的前视图高度和右视图高度，只能由单独的积木塔来满足，贡献其高度值。

算法步骤：
- 复制前视图数组 $\textit{front}$ 和右视图数组 $\textit{right}$。
- 对于 $\textit{front}$ 中的每个高度 $f$，在 $\textit{right}$ 中寻找相同的值。若找到，则将该高度贡献到 $\textit{minBlocks}$（加上 $f$），并将该 $\textit{right}$ 元素置为 $0$，表示已匹配；同时跳出内层循环，继续处理下一个 $\textit{front}$ 元素。
- 遍历结束后，将 $\textit{front}$ 和 $\textit{right}$ 中剩余的非零值相加，得到额外的积木数。
- 最终 $\textit{minBlocks} =$ 匹配贡献之和 + 剩余前视图之和 + 剩余右视图之和。

### 可添加积木数 $M$

$$
M = maxTotal - minBlocks
$$

### 复杂度分析

每个测试用例需要 $O(K^2)$ 计算最大积木数，$O(K^2)$ 计算最小积木数，$K \le 8$，完全可接受。

```cpp
// Matty's Blocks
// UVa ID: 434

// Submission Date: 2016-07-29
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int cases = 0;
    cin >> cases;

    for (int i = 1; i <= cases; i++)
    {
        int row;
        cin >> row;

        vector<int> front_view(row), right_view(row);

        for (int j = 0; j < row; j++)
            cin >> front_view[j];
        for (int j = 0; j < row; j++)
            cin >> right_view[j];

        int max_blocks = 0;
        for (int j = 0; j < row; j++)
            for (int k = 0; k < row; k++)
                max_blocks += min(right_view[j], front_view[k]);

        int min_blocks = 0;
        for (int j = 0; j < row; j++)
            for (int k = 0; k < row; k++)
                if (front_view[j] == right_view[k])
                {
                    min_blocks += front_view[j];
                    front_view[j] = 0;
                    right_view[k] = 0;
                    break;
                }

        for (int j = 0; j < row; j++)
            min_blocks += front_view[j] + right_view[j];
                   
        cout << "Matty needs at least " << min_blocks;
        cout << " blocks, and can add at most ";
        cout << (max_blocks - min_blocks) << " extra blocks.\n";
    }

    return 0;
}
```
