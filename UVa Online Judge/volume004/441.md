## 题目描述

题目要求从给定的集合 $S$（包含 $k$ 个数字）中选出所有 $6$ 个数字的组合，并按字典序输出。集合 $S$ 中的数字已按升序给出。每个组合内的数字也按升序排列。

## 输入格式

输入包含多个测试用例。每个测试用例一行，第一个整数 $k$（$6 < k < 13$），后面跟 $k$ 个升序排列的整数，表示集合 $S$。输入以 $k = 0$ 结束。

## 输出格式

对于每个测试用例，输出所有可能的 $6$ 数字组合，每个组合一行，数字之间用单个空格分隔。组合按字典序输出（即先按第一个数字排序，再按第二个数字排序，依此类推）。测试用例之间用空行分隔，最后一个测试用例后不输出空行。

## 题目分析

本题的核心是生成所有从 $k$ 个数字中选取 $6$ 个数字的组合，并按字典序输出。

### 组合生成

由于 $k \le 12$，总组合数为 $\binom{k}{6}$，最大为 $\binom{12}{6} = 924$，可以直接使用回溯法（深度优先搜索）生成所有组合。

### 回溯算法

从第一个数字开始，每次选择一个数字加入当前组合，然后递归地选择下一个数字。为了避免重复，保证选择的数字索引递增即可。

设当前已选数字个数为 $\textit{depth}$（从 $0$ 开始），上一个选择的数字在数组中的索引为 $\textit{selected\_index}$（初始为 $0$），则下一个数字的索引可以从 $\textit{selected\_index} + 1$ 开始枚举，直到剩余数字足够填满 $6$ 个位置为止。

### 字典序输出

由于输入的数字本身是升序排列的，且回溯过程中按索引递增顺序选择数字，生成的组合自然满足字典序要求（因为组合是按第一个数字递增、第二个数字递增等顺序生成的）。

### 输出格式

每个测试用例输出完成后，若还有下一个测试用例，则输出一个空行。

### 复杂度分析

每个测试用例生成 $\binom{k}{6}$ 个组合，每个组合输出 $6$ 个数字，总复杂度 $O\left(\binom{k}{6} \times 6\right)$，完全可接受。

// Lotto

#include <bits/stdc++.h>

using namespace std;

int k, cases = 0;
vector<int> number(50), selected(6);

void backtrack(int depth, int selected_index)
{
    if (depth == 6)
    {
        for (int i = 0; i < 6; i++)
        {
            if (i > 0) cout << ' ';
            cout << selected[i];
        }
        cout << endl;
        
        return;
    }
    
    for (int i = 1; i <= (k - selected_index) - (5 - depth); i++)
    {
        selected[depth] = number[selected_index + i];
        backtrack(depth + 1, selected_index + i);
    }
}

int main(int argc, char *argv[])
{
    ios::sync_with_stdio(false);

    while (cin >> k, k)
    {
        if (cases++) cout << endl;

        for (int i = 1; i <= k; i++)
            cin >> number[i];

        backtrack(0, 0);
    }
    
    return 0;
}
