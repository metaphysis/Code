## 题目描述

题目要求实现消息的编码和解码功能。编码规则为：从消息的最后一个字符开始到第一个字符结束，依次取出每个字符的 $\texttt{ASCII}$ 码，将该 $\texttt{ASCII}$ 码的十进制数字串反转后拼接在一起。解码时，将编码字符串反转后，按两到三位数字解析出 $\texttt{ASCII}$ 码，还原出原字符。消息只包含大写字母（$\texttt{A} \sim \texttt{Z}$）、小写字母（$\texttt{a} \sim \texttt{z}$）、空格以及字符 `!`、`,`、`.`、`:`、`;`、`?`。

## 输入格式

输入包含多行，每行是一个正常消息（未编码）或已编码的消息。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每行输入，若输入是正常消息，则输出其编码后的字符串；若输入是已编码的消息，则输出其解码后的字符串。

## 样例

输入

```
abc
798999
Have a Nice Day !
```

输出

```
998979
cba
332312179862310199501872379231018117927
```

## 题目分析

本题的核心是实现 $\texttt{ASCII}$ 码与字符之间的双向转换，并正确处理数字串的拼接与解析。

### 编码过程

对于正常消息：
1. 从最后一个字符开始向前遍历每个字符。
2. 获取字符的 $\texttt{ASCII}$ 码（十进制整数）。
3. 将该整数的十进制数字串反转。
4. 将反转后的数字串拼接到编码结果中。
5. 最后输出编码结果。

注意：编码结果是一个数字串，没有空格分隔。

### 解码过程

对于已编码消息（全为数字）：
1. 将整个数字串反转。
2. 从左到右解析数字串，每次取 $2$ 或 $3$ 位数字转换为整数。
3. 该整数即为字符的 $\texttt{ASCII}$ 码，将其转换为字符输出。
4. 解析时需要判断：若当前两位数字 $\ge 32$ 且 $\le 99$，且对应的字符在有效字符集中，则取两位；否则取三位。

### 有效字符集

有效字符及其 $\texttt{ASCII}$  码范围：
- 大写字母：$\texttt{A} \sim \texttt{Z}$（$65 \sim 90$）
- 小写字母：$\texttt{a} \sim \texttt{z}$（$97 \sim 122$）
- 空格：$32$
- 标点符号：`!`（$33$）、`,`（$44$）、`.`（$46$）、`:`（$58$）、`;`（$59$）、`?`（$63$）

由于 $\texttt{ASCII}$ 码 $65$ 到 $99$ 之间既有大写字母也有标点符号，而三位数字必然 $\ge 100$，对应小写字母（$97 \sim 122$）的部分范围。因此解码时可以用查表法或基于范围的判断。

### 实现方法

- 预处理建立字符到数字串的映射 $\textit{encoder}$ 和数字串到字符的映射 $\textit{decoder}$，覆盖所有有效字符。
- 解码时，每遇到一个 $2$ 位或 $3$ 位的数字串，在 $\textit{decoder}$ 中查找对应字符。

### 输入处理

注意输入可能包含空行，空行应直接输出空行。

### 复杂度分析

每条消息长度不超过 $80$，编码和解码均为线性扫描，复杂度 $O(L)$。

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    map<char, string> encoder = {{' ', "32"}, {'!', "33"}, {',', "44"}, {'.', "46"}, {':', "58"}, {';', "59"}, {'?', "63"}};
    map<string, char> decoder = {{"32", ' '}, {"33", '!'}, {"44", ','}, {"46", '.'}, {"58", ':'}, {"59", ';'}, {"63", '?'}};
    
    for (int i = 65; i <= 90; i++)
    {
        string temp = to_string(i);
        encoder[i] = temp;
        decoder[temp] = i;
        
        temp = to_string(i + 32);
        encoder[i + 32] = temp;
        decoder[temp] = i + 32;
    }
    
    string line;
    while (getline(cin, line))
    {
        if (line.length() == 0)
        {
            cout << endl;
            continue;
        }
        
        string text;
        if (isdigit(line.front()))
        {
            reverse(line.begin(), line.end());
            
            int index = 0;
            string normal;
            while (index < line.length())
            {
                if (decoder.find(line.substr(index, 2)) != decoder.end())
                {
                    cout << decoder[line.substr(index, 2)];
                    index += 2;
                    continue;
                }
                
                cout << decoder[line.substr(index, 3)];
                index += 3;
            }
        }
        else
        {
            for (int i = 0; i < line.length(); i++)
                text += encoder[line[i]];
        }
        
        reverse(text.begin(), text.end());
        cout << text << endl;
    }
    
    return 0;
}
