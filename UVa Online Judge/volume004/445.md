[UVa 445 Marvelous Mazes](https://blog.csdn.net/metaphysis/article/details/161848788)

## 题目描述

题目要求根据描述绘制迷宫。每行迷宫的描述由一系列数字和字符组成，数字表示后面字符的重复次数。如果多个数字连续出现，则将这些数字相加作为重复次数。字符 `b` 表示空格。不同行之间用感叹号 `!` 或换行符分隔。不同迷宫之间用一个空行分隔。输出时，每个迷宫按描述绘制，两个迷宫之间输出一个空行。

## 输入格式

输入包含若干行，描述一个或多个迷宫。行内可能包含数字、字母 `A` 到 `Z`、`*`、`b`（表示空格）和 `!`（表示换行）。连续数字应相加。迷宫之间由一个空行分隔。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每个迷宫，输出其图形表示。两个迷宫之间用一个空行分隔。

## 样例

输入

```
1T1b5T!1T2b1T1b2T!1T1b1T2b2T!1T3b1T1b1T!3T3b1T!1T3b1T1b1T!5T1*1T

11X21b1X
4X1b1X
```

输出

```
T TTTTT
T  T T  TT
T T T T T T
T   T T T T
TTT   T
T   T T T T
TTTTT*T

XX X
XXXX X
```

## 题目分析

本题的核心是解析描述字符串，并根据数字累加结果重复输出相应字符。

### 解析规则

- 连续的数字字符：将这些数字相加，得到重复次数。
- 遇到非数字字符（字母、`*`、`b`）：
  - 若字符为 `b`，输出空格。
  - 否则输出该字符。
  - 重复次数为之前累加的数字和
- 遇到 `!`：输出换行。
- 遇到换行符：输出换行，表示当前迷宫的一行结束。连续的换行符（空行）表示迷宫之间的分隔。

### 实现要点

- 由于输入可能包含空格，需要保留空白字符。使用 `cin.unsetf(ios::skipws)` 禁用跳过空白。
- 逐字符读取输入，维护当前行累计的重复次数 `draw_time`。
- 遇到数字时累加到 `draw_time`。
- 遇到 `b` 时输出空格（重复 `draw_time` 次）。
- 遇到其他字母或 `*` 时输出该字符（重复 `draw_time` 次）。
- 遇到 `!` 时输出换行。
- 遇到换行符时输出换行，并重置行内状态。
- 两个迷宫之间的空行需要在输出中体现为两个连续的换行（即一个空行）。

### 复杂度分析

逐字符处理输入，每个字符最多输出 $132$ 次，总复杂度 $O($输入长度 $\times$ 最大重复次数$)$，可接受。

## 代码实现

```cpp
// Marvelous Mazes
// UVa ID: 445

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    ios::sync_with_stdio(false);

    cin.unsetf(ios::skipws);
    
    char control;
    int letter_readed = 0, draw_time = 0;
    while (cin >> control)
    {
        if (control == '\n')
        {
            if (letter_readed == 0)
            {
                cout << '\n';
                continue;
            }
        }
        
        letter_readed++;
        if (isdigit(control)) draw_time += control - '0';
        else if (isblank(control)) continue;
        else if (control == '!') cout << '\n';
        else if (control == '\n')
        {
            cout << '\n';
            letter_readed = 0;
        }
        else
        {
            for (int i = 1; i <= draw_time; i++)
                cout << (control == 'b' ? ' ' : control);
            draw_time = 0;
        }
    }
    
    return 0;
}
```
