[UVa 446 Kibbles n Bits n Bits n Bits](https://blog.csdn.net/metaphysis/article/details/161848802)

## 题目描述

题目要求对给定的十六进制数进行加法或减法运算，并输出结果。每个十六进制数的二进制表示也需要输出，且二进制数必须固定为 $13$ 位（不足高位补 $0$）。输入保证减法时第一个数不小于第二个数，结果非负。十六进制数最大为 $\texttt{FFF}$。

## 输入格式

第一行一个整数 $N$，表示表达式的个数。接下来 $N$ 行，每行一个表达式，格式为 `HEX1 + HEX2` 或 `HEX1 - HEX2`，元素之间用一个空格分隔。十六进制数使用大写字母。

## 输出格式

对于每个表达式，输出一行，格式为：
```
BINARY1 + BINARY2 = DECIMAL
```
或
```
BINARY1 - BINARY2 = DECIMAL
```
其中 $\texttt{BINARY1}$ 和 $\texttt{BINARY2}$ 是 $13$ 位二进制字符串（无空格），$\texttt{DECIMAL}$ 是十进制结果。

## 样例

输入

```
2
A + 3
AAA + BBB
```

输出

```
0000000001010 + 0000000000011 = 13
0101010101010 + 0101110111011 = 5733
```

## 题目分析

本题的核心是十六进制与十进制、二进制之间的转换，以及固定位宽的二进制输出。

### 转换方法

- 十六进制转十进制：可以使用 `stoi("0x" + hex, nullptr, 0)`，其中 `0x` 前缀表示十六进制。
- 十进制转二进制：使用 `bitset<13>(value).to_string()` 可以得到 $13$ 位二进制字符串。

### 运算

根据运算符 `+` 或 `-` 对十进制值进行相应运算。

### 输出格式

注意二进制字符串之间、运算符之间、等号前后均有空格分隔。

### 复杂度分析

每组表达式只需常数时间计算。

## 代码实现

```cpp
// Kibbles n Bits n Bits n Bits
// UVa ID: 446
// Verdict: Accepted
// Submission Date: 2016-07-15
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int n;
    cin >> n;

    string hex1, operators, hex2;
    int hex1_value, hex2_value, result;
    
    for (int i = 1; i <= n; i++)
    {
        cin >> hex1 >> operators >> hex2;
        hex1_value = stoi("0x" + hex1, nullptr, 0);
        hex2_value = stoi("0x" + hex2, nullptr, 0);
        result = hex1_value + (operators == "+" ? hex2_value : -hex2_value);
        
        bitset<13> first(hex1_value), second(hex2_value);
        cout << first.to_string() << " " << operators << " " << second.to_string() << " = " << result << '\n';
    }
    
    return 0;
}
```
