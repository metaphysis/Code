[UVa 447 Population Explosion](https://blog.csdn.net/metaphysis/article/details/161848893)

## 题目描述

题目要求模拟一个 $20 \times 20$ 网格上的生命游戏（类似于康威生命游戏）。每个单元格可以是空的（空格）或有人居住（用 `O` 表示）。模拟规则如下：

- 每个有居住的单元格，若其邻居数量为 $2$ 或 $3$，则存活到下一轮。
- 若邻居数量为 $4$ 或更多，则因过度拥挤而死亡；若邻居数量为 $1$ 或 $0$，则因孤立而死亡。
- 每个空单元格，若其恰好有 $3$ 个邻居，则下一轮变为有人居住。

邻居包括周围 $8$ 个方向（上、下、左、右、四个对角线）。输入给出初始居住位置的坐标（行、列，$1$ 到 $20$）。需要输出从第 $1$ 年到第 $Y$ 年的每年人口地图，其中第 $1$ 年对应初始配置。

## 输入格式

第一行一个整数 $N$，表示测试用例的数量，后面跟一个空行。每个测试用例的第一行一个整数 $Y$，表示模拟的年数。接下来若干行，每行两个整数 $x$ 和 $y$，表示初始有居住的单元格坐标。输入以空行结束。两个连续测试用例之间由一个空行分隔。

## 输出格式

对于每个测试用例，输出：
- 首先输出一行 $20$ 个星号（`********************`）。
- 然后输出第 $1$ 年到第 $Y$ 年每年的人口地图，每年输出后跟一行 $20$ 个星号。每年地图共 $20$ 行，每行 $20$ 个字符，居住位置输出 `O`，空位置输出空格。
- 输出完第 $Y$ 年后，最后输出一行 $20$ 个星号。
- 两个连续测试用例之间输出一个空行。

## 样例

输入

```
1

3
5 4
5 5
5 6
5 7
```

输出

```
********************
    OOOO
********************
   OO OO
********************
   O O O
********************
```

## 题目分析

本题的核心是模拟二维网格上的细胞自动机（康威生命游戏的变种）。

### 邻居计数

每个单元格的邻居包括其周围 $8$ 个方向的单元格。边界上的单元格邻居较少，需注意边界检查。

### 状态更新

同时更新所有单元格的状态，即下一轮的状态基于当前轮的状态计算，不能混用。

### 模拟流程

- 使用二维数组 $\textit{population}[20][20]$ 存储当前状态（$1$ 表示有人，$0$ 表示空）。
- 对于每个年份：
  1. 输出当前状态的地图。
  2. 计算下一状态：
     - 遍历每个单元格，统计其邻居数量。
     - 根据规则确定下一状态，存入 $\textit{next}$ 数组。
  3. 将 $\textit{next}$ 复制到 $\textit{population}$。
- 输出完所有年份后，输出一行星号。

### 输出格式

注意：每年地图输出后都要输出一行 $20$ 个星号，包括初始年份（第 $1$ 年）之后。样例显示第 $1$ 年地图输出后也有一行星号，所以模拟循环中应在每轮开始时输出星号，然后输出地图，循环结束后再输出一行星号？实际上参考代码的处理是：在模拟循环中先输出星号，再输出地图；循环结束后输出最后一行星号。这样第 $1$ 年之前会有一行星号，最后也有一行星号。

### 复杂度分析

每年需要遍历 $20 \times 20 = 400$ 个单元格，每个单元格统计 $8$ 个邻居，总操作数 $O(Y \times 400 \times 8)$，$Y$ 未知但合理范围内可接受。

```cpp
// Population Explosion
// UVa ID: 447

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    getline(cin, line);
    int cases = stoi(line);
    
    getline(cin, line);
    for (int i = 1; i <= cases; i++)
    {
        if (i > 1) cout << '\n';
        
        getline(cin, line);
        int years = stoi(line);

        int population[20][20], next[20][20], x, y;
        
        memset(population, 0, sizeof(population));
        while (getline(cin, line), line.length() > 0)
        {
            istringstream iss(line);
            iss >> x >> y;
            population[x - 1][y - 1] = 1;
        }
        
        for (int j = 1; j <= years; j++)
        {
            cout << "********************\n";
            for (int r = 0; r < 20; r++)
            {
                for (int c = 0; c < 20; c++)
                    if (population[r][c])
                        cout << 'O';
                    else
                        cout << ' ';
                cout << '\n';
            }
            
            memset(next, 0, sizeof(next));            
            for (int r = 0; r < 20; r++)
                for (int c = 0; c < 20; c++)
                {
                    int living = 0;
                    for (int offsetx = -1; offsetx <= 1; offsetx++)
                        for (int offsety = -1; offsety <= 1; offsety++)
                        {
                            if (offsetx == 0 && offsety == 0)
                                continue;
                                
                            int nextr= r + offsetx, nextc = c + offsety;
                            if (nextr >= 0 && nextr < 20 && nextc >= 0 && nextc < 20 && population[nextr][nextc])
                                living++;
                        }
                    
                    if (population[r][c])
                    {
                        if (living >= 4 || living <= 1)
                            next[r][c] = 0;
                        else
                            next[r][c] = 1;
                    }
                    else
                    {
                        if (living == 3)
                            next[r][c] = 1;
                    }
                }
                
            memcpy(population, next, sizeof(next));
        }
        cout << "********************\n";
    }
    
    return 0;
}
```
