## 题目描述

题目要求将十六进制的可执行代码反汇编为汇编指令。每行输入包含 $30$ 个十六进制数字（最后一行可能少于 $30$ 个）。指令格式如下：

- 每条指令由 $4$ 位操作码和若干操作数组成，每个操作数为 $16$ 位（其中 $2$ 位模式位，$14$ 位数值位）。
- 操作数模式：
  - `00`：寄存器（`R` + 数值）
  - `01`：绝对地址（`$` + 数值）
  - `10`：相对地址（`PC+` + 数值）
  - `11`：常数（直接输出数值）

操作码对应指令（十六进制）：

| 操作码 | 指令 | 操作数数量 |
|--------|------|------------|
| 0 | ADD | 2 |
| 1 | SUB | 2 |
| 2 | MUL | 2 |
| 3 | DIV | 2 |
| 4 | MOV | 2 |
| 5 | BREQ | 1 |
| 6 | BRLE | 1 |
| 7 | BRLS | 1 |
| 8 | BRGE | 1 |
| 9 | BRGR | 1 |
| A | BRNE | 1 |
| B | BR | 1 |
| C | AND | 3 |
| D | OR | 3 |
| E | XOR | 3 |
| F | NOT | 1 |

## 输入格式

输入包含若干行，每行由十六进制数字组成（`0` 到 `9`、`A` 到 `F`），每行最多 $30$ 个字符。所有行连接起来构成完整的可执行代码（无空格）。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

输出若干行，每行一条汇编指令，格式如样例所示。

## 样例

输入

```
4C00D00004C0020001000000001400
005FFFB801E
```

输出

```
MOV 13,R0
MOV 2,R1
ADD R0,R1
MOV R0,$8191
BR PC+30
```

## 题目分析

本题的核心是将十六进制字符串解析为二进制位，再按指令格式解析出操作码和操作数。

### 十六进制转二进制

每个十六进制字符对应 $4$ 位二进制。将整个十六进制字符串转换为二进制字符串后，按顺序解析。

### 指令解析流程

1. 读取所有输入行，拼接成一个十六进制字符串。
2. 遍历二进制位流（或直接遍历十六进制字符，每次取 $1$ 个十六进制字符作为操作码的前 $4$ 位？注意操作码是 $4$ 位，即 $1$ 个十六进制字符）。因此可以直接按十六进制字符处理：第一个十六进制字符即为操作码。
3. 根据操作码确定操作数个数：
   - 若操作码为 `0` 到 `4`：取 $2$ 个操作数，每个操作数占 $4$ 个十六进制字符（$16$ 位）。
   - 若操作码为 `5` 到 `B` 或 `F`：取 $1$ 个操作数，占 $4$ 个十六进制字符。
   - 若操作码为 `C`、`D`、`E`：取 $3$ 个操作数，每个占 $4$ 个十六进制字符。
4. 对于每个操作数：
   - 第一个十六进制字符的高 $2$ 位决定模式，低 $2$ 位和后续 $3$ 个字符（共 $14$ 位）组成数值。
   - 根据模式输出：
     - `00`：`R` + 数值
     - `01`：`$` + 数值
     - `10`：`PC+` + 数值
     - `11`：直接输出数值
5. 输出指令名称和操作数（逗号分隔）。

### 实现细节

- 可以使用 `bitset<14>` 将 $14$ 位二进制字符串转换为整数。
- 注意数值范围：寄存器编号 $0$ 到 $1023$，地址 $0$ 到 $16383$，偏移量 $0$ 到 $16363$，常数 $0$ 到 $16383$。

### 复杂度分析

每条指令长度固定，解析过程为线性扫描，时间复杂度 $O($代码长度$)$。

```cpp
// OOPS!

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

map<char, string> hex_value = {
    {'0', "0000"}, {'1', "0001"}, {'2', "0010"}, {'3', "0011"}, {'4', "0100"}, 
    {'5', "0101"}, {'6', "0110"}, {'7', "0111"}, {'8', "1000"}, {'9', "1001"}, 
    {'A', "1010"}, {'B', "1011"}, {'C', "1100"}, {'D', "1101"}, {'E', "1110"}, 
    {'F', "1111"}
};

map<char, string> instruction = {
    {'0', "ADD"}, {'1', "SUB"}, {'2', "MUL"}, {'3', "DIV"}, {'4', "MOV"},
    {'5', "BREQ"}, {'6', "BRLE"}, {'7', "BRLS"}, {'8', "BRGE"}, {'9', "BRGR"},
    {'A', "BRNE"}, {'B', "BR"}, {'C', "AND"}, {'D', "OR"}, {'E', "XOR"},
    {'F', "NOT"}
};

string source_code;
int indexer = 0;

string getOperand(string& opcode)
{
    bitset<14> number(opcode.substr(2));
    string operand = to_string(number.to_ulong());
    if (opcode[0] == '0' && opcode[1] == '0') return "R" + operand;
    else if (opcode[0] == '0' && opcode[1] == '1') return "$" + operand;
    else if (opcode[0] == '1' && opcode[1] == '0') return "PC+" + operand;
    else return operand;
}

void arithmetic(char letter)
{
    string op1, op2;
    for (int i = 0; i < 4; i++) op1 += hex_value[source_code[indexer++]];
    for (int i = 0; i < 4; i++) op2 += hex_value[source_code[indexer++]];
    cout << instruction[letter] << ' ' << getOperand(op1) << ',' << getOperand(op2) << '\n';
}

void compare(char letter)
{
    string op1;
    for (int i = 0; i < 4; i++) op1 += hex_value[source_code[indexer++]];
    cout << instruction[letter] << ' ' << getOperand(op1) << '\n';    
}

void boolean(char letter)
{
    string op1, op2, op3;
    for (int i = 0; i < 4; i++) op1 += hex_value[source_code[indexer++]];
    for (int i = 0; i < 4; i++) op2 += hex_value[source_code[indexer++]];
    for (int i = 0; i < 4; i++) op3 += hex_value[source_code[indexer++]];
    cout << instruction[letter] << ' ';
    cout << getOperand(op1) << ',' << getOperand(op2) << ',' << getOperand(op3) << '\n';
}

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    
    string line;
    while (getline(cin, line))
        source_code += line;

    for (int i = source_code.length(); i >= 0; i--)
        if (isblank(source_code[i]))
            source_code.erase(source_code.begin() + i);

    while (indexer < source_code.length())
    {
        char last_letter = source_code[indexer++];
        if (last_letter == '0' || last_letter == '1' || last_letter == '2' ||
            last_letter == '3' || last_letter == '4')
            arithmetic(last_letter);
        else if (last_letter == '5' || last_letter == '6' || last_letter == '7' ||
            last_letter == '8' || last_letter == '9' || last_letter == 'A' ||
            last_letter == 'B' || last_letter == 'F')
            compare(last_letter);
        else
            boolean(last_letter);
    }
    
    return 0;
}
```
