## 题目描述

题目要求根据给定的调式（大调）和音程，计算目标音。输入包含若干对行：第一行指定大调（$\texttt{C}$、$\texttt{Db}$、$\texttt{D}$、$\texttt{Eb}$、$\texttt{E}$、$\texttt{F}$、$\texttt{Gb}$、$\texttt{G}$、$\texttt{Ab}$、$\texttt{A}$、$\texttt{Bb}$、$\texttt{B}$ 之一），第二行包含一个或多个音程计算请求，格式为 **起始音 方向 音程**，多个请求之间用分号 `;` 分隔。方向为 `UP` 或 `DOWN`，音程为 `SECOND`、`THIRD`、`FOURTH`、`FIFTH`、`SIXTH`、`SEVENTH` 或 `OCTAVE`。需要判断起始音是否属于该大调，若是则计算并输出目标音；否则输出 `invalid note for this key`。

## 输入格式

输入包含多对行。第一行一个字符串表示大调名称。第二行包含一个或多个音程请求，格式如 `F UP SECOND; G DOWN THIRD`。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每个大调，首先输出一行 `Key of X`，其中 `X` 为大调名称。然后对于每个音程请求，输出一行：若起始音有效，输出 **起始音: 方向 音程 > 目标音**；否则输出 **起始音: `invalid note for this key`**。每个大调输出后跟一个空行。

## 样例

输入

```
C
F UP SECOND; G DOWN THIRD
E
F# DOWN FOURTH; Bb DOWN SEVENTH; B UP OCTAVE
```

输出

```
Key of C
F: UP SECOND > G
G: DOWN THIRD > E

Key of E
F#: DOWN FOURTH > C#
Bb: invalid note for this key
B: UP OCTAVE > B
```

## 题目分析

本题的核心是根据大调的音阶序列和给定的音程，在音阶中移动指定步数得到目标音。

### 大调音阶

$12$ 个大调的音阶（每个音阶包含 $7$ 个不同的音名，不包括重复的主音）如下：
- $\texttt{C：C, D, E, F, G, A, B}$
- $\texttt{Db：Db, Eb, F, Gb, Ab, Bb, C}$
- $\texttt{D：D, E, F\#, G, A, B, C\#}$
- $\texttt{Eb：Eb, F, G, Ab, Bb, C, D}$
- $\texttt{E：E, F\#, G\#, A, B, C\#, D\#}$
- $\texttt{F：F, G, A, Bb, C, D, E}$
- $\texttt{Gb：Gb, Ab, Bb, Cb, Db, Eb, F}$
- $\texttt{G：G, A, B, C, D, E, F\#}$
- $\texttt{Ab：Ab, Bb, C, Db, Eb, F, G}$
- $\texttt{A：A, B, C\#, D, E, F\#, G\#}$
- $\texttt{Bb：Bb, C, D, Eb, F, G, A}$
- $\texttt{B：B, C\#, D\#, E, F\#, G\#, A\#}$

注意：音阶中相邻音之间的间隔为全音（两个半音）或半音（一个半音），但音程（如 `SECOND`）在音阶中是指音级差，而非半音数。例如 `SECOND` 表示在音阶中移动 $1$ 步（从当前音到下一个音），`THIRD` 表示移动 $2$ 步，依此类推。`OCTAVE` 表示移动 $7$ 步（回到同音名的高八度）。

### 音程计算

- 将音阶存储在长度为 $7$ 的数组中。
- 找到起始音在数组中的索引 $i$（$0$ 到 $6$）。
- 若方向为 `UP`，目标音索引为 $(i + (intervalStep) ) \bmod 7$，其中 $intervalStep =$ 音程数值 $- 1$（如 `SECOND` 移动 $1$ 步）。
- 若方向为 `DOWN`，目标音索引为 $(i - (intervalStep) + 7) \bmod 7$。

### 有效性判断

起始音必须在大调音阶中（即与音阶中的某个音符完全匹配，包括升降号）。注意：降号用 `b` 表示，升号用 `#` 表示。输入中的音符可能使用等音异名（如 `F#` 和 `Gb`），但大调音阶中已指定了具体的表示法（如 `F#` 或 `Gb`），所以直接字符串比较即可。

### 复杂度分析

每个音程请求只需在 $7$ 个音中查找起始音，复杂度 $O(7)$，完全可接受。

## 代码实现

```cpp
// Majoring in Scales
// UVa ID: 449
// Verdict: Accepted
// Submission Date: 2016-08-06
// UVa Run Time: 0.020s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    map<string, int> directions = {
        {"UP", 1}, {"DOWN", -1}
    };

    map<string, int> intervals = {
        {"SECOND", 2}, {"THIRD", 3}, {"FOURTH", 4}, {"FIFTH", 5},
        {"SIXTH", 6}, {"SEVENTH", 7}, {"OCTAVE", 8}
    };

    map<string, vector<string>> scales = {
        {"C", {"C", "D", "E", "F", "G", "A", "B"}},
        {"Db", {"Db", "Eb", "F", "Gb", "Ab", "Bb", "C"}},
        {"D", {"D", "E", "F#", "G", "A", "B", "C#"}},
        {"Eb", {"Eb", "F", "G", "Ab", "Bb", "C", "D"}},
        {"E", {"E", "F#", "G#", "A", "B", "C#", "D#"}},
        {"F", {"F", "G", "A", "Bb", "C", "D", "E"}},
        {"Gb", {"Gb", "Ab", "Bb", "Cb", "Db", "Eb", "F"}},
        {"G", {"G", "A", "B", "C", "D", "E", "F#"}},
        {"Ab", {"Ab", "Bb", "C", "Db", "Eb", "F", "G"}},
        {"A", {"A", "B", "C#", "D", "E", "F#", "G#"}},
        {"Bb", {"Bb", "C", "D", "Eb", "F", "G", "A"}},
        {"B", {"B", "C#", "D#", "E", "F#", "G#", "A#"}}
    };
    
    string line;
    while (getline(cin, line))
    {
        string key;
        istringstream iss(line);
        iss >> key;
        
        cout << "Key of " << key << '\n';
        
        getline(cin, line);
        iss.clear(); iss.str(line);
        
        string block, tone, direction, interval;
        while (getline(iss, block, ';'))
        {
            istringstream cmd(block);
            cmd >> tone >> direction >> interval;
            cout << tone << ": ";
            
            bool found = false;
            for (int i = 0; i < scales[key].size(); i++)
                if (scales[key][i] == tone)
                {
                    cout << direction << ' ' << interval << " > ";
                    string next_tone = scales[key][(i + directions[direction] * (intervals[interval] - 1) + 7) % 7];
                    cout << next_tone << '\n';
                    found = true;
                    break;
                }
            
            if (found == false)
                cout << "invalid note for this key\n";
        }
        cout << '\n';
    }
    
    return 0;
}
```
