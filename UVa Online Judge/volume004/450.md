## 题目描述

题目要求将多个系别的教师名单合并，并按姓氏字母顺序排序后输出。每个系别的输入格式为：第一行系别名称，后面若干行每行一个教师记录，字段顺序为：称谓（$\texttt{Title}$）、名（$\texttt{First Name}$）、姓（$\texttt{Last Name}$）、街道地址（$\texttt{Street Address}$）、家庭电话（$\texttt{Home Phone}$）、工作电话（$\texttt{Work Phone}$）、校园信箱（$\texttt{Campus Mailbox}$），字段之间用逗号分隔。不同系别的数据之间用一个空行分隔。输出时每条记录以一行 $40$ 个短横线开头，然后按指定格式输出各字段。

## 输入格式

第一行一个整数 $N$（$2 \le N \le 12$），表示系别的数量。接下来依次输入每个系别的数据：第一行系别名称，后面若干行教师记录，每行 $7$ 个字段，用逗号分隔。每个系别的数据结束后有一个空行（最后一个系别后可能没有空行）。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每个教师记录，输出：
```
----------------------------------------
Title FirstName LastName
Street Address
Department: DepartmentName
Home Phone: HomePhone
Work Phone: WorkPhone
Campus Box: CampusBox
```
注意：称谓和姓名之间、姓名和地址之间、各标签和内容之间均有空格。每条记录后没有额外的空行。

## 题目分析

本题的核心是读取多个系别的教师数据，按姓氏排序后格式化输出。

### 数据读取

- 先读取 $N$。
- 对于每个系别，先读取一行系别名称。
- 然后循环读取教师记录行，直到遇到空行（即 `line.length() == 0`）为止。
- 每条教师记录使用逗号分隔解析出 $7$ 个字段，加上系别名称共 $8$ 个字段。

### 排序

按姓氏（第 $4$ 个字段，索引 $3$）的字典序升序排序。若姓氏相同如何处理？题目未明确，但可保持原顺序（稳定排序）。

### 输出格式

- 先输出一行 $40$ 个短横线。
- 然后输出称谓、名、姓，之间用空格分隔。
- 换行后输出地址。
- 换行后输出 `Department: 系别名称`。
- 换行后输出 `Home Phone: 家庭电话`。
- 换行后输出 `Work Phone: 工作电话`。
- 换行后输出 `Campus Box: 校园信箱`。

注意：输出中没有额外的空行分隔记录，但每条记录前都有短横线。

### 复杂度分析

- 读取所有记录 $O(\text{总记录数})$。
- 排序 $O(M \log M)$，$M$ 为总教师数，可接受。

## 代码实现

```cpp
// Little Black Book

// Submission Date: 2016-07-17
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct person {
    // string 0 - department, 1 - title, 2 - firstname, 3 - lastname,
    // 4 - address, 5 - homephone, 6 - workphone, 7 - mailbox;
    vector<string> information;
    bool operator<(const person& another) const
    {
        return information[3] < another.information[3];
    }
};

vector<vector<string>> persons;

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    getline(cin, line);
    int cases = stoi(line);
    
    vector<person> persons;
    for (int i = 1; i <= cases; i++) {
        string department;
        getline(cin, department);

        while (getline(cin, line), line.length() > 0) {
            person someone;
            someone.information.push_back(department);

            istringstream iss(line);
            string block;
            while (getline(iss, block, ','))
                someone.information.push_back(block);

            persons.push_back(someone);
        }
    }

    sort(persons.begin(), persons.end());
    for (auto someone : persons) {
        cout << "----------------------------------------\n";
        cout << someone.information[1] << ' ';
        cout << someone.information[2] << ' ';
        cout << someone.information[3] << '\n';
        
        cout << someone.information[4] << '\n';
        
        cout << "Department: " << someone.information[0] << '\n';
        cout << "Home Phone: " << someone.information[5] << '\n';
        cout << "Work Phone: " << someone.information[6] << '\n';
        cout << "Campus Box: " << someone.information[7] << '\n';
    }
    
    return 0;
}
```
