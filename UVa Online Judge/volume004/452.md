[UVa 452 Project Scheduling](https://blog.csdn.net/metaphysis/article/details/161886857)

## 题目描述

题目要求计算完成一个项目所需的最短时间。项目由若干任务组成，每个任务有名称（一个大写字母）、所需天数和前置任务列表（必须在此之前完成的任务）。任务可以并行执行，只要其前置任务已完成。需要计算所有任务完成的最早时间。

## 输入格式

第一行一个整数 $N$，表示测试用例的数量，后面跟一个空行。每个测试用例包含若干行（最多 $27$ 行），每行描述一个任务，格式为：任务名（大写字母）、所需天数（整数）、以及零个或多个前置任务名（大写字母，无空格）。输入以空行结束。两个连续测试用例之间由一个空行分隔。

## 输出格式

对于每个测试用例，输出一行一个整数，表示完成所有任务所需的最短时间。两个连续测试用例的输出之间由一个空行分隔。

## 样例

输入

```
2

A 5
B 3 A
D 2 A
C 2 B
F 2 CE
E 4 DC

A 5
B 3 A
D 2 A
C 2 B
F 2 CE
E 4 DC
```

输出

```
16
16
```

## 题目分析

本题的核心是计算有向无环图（$\texttt{DAG}$）上的最长路径（关键路径）。每个任务是一个节点，边 $u \to v$ 表示 $u$ 是 $v$ 的前置任务。任务的完成时间等于其所有前置任务完成时间的最大值加上自身的持续时间。

### 关键路径计算

可以使用拓扑排序（$\texttt{topological sorting}$）动态规划计算每个任务的最早完成时间：

- 设 $\textit{elapsed}[i]$ 表示任务 $i$ 的最早完成时间。
- 初始化 $\textit{elapsed}[i] = \textit{days}[i]$（若无前置任务）。
- 按拓扑顺序处理任务：对于任务 $i$，将其 $\textit{elapsed}[i]$ 传播到其后继任务 $j$，更新 $\textit{elapsed}[j] = \max(\textit{elapsed}[j], \textit{elapsed}[i] + \textit{days}[j])$。

最终答案为所有 $\textit{elapsed}[i]$ 的最大值。

### 拓扑排序实现

- 统计每个任务的入度（前置任务数量）。
- 将所有入度为 $0$ 的任务加入队列。
- 每次从队列中取出一个任务，将其 $\textit{elapsed}$ 值传播到后继任务，后继任务的入度减 $1$，若入度变为 $0$ 则加入队列。
- 若图中有环，则无法完成（但题目保证输入合法，无环）。

### 注意点

- 任务名仅为大写字母，但输入中可能不连续（如示例中只有 $\texttt{A,B,C,D,E,F}$），需要处理未出现的字母。
- 任务持续时间以整数给出。
- 前置任务列表可能为空，也可能包含多个字母（如 `CE` 表示 $\texttt{C}$ 和 $\texttt{E}$）。

### 复杂度分析

节点数最多 $26$，边数最多 $26^2$，拓扑排序复杂度 $O(26^2)$。

## 代码实现

```cpp
// Project Scheduling
// UVa ID: 452
// Verdict: Accepted
// Submission Date: 
// UVa Run Time: 0.110s

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    
    getline(cin, line);
    int cases = stoi(line);
    
    getline(cin, line);
    for (int i = 1; i <= cases; i++)
    {
        if (i > 1) cout << endl;
        
        int edges[30][30] = {}, days_needed[30] = {}, elapsed[30] = {}, indegree[30] = {}, visited[30] = {};
        
        while (getline(cin, line), line.length() > 0)
        {
            char letter;
            int days;
            string pretask;
            
            istringstream iss(line);
            iss >> letter >> days >> pretask;
            
            visited[letter - 'A'] = 1;
            elapsed[letter - 'A'] = days;
            days_needed[letter - 'A'] = days;
            
            for (int j = 0; j < pretask.length(); j++)
                edges[pretask[j] - 'A'][letter - 'A'] = 1;
            indegree[letter - 'A'] += pretask.length();
        }
        
        // topological sorting
        int unvisited[30];
        memcpy(unvisited, visited, sizeof(visited));
        
        while (true)
        {
            int indexer = -1;
            for (int j = 0; j < 26; j++)
                if (unvisited[j] && indegree[j] == 0)
                {
                    indexer = j;
                    break;
                }
            if (indexer == -1) break;
                
            unvisited[indexer] = 0;
            for (int j = 0; j < 26; j++)
                if (edges[indexer][j])
                {
                    elapsed[j] = max(elapsed[j], elapsed[indexer] + days_needed[j]);
                    indegree[j]--;
                }
        }
        
        int max_days = 0;
        for (int i = 0; i < 26; i++)
            if (visited[i])
                max_days = max(max_days, elapsed[i]);
        
        cout << max_days << '\n';
    }
    
    return 0;
}
```
