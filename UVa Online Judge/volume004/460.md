[UVa 460 Overlapping Rectangles](https://blog.csdn.net/metaphysis/article/details/161913922)

## 题目描述

题目要求判断两个轴对齐的矩形是否重叠，若重叠则输出重叠区域的左下角和右上角坐标。矩形由左下角坐标 $(X_{LL}, Y_{LL})$ 和右上角坐标 $(X_{UR}, Y_{UR})$ 定义，且满足 $X_{LL} < X_{UR}$、$Y_{LL} < Y_{UR}$。若两矩形仅边重合而无内部重叠，视为不重叠。

## 输入格式

第一行一个整数 $N$，表示测试用例的数量，后面跟一个空行。每个测试用例包含两行，每行四个整数，分别表示第一个矩形和第二个矩形的左下角和右上角坐标。两个连续测试用例之间由一个空行分隔。

## 输出格式

对于每个测试用例，若两矩形不重叠，输出 `No Overlap`；否则输出四个整数：重叠矩形的左下角 $x$、左下角 $y$、右上角 $x$、右上角 $y$。两个连续测试用例的输出之间由一个空行分隔。

## 样例

输入

```
1

0 20 100 120
80 50 500 60
```

输出

```
80 50 100 60
```

## 题目分析

本题的核心是计算两个轴对齐矩形的交集。

### 重叠判断

设矩形 $R_1$ 的左下角 $(x_1, y_1)$、右上角 $(x_2, y_2)$，矩形 $R_2$ 的左下角 $(x_3, y_3)$、右上角 $(x_4, y_4)$。则重叠矩形的左下角坐标为：
$$
\textit{lowx} = \max(x_1, x_3),\quad \textit{lowy} = \max(y_1, y_3)
$$
右上角坐标为：
$$
\textit{upx} = \min(x_2, x_4),\quad \textit{upy} = \min(y_2, y_4)
$$
若 $\textit{lowx} \ge \textit{upx}$ 或 $\textit{lowy} \ge \textit{upy}$，则两矩形无重叠（包括仅边重合的情况）。否则，重叠矩形即为 $(\textit{lowx}, \textit{lowy}, \textit{upx}, \textit{upy})$。

### 注意点

- 坐标均为整数，范围 $0$ 到 $9999$。
- 仅边重合（如一个矩形的右边与另一个矩形的左边重合）时，$\textit{lowx} = \textit{upx}$，属于不重叠。

### 复杂度分析

每个测试用例只需常数时间计算。

## 代码实现

```cpp
// Overlapping Rectangles
// UVa ID: 460
// Verdict: Accepted

// UVa Run Time: 0.000s

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int cases;
    cin >> cases;
    
    int x1, y1, x2, y2, x3, y3, x4, y4;
    for (int i = 1; i <= cases; i++)
    {
        if (i > 1) cout << '\n';
        
        cin >> x1 >> y1 >> x2 >> y2;
        cin >> x3 >> y3 >> x4 >> y4;
        
        int lowx = max(x1, x3), lowy = max(y1, y3), upx = min(x2, x4), upy = min(y2, y4);
        if (lowx >= upx || lowy >= upy)
            cout << "No Overlap\n";
        else
            cout << lowx << ' ' << lowy << ' ' << upx << ' ' << upy << '\n';
    }
    
    return 0;
}
```
