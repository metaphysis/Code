[UVa 462 Bridge Hand Evaluator](https://blog.csdn.net/metaphysis/article/details/161913981)

## 题目描述

题目要求根据桥牌手牌评估规则，输出推荐叫牌。规则如下：

1. 基础点数：$\texttt{A}=4$，$\texttt{K}=3$，$\texttt{Q}=2$，$\texttt{J}=1$。
2. 某花色中若 $\texttt{K}$ 是唯一牌，则减 $1$ 点。
3. 某花色中若 $\texttt{Q}$ 且该花色牌数 $\le 2$，则减 $1$ 点（即只有 $0$ 或 $1$ 张其他牌）。
4. 某花色中若 $\texttt{J}$ 且该花色牌数 $\le 3$，则减 $1$ 点（即只有 $0$、$1$ 或 $2$ 张其他牌）。
5. 某花色恰好有 $2$ 张牌，加 $1$ 点。
6. 某花色恰好有 $1$ 张牌，加 $2$ 点。
7. 某花色没有牌，加 $2$ 点。

花色“停止”（$\texttt{stopped}$）的条件：有 $\texttt{A}$；或有 $\texttt{K}$ 且至少还有一张其他牌；或有 $\texttt{Q}$ 且至少还有两张其他牌。

叫牌规则：
- 若基础点数（不包括规则 $5$、$6$、$7$）$\ge 16$ 且所有花色均停止，则叫 `BID NO-TRUMP`。
- 否则，若总点数 $\ge 14$，则在牌数最多的花色中叫 `BID S`、`BID H`、`BID D` 或 `BID C`（优先顺序 $\texttt{S,H,D,C}$）。
- 否则，叫 `PASS`。

## 输入格式

输入包含多行，每行 $13$ 张牌，每张牌由两个字符组成：点数（$\texttt{A,2,3,4,5,6,7,8,9,T,J,Q,K}$）和花色（$\texttt{S,H,D,C}$）。牌之间用空格分隔。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每行输入，输出一行推荐叫牌：`PASS`、`BID S`、`BID H`、`BID D`、`BID C` 或 `BID NO-TRUMP`。

## 样例

输入

```
KS QS TH 8H 4H AC QC TC 5C KD QD JD 8D
AC 3C 4C AS 7S 4S AD TD 7D 5D AH 7H 5H
```

输出

```
BID D
BID NO-TRUMP
```

## 题目分析

本题的核心是按照给定规则计算手牌点数并决定叫牌。

### 数据结构

使用数组 $\textit{countOfSuits}[4]$ 记录每个花色的牌数，顺序为 $\texttt{S,H,D,C}$。使用二维数组 $\textit{countOfFaces}[4][4]$ 记录每个花色中 $\texttt{A,K,Q,J}$ 的出现次数，顺序为 $\texttt{A,K,Q,J}$。

### 计算步骤

1. **基础点数**：遍历所有牌，累加 $\texttt{A,K,Q,J}$ 对应的点数，并记录到 $\textit{countOfFaces}$ 中，同时累加 $\textit{countOfSuits}$。
2. **减点**（规则 $2,3,4$）：
   - 对每个花色，若 $\texttt{K}$ 存在且该花色牌数等于 $1$，则减去 $\texttt{K}$ 的数量（通常为 $1$）。
   - 若 $\texttt{Q}$ 存在且该花色牌数 $\le 2$，则减去 $\texttt{Q}$ 的数量。
   - 若 $\texttt{J}$ 存在且该花色牌数 $\le 3$，则减去 $\texttt{J}$ 的数量。
3. **无将叫牌判断**：
   - 检查所有花色是否停止。
   - 若全停止且当前点数（未加规则 $5,6,7$）$\ge 16$，则输出 `BID NO-TRUMP`。
4. **加点**（规则 $5,6,7$）：
   - 对每个花色，若牌数为 $2$，加 $1$ 点；若牌数为 $1$ 或 $0$，加 $2$ 点。
5. **叫牌判断**：
   - 若总点数 $< 14$，输出 `PASS`。
   - 否则，找出牌数最多的花色，按 $\texttt{S} > \texttt{H} > \texttt{D} > \texttt{C}$ 的优先级输出（若多个花色牌数相同，取优先级高的）。

### 复杂度分析

每手牌处理 $13$ 张，常数时间，完全可接受。

## 代码实现

```cpp
// Bridge Hand Evaluator
// UVa ID: 462
// Verdict: Accepted
// Submission Date: 2016-07-23
// UVa Run Time: 0.030s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    map<char, int> suits = {{'S', 0}, {'H', 1}, {'D', 2}, {'C', 3}};
    map<char, int> point = {{'A', 4}, {'K', 3}, {'Q', 2}, {'J', 1}};
    map<char, int> faces = {{'A', 0}, {'K', 1}, {'Q', 2}, {'J', 3}};

    string line, card;
    while (getline(cin, line))
    {
        istringstream iss(line);
        int countOfSuits[4] = {}, countOfFaces[4][4] = {};

        // rule 1
        int points = 0;
        while (iss >> card)
        {
            if (point.find(card.front()) != point.end())
            {
                points += point[card.front()];
                countOfFaces[suits[card.back()]][faces[card.front()]]++;
            }
            countOfSuits[suits[card.back()]]++;
        }

        // rule 2, 3, 4
        for (int i = 0; i < 4; i++)
        {
            if (countOfFaces[i][1] > 0 && countOfFaces[i][1] == countOfSuits[i])
                points -= countOfFaces[i][1];
            if (countOfFaces[i][2] > 0 && countOfFaces[i][2] >= countOfSuits[i] - 1)
                points -= countOfFaces[i][2];
            if (countOfFaces[i][3] > 0 && countOfFaces[i][3] >= countOfSuits[i] - 2)
                points -= countOfFaces[i][3];
        }

        // no trump
        bool all_stopped = true;
        for (int i = 0; i < 4; i++)
            all_stopped = all_stopped && (countOfFaces[i][0] >= 1 ||
            (countOfFaces[i][1] >= 1 && countOfFaces[i][1] <= countOfSuits[i] - 1) ||
            (countOfFaces[i][2] >= 1 && countOfFaces[i][2] <= countOfSuits[i] - 2));

        if (all_stopped && points >= 16)
        {
            cout << "BID NO-TRUMP\n";
            continue;
        }

        // rule 5, 6, 7
        for (int i = 0; i < 4; i++)
            if (countOfSuits[i] == 2) points += 1;
            else if (countOfSuits[i] <= 1) points += 2;

        if (points < 14)
        {
            cout << "PASS\n";
            continue;
        }

        // bid some suit
        int max_length = *max_element(countOfSuits, countOfSuits + 4);
        if (countOfSuits[0] == max_length) cout << "BID S\n";
        else if (countOfSuits[1] == max_length) cout << "BID H\n";
        else if (countOfSuits[2] == max_length) cout << "BID D\n";
        else cout << "BID C\n";
    }
    
    return 0;
}
```
