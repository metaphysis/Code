## 题目描述

题目要求找出所有满足条件的整数对 $(s_1, s_2)$，使得：
- $s_1 / s_2 = N$，其中 $N$ 是给定的整数；
- $s_1$ 和 $s_2$ 的十进制表示中均不包含重复数字。

输出时按 $s_1$ 升序排列。

## 输入格式

第一行一个整数 $T$，表示测试用例的数量，后面跟一个空行。每个测试用例一行，包含一个整数 $N$。两个连续测试用例之间由一个空行分隔。

## 输出格式

对于每个测试用例，输出若干行，每行格式为 `s1 / s2 = N`。按 $s_1$ 升序排列。两个连续测试用例的输出之间由一个空行分隔。

## 样例

输入

```
1

1234567890
```

输出

```
1234567890 / 1 = 1234567890
2469135780 / 2 = 1234567890
4938271560 / 4 = 1234567890
6172839450 / 5 = 1234567890
8641975230 / 7 = 1234567890
9876543120 / 8 = 1234567890
```

## 题目分析

本题的核心是枚举所有满足条件的 $s_2$，然后计算 $s_1 = N \times s_2$，并检查 $s_1$ 和 $s_2$ 是否都不含重复数字。

### 枚举范围

$s_2$ 必须是各位数字不重复的正整数，且 $s_1$ 也必须是各位数字不重复的正整数。由于 $s_1$ 最大可能为 $9876543210$（$10$ 位数字，含 $0$ 到 $9$ 各一次），因此 $s_2 \le 9876543210 / N$。但更简单的方法是预先生成所有各位数字不重复的数字，最多为 $\sum_{k=1}^{10} P(10, k) \approx 9,864,100$，但实际有效数字（不含前导零）约为 $\sum_{k=1}^{10} 9 \times P(9, k-1) \approx 9,864,100$，仍然太大。需要优化。

实际上，由于 $s_1$ 和 $s_2$ 都不含重复数字，且 $s_1 = N \times s_2$，$s_2$ 的位数不能太大。通常枚举 $s_2$ 到 $10^6$ 左右即可。参考代码中预先生成了所有位数不超过 $6$ 且各位数字不重复的数字（包括前导零？实际生成的是不含前导零的？），共约 $9 + 9 \times 9 + 9 \times 9 \times 8 + \ldots$，数量约 $9 \times \sum_{k=0}^{5} P(9, k) \approx 9 \times (1 + 9 + 72 + 504 + 3024 + 15120) = 9 \times 18730 = 168570$，加上 $0$ 共约 $17$ 万，完全可接受。

### 生成方法

使用回溯法生成所有各位数字不重复的数字（允许 $0$ 到 $9$，但不能有前导零？参考代码中从 $1$ 到 $9$ 开始，然后递归添加 $0$ 到 $9$ 中未使用的数字，生成的数字包括 $0$ 本身吗？初始 `current=0`，但第一层循环从 $0$ 开始，会生成以 $0$ 开头的数字，如 `0`、`01`（即 $1$）、`02` 等。但 `0` 作为 $s_2$ 会导致 $s_1=0$，不符合要求（$s_1$ 应无重复数字，$0$ 有重复？$0$ 只有一位数字，不算重复）。实际实现中，生成的数字包括 $0$，但后续检查时会过滤。

### 检查重复数字

对 $s_1$ 和 $s_2$ 的十进制字符串分别检查是否有重复字符：排序后相邻比较即可。

### 复杂度分析

预生成约 $17$ 万个数，每个测试用例遍历这些数直到 $N \times s_2 > 9876543210$，实际枚举次数有限。

## 代码实现

```cpp
// Magic Numbers
// UVa ID: 471
// Verdict: Accepted
// Submission Date: 2016-07-18
// UVa Run Time: 0.020s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

vector<long long> numbers(200000, 0);
vector<bool> visited(10);
int counter = 0;

void backtrack(long long current, int depth)
{
    if (depth == 6)
        return;
        
    for (int i = 0; i < visited.size(); i++)
        if (visited[i] == false)
        {
            visited[i] = true;
            numbers[counter++] = current * 10 + i;
            backtrack(current * 10 + i, depth + 1);
            visited[i] = false;
        }
}

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    fill(visited.begin(), visited.end(), false);
    backtrack(0, 0);
    
    sort(numbers.begin(), numbers.end());
    counter = unique(numbers.begin(), numbers.end()) - numbers.begin();
    
    int cases;
    cin >> cases;
    
    long long n;
    for (int i = 1; i <= cases; i++)
    {
        if (i > 1) cout << endl;
        
        cin >> n;
        
        for (int j = 1; j < counter; j++)
        {
            long long multiplication = n * numbers[j];
            if (multiplication <= 9876543210LL)
            {
                string text = to_string(multiplication);
                sort(text.begin(), text.end());
                bool same = false;
                for (int k = 0; k < text.length() - 1; k++)
                    if (text[k] == text[k + 1])
                    {
                        same = true;
                        break;
                    }
                if (same == false)
                    cout << multiplication << " / " << numbers[j] << " = " << n << '\n';
            }
            else
                break;
        }
    }
    
    return 0;
}
```
