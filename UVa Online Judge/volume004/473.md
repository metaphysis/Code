[UVa 473 Raucous Rockers](https://blog.csdn.net/metaphysis/article/details/161945223)

## 题目描述

题目要求将 $n$ 首歌曲按创作时间顺序分配到 $m$ 张光盘上，每张光盘容量为 $t$ 分钟，每首歌曲不能拆分到多张光盘。目标是最大化被选中的歌曲数量。

## 输入格式

第一行一个整数 $D$，表示数据集的个数，后面跟一个空行。每个数据集的第一行包含三个整数 $n$、$t$、$m$。第二行包含 $n$ 个整数，表示每首歌曲的长度（单位为分钟）。每个 $t_i < t$，且 $\sum t_i > m \times t$。两个连续数据集之间由一个空行分隔。

## 输出格式

对于每个数据集，输出一行一个整数，表示能放入 $m$ 张光盘的最大歌曲数量。两个连续数据集的输出之间由一个空行分隔。

## 样例

输入

```
2

10 5 3
3,5,1,2,3,5,4,1,1,5

1 1 1
1
```

输出

```
6
1
```

## 题目分析

本题的核心是在保持歌曲原有顺序的前提下，将它们分配到 $m$ 个容量为 $t$ 的背包中，使得放入的歌曲数量最多。这是一个多维背包问题，可以用动态规划求解。

### 动态规划定义

设 $\textit{dp}[i][j][k]$ 表示考虑前 $i$ 首歌曲，使用了 $j$ 张光盘，且当前光盘已用容量为 $k$ 时，能够放入的最大歌曲数量。但这样状态数为 $n \times m \times t$，$n$ 最大未知，$t \le ?$，可接受。

状态转移：
- 不选第 $i$ 首歌曲：$\textit{dp}[i][j][k] = \max(\textit{dp}[i][j][k], \textit{dp}[i-1][j][k])$
- 选第 $i$ 首歌曲：
  - 若放入当前光盘（$k + t_i \le t$）：$\textit{dp}[i][j][k + t_i] = \max(\textit{dp}[i][j][k + t_i], \textit{dp}[i-1][j][k] + 1)$
  - 若放入新光盘（$j < m$）：$\textit{dp}[i][j+1][t_i] = \max(\textit{dp}[i][j+1][t_i], \textit{dp}[i-1][j][k] + 1)$

### 简化

由于 $n$、$m$、$t$ 的具体范围未给出，但 $t_i < t$，且 $\sum t_i > m \times t$，可以假设 $t$ 不大。实际上，可以使用一维 $\texttt{DP}$ 优化空间。

### 算法

1. 初始化 $\textit{dp}[0][0] = 0$，其他为 $-\infty$。
2. 遍历每首歌曲 $i$：
   - 从后向前更新（避免同一首歌被多次使用）：
     - 对于每张光盘 $j$（从 $m-1$ 到 $0$），对于每个容量 $k$（从 $t - t_i$ 到 $0$），更新放入当前光盘的状态。
     - 对于每张光盘 $j$（从 $m-1$ 到 $0$），对于每个容量 $k$，更新放入新光盘的状态。
3. 最终答案为 $\max_{0 \le j \le m, 0 \le k \le t} \textit{dp}[j][k]$。

### 复杂度分析

时间复杂度 $O(n \times m \times t)$，空间复杂度 $O(m \times t)$。对于合理范围内的 $n$、$m$、$t$，可接受。

```cpp
// Raucous Rockers

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int datasets;
    cin >> datasets;
    
    for (int ds = 0; ds < datasets; ++ds) {
        if (ds) cout << '\n';
        
        int n, t, m;
        cin >> n >> t >> m;
        
        vector<int> songs(n);
        char comma;
        for (int i = 0; i < n; ++i) {
            cin >> songs[i];
            if (i < n - 1) cin >> comma;
        }
        
        // dp[j][k]: 使用 j 张光盘，当前光盘已用 k 分钟时，最多歌曲数
        vector<vector<int>> dp(m + 1, vector<int>(t + 1, -1));
        dp[0][0] = 0;
        
        for (int i = 0; i < n; ++i) {
            int length = songs[i];
            // 逆序更新，避免重复使用当前歌曲
            for (int j = m; j >= 0; --j) {
                for (int k = t; k >= 0; --k) {
                    if (dp[j][k] < 0) continue;
                    // 尝试放入当前光盘
                    if (k + length <= t) {
                        dp[j][k + length] = max(dp[j][k + length], dp[j][k] + 1);
                    }
                    // 尝试放入新光盘
                    if (j < m) {
                        dp[j + 1][length] = max(dp[j + 1][length], dp[j][k] + 1);
                    }
                }
            }
        }
        
        int ans = 0;
        for (int j = 0; j <= m; ++j) {
            for (int k = 0; k <= t; ++k) {
                ans = max(ans, dp[j][k]);
            }
        }
        cout << ans << '\n';
    }
    
    return 0;
}
```
