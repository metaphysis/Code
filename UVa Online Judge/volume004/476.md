[UVa 476 Points in Figures Rectangles](https://blog.csdn.net/metaphysis/article/details/161945304)

## 题目描述

题目要求判断给定点是否在给定的矩形内部（边界上的点不算）。矩形由左上角和右下角坐标给出。输入包含多个矩形描述和多个点坐标。输出每个点所在的矩形编号（按输入顺序），若不在任何矩形内则输出相应消息。

## 输入格式

输入包含两部分：
- 第一部分：若干行，每行以字符 `r` 开头，后跟四个实数，表示矩形的左上角 $(x_1, y_1)$ 和右下角 $(x_2, y_2)$ 坐标。矩形数量 $n \le 10$。以一行 `*` 结束。
- 第二部分：若干行，每行两个实数，表示点的坐标。以 `9999.9 9999.9` 结束（该点不参与判断）。

## 输出格式

对于每个点，输出一行：
- 若点在某个矩形内部，输出 `Point i is contained in figure j`，其中 $i$ 为点序号（从 $1$ 开始），$j$ 为矩形序号（从 $1$ 开始）。若点在多个矩形内，则每个矩形输出一行。
- 若点不在任何矩形内，输出 `Point i is not contained in any figure`。

## 样例

输入

```
r 8.5 17.0 25.5 -8.5
r 0.0 10.3 5.5 0.0
r 2.5 12.5 12.5 2.5
*
2.0 2.0
4.7 5.3
6.9 11.2
20.0 20.0
17.6 3.2
-5.2 -7.8
9999.9 9999.9
```

输出

```
Point 1 is contained in figure 2
Point 2 is contained in figure 2
Point 2 is contained in figure 3
Point 3 is contained in figure 3
Point 4 is not contained in any figure
Point 5 is contained in figure 1
Point 6 is not contained in any figure
```

## 题目分析

本题的核心是判断点是否在轴对齐的矩形内部（不包含边界）。

### 矩形表示

给定左上角 $(x_1, y_1)$ 和右下角 $(x_2, y_2)$，矩形的四条边为：
- 左边：$x = x_1$
- 右边：$x = x_2$
- 上边：$y = y_1$
- 下边：$y = y_2$

注意：左上角的 $y$ 坐标可能大于右下角的 $y$ 坐标（因为 $y$ 轴方向向上）。因此，矩形的 $x$ 范围为 $[\min(x_1, x_2), \max(x_1, x_2)]$，$y$ 范围为 $[\min(y_1, y_2), \max(y_1, y_2)]$。

### 点在矩形内部的条件

点 $(x, y)$ 在矩形内部（不包括边界）当且仅当：
$$
\min(x_1, x_2) < x < \max(x_1, x_2) \quad \text{且} \quad \min(y_1, y_2) < y < \max(y_1, y_2)
$$

### 实现方法

- 读取矩形时，记录矩形的 $x$ 范围（左、右）和 $y$ 范围（上、下）。
- 对于每个点，遍历所有矩形，检查是否满足上述条件。
- 输出时注意点和矩形的编号（从 $1$ 开始）。

### 精度处理

由于输入为实数，可能包含浮点误差。判断时使用严格的 `>` 和 `<` 比较，无需容差（因为边界上的点不算内部）。若输入有精度问题，可设置一个很小的 $\epsilon$。

### 复杂度分析

$n \le 10$，点数未知但有限，总复杂度 $O(\text{点数} \times n)$。

```cpp
// Points in Figures: Rectangles

#include <bits/stdc++.h>

using namespace std;

const double EPSILON = 1e-7;

struct point
{
    double x, y;
};

struct rectangle
{
    point left_top, right_top, right_bottom, left_bottom;
};

vector<rectangle> rectangles;
int cases = 0;

double direction(point a, point b, point c)
{
    return (b.x - a.x) * (c.y - a.y) - (c.x - a.x) * (b.y - a.y);
}

void isContained(point test)
{
    ++cases;
    bool flag = false;
    for (int i = 0; i < rectangles.size(); i++)
    {
        rectangle rect = rectangles[i];
        if (direction(rect.left_top, rect.right_top, test) < -EPSILON &&
            direction(rect.right_top, rect.right_bottom, test) < -EPSILON &&
            direction(rect.right_bottom, rect.left_bottom, test) < -EPSILON &&
            direction(rect.left_bottom, rect.left_top, test) < -EPSILON)
        {
            flag = true;
            cout << "Point " << cases << " is contained in figure " << (i + 1) << endl;
        }
    }
    
    if (!flag) cout << "Point " << cases << " is not contained in any figure" << endl;
}

int main(int argc, char *argv[])
{
    ios::sync_with_stdio(false);

    char input;
    while (cin >> input, input != '*')
    {
        double left_top_x, left_top_y, right_bottom_x, right_bottom_y;
        cin >> left_top_x >> left_top_y >> right_bottom_x >> right_bottom_y;
        rectangle rect;
        rect.left_top = (point){left_top_x, left_top_y};
        rect.right_top = (point){right_bottom_x, left_top_y};
        rect.right_bottom = (point){right_bottom_x, right_bottom_y};
        rect.left_bottom = (point){left_top_x, right_bottom_y};
        rectangles.push_back(rect);
    }
    
    string test_x, test_y;
    while (cin >> test_x >> test_y)
    {
        if (test_x == "9999.9" && test_y == "9999.9") break;
        isContained((point){stod(test_x), stod(test_y)});
    }
    
    return 0;
}
```
