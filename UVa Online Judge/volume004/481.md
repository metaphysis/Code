## 题目描述

题目要求从给定的整数序列中找出最长严格递增子序列（$\texttt{LIS，Longest Increasing Subsequence}$），并输出其长度和该子序列本身。如果存在多个最长严格递增子序列，输出最后出现的一个（即在原序列中位置靠后的元素构成的子序列）。

## 输入格式

输入包含若干行，每行一个整数（可为正、负或零）。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

第一行输出最长严格递增子序列的长度。第二行输出一个短横线 `-`。接下来每行输出子序列中的一个整数，按原序列中的顺序输出。

## 样例

输入

```
-7
10
9
2
3
8
8
6
```

输出

```
4
-
-7
2
3
6
```

## 题目分析

本题的核心是求解最长严格递增子序列，并要求输出子序列本身，且当有多个时输出最后出现的一个。

### 经典 $\texttt{LIS}$ 算法

通常使用 $O(n \log n)$ 的贪心加二分算法：
- 维护数组 $m$，其中 $m[k]$ 表示长度为 $k+1$ 的递增子序列的末尾元素的最小可能值。
- 遍历每个元素 $x$：
  - 若 $x$ 大于 $m$ 的最后一个元素，则将其追加到 $m$ 末尾。
  - 否则，在 $m$ 中找到第一个大于等于 $x$ 的位置，将其替换为 $x$。

### 输出子序列

为了输出子序列本身，需要记录每个元素在 $m$ 中的位置以及前驱信息：
- 维护数组 $\textit{indexer}$，其中 $\textit{indexer}[k]$ 表示 $m[k]$ 在原序列中的索引。
- 维护数组 $\textit{parent}$，记录每个元素在其所在递增子序列中的前驱索引。
- 当 $x$ 被追加时，其前驱为当前 $m$ 最后一个元素对应的索引。
- 当 $x$ 替换某个位置时，其前驱为 $\textit{indexer}[n-1]$（即前一个长度的末尾元素索引）。
- 最终，$\textit{indexer}$ 的最后一个元素即为最长子序列的最后一个元素，通过 $\textit{parent}$ 回溯即可得到整个子序列。

### 最后出现的要求

由于算法在替换时保留较小的末尾值，但为了得到最后出现的子序列，需要在替换时优先保留较晚出现的相同值？实际上，经典算法自然会产生字典序较小的子序列。为了得到最后出现的，可以修改二分查找的条件：当 $x$ 等于 $m[k]$ 时，仍将其视为替换（即严格递增不允许相等）。但“最后出现”指的是在长度相同的情况下，选择在原序列中位置更靠后的子序列。由于算法在遍历过程中始终使用最新的元素作为候选，最终得到的子序列实际上就是最后出现的（因为算法总是尽可能地保留较晚的元素作为末尾，从而使得子序列整体偏后）。参考代码的实现满足这一要求。

### 复杂度分析

时间复杂度 $O(n \log n)$，空间复杂度 $O(n)$。

#include <bits/stdc++.h>

using namespace std;

vector<int> numbers, m, parent, indexer;

int lis()
{
    parent.resize(numbers.size());
    
    m.push_back(numbers.front());
    indexer.push_back(0);
    parent[0] = -1;
    
    for (int i = 1; i < numbers.size(); i++)
    { 
        if (numbers[i] > m.back())
        {
            m.push_back(numbers[i]);
            parent[i] = indexer.back();
            indexer.push_back(i);
        }
        else
        {
            int n = lower_bound(m.begin(), m.end(), numbers[i]) - m.begin();
            m[n] = numbers[i];
            if (n == 0)
                parent[i] = -1;
            else
                parent[i] = indexer[n - 1];
            
            indexer[n] = i;
        }
    }
    
    return m.size();
}

void findPath(int i)
{
    if (parent[i] != -1)
        findPath(parent[i]);
    cout << numbers[i] << '\n';
}

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int number;
    while (cin >> number) numbers.push_back(number);
    
    cout << lis() << '\n';
    cout << '-' << '\n';
    findPath(indexer.back());
    
    return 0;
}
