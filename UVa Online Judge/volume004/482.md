## 题目描述

题目要求根据给定的索引数组 $p$ 对数据数组 $x$ 进行重排。索引数组 $p$ 包含 $1$ 到 $n$ 的整数（不一定按顺序），表示新数组中每个位置上的元素在原数组中的索引。即 $x'_{p_i} = x_i$。给定 $p$ 和 $x$，输出重排后的数组 $x'$，每行一个元素。

## 输入格式

第一行一个整数 $N$，表示测试用例的数量，后面跟一个空行。每个测试用例包含两行：
- 第一行：$n$ 个整数，表示索引数组 $p$。
- 第二行：$n$ 个浮点数（或其他格式的数字），表示数据数组 $x$。
两个连续测试用例之间由一个空行分隔。

## 输出格式

对于每个测试用例，输出 $n$ 行，每行一个重排后的数据，按 $x'$ 的顺序（即位置 $1$ 到 $n$）。两个连续测试用例的输出之间由一个空行分隔。

## 样例

输入

```
1

3 1 2
32.0 54.7 -2
```

输出

```
54.7
-2
32.0
```

## 题目分析

本题的核心是根据索引数组 $p$ 将数据数组 $x$ 重新排列。关系为 $x'_{p_i} = x_i$，即原数组的第 $i$ 个元素应放在新数组的第 $p_i$ 个位置。

### 算法步骤

1. 读取索引数组 $p$，长度为 $n$。
2. 读取数据数组 $x$，长度也为 $n$。
3. 创建结果数组 $x'$，大小为 $n$。
4. 对于每个 $i$（$0$ 到 $n-1$），设置 $x'[p_i - 1] = x[i]$。
5. 按顺序输出 $x'$。

### 注意点

- 索引数组中的值是从 $1$ 开始的，需要转换为 $0$ 索引。
- 数据数组中的数字可能包含负号、小数点等，应作为字符串原样输出（以保留原始格式）。
- 输入中可能有多余的空格或空行，需要正确处理。

### 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

// Permutation Arrays

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    
    getline(cin, line);
    int cases = stoi(line);

    for (int i = 1; i <= cases; i++)
    {
        if (i > 1) cout << endl;
        vector<int> order;
        vector<string> number;
        
        getline(cin, line);
        getline(cin, line);
        istringstream iss(line);
        
        int index;
        while (iss >> index)
            order.push_back(index);
            
        getline(cin, line);
        iss.clear();
        iss.str(line);
        string block;
        while (iss >> block)
            number.push_back(block);
            
        vector<int> output(order.size());
        for (int j = 0; j < order.size(); j++)
            output[order[j] - 1] = j;
            
        for (int j = 0; j < output.size(); j++)
            cout << number[output[j]] << '\n';
    }
    
    return 0;
}
