## 题目描述

题目要求统计整数序列中每个不同整数出现的次数，并按整数第一次出现的顺序输出。

## 输入格式

输入包含若干整数（正、负或零），以文件结束符（$\texttt{EOF}$）终止。输入可能很长。

## 输出格式

输出若干行，每行包含一个整数及其出现次数，中间用空格分隔。整数按输入中第一次出现的顺序输出。

## 样例

输入

```
3 1 2 2 1 3 5 3 3 2
```

输出

```
3 4
1 2
2 3
5 1
```

## 题目分析

本题的核心是记录每个整数第一次出现的顺序，并统计其出现次数。

### 算法步骤

- 使用一个向量 $\textit{order}$ 记录整数第一次出现的顺序。
- 使用一个集合 $\textit{appeared}$ 判断整数是否已经出现过。
- 使用一个映射 $\textit{counter}$ 统计每个整数的出现次数。
- 遍历输入整数：
  - 若整数未出现过，则将其加入 $\textit{order}$ 和 $\textit{appeared}$。
  - 无论是否出现过，$\textit{counter}[n]++$。
- 按 $\textit{order}$ 的顺序输出每个整数及其计数。

### 复杂度分析

时间复杂度 $O(n \log m)$，其中 $n$ 为整数个数，$m$ 为不同整数个数。空间复杂度 $O(m)$。

```cpp
#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    
    vector<int> number;
    set<int> appeared;
    map<int, int> counter;
    
    int n;
    while (cin >> n)
    {
        if (appeared.find(n) == appeared.end())
        {
            number.push_back(n);
            appeared.insert(n);
        }
        counter[n]++;
    }
    
    for (auto i : number) cout << i << " " << counter[i] << endl;
        
    return 0;
}
```
