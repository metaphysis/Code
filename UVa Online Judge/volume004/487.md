## 题目描述

题目要求在 $N \times N$ 的字母网格中找出所有满足以下条件的单词：
- 单词长度至少为 $3$。
- 单词中相邻字母在网格中必须是相邻的（八个方向：水平、垂直、对角线）。
- 单词中的字母不能重复使用网格中的同一位置。
- 单词的字母序列必须严格递增（按 $\texttt{ASCII}$ 值，即后一个字母必须大于前一个字母）。
- 每个单词在输出中只出现一次。

输出要求：先按长度升序排列，长度相同则按字典序升序。

## 输入格式

第一行一个整数 $T$，表示测试用例的数量，后面跟一个空行。每个测试用例的第一行为整数 $N$（$1 \le N \le 20$），接下来 $N$ 行每行 $N$ 个字符，表示字母网格。两个连续测试用例之间由一个空行分隔。

## 输出格式

对于每个测试用例，输出所有合法的单词，每行一个。两个连续测试用例的输出之间由一个空行分隔。如果没有合法单词，则不输出任何内容。

## 题目分析

本题的核心是在网格中搜索所有严格递增的路径（长度 $\ge 3$），并去重输出。

### 搜索策略

由于网格规模最大为 $20 \times 20 = 400$，路径数量可能很大，但每个字符只能使用一次且字母必须严格递增，这限制了路径长度（最多 $26$ 个不同字母）。可以使用广度优先搜索（$\texttt{BFS}$）或深度优先搜索（$\texttt{DFS}$）生成所有路径。

### 去重

- 同一个单词可能从不同的起始位置或通过不同的路径得到，需要去重。可以使用 $\texttt{set<string>}$ 存储所有找到的单词。
- 同时，为了避免重复搜索相同的“状态”（即相同位置、相同单词），可以使用一个标记集合 $\textit{tags}$ 记录已经处理过的 $(i, j, word)$ 组合。但注意，由于路径不能重复使用位置，不同顺序的访问会导致不同的单词，因此需要按位置和单词字符串联合去重。

### 算法步骤

1. 初始化一个队列，将每个格子作为起始点入队，单词初始为该格子字母。
2. 当队列非空时：
   - 弹出当前状态（位置 $(i, j)$，单词 $w$）。
   - 遍历 $8$ 个相邻方向：
     - 若相邻位置 $(ni, nj)$ 的字母大于 $w$ 的最后一个字母，则形成新单词 $nw = w + table[ni][nj]$。
     - 若 $nw$ 长度 $\ge 3$，将其加入单词集合。
     - 将新状态 $(ni, nj, nw)$ 入队（无论长度是否 $\ge 3$，因为后续还可继续延长）。
   - 注意：由于路径不能重复使用格子，但算法中没有显式禁止重复使用同一个格子。因为字母必须严格递增，所以不会出现回到之前格子（因为之前格子字母更小），但可能经过不同格子？实际上，由于严格递增，不可能形成环，因此不会重复使用格子。所以无需额外的访问标记。

3. 搜索结束后，将单词集合按长度和字典序排序输出。

### 复杂度分析

每个状态由位置和单词唯一确定，单词长度最多 $26$，位置最多 $400$，状态数有限。实际运行效率较高。

```cpp
// Boggle Blitz

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

struct state
{
    int i, j;
    string word;
};

bool cmp(string& a, string& b)
{
    if (a.length() != b.length())
        return a.length() < b.length();
    else
        return a < b;
}

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int cases;
    cin >> cases;
    
    for (int i = 1; i <= cases; i++)
    {
        if (i > 1) cout << '\n';
        
        char table[20][20];

        int n;
        cin >> n;
        
        string line;
        for (int j = 1; j <= n; j++)
        {
            cin >> line;
            for (int k = 0; k < line.length(); k++)
                table[j -  1][k] = line[k];
        }
        
        set<string> words, tags;
        
        queue<state> unvisited;
        for (int j = 0; j < n; j++)
            for (int k = 0; k < n; k++)
            {
                state start;
                start.i = j, start.j = k;
                start.word += table[j][k];
                unvisited.push(start);
            }
            
        while (unvisited.empty() == false)
        {
            state current = unvisited.front();
            unvisited.pop();
            
            for (int offsetx = -1; offsetx <= 1; offsetx++)
                for (int offsety = -1; offsety <= 1; offsety++)
                {
                    if (offsetx == 0 && offsety == 0)
                        continue;
                        
                    int nexti = current.i + offsetx, nextj = current.j + offsety;
                    if (nexti >= 0 && nexti < n && nextj >= 0 && nextj < n && table[nexti][nextj] > current.word.back())
                    {
                        string next_word = current.word + table[nexti][nextj];
                        if (next_word.length() >= 3)
                        {
                            string tag = next_word + to_string(nexti) + to_string(nextj);
                            if (tags.find(tag) == tags.end())
                            {
                                tags.insert(tag);
                                words.insert(next_word);
                                unvisited.push((state){nexti, nextj, next_word});
                            }
                        }
                        else
                        {
                            unvisited.push((state){nexti, nextj, next_word});
                        }
                    }
                }
        }
        
        vector<string> allWords;

        for (auto word : words)
            allWords.push_back(word);
            
        sort(allWords.begin(), allWords.end(), cmp);
        for (auto word : allWords)
            cout << word << '\n';
    }
    
    return 0;
}
```
