## 题目描述

题目要求将多行句子顺时针旋转 $90$ 度后输出。即原来的第一行变为最右边的一列，原来的最后一行变为最左边的一列。输出时，每行对应原输入的一列（从上到下），行末不包含多余空格。

## 输入格式

输入包含最多 $100$ 行，每行不超过 $100$ 个字符。输入以文件结束符（$\texttt{EOF}$）终止。字符包括空格、标点、字母等（制表符不合法）。

## 输出格式

输出旋转后的图形，每一行对应原输入的一列（从最后一行的第一个字符到第一行的第一个字符），行末无多余空格。

## 题目分析

本题的核心是将输入文本矩阵顺时针旋转 $90$ 度。设输入有 $R$ 行，最大行长为 $C$，则输出应有 $C$ 行，每行 $R$ 个字符。输出第 $i$ 行（$0$ 索引）对应原矩阵的第 $i$ 列，但按从下到上的顺序：即输出第 $i$ 行第 $j$ 个字符对应原矩阵第 $(R-1-j)$ 行第 $i$ 列。

### 算法步骤

1. 读取所有输入行，记录最大长度 $maxLen$。
2. 对于 $i$ 从 $0$ 到 $maxLen-1$：
   - 对于 $j$ 从 $R-1$ 到 $0$：
     - 若 $i < sentences[j].length()$，则输出 $sentences[j][i]$。
     - 否则输出空格。
   - 输出换行。

### 注意点

- 输出行末不应有多余空格，但上述循环中若某列后面全是空格，则这些空格应输出（因为旋转后它们位于行内）。实际上，题目要求输出空格作为空白位置，但行末空格通常不要求保留。参考代码未做特殊处理，直接输出所有列，包括末尾空格。
- 输入中可能包含制表符，需要过滤或处理。

### 复杂度分析

时间复杂度 $O(R \times C)$，$R \le 100$，$C \le 100$，完全可接受。

## 代码实现

```cpp
// Rotating Sentences
// UVa ID: 490
// Verdict: Accepted
// Submission Date: 2016-07-13
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    ios::sync_with_stdio(false);

    int max_length = 0;
    vector<string> sentences;
    string line;
    while (getline(cin, line))
    {
        for (int i = line.length() - 1; i >= 0; i--)
            if (line[i] == '\t')
                line.erase(line.begin() + i);
        max_length = max(max_length, (int)line.length());        
        sentences.push_back(line);
    }
    
    for (int i = 0; i < max_length; i++)
    {
        for (int j = sentences.size() - 1; j >= 0; j--)
            if (i < sentences[j].length())
                cout << sentences[j][i];
            else
                cout << ' ';
        cout << endl;
    }
    
    return 0;
}
```
