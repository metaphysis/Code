## 题目描述

题目要求计算多项式在多个 $x$ 值处的取值。多项式系数按 $c_0 x^n + c_1 x^{n-1} + \dots + c_n$ 的顺序给出（$n$ 为多项式的次数）。对于每组数据，输出每个 $x$ 对应的多项式值。

## 输入格式

输入包含偶数行，每对相邻行表示一个测试用例：第一行是多项式的系数列表（整数），第二行是 $x$ 值的列表（整数）。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每个测试用例，输出一行，包含每个 $x$ 对应的多项式值，之间用空格分隔。

## 样例

输入

```
-2
-5 0 1 6 -1
-7 6 -1
```

输出

```
-2 -2
-2 -2 -2 -2 -2 -6 5 -2
```

## 题目分析

本题的核心是多项式求值。直接使用霍纳方法（$\texttt{Horner's method}$）可以高效计算。

### 霍纳方法

对于多项式 $P(x) = c_0 x^n + c_1 x^{n-1} + \dots + c_n$，可改写为：
$$
P(x) = (\dots ((c_0 x + c_1)x + c_2)x + \dots )x + c_n
$$
计算时从最高次项开始，每次乘以 $x$ 并加上下一项系数，只需 $n$ 次乘法和 $n$ 次加法。

### 算法步骤

- 对于每个 $x$，初始化 $\textit{sum} = 0$。
- 从系数列表的第一个元素（$c_0$）开始，依次更新 $\textit{sum} = \textit{sum} \times x + c_i$。
- 最终 $\textit{sum}$ 即为多项式值。

### 注意点

- 系数列表长度即为 $n+1$。
- 注意输入中可能有负号与数字相连，如 `-2` 表示整数 $-2$。

### 复杂度分析

每个 $x$ 计算 $O(n)$ 次，总复杂度 $O(m \times n)$。

```cpp
// Polly the Polynomial

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    istringstream iss;
    
    vector<long long> coefficients;
    
    string line;
    while (getline(cin, line))
    {
        iss.clear();
        iss.str(line);
        
        coefficients.clear();
        long long number;
        while (iss >> number)
            coefficients.push_back(number);
            
        getline(cin, line);
        iss.clear();
        iss.str(line);
        
        bool first = true;
        while (iss >> number)
        {
            long long sum = 0, base = 1;
            for (int i = coefficients.size() - 1; i >= 0; i--)
            {
                sum += base * coefficients[i];
                base *= number;
            }
            if (first) first = false;
            else cout << ' ';
            cout << sum;
        }
        cout << '\n';
    }
    
    return 0;
}
```
