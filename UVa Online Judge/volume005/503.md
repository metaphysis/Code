[UVa 503 Parallelepiped Walk](https://blog.csdn.net/metaphysis/article/details/162025764)

## 题目描述

题目要求计算长方体表面上两点之间的最短路径长度的平方。长方体尺寸为 $L \times W \times H$，顶点坐标 $(x,y,z)$ 满足 $0 \le x \le L$、$0 \le y \le W$、$0 \le z \le H$。两点 $A(x_1,y_1,z_1)$ 和 $B(x_2,y_2,z_2)$ 均在长方体表面上。需要计算最短路径长度的平方。

## 输入格式

输入包含多行，每行 $9$ 个整数，顺序为：$L, W, H, x_1, y_1, z_1, x_2, y_2, z_2$。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每行输入，输出一行一个整数，表示最短路径长度的平方。

## 样例

输入

```
5 5 2 3 1 2 3 5 0
300 600 900 300 550 0 0 550 900
```

输出

```
36
970000
```

## 题目分析

本题的核心是计算长方体表面上两点之间的最短路径长度。可以将长方体表面展开成平面，然后计算展开后两点之间的直线距离，取所有可能展开方式中的最小值。

### 展开方法

长方体有 $6$ 个面，两点可能位于不同的面上。最短路径可能经过 $0$、$1$ 或 $2$ 个棱（即穿过 $0$、$1$ 或 $2$ 个面）。通过旋转反射（$\texttt{rotate}$）可以将问题转化为平面上的点距离计算。

### 算法

- 将点 $A$ 固定在某个面上（例如 $z=0$ 面）。
- 通过旋转反射，将点 $B$ 映射到与 $A$ 同一平面的不同位置，计算欧几里得距离的平方。
- 遍历所有可能的旋转反射组合，取最小值。

具体实现中，使用递归函数 $\texttt{rotate}$ 模拟在 $x$、$y$、$z$ 方向上的展开。

### 复杂度分析

每次递归最多 $4$ 种选择，深度为 $2$，常数时间。

## 代码实现

```cpp
// Parallelepiped Walk
// UVa ID: 503
// Verdict: Accepted
// Submission Date: 2017-04-21
// UVa Run Time: 0.000s
//
// 版权所有（C）2017，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int curve;

void rotate(int i, int j, int x, int y, int z, int x0, int y0, int L, int W, int H)
{
    if (z == 0)
        curve = min(curve, x * x + y * y);
    else
    {
        if ((i >= 0) && (i < 2))
            rotate(i + 1, j, x0 + L + z, y, x0 + L - x, x0 + L, y0, H, W, L);
        if ((j >= 0) && (j < 2))
            rotate(i, j + 1, x, y0 + W + z, y0 + W - y, x0, y0 + W, L, H, W);
        if ((i <= 0) && (i > -2))
            rotate(i - 1, j, x0 - z, y, x - x0, x0 - H, y0, H, W, L);
        if ((j <= 0) && (j > -2))
            rotate(i, j - 1, x, y0 - z, y - y0, x0, y0 - H, L, H, W);
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int L, W, H, x1, y1, z1, x2, y2, z2;

    while (cin >> L >> W >> H >> x1 >> y1 >> z1 >> x2 >> y2 >> z2)
    {
        if (z1 != 0 && z1 != H)
        {
            if (y1 == 0 || y1 == W)
                swap(y1, z1), swap(y2, z2), swap(W, H);
            else
                swap(x1, z1), swap(x2, z2), swap(L, H);
        }
        if (z1 == H)
            z1 = 0, z2 = H - z2;

        curve = numeric_limits<int>::max();
        rotate(0, 0, x2 - x1, y2 - y1, z2, -x1, -y1, L, W, H);
        cout << curve << '\n';
    }

    return 0;
}
```
