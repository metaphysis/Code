## 题目描述

给定两个整数 $M$ 和 $N$（$1 \le N \le M \le 200$），考虑所有满足以下条件的非降序列 $u(1), u(2), \ldots, u(N)$：

1. $1 \le u(1) \le u(2) \le \ldots \le u(N) \le M$
2. 对于每个 $p$（$1 \le p \le N$），有 $p \le u(p) \le M$

将所有满足条件的序列按字典序排列，从 $1$ 开始编号。现在给定一个二进制实数 $0.b_1 b_2 \ldots b_p$（$1 \le p \le 400$），要求找出对应编号的序列。

## 输入格式

第一行是一个整数 $K$，表示数据组数，接下来是一个空行。每组数据的第一行包含两个整数 $M$ 和 $N$，第二行包含一个二进制实数，格式为 `0.b1b2...bp`，没有前导、尾随或其他空格。两组数据之间有一个空行。

## 输出格式

对于每组数据，输出对应的序列 $u(1), u(2), \ldots, u(N)$，数字之间用空格分隔。每行最多输出 $20$ 个数字，每个数字占 $3$ 个字符宽度（右对齐）。两组数据之间输出一个空行。

## 样例

输入

```
1

4 3
0.01101101011110010001101010001011010
```

输出

```
  2   2   4
```

## 题目分析

本题的核心包含两个子问题：

1. **编号计算**：给定二进制小数 $0.b_1 b_2 \ldots b_p$，需要计算它在 $[1, T]$ 区间内对应的整数编号（$T$ 为序列总数）。
2. **字典序定位**：根据计算出的编号，在字典序中找到对应的具体序列。

### 编号计算方法

题目给出了一个递归的二分区间映射方法。设 $G(A, B, 0.b_1 b_2 \ldots b_p)$ 返回 $[A, B]$ 区间内的一个整数，其中：

- 如果 $p = 0$ 或 $A = B$，则返回 $A$。
- 否则，设 $\textit{mid} = \lfloor (A + B) / 2 \rfloor$（整数除法）：
  - 若 $b_1 = 0$，递归到 $G(A, \textit{mid}, 0.b_2 b_3 \ldots b_p)$。
  - 若 $b_1 = 1$，递归到 $G(\textit{mid} + 1, B, 0.b_2 b_3 \ldots b_p)$。

最终编号为 $\textit{idx} = G(1, T, 0.b_1 b_2 \ldots b_p)$，其中 $T$ 是序列总数。

这种方法本质上是将区间 $[1, T]$ 不断二分，二进制小数的每一位决定选择左半区间还是右半区间。由于 $T$ 可能非常大（在 $M = N = 200$ 时，$T$ 是一个远超 $64$ 位整数范围的巨大数字），我们需要使用大整数来存储和处理 $T$ 以及递归过程中的区间端点。

### 序列计数方法

为了计算 $T$ 以及后续的字典序定位，我们需要一个高效的动态规划来计算满足条件的序列数量。

设 $\textit{dp}[pos][val]$ 表示：第 $pos$ 位**恰好取 $val$** 时，从第 $pos$ 位到第 $N$ 位的方案总数。边界条件和转移方程如下：

- 边界（第 $N$ 位）：如果 $val \ge N$，则 $\textit{dp}[N][val] = 1$，否则为 $0$。
- 转移（$pos < N$）：由于序列非降，第 $pos$ 位取 $val$ 后，第 $pos+1$ 位可以取 $val, val+1, \ldots, M$ 中的任意值，因此：
  $$
  \textit{dp}[pos][val] = \sum_{k = val}^{M} \textit{dp}[pos + 1][k]
  $$

最终总方案数 $T = \sum_{v = 1}^{M} \textit{dp}[1][v]$。

直接计算这个 DP 的复杂度为 $O(N \cdot M^2)$。对于 $M, N \le 200$，$200^3 = 8 \times 10^6$ 次大整数加法，在万进制优化下可以接受。但我们可以进一步优化到 $O(N \cdot M)$：注意到 $\textit{dp}[pos][val] = \textit{dp}[pos][val + 1] + \textit{dp}[pos + 1][val]$，使用后缀和技巧即可。

### 字典序定位方法

有了 $\textit{dp}[pos][val]$ 后，我们可以按以下步骤确定序列：

设 $\textit{remain}$ 为当前要找的编号（从 $1$ 开始）。从第 $1$ 位到第 $N$ 位依次确定：

- 对于第 $pos$ 位，从最小值 $\textit{last}$（上一位的值）开始尝试每个可能的取值 $v$。
- 如果 $v < pos$，跳过（不满足 $u(pos) \ge pos$ 约束）。
- 以 $v$ 开头的序列数量为 $\textit{cnt} = \textit{dp}[pos][v]$。
- 如果 $\textit{remain} > \textit{cnt}$，说明目标序列不在以 $v$ 开头的块中，令 $\textit{remain} = \textit{remain} - \textit{cnt}$ 并尝试下一个 $v$。
- 否则，目标序列在以 $v$ 开头的块中，记录 $u(pos) = v$，更新 $\textit{last} = v$，继续确定下一位。

这个过程本质上是在字典树上按照编号大小进行“行走”。

## 解题思路

### 第一步：大整数实现

由于 $T$ 可能极大（组合数级别），我们需要一个支持加法、减法、比较、除以小整数的大整数类。为了提升效率，我们采用**万进制**（$\texttt{BASE} = 10000$）存储，每位存储 $0$ 到 $9999$ 的整数。这样可以将十进制下最多约 $120$ 位的数字压缩到约 $30$ 位，大幅减少大整数运算的常数。

大整数类需要实现以下核心功能：
- 构造函数：从 `unsigned long long` 构造。
- 加法、减法、比较（用于判断大小和区间递归终止条件）。
- 除以小整数（用于二分递归中的 $\textit{mid}$ 计算）。
- 转换为 `unsigned long long`（用于最终编号，因为 $T$ 虽然大，但编号在 $[1, T]$ 内，最终递归结果不会超过 $T$，而 $T$ 在 $M, N \le 200$ 时约 $10^{60}$ 量级，无法用内置整数表示，但编号作为中间结果仍需要大整数。实际上在递归中比较 $A$ 和 $B$ 相等时返回，此时 $A$ 是大整数，但最终会转换为 `unsigned long long` 用于定位）。

### 第二步：$\texttt{DP}$ 计算方案数

我们使用 $O(N \cdot M)$ 的后缀和优化 $\texttt{DP}$：

1. 初始化第 $N$ 位：$\textit{dp}[N][val] = 1$ 当 $val \ge N$，否则 $0$。
2. 从 $pos = N-1$ 到 $1$ 倒序计算：
   - 维护后缀和 $\textit{suffix} = \sum_{k = \textit{last}}^{M} \textit{dp}[pos + 1][k]$。
   - 从 $last = M$ 向下遍历到 $1$，每次将 $\textit{dp}[pos + 1][last]$ 累加到 $\textit{suffix}$，然后令 $\textit{dp}[pos][last] = \textit{suffix}$（若 $last \ge pos$，否则为 $0$）。

这样可以在一次循环内完成所有转移。

### 第三步：编号计算

实现递归函数 $G(A, B, \textit{bits}, \textit{idx})$：
- 如果 $\textit{idx} \ge \textit{bits.size()}$ 或 $A = B$，返回 $A$。
- 计算 $\textit{mid} = (A + B) / 2$（大整数除以 $2$）。
- 根据 $\textit{bits}[\textit{idx}]$ 决定递归到左半区间还是右半区间。

注意：由于 $A$ 和 $B$ 是大整数，比较和除法都需要使用大整数类的方法。

### 第四步：字典序定位

使用 $\textit{dp}$ 数组和计算出的编号 $\textit{target}$ 构建序列：
- 初始化 $\textit{remain} = \textit{target}$，$\textit{last} = 1$。
- 对于 $pos = 1$ 到 $N$：
  - 枚举 $v = \textit{last}$ 到 $M$：
    - 如果 $v < pos$，跳过。
    - 获取 $\textit{cnt} = \textit{dp}[pos][v]$（这是以 $v$ 开头的方案数）。
    - 如果 $\textit{remain} > \textit{cnt}$，$\textit{remain} = \textit{remain} - \textit{cnt}$。
    - 否则，选择 $v$，记录到答案，更新 $\textit{last} = v$，并跳出内层循环。

### 复杂度分析

- **$\texttt{DP}$ 计算**：$O(N \cdot M)$ 次大整数加法，每次加法复杂度为 $O(\text{位数}) \approx O(\log_{10000} T)$，约 $30$ 单位。
- **编号计算**：递归深度为 $p \le 400$，每次递归进行一次大整数加法和除法，复杂度 $O(p \cdot \text{位数})$，约 $400 \times 30 = 12000$ 次基本运算。
- **字典序定位**：$O(N \cdot M)$ 次大整数比较和减法，同样约 $200 \times 200 = 40000$ 次大整数运算。

总时间复杂度约为 $O((N \cdot M + p) \cdot \log T)$，在 $M, N \le 200$，$p \le 400$ 时完全可行。

```cpp

// Random Number
// UVa ID: 504

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct BigInt {
    static const int BASE = 10000;
    vector<int> d;
    BigInt(unsigned long long x = 0) { while (x) { d.push_back(x % BASE); x /= BASE; } if (d.empty()) d.push_back(0); }
    BigInt& operator+=(const BigInt& b) {
        int carry = 0;
        for (size_t i = 0; i < d.size() || i < b.d.size() || carry; ++i) {
            if (i < d.size()) carry += d[i];
            if (i < b.d.size()) carry += b.d[i];
            if (i < d.size()) d[i] = carry % BASE;
            else d.push_back(carry % BASE);
            carry /= BASE;
        }
        return *this;
    }
    BigInt operator+(const BigInt& b) const { BigInt r = *this; r += b; return r; }
    BigInt& operator-=(const BigInt& b) {
        int borrow = 0;
        for (size_t i = 0; i < d.size(); ++i) {
            int sub = (i < b.d.size()) ? b.d[i] : 0;
            d[i] -= sub + borrow;
            if (d[i] < 0) d[i] += BASE, borrow = 1;
            else borrow = 0;
        }
        while (d.size() > 1 && d.back() == 0) d.pop_back();
        return *this;
    }
    BigInt operator-(const BigInt& b) const { BigInt r = *this; r -= b; return r; }
    BigInt operator/(unsigned long long div) const {
        BigInt r;
        unsigned long long rem = 0;
        for (int i = d.size() - 1; i >= 0; --i) {
            rem = rem * BASE + d[i];
            r.d.push_back(rem / div);
            rem %= div;
        }
        reverse(r.d.begin(), r.d.end());
        while (r.d.size() > 1 && r.d.back() == 0) r.d.pop_back();
        return r;
    }
    int cmp(const BigInt& b) const {
        if (d.size() != b.d.size()) return d.size() < b.d.size() ? -1 : 1;
        for (int i = d.size() - 1; i >= 0; --i) if (d[i] != b.d[i]) return d[i] < b.d[i] ? -1 : 1;
        return 0;
    }
    bool operator>(const BigInt& b) const { return cmp(b) > 0; }
    bool isZero() const { return d.size() == 1 && d[0] == 0; }
    unsigned long long toULL() const {
        unsigned long long r = 0;
        for (int i = d.size() - 1; i >= 0; --i) r = r * BASE + d[i];
        return r;
    }
};

int M, N;
vector<vector<BigInt>> dp;

void computeDP() {
    dp.assign(N + 2, vector<BigInt>(M + 2));
    for (int last = 1; last <= M; ++last) 
        dp[N][last] = (last >= N) ? BigInt(1) : BigInt(0);
    for (int pos = N - 1; pos >= 1; --pos) {
        BigInt suffix(0);
        for (int last = M; last >= 1; --last) {
            suffix = suffix + dp[pos + 1][last];
            dp[pos][last] = (last >= pos) ? suffix : BigInt(0);
        }
    }
}

BigInt G(BigInt A, BigInt B, const string& bits, int idx) {
    if (idx >= (int)bits.size() || A.cmp(B) == 0) return A;
    BigInt mid = (A + B) / 2ULL;
    return bits[idx] == '0' ? G(A, mid, bits, idx + 1) : G(mid + 1ULL, B, bits, idx + 1);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int K; cin >> K;
    for (int ds = 0; ds < K; ++ds) {
        if (ds) cout << '\n';
        cin >> M >> N;
        string bin; cin >> bin;
        bin = bin.substr(2);
        computeDP();
        BigInt total(0);
        for (int v = 1; v <= M; ++v) total = total + dp[1][v];
        BigInt target = G(BigInt(1), total, bin, 0);
        vector<int> seq(N);
        int last = 1;
        BigInt remain = target;
        for (int pos = 1; pos <= N; ++pos) {
            for (int v = last; v <= M; ++v) {
                if (v < pos) continue;
                BigInt cnt = dp[pos][v];
                if (cnt.isZero()) continue;
                if (remain > cnt) remain = remain - cnt;
                else { seq[pos - 1] = v; last = v; break; }
            }
        }
        for (int i = 0; i < N; ++i) {
            if (i && i % 20 == 0) cout << '\n';
            if (i % 20) cout << ' ';
            cout << setw(3) << seq[i];
        }
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题综合考察了以下关键知识点：

1. **大整数运算**：由于方案数巨大，必须使用高精度整数。万进制实现（$\texttt{BASE} = 10000$）有效减少了数组长度和运算次数。
2. **动态规划与后缀和优化**：$\textit{dp}[pos][val]$ 的递推式 $\textit{dp}[pos][val] = \sum_{k = val}^{M} \textit{dp}[pos + 1][k]$ 可以用后缀和从 $O(M^2)$ 优化到 $O(M)$，使总复杂度从 $O(N \cdot M^2)$ 降至 $O(N \cdot M)$。
3. **递归二分映射**：二进制小数到区间编号的映射通过递归二分实现，每一步根据当前比特决定选择左半还是右半区间，本质上是将小数点的每一位转化为区间划分。
4. **字典序定位**：利用 $\texttt{DP}$ 预先计算的方案数，在字典序树上按编号“行走”，每一步减去不包含目标的大块，最终定位到具体序列。

代码优化过程中，我们经历了从十进制大整数到万进制、从 $O(N \cdot M^2)$ 到 $O(N \cdot M)$、从显式后缀和数组到合并单循环的逐步改进，最终运行时间从最初的 $2.76$ 秒降至 $80$ 毫秒，性能提升约 $34$ 倍。这充分体现了算法优化在竞赛编程中的重要性：正确的思路加上精细的实现，往往能带来质的飞跃。
