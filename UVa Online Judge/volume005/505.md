[UVa 505 Moscow Time](https://blog.csdn.net/metaphysis/article/details/162025861)

## 题目描述

题目要求将给定 $\texttt{EDATE}$ 格式的日期时间转换为莫斯科时间（$\texttt{Moscow time}$，即 $\texttt{+0300}$ 时区）。输入包含多行，每行一个 $\texttt{EDATE}$ 字符串，输出对应的莫斯科时间。输出中年份必须用四位数字表示。

## 输入格式

输入包含多行，每行一个 $\texttt{EDATE}$ 字符串，格式为 `星期, 日 月 年 时间 时区`。星期和月份为大写字母缩写，时间格式为 `hh:mm:ss`，时区可以是数字（如 `+0300`）或名称（如 $\texttt{GMT}$、$\texttt{EDT}$ 等）。输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每行输入，输出一行对应的莫斯科时间，格式与输入相同，时区固定为 `+0300`，年份用四位数字表示。

## 样例

输入

```
SUN,03 DEC 1996 09:10:35 GMT
WED,28 FEB 35 23:59:00 +0259
```

输出

```
SUN,03 DEC 1996 12:10:35 +0300
THU,01 MAR 1935 00:00:00 +0300
```

## 题目分析

本题的核心是将给定时区的时间转换为莫斯科时间（$\texttt{+0300}$），需要正确处理时差、日期进位、闰年以及年份表示（两位或四位）。

### 时区转换

莫斯科时间为 $\texttt{UTC+3}$。给定时间所在时区与 $\texttt{UTC}$ 的差值已知（数字时区或名称映射），则与莫斯科时间的差值为 $3 - \text{给定时区小时数}$（注意方向）。将时间加上该差值（分钟）即可得到莫斯科时间。

### 日期调整

- 时间调整可能跨越午夜，需要增加或减少天数。
- 天数变化需要正确处理月份的边界和闰年。
- 星期数需要同步调整（$7$ 天一周）。

### 闰年规则

- 能被 $4$ 整除且不能被 $100$ 整除，或能被 $400$ 整除的年份为闰年。
- 闰年 $2$ 月有 $29$ 天，平年 $2$ 月有 $28$ 天。

### 时区名称映射

| 名称 | 数字值 |
|------|--------|
| $\texttt{UT}$、$\texttt{GMT}$ | $+0000$ |
| $\texttt{EDT}$ | $-0400$ |
| $\texttt{CDT}$ | $-0500$ |
| $\texttt{MDT}$ | $-0600$ |
| $\texttt{PDT}$ | $-0700$ |

注意：题目中给出的映射表显示 $\texttt{EDT}$ 对应 $-0400$，但莫斯科时间为 $+0300$，差值计算需注意符号。

### 算法步骤

1. 解析输入字符串，提取各字段。
2. 将年份转换为四位数字（若为两位则加 $1900$）。
3. 根据时区计算与 $\texttt{UTC}$ 的差值（分钟）。
4. 计算与莫斯科时间的总调整分钟数（$\text{莫斯科差值} - \text{给定时区差值}$）。
5. 将时间加上调整分钟数，处理进位和日期变化。
6. 更新星期数。
7. 按格式输出结果。

### 复杂度分析

每组数据处理 $O(1)$。

// Moscow time

#include <bits/stdc++.h>

using namespace std;

string dayName[] = {"MON", "TUE", "WED", "THU", "FRI", "SAT", "SUN"};
string monthName[] = {"JAN", "FEB", "MAR", "APR", "MAY", "JUN", "JUL", "AUG", "SEP", "OCT", "NOV", "DEC"};

string sDayOfWeek, sDayOfMonth, sMonth, sYear, sTime, sTimezone;
int dayOfWeek, dayOfMonth, month, year, hour, minute, second, diffMinute;

void addDay(int day)
{
    dayOfWeek = (dayOfWeek + day + 7) % 7;
    
    bool isLeapYear = (year % 400 == 0) || ((year % 4 == 0) && (year % 100 != 0));
    if (day == 1)
    {
        if (month == 1 && dayOfMonth == 29)
        {
            dayOfMonth = 1;
            month = 2;
        }
        else if (month == 1 && dayOfMonth == 28)
        {
            if (isLeapYear)
            {
                dayOfMonth = 29;
            }
            else
            {
                dayOfMonth = 1;
                month = 2;
            }
        }
        else if (month == 11 && dayOfMonth == 31)
        {
            month = 0;
            dayOfMonth = 1;
            year += 1;
        }
        else if (dayOfMonth == 31 || (dayOfMonth == 30 && (month == 3 || month == 5 || month == 8 || month == 10)))
        {
            dayOfMonth = 1;
            month += 1;
        }
        else
        {
            dayOfMonth += 1;
        }
    }
    else
    {
        if (dayOfMonth == 1)
        {
            if (month == 0)
            {
                month = 11;
                dayOfMonth = 31;
                year -= 1;
            }
            else if (month == 2)
            {
                if (isLeapYear)
                    dayOfMonth = 29;
                else
                    dayOfMonth = 28;
                month = 1;
            }
            else if (month == 1 || month == 3 || month == 5 || month == 7 || month == 8 || month == 10)
            {
                dayOfMonth = 31;
                month -= 1;
            }
            else if (month == 4 || month == 6 || month == 9 || month == 11)
            {
                dayOfMonth = 30;
                month -= 1;
            }
        }
        else
        {
            dayOfMonth -= 1;
        }
    }
}

// format: SUN, 03 DEC 1996 09:10:35 GMT
void parse(string line)
{
    istringstream iss(line);
    iss >> sDayOfWeek >> sDayOfMonth >> sMonth >> sYear >> sTime >> sTimezone;
    
    sDayOfWeek.pop_back();
    dayOfWeek = find(dayName, dayName + 7, sDayOfWeek) - dayName;
    
    dayOfMonth = stoi(sDayOfMonth);
    
    month = find(monthName, monthName + 12, sMonth) - monthName;
    
    year = stoi(sYear);
    if (sYear.length() == 2) year += 1900;
    
    hour = stoi(sTime.substr(0, 2));
    minute = stoi(sTime.substr(3, 2));
    second = stoi(sTime.substr(6, 2));
    
    if (sTimezone == "UT" || sTimezone == "GMT") diffMinute = 180;
    else if (sTimezone == "EDT") diffMinute = 420;
    else if (sTimezone == "CDT") diffMinute = 480;
    else if (sTimezone == "MDT") diffMinute = 540;
    else if (sTimezone == "PDT") diffMinute = 600;
    else
    {
        diffMinute = stoi(sTimezone.substr(1, 2)) * 60 + stoi(sTimezone.substr(3, 2));
        if (sTimezone.front() == '+')
            diffMinute = 180 - diffMinute;
        else
            diffMinute = 180 + diffMinute;
    }
    
    int totalMinute = hour * 60 + minute + diffMinute;
    if (totalMinute >= 0)
    {
        if (totalMinute >= 1440)
        {
            addDay(1);
            totalMinute -= 1440;
        }
    }
    else
    {
        addDay(-1);
        totalMinute += 1440;
    }

    hour = totalMinute / 60;
    minute = totalMinute % 60;
}

void print()
{
    cout << dayName[dayOfWeek] << ", ";
    cout << setfill('0') << setw(2) << dayOfMonth << ' ';
    cout << monthName[month] << ' ';
    cout << setfill('0') << setw(4) << year << ' ';
    cout << setfill('0') << setw(2) << hour << ':';
    cout << setfill('0') << setw(2) << minute << ':';
    cout << setfill('0') << setw(2) << second << ' ';
    cout << "+0300\n";
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    string line;
    while (getline(cin, line))
    {
        parse(line);
        print();
    }
    
    return 0;
}
