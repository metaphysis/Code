[UVa 512 Spreadsheet Tracking](https://blog.csdn.net/metaphysis/article/details/162054495)

## 题目描述

题目要求模拟电子表格在行/列的删除、插入和单元格内容交换操作后，追踪原始单元格中数据的最终位置。给定初始表格的行数 $r$ 和列数 $c$，以及一系列操作命令。随后给出若干查询，每个查询给出原始表格中的一个单元格坐标 $(r, c)$，需要输出该单元格中的数据最终移动到了哪个位置，若数据已被删除则输出 `GONE`。

## 输入格式

每个电子表格以一行两个整数 $r$ 和 $c$ 开始（$r, c \le 50$），接着一行一个整数 $n$（操作数）。接下来 $n$ 行，每行一个操作命令：
- `EX r1 c1 r2 c2`：交换单元格 $(r1, c1)$ 和 $(r2, c2)$ 的内容。
- `DR A x1 x2 ... xA`：删除行 $x1, x2, \ldots, xA$。
- `DC A x1 x2 ... xA`：删除列 $x1, x2, \ldots, xA$。
- `IR A x1 x2 ... xA`：在行 $x1, x2, \ldots, xA$ 之前各插入一个空行。
- `IC A x1 x2 ... xA`：在列 $x1, x2, \ldots, xA$ 之前各插入一个空列。
操作结束后，一行一个整数 $q$（查询数），接下来 $q$ 行每行两个整数 $r, c$，表示原始表格中的坐标。
输入以 $r=0, c=0$ 结束。

## 输出格式

对于每个电子表格，输出 `Spreadsheet #X`（$X$ 从 $1$ 开始）。对于每个查询，输出 `Cell data in (r,c) moved to (nr,nc)` 或 `Cell data in (r,c) GONE`。不同电子表格的输出之间用一个空行分隔。

## 样例

输入

```
7 9
5
DR 2 1 5
DC 4 3 6 7 9
IC 1 3
IR 2 2 4
EX 1 2 6 5
4
4 8
5 5
7 8
6 5
0 0
```

输出

```
Spreadsheet #1
Cell data in (4,8) moved to (4,6)
Cell data in (5,5) GONE
Cell data in (7,8) moved to (7,6)
Cell data in (6,5) moved to (1,2)
```

## 题目分析

本题的核心是跟踪每个原始单元格在操作后的位置变化。由于表格最大为 $50 \times 50$，可以直接模拟每个单元格的位置。

### 数据结构

使用二维数组 $\textit{grid}[i][j]$ 存储原始单元格 $(i, j)$ 的当前位置。初始时 $\textit{grid}[i][j] = (i, j)$。

### 操作实现

- **删除行/列**：对于要删除的行/列，将该行/列所有单元格的位置标记为 $(0,0)$（表示 `GONE`）。其他行/列根据删除的行/列数量调整位置。
- **插入行/列**：在指定行/列之前插入新行/列，原有行/列的位置向下/向右移动。
- **交换单元格**：交换两个单元格的位置信息。

### 删除操作的位置调整

对于删除操作，先将要删除的行/列排序，然后对于每个现有的单元格，计算其前方有多少被删除的行/列，从而得到新位置。也可以直接遍历所有单元格，若其行/列在删除列表中，则标记为 `GONE`；否则，新行号 = 原行号 - 前方删除数量。

### 插入操作的位置调整

对于插入操作，将要插入的行/列排序，然后对于每个单元格，新行号 = 原行号 + 前方插入数量。

### 复杂度分析

每次操作遍历整个表格 $O(r \times c)$，$r, c \le 50$，操作数有限，完全可接受。

## 代码实现

```cpp
// Spreadsheet Tracking
// UVa ID: 512
// Verdict: Accepted
// Submission Date: 2016-12-23
// UVa Run Time: 0.020s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int cases = 0;
    int r, c, n, A, q, originalR, originalC, nextR, nextC;
    int x[10], z[60];
    string command;
    pair<int, int> grid[60][60];

    while (cin >> r >> c, r > 0)
    {
        for (int i = 1; i <= r; i++)
            for (int j = 1; j <= c; j++)
                grid[i][j] = make_pair(i, j);
                
        cin >> n;
        for (int k = 1; k <= n; k++)
        {
            cin >> command;
            if (command == "DR" || command == "DC" || command == "IR" || command == "IC")
            {
                cin >> A;
                for (int i = 0; i < A; i++) cin >> x[i];

                sort(x, x + A);

                if (command == "DR" || command == "DC")
                {
                    for (int i = 1; i <= 50; i++)
                    {
                        if (binary_search(x, x + A, i))
                            z[i] = i;
                        else
                            z[i] = upper_bound(x, x + A, i) - x;
                    }

                    if (command == "DR")
                    {
                        for (int i = 1; i <= r; i++)
                            for (int j = 1; j <= c; j++)
                                if (grid[i][j].first > 0 && grid[i][j].second > 0)
                                    grid[i][j].first -= z[grid[i][j].first];
                    }
                    else
                    {
                        for (int i = 1; i <= r; i++)
                            for (int j = 1; j <= c; j++)
                                if (grid[i][j].first > 0 && grid[i][j].second > 0)
                                    grid[i][j].second -= z[grid[i][j].second];
                    }
                }
                else
                {
                    for (int i = 1; i <= 50; i++)
                        z[i] = upper_bound(x, x + A, i) - x;

                    if (command == "IR")
                    {
                        for (int i = 1; i <= r; i++)
                            for (int j = 1; j <= c; j++)
                                if (grid[i][j].first > 0 && grid[i][j].second > 0)
                                    grid[i][j].first += z[grid[i][j].first];
                    }
                    else
                    {
                        for (int i = 1; i <= r; i++)
                            for (int j = 1; j <= c; j++)
                                if (grid[i][j].first > 0 && grid[i][j].second > 0)
                                    grid[i][j].second += z[grid[i][j].second];
                    }
                }
            }
            else
            {
                cin >> originalR >> originalC >> nextR >> nextC;
                for (int i = 1; i <= r; i++)
                    for (int j = 1; j <= c; j++)
                    {
                        if (grid[i][j].first == originalR && grid[i][j].second == originalC)
                            grid[i][j] = make_pair(nextR, nextC);
                        else if (grid[i][j].first == nextR && grid[i][j].second == nextC)
                            grid[i][j] = make_pair(originalR, originalC);
                    }
            }
        }
        
        if (cases > 0) cout << '\n';
        cout << "Spreadsheet #" << ++cases << '\n';
                
        cin >> q;
        for (int k = 1; k <= q; k++)
        {
            cin >> r >> c;
            
            cout << "Cell data in (" << r << ',' << c << ") ";
            if (grid[r][c].first > 0 && grid[r][c].second > 0)
            {
                cout << "moved to (";
                cout << grid[r][c].first << ',' << grid[r][c].second << ")\n";
            }
            else
                cout << "GONE\n";
        }
    }
    
    return 0;
}
```
