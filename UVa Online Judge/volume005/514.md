## 题目描述

题目要求判断给定的出站顺序是否可以通过一个栈（即站台）实现。初始时，列车从 $A$ 方向驶来，车厢编号为 $1, 2, \ldots, N$（按顺序）。列车可以进入站台（栈）暂存，也可以直接从 $A$ 到 $B$ 而不进站。站台是单轨道，后进先出。需要判断是否能得到指定的出站顺序。

## 输入格式

输入包含多个数据块。每个数据块的第一行是一个整数 $N$（$1 \le N \le 1000$），表示车厢数量。接下来若干行，每行是一个 $1$ 到 $N$ 的排列，表示目标出站顺序。每个数据块以一行 `0` 结束。最后一个数据块以一行 `0` 结束。

## 输出格式

对于每个目标顺序，输出一行 `Yes` 或 `No`。每个数据块的输出后跟一个空行。

## 样例

输入

```
5
1 2 3 4 5
5 4 1 2 3
0
6
6 5 4 3 2 1
0
0
```

输出

```
Yes
No

Yes
```

## 题目分析

本题的核心是模拟栈的入栈和出栈过程。初始时，车厢按顺序从 $1$ 到 $N$ 依次到达。需要判断是否能通过栈操作得到目标序列。

### 算法

- 维护一个栈，表示站台中的车厢。
- 维护一个变量 $\textit{current}$，表示下一个可入栈的车厢编号（从 $1$ 开始）。
- 遍历目标序列中的每个车厢 $t$：
  - 若 $\textit{current} \le t$，则将 $\textit{current}$ 到 $t$ 的车厢依次压入栈，然后 $\textit{current}$ 更新为 $t+1$，最后弹出栈顶（即 $t$）。
  - 若栈非空且栈顶等于 $t$，则弹出栈顶。
  - 否则，无法得到该序列，输出 `No`。
- 若成功处理完所有车厢，输出 `Yes`。

### 复杂度分析

每个车厢最多入栈一次、出栈一次，时间复杂度 $O(N)$。

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    string line;
    while (getline(cin, line), line != "0")
    {
        int n = stoi(line);
        while (getline(cin, line), line != "0")
        {
            int number, current = 1;
            stack<int> rails;
            istringstream iss(line);
            
            bool yes = true;
            while (iss >> number)
            {
                if (number == current)
                {
                    current++;
                }
                else if (rails.empty() == false && number == rails.top())
                {
                    rails.pop();
                }
                else if (number > current)
                {
                    while (current < number)
                    {
                        rails.push(current);
                        current++;
                    }
                    current++;
                }
                else
                {
                    yes = false;
                    break; 
                }
            }
            
            cout << (yes ? "Yes\n" : "No\n");
        }
        cout << '\n';
    }
    
    return 0;
}
