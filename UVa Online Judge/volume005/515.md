## 题目描述

题目要求判断是否存在一个长度为 $n$ 的整数序列 $S = \{a_1, a_2, \ldots, a_n\}$，满足 $m$ 个约束条件。每个约束条件给出一个子序列的和与一个整数 $k_i$ 的比较关系（大于或小于）。需要判断是否存在这样的序列。

## 输入格式

输入包含多个数据块。每个数据块的第一行包含两个整数 $n$ 和 $m$（$0 < n, m \le 100$）。接下来 $m$ 行，每行格式为 `s_i n_i o_i k_i`，其中 `o_i` 为 `gt`（$>$）或 `lt`（$<$）。`s_i` 为子序列的起始位置（从 $1$ 开始），`n_i$ 为子序列的长度，`k_i$ 为比较的整数。输入以一行 `0` 结束。

## 输出格式

对于每个数据块，若存在满足条件的序列，输出 `lamentable kingdom`；否则输出 `successful conspiracy`。

## 样例

输入

```
4 2
1 2 gt 0
2 2 lt 2
1 2
1 0 gt 0
1 0 lt 0
0
```

输出

```
lamentable kingdom
successful conspiracy
```

## 题目分析

本题的核心是判断差分约束系统是否有解。每个约束条件可以转化为关于前缀和的不等式。

### 前缀和表示

设前缀和 $S_i = a_1 + a_2 + \dots + a_i$，且 $S_0 = 0$。则子序列 $a_{s_i} + a_{s_i + 1} + \dots + a_{s_i + n_i}$ 的和为 $S_{s_i + n_i} - S_{s_i - 1}$。

### 转化为差分约束

- 若 $S_{s_i + n_i} - S_{s_i - 1} > k_i$，则 $S_{s_i + n_i} - S_{s_i - 1} \ge k_i + 1$，即 $S_{s_i - 1} \le S_{s_i + n_i} - (k_i + 1)$。
- 若 $S_{s_i + n_i} - S_{s_i - 1} < k_i$，则 $S_{s_i + n_i} - S_{s_i - 1} \le k_i - 1$，即 $S_{s_i + n_i} \le S_{s_i - 1} + (k_i - 1)$。

这两种形式都可以写成 $x_u - x_v \le w$ 的形式，即差分约束的标准形式。使用 $\texttt{Bellman-Ford}$ 算法判断是否存在负环即可。

### 算法

1. 建立图，节点为 $0$ 到 $n$（共 $n+1$ 个前缀和节点）。
2. 对于每个约束，添加对应的有向边。
3. 添加虚拟源点 $0$ 到所有节点的边，权值为 $0$。
4. 运行 $\texttt{Bellman-Ford}$ 算法，若 $n+1$ 次松弛后仍有更新，则存在负环，即无解；否则有解。

### 复杂度分析

节点数 $n+2 \le 102$，边数 $m + n + 1 \le 201$，$\texttt{Bellman-Ford}$ 复杂度 $O((n+m) \times n)$，可接受。

## 代码实现

```cpp
// King
// UVa ID: 515
// Verdict: Accepted
// Submission Date: 2017-04-28
// UVa Run Time: 0.040s
//
// 版权所有（C）2017，邱秋。metaphysis # yeah dot net
//
// System of difference constraints, Bellman-Ford algorithm.
//

#include <bits/stdc++.h>

using namespace std;

struct edge
{
    int u, v, weight;
};

edge edges[1024];
int nedges, dist[1024], n, m, si, ni, ki;
string oi;

void addEdge(int u, int v, int weight) { edges[nedges++] = edge{ u, v, weight }; }

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    while (cin >> n, n > 0)
    {
        cin >> m;

        nedges = 0;
        for (int i = 1; i <= m; i++)
        {
            cin >> si >> ni >> oi >> ki;

            if (oi.front() == 'g')
                addEdge(si + ni + 1, si, -ki - 1);
            else
                addEdge(si, si + ni + 1, ki - 1);
        }

        n += 2;
        for (int i = 1; i < n; i++)
            addEdge(0, i, 0);

        dist[0] = 0;
        for (int i = 1; i < n; i++)
            dist[i] = (1 << 30);

        int iterations = 0, updated = 0;
        do
        {
            updated = 0;
            for (int i = 0; i < nedges; i++)
            {
                int weight = dist[edges[i].u] + edges[i].weight;
                if (dist[edges[i].v] > weight)
                    updated++, dist[edges[i].v] = weight;
            }
        }
        while (updated && iterations++ < n);

        cout << (updated ? "successful conspiracy\n" : "lamentable kingdom\n");
    }

    return 0;
}
```
