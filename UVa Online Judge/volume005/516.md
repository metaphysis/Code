## 题目描述

题目定义了一种质数进制表示法：每个大于 $1$ 的整数 $x$ 可以唯一表示为质数幂的乘积形式：
$$
x = p_0^{e_0} \cdot p_1^{e_1} \cdots p_k^{e_k}
$$
其中 $p_0 < p_1 < \cdots < p_k$ 为质数，$e_i \ge 1$。输入给出若干行，每行是某个正整数 $x$（$2 < x \le 32767$）的质数进制表示（按 $p_i$ 递减顺序，每对 $p_i$ 和 $e_i$ 用空格分隔）。对于每个 $x$，输出 $x-1$ 的质数进制表示（同样按 $p_i$ 递减顺序）。输入以一行 `0` 结束。

## 输入格式

输入包含多行，每行若干个整数，表示 $p_i$ 和 $e_i$ 交替出现（$p_i$ 递减）。最后一行是 `0`。

## 输出格式

对于每个非零输入行，输出一行，表示 $x-1$ 的质数进制表示，格式与输入相同（$p_i$ 递减，每对之间用空格分隔）。

## 样例

输入

```
17 1
5 1 2 1
509 1 59 1
0
```

输出

```
2 4 3 2
13 1 11 1 7 1 5 1 3 1 2 1
```

## 题目分析

本题的核心是计算给定质数幂乘积表示的数减去 $1$ 后的质因数分解。

### 算法步骤

1. 从输入读取 $p_i$ 和 $e_i$，计算 $x = \prod p_i^{e_i}$。
2. 计算 $y = x - 1$。
3. 对 $y$ 进行质因数分解，得到质数及其指数。
4. 按质数降序输出。

### 注意事项

- $x$ 最大为 $32767$，可以直接使用整型计算。
- 质因数分解时，从 $2$ 开始遍历质数，直到 $\sqrt{y}$ 或 $y$ 变为 $1$。
- 输出时按质数降序排列。

### 复杂度分析

每组数据 $O(\sqrt{x})$ 分解，可接受。

```cpp
// Prime Land

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAX_N = 33000;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);

    int primes[MAX_N + 1] = { 0 }, prime_count = 0, factors[16][2], factor_count;
    
    primes[prime_count++] = 2;
    for (int i = 3; i <= MAX_N; i += 2)
        if (primes[i] == 0)
        {
            for (int j = 2 * i; j <= MAX_N; j += i)
                primes[j] = -1;
            primes[prime_count++] = i;
        }

    string line;
    while (getline(cin, line), line != "0")
    {
        int n = 1, p, e;
        
        istringstream iss(line);
        while (iss >> p >> e)
            n *= pow(p, e);

        n--;
        factor_count = 0;
        memset(factors, 0, sizeof(factors));

        for (int i = 0; i < prime_count && n > 1; i++)
        {
            if (n % primes[i] == 0)
            {
                factors[factor_count][0] = primes[i];
                factors[factor_count][1] = 1;
                n /= primes[i];
                
                while (n > 1 && n % primes[i] == 0)
                {
                    factors[factor_count][1]++;
                    n /= primes[i];
                }
                
                factor_count++;
            }
        }
        
        cout << factors[factor_count - 1][0] << ' ' << factors[factor_count - 1][1];
        for (int i = factor_count - 2; i >= 0; i--)
            cout << ' ' << factors[i][0] << ' ' << factors[i][1];
        cout << '\n';
    }
    
    return 0;
}
```
