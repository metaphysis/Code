## 题目描述

题目要求模拟一个长度为 $n$ 的循环单词的演化过程。单词由字母 `a` 和 `b` 组成，循环意味着首尾相邻。每个位置 $i$ 的下一状态由该位置及其左右邻居（位置 $i-2$、$i$、$i+1$）的当前字母共同决定，共有 $2^3 = 8$ 种可能组合，每种组合对应一个输出字母（`a` 或 `b`）。给定初始单词和演化步数 $s$（$s$ 可达 $2 \times 10^9$），输出经过 $s$ 步后字典序最小的循环等价单词。

## 输入格式

每个数据块包含：
- 第一行：整数 $n$（$2 < n < 16$）。
- 第二行：长度为 $n$ 的字符串，由 `a` 和 `b` 组成。
- 接下来 $8$ 行：每行一个长度为 $4$ 的字符串 $c_1c_2c_3c_4$，表示规则：若模式 $c_1c_2c_3$ 匹配，则输出 $c_4$。
- 最后一行：整数 $s$（$0 \le s \le 2 \times 10^9$）。
输入以文件结束符（$\texttt{EOF}$）终止。

## 输出格式

对于每个数据块，输出一行，即 $s$ 步后字典序最小的循环等价单词。

## 样例

输入

```
5
aaaaa
aaaa
aaab
aabb
abab
abbb
baab
bbab
bbbb
1
```

输出

```
bbbbb
```

## 题目分析

本题的核心是模拟循环单词的演化，并利用状态循环加速。

### 状态表示

由于 $n < 16$，每个单词可以用一个 $16$ 位整数表示（$0$ 表示 `a`，$1$ 表示 `b`）。总状态数最多 $2^{16} = 65536$，可以存储。

### 演化规则

对于每个位置 $i$，需要获取三个位置的字母：$i-2$、$i$、$i+1$（模 $n$）。这三个位组成一个 $3$ 位二进制数 $k$，然后根据规则表 $\textit{rules}[k]$ 得到新位。所有位置同时更新。

### 循环检测

由于状态数有限，经过一定步数后必然进入循环。使用数组 $\textit{steps}[state]$ 记录每个状态首次出现的步数。模拟过程中：
- 若当前状态已出现过，则进入循环，可直接计算出 $s$ 步后的状态。
- 否则，继续模拟。

### 输出

最终状态表示为二进制字符串，生成所有循环移位，取字典序最小的输出（`a` < `b`）。

### 复杂度分析

预处理规则 $O(1)$，模拟最多 $65536$ 步，之后查询 $O(1)$，可接受。

## 代码实现

```cpp
// Word
// UVa ID: 517
// Verdict: Accepted
// Submission Date: 2016-12-24
// UVa Run Time: 0.000s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 1 << 16;

int rules[8], steps[MAXN], indexer[MAXN];

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    
    int n, s;
    string word, rule;
    
    while (cin >> n)
    {
        cin >> word;

        int w = 0;
        for (int i = 0; i < word.length(); i++)
        {
            w *= 2;
            if (word[i] == 'b') w++;
        }
        
        for (int i = 1; i <= 8; i++)
        {
            cin >> rule;

            int r = 0;
            for (int j = 0; j < rule.length() - 1; j++)
            {
                r *= 2;
                if (rule[j] == 'b') r++;
            }
            rules[r] = rule.back() - 'a';
        }

        cin >> s;

        memset(steps, -1, sizeof(steps));
        
        for (int i = 0; i < s; i++)
        {
            if (steps[w] >= 0)
            {
                int t = (s - i) % (i - steps[w]);
                w = indexer[steps[w] + t];
                break;
            }
            else
            {
                steps[w] = i;
                indexer[i] = w;
                
                int ww = 0;
                for (int j = 0; j < n; j++)
                {
                    int k = 0;
                    if ((1 << (j + 2) % n) & w) k += 4;
                    if ((1 << j) & w) k += 2;
                    if ((1 << ((j - 1 + n) % n)) & w) k += 1;
                    ww |= (rules[k] << j);
                }
                w = ww;
            }
        }
        
        word = bitset<16>(w).to_string().substr(16 - n);

        set<string> words;
        string wordword = word + word;
        for (int i = 0; i < word.length(); i++)
            words.insert(wordword.substr(i, word.length()));

        word = *(words.begin());
        for (int i = 0; i < word.length(); i++)
        {
            if (word[i] == '0') cout << 'a';
            else cout << 'b';
        }
        cout << '\n';
    }
    
    return 0;
}
```
