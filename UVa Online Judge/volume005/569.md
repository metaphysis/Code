## 题目描述

马蹄铁游戏是将马蹄铁投向地面上的桩子。每 $4$ 次投掷构成一个“回合”（$\texttt{turn}$）。计分规则如下：

- **套中（$\texttt{ringer}$）** ：如果桩子的中心位于马蹄铁内部区域（由半圆弧和连接两脚的直线围成），且马蹄铁不接触桩子，得 $5$ 分。
- **触碰到（$\texttt{toucher}$）** ：如果马蹄铁的任何部分接触到桩子，得 $2$ 分。
- **摆荡（$\texttt{swinger}$）** ：如果不是套中也不是触碰到，但将马蹄铁绕其弧中点 $B$ 旋转时会有部分碰到桩子，得 $1$ 分。
- **其他情况**：得 $0$ 分。

**马蹄铁模型**：数学上的半圆，半径 $R = 10$ 厘米。位置由两个点定义：
- 点 $A$：半圆的圆心
- 点 $B$：半圆弧的中点（即从 $A$ 到 $B$ 是半径方向）

**桩子**：位于坐标 $(0,0)$，直径 $2$ 厘米，即桩子区域是以 $(0,0)$ 为圆心、半径 $r = 1$ 厘米的圆盘。

**输入**：多个回合，每个回合 $4$ 次投掷。每次投掷一行，每行四个浮点数：$A$ 的 $(X,Y)$，$B$ 的 $(X,Y)$。保证 $|AB| = 10 \pm 0.000001$ 厘米。最多 $9999$ 回合。

**输出**：第一行 `"Turn Score"`，然后每回合一行：回合号（右对齐占 $4$ 列）、一个空格（占 $5 \sim 8$ 列）、得分（右对齐占 $9 \sim 10$ 列，$0 \sim 9$ 分时前面有一个空格）。

## 解题思路

### 第一步：建立坐标系

我们定义：
- 桩心 $O = (0,0)$
- 马蹄铁圆心 $A = (a_x, a_y)$
- 马蹄铁弧中点 $B = (b_x, b_y)$
- 半径 $R = 10$，桩半径 $r = 1$

题目保证 $|AB| = R$（在误差范围内）。

### 第二步：坐标变换

直接在半圆区域上做几何判断比较繁琐。一个巧妙的思路是建立以 $A$ 为原点、$AB$ 为基准的局部坐标系。

令向量 $\vec{AB} = (b_x - a_x,\ b_y - a_y)$，长度为 $R$。

对于桩心 $O$，它在局部坐标系中的坐标可以通过以下方式计算：

将 $O$ 视为在 $AB$ 方向上的投影和垂直方向上的偏移。具体地，设：
- 沿 $AB$ 方向的投影长度：$p_y = \frac{\vec{AO} \cdot \vec{AB}}{R}$
- 垂直 $AB$ 方向的偏移长度：$p_x = \frac{|\vec{AO} \times \vec{AB}|}{R}$

这里 $\times$ 表示二维叉积（有正负，取绝对值后表示距离）。经过推导，可以得到：
$$p_x = -\frac{(b_y - a_y) a_x - (b_x - a_x) a_y}{R}$$
$$p_y = -\frac{(b_x - a_x) a_x + (b_y - a_y) a_y}{R}$$

变换后的 $(p_x, p_y)$ 具有清晰的几何意义：
- $p_y$ 表示 $O$ 在 $AB$ 方向上的投影（从 $A$ 指向 $B$ 为正方向）
- $p_x$ 表示 $O$ 到直线 $AB$ 的垂直距离（取正值）

这样，原始的半圆问题就转化为：圆心在 $(0,0)$、半径为 $R$ 的半圆，开口朝向 $+y$ 方向（即半圆区域为 $\{(x,y) \mid x^2 + y^2 \le R^2,\ y \ge 0\}$），而桩心 $O$ 在局部坐标系中的位置为 $(p_x, p_y)$。

### 第三步：判断“套中”（$\texttt{ringer}$）

套中条件：
1. 桩心在半圆内部：$p_x^2 + p_y^2 < R^2$ 且 $p_y \ge 0$
2. 马蹄铁不接触桩子：桩子圆盘与半圆区域无交集

由于桩子半径为 $1$，桩心在半圆内部时，要保证马蹄铁不接触桩子，等价于桩心到 $A$ 的距离大于 $1$（否则桩心本身就在桩子圆内，必然接触）。同时还要考虑边界情况，但经过坐标变换，条件简化为：
$$p_x^2 + p_y^2 < (R - 1)^2 = 9^2 = 81$$

因为如果桩心到 $A$ 的距离小于 $R-1$，那么以 $O$ 为圆心、半径为 $1$ 的圆盘一定完全落在半径为 $R$ 的大圆盘内部，且由于 $p_y \ge 0$，它也在半圆内部，所以不会接触边界。反之，如果距离在 $[R-1, R)$ 之间，则可能接触桩子，此时应判为触碰到而非套中。

所以套中判断为：
$$p_y \ge 0 \ \text{且} \ p_x^2 + p_y^2 < (R-1)^2$$

### 第四步：判断“触碰到”（$\texttt{toucher}$）

触碰到条件：马蹄铁的任何部分与桩子圆盘（半径为 $1$）相交。这包括两种情况：

**情况一**：桩心在半圆开口侧（$p_y \ge 0$）且桩心到 $A$ 的距离小于 $R+1$（即两个圆盘相交）：
$$p_x^2 + p_y^2 < (R+1)^2$$

**情况二**：桩心在半圆背侧（$p_y < 0$），但马蹄铁的“脚尖”（半圆底部，即局部坐标系中的 $(0,0)$ 点？不对，半圆底部是 $A$ 点？需要仔细分析）

当 $p_y < 0$ 时，桩心不在半圆内，但马蹄铁的直径端点（即 $A$ 点）可能靠近桩子。此时需要检查马蹄铁的直径线段（局部坐标系中从 $(-R,0)$ 到 $(R,0)$）是否与桩子圆盘相交。由于对称性，我们检查 $A$ 点（即局部原点）到桩心的距离：
$$(p_x - R)^2 + p_y^2 < 1^2$$

为什么是 $p_x - R$？因为在局部坐标系中，$A$ 对应的坐标是 $(0,0)$ 吗？不对——经过变换后，$A$ 是局部坐标系的原点，所以 $A$ 的坐标是 $(0,0)$，$B$ 的坐标是 $(0,R)$（因为 $AB$ 沿 $+y$ 方向，长度为 $R$）。那么直径的两个端点是 $(\pm R, 0)$。桩心在局部坐标为 $(p_x, p_y)$，它到直径端点的距离：
- 到 $(R,0)$ 的距离平方：$(p_x - R)^2 + p_y^2$
- 到 $(-R,0)$ 的距离平方：$(p_x + R)^2 + p_y^2$

由于 $p_x$ 已取绝对值（对称性），我们只需检查到 $(R,0)$ 的距离即可。如果这个距离小于 $1$，说明直径端点与桩子圆盘相交，即为触碰到。

所以触碰到判断为：
- 若 $p_y \ge 0$ 且 $p_x^2 + p_y^2 < (R+1)^2$，得 $2$ 分
- 否则若 $(p_x - R)^2 + p_y^2 < 1$，也得 $2$ 分

### 第五步：判断“摆荡”（$\texttt{swinger}$）

摆荡条件：既不是套中也不是触碰到，但将马蹄铁绕 $B$ 点旋转时会碰到桩子。

绕 $B$ 点旋转时，$B$ 固定，半圆作为一个刚体旋转。在局部坐标系中，$B = (0,R)$。旋转过程中，半圆上任意一点到 $B$ 的距离保持不变。半圆上离 $B$ 最远的点是直径的另一端，距离为 $2R = 20$。但更重要的是，旋转时半圆的“有效覆盖区域”是：对于任意一个点 $P$，如果存在某个旋转角度使得 $P$ 在半圆内，则 $P$ 到 $B$ 的距离满足一定条件。

一个经典的结论是：在局部坐标系中，判断桩心 $O = (p_x, p_y)$ 是否可以通过旋转 $B$ 被半圆覆盖，等价于检查点 $(p_x, p_y - R)$ 到原点的距离是否小于等于某个阈值。这是因为旋转相当于改变 $A$ 的位置，而 $A$ 的轨迹是以 $B$ 为圆心、半径为 $R$ 的圆。通过几何推导，可得到判断条件：
$$p_x^2 + (p_y - R)^2 \le (R\sqrt{2} + 1)^2$$

其中 $R\sqrt{2}$ 是半圆上某特殊点到 $B$ 的距离，加上 $1$ 是考虑桩子半径。

因此，摆荡判断为：
$$p_x^2 + (p_y - R)^2 \le (R\sqrt{2} + 1)^2$$

注意：这个判断需要在前两个条件都不满足的情况下执行。

### 第六步：完整计分逻辑

综合以上分析，单次投掷的得分流程：

```
得分 = 0
若 p_y >= 0:
    若 p_x^2 + p_y^2 < (R-1)^2:
        得分 += 5
    否则若 p_x^2 + p_y^2 < (R+1)^2:
        得分 += 2
    否则:
        若 p_x^2 + (p_y-R)^2 <= (R*sqrt(2)+1)^2:
            得分 += 1
否则（p_y < 0）:
    若 (p_x-R)^2 + p_y^2 < 1:
        得分 += 2
    否则:
        若 p_x^2 + (p_y-R)^2 <= (R*sqrt(2)+1)^2:
            得分 += 1
```

### 第七步：输出格式

- 第一行输出 `"Turn Score"`
- 每 $4$ 次投掷为一个回合，回合号从 $1$ 开始
- 使用 `printf("%4d%6d\n", turnNum, turnScore)` 实现右对齐

## 代码实现

```cpp
// Horse Shoe Scoring
// UVa ID: 569
// Verdict: Accepted
// Submission Date: 2026-05-16
// UVa Run Time: 0.060s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double R = 10.0;   // 马蹄铁半径

// 计算单次投掷得分
int scoreOneToss(double ax, double ay, double bx, double by) {
    // 坐标变换：将B点平移到A点
    bx -= ax;
    by -= ay;
    // 计算桩心在局部坐标系中的坐标 (px, py)
    double px = -(by * ax - bx * ay) / R;
    double py = -(bx * ax + by * ay) / R;
    // 垂直距离取正值（对称性）
    if (px < 0) px = -px;
    
    int score = 0;
    
    // 桩心在半圆开口侧
    if (py >= 0) {
        double d = px * px + py * py;   // 桩心到A距离的平方
        // 套中：距离平方 < (R-1)^2 = 81
        if (d < pow(R - 1, 2)) {
            score += 5;
        }
        // 触碰到：距离平方 < (R+1)^2 = 121
        else if (d < pow(R + 1, 2)) {
            score += 2;
        }
        // 摆荡：检查旋转后能否碰到
        else {
            d = px * px + (py - R) * (py - R);
            if (d <= pow(R * sqrt(2) + 1, 2)) {
                score += 1;
            }
        }
    }
    // 桩心在半圆背侧
    else {
        // 检查直径端点是否碰到桩子
        double d = (px - R) * (px - R) + py * py;
        if (d < 1) {
            score += 2;
        }
        // 摆荡
        else {
            d = px * px + (py - R) * (py - R);
            if (d <= pow(R * sqrt(2) + 1, 2)) {
                score += 1;
            }
        }
    }
    return score;
}

int main() {
    double ax, ay, bx, by;
    vector<int> scores;   // 存储每次投掷得分
    
    // 读取所有投掷
    while (cin >> ax >> ay >> bx >> by) {
        scores.push_back(scoreOneToss(ax, ay, bx, by));
    }
    
    // 输出表头
    cout << "Turn Score" << endl;
    
    // 每4次投掷为一个回合
    for (int i = 0; i < (int)scores.size(); i += 4) {
        int turnScore = scores[i] + scores[i + 1] + scores[i + 2] + scores[i + 3];
        // 格式：回合号占4列，得分占6列（自动右对齐）
        printf("%4d%6d\n", i / 4 + 1, turnScore);
    }
    
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为投掷次数，每次投掷仅进行常数次浮点运算。
- **空间复杂度**：$O(n)$，用于存储所有投掷得分（最多 $4 \times 9999 = 39996$ 次投掷，可以接受）。也可优化为 $O(1)$ 空间，边读边累加每回合得分。

## 注意事项

1. **精度处理**：由于输入保证 $|AB| = 10 \pm 0.000001$，且浮点运算误差较小，代码中直接使用 `<` 和 `<=` 比较，未额外添加 $\texttt{EPS}$，实测可通过。
2. **平方代替开方**：代码中全部使用平方距离进行比较，避免了开方运算，提高了效率和精度。
3. **对称性利用**：$p_x$ 取绝对值利用了半圆左右对称的特性，简化了判断。
