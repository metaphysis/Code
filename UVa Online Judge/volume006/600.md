[UVa 600 A Duckpin Tournament](https://blog.csdn.net/metaphysis/article/details/155169366)

## 题目描述

在鸭柱保龄球锦标赛中，选手通过参加多场比赛获得锦标赛积分，积分最高的选手获胜。比赛由三局游戏组成，选手通过赢得比赛和在比赛中获得最高单局得分来获得积分。

### 比赛规则

- 每局游戏分为 $10$ 轮
- 每轮有三次尝试机会击倒 $10$ 个瓶柱
- **全中**：第一次尝试击倒所有 $10$ 个瓶柱，该轮结束
- **补中**：两次尝试击倒所有 $10$ 个瓶柱，该轮结束  
- **犯规**：选手越过犯规线，该轮结束，只计算犯规前击倒的瓶柱
- **奖励分**：
  - 补中：加上下一次尝试击倒的瓶柱数
  - 全中：加上后两次尝试击倒的瓶柱数
- **第 $10$ 轮特殊规则**：如果获得全中或补中，选手可以立即进行额外的尝试来获得奖励分

### 输入格式

输入包含多场比赛数据，每场比赛包括：
- 选手数量 $n$ ($1 \leq n \leq 4$)
- $n$ 个选手姓名（每个姓名最多 $10$ 个字母字符）
- 每位选手每局游戏的三行投掷数据：
  - 第一行：$10$-$12$ 个整数，表示第一次尝试
  - 第二行：不定数量的整数，表示第二次尝试
  - 第三行：不定数量的整数，表示第三次尝试
- 比赛以 `#` 结束
- 输入以选手数量为 $0$ 结束

### 输出格式

输出每位选手每局游戏的逐轮得分：
- 选手姓名：左对齐，宽度 $10$ 字符
- $10$ 个轮次得分：右对齐，宽度 $4$ 字符
- 比赛结束后输出系列总分最高者和单局最高分者

## 解题思路

### 问题分析

本题的核心难点在于处理**非对齐的输入数据**和**复杂的计分规则**：

1. **输入数据不对齐**：第二次和第三次尝试的数据行可能少于 $10$ 个数字，需要通过保龄球规则推断哪些轮需要这些尝试
2. **计分规则复杂**：需要正确处理全中、补中、犯规、奖励分以及第 $10$ 轮的特殊情况
3. **数据量大**：每位选手每局游戏有 $3$ 行数据，需要高效处理

### 关键洞察

发现一个巧妙的解决方案：**使用特殊标记统一处理三行数据**。这种方法避免了复杂的索引计算和对齐问题。

### 算法设计

#### 1. 数据预处理

将每局游戏的三行数据用特殊标记 `" Q "` 连接成一个字符串：

```cpp
stringstream combined(line1 + " Q " + line2 + " Q " + line3);
```

这样可以将三次尝试的数据统一处理，通过特殊标记区分不同的尝试类型。

#### 2. 投掷记录构建

使用四元组记录每个投掷的完整信息：
```cpp
vector<tuple<int, int, int, int>> throws; // (frame, attempt, score, totalPins)
```

其中：
- `frame`：轮次（$0$-索引）
- `attempt`：尝试类型（$1$=第一次，$2$=第二次，$3$=第三次）
- `score`：本次击倒的瓶柱数（负值表示犯规）
- `totalPins`：该轮累计击倒的瓶柱数

#### 3. 智能帧分配

通过维护 `framePins` 数组来跟踪每轮的累计击倒数：
```cpp
while (framePins[currentFrame] == 10) currentFrame++;
```

当某轮累计击倒数达到 $10$（全中或补中）时，自动跳过该轮，继续处理下一轮。

#### 4. 计分计算

分为两个阶段：

**阶段一：基础分计算**
```cpp
if (scoreVal >= 0) frameScores[frame] += scoreVal;
```

只累加非负的得分，犯规的负分不计入基础分。

**阶段二：奖励分计算**
```cpp
if (scoreVal >= 0 && totalPins == 10) {
    if (attempt == 1) bonusAttempts = 2; // 全中
    else if (attempt == 2) bonusAttempts = 1; // 补中
}
```

根据投掷类型确定奖励次数，然后累加后续投掷的得分。

#### 5. 累计得分

最后计算每轮的累计得分：
```cpp
for (int i = 1; i < 10; i++) 
    frameScores[i] += frameScores[i - 1];
```

### 复杂度分析

- **时间复杂度**：$O(n \times m)$，其中 $n$ 是选手数量，$m$ 是投掷次数
- **空间复杂度**：$O(n + m)$，存储选手信息和投掷记录

### 代码实现

```cpp
// A Duckpin Tournament
// UVa ID: 600
// Verdict: Accepted
// Submission Date: 2025-11-23
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Player {
    string name;
    int totalScore = 0;
    int maxGameScore = 0;
};

vector<int> calculateGame(const string& line1, const string& line2, const string& line3) {
    stringstream combined(line1 + " Q " + line2 + " Q " + line3);
    vector<int> frameScores(10, 0), framePins(12, 0);
    vector<tuple<int, int, int, int>> throws; // (frame, attempt, score, totalPins)
    int currentFrame = 0, attemptType = 1;
    string token;
    while (combined >> token) {
        if (token == "Q") {
            attemptType++;
            currentFrame = 0;
            continue;
        }
        int score = stoi(token);
        // 跳过已经完成（全中/补中）的frame
        while (framePins[currentFrame] == 10) currentFrame++;
        // 更新frame的累计击倒数
        if (score < 0) framePins[currentFrame] = 10; // 犯规视为完成该frame
        else framePins[currentFrame] += score;
        throws.emplace_back(currentFrame, attemptType, score, framePins[currentFrame]);
        currentFrame++;
    }
    // 按frame排序投掷记录
    sort(throws.begin(), throws.end());
    // 计算每个frame的得分
    for (int i = 0; i < throws.size(); i++) {
        auto [frame, attempt, scoreVal, totalPins] = throws[i];
        if (frame >= 10) break; // 只处理前10个frame
        // 基础分（只计算正分）
        if (scoreVal >= 0) frameScores[frame] += scoreVal;
        // 计算奖励分
        int bonusAttempts = 0;
        if (scoreVal >= 0 && totalPins == 10) {
            if (attempt == 1) bonusAttempts = 2; // 第一次尝试全中
            else if (attempt == 2) bonusAttempts = 1; // 第二次尝试补中
        }
        // 添加奖励分
        for (int j = 1; j <= bonusAttempts; j++) {
            auto [nextFrame, nextAttempt, nextScore, nextTotal] = throws[i + j];
            if (nextScore >= 0) frameScores[frame] += nextScore;
            else break; // 遇到犯规停止奖励
        }
    }
    // 计算累计得分
    for (int i = 1; i < 10; i++) frameScores[i] += frameScores[i - 1];
    return frameScores;
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int n;
    while (cin >> n && n != 0) {
        vector<Player> players(n);
        for (int i = 0; i < n; i++) cin >> players[i].name;
        cin.ignore(128, '\n');
        vector<string> data;
        string line;
        // 读取所有比赛数据
        while (getline(cin, line)) {
            if (line.find('#') != string::npos) break;
            data.push_back(line);
        }
        // 处理每个选手的每局比赛
        for (int i = 0; i < data.size(); i += 3) {
            int playerIndex = (i / 3) % n;
            vector<int> scores = calculateGame(data[i], data[i + 1], data[i + 2]);
            // 格式化输出
            cout << left << setw(10) << players[playerIndex].name;
            for (int score : scores) cout << right << setw(4) << score;
            cout << endl;
            // 更新选手统计
            int gameScore = scores.back();
            players[playerIndex].totalScore += gameScore;
            players[playerIndex].maxGameScore = max(players[playerIndex].maxGameScore, gameScore);
        }
        // 确定获胜者
        int bestSeries = 0, bestGame = 0;
        string seriesWinner, gameWinner;
        for (const auto& player : players) {
            if (player.totalScore > bestSeries) {
                bestSeries = player.totalScore;
                seriesWinner = player.name;
            }
            if (player.maxGameScore > bestGame) {
                bestGame = player.maxGameScore;
                gameWinner = player.name;
            }
        }
        cout << seriesWinner << " has the high series score of " << bestSeries << "." << '\n';
        cout << gameWinner << " has the high game score of " << bestGame << "." << '\n';
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题的难点主要在于处理非规范的输入格式和实现复杂的保龄球计分规则。通过使用特殊标记统一处理数据、维护投掷记录四元组、以及智能的帧分配机制，我们能够优雅地解决这些问题。这种方法的优势在于避免了复杂的索引计算，使代码更加清晰和健壮。
