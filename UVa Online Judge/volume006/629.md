## 题目分析

本题要求我们根据给定的样本差异矩阵，划分出所有**极大无差异样本集合**。 所谓“无差异”是指两个样本之间没有显著差异（用 `-` 表示）；而“极大”是指这个集合不能再加入任何其他样本而仍然保持无差异性质。

**关键点理解**：
- 样本数量 $n \leq 10$，因此可以使用暴力枚举所有子集的方法。
- 矩阵只使用上三角部分，但关系是对称的。
- 每个样本可能属于多个极大无差异集合。
- 输出时，需要按规则为每个集合分配字母标识符，并为每个样本输出其所属的所有集合的标识符。

**问题本质**：
如果将样本看作图中的顶点，两个样本之间若无差异则在它们之间连一条边，那么：
- 一个“无差异集合”对应图中的一个**团**（$\texttt{clique}$），即任意两点之间都有边。
- 一个“极大无差异集合”对应一个**极大团**（$\texttt{maximal clique}$），即不能再加入任何其他顶点而仍然构成团。

因此，问题转化为：
1. 根据输入矩阵构建无向图（边表示无差异）。
2. 找出图中所有的极大团。
3. 将极大团按规则排序并分配字母标识符。
4. 对每个顶点（样本），输出包含它的所有极大团的标识符（按字母顺序）。

## 解题思路

### 1. 数据读取与建图
- 读取样本数 $n$。
- 读取 $n$ 行字符串，每行长度为 $n$。
- 对于 $i < j$，如果 `matrix[i][j] == '-'`，则在顶点 $i$ 和 $j$ 之间建立无向边（实际存储为邻接矩阵或布尔矩阵）。

### 2. 枚举所有极大团
由于 $n \leq 10$，我们可以直接枚举所有非空子集（共 $2^n - 1$ 个）：
- 对于每个子集，检查它是否是一个团（即子集中任意两个顶点之间都有边）。
- 如果是团，再检查它是否是极大的：尝试向该子集中添加任何一个不在子集中的顶点，如果添加后仍然是团，则说明它不是极大的。
- 将所有极大团保存下来。

### 3. 极大团排序
按照题目要求排序：
- 优先按集合大小降序。
- 大小相同时，按集合中最小顶点编号升序（注意顶点编号从 $0$ 开始，但题目中样本编号从 $1$ 开始，我们只需保持内部一致即可）。
这里可以直接使用 `vector<int>` 表示集合，利用 `vector` 的字典序比较即可实现第二个条件。

### 4. 分配字母标识符
按排序后的顺序，依次为每个极大团分配字母 `'a'`、`'b'`、`'c'`……。

### 5. 为每个样本输出标识符
对于每个样本 $i$，遍历所有极大团，如果该团包含 $i$，则将对应的字母加入该样本的标识符字符串中。
最后将每个样本的标识符字符串按字母顺序排序后输出。

### 6. 输出格式
每个样本一行，输出其标识符字符串。 每个测试用例后输出一行 `"-----"`。

## 复杂度分析
- 枚举所有子集：$O(2^n)$，$n \leq 10$，最多 $1024$ 个子集，完全可行。
- 检查团是否为极大团：每个子集最多检查 $n$ 个顶点，每个顶点检查与当前团中所有顶点的连接情况，因此每个子集的最坏复杂度为 $O(n^3)$。
- 总复杂度约为 $O(2^n \cdot n^3)$，在 $n=10$ 时约为 $1024 \times 1000 \approx 10^6$，完全在可接受范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 检查子集是否为团（所有顶点间都无差异）
bool isClique(const vector<vector<bool>>& noDiff, const vector<int>& subset) {
    for (int i = 0; i < subset.size(); ++i)
        for (int j = i + 1; j < subset.size(); ++j)
            if (!noDiff[subset[i]][subset[j]]) return false;
    return true;
}

// 检查团是否为极大团
bool isMaximalClique(const vector<vector<bool>>& noDiff, const vector<int>& clique, int n) {
    vector<bool> inClique(n, false);
    for (int v : clique) inClique[v] = true;
    for (int v = 0; v < n; ++v) {
        if (inClique[v]) continue;
        // 尝试将 v 加入团中
        bool canAdd = true;
        for (int u : clique)
            if (!noDiff[u][v]) {
                canAdd = false;
                break;
            }
        if (canAdd) return false; // 可以加入，说明不是极大团
    }
    return true;
}

int main() {
    int n;
    bool firstMatrix = true;
    while (cin >> n) {
        vector<string> mat(n);
        for (int i = 0; i < n; ++i) cin >> mat[i];
        // 构建无差异图
        vector<vector<bool>> noDiff(n, vector<bool>(n, false));
        for (int i = 0; i < n; ++i) {
            noDiff[i][i] = true; // 自己和自己无差异
            for (int j = i + 1; j < n; ++j)
                if (mat[i][j] == '-') noDiff[i][j] = noDiff[j][i] = true;
        }
        // 找出所有极大团
        vector<vector<int>> maximalCliques;
        int totalSubsets = 1 << n;
        for (int mask = 1; mask < totalSubsets; ++mask) {
            vector<int> subset;
            for (int i = 0; i < n; ++i)
                if (mask & (1 << i)) subset.push_back(i);
            if (isClique(noDiff, subset) && isMaximalClique(noDiff, subset, n))
                maximalCliques.push_back(subset);
        }
        // 排序极大团：大小降序，大小相同则按最小元素升序
        sort(maximalCliques.begin(), maximalCliques.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 if (a.size() != b.size()) return a.size() > b.size();
                 return a < b; // vector 的字典序比较
             });
        // 为每个极大团分配字母标识符
        map<vector<int>, char> cliqueToChar;
        char currentChar = 'a';
        for (const auto& clique : maximalCliques)
            cliqueToChar[clique] = currentChar++;
        // 为每个样本收集标识符
        vector<string> sampleLabels(n);
        for (int i = 0; i < n; ++i) {
            string labels;
            for (const auto& clique : maximalCliques)
                if (find(clique.begin(), clique.end(), i) != clique.end())
                    labels += cliqueToChar[clique];
            sort(labels.begin(), labels.end());
            sampleLabels[i] = labels;
        }
        // 输出结果
        for (int i = 0; i < n; ++i) cout << sampleLabels[i] << '\n';
        cout << "-----\n";
    }
    return 0;
}
```

## 总结
本题是一个典型的**极大团枚举**问题，由于数据规模很小，可以直接暴力枚举所有子集并检查。 解题的关键在于正确理解“极大无差异集合”与图论中“极大团”的对应关系，并按照题目要求进行排序和输出格式化。

注意点：
- 需要处理多个测试用例，直到输入结束。
- 输出时每个样本的标识符字符串需要按字母顺序排序。
- 每个测试用例后输出分隔线。

该解法思路清晰，代码简洁，能够高效地通过题目给定的数据范围。
