## 题目描述

单人游戏通常通过一系列"移动"直到达到游戏的最终状态，最终状态会产生胜利、失败或一个分数。大多数玩家试图通过良好的策略来优化游戏结果。但在这个问题中，我们关心的是如果随机玩会发生什么。毕竟，这些游戏大多是为了消磨时间，而随机玩与其他策略一样能达成这个目标。

游戏可以非常紧凑地表示为（可能是无限的）树。树的每个节点表示一个可能的游戏状态。树的根对应游戏的起始位置。对于一个内部节点，其子节点是可以通过一次移动到达的游戏状态。叶子节点是最终状态，每个叶子节点都分配了一个数字，表示到达该叶子时获得的分数。

树使用以下文法定义：

```ebnf
定义     ::= 标识符 "=" 实数树
实数树   ::= "(" 树 ")"
树       ::= 标识符 | 整数 | "(" 树 ")"
标识符   ::= a | b | ... | z
整数     ∈  {..., -3, -2, -1, 0, 1, 2, 3, ...}
```

通过使用一个 *定义* ，等式右边的 *实数树* 被分配给左边的 *标识符* 。一个 *实数树* 包含一个根节点和一个或多个子节点，表示为一个括在括号中的序列。而一个 *树* 要么是：

* 由给定 *标识符* 表示的树，或者
* 一个叶子节点，由一个单独的 *整数* 表示，或者  
* 一个内部节点，由一个或多个 *树* （其子节点）的序列表示，括在括号中。

你的目标是计算期望分数，如果随机玩的话，即在每个内部节点均匀随机选择一个子节点。即使对于在我们框架中可定义的无限树，只要游戏结束的概率（随机玩）为 $1$，这个期望分数就是良定义的。

### 输入格式

输入文件包含多个游戏树描述。每个描述以一行开始，包含描述中使用的标识符数量 $n$。使用的标识符将是字母表的前 $n$ 个小写字母。接下来的 $n$ 行包含这些标识符的定义（按顺序 `a` , `b` , …）。每个定义可能包含任意的空白字符（但当然单个整数内不会有空格）。定义的右边将只包含前 $n$ 个小写字母中的标识符。

输入以 $n = 0$ 开始的测试用例结束。此测试用例不应处理。

### 输出格式

对于输入中的每个游戏树描述，首先输出游戏编号。然后，对于所有 $n$ 个标识符，按顺序 `a` , `b` , …，输出以下内容。如果一个标识符表示的游戏树结束概率为 $1$，则打印期望分数（随机玩时）。该值应精确到小数点后三位。

如果变量描述的游戏结束概率不为 $1$，则打印 `Expected score of id undefined` 代替。

每个测试用例后输出一个空行。

## 题目分析

这是一个关于**随机过程期望值计算**的问题，涉及**线性方程组求解**和**概率论**的应用。

### 关键概念理解

$1$. **游戏树结构**：每个变量定义一棵树，树节点可以是：
   - 数字叶子节点（终止状态，有分数）
   - 变量引用节点（指向其他变量的定义）
   - 内部节点（有多个子节点，随机均匀选择）

$2$. **随机游戏规则**：从根节点开始，如果是内部节点，则均匀随机选择一个子节点继续；如果是数字叶子节点，则游戏结束并获得该分数；如果是变量引用，则跳转到该变量的定义继续。

$3$. **期望分数**：从某个变量开始随机游戏，最终获得的分数的数学期望。

$4$. **游戏结束概率**：从某个变量开始，最终到达数字叶子节点的概率。只有当这个概率为 $1$时，期望分数才定义良好。

### 数学模型建立

对于每个变量 $i$（$i = 0, 1, ..., n-1$ 对应  `a` , `b` , ..., `z` ），设 $E[i]$ 表示从变量 $i$ 开始游戏的期望分数。

根据游戏规则：

$1$. 如果变量 $i$ 定义为数字 $v$，则 $E[i] = v$。

$2$. 如果变量 $i$ 定义为变量引用 $j$，则 $E[i] = E[j]$。

$3$. 如果变量 $i$ 定义为内部节点，有 $k$ 个子节点，每个子节点 $c_m$（$m = 1, 2, ..., k$）的期望为 $E[c_m]$，则：

   $$E[i] = \frac{1}{k} \sum_{m=1}^{k} E[c_m]$$

对于情况 $3$，子节点 $c_m$ 可能是数字、变量引用或其他内部节点。我们可以递归展开，最终每个 $E[i]$ 都可以表示为其他 $E[j]$ 的线性组合加上常数项。

### 线性方程组

通过上述分析，我们可以为每个变量 $i$ 建立一个线性方程：
$$E[i] = \sum_{j=0}^{n-1} a_{ij} E[j] + b_i$$

其中：
- $a_{ij}$ 是 $E[i]$ 依赖于 $E[j]$ 的系数
- $b_i$ 是常数项（来自数字叶子节点）

将所有方程整理为标准形式：
$$E[i] - \sum_{j=0}^{n-1} a_{ij} E[j] = b_i$$

写成矩阵形式：
$$(I - A)E = B$$

其中：
- $I$ 是 $n \times n$ 单位矩阵
- $A = [a_{ij}]$ 是系数矩阵
- $E = [E[0], E[1], ..., E[n-1]]^T$ 是期望向量
- $B = [b_0, b_1, ..., b_{n-1}]^T$ 是常数向量

### 存在唯一解的条件

根据线性代数理论，方程组 $(I - A)E = B$ 有唯一解当且仅当矩阵 $(I - A)$ 可逆，即$\det(I - A) \neq 0$。

从概率论角度，这等价于**游戏结束概率为 $1$**。如果从某个节点出发，存在正概率进入无限循环而不结束，则对应的方程组要么无解，要么有无穷多解。

在实际求解中，我们通过**高斯消元法**求解线性方程组。消元完成后：
$1$. 如果一个变量有唯一解（对应的方程中只有该变量系数非零且为 $1$），则该变量有定义的期望值。
$2$. 如果一个变量是自由变量（无法确定唯一值），则该变量未定义（游戏结束概率不为 $1$）。

## 解题思路

### 步骤 $1$：解析输入

$1$. 读取变量数量 $n$。
$2$. 对于每个变量（按  `a` , `b` , ... 顺序）：
   - 读取一行定义
   - 找到等号位置，提取右侧表达式字符串
   - 解析表达式为树结构

### 步骤 $2$：表达式解析算法

采用递归下降解析法，处理三种情况：

$1$. **括号表达式** `(...)`：创建内部节点，递归解析子表达式
$2$. **数字**（可能带负号）：创建数字叶子节点
$3$. **小写字母**：创建变量引用节点

### 步骤 $3$：建立线性方程组
对于每个变量 $i$：

$1$. 初始化方程：$mt[i][i] = 1.0$（对应 $E[i]$ 的系数）
$2$. 深度优先遍历（ $\texttt{DFS}$ ）该变量的表达式树：
   - 遇到数字叶子节点：将数值乘以权重加到常数项 $mt[i][n]$
   - 遇到变量引用节点 $j$：将权重加到系数 $mt[i][j]$（实际上是减去，因为方程是 $E[i] - Σ... = 0$）
   - 遇到内部节点：权重平均分配给子节点，递归处理

### 步骤 $4$：高斯消元求解

使用**高斯-约旦消元法**：

$1$. 对于每一列，寻找主元（绝对值最大的元素）
$2$. 交换行使主元到对角线位置
$3$. 归一化主元行
$4$. 用主元行消去其他行的当前列元素
$5$. 消元完成后，提取解：
   - 如果一个方程只有第 $j$ 个变量系数为 $1$，其他系数接近 $0$，则 $x[j] = mt[i][n]$
   - 否则，该变量为自由变量（未定义）

### 步骤 $5$：输出结果

$1$. 输出游戏编号
$2$. 对于每个变量：
   - 如果有定义，输出期望值（保留 $3$ 位小数）
   - 如果未定义，输出 `undefined`

$3$. 输出空行分隔测试用例

## 算法复杂度分析

- **时间复杂度**：主要取决于高斯消元，为 $O(n^3)$，其中 $n \leq 26$（小写字母数量），完全可行。
- **空间复杂度**：$O(n^2)$ 存储系数矩阵。

## 边界情况处理

1. **空表达式**：解析时返回值为 $0$ 的节点
2. **自引用**：在方程中表现为 $a_{ii} \neq 0$，高斯消元会自动处理
3. **循环引用**：多个变量相互引用，可能使方程组无唯一解
4. **数值精度**：使用 $10^{-12}$ 作为精度容差
5. **自由变量判断**：严格检查系数矩阵，避免误判

## 代码实现

```cpp
// Single-Player Games
// UVa ID: 664
// Verdict: Accepted
// Submission Date: 2026-01-10
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 26;          // 最大变量数（小写字母数量）
const double EPS = 1e-12;     // 数值精度容差

// 系数矩阵：mt[i][j] 表示第i个方程中E[j]的系数，mt[i][n]为常数项
double mt[MAXN][MAXN + 1];
double x[MAXN];               // 解向量
bool freeX[MAXN];             // 标记自由变量（未定义）

// 树节点结构
struct TreeNode {
    int type;                 // 0:数字, 1:变量引用, 2:内部节点
    int value;                // 数字值或变量索引(0-25)
    vector<TreeNode*> children; // 子节点列表
    
    TreeNode() : type(0), value(0) {}
    ~TreeNode() { for (auto child : children) delete child; }
};

// 高斯消元法求解线性方程组
void gauss(int n) {
    memset(freeX, true, sizeof(freeX));  // 初始假设所有变量都是自由变量
    int row = 0, col = 0;
    
    // 高斯-约旦消元：化为行简化阶梯形
    for (; row < n && col < n; row++, col++) {
        // 寻找当前列绝对值最大的元素作为主元
        int pivot = row;
        for (int i = row + 1; i < n; i++)
            if (fabs(mt[i][col]) > fabs(mt[pivot][col]))
                pivot = i;
        
        // 如果主元接近0，跳过该列
        if (fabs(mt[pivot][col]) < EPS) {
            row--;
            continue;
        }
        
        // 交换行使主元到对角线位置
        if (pivot != row)
            for (int j = col; j <= n; j++)
                swap(mt[row][j], mt[pivot][j]);
        
        // 归一化主元行
        double base = mt[row][col];
        for (int j = col; j <= n; j++) 
            mt[row][j] /= base;
        
        // 使用主元行消去其他行的当前列元素
        for (int i = 0; i < n; i++)
            if (i != row && fabs(mt[i][col]) > EPS) {
                double factor = mt[i][col];
                for (int j = col; j <= n; j++)
                    mt[i][j] -= factor * mt[row][j];
            }
    }
    
    // 提取解
    memset(x, 0, sizeof(x));
    for (int i = 0; i < n; i++) {
        int varIdx = -1;  // 尝试找到该方程确定的变量
        
        // 检查该方程是否只包含一个变量（系数为1）
        for (int j = 0; j < n; j++)
            if (fabs(mt[i][j]) > EPS)
                if (varIdx == -1) varIdx = j;  // 第一个非零系数
                else { varIdx = -1; break; }   // 多个非零系数，不是唯一变量
        
        // 如果找到唯一变量且其系数接近1，则提取解
        if (varIdx != -1 && fabs(mt[i][varIdx] - 1.0) < EPS) {
            x[varIdx] = mt[i][n];
            freeX[varIdx] = false;  // 该变量有唯一解，不是自由变量
        }
    }
}

// 深度优先遍历表达式树，建立线性方程
// root: 当前节点
// eqIdx: 当前方程的索引（对应哪个变量）
// n: 变量总数
// weight: 当前路径的权重（概率）
void dfs(TreeNode* root, int eqIdx, int n, double weight) {
    if (root->type == 0) {  // 数字叶子节点
        mt[eqIdx][n] += weight * root->value;  // 加到常数项
    }
    else if (root->type == 1) {  // 变量引用节点
        mt[eqIdx][root->value] -= weight;  // 减去系数（因为方程是 E[i] - Σ... = 0）
    }
    else {  // 内部节点
        // 权重平均分配给子节点
        double child_weight = weight / root->children.size();
        for (auto child : root->children)
            dfs(child, eqIdx, n, child_weight);
    }
}

// 递归解析表达式字符串
// s: 表达式字符串
// idx: 当前解析位置
// n: 变量总数（用于验证变量引用是否有效）
TreeNode* parseExpression(const string& s, int& idx, int n) {
    TreeNode* node = new TreeNode();
    
    // 跳过空白字符
    while (idx < s.size() && isspace(s[idx])) idx++;
    if (idx >= s.size()) return node;
    
    if (s[idx] == '(') {  // 括号表达式（内部节点）
        node->type = 2;
        idx++;  // 跳过 '('
        
        // 解析所有子表达式
        while (true) {
            while (idx < s.size() && isspace(s[idx])) idx++;
            if (idx >= s.size() || s[idx] == ')') break;
            
            TreeNode* child = parseExpression(s, idx, n);
            node->children.push_back(child);
        }
        
        if (idx < s.size() && s[idx] == ')') idx++;  // 跳过 ')'
    }
    else if (isdigit(s[idx]) || s[idx] == '-') {  // 数字（可能为负）
        node->type = 0;
        int sign = 1;
        
        // 处理负号
        if (s[idx] == '-') {
            sign = -1;
            idx++;
        }
        
        // 解析数字
        int v = 0;
        while (idx < s.size() && isdigit(s[idx])) {
            v = v * 10 + (s[idx] - '0');
            idx++;
        }
        node->value = v * sign;
    }
    else if (islower(s[idx])) {  // 变量引用
        node->type = 1;
        node->value = s[idx] - 'a';  // 转换为0-25的索引
        idx++;
    }
    
    return node;
}

int main() {
    int n, T = 0;  // n: 变量数，T: 测试用例编号
    
    while (cin >> n && n) {
        T++;
        cin.ignore(128, '\n');  // 忽略换行符
        
        // 初始化系数矩阵
        for (int i = 0; i < n; i++)
            for (int j = 0; j <= n; j++)
                mt[i][j] = 0.0;
        
        // 读取并解析每个变量的定义
        for (int i = 0; i < n; i++) {
            string line;
            getline(cin, line);
            
            // 找到等号位置
            size_t equal = line.find('=');
            string expr = line.substr(equal + 1);
            
            // 解析表达式为树结构
            int idx = 0;
            TreeNode* root = parseExpression(expr, idx, n);
            
            // 建立方程：E[i] = Σ(子节点期望)
            // 转换为：E[i] - Σ(子节点期望) = 0
            mt[i][i] = 1.0;  // E[i]的系数为1
            dfs(root, i, n, 1.0);  // 遍历树建立方程
            
            delete root;  // 释放树内存
        }
        
        // 使用高斯消元法求解线性方程组
        gauss(n);
        
        // 输出结果
        cout << "Game " << T << '\n';
        for (int i = 0; i < n; i++) {
            char id = 'a' + i;
            if (freeX[i]) {  // 自由变量（未定义）
                cout << "Expected score for " << id << " undefined\n";
            }
            else {  // 有唯一解
                cout << fixed << setprecision(3);
                cout << "Expected score for " << id << " = " << x[i] << '\n';
            }
        }
        cout << '\n';  // 测试用例间空行
    }
    
    return 0;
}
```

## 总结

本题的关键在于将随机游戏过程建模为线性方程组，通过**高斯消元法**求解。算法分为几个主要步骤：

1. **解析输入**：将文本定义转换为树结构
2. **建立方程**：遍历树结构，为每个变量建立线性方程
3. **求解方程**：使用高斯消元法求解线性方程组
4. **判断解的存在性**：通过检查变量是否有唯一解来判断游戏结束概率是否为 $1$

这种方法的时间复杂度为 $O(n^3)$，空间复杂度为 $O(n^2)$，对于 $n \leq 26$ 的规模完全可行。该解法巧妙地将概率问题转化为线性代数问题，是解决此类期望计算问题的典型方法。
