## 题目描述

在"新一代"操作系统的 $\texttt{NG}$ 文件系统中，磁盘空间被划分为 $N$ 个大小相等的簇，编号从 $1$ 到 $N$。每个文件占据一个或多个簇，所有未被占用的簇被认为是空闲的。为了获得最快的读取速度，每个文件的所有簇应该连续存放，且文件按访问频率降序排列：文件 $1$ 占据簇 $1,2,\ldots,S_1$，文件 $2$ 占据簇 $S_1+1,S_1+2,\ldots,S_1+S_2$，依此类推。

一次簇移动操作包括：读取一个已占用的簇到内存，然后将其内容写入某个空闲簇。之后，原簇变为空闲，目标簇变为占用。

目标：通过最少数量的簇移动操作，将文件按最优方式放置在磁盘上。

### 输入格式

- 第一行：整数 $M$（数据集数量）
- 每个数据集：
  - 第一行：$N$ 和 $K$（$1 \leq K < N \leq 10000$）
  - 接下来 $K$ 行：每行描述一个文件，以 $S_i$ （文件大小）开头，后跟 $S_i$ 个整数表示该文件当前占用的簇号

### 输出格式

- 对于每个数据集，输出任意最优移动序列
- 每个移动操作输出两个整数：$P_j$ $Q_j$（从 $P_j$ 移动到 $Q_j$）
- 如果无需优化，输出 `No optimization needed`
- 数据集之间输出空行

## 题目分析

### 问题本质

这是一个典型的磁盘碎片整理问题，核心在于重新排列文件簇的位置，使得：

1. **文件顺序**：文件按编号顺序连续存放
2. **簇连续性**：每个文件的所有簇连续存储
3. **移动最少化**：使用最少的移动操作完成整理

### 关键观察

1. **目标布局**：文件 $i$ 应该占据从 $\text{start}_i$ 到 $\text{start}_i + S_i - 1$ 的连续簇
2. **移动约束**：一次移动操作需要目标簇为空闲状态
3. **环的存在**：当所有目标位置都被占用时，会形成循环依赖，需要借助空闲簇打破环

### 解题思路

我们采用基于图论的方法来解决这个问题：

#### 1. 建立映射关系

创建两个核心数组：
- $\texttt{where}[i]$：数据 $i$ 当前所在的物理簇
- $\texttt{belong}[i]$：物理簇 $i$ 当前存储的数据编号

#### 2. 识别两种结构

- **链结构**：存在一条从当前簇到空闲簇的路径，可以直接顺序移动
- **环结构**：所有相关簇都相互依赖，形成环，需要借助空闲簇打破

#### 3. 处理策略

**对于链结构**：
- 找到空簇后，沿着依赖链向前移动
- 每次移动都释放出一个新的空簇，继续处理

**对于环结构**：
1. 找到系统中的空闲簇
2. 将环中的一个簇移动到空闲位置，打破环
3. 处理剩余的链结构
4. 将数据移回正确位置

#### 4. 算法正确性

该算法保证：
- 每次移动都是必要的
- 环处理使用最少的中转操作
- 最终所有数据都在正确位置

## 算法实现

```cpp
// Defragment
// UVa ID: 669

#include <bits/stdc++.h>
using namespace std;
const int MAXN = 10010;
int belong[MAXN], where[MAXN];
int main() {
    int T;
    cin >> T;
    while (T--) {
        int N, K, S;
        cin >> N >> K;
        memset(where, 0, sizeof where);
        memset(belong, 0, sizeof belong);
        int dataId = 0;
        for (int dt = 1; dt <= K; dt++) {
            cin >> S;
            int clusterId;
            vector<int> clusters;
            for (int i = 1; i <= S; i++) {
                cin >> clusterId;
                dataId++;
                // 构建双向链表
                // 簇 dataId 的数据目前位于簇 clusterId
                where[dataId] = clusterId;
                // 位于簇 clusterId 的数据属于簇 dataId
                belong[clusterId] = dataId;
            }
        }
        int defragmented = 0;
        while (true) {
            // 寻找空簇
            int dataToMove = -1, empty = -1, done = 0;
            for (int i = 1; i <= dataId; i++) {
                // 计数归位数据的数量
                if (where[i] == i) { done++; continue; }
                // 当前簇未存储数据
                if (!belong[i]) { empty = i; break; }
                // 存有未归位数据
                dataToMove = i;
            }
            // 所有数据已经归位
            if (done == dataId) break;
            // 找到空簇，开始处理
            if (empty != -1) {
                while (true) {
                    if (!where[empty]) break;
                    cout << where[empty] << ' ' << empty << '\n';
                    // 记录空簇
                    int tmp = where[empty];
                    // 设置数据已经归位
                    where[empty] = empty;
                    belong[empty] = empty;
                    // 设置空簇
                    empty = tmp;
                }
                // 正确设置空簇的状态
                belong[empty] = 0;
            } else {
                // 没有找到空簇，说明所有应该存储数据的簇被占用，
                // 未归位的簇构成一个环或多个环，任选一个未归位的簇开始处理
                // 先寻找一个空簇作为中转，根据题目约束，该簇肯定存在
                for (int i = 1; i <= N; i++)
                    if (!belong[i]) {
                        empty = i;
                        break;
                    }
                // 将环的起始簇移动到中转位置
                cout << dataToMove << ' ' << empty << '\n';
                // 记录环的起始簇
                int start = dataToMove;
                // 沿着环移动数据
                while (true) {
                    // 如果数据来源是环的起点，移动后退出
                    if (where[dataToMove] == start) {
                        cout << empty << ' ' << dataToMove << '\n';
                        // 设置数据已归位
                        where[dataToMove] = dataToMove;
                        belong[dataToMove] = dataToMove;
                        // 可以不设置空簇的状态，因为寻找的空簇就满足此条件
                        // belong[empty] = 0;
                        break;
                    }
                    cout << where[dataToMove] << ' ' << dataToMove << '\n';
                    // 设置数据已归位
                    int tmp = where[dataToMove];
                    where[dataToMove] = dataToMove;
                    belong[dataToMove] = dataToMove;
                    dataToMove = tmp;
                }
            }
            defragmented = 1;
        }
        if (!defragmented) cout << "No optimization needed\n";
        if (T) cout << '\n';
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(N)$，每个簇最多被处理一次
- **空间复杂度**：$O(N)$，用于存储映射关系
- **移动次数**：最优，等于需要移动的簇数量加上环的打破操作

## 总结

本题通过巧妙的双向映射和环检测机制，实现了最优的磁盘碎片整理策略。算法核心在于识别和处理两种不同的依赖结构，确保以最少的移动操作完成文件重排。在实际应用中，这种思路可以扩展到更复杂的存储优化场景。
