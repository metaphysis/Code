## **题目翻译**

假设有 $K$ 个文件，表示为 $F_{1},F_{2},\ldots,F_{K}$ 。这些文件的总长度（按块数计算）为 $N$ 块，每个文件的长度为 $L_{i}$ 块（$1 \leq i \leq K$）。文件 $F_{i}$ 的第 $b$ 块表示为 $F_{i}(b)$（$1 \leq b \leq L_{i}$）。例如，$F_{2}$ 的第 $9$ 块是 $F_{2}(9)$，$F_{3}$ 的第 $4$ 块是 $F_{3}(4)$。

现在考虑一个存储空间 $\texttt{S}$，它包含一个读取头和 $N$ 个块，块的编号从 $0$ 到 $N-1$ 。这 $K$ 个文件按顺序 $F_{1},F_{2},F_{3},\ldots,F_{K}$ 存储在空间 $\texttt{S}$ 中，且没有剩余空闲块，即：

$$
\sum_{i=1}^{K}L_{i}=N
$$

从 $\texttt{S}$ 中读取时，使用一个配置文件数组 $PF$ 指示每个文件开始读取的块号。读取顺序是：先读 $F_{1}$ 的一个块，然后读 $F_{2}$ 的一个块，……，读 $F_{K}$ 的一个块，每次每个文件只读一个块。读完 $F_{K}$ 后，重新开始读 $F_{1}$ 的下一个块，接着是 $F_{2}$ 的下一个块，……，如此循环。在一个文件内部，如果上次读取已经到达最后一个块，则下一个要读取的块是该文件的第一个块。

显然，读取头在每次读取时都需要移动若干个块。因此，我们定义 $\texttt{TB}(P)$ 为读取头在连续 $P$ 次读取中需要移动的块总数。给定 $PF$ 数组，可以假设读取头初始时停留在第一个要读取的文件的起始块上，因此 $\texttt{TB}(1)=0$。

**示例**：设 $K=3,N=12,L_{1}=5,L_{2}=3,L_{3}=4$，$PF$ 为 $2,3,3$。这三个文件存储在 $\texttt{S}$ 中。

根据给定的 $PF$，读取头初始时停留在 $F_{1}$ 的第 $2$ 块，即 $F_{1}(2)$，位于位置 $1$（块编号从 $0$ 开始）。第一次读取不需要移动，$\texttt{TB}(1)=0$。第二次读取是读 $F_{2}$ 的第 $3$ 块，位于位置 $7$，移动 $6$ 块，$\texttt{TB}(2)=6$。第三次读取是读 $F_{3}$ 的第 $3$ 块，位于位置 $10$，移动 $3$ 块，$\texttt{TB}(3)=9$。第四次读取是读 $F_{1}$ 的第 $3$ 块，位于位置 $2$，移动 $8$ 块，$\texttt{TB}(4)=17$。

**输入格式**：多组测试数据。第一行是测试用例数 $l$，接下来 $l$ 行每行给出 $K,N,L_{1}\ L_{2}\ \ldots\ L_{K},PF_{1}\ PF_{2}\ \ldots\ PF_{K},P$，最后一行是 $-1$ 表示输入结束。

**输出格式**：对每个测试用例输出一行，即 $\texttt{TB}(P)$ 的值。

**数据范围**：$1 \leq K \leq 10$，$1 \leq N \leq 1000$，$1 \leq L_{i} \leq 100$，$1 \leq PF_{i} \leq L_{i}$，$1 < P \leq 1000$。

## **题目分析**

本题要求模拟一个读取头在连续存储的文件块之间移动的过程，并计算在 $P$ 次读取操作中移动的总块数。由于文件是连续存储的，且读取顺序是循环轮询每个文件，因此可以通过预处理每个文件的起始存储位置，然后模拟每次读取的位置变化，累加移动距离。

### **关键点**
1. **文件存储结构**：文件 $F_{i}$ 在存储空间 $\texttt{S}$ 中的起始位置可以通过累加前 $i-1$ 个文件的长度得到。
2. **读取顺序**：读取操作按文件编号 $1 \to 2 \to \cdots \to K \to 1 \to \cdots$ 循环进行。
3. **块号循环**：在单个文件内部，块号读取是循环的：当读到最后一个块后，下一个块回到第一个块。
4. **移动距离**：每次移动的距离是读取头当前位置与下一个读取块的绝对位置之差的绝对值。
5. **初始位置**：第一次读取时，读取头已经位于第一个文件的起始块（由 $PF_{1}$ 决定），因此第一次移动距离为 $0$。

---

## **解题思路**

### **步骤 1：预处理文件起始位置**
设 $\texttt{startPos}[i]$ 表示文件 $F_{i}$ 在 S 中的起始块位置（$\texttt{0-based}$）。由于文件是连续存储的，可以递推计算：
- $\texttt{startPos}[1] = 0$
- $\texttt{startPos}[i] = \texttt{startPos}[i-1] + L_{i-1}$（$i \ge 2$）

### **步骤 2：块号到绝对位置的映射**
文件 $F_{i}$ 的第 $b$ 块（$1 \le b \le L_{i}$）在 $\texttt{S}$ 中的绝对位置为：
$$
\texttt{absPos} = \texttt{startPos}[i] + (b - 1)
$$

### **步骤 3：模拟读取过程**
1. 初始化：
   - $\texttt{curBlock}[i] = PF_{i}$（表示当前要读取的块号）
   - $\texttt{currentPos} = \texttt{startPos}[1] + (PF_{1} - 1)$（读取头初始位置）
   - $\texttt{totalMove} = 0$

2. 进行 $P$ 次读取（$t$ 从 $1$ 到 $P$）：
   - 计算当前读取的文件编号：$\texttt{fileIdx} = ((t-1) \bmod K) + 1$（转换为 $\texttt{1-based}$）
   - 计算下一个块的绝对位置 $\texttt{nextPos}$：
$$
     \texttt{nextPos} = \texttt{startPos}[\texttt{fileIdx}] + (\texttt{curBlock}[\texttt{fileIdx}] - 1)
$$
   - 如果 $t > 1$，累加移动距离：
$$
     \texttt{totalMove} += |\texttt{nextPos} - \texttt{currentPos}|
$$
   - 更新当前位置：$\texttt{currentPos} = \texttt{nextPos}$
   - 更新当前文件的下一块号：
     - 如果 $\texttt{curBlock}[\texttt{fileIdx}] == L[\texttt{fileIdx}]$，则 $\texttt{curBlock}[\texttt{fileIdx}] = 1$
     - 否则 $\texttt{curBlock}[\texttt{fileIdx}] += 1$

3. 输出 $\texttt{totalMove}$。

---

## **复杂度分析**
- 预处理起始位置：$O(K)$
- 模拟 $P$ 次读取：$O(P)$
- 总复杂度：$O(K + P)$，在题目数据范围内完全可行。

```cpp
// Movement of Reading Head
// UVa ID: 680

#include <bits/stdc++.h>
using namespace std;

int main() {
    int testCases;
    cin >> testCases;
    for (int tc = 1; tc <= testCases; ++tc) {
        int K, N, P;
        cin >> K >> N;
        vector<int> L(K + 1);          // 文件长度，索引从1开始
        for (int i = 1; i <= K; ++i) cin >> L[i];
        vector<int> PF(K + 1);         // 起始块号，索引从1开始
        for (int i = 1; i <= K; ++i) cin >> PF[i];
        cin >> P;

        // 计算每个文件在存储空间S中的起始位置（0-based）
        vector<int> startPos(K + 1, 0);
        for (int i = 2; i <= K; ++i) startPos[i] = startPos[i - 1] + L[i - 1];

        // 当前每个文件要读取的块号（1-based）
        vector<int> curBlock = PF;

        // 读取头当前位置（绝对位置，0-based）
        int currentPos = startPos[1] + (PF[1] - 1);
        long long totalMove = 0;

        // 模拟P次读取
        for (int t = 1; t <= P; ++t) {
            // 确定当前读取的文件索引（0-based，对应文件F_{idx+1}）
            int fileIdx = (t - 1) % K + 1;  // 转换为1-based文件索引

            // 计算下一个要读取的块的绝对位置
            int nextPos = startPos[fileIdx] + (curBlock[fileIdx] - 1);

            if (t > 1) {
                totalMove += abs(nextPos - currentPos);
                currentPos = nextPos;
            } else {
                // 第一次读取，读取头已经在目标位置，不需要移动
                currentPos = nextPos;
            }

            // 更新该文件的下一个读取块号
            if (curBlock[fileIdx] == L[fileIdx]) curBlock[fileIdx] = 1;
            else curBlock[fileIdx] += 1;
        }

        cout << totalMove << endl;
    }
    int endMarker;
    cin >> endMarker;  // 读入-1，表示输入结束
    return 0;
}
```
