## 题目描述

本题是一个经典的数学表达式构造问题。给定一个包含数字和等号的字符串（例如 `957=52`），以及一组运算符（例如 `+*`），要求将运算符插入到数字之间的适当位置，使得等号两边的表达式在**严格从左到右计算且所有运算符优先级相同**的条件下结果相等。

### 关键约束条件

1. **数字顺序和等号位置固定**：不能改变数字的原始顺序和等号的位置。
2. **运算符使用**：每个运算符必须恰好使用一次。
3. **计算规则**：所有运算符优先级相同，严格从左到右计算。
4. **数字处理**：数字可以是多位数，但不能有前导零（除非数字本身就是 $0$ ）。
5. **除法规则**：除法结果为整数，分母不能为零，且必须整除。
6. **数值范围**：表达式中任何数值不超过 $6$ 位十进制数字。

## 问题分析

### 核心难点

本题的难点在于需要同时确定两个方面：

1. **数字的分组方式**：原始的数字字符序列需要被分割成多个整数，这些整数将作为表达式中的操作数。
2. **运算符的分配和排列**：给定的运算符需要分配到等号两边，并插入到操作数之间。

### 数学建模

设等号左边有 $L$ 个数字字符，右边有 $R$ 个数字字符，总共有 $N$ 个运算符。

如果左边分配 $k$ 个运算符，那么：
- 左边需要 $k+1$ 个操作数
- 右边需要 $(N-k)+1$ 个操作数

这意味着我们需要将左边的 $L$ 个字符分割成 $k+1$ 个非空子串，每个子串表示一个整数；同样，将右边的 $R$ 个字符分割成 $N-k+1$ 个整数。

## 解题思路

### 总体策略

采用**两层枚举+回溯搜索**的策略：

1. **外层枚举**：枚举左边分配的运算符数量 $k$（$0 \leq k \leq N$）。
2. **内层搜索**：对于每个 $k$ 值：
   - 确定左右两边需要的操作数数量
   - 枚举所有可能的数字分割方式
   - 枚举所有运算符的排列和分配方式
   - 验证表达式是否成立

### 详细步骤

#### 步骤 $1$：枚举运算符分配

对于总数为 $N$ 的运算符集合，左边可以分配 $0$ 到 $N$ 个运算符。对于每个可能的分配方案：
- 左边运算符数：$k$
- 右边运算符数：$N-k$
- 左边操作数数：$k+1$
- 右边操作数数：$N-k+1$

#### 步骤 $2$：生成数字分割方案

将 $L$ 个字符分割成 $k+1$ 个非空子串的问题等价于：在 $L-1$ 个间隔中选择 $k$ 个位置进行分割。

我们可以用递归方法生成所有可能的分割方案，每个子串的长度至少为 $1$，且子串长度之和等于 $L$。

#### 步骤 $3$：验证数字有效性

对于每个分割方案生成的子串，需要检查：
1. 不能有前导零（除非子串就是 `0`）
2. 数字不超过 $6$ 位

#### 步骤 $4$：分配运算符并计算

对于有效的数字分割方案：
1. 生成运算符的所有排列（使用 `next_permutation`）
2. 将前 $k$ 个运算符分配给左边，剩余的分配给右边
3. 按照题目要求的计算规则（从左到右，优先级相同）计算左右两边的值
4. 检查两边值是否相等

#### 步骤 $5$：输出结果

找到第一个满足条件的表达式即输出，如果所有可能性都尝试后仍无解，则输出 `NO SOLUTION`。

### 算法复杂度分析

设数字字符总数为 $M$（不超过 $10$），运算符数量为 $N$（不超过 $5$）。

1. **枚举运算符分配**：$O(N)$
2. **生成数字分割方案**：使用组合数，最坏情况 $O(C_{M-1}^{N})$
3. **生成运算符排列**：$O(N!)$
4. **计算表达式值**：$O(N)$

总复杂度在可接受范围内，因为 $M$ 和 $N$ 都很小。

### 关键优化

1. **提前剪枝**：如果左右两边需要的操作数数量超过可用字符数，直接跳过。
2. **有效性检查**：在生成数字分割时就检查数字有效性，避免无效计算。
3. **使用排列生成**：利用 `next_permutation` 高效生成所有运算符排列。

```cpp
// Placing the Ops
// UVa ID: 695
// Verdict: Accepted
// Submission Date: 2026-01-02
// UVa Run Time: 0.020s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int caseNum = 1;  // 测试用例编号

// 计算表达式的值（从左到右，优先级相同）
int evaluate(const vector<int>& nums, const vector<char>& ops) {
    int answer = nums[0];
    for (size_t i = 0; i < ops.size(); ++i) {
        int next = nums[i + 1];
        char op = ops[i];
        if (op == '+') answer += next;
        else if (op == '-') answer -= next;
        else if (op == '*') answer *= next;
        else { // 除法
            if (next == 0) return INT_MAX;  // 除零错误
            answer /= next;  // 整数除法
        }
    }
    return answer;
}

// 检查数字是否有效（无前导零，除非数字就是0）
bool isValidNumber(const string& numStr) {
    if (numStr.length() > 1 && numStr[0] == '0') return false;
    return true;
}

vector<vector<int>> assigned;  // 存储所有长度分配方案
vector<int> tmp;  // 当前正在构建的长度分配方案

// 使用递归生成所有长度组合（将remaining个字符分成parts个数字）
void dfs(int remaining, int parts) {
    if (parts == 0) {
        if (remaining == 0) assigned.push_back(tmp);
        return;
    }
    // 每个数字至少1位，最多 remaining - (parts - 1) 位
    for (int len = 1; len <= remaining - (parts - 1); ++len) {
        tmp.push_back(len);
        dfs(remaining - len, parts - 1);
        tmp.pop_back();
    }
}

bool solve(const string& equation, const string& ops) {
    int eqPos = equation.find('=');  // 等号位置
    string leftStr = equation.substr(0, eqPos);  // 等号左边的数字字符
    string rightStr = equation.substr(eqPos + 1);  // 等号右边的数字字符
    int totalOps = ops.size();  // 运算符总数
    
    // 枚举左边运算符数量
    for (int leftOps = 0; leftOps <= totalOps; ++leftOps) {
        int rightOps = totalOps - leftOps;
        int leftDigits = leftOps + 1;  // 左边需要的数字数量
        int rightDigits = rightOps + 1;  // 右边需要的数字数量
        
        // 检查字符数量是否足够
        if (leftDigits > (int)leftStr.size()) continue;
        if (rightDigits > (int)rightStr.size()) continue;
        
        // 生成左边数字的所有位数分配方案
        tmp.clear();
        assigned.clear();
        dfs(leftStr.size(), leftDigits);
        vector<vector<int>> leftLengths = assigned;
        
        // 生成右边数字的所有位数分配方案
        tmp.clear();
        assigned.clear();
        dfs(rightStr.size(), rightDigits);
        vector<vector<int>> rightLengths = assigned;
        
        // 尝试所有左右长度组合
        for (const auto& leftLen : leftLengths) {
            for (const auto& rightLen : rightLengths) {
                // 构建左边的数字
                vector<int> leftNums;
                int pos = 0;
                bool valid = true;
                for (int len : leftLen) {
                    string numStr = leftStr.substr(pos, len);
                    if (!isValidNumber(numStr)) {
                        valid = false;
                        break;
                    }
                    leftNums.push_back(stoi(numStr));
                    pos += len;
                }
                if (!valid) continue;
                
                // 构建右边的数字
                vector<int> rightNums;
                pos = 0;
                for (int len : rightLen) {
                    string numStr = rightStr.substr(pos, len);
                    if (!isValidNumber(numStr)) {
                        valid = false;
                        break;
                    }
                    rightNums.push_back(stoi(numStr));
                    pos += len;
                }
                if (!valid) continue;
                
                // 生成运算符的所有排列
                string sortedOps = ops;
                sort(sortedOps.begin(), sortedOps.end());
                do {
                    // 分配运算符到左右两边
                    vector<char> leftOpsVec, rightOpsVec;
                    for (int i = 0; i < leftOps; ++i) leftOpsVec.push_back(sortedOps[i]);
                    for (int i = leftOps; i < totalOps; ++i) rightOpsVec.push_back(sortedOps[i]);
                    
                    // 计算左右两边的值
                    int leftVal = evaluate(leftNums, leftOpsVec);
                    int rightVal = evaluate(rightNums, rightOpsVec);
                    
                    // 检查等式是否成立
                    if (leftVal == rightVal && leftVal != INT_MAX) {
                        // 输出结果
                        cout << "Case " << caseNum++ << ": ";
                        for (size_t i = 0; i < leftNums.size(); ++i) {
                            cout << leftNums[i];
                            if (i < leftOpsVec.size()) cout << leftOpsVec[i];
                        }
                        cout << '=';
                        for (size_t i = 0; i < rightNums.size(); ++i) {
                            cout << rightNums[i];
                            if (i < rightOpsVec.size()) cout << rightOpsVec[i];
                        }
                        cout << '\n';
                        return true;
                    }
                } while (next_permutation(sortedOps.begin(), sortedOps.end()));
            }
        }
    }
    return false;
}

int main() {
    string equation;
    while (cin >> equation) {
        if (equation == "$") break;
        string ops;
        cin >> ops;
        if (!solve(equation, ops))
            cout << "Case " << caseNum++ << ": NO SOLUTION\n";
    }
    return 0;
}
```

## 总结

本题是一个典型的搜索问题，通过合理的枚举和剪枝策略可以在有限的时间内找到解。解题的关键在于：

1. **理解计算规则**：严格从左到右，运算符优先级相同。
2. **分离关注点**：将问题分解为数字分割和运算符分配两个子问题。
3. **有效剪枝**：利用约束条件提前排除不可能的情况。
4. **系统搜索**：使用递归和排列生成系统地探索所有可能性。

这种类型的题目不仅考察编程能力，也考察对问题的分析和建模能力。掌握这类问题的解题思路，对于解决其他类似的组合搜索问题也很有帮助。
