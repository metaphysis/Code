[710 The Game](https://blog.csdn.net/metaphysis/article/details/163907335)

## 题目描述

游戏在一个 $w \times h$ 的矩形棋盘上进行，每个格子可能包含棋子（`X`）或是空的（空格）。需要判断两个棋子之间能否用一条路径连接，路径满足两个性质：由水平或垂直的直线段组成，且不穿过任何其他棋子。允许路径暂时离开棋盘。给定多组查询，每组给出两个棋子的坐标，要求输出连接它们所需的最少直线段数，若不可能则输出 `impossible`。

## 输入格式

输入包含多个棋盘描述。每个描述的第一行包含两个整数 $w$ 和 $h$（$1 \le w, h \le 75$），分别表示棋盘的宽度和高度。接下来 $h$ 行，每行包含恰好 $w$ 个字符，`X` 表示该位置有棋子，空格表示空位。每个描述后面跟随若干查询行，每行四个整数 $x_1, y_1, x_2, y_2$，满足 $1 \le x_1, x_2 \le w$，$1 \le y_1, y_2 \le h$，坐标左上角为 $(1, 1)$，两个棋子不同。查询以一行 `0 0 0 0` 结束。整个输入以 $w = h = 0$ 结束，该行不予处理。

## 输出格式

对于每个棋盘，首先输出一行 `Board #n:`，其中 $n$ 为棋盘编号。然后对于每个查询，输出一行 `Pair m: k segments.`，其中 $m$ 为该棋盘内查询的编号（从 $\texttt{1}$ 开始），$k$ 为最少线段数，若不可达则输出 `Pair m: impossible.`。每个棋盘输出后跟一个空行。

## 样例输入

```
5 4
XXXXX
X   X
XXX X
X XXX
2 3 5 3
1 3 4 4
2 3 3 4
0 0 0 0
0 0
```

## 样例输出

```
Board #1:
Pair 1: 4 segments.
Pair 2: 3 segments.
Pair 3: impossible.

```

## 题目分析

棋盘上棋子占据的格子不可通行，空格可通行，且允许路径延伸到棋盘外部（即边界外的虚拟空格）。路径由水平或垂直的线段组成，转折处计为新的线段。目标是在这样的网格图中，求两点间的最少线段数。由于棋盘最大 $75 \times 75$，且查询数不限，需要在每次查询时进行搜索。

搜索时，路径上的每个点要么是空格，要么是目标棋子（终点），不能经过其他棋子。由于允许离开棋盘，我们在棋盘四周增加一圈空白格子，将搜索范围扩展为 $(h+2) \times (w+2)$，并在这些扩展格上允许通行。起始点和目标点均为棋子，但它们本身可作为路径的一部分（起点和终点），但搜索中不能穿过其他棋子。

最少线段数问题等价于在四连通网格中求最少方向改变的路径。通常做法是广度优先搜索，状态包含当前位置和当前方向，每次移动若方向不变则段数不变，若改变则段数 $+1$，起始时方向不计，第一段也算作 $\texttt{1}$ 段。也可以使用深度优先搜索进行剪枝，记录当前已用段数，若超过当前最优则回溯。

## 解题思路

对于每个查询，采用深度优先搜索（$\texttt{DFS}$）寻找最少线段数。定义全局变量 $\textit{steps}$ 存储当前最优解，初始化为无穷大。递归函数 $\texttt{dfs}(r, c, dir, moves)$ 表示当前在 $(r, c)$，上一次移动方向为 $\textit{dir}$（$\texttt{-1}$ 表示起始，无方向），已经使用了 $\textit{moves}$ 段。若 $\textit{moves} \ge \textit{steps}$，则剪枝。枚举四个方向 $k$（上、右、下、左），若 $k$ 与 $\textit{dir}$ 相反（即 $k = (dir+2) \% 4$），则跳过以避免原地折返。计算下一位置 $(nr, nc)$，若越界（扩展后范围为 $0$ 到 $h+1$，$0$ 到 $w+1$）则跳过。若该位置已被访问则跳过。若该位置是目标点 $(my2, mx2)$，则更新 $\textit{steps} = \min(\textit{steps}, \textit{moves} + (k != dir))$，因为转向会产生新段。若该位置是棋子（`X`）且不是目标点，则跳过。否则标记该位置为已访问，递归调用 $\texttt{dfs}(nr, nc, k, moves + (k != dir))$，回溯时取消标记。

起始调用 $\texttt{dfs}(y1, x1, -1, 0)$，其中方向 $\texttt{-1}$ 在计算转向时不增加段数（因为 $k != -1$ 恒为真，但我们在递归中判断 $k != dir$ 时，若 $\textit{dir} = -1$，则 $k != -1$ 为真，所以第一段会正确计数为 $\texttt{1}$，这也符合实际）。需要将起始点标记为已访问，避免走回起点。扩展边界使得路径可以离开棋盘，但起点和终点均在原棋盘内。

由于 $w, h \le 75$，每次 $\texttt{DFS}$ 的状态数最多为 $(h+2)(w+2) \times 4$，剪枝有效，且查询数量有限，可以在时限内完成。

## 代码实现

```cpp
// The Game
// UVa ID: 710
// Verdict: Accepted
// Submission Date: 2018-05-11
// UVa Run Time: 0.000s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;

char grid[80][80];
int W, H, mx1, my1, mx2, my2, steps, visited[80][80];
int offset[4][2] = {{-1, 0}, {0, 1}, {1, 0}, {0, -1}};

void dfs(int mr, int mc, int dir, int moves) {
    if (moves > steps) return;
    for (int k = 0; k < 4; k++) {
        if ((k + 2) % 4 == dir) continue;
        int rr = mr + offset[k][0], cc = mc + offset[k][1];
        if (rr < 0 || rr > H + 1 || cc < 0 || cc > W + 1) continue;
        if (visited[rr][cc]) continue;
        if (rr == my2 && cc == mx2) {
            steps = min(steps, moves + (k != dir));
            continue;
        }
        if (grid[rr][cc] == 'X') continue;
        visited[rr][cc] = 1;
        dfs(rr, cc, k, moves + (k != dir));
        visited[rr][cc] = 0;
    }
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int cases = 0;
    while (cin >> W >> H) {
        if (W == 0) break;
        cout << "Board #" << ++cases << ":\n";
        memset(grid, ' ', sizeof(grid));
        cin.ignore(256, '\n');
        string line;
        for (int i = 1; i <= H; i++) {
            getline(cin, line);
            for (int j = 0; j < W; j++)
                grid[i][j + 1] = line[j];
        }
        int pairs = 0;
        while (cin >> mx1 >> my1 >> mx2 >> my2) {
            if (mx1 == 0) break;
            cout << "Pair " << ++pairs << ": ";
            memset(visited, 0, sizeof(visited));
            steps = INF;
            visited[my1][mx1] = 1;
            dfs(my1, mx1, -1, 0);
            if (steps != INF) cout << steps << " segments.\n";
            else cout << "impossible.\n";
        }
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题通过深度优先搜索求解网格中两点间的最少线段数。关键点在于允许路径离开棋盘，因此需要在棋盘外围增加一圈空白格子；搜索时记录当前方向，利用转向次数作为代价，并剪枝优化。由于棋盘尺寸较小，$\texttt{DFS}$ 配合最优性剪枝足以应对所有查询。该解法直观，易于实现，且能正确处理路径从外部绕行的情况。注意坐标输入顺序为 $x$（列）、$y$（行），代码中需正确映射到数组下标。通过标记已访问避免重复，保证搜索效率。
