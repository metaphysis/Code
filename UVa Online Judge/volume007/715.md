## 题目描述

$\texttt{Malidinesia}$ 的古代喜剧团想要演出 $\texttt{Aristofanes}$ 的一部新发现的喜剧。为保密，导演决定在信件中使用替换密码。每次更换密钥时，他会从字典中随机选择一些单词加密后发送，同时通过安全通道发送明文单词。接收方通过比较明文和密文单词可以重建替换表。

然而，密码专家发现该系统有时不安全：即使不知道明文单词，对手也可能解密消息。原因是导演从字典中选择单词并加密时，从不改变它们的顺序（字典中的单词是按字典序排序的）。

你的任务是判断给定的加密消息是否可以被唯一解密。

### 输入格式

输入包含 $N$ 个测试用例。第一行包含一个正整数 $N$ 。每个测试用例格式如下：

- 第一行：两个正整数 $A$ 和 $K$ ，用空格分隔。 $A$ 表示替换字母表的大小（使用英文字母表的前 $A$ 个小写字母，即 `a` 到 `z` ）， $K$ 表示加密单词的数量。
- 接下来 $K$ 行：每行一个加密单词。
- 最后一行：加密消息。

### 输出格式

对于每个测试用例，输出一行。如果消息可以被唯一解密，则输出解密后的消息；否则输出 `Message cannot be decrypted.` 。

### 样例输入

```
2
5 6
cebdbac
cac
ecd
dca
aba
bac
cedab
4 4
cca
cad
aac
bca
bdac
```

### 样例输出

```
abcde
Message cannot be decrypted.
```

## 题目分析

### 问题本质

这是一个密码分析问题。我们已知：
1. 明文单词来自字典，且按字典序排序。
2. 这些单词使用同一个替换表进行加密（替换表是一个双射：每个字母映射到另一个字母）。
3. 加密后的单词顺序与明文单词的字典序一致。

我们需要根据加密单词的排列顺序推断出替换表，然后用它来解密消息。关键点在于：**可能不止一个替换表满足约束**。如果存在多个替换表，但所有替换表对给定消息的解密结果相同，那么消息仍可被唯一解密。

### 约束条件推导

设明文单词为 $p_1, p_2, \ldots, p_K$ ，密文单词为 $c_1, c_2, \ldots, c_K$ ，且 $p_1 < p_2 < \cdots < p_K$ （字典序）。加密过程是应用一个双射 $f: \text{字母表} \to \text{字母表}$ ，使得 $c_i = f(p_i)$ 。

对于任意相邻单词对 $(c_i, c_{i+1})$ ，由于 $p_i < p_{i+1}$ ，存在第一个不同位置 $j$ ，满足：
- 对于所有 $k < j$ ， $p_i[k] = p_{i+1}[k]$ （即 $c_i[k] = c_{i+1}[k]$ ）。
- $p_i[j] < p_{i+1}[j]$ 。

由于 $c_i = f(p_i)$ ， $c_{i+1} = f(p_{i+1})$ ，因此 $c_i[j] = f(p_i[j])$ ， $c_{i+1}[j] = f(p_{i+1}[j])$ 。于是我们得到约束：

$$
f^{-1}(c_i[j]) < f^{-1}(c_{i+1}[j])
$$

其中 $f^{-1}$ 是 $f$ 的逆映射（因为 $f$ 是双射）。换句话说，密文字母 $c_i[j]$ 映射的明文字母必须小于 $c_{i+1}[j]$ 映射的明文字母。

### 建模为图论问题

我们可以将约束表示为有向图：
- 节点：字母表中的字母（共 $A$ 个）。
- 边：如果存在约束 $f^{-1}(u) < f^{-1}(v)$ ，则添加一条从 $u$ 到 $v$ 的有向边，表示 $u$ 映射的字母必须小于 $v$ 映射的字母。

注意：这里的“小于”是指字母在字母表中的顺序，即 `a` $<$ `b` $< ... <$ `z` 。

### 问题转化为搜索问题

我们需要找到所有双射 $f$ （即排列），使得对于图中的每条边 $u \to v$ ，都有 $f^{-1}(u) < f^{-1}(v)$ 。等价地，如果我们定义 $g = f^{-1}$ ，那么 $g$ 是一个从密文字母到明文字母的双射，且满足 $g(u) < g(v)$ 对于所有边 $u \to v$ 成立。

这实际上要求 $g$ 是图的一个**拓扑排序**的逆映射。更准确地说，如果我们给每个明文字母分配一个排名，那么 $g$ 必须满足：如果存在边 $u \to v$ ，则 $g(u)$ 的排名小于 $g(v)$ 的排名。

### 唯一性判断

可能存在多个满足条件的双射 $g$ 。我们需要检查：
1. 是否存在至少一个满足条件的双射。
2. 如果存在多个，它们对给定消息的解密结果是否相同。

解密消息时，对于消息中的每个密文字母 $x$ ，解密结果为 $g(x)$ 对应的字母。因此，如果所有满足条件的 $g$ 对消息中出现的字母映射结果一致，那么消息可被唯一解密。

## 解题思路

### 算法步骤

1. **预处理约束**：遍历所有相邻的加密单词对，找到第一个不同位置的字母，建立有向边。
2. **回溯搜索**：使用深度优先搜索（ $\texttt{DFS}$ ）枚举所有可能的双射 $g$ ，在搜索过程中进行剪枝。
   - 维护当前已映射的字母对。
   - 检查当前部分映射是否与所有约束一致。
   - 如果发现矛盾，则回溯。
3. **一致性检查**：
   - 记录第一个找到的有效双射对消息的解密结果。
   - 对于后续找到的双射，比较解密结果是否与第一个相同。
   - 如果发现不同，则标记为不一致。
4. **输出结果**：
   - 如果没有找到任何有效双射，输出 `Message cannot be decrypted.` 。
   - 如果找到至少一个双射且所有双射的解密结果一致，输出解密消息。
   - 如果找到多个双射且解密结果不一致，输出 `Message cannot be decrypted.` 。

### 优化策略

1. **剪枝**：在 $\texttt{DFS}$ 过程中，每当添加一个映射时，检查所有涉及该字母的约束是否被违反。
2. **启发式顺序**：优先处理约束多的字母，可以加速搜索。
3. **提前终止**：一旦发现两个解产生不同的解密结果，即可终止搜索。
4. **限制搜索数量**：如果找到的解数量超过一定阈值（例如 $50$ ），可以认为存在多个解，直接判定为不一致（在线测试网站的数据，对于阈值为 $2$ 即可以通过）。

### 复杂度分析

最坏情况下需要枚举所有 $A!$ 种排列。但通过剪枝和启发式顺序，实际搜索空间大大减少。对于 $A \leq 26$ ，在合理时间内可解。

## 代码实现

```cpp
// Substitution Cipher
// UVa ID: 715
// Verdict: Accepted
// Submission Date: 2026-01-01
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXA = 26;

int A, K;
int mapping[MAXA];
bool used[MAXA], inconsistent = false;
vector<int> rules[MAXA];
string message, decrypted;

// 检查当前部分映射是否与所有约束一致
bool checkConstraints(int idx) {
    for (int u = 0; u <= idx; u++)
        for (auto v : rules[u])
            if (mapping[v] != -1)
                if (mapping[v] < mapping[u])
                    return false;
    return true;
}

// 合法解的个数
int cnt = 0;

// 回溯搜索
void dfs(int idx) {
    // 如果已经找到“足够多”的解仍保持一致则提前终止
    if (inconsistent || cnt >= 50) return;
    // 如果所有字母都已处理
    if (idx == A) {
        cnt++;
        string tmp;
        for (char ch : message) {
            if (islower(ch) && ch - 'a' < A) tmp += char('a' + mapping[ch - 'a']);
            else tmp += ch;
        }
        if (decrypted.length() && decrypted != tmp) inconsistent = true;
        else decrypted = tmp;
        return;
    }
    // 尝试将当前字母映射到所有可用明文字母
    for (int p = 0; p < A; p++) {
        if (!used[p]) {
            mapping[idx] = p;
            used[p] = true;
            // 检查约束
            if (checkConstraints(idx)) {
                dfs(idx + 1);
                if (inconsistent) return;
            }
            // 回溯
            mapping[idx] = -1;
            used[p] = false;
        }
    }
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int N; cin >> N;
    string words[1024];
    while (N--) {
        cin >> A >> K;
        for (int i = 0; i < K; ++i) cin >> words[i];
        cin.ignore(128, '\n');
        getline(cin, message);
        // 获取约束关系
        for (int i = 0; i < A; i++) rules[i].clear();
        for (int i = 0; i < K; i++)
            for (int j = i + 1; j < K; j++) {
                string a = words[i], b = words[j];
                int L = min(a.length(), b.length());
                for (int k = 0; k < L; k++)
                    if (a[k] != b[k]) {
                        rules[a[k] - 'a'].push_back(b[k] - 'a');
                        break;
                    }
            }
                
        // 回溯搜索
        inconsistent = false;
        cnt = 0;
        decrypted.clear();
        memset(mapping, -1, sizeof mapping);
        memset(used, false, sizeof used);
        dfs(0);
        
        // 输出结果
        if (inconsistent) cout << "Message cannot be decrypted.\n";
        else cout << decrypted << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于理解字典序约束如何转化为字母之间的序关系，并通过回溯搜索找到所有可能的替换表。需要注意的唯一性判断是：即使存在多个替换表，只要它们对消息的解密结果相同，消息仍可被唯一解密。

算法通过剪枝和提前终止优化，能够在合理时间内解决 $A \leq 26$ 的问题。代码实现简洁高效，适合竞赛环境。
