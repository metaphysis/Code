## 题目描述

三维拼图问题是经典十五拼图问题的三维扩展。给定一个 $M \times M \times M$ 的立方体拼图，其中包含 $M^3 - 1$ 个编号瓦片和一个空位。目标是通过滑动瓦片将拼图恢复到原始状态。

**原始配置**：坐标为 $(x, y, z)$ 的槽位包含瓦片编号 $z \times M^2 + y \times M + x + 1$，且位置 $(M-1, M-1, M-1)$ 为空。

**允许操作**：只能将相邻瓦片沿三个主要方向滑动到空位中。

## 输入格式

- 第一行：测试用例数量 $N$
- 每个测试用例：
  - 第一行：整数 $M$ ($1 \leq M \leq 100$)
  - 接下来 $M$ 行：每行包含 $M^2$ 个数字，表示一层中的所有瓦片
  - 数字 $0$ 表示空位

## 输出格式

对于每个测试用例，输出一行：
- 如果可解：`Puzzle can be solved.`
- 如果不可解：`Puzzle is unsolvable.`

## 题目分析

### 问题本质

这是一个三维排列的奇偶性问题。与二维拼图类似，三维拼图的可解性取决于两个因素：

1. **排列的奇偶性**：瓦片排列的逆序数奇偶性
2. **空位位置的奇偶性**：空位到目标位置的移动距离奇偶性

### 关键洞察

经过数学推导和验证，我们发现三维拼图的可解性规律如下：

- **当 $M$ 为奇数时**：逆序数必须为偶数
- **当 $M$ 为偶数时**：逆序数的奇偶性必须与 $(Y\text{轴步数} + Z\text{轴步数})$ 的奇偶性相同

其中：
- $Y\text{轴步数} = M - 1 - \text{空位}Y\text{坐标}$
- $Z\text{轴步数} = M - 1 - \text{空位}Z\text{坐标}$

### 算法设计

1. **数据读取**：按层读取拼图状态，记录空位坐标
2. **构建序列**：排除空位，构建一维瓦片序列
3. **计算逆序数**：使用归并排序高效计算逆序数
4. **可解性判断**：根据 $M$ 的奇偶性应用相应规则

### 时间复杂度

- 归并排序计算逆序数：$O(M^3 \log M)$
- 对于 $M \leq 100$，$M^3 = 1,000,000$，在合理时间内完成

## 解题思路详解

### 步骤1：理解坐标系统

拼图使用三维坐标 $(x, y, z)$，其中：
- $x$：层内水平方向 ($0$ 到 $M-1$)
- $y$：层内垂直方向 ($0$ 到 $M-1$)  
- $z$：层编号 ($0$ 到 $M-1$，$0$ 为顶层)

输入数据按层组织，每层按行优先顺序排列。

### 步骤2：逆序数计算

逆序数指序列中逆序对的数量。对于序列 $a_1, a_2, \ldots, a_n$，如果 $i < j$ 且 $a_i > a_j$，则 $(a_i, a_j)$ 是一个逆序对。

**重要**：计算逆序数时要排除空位（值为 $0$ 的元素）。

### 步骤3：可解性条件推导

基于群论和排列理论，三维拼图的可解性条件为：

- **$M$ 为奇数**：空位在任意位置的移动都不会改变排列的奇偶性，因此要求初始排列为偶排列（逆序数为偶数）
- **$M$ 为偶数**：空位在 $Y$ 轴和 $Z$ 轴方向的移动会改变排列的奇偶性，因此要求逆序数奇偶性与 $(Y\text{步数} + Z\text{步数})$ 奇偶性匹配

### 步骤4：算法实现细节

1. **高效逆序数计算**：使用归并排序的变体，在合并过程中统计逆序数
2. **空位坐标记录**：在读取数据时记录空位的 $(x, y, z)$ 坐标
3. **奇偶性判断**：使用模 $2$ 运算判断奇偶性

```cpp
#include <bits/stdc++.h>
using namespace std;

// 使用归并排序计算逆序数（排除0）
long long mergeCount(vector<int>& arr, vector<int>& temp, int left, int right) {
    if (left >= right) return 0;
    
    int mid = left + (right - left) / 2;
    long long count = 0;
    
    count += mergeCount(arr, temp, left, mid);
    count += mergeCount(arr, temp, mid + 1, right);
    
    int i = left, j = mid + 1, k = left;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            count += mid - i + 1;
            temp[k++] = arr[j++];
        }
    }
    
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    
    for (int idx = left; idx <= right; idx++) {
        arr[idx] = temp[idx];
    }
    
    return count;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int t;
    cin >> t;
    
    while (t--) {
        int m;
        cin >> m;
        
        // 读取数据并构建排除0的序列
        vector<int> sequence;
        int blankX, blankY, blankZ;
        bool foundZero = false;
        
        for (int z = 0; z < m; z++) {
            for (int y = 0; y < m; y++) {
                for (int x = 0; x < m; x++) {
                    int num;
                    cin >> num;
                    if (num == 0) {
                        blankX = x;
                        blankY = y; 
                        blankZ = z;
                        foundZero = true;
                    } else {
                        sequence.push_back(num);
                    }
                }
            }
        }
        
        // 计算逆序数
        long long inversions = 0;
        if (!sequence.empty()) {
            vector<int> temp(sequence.size());
            inversions = mergeCount(sequence, temp, 0, sequence.size() - 1);
        }
        
        bool solvable;
        
        if (m % 2 == 1) {
            // M为奇数：逆序数必须为偶数
            solvable = (inversions % 2 == 0);
        } else {
            // M为偶数：y步数+z步数与逆序数奇偶性不同时不可解
            int ySteps = (m - 1 - blankY);
            int zSteps = (m - 1 - blankZ);
            int stepsParity = (ySteps + zSteps) % 2;
            int inversionParity = inversions % 2;
            // 如果异或结果为1（奇偶性不同），则不可解
            solvable = !((stepsParity ^ inversionParity) & 1);
        }
        
        if (solvable) cout << "Puzzle can be solved." << endl;
        else cout << "Puzzle is unsolvable." << endl;
    }
    
    return 0;
}
```

## 总结

三维拼图问题通过将排列奇偶性与空位位置相结合来判断可解性。该算法高效可靠，能够处理 $M = 100$ 的大规模数据。关键在于理解不同维度下空位移动对排列奇偶性的影响，并据此设计相应的判断条件。
