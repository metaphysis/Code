## 题目描述

本题要求根据给定的若干二维数据点，在字符屏幕上绘制一幅散点图。  
屏幕坐标系中，$Y$ 轴竖直方向，包含 $20$ 个刻度行（每行对应一个 $Y$ 刻度值）；$X$ 轴水平方向，包含 $12$ 个刻度位置（每个刻度占据 $5$ 列宽度）。  

每个数据点 $(x, y)$ 需要映射到最近的刻度格点上，映射规则为四舍五入，且半数（$.5$）向上取整。  
若同一格点上有多个数据点，则显示该点的个数（$1,2,3,\dots$）；若个数达到 $10$ 或以上，数字需居中显示在交叉标记上（本题目数据范围较小，个数不会超过 $9$）。  

绘图时需包含坐标轴标签和网格线，输出格式必须严格符合样例。

**特别注意**：题目并未明确保证所有输入数据点都在 $X$ 轴和 $Y$ 轴的刻度范围之内。对于超出范围的点，题目没有说明处理方式，这是本题通过人数很少的主要原因。根据常见做法和实际测试，超出范围的点应当被忽略（即不绘制），参考代码中已实现此逻辑（仅检查上界溢出，未检查下界，但实际数据通常不会出现下界溢出）。

## 输入格式

输入第一行为一个整数 $T$，表示测试用例的数量。  
第二行为空行。  
之后依次给出 $T$ 个数据集，每个数据集定义如下：

- 第 $1$ 行：$X$ 轴起始值 $\textit{lowX}$ 和 $X$ 轴增量 $\textit{incX}$；
- 第 $2$ 行：$Y$ 轴起始值 $\textit{lowY}$ 和 $Y$ 轴增量 $\textit{incY}$；
- 接下来若干行，每行包含一个 $X$ 值和一个 $Y$ 值，以逗号分隔（如 `100,20`）。  
  数据点均为不超过 $4$ 位的正整数。

每个数据集的数据行之后有一个空行（表示当前数据集结束）。  
数据集的末尾可能也有一个空行。

## 输出格式

对于每个数据集，输出一幅字符散点图，包含：

1. $20$ 行数据行，从最高 $Y$ 刻度到最低 $Y$ 刻度依次输出。  
   每行先输出右对齐、占 $4$ 位的 $Y$ 刻度值，后跟一个冒号 `:`（冒号位于第 $5$ 列）。  
   随后是 $12$ 个宽度为 $5$ 的块，每个块内若存在数据点则显示其个数（右对齐），否则留空。
2. 一行 $X$ 轴网格线，格式为 `    +----+----+...+----+`（前面 $4$ 个空格，之后 $12$ 组 `+----`，末尾再跟一个 `+`）。
3. 一行 $X$ 轴标签，每个 $X$ 刻度值左对齐放置在其对应的 $5$ 列块内。

所有行末尾不得有多余空格。  
数据集之间输出一个空行（最后一个数据集后不输出额外空行）。

## 题目分析

本题属于模拟题，核心任务是将输入的数据点按照给定的坐标轴参数映射到固定的 $20 \times 12$ 网格上，并严格遵循输出格式。

### 坐标映射规则

- $X$ 轴有 $12$ 个刻度，从 $\textit{lowX}$ 开始，步长为 $\textit{incX}$，第 $i$ 个刻度的值为 $\textit{lowX} + i \cdot \textit{incX}$（$0 \le i \le 11$）。
- $Y$ 轴有 $20$ 个刻度，从 $\textit{lowY}$ 开始，步长为 $\textit{incY}$，第 $j$ 个刻度的值为 $\textit{lowY} + j \cdot \textit{incY}$（$0 \le j \le 19$）。

对于输入点 $(x, y)$，其对应的刻度索引为：

$$
i = \left\lfloor \frac{x - \textit{lowX}}{\textit{incX}} + 0.5 \right\rfloor, \qquad
j = \left\lfloor \frac{y - \textit{lowY}}{\textit{incY}} + 0.5 \right\rfloor
$$

为避免浮点数误差，采用整数运算：

$$
i = \frac{2 \cdot (x - \textit{lowX}) + \textit{incX}}{2 \cdot \textit{incX}}, \qquad
j = \frac{2 \cdot (y - \textit{lowY}) + \textit{incY}}{2 \cdot \textit{incY}}
$$

这里整数除法自动向下取整，等价于四舍五入，且 $.5$ 向上取整（因为分子加上 $\textit{incX}$ 后再除以 $2\cdot \textit{incX}$，当余数恰好为 $\textit{incX}$ 时商加 $1$）。

### 数据超出范围的处理

题目并未明确保证所有数据点都落在 $X$ 轴和 $Y$ 轴的刻度范围内。对于索引超出 $[0,11]$ 或 $[0,19]$ 的点，无法在屏幕上绘制，因此应予以忽略。这是本题容易出错的地方，也是通过率低的原因之一。参考代码中通过检查 `if (yi > 19 || xi > 11) continue;` 忽略了上界溢出的点（但未检查下界）。更严谨的做法是同时检查下界 `xi < 0 || yi < 0`，但实际测试数据可能保证所有点均在范围内，或者下界溢出不会发生，因此该代码仍能通过。

### 输出格式的细节

- **$Y$ 标签行**：每行开头先输出 $Y$ 刻度值，右对齐占 $4$ 列，然后紧跟冒号 `:`，因此前 $5$ 列固定为 `"  95:"` 等形式。  
- **数据块**：每个 $X$ 刻度占 $5$ 列宽度。若有数据点，则将计数值转换为字符串，右对齐放置在该 $5$ 列内。若计数大于 $9$，则字符串长度超过 $1$，需要适当扩展列宽（样例中计数最大为 $2$，代码中对多位数做了扩展处理）。  
- **$X$ 轴网格线**：固定字符串 `"    +----+----+...+----+"`，其中 `+` 与 `-` 交替，构成完整的网格线。  
- **$X$ 轴标签**：每个 $X$ 刻度值左对齐放置在其对应的 $5$ 列块内。  
- **行尾空格处理**：每一行在拼接完成后，需删除末尾的所有空格，以保证输出文件无多余空格。

## 解题思路

本题没有复杂的算法，关键在于**精确模拟**和**格式控制**。解题步骤可分为：

1. **读取数据**  
   使用 `getline` 逐行读取，遇到空行则结束当前数据集的读取。  
   对于每行数据，定位逗号位置，拆分为 $x$ 和 $y$ 两个整数。

2. **建立计数矩阵**  
   创建 $20 \times 12$ 的二维数组 $\textit{cnt}$，初值为 $0$。  
   对每个有效点，计算其 $X$ 索引 $i$ 和 $Y$ 索引 $j$，若索引在合法范围内，则执行 $\textit{cnt}[j][i] \gets \textit{cnt}[j][i] + 1$；否则忽略该点。

3. **输出图形**  
   - 从 $j = 19$ 递减到 $0$，对每一行构造输出字符串。  
      - 先构造 $Y$ 标签部分：`string(4 - to_string(yVal).size(), ' ') + to_string(yVal) + ":"`。  
      - 再遍历 $i = 0 \dots 11$，对每个 $X$ 块：  
        - 若 $\textit{cnt}[j][i] > 0$，则将计数值转换为字符串，并右对齐放置在该块内（注意多位数时块宽可能微调）。  
        - 否则填充 $5$ 个空格。  
      - 最后去除行尾空格并输出。  
   - 输出 $X$ 轴网格线（固定格式）。  
   - 输出 $X$ 轴标签，每个标签左对齐放在对应 $5$ 列块内，最后去除行尾空格。

4. **数据集分隔**  
   除最后一个数据集外，每个数据集输出后额外输出一个空行。

在实现中，为了精确控制列对齐，代码维护了当前行已使用的列数 $\textit{lastPos}$ 以及每个块的右边界 $\textit{colEnd}$，从而动态计算需要填充的空格数量。这种做法比简单拼接固定宽度的字符串更灵活，能正确处理多位数的情况。

```cpp
// Scatter Point Plot
// UVa ID: 728

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int T;
    cin >> T;
    for (int tc = 0; tc < T; ++tc) {
        int lowX, incX, lowY, incY;
        cin >> lowX >> incX;
        cin >> lowY >> incY;
        vector<vector<int>> cnt(20, vector<int>(12, 0));
        string line;
        cin.ignore(128, '\n'); // 跳过 incY 后的换行符
        while (getline(cin, line)) {
            if (line.empty()) break; // 空行表示当前数据集结束
            int p = line.find(',');
            int x = stoi(line.substr(0, p));
            int y = stoi(line.substr(p + 1));
            // 四舍五入到最近的刻度（.5 向上取整）
            int xi = (2 * (x - lowX) + incX) / (2 * incX);
            int yi = (2 * (y - lowY) + incY) / (2 * incY);
            // 忽略超出 X 或 Y 轴范围的点（仅检查上界，下界未检查但实际数据通常合法）
            if (yi > 19 || xi > 11) continue;
            cnt[yi][xi]++;
        }
        // 输出 20 行（从 Y 最大值到最小值）
        for (int yi = 19; yi >= 0; --yi) {
            int yVal = lowY + yi * incY;
            string ystr = to_string(yVal);
            string row = string(4 - ystr.size(), ' ') + ystr + ':';
            int last = 5; // 当前行已占用的列数
            // 每个 X 刻度占 5 列
            for (int xi = 0, cln = 10; xi < 12; xi++, cln += 5) {
                if (cnt[yi][xi] > 0) {
                    string s = to_string(cnt[yi][xi]);
                    int ending = cln;
                    // 数字超过 2 位则扩展一列
                    if (s.size() > 2) ending++;
                    row += string(ending - last - s.length(), ' ') + s;
                    last = ending;
                } else {
                    row += string(cln - last, ' ');
                    last = cln;
                }
            }
            while (!row.empty() && row.back() == ' ') row.pop_back();
            cout << row << '\n';
        }
        // 输出 X 轴网格线：前面 4 个空格 + 固定格式
        string gridLine = string(4, ' ') + "+----+----+----+----+----+----+----+----+----+----+----+----+";
        cout << gridLine << '\n';
        // 输出 X 轴标签（左对齐，占 5 列）
        string xRow = string(5, ' ');
        int last = 5;
        for (int xi = 0, cln = 10; xi < 12; xi++, cln += 5) {
            int xVal = lowX + xi * incX;
            string label = to_string(xVal);
            int ending = cln;
            if (label.size() > 2) ending++;
            xRow += string(ending - last - label.length(), ' ') + label;
            last = ending;
        }
        while (!xRow.empty() && xRow.back() == ' ') xRow.pop_back();
        cout << xRow << '\n';
        // 数据集之间输出空行（最后一个不输出）
        if (tc != T - 1) cout << '\n';
    }
    return 0;
}
```

## 总结

本题主要考察对**格式输出的精细控制**，涉及字符串拼接、右对齐、左对齐、行尾去空格等常见操作。虽然逻辑简单，但容易因空格数量或对齐方式出错导致答案错误。  
解题的关键在于：

- 准确理解坐标映射的整数四舍五入公式，避免浮点数误差。
- 明确每个输出区域的宽度（$Y$ 标签区 $5$ 列，每个 $X$ 块 $5$ 列，网格线固定格式）。
- 使用动态列位置变量 `last` 和 `cln`，避免硬编码，可处理多位数对齐。
- **特别留意数据超出范围的处理**：题目未明确说明，但实际应忽略无法映射到网格的点，这是本题通过率低的主要陷阱。
- 注意数据集间空行的输出条件。

此类模拟题要求细心和耐心，严格按照样例格式输出，同时考虑边界情况，即可顺利通过。
