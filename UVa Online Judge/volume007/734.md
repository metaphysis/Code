## 题目描述

这是一个六边形拼图游戏，包含 $7$ 个六边形的木块（标记为 $\texttt{A}$ 到 $\texttt{G}$）和 $7$ 个插槽（编号 $0$ 到 $6$）。插槽的排列方式为：一个中心插槽（$0$）和六个围绕它的外围插槽（$1$ 到 $6$）。

每个六边形的六条边上都印有一个数字（$0$ 到 $9$ 之间）。玩家需要将 $7$ 个六边形放置到 $7$ 个插槽上，并可以旋转每个六边形，使得相邻六边形的相邻边上的数字相等。

图 $3$ 展示了一个已解决的拼图示例。

## 输入格式

输入包含多个数据集。每个数据集包含 $7$ 行，每行有 $6$ 个连续的数字（没有空格）。第 $1$ 行对应六边形 $\texttt{A}$，第 $2$ 行对应六边形 $\texttt{B}$，以此类推直到六边形 $\texttt{G}$。

每行中的第一个数字表示六边形在“$12$ 点方向”的边上的数字（称为“顶部”边）。随后的 $5$ 个数字表示从顶部边开始顺时针方向的边上的数字。

每个数据集之后有一行只包含一个星号（$\texttt{*}$）作为分隔符。最后一个数据集之后也有分隔符。

## 输出格式

对于每个数据集，如果无解，输出一行 $\texttt{No solution possible}$。如果有解，输出以下格式的解决方案：

```
PEG   HEX   POSITION
---   ---   --------
 0     A     123456
 1     B     234561
 ...
 6     G     612345
```

每列的含义如下：

1. $\texttt{PEG}$：插槽编号（$0$ 到 $6$）
2. $\texttt{HEX}$：放置在该插槽上的六边形标签（$\texttt{A}$ 到 $\texttt{G}$）
3. $\texttt{POSITION}$：该六边形在解决方案中的方向，从顶部边开始顺时针的 $6$ 个数字

每个解决方案（或无解信息）之后输出一行包含 $36$ 个星号（$\texttt{*}$）作为分隔符。

## 题目分析与解题思路

### 问题分析

这是一个典型的**排列组合搜索问题**，需要在 $7$ 个插槽上放置 $7$ 个六边形，每个六边形有 $6$ 种可能的旋转方向，总共的搜索空间为：

$$7! \times 6^7 \approx 5,040 \times 279,936 \approx 1.41 \times 10^9$$

这是一个巨大的搜索空间，直接暴力枚举是不可行的。因此，我们需要使用**回溯搜索**和**剪枝**技术。

### 六边形布局与邻接关系

理解六边形之间的几何关系是解决本题的关键。插槽的布局如下：

```
      1
    6   2
  5   0   3
      4
```

中心插槽 $0$ 与所有外围插槽相邻。外围插槽按顺时针方向相邻：$1$ - $2$ - $3$ - $4$ - $5$ - $6$ - $1$（形成一个环）。

在代码中，我们用以下数据结构表示这些邻接关系：

```cpp
// 邻接表：g[peg] = {(otherPeg, {myEdge, otherEdge}), ...}
vector<pair<int, pair<int, int>>> g[7];
```

其中，$\texttt{myEdge}$ 和 $\texttt{otherEdge}$ 分别表示当前插槽和相邻插槽的边索引（$0$ - $5$）。

### 关键数据结构

1. **$\texttt{Hexagon}$ 结构体**：存储六边形的标签和六个边的值。
2. **$\texttt{pegs[]}$ 数组**：记录每个插槽上放置的六边形索引。
3. **$\texttt{rotation[]}$ 数组**：记录每个插槽上六边形的旋转量（$0$ - $5$）。
4. **$\texttt{used[]}$ 数组**：标记哪些六边形已经被使用。

### 算法设计

我们使用深度优先搜索（$\texttt{DFS}$）来回溯搜索所有可能的排列和旋转。搜索过程如下：

1. **搜索顺序**：按插槽编号 $0$ 到 $6$ 的顺序依次放置六边形。
2. **状态表示**：当前搜索深度 $\texttt{depth}$ 表示正在放置的插槽编号。
3. **选择六边形**：对于当前插槽，尝试所有未使用的六边形。
4. **选择旋转**：对于每个六边形，尝试所有 $6$ 种旋转方向。
5. **约束检查**：在放置每个六边形后，检查它与所有已放置六边形的相邻边是否匹配。
6. **回溯**：如果当前选择导致无解，撤销选择并尝试其他可能性。

### 剪枝优化

为了提高搜索效率，我们采用了以下剪枝策略：

1. **即时约束检查**：在放置每个六边形后立即检查相邻约束，而不是等到所有六边形都放置完毕。
2. **双向邻接关系**：为了支持只检查最新放置插槽的约束，我们存储了双向的邻接关系。这样，当放置插槽 $i$ 时，只需要检查 $\texttt{g[i]}$ 中与已放置插槽的关系。
3. **早期终止**：一旦发现约束不满足，立即回溯，不再尝试该六边形的其他旋转方向。

### 算法复杂度分析

- **最坏情况**：$O(7! \times 6^7) \approx 1.41 \times 10^9$ 种状态
- **实际运行**：由于约束剪枝，实际搜索的状态数远少于理论值
- **每次检查**：$O(1)$ 到 $O(3)$（每个插槽最多有 $3$ 个相邻插槽）

### 实现细节

1. **边索引计算**：六边形旋转后，边索引需要相应调整。我们使用取模运算：
   $$\text{边值} = \text{edges}[(\text{边索引} + \text{旋转量}) \mod 6]$$

2. **邻接关系初始化**：根据六边形布局的几何关系，预先计算好所有相邻关系。

3. **输入处理**：注意正确处理数据集之间的分隔符和文件结束条件。

4. **输出格式**：严格按照题目要求的格式输出，包括列标题和对齐。

### 可能的扩展

1. **对称性剪枝**：由于旋转对称性，可以减少搜索空间。
2. **启发式搜索**：优先放置约束最多的六边形。
3. **记忆化搜索**：记录已搜索的状态，避免重复计算。

## 完整代码

```cpp
// The Programmer's Hex
// UVa ID: 734
// Verdict: Accepted
// Submission Date: 2026-01-02
// UVa Run Time: 0.120s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 六边形结构体，存储标签和六个边的值
struct Hexagon {
    char label;
    int edges[6];
} hexagons[7];

int pegs[7];            // pegs[i] = 六边形索引，表示第 i 个插槽放置的六边形编号
int rotation[7];        // rotation[i] = 旋转次数，表示第 i 个插槽六边形的旋转量
bool used[7];           // 标记六边形是否已被使用

// 邻接表：g[peg] = {(相邻插槽, {我的边索引, 对方的边索引}), ...}
vector<pair<int, pair<int, int>>> g[7];

// 初始化邻接关系
void initialize() {
    // 中心插槽 0 与外围插槽的邻接关系（双向）
    g[0].push_back({1, {0, 3}}); g[1].push_back({0, {3, 0}});
    g[0].push_back({2, {1, 4}}); g[2].push_back({0, {4, 1}});
    g[0].push_back({3, {2, 5}}); g[3].push_back({0, {5, 2}});
    g[0].push_back({4, {3, 0}}); g[4].push_back({0, {0, 3}});
    g[0].push_back({5, {4, 1}}); g[5].push_back({0, {1, 4}});
    g[0].push_back({6, {5, 2}}); g[6].push_back({0, {2, 5}});
    
    // 外围插槽之间的邻接关系（双向，顺时针方向）
    g[1].push_back({2, {2, 5}}); g[2].push_back({1, {5, 2}});
    g[2].push_back({3, {3, 0}}); g[3].push_back({2, {0, 3}});
    g[3].push_back({4, {4, 1}}); g[4].push_back({3, {1, 4}});
    g[4].push_back({5, {5, 2}}); g[5].push_back({4, {2, 5}});
    g[5].push_back({6, {0, 3}}); g[6].push_back({5, {3, 0}});
    g[6].push_back({1, {1, 4}}); g[1].push_back({6, {4, 1}});
}

// 获取旋转后的边值
inline int getEdge(int h, int r, int e) {
    return hexagons[h].edges[(e + r) % 6];
}

// 检查当前插槽与已放置插槽的约束
bool checkConstraints(int peg) {
    for (auto &e : g[peg]) {
        int otherPeg = e.first;
        if (pegs[otherPeg] == -1) continue;  // 相邻插槽未放置，跳过检查
        int edgeSelf = e.second.first;
        int edgeOther = e.second.second;
        int self = getEdge(pegs[peg], rotation[peg], edgeSelf);
        int other = getEdge(pegs[otherPeg], rotation[otherPeg], edgeOther);
        if (self != other) return false;
    }
    return true;
}

// 深度优先搜索（回溯）
bool dfs(int depth) {
    if (depth == 7) return true;  // 所有插槽都已放置
    for (int h = 0; h < 7; ++h) {
        if (used[h]) continue;     // 六边形已被使用
        used[h] = true;
        pegs[depth] = h;
        // 尝试所有 6 种旋转方向
        for (int r = 0; r < 6; ++r) {
            rotation[depth] = r;
            if (checkConstraints(depth))        // 检查约束
                if (dfs(depth + 1)) return true; // 继续搜索下一层
        }
        used[h] = false;           // 回溯
        pegs[depth] = -1;
    }
    return false;
}

int main() {
    initialize();                  // 初始化邻接关系
    string line[7];
    
    while (cin >> line[0]) {       // 读取第一个六边形
        // 读取剩余六个六边形
        for (int i = 1; i <= 6; i++) cin >> line[i];
        
        // 解析六边形数据
        for (int i = 0; i < 7; ++i) {
            hexagons[i].label = 'A' + i;
            for (int j = 0; j < 6; ++j)
                hexagons[i].edges[j] = line[i][j] - '0';
        }
        
        // 初始化状态
        fill(pegs, pegs + 7, -1);
        fill(rotation, rotation + 7, 0);
        fill(used, used + 7, false);
        
        // 搜索解决方案
        if (!dfs(0)) cout << "No solution possible\n";
        else {
            // 输出解决方案
            cout << "PEG   HEX   POSITION\n";
            cout << "---   ---   --------\n";
            for (int i = 0; i < 7; ++i) {
                int h = pegs[i], r = rotation[i];
                cout << ' ' << i << string(5, ' ');
                cout << hexagons[h].label << string(5, ' ');
                for (int e = 0; e < 6; ++e) cout << getEdge(h, r, e);
                cout << '\n';
            }
        }
        
        // 输出分隔符
        cout << string(36, '*') << '\n';
        
        // 读取数据集分隔符（*）
        cin >> line[0];
    }
    
    return 0;
}
```
