[UVa 738 A Logical Problem](https://blog.csdn.net/metaphysis/article/details/160575676)

## 题目描述

给定一个由 $\texttt{ASCII}$ 字符绘制的逻辑电路图，包含若干个双输入与门（$\texttt{AND}$）和或门（$\texttt{OR}$），以及若干输入变量（用大写字母 `A` – `Z` 表示）和一个输出标记 `?` 。电路中的路径由横线 `-` 和竖线 `|` 组成，交叉点用 `+` 表示，可以在交叉点处进行 $90^\circ$ 转弯。每个门可以对其输入或输出进行反相，反相标记为小写字母 `o` 放置在相应路径上。

输入文件包含多个电路图，每个电路图以 `*` 作为结束标记，后面跟着若干行输入值（每行是一组 $0$ 和 $1$ 组成的字符串，长度等于该电路中输入变量的个数）。你的任务是：对于每个电路的每组输入，计算输出 `?` 的值。

## 题目分析

### 电路表示规则

根据题目描述和实际数据格式，门有固定的 $3 \times 3$ 表示：

- 第一行：`:\`（冒号 + 右斜杠）
- 第二行：`: )`（$\texttt{AND}$ 门）或 `: >`（$\texttt{OR}$ 门）
- 第三行：`:/`（冒号 + 左斜杠）

其中门中心的冒号 `:` 是关键定位点。门的两个输入从左侧水平进入，分别接入第一行和第三行冒号左侧的位置；门的输出从右侧水平离开，接在第二行冒号右侧 $3$ 个字符的位置（即 `)` 或 `>` 所在列）。反相标记 `o` 可能出现在输入线路上（紧邻门左侧）或输出线路上（紧邻 `)` 或 `>` 右侧）。

### 关键难点

1. **输出标记 `?` 的连接方向不固定**：`?` 可能从上下左右任意方向连接路径，不能默认从左侧进入。
2. **路径追踪需要处理转向**：遇到 `+` 时需要判断方向变化。
3. **门的定位依赖于冒号**：从输出端进入门时，需要先定位到 `)` 或 `>`，然后回退到冒号位置才能找到两个输入端。
4. **输入变量个数可变**：每组输入值的字符串长度等于变量个数，变量按字母顺序对应 `A`，`B`，`C`，`…`。
5. **输出格式要求**：每个电路的每组输入**单独输出一行**结果，**每两组输入之间**（即每个电路输出结束后）输出一个空行。注意最后一个电路之后也要有空行。

## 解题思路

### 整体框架

本题不需要显式构建完整的有向图，而是采用反向递归求解：从输出 `?` 出发，沿着路径反向追踪，遇到门则递归计算其两个输入的值，直到到达输入字母。这种方法简洁高效，避免了复杂图的构建。

### 步骤详解

#### 1. 数据读入与存储

因为电路图最大尺寸为 $100 \times 100$，我们使用二维字符数组 `g` 存储，索引从 $1$ 开始（方便边界处理）。未使用的区域用 `'.'` 填充作为边界标记。

读取过程：
- 逐行读入，遇到 `*` 表示电路图结束。
- 紧接着读取若干行输入值，直到下一个 `*` 之前。
- 对于每一组输入值字符串，提取其中的 `0` 和 `1` 存入数组 `V`（$V[0]$ 对应变量 `A`，$V[1]$ 对应变量 `B`，依此类推）。

#### 2. 确定起始方向

输出标记 `?` 可能连接一条 `-` 或 `|` 路径，我们需要找到路径从哪个方向连接到 `?` 。枚举四个方向（上、左、下、右），如果相邻格子是 `-` 或 `|`（也可以是 `+` 或 `o` 等，但实际直接连接一定是 `-` 或 `|`），则该方向即为起始方向。

#### 3. 路径追踪函数 `walkToNode`

给定当前位置 `(x, y)` 和当前方向 `dir`，沿路径走到下一个“节点”（变量字母、门的输出端 `)` 或 `>`）。

处理逻辑：
- 向当前方向走一步到 `(tx, ty)`。
- 如果 `(tx, ty)` 是 `-`、`|` 或 `o`，则继续沿相同方向走（更新当前位置）。
- 如果 `(tx, ty)` 是 `+`（交叉点），则需要尝试转向：
  - 交叉点处只能改变方向至垂直方向（即从水平进入则转向垂直，从垂直进入则转向水平）。
  - 枚举两个垂直方向（`dir + 1` 和 `dir + 3`，模 $4$ 后对应左转和右转）。
  - 检查上一位置 `(x, y)` 的字符与下一位置 `(nx, ny)` 的字符是否满足 `-` 与 `|` 的对应关系，如果满足则更新当前位置和方向，跳出循环。
- 如果 `(tx, ty)` 是 `)`、`>` 或大写字母，则返回 `(tx, ty)`（表示到达门输出端或输入变量）。

注意：交叉点转向后，**不会停留在 `+` 上**，而是直接移动到转向后的下一个位置，避免死循环。

#### 4. 递归计算函数 `dfs`

给定当前位置 `(x, y)` 和当前方向 `dir`，返回该节点的逻辑值。

- 首先调用 `walkToNode` 到达下一个节点 `(cx, cy)`。
- 如果该节点是大写字母，直接返回对应的输入值 `V[c - 'A']`。
- 否则，该节点是门的输出端 `)` 或 `>` ：
  - 门中心冒号位于 `(cx, cy - 2)`（因为 `)` 或 `>` 在冒号右侧第 $2$ 列）。
  - 两个输入端分别位于冒号上一行的左侧 `(cx - 1, cy - 3)` 和下一行的左侧 `(cx + 1, cy - 3)`。
  - 递归计算两个输入值（方向都是 `LEFT`，因为输入从左侧接入）。
  - 检查输入路径上是否有 `o`，若有则取反。
  - 根据门类型计算输出：$\texttt{AND}$ 门做逻辑与，$\texttt{OR}$ 门做逻辑或。
  - 检查输出路径上是否有 `o`，若有则取反。
  - 返回结果。

#### 5. 输出格式控制

使用一个布尔变量 `cases` 记录是否已经输出过电路，在每组电路输出之前判断是否需要先输出空行。但更简洁的做法是：每个电路处理结束后（即输入值全部处理完）直接输出一个换行。

注意：最后一组电路结束后也需要输出空行，这符合题目要求。

## 复杂度分析

- 每个电路最多 $100 \times 100 = 10^4$ 个格子。
- 每个门递归计算一次，门的个数不超过格子数。
- 路径追踪每次移动一步，总步数不超过格子数。
- 时间复杂度：$O(N \times M)$，其中 $N$ 为格子数，$M$ 为输入组数。
- 空间复杂度：$O(N)$，用于存储电路图和递归栈。

## 代码实现

```cpp
// A Logical Problem
// UVa ID: 738
// Verdict: Accepted
// Submission Date: 2026-04-28
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 110;
const int UP = 0, LEFT = 1, DOWN = 2, RIGHT = 3;

int V[32];
int offset[4][2] = {{-1, 0}, {0, -1}, {1, 0}, {0, 1}};
char g[MAXN][MAXN], marker = '.';

// 从 (x, y) 沿方向 dir 走到下一个节点（变量或门输出端）
pair<int, int> walkToNode(int x, int y, int dir) {
    while (true) {
        int tx = x + offset[dir][0], ty = y + offset[dir][1];
        char c = g[tx][ty];
        // 路径字符：继续直行
        if (c == 'o' || c == '-' || c == '|') {
            x = tx, y = ty;
            continue;
        }
        // 交叉点：尝试转向
        if (c == '+') {
            for (int i = 1; i <= 3; i += 2) {
                int ndir = (dir + i) % 4;
                int nx = tx + offset[ndir][0], ny = ty + offset[ndir][1];
                if ((g[x][y] == '-' && g[nx][ny] == '|') || 
                    (g[x][y] == '|' && g[nx][ny] == '-')) {
                    x = nx, y = ny;
                    dir = ndir;
                    break;
                }
            }
            continue;
        }
        // 到达门输出端或输入变量
        if (c == ')' || c == '>' || isupper(c)) return {tx, ty};
    }
}

// 递归计算节点值
int dfs(int x, int y, int dir) {
    auto [cx, cy] = walkToNode(x, y, dir);
    char c = g[cx][cy];
    // 输入变量
    if (c >= 'A' && c <= 'Z') return V[c - 'A'];
    // 门输出端
    int v1 = dfs(cx - 1, cy - 3, LEFT);
    int v2 = dfs(cx + 1, cy - 3, LEFT);
    if (g[cx - 1][cy - 3] == 'o') v1 = 1 - v1;
    if (g[cx + 1][cy - 3] == 'o') v2 = 1 - v2;
    int v = (c == ')') ? (v1 & v2) : (v1 | v2);
    if (g[cx][cy + 1] == 'o') v = 1 - v;
    return v;
}

// 确定 '?' 的起始方向（只检测 '-' 或 '|' 的直接连接）
int getStartDir(int x, int y) {
    for (int d = 0; d < 4; d++) {
        int nx = x + offset[d][0], ny = y + offset[d][1];
        char c = g[nx][ny];
        if (c == '-' || c == '|') return d;
    }
    return -1;
}

int main() {
    string line;
    int rows = 1, outx, outy;
    memset(g, marker, sizeof g);
    
    while (getline(cin, line)) {
        if (line == "*") {
            // 处理当前电路的所有输入
            while (getline(cin, line)) {
                if (line == "*") {
                    // 电路结束，输出空行（每组测试数据后都有一个空行）
                    cout << '\n';
                    // 重置网格和行号
                    memset(g, marker, sizeof g);
                    rows = 1;
                    break;
                }
                // 解析输入值
                for (int i = 0; i < (int)line.length(); i++) V[i] = line[i] - '0';
                int startDir = getStartDir(outx, outy);
                cout << dfs(outx, outy, startDir) << '\n';
            }
        } else {
            // 读取电路图的一行
            for (int j = 0; j < (int)line.length(); j++) {
                g[rows][j + 1] = line[j];
                if (line[j] == '?') {
                    outx = rows;
                    outy = j + 1;
                }
            }
            rows++;
        }
    }
    return 0;
}
```

## 总结

本题的难点不在于算法本身，而在于对 $\texttt{ASCII}$ 电路图的精确解析和对题目细节的把握：

- 输出标记 `?` 的连接方向需要动态检测。
- 交叉点 `+` 的转向逻辑必须严谨。
- 门的定位依赖于冒号 `:` 与 `)` / `>` 的位置关系。
- 输出格式要求“每组测试数据后都输出一个空行”，包括最后一组。

掌握这些细节后，使用反向递归求解即可高效通过。
