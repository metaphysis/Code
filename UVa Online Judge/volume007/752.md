## 题目描述

给定一个 $n \times n$ 的测试图像（其中 $n$ 是 $2$ 的幂，$1 \leq n \leq 16$），其像素值从 $0$ 到 $n^2 - 1$ 按行优先顺序递增排列。这个图像使用四叉树编码，并且在编码过程中用密码进行了加密：每次将区域划分为四个子象限时，四个子分支的顺序会被重新排列。重排顺序由密码和当前节点编号共同决定。

现在给出了这个测试图像的四叉树编码（已加密），以及另一个使用相同密码加密的秘密图像的四叉树编码。要求根据测试图像的编码推断出密码规则，并解码出秘密图像。

## 题目分析

### 四叉树编码基础

四叉树是一种常用于图像压缩的数据结构。对于一个 $n \times n$ 的图像（$n$ 是 $2$ 的幂）：

$1$.  如果当前区域所有像素值相同，则创建一个叶节点，存储该像素值。
$2$.  否则，创建四个子节点，分别对应四个象限：左上（`NW`）、右上（`NE`）、左下（`SW`）、右下（`SE`）。然后递归处理每个象限。

节点编号规则：
- 根节点编号为 $0$
- 如果节点编号为 $k$，则其四个子节点编号为 $4k+1$、$4k+2$、$4k+3$、$4k+4$

### 加密过程

在加密版本中，每次划分区域时，四个子节点的**物理顺序**会被密码重新排列。也就是说，虽然子节点的编号仍然是 $4k+1$、$4k+2$、$4k+3$、$4k+4$（这是由编号规则决定的），但它们对应的物理象限（`NW、NE、SW、SE`）可能发生了变化。

### 测试图像的特殊性

测试图像的像素值从 $0$ 到 $n^2 - 1$ 严格递增且互不相同。这意味着：

$1$.  除非是 $1 \times 1$ 的单个像素，否则区域不可能均匀，所以四叉树会一直划分到单个像素。
$2$.  每个叶节点对应一个唯一的像素值，这个值实际上就是该像素在**标准测试图像**中的位置索引（行优先顺序）。

### 关键洞察

密码加密并没有改变四叉树的**拓扑结构**（节点编号和父子关系保持不变），而是改变了**叶节点值与物理位置的对应关系**。

对于测试图像：
- 在标准（未加密）编码中，节点 $k$ 的叶值等于它对应像素的位置索引 $i \times n + j$
- 在加密编码中，节点 $k$ 的叶值仍然是这个位置索引，但这个节点现在可能被映射到了不同的物理位置

因此，**`test[k]` 的值就是节点 $k$ 在标准图像中应该对应的像素索引**。

对于秘密图像：
- 在加密编码中，节点 $k$ 的叶值 `secret[k]` 就是秘密图像中对应区域的值

所以，我们可以直接建立映射：  
像素位置 `test[k]` ←→ 像素值 `secret[k]`

## 解题思路

### 算法设计

1.  **读取输入**：读取测试图像和秘密图像的四叉树编码，分别存储在 `test[]` 和 `secret[]` 数组中。
2.  **深度优先遍历四叉树**：从根节点开始递归遍历：
    - 如果当前节点在秘密图像编码中是叶节点（`secret[node] != -1`），则记录该节点的值
    - 如果当前区域大小为 $1 \times 1$（即到达像素级别），则建立映射：`decoded[test[node]] = 当前节点的值`
    - 否则，继续递归处理四个子象限
3.  **输出结果**：将 `decoded` 数组按行优先顺序输出为 $n \times n$ 矩阵。

### 为什么这种方法可行？

- 对于测试图像，`test[node]` 的值就是该节点在标准图像中的像素位置索引（$0$ 到 $n^2-1$）
- 对于秘密图像，`secret[node]` 的值就是该节点在加密图像中的像素值
- 密码的作用就是改变了节点到物理位置的映射，但 `test[node]` 恰好告诉了我们**标准位置**，`secret[node]` 告诉了我们**应该放在这个位置的值**

因此，`decoded[test[node]] = secret[node]` 直接完成了从加密位置到标准位置的转换。

### 时间复杂度

- 四叉树有 $O(n^2)$ 个节点（因为最终有 $n^2$ 个叶节点）
- 每个节点访问一次，时间复杂度为 $O(n^2)$
- 对于 $n \leq 16$（最大 $256$ 个像素），效率完全足够

### 空间复杂度

- 需要存储测试图像编码和秘密图像编码，空间为 $O(n^2)$
- 输出矩阵空间为 $O(n^2)$

```cpp
// Unscrambling Images
// UVa ID: 752

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 516;  // 最大节点数：对于n=16，最大节点编号略大于256

int main() {
    cin.tie(0); 
    cout.tie(0); 
    ios::sync_with_stdio(false);  // 加速输入输出
    
    int T;  // 测试用例数量
    cin >> T;
    
    for (int cs = 1; cs <= T; ++cs) {  // 处理每个测试用例
        int n;
        cin >> n;
        
        // 读取测试图像编码
        int m;
        cin >> m;
        int test[MAXN];
        memset(test, 0, sizeof test);  // 初始化
        for (int i = 0; i < m; ++i) {
            int k, v;
            cin >> k >> v;
            test[k] = v;  // 节点k的值
        }
        
        // 读取秘密图像编码
        cin >> m;
        int secret[MAXN];
        memset(secret, -1, sizeof secret);  // 初始化为-1，表示不是叶节点
        for (int i = 0; i < m; ++i) {
            int k, v;
            cin >> k >> v;
            secret[k] = v;  // 节点k的值
        }
        
        // 解码秘密图像
        int decoded[MAXN];  // 存储最终图像（按行优先顺序）
        function<void(int, int, int, int, int)> decode = [&](int node, int r, int c, int size, int value) {
            // 如果是叶子节点，更新当前值
            if (~secret[node]) value = secret[node];  // ~x表示x!=-1
            
            // 如果区域大小为1×1，记录到对应位置
            if (size == 1) {
                decoded[test[node]] = value;  // 关键步骤：建立映射
                return;
            }
            
            // 继续划分四个象限
            int half = size / 2;
            decode(4 * node + 1, r, c, half, value);           // 左上
            decode(4 * node + 2, r, c + half, half, value);    // 右上
            decode(4 * node + 3, r + half, c, half, value);    // 左下
            decode(4 * node + 4, r + half, c + half, half, value); // 右下
        };
        
        decode(0, 0, 0, n, -1);  // 从根节点开始
        
        // 输出结果
        cout << "Case " << cs << "\n\n";
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j)
                cout << setw(4) << decoded[i * n + j];  // 按行优先输出
            cout << '\n';
        }
        if (cs < T) cout << '\n';  // 测试用例间空行
    }
    
    return 0;
}
```

## 代码说明

### 变量定义

- `test[MAXN]`：存储测试图像编码，`test[k]` 表示节点 $k$ 的值
- `secret[MAXN]`：存储秘密图像编码，`secret[k]` 表示节点 $k$ 的值，初始化为 $-1$ 表示不是叶节点
- `decoded[MAXN]`：存储解码后的图像，按行优先顺序
- `T`：测试用例数量
- `n`：图像大小

### 关键函数

`decode(int node, int r, int c, int size, int value)` 是递归解码函数：
- `node`：当前节点编号
- `r, c`：当前区域左上角坐标
- `size`：当前区域边长
- `value`：当前节点的值（如果是均匀区域则从上到下传递）

### 核心步骤

```cpp
if (size == 1) {
    decoded[test[node]] = value;  // 关键映射
    return;
}
```

这行代码是算法的核心：`test[node]` 是标准位置，`value` 是秘密值，直接建立映射。

### 输出格式

- 每个像素值占 $4$ 个字符宽度，右对齐
- 测试用例编号后有空行
- 测试用例之间有空行

## 总结

本题的关键在于理解测试图像的特殊性：像素值从 $0$ 到 $n^2 - 1$ 递增且互不相同。这使得 `test[node]` 的值实际上就是标准图像中的像素位置索引。利用这一特性，可以直接建立从加密位置到标准位置的映射，无需显式计算密码的排列规则。

这种解法思想巧妙，代码简洁高效，时间复杂度为 $O(n^2)$，完全满足题目要求。通过本题，我们可以学习到如何利用特殊条件简化问题，以及四叉树在图像处理中的应用。
