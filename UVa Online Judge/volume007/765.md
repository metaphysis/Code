## 题目分析

本题要求我们处理一个包含参考文献的文档，按照特定规则对参考文献进行重新编号和排序。文档由多个段落组成，段落之间用空行分隔。每个段落可能是以下两种类型之一：

1. **常规段落** ：普通文本内容，其中可能包含对参考文献的引用，引用格式为 `[数字]` ，例如 `[23]` 
2. **参考文献描述段落** ：以参考文献编号开头，格式为 `[数字]` 描述内容 ，例如 `[23] It is the description... `

### 关键约束条件

- 每个参考文献编号都有且只有一个对应的描述段落
- 每个描述段落都至少被一个常规段落引用
- 参考文献编号为不超过 $999$ 的正整数
- 描述段落不超过 $3$ 行，总行数不超过 $40000$ 行
- 每行长度不超过 $80$ 个字符

### 处理规则

需要按照以下规则处理文档：

1. **重新编号** ：按照参考文献在常规段落中首次出现的顺序，从 $1$ 开始重新编号
2. **排序描述段落** ：所有参考文献描述段落按照新编号排序后放在文档末尾
3. **保持常规段落顺序** ：常规段落的相对顺序保持不变
4. **保持格式** ：除重新编号外，不对段落内容做其他修改

## 解题思路

### 总体流程

解决这个问题需要以下步骤：

1. **读取和解析输入** ：正确处理多行输入，识别段落边界
2. **识别段落类型** ：区分常规段落和参考文献描述段落
3. **提取引用信息** ：从常规段落中提取所有引用编号，记录首次出现顺序
4. **建立编号映射** ：建立旧编号到新编号的映射关系
5. **更新常规段落** ：将常规段落中的引用替换为新编号
6. **处理描述段落** ：更新描述段落的编号并排序
7. **格式化输出** ：按照要求格式输出最终结果

### 详细实现步骤

#### 1. 段落分割

首先需要正确识别段落。题目定义段落之间由至少一个空行分隔。空行是指只包含空格或完全没有字符的行。需要注意的是，可能存在连续多个空行的情况，我们需要正确处理。

实现方法：遍历所有行，当遇到空行时，将当前积累的行作为一个段落，然后跳过后续的空行。

#### 2. 识别段落类型

段落类型的判断依据是段落的第一行：如果第一行以 `[` 开头，则为参考文献描述段落；否则为常规段落。

#### 3. 提取引用信息

从常规段落中提取所有引用编号需要用到正则表达式。引用格式为 `[数字]` ，可以使用正则表达式 `\[(\d+)\]` 进行匹配。

需要特别注意的是：只需要记录每个引用编号的**首次出现顺序**。可以使用一个集合（ `unordered_set` ）来记录已经出现过的编号，当遇到新的编号时，将其加入到顺序列表中。

#### 4. 建立编号映射

按照首次出现顺序列表，从 $1$ 开始为每个编号分配新编号，建立旧编号到新编号的映射。

#### 5. 更新常规段落

遍历所有常规段落，使用正则表达式匹配所有引用，将旧编号替换为对应的新编号。这里需要注意保持段落的原始格式，只替换编号部分。

#### 6. 处理描述段落

对于每个描述段落：
- 从第一行提取旧编号
- 根据映射关系找到新编号
- 更新第一行的编号部分
- 添加到待排序的列表

所有描述段落按照新编号排序。

#### 7. 格式化输出

输出格式要求：
- 所有段落之间用一个真正的空行分隔
- 第一个段落前不能有空行
- 先输出所有常规段落（保持原顺序）
- 然后输出排序后的描述段落

### 算法复杂度分析

- **时间复杂度** ：$O(N + M \log M)$，其中 $N$ 是总行数，$M$ 是参考文献数量。主要时间消耗在正则匹配和描述段落排序上。
- **空间复杂度** ：$O(N)$，需要存储所有段落内容。

### 关键难点

1. **正确处理段落分割** ：需要处理连续空行的情况
2. **准确提取引用编号** ：使用正则表达式确保只匹配正确的引用格式
3. **保持首次出现顺序** ：使用集合记录已出现的编号
4. **输出格式控制** ：确保段落间的空行数量正确

#include <bits/stdc++.h>
using namespace std;

// 检查一行是否为空行（只包含空格或无字符）
bool isEmptyLine(const string& s) {
    return all_of(s.begin(), s.end(), ::isspace);
}

// 从字符串中提取参考文献编号，如"[23]"返回23
int extractRefNum(const string& s) {
    if (s.empty() || s[0] != '[') return -1;
    int num = 0;
    for (size_t i = 1; i < s.size() && s[i] != ']'; ++i) 
        if (isdigit(s[i])) num = num * 10 + (s[i] - '0');
    return num;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    // 读取所有行
    vector<string> lines;
    string line;
    while (getline(cin, line)) 
        lines.push_back(line);
    
    // 分割段落：根据空行分隔
    vector<vector<string>> paragraphs;
    vector<string> curPara;
    for (size_t i = 0; i < lines.size(); ++i) {
        if (isEmptyLine(lines[i])) {
            if (!curPara.empty()) paragraphs.push_back(curPara);
            curPara.clear();
            // 跳过连续的空行
            while (i + 1 < lines.size() && isEmptyLine(lines[i + 1])) i++;
        } else curPara.push_back(lines[i]);
    }
    if (!curPara.empty()) paragraphs.push_back(curPara);
    
    // 识别段落类型并收集信息
    vector<vector<string>> regularParas;  // 常规段落
    vector<pair<int, vector<string>>> refDescs;  // 参考文献描述段落(旧编号, 内容)
    regex refPat(R"(\[(\d+)\])");  // 匹配引用的正则表达式
    vector<int> firstOrder;  // 引用首次出现的顺序
    unordered_set<int> seenRefs;  // 已经出现过的引用编号
    
    for (const auto& para : paragraphs) {
        // 参考文献描述段落：第一行以'['开头
        if (!para.empty() && para[0][0] == '[') {
            int refNum = extractRefNum(para[0]);
            if (refNum > 0) refDescs.emplace_back(refNum, para);
        } else {
            // 常规段落
            regularParas.push_back(para);
            // 提取其中的所有引用编号，记录首次出现顺序
            for (const string& line : para) {
                auto start = line.cbegin();
                smatch match;
                while (regex_search(start, line.cend(), match, refPat)) {
                    int refNum = stoi(match[1]);
                    if (seenRefs.insert(refNum).second) 
                        firstOrder.push_back(refNum);
                    start = match.suffix().first;
                }
            }
        }
    }
    
    // 建立旧编号到新编号的映射
    unordered_map<int, int> oldToNew;
    for (size_t i = 0; i < firstOrder.size(); ++i) 
        oldToNew[firstOrder[i]] = i + 1;
    
    // 输出常规段落，更新引用编号
    bool first = true;
    for (const auto& para : regularParas) {
        if (!first) cout << "\n\n";
        first = false;
        for (size_t i = 0; i < para.size(); ++i) {
            if (i > 0) cout << "\n";
            string line = para[i];
            auto start = line.cbegin();
            smatch match;
            // 替换行中的所有引用编号
            while (regex_search(start, line.cend(), match, refPat)) {
                cout << string(start, match[0].first);
                int oldNum = stoi(match[1]);
                cout << "[" << oldToNew[oldNum] << "]";
                start = match.suffix().first;
            }
            cout << string(start, line.cend());
        }
    }
    
    // 处理参考文献描述段落：更新编号并排序
    vector<pair<int, vector<string>>> updatedDescs;
    for (auto& desc : refDescs) {
        int oldNum = desc.first;
        if (!oldToNew.count(oldNum)) continue;  // 跳过没有被引用的描述
        int newNum = oldToNew[oldNum];
        vector<string> newDesc = desc.second;
        // 更新第一行的编号
        size_t pos = newDesc[0].find(']');
        if (pos != string::npos) 
            newDesc[0] = "[" + to_string(newNum) + "]" + newDesc[0].substr(pos + 1);
        updatedDescs.emplace_back(newNum, newDesc);
    }
    
    // 按新编号排序
    sort(updatedDescs.begin(), updatedDescs.end());
    
    // 输出参考文献描述段落
    for (const auto& desc : updatedDescs) {
        if (!first) cout << "\n\n";
        first = false;
        const auto& lines = desc.second;
        for (size_t i = 0; i < lines.size(); ++i) {
            if (i > 0) cout << "\n";
            cout << lines[i];
        }
    }
    
    if (!first) cout << "\n";
    return 0;
}
