## 题目描述

魔术师 $\texttt{David Copperfield}$ 表演一个经典魔术。屏幕上显示一个 $N$ 行 $N$ 列的方格，每个格子中有一张不同的图片，图片按行从上到下、列从左到右依次编号为 $1$ 到 $N^2$。每位观众将手指放在左上角编号为 $1$ 的图片上。魔术师每次给出一个移动次数 $k_i$，观众必须沿上下左右方向移动恰好 $k_i$ 步（每一步只能移动到相邻且存在的图片）。在观众移动之后，魔术师会移除若干张图片，并保证观众手指所指的图片不在移除之列。重复多轮后，最终所有图片恰好剩下一张，魔术师宣布“抓住你了”。

你需要编写程序，帮助魔术师设计每一轮的移动次数 $k_i$ 以及每一轮要移除的图片编号序列，使得最终只剩一张图片。

## 输入格式

输入第一行为一个正整数 $T$，表示测试用例个数。之后每个测试用例占一行，包含一个整数 $N$（$2 \le N \le 100$）。两个测试用例之间由一个空行隔开（但输入中可能只有一个 $N$ 而无多余空行，样例中未明确空行格式，实现时直接读取整数即可）。

## 输出格式

对于每个测试用例，输出若干行。每行以 $k_i$ 开头，后面跟着本轮要移除的图片编号 $x_{i,1}, x_{i,2}, \dots, x_{i,m_i}$，所有数字用空格分隔。要求：
- 每轮至少移除一张图片；
- 每个图片在整个过程中只能被移除一次；
- 所有 $k_i$ 两两不同，且 $2N \le k_i \le 10000$；
- 最终所有图片除了一张外都被移除。

两个测试用例的输出之间用一个空行隔开。

## 样例

输入

```
1

3
```

输出

```
8     4 6
13    9
10    7 1
7     8
11    3 5
```
## 题目分析

本题要求构造一个满足条件的删除序列，而不是判断可行性或求最优解。由于 $N \le 100$，总图片数 $V = N^2 \le 10000$，我们可以设计任意合法的构造策略。

直接正向模拟需要考虑每一步删除后剩余图片必须保持连通性，因为观众后续的移动必须在剩余图片之间进行。如果剩余图片不连通，观众可能无法从一个连通分量移动到另一个，从而导致魔术失败。动态维护连通性并选择可删除的图片，虽然可行但实现较复杂，且每轮都需要做多次连通性检查，时间复杂度可能较高。

观察棋盘的结构：相邻格子的颜色（按国际象棋棋盘黑白染色）总是相反。从左上角（编号 $1$）出发，每走一步颜色翻转。因此若 $k$ 为奇数，则观众移动后所在格子的颜色与起点相反；若 $k$ 为偶数，则颜色相同。魔术师可以自由选择 $k$ 的奇偶性，但题目要求 $k \ge 2N$ 且互异，我们完全可以全部取奇数。

如果每轮都取奇数步，那么观众移动后必然处在与上一轮起点颜色相反的格子上。于是，**本轮可以安全移除所有与上一轮起点颜色相同的格子**，因为观众一定不在那些格子上。然而，一次性移除整个颜色类可能导致剩余图片不连通。因此需要更巧妙的构造。

## 解题思路

我们采用 **逆向构造** 的方法，避免正向过程中复杂的连通性维护。

### 逆向添加过程

从魔术的最终状态出发：只剩一张图片，我们选定它为左上角编号 $1$。现在反向思考，观众并没有真正移动，我们只是倒着“添加”之前被移除的图片。

对棋盘上的每个格子，计算从编号 $1$ 出发的最短步数（即曼哈顿距离）$d$。由于棋盘是网格，$d$ 的范围为 $0$ 到 $D = 2N-2$。将所有格子按距离 $d$ 分组，得到 $D+1$ 层：第 $0$ 层只有编号 $1$，第 $1$ 层为所有距离为 $1$ 的格子，以此类推。

逆向添加的顺序为：从第 $1$ 层开始，依次添加第 $2$ 层、第 $3$ 层、……、第 $D$ 层。为什么这样能保证连通性？因为 $\texttt{BFS}$ 的性质保证了第 $d$ 层的每个格子都与第 $d-1$ 层的某个格子相邻，而第 $d-1$ 层在添加第 $d$ 层时已经存在于集合中，所以新加入的每个格子都能与已有集合连通，整体保持连通。

### 正向删除序列

将上述逆向添加过程反转，就得到正向删除的轮次：
- 第 $1$ 轮删除第 $D$ 层；
- 第 $2$ 轮删除第 $D-1$ 层；
- ……
- 最后第 $D$ 轮删除第 $1$ 层。

检查安全性：起点编号 $1$ 的距离为 $0$，颜色与 $1$ 相同（设为颜色 $0$）。因为 $D = 2N-2$ 是偶数，所以第 $D$ 层的颜色也是 $0$。第 $1$ 轮删除第 $D$ 层，与观众起点颜色相同。观众在本轮移动奇数步后一定处于颜色 $1$，故不会被删除。之后每一轮删除的层距离递减 $1$，颜色交替变化，而观众每轮移动奇数步，其所在颜色也交替变化，且始终与当前删除层的颜色相反，因此安全。

### 移动次数 $k_i$ 的分配

共有 $D$ 轮（$D \le 198$）。题目要求每个 $k_i$ 在 $[2N, 10000]$ 内且互不相同。我们取从 $2N$ 开始的递增奇数序列：若 $2N$ 为偶数则取 $2N+1$，否则取 $2N$，之后每次加 $2$。由于 $D$ 很小，显然有足够多的奇数可用。

### 算法步骤

1. 读入 $N$，建立 $V = N^2$ 个节点的网格图，编号 $1$ 到 $V$。
2. 从节点 $1$ 开始 BFS，计算每个节点的最短距离 $\textit{dist}$，得到最大距离 $D$。
3. 按照距离 $1$ 到 $D$ 将节点分层，每层存储所有该距离的节点编号（不包括起点 $1$）。
4. 构造正向删除轮次：从距离 $D$ 向下到 $1$，将每层作为一轮。
5. 生成 $k$：初值 $k = 2N$，若 $k$ 为偶数则 $k \gets k+1$，每轮输出后 $k \gets k+2$。
6. 输出每轮的 $k$ 和该层所有编号。

### 正确性证明

- **连通性**：逆向添加时，每层都能与已添加的上一层相邻，因此正向删除时，删掉最外层后，剩余部分仍然连通（因为最外层的点只与内层相邻，删除它们不会切断内层之间的连接）。
- **安全性**：每轮删除层的颜色与观众在移动前所在颜色相同，而移动奇数步后观众颜色相反，故不会被删。
- **终止性**：每轮删除至少一层，共 $D$ 轮后剩余恰好第 $0$ 层（即编号 $1$）。
- $k$ **合法性**：所有 $k$ 均为互不相同的奇数，且最小值为 $2N$ 或 $2N+1$，满足 $\ge 2N$，且最大值为 $2N + 2(D-1) \le 2N + 2(2N-3) = 6N-6 \le 594 < 10000$，满足上限。

### 复杂度分析

- BFS 遍历 $V$ 个节点和 $O(V)$ 条边，时间复杂度 $O(V)$。
- 分层和输出也只需 $O(V)$。
- 总时间复杂度 $O(N^2)$，空间复杂度 $O(N^2)$，完全满足 $N \le 100$ 的限制。

## 代码实现

```cpp
// Magic of David Copperfield
// UVa ID: 769
// Verdict: Accepted
// Submission Date: 2026-07-06
// UVa Run Time: 0.040s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    bool firstCase = true;

    while (T--) {
        int N;
        cin >> N;
        int V = N * N;

        // 建图：相邻格子连边
        vector<vector<int>> adj(V + 1);
        auto addEdge = [&](int a, int b) {
            adj[a].push_back(b);
            adj[b].push_back(a);
        };
        for (int r = 0; r < N; ++r)
            for (int c = 0; c < N; ++c) {
                int id = r * N + c + 1;
                if (r > 0) addEdge(id, id - N);
                if (r + 1 < N) addEdge(id, id + N);
                if (c > 0) addEdge(id, id - 1);
                if (c + 1 < N) addEdge(id, id + 1);
            }

        // BFS 求到起点 1 的最短距离
        vector<int> dist(V + 1, -1);
        queue<int> q;
        dist[1] = 0;
        q.push(1);
        int maxDist = 0;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            maxDist = max(maxDist, dist[u]);
            for (int v : adj[u])
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    q.push(v);
                }
        }

        // 按距离分层（距离从 1 到 maxDist）
        vector<vector<int>> layers(maxDist + 1);
        for (int id = 2; id <= V; ++id)
            layers[dist[id]].push_back(id);

        // 正向轮次：距离从大到小
        vector<vector<int>> forwardRounds;
        for (int d = maxDist; d >= 1; --d)
            if (!layers[d].empty())
                forwardRounds.push_back(layers[d]);

        // 分配 k：从 2N 开始取奇数
        int k = 2 * N;
        if (k % 2 == 0) ++k;

        // 输出当前测试用例结果
        if (!firstCase) cout << '\n';
        firstCase = false;

        for (const auto &round : forwardRounds) {
            cout << k;
            for (int x : round) cout << ' ' << x;
            cout << '\n';
            k += 2;
        }
    }

    return 0;
}
```

## 总结

本题的核心技巧是 **逆向思维** 和 **$\texttt{BFS}$ 分层**。通过从最终状态倒推，利用 $\texttt{BFS}$ 的距离分层性质，我们可以轻松构造出每一步的删除集合，且天然保证剩余图片的连通性，完全避开了正向模拟时复杂的连通性动态判断。同时，通过固定选取奇数步数，确保了每次删除的图片颜色与观众所在颜色相反，从而保证安全。

这种“反向构造”的方法在若干魔术题或游戏题中十分常见，其本质是将一个动态过程转化为静态的层次划分，是降低思维和实现复杂度的有效手段。

关键点：
- 棋盘染色与步数奇偶性之间的关系；
- $\texttt{BFS}$ 层的连通性保证；
- 逆向反转得到正向操作序列；
- 奇数步数的统一选择简化颜色匹配。

该算法时空复杂度均为 $O(N^2)$，在 $N \le 100$ 时非常高效，代码简洁且易于验证正确性。
