## 题目描述

城市 $\texttt{AllSquared}$ 坐落在一个 $n \times m$ 平方英里的矩形区域内，其中 $n$ 是高度（南北方向），$m$ 是宽度（东西方向）。街道是水平分割线，从北到南编号为 $0$ 到 $n$；大道是垂直分割线，从西到东编号为 $0$ 到 $m$。这些线条将城市划分为 $n \times m$ 个基本单元。

城市被进一步划分为 $h \times v$ 个县（county），其中 $h$ 和 $v$ 分别表示水平和垂直方向的分割数。水平分割线位于指定的街道 $s_1, \dots, s_{h-1}$ 上，垂直分割线位于指定的大道 $a_1, \dots, a_{v-1}$ 上。这些分割线将城市划分为 $h \times v$ 个矩形区域，每个区域称为一个县。

每个县都有一个正整数的通行费（$\texttt{circulation fee}$）。汽车在进入某个县时，需要支付该县的通行费。如果汽车的起点恰好位于划分该县的边界线（街道或大道）上，则不收取该县的费用。汽车可以在街道或大道上自由行驶，不产生费用，只有进入县内部时才收费。

给定起点和终点坐标（均在街道或大道上），要求计算从起点到终点的最小总通行费用。

## 输入格式

输入包含多个测试实例。每个实例的格式如下：

- 第一行包含两个正整数 $n$ 和 $m$（$0 < h \le n < 100$，$0 < v \le m < 100$），表示城市尺寸。
- 第二行包含两个正整数 $h$ 和 $v$，表示水平和垂直方向的分割数。
- 第三行包含 $h-1$ 个整数 $s_1, \dots, s_{h-1}$（$1 \le s_i \le n-1$），表示水平分割线所在的街道编号。
- 第四行包含 $v-1$ 个整数 $a_1, \dots, a_{v-1}$（$1 \le a_i \le m-1$），表示垂直分割线所在的大道编号。
- 接下来 $h$ 行，每行 $v$ 个正整数 $p_{ij}$（$0 < p_{ij} < 10000$），表示每个县的通行费。顺序为从上到下（北到南）、从左到右（西到东）。
- 最后一行包含四个整数 $w_1, t_1, w_2, t_2$，分别表示起点的街道和大道编号，以及终点的街道和大道编号（$0 \le w_1, w_2 \le n$，$0 \le t_1, t_2 \le m$）。

每个实例以一行以 `%` 开头的行结束。数字之间可以有任意数量的空格或空行。

## 输出格式

对于每个测试实例，输出一行一个整数，表示从起点到终点的最小总通行费用。

## 题目分析

本题的核心是将地理网格中的通行问题转化为图论中的最短路径问题。城市由街道和大道划分成基本网格，而县是由分割线进一步划分出的矩形区域。汽车在边界线上行驶不产生费用，只有进入某个县时才支付该县的通行费。起点如果位于某县的边界上，则进入该县时不需要支付费用；但终点所在的县，无论起点在边界上，最后进入该县仍需支付费用（因为进入该县这个行为发生）。

因为所有通行费均为正数，最优路径不会重复进入同一个县（否则绕圈会增加费用），所以问题可以抽象为在 $h \times v$ 个县组成的网格图上求最短路径。每个县对应一个节点，节点之间的边表示汽车从一个县进入相邻县，边权等于目标县的通行费（因为进入目标县才收费）。起点可以免费选择其所在边界上的任意一个县作为起始节点，因此我们引入一个超级源点，从该源点到所有可能的起始县连边权为 $0$。终点则需要考虑进入终点所在县的费用，因此答案是从超级源点到任意一个终点所在县的最短距离，该距离已经包含了进入终点县的费用。

## 解题思路

### 步骤一：确定县的边界

给定水平分割线 $s_1, \dots, s_{h-1}$ 和垂直分割线 $a_1, \dots, a_{v-1}$，我们可以计算出每个县的北、南、西、东边界。设县 $(i, j)$（$0 \le i < h$ 为行索引，$0 \le j < v$ 为列索引），其边界为：

- 北边界：若 $i = 0$，则为 $0$，否则为 $s_{i-1}$；
- 南边界：若 $i = h-1$，则为 $n$，否则为 $s_i$；
- 西边界：若 $j = 0$，则为 $0$，否则为 $a_{j-1}$；
- 东边界：若 $j = v-1$，则为 $m$，否则为 $a_j$。

这样，任意点 $(x, y)$（街道 $x$，大道 $y$）落在县 $(i, j)$ 内当且仅当北边界 $\le x \le$ 南边界 且 西边界 $\le y \le$ 东边界。注意因为点在边界上也属于该县，但若在分割线上，可能同时属于多个县（最多四个），所以起点和终点可能位于多个县的边界上。

### 步骤二：确定起始节点集合和目标节点集合

对于起点 $(w_1, t_1)$，遍历所有县，如果该点落在该县的边界内（包括边界），则该县可以作为起始县，不需要支付该县的费用。将所有这些县对应的节点编号加入起始集合 $S$。

对于终点 $(w_2, t_2)$，同样遍历所有县，如果点落在该县内（包括边界），则该县是可能的目标县。因为最终要进入终点所在的县，所以需要支付该县的费用，因此这些节点为目标节点集合 $T$。

### 步骤三：构建图

节点总数为 $N = h \times v$。我们引入一个超级源点，编号为 $N$。从超级源点到每个起始节点连一条有向边，权值为 $0$。

对于任意两个相邻的县（上下左右相邻），从当前县 $u$ 到相邻县 $v$ 连一条有向边，权值等于 $v$ 县的通行费（即进入 $v$ 县需支付的费用）。注意：汽车从 $u$ 县行驶到 $v$ 县，需要跨越分割线，进入 $v$ 县内部才收费，因此边权是目标县费用。如果汽车沿着边界行驶，则不会进入任何县内部，但我们的图模型只考虑县与县之间的穿越，若起点和终点在同一县的边界上，可能无需进入任何县，费用为 $0$。这种情况也会被超级源点到该县的零边覆盖，且目标集合包含该县，答案会为 $0$（如果起点和终点都在该县边界且不进入其他县）。

### 步骤四：运行最短路径算法

由于边权均为非负整数，我们使用 $\texttt{Dijkstra}$ 算法从超级源点计算到所有节点的最短距离。最终答案即为 $\min_{t \in T} \textit{dist}[t]$。

### 正确性说明

- 所有县之间的移动只能通过边界线，而边界线是共享的，因此从县 $u$ 到县 $v$ 的最直接方式就是越过它们的公共边界，支付 $v$ 的费用。任何更复杂的路径（经过多个县）都可以分解为一系列相邻县之间的移动，费用为各目标县费用之和，这与图中的路径一一对应。
- 超级源点提供了起点可免费进入任意一个起始县的能力，符合题目规则。
- 目标集合 $T$ 包含了所有可能包含终点的县，最终答案取最小值，因为到达终点后无需再移动，只需确保进入该县的费用已被支付。

### 复杂度分析

- 节点数 $N = h \times v \le 100 \times 100 = 10^4$，边数约为 $4N$（每个节点最多四个邻边）加上超级源点边数。
- $\texttt{Dijkstra}$ 使用优先队列，时间复杂度为 $O((N + E) \log N)$，在本题限制下完全可以接受。
- 空间复杂度为 $O(N + E)$。

```cpp
// Driving in City Squares

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    while (cin >> n) {
        cin >> m;
        int h, v;
        cin >> h >> v;
        vector<int> s(h - 1), a(v - 1);
        for (int i = 0; i < h - 1; ++i) cin >> s[i];
        for (int i = 0; i < v - 1; ++i) cin >> a[i];
        vector<vector<int>> fee(h, vector<int>(v));
        for (int i = 0; i < h; ++i)
            for (int j = 0; j < v; ++j)
                cin >> fee[i][j];
        int w1, t1, w2, t2;
        cin >> w1 >> t1 >> w2 >> t2;
        // 计算每个县的边界
        vector<int> north(h), south(h), west(v), east(v);
        for (int i = 0; i < h; ++i) {
            north[i] = (i == 0) ? 0 : s[i - 1];
            south[i] = (i == h - 1) ? n : s[i];
        }
        for (int j = 0; j < v; ++j) {
            west[j] = (j == 0) ? 0 : a[j - 1];
            east[j] = (j == v - 1) ? m : a[j];
        }
        // 确定起始县集合和目标县集合
        vector<int> startNodes, targetNodes;
        for (int i = 0; i < h; ++i) {
            for (int j = 0; j < v; ++j) {
                int id = i * v + j;
                if (w1 >= north[i] && w1 <= south[i] && t1 >= west[j] && t1 <= east[j])
                    startNodes.push_back(id);
                if (w2 >= north[i] && w2 <= south[i] && t2 >= west[j] && t2 <= east[j])
                    targetNodes.push_back(id);
            }
        }
        int N = h * v;
        int S = N;                        // 超级源点
        vector<vector<pair<int, int>>> adj(N + 1);
        // 超级源点到所有起始节点距离0
        for (int id : startNodes) adj[S].push_back({id, 0});
        // 相邻县之间的边，边权为目标县费用
        int dirs[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};
        for (int i = 0; i < h; ++i) {
            for (int j = 0; j < v; ++j) {
                int u = i * v + j;
                for (auto &d : dirs) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni < 0 || ni >= h || nj < 0 || nj >= v) continue;
                    int vNode = ni * v + nj;
                    adj[u].push_back({vNode, fee[ni][nj]});
                }
            }
        }
        // Dijkstra
        vector<int> dist(N + 1, INF);
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
        dist[S] = 0;
        pq.push({0, S});
        while (!pq.empty()) {
            auto [d, u] = pq.top(); pq.pop();
            if (d != dist[u]) continue;
            for (auto &[vNode, w] : adj[u]) {
                if (dist[vNode] > dist[u] + w) {
                    dist[vNode] = dist[u] + w;
                    pq.push({dist[vNode], vNode});
                }
            }
        }
        int ans = INF;
        for (int id : targetNodes) ans = min(ans, dist[id]);
        cout << ans << '\n';
        // 读取实例结束标记 '%'
        string endMark;
        cin >> endMark;   // 应为 "%"
    }
    return 0;
}
```

## 总结

本题的关键在于将地理空间离散化为县之间的图模型，并正确处理起点免费和终点付费的规则。我们通过引入超级源点统一处理起点可免费进入多个县的情况，使用 $\texttt{Dijkstra}$ 算法求出最短路径。由于费用为正，保证了最短路径不会自环，简化了问题。该建模方法具有普适性，可应用于类似的有区域划分、边界行驶不收费的路径规划问题。

技巧点：
- 将“进入县支付费用”转化为边权，且边权归目标节点。
- 起点位于边界时，同时属于多个县，需将所有可能的起始县纳入零权边。
- 终点同样可能位于多个县，取最小值。
- 使用邻接表和优先队列实现 $\texttt{Dijkstra}$，确保高效。
