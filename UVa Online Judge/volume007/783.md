## 题目描述

两个城镇 $T1$ 和 $T2$ 通过一条双轨铁路连接，它们之间的距离为 $d$ 米。从 $T1$ 开往 $T2$ 的火车每隔 $t_1$ 秒发出一趟，速度为 $v_1$ 米/秒；从 $T2$ 开往 $T1$ 的火车每隔 $t_2$ 秒发出一趟，速度为 $v_2$ 米/秒。

要求在时间区间 $[0, t_f]$ 秒内，计算在这条铁路上发生的火车相遇次数。规定：
- 在时刻 $0$，两列火车同时分别从 $T1$ 和 $T2$ 出发；
- 所有输入输出数据均为整数。

## 问题分析

### 1. 基本概念

对于从 $T1$ 出发的第 $i$ 列火车（$i = 0, 1, 2, \dots$）：
- 出发时刻：$a_i = i \times t_1$
- 行驶时间：$T_{d1} = \frac{d}{v_1}$
- 在轨道上的时间区间：$[a_i, a_i + T_{d1}]$

对于从 $T2$ 出发的第 $j$ 列火车（$j = 0, 1, 2, \dots$）：
- 出发时刻：$b_j = j \times t_2$
- 行驶时间：$T_{d2} = \frac{d}{v_2}$
- 在轨道上的时间区间：$[b_j, b_j + T_{d2}]$

### 2. 相遇条件推导

两列火车在轨道上相遇，意味着存在一个时刻 $t$，使得：
1. 两列火车都在轨道上行驶（即 $t$ 同时属于两个时间区间）；
2. 两列火车行驶的距离之和等于轨道全长 $d$。

设相遇时刻为 $t$，则：
- 从 $T1$ 出发的火车行驶距离：$(t - a_i) v_1$
- 从 $T2$ 出发的火车行驶距离：$(t - b_j) v_2$

相遇时满足：
$$(t - a_i) v_1 + (t - b_j) v_2 = d$$

整理得：
$$t(v_1 + v_2) = d + a_i v_1 + b_j v_2$$
$$t = \frac{d + a_i v_1 + b_j v_2}{v_1 + v_2}$$

### 3. 相遇的约束条件

求得的相遇时刻 $t$ 必须同时满足：
- $t \ge \max(a_i, b_j)$（两车都已出发）
- $t \le \min(a_i + T_{d1}, b_j + T_{d2})$（两车都未到达终点）
- $0 \le t \le t_f$（在考察的时间范围内）

### 4. 关键边界问题

需要注意的是，即使某列火车的出发时间较晚，只要相遇时刻 $t$ 不超过 $t_f$，且两车都在轨道上，就应该计入相遇次数。例如，$i=2$ 出发的列车（$a_2 = 2t_1$）可能与 $j=0$ 出发的列车在 $t=2$ 秒相遇，只要 $t \le t_f$ 就应当计数。

因此，枚举范围不能简单地限制在出发时刻不超过 $t_f$ 的列车，而应考虑出发时刻不超过 $t_f + T_{d1}$（或 $t_f + T_{d2}$）的列车，因为出发较晚的列车仍可能在 $t_f$ 之前与较早出发的列车相遇。

## 解题思路

### 1. 枚举范围确定

对于 $i$ 的最大值：如果出发时刻 $a_i > t_f + T_{d1}$，那么即使出发后立即相遇，相遇时间也会大于 $t_f$，所以：
$$i_{max} = \left\lfloor \frac{t_f + T_{d1}}{t_1} \right\rfloor + 2$$

同样对于 $j$：
$$j_{max} = \left\lfloor \frac{t_f + T_{d2}}{t_2} \right\rfloor + 2$$

这里多加 $2$ 是为了防止浮点数精度问题导致的边界漏判。

### 2. 算法步骤

1. 读入数据 $d, v_1, v_2, t_1, t_2, t_f$；
2. 计算单程行驶时间 $T_{d1} = d / v_1$ 和 $T_{d2} = d / v_2$；
3. 确定枚举上界 $maxI$ 和 $maxJ$；
4. 双重循环枚举所有可能的 $(i, j)$ 组合；
5. 对每组 $(i, j)$ 计算相遇时刻 $t = \frac{d + i t_1 v_1 + j t_2 v_2}{v_1 + v_2}$；
6. 检查 $t$ 是否满足所有约束条件：
   - $t \ge \max(i t_1, j t_2)$
   - $t \le i t_1 + T_{d1}$
   - $t \le j t_2 + T_{d2}$
   - $0 \le t \le t_f$
7. 统计满足条件的相遇次数。

### 3. 时间复杂度分析

枚举范围约为 $\frac{t_f}{t_1} \times \frac{t_f}{t_2}$ 量级。由于 $t_1, t_2$ 通常不会太小，这种直接枚举的方法在实际数据范围内是可行的。

### 4. 注意事项

- **浮点数精度**：比较时间时引入一个很小的误差容限（如 $10^{-9}$），避免因浮点运算误差导致的边界判断错误；
- **边界包含**：列车刚好在到达时刻相遇也应计数，因此检查 $t \le a_i + T_{d1}$ 时需包含等号；
- **出发时刻约束**：$t$ 必须大于等于两车中较晚的出发时刻，因为只有两车都出发后才能相遇。

## 样例验证

输入：$10\ 5\ 5\ 1\ 1\ 2$

计算过程：
- $T_{d1} = 10 / 5 = 2$ 秒，$T_{d2} = 10 / 5 = 2$ 秒；
- 相遇时刻公式：$t = \frac{10 + i \times 5 + j \times 5}{10} = 1 + 0.5(i + j)$

枚举所有可能的 $(i, j)$ 组合：

| $i$ | $j$ | $t$ | 是否满足条件 | 说明 |
|-----|-----|-----|--------------|------|
| $0$ | $0$ | $1.0$ | ✅ | 两车同时出发，$t=1$ 秒相遇 |
| $1$ | $0$ | $1.5$ | ✅ | $i=1$ 在 $1$ 秒出发，与 $j=0$ 相遇 |
| $0$ | $1$ | $1.5$ | ✅ | $j=1$ 在 $1$ 秒出发，与 $i=0$ 相遇 |
| $1$ | $1$ | $2.0$ | ✅ | 两车都在 $1$ 秒出发，$t=2$ 秒相遇 |
| $2$ | $0$ | $2.0$ | ✅ | $i=2$ 在 $2$ 秒出发，与 $j=0$ 在 $t=2$ 秒相遇 |
| $0$ | $2$ | $2.0$ | ✅ | $j=2$ 在 $2$ 秒出发，与 $i=0$ 在 $t=2$ 秒相遇 |

其他组合出发时间过晚或相遇时间超过 $t_f$。

共 $6$ 次相遇，与题目预期一致。

## 代码实现

```cpp
// Trains
// UVa ID: 783
// Verdict: Accepted
// Submission Date: 2026-02-27
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int d, v1, v2, t1, t2, tf;
    while (cin >> d >> v1 >> v2 >> t1 >> t2 >> tf) {
        int cnt = 0;
        double Td1 = static_cast<double>(d) / v1;   // T1到T2单程时间
        double Td2 = static_cast<double>(d) / v2;   // T2到T1单程时间
        
        // 枚举上界，多加2避免边界漏判
        int maxI = (tf + Td1) / t1 + 2;
        int maxJ = (tf + Td2) / t2 + 2;
        
        for (int i = 0; i <= maxI; i++) {
            double a = i * t1;                       // T1出发时刻
            if (a > tf + Td1 + 1e-9) break;          // 出发太晚，后续更晚
            
            for (int j = 0; j <= maxJ; j++) {
                double b = j * t2;                    // T2出发时刻
                if (b > tf + Td2 + 1e-9) break;       // 出发太晚
                
                // 计算相遇时刻
                double t = (d + a * v1 + b * v2) / (v1 + v2);
                
                if (t < -1e-9 || t > tf + 1e-9) continue;   // 相遇时间超出范围
                if (t + 1e-9 < max(a, b)) continue;         // 未出发不能相遇
                
                // 检查是否在轨道上（允许微小浮点误差）
                if (t > a + Td1 + 1e-9) continue;
                if (t > b + Td2 + 1e-9) continue;
                
                cnt++;
            }
        }
        
        cout << cnt << endl;
    }
    return 0;
}
```
