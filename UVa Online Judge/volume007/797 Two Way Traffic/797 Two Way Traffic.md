## 题目描述

一条高速公路穿过一个长度为 $d$ 米的隧道。东行交通流量为每 $t_1$ 秒一辆车，西行交通流量为每 $t_2$ 秒一辆车。东行车辆以恒定速度 $v_1$ 米/秒行驶，西行车辆以恒定速度 $v_2$ 米/秒行驶。

计算在闭时间区间 $[t_i, t_f]$（秒）内，隧道内部发生的车辆“会合”次数。已知：

- 会合点若位于隧道入口之间（不包括入口本身）则视为在隧道内部；
- 在 $t = 0$ 时，有一辆东行车辆距隧道入口 $d_1$ 米，另有一辆西行车辆距隧道入口 $d_2$ 米，这两辆车属于既有的车流。

所有输入输出数据均为整数。参数取值范围：

- $0 \le d, d_1, d_2 \le 100000$  
- $0 < t_1, t_2 \le 10000$  
- $-10000 \le t_i, t_f \le 10000$

## 输入格式

输入文件包含多组数据。每组数据占一行，格式为：

`d d1 d2 v1 v2 t1 t2 ti tf`

数据保证正确。

## 输出格式

对于每组数据，输出一行一个整数，表示隧道内发生的会合次数。

## 样例

**样例输入**  
```
1 0 0 1 1 1 1 0 10
2 1 1 1 1 1 1 0 1
3 2 1 1 1 1 1 0 0
3 2 1 1 1 1 1 1 1
3 2 1 1 1 1 1 0 1
6525 100000 55000 22 33 3 4 -10000 -3600
10 4 2 2 7 263450
```

**样例输出**  

```
10
4
2
2
7
263450
```

## 题目分析

本题需要统计在给定时间区间内，所有相向行驶的车辆对在隧道内部相遇的次数。车辆以固定的时间间隔发车，且速度恒定，因此每辆车的运动轨迹完全由其进入隧道的时刻决定。

设东行车辆进入隧道的时刻为  
$$
E_k = \frac{d_1}{v_1} + k \cdot t_1 \quad (k \in \mathbb{Z})
$$
西行车辆进入隧道的时刻为  
$$
W_j = \frac{d_2}{v_2} + j \cdot t_2 \quad (j \in \mathbb{Z})
$$

其中 $k$ 和 $j$ 为整数编号（可以为负，表示 $0$ 时刻之前已进入隧道的车辆）。

若一辆东行车在时刻 $E_k$ 进入隧道，一辆西行车在时刻 $W_j$ 进入隧道，则它们会在隧道内相遇，当且仅当：

1. 相遇时刻 $t$ 落在闭区间 $[t_i, t_f]$ 内；
2. 相遇位置严格位于隧道内部（即 $0 < x < d$）。

根据运动学，两车相遇的时刻为  
$$
t = \frac{d + v_1 E_k + v_2 W_j}{v_1 + v_2}
$$
相遇位置为  
$$
x = v_1 (t - E_k) = \frac{v_1 \big(d + v_2 (W_j - E_k)\big)}{v_1 + v_2}
$$

条件 $0 < x < d$ 等价于  
$$
-\frac{d}{v_2} < W_j - E_k < \frac{d}{v_1}
$$

将 $E_k, W_j$ 代入并乘以 $v_1 v_2$ 以消除分母，得到关于整数 $k, j$ 的两个线性不等式组。

因此，问题转化为：在二维整数格点 $(k, j)$ 中，统计满足一组线性不等式条件的点对数量。由于每一组数据中，$k$ 与 $j$ 的范围可能较大（因为时间区间跨度可达 $20000$ 秒），不能直接双重枚举，需要利用线性不等式的单调性进行优化。

## 解题思路

### 1. 约束条件转化为整数线性不等式

设  
$$
C = d + d_1 + d_2
$$
将 $E_k$ 和 $W_j$ 代入相遇时刻公式，得到相遇时刻 $t$ 为  
$$
t = \frac{C + v_1 t_1 k + v_2 t_2 j}{v_1 + v_2}
$$

时间条件 $t_i \le t \le t_f$ 等价于  
$$
t_i (v_1 + v_2) \le C + v_1 t_1 k + v_2 t_2 j \le t_f (v_1 + v_2)
$$

位置条件 $0 < x < d$ 等价于  
$$
-d v_1 < (d_2 v_1 - d_1 v_2) + v_1 v_2 (j t_2 - k t_1) < d v_2
$$

对于固定的 $k$，上面两个不等式均为关于 $j$ 的线性不等式（系数 $v_2 t_2$ 和 $v_1 v_2 t_2$ 均为正数），因此可以直接解出 $j$ 的整数上下界，取交集后区间长度即为该 $k$ 对应的可行 $j$ 的数量。

### 2. 枚举范围的确定

我们只需枚举那些在时间区间内有可能进入隧道并与对方车辆相遇的东行车辆。一辆东行车若要在时间区间内相遇，它进入隧道的时刻 $E_k$ 必须满足  
$$
t_i - \frac{d}{v_1} \le E_k \le t_f
$$
否则，即使与西行车同时进入，相遇时刻也会超出区间或根本不在隧道内相遇。

由此可得到 $k$ 的整数范围：

$$
k_{\min} = \left\lceil \frac{t_i v_1 - d - d_1}{t_1 v_1} \right\rceil, \quad
k_{\max} = \left\lfloor \frac{t_f v_1 - d_1}{t_1 v_1} \right\rfloor
$$

同样，也可以枚举西行车辆，但二者之一即可，因为对于每个 $k$，所有满足条件的 $j$ 都可通过不等式直接求出。

### 3. 区间计数

对于每个枚举的 $k$，按如下步骤计算：

- 由时间条件解出 $j$ 的区间 $[j_{\textit{time\_low}}, j_{\textit{time\_high}}]$；
- 由位置条件解出 $j$ 的严格开区间，转换为整数闭区间 $[j_{\textit{pos\_low}}, j_{\textit{pos\_high}}]$；
- 取两个区间的交集，长度即为该 $k$ 下可行的 $j$ 的数量，累加至答案。

因为不等式均为线性且系数为正，上下界的计算可用整数除法的向上/向下取整实现，避免了浮点数误差。

### 4. 边界处理

注意位置条件是严格不等式 $0 < x < d$，因此解出的 $j$ 上下界需要排除等号情况，即左边界要加 $1$，右边界要减 $1$。

时间条件是闭区间，可直接使用 $\le$ 和 $\ge$。

### 5. 复杂度分析

枚举的 $k$ 数量约为  
$$
\frac{t_f - t_i}{t_1} + O(1)
$$
在最坏情况下，时间区间长度为 $20000$ 秒，$t_1$ 最小为 $1$，故最多枚举约 $20000$ 个 $k$。对于每个 $k$，计算 $j$ 的区间为常数时间，因此总时间复杂度为 $O(\text{区间长度} / t_1)$，完全满足题目要求。空间复杂度为 $O(1)$。

```cpp
// Two Way Traffic

#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

// 向下取整除法 (b > 0)
int64 floor_div(int64 a, int64 b) {
    if (a >= 0) return a / b;
    return - ((-a + b - 1) / b);
}

// 向上取整除法 (b > 0)
int64 ceil_div(int64 a, int64 b) {
    if (a >= 0) return (a + b - 1) / b;
    return - ((-a) / b);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int64 d, d1, d2, v1, v2, t1, t2, ti, tf;
    while (cin >> d >> d1 >> d2 >> v1 >> v2 >> t1 >> t2 >> ti >> tf) {
        int64 ans = 0;
        int64 C = d + d1 + d2;                     // d + v1*(d1/v1) + v2*(d2/v2) 的分子
        // k 的范围：ti - d/v1 <= d1/v1 + k*t1 <= tf
        int64 k_min = ceil_div(ti * v1 - d - d1, t1 * v1);
        int64 k_max = floor_div(tf * v1 - d1, t1 * v1);
        for (int64 k = k_min; k <= k_max; ++k) {
            // 时间条件解 j
            int64 time_low_num = ti * (v1 + v2) - C - v1 * t1 * k;
            int64 time_high_num = tf * (v1 + v2) - C - v1 * t1 * k;
            int64 j_time_low = ceil_div(time_low_num, v2 * t2);
            int64 j_time_high = floor_div(time_high_num, v2 * t2);
            // 位置条件解 j
            // 原式： -d*v1 < (d2*v1 - d1*v2) + v1*v2*(j*t2 - k*t1) < d*v2
            int64 A = (d2 * v1 - d1 * v2) - v1 * v2 * k * t1;
            int64 B = v1 * v2 * t2;   // > 0
            // 左边严格大于：A + B*j > -d*v1  =>  j > (-d*v1 - A)/B
            int64 j_pos_low = floor_div(-d * v1 - A, B) + 1;
            // 右边严格小于：A + B*j < d*v2   =>  j < (d*v2 - A)/B
            int64 j_pos_high = ceil_div(d * v2 - A, B) - 1;
            int64 j_low = max(j_time_low, j_pos_low);
            int64 j_high = min(j_time_high, j_pos_high);
            if (j_low <= j_high) ans += j_high - j_low + 1;
        }
        cout << ans << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于将动态的车辆相遇问题转化为静态的整数线性不等式组，通过枚举一个维度的变量，利用线性不等式的单调性在另一维度上直接计算可行区间，从而避免了双重循环。解题过程中需要特别注意：

- 严格不等号与闭区间的转换（位置条件为开区间，需加减 $1$）；
- 整数除法的正确取整（向上取整与向下取整）；
- 变量范围较大时使用 `long long` 避免溢出。

该技巧在处理周期性事件计数问题中具有通用性，例如周期性轨道交汇、信号周期同步等场景，均可通过将时间离散化为整数倍周期并利用线性不等式求解。
