[UVa 802 Lead or Gold](https://blog.csdn.net/metaphysis/article/details/157723887)

## 题目描述

炼金术士们发现，将三种化学物质 **$\texttt{Algonene}$**、 **$\texttt{Basicine}$** 和 **$\texttt{Cobolase}$**（简称 `A`、`B`、`C`）按特定比例混合，可以制造出能将铅转化为金的混合物。 但是，这三种物质通常不是单独出售，而是预先混合成若干种**已知比例**的溶液。 题目给出 $n$ 种已知比例的溶液（第 $i$ 种比例为 $a_i : b_i : c_i$），并询问能否通过将若干份这些溶液混合，得到一种**目标比例** $a : b : c$ 的溶液。 混合时，每种已知溶液可以取任意**非负**份数（可以是分数，但比例是有理数，所以可以通分转化为整数份数问题）。

**输入** 包含多个测试用例。 每个测试用例格式为： 第一行是整数 $n$ $(0 \le n < 100)$， 接下来 $n$ 行每行三个非负整数 $a_i, b_i, c_i$（至少一个为正）， 最后一行是三个非负整数 $a, b, c$（至少一个为正）。 输入以一行单独的 $0$ 结束。

**输出** 对于每个测试用例，先输出 `Mixture k`（$k$ 为测试序号），再输出 `Possible` 或 `Impossible`。

---

## 题目分析

这是一个典型的**向量线性组合**问题。 我们可以将每种已知溶液视为一个三维向量 $\vec{v_i} = (a_i, b_i, c_i)$， 将目标溶液视为向量 $\vec{t} = (a, b, c)$。 我们的问题是：是否存在一组**非负实数**系数 $x_1, x_2, \dots, x_n$（每种溶液所取的“份数”），使得

$$
x_1 \vec{v_1} + x_2 \vec{v_2} + \dots + x_n \vec{v_n} = \vec{t}
$$

成立？

由于比例具有**齐次性**（所有分量乘以同一个正数 $k$，比例不变），所以实际上我们只关心向量的**方向**，而不是长度。 也就是说，如果存在一组**非负实数**系数使得 $\sum x_i \vec{v_i}$ 与 $\vec{t}$ **同方向**（即平行且同向），那么我们就可以通过缩放得到完全相等的向量。

因此，问题转化为： **目标向量 $\vec{t}$ 是否位于由已知向量集 $\{ \vec{v_i} \}$ 所张成的凸锥（$\texttt{convex cone}$）内？**

**凸锥** 是指所有形如 $\sum_{i=1}^n \lambda_i \vec{v_i}$（其中 $\lambda_i \ge 0$）的向量构成的集合。 我们的目标就是判断 $\vec{t}$ 是否在这个锥内。

---

## 解题思路

判断一个向量是否在凸锥内，在计算几何中是一个经典问题。 对于三维空间，一个实用的方法是： **一个向量在凸锥内的充要条件是，它可以表示为至多三个已知向量的非负线性组合**（$\texttt{Carathéodory}$ 定理在锥情形下的结论）。 这是因为锥是凸的，而三维空间的锥可以由其**极方向**（即已知向量）生成，任何锥内点都可以由不超过三个极方向的非负组合表示。

因此，我们不需要考虑所有 $n$ 个向量，只需要检查所有**至多三个向量**的组合能否线性表示出 $\vec{t}$。 具体来说，我们需要检查以下三种情况：

1.  **单个向量**： 目标向量 $\vec{t}$ 必须与某个已知向量 $\vec{v_i}$ 平行且同向。 即 $\vec{v_i} \times \vec{t} = \vec{0}$（叉积为零表示平行）且 $\vec{v_i} \cdot \vec{t} > 0$（点积为正表示同向，注意两者均非零向量）。 如果 $\vec{t}$ 是零向量，则需要 $\vec{v_i}$ 也是零向量，但题目规定至少一个分量为正，所以零向量目标不可能由单个非零向量得到（除非没有已知溶液且目标也是零向量，但这种情况输入已排除）。

2.  **两个向量**： 如果两个已知向量 $\vec{v_i}$ 和 $\vec{v_j}$ **平行**（$\vec{v_i} \times \vec{v_j} = \vec{0}$），那么它们张成的锥退化成一条线。 此时只需要 $\vec{t}$ 与它们平行且方向相同（即与其中一个点积非负）即可。

    如果两个向量**不平行**，则它们张成一个二维平面上的锥（过原点的扇形）。 此时，$\vec{t}$ 必须满足两个条件：
    *   $\vec{t}$ 与 $\vec{v_i}$、$\vec{v_j}$ **共面**，即 $\vec{t} \cdot (\vec{v_i} \times \vec{v_j}) = 0$。
    *   在二维平面上，$\vec{t}$ 可以表示为 $\vec{v_i}$ 和 $\vec{v_j}$ 的非负线性组合。 我们可以任意选取两个线性无关的分量（例如 $x$ 和 $y$ 分量），构成一个二维线性方程组，用克莱姆法则求解组合系数 $p, q$，并检查它们是否非负。

3.  **三个向量**： 如果三个向量 $\vec{v_i}$、$\vec{v_j}$、$\vec{v_k}$ **线性无关**（即它们的混合积 $\vec{v_i} \cdot (\vec{v_j} \times \vec{v_k}) \ne 0$），那么它们张成整个三维空间的正卦限部分。 此时，任何目标向量 $\vec{t}$ 理论上都可以被表示，但系数必须非负。 我们可以使用三维的克莱姆法则求解系数 $p, q, r$：
    $$
    \begin{aligned}
    p &= \frac{\vec{t} \cdot (\vec{v_j} \times \vec{v_k})}{\vec{v_i} \cdot (\vec{v_j} \times \vec{v_k})} \\
    q &= \frac{\vec{t} \cdot (\vec{v_k} \times \vec{v_i})}{\vec{v_i} \cdot (\vec{v_j} \times \vec{v_k})} \\
    r &= \frac{\vec{t} \cdot (\vec{v_i} \times \vec{v_j})}{\vec{v_i} \cdot (\vec{v_j} \times \vec{v_k})}
    \end{aligned}
    $$
    我们并不需要真正进行除法（避免浮点误差），只需要判断分子与分母的符号关系即可。 如果分母（混合积）为正，则要求三个分子都 $\ge 0$； 如果分母为负，则要求三个分子都 $\le 0$。 这等价于系数 $p, q, r$ 都为非负（因为分母的正负会影响系数的整体符号）。

    **重要细节**： 如果三个向量线性相关（混合积为零），意味着它们共面，这种情况已经包含在“两个向量”的检查中（因为其中至少一个向量可以由另外两个线性表示），所以我们可以跳过混合积为零的三元组。

**算法流程总结**：
1.  读取所有已知向量 $\vec{v_i}$ 和目标向量 $\vec{t}$。
2.  按顺序检查：
    *   单个向量能否表示 $\vec{t}$。
    *   任意两个向量能否表示 $\vec{t}$。
    *   任意三个线性无关的向量能否用非负系数表示 $\vec{t}$。
3.  只要任何一种情况成立，答案就是 `Possible`，否则为 `Impossible`。

**时间复杂度**： 最多有 $100$ 个向量，检查所有单个、两个、三个向量的组合是 $O(n^3)$，在 $n=100$ 时约为 $10^6$ 量级，完全可以接受。

## 代码实现

```cpp
// Lead or Gold
// UVa ID: 802
// Verdict: Accepted
// Submission Date: 2026-02-02
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Vector {
    long long a, b, c;
    Vector(long long a = 0, long long b = 0, long long c = 0) : a(a), b(b), c(c) {}
    Vector operator-(const Vector& other) const { return Vector(a - other.a, b - other.b, c - other.c); }
    bool isZero() const { return a == 0 && b == 0 && c == 0; }
};

// 点积
long long dot(const Vector& u, const Vector& v) {
    return u.a * v.a + u.b * v.b + u.c * v.c;
}

// 叉积
Vector cross(const Vector& u, const Vector& v) {
    return Vector(u.b * v.c - u.c * v.b, u.c * v.a - u.a * v.c, u.a * v.b - u.b * v.a);
}

// 判断目标向量 target 是否可以由向量 x 和 y 的非负线性组合得到（二维情况）
bool checkTwo(const Vector& x, const Vector& y, const Vector& target) {
    // 选取两个不相关的分量进行二维判断
    for (int p = 0; p < 3; p++)
    for (int q = p + 1; q < 3; q++) {
        long long a1 = (p == 0 ? x.a : (p == 1 ? x.b : x.c));
        long long b1 = (q == 0 ? x.a : (q == 1 ? x.b : x.c));
        long long a2 = (p == 0 ? y.a : (p == 1 ? y.b : y.c));
        long long b2 = (q == 0 ? y.a : (q == 1 ? y.b : y.c));
        long long c1 = (p == 0 ? target.a : (p == 1 ? target.b : target.c));
        long long c2 = (q == 0 ? target.a : (q == 1 ? target.b : target.c));
        long long det = a1 * b2 - a2 * b1; // 二维行列式
        if (det == 0) continue; // 两向量在该投影上平行，换一组分量
        long long xNum = c1 * b2 - c2 * b1; // 对应 x 系数的分子
        long long yNum = a1 * c2 - a2 * c1; // 对应 y 系数的分子
        // 根据分母正负判断分子符号是否都非负
        if (det > 0) { if (xNum >= 0 && yNum >= 0) return true; }
        else { if (xNum <= 0 && yNum <= 0) return true; }
    }
    return false;
}

int main() {
    int n, testCase = 0;
    bool firstCase = true;
    while (cin >> n && n != 0) {
        if (firstCase) firstCase = false;
        else cout << endl; // 测试用例之间输出空行
        testCase++;
        vector<Vector> mixtures(n);
        for (int i = 0; i < n; i++) cin >> mixtures[i].a >> mixtures[i].b >> mixtures[i].c;
        Vector target;
        cin >> target.a >> target.b >> target.c;

        bool possible = false;
        // 情况1: 检查单个向量
        for (int i = 0; i < n && !possible; i++) {
            // 平行且同向
            if (cross(mixtures[i], target).isZero() && dot(mixtures[i], target) > 0) possible = true;
        }
        // 情况2: 检查两个向量的组合
        for (int i = 0; i < n && !possible; i++)
        for (int j = i + 1; j < n && !possible; j++) {
            Vector cr = cross(mixtures[i], mixtures[j]);
            if (cr.isZero()) {
                // 平行情况，只要目标与其中之一平行且同向即可
                if (cross(mixtures[i], target).isZero()) {
                    if (dot(mixtures[i], target) >= 0 || dot(mixtures[j], target) >= 0) possible = true;
                }
            } else {
                // 不平行，需要共面且可非负表示
                if (dot(target, cr) == 0 && checkTwo(mixtures[i], mixtures[j], target)) possible = true;
            }
        }
        // 情况3: 检查三个线性无关向量的组合
        for (int i = 0; i < n && !possible; i++)
        for (int j = i + 1; j < n && !possible; j++)
        for (int k = j + 1; k < n && !possible; k++) {
            Vector v1 = mixtures[i], v2 = mixtures[j], v3 = mixtures[k];
            long long denom = dot(v3, cross(v1, v2)); // 混合积，即分母
            if (denom == 0) continue; // 线性相关，跳过（已由两向量覆盖）
            long long xNum = dot(target, cross(v2, v3)); // p 的分子
            long long yNum = dot(target, cross(v3, v1)); // q 的分子
            long long zNum = dot(target, cross(v1, v2)); // r 的分子
            // 根据分母正负判断所有分子是否同号且非负（相对于分母）
            if (denom > 0) { if (xNum >= 0 && yNum >= 0 && zNum >= 0) possible = true; }
            else { if (xNum <= 0 && yNum <= 0 && zNum <= 0) possible = true; }
        }

        cout << "Mixture " << testCase << endl;
        cout << (possible ? "Possible" : "Impossible") << endl;
    }
    return 0;
}
```

## 关键点与注意事项

1.  **整数运算**： 为避免浮点数精度误差，全程使用整数（`long long`）进行点积、叉积和行列式计算。
2.  **符号判断代替除法**： 在判断系数非负时，我们只关心分子与分母的符号关系，不进行实际的除法运算，保证了正确性。
3.  **退化情况处理**： 当两个向量平行或三个向量共面时，问题会降维。 代码中通过 `cross().isZero()` 和 `dot(target, cr) == 0` 等条件进行判断，并调用相应的低维处理逻辑。
4.  **零向量**： 题目保证已知向量和目标向量至少有一个分量为正，所以零向量不会出现在输入中，简化了边界判断。
5.  **输出格式**： 注意测试用例之间的空行，以及最后一个测试用例后不要有多余空行。

此题本质是**线性规划**在低维（三维）下的特例，利用几何性质可以高效解决。 理解向量、叉积、混合积的几何意义是解题的关键。
