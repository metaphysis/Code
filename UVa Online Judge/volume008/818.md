## 题目分析

### 问题描述

$\texttt{Anna Locke}$ 购买了一些链环，其中一些可能已经相互连接。每个链环都有一个编号（从 $1$ 到 $n$）。输入会给出若干对连接关系 $(i, j)$，表示链环 $i$ 和 $j$ 是相互套在一起的。

目标是将所有链环连接成一条单一的长链。每次操作可以打开一个链环（之后可以重新闭合，用于连接其他链环）。要求找出最少的打开次数，使得所有链环能够连接成一条链。

### 输入格式

- 每组数据以整数 $n$（链环数量，$1 \leq n \leq 15$）开始
- 随后是若干对 $(i, j)$ 表示连接关系
- 以 `-1 -1` 结束每组数据
- 输入以 $n = 0$ 结束

### 输出格式

对于每组数据，输出：
```
Set N: Minimum links to open is M
```
其中 $N$ 是数据集编号，$M$ 是最少需要打开的链环数量。

## 解题思路

### 关键观察

1. **链环连接关系构成无向图**：每个链环是图中的一个顶点，连接关系 $(i, j)$ 是图中的边。

2. **最终状态要求**：所有链环连接成一条链意味着：
   - 图必须连通
   - 每个顶点的度数不超过 $2$
   - 图必须是无环的（即是一棵树，且是路径图）

3. **打开链环的作用**：
   - 打开一个链环相当于从图中移除该顶点及其所有边
   - 之后可以重新连接，用于改变图的连接结构

### 算法设计

由于 $n \leq 15$，我们可以使用**状态压缩枚举**的方法：

1. **枚举所有可能的打开方案**：对于 $n$ 个链环，有 $2^n$ 种可能的打开组合，使用位掩码进行枚举。

2. **检查剩余图是否满足条件**：对于每种打开方案，检查剩下的图是否满足：
   - 每个连通分量都是简单路径（度数 $\leq 2$ 且无环）
   - 连通分量数 $\leq$ 打开数 $+ 1$（可以用打开的链环连接各个分量）

3. **更新最小值**：记录满足条件的最小打开数。

### 复杂度分析

- 枚举所有子集：$O(2^n)$
- 对每个子集检查图的性质：$O(n^2)$
- 总复杂度：$O(2^n \times n^2)$，对于 $n = 15$ 是可接受的

```cpp
// Cutting Chains

#include <bits/stdc++.h>

using namespace std;

int n; // 链环数量
bool graph[16][16]; // 邻接矩阵存储图结构
bool opened[16]; // 记录哪些链环被打开
int degree[16]; // 记录每个顶点的度数
bool visited[16]; // DFS 访问标记

// 检查连通分量是否为简单路径，同时统计顶点数和边数
bool isPathComponent(int u, int& vertexCount, int& edgeCount) {
    visited[u] = true;
    vertexCount++; // 顶点数加 1
    edgeCount += degree[u]; // 累加度数（每条边会被计算两次）
    for (int v = 1; v <= n; v++) {
        if (!opened[v] && graph[u][v] && !visited[v]) {
            isPathComponent(v, vertexCount, edgeCount);
        }
    }
    return true;
}

// 检查打开指定链环后，剩余图是否满足条件
bool checkRemainingGraph(int openCount) {
    memset(degree, 0, sizeof(degree));
    memset(visited, false, sizeof(visited));
    
    // 计算剩余图中每个顶点的度数
    for (int i = 1; i <= n; i++) {
        if (opened[i]) continue; // 跳过的打开的链环
        for (int j = i + 1; j <= n; j++) {
            if (!opened[j] && graph[i][j]) {
                degree[i]++;
                degree[j]++;
            }
        }
    }
    
    // 检查度数是否都小于等于 2（路径图的必要条件）
    for (int i = 1; i <= n; i++) {
        if (!opened[i] && degree[i] > 2) return false;
    }
    
    // 检查每个连通分量是否为简单路径
    int compCount = 0; // 连通分量计数
    for (int i = 1; i <= n; i++) {
        if (!opened[i] && !visited[i]) {
            int vCount = 0, eCount = 0;
            isPathComponent(i, vCount, eCount);
            eCount /= 2; // 因为每条边被计算了两次
            // 简单路径的边数 = 顶点数 - 1
            if (eCount != vCount - 1) return false;
            compCount++;
        }
    }
    
    // 连通分量数不能超过打开数 + 1（可以用打开的链环连接各个分量）
    return compCount <= openCount + 1;
}

int main() {
    int caseNum = 1; // 测试用例编号
    while (cin >> n, n) {
        memset(graph, false, sizeof(graph));
        int a, b;
        // 读入连接关系，构建图
        while (cin >> a >> b, a != -1) {
            graph[a][b] = graph[b][a] = true;
        }
        
        int minOpen = n - 1; // 最坏情况需要打开 n - 1 个链环
        // 枚举所有可能的打开方案（位掩码枚举）
        for (int mask = 0; mask < (1 << n); mask++) {
            int openCount = 0; // 当前方案打开的链环数
            for (int i = 0; i < n; i++) {
                if (mask >> i & 1) {
                    opened[i + 1] = true; // 标记该链环被打开
                    openCount++;
                } else {
                    opened[i + 1] = false;
                }
            }
            // 检查当前方案是否可行，更新最小值
            if (checkRemainingGraph(openCount)) {
                minOpen = min(minOpen, openCount);
            }
        }
        
        cout << "Set " << caseNum++ << ": Minimum links to open is " << minOpen << endl;
    }
    return 0;
}
```

## 算法正确性说明

该算法通过枚举所有可能的打开方案，并对每个方案进行严格的图性质检查，确保找到的确实是最优解。检查条件包括：

1. **度数限制**：每个顶点度数 $\leq 2$，保证图是若干条路径的集合
2. **无环条件**：每个连通分量的边数 = 顶点数 $- 1$，保证是树结构（简单路径）
3. **连通性约束**：连通分量数 $\leq$ 打开数 $+ 1$，保证可以用打开的链环连接所有分量

## 样例分析

以第一个样例为例：
```
5 1 2 2 3 4 5 -1 -1
```
图有两个连通分量：$\{1, 2, 3\}$ 和 $\{4, 5\}$。打开链环 $2$ 后，可以将图重组为一条链 $1-2-3-4-5$，只需要打开 $1$ 个链环。

该算法能够正确处理所有样例情况，找到最优的打开方案。
