## 题目描述

$\texttt{ACME}$ 公司向客户销售商品，客户通常在发货后 30 天内付款，但存在客户无法履约的风险。公司为每个客户设定了债务上限，低于上限的部分由金融保险公司承保，超出部分由 $\texttt{ACME}$ 公司自担风险。

为了评估是否需要与保险公司重新谈判债务上限，$\texttt{CEO}$ 需要知道当前有多少比例的债务没有被保险覆盖。财务部门使用以下公式计算未覆盖风险百分比：

$$
\frac{\sum_{c} \int_{t_0}^{t_1} \max(D_c(t) - L_c, 0)}{\sum_{c} \int_{t_0}^{t_1} D_c(t)}
$$

其中 $D_c(t)$ 是客户 $c$ 在时间 $t$ 的债务函数（阶跃函数），$L_c$ 是该客户的债务上限。分子是未覆盖风险（债务超出上限部分的面积），分母是总风险（债务总面积）。

### 输入格式

- 第一行是一个正整数，表示测试用例数量。用例之间有一个空行。
- 每个测试用例：第一行是客户数量。
- 对于每个客户：
  - 第一行包含债务上限和销售次数 $n$。
  - 接下来 $n$ 行，每行三个整数：销售金额、发票日期（一年中的第几天）、收款日期（一年中的第几天）。

### 输出格式

每个测试用例输出一行，包含截断到两位小数的未覆盖风险百分比，后跟百分号 `%`。两个用例之间输出一个空行。

### 样例

**输入**

```
1

2
40000 3
35000 32 61
15000 45 72
40000 97 123
55000 4
12000 10 52
30000 32 64
33000 44 73
50000 62 94
```

**输出**

```
11.85%
```

## 题目分析

### 1. 债务函数的理解

每个客户的债务随时间变化是一个**分段常数函数**（阶跃函数）。债务的变化只发生在两个时刻：

- **发票日**：销售发生后，客户债务增加（增加金额等于销售金额）。
- **收款日**：客户付款后，债务减少（减少金额等于销售金额）。

例如，客户有一笔销售：金额 $1000$，发票日 $10$，收款日 $50$。那么：
- 在 $t < 10$ 时，这笔销售不影响债务。
- 在 $10 \le t < 50$ 时，债务增加 $1000$。
- 在 $t \ge 50$ 时，债务减少 $1000$。

### 2. 风险计算方式

风险定义为债务函数与时间轴围成的**面积**，即积分 $\int D_c(t) dt$。由于债务函数是分段的，总面积可以通过在每个时间区间上计算面积后累加得到。

**总风险**：
$$
totalRisk = \sum_{\text{每个区间}} (\text{债务} \times \text{区间长度})
$$

**未覆盖风险**（超出债务上限的部分）：
$$
uncoveredRisk = \sum_{\text{每个区间}} \max(\text{债务} - L_c, 0) \times \text{区间长度}
$$

### 3. 时间区间划分

因为债务只在特定日期发生变化（发票日或收款日），所以我们可以将这些日期作为**分割点**，将时间轴划分为若干小区间。在每个小区间内，债务是常数。

具体做法：
- 收集所有销售的发货日（增加债务）和收款日（减少债务）作为事件点。
- 将所有事件点按日期排序。
- 相邻两个事件点之间的时间段内，债务保持不变。

例如，如果有事件发生在第 $10$ 天，下一个事件在第 $15$ 天，则区间 $[10, 15)$ 内债务是常数。

### 4. 多个客户的合并

题目要求的是所有客户的**总未覆盖风险**除以**总风险**。因此不能分别计算每个客户的百分比再平均，而应将所有客户的风险累加后再计算：

$$
percent = \frac{\sum uncoveredRisk_c}{\sum totalRisk_c} \times 100\%
$$

### 5. 关键细节

- **日期范围**：题目仅涉及一年中的第几天，因此最大日期不超过 $365$，但实际解题中不需要假设固定范围，直接使用事件点即可。
- **截断到两位小数**：要求截断（$\texttt{truncate}$），而非四舍五入。$\texttt{C++}$ 中可以用 `floor(value * 100) / 100` 实现。
- **同一日期的多笔事件**：同一天可能有多笔销售或收款，需要一次性处理完当天所有事件后再应用债务变化，否则会导致区间划分错误。

## 解题思路

### 1. 数据结构设计

- 用结构体 `Event` 表示一个事件，包含 `day`（发生日期）和 `delta`（债务变化量，正为增加，负为减少）。
- 每个客户的事件列表独立存储，最后分别扫描处理。

### 2. 算法步骤

**步骤一：读入测试用例数量**

**步骤二：对于每个测试用例**

1. 读入客户数量 `numClients`。
2. 初始化 `totalRisk = 0.0` 和 `totalUncoveredRisk = 0.0`。
3. 对于每个客户：
   a. 读入债务上限 `limit` 和销售次数 `numSales`。
   b. 创建空事件列表 `events`。
   c. 对于每一笔销售：
      - 读入 `value`（销售金额）、`invoiceDay`（发票日）、`receiptDay`（收款日）。
      - 添加事件：`{invoiceDay, +value}`（债务增加）。
      - 添加事件：`{receiptDay, -value}`（债务减少）。
   d. 将 `events` 按 `day` 升序排序。
   e. 初始化 `currentDebt = 0`，`prevDay = -1`。
   f. 遍历排序后的事件列表（注意：同一天可能有多个事件）：
      - 如果 `prevDay != -1` 且当前事件日大于 `prevDay`：
        - 区间长度 = `curDay - prevDay`。
        - 总风险 += `currentDebt * 区间长度`。
        - 如果 `currentDebt > limit`：未覆盖风险 += `(currentDebt - limit) * 区间长度`。
      - 然后处理当天所有事件（循环累加 `delta` 到 `currentDebt`）。
      - 更新 `prevDay` 到当前事件日。
   g. 注意：最后一个事件之后不再有变化，不需要额外处理，因为风险面积只覆盖到最后一个事件点。

**步骤三：计算百分比并输出**

$$
percent = \frac{totalUncoveredRisk}{totalRisk} \times 100
$$

- 如果 `totalRisk == 0`，则百分比为 $0$。
- 截断处理：`percent = floor(percent * 100) / 100`。
- 输出格式：`printf("%.2f%%\n", percent)`，其中 `%%` 输出一个百分号。

**步骤四：用例之间输出空行**

### 3. 正确性验证（以样例为例）

样例中有两个客户。

**客户 $1$**：上限 $40000$，3 笔销售。

- 销售 $1$：$35000$，$[32, 61)$ 区间债务 $35000$。
- 销售 $2$：$15000$，$[45, 72)$ 区间债务 $35000+15000=50000$。
- 销售 $3$：$40000$，$[97, 123)$ 区间债务 $40000$。

计算总风险和各区间未覆盖部分，累加后可得其未覆盖风险。

**客户 $2$**：上限 $55000$，$4$ 笔销售。

类似计算。最后总未覆盖风险之和除以总风险之和再乘 $100$ 得到 $11.85\%$，与样例输出一致。

## 复杂度分析

- 每个客户的事件数量：$O(S)$。
- 排序复杂度：$O(S \log S)$。
- 扫描复杂度：$O(S)$。
- 总复杂度：$O(\sum (S \log S))$，在题目约束下完全可行。
- $S$ 表示交易的数量。

## 注意事项

1. **同一天多个事件**：必须确保在同一天内先计算前一个区间，再累加当天所有事件的 `delta`，顺序不能错。
2. **浮点精度**：使用 `double` 存储风险和百分比，精度足够。
3. **截断而非四舍五入**：使用 `floor` 实现截断。
4. **空行处理**：两个测试用例之间需要输出空行，但最后一个用例后不需要多余空行。

```cpp
// Financial Risk
// UVa ID: 832
// Verdict: Accepted

// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Event {
    int day;
    long long delta;  // 债务变化量
};

void solve() {
    int numClients;
    cin >> numClients;

    double totalRisk = 0.0;           // 所有客户的总风险
    double totalUncoveredRisk = 0.0;  // 所有客户的未覆盖风险

    for (int i = 0; i < numClients; ++i) {
        long long limit;  // 债务上限
        int numSales;
        cin >> limit >> numSales;

        vector<Event> events;

        for (int j = 0; j < numSales; ++j) {
            long long value;
            int invoiceDay, receiptDay;
            cin >> value >> invoiceDay >> receiptDay;

            events.push_back({invoiceDay, value});   // 发票日增加债务
            events.push_back({receiptDay, -value});  // 收款日减少债务
        }

        // 按天排序事件
        sort(events.begin(), events.end(), [](const Event& a, const Event& b) {
            return a.day < b.day;
        });

        long long currentDebt = 0;
        int prevDay = -1;

        // 扫描时间轴
        for (size_t j = 0; j < events.size(); ++j) {
            int curDay = events[j].day;

            if (prevDay != -1 && curDay > prevDay) {
                double intervalLen = curDay - prevDay;
                totalRisk += currentDebt * intervalLen;
                if (currentDebt > limit)
                    totalUncoveredRisk += (currentDebt - limit) * intervalLen;
            }

            // 应用当前天的所有变化（同一天可能有多笔）
            currentDebt += events[j].delta;
            prevDay = curDay;
        }
    }

    double percent = (totalRisk == 0) ? 0.0 : (totalUncoveredRisk / totalRisk) * 100.0;
    // 截断到两位小数
    percent = floor(percent * 100.0) / 100.0;

    printf("%.2f%%\n", percent);
}

int main() {
    int caseCount;
    cin >> caseCount;

    for (int caseIdx = 0; caseIdx < caseCount; ++caseIdx) {
        if (caseIdx > 0) cout << endl;  // 用例之间空行
        solve();
    }
    return 0;
}
```
