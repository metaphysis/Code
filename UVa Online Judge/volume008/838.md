## 题目描述

蠕虫世界是一个由 $N \times N$ 网格组成的数字世界，每个格子包含一个正整数。蠕虫在这个网格上移动时遵循特殊的规则：

- 蠕虫可以从任意格子开始爬行
- 每次只能向**上下左右**四个方向移动（不能对角线移动）
- 当蠕虫**第一次**接触到某个数字时，它的免疫系统会被激活
- 如果蠕虫**第二次**接触到相同的数字，它会立即死亡

我们需要找到蠕虫在死亡前能够访问的**最长路径长度**（以访问的格子数量计算）。

### 输入格式

- 第一行：测试用例数量 $T$
- 每个测试用例：
  - 第一行：网格大小 $N$ ($0 < N \leq 12$)
  - 接下来 $N$ 行：每行 $N$ 个正整数（数字小于 $1000$)

### 输出格式

- 对于每个测试用例，输出最长路径长度
- 测试用例之间用空行分隔

### 样例

**输入：**
```
1

3
1 2 1
2 3 4
3 2 1
```

**输出：**
```
4
```

## 题目分析

### 问题本质

这是一个在网格上寻找**最长不重复数字路径**的问题。由于路径上的所有数字必须互不相同，这实际上是一个带有特殊约束的路径搜索问题。

### 关键观察

1. **搜索空间**：网格最大为 $12 \times 12 = 144$ 个格子，但实际路径长度受限于不同数字的数量
2. **约束条件**：路径中不能出现重复数字
3. **移动方式**：只能上下左右移动，形成连通路径

### 算法选择

由于 $N \leq 12$，我们可以使用**深度优先搜索（$\texttt{DFS}$）** 来探索所有可能的路径。但朴素的 $\texttt{DFS}$ 会超时，需要以下优化：

## 解题思路

### 1. 理论最大值剪枝

首先计算网格中**不同数字的总数** $\textit{uniqueCount}$，这代表了理论上的最大可能路径长度。在 $\texttt{DFS}$ 过程中，一旦找到长度为 $\textit{uniqueCount}$ 的路径，就可以立即终止所有搜索。

### 2. 高效的访问标记

使用大小为 $1000$ 的布尔数组 $\textit{numberVisited}$ 来记录哪些数字已经被访问过。这里采用一个巧妙的**反向标记**技巧：

- 进入某个格子时：$\textit{numberVisited}[current] = \texttt{false}$（标记为未访问）
- 检查邻居时：如果 $\textit{numberVisited}[neighbor] = \texttt{false}$，说明该数字可用
- 回溯时：$\textit{numberVisited}[current] = \texttt{true}$（恢复状态）

这种反向标记简化了条件判断。

### 3. 搜索顺序优化

使用**上、左、下、右**的搜索顺序（逆时针方向），这种顺序在实践中表现更好，可能因为：
- 更倾向于沿着边界移动，更快遇到重复数字触发剪枝
- 内存访问模式更友好

### 4. 全局变量优化

使用全局变量来：
- 避免函数参数传递的开销
- 使用固定大小数组替代 $\texttt{vector}$，提高内存访问效率

## 算法步骤

1. **预处理**：
   - 读取网格数据
   - 计算不同数字的数量 $\textit{uniqueCount}$

2. **深度优先搜索**：
   - 从每个格子作为起点开始搜索
   - 使用 $\textit{numberVisited}$ 数组确保路径数字不重复
   - 如果找到长度为 $\textit{uniqueCount}$ 的路径，立即返回

3. **输出结果**：
   - 记录所有搜索中找到的最大路径长度

## 复杂度分析

- **时间复杂度**：最坏情况下 $O(N^2 \times 4^L)$，其中 $L$ 是路径长度
- **空间复杂度**：$O(N^2 + K)$，其中 $K$ 是数字范围（$1000$）

由于剪枝优化，实际运行效率远好于理论最坏情况。

```cpp
// Worm World

#include <bits/stdc++.h>
using namespace std;

int grid[12][12];
int directions[4][2] = {{-1, 0}, {0, -1}, {1, 0}, {0, 1}};  // 上左下右
bool numberVisited[1001];  // 记录数字是否被访问过
int maxAnswer, uniqueCount, gridSize, testCases, currentSteps;

void dfs(int row, int col) {
    if (maxAnswer == uniqueCount) return;  // 找到理论最大值，提前返回
    numberVisited[grid[row][col]] = false;  // 标记当前数字为未访问
    for (int k = 0; k < 4; k++) {
        int newRow = row + directions[k][0];
        int newCol = col + directions[k][1];
        // 边界检查
        if (newRow < 0 || newRow >= gridSize || newCol < 0 || newCol >= gridSize) continue;
        // 数字重复检查
        if (!numberVisited[grid[newRow][newCol]]) continue;
        currentSteps++;
        dfs(newRow, newCol);
        currentSteps--;
    }
    maxAnswer = max(maxAnswer, currentSteps);
    numberVisited[grid[row][col]] = true;  // 恢复当前数字状态
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> testCases;
    for (int caseNum = 0; caseNum < testCases; caseNum++) {
        cin >> gridSize;
        maxAnswer = uniqueCount = 0;
        memset(numberVisited, 0, sizeof(numberVisited));
        // 读取网格并计算不同数字的数量
        for (int i = 0; i < gridSize; i++)
            for (int j = 0; j < gridSize; j++) {
                cin >> grid[i][j];
                if (!numberVisited[grid[i][j]]) {
                    numberVisited[grid[i][j]] = true;
                    uniqueCount++;
                }
            }
        // 从每个格子开始DFS
        for (int i = 0; i < gridSize; i++)
            for (int j = 0; j < gridSize; j++) {
                currentSteps = 1;
                dfs(i, j);
            }
        cout << maxAnswer << '\n';
        if (caseNum < testCases - 1) cout << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于如何高效地剪枝和优化 $\texttt{DFS}$ 搜索。通过理论最大值剪枝、反向标记技巧和搜索顺序优化，我们能够在合理时间内解决这个看似指数复杂度的搜索问题。这种优化思路在解决类似的约束满足问题时非常有用。
