## 题目描述

许多加油站在发光标牌上使用塑料数字来显示价格。当某个数字的数量不够时，工作人员可能会把它倒过来使用另一个数字代替。

数字的翻转规则如下：
- 数字 `0`、`1`、`8` 翻转后保持不变
- 数字 `2` 和 `5` 可以互相翻转
- 数字 `6` 和 `9` 可以互相翻转
- 其他数字不能翻转

由于价格快速上涨，某个加油站已经用完了所有可用的数字来显示当前价格。工作人员可以通过重新排列数字（包括翻转某些数字）来显示更高的价格。

给定当前价格（格式为包含小数点的字符串，小数点总是在最后一个数字之前），要求找出**使用相同数字集合**能够显示的**下一个更高价格**。如果无法提高价格，输出 `"The price cannot be raised."`。

**输入格式**：多行输入，每行包含 $2$ 到 $30$ 个字符（包含一个小数点），最后一行是一个单独的点号表示输入结束。

**输出格式**：对于每个输入，输出下一个更高价格，或无法提高的提示信息。

### 样例输入
```
65.2
76.7
77.7
.
```

### 样例输出
```
65.5
77.6
The price cannot be raised.
```

## 题目分析

本题的核心在于理解数字的**可翻转特性**和**排列组合**的关系。我们需要在保持数字集合不变的前提下，通过重新排列和翻转操作，找到比原价格大的最小价格。

### 关键观察

1. **数字的等效性**：由于翻转操作，某些数字对是等价的（如 $2$ 和 $5$，$6$ 和 $9$），这增加了可用的数字选择。

2. **小数点位置固定**：小数点始终在倒数第二位之前，这影响了数字的权重分布。

3. **前导零限制**：整数部分不能有前导零（除非整个整数部分就是 $0$）。

## 解题思路

### 核心算法：贪心搜索

本解法采用从右向左扫描的贪心策略，寻找第一个可以增大的位置，这与标准库中 `next_permutation` 算法的思想一致。

#### 算法步骤：

1. **预处理**：移除输入字符串中的小数点，便于处理。

2. **从低位到高位扫描**：对于每个位置 $i$（从右向左），尝试两种增大方式：

   - **方式一**：直接翻转当前数字（仅适用于 $2$ 或 $6$）
     - 如果 `price[i]` 是 $2$，翻转为 $5$
     - 如果 `price[i]` 是 $6$，翻转为 $9$
     - 翻转后，将位置 $i+1$ 之后的部分标准化为最小字典序

   - **方式二**：与后面的数字交换
     - 在位置 $i$ 之后寻找可以交换的数字
     - 考虑两种候选：原始数字和翻转后的数字
     - 选择能使 `price[i]` 增大的最小数字进行交换
     - 交换后，标准化剩余部分

3. **标准化处理**：对于确定位置之后的部分，将所有 $5$ 转为 $2$，$9$ 转为 $6$，然后按升序排序，确保得到的是最小可能的排列。

4. **结果选择**：收集所有候选解，选择最小的一个作为答案。

### 算法正确性证明

该算法的正确性基于以下观察：
- 我们要找的是**下一个排列**，因此第一个能够增大的位置决定了新价格的大小
- 在该位置使用尽可能小的增大值，并在后面部分使用最小排列，可以确保得到的是严格的下一个更大价格
- 标准化处理确保了数字表示的一致性，避免重复计数

### 时间复杂度

- 对于长度为 $n$ 的数字串，算法最多检查 $O(n)$ 个位置
- 每个位置最多与 $O(n)$ 个后续位置比较
- 排序操作的时间复杂度为 $O(n \log n)$
- 总体时间复杂度：$O(n^2 \log n)$，在 $n \leq 30$ 时完全可行

### 空间复杂度

- 主要空间用于存储候选解：$O(n)$

```cpp
// Gas Station Numbers

#include <bits/stdc++.h>
using namespace std;

// 数字翻转映射表
map<char, char> fliped = {
    {'0', '0'}, {'1', '1'}, {'2', '5'}, {'3', '3'}, {'4', '4'},
    {'5', '2'}, {'6', '9'}, {'7', '7'}, {'8', '8'}, {'9', '6'}
};

/**
 * 标准化字符串：将指定位置之后的部分转换为最小字典序
 * @param s 要标准化的字符串
 * @param k 起始位置
 */
void normalize(string& s, int k) {
    // 将5转为2，9转为6，统一使用较小的表示
    for (size_t i = k; i < s.size(); i++) {
        if (s[i] == '5') s[i] = '2';
        if (s[i] == '9') s[i] = '6';
    }
    // 对剩余部分排序，得到最小排列
    sort(s.begin() + k, s.end());
}

int main() {
    string line;
    while (getline(cin, line)) {
        if (line == ".") break;  // 输入结束
        
        string price = line;
        // 移除小数点，便于处理
        price.erase(price.find('.'), 1);
        
        vector<string> answer;  // 存储所有候选解
        int n = price.length();
        int changed = 0;  // 标记是否找到可行解
        
        // 从右向左扫描每个位置
        for (int i = n - 1; i >= 0; i--) {
            // 情况1：当前数字可以直接翻转增大（2->5 或 6->9）
            if (price[i] == '2' || price[i] == '6') {
                string s = price;
                s[i] = fliped[s[i]];  // 执行翻转
                normalize(s, i + 1);   // 标准化剩余部分
                answer.push_back(s);   // 加入候选
                changed = 1;
            }
            
            // 情况2：与后面的数字交换
            int bestJ = -1;    // 最佳交换位置
            char bestC = -1;   // 最佳交换字符
            
            // 在当前位置之后寻找可交换的数字
            for (int j = i + 1; j < n; j++) {
                // 检查原始数字是否大于当前位置数字
                if (price[j] > price[i]) {
                    if (bestJ == -1 || price[j] < bestC) {
                        bestJ = j;
                        bestC = price[j];
                    }
                }
                // 检查翻转后的数字是否大于当前位置数字
                if (fliped[price[j]] > price[i]) {
                    if (bestJ == -1 || fliped[price[j]] < bestC) {
                        bestJ = j;
                        bestC = fliped[price[j]];
                    }
                }
            }
            
            // 如果找到可交换的数字
            if (bestJ != -1) {
                string s = price;
                // 执行交换
                s[bestJ] = s[i];  // 当前位置数字移到后面
                s[i] = bestC;     // 更大的数字移到当前位置
                normalize(s, i + 1);  // 标准化剩余部分
                answer.push_back(s);  // 加入候选
                changed = 1;
            }
            
            // 如果找到解，立即停止（贪心：第一个能增大的位置就是关键位置）
            if (changed) break;
        }
        
        // 选择最小的候选解
        sort(answer.begin(), answer.end());
        string r;
        if (answer.size()) r = answer.front();
        
        // 输出结果
        if (r.empty()) {
            cout << "The price cannot be raised.\n";
        } else {
            // 重新插入小数点（在倒数第二位之前）
            cout << r.substr(0, r.length() - 1) << '.' << r.back() << '\n';
        }
    }
    return 0;
}
```

## 总结

本题通过巧妙的贪心策略，结合数字翻转的特性，高效地找到了下一个更高价格。算法的核心在于：
- 从右向左寻找第一个可以增大的位置
- 考虑直接翻转和数字交换两种增大方式
- 通过标准化确保得到最小可能的排列

这种方法既保证了正确性，又具有较高的效率，是解决此类排列问题的优秀范例。
