## 题目描述

你被蒙上眼睛后放置在一个迷宫的某个位置，你不知道自己的起始位置，但你有一张迷宫地图。迷宫是一个 $n \times n$ 的网格（$n \leq 8$），每个格子要么是阻塞的（用字符 `'0'` 表示），要么是可通行的（用字符 `'.'` 表示）。你总是知道北方方向。

你有四种移动方式：**北（$\texttt{north}$）、南（$\texttt{south}$）、东（$\texttt{east}$）、西（$\texttt{west}$）** 。你的任务是找到一个**最短的移动序列**，使得无论你初始时在哪个可通行位置，按照这个序列移动后都能**逃脱迷宫**。逃脱的定义是：当你到达网格的**外部边缘**的任一格子时（如果初始位置就在边缘，则已经逃脱）。一旦逃脱，后续移动不再影响你。如果你试图走入一个阻塞的格子，你会停留在原地。

可以假设从迷宫中的每个可通行位置都**可能逃脱**。

### 输入格式

输入以一个正整数 $T$ 开始，表示测试用例的数量。每个测试用例之间用一个空行分隔。

每个测试用例包含一个正整数 $n$（$n \leq 8$），随后是 $n$ 行，每行 $n$ 个字符，表示迷宫网格。字符 `'0'` 表示阻塞格子，字符 `'.'` 表示可通行格子。

### 输出格式

对于每个测试用例，输出若干行，每行是 `"north"`、`"south"`、`"east"` 或 `"west"` 之一，表示一个最短的移动序列，该序列能保证从任意可通行起始位置逃脱。如果有多个最短序列，输出任意一个即可。两个连续测试用例的输出之间用一个空行分隔。

### 样例输入
```
1

4
00.0
...0
00.
0..0
```

### 样例输出
```
east
north
```

## 题目分析

### 问题本质

这是一个**确定性的状态空间搜索问题**。我们需要找到一个**固定的指令序列**，使得无论从哪个可通行格子开始，执行完这个序列后，都能保证到达边界（逃脱）。

关键点：
1. **状态是位置的集合**：由于不知道起始位置，我们必须考虑所有可能的起始位置。因此，当前状态是**所有可能位置的集合**。
2. **移动是确定性的**：对于集合中的每个位置，执行相同的移动指令：
   - 如果目标格子可通行，则移动到新位置；
   - 如果目标格子阻塞，则停留在原地；
   - 如果新位置是边界，则该位置**逃脱**，从当前集合中移除。
3. **目标状态**：当所有可能位置都逃脱时，即当前集合为空时，序列满足要求。
4. **最短序列**：需要找到最短的指令序列。

### 状态表示与编码

由于 $n \leq 8$，最多有 $64$ 个格子。我们可以用一个 **$64$ 位整数（`long long`）** 作为位掩码来表示状态集合，其中第 $i$ 位为 $1$ 表示第 $i$ 个格子是可能位置之一。

为了编码方便，我们将二维坐标 $(x, y)$ 映射到一维索引：  
$$idx = x \times n + y$$

### 搜索策略选择

最直观的方法是使用 **广度优先搜索（$\texttt{BFS}$）** ，因为我们需要最短路径。$\texttt{BFS}$ 从初始状态（所有可通行位置的集合）开始，每次尝试四种移动，生成新状态，直到找到目标状态（集合为空）。

**为什么不用 $\texttt{DFS}$ 或 $\texttt{IDDFS}$？**  
- 虽然 $n$ 很小，但状态空间可能很大（最多 $2^{64}$ 个集合），$\texttt{BFS}$ 能保证找到最短解，而 $\texttt{DFS}$ 可能陷入深层搜索。
- 实际可达状态数有限，因为每次移动都是确定性的，且格子数少，$\texttt{BFS}$ 可行。

### 算法流程

1. **初始化**：
   - 读取迷宫，标记所有可通行格子。
   - 初始状态掩码 `startMask` 包含所有可通行格子（但需排除一开始就在边界的格子，因为它们已经逃脱）。

2. **BFS 搜索**：
   - 队列元素：`(inMazeMask, path)`，其中 `inMazeMask` 是仍在迷宫中的位置集合，`path` 是已执行的指令序列。
   - 使用 `map` 或 `unordered_set` 记录访问过的状态，避免重复搜索。
   - 每次从队列取出一个状态，尝试四种移动：
     - 对于 `inMazeMask` 中的每个位置，尝试向指定方向移动：
       - 如果目标格子可通行，且是边界，则该位置逃脱（从新掩码中移除）；
       - 如果目标格子可通行，但不是边界，则移动到新位置；
       - 如果目标格子阻塞，则留在原地（如果原地是边界，则逃脱）。
     - 生成新掩码 `newMask`，如果未访问过，则加入队列。
   - 当 `inMazeMask` 为空（所有位置已逃脱）时，找到解。

3. **输出结果**：
   - 将指令索引转换为方向名称输出。

### 时间复杂度分析

- 状态数：最多 $2^{64}$ 个，但实际 BFS 访问的状态数远小于此，因为每次移动会减少或扩散位置集合。
- 每个状态扩展 $4$ 个方向，每次扩展需要遍历最多 $64$ 个格子。
- 对于 $n \leq 8$ 的小迷宫，$\texttt{BFS}$ 可以在很短时间内找到解。

## 代码实现

```cpp
// Maze
// UVa ID: 851
// Verdict: Accepted
// Submission Date: 2025-12-30
// UVa Run Time: 6.080s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net


#include <bits/stdc++.h>
using namespace std;

const int MAXN = 8;
const int dx[4] = {-1, 1, 0, 0};  // north, south, east, west
const int dy[4] = {0, 0, 1, -1};
const string dirName[4] = {"north", "south", "east", "west"};

struct State {
    long long inMaze;    // 仍在迷宫中的位置集合（位掩码）
    vector<int> path;    // 已执行的移动序列
};

// 将坐标编码为位掩码中的位置
inline int encode(int x, int y, int n) {
    return x * n + y;
}

// 判断格子是否在边界
inline bool isBorder(int x, int y, int n) {
    return x == 0 || x == n - 1 || y == 0 || y == n - 1;
}

// 执行移动指令，返回新的状态掩码
pair<long long, long long> applyMove(long long inMaze, long long escaped, int dir, int n, const vector<string>& grid) {
    long long newInMaze = 0;
    long long newEscaped = escaped;  // 已逃脱的位置保持不变
    
    for (int x = 0; x < n; ++x) {
        for (int y = 0; y < n; ++y) {
            if (grid[x][y] != '.') continue;  // 忽略阻塞格子
            int idx = encode(x, y, n);
            
            // 如果这个位置已经逃脱，跳过
            if (escaped & (1LL << idx)) continue;
            
            // 如果这个位置不在当前迷宫中，跳过
            if (!(inMaze & (1LL << idx))) continue;
            
            // 尝试移动
            int nx = x + dx[dir];
            int ny = y + dy[dir];
            
            if (nx >= 0 && nx < n && ny >= 0 && ny < n && grid[nx][ny] == '.') {
                // 可移动到新位置
                if (isBorder(nx, ny, n)) {
                    // 到达边界，逃脱
                    newEscaped |= (1LL << encode(nx, ny, n));
                } else {
                    // 仍在迷宫中
                    newInMaze |= (1LL << encode(nx, ny, n));
                }
            } else {
                // 不可移动，留在原地
                if (isBorder(x, y, n)) {
                    // 当前位置已经是边界，逃脱
                    newEscaped |= (1LL << idx);
                } else {
                    // 仍在迷宫中
                    newInMaze |= (1LL << idx);
                }
            }
        }
    }
    
    return {newInMaze, newEscaped};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int t;
    cin >> t;
    bool firstCase = true;
    
    while (t--) {
        if (!firstCase) cout << endl;
        firstCase = false;
        
        int n;
        cin >> n;
        vector<string> grid(n);
        for (int i = 0; i < n; ++i) cin >> grid[i];
        
        // 初始状态：所有可通行位置都在迷宫中（除了已经在边界的）
        long long startInMaze = 0;
        for (int x = 0; x < n; ++x) {
            for (int y = 0; y < n; ++y) {
                if (grid[x][y] == '.') {
                    int idx = encode(x, y, n);
                    // 如果开始就在边界，直接逃脱，不在迷宫中
                    if (!isBorder(x, y, n)) {
                        startInMaze |= (1LL << idx);
                    }
                }
            }
        }
        
        // 如果开始时所有位置都已逃脱
        if (startInMaze == 0) {
            // 输出空序列（即无输出）
            continue;
        }
        
        // BFS 搜索
        queue<State> q;
        map<pair<long long, long long>, bool> visited;
        
        q.push({startInMaze, {}});
        visited[{startInMaze, 0}] = true;
        
        vector<int> answer;
        
        while (!q.empty()) {
            State cur = q.front(); q.pop();
            
            // 如果迷宫中已无位置，找到解
            if (cur.inMaze == 0) {
                answer = cur.path;
                break;
            }
            
            // 尝试四种移动
            for (int d = 0; d < 4; ++d) {
                auto [newInMaze, newEscaped] = applyMove(cur.inMaze, 0, d, n, grid);
                
                // 如果移动后状态未访问过
                if (!visited[{newInMaze, newEscaped}]) {
                    visited[{newInMaze, newEscaped}] = true;
                    vector<int> newPath = cur.path;
                    newPath.push_back(d);
                    q.push({newInMaze, newPath});
                }
            }
        }
        
        // 输出答案
        for (int d : answer) {
            cout << dirName[d] << endl;
        }
    }
    
    return 0;
}
```

## 代码说明

1. **状态结构体 `State`**：包含仍在迷宫中的位置集合 `inMaze` 和已执行的移动序列 `path`。
2. **移动函数 `applyMove`**：根据当前状态和移动方向，计算新状态。正确处理了边界逃脱和撞墙停留的情况。
3. **$\texttt{BFS}$ 搜索**：使用队列进行广度优先搜索，保证找到最短序列。使用 `map` 记录访问过的状态，避免重复搜索。
4. **初始状态处理**：开始时就在边界的位置直接算作逃脱，不在初始集合中。
5. **输出**：将移动方向的索引转换为名称输出。

## 总结

本题的关键在于**将不确定的起始位置转化为状态集合**，然后通过 $\texttt{BFS}$ 搜索状态空间找到最短指令序列。位掩码的使用极大简化了状态表示和操作，使得算法高效可行。

**核心思想**：将多个可能位置作为一个整体状态，通过确定性移动进行状态转移，最终使状态集合为空（所有位置逃脱）。

这种思路可以推广到其他类似“从任意起始位置保证到达目标”的问题中。
