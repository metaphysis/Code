## 题目描述

一个电子电路由元件、引脚和导线组成。每根导线连接一对引脚。如果两个引脚 $a$ 和 $b$ 直接由一根导线连接，或者存在一个引脚序列 $a_1, a_2, \ldots, a_k$，使得 $a$ 与 $a_1$、$a_1$ 与 $a_2$、$\ldots$、$a_{k-1}$ 与 $a_k$、$a_k$ 与 $b$ 都由导线连接，则称这两个引脚是**电气等价**的。

一个**网络**是电气等价引脚的最大集合。*最大*意味着网络外的任何引脚都不与网络内的任何引脚电气等价。

给定一组引脚和一组导线，你的任务是确定电路中定义的网络数量。

## 输入格式

输入以一个单独的正整数开始，表示接下来的测试用例数量。每个测试用例包含：
- 第一行：引脚数量 $N$（引脚编号从 $1$ 到 $N$）
- 随后若干行：每行包含偶数个数字，每两个数字组成一条导线连接的引脚对
- 测试用例之间用空行分隔

## 输出格式

对于每个测试用例，输出网络的数量。两个连续用例的输出之间用一个空行分隔。

## 题目分析

### 问题本质

这个问题本质上是一个**图的连通分量计数**问题：
- 将每个引脚看作图中的一个**顶点**
- 将每条导线看作连接两个顶点的一条**边**
- 电气等价的引脚构成一个**连通分量**
- 网络就是图中的**连通分量**

因此，我们需要计算给定图中的连通分量数量。

### 关键观察

1. **等价关系**：电气等价性满足等价关系的三个性质：
   - 自反性：每个引脚与自身电气等价
   - 对称性：如果 $a$ 与 $b$ 电气等价，则 $b$ 与 $a$ 也电气等价
   - 传递性：如果 $a$ 与 $b$ 电气等价，且 $b$ 与 $c$ 电气等价，则 $a$ 与 $c$ 电气等价

2. **连通性**：电气等价实际上定义了图的连通性，两个引脚电气等价当且仅当它们在图中连通

### 解题思路

我们可以使用两种主要方法解决这个问题：

#### 方法一：深度优先搜索（$\texttt{DFS}$）

1. 构建图的邻接表表示
2. 使用 $\texttt{DFS}$ 遍历图，每次完整的 $\texttt{DFS}$ 遍历会访问一个连通分量中的所有顶点
3. 统计 $\texttt{DFS}$ 的启动次数，即为连通分量的数量

时间复杂度：$O(N + E)$，其中 $N$ 是顶点数，$E$ 是边数

#### 方法二：并查集（$\texttt{Union-Find}$）

1. 初始化并查集，每个顶点单独成一个集合
2. 对于每条边，合并两个顶点所在的集合
3. 统计最终不同集合的数量，即为连通分量的数量

时间复杂度：$O(E \cdot \alpha(N))$，其中 $\alpha$ 是反阿克曼函数，在实际应用中可视为常数

### 算法选择

我们选择**并查集**算法，因为：
- 代码实现简洁
- 对于稀疏图和稠密图都有良好的性能
- 不需要显式构建图结构

## 并查集算法详解

### 核心操作

1. **$\texttt{findSet}(x)$**：查找元素 $x$ 所在集合的代表元素（根节点），同时进行路径压缩优化
2. **$\texttt{unionSet}(a, b)$**：合并元素 $a$ 和 $b$ 所在的集合

### 路径压缩优化

在 $\texttt{findSet}$ 操作中，我们将查找路径上的所有节点直接连接到根节点，从而降低树的高度，提高后续查找的效率。

### 算法步骤

1. 初始化：每个引脚自成一个集合
2. 处理每条边：合并边连接的两个引脚所在的集合
3. 统计结果：计算不同根节点的数量

## 代码实现

```cpp
// Circuit Nets
// UVa ID: 879
// Verdict: Accepted
// Submission Date: 2025-11-20
// UVa Run Time: 0.100s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

vector<int> parent;

int findSet(int x) {
    if (parent[x] != x) parent[x] = findSet(parent[x]);
    return parent[x];
}

void unionSet(int a, int b) {
    int rootA = findSet(a);
    int rootB = findSet(b);
    if (rootA != rootB) parent[rootB] = rootA;
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        parent.resize(n + 1);
        for (int i = 1; i <= n; i++) parent[i] = i;
        cin.ignore(128, '\n'); // 忽略换行符
        
        // 注意：输入可能是多行
        string line;
        while (getline(cin, line) && !line.empty()) {
            stringstream ss(line);
            int a, b;
            while (ss >> a >> b) unionSet(a, b);
        }
        
        unordered_set<int> nets;
        for (int i = 1; i <= n; i++) nets.insert(findSet(i));
        
        cout << nets.size() << endl;
        if (t) cout << endl;
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(E \cdot \alpha(N))$，其中 $E$ 是边的数量，$N$ 是顶点数量，$\alpha$ 是反阿克曼函数
- **空间复杂度**：$O(N)$，用于存储并查集的父节点数组
## 总结

本题通过将实际问题抽象为图的连通分量问题，展示了并查集在解决连通性问题中的高效性和简洁性。并查集的路径压缩优化确保了算法的高效性，使其能够处理大规模数据。
