# 题目描述

地图由 $L \times C$ 个六边形组成，地图左右边界相连，形成一个圆柱形网格。每个六边形具有一个正偶数标准代价。

$\texttt{Gilix}$ 从一个起点出发，前往指定终点。移动到相邻六边形时，移动时间取决于目标六边形的标准代价：

- 未饮用药水时，移动时间等于目标六边形的标准代价。
- 饮用药水后，移动时间等于目标六边形标准代价的一半。

药水只能在指定六边形处饮用一次，饮用过程不消耗时间。求 $\texttt{Gilix}$ 从起点到终点所需的最少时间。

# 输入格式

第一行包含两个整数 $L$ 和 $C$，表示地图的行数和列数。

接下来 $L$ 行，每行包含 $C$ 个正偶数，表示对应六边形的标准代价。

随后输入三行，每行包含两个整数 $X$ 和 $Y$：

- 第一行表示起点坐标。
- 第二行表示终点坐标。
- 第三行表示药水位置坐标。

坐标范围如下：

$$
1 \le L \le 300
$$

$$
1 \le C \le 300
$$

$$
0 \le X < L
$$

$$
0 \le Y < C
$$

每个六边形的标准代价不超过 $30$。

# 输出格式

输出一个整数，表示从起点到终点所需的最少时间。

# 样例输入

```text
4 8
4 2 2 2 4 4 6 10
2 6 8 4 4 4 4 2
8 2 6 8 4 4 4 6
6 4 4 6 8 4 4 4
0 0
3 4
1 1
```

# 样例输出

```text
18
```

# 题目分析

每次移动的代价由目标六边形决定，因此从一个位置移动到另一个位置时，边权就是目标位置的标准代价。饮用药水后，所有移动边的代价变为原来的一半。

药水必须在指定位置饮用，因此任意一条合法路线都可以划分为两部分：

- 从起点到药水位置，此时尚未饮用药水；
- 从药水位置到终点，此时已经饮用药水。

第一部分的移动代价使用目标六边形的完整标准代价，第二部分的移动代价使用目标六边形标准代价的一半。药水位置本身不产生额外代价。

地图中的每个六边形可以看成图中的一个顶点，相邻六边形之间建立有向边。由于所有移动代价都是正数，使用 $\texttt{Moore-Dijkstra}$ 算法可以求出带权图中的最短路。

地图左右相连，因此列坐标需要进行循环处理。例如，当列坐标变为 $-1$ 时，将其转换为 $C - 1$；当列坐标变为 $C$ 时，将其转换为 $0$。地图上下不相连，超出行范围的位置不能移动到。

对于六边形网格，水平方向的相邻位置为 $(x, y - 1)$ 和 $(x, y + 1)$。上下相邻位置与当前行的奇偶性有关：

- 当前行 $x$ 为偶数时，上下两行的斜向相邻列为 $y - 1$；
- 当前行 $x$ 为奇数时，上下两行的斜向相邻列为 $y + 1$。

因此每个六边形最多有 $6$ 个相邻位置。

# 解题思路

使用两次 $\texttt{Moore-Dijkstra}$ 算法完成计算。

第一次从起点出发，按照未饮用药水的规则计算最短路。移动到位置 $(nx, ny)$ 时，边权为该位置的标准代价：

$$
w = cost[nx][ny]
$$

第一次最短路得到起点到药水位置的最短时间，记为 $d_1$。

第二次从药水位置出发，按照已经饮用药水的规则计算最短路。移动到位置 $(nx, ny)$ 时，边权为该位置标准代价的一半：

$$
w = \frac{cost[nx][ny]}{2}
$$

第二次最短路得到药水位置到终点的最短时间，记为 $d_2$。

最终答案为：

$$
answer = d_1 + d_2
$$

算法过程如下。

步骤 $\texttt{1}$. 读入地图及起点、终点和药水位置。

步骤 $\texttt{2}$. 从起点运行一次未饮用药水状态下的 $\texttt{Moore-Dijkstra}$，得到到达药水位置的最短距离。

步骤 $\texttt{3}$. 从药水位置运行一次饮用药水状态下的 $\texttt{Moore-Dijkstra}$，得到到达终点的最短距离。

步骤 $\texttt{4}$. 将两段最短距离相加并输出。

设顶点数量为 $V = L \times C$。每个顶点最多连接 $6$ 条边，因此边数与 $V$ 同阶。一次 $\texttt{Moore-Dijkstra}$ 的时间复杂度为 $O(V \log V)$，执行两次后时间复杂度仍为：

$$
O(L \times C \times \log(L \times C))
$$

距离数组、地图数组和优先队列占用的空间复杂度为：

$$
O(L \times C)
$$

# 代码实现

代码使用优先队列维护当前距离最小的状态。顶点编号通过公式 $id = x \times C + y$ 转换为一维编号，从而简化距离数组的存储。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> dijkstra(const vector<vector<int>>& cost, int sx, int sy, bool fast) {
    int l = cost.size(), c = cost[0].size(), n = l * c, inf = INT_MAX;
    vector<int> dist(n, inf);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> que;
    int start = sx * c + sy;
    dist[start] = 0;
    que.push({0, start});
    while (!que.empty()) {
        pair<int, int> cur = que.top();
        que.pop();
        int dis = cur.first, id = cur.second;
        if (dis != dist[id]) continue;
        int x = id / c, y = id % c;
        int dy = x % 2 == 0 ? -1 : 1;
        int dx[6] = {0, 0, -1, -1, 1, 1};
        int dc[6] = {-1, 1, 0, dy, 0, dy};
        for (int i = 0; i < 6; i++) {
            int nx = x + dx[i], ny = y + dc[i];
            if (nx < 0 || nx >= l) continue;
            ny = (ny + c) % c;
            int nid = nx * c + ny;
            int weight = fast ? cost[nx][ny] / 2 : cost[nx][ny];
            int nd = dis + weight;
            if (nd < dist[nid]) {
                dist[nid] = nd;
                que.push({nd, nid});
            }
        }
    }
    return dist;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int l, c;
    cin >> l >> c;
    vector<vector<int>> cost(l, vector<int>(c));
    for (int i = 0; i < l; i++)
        for (int j = 0; j < c; j++)
            cin >> cost[i][j];
    int sx, sy, tx, ty, px, py;
    cin >> sx >> sy;
    cin >> tx >> ty;
    cin >> px >> py;
    vector<int> before = dijkstra(cost, sx, sy, false);
    vector<int> after = dijkstra(cost, px, py, true);
    int potionId = px * c + py, targetId = tx * c + ty;
    cout << before[potionId] + after[targetId] << '\n';
    return 0;
}
```

# 总结

本题的关键在于利用药水位置将路线划分为两个独立阶段：

- 起点到药水位置使用完整代价；
- 药水位置到终点使用减半代价。

由于所有边权均为正数，两个阶段分别使用 $\texttt{Moore-Dijkstra}$ 算法求最短路即可。处理六边形网格时，需要根据行的奇偶性确定斜向邻居，并对列坐标进行循环处理，以符合圆柱形地图的边界特征。
