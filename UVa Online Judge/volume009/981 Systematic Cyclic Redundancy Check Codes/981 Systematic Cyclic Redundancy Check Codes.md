
> **摘要**：本文围绕系统循环冗余校验（$\texttt{CRC}$）编码的合法性判定问题展开。给定原始数据长度 $k$、编码后的二进制字符串 $E$ 与生成多项式字符串 $G$，需要判断 $E$ 能否由 $G$ 生成：若合法则输出 $E$ 的前 $k$ 位作为原始数据，否则输出 `ERROR`。文章从模 $2$ 运算的性质出发，指出模 $2$ 加法与减法均等价于按位异或，从而将 $\texttt{CRC}$ 校验转化为对 $E$ 做模 $2$ 多项式除法并检查余数是否全为 $0$。

# 题目描述

给定原始数据字长度 $k$、系统循环冗余校验编码后的二进制字符串 $E$，以及生成多项式对应的二进制字符串 $G$。编码过程首先将原始数据对应的多项式左移 $n - k$ 位，再与该多项式除以 $G$ 后得到的余数进行模 $2$ 加法，得到编码结果 $E$，其中 $n$ 表示编码字符串的长度。

程序需要判断给定的编码字符串是否能够由给定的生成多项式生成。若编码合法，则输出编码字符串的前 $k$ 位，也就是原始数据；否则输出 `ERROR`。

# 输入格式

输入包含若干组测试数据，每组数据占用三行：

- 第一行包含一个整数 $k$，表示原始数据的长度，满足 $k \le 16$。
- 第二行包含一个只由字符 `0` 和 `1` 组成的二进制字符串 $E$，表示编码后的消息。
- 第三行包含一个只由字符 `0` 和 `1` 组成的二进制字符串 $G$，表示生成多项式。

每个二进制字符串的长度均不超过 $200$。输入持续到文件结束。

# 输出格式

对于每组测试数据：

- 如果编码字符串合法，输出其前 $k$ 位。
- 如果编码字符串不合法，输出 `ERROR`。

每组测试数据输出一行。

# 样例输入

```text
3
1101001
11101
3
1101011
11101
```

# 样例输出

```text
110
ERROR
```

# 题目分析

系统循环冗余校验编码具有一个重要性质：编码字符串 $E$ 的前 $k$ 位保留了原始数据，后 $n - k$ 位是校验信息。编码时，原始数据左移 $n - k$ 位后加上余数，因此完整编码字符串能够被生成多项式 $G$ 整除。

这里的加法和除法都在模 $2$ 的意义下进行。模 $2$ 加法等价于按位异或，满足相同二进制位相加得到 $0$，不同二进制位相加得到 $1$。因此，除法过程不需要进行普通整数除法，只需要在当前最高位为 `1` 时，将生成多项式与当前字符串对应位置进行异或。

对编码字符串 $E$ 使用生成多项式 $G$ 进行模 $2$ 除法后，如果余数全部为 $0$，则说明 $E$ 能够被 $G$ 整除，符合系统循环冗余校验的编码条件。此时，直接取 $E$ 的前 $k$ 位即可恢复原始数据。

如果余数中存在 `1`，则编码字符串没有通过校验，输出 `ERROR`。当 $E$ 的长度小于 $G$ 的长度时，无法进行有效除法，也应判定为非法编码。

# 解题思路

首先读入 $k$、编码字符串 $E$ 和生成多项式字符串 $G$，并记编码字符串长度为 $n$，生成多项式长度为 $m$。

随后按照从左到右的顺序处理编码字符串。处理位置为 $i$ 时，如果当前位置的字符是 `1`，就将 $G$ 的每一位与从位置 $i$ 开始的连续 $m$ 位进行异或。由于最高位为 `1` 的部分已经被消去，继续向右处理即可完成模 $2$ 除法。

处理范围为所有满足 $i + m \le n$ 的位置。除法结束后，可能保留的非零部分只能位于最后 $m - 1$ 位，因此检查从位置 $n - m + 1$ 到位置 $n - 1$ 的所有字符：

- 若全部为 `0`，则校验通过，输出原字符串 $E$ 的前 $k$ 位。
- 若存在字符 `1`，则校验失败，输出 `ERROR`。

整个过程中直接修改编码字符串的副本，不会影响后续对原始数据前 $k$ 位的提取。

设编码字符串长度为 $n$，生成多项式长度为 $m$。外层扫描最多进行 $n$ 次，内层异或最多进行 $m$ 次，因此时间复杂度为 $O(nm)$。字符串副本占用 $O(n)$ 的额外空间，除此之外只使用常数级变量，所以空间复杂度为 $O(n)$。

# 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

bool checkCrc(string e, const string &g) {
    int n = (int)e.size(), m = (int)g.size();
    if (n < m)
        return false;
    for (int i = 0; i + m <= n; ++i)
        if (e[i] == '1')
            for (int j = 0; j < m; ++j)
                e[i + j] = e[i + j] == g[j] ? '0' : '1';
    for (int i = n - m + 1; i < n; ++i)
        if (e[i] == '1')
            return false;
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int k;
    string e, g;
    while (cin >> k >> e >> g) {
        if (checkCrc(e, g)) cout << e.substr(0, k) << '\n';
        else cout << "ERROR\n";
    }
    return 0;
}
```

# 总结

本题的核心是利用系统循环冗余校验的整除性质判断编码是否合法。编码字符串经过生成多项式进行模 $2$ 除法后，余数为全 $0$ 时校验通过，否则校验失败。

实现模 $2$ 除法时，将普通减法替换为按位异或即可。校验通过后，系统编码的前 $k$ 位就是原始数据，因此无需额外计算即可完成解码。
