## 题目分析

### 问题描述

在一个巨大的奶酪中，生活着两只奶酪螨虫 $\texttt{Amelia}$ 和另一只雄性螨虫。$\texttt{Amelia}$ 想要尽快找到另一只螨虫，但奶酪中有很多空洞，这会影响她的行进时间：

- 在奶酪中行进：$1$ 毫米需要 $10$ 秒
- 在空洞中行进：时间可以忽略不计（瞬间通过）

空洞是球形的，可能重叠形成复杂形状。我们需要找到 $\texttt{Amelia}$ 到达另一只螨虫的最短时间。

### 输入格式

- 第一行：整数 $n$ ($0 \leq n \leq 100$)，表示空洞数量
- 接下来 $n$ 行：每行四个整数 $x_i, y_i, z_i, r_i$，表示空洞的中心坐标和半径
- 接下来两行：分别给出 $\texttt{Amelia}$ 的位置 $(x_A, y_A, z_A)$ 和另一只螨虫的位置 $(x_O, y_O, z_O)$
- 输入以 $-1$ 结束

### 输出格式

对于每个测试用例，输出最小时间（秒），四舍五入到整数。

## 解题思路

### 关键观察

1. **问题本质**：这是一个三维空间中的最短路径问题，但路径权重在不同区域不同
2. **空洞特性**：在空洞内部或表面移动时间为 $0$，在奶酪中移动时间为距离 $\times 10$ 秒
3. **建模方法**：将问题转化为图论问题，使用最短路径算法求解

### 图的构建

我们将整个问题建模为一个带权无向图：

- **节点**：起点（$\texttt{Amelia}$）、终点（另一只螨虫）、所有空洞的球心
- **边权重**：两个节点之间的"有效奶酪距离"

#### 距离计算规则

1. **起点/终点到空洞**：
   $$
   distance = \max(0, \text{到球心的距离} - \text{半径})
   $$
   如果点在空洞内，距离为 $0$

2. **空洞到空洞**：
   $$
   distance = \max(0, \text{球心距离} - r_1 - r_2)
   $$
   如果空洞相交或相切，距离为 $0$

3. **起点到终点**：直接计算欧几里得距离

### 算法选择

由于图的规模较小（最多 $102$ 个节点），我们使用 **$\texttt{Dijkstra}$ 算法** 来求解单源最短路径。

### 时间复杂度

- 节点数：$n + 2$
- 边数：$O(n^2)$
- $\texttt{Dijkstra}$ 算法复杂度：$O((n+2)^2 \log n)$
- 对于 $n \leq 100$，完全可行

## 算法步骤

1. **读入数据**：空洞信息、起点和终点坐标
2. **构建图**：计算所有节点对之间的有效距离
3. **运行 $\texttt{Dijkstra}$**：从起点到终点的最短路径
4. **计算时间**：最短距离 $\times 10$，四舍五入输出

```cpp
// Say Cheese
// UVa ID: 1001

#include <bits/stdc++.h>

using namespace std;

struct Hole {
    double x, y, z, r;
};

struct Point {
    double x, y, z;
};

double dist(const Point& a, const Point& b) {
    double dx = a.x - b.x;
    double dy = a.y - b.y;
    double dz = a.z - b.z;
    return sqrt(dx*dx + dy*dy + dz*dz);
}

double dist(const Hole& a, const Hole& b) {
    return max(0.0, dist(Point{a.x, a.y, a.z}, Point{b.x, b.y, b.z}) - a.r - b.r);
}

double dist(const Hole& a, const Point& p) {
    return max(0.0, dist(Point{a.x, a.y, a.z}, p) - a.r);
}

int main() {
    int n;
    int caseNum = 1;
    while (cin >> n && n != -1) {
        vector<Hole> holes(n);
        for (int i = 0; i < n; i++) {
            cin >> holes[i].x >> holes[i].y >> holes[i].z >> holes[i].r;
        }
        Point start, end;
        cin >> start.x >> start.y >> start.z;
        cin >> end.x >> end.y >> end.z;

        int nodes = n + 2;
        vector<vector<double>> graph(nodes, vector<double>(nodes, 0.0));

        // 起点到各洞
        for (int i = 0; i < n; i++) {
            graph[0][i+1] = dist(holes[i], start);
            graph[i+1][0] = graph[0][i+1];
        }
        // 终点到各洞
        for (int i = 0; i < n; i++) {
            graph[n+1][i+1] = dist(holes[i], end);
            graph[i+1][n+1] = graph[n+1][i+1];
        }
        // 洞与洞之间
        for (int i = 0; i < n; i++) {
            for (int j = i+1; j < n; j++) {
                graph[i+1][j+1] = dist(holes[i], holes[j]);
                graph[j+1][i+1] = graph[i+1][j+1];
            }
        }
        // 起点到终点
        graph[0][n+1] = ::dist(start, end);
        graph[n+1][0] = graph[0][n+1];

        // Dijkstra
        vector<double> distDijk(nodes, 1e18);
        distDijk[0] = 0;
        priority_queue<pair<double, int>, vector<pair<double, int>>, greater<pair<double, int>>> pq;
        pq.push({0.0, 0});

        while (!pq.empty()) {
            double d = pq.top().first;
            int u = pq.top().second;
            pq.pop();
            if (d > distDijk[u]) continue;
            for (int v = 0; v < nodes; v++) {
                if (u == v) continue;
                double nd = d + graph[u][v];
                if (nd < distDijk[v]) {
                    distDijk[v] = nd;
                    pq.push({nd, v});
                }
            }
        }

        double travelTime = distDijk[n+1] * 10.0;
        int result = static_cast<int>(travelTime + 0.5); // 四舍五入

        cout << "Cheese " << caseNum << ": Travel time = " << result << " sec\n";
        caseNum++;
    }

    return 0;
}
```

## 总结

本题的关键在于将三维空间中的移动问题转化为图论问题，通过合理的距离计算规则来构建图的边权重。使用 $\texttt{Dijkstra}$ 算法可以高效求解最短路径，最终得到最小时间。

这种"几何+图论"的组合问题在编程竞赛中比较常见，需要选手具备将现实问题抽象为计算模型的能力。
