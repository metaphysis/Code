[UVa 1009 Balloons in a Box](https://blog.csdn.net/metaphysis/article/details/154398196)

## 题目描述

给定一个长方体盒子和 $n$ 个点，每个点可以放置一个气球。放置规则如下：
- 将气球以该点为中心膨胀，直到碰到盒子边界或之前放置的气球表面
- 不能选择盒子外的点或已在气球内部的点
- 可以按任意顺序使用这些点，也可以不使用某些点
- 目标：最大化气球总体积，最后输出盒子中未被气球占据的体积

输入包含多个测试用例，每个测试用例格式为：
- 第一行：点数 $n$ $(1 \leq n \leq 6)$
- 第二行：盒子一个角的 $(x, y, z)$ 坐标
- 第三行：盒子对角角的 $(x, y, z)$ 坐标  
- 接下来 $n$ 行：每个点的 $(x, y, z)$ 坐标

## 题目分析

### 关键点分析

1. **气球半径计算**：每个气球的半径由以下因素决定：
   - 到盒子六个面的最小距离
   - 到所有已放置气球表面的最小距离（即 $\text{distance}(\text{center}_i, \text{center}_j) - \text{radius}_j$）

2. **放置策略**：
   - 可以选择点的子集进行放置
   - 点的放置顺序会影响最终总体积
   - 需要找到最优的子集和放置顺序

3. **约束条件**：
   - $n \leq 6$，允许使用暴力枚举
   - 盒子边与坐标轴平行
   - 坐标值为整数

### 解题思路

由于 $n$ 的最大值为 $6$，我们可以采用**暴力枚举**的方法：

1. **枚举所有非空子集**：使用位掩码枚举所有可能的点选择方案
2. **枚举每个子集的所有排列**：对于选中的点，尝试所有可能的放置顺序
3. **计算每种情况下的总体积**：
   - 按顺序放置气球，计算每个气球的半径
   - 半径取到盒子边界和已放置气球表面的最小距离
   - 如果半径 $\leq 0$，则该气球无法放置
4. **记录最大体积**：在所有子集和排列组合中找到气球总体积的最大值
5. **计算未占据体积**：盒子体积减去最大气球总体积，四舍五入到整数

// Balloons in a Box

#include <bits/stdc++.h>

using namespace std;

struct Point {
    double x, y, z;
    Point(double x = 0, double y = 0, double z = 0) : x(x), y(y), z(z) {}
};

double dist(const Point& a, const Point& b) {
    return sqrt((a.x - b.x) * (a.x - b.x) +
                (a.y - b.y) * (a.y - b.y) +
                (a.z - b.z) * (a.z - b.z));
}

double volume(double r) {
    return (4.0 / 3.0) * M_PI * r * r * r;
}

int main() {
    int n;
    int caseNum = 1;
    while (cin >> n && n != 0) {
        Point p1, p2;
        cin >> p1.x >> p1.y >> p1.z;
        cin >> p2.x >> p2.y >> p2.z;
        
        vector<Point> points(n);
        for (int i = 0; i < n; i++) {
            cin >> points[i].x >> points[i].y >> points[i].z;
        }
        
        double boxVol = fabs((p2.x - p1.x) * (p2.y - p1.y) * (p2.z - p1.z));
        
        double maxBalloonVol = 0.0;
        
        // 枚举所有非空子集
        for (int mask = 1; mask < (1 << n); mask++) {
            vector<int> indices;
            for (int i = 0; i < n; i++) {
                if (mask & (1 << i)) {
                    indices.push_back(i);
                }
            }
            
            // 枚举该子集的所有排列
            do {
                vector<double> radius(n, 0.0);
                double totalVol = 0.0;
                
                for (int i = 0; i < indices.size(); i++) {
                    int idx = indices[i];
                    Point pt = points[idx];
                    
                    // distance to box sides
                    double r = min({fabs(pt.x - p1.x), fabs(pt.x - p2.x),
                                    fabs(pt.y - p1.y), fabs(pt.y - p2.y),
                                    fabs(pt.z - p1.z), fabs(pt.z - p2.z)});
                    
                    // distance to existing balloons
                    for (int j = 0; j < i; j++) {
                        int prevIdx = indices[j];
                        if (radius[prevIdx] > 0) {
                            double d = dist(pt, points[prevIdx]) - radius[prevIdx];
                            if (d > 0) {
                                r = min(r, d);
                            } else {
                                r = 0;
                                break;
                            }
                        }
                    }
                    
                    if (r > 0) {
                        radius[idx] = r;
                        totalVol += volume(r);
                    } else {
                        radius[idx] = 0;
                        // 这里不break，继续尝试放置后面的气球
                        // 因为可能这个点放不了，但后面的点还能放
                    }
                }
                
                maxBalloonVol = max(maxBalloonVol, totalVol);
                
            } while (next_permutation(indices.begin(), indices.end()));
        }
        
        double unusedVol = boxVol - maxBalloonVol;
        int result = static_cast<int>(round(unusedVol));
        
        cout << "Box " << caseNum << ": " << result << "\n\n";
        caseNum++;
    }
    
    return 0;
}
