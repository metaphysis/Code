## 题目描述

太阳系中的行星运动遵循开普勒三大定律。给定第一颗行星的轨道参数（半长轴 $a_1$、半短轴 $b_1$、公转周期 $t_1$）和第二颗行星的轨道参数（半长轴 $a_2$、半短轴 $b_2$），以及一个时间 $t$（天）。第二颗行星的轨道与坐标轴对齐，中心在原点，太阳位于 $x$ 坐标非负的焦点上，行星从轨道上 $x$ 坐标最大的点（即 $(a_2, 0)$）开始逆时针运动。要求计算经过 $t$ 天后该行星的位置 $(x, y)$，输出保留三位小数。

## 题目分析

本题的核心是应用开普勒定律描述行星运动。行星轨道为椭圆，运动速度不是均匀的，不能简单地用匀速圆周运动计算角度。需要利用**开普勒第三定律**求出第二颗行星的公转周期，再通过**开普勒方程**从时间求出偏近点角，最后得到行星坐标。

### 开普勒第三定律

> 两颗行星公转周期平方之比等于轨道半长轴立方之比：
> 
> $$
> \left( \frac{t_1}{t_2} \right)^2 = \left( \frac{a_1}{a_2} \right)^3
> $$

由此可得第二颗行星的公转周期：

$$
t_2 = t_1 \cdot \sqrt{ \left( \frac{a_2}{a_1} \right)^3 }
$$

### 开普勒方程

行星在轨道上运动时，**平近点角** $M$（假设匀速圆周运动对应的角度）与**偏近点角** $E$（椭圆上真实角度对应的辅助变量）满足：

$$
M = E - e \sin E
$$

其中：
- $M = \dfrac{t}{t_2} \times 2\pi$（取模 $2\pi$）
- $e = \sqrt{1 - \left( \dfrac{b_2}{a_2} \right)^2}$ 为离心率
- 开普勒方程需要数值求解

### 坐标计算

一旦求得偏近点角 $E$，行星在以椭圆中心为原点的坐标系中的坐标为：

$$
x = a_2 \cos E, \quad y = b_2 \sin E
$$

## 解题思路

1. 根据开普勒第三定律计算 $t_2$；
2. 计算离心率 $e$；
3. 计算平近点角 $M$ 并取模 $2\pi$；
4. 使用**牛顿迭代法**求解 $E$（迭代 $10$ 次足够收敛）；
5. 计算 $x$ 和 $y$，按格式输出。

### 牛顿迭代公式

令 $f(E) = E - e\sin E - M = 0$，则：

$$
E_{n+1} = E_n - \frac{f(E_n)}{f'(E_n)} = E_n - \frac{E_n - e\sin E_n - M}{1 - e\cos E_n}
$$

初始值可取 $E_0 = M$。

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);

int main() {
    int a1, b1, t1, a2, b2, t;
    int caseNum = 0;
    
    while (true) {
        cin >> a1 >> b1 >> t1 >> a2 >> b2 >> t;
        if (a1 == 0 && b1 == 0 && t1 == 0 && a2 == 0 && b2 == 0 && t == 0) break;
        
        ++caseNum;
        
        // 开普勒第三定律：计算第二颗行星的公转周期
        double T2 = t1 * sqrt(pow(1.0 * a2 / a1, 3));
        
        // 离心率
        double e = sqrt(1.0 - (1.0 * b2 / a2) * (1.0 * b2 / a2));
        
        // 平近点角，取模 2*PI
        double M = fmod(2.0 * PI * (t / T2), 2.0 * PI);
        
        // 牛顿法求解偏近点角 E
        double E = M;
        for (int i = 0; i < 10; ++i) {
            double f = E - e * sin(E) - M;
            double fPrime = 1.0 - e * cos(E);
            E = E - f / fPrime;
        }
        
        double x = a2 * cos(E);
        double y = b2 * sin(E);
        
        cout << fixed << setprecision(3);
        cout << "Solar System " << caseNum << ": " << x << " " << y << endl;
    }
    
    return 0;
}
```

## 注意事项

- 使用 `fmod` 对平近点角取模，避免角度过大；
- 牛顿迭代的初始值选择 $M$ 在离心率不太大时收敛很快；
- 输出时使用 `fixed` 和 `setprecision(3)` 控制小数点后三位；
- 注意输入结束条件为六个 $0$。
