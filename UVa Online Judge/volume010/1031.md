## 题目描述

给定若干个密文字符串，每个密文是通过 $\texttt{Kant-DeWitt}$ 加密方法生成的。加密过程如下：

1. 选择一个长度为 $n$ 的明文 $p$ 和一个长度 $m \ge 2n$ 的密文 $c$。
2. 选择参数 $s, t, i, j$，满足 $0 \le s, t, i, j < m$ 且 $i < j$。
3. **第一次放置**：将明文的第 $1$ 个字符放在位置 $s$，之后每放置一个字符，跳过 $i$ 个空槽，将下一个字符放在接下来的第一个空槽中。
4. **第二次放置**：从位置 $t$ 开始找到第一个空槽，将明文的第 $1$ 个字符放在该位置，之后每放置一个字符，跳过 $j$ 个空槽，将下一个字符放在接下来的第一个空槽中。
5. 剩余空槽用随机字母填充。

给定密文字符串，需要找出可能被编码的最长明文。如果有多个不同明文长度相同且均为最长，则输出 $\texttt{Codeword not unique}$。

## 输入格式

输入包含若干行，每行一个密文字符串，仅由大写字母组成，长度在 $2$ 到 $40$ 之间。输入以一行单独的 $\texttt{X}$ 结束。

## 输出格式

对于每个密文字符串，输出一行，格式为 $\texttt{Code k: X}$，其中 $k$ 是测试用例编号（从 $1$ 开始），$X$ 是最长明文。如果最长明文不唯一，则输出 $\texttt{Codeword not unique}$。

## 样例

输入
```
APPURAAURGEGEWE
ABABABAB
THEACM
PROGRAMMINGCONTEST
X
```

输出
```
Code 1: PRAGUE
Code 2: Codeword not unique
Code 3: Codeword not unique
Code 4: Codeword not unique
```

## 题目分析

本题的核心是逆向推导 $\texttt{Kant-DeWitt}$ 加密过程。已知密文 $c$，需要找出所有可能的明文 $p$，使得存在参数 $m, s, t, i, j$ 满足加密规则，且密文 $c$ 能够由该明文按照规则生成。

由于密文长度 $m \le 40$，明文长度 $n$ 满足 $n \le m/2$，我们可以采用枚举所有参数组合的方式，模拟加密过程，验证是否能生成给定的密文。

### 加密过程的数学描述

设明文长度为 $n$，密文长度为 $m$。

**第一次放置**：从位置 $s$ 开始，每次跳过 $i$ 个空槽。由于初始时所有位置都是空的，第一次放置的位置序列 $pos_1[0], pos_1[1], \dots, pos_1[n-1]$ 满足：

$$
pos_1[0] = s
$$

$$
pos_1[k] = \text{从 } pos_1[k-1] \text{ 开始，跳过 } i \text{ 个空槽后的下一个空槽}
$$

这里"空槽"指尚未被第一次放置占用的位置。

**第二次放置**：从位置 $t$ 开始找到第一个空槽作为起点，然后每次跳过 $j$ 个空槽。此时"空槽"指既未被第一次放置占用，也未被第二次放置已放置的字符占用的位置。

### 关键观察

1. **第一次放置的独立性**：第一次放置只依赖于参数 $s$ 和 $i$，与第二次放置无关。
2. **明文的一致性**：两次放置的明文必须完全相同。
3. **位置不重叠**：两次放置的位置集合不能有交集，否则同一位置会被两个字符占用。

### 算法设计思路

基于上述观察，算法分为三个层次：

1. **枚举明文长度 $n$**：从 $m/2$ 向下枚举，找到第一个可行的 $n$ 即为最长长度。
2. **枚举第一次放置参数**：枚举 $s$ 和 $i$，模拟第一次放置，得到明文 $p$。
3. **验证第二次放置**：对于给定的明文 $p$ 和第一次放置的位置集合，枚举 $t$ 和 $j$，验证能否完成第二次放置。

## 解题思路

### 整体框架

算法采用"从大到小枚举 + 剪枝"的策略：

1. 对每个密文 $c$，长度 $m$，明文长度 $n$ 从 $m/2$ 向下枚举到 $1$。
2. 对于每个 $n$，枚举第一次放置的参数 $s$ 和 $i$。
3. 如果第一次放置成功，得到候选明文 $p$，验证第二次放置。
4. 如果某个 $n$ 下有解，记录所有不同的明文，停止枚举。

### 第一次放置的优化

第一次放置时，所有位置都是空的，因此位置序列与起始位置 $s$ 具有**线性关系**：

设 $slots_0$ 为从位置 $0$ 开始、间隔为 $i$ 的放置位置序列，则从位置 $s$ 开始的放置位置序列为：

$$
slots_s[k] = (slots_0[k] + s) \bmod m
$$

利用这一性质，我们只需要对每个 $i$ 计算一次从 $0$ 开始的放置序列，然后通过平移 $s$ 得到所有起始位置的结果。

```cpp
vector<int> slots = simulateFirst(0, i, n);  // 从0开始计算一次
for (int s = 0; s < m; s++) {
    int idx = (slots[k] + s) % m;  // 平移到起始位置 s
}
```

### 第二次放置的空槽列表优化

第二次放置时，空槽集合是动态变化的。我们使用一个动态数组 $\textit{slots}$ 来维护当前所有可用的空槽位置：

1. 初始时，$\textit{slots}$ 包含所有未被第一次放置占用的位置。
2. 放置一个字符后，从 $\textit{slots}$ 中删除该位置。
3. 跳过 $j$ 个空槽，即从当前位置 $pos$ 在 $\textit{slots}$ 中往后数 $j$ 个位置。

关键技巧：用一个指针 $\textit{pos}$ 始终指向**下一个要放置的位置**在 $\textit{slots}$ 中的索引。每次删除当前位置后，$\textit{pos}$ 自动指向被删除元素的后继。

```cpp
int pos = 0;
while (slots[pos] != t) ++pos;        // 找到起始位置
slots.erase(slots.begin() + pos);      // 删除起始位置
if (pos == slots.size()) pos = 0;      // 处理绕回

for (int k = 1; k < n; k++) {
    pos = (pos + j) % slots.size();    // 跳过 j 个空槽
    int dest = slots[pos];              // 目标位置
    if (cipher[dest] != message[k]) break;
    slots.erase(slots.begin() + pos);   // 删除当前位置
    if (pos == slots.size()) pos = 0;   // 处理绕回
}
```

### 剪枝策略

1. **频次剪枝**：如果一个字符在候选明文中出现的次数超过在密文中出现次数的一半，则不可能完成两次放置（因为两次放置总共需要该字符出现 $2 \times \text{freq}$ 次）。

```cpp
if (f[c - 'A'] * 2 > F[c - 'A']) { valid = 0; break; }
```

2. **长度上界**：明文长度 $n$ 最多为 $m/2$，因为两次放置需要 $2n$ 个不同位置。

3. **提前终止**：一旦某个 $n$ 有解，立即停止枚举更小的 $n$。

### 复杂度分析

- 枚举明文长度 $n$：$O(m)$ 次，$m \le 40$。
- 枚举第一次放置参数 $s$ 和 $i$：$O(m^2)$ 次。
- 枚举第二次放置参数 $t$ 和 $j$：$O(m^2)$ 次。
- 每次放置模拟 $O(n)$ 个字符。

总时间复杂度：$O(m^4 \cdot n) \approx O(40^5)$，实际运行中由于剪枝和 $n \le m/2$，远小于理论上限。

空间复杂度：$O(m)$，用于存储位置数组。

## 代码实现

```cpp
// Insecure in Prague

#include <bits/stdc++.h>
using namespace std;

string cipher, message;
int m, F[26], p[45], flag[45];
set<string> answers;

// 模拟第一次放置，返回位置序列
// 参数：s-起始位置，i-间隔，n-明文长度
vector<int> simulateFirst(int s, int i, int n) {
    vector<int> slots;
    memset(flag, -1, sizeof flag);
    for (int k = 0; k < n; k++) {
        flag[s] = k;
        slots.push_back(s);
        int skipped = 0;
        while (skipped < i) {
            s = (s + 1) % m;
            if (flag[s] == -1) skipped++;
        }
        do s = (s + 1) % m; while (flag[s] != -1);
    }
    return slots;
}

// 模拟第二次放置，检查是否能放置成功
// 参数：i-第一次放置的间隔，n-明文长度
bool simulateSecond(int i, int n) {
    // 构建空槽列表（未被第一次占用的位置）
    vector<int> empty;
    for (int k = 0; k < m; k++) if (p[k] == -1) empty.push_back(k);
    
    // 收集可能的起始位置（必须是空槽且字符匹配）
    vector<int> starts;
    for (int t = 0; t < m; t++)
        if (p[t] == -1 && cipher[t] == message.front())
            starts.push_back(t);
    
    for (int t : starts) {
        for (int j = i + 1; j < m; j++) {
            vector<int> slots = empty;
            int pos = 0;
            while (slots[pos] != t) ++pos;
            slots.erase(slots.begin() + pos);
            if (pos == slots.size()) pos = 0;
            
            int valid = 1;
            for (int k = 1; k < n; ++k) {
                pos = (pos + j) % slots.size();
                int dest = slots[pos];
                if (cipher[dest] != message[k]) { valid = 0; break; }
                slots.erase(slots.begin() + pos);
                if (pos == slots.size()) pos = 0;
            }
            if (valid) return true;
        }
    }
    return false;
}

void solve() {
    m = cipher.length();
    memset(F, 0, sizeof(F));
    for (char c : cipher) F[c - 'A']++;
    answers.clear();
    
    // 从大到小枚举明文长度
    for (int n = m / 2; n >= 1; n--) {
        for (int i = 0; i < m && answers.size() <= 1; i++) {
            // 只计算一次从0开始的放置序列，利用线性关系平移
            vector<int> slots = simulateFirst(0, i, n);
            for (int s = 0; s < m && answers.size() <= 1; s++) {
                message.clear();
                int f[26] = {0}, valid = 1;
                memset(p, -1, sizeof p);
                
                // 平移得到从s开始的放置位置
                for (int k = 0; k < n; k++) {
                    int idx = (slots[k] + s) % m;
                    p[idx] = k;
                    char c = cipher[idx];
                    message += c;
                    f[c - 'A']++;
                    // 频次剪枝
                    if (f[c - 'A'] * 2 > F[c - 'A']) { valid = 0; break; }
                }
                if (!valid) continue;
                if (simulateSecond(i, n)) answers.insert(message);
            }
        }
        if (answers.size()) return;
    }
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    string line;
    int cs = 1;
    while (getline(cin, line)) {
        if (line == "X") break;
        cipher = line;
        solve();
        cout << "Code " << cs++ << ": ";
        if (answers.size() == 1) cout << *answers.begin() << '\n';
        else cout << "Codeword not unique" << '\n';
    }
    return 0;
}
```

## 总结

本题的核心技巧包括：

1. **逆向枚举**：从最长可能的明文长度开始枚举，找到第一个可行解即为答案。

2. **线性平移优化**：第一次放置的位置序列具有线性关系，只需计算一次基准序列，通过平移得到所有起始位置的结果。

3. **空槽列表动态维护**：第二次放置时使用动态数组维护空槽，通过指针操作实现 $O(1)$ 的跳跃和删除。

4. **频次剪枝**：利用字符出现次数的必要条件提前排除不可能的解。

5. **集合去重**：使用 $\texttt{set}$ 自动去重，方便判断明文是否唯一。

本题虽然枚举复杂度较高，但由于 $m \le 40$，配合合理的剪枝和优化，能够在时限内通过。关键是要理解加密过程的本质，将问题转化为参数枚举和模拟验证。
