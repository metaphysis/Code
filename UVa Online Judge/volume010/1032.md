[UVa 1032 Intersecting Dates](https://blog.csdn.net/metaphysis/article/details/162044836)

## 题目描述

给定多个测试用例，每个用例包含两组日期范围：已有报价的日期范围和当前需要的日期范围。需要计算必须从服务中新获取的日期范围，即所需日期范围减去已有日期范围的差集。要求合并重叠或相邻的日期范围，并按时间顺序输出结果。

## 输入格式

每个测试用例以两个非负整数 $NX$ 和 $NR$ 开头（$0 \le NX, NR \le 100$），分别表示已有日期范围和所需日期范围的数量。接下来有 $NX + NR$ 对日期，每对日期中第一个日期小于等于第二个日期。前 $NX$ 对表示已有日期范围，后 $NR$ 对表示所需日期范围。日期格式为 `YYYYMMDD`，年份范围为 $1700$ 到 $2100$。输入以 `0 0` 结束。

## 输出格式

对于每个测试用例，首先输出 `Case N:` 独占一行。随后输出必须获取的日期范围，每个日期范围占一行，行首有 4 个空格的缩进。如果没有必须获取的日期范围，则输出 `No additional quotes are required.`。如果日期范围由单个日期组成，则直接输出该日期；否则输出 `start to end` 格式。多个测试用例之间用空行分隔。

```
19720101 19720131

19720301 19720301
```


## 题目分析

本题的核心是**集合差运算**：给定已有日期范围集合 $A$ 和所需日期范围集合 $B$，求 $B \setminus A$，即需要新获取的日期范围。

日期范围的直接处理面临几个挑战：

1. **日期比较与相邻判断**：日期格式为 `YYYYMMDD`，虽然可以按整数比较大小，但判断两个日期是否相邻需要处理月份天数、闰年等复杂边界条件。

2. **区间合并**：如果两个日期范围相邻或重叠，需要合并为一个连续范围。例如 `[1/1/2020, 1/31/2020]` 和 `[2/1/2020, 2/28/2020]` 相邻，应合并为 `[1/1/2020, 2/28/2020]`。

3. **差集计算**：需要从每个所需区间中扣除所有已有区间的覆盖部分，未被覆盖的部分就是需要获取的。

4. **输出格式精确**：每个日期范围前有 4 个空格缩进，单日期特殊处理，Case 之间用空行分隔。

一种直观的解决方案是：**将日期统一转换为从某个基准日开始的天数**。这样日期区间就变成了整数区间，所有的比较、合并、差集运算都简化为整数运算，完全避免了日期边界处理的复杂性。

## 解题思路

### 1. 日期与天数的转换

选择 $1700$ 年 $1$ 月 $1$ 日作为基准日（题目保证年份 $\ge 1700$）。定义函数 $\textit{dateToDays}$：

$$
\textit{dateToDays}(\textit{date}) = \sum_{y=1700}^{\textit{year}-1} \textit{daysInYear}(y) + \sum_{m=1}^{\textit{month}-1} \textit{daysInMonth}(\textit{year}, m) + (\textit{day} - 1)
$$

其中 $\textit{daysInYear}(y)$ 返回 $y$ 年的天数（$365$ 或 $366$），$\textit{daysInMonth}(y, m)$ 返回 $y$ 年 $m$ 月的天数。这样，每个日期都唯一对应一个从 $0$ 开始的整数天数。

反向转换 $\textit{daysToDate}$ 则通过逐年、逐月减去天数来恢复日期。

### 2. 区间合并

给定一组整数区间 $[l, r]$，合并规则为：

- 按左端点升序排序。
- 依次扫描，若当前区间的左端点 $\textit{curL}$ 小于等于上一个合并区间的右端点加 $1$（即 $\textit{curL} \le \textit{lastR} + 1$），说明两个区间相邻或重叠，合并为 $[\textit{lastL}, \max(\textit{lastR}, \textit{curR})]$。
- 否则，当前区间作为一个新的合并区间。

相邻判断使用 $\le \textit{lastR} + 1$ 是因为日期连续时，例如 `[1, 31]` 和 `[32, 59]` 在日期上相邻，中间没有空缺，应当合并。

### 3. 差集计算

已有区间集合合并为 $\textit{mergedExisting}$，所需区间集合合并为 $\textit{mergedRequired}$。对每个所需区间 $[\textit{reqL}, \textit{reqR}]$：

- 维护变量 $\textit{curL} = \textit{reqL}$，表示当前尚未被覆盖的区间起点。
- 遍历 $\textit{mergedExisting}$ 中的每个区间 $[\textit{exL}, \textit{exR}]$：
  - 如果 $\textit{exR} < \textit{curL}$，该已有区间在当前区间之前，跳过。
  - 如果 $\textit{exL} > \textit{reqR}$，后续已有区间也不会覆盖当前区间，跳出循环。
  - 如果已有区间覆盖了 $\textit{curL}$ 的位置（$\textit{exL} \le \textit{curL} \le \textit{exR}$），则 $\textit{curL}$ 更新为 $\textit{exR} + 1$。
  - 如果已有区间在 $\textit{curL}$ 之后开始（$\textit{curL} < \textit{exL} \le \textit{reqR}$），则 $[\textit{curL}, \textit{exL} - 1]$ 是未被覆盖的部分，加入结果集，然后 $\textit{curL}$ 更新为 $\max(\textit{curL}, \textit{exR} + 1)$。
- 遍历结束后，若 $\textit{curL} \le \textit{reqR}$，剩余部分加入结果集。

### 4. 结果输出

将结果天数区间转换回日期格式，按顺序输出：

- 每个测试用例先输出 `Case N:` 独占一行。
- 每个日期范围前缩进 4 个空格。
- 单日期输出格式为 `M/D/YYYY`，多日期输出 `M1/D1/YYYY1 to M2/D2/YYYY2`。
- 多个日期范围用换行分隔。
- 不同测试用例之间用空行分隔。

### 复杂度分析

- 每个测试用例中，日期转换复杂度为 $O(NX \cdot Y + NR \cdot Y)$，其中 $Y$ 为年份跨度（最大约 $400$），可视为常数。
- 区间排序复杂度为 $O((NX + NR) \log (NX + NR))$。
- 差集计算复杂度为 $O(NX \cdot NR)$，但 $NX, NR \le 100$，完全可接受。
- 总时间复杂度：$O((NX + NR) \log (NX + NR))$，空间复杂度：$O(NX + NR)$。

```cpp
// Intersecting Dates
// UVa ID: 1032
// Verdict: Accepted
// Submission Date: 2026-06-16
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 判断是否为闰年
bool isLeap(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

// 每月的天数（非闰年）
int daysInMonth[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

// 将日期 YYYYMMDD 转换为从 1/1/1700 开始经过的天数
int dateToDays(int date) {
    int year = date / 10000;
    int month = (date / 100) % 100;
    int day = date % 100;
    
    int total = 0;
    // 累加年份
    for (int y = 1700; y < year; ++y) {
        total += isLeap(y) ? 366 : 365;
    }
    // 累加月份
    for (int m = 1; m < month; ++m) {
        if (m == 2) total += isLeap(year) ? 29 : 28;
        else total += daysInMonth[m];
    }
    // 累加天数（从1号开始，所以减1使1号对应0）
    total += day - 1;
    return total;
}

// 将天数转换回 YYYYMMDD 格式
int daysToDate(int days) {
    int year = 1700;
    // 减去每年的天数
    while (true) {
        int daysInYear = isLeap(year) ? 366 : 365;
        if (days < daysInYear) break;
        days -= daysInYear;
        ++year;
    }
    int month = 1;
    while (true) {
        int daysInMon = (month == 2) ? (isLeap(year) ? 29 : 28) : daysInMonth[month];
        if (days < daysInMon) break;
        days -= daysInMon;
        ++month;
    }
    int day = days + 1;  // 因为之前减了1，现在加回来
    return year * 10000 + month * 100 + day;
}

// 格式化日期为 月/日/年
string formatDate(int date) {
    int year = date / 10000;
    int month = (date / 100) % 100;
    int day = date % 100;
    return to_string(month) + "/" + to_string(day) + "/" + to_string(year);
}

// 合并区间（区间用天数表示）
vector<pair<int, int>> mergeIntervals(vector<pair<int, int>>& intervals) {
    if (intervals.empty()) return {};
    sort(intervals.begin(), intervals.end());
    vector<pair<int, int>> merged;
    merged.push_back(intervals[0]);
    for (size_t i = 1; i < intervals.size(); ++i) {
        int curL = intervals[i].first, curR = intervals[i].second;
        int lastL = merged.back().first, lastR = merged.back().second;
        // 相邻或重叠则合并（相邻条件：curL <= lastR + 1）
        if (curL <= lastR + 1) merged.back().second = max(lastR, curR);
        else merged.push_back({curL, curR});
    }
    return merged;
}

int main() {
    int NX, NR;
    int caseNo = 0;
    while (cin >> NX >> NR) {
        if (NX == 0 && NR == 0) break;
        
        vector<pair<int, int>> existing, required;
        // 读取已有区间并转换为天数
        for (int i = 0; i < NX; ++i) {
            int startDate, endDate;
            cin >> startDate >> endDate;
            int startDay = dateToDays(startDate);
            int endDay = dateToDays(endDate);
            existing.push_back({startDay, endDay});
        }
        // 读取所需区间并转换为天数
        for (int i = 0; i < NR; ++i) {
            int startDate, endDate;
            cin >> startDate >> endDate;
            int startDay = dateToDays(startDate);
            int endDay = dateToDays(endDate);
            required.push_back({startDay, endDay});
        }
        
        // 合并已有区间（天数版本）
        vector<pair<int, int>> mergedExisting = mergeIntervals(existing);
        // 合并所需区间（天数版本）
        vector<pair<int, int>> mergedRequired = mergeIntervals(required);
        
        // 计算差集：所需区间减去已有区间
        vector<pair<int, int>> resultDays;
        for (auto req : mergedRequired) {
            int reqL = req.first, reqR = req.second;
            int curL = reqL;
            for (auto ex : mergedExisting) {
                int exL = ex.first, exR = ex.second;
                if (exR < curL) continue;
                if (exL > reqR) break;
                // 已有区间覆盖了当前待处理区间的一部分
                if (exL <= curL && exR >= curL) {
                    curL = exR + 1;
                } else if (exL > curL && exL <= reqR) {
                    // 未被覆盖的部分：curL 到 exL-1
                    if (curL <= exL - 1) {
                        resultDays.push_back({curL, exL - 1});
                    }
                    curL = max(curL, exR + 1);
                }
                if (curL > reqR) break;
            }
            // 剩余未被覆盖的部分
            if (curL <= reqR) {
                resultDays.push_back({curL, reqR});
            }
        }
        
        // 将天数结果转换回日期格式
        vector<pair<int, int>> resultDates;
        for (auto p : resultDays) {
            int startDate = daysToDate(p.first);
            int endDate = daysToDate(p.second);
            resultDates.push_back({startDate, endDate});
        }
        
        // 输出
        if (caseNo) cout << '\n';
        cout << "Case " << ++caseNo << ":\n";
        if (resultDates.empty()) cout << "    No additional quotes are required.\n";
        else {
            for (size_t i = 0; i < resultDates.size(); ++i) {
                int l = resultDates[i].first, r = resultDates[i].second;
                cout << "    ";
                if (l == r) cout << formatDate(l);
                else cout << formatDate(l) << " to " << formatDate(r);
                cout << '\n';
            }
        }
    }
    return 0;
}
```

## 总结

本题的关键技巧是将日期转换为天数，将复杂的时间边界问题转化为简单的整数区间运算。这种**统一表示法**是处理日期、时间等区间问题的常用思路，值得借鉴。

需要注意的输出细节包括：
- 每个日期范围前有 4 个空格缩进。
- 单日期时不输出 `to` 部分。
- 不同测试用例之间用空行分隔。
- 合并时相邻区间（差 $1$ 天）也要合并。

通过将日期标准化为天数，区间合并和差集计算的逻辑变得清晰简洁，避免了手动处理闰年、大小月等边界问题，使代码更加健壮和易于维护。
