## 题目翻译

有一个会议需要安排工作坊和房间。每个工作坊有参与人数 $p$ 和持续时间 $d$（分钟），所有工作坊都在 $14:00$ 开始。每个房间有座位数 $s$ 和必须清空的时间 $hh:mm$（从 $14:01$ 到 $23:59$），房间从 $14:00$ 开始可用。

目标是将工作坊分配到房间中，每个工作坊必须分配到一个容量足够（$s \geq p$）且可用时间足够（可用时间 $\geq d$）的房间。如果无法全部分配，剩余的工作坊将被安排在帐篷中。

优化目标有两个优先级：
1. **最小化帐篷工作坊的数量**
2. 在满足前述条件的前提下，**最小化参加帐篷工作坊的总人数**

## 问题分析

这是一个典型的**带权二分图匹配**问题：
- 左部节点：工作坊，每个节点有权重 $p$（人数）
- 右部节点：房间，每个节点有容量 $s$ 和可用时间 $t$
- 边：如果工作坊 $i$ 可以放入房间 $j$（$p_i \leq s_j$ 且 $d_i \leq t_j$），则存在一条边
- 目标：在最大匹配的前提下，让匹配的节点权重和最大（等价于让未匹配的节点权重和最小）

## 解题思路

### 方法一：匈牙利算法

匈牙利算法是求解二分图最大匹配的经典算法。为了满足第二个优化目标，我们需要在求最大匹配的同时，优先匹配人数多的工作坊。

#### 算法步骤

1. **数据读取与预处理**
   - 读取工作坊信息 $(p, d)$
   - 读取房间信息 $(s, t)$，将清空时间转换为从 $14:00$ 开始的分钟数：$t = (hh - 14) \times 60 + mm$

2. **构建邻接表**
   - 对于每个工作坊 $i$ 和每个房间 $j$，如果满足 $p_i \leq s_j$ 且 $d_i \leq t_j$，则在邻接表中添加边 $i \rightarrow j$

3. **工作坊排序**
   - 将工作坊按人数降序排序，这样在 DFS 过程中会优先尝试匹配人数多的工作坊

4. **匈牙利算法求最大匹配**
   - 对每个工作坊（按人数降序顺序）尝试寻找增广路
   - 使用 $\texttt{seen}$ 数组标记本轮 $\texttt{DFS}$ 中已访问的房间，避免重复访问
   - $\texttt{matchR}[j]$ 记录房间 $j$ 匹配的工作坊编号，$-1$ 表示未匹配

5. **结果统计**
   - 匹配数 $matched$ = 成功匹配的工作坊数量
   - 帐篷工作坊数量 = $w - matched$
   - 帐篷人数 = 未匹配的工作坊人数之和

#### 时间复杂度

- 构建邻接表：$O(w \times r)$
- 匈牙利算法：最坏 $O(w \times r \times w)$，但在本题数据范围（$w, r \leq 1000$）下可接受
- 实际运行时间约 $840\text{ms}$

### 方法二：贪心 + 排序

观察题目特点，我们可以发现一个更巧妙的贪心策略，不需要复杂的图匹配算法。

#### 贪心策略的正确性证明

**贪心策略**：
1. 将工作坊按人数升序排序
2. 将房间按可用时间升序排序
3. 对每个房间（按时间紧迫顺序），从人数最大的工作坊开始找第一个可行的未分配工作坊

**为什么这是正确的？**

1. **按房间时间升序处理**：时间越紧迫的房间越早处理，避免浪费可用时间长的房间去匹配短工作坊，从而最大化匹配数
2. **对每个房间选最大可行工作坊**：在保证匹配数最大的前提下，优先消耗人数多的工作坊，这样剩下的小工作坊更容易被后续房间匹配，同时让已匹配的工作坊人数总和最大
3. **工作坊按人数升序排序**：配合从大到小扫描，保证每次都能快速找到当前最大的可行工作坊

这个贪心策略实际上等价于：
- 先满足时间约束紧的房间
- 在时间允许的情况下，优先分配人数多的工作坊
- 这样可以最大化匹配数，同时最大化匹配的总人数

#### 算法步骤

1. **数据读取与预处理**（同方法一）

2. **排序**
   - 工作坊按人数升序排序：`sort(workshops + 1, workshops + w + 1)`
   - 房间按可用时间升序排序：`sort(rooms + 1, rooms + r + 1)`

3. **贪心匹配**
   ```
   for 每个房间 i (按时间升序)
       for 工作坊 j = w downto 1 (从人数最大开始)
           if 工作坊 j 未分配 and 容量够 and 时间够
               分配房间 i 给工作坊 j
               break
   ```

4. **结果统计**
   - 匹配数 $matched$ = 成功分配的工作坊数量
   - 帐篷工作坊数量 = $w - matched$
   - 帐篷人数 = 总人数 - 已匹配的工作坊人数之和

#### 时间复杂度

- 排序：$O(w \log w + r \log r)$
- 贪心匹配：$O(r \times w)$
- 总复杂度约 $10^6$，非常高效

## 代码实现

### 方法一：匈牙利算法实现

```cpp
// Workshops
// UVa ID: 1046
// Verdict: Accepted
// Submission Date: 2026-02-27
// UVa Run Time: 1.020s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Workshop {
    int participants;
    int duration;
};

struct Room {
    int seats;
    int availableTime;
};

bool canAssign(const Workshop &w, const Room &r) {
    return r.seats >= w.participants && r.availableTime >= w.duration;
}

bool dfs(int u, const vector<vector<int>> &adj, vector<int> &matchR, vector<bool> &seen) {
    for (int v : adj[u]) {
        if (!seen[v]) {
            seen[v] = true;
            if (matchR[v] == -1 || dfs(matchR[v], adj, matchR, seen)) {
                matchR[v] = u;
                return true;
            }
        }
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int trial = 0, w, r;
    while (cin >> w, w) {
        trial++;
        
        vector<Workshop> workshops(w);
        for (int i = 0; i < w; i++)
            cin >> workshops[i].participants >> workshops[i].duration;
        
        cin >> r;
        vector<Room> rooms(r);
        for (int i = 0; i < r; i++) {
            int seats, hh, mm;
            char colon;
            cin >> seats >> hh >> colon >> mm;
            rooms[i].seats = seats;
            rooms[i].availableTime = (hh - 14) * 60 + mm;
        }
        
        // 构建邻接表
        vector<vector<int>> adj(w);
        for (int i = 0; i < w; i++)
            for (int j = 0; j < r; j++)
                if (canAssign(workshops[i], rooms[j]))
                    adj[i].push_back(j);
        
        // 按人数降序排序工作坊
        vector<int> order(w);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return workshops[a].participants > workshops[b].participants;
        });
        
        // 匈牙利算法求最大匹配
        vector<int> matchR(r, -1);
        int matched = 0;
        for (int u : order) {
            vector<bool> seen(r, false);
            if (dfs(u, adj, matchR, seen))
                matched++;
        }
        
        // 统计帐篷人数
        int tentWorkshops = w - matched;
        int tentParticipants = 0;
        vector<bool> used(w, false);
        for (int j = 0; j < r; j++)
            if (matchR[j] != -1)
                used[matchR[j]] = true;
        for (int i = 0; i < w; i++)
            if (!used[i])
                tentParticipants += workshops[i].participants;
        
        cout << "Trial " << trial << ": " << tentWorkshops << " " << tentParticipants << "\n\n";
    }
    return 0;
}
```

### 方法二：贪心 + 排序实现

```cpp
// Workshops
// UVa ID: 1046
// Verdict: Accepted
// Submission Date: 2026-02-27
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int trial = 0;
    int w, r;
    
    while (cin >> w, w) {
        trial++;
        
        // 存储工作坊：first = 人数, second = 时长
        vector<pair<int, int>> workshops(w + 1);
        for (int i = 1; i <= w; i++)
            cin >> workshops[i].first >> workshops[i].second;
        
        cin >> r;
        // 存储房间：first = 可用时间, second = 容量
        vector<pair<int, int>> rooms(r + 1);
        for (int i = 1; i <= r; i++) {
            int seats, hh, mm;
            char colon;
            cin >> seats >> hh >> colon >> mm;
            rooms[i].first = (hh - 14) * 60 + mm;  // 可用时间
            rooms[i].second = seats;                // 容量
        }
        
        // 关键步骤1：工作坊按人数升序排序
        sort(workshops.begin() + 1, workshops.end());
        // 关键步骤2：房间按可用时间升序排序
        sort(rooms.begin() + 1, rooms.end());
        
        vector<bool> used(w + 1, false);
        int matched = 0;
        int totalParticipants = 0;
        
        // 关键步骤3：对每个房间，从大到小找可行的工作坊
        for (int i = 1; i <= r; i++) {
            int roomTime = rooms[i].first;
            int roomCap = rooms[i].second;
            
            // 从人数最大的工作坊开始找
            for (int j = w; j >= 1; j--) {
                if (!used[j] && 
                    workshops[j].first <= roomCap &&  // 人数够
                    workshops[j].second <= roomTime) { // 时间够
                    used[j] = true;
                    matched++;
                    totalParticipants += workshops[j].first;
                    break;
                }
            }
        }
        
        // 计算总人数
        int sumAll = 0;
        for (int i = 1; i <= w; i++)
            sumAll += workshops[i].first;
        
        int tentWorkshops = w - matched;
        int tentParticipants = sumAll - totalParticipants;
        
        cout << "Trial " << trial << ": " << tentWorkshops << " " << tentParticipants << "\n\n";
    }
    
    return 0;
}
```

## 总结

本题的两种解法各有特点：

| 方法 | 时间复杂度 | 代码复杂度 | 思路 |
|------|------------|------------|------|
| 匈牙利算法 | $O(w \times r \times w)$ | 中等 | 标准二分图匹配 + 按权重排序 |
| 贪心 + 排序 | $O(w \log w + r \log r + w \times r)$ | 简单 | 巧妙利用排序和贪心策略 |

贪心解法不仅代码简洁，而且效率更高，是本题的最优解法。其核心思想是：**按时间紧迫度处理房间，优先分配人数多的工作坊**，这样在保证最大匹配数的同时，自然达到了最小化帐篷人数的目标。
