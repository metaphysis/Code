## 题目描述

$\texttt{Hugh Samston}$ 拥有一家餐饮服务公司，受邀为 $\texttt{ICPC}$ 世界总决赛提供甜点。他将提供带有一勺冰淇淋的派切片。 $\texttt{Hugh}$ 希望提供最佳服务，同时获得最大利润。他知道：

- 每种派类型的切片数量
- 每种冰淇淋类型的勺数
- 每种派与冰淇淋组合的利润（某些组合不可销售，用 $-1$ 表示）
- 派切片总数等于冰淇淋勺总数，所有物品都会被用完

要求计算在所有物品都配对销售的情况下，能够获得的最小和最大利润。

## 输入格式

输入包含多个测试用例。每个测试用例格式如下：
- 第一行：两个整数 $P$ $(P \le 50)$ 和 $I$ $(I \le 50)$ ，表示派类型数和冰淇淋类型数
- 第二行： $P$ 个整数，表示每种派类型的切片数量
- 第三行： $I$ 个整数，表示每种冰淇淋类型的勺数
- 接下来 $P$ 行，每行 $I$ 个浮点数，表示利润矩阵
- 最后一行为 `0 0`

所有整数 $\le 100$ ，可销售组合利润 $>0$ 且 $\le 10$ ，保留两位小数。保证至少有一种可行方案。

## 输出格式

对每个测试用例，输出问题编号（从 $1$ 开始）以及最小和最大利润，格式为：  
`Problem X: min_profit to max_profit`  
所有数字保留两位小数。

## 题目分析

这是一个典型的 **二分图带权匹配问题** ：

- **左部节点** ：派切片（每种类型有多个切片，可视为多个相同节点）
- **右部节点** ：冰淇淋勺（同理）
- **边权** ：利润（不可销售则不连边）
- **目标** ：找到一个完美匹配（所有切片和勺都配对），使得总利润最小或最大

由于每种类型可能有多件物品，这是一个 **多对多匹配问题** ，可以转化为 **最小费用最大流** 和 **最大费用最大流** 问题。

### 网络流建模

建立费用流模型如下：

1. **源点 $S$** 到 **每种派类型节点 $p_i$** ：
   - 容量：该类型派的数量
   - 费用： $0$

2. **每种派类型节点 $p_i$** 到 **每种冰淇淋类型节点 $i_j$** ：
   - 容量：无穷大（只要数量够即可）
   - 费用：该组合的利润（若为 $-1$ 则不建边）

3. **每种冰淇淋类型节点 $i_j$** 到 **汇点 $T$** ：
   - 容量：该类型冰淇淋的数量
   - 费用： $0$

### 求解步骤

1. **最小利润** ：直接对上述网络跑最小费用最大流，得到的总费用即为最小总利润。
2. **最大利润** ：将边的费用取负，再跑最小费用最大流，得到的总费用取负即为最大总利润。

### 数值处理细节

- 利润为浮点数，但最多两位小数。为避免浮点误差，将所有利润乘以 $100$ 转为整数，最后输出时再除以 $100.0$ 。
- 容量和节点数： $P, I \le 50$ ，每种物品数量 $\le 100$ ，总物品数 $\le 5000$ 。但节点数只有 $P+I+2 \le 102$ ，边数 $O(P \times I)$ ，使用 $\texttt{SPFA}$ 算法实现费用流完全可行。

---

## 算法复杂度分析

- 节点数： $O(P+I)$
- 边数： $O(P \times I)$
- 费用流算法：使用 $\texttt{SPFA}$ 寻找增广路，每次增广至少增加 $1$ 单位流量，总流量为总物品数 $N$ ，因此复杂度约为 $O(N \times \text{边数})$ 。最坏情况 $N \le 5000$ ，边数 $\le 2500$ ，计算量约 $1.25 \times 10^7$ ，在合理范围内。

## 代码实现

```cpp
// Remember the A La Mode

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
const int MAXN = 105; // 最多 50+50+2 个节点

struct Edge {
    int to, cap, flow, cost, next;
} edges[100005];
int head[MAXN], edgeCnt;
int pre[MAXN], dist[MAXN];
bool inQueue[MAXN];
int nodeCnt;

void initGraph(int n) {
    nodeCnt = n;
    edgeCnt = 0;
    memset(head, -1, sizeof(head));
}

void addEdge(int u, int v, int cap, int cost) {
    edges[edgeCnt] = {v, cap, 0, cost, head[u]};
    head[u] = edgeCnt++;
    edges[edgeCnt] = {u, 0, 0, -cost, head[v]};
    head[v] = edgeCnt++;
}

bool spfa(int s, int t, int& flow, int& cost) {
    queue<int> q;
    memset(dist, 0x3f, sizeof(dist));
    memset(inQueue, false, sizeof(inQueue));
    dist[s] = 0;
    pre[s] = -1;
    q.push(s);
    inQueue[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inQueue[u] = false;
        for (int i = head[u]; i != -1; i = edges[i].next) {
            Edge& e = edges[i];
            if (e.cap > e.flow && dist[e.to] > dist[u] + e.cost) {
                dist[e.to] = dist[u] + e.cost;
                pre[e.to] = i;
                if (!inQueue[e.to]) {
                    q.push(e.to);
                    inQueue[e.to] = true;
                }
            }
        }
    }
    if (dist[t] == INF) return false;
    int aug = INF;
    for (int u = t; u != s; u = edges[pre[u] ^ 1].to)
        aug = min(aug, edges[pre[u]].cap - edges[pre[u]].flow);
    flow += aug;
    cost += dist[t] * aug;
    for (int u = t; u != s; u = edges[pre[u] ^ 1].to) {
        edges[pre[u]].flow += aug;
        edges[pre[u] ^ 1].flow -= aug;
    }
    return true;
}

int minCostMaxFlow(int s, int t) {
    int flow = 0, cost = 0;
    while (spfa(s, t, flow, cost));
    return cost;
}

int main() {
    int P, I, caseNo = 1;
    while (scanf("%d %d", &P, &I) == 2 && (P || I)) {
        vector<int> pieCount(P), iceCount(I);
        for (int i = 0; i < P; i++) scanf("%d", &pieCount[i]);
        for (int i = 0; i < I; i++) scanf("%d", &iceCount[i]);
        vector<vector<double>> profit(P, vector<double>(I));
        for (int i = 0; i < P; i++)
            for (int j = 0; j < I; j++)
                scanf("%lf", &profit[i][j]);
        
        // 建图：节点编号：0~P-1 为派类型，P~P+I-1 为冰淇淋类型，P+I 为源点，P+I+1 为汇点
        int S = P + I, T = P + I + 1;
        initGraph(P + I + 2);
        
        // 源点到派类型
        for (int i = 0; i < P; i++) addEdge(S, i, pieCount[i], 0);
        // 冰淇淋类型到汇点
        for (int j = 0; j < I; j++) addEdge(P + j, T, iceCount[j], 0);
        // 派类型到冰淇淋类型（仅当利润不为-1）
        for (int i = 0; i < P; i++)
            for (int j = 0; j < I; j++)
                if (profit[i][j] >= 0) addEdge(i, P + j, INF, (int)(profit[i][j] * 100 + 0.5));
        
        int minProfit = minCostMaxFlow(S, T);
        
        // 重新建图求最大费用最大流（将费用取负）
        initGraph(P + I + 2);
        for (int i = 0; i < P; i++) addEdge(S, i, pieCount[i], 0);
        for (int j = 0; j < I; j++) addEdge(P + j, T, iceCount[j], 0);
        for (int i = 0; i < P; i++)
            for (int j = 0; j < I; j++)
                if (profit[i][j] >= 0) addEdge(i, P + j, INF, -(int)(profit[i][j] * 100 + 0.5));
        
        int maxProfit = -minCostMaxFlow(S, T);
        
        printf("Problem %d: %.2f to %.2f\n", caseNo++, minProfit / 100.0, maxProfit / 100.0);
    }
    return 0;
}
```

## 总结

本题通过将多对多匹配问题转化为费用流问题，巧妙地解决了利润最小化和最大化的问题。关键点在于：
1. 正确建模，将派类型和冰淇淋类型作为中间节点
2. 处理浮点数利润时转换为整数以避免精度问题
3. 通过费用取负的方式统一用最小费用流算法求解最大利润问题

这种建模方法在许多类似分配问题中都非常实用，是图论和网络流应用的经典案例。
