[UVa 1063 Marble Game](https://blog.csdn.net/metaphysis/article/details/158318598)

## 题目描述

在一个 $N \times N$ 的棋盘上（$2 \leq N \leq 4$），有 $M$ 个弹珠和 $M$ 个洞，分别编号为 $1$ 到 $M$。棋盘上可能有 $W$ 堵墙，每堵墙位于两个相邻的方格之间。游戏开始时，每个弹珠占据一个不同的方格。每次移动可以选择抬起棋盘的一侧（东、南、西、北），所有弹珠会同时向相反方向滚动，直到遇到以下情况之一停止：

- 遇到墙
- 遇到空洞（掉进去）
- 下一个方格被其他弹珠占据
- 到达棋盘边界（边界视为墙）

弹珠掉进洞后，该洞被填满，其他弹珠之后可以滚过这个洞。游戏目标是用最少的移动次数，让每个弹珠都掉进与自己编号相同的洞里。

## 题目分析

这是一个典型的状态空间搜索问题。由于棋盘最大为 $4 \times 4$，状态数量是有限的，可以使用 $\texttt{BFS}$ 求最少移动次数。

### 状态表示

每个状态需要包含以下信息：

- 每个弹珠的当前位置（如果已进洞，则位置标记为 $(-1, -1)$）
- 每个弹珠进了哪个洞（$-1$ 表示未进洞）
- 每个洞是否已被填满

由于 $M \leq N^2 \leq 16$，状态数量在可接受范围内。

### 移动规则

一次移动需要模拟所有弹珠同时滚动的过程。关键点在于：

1. **同时性**：所有弹珠同时开始移动，不能按顺序一个一个处理
2. **相互阻挡**：弹珠移动过程中可能被其他弹珠挡住
3. **空洞处理**：任何弹珠遇到未填的洞都会掉进去，洞被填满
4. **多步移动**：一次抬起操作中，弹珠可能连续滚动多格，直到被阻挡

### 模拟方法

采用逐格模拟的方法：

1. 重复执行直到没有弹珠能移动：
   - 按移动方向的相反顺序处理每个弹珠（这样可以正确处理阻挡关系）
   - 每个弹珠尝试向指定方向移动一格
   - 检查下一格是否可进入（无墙、无边界、无其他弹珠）
   - 如果是未填的洞，则弹珠进洞
   - 否则移动到下一格

2. 记录所有弹珠移动完成后，得到新状态

### 搜索算法

使用 $\texttt{BFS}$：

- 初始状态：所有弹珠在初始位置，所有洞未填
- 从队列取出状态，尝试四个方向移动，得到新状态
- 若新状态达到目标（每个弹珠都在对应编号的洞里），则返回步数
- 使用哈希集合判重，避免重复访问

## 解题思路详解

### 1. 数据结构设计

```cpp
struct State {
    vector<pair<int, int>> balls;    // 弹珠位置，(-1, -1)表示已进洞
    vector<int> ballInHole;           // 弹珠进的洞编号，-1表示未进
    vector<bool> holeFilled;          // 洞是否被填
};
```

- `balls[i]`：弹珠 $i$ 的坐标，若已进洞则为 $(-1, -1)$
- `ballInHole[i]`：弹珠 $i$ 进了哪个洞，未进则为 $-1$
- `holeFilled[j]`：洞 $j$ 是否已被填

### 2. 墙的存储

由于棋盘很小，可以用邻接表存储墙：

```cpp
set<pair<int, int>> walls[16];  // walls[格子编号] = 与该格子有墙的格子集合
```

格子编号 = $r \times N + c$。

### 3. 移动模拟

移动函数 `move(State s, int dir)` 的实现：

```cpp
State move(State s, int dir) {
    bool changed;
    do {
        changed = false;
        // 按移动方向的相反顺序处理
        vector<int> order(M);
        iota(order.begin(), order.end(), 0);
        if (dir == 0) // 北：从下到上
            sort(order.begin(), order.end(), [&](int a, int b) {
                return s.balls[a].first > s.balls[b].first;
            });
        else if (dir == 1) // 南：从上到下
            sort(order.begin(), order.end(), [&](int a, int b) {
                return s.balls[a].first < s.balls[b].first;
            });
        else if (dir == 2) // 西：从右到左
            sort(order.begin(), order.end(), [&](int a, int b) {
                return s.balls[a].second > s.balls[b].second;
            });
        else // 东：从左到右
            sort(order.begin(), order.end(), [&](int a, int b) {
                return s.balls[a].second < s.balls[b].second;
            });
        
        auto newBalls = s.balls;
        for (int idx : order) {
            if (s.ballInHole[idx] != -1) continue; // 已进洞
            
            int r = s.balls[idx].first, c = s.balls[idx].second;
            int nr = r + dr[dir], nc = c + dc[dir];
            
            // 边界检查
            if (nr < 0 || nr >= N || nc < 0 || nc >= N) continue;
            // 墙检查
            if (hasWall(r, c, nr, nc)) continue;
            
            // 检查目标格是否有其他弹珠
            bool occupied = false;
            for (int j = 0; j < M; j++) {
                if (j == idx) continue;
                if (s.ballInHole[j] != -1) continue; // 已进洞的不占格子
                if (newBalls[j].first == nr && newBalls[j].second == nc) {
                    occupied = true;
                    break;
                }
            }
            if (occupied) continue;
            
            // 检查目标格是否有未填的洞
            int holeIdx = -1;
            for (int j = 0; j < M; j++) {
                if (!s.holeFilled[j] && holePos[j].first == nr && holePos[j].second == nc) {
                    holeIdx = j;
                    break;
                }
            }
            
            if (holeIdx != -1) {
                // 进洞
                newBalls[idx] = {-1, -1};
                s.ballInHole[idx] = holeIdx;
                s.holeFilled[holeIdx] = true;
                changed = true;
            } else {
                // 正常移动
                newBalls[idx] = {nr, nc};
                changed = true;
            }
        }
        s.balls = newBalls;
    } while (changed);
    
    return s;
}
```

### 5. $\texttt{BFS}$ 主流程

```cpp
int solve() {
    State start;
    start.balls = ballStart;
    start.ballInHole.assign(M, -1);
    start.holeFilled.assign(M, false);
    
    queue<pair<State, int>> q;
    q.push({start, 0});
    
    unordered_set<State, StateHash> visited;
    visited.insert(start);
    
    while (!q.empty()) {
        auto [cur, steps] = q.front(); q.pop();
        if (isGoal(cur)) return steps;
        
        for (int d = 0; d < 4; d++) {
            State nxt = move(cur, d);
            if (visited.count(nxt)) continue;
            visited.insert(nxt);
            q.push({nxt, steps + 1});
        }
    }
    return -1;
}
```

## 复杂度分析

- 状态数：每个弹珠有 $N^2$ 种可能位置，加上进洞状态，最多 $(N^2 + 1)^M$ 种，但实际远小于此
- 每次移动模拟：$O(M \cdot N)$，因为最多滚动 $N$ 步
- 总复杂度：在 $N \leq 4, M \leq 16$ 时完全可以接受

## 注意事项

1. 移动顺序很重要：必须按移动方向的相反顺序处理，才能正确处理弹珠之间的阻挡关系
2. 多步移动：一次抬起操作可能让弹珠连续移动多格，需要用 `do-while` 循环模拟
3. 进洞处理：弹珠进洞后，洞的状态要立即更新，因为其他弹珠在同一移动中可能滚过这个洞
4. 判重：使用自定义哈希函数，确保相同状态不会被重复访问

// Marble Game

#include <bits/stdc++.h>
using namespace std;

struct State {
    vector<pair<int, int>> balls;    // 弹珠位置，(-1, -1)表示已进洞
    vector<int> ballInHole;           // 弹珠进的洞编号，-1表示未进
    vector<bool> holeFilled;          // 洞是否被填
    
    bool operator==(const State& o) const {
        return balls == o.balls && ballInHole == o.ballInHole && holeFilled == o.holeFilled;
    }
};

struct StateHash {
    size_t operator()(const State& s) const {
        size_t h = 0;
        for (auto& p : s.balls) h = h * 31 + (p.first * 10 + p.second);
        for (int v : s.ballInHole) h = h * 31 + (v + 1);
        for (bool b : s.holeFilled) h = h * 31 + b;
        return h;
    }
};

int N, M, W;
vector<pair<int, int>> ballStart, holePos;
set<pair<int, int>> walls[16];
int dr[4] = {-1, 1, 0, 0}, dc[4] = {0, 0, -1, 1};

bool hasWall(int r1, int c1, int r2, int c2) {
    return walls[r1 * N + c1].count({r2, c2}) > 0;
}

    do {
        changed = false;
        // 按移动方向的相反顺序处理
        vector<int> order(M);
        iota(order.begin(), order.end(), 0);
        if (dir == 0) // 北：从下到上

            });

            sort(order.begin(), order.end(), [&](int a, int b) {
                return s.balls[a].first < s.balls[b].first;
            });
        else if (dir == 2) // 西：从右到左
            sort(order.begin(), order.end(), [&](int a, int b) {
                return s.balls[a].second > s.balls[b].second;
            });
        else // 东：从左到右
            sort(order.begin(), order.end(), [&](int a, int b) {
                return s.balls[a].second < s.balls[b].second;
            });
        
        auto newBalls = s.balls;
        for (int idx : order) {
            if (s.ballInHole[idx] != -1) continue; // 已进洞
            
            int r = s.balls[idx].first, c = s.balls[idx].second;
            int nr = r + dr[dir], nc = c + dc[dir];
            
            // 边界检查
            if (nr < 0 || nr >= N || nc < 0 || nc >= N) continue;
            // 墙检查
            if (hasWall(r, c, nr, nc)) continue;

                if (s.ballInHole[j] != -1) continue; // 已进洞的不占格子
                if (newBalls[j].first == nr && newBalls[j].second == nc) {
                    occupied = true;

                }

            int holeIdx = -1;

                if (!s.holeFilled[j] && holePos[j].first == nr && holePos[j].second == nc) {
                    holeIdx = j;
                    break;
                }
            }
            
            if (holeIdx != -1) {
                // 进洞

                s.ballInHole[idx] = holeIdx;
                s.holeFilled[holeIdx] = true;

            } else {

                newBalls[idx] = {nr, nc};

            }

    return s;

bool isGoal(const State& s) {
    for (int i = 0; i < M; i++)
        if (s.ballInHole[i] != i) return false;
    return true;
}

int solve() {
    State start;
    start.balls = ballStart;
    start.ballInHole.assign(M, -1);
    start.holeFilled.assign(M, false);
    
    queue<pair<State, int>> q;
    q.push({start, 0});
    
    unordered_set<State, StateHash> visited;
    visited.insert(start);
    
    while (!q.empty()) {
        auto [cur, steps] = q.front(); q.pop();
        if (isGoal(cur)) return steps;
        
        for (int d = 0; d < 4; d++) {
            State nxt = move(cur, d);
            if (visited.count(nxt)) continue;
            visited.insert(nxt);
            q.push({nxt, steps + 1});
        }
    }
    return -1;
}

    ios::sync_with_stdio(false);

    while (cin >> N >> M >> W) {
        if (N == 0 && M == 0 && W == 0) break;
