## 题目分析

本题是一个组合逻辑电路故障诊断问题。电路由与门 ($\texttt{and}$)、或门 ($\texttt{or}$)、异或门 ($\texttt{xor}$) 和非门 ($\texttt{not}$) 组成，**最多只有一个门可能失效**。失效方式有三种：

1. **输出取反** - 始终输出正确输出的相反值
2. **恒为 $0$** - 始终输出 $0$
3. **恒为 $1$** - 始终输出 $1$

我们需要根据多组输入输出的观测值来判断：

- 电路是否完全正常？
- 如果异常，能否**唯一确定**故障门及其故障类型？
- 如果不能唯一确定，输出相应提示。

## 解题思路

### 1. 电路建模

每个门有类型 ($\texttt{a/n/o/x}$) 和输入列表。输入可以是：
- 电路原始输入：$\texttt{i1}, \texttt{i2}, \dots$
- 其他门的输出：$\texttt{g1}, \texttt{g2}, \dots$

输出定义：每个输出 $u_j$ 对应某个门的输出。

由于电路**无反馈回路**，门之间构成一个有向无环图 ($\texttt{DAG}$)。

### 2. 拓扑排序

为了正确计算每个门的输出，必须按照**依赖关系**的顺序计算：先计算输入只依赖原始输入的门，再计算依赖其他门输出的门。

使用 $\texttt{Kahn}$ 算法进行拓扑排序：
- 统计每个门的入度（依赖的其他门数量）
- 将入度为 $0$ 的门加入队列
- 依次取出队列中的门，将其指向的门的入度减 $1$，若减到 $0$ 则加入队列
- 得到的顺序即为计算顺序

### 3. 无故障电路模拟

给定一组输入值，按照拓扑顺序依次计算每个门的输出：
- 对于非门：输出 = 非(输入)
- 对于与门：输出 = 输入 $1$ & 输入 $2$
- 对于或门：输出 = 输入 $1$ | 输入 $2$
- 对于异或门：输出 = 输入 $1$ ^ 输入 $2$

最后根据输出定义，收集对应门的输出值。

### 4. 故障电路模拟

假设故障门为 $g$，故障类型为 $t$：
- $t = 0$：输出取反
- $t = 1$：输出恒为 $0$
- $t = 2$：输出恒为 $1$

在计算过程中，当计算到故障门时，先计算其正常输出，再根据故障类型修改输出值。其他门正常工作。

### 5. 故障诊断算法

1. **先检查无故障情况**：对所有观测，用无故障模拟计算输出，若全部匹配，则电路正常。
2. **若不正常**，枚举所有可能的故障假设：
   - 故障门 $g \in [0, G-1]$
   - 故障类型 $t \in \{0,1,2\}$
3. 对每个假设，检查是否与**所有观测**一致：
   - 用故障模拟计算每组输入的输出
   - 与观测输出比较
4. 收集所有匹配的假设：
   - 若无匹配假设（理论上不会发生，因为至少有一个真实故障）
   - 若仅有一个匹配假设，则唯一确定故障
   - 若有多个匹配假设，则无法完全分类

### 6. 复杂度分析

- 门数 $G \leq 19$，输入数 $N \leq 8$，输出数 $U \leq 19$，观测数 $B$ 无明确上限但通常不大。
- 拓扑排序 $O(G^2)$
- 每次模拟 $O(G)$
- 枚举故障假设 $O(3G \cdot B \cdot G) = O(3G^2B)$，完全可以接受。

```cpp
// My Bad

#include <bits/stdc++.h>
using namespace std;

struct Gate { char type; vector<string> ins; };

int N, G, U;
vector<Gate> gates;
vector<int> outs;
vector<vector<int>> inObs, outObs;

int getVal(const string& s, const vector<int>& inV, const vector<int>& gateV) {
    return s[0] == 'i' ? inV[stoi(s.substr(1)) - 1] : gateV[stoi(s.substr(1)) - 1];
}

vector<int> topoOrder() {
    vector<int> deg(G, 0);
    vector<vector<int>> adj(G);
    for (int i = 0; i < G; ++i)
        for (const string& in : gates[i].ins)
            if (in[0] == 'g') {
                int from = stoi(in.substr(1)) - 1;
                adj[from].push_back(i);
                deg[i]++;
            }
    queue<int> q;
    for (int i = 0; i < G; ++i) if (deg[i] == 0) q.push(i);
    vector<int> order;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : adj[u]) if (--deg[v] == 0) q.push(v);
    }
    return order;
}

vector<int> compute(const vector<int>& inV, int fgate = -1, int ftype = -1) {
    vector<int> gateV(G, 0);
    vector<int> order = topoOrder();
    for (int idx : order) {
        Gate& g = gates[idx];
        int normal;
        if (g.type == 'n') normal = !getVal(g.ins[0], inV, gateV);
        else {
            int v1 = getVal(g.ins[0], inV, gateV), v2 = getVal(g.ins[1], inV, gateV);
            if (g.type == 'a') normal = v1 & v2;
            else if (g.type == 'o') normal = v1 | v2;
            else normal = v1 ^ v2;
        }
        if (idx == fgate) {
            if (ftype == 0) gateV[idx] = !normal;
            else if (ftype == 1) gateV[idx] = 0;
            else gateV[idx] = 1;
        } else gateV[idx] = normal;
    }
    vector<int> res(U);
    for (int i = 0; i < U; ++i) res[i] = gateV[outs[i] - 1];
    return res;
}

int main() {
    int caseNo = 1;
    while (cin >> N >> G >> U, N || G || U) {
        gates.resize(G);
        for (int i = 0; i < G; ++i) {
            cin >> gates[i].type;
            int cnt = gates[i].type == 'n' ? 1 : 2;
            gates[i].ins.resize(cnt);
            for (int j = 0; j < cnt; ++j) cin >> gates[i].ins[j];
        }
        outs.resize(U);
        for (int i = 0; i < U; ++i) cin >> outs[i];
        int B; cin >> B;
        inObs.assign(B, vector<int>(N));
        outObs.assign(B, vector<int>(U));
        for (int i = 0; i < B; ++i) {
            for (int j = 0; j < N; ++j) cin >> inObs[i][j];
            for (int j = 0; j < U; ++j) cin >> outObs[i][j];
        }
        
        bool ok = true;
        for (int i = 0; i < B && ok; ++i) if (compute(inObs[i]) != outObs[i]) ok = false;
        if (ok) { cout << "Case " << caseNo++ << ": No faults detected\n"; continue; }
        
        vector<pair<int, int>> cand;
        for (int g = 0; g < G; ++g) for (int t = 0; t < 3; ++t) {
            bool match = true;
            for (int i = 0; i < B && match; ++i)
                if (compute(inObs[i], g, t) != outObs[i]) match = false;
            if (match) cand.emplace_back(g, t);
        }
        
        if (cand.size() == 1) {
            auto [g, t] = cand[0];
            cout << "Case " << caseNo++ << ": Gate " << g + 1 << " is failing; output ";
            if (t == 0) cout << "inverted\n";
            else if (t == 1) cout << "stuck at 0\n";
            else cout << "stuck at 1\n";
        } else cout << "Case " << caseNo++ << ": Unable to totally classify the failure\n";
    }
    return 0;
}
```

## 总结

本题的关键在于**正确建模电路依赖关系**（拓扑排序）和**全面枚举故障假设**。通过模拟无故障和故障情况下的电路行为，并与观测值比对，可以唯一确定故障门及其类型（如果可能）。由于门数较少，枚举所有假设是可行的。
