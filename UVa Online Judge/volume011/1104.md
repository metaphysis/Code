## 题目描述

一家微处理器公司需要在一块 $N \times N$ 的芯片上布置可互换的组件（部件）。芯片的每个插槽可以是以下三种状态之一：

- `'.'`：空插槽，可以放置部件
- `'C'`：已被其他组件占用的插槽
- `'/'`：禁用插槽，不能使用

你需要尽可能多地安装部件，但需要满足以下约束条件：

1. **行列相等约束**：对于每个 $i$ ($1 \leq i \leq N$)，第 $i$ 行的组件总数必须等于第 $i$ 列的组件总数。组件总数包括原有的 `'C'` 和新添加的部件。

2. **比例约束**：任何一行或一列的组件总数不得超过总组件数的 $A/B$。即对于任意的行 $i$ 或列 $j$，有：
   $$
   row_i \leq \frac{A}{B} \times totalComponents, \quad col_j \leq \frac{A}{B} \times totalComponents
   $$

## 题目分析

这是一个典型的带约束的最大化问题，主要难点在于同时满足行列相等约束和比例约束。

### 约束分析

1. **位置约束**：只能在 `'.'` 位置放置部件，`'C'` 位置已有固定组件，`'/'` 位置完全禁用。

2. **行列相等约束**：这是最关键的约束，要求对于每个 $i$，第 $i$ 行的组件数等于第 $i$ 列的组件数。这意味着我们的选择不是独立的，行列之间存在着强烈的耦合关系。

3. **比例约束**：这是一个全局约束，任何单行或单列的组件数不能超过总组件数的 $A/B$。这个约束是非线性的，因为总组件数本身也是变量。

### 解题思路

我们采用**费用流 + 枚举**的方法来解决这个问题：

#### 关键洞察

1. **网络流建模**：将问题转化为网络流问题，其中：
   - 行和列分别作为节点
   - 空插槽作为从行节点到列节点的边
   - 使用费用流来区分已有组件和新增部件

2. **枚举上界**：由于比例约束是非线性的，我们枚举每行/列的最大组件数 $maxt$，将其转化为线性约束。

3. **费用流设计**：
   - 总流量表示总可用位置数
   - 费用表示未使用的空位置数
   - 通过最小费用最大流找到最优解

#### 网络流建模细节

**节点设计**：
- $0$ 到 $N-1$：行节点
- $N$ 到 $2N-1$：列节点  
- $2N$：源点 $s$
- $2N+1$：汇点 $t$

**边设计**：
1. **源点 → 行节点 $i$**：容量 = 第 $i$ 行的总可用位置数，费用 = $0$
2. **行节点 $i$ → 列节点 $i$**：容量 = $maxt$，费用 = $0$（关键边，保证行列相等）
3. **列节点 $i$ → 汇点**：容量 = 第 $i$ 列的总可用位置数，费用 = $0$
4. **行节点 $i$ → 列节点 $j$**（对于每个空位置 $(i,j)$）：容量 = $1$，费用 = $1$

**费用流含义**：
- 总流量 $flow$ = 总可用位置数
- 总费用 $cost$ = 未使用的空位置数
- 使用的空位置数 = $flow - cost$ = 新增部件数
- 总组件数 = 原有 $C$ 数 + 新增部件数

#### 算法流程

1. **预处理**：统计每行每列的总可用位置数和原有 $C$ 的数量
2. **枚举 $maxt$**：从 $0$ 到 $N$ 枚举每行/列的最大组件数
3. **构建网络流**：按照上述建模构建费用流图
4. **计算最小费用最大流**：使用 $\texttt{SPFA}$ 算法求解
5. **检查约束**：
   - 满流条件：$flow = totalPositions$
   - 比例约束：$totalComponents \times A \geq maxt \times B$
6. **更新答案**：在所有满足条件的 $maxt$ 中取最大值

### 复杂度分析

- 节点数：$O(N)$
- 边数：$O(N^2)$
- 枚举次数：$O(N)$
- 费用流复杂度：$O(N^3)$（$\texttt{SPFA}$ 算法）
- 总复杂度：$O(N^4)$，对于 $N \leq 40$ 可以接受

## 代码实现

```cpp
// Chips Challenge
// UVa ID: 1104
// Verdict: Accepted
// Submission Date: 2025-11-21
// UVa Run Time: 0.430s

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
const int MAXN = 45;
const int MAXV = 200;

struct Edge {
    int to, cap, cost, rev;
    Edge(int to, int cap, int cost, int rev) : to(to), cap(cap), cost(cost), rev(rev) {}
};

vector<Edge> graph[MAXV];
int dist[MAXV], prevv[MAXV], preve[MAXV];
bool inQueue[MAXV];

void addEdge(int from, int to, int cap, int cost) {
    graph[from].emplace_back(to, cap, cost, graph[to].size());
    graph[to].emplace_back(from, 0, -cost, graph[from].size() - 1);
}

bool spfa(int s, int t) {
    memset(dist, 0x3f, sizeof(dist));
    memset(inQueue, 0, sizeof(inQueue));
    queue<int> q;
    dist[s] = 0;
    q.push(s);
    inQueue[s] = true;
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inQueue[u] = false;
        for (int i = 0; i < graph[u].size(); i++) {
            Edge& e = graph[u][i];
            if (e.cap > 0 && dist[e.to] > dist[u] + e.cost) {
                dist[e.to] = dist[u] + e.cost;
                prevv[e.to] = u;
                preve[e.to] = i;
                if (!inQueue[e.to]) {
                    inQueue[e.to] = true;
                    q.push(e.to);
                }
            }
        }
    }
    return dist[t] < INF;
}

int minCostMaxFlow(int s, int t, int& cost) {
    int flow = 0;
    cost = 0;
    while (spfa(s, t)) {
        int f = INF;
        for (int v = t; v != s; v = prevv[v]) {
            f = min(f, graph[prevv[v]][preve[v]].cap);
        }
        flow += f;
        for (int v = t; v != s; v = prevv[v]) {
            Edge& e = graph[prevv[v]][preve[v]];
            e.cap -= f;
            graph[e.to][e.rev].cap += f;
            cost += f * e.cost;
        }
    }
    return flow;
}

int n, A, B;
char grid[MAXN][MAXN];

int main() {
    int caseNum = 1;
    while (cin >> n >> A >> B, n || A || B) {
        int totalPositions = 0;  // 总可用位置数（C和.）
        int originalC = 0;       // 原有C的数量
        int rowTotal[MAXN] = {0}; // 每行的总可用位置数
        int colTotal[MAXN] = {0}; // 每列的总可用位置数
        for (int i = 0; i < n; i++) {
            cin >> grid[i];
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 'C' || grid[i][j] == '.') {
                    totalPositions++;
                    rowTotal[i]++;
                    colTotal[j]++;
                    originalC += (grid[i][j] == 'C');
                }
            }
        }
        int answer = -1;
        // 枚举每行/列的最大组件数 maxt
        for (int maxt = 0; maxt <= n; maxt++) {
            int s = 2 * n, t = 2 * n + 1;
            for (int i = 0; i <= t; i++) graph[i].clear();
            for (int i = 0; i < n; i++) {
                // 源点→行节点：容量 = 该行的总可用位置数
                addEdge(s, i, rowTotal[i], 0);
                // 行节点→对应列节点：容量 = maxt（行列相等约束 + 上界约束）
                addEdge(i, i + n, maxt, 0);
                // 列节点→汇点：容量 = 该列的总可用位置数
                addEdge(i + n, t, colTotal[i], 0);
                // 添加空位置的边：费用1表示不选择这个位置
                for (int j = 0; j < n; j++) {
                    if (grid[i][j] == '.') {
                        addEdge(i, j + n, 1, 1);
                    }
                }
            }
            int cost;
            int flow = minCostMaxFlow(s, t, cost);
            // 关键检查条件
            if (flow == totalPositions) {
                int totalComponents = flow - cost;  // 总组件数（原有+新增）
                if (totalComponents * A >= maxt * B) {
                    int newWidgets = totalComponents - originalC;  // 新增部件数
                    answer = max(answer, newWidgets);
                }
            }
        }
        cout << "Case " << caseNum++ << ": ";
        if (answer == -1) cout << "impossible" << endl;
        else cout << answer << endl;
    }
    return 0;
}
```

## 总结

本题通过巧妙的网络流建模将复杂的约束条件转化为可计算的形式。关键点在于：

1. **行列相等约束**：通过行节点到对应列节点的特殊边来保证
2. **比例约束**：通过枚举上界将其线性化
3. **费用流设计**：用费用区分已有组件和新增部件

这种建模方法在解决类似的带约束的组合优化问题时具有很强的参考价值。
