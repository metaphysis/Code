
> **摘要**：本题要求在给定城市网格与咖啡店分布下，对每个最大步行距离 $m$ 找出能覆盖最多咖啡店的路口，并按纵坐标、横坐标最小处理并列。核心做法是通过坐标变换 $u=x-y+dy$、$v=x+y$ 将曼哈顿距离约束转化为轴对齐正方形区域查询，再用二维前缀和实现常数时间的区域计数，整体复杂度为每组数据 $O((dx+dy)^2 + q \cdot dx \cdot dy)$。

 # 题目描述

城市由纵横交错的街道组成，路口坐标为 $(x,y)$。咖啡店分布在部分路口。一个人从某个路口出发，只能沿街道行走，因此从 $(a,b)$ 到 $(c,d)$ 的距离为 $|a-c|+|b-d|$。

对于给定的最大步行距离 $m$，需要找出一个路口，使得距离不超过 $m$ 的咖啡店数量最多。若有多个路口达到最大值，优先选择纵坐标最小的位置；若仍然并列，则选择横坐标最小的位置。

# 输入格式

输入包含多组测试数据。每组数据的首行包含四个整数 $dx$、$dy$、$n$ 和 $q$，分别表示城市网格的宽度、高度、咖啡店数量和查询数量，其中 $1 \le dx,dy \le 1000$、$0 \le n \le 5 \times 10^5$、$1 \le q \le 20$。

接下来 $n$ 行，每行包含两个整数 $x_i$ 和 $y_i$，表示一家咖啡店所在的路口，满足 $1 \le x_i \le dx$、$1 \le y_i \le dy$，且每个路口至多有一家咖啡店。

接下来 $q$ 行，每行包含一个整数 $m$，表示最大步行距离，满足 $0 \le m \le 10^6$。

输入以一行四个 $0$ 结束。

# 输出格式

对每组测试数据，先输出测试用例编号。然后每个查询输出一行，包含距离不超过 $m$ 的咖啡店最大数量，以及对应路口坐标，格式为 `数量 (x,y)`。

若多个路口的咖啡店数量相同，按照题意依次选择纵坐标最小、横坐标最小的路口。

# 样例输入

```text
4 4 5 3
1 1
1 2
3 3
4 4
2 4
1
2
4
0 0 0 0
```

# 样例输出

```text
Case 1:
3 (3,4)
4 (2,2)
5 (3,1)
```

# 题目分析

直接对每个候选路口统计曼哈顿距离不超过 $m$ 的咖啡店，单次查询需要枚举所有路口并逐个检查所有咖啡店，时间复杂度为 $O(dx \cdot dy \cdot n)$，无法满足数据范围。

关键是将曼哈顿距离转化为平面坐标中的矩形区域查询。对于路口 $(x,y)$，定义变换后的坐标为 $u=x-y+dy$、$v=x+y$。对任意两个路口 $(x_1,y_1)$、$(x_2,y_2)$，有：
$$
|x_1-x_2|+|y_1-y_2| = \max(|u_1-u_2|, |v_1-v_2|)
$$
因此，距离不超过 $m$ 的条件等价于变换后两个坐标分别相差不超过 $m$。以候选路口变换后的坐标为中心，所有符合条件的咖啡店落在一个边长为 $2m$ 的轴对齐正方形内。

变换后的坐标范围均可由 $1$ 到 $dx+dy$ 覆盖。将每家咖啡店映射到新坐标平面后，用二维前缀和预处理任意矩形内的咖啡店数量。每次查询枚举所有路口，并通过矩形求和得到其覆盖数量。枚举次序为纵坐标从小到大、横坐标从小到大，且只有在数量严格增加时更新答案，因此并列时自然保留题目要求的位置。

# 解题思路

对输入中的每家咖啡店 $(x,y)$，计算变换坐标 $u=x-y+dy$、$v=x+y$，并在二维数组中将对应位置加一。所有咖啡店录入后，对数组构造二维前缀和，使得任意矩形区域中的咖啡店数量都能在常数时间内求出。

对于每个查询距离 $m$，按 $y=1,2,\ldots,dy$、再按 $x=1,2,\ldots,dx$ 的顺序枚举候选路口。计算其变换坐标 $(u,v)$，将查询正方形边界限制在前缀和数组范围内：
$$
u_l=\max(u-m,1),\quad u_r=\min(u+m,dx+dy)
$$
$$
v_l=\max(v-m,1),\quad v_r=\min(v+m,dx+dy)
$$
用二维前缀和的容斥公式计算矩形中的咖啡店数量：
$$
S(u_r,v_r)-S(u_r,v_l-1)-S(u_l-1,v_r)+S(u_l-1,v_l-1)
$$
其中 $S(a,b)$ 表示左上角至 $(a,b)$ 的前缀区域内咖啡店总数。若当前数量严格大于已记录的最大值，则更新最大值和路口坐标。由于枚举顺序与题目优先级一致，数量相同时不更新即可正确处理平局。

设 $A=dx \cdot dy$，变换网格边长为 $dx+dy$。每组数据的前缀和预处理时间为 $O((dx+dy)^2)$；每个查询枚举全部路口，时间为 $O(A)$；空间复杂度为 $O((dx+dy)^2)$。

```cpp
// Coffee Central

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 2048;

int sum[MAXN][MAXN];

void rotate(int x, int y, int &tx, int &ty, int dx, int dy)
{
	tx = x - y + dy, ty = x + y;
}

void query(int m, int dx, int dy)
{
	int ret = 0, ret_x = 1, ret_y = 1, tx, ty;
	for (int j = 1; j <= dy; j++) {
		for (int i = 1; i <= dx; i++) {
			rotate(i, j, tx, ty, dx, dy);
			int lx, rx, ly, ry, cnt;
			lx = max(tx - m, 1);
			ly = max(ty - m, 1);
			rx = min(tx + m, dx + dy);
			ry = min(ty + m, dx + dy);
			cnt = sum[rx][ry] - sum[rx][ly - 1] - sum[lx - 1][ry] + sum[lx - 1][ly - 1];
			if (cnt > ret) { ret = cnt, ret_x = i, ret_y = j; }
		}
	}
	cout << ret << " (" << ret_x << ',' << ret_y << ")\n";
}

int main(int argc, char *argv[])
{
	int dx, dy, n, q;
	int x, y, tx, ty, m, cases = 0;
	while (cin >> dx >> dy >> n >> q, dx) {
		memset(sum, 0, sizeof(sum));
		for (int i = 0; i < n; i++) {
			cin >> x >> y;
			rotate(x, y, tx, ty, dx, dy);
			sum[tx][ty]++;
		}
		for (int i = 1; i <= dx + dy; i++) {
			for (int j = 1, s = 0; j <= dx + dy; j++) {
				s += sum[i][j];
				sum[i][j] = sum[i - 1][j] + s;
			}
		}
		cout << "Case " << ++cases << ":\n";
		for (int i = 0; i < q; i++) {
			cin >> m;
			query(m, dx, dy);
		}
	}
	return 0;
}
```

# 总结

本题的核心是使用坐标变换把曼哈顿距离约束转化为正方形区域查询，再用二维前缀和将每次区域计数降为常数时间。按题目优先级枚举候选位置，并在数量相等时保留先出现的位置，即可简洁地实现平局处理。
