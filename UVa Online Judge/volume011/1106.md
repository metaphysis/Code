## 题目描述

你是 $\texttt{ACM}$ 公司的总监，在重组期内需要买卖机器并运营它们来获取利润。公司一次最多只能拥有一台机器。每台机器 $M_i$ 在特定的某一天 $D_i$ 出售，价格 $P_i$，转售价 $R_i$，日利润 $G_i$。如果 $D_i$ 天不买，机器就会被人买走。购买后从 $D_i + 1$ 天开始运营，每天产生 $G_i$ 利润。卖出当天不能运营，但可以在同一天卖出后立即买入新机器。重组期共 $D$ 天，结束后 $\texttt{ACM}$ 会卖出手中持有的机器。初始资金为 $C$。求最终能获得的最大现金。

## 题目分析

### 状态定义

由于 $D$ 最大可达 $10^9$，不能按天进行动态规划。注意到只有 $N$ 台机器（$N \leq 10^5$），我们只需考虑这些出售日。

定义 $f_i$ 为**买入机器 $i$ 之前**所拥有的现金。那么：

- 买入机器 $i$ 需要 $f_i \geq P_i$
- 买入后持有到某一天卖出，可以获得利润

### 转移方程

假设我们在第 $D_i$ 天买入机器 $i$，然后在第 $D_j$ 天（$D_j > D_i$）卖出机器 $i$ 并买入机器 $j$。运营天数是从 $D_i + 1$ 到 $D_j - 1$，共 $(D_j - 1) - (D_i + 1) + 1 = D_j - D_i - 1$ 天。

因此，卖出机器 $i$ 后的现金为：

$$f_j = f_i - P_i + (D_j - D_i - 1) \times G_i + R_i$$

整理得到：

$$f_j = \big[ f_i - P_i - (D_i + 1) \times G_i + R_i \big] + D_j \times G_i$$

这是一个关于 $D_j$ 的一次函数：

$$f_j = b_i + a_i \times D_j$$

其中：
- $a_i = G_i$（斜率）
- $b_i = f_i - P_i - (D_i + 1) \times G_i + R_i$（截距）

### 问题转化

对于每个机器 $j$，我们需要从所有满足 $D_i < D_j$ 且 $f_i \geq P_i$ 的机器 $i$ 中，选择一条直线 $y = a_i x + b_i$，使得在 $x = D_j$ 处的取值最大。这就是典型的**动态凸包**或**李超线段树**优化问题。

### 最终答案计算

重组期结束后（第 $D$ 天之后），我们可能还持有一台机器。假设最后买入的机器是 $i$，则在第 $D+1$ 天卖出时，运营天数为 $D+1 - D_i - 1 = D - D_i$ 天。最终现金为：

$$ans = f_i - P_i + (D - D_i) \times G_i + R_i$$

此外，也可以选择不买任何机器，答案为初始现金 $C$。

## 算法设计

### 数据结构选择：李超线段树

李超线段树支持：
- 添加一条直线 $y = mx + b$
- 查询 $x$ 处的最大值

时间复杂度 $O(\log N)$ 每次操作，总复杂度 $O(N \log N)$。

### 实现步骤

1. 读入 $N, C, D$，按 $D_i$ 排序所有机器。
2. 提取所有 $D_i$ 作为李超线段树的坐标。
3. 初始化李超线段树，加入初始直线 $y = 0 \cdot x + C$（表示不买机器时的现金）。
4. 遍历每台机器 $j$：
   - 查询 $x = D_j$ 得到 $f_j$（买入 $j$ 前的最大现金）
   - 如果 $f_j \geq P_j$，计算最终答案候选值，并添加新直线 $y = G_j \cdot x + (f_j - P_j - (D_j + 1) \cdot G_j + R_j)$
5. 输出所有候选最大值。

### 正确性说明

- 李超线段树维护了所有可能的买入决策对应的直线。
- 每次查询时，$D_j$ 递增，保证了转移的时序正确性。
- 由于 $N \leq 10^5$，坐标离散化后李超树节点数为 $4N$，内存足够。

## 复杂度分析

- 排序：$O(N \log N)$
- 离散化：$O(N \log N)$
- 李超树操作：每次 $O(\log N)$，共 $O(N \log N)$
- 总复杂度：$O(N \log N)$

```cpp
// Machine Works

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

struct Machine {
    int d, p, r, g;
};

struct Line {
    ll m, b;
    Line(ll m = 0, ll b = -1e18) : m(m), b(b) {}
    ll eval(ll x) const { return m * x + b; }
};

class LiChaoTree {
    vector<Line> tree;
    vector<ll> xs;
    int n;
public:
    LiChaoTree(vector<ll>& coords) : xs(coords) {
        sort(xs.begin(), xs.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        n = xs.size();
        tree.assign(4 * n, Line(0, -1e18));
    }
    
    void addLine(Line newLine, int node, int l, int r) {
        int midIdx = (l + r) / 2;
        ll xl = xs[l], xr = xs[r - 1], xm = xs[midIdx];
        bool leftBetter = newLine.eval(xl) > tree[node].eval(xl);
        bool midBetter = newLine.eval(xm) > tree[node].eval(xm);
        
        if (midBetter) swap(tree[node], newLine);
        if (r - l == 1) return;
        
        if (leftBetter != midBetter) addLine(newLine, node * 2, l, midIdx);
        else addLine(newLine, node * 2 + 1, midIdx, r);
    }
    
    void addLine(Line line) { addLine(line, 1, 0, n); }
    
    ll query(ll x, int node, int l, int r) {
        if (r - l == 1) return tree[node].eval(x);
        int midIdx = (l + r) / 2;
        if (x <= xs[midIdx - 1]) return max(tree[node].eval(x), query(x, node * 2, l, midIdx));
        else return max(tree[node].eval(x), query(x, node * 2 + 1, midIdx, r));
    }
    
    ll query(ll x) { return query(x, 1, 0, n); }
};

bool cmpD(const Machine& a, const Machine& b) { return a.d < b.d; }

int main() {
    int n, d, caseNo = 0;
    ll c;
    while (scanf("%d %lld %d", &n, &c, &d) == 3 && (n || c || d)) {
        vector<Machine> machines(n);
        for (int i = 0; i < n; ++i)
            scanf("%d %d %d %d", &machines[i].d, &machines[i].p, &machines[i].r, &machines[i].g);
        sort(machines.begin(), machines.end(), cmpD);
        
        vector<ll> days;
        for (auto& m : machines) days.push_back(m.d);
        LiChaoTree lichao(days);
        
        ll best = c;
        lichao.addLine(Line(0, c));
        
        for (auto& m : machines) {
            ll f = lichao.query(m.d);
            if (f >= m.p) {
                ll profit = f - m.p + (ll)(d - m.d) * m.g + m.r;
                if (profit > best) best = profit;
                ll b = f - m.p - (ll)(m.d + 1) * m.g + m.r;
                lichao.addLine(Line(m.g, b));
            }
        }
        
        printf("Case %d: %lld\n", ++caseNo, best);
    }
    return 0;
}
```

## 总结

本题的关键在于将动态规划转移方程转化为直线形式，并利用李超线段树高效维护最大值。通过离散化 $D_i$ 坐标，我们避免了按天 $\texttt{DP}$ 的时间爆炸问题，最终在 $O(N \log N)$ 时间内求解。这种斜率优化与李超树的结合是处理此类带时间约束的买卖问题的经典手法。
