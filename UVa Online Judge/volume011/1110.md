## 题目描述

一位法老继承了大量石头立方体，他命令建筑师使用所有这些立方体建造金字塔，要求不留下任何一个立方体。建筑师解释说并非任意数量的立方体都能构成金字塔。法老经过思考后提出了新的限制条件：

1. 必须使用所有立方体。
2. 可以建造多个金字塔，但必须尽可能少建金字塔。
3. 所有金字塔必须互不相同。
4. 每个金字塔的高度至少为 $2$。
5. 满足以上条件的前提下，最大的金字塔必须尽可能大（包含最多的立方体）。
6. 满足以上条件的前提下，第二大的金字塔必须尽可能大。
7. 依此类推...

给定立方体的数量 $c$ $(1 \le c \le 10^6)$，确定如何满足法老的所有限制条件。

### 金字塔类型

- **高金字塔 ($\texttt{High Pyramid}$)** ：基底为 $n \times n$，上一层为 $(n-1) \times (n-1)$，直到顶层的 $1 \times 1$。其立方体数量为：
  $$
  \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}
  $$

- **低金字塔 ($\texttt{Low Pyramid}$)** ：基底为 $n \times n$，上一层为 $(n-2) \times (n-2)$，直到顶层为 $2 \times 2$（当 $n$ 为偶数）或 $1 \times 1$（当 $n$ 为奇数）。其立方体数量为：
  $$
  \sum_{k=0}^{\lfloor n/2 \rfloor} (n-2k)^2 = \frac{n(n+1)(n+2)}{6}
  $$

## 题目分析

本题是一个组合优化问题，需要将给定的立方体数量 $c$ 分解为若干个互不相同的金字塔（每个金字塔至少高度为 $2$，即基底 $\ge 2$），并且满足以下优先级：

1. 金字塔数量尽可能少（最高优先级）
2. 在金字塔数量最少的前提下，金字塔序列按立方体数量降序排列，且要求字典序最大（即第一个金字塔尽可能大，然后第二个尽可能大，依此类推）
3. 金字塔互不相同（基底长度和类型都不同）

### 关键难点

1. **搜索空间大**：$c$ 最大为 $10^6$，金字塔数量大约有 $200$ 个，直接暴力搜索不可行。
2. **约束条件复杂**：需要同时满足最少数量和最大字典序。
3. **金字塔数量有限**：需要生成所有可能的高金字塔和低金字塔。

## 解题思路

### 1. 金字塔生成与预处理

首先，我们需要生成所有可能的金字塔（基底 $\ge 2$），包括高金字塔和低金字塔：

- 高金字塔：基底从 $2$ 开始，计算立方体数量，直到超过 $10^6$
- 低金字塔：基底从 $3$ 开始（高度至少为 $2$），计算立方体数量，直到超过 $10^6$

将所有金字塔按立方体数量降序排序，为后续搜索做准备。

### 2. 算法选择

由于金字塔数量有限（约 $200$ 个），而解中的金字塔数量通常很少，我们选择 **深度优先搜索 ($\texttt{DFS}$) + 强力剪枝** 的方案。

### 3. 搜索策略

1. **贪心初始解**：先用贪心算法（从大到小选择金字塔）得到一个可行解，作为搜索的上界。
2. **深度优先搜索**：从最大的金字塔开始尝试，逐步构建解。
3. **强剪枝优化**：应用多种剪枝策略大幅减少搜索空间。

### 4. 剪枝策略

1. **深度剪枝**：当前金字塔数量已不少于最优解时，直接剪枝。
2. **可行性剪枝**：当前剩余立方体为 $0$ 时，记录可行解。
3. **索引剪枝**：已遍历完所有金字塔但仍有剩余立方体时，剪枝。
4. **大小剪枝**：跳过立方体数量大于剩余量的金字塔。
5. **数量下界剪枝**：估算最少还需多少个金字塔（用当前最大金字塔估算），如果当前深度加上这个下界已不少于最优解，剪枝。
6. **重复性剪枝**：避免选择基底和类型都相同的金字塔。
7. **最优解剪枝**：如果已经找到单金字塔最优解，立即终止搜索。

### 5. 解的比较

两个解的比较规则：
1. 优先比较金字塔数量，数量少的更优。
2. 数量相同时，比较金字塔序列的字典序（按立方体数量降序比较）。

## 时间复杂度分析

- 金字塔生成：$O(\sqrt[3]{c})$，约 $100$ 个金字塔。
- 贪心初始解：$O(n)$，$n$ 为金字塔数量。
- DFS搜索：通过强力剪枝，实际搜索深度和宽度都受到严格限制。最坏情况下可能需要遍历所有组合，但实际运行中由于剪枝策略有效，可以在合理时间内完成。

## 代码实现

```cpp
// Pyramids
// UVa ID: 1110
// Verdict: Accepted
// Submission Date: 2026-01-13
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Pyramid {
    int cubes, base;
    char type;
    Pyramid(int c = 0, int b = 0, char t = 'H') : cubes(c), base(b), type(t) {}
    bool operator<(const Pyramid& other) const { return cubes > other.cubes; }
};

vector<Pyramid> allPyramids;
const int MAXC = 1000000, INF = 0x3f3f3f3f;
vector<Pyramid> best;
int minCount;

int highPyramidCubes(int base) { return base * (base + 1) * (2 * base + 1) / 6; }
int lowPyramidCubes(int base) { return base * (base + 1) * (base + 2) / 6; }

void initialize() {
    for (int base = 2; ; base++) {
        int cubesH = highPyramidCubes(base);
        if (cubesH <= MAXC) allPyramids.push_back(Pyramid(cubesH, base, 'H'));
        if (base >= 3) {
            int cubesL = lowPyramidCubes(base);
            if (cubesL > MAXC) break;
            allPyramids.push_back(Pyramid(cubesL, base, 'L'));
        }
    }
    sort(allPyramids.begin(), allPyramids.end());
}

// 比较两个序列的优劣
bool isBetter(const vector<Pyramid>& a, const vector<Pyramid>& b) {
    if (a.size() != b.size()) return a.size() < b.size();
    for (size_t i = 0; i < a.size(); i++)
        if (a[i].cubes != b[i].cubes)
            return a[i].cubes > b[i].cubes;
    return false;
}

// DFS搜索，带剪枝
void dfs(int remain, int startIdx, int depth, vector<Pyramid>& current) {
    // 剪枝1：当前序列已超过最优解的金字塔数量
    if (depth >= minCount) return;
    // 剪枝2：剩余立方体为0，找到可行解
    if (remain == 0) {
        if (depth < minCount || (depth == minCount && isBetter(current, best))) {
            minCount = depth;
            best = current;
            sort(best.begin(), best.end()); // 保持降序
        }
        return;
    }
    // 剪枝3：剩余立方体太小，无法用剩余金字塔填充
    if (startIdx >= allPyramids.size()) return;
    // 剪枝4：当前最大金字塔太大，直接跳过
    while (startIdx < allPyramids.size() && allPyramids[startIdx].cubes > remain)
        startIdx++;
    if (startIdx >= allPyramids.size()) return;
    // 剪枝5：即使使用最小的金字塔也无法在最小数量内填满
    // 估算最小可能金字塔数：使用当前最大的金字塔
    int maxCubes = allPyramids[startIdx].cubes;
    int minPossible = (remain + maxCubes - 1) / maxCubes; // 向上取整
    if (depth + minPossible >= minCount) return;
    // 尝试从startIdx开始选择金字塔
    for (int i = startIdx; i < allPyramids.size(); i++) {
        int cubes = allPyramids[i].cubes;
        if (cubes > remain) continue;
        // 剪枝6：避免重复选择相同底座和类型的金字塔
        bool duplicate = false;
        for (const Pyramid& p : current) {
            if (p.base == allPyramids[i].base && p.type == allPyramids[i].type) {
                duplicate = true;
                break;
            }
        }
        if (duplicate) continue;
        current.push_back(allPyramids[i]);
        dfs(remain - cubes, i + 1, depth + 1, current);
        current.pop_back();
        // 剪枝7：如果已经找到最优解，可以提前退出
        if (minCount == 1) return; // 单金字塔最优解
    }
}

int main() {
    initialize();
    int c, caseNo = 1;
    while (cin >> c && c) {
        cout << "Case " << caseNo++ << ": ";
        minCount = INF;
        best.clear();
        vector<Pyramid> current;
        // 使用DFS搜索更优解
        dfs(c, 0, 0, current);
        if (best.empty()) cout << "impossible\n";
        else {
            for (size_t i = 0; i < best.size(); i++) {
                if (i > 0) cout << ' ';
                cout << best[i].base << best[i].type;
            }
            cout << '\n';
        }
    }
    return 0;
}
```

## 总结

本题的关键在于将复杂的约束条件转化为有效的搜索和剪枝策略。通过 $\texttt{DFS}$ 配合多种剪枝条件，可以在有限时间内找到最优解。该解法充分利用了金字塔数量有限的特点，通过贪心获得初始上界，再通过深度优先搜索寻找更优解，最终成功解决了这个组合优化问题。

算法的主要优势：
1. 剪枝策略强力有效，大幅减少搜索空间
2. 贪心初始解提供了良好的上界
3. 代码结构清晰，易于理解和调试
