
> **摘要**：本题给定一个由 $n$ 个单元格组成的有向带权迷宫，每个单元格中有一只老鼠，要求统计在时间限制 $T$ 内能够到达出口 $E$ 的老鼠数量。由于边是有向的，直接以出口为起点求最短路得到的是反方向的距离，因此需要构造反向图，在反向图上以出口 $E$ 为源点运行 $\texttt{Dijkstra}$ 算法，得到原图中每个单元格到出口的最短时间，最后统计距离不超过 $T$ 的单元格数量。算法时间复杂度为 $O(n^2+m)$，空间复杂度为 $O(n+m)$。

 # 题目描述

迷宫由 $n$ 个单元格组成，每个单元格与其他单元格之间通过通道连接。每条通道具有固定的通行时间，并且通道可能是单向的，因此从单元格 $a$ 到单元格 $b$ 可以通行时，从 $b$ 到 $a$ 不一定可以通行。

迷宫中有一个出口单元格 $E$。每只老鼠都会选择一条到达出口的最短时间路径。实验开始时，每个单元格中放置一只老鼠，同时启动倒计时器。当倒计时结束时，统计在不超过 $T$ 个时间单位内到达出口的老鼠数量。

迷宫不存在通道容量限制，任意数量的老鼠可以同时通过同一条通道。

# 输入格式

输入首先包含一个正整数 $C$，表示测试用例数量。测试用例之间由空行分隔。

每组测试用例包含以下内容：

- 第一行包含整数 $n$，表示迷宫中的单元格数量。
- 第二行包含整数 $E$，表示出口单元格编号。
- 第三行包含整数 $T$，表示倒计时器的时间限制。
- 第四行包含整数 $m$，表示通道数量。
- 接下来 $m$ 行，每行包含三个整数 $a$、$b$ 和 $w$，表示存在一条从单元格 $a$ 到单元格 $b$ 的有向通道，通行时间为 $w$。

单元格编号范围为 $1$ 到 $n$，且 $n \le 100$。

# 输出格式

对于每组测试用例，输出一行整数，表示在不超过 $T$ 个时间单位内到达出口的老鼠数量。

相邻两组测试用例的输出之间输出一个空行。

# 题目分析

题目要求计算每个单元格到出口 $E$ 的最短时间，并统计最短时间不超过 $T$ 的单元格数量。由于每个单元格中恰好放置一只老鼠，因此满足条件的单元格数量就是最终能够逃出的老鼠数量。

通道是有向的，从 $a$ 到 $b$ 的通道不能直接用于从 $b$ 到 $a$。如果直接以出口 $E$ 为起点在原图中运行单源最短路算法，得到的是出口到其他单元格的最短距离，而题目需要的是其他单元格到出口的最短距离，方向正好相反。

解决方向问题的方法是构造反向图。对于原图中的有向边 $a \to b$，在反向图中加入有向边 $b \to a$，并保持边权不变。这样，原图中从任意单元格 $i$ 到出口 $E$ 的路径，会对应反向图中从 $E$ 到 $i$ 的路径，且两条路径的总时间完全相同。

因此，在反向图中从出口 $E$ 出发计算单源最短路，就可以得到原图中每个单元格到出口的最短时间。

所有通道的通行时间均为非负数，因此可以使用 $\texttt{Dijkstra}$ 算法。代码使用邻接表保存反向图，并通过遍历所有未确定节点选择当前距离最小的节点。由于节点数量最多为 $100$，采用线性查找最小距离节点即可满足复杂度要求。

设单元格数量为 $n$，通道数量为 $m$。代码中的 $\texttt{Dijkstra}$ 实现使用邻接表遍历边，并在线性时间内寻找未访问节点中的最小距离节点，因此时间复杂度为 $O(n^2+m)$，空间复杂度为 $O(n+m)$。

# 解题思路

首先读取迷宫的单元格数量 $n$、出口编号 $E$、时间限制 $T$ 和通道数量 $m$。

对于每条原图中的通道 $a \to b$，不将其保存为从 $a$ 到 $b$ 的边，而是保存为反向图中的边 $b \to a$。边权仍然为该通道的通行时间。

随后，以出口 $E$ 为起点运行单源最短路算法：

- 将出口 $E$ 的最短距离初始化为 $0$。
- 将其他单元格的最短距离初始化为无穷大。
- 每次选择当前未访问且距离最小的单元格，将其标记为已访问。
- 遍历该单元格的所有反向边，并尝试更新相邻单元格的最短距离。
- 当所有可以到达的单元格都完成处理后，算法结束。

反向图中从出口 $E$ 到单元格 $i$ 的最短距离，等于原图中从单元格 $i$ 到出口 $E$ 的最短距离。最后遍历所有单元格，统计满足 $\textit{dist}[i] \le T$ 的单元格数量。

其中，出口自身的距离为 $0$，由于 $T$ 为非负数，出口单元格也会被统计在答案中。

```cpp
// Mice and Maze

#include <bits/stdc++.h>

using namespace std;

const int MAXV = 1010, INF = 0x3fffffff;

struct edge
{
    int to, weight;
    edge (int to = 0, int weight = 0): to(to), weight(weight) {}
    bool operator<(const edge &e) const { return weight > e.weight; }
};

list<edge> edges[MAXV];
int dist[MAXV], parent[MAXV], visited[MAXV];
int n, m, E, T;

void mooreDijkstra(int u)
{
    for (int i = 1; i <= n; i++) dist[i] = INF, parent[i] = -1, visited[i] = 0;
    dist[u] = 0;

    while (!visited[u])
    {
        visited[u] = 1;
        for (auto e : edges[u])
            if (!visited[e.to] && dist[e.to] > dist[u] + e.weight)
                dist[e.to] = dist[u] + e.weight, parent[e.to] = u;

        int minDist = INF;
        for (int i = 1; i <= n; i++)
            if (!visited[i] && minDist > dist[i])
                minDist = dist[i], u = i;
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int cases;
    cin >> cases;
    for (int c = 1; c <= cases; c++)
    {
        cin >> n >> E >> T >> m;

        for (int i = 1; i <= n; i++)
            edges[i].clear();

        int u, v, weight;
        for (int i = 1; i <= m; i++)
        {
            cin >> u >> v >> weight;
            edges[v].push_back(edge(u, weight));
        }
        mooreDijkstra(E);
        int mice = 0;
        for (int i = 1; i <= n; i++)
            if (dist[i] <= T) mice++;
        if (c > 1) cout << '\n';
        cout << mice << '\n';
    }

    return 0;
}
```

# 总结

本题的关键在于将“每个单元格到出口的最短路”转换为“从出口到每个单元格的最短路”。

- 将每条有向边反向，构造反向图。
- 在反向图中以出口为起点运行 $\texttt{Dijkstra}$ 算法。
- 统计最短距离不超过 $T$ 的单元格数量。
- 使用邻接表存储图，时间复杂度为 $O(n^2+m)$，空间复杂度为 $O(n+m)$。

反向建图能够直接处理有向边方向问题，是本题最核心的图论技巧。
