## 题目描述

在莫尔斯电码中，字母被编码为点（`.`）和划（`-`）的序列。当字母之间没有停顿的时候，一段莫尔斯电码可能有多种解释。例如，`----` 可以被解释为 `"CAT"` 或 `"NXT"` 等。

给定一个莫尔斯码字符串（只包含 `.` 和 `-`，长度不超过 $1000$）和一个词典（包含 $N$ 个单词，$N \leq 10000$），要求计算将整个莫尔斯码字符串完全分割成词典中的单词（每个单词必须完全匹配）的不同短语的数量。结果保证不超过 $2 \times 10^9$。

输入的第一行是测试用例的数量 $T$，每个测试用例包含一个莫尔斯字符串、单词数量 $N$ 和 $N$ 个单词。输出每个测试用例的短语数量，相邻用例的输出之间有一个空行。

## 题目分析

本题的关键在于 **莫尔斯码没有分隔符**，因此同一个莫尔斯序列可能对应多种单词分割方式。

**核心难点**：
1. 词典中的单词需要通过字母到莫尔斯码的映射先转换成莫尔斯码串。
2. 需要在莫尔斯码字符串上进行动态规划，快速判断从某个位置开始能否匹配某个单词的莫尔斯码。
3. 词典单词数量最多 $10000$，莫尔斯串长度最多 $1000$，直接对每个位置遍历所有单词进行匹配会导致 $O(L \cdot N \cdot wordLen)$ 超时。

**关键观察**：
- 单词的莫尔斯码长度不一，但总长度有限。
- 可以**将词典中所有单词的莫尔斯码构建成 $\texttt{Trie}$ 树（前缀树）**，这样在莫尔斯码串上从某个位置开始匹配时，只需沿着 $\texttt{Trie}$ 向下遍历，$O(L \cdot avgMatchLen)$ 即可找到所有可能的匹配长度。
- 这样每个位置 $i$ 的匹配过程是沿着 $\texttt{Trie}$  前进，直到无法匹配或到达叶节点，复杂度大幅降低。

## 解题思路

### 1. 预处理：字母到莫尔斯码的映射

定义数组 `morseMap[26]`，将 `'A'` 到 `'Z'` 映射为对应的莫尔斯码（用 `.` 和 `-` 表示）。

### 2. 词典预处理

对于词典中的每个单词，通过映射将其转换为莫尔斯码串。然后**将所有单词的莫尔斯码插入到 $\texttt{Trie}$ 树中**。  
在 $\texttt{Trie}$ 树的每个节点上，使用一个 `vector<int>` 存储**以该节点结尾的单词的莫尔斯码长度**（因为可能有多个不同单词对应相同的莫尔斯码，如 `"AT"` 和 `"T"` 可能产生相同莫尔斯码，但通常不会，这里仍保存长度）。

### 3. 动态规划状态定义

设 $dp[i]$ 表示莫尔斯码字符串的**前 $i$ 个字符**可以解析成的不同短语的数量。  
初始化 $dp[0] = 1$（空串可以解析为空短语）。  
目标：$dp[L]$，其中 $L$ 是莫尔斯码字符串的长度。

### 4. 状态转移

对于每个位置 $i$（$0 \le i < L$），如果 $dp[i] > 0$，则从 $\texttt{Trie}$ 的根节点出发，尝试从莫尔斯字符串的第 $i$ 个字符开始向后匹配：

- 设 $j$ 从 $i$ 开始，依次取字符 `morse[j]`。
- 如果当前 $\texttt{Trie}$ 节点存在对应的子节点，则移动到子节点；否则匹配失败，跳出循环。
- 如果当前 $\texttt{Trie}$ 节点存储了单词长度（即 `wordLengths` 非空），则对于每一个长度 $wlen$，有：
$$
  dp[i + wlen] \mathrel{+}= dp[i]
$$
  注意：$i + wlen$ 必须不超过 $L$。

这样，每个位置 $i$ 的匹配是沿着 $\texttt{Trie}$ 一次遍历完成的，时间复杂度为 $O(L \cdot$ 平均匹配深度$)$，而平均匹配深度不超过最长莫尔斯码的长度（每个字母平均 $2~4$ 个符号，单词长度有限）。

### 5. 复杂度分析

- 构建 $\texttt{Trie}$：$O(\sum wordMorseLen)$，每个单词长度不超过莫尔斯串总长度。
- 动态规划：每个 $i$ 最多沿 Trie 走 $O(L)$ 步，但实际因为莫尔斯码字符串长度限制和 Trie 深度限制，总复杂度约为 $O(L \cdot maxMorseWordLen)$，满足要求。

### 6. 结果范围

题目保证结果 $\le 2 \times 10^9$，因此使用 `int` 即可。但为防中间累加溢出，可以使用 `long long` 最后转 `int`，或直接使用 `int`（因为加和不会超过 $2 \times 10^9$）。

```cpp
// Multiple Morse Matches
// UVa ID: 1113

#include <bits/stdc++.h>
using namespace std;

// 字母到莫尔斯码的映射
const string morseMap[26] = {
    ".-", "-...", "-.-.", "-..", ".", "..-.", "--.", "....", "..", ".---",
    "-.-", ".-..", "--", "-.", "---", ".--.", "--.-", ".-.", "...", "-",
    "..-", "...-", ".--", "-..-", "-.--", "--.."
};

// 将单词转换为莫尔斯码
string wordToMorse(const string& word) {
    string res = "";
    for (char c : word) res += morseMap[c - 'A'];
    return res;
}

// Trie 树节点
struct TrieNode {
    unordered_map<char, TrieNode*> children;
    vector<int> wordLengths; // 存储以当前节点结尾的单词的莫尔斯码长度
    
    TrieNode() {}
};

// 向 Trie 中插入莫尔斯码单词
void insertTrie(TrieNode* root, const string& morse, int len) {
    TrieNode* node = root;
    for (char c : morse) {
        if (!node->children.count(c))
            node->children[c] = new TrieNode();
        node = node->children[c];
    }
    node->wordLengths.push_back(len);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int T;
    cin >> T;
    
    for (int caseNum = 0; caseNum < T; ++caseNum) {
        if (caseNum > 0) cout << "\n"; // 用例之间空行
        
        string morse;
        cin >> morse; // 莫尔斯码字符串（连续，无空格）
        
        int N;
        cin >> N;
        
        // 构建 Trie 树
        TrieNode* root = new TrieNode();
        for (int i = 0; i < N; ++i) {
            string word;
            cin >> word;
            string morseWord = wordToMorse(word);
            insertTrie(root, morseWord, (int)morseWord.length());
        }
        
        int len = (int)morse.length();
        vector<long long> dp(len + 1, 0);
        dp[0] = 1;
        
        // 动态规划
        for (int i = 0; i < len; ++i) {
            if (dp[i] == 0) continue;
            
            TrieNode* node = root;
            // 从位置 i 开始向后匹配
            for (int j = i; j < len; ++j) {
                char c = morse[j];
                if (!node->children.count(c)) break;
                node = node->children[c];
                
                // 检查是否有单词在此结束
                for (int wlen : node->wordLengths) {
                    if (i + wlen <= len) {
                        dp[i + wlen] += dp[i];
                    }
                }
            }
        }
        
        cout << dp[len] << "\n";
        
        // 释放 Trie 内存（为简洁起见省略，实际竞赛中可接受）
    }
    
    return 0;
}
```
