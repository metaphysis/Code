## 题目描述

第二类斯特林数 $S(n, m)$ 表示将一个包含 $n$ 个元素的集合划分为 $m$ 个非空子集的方法数。题目要求计算 $S(n, m) \bmod 2$，即斯特林数的奇偶性。

**输入格式**：
- 首行为测试用例数量
- 每个测试用例包含两个整数 $n$ 和 $m$ ($1 \leq m \leq n \leq 10^9$)

**输出格式**：
- 每个测试用例输出 $S(n, m) \bmod 2$
- 测试用例间用空行分隔

## 题目分析

### 直接计算不可行
斯特林数可以通过递推公式计算：
$$S(n, m) = m \cdot S(n-1, m) + S(n-1, m-1), \quad 1 < m < n$$

但对于 $n$ 高达 $10^9$ 的情况，无论是时间复杂度还是空间复杂度，直接计算都是不可行的。

### 数学性质分析

我们需要利用斯特林数模 $2$ 的数学性质。经过组合数学的研究，发现第二类斯特林数 $S(n, m)$ 的奇偶性与二进制表示有密切关系。

**关键结论**：
$$S(n, m) \bmod 2 = 1 \quad \text{当且仅当} \quad (n - m) \ \&\ \left( \left\lfloor \frac{m + 1}{2} \right\rfloor - 1 \right) = 0$$

其中 $\&$ 表示按位与运算。

### 结论推导思路

这个结论的推导基于以下几个数学工具：

1. **组合数奇偶性**（卢卡斯定理）：
   $$\binom{n}{m} \bmod 2 = 1 \quad \text{当且仅当} \quad m \ \&\ n = m$$

2. **斯特林数与组合数的关系**：
   斯特林数的奇偶性可以转化为某个组合数的奇偶性

3. **二进制分析**：
   通过分析斯特林数递推公式在模 $2$ 下的行为，可以发现其奇偶性模式

## 解题思路

基于上述数学结论，我们的算法非常简单：

1. 计算 $diff = n - m$
2. 计算 $k = \lfloor \frac{m + 1}{2} \rfloor - 1$
3. 检查按位与运算：$diff \ \&\ k == 0$
4. 如果为真，输出 $1$；否则输出 $0$

**算法复杂度**：$O(1)$ 每个测试用例

## 代码实现

```cpp
// Binary Stirling Numbers

#include <iostream>
using namespace std;

int stirlingParity(int n, int m) {
    int diff = n - m;
    int k = (m + 1) / 2 - 1;
    return (diff & k) == 0 ? 1 : 0;
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n, m;
        cin >> n >> m;
        cout << stirlingParity(n, m) << endl;
```

## 总结

本题展示了组合数学中一个有趣的现象：看似复杂的组合计数问题，在模 $2$ 的情况下往往有简洁的二进制性质。通过利用斯特林数的奇偶性规律，我们能够在常数时间内解决原本需要指数级复杂度的问题。

这种将组合问题转化为位运算的技巧在竞赛编程中非常有用，特别是在处理大数情况和模小素数的问题时。
