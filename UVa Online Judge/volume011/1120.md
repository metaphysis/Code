## 题目描述

在 $\texttt{Additivia}$ 这个小国，居民们不知道什么是"找零"，这可能与他们也不知道"减法"有关。当他们购买物品时，必须支付恰好等于商品价格的金额（使用他们的货币 $\texttt{addollar}$）。另一种不太吸引人的选择是多付钱。

$\texttt{Additivia}$ 的一位数学家 $\texttt{Adem}$ 教授提出了一种算法来保持钱包的平衡。思路如下：假设你拥有面值为 $v_1$ 的硬币数量多于面值为 $v_2$ 的硬币数量，那么在每次购物时，你应当尽量花费至少与面值 $v_2$ 的硬币数量一样多的面值 $v_1$ 的硬币。当然，过多花费 $v_1$ 硬币也不是好主意，但为了简化算法，$\texttt{Adem}$ 教授决定忽略这个问题。

现在需要编写一个程序，判断在给定一组硬币面值的情况下，能否按照 $\texttt{Adem}$ 算法的规则支付某个金额。

## 输入格式

- 第一行是一个正整数，表示测试用例的数量
- 每个测试用例之间有一个空行
- 每个测试用例的第一行是要支付的金额 $x$（$1 \leq x \leq 100000$）
- 第二行是不同硬币面值的种类数 $k$（$1 \leq k \leq 5$）
- 第三行是硬币的面值 $v_1, \ldots, v_k$（$1 \leq v_i \leq 10000$）

**重要约束**：硬币面值的顺序是重要的——你必须花费至少与 $v_2$ 硬币数量一样多的 $v_1$ 硬币，至少与 $v_3$ 硬币数量一样多的 $v_2$ 硬币，依此类推。

## 输出格式

对于每个测试用例，输出 `YES` 或 `NO`，表示是否能够按照规则支付给定金额。两个测试用例的输出之间用一个空行分隔。

## 题目分析

### 问题本质

这个问题要求我们判断是否存在一组非负整数 $c_1, c_2, \ldots, c_k$，满足以下两个条件：

1. **金额条件**：$c_1v_1 + c_2v_2 + \cdots + c_kv_k = x$
2. **数量约束**：$c_1 \geq c_2 \geq c_3 \geq \cdots \geq c_k \geq 0$

其中 $c_i$ 表示使用的面值为 $v_i$ 的硬币数量。

### 关键观察

1. **问题规模**：$k$ 的最大值为 $5$，这很小，但 $x$ 的最大值达到 $100000$，如果使用朴素的暴力枚举会超时
2. **约束条件**：数量必须非递增，这为我们提供了重要的剪枝机会
3. **搜索顺序**：从高面值到低面值进行搜索，可以更有效地利用约束条件进行剪枝

### 算法选择

由于$k$很小，我们可以使用**深度优先搜索（$\texttt{DFS}$）** 配合**剪枝**来解决问题：

- 从第一种硬币开始枚举可能的数量
- 对于每种硬币，其数量不能超过前一种硬币的数量（保持非递增）
- 同时，当前选择的硬币总价值不能超过目标金额$x$
- 一旦找到满足条件的组合，立即返回成功

## 解题思路详解

### $\texttt{DFS}$ 设计

我们设计一个递归函数：
```cpp
void dfs(int idx, int remaining, int prevCount)
```
参数说明：
- `idx`：当前正在处理的硬币种类索引（从 $0$ 开始）
- `remaining`：剩余需要支付的金额
- `prevCount`：前一种硬币使用的数量（用于约束当前硬币的最大数量）

### 搜索策略

1. **基准情况**：当处理完所有硬币种类时（`idx == k`），检查剩余金额是否为 $0$

2. **枚举范围**：对于当前硬币，其数量 `count` 的取值范围为：
   - 上限：`min(prevCount, remaining / values[idx])`（受前一种硬币数量和剩余金额限制）
   - 下限：$0$

3. **剪枝优化**：
   - 从大到小枚举数量，这样更有可能快速找到解
   - 一旦找到解，立即返回，避免不必要的搜索

### 复杂度分析

- 最坏情况下，搜索空间受限于非递增约束，远小于朴素的组合搜索
- 由于 $k$ 很小（最多 $5$），且约束条件严格，实际运行效率很高

## 代码实现

```cpp
// No Change

// Verdict: Accepted
// Submission Date: 2025-11-16
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int x, k;
vector<int> values;
bool found;

void dfs(int idx, int remaining, int prevCount) {
    if (found) return;
    if (idx == k) {
        if (remaining == 0) found = true;
        return;
    }
    int maxCount = min(prevCount, remaining / values[idx]);
    for (int count = maxCount; count >= 0; --count) {
        dfs(idx + 1, remaining - count * values[idx], count);
        if (found) return;
    }
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        cin >> x >> k;
        values.resize(k);
        for (int i = 0; i < k; ++i)
            cin >> values[i];
        found = false;
        dfs(0, x, x / values[0] + 1); // 初始 prevCount 设为最大可能值
        cout << (found ? "YES" : "NO") << endl;
        if (t) cout << endl;
    }
    return 0;
}
```

## 算法亮点

1. **高效的剪枝**：利用数量非递增约束和金额限制，大幅减少搜索空间
2. **合理的搜索顺序**：从大到小枚举数量，提高找到解的概率
3. **提前终止**：一旦找到解就立即返回，避免不必要的计算

## 总结

本题通过巧妙的 $\texttt{DFS}$ 设计和剪枝策略，成功解决了在严格数量约束下的硬币支付问题。关键在于理解数量非递增约束如何转化为搜索过程中的有效剪枝条件，从而在合理的时间内解决问题。这种结合约束条件和深度优先搜索的方法，在解决组合优化问题时具有很好的参考价值。
