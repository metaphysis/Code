
> **摘要**：给定一个由 $N$ 个正整数组成的序列与目标值 $S$，求元素和大于或等于 $S$ 的最短连续子序列长度，不存在则输出 $0$。利用序列元素全为正数带来的单调性，采用滑动窗口（队列维护）在一次线性扫描中完成求解，每个元素最多入队、出队各一次，时间复杂度 $O(N)$，空间复杂度 $O(N)$。

 # 题目描述

给定一个由 $N$ 个正整数组成的序列，以及一个正整数 $S$。求一个连续子序列，使其元素和大于或等于 $S$，并输出满足条件的连续子序列的最小长度。若不存在符合条件的连续子序列，输出 $0$。

# 输入格式

输入包含多组测试数据，每组数据包括：

- 第一行包含两个整数 $N$ 和 $S$。
- 第二行包含 $N$ 个正整数，表示序列中的元素。

输入以文件结束符结束。

# 输出格式

对于每组测试数据，输出一行一个整数，表示满足条件的连续子序列最小长度；不存在符合条件的连续子序列时输出 $0$。

# 样例输入

```text
10 15
5 1 3 5 10 7 4 9 2 8
5 11
1 2 3 4 5
```

# 样例输出

```text
2
3
```

# 题目分析

题目要求的子序列必须由原序列中一段连续元素构成，并且这一段元素的和至少为 $S$。目标是在所有满足条件的区间中找到长度最小者。由于序列中的元素均为正整数，区间和会随着右端点向右移动而增加，随着左端点向右移动而减少，这一性质使得滑动窗口能够在一次扫描中维护当前区间。

具体来说，固定右端点并不断加入新元素后，只要当前区间的和达到 $S$，就可以尝试移除最左侧的元素，以缩短区间。每次移除前记录当前长度，因此所有可能成为最短答案的窗口都会被纳入比较。若扫描完整个序列后从未出现区间和达到 $S$，则不存在符合条件的连续子序列。

# 解题思路

使用队列保存当前窗口中的元素，并用变量 `sum` 记录窗口元素和，用 `minimum` 记录目前发现的最小窗口长度。

依次读取序列中的每个元素，将其加入队列并累加到 `sum`。每次加入元素后，只要 `sum` 大于或等于 $S$ 且队列非空，就记录队列长度与当前最小长度的较小值，再从队首移除元素并从 `sum` 中减去该元素。由于所有元素均为正数，移除队首后窗口和只会减小；继续执行收缩操作，便能找到以当前右端点结尾的最短可行窗口。

整个过程只需从左到右扫描序列一次。每个元素最多入队一次、出队一次，因此时间复杂度为 $O(N)$。队列最多保存 $N$ 个元素，空间复杂度为 $O(N)$。

# 代码实现

```cpp
// Subsequence

// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int N, S;
    while (cin >> N >> S)
    {
        queue<int> q;
        int n, sum = 0, minimum = 0x3f3f3f3f;
        for (int i = 1; i <= N; i++)
        {
            cin >> n;
            sum += n;
            q.push(n);
            while (sum >= S && !q.empty()) 
            {
                minimum = min(minimum, (int)q.size());
                sum -= q.front();
                q.pop();
            }
        }
        if (minimum == 0x3f3f3f3f) minimum = 0;
        cout << minimum << '\n';
    }

    return 0;
}
```

# 总结

本题利用了正整数序列的单调性，将连续子序列的最短长度问题转化为滑动窗口问题。窗口和达到目标后立即收缩，并在每次收缩前更新答案。每个元素最多进入和离开窗口各一次，因此算法在线性时间内完成。
