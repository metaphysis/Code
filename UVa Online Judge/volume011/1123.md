## 题目分析

本题要求统计给定文本中所有长度为 $N$ 的不同子串的数量。其中，文本中可能出现的不同字符数为 $NC$。题目保证所有可能的子串数量不超过 $1600$ 万。

### 关键点分析

$1$. **问题规模**：直接存储所有子串会占用大量内存且效率低下，因为每个子串长度为 $N$，而子串数量可能很大。
$2$. **字符集限制**：文本中实际出现的不同字符数不超过 $NC$，这提示我们可以将字符映射到数字 $0$ 到 $NC-1$。
$3$. **哈希优化**：我们可以将每个长度为 $N$ 的子串视为一个 $NC$ 进制的 $N$ 位数，计算其对应的整数值作为哈希值。这样可以在 $O(1)$ 时间内判断子串是否出现过。
$4$. **滚动哈希**：通过滑动窗口技术，我们可以在 $O(1)$ 时间内计算相邻窗口的哈希值，从而将整体时间复杂度优化到 $O(L)$，其中 $L$ 是文本长度。

### 算法步骤

$1$. **字符映射**：遍历文本，为每个不同字符分配一个唯一的数字编号（$0$ 到 $NC-1$）。
$2$. **预计算幂值**：计算 $NC^{N-1}$，用于在滑动窗口时快速移除最左字符的贡献。
$3$. **滑动窗口哈希**：
   - 初始化第一个窗口的哈希值
   - 使用布尔数组标记出现过的哈希值
   - 滑动窗口时，移除最左字符的贡献，加入新字符的贡献
$4$. **统计结果**：统计不同哈希值的数量即为不同子串的数量。

### 复杂度分析

- **时间复杂度**：$O(L)$，其中 $L$ 是文本长度
- **空间复杂度**：$O(NC^N)$，但题目保证不超过 $1600$ 万

## 参考代码

```cpp
// Crazy Search
// UVa ID: 1123
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXHASH = 16000000;  // 最大哈希值范围
bool used[MAXHASH];            // 标记数组，记录哈希值是否出现过
int charMap[256];              // 字符到数字的映射表
char text[1000000];            // 输入文本缓冲区

int main() {
    int T;  // 测试用例数量
    scanf("%d", &T);
    while (T--) {
        int N, NC;  // N: 子串长度, NC: 字符集大小
        scanf("%d%d%s", &N, &NC, text);
        // 初始化字符映射表为-1
        memset(charMap, -1, sizeof(charMap));
        int id = 0;  // 当前分配的字符编号
        // 建立字符到数字的映射
        for (char *p = text; *p; p++)
            if (charMap[(int)*p] == -1)
                charMap[(int)*p] = id++;
        // 计算 NC^(N-1)，用于滑动窗口时移除最左字符
        int power = 1;
        for (int i = 1; i < N; i++) power *= NC;
        // 初始化标记数组
        memset(used, 0, sizeof(used));
        int hash = 0;           // 当前窗口的哈希值
        int len = strlen(text); // 文本长度
        int count = 0;          // 不同子串计数器
        // 滑动窗口处理所有子串
        for (int i = 0; i < len; i++) {
            // 加入新字符到哈希值
            hash = hash * NC + charMap[(int)text[i]];
            // 当窗口长度达到N时开始统计
            if (i >= N - 1) {
                // 如果该哈希值未出现过，计数并标记
                if (!used[hash]) {
                    used[hash] = true;
                    count++;
                }
                // 移除最左字符的贡献，为下一个窗口准备
                hash -= charMap[(int)text[i - N + 1]] * power;
            }
        }
        // 输出结果
        printf("%d\n", count);
        // 测试用例间输出空行
        if (T) printf("\n");
    }
    return 0;
}
```

## 总结

本题通过将子串转换为 $NC$ 进制数的方法，巧妙地避免了直接存储字符串的开销。结合滑动窗口技术，实现了 $O(L)$ 时间复杂度的高效算法。关键在于利用字符集有限的特性，将字符串比较问题转化为整数标记问题，大大提高了效率。
