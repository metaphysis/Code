 # 题目描述

给定一个已经写出答案的数学表达式，要求构造一个能得到该答案的最简单方程。题目规定，最简单的方程就是原样保留给定的答案，因此程序只需逐行读取输入并原样输出。

# 输入格式

每行包含一个解，形式为 `<符号> = <值>`。输入包含多行。

# 输出格式

对于每行输入，将该行内容原样输出，包括空格。

# 样例输入

```text
Y = 3
X=9
```

# 样例输出

```text
Y = 3
X=9
```

# 题目分析

题目要求输出能导向给定答案的最简单方程。根据题意，直接把输入行作为方程输出即可，无需进行数学运算、解析或格式转换。输入中的空格属于需要保留的内容，因此不能使用会按空白字符切分数据的读取方式。

# 解题思路

使用 `getline` 逐行读取标准输入。每读取一行，就立即输出该行，并在末尾补上换行符。这样能够保留行内所有字符，包括空格和等号两侧的格式。读到文件末尾后程序结束。

设输入总字符数为 $N$，每个字符只被读取和输出一次，因此时间复杂度为 $O(N)$。程序保存当前输入行，空间复杂度为 $O(N)$，其中 $N$ 表示最长输入行的长度。

# 代码实现

代码使用 `getline` 读取整行，并直接输出原始内容。

```cpp
// Celebrity Jeopardy
// UVa ID: 1124
// Verdict: Accepted
// Submission Date: 2017-12-17
// UVa Run Time: 0.000s
//
// 版权所有（C）2017，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    string line;
    while (getline(cin, line)) cout << line << '\n';
    return 0;
}
```

# 总结

本题的关键是识别输入与输出内容完全相同，并使用逐行读取方式保留格式。对于要求原样处理文本的题目，应避免按空格拆分输入。
