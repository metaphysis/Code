
> **摘要**：本文讨论一个基于质数关系集合的经典图论问题：给定 $P$ 个质数与依次到达的 $R$ 个关系，每次尝试把新关系加入集合 $C$，若加入后存在某个子集乘积为完全平方数，则计数加一并丢弃该关系。文章指出，把质数看作顶点、关系看作无向边后，「子集乘积为完全平方数」等价于所选边集构成环，因此集合 $C$ 始终是一片森林。基于这一转化，只需用并查集（$\texttt{DSU}$）在线判断新边两端是否已连通：不连通则合并，连通则答案加一。配合路径压缩与按大小合并，总时间复杂度为 $O(R\alpha(P))$，空间复杂度为 $O(P)$，可轻松应对 $P, R \le 10^6$ 的数据规模。

# 题目描述

给定 $P$ 个编号为 $1$ 到 $P$ 的质数，以及依次到达的 $R$ 个关系。每个关系由两个不同质数构成，记为 $\{p_i, q_i\}$。

维护一个关系集合 $C$，初始时 $C$ 为空。每当新关系到达时，若将该关系加入 $C$ 后不存在任何子集乘积为完全平方数，则将该关系加入 $C$；否则，平方数计数加 $1$，且不将该关系保存到 $C$ 中。

对于每组数据，输出整个过程中出现的平方数数量。

# 输入格式

输入包含多组测试数据，相邻两组测试数据之间存在空行。

每组测试数据的第一行包含两个整数 $P$ 和 $R$，其中 $P \le 10^6$，$R \le 10^6$。

接下来有 $R$ 行，每行包含两个整数 $i$ 和 $j$，表示一个关系 $\{p_i, p_j\}$，其中 $1 \le i, j \le P$。

# 输出格式

对于每组测试数据，输出能够形成完全平方数的次数。

相邻两组输出之间输出一个空行。

# 样例输入

```text
6 7
1 2
3 5
2 4
1 4
3 5
1 6

4 6
2 3
1 2
1 2
1 2
```

# 样例输出

```text
3

2
```

# 题目分析

每个质数只关心出现次数的奇偶性。若若干关系的乘积是完全平方数，则其中每个质数出现的次数均为偶数。

将每个质数视为无向图中的一个顶点，将一个关系 $\{p_i, q_i\}$ 视为连接两个顶点的一条无向边。选择若干关系相乘时，某个质数出现的次数等于对应顶点在所选边集中的度数。

因此，若若干关系的乘积为完全平方数，则所选边集中每个顶点的度数均为偶数。无向图中所有顶点度数均为偶数的非空边集必然包含环。反过来，环上的每个顶点恰好连接两条被选中的边，出现次数均为 $2$，这些关系的乘积必然是完全平方数。

由此可知，题目中维护的集合 $C$ 始终不包含环，因此 $C$ 对应的图始终是一片森林。每次新关系到达时，只需要判断其两个端点是否已经位于同一棵树中。

# 解题思路

使用 $\texttt{DSU}$ 维护当前森林中各顶点的连通关系。

步骤 $\texttt{1}$. 初始时，每个顶点单独构成一个连通块，答案 $ans$ 初始化为 $0$。

步骤 $\texttt{2}$. 对于新到达的关系 $(x, y)$，分别找到 $x$ 和 $y$ 所在连通块的根节点。

步骤 $\texttt{3}$. 若两个根节点不同，则 $x$ 和 $y$ 当前不连通。加入这条边不会形成环，将两个连通块合并，并将该关系保留在集合 $C$ 中。

步骤 $\texttt{4}$. 若两个根节点相同，则 $x$ 和 $y$ 已经连通。当前森林中存在一条从 $x$ 到 $y$ 的唯一简单路径，新边与该路径构成一个环，因此产生一个完全平方数，令 $ans$ 加 $1$，且不合并两个连通块。

$\texttt{DSU}$ 采用路径压缩和按集合大小合并。每次查询与合并的均摊时间复杂度为 $O(\alpha(P))$，其中 $\alpha$ 为反阿克曼函数，增长速度极慢。

处理 $R$ 个关系的总时间复杂度为：

$$
O(R \alpha(P))
$$

空间复杂度为：

$$
O(P)
$$

# 代码实现

$\texttt{Dsu}$ 类使用数组 $\textit{parent}$ 维护每个节点的父节点，数组 $\textit{size}$ 维护连通块大小。$\texttt{findRoot}$ 函数通过路径压缩查找根节点，$\texttt{mergeSet}$ 函数负责判断两个顶点能否合并。

```cpp
#include <bits/stdc++.h>
using namespace std;

class Dsu {
private:
    vector<int> parent, size;
public:
    Dsu(int n) {
        parent.resize(n + 1);
        size.assign(n + 1, 1);
        for (int i = 1; i <= n; i++) parent[i] = i;
    }
    int findRoot(int x) {
        if (parent[x] != x) parent[x] = findRoot(parent[x]);
        return parent[x];
    }
    bool mergeSet(int x, int y) {
        int rx = findRoot(x), ry = findRoot(y);
        if (rx == ry) return false;
        if (size[rx] < size[ry]) swap(rx, ry);
        parent[ry] = rx;
        size[rx] += size[ry];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int p, r, caseNum = 0, x, y, ans;
    while (cin >> p >> r) {
        Dsu dsu(p);
        ans = 0;
        for (int i = 0; i < r; i++) {
            cin >> x >> y;
            if (!dsu.mergeSet(x, y)) ans++;
        }
        if (caseNum++) cout << '\n';
        cout << ans << '\n';
    }
    return 0;
}
```

# 总结

本题的核心是将关系转化为无向图中的边，并将完全平方数条件转化为图中的环结构。集合 $C$ 不存在平方子积，等价于其对应图不存在环，因此该图始终是一片森林。

新边的两个端点已经连通时，新边必然形成环，答案加 $1$；两个端点不连通时，直接合并连通块。使用 $\texttt{DSU}$ 能够在线完成所有关系的判断，满足 $P$ 和 $R$ 均达到 $10^6$ 时的效率要求。
