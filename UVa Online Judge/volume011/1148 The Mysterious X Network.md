
> **摘要**：本题给定一个由校友认识关系构成的无权无向图，要求求出从起点校友 $c_1$ 到目标校友 $c_2$ 的最少中间校友人数。核心思路是将问题转化为无权图上的最短路径问题，使用广度优先搜索（$\texttt{BFS}$）求出最短路径边数，再减去 $1$ 得到中间顶点数量。每组测试用例的时间复杂度为 $O(N+M)$，空间复杂度为 $O(N+M)$。

 # 题目描述

某所学校的校友之间形成了一个相互联系的网络。校友之间的认识关系是对称的，即一个校友认识另一个校友时，后者也认识前者。题目保证任意两名校友之间都存在一条联系路径。

当一名校友希望向另一名校友寻求帮助时，可以通过若干名中间校友逐步联系到对方。给定所有校友之间的认识关系，以及寻求帮助的校友 $c_1$ 和目标校友 $c_2$，求联系过程中所需的最少中间校友人数。起点校友和终点校友不计入中间人数。

# 输入格式

输入的第一行包含一个正整数 $T$，表示测试用例的数量。该行之后有一个空行，相邻测试用例之间也有一个空行。

每组测试用例的第一行包含一个整数 $N$，表示校友总人数，满足 $1 \le N \le 10^5$。所有校友的编号为 $0$ 到 $N-1$。

接下来有 $N$ 行，每行首先给出一名校友的编号 $c$，然后给出他认识的校友人数 $n_c$，最后给出这 $n_c$ 名校友的编号。其中 $0 \le n_c < 100$，各整数之间以空格分隔。

最后一行包含两个整数 $c_1$ 和 $c_2$，分别表示寻求帮助的校友和目标校友，且 $c_1 \ne c_2$。

# 输出格式

对于每组测试用例，输出一行，依次包含 $c_1$、$c_2$ 和联系到目标校友所需的最少中间校友人数，三个整数之间以一个空格分隔。

相邻测试用例的输出之间保留一个空行。

# 样例输入

```text
1

4
0 3 1 2 3
1 1 0
2 2 0 3
3 2 0 2
1 2
```

# 样例输出

```text
1 2 1
```

# 题目分析

将每名校友看作图中的一个顶点，将两名校友之间的认识关系看作一条无向边，就得到了一个无权无向图。一次关系传递对应沿一条边从当前顶点到达相邻顶点。题目要求最少经过多少名中间校友，本质上就是求起点 $c_1$ 到终点 $c_2$ 的最短路径，再将路径长度换算为中间顶点数量。

设一条联系路径为 $v_0,v_1,\ldots,v_d$，其中 $v_0=c_1$，$v_d=c_2$。这条路径经过 $d$ 条边，包含 $d+1$ 个顶点，去掉起点和终点后，中间校友人数为 $d-1$。由于 $c_1 \ne c_2$，并且题目保证任意两名校友之间都存在联系路径，所以最短路径长度至少为 $1$，答案至少为 $0$。当两名校友直接认识时，最短路径长度为 $1$，对应的中间人数正好为 $0$。因此，只需计算最短路径的边数，最后减去 $1$。

图中的所有边都表示一次关系传递，边的代价相同，因此使用广度优先搜索 $\texttt{BFS}$ 求最短路径。广度优先搜索按照距离从小到大的顺序访问顶点：先访问起点，再访问与起点相距 $1$ 条边的顶点，随后访问相距 $2$ 条边的顶点，依次推进。某个顶点第一次被发现时，其最短距离就已经确定，无须继续尝试更新。

样例中，校友 $1$ 认识校友 $0$，校友 $0$ 认识校友 $2$，因此存在路径 $1 \to 0 \to 2$。校友 $1$ 与校友 $2$ 不直接认识，最短路径包含 $2$ 条边，所需的中间校友人数为 $2-1=1$。

# 解题思路

使用邻接表保存图。读入一条从校友 $u$ 到校友 $v$ 的认识关系时，同时将 $v$ 加入 $u$ 的邻接表，并将 $u$ 加入 $v$ 的邻接表，以体现认识关系的对称性。输入中同一对校友的关系会在双方的记录中重复出现，因此这种建图方式会产生重复边。重复边只会增加邻接表的遍历次数，不会影响最短路径结果，因为每个顶点只在第一次被发现时入队。

对每组测试用例，先清空当前 $N$ 个顶点的邻接表，并将访问标记数组 $\textit{visited}$ 清零，避免上一组数据影响当前结果。建图完成后，将起点的距离设为 $\textit{length}[c_1]=0$，把起点加入队列，并立即标记为已访问。随后不断取出队首顶点 $u$，遍历它的所有邻接顶点 $v$。对于尚未访问的顶点，令 $\textit{length}[v]=\textit{length}[u]+1$，将其加入队列并标记为已访问。访问标记在入队时设置，保证同一个顶点不会被多个前驱重复加入队列。

这一过程的正确性来自队列维护的距离顺序。起点距离为 $0$，显然正确。假设当前取出的顶点 $u$ 的距离已经是最短距离，那么从它到达一个尚未访问的邻接顶点 $v$，便得到长度为 $\textit{length}[u]+1$ 的路径。若存在更短的路径到达 $v$，该路径上位于 $v$ 之前的顶点距离一定小于 $\textit{length}[u]$，按照广度优先搜索的处理顺序，它早已出队并发现 $v$，这与 $v$ 尚未访问矛盾。因此，每个顶点第一次被发现时记录的距离都是最短距离。

代码在目标顶点 $c_2$ 出队后结束搜索，此时 $\textit{length}[c_2]$ 已经是从起点到目标的最短路径边数。最终输出 $\textit{length}[c_2]-1$，即最少中间校友人数。输入使用格式化读取，空行会作为空白字符自动跳过；输出时，从第二组测试用例开始先输出一个换行，从而满足相邻结果之间保留一个空行的要求。

设 $M=\sum_{c=0}^{N-1}n_c$，表示输入中列出的认识关系总数，包含双方分别列出的关系。代码对每条输入关系保存两个邻接表元素，因此共保存 $2M$ 个邻接表元素。初始化需要 $O(N)$ 时间，建图需要 $O(M)$ 时间，广度优先搜索中每个顶点最多入队一次、每个邻接表元素最多被扫描一次，因此每组测试用例的时间复杂度为 $O(N+M)$。邻接表占用 $O(N+M)$ 空间，距离数组、访问标记数组和队列所需空间均为 $O(N)$，所以空间复杂度为 $O(N+M)$。代码中的数组按题目规模上限预分配。由于 $n_c<100$，有 $M\le 99N$，在本题约束下，时间复杂度和空间复杂度均可进一步写为 $O(N)$。

# 代码实现

```cpp
// The Mysterious X Network
// UVa ID: 1148

// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXV = 100010;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int cases, n, nc, c1, c2, length[MAXV], visited[MAXV];
    list<int> edges[MAXV];

    cin >> cases;
    for (int c = 1; c <= cases; c++)
    {
        cin >> n;
        
        for (int i = 0; i < n; i++)
        {
            visited[i] = 0;
            edges[i].clear();
        }
        
        for (int i = 0; i < n; i++)
        {
            cin >> c1 >> nc;
            for (int j = 0; j < nc; j++)
            {
                cin >> c2;
                edges[c1].push_back(c2);
                edges[c2].push_back(c1);
            }
        }

        cin >> c1 >> c2;
        length[c1] = 0;
        queue<int> q;
        q.push(c1);
        visited[c1] = 1;
        while (!q.empty())
        {
            int u = q.front(); q.pop();
            for (auto v : edges[u])
                if (!visited[v])
                {
                    length[v] = length[u] + 1;
                    q.push(v);
                    visited[v] = 1;
                }
            if (u == c2) break;
        }
        if (c > 1) cout << '\n';
        cout << c1 << ' ' << c2 << ' ' << (length[c2] - 1) << '\n';
    }

    return 0;
}
```

# 总结

本题的关键是将校友关系抽象为无权无向图，并区分最短路径边数与中间顶点数量。使用 $\texttt{BFS}$ 得到最短路径长度后，减去 $1$ 就得到最少中间校友人数。实现时，在顶点入队时设置访问标记，能够避免重复入队，也使重复边不影响答案；处理多组数据时清空邻接表和访问标记，并按要求输出组间空行，即可完整解决本题。
