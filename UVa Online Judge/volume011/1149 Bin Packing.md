
> **摘要**：本题给定 $n$ 件长度不超过箱子长度 $l$ 的一维物品，每个箱子最多装 $2$ 件且物品长度之和不超过 $l$，求装下全部物品所需的最少箱子数。核心结论是箱子数 $q=n-p$（$p$ 为合法配对数量），故问题转化为最大化配对。将物品长度升序排序后，用双指针从两端贪心：最短与最长之和不超过 $l$ 则配对，否则最长物品单独装箱，配合交换论证可证其最优性。总时间复杂度 $O(n\log n)$，空间复杂度 $O(n)$。

 # 题目描述

给定 $n$ 件一维物品，第 $i$ 件物品的长度为 $l_i$。所有箱子的长度均为 $l$，且每件物品都满足 $l_i \le l$。需要将所有物品装入箱子，每个箱子最多装入 $2$ 件物品，同一个箱子内物品的长度之和不能超过 $l$，每件物品必须且只能装入一个箱子。求装下所有物品所需的最少箱子数量 $q$。

# 输入格式

第一行包含一个正整数 $T$，表示测试用例的数量。该行之后有一个空行，相邻测试用例之间也有一个空行。

每组测试用例的第一行包含一个整数 $n$，表示物品数量，满足 $1 \le n \le 10^5$；第二行包含一个整数 $l$，表示箱子长度，满足 $l \le 10000$；随后 $n$ 行，每行包含一个整数 $l_i$，表示一件物品的长度，且 $l_i \le l$。

# 输出格式

对于每组测试用例，输出一个整数，表示装下全部物品所需的最少箱子数量。相邻测试用例的输出之间用一个空行分隔。

# 样例输入

```text
1

10
80
70
15
30
35
10
80
20
35
10
30
```

# 样例输出

```text
6
```

# 题目分析

每个箱子最多容纳 $2$ 件物品，因此最终装箱方案只包含单独装箱和两件配对装箱两种形式。设成功配对的数量为 $p$，配对物品需要 $p$ 个箱子，其余 $n-2p$ 件物品各自占用一个箱子，箱子总数为
$$
q=p+(n-2p)=n-p.
$$
因此，最小化箱子数量等价于最大化合法配对数量。这里的配对不仅受到物品数量限制，还要求配对的两件物品长度之和不超过箱子长度。

将物品长度按非递减顺序排列，记为 $a_0,a_1,\ldots,a_{n-1}$。考虑当前尚未处理的最短物品和最长物品：如果二者长度之和超过 $l$，那么最长物品与其他任何剩余物品的长度之和也都超过 $l$，因此最长物品必须单独装箱；如果二者长度之和不超过 $l$，则将它们放入同一个箱子能够保留最优解。这一性质使得排序后的双指针贪心成立，每次处理最长物品，并根据剩余最短物品的长度确定是否配对。

# 解题思路

首先对物品长度进行升序排序，使用左右两个指针分别指向尚未处理的最短物品和最长物品，并将箱子计数初始化为 $0$。只要两个指针尚未相遇，就比较它们所指物品的长度之和：若不超过 $l$，将两件物品装入同一个箱子，两个指针分别向中间移动；若超过 $l$，将最长物品单独装箱，只移动右指针。每次处理都会确定一个箱子，因此箱子计数增加 $1$。循环结束后，如果两个指针指向同一件物品，则还剩下一件物品，需要再增加 $1$ 个箱子；如果两个指针已经交错，则所有物品均已装箱。

下面证明每次选择都能够保留最优解。设当前剩余物品中最短物品的长度为 $x$，最长物品的长度为 $y$。当 $x+y>l$ 时，任意其他剩余物品的长度 $z$ 都满足 $z\ge x$，因此 $z+y\ge x+y>l$，最长物品只能单独装箱，这一步是所有合法方案都必须执行的选择。当 $x+y\le l$ 时，取当前物品集合的任意一个最优方案。如果 $x$ 与 $y$ 已经配对，则当前贪心选择与该最优方案一致；如果二者都单独装箱，则将它们合并能够减少一个箱子，与原方案最优矛盾；如果其中一件单独装箱，另一件与长度为 $u$ 的物品配对，则改成 $x$ 与 $y$ 配对、$u$ 单独装箱，箱子数量保持不变；如果 $x$ 与长度为 $u$ 的物品配对，$y$ 与长度为 $v$ 的物品配对，则改成 $x$ 与 $y$ 配对、$u$ 与 $v$ 配对。由于 $y$ 是最长物品，且原来的配对满足 $y+v\le l$，因此
$$
u+v\le y+v\le l.
$$
交换后的两组配对均合法，箱子数量也保持不变。因此，当最短物品与最长物品能够配对时，一定存在包含该配对的最优方案。每次贪心选择后，剩余问题仍具有相同结构，持续执行即可得到全局最优解。

样例中，排序后的长度依次为 $10,10,15,20,30,30,35,35,70,80$，箱子长度为 $80$。按照上述方法，装箱结果依次为 $(80)$、$(10,70)$、$(10,35)$、$(15,35)$、$(20,30)$、$(30)$，共使用 $6$ 个箱子。

对于每组测试用例，排序的时间复杂度为 $O(n\log n)$，双指针扫描的时间复杂度为 $O(n)$，总时间复杂度为 $O(n\log n)$。按物品数量计，存储物品长度所需的空间复杂度为 $O(n)$；给定代码使用容量为 $100010$ 的固定数组覆盖题目中的全部数据范围，排序的递归栈空间为 $O(\log n)$。输入采用格式化读取，空行会作为空白字符自动跳过；每组答案输出后，仅在仍有后续测试用例时输出额外空行。

# 代码实现

代码中的 $L$ 对应题目中的箱子长度 $l$，数组 $\textit{li}$ 保存物品长度，$\textit{head}$ 和 $\textit{rear}$ 分别表示左右指针，$r$ 记录已经使用的箱子数量。调用 $\texttt{sort}$ 函数完成升序排序后，按照上述贪心策略移动指针并统计答案。

```cpp
// Bin Packing
// UVa ID: 1149
// Verdict: Accepted
// Submission Date: 2023-07-05
// UVa Run Time: 0.020s
//
// 版权所有（C）2023，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
int main(int argc, char *argv[]) {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int li[100010], n, L, T;
    cin >> T;
    while (T--) {
        cin >> n >> L;
        for (int i = 0; i < n; i++) cin >> li[i];
        sort(li, li + n);
        int r = 0, head = 0, rear = n - 1;
        while (head < rear) {
            if (li[head] + li[rear] <= L) head++, rear--, r++;
            else rear--, r++;
        }
        if (head == rear) r++;
        cout << r << '\n';
        if (T) cout << '\n';
    }
    return 0;
}
```

# 总结

本题的关键是利用每个箱子最多装入 $2$ 件物品的限制，将最少装箱问题转化为最多合法配对问题。排序后，最长物品无法与最短物品配对时必须单独装箱，能够配对时则通过交换论证保证该选择保留最优解。双指针让每件物品只被处理一次，最终以 $O(n\log n)$ 的时间复杂度得到最少箱子数量。实现时需要正确处理最后剩余的单件物品，并遵守多组输出之间空一行的格式要求。
