
> **摘要**：本题给定四个长度为 $n$ 的整数序列 $A$、$B$、$C$、$D$，要求统计满足 $a+b+c+d=0$ 的四元组数量。直接四重枚举的 $O(n^4)$ 复杂度无法承受 $n\le 4000$ 的数据规模，因此采用折半枚举：先分别构造 $A+B$ 与 $C+D$ 两组两数之和数组，再对其中一组排序，遍历另一组并用 `lower_bound` 与 `upper_bound` 统计相反数的出现次数，将复杂度降至 $O(n^2\log n)$，空间复杂度为 $O(n^2)$。实现时需保留重复和、用左右边界之差计数，并注意答案上界 $n^4$ 需要 64 位整数。

 # 题目描述

给定 $4$ 个长度均为 $n$ 的整数序列 $A$、$B$、$C$、$D$，分别从每个序列中选择一个元素，统计满足下式的四元组数量：
$$
a+b+c+d=0
$$
其中 $a\in A$、$b\in B$、$c\in C$、$d\in D$。每次选择按照元素在序列中的位置区分，因此相同数值出现在不同位置时，对应不同的选择。

# 输入格式

第一行包含一个正整数，表示测试用例数量。其后给出各组测试数据，第一组数据之前以及相邻两组数据之间均有一个空行。

每组数据的第一行包含一个整数 $n$，表示每个序列的长度，其中 $1\le n\le 4000$。接下来共有 $n$ 行，每行包含 $4$ 个整数，分别表示序列 $A$、$B$、$C$、$D$ 在当前位置上的元素。所有元素的绝对值均不超过 $2^{28}$。

# 输出格式

对于每组测试数据，输出一行，表示元素之和等于 $0$ 的四元组数量。相邻两组测试数据的输出之间保留一个空行。

# 样例输入

```text
1

6
-45 22 42 -16
-41 -27 56 30
-36 53 -37 77
-36 30 -75 -46
26 -38 -10 62
-32 -54 -6 45
```

# 样例输出

```text
5
```

# 题目分析

直接枚举分别来自 $4$ 个序列的元素，需要检查 $n^4$ 个四元组，时间复杂度为 $O(n^4)$。当 $n=4000$ 时，枚举数量达到 $256000000000000$，无法满足计算效率要求。题目的关键在于将四个元素之间的关系拆成两对元素之间的关系：
$$
A_i+B_j+C_k+D_l=0
\iff
A_i+B_j=-(C_k+D_l)
$$
因此，只需分别求出序列 $A$ 与 $B$ 的所有两数之和，以及序列 $C$ 与 $D$ 的所有两数之和，再统计两组和中互为相反数的配对数量。每组两数之和都包含 $n^2$ 个元素，问题规模由四重枚举转化为对两个长度为 $n^2$ 的数组进行匹配，这正是折半枚举的核心思想。

重复值是本题计数的重点。两个不同的下标组合即使产生相同的两数之和，也必须分别保留，因为它们对应不同的元素选择。设某个和 $s$ 在第一组两数之和中出现 $p$ 次，$-s$ 在第二组两数之和中出现 $q$ 次，则这两个值对答案的贡献为 $p\times q$。通过代码采用逐项遍历第一组两数之和、查询第二组中目标值出现次数的方式完成统计：第一组中的每次出现都会累加 $q$，最终自然得到 $p\times q$，因此整个过程不能对两数之和去重。

排序使重复值集中在连续区间内，从而能够通过两次二分查找计算出现次数。对于目标值 $t$，其首次出现的位置等于第一个大于等于 $t$ 的元素位置，而其最后一次出现之后的位置等于第一个大于 $t$ 的元素位置。两者之差就是 $t$ 的出现次数；目标值不存在时，两者相等，贡献为 $0$。

# 解题思路

将序列下标设为从 $0$ 开始，构造两个长度均为 $n^2$ 的数组 $\textit{AB}$ 和 $\textit{CD}$，分别保存所有跨序列的两数之和：
$$
\textit{AB}_{in+j}=A_i+B_j,\qquad
\textit{CD}_{in+j}=C_i+D_j,\qquad
0\le i,j<n
$$
这里的 $in+j$ 将下标对映射到连续的一维位置，保证每一种选择都恰好保存一次。随后对两个数组分别进行升序排序。通过代码同时排序两个数组，其中对 $\textit{CD}$ 的排序用于支持二分查找，对 $\textit{AB}$ 的排序保留了其全部元素及出现次数。

依次遍历 $\textit{AB}$ 中的每一个元素 $s$，令目标值 $t=-s$。由于 $\textit{CD}$ 已经有序，当 $t$ 小于其最小值或大于其最大值时，该目标值的出现次数为 $0$，直接处理下一个元素；否则，调用 $\texttt{lower_bound}$ 找到第一个大于等于 $t$ 的位置 $k_1$，再调用 $\texttt{upper_bound}$ 找到第一个大于 $t$ 的位置 $k_2$。通过代码将后一次查找的起点设置为 $k_1$，因为所有位于 $k_1$ 之前的元素均小于 $t$，不会成为第一个大于 $t$ 的元素。以数组末尾之后的位置作为不存在时的返回位置，则目标值的出现次数为：
$$
\operatorname{count}(t)=k_2-k_1
$$
将每次查询得到的次数累加，就得到全部合法四元组的数量：
$$
\textit{ans}=
\sum_{r=0}^{n^2-1}
\operatorname{count}\!\left(-\textit{AB}_r\right)
$$
正确性来自四元组与两组下标对之间的一一对应关系。对于任意合法四元组 $(i,j,k,l)$，数组 $\textit{AB}$ 中对应下标对 $(i,j)$ 的元素恰好被遍历一次，而数组 $\textit{CD}$ 中对应下标对 $(k,l)$ 的元素必然等于它的相反数，因此该四元组恰好被计入一次。反过来，每次累加的匹配都满足两组和互为相反数，对应四个元素之和为 $0$，因此不会计入非法四元组。重复值保留了不同下标对的全部出现次数，所以相同数值也不会造成漏计。

构造两个数组需要 $O(n^2)$ 时间，排序需要 $O(n^2\log(n^2))$ 时间，执行 $n^2$ 次二分查询同样需要 $O(n^2\log(n^2))$ 时间，因此总时间复杂度为 $O(n^2\log n)$。两个两数之和数组各保存 $n^2$ 个元素，空间复杂度为 $O(n^2)$。

计数类型需要单独说明。答案最大为 $n^4$，当所有输入元素均为 $0$ 且 $n=4000$ 时，答案为 $256000000000000$，超出常见的 $32$ 位有符号整数范围。所附通过代码使用 $\texttt{int}$ 类型的 $\textit{pairs}$ 保存答案，在这一合法极端输入下会发生有符号整数溢出，无法保证正确输出；覆盖完整题面范围需要使用 $\texttt{long long}$ 保存答案。下文按照要求原样保留通过代码。

# 代码实现
```cpp
// 4 Values Whose Sum is 0
// UVa ID: 1152
// Verdict: Accepted
// Submission Date: 2019-01-28
// UVa Run Time: 1.930s
//
// 版权所有（C）2019，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 4010;

long long A[MAXN], B[MAXN], C[MAXN], D[MAXN];
long long AB[MAXN * MAXN], CD[MAXN * MAXN];

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int cases, n;
    cin >> cases;
    for (int cs = 1; cs <= cases; cs++)
    {
        cin >> n;
        for (int i = 0; i < n; i++)
            cin >> A[i] >> B[i] >> C[i] >> D[i];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
            {
                AB[i * n + j] = A[i] + B[j];
                CD[i * n + j] = C[i] + D[j];
            }
        sort(AB, AB + n * n);
        sort(CD, CD + n * n);
        int last = n * n, pairs = 0;
        for (int i = 0; i < last; i++)
        {
            long long T = -AB[i];
            if (T < CD[0] || T > CD[last - 1]) continue;
            int k1 = lower_bound(CD, CD + last, T) - CD;
            int k2 = upper_bound(CD + k1, CD + last, T) - CD;
            pairs += k2 - k1;
        }
        if (cs > 1) cout << '\n';
        cout << pairs << '\n';
    }
    return 0;
}
```

# 总结

本题通过折半枚举，将四个序列的组合计数转化为两组两数之和的相反数匹配，再利用排序与二分查找统计重复次数，将时间复杂度从 $O(n^4)$ 降低到 $O(n^2\log n)$，空间复杂度为 $O(n^2)$。实现时的关键是保留重复和、用左右边界之差计算出现次数，并根据答案上界选择足够宽的整数类型。这种先拆分组合、再匹配中间结果的方法适用于多组元素之间的求和与计数问题。
