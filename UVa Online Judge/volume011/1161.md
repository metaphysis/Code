## 题目描述

某知名足球队管理层针对国际客场比赛中缺乏球迷支持的问题进行了研究，发现**唯一原因**是旅行安排过于困难。为了解决这个问题，管理层需要你编写一个程序，计算在给定一天内，利用常规航班的可用座位，**最多能有多少人**从出发城市飞到目的地城市，并且**在或早于指定最晚到达时间**抵达。

旅客可以从一座城市前往另一座城市，并且可以进行多次中转。每次中转至少需要 **$30$ 分钟**，即下一航班的起飞时间必须至少比上一航班的到达时间晚 $30$ 分钟。给定一天内的所有航班信息以及最晚到达时间，你的程序应计算出**最多能有多少人**（直接或间接）从出发城市前往目的地城市，并在最晚到达时间之前（含）抵达。

---

## 输入格式

输入包含多个测试用例，每个测试用例格式如下。连续测试用例之间用一个空行分隔。

- 第一行：一个整数（ $\leq 150$ ），表示有航班连接的城市数量。
- 第二行：一个字符串，表示出发城市。
- 第三行：一个字符串，表示目的地城市。
- 第四行：最晚到达时间，格式为 $\texttt{HHMM}$ ，其中 $\texttt{HH}$ 是小时（ $00$ - $23$ ）， $\texttt{MM}$ 是分钟（ $00$ - $59$ ）。
- 第五行：一个整数 $N$ （ $\leq 5000$ ），表示航班数量。
- 接下来的 $N$ 行：每行包含一个航班的信息，格式为：
  ```
  O E C D A
  ```
  其中：
  - $O$ 和 $E$ 是字符串，分别表示航班的起点和终点城市（城市名称最多 $8$ 个字符）。
  - $C$ 是整数（ $0$ - $300$ ），表示该航班的可用座位数。
  - $D$ 和 $A$ 是整数，表示起飞和到达时间，格式为 $\texttt{HHMM}$ 。所有航班都在同一天内完成。

---

## 输出格式

对于每个测试用例，输出一行一个整数，表示在给定条件下，最多能从出发城市到达目的地城市的人数。

## 题目分析

本题是一个**最大流问题**，但增加了时间约束和中转时间限制。每个航班有容量（座位数），旅客可以在不同城市间中转，但必须满足中转时间至少 $30$ 分钟的限制，且最终必须在最晚到达时间前抵达目的地。

### 关键难点

1. **时间限制**：航班有具体的起飞和到达时间，旅客必须按照时间顺序旅行。
2. **中转时间限制**：两次航班之间必须至少有 $30$ 分钟的间隔。
3. **多城市多航班**：最多有 $150$ 个城市和 $5000$ 个航班，需要高效算法。

### 解题思路

#### 1. 问题转化

将每个航班视为一个节点，而不是将城市和时间点作为节点。这样可以将问题转化为标准的**最大流问题**。

- 每个航班节点拆分为两个节点：**入点**和**出点**，中间用容量为航班座位数的边连接。
- 如果旅客可以从航班 $i$ 中转至航班 $j$ ，则从航班 $i$ 的出点连接到航班 $j$ 的入点，容量为无穷大。
- 中转条件：
  1. 航班 $i$ 的到达城市等于航班 $j$ 的起飞城市。
  2. 航班 $j$ 的起飞时间 $\geq$ 航班 $i$ 的到达时间 $+ 30$ 分钟。

#### 2. 建图模型

- **源点** $\rightarrow$ 所有从出发城市起飞的航班的入点，容量无穷大。
- 每个航班的入点 $\rightarrow$ 出点，容量为该航班的座位数。
- 航班 $i$ 的出点 $\rightarrow$ 航班 $j$ 的入点（如果满足中转条件），容量无穷大。
- 所有到达目的地城市且到达时间 $\leq$ 最晚到达时间的航班的出点 $\rightarrow$ **汇点**，容量无穷大。

这样，旅客的流动路径为：  
源点 $\rightarrow$ 航班 $1$ 入点 $\rightarrow$ 航班 $1$ 出点 $\rightarrow$ 航班 $2$ 入点 $\rightarrow$ 航班 $2$ 出点 $\rightarrow$ … $\rightarrow$ 汇点

#### 3. 时间处理

- 将 $\texttt{HHMM}$ 格式的时间转换为从午夜开始的分钟数，便于比较和计算。
- 注意：输入的时间可能是以 $0$ 开头的整数（如 $\texttt{0930}$ ），在 $\texttt{C++}$ 中直接读取整数会将其解释为八进制数，导致错误。因此应将时间作为字符串读取，再转换为分钟数。

#### 4. 算法选择

- 由于航班数 $N \leq 5000$ ，每个航班拆分为两个节点，节点总数约为 $2N + 2 \leq 10002$ 。
- 中转边最多有 $N^2$ 条，在最坏情况下约为 $25 \times 10^6$ 条，但实际可中转的航班对远少于这个数。
- 使用 **$\texttt{Dinic}$ 算法**求解最大流，其时间复杂度为 $O(E \sqrt{V})$ 或 $O(V^2 E)$ ，在本题数据范围内可以接受。

#### 5. 注意事项

- 多个测试用例之间可能有空行分隔，也可能没有（根据实际输入）。代码应能处理这两种情况。
- 城市名称区分大小写，应使用字符串直接比较。
- 所有航班都在同一天内，无需处理跨天情况。

---

## 算法步骤

1. 读取城市数量，如果读取失败则结束。
2. 读取出发城市、目的地城市、最晚到达时间（字符串形式）。
3. 读取航班数量 $N$ 。
4. 读取每个航班的信息，将时间从 $\texttt{HHMM}$ 格式转换为分钟数。
5. 建图：
   - 创建源点 $s$ 和汇点 $t$ 。
   - 为每个航班创建两个节点：入点 $i$ 和出点 $i+N$ 。
   - 连接 $i \rightarrow i+N$ ，容量为航班座位数。
   - 对于所有满足中转条件的航班对 $(i, j)$ ，连接 $i+N \rightarrow j$ ，容量为无穷大。
   - 连接 $s \rightarrow i$ （如果航班 $i$ 从出发城市起飞），容量为无穷大。
   - 连接 $i+N \rightarrow t$ （如果航班 $i$ 到达目的地城市且到达时间 $\leq$ 最晚到达时间），容量为无穷大。
6. 运行 $\texttt{Dinic}$ 最大流算法。
7. 输出最大流值，即最多能到达的人数。
8. 重复处理下一个测试用例。

---

## 时间复杂度

- 建图： $O(N^2)$ ，但可通过优化减少（例如按城市和时间排序）。
- $\texttt{Dinic}$ 算法： $O(E \sqrt{V})$ 或 $O(V^2 E)$ ，其中 $V \leq 10002$ ， $E \leq N + N^2 + 2N \approx N^2$ 。
- 在 $N=5000$ 的最坏情况下， $E$ 可能达到 $25 \times 10^6$ ， $\texttt{Dinic}$ 算法可能较慢，但实际数据通常远小于最坏情况。

```cpp
// Objective: Berlin

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net


#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

int timeToMinutes(string t) {
    int h = stoi(t.substr(0, 2));
    int m = stoi(t.substr(2, 2));
    return h * 60 + m;
}

struct Edge {
    int to, cap, rev;
    Edge(int t, int c, int r) : to(t), cap(c), rev(r) {}
};

class Dinic {
private:
    vector<vector<Edge>> graph;
    vector<int> level, iter;
public:
    Dinic(int n) {
        graph.resize(n);
    }
    void addEdge(int from, int to, int cap) {
        graph[from].emplace_back(to, cap, graph[to].size());
        graph[to].emplace_back(from, 0, graph[from].size() - 1);
    }
    void bfs(int s) {
        level.assign(graph.size(), -1);
        queue<int> q;
        level[s] = 0;
        q.push(s);
        while (!q.empty()) {
            int v = q.front(); q.pop();
            for (auto &e : graph[v]) {
                if (e.cap > 0 && level[e.to] < 0) {
                    level[e.to] = level[v] + 1;
                    q.push(e.to);
                }
            }
        }
    }
    int dfs(int v, int t, int f) {
        if (v == t) return f;
        for (int &i = iter[v]; i < graph[v].size(); ++i) {
            Edge &e = graph[v][i];
            if (e.cap > 0 && level[v] < level[e.to]) {
                int d = dfs(e.to, t, min(f, e.cap));
                if (d > 0) {
                    e.cap -= d;
                    graph[e.to][e.rev].cap += d;
                    return d;
                }
            }
        }
        return 0;
    }
    int maxFlow(int s, int t) {
        int flow = 0;
        while (true) {
            bfs(s);
            if (level[t] < 0) return flow;
            iter.assign(graph.size(), 0);
            int f;
            while ((f = dfs(s, t, INF)) > 0) {
                flow += f;
            }
        }
    }
};

struct Flight {
    string from, to;
    int cap, dep, arr;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int cityCount;
    while (cin >> cityCount) {
        string startCity, endCity, latestTimeStr;
        cin >> startCity >> endCity >> latestTimeStr;
        int latestMinutes = timeToMinutes(latestTimeStr);

        int flightCount;
        cin >> flightCount;

        vector<Flight> flights(flightCount);
        for (int i = 0; i < flightCount; ++i) {
            string depStr, arrStr;
            cin >> flights[i].from >> flights[i].to >> flights[i].cap 
                >> depStr >> arrStr;
            flights[i].dep = timeToMinutes(depStr);
            flights[i].arr = timeToMinutes(arrStr);
        }

        // 创建图：每个航班拆分为两个节点（入点和出点）
        // 节点0..flightCount-1: 航班入点
        // 节点flightCount..2*flightCount-1: 航班出点
        int source = 2 * flightCount;
        int sink = 2 * flightCount + 1;
        Dinic dinic(2 * flightCount + 2);

        // 连接航班的入点到出点，容量为座位数
        for (int i = 0; i < flightCount; ++i) {
            dinic.addEdge(i, flightCount + i, flights[i].cap);
        }

        // 连接可以中转的航班：航班i的到达 -> 航班j的起飞
        // 如果：1) i.to == j.from, 2) j.dep >= i.arr + 30
        for (int i = 0; i < flightCount; ++i) {
            for (int j = 0; j < flightCount; ++j) {
                if (i == j) continue;
                if (flights[i].to == flights[j].from && 
                    flights[j].dep >= flights[i].arr + 30) {
                    dinic.addEdge(flightCount + i, j, INF);
                }
            }
        }

        // 源点连接到所有从出发城市起飞的航班
        for (int i = 0; i < flightCount; ++i) {
            if (flights[i].from == startCity) {
                dinic.addEdge(source, i, INF);
            }
        }

        // 所有到达目的地城市且时间≤最晚到达时间的航班连接到汇点
        for (int i = 0; i < flightCount; ++i) {
            if (flights[i].to == endCity && flights[i].arr <= latestMinutes) {
                dinic.addEdge(flightCount + i, sink, INF);
            }
        }

        int maxPeople = dinic.maxFlow(source, sink);
        cout << maxPeople << endl;
    }

    return 0;
}
```

## 总结

本题通过巧妙的图建模，将带有时间约束的航班中转问题转化为标准的最大流问题。每个航班作为节点，通过拆点处理容量限制，通过连接边处理中转时间限制。使用 $\texttt{Dinic}$ 算法求解最大流，即可得到最多能到达目的地的人数。注意时间格式的处理和多个测试用例的输入格式，是本题实现的关键细节。
