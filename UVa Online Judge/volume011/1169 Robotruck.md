
> **摘要**：本题要求按顺序投递 $N$ 个带坐标与重量的包裹，运输车载重上限为 $C$，每次只能装载一段连续包裹并往返邮局，求最小总移动距离。由于投递顺序固定，方案等价于把包裹序列划分为若干重量和不超过 $C$ 的连续区间。设 $\textit{dp}[i]$ 为送完前 $i$ 个包裹的最小总距离，利用重量前缀和与曼哈顿距离前缀和可将转移拆分为仅与终点有关的部分和仅与分界位置有关的 $G(j)$。由于包裹重量为正，合法分界位置单调右移，配合单调队列维护最小 $G$ 值，可在 $O(N)$ 时间、$O(N)$ 空间内完成求解。

 # 题目描述

工厂中有一辆负责投递包裹的机器人运输车，邮局位于坐标原点 $(0,0)$。包裹按照固定顺序从传送带到达，每个包裹都有指定的投递位置和重量。运输车的最大载重为 $C$，每次装载的包裹总重量不能超过 $C$。运输车能够在装入一段连续包裹后出发，按照包裹到达的顺序完成投递，再返回邮局继续装载，直到所有包裹全部送达。

运输车每次只能沿水平方向或竖直方向移动一个单位，因此两个位置之间的最短距离为曼哈顿距离。一次运输的总距离包括从邮局前往首个包裹投递位置的距离、依次经过各个投递位置的距离，以及从最后一个投递位置返回邮局的距离。求送完所有包裹所需的最小总移动距离。

# 输入格式

输入包含多组测试数据，第一行为测试数据组数 $T$。每组数据之前有一个空行。

每组数据首先输入一个正整数 $C$，表示运输车的最大载重，满足 $C \le 100$；随后输入一个正整数 $N$，表示包裹数量，满足 $N \le 100000$。接下来输入 $N$ 行，每行包含三个整数 $x_i$、$y_i$、$w_i$，分别表示第 $i$ 个包裹的投递坐标和重量，其中 $x_i,y_i \ge 0$，且 $0<w_i<C$。输入顺序就是包裹到达传送带的顺序。

# 输出格式

对于每组测试数据，输出一行整数，表示完成全部投递所需的最小总移动距离。相邻两组测试数据的输出之间保留一个空行。

# 样例输入

```text
1

10
4
1 2 3
1 0 3
3 1 4
3 1 4
```

# 样例输出

```text
14
```

# 题目分析

包裹必须按照输入顺序投递，因此每次运输处理的包裹必然构成原序列中的一个连续区间。整个运输方案等价于把包裹序列划分成若干个连续区间，使每个区间的重量总和不超过 $C$，并使所有区间各自往返邮局的距离之和最小。不同运输之间通过返回邮局衔接，因此确定最后一次运输的起点后，前面的包裹能够独立采用最优方案，这正是动态规划所需的最优子结构。

设第 $i$ 个投递位置为 $P_i=(x_i,y_i)$，并令 $P_0=(0,0)$。用 $d(P_a,P_b)$ 表示两个位置之间的曼哈顿距离：
$$
d(P_a,P_b)=|x_a-x_b|+|y_a-y_b|
$$
由于所有坐标均非负，第 $i$ 个投递位置到邮局的距离为 $d_2[i]=x_i+y_i$。再定义重量前缀和 $\textit{sw}[i]$ 与相邻位置距离前缀和 $\textit{sd}_1[i]$：
$$
\textit{sw}[0]=0,\qquad
\textit{sw}[i]=\sum_{k=1}^{i}w_k
$$
$$
\textit{sd}_1[0]=0,\qquad
\textit{sd}_1[i]=\sum_{k=1}^{i}d(P_{k-1},P_k)
$$
这里的 $\textit{sd}_1[i]$ 包含从邮局到首个投递位置的距离。对于一次运输负责的区间 $[j+1,i]$，其总重量为 $\textit{sw}[i]-\textit{sw}[j]$，而区间内部从 $P_{j+1}$ 依次移动到 $P_i$ 的距离为 $\textit{sd}_1[i]-\textit{sd}_1[j+1]$。因此，这次运输的总距离为：
$$
d_2[j+1]+\textit{sd}_1[i]-\textit{sd}_1[j+1]+d_2[i]
$$
当区间只有一个包裹时，内部移动距离为 $0$，上述表达式仍然成立。

定义 $\textit{dp}[i]$ 为按顺序送完前 $i$ 个包裹并返回邮局的最小总距离，初始状态为 $\textit{dp}[0]=0$。枚举最后一次运输之前已经送完的包裹数量 $j$，得到状态转移：

$$
\textit{dp}[i]=
\min_{\substack{0\le j<i\\
\textit{sw}[i]-\textit{sw}[j]\le C}}
\left(
\textit{dp}[j]+d_2[j+1]
+\textit{sd}_1[i]-\textit{sd}_1[j+1]+d_2[i]
\right)
$$

直接对每个状态枚举所有分界位置，形成二次规模的枚举过程。进一步观察转移式，所有只与当前终点 $i$ 有关的部分都能提出最小值之外。定义候选分界位置的代价：

$$
G(j)=\textit{dp}[j]+d_2[j+1]-\textit{sd}_1[j+1]
$$

则转移化为：

$$
\textit{dp}[i]=
\textit{sd}_1[i]+d_2[i]+
\min_{\substack{0\le j<i\\
\textit{sw}[i]-\textit{sw}[j]\le C}}G(j)
$$

问题由此转化为：随着 $i$ 递增，在满足载重限制的候选分界位置中维护最小的 $G(j)$。由于包裹重量均为正数，重量前缀和严格递增，合法分界位置的左端点只会向右移动，因此能够使用单调队列维护这一最小值。

# 解题思路

首先顺序读取包裹，预处理重量前缀和 $\textit{sw}$、相邻位置距离前缀和 $\textit{sd}_1$，以及各位置到邮局的距离 $d_2$。随后使用双端队列保存候选分界位置，使队列中的下标严格递增，同时对应的 $G$ 值严格递增。初始时只有分界位置 $0$，表示尚未投递任何包裹，因此将其加入队列。

计算 $\textit{dp}[i]$ 时，先检查队首分界位置是否满足载重限制。如果 $\textit{sw}[i]-\textit{sw}[j]>C$，则从队首删除该位置，并继续检查新的队首。队列下标递增，重量前缀和也严格递增，因此所有超载候选都集中在队列前部。并且随着后续包裹加入，$\textit{sw}[i]$ 继续增大，已经超载的分界位置永远不会重新合法，删除这些位置不会影响之后的答案。完成删除后，队首就是当前合法候选中 $G$ 值最小的位置，直接利用它计算：
$$
\textit{dp}[i]=
G(\textit{dq.front()})+\textit{sd}_1[i]+d_2[i]
$$

得到 $\textit{dp}[i]$ 后，分界位置 $i$ 就能作为后续运输的候选。若队尾已有候选位置 $j$ 满足 $G(j)\ge G(i)$，则删除 $j$。这一删除具有明确的支配关系：由于 $j<i$ 且所有重量为正，有 $\textit{sw}[j]<\textit{sw}[i]$，对于任何未来终点 $k>i$，均满足：
$$
\textit{sw}[k]-\textit{sw}[i]
<
\textit{sw}[k]-\textit{sw}[j]
$$
因此，只要较早的分界位置 $j$ 满足载重限制，较新的分界位置 $i$ 就同样满足载重限制；同时 $G(i)\le G(j)$，使用 $i$ 得到的转移代价也不大于使用 $j$ 的代价。较早位置 $j$ 不再具有保留价值。不断删除满足条件的队尾后，再把 $i$ 加入队尾，即可恢复队列中 $G$ 值严格递增的性质。

上述维护过程保证了动态规划转移的正确性：所有因超载而删除的候选在未来始终不合法；所有因队尾比较而删除的候选都被更新、代价不大的候选支配；其余候选中，队首具有最小的 $G$ 值。因此，每次计算都取得合法转移中的最小值，结合初始状态 $\textit{dp}[0]=0$，最终得到的 $\textit{dp}[N]$ 就是全部包裹的最小投递距离。由于每个包裹的重量都小于 $C$，单独运输任意一个包裹都满足容量限制，所以每个状态始终存在合法转移。

实现中只在 $i<N$ 时执行插入前的队尾比较，因为 $G(i)$ 需要访问下一个投递位置的信息。处理完最后一个包裹后，已不存在后续转移，因此无需计算 $G(N)$；代码随后将 $N$ 放入队列，也不会再访问该候选的代价。多组数据通过格式化输入读取，输入中的空行会自动跳过。

样例中，将前 $2$ 个包裹安排在一次运输中，后 $2$ 个包裹安排在另一次运输中，两次载重分别为 $6$ 和 $8$，均不超过 $10$。对应的运输距离分别为 $3+2+1=6$ 和 $4+0+4=8$，最小总距离为 $14$。

每个候选分界位置只入队一次，并且最多被删除一次，因此队列维护的总时间为 $O(N)$，预处理也只需 $O(N)$ 时间。每组数据的时间复杂度为 $O(N)$，空间复杂度为 $O(N)$，用于保存动态规划数组、前缀信息和候选队列。

# 代码实现

```cpp
// Robotruck
// UVa ID: 1169
// Verdict: Accepted
// Submission Date: 2019-07-25
// UVa Run Time: 0.030s
//
// 版权所有（C）2019，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 100010;

int dp[MAXN], sw[MAXN], sd1[MAXN], d2[MAXN];

int G(int j) { return dp[j] + d2[j + 1] - sd1[j + 1]; }

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int cases, C, N;
    dp[0] = 0, sw[0] = 0, sd1[0] = 0, d2[0] = 0;
    cin >> cases;
    for (int cs = 1; cs <= cases; cs++) {
        cin >> C >> N;
        int xx = 0, yy  = 0, x, y, w;
        for (int i = 1; i <= N; i++) {
            cin >> x >> y >> w;
            sw[i] = sw[i - 1] + w;
            sd1[i] = sd1[i - 1] + abs(x - xx) + abs(y - yy);
            d2[i] = x + y;
            xx = x, yy = y;
        }
        deque<int> dq;
        dq.push_front(0);
        for (int i = 1; i <= N; i++) {
            while (!dq.empty() && sw[i] - sw[dq.front()] > C) dq.pop_front();
            dp[i] = G(dq.front()) + sd1[i] + d2[i];
            if (i < N) while (!dq.empty() && G(dq.back()) >= G(i)) dq.pop_back();
            dq.push_back(i);
        }
        if (cs > 1) cout << '\n';
        cout << dp[N] << '\n';
    }
    return 0;
}
```

# 总结

本题的关键是把按顺序投递转化为连续区间划分，再利用前缀和快速计算一次运输的重量与距离。将动态规划转移拆成仅与终点有关的部分和仅与分界位置有关的 $G$ 值后，正重量带来的合法区间单调性与候选之间的支配关系共同支持单调队列优化。队首删除永久超载的候选，队尾删除被更新候选支配的位置，从而以 $O(N)$ 时间和 $O(N)$ 空间求出最优答案。
