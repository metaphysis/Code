
> **摘要**：本文讨论如何在一个连通无向带权图中，以最小总费用连接全部城市，即求解最小生成树问题。文章将城市与链路抽象为顶点与边，说明正权条件下最优方案不含环，并采用 $\texttt{Kruskal}$ 算法按边权从小到大选边、用并查集判断连通分量，同时给出城市名称到整数编号的映射方法、正确性证明与复杂度分析。

 # 题目描述

一个欧洲互联网服务提供商联盟管理着连接多个城市的骨干网络。城市之间的直接链路是双向的，每条链路都有一个传输费用，并且原网络保证任意两个城市之间都能通过若干条链路相互到达。

为了向所有城市广播电视节目，需要从现有链路中选出一部分，使选出的链路连接全部城市，同时使这些链路的费用总和最小。给定城市之间的链路及其费用，求满足要求的最小总费用。

# 输入格式

输入包含多组测试数据，第一行是测试数据组数 $T$。每组测试数据前有一个空行。

每组测试数据的第一行包含一个正整数 $M$，表示城市数量，满足 $1 \le M \le 2000$；第二行包含一个整数 $N$，表示现有链路数量，满足 $0 \le N \le 50000$。接下来的 $N$ 行，每行包含两个城市名称 $B$、$E$ 和一个整数 $C$，表示城市 $B$ 与城市 $E$ 之间存在一条费用为 $C$ 的双向链路。城市名称的长度不超过 $8$ 个字符，费用满足 $1 \le C \le 30$。

题目保证原网络连通。

# 输出格式

对于每组测试数据，输出一行整数，表示连接所有城市所需的最小总费用。

相邻两组测试数据的输出之间保留一个空行。

# 样例输入

```text
1

4
5
lisbon london 6
lisbon paris 5
london paris 1
london berlin 2
paris berlin 10
```

# 样例输出

```text
8
```

# 题目分析

将每座城市视为一个顶点，将每条双向链路视为一条无向边，链路费用作为边权，题目就转化为：在一个连通无向带权图中，选取一些边，使全部 $M$ 个顶点连通，并使所选边的权值总和最小。这里的费用是所选链路的费用之和，不是从某个起点到各个城市的最短距离之和，因此需要求解最小生成树。

由于所有边权都是正数，最优方案中不会包含环。若选出的连通子图存在环，删除环上的任意一条边后，环上各顶点仍能通过剩余边相互到达，整个子图仍然连通，而总费用严格减小，这与原方案最优矛盾。因此，最优方案必然是一棵覆盖所有顶点的树，包含 $M-1$ 条边。当 $M=1$ 时，不需要选取任何链路，答案为 $0$。

本题适合使用 $\texttt{Kruskal}$ 算法：按照边权从小到大考虑各条边，只接纳连接两个不同连通分量的边。这样既优先使用费用较低的链路，又保证所选边始终不形成环。判断两个端点是否已经连通，需要维护不断合并的连通分量，并查集能够直接完成这一任务。城市名称采用字符串表示，还需要先将不同名称映射为连续整数编号，便于存储边和维护并查集。

样例中，依次选择 $\texttt{london}$ 与 $\texttt{paris}$ 之间费用为 $1$ 的链路、$\texttt{london}$ 与 $\texttt{berlin}$ 之间费用为 $2$ 的链路，以及 $\texttt{lisbon}$ 与 $\texttt{paris}$ 之间费用为 $5$ 的链路，即可连接全部 $4$ 座城市，总费用为 $1+2+5=8$。

# 解题思路

读入每组数据时，首先清空城市名称与编号之间的映射。每当遇到尚未出现的城市名称，就为其分配一个新的整数编号，编号从 $0$ 开始递增。随后将每条链路保存为由两个端点编号和费用组成的边。代码使用 $\texttt{map}$ 维护这一映射，城市名称长度不超过 $8$，字符串比较的开销具有固定上界。输入使用格式化提取操作，空格和空行都会被自动跳过，因此无需单独处理测试数据前的空行。

初始化并查集时，让每个顶点单独构成一个集合，并将各集合的秩设为 $0$。查询操作采用路径压缩，将查询路径上的顶点直接连接到集合代表；合并操作采用按秩合并，将秩较小的树连接到秩较大的树上，只有两棵树的秩相等时，合并后根节点的秩才增加。这两项优化使连续的查询与合并操作具有很低的均摊开销。

将全部边按照费用从小到大排序，并将答案初始化为 $0$。随后依次检查每条边：若两个端点属于同一个集合，说明当前已经存在连接它们的路径，加入这条边会形成环，因此跳过；若两个端点属于不同集合，就选择这条边，将其费用加入答案，并合并两个集合。给定代码会扫描全部 $N$ 条边；在生成树已经形成后，其余边的两个端点均属于同一集合，因此不会继续增加费用。原图保证连通，所以扫描结束后，所选边一定连接全部城市。

这一贪心过程的正确性由割性质保证。设当前已选边集为 $F$，并且存在一棵最小生成树包含 $F$。初始时 $F$ 为空，这一条件成立。考虑下一条被接纳的边 $e$，其两个端点位于不同的当前连通分量中。取其中一个连通分量的顶点集为 $S$，边 $e$ 跨越割 $(S,V\setminus S)$。由于边按照权值非递减的顺序处理，任何权值严格小于 $e$ 的边都已经被检查过；若其中有边跨越当前的这个割，它在被检查时的两个端点也必然属于不同分量，从而早已被接纳并使两个端点在当前连通，这与它跨越当前割矛盾。因此，$e$ 是跨越该割的最小权边之一。

取一棵包含 $F$ 的最小生成树。如果它已经包含 $e$，则接纳 $e$ 后上述条件继续成立；否则，将 $e$ 加入这棵树会形成一个环，环中必然还存在另一条跨越同一割的边 $f$。由于 $w(e)\le w(f)$，删除 $f$ 并保留 $e$ 后，总权值不会增加，所得生成树仍然最优。同时，$F$ 中的边都位于当前各连通分量内部，边 $f$ 不属于 $F$，因此新的最小生成树包含 $F\cup\{e\}$。由此，每次接纳边都保持正确性。最终所选边构成生成树，并且包含于一棵最小生成树中，所以它本身就是最小生成树。

复杂度方面，城市名称映射需要 $O(N\log(M+1))$ 时间，边排序需要 $O(N\log(N+1))$ 时间，并查集初始化需要 $O(M)$ 时间，扫描全部边的并查集操作需要 $O(N\alpha(M))$ 的均摊时间，其中 $\alpha$ 为反阿克曼函数。因此，总时间复杂度为 $O(M+N\log(M+1)+N\log(N+1))$。边数组、城市名称映射和并查集共需要 $O(M+N)$ 的空间；给定实现通过固定容量数组预留边和顶点的存储位置。

```cpp
#include <bits/stdc++.h>

using namespace std;

const int MAXV = 2010;

struct edge
{
    int from, to, cost;
    edge (int from = 0, int to = 0, int cost = 0): from(from), to(to), cost(cost) {}
    bool operator<(const edge& x) const {
        return cost < x.cost;
    }
};

edge edges[50010];
int parent[MAXV], ranks[MAXV];
int numberOfVertices, numberOfEdges;
map<string, int> indexer;

void makeSet()
{
    for (int i = 0; i < numberOfVertices; i++) {
        parent[i] = i; ranks[i] = 0;
    }
}

int findSet(int x)
{
    return (parent[x] == x ? x : parent[x] = findSet(parent[x]));
}

void unionSet(int x, int y)
{
    x = findSet(x), y = findSet(y);
    if (x != y) {
        if (ranks[x] > ranks[y]) parent[y] = x;
        else {
            parent[x] = y;
            if (ranks[x] == ranks[y]) ranks[y]++;
        }
    }
}

int kruskal()
{
    int minWeightSum = 0;
    makeSet();
    sort(edges, edges + numberOfEdges);
    for (int i = 0; i < numberOfEdges; i++) {
        int x = findSet(edges[i].from), y = findSet(edges[i].to);
        if (x != y) {
            unionSet(x, y);
            minWeightSum += edges[i].cost;
        }
    }
    return minWeightSum;
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int cases;
    cin >> cases;
    while (cases--)
    {
        cin >> numberOfVertices >> numberOfEdges;
        int cost, cnt = 0;
        string from, to;
        indexer.clear();
        for (int i = 0; i < numberOfEdges; i++)
        {
            cin >> from >> to >> cost;
            if (indexer.find(from) == indexer.end()) indexer[from] = cnt++;
            if (indexer.find(to) == indexer.end()) indexer[to] = cnt++;
            edges[i] = edge(indexer[from], indexer[to], cost);
        }
        cout << kruskal() << '\n';
        if (cases) cout << '\n';
    }
    return 0;
}
```

# 总结

本题的关键是将“以最小总费用连接全部城市”转化为最小生成树问题。正权条件保证最优方案不含环，$\texttt{Kruskal}$ 算法通过按边权排序和跨连通分量选边构造最优解，并查集负责高效判断连通关系。实现时还需完成字符串城市名称到整数编号的映射，并在相邻测试数据的输出之间保留一个空行。
