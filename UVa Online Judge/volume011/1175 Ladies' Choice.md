
> **摘要**：本题要求在男女双方各自给出严格偏好顺序的前提下，为 $N$ 名女生与 $N$ 名男生构造一个稳定匹配，并满足女士优先原则，使每名女生都获得她在所有稳定匹配中能够得到的最喜欢的舞伴。文章将“不存在双方都愿意更换舞伴的组合”转化为稳定匹配条件，采用女生主动邀请的 $\texttt{Gale-Shapley}$ 算法求解，通过排名表把偏好比较降为 $O(1)$，用邀请位置记录避免重复尝试，用队列维护待邀请女生，最终在 $O(N^2)$ 时间与 $O(N^2)$ 空间内完成每组数据，并给出稳定性与女生最优性的完整证明及通过代码。

 # 题目描述

学校准备为毕业舞会安排舞伴，共有 $N$ 名女生和 $N$ 名男生。每名女生都会按照自己的喜好，对所有男生给出一个严格的偏好顺序；每名男生也会按照自己的喜好，对所有女生给出一个严格的偏好顺序。

需要为每名女生安排一名男生，使所有人恰好组成 $N$ 对舞伴，并且不存在这样一对尚未配对的男女：女生更喜欢这名男生而不是自己的舞伴，同时男生也更喜欢这名女生而不是自己的舞伴。满足这一条件的配对称为稳定匹配。由于舞会采用女士优先的原则，要求在所有稳定匹配中，让每名女生都获得自己能够得到的最喜欢的舞伴。

# 输入格式

第一行包含一个整数 $T$，表示测试数据组数。每组数据之前有一个空行。

每组数据的第一行包含一个正整数 $N$，满足 $1 \le N \le 1000$，表示女生和男生各有 $N$ 人，双方分别按照 $1$ 到 $N$ 编号。

接下来 $N$ 行描述女生的偏好。第 $i$ 行包含 $1$ 到 $N$ 的一个排列，按照喜欢程度从高到低给出女生 $i$ 对所有男生的排序。

再接下来 $N$ 行描述男生的偏好。第 $i$ 行包含 $1$ 到 $N$ 的一个排列，按照喜欢程度从高到低给出男生 $i$ 对所有女生的排序。

# 输出格式

对于每组数据，输出 $N$ 行，第 $i$ 行输出分配给女生 $i$ 的男生编号。

相邻两组数据的输出之间用一个空行分隔。

# 样例输入

```text
3 2 4 1 5
```


# 题目分析

题目的核心约束是稳定性。设女生 $w$ 当前的舞伴为男生 $m$，男生 $m'$ 当前的舞伴为女生 $w'$。如果女生 $w$ 更喜欢男生 $m'$，同时男生 $m'$ 也更喜欢女生 $w$，那么女生 $w$ 与男生 $m'$ 就构成一对阻塞对，当前匹配因此不稳定。题目要求消除所有阻塞对，并且在所有稳定匹配中实现女生最优。这里的女生最优具有逐人最优的含义：对于每名女生，她在最终结果中的舞伴，都是她在所有稳定匹配中能够获得的最喜欢的男生。

这一问题使用由女生主动发起邀请的 $\texttt{Gale-Shapley}$ 稳定婚姻算法解决。每名尚未配对的女生按照自己的偏好顺序依次邀请男生；每名男生始终保留截至当前收到的邀请中自己最喜欢的女生。男生收到更喜欢的女生的邀请时，会解除原有的临时配对，原来的女生继续邀请自己尚未邀请过的男生。所有配对在算法结束前都属于临时配对，男生保留对象的偏好只会变好，女生邀请对象的偏好则按照自己的列表逐渐降低。

为了高效判断男生是否接受新邀请，需要将男生的偏好列表转换为排名表。设 $\textit{mPrefer}[m][w]$ 表示女生 $w$ 在男生 $m$ 的偏好列表中的位置，排名越小表示越喜欢。于是，比较两名女生只需比较她们的排名，单次判断的时间复杂度为 $O(1)$。女生一侧只需保存按偏好排序的男生列表，以及已经邀请到的位置，从而保证每一对男女之间至多发生一次邀请。

# 解题思路

首先读取双方的偏好列表，并建立排名表。数组 $\textit{wList}[w][j]$ 表示女生 $w$ 第 $j$ 喜欢的男生，数组 $\textit{mPrefer}[m][w]$ 表示男生 $m$ 对女生 $w$ 的偏好排名。通过队列维护当前需要继续邀请的女生，初始时所有女生均未配对，因此全部入队。数组 $\textit{wLast}[w]$ 记录女生 $w$ 已经邀请到的位置，数组 $\textit{mMatched}[m]$ 记录男生 $m$ 当前保留的女生，取值为 $0$ 表示尚未配对。

每次取出一名女生，从她尚未邀请过的最喜欢的男生开始尝试。如果该男生尚未配对，就建立临时配对；如果该男生已经配对，但更喜欢当前发出邀请的女生，就将原来的女生重新加入队列，再建立新的临时配对；如果该男生更喜欢原来的女生，就拒绝当前邀请，当前女生继续尝试偏好列表中的下一名男生。当前女生获得临时舞伴后，本轮处理结束。数组 $\textit{in}$ 记录女生是否已经在队列中，避免重复入队。

算法一定结束，并且结束时所有人都已配对。每名女生都严格按照偏好列表向后推进，不会重复邀请同一名男生，因此邀请总数不超过 $N^2$。同时，男生一旦收到邀请，就会始终保留一名女生，之后只会更换对象，不会重新变为未配对状态。如果一名尚未配对的女生已经邀请过所有男生，那么所有男生都已经收到过邀请，并且当前都保留着一名女生，这意味着全部 $N$ 名女生都已配对，与该女生尚未配对矛盾。因此，未配对的女生始终还有能够继续邀请的对象，队列最终清空时形成完整匹配。

最终匹配满足稳定性。设女生 $w$ 比起最终舞伴更喜欢男生 $m$。由于女生按偏好顺序邀请，女生 $w$ 在获得最终舞伴之前一定邀请过男生 $m$，并且曾被男生 $m$ 拒绝，或者在临时配对后被替换。发生拒绝或替换时，男生 $m$ 已经保留了比女生 $w$ 更喜欢的对象；此后男生保留对象的偏好只会变好，因此男生 $m$ 一定更喜欢最终舞伴而不是女生 $w$。所以，任何女生更喜欢的其他男生都不会同时更喜欢她，最终匹配不存在阻塞对。

女生最优性来自拒绝操作的性质：一旦男生拒绝某名女生，这两个人就不会在任何稳定匹配中成为舞伴。用反证法证明这一性质。假设存在某次拒绝，使被拒绝的女生 $w$ 与拒绝她的男生 $m$ 仍能在某个稳定匹配 $S$ 中配对，并选择整个执行过程中最早出现的这种拒绝。男生 $m$ 当时保留另一名女生 $w'$，且更喜欢 $w'$。设女生 $w'$ 在匹配 $S$ 中的舞伴为 $m'$。如果女生 $w'$ 更喜欢 $m'$ 而不是 $m$，那么她在邀请 $m$ 之前就已经邀请过 $m'$，并且被 $m'$ 拒绝，这就出现了更早的、拒绝稳定匹配中舞伴的操作，与选择矛盾。因此，女生 $w'$ 更喜欢 $m$ 而不是 $m'$，而男生 $m$ 更喜欢 $w'$ 而不是自己在匹配 $S$ 中的舞伴 $w$，于是 $w'$ 与 $m$ 构成匹配 $S$ 的阻塞对，再次矛盾。由此可知，每名女生最终舞伴之前的所有更优选择都不属于任何稳定匹配，因此最终结果对每名女生都是最优的。

读取和预处理偏好列表需要 $O(N^2)$ 时间，邀请总次数至多为 $N^2$，每次邀请只进行常数次比较与队列操作，因此每组数据的时间复杂度为 $O(N^2)$。偏好列表和排名表占用 $O(N^2)$ 空间，其余匹配数组与队列占用 $O(N)$ 空间，总空间复杂度为 $O(N^2)$。

```cpp
// Ladies' Choice
// UVa ID: 1175

// 版权所有（C）2019，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 1010;

int n;
int mList[MAXN][MAXN], wList[MAXN][MAXN];
int mPrefer[MAXN][MAXN], wPrefer[MAXN][MAXN];
int mLast[MAXN], wLast[MAXN];
int mMatched[MAXN], wMatched[MAXN];
int in[MAXN];

void galeShapley()
{
    for (int i = 1; i <= n; i++) wLast[i] = mMatched[i] = in[i] = 0;
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        q.push(i);
        in[i] = 1;
    }
    while (!q.empty()) {
        int w = q.front(); q.pop();
        in[w] = 0;
        for (wLast[w]++; wLast[w] <= n; wLast[w]++) {
            int m = wList[w][wLast[w]];
            if (!mMatched[m] || (mPrefer[m][w] < mPrefer[m][mMatched[m]])) {
                if (mMatched[m] && !in[mMatched[m]]) {
                    q.push(mMatched[m]);
                    in[mMatched[m]] = 1;
                }
                wMatched[w] = m;
                mMatched[m] = w;
                break;
            }
        }
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int cases;
    cin >> cases;
    for (int cs = 1; cs <= cases; cs++)
    {
        cin >> n;

        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
            {
                cin >> wList[i][j];
                wPrefer[i][wList[i][j]] = j;
            }
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
            {
                cin >> mList[i][j];
                mPrefer[i][mList[i][j]] = j;
            }
        galeShapley();
        if (cs > 1) cout << '\n';
        for (int i = 1; i <= n; i++)
            cout << wMatched[i] << '\n';
    }

    return 0;
}
```

# 总结

本题的关键是将“没有双方都愿意更换舞伴的男女组合”转化为稳定匹配条件，并通过女生主动邀请的 $\texttt{Gale-Shapley}$ 算法实现女生最优。实现时，用排名表将偏好比较降为 $O(1)$，用邀请位置记录避免重复尝试，用队列维护需要继续邀请的女生，从而在 $O(N^2)$ 时间和 $O(N^2)$ 空间内完成每组数据。理解男生保留对象的偏好单调改善，以及被拒绝的配对不属于任何稳定匹配，是证明稳定性与女生最优性的关键。
