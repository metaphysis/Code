
> **摘要**：本题围绕一个变形的约瑟夫环游戏展开：每轮先按步长 $2$ 报数确定幸存者，再让编号大于幸存者的玩家各获 $1$ 单位货币并永久退出；当某轮无人退出时，向剩余玩家每人支付 $2$ 单位货币并结束。由于剩余玩家编号始终连续，游戏状态可压缩为当前人数。文章给出 $O(M)$ 预处理幸存者下标、每组数据 $O(\log n)$ 逐轮累计的解法。

 # 题目描述

有 $n$ 名玩家围成一圈，编号依次为 $1$ 到 $n$。每轮游戏都从编号为 $1$ 的玩家开始报数，每隔一人暂时移除一人，即首先移除编号为 $2$ 的玩家，随后继续沿圆圈报数，直到只剩下一名幸存者。

确定本轮幸存者后，所有编号大于幸存者编号的玩家，每人获得 $1$ 单位货币，并永久退出游戏。其余玩家保留原编号，重新进行下一轮游戏。报数过程中的暂时移除只用于确定本轮幸存者，不影响玩家是否参与下一轮游戏。

当某一轮结束后没有玩家永久退出时，向当前所有玩家每人支付 $2$ 单位货币，游戏结束。求整个游戏需要支付的货币总额。

# 输入格式

输入包含多组测试数据，每组数据独占一行，包含一个整数 $n$，表示最初的玩家人数，满足 $1 \le n \le 32767$。

输入以文件结束符结束。

# 输出格式

对于每组测试数据，输出一行一个整数，表示需要支付的货币总额。题目保证答案不超过 $65535$。

# 样例输入

```text
5
10
7
```

# 样例输出

```text
8
13
14
```

# 题目分析

本题包含两个相互关联的过程：先通过约瑟夫环确定当前人数对应的幸存者，再根据幸存者的编号决定本轮永久退出的人数及支付金额。由于永久退出的始终是编号大于幸存者编号的玩家，剩余玩家的编号始终构成从 $1$ 开始的连续区间。因此，后续游戏的状态完全由当前人数决定，无需维护实际的圆圈，也无需记录每名玩家的状态。

设当前有 $m$ 名玩家，按题目中的编号方式得到的幸存者编号为 $s$。若 $s < m$，则编号从 $s+1$ 到 $m$ 的玩家永久退出，共有 $m-s$ 人，本轮支付金额为 $m-s$，下一轮人数变为 $s$。若 $s=m$，则没有玩家永久退出，游戏立即结束，并向当前的 $m$ 名玩家支付总计 $2m$ 的货币。因此，求出每种人数对应的幸存者后，整个支付过程就转化为人数不断缩小的状态转移。

以 $n=5$ 为例，首轮幸存者编号为 $3$，编号为 $4$ 和 $5$ 的玩家各获得 $1$ 单位货币并永久退出，本轮支付 $2$。剩余 $3$ 名玩家重新进行游戏，幸存者仍为编号 $3$ 的玩家，此轮人数不再减少，因此再支付 $2\times 3=6$，总支付金额为 $8$。

# 解题思路

首先预处理约瑟夫环的幸存者位置。为方便递推，采用从 $0$ 开始的下标，令 $\textit{survivor}[m]$ 表示有 $m$ 名玩家时最终幸存者的下标，其取值范围为 $0$ 到 $m-1$。只有一名玩家时，幸存者下标为 $0$，因此初始状态为：
$$
\textit{survivor}[1]=0
$$
当有 $m$ 名玩家时，首次移除的玩家下标为 $1$，接下来从原下标为 $2$ 的玩家继续报数。将剩余玩家从该位置开始重新编号，问题就缩小为人数为 $m-1$ 的同类问题。缩小后的幸存者下标加上 $2$，再对 $m$ 取模，即可恢复其在原圆圈中的下标。因此递推关系为：
$$
\textit{survivor}[m]=(\textit{survivor}[m-1]+2)\bmod m
$$
按照人数递增的顺序，预处理到最大人数 $M=32767$，即可在每轮游戏中直接查询幸存者下标。

接着处理每组输入。用 $n$ 表示当前人数，用 $\textit{cnt}$ 累计支付金额，初始时 $\textit{cnt}=0$。查询当前幸存者下标 $\textit{last}=\textit{survivor}[n]$，其对应的实际编号为 $\textit{last}+1$。当 $\textit{last}=n-1$ 时，幸存者就是当前编号最大的玩家，本轮没有玩家永久退出，因此将 $2n$ 加入答案并结束。否则，永久退出的人数为 $n-1-\textit{last}$，将这部分金额加入答案，并把当前人数更新为 $\textit{last}+1$，继续下一轮。

这一过程正确地维护了游戏状态：每轮开始时，参与者恰好是编号从 $1$ 到 $n$ 的玩家，且 $\textit{cnt}$ 等于此前已经支付的金额。预处理结果给出了本轮的准确幸存者，随后删除所有编号更大的玩家，更新后的参与者仍然构成连续编号区间，增加的金额也恰好等于本轮永久退出人数。当幸存者编号等于当前人数时，程序按照题意支付最后的 $2n$ 并结束。因此，最终输出就是整个游戏的总支付金额。

还可以从整体上验证金额统计。设游戏结束时剩余 $r$ 名玩家，则此前永久退出的玩家共有 $n_0-r$ 名，其中 $n_0$ 表示初始人数。这些玩家每人获得 $1$ 单位货币，最终留下的玩家每人获得 $2$ 单位货币，因此总金额满足：
$$
(n_0-r)+2r=n_0+r
$$
程序逐轮累加永久退出玩家的报酬，再加上最后剩余玩家的报酬，与上述总金额完全一致。

下面分析复杂度。步长为 $2$ 的约瑟夫环中，若当前人数写成 $n=2^k+t$，其中 $0\le t<2^k$，则采用从 $1$ 开始编号的幸存者编号为：
$$
s=2t+1
$$
在二进制表示中，这等价于把最高位的 $1$ 移到末尾，再去掉前导零。每次人数更新都执行这样的变换；当二进制表示全部为 $1$ 时，人数保持不变，游戏结束。在处理完初始二进制表示中的所有位之前，原有的零都会被移至前端并删除，因此轮数为 $O(\log n)$。预处理的时间复杂度为 $O(M)$，每组数据的处理时间复杂度为 $O(\log n)$；若共有 $T$ 组数据，总时间复杂度为 $O(M+T\log M)$。幸存者数组占用 $O(M)$ 空间，每组数据额外使用 $O(1)$ 空间，总空间复杂度为 $O(M)$。

```cpp

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int survivor[32800];
    survivor[1] = 0;
    for (int i = 2; i <= 32767; i++) survivor[i] = (survivor[i - 1] + 2) % i;
    int n;
    while (cin >> n)
    {
        int cnt = 0;
        while (true)
        {
            int last = survivor[n];
            if (last == n - 1)
            {
                cnt += 2 * n;
                break;
            }
            cnt += n - 1 - last;
            n = last + 1;
        }
        cout << cnt << '\n';
    }
    return 0;
}
```

# 总结

本题的关键是区分报数中的暂时移除与每轮结束后的永久退出，并利用剩余玩家编号始终连续的性质，将游戏状态压缩为当前人数。通过约瑟夫环递推预处理幸存者下标，再逐轮累计永久退出玩家的报酬，最后支付剩余玩家的报酬，即可得到答案。实现时需要统一下标含义：数组记录的是从 $0$ 开始的下标，实际幸存者编号需要加 $1$，永久退出人数则为当前人数减去实际幸存者编号。
