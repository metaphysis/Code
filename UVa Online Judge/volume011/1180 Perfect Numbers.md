
> **摘要**：本题要求判断由 $N = 2^{p-1}(2^p - 1)$ 生成的整数是否为完全数。利用偶完全数的结构定理，只需判断 $p$ 与 $2^p - 1$ 是否同时为质数；再结合 $2^{33}$ 的上界，可将有效指数压缩为集合 $\{2, 3, 5, 7, 13, 17\}$，从而以 $O(T)$ 总时间、$O(1)$ 额外空间完成全部判断。

 # 题目描述

完全数是指恰好等于其所有真因子之和的正整数，其中真因子是小于这个整数本身的正因子。例如，$6 = 1 + 2 + 3$，因此 $6$ 是完全数；$28 = 1 + 2 + 4 + 7 + 14$，因此 $28$ 也是完全数。

给定若干整数 $p$，判断由下式生成的整数是否为完全数：
$$
N = 2^{p-1}(2^p - 1)
$$
题目保证所涉及的完全数不超过 $2^{33}$。

# 输入格式

输入包含两行。第一行包含一个整数 $T$，表示需要判断的整数个数。第二行包含 $T$ 个整数 $p$，相邻整数之间使用英文逗号分隔。

# 输出格式

对于每个整数 $p$，单独输出一行。如果它生成的整数是完全数，输出 $\texttt{Yes}$；否则输出 $\texttt{No}$。

# 样例输入

```text
6
2,3,4,5,6,7
```

# 样例输出

```text
Yes
Yes
No
Yes
No
Yes
```

# 题目分析

直接按照完全数的定义求出 $N$ 的所有真因子并累加，会产生不必要的计算。本题生成整数的形式已经固定，因此应利用偶完全数的结构进行判断。欧几里得与欧拉的相关定理表明：一个正偶数是完全数，当且仅当它能够表示为 $2^{p-1}(2^p - 1)$，其中 $p$ 和 $2^p - 1$ 都是质数。因此，本题的核心是确定哪些指数 $p$ 满足这个条件。

仅判断 $p$ 是否为质数并不充分。例如，$11$ 是质数，但 $2^{11} - 1 = 2047 = 23 \times 89$，不是质数，所以它不能生成完全数。另一方面，$2^p - 1$ 为质数时，$p$ 必须为质数。对于合数指数 $p = ab$，其中 $a > 1$、$b > 1$，有：
$$
2^{ab} - 1 = (2^a - 1)\left(1 + 2^a + 2^{2a} + \cdots + 2^{(b-1)a}\right)
$$
右侧两个因子都大于 $1$，所以 $2^p - 1$ 为合数。这说明筛选质数指数，再检查对应的 $2^p - 1$，就能完整确定符合条件的指数。

题目给出的数值上界使符合条件的指数集合非常小。当 $p \ge 18$ 时，有：
$$
2^{p-1}(2^p - 1) \ge 2^{17}(2^{18} - 1) > 2^{33}
$$
因此，在题目允许的完全数范围内，只需考虑不超过 $17$ 的质数指数，即 $2$、$3$、$5$、$7$、$11$、$13$ 和 $17$。其中只有 $11$ 对应的 $2^p - 1$ 是合数，其余指数均满足要求。由此得到完整的有效指数集合：
$$
S = \{2, 3, 5, 7, 13, 17\}
$$

# 解题思路

先利用数学结论确定有效指数集合，再对每个输入进行常数次比较。各个候选质数指数对应的计算结果如下：

| 指数 $p$ | $2^p - 1$ | 是否为质数 |
| --- | --- | --- |
| $2$ | $3$ | 是 |
| $3$ | $7$ | 是 |
| $5$ | $31$ | 是 |
| $7$ | $127$ | 是 |
| $11$ | $2047 = 23 \times 89$ | 否 |
| $13$ | $8191$ | 是 |
| $17$ | $131071$ | 是 |

对于每个读入的 $p$，检查它是否属于集合 $S$。属于该集合时输出 $\texttt{Yes}$，否则输出 $\texttt{No}$。程序直接判断指数，无须计算生成的完全数，也无须在运行时进行质数判定。这样既减少了运算，也避免了存储较大完全数的需求。

输入中的整数使用逗号分隔，因此读完一个整数后，只要后面还有待处理的数据，就额外读取一个字符以消耗分隔逗号。最后一个整数后不再读取分隔符。整数提取和字符提取都会跳过前导空白，因此这种读取方式也能处理逗号两侧存在空格的输入。

正确性由有效指数集合的完整性保证。对于集合中的每个 $p$，$p$ 和 $2^p - 1$ 都是质数，因此生成的整数一定是完全数。对于集合外的指数，在题目限定范围内，合数指数不满足必要条件，质数指数 $11$ 对应的 $2^{11} - 1$ 也不是质数，而更大的指数生成的整数超过题目允许的完全数上界。因此，程序对每个输入的判断都与题目要求一致。

每组数据仅进行固定次数的比较和输入输出操作，时间复杂度为 $O(1)$。处理全部 $T$ 组数据的总时间复杂度为 $O(T)$，额外空间复杂度为 $O(1)$。

# 总结

本题的关键是利用偶完全数的结构定理，将因子求和问题转化为指数判定问题，再结合 $2^{33}$ 的数值上界，把所有有效指数压缩为集合 $\{2, 3, 5, 7, 13, 17\}$。实现时直接进行集合成员判断，并正确消耗输入中的逗号，即可在线性总时间和常数额外空间内完成全部判断。
