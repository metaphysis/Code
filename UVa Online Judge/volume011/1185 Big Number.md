
> **摘要**：本题要求计算 $n!$ 的十进制位数（$1 \le n \le 10^7$）。核心思路是利用位数公式 $d = \lfloor \log_{10}(n!) \rfloor + 1$，把「计算阶乘」转化为「累加对数」，从而避免构造大整数。代码采用分段策略：$n < 50$ 时直接累加 $\log_{10}i$ 保证精度，$n \ge 50$ 时使用 $\texttt{Stirling}$ 近似公式，使每组数据的时间与空间复杂度均为 $O(1)$。文中还讨论了对数误差界与取整边界对结果的影响。

 # 题目描述

给定一个正整数 $n$，求 $n!$ 的十进制表示包含多少位数字。其中，阶乘定义为：
$$
n! = 1 \times 2 \times \cdots \times n
$$
每组测试数据输出一个整数，表示对应阶乘的位数。

# 输入格式

第一行包含一个整数 $T$，表示测试数据的组数。接下来 $T$ 行，每行包含一个整数 $n$，满足 $1 \le n \le 10^7$。

# 输出格式

对于每组测试数据，输出一行，包含一个整数，表示 $n!$ 的十进制位数。

# 样例输入

```text
2
10
20
```

# 样例输出

```text
7
19
```

# 题目分析

本题只要求阶乘的位数，直接计算阶乘会产生大量无关的中间结果。随着 $n$ 增大，$n!$ 很快超出普通整数类型的表示范围；即使使用高精度整数，也需要维护整个阶乘并执行大量乘法。解决本题的关键是将“计算阶乘”转化为“计算阶乘的对数”，直接获得位数。

对于任意正整数 $x$，设其十进制位数为 $d$，则有：
$$
10^{d-1} \le x < 10^d
$$
两边取以 $10$ 为底的对数，得到：
$$
d-1 \le \log_{10}x < d
$$
因此，正整数的位数公式为：
$$
d = \left\lfloor \log_{10}x \right\rfloor + 1
$$
将 $x$ 替换为 $n!$，再利用乘积的对数等于各因子对数之和，得到：
$$
d = \left\lfloor \log_{10}(n!) \right\rfloor + 1
  = \left\lfloor \sum_{i=1}^{n}\log_{10}i \right\rfloor + 1
$$
这个公式避免了计算阶乘本身，但对每组数据逐项求和仍需进行 $n$ 次对数运算。由于 $n$ 的上限为 $10^7$，通过代码采用分段计算：较小的 $n$ 使用对数求和，较大的 $n$ 使用 $\texttt{Stirling}$ 近似公式，将单组数据的计算量降为常数级。

# 解题思路

当 $n < 50$ 时，直接累加 $\log_{10}1$ 到 $\log_{10}n$，然后向下取整并加 $1$。这一分支最多累加 $49$ 项，计算量很小，同时避开了 $\texttt{Stirling}$ 公式在较小参数处误差较大的区间。对于 $n=1$，累加结果为 $\log_{10}1=0$，最终输出 $1$，与 $1!=1$ 的位数一致。

当 $n \ge 50$ 时，使用 $\texttt{Stirling}$ 近似公式：
$$
n! \approx \sqrt{2\pi n}\left(\frac{n}{e}\right)^n
$$
其中，$e$ 是自然对数的底数，$\pi$ 是圆周率。两边取以 $10$ 为底的对数，得到：
$$
\log_{10}(n!)
\approx
\frac{1}{2}\log_{10}(2\pi n)
+
n\log_{10}\left(\frac{n}{e}\right)
$$
令右侧表达式为 $L(n)$，则代码使用的位数计算式为：
$$
d \approx \left\lfloor L(n) \right\rfloor + 1=
\left\lfloor
\frac{\log_{10}(2\pi n)}{2}
+
n\log_{10}\left(\frac{n}{e}\right)
\right\rfloor + 1
$$
代码通过 $\texttt{acos}$ 计算 $\arccos(-1)=\pi$，通过 $\texttt{exp}$ 计算 $e^1=e$。由于这一分支中的表达式为正数，将其加 $1$ 后赋给整数变量时，截去小数部分的效果与先向下取整再加 $1$ 一致。

近似公式的误差需要与位数取整一起理解。对于正整数 $n$，$\texttt{Stirling}$ 公式满足以下对数误差界：
$$
L(n)+\frac{1}{(12n+1)\ln 10}
<
\log_{10}(n!)
<
L(n)+\frac{1}{12n\ln 10}
$$
因此，$L(n)$ 略小于真实的阶乘对数，且误差随 $n$ 增大而减小。在 $n \ge 50$ 时，误差小于：
$$
\frac{1}{600\ln 10}<0.000724
$$
误差很小本身并不构成向下取整结果一致的充分证明：当真实值与近似值之间跨过整数边界时，位数结果仍会相差 $1$。所给通过代码直接使用近似结果，没有加入误差修正或整数边界判定，其实现依据是该计算方式在本题评测中的通过结果。对数求和分支的位数推导是精确的，实际计算使用浮点数；近似分支则额外包含 $\texttt{Stirling}$ 公式的截断误差。

复杂度方面，小数值分支的循环次数最多为 $49$，大数值分支只执行固定次数的数学运算。因此，在本题固定分段阈值下，每组测试数据的时间复杂度为 $O(1)$，共 $T$ 组数据的总时间复杂度为 $O(T)$；程序只使用若干变量，额外空间复杂度为 $O(1)$。

```cpp
#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0); cout.tie(0); ios_base::sync_with_stdio(false);
    int cases, n;
    cin >> cases;
    while (cases--)
    {
        cin >> n;
        if (n < 50)
        {
            // normal method
            double sum = 0.0;
            for (int i = 1; i <= n; i++)
                sum += log10(i);
            cout << ((int)floor(sum) + 1) << endl;
        }
        else
        {
            // stirling's approximation
            int count = log10(2 * acos(-1.0) * n) / 2.0 + n * log10(n / exp(1)) + 1;
            cout << count << endl;
        }
    }
    return 0;
}
```

# 总结

本题的核心是利用十进制位数公式，将阶乘位数转化为阶乘对数的向下取整结果，从而避免构造大整数。通过代码采用分段计算，小数值直接累加对数，大数值使用 $\texttt{Stirling}$ 近似公式，使每组数据只需常数级时间和空间。处理此类题目时，需要区分精确的数学变换与近似计算，并关注近似误差对取整边界的影响。
