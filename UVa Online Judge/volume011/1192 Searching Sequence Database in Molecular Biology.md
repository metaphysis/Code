
> **摘要**：本题要求在允许插入空位的前提下，计算查询核酸序列与数据库中每条序列的最优完整对齐得分（相同字符 $+5$、不同字符 $-4$、字符对空位 $-7$），并输出所有达到最高相似度的数据库序列及得分。文章从题意出发，分析完整对齐的三种列形式与最优子结构，给出后缀动态规划的状态定义、转移方程与边界条件，并用记忆化搜索实现，最后分析时间复杂度为 $O(nS+k)$、空间复杂度为 $O(B^2+n+S+k)$。

 # 题目描述

给定一条查询核酸序列和数据库中的若干条核酸序列，每条序列均由字符 $\texttt{A}$、$\texttt{C}$、$\texttt{G}$、$\texttt{T}$ 组成。通过在序列中插入空位，使两条序列的字符按原有顺序对齐，并按照以下规则计算对齐得分：

- 两个相同字符对齐，得分为 $5$。
- 两个不同字符对齐，得分为 $-4$。
- 一个字符与一个空位对齐，得分为 $-7$。

两条序列的相似度定义为完整对齐它们所能得到的最大总得分。完整对齐要求两条序列中的所有字符均参与对齐，不能丢弃开头、结尾或中间的字符。请计算查询序列与每条数据库序列的相似度，输出所有达到最高相似度的数据库序列及对应得分。存在并列结果时，按照它们在输入中的出现顺序输出。

# 输入格式

输入首先给出查询序列，随后给出若干条数据库序列，直到文件结束。每条序列占两行，格式如下：

```text
>sequence name
sequence data
```

首行为以 `>` 开头的序列名称，次行为序列内容。相邻序列之间有一个空行。

# 输出格式

首先输出查询序列，再输出所有相似度最高的数据库序列及其相似度。输出中的固定文字、换行和空行安排如下：

```text
The query sequence is:
查询序列内容

The most similar sequences are:

数据库序列内容
The similarity score is: 相似度

数据库序列内容
The similarity score is: 相似度
```

只输出序列内容，不输出序列名称。多个并列结果之间用一个空行分隔。

# 样例输入

```text
>query
ACGGG

>seq1
ACGGT

>seq2
ACGGGG

>seq3
TCCGGTT

>seq4
TCGGG

>seq5
AACGGG
```

# 样例输出

```text
The query sequence is:
ACGGG

The most similar sequences are:

ACGGGG
The similarity score is: 18

AACGGG
The similarity score is: 18
```

# 题目分析

本题的核心是求两条序列的最优完整对齐得分。直接逐个比较对应位置无法解决问题，因为插入空位会改变后续字符的对应关系，而一次空位带来的扣分能够换取后续更多的字符匹配。例如，样例中的查询序列长度为 $5$，数据库序列 $\texttt{ACGGGG}$ 的长度为 $6$，通过插入一个空位，可以得到 $5$ 对相同字符以及 $1$ 个与空位对齐的字符，总得分为 $5\times 5-7=18$。序列 $\texttt{AACGGG}$ 同样能够取得 $18$ 分，因此两条序列都需要输出。

设查询序列为 $s$，长度为 $n$，当前数据库序列为 $t$，长度为 $m$。从左向右观察任意一种完整对齐，当前一列只有三种有效形式：取出两条序列的当前字符并将它们对齐；取出查询序列的当前字符并与空位对齐；取出数据库序列的当前字符并与空位对齐。两个空位对齐不会消耗任何字符，也不会产生有意义的字符对应，因此不属于需要考虑的对齐形式。这三种选择覆盖了所有有效对齐方式，并且每次选择后，剩余部分仍然是两个后缀之间的完整对齐问题，具有明确的最优子结构。

不同的对齐选择会反复到达相同的后缀组合，因此直接递归会重复计算。使用动态规划记录每一对后缀的最优得分，就能使每个状态只计算一次。还需要注意，完整对齐与只寻找局部相似片段不同：当一条序列已经用完时，另一条序列的剩余字符必须全部与空位对齐，并继续扣分；状态值也不能与 $0$ 取最大值，否则会允许提前结束对齐，改变题意。

# 解题思路

定义 $\textit{dp}[i][j]$ 表示后缀 $s[i\ldots n-1]$ 与后缀 $t[j\ldots m-1]$ 完整对齐的最大得分，其中 $i$、$j$ 分别表示两条序列当前尚未处理的位置。答案为 $\textit{dp}[0][0]$。令当前两个字符直接对齐的得分为 $w(i,j)$，则有
$$
w(i,j)=
\begin{cases}
5, & s_i=t_j,\\
-4, & s_i\ne t_j.
\end{cases}
$$
当两条序列均有字符尚未处理时，分别枚举当前一列的三种形式：直接对齐两个字符后，同时推进两个位置；将查询序列的当前字符与空位对齐后，只推进查询序列的位置；将数据库序列的当前字符与空位对齐后，只推进数据库序列的位置。取三种方案中的最大得分，得到转移方程：
$$
\textit{dp}[i][j]=
\max\left\{
\begin{aligned}
&w(i,j)+\textit{dp}[i+1][j+1],\\
&-7+\textit{dp}[i+1][j],\\
&-7+\textit{dp}[i][j+1].
\end{aligned}
\right.
$$
当 $i=n$ 或 $j=m$ 时，至少一条序列已经全部处理完毕。此时剩余字符的总数为 $(n-i)+(m-j)$，每个字符都必须与空位对齐，因此边界条件为
$$
\textit{dp}[i][j]=-7\bigl((n-i)+(m-j)\bigr).
$$
当两条序列同时结束时，上式自然得到 $0$。

代码使用记忆化搜索实现上述动态规划，由 $\texttt{dfs}$ 函数计算状态。处理每条数据库序列前，将当前有效区域内的状态初始化为 $-\texttt{INF}$，表示尚未计算；访问已计算的状态时直接返回记录的结果。由于合法最优得分能够为负数，不能使用 $0$ 作为未计算标记。读入采用按空白分隔的方式，空行会被自动跳过，每条记录先读入并忽略名称，再读入序列内容。

状态转移的正确性由剩余字符总数上的归纳得到。边界状态只有将剩余字符全部与空位对齐这一种处理方式，所得分数正确。对于非边界状态，任意合法对齐的首列必定属于前述三种形式之一，移除首列后得到规模更小的后缀对齐问题。每种转移都使用对应后缀的最优得分，因此不会遗漏最优方案；同时，每种转移都能与其后缀方案拼接成合法完整对齐，因此不会引入无效答案。取三种转移的最大值，得到当前状态的最优得分。

依次计算查询序列与每条数据库序列的相似度，并保存数据库序列及其得分。全部读入后，先求所有得分的最大值，再按照输入顺序遍历，输出得分等于最大值的所有序列。这样既保留全部并列结果，也保证输出顺序正确。

设数据库共有 $k$ 条序列，第 $r$ 条序列的长度为 $m_r$，并记 $S=\sum_{r=1}^{k}m_r$。单次比较包含 $nm_r$ 个非边界状态，每个状态只进行常数次转移，时间复杂度为 $O(nm_r)$。计入输入和结果扫描，总时间复杂度为 $O(n+S+nS+k)$；对于非空序列，可写为 $O(nS+k)$。给定代码使用固定大小的二维数组，令其边长 $B=1010$，状态表占用 $O(B^2)$ 空间，保存所有数据库序列和得分占用 $O(S+k)$ 空间，查询序列及递归调用栈占用 $O(n+\max_r m_r)$ 空间，因此总空间复杂度为 $O(B^2+n+S+k)$。

# 代码实现

```cpp
// Searching Sequence Database in Molecular Biology
// UVa ID: 1192
// Verdict: Accepted
// Submission Date: 2023-05-15
// UVa Run Time: 0.600s
//
// 版权所有（C）2023，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;

string s, t;
int dp[1010][1010], ns, nt;
vector<string> ss;
vector<int> c;

int dfs(int i, int j) {
    if (i == ns || j == nt) return -7 * (ns + nt - i - j);
    if (dp[i][j] != -INF) return dp[i][j];
    int c = (s[i] == t[j] ? 5 : -4) + dfs(i + 1, j + 1);
    c = max(c, -7 + dfs(i, j + 1));
    c = max(c, -7 + dfs(i + 1, j));
    return dp[i][j] = c;
}

int main(int argc, char *argv[]) {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    cin >> s >> s;
    cout << "The query sequence is:\n";
    cout << s << '\n';
    cout << '\n';
    ns = s.length();
    while (cin >> t) {
        cin >> t;
        ss.push_back(t);
        nt = t.length();
        for (int i = 0; i < ns; i++)
            for (int j = 0; j < nt; j++)
                dp[i][j] = -INF;
        c.push_back(dfs(0, 0));
    }
    cout << "The most similar sequences are:\n";
    cout << '\n';
    int mc = *max_element(c.begin(), c.end());
    int printed = 0;
    for (int i = 0; i < c.size(); i++)
        if (c[i] == mc) {
            if (printed) cout << '\n';
            cout << ss[i] << '\n';
            cout << "The similarity score is: " << mc << '\n';
            printed = 1;
        }
    return 0;
}
```

# 总结

本题通过后缀动态规划求解序列的最优完整对齐，将每个位置的选择归纳为字符直接对齐、查询字符与空位对齐、数据库字符与空位对齐三种情况，并用记忆化搜索消除重复计算。实现的关键是正确处理序列耗尽后的空位罚分、使用独立标记区分未计算状态与合法负分，以及在处理不同数据库序列前重新初始化状态表。完成各条序列的相似度计算后，统一求最大值并按原顺序输出全部并列结果。
