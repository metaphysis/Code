
> **摘要**：本文针对「雷达安装」问题，将每座岛屿对雷达位置的约束转化为海岸线上的一个可行闭区间，从而把最少雷达问题归约为区间选点问题。文章给出按岛屿横坐标排序、持续维护当前组公共交集的贪心算法，并借助区间关于横坐标对称的性质证明其最优性；同时分析了 $y_i>d$ 时无解的判定、闭区间端点相等的处理，以及原代码初始交集设置对 $d=0$ 情形的依赖。算法总时间复杂度为 $O(n\log n)$，空间复杂度为 $O(n)$。

 # 题目描述

海岸线是一条无限长的直线，陆地和海洋分别位于海岸线的两侧。建立平面直角坐标系，将海岸线设为 $x$ 轴，海洋位于 $x$ 轴上方。海洋中有 $n$ 座岛屿，每座岛屿视为一个点，第 $i$ 座岛屿的坐标为 $(x_i,y_i)$。

雷达只能安装在海岸线上，每台雷达的覆盖半径均为 $d$。当岛屿与雷达之间的距离不超过 $d$ 时，该岛屿被雷达覆盖。求覆盖全部岛屿所需的最少雷达数量；若无法覆盖全部岛屿，则输出 $-1$。

# 输入格式

输入包含多组测试数据。每组测试数据的第一行包含两个整数 $n$ 和 $d$，分别表示岛屿数量和雷达覆盖半径，其中 $1\le n\le 1000$。

接下来 $n$ 行，每行包含两个整数 $x_i$ 和 $y_i$，表示一座岛屿的坐标。测试数据之间由空行分隔。

当读入的 $n$ 和 $d$ 均为 $0$ 时，输入结束，该行不作为测试数据处理。

# 输出格式

每组测试数据输出一行，格式为 `Case k: ans`，其中 $k$ 表示从 $1$ 开始的测试数据编号，$ans$ 表示覆盖全部岛屿所需的最少雷达数量。不存在可行方案时，$ans=-1$。

# 样例输入

```text
3 2
1 2
-3 1
2 1

1 2
0 2

0 0
```

# 样例输出

```text
Case 1: 2
Case 2: 1
```

# 题目分析

雷达安装位置虽然连续且无限，但每座岛屿对雷达位置的限制能够表示为海岸线上的一个闭区间。设覆盖岛屿 $(x_i,y_i)$ 的雷达安装在 $(p,0)$，根据两点间的距离公式，必须满足
$$
(p-x_i)^2+y_i^2\le d^2.
$$
岛屿到海岸线的最短距离为 $y_i$，因此，只要存在 $y_i>d$，这座岛屿就无法被任何雷达覆盖，整组数据的答案为 $-1$。当 $y_i\le d$ 时，将距离限制整理为
$$
x_i-\sqrt{d^2-y_i^2}\le p\le x_i+\sqrt{d^2-y_i^2}.
$$
定义岛屿对应的可行区间为
$$
I_i=[L_i,R_i],\qquad
L_i=x_i-\sqrt{d^2-y_i^2},\qquad
R_i=x_i+\sqrt{d^2-y_i^2}.
$$
雷达安装在 $I_i$ 中的任意位置，都能覆盖第 $i$ 座岛屿。原问题由此转化为：在数轴上选择尽量少的点，使每个可行区间至少包含一个被选中的点。

多个岛屿能够共用一台雷达，当且仅当它们的可行区间存在公共交集。设当前一组区间的交集为 $[A,B]$，加入新区间 $[L_i,R_i]$ 后，交集更新为
$$
[A',B']=[\max(A,L_i),\min(B,R_i)].
$$
当 $A'\le B'$ 时，更新后的交集非空，这些岛屿继续共用一台雷达；当 $A'>B'$ 时，当前组不能继续接纳这座岛屿，需要结束当前组，并从新区间开始建立下一组。闭区间端点也属于可行位置，因此交集退化为一个点时，仍然只需要一台雷达。

给定代码按照岛屿横坐标递增的顺序处理区间。这里的排序依据是区间中点，而不是区间端点，因此必须结合区间关于 $x_i$ 对称的性质证明贪心策略。对于已经处理的任意区间，都有 $L_j\le x_j\le x_i\le R_i$，所以当前交集的左端点一定满足 $A\le R_i$。因此，加入新区间后交集变空，只会由 $L_i>B$ 引起，即新区间完全位于当前交集右侧。这一性质保证了扫描过程始终向右推进。

# 解题思路

先读入全部岛屿，并检查是否存在 $y_i>d$。即使已经发现无解，也必须继续读完本组数据，保证下一组输入的位置正确。随后按照横坐标 $x_i$ 递增排序；存在无法覆盖的岛屿时，直接输出 $-1$。

对于有解的数据，依次计算每座岛屿对应的可行区间，并维护当前组所有区间的公共交集。新区间与当前交集相交时，将交集收缩为两者的交集；两者不相交时，增加雷达数量，并将当前交集重置为新区间。最终每组岛屿使用一台雷达，雷达安装在该组公共交集中的任意位置即可。

下面证明这种分组方式得到的雷达数量最少。设扫描后形成 $g$ 个组，从每组中选出右端点最小的区间作为代表区间。对于某一组，设它的首个区间为 $[L_s,R_s]$，代表区间为 $[L_q,R_q]$。由于岛屿按照横坐标递增处理，且代表区间的右端点最小，有 $x_q\ge x_s$ 和 $R_q\le R_s$。利用区间关于岛屿横坐标对称的性质，得到
$$
L_q=2x_q-R_q\ge 2x_s-R_s=L_s.
$$
也就是说，每组代表区间的左端点不小于该组首个区间的左端点。设上一组公共交集的右端点为 $B$，下一组的首个区间之所以开启新组，正是因为其左端点大于 $B$。而上一组代表区间的右端点恰好为 $B$，下一组代表区间的左端点又不小于下一组首个区间的左端点，所以相邻两组的代表区间严格分离。由此，选出的 $g$ 个代表区间两两不相交，任何一台雷达都无法同时覆盖其中两个区间对应的岛屿，所有可行方案至少需要 $g$ 台雷达。算法对每组使用一台雷达，总共使用 $g$ 台，达到下界，因此结果最优。

样例的第一组数据中，岛屿 $(1,2)$ 对应的区间为 $[1,1]$，岛屿 $(-3,1)$ 对应的区间为 $[-3-\sqrt{3},-3+\sqrt{3}]$，岛屿 $(2,1)$ 对应的区间为 $[2-\sqrt{3},2+\sqrt{3}]$。后两个横坐标较大的岛屿对应区间在位置 $1$ 相交，能够共用一台雷达；横坐标为 $-3$ 的岛屿需要单独覆盖，因此答案为 $2$。第二组只有一座岛屿，在其正下方安装一台雷达即可，答案为 $1$。

排序的时间复杂度为 $O(n\log n)$，计算区间并维护交集的时间复杂度为 $O(n)$，总时间复杂度为 $O(n\log n)$。保存岛屿坐标需要 $O(n)$ 空间，排序递归栈需要 $O(\log n)$ 空间，总空间复杂度为 $O(n)$。

# 代码实现

```cpp
// Radar Installation
// UVa ID: 1193
// Verdict: Accepted

// UVa Run Time: 0.000s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

struct island
{
    int x, y;
    bool operator<(const island &i) const
    {
       return x < i.x;
    }
}islands[1010];

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int n, d, cases = 0;
    while (cin >> n >> d, n > 0)
    {
        bool flag = true;
        for (int i = 0; i < n; i++)
        {
            cin >> islands[i].x >> islands[i].y;
            if (islands[i].y > d) flag = false;
        }
        sort(islands, islands + n);
        cout << "Case " << ++cases << ": ";
        if (!flag) cout << "-1\n";
        else
        {
            int radars = 0;
            double cleft = islands[0].x - 2 * d, cright = islands[0].x - 2 * d;
            double covered, nleft, nright;
            for (int i = 0; i < n; i++)
            {
                covered = sqrt(d * d - islands[i].y * islands[i].y);
                nleft = islands[i].x - covered, nright = islands[i].x + covered;
                cleft = max(cleft, nleft);
                cright = min(cright, nright);
                if (cleft > cright)
                {
                    radars++;
                    cleft = nleft, cright = nright;
                }
            }
            cout << radars << '\n';
        }
    }
    return 0;
}
```

# 总结

本题的关键是将平面上的距离限制转化为海岸线上的可行区间，再将最少雷达问题转化为区间选点问题。按照岛屿横坐标排序后，利用区间关于横坐标对称的性质，持续维护当前组的公共交集，并在交集为空时建立新组。每组对应一台雷达，而各组右端点最小的代表区间两两不相交，为雷达数量提供了相同的下界，从而证明贪心方案最优。处理时还需保留闭区间端点相等的情况，并检查岛屿高度是否超过覆盖半径。
