
> **摘要**：本题要求在可自由调整作业顺序的前提下，为每项作业选择机器 $A$ 或机器 $B$ 的某个工作模式完成，求完成全部作业所需的最少重启次数。核心思路是：初始模式 $0$ 可免费完成相关作业，剩余作业转化为二分图的最小顶点覆盖问题，再依据 $\texttt{Kőnig}$ 定理等价为最大匹配，用匈牙利算法在 $O(k+n^2m)$ 时间内求解。

 # 题目描述

有两台机器 $A$ 和 $B$。机器 $A$ 有 $n$ 种工作模式，编号为 $0$ 到 $n-1$；机器 $B$ 有 $m$ 种工作模式，编号为 $0$ 到 $m-1$。初始时，两台机器均处于模式 $0$。

现在需要完成 $k$ 项作业。每项作业用三元组 $(i,x,y)$ 描述，表示编号为 $i$ 的作业既能由处于模式 $x$ 的机器 $A$ 完成，也能由处于模式 $y$ 的机器 $B$ 完成，选择其中一种方式即可。机器每次切换工作模式都需要手动重启。通过调整作业执行顺序，并为每项作业选择合适的机器，求完成全部作业所需的最少重启次数。

# 输入格式

输入包含多组测试数据。每组数据的首行包含三个正整数 $n,m,k$，其中 $n,m<100$，$k<1000$。

接下来 $k$ 行，每行包含三个整数 $i,x,y$，表示作业编号及其在两台机器上对应的工作模式，其中 $0\le x<n$，$0\le y<m$。

当读入的一行仅包含 $0$ 时，输入结束。

# 输出格式

对于每组测试数据，输出一行，包含一个整数，表示完成全部作业所需的最少重启次数。

# 样例输入

```text
5 5 10
0 1 1
1 1 2
2 1 3
3 1 4
4 2 1
5 2 2
6 2 3
7 2 4
8 3 3
9 4 3
0
```

# 样例输出

```text
3
```

# 题目分析

本题的关键是将“安排作业并减少重启”转化为“选择尽量少的工作模式”。由于作业执行顺序能够自由调整，分配给同一台机器、同一种模式的作业能够集中完成，因此每种被使用的非零模式只需进入一次。若机器使用了 $r$ 种不同的非零模式，就需要至少重启 $r$ 次；先完成分配给初始模式 $0$ 的全部作业，再依次进入这些非零模式，恰好重启 $r$ 次即可完成对应作业。因此，最少重启次数等于两台机器总共需要选择的最少非零模式数量。

模式 $0$ 需要单独处理。两台机器初始时都处于模式 $0$，因此，对于满足 $x=0$ 或 $y=0$ 的作业，直接交给对应机器在初始阶段完成，不会增加重启次数，也不会对其他非零模式的选择形成约束。这些作业无需参与后续优化。对于剩余作业，其对应的两个模式均非零，必须在机器 $A$ 的模式 $x$ 和机器 $B$ 的模式 $y$ 中至少选择一个。

以机器 $A$ 的所有非零模式作为左部顶点，以机器 $B$ 的所有非零模式作为右部顶点；每项剩余作业对应一条连接其两个可选模式的边。选择一个顶点，表示使用对应机器的这一工作模式，并支付一次重启代价。每条边至少有一个端点被选择，恰好表示每项作业至少有一种执行方式得到满足。因此，问题转化为二分图的最小顶点覆盖。根据 $\texttt{Kőnig}$ 定理，二分图的最小顶点覆盖大小等于最大匹配大小，求出最大匹配数即可得到答案。

# 解题思路

首先建立二分图。对于输入的每项作业，在机器 $A$ 的模式 $x$ 与机器 $B$ 的模式 $y$ 之间记录一条边。代码采用邻接矩阵 $g$ 存储连接关系，$g[x][y]=1$ 表示存在能够由这两个模式之一完成的作业。多项作业对应同一对模式时，它们对模式选择提出的约束完全相同，因此合并为一条边不影响答案。代码保留与模式 $0$ 相连的边，但匹配过程只枚举非零模式，使这些边不参与计算，效果等同于提前删除相关作业。

随后使用匈牙利算法，通过深度优先搜索寻找增广路。数组 $cx$ 和 $cy$ 分别记录左右两侧顶点当前匹配的另一端，值为 $0$ 表示尚未匹配。由于实际参与匹配的模式编号均从 $1$ 开始，使用 $0$ 作为未匹配标记不会产生冲突。依次从尚未匹配的左部顶点出发，检查与其相邻的右部顶点。若右部顶点尚未匹配，就直接建立匹配；若已经匹配，则尝试为它原来匹配的左部顶点重新寻找匹配位置，重新安排成功后，再将当前左部顶点与该右部顶点匹配。一次成功的搜索会使匹配数量增加 $1$。

每次从新的左部顶点开始搜索前，都要清空访问标记，使此前搜索访问过的顶点能够重新参与匹配调整。在同一次搜索中，右部访问标记保证每个右部顶点至多被处理一次，避免沿交替连接反复搜索。代码中的 $vx$ 记录左部顶点的访问情况，实际控制搜索去重的是右部访问数组 $vy$。全部左部顶点处理完毕后，得到最大匹配，输出其大小即可。

这一结论具有严格的上下界依据。设最大匹配大小为 $M$，匹配中的 $M$ 条边两两不共享端点，任何顶点覆盖都必须为每条匹配边选择至少一个端点，因此至少需要选择 $M$ 个模式。根据 $\texttt{Kőnig}$ 定理，存在大小恰好为 $M$ 的顶点覆盖，将每项作业分配给其被选择的端点所代表的模式，再按模式集中执行，就能用 $M$ 次重启完成全部作业。因此，最少重启次数恰好为 $M$。样例中，选择机器 $A$ 的模式 $1$、模式 $2$，以及机器 $B$ 的模式 $3$，即可完成全部作业；同时，图中存在大小为 $3$ 的匹配，所以答案为 $3$。

建图需要 $O(k)$ 时间。在一次增广搜索中，至多处理 $m-1$ 个右部顶点，每个被递归处理的左部顶点需要扫描全部右部模式，单次搜索的时间复杂度为 $O(nm)$；最多进行 $n-1$ 次搜索，因此总时间复杂度为 $O(k+n^2m)$。邻接矩阵占用 $O(nm)$ 空间，匹配数组、访问数组及递归栈占用 $O(n+m)$ 空间，总空间复杂度为 $O(nm+n+m)$。

```cpp
// Machine Schedule

// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXV = 110;

int g[MAXV][MAXV], vx[MAXV], vy[MAXV], cx[MAXV], cy[MAXV], nx, my, kj;

// 使用深度优先搜索寻找增广路，一次搜索只能使当前的匹配数增加1。
int dfs(int u)
{
    // 设置机器A的模式u为已访问。
    vx[u] = 1;

    // 考虑所有与模式u能够完成同一项作业的模式v。由于机器的初始状态为模式0，
    // 不需重启机器，故从模式1开始寻找增广路。
    for (int v = 1; v < my; v++)
        if (g[u][v] && !vy[v])
        {
            // 如果v尚未匹配或者v已经匹配但是从v出发可以找到增广路则匹配成功。
            vy[v] = 1;
            if (!cy[v] || dfs(cy[v]))
            {
                // 更改匹配。
                cx[u] = v;
                cy[v] = u;
                return 1;
            }
        }
        
    // 未能找到增广路，已经是最大匹配。
    return 0;
}

// 匈牙利算法求最大匹配数。
int hungarian()
{
    int matches = 0;
    memset(cx, 0, sizeof(cx)); memset(cy, 0, sizeof(cy));
    
    // 机器A和机器B最初工作在模式0，在模式0状态下可以完成的作业不需要重新
    // 启动机器，故从模式1开始匹配。
    for (int i = 1; i < nx; i++)
        if (!cx[i])
        {
            // 注意寻找之前需要将访问标记置为初始状态。
            memset(vx, 0, sizeof(vx)); memset(vy, 0, sizeof(vy));
            
            // 每找到一条增广路，可使得匹配数增加1。
            matches += dfs(i);
        }
    return matches;
}

int main(int argc, char *argv[])
{
    while (cin >> nx, nx > 0)
    {
        cin >> my >> kj;

        // 根据作业约束建立二部图。
        memset(g, 0, sizeof(g));
        for (int t, x, y, i = 0; i < kj; i++)
        {
            cin >> t >> x >> y;
            g[x][y] = 1;
        }

        // 使用匈牙利算法求匹配数，从而得到点覆盖数。
        cout << hungarian() << '\n';
    }
    
	return 0;
}
```

# 总结

本题利用作业顺序能够自由调整这一条件，将重启次数转化为使用的非零模式数量，再将每项作业的两种执行方式表示为二分图的一条边，从而建立最小顶点覆盖模型。初始模式 $0$ 对应免费完成作业的机会，必须排除其相关约束；其余部分依据 $\texttt{Kőnig}$ 定理转化为最大匹配，并使用匈牙利算法求解。对于每个任务都能由两类资源中的某一种完成、且目标是最小化所选资源数量的问题，这种建图方式具有直接的应用价值。
