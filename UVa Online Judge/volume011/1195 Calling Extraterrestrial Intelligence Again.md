
> **摘要**：本题要求在面积上限 $m$ 与宽高比下限 $\frac{a}{b}$ 的约束下，选出两个质数 $p,q$ 作为图像的宽和高，使乘积 $pq$ 最大。核心做法是先用线性筛预处理 $100000$ 以内的质数，再枚举满足 $p\le q$ 的有序质数对，用 $pq\le m$ 判断面积、用交叉相乘 $aq\le bp$ 判断比例，并在面积超限时及时结束内层循环。整体时间复杂度为 $O(L+TP^2)$，空间复杂度为 $O(L)$。

 # 题目描述

为了向外星文明发送信息，需要将信息排列成一幅矩形图像。图像的宽和高都必须是质数，并且需要在面积限制和宽高比例限制下，使图像面积尽可能大。

给定整数 $m$ 以及分数 $\frac{a}{b}$，求两个质数 $p,q$，分别作为图像的宽和高，满足：
$$
pq\le m,\qquad \frac{a}{b}\le\frac{p}{q}\le 1
$$
在满足上述条件的所有质数对中，选择乘积 $pq$ 最大的一组，输出 $p$ 和 $q$。

# 输入格式

输入包含多组测试数据，测试数据最多有 $2000$ 组。

每组数据占一行，包含三个正整数 $m,a,b$，依次表示面积上限、宽高比下限的分子和分母。数据范围为：
$$
4<m\le 100000,\qquad 1\le a\le b\le 1000
$$
当输入为三个 $0$ 时，输入结束，这一行不需要处理。

# 输出格式

对于每组测试数据，输出一行，包含两个正整数 $p,q$，分别表示最优图像的宽和高，两个整数之间用一个空格分隔。

# 样例输入

```text
5 1 2
99999 999 999
1680 5 16
1970 1 1
2002 4 11
0 0 0
```

# 样例输出

```text
2 2
313 313
23 73
43 43
37 53
```

# 题目分析

题目要求同时满足质数、面积和比例三个条件。由 $\frac{p}{q}\le 1$ 可知 $p\le q$，因此只需要考虑宽不大于高的质数对，无需重复枚举交换顺序后的情况。又因为质数至少为 $2$，结合 $pq\le m$，可得 $q\le\lfloor m/2\rfloor$；由 $p\le q$ 还能推出 $p^2\le m$，即 $p\le\lfloor\sqrt m\rfloor$。这些性质说明，所有候选宽高都处于有限范围内，预处理质数后即可通过枚举寻找最优解。

比例限制不需要通过浮点除法判断。由于 $b$ 和 $q$ 都是正数，将 $\frac{a}{b}\le\frac{p}{q}$ 交叉相乘，得到完全等价的整数条件：
$$
aq\le bp
$$
这样既能准确处理比例恰好等于下限的情况，也避免了浮点误差。于是，对于一对满足 $p\le q$ 的质数，只需判断 $pq\le m$ 和 $aq\le bp$，即可确定其合法性，再比较乘积大小来维护最优答案。

多组测试数据共用同一个数值上限，因此质数只需预处理一次。代码使用线性筛生成小于 $100000$ 的全部质数。由于任何合法答案都满足 $q\le 50000$，这一预处理范围完整覆盖所有候选值。枚举时按质数从小到大的顺序选择 $q$，一旦出现 $pq>m$，后续更大的 $q$ 同样不满足面积限制，因此能够立即结束当前宽度对应的内层枚举。

# 解题思路

首先使用线性筛建立递增的质数表。依次处理从 $2$ 开始的整数，若当前整数尚未被标记为合数，就将其加入质数表；随后用已经得到的质数与当前整数相乘，标记对应的合数。当枚举到能够整除当前整数的质数时，结束这一轮标记。线性筛通过这一终止规则，使每个合数只由其最小质因子对应的组合标记一次，从而在线性时间内完成预处理。

代码中的 $primes$ 数组同时存储质数表和合数标记：已经写入的前缀保存递增质数，其余位置承担筛选标记的作用。处理整数 $i$ 时，已有质数的数量小于 $i$，因此把新质数写入数组前缀只会覆盖已经完成筛选判定的位置，不会破坏后续整数的判定。内层标记的位置为 $i$ 与某个质数的乘积，至少为 $2i$，也不会覆盖当前已经保存的质数表。由此能够在同一个数组中完成两种用途。

接着逐组处理输入，将当前最大面积初始化为 $0$。外层依次选择质数 $p$，内层从 $p$ 在质数表中的位置开始选择 $q$，从而直接保证 $p\le q$。每得到一对质数，先检查面积：若 $pq>m$，立即结束内层循环；否则检查 $aq\le bp$，若比例合法且面积严格大于当前最优面积，就同时更新最大面积及其对应的宽和高。输入结束标记出现后，程序终止。

代码没有在 $p^2>m$ 时结束外层循环，而是继续访问后续质数。此时内层第一次检查就会因 $pq>m$ 而退出，不会影响正确性，只会增加少量无效检查。对于任意合法答案 $(p,q)$，质数表包含这两个数，且内层枚举包含所有不小于 $p$、乘积不超过 $m$ 的候选质数，因此该答案一定会被检查。所有记录下来的答案又都经过面积和比例验证，所以最终保留的正是面积最大的合法质数对。由于 $m>4$ 且 $\frac{a}{b}\le 1$，质数对 $(2,2)$ 始终合法，程序一定会在输出前完成答案赋值。

以样例中 $m=1680$、$a=5$、$b=16$ 的数据为例，质数对 $(23,73)$ 满足：
$$
23\times73=1679\le1680,\qquad 5\times73=365\le368=16\times23
$$
因此该质数对合法。它的面积距离上限仅差 $1$，而面积 $1680$ 的分解包含多个质因子，无法表示成两个质数的乘积，所以最大面积为 $1679$，对应输出为 $23$ 和 $73$。

设预处理上限为 $L$，小于 $L$ 的质数数量为 $P$，测试数据组数为 $T$。线性筛的时间复杂度为 $O(L)$；每组数据枚举的质数对数量至多为 $O(P^2)$，因此总时间复杂度上界为 $O(L+TP^2)$。实际执行中，面积超限就会结束内层循环，枚举量显著小于完整的质数对数量；对某个满足 $p^2\le m$ 的质数 $p$，仅需检查不超过 $\lfloor m/p\rfloor$ 的候选高度及一次超限判断。质数表与筛选标记共用长度为 $L$ 的数组，其余变量只占常数空间，因此空间复杂度为 $O(L)$。

# 代码实现

```cpp
// Calling Extraterrestrial Intelligence Again
// UVa ID: 1195
// Verdict: Accepted
// Submission Date: 2018-11-30
// UVa Run Time: 0.040s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 100000;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int primes[MAXN] = {}, cnt = 0;
    for (int i = 2; i < MAXN; i++)
    {
        if (!primes[i]) primes[cnt++] = i;
        for (int j = 0; j < cnt && i * primes[j] < MAXN; j++)
        {
            primes[i * primes[j]] = 1;
            if (i % primes[j] == 0) break;
        }
    }
    long long m, a, b;
    while (cin >> m >> a >> b)
    {
        if (m == 0) break;
        long long most = 0, p, q, pp, qq;
        for (int i = 0; i < cnt; i++)
        {
            p = primes[i];
            for (int j = i; j < cnt; j++)
            {
                q = primes[j];
                if (p * q > m) break;
                if (a * q <= b * p && p * q > most)
                {
                    most = p * q;
                    pp = p, qq = q;
                }
            }
        }
        cout << pp << ' ' << qq << '\n';
    }
    return 0;
}
```

# 总结

本题通过预处理质数，将宽高选择转化为有序质数对的枚举。利用 $p\le q$ 消除对称重复，利用质数递增时乘积也递增的性质，在面积超限后及时结束内层循环，再通过 $aq\le bp$ 精确判断比例约束。关键技巧是把分数比较转化为整数运算，并结合候选值的单调性减少无效枚举。
