
> **摘要**：本题给定 $n$ 个由左侧、中部凸起数量 $(l,m)$ 描述的积木，要求按 $l\ge l'$、$m\ge m'$ 的叠放规则搭出最高的积木堆。解法先将积木按 $(l_i,m_i)$ 字典序升序排序，把自由排列的二维叠放问题转化为有序序列上的最长链问题，再以「以积木 $i$ 为顶部时的最大高度」为状态做动态规划，枚举合法前驱转移，时间复杂度 $O(n^2)$、空间复杂度 $O(n)$。

 # 题目描述

给定 $n$ 个积木，每个积木由两个参数 $(l,m)$ 描述，分别表示其左侧和中部的凸起数量，底部具有对应数量的凹槽。

参数为 $(l,m)$ 的积木能够叠放在参数为 $(l',m')$ 的积木上方，当且仅当：
$$
l\ge l',\qquad m\ge m'
$$
每个积木最多使用一次，积木的使用顺序能够自由调整。求能够搭出的最高积木堆所包含的积木数量。

# 输入格式

输入包含多组测试数据。每组数据首先给出一个整数 $n$，表示积木数量，满足 $1\le n\le 10000$。

接下来 $n$ 行，每行包含两个整数 $l_i,m_i$，表示一个积木的两个参数，满足 $1\le l_i,m_i\le 100$。

当读入的 $n=0$ 时，输入结束。

# 输出格式

对于每组测试数据，输出一行，包含一个整数，表示最高积木堆包含的积木数量。

所有测试数据处理完毕后，单独输出一行星号 `*`，表示输出结束。

# 样例输入

```text
3
3 2
1 1
2 3
5
4 2
2 4
3 3
1 1
5 5
0
```

# 样例输出

```text
2
3
*
```

# 题目分析

根据叠放规则，从下向上观察一个合法积木堆，其左侧参数和中部参数都必须单调不减。因此，本题要求从给定积木中选择尽量多的积木，并排列成两个参数同时单调不减的序列。两个参数之间存在共同约束，仅按其中一个参数选择积木无法保证另一个参数也满足要求。例如，参数为 $(2,3)$ 和 $(3,2)$ 的两个积木，无论如何安排上下顺序，都无法相互叠放。

输入顺序不限制积木的使用顺序，因此先对所有积木排序。排序规则为左侧参数从小到大，左侧参数相同时，中部参数从小到大。排序后，对于下标满足 $j<i$ 的两个积木，左侧参数已经满足 $l_j\le l_i$；再检查中部参数是否满足 $m_j\le m_i$，即可判断积木 $i$ 能否放在积木 $j$ 上方。左侧参数相同时按中部参数升序排列十分关键，因为左侧参数相等的积木仍然能够连续叠放，这种排序使它们按合法方向出现在序列中。

经过排序，问题转化为寻找一条最长的合法叠放序列，适合使用动态规划。以某个积木作为最上方积木时，其下方的最后一个积木必须排在它之前，并满足两个参数均不大于它。枚举这些合法的前驱积木，就能从已经求出的较小子问题得到当前状态。叠放条件允许参数相等，因此完全相同的多个积木也能全部参与叠放，状态转移必须使用非严格比较。

# 解题思路

将积木按照 $(l_i,m_i)$ 的字典序升序排列，并使用排序后的下标描述每个积木。定义 $\textit{length}[i]$ 表示以积木 $i$ 为最上方积木时，能够构成的最高积木堆所包含的积木数量。每个积木都能单独构成一个高度为 $1$ 的积木堆，因此所有状态的初始值均为 $1$。对于每个积木 $i$，枚举所有满足 $j<i$ 的积木 $j$，若 $l_j\le l_i$ 且 $m_j\le m_i$，就在以积木 $j$ 为顶部的最优积木堆上添加积木 $i$，得到状态转移：
$$
\textit{length}[i]=
\max\left(
\{1\}\cup
\left\{
\textit{length}[j]+1
\mid 0\le j<i,\ l_j\le l_i,\ m_j\le m_i
\right\}
\right)
$$
按下标从小到大计算各个状态，转移依赖的状态均已计算完毕。最高积木堆的顶部能够是任意一个积木，因此最终答案为：
$$
\max_{0\le i<n}\textit{length}[i]
$$

上述转移能够完整覆盖所有合法叠放方案。对于任意一个顶部为积木 $i$、高度大于 $1$ 的合法积木堆，设紧邻其下方的积木为 $j$，则必有 $l_j\le l_i$ 且 $m_j\le m_i$。若两个积木的参数不同，排序会将积木 $j$ 放在积木 $i$ 之前；若参数完全相同，则这些积木能够按排序后的下标依次排列，叠放合法性保持不变。因此，始终存在与排序顺序一致的最优方案，其顶部下方的积木会被状态转移枚举到。反过来，每次转移都只在两个参数满足叠放条件时添加积木，并且下标严格增大，既保证了叠放合法，也保证了每个积木只使用一次。由此得到的状态值和最终答案均正确。

样例中的第一组积木排序后为 $(1,1)$、$(2,3)$、$(3,2)$。后两个积木都能放在 $(1,1)$ 上方，但它们彼此无法叠放，所以最大高度为 $2$。第二组积木能够从下到上依次选择 $(1,1)$、$(3,3)$、$(5,5)$，形成高度为 $3$ 的积木堆；中间的 $(2,4)$、$(3,3)$、$(4,2)$ 两两无法叠放，因此无法得到更高的结果。

对于每组测试数据，排序的时间复杂度为 $O(n\log n)$，动态规划枚举所有前后积木对，检查次数为 $\frac{n(n-1)}{2}$，时间复杂度为 $O(n^2)$，最终求最大值需要 $O(n)$ 时间，因此总时间复杂度为 $O(n^2)$。积木数组和状态数组均占用 $O(n)$ 空间，总空间复杂度为 $O(n)$。

# 代码实现

```cpp
// Tiling Up Blocks
// UVa ID: 1196
// Verdict: Accepted
// Submission Date: 2017-10-05
// UVa Run Time: 0.010s
//
// 版权所有（C）2017，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

struct tile
{
    int l, m;
    bool operator<(const tile &t) const
    {
        if (l != t.l) return l < t.l;
        else return m < t.m;
    }
};

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int n, left, middle;
    while (cin >> n, n > 0)
    {
        vector<tile> tiles;
        vector<int> length(n, 1);
        for (int i = 0; i < n; i++)
        {
            cin >> left >> middle;
            tiles.push_back(tile{left, middle});
        }
        sort(tiles.begin(), tiles.end());
        for (int i = 0; i < n; i++)
            for (int j = 0; j < i; j++)
                if (tiles[i].l >= tiles[j].l && tiles[i].m >= tiles[j].m)
                    if (length[j] + 1 > length[i])
                        length[i] = length[j] + 1;
        cout << *max_element(length.begin(), length.end()) << '\n';
    }
    cout << "*\n";
    return 0;
}
```

# 总结

本题通过排序将自由排列的二维叠放关系转化为有序的状态转移，再以“某个积木作为顶部时的最大高度”为状态，枚举合法前驱求出最优解。关键在于左侧参数相同时仍按中部参数升序排列，以及使用非严格不等式处理参数相等的积木。这种先排序、再进行动态规划的方法，同样适用于具有多个属性约束的最长链问题。
