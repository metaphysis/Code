
> **摘要**：题目给定 $n$ 名学生与 $m$ 个学生团体，团体内部成员相互接触，一旦有人被认定为疑似感染者，整个团体都会被认定，且该状态会通过重叠团体持续传播。初始只有学生 $0$ 疑似感染，求最终疑似感染者总数。核心思路是把每名学生看作顶点、团体成员间的接触看作边，答案即学生 $0$ 所在连通分量的大小，用并查集维护连通性：读入每个团体时将其首名成员与其余成员依次合并，最后统计与学生 $0$ 同根的学生数量。配合路径压缩与按秩合并，单组数据时间复杂度为 $O(m+(n+S)\alpha(n))$，空间复杂度 $O(n)$。

 # 题目描述

某所大学中有 $n$ 名学生，编号为 $0$ 到 $n-1$。学校内共有 $m$ 个学生团体，同一团体的学生经常相互接触，一名学生也能同时参加多个团体。

学校规定：一旦某个团体内有一名学生被认定为疑似感染者，该团体内的所有学生都被认定为疑似感染者。这一规则会持续生效，因此疑似感染者会通过相互重叠的团体继续扩展。

初始时，只有学生 $0$ 被认定为疑似感染者。给出所有团体的成员名单，求最终被认定为疑似感染者的学生总数。

# 输入格式

输入包含多组测试数据。每组数据的第一行包含两个整数 $n,m$，分别表示学生数量和团体数量，满足：
$$
0<n\le 30000,\qquad 0\le m\le 500
$$
接下来 $m$ 行，每行描述一个团体。每行首先给出一个整数 $k$，表示该团体的成员数量，随后给出 $k$ 个学生编号。所有学生编号均在 $0$ 到 $n-1$ 之间。

当读入的 $n=0$ 且 $m=0$ 时，输入结束，这组数据不需要处理。

# 输出格式

对于每组测试数据，输出一行，包含一个整数，表示最终的疑似感染者数量。

# 样例输入

```text
100 4
2 1 2
5 10 13 11 12 14
2 0 1
2 99 2
200 2
1 5
5 1 2 3 4 5
1 0
0 0
```

# 样例输出

```text
4
1
1
```

# 题目分析

同一团体中的学生具有共同的疑似感染状态：只要其中一人成为疑似感染者，其余成员也会被认定为疑似感染者。不同团体之间还会通过共同成员产生联系。例如，某个团体包含学生 $0$ 和学生 $1$，另一个团体包含学生 $1$ 和学生 $2$，那么学生 $0$ 的疑似感染状态会先扩展到学生 $1$，再扩展到学生 $2$。因此，不能只统计直接与学生 $0$ 同属一个团体的学生，还必须考虑通过多个团体形成的间接联系。

将每名学生视为一个顶点，同一团体内的成员之间具有连接关系，疑似感染状态就会沿着这些连接传播。最终的疑似感染者恰好是与学生 $0$ 位于同一个连通分量中的所有学生。这个结论同时包含两个方向：与学生 $0$ 连通的学生，都能通过一条由共同团体关系构成的路径被逐步认定为疑似感染者；与学生 $0$ 不连通的学生所在分量没有初始疑似感染者，也没有通向学生 $0$ 的传播路径，因此不会被认定为疑似感染者。

本题只需要维护学生之间是否连通，无需保存具体的接触路径，因此使用并查集。每个集合代表一个已经建立联系的学生群体，读入一个团体时，将其全部成员合并到同一个集合。对于包含 $k$ 名成员的团体，只需选定其中一名成员，将其与其余 $k-1$ 名成员分别合并，就能使整个团体连通，无需枚举团体内的所有成员对。所有团体处理完成后，统计与学生 $0$ 属于同一个集合的学生数量，即为答案。

# 解题思路

首先初始化并查集，让每名学生单独构成一个集合。数组 $\textit{parent}$ 记录各个结点的父结点，初始时满足 $\textit{parent}[i]=i$；数组 $\textit{ranks}$ 记录按秩合并所需的秩，初始值均为 $0$。集合的根结点作为该集合的代表，同一集合中的所有学生通过查找操作得到相同的根结点。

随后依次读入各个团体。代码将当前团体的首名成员记为 $z_1$，再依次读入其余成员 $z_2$，并合并 $z_1$ 与 $z_2$ 所在的集合。合并操作首先查找两个成员各自的根结点；若根结点相同，说明它们已经连通，无需修改；若根结点不同，就将秩较小的根连接到秩较大的根。两个根的秩相等时，将其中一个连接到另一个，并将保留的根的秩增加 $1$。团体只有一名成员时，不执行合并，该学生仍然通过已有关系归属于对应集合。

为了提高查找效率，代码在 $\texttt{findSet}$ 函数中使用路径压缩。查找某个结点所属集合的根时，递归访问其父结点，并在返回时将沿途结点直接连接到根结点。路径压缩与按秩合并共同降低了后续查找和合并操作的开销。需要注意，合并完成后，学生 $0$ 所在集合的根结点不一定仍然是 $0$，因此判断某名学生是否属于疑似感染者集合时，必须比较双方查找得到的根，而不能直接判断其根是否等于 $0$。

处理完全部团体后，遍历所有学生。对于学生 $i$，若其集合代表与学生 $0$ 的集合代表相同，就将计数增加 $1$。学生 $0$ 本身也参与统计，因此即使没有任何团体，答案仍然为 $1$。整个过程中，每次合并只连接同一团体的成员，不会引入无关的连通关系；同时，每个团体的所有成员都被合并，团体之间通过共同成员产生的联系也会自动传递。因此，最终并查集中的集合恰好对应全部团体关系形成的连通分量，统计结果就是全部疑似感染者的数量。

样例的首组数据中，学生 $0$ 与学生 $1$ 同属一个团体，学生 $1$ 又与学生 $2$ 同属一个团体，学生 $2$ 再与学生 $99$ 同属一个团体，因此最终疑似感染者为学生 $0$、学生 $1$、学生 $2$ 和学生 $99$，总数为 $4$。第二组数据中，学生 $0$ 没有通过任何团体与其他学生建立联系，答案为 $1$。最后一组数据没有团体，唯一的学生 $0$ 是初始疑似感染者，答案同样为 $1$。

设所有团体名单中出现的成员总数为 $S$，重复参加不同团体的学生按出现次数计入。初始化和最终遍历涉及 $O(n)$ 个元素，读取团体信息需要 $O(m+S)$ 时间，合并次数为 $O(S)$。采用路径压缩和按秩合并后，并查集操作的均摊时间复杂度为 $O(\alpha(n))$，其中 $\alpha$ 为反阿克曼函数，因此每组数据的总时间复杂度为 $O(m+(n+S)\alpha(n))$。父结点数组和秩数组占用 $O(n)$ 空间，按秩合并下递归查找的栈深度为 $O(\log n)$，总空间复杂度为 $O(n)$。

```cpp
#include <bits/stdc++.h>

using namespace std;

const int MAXV = 30010;

int parent[MAXV], ranks[MAXV];

void makeSet(int n)
{
    for (int i = 0; i < n; i++) parent[i] = i, ranks[i] = 0;
}

// 带路径压缩的查找，使用递归实现。
int findSet(int x)
{
    return (x == parent[x] ? x : parent[x] = findSet(parent[x]));
}

//  集合的按秩合并。
bool unionSet(int x, int y)
{
    x = findSet(x), y = findSet(y);
    if (x != y) {
        if (ranks[x] > ranks[y]) parent[y] = x;
        else {
            parent[x] = y;
            if (ranks[x] == ranks[y]) ranks[y]++;
        }
        return true;
    }
    return false;
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int n, m, k, z1, z2;
    while (cin >> n >> m, n > 0)
    {
        makeSet(n);
        for (int i = 1; i <= m; i++)
        {
            cin >> k >> z1;
            for (int j = 2; j <= k; j++)
            {
                cin >> z2;
                unionSet(z1, z2);
            }
        }
        int cnt = 0;
        for (int i = 0; i < n; i++)
            if (findSet(i) == findSet(0))
                cnt++;
        cout << cnt << '\n';
    }
    return 0;
}
```

# 总结

本题将团体内部的疑似感染扩展规则转化为连通关系，最终答案就是学生 $0$ 所在连通分量的大小。处理一个团体时，将首名成员与其余成员分别合并，即可用线性于成员数量的操作建立整个团体的联系。路径压缩与按秩合并保证了并查集的处理效率，而通过查找集合代表进行比较，则保证了根结点发生变化后仍能正确判断学生之间的连通性。
