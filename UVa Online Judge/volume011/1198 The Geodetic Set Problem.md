
> **摘要**：本文讨论无向简单图中「测地集」的判定问题——给定顶点子集 $D$，判断所有 $D$ 中端点对的最短路径顶点并集是否覆盖全图。文章从测地集定义出发，指出多条等长最短路径必须全部计入覆盖范围，并利用 $\textit{dist}[u][x]+\textit{dist}[x][v]=\textit{dist}[u][v]$ 刻画顶点位于最短路径上的充要条件。实现上采用 $\texttt{Floyd}$ 算法预处理距离，同时为每个顶点对维护一个「分解顶点列表」：距离严格变短时清空重建，距离相等时追加记录，从而完整保留等长最短路径信息；查询时枚举集合内所有有序端点对并递归展开分解关系，标记全部覆盖顶点。预处理复杂度 $O(n^3)$，单次查询上界 $O(n^4)$，空间 $O(n^3)$。

 # 题目描述

给定一个连通的无向简单图 $G=(V,E)$，其中 $V$ 为顶点集合，$E$ 为边集合。任意两个顶点 $u,v$ 之间的距离，定义为它们之间最短路径所包含的边数。

记 $I(u,v)$ 为所有位于某条 $u$ 到 $v$ 的最短路径上的顶点组成的集合，包含端点 $u,v$。若两个顶点之间存在多条最短路径，则这些最短路径上的顶点都属于 $I(u,v)$。

对于顶点集合 $D\subseteq V$，定义：
$$
I(D)=\bigcup_{u,v\in D}I(u,v)
$$
若 $I(D)=V$，则称 $D$ 为图的测地集。

给出图以及若干个顶点子集，判断每个子集是否为测地集。

# 输入格式

每个图的数据首先包含一个整数 $n$，表示顶点数量，满足 $2\le n\le 40$。图中的顶点编号为 $1$ 到 $n$。

接下来 $n$ 行，第 $i$ 行列出与顶点 $i$ 相邻的所有顶点编号。同一行中的整数之间至少有一个空格，每行不包含相邻顶点的数量。

随后一行包含一个整数 $q$，表示需要判断的顶点子集数量。接下来 $q$ 行，每行列出一个顶点子集 $D$ 中的全部顶点编号，同样不包含集合大小。

所给代码持续读取图的数据，直到输入结束。

# 输出格式

对于每个顶点子集，若它是测地集，输出一行 $\texttt{yes}$；否则输出一行 $\texttt{no}$。

# 样例输入

```text
5
2 3
1 3 4
1 2 5
2 5
3 4
6
1 2 3 4 5
1 2 5
2 4
1 3 4
1 4 5
3 4 5
```

# 样例输出


# 题目分析

判断测地集的关键在于覆盖所有最短路径上的顶点，而不是只选择每对端点之间的一条最短路径。若两个顶点之间存在多条等长的最短路径，不同路径上的顶点都需要计入覆盖范围。例如，样例中顶点 $2$ 到顶点 $5$ 存在路径 $2\to3\to5$ 和 $2\to4\to5$，两条路径长度均为 $2$，因此 $I(2,5)=\{2,3,4,5\}$。只记录其中一条路径会漏掉另一条路径上的顶点，进而影响测地集的判断。

设 $\textit{dist}[u][v]$ 表示顶点 $u$ 到顶点 $v$ 的最短距离。顶点 $x$ 位于某条 $u$ 到 $v$ 的最短路径上，当且仅当：
$$
\textit{dist}[u][x]+\textit{dist}[x][v]=\textit{dist}[u][v]
$$
等式成立时，将 $u$ 到 $x$ 的最短路径与 $x$ 到 $v$ 的最短路径连接起来，长度恰好等于 $u$ 到 $v$ 的最短距离，因此能够覆盖顶点 $x$。反过来，将一条经过 $x$ 的最短路径在 $x$ 处分开，得到的两段也必须分别为最短路径，所以等式必然成立。这一性质揭示了最短路径的递归分解结构。

所给代码使用 $\texttt{Floyd}$ 算法计算所有顶点对之间的最短距离，同时记录能够参与最短路径分解的中间顶点。与只保存一个中间顶点的路径还原方式不同，代码为每个顶点对保存一个中间顶点列表：发现更短路径时清空旧记录，发现等长路径时追加记录。查询时，枚举集合中的所有端点对，递归展开这些分解关系，将涉及的顶点全部标记。最终所有顶点都被标记，便说明该集合是测地集。

# 解题思路

首先建立距离矩阵。对于图中存在的无向边 $(u,v)$，令 $\textit{dist}[u][v]=\textit{dist}[v][u]=1$；对于每个顶点 $u$，令 $\textit{dist}[u][u]=0$；其余距离初始化为足够大的值。由于邻接表和查询集合都没有给出各行的元素数量，代码按整行读取，再通过字符串流解析其中的顶点编号，确保每一行对应一个完整的邻接表或查询集合。

随后执行 $\texttt{Floyd}$ 算法，按顺序枚举中间顶点 $k$ 以及两个端点 $i,j$。使用列表 $\textit{parent}[i][j]$ 保存当前最短路径的分解顶点。若经过 $k$ 得到的距离严格更短，就更新距离、清空原列表，并将 $k$ 加入列表；若经过 $k$ 得到的距离与当前距离相等，则保留原列表并追加 $k$。相应的距离更新为：
$$
\textit{dist}[i][j]
\leftarrow
\min\left(\textit{dist}[i][j],\textit{dist}[i][k]+\textit{dist}[k][j]\right)
$$
严格变短时清空列表，保证已经失去最优性的分解记录不再保留；距离相等时追加记录，保证不同最短路径提供的覆盖信息都能参与后续搜索。

对于每个查询，先清空顶点覆盖数组 $\textit{visited}$ 和分解访问数组 $\textit{used}$，再枚举查询集合中的所有有序端点对 $(s,e)$，调用 $\texttt{dfs}$ 函数。搜索顶点对 $(i,j)$ 时，遍历 $\textit{parent}[i][j]$ 中的每个分解顶点 $v$。若三元组 $(i,j,v)$ 尚未处理，就将其标记为已处理，并将顶点 $v$ 标记为已覆盖，然后分别递归处理 $(i,v)$ 和 $(v,j)$，继续展开两段最短路径。这样既记录当前分解顶点，也逐步覆盖各段最短路径中的其他顶点。

代码中的分解列表包含端点本身。因为 $\textit{dist}[i][i]=0$，所以始终有：

$$
\textit{dist}[i][j]=
\textit{dist}[i][i]+\textit{dist}[i][j]=
\textit{dist}[i][j]+\textit{dist}[j][j]
$$

因此，端点也会作为等长分解顶点被记录，并在搜索中得到覆盖。查询还会枚举形如 $(s,s)$ 的端点对，所以集合中的顶点本身同样会被标记，无需单独进行初始化。包含端点的分解会使递归再次进入相同的顶点对，$\textit{used}[i][j][v]$ 在递归前完成标记，保证每个分解三元组只展开一次，从而阻止重复展开并保证搜索终止。

上述过程与测地集的定义完全对应：最短路径上的分解顶点及其两段子路径都属于同一对端点的最短路径覆盖范围，递归展开不会加入范围之外的顶点；等长分解全部得到保留，递归又会继续处理每一段最短路径，因此所有最短路径上的顶点都能被覆盖。枚举查询集合中的所有端点对后，$\textit{visited}$ 记录的正是 $I(D)$。检查编号为 $1$ 到 $n$ 的顶点是否全部被标记，即可输出判断结果。覆盖过程中得到的新顶点只用于路径展开，不会作为查询集合的新成员再次任意配对，这与定义中端点必须来自原集合 $D$ 的要求一致。

样例中的集合 $\{1,2,5\}$ 能覆盖所有顶点：集合中的顶点自身被覆盖，顶点 $3$ 位于顶点 $1$ 到顶点 $5$ 的最短路径上，顶点 $4$ 位于顶点 $2$ 到顶点 $5$ 的一条最短路径上，因此输出 $\texttt{yes}$。集合 $\{2,4\}$ 的两个顶点直接相邻，其最短路径只包含这两个顶点，无法覆盖全图，因此输出 $\texttt{no}$。集合 $\{3,4,5\}$ 的所有端点对最短路径都无法覆盖顶点 $1$，同样输出 $\texttt{no}$。

预处理的 $\texttt{Floyd}$ 算法需要 $O(n^3)$ 时间，每个顶点对最多记录 $n$ 个分解顶点，全部分解列表占用 $O(n^3)$ 空间。对于单个查询，最多有 $O(n^3)$ 个分解三元组被首次处理，每次首次处理至多产生两次递归调用；每次调用又会扫描一个长度为 $O(n)$ 的列表，因此按照所给实现，单个查询的时间复杂度上界为 $O(n^4)$，总时间复杂度上界为 $O(n^3+qn^4)$。分解列表、三维访问数组及递归栈的空间均不超过 $O(n^3)$，因此总空间复杂度为 $O(n^3)$。

# 代码实现

```cpp
// The Geodetic Set Problem
// UVa ID: 1198

// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXV = 64, INF = 0x3f3f3f3f;

int n, q, dist[MAXV][MAXV], visited[MAXV], used[MAXV][MAXV][MAXV];
vector<int> parent[MAXV][MAXV];
string line;

void dfs(int i, int j)
{
    for (auto v : parent[i][j])
    {
        if (used[i][j][v]) continue;
        used[i][j][v] = 1;
        visited[v] = 1;
        dfs(i, v);
        dfs(v, j);
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    while (cin >> n)
    {
        cin.ignore(1024, '\n');
        memset(dist, 0x3f, sizeof(dist));
        for (int u = 1, v; u <= n; u++)
        {
            getline(cin, line);
            istringstream iss(line);
            while (iss >> v) dist[u][v] = dist[v][u] = 1;
            dist[u][u] = 0;
        }
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                parent[i][j].clear();
        for (int k = 1; k <= n; k++)
            for (int i = 1; i <= n; i++)
                for (int j = 1; j <= n; j++)
                {
                    if (dist[i][j] > dist[i][k] + dist[k][j])
                    {
                        dist[i][j] = dist[i][k] + dist[k][j];
                        parent[i][j].clear();
                        parent[i][j].push_back(k);
                    }
                    else if (dist[i][j] == dist[i][k] + dist[k][j])
                    {
                        parent[i][j].push_back(k);
                    }
                }
        cin >> q;
        cin.ignore(1024, '\n');
        for (int i = 1, v; i <= q; i++)
        {
            getline(cin, line);
            istringstream iss(line);
            vector<int> vertices;
            while (iss >> v) vertices.push_back(v);
            memset(used, 0, sizeof(used));
            memset(visited, 0, sizeof(visited));
            for (auto s : vertices)
                for (auto e : vertices)
                    dfs(s, e);
            if (count(visited + 1, visited + n + 1, 0) == 0)
                cout << "yes\n";
            else
                cout << "no\n";
        }
    }
    return 0;
}
```

# 总结

本题将测地集的判断转化为集合内所有端点对的最短路径顶点覆盖问题。核心是完整保留等长最短路径的分解信息，再通过递归展开求出覆盖并集。实现时，严格变短需要清空旧分解，距离相等需要追加新分解，递归展开前需要标记已处理的分解三元组。掌握最短距离等式与最短路径分解之间的联系，就能准确处理多条最短路径共同参与覆盖的情况。
