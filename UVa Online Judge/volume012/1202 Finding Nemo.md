
> **摘要**：给定由平行于坐标轴的墙壁与门构成的迷宫，以及 $\texttt{Nemo}$ 的位置，要求从起点 $(0,0)$ 出发到达 $\texttt{Nemo}$ 处最少需要经过多少扇门，无法到达则输出 $-1$。核心思路是把每个单位方格视为图上的顶点，墙壁和门作为相邻方格之间的通行限制：自由移动代价为 $0$，穿门代价为 $1$，墙壁禁止通行，从而将问题转化为非负边权图上的最短路径问题，用 $\texttt{Dijkstra}$ 算法求解。时间复杂度为 $O(T+N+S^2\log(S^2))$，其中 $S=201$。

 # 题目描述

$\texttt{Nemo}$ 独自进入深海后迷失了方向，向父亲 $\texttt{Marlin}$ 发出了求救信号。海底由若干墙壁和门构成迷宫，所有墙壁都平行于坐标轴，厚度视为 $0$。每扇门都开在墙上，长度固定为 $1$。

$\texttt{Marlin}$ 从 $(0,0)$ 出发，能够在没有墙壁阻挡的区域自由移动，也能够穿过墙上的门，但不能直接穿过墙壁。由于经过门存在危险，他希望在到达 $\texttt{Nemo}$ 所在位置的过程中，经过的门数尽可能少。

给定墙壁、门以及 $\texttt{Nemo}$ 的位置，求最少需要经过多少扇门。如果无法到达，输出 $-1$。

# 输入格式

输入包含多组测试数据。

每组数据首先包含两个非负整数 $M$ 和 $N$，分别表示墙壁数量和门的数量。

接下来 $M$ 行，每行包含四个整数 $x,y,d,t$，描述一面墙壁。其中，$(x,y)$ 为墙壁的左下端点，$t$ 为墙壁长度，$d$ 表示方向：

- 当 $d=0$ 时，墙壁平行于横轴，从 $(x,y)$ 延伸到 $(x+t,y)$。
- 当 $d=1$ 时，墙壁平行于纵轴，从 $(x,y)$ 延伸到 $(x,y+t)$。

所有墙壁端点的坐标均在 $[1,199]$ 范围内。

接下来 $N$ 行，每行包含三个整数 $x,y,d$，描述一扇门。各参数含义与墙壁相同，门的长度固定为 $1$，因此省略长度参数。

随后一行包含两个正浮点数 $f_1,f_2$，表示 $\texttt{Nemo}$ 的位置 $(f_1,f_2)$。该位置不在任何墙壁或门上。

当读入 $M=-1$ 且 $N=-1$ 时，输入结束，这组数据不需要处理。

# 输出格式

对于每组测试数据，输出一行，表示到达 $\texttt{Nemo}$ 所在位置最少需要经过的门数。

如果无法到达，输出 $-1$。

# 题目分析

本题要求最少经过的门数，移动距离本身不产生代价。因此，沿着空旷区域移动的代价为 $0$，穿过一扇门的代价为 $1$，遇到没有门的墙壁则禁止通行。将这些移动关系转化为图上的边之后，问题就是求非负边权图中的最短路径，路径权值之和恰好等于经过的门数。

建图的关键是区分网格中的区域与网格交点。墙壁位于整数坐标构成的网格线上，因此使用单位方格作为图中的顶点。编号为 $(i,j)$ 的顶点代表横坐标介于 $i$ 与 $i+1$、纵坐标介于 $j$ 与 $j+1$ 的方格内部。每个方格只与上、右、下、左四个相邻方格建立移动关系，两个方格之间的公共边决定能否移动以及移动代价。这样，墙壁和门都作用于方格之间的连接，而不是占据某个方格。

对于长度为 $1$、起点为 $(x,y)$ 的水平线段，它分隔的是方格 $(x,y-1)$ 与 $(x,y)$；对于长度为 $1$、起点为 $(x,y)$ 的竖直线段，它分隔的是方格 $(x-1,y)$ 与 $(x,y)$。若线段是墙壁，就禁止两侧方格相互通行；若线段是门，就允许双向通行，并将代价设为 $1$。一面长度为 $t$ 的墙壁需要拆成 $t$ 段单位线段处理。由于门开在墙上，必须先设置墙壁，再用门的信息覆盖相应位置的阻断关系。

目标位置对应的方格通过向下取整得到：
$$
n_x=\lfloor f_1\rfloor,\qquad n_y=\lfloor f_2\rfloor
$$
目标不位于墙壁或门上，因此这一映射能够正确表示目标所属的可通行区域。起点 $(0,0)$ 位于所有墙壁之外，使用方格 $(0,0)$ 作为起始状态。墙壁端点坐标不超过 $199$，代码保留横纵编号均为 $0$ 到 $200$ 的方格，为绕过全部墙壁留下外围通道。若目标方格超出该范围，则目标处于所有障碍之外，与起点之间存在不经过任何门的路线，答案为 $0$。

# 解题思路

首先初始化网格的四个方向。代码使用方向编号 $0,1,2,3$ 分别表示上、右、下、左，并用数组 $\textit{edges}[i][j][k]$ 表示从方格 $(i,j)$ 沿方向 $k$ 移动的状态：值为 $-1$ 表示禁止通行，值为 $0$ 表示自由通行，值为 $1$ 表示需要经过一扇门。初始时所有内部连接的代价均为 $0$，再将网格最外侧指向范围之外的方向设为 $-1$，保证搜索不会越界。

读入墙壁时，逐段修改相邻方格之间的双向连接。对于水平墙壁 $(x,y,0,t)$，枚举 $0\le j<t$，将方格 $(x+j,y)$ 向下以及方格 $(x+j,y-1)$ 向上的连接都设为 $-1$；对于竖直墙壁 $(x,y,1,t)$，将方格 $(x,y+j)$ 向左以及方格 $(x-1,y+j)$ 向右的连接都设为 $-1$。随后读入门，将对应的双向连接改为 $1$。双向同步修改保证了从墙壁任意一侧观察时，通行规则都一致。

建图完成后，调用 $\texttt{mooreDijkstra}$ 函数执行 $\texttt{Dijkstra}$ 算法。距离数组 $\textit{dist}[i][j]$ 表示从起点到达方格 $(i,j)$ 最少经过的门数，初始设为 $-1$，表示尚未到达，再将 $\textit{dist}[0][0]$ 设为 $0$。优先队列按照累计门数从小到大取出状态，并检查其四个方向。对于允许通行的相邻方格，设当前方格为 $u$、相邻方格为 $v$、移动代价为 $w(u,v)$，若相邻方格尚未到达，或者满足：
$$
\textit{dist}[v]>\textit{dist}[u]+w(u,v)
$$
就更新其距离，并将新状态加入优先队列。搜索结束后，范围内目标方格的距离就是答案；若距离仍为 $-1$，则目标不可达。代码允许同一方格因距离更新而多次进入队列，每次扩展均使用距离数组中保存的当前值。

这一方法的正确性建立在区域划分与路径代价的一致性上。任意合法行走路线经过相邻方格时，都对应一条允许通行的图边；没有墙壁的边代价为 $0$，门对应的边代价为 $1$，所以图路径的权值等于实际经过的门数。反过来，图中的每条允许通行的边都对应一次合法的方格间移动，因此图路径也能还原为合法路线。所有边权均非负，$\texttt{Dijkstra}$ 算法求出的最短路径权值就是最少经过的门数。

设网格边长为 $S$，所有墙壁的长度之和为 $T$。网格共有 $S^2$ 个顶点，每个顶点最多连接 $4$ 个邻点，因此边数为 $O(S^2)$。初始化需要 $O(S^2)$ 时间，设置墙壁和门需要 $O(T+N)$ 时间，使用优先队列求最短路径需要 $O(S^2\log(S^2))$ 时间，总时间复杂度为：
$$
O\bigl(T+N+S^2\log(S^2)\bigr)
$$
连接数组、距离数组和优先队列所需的空间均为 $O(S^2)$，因此空间复杂度为 $O(S^2)$。本代码中 $S=201$。

# 代码实现

结构体 $\texttt{edge}$ 保存待处理方格及其入队时的距离，并通过重载比较运算符，使优先队列优先取出距离较小的状态。数组 $\textit{edges}$ 保存相邻方格之间的通行状态，数组 $\textit{dist}$ 保存最少经过的门数。以下为获得通过的代码。

```cpp
// Finding Nemo
// UVa ID: 1202
// Verdict: Accepted
// Submission Date: 2018-02-08
// UVa Run Time: 0.020s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXV = 201;

struct edge
{
    int x, y, weight;
    edge (int x = 0, int y = 0, int weight = 0): x(x), y(y), weight(weight) {}
    bool operator<(const edge &e) const { return weight > e.weight; }
};

int edges[MAXV][MAXV][4];
int dist[MAXV][MAXV];
int offset[4][2] = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

void mooreDijkstra()
{
    for (int i = 0; i < MAXV; i++)
        for (int j = 0; j < MAXV; j++)
            dist[i][j] = -1;
    dist[0][0] = 0;
    priority_queue<edge> q;
    q.push(edge(0, 0, 0));
    while (!q.empty())
    {
        edge v = q.top(); q.pop();
        for (int k = 0; k < 4; k++)
            if (edges[v.x][v.y][k] >= 0)
            {
                int nextx = v.x + offset[k][0], nexty = v.y + offset[k][1];
                if (dist[nextx][nexty] < 0 || dist[nextx][nexty] > dist[v.x][v.y] + edges[v.x][v.y][k])
                {
                    dist[nextx][nexty] = dist[v.x][v.y] + edges[v.x][v.y][k];
                    q.push(edge(nextx, nexty, dist[nextx][nexty]));
                }
            }
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int M, N, x, y, d, t, nemox, nemoy;
    double f1, f2;
    while (cin >> M >> N, M >= 0)
    {
        memset(edges, 0, sizeof(edges));
        for (int i = 0; i < MAXV; i++)
        {
            edges[0][i][3] = -1;
            edges[i][0][2] = -1;
            edges[i][MAXV - 1][0] = -1;
            edges[MAXV - 1][i][1] = -1;
        }
        for (int i = 0; i < M; i++)
        {
            cin >> x >> y >> d >> t;
            // Horizontal
            if (d == 0)
            {
                for (int j = 0; j < t; j++)
                {
                    edges[x + j][y][2] = edges[x + j][y - 1][0] = -1;
                }
            }
            // Vertical
            else
            {
                for (int j = 0; j < t; j++)
                {
                    edges[x][y + j][3] = edges[x - 1][y + j][1] = -1;
                }
            }
        }
        for (int i = 0; i < N; i++)
        {
            cin >> x >> y >> d;
            if (d == 0)
            {
                edges[x][y][2] = edges[x][y - 1][0] = 1;
            }
            else
            {
                edges[x][y][3] = edges[x - 1][y][1] = 1;
            }
        }
        cin >> f1 >> f2;
        nemox = (int)floor(f1), nemoy = (int)floor(f2);
        mooreDijkstra();
        if (nemox < MAXV && nemoy < MAXV)
            cout << dist[nemox][nemoy] << '\n';
        else
            cout << 0 << '\n';
    }
    return 0;
}
```

# 总结

本题的关键是将单位方格作为顶点，将墙壁和门作为相邻方格之间的通行限制。自由移动的代价为 $0$，穿门的代价为 $1$，墙壁禁止通行，由此将最少穿门问题转化为非负边权最短路径问题。实现时需要准确对应水平、竖直线段两侧的方格，双向更新连接，并在读入墙壁后用门覆盖相应位置。利用障碍物的坐标范围保留外围通道，再通过 $\texttt{Dijkstra}$ 算法求解，就能得到最少经过的门数并判断目标是否可达。
