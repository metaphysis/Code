
> **摘要**：本题要求模拟数据流管理系统中多个周期性查询的返回过程。每条查询注册后按固定周期不断返回结果，需要输出前 $K$ 次返回结果对应的查询编号，返回时间相同时按编号升序排列。核心做法是用优先队列维护所有查询的下一次返回事件，每次取出最早事件、输出编号并将时间加上周期后重新入队，时间复杂度为 $O\bigl((R+K)\log R\bigr)$。

# 题目描述

$\texttt{Argus}$ 是一个数据流管理系统，用户可以向系统注册多个周期性查询。每条查询由查询编号和返回周期组成，注册后经过对应的周期时间，查询第一次返回结果，之后每隔相同的周期时间返回一次结果。

给定所有已经注册的查询，要求按照实际返回时间的先后顺序，输出前 $K$ 次返回结果对应的查询编号。

如果多个查询在同一时刻返回结果，则按照查询编号从小到大的顺序依次输出。

# 输入格式

输入分为两个部分。

第一部分包含若干条注册指令，每条指令占一行，格式如下：

```text
Register Q_num Period
```

其中，$Q_{\text{num}}$ 表示查询编号，满足 $0<Q_{\text{num}}\le 3000$；$\textit{Period}$ 表示返回周期，满足 $0<\textit{Period}\le 3000$。所有查询编号互不相同，注册指令数量不超过 $1000$。

当读入一行内容为 `#` 时，第一部分结束。

第二部分只有一行，包含一个正整数 $K$，满足 $K\le 10000$，表示需要输出的返回结果数量。

# 输出格式

输出 $K$ 行。

每行输出一次返回结果对应的查询编号。输出顺序必须按照返回时间递增排列；当返回时间相同时，按照查询编号递增排列。

# 样例输入

```text
Register 2004 200
Register 2005 300
#
5
```

# 样例输出

```text
2004
2005
2004
2004
2005
```

# 题目分析

每条查询都具有固定的返回周期。对于查询编号为 $q$、周期为 $p$ 的查询，它的返回时间序列为：

$$
p,2p,3p,\ldots
$$

因此，查询注册时产生的第一次事件时间为 $p$。当某次事件被输出后，该查询的下一次事件时间只需要在当前时间的基础上加上周期 $p$。

本题需要不断从所有查询的下一次返回事件中选择最早的一次。选择规则包含两个关键条件：

- 返回时间较小的事件优先。
- 返回时间相同时，查询编号较小的事件优先。

这两个条件构成了事件的完整排序关系。使用优先队列维护所有查询当前的下一次返回事件，就可以在每次操作中直接取出最优事件。取出查询后，输出其编号，并将它的下一次返回时间增加一个周期，再放回优先队列。重复执行 $K$ 次即可得到答案。

优先队列中的每个元素包含查询编号、当前下一次返回时间和固定周期三个信息。排序时先比较当前返回时间，再比较查询编号。代码通过重载结构体 $\texttt{query}$ 的比较运算符实现这一规则。由于标准库优先队列默认将“较大”元素放在顶部，因此代码将比较结果反向设置，使返回时间较小、查询编号较小的元素位于队首。

# 解题思路

首先读取每条注册指令。指令的第一个单词是 `Register`，随后读取查询编号 $\textit{id}$ 和周期 $\textit{period}$。该查询第一次返回发生在 $\textit{period}$ 时刻，因此将其当前返回时间 $\textit{seconds}$ 初始化为 $\textit{period}$，并将查询对象加入优先队列。

读入结束标记 `#` 后，再读取需要输出的次数 $K$。每次从优先队列顶部取出一个查询对象：

- 输出该查询的编号 $\textit{id}$。
- 将其下一次返回时间 $\textit{seconds}$ 增加固定周期 $\textit{period}$。
- 将更新后的查询重新加入优先队列。

设某次取出的查询当前返回时间为 $s$，周期为 $p$，更新后时间为：

$$
s'=s+p
$$

这样可以保证该查询的后续返回事件按照周期规律持续产生。由于优先队列在每次操作前都包含所有查询的下一次返回事件，因此取出的事件始终符合题目的时间与编号排序要求。

算法的正确性可以从以下方面说明。首先，每个查询在优先队列中始终只保留它尚未输出的最早一次返回事件。初始时该事件时间为查询周期，符合第一次返回规则；每次输出后将时间增加一个周期，得到该查询的下一次返回时间，因此这一性质始终成立。其次，优先队列按照返回时间升序、查询编号升序选择队首元素，所以每次取出的事件都是当前所有未输出事件中应最先发生的事件。最后，输出后重新加入同一查询的下一次事件，继续维护所有查询的最早未输出事件，因此连续执行 $K$ 次后得到的正是前 $K$ 次返回结果。

设注册查询数量为 $R$。建立优先队列需要将 $R$ 个元素逐个插入，时间复杂度为 $O(R\log R)$。每次输出需要执行一次删除队首和一次重新插入，单次时间复杂度为 $O(\log R)$，共执行 $K$ 次，因此处理输出的时间复杂度为 $O(K\log R)$。总时间复杂度为：

$$
O\bigl((R+K)\log R\bigr)
$$

优先队列最多保存 $R$ 个查询对象，因此空间复杂度为：

$$
O(R)
$$

# 代码实现

代码中的 $\texttt{query}$ 结构体保存查询编号、下一次返回时间和固定周期。比较函数首先按照返回时间排序，在返回时间相同时按照查询编号排序。主函数负责读取注册指令，并通过优先队列模拟前 $K$ 次返回事件。

```cpp
// Argus
// UVa ID: 1203
// Verdict: Accepted
// Submission Date: 2018-01-07
// UVa Run Time: 0.000s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

struct query
{
    int id, seconds, period;
    bool operator<(const query &q) const
    {
        if (seconds != q.seconds) return seconds > q.seconds;
        return id > q.id;
    }
};

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    string command;
    int id, period;
    priority_queue<query> q;
    
    while (cin >> command)
    {
        if (command.front() == '#') break;
        cin >> id >> period;
        q.push(query{id, period, period});
    }
    
    int k;
    cin >> k;
    while (k--)
    {
        query qy = q.top(); q.pop();
        cout << qy.id << '\n';
        qy.seconds += qy.period;
        q.push(qy);
    }
    
    return 0;
}
```

# 总结

本题本质上是对多个周期性事件进行多路归并。每个查询对应一个按照固定周期递增的事件序列，优先队列负责维护所有序列当前尚未输出的最小事件。

实现时需要注意以下关键点：

- 查询的第一次返回时间等于其周期。
- 每次输出后，只需将当前时间增加一个周期。
- 排序首先比较返回时间，返回时间相同时比较查询编号。
- 输出一个事件后，必须将该查询的下一次事件重新加入优先队列。
- 使用优先队列可以将每次选择事件的复杂度控制为 $O(\log R)$。

通过维护每个查询的下一次返回事件，整个问题能够以清晰且高效的方式完成。
