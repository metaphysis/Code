
> **摘要**：本文讨论带树形优先约束的单机调度问题：给定一棵 $N$ 个节点的有根树，每个节点有权值 $C_i$，要求父节点先于子节点染色，最小化 $\sum C_i F_i$。文章从排序不等式出发说明简单贪心失效，进而推导出以“等效权值”（块内权值之和除以节点个数）为度量的贪心合并性质，给出合并算法、代价增量计算方式与优先队列实现，最终得到 $O(N \log N)$ 的解法，并附完整 $\texttt{C++}$ 代码与样例验证。

## 题目描述

给定一棵 $N$ 个节点的有根树，根节点为 $R$。每个节点 $i$ 有一个染色代价因子 $C_i$。染色过程从时刻 $0$ 开始，每染色一个节点耗时 $1$ 个单位时间。节点 $i$ 的染色完成时刻记为 $F_i$，则节点 $i$ 的染色代价为 $C_i \times F_i$。染色必须满足父节点优先于子节点的约束：一个节点只有在其父节点被染色之后才能被染色。求完成整棵树染色的最小总染色代价。

## 输入格式

输入包含多个测试用例。每个测试用例的第一行包含两个整数 $N$ 和 $R$（$1 \le N \le 1000$，$1 \le R \le N$），分别表示树的节点数和根节点编号。第二行包含 $N$ 个整数，第 $i$ 个整数为节点 $i$ 的染色代价因子 $C_i$（$1 \le C_i \le 500$）。接下来的 $N-1$ 行，每行包含两个节点编号 $V_1$ 和 $V_2$，表示树的一条有向边，其中 $V_1$ 是 $V_2$ 的父节点。所有边均会被列出，且不会重复。输入以 $N=0$ 且 $R=0$ 结束，该行不应被处理。

## 输出格式

对于每个测试用例，输出一行，包含染色所有节点的最小总染色代价。

## 样例

**输入**

```text
5 1
1 2 1 2 4
1 2
1 3
2 4
3 5
0 0
```

**输出**

```text
33
```

## 题目分析

本题的本质是带树形优先约束的单机调度问题。将每个节点视为一个作业，其加工时间均为 $1$ 个单位，权重为 $C_i$，目标是最小化加权完成时间之和 $\sum C_i F_i$，约束为树形优先序。

若没有优先约束，根据排序不等式，最优策略是按照 $C_i$ 从大到小的顺序依次染色。然而树形优先约束的存在使得这一简单贪心失效：一个 $C_i$ 很大的子节点必须等待其父节点先被染色，其间可能插入其他可染色的节点，从而增加该大权值节点的完成时间。因此需要寻找更精细的贪心策略。

> **提示**： $\texttt{Horn}$ 在其论文《$\texttt{Single-Machine Job Sequencing with Treelike Precedence Ordering and Linear Delay Penalties}$》中给出了该问题的有效解法。核心思想是：在最优染色序列中，除根节点外，当前平均权值最大的连通块一旦其父节点被染色，就必须立即被整体染色。基于此性质，可以通过反复合并平均权值最大的节点与其父节点来构造最优序列。

## 解题思路

### 贪心性质的推导

考虑两个已经确定必须连续染色的节点 $x$ 和 $y$（先 $x$ 后 $y$），它们构成一个染色块。另有一个外部节点 $z$，需要决定 $z$ 应该放在该染色块之前还是之后。

两种顺序的代价分别为：

- 顺序 $x \to y \to z$：$C_x + 2C_y + 3C_z$
- 顺序 $z \to x \to y$：$C_z + 2C_x + 3C_y$

两式相减得：

$$(C_x + 2C_y + 3C_z) - (C_z + 2C_x + 3C_y) = 2C_z - (C_x + C_y)$$

当 $2C_z - (C_x + C_y) < 0$，即 $C_z < \dfrac{C_x + C_y}{2}$ 时，顺序 $x \to y \to z$ 更优；否则顺序 $z \to x \to y$ 更优。

由此可知，判断一个染色块与外部节点的相对顺序时，比较的是外部节点的权值 $C_z$ 与染色块的平均权值 $\dfrac{C_x + C_y}{2}$。将这一结论推广到包含多个节点的染色块：一个染色块的整体“等效权值”定义为该块内所有节点 $C_i$ 之和除以块内节点个数。等效权值越大的染色块，在满足优先约束的前提下应当越早被染色。

### 合并算法

基于上述性质，算法流程如下：

规则 $\texttt{1}$. 初始时，每个节点各自构成一个染色块，块的权值总和为 $C_i$，节点个数为 $1$，等效权值为 $C_i$。

规则 $\texttt{2}$. 每次选择除根节点所在块外等效权值最大的染色块，将其与父节点所在的染色块合并。合并时，被选中的块紧跟在父块之后染色。

规则 $\texttt{3}$. 合并后更新父块的总权值（累加子块的总权值）、节点个数（累加子块的节点个数）和等效权值（总权值除以节点个数）。

规则 $\texttt{4}$. 重复规则 $\texttt{2}$ 和规则 $\texttt{3}$，共合并 $N-1$ 次，直到所有节点合并到根节点所在的块中。

### 代价计算

在合并过程中同步计算总染色代价。设当前选中块 $u$ 的父块为 $p$，$p$ 的节点个数为 $\textit{cnt}_p$，$u$ 的总权值为 $\textit{sum}_u$。将 $u$ 整体接在 $p$ 之后染色时，$u$ 中每个节点的完成时刻都会额外增加 $\textit{cnt}_p$ 个单位时间（因为 $p$ 中的节点先被染色），因此总代价增加 $\textit{cnt}_p \times \textit{sum}_u$。

初始时总代价为所有节点 $C_i$ 之和（每个节点至少在时刻 $1$ 被染色，贡献 $C_i \times 1$）。每次合并将上述增量累加到总代价中，最终得到最小总染色代价。

### 数据结构实现

使用优先队列（大根堆）维护所有非根染色块的等效权值，每次取出堆顶元素进行合并。由于合并后父块的等效权值会增大，需要将更新后的父块重新入队。同时需要维护每个节点的父节点关系，以及合并后子节点的子节点需要重新指向父块。

### 复杂度分析

- **时间复杂度**：每次合并操作需要 $O(\log N)$ 时间从优先队列中取出和插入元素，共进行 $N-1$ 次合并，总时间复杂度为 $O(N \log N)$。
- **空间复杂度**：$O(N)$，用于存储树结构和各染色块信息。

## 代码实现

```cpp
// Color a Tree

// 版权所有（C）2021，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXV = 1010;

int N, R, factor[MAXV], ai[MAXV], bi[MAXV];
double ri[MAXV];
vector<int> g[MAXV], s[MAXV];

void dfs(int u) {
    ri[u] = (double)ai[u] / bi[u];
    if (!g[u].size()) return;
    for (auto v : g[u]) {
        dfs(v);
        s[u].push_back(v);
    }
    while (true) {
        int maxI = -1;
        double r = 0;
        for (int i = 0; i < s[u].size(); i++)
            if (ri[s[u][i]] >= r) {
                r = ri[s[u][i]];
                maxI = i;
            }
        if (r < ri[u]) break;
        ai[u] += ai[s[u][maxI]], bi[u] += bi[s[u][maxI]];
        ri[u] = (double)ai[u] / bi[u];
        for (auto v : s[s[u][maxI]]) s[u].push_back(v);
        s[u].erase(s[u].begin() + maxI);
    }
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    while (cin >> N >> R)     {
        if (N == 0) break;
        for (int i = 1; i <= N; i++) { cin >> factor[i]; ai[i] = factor[i]; bi[i] = 1; }
        for (int i = 1; i <= N; i++) { g[i].clear(); s[i].clear(); }
        for (int i = 1, u, v; i < N; i++) {
            cin >> u >> v;
            g[u].push_back(v);
        }
        dfs(R);
        int elapsed = 1, cost = 0;
        priority_queue<pair<double, int>> q;
        q.push(make_pair(ri[R], R));
        while (!q.empty()) {
            pair<double, int> p = q.top(); q.pop();
            cost += elapsed * factor[p.second];
            for (auto v : g[p.second]) q.push(make_pair(ri[v], v));
            elapsed++;
        }
        cout << cost << '\n';
    }
    return 0;
}
```

## 总结

本题的核心技巧是将树形优先约束下的加权完成时间最小化问题，转化为基于“等效权值”的贪心合并问题。关键结论是：除根节点外，等效权值最大的染色块一旦其父块被染色，就必须立即被整体染色。

该解法本质上是 $\texttt{Horn}$ 论文中针对树形优先约束单机调度问题的最优算法的具体实现。通过将节点合并为染色块并维护其平均权值，将复杂的树形约束问题简化为一系列两两比较和合并操作。

值得注意的要点：

- 不能直接按照 $C_i$ 从大到小贪心，该策略存在反例。
- 等效权值（平均值）是决定染色顺序的正确度量。
- 合并时同步累加代价可以避免最后重新构造染色序列。
- 使用优先队列可将时间复杂度优化至 $O(N \log N)$。

本题的贪心策略和合并技巧是处理一类树形优先序调度问题的经典方法，具有广泛的借鉴意义。
