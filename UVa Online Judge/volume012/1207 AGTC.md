
> **摘要**：本文讨论字符串编辑距离问题——给定两个字符串 $x$、$y$（$n \ge m$），允许删除、插入、替换三种代价均为 $1$ 的操作，求将 $x$ 转换为 $y$ 的最少操作次数。文章从问题分析入手，以 $\textit{dp}[i][j]$ 表示将 $x$ 的前 $i$ 个字符转换为 $y$ 的前 $j$ 个字符的最少代价，给出空串边界初始化与三种末尾决策的状态转移方程，并说明其正确性。时间复杂度 $O(mn)$，空间复杂度 $O(mn)$。

 # 题目描述

给定两个由有限字符集中的字符组成的字符串 $x$ 和 $y$，字符串长度分别为 $m$ 和 $n$，其中 $n \ge m$。将字符串 $x$ 转换为字符串 $y$，允许执行以下操作：

- 删除：删除当前字符串中的一个字符。
- 插入：在当前字符串的任意位置插入一个字符。
- 替换：将当前字符串中的一个字符替换为另一个字符。

每次操作的代价均为 $1$，相同字符之间的匹配不产生代价。求完成转换所需的最少操作次数，即两个字符串之间的编辑距离。

# 输入格式

输入包含多组数据，持续读取至文件结束。

每组数据占两行。第一行包含字符串 $x$ 的长度 $m$ 和字符串 $x$；第二行包含字符串 $y$ 的长度 $n$ 和字符串 $y$。长度与字符串之间以空白字符分隔。

# 输出格式

对于每组数据，输出一个整数，表示将字符串 $x$ 转换为字符串 $y$ 所需的最少操作次数。每组结果独占一行。

# 样例输入

```text
10 AGTCTGACGC
11 AGTAAGTAGGC
```

# 样例输出

```text
4
```

# 题目分析

本题要求在删除、插入和替换这三类操作中选择总代价最小的转换方案。仅根据当前位置的字符是否相同来决定操作，无法保证最优，因为插入和删除会改变后续字符的对应关系。例如，当前两个字符不同，既存在直接替换的方案，也存在通过插入或删除，使后续字符重新对齐的方案。因此，需要同时比较这些选择对整体转换代价的影响。字符串的前缀具有明确的递推关系，适合使用动态规划，也就是 $\texttt{DP}$。

设 $\textit{dp}[i][j]$ 表示将字符串 $x$ 的前 $i$ 个字符转换为字符串 $y$ 的前 $j$ 个字符所需的最少操作次数。对于两个非空前缀，按照末尾字符的对应关系划分：若 $x$ 的末尾字符被删除，则问题归结为更短的源串前缀与当前目标前缀之间的转换；若 $y$ 的末尾字符通过插入得到，则问题归结为当前源串前缀与更短的目标前缀之间的转换；若两个末尾字符相互对应，则根据字符是否相同，选择直接匹配或执行替换。这些情况覆盖了所有有效转换方案，并且每种情况都会转移到更短的前缀，因此能够通过较小状态逐步求出完整字符串的答案。

# 解题思路

首先处理空串边界。两个空串之间不需要操作；将长度为 $i$ 的前缀转换为空串，必须删除全部 $i$ 个字符；将空串转换为长度为 $j$ 的前缀，必须插入全部 $j$ 个字符。因此，初始化为：

$$
\textit{dp}[0][0]=0,\qquad
\textit{dp}[i][0]=i\quad(1\le i\le m),\qquad
\textit{dp}[0][j]=j\quad(1\le j\le n)
$$

对于 $i\ge 1$、$j\ge 1$ 的状态，删除源串末尾字符的代价为 $\textit{dp}[i-1][j]+1$；在源串末尾插入目标串末尾字符的代价为 $\textit{dp}[i][j-1]+1$；让两个末尾字符对应的代价，则是在 $\textit{dp}[i-1][j-1]$ 的基础上，根据字符是否相同增加相应费用。定义：

$$
c(i,j)=\begin{cases}
0,&x_{i-1}=y_{j-1},\\
1,&x_{i-1}\ne y_{j-1}.
\end{cases}
$$

这里字符串下标从 $0$ 开始，因此长度为 $i$ 的前缀末尾字符是 $x_{i-1}$，长度为 $j$ 的前缀末尾字符是 $y_{j-1}$。综合三种选择，得到状态转移方程：

$$
\textit{dp}[i][j]=
\min\left(
\textit{dp}[i-1][j]+1,\;
\textit{dp}[i][j-1]+1,\;
\textit{dp}[i-1][j-1]+c(i,j)
\right)
$$

按照前缀长度从小到大的顺序填写状态表，计算当前状态时，其上方、左方和左上方的状态均已确定。对于任意最优的前缀对齐方案，其末尾必然属于删除、插入或匹配与替换中的一种情况；去掉末尾对应的操作后，剩余部分必须是相应子问题的最优方案，否则将其替换为更优方案就会降低总代价，与原方案最优矛盾。因此，上述转移既覆盖全部情况，又在所有情况中取到最小代价，最终答案为 $\textit{dp}[m][n]$。样例中，通过 $3$ 次替换和 $1$ 次插入即可完成转换，最少操作次数为 $4$。

每组数据需要计算 $m\times n$ 个非边界状态，每个状态只进行常数次比较与加法，包含边界初始化后的时间复杂度为 $O(mn+m+n)$；当两个字符串均非空时，记为 $O(mn)$。二维状态表的空间复杂度为 $O((m+1)(n+1))$，非空字符串情况下记为 $O(mn)$。给定代码使用预先分配的 $1024\times1024$ 数组保存状态，实际固定分配 $1024^2$ 个整数单元，要求字符串长度不超过 $1023$。

# 代码实现

代码中的 $\texttt{med}$ 函数根据两个字符串的实际长度初始化边界并计算编辑距离；主函数持续读取数据，每读取一组就输出对应答案。以下保留通过代码的原有内容及注释。

```cpp
// AGTC
// UVa ID: 1207
// Verdict: Accepted
// Submission Date: 2018-03-29
// UVa Run Time: 0.000s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int dp[1024][1024];

int med(string &S, string &T)
{
    dp[0][0] = 0;
    int M = S.length(), N = T.length();
    for (int i = 1; i <= M; i++) dp[i][0] = i;
    for (int j = 1; j <= N; j++) dp[0][j] = j;
    for (int i = 1; i <= M; i++)
        for (int j = 1; j <= N; j++)
        {
            int deleted = dp[i - 1][j] + 1;
            int inserted = dp[i][j - 1] + 1;
            int replaced = dp[i - 1][j - 1];
            if (S[i - 1] != T[j - 1]) replaced = dp[i - 1][j - 1] + 1;
            dp[i][j] = min(min(deleted, inserted), replaced);
        }
    return dp[M][N];
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int n1, n2;
    string s1, s2;
    while (cin >> n1)
    {
        cin >> s1 >> n2 >> s2;
        cout << med(s1, s2) << '\n';
    }

    return 0;
}
```

# 总结

本题的关键是以两个字符串的前缀长度定义状态，将整体转换拆解为删除、插入以及匹配或替换三类末尾决策。空串边界保证递推能够覆盖完整状态范围，按前缀长度递增计算则保证所有依赖均已求解。实现时需要准确区分前缀长度与字符下标，并在每组数据开始时重新初始化边界。该方法是处理字符串编辑距离的标准动态规划方法。
