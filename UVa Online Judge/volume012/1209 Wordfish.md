
> **摘要**：本题给定若干由互不重复大写字母组成的用户名，要求在其字典序排列中取原用户名前后各 $10$ 个共 $21$ 个候选排列，对每个排列计算相邻字符字母距离的最小值，选出该值最大且字典序最小的排列，并将其与最小距离拼接输出。解法利用 `prev_permutation` 与 `next_permutation` 直接构造候选集合，排序后一次扫描即可同时满足评分最大与字典序优先，时间复杂度 $O(KL\log K)$（$K=21$）。

 # 题目描述

给定若干用户名，每个用户名仅由大写英文字母组成，且同一个字母在一个用户名中至多出现一次。密码由用户名的字符排列按照以下规则确定。

按照字典序排列用户名的所有排列，取以原用户名为中间位置的连续 $21$ 个排列，即原用户名、它之前的 $10$ 个排列和它之后的 $10$ 个排列。对于其中的每个排列，计算所有相邻字符之间字母距离的最小值。字母距离定义为两个字母在字母表中的位置之差的绝对值。

选择最小相邻字母距离最大的排列。如果多个排列取得相同的最大值，则选择字典序最小的排列。将选中的排列与其最小相邻字母距离直接拼接，得到该用户名对应的密码。

# 输入格式

输入包含若干行，每行给出一个用户名，读取至文件结束。

每个用户名仅包含大写英文字母，长度不超过 $20$，且不存在重复字母。用户名总数不超过 $12$。

# 输出格式

对于每个用户名，输出一行密码，由选中的排列及其最小相邻字母距离组成，两者之间不添加空格或其他分隔符。

# 样例输入

```text
WORDFISH
```

# 样例输出

```text
WORDHSFI3
```

# 题目分析

设用户名长度为 $L$。由于用户名中的字符互不相同，全部排列共有 $L!$ 个，枚举所有排列会产生大量无关计算。题目只要求检查原用户名附近的 $21$ 个连续排列，因此应直接沿字典序向前、向后生成候选排列。标准库提供的 $\texttt{prev\_permutation}$ 和 $\texttt{next\_permutation}$ 函数分别用于生成字典序中的前一个排列和后一个排列，能够直接完成候选集合的构造。

对于候选排列 $s$，定义其评分为所有相邻字符距离的最小值：
$$
D(s)=\min_{1\le i<L}\left|s_i-s_{i-1}\right|
$$
其中字符下标从 $0$ 开始，字符相减表示对应字母在字母表中的位置之差。题目要求最大化 $D(s)$，而不是最大化所有相邻距离之和，也不是选择某一对字母距离最大的排列。因此，每个排列都必须先完整检查相邻字符，求出其中最小的距离，再与其他排列的评分比较。

评分相同时需要选择字典序最小的排列。将候选集合按字典序升序排序后依次检查，并且仅在评分严格增大时更新答案，就能同时满足评分最大和字典序最小这两个要求。因为相同评分的排列中，字典序最小者最先被访问，后续相同评分不会覆盖它。

# 解题思路

首先将原用户名放入候选集合，并使用两个字符串副本分别维护向前和向后的枚举位置。每轮对前者调用 $\texttt{prev\_permutation}$，对后者调用 $\texttt{next\_permutation}$，将成功生成的排列加入候选集合。在题目规定的以原用户名为中间位置的候选范围内，经过 $10$ 轮扩展，即可得到原用户名及其前后各 $10$ 个排列，共 $21$ 个候选。代码使用集合大小控制扩展，并在一轮中两个方向都未成功生成排列时结束枚举。

随后对候选集合按字典序升序排序。依次遍历每个候选排列，从相邻字符对中计算绝对差，并持续取最小值，得到该排列的评分。将当前最优评分初始化为 $-1$，每当当前排列的评分严格大于已有最优评分时，就同时更新最优评分和答案排列。遍历结束后，直接输出答案排列及最优评分。

这一过程的正确性来自候选枚举与答案维护两个方面。向前、向后逐次生成相邻排列，覆盖题目要求检查的连续排列范围；对每个候选完整扫描相邻字符，得到的评分恰好符合题目定义。设当前已检查候选中的最大评分为 $B$，遇到评分大于 $B$ 的排列时更新答案，保证答案评分始终最大；遇到评分等于 $B$ 的排列时保留原答案，由于访问顺序已经按字典序排列，保留的正是同评分中最小的排列。因此，最终得到的排列满足全部选择规则。

样例选中的排列为 $\texttt{WORDHSFI}$，其相邻字符距离依次为 $8$、$3$、$14$、$4$、$11$、$13$、$3$，最小值为 $3$。该排列是候选集合中评分最大的排列中字典序最小者，因此输出 $\texttt{WORDHSFI3}$。

设候选排列数量为 $K$，本题中 $K=21$。生成候选需要 $O(KL)$ 时间；排序时每次字符串比较最多检查 $L$ 个字符，需要 $O(KL\log K)$ 时间；计算全部候选评分需要 $O(KL)$ 时间。因此，每个用户名的总时间复杂度为 $O(KL\log K)$，由于 $K$ 为固定常数，也可记为 $O(L)$。保存候选字符串需要 $O(KL)$ 空间，在本题中同样可记为 $O(L)$。

# 代码实现

代码使用 $\texttt{candidate}$ 保存候选排列，通过排序和严格增大的评分更新条件处理字典序优先规则。以下原样保留通过代码及其注释。

```cpp
// Wordfish
// UVa ID: 1209

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    string line, username1, username2, password;
    while (getline(cin, line))
    {
        vector<string> candidate;
        candidate.push_back(line);

        username1 = line, username2 = line;
        while (candidate.size() < 21)
        {
            bool updated = false;
            if (prev_permutation(username1.begin(), username1.end()))
            {
                candidate.push_back(username1);
                updated = true;
            }
            if (next_permutation(username2.begin(), username2.end()))
            {
                candidate.push_back(username2);
                updated = true;
            }
            if (!updated) break;
        }
        
        sort(candidate.begin(), candidate.end());

        int maxminDist = -1;
        for (auto s : candidate)
        {
            int minDist = 1024;
            for (int i = 1; i < s.length(); i++)
                minDist = min(minDist, abs(s[i] - s[i - 1]));
            if (minDist > maxminDist)
            {
                maxminDist = minDist;
                password = s;
            }
        }
        cout << password << maxminDist << '\n';
    }

    return 0;
}
```

# 总结

本题的关键是将枚举范围限制在原用户名附近的固定数量排列，利用字典序相邻排列函数直接构造候选集合。评价候选时，先求相邻字符距离的最小值，再在所有候选中最大化该值；处理并列答案时，先按字典序排序，再仅在评分严格增大时更新。这个技巧将主要优化目标与字典序优先规则统一到一次顺序扫描中。
