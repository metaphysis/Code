
> **摘要**：给定若干不超过 $10000$ 的正整数，统计每个数能表示为一段连续素数之和的方案数。解法先用埃拉托斯特尼筛法生成素数，再枚举所有连续素数区间并累加区间和，利用素数均为正数、区间和超过上限即可提前终止的性质完成预处理，最后对每个查询 $O(1)$ 输出答案。

# 题目描述

给定一个正整数 $n$，统计它能够表示为一个或多个连续素数之和的方案数。连续素数必须来自素数序列中的一段，不能跳过中间的素数，也不能重复使用不连续的素数。

例如，$53$ 可以表示为 $5+7+11+13+17$，也可以直接表示为 $53$，因此共有 $2$ 种表示方法。

# 输入格式

输入包含一列正整数，每个数单独占一行，数值范围为 $2$ 到 $10000$。输入以 $0$ 结束，$0$ 不需要处理。

# 输出格式

对于每个输入的正整数，输出一行，表示该数可以表示为连续素数之和的方案数。

# 样例输入

```text
2
3
17
41
20
666
12
53
0
```

# 样例输出

```text
1
1
2
3
0
0
1
2
```

# 题目分析

本题的核心是统计所有素数连续区间的和。若素数序列为 $p_0,p_1,\ldots$，则以 $p_i$ 为起点、以 $p_j$ 为终点的表示对应区间和
$$
p_i+p_{i+1}+\cdots+p_j
$$
其中 $i\le j$。每个连续区间只对应一种表示，因此枚举所有起点和终点，并统计区间和等于目标数的次数，即可得到答案。

输入范围上限为 $10000$。先筛出不超过该范围的素数，再从每个素数位置出发累加后续素数。由于所有素数均为正数，区间和一旦超过 $10000$，继续累加只会更大，因此可以停止当前起点的枚举。

通过预处理，可以一次性统计所有不超过 $10000$ 的整数的答案。之后每读入一个数，只需直接查询预处理数组。这样避免了对每个输入数重复枚举区间。

# 解题思路

首先使用埃拉托斯特尼筛法生成素数。代码从整数 $2$ 开始扫描：遇到尚未标记的数，就将其加入素数数组，并将它的倍数标记为合数。由于最大查询值为 $10000$，预处理的范围覆盖至 $10000$ 以上即可。

接着枚举每个素数下标 $i$ 作为连续区间起点，将区间和初始化为 $0$。从 $i$ 开始依次加入素数 $p_j$，每加入一个素数，就将当前区间和对应的计数增加 $1$。当区间和大于 $10000$ 时，停止该起点的枚举，因为之后的素数均为正数，区间和不可能再回到有效范围。

完成预处理后，数组 `answer[n]` 保存整数 $n$ 的表示方案数。输入阶段持续读取整数，遇到 $0$ 结束；对其他输入直接输出对应计数。

筛素数的时间复杂度为 $O(U\log\log U)$，其中 $U$ 为筛选范围。枚举连续素数区间的时间复杂度在最坏情况下为 $O(P^2)$，其中 $P$ 是范围内的素数个数；实际执行中，每个起点的累加在区间和超过 $10000$ 后立即停止。预处理数组与筛选数组占用 $O(U)$ 空间。

# 代码实现

代码先筛选素数，再枚举所有可能的连续素数区间并统计其和，最后通过预处理数组回答输入中的每个查询。

```cpp
// Sum of Consecutive Prime Numbers
// UVa ID: 1210
// Verdict: Accepted
// Submission Date: 2018-03-02
// UVa Run Time: 0.000s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int primes[20010] = {0}, cnt = 0;
    for (int i = 2; i < 20010; i++)
        if (!primes[i])
        {
            primes[cnt++] = i;
            for (int j = i + i; j < 20010; j += i)
                primes[j] = 1;
            if (i > 10000) break;
        }
    int answer[100010] = {0};
    for (int i = 0; i < cnt; i++)
    {
        int sum = 0;
        for (int j = i; j < cnt; j++)
        {
            sum += primes[j];
            answer[sum]++;
            if (sum > 10000) break;
        }
    }
    int n;
    while (cin >> n, n > 0)
    {
        cout << answer[n] << '\n';
    }
    return 0;
}
```

# 总结

本题将“连续素数之和”转化为素数序列上的连续区间枚举。先用筛法生成素数，再从每个起点累计区间和并统计次数；利用素数均为正数这一性质，在区间和超过最大查询值后即可提前结束。预处理所有答案后，每个输入只需进行一次数组查询。
