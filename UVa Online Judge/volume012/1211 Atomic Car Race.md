
> **摘要**：本题给定一条赛道上的 $n$ 个检查点及换胎耗时、轮胎速度参数，要求计算赛车从起点到终点的最短总时间。核心思路是先把任意两检查点之间「不换胎」的行驶时间预处理为区间代价 $\textit{dist}[i][j]$，再以检查点为状态做动态规划，枚举最后一次换胎位置完成转移，最终答案为 $\textit{dp}[n]$。整体时间复杂度为 $O(n^2A+n^2)$，空间复杂度为 $O(n^2)$。

# 题目描述

一场汽车比赛的赛道上有 $n$ 个检查点，第 $n$ 个检查点是终点。检查点距离起点分别为 $a_1,a_2,\ldots,a_n$，且满足严格递增。除终点外，赛车可以选择是否更换轮胎。每次更换轮胎需要耗时 $b$ 秒；起点出发时使用新轮胎，不需要额外计费。

轮胎更换后，轮胎温度较低，赛车在一段距离内速度较慢；行驶较长距离后，轮胎磨损又会使赛车速度下降。设距离最近一次换胎位置或起点的距离为 $x$，每行驶 $1$ 公里的时间为：

$$
t(x)=
\begin{cases}
\dfrac{1}{v-f(r-x)},&x<r,\\[6pt]
\dfrac{1}{v-e(x-r)},&x\ge r.
\end{cases}
$$

给定赛道、换胎耗时及相关参数，求赛车从起点到终点所需的最短总时间。

# 输入格式

输入包含多组数据，以一行中的单个 $0$ 结束。

每组数据包含：

- 第一行给出检查点数量 $n$。
- 第二行给出 $n$ 个检查点距离 $a_1,a_2,\ldots,a_n$。
- 第三行给出换胎耗时 $b$。
- 第四行给出整数 $r$ 和实数 $v,e,f$。

# 输出格式

每组数据输出一行，表示最优策略下到达终点所需的时间。输出误差不超过 $0.001$。

# 样例输入

# 题目分析

换胎后，后续路段的行驶时间只取决于距最近一次换胎位置的距离。因此，如果在某个检查点换胎，此前的行驶情况不会影响之后的轮胎状态。可以把一次连续行驶过程看作从一个换胎点到下一个换胎点，或者从起点直接行驶到某个检查点。

对于任意两个检查点 $i$ 和 $j$，其中 $i<j$，可以预先计算从 $a_i$ 行驶到 $a_j$ 且中途不换胎的时间。起点记为检查点 $0$，并设 $a_0=0$。这一段路程的每一公里按其距起点（或最近换胎点）的公里数 $x$ 计算耗时，再将这些耗时累加。

然后对检查点进行动态规划。令 $\textit{dp}[i]$ 表示到达检查点 $i$ 的最短时间。设上一次换胎位置为检查点 $j$，则从 $j$ 到 $i$ 的路程不换胎，且若 $j$ 不是起点，在 $j$ 处需要支付一次换胎时间。比较所有可能的 $j$，即可得到到达 $i$ 的最短时间。

# 解题思路

设置 $a_0=0$，将起点和全部检查点统一编号为 $0$ 至 $n$。对每组数据，先计算任意 $i<j$ 的不换胎行驶时间 $\textit{dist}[i][j]$。令该段长度为 $a_j-a_i$，依次枚举段内每公里对应的距离 $x$，并根据 $x<r$ 或 $x\ge r$，累加相应的单位行驶时间：

$$
\textit{dist}[i][j]=
\sum_{x=0}^{a_j-a_i-1}
\begin{cases}
\dfrac{1}{v-f(r-x)},&x<r,\\[6pt]
\dfrac{1}{v-e(x-r)},&x\ge r.
\end{cases}
$$

由于每段的行驶时间只与段长和参数有关，这个预处理可以复用于不同的换胎方案。代码将每个区间的行驶时间保存在二维数组中。

动态规划的初始状态为 $\textit{dp}[0]=0$。对于每个终点检查点 $i$，枚举之前的检查点 $j$。若从 $j$ 到 $i$ 之间不换胎，则候选总时间由到达 $j$ 的最短时间、可能发生的换胎耗时和该段行驶时间组成：

$$
\textit{dp}[i]=
\min_{0\le j<i}
\left(
\textit{dp}[j]+(j>0?b:0)+\textit{dist}[j][i]
\right).
$$

当 $j=0$ 时，起点出发不需要支付换胎时间；当 $j>0$ 时，赛车需要在检查点 $j$ 更换轮胎。终点无需换胎，因为转移只在到达终点时结束，不会从终点继续出发。

该状态转移枚举了最后一次换胎位置的全部可能情况。任意合法策略到达检查点 $i$ 时，都有一个确定的前一换胎点 $j$；其最后一段行驶时间为 $\textit{dist}[j][i]$，之前的部分至少需要 $\textit{dp}[j]$，因此该策略对应某个转移候选。反过来，每个转移候选都对应一条合法策略。取所有候选的最小值，就得到最短到达时间。最终答案为 $\textit{dp}[n]$。

设赛道总长度为 $A=a_n$。预处理区间时间需要对每个检查点对扫描相应的距离，时间复杂度为 $O(n^2A)$；动态规划枚举所有前驱的时间复杂度为 $O(n^2)$。整体时间复杂度为 $O(n^2A+n^2)$，空间复杂度为 $O(n^2)$。

# 代码实现

代码首先计算任意两检查点之间不换胎的行驶时间，再通过动态规划求出到达各检查点的最短时间。输出保留 $4$ 位小数，满足题目精度要求。

```cpp
// Atomic Car Race
// UVa ID: 1211
// Verdict: Accepted
// Submission Date: 2018-09-14
// UVa Run Time: 0.550s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int n;
int ai[110] = {}, r;
double b, v, e, f;
double dist[110][110], cache[110];

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int cases = 0;
    while (cin >> n, n > 0)
    {
        for (int i = 1; i <= n; i++)
            cin >> ai[i];
        cin >> b >> r >> v >> e >> f;

        ai[0] = 0;
        for (int i = 0; i <= n; i++)
            for (int j = i + 1; j <= n; j++)
            {
                dist[i][j] = 0;
                for (int x = 0; x < (ai[j] - ai[i]); x++)
                {
                    if (x < r) dist[i][j] += 1.0 / (v - f * (r - x));
                    else dist[i][j] += 1.0 / (v - e * (x - r));
                }
                dist[j][i] = dist[i][j];
            }

        cache[0] = 0;
        for (int i = 1; i <= n; i++)
        {
            cache[i] = 1e10;
            for (int j = 0; j < i; j++)
                cache[i] = min(cache[i], cache[j] + (j ? b : 0) + dist[j][i]);
        }
        cout << fixed << setprecision(4) << cache[n] << endl;
    }

    return 0;
}
```

# 总结

本题先将不换胎行驶的一段路作为独立代价进行预处理，再以检查点为状态进行动态规划。状态转移的关键是枚举最后一次换胎的位置，并区分起点与普通检查点的换胎费用。这样可以在明确的区间代价和检查点状态上求出全程最短时间。
