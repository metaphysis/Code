
> **摘要**：给定一个只含小写字母的字符串和依次执行的 $k$ 次切割位置，每次切割作用于当前包含该位置的子串，代价为只出现在切割后一侧的不同字符数量，求全部切割的总代价。解法按字母建立位置表，并用有序边界数组维护当前各子串，逐次定位切割所在区间并统计两侧出现状态不同的字母数，时间复杂度 $O(n+k(n+k))$。

# 题目描述

给定一个只包含小写英文字母的字符串，以及依次执行的 $k$ 次切割位置。每次切割都作用于当前包含该位置的子串，并将其分成左右两部分。

一次切割的代价是：只出现在左半部分或只出现在右半部分的不同字符数量。也就是说，若某个字母在切割后的两侧都出现，或两侧都未出现，则不计入代价；只在一侧出现则计 $1$。

求依次执行全部切割后的总代价。

# 输入格式

第一行给出数据组数 $T$。

每组数据包含三行：

- 第一行给出切割次数 $k$。
- 第二行给出 $k$ 个切割位置，按执行顺序排列。
- 第三行给出待切割的字符串。

# 输出格式

每组数据输出一行，表示所有切割的总代价。

# 样例输入

```text
2
3
5 3 6
ababccd
2
4 2
ababcd
```

# 样例输出

```text
7
4
```

# 题目分析

切割位置是相对于原字符串给出的。虽然切割操作是依次进行的，但每次切割只会影响当前包含该位置的子串。可以用一组边界描述当前字符串被切成的各个子串：初始时只有边界 $0$ 和字符串长度；每次切割后，将新的切割位置插入边界序列。

对于切割位置 $m$，找到它所在的当前子串 $[l,r)$，切割后得到 $[l,m)$ 和 $[m,r)$。区间使用左闭右开形式，便于表示字符在原字符串中的位置。

对于每个字母，分别判断它是否出现在左右两部分。若它恰好出现在一侧，就为本次切割贡献 $1$；若两侧都出现或都不出现，则贡献为 $0$。将所有字母的贡献累加，得到本次切割的代价。

# 解题思路

先读取字符串，并按字母建立位置表 `idx`：`idx[c]` 保存字母 `c` 在原字符串中出现的所有下标。这样检查某个字母在区间内是否出现时，只需要扫描该字母的位置列表。

维护有序边界数组 `sorted`，初始内容为 $0$ 和字符串长度。处理切割位置 $m$ 时，从右向左查找满足 `sorted[i] < m` 的边界。此时当前子串的左边界是 `sorted[i]`，右边界是 `sorted[i + 1]`。对每个字母，扫描它的位置列表，检查是否有下标落在左半部分 $[l,m)$，以及是否有下标落在右半部分 $[m,r)$。若这两个判断结果不同，该字母只出现于一侧，总代价加 $1$。

完成本次切割的代价统计后，将 $m$ 插入边界数组中，以便后续切割能够定位到正确的当前子串。按输入顺序处理所有切割，累计代价并输出。

正确性可由每次切割的独立统计保证：边界数组始终准确表示当前所有子串；因此找到的 $[l,r)$ 正是本次切割影响的子串。对于任意字母，位置表能准确判断它在左右区间是否出现，而两侧出现状态不同恰好等价于该字母只出现在切割后的一部分。因此，每次统计都与题目定义一致，所有切割代价之和就是所求结果。

设字符串长度为 $n$，切割次数为 $k$。建立位置表需要 $O(n)$ 时间。每次切割检查所有字母的位置，合计扫描的字符位置不超过 $n$，另外还需扫描 $26$ 个字母；查找并插入切割边界最坏需要 $O(k)$ 时间。因此总时间复杂度为 $O(n+k(n+k))$，空间复杂度为 $O(n+k)$。

# 代码实现

代码按字母保存字符位置，每次切割时定位当前子串，并统计只出现在切割一侧的字母数。

```cpp
// String Cutting
// UVa ID: 1215
// Verdict: Accepted
// Submission Date: 2018-03-28
// UVa Run Time: 0.030s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    string line;
    int cases, k;
    cin >> cases;
    for (int c = 1; c <= cases; c++)
    {
        cin >> k;
        vector<int> cuts(k), sorted;
        for (int i = 0; i < k; i++) cin >> cuts[i];

        cin >> line;
        vector<vector<int>> idx(26);
        for (int i = 0; i < line.length(); i++)
            idx[line[i] - 'a'].push_back(i);

        int cost = 0;
        sorted.push_back(0); sorted.push_back(line.length());
        for (auto m : cuts)
        {
            int l = -1, r = -1;
            for (int i = sorted.size() - 1; i >= 0; i--)
                if (m > sorted[i])
                {
                    l = sorted[i], r = sorted[i + 1];
                    for (auto x : idx)
                    {
                        bool inLeft = 0, inRight = 0;
                        for (auto y : x)
                        {
                            if (y >= l && y < m) inLeft = 1;
                            if (y >= m && y < r) inRight = 1;
                        }
                        if (inLeft + inRight == 1) cost++;
                    }
                    sorted.insert(sorted.begin() + i + 1, m);
                    break;
                }
        }
        cout << cost << '\n';
    }

    return 0;
}
```

# 总结

本题需要区分“字符出现次数”和“不同字符是否出现”：切割代价只与每个字母在左右两侧是否出现有关。用位置表判断字母在两部分中的出现情况，并用有序边界记录已经执行的切割，就能按顺序准确计算每次切割的代价。
