
> **摘要**：本题要求在给定的有向带权道路图上，为若干条指定景点序列规划最短骑行路线。每条路线的起点与终点固定，中间景点可任意排序，需在满足相邻景点间存在道路的前提下使总距离最小，无法完成时输出 $0$。核心解法为深度优先搜索枚举中间景点的排列，配合道路存在性检查、访问标记去重以及基于「道路距离至少为 1」的下界剪枝，时间复杂度为 $O((k-2)!\cdot k)$。

# 题目描述

$\texttt{Superior Island}$ 是一座风景优美的岛屿，岛上只允许骑自行车通行。岛上有许多连接各个摄影景点的单行自行车道。旅游委员会计划设计 $r$ 条骑行路线，每条路线必须经过指定的景点，未指定的景点不能出现在路线中。给定岛上的道路地图和每条路线要求经过的景点，求每条路线的最短距离。

每个景点在一条路线中最多出现一次。指定景点中的起点是路线的起点，最后一个景点是路线的终点，中间的景点可以按任意顺序访问。

# 输入格式

输入包含多组数据，每组数据分为两部分。

第一行包含两个整数 $n$ 和 $r$，分别表示景点数量和需要规划的路线数量。接下来 $n$ 行，每行包含 $n$ 个整数，第 $i$ 行第 $j$ 个整数表示从景点 $i$ 到景点 $j$ 的单行道路距离。距离在 $0$ 到 $10$ 之间，$0$ 表示没有直达道路。

之后有 $r$ 行，每行列出一条路线需要经过的景点。每行的第一个景点是起点，最后一个景点是终点，中间的景点可以任意排序。每行景点数量不固定。

# 输出格式

对每条路线输出一个整数，表示该路线的最短距离。如果路线无法完成，输出 $0$。

# 样例输入

```text
6 3
0 1 2 0 1 1
1 0 1 1 1 0
0 2 0 1 3 0
4 3 1 0 0 0
0 0 1 1 0 0
1 0 0 0 0 0
1 3 5
6 3 2 5
6 1 2 3 4 5
```

# 样例输出

```text
5
0
7
```

# 题目分析

每条路线的起点和终点固定，路线中间的指定景点则可以按任意顺序访问。因此，问题的核心是为中间景点选择一个排列，使起点、排列中的景点以及终点依次相连，并让总距离最小。

道路是单向的，两个景点之间可能没有直达道路。只有当路线中相邻的两个景点之间存在道路时，这种排列才是有效路线。道路距离非零且最多为 $10$，所以路线距离是所有相邻景点间道路距离之和。

如果一条路线只有起点和终点，就只需检查两者之间是否存在直达道路；存在时输出该道路距离，否则输出 $0$。如果还包含中间景点，则需要枚举中间景点的访问顺序，并在搜索过程中跳过没有对应道路的选择，最终求出所有有效顺序中的最小总距离。

题目给出的景点数量上限为 $100$，但路线所列景点保存在长度为 $32$ 的数组中，因此该实现依赖于每条路线所列景点数量不超过该数组容量。设一条路线包含 $k$ 个景点，其中起点和终点固定，中间有 $k-2$ 个景点。最坏情况下，搜索会枚举这些中间景点的排列，时间复杂度为 $O((k-2)!\cdot k)$，空间复杂度为 $O(k)$，其中空间用于保存景点列表、访问标记和当前排列。

# 解题思路

使用深度优先搜索枚举中间景点的访问顺序。搜索状态由当前排列深度和已经走过的距离构成，同时用访问标记保证每个中间景点最多使用一次。

每次准备选择一个尚未访问的中间景点时，先检查从当前所在位置到该景点是否有道路。若没有道路，该分支无法继续，直接跳过；若有道路，则将该景点加入当前排列，并把对应道路距离累加到当前路线长度中。深度为 $0$ 时，当前位置是固定起点；之后则是当前排列中的最后一个景点。

当所有中间景点都已加入排列后，检查最后一个中间景点到固定终点是否存在道路。存在时，用当前距离加上这段道路距离更新最短距离。搜索结束后，如果最短距离仍未更新，说明没有任何有效路线，输出 $0$。

搜索还使用了一个下界剪枝。任意一段存在的道路距离至少为 $1$，因此从当前状态到路线终点，至少还需要经过与剩余边数相等的距离。若当前距离加上这个下界已经不小于已找到的最短路线，就不可能得到更优答案，可以停止搜索该分支。这个剪枝不会排除最优解，因为它使用的是剩余路段距离的下界。

当路线只有起点和终点时，不进行排列搜索，直接读取对应道路距离。道路距离为 $0$ 表示没有道路，因此该情况的输出自然为 $0$。

# 代码实现

```cpp
// Route Planning
// UVa ID: 1217
// Verdict: Accepted
// Submission Date: 2018-07-22
// UVa Run Time: 0.000s
//
// 版权所有（C）2018，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int n, r, INF = 0x3f3f3f3f;
int dist[110][110], spot[32], used[32], shorest, cnt;
int path[32], firstSpot, lastSpot;

void dfs(int depth, int length)
{
    if (depth == cnt - 2)
    {
        if (dist[spot[path[depth - 1]]][lastSpot])
        {
            shorest = min(shorest, length + dist[spot[path[depth - 1]]][lastSpot]);
        }
        return;
    }
    if (length + (cnt - 1 - depth) >= shorest) return;
    for (int i = 1; i < cnt - 1; i++)
    {
        if (used[i]) continue;
        if (!depth && !dist[firstSpot][spot[i]]) continue;
        if (depth && !dist[spot[path[depth - 1]]][spot[i]]) continue;
        used[i] = 1, path[depth] = i;
        if (!depth)
            dfs(depth + 1, dist[firstSpot][spot[i]]);
        else
            dfs(depth + 1, length + dist[spot[path[depth - 1]]][spot[i]]);
        used[i] = 0;
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    string line;
    while (cin >> n >> r)
    {
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                cin >> dist[i][j];
        cin.ignore(256, '\n');
        for (int i = 1; i <= r; i++)
        {
            getline(cin, line);
            istringstream iss(line);
            cnt = 0;
            while (iss >> spot[cnt]) cnt++;
            if (cnt == 2)
            {
                cout << dist[spot[0]][spot[1]] << '\n';
                continue;
            }
            firstSpot = spot[0], lastSpot = spot[cnt - 1];
            memset(used, 0, sizeof(used));
            used[0] = used[cnt - 1] = 1;
            shorest = INF;
            dfs(0, 0);
            if (shorest != INF) cout << shorest << '\n';
            else cout << "0\n";
        }
    }

    return 0;
}
```

# 总结

本题将路线规划转化为固定起点和终点之间的排列搜索。搜索时通过道路存在性检查排除无效相邻关系，通过访问标记避免重复景点，并利用道路距离至少为 $1$ 这一条件进行下界剪枝。路线只有起点和终点时可以直接处理，无需进入搜索。
