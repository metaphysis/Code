
> **摘要**：本题要求在 $2\times n$ 的矩形板上用 $1\times2$、$2\times1$、$2\times2$ 三种瓷砖完全铺满，并把旋转 $180^\circ$ 后相同的铺法视为同一种编码，求不同编码的数量。文章先忽略旋转等价，用动态规划 $f[n]=f[n-1]+2f[n-2]$ 统计全部铺法；再按 $n$ 的奇偶性分类，推导旋转后保持不变的对称铺法数 $g[n]$；最后利用「对称铺法单独成类、其余铺法两两配对」的 Burnside 思想，得到答案 $\dfrac{f[n]+g[n]}{2}$。配合 $O(N)$ 预处理与 $O(1)$ 单次查询的 C++ 实现，可高效通过 $3\le n\le 30$ 的全部数据。

 # 题目描述

有一块 $2\times n$ 的矩形板，需要使用以下三种尺寸的瓷砖将它完全铺满：

- $1\times 2$ 的横向瓷砖；
- $2\times 1$ 的竖向瓷砖；
- $2\times 2$ 的正方形瓷砖。

每个单元格都必须恰好被一块瓷砖覆盖，瓷砖不能重叠，也不能超出矩形板。

矩形板可以上下颠倒放置：如果一种铺法旋转 $180^\circ$ 后与另一种铺法相同，则这两种铺法视为同一种编码。

给定 $n$，求不同编码的数量。

# 输入格式

第一行输入一个整数 $T$，表示测试数据组数。

接下来 $T$ 行，每行包含一个整数 $n$，表示矩形板的长度。

数据范围为：

$$
3\le n\le 30
$$

# 输出格式

对于每组测试数据，输出一行一个整数，表示长度为 $n$ 的不同编码数量。

# 样例输入

```text
2
3
4
```

# 样例输出

```text
3
8
```

# 题目分析

先暂时不考虑旋转后相同的问题，计算所有铺法数量。

观察矩形板最左侧：

1. 如果放一块竖向的 $2\times1$ 瓷砖，会占用一列；
2. 如果放两块横向的 $1\times2$ 瓷砖，会占用两列；
3. 如果放一块 $2\times2$ 的正方形瓷砖，也会占用两列。

因此，一个铺法可以看成若干个宽度为 $1$ 或 $2$ 的完整块从左到右排列。其中宽度为 $1$ 的块有一种，宽度为 $2$ 的块有两种。

接着考虑旋转 $180^\circ$。每个完整块旋转后形状不变，但块的排列顺序会反过来。因此，两种铺法属于同一种编码，当且仅当它们的块序列相同，或者互为逆序。

对于不随旋转改变的铺法，每种铺法只对应一个编码；对于旋转后不同的铺法，每两种铺法对应一个编码。设所有铺法数为 $f[n]$，旋转后不变的铺法数为 $g[n]$，那么答案为：

$$
\frac{f[n]+g[n]}{2}
$$

# 解题思路

## 1. 计算所有铺法数

设 $f[n]$ 表示不考虑旋转等价时，铺满 $2\times n$ 矩形板的铺法数。

根据最左侧的放法：

- 放一块竖向瓷砖，剩余宽度为 $n-1$，有 $f[n-1]$ 种铺法；
- 放两块横向瓷砖或一块正方形瓷砖，剩余宽度为 $n-2$，共有 $2f[n-2]$ 种铺法。

因此：

$$
f[n]=f[n-1]+2f[n-2]
$$

初始值为：

$$
f[0]=1,\qquad f[1]=1
$$

其中 $f[0]=1$ 表示空矩形对应一种空铺法，便于递推。

## 2. 计算旋转后不变的铺法数

旋转后不变，意味着从左到右的块序列与从右到左相同。需要根据 $n$ 的奇偶性分类讨论。

### $n$ 为奇数

设 $n=2k+1$。

由于整个宽度为奇数，中间必须有一个宽度为 $1$ 的竖向瓷砖。其左侧宽度为 $k$，可以任意铺设；右侧由左侧旋转确定。

因此：

$$
g[2k+1]=f[k]
$$

### $n$ 为偶数

设 $n=2k$。

此时对称铺法分为两类：

- 中心线位于两个块之间：左半部分可以任意铺设，右半部分由左半部分确定，共有 $f[k]$ 种；
- 中心线穿过一个宽度为 $2$ 的块：这个块有两种选择，剩下左侧宽度为 $k-1$，共有 $2f[k-1]$ 种。

因此：

$$
g[2k]=f[k]+2f[k-1]
$$

## 3. 合并等价铺法

旋转后不变的 $g[n]$ 种铺法各自形成一个编码；剩余的 $f[n]-g[n]$ 种铺法两两配对。

所以不同编码的数量为：

$$
g[n]+\frac{f[n]-g[n]}{2}
=
\frac{f[n]+g[n]}{2}
$$

预处理 $f[0]$ 到 $f[30]$，每组数据即可直接计算答案。

# 正确性证明

首先证明递推式能正确计算所有铺法数。对于任意一块 $2\times n$ 的矩形板，观察最左侧一列。如果使用竖向瓷砖覆盖，则剩余部分有 $f[n-1]$ 种铺法；否则上下两个单元格必须分别由横向瓷砖覆盖，或者共同由一块 $2\times2$ 瓷砖覆盖，剩余部分各有 $f[n-2]$ 种铺法。三种情况互不重叠且覆盖所有可能，因此 $f[n]=f[n-1]+2f[n-2]$ 正确。

对于旋转后不变的铺法，其块序列必须关于中心对称。当 $n=2k+1$ 时，中心块只能是宽度为 $1$ 的竖向瓷砖，左半部分确定后右半部分唯一确定，故共有 $f[k]$ 种。当 $n=2k$ 时，中心线要么位于两个块之间，要么穿过一个宽度为 $2$ 的块，分别有 $f[k]$ 和 $2f[k-1]$ 种，两类互不重叠且覆盖所有对称铺法，因此 $g[n]$ 的计算正确。

最后，任意铺法旋转两次后会回到原状。所以，旋转后不变的铺法各自对应一个编码，其余铺法恰好两两对应同一个编码。公式 $(f[n]+g[n])/2$ 恰好统计了所有不同编码，算法正确。

# 复杂度分析

设允许的最大长度为 $N$。

- 预处理时间复杂度为 $O(N)$，每组测试数据的计算时间为 $O(1)$；
- 空间复杂度为 $O(N)$。

本题中 $N=30$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int MAXN = 30;
    long long f[MAXN + 1] = {};
    f[0] = 1;
    f[1] = 1;
    for (int n = 2; n <= MAXN; n++) f[n] = f[n - 1] + 2 * f[n - 2];
    int cases;
    cin >> cases;
    while (cases--) {
        int n;
        cin >> n;
        long long symmetric;
        if (n % 2 == 1) symmetric = f[n / 2];
        else {
            int k = n / 2;
            symmetric = f[k] + 2 * f[k - 1];
        }
        cout << (f[n] + symmetric) / 2 << '\n';
    }
    return 0;
}
```

# 总结

本题先用动态规划统计所有铺法，再统计旋转 $180^\circ$ 后保持不变的铺法。其余铺法都与各自的旋转结果两两配对，因此最终答案为：

$$
\dfrac{\text{所有铺法数}+\text{对称铺法数}}{2}
$$
