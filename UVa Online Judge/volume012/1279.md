## 题目描述

小行星游骑兵军团在太阳系中的各个小行星上建立了基地。作为小行星通信部的成员，你需要确保所有基地之间能够相互通信。你可以建立通信链路，每条链路的成本与两个基地之间的距离成正比。由于小行星会移动，你需要在不同时间切换通信链路，以始终保持最便宜的通信系统。你的任务是计算需要切换多少次通信系统。

每个小行星被视为一个点，以固定速度线性移动，且不会相撞。在任何时间 $t \geq 0$ 时最优的中继系统，对于任意满足 $t < s < t + 10^{-6}$ 的时间 $s$ 都是唯一最优的。初始最优中继系统也是唯一的。

## 输入格式

每个测试用例第一行包含一个整数 $n$（$2 \leq n \leq 50$），表示小行星基地的数量。接下来 $n$ 行，每行包含六个整数 $x, y, z, v_x, v_y, v_z$，分别表示小行星的初始位置坐标和速度分量。坐标范围为 $[-150, 150]$，速度分量的范围为 $[-100, 100]$。

## 输出格式

对于每个测试用例，输出一行 `Case i: k`，其中 $i$ 是测试用例编号（从 $1$ 开始），$k$ 是需要设置或修改中继系统的次数。

## 样例

输入

```
3
0 0 0 0 0 5
0 0 0 0 0 10
1 0 -1 0 0 4
0 0 0 1 0 0
0 1 0 0 -1 0
1 1 1 3 1 1
-1 -1 2 1 -1 -1
```

输出

```
Case 1: 3
Case 2: 3
```

## 题目分析

本题的核心是在动态变化的完全图上维护最小生成树（$\texttt{MST}$），并统计 $\texttt{MST}$ 结构发生变化的次数。

由于 $n \leq 50$，完全图的边数为 $m = n(n-1)/2 \leq 1225$。每条边的权值是两端点之间的距离，而距离是时间的二次函数。具体来说，对于任意两点 $i$ 和 $j$，它们之间的距离平方为：

$$
d_{ij}^2(t) = (x_i + v_{xi}t - x_j - v_{xj}t)^2 + (y_i + v_{yi}t - y_j - v_{yj}t)^2 + (z_i + v_{zi}t - z_j - v_{zj}t)^2
$$

展开后得到：

$$
d_{ij}^2(t) = a_{ij} t^2 + b_{ij} t + c_{ij}
$$

其中：

$$
\begin{aligned}
a_{ij} &= (v_{xi} - v_{xj})^2 + (v_{yi} - v_{yj})^2 + (v_{zi} - v_{zj})^2 \\
b_{ij} &= 2 \left[ (x_i - x_j)(v_{xi} - v_{xj}) + (y_i - y_j)(v_{yi} - v_{yj}) + (z_i - z_j)(v_{zi} - v_{zj}) \right] \\
c_{ij} &= (x_i - x_j)^2 + (y_i - y_j)^2 + (z_i - z_j)^2
\end{aligned}
$$

由于比较距离等价于比较距离平方（平方根函数单调递增），我们可以直接使用 $a t^2 + b t + c$ 作为边权。

$\texttt{MST}$ 的结构发生变化，当且仅当某两条边的权值相等，且这种相等导致它们的最小生成树中的角色互换。因此，我们需要找到所有使得两条边权值相等的时刻，并检查在这些时刻 $\texttt{MST}$ 是否真的发生了变化。

## 解题思路

### 事件生成

对于任意两条边 $e_i$ 和 $e_j$，它们权值相等的时间由方程 $(a_i - a_j) t^2 + (b_i - b_j) t + (c_i - c_j) = 0$ 给出。这是一个二次方程，最多有两个正实根。我们收集所有正根作为候选事件时间。

由于题目保证在任意事件时间 $t$ 后的 $(t, t + 10^{-6})$ 区间内 $\texttt{MST}$ 是唯一且稳定的，我们可以在每个事件时间后取一个微小偏移（如 $t + 10^{-7}$）来计算 $\texttt{MST}$，从而避免处理事件点本身的歧义。

### 增量维护 $\texttt{MST}$

一个朴素的方法是：在每个事件时间后重新运行 $\texttt{Kruskal}$ 算法，比较相邻两次的 $\texttt{MST}$ 边集是否相同。但这种方法效率较低，因为 $m$ 最大可达 $1225$，事件数最多约 $O(m^2)$，总复杂度可能达到 $O(m^3 \log m)$，在 $n=50$ 时仍然可以接受，但存在更高效的增量方法。

更高效的方法是**维护当前 $\texttt{MST}$ 的边集**，并只考虑那些可能引起交换的事件：即一条树边和一条非树边权值相等的事件。当事件发生时，我们尝试用非树边替换树边。如果替换后仍然构成生成树（即去掉树边后，非树边连接的是两个不同的连通分量），则 $\texttt{MST}$ 发生变化，计数加一，并更新边集。

### 算法流程

1. 生成所有边，计算二次函数系数 $a, b, c$，按 $c$（即 $t=0$ 时的距离平方）排序。
2. 使用 $\texttt{Kruskal}$ 算法构建初始 $\texttt{MST}$，记录每条树边及其在树中的位置。
3. 生成所有事件：对于每对边 $(i, j)$，解方程 $a_i t^2 + b_i t + c_i = a_j t^2 + b_j t + c_j$，得到正根 $t$，记录事件 $(t, i, j)$，表示在时间 $t$ 时边 $i$ 和 $j$ 权值相等。按照题目约定，我们需要记录一个方向：在 $t + \epsilon$ 时权值较小的边应替换权值较大的边。
4. 将所有事件按时间排序并去重。
5. 按时间顺序处理事件：若事件涉及的两条边中，旧边在当前 $\texttt{MST}$ 中而新边不在，则尝试替换：
   - 临时从 $\texttt{MST}$ 中移除旧边。
   - 检查新边是否能连接两个不同连通分量。
   - 若能，则更新 $\texttt{MST}$ 边集，计数加一。
6. 输出最终的切换次数（初始系统算一次）。

### 复杂度分析

- 边数：$m = O(n^2)$，当 $n=50$ 时 $m=1225$。
- 事件数：$O(m^2) \approx 1.5 \times 10^6$，每个事件由解二次方程得到，计算量为常数。
- 排序：$O(m^2 \log m)$，约 $1.5 \times 10^6 \times 21 \approx 3 \times 10^7$ 次比较，可行。
- 事件处理：每个事件需要 $O(n)$ 的时间检查连通性（并查集操作），总复杂度 $O(n m^2) \approx 50 \times 1.5 \times 10^6 = 7.5 \times 10^7$，在时限内可接受。

### 正确性说明

- 事件的生成覆盖了所有可能改变 $\texttt{MST}$ 结构的时间点，因为 $\texttt{MST}$ 的变化只发生在两条边权值相等的时刻。
- 通过维护当前 $\texttt{MST}$ 边集，并在事件发生时检查替换可行性，保证了我们只在实际发生变化的时刻计数。
- 题目保证在事件时间后的一小段时间内 $\texttt{MST}$ 唯一，因此使用 $t + \epsilon$ 的时间点判断权值大小关系是安全的。

## 代码实现

```cpp
// Asteroid Rangers
// UVa ID: 1279
// Verdict: Accepted
// Submission Date: 2026-06-03
// UVa Run Time: 0.470s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double EPS = 1e-8;
const int MAXN = 55;
const int MAXE = MAXN * (MAXN - 1) / 2;

int n, eCnt;

struct Point {
    double px, py, pz, vx, vy, vz;
    void get() {
        cin >> px >> py >> pz >> vx >> vy >> vz;
    }
} pts[MAXN];

struct Edge {
    double A, B, C;
    int from, to;
    Edge() {}
    Edge(int f, int t, double a, double b, double c) : from(f), to(t), A(a), B(b), C(c) {}
    bool operator < (const Edge& o) const {
        return C < o.C;
    }
} edges[MAXE];

double square(double x) { return x * x; }

void initEdges() {
    eCnt = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            double dx = pts[i].px - pts[j].px;
            double dy = pts[i].py - pts[j].py;
            double dz = pts[i].pz - pts[j].pz;
            double dvx = pts[i].vx - pts[j].vx;
            double dvy = pts[i].vy - pts[j].vy;
            double dvz = pts[i].vz - pts[j].vz;
            double A = square(dvx) + square(dvy) + square(dvz);
            double B = 2 * (dx * dvx + dy * dvy + dz * dvz);
            double C = square(dx) + square(dy) + square(dz);
            edges[eCnt++] = Edge(i, j, A, B, C);
        }
    }
    sort(edges, edges + eCnt);
}

struct Event {
    double time;
    int enter, leave;
    Event(double t = 0, int e = 0, int l = 0) : time(t), enter(e), leave(l) {}
    bool operator < (const Event& o) const {
        return time < o.time;
    }
};

vector<Event> events;

void buildEvents() {
    events.clear();
    for (int i = 0; i < eCnt; ++i) {
        for (int j = i + 1; j < eCnt; ++j) {
            int p = i, q = j;
            if (edges[p].A < edges[q].A) swap(p, q);
            double dA = edges[p].A - edges[q].A;
            double dB = edges[p].B - edges[q].B;
            double dC = edges[p].C - edges[q].C;
            
            if (fabs(dA) < EPS) {
                if (fabs(dB) < EPS) continue;
                if (dB > 0) {
                    swap(p, q);
                    dB = -dB;
                    dC = -dC;
                }
                if (dC > 0) events.push_back(Event(-dC / dB, p, q));
                continue;
            }
            
            double delta = dB * dB - 4 * dA * dC;
            if (delta < EPS) continue;
            delta = sqrt(delta);
            double x1 = (-dB - delta) / (2 * dA);
            double x2 = (delta - dB) / (2 * dA);
            if (x1 > 0) events.push_back(Event(x1, p, q));
            if (x2 > 0) events.push_back(Event(x2, q, p));
        }
    }
    sort(events.begin(), events.end());
}

int dsu[MAXN];

void dsuInit() {
    for (int i = 0; i < n; ++i) dsu[i] = i;
}

int dsuFind(int x) {
    return dsu[x] == x ? x : dsu[x] = dsuFind(dsu[x]);
}

bool dsuMerge(int x, int y) {
    int rx = dsuFind(x), ry = dsuFind(y);
    if (rx == ry) return false;
    dsu[rx] = ry;
    return true;
}

int simulate() {
    int mark[MAXE] = {0};
    int mst[MAXN];
    
    dsuInit();
    int cur = 0;
    for (int i = 0; i < eCnt; ++i) {
        if (dsuMerge(edges[i].from, edges[i].to)) {
            mst[mark[i] = ++cur] = i;
            if (cur == n - 1) break;
        }
    }
    
    int cnt = 1;
    
    for (size_t i = 0; i < events.size(); ++i) {
        int out = events[i].leave;
        int in = events[i].enter;
        
        if (mark[out] && !mark[in]) {
            dsuInit();
            int pos = mark[out];
            
            for (int j = 1; j < n; ++j) {
                if (j != pos) {
                    dsuMerge(edges[mst[j]].from, edges[mst[j]].to);
                }
            }
            
            if (dsuMerge(edges[in].from, edges[in].to)) {
                cnt++;
                mark[in] = pos;
                mst[pos] = in;
                mark[out] = 0;
            }
        }
    }
    
    return cnt;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T = 0;
    while (cin >> n) {
        for (int i = 0; i < n; ++i) pts[i].get();
        initEdges();
        buildEvents();
        cout << "Case " << ++T << ": " << simulate() << "\n";
    }
    return 0;
}
```

## 总结

本题是动态最小生成树（$\texttt{Kinetic MST}$）的经典问题，核心难点在于：

1. **将距离函数转化为二次函数**：通过平方消除根号，简化比较。
2. **事件生成**：求解两条边权值相等的时间，并正确处理事件方向。
3. **增量维护 $\texttt{MST}$**：只关注树边与非树边的交换，避免全局重建。

关键技巧：
- 使用 $t + \epsilon$ 判断事件后的权值大小，利用题目提供的稳定性保证。
- 用位置数组 `mark` 快速判断一条边是否在当前 $\texttt{MST}$ 中。
- 替换时只重建部分并查集，复杂度 $O(n)$ 每次事件。

本题适合作为学习动态图算法和计算几何的练习，也展示了如何将物理运动问题转化为数学模型求解。
