## 题目分析

### 问题描述
$\texttt{Plate Shipping Company}$ 需要将来自多个制造商的盘子堆合并成一个有序堆。每个制造商的盘子堆已经是正确排序的（从小到大）。允许两种操作：

1. **拆分 ($\texttt{Split}$)**：将一个堆的顶部任意部分提起，形成一个新的堆
2. **合并 ($\texttt{Join}$)**：将一个堆放在另一个堆的顶部，仅当顶部堆的底部盘子不大于底部堆的顶部盘子时允许

目标：找到将 $n$ 个初始堆合并成一个有序堆所需的最少操作次数。

### 输入格式
- 第一行：整数 $n$ ($1 \leq n \leq 50$)，表示堆的数量
- 接下来 $n$ 行：每行第一个整数 $h$ ($1 \leq h \leq 50$) 表示堆的高度，后面 $h$ 个正整数表示盘子的直径（从上到下，非递减）

### 输出格式
对于每个测试用例，输出用例编号和最小操作次数。

## 解题思路

### 数学模型建立

#### 连通分量视角
我们可以将所有盘子看作一个图：
- **初始状态**：有 $n$ 个独立的连通分量（每个初始堆是一个连通分量）
- **拆分操作**：创建一个新的连通分量（增加1个连通分量）
- **合并操作**：将两个连通分量合并为一个（减少1个连通分量）

#### 操作次数的数学推导
设：
- $split$ = 拆分操作次数
- $join$ = 合并操作次数
- $n$ = 初始堆数量（初始连通分量数）

**拆分后**：总连通分量数 = $n + split$

**最终目标**：将所有连通分量合并成 $1$ 个

**合并次数**：$join = (n + split) - 1 = n + split - 1$

**总操作次数**：
$$
\begin{aligned}
total &= split + join \\
&= split + (n + split - 1) \\
&= 2 \times split + n - 1
\end{aligned}
$$

因此，问题的核心转化为**最小化拆分次数** $split$。

### 关键观察

1. **盘子分组**：相同直径的盘子可以分为一组。如果多个相同直径的盘子来自同一个堆，它们可以被视为一个（因为操作时它们会一起处理）。

2. **拆分次数的计算**：对于每种盘子类型（相同直径），如果它出现在 $cnt$ 个不同的堆中，在最坏情况下需要 $cnt$ 次拆分来获取所有这些盘子。

3. **优化机会**：在某些情况下可以避免不必要的拆分，减少拆分次数。

### 动态规划解法

#### 状态定义
设 $dp[i][j]$ 表示处理完前 $i$ 种盘子类型，且最后处理的盘子来自第 $j$ 堆的**最小拆分次数**。

#### 预处理
1. 读取所有盘子，存储为（直径，堆编号）对
2. 按直径排序并使用 `unique` 去重（去除相同直径且相同堆的重复盘子）
3. 将相同直径的盘子分组，记录每组出现在哪些堆中
   - $hasPlate[i][j]$：第 $i$ 种盘子类型是否在第 $j$ 堆中出现
   - $cnt[i]$：第 $i$ 种盘子类型涉及的不同堆数量

#### 状态转移详解
状态转移的核心公式：
```cpp
if (hasPlate[i][k] && (cnt[i] == 1 || k != j))
    dp[i+1][j] = min(dp[i+1][j], dp[i][k] + cnt[i] - 1);
else
    dp[i+1][j] = min(dp[i+1][j], dp[i][k] + cnt[i]);
```

##### 转移条件解释

**基本拆分次数**：对于第 $i$ 种盘子类型，如果它出现在 $cnt[i]$ 个不同的堆中，在最坏情况下我们需要 $cnt[i]$ 次拆分来获取所有这些盘子。

**减少拆分次数的条件**：

1. **`cnt[i] == 1`**：这种盘子只在一个堆中出现
   - 我们别无选择，只能从那个堆获取
   - 不增加拆分决策次数
   - 拆分次数增加 $cnt[i] - 1 = 0$

2. **`k != j`**：从前一个堆 $k$ 切换到目标堆 $j$，且堆 $k$ 也有这种盘子
   - 我们可以直接从堆 $k$ 获取这些盘子
   - 不需要为了从堆 $j$ 获取而专门拆分
   - 节省一次拆分，拆分次数增加 $cnt[i] - 1$

**为什么 `k == j` 且 `cnt[i] > 1` 时不减少拆分**：
- 我们还在使用同一个堆 $j$
- 但当前类型的盘子需要从堆 $j$ 中拆分出来（因为还有其他堆也有这种盘子）
- 我们需要一次专门的拆分操作来分离这些盘子
- 因此拆分次数不能减少

##### 物理操作的直观理解

想象按直径顺序处理盘子：

- **情况 $1$**（条件成立）：刚处理完堆 $A$ 的盘子，下一个尺寸的盘子在堆 $A$ 中也有
  - 直接从堆 $A$ 取这些盘子，不需要额外拆分
  - 节省 $1$ 次拆分

- **情况 $2$**（条件不成立）：刚处理完堆 $A$ 的盘子，下一个尺寸的盘子虽然在堆 $A$ 中，但还有其他堆也有
  - 需要从堆 $A$ 中拆分出这些盘子，以便后续处理其他堆的同尺寸盘子
  - 需要 $1$ 次拆分

#### 算法步骤

1. **初始化**：对于第一种盘子类型，如果出现在堆 $j$，则 $dp[1][j] = cnt[1]$
2. **状态转移**：按照上述规则计算 $dp[i][j]$
3. **最终结果**：
   - 最小拆分次数 $minSplit = \min(dp[M][j])$，其中 $M$ 是盘子类型总数
   - 总操作次数 $result = 2 \times minSplit + n - 1$

### 时间复杂度分析
- 盘子总数最多：$50 \times 50 = 2500$
- 动态规划状态数：$O(M \times n^2)$，其中 $M \leq 2500$，$n \leq 50$
- 总时间复杂度：$O(2500 \times 2500) \approx 6.25 \times 10^6$，可以接受

```cpp
// Stacking Plates

#include <bits/stdc++.h>
using namespace std;
const int INF = 0x3f3f3f3f;
const int MaxN = 50;
const int MaxH = 50;

int main() {
    int n, caseId = 1;
    while (cin >> n) {
        vector<pair<int, int>> plates;
        int totPlates = 0;
        for (int i = 1; i <= n; i++) {
            int h;
            cin >> h;
            for (int j = 0; j < h; j++) {
                int sizeVal;
                cin >> sizeVal;
                plates.push_back({sizeVal, i});
                totPlates++;
            }
        }
        sort(plates.begin(), plates.end());
        int c = unique(plates.begin(), plates.end()) - plates.begin();
        vector<vector<bool>> hasPlate;
        vector<int> cnt;
        int typeCnt = 0;
        for (int i = 0; i < c; i++) {
            int start = i;
            while (i + 1 < c && plates[i + 1].first == plates[i].first) i++;
            hasPlate.push_back(vector<bool>(n + 1, false));
            cnt.push_back(i - start + 1);
            for (int j = start; j <= i; j++)
                hasPlate[typeCnt][plates[j].second] = true;
            typeCnt++;
        }
        vector<vector<int>> dp(typeCnt + 1, vector<int>(n + 1, INF));
        for (int j = 1; j <= n; j++)
            if (hasPlate[0][j]) dp[1][j] = cnt[0];
        for (int i = 1; i < typeCnt; i++)
            for (int j = 1; j <= n; j++)
                if (hasPlate[i][j])
                    for (int k = 1; k <= n; k++)
                        if (dp[i][k] != INF)
                            if (hasPlate[i][k] && (cnt[i] == 1 || k != j))
                                dp[i + 1][j] = min(dp[i + 1][j], dp[i][k] + cnt[i] - 1);
                            else dp[i + 1][j] = min(dp[i + 1][j], dp[i][k] + cnt[i]);
        int minCost = INF;
        for (int j = 1; j <= n; j++)
            minCost = min(minCost, dp[typeCnt][j]);
        int result = 2 * minCost - n - 1;
        cout << "Case " << caseId++ << ": " << result << endl;
    }
    return 0;
}
```

## 样例分析

### 样例1
```
输入：
2
3 1 2 4
2 3 5
输出：
Case 1: 5
```

解释：
- 盘子类型：$1$（堆 $1$）、$2$（堆 $1$）、$3$（堆 $2$）、$4$（堆 $1$）、$5$（堆 $2$）
- 最小拆分次数：$2$（拆分堆 $1$ 得到 $[1, 2]$ 和 $[4]$，拆分堆 $2$ 得到 $[3]$ 和 $[5]$）
- 计算：$2 \times 2 + 2 - 1 = 4 + 1 = 5$

### 样例2
```
输入：
3
4 1 1 1 1
4 1 1 1 1
4 1 1 1 1
输出：
Case 2: 2
```

解释：
- 盘子类型：$1$（堆 $1$、堆 $2$、堆 $3$）
- 最小拆分次数：$0$（所有堆都只有尺寸 $1$，不需要拆分）
- 计算：$2 \times 0 + 3 - 1 = 0 + 2 = 2$

## 总结

本题的解题关键在于：
1. 建立数学模型：将操作转化为连通分量的变化
2. 推导出公式：总操作次数 $= 2 \times split + n - 1$
3. 通过动态规划最小化拆分次数 $split$
4. 利用盘子分组和状态转移优化减少不必要的拆分

这种解法巧妙地避免了直接模拟复杂的物理操作，通过数学建模和动态规划得到了高效且正确的解决方案。核心难点在于理解状态转移中减少拆分次数的条件，这需要对物理操作过程有深入的理解。
