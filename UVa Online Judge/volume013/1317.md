## 题目描述

你被任命为一家著名音乐厅的主任，需要挽救其免于破产。音乐厅有两个相同大小和布局的厅室，每天每个厅室只能举办一场音乐会。你收到了下一年度的音乐会申请，每个申请包含一个时间段 $[i, j]$ 和一个出价 $w$（日元），其中 $i$ 和 $j$ 分别是该时间段的第一天和最后一天（$1 \le i \le j \le 365$）。

每个申请要么被完全接受（在整个时间段内使用同一个厅室），要么被完全拒绝。由于音乐厅经济状况严峻，你需要忽略艺术质量，只通过接受最有利润的申请来最大化全年的总收入。

**输入格式**
- 多个数据集，每个数据集以整数 $n$（申请数量）开始
- 接下来 $n$ 行，每行包含三个整数 $i\ j\ w$
- 一行包含单个 $0$ 表示输入结束
- $1 \le n \le 1000$，$1 \le w \le 10^6$

**输出格式**
- 对于每个数据集，输出一个整数表示最大总收入

**样例输入**

## 题目分析

### 问题本质

这是一个**带权区间调度问题**的扩展版本，具有两个相同的资源（厅室）。每个申请可以看作是一个带权的时间区间，我们需要选择若干区间分配给两个厅室，使得：

1. 每个厅室内分配的区间互不重叠（时间上不冲突）
2. 每个区间最多被分配给一个厅室
3. 总收益（权值和）最大化

这等价于在区间图中找到两个顶点不相交的路径（每个路径对应一个厅室的安排），使得路径上顶点的权值之和最大。

## 解题思路

### 方法一：天数流量边建模

这是一种更优雅高效的建模方法，通过将时间轴上的每一天看作网络中的节点来建立流量边。

#### 建模思路

1. **节点设计**：
   - 创建源点 $S$ 和汇点 $T$
   - 为每一天 $d$（$1 \le d \le 366$）创建一个节点，其中第 $366$ 天作为虚拟的结束点
   - 每个区间 $[i, j]$ 也作为一个节点

2. **边设计**：
   - 从源点 $S$ 到第 $1$ 天：容量为 $2$，费用为 $0$（表示有两个厅室可用）
   - 从第 $d$ 天到第 $d+1$ 天：容量为 $2$，费用为 $0$（表示时间流逝，厅室空闲）
   - 对于每个区间 $[i, j]$ 及其价值 $w$：
     - 从第 $i$ 天到区间节点：容量为 $1$，费用为 $0$
     - 从区间节点到第 $j+1$ 天：容量为 $1$，费用为 $-w$
   - 从第 $366$ 天到汇点 $T$：容量为 $2$，费用为 $0$

#### 工作原理

流量从第 $1$ 天流向第 $366$ 天，代表时间的流逝。当流量经过 $i \to$区间$\to j+1$ 的路径时，表示接受该区间申请：
- **容量限制为 $2$**：确保最多有两个厅室同时使用
- **流量守恒**：每天的流出流量等于下一天的流入流量
- **区间占用**：接受区间 $[i, j]$ 时，流量从第 $i$ 天进入区间节点，再从区间节点流出到第 $j+1$ 天，相当于占用了 $i$ 到 $j$ 这段时间
- **避免重叠**：由于流量必须连续流动，且每个区间节点只能通过 $1$ 的流量，所以区间不会重叠使用同一个厅室

#### 算法步骤

1. **建图**：按照上述建模思路建立网络流图
2. **运行最小费用最大流**：使用带势能的 $\texttt{Dijkstra}$ 算法求解
3. **获取结果**：最小费用为负值（因为边费用为负），最大收益为 $-$ 最小费用

### 方法二：区间节点拆点建模

这是另一种常见的建模方法，通过将每个区间拆分为入点和出点来建立兼容性边。

#### 建模思路

1. **节点设计**：
   - 为每个区间 $i$ 创建两个节点：$in_i$（入点）和 $out_i$（出点）
   - 添加源点 $S$ 和汇点 $T$

2. **边设计**：
   - 从 $in_i$ 到 $out_i$ 的边：容量为 $1$，费用为 $-w_i$
   - 从 $S$ 到每个 $in_i$ 的边：容量为 $1$，费用为 $0$
   - 从每个 $out_i$ 到 $T$ 的边：容量为 $1$，费用为 $0$
   - 对于任意两个不重叠的区间 $i$ 和 $j$（$i.end < j.start$），从 $out_i$ 到 $in_j$ 的边：容量为 $1$，费用为 $0$

#### 优化策略

- **区间排序**：先按结束时间排序，这样每个区间只需要连接到它之后且不重叠的区间
- **链式前向星**：使用静态数组存储图，提高访问效率
- **$\texttt{SPFA}$ 算法**：适合处理带负权边的图

## 两种方法对比

| 特性 | 天数流量边方法 | 区间节点拆点方法 |
|------|----------------|----------------|
| **建图复杂度** | $O(n)$ | $O(n^2)$ |
| **边数** | $O(n + 365)$ | 最多 $O(n^2)$ |
| **节点数** | $n + 368$ | $2n + 2$ |
| **直观性** | 更直观，直接对应时间轴 | 较复杂，需要理解区间兼容性 |
| **扩展性** | 易扩展到 $k$ 个厅室 | 易扩展到 $k$ 个厅室 |
| **实际效率** | 稳定，不受区间密度影响 | 对于密集区间可能较慢 |

## 时间复杂度分析

### 天数流量边方法
- 建图：$O(n)$
- 节点数：约 $n + 368$
- 边数：约 $n + 365$
- 最小费用最大流：使用带势能的 Dijkstra，复杂度 $O(F \cdot E \log V)$，其中 $F=2$（最大流量），实际运行非常快

### 区间节点拆点方法
- 排序：$O(n \log n)$
- 建图：$O(n^2)$
- 节点数：$2n + 2$
- 边数：最多 $O(n^2)$
- 最小费用最大流：复杂度 $O(F \cdot V \cdot E)$，最坏情况下可能较慢

## 天数流量边方法正确性证明

1. **容量约束**：
   - 每天到第二天的边容量为 $2$，确保最多两个厅室
   - 每个区间入边和出边容量为 $1$，确保每个区间最多被选择一次

2. **时间连续性**：
   - 流量必须从第 $i$ 天流经区间节点到第 $j+1$ 天
   - 这保证了区间 $[i, j]$ 被完整占用

3. **避免冲突**：
   - 如果两个区间时间重叠，它们需要共享同一天的时间边
   - 由于时间边容量为 $2$，最多两个区间可以同时进行

4. **收益最大化**：
   - 费用为 $-w$，最小费用对应最大收益
   - 算法会选择使总费用最小（即收益最大）的区间组合

```cpp
// Concert Hall Scheduling
// UVa ID: 1317
// Verdict: Accepted
// Submission Date: 2026-01-22
// UVa Run Time: 0.120s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int DAYS = 367;  // 第366天作为虚拟结束点

struct Edge {
    int to, rev, cap, cost;
};

struct MinCostMaxFlow {
    vector<vector<Edge>> g;
    vector<int> dist, potential, prevv, preve;
    int n;
    
    MinCostMaxFlow(int n) : n(n), g(n), dist(n), potential(n), prevv(n), preve(n) {}
    
    void addEdge(int from, int to, int cap, int cost) {
        g[from].push_back({to, (int)g[to].size(), cap, cost});
        g[to].push_back({from, (int)g[from].size() - 1, 0, -cost});
    }
    
    pair<int, int> minCostMaxFlow(int s, int t, int maxf) {
        int flow = 0, cost = 0;
        fill(potential.begin(), potential.end(), 0);
        while (flow < maxf) {
            fill(dist.begin(), dist.end(), INF);
            dist[s] = 0;
            using P = pair<int, int>;
            priority_queue<P, vector<P>, greater<P>> pq;
            pq.push({0, s});
            while (!pq.empty()) {
                auto [d, v] = pq.top(); pq.pop();
                if (dist[v] < d) continue;
                for (int i = 0; i < g[v].size(); i++) {
                    Edge& e = g[v][i];
                    if (e.cap > 0 && dist[e.to] > dist[v] + e.cost + potential[v] - potential[e.to]) {
                        dist[e.to] = dist[v] + e.cost + potential[v] - potential[e.to];
                        prevv[e.to] = v;
                        preve[e.to] = i;
                        pq.push({dist[e.to], e.to});
                    }
                }
            }
            if (dist[t] == INF) break;
            for (int v = 0; v < n; v++) potential[v] += dist[v];
            int d = maxf - flow;
            for (int v = t; v != s; v = prevv[v]) {
                d = min(d, g[prevv[v]][preve[v]].cap);
            }
            flow += d;
            cost += d * potential[t];
            for (int v = t; v != s; v = prevv[v]) {
                Edge& e = g[prevv[v]][preve[v]];
                e.cap -= d;
                g[v][e.rev].cap += d;
            }
        }
        return {flow, cost};
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n && n) {
        // 节点编号：
        // 0: 源点 S
        // 1-366: 第1-366天（其中第366天是虚拟结束点）
        // 367-366+n: 区间节点
        // 367+n: 汇点 T
        int S = 0;
        int T = DAYS + n + 1;
        int dayStart = 1;
        int intervalStart = DAYS + 1;
        int totalNodes = T + 1;
        MinCostMaxFlow mcmf(totalNodes);
        // 从源点到第1天，容量为2（两个厅室）
        mcmf.addEdge(S, dayStart, 2, 0);
        // 天数之间的连接边，容量为2
        for (int d = 1; d < DAYS; d++)
            mcmf.addEdge(dayStart + d - 1, dayStart + d, 2, 0);
        // 从第366天到汇点
        mcmf.addEdge(dayStart + DAYS - 1, T, 2, 0);
        // 添加区间
        for (int i = 0; i < n; i++) {
            int start, end, value;
            cin >> start >> end >> value;
            int intervalNode = intervalStart + i;
            // 从第start天到区间节点，容量为1，费用为0
            mcmf.addEdge(dayStart + start - 1, intervalNode, 1, 0);
            // 从区间节点到第end+1天，容量为1，费用为-value
            // 注意：如果end+1超过365，则连接到第366天
            int nextDay = min(end + 1, DAYS);
            mcmf.addEdge(intervalNode, dayStart + nextDay - 1, 1, -value);
        }
        // 求最小费用最大流，最大流量为2
        auto result = mcmf.minCostMaxFlow(S, T, 2);
        int maxIncome = -result.second;
        cout << maxIncome << "\n";
    }
    return 0;
}
```

## 参考代码（区间建立流量边，链式前向星 $+ \ \texttt{SFFA}$ 实现）

```cpp
// Concert Hall Scheduling
// UVa ID: 1317
// Verdict: Accepted
// Submission Date: 2026-01-22
// UVa Run Time: 0.610s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int MAXN = 2510;
const int MAXM = 600010;

struct Edge {
    int to, next, cap, cost;
} edges[MAXM * 2];

int head[MAXN], cnt;

void addEdge(int from, int to, int cap, int cost) {
    edges[cnt] = {to, head[from], cap, cost};
    head[from] = cnt++;
    edges[cnt] = {from, head[to], 0, -cost};
    head[to] = cnt++;
}

struct MinCostMaxFlow {
    int n, dist[MAXN], pre[MAXN], preEdge[MAXN];
    bool inQueue[MAXN];
    
    MinCostMaxFlow(int n) : n(n) {}
    
    bool spfa(int s, int t) {
        fill(dist, dist + n, INF);
        memset(inQueue, false, sizeof(inQueue));
        dist[s] = 0;
        queue<int> q;
        q.push(s);
        inQueue[s] = true;
        
        while (!q.empty()) {
            int u = q.front(); q.pop();
            inQueue[u] = false;
            for (int i = head[u]; ~i; i = edges[i].next) {
                int v = edges[i].to;
                if (edges[i].cap > 0 && dist[v] > dist[u] + edges[i].cost) {
                    dist[v] = dist[u] + edges[i].cost;
                    pre[v] = u;
                    preEdge[v] = i;
                    if (!inQueue[v]) {
                        q.push(v);
                        inQueue[v] = true;
                    }
                }
            }
        }
        return dist[t] < INF;
    }
    
    pair<int, int> minCostMaxFlow(int s, int t, int maxf) {
        int flow = 0, cost = 0;
        while (flow < maxf && spfa(s, t)) {
            int d = maxf - flow;
            for (int v = t; v != s; v = pre[v]) {
                d = min(d, edges[preEdge[v]].cap);
            }
            flow += d;
            cost += d * dist[t];
            for (int v = t; v != s; v = pre[v]) {
                int i = preEdge[v];
                edges[i].cap -= d;
                edges[i ^ 1].cap += d;
            }
        }
        return {flow, cost};
    }
};

struct Interval {
    int start, end, value;
    bool operator<(const Interval& other) const {
        return end < other.end;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n && n) {
        vector<Interval> itls(n);
        for (int i = 0; i < n; i++) {
            cin >> itls[i].start >> itls[i].end >> itls[i].value;
        }
        sort(itls.begin(), itls.end());
        // 节点编号：0:源点, 1:汇点, 2~2n+1:区间节点（拆点）
        int S = 0, T = 1;
        int offset = 2;
        int totalNodes = offset + 2 * n;
        memset(head, -1, sizeof(head));
        cnt = 0;
        MinCostMaxFlow mcmf(totalNodes);
        // 为每个区间添加拆点边
        for (int i = 0; i < n; i++) {
            int inNode = offset + 2 * i;
            int outNode = offset + 2 * i + 1;
            addEdge(inNode, outNode, 1, -itls[i].value);
            addEdge(S, inNode, 1, 0);
            addEdge(outNode, T, 1, 0);
        }
        // 添加区间之间的连接边
        for (int i = 0; i < n; i++) {
            int out = offset + 2 * i + 1;
            for (int j = i + 1; j < n; j++) {
                if (itls[i].end < itls[j].start) {
                    int in = offset + 2 * j;
                    addEdge(out, in, 1, 0);
                }
            }
        }
        auto result = mcmf.minCostMaxFlow(S, T, 2);
        int maxIncome = -result.second;
        cout << maxIncome << "\n";
    }
    return 0;
}
```

## 总结

本题展示了网络流在解决区间调度问题中的强大应用。天数流量边方法通过巧妙的时间轴建模，将问题转化为一个简洁高效的最小费用最大流问题。这种方法具有以下优势：

1. **建模直观**：直接对应物理时间，易于理解
2. **效率高**：边数少，算法运行稳定
3. **扩展性强**：可轻松扩展到多个厅室或更复杂的时间约束
4. **实现简洁**：代码量少，逻辑清晰

对于竞赛和实际问题，天数流量边方法是解决此类区间调度问题的首选方案。它体现了算法设计中"将复杂问题转化为已知模型"的重要思想，是网络流应用的一个经典范例。
