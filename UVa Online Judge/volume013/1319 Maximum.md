
> **摘要**：本题要求在 $m$ 个实数满足区间约束与线性总和约束的条件下，最大化 $\sum x_i^p$（$p$ 为偶数）。由于 $x^p$ 是凸函数，最大值必在可行域极点取得，而极点结构极为简洁——所有变量取端点，或至多一个变量取内部值。据此枚举 $t$（取上限的变量个数）即可在 $O(m)$ 时间内求解，配合 `long double` 与容差判断保证精度。

## 题目描述

给定 $m$ 个实数 $x_1, x_2, \ldots, x_m$，它们满足约束：

- 对于每个 $i$，有 $-\dfrac{1}{\sqrt{a}} \le x_i \le \sqrt{a}$；
- 总和满足 $x_1 + x_2 + \cdots + x_m = b\sqrt{a}$。

其中 $a$ 和 $b$ 是整数，$a > 0$，$p$ 是一个给定的偶正整数。

要求计算表达式

$$
x_1^p + x_2^p + \cdots + x_m^p
$$

在满足上述所有约束的条件下的最大值，并将结果四舍五入到最接近的整数。

## 输入格式

输入包含多组测试数据，每组数据占一行。每行包含四个整数 $m$、$p$、$a$、$b$，其中 $m \le 2000$，$p \le 12$，且 $p$ 为偶数。输入保证对于每一组数据，至少存在一组实数 $x_i$ 满足所有条件。

## 输出格式

对于每组输入，输出一行一个整数，表示所求最大值的四舍五入结果。

## 样例

**输入**

```text
1997 12 3 -318
10 2 4 -1
```

**输出**

```text
189548
6
```

## 题目分析

目标函数为 $\sum_{i=1}^m x_i^p$，其中 $p$ 是偶数。定义区间 $[L, U]$，其中

$$
L = -\frac{1}{\sqrt{a}},\qquad U = \sqrt{a}.
$$

可行域是所有 $x_i \in [L, U]$ 且满足线性等式 $\sum x_i = b\sqrt{a}$ 的超矩形与超平面的交集。

当 $p$ 为偶数时，函数 $f(x) = x^p$ 在区间 $[L, U]$ 上的二阶导数为 $f''(x) = p(p-1)x^{p-2}$。由于 $p \ge 2$ 且为偶数，$x^{p-2} \ge 0$ 恒成立（因为 $p-2$ 为偶数或零），故 $f''(x) \ge 0$，即 $f$ 是凸函数。凸函数在线性约束下的最大值必然出现在可行域的极点（即极端点）。对于这种由超矩形和一个线性等式约束构成的凸多面体，其极点具有如下结构：最多只有一个坐标分量取区间内部值，其余所有坐标分量必须取区间端点（下限 $L$ 或上限 $U$）。

因此，最大值一定可以在两类候选点中达到：

- 类别 $\texttt{1}$. 所有变量均取端点（即每个 $x_i$ 要么等于 $L$ 要么等于 $U$）。
- 类别 $\texttt{2}$. 恰好有一个变量取内部值 $z \in (L, U)$，其余变量全取端点。

不存在其他类型的极点。因此，我们只需枚举这两类可能，分别计算目标值，取最大值即可。

## 解题思路

令总和 $S = b\sqrt{a}$。记取上限 $U$ 的变量个数为 $t$。

### 类别 $\texttt{1}$：全部取端点

此时共有 $t$ 个变量取 $U$，其余 $m-t$ 个变量取 $L$。总和为

$$
tU + (m-t)L.
$$

若该总和与 $S$ 的绝对误差在浮点容差范围内，则该组可行。对应的目标值为

$$
tU^p + (m-t)L^p.
$$

枚举 $t$ 从 $0$ 到 $m$，检查等式是否成立，并更新最大值。

### 类别 $\texttt{2}$：一个内部变量

设内部变量为 $z$，取 $U$ 的个数为 $t$，取 $L$ 的个数为 $m-t-1$。由总和约束得

$$
z = S - tU - (m-t-1)L.
$$

若 $z \in [L, U]$（考虑浮点误差），则此组可行。对应的目标值为

$$
tU^p + z^p + (m-t-1)L^p.
$$

枚举 $t$ 从 $0$ 到 $m-1$，检查 $z$ 是否落在区间内，并更新最大值。

取两种类别中的所有可行值中的最大值作为最终答案。最后使用四舍五入函数转换为整数输出。

### 复杂度分析

- 时间复杂度：对于每组数据，枚举 $t$ 的次数为 $O(m)$，每次计算使用 $O(1)$ 的乘方运算（$p \le 12$），故总时间复杂度为 $O(m)$。
- 空间复杂度：仅使用常数个变量，空间复杂度为 $O(1)$。

## 代码实现

```cpp
// Maximum

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, p, a, b;
    while (cin >> m >> p >> a >> b) {
        long double sqrtA = sqrtl((long double)a);
        long double L = -1.0L / sqrtA;          // 下限
        long double U = sqrtA;                  // 上限
        long double total = (long double)b * sqrtA;
        long double ans = -1.0e100L;
        const long double eps = 1e-9L;
        // 1) 全部取端点：t个U，其余L
        for (int t = 0; t <= m; ++t) {
            long double sum = t * U + (m - t) * L;
            if (fabsl(sum - total) <= eps) {
                long double val = t * powl(U, p) + (m - t) * powl(L, p);
                if (val > ans) ans = val;
            }
        }
        // 2) 一个内部变量z，其余取端点
        for (int t = 0; t < m; ++t) {
            long double z = total - t * U - (m - t - 1) * L;
            if (z >= L - eps && z <= U + eps) {
                long double val = t * powl(U, p) + powl(z, p) + (m - t - 1) * powl(L, p);
                if (val > ans) ans = val;
            }
        }
        // 四舍五入到最接近整数
        long long result = llroundl(ans);
        cout << result << '\n';
    }
    return 0;
}
```

## 总结

本题的核心是利用凸函数的性质，将连续优化问题转化为有限个极值点的枚举。由于 $p$ 为偶数，$x^p$ 是凸函数，其最大值必然在可行域的极点取得，而极点的结构非常简洁：所有变量在边界，或最多一个在内部。这一性质大幅降低了计算复杂度，使得枚举 $O(m)$ 即可完成。

关键技巧在于：

- 正确识别上下限 $L$ 和 $U$（注意下限为负值）。
- 使用高精度浮点数（`long double`）以避免数值误差，并设定容差进行等式判断。
- 采用四舍五入函数 `llroundl` 保证输出精度。

该解法简洁高效，适用于题目给定的数据范围（$m \le 2000$，$p \le 12$），且多组输入下仍能快速求解。
