## 题目描述

$\texttt{Chris Ltd.}$ 公司正在开发一种新的排序硬件 $\texttt{Maximizer}$。该硬件有 $n$ 个输入，编号从 $1$ 到 $n$ ，每个输入是一个整数。硬件只有一个输出，表示当前输入中的最大值。

$\texttt{Maximizer}$ 的实现方式是一个由 $m$ 个排序器（$\texttt{Sorter}$）组成的管道。每个排序器 $Sorter(i, j)$ 会对输入的第 $i$ 到第 $j$ 个位置上的值进行非递减排序，其他位置的值保持不变。所有排序器依次连接，最后一个排序器的第 $n$ 个输出就是 $\texttt{Maximizer}$ 的输出。

现在发现，某些排序器可以从管道中移除，而 $\texttt{Maximizer}$ 仍然能够对所有可能的输入数据给出正确结果。问题是：**在保持正确性的前提下，最短的排序器子序列的长度是多少？**

**输入**  
第一行是测试用例数量 $t$ ，之后每个测试用例格式如下：  
- 第一行：两个整数 $n$ 和 $m$ （ $2 \le n \le 50000$ ， $1 \le m \le 500000$ ）  
- 接下来 $m$ 行：每行两个整数 $i_k$ 和 $j_k$ （ $1 \le i_k < j_k \le n$ ），表示第 $k$ 个排序器的参数。

**输出**  
对每个测试用例，输出一个整数，表示最短子序列的长度。测试用例之间输出一个空行。

---

## 题目分析

我们需要选择排序器的一个子序列（保持原有顺序），使得对于**所有可能的输入值组合**，最终第 $n$ 个输出都是正确的最大值。

### 问题转化

考虑最大值从输入位置 $1$ 出发，最终到达输出位置 $n$ 的过程。  
每个 $Sorter(i, j)$ 的作用是：如果最大值当前位于区间 $[i, j]$ 内的某个位置，那么经过这个排序器后，最大值会被移到位置 $j$（因为排序后最大值在区间的最后）。  
因此，排序器可以看作是将最大值从某个小于等于 $j$ 的位置“推送”到位置 $j$ 的工具。

更精确地，如果我们定义状态：

> $dp[x]$ 表示将最大值从位置 $1$ 传递到位置 $x$ 所需的最少排序器数量。

那么对于每个 $Sorter(i, j)$ ，如果最大值已经到达某个位置 $p \in [i, j-1]$ ，那么通过这个排序器，最大值就可以到达位置 $j$ 。  
因此，我们可以用 $dp[p] + 1$ 去更新 $dp[j]$ ，其中 $p \in [i, j-1]$ 。  
由于我们要求的是最少数量，所以应该取 $dp[i], dp[i+1], \dots, dp[j-1]$ 中的最小值再加 $1$ 来更新 $dp[j]$ 。

### 动态规划方程

初始化：
- $dp[1] = 0$（最大值已经在位置 $1$ 时不需要任何操作）
- $dp[2 \dots n] = \infty$

对于每个排序器 $(i, j)$ ：
$$
dp[j] = \min(dp[j],\ \min\{dp[i], dp[i+1], \dots, dp[j-1]\} + 1)
$$

我们需要按输入顺序依次处理排序器，因为子序列必须保持原顺序。

---

## 算法设计

直接按照上述方程实现，复杂度为 $O(m \cdot (j-i))$ ，在 $n, m$ 很大时会超时。  
注意到我们需要频繁查询区间 $[i, j-1]$ 内 $dp$ 值的最小值，因此可以使用**线段树**来维护 $dp$ 数组，将每次查询和更新的复杂度降到 $O(\log n)$ 。

### 算法步骤

1. 初始化线段树，将 $dp[1]$ 设为 $0$ ，其余设为无穷大。
2. 依次读入每个排序器 $(i, j)$ ：
   - 在线段树上查询区间 $[i, j-1]$ 的最小值 `minVal` 。
   - 如果 `minVal + 1 < dp[j]` ，则更新 $dp[j] = minVal + 1$ ，并在线段树上更新位置 $j$ 的值。
3. 最终 $dp[n]$ 就是答案。

**注意**：由于排序器可能以任意顺序给出，且 $i$ 可能大于 $j$ ，需要先确保 $i < j$ 。

---

## 复杂度分析

- **时间复杂度**： $O(m \log n)$ ，其中 $m$ 是排序器数量， $n$ 是输入数量。
- **空间复杂度**： $O(n)$ ，主要用于线段树和 $dp$ 数组。

## 代码实现

```cpp
// Minimizing Maximizer
// UVa ID: 1322
// Verdict: Accepted
// Submission Date: 2026-01-02
// UVa Run Time: 0.270s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int MAX_N = 50005;
int dp[MAX_N];
int segTree[4 * MAX_N];

// 更新线段树：将位置 idx 的值设为 value
void update(int node, int left, int right, int idx, int value) {
    if (left == right) {
        segTree[node] = value;
        return;
    }
    int mid = (left + right) / 2;
    if (idx <= mid) update(node * 2, left, mid, idx, value);
    else update(node * 2 + 1, mid + 1, right, idx, value);
    segTree[node] = min(segTree[node * 2], segTree[node * 2 + 1]);
}

// 查询区间 [ql, qr] 的最小值
int query(int node, int left, int right, int ql, int qr) {
    if (qr < left || ql > right) return INF;
    if (ql <= left && right <= qr) return segTree[node];
    int mid = (left + right) / 2;
    return min(query(node * 2, left, mid, ql, qr),
               query(node * 2 + 1, mid + 1, right, ql, qr));
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n, m;
        cin >> n >> m;
        // 初始化 dp 数组
        for (int i = 1; i <= n; i++) dp[i] = INF;
        dp[1] = 0;
        // 初始化线段树
        for (int i = 0; i < 4 * MAX_N; i++) segTree[i] = INF;
        update(1, 1, n, 1, 0);
        for (int k = 0; k < m; k++) {
            int i, j;
            cin >> i >> j;
            if (i > j) swap(i, j);  // 确保 i < j
            // 查询 dp[i] 到 dp[j-1] 的最小值
            int minVal = query(1, 1, n, i, j - 1);
            if (minVal + 1 < dp[j]) {
                dp[j] = minVal + 1;
                update(1, 1, n, j, dp[j]);
            }
        }
        cout << dp[n] << "\n";
        if (t) cout << "\n";  // 测试用例之间输出空行
    }
    return 0;
}
```

## 总结

本题的关键在于将硬件正确性问题转化为一个区间覆盖的动态规划问题，并利用线段树高效维护区间最小值。  
通过维护 $dp[x]$ 表示最大值到达位置 $x$ 所需的最少排序器数量，我们可以在 $O(m \log n)$ 时间内求出答案。  
注意处理输入顺序和边界条件，以及测试用例之间的输出格式即可。
