[UVa 1350 Pinary](https://blog.csdn.net/metaphysis/article/details/155275496## 题目描述

$\texttt{Pinary}$ 数是一种特殊的数字表示法，它只使用两个数字 $0$ 和 $1$，并且遵循以下规则：
$1.$ 不能以 $0$ 开头（与普通数字相同）
$2.$ 两个连续的数字不能都是 $1$（即禁止出现 $11$）

这意味着 $\texttt{Pinary}$ 数的有效序列包括：$1$, $10$, $100$, $101$, $1000$, $1001$, $\ldots$ 等。例如，$100101000$ 是一个有效的 $\texttt{Pinary}$ 数，而 $0010101$（以 $0$ 开头）和 $10110001$（包含 $11$）都不是有效的 $\texttt{Pinary}$ 数。

每个 $\texttt{Pinary}$ 数按照长度顺序和字典序对应一个正整数：
- $1$ → $1$
- $10$ → $2$  
- $100$ → $3$
- $101$ → $4$
- $1000$ → $5$

## 输入输出格式

**输入：**
- 第一行：测试用例数 $T$
- 每个测试用例：一个正整数 $2 < K < 90,000,000$

**输出：**
- 每个测试用例输出一行：对应整数 $K$ 的 $\texttt{Pinary}$ 数表示

## 样例

**输入：**
```
3
7
2000
22
```

**输出：**
```
1010
1001000001001000
1000001
```

## 问题分析

### $\texttt{Pinary}$ 数的规律

通过观察 $\texttt{Pinary}$ 数的序列，我们可以发现一个重要的规律：

- 长度为 $1$ 的 $\texttt{Pinary}$ 数：$1$ ($1$)
- 长度为 $2$ 的 $\texttt{Pinary}$ 数：$10$ ($2$)
- 长度为 $3$ 的 $\texttt{Pinary}$ 数：$100$ ($3$), $101$ ($4$)
- 长度为 $4$ 的 $\texttt{Pinary}$ 数：$1000$ ($5$), $1001$ ($6$), $1010$ ($7$)
- 长度为 $5$ 的 $\texttt{Pinary}$ 数：$10000$ ($8$), $10001$ ($9$), $10010$ ($10$), $10100$ ($11$), $10101$ ($12$)

可以发现，长度为 $n$ 的 $\texttt{Pinary}$ 数的数量正好等于斐波那契数 $F(n)$。

### 斐波那契表示法

这个问题实际上是一个**斐波那契表示问题**（$\texttt{Zeckendorf}$ 表示）。每个正整数都可以唯一地表示为不相邻的斐波那契数的和。

在我们的问题中：
- 斐波那契数列定义为：$F(0) = 1$, $F(1) = 2$, $F(n) = F(n-1) + F(n-2)$
- 每个 $\texttt{Pinary}$ 数对应一个唯一的正整数
- $\texttt{Pinary}$ 数的构造规则确保了不会出现连续的 $1$

## 解题思路

### 算法步骤

$1.$ **预计算斐波那契数列**：
   - 计算斐波那契数直到超过最大可能的 $K$ 值（$90,000,000$）
   - 这里 $fib[i]$ 表示第 $i$ 个斐波那契数

$2.$ **查找 $\texttt{Pinary}$ 数表示**：
   - 对于给定的 $K$，找到最大的斐波那契数不超过 $K$
   - 从高位到低位构造 $\texttt{Pinary}$ 数
   - 如果当前斐波那契数 $fib[i] \leq K$ 且前一位不是 $1$，则当前位设为 $1$，并减去 $fib[i]$
   - 否则当前位设为 $0$
   - 使用标志位确保不会出现连续的 $1$

### 时间复杂度

- 预计算斐波那契数列：$O(\log K_{max})$
- 每个查询：$O(\log K)$
- 总复杂度：$O(T \log K)$，对于题目约束非常高效

## 代码实现

```cpp
// Pinary

#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 50;  // 90,000,000对应的斐波那契索引
long long fib[MAX_N];

void precomputeFibonacci() {
    fib[0] = 1;
    fib[1] = 2;
    for (int i = 2; i < MAX_N; i++)
        fib[i] = fib[i-1] + fib[i-2];
}

string findPinaryNumber(long long k) {
    // 找到最大的斐波那契数不超过k
    int maxIndex = 0;
    while (fib[maxIndex] <= k) maxIndex++;
    maxIndex--;
    
    string result = "";
    bool lastWasOne = false;
    
    for (int i = maxIndex; i >= 0; i--) {
        if (fib[i] <= k && !lastWasOne) {
            result += '1';
            k -= fib[i];
            lastWasOne = true;
        } else {
            result += '0';
            lastWasOne = false;
        }
    }
    
    return result;
}

int main() {
    precomputeFibonacci();
    
    int t;
    cin >> t;
    
    while (t--) {
        long long k;
        cin >> k;
        cout << findPinaryNumber(k) << endl;
    }
    
    return 0;
}
```

## 算法正确性证明

该算法的正确性基于斐波那契表示定理（$\texttt{Zeckendorf}$ 定理）：
$1.$ 每个正整数都可以唯一地表示为不连续的斐波那契数的和
$2.$ 我们的构造过程确保了不会选择相邻的斐波那契数（通过 $\texttt{lastWasOne}$ 标志）
$3.$ 从高位到低位的贪心选择保证了表示的唯一性
