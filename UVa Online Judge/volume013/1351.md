### **问题描述**

我们设计了一种类似行程长度编码（ $\texttt{RLE}$ ）的字符串压缩方法，其规则为：如果一个子串 $S$ 重复出现了 $k$ 次，那么可以用 $k(S)$ 来替换这 $k$ 个 $S$ 。 例如， `letsogogogo` 可以压缩为 `lets3(go)` 。 压缩可以嵌套，即 $S$ 本身也可以是压缩后的字符串。 题目要求我们计算，对于一个给定的字符串，按照此规则能得到的最短压缩字符串的长度。

### **输入与输出**

*   **输入**：第一行是测试用例的数量 $T$ 。 接下来 $T$ 行，每行一个由小写字母组成的字符串，长度不超过 $200$ 。
*   **输出**：对于每个测试用例，输出其最短压缩字符串的长度。

### **题目分析**

这道题的核心在于如何高效地枚举一个字符串所有可能的压缩方式（包括嵌套压缩），并找到最优解。 字符串长度最多为 $200$ ，这提示我们可以使用 $O(n^3)$ 级别的算法。

我们很容易想到使用 **动态规划** 来解决。 对于这类涉及子串最优解的问题，一个经典的思路是定义二维状态 $dp[l][r]$ ，表示原字符串中从下标 $l$ 到 $r$ （包含两端）的子串，经过压缩后能得到的最短长度。

我们的目标是计算出 $dp[0][n-1]$ 。

### **解题思路详解**

#### **1. 状态定义与初始化**

*   `dp[l][r]`： 子串 `s[l..r]` 的最短压缩长度。
*   **初始化**： 对于长度为 $1$ 的子串，即 $l == r$ ，显然它不能被压缩，其最短长度就是 $1$ 。 所以 `dp[i][i] = 1` 。

#### **2. 状态转移**

我们需要考虑如何从更小的子串推导出 `dp[l][r]` 。 对于一个子串 `s[l..r]` ，有两种基本情况：

**情况一：直接拼接**
子串 `s[l..r]` 可以看作是由两个非空的连续子串 `s[l..k]` 和 `s[k+1..r]` 拼接而成。 那么它的最短长度就是这两个子串各自最短长度之和的最小值。 因此我们需要枚举所有可能的分割点 $k$ ：
$$
dp[l][r] = \min_{l \le k < r} \{ dp[l][k] + dp[k+1][r] \}
$$

**情况二：整体压缩为 `k(S)` 形式**
如果子串 `s[l..r]` 本身是由一个更短的子串 $S$ 重复 $k$ 次（$k>1$）构成的，那么我们可以考虑将其整体压缩。 例如 `abcabcabc` 是由 `abc` 重复 $3$ 次构成，可以压缩为 `3(abc)`。

设 `S = s[l..t]` ，其长度为 `subLen = t - l + 1` 。 如果整个区间长度 `len = r - l + 1` 能被 `subLen` 整除，我们才需要检查它是否真的是由 `S` 重复而来。
1.  **检查重复性**：遍历整个 `s[l..r]` ，检查每个位置的字符是否满足 `s[i] == s[l + (i - l) % subLen]` 。 如果全部满足，则说明它是重复串。
2.  **计算压缩后长度**：如果它是重复串，设重复次数 $k = len / subLen$ 。
    *   $k$ 的位数：`int kDigits = to_string(k).size()`
    *   括号占 $2$ 个字符。
    *   子串 $S$ 本身的最短长度是 `dp[l][t]`（注意， $S$ 本身可能已经被压缩了，这正是嵌套压缩的体现）。
    *   因此，整体压缩后的长度为：$kDigits + dp[l][t] + 2$。
    *   我们需要用这个值去更新 `dp[l][r]` ： `dp[l][r] = min(dp[l][r], kDigits + dp[l][t] + 2)`。

我们需要枚举所有可能的 $S$ 的结束位置 $t$ （即所有可能的重复单元）。

#### **3. 计算顺序与最终答案**

由于计算 `dp[l][r]` 需要用到长度更短的子串的结果（即 `dp[l][k]`、`dp[k+1][r]`、`dp[l][t]`），我们应该按照 **子串长度从小到大** 的顺序进行计算。
1.  初始化所有长度为 $1$ 的区间。
2.  外层循环枚举子串长度 `len` 从 $2$ 到 $n$。
3.  内层循环枚举子串的起始位置 `l`，并根据 `len` 计算出结束位置 `r`。
4.  在这个 `(l, r)` 确定的区间内，先进行 **情况一（分割）** 的转移，再进行 **情况二（整体压缩）** 的转移。

最终，`dp[0][n-1]` 就是整个字符串的最短压缩长度。

**时间复杂度**：状态数为 $O(n^2)$，对于每个状态，情况一的转移需要 $O(n)$ 时间枚举分割点，情况二的转移在最坏情况下也需要 $O(n)$ 时间枚举重复单元并检查。 因此总时间复杂度约为 $O(n^3)$，在 $n \le 200$ 时完全可行。

### **代码实现**

```cpp
// String Compression
// UVa ID: 1351
// Verdict: Accepted
// Submission Date: 2026-01-14
// UVa Run Time: 0.030s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t; cin >> t; // 读取测试用例数量
    while (t--) {
        string s; cin >> s; // 读取字符串
        int n = s.size();
        // dp[l][r] 表示子串 s[l..r] 的最短压缩长度
        vector<vector<int>> dp(n, vector<int>(n, INT_MAX));
        
        // 初始化：单个字符长度为1
        for (int i = 0; i < n; i++) dp[i][i] = 1;
        
        // 枚举区间长度，从小到大计算
        for (int len = 2; len <= n; len++) {
            for (int l = 0; l + len - 1 < n; l++) {
                int r = l + len - 1; // 区间结束位置
                
                // 情况1：将区间分割为两部分，直接拼接
                for (int k = l; k < r; k++) 
                    dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r]);
                
                // 情况2：尝试将整个区间压缩为 k(S) 形式
                for (int t = l; t < r; t++) {
                    int subLen = t - l + 1; // 候选重复单元 S 的长度
                    if (len % subLen != 0) continue; // 长度必须整除
                    
                    // 检查整个区间是否由 s[l..t] 重复构成
                    bool isRepeat = true;
                    for (int i = l; i <= r; i++) 
                        if (s[i] != s[l + (i - l) % subLen]) { isRepeat = false; break; }
                    
                    if (isRepeat) {
                        int k = len / subLen; // 重复次数
                        int kDigits = to_string(k).size(); // k 的位数
                        // 压缩后长度 = k的位数 + 括号2个 + 重复单元S的最短长度
                        int compressedLen = kDigits + dp[l][t] + 2;
                        dp[l][r] = min(dp[l][r], compressedLen);
                    }
                }
            }
        }
        
        // 输出整个字符串的最短压缩长度
        cout << dp[0][n - 1] << endl;
    }
    return 0;
}
```

**总结**： 本题是一道经典的区间动态规划问题，通过合理定义状态 `dp[l][r]` 并仔细处理 **直接拼接** 和 **整体模式压缩** 两种状态转移，可以高效地求出最优解。 关键在于理解并实现嵌套压缩的递归特性，这在动态规划中通过 `dp[l][t]` 来自然地体现。
