## 题目描述

一座悬索桥的主缆从桥的一端延伸到另一端，支撑着桥面。主缆位于高塔顶部，并在两端固定于锚固点。塔使得主缆能够跨越长距离。

假设相邻两塔之间的最大距离为 $D$ ，塔顶到桥面的距离为 $H$ 。还假设任意两相邻塔之间的缆索形状为相同的对称抛物线。现在给定桥的长度 $B$ 和缆索总长度 $L$ ，请你计算桥面与缆索最低点之间的距离，且要求建造的塔的数量最少（假设桥的两端总是各有一座塔）。

### 输入格式

输入包含多个测试用例。第一行是一个整数 $T$ （$1 \leq T \leq 10$），表示测试用例数量。随后是 $T$ 个测试用例，每个用例前有一个空行。

每个测试用例一行，包含四个正整数：

- $D$ ：相邻塔之间的最大距离
- $H$ ：塔顶到桥面的距离
- $B$ ：桥的长度
- $L$ ：缆索总长度

保证 $B \leq L$ ，缆索始终在桥面之上。

### 输出格式

输出每个测试用例的结果，格式为：

```
Case #:
x.xx
```

其中 `# `从 $1$ 开始编号。两个连续用例之间用一个空行分隔，最后一个用例后无空行。结果保留两位小数。

## 题目分析

本题是一个基于抛物线模型的物理/几何问题。核心在于理解缆索的形状和长度计算，并利用数值方法求解。

### 关键理解

1. **塔的布置** ：为了使用最少数量的塔，应尽可能让相邻塔之间的距离接近最大允许距离 $D$ 。设需要 $n$ 座塔（包括两端的塔），则：
   - $n = \lceil B/D \rceil + 1$
   - 实际塔间距 $d = B / (n-1)$

2. **抛物线模型** ：以两塔中点为原点建立坐标系，桥面为 $y = 0$ 。设：
   - 塔位于 $x = \pm d/2$ 处
   - 塔顶高度（相对于桥面）为 $H$
   - 缆索最低点高度（相对于桥面）为 $h$ （待求）

   抛物线方程为：
   $$
   y(x) = a x^2 + h
   $$
   由于抛物线通过塔顶：
   $$
   y(d/2) = a (d/2)^2 + h = H
   $$
   解得：
   $$
   a = \frac{4(H-h)}{d^2}
   $$

3. **缆索长度计算** ：单段缆索的长度为抛物线弧长：
   $$
   s = \int_{-d/2}^{d/2} \sqrt{1 + [y'(x)]^2} \, dx
   $$
   其中 $y'(x) = 2a x = \frac{8(H-h)}{d^2} x$ 。

   令 $k = \frac{4(H-h)}{d^2}$ ，则 $y' = 2k x$ 。代入积分得：
   $$
   s = \int_{-d/2}^{d/2} \sqrt{1 + (2k x)^2} \, dx
   $$

   利用积分公式：
   $$
   \int \sqrt{1 + (2k x)^2} \, dx = \frac{x}{2} \sqrt{1 + 4k^2 x^2} + \frac{1}{4k} \sinh^{-1}(2k x)
   $$

   计算定积分得：
   $$
   s = \frac{d}{2} \sqrt{1 + m^2} + \frac{d^2}{8(H-h)} \ln\left(m + \sqrt{1+m^2}\right)
   $$
   其中 $m = \frac{4(H-h)}{d}$ ，$\sinh^{-1}(x) = \ln(x + \sqrt{1+x^2})$ 。

4. **总长度约束** ：总缆索长度 $L$ 等于 $(n-1)$ 段缆索长度之和：
   $$
   (n-1) \cdot s = L
   $$
   这是一个关于 $h$ 的方程。

### 解题思路

1. **计算塔的数量和间距** ：
   - $n = \lceil B/D \rceil + 1$
   - $d = B / (n-1)$

2. **二分法求解 $h$** ：
   - $h$ 的取值范围为 $[0, H]$
   - 对于给定的 $h$ ，计算总缆索长度
   - 比较计算长度与给定长度 $L$ ：
     - 如果计算长度 $< L$ ，说明缆太短，需要降低最低点（减小 $h$）
     - 如果计算长度 $> L$ ，说明缆太长，需要升高最低点（增大 $h$）
   - 二分迭代直到达到足够精度

3. **数值稳定性** ：当 $H-h$ 接近 $0$ 时，公式中的 $\frac{d^2}{8(H-h)}$ 项可能溢出，需要特殊处理。

### 算法步骤

1. 读取测试用例数 $T$
2. 对于每个测试用例：
   $a$. 读取 $D, H, B, L$
   $b$. 计算 $n$ 和 $d$
   $c$. 在 $[0, H]$ 范围内二分搜索 $h$
   $d$. 输出结果，保留两位小数

### 复杂度分析

- 时间复杂度：每个测试用例 $O(K \cdot n)$ ，其中 $K$ 是二分迭代次数（通常 $40-80$ 次足够），$n$ 是塔的数量，但这里 $n$ 很小
- 空间复杂度：$O(1)$

## 代码实现

```cpp
// Bridge
// UVa ID: 1356
// Verdict: Accepted
// Submission Date: 2025-12-26
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 计算单段缆索长度
double cableLength(double d, double H, double h) {
    double m = 4.0 * (H - h) / d;
    double sqrtTerm = sqrt(1.0 + m * m);
    double term1 = d / 2.0 * sqrtTerm;
    // 避免除以0
    if (H - h < 1e-12) return d;
    double term2 = d * d / (8.0 * (H - h)) * log(m + sqrtTerm);
    return term1 + term2;
}

int main() {
    int T;
    cin >> T;
    for (int t = 1; t <= T; ++t) {
        if (t > 1) cout << endl;

        double D, H, B, L;
        cin >> D >> H >> B >> L;

        // 最少塔数
        int n = (int)ceil(B / D) + 1;
        double d = B / (n - 1);

        // 二分法求h
        double left = 0.0, right = H;
        for (int iter = 0; iter < 80; ++iter) {
            double mid = (left + right) / 2.0;
            double totalCable = (n - 1) * cableLength(d, H, mid);
            if (totalCable < L) 
                right = mid;  // 缆太短，需要降低最低点（减小h）
            else 
                left = mid;
        }

        double h = (left + right) / 2.0;
        cout << "Case " << t << ":" << endl;
        cout << fixed << setprecision(2) << h << endl;
    }
    return 0;
}
```

## 示例分析

### 样例1

输入：
```
20 101 400 4042
```

计算：
- $B/D = 400/20 = 20$ ，所以 $n = 20 + 1 = 21$
- $d = 400 / (21-1) = 20$
- 每段缆索长度应为 $4042 / 20 = 202.1$

求解 $h$ 得 $h \approx 1.00$ ，输出：
```
Case 1:
1.00
```

### 样例2

输入：
```
1 2 3 4
```

计算：
- $B/D = 3/1 = 3$ ，所以 $n = 3 + 1 = 4$
- $d = 3 / (4-1) = 1$

求解 $h$ 得 $h \approx 1.60$ ，输出：
```
Case 2:
1.60
```
