## 题目分析

### 题意理解
考古学家发现了一个金字塔洞穴系统，洞穴之间通过通道连接，整个结构形成一棵树。其中一个洞穴与外部相连，作为树的根节点。机器人从根节点进入，按照特定的 $\texttt{DFS}$ 规则遍历整个洞穴系统：

1. 进入洞穴时，将洞穴的颜色记录到输出带上
2. 每次选择最左边未访问的通道前进
3. 当无未访问通道时，从栈顶取出通道描述，沿原路返回

机器人最终返回外部世界时，输出带上记录的颜色序列就是洞穴的访问顺序。现在给定这个颜色序列，需要计算可能产生该序列的不同洞穴系统数量。

### 关键观察
1. **序列结构**：颜色序列实际上是树的先序遍历序列
2. **首尾相同**：序列的第一个和最后一个字符必须相同，因为它们都对应根节点
3. **递归结构**：序列可以递归地分解为根节点和若干子树，每个子树本身也是一个完整的"根到根"序列

### 动态规划解法
定义 $dp[l][r]$ 表示子串 $S[l..r]$ 能形成的不同树结构的数量，其中：
- $S[l]$ 必须是该子树的根节点颜色
- $S[r]$ 必须是该子树遍历的最后一个节点颜色
- 要求 $S[l] = S[r]$，因为子树遍历从根开始，最后回到根

**状态转移方程**：
对于区间 $[l, r]$，如果 $S[l] = S[r]$，我们可以枚举第一棵子树的范围：
$$dp[l][r] = \sum_{k=l+2}^{r} [S[l] = S[k]] \times dp[l+1][k-1] \times dp[k][r]$$

其中：
- $k$ 是划分点，$S[k]$ 与根节点 $S[l]$ 颜色相同
- $dp[l+1][k-1]$ 是第一棵子树的数量
- $dp[k][r]$ 是剩余部分形成的子树数量

**边界条件**：
- 当 $l = r$ 时，$dp[l][r] = 1$（单节点树）
- 当 $S[l] \neq S[r]$ 时，$dp[l][r] = 0$

### 算法复杂度
- 时间复杂度：$O(n^3)$，其中 $n$ 是序列长度
- 空间复杂度：$O(n^2)$

## 代码实现
```cpp
// Exploring Pyramids
// UVa ID: 1362
// Verdict: Accepted
// Submission Date: 2025-10-19
// UVa Run Time: 0.040s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <vector>
using namespace std;
const int MOD = 1000000000;
int main() {
    string S;
    while (cin >> S) {
        int n = S.length();
        vector<vector<long long>> dp(n, vector<long long>(n, 0));
        // 初始化：单节点树的方案数为1
        for (int i = 0; i < n; i++)
            dp[i][i] = 1;
        // 枚举区间长度
        for (int len = 2; len <= n; len++) {
            for (int l = 0; l + len - 1 < n; l++) {
                int r = l + len - 1;
                // 首尾颜色不同，无法形成树结构
                if (S[l] != S[r]) continue;
                // 枚举划分点k
                for (int k = l + 2; k <= r; k++) {
                    // 找到与根节点颜色相同的位置
                    if (S[l] == S[k]) {
                        // 累加方案数：第一棵子树 × 剩余子树
                        dp[l][r] = (dp[l][r] + dp[l + 1][k - 1] * dp[k][r]) % MOD;
                    }
                }
            }
        }
        // 输出整个序列对应的方案数
        cout << dp[0][n-1] << endl;
    }
    return 0;
}
```

## 总结
本题通过动态规划将问题分解为子问题，利用树的递归性质和 $\texttt{DFS}$ 遍历特性，巧妙地计算了可能树结构的数量。关键点在于理解序列的首尾相同特性，以及如何通过枚举划分点将问题分解为更小的子问题。
