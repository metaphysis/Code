## 题目分析

本题是经典的 **$\texttt{Joseph Problem}$** 的一个变种。原 $\texttt{Joseph}$ 问题是通过递推公式 $r = (r + k) \mod i$ 来求解最后幸存者的编号，但 $\texttt{Joseph}$ 记错了算法，误以为是通过累加 $k \mod i$ 来求解。

### 问题转化

题目要求计算：
$$
S = \sum_{i=1}^n (k \mod i)
$$
其中 $1 \leq n, k \leq 10^9$。

### 直接计算的困难

如果直接循环 $i$ 从 $1$ 到 $n$ 计算 $k \mod i$，时间复杂度为 $O(n)$，在 $n$ 和 $k$ 达到 $10^9$ 时完全不可行，必须寻找更高效的数学方法。

### 数学转换

利用模运算的定义：
$$
k \mod i = k - i \times \left\lfloor \frac{k}{i} \right\rfloor
$$
我们可以将原式改写为：
$$
S = \sum_{i=1}^n (k \mod i) = \sum_{i=1}^n \left(k - i \times \left\lfloor \frac{k}{i} \right\rfloor\right)
$$
进一步化简得：
$$
S = n \times k - \sum_{i=1}^n i \times \left\lfloor \frac{k}{i} \right\rfloor
$$

### 关键优化

现在问题转化为计算：
$$
T = \sum_{i=1}^n i \times \left\lfloor \frac{k}{i} \right\rfloor
$$

观察 $\left\lfloor \frac{k}{i} \right\rfloor$ 的值，当 $i$ 变化时，这个值会在一段区间内保持不变。我们可以利用这一性质进行分段计算：

1. 对于 $i \leq \min(n, k)$ 的部分，我们按值域分段计算
2. 对于 $i > k$ 的部分，$\left\lfloor \frac{k}{i} \right\rfloor = 0$，贡献为 $0$

### 分段计算原理

设当前区间起始为 $i$，计算 $q = \left\lfloor \frac{k}{i} \right\rfloor$，则满足 $\left\lfloor \frac{k}{j} \right\rfloor = q$ 的最大 $j$ 为：
$$
j = \min\left(n, \left\lfloor \frac{k}{q} \right\rfloor\right)
$$
在区间 $[i, j]$ 上，对 $T$ 的贡献为：
$$
q \times \frac{(i + j) \times (j - i + 1)}{2}
$$
然后将 $i$ 更新为 $j + 1$，继续计算下一个区间。

### 算法复杂度

该算法的时间复杂度为 $O(\sqrt{k})$，能够高效处理 $n, k \leq 10^9$ 的情况。

## 代码实现

```cpp
// Joseph's Problem
// UVa ID: 1363
// Verdict: Accepted
// Submission Date: 2025-10-23
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
int main() {
    long long n, k;
    while (cin >> n >> k) {
        long long totalSum = 0;
        long long maxIndex = min(n, k);
        
        // 分段计算 sum_{i=1..maxIndex} i * floor(k/i)
        long long currentIndex = 1;
        while (currentIndex <= maxIndex) {
            long long quotient = k / currentIndex;
            long long nextIndex = min(maxIndex, k / quotient);
            // 在区间 [currentIndex, nextIndex] 内 floor(k/t) = quotient
            long long segmentSum = quotient * (currentIndex + nextIndex) * (nextIndex - currentIndex + 1) / 2;
            totalSum += segmentSum;
            currentIndex = nextIndex + 1;
        }
        
        long long result = n * k - totalSum;
        cout << result << endl;
    }
    return 0;
}
```

### 代码说明

- `n` 和 `k` 分别表示题目中的 $n$ 和 $k$
- `totalSum` 存储 $T = \sum i \times \lfloor k/i \rfloor$ 的值
- `maxIndex = min(n, k)` 确定需要计算的最大索引
- 使用 `currentIndex` 遍历区间，`quotient` 表示当前的 $\lfloor k/i \rfloor$ 值
- `nextIndex` 表示当前商值不变的最大索引
- `segmentSum` 计算当前区间的贡献值
- 最终结果 `result = n * k - totalSum` 即为所求的 $\sum (k \mod i)$

该算法通过数学转换和分段优化，将原本 $O(n)$ 的复杂度降低到 $O(\sqrt{k})$，能够高效解决大规模数据的问题。
