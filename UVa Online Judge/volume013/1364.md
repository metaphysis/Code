[UVa 1364 Knights of the Round Table](https://blog.csdn.net/metaphysis/article/details/153827776)

## 题目描述

亚瑟王国的骑士数量近年来急剧增加，导致圆桌会议很难全员到齐。骑士们在讨论时容易激动，尤其是在饮酒后。为了防止冲突，梅林制定了两个规则：

1. **憎恨关系限制**：互相憎恨的骑士不能坐在相邻位置。
2. **奇数人数限制**：圆桌边的骑士人数必须是奇数（且至少 $3$ 人）。

如果一个骑士无法参与任何满足条件的座位安排，他就会被开除。我们需要计算必须开除的骑士数量。

---

## 输入格式

输入包含多个测试块，每块格式如下：

- 第一行：$n$ $m$（骑士数 $n$，憎恨关系数 $m$）
- 接下来 $m$ 行：每行两个整数 $k_1$ $k_2$，表示 $k_1$ 和 $k_2$ 互相憎恨
- 以 $n = 0, m = 0$ 结束输入

**数据范围**：
- $1 \leq n \leq 1000$
- $1 \leq m \leq 10^6$

---

## 输出格式

对每个测试块输出一个整数：必须开除的骑士数量。

---

## 题目分析

### 问题转化

将骑士视为图 $G$ 的顶点，如果两个骑士互相憎恨，则在图中连一条边。我们需要在 $G$ 的**补图** $\overline{G}$ 中寻找满足条件的座位安排：

- 在 $\overline{G}$ 中，边表示可以相邻坐的骑士对。
- 圆桌座位对应 $\overline{G}$ 中的一个环，且环的长度为奇数（至少 $3$）。

因此，问题转化为：在 $\overline{G}$ 中，找出所有属于**长度 $\geq 3$ 的奇环**的顶点。不属于任何奇环的顶点对应的骑士将被开除。

### 关键结论

- 一个图是二分图 ⇔ 图中不含奇环。
- 如果一个点双连通分量（$\texttt{Biconnected Component}$）不是二分图，则它包含奇环，且该分量中**所有顶点**都属于某个奇环。

### 算法步骤

1. **建立原图**：使用邻接矩阵存储憎恨关系。
2. **构建补图**：在原图中没有边的顶点对，在补图中连边。
3. **寻找点双连通分量**：使用 $\texttt{Tarjan}$ 算法。
4. **检查奇环**：对每个大小 $\geq 3$ 的点双连通分量进行二分图判定：
   - 如果不是二分图，则标记该分量中所有顶点为“安全”。
5. **统计结果**：未被标记的顶点数量即为开除的骑士数。

### 复杂度分析

- 邻接矩阵空间：$O(n^2)$
- $\texttt{Tarjan}$ 算法时间：$O(n + m')$，其中 $m'$ 是补图的边数
- 二分图检查：$O(n + m')$
- 总复杂度在 $n \leq 1000$ 时可行

## 代码实现

```cpp
// Knights of the Round Table
// UVa ID: 1364

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 1005;

bool hate[MAXN][MAXN]; // 原图的憎恨关系矩阵
vector<int> graph[MAXN]; // 补图的邻接表
int n, m;

// Tarjan 算法相关变量
int dfn[MAXN], low[MAXN], dfsClock;
stack<int> stk;
vector<vector<int>> bccList; // 存储所有点双连通分量
bool isCut[MAXN]; // 标记割点

// 二分图染色检查
bool checkBipartite(int start, const vector<int>& component, int color[]) {
    queue<int> q;
    q.push(start);
    color[start] = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : graph[u]) {
            // 检查 v 是否在当前分量中
            bool inComponent = false;
            for (int x : component) {
                if (x == v) {
                    inComponent = true;
                    break;
                }
            }
            if (!inComponent) continue;

            if (color[v] == -1) {
                color[v] = color[u] ^ 1;
                q.push(v);
            } else if (color[v] == color[u]) {
                return false; // 发现奇环
            }
        }
    }
    return true;
}

void tarjan(int u, int parent) {
    dfn[u] = low[u] = ++dfsClock;
    stk.push(u);
    int childCount = 0;
    
    for (int v = 1; v <= n; v++) {
        if (!hate[u][v] && u != v) { // 补图中的边
            if (!dfn[v]) {
                childCount++;
                tarjan(v, u);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    if (parent != -1 || childCount > 1) isCut[u] = true;
                    vector<int> component;
                    component.push_back(u);
                    while (true) {
                        int x = stk.top(); stk.pop();
                        component.push_back(x);
                        if (x == v) break;
                    }
                    bccList.push_back(component);
                }
            } else if (v != parent && dfn[v] < dfn[u]) {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    while (cin >> n >> m, n || m) {
        // 初始化
        memset(hate, 0, sizeof(hate));
        for (int i = 1; i <= n; i++) graph[i].clear();
        bccList.clear();
        while (!stk.empty()) stk.pop();
        dfsClock = 0;
        memset(dfn, 0, sizeof(dfn));
        memset(low, 0, sizeof(low));
        memset(isCut, 0, sizeof(isCut));

        // 读入憎恨关系
        for (int i = 0; i < m; i++) {
            int a, b;
            cin >> a >> b;
            hate[a][b] = hate[b][a] = true;
        }

        // 构建补图
        for (int i = 1; i <= n; i++) {
            for (int j = i + 1; j <= n; j++) {
                if (!hate[i][j]) {
                    graph[i].push_back(j);
                    graph[j].push_back(i);
                }
            }
        }

        // 使用 Tarjan 算法找点双连通分量
        for (int i = 1; i <= n; i++) {
            if (!dfn[i]) {
                tarjan(i, -1);
                // 处理栈中剩余的点
                if (!stk.empty()) {
                    vector<int> component;
                    while (!stk.empty()) {
                        component.push_back(stk.top());
                        stk.pop();
                    }
                    bccList.push_back(component);
                }
            }
        }

        // 标记能留下的骑士
        bool safe[MAXN] = {false};
        for (const auto& component : bccList) {
            if (component.size() < 3) continue; // 奇环至少需要 3 个点
            int color[MAXN];
            memset(color, -1, sizeof(color));
            // 检查是否为二分图
            if (!checkBipartite(component[0], component, color)) {
                // 不是二分图，包含奇环，标记所有顶点
                for (int u : component) safe[u] = true;
            }
        }

        // 统计必须开除的人数
        int expelledCount = 0;
        for (int i = 1; i <= n; i++) {
            if (!safe[i]) expelledCount++;
        }
        cout << expelledCount << "\n";
    }

    return 0;
}
```

## 总结

本题通过图论建模，将骑士座位问题转化为补图中的奇环检测问题。利用点双连通分量和二分图性质，高效地找出所有能参与合法座位的骑士。算法结合了 $\texttt{Tarjan}$ 求点双连通分量和 $\texttt{BFS}$ 染色法，在合理复杂度内解决了问题。
