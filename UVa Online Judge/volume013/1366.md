## 题目分析

### 问题描述

$\texttt{NASA}$ 在火星上发现了一个 $n \times m$ 的矩形区域，富含两种重要矿物：$\texttt{yeyenum}$ 和 $\texttt{bloggium}$。每个单元格中含有不同数量的这两种矿物。

宇航员需要在区域西边建造 $\texttt{yeyenum}$ 精炼厂，在北边建造 $\texttt{bloggium}$ 精炼厂。任务是为该区域设计传送带系统，使得能够开采的矿物总量最大化。

### 传送带规则

1. **两种传送带类型**：
   - 东西向：将 $\texttt{yeyenum}$ 向西运输
   - 南北向：将 $\texttt{bloggium}$ 向北运输

2. **限制条件**：
   - 每个单元格只能建造一种传送带
   - 矿物运输必须直线进行，不能转弯
   - 如果南北向传送带上方有东西向传送带，矿物会丢失
   - 如果东西向传送带左侧有南北向传送带，矿物会丢失
   - 矿物必须在开采的单元格立即装上相应传送带

### 问题转化

实际上，整个网格可以被一条从西北到东南的阶梯状分界线划分为两个区域：
- **左上区域**：全部使用南北向传送带，运输 $\texttt{bloggium}$ 到北边工厂
- **右下区域**：全部使用东西向传送带，运输 $\texttt{yeyenum}$ 到西边工厂

我们的目标是找到最优的分界线，使得两种矿物的总运输量最大。

## 解题思路

### 动态规划方法

我们使用动态规划来解决这个问题，定义以下数组和状态：

#### 预处理数组

1. **$Y[i][j]$**：第 $i$ 行前 $j$ 列的 $\texttt{yeyenum}$ 总和
   - 表示如果第 $i$ 行的前 $j$ 列都使用东西向传送带，能获得的 $\texttt{yeyenum}$ 总量

2. **$B[i][j]$**：第 $j$ 列前 $i$ 行的 $\texttt{bloggium}$ 总和
   - 表示如果第 $j$ 列的前 $i$ 行都使用南北向传送带，能获得的 $\texttt{bloggium}$ 总量

#### 动态规划状态

定义 **$dp[i][j]$**：考虑前 $i$ 行和前 $j$ 列时能获得的最大矿物量

#### 状态转移方程

对于每个位置 $(i, j)$，我们有两种选择：

1. **将第 $i$ 行的前 $j$ 列设为东西向传送带**
   - 收益为：$dp[i-1][j] + Y[i][j]$
   - 这意味着前 $i-1$ 行已经处理完毕，当前行新增 $Y[i][j]$ 的 $\texttt{yeyenum}$

2. **将第 $j$ 列的前 $i$ 行设为南北向传送带**
   - 收益为：$dp[i][j-1] + B[i][j]$
   - 这意味着前 $j-1$ 列已经处理完毕，当前列新增 $B[i][j]$ 的 $\texttt{bloggium}$

因此状态转移方程为：
$$dp[i][j] = \max(dp[i-1][j] + Y[i][j],\ dp[i][j-1] + B[i][j])$$

#### 边界条件
- $dp[0][j] = 0$（没有行时收益为 $0$）
- $dp[i][0] = 0$（没有列时收益为 $0$）

// Martian Mining

#include <bits/stdc++.h>
using namespace std;
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int n, m;
    while (cin >> n >> m && (n || m)) {
        vector<vector<int>> yey(n + 1, vector<int>(m + 1, 0));
        vector<vector<int>> blog(n + 1, vector<int>(m + 1, 0));
        // 输入 yeyenum
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= m; ++j)
                cin >> yey[i][j];
        // 输入 bloggium
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= m; ++j)
                cin >> blog[i][j];
        // 预处理 Y[i][j]：第 i 行前 j 列的 yeyenum 和
        vector<vector<int>> Y(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= m; ++j)
                Y[i][j] = Y[i][j - 1] + yey[i][j];
        // 预处理 B[i][j]：第 j 列前 i 行的 bloggium 和
        vector<vector<int>> B(n + 1, vector<int>(m + 1, 0));
        for (int j = 1; j <= m; ++j)
            for (int i = 1; i <= n; ++i)
                B[i][j] = B[i - 1][j] + blog[i][j];
        // DP
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= m; ++j)
                dp[i][j] = max(dp[i - 1][j] + Y[i][j], dp[i][j - 1] + B[i][j]);
        cout << dp[n][m] << "\n";
    }
    return 0;
}
