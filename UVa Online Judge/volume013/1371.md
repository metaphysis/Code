## 题目描述

给定两个字符串 $A$ 和 $B$ ，定义编辑距离为将 $A$ 转换为 $B$ 所需的最少操作次数，允许的操作有修改、删除和插入。

一个字符串 $p$ 被称为字符串 $x$ 的精确周期，如果 $x$ 可以写成 $x = p^k$ 且 $p$ 最短。类似地，我们定义近似周期：将 $x$ 划分为非空子串 $p_1, p_2, \dots, p_t$ ，如果 $y$ 与每个 $p_i$ 的编辑距离都不超过整数 $k$ ，则称 $y$ 是 $x$ 的一个 $k$ - 近似周期。

**问题**：给定字符串 $x$ 和 $y$ ，求最小的 $k$ 使得 $y$ 是 $x$ 的一个 $k$ - 近似周期。

**输入**：第一行是测试用例数 $T$ ，每个测试用例包含两行，第一行为 $y$ ，第二行为 $x$ 。$1 \le |y| \le 50$ ，$1 \le |x| \le 5000$ ，字符集为小写英文字母。

**输出**：每个测试用例输出一行，即最小的 $k$ 。

## 题目分析

本题的核心是要找到一个最小的整数 $k$ ，使得我们可以将长字符串 $x$ 切割成若干段，每一段都与给定的模式串 $y$ 的编辑距离不超过 $k$ 。这实际上是一个**最小化最大段编辑距离**的最优化问题，并且切割方式是任意的。

直接枚举所有切割方式显然不可行，因为 $|x|$ 最大可达 $5000$ ，切割方案是指数级的。我们需要一种更高效的方法，同时处理“切割”和“编辑距离计算”两个维度。

## 解题思路

我们有两种典型的解法，它们分别对应了上述两份通过代码。

### 解法一：二分答案 + 动态规划验证

这是最直观的思路：我们对答案 $k$ 进行二分搜索，然后检查是否存在一种合法的切割方式。

#### 二分答案的可行性

最小可能的 $k$ 为 $0$（当 $x$ 可以由 $y$ 精确重复拼接而成），最大可能的 $k$ 不超过 $|y|$（因为任何字符串与 $y$ 的编辑距离最多为 $|y|$，例如全部删除后再插入 $y$）。因此二分范围是 $[0, |y|]$ ，二分次数约为 $\log_2 50 \le 6$ 次。

#### 验证函数的实现

对于给定的 $k$ ，我们需要判断能否将 $x$ 切成若干段，使得每段与 $y$ 的编辑距离 $\le k$ 。这可以用 $\texttt{DP}$ 完成：

- 定义 $dp[i]$ 表示 $x[0..i-1]$ 能否被成功划分，初始 $dp[0] = \text{true}$ 。
- 转移：如果存在 $j < i$ 使得 $dp[j] = \text{true}$ 且子串 $x[j..i-1]$ 与 $y$ 的编辑距离 $\le k$ ，则 $dp[i] = \text{true}$ 。
- 最终检查 $dp[|x|]$ 即可。

#### 编辑距离的快速计算

在验证过程中，我们需要频繁判断某个子串与 $y$ 的编辑距离。如果每次都用标准的 $O(|y| \cdot \text{len})$ 算法计算，总复杂度会达到 $O(|x|^2 \cdot |y| \cdot \log |y|)$ ，对于 $|x| = 5000, |y| = 50$ 来说会超时。

优化策略是在固定起点 $j$ 时，逐步扩展终点 $i$ ，用滚动数组维护编辑距离，并利用剪枝：一旦某次扩展中编辑距离的最小值已经超过 $k$ ，则继续扩展只会更大，可以直接跳出。这样每个起点的计算量约为 $O(|y| \cdot (|y| + k))$ ，总复杂度 $O(|x| \cdot |y| \cdot k \cdot \log |y|)$ ，可以通过。

### 解法二：融合 $\texttt{DP}$（状态合并法）

第二种解法更为巧妙，它将“切割”和“编辑距离”两个过程融合在一个二维 $\texttt{DP}$ 中，省去了二分，直接得到答案。

#### $\texttt{DP}$ 状态定义

定义 $dp[i][j]$ 表示处理到 $x$ 的前 $i$ 个字符，当前正在匹配的段已经匹配到 $y$ 的第 $j$ 个字符时，所有已完成段的总编辑次数的最小值。这里 $j$ 的取值范围是 $0$ 到 $|y|$ ，其中 $j = m$ 表示当前段已经完整匹配了 $y$ 。

#### 状态转移

1. **段重置**：如果 $dp[i][m] \le k$ ，说明在位置 $i$ 可以结束当前段，且该段的编辑代价不超过 $k$ 。那么我们可以从这里开始新的一段，因此 $dp[i][0] = 0$ 。这是实现“切割”的关键。
2. **匹配 / 替换**：将 $x[i+1]$ 与 $y[j+1]$ 对齐，如果字符相同则代价为 $0$ ，否则为 $1$ ，即 $dp[i+1][j+1] = \min(dp[i+1][j+1], dp[i][j] + \text{cost})$ 。
3. **删除**：跳过 $x[i+1]$ ，代价为 $1$ ，即 $dp[i+1][j] = \min(dp[i+1][j], dp[i][j] + 1)$ 。
4. **插入**：在 $x$ 中插入 $y[j+1]$ ，代价为 $1$ ，即 $dp[i][j+1] = \min(dp[i][j+1], dp[i][j] + 1)$ 。

#### 求解答案

我们并不需要二分 $k$ ，而是通过二分搜索来找到最小的 $k$ 使得 $dp[n][m] \le k$ 。但由于 $dp$ 本身依赖于 $k$（通过段重置的条件），我们仍然需要二分。不过这个 $\texttt{DP}$ 的形式更紧凑，常数更小，运行效率更高。

#### 复杂度分析

- 时间复杂度：$O(|x| \cdot |y| \cdot \log |y|)$ ，约 $5000 \times 50 \times 6 = 1.5 \times 10^6$ 次状态转移，非常快。
- 空间复杂度：$O(|x| \cdot |y|)$ ，约 $5000 \times 50 = 2.5 \times 10^5$ 个整数，可以接受。

以下是上述两种解法的完整代码。

### 解法一：二分答案 + 分段验证

```cpp
// Period

// UVa Run Time: 1.850s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int n, m;
string x, y;

// 返回 true 如果存在一种划分使得每段与 y 的编辑距离 <= k
bool check(int k) {
    // reachable[i] 表示 x[0..i-1] 能否被成功划分
    vector<bool> reachable(n + 1, false);
    reachable[0] = true;
    
    // 对每个可能的分段起点
    for (int start = 0; start < n; ++start) {
        if (!reachable[start]) continue;
        
        // 计算从 start 开始的所有子串与 y 的编辑距离
        // dpPrev[j] 表示 x[start..cur-1] 与 y[0..j-1] 的编辑距离
        vector<int> dpPrev(m + 1), dpCurr(m + 1);
        for (int j = 0; j <= m; ++j) dpPrev[j] = j;
        
        int curLen = 0;
        for (int end = start + 1; end <= n; ++end) {
            ++curLen;
            dpCurr[0] = curLen;
            int minVal = curLen;
            
            for (int j = 1; j <= m; ++j) {
                int cost = (x[end - 1] == y[j - 1]) ? 0 : 1;
                dpCurr[j] = min({dpPrev[j] + 1, dpCurr[j - 1] + 1, dpPrev[j - 1] + cost});
                minVal = min(minVal, dpCurr[j]);
            }
            
            if (dpCurr[m] <= k) reachable[end] = true;
            if (minVal > k) break;  // 继续扩展只会更大，提前退出
            
            swap(dpPrev, dpCurr);
        }
    }
    return reachable[n];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    while (T--) {
        cin >> y >> x;
        n = x.size(), m = y.size();
        
        int lo = 0, hi = m, ans = m;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (check(mid)) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 解法二：融合 $\texttt{DP}$ 法

```cpp
// Period
// UVa ID: 1371
// Verdict: Accepted
// Submission Date: 2026-06-03
// UVa Run Time: 0.220s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
const int MAX_N = 5004;
const int MAX_M = 52;

int n, m;
char yStr[MAX_M], xStr[MAX_N];
int dp[MAX_N][MAX_M];

bool check(int k) {
    memset(dp, 0x3f, sizeof(dp));
    dp[0][0] = 0;
    
    for (int i = 0; i <= n; ++i) {
        if (dp[i][m] <= k) dp[i][0] = 0;
        
        for (int j = 0; j <= m; ++j) {
            if (dp[i][j] > k) continue;
            
            if (i < n && j < m) {
                int cost = (xStr[i + 1] == yStr[j + 1]) ? 0 : 1;
                dp[i + 1][j + 1] = min(dp[i + 1][j + 1], dp[i][j] + cost);
            }
            if (i < n) dp[i + 1][j] = min(dp[i + 1][j], dp[i][j] + 1);
            if (j < m) dp[i][j + 1] = min(dp[i][j + 1], dp[i][j] + 1);
        }
    }
    
    return dp[n][m] <= k;
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        scanf("%s", yStr + 1);
        scanf("%s", xStr + 1);
        m = strlen(yStr + 1);
        n = strlen(xStr + 1);
        
        int left = 0, right = m, ans = m;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (check(mid)) {
                ans = mid;
                right = mid - 1;
            } else left = mid + 1;
        }
        
        printf("%d\n", ans);
    }
    return 0;
}
```

## 总结

本题两种解法各有优劣：

- **解法一**思路直观，易于理解，通过二分答案和分段验证，配合编辑距离的滚动数组计算和剪枝，能够高效求解。
- **解法二**将分段逻辑融入编辑距离 $\texttt{DP}$ 中，状态设计更为紧凑，常数更小，运行速度更快。

实际提交中，两种方法都能在规定时间内通过。推荐优先理解第一种解法，因为它更符合常规思维；在追求极致效率时，可以采用第二种解法。
