## 题目描述

给定一个正整数 $n$，我们需要计算 $x^n$，只能从 $x$ 开始，通过一系列的乘法和除法运算（每次运算的结果必须是 $x$ 的正整数次幂），求最少需要的运算次数。

例如：
- 计算 $x^{31}$：
  - 只使用乘法：最少需要 $7$ 次乘法
  - 使用乘法和除法：最少需要 $6$ 次运算（$5$ 次乘法 + $1$ 次除法）

**输入**：多组测试数据，每行一个整数 $n$ ($1 \leq n \leq 1000$)，以 $0$ 结束
**输出**：对于每个 $n$，输出最少运算次数

## 题目分析

### 问题本质

这是一个典型的**加法链（$\texttt{Addition Chain}$）问题**的扩展版本。在标准的加法链问题中，我们只能使用加法（对应乘法运算），而本题允许使用减法（对应除法运算），因此这是一个**加法-减法链（$\texttt{Addition-Subtraction Chain}$）问题**。

### 关键观察

1. **运算规则**：每次运算只能是已有的两个幂次相加（乘法）或相减（除法），结果必须是正幂次
2. **起始状态**：初始时只有 $x^1$
3. **目标状态**：得到 $x^n$
4. **最优性**：允许除法可以显著减少运算次数，例如 $x^{31}$ 可以从 $6$ 次运算减少到 $5$ 次

### 算法选择

由于 $n \leq 1000$，我们可以使用**迭代加深搜索（$\texttt{Iterative Deepening DFS}$）** 结合剪枝策略：

- **迭代加深**：从深度 $1$ 开始逐步增加搜索深度，找到最少步数
- **状态表示**：用一个数组记录当前已得到的幂次
- **运算规则**：从当前已有的幂次中选择两个进行加法或减法
- **剪枝策略**：
  - 如果当前最大值在剩余步数内翻倍也达不到目标，则剪枝
  - 避免重复状态

### 复杂度分析

- 由于使用迭代加深，空间复杂度为 $O(d)$，其中 $d$ 是最少步数
- 时间复杂度取决于搜索树的规模，但通过剪枝可以控制在可接受范围内
- 对于 $n \leq 1000$，实际运行时间在合理范围内

## 算法实现细节

### 核心思想

1. **状态扩展**：每一步从当前已有的幂次中选择两个进行组合
   - 加法：$a + b$（对应乘法：$x^a \times x^b = x^{a+b}$）
   - 减法：$a - b$，要求 $a > b$（对应除法：$x^a \div x^b = x^{a-b}$）

2. **剪枝优化**：
   - 设当前最大值为 $m$，剩余步数为 $k$
   - 如果 $m \times 2^k < n$，则不可能达到目标，剪枝

3. **搜索顺序**：从大到小尝试，优先考虑较大的新值

### 特殊情况处理

- $n = 1$：不需要任何运算，直接输出 $0$
- 其他情况：从深度 $1$ 开始迭代加深搜索

```cpp
// Power Calculus

#include <iostream>
#include <algorithm>
using namespace std;

int target;        // 目标指数 n
int maxDepth;      // 当前迭代加深的最大深度
int currentChain[20]; // 存储当前的幂次链，currentChain[i] 表示第 i 步得到的指数

/**
 * 迭代加深搜索函数
 * @param currentStep 当前搜索的步数
 * @return 是否在当前深度限制下找到解
 */
bool idaStar(int currentStep) {
    // 如果当前步数已经达到目标，检查是否找到解
    if (currentStep == maxDepth) {
        return currentChain[currentStep] == target;
    }
    
    // 剪枝：如果当前最大值在剩余步数内即使每一步都翻倍也达不到目标，则剪枝
    // 剩余步数 = maxDepth - currentStep
    int currentMax = currentChain[currentStep];
    if ((currentMax << (maxDepth - currentStep)) < target) {
        return false;
    }
    
    // 尝试所有可能的组合：当前最大值与链中已有的每个值进行运算
    for (int i = currentStep; i >= 0; i--) {
        // 加法运算（乘法）：currentChain[currentStep] + currentChain[i]
        int nextValue = currentChain[currentStep] + currentChain[i];
        if (nextValue <= 10000) {  // 防止数值过大
            currentChain[currentStep + 1] = nextValue;
            if (idaStar(currentStep + 1)) {
                return true;
            }
        }
        
        // 减法运算（除法）：currentChain[currentStep] - currentChain[i]
        nextValue = currentChain[currentStep] - currentChain[i];
        if (nextValue > 0) {  // 结果必须为正指数
            currentChain[currentStep + 1] = nextValue;
            if (idaStar(currentStep + 1)) {
                return true;
            }
        }
    }
    return false;
}

int main() {
    while (cin >> target && target != 0) {
        // 特殊情况：x^1 不需要任何运算
        if (target == 1) {
            cout << 0 << endl;
            continue;
        }
        
        // 初始化幂次链，起始状态为 x^1
        currentChain[0] = 1;
        maxDepth = 1;
        
        // 迭代加深搜索：从深度1开始逐步增加深度限制
        while (true) {
            if (idaStar(0)) {
                cout << maxDepth << endl;
                break;
            }
            maxDepth++;
        }
    }
    return 0;
}
```

## 总结

本题通过迭代加深搜索结合有效的剪枝策略，解决了加法-减法链的最小长度问题。关键点在于：

1. 理解乘法对应加法、除法对应减法的关系
2. 使用迭代加深保证找到最少步数解
3. 通过合理的剪枝大幅减少搜索空间
4. 注意边界情况的处理

该算法对于 $n \leq 1000$ 的数据规模具有很好的效率和正确性。
