## 题目描述

在公元 $29XX$ 年，地球上某个小国的政府出台了一部法律，限制人们的名只能使用其文化中的传统名字，以保护其文化独特性。该国的语言学家每年制定一套规则，只有符合这些规则的名字才被允许在该年使用。此外，法律还要求每个人使用根据出生日期计算出的特定长度的名字，否则太多人会使用相同的非常流行的名字。自该法律颁布以来，新生儿父母们的常见任务是：在给定长度的合法名字中，找出按字母顺序排列最靠前的名字，因为在他们的文化中，字母顺序靠前的名字有各种好处。

合法名字是仅由小写字母组成的字符串，可以通过对初始字符串 `"S"`（一个仅由单个大写 `S` 组成的字符串）反复应用规则集得到。

每条规则的形式为 $A \rightarrow \alpha$，其中 $A$ 是大写字母，$\alpha$ 是由小写字母和 / 或大写字母组成的字符串。将这样的规则应用于字符串，即将字符串中出现的字母 $A$ 替换为字符串 $\alpha$。如果原字符串中有两个或更多 $A$，可以任意选择一个进行替换。

下面是一个规则集示例：

$$
\mathrm{S} \rightarrow \mathrm{aAB} \quad (1) \\
\mathrm{A} \rightarrow \mathrm{aA} \quad (2) \\
\mathrm{A} \rightarrow \mathrm{Aa} \quad (3) \\
\mathrm{B} \rightarrow \mathrm{AbbA} \quad (4)
$$

将规则 $(1)$ 应用于 `"S"`，得到 `"aAB"`。将规则 $(2)$ 应用于它，结果为 `"aB"`，因为 `A` 被替换为空串。然后可以使用规则 $(4)$ 得到 `"aAbbA"`。对第一个 `A` 应用规则 $(3)$ 得到 `"aAabbA"`。对末尾的 `A` 应用规则 $(2)$ 得到 `"aAabb"`。最后再次对剩余的 `A` 应用规则 $(2)$ 得到 `"aabb"`。由于该字符串中不再有大写字母，因此 `"aabb"` 是一个合法名字。

该国的语言学家有时可能会定义荒谬的规则集，例如：

$$
\mathrm{S} \rightarrow \mathrm{sA} \quad (1) \\
\mathrm{A} \rightarrow \mathrm{saS} \quad (2) \\
\mathrm{B} \rightarrow \mathrm{aaa} \quad (3)
$$

使用该规则集唯一可能的重写序列是：

$$
\mathrm{S} \xrightarrow{(1)} \mathrm{sA} \xrightarrow{(2)} \mathrm{saS} \xrightarrow{(1)} \mathrm{saA} \xrightarrow{(2)} \cdots
$$

这永远不会终止，因此不存在合法名字。另外，规则 $(3)$ 永远无法使用，因为其左部 `B` 没有在其他地方出现。

某些大写字母可能在重写步骤中出现但没有为其提供规则。极端情况下，甚至 `S` 可能没有规则，此时当然也没有合法名字。可怜的没有名字的婴儿们，唉！

现在你的任务是编写一个程序，在给定规则集中找到给定长度的合法名字中按字母顺序最靠前的名字。

## 输入格式

输入是一系列数据集，后跟一行包含两个由空格分隔的零表示输入结束。每个数据集以一行开始，包含两个由空格分隔的整数 $n$ 和 $l$，其中 $n$（$1 \le n \le 50$）是规则数量，$l$（$0 \le l \le 20$）是所需名字长度。之后是 $n$ 行，每行表示一条规则。每行以一个大写字母 `'A'` 到 `'Z'` 开头，后跟字符 `'='`（代替 $\rightarrow$），再后跟规则的右部，右部是由字母 `'A'` 到 `'Z'` 和 `'a'` 到 `'z'` 组成的字符串。右部长度不超过 $10$，可能为零。表示规则的行中没有空格。

## 输出格式

输出由若干行组成，每行显示与输入中相应数据集对应的答案。每行是由小写字母 `'a'` 到 `'z'` 组成的字符串，即符合给定规则和长度的第一个合法名字。当给定规则集没有给定长度的合法字符串时，对应输出行应显示单个连字符 `'-'`。输出中不应包含其他字符。

## 题目分析

本题本质上是一个**上下文无关文法**（$\texttt{Context-Free Grammar}$）的推导问题。给定一组产生式规则，起始符号为 `S`，目标是从 `S` 出发，经过有限步推导，得到一个仅由小写字母组成的、长度为 $l$ 的字符串，并且要求这个字符串在所有可能的推导结果中字典序最小。

关键约束条件为：

- 目标长度 $l \le 20$，非常小。
- 规则数量 $n \le 50$。
- 每条规则右部长度 $\le 10$。
- 非终结符只有 $26$ 个大写字母。

由于目标长度很小，我们可以考虑使用**动态规划**（$\texttt{Dynamic Programming}$）按长度递增的方式计算每个非终结符能够生成的所有长度的字典序最小字符串。

直接的想法是定义 $\textit{dp}[A][len]$ 表示从非终结符 $A$ 出发，能够生成的、长度为 $len$ 的字典序最小的纯小写字符串。如果不存在这样的字符串，则标记为不可达。

对于规则 $A \rightarrow \alpha$，其中 $\alpha$ 是由大写字母（非终结符）和小写字母（终结符）组成的字符串。若 $\alpha$ 中所有字符均为小写字母，则 $\textit{dp}[A][|\alpha|]$ 可以直接更新为 $\alpha$。若 $\alpha$ 中包含非终结符，则需要将 $\alpha$ 中的每个非终结符替换为某个长度的纯小写字符串，使得所有部分的长度之和加上固定小写字母的数量等于目标长度 $len$。由于右部长度 $\le 10$，非终结符的数量很少，我们可以枚举所有可能的长度分配方案。

然而，这种方法在处理规则之间的相互依赖时会遇到困难。例如规则 $S \rightarrow SA$ 和 $A \rightarrow a$，要计算 $\textit{dp}[S][len]$ 需要依赖 $\textit{dp}[S][k]$ 和 $\textit{dp}[A][len-k]$，其中 $k < len$，这符合按长度递增计算的顺序。但若规则中存在 $A \rightarrow B$ 和 $B \rightarrow A$ 这样的循环依赖，且两者都能生成空串，则简单的按长度递增 DP 可能无法处理同一长度内的相互转移。

观察到一个重要性质：如果 $X \rightarrow YZ$ 且 $Y$ 可以生成空串，则 $X$ 可以生成 $Z$ 所能生成的所有字符串；同理，如果 $Z$ 可以生成空串，则 $X$ 可以生成 $Y$ 所能生成的所有字符串。这种转移发生在**同一长度**上，因为空串的长度为 $0$，不会改变总长度。因此，我们需要在处理完所有跨长度的转移后，在同一长度内进行闭包计算。

## 解题思路

### 核心思想：符号化子串 + 二叉树分解 + 分层 $\texttt{DP}$
#### 1. 符号化所有子串

将每条规则右部的所有**后缀子串**都作为一个独立的符号加入到符号系统中。例如对于规则右部 `"aAB"`，其后缀子串包括 `"aAB"`、`"AB"`、`"B"`。每个符号都有一个唯一的整数 ID，同时记录其对应的原始字符串。这样做的目的是将任意长度的字符串分解为两个部分的组合：`head + tail`，其中 `head` 是第一个字符（可能为大写或小写），`tail` 是剩余部分。

#### 2. 建立二叉分解关系

对于每个符号 $X$，如果其对应的字符串可以分解为 $Y + Z$（其中 $Y$ 是第一个字符对应的符号，$Z$ 是剩余后缀对应的符号），则建立关系：

- $Y$ 和 $Z$ 可以组合成 $X$，即 $\textit{dp}[X][len] = \min(\textit{dp}[X][len], \textit{dp}[Y][k] + \textit{dp}[Z][len-k])$。
- 同时记录 $\textit{head}[X] = Y$ 和 $\textit{tail}[X] = Z$，用于跨长度的组合转移。

这种分解将任意长度的字符串转化为二叉树结构，使得 DP 可以像处理二叉树的拼接一样处理字符串的组合。

#### 3. 两种 $\texttt{DP}$ 转移

算法按目标长度 $len$ 从 $0$ 到 $L$ 递增计算，对于每个长度，执行两种转移：

**跨长度转移（组合转移）**：

$$
\textit{dp}[X][len] = \min_{1 \le k < len} \left( \textit{dp}[\textit{head}[X]][k] + \textit{dp}[\textit{tail}[X]][len-k] \right)
$$

这表示符号 $X$ 对应的字符串可以拆分为 $\textit{head}[X]$ 和 $\textit{tail}[X]$ 两个部分，分别生成长度为 $k$ 和 $len-k$ 的字符串后拼接。

**同层转移（空串消除转移）**：

对于规则 $A \rightarrow \alpha$，建立反向边 $\alpha \rightarrow A$。如果 $\alpha$ 可以分解为 $P + Q$，且 $P$ 能生成空串（即 $\textit{dp}[P][0]$ 存在），则 $A$ 可以生成 $Q$ 所能生成的所有字符串。这种转移不改变总长度，因此在同一长度内通过**优先队列**进行闭包传播。

具体实现中，$\textit{trans}[X]$ 存储所有形如 $X \rightarrow YZ$ 的分解关系，其中 $Y$ 是可能生成空串的部分。在 `search(len)` 函数中，所有当前长度可达的符号被加入优先队列，按字典序从小到大弹出，然后通过 $\textit{trans}$ 边进行传播，确保同一长度内的所有可达状态都被发现，且每个状态首次被访问时得到的就是字典序最小的结果。

### 算法正确性证明

1. **基础情况**：符号本身就是纯小写字符串时，$\textit{dp}[id][|s|] = s$ 作为初始值。

2. **跨长度转移的正确性**：若符号 $X$ 对应的字符串可以分解为 $Y + Z$，则 $X$ 能生成的所有字符串都可以由 $Y$ 生成的字符串和 $Z$ 生成的字符串拼接而成。由于 $Y$ 和 $Z$ 的长度都小于 $X$ 的长度（当 $X$ 长度 $>1$ 时），按长度递增处理保证了 $\textit{dp}[Y]$ 和 $\textit{dp}[Z]$ 已经计算完毕。

3. **同层转移的正确性**：若存在规则 $A \rightarrow \alpha$，且 $\alpha$ 可以分解为 $P + Q$，其中 $P$ 能生成空串，则 $A$ 能生成 $Q$ 所能生成的所有字符串。这种转移不改变总长度，因此必须在同一长度内处理。通过优先队列按字典序进行闭包传播，保证了所有可达状态都被发现，且每个状态取到的是字典序最小的字符串。

4. **终止性**：由于长度 $L \le 20$，按长度递增处理，每个状态最多被更新有限次，算法必然终止。

### 复杂度分析

- 符号数量：每个规则右部长度 $\le 10$，其所有后缀子串数量 $\le 10$，规则数量 $\le 50$，因此符号总数 $m \le 50 \times 10 + 1 = 501$，实际远小于此值。
- 长度范围：$L \le 20$。
- 状态总数：$m \times (L+1) \le 501 \times 21 \approx 10521$。
- 跨长度转移：对每个符号 $i$ 和每个长度 $len$，枚举 $k$ 从 $1$ 到 $len-1$，复杂度 $O(m \times L^2)$。
- 同层转移：使用优先队列，每个状态入队出队一次，每条 $\textit{trans}$ 边被检查一次，复杂度 $O((m + E) \log m)$，其中 $E$ 是 $\textit{trans}$ 边的数量。
- 总时间复杂度：$O(m \times L^2 + (m + E) \log m)$，在给定约束下完全可以接受。
- 空间复杂度：$O(m \times L + E)$。

## 代码实现

```cpp
// The Best Name for Your Baby
// UVa ID: 1375

// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAX_RULES = 55;
const int MAX_LEN = 25;
const int MAX_SYMS = 50 * 20 + 100;

struct Transform {
    int target;
    int emptyPart;
    Transform(int t, int e) : target(t), emptyPart(e) {}
};

int n, L;
int symCnt;
string rules[MAX_RULES];
string symStr[MAX_SYMS];
map<string, int> symToId;
string dp[MAX_SYMS][MAX_LEN];
vector<Transform> trans[MAX_SYMS];
int head[MAX_SYMS], tail[MAX_SYMS];

struct Node {
    int id;
    string str;
    Node(int i, string s) : id(i), str(s) {}
    bool operator<(const Node& other) const {
        return str > other.str;
    }
};

int getId(const string& s) {
    if (symToId.count(s)) return symToId[s];
    symStr[symCnt] = s;
    return symToId[s] = symCnt++;
}

void addIntermediateSymbol(const string& str) {
    int id = getId(str);
    int len = str.length();
    if (len < 2) return;
    int h = getId(str.substr(0, 1));
    int t = getId(str.substr(1));
    trans[h].push_back(Transform(id, t));
    trans[t].push_back(Transform(id, h));
    head[id] = h;
    tail[id] = t;
}

bool isLowercaseOnly(const string& s) {
    for (char c : s) {
        if (!(c >= 'a' && c <= 'z')) return false;
    }
    return true;
}

string minString(const string& a, const string& b) {
    if (a == "-") return b;
    if (b == "-") return a;
    return (a < b) ? a : b;
}

bool visited[MAX_SYMS];

void searchSameLevel(int len) {
    memset(visited, 0, sizeof(visited));
    priority_queue<Node> pq;
    
    for (int i = 0; i < symCnt; i++) {
        if (dp[i][len] != "-") {
            pq.push(Node(i, dp[i][len]));
        }
    }
    
    while (!pq.empty()) {
        Node cur = pq.top();
        pq.pop();
        int x = cur.id;
        string s = cur.str;
        if (visited[x]) continue;
        visited[x] = true;
        
        for (const Transform& t : trans[x]) {
            int target = t.target;
            int empty = t.emptyPart;
            if (dp[empty][0] == "" && (dp[target][len] == "-" || s < dp[target][len])) {
                dp[target][len] = s;
                pq.push(Node(target, s));
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    while (cin >> n >> L && (n != 0 || L != 0)) {
        symToId.clear();
        symCnt = 0;
        getId("");
        
        for (int i = 0; i < MAX_SYMS; i++) {
            trans[i].clear();
        }
        
        for (int i = 0; i < n; i++) {
            cin >> rules[i];
            int left = getId(rules[i].substr(0, 1));
            int right = getId(rules[i].substr(2));
            
            trans[right].push_back(Transform(left, getId("")));
            
            int len = rules[i].length();
            for (int k = 2; k < len; k++) {
                addIntermediateSymbol(rules[i].substr(k));
            }
        }
        
        for (int i = 0; i < symCnt; i++) {
            for (int j = 0; j <= L; j++) {
                dp[i][j] = "-";
            }
        }
        dp[0][0] = "";
        
        for (int len = 0; len <= L; len++) {
            for (int i = 0; i < symCnt; i++) {
                if ((int)symStr[i].length() == len && isLowercaseOnly(symStr[i])) {
                    dp[i][len] = symStr[i];
                }
                
                if ((int)symStr[i].length() < 2) continue;
                
                int first = head[i];
                int second = tail[i];
                for (int k = 1; k < len; k++) {
                    if (dp[first][k] != "-" && dp[second][len - k] != "-") {
                        dp[i][len] = minString(dp[i][len], dp[first][k] + dp[second][len - k]);
                    }
                }
            }
            searchSameLevel(len);
        }
        
        cout << dp[getId("S")][L] << "\n";
    }
    
    return 0;
}
```

## 总结

本题的核心技巧在于**将上下文无关文法的推导问题转化为字符串的二叉分解问题**，并通过以下关键技术实现高效求解：

1. **符号化所有子串**：将规则右部的所有后缀子串作为独立符号，将任意长度的字符串转化为二叉树结构，使得 $\texttt{DP}$ 可以像处理二叉树的拼接一样处理字符串的组合。

2. **分层动态规划**：按长度递增处理，先进行跨长度的组合转移，再进行同长度的空串消除闭包计算，保证了所有依赖关系的正确处理。

3. **优先队列传播**：在同层转移中使用优先队列按字典序处理状态，确保每个状态首次被访问时得到的就是字典序最小的结果，避免了重复更新。

4. **空串处理**：将空串作为一个特殊符号（$\texttt{ID}$ 为 $0$），通过 $\textit{dp}[0][0] = ""$ 统一处理所有空串相关的转移。

该算法的精妙之处在于它没有直接处理规则的递归推导，而是通过将规则右部拆分为二叉树结构，将问题转化为更易于 $\texttt{DP}$ 处理的字符串拼接问题。这种**结构转换**的思维方式在解决形式语言相关问题时非常有用，值得深入理解和掌握。
