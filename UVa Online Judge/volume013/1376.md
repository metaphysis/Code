[UVa 1376 Animal Run](https://blog.csdn.net/metaphysis/article/details/155137573)

## 题目描述

动物园中的动物们决定在夜晚逃离。动物园的路径可以被表示为一个 $n \times m$ 的网格图，所有路径都是双向的，可以是**水平**、**垂直**或**对角线**方向。动物从**左上角**出发，如果它们能通过路径到达**右下角**，则获得自由。

为了阻止动物逃跑，警方需要封锁一些路径。每条路径都有一个对应的**权重**，表示封锁该路径所需的警力数量。你的任务是计算**至少需要多少警力**，才能确保动物无法从起点到达终点。

**输入格式**：
- 多组测试数据，每组数据以两个整数 $n$ 和 $m$ 开始（$3 \leq n, m \leq 1000$）。
- 接下来 $n$ 行，每行 $m-1$ 个整数，表示封锁**水平**路径所需的警力。
- 接下来 $n-1$ 行，每行 $m$ 个整数，表示封锁**垂直**路径所需的警力。
- 接下来 $n-1$ 行，每行 $m-1$ 个整数，表示封锁**对角线**路径所需的警力。
- 输入以 `0 0` 结束。

**输出格式**：
对于每组数据，输出：
```
Case 1: Minimum = 14
```

## 题目分析

这是一个典型的**网络流最小割**问题，等价于**最大流**问题。但由于图是**平面图**，我们可以利用其特殊性质，将最小割问题转化为**对偶图的最短路**问题。

### 核心思路

1. **最小割**：在原图中，我们希望选择一些边进行切断（封锁），使得起点和终点不连通，且这些边的权重之和最小。
2. **平面图对偶**：在平面图中，每个**面**（包括外部无限面）可以转化为对偶图中的一个**节点**。原图中的每条边在对偶图中连接两个相邻的面。
3. **关键结论**：在平面图中，从起点到终点的**最小割**，等价于在对偶图中从**起点所在的外部面**到**终点所在的外部面**的**最短路径**。

### 对偶图构建方法

我们将每个小方格（$n-1$ 行 $m-1$ 列）视为一个**面**。为了更精细地表示路径方向，我们将每个小方格进一步划分为**两个三角形区域**（用 `half = 0` 和 `half = 1` 表示）。

- **起点 $s$**：表示左上角的外部区域。
- **终点 $t$**：表示右下角的外部区域。
- **内部节点**：使用函数 `id(i, j, half)` 表示第 $i$ 行第 $j$ 列小方格的某个三角形区域。

#### 边的转换规则

1. **水平边**（位于第 $i$ 行，连接第 $j$ 和 $j+1$ 列）：
   - 在对偶图中连接 `(i, j, 1)` 和 `(i - 1, j, 0)`。
   - 如果 $i-1 < 0$ 或 $j \geq m-1$，则连接到起点 $s$ 或终点 $t$。

2. **垂直边**（位于第 $j$ 列，连接第 $i$ 和 $i+1$ 行）：
   - 在对偶图中连接 `(i, j - 1, 1)` 和 `(i, j, 0)`。
   - 如果 $j-1 < 0$ 或 $i \geq n-1$，则连接到起点 $s$ 或终点 $t$。

3. **对角边**（位于小方格 $(i, j)$ 内）：
   - 在对偶图中连接同一个方格的 `(i, j, 0)` 和 `(i, j, 1)`。

### 算法步骤

1. 读入 $n$ 和 $m$。
2. 读入水平、垂直、对角边的权重。
3. 构建对偶图：
   - 为每个小方格的两个三角形区域创建节点。
   - 根据上述规则添加边。
4. 使用 $\texttt{Dijkstra}$ 算法计算从起点 $s$ 到终点 $t$ 的最短路径。
5. 输出最短路径长度，即为所需的最小警力。

---

## 复杂度分析

- **节点数**：最多约为 $2 \times n \times m + 2$。
- **边数**：每个小方格最多有 $6$ 条边（两个三角形各连 $3$ 条），总边数约为 $O(n \times m)$。
- **时间复杂度**：使用优先队列的 $\texttt{Dijkstra}$ 算法为 $O(E \log V) = O(nm \log(nm))$，在 $n, m \leq 1000$ 时可行。

```cpp
// Animal Run

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int N = 3e6 + 9;
const ll INF = 1e18;

vector<pair<int, ll>> graph[N];

ll dijkstra(int s, int t) {
    vector<ll> dist(t + 1, INF);
    vector<bool> vis(t + 1, false);
    dist[s] = 0;
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
    pq.push({0, s});
    
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (vis[u]) continue;
        vis[u] = true;
        if (u == t) break;
        
        for (auto [v, w] : graph[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist[t];
}

int n, m, s, t;

int getId(int i, int j, int half) {
    if (j < 0 || i >= n - 1) return s;
    if (i < 0 || j >= m - 1) return t;
    return i * m + j + n * m * half;
}

void addEdge(int u, int v, int w) {
    graph[u].push_back({v, w});
    graph[v].push_back({u, w});
}

void solve(int caseNum) {
    s = 2 * n * m + 1;
    t = s + 1;
    
    // 读入水平边
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m - 1; j++) {
            int w; cin >> w;
            addEdge(getId(i, j, 1), getId(i - 1, j, 0), w);
        }
    }
    
    // 读入垂直边
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < m; j++) {
            int w; cin >> w;
            addEdge(getId(i, j - 1, 1), getId(i, j, 0), w);
        }
    }
    
    // 读入对角边
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < m - 1; j++) {
            int w; cin >> w;
            addEdge(getId(i, j, 0), getId(i, j, 1), w);
        }
    }
    
    ll result = dijkstra(s, t);
    cout << "Case " << caseNum << ": Minimum = " << result << endl;
    
    // 清理图
    for (int i = 0; i <= t; i++) graph[i].clear();
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);
    int caseNum = 1;
    while (cin >> n >> m && (n || m)) {
        solve(caseNum);
        caseNum++;
    }
    return 0;
}
```

## 总结

本题的关键在于理解**平面图最小割与对偶图最短路的等价关系**，并正确构建对偶图。通过将每个小方格划分为两个三角形区域，可以更自然地表示水平、垂直和对角边的连接关系。最终使用 $\texttt{Dijkstra}$ 算法求解最短路，即可得到原问题的最小割。
