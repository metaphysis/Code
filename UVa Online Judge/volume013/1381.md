[UVa 1381 Balancing the Scale](https://blog.csdn.net/metaphysis/article/details/161727259)

## 题目描述

你有一个奇怪的天平（如题目原图所示），需要在不同的方格上放置不同的数字，使得天平平衡。平衡条件由以下两个方程给出：

$$
x_{1} \times 4 + x_{2} \times 3 + x_{3} \times 2 + x_{4} = x_{5} + x_{6} \times 2 + x_{7} \times 3 + x_{8} \times 4
$$

$$
y_{1} \times 4 + y_{2} \times 3 + y_{3} \times 2 + y_{4} = y_{5} + y_{6} \times 2 + y_{7} \times 3 + y_{8} \times 4
$$

其中 $x_{1}$ 到 $x_{8}$ 和 $y_{1}$ 到 $y_{8}$ 是天平上的 $16$ 个方格，每个方格放置一个数字。要求所有数字互不相同，且每个数字恰好使用一次。

旋转和反转视为同一种排列，只计算一次。

## 输入格式

输入包含多个测试用例。每个测试用例由一行 $16$ 个不同的整数组成，整数范围在 $[1, 1024]$ 之间。  
一行包含一个整数 $0$ 表示输入结束，该行不应被处理。

## 输出格式

对于每个测试用例，如果存在平衡方案，输出一行，格式为 `Case i: ans`，其中 $i$ 是测试用例编号（从 $1$ 开始），$ans$ 是不同平衡方式的数量。若不存在，输出 $0$。

## 样例

输入

```cpp
87 33 98 83 67 97 44 72 91 78 46 49 64 59 85 88
0
```

输出

```cpp
Case 1: 15227223
```

## 题目分析

本题要求将 $16$ 个互不相同的数字分配到 $16$ 个固定位置（$x_{1} \dots x_{8}$ 和 $y_{1} \dots y_{8}$），使得两个独立的一次方程同时成立。每个位置具有固定的权重系数。

第一个方程涉及 $x$ 系列的 $8$ 个数字，第二个方程涉及 $y$ 系列的 $8$ 个数字。两个方程形式完全相同，且共享数字集合（即 $x$ 和 $y$ 共同使用所有 $16$ 个数字，没有重叠）。

直接枚举 $16!$ 种排列显然不可行。观察方程结构可以发现，每个方程左右两侧各 $4$ 个位置，权重分别为 $4,3,2,1$ 和 $1,2,3,4$，具有对称性。

因此，对于 $8$ 个数字，我们可以采用 **$\texttt{Meet-in-the-Middle}$（折半搜索）** 技术：先枚举左侧 $4$ 个数字的所有组合和排列，计算加权和，再枚举右侧 $4$ 个数字的组合和排列，寻找和相等的配对。

这样，单个 $8$ 元集合的计数复杂度从 $O(8!)$ 降低到 $O(\binom{8}{4} \times 4!)$，即约 $1680$ 次操作。

## 解题思路

### 整体框架

对于给定的 $16$ 个数字，我们需要：
1. 将所有 $16$ 个数字分配到两个 $8$ 元集合 $X$ 和 $Y$（$X \cup Y = \text{全集}$，$X \cap Y = \varnothing$）。
2. 对每个 $8$ 元集合，计算其内部所有满足方程的排列方式数。
3. 将 $X$ 和 $Y$ 的方式数相乘，累加到答案中。
4. 最后除以对称群大小去重。

### 关键优化：$\texttt{Meet-in-the-Middle}$ 计数

对于给定 $8$ 个数字，如何计算所有满足方程的排列数？

方程：
$$
4a + 3b + 2c + d = e + 2f + 3g + 4h
$$

其中 $\{a,b,c,d,e,f,g,h\}$ 是这 $8$ 个数字的一个排列。

我们可以：
- 枚举所有从 $8$ 个数字中选 $4$ 个作为左半部分 $\{a,b,c,d\}$ 的组合（$\binom{8}{4} = 70$ 种）。
- 对每个组合，枚举 $4! = 24$ 种排列，计算左半加权和 $S_L = 4a + 3b + 2c + d$。
- 用哈希表 `leftMap[sum][mask]` 记录：左半加权和为 $sum$、且所用数字集合的位掩码为 $mask$ 的排列个数。
- 类似地，枚举右半部分 $\{e,f,g,h\}$ 的所有组合和排列，计算右半加权和 $S_R = e + 2f + 3g + 4h$。
- 对于每个右半排列，在 `leftMap[S_R]` 中查找所有与当前右半位掩码**无交集**的左半掩码，合并得到完整的 $8$ 元集合掩码，累加计数。

最终得到 `fullMask -> 排列数` 的映射 `xWays`。

### 配对 $X$ 和 $Y$

得到 `xWays` 后，对于每个 $X$ 的掩码 $\textit{maskX}$，其补集就是 $Y$ 的数字集合。如果 `xWays` 中也存在 $\textit{maskY}$，则将两者对应的排列数相乘并累加。

### 去重处理

题目要求旋转和反转视为同一种排列。这里的对称性包括：
- 上下交换（$x$ 和 $y$ 整体互换）：每个配置会被计算两次（一次作为 $X$，一次作为 $Y$），需除以 $2$。
- $x$ 系列左右镜像：每个 $x$ 排列对应一个镜像排列（交换左边和右边，同时调整权重），两者都会被枚举到，需再除以 $2$。
- $y$ 系列左右镜像：同理，再除以 $2$。

总对称群大小为 $2 \times 2 \times 2 = 8$，因此最终答案需要除以 $8$。

### 复杂度分析

- 预处理单个 $8$ 元集合：左半枚举 $\binom{8}{4} \times 4! \approx 1680$ 种，右半同理，每步哈希表查找 $O(1)$ 均摊，总计约 $3360$ 次操作。
- 枚举所有 $X$ 的 $8$ 元集合：即枚举 $16$ 选 $8$，共 $\binom{16}{8} = 12870$ 种。每个 $8$ 元集合需要调用上述预处理，总操作约 $12870 \times 3360 \approx 4.3 \times 10^7$，在 $1$ 秒内可完成。
- 哈希表操作和位运算均为常数时间，空间复杂度 $O(\binom{16}{8} \cdot \text{平均映射数})$，可接受。

## 代码实现

```cpp
// Balancing the Scale
// UVa ID: 1381
// Verdict: Accepted
// Submission Date: 2026-06-05
// UVa Run Time: 1.960s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

map<int, long long> countAll8Tuples(const vector<int>& nums) {
    map<int, long long> result;
    int n = nums.size();
    
    // leftMap[sum][mask] = count
    map<int, map<int, int>> leftMap;
    
    // 枚举左边 4 个数（权重 4,3,2,1）
    for (int leftMask = 0; leftMask < (1 << n); ++leftMask) {
        if (__builtin_popcount(leftMask) != 4) continue;
        vector<int> leftNums;
        for (int i = 0; i < n; ++i) if (leftMask >> i & 1) leftNums.push_back(nums[i]);
        do {
            int sum = leftNums[0]*4 + leftNums[1]*3 + leftNums[2]*2 + leftNums[3];
            leftMap[sum][leftMask]++;
        } while (next_permutation(leftNums.begin(), leftNums.end()));
    }
    
    // 枚举右边 4 个数（权重 1,2,3,4），与左边配对
    for (int rightMask = 0; rightMask < (1 << n); ++rightMask) {
        if (__builtin_popcount(rightMask) != 4) continue;
        vector<int> rightNums;
        for (int i = 0; i < n; ++i) if (rightMask >> i & 1) rightNums.push_back(nums[i]);
        do {
            int sum = rightNums[0] + rightNums[1]*2 + rightNums[2]*3 + rightNums[3]*4;
            if (leftMap.find(sum) == leftMap.end()) continue;
            for (auto& [leftMask, cnt] : leftMap[sum]) {
                if (leftMask & rightMask) continue;
                int fullMask = leftMask | rightMask;
                result[fullMask] += cnt;
            }
        } while (next_permutation(rightNums.begin(), rightNums.end()));
    }
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    vector<int> nums(16);
    int caseNum = 1;
    
    while (cin >> nums[0], nums[0]) {
        for (int i = 1; i < 16; ++i) cin >> nums[i];
        sort(nums.begin(), nums.end());
        
        auto xWays = countAll8Tuples(nums);
        
        long long ans = 0;
        for (auto& [maskX, cntX] : xWays) {
            int maskY = ((1 << 16) - 1) ^ maskX;
            if (xWays.find(maskY) != xWays.end()) {
                ans += cntX * xWays[maskY];
            }
        }
        
        // 除以 8 去重（上下对称 2 × x左右镜像 2 × y左右镜像 2）
        ans /= 8;
        
        cout << "Case " << caseNum++ << ": " << ans << "\n";
    }
    return 0;
}
```

## 总结

本题的核心技巧是 **$\texttt{Meet-in-the-Middle}$** 与 **状态压缩** 的结合：

1. 将 $16$ 个数字的分配问题分解为两个独立的 $8$ 元子问题，利用 $\binom{16}{8}$ 枚举所有分配。
2. 对每个 $8$ 元集合，利用折半搜索将排列枚举从 $8!$ 降低到 $\binom{8}{4} \times 4!$，大幅提升效率。
3. 使用位掩码表示数字集合，方便快速判断交集和补集。
4. 最后利用对称性分析，除以 $8$ 消除旋转和反转带来的重复计数。

这类问题的通用解法是：当方程具有**可分割性**（左右独立且权重对称）时，折半搜索是最优选择。同时，对称性处理是计数类问题中不可忽视的细节。
