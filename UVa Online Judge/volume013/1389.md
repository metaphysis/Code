## 题目分析

### 问题描述

约翰是一家私营中型公司的首席执行官。公司老板决定让自己的儿子斯科特担任公司经理。约翰担心如果斯科特在新经理职位上表现出色，老板最终会将 $\texttt{CEO}$ 职位交给斯科特，因此他决定通过精心选择斯科特将要管理的团队来让斯科特的生活尽可能艰难。

约翰知道哪些员工组合在同一个团队中合作不佳。他定义了一个团队的**硬度因子**：团队中合作不佳的员工对数除以团队总人数。硬度因子越大，团队越难管理。约翰的任务是找到公司中最难管理的员工群体，并将其作为斯科特的团队。

### 输入输出格式

**输入**：
- 第一行包含两个整数 $n$ 和 $m$ ($1 \leq n \leq 100$, $0 \leq m \leq 1000$)
- $n$ 表示公司总人数（人员编号从 $1$ 到 $n$）
- $m$ 表示合作不佳的员工对数
- 接下来 $m$ 行，每行包含两个整数 $a_i$ 和 $b_i$，表示一对合作不佳的员工

**输出**：
- 对于每个测试用例，输出一个整数 $k$ 表示最难管理团队的人数
- 随后 $k$ 行按升序列出该团队的成员
- 如果存在多个团队具有相同的硬度因子，输出任意一个即可

### 问题本质

这是一个**最大密度子图**问题：
- 将员工视为图中的顶点
- 将合作不佳的关系视为图中的边
- 目标是找到一个顶点子集 $S$，使得子图的边数 $|E(S)|$ 与顶点数 $|S|$ 的比值 $\frac{|E(S)|}{|S|}$ 最大化

### 样例分析

对于样例输入：
```
5 6
1 5
5 4
4 2
2 5
1 2
3 1
4 0
```

对应的图结构为：
- 顶点：$1,2,3,4,5$
- 边：$(1,5), (5,4), (4,2), (2,5), (1,2), (3,1)$

最优解为团队 $\{1,2,4,5\}$：
- 团队人数：$4$
- 内部冲突边数：$5$（所有边除了 $(3,1)$）
- 硬度因子：$\frac{5}{4} = 1.25$

## 算法思路

### 分数规划方法

我们要求最大化：
$$\max_{S \neq \emptyset} \frac{|E(S)|}{|S|}$$

设最大值为 $g$，则对于最优解有：
$$|E(S)| - g \cdot |S| = 0$$

对于给定的 $g$，我们检查是否存在 $S$ 使得：
$$|E(S)| - g \cdot |S| > 0$$

### 网络流建模

通过以下步骤将问题转化为最小割问题：

1. **建图**：
   - 创建源点 $s$ 和汇点 $t$
   - 源点 $s$ 向每个员工顶点连接容量为 $m$ 的边
   - 每个员工顶点向汇点 $t$ 连接容量为 $m + 2g - \texttt{degree}(u)$ 的边
   - 对于每条冲突边 $(u,v)$，在 $u$ 和 $v$ 之间添加双向容量为 $1$ 的边

2. **最小割与密度关系**：
   - 计算最小割值 $\texttt{mincut}$
   - 密度判断值：$\texttt{value} = \frac{m \cdot n - \texttt{mincut}}{2}$
   - 如果 $\texttt{value} > 0$，说明存在密度大于 $g$ 的子图

### 二分查找

使用二分法寻找最优密度 $g$：
- 初始范围：$[0, m]$（最大可能密度不超过 $m$）
- 精度要求：$10^{-7}$
- 对于每个中间值 $mid$，构建流网络并计算最小割
- 根据结果调整搜索范围

### 方案提取

找到最优 $g$ 后：
- 在残量网络中进行 $\texttt{BFS}$，从源点 $s$ 可达的顶点即为最大密度子图的成员
- 对这些顶点排序并输出

## 复杂度分析

- **时间复杂度**：$O(\log m \cdot \text{MaxFlow}(n, m))$
  - 二分查找：$O(\log m)$
  - $\texttt{Dinic}$ 算法：$O(n^2m)$
  - 总体：$O(n^2m \log m)$，在 $n \leq 100$ 时可接受
- **空间复杂度**：$O(n + m)$

```cpp
// Hard Life

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <cmath>
#include <cstring>
using namespace std;

const int MAXN = 105;
const int MAXM = 1005;
const int MAXV = MAXN + 2;
const double INF = 1e9;
const double EPS = 1e-7;

// 网络流边结构
struct Edge {
    int to, rev;      // 目标顶点，反向边索引
    double cap;       // 容量
};

vector<Edge> g[MAXV]; // 流网络邻接表
int level[MAXV], iter[MAXV]; // Dinic算法层级图和当前弧
int n, m;             // 顶点数，边数
int edges[MAXM][2];   // 存储输入的边
int degree[MAXN];     // 每个顶点的度数

// 添加流网络边
void add_edge(int from, int to, double cap) {
    g[from].push_back({to, (int)g[to].size(), cap});
    g[to].push_back({from, (int)g[from].size() - 1, 0.0});
}

// BFS构建层级图
void bfs(int s) {
    memset(level, -1, sizeof(level));
    queue<int> q;
    level[s] = 0;
    q.push(s);
    while (!q.empty()) {
        int v = q.front(); q.pop();
        for (auto &e : g[v]) {
            if (e.cap > EPS && level[e.to] < 0) {
                level[e.to] = level[v] + 1;
                q.push(e.to);
            }
        }
    }
}

// DFS寻找增广路
double dfs(int v, int t, double f) {
    if (v == t) return f;
    for (int &i = iter[v]; i < (int)g[v].size(); i++) {
        Edge &e = g[v][i];
        if (e.cap > EPS && level[v] < level[e.to]) {
            double d = dfs(e.to, t, min(f, e.cap));
            if (d > EPS) {
                e.cap -= d;
                g[e.to][e.rev].cap += d;
                return d;
            }
        }
    }
    return 0;
}

// Dinic算法计算最大流
double max_flow(int s, int t) {
    double flow = 0;
    while (true) {
        bfs(s);
        if (level[t] < 0) return flow;
        memset(iter, 0, sizeof(iter));
        double f;
        while ((f = dfs(s, t, INF)) > EPS) {
            flow += f;
        }
    }
}

bool vis[MAXV];
// 从源点DFS寻找最小割S集合（最大密度子图）
void find_vertices(int v, vector<int> &res) {
    if (v < n) res.push_back(v + 1); // 转换回1-based编号
    vis[v] = true;
    for (auto &e : g[v]) {
        if (e.cap > EPS && !vis[e.to]) {
            find_vertices(e.to, res);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    bool first_case = true;
    while (cin >> n >> m) {
        if (!first_case) cout << "\n";
        first_case = false;

        // 处理无边特殊情况
        if (m == 0) {
            cout << "1\n1\n";
            continue;
        }

        memset(degree, 0, sizeof(degree));
        // 读入边并计算度数
        for (int i = 0; i < m; i++) {
            int a, b;
            cin >> a >> b;
            a--; b--;
            edges[i][0] = a;
            edges[i][1] = b;
            degree[a]++;
            degree[b]++;
        }

        double low = 0.0, high = m;
        vector<int> best_team;
        
        // 二分查找最优密度g
        while (high - low > 1e-7) {
            double mid = (low + high) / 2;
            // 构建流网络
            int s = n, t = n + 1;
            for (int i = 0; i < n + 2; i++) g[i].clear();
            // s到每个顶点容量m
            for (int i = 0; i < n; i++) {
                add_edge(s, i, m);
                add_edge(i, t, m + 2 * mid - degree[i]);
            }
            // 顶点间双向边容量1
            for (int i = 0; i < m; i++) {
                int a = edges[i][0], b = edges[i][1];
                add_edge(a, b, 1.0);
                add_edge(b, a, 1.0);
            }
            double mincut = max_flow(s, t);
            double value = (m * n - mincut) / 2.0;
            
            if (value > EPS) {
                low = mid;
                // 记录当前最优团队
                memset(vis, 0, sizeof(vis));
                vector<int> team;
                find_vertices(s, team);
                if (!team.empty()) best_team = team;
            } else {
                high = mid;
            }
        }

        // 确保至少有一个顶点
        if (best_team.empty()) best_team.push_back(1);
        sort(best_team.begin(), best_team.end());
        cout << best_team.size() << "\n";
        for (int v : best_team) {
            cout << v << "\n";
        }
    }

    return 0;
}
```

## 总结

本题通过将最大密度子图问题转化为网络流最小割问题，利用分数规划和二分查找高效求解。算法在合理的时间复杂度内解决了问题，适用于给定的数据范围。关键点在于理解密度最大化与最小割之间的数学关系，以及如何通过流网络建模来找到最优解。
