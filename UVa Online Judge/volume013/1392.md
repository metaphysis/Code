[UVa 1392 DNA Regions](https://blog.csdn.net/metaphysis/article/details/157552008)

## 题目描述

给定两个长度均为 $n$ 的 $\texttt{DNA}$ 序列，每个序列仅包含字符 $\texttt{A}$、$\texttt{C}$、$\texttt{G}$、$\texttt{T}$ 。我们需要找到最长的“保守区域”。保守区域定义为：一个连续的子区间，在该区间内，两个序列对应位置字符不同的数量不超过区间长度的 $p\%$ 。换句话说，对于区间 $[l, r]$ （从 $0$ 索引），设 $diff(l, r)$ 表示该区间内两个序列字符不同的位置数，则要求：

$$
\frac{diff(l, r)}{r - l + 1} \times 100 \le p
$$

其中 $p$ 是一个介于 $1$ 到 $99$ 之间的整数。我们的目标是找到满足该条件的最长区间的长度。如果不存在任何满足条件的区间，则输出 `No solution.` 。

## 输入格式

输入包含多个测试用例。每个测试用例的第一行包含两个整数 $n$ 和 $p$ （ $1 \le n \le 150000$ ， $1 \le p \le 99$ ）。接下来两行分别给出两个长度为 $n$ 的 $\texttt{DNA}$ 序列。输入以 $n = 0$ 结束。

## 输出格式

对于每个测试用例，输出一行，包含一个整数，表示最长保守区域的长度。如果没有满足条件的区域，则输出 `No solution.` 。

## 题目分析

### 问题转化

设 $d[i] = 1$ 如果两个序列在第 $i$ 个位置（ $0$ 开始计数）的字符不同，否则 $d[i] = 0$ 。定义前缀和数组 $pre$ ，其中 $pre[i]$ 表示前 $i$ 个位置中 $d$ 值的和，即：

$$
pre[i] = \sum_{k=0}^{i-1} d[k], \quad pre[0] = 0
$$

对于任意区间 $[l, r]$ ，其差异数 $diff(l, r)$ 可表示为：

$$
diff(l, r) = pre[r+1] - pre[l]
$$

那么原条件可写为：

$$
100 \times (pre[r+1] - pre[l]) \le p \times (r - l + 1)
$$

整理这个不等式：

$$
100 \times pre[r+1] - 100 \times pre[l] \le p \times (r+1) - p \times l
$$

移项得：

$$
100 \times pre[r+1] - p \times (r+1) \le 100 \times pre[l] - p \times l
$$

令：

$$
f(i) = 100 \times pre[i] - p \times i
$$

则条件简化为：

$$
f(r+1) \le f(l)
$$

### 问题重述

现在问题转化为：寻找最大的 $len = (r+1) - l$ ，使得存在 $l$ 和 $r$ （ $l \le r$ ）满足 $f(r+1) \le f(l)$ 。换句话说，对于每个可能的右端点 $i = r+1$ ，我们需要找到最小的左端点 $j = l$ （ $j < i$ ）使得 $f(j) \ge f(i)$ 。那么以 $i$ 为右端点的最长保守区域长度就是 $i - j$ 。我们的目标就是最大化这个长度。

### 算法设计

直接枚举所有 $i$ 和 $j$ 是 $O(n^2)$ 的，对于 $n$ 最大为 $150000$ 不可行。因此需要更高效的方法。

**核心观察** ：我们需要对每个 $i$ 快速找到最小的 $j < i$ 且 $f(j) \ge f(i)$ 。这可以通过排序和扫描来解决。

具体步骤：

1.  计算数组 $f[0..n]$ ，其中 $f[i] = 100 \times pre[i] - p \times i$ 。
2.  将 $n+1$ 个二元组 $(f[i], i)$ 按照 $f$ 值降序排序（实际实现时，我们存储 $(-f[i], i)$ 并按 $-f[i]$ 升序排序，等价于按 $f[i]$ 降序）。
3.  按排序后的顺序遍历这些二元组。维护一个变量 $minIdx$ ，表示到目前为止遇到的最小索引（即 $i$ 的值）。
4.  对于当前二元组 $(-f[i], i)$ ：
    *   如果 $minIdx < i$ ，则区间 $[minIdx, i-1]$ 满足 $f(i) \le f(minIdx)$ （因为当前元素在排序数组中位于 $minIdx$ 对应的元素之后，意味着 $f(i) \le f(minIdx)$ ），且长度为 $i - minIdx$ 。用该长度更新答案。
    *   用 $i$ 更新 $minIdx$ ： $minIdx = \min(minIdx, i)$ 。

**正确性证明** ：排序后，对于任意 $i$ ，所有排在它前面的元素 $j$ 都满足 $f(j) \ge f(i)$ 。我们维护的 $minIdx$ 是这些 $j$ 中的最小索引。因此， $minIdx$ 就是对于当前 $i$ 的最优左端点（最小的 $j$ 满足 $f(j) \ge f(i)$ ）。遍历所有 $i$ 即可找到全局最优解。

**特殊情况** ：当 $p = 100$ 时，任何区间都满足条件（因为差异数最多为区间长度， $100\%$ 的差异也是允许的），所以最长保守区域长度就是 $n$ 。可以单独处理此情况以避免后续计算。

**时间复杂度** ：
*   计算前缀和 $pre$ 和 $f$ 数组： $O(n)$ 。
*   排序： $O(n \log n)$ 。
*   扫描： $O(n)$ 。
*   总复杂度 $O(n \log n)$ ，对于 $n \le 150000$ 是可行的。

**空间复杂度** ： $O(n)$ ，用于存储前缀和、 $f$ 数组以及排序所需的二元组。

## 解题思路总结

1.  **数学建模** ：将原百分比条件转化为关于前缀和的不等式，并引入辅助函数 $f(i)$ ，使问题简化为寻找满足 $f(r+1) \le f(l)$ 的最大区间长度。
2.  **问题转化** ：进一步转化为对每个右端点 $i$ ，寻找最小的左端点 $j$ 使得 $f(j) \ge f(i)$ 。
3.  **排序扫描** ：通过按 $f$ 值降序排序所有位置，并在扫描过程中维护已遇到的最小索引，可以在 $O(n \log n)$ 时间内求解。
4.  **特殊处理** ： $p = 100$ 时直接输出 $n$ 。
5.  **边界情况** ：如果没有找到任何满足条件的区间（答案保持为 $0$ ），则输出 `No solution.` 。

## 代码实现

```cpp
// DNA Regions
// UVa ID: 1392
// Verdict: Accepted
// Submission Date: 2026-01-30
// UVa Run Time: 0.030s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, p;
    while (cin >> n >> p) {
        if (n == 0) break;
        string s1, s2;
        cin >> s1 >> s2;
        // 特殊情况：如果 p = 100，整个序列都是保守区域
        if (p == 100) {
            cout << n << "\n";
            continue;
        }
        // 计算前缀和：pre[i] 表示前 i 个位置的不同字符数
        vector<int> pre(n + 1, 0);
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + (s1[i] != s2[i]);
        // 计算 f[i] = 100 * pre[i] - p * i
        vector<long long> f(n + 1, 0);
        for (int i = 0; i <= n; ++i) f[i] = 100LL * pre[i] - 1LL * p * i;
        // 存储 (-f[i], i) 对，并按 -f[i] 排序（即按 f[i] 降序）
        vector<pair<long long, int>> pairs;
        for (int i = 0; i <= n; ++i) pairs.emplace_back(-f[i], i);
        sort(pairs.begin(), pairs.end());
        int r = 0;
        int minIndex = n + 1;  // 维护到当前位置为止的最小索引
        // 遍历排序后的数组
        for (int idx = 0; idx <= n; ++idx) {
            int currentIndex = pairs[idx].second;
            // 如果之前有更小的索引，可以形成区间
            if (minIndex < currentIndex) {
                int length = currentIndex - minIndex;
                if (length > r) r = length;
            }
            // 更新最小索引
            if (currentIndex < minIndex) minIndex = currentIndex;
        }
        // 输出结果
        if (r == 0) cout << "No solution.\n";
        else cout << r << "\n";
    }
    return 0;
}
```

## 代码说明

1.  **输入输出优化** ：使用 `ios::sync_with_stdio(false)` 和 `cin.tie(nullptr)` 加速输入输出。
2.  **前缀和计算** ： `pre[i+1]` 存储前 $i$ 个位置（索引 $0$ 到 $i$ ）的差异数。注意 `pre[0] = 0` 。
3.  **$f$ 数组计算** ：使用 `long long` 防止乘法溢出。 $f[i] = 100 \times pre[i] - p \times i$ 。
4.  **排序技巧** ：存储 $(-f[i], i)$ 并按默认升序排序，等价于按 $f[i]$ 降序排序。
5.  **扫描过程** ：维护 `minIndex` 记录已遍历元素中的最小原始索引。当遇到一个更大的索引时，其与 `minIndex` 形成的区间就是当前右端点的候选最长区间。
6.  **结果输出** ：如果最终 `r` 为 $0$ ，输出 `No solution.` ，否则输出 `r` 。

## 复杂度分析

*   **时间复杂度** ： $O(n \log n)$ ，主要由排序步骤决定。 $n$ 最大为 $150000$ ，可以接受。
*   **空间复杂度** ： $O(n)$ ，用于存储前缀和数组、 $f$ 数组和排序所需的二元组。

## 总结

本题的关键在于通过数学变换将百分比条件转化为一个关于前缀和函数 $f$ 的不等式，进而将问题转化为一个经典的最长满足条件的区间问题。通过巧妙的排序和扫描方法，我们可以在 $O(n \log n)$ 时间内高效求解。需要注意处理 $p = 100$ 的特殊情况以及使用足够的数据类型防止溢出。
