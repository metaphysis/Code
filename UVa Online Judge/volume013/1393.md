## 题目描述

$\texttt{Hackerland}$ 是一个快乐的民主国家，拥有 $m \times n$ 个城市，这些城市排列成一个 $m$ 行 $n$ 列的矩形网格。城市之间通过现有的道路系统连接：有 $m$ 条东西向的道路（连接每行的所有城市）和 $n$ 条南北向的道路（连接每列的所有城市）。

根据公众需求，需要在现有的正交道路系统基础上补充一个高速公路系统，使得任意两个城市之间都有直接连接。每条高速公路是一条直线，穿过两个或更多城市。如果两个城市位于同一条高速公路上，那么它们就直接连接。

**重要规则**：
- 如果两个城市在同一行或同一列，它们已经通过现有道路系统连接，不需要额外的高速公路
- 一条穿过多个城市的直线只算作一条高速公路

你的任务是计算需要建设的高速公路数量。

## 输入格式
输入包含多个测试用例块。每个测试用例包含一行，有两个整数 $1 \leq n, m \leq 300$，指定城市的数量。输入以 $n = m = 0$ 结束。

## 输出格式
对于每个测试用例，输出一行包含一个整数，表示必须建设的高速公路数量。

## 题目分析

### 问题本质
这个问题可以转化为：在 $m \times n$ 的网格点中，找出所有至少连接两个点的非水平、非垂直的直线数量。

### 关键观察
1. **排除已有连接**：同一行或同一列的城市已经通过原有道路连接，因此我们只关心斜线（斜率不为 $0$ 或无穷大）
2. **直线表示**：每条直线可以用斜率和一个参数（如截距）唯一确定
3. **避免重复计数**：同一条直线可能被多个点对共享，需要避免重复计数

### 数学建模
对于网格点 $(0,0)$ 到 $(i,j)$ 的线段：
- 如果 $\gcd(i,j) = 1$，那么这条线段上除了端点外没有其他网格点
- 如果 $\gcd(i,j) > 1$，那么这条线段上会有其他网格点

这引出了**可见点**的概念：从原点 $(0,0)$ 出发，点 $(i,j)$ 是可见的当且仅当 $\gcd(i,j) = 1$。

## 解题思路

### 动态规划方法
我们使用两个动态规划数组：

#### 1. `visiblePoints[i][j]`
表示在 $i \times j$ 的矩形中，从 $(0,0)$ 出发可见的点的数量（不包括 $(0,0)$ 本身）。

状态转移方程：
$$
\texttt{visiblePoints}[i][j] = \texttt{visiblePoints}[i-1][j] + \texttt{visiblePoints}[i][j-1] - \texttt{visiblePoints}[i-1][j-1] + [\gcd(i,j) = 1]
$$

其中 $[\gcd(i,j) = 1]$ 是指示函数，当 $\gcd(i,j) = 1$ 时为 $1$，否则为 $0$。

#### 2. `highwayCount[i][j]`
表示在 $i \times j$ 的矩形中，所有可能的斜线数量。

状态转移方程：
$$
\texttt{highwayCount}[i][j] = \texttt{highwayCount}[i-1][j] + \texttt{highwayCount}[i][j-1] - \texttt{highwayCount}[i-1][j-1] + \texttt{visiblePoints}[i][j] - \texttt{visiblePoints}[\lfloor i/2 \rfloor][\lfloor j/2 \rfloor]
$$

### 算法步骤
1. **预处理**：计算所有 $1 \leq i,j \leq 300$ 的 `visiblePoints[i][j]` 和 `highwayCount[i][j]`
2. **查询处理**：对于每个测试用例 $(n, m)$，输出 $2 \times \texttt{highwayCount}[n-1][m-1]$
3. **乘以 $2$**：因为每条斜线都有正负两个方向（斜率互为相反数）

### 复杂度分析
- **时间复杂度**：预处理 $O(N^2)$，其中 $N = 300$；每次查询 $O(1)$
- **空间复杂度**：$O(N^2)$

## 参考代码

```cpp
// Highways

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int gridSize = 305;
int visiblePoints[gridSize][gridSize];
int highwayCount[gridSize][gridSize];

void initializeTables() {
    for (int i = 1; i < gridSize; i++)
        for (int j = 1; j < gridSize; j++)
            visiblePoints[i][j] = visiblePoints[i - 1][j] + visiblePoints[i][j - 1] - visiblePoints[i - 1][j - 1] + (__gcd(i, j) == 1);
    for (int i = 1; i < gridSize; i++)
        for (int j = 1; j < gridSize; j++)
            highwayCount[i][j] = highwayCount[i - 1][j] + highwayCount[i][j - 1] - highwayCount[i - 1][j - 1] + visiblePoints[i][j] - visiblePoints[i / 2][j / 2];
}

int main() {
    initializeTables();
    int n, m;
    while (cin >> n >> m and (n != 0 or m != 0))
        cout << 2 * highwayCount[n - 1][m - 1] << endl;
    return 0;
}
```

## 总结

本题的关键在于将几何问题转化为数论问题，利用最大公约数来判断直线的唯一性。通过动态规划预处理所有可能的结果，可以在查询时快速给出答案。这种"预处理+查询"的模式在处理多个测试用例时非常高效。

算法核心思想是利用可见点的概念来避免重复计数，确保每条直线只被计算一次。最终结果乘以 $2$ 是因为我们考虑了斜率的正负两个方向。
