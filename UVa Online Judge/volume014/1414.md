## 题目分析

本题是经典汉诺塔问题的一个变种 。 与标准汉诺塔不同 ， 这里的移动规则由一个固定的策略列表决定 。 策略列表包含所有六种可能的移动 （ $\texttt{AB}$ 、 $\texttt{AC}$ 、 $\texttt{BA}$ 、 $\texttt{BC}$ 、 $\texttt{CA}$ 、 $\texttt{CB}$ ）， 并按照给定的顺序排列 。

算法规则如下 ：

1. 每一步 ， 按照策略列表的顺序 ， 选择**第一个合法**的移动执行
2. **附加约束** ： 不能连续两次移动同一个盘子
3. 目标状态 ： 所有 $n$ 个盘子都在柱子 $\texttt{B}$ 或柱子 $\texttt{C}$ 上

题目要求 ： 对于给定的 $n$ （ $1 \leq n \leq 30$ ） 和策略列表 ， 计算出完成游戏所需的最少移动次数 。 答案不超过 $10^{18}$ 。

## 关键观察

这道题最精妙的地方在于 ： **虽然策略有 $6! = 720$ 种可能 ， 但递推参数只有 $3$ 种组合** 。

为什么 ？ 因为策略列表中**只有每个柱子的第一个合法移动**会影响递归结构 ， 后续移动的顺序对递推公式没有影响 。

### 核心递推关系

对于任何策略 ， 移动 $n$ 个盘子的步数都满足**线性递推** ：

$$dp[n] = dp[n-1] \times x + y$$

其中 ：
- $x$ 是递归因子 （ $2$ 或 $3$ ）
- $y$ 是修正项 （ $0$ 、 $1$ 或 $2$ ）

边界条件 ： $dp[1] = 1$ （ 一个盘子总是需要 $1$ 步 ）。

### 三种情况的具体含义

#### 情况 1 ： $(x, y) = (3, 0)$

**条件** ： 柱子 $\texttt{B}$ 和柱子 $\texttt{C}$ 的**第一个合法移动**都不是 $\texttt{A}$ 。

**含义** ： 无法直接将盘子从 $\texttt{B}$ 或 $\texttt{C}$ 移回 $\texttt{A}$ 。 移动 $n$ 个盘子的过程是 ：

- 将 $n-1$ 个盘子从 $\texttt{A}$ 移到某个柱子 ： $dp[n-1]$ 步
- 将最大盘子移到目标柱 ： 需要 $dp[n-1]$ 步的反复腾挪
- 将 $n-1$ 个盘子移回目标柱 ： $dp[n-1]$ 步

总计 ： $dp[n] = 3 \times dp[n-1] + 0$ 。

#### 情况 2 ： $(x, y) = (3, 2)$

**条件** ： 柱子 $\texttt{A}$ 的**第一个合法移动**是某个柱子 $P$ ， 且 $P$ 的**第一个合法移动**是 $\texttt{A}$ 。 即存在 $\texttt{A} \to P \to \texttt{A}$ 的循环 。

**含义** ： 移动最大盘子前需要额外的 $2$ 步调整 。 递推关系为 ：

$$dp[n] = 3 \times dp[n-1] + 2$$

#### 情况 3 ： $(x, y) = (2, 1)$

**条件** ： 不符合情况 $1$ 和情况 $2$ 的所有其他策略 。

**含义** ： 这就是**经典汉诺塔**的最优策略 ！ 递推关系为 ：

$$dp[n] = 2 \times dp[n-1] + 1$$

这正是我们所熟知的公式 $dp[n] = 2^n - 1$ 。

## 算法设计

### 步骤 $1$ ： 读取策略 ， 提取关键信息

我们并不需要存储全部 $6$ 个移动 ， 只需要记录**每个柱子的第一个合法目标** 。

- 用数组 $\texttt{firstMove}[4]$ 表示 ， 下标 $1,2,3$ 分别对应柱子 $\texttt{A},\texttt{B},\texttt{C}$
- 遍历策略列表 ， 如果某个柱子的 $\texttt{firstMove}$ 尚未设置 ， 就设置为当前移动的目标柱

### 步骤 $2$ ： 根据条件判断属于哪种情况

```cpp
if (firstMove[2] != 1 && firstMove[3] != 1) {
    // 情况1: B和C都不能直接移到A
    x = 3, y = 0;
} else if (firstMove[firstMove[1]] == 1) {
    // 情况2: 存在 A -> ? -> A 的循环
    x = 3, y = 2;
} else {
    // 情况3: 其他所有情况
    x = 2, y = 1;
}
```

### 步骤 $3$ ： 递推计算

$$dp[1] = 1$$
$$dp[i] = dp[i-1] \times x + y, \quad i = 2, 3, \dots, n$$

时间复杂度 $O(n)$ ， 空间复杂度 $O(n)$ ， $n \leq 30$ 时完全足够 。

## 样例验证

### 样例 $1$

```
3
AB BC CA BA CB AC
```

- $\texttt{A}$ 的第一个目标 ： $\texttt{B}$ （ $\texttt{AB}$ ） $\Rightarrow firstMove[1] = 2$
- $\texttt{B}$ 的第一个目标 ： $\texttt{C}$ （ $\texttt{BC}$ ） $\Rightarrow firstMove[2] = 3 \neq 1$
- $\texttt{C}$ 的第一个目标 ： $\texttt{A}$ （ $\texttt{CA}$ ） $\Rightarrow firstMove[3] = 1$

判断 ：
- $\texttt{firstMove[2] != 1 \&\& firstMove[3] != 1}$ ？ 不成立 ， 因为 $\texttt{firstMove[3] = 1}$
- $\texttt{firstMove[firstMove[1]] = firstMove[2] = 3 != 1}$ $\Rightarrow$ **情况 $3$**

计算 ：
$$dp[1] = 1$$
$$dp[2] = 2 \times 1 + 1 = 3$$
$$dp[3] = 2 \times 3 + 1 = 7$$

输出 ： $7$

### 样例 $2$

```
2
AB BA CA BC CB AC
```

- $\texttt{A}$ 的第一个目标 ： $\texttt{B}$ $\Rightarrow firstMove[1] = 2$
- $\texttt{B}$ 的第一个目标 ： $\texttt{A}$ $\Rightarrow firstMove[2] = 1$
- $\texttt{C}$ 的第一个目标 ： $\texttt{A}$ $\Rightarrow firstMove[3] = 1$

判断 ：
- $\texttt{firstMove[2] != 1 \&\& firstMove[3] != 1}$ ？ 不成立
- $\texttt{firstMove[firstMove[1]] = firstMove[2] = 1}$ $\Rightarrow$ **情况 $2$**

计算 ：
$$dp[1] = 1$$
$$dp[2] = 3 \times 1 + 2 = 5$$

输出 ： $5$

## 为什么不需要完整模拟 ？

本题最大的陷阱在于 ： 看似需要模拟整个移动过程 ， 但实际上移动序列的**宏观递归结构**完全由每个柱子的第一个合法移动决定 。

- 后续移动的顺序只会影响**同一层递归内部**的细节 ， 不会改变**递归因子** $x$ 和**修正项** $y$
- 这种性质来源于汉诺塔问题的递归本质 ： 处理 $n$ 个盘子时 ， 总是先将 $n-1$ 个盘子移开 ， 移动最大盘 ， 再将 $n-1$ 个盘子移回
- 策略列表的作用是**延迟**这些步骤 ， 但不会改变基本框架

## 结论

这道题是**数学归纳法**与**递推关系**的经典应用 。 通过深入分析问题的递归结构 ， 我们将看似复杂的策略问题化简为三种简单的线性递推关系 ， 从而在 $O(n)$ 时间内求解 。

本题也提醒我们 ： **不要被问题的表面复杂度迷惑** ， 要善于发现隐藏在复杂规则下的简单数学结构 。

```cpp
// Hanoi Towers

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int N = 50;
int n;
ll x, y, dp[N];

// 根据策略确定递推参数 (x, y)，使得 dp[n] = dp[n-1] * x + y
void initialize() {
    int firstMove[4] = {0};  // firstMove[i] = 从柱子i第一个合法移动的目标柱, 1:A, 2:B, 3:C
    char s[3];
    
    // 读取6个移动，但只记录每个柱子的第一个合法目标
    for (int i = 0; i < 6; i++) {
        scanf("%s", s);
        int src = s[0] - 'A' + 1;
        int dst = s[1] - 'A' + 1;
        
        if (firstMove[src]) continue;  // 已经记录过该柱子的第一个移动
        firstMove[src] = dst;
    }
    
    // 情况1: 柱子B和C都不能直接移动到A
    if (firstMove[2] != 1 && firstMove[3] != 1) {
        x = 3, y = 0;
    }
    // 情况2: 从A移动到的柱子能够立即移回A
    else if (firstMove[firstMove[1]] == 1) {
        x = 3, y = 2;
    }
    // 情况3: 其他所有情况（包括经典汉诺塔策略）
    else {
        x = 2, y = 1;
    }
}

int main() {
    while (scanf("%d", &n) == 1) {
        initialize();
        dp[1] = 1;  // 1个盘子总是需要1步
        for (int i = 2; i <= n; i++)
            dp[i] = dp[i - 1] * x + y;
        printf("%lld\n", dp[n]);
    }
    return 0;
}
```
