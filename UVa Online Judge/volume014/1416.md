## 题目描述

联合国军队对恐怖分子发动了新一波空袭。任务目标是降低敌军的后勤机动性。每次空袭会摧毁一条路径，从而增加两个敌军地点之间的最短路径运输成本。我们总是希望造成最大程度的破坏。

假设有 $n$ 个敌军地点，通过 $m$ 条双向路径连接，每条路径有特定的运输成本。敌军的**总运输成本**定义为：

$$
c = \sum_{i=1}^{n} \sum_{j=1}^{n} path(i,j)
$$

其中 $path(i,j)$ 是地点 $i$ 和 $j$ 之间的最短路径长度。如果 $i$ 和 $j$ 不连通，则 $path(i,j) = L$。每次空袭只能摧毁一条路径。空袭后的总运输成本记为 $c'$。为了最大化对敌军的破坏，联合国空军需要找到最大的 $c' - c$。

### 输入格式

每个测试用例的第一行包含三个整数：$n$, $m$, $L$。其中 $1 < n \leq 100$, $1 \leq m \leq 1000$, $1 \leq L \leq 10^8$。

接下来的 $m$ 行，每行包含三个整数：$a$, $b$, $s$，表示 $a$ 和 $b$ 之间的路径长度为 $s$。

### 输出格式

对于每个测试用例，输出空袭前的总运输成本和空袭后的最大总运输成本，用空格分隔。

### 样例输入
```
4 6 1000
1 3 2
1 4 4
2 1 3
2 3 3
3 4 1
4 2 2
```

### 样例输出
```
28 38
```

## 题目分析

### 问题理解

本题需要解决两个核心问题：

1. **计算原始总运输成本**：在空袭前，计算所有点对之间的最短路径之和
2. **寻找最大破坏效果**：通过删除一条边，使得空袭后的总运输成本最大化

### 关键观察

- **图规模**：$n \leq 100$，可以使用 $O(n^3)$ 的 $\texttt{Floyd-Warshall}$ 算法
- **边数量**：$m \leq 1000$，可以枚举每条边进行删除测试
- **不连通情况**：当两点不连通时，使用 $L$ 作为距离值
- **多重边处理**：两个顶点之间可能存在多条边，需要正确处理

### 算法选择

由于 $n$ 的规模较小，我们选择 **$\texttt{Floyd-Warshall}$ 算法** 来计算所有点对最短路径。该算法的时间复杂度为 $O(n^3)$，在给定的约束条件下是可接受的。

### 解题思路

1. **构建原始图**：
   - 初始化邻接矩阵，对角线元素为 $0$，其他为无穷大
   - 对于每条边，如果存在多重边，只保留权重最小的边

2. **计算原始成本**：
   - 使用 $\texttt{Floyd-Warshall}$ 算法计算所有点对最短路径
   - 遍历所有点对，累加最短路径值（不连通时使用 $L$）

3. **寻找最大破坏**：
   - 枚举每条边进行删除测试
   - 对于每条被删除的边，重新构建图并计算最短路径
   - 记录所有可能情况中的最大总运输成本

4. **输出结果**：
   - 输出原始总成本和最大破坏后的总成本

### 复杂度分析

- **时间复杂度**：$O(m \times n^3)$
  - 原始 $\texttt{Floyd-Warshall}$：$O(n^3)$
  - 对于 $m$ 条边，每次删除后重新计算：$O(m \times n^3)$
- **空间复杂度**：$O(n^2)$，用于存储邻接矩阵

### 边界情况处理

- **单一边情况**：当图中只有一条边时，删除该边会导致所有点对不连通
- **多重边情况**：正确处理同一顶点对之间的多条边
- **不连通图**：使用 $L$ 作为不连通点对的距离

## 代码实现

```cpp
// Warfare And Logistics

// Verdict: Accepted
// Submission Date: 2025-11-16
// UVa Run Time: 0.860s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const long long INF = 1e18;

int main() {
    int n, m, L;
    while (cin >> n >> m >> L) {
        vector<tuple<int, int, int>> edges;
        vector<vector<long long>> originalDist(n + 1, vector<long long>(n + 1, INF));
        
        for (int i = 1; i <= n; i++)
            originalDist[i][i] = 0;
        
        // 存储所有边
        for (int i = 0; i < m; i++) {
            int a, b, s;
            cin >> a >> b >> s;
            edges.emplace_back(a, b, s);
            // 构建原始图时取最短的边
            if (s < originalDist[a][b]) {
                originalDist[a][b] = originalDist[b][a] = s;
            }
        }
        
        // 计算原始图的最短路径
        auto originalFloyd = originalDist;
        for (int k = 1; k <= n; k++)
            for (int i = 1; i <= n; i++)
                for (int j = 1; j <= n; j++)
                    if (originalFloyd[i][k] < INF && originalFloyd[k][j] < INF)
                        originalFloyd[i][j] = min(originalFloyd[i][j], originalFloyd[i][k] + originalFloyd[k][j]);
        
        long long originalCost = 0;
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                originalCost += (originalFloyd[i][j] < INF ? originalFloyd[i][j] : L);
        
        long long maxCost = 0;
        
        // 对每条边尝试删除
        for (auto& e : edges) {
            int a = get<0>(e), b = get<1>(e), s = get<2>(e);
            
            // 重新初始化距离矩阵
            vector<vector<long long>> dist(n + 1, vector<long long>(n + 1, INF));
            for (int i = 1; i <= n; i++)
                dist[i][i] = 0;
            
            // 构建删除该边后的图
            for (auto& edge : edges) {
                int u = get<0>(edge), v = get<1>(edge), w = get<2>(edge);
                // 如果是被删除的边，跳过
                if (u == a && v == b && w == s) continue;
                // 否则取最短的边
                if (w < dist[u][v]) {
                    dist[u][v] = dist[v][u] = w;
                }
            }
            
            // 计算删除该边后的最短路径
            for (int k = 1; k <= n; k++)
                for (int i = 1; i <= n; i++)
                    for (int j = 1; j <= n; j++)
                        if (dist[i][k] < INF && dist[k][j] < INF)
                            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
            
            long long newCost = 0;
            for (int i = 1; i <= n; i++)
                for (int j = 1; j <= n; j++)
                    newCost += (dist[i][j] < INF ? dist[i][j] : L);
            
            maxCost = max(maxCost, newCost);
        }
        
        cout << originalCost << " " << maxCost << endl;
    }
    return 0;
}
```

## 总结

本题通过枚举所有可能的边删除情况，结合 $\texttt{Floyd-Warshall}$ 算法高效地解决了最短路径计算问题。关键在于正确处理多重边和不连通情况，以及合理利用 $n$ 的规模限制选择合适的算法。

对于更大的 $n$ 值，可以考虑使用 $m$ 次 $\texttt{Dijkstra}$ 算法来优化，但在本题的约束条件下，当前的解法已经足够高效且易于实现。
