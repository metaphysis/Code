## 题目描述

$\texttt{Sheryl}$ 在 $\texttt{Brada}$ 国的一家软件公司开发 $\texttt{Windows}$ 操作系统。这个操作系统运行在文本模式下，窗口由大写字母（ `A` 到 `Z` ）组成边框，每个窗口有唯一的 $\texttt{ID}$ （一个字母）。窗口都是矩形，边框至少 $3$ 个字符宽和 $3$ 个字符高。窗口之间可以重叠。

如果一个窗口的 **任何部分**（包括边框和内部）都没有被其他窗口覆盖，则称它为 **“顶层窗口”** 。顶层窗口通常与用户交互最频繁，因此需要分配更多 $\texttt{CPU}$ 时间和更高优先级。

给定一个 $n \times m$ 的文本屏幕（ $1 \le n,m \le 100$ ），用字符表示窗口边框，非边框部分用 `.` 表示。要求找出所有顶层窗口的 $\texttt{ID}$ ，并按字母顺序输出。

### 输入格式
- 多个测试用例，每个用例以 $n$ 和 $m$ 开始。
- 接下来 $n$ 行，每行 $m$ 个字符。
- 输入以 `0 0` 结束。

### 输出格式
- 对于每个测试用例，输出一行，包含所有顶层窗口的 $\texttt{ID}$ ，按字母顺序排列，中间不留空格。

### 样例输入
```
9 26
..........................
....AAAAAAAAAAAAA.........
....A...........A.........
....A.......BBBBBBBBBB....
....A.......B........BCCC.
....AAAAAAAAB........B..C.
.......C....BBBBBBBBBB..C.
.......CCCCCCCCCCCCCCCCCC.
..........................
7 25
.........................
....DDDDDDDDDDDDD........
....D...........D........
....D...........D........
....D...........D..AAA...
....DDDDDDDDDDDDD..A.A...
...................AAA...
0 0
```

### 样例输出
```
B
AD
```

## 题目分析

我们需要判断哪些窗口是顶层窗口，即它的 **整个矩形区域**（包括边框和内部）都没有被其他窗口覆盖。

### 关键点
1. **窗口的表示**：一个窗口由其边框字母唯一标识，边框是矩形，至少 $3 \times 3$ 大小。
2. **覆盖的定义**：如果窗口的 **任意一个字符**（边框或内部）被其他窗口的字符（边框或内部）占据，则该窗口被覆盖。
3. **顶层窗口条件**：
   - 边框完整：四条边全部由该窗口的字母组成。
   - 内部为空：边框内的所有字符必须是 `.` ，表示没有被其他窗口覆盖。

### 思路
对于每个可能的大写字母（ `A` 到 `Z` ）：
1. **定位窗口**：在屏幕中找到该字母第一次出现的位置（即窗口的左上角）。
2. **确定尺寸**：从左上角向右、向下延伸，直到遇到非该字母的字符，确定宽度和高度。
3. **验证边框**：
   - 宽度和高度必须至少为 $3$ 。
   - 四条边上的所有字符必须全是该字母。
4. **验证内部**：边框内的所有字符必须全是 `.` 。
5. **标记顶层**：如果以上条件都满足，则该窗口是顶层窗口。

### 算法复杂度
- 对于每个字母，我们遍历整个屏幕一次，复杂度为 $O(26 \times n \times m)$ 。
- 由于 $n, m \le 100$ ，总计算量很小，完全可行。

```cpp
// Ugly Windows

#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<string> grid;
bool isTop[26];

void checkTop(char ch) {
    int sr = -1, sc = -1;
    // 找左上角
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++)
            if (grid[i][j] == ch) {
                sr = i; sc = j;
                break;
            }
        if (sr != -1) break;
    }
    if (sr == -1) return; // 没找到该字母
    // 向右延伸
    int width = 1;
    while (sc + width < m && grid[sr][sc + width] == ch) width++;
    // 向下延伸
    int height = 1;
    while (sr + height < n && grid[sr + height][sc] == ch) height++;
    // 检查是否满足最小尺寸（避免把尺寸 1 的窗口视为合法窗口）
    if (width < 3 || height < 3) return;
    // 检查下边和右边是否全是 ch
    // 下边
    for (int j = sc; j < sc + width; j++)
        if (grid[sr + height - 1][j] != ch) return;
    // 右边
    for (int i = sr; i < sr + height; i++)
        if (grid[i][sc + width - 1] != ch) return;
    // 检查内部是否全是 '.'（没有被其他窗口覆盖）
    for (int i = sr + 1; i < sr + height - 1; i++)
        for (int j = sc + 1; j < sc + width - 1; j++)
            if (grid[i][j] != '.') return;
    isTop[ch - 'A'] = true;
}

int main() {
    while (cin >> n >> m && (n || m)) {
        grid.resize(n);
        for (int i = 0; i < n; i++) cin >> grid[i];
        memset(isTop, 0, sizeof isTop);
        for (char ch = 'A'; ch <= 'Z'; ch++) checkTop(ch);
        for (int i = 0; i < 26; i++)
            if (isTop[i]) cout << char('A' + i);
        cout << endl;
    }
    return 0;
}
```
