## 题目分析

### 问题描述

本题要求我们处理销售员的工作路径修正问题。给定一个连通的无向图表示销售员的工作区域，以及一个可能包含错误的工作路径，我们需要找到一个**正确的路径**，使得新路径与原路径的距离最小。

**关键概念说明：**
- **正确路径**：路径中任意两个连续顶点必须是相同的顶点或在图中相邻（有边连接）
- **距离定义**：两个相同长度路径 $A$ 和 $B$ 的距离为对应位置顶点不同的次数
- **目标**：找到与原路径长度相同的正确路径，使得距离最小化

### 输入输出规格

**输入格式：**
- 第一行：测试用例数 $T$
- 每个测试用例：
  - 第一行：顶点数 $n_1$ ($3 \leq n_1 \leq 100$)，边数 $n_2$ ($2 \leq n_2 \leq 4950$)
  - 接下来 $n_2$ 行：每条边的两个顶点
  - 最后一行：路径长度 $n$ ($2 \leq n \leq 200$)，后跟 $n$ 个顶点序列

**输出格式：**
- 每个测试用例一行，输出最小距离

## 解题思路

### 核心洞察

这个问题可以转化为一个**动态规划**问题，我们需要在图的约束下为路径的每个位置选择合适的顶点。

### 动态规划状态设计

定义状态：
- $dp[i][v]$ 表示处理到路径第 $i$ 个位置时，选择顶点 $v$ 的最小累计距离

**状态转移方程：**
对于位置 $i$ 选择顶点 $v$，考虑所有可能的前一个顶点 $u$：
- 如果 $u$ 和 $v$ 相同或相邻（即 $graph[u][v] = true$）
- 则 $dp[i][v] = \min(dp[i][v], dp[i-1][u] + cost)$
- 其中 $cost = 0$ 如果 $v$ 等于原路径第 $i$ 个顶点，否则 $cost = 1$

### 算法步骤

1. **图构建**：使用邻接矩阵存储图的连接关系，包括自环（顶点与自身相邻）
2. **初始化**：对于第一个位置，所有顶点都是候选，距离为 $0$（相同）或 $1$（不同）
3. **状态转移**：对于每个后续位置，枚举所有可能的当前顶点和前一个顶点组合
4. **结果提取**：最后一个位置所有可能顶点中的最小距离即为答案

### 复杂度分析

- 顶点数：$n_1 \leq 100$
- 路径长度：$n \leq 200$
- 时间复杂度：$O(n \times n_1^2) \approx 200 \times 100^2 = 2 \times 10^6$，完全可行
- 空间复杂度：$O(n \times n_1)$，同样可行

```cpp
// Salesmen

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <cstring>
#include <algorithm>
using namespace std;

const int MAX_VERTICES = 105;
const int MAX_PATH_LENGTH = 205;
const int INF = 0x3f3f3f3f;

bool graph[MAX_VERTICES][MAX_VERTICES];
int dp[MAX_PATH_LENGTH][MAX_VERTICES];
vector<int> path;

int main() {
    int testCases;
    cin >> testCases;
    while (testCases--) {
        int numVertices, numEdges;
        cin >> numVertices >> numEdges;
        
        memset(graph, false, sizeof(graph));
        for (int i = 1; i <= numVertices; i++) {
            graph[i][i] = true; // 同一个顶点是相邻的
        }
        
        for (int i = 0; i < numEdges; i++) {
            int u, v;
            cin >> u >> v;
            graph[u][v] = graph[v][u] = true;
        }
        
        int pathLength;
        cin >> pathLength;
        path.resize(pathLength + 1);
        for (int i = 1; i <= pathLength; i++) {
            cin >> path[i];
        }
        
        memset(dp, INF, sizeof(dp));
        
        // 初始化第一个位置
        for (int v = 1; v <= numVertices; v++) {
            dp[1][v] = (path[1] == v ? 0 : 1);
        }
        
        // 动态规划
        for (int i = 2; i <= pathLength; i++) {
            for (int v = 1; v <= numVertices; v++) {
                for (int u = 1; u <= numVertices; u++) {
                    if (graph[u][v]) {
                        dp[i][v] = min(dp[i][v], dp[i - 1][u] + (path[i] == v ? 0 : 1));
                    }
                }
            }
        }
        
        int minDistance = INF;
        for (int v = 1; v <= numVertices; v++) {
            minDistance = min(minDistance, dp[pathLength][v]);
        }
        
        cout << minDistance << endl;
    }
    return 0;
}
```

## 样例分析

### 样例1
```
输入路径: [1 2 2 7 5 5 5 7 4]
输出: 1
```
说明：只需要将第 $4$ 个位置的 $7$ 改为 $6$ 或 $4$ 即可得到正确路径，距离为 $1$

### 样例2
```
输入路径: [1 2 2 6 5 5 5 7 4]
输出: 0
```
说明：原路径本身就是正确路径，距离为 $0$

## 总结

本题通过动态规划巧妙地解决了路径修正问题。关键在于：
1. 正确理解"正确路径"的定义
2. 设计合适的状态表示和转移方程
3. 注意图的连通性和自环情况

这种动态规划方法在图路径相关问题中具有通用性，可以推广到类似的约束满足问题中。
