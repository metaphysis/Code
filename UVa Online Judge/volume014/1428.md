## 题目描述

有 $N$ ($3 \leq N \leq 20000$) 个乒乓球选手住在一条东西走向的街道上（将街道视为一条线段）。每个选手有一个唯一的技能值。为了提升技能，他们经常互相比赛。如果两个选手想要比赛，他们必须选择其他选手中的一个作为裁判，并在裁判家中举行比赛。

有两个限制条件：
1. 裁判的技能值不能同时高于或同时低于两个参赛者的技能值
2. 参赛者到裁判家的总步行距离不能超过两个参赛者家之间的距离

如果裁判或任一参赛者不同，我们就认为是不同的比赛。问题是要计算在这条乒乓球街道上可以举行多少种不同的比赛。

## 输入格式

第一行包含整数 $T$ ($1 \leq T \leq 20$)，表示测试用例的数量，后面跟着 $T$ 行，每行描述一个测试用例。

每个测试用例包含 $N + 1$ 个整数。第一个整数是 $N$，表示选手数量。接着是 $N$ 个不同的整数 $a_1, a_2, \ldots, a_N$，按从西到东的顺序给出每个选手的技能值 ($1 \leq a_i \leq 100000$)。

## 输出格式

对于每个测试用例，输出一行包含一个整数，表示不同比赛的总数。

## 题目分析

### 条件分析

让我们仔细分析题目中的两个条件：

**条件 1：裁判的技能值限制**
- 裁判的技能值不能同时高于或同时低于两个参赛者的技能值
- 这意味着裁判的技能值必须严格介于两个参赛者的技能值之间
- 由于所有技能值都是唯一的，所以不会出现相等的情况

**条件 2：步行距离限制**
设参赛者位置为 $i$ 和 $j$（$i < j$），裁判位置为 $k$。

总步行距离 = $|x_i - x_k| + |x_j - x_k|$
两家之间的距离 = $|x_i - x_j| = x_j - x_i$（因为 $i < j$）

条件要求：
$|x_i - x_k| + |x_j - x_k| \le x_j - x_i$

考虑 $k$ 的可能位置：
- 如果 $k < i$：步行距离 = $(x_i - x_k) + (x_j - x_k) = x_i + x_j - 2x_k$
  代入条件：$x_i + x_j - 2x_k \le x_j - x_i$ → $2x_i \le 2x_k$ → $x_i \le x_k$，与 $k < i$ 矛盾
- 如果 $k > j$：步行距离 = $(x_k - x_i) + (x_k - x_j) = 2x_k - x_i - x_j$
  代入条件：$2x_k - x_i - x_j \le x_j - x_i$ → $2x_k \le 2x_j$ → $x_k \le x_j$，与 $k > j$ 矛盾

因此，唯一可能的情况是 $i < k < j$，即裁判必须严格住在两个参赛者之间。

### 问题转化

综合两个条件，问题转化为：

> 统计所有三元组 $(i, k, j)$，其中 $i < k < j$，并且 $a_k$ 的值严格在 $a_i$ 和 $a_j$ 之间。

### 高效解法

对于每个可能的裁判位置 $k$，我们需要计算：
- $leftLess[k]$：在 $k$ 左边且技能值小于 $a_k$ 的人数
- $leftGreater[k]$：在 $k$ 左边且技能值大于 $a_k$ 的人数  
- $rightLess[k]$：在 $k$ 右边且技能值小于 $a_k$ 的人数
- $rightGreater[k]$：在 $k$ 右边且技能值大于 $a_k$ 的人数

那么以 $k$ 为裁判的比赛数量为：
$count(k) = leftLess[k] \times rightGreater[k] + leftGreater[k] \times rightLess[k]$

最终答案：
$ans = \sum_{k=1}^N count(k)$

由于 $N$ 最大为 $20000$，$O(N^2)$ 的算法会超时，我们需要 $O(N \log N)$ 的算法。

### 算法选择

使用$\texttt{Fenwick Tree}$来高效统计：
- 从左到右扫描，计算 $leftLess$ 和 $leftGreater$
- 从右到左扫描，计算 $rightLess$ 和 $rightGreater$

由于技能值范围是 $1$ 到 $100000$，我们可以直接用技能值作为树状数组的下标。

## 算法步骤

1. 读入数据
2. 对每个测试用例：
   - 初始化树状数组
   - 从左到右遍历：
     - $leftLess[k] = query(a[k]-1)$
     - $leftGreater[k] = (k-1) - leftLess[k]$
     - 将 $a[k]$ 位置加 $1$
   - 清空树状数组
   - 从右到左遍历：
     - $rightLess[k] = query(a[k]-1)$
     - $rightGreater[k] = (N-k) - rightLess[k]$
     - 将 $a[k]$ 位置加 $1$
   - 对每个 $k$ 累加 $leftLess[k] \times rightGreater[k] + leftGreater[k] \times rightLess[k]$
3. 输出结果

## 复杂度分析

- 每次查询和更新树状数组的时间复杂度为 $O(\log M)$，其中 $M = 100000$
- 进行两次遍历，每次 $N$ 次操作
- 总时间复杂度：$O(T \cdot N \log M)$，完全可行

```cpp
// Ping Pong

#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 20005;      // 最大玩家数量
const int MAXVAL = 100005;   // 最大技能值

int T, N;                    // T:测试用例数, N:玩家数
int a[MAXN];                 // 存储玩家技能值
int leftLess[MAXN], leftGreater[MAXN], rightLess[MAXN], rightGreater[MAXN]; // 左右统计数组

// 树状数组
int BIT[MAXVAL];

// 更新树状数组
void update(int idx, int val) {
    while (idx < MAXVAL) {
        BIT[idx] += val;
        idx += (idx & -idx);
    }
}

// 查询前缀和
int query(int idx) {
    int sum = 0;
    while (idx > 0) {
        sum += BIT[idx];
        idx -= (idx & -idx);
    }
    return sum;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> T;
    while (T--) {
        cin >> N;
        for (int i = 1; i <= N; i++) {
            cin >> a[i];
        }

        // 从左到右扫描，计算左边小于和大于当前技能值的人数
        memset(BIT, 0, sizeof(BIT));
        for (int i = 1; i <= N; i++) {
            leftLess[i] = query(a[i] - 1);        // 查询小于a[i]的数量
            leftGreater[i] = (i - 1) - leftLess[i]; // 左边总人数减去小于的就是大于的
            update(a[i], 1);                      // 标记当前技能值已出现
        }

        // 从右到左扫描，计算右边小于和大于当前技能值的人数
        memset(BIT, 0, sizeof(BIT));
        for (int i = N; i >= 1; i--) {
            rightLess[i] = query(a[i] - 1);       // 查询小于a[i]的数量
            rightGreater[i] = (N - i) - rightLess[i]; // 右边总人数减去小于的就是大于的
            update(a[i], 1);                      // 标记当前技能值已出现
        }

        // 计算总比赛数
        long long ans = 0;
        for (int i = 1; i <= N; i++) {
            ans += (long long)leftLess[i] * rightGreater[i] + (long long)leftGreater[i] * rightLess[i];
        }

        cout << ans << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于将复杂的条件约束转化为清晰的三元组统计问题，并利用$\texttt{Fenwick Tree}$高效地完成统计。通过分别从左右两个方向扫描并维护技能值的出现情况，我们可以在 $O(N \log M)$ 的时间复杂度内解决问题，其中 $M$ 是技能值的范围。这种使用树状数组统计顺序关系的方法在解决类似问题时非常有用。
