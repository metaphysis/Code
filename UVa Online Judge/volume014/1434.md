## 题目分析

本题要求计算一个看似复杂的数学表达式：

$$S_n = \sum_{k=1}^n \left[ \frac{(3k+6)! + 1}{3k+7} - \left\lfloor \frac{(3k+6)!}{3k+7} \right\rfloor \right]$$

其中 $\lfloor x \rfloor$ 表示不超过 $x$ 的最大整数。

### 关键观察

设 $m = 3k + 7$，那么 $3k + 6 = m - 1$，原式可重写为：

$$\frac{(m-1)! + 1}{m} - \left\lfloor \frac{(m-1)!}{m} \right\rfloor$$

### 应用威尔逊定理

**威尔逊定理**指出：对于质数 $p$，有 $(p-1)! \equiv -1 \pmod{p}$，即 $(p-1)! + 1$ 能被 $p$ 整除。

#### 情况分析

1. **当 $m$ 是质数时**：
   - 根据威尔逊定理，$\frac{(m-1)! + 1}{m}$ 是整数
   - 设 $\frac{(m-1)! + 1}{m} = A$（整数）
   - 那么 $\frac{(m-1)!}{m} = A - \frac{1}{m}$
   - 因此 $\left\lfloor \frac{(m-1)!}{m} \right\rfloor = A - 1$
   - 两项相减：$A - (A - 1) = 1$

2. **当 $m$ 是合数时**：
   - 对于 $m > 4$ 的合数，$(m-1)!$ 能被 $m$ 整除
   - 因此 $\frac{(m-1)! + 1}{m}$ 不是整数
   - 但 $\frac{(m-1)!}{m}$ 是整数
   - 设 $\frac{(m-1)!}{m} = B$（整数）
   - 那么 $\frac{(m-1)! + 1}{m} = B + \frac{1}{m}$
   - 两项相减：$(B + \frac{1}{m}) - B = \frac{1}{m}$
   - 由于 $m > 1$，$\frac{1}{m} < 1$，所以最终结果为 $0$

### 问题转化

通过以上分析，我们发现：

- 当 $3k+7$ 是质数时，对应项为 $1$
- 当 $3k+7$ 是合数时，对应项为 $0$

因此，原问题转化为：

$$S_n = \sum_{k=1}^n [3k+7 \text{ 是质数}]$$

其中 $[P]$ 是指示函数，当命题 $P$ 为真时值为 $1$，否则为 $0$。

## 解题思路

### 算法选择

1. **预处理质数**：使用埃拉托斯特尼筛法预处理 $3 \times 10^6 + 10$ 范围内的所有质数
2. **前缀和数组**：预处理前缀和数组，$prefix[i]$ 表示 $k$ 从 $1$ 到 $i$ 时满足 $3k+7$ 是质数的个数
3. **查询处理**：对于每个查询 $n$，直接输出 $prefix[n]$

#include <bits/stdc++.h>
using namespace std;

const int MAX_K = 1000000;                    // k 的最大值
const int MAX_M = 3 * MAX_K + 10;             // m = 3k+7 的最大值

vector<bool> isPrime;                         // 标记是否为质数
vector<int> prefixSum;                        // 前缀和数组

// 埃拉托斯特尼筛法预处理质数
void sieve() {
    isPrime.assign(MAX_M + 1, true);          // 初始化为全是质数
    isPrime[0] = isPrime[1] = false;          // 0 和 1 不是质数
    for (int i = 2; i * i <= MAX_M; i++) {
        if (isPrime[i]) {                     // 如果 i 是质数
            for (int j = i * i; j <= MAX_M; j += i) {
                isPrime[j] = false;           // 标记 i 的倍数为非质数
            }
        }
    }
}

// 预处理前缀和数组
void precompute() {
    sieve();                                  // 先筛出质数
    prefixSum.resize(MAX_K + 1, 0);           // 初始化前缀和数组
    for (int k = 1; k <= MAX_K; k++) {
        int m = 3 * k + 7;                    // 计算 m = 3k+7
        // 如果 m 是质数，当前项为 1，否则为 0
        prefixSum[k] = prefixSum[k - 1] + (isPrime[m] ? 1 : 0);
    }
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    precompute();
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        cout << prefixSum[n] << "\n";
    }
    return 0;
}
