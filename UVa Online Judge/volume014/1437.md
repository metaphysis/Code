## 题目描述

有两个长度相等的字符串 $A$ 和 $B$，都由小写字母组成。你有一个强大的字符串画家，可以将任意一段连续的字符全部刷成同一个字符。也就是说，使用画家后，该段字符都由同一种字符组成。

你的任务是用最少的操作次数将字符串 $A$ 变成字符串 $B$。

**输入格式**  
输入包含多个测试用例。每个测试用例包含两行：
- 第一行是字符串 $A$
- 第二行是字符串 $B$

字符串长度不超过 $100$。

**输出格式**  
每个测试用例输出一行，包含一个整数表示答案。

**样例输入**
```
zzzzzfzzzzz
abcdefedcba
abababababab
cdcdcdcdcdcd
```

**样例输出**
```
6
7
```

## 题目分析

### 问题理解

这是一个典型的区间动态规划问题。我们需要找到将字符串 $A$ 转换为字符串 $B$ 的最少刷子操作次数。

关键观察：
1. 如果 $A$ 和 $B$ 在某个位置字符相同，那么这个位置可能不需要额外的刷子操作
2. 一次刷子操作可以将任意长度的连续区间刷成同一个字符
3. 问题可以分解为两个子问题：
   - 将空白字符串刷成 $B$ 的最少操作次数
   - 利用 $A$ 和 $B$ 的相似性来减少操作次数

### 解题思路

我们采用两步走的策略：

#### 第一步：预处理 $\texttt{DP}$ 数组

定义 $dp[i][j]$ 表示将空白字符串刷成 $B[i..j]$ 所需的最少操作次数。

状态转移方程：
- 初始情况：$dp[i][i] = 1$（单个字符需要一次操作）
- 对于区间 $[i, j]$：
  - 最坏情况：$dp[i][j] = dp[i+1][j] + 1$
  - 优化：如果存在 $k \in [i+1, j]$ 使得 $B[i] == B[k]$，那么：
    $dp[i][j] = min(dp[i][j], dp[i+1][k] + dp[k+1][j])$

这个优化的思路是：如果 $B[i]$ 和 $B[k]$ 相同，我们可以先刷 $[i, k]$ 区间，然后刷 $[k+1, j]$ 区间，这样可以减少操作次数。

#### 第二步：计算最终答案

定义 $ans[i]$ 表示将 $A[0..i]$ 刷成 $B[0..i]$ 的最少操作次数。

初始化：
- 如果 $A[0] == B[0]$，则 $ans[0] = 0$
- 否则 $ans[0] = 1$

状态转移：
- 如果 $A[i] == B[i]$，则 $ans[i] = ans[i-1]$（这个位置不需要额外操作）
- 否则，我们需要考虑所有可能的分割点：
  $ans[i] = min(ans[j] + dp[j+1][i])$，其中 $j \in [0, i-1]$
  - 特殊情况：$ans[i] = min(ans[i], dp[0][i])$（整个区间重刷）

### 算法复杂度

- 预处理 $\texttt{DP}$ 数组：$O(n^3)$
- 计算答案数组：$O(n^2)$
- 总复杂度：$O(n^3)$，对于 $n \leq 100$ 完全可行

```cpp
// String Painter

#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

int main() {
    string A, B;
    while (cin >> A >> B) {
        int n = A.length();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        
        // Step 1: 计算dp[i][j] - 将空白串刷成B[i..j]的最小次数
        for (int i = n - 1; i >= 0; --i) {
            dp[i][i] = 1;  // 单个字符需要1次操作
            for (int j = i + 1; j < n; ++j) {
                // 最坏情况：先刷i位置，再刷剩下的
                dp[i][j] = dp[i + 1][j] + 1;
                // 寻找优化机会：如果B[i] == B[k]，可以合并操作
                for (int k = i + 1; k <= j; ++k) {
                    if (B[i] == B[k]) {
                        // 状态转移：dp[i][j] = min(dp[i][j], dp[i+1][k] + dp[k+1][j])
                        dp[i][j] = min(dp[i][j], dp[i + 1][k] + (k + 1 > j ? 0 : dp[k + 1][j]));
                    }
                }
            }
        }

        // Step 2: 计算ans[i] - 将A[0..i]刷成B[0..i]的最小次数
        vector<int> ans(n, 0);
        // 初始化第一个字符
        if (A[0] == B[0]) {
            ans[0] = 0;  // 第一个字符相同，不需要操作
        } else {
            ans[0] = 1;  // 第一个字符不同，需要1次操作
        }

        for (int i = 1; i < n; ++i) {
            if (A[i] == B[i]) {
                // 当前字符相同，继承前一个结果
                ans[i] = ans[i - 1];
            } else {
                // 当前字符不同，考虑所有可能的分割点
                ans[i] = dp[0][i];  // 最坏情况：整个区间重刷
                for (int j = 0; j < i; ++j) {
                    // 在j处分割：前j个字符用ans[j]，后面的用dp[j+1][i]
                    ans[i] = min(ans[i], ans[j] + dp[j + 1][i]);
                }
            }
        }

        cout << ans[n - 1] << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于将复杂问题分解为两个相对简单的子问题：
1. 将空白字符串刷成目标字符串的最小操作次数
2. 利用源字符串和目标字符串的相似性来优化操作次数

通过区间动态规划的方法，我们能够高效地解决这个问题。预处理 DP 数组帮助我们快速计算任意子区间的操作次数，而答案数组则充分利用了源字符串和目标字符串的匹配信息来减少不必要的操作。
