## 题目描述

你曾有一位会计师，她记录了你所有的开支。每天你向她发送支出记录，她会将这些记录追加到一个大的汇总文件中。你的每条记录包含多行，格式如下：

```
bed = 100  
table = 150  
furniture = bed + table  
furniture = furniture + 10  
```

这表示你在家具上花费了$250$，在运输上花费了$10$（可能如此）。更一般地说，你的记录中的每一行是以下两种形式之一：

- `name = number`
- `name = item + item`

其中 `item` 可以是数字或名称，`number` 是不超过 $10^9$ 的自然数（没有前导零），`name` 是任意大小写字母组成的字符串。

在将你的记录转移到汇总文件时，会计师既不会改变记录中行的顺序，也不会打乱不同记录的行。但有时她会改变名称……她这样做是一致的，将单个记录中所有出现的名称改为相同的新名称。此外，同一记录中的不同名称在汇总文件中被重写为不同的名称。但这不能保证与你的其他记录一致——一个记录中的名称 `beer` 可能被重写为 `drink`，另一个记录中的名称 `tee` 可能也被重写为 `drink`，而下一个记录中的 `beer` 可能被重写为 `food`。我们将她的记录版本称为转录本。

问题是你的会计师刚刚辞职了（而且，事实证明，她带走了你大部分积蓄），你只剩下汇总文件和一大堆未排序的记录。你想检查是否有可能某些记录没有被记录在汇总中，因此对于每个记录，你都在搜索汇总文件中可能是其转录本的部分。

## 算法分析与难点解析

### 问题难点

本题的核心挑战在于处理**变量名重映射**问题。在同一个记录（note）中，变量名可以被任意重命名，但必须保持结构一致性。这意味着：

1. **同一记录内的变量名映射一致**：如果 `a` 被重命名为 `x`，那么该记录中所有 `a` 都变为 `x`
2. **不同记录间的映射独立**：记录 $1$ 中的 `a` 可能映射为 `x`，记录 $2$ 中的 `a` 可能映射为 `y`
3. **结构必须保持**：变量之间的引用关系必须保持不变

### 解决方案：归一化编码与 $\texttt{Aho-Corasick}$ 自动机

#### 1. 编码策略

我们采用一种巧妙的编码方案，将变量名转换为数值表示：

- **数字字面量**：直接转换为负数值，如 `100` → `-100`
- **新变量名**：编码为 `当前位置 + 1`，表示这是一个新引入的变量
- **引用已有变量**：编码为 `当前位置 - 上次出现位置`，表示相对引用关系

例如记录：
```
a = 100
b = a + 200
```
编码为：`[1, EQ, -100, ED, 5, EQ, 4, -200, ED]`

#### 2. 归一化处理的关键洞察

这是算法的核心创新点。当在长汇总文件中匹配时，变量名的绝对位置会很大，但与记录中的相对位置可能不匹配。我们使用 `min(depth, token)` 进行归一化：

- 如果 `token <= depth`：表示引用当前模式内部的变量，需要精确匹配
- 如果 `token > depth`：表示引用模式开始前的变量，任何大于 `depth` 的值都等价

这种归一化确保了：
- 模式内部引用关系保持精确
- 外部引用被正确归类，不受绝对位置影响

#### 3. $\texttt{Aho-Corasick}$ 自动机的应用

我们将所有记录的编码模式插入到 $\texttt{Trie}$ 树中，然后构建 $\texttt{Aho-Corasick}$ 自动机：

- **$\texttt{Trie}$ 构建**：使用原始编码，不进行归一化
- **失败指针构建**：在构建时使用归一化进行查找
- **匹配阶段**：对汇总文本的 $\texttt{token}$ 进行归一化后匹配

这种方法的时间复杂度为 $O(L)$，其中 $L$ 是总文本长度，能够处理题目中的大规模数据。

### 算法正确性证明

归一化处理的正确性基于以下观察：

1. **结构不变性**：无论变量名如何重映射，变量之间的相对引用关系保持不变
2. **深度边界**：对于深度为 $d$ 的节点，任何大于 $d$ 的引用都指向模式开始前的变量
3. **一致性保证**：同一记录的不同重命名版本会产生相同的编码序列

通过将汇总文本中的绝对位置映射到记录模式的相对结构中，我们成功解决了变量重命名带来的匹配难题。

```cpp
// Accountant Notes
// UVa ID: 1441
// Verdict: Accepted
// Submission Date: 2025-10-26
// UVa Run Time: 1.290s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 特殊标记定义
const int EQ = -1e9 - 1;   // 表示 '=' 分隔符
const int ED = -1e9 - 2;   // 表示行结束符

struct AC {
    struct Node {
        unordered_map<int, int> ch;  // 子节点映射: token -> 节点编号
        int fail = 0;                // 失败指针
        int depth = 0;               // 节点深度
        vector<int> notes;           // 匹配到此节点时对应的记录编号
    };
    vector<Node> nodes;
    
    AC() { 
        nodes.emplace_back(); 
        nodes[0].depth = 1;  // 根节点深度为1
    }
    
    // 插入记录模式到Trie树
    void insert(const vector<int>& pattern, int id) {
        int u = 0;  // 从根节点开始
        for (int token : pattern) {
            // 如果边不存在，创建新节点
            if (!nodes[u].ch.count(token)) {
                nodes.emplace_back();
                nodes.back().depth = nodes[u].depth + 1;
                nodes[u].ch[token] = nodes.size() - 1;
            }
            u = nodes[u].ch[token];
        }
        nodes[u].notes.push_back(id);  // 记录匹配到此节点的记录编号
    }
    
    // 构建Aho-Corasick自动机的失败指针
    void build() {
        queue<int> q;
        // 根节点的所有子节点的失败指针指向根节点
        for (auto& [token, child] : nodes[0].ch) 
            q.push(child);
        
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto& [token, child] : nodes[u].ch) {
                int v = nodes[u].fail;
                // 沿失败链寻找匹配的边（使用归一化）
                while (v && !nodes[v].ch.count(min(nodes[v].depth, token))) 
                    v = nodes[v].fail;
                
                // 设置失败指针
                if (v) {
                    nodes[child].fail = nodes[v].ch[min(nodes[v].depth, token)];
                } else {
                    // 检查根节点是否有匹配的边
                    int norm = min(1, token);  // 根节点的子节点深度为1
                    nodes[child].fail = nodes[0].ch.count(norm) ? nodes[0].ch[norm] : 0;
                }
                q.push(child);
            }
        }
    }
    
    // 在文本中匹配所有记录
    vector<int> match(const vector<int>& text, const vector<int>& noteLen, int k) {
        vector<int> res(k + 1);           // 记录每个记录的匹配结束行
        vector<bool> vis(nodes.size());   // 节点访问标记（去重）
        int u = 0, line = 1;              // 当前节点和行号
        
        for (int token : text) {
            // 对文本token进行归一化
            int norm = min(nodes[u].depth, token);
            int v = u;
            
            // 沿失败链寻找匹配
            while (v && !nodes[v].ch.count(norm)) {
                v = nodes[v].fail;
                norm = min(nodes[v].depth, token);  // 重新计算归一化值
            }
            
            // 转移到匹配的节点或根节点
            if (v) {
                u = nodes[v].ch[norm];
            } else {
                u = nodes[0].ch.count(min(1, token)) ? nodes[0].ch[min(1, token)] : 0;
            }
            
            // 标记所有匹配的记录
            for (v = u; v && !vis[v]; v = nodes[v].fail) {
                vis[v] = true;
                for (int id : nodes[v].notes) {
                    if (!res[id]) res[id] = line;  // 记录第一次匹配的结束行
                }
            }
            
            // 遇到行结束符时更新行号
            if (token == ED) line++;
        }
        return res;
    }
};

// 将文本行编码为token序列
vector<int> encode(int lines) {
    vector<int> res;
    unordered_map<string, int> pos;  // 记录变量名最近出现的位置
    int idx = 0;                     // 当前编码位置
    
    cin.ignore();  // 忽略换行符
    for (int i = 0; i < lines; i++) {
        string line, name, expr1, expr2;
        char _;
        getline(cin, line);
        stringstream ss(line);
        ss >> name >> _ >> expr1;
        
        // 编码lambda函数
        auto enc = [&](const string& s) {
            if (!s.empty() && isdigit(s[0]) && (s.size() == 1 || s[0] != '0')) {
                // 数字字面量：转换为负值
                res.push_back(-stoi(s));
                idx++;
            } else {
                // 变量名：新变量为idx+1，引用变量为位置差
                res.push_back(pos.count(s) ? idx - pos[s] : idx + 1);
                pos[s] = idx++;
            }
        };
        
        enc(name);           // 编码变量名
        res.push_back(EQ);   // 等号分隔符
        idx++;
        enc(expr1);          // 编码第一个表达式
        
        // 如果有第二个表达式
        if (ss >> _ >> expr2) 
            enc(expr2);
        
        res.push_back(ED);   // 行结束符
        idx++;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int Z;
    cin >> Z;
    while (Z--) {
        int k;
        cin >> k;
        AC ac;
        vector<int> noteLen(k + 1);
        
        // 读取并编码所有记录
        for (int i = 1; i <= k; i++) {
            cin >> noteLen[i];
            ac.insert(encode(noteLen[i]), i);
        }
        
        ac.build();  // 构建自动机
        
        // 读取并编码汇总文件
        int sumLines;
        cin >> sumLines;
        auto matchRes = ac.match(encode(sumLines), noteLen, k);
        
        // 输出结果
        for (int i = 1; i <= k; i++) {
            if (matchRes[i]) {
                // 起始行 = 结束行 - 记录行数 + 1
                cout << matchRes[i] - noteLen[i] + 1 << "\n";
            } else {
                cout << "NONE\n";
            }
        }
    }
    return 0;
}
```

## 总结

本题通过巧妙的编码方案和归一化处理，成功解决了变量重命名下的模式匹配问题。$\texttt{Aho-Corasick}$ 自动机提供了高效的多模式匹配能力，而归一化技术则确保了在不同重命名情况下的正确匹配。该算法的时间复杂度为 $O(L)$，空间复杂度为 $O($总模式长度$)$，完全满足题目的大数据量要求。
