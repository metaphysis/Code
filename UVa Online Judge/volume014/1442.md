## 题目分析

我们有一个一维洞穴，宽度为 $n$，每个位置 $i$ 对应一个区间 $[i, i+1)$：

- $p_i$ 表示第 $i$ 段的地面高度
- $s_i$ 表示第 $i$ 段的天花板高度

可以在洞穴中注入燃料（液体），燃料表面必须严格低于天花板（可以无限接近），并且燃料遵循重力规则：
- 在水平地面上会均匀铺开
- 会从高处流向低处  
- 符合连通器原理

目标：求可以注入的燃料的最大总横截面积。

## 解题思路

这个问题可以转化为寻找每个位置的**最大允许水面高度**，使得：
1. 水面高度不超过任何位置的天花板高度
2. 水面高度不低于地面高度
3. 满足连通性约束

**关键观察**：由于液体会找平，整个连通区域的水面高度必须相同，且不能超过该区域内最小的天花板高度。

**算法步骤**：
1. 从左到右扫描，计算每个位置考虑左边连通性时的水面高度
2. 从右到左扫描，计算每个位置考虑右边连通性时的水面高度  
3. 取两次扫描结果的较小值作为最终水面高度
4. 计算每个位置的水量并累加

## 复杂度分析
- **时间复杂度**：$O(n)$，两次线性扫描
- **空间复杂度**：$O(n)$，存储高度数组

#include <bits/stdc++.h>
using namespace std;
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int Z;
    cin >> Z;
    while (Z--) {
        int n;
        cin >> n;
        vector<int> p(n), s(n);
        for (int i = 0; i < n; ++i) cin >> p[i];
        for (int i = 0; i < n; ++i) cin >> s[i];
        vector<int> level(n);
        int cur = s[0];
        for (int i = 0; i < n; ++i) {
            if (cur > s[i]) cur = s[i];
            if (cur < p[i]) cur = p[i];
            level[i] = cur;
        }
        cur = s[n - 1];
        for (int i = n - 1; i >= 0; --i) {
            if (cur > s[i]) cur = s[i];
            if (cur < p[i]) cur = p[i];
            level[i] = min(level[i], cur);
        }
        long long area = 0;
        for (int i = 0; i < n; ++i)
            area += level[i] - p[i];
        cout << area << "\n";
    }
    return 0;
}
