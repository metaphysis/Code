## 题目描述

装饰是一个在圣诞节期间非常重要的职业。一个花环由 $n$ 个等长的片段组成，片段 $i$ 的重量为 $w_i$。花环需要固定在天花板上的 $m$ 个点，起点固定在点 $1$，终点固定在点 $m$。固定点将花环分成若干个段，每个段由若干个连续的片段组成。

悬挂花环需要满足以下规则：

1. 每个段必须包含**正偶数**个片段，且每个段可以平分成两个半段。
2. 每个半段最多包含 $d$ 个片段。
3. 需要最小化所有半段中**最重半段的重量**（半段的重量为该半段内所有片段的重量之和）。

## 输入格式

第一行包含一个正整数 $Z$（$Z \le 50$），表示测试用例的数量。

每个测试用例包含两行：
- 第一行包含三个正整数 $n, m, d$（$1 \le n \le 40000$，$2 \le m \le 10000$，$1 \le d \le 10000$）。
- 第二行包含 $n$ 个正整数 $w_1, w_2, \ldots, w_n$（$1 \le w_i \le 10000$），表示每个片段的重量。

## 输出格式

对于每个测试用例，输出一行一个整数，表示最优悬挂方式中最重半段的重量。如果无法满足条件 $(i)$ 和 $(ii)$，则输出 `"BAD"`。

## 样例

输入

```
4
4 3 10
10 10 20 20
6 4 10
1 1 100 100 1 1
6 3 10
1 1 100 100 1 1
1 2 2
333
```

输出

```
20
100
200
BAD
```

## 题目分析

本题要求将 $n$ 个片段分成 $m-1$ 个段（因为 $m$ 个固定点产生 $m-1$ 个段），每个段的长度必须为**偶数**且不超过 $2d$。每个段再平分成两个半段，每个半段的长度（即片段个数）不超过 $d$。

目标是最小化所有半段重量和的最大值。

如果直接枚举所有可能的分段方式，状态空间巨大，不可行。注意到问题的结构：
- 分段长度必须是偶数，且有一个明确的上限 $2d$。
- 目标是最小化最大值，符合**二分答案**的特征。
- 对于固定的最大半段重量 $X$，我们需要判断是否存在合法的分段方式。

因此，本题的核心思路是：
1. 二分答案 $X$，猜测最重半段的重量上限。
2. 对于给定的 $X$，判断是否存在一种分段方式，使得每个半段的重量和都 $\le X$。

## 解题思路

### 可行性判断（$\texttt{check}$ 函数）

对于固定的 $X$，我们需要判断能否将 $n$ 个片段分成恰好 $k = m-1$ 个段，使得：
- 每个段的长度是偶数且 $\le 2d$。
- 每个段的前半段和、后半段和都 $\le X$。

考虑使用动态规划：
- 状态：$\textit{dp}[i][0/1]$ 表示处理完前 $i$ 个片段后，所用的最少段数，其中 $0/1$ 表示段数的奇偶性（因为我们需要最终段数 $k$ 的奇偶性信息）。
- 初始化：$\textit{dp}[0][0] = 0$，其余为无穷大。
- 转移：枚举最后一段的长度 $2j$（$1 \le j \le d$，且 $2j \le i$），计算这段的两个半段和：
  - 前半段和：$\textit{sum}[i-j] - \textit{sum}[i-2j]$
  - 后半段和：$\textit{sum}[i] - \textit{sum}[i-j]$
  
  如果两者都 $\le X$，则状态转移：
  - $\textit{dp}[i][0] = \min(\textit{dp}[i][0], \textit{dp}[i-2j][1] + 1)$
  - $\textit{dp}[i][1] = \min(\textit{dp}[i][1], \textit{dp}[i-2j][0] + 1)$

- 最终判断：$\textit{dp}[n][k \bmod 2] \le k$ 是否成立。

**优化**：由于片段重量为正整数，后半段和随 $j$ 增加而严格递增。因此，在枚举 $j$ 时，一旦后半段和超过 $X$，就可以立即跳出循环，这大大减少了枚举量。

### 二分答案

- 下界：所有片段重量的最大值 $\max(w_i)$（因为最重的半段至少包含最重的单个片段）。
- 上界：所有片段重量之和 $\sum w_i$（最坏情况是所有片段在一个半段中）。
- 在 $[\textit{low}, \textit{high}]$ 范围内二分，找到最小的 $X$ 使得 $\texttt{check}(X)$ 为真。

### 预处理与剪枝

- 使用前缀和数组 $\textit{sum}$，可以在 $O(1)$ 时间内计算任意子段的和。
- 提前判断不可能的情况：
  - 如果 $n$ 是奇数，不可能分成若干偶数长度的段。
  - 如果 $n < 2k$，则总片段数不够每段至少 $2$ 个。
  - 如果 $n > 2kd$，则总片段数超过每段最多 $2d$ 个的容量。

## 代码实现

```cpp
// Garlands
// UVa ID: 1443
// Verdict: Accepted
// Submission Date: 2026-06-10
// UVa Run Time: 4.940s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;

int n, m, d;
int sum[40010];          // 前缀和，sum[i] = w1 + ... + wi
int dp[40010][2];        // dp[i][0/1]：前 i 个物品分成偶数/奇数段所需的最少段数

// 检查当最重半段重量不超过 X 时是否可行
bool check(int X) {
    // 初始化
    for (int i = 0; i <= n; ++i) dp[i][0] = dp[i][1] = INF;
    dp[0][0] = 0;                     // 0 个物品，0 段（偶数），段数为 0

    // i 必须是偶数，因为每段长度是偶数
    for (int i = 2; i <= n; i += 2) {
        // 枚举最后一个半段的长度 j，对应段长度为 2*j
        for (int j = 1; j <= d && 2 * j <= i; ++j) {
            int secondHalf = sum[i] - sum[i - j];            // 后半段的和
            if (secondHalf > X) break;                       // 后半段已超限，更大的 j 只会更大
            int firstHalf = sum[i - j] - sum[i - 2 * j];      // 前半段的和
            if (firstHalf > X) continue;                     // 前半段超限，尝试下一个 j

            // 状态转移：当前段是第 (前段数+1) 段，奇偶性翻转
            dp[i][0] = min(dp[i][0], dp[i - 2 * j][1] + 1);
            dp[i][1] = min(dp[i][1], dp[i - 2 * j][0] + 1);
        }
    }
    // 需要总段数 = m-1，检查其奇偶性且段数不超过 m-1
    return dp[n][(m - 1) & 1] <= m - 1;
}

int main() {
    int Z;
    scanf("%d", &Z);
    while (Z--) {
        scanf("%d %d %d", &n, &m, &d);
        sum[0] = 0;
        for (int i = 1; i <= n; ++i) {
            int w;
            scanf("%d", &w);
            sum[i] = sum[i - 1] + w;
        }

        // 可行性剪枝：总长度 n 必须为偶数，且每段至少 2 个，最多 2d 个
        if ((n & 1) || n < 2 * (m - 1) || n > 2 * (m - 1) * d) {
            printf("BAD\n");
            continue;
        }

        int left = 1, right = sum[n], ans = -1;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (check(mid)) {
                ans = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        printf("%d\n", ans);
    }
    return 0;
}
```

## 总结

本题的核心技巧包括：
1. **二分答案**：当问题要求最小化最大值时，二分答案往往是有效的思路。
2. **动态规划**：通过设计合适的状态（奇偶性），将可行性判断转化为 $\texttt{DP}$ 问题。
3. **单调性优化**：利用重量为正整数的性质，在枚举段长时一旦超限即可跳出循环，大幅降低复杂度。
4. **前缀和**：快速计算子段和，是处理区间和问题的常用工具。

**复杂度分析**：
- 预处理：$O(n)$。
- 二分答案：$O(\log(\sum w_i)) \approx 29$ 次。
- 每次 $\texttt{check}$：$O(n \cdot d)$，但通过 `break` 优化后，内层循环实际执行次数与 $X$ 有关。在最坏情况下（$X$ 很大时），每个 $i$ 可能遍历所有 $j$，但由于 $n \le 40000$，$d \le 10000$，$n \cdot d$ 最大为 $4 \times 10^8$，配合剪枝和较小的常数，在 $20$ 秒时限内可通过。
- 总复杂度：$O(n \cdot d \cdot \log(\sum w_i))$，实际运行良好。

**关键点**：
- 段长度必须为偶数，因此 $i$ 和 $j$ 的枚举都需保证偶数。
- 奇偶性状态的设计是为了匹配最终段数 $m-1$ 的奇偶性，避免额外记录段数本身。
- 剪枝条件（$n$ 为奇数、片段数不足或过多）可以提前排除不可能的情况。
