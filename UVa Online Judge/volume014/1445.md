## 题目描述

国际毕加索立体主义中心举办了一场艺术品竞赛，获奖作品将陈列在博物馆正前方。该艺术品由堆叠在地面上的立方体组成，旨在吸引游客观察从不同角度观看时艺术品形状的变化。

艺术品由边长为 $1$ 英尺的立方体组成，建在划分为 $1$ 英尺 $\times$ $1$ 英尺方格的地面上。立方体必须要么放在地面上（与网格单位方格对齐），要么放在另一个立方体上（上方立方体的底面与下方立方体的顶面完全贴合）。

每件艺术品设计提案包含：
- **正视图**：网格每列（从左到右）的立方体堆的最大高度
- **侧视图**：网格每行（从右到左看的顺序）的立方体堆的最大高度

你的任务是找出安装艺术品所需的**最少立方体数量**。

## 输入格式

输入包含多个数据集，以一行两个零结束。每个数据集格式如下：

```
w d
h₁ h₂ ... h_w
h′₁ h′₂ ... h′_d
```

其中：
- $w$ 和 $d$ 分别表示网格的列数和行数（$1 \leq w, d \leq 10$）
- 第二行包含 $w$ 个整数，表示正视图每列的最大高度（$1 \leq h_i \leq 20$）
- 第三行包含 $d$ 个整数，表示侧视图每行的最大高度（$1 \leq h′_i \leq 20$）

## 输出格式

对每个数据集，输出一行，包含所需的最少立方体数量。

## 题目分析

### 问题理解

我们需要构造一个 $w \times d$ 的网格，每个格子 $(i, j)$ 可以堆放一定高度的立方体，要求：

1. 第 $i$ 列的所有格子中，至少有一个格子的立方体堆高度等于 `front[i]`（正视图要求）
2. 第 $j$ 行的所有格子中，至少有一个格子的立方体堆高度等于 `side[j]`（侧视图要求）
3. 每个格子 $(i, j)$ 的实际高度不能超过 `min(front[i], side[j])`

目标是最小化所有格子的立方体总数。

### 关键观察

这个问题的核心在于**高度匹配**：

- 如果一个高度值同时出现在正视图和侧视图中，我们可以用**同一个立方体堆**同时满足列和行的要求
- 如果一个高度值只出现在一个视图中，我们需要单独为它建造立方体堆

### 解题思路

1. **排序处理**：将正视图和侧视图的高度数组分别按降序排序
2. **贪心匹配**：使用双指针法从高到低匹配两个数组中的高度值
   - 如果当前正视图高度等于侧视图高度，则该高度可以同时满足一列和一行，只需建造一次
   - 如果正视图高度大于侧视图高度，则先满足正视图要求
   - 如果侧视图高度大于正视图高度，则先满足侧视图要求
3. **统计总数**：将所有建造的高度值相加得到最少立方体数

### 算法正确性证明

这种贪心策略的正确性基于：
- 高度值越大，对立方体数量的贡献越大，应该优先处理
- 匹配相等的高度值可以节省立方体，因为一个堆可以同时满足两个约束
- 从高到低处理确保了我们不会错过可能的匹配机会

## 代码实现

```cpp
// Cubist Artwork
// UVa ID: 1445
// Verdict: Accepted
// Submission Date: 2025-11-29
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int w, d;
    while (cin >> w >> d && (w || d)) {
        vector<int> front(w), side(d);
        for (int i = 0; i < w; i++) cin >> front[i];
        for (int i = 0; i < d; i++) cin >> side[i];
        
        // 将正视图和侧视图按降序排序
        sort(front.begin(), front.end(), greater<int>());
        sort(side.begin(), side.end(), greater<int>());
        
        int totalCubes = 0;
        int i = 0, j = 0;
        
        // 使用双指针法匹配高度
        while (i < w && j < d) {
            if (front[i] == side[j]) {
                // 高度相等，可以同时满足列和行
                totalCubes += front[i];
                i++;
                j++;
            } else if (front[i] > side[j]) {
                // 正视图高度更大，先满足列要求
                totalCubes += front[i];
                i++;
            } else {
                // 侧视图高度更大，先满足行要求
                totalCubes += side[j];
                j++;
            }
        }
        
        // 处理剩余未匹配的高度
        while (i < w) totalCubes += front[i++];
        while (j < d) totalCubes += side[j++];
        
        cout << totalCubes << endl;
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(w \log w + d \log d)$，主要来自排序操作
- **空间复杂度**：$O(w + d)$，用于存储正视图和侧视图的高度数组

由于 $w, d \leq 10$，该算法在题目约束下非常高效。

## 总结

本题通过巧妙的贪心匹配策略，将三维立体堆叠问题转化为二维的高度匹配问题。关键在于认识到相等的正视图和侧视图高度可以共享立方体堆，从而减少总立方体数量。这种思路在解决类似的约束满足问题时具有很好的参考价值。
