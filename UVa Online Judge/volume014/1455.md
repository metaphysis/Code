## 题目描述

在一个古代王国中，有 $n$ 座城市。最初，所有城市都是孤立的。国王命令臣民修建连接城市的道路。随着时间的推移，许多道路被修建。每条道路始终沿两个城市之间的线段修建。通过道路连通性，所有城市被划分成互不相交的连通分量，每个连通分量被称为一个“州”（$\texttt{state}$）。一个州由城市和连接它们的道路组成。

历史记录按顺序给出了道路修建的时间序列。连接城市 $A$ 和 $B$ 的道路不会在除了 $A$ 和 $B$ 之外的点与其他道路相交。在修建之前， $A$ 和 $B$ 可能属于同一个州，也可能属于不同的州。修建之后， $A$ 和 $B$ 将属于同一个州，即如果需要，两个州将合并为一个州。

历史学家 $\texttt{Kim}$ 教授关心以下问题：在过去的某个时刻，一条水平线 $y=C$ （对应特定地点的纬度）穿过了多少个州？以及这些州总共有多少城市？

你需要编写一个程序来处理以下两种类型的命令：

- `road A B` ：修建连接城市 $A$ 和 $B$ 的道路。该道路不会在除了 $A$ 和 $B$ 之外的点与其他道路相交。这是一条信息性命令，程序不需要响应。
- `line C` ：这是一条查询。程序应输出直线 $y=C$ 穿过的州的数量以及这些州的总城市数。

### 输入格式

输入包含 $T$ 个测试用例。每个测试用例格式如下：

1. 第一行：整数 $n$ （ $1 \leq n \leq 100,000$ ），城市数量
2. 接下来 $n$ 行：每行两个整数 $x$ 和 $y$ （ $0 \leq x,y \leq 1,000,000$ ），表示城市坐标
3. 一行：整数 $m$ （ $1 \leq m \leq 200,000$ ），命令数量
4. 接下来 $m$ 行：每条命令为 `road A B` 或 `line C` ，其中 $0 \leq A \neq B < n$ ， $C$ （ $0 < C < 1,000,000$ ）是一个实数，其小数部分始终为 $0.5$ 。

同一对城市之间最多修建一条道路，每个测试用例至少包含一条查询。

### 输出格式

对于每个 `line C` 查询，输出一行两个整数：穿过的州的数量和这些州的总城市数。

## 题目分析

### 核心问题

我们需要动态维护一个图（随着道路的添加，连通分量不断合并），并支持查询：给定水平线 $y=C$ ，统计当前有多少个连通分量被该水平线“穿过”，以及这些分量中的节点总数。

### 关键观察

1. **穿透条件** ：一条边（道路）被水平线 $y=C$ 穿过，当且仅当它的两个端点一个在 $C$ 上方，一个在 $C$ 下方，即 $y_1 < C < y_2$ 或 $y_2 < C < y_1$ 。

2. **连通分量的穿透条件** ：一个连通分量（州）被 $y=C$ 穿过，当且仅当该分量中**存在至少一条边**被 $y=C$ 穿过。

3. **重要定理** ：对于一个连通图，如果它包含至少一个 $y>C$ 的顶点和至少一个 $y<C$ 的顶点，那么 $y=C$ **必然**会穿过该图（因为存在一条路径连接上下顶点，而路径上必然有一条边穿过 $y=C$ ）。

4. **推论** ：一个连通分量被 $y=C$ 穿过 **当且仅当** 该分量的最小 $y$ 坐标小于 $C$ **且** 最大 $y$ 坐标大于 $C$ 。即： $\min Y < C < \max Y$ 。

### 证明

设连通分量 $G$ 中：
- 存在顶点 $u$ 满足 $y_u > C$
- 存在顶点 $v$ 满足 $y_v < C$
- $G$ 是连通的

由于 $G$ 连通，存在从 $u$ 到 $v$ 的路径。沿着该路径， $y$ 坐标从大于 $C$ 连续变化到小于 $C$ 。根据介值定理，路径上必然存在一点 $P$ 满足 $y_P = C$ 。由于 $C$ 总是 $X.5$ 形式（小数部分 $0.5$ ），而所有城市坐标都是整数，因此 $P$ 不可能是任何城市顶点，只能是某条边上的点。故该边被 $y=C$ 穿过。

### 算法设计

基于上述推论，我们只需要为每个连通分量维护：
- 最小 $y$ 坐标 $\min Y$
- 最大 $y$ 坐标 $\max Y$
- 分量中的城市数量 $\text{size}$

当查询 $y=C$ 时，统计所有满足 $\min Y < C < \max Y$ 的分量即可。

### 数据结构

1. **并查集 ($\texttt{Union-Find}$)** ：维护连通分量，支持高效合并。
2. **每个分量的附加信息** ：
   - $\text{minY}[i]$ ：以 $i$ 为根的分量的最小 $y$ 坐标
   - $\text{maxY}[i]$ ：以 $i$ 为根的分量的最大 $y$ 坐标
   - $\text{size}[i]$ ：以 $i$ 为根的分量的城市数量
3. **全局状态维护** ：我们需要快速查询有多少个分量满足 $\min Y < C < \max Y$ 。由于 $C$ 的范围很大（ $0$ 到 $1,000,000$ ，步长 $0.5$ ，共 $2,000,001$ 个可能值），直接维护每个 $C$ 的答案是不现实的。

### 高效查询方案

我们注意到，每个分量对 $C$ 的贡献是一个**连续区间**：所有满足 $\min Y < C < \max Y$ 的 $C$ 。由于 $C$ 是 $X.5$ 形式，我们可以将 $y$ 坐标乘以 $2$ 转换为整数：
- 城市坐标： $y \rightarrow 2y$
- 水平线 $C = X.5 \rightarrow 2C = 2X+1$ （奇数）

此时，分量对 $C$ 的贡献区间为： $[2\times\min Y + 1,\ 2\times\max Y - 1]$ 中的所有奇数。

我们可以使用**差分数组**技巧：
- 当创建一个新分量（或分量更新）时，在区间 $[L,R]$ 内的所有奇数位置加上该分量的贡献
- 当两个分量合并时，先移除旧分量的贡献，再添加新分量的贡献
- 查询时，通过前缀和即可得到当前 $C$ 的总贡献

### 算法步骤

1. **初始化** ：
   - 每个城市是一个独立分量
   - 单点城市（只有一个城市的分量）不会产生穿透，所以初始时不更新差分数组

2. **处理 `road A B` 命令** ：
   - 查找 $A$ 和 $B$ 所在分量的根
   - 如果已在同一分量，跳过
   - 否则：
     a. 从差分数组中移除两个旧分量的贡献
     b. 合并两个分量（更新 $\min Y$ 、 $\max Y$ 、 $\text{size}$ ）
     c. 向差分数组添加新分量的贡献

3. **处理 `line C` 查询** ：
   - 将 $C$ 转换为整数形式： $C_{\text{int}} = 2\times\lfloor C\rfloor + 1$
   - 计算前缀和得到当前 $C$ 对应的州数量和城市总数
   - 输出结果

### 复杂度分析

- **并查集操作** ： $O(\alpha(n))$ ，近乎常数时间
- **差分更新** ：每次合并需要更新差分数组，但每个分量最多被合并 $O(\log n)$ 次（按大小合并），总更新次数 $O(n \log n)$
- **查询操作** ： $O(1)$ 前缀和查询
- **总复杂度** ： $O((n+m)\alpha(n) + n \log n)$ ，可以处理 $n \leq 100,000$ ， $m \leq 200,000$ 的数据规模

### 注意事项

1. **浮点数处理** ： $C$ 的小数部分总是 $0.5$ ，直接读取字符串并解析整数部分可以避免浮点误差。
2. **区间边界** ：注意 $\min Y < C < \max Y$ 是严格不等式，且 $C$ 不可能是整数。
3. **内存优化** ：差分数组大小为 $2\times 10^6 + 10$ ，使用 `long long` 类型避免溢出。

## 代码实现

```cpp
// Kingdom
// UVa ID: 1455
// Verdict: Accepted
// Submission Date: 2025-12-30
// UVa Run Time: 0.270s

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;
const int MAXY = 2000010; // 2 * 1,000,000 + 10

struct Point {
    int x, y;
    Point() {}
    Point(int x, int y) : x(x), y(y) {}
};

Point cities[MAXN];
int parent[MAXN];
int stateSize[MAXN];
int minY[MAXN];
int maxY[MAXN];

// 差分数组，用于快速区间更新和单点查询
long long diffState[MAXY];  // 州数量的差分
long long diffCity[MAXY];   // 城市总数的差分

// 并查集查找（路径压缩）
int findSet(int x) {
    if (parent[x] != x) parent[x] = findSet(parent[x]);
    return parent[x];
}

// 更新差分数组：在区间[l, r]内的所有奇数位置加上delta
// l和r是转换后的坐标（乘以2后的值）
void updateRange(int l, int r, int size, int delta) {
    if (l > r) return;
    
    // 确保l和r是奇数（因为C对应的都是奇数）
    if (l % 2 == 0) l++;
    if (r % 2 == 0) r--;
    if (l > r) return;
    
    // 差分更新
    diffState[l] += delta;
    if (r + 2 < MAXY) diffState[r + 2] -= delta;
    
    diffCity[l] += delta * size;
    if (r + 2 < MAXY) diffCity[r + 2] -= delta * size;
}

// 合并两个连通分量
void unionSet(int a, int b) {
    int ra = findSet(a);
    int rb = findSet(b);
    if (ra == rb) return;
    
    // 先移除两个旧分量的贡献
    updateRange(minY[ra] * 2 + 1, maxY[ra] * 2 - 1, stateSize[ra], -1);
    updateRange(minY[rb] * 2 + 1, maxY[rb] * 2 - 1, stateSize[rb], -1);
    
    // 按大小合并，小树合并到大树
    if (stateSize[ra] < stateSize[rb]) swap(ra, rb);
    
    // 执行合并
    parent[rb] = ra;
    stateSize[ra] += stateSize[rb];
    minY[ra] = min(minY[ra], minY[rb]);
    maxY[ra] = max(maxY[ra], maxY[rb]);
    
    // 添加新分量的贡献
    updateRange(minY[ra] * 2 + 1, maxY[ra] * 2 - 1, stateSize[ra], 1);
}

int main() {
    int T;
    scanf("%d", &T);
    
    while (T--) {
        int n;
        scanf("%d", &n);
        
        // 初始化差分数组
        memset(diffState, 0, sizeof(diffState));
        memset(diffCity, 0, sizeof(diffCity));
        
        for (int i = 0; i < n; i++) {
            scanf("%d %d", &cities[i].x, &cities[i].y);
            parent[i] = i;
            stateSize[i] = 1;
            minY[i] = cities[i].y;
            maxY[i] = cities[i].y;
            
            // 单点城市（只有一个城市的分量）不会产生穿透
            // 所以不需要更新差分数组
        }
        
        int m;
        scanf("%d", &m);
        
        while (m--) {
            char cmd[10];
            scanf("%s", cmd);
            
            if (cmd[0] == 'r') {
                // road 命令：修建道路
                int a, b;
                scanf("%d %d", &a, &b);
                unionSet(a, b);
            } 
            else {
                // line 命令：查询
                char cStr[20];
                scanf("%s", cStr);
                
                // 解析 C = X.5 为整数形式 2X+1
                int integerPart = 0;
                for (int i = 0; cStr[i] && cStr[i] != '.'; i++) {
                    integerPart = integerPart * 10 + (cStr[i] - '0');
                }
                int C = integerPart * 2 + 1;  // 2*X + 1
                
                // 计算前缀和得到当前C的答案
                // 注意：我们只需要累加到C位置（包括C）
                long long stateCount = 0;
                long long cityCount = 0;
                
                // 累加所有奇数位置的前缀和
                for (int i = 1; i <= C; i += 2) {
                    stateCount += diffState[i];
                    cityCount += diffCity[i];
                }
                
                printf("%lld %lld\n", stateCount, cityCount);
            }
        }
    }
    
    return 0;
}
```

## 总结

本题的关键在于发现**连通分量被水平线穿过的充要条件**： $\min Y < C < \max Y$ 。基于这一观察，我们可以将问题简化为维护每个分量的最小/最大 $y$ 坐标，并使用差分数组技巧高效处理区间更新和单点查询。

算法结合了并查集（维护连通性）和差分数组（维护穿透状态），在 $O((n+m)\alpha(n) + n \log n)$ 的时间复杂度内解决了问题，能够高效处理大规模数据。

注意在实际实现中，需要小心处理浮点数精度问题（通过读取字符串避免）和边界条件（严格不等式的处理）。
