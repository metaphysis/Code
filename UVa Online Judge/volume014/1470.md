## 题目描述

施放咒语是现实生活中最难理解的技术之一。实际上，人们很难区分真正的咒语（如 `"abrahelhelhelleh"`，在战斗中使用并在魔法大学中教授）和尖叫声（如 `"rachelhellabracadabra"`，未受过教育的女巫用来对猫喊叫）。

无声大学的研究表明，一个词语的力量（无论是真正的咒语还是尖叫声）与法师倒念词语的能力有关。具体来说，词语的力量是形如 $ww^R ww^R$ 的最大子串长度，其中 $w$ 是任意字符序列，$w^R$ 是 $w$ 的逆序。如果不存在这样的子串，则词语的力量为 $0$。

例如：
- `abrahellehhelleh` 的力量是 $12$，因为它包含 `hellehhelleh`
- `rachelhellabracadabra` 的力量是 $0$

注意：词语的力量总是 $4$ 的倍数。

## 输入格式

输入包含多个测试用例。第一行是一个正整数 $Z \leq 40$，表示测试用例的数量。然后是 $Z$ 个测试用例，每个测试用例的格式如下：

输入是一行，包含一个长度最多为 $3 \times 10^5$ 的单词，由英文字母（大写或小写）组成。

## 输出格式

对于每个测试用例，输出一个整数 $k$，表示词语的力量。

## 题目分析

### 问题理解

我们需要在给定的字符串中找到最长的子串，该子串具有 $ww^R ww^R$ 的结构，其中：
- $w$ 是任意非空字符串
- $w^R$ 是 $w$ 的逆序
- 整个子串长度为 $4 \times |w|$

这种结构可以理解为两个相同的偶长度回文串的拼接。

### 关键观察

1. **结构特性**：$ww^R$ 本身就是一个偶长度回文串，因此 $ww^R ww^R$ 就是两个相同的偶长度回文串的连续出现。

2. **对称性质**：如果存在位置 $i$ 和 $i - k$（其中 $k = |w|$），使得：
   - 以 $i$ 为中心的偶回文长度至少为 $2k$
   - 以 $i - k$ 为中心的偶回文长度至少为 $2k$
   
   那么这两个回文串自动构成 $ww^R ww^R$ 结构，且两个部分相同。

3. **长度约束**：由于总长度必须是 $4$ 的倍数，我们只需要检查长度为 $4, 8, 12, \ldots$ 的可能情况。

### 解题思路

1. **预处理**：使用 $\texttt{Manacher}$ 算法计算字符串中所有位置的偶回文半径。

2. **搜索策略**：
   - 对于每个位置 $i$，将其偶回文半径转换为实际长度（乘以 $2$）
   - 如果当前长度大于等于已知最大力量加 $4$，则检查是否能形成更大的 $ww^R ww^R$ 结构
   - 从当前最优解 $+4$ 开始，以 $4$ 为步长递增检查

3. **验证条件**：对于候选长度 $\textit{current}$，检查位置 $i - \textit{current}/4$ 的偶回文长度是否至少为 $\textit{current}/2$。如果满足，则更新最大力量。

## 算法复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 是字符串长度。$\texttt{Manacher}$ 算法的时间复杂度为 $O(n)$，主循环也是 $O(n)$。
- **空间复杂度**：$O(n)$，用于存储 $\texttt{Manacher}$ 算法的结果。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> manacher(const string &s) {
    int n = s.length();
    vector<int> d2(n, 0);
    for (int i = 0, l = 0, r = -1; i < n; i++) {
        int k = (i > r) ? 0 : min(d2[l + r - i + 1], r - i + 1);
        while (0 <= i - k - 1 && i + k < n && s[i - k - 1] == s[i + k]) k++;
        d2[i] = k--;
        if (i + k > r) {
            l = i - k - 1;
            r = i + k;
        }
    }
    return d2;
}

int solve(const string &s) {
    int n = s.length();
    if (n < 4) return 0;
    vector<int> d2 = manacher(s);
    int maxPower = 0;
    for (int i = 0; i < n; i++) {
        d2[i] *= 2;
        if (d2[i] >= maxPower + 4) {
            int current = maxPower + 4;
            while (current <= d2[i]) {
                int secondCenter = i - current / 4;
                if (secondCenter >= 0 && d2[secondCenter] >= current / 2) maxPower = current;
                current += 4;
            }
        }
    }
    return maxPower;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int z;
    cin >> z;
    while (z--) {
        string word;
        cin >> word;
        cout << solve(word) << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于理解 $ww^R ww^R$ 结构的数学性质，并利用 $\texttt{Manacher}$ 算法高效地检测这种结构。通过巧妙的几何位置验证，避免了显式的字符串比较，实现了线性时间复杂度的解决方案。

这种方法的精妙之处在于利用了回文串的对称性质，将复杂的字符串匹配问题转化为简单的数值比较问题，展现了算法设计的美感。
