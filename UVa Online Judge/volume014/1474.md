[UVa 1474 Evacuation Plan](https://blog.csdn.net/metaphysis/article/details/161323656)

## 题目描述

$\texttt{Flatland}$ 政府正在修建一条新高速公路，公路上有 $n$ 个施工队，附近有 $m$ 个避难所。每个施工队必须分配到一个避难所，且每个避难所至少被分配一个施工队。施工队 $i$ 到避难所 $j$ 的燃料消耗等于两者位置差的绝对值 $|x_i - y_j|$。需要找到总燃料最小的分配方案，并输出每个施工队分配的避难所编号（按输入顺序编号 $1$ 至 $m$）。

**输入约束**：$1 \leq m \leq n \leq 4000$，所有位置为正整数且互不相同。

**输入格式**（多组测试数据）：
- 第一行：$n$
- 第二行：$n$ 个整数，表示施工队的位置
- 第三行：$m$
- 第四行：$m$ 个整数，表示避难所的位置

**输出格式**：
- 第一行：最小总燃料
- 第二行：$n$ 个整数，表示每个施工队分配的避难所编号

## 题目分析

### 1. 排序与连续性性质

将施工队和避难所分别按坐标从小到大排序后，**最优解中每个避难所对应一段连续的施工队**。这是因为如果存在交叉分配，交换分配方案不会使总距离增加（交换论证法）。

因此，问题转化为：将排序后的 $n$ 个施工队分成 $m$ 个连续的非空段，第 $j$ 段分配给排序后的第 $j$ 个避难所，最小化各段内施工队到对应避难所的距离之和。

### 2. 距离的快速计算

对于排序后的施工队位置 $x[0..n-1]$ 和避难所位置 $y[0..m-1]$，区间 $[l, r]$ 内施工队到避难所 $y_j$ 的距离和为：

$$
cost(l, r, j) = \sum_{t=l}^{r} |x_t - y_j|
$$

由于 $x$ 已排序，可以 $O(1)$ 计算：找到第一个大于 $y_j$ 的位置 $p$，则：

- 左边部分 $[l, p-1]$ 全部 $\le y_j$，距离和为 $y_j \cdot (p-l) - (\text{pre}[p-1] - pre[l-1])$
- 右边部分 $[p, r]$ 全部 $> y_j$，距离和为 $(pre[r] - pre[p-1]) - y_j \cdot (r-p+1)$

其中 $pre[i] = \sum_{t=0}^{i} x_t$ 为前缀和。

## 解法一：前缀 $\texttt{DP}$ + 分治优化

### 状态定义

设 $dp[i][j]$ 表示将排序后的前 $i$ 个施工队（从 $1$ 开始编号）分配到排序后的前 $j$ 个避难所的最小总距离，且每个避难所至少有一个施工队。

边界条件：$dp[0][0] = 0$，$dp[i][0] = \infty$（$i > 0$）。

### 转移方程

考虑第 $j$ 个避难所负责的施工队区间为 $[k+1, i]$，则：

$$
dp[i][j] = \min_{j-1 \leq k < i} \left\{ dp[k][j-1] + cost(k+1, i, j) \right\}
$$

其中 $k$ 至少为 $j-1$ 是因为前 $j-1$ 个避难所至少需要 $j-1$ 个施工队。

### 决策单调性与分治优化

对于固定的 $j$，定义 $K[i] = \min_{k} \{ dp[k][j-1] + cost(k+1, i, j) \}$。可以证明 $K[i]$ 关于 $i$ 单调不降，这一性质称为决策单调性。

分治优化利用决策单调性，将计算过程递归进行：

- 函数 `divide(l, r, optL, optR)` 表示计算 $dp[l..r][j]$ 的值，且已知这些状态的最优决策点均在 $[\texttt{optL}, \texttt{optR}]$ 范围内。
- 取中点 $\texttt{mid} = (l+r)/2$，枚举 $k$ 从 $\texttt{optL}$ 到 $\min(\texttt{optR}, \texttt{mid}-1)$，找到 $\texttt{mid}$ 的最优决策点 $\texttt{bestK}$。
- 递归处理左半区间 $[l, \texttt{mid}-1]$，决策点范围为 $[\texttt{optL}, \texttt{bestK}]$；递归处理右半区间 $[\texttt{mid}+1, r]$，决策点范围为 $[\texttt{bestK}, \texttt{optR}]$。

### 预处理加速

为了 $O(1)$ 计算 $cost(k+1, i, j)$，需要快速获得区间 $[k+1, i]$ 中第一个大于 $y_j$ 的位置。预处理 $\texttt{ptr}[j][i]$ 表示对于避难所 $j$，前 $i$ 个施工队中最后一个位置 $\le y_j$ 的下标。则区间 $[l, r]$ 中第一个大于 $y_j$ 的位置为 $\max(l, \texttt{ptr}[j][r] + 1)$。

### 复杂度分析

- 排序：$O(n \log n + m \log m)$
- $\texttt{ptr}$ 预处理：$O(mn)$
- $\texttt{DP}$：每层分治 $O(n \log n)$，共 $m$ 层，总 $O(m n \log n)$
- 总复杂度：$O(m n \log n)$，在 $n, m \leq 4000$ 时约 $1.92 \times 10^8$ 次操作，可以通过。

### 代码实现（解法一）

```cpp
// Evacuation Plan
// UVa ID: 1474
// Verdict: Accepted
// Submission Date: 2026-05-22
// UVa Run Time: 4.930s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int MAXN = 4005;
const ll INF = 1e18;

int n, m;
pair<int, int> team[MAXN];          // (位置, 原始下标)
pair<int, int> shelterWithId[MAXN]; // (位置, 原始编号)
int shelterPos[MAXN];               // 排序后的避难所位置
int shelterOriginalId[MAXN];        // 排序后的避难所对应的原始编号
ll dpPrev[MAXN], dpCur[MAXN];
int choice[MAXN][MAXN];
ll pre[MAXN];
int ptr[MAXN][MAXN]; // ptr[j][i] = 对于避难所 j，前 i 个队伍中最后一个 <= shelterPos[j] 的位置

// 计算 cost(l, r, j) = [l, r] 的队伍到 shelterPos[j] 的距离和
inline ll cost(int l, int r, int j) {
    int s = shelterPos[j];
    int p = ptr[j][r];
    if (p < l) {
        return (pre[r] - pre[l-1]) - (ll)s * (r - l + 1);
    }
    if (p >= r) {
        return (ll)s * (r - l + 1) - (pre[r] - pre[l-1]);
    }
    ll left = (ll)s * (p - l + 1) - (pre[p] - pre[l-1]);
    ll right = (pre[r] - pre[p]) - (ll)s * (r - p);
    return left + right;
}

// 分治优化
void divide(int j, int l, int r, int optL, int optR) {
    if (l > r) return;
    int mid = (l + r) >> 1;
    int bestK = -1;
    ll bestVal = INF;
    for (int k = max(optL, j - 1); k <= min(optR, mid - 1); ++k) {
        ll val = dpPrev[k] + cost(k + 1, mid, j);
        if (val < bestVal) {
            bestVal = val;
            bestK = k;
        }
    }
    dpCur[mid] = bestVal;
    choice[j][mid] = bestK;
    divide(j, l, mid - 1, optL, bestK);
    divide(j, mid + 1, r, bestK, optR);
}

void solve() {
    // 读入队伍
    for (int i = 1; i <= n; ++i) {
        cin >> team[i].first;
        team[i].second = i;
    }
    
    // 读入避难所，记录原始编号
    cin >> m;
    for (int i = 1; i <= m; ++i) {
        cin >> shelterWithId[i].first;
        shelterWithId[i].second = i; // 原始编号从 1 开始
    }
    
    // 排序
    sort(team + 1, team + n + 1);
    sort(shelterWithId + 1, shelterWithId + m + 1);
    
    // 提取排序后的避难所位置和原始编号
    for (int j = 1; j <= m; ++j) {
        shelterPos[j] = shelterWithId[j].first;
        shelterOriginalId[j] = shelterWithId[j].second;
    }
    
    // 前缀和
    pre[0] = 0;
    for (int i = 1; i <= n; ++i) pre[i] = pre[i - 1] + team[i].first;
    
    // 预处理 ptr[j][i]
    for (int j = 1; j <= m; ++j) {
        int p = 0;
        for (int i = 1; i <= n; ++i) {
            if (team[i].first <= shelterPos[j]) p = i;
            ptr[j][i] = p;
        }
    }
    
    // 初始化
    for (int i = 0; i <= n; ++i) dpPrev[i] = INF;
    dpPrev[0] = 0;
    
    // DP 主循环
    for (int j = 1; j <= m; ++j) {
        divide(j, j, n, j - 1, n);
        swap(dpPrev, dpCur);
    }
    
    // 输出总燃料
    cout << dpPrev[n] << "\n";
    
    // 回溯分配：assignByOriginalTeam[原始队伍下标] = 避难所原始编号
    vector<int> assignByOriginalTeam(n + 1);
    int cur = n;
    for (int j = m; j >= 1; --j) {
        int prev = choice[j][cur];
        // 当前避难所（排序后下标 j）分配给队伍区间 [prev+1, cur]
        int originalShelterId = shelterOriginalId[j];
        for (int i = prev + 1; i <= cur; ++i) {
            int originalTeamId = team[i].second;
            assignByOriginalTeam[originalTeamId] = originalShelterId;
        }
        cur = prev;
    }
    
    // 按原始队伍顺序输出
    for (int i = 1; i <= n; ++i) {
        cout << assignByOriginalTeam[i] << (i == n ? "\n" : " ");
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    while (cin >> n) solve();
    return 0;
}
```

## 解法二：后缀 $\texttt{DP}$ + 贪心构造

### 逆向思维

定义 $suf[i][j]$ 表示从第 $i$ 个施工队到末尾、第 $j$ 个避难所到末尾的最小总距离（其中施工队和避难所均已排序，下标从 $0$ 开始）。这样定义的好处是：处理到末尾时自然满足“每个避难所至少一队”的约束。

### 转移方程

边界条件：
- $suf[n-1][m-1] = |x_{n-1} - y_{m-1}|$
- $suf[i][m-1] = suf[i+1][m-1] + |x_i - y_{m-1}|$（只剩最后一个避难所）

对于一般情况，考虑第 $i$ 个施工队分配给第 $j$ 个避难所，设 $cost = |x_i - y_j|$：

- 若下一个施工队分配给下一个避难所：$cost + suf[i+1][j+1]$
- 若当前避难所可以容纳多个施工队（即 $n-i > m-j$）：$cost + suf[i+1][j]$

取最小值：

$$
suf[i][j] = \min(cost + suf[i+1][j+1],\ cost + suf[i+1][j]) \quad \text{当 } n-i > m-j
$$

$$
suf[i][j] = cost + suf[i+1][j+1] \quad \text{当 } n-i = m-j
$$

### 贪心构造

计算出 $suf$ 表后，从前向后构造分配方案：

- 维护当前施工队下标 $i$ 和当前避难所下标 $j$（均从 $0$ 开始）
- 当前施工队分配给第 $j$ 个避难所（注意输出时需转换为原始编号）
- 决定下一个施工队是否切换到下一个避难所：
  - 如果 $j+1 < m$ 且 $n-i > m-j$ 且 $suf[i+1][j] > suf[i+1][j+1]$，则下一个施工队应切换到下一个避难所（$j \gets j+1$）
  - 否则，如果 $n-i = m-j$（即剩余施工队数等于剩余避难所数），则必须切换到下一个避难所（$j \gets j+1$）

### 复杂度分析

- 排序：$O(n \log n + m \log m)$
- $\texttt{DP}$：$O(mn)$
- 构造：$O(n)$
- 总复杂度：$O(mn)$，优于解法一。

### 代码实现（解法二）

```cpp
// Evacuation Plan
// UVa ID: 1474
// Verdict: Accepted
// Submission Date: 2026-05-22
// UVa Run Time: 0.660s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int MAXN = 4005;
const ll INF = 1e18;

int n, m;
pair<int, int> team[MAXN];
pair<int, int> shelter[MAXN];
ll suf[MAXN][MAXN];
int teamPos[MAXN], shelterPos[MAXN], shelterId[MAXN];

void solve() {
    for (int i = 0; i < n; ++i) cin >> team[i].first, team[i].second = i;
    cin >> m;
    for (int i = 0; i < m; ++i) cin >> shelter[i].first, shelter[i].second = i;
    sort(team, team + n);
    sort(shelter, shelter + m);
    for (int i = 0; i < n; ++i) teamPos[i] = team[i].first;
    for (int i = 0; i < m; ++i) shelterPos[i] = shelter[i].first, shelterId[i] = shelter[i].second;
    // 后缀DP
    suf[n - 1][m - 1] = abs(teamPos[n - 1] - shelterPos[m - 1]);
    for (int i = n - 2; i >= 0; --i) suf[i][m - 1] = suf[i + 1][m - 1] + abs(teamPos[i] - shelterPos[m - 1]);
    for (int i = n - 2; i >= 0; --i)
        for (int j = m - 2; j >= 0; --j) {
            ll cost = abs(teamPos[i] - shelterPos[j]);
            suf[i][j] = cost + suf[i + 1][j + 1];
            if (n - i > m - j) suf[i][j] = min(suf[i][j], cost + suf[i + 1][j]);
        }
    cout << suf[0][0] << '\n';
    // 贪心构造
    vector<int> ans(n);
    for (int i = 0, j = 0; i < n; ++i) {
        ans[team[i].second] = shelterId[j] + 1;
        if (j + 1 < m && n - i > m - j && suf[i + 1][j] > suf[i + 1][j + 1]) j++;
        else if (n - i == m - j) j++;
    }
    for (int i = 0; i < n; ++i) cout << ans[i] << " \n"[i == n - 1];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    while (cin >> n) solve();
    return 0;
}
```

## 两种解法对比

| 对比项 | 解法一（前缀 $\texttt{DP}$ + 分治优化） | 解法二（后缀 $\texttt{DP}$ + 贪心构造） |
|--------|------------------------------|------------------------------|
| $\texttt{DP}$ 方向 | 从前向后 | 从后向前 |
| 状态定义 | $dp[i][j]$ 表示前缀 | $suf[i][j]$ 表示后缀 |
| 转移方式 | 枚举分界点 $k$，取最小值 | 比较两种决策，取最小值 |
| 优化方法 | 分治优化（决策单调性） | 无需额外优化 |
| 构造方式 | 回溯 $\texttt{DP}$ 表 | 贪心扫描 |
| 时间复杂度 | $O(m n \log n)$ | $O(m n)$ |
| 代码复杂度 | 较高 | 较低 |

## 注意事项

1. **编号映射**：排序后避难所的编号会改变，需要在输入时记录原始编号，并在输出时还原。
2. **多组数据**：使用 `while (cin >> n)` 循环处理。
3. **下标约定**：解法一使用从 $1$ 开始编号方便处理边界，解法二使用从 $0$ 开始编号简化数组访问。
4. **数据类型**：使用 `long long}` 存储总距离，防止溢出。
