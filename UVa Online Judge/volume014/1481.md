## 题目描述

给定两条染色体，每条染色体都是一个 $1$ 到 $n$ 的排列。定义 **正证据** 为一对长度相同且均大于 $1$ 的连续子序列，其中第一条染色体的子序列是第二条染色体对应子序列的一个排列。统计这样的正证据的数量。

## 问题分析

### 核心条件解读
本题的关键在于理解“正证据”的定义：

1. **连续子序列**：不是子序列，而是子数组（连续的一段）。
2. **长度大于 $1$**：单个基因不算。
3. **互为排列**：由于每条染色体中 $1 \sim n$ 每个数字只出现一次，因此“互为排列”等价于 **两个子序列包含的元素集合完全相同**。
4. **两条子序列长度相等**：既然集合相同且无重复元素，长度自然相等。

因此，问题转化为：

> 统计四元组 $(i, j, k, l)$ 的数量，满足：
> - $j - i + 1 = l - k + 1 = len \geq 2$
> - $\{a[i], a[i+1], ..., a[j]\} = \{b[k], b[k+1], ..., b[l]\}$

其中 $a$ 和 $b$ 是长度为 $n$ 的排列。

## 朴素思路与复杂度分析

最直接的方法是枚举所有子数组对，检查集合相等性。

- 枚举 $a$ 的所有子数组：$O(n^2)$
- 枚举 $b$ 的所有子数组：$O(n^2)$
- 检查集合相等：$O(n)$（排序或哈希）

总复杂度 $O(n^5)$，完全不可行。

若固定长度 $len$，滑动窗口检查，则 $a$ 有 $n-length+1$ 个窗口，$b$ 有 $n-length+1$ 个窗口，对每个长度进行窗口对比较，复杂度为 $O(n^3)$。$n=3000$ 时仍不可接受。

## 关键洞察

由于两个序列都是排列，每个数字只出现一次，因此：

- 对于 $a$ 中任意一个连续子数组，其元素集合唯一确定。
- 该集合在 $b$ 中出现的 **位置集合** 也是唯一确定的。
- 这个位置集合在 $b$ 中能够构成一个连续子数组的 **充要条件** 是：这些位置的最小值与最大值之差 $+1$ 等于子数组长度。

**重要结论**：
> 对于 $a$ 中从 $i$ 到 $j$ 的连续子数组，若它在 $b$ 中对应的位置最小值为 $minPos$，最大值为 $maxPos$，则 $b$ 中存在一个连续子数组恰好包含这些元素的 **充分必要条件** 是：
> $$maxPos - minPos + 1 = j - i + 1$$
>
> 此时，这个 $b$ 的子数组就是 $b[minPos .. maxPos]$，并且它与 $a[i .. j]$ 互为排列，构成一个正证据。

这个条件 **唯一确定** 了 $b$ 中的匹配子数组，不需要额外枚举。

## 算法设计

基于上述结论，我们可以设计一个 $O(n^2)$ 的算法：

1. **预处理**：建立从基因值到其在 $b$ 中位置的映射 $posB$。
2. **枚举 $a$ 的左端点** $i$：
   - 初始化 $minPos = n$，$maxPos = -1$。
   - 枚举 $a$ 的右端点 $j$ 从 $i$ 到 $n-1$：
     - 获取当前元素 $a[j]$ 在 $b$ 中的位置 $p = posB[a[j]]$。
     - 更新 $minPos = \min(minPos, p)$，$maxPos = \max(maxPos, p)$。
     - 当前子数组长度 $length = j - i + 1$。
     - 若 $length > 1$ 且 $maxPos - minPos + 1 == length$，则计数器加 $1$。

### 正确性证明

**必要性**：
若 $a[i..j]$ 与 $b$ 的某个连续子数组互为排列，则该 $b$ 子数组必然包含 $a[i..j]$ 中所有元素对应的位置，且不能包含其他元素（否则元素集合不同）。因此这个 $b$ 子数组的左端点 ≤ 这些位置的最小值，右端点 ≥ 这些位置的最大值。同时，由于长度必须等于 $j-i+1$，因此该子数组只能是 $b[minPos .. maxPos]$。

**充分性**：
若 $maxPos - minPos + 1 = j - i + 1$，则 $b[minPos .. maxPos]$ 的长度正好等于 $a[i..j]$ 的长度，并且它包含了 $a[i..j]$ 的所有元素（因为 $minPos$ 和 $maxPos$ 覆盖了这些元素的位置），由鸽巢原理，它不可能包含其他元素。因此这两个子数组互为排列。

## 复杂度分析

- **时间复杂度**：$O(n^2)$。外层循环 $n$ 次，内层循环平均 $n/2$ 次，每次操作 $O(1)$。
- **空间复杂度**：$O(n)$。存储两个排列和位置映射数组。

对于 $n \leq 3000$，最坏情况下约 $4.5 \times 10^6$ 次迭代，完全可行。

## 示例验证

以样例输入第一个测试用例为例：

$a = [3, 2, 1, 4]$
$b = [1, 2, 4, 3]$
$posB = [\_, 0, 1, 3, 2]$（下标从 $0$ 开始）

- $i=0$：
  - $j=1$：集合 $\{3,2\}$，位置 $\{3,1\}$，$min=1,max=3,length=2$，$3-1+1=3\neq2$ ❌
  - $j=2$：集合 $\{3,2,1\}$，位置 $\{3,1,0\}$，$min=0,max=3,length=3$，$3-0+1=4\neq3$ ❌
  - $j=3$：集合 $\{3,2,1,4\}$，位置 $\{3,1,0,2\}$，$min=0,max=3,length=4$，$3-0+1=4=4$ ✅
- $i=1$：
  - $j=2$：集合 $\{2,1\}$，位置 $\{1,0\}$，$min=0,max=1,length=2$，$1-0+1=2=2$ ✅
  - $j=3$：集合 $\{2,1,4\}$，位置 $\{1,0,2\}$，$min=0,max=2,length=3$，$2-0+1=3=3$ ✅
- $i=2$：
  - $j=3$：集合 $\{1,4\}$，位置 $\{0,2\}$，$min=0,max=2,length=2$，$2-0+1=3\neq2$ ❌

总计 $3$ 个正证据，与样例输出一致。

## 代码实现

```cpp
// Genome Evolution
// UVa ID: 1481
// Verdict: Accepted
// Submission Date: 2026-02-13
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n;
    while (cin >> n && n != 0) {
        vector<int> a(n), b(n);
        for (int i = 0; i < n; ++i) cin >> a[i];
        for (int i = 0; i < n; ++i) cin >> b[i];
        // 记录 b 中每个值的位置
        vector<int> posB(n + 1);
        for (int i = 0; i < n; ++i) posB[b[i]] = i;
        int r = 0;
        for (int i = 0; i < n; ++i) {
            int minPos = n, maxPos = -1;
            for (int j = i; j < n; ++j) {
                int p = posB[a[j]];
                if (p < minPos) minPos = p;
                if (p > maxPos) maxPos = p;
                int length = j - i + 1;
                if (length > 1 && maxPos - minPos + 1 == length) ++r;
            }
        }
        cout << r << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于将“互为排列”这一集合相等条件，转化为 **位置区间长度与子数组长度相等** 这一易于验证的条件。利用排列的无重复性，我们将两个序列的匹配问题简化为对单个序列的滑动窗口扫描，将复杂度从 $O(n^3)$ 优化到 $O(n^2)$，从而在 $n=3000$ 的规模下顺利通过。

这种 **从元素值映射到位置索引** 的思想在处理排列相关问题时非常常见，值得举一反三。
