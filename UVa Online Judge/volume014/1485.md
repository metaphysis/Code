[UVa 1485 Permutation Counting](https://blog.csdn.net/metaphysis/article/details/153418333)

## 题目分析

### 问题描述

给定一个长度为 $N$ 的排列 $a_1, a_2, \ldots, a_N$（即 $\{1, 2, \ldots, N\}$ 的一个排列），定义其 **$\texttt{E-value}$** 为满足 $a_i > i$ 的位置数量。例如：

- 排列 $\{1, 3, 2, 4\}$ 的 $\texttt{E-value}$ 为 $1$（只有位置 $2$ 满足 $a_2 = 3 > 2$）
- 排列 $\{4, 3, 2, 1\}$ 的 $\texttt{E-value}$ 为 $2$（位置 $1$ 和 $2$ 满足条件）

要求计算有多少个长度为 $N$ 的排列的 $\texttt{E-value}$ 恰好等于 $k$，结果对 $1,000,000,007$ 取模。

### 输入输出

- **输入**：多个测试用例，每行包含两个整数 $N$ 和 $k$（$1 \leq N \leq 1000$，$0 \leq k \leq N$）
- **输出**：每个测试用例输出一行，表示答案模 $1,000,000,007$ 的结果

### 样例分析

对于 $N = 3$：
- $k = 0$：只有排列 $\{1, 2, 3\}$，输出 $1$
- $k = 1$：排列有 $\{1, 3, 2\}$、$\{2, 1, 3\}$、$\{3, 1, 2\}$、$\{3, 2, 1\}$，输出 $4$

## 解题思路

### 直接枚举不可行

$N$ 最大为 $1000$，排列总数 $N!$ 是一个极大的数字，直接枚举所有排列并统计 $\texttt{E-value}$ 显然不可行。

### 动态规划方法

我们使用动态规划来解决这个问题。定义状态：

- $dp[n][m]$：长度为 $n$ 的排列中，$\texttt{E-value}$ 恰好为 $m$ 的排列数量

考虑如何从 $n-1$ 扩展到 $n$：

#### 情况分析

1. **数字 $n$ 放在位置 $n$**
   - 此时 $a_n = n$，不增加 $\texttt{E-value}$
   - 前 $n-1$ 个位置需要有 $k$ 个 $\texttt{E-value}$ 位置
   - 贡献：$dp[n-1][k]$

2. **数字 $n$ 放在位置 $i$（$1 \leq i \leq n-1$）**
   - 此时 $a_i = n > i$，位置 $i$ 成为 $\texttt{E-value}$ 位置
   - 原来在位置 $i$ 的数字 $x$ 被移动到位置 $n$
   - 需要分析这对 $\texttt{E-value}$ 的影响：
     - 如果原来位置 $i$ 已经是 $\texttt{E-value}$ 位置（$x > i$），则 $\texttt{E-value}$ 总数不变
     - 如果原来位置 $i$ 不是 $\texttt{E-value}$ 位置（$x \leq i$），则 $\texttt{E-value}$ 总数增加 $1$

#### 递推公式推导

在长度为 $n-1$、$\texttt{E-value}$ 为 $m$ 的排列中：
- 有 $m$ 个 $\texttt{E-value}$ 位置
- 有 $n-1-m$ 个非 $\texttt{E-value}$ 位置

因此：
- 插入到 $\texttt{E-value}$ 位置：从 $dp[n-1][m]$ 转移到 $dp[n][m]$，有 $m$ 种选择
- 插入到非 $\texttt{E-value}$ 位置：从 $dp[n-1][m]$ 转移到 $dp[n][m+1]$，有 $n-1-m$ 种选择

结合情况 $1$，得到递推公式：

$$
dp[n][k] = dp[n-1][k] \cdot (1 + k) + dp[n-1][k-1] \cdot (n - k)
$$

#### 边界条件

- $dp[0][0] = 1$（空排列）
- $dp[n][k] = 0$ 当 $k < 0$ 或 $k > n$
- $dp[n][0] = 1$（只有恒等排列满足 $\texttt{E-value}$ 为 $0$）

### 复杂度分析

- 时间复杂度：$O(N^2)$，对于 $N \leq 1000$ 是可接受的
- 空间复杂度：$O(N^2)$，可以使用滚动数组优化到 $O(N)$，但本题 $N$ 较小，直接使用二维数组即可

## 代码实现

```cpp
// Permutation Counting
// UVa ID: 1485
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
using namespace std;

const int MOD = 1000000007;  // 模数
const int MAXN = 1000;       // 最大N值

int main() {
    // 预计算所有dp值
    vector<vector<long long>> dp(MAXN + 1, vector<long long>(MAXN + 1, 0));
    dp[0][0] = 1;  // 边界条件：空排列
    
    for (int n = 1; n <= MAXN; n++) {
        dp[n][0] = 1;  // 只有恒等排列满足E-value=0
        for (int k = 1; k <= n; k++) {
            // 递推公式：dp[n][k] = dp[n-1][k]*(1+k) + dp[n-1][k-1]*(n-k)
            dp[n][k] = (dp[n-1][k] * (1 + k) + dp[n-1][k-1] * (n - k)) % MOD;
        }
    }
    
    // 处理输入输出
    int N, k;
    while (cin >> N >> k) {
        cout << dp[N][k] << endl;
    }
    
    return 0;
}
```

## 算法特点

1. **预处理**：预先计算所有可能的 $N$ 和 $k$ 的组合，查询时直接输出结果
2. **模运算**：在每次加法乘法后立即取模，防止溢出
3. **边界处理**：正确处理 $k=0$ 的特殊情况

该算法能够高效处理题目给定的数据范围，并且思路清晰，易于理解和实现。
