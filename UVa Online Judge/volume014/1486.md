## 题目描述

有 $N$ 个城市和 $M$ 条有向道路连接它们。现在需要将 $K$ 个单位的货物从城市 $1$ 运送到城市 $N$ 。每条道路 $i$ 有一个系数 $a_i$ 和一个容量上限 $C_i$ 。如果沿该道路运输 $x$ 个单位的货物，则需要支付 $a_i \times x^2$ 美元雇佣守卫。每条道路只能运输整数单位的货物，且不能超过其容量上限 $C_i$ 。求安全运输所有 $K$ 个单位货物的最小费用。如果无法完成，输出 $-1$ 。

**输入格式** ：多个测试用例。每个用例第一行包含三个整数 $N$ , $M$ 和 $K$ （ $1 \leq N \leq 100$ , $1 \leq M \leq 5000$ , $0 \leq K \leq 100$ ）。接下来 $M$ 行，每行四个整数 $u_i$ , $v_i$ , $a_i$ , $C_i$ ，表示从城市 $u_i$ 到城市 $v_i$ 的有向道路，系数为 $a_i$ ，容量上限为 $C_i$ （ $1 \leq u_i, v_i \leq N$ , $0 < a_i \leq 100$ , $C_i \leq 5$ ）。

**输出格式** ：每个测试用例输出一行，表示最小费用。如果无法运送所有货物，输出 $-1$ 。

## 题目分析

本题是一个**带有二次费用函数和容量限制的最小费用流问题** 。核心难点在于费用函数是二次的（ $a_i \times x^2$ ），而传统的最小费用流算法通常处理线性费用。

### 关键观察

1. **容量限制很小** ： $C_i \leq 5$ ，这意味着每条边的容量很小。
2. **货物量适中** ： $K \leq 100$ ，总流量需求不大。
3. **费用函数性质** ：对于一条边，运输 $x$ 个单位货物的费用为 $a_i \times x^2$ 。这个二次函数具有**凸性** ，即边际成本递增。

### 解题思路

#### 1. 将二次费用转化为线性费用

由于每条边的容量 $C_i \leq 5$ ，我们可以将每条边**拆分成 $C_i$ 条容量为 $1$ 的平行边** 。对于第 $j$ 条边（ $j = 1, 2, \dots, C_i$ ），其费用为运输 $j$ 个单位和 $j-1$ 个单位货物的费用差：

$$
\text{费用}_j = a_i \times j^2 - a_i \times (j-1)^2 = a_i \times (2j - 1)
$$

这样，我们就将二次费用问题转化为了**线性费用问题** ，因为现在每条边的费用是固定的（不随流量变化）。

#### 2. 转化为最小费用流问题

经过上述转换后，我们得到了一个**带容量限制的最小费用流问题** ：
- 源点：城市 $1$
- 汇点：城市 $N$
- 需求流量： $K$
- 每条边的容量为 $1$ ，费用为 $a_i \times (2j - 1)$

我们需要找到从源点到汇点的**流量恰好为 $K$ 的最小费用流** 。

#### 3. 算法选择

由于 $N \leq 100$ ， $M \leq 5000$ ，每条边最多拆分成 $5$ 条边，所以总边数不超过 $5 \times 5000 = 25000$ 。使用基于 $\texttt{SPFA}$ 的最小费用流算法是可行的。

算法步骤：
1. 构建图，将每条原始边拆分为 $C_i$ 条容量为 $1$ 、费用递增的边。
2. 使用最小费用流算法，每次寻找费用最小的增广路。
3. **关键** ：当流量达到 $K$ 时立即停止，而不是寻找最大流。
4. 如果算法结束时流量小于 $K$ ，则输出 $-1$ ；否则输出总费用。

#### 4. 算法正确性证明

- 由于费用函数 $a_i \times x^2$ 是凸函数，将边拆分为费用递增的平行边后，算法会**优先使用费用较低的边** ，这恰好模拟了二次费用函数的边际成本递增特性。
- 当流量达到 $K$ 时停止，确保了我们找到的是运输恰好 $K$ 个单位的最小费用方案，而不是最大流方案。

## 时间复杂度分析

- 每次 $\texttt{SPFA}$ 的时间复杂度为 $O(VE)$ ，其中 $V = N \leq 100$ ， $E \leq 25000$ 。
- 最多需要 $K \leq 100$ 次增广。
- 总时间复杂度约为 $O(K \times VE) \approx 100 \times 100 \times 25000 = 2.5 \times 10^8$ ，在合理优化下可以通过。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
const int MAXN = 105;
const int MAXM = 50005;

struct Edge {
    int to, next, cap, cost;
} edge[MAXM];
int head[MAXN], tot;
int pre[MAXN], dist[MAXN];
bool vis[MAXN];

// 添加有向边
void addEdge(int u, int v, int cap, int cost) {
    edge[tot].to = v; edge[tot].cap = cap; edge[tot].cost = cost; edge[tot].next = head[u]; head[u] = tot++;
    edge[tot].to = u; edge[tot].cap = 0; edge[tot].cost = -cost; edge[tot].next = head[v]; head[v] = tot++;
}

// SPFA 寻找最短增广路
bool spfa(int s, int t) {
    memset(dist, 0x3f, sizeof(dist));
    memset(vis, false, sizeof(vis));
    memset(pre, -1, sizeof(pre));
    queue<int> q;
    dist[s] = 0; vis[s] = true; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        vis[u] = false;
        for (int i = head[u]; i != -1; i = edge[i].next) {
            int v = edge[i].to;
            if (edge[i].cap > 0 && dist[v] > dist[u] + edge[i].cost) {
                dist[v] = dist[u] + edge[i].cost;
                pre[v] = i;
                if (!vis[v]) vis[v] = true, q.push(v);
            }
        }
    }
    return pre[t] != -1;
}

// 最小费用流，限制流量为 needFlow
int minCostFlow(int s, int t, int needFlow) {
    int cost = 0, flow = 0;
    while (spfa(s, t) && flow < needFlow) {
        int minFlow = INF;
        for (int i = pre[t]; i != -1; i = pre[edge[i ^ 1].to]) 
            minFlow = min(minFlow, edge[i].cap);
        minFlow = min(minFlow, needFlow - flow);  // 限制不超过需要的流量
        for (int i = pre[t]; i != -1; i = pre[edge[i ^ 1].to]) {
            edge[i].cap -= minFlow;
            edge[i ^ 1].cap += minFlow;
            cost += edge[i].cost * minFlow;
        }
        flow += minFlow;
    }
    if (flow < needFlow) return -1;  // 无法达到需要的流量
    return cost;
}

int main() {
    int n, m, k;
    while (scanf("%d %d %d", &n, &m, &k) == 3) {
        memset(head, -1, sizeof(head));
        tot = 0;
        int src = 1, sink = n;
        
        // 读取当前测试用例的所有道路
        for (int i = 0; i < m; ++i) {
            int u, v, a, c;
            scanf("%d %d %d %d", &u, &v, &a, &c);
            // 将边拆分为 c 条容量为 1，费用为 a*(2*j-1) 的边
            for (int j = 1; j <= c; ++j) 
                addEdge(u, v, 1, a * (2 * j - 1));
        }
        
        int cost = minCostFlow(src, sink, k);
        printf("%d\n", cost);
    }
    return 0;
}
```

## 总结

本题的解题关键在于：
1. **利用容量限制小的特点** ，将每条边拆分为多条平行边。
2. **将二次费用转化为线性费用** ，通过计算费用差实现。
3. **使用最小费用流算法** ，并在流量达到 $K$ 时停止。
4. **注意处理多个测试用例** ，确保每个用例独立处理。

这种将非线性费用转化为线性费用的技巧在网络流问题中非常有用，特别是在费用函数具有凸性的情况下。
