## 题目描述

有 $N$ 个人在排队等待激活游戏，番茄（$\texttt{Tomato}$）初始时排在第 $M$ 个位置。服务器每次处理队首请求时，可能发生以下四种情况之一：

1. **激活失败**（概率 $p_1$）：队首请求保留，下次继续处理
2. **连接失败**（概率 $p_2$）：队首玩家掉线并重新排到队尾
3. **激活成功**（概率 $p_3$）：队首玩家成功激活并离开队列
4. **服务不可用**（概率 $p_4$）：服务器宕机，所有排队请求无法再被处理

我们需要计算**服务器宕机时，番茄还在队列中且前面不超过 $K-1$ 个人**的概率。

## 输入格式

多组测试数据（不超过 $40$ 组），每组数据包含：
- 三个整数：$N, M, K$（$1 \leq M \leq N \leq 2000$，$K \geq 1$）
- 四个实数：$p_1, p_2, p_3, p_4$（$0 \leq p_1, p_2, p_3, p_4 \leq 1$，且 $p_1 + p_2 + p_3 + p_4 = 1$）

## 输出格式

对于每组数据，输出所求概率，保留 $5$ 位小数。

## 题目分析

### 问题本质

这是一个典型的**概率动态规划**问题，需要计算在特定条件下服务器宕机的概率。问题的难点在于队列的动态变化：队首可能保持不变、可能移到队尾、可能离开队列。

### 状态定义

设 $dp[i][j]$ 表示队列中有 $i$ 个人，番茄排在第 $j$ 个位置时，发生"坏情况"（即服务器宕机时番茄前面不超过 $K-1$ 人）的概率。

### 状态转移方程

根据队首处理的不同结果，我们可以建立状态转移：

1. **当 $j = 1$（番茄在队首）**：
   - 激活失败：状态不变，概率贡献 $p_1 \cdot dp[i][1]$
   - 连接失败：番茄排到队尾，概率贡献 $p_2 \cdot dp[i][i]$
   - 激活成功：番茄离开，不会发生坏情况，贡献 $0$
   - 服务器宕机：此时番茄前面有 $0$ 人，满足条件，贡献 $p_4 \cdot 1$

   因此：
   $$
   dp[i][1] = p_1 \cdot dp[i][1] + p_2 \cdot dp[i][i] + p_4
   $$

2. **当 $2 \leq j \leq K$（番茄在前 $K$ 个位置）**：
   - 激活失败：状态不变，概率贡献 $p_1 \cdot dp[i][j]$
   - 连接失败：番茄位置前移一位，概率贡献 $p_2 \cdot dp[i][j-1]$
   - 激活成功：队首离开，队列长度减 $1$，番茄位置前移一位，概率贡献 $p_3 \cdot dp[i-1][j-1]$
   - 服务器宕机：满足条件，贡献 $p_4 \cdot 1$

   因此：
   $$
   dp[i][j] = p_1 \cdot dp[i][j] + p_2 \cdot dp[i][j-1] + p_3 \cdot dp[i-1][j-1] + p_4
   $$

3. **当 $j > K$（番茄在 $K$ 个位置之后）**：
   - 与情况2类似，但服务器宕机时不满足条件，贡献 $0$

   因此：
   $$
   dp[i][j] = p_1 \cdot dp[i][j] + p_2 \cdot dp[i][j-1] + p_3 \cdot dp[i-1][j-1]
   $$

### 方程整理

将上述方程整理，消去等号右边的 $dp[i][j]$ 项：

对于 $j = 1$：
$$
dp[i][1] = \frac{p_2}{1-p_1} \cdot dp[i][i] + \frac{p_4}{1-p_1}
$$

对于 $2 \leq j \leq K$：
$$
dp[i][j] = \frac{p_2}{1-p_1} \cdot dp[i][j-1] + \frac{p_3}{1-p_1} \cdot dp[i-1][j-1] + \frac{p_4}{1-p_1}
$$

对于 $j > K$：
$$
dp[i][j] = \frac{p_2}{1-p_1} \cdot dp[i][j-1] + \frac{p_3}{1-p_1} \cdot dp[i-1][j-1]
$$

### 求解技巧

由于 $dp[i][1]$ 依赖于 $dp[i][i]$，形成了循环依赖。我们可以通过以下方法求解：

1. 设 $p_{21} = \frac{p_2}{1-p_1}$，$p_{31} = \frac{p_3}{1-p_1}$，$p_{41} = \frac{p_4}{1-p_1}$
2. 对于每个 $i$，我们可以将 $dp[i][j]$ 表示为 $dp[i][i]$ 的线性函数
3. 通过累加系数，最终解出 $dp[i][i]$，然后回代得到所有 $dp[i][j]$

### 边界条件

- 当 $i = 1$ 时：$dp[1][1] = \frac{p_4}{1-p_1-p_2}$（如果分母不为 $0$）
- 特别地，如果 $p_4 = 0$，则答案直接为 $0$

## 算法复杂度

- 时间复杂度：$O(N^2)$，对于 $N \leq 2000$ 可以接受
- 空间复杂度：$O(N^2)$，使用二维数组存储状态

```cpp
// Activation

#include <iostream>
#include <cstdio>
#include <cmath>
#include <cstring>
using namespace std;

const int MAXN = 2005;
const double EPS = 1e-9;

double dp[MAXN][MAXN];  // dp[i][j]: 队列有i个人，番茄在第j个位置时的概率
double powp1[MAXN];     // 存储p21的幂次，用于快速计算
double c[MAXN];         // 辅助数组，存储中间计算结果

int main() {
    int N, M, K;
    double p1, p2, p3, p4;
    
    // 处理多组测试数据
    while (scanf("%d%d%d%lf%lf%lf%lf", &N, &M, &K, &p1, &p2, &p3, &p4) == 7) {
        // 如果服务器宕机概率为0，直接输出0
        if (fabs(p4) < EPS) {
            printf("0.00000\n");
            continue;
        }
        
        // 预处理概率系数
        double p21 = p2 / (1 - p1);
        double p31 = p3 / (1 - p1);
        double p41 = p4 / (1 - p1);
        
        // 计算p21的幂次，用于后续计算
        powp1[0] = 1.0;
        for (int i = 1; i <= N; i++) {
            powp1[i] = powp1[i-1] * p21;
        }
        
        // 初始化边界条件
        dp[1][1] = p41 / (1 - p21);
        c[1] = p41;
        
        // 动态规划求解
        for (int i = 2; i <= N; i++) {
            // 计算c数组
            for (int j = 2; j <= i; j++) {
                c[j] = p31 * dp[i-1][j-1];
                if (j <= K) {
                    c[j] += p41;  // 前K个位置，服务器宕机时满足条件
                }
            }
            
            // 解出dp[i][i]
            double sum = 0.0;
            for (int j = 1; j <= i; j++) {
                sum += powp1[i - j] * c[j];
            }
            dp[i][i] = sum / (1 - powp1[i]);
            
            // 回代计算其他dp[i][j]
            dp[i][1] = p21 * dp[i][i] + c[1];
            for (int j = 2; j < i; j++) {
                dp[i][j] = p21 * dp[i][j-1] + c[j];
            }
        }
        
        // 输出结果，保留5位小数
        printf("%.5f\n", dp[N][M]);
    }
    return 0;
}
```

## 总结

本题通过动态规划方法解决了排队激活中的概率计算问题。关键在于：
1. 合理定义状态表示队列长度和番茄位置的关系
2. 正确处理四种不同的事件对状态的影响
3. 使用数学技巧解决状态间的循环依赖关系

该解法在时间复杂度和空间复杂度上都能够满足题目要求，是一个典型且高效的概率动态规划应用。
