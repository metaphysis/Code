[UVa 1500 Alice and Bob](https://blog.csdn.net/metaphysis/article/details/155395766)


## 题目描述

$\texttt{Alice}$ 和 $\texttt{Bob}$ 发明了一个新游戏。游戏开始时，他们写下 $N$ 个随机正整数，然后轮流进行操作（$\texttt{Alice}$ 先手），每次操作可以选择：

1. 将一个数字减 $1$
2. 删除任意两个数字，写下它们的和

当一个数字被减到 $0$ 时，会自动被删除。当所有数字都被删除时游戏结束，无法操作的人输掉游戏。

两人都采用最优策略，我们需要判断对于给定的初始数字，谁会获胜。

## 输入格式

- 第一行包含整数 $T$ ($1 \leq T \leq 4000$)，表示测试用例数量
- 每个测试用例包含两行：
  - 第一行包含整数 $N$ ($1 \leq N \leq 50$)
  - 第二行包含 $N$ 个正整数 $A_1, A_2, \ldots, A_N$ ($1 \leq A_i \leq 1000$)

## 输出格式

对于每个测试用例，输出一行：`Case #X: Y`，其中 $X$ 是测试用例编号（从 $1$ 开始），$Y$ 是 `Alice` 或 `Bob`。

## 题目分析

这是一个组合博弈问题，我们需要找到游戏的必胜策略。通过分析游戏规则，可以发现游戏的关键在于数字 $1$ 的特殊性质和非 $1$ 数字的消除步数。

### 关键观察

1. **操作分析**：
   - 减 $1$ 操作：减少某个数字的值，可能删除该数字（当值变为 $0$ 时）
   - 合并操作：减少数字个数，但不改变数字总和

2. **数字 $1$ 的特殊性**：
   - 对数字 $1$ 执行减 $1$ 操作会立即删除该数字
   - 数字 $1$ 不能通过减 $1$ 操作来改变值（只能删除）

3. **非 $1$ 数字的消除步数**：
   - 每个非 $1$ 数字需要其数值次减 $1$ 操作
   - 将 $k$ 个非 $1$ 数字合并成 $1$ 个需要 $k-1$ 次合并操作

### 解题思路

经过数学推导和博弈分析，我们得到以下结论：

设：
- $c$ = 数字 $1$ 的个数
- $s$ = 非 $1$ 数字的消除步数

其中 $s$ 的计算方法为：
$$s = \sum_{a_i > 1} a_i + (\text{非}1\text{数字个数} - 1)$$

**胜负判断规则**：

1. **当 $s > 2$ 时**：
   - 如果 $s$ 为奇数 **或** $c$ 为奇数，则 $\texttt{Alice}$ 必胜
   - 否则 $\texttt{Bob}$ 必胜

2. **当 $s \leq 2$ 时**（即 $s = 0$ 或 $s = 2$）：
   - 如果 $c$ 是 $3$ 的倍数，则 $\texttt{Bob}$ 必胜
   - 否则 $\texttt{Alice}$ 必胜

### 证明思路

**情况 1：$s > 2$**

- $s$ 为奇数，$c$ 为偶数：先手对非 $1$ 数字减 $1$，转移到必败态
- $s$ 为偶数，$c$ 为奇数：先手对 $1$ 减 $1$，转移到必败态
- $s$ 为奇数，$c$ 为奇数：先手合并 $1$ 和非 $1$ 数字，转移到必败态
- $s$ 为偶数，$c$ 为偶数：无论先手做什么，都会转移到必胜态

**情况 2：$s \leq 2$**

- $c \bmod 3 = 1$：先手对 $1$ 减 $1$，转移到必败态
- $c \bmod 3 = 2$：先手合并两个 $1$，转移到必败态
- $c \bmod 3 = 0$：任何操作都会转移到必胜态

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int testCases;
    cin >> testCases;
    for (int caseNum = 1; caseNum <= testCases; caseNum++) {
        int n;
        cin >> n;
        int oneCount = 0;        // 数字1的个数
        int nonOneStepCount = 0; // 非1数字的消除步数
        int nonOneCount = 0;     // 非1数字的个数
        for (int i = 0; i < n; i++) {
            int num;
            cin >> num;
            if (num == 1) oneCount++;
            else {
                nonOneStepCount += num;  // 每个非1数字需要num次减1操作
                nonOneCount++;
            }
        }
        // 计算非1数字的总消除步数：
        // 1. 减1操作步数：所有非1数字值之和
        // 2. 合并操作步数：nonOneCount-1（将nonOneCount个数字合并成1个需要nonOneCount-1次合并操作）
        if (nonOneCount > 0) {
            nonOneStepCount += nonOneCount - 1;
        }
        string winner;
        if (nonOneStepCount > 2) {
            // 情况1：非1数字消除步数大于2
            // 当非1步数为奇数 或 1的个数为奇数时，先手必胜
            // 证明思路：
            // - 非1步数为奇数，1的个数为偶数：先手对非1数字减1，转移到必败态
            // - 非1步数为偶数，1的个数为奇数：先手对1减1，转移到必败态  
            // - 非1步数为奇数，1的个数为奇数：先手合并1和非1数字，转移到必败态
            winner = (nonOneStepCount % 2 == 1 || oneCount % 2 == 1) ? "Alice" : "Bob";
        } else {
            // 情况2：非1数字消除步数小于等于2（只有0或2两种情况）
            // 当1的个数是3的倍数时，先手必败；否则先手必胜
            // 证明思路：
            // - 1的个数模3余1：先手对1减1，转移到必败态
            // - 1的个数模3余2：先手合并两个1，转移到必败态
            // - 1的个数模3余0：任何操作都会转移到必胜态
            winner = (oneCount % 3 == 0) ? "Bob" : "Alice";
        }
        cout << "Case #" << caseNum << ": " << winner << endl;
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(T \times N)$，其中 $T$ 是测试用例数量，$N$ 是每个测试用例的数字个数
- **空间复杂度**：$O(1)$，只使用了常数级别的额外空间
