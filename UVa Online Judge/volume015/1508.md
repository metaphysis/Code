## 题目描述

韩国国防科学研究院（$\texttt{KDSI}$）研发了 $N$ 种新装备，每种装备在五个类别上有评分：攻击提升、防御提升、视野提升、便携性和易用性。每个类别的评分是 $0$ 到 $10000$ 的整数。

每个士兵最多可以安装 $K$ 种装备。如果安装多种装备，每个类别上的能力提升值取所选装备在该类别评分的最大值。组合的目标分数定义为五个类别最大值之和。

给定 $N$ 种装备的评分和整数 $K$ $(1 \le K \le N)$ ，求选择恰好 $K$ 种装备能获得的最大目标分数。

**输入格式**
- 第一行：测试用例数 $T$
- 每个测试用例：
  - 第一行：$N$ 和 $K$
  - 接下来 $N$ 行：每行 $5$ 个整数，表示装备的五个评分

**输出格式**
- 每个测试用例一行：最大目标分数

**数据范围**
- $1 \le N \le 10000$
- $1 \le K \le N$
- 评分范围 $0 \sim 10000$

## 题目分析

### 问题本质
我们需要从 $N$ 种装备中选择恰好 $K$ 种，使得五个类别中每种类别取所选装备在该类别的最大评分，然后将这五个最大值相加，最大化这个和。

### 关键观察
1. **维度数量固定且很小** ：只有 $5$ 个维度（类别）。
2. **$N$ 可以很大** （最大 $10000$ ），$K$ 最大也是 $N$ 。
3. **直接暴力枚举组合不可行** ：组合数为 $C(N, K)$ ，当 $N=10000, K=5000$ 时不可计算。

### 深入思考

#### 当 $K \ge 5$ 时
由于只有 $5$ 个维度，我们最多需要 $5$ 个装备就能覆盖所有维度的最大值（每个装备可能贡献多个维度的最大值）。当 $K \ge 5$ 时，我们总能选择不超过 $5$ 个装备来获得每个维度的全局最大值。因此：

- 最优解就是取每个维度的全局最大值，然后求和。
- 证明：设第 $j$ 个维度的全局最大值为 $max_j$ ，我们可以分别选择在每个维度上达到 $max_j$ 的装备（可能少于 $5$ 个，因为一个装备可能在多个维度上都是最大值）。由于 $K \ge 5$ ，我们可以选择这些装备（如果少于 $5$ 个，再任意选其他装备补足 $K$ 个），目标分数就是 $\sum_{j=1}^{5} max_j$ 。

#### 当 $K < 5$ 时
这是问题的难点。我们需要选择恰好 $K$ 个装备，而 $K$ 可能小于 $5$ ，这意味着我们可能无法让每个维度都由不同的装备提供最大值（一个装备可能贡献多个维度的最大值）。

**关键性质** ：在最优解中，每个维度的最大值提供者（即在该维度评分最高的所选装备）一定属于该维度评分最高的前 $K$ 个装备之一。

**证明思路** （反证法）：
假设在最优解中，存在某个维度 $j$ ，其最大值提供者 $eq$ 在该维度的评分排在第 $K+1$ 名或更后。那么存在至少 $K$ 个装备在维度 $j$ 上的评分高于 $eq$ 。考虑用这 $K$ 个装备中的一个替换 $eq$ ：
1. 在维度 $j$ 上，新装备的评分更高，因此不会降低该维度的最大值。
2. 在其他维度上，新装备的评分可能较低，但不会影响那些维度的最大值（因为最大值可能由其他装备保持）。
因此，替换后目标分数不会降低，且经过有限次替换，最终每个维度的最大值提供者都在该维度的前 $K$ 名中。

### 算法设计

基于以上分析：

1. **当 $K \ge 5$ 时** ：
   - 遍历所有装备，计算每个维度的全局最大值。
   - 输出五个最大值的和。

2. **当 $K < 5$ 时** ：
   - 为每个维度 $j$ ，找出该维度评分最高的前 $10$ 个装备（取 $10$ 而不是 $K$ 是为了更安全，保证正确性）。
   - 将这些装备的索引收集起来，去重，形成候选装备集合。
   - 在候选集合中枚举所有大小为 $K$ 的组合，计算每种组合的目标分数，取最大值。

### 候选集合大小的合理性
- 每个维度取前 $10$ 名，最多有 $5 \times 10 = 50$ 个候选装备（去重后可能更少）。
- 枚举 $C(50, K)$ 个组合：
  - $K=1$: $50$ 种
  - $K=2$: $1225$ 种
  - $K=3$: $19600$ 种
  - $K=4$: $230300$ 种
- 每个组合计算需要 $O(K \times 5)$ 时间，完全可行。

### 算法正确性证明补充
为什么取前 $10$ 名而不是前 $K$ 名？
- 考虑 $K=2$ 的情况，某个维度上排名第 $3$ 的装备是否可能成为最优解的一部分？根据之前的证明，如果它是最优解中某个维度的最大值提供者，那么存在排名前 $2$ 的装备可以替换它而不降低目标分数。但为了保证算法鲁棒性，取前 $10$ 名更安全，且计算量仍然可接受。

## 算法步骤

1. 读取测试用例数 $T$ 。
2. 对每个测试用例：
   - 读取 $N, K$ 和 $N$ 个装备的评分。
   - 如果 $K \ge 5$ ：
     - 计算每个维度的全局最大值 $max_j$ 。
     - 输出 $\sum_{j=1}^{5} max_j$ 。
   - 如果 $K < 5$ ：
     - 对每个维度 $j$ ，按评分降序排序装备，取前 $\min(10, N)$ 个装备的索引加入候选集。
     - 候选集去重。
     - 如果候选集大小 $\le K$ ，直接计算这些装备组合的分数。
     - 否则，使用 $\texttt{DFS}$ 枚举所有大小为 $K$ 的组合，计算目标分数并取最大值。
     - 输出最大值。

## 时间复杂度分析

- $K \ge 5$ 时：$O(N)$ 。
- $K < 5$ 时：
  - 排序：$5 \times O(N \log N)$ ，但 $N \le 10000$ ，可接受。
  - 枚举组合：最多 $C(50, 4) = 230300$ 种组合，每种组合计算 $O(20)$ ，总操作约 $4.6 \times 10^6$ ，完全可行。

## 空间复杂度

- 存储装备评分：$O(N)$ 。
- 候选集：最多 $50$ 个装备。
- $\texttt{DFS}$ 递归深度：$K \le 4$ 。

```cpp
// Equipment
// UVa ID: 1508

#include <bits/stdc++.h>
using namespace std;

// 深度优先搜索枚举所有大小为k的组合
void dfs(const vector<vector<int>>& candidates, int start, int k, vector<int>& current, int& bestScore) {
    if (k == 0) {
        // 计算当前组合的目标分数：五个维度的最大值之和
        vector<int> maxVals(5, 0);
        for (int idx : current) {
            for (int j = 0; j < 5; ++j) {
                if (candidates[idx][j] > maxVals[j]) maxVals[j] = candidates[idx][j];
            }
        }
        int score = 0;
        for (int v : maxVals) score += v;
        if (score > bestScore) bestScore = score;
        return;
    }
    // 组合枚举
    for (int i = start; i <= (int)candidates.size() - k; ++i) {
        current.push_back(i);
        dfs(candidates, i + 1, k - 1, current, bestScore);
        current.pop_back();
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int N, K;
        cin >> N >> K;
        vector<vector<int>> equipment(N, vector<int>(5));
        for (int i = 0; i < N; ++i)
            for (int j = 0; j < 5; ++j)
                cin >> equipment[i][j];

        // 情况1: K >= 5，直接取每个维度的全局最大值
        if (K >= 5) {
            vector<int> maxPerCategory(5, 0);
            for (int j = 0; j < 5; ++j) {
                for (int i = 0; i < N; ++i) {
                    if (equipment[i][j] > maxPerCategory[j]) maxPerCategory[j] = equipment[i][j];
                }
            }
            int total = 0;
            for (int v : maxPerCategory) total += v;
            cout << total << '\n';
            continue;
        }

        // 情况2: K < 5，构建候选装备集合
        vector<int> candidateIndices;
        int candidatesPerCategory = min(10, N); // 每个维度取前10名
        
        for (int j = 0; j < 5; ++j) {
            // 按第j维评分排序装备索引
            vector<pair<int, int>> sortedByCategory;
            for (int i = 0; i < N; ++i) sortedByCategory.emplace_back(equipment[i][j], i);
            // 降序排序
            sort(sortedByCategory.begin(), sortedByCategory.end(), 
                 [](const pair<int, int>& a, const pair<int, int>& b) {
                     return a.first > b.first;
                 });
            // 取前candidatesPerCategory个
            for (int t = 0; t < candidatesPerCategory && t < (int)sortedByCategory.size(); ++t) {
                candidateIndices.push_back(sortedByCategory[t].second);
            }
        }
        
        // 去重
        sort(candidateIndices.begin(), candidateIndices.end());
        candidateIndices.erase(unique(candidateIndices.begin(), candidateIndices.end()), candidateIndices.end());
        
        // 构建候选装备列表
        vector<vector<int>> candidates;
        for (int idx : candidateIndices) candidates.push_back(equipment[idx]);
        
        // 计算最佳分数
        int bestScore = 0;
        if ((int)candidates.size() <= K) {
            // 候选装备数量不足K个，直接计算
            vector<int> maxVals(5, 0);
            for (const auto& eq : candidates) {
                for (int j = 0; j < 5; ++j) {
                    if (eq[j] > maxVals[j]) maxVals[j] = eq[j];
                }
            }
            for (int v : maxVals) bestScore += v;
        } else {
            // 枚举所有大小为K的组合
            vector<int> current;
            dfs(candidates, 0, K, current, bestScore);
        }
        
        cout << bestScore << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于利用维度数量少（只有 $5$ 个）的特点进行优化：
1. 当 $K \ge 5$ 时，问题简化为取每个维度的全局最大值。
2. 当 $K < 5$ 时，通过证明最优解中每个维度的最大值提供者都在该维度前 $K$ 名中，将候选装备数量限制在很小的范围内，然后枚举所有组合。

这种思想在许多组合优化问题中都有应用：当维度或约束很少时，可以通过限制候选集来减少搜索空间。本题取每个维度前 $10$ 名是一个经验值，在保证正确性的同时控制了计算量。
