## 题目描述

$\texttt{JungHeum}$ 最近开了一家名为 $\texttt{Triangle}$ 的餐厅，并为其定制了一个特殊的霓虹灯标志。这个标志有 $N$ 个角点均匀分布在一个圆周上，每两个不同的角点之间都有一根发光管连接，因此总共有 $N \times (N-1)/2$ 根发光管。

发光管只有两种颜色：红色（用 `1` 表示）和蓝色（用 `0` 表示）。$\texttt{JungHeum}$ 希望知道在这个完全图中，有多少个三角形是**单色**的，即三条边颜色相同的三角形。

例如，当 $N = 5$ 时，可能只有 2 个单色三角形。

## 输入格式

- 第一行包含整数 $T$，表示测试用例的数量
- 每个测试用例：
  - 第一行包含整数 $N$，表示角点数量
  - 接下来的 $N-1$ 行，第 $i$ 行包含 $N-i$ 个整数，表示连接角点 $i$ 与角点 $i+1$ 到 $N$ 的发光管颜色

## 输出格式

对于每个测试用例，输出一行，包含单色三角形的数量。

## 题目分析

### 问题本质

我们需要在一个完全图 $K_N$ 中，统计所有三条边颜色相同的三角形的数量。图中的每条边被染成红色或蓝色。

### 直接方法的局限性

最直接的方法是枚举所有可能的三角形（组合数 $C_N^3$），然后检查每个三角形的三条边是否同色。当 $N = 1000$ 时，$C_{1000}^3 \approx 1.67 \times 10^8$，这个数量级在时间限制内可能勉强通过，但我们需要更高效的算法。

### 优化思路：补集思想

我们可以利用补集的思想来计算单色三角形的数量：

1. **计算总三角形数**：$\texttt{total} = \frac{N(N-1)(N-2)}{6}$

2. **计算非单色三角形数**：非单色三角形是指三条边颜色不全相同的三角形

3. **单色三角形数** = 总三角形数 - 非单色三角形数

### 关键观察

对于非单色三角形，其特点是**至少有一个顶点的两条出边颜色不同**。

更精确地说：
- 对于每个顶点 $i$，设：
  - $R_i$ = 从顶点 $i$ 出发的红边数量
  - $B_i$ = 从顶点 $i$ 出发的蓝边数量
  - 由于是完全图，$R_i + B_i = N - 1$

- 对于顶点 $i$，它参与的非单色三角形数量为 $R_i \times B_i$
- 每个非单色三角形恰好有 2 个顶点满足"两条出边颜色不同"的条件

因此：
$$\texttt{non\_mono} = \frac{1}{2} \sum_{i=1}^N (R_i \times B_i)$$

最终：
$$\texttt{mono} = \frac{N(N-1)(N-2)}{6} - \frac{1}{2} \sum_{i=1}^N (R_i \times B_i)$$

### 算法步骤

1. 读取输入，构建图的邻接关系
2. 对于每个顶点，统计红边和蓝边的数量
3. 计算总三角形数
4. 计算非单色三角形数
5. 输出单色三角形数

### 复杂度分析

- 时间复杂度：$O(N^2)$，主要用于读取输入和统计每个顶点的边数
- 空间复杂度：$O(N^2)$，用于存储图的邻接矩阵

## 代码实现

```cpp
// Neon Sign
// UVa ID: 1510
// Verdict: Accepted
// Submission Date: 2025-11-18
// UVa Run Time: 0.200s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
  int T;
  cin >> T;
  while (T--) {
    int n;
    cin >> n;
    vector<vector<int>> color(n + 1, vector<int>(n + 1, 0));
    // 读取输入，构建颜色矩阵
    for (int i = 1; i <= n - 1; i++)
      for (int j = i + 1; j <= n; j++)
        cin >> color[i][j];
    
    // 统计每个顶点的红边和蓝边数量
    vector<int> redCount(n + 1, 0), blueCount(n + 1, 0);
    for (int i = 1; i <= n; i++)
      for (int j = 1; j <= n; j++) {
        if (i == j) continue;
        int c;
        if (i < j) c = color[i][j];
        else c = color[j][i];
        if (c == 1) redCount[i]++;
        else blueCount[i]++;
      }
    
    // 计算总三角形数
    long long totalTriangles = (long long)n * (n - 1) * (n - 2) / 6;
    // 计算非单色三角形数
    long long nonMono = 0;
    for (int i = 1; i <= n; i++)
      nonMono += (long long)redCount[i] * blueCount[i];
    nonMono /= 2;
    
    // 计算单色三角形数
    long long mono = totalTriangles - nonMono;
    cout << mono << endl;
  }
  return 0;
}
```

## 总结

本题的关键在于发现非单色三角形的特征：每个非单色三角形恰好有两个顶点，从这两个顶点出发的两条边颜色不同。通过统计每个顶点的红边和蓝边数量，我们可以高效地计算出非单色三角形的数量，从而得到单色三角形的数量。

这种利用补集思想和组合计数的方法，将原本 $O(N^3)$ 的枚举问题优化到了 $O(N^2)$，对于 $N \leq 1000$ 的数据规模是完全可行的。
