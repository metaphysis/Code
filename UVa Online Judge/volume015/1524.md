## 题目描述

约翰·史密斯管理着一座大型冷库，为了避免因温度异常导致货物损坏，他安装了一套自动温控系统。该系统根据给定的多项式函数 $f(x)$ 调节温度，使得在时刻 $x$ 的温度等于 $f(x)$ 。史密斯先生想知道从开始时间 $s$ 到结束时间 $e$ 这段时间内的平均温度，以便评估系统的调节效果。

你需要编写一个程序，读入多项式的最高次数 $n$ 、各项系数（按幂次从高到低排列）以及时间区间 $[s, e]$ ，计算并输出该时间段内的平均温度，结果保留三位小数。

---

## 输入格式

- 输入包含多个数据集。
- 每个数据集的第一行是一个整数 $n$ （ $n < 100$ ），表示多项式的最高次数。若 $n = 0$ ，表示输入结束。
- 接下来一行包含 $n + 1$ 个实数，表示多项式的系数，顺序为从 $x^n$ 到 $x^0$ 。
- 最后一行包含两个实数 $s$ 和 $e$ （ $s < e$ ），表示时间区间的起点和终点。

---

## 输出格式

对于每个数据集，输出一个实数，表示 $f(x)$ 在 $[s, e]$ 上的平均值，保留三位小数，每个结果占一行。

## 题目分析

本题要求计算一个多项式函数 $f(x)$ 在区间 $[s, e]$ 上的平均值。根据数学定义，函数 $f(x)$ 在区间 $[a, b]$ 上的平均值为：

$$
average = \frac{1}{b - a} \int_a^b f(x) \, dx
$$

因此，我们需要计算多项式 $f(x)$ 在 $[s, e]$ 上的定积分，再除以区间长度 $e - s$ 。

---

## 解题思路

### 1. 多项式积分

多项式积分具有线性性质，可以逐项积分。设多项式为：

$$
f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0
$$

则其不定积分为：

$$
\int f(x) \, dx = \frac{a_n}{n+1} x^{n+1} + \frac{a_{n-1}}{n} x^{n} + \dots + \frac{a_1}{2} x^2 + a_0 x + C
$$

在区间 $[s, e]$ 上的定积分为：

$$
\int_s^e f(x) \, dx = \sum_{k=0}^{n} \frac{a_k}{k+1} \left( e^{k+1} - s^{k+1} \right)
$$

注意：题目输入时系数是按幂次从高到低给出的，即 $a_n, a_{n-1}, \dots, a_0$ 。因此，在计算时需要正确对应系数与幂次。

### 2. 计算步骤

1. 读入最高次数 $n$ ，若为 $0$ 则结束程序。
2. 读入 $n+1$ 个系数，存入数组 `coeff` ， `coeff[i]` 对应 $x^{n-i}$ 的系数。
3. 读入区间端点 $s$ 和 $e$ 。
4. 遍历所有系数，对于第 $i$ 个系数（对应幂次 $power = n-i$ ），计算积分贡献：
   $$
   term = \frac{coeff[i]}{power + 1} \left( e^{power+1} - s^{power+1} \right)
   $$
   累加到 `integral` 中。
5. 计算平均值：
   $$
   average = \frac{integral}{e - s}
   $$
6. 输出结果，保留三位小数。

### 3. 注意事项

- 幂次运算使用 `pow` 函数。
- 输出使用 `fixed` 和 `setprecision(3)` 控制格式。
- 注意浮点数精度问题，题目要求精度为三位小数，使用 `double` 类型足够。

## 代码实现

```cpp
// Hot or Cold?
// UVa ID: 1524
// Verdict: Accepted
// Submission Date: 2026-01-30
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    while (cin >> n && n != 0) {
        vector<double> coeff(n + 1);
        // 读入系数，从最高次到常数项
        for (int i = 0; i <= n; ++i) cin >> coeff[i];
        double s, e;
        cin >> s >> e;
        double integral = 0.0;
        // 计算定积分
        for (int i = 0; i <= n; ++i) {
            int power = n - i; // 当前项的次数
            integral += coeff[i] * (pow(e, power + 1) - pow(s, power + 1)) / (power + 1);
        }
        double average = integral / (e - s);
        cout << fixed << setprecision(3) << average << endl;
    }
    return 0;
}
```

## 复杂度分析

- 时间复杂度：对于每个数据集，需要遍历 $n+1$ 个系数，每次进行一次幂运算（ $O(1)$ ），因此总复杂度为 $O(n)$ ，在 $n < 100$ 的情况下非常高效。
- 空间复杂度： $O(n)$ ，用于存储系数。
