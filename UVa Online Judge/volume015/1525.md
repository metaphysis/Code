## 题目描述

本题描述了一个关于**字母二叉搜索树**（$\texttt{Binary Search Tree of Letters}$）的特殊操作过程，我们需要根据这个过程的输出结果来**重构原始二叉搜索树**，并输出其**前序遍历**结果。

### 操作过程
1. 从一棵字母二叉搜索树开始。
2. 移除当前树的所有**叶子节点**（即左右子树均为空的节点），并按字母顺序记录被移除的字母。
3. 重复步骤 2，直到树为空。

### 输入格式
- 输入包含多个数据集。
- 每个数据集由若干行组成，每行包含一组按字母顺序排列的大写字母，表示一轮操作中被移除的叶子节点。
- 数据集之间用一个仅包含星号 `*` 的行分隔。
- 最后一个数据集后用一个仅包含美元符号 `$` 的行表示输入结束。
- 输入中不含空格或空行。

### 输出格式
- 对于每个数据集，输出一行，即重构出的二叉搜索树的**前序遍历**结果（无空格）。

### 样例输入
```
BDHPY
CM
GQ
K
*
AC
B
$
```

### 样例输出
```
KGCBDHQMPY
BAC
```

## 题目分析与解题思路

### 1. 问题本质理解

本题的核心是一个**逆向构造二叉搜索树**的问题。  
我们已知的是：在一系列“回合”中，每次移除当前树的所有叶子节点，并按字母顺序输出这些叶子节点。  
我们需要根据这些输出序列，**反向推导**出原始的二叉搜索树。

### 2. 关键观察

1. **最后一轮移除的节点是原树的根节点**（当树只剩一个节点时）。  
   更一般地，**最后一轮移除的节点是最后剩下的节点**，这些节点在构造过程中是**最先被插入**的。
2. 输入中每行的字母是**按字母顺序排序**的，这是由二叉搜索树的性质决定的：
   - 对于任意节点，左子树的所有节点字母小于该节点，右子树的所有节点字母大于该节点。
   - 当我们在同一轮移除多个叶子节点时，它们来自树的不同部分，但按字母顺序收集在一起。
3. **构造顺序**：  
   如果我们从最后一轮（即输入的最后一行）开始，逐步向前处理，那么每个节点都会在**其子节点之前**被插入到树中。  
   这符合二叉搜索树的**自顶向下**构造逻辑。

### 3. 逆向构造算法

我们可以采用以下步骤进行构造：

1. 读取一个数据集的所有行，存储在一个向量中，顺序为从第一轮到最后一轮。
2. **从最后一行开始向前处理**（即从最后一轮到第一轮）。
3. 对于每一行的每个字母：
   - 按照二叉搜索树的规则，将其插入到当前已构建的树中。
   - 插入规则：从根节点开始，若待插入字母小于当前节点字母，则进入左子树；否则进入右子树，直到找到空位置插入。
4. 全部插入完成后，对树进行**前序遍历**，得到结果。

### 4. 为什么这样做是正确的？

- **逆序插入**保证了**父节点先于子节点**被插入。  
  最后一轮移除的节点是最后剩下的节点，即最深层的节点（或根节点），因此它们应该最先被插入，作为后续节点的父节点或祖先。
- **$\texttt{BST}$ 插入规则**保证了树的唯一性。  
  对于一组给定的节点，按固定顺序插入到 $\texttt{BST}$ 中，最终树的结构是唯一的。
- 由于输入数据本身来源于一棵合法的 $\texttt{BST}$，因此逆序插入一定能够重构出唯一的原始树。

### 5. 时间复杂度分析

- 每个节点插入一次，插入复杂度为 $O(h)$，其中 $h$ 是当前树的高度。
- 最坏情况下（输入完全有序），树退化为链表，$h = O(n)$，总复杂度 $O(n^2)$。
- 在本题数据范围内（节点数较少），此复杂度完全可接受。

```cpp
// Falling Leaves

#include <bits/stdc++.h>
using namespace std;

// BST 结点定义
struct TreeNode {
    char data;
    TreeNode* left;
    TreeNode* right;
    TreeNode(char c) : data(c), left(nullptr), right(nullptr) {}
};

// 向 BST 插入一个字符
TreeNode* insertBST(TreeNode* root, char ch) {
    if (root == nullptr) return new TreeNode(ch);
    if (ch < root->data) root->left = insertBST(root->left, ch);
    else root->right = insertBST(root->right, ch);
    return root;
}

// 前序遍历并收集结果
void preorderTraversal(TreeNode* root, string& result) {
    if (root == nullptr) return;
    result.push_back(root->data);
    preorderTraversal(root->left, result);
    preorderTraversal(root->right, result);
}

int main() {
    string line;
    vector<vector<string>> allDataSets;

    // 读取所有数据集
    while (true) {
        vector<string> dataSet;
        while (cin >> line && line != "*" && line != "$") dataSet.push_back(line);
        allDataSets.push_back(dataSet);
        if (line == "$") break;
    }

    // 处理每个数据集
    for (const auto& dataSet : allDataSets) {
        TreeNode* root = nullptr;
        // 逆序插入：从最后一轮开始
        for (auto it = dataSet.rbegin(); it != dataSet.rend(); ++it) {
            for (char ch : *it) root = insertBST(root, ch);
        }
        string result;
        preorderTraversal(root, result);
        cout << result << endl;
    }

    return 0;
}
```

## 总结

本题是一道典型的**逆向构造二叉搜索树**问题，通过观察操作过程的特性（叶子移除顺序与树结构的关系），我们可以设计出简洁高效的构造算法。  
核心在于**逆序插入**和 **$\texttt{BST}$ 标准插入规则**的结合，确保了重构的唯一性和正确性。  
代码实现简洁明了，适合作为二叉搜索树和递归遍历的练习题目。

**关键点回顾**：
- 逆序处理输入行（从最后一行到第一行）。
- 每行内部按字母顺序，但插入时按 $\texttt{BST}$ 规则。
- 前序遍历输出结果。

本题不仅考察对 $\texttt{BST}$ 的理解，也锻炼了逆向思维和递归编程能力。
