## 题目描述

给定一个标准的 $12$ 小时制模拟时钟，包含时针和分针。要求计算在给定的时间区间内，分针追上时针（即从后面赶上）的次数。

### 输入格式
- 输入包含多行，每行包含四个整数
- 前两个数表示起始时间（小时和分钟），后两个数表示结束时间（小时和分钟）
- 小时范围为 $1$ 到 $12$，分钟范围为 $0$ 到 $59$
- 起始时间和结束时间不会正好是分针与时针重合的时刻
- 起始时间与结束时间不同
- 时针在起始到结束时间内转动角度小于 $360$ 度

### 输出格式
- 每行输出起始时间、结束时间和分针追上时针的次数
- 时间格式为 $\texttt{hh:mm}$，小时和分钟都用 $2$ 位数字表示

## 题目分析

### 分针与时针重合的规律

在 $12$ 小时制时钟中：
- 分针每分钟转动 $6$ 度
- 时针每分钟转动 $0.5$ 度  
- 分针相对于时针的角速度为 $6 - 0.5 = 5.5$ 度/分钟

分针与时针重合的条件是它们之间的角度差为 $360$ 度的整数倍。设从 $12:00$ 开始经过 $t$ 分钟后两针重合，则有：

$$
6t \equiv 0.5t \pmod{360}
$$

化简得：

$$
5.5t = 360k \quad (k \in \mathbb{Z})
$$

$$
t = \frac{720}{11}k
$$

在 $12$ 小时（$720$ 分钟）内，$k$ 的取值范围为 $0$ 到 $10$，共 $11$ 次重合。

### 关键观察

1. **重合时刻**：分针与时针在以下时刻重合（从 $12:00$ 开始计算）：
   $$
   T_k = \frac{720}{11}k \quad (k = 0,1,2,\dots,10)
   $$

2. **时间区间处理**：
   - 如果结束时间小于起始时间，说明时间跨过了 $12$ 点
   - 此时需要将结束时间加上 $720$ 分钟（$12$ 小时）来处理

3. **计数方法**：
   - 将起始时间和结束时间都转换为从 $12:00$ 开始的分钟数
   - 检查所有重合时刻 $T_k$ 是否在区间 $(start, end)$ 内
   - 对于跨 $12$ 点的情况，还需要考虑下一周期的重合时刻

## 算法步骤

1. 读取起始时间 $(h_1, m_1)$ 和结束时间 $(h_2, m_2)$
2. 转换为从 $12:00$ 开始的分钟数：
   - $start = (h_1 \bmod 12) \times 60 + m_1$
   - $end = (h_2 \bmod 12) \times 60 + m_2$
3. 如果 $end \leq start$，说明跨过 $12$ 点，将 $end$ 加上 $720$
4. 初始化计数器 $count = 0$
5. 遍历 $k = 0$ 到 $20$（覆盖当前周期和下一周期）：
   - 计算重合时刻 $meet = \frac{720}{11}k$
   - 如果 $start < meet < end$，则 $count$ 加 $1$
   - 如果 $meet > end + 1$，提前退出循环
6. 输出格式化结果

## 复杂度分析
- 时间复杂度：$O(1)$，循环最多执行 $21$ 次
- 空间复杂度：$O(1)$，只使用常数个变量

using namespace std;

int main() {
    int h1, m1, h2, m2;
    // 注意，题目描述中并未提到需要输出此行信息，若不输出，无法获得 Accepted
    cout << "Program 3 by team X\n";
    // 输出表头
    cout << "Initial time  Final time  Passes" << endl;
    while (cin >> h1 >> m1 >> h2 >> m2) {
        // 转换为从12:00开始的分钟数
        int start = (h1 % 12) * 60 + m1;
        int end = (h2 % 12) * 60 + m2;
        bool crossed_12 = false;
        // 如果结束时间小于起始时间，表示跨过12点
        if (end <= start) {
            end += 720; // 12小时
            crossed_12 = true;
        }
        int count = 0;
        // 检查所有可能的k值，直到覆盖整个区间
        for (int k = 0; k <= 20; k++) {
            double meet = 720.0 * k / 11;
            // 严格在开区间 (start, end) 内
            if (meet > start && meet < end) {
                count++;
            }
            // 如果已经超出区间范围，提前退出
            if (meet > end + 1) break;
        }
        // 输出，严格按照题目格式
        // 注意：小时部分用空格填充，分钟部分用0填充
        cout << "       " 
             << setw(2) << setfill('0') << h1 << ":" 
             << setw(2) << setfill('0') << m1
             << "       "
             << setw(2) << setfill('0') << h2 << ":" 
             << setw(2) << setfill('0') << m2
             << setw(8) << setfill(' ') << count << endl;
    }
    // 注意，题目描述中并未提到需要输出此行信息，若不输出，无法获得 Accepted
    cout << "End of program 3 by team X\n";
    return 0;
}

## 总结

本题的关键在于理解分针与时针重合的数学规律，以及正确处理时间区间（特别是跨 $12$ 点的情况）。通过将时间统一转换为从 $12:00$ 开始的分钟数，可以简化重合时刻的判断。算法的时间复杂度和空间复杂度都是常数级别，效率很高。
