## 题目描述

$\texttt{Extreme}$ 博士制作了一台高精度望远镜来观测遥远现象。望远镜的横截面是一个半径为 $1$ 的完美圆形。为了测量磁通量变化的影响，他需要沿着圆周上固定的点用细导线形成一个多边形线圈。圆周上有 $n$ 个固定点，位置用参数 $p_i$ 表示，满足 $0 \leq p_1 < p_2 < \cdots < p_n < 1$ ，其中 $p_i$ 对应旋转角度 $2\pi p_i$ 弧度。

现在需要从这 $n$ 个点中选出恰好 $m$ 个点，形成一个 $m$ 边形，使得该多边形的面积最大。多边形顶点必须按圆周上的顺序排列（不自交）。

已知半径为 $1$ 的圆中，内角为 $\alpha$ 弧度的等腰三角形（两腰长为 $1$ ）面积为 $\frac{1}{2}\sin\alpha$ 。

## 输入格式

输入包含多个测试用例，每个测试用例格式如下：
```
n m
p1 p2 ... pn
```
其中 $3 \leq n \leq 40$ ， $3 \leq m \leq n$ 。输入以一行 `0 0` 结束。

## 输出格式

对于每个测试用例，输出最大面积，保留 $6$ 位小数，误差不超过 $10^{-6}$ 。

## 题目分析

### 1. 问题本质

这是一个在圆周上选择点构成最大面积多边形的问题。由于圆周半径为 $1$ ，我们可以利用圆心角来计算面积。

### 2. 面积计算公式

对于按顺序排列的顶点 $\theta_0, \theta_1, \ldots, \theta_{m-1}$ （单位：弧度），多边形面积可以通过将多边形划分为以圆心为顶点的 $m$ 个三角形来计算：

$$
\texttt{Area} = \frac{1}{2} \sum_{i=0}^{m-1} \sin(\theta_{i+1} - \theta_i)
$$

其中 $\theta_m = \theta_0 + 2\pi$ ，确保多边形闭合。

这个公式的推导基于：每个三角形由圆心和两个相邻多边形顶点组成，三角形的面积为 $\frac{1}{2}\sin(\Delta\theta)$ ，其中 $\Delta\theta$ 是两顶点间的圆心角。

### 3. 问题难点

1. **圆周循环性** ：点分布在圆周上，第一个点和最后一个点需要连接闭合。
2. **顺序限制** ：多边形顶点必须按角度递增顺序选取，避免自交。
3. **组合优化** ：从 $n$ 个点中选 $m$ 个点，组合数为 $C_n^m$ ，在 $n=40, m=20$ 时达到最大约 $1.37 \times 10^{11}$ ，不能暴力枚举。

### 4. 解题思路

考虑动态规划解决。由于圆周的循环性，我们可以**固定第一个顶点**，然后考虑从该顶点开始按角度顺序选择后续顶点。

**动态规划状态定义** ：设 $dp[i][k]$ 表示以第 $i$ 个点为当前链的最后一个顶点，已经选取了 $k$ 个顶点时的最大面积（从固定的第一个点开始）。

**转移方程** ：
$$
dp[i][k] = \max_{j < i} \left( dp[j][k-1] + \frac{1}{2} \sin(\theta_i - \theta_j) \right)
$$
其中 $\theta_i$ 和 $\theta_j$ 是点的弧度角，且 $j$ 必须在 $i$ 之前（角度更小）。

**初始化** ：当 $k=1$ 时，只有第一个点，面积 $dp[start][1] = 0$ 。

**闭合处理** ：当选取了 $m$ 个顶点后，需要连接最后一个顶点回到第一个顶点：
$$
\text{总面积} = dp[i][m] + \frac{1}{2} \sin(\theta_{start} + 2\pi - \theta_i)
$$

**枚举起始点** ：由于第一个顶点不确定，需要枚举所有点作为起始点。对于每个起始点，将点按角度重新排序（从起始点开始，到起始点之前结束，角度加上 $2\pi$ 偏移），然后进行动态规划 。

### 5. 算法复杂度

- 枚举起始点： $O(n)$
- 状态数： $O(n \times m)$
- 转移： $O(n^2 \times m)$

总复杂度 $O(n^3 \times m)$ ，在 $n \leq 40$ 时可行。

### 6. 精度处理

- 使用 `double` 类型存储角度和面积。
- 圆周率 $\pi$ 使用高精度值 $3.14159265358979323846$ 。
- 输出保留 $6$ 位小数。

## 代码实现

```cpp
// Telescope

#include <bits/stdc++.h>
using namespace std;

const double PI = 3.14159265358979323846;
const double TWO_PI = 2.0 * PI;

// 计算最大多边形面积
double maxPolygonArea(int n, int m, vector<double>& p) {
    if (m < 3) return 0.0;
    
    // 将位置参数转换为弧度角
    vector<double> angle(n);
    for (int i = 0; i < n; ++i)
        angle[i] = p[i] * TWO_PI;
    
    double maxArea = 0.0;
    
    // 枚举第一个顶点
    for (int start = 0; start < n; ++start) {
        // 创建从start开始的角度序列，处理圆周循环
        vector<double> sortedAngles;
        for (int i = start; i < n; ++i)
            sortedAngles.push_back(angle[i]);
        for (int i = 0; i < start; ++i)
            sortedAngles.push_back(angle[i] + TWO_PI);
        
        int cnt = sortedAngles.size();
        if (cnt < m) continue;  // 点数不足
        
        // DP数组，初始化为负无穷大
        vector<vector<double>> dp(cnt, vector<double>(m + 1, -1e9));
        dp[0][1] = 0.0;  // 第一个点（起始点）单独一个点，面积为0
        
        // DP转移
        for (int k = 2; k <= m; ++k) {
            for (int i = k - 1; i < cnt; ++i) {
                for (int j = k - 2; j < i; ++j) {
                    // 计算三角形面积：0.5 * sin(角度差)
                    double triangleArea = 0.5 * sin(sortedAngles[i] - sortedAngles[j]);
                    dp[i][k] = max(dp[i][k], dp[j][k - 1] + triangleArea);
                }
            }
        }
        
        // 闭合多边形：连接最后一个顶点回到起始点
        // 起始点角度需要加上2π，因为sortedAngles[0]是原始起始点角度
        double startAngle = sortedAngles[0] + TWO_PI;
        for (int i = m - 1; i < cnt; ++i) {
            if (dp[i][m] < -1e8) continue;  // 不可达状态
            double closeArea = 0.5 * sin(startAngle - sortedAngles[i]);
            maxArea = max(maxArea, dp[i][m] + closeArea);
        }
    }
    
    return maxArea;
}

int main() {
    int n, m;
    while (cin >> n >> m, n || m) {
        vector<double> p(n);
        for (int i = 0; i < n; ++i)
            cin >> p[i];
        // 确保输入已排序，题目保证但再次排序更安全
        sort(p.begin(), p.end());
        double ans = maxPolygonArea(n, m, p);
        printf("%.6lf\n", ans);
    }
    return 0;
}
```

## 代码说明

1. **角度转换** ：将输入的 $p_i$ 乘以 $2\pi$ 得到弧度角。
2. **枚举起始点** ：外层循环枚举每个点作为多边形的第一个顶点。
3. **重新排序** ：对于每个起始点，创建新的角度序列，从起始点开始，到起始点之前结束，后部分的角度加上 $2\pi$ 偏移，确保角度单调递增且覆盖整个圆周。
4. **动态规划** ：使用三维循环实现动态规划转移，注意下标范围限制确保顶点顺序。
5. **闭合处理** ：计算最后一个顶点与起始点（加上 $2\pi$ 偏移）之间的三角形面积，加到动态规划值上得到总面积。
6. **精度控制** ：使用 `printf` 输出 $6$ 位小数。
