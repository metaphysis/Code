## 题目描述

黑客 $\texttt{Bill}$ 不小心丢失了工作站硬盘上的所有信息，而且没有任何备份。虽然文件内容无法恢复，但他希望能够重建多年精心维护的目录结构。幸运的是，他保留了几份目录列表的副本，从中恢复出了一些目录的完整路径（如 `WINNT\SYSTEM32\CERTSRV\CERTC0-1\X86`）。

你的任务是根据这些路径信息，重建并输出格式化的目录树结构。

### 输入格式

- 多个数据集，每个数据集包含：
  - 第一行：整数 $N$ ($1 \leq N \leq 500$)，表示不同目录路径的数量
  - 接下来 $N$ 行：每行一个目录路径，不包含空格
  - 路径由反斜杠 `\` 分隔的目录名组成
  - 每个目录名由 $1$ 到 $8$ 个字符组成（大写字母、数字或特定特殊字符）
- 数据集之间用空行分隔

### 输出格式

- 格式化输出目录树
- 每个目录名单独一行
- 子目录比父目录多一个前导空格
- 同级目录按字典序排列
- 数据集之间用空行分隔

### 示例

**输入：**
```
7
WINNT\SYSTEM32\CONFIG
GAMES
WINNT\DRIVERS
HOME
WIN\SOFT
GAMES\DRIVERS
WINNT\SYSTEM32\CERTSRV\CERTC0-1\X86
```

**输出：**
```
GAMES
 DRIVERS
HOME
WIN
 SOFT
WINNT
 DRIVERS
 SYSTEM32
  CERTSRV
   CERTCO-1
    X86
  CONFIG
```

## 题目分析

### 问题本质

这是一个典型的**树形结构构建与遍历**问题。我们需要：

1. 将扁平的路径列表转换为层次化的树形结构
2. 维护目录间的父子关系
3. 按特定顺序和格式输出目录树

### 关键难点

1. **路径解析**：需要正确处理反斜杠分隔的路径字符串
2. **树形结构构建**：高效地建立目录间的层次关系
3. **字典序排序**：同级目录必须按字典序排列
4. **格式化输出**：根据深度控制缩进空格数量

### 数据结构选择

考虑到目录树的特性，我们选择使用 **字典树（$\texttt{Trie}$）** 结构：

- 每个节点代表一个目录
- 节点的子节点映射存储该目录下的所有直接子目录
- 使用 `map` 或 `unordered_map` 来维护子目录，便于自动排序和快速查找

## 解题思路

### 步骤一：路径解析

对于每个路径字符串，使用反斜杠 `\` 作为分隔符进行拆分：
```
WINNT\SYSTEM32\CONFIG → ["WINNT", "SYSTEM32", "CONFIG"]
```

### 步骤二：树形结构构建

采用字典树的方式插入每个路径：

1. 从根节点开始
2. 对于路径中的每个目录名：
   - 如果当前节点没有该子目录，创建新节点
   - 移动到对应的子节点
3. 重复直到处理完整个路径

### 步骤三：格式化输出

使用深度优先遍历（$\texttt{DFS}$）递归输出：

1. 对当前节点的所有子目录名按字典序排序
2. 对于每个子目录：
   - 输出当前深度的缩进空格
   - 输出目录名
   - 递归处理该目录的子目录，深度加 $1$

### 算法复杂度分析

- **时间复杂度**：$O(N \times L \times \log M)$
  - $N$：路径数量
  - $L$：路径平均长度
  - $M$：节点平均子节点数
  - 主要开销在排序和树操作
- **空间复杂度**：$O(N \times L)$，用于存储目录树结构

```cpp
#include <iostream>
#include <string>
#include <map>
#include <vector>
#include <sstream>
#include <algorithm>

using namespace std;

// 目录树节点
struct Directory {
    map<string, Directory*> children;
    
    ~Directory() {
        for (auto& child : children) {
            delete child.second;
        }
    }
};

// 分割路径
vector<string> splitPath(const string& path) {
    vector<string> result;
    stringstream ss(path);
    string item;
    
    while (getline(ss, item, '\\')) {
        result.push_back(item);
    }
    
    return result;
}

// 插入路径到目录树
void insertPath(Directory* root, const vector<string>& path) {
    Directory* current = root;
    
    for (const string& dir : path) {
        if (current->children.find(dir) == current->children.end()) {
            current->children[dir] = new Directory();
        }
        current = current->children[dir];
    }
}

// 递归打印目录树
void printTree(Directory* node, int depth = 0) {
    // 按字典序排序子目录名
    vector<string> dirNames;
    for (const auto& child : node->children) {
        dirNames.push_back(child.first);
    }
    sort(dirNames.begin(), dirNames.end());
    
    // 打印当前深度的所有目录
    for (const string& dirName : dirNames) {
        // 输出缩进
        for (int i = 0; i < depth; i++) {
            cout << " ";
        }
        // 输出目录名
        cout << dirName << endl;
        // 递归打印子目录
        printTree(node->children[dirName], depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int N;
    bool firstDataset = true;
    
    while (cin >> N) {
        // 跳过数据集之间的空行
        if (!firstDataset) {
            cout << endl;
        }
        firstDataset = false;
        
        // 读取换行符
        cin.ignore();
        
        Directory root;
        
        // 读取并处理所有路径
        for (int i = 0; i < N; i++) {
            string path;
            getline(cin, path);
            
            vector<string> pathComponents = splitPath(path);
            insertPath(&root, pathComponents);
        }
        
        // 打印目录树
        printTree(&root);
    }
    
    return 0;
}
```

## 总结

本题通过字典树结构优雅地解决了目录路径到树形结构的转换问题。关键点在于：

1. **选择合适的树形结构**来维护目录关系
2. **路径解析**时注意分隔符处理
3. **递归遍历**配合深度控制实现格式化输出
4. **字典序排序**确保输出符合要求

这种解法不仅高效正确，而且代码清晰易懂，体现了树形结构在层次数据处理中的优势。
