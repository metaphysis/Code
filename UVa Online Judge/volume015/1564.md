## 题目描述

小部件工厂生产 $n$ 种不同类型的小部件，制造每种类型的小部件所需时间介于 $3$ 到 $9$ 天之间。由于管理混乱，工厂无法确定每种小部件的具体制造时间。幸运的是，工厂保留了一些工人记录：每条记录包含工人开始工作的星期几、被解雇的星期几，以及在此期间制造的所有小部件类型序列（按制造顺序）。已知工人每周工作 $7$ 天，从开始工作到被解雇期间每天都不间断工作。请根据这些记录推断出每种小部件的制造时间。

**输入格式**  
输入包含多组测试数据，每组数据以一行 $n$ $m$ 开始，其中 $1 \le n, m \le 300$ 分别表示小部件类型数和记录数。随后是 $m$ 条记录，每条记录占两行：第一行包含整数 $k$ （$1 \le k \le 10000$） 以及两个星期字符串（如 $\texttt{MON}$ , $\texttt{TUE}$ 等），分别表示该工人制造的小部件总数、开始工作的星期几和被解雇的星期几；第二行包含 $k$ 个介于 $1$ 和 $n$ 之间的整数，表示按制造顺序的小部件类型序列。输入以 $n = m = 0$ 结束。

**输出格式**  
对于每组测试数据，输出一行。如果存在唯一解，输出 $n$ 个介于 $3$ 和 $9$ 之间的整数（用空格分隔），表示每种小部件的制造时间；如果存在多个解，输出 `Multiple solutions.` ；如果无解，输出 `Inconsistent data.` 。

## 问题分析

本题的核心在于从工人记录中建立关于小部件制造时间的方程组，并求解这个方程组。每个工人记录提供了以下信息：

1.  **时间跨度约束** ：从开始日到结束日所经过的总天数（模 $7$ ）等于该工人制造的所有小部件的制造时间之和（模 $7$ ）。  
    设开始日为星期 $s$ ，结束日为星期 $e$ （将星期映射为数字：$\texttt{MON}=0, \texttt{TUE}=1, \dots, \texttt{SUN}=6$ ），则经过的天数为 $(e - s + 7) \bmod 7$ 。需要注意的是，由于题目说明工人从开始日到结束日每天工作，因此实际经过天数为 $(e - s + 1) \bmod 7$ （当 $e \ge s$ 时）或 $(e - s + 8) \bmod 7$ （当 $e < s$ 时）。代码中采用 $(e - s + 8) \bmod 7$ 统一处理，因为 $(e - s + 8) \bmod 7 = (e - s + 1) \bmod 7$ （模 $7$ 意义下）。

2.  **制造时间求和** ：设第 $i$ 种小部件的制造时间为 $x_i$ （未知数，$3 \le x_i \le 9$），工人制造的第 $j$ 个小部件类型为 $t_j$ ，则该工人制造的总时间为 $\sum_{j=1}^{k} x_{t_j}$ 。在模 $7$ 意义下，有：
    $$
    \sum_{j=1}^{k} x_{t_j} \equiv (e - s + 8) \bmod 7
    $$

3.  **建立线性方程组** ：将每种小部件类型的制造次数统计出来，设工人 $p$ 制造类型 $i$ 的小部件数量为 $c_{p,i}$ ，则对应该工人的方程为：
    $$
    \sum_{i=1}^{n} c_{p,i} \cdot x_i \equiv d_p \pmod{7}
    $$
    其中 $d_p = (e_p - s_p + 8) \bmod 7$ 。

这样，我们得到了一个模 $7$ 的线性方程组，有 $m$ 个方程、$n$ 个未知数 $x_1, x_2, \dots, x_n$ 。由于模数 $7$ 是素数，我们可以使用高斯消元法在模 $7$ 下求解该方程组。

## 解题思路

### 1. 高斯消元法（模 $7$ ）

由于模 $7$ 是素数，我们可以在有限域 $\mathbb{F}_7$ 上进行高斯消元。步骤如下：

- **消元过程** ：遍历每一列，选择当前列中非零元素所在的行作为主元行，将其交换到当前行。然后，将该行的主元系数化为 $1$ （乘以模 $7$ 下的逆元）。接着，用该行消去其他行中当前列的元素（模 $7$ 运算）。
- **记录变量位置** ：用数组 $\texttt{where}$ 记录每个变量在消元后所在的行号，若变量未出现在任何方程的主元位置，则为自由变量。
- **回代求解** ：消元完成后，若某行出现 $0 = \text{非零}$ 的情况，则方程组无解。否则，从最后一个非零行开始回代，得到每个变量的模 $7$ 解。

### 2. 解的存在性与唯一性判定

- **无解** ：在高斯消元过程中，若某行所有系数为 $0$ 而右侧常数不为 $0$ ，则方程组无解。
- **唯一解** ：若消元后非零行数等于变量数 $n$ ，且每个变量都有唯一的主元行，则方程组有唯一解（在模 $7$ 意义下）。
- **多解** ：若存在自由变量（即某个变量没有对应的主元行），则方程组在模 $7$ 意义下有多解。此时，由于题目要求输出整数解（且每个 $x_i$ 必须在 $3$ 到 $9$ 之间），我们还需进一步判断：
    - 对于自由变量，它可以取模 $7$ 下的任意值（$0$ 到 $6$），每个模值对应到 $3$ 到 $9$ 之间的可能天数（可能对应多个天数，例如模 $0$ 对应 $7$ ，模 $1$ 对应 $1$ 或 $8$ ，但 $1$ 不在 $3$–$9$ 范围内，所以实际上只有 $8$ 符合条件）。因此，自由变量的存在通常意味着多解，除非所有可能的赋值都会导致某些变量超出 $3$–$9$ 的范围。

### 3. 解的转换与验证

由于我们求解的是模 $7$ 意义下的解，而实际需要的解是 $3$ 到 $9$ 之间的整数，因此需要将模解转换为实际天数：

- 对于每个变量 $x_i$ ，其模 $7$ 值为 $v_i$ 。我们需要在 $3$ 到 $9$ 之间找到一个整数 $d$ ，使得 $d \bmod 7 = v_i$ 。如果找不到这样的 $d$ ，则该解无效（无解）。
- 对于唯一解的情况，我们只需为每个变量找到满足条件的 $d$ 即可。如果存在某个变量找不到对应的 $d$ ，则输出 `Inconsistent data.` 。
- 对于多解的情况（存在自由变量），我们直接输出 `Multiple solutions.` ，无需进一步枚举。这是因为在模 $7$ 意义下存在多个解时，通常对应多个不同的整数解（在 $3$–$9$ 范围内），除非所有可能的整数解都落在范围外，但这种情况极少见，且题目要求只需判断是否有多解，并不需要输出具体解。

### 4. 算法流程总结

1. 读入 $n$ 和 $m$ 。
2. 对于每条工人记录：
   - 将开始日和结束日转换为数字 $s$ 和 $e$ 。
   - 计算右侧常数 $d = (e - s + 8) \bmod 7$ 。
   - 统计该工人制造每种小部件的数量 $c_i$ （模 $7$ ），建立方程。
3. 构建增广矩阵 $m \times (n+1)$ ，进行模 $7$ 高斯消元。
4. 根据消元结果判断：
   - 若出现矛盾，输出 `Inconsistent data.` 。
   - 若存在自由变量，输出 `Multiple solutions.` 。
   - 若为唯一解，则将每个变量的模 $7$ 值转换为 $3$–$9$ 之间的整数，若转换成功则输出，否则输出 `Inconsistent data.` 。

## 复杂度分析

- **时间复杂度** ：高斯消元的时间复杂度为 $O(m \cdot n \cdot \min(m, n))$ ，在本题中 $n, m \le 300$ ，因此消元过程是可行的。
- **空间复杂度** ：需要存储 $m \times (n+1)$ 的矩阵，空间复杂度为 $O(m \cdot n)$ 。

```cpp
// Widget Factory

#include <bits/stdc++.h>
using namespace std;

const int MOD = 7;
const int MIN_DAY = 3;
const int MAX_DAY = 9;

// 将星期字符串转换为数字（0-6）
int dayToInt(const string& s) {
    if (s == "MON") return 0;
    if (s == "TUE") return 1;
    if (s == "WED") return 2;
    if (s == "THU") return 3;
    if (s == "FRI") return 4;
    if (s == "SAT") return 5;
    return 6;
}

// 求模 MOD 下的逆元，由于 MOD=7 是素数，直接枚举即可
int inv(int a) {
    for (int i = 0; i < MOD; i++) if ((a * i) % MOD == 1) return i;
    return 0;
}

// 高斯消元求解模线性方程组，返回：0无解，1唯一解，2多解
int gauss(vector<vector<int>>& a, vector<int>& ans, int n, int m) {
    int row = 0;
    vector<int> where(m, -1);
    
    // 消元过程
    for (int col = 0; col < m && row < n; col++) {
        // 选择主元行
        int sel = row;
        for (int i = row; i < n; i++) if (a[i][col] > a[sel][col]) sel = i;
        if (a[sel][col] == 0) continue; // 该列全零，跳过（自由变量）
        // 交换到当前行
        for (int j = col; j <= m; j++) swap(a[sel][j], a[row][j]);
        where[col] = row; // 记录变量 col 所在的行
        
        // 将主元系数化为 1
        int invVal = inv(a[row][col]);
        for (int j = col; j <= m; j++) a[row][j] = a[row][j] * invVal % MOD;
        
        // 消去其他行的当前列
        for (int i = 0; i < n; i++) if (i != row) {
            int c = a[i][col];
            if (c == 0) continue;
            for (int j = col; j <= m; j++) {
                a[i][j] = (a[i][j] - c * a[row][j]) % MOD;
                if (a[i][j] < 0) a[i][j] += MOD;
            }
        }
        row++;
    }
    
    // 初始化解向量
    ans.assign(m, 0);
    for (int i = 0; i < m; i++) if (where[i] != -1) 
        ans[i] = a[where[i]][m] * inv(a[where[i]][i]) % MOD;
    
    // 验证解是否满足所有方程
    for (int i = 0; i < n; i++) {
        int sum = 0;
        for (int j = 0; j < m; j++) sum = (sum + a[i][j] * ans[j]) % MOD;
        if (sum != a[i][m]) return 0; // 无解
    }
    
    // 检查是否有自由变量
    for (int i = 0; i < m; i++) if (where[i] == -1) return 2; // 多解
    
    return 1; // 唯一解
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    while (cin >> n >> m, n || m) {
        // 增广矩阵：m 行，n 列系数 + 1 列常数
        vector<vector<int>> a(m, vector<int>(n + 1, 0));
        
        for (int i = 0; i < m; i++) {
            int k; string s, t;
            cin >> k >> s >> t;
            int start = dayToInt(s), end = dayToInt(t);
            // 计算右侧常数：经过的天数模 7
            a[i][n] = (end - start + 8) % MOD; // +8 等价于 +1 mod 7
            
            // 统计每种小部件的制造次数（模 7）
            vector<int> cnt(n, 0);
            for (int j = 0; j < k; j++) {
                int x; cin >> x;
                cnt[x - 1]++;
            }
            for (int j = 0; j < n; j++) a[i][j] = cnt[j] % MOD;
        }
        
        vector<int> ans(n);
        int res = gauss(a, ans, m, n);
        
        if (res == 0) {
            // 无解
            cout << "Inconsistent data.\n";
        } else if (res == 2) {
            // 多解
            cout << "Multiple solutions.\n";
        } else {
            // 唯一解，将模 7 值转换为 3-9 之间的天数
            bool valid = true;
            for (int i = 0; i < n; i++) {
                int val = ans[i];
                bool found = false;
                for (int d = MIN_DAY; d <= MAX_DAY; d++) {
                    if (d % MOD == val) {
                        ans[i] = d;
                        found = true;
                        break;
                    }
                }
                if (!found) {
                    valid = false;
                    break;
                }
            }
            
            if (!valid) {
                cout << "Inconsistent data.\n";
            } else {
                for (int i = 0; i < n; i++) {
                    if (i) cout << " ";
                    cout << ans[i];
                }
                cout << "\n";
            }
        }
    }
    
    return 0;
}
```

## 总结

本题通过将实际工作记录转化为模 $7$ 线性方程组，利用高斯消元法求解，并根据解的结构判断解的存在性与唯一性。关键在于理解模 $7$ 运算的性质以及自由变量与多解之间的关系。代码实现时需要注意模运算的细节，特别是求逆元和消元过程中的模处理。最终算法能够在题目限制范围内高效运行。
