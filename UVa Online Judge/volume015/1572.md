[UVa 1572 Self-Assembly](https://blog.csdn.net/metaphysis/article/details/153690328)

## 题目描述

自动化学制造正在实验一种称为自组装的过程。在这个过程中，具有天然亲和力的分子在溶液中混合，并自发组装成更大的结构。但存在一个问题：有时分子会组装成无限大的结构，这会堵塞机器。

你需要编写一个程序来判断给定的分子集合是否可以组装成无限大的结构。我们做两个简化假设：
1. 问题限制在二维空间
2. 每个分子表示为正方形，正方形的四条边代表该分子可以连接到其他兼容分子的表面

## 输入格式

输入包含多个测试用例。每个测试用例有两行：
- 第一行：整数 $n$ ($1 \leq n \leq 40000$)，表示分子类型的数量
- 第二行：$n$ 个八字符字符串，每个字符串描述一个分子类型，字符串之间用空格分隔

每个字符串由四个双字符的连接标签组成，按顺时针顺序表示分子的四条边。

## 输出格式

对于每个测试用例，如果分子类型集合可以生成无限大的结构，输出 `unbounded`；否则输出 `bounded`。

## 题目分析

### 连接规则

每个分子的边有三种可能的标签：
- **字母+符号**：如 `A+`、`B-` 等
  - 兼容规则：相同字母、相反符号可以连接（如 `A+` 与 `A-`）
  - 相同字母、相同符号不能连接（如 `A+` 与 `A+`）
  - 不同字母不能连接（如 `A+` 与 `B-`）
- **00**：表示该边不能连接任何边（包括另一个 `00`）

### 关键观察

分子可以**任意旋转和翻转**，这意味着分子四条边的顺序可以任意排列。我们有无限多个每种类型的分子可用。

### 图论建模

这是一个经典的图论问题，可以转化为**有向图中的环检测**问题。

#### 节点表示
- 将每个可能的连接标签（除去 `00`）看作一个节点
- 共有 $26$ 个字母 × $2$ 种符号 = $52$ 个节点
- 编号方式：`A+` = $0$, `A-` = $1$, `B+` = $2$, `B-` = $3$, ..., `Z+` = $50$, `Z-` = $51$

#### 边表示
对于每个分子，考虑它的四条边（考虑所有旋转/翻转排列）：
- 对于任意两条不同的非 `00` 边 $e$ 和 $f$
- 添加有向边：$opposite(e) \rightarrow f$

**为什么这样建模？**
- 节点表示"需要的连接类型"
- 边表示"通过一个分子可以从一种连接需求转换到另一种连接需求"
- 如果存在环，就可以沿着环不断添加分子，结构可以无限增长

#### 环检测
- 在构建的有向图中进行深度优先搜索（$\texttt{DFS}$）
- 如果发现环，则输出 `unbounded`
- 否则输出 `bounded`

## 算法复杂度
- 节点数固定为 $52$
- 每个分子最多添加 $12$ 条边（$4 \times 3$）
- 总边数 $O(n)$
- 环检测复杂度 $O(V+E)$，其中 $V=52$，几乎是常数时间

## 代码实现

```cpp
// Self-Assembly
// UVa ID: 1572
// Verdict: Accepted
// Submission Date: 2025-10-21
// UVa Run Time: 0.140s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int NODES = 52; // A+ = 0, A- = 1, B+ = 2, B- = 3, ... Z+ = 50, Z- = 51

// 将字符标签转换为节点索引
int charToIndex(char letter, char sign) {
    int base = (letter - 'A') * 2;
    if (sign == '+') return base;
    else return base + 1;
}

// 获取相反符号的节点索引（利用异或操作）
int opposite(int idx) {
    return idx ^ 1; // 0<->1, 2<->3, ...
}

// 检测有向图中是否存在环
bool hasCycle(const vector<vector<int>>& graph) {
    int n = graph.size();
    vector<int> visited(n, 0); // 0=未访问, 1=在栈中, 2=已完成
    bool cycle = false;
    // 使用function包装递归lambda函数
    function<void(int)> dfs = [&](int u) {
        visited[u] = 1;
        for (int v : graph[u]) {
            if (visited[v] == 0) {
                dfs(v);
            } else if (visited[v] == 1) {
                cycle = true;
            }
            if (cycle) return;
        }
        visited[u] = 2;
    };
    for (int i = 0; i < n; i++) {
        if (visited[i] == 0) {
            dfs(i);
            if (cycle) return true;
        }
    }
    return false;
}

int main() {
    int n;
    while (cin >> n) {
        vector<vector<int>> graph(NODES);
        for (int i = 0; i < n; i++) {
            string mol;
            cin >> mol;
            // 分子长度为8字符，4个两字符标签
            int edges[4];
            for (int j = 0; j < 4; j++) {
                string label = mol.substr(j * 2, 2);
                if (label == "00") {
                    edges[j] = -1;
                } else {
                    edges[j] = charToIndex(label[0], label[1]);
                }
            }
            // 对分子上的每条非-1边，与其他非-1边建立 opposite(e) -> f
            for (int j = 0; j < 4; j++) {
                if (edges[j] == -1) continue;
                for (int k = 0; k < 4; k++) {
                    if (k == j || edges[k] == -1) continue;
                    graph[opposite(edges[j])].push_back(edges[k]);
                }
            }
        }
        if (hasCycle(graph)) {
            cout << "unbounded" << endl;
        } else {
            cout << "bounded" << endl;
        }
    }
    return 0;
}
```

## 总结

本题通过巧妙的图论建模，将分子自组装问题转化为有向图的环检测问题。核心思想是利用分子可以旋转翻转的特性，建立连接需求之间的转换关系。如果存在循环的转换路径，就能无限扩展结构。这种建模方法在解决组合优化和自组装问题时非常有效。
