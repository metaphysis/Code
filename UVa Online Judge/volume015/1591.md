## 题目分析

### 问题背景
$\texttt{Dr. Tuple}$ 正在为 $\texttt{ACM}$ 公司开发一个数据挖掘应用程序，其中包含两个数组 $P$ 和 $Q$，每个数组都有 $N$ 条记录。数组 $P$ 中的记录大小为 $S_P$ 字节，数组 $Q$ 中的记录大小为 $S_Q$ 字节。

### 核心问题
在访问数组 $Q$ 时，需要计算记录的字节偏移量。直接的计算公式为：
$$Qofs(i) = \frac{Pofs(i)}{S_P} \times S_Q$$
这个公式包含乘法和除法运算，在现代处理器上效率较低。

### 优化方案
$\texttt{Dr. Tuple}$ 提出了一个快速计算公式：
$$Qofs'(i) = (Pofs(i) + (Pofs(i) \ll A)) \gg B$$
其中：
- $\ll A$ 表示左移 $A$ 位（相当于乘以 $2^A$）
- $\gg B$ 表示右移 $B$ 位（相当于除以 $2^B$）

这个公式等价于：
$$Qofs'(i) = \left\lfloor \frac{Pofs(i) \times (1 + 2^A)}{2^B} \right\rfloor$$

### 任务目标
我们需要找到最优的 $A$ 和 $B$，使得：
1. 所有记录的 $Qofs'(i)$ 互不重叠
2. 所需内存 $K$ 最小
3. 如果多个 $(A,B)$ 得到相同的 $K$，选择 $A$ 最小的，再选择 $B$ 最小的

### 关键约束
为了保证记录不重叠，需要满足：
$$\frac{S_P \times (1 + 2^A)}{2^B} \ge S_Q$$

所需内存的计算公式为：
$$K = \left\lfloor \frac{(N-1) \times S_P \times (1 + 2^A)}{2^B} \right\rfloor + S_Q$$

### 算法思路
1. 枚举所有可能的 $A$ 和 $B$（范围设为 $0$ 到 $31$）
2. 检查是否满足约束条件 $S_P \times (1 + 2^A) \ge S_Q \times 2^B$
3. 如果满足条件，计算对应的 $K$ 值
4. 选择最小的 $K$，如果 $K$ 相同则按题目要求选择 $A$ 和 $B$

## 代码实现
```cpp
// Data Mining
// UVa ID: 1591
// Verdict: Accepted
// Submission Date: 2025-10-20
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <climits>

using namespace std;

int main() {
    long long N, SP, SQ;
    while (cin >> N >> SP >> SQ) {
        long long bestK = LLONG_MAX;  // 初始化最佳K为最大值
        int bestA = -1, bestB = -1;   // 初始化最佳A和B
        
        // 枚举所有可能的A和B
        for (int A = 0; A <= 31; A++) {
            for (int B = 0; B <= 31; B++) {
                // 检查是否满足不重叠条件
                if (SP * (1LL + (1LL << A)) >= SQ * (1LL << B)) {
                    // 计算所需内存K
                    long long K = ((N - 1) * SP * (1LL + (1LL << A))) / (1LL << B) + SQ;
                    // 更新最优解
                    if (K < bestK) {
                        bestK = K;
                        bestA = A;
                        bestB = B;
                    } else if (K == bestK) {
                        // K相同时，选择A较小的
                        if (A < bestA) {
                            bestA = A;
                            bestB = B;
                        } else if (A == bestA && B < bestB) {
                            // A相同时，选择B较小的
                            bestB = B;
                        }
                    }
                }
            }
        }
        // 输出结果
        cout << bestK << " " << bestA << " " << bestB << endl;
    }
    return 0;
}
```

## 复杂度分析
- 时间复杂度：$O(32 \times 32) = O(1024)$，对于每个测试数据都是常数时间
- 空间复杂度：$O(1)$，只使用了几个变量

该算法通过枚举所有可能的 $(A,B)$ 组合，确保找到满足条件的最优解，同时保证了高效性。
