## 题目分析

### 问题描述

给定一个包含 $n$ 个房间和 $m$ 条通道的无向图，每条通道有一个颜色值 $c_i$。参赛者从房间 $1$ 出发，目标是到达房间 $n$。比赛规则如下：

- 获胜者是路径长度最短（经过的通道数最少）的参赛者
- 如果有多个参赛者路径长度相同，则选择颜色序列字典序最小的路径（称为理想路径）

**字典序比较规则**：序列 $(a_1, a_2, \ldots, a_k)$ 比序列 $(b_1, b_2, \ldots, b_k)$ 字典序小，当且仅当存在某个位置 $i$，使得 $a_i < b_i$，且对于所有 $j < i$ 有 $a_j = b_j$。

### 输入格式

- 第一行：$n$ 和 $m$（$2 \leq n \leq 100000$, $1 \leq m \leq 200000$）
- 接下来 $m$ 行：每行三个整数 $a_i, b_i, c_i$，表示连接房间 $a_i$ 和 $b_i$ 的通道颜色为 $c_i$
- 保证从房间 $1$ 可以到达房间 $n$

### 输出格式

- 第一行：最短路径长度 $k$
- 第二行：理想路径的颜色序列（按经过顺序）

## 解题思路

### 核心挑战

这个问题需要在保证路径长度最短的前提下，进一步选择颜色序列字典序最小的路径。这是一个**双层优化**问题：

1. **第一层优化**：路径长度最短
2. **第二层优化**：在最短路径中颜色序列字典序最小

### 关键观察

1. **最短路径性质**：从房间 $n$ 反向进行 $\texttt{BFS}$，可以计算出每个房间到终点的最短距离
2. **分层构造**：从起点 $1$ 开始，按照 $\texttt{BFS}$ 层次逐层前进，在每一层选择颜色最小的边
3. **字典序保证**：由于路径是固定的长度，我们可以在每一层选择当前可能的最小颜色，这样构造出的颜色序列就是字典序最小的

### 算法步骤

#### 步骤 1：计算最短距离

从终点 $n$ 开始进行 $\texttt{BFS}$，计算每个节点到终点的最短距离 $dist[u]$。这样我们就知道哪些边位于最短路径上：对于边 $(u, v)$，如果 $dist[v] = dist[u] - 1$，则这条边可能在从 $u$ 到 $n$ 的最短路径上。

#### 步骤 2：构造理想路径

从起点 $1$ 开始，按照以下过程逐层构造路径：

1. **初始化**：当前层只包含起点 $1$
2. **逐层处理**：对于每一层，直到到达终点 $n$：
   - 找出从当前层所有节点出发，通往下一层（$dist[v] = dist[u] - 1$）的所有边的颜色
   - 选择这些颜色中的最小值
   - 将所有通过颜色等于最小值的边到达的节点加入下一层
   - 记录选择的颜色
3. **输出结果**：输出路径长度和颜色序列

### 复杂度分析

- **$\texttt{BFS}$ 计算距离**：$O(n + m)$
- **分层构造路径**：每层处理所有相关边，总体 $O(n + m)$
- **总复杂度**：$O(n + m)$，适合题目数据范围

### 算法正确性证明

1. **最短路径保证**：我们只沿着 $dist[v] = dist[u] - 1$ 的边前进，保证始终在最短路径上
2. **字典序最小保证**：在每一层都选择当前可能的最小颜色，由于路径长度固定，这种贪心策略可以保证整体字典序最小
3. **完整性保证**：我们考虑了所有可能的最短路径，不会遗漏任何候选

## 代码实现

```cpp
// Ideal Path
// UVa ID: 1599
// Verdict: Accepted

// UVa Run Time: 0.110s

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <cstring>
using namespace std;

const int MAXN = 100005;
const int INF = 1e9;

struct Edge {
    int to, color;
};

int n, m;
vector<Edge> graph[MAXN];
int dist[MAXN];
bool vis[MAXN];
vector<int> curLayer, nextLayer;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    while (cin >> n >> m) {
        for (int i = 1; i <= n; i++) {
            graph[i].clear();
        }

        for (int i = 0; i < m; i++) {
            int a, b, c;
            cin >> a >> b >> c;
            graph[a].push_back({b, c});
            graph[b].push_back({a, c});
        }

        // 从终点 n 开始 BFS，计算每个节点到终点的最短距离
        fill(dist, dist + n + 1, INF);
        queue<int> q;
        dist[n] = 0;
        q.push(n);

        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (const Edge& e : graph[u]) {
                if (dist[e.to] > dist[u] + 1) {
                    dist[e.to] = dist[u] + 1;
                    q.push(e.to);
                }
            }
        }

        // 从起点 1 开始构造理想路径
        fill(vis, vis + n + 1, false);
        curLayer.clear();
        curLayer.push_back(1);
        vis[1] = true;

        vector<int> colors;  // 存储理想路径的颜色序列

        // 按层处理，共 dist[1] 层（从 1 到 n 的步数）
        for (int step = 0; step < dist[1]; step++) {
            // 找出从当前层所有节点出发，通往下一层的边的最小颜色
            int minColor = INF;
            for (int u : curLayer) {
                for (const Edge& e : graph[u]) {
                    // 只考虑在最短路径上的边
                    if (dist[e.to] == dist[u] - 1) {
                        minColor = min(minColor, e.color);
                    }
                }
            }

            colors.push_back(minColor);  // 记录当前层选择的最小颜色

            // 收集所有通过最小颜色边到达的下一层节点
            nextLayer.clear();
            for (int u : curLayer) {
                for (const Edge& e : graph[u]) {
                    if (dist[e.to] == dist[u] - 1 && e.color == minColor && !vis[e.to]) {
                        vis[e.to] = true;
                        nextLayer.push_back(e.to);
                    }
                }
            }

            // 更新当前层为下一层，继续处理
            curLayer.swap(nextLayer);
            // 去重，避免重复处理同一节点
            sort(curLayer.begin(), curLayer.end());
            curLayer.erase(unique(curLayer.begin(), curLayer.end()), curLayer.end());
        }

        // 输出结果
        cout << colors.size() << "\n";
        for (size_t i = 0; i < colors.size(); i++) {
            if (i > 0) cout << " ";
            cout << colors[i];
        }
        cout << "\n";
    }

    return 0;
}
```

## 总结

本题通过**反向 $\texttt{BFS}$ + 分层贪心**的方法，高效地解决了在最短路径中寻找字典序最小颜色序列的问题。算法充分利用了图的结构特性，在保证正确性的同时达到了最优的时间复杂度 $O(n + m)$，能够处理大规模输入数据。

关键技巧：
1. 从终点反向 $\texttt{BFS}$ 确定最短距离
2. 按 $\texttt{BFS}$ 层次逐层推进
3. 在每一层贪心选择最小颜色
4. 使用集合去重避免重复处理

这种方法可以推广到其他需要在最短路径基础上进行次级优化的图论问题中。
