## 题目描述

**网格动物**（$\texttt{Lattice animal}$）是网格上一组相连的格子。在正方形网格上的网格动物是一个热门的研究对象，通常被称为**多连方块**（$\texttt{polyomino}$）。多连方块由边相邻的正方形组成，包含 $n$ 个正方形的多连方块称为 $n$-多连方块。

在这个问题中，你需要找出**不同的自由 $n$-多连方块**的数量，这些方块能放入一个 $w \times h$ 的矩形内。**自由多连方块**可以进行旋转和翻转，也就是说它们的旋转和镜像被视为相同的形状。

例如，有 $5$ 种不同的五连方块（$5$-多连方块）可以放入 $2 \times 4$ 的矩形中，有 $3$ 种不同的八连方块（$8$-多连方块）可以放入 $3 \times 3$ 的矩形中。

### 输入格式
输入文件包含多个测试用例，每行一个。每行包含 $3$ 个整数 $n$, $w$, $h$（$1 \leq n \leq 10$, $1 \leq w, h \leq n$）。

### 输出格式
对于每个测试用例，输出一行一个整数，表示能放入 $w \times h$ 矩形的不同的自由 $n$-多连方块的数量。

### 样例输入
```
5 1 4
5 2 4
5 3 4
5 5 5
8 3 3
```

### 样例输出
```
0
5
11
12
3
```

## 题目分析

### 问题理解
我们需要计算在 $w \times h$ 的矩形内能放置的不同的自由 $n$-多连方块的数量。关键在于：

1. **连通性**：多连方块必须由边相邻的格子组成
2. **自由等价**：旋转和翻转视为相同形状
3. **边界约束**：必须能放入给定的矩形内

### 数据范围分析
- $n \leq 10$：这个范围相对较小，允许我们预先生成所有可能的 $n$-多连方块
- $w, h \leq n$：由于多连方块包含 $n$ 个格子，矩形尺寸不会超过 $n$

### 关键挑战
1. **生成所有多连方块**：需要系统性地生成所有可能的连通形状
2. **去重处理**：识别并合并旋转和翻转后相同的形状
3. **高效判断**：快速判断一个多连方块是否能放入给定矩形

## 解题思路

### 算法选择
我们采用**增量生成法**来构建所有多连方块：

1. **基础情况**：$1$-多连方块只有一个格子
2. **递推生成**：对于每个 $(n-1)$-多连方块，在其所有相邻位置添加新格子，生成候选的 $n$-多连方块
3. **规范化表示**：对每个新生成的多连方块进行规范化处理，消除旋转和翻转的重复

### 规范化处理
为了处理自由多连方块的等价性，我们对每个多连方块生成所有 $8$ 种可能的对称变换（$4$ 种旋转 × $2$ 种翻转），然后选择其中"最小"的表示作为标准形式。

### 预计算优化
由于 $n$ 的范围很小（$n \leq 10$），我们可以在程序开始时预计算所有可能的 $n$-多连方块，并对所有可能的 $(n, w, h)$ 组合预先计算答案。

### 判断能否放入矩形
对于一个多连方块，我们计算其边界框的宽度和高度，然后检查是否满足：
- 宽度 $\leq w$ 且高度 $\leq h$，或者
- 宽度 $\leq h$ 且高度 $\leq w$

## 算法步骤

1. **初始化**：创建单格子的 $1$-多连方块
2. **递推生成**：
   - 对于每个尺寸从 $2$ 到 $10$ 的多连方块
   - 对每个 $(n-1)$-多连方块，找到所有相邻的空位
   - 在每个空位添加新格子，生成新的多连方块
   - 规范化新生成的多连方块并去重
3. **预计算答案**：对于每个 $(n, w, h)$ 组合，统计能放入矩形的不同多连方块数量
4. **查询处理**：对于每个输入，直接输出预计算的结果

## 复杂度分析

- **时间复杂度**：预计算阶段主要取决于多连方块的数量。对于 $n=10$，自由多连方块的数量约为 $4655$，在可接受范围内
- **空间复杂度**：需要存储所有多连方块的规范化表示，由于 $n$ 较小，空间需求可控

```cpp
// Lattice Animals

#include <iostream>
#include <vector>
#include <set>
#include <algorithm>
#include <map>
#include <cstring>
using namespace std;

const int MAX_N = 10;
const int GRID_SIZE = 20; // 足够大的网格

struct Polyomino {
    char cells[GRID_SIZE][GRID_SIZE];
    int minX, maxX, minY, maxY;
    int size;
    
    Polyomino() {
        memset(cells, 0, sizeof(cells));
        minX = minY = GRID_SIZE;
        maxX = maxY = -1;
        size = 0;
    }
    
    void addCell(int x, int y) {
        cells[x + GRID_SIZE/2][y + GRID_SIZE/2] = 1;
        minX = min(minX, x);
        maxX = max(maxX, x);
        minY = min(minY, y);
        maxY = max(maxY, y);
        size++;
    }
    
    // 获取规范化表示
    Polyomino getCanonical() const {
        vector<Polyomino> variants;
        Polyomino current = *this;
        
        for (int flip = 0; flip < 2; flip++) {
            for (int rot = 0; rot < 4; rot++) {
                variants.push_back(current.normalize());
                current = current.rotate90();
            }
            current = this->flip();
        }
        
        // 返回最小的
        Polyomino best = variants[0];
        for (const auto& v : variants) {
            if (v < best) best = v;
        }
        return best;
    }
    
    Polyomino normalize() const {
        Polyomino result;
        for (int i = 0; i < GRID_SIZE; i++) {
            for (int j = 0; j < GRID_SIZE; j++) {
                if (cells[i][j]) {
                    result.addCell(i - GRID_SIZE/2 - minX, j - GRID_SIZE/2 - minY);
                }
            }
        }
        return result;
    }
    
    Polyomino rotate90() const {
        Polyomino result;
        for (int i = 0; i < GRID_SIZE; i++) {
            for (int j = 0; j < GRID_SIZE; j++) {
                if (cells[i][j]) {
                    int x = i - GRID_SIZE/2;
                    int y = j - GRID_SIZE/2;
                    result.addCell(y, -x);
                }
            }
        }
        return result;
    }
    
    Polyomino flip() const {
        Polyomino result;
        for (int i = 0; i < GRID_SIZE; i++) {
            for (int j = 0; j < GRID_SIZE; j++) {
                if (cells[i][j]) {
                    int x = i - GRID_SIZE/2;
                    int y = j - GRID_SIZE/2;
                    result.addCell(x, -y);
                }
            }
        }
        return result;
    }
    
    bool operator<(const Polyomino& other) const {
        if (size != other.size) return size < other.size;
        
        // 比较网格表示
        for (int i = 0; i < GRID_SIZE; i++) {
            for (int j = 0; j < GRID_SIZE; j++) {
                if (cells[i][j] != other.cells[i][j]) {
                    return cells[i][j] < other.cells[i][j];
                }
            }
        }
        return false;
    }
    
    bool fitsInRectangle(int w, int h) const {
        int width = maxX - minX + 1;
        int height = maxY - minY + 1;
        return (width <= w && height <= h) || (width <= h && height <= w);
    }
    
    void getNeighbors(vector<pair<int, int>>& neighbors) const {
        int dx[] = {1, -1, 0, 0};
        int dy[] = {0, 0, 1, -1};
        
        set<pair<int, int>> neighborSet;
        
        for (int i = 0; i < GRID_SIZE; i++) {
            for (int j = 0; j < GRID_SIZE; j++) {
                if (cells[i][j]) {
                    int x = i - GRID_SIZE/2;
                    int y = j - GRID_SIZE/2;
                    
                    for (int d = 0; d < 4; d++) {
                        int nx = x + dx[d];
                        int ny = y + dy[d];
                        int gridX = nx + GRID_SIZE/2;
                        int gridY = ny + GRID_SIZE/2;
                        
                        if (gridX >= 0 && gridX < GRID_SIZE && 
                            gridY >= 0 && gridY < GRID_SIZE && 
                            !cells[gridX][gridY]) {
                            neighborSet.insert({nx, ny});
                        }
                    }
                }
            }
        }
        
        neighbors.assign(neighborSet.begin(), neighborSet.end());
    }
    
    Polyomino addCellToCopy(int x, int y) const {
        Polyomino result = *this;
        result.addCell(x, y);
        return result;
    }
};

vector<set<Polyomino>> precomputeAllPolyominoes() {
    vector<set<Polyomino>> allPolyominoes(MAX_N + 1);
    
    // 基础情况
    Polyomino mono;
    mono.addCell(0, 0);
    allPolyominoes[1].insert(mono.getCanonical());
    
    for (int n = 2; n <= MAX_N; n++) {
        set<Polyomino> newSet;
        
        for (const auto& poly : allPolyominoes[n - 1]) {
            vector<pair<int, int>> neighbors;
            poly.getNeighbors(neighbors);
            
            for (const auto& neighbor : neighbors) {
                Polyomino newPoly = poly.addCellToCopy(neighbor.first, neighbor.second);
                newSet.insert(newPoly.getCanonical());
            }
        }
        
        allPolyominoes[n] = newSet;
    }
    
    return allPolyominoes;
}

int main() {
    auto allPolyominoes = precomputeAllPolyominoes();
    
    // 预计算所有答案
    int answer[MAX_N + 1][MAX_N + 1][MAX_N + 1] = {0};
    
    for (int n = 1; n <= MAX_N; n++) {
        for (int w = 1; w <= MAX_N; w++) {
            for (int h = 1; h <= MAX_N; h++) {
                int count = 0;
                for (const auto& poly : allPolyominoes[n]) {
                    if (poly.fitsInRectangle(w, h)) {
                        count++;
                    }
                }
                answer[n][w][h] = count;
            }
        }
    }
    
    int n, w, h;
    while (cin >> n >> w >> h) {
        cout << answer[n][w][h] << endl;
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解多连方块的生成和规范化过程。通过系统性地从小的多连方块构建大的多连方块，并利用规范化处理来消除对称重复，我们能够高效地解决这个问题。预计算策略使得查询响应非常快速，适合在线评测系统的要求。

这种**组合生成+规范化去重**的方法在解决类似的组合计数问题中具有广泛的适用性，特别是在处理具有对称性的几何对象时。
