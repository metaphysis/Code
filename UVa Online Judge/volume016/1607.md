## 题目描述

在当代 $\texttt{VLSI}$ 芯片工业中，电气工程师使用的软件工具会执行许多优化。本题要求实现一种特定的芯片设计优化。

给定一个由 $\texttt{NAND}$ 门组成的无环网络（$\texttt{NAND}$ 门的输出是其输入的否定合取，即当且仅当两个输入值都为 $1$ 时，输出值为 $0$）。该网络是已合成组件的一部分，不能更改。网络的所有输入都连接到同一个信号 $x$。

目标是将 $x$ 从某些输入断开，并将常量信号 $0$ 和/或 $1$ 分配给这些输入，同时保持设计实现的功能不变。

如果连接到 $x$ 的输入数量尽可能少，但网络仍然计算与所有输入都连接到 $x$ 时相同的函数，则称这种分配是最优的。

## 输入格式

第一行包含一个正整数 $d$，表示数据集的数量。

每个数据集包含两行：
- 第一行：两个正整数 $n$ 和 $m$，分别表示网络输入的数量和门的数量
- 第二行：$2m$ 个非零整数，描述每个门的两个输入源

## 输出格式

对于每个数据集，输出一行包含 $n$ 个字符的字符串，每个字符是 `0`、`1` 或 `x`，表示对相应网络输入的分配。

## 题目分析

### 问题本质

这是一个逻辑电路优化问题，我们需要找到最小的输入集合来保持电路功能不变。所有原始输入都连接到同一个信号 $x$，我们可以用常量 $0$ 或 $1$ 替换某些输入，目标是最大化替换的数量（即最小化保留的 $x$ 数量）。

### 关键观察

1. **单调性特性**：$\texttt{NAND}$ 门具有特殊的逻辑特性，当输入从全 $0$ 逐渐变为全 $1$ 时，输出变化具有单调性
2. **唯一关键点**：在输入从全 $0$ 到全 $1$ 的变化过程中，存在一个关键的分界点，只有该点的输入需要保持为变量 $x$，其他输入都可以设为常量
3. **二分查找应用**：利用单调性，我们可以使用二分查找来高效地找到这个关键分界点

### 解题思路

1. **电路模拟**：实现一个函数来模拟电路的运行，给定输入配置时计算输出值
2. **边界情况检查**：
   - 如果全 $0$ 输入和全 $1$ 输入产生相同的输出，说明所有输入都可以设为常量
   - 否则，存在至少一个输入必须保持为变量 $x$
3. **二分查找分界点**：
   - 定义：前 $k$ 个输入为 $0$，后面的输入为 $1$
   - 寻找最小的 $k$，使得这种配置的输出与全 $1$ 输入时的输出相同
   - 这个 $k$ 就是必须设为 $x$ 的输入位置
4. **构造输出**：
   - 分界点之前的所有输入设为 $0$
   - 分界点的输入设为 $x$
   - 分界点之后的所有输入设为 $1$

## 算法正确性证明

### 单调性证明

对于 $\texttt{NAND}$ 门网络，当我们将输入从全 $0$ 逐渐变为全 $1$ 时（即不断增加值为 $1$ 的输入数量），输出值的变化具有单调性。这是因为：

- $\texttt{NAND}$ 门的输出对于单个输入的变化是单调的
- 整个无环网络保持了这种单调特性

### 分界点存在性

由于单调性的存在，当输入配置从全 $0$ 变化到全 $1$ 时，输出值会从某个值变化到另一个值。根据中间值定理，存在一个唯一的分界点，该点的输入配置决定了输出的变化。

### 最优性证明

该算法找到的分界点确保了：
- 只有 $1$ 个输入需要保持为变量 $x$
- 其他所有输入都可以安全地设为常量
- 电路功能与原始配置完全相同

这显然是最优解，因为如果存在 $0$ 个 $x$ 的解决方案，我们在第一步的边界检查中就已经处理了。

## 复杂度分析

- **空间复杂度**：$O(n + m)$，用于存储输入数据和中间结果
- **时间复杂度**：$O(m \log n)$
  - 每次电路模拟需要 $O(m)$ 时间
  - 二分查找需要进行 $O(\log n)$ 次模拟
  - 总复杂度为 $O(m \log n)$，对于 $n \leq 100000$，$m \leq 200000$ 是可接受的

```cpp
// Gates

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010, MAXM = 200010;

int n, m;
int a[MAXM], b[MAXM];
int in[MAXN], out[MAXM];

int run(int k) {
    // 初始化输入：前k个为0，后面为1
    for (int i = 1; i <= k; i++) in[i] = 0;
    for (int i = k + 1; i <= n; i++) in[i] = 1;
    // 计算每个门的输出
    for (int i = 1; i <= m; i++) {
        int A, B;
        // 处理第一个输入
        if (a[i] < 0) A = in[-a[i]];
        else A = out[a[i]];
        // 处理第二个输入  
        if (b[i] < 0) B = in[-b[i]];
        else B = out[b[i]];
        // NAND 运算
        out[i] = !(A & B);
    }
    
    return out[m];
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int d;
    cin >> d;
    while (d--) {
        cin >> n >> m;
        for (int i = 1; i <= m; i++) cin >> a[i] >> b[i];
        int zero = run(0);  // 全0输入时的输出
        int one = run(n);  // 全1输入时的输出
        if (zero == one) {
            // 所有输入都可以设为常量
            for (int i = 1; i <= n; i++) cout << '0';
            cout << '\n';
            continue;
        }
        // 二分查找分界点
        int l = 1, r = n;
        while (l < r) {
            int t = (l + r) >> 1;
            if (run(t) == one) r = t;
            else l = t + 1;
        }
        // 输出结果
        for (int i = 1; i < r; i++) cout << '0';
        cout << 'x';
        for (int i = r + 1; i <= n; i++) cout << '1';
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题展示了一个巧妙的算法设计，通过利用逻辑电路的单调特性和二分查找，高效地解决了电路优化问题。关键洞察在于认识到只有一个输入需要保持为变量，其他都可以设为常量，这大大简化了问题的复杂度。

该解法的时间复杂度为 $O(m \log n)$，空间复杂度为 $O(n + m)$，能够高效处理题目给出的最大数据规模。
