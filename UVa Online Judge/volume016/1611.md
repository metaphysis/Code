## 题目描述

有 $n$ 个箱子等待被装载到船上，编号为 $1, 2, \ldots, n$，编号决定了装载顺序。但箱子目前以任意顺序排成一行。你需要使用一个特殊的起重机来排序箱子。

起重机的工作方式：选择一个长度为偶数的连续区间 $[l, r]$，起重机将该区间的前半部分与后半部分交换，两半内部的顺序保持不变。

例如：区间 $[1, 7, 9, 2]$ 交换后变为 $[9, 2, 1, 7]$。

起重机的移动计数器是一个 $9$ 进制整数，最多 $6$ 位数字，因此最多允许 $9^6 = 531441$ 次移动。

## 输入格式

第一行包含测试用例数 $T$。

每个测试用例：
- 第一行：整数 $n$ ($1 \leq n \leq 10000$)
- 第二行：$\{1, 2, \ldots, n\}$ 的一个排列

## 输出格式

对每个测试用例：
- 第一行：移动次数 $m$
- 接下来 $m$ 行：每行两个整数 $l$ 和 $r$，表示要交换的区间

## 题目分析

### 操作特性分析

起重机的操作本质上是**块交换**：对于区间 $[l, r]$（长度为偶数），将前半部分 $[l, l+\frac{r-l+1}{2}-1]$ 与后半部分 $[l+\frac{r-l+1}{2}, r]$ 交换，保持各自内部顺序不变。

这个操作的特点是：
- 只能交换等长的两个连续块
- 操作是可逆的
- 通过多次操作可以实现任意排列的排序

### 解题思路

我们采用**从大到小贪心排序**的策略：

1. **排序顺序**：从数字 $n$ 开始到数字 $1$，依次将每个数字放到正确位置
2. **位置调整**：对于当前数字 $num$，设其当前位置为 $pos$，目标位置为 $num$
3. **移动策略**：
   - 如果 $pos = num$：数字已在正确位置，跳过
   - 如果 $num - pos$ 为奇数：先执行 $[pos, pos+1]$ 交换，使数字右移一位，将距离变为偶数
   - 如果 $num - pos$ 为偶数：执行 $[pos, pos+dist-1]$ 交换（$dist = num - pos$），使数字右移 $dist/2$ 位

### 为什么这样可行？

**关键观察**：当执行 $[pos, pos+dist-1]$ 交换时（$dist$ 为偶数）：
- 区间长度为 $dist$（偶数）
- 数字 $num$ 位于区间左半部分的第一个位置
- 交换后，$num$ 会移动到位置 $pos + dist/2$
- 这样每次移动都将距离减半，最多 $O(\log n)$ 次移动就能将数字放到正确位置

**边界处理**：当距离为奇数时，先与后一个元素交换调整奇偶性，确保后续操作区间长度为偶数。

### 复杂度分析

- **时间复杂度**：每个数字最多需要 $O(\log n)$ 次移动，总移动次数 $O(n \log n)$，远小于 $531441$ 的限制
- **空间复杂度**：$O(n)$ 用于存储数组和位置映射

## 代码实现

```cpp
// Crane

// UVa Run Time: 0.260s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int n;
vector<int> arr;
vector<pair<int, int>> moves;
vector<int> posMap;

void makeMove(int l, int r) {
    int len = r - l + 1;
    int half = len / 2;
    
    for (int i = 0; i < half; i++) {
        swap(arr[l - 1 + i], arr[l - 1 + half + i]);
    }
    moves.push_back({l, r});
    
    for (int i = l; i <= r; i++) {
        posMap[arr[i - 1]] = i;
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int T;
    cin >> T;
    while (T--) {
        cin >> n;
        arr.resize(n);
        posMap.resize(n + 1);
        
        for (int i = 0; i < n; i++) {
            cin >> arr[i];
            posMap[arr[i]] = i + 1;
        }
        moves.clear();
        
        for (int num = n; num >= 1; num--) {
            int pos = posMap[num];
            
            while (pos != num) {
                int dist = num - pos;
                
                if (dist % 2 == 1) {
                    makeMove(pos, pos + 1);
                    pos = pos + 1;
                } else {
                    makeMove(pos, pos + dist - 1);
                    pos = pos + dist / 2;
                }
            }
        }
        
        cout << moves.size() << "\n";
        for (auto& p : moves) {
            cout << p.first << " " << p.second << "\n";
        }
    }
    return 0;
}
```

## 算法正确性证明

通过数学归纳法可以证明该算法的正确性：

1. **基础情况**：当处理数字 $n$ 时，算法能将其移动到位置 $n$
2. **归纳假设**：假设数字 $n, n-1, \ldots, k+1$ 都已正确放置
3. **归纳步骤**：处理数字 $k$ 时，由于比 $k$ 大的数字都已就位，不会干扰 $k$ 的移动过程

每次移动都保证区间长度为偶数，且数字向目标位置收敛，因此算法必然在有限步内完成。

## 总结

本题的关键在于理解起重机操作的本质，并设计出高效的贪心策略。通过从大到小排序和维护位置映射，我们能够在移动次数限制内完成排序任务。这种"逐步逼近"的思想在许多排序和构造问题中都很常见。
