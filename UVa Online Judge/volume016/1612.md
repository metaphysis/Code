## 题目描述

一场比赛刚刚结束，共有 $3$ 道题目和 $n$ 名选手。每名选手的编号从 $1$ 到 $n$。最终排名由 $3$ 道题的总分决定，总分越高排名越高（排名数字越小）。如果两名选手总分相同，编号较小的选手排名更高。

对于每道题目，我们知道如果选手没有完全做错，他可能得到的分数（如果完全做错，该题得分为 $0$）。但我们不知道选手是否真的在某道题上得分。

**重要约束**：对于每道题目，选手要么得到题目给定的完整分数，要么得到 $0$ 分，不能得到部分分数。

给定一个预测排名，你需要判断这个排名是否可能。如果可能，输出排名最低的选手可能获得的最高总分（保留 $2$ 位小数）；否则输出 "No solution"。

### 输入格式

输入包含多个测试用例：
- 第一行：整数 $n$（$n \leq 16384$），表示选手人数
- 接下来 $n$ 行：每行三个实数 $a, b, c$（$0 \leq a, b, c < 1000$，最多 $2$ 位小数）
- 再一行：$n$ 个整数，表示从第 $1$ 名到第 $n$ 名的选手编号
- 最后一个测试用例后是一个单独的 $0$

### 输出格式

对于每个测试用例：
- 如果排名可能，输出 `Case X: Y`（$Y$ 保留 $2$ 位小数）
- 否则输出 `Case X: No solution`

## 题目分析

### 问题本质

这是一个**约束满足问题**，我们需要：
1. 为每个选手选择每道题的得分（$0$ 分或满分）
2. 满足给定的排名顺序约束
3. 在满足约束的前提下，最大化最后一名的总分

### 关键约束分析

1. **得分约束**：每道题只有两种选择 - $0$ 分或满分，不能得部分分数
2. **排名约束**：对于相邻排名的选手 $i$（前）和 $j$（后）：
   - 如果 $\texttt{id}(i) < \texttt{id}(j)$：$\texttt{score}(i) \geq \texttt{score}(j)$
   - 如果 $\texttt{id}(i) > \texttt{id}(j)$：$\texttt{score}(i) > \texttt{score}(j)$

### 解题思路

#### 步骤 1：生成可能的得分组合

每个选手有 $3$ 道题，每道题有 $2$ 种选择（得满分或得 $0$ 分），因此每个选手有 $2^3 = 8$ 种可能的得分组合。我们需要为每个选手预计算所有可能的得分总和。

#### 步骤 2：逆向动态规划

为了最大化最后一名的分数，我们采用**从后向前**的处理顺序：

1. **从最后一名开始**：枚举最后一名的所有可能分数
2. **对于每个候选分数**：检查是否能构造出满足排名约束的完整解
3. **逆向递推**：对于第 $i$ 名选手，根据第 $i+1$ 名选手的可行分数，确定第 $i$ 名选手的可行分数

#### 步骤 3：约束检查

对于相邻的两名选手 $i$（排名较高）和 $j$（排名较低）：
- 如果 $\texttt{id}(i) < \texttt{id}(j)$：要求 $\texttt{score}(i) \geq \texttt{score}(j)$
- 如果 $\texttt{id}(i) > \texttt{id}(j)$：要求 $\texttt{score}(i) > \texttt{score}(j)$

#### 步骤 4：寻找最优解

在所有可行的解中，选择最后一名的最高可能分数作为答案。

### 算法复杂度

- 每个选手最多有 $8$ 种得分组合
- 对于每个测试用例，最坏情况下需要检查所有选手的所有可能组合
- 总体复杂度为 $O(n \times 8^2)$，对于 $n \leq 16384$ 是可接受的

## 代码实现

```cpp
// Guess

#include <iostream>
#include <vector>
#include <algorithm>
#include <iomanip>
#include <cmath>
#include <functional>
#include <bitset>

using namespace std;

const double EPS = 1e-9;
const double INF = 1e9;

struct Player {
    int id;
    double scores[3];
    vector<double> possibleTotals; // 所有可能的得分组合总和
};

int n;
vector<Player> players;
vector<int> rankOrder;

// 生成所有可能的得分组合
void generatePossibleTotals(Player& player) {
    player.possibleTotals.clear();
    for (int mask = 0; mask < 8; ++mask) {
        double total = 0.0;
        for (int i = 0; i < 3; ++i) {
            if (mask & (1 << i)) {
                total += player.scores[i];
            }
        }
        player.possibleTotals.push_back(total);
    }
    // 排序并去重
    sort(player.possibleTotals.begin(), player.possibleTotals.end());
    player.possibleTotals.erase(unique(player.possibleTotals.begin(), player.possibleTotals.end()), 
                               player.possibleTotals.end());
}

// 检查在给定最后一名总分的情况下，排名是否可能
bool check(double lastScore) {
    // dp[i] 表示第i名选手所有可能的分数（从0开始）
    vector<vector<double>> dp(n);
    
    // 初始化最后一名
    int lastId = rankOrder[n - 1];
    for (double score : players[lastId].possibleTotals) {
        if (fabs(score - lastScore) < EPS || score > lastScore - EPS) {
            dp[n - 1].push_back(score);
        }
    }
    if (dp[n - 1].empty()) return false;
    
    // 从倒数第二名向前处理
    for (int i = n - 2; i >= 0; --i) {
        int currentId = rankOrder[i];
        int nextId = rankOrder[i + 1];
        
        for (double currentScore : players[currentId].possibleTotals) {
            // 检查是否满足与下一名的约束
            for (double nextScore : dp[i + 1]) {
                if (currentId < nextId) {
                    // ID更小，可以相等或更大
                    if (currentScore > nextScore - EPS) {
                        dp[i].push_back(currentScore);
                        break; // 找到一个满足条件的即可
                    }
                } else {
                    // ID更大，必须严格大于
                    if (currentScore > nextScore + EPS) {
                        dp[i].push_back(currentScore);
                        break; // 找到一个满足条件的即可
                    }
                }
            }
        }
        
        // 去重
        sort(dp[i].begin(), dp[i].end());
        dp[i].erase(unique(dp[i].begin(), dp[i].end()), dp[i].end());
        
        if (dp[i].empty()) return false;
    }
    
    return true;
}

double solve() {
    // 为每个选手生成所有可能的得分组合
    for (int i = 0; i < n; ++i) {
        generatePossibleTotals(players[i]);
    }
    
    // 获取最后一名的所有可能分数
    int lastId = rankOrder[n - 1];
    vector<double> candidateScores = players[lastId].possibleTotals;
    sort(candidateScores.begin(), candidateScores.end());
    
    // 二分搜索最后一名的最高可能总分
    double ans = -1.0;
    for (double score : candidateScores) {
        if (check(score)) {
            ans = score;
        }
    }
    
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int caseNum = 1;
    while (cin >> n && n != 0) {
        players.resize(n);
        rankOrder.resize(n);
        
        // 读取选手数据
        for (int i = 0; i < n; ++i) {
            players[i].id = i;
            cin >> players[i].scores[0] >> players[i].scores[1] >> players[i].scores[2];
        }
        
        // 读取排名顺序
        for (int i = 0; i < n; ++i) {
            int id;
            cin >> id;
            rankOrder[i] = id - 1; // 转换为 0-based 索引
        }
        
        double result = solve();
        
        cout << "Case " << caseNum << ": ";
        if (result < 0) {
            cout << "No solution" << endl;
        } else {
            cout << fixed << setprecision(2) << result << endl;
        }
        
        caseNum++;
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解题目约束并设计合适的搜索策略：

1. **离散性处理**：由于每道题只能得满分或 $0$ 分，问题本质是离散的
2. **逆向思维**：从最后一名开始向前处理，便于最大化最后一名的分数
3. **可行性检查**：通过动态规划维护每个排名的可行分数集合

该算法能够高效地解决问题，并在合理的时间内处理最大规模的数据。
