## 题目分析

### 问题描述

有两家银行在金融市场重新开放时进行交易。在第 $i$ 分钟 ($1 \leq i \leq n$)，交易量为 $a_i$ 份合约，其中 $1 \leq a_i \leq i$。我们需要为每分钟的交易分配一个符号 $b_i \in \{+1, -1\}$，使得：

$$
\sum_{i=1}^{n} a_i b_i = 0
$$

其中 $b_i = +1$ 表示第一家银行买入，$b_i = -1$ 表示第二家银行买入。如果存在这样的分配方案，输出 `"Yes"` 和具体的 $b_i$ 序列；否则输出 `"No"`。

### 关键条件分析

1. **交易量限制**：$1 \leq a_i \leq i$ 这个条件非常关键，它保证了当总和为偶数时，一定存在解
2. **平衡要求**：所有带符号的交易量之和必须为 $0$，这意味着正负两组的交易量总和必须相等
3. **问题本质**：这是一个**子集划分问题**，需要将 $a_i$ 分成两个和相等的子集

## 解题思路

### 可行性判断

设总和 $S = \sum_{i=1}^{n} a_i$：

- 如果 $S$ 是奇数，直接输出 `"No"`（无法分成两个整数和相等的部分）
- 如果 $S$ 是偶数，目标值 $T = S/2$

### 构造算法

由于题目条件 $1 \leq a_i \leq i$ 的特殊性，我们可以使用**贪心算法**从大到小构造解：

1. 从 $i = n$ 到 $1$ 倒序遍历
2. 如果当前 $a_i \leq$ 剩余目标值 $T$，则选择该元素（$b_i = +1$），并从 $T$ 中减去 $a_i$
3. 否则不选择该元素（$b_i = -1$）

### 算法正确性证明

这个贪心策略能够成功的关键在于题目条件 $a_i \leq i$。通过数学归纳法可以证明：

- 当 $n = 1$ 时，$a_1 = 1$，总和为奇数，无解
- 对于更大的 $n$，条件保证了从大到小贪心选择时，总能恰好达到目标值 $T$

### 复杂度分析

- 时间复杂度：$O(n)$，只需要两次线性遍历
- 空间复杂度：$O(n)$，用于存储输入和输出数组

## 代码实现

```cpp
// Hell on the Markets

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <cstdio>

using namespace std;

int main() {
    int n;
    // 循环读取多个测试用例
    while (scanf("%d", &n) == 1) {
        vector<int> tradeVolume(n);  // 存储每分钟的交易量
        long long totalSum = 0;      // 交易总量
        
        // 读取输入并计算总和
        for (int i = 0; i < n; i++) {
            scanf("%d", &tradeVolume[i]);
            totalSum += tradeVolume[i];
        }

        // 如果总和为奇数，直接输出 No
        if (totalSum % 2 != 0) {
            printf("No\n");
            continue;
        }

        long long targetSum = totalSum / 2;  // 目标总和
        vector<int> signAssignment(n, -1);   // 符号分配，默认全为 -1

        // 从后往前贪心选择
        for (int i = n - 1; i >= 0; i--) {
            if (tradeVolume[i] <= targetSum) {
                signAssignment[i] = 1;           // 选择该交易量
                targetSum -= tradeVolume[i];     // 更新剩余目标值
            }
        }

        // 输出结果
        printf("Yes\n");
        for (int i = 0; i < n; i++) {
            printf("%d", signAssignment[i]);
            if (i < n - 1) printf(" ");
        }
        printf("\n");
    }
    return 0;
}
```

## 总结

本题的关键在于发现题目条件 $1 \leq a_i \leq i$ 的特殊性，这个条件保证了当总和为偶数时，使用从大到小的贪心策略一定能找到解。这种类型的题目在编程竞赛中比较常见，需要选手能够识别出特殊条件并设计出简单高效的构造算法。

算法的时间复杂度为 $O(n)$，空间复杂度为 $O(n)$，完全满足题目中 $n \leq 100,000$ 的数据规模要求。
