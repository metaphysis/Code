## 问题描述

$\texttt{Bob}$ 需要在一条长度为 $L$ 的高速公路（建模为从 $0$ 到 $L$ 的线段）上设置最少的出口，使得所有村庄都能被至少一个出口覆盖。每个村庄是平面上的一个点 $(x, y)$，已知所有村庄到高速公路的垂直距离不超过 $D$。一个村庄能被某个出口覆盖的条件是：该村庄到出口的欧几里得距离不超过 $D$。

### 输入格式
- 高速公路长度 $L$（整数）
- 覆盖距离 $D$（整数）
- 村庄数量 $N$
- 每个村庄的坐标 $(x, y)$

### 输出格式
- 最少需要的出口数量

### 样例
输入：
```
100 50 3
2 4
50 10
70 30
```
输出：
```
1
```

## 问题分析

### 关键洞察
1. **几何关系**：对于每个村庄 $(x, y)$，由于它到高速公路的垂直距离 $|y| \leq D$，因此存在高速公路上的一个区间，在这个区间内任意位置设置出口都能覆盖该村庄。

2. **区间计算**：根据勾股定理，村庄 $(x, y)$ 对应的出口位置 $p$ 必须满足：
   $$
   \sqrt{(p - x)^2 + y^2} \leq D
   $$
   解得：
   $$
   x - \sqrt{D^2 - y^2} \leq p \leq x + \sqrt{D^2 - y^2}
   $$
   同时 $p$ 必须在 $[0, L]$ 范围内。

3. **问题转化**：将每个村庄转化为一个区间 $[l_i, r_i]$，问题转化为：在数轴上选择最少的点，使得每个区间内至少包含一个点。

### 算法选择
这是一个经典的**区间覆盖点**问题，可以使用贪心算法高效解决：

1. 将所有区间按照右端点升序排序
2. 遍历排序后的区间：
   - 如果当前区间左端点大于上一个出口位置，则在该区间右端点放置新出口
   - 否则，该区间已被上一个出口覆盖

### 算法正确性证明
贪心选择右端点可以最大化覆盖范围。由于区间按右端点排序，每次选择当前区间的右端点作为出口位置，可以保证覆盖所有左端点小于等于该右端点的区间。

## 代码实现

```cpp
// Highway
// UVa ID: 1615
// Verdict: Accepted
// Submission Date: 2025-11-04
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>

using namespace std;

// 区间结构体，表示每个村庄对应的出口位置区间
struct VillageInterval {
    double leftEnd;  // 区间左端点
    double rightEnd; // 区间右端点
    
    // 重载小于运算符，用于按右端点排序
    bool operator<(const VillageInterval& other) const {
        return rightEnd < other.rightEnd;
    }
};

int main() {
    int highwayLength, coverDistance, villageCount;
    
    // 处理多个测试用例直到文件结束
    while (cin >> highwayLength >> coverDistance >> villageCount) {
        vector<VillageInterval> intervals;
        
        // 处理每个村庄
        for (int i = 0; i < villageCount; ++i) {
            int xPos, yPos;
            cin >> xPos >> yPos;
            
            // 计算村庄到高速公路的垂直距离
            double verticalDist = abs(yPos);
            
            // 如果垂直距离大于覆盖距离，该村庄无法被覆盖（根据题目保证不会发生）
            if (verticalDist > coverDistance) {
                continue;
            }
            
            // 计算出口在高速公路上的水平覆盖范围
            double horizontalRange = sqrt(coverDistance * coverDistance - verticalDist * verticalDist);
            
            // 计算有效的出口位置区间，限制在 [0, highwayLength] 范围内
            double intervalStart = max(0.0, xPos - horizontalRange);
            double intervalEnd = min(static_cast<double>(highwayLength), xPos + horizontalRange);
            
            intervals.push_back({intervalStart, intervalEnd});
        }
        
        // 按区间右端点升序排序
        sort(intervals.begin(), intervals.end());
        
        int exitCount = 0;          // 出口计数器
        double lastExitPos = -1.0;  // 上一个出口位置，初始化为 -1
        
        // 贪心算法：遍历所有区间
        for (const auto& interval : intervals) {
            // 如果当前区间左端点大于上一个出口位置，需要设置新出口
            if (lastExitPos < interval.leftEnd) {
                ++exitCount;
                lastExitPos = interval.rightEnd; // 在区间右端点设置出口
            }
        }
        
        // 输出结果
        cout << exitCount << endl;
    }
    
    return 0;
}
```

## 总结

本题通过几何分析将问题转化为经典的区间覆盖点问题，利用贪心算法得到最优解。算法的核心在于：
1. 将每个村庄转化为高速公路上的覆盖区间
2. 按区间右端点排序
3. 贪心选择出口位置

这种方法保证了在 $O(N \log N)$ 时间内解决问题，适用于大规模数据输入。
