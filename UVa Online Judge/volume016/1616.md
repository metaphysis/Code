## 题目分析

本题要求为每个劫匪团伙分配一个新的区间，满足以下条件：
1. 所有新区间互不相交
2. 每个新区间是原区间的子区间  
3. 所有新区间长度相等
4. 最大化这个公共长度

这是一个典型的**最大化最小值**问题，通常可以使用**二分搜索**来解决。

## 解题思路

### 方法一：整数精确比较

#### 核心思想
使用整数运算来避免浮点数精度问题，通过二分搜索找到最大的长度 $L = \frac{p}{q}$。

#### 算法步骤
1. **排序**：按左端点排序所有区间
2. **识别重叠段**：找到所有相互重叠的连续区间段，这些段的大小作为候选分母
3. **二分搜索**：在可能的分子范围内进行二分搜索
4. **检查函数**：对于给定的 $\frac{p}{q}$，检查是否能分配互不相交的长度为 $\frac{p}{q}$ 的子区间
5. **贪心分配**：从每个区间的左端点开始，尽可能靠左地分配子区间

#### 关键优化
- 只检查候选分母，减少检查次数
- 使用整数运算避免精度问题

        long long currentEnd = intervals[i].b * q;
        long long start = max(last, currentStart);
        long long end = start + p;

        last = end;
    }
    return true;
}

        vector<int> candidates;
        int i = 0;
        while (i < n) {
            int j = i;
            long long minEnd = intervals[i].b;
            while (j < n && intervals[j].a < minEnd) {
                minEnd = min(minEnd, (long long)intervals[j].b);
                j++;

            candidates.push_back(j - i);
            i = j;
        }
        // 去重并排序
        sort(candidates.begin(), candidates.end());
        candidates.erase(unique(candidates.begin(), candidates.end()), candidates.end());
        // 二分搜索分子

        while (left <= right) {

            bool found = false;

                    found = true;
                    if (mid * bestQ > bestP * q) {

                        bestQ = q;

### 方法二：浮点数二分搜索

#### 核心思想
使用浮点数二分搜索找到最大长度，然后将结果转换为最接近的分数。

#### 算法步骤
1. **排序**：按右端点排序所有区间
2. **浮点数二分**：在 $[0, 10^6]$ 范围内二分搜索最大长度 $L$
3. **贪心检查**：对于候选长度 $L$，检查是否能分配互不相交的长度为 $L$ 的子区间
4. **分数转换**：将浮点数结果转换为最接近的不可约分数

#### 优势
- 实现简单直观
- 在实际评测中能够通过

#### 代码实现

#include <bits/stdc++.h>
using namespace std;

struct Interval {
    int f, b;
    bool operator<(const Interval& that) const {
        return b < that.b;
    }
};

Interval intervals[100005];

int main() {
    int n;
    while (scanf("%d", &n) != EOF) {
        for (int i = 0; i < n; i++) scanf("%d%d", &intervals[i].f, &intervals[i].b);
        sort(intervals, intervals + n);

        double left = 0, right = 1000000;
        while (right - left > 1e-9) {
            double mid = left + (right - left) / 2;
            double pos = 0;
            int i;
            for (i = 0; i < n; i++) {
                if (pos < intervals[i].f) pos = intervals[i].f;
                if (pos + mid > intervals[i].b) break;
                pos += mid;
            }
            if (i == n) left = mid;
            else right = mid;
        }

        int numerator = 0, denominator = 1;
        for (int d = 1; d <= n; d++) {
            int c = round(left * d);
            if (fabs(1.0 * numerator / denominator - left) > fabs(1.0 * c / d - left)) {
                numerator = c;
                denominator = d;
            }
        }
        printf("%d/%d\n", numerator, denominator);
    }
    return 0;
}
