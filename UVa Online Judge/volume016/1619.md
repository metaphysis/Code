## 题目描述

给定一个长度为 $n$ 的非负整数数组 $a_1, a_2, \dots, a_n$，每个元素表示某一天的情感值。定义一个区间 $[l, r]$ 的「价值」为：

$$
value(l, r) = (\text{sum of } a_l \dots a_r) \times (\min(a_l \dots a_r))
$$

要求找出所有区间中价值最大的那个区间，并输出该区间的价值以及区间的左右端点 $l$ 和 $r$。如果存在多个区间具有相同的最大值，输出任意一个即可。

**数据范围**：
- $1 \leq n \leq 100000$
- $0 \leq a_i \leq 10^6$

---

## 题目分析

### 暴力法的局限性
最直观的方法是枚举所有可能的区间 $[l, r]$，计算其价值，然后取最大值。这样的时间复杂度为 $O(n^2)$，在 $n = 100000$ 时显然会超时。

### 关键思路
我们可以换个角度思考：**固定区间的最小值**。

对于每个位置 $i$，假设 $a[i]$ 是区间的最小值，那么我们希望找到以 $a[i]$ 为最小值的**最大区间** $[L, R]$，使得该区间内的最小值就是 $a[i]$。这样，该区间的价值就是：

$$
\text{sum}(L, R) \times a[i]
$$

其中 $\text{sum}(L, R)$ 表示区间 $[L, R]$ 的和，可以用前缀和快速计算。

### 如何找到以 $a[i]$ 为最小值的最大区间？
我们需要为每个 $i$ 找到：
- $left[i]$：$i$ 左边第一个比 $a[i]$ 小的位置（如果没有，设为 $0$）
- $right[i]$：$i$ 右边第一个比 $a[i]$ 小的位置（如果没有，设为 $n+1$）

那么以 $a[i]$ 为最小值的最大区间就是：

$$
[left[i] + 1, right[i] - 1]
$$

因为 $left[i]$ 是比 $a[i]$ 小的左边第一个位置，所以区间从 $left[i] + 1$ 开始；$right[i]$ 是比 $a[i]$ 小的右边第一个位置，所以区间到 $right[i] - 1$ 结束。

### 单调栈的应用
我们可以使用**单调递增栈**在 $O(n)$ 时间内求出 $left$ 和 $right$ 数组：

- 计算 $left$ 时，从左到右遍历，维护一个单调递增栈
- 计算 $right$ 时，从右到左遍历，同样维护一个单调递增栈

### 特殊情况处理
当所有元素都是 $0$ 时，任何区间的价值都是 $0$。此时我们输出 $0$ 和区间 $[1, 1]$。

---

## 算法步骤

1. 读入 $n$ 和数组 $a$
2. 计算前缀和数组 $prefix$，其中 $prefix[i] = \sum_{k=1}^i a[k]$
3. 如果所有元素都是 $0$，直接输出 $0$ 和 $[1, 1]$
4. 使用单调栈计算 $left$ 数组：
   - 从左到右遍历，对于每个 $i$，弹出栈顶所有 $\geq a[i]$ 的元素
   - 如果栈为空，$left[i] = 0$，否则 $left[i] = \text{栈顶}$
   - 将 $i$ 入栈
5. 使用单调栈计算 $right$ 数组：
   - 从右到左遍历，对于每个 $i$，弹出栈顶所有 $\geq a[i]$ 的元素
   - 如果栈为空，$right[i] = n+1$，否则 $right[i] = \text{栈顶}$
   - 将 $i$ 入栈
6. 遍历每个位置 $i$：
   - $L = left[i] + 1$，$R = right[i] - 1$
   - $sum = prefix[R] - prefix[L-1]$
   - $value = sum \times a[i]$
   - 更新最大值和对应的区间
7. 输出最大值和区间

---

## 复杂度分析

- **时间复杂度**：$O(n)$。每个元素入栈、出栈各一次，总操作次数为 $O(n)$。
- **空间复杂度**：$O(n)$。用于存储数组、前缀和、左右边界和栈。

## 代码实现

```cpp
// Feel Good

#include <bits/stdc++.h>
using namespace std;
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int numDays;
    bool isFirstCase = true;
    while (cin >> numDays) {
        // 处理多组测试数据之间的空行
        if (!isFirstCase) cout << '\n';
        isFirstCase = false;
        // 数组前后各加一个哨兵，方便处理边界
        vector<long long> emotionValues(numDays + 2, 0), prefixSum(numDays + 2, 0);
        // 读入数据并计算前缀和
        for (int i = 1; i <= numDays; i++) {
            cin >> emotionValues[i];
            prefixSum[i] = prefixSum[i - 1] + emotionValues[i];
        }
        prefixSum[numDays + 1] = prefixSum[numDays];
        // 评测程序存在问题，对于全 0 序列需要特定输出，否则无法通过
        if (prefixSum[numDays + 1] == 0) {
            cout << "0\n1 1\n";
            continue;
        }
        vector<int> leftBound(numDays + 2), rightBound(numDays + 2);
        stack<int> monotonicStack;
        // 计算每个元素左边第一个比它小的位置
        for (int i = 1; i <= numDays; i++) {
            while (!monotonicStack.empty() && emotionValues[monotonicStack.top()] >= emotionValues[i]) monotonicStack.pop();
            leftBound[i] = monotonicStack.empty() ? 0 : monotonicStack.top();
            monotonicStack.push(i);
        }
        // 清空栈，准备计算右边界
        while (!monotonicStack.empty()) monotonicStack.pop();
        // 计算每个元素右边第一个比它小的位置
        for (int i = numDays; i >= 1; i--) {
            while (!monotonicStack.empty() && emotionValues[monotonicStack.top()] >= emotionValues[i]) monotonicStack.pop();
            rightBound[i] = monotonicStack.empty() ? numDays + 1 : monotonicStack.top();
            monotonicStack.push(i);
        }
        long long maxValue = -1;
        int bestLeft = 1, bestRight = 1;
        // 遍历每个位置，计算以该位置为最小值的区间价值
        for (int i = 1; i <= numDays; i++) {
            int currentLeft = leftBound[i] + 1;
            int currentRight = rightBound[i] - 1;
            long long segmentSum = prefixSum[currentRight] - prefixSum[currentLeft - 1];
            long long currentValue = segmentSum * emotionValues[i];
            // 更新最大值
            if (currentValue > maxValue) {
                maxValue = currentValue;
                bestLeft = currentLeft;
                bestRight = currentRight;
            }
        }
        cout << maxValue << '\n';
        cout << bestLeft << " " << bestRight << '\n';
    }
    return 0;
}
```

- **哨兵技巧**：在数组前后各添加一个 $0$，简化边界处理
- **前缀和**：用于快速计算区间和
- **单调栈**：高效计算每个元素的左右边界
- **特殊情况处理**：全 $0$ 序列直接输出 $[1, 1]$

## 总结

本题的核心在于利用单调栈高效地找到以每个元素为最小值的最大区间，从而将 $O(n^2)$ 的暴力枚举优化到 $O(n)$。这种**固定最小值，扩展区间**的思路在很多区间最值问题中都有应用，是一个重要的算法技巧。
