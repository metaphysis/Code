## 题目描述

给定一个由 `'('`, `')'`, `'['`, `']'` 四种字符组成的字符串，要求找到一个**最短的合法括号序列**，使得给定的字符串是它的一个**子序列**（$\texttt{subsequence}$）。

**合法括号序列**的定义如下：
1. 空序列是合法的
2. 如果 $S$ 是合法的，那么 $(S)$ 和 $[S]$ 也是合法的
3. 如果 $A$ 和 $B$ 都是合法的，那么 $AB$ 也是合法的

**子序列**的定义：字符串 $a_1a_2\ldots a_n$ 是字符串 $b_1b_2\ldots b_m$ 的子序列，如果存在下标序列 $1 \leq i_1 < i_2 < \ldots < i_n \leq m$，使得对于所有 $1 \leq j \leq n$，都有 $a_j = b_{i_j}$。

## 题目分析

这个问题可以看作是一个**最短公共超序列**（$\texttt{Shortest Common Supersequence, SCS}$）问题的变种，但有一个重要的约束条件：超序列必须是一个合法的括号序列。

### 关键观察

1. **基本构造**：对于任意一个字符，最短的包含它的合法序列是给它加上匹配的括号。例如：
   - `'('` → `"()"`
   - `'['` → `"[]"`

2. **区间结构**：如果字符串的两端字符是匹配的括号对，那么最优解可能是将中间部分处理后在两端加上这对括号。

3. **组合结构**：合法括号序列可以由多个合法的子序列拼接而成。

### 动态规划思路

我们使用**区间动态规划**来解决这个问题：

- **状态定义**：设 $dp[i][j]$ 表示将子串 $s[i..j]$ 包含为子序列的**最短合法括号序列**的长度。
- **状态转移**：
  1. **两端匹配**：如果 $s[i]$ 和 $s[j]$ 匹配（即 `'('` 与 `')'` 或 `'['` 与 `']'`），则：
     $$
     dp[i][j] = \min(dp[i][j], dp[i+1][j-1] + 2)
     $$
     表示在中间部分的最优解外加上一对匹配的括号。
  
  2. **分割合并**：枚举分割点 $k$ ($i \leq k < j$)：
     $$
     dp[i][j] = \min(dp[i][j], dp[i][k] + dp[k+1][j])
     $$
     表示将序列分成两部分分别处理，然后拼接。

- **初始条件**：
  - 空区间：$dp[i][i-1] = 0$
  - 单字符区间：$dp[i][i] = 2$（因为需要加一对括号）

- **路径记录**：使用 $path[i][j]$ 记录最优解的构造方式：
  - 如果 $path[i][j] = -1$，表示最优解是在两端加括号
  - 如果 $path[i][j] = k$，表示最优解是在位置 $k$ 处分割

### 算法复杂度

- **时间复杂度**：$O(n^3)$，其中 $n \leq 100$，完全可行
- **空间复杂度**：$O(n^2)$

## 代码实现

```cpp
// Brackets Sequence
// UVa ID: 1626
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.330s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <vector>
#include <cstring>
using namespace std;

const int MAXN = 105;
const int INF = 1e9;

int dp[MAXN][MAXN];  // dp[i][j]：子串s[i..j]的最短合法超序列长度
int path[MAXN][MAXN]; // 记录构造路径
string s;

// 判断两个字符是否匹配的括号
bool match(char a, char b) {
    return (a == '(' && b == ')') || (a == '[' && b == ']');
}

// 递归构造最优解
void print(int i, int j) {
    if (i > j) return;
    if (i == j) { // 单字符情况
        if (s[i] == '(' || s[i] == ')') cout << "()";
        else cout << "[]";
        return;
    }
    if (path[i][j] == -1) { // 两端加括号的情况
        cout << s[i];
        print(i + 1, j - 1);
        cout << s[j];
    } else { // 分割的情况
        int k = path[i][j];
        print(i, k);
        print(k + 1, j);
    }
}

void solve() {
    int n = s.length();
    if (n == 0) {
        cout << "\n";
        return;
    }

    // 初始化DP数组
    for (int i = 0; i < n; i++) {
        dp[i][i] = 2; // 单字符需要两个字符的括号对
        dp[i + 1][i] = 0; // 空串长度为0
    }

    // 区间DP
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            dp[i][j] = INF;

            // 情况1：如果两端字符匹配
            if (match(s[i], s[j])) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
                path[i][j] = -1;
            }

            // 情况2：枚举分割点
            for (int k = i; k < j; k++) {
                if (dp[i][k] + dp[k + 1][j] < dp[i][j]) {
                    dp[i][j] = dp[i][k] + dp[k + 1][j];
                    path[i][j] = k;
                }
            }
        }
    }

    // 输出结果
    print(0, n - 1);
    cout << "\n";
}

int main() {
    int t;
    cin >> t;
    cin.ignore(); // 忽略第一行末尾的换行
    while (t--) {
        getline(cin, s); // 读取空行或数据
        if (s.empty()) getline(cin, s); // 如果读到空行，再读一次
        solve();
        if (t) cout << "\n"; // 输出案例间空行
    }
    return 0;
}
```

## 总结

本题通过区间动态规划巧妙地解决了最短合法括号序列问题。关键在于：

1. **状态设计**：$dp[i][j]$ 表示子问题的最优解
2. **转移方程**：考虑两端匹配和中间分割两种情况
3. **路径记录**：通过 $path$ 数组记录构造方式，便于最后输出结果

这种方法不仅保证了找到最短的合法序列，还能高效地构造出具体的解。对于 $n \leq 100$ 的数据规模，$O(n^3)$ 的复杂度是完全可行的。
