## 题目描述

阿里巴巴想要收集分布在一条直线道路上的 $n$ $(n \leq 10000)$ 个宝藏。每个宝藏 $i$ 位于位置 $d_i$，并且有一个截止时间 $t_i$，必须在时间 $t_i$ **之前**到达该位置才能成功收集（注意是严格小于）。收集宝藏本身不耗时，但移动需要时间。阿里巴巴可以从任意位置出发，目标是找到一个访问顺序，使得所有宝藏都在其截止时间前被收集，并且**总完成时间最小**（即最后一个宝藏被收集的时刻）。

### 输入格式

- 第一行：宝藏数量 $n$
- 接下来 $n$ 行：每行两个整数 $d_i$ 和 $t_i$，表示宝藏的位置和截止时间

### 输出格式

- 如果存在可行方案，输出最小完成时间
- 否则输出 `No solution`

### 样例输入
```
5
1 3
3 1
5 8
8 19
10 15
```

### 样例输出
```
11
```

## 题目分析

### 问题本质

这是一个**带截止时间的一维路径规划问题**，可以看作是一维 $\texttt{TSP}$（旅行商问题）的变种，增加了时间窗口约束。我们需要在满足所有截止时间的前提下，找到一条访问所有宝藏的路径，并最小化路径的总时间（即最大位置访问时间）。

### 关键观察

1. **最优路径结构**：在一维直线上，最优路径一定是**连续区间扩展**的形式，即从某个起点开始，向左或向右依次扩展，不会出现跳跃式访问。
2. **状态定义**：可以使用动态规划，定义状态 $dp[i][j][0/1]$ 表示收集完区间 $[i,j]$ 的所有宝藏，且当前位于**左端点** $(0)$ 或**右端点** $(1)$ 的最小时间。
3. **时间约束**：每次状态转移时，必须检查新状态的累计时间是否严格小于当前宝藏的截止时间。

## 解题思路

### 动态规划状态设计

我们定义：
- $dp[i][j][0]$：收集完区间 $[i, j]$ 的所有宝藏，且最后停留在**左端点 $i$** 的最小时间
- $dp[i][j][1]$：收集完区间 $[i, j]$ 的所有宝藏，且最后停留在**右端点 $j$** 的最小时间

### 状态转移方程

设 $dist(a, b) = |d_a - d_b|$ 表示从位置 $a$ 到位置 $b$ 的移动时间。

#### 从 $dp[i][j][0]$ 扩展：
1. 从 $i$ 向左走到 $i-1$：
   $$
   dp[i-1][j][0] = \min\left(dp[i-1][j][0],\ dp[i][j][0] + dist(i, i-1)\right)
   $$
   需满足：$dp[i][j][0] + dist(i, i-1) < t_{i-1}$
2. 从 $i$ 向右走到 $j+1$（实际不会发生，因为 $j+1$ 不在区间内）

#### 从 $dp[i][j][1]$ 扩展：
1. 从 $j$ 向左走到 $i-1$：
   $$
   dp[i-1][j][0] = \min\left(dp[i-1][j][0],\ dp[i][j][1] + dist(j, i-1)\right)
   $$
   需满足：$dp[i][j][1] + dist(j, i-1) < t_{i-1}$
2. 从 $j$ 向右走到 $j+1$：
   $$
   dp[i][j+1][1] = \min\left(dp[i][j+1][1],\ dp[i][j][1] + dist(j, j+1)\right)
   $$
   需满足：$dp[i][j][1] + dist(j, j+1) < t_{j+1}$

### 算法步骤

1. **排序**：将所有宝藏按位置升序排序。
2. **初始化**：对于每个单独宝藏 $i$，如果 $0 < t_i$，则 $dp[i][i][0] = dp[i][i][1] = 0$。
3. **区间 DP**：按区间长度从小到大进行动态规划：
   - 对于区间 $[i, j]$，尝试从四种可能的前驱状态转移过来
   - 每次转移检查时间约束
4. **结果提取**：最终答案为 $\min(dp[0][n-1][0], dp[0][n-1][1])$，如果均为无穷大则无解。

### 复杂度分析

- **时间复杂度**：$O(n^2)$，需要枚举所有区间
- **空间复杂度**：使用滚动数组优化后为 $O(n)$

```cpp
// Alibaba

#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

struct Treasure {
    int pos;
    int deadline;
};

bool comparePos(const Treasure& a, const Treasure& b) {
    return a.pos < b.pos;
}

int main() {
    int n;
    while (cin >> n) {
        vector<Treasure> treasures(n);
        for (int i = 0; i < n; i++) {
            cin >> treasures[i].pos >> treasures[i].deadline;
        }
        
        // 按位置排序
        sort(treasures.begin(), treasures.end(), comparePos);
        
        // 滚动数组DP：dp0[i][0/1]表示当前区间，dp1[i][0/1]表示下一区间
        vector<vector<int>> dp0(n, vector<int>(2, INT_MAX));
        vector<vector<int>> dp1(n, vector<int>(2, INT_MAX));
        
        // 初始化单个宝藏
        for (int i = 0; i < n; i++) {
            if (0 < treasures[i].deadline) {
                dp0[i][0] = 0;
                dp0[i][1] = 0;
            }
        }
        
        // 区间DP，按长度递增
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                dp1[i][0] = INT_MAX;
                dp1[i][1] = INT_MAX;
                
                // 从dp[i+1][j][0]扩展到dp[i][j][0]
                if (dp0[i+1][0] != INT_MAX) {
                    int move_time = treasures[i+1].pos - treasures[i].pos;
                    int new_time = dp0[i+1][0] + move_time;
                    if (new_time < treasures[i].deadline) {
                        dp1[i][0] = min(dp1[i][0], new_time);
                    }
                }
                
                // 从dp[i+1][j][1]扩展到dp[i][j][0]
                if (dp0[i+1][1] != INT_MAX) {
                    int move_time = treasures[j].pos - treasures[i].pos;
                    int new_time = dp0[i+1][1] + move_time;
                    if (new_time < treasures[i].deadline) {
                        dp1[i][0] = min(dp1[i][0], new_time);
                    }
                }
                
                // 从dp[i][j-1][0]扩展到dp[i][j][1]
                if (dp0[i][0] != INT_MAX) {
                    int move_time = treasures[j].pos - treasures[i].pos;
                    int new_time = dp0[i][0] + move_time;
                    if (new_time < treasures[j].deadline) {
                        dp1[i][1] = min(dp1[i][1], new_time);
                    }
                }
                
                // 从dp[i][j-1][1]扩展到dp[i][j][1]
                if (dp0[i][1] != INT_MAX) {
                    int move_time = treasures[j].pos - treasures[j-1].pos;
                    int new_time = dp0[i][1] + move_time;
                    if (new_time < treasures[j].deadline) {
                        dp1[i][1] = min(dp1[i][1], new_time);
                    }
                }
            }
            swap(dp0, dp1);
        }
        
        int result = min(dp0[0][0], dp0[0][1]);
        if (result == INT_MAX) {
            cout << "No solution" << endl;
        } else {
            cout << result << endl;
        }
    }
    return 0;
}
```

## 总结

本题通过**区间动态规划**的方法，巧妙地处理了一维直线上的带截止时间路径规划问题。关键在于将问题分解为更小的区间子问题，并通过状态记录当前位置（左端点或右端点）来减少状态数。排序预处理确保了位置的有序性，滚动数组优化则大幅降低了空间复杂度，使得算法能够在 $n \leq 10000$ 的规模下高效运行。

这种“区间 $\texttt{DP}$ + 滚动数组”的思路，在许多一维路径规划问题中都有广泛应用，值得深入理解和掌握。
