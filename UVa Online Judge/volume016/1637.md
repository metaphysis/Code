## 题目描述

$\texttt{Double Patience}$ 是一种单人纸牌游戏，使用一副标准的 $36$ 张牌（从 $6$ 到 $\texttt{A}$，四种花色）。游戏开始时，将洗好的牌在桌上摆成 $9$ 堆，每堆 $4$ 张牌，牌面朝上。

玩家轮流进行操作。在每一轮中，玩家可以从任意两堆中取出顶部的牌，如果这两张牌的**点数相同**，则可以将它们移除。如果存在多种可能的移除方式，玩家可以任意选择一种。如果所有牌都被移除，玩家获胜；如果桌上仍有牌但无法进行任何合法移动，玩家失败。

$\texttt{George}$ 喜欢玩这个游戏，但当存在多种移除选择时，他不知道该如何选择。他不想过多思考，因此在这种情况下，他会从所有可能的牌对中**等概率随机选择一对**进行移除。

你的任务是：给定游戏开始时桌上的牌堆布局，计算 $\texttt{George}$ 按照这种随机策略获胜的概率。

---

## 输入格式

输入包含多个测试用例，每个测试用例由 $9$ 行组成。每行描述一堆牌，从底部牌到顶部牌依次给出。每张牌由两个字符表示：第一个字符表示点数，第二个字符表示花色。

- **点数**：$\texttt{6}$、$\texttt{7}$、$\texttt{8}$、$\texttt{9}$、$\texttt{T}$（$10$）、$\texttt{J}$（$\texttt{Jack}$）、$\texttt{Q}$（$\texttt{Queen}$）、$\texttt{K}$（$\texttt{King}$）、$\texttt{A}$（$\texttt{Ace}$）
- **花色**：$\texttt{S}$（$\texttt{Spades}$）、$\texttt{C}$（$\texttt{Clubs}$）、$\texttt{D}$（$\texttt{Diamonds}$）、$\texttt{H}$（$\texttt{Hearts}$）

例如，$\texttt{KS}$ 表示黑桃 $\texttt{King}$。

每张牌之间用一个空格分隔。

---

## 输出格式

对于每个测试用例，输出一行一个实数，表示 $\texttt{George}$ 获胜的概率，精确到 $10^{-6}$。

## 题目分析

### 游戏规则回顾

- 初始状态：$9$ 堆牌，每堆 $4$ 张，牌面朝上。
- 每次操作：选择两堆，移除其顶部牌（仅当这两张牌点数相同）。
- 胜利条件：所有牌被移除。
- 失败条件：仍有牌但无法继续。
- $\texttt{George}$ 的策略：若存在 $k$ 对可移除的牌，则每对以概率 $\frac{1}{k}$ 被选中。

### 问题本质

这是一个**状态搜索 + 记忆化** 的问题。我们需要计算从初始状态出发，按照随机策略获胜的概率。

### 状态表示

我们可以用一个长度为 $9$ 的数组表示当前状态，其中每个元素表示该堆当前顶部牌的位置（$0$ 表示顶部牌，$1$ 表示下一张，依此类推）。如果某堆已经为空，则将其位置设为 $4$。

由于每堆最多有 $4$ 张牌，加上“空堆”状态，每个位置有 $5$ 种可能。因此总状态数为：

$$
5^9 = 1953125
$$

这个数量在合理范围内，适合使用记忆化搜索。

### 状态编码

为了高效存储状态，我们可以将 $9$ 个位置编码为一个整数：

$$
\text{state} = \sum_{i=0}^{8} \text{tops}[i] \times 5^i
$$

这样每个状态对应一个唯一的整数，便于使用 `map` 进行记忆化。

### 状态转移

设当前状态为 $state$：

1. 解码得到各堆顶部位置 $tops[0..8]$。
2. 检查是否所有堆为空：若是，返回概率 $1.0$（胜利）。
3. 找出所有可移除的牌对：
   - 遍历所有不同的两堆 $i$ 和 $j$（$i < j$）。
   - 若两堆均非空，且顶部牌点数相同，则记录 $(i, j)$。
4. 若没有可移除的牌对，返回 $0.0$（失败）。
5. 若有 $k$ 对可移除的牌对，则对每一对 $(i, j)$：
   - 更新 $tops[i]$ 和 $tops[j]$（加 $1$，表示移除顶部牌）。
   - 编码为新状态 $newState$。
   - 递归计算 $\texttt{dfs}(newState)$，并累加概率。
6. 最终概率为：

$$
P(\text{state}) = \frac{1}{k} \sum_{\text{每对}} P(\text{newState})
$$

### 输入处理细节

题目中每行的输入顺序是**从底部牌到顶部牌**。为了便于处理，我们在读入时将顺序反转，使得：

- `piles[i][0]` 存储顶部牌
- `piles[i][3]` 存储底部牌

这样，在游戏过程中，移除顶部牌只需将对应堆的索引加 $1$，即可访问下一张牌。

---

## 算法复杂度

- 状态总数：$5^9 = 1953125$
- 每个状态最多有 $\binom{9}{2} = 36$ 种可能的移动
- 使用记忆化后，每个状态只计算一次
- 总复杂度约为 $O(5^9 \times 36)$，在合理范围内

## 参考代码

```cpp
// Double Patience
// UVa ID: 1637
// Verdict: Accepted
// Submission Date: 2025-10-26
// UVa Run Time: 0.030s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

// 全局变量存储输入牌堆（反向存储：索引0是顶部牌，索引3是底部牌）
vector<vector<string>> piles(9, vector<string>(4));
map<int, double> dp; // 记忆化：state -> 获胜概率

// 从状态编码中获取各堆顶部位置
void decode(int state, vector<int>& tops) {
    for (int i = 0; i < 9; i++) tops[i] = state % 5, state /= 5;
}

// 将各堆顶部位置编码为整数
int encode(const vector<int>& tops) {
    int state = 0, base = 1;
    for (int i = 0; i < 9; i++) state += tops[i] * base, base *= 5;
    return state;
}

// 递归计算获胜概率
double dfs(int state) {
    if (dp.count(state)) return dp[state];
    vector<int> tops(9);
    decode(state, tops);
    // 检查是否所有堆都空了
    bool allEmpty = true;
    for (int i = 0; i < 9; i++) {
        if (tops[i] < 4) {
            allEmpty = false;
            break;
        }
    }
    if (allEmpty) return 1.0;
    // 找出所有可移除的牌对
    vector<pair<int, int>> moves;
    for (int i = 0; i < 9; i++) {
        if (tops[i] >= 4) continue; // 堆空
        for (int j = i + 1; j < 9; j++) {
            if (tops[j] >= 4) continue;
            // 现在 piles[i][tops[i]] 是顶部牌（因为反向存储）
            string card1 = piles[i][tops[i]];
            string card2 = piles[j][tops[j]];
            if (card1[0] == card2[0]) // 相同点数
                moves.push_back({i, j});
        }
    }
    if (moves.empty()) return 0.0; // 无合法移动，输
    double p = 0.0;
    int k = moves.size();
    for (auto& move : moves) {
        int i = move.first, j = move.second;
        vector<int> newTops = tops;
        newTops[i]++;  // 移除顶部牌，索引递增访问下面的牌
        newTops[j]++;
        int newState = encode(newTops);
        p += dfs(newState);
    }
    p /= k;
    dp[state] = p;
    return p;
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    while (true) {
        // 读取输入并反向存储
        for (int i = 0; i < 9; i++)
            // 正向读入：底部牌 → 顶部牌
            // 反向存储：索引0存顶部牌，索引3存底部牌
            for (int j = 3; j >= 0; j--)
                if (!(cin >> piles[i][j]))
                    return 0; // 输入结束
        dp.clear();
        // 初始时每堆顶部是第0张牌（因为反向存储后索引0是顶部牌）
        vector<int> startTops(9, 0);
        int startState = encode(startTops);
        double r = dfs(startState);
        cout << fixed << setprecision(6) << r << "\n";
    }
    return 0;
}
```

## 总结

本题通过**状态压缩**和**记忆化搜索**有效解决了随机策略下的获胜概率计算问题。关键在于：

- 合理表示和编码游戏状态
- 正确处理输入顺序和牌堆索引
- 使用记忆化避免重复计算

该解法在时间和空间复杂度上均满足题目要求，能够高效处理最大规模的数据。
