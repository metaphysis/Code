## 题目描述

有 $n$ 根高度分别为 $1, 2, \ldots, n$ 的杆子排成一行。从左侧或右侧观察这些杆子时，较高的杆子会遮挡住较矮的杆子。例如，对于 $4$ 根杆子的两种排列方式，可能从左侧只能看到 $1$ 根杆子，从右侧能看到 $2$ 根杆子。

要求编写程序计算满足条件的排列数目：对于 $n$ 根杆子，从左侧能看到 $l$ 根，从右侧能看到 $r$ 根。

**输入格式**  
- 第一行输入测试用例数量 $T$  
- 每个测试用例一行，包含三个整数 $n$, $l$, $r$ ($1 \leq l, r \leq n \leq 20$)

**输出格式**  
- 每个测试用例输出一行，表示满足条件的排列数目

## 题目分析

这是一个经典的组合数学问题，涉及排列的可见性计数。关键在于理解最高的杆子（高度为 $n$）在排列中的位置对可见性的影响。

### 可见性规则
- 从左侧看：一根杆子可见当且仅当它比左边所有杆子都高
- 从右侧看：一根杆子可见当且仅当它比右边所有杆子都高

### 动态规划思路

定义 $dp[n][l][r]$ 表示 $n$ 根杆子的排列中，从左侧看到 $l$ 根、从右侧看到 $r$ 根的方案数。

考虑最矮的杆子（高度 $1$）的放置位置：

1. **放在最左边**
   - 最矮杆必定从左侧可见，因此左侧可见数增加 $1$
   - 右侧可见数不变
   - 贡献：$dp[n-1][l-1][r]$

2. **放在最右边**
   - 最矮杆必定从右侧可见，因此右侧可见数增加 $1$
   - 左侧可见数不变
   - 贡献：$dp[n-1][l][r-1]$

3. **放在中间位置**（有 $n-2$ 个选择）
   - 最矮杆在中间时，既不会增加左侧可见数也不会增加右侧可见数
   - 因为它在中间，左右两侧都有杆子，不会影响可见性计数
   - 贡献：$(n-2) \times dp[n-1][l][r]$

由此得到递推公式：
$$dp[n][l][r] = dp[n-1][l-1][r] + dp[n-1][l][r-1] + (n-2) \times dp[n-1][l][r]$$

### 边界条件
- 只有 $1$ 根杆子时：$dp[1][1][1] = 1$
- 其他情况初始为 $0$

### 算法复杂度
- 预处理：$O(n^3)$，其中 $n \leq 20$，计算量可接受
- 查询：$O(1)$

## 代码实现

```cpp
// Pole Arrangement
// UVa ID: 1638
// Verdict: Accepted
// Submission Date: 2025-10-23
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
using LL = long long; // 使用 long long 防止溢出
int main() {
    const int MAX_N = 20;
    // dp[n][l][r] 表示 n 根杆子，左边看到 l 根，右边看到 r 根的方案数
    vector<vector<vector<LL>>> dp(MAX_N + 1, vector<vector<LL>>(MAX_N + 1, vector<LL>(MAX_N + 1, 0)));
    // 初始化：只有 1 根杆子时，左右都只能看到这 1 根
    dp[1][1][1] = 1;
    // 动态规划预处理所有情况
    for (int n = 2; n <= MAX_N; n++)
        for (int l = 1; l <= n; l++)
            for (int r = 1; r <= n; r++)
                // 递推公式：
                // 1. 最矮杆放最左边：左边可见数 +1
                // 2. 最矮杆放最右边：右边可见数 +1  
                // 3. 最矮杆放中间：有 n-2 种选择，可见数不变
                dp[n][l][r] = dp[n - 1][l - 1][r] + dp[n - 1][l][r - 1] + (n - 2) * dp[n - 1][l][r];
    int T;
    cin >> T;
    while (T--) {
        int n, l, r;
        cin >> n >> l >> r;
        // 直接查询预处理结果
        cout << dp[n][l][r] << "\n";
    }

    return 0;
}
```

本题通过动态规划巧妙解决了杆子排列的可见性计数问题。关键在于分析最高杆子的位置对可见性的影响，并建立相应的递推关系。预处理所有可能情况后，即可在常数时间内回答每个查询。
