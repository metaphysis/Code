## 题目描述

给定两个整数 $a$ 和 $b$（$0 < a, b < 10^7$），将区间 $[a, b]$ 内的所有整数（包含端点）写成一个列表。任务是统计在列表中，数码 $0$ 到 $9$ 各自出现的总次数。

例如，若 $a = 1024$，$b = 1032$，列表为：
```
1024 1025 1026 1027 1028 1029 1030 1031 1032
```
其中数码 $0$ 出现 $10$ 次，数码 $1$ 出现 $10$ 次，数码 $2$ 出现 $7$ 次，数码 $3$ 出现 $3$ 次，其余数码均为 $0$ 次。

## 输入格式

输入包含至多 $500$ 行，每行两个整数 $a$ 和 $b$。输入以一行 `0 0` 结束，该行不作处理。

## 输出格式

对于每一组输入，输出一行，包含 $10$ 个由空格分隔的数字，依次表示数码 $0$ 到 $9$ 在区间 $[a, b]$ 中出现的总次数。

## 题目分析

本题的核心是高效统计区间内所有数字中每个数码的出现次数。由于 $a$ 和 $b$ 的上限为 $10^7$，若直接遍历区间内的每个数字并逐位统计，最坏情况下单组数据需处理 $10^7$ 个数字，每组数字需处理 $7$ 位，总操作次数约为 $7 \times 10^7$，而输入最多有 $500$ 组，时间上不可接受。因此需要利用数位统计的规律，采用数学方法或动态规划进行高效计算。

本题的经典解法有两种：其一是基于数学递推的直接统计法，按位计算每个数码的出现次数；其二是数位型动态规划，通过记忆化搜索逐位决策并累加计数。两种方法都能在 $O(\log n)$ 或 $O(\log^2 n)$ 的时间内完成单次数码统计，足以应对题目要求。

## 解题思路

### 思路一：直接递推（数学方法）

核心思想是分别计算 $[0, n]$ 中每个数码的出现次数，再利用前缀和相减得到 $[a, b]$ 的结果。对于给定的 $n$ 和目标数码 $d$，按十进制位从低位到高位依次处理。设当前位权值为 $\textit{base}$（$1, 10, 100, \dots$），当前位的数字为 $\textit{cur}$，高位部分为 $\textit{high}$，低位部分为 $\textit{low}$。

对于非零数码 $d \neq 0$：
- 若 $\textit{cur} < d$，该位上数码 $d$ 出现的次数为 $\textit{high} \times \textit{base}$。
- 若 $\textit{cur} = d$，次数为 $\textit{high} \times \textit{base} + \textit{low} + 1$。
- 若 $\textit{cur} > d$，次数为 $(\textit{high} + 1) \times \textit{base}$。

对于数码 $0$，需要特殊处理前导零。数码 $0$ 不能在最高位出现（否则会引入无效的前导零），因此仅在 $\textit{high} \neq 0$ 时计算：
- 若 $\textit{cur} = 0$，次数为 $(\textit{high} - 1) \times \textit{base} + \textit{low} + 1$。
- 若 $\textit{cur} > 0$，次数为 $\textit{high} \times \textit{base}$。

将所有位的贡献累加，即得到 $[0, n]$ 中数码 $d$ 的总出现次数。对于 $[1, n]$ 的情况，数码 $0$ 的处理稍作调整即可，原代码中通过边界条件处理。

### 思路二：数位动态规划

定义 $\textit{solve}(n, d)$ 为 $[0, n]$ 中数码 $d$ 的出现次数，最终答案为 $\textit{solve}(b, d) - \textit{solve}(a-1, d)$。采用记忆化搜索实现数位 $\texttt{DP}$。

状态定义：$\textit{dp}[\textit{pos}][\textit{cnt}][\textit{tight}][\textit{lead}]$，其中：
- $\textit{pos}$ 表示当前处理的位数（从高位到低位）。
- $\textit{cnt}$ 表示已经统计到的目标数码 $d$ 的个数。
- $\textit{tight}$ 表示当前前缀是否与原数 $n$ 的前缀完全相同（即是否受到上界约束）。
- $\textit{lead}$ 表示是否已经开始非前导零部分（用于正确处理数码 $0$ 的统计）。

边界条件：当 $\textit{pos}$ 到达字符串末尾时，返回 $\textit{cnt}$。

转移过程：枚举当前位的数字 $x$（取值范围由 $\textit{tight}$ 决定），更新：
- $\textit{nextTight} = \textit{tight} \ \&\&\ (x == \textit{limit})$。
- $\textit{nextLead} = \textit{lead} \ ||\ (x \neq 0)$。
- $\textit{add} = (\textit{nextLead} \ \&\&\ x == d)$，即若当前位是有效数字且等于目标数码，则增加 $1$。

递归调用 $\textit{dfs}(\textit{pos}+1, \textit{cnt}+\textit{add}, \textit{nextTight}, \textit{nextLead})$，并累加结果。利用记忆化数组避免重复计算，状态总数约为 $12 \times 12 \times 2 \times 2 = 576$，效率极高。

## 代码实现

### 直接递推版本

```cpp
// The Counting Problem
// UVa ID: 1640
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

// 计算从1到n中数字d出现的次数
ll countDigit(ll n, int d) {
    if (n < 1) return 0;  // 处理边界情况
    ll ans = 0, base = 1; // base表示当前位的权值
    while (base <= n) {
        ll cur = (n / base) % 10;   // 当前位的数字
        ll high = n / (base * 10);  // 高位部分
        ll low = n % base;          // 低位部分
        
        if (d != 0) {  // 处理非零数字
            if (cur < d) {
                ans += high * base;
            } else if (cur == d) {
                ans += high * base + low + 1;
            } else {
                ans += (high + 1) * base;
            }
        } else {  // 处理数字0，需要特殊处理前导零
            if (high != 0) {  // 确保不是最高位
                if (cur == 0) {
                    ans += (high - 1) * base + low + 1;
                } else {
                    ans += high * base;
                }
            }
        }
        base *= 10;  // 移动到下一位
    }
    return ans;
}

int main() {
    ll a, b;
    while (cin >> a >> b && (a || b)) {  // 读取直到遇到0 0
        if (a > b) swap(a, b);  // 确保a <= b
        // 输出每个数字的出现次数
        for (int d = 0; d < 10; d++) {
            if (d > 0) cout << " ";
            cout << countDigit(b, d) - countDigit(a - 1, d);
        }
        cout << endl;
    }
    return 0;
}
```

### 数位动态规划版本

```cpp
// The Counting Problem
// UVa ID: 1640
// Verdict: Accepted
// Submission Date: 2026-06-07
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

ll dp[12][12][2][2];  // dp[pos][cnt][tight][lead]
string s;
int t;  // 目标数字

ll dfs(int pos, int cnt, bool tight, bool lead) {
    if (pos == s.size()) return cnt;
    if (~dp[pos][cnt][tight][lead]) return dp[pos][cnt][tight][lead];
    ll r = 0;
    int limit = tight ? s[pos] - '0' : 9;
    for (int d = 0; d <= limit; d++) {
        bool nextTight = tight && (d == limit), nextLead = lead || d;
        int add = nextLead && (d == t);
        r += dfs(pos + 1, cnt + add, nextTight, nextLead);
    }
    return dp[pos][cnt][tight][lead] = r;
}

ll solve(ll n, int d) {
    if (n < 0) return 0;
    s = to_string(n);
    t = d;
    memset(dp, -1, sizeof(dp));
    return dfs(0, 0, true, false);
}

int main() {
    ll a, b;
    while (cin >> a >> b && (a || b)) {
        if (a > b) swap(a, b);
        for (int d = 0; d < 10; ++d) {
            if (d) cout << ' ';
            cout << solve(b, d) - solve(a - 1, d);
        }
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题是经典的数位统计问题，两种解法各有优劣。直接递推法时间复杂度为 $O(\log_{10} n)$，常数极小，运行速度最快，但需要针对数码 $0$ 单独处理前导零，逻辑稍显复杂。数位 $\texttt{DP}$ 法时间复杂度为 $O(\log_{10}^2 n)$，虽然稍慢一些，但状态清晰、逻辑统一，无需区分数码 $0$ 的特殊情况，且易于扩展到更复杂的数位约束问题（如统计不含某数字的数字个数、数字和约束等）。在实际编程中，两种方法均可通过本题的数据范围，读者可根据自身偏好选择实现。无论采用哪种方法，核心思想都是利用数位的规律将区间统计转化为前缀和作差，从而避免逐数枚举，达到高效计算的目的。
