[UVa 1643 Angle and Squares](https://blog.csdn.net/metaphysis/article/details/156983877)

## 题目描述

在第一象限的平面直角坐标系中，有一个角，其顶点固定在原点 $O$ 上，两条射线 $OA$ 和 $OB$ 由输入给出。给定 $N$ 个正方形，这些正方形的边必须平行于坐标轴，且可以在第一象限内任意平移（但不能旋转）。要求将这些正方形放置在角内，使得由两条射线和正方形边界围成的封闭区域面积最大，且这个面积不包括正方形自身的面积。

**输入**：多个测试用例。每个测试用例以一行整数 $N$ （$0 < N < 10$）开始，表示正方形数量。接下来一行包含四个浮点数 $x_a, y_a, x_b, y_b$ ，表示点 $A(x_a, y_a)$ 和 $B(x_b, y_b)$ ，射线 $OA$ 和 $OB$ 构成角。随后 $N$ 行每行一个浮点数，表示正方形边长。所有浮点数在 $[1, 20]$ 范围内。当 $N = 0$ 时输入结束。

**输出**：对每个测试用例，输出一个浮点数，表示最大可围成的面积，保留三位小数。

## 题目分析

这是一个几何最优化问题。关键是要理解如何放置正方形才能最大化由角和正方形边界围成的区域面积。

### 关键观察

1. **正方形必须完全在角内**：由于正方形边平行坐标轴，且在第一象限，它们必须位于两条射线之间。
2. **最优放置方式**：通过几何分析可以发现，最优策略是将所有正方形沿着一条与坐标轴成 $135^\circ$ 的直线紧密排列，使得：
   - 第一个正方形的**左上角**在射线 $OB$（上边界）上
   - 最后一个正方形的**右下角**在射线 $OA$（下边界）上
   - 中间每个正方形的左上角紧贴前一个正方形的右下角
   
   这样所有正方形的对角线共线，形成一条连续的斜线段。

### 数学推导

设射线 $OA$ 方程为 $y = k_1 x$ （下边界）  
设射线 $OB$ 方程为 $y = k_2 x$ （上边界），且 $k_1 \le k_2$ 。

设正方形边长依次为 $a_1, a_2, \dots, a_N$ ，令 $S = \sum_{i=1}^N a_i$ 。

按照上述最优放置方式：
- 第一个正方形左上角坐标为 $(x_1, y_1)$ ，在 $OB$ 上：$y_1 = k_2 x_1$ 。
- 最后一个正方形右下角在 $OA$ 上。
- 所有正方形对角共线，方向向量为 $(1, -1)$（即与 $x$ 轴成 $135^\circ$ 角）。

设这条斜线段从 $P$（在 $OB$ 上）到 $Q$（在 $OA$ 上），长度为 $S\sqrt{2}$ 。  
由几何关系可得：
$$
x_1 = \frac{S(k_1 + 1)}{k_2 - k_1}
$$
$$
y_1 = k_2 x_1
$$

这条斜线段与两条射线围成一个三角形 $OPQ$ ，其面积为：
$$
Area_{\triangle OPQ} = \frac{1}{2} \cdot S^2 \cdot \frac{(k_1 + 1)(k_2 + 1)}{k_2 - k_1}
$$

### 面积计算

在三角形 $OPQ$ 中，包含每个正方形的一半面积（因为每个正方形被其对角线平分）。但题目要求围成区域**不包括**正方形面积，因此需要从三角形面积中减去这些部分。

所求面积 = 三角形 $OPQ$ 面积 - 所有正方形面积的一半：
$$
\text{答案} = \frac{1}{2} \cdot S^2 \cdot \frac{(k_1 + 1)(k_2 + 1)}{k_2 - k_1} - \frac{1}{2} \sum_{i=1}^N a_i^2
$$

### 重要性质

从公式可以看出，答案**与正方形的排列顺序无关**，只与边长之和 $S$ 以及各边长平方和有关。因此无需枚举排列，直接计算即可。

## 算法步骤

1. 读取 $N$ ，若为 $0$ 则结束。
2. 读取 $x_a, y_a, x_b, y_b$ ，计算斜率 $k_1 = y_a / x_a$ ，$k_2 = y_b / x_b$ 。
3. 确保 $k_1 \le k_2$ （若不满足则交换）。
4. 读取 $N$ 个正方形边长，计算：
   - $S = \sum a_i$ （边长之和）
   - $sumSq = \sum a_i^2$ （边长平方和）
5. 计算：
   $$
   result = \frac{1}{2} \cdot S^2 \cdot \frac{(k_1 + 1)(k_2 + 1)}{k_2 - k_1} - \frac{1}{2} \cdot sumSq
   $$
6. 若结果小于 $0$ （由于浮点误差），则设为 $0$ 。
7. 输出结果，保留三位小数。

## 时间复杂度

每个测试用例 $O(N)$ ，由于 $N < 10$ ，非常高效。

## 空间复杂度

$O(1)$ ，仅需常数空间。

## 代码实现

```cpp
// Angle and Squares
// UVa ID: 1643

// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    while (cin >> n && n != 0) {
        double xa, ya, xb, yb;
        cin >> xa >> ya >> xb >> yb;
        double k1 = ya / xa, k2 = yb / xb;
        if (k1 > k2) swap(k1, k2); // 确保 k1 <= k2
        double S = 0.0;
        double sumSquares = 0.0;
        for (int i = 0; i < n; ++i) {
            double a;
            cin >> a;
            S += a;
            sumSquares += a * a;
        }
        double triangleArea = 0.5 * S * S * (k1 + 1.0) * (k2 + 1.0) / (k2 - k1);
        double result = triangleArea - 0.5 * sumSquares;
        cout << fixed << setprecision(3) << result << '\n';
    }
    return 0;
}
```

## 样例验证

### 样例输入

```
1
2.000 3.000 3.000 2.000
1.000
0
```

### 计算过程

1. $k_1 = 3.000 / 2.000 = 1.5$ ，$k_2 = 2.000 / 3.000 \approx 0.6667$  
   由于 $k_1 > k_2$ ，交换后 $k_1 = 0.6667$ ，$k_2 = 1.5$ 。

2. $S = 1.0$ ，$sumSquares = 1.0$ 。

3. 三角形面积：
   $$
   triangleArea = 0.5 \times 1^2 \times \frac{(0.6667 + 1)(1.5 + 1)}{1.5 - 0.6667} \approx 2.5
   $$

4. 答案：
   $$
   result = 2.5 - 0.5 \times 1.0 = 2.0
   $$

与样例输出一致。

## 总结

本题的关键在于发现最优放置方式下所有正方形对角共线，从而将问题转化为简单的几何公式计算。这种解法避免了复杂的搜索，直接通过数学推导得到简洁高效的解决方案。
