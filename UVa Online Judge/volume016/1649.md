## 题目描述

$\texttt{Gunnar}$ 是一位健忘的研究员，他在计算二项式系数 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ 时得到了结果 $m$ ，但忘记了输入参数 $n$ 和 $k$ 。现在给定 $m$ ，要求找出所有满足 $\binom{n}{k} = m$ 的整数对 $(n, k)$ ，其中 $n \ge k \ge 0$ 。

**输入** ：第一行一个整数 $t$ 表示测试用例数量（ $t \le 100$ ），随后 $t$ 行每行一个整数 $m$ （ $2 \le m \le 10^{15}$ ）。

**输出** ：对于每个测试用例，第一行输出解的数量，第二行按 $n$ 递增、 $n$ 相同时按 $k$ 递增的顺序输出所有 $(n, k)$ 对。

## 题目分析

本题的核心是求解组合数方程：

$$
\binom{n}{k} = m
$$

其中 $m$ 已知，需要找出所有整数解 $(n, k)$ 。

### 关键观察

1. **平凡解** ： $(m, 1)$ 和 $(m, m-1)$ 总是解，因为 $\binom{m}{1} = \binom{m}{m-1} = m$ 。

2. **对称性** ： $\binom{n}{k} = \binom{n}{n-k}$ ，因此每个解 $(n, k)$ 对应另一个解 $(n, n-k)$ （除非 $k = n-k$ ）。

3. **$k$ 的范围限制** ：当 $k \ge 2$ 时，由于 $\binom{n}{2} = \frac{n(n-1)}{2} \le m$ ，可得 $n \approx O(\sqrt{2m})$ 。实际上，随着 $k$ 增大， $n$ 增长更快， $k$ 不会太大。对于 $m \le 10^{15}$ ， $k$ 最大约为 $30$ 。

4. **数学变换** ：将原方程改写为：
$$
   n \times (n-1) \times \cdots \times (n-k+1) = m \times k!
$$
   两边取对数：
$$
   \sum_{i=0}^{k-1} \log(n-i) = \log(m) + \log(k!)
$$

## 解题思路

基于以上观察，我们采用以下算法：

### 1. 处理平凡解
直接加入 $(m, 1)$ 和 $(m, m-1)$ 。

### 2. 枚举 $k$
对于 $k$ 从 $2$ 到 $30$ （因为当 $k > 30$ 时， $\binom{k+1}{k} = k+1 > m$ 或 $k!$ 过大）：
- 计算 $\log(m \times k!) = \log(m) + \log(k!)$
- 计算 $(m \times k!)^{1/k} = \exp\left(\frac{\log(m) + \log(k!)}{k}\right)$
- 估计 $n$ 的值： $n \approx \text{round}\left((m \times k!)^{1/k} + \frac{k-1}{2}\right)$

### 3. 小范围搜索
在 $n$ 的估计值附近小范围（如 $\pm 3$ ）搜索：
- 计算 $\sum_{i=0}^{k-1} \log(n-i)$
- 如果与 $\log(m) + \log(k!)$ 的差小于 $10^{-12}$ ，则认为找到候选解
- 加入 $(n, k)$ 和对称解 $(n, n-k)$ （如果不同）

### 4. 去重排序
最后对所有解排序去重，按题目要求输出。

### 算法优势
- **避免整数溢出** ：使用对数运算，完全避免 $k!$ 和连续乘积的溢出问题
- **高效搜索** ：浮点数估计准确，只需在极小的范围内搜索
- **数学精确** ：通过对数相等判断，避免了浮点数直接相乘的误差

## 时间复杂度分析
- 外层循环 $k$ ：最多 $29$ 次
- 内层搜索 $n$ ：最多 $7$ 次（估计值 $\pm 3$ ）
- 每次计算对数： $O(k)$ ，最大 $30$ 次
- 总计算量约 $29 \times 7 \times 30 \approx 6000$ 次浮点运算
- 对于 $100$ 个测试用例，完全在可接受范围内

```cpp
// Binomial Coefficients
// UVa ID: 1649
// Verdict: Accepted

// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const double EPS = 1e-12;  // 更小的误差阈值

int main() {
    int t; cin >> t;
    while (t--) {
        ll m; cin >> m;
        vector<pair<ll, ll>> ans;
        // 加入边界解
        ans.push_back({m, 1});
        ans.push_back({m, m - 1});
        // 预先计算 log(2), log(3), ..., log(60)
        vector<double> log_fact(61, 0);
        for (int i = 2; i <= 60; i++) log_fact[i] = log_fact[i - 1] + log(i);
        double log_m = log(m);
        // 枚举 k 从 2 到 60
        for (ll k = 2; k <= 60; k++) {
            // 计算 log(m × k!) = log(m) + log(k!)
            double target_log = log_m + log_fact[k];
            // 计算 (m × k!)^(1/k) = exp(target_log / k)
            double target_root = exp(target_log / k);
            // 估算 n：n ≈ target_root + (k-1)/2
            ll est = llround(target_root) + (k - 1) / 2;
            if (est < k) break;
            // 搜索范围：在估计值附近小范围搜索
            // 因为浮点数估计通常很准确
            ll left = max(k, est - 3), right = est + 3;
            for (ll n = left; n <= right; n++) {
                // 快速计算 log(n × (n-1) × ... × (n-k+1))
                // 这等于 log(n!) - log((n-k)!)
                double product_log = 0.0;
                for (ll i = 0; i < k; i++) product_log += log(n - i);
                // 浮点数匹配检查
                if (fabs(product_log - target_log) < EPS) {
                    ans.push_back({n, k});
                    if (k != n - k) ans.push_back({n, n - k});
                    break;
                }
            }
        }
        // 排序去重
        sort(ans.begin(), ans.end());
        ans.erase(unique(ans.begin(), ans.end()), ans.end());
        // 输出
        cout << ans.size() << "\n";
        if (!ans.empty()) {
            for (size_t i = 0; i < ans.size(); i++) {
                cout << "(" << ans[i].first << "," << ans[i].second << ")";
                if (i + 1 < ans.size()) cout << " ";
            }
            cout << "\n";
        } else cout << "\n";
    }
    return 0;
}
```

## 总结

本题通过数学变换将组合数方程转化为对数等式，利用浮点数运算的高效性和准确性，在极小的搜索范围内找到所有解。算法避免了传统方法中的大整数溢出问题，同时保证了时间效率，是一个典型的数学优化与计算机科学结合的例题。

关键点在于认识到对于较大的 $k$ ， $n$ 的估计值非常准确，以及通过对数运算避免数值溢出。这种思路在解决其他涉及大组合数或阶乘的问题时也值得借鉴。
