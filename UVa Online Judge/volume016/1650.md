## 题目描述

排列的签名是一个字符串，计算方式如下：对于排列中每对连续元素，如果第二个元素大于第一个，则写下字母 `'I'`（递增），否则写下字母 `'D'`（递减）。例如，排列 $\{3,1,2,7,4,6,5\}$ 的签名是 `"DIDID"`。

你的任务是：给定一个描述多个可能排列的签名的字符串，找出有多少个排列满足该签名。

**注意：** 对任意正整数 $n$，一个 $n$ 个元素的排列是一个长度为 $n$ 的序列，包含从 $1$ 到 $n$ 的每个整数恰好一次。

### 输入格式

每个测试用例是一个长度为 $1$ 到 $1000$ 的字符串，只包含字母 `'I'`、`'D'` 或 `'?'`，表示一个排列签名。

每个测试用例单独占一行，没有前导或尾随空格。处理到文件结束。字符串中的 `'?'` 可以是 `'I'` 或 `'D'`。

### 输出格式

对每个测试用例，输出一行，表示满足签名的排列数量。如果结果太大，输出对 $1000000007$ 取模后的余数。

## 题目分析

这是一个典型的动态规划计数问题。我们需要计算满足给定签名约束的排列数量，其中签名可能包含不确定的字符 `'?'`。

### 关键观察

1. 对于长度为 $n$ 的签名字符串，对应的排列长度为 $n+1$
2. 签名中的每个字符约束了相邻两个数字的大小关系：
   - `'I'` 表示后一个数字大于前一个数字
   - `'D'` 表示后一个数字小于前一个数字
   - `'?'` 表示两种可能性都可以

### 动态规划思路

我们定义 $dp[i][j]$ 表示考虑前 $i$ 个数字（即排列长度为 $i$），且最后一个数字是 $j$ 的满足条件的排列数量。

**状态转移分析：**

- 当第 $i$ 个字符是 `'I'` 时，要求第 $i+1$ 个数字大于第 $i$ 个数字：
  $$dp[i+1][j] = \sum_{k=1}^{j-1} dp[i][k]$$

- 当第 $i$ 个字符是 `'D'` 时，要求第 $i+1$ 个数字小于第 $i$ 个数字：
  $$dp[i+1][j] = \sum_{k=j}^{i} dp[i][k]$$

- 当第 $i$ 个字符是 `'?'` 时，两种情况都要考虑

**优化技巧：**

直接计算上述和式的时间复杂度是 $O(n^3)$，对于 $n \leq 1000$ 来说太高。我们可以使用前缀和优化：

1. 维护前缀和数组，使得 $sum[i][j] = \sum_{k=1}^j dp[i][k]$
2. 这样区间和可以在 $O(1)$ 时间内计算：
   - `'I'` 情况：$dp[i+1][j] = sum[i][j-1]$
   - `'D'` 情况：$dp[i+1][j] = sum[i][i] - sum[i][j-1]$

### 算法复杂度

- **时间复杂度：** $O(n^2)$，其中 $n$ 是签名长度
- **空间复杂度：** $O(n^2)$，可优化到 $O(n)$

## 代码实现

```cpp
// Number String

#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;

int countPermutations(string s) {
    int n = s.length();
    vector<vector<int>> dp(n + 1, vector<int>(n + 2, 0));
    dp[0][1] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i + 1; j++) {
            if (s[i - 1] == 'I' || s[i - 1] == '?') {
                dp[i][j] = (dp[i][j] + dp[i - 1][j - 1]) % MOD;
            }
            if (s[i - 1] == 'D' || s[i - 1] == '?') {
                dp[i][j] = (dp[i][j] + (dp[i - 1][i] - dp[i - 1][j - 1] + MOD) % MOD) % MOD;
            }
        }
        for (int j = 1; j <= i + 1; j++)
            dp[i][j] = (dp[i][j] + dp[i][j - 1]) % MOD;
    }
    return dp[n][n + 1];
}

int main() {
    string s;
    while (cin >> s)
        cout << countPermutations(s) << endl;
    return 0;
}
```

## 代码解释

1. **初始化：** $dp[0][1] = 1$ 表示长度为 $1$ 的排列只有 $1$ 种（数字 $1$）
2. **主循环：** 遍历每个签名字符
   - 对于 `'I'` 或 `'?'`，累加前 $j-1$ 个数字的排列数
   - 对于 `'D'` 或 `'?'`，累加从 $j$ 到 $i$ 的数字的排列数
3. **前缀和计算：** 每轮结束后计算前缀和，为下一轮做准备
4. **结果：** $dp[n][n+1]$ 即为所有满足条件的排列数

该算法巧妙地利用了动态规划和前缀和优化，高效地解决了这个排列计数问题。
