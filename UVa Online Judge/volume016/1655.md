## 题目描述

$\texttt{Rikka}$ 是一名患有严重中二病的高中女生，不幸的是她的数学成绩很差。在数学考试中屡次得分很低之后，她面临着如果成绩持续低迷，她的社团将被解散的局面。

在接下来的考试中，她遇到了如下一个难题：

记 $f(x)$ 为满足 $(a \cdot b) \mid x$（即 $x \bmod (a \cdot b) = 0$）的有序正整数对 $(a, b)$ 的数量。给定一个正整数 $n$，Rikka 需要计算：

$$
f(1) + f(2) + \cdots + f(n)
$$

## 输入格式

有多组测试用例。对于每个测试用例，输入只有一行，包含一个整数 $n$（$1 \le n \le 10^{11}$）。输入以 $\texttt{EOF}$ 结束。

## 输出格式

对于每个测试用例，输出一行 `Case X: Y`，其中 $X$ 是测试用例编号（从 $1$ 开始），$Y$ 是所求答案。

## 样例

输入

```
1
3
6
10
15
21
28
```

输出

```
Case 1: 1
Case 2: 7
Case 3: 25
Case 4: 53
Case 5: 95
Case 6: 161
Case 7: 246
```

## 题目分析

首先分析 $f(x)$ 的含义。$f(x)$ 统计满足 $(a \cdot b) \mid x$ 的有序正整数对 $(a, b)$ 的数量。令 $c = a \cdot b$，则 $c$ 是 $x$ 的一个正因子。对于每个因子 $c$，将其分解为两个正整数乘积 $a \cdot b = c$ 的有序对数量正好是 $c$ 的因子个数 $\tau(c)$。

因此有：

$$
f(x) = \sum_{c \mid x} \tau(c)
$$

于是所求的 $S(n)$ 为：

$$
S(n) = \sum_{x=1}^{n} f(x) = \sum_{x=1}^{n} \sum_{c \mid x} \tau(c)
$$

交换求和顺序：

$$
S(n) = \sum_{c=1}^{n} \tau(c) \cdot \left\lfloor \frac{n}{c} \right\rfloor
$$

另一方面，由于 $\tau(c) = \sum_{d \mid c} 1$，代入上式：

$$
S(n) = \sum_{c=1}^{n} \left\lfloor \frac{n}{c} \right\rfloor \sum_{d \mid c} 1
= \sum_{d=1}^{n} \sum_{k=1}^{\lfloor n/d \rfloor} \left\lfloor \frac{n}{d \cdot k} \right\rfloor
$$

令 $a = d$，$b = k$，$c = \left\lfloor \frac{n}{d \cdot k} \right\rfloor$，则 $a \cdot b \cdot c \le n$。于是 $S(n)$ 有了一个简洁的组合意义：

$$
S(n) = \#\{(a, b, c) \in \mathbb{Z}^+ : a \cdot b \cdot c \le n\}
$$

即 $S(n)$ 等于所有满足乘积不超过 $n$ 的有序正整数三元组 $(a, b, c)$ 的个数。

这个转化是本题的关键：将复杂的数论函数求和问题，转化为一个纯粹的组合计数问题。

## 解题思路

### 直接计数的困难

如果直接枚举三个变量 $a, b, c$，需要三重循环，复杂度为 $O(n^3)$，完全不可行。即使利用整除分块优化，对于 $n = 10^{11}$ 也无法在时限内完成。

### 利用对称性优化

注意到三元组 $(a, b, c)$ 的三个位置是对称的。我们可以**只枚举排序后的三元组**，然后根据相等情况乘以对应的排列数。

设 $x \le y \le z$ 且 $x \cdot y \cdot z \le n$，则 $(x, y, z)$ 的不同排列构成不同的有序三元组。根据 $x, y, z$ 的相等关系，排列数分为四种情况：

| 情况 | 条件 | 排列数 |
|------|------|--------|
| $1$ | $x = y = z$ | $1$ |
| $2$ | $x = y < z$ | $3$ |
| $3$ | $x < y = z$ | $3$ |
| $4$| $x < y < z$ | $6$ |

于是 $S(n)$ 可以分解为这四种情况的贡献之和。

### 枚举范围的确定

由于 $x \le y \le z$ 且 $x \cdot y \cdot z \le n$，$x$ 的最大值为 $\lfloor \sqrt[3]{n} \rfloor$，因为 $x^3 \le n$。记这个上限为 $\textit{limit}$。

对于固定的 $x = i$：
- 情况 `1`（$x = y = z$）：贡献为 $1$，$i$ 从 $1$ 到 $\textit{limit}$，共 $\textit{limit}$ 种。
- 情况 `2`（$x = y < z$）：$z$ 的取值范围为 $i+1$ 到 $\lfloor n / i^2 \rfloor$，数量为 $\lfloor n / i^2 \rfloor - i$，每种贡献为 $3$。
- 情况 `3` 和 `4`（$x < y \le z$）：枚举 $y = j$，其中 $j > i$ 且 $i \cdot j^2 \le n$。
  - 当 $y < z$ 时，$z$ 的取值范围为 $j+1$ 到 $\lfloor n / (i \cdot j) \rfloor$，数量为 $\lfloor n / (i \cdot j) \rfloor - j$，每种贡献为 $6$。
  - 当 $y = z$ 时，$z = j$，贡献为 $3$。

### 算法步骤

1. 读入 $n$。
2. 计算 $\textit{limit} = \lfloor \sqrt[3]{n} \rfloor$。由于浮点数精度问题，使用 `pow` 计算后需要微调。
3. 初始化答案 $\textit{ans} = \textit{limit}$（情况 `1` 的贡献）。
4. 对于 $i$ 从 $1$ 到 $\textit{limit}$：
   - 计算情况 `2` 的贡献：$\textit{tmp} = \lfloor n / i^2 \rfloor - i$，若 $\textit{tmp} > 0$，则 $\textit{ans} \mathrel{+}= 3 \cdot \textit{tmp}$。
   - 对于 $j$ 从 $i+1$ 开始，满足 $i \cdot j^2 \le n$：
     - 情况 `4` 的贡献：$\textit{tmp} = \lfloor n / (i \cdot j) \rfloor - j$，若 $\textit{tmp} > 0$，则 $\textit{ans} \mathrel{+}= 6 \cdot \textit{tmp}$。
     - 情况 `3` 的贡献：$\textit{ans} \mathrel{+}= 3$。
5. 输出 $\textit{ans}$。

### 复杂度分析

外层循环次数为 $\textit{limit} = \lfloor \sqrt[3]{n} \rfloor \approx 4641$（当 $n = 10^{11}$ 时）。内层循环中，对于每个 $i$，$j$ 的上界为 $\lfloor \sqrt{n/i} \rfloor$。总迭代次数约为：

$$
\sum_{i=1}^{\lfloor \sqrt[3]{n} \rfloor} \sqrt{\frac{n}{i}} \approx O(n^{2/3})
$$

当 $n = 10^{11}$ 时，$n^{2/3} \approx 2.15 \times 10^7$，在 $3$ 秒内完全可以接受。

空间复杂度为 $O(1)$。

## 代码实现

```cpp
// Exam

// Verdict: Accepted
// Submission Date: 2026-06-17
// UVa Run Time: 1.120s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

ll n, limit;

ll work() {
    ll tmp, res = 0;
    res = limit;
    for (ll i = 1; i <= limit; ++i) {
        tmp = n / (i * i) - i;
        if (tmp > 0) res += 3 * tmp;
        for (ll j = i + 1; i * j * j <= n; ++j) {
            tmp = n / (i * j) - j;
            if (tmp > 0) res += 6 * tmp;
            res += 3;
        }
    }
    return res;
}

int main() {
    int caseNo = 0;
    while (scanf("%lld", &n) != EOF) {
        limit = pow((long double)n, 1.0L / 3.0L);
        while ((limit + 1) * (limit + 1) * (limit + 1) <= n) ++limit;
        while (limit * limit * limit > n) --limit;
        printf("Case %d: %lld\n", ++caseNo, work());
    }
    return 0;
}
```

## 总结

本题的核心技巧是将数论函数求和问题转化为组合计数问题：

1. **关键转化**：$f(x)$ 的定义等价于统计满足 $a \cdot b \mid x$ 的有序对，进一步转化为统计 $a \cdot b \cdot c \le n$ 的有序三元组个数。

2. **去重计数**：通过枚举排序后的三元组 $(x \le y \le z)$，根据相等情况乘以对应的排列数（$1, 3, 3, 6$），避免了 $6$ 倍的重复枚举。

3. **枚举范围的优化**：$x$ 只需枚举到 $\lfloor \sqrt[3]{n} \rfloor$，$y$ 只需枚举到 $\lfloor \sqrt{n/x} \rfloor$，总复杂度为 $O(n^{2/3})$。

4. **精度处理**：使用 `pow` 计算立方根后，通过 while 循环微调，避免了浮点数精度问题。

本题的启示是：当遇到复杂的数论求和时，可以尝试寻找其组合意义，往往能获得更简洁高效的解法。
