## 题目描述

荷兰历史上最著名的海军上将米歇尔·阿德里安松·德·鲁伊特在 $17$ 世纪英荷战争中以其卓越的海战战术闻名。他发明了"德·鲁伊特机动"战术：两艘战舰从同一个起点出发，沿着不同的路线航行，最终在同一个目的地汇合。

在这个问题中，海上航点用顶点表示，可能的航道用有向边表示。对于任意两个航点 $W_1$ 和 $W_2$，最多只有一条从 $W_1$ 到$W_2$的航道。每条有向边标记了安全通过该航道需要发射的炮弹数量。

德·鲁伊特机动要求两艘战舰必须沿着**点不交且边不交**的路径航行（除了起点和终点可以相同）。作为节俭的荷兰人，德·鲁伊特希望最小化两艘战舰发射的炮弹总数。

**输入格式：**
- 第一行包含两个整数 $v$ ($3 \leq v \leq 1000$) 和 $e$ ($3 \leq e \leq 10000$)，分别表示航点数量和航道数量
- 接下来 $e$ 行，每行包含三个整数：$a_i$, $b_i$, $c_i$，表示从航点 $a_i$ 到 $b_i$ 的有向航道，需要发射 $c_i$ 个炮弹

起点是航点 $1$，终点是航点 $v$。保证至少存在两条点边不交的路径从 $1$ 到 $v$。

**输出格式：**
- 一个正整数，表示两艘战舰到达目的地时发射的最小炮弹总数

## 题目分析

### 问题本质

这是一个典型的**最小费用点边不交双路径问题**。我们需要找到从起点到终点的两条路径，满足：
1. 除了起点和终点外，两条路径不共享任何顶点
2. 两条路径不共享任何边
3. 两条路径的边权之和最小

### 图论建模

这类问题可以通过**网络流**技术解决，具体来说是**最小费用最大流**算法。核心思想是将原问题转化为在特定构造的流网络中寻找流量为 $2$ 的最小费用流。

### 关键思路：顶点容量限制

为了确保除了起点和终点外的顶点不被两艘船同时经过，我们采用**顶点拆分**技术：
- 将每个顶点 $i$ 拆分成两个顶点：入点 $i_{in}$ 和出点 $i_{out}$
- 在 $i_{in}$ 和 $i_{out}$ 之间添加一条容量为 $1$、费用为 $0$ 的边
- 这样确保每个中间顶点最多被一艘船经过

对于起点和终点，由于两艘船都可以经过，它们内部的拆点边容量设为 $2$。

### 网络流构造

1. **顶点编号方案**：
   - 原顶点 $i$ 的入点编号为 $i$，出点编号为 $i + v$
   - 超级源点 $S = 0$，超级汇点 $T = 2v + 1$

2. **边构造**：
   - 内部拆点边：$i \to i + v$，容量为 $1$（起点终点为 $2$），费用为 $0$
   - 原图边 $a \to b$：转化为 $a + v \to b$，容量为 $1$，费用为 $c$
   - 源点到起点：$S \to 1$，容量为 $2$，费用为 $0$
   - 终点到汇点：$v + v \to T$，容量为 $2$，费用为 $0$

### 算法选择

使用 $\texttt{SPFA（Shortest Path Faster Algorithm}）$实现的最小费用流算法，因为：
- 图中可能存在负权边（反向边费用为负）
- 顶点和边数量在可接受范围内（$v \leq 1000$, $e \leq 10000$）
- 所需流量较小（仅为 $2$）

### 复杂度分析

- 空间复杂度：$O(v + e)$
- 时间复杂度：$O(F \cdot v \cdot e)$，其中 $F = 2$，实际运行效率较高

## 解题思路详解

### 步骤1：理解顶点拆分

顶点拆分的目的是将"顶点容量"限制转化为"边容量"限制。对于普通顶点，我们设置容量为 $1$ 的边，确保只有一艘船能经过；对于起点和终点，设置容量为 $2$ 的边，允许两艘船经过。

### 步骤2：流网络构建

构建的流网络具有以下性质：
- 每条原图的边对应流网络中的一条容量为 $1$ 的边
- 每个原图的顶点对应流网络中的一条容量受限的边
- 从源点到汇点的流量为 $2$ 对应找到两条路径

### 步骤3：最小费用流算法

使用基于 $\texttt{SPFA}$ 的最小费用流算法：
1. 每次寻找从源点到汇点的最短路（按费用）
2. 沿最短路增广单位流量
3. 更新残余网络
4. 重复直到流量达到 $2$ 或无法增广

### 步骤4：正确性保证

由于我们使用了顶点拆分技术，保证了：
- 点不交：中间顶点的内部边容量为 $1$
- 边不交：原图边的容量为 $1$
- 起点终点共享：相应的内部边容量为 $2$

```cpp
// Admiral

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <climits>
using namespace std;

// 流边结构体
struct Edge {
    int to;        // 目标顶点
    int capacity;  // 容量
    int cost;      // 费用
    int rev;       // 反向边索引
};

class MinCostMaxFlow {
private:
    int n;  // 顶点数量
    vector<vector<Edge>> graph;  // 邻接表表示的流网络
    vector<int> dist;    // 最短距离数组
    vector<int> prevv;   // 前驱顶点
    vector<int> preve;   // 前驱边索引
    const int INF = INT_MAX / 2;  // 无穷大值

public:
    // 构造函数，初始化流网络
    MinCostMaxFlow(int n) : n(n), graph(n), dist(n), prevv(n), preve(n) {}

    // 添加边：从from到to，容量为capacity，费用为cost
    void add_edge(int from, int to, int capacity, int cost) {
        graph[from].push_back({to, capacity, cost, (int)graph[to].size()});
        // 添加反向边，初始容量为0，费用为-cost
        graph[to].push_back({from, 0, -cost, (int)graph[from].size() - 1});
    }

    // 最小费用流算法：从s到t，需要required_flow的流量
    int min_cost_flow(int s, int t, int required_flow) {
        int total_flow = 0;   // 总流量
        int total_cost = 0;   // 总费用
        
        while (required_flow > 0) {
            // 初始化距离数组
            fill(dist.begin(), dist.end(), INF);
            dist[s] = 0;
            bool updated = true;
            
            // SPFA算法寻找最短路
            while (updated) {
                updated = false;
                for (int v = 0; v < n; ++v) {
                    if (dist[v] == INF) continue;
                    for (int i = 0; i < graph[v].size(); ++i) {
                        Edge& e = graph[v][i];
                        // 如果边有剩余容量且可以松弛
                        if (e.capacity > 0 && dist[e.to] > dist[v] + e.cost) {
                            dist[e.to] = dist[v] + e.cost;
                            prevv[e.to] = v;    // 记录前驱顶点
                            preve[e.to] = i;    // 记录前驱边索引
                            updated = true;
                        }
                    }
                }
            }
            
            // 如果无法到达汇点，返回-1
            if (dist[t] == INF) {
                return -1;
            }
            
            // 计算增广路径上的最小容量
            int flow = required_flow;
            for (int v = t; v != s; v = prevv[v]) {
                flow = min(flow, graph[prevv[v]][preve[v]].capacity);
            }
            
            // 更新流量需求
            required_flow -= flow;
            total_flow += flow;
            
            // 更新残余网络
            for (int v = t; v != s; v = prevv[v]) {
                Edge& e = graph[prevv[v]][preve[v]];
                total_cost += e.cost * flow;  // 累加费用
                e.capacity -= flow;           // 减少正向边容量
                graph[e.to][e.rev].capacity += flow;  // 增加反向边容量
            }
        }
        
        return total_cost;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int v, e;
    while (cin >> v >> e) {
        // 设置超级源点和超级汇点
        // 顶点编号方案：
        // - 原顶点i的入点编号为i，出点编号为i+v
        // - 超级源点S=0，超级汇点T=2*v+1
        int S = 0, T = 2 * v + 1;
        MinCostMaxFlow mcmf(2 * v + 2);

        // 添加内部拆点边：i->i+v
        // 对于起点和终点，容量为2（允许两艘船经过）
        // 对于其他顶点，容量为1（确保点不交）
        for (int i = 1; i <= v; i++) {
            int cap = (i == 1 || i == v) ? 2 : 1;
            mcmf.add_edge(i, i + v, cap, 0);
        }

        // 添加原图的边：a->b 转化为 a_out->b_in
        // 容量为1确保边不交，费用为炮弹数量
        for (int i = 0; i < e; i++) {
            int a, b, c;
            cin >> a >> b >> c;
            mcmf.add_edge(a + v, b, 1, c);
        }

        // 连接超级源点到起点入点
        mcmf.add_edge(S, 1, 2, 0);
        // 连接终点出点到超级汇点
        mcmf.add_edge(v + v, T, 2, 0);

        // 计算最小费用流，需要2的流量
        int ans = mcmf.min_cost_flow(S, T, 2);
        cout << ans << "\n";
    }

    return 0;
}
```

## 总结

本题展示了如何将复杂的路径约束问题转化为网络流问题：
- **顶点拆分**处理点不交约束
- **边容量**处理边不交约束
- **最小费用流**寻找最优解

这种建模技巧在图论和组合优化中非常实用，可以解决许多类似的资源分配和路径规划问题。
