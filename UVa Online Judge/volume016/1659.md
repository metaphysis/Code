## 题目描述

$\texttt{Laura Luo}$ 发明了一个绘画游戏。给定一幅有 $n$ 个点的铅笔素描，你需要通过画环的方式为其上色。每次画一个新环时，从某个点开始，沿着一些线段画，最后回到起点。每个点可以被访问多次，但每条线段最多只能被画一次。为了让图画看起来有趣，不同的线段必须用不同颜色画。对于每条线段，$\texttt{Laura}$ 已经决定了画它的方向。

画完后，分数按如下方式计算：你画的每单位长度获得 $x$ 分，每使用一种颜色扣除 $y$ 分（$\texttt{Laura}$ 准备了足够多不同颜色的水彩笔）。

请编写程序计算你能得到的最高分。

**输入格式**
- 每个测试用例的第一行包含三个正整数 $n, x, y$（$1 \leq n \leq 100, 1 \leq x, y \leq 1000$）
- 接下来 $n$ 行每行描述一个点（点按输入顺序编号为 $1$ 到 $n$）
- 每行的前两个整数 $(x_i, y_i)$ 指定其坐标（$0 \leq x_i, y_i \leq 1000$）
- 其余整数是它连接到的点，以 $0$ 结尾
- 如果点 $v$ 出现在点 $u$ 的列表中，则存在一条从 $u$ 到 $v$ 的线段，且 $\texttt{Laura}$ 会按照从 $u$ 到 $v$ 的方向画这条线段
- 没有重复的点，且线段数不超过 $500$
- 最后一个测试用例后是一个单独的 $0$，表示输入结束

**输出格式**
对于每个测试用例，输出用例编号和你能得到的最高分，保留两位小数。

## 题目分析

### 问题本质

这是一个**最大费用循环流**（$\texttt{Maximum Cost Circulation}$）问题。我们需要在有向图中选择一组环，使得总收益最大化，同时满足：
1. 每条有向边最多被使用一次
2. 每个点可以属于多个环
3. 每条边的收益 = 长度 × $x$ - $y$

### 数学模型

设图 $G = (V, E)$，其中 $V$ 是点集，$E$ 是有向边集。对于每条边 $e = (u, v) \in E$：
- 长度：$length(e)$
- 收益：$profit(e) = length(e) \times x - y$

我们需要找到一组边不相交的环 $C_1, C_2, \ldots, C_k$，使得总收益 $\sum_{i=1}^k \sum_{e \in C_i} profit(e)$ 最大化。

### 关键观察

1. **环的性质**：在一个环中，每个点的入度等于出度（流量守恒）
2. **边的选择**：如果一条边的收益为正（$profit(e) > 0$），我们倾向于选择它；如果收益为负，我们倾向于不选择它
3. **容量限制**：每条边最多使用一次，这对应容量为 $1$

## 解题思路

### 转化为最小费用最大流问题

我们可以将最大费用循环流问题转化为最小费用最大流问题：

1. **费用设置**：
   - 对于收益为正的边：我们希望强制选择它，可以将其收益预先计入总收益，然后在流网络中将其费用设为正数（选择时需要支付）
   - 对于收益非正的边：我们不希望选择它，将其费用设为正数（选择时需要支付）

2. **流量平衡**：
   - 计算每个点的出度与入度之差 $balance[v] = outdegree(v) - indegree(v)$
   - 如果 $balance[v] > 0$，说明点 $v$ 需要额外的流出流量，从源点 $S$ 向 $v$ 连边
   - 如果 $balance[v] < 0$，说明点 $v$ 需要额外的流入流量，从 $v$ 向汇点 $T$ 连边

### 具体建图策略

对于每条有向边 $(u, v)$：

1. **计算收益**：$profit = length(u,v) \times x - y$
2. **分类处理**：
   - 如果 $profit > 0$（正收益边）：
     - 预先将 $profit$ 加入总收益
     - 反向建边：添加边 $(v, u)$，容量为 $1$，费用为 $profit$
     - 更新度平衡：$balance[u]\texttt{--}$, $balance[v]\texttt{++}$
   - 如果 $profit \leq 0$（非正收益边）：
     - 正向建边：添加边 $(u, v)$，容量为 $1$，费用为 $-profit$
3. **平衡流量**：
   - 对于每个点 $i$：
     - 如果 $balance[i] > 0$：添加边 $(S, i)$，容量为 $balance[i]$，费用为 $0$
     - 如果 $balance[i] < 0$：添加边 $(i, T)$，容量为 $-balance[i]$，费用为 $0$

### 算法流程

1. 读取输入，计算所有边的长度和收益
2. 初始化网络流图
3. 按照上述策略建图
4. 运行最小费用最大流算法（使用 $\texttt{SPFA}$ 或 $\texttt{Dijkstra}$ 带势能）
5. 计算最终收益：$result =$总预计算收益 $-$ 最小费用
6. 如果结果为负，输出 $0.00$；否则输出结果

### 复杂度分析

- 点数：$n \leq 100$
- 边数：$m \leq 500$
- 网络流中的点：$n+2$
- 网络流中的边：$O(m)$
- 最小费用最大流复杂度：$O(F \cdot VE)$，其中 $F$ 是最大流值
- 实际运行时间：在题目限制下完全可以接受

## 正确性证明

### 1. 流量守恒保证形成环

在最小费用最大流中，除了源点和汇点，所有中间节点的流入量等于流出量。这意味着：
- 每个点 $v$ 的入度等于出度
- 这正好对应了环的要求：每个点在环中必须满足流量守恒

### 2. 费用设置保证最大收益

- 对于正收益边：我们预先将其收益加入总收益，然后在流网络中选择它需要支付正费用。最小费用流会尽量减少支付，这意味着它会尽量选择这些边（因为不选的话，相当于"支付"了收益）
- 对于非正收益边：选择它需要支付正费用，最小费用流会尽量避免选择它们

### 3. 容量限制保证边不相交

每条边的容量为 $1$，确保每条边最多被使用一次。通过反向边的机制，算法可以调整环的选择，达到全局最优。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 110, MAXE = 2000, INF = 1e9;
const double EPS = 1e-8;
struct Edge { int to, next, cap; double cost; } edge[MAXE * 2];
int head[MAXN], cnt = 0, source, sink;
double result;
void reset(int s, int t) {
    cnt = 0; memset(head, -1, sizeof head); result = 0.0; source = s; sink = t;
}
void addArc(int from, int to, int capacity, double cost) {
    edge[cnt] = {to, head[from], capacity, cost}; head[from] = cnt++;
    edge[cnt] = {from, head[to], 0, -cost}; head[to] = cnt++;
}
bool spfa() {
    vector<double> dist(MAXN, 2.0 * INF); vector<int> flow(MAXN, 0), parent(MAXN, -1);
    vector<bool> in(MAXN, false); queue<int> q;
    dist[source] = 0.0; flow[source] = INF; q.push(source); in[source] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop(); in[u] = false;
        for (int e = head[u]; ~e; e = edge[e].next) {
            int v = edge[e].to;
            if (edge[e].cap > 0 && dist[v] > dist[u] + edge[e].cost + EPS) {
                dist[v] = dist[u] + edge[e].cost; flow[v] = min(flow[u], edge[e].cap);
                parent[v] = e;
                if (!in[v]) { q.push(v); in[v] = true; }
            }
        }
    }
    if (dist[sink] > INF || parent[sink] == -1) return false;
    int f = flow[sink]; result += f * dist[sink];
    for (int node = sink; node != source; node = edge[parent[node] ^ 1].to) {
        int e = parent[node]; edge[e].cap -= f; edge[e ^ 1].cap += f;
    }
    return true;
}
double getD(int x1, int y1, int x2, int y2) {
    double dx = x1 - x2, dy = y1 - y2; return sqrt(dx * dx + dy * dy);
}
int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, X, Y, testCase = 0;
    while (scanf("%d", &n) == 1 && n) {
        scanf("%d %d", &X, &Y);
        vector<int> px(n + 1), py(n + 1); vector<vector<int>> g(n + 1);
        for (int i = 1; i <= n; i++) {
            scanf("%d %d", &px[i], &py[i]);
            int v; while (scanf("%d", &v) && v != 0) g[i].push_back(v);
        }
        reset(n + 1, n + 2); vector<int> db(n + 1, 0);
        for (int i = 1; i <= n; i++) for (int j : g[i]) {
            double distance = getD(px[i], py[i], px[j], py[j]);
            double profit = distance * X - Y;
            if (profit > 0) {
                addArc(j, i, 1, profit); result -= profit; db[i]--; db[j]++;
            } else addArc(i, j, 1, -profit);
        }
        for (int i = 1; i <= n; i++) {
            if (db[i] > 0) addArc(source, i, db[i], 0.0);
            else if (db[i] < 0) addArc(i, sink, -db[i], 0.0);
        }
        while (spfa()) {}
        result = -result; if (fabs(result) < EPS) result = 0.0;
        printf("Case %d: %.2f\n", ++testCase, result);
    }
    return 0;
}
```

## 总结

本题是一道经典的最大费用循环流问题，通过巧妙的图转化，将其转化为最小费用最大流问题。关键点在于：
1. 正收益边的反向建图策略
2. 通过度平衡连接源点和汇点
3. 使用 $\texttt{SPFA}$ 算法求解最小费用最大流

这种将组合优化问题转化为网络流问题的方法在图论中非常常见，是解决一类边不相交环选择问题的有效技巧。
