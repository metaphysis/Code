## 题目分析

本题描述了一个 $n \times m$ 的网格岛屿，每个格子有一个高度值。海平面每年上升 $1$ 米，在第 $i$ 年时海平面为 $i$ 米。高度不超过当前海平面的格子会被淹没，相邻的未被淹没的格子（上下左右方向）组成未被淹没的区域。我们需要对每个查询年份 $t_j$，输出该年份未被淹没的区域数量。

### 关键观察

1. **海平面单调递增**：查询的 $t_j$ 是单调不降的
2. **淹没过程不可逆**：一旦某个格子被淹没，它就不会再变回未被淹没状态
3. **连通区域动态变化**：随着海平面上升，未被淹没的区域会分裂或合并

## 解题思路

### 核心思想：逆序处理

正序处理（从低海平面到高海平面）比较困难，因为：
- 格子被淹没后，连通区域会分裂，难以维护
- 分裂操作比合并操作复杂得多

因此我们采用**逆序处理**的思路：
- 从**高海平面到低海平面**处理查询
- 相当于水位**下降**，格子从"淹没"状态变为"未被淹没"状态
- 这样我们就是在**添加**格子，更容易用并查集维护连通性

### 算法步骤

1. **数据预处理**：
   - 将所有格子按高度**降序**排序
   - 将查询按海平面**降序**排序，但保留原始顺序用于输出

2. **并查集维护连通性**：
   - 初始时所有格子都处于"淹没"状态，区域数为 $0$
   - 按高度从高到低依次"添加"格子（变为未被淹没）
   - 每添加一个格子，区域数加 $1$
   - 检查新格子与四周已添加格子的连通性，合并连通区域，每合并一次区域数减 $1$

3. **结果输出**：
   - 按照原始查询顺序输出结果

### 复杂度分析

- **时间复杂度**：$O(nm \alpha(nm) + T \log T)$，其中 $\alpha$ 是反阿克曼函数
- **空间复杂度**：$O(nm + T)$

## 代码实现

```cpp
// Islands
// UVa ID: 1665
// Verdict: Accepted
// Submission Date: 2025-11-22
// UVa Run Time: 0.680s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int dx[] = {0, 0, 1, -1};
const int dy[] = {1, -1, 0, 0};

struct Cell {
    int height, x, y;
    bool operator<(const Cell& other) const {
        return height > other.height;
    }
};

vector<int> parent;

int findSet(int x) {
    return parent[x] == x ? x : parent[x] = findSet(parent[x]);
}

bool unionSet(int a, int b) {
    int ra = findSet(a), rb = findSet(b);
    if (ra != rb) {
        parent[ra] = rb;
        return true;
    }
    return false;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int Z;
    cin >> Z;
    while (Z--) {
        int n, m;
        cin >> n >> m;
        vector<vector<int>> height(n, vector<int>(m));
        vector<Cell> cells;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++) {
                cin >> height[i][j];
                cells.push_back({height[i][j], i, j});
            }
        sort(cells.begin(), cells.end());

        int T;
        cin >> T;
        vector<int> queries(T);
        for (int i = 0; i < T; i++) cin >> queries[i];

        vector<int> idx(T);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(), [&](int a, int b) {
            return queries[a] > queries[b];
        });

        parent.resize(n * m);
        iota(parent.begin(), parent.end(), 0);
        vector<bool> added(n * m, false);

        vector<int> result(T);
        int cur = 0, regions = 0;
        for (int i : idx) {
            int seaLevel = queries[i];
            while (cur < cells.size() && cells[cur].height > seaLevel) {
                int x = cells[cur].x, y = cells[cur].y;
                int id = x * m + y;
                added[id] = true;
                regions++;
                for (int d = 0; d < 4; d++) {
                    int nx = x + dx[d], ny = y + dy[d];
                    if (nx >= 0 && nx < n && ny >= 0 && ny < m && added[nx * m + ny])
                        if (unionSet(id, nx * m + ny)) regions--;
                }
                cur++;
            }
            result[i] = regions;
        }

        // 虽然题目描述中输出约束是间隔输出空格，但是在线测试数据要求每个数值后都输出一个空格
        for (int i = 0; i < T; i++)
            cout << result[i] << ' ';
        cout << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于逆向思维：将海平面上升导致的淹没过程，转化为海平面下降导致的"浮出"过程。这种思路配合并查集数据结构，能够高效地维护连通区域的动态变化。逆向处理在解决这类单调变化的问题中是一个很有用的技巧。
