## 题目描述

雷城有许多房屋，它们通过闪电供电。房屋之间通过电线连接，电线连接方式使得从任意一个房屋到另一个房屋恰好只有一条路径。每个房屋都有一个可以存储无限电能的大型电池。

每天，会有多次闪电击中不同的房屋。这些闪电很不寻常，每次闪电会同时击中两个房屋：一个房屋 $A$ 被红色闪电击中，另一个房屋 $B$ 被蓝色闪电击中。闪电击中后，从 $A$ 到 $B$ 路径上的所有房屋（包括 $A$ 和 $B$）都会获得一定量的电能，这些电能会被加到房屋的电池中。

雷城市长想要一份月底每个房屋存储电能的报告，每个房主需要根据这个报告缴税。为了防止房主报告不准确的电池能量（为了少缴税），你需要根据当月观测到的闪电数据生成正确的报告。月初时，每个房屋的电池能量读数为 $0$。

### 输入格式

第一行输入包含一个整数 $T$ ($T \leq 10$)，表示测试用例的数量。每个测试用例以整数 $N$ ($2 \leq N \leq 50,000$) 开始，表示雷城中的房屋数量。接下来的 $N-1$ 行描述电线连接，每行包含两个整数 $X$ 和 $Y$，表示房屋 $X$ 和房屋 $Y$ 相连。房屋编号从 $0$ 到 $N-1$。接下来一行包含一个数字 $Q$ ($1 \leq Q \leq 50,000$)，表示观测到的闪电次数。接下来的 $Q$ 行描述当月发生的特殊闪电，每行包含三个整数 $A$、$B$、$C$，表示红色闪电击中房屋 $A$，蓝色闪电击中房屋 $B$，传输的能量为 $C$（最多 $100$）。

### 输出格式

对于每个测试用例，输出 `Case #X:`（不带引号），其中 $X$ 是测试用例编号，然后输出 $N$ 行，每行是从房屋 $0$ 到房屋 $N-1$ 的月底电池能量读数。

## 题目分析

这是一个典型的**树上路径更新**问题。我们需要在一棵树（$N$ 个节点，$N-1$ 条边）上处理多次更新操作，每次更新会影响从节点 $A$ 到节点 $B$ 的路径上的所有节点，最后需要查询每个节点的最终值。

### 问题难点

1. **数据规模大**：$N$ 和 $Q$ 最大都能达到 $50,000$，如果使用朴素的暴力方法（每次更新都遍历整条路径），时间复杂度为 $O(N \times Q)$，在极限情况下会达到 $2.5 \times 10^9$ 次操作，显然会超时。

2. **树结构**：房屋之间的连接形成一棵树，这意味着任意两个节点之间有且仅有一条简单路径。

3. **多次更新，单次查询**：我们需要处理多次更新操作，但只需要在最后进行一次查询。

### 解题思路

对于这类树上路径更新问题，一个高效的解决方案是使用**树上差分**技术，结合**最近公共祖先**算法。

#### 树上差分原理

树上差分的基本思想是将路径更新转化为节点更新，最后通过一次 $\texttt{DFS}$ 汇总得到每个节点的最终值。

对于每次闪电 $(A, B, C)$：
- 在节点 $A$ 处增加 $C$
- 在节点 $B$ 处增加 $C$
- 在 $\texttt{LCA}(A,B)$ 处减少 $C$
- 在 $\texttt{LCA}(A,B)$ 的父节点处减少 $C$（如果存在）

这样操作后，当我们从根节点开始进行 $\texttt{DFS}$ 汇总时，路径 $A \to B$ 上的所有节点都会正确地增加 $C$，而其他节点不受影响。

#### 算法步骤

1. **预处理**：
   - 构建树的邻接表表示
   - 使用 $\texttt{DFS}$ 预处理每个节点的深度和父节点信息
   - 使用倍增法预处理 $\texttt{LCA}$ 查询表

2. **处理闪电**：
   - 对于每个闪电 $(A, B, C)$，计算 $A$ 和 $B$ 的 $\texttt{LCA}$
   - 按照树上差分规则更新差分数组

3. **汇总结果**：
   - 从根节点开始进行一次 $\texttt{DFS}$，将差分数组的值累加到所有子节点
   - 最终每个节点的值就是其电池能量

### 时间复杂度分析

- **预处理**：$O(N \log N)$
- **每次 $\texttt{LCA}$ 查询**：$O(\log N)$
- **每次闪电更新**：$O(\log N)$
- **最终汇总**：$O(N)$
- **总复杂度**：$O((N + Q) \log N)$，对于 $N, Q \leq 50,000$ 完全可行

```cpp
// Lightning Energy Report

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 50005;
const int LOG = 16;

vector<int> graph[MAXN];
int depth[MAXN];
int parent[MAXN][LOG];
int diff[MAXN];
int result[MAXN];

void dfs(int u, int p) {
    depth[u] = depth[p] + 1;
    parent[u][0] = p;
    for (int i = 1; i < LOG; i++) 
        if (parent[u][i-1] != -1) 
            parent[u][i] = parent[parent[u][i-1]][i-1];
    
    for (int v : graph[u]) 
        if (v != p) 
            dfs(v, u);
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    
    int diffDepth = depth[u] - depth[v];
    for (int i = 0; i < LOG; i++) 
        if (diffDepth & (1 << i)) 
            u = parent[u][i];
    
    if (u == v) return u;
    
    for (int i = LOG - 1; i >= 0; i--) 
        if (parent[u][i] != parent[v][i]) {
            u = parent[u][i];
            v = parent[v][i];
        }
    
    return parent[u][0];
}

void accumulate(int u, int p) {
    result[u] = diff[u];
    for (int v : graph[u]) 
        if (v != p) {
            accumulate(v, u);
            result[u] += result[v];
        }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int t;
    cin >> t;
    for (int caseNum = 1; caseNum <= t; caseNum++) {
        int n;
        cin >> n;
        
        // 初始化
        for (int i = 0; i < n; i++) {
            graph[i].clear();
            diff[i] = 0;
            result[i] = 0;
            for (int j = 0; j < LOG; j++) 
                parent[i][j] = -1;
        }
        
        // 建树
        for (int i = 0; i < n - 1; i++) {
            int x, y;
            cin >> x >> y;
            graph[x].push_back(y);
            graph[y].push_back(x);
        }
        
        // 预处理LCA
        depth[0] = 0;
        dfs(0, -1);
        
        // 处理闪电
        int q;
        cin >> q;
        while (q--) {
            int a, b, c;
            cin >> a >> b >> c;
            int l = lca(a, b);
            
            diff[a] += c;
            diff[b] += c;
            diff[l] -= c;
            if (parent[l][0] != -1) 
                diff[parent[l][0]] -= c;
        }
        
        // 汇总结果
        accumulate(0, -1);
        
        // 输出结果
        cout << "Case #" << caseNum << ":\n";
        for (int i = 0; i < n; i++) 
            cout << result[i] << "\n";
    }
    
    return 0;
}
```

## 总结

本题展示了如何高效处理树上的路径更新问题。通过使用树上差分技术和 $\texttt{LCA}$ 算法，我们将原本需要 $O(N)$ 时间的路径更新操作优化到 $O(\log N)$ 时间，从而能够处理大规模数据。

这种技术的核心思想是将路径操作转化为节点操作，最后通过一次遍历汇总结果。这种思想在很多树相关问题中都有应用，是算法竞赛中的重要技巧。
