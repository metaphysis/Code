## 题目描述

我们有一块尺寸为 $100 \times 100 \times 100$ 毫米的奶酪块，内部有 $n$ 个球形孔洞。需要垂直于 $z$ 轴将其切成 $s$ 片，使得每片的重量（即奶酪体积）相等。孔洞信息以微米为单位给出，奶酪块占据 $0 \leq x, y, z \leq 100000$ 微米的区域，孔洞不重叠但可能相切，且完全包含在奶酪内。

## 题目分析

### 核心难点

1. **孔洞对体积的影响** ：每个切片中可能包含多个孔洞的一部分，需要精确计算切片内奶酪的实际体积。
2. **单位转换**：输入坐标为微米，而尺寸为毫米，需要统一单位。
3. **高精度要求**：误差不超过 $10^{-6}$，需要使用浮点数二分查找。

### 关键观察

- 奶酪总体积 = 长方体体积 - 所有孔洞体积。
- 每片目标体积 = 总体积 / $s$。
- 由于切片垂直于 $z$ 轴，每个切片是一个 $100 \times 100 \times \Delta z$ 的长方体，减去其中被孔洞占据的部分。
- 孔洞是球体，被平面 $z = a$ 和 $z = b$ 截取的部分可以用定积分精确计算。

## 解题思路

### 步骤 1：单位转换

将所有输入数值除以 $1000$，转换为毫米：

- 半径 $r \to r / 1000$
- 中心坐标 $x, y, z \to x / 1000, y / 1000, z / 1000$
- 奶酪边界 $100000 \to 100$ 毫米

### 步骤 2：计算总体积

```cpp
总体积 = 100 * 100 * 100 - Σ (4/3 * π * r³)
```

### 步骤 3：计算球体被平面截取的体积

对于球心 $(x_0, y_0, z_0)$，半径 $R$，在 $z$ 区间 $[z_1, z_2]$ 内的体积为：

$$V = \int_{\max(z_1, z_0-R)}^{\min(z_2, z_0+R)} \pi \left[ R^2 - (z - z_0)^2 \right] dz$$

积分结果为：

$$F(z) = \pi \left[ R^2 (z - z_0) - \frac{(z - z_0)^3}{3} \right]$$

则：

$$V = F(\min(z_2, z_0+R)) - F(\max(z_1, z_0-R))$$

特殊情况：
- 若区间与球无交集，体积为 $0$。
- 若区间完全包含整个球，体积为 $\frac{4}{3}\pi R^3$。

### 步骤 4：二分查找切片的边界

定义函数 `cheeseVolumeUpToZ(z)` 为从底部 $z=0$ 到 $z$ 的奶酪体积：

```cpp
cheeseVolumeUpToZ(z) = 100 * 100 * z - Σ sphereSliceVolume(hole, 0, z)
```

对于第 $i$ 片（从底部开始编号，$i=0,1,\dots,s-1$），需要找到 $z_{i+1}$ 使得：

$$cheeseVolumeUpToZ(z_{i+1}) = (i+1) \times \text{targetSliceVol}$$

其中 $targetSliceVol =$ 总奶酪体积 $/ s$。

使用二分查找求解 $z_{i+1}$，初始范围 $[z_i, 100]$，进行 $40$ 次迭代以保证精度。

### 步骤 5：输出结果

第 $i$ 片的厚度 = $z_{i+1} - z_i$，每行输出一个厚度值，保留 $9$ 位小数。

## 复杂度分析

- 每个测试用例有 $n$ 个孔洞，$s$ 片。
- 每次二分查找需要 $O(n)$ 计算体积。
- 二分迭代次数固定为 $60$，总复杂度 $O(s \cdot n \cdot 60)$，在 $n \leq 10000, s \leq 100$ 时可接受。

## 注意事项

1. **精度处理**：使用 `double` 类型，误差控制在 $10^{-9}$。
2. **边界条件**：当孔洞刚好在切面上时，使用 `EPS` 处理避免重复计算或遗漏。
3. **输入格式**：多测试用例直到 `EOF`。
4. **输出格式**：每个切片厚度一行，不同测试用例之间不输出空行。

## 代码实现

```cpp
// Cutting Cheese
// UVa ID: 1712

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);
const double EPS = 1e-9;
const double L = 0.0;
const double R = 100.0;

struct Hole {
    double r, z0, zLow;   // z0 是球心 z 坐标, zLow = z0 - r
    double r2;            // 半径平方，用于快速计算
};

inline double sphereSliceVolume(const Hole& h, double z1, double z2) {
    double R = h.r, z0 = h.z0;
    if (z2 <= z0 - R + EPS || z1 >= z0 + R - EPS) return 0.0;
    double low = max(z1, z0 - R);
    double high = min(z2, z0 + R);
    if (high - low < EPS) return 0.0;
    if (low <= z0 - R + EPS && high >= z0 + R - EPS)
        return 4.0/3.0 * PI * R * R * R;
    auto F = [&](double z) -> double {
        double dz = z - z0;
        return PI * (h.r2 * dz - dz * dz * dz / 3.0);
    };
    return F(high) - F(low);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout << fixed << setprecision(9);
    
    int n, s;
    while (cin >> n >> s) {
        vector<Hole> holes(n);
        double totalHoleVol = 0.0;
        for (int i = 0; i < n; ++i) {
            double r, x, y, z;
            cin >> r >> x >> y >> z;
            r /= 1000.0; x /= 1000.0; y /= 1000.0; z /= 1000.0;
            holes[i] = {r, z, z - r, r * r};
            totalHoleVol += 4.0/3.0 * PI * r * r * r;
        }
        // 按 z0 - r 升序排序，便于二分查找有效孔洞
        sort(holes.begin(), holes.end(), [](const Hole& a, const Hole& b) {
            return a.zLow < b.zLow;
        });
        
        double totalCheeseVol = 100.0 * 100.0 * 100.0 - totalHoleVol;
        double targetSliceVol = totalCheeseVol / s;
        
        vector<double> ans(s);
        double prevZ = 0.0;
        
        // 预分配 lambda，避免重复构造
        auto cheeseVolumeUpToZ = [&](double zCut) -> double {
            double vol = 10000.0 * zCut;  // 100*100 = 10000
            // 二分查找第一个 zLow >= zCut 的孔洞
            int idx = upper_bound(holes.begin(), holes.end(), zCut,
                [](double val, const Hole& h) { return val < h.zLow; }) - holes.begin();
            for (int i = 0; i < idx; ++i)
                vol -= sphereSliceVolume(holes[i], 0.0, zCut);
            return vol;
        };
        
        for (int i = 0; i < s; ++i) {
            double needVol = (i + 1) * targetSliceVol;
            double lo = prevZ, hi = R;
            for (int iter = 0; iter < 40; ++iter) {  // 40 次足够
                double mid = (lo + hi) * 0.5;
                if (cheeseVolumeUpToZ(mid) < needVol)
                    lo = mid;
                else
                    hi = mid;
            }
            double curZ = (lo + hi) * 0.5;
            ans[i] = curZ - prevZ;
            prevZ = curZ;
        }
        
        for (int i = 0; i < s; ++i)
            cout << ans[i] << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于将三维几何问题转化为一维积分问题，利用二分查找精确求解切片边界。关键在于正确计算球体被平面截取部分的体积，并处理好单位转换与精度控制。该解法效率高、精度足，能够满足题目要求。
