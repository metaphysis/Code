[UVa 1726 Automatic Cheater Detection](https://blog.csdn.net/metaphysis/article/details/154407636)

## 题目分析

本题要求我们检测学生在 $\texttt{MCQ}$ 考试中的可疑作弊行为。具体规则如下：

### 题目属性
- **难度** $d$：整数 $1 \leq d \leq 10$，数值越大题目越难
- **状态** $s$：$1$ 表示题目泄露，$0$ 表示题目未泄露
- **结果** $r$：$\texttt{c}$ 表示答对，$\texttt{i}$ 表示答错

### 可疑行为定义
当同时满足以下条件时，记作一次可疑行为：
1. 学生答对了一道**泄露的**难度为 $d_1$ 的题目
2. 学生答错了一道**未泄露的**难度为 $d_2$ 的题目  
3. 且 $d_1 > d_2$

### 输入输出要求
- 输入包含多个测试用例
- 每个测试用例最多包含 $50000$ 道题目
- 输出每个测试用例中的可疑行为总数

## 解题思路

### 暴力解法分析
最直接的方法是枚举所有题目对，检查是否满足可疑行为的条件。这种方法的时间复杂度为 $O(Q^2)$，对于 $Q = 50000$ 的情况会超时。

### 优化思路
利用**难度值范围很小**（只有 $1$ 到 $10$）这一特点，我们可以设计更高效的算法：

1. **统计计数**：
   - 对于每个难度 $d$，统计：
     - $\texttt{leakedCorrect}[d]$：泄露且答对的题目数量
     - $\texttt{notLeakedIncorrect}[d]$：未泄露且答错的题目数量

2. **前缀和预处理**：
   - 计算 $\texttt{prefixIncorrect}[k]$：难度 $\leq k$ 的未泄露且答错的题目总数
   - 这样可以在 $O(1)$ 时间内查询任意难度范围内的未泄露答错题目数

3. **计算可疑行为**：
   - 对于每个难度 $d_1$（泄露且答对）：
     - 对应的未泄露答错题目难度必须小于 $d_1$
     - 可疑行为数 += $\texttt{leakedCorrect}[d_1] \times \texttt{prefixIncorrect}[d_1 - 1]$

## 代码实现

```cpp
// Automatic Cheater Detection
// UVa ID: 1726
// Verdict: Accepted
// Submission Date: 2025-11-04
// UVa Run Time: 0.170s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <cstring>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int testCaseCount;
    cin >> testCaseCount;
    
    while (testCaseCount--) {
        int questionCount;
        cin >> questionCount;
        
        // 统计数组：下标 1~10 对应难度 1~10
        int leakedCorrect[11] = {0};          // 泄露且答对的题目数
        int notLeakedIncorrect[11] = {0};     // 未泄露且答错的题目数
        
        // 读取并统计每道题目的信息
        for (int i = 0; i < questionCount; i++) {
            int difficulty, status;
            char result;
            cin >> difficulty >> status >> result;
            
            if (status == 1 && result == 'c') {
                leakedCorrect[difficulty]++;
            } else if (status == 0 && result == 'i') {
                notLeakedIncorrect[difficulty]++;
            }
        }
        
        // 计算前缀和：prefixIncorrect[k] 表示难度 ≤ k 的未泄露答错题目总数
        int prefixIncorrect[11] = {0};
        for (int k = 1; k <= 10; k++) {
            prefixIncorrect[k] = prefixIncorrect[k - 1] + notLeakedIncorrect[k];
        }
        
        // 计算总可疑行为数
        long long totalSuspicious = 0;
        for (int d1 = 2; d1 <= 10; d1++) {  // d1 从 2 开始，因为需要 d1 > d2
            if (leakedCorrect[d1] > 0) {
                totalSuspicious += (long long)leakedCorrect[d1] * prefixIncorrect[d1 - 1];
            }
        }
        
        cout << totalSuspicious << "\n";
    }
    
    return 0;
}
```
