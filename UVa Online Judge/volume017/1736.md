[UVa 1736 Balanced Diet](https://blog.csdn.net/metaphysis/article/details/153410290)

## 题目描述

丹尼每天从糖果店购买并吃掉一颗糖果。商店有 $m$ 种糖果，编号从 $1$ 到 $m$。丹尼希望保持均衡饮食，因此为每种糖果类型 $i$ 分配了一个目标比例 $f_i$（$0 < f_i \leq 1$）。设 $s_i$ 表示丹尼已吃的第 $i$ 种糖果的数量，$n = \sum_{i=1}^m s_i$ 表示总糖果数。糖果集合是**平衡的**当且仅当对于所有 $i$ 满足：
$$
n f_i - 1 < s_i < n f_i + 1
$$
丹尼已经吃了一段时间的糖果，并且到目前为止的所有前缀序列（包括整个序列）都是平衡的。现在他想知道在保持平衡的前提下，最多还能吃多少颗糖果。如果数量没有上限，则输出 `forever`。

---

## 输入格式

- 第一行：两个整数 $m$（糖果种类数，$1 \leq m \leq 10^5$）和 $k$（已吃糖果数，$0 \leq k \leq 10^5$）
- 第二行：$m$ 个正整数 $a_1, \ldots, a_m$，满足 $f_i = \frac{a_i}{\sum_{j=1}^m a_j}$，且 $\sum a_j \leq 10^5$
- 第三行：$k$ 个整数 $b_1, \ldots, b_k$，表示已吃糖果的类型序列

---

## 输出格式

- 一行一个整数表示最多还能吃的糖果数，或 `forever`

---

## 题目分析

### 平衡条件的等价形式

将 $f_i = \frac{a_i}{tot}$（其中 $tot = \sum_{j=1}^m a_j$）代入平衡条件：
$$
n \cdot \frac{a_i}{tot} - 1 < s_i < n \cdot \frac{a_i}{tot} + 1
$$
两边乘以 $tot$ 得：
$$
n a_i - tot < s_i \cdot tot < n a_i + tot
$$
由于 $s_i$、$n$、$a_i$、$tot$ 都是整数，严格不等式等价于：
$$
n a_i - tot + 1 \leq s_i \cdot tot \leq n a_i + tot - 1
$$

### 关键思路

我们关注**上界条件**：
$$
s_i < \frac{n a_i}{tot} + 1
$$
假设当前已吃 $s_i$ 颗第 $i$ 种糖果，若再吃一颗该种糖果，则 $s_i' = s_i + 1$，必须满足：
$$
s_i + 1 < \frac{n a_i}{tot} + 1
$$
化简得：
$$
s_i < \frac{n a_i}{tot}
$$
即：
$$
n > \frac{s_i \cdot tot}{a_i}
$$
由于 $n$ 是整数，因此：
$$
n \geq \left\lfloor \frac{s_i \cdot tot}{a_i} \right\rfloor + 1
$$
但更实用的形式是计算**下一次不能吃该种糖果的最小 $n$**：
$$
next_n = \left\lceil \frac{(s_i + 1) \cdot tot}{a_i} \right\rceil
$$
表示如果再吃一颗第 $i$ 种糖果，必须在 $n < next_n$ 之前吃，否则会破坏平衡。

### 算法设计

1. **初始化**：
   - 读入 $m$、$k$、$a_i$ 序列和已吃糖果序列 $b_i$
   - 统计每种糖果已吃数量 $s_i$，计算 $tot = \sum a_i$

2. **优先队列**：
   - 对于每种糖果 $i$，计算 $next_n = \lceil (s_i + 1) \cdot tot / a_i \rceil$
   - 将所有 $(next_n, i)$ 存入小根堆

3. **模拟过程**：
   - 从 $n = k$ 开始，每次循环：
     - $n \gets n + 1$
     - 取出堆顶 $(next_n, i)$
     - 如果 $next_n < n$，说明不能再吃，退出循环
     - 否则，吃掉一颗第 $i$ 种糖果，更新 $s_i$，重新计算 $next_n$ 并放回堆中
     - 如果 $n$ 是 $tot$ 的倍数，则判定为 `forever`

4. **输出结果**：
   - 若为 `forever`，输出 `"forever"`
   - 否则输出 $n - k - 1$（因为 $n$ 是第一个不能吃的总糖果数）

---

## 复杂度分析

- 时间复杂度：$O((m + k + \text{答案}) \log m)$，由于 $tot \leq 10^5$，模拟次数有限
- 空间复杂度：$O(m)$

## 代码实现

```cpp
// Balanced Diet
// UVa ID: 1736
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.390s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;
int main() {
    int m, k;
    while (cin >> m >> k) {
        vector<long long> a(m);
        long long tot = 0;
        for (int i = 0; i < m; i++) {
            cin >> a[i];
            tot += a[i];
        }
        vector<long long> s(m, 0);
        for (int i = 0; i < k; i++) {
            int b;
            cin >> b;
            s[b - 1]++;
        }
        priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> pq;
        for (int i = 0; i < m; i++) {
            long long next_n = ((s[i] + 1) * tot + a[i] - 1) / a[i];
            pq.push({next_n, i});
        }
        long long n = k;
        bool forever = false;
        while (true) {
            n++;
            auto [next_n, idx] = pq.top();
            if (next_n < n) {
                n = next_n;
                break;
            }
            pq.pop();
            s[idx]++;
            long long new_next_n = ((s[idx] + 1) * tot + a[idx] - 1) / a[idx];
            pq.push({new_next_n, idx});
            if (n % tot == 0) {
                forever = true;
                break;
            }
        }
        if (forever) {
            cout << "forever\n";
        } else {
            cout << n - k - 1 << "\n";
        }
    }
    return 0;
}
```

## 总结

本题通过将平衡条件转化为对每种糖果的"下一次不能吃"的最小 $n$ 值，利用优先队列模拟吃糖果的过程，高效地求出最大可增数量或判断是否可无限吃。关键在于理解 next_n 的计算和模拟过程中的边界检查。
