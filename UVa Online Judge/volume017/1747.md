[UVa 1747 Swap Space](https://blog.csdn.net/metaphysis/article/details/155060961)

## 题目描述

你管理着一个大型计算机集群，其中的硬盘使用不同的文件系统类型存储数据。你最近决定将这些文件系统统一为同一类型。这是一个相当大的挑战，因为所有硬盘目前都在使用中，且所有硬盘都已存满重要数据，你不能丢失任何数据。此外，将硬盘重新格式化为新文件系统可能会显著改变其容量。为了能够进行重新格式化，你需要购买一个额外的硬盘。显然，你希望通过最小化这种额外存储的大小来节省资金。

你可以按任意顺序重新格式化硬盘。在重新格式化硬盘之前，你必须将该硬盘上的所有数据移动到一个或多个其他硬盘上，必要时可以拆分数据。硬盘重新格式化后，你可以立即开始使用它来存储来自其他硬盘的数据。不必将所有数据放回它们最初所在的硬盘上——事实上，如果某些硬盘在新文件系统下的容量较小，这可能甚至是不可能的。也允许某些数据最终存放在额外的硬盘上。

### 输入格式

输入以一行整数 $n$ ($1 \leq n \leq 10^6$) 开始，表示集群中的硬盘数量。接下来是 $n$ 行，每行描述一个硬盘，包含两个整数 $a$ 和 $b$，其中 $a$ 是旧文件系统下的容量，$b$ 是新文件系统下的容量。

所有容量以 $\texttt{GB}$ 为单位，且满足 $1 \leq a, b \leq 10^9$。

### 输出格式

对于每个测试用例，输出你需要购买的总额外容量（以 $\texttt{GB}$ 为单位）。

### 样例输入

```
4
6 6
1 7
3 5
3 5
4
2 2
3 3
5 1
5 10
```

### 样例输出

```
1
5
```

## 题目分析与解题思路

### 问题分析

这是一个典型的资源调度和优化问题。我们需要找到最小的额外存储空间，使得能够按某种顺序重新格式化所有硬盘，同时保证在重新格式化过程中不会丢失任何数据。

关键约束条件：
- 在重新格式化每个硬盘前，必须将其所有数据移动到其他硬盘（包括额外购买的硬盘）
- 重新格式化后，硬盘可以立即用于存储其他硬盘的数据
- 数据可以拆分存储到多个硬盘上
- 最终数据不必回到原始硬盘

### 核心思路

通过分析，我们可以将硬盘分为两类：

1. **增益硬盘**：新容量 $b$ 大于或等于旧容量 $a$ ($b \geq a$)
   - 重新格式化后，这些硬盘会提供额外的存储空间
   - 应该优先处理这类硬盘，以便尽早获得更多可用空间

2. **损耗硬盘**：新容量 $b$ 小于旧容量 $a$ ($b < a$)
   - 重新格式化后，这些硬盘的容量会减少
   - 应该稍后处理这类硬盘，避免过早消耗可用空间

### 贪心策略

1. **对增益硬盘的处理顺序**：按旧容量 $a$ 升序排列
   - 先处理容量小的硬盘，需要的临时空间少，风险小
   - 尽早释放空间用于后续操作

2. **对损耗硬盘的处理顺序**：按新容量 $b$ 降序排列
   - 先处理那些重新格式化后还能提供较多空间的硬盘
   - 这样可以最大化后续可用的存储空间

3. **整体处理顺序**：先处理所有增益硬盘，再处理所有损耗硬盘

### 算法流程

1. 读取输入数据，将硬盘分为增益硬盘和损耗硬盘两类
2. 对增益硬盘按旧容量升序排序
3. 对损耗硬盘按新容量降序排序
4. 按照"先增益后损耗"的顺序处理所有硬盘
5. 模拟重新格式化过程：
   - 维护当前可用空间 `currentSpace`
   - 对于每个要格式化的硬盘：
     - 如果当前可用空间不足该硬盘的旧容量，则需要购买额外空间
     - 重新格式化后，更新当前可用空间：`currentSpace += b - a`
6. 输出需要购买的总额外空间

### 复杂度分析

- 时间复杂度：$O(n \log n)$，主要来自排序操作
- 空间复杂度：$O(n)$，用于存储硬盘信息

## 代码实现

```cpp
// Swap Space
// UVa ID: 1747
// Verdict: Accepted

// UVa Run Time: 0.510s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Drive {
    long long a, b;
};

int main() {
    int n;
    while (cin >> n) {
        vector<Drive> drives(n);
        for (int i = 0; i < n; i++) {
            cin >> drives[i].a >> drives[i].b;
        }
        
        // 分离两类硬盘：新容量≥旧容量 vs 新容量<旧容量
        vector<Drive> gain, loss;
        for (const auto& drive : drives) {
            if (drive.b >= drive.a) {
                gain.push_back(drive);
            } else {
                loss.push_back(drive);
            }
        }
        
        // 增益硬盘按旧容量升序，损耗硬盘按新容量降序
        sort(gain.begin(), gain.end(), [](const Drive& d1, const Drive& d2) {
            return d1.a < d2.a;
        });
        sort(loss.begin(), loss.end(), [](const Drive& d1, const Drive& d2) {
            return d1.b > d2.b;
        });
        
        // 合并处理顺序：先处理增益硬盘，再处理损耗硬盘
        vector<Drive> orderedDrives;
        orderedDrives.insert(orderedDrives.end(), gain.begin(), gain.end());
        orderedDrives.insert(orderedDrives.end(), loss.begin(), loss.end());
        
        long long currentSpace = 0;
        long long extraNeeded = 0;
        
        for (const auto& drive : orderedDrives) {
            if (drive.a > currentSpace) {
                extraNeeded += drive.a - currentSpace;
                currentSpace = drive.a;
            }
            currentSpace += drive.b - drive.a;
        }
        
        cout << extraNeeded << endl;
    }
    return 0;
}
```
