[UVa 10027 Language Cardinality](https://blog.csdn.net/metaphysis/article/details/154849606)

## 题目描述

给定一个形式语言，由以下两部分定义：

- 一个初始字符串
- 一组替换规则，形式为 $s_1 \to s_2$，其中 $s_1$ 和 $s_2$ 都是字符串

该语言定义为：从初始字符串开始，反复将 $s_1$ 替换为 $s_2$ 所能生成的所有字符串的集合。

例如，对于初始字符串 `"AyB"` 和替换规则：
```
"A"->"ab"
"Ay"->"cdy" 
"B"->"w"
"B"->"x"
```

生成的语言包含 $9$ 个字符串：
```
{"AyB", "Ayw", "Ayx", "abyB", "abyw", "abyx", "cdyB", "cdyw", "cdyx"}
```

**任务**：计算给定语法生成的语言中不同字符串的数量。如果超过 $1000$ 个，输出 `"Too many."`。

## 输入格式

- 第一行：测试用例数量
- 每个测试用例：
  - 第一行：初始字符串（用引号包围）
  - 后续行：替换规则，每行一个，格式为 `"left"->"right"`
  - 测试用例之间用空行分隔

**约束**：
- 最多 $100$ 条替换规则
- 每个字符串包含 $0$ 到 $10$ 个大小写字母
- 输入中没有空格

## 输出格式

对于每个测试用例，输出不同字符串的数量，如果超过 $1000$ 则输出 `"Too many."`，测试用例之间用空行分隔。

## 题目分析

### 问题本质

这是一个**字符串生成系统**的问题，我们需要模拟从初始字符串开始，通过应用替换规则所能达到的所有可能字符串。

### 关键观察

1. **无限生成情况**：某些规则会导致字符串无限增长：
   - 空串替换为非空串：`""->"a"` 可以在任意位置无限插入字符
   - 右部包含左部：如 `"a"->"aa"` 会导致无限递归扩展

2. **搜索空间限制**：题目要求最多处理 $1000$ 个不同字符串，这提示我们可以使用**广度优先搜索**（$\texttt{BFS}$）或**深度优先搜索**（$\texttt{DFS}$）来探索状态空间。

3. **性能考虑**：由于规则最多 $100$ 条，字符串长度有限，直接使用字符串查找和替换在可接受范围内。

## 解题思路

### 1. 无限情况检测

在开始搜索前，先检查是否存在会导致无限生成的规则：
- 如果 `left.empty() && !right.empty()`：空串替换为非空串
- 如果 `right.find(left) != right.npos`：右部包含左部

发现任何此类规则，直接返回 `"Too many."`。

### 2. 搜索策略

使用**带优先队列的广度优先搜索**：

- **数据结构**：
  - `set<string>`：存储已生成的字符串，用于去重
  - `priority_queue<string, vector<string>, cmp>`：待处理的字符串队列

- **优先策略**：优先处理**较短**的字符串，这有助于：
  - 更快发现小规模解空间
  - 避免在过长的字符串上进行无效搜索
  - 控制内存使用

### 3. 替换过程

对于每个当前字符串，尝试所有规则的所有匹配位置：
```cpp
for 每条规则:
    pos = 0
    while 在current中找到rule.left从pos开始的位置:
        生成新字符串 = current[0:pos] + rule.right + current[pos+len(rule.left):]
        如果是新字符串，加入集合和队列
        pos += 1
```

### 4. 终止条件

- 队列为空：所有可达字符串都已生成
- 生成字符串数 > $1000$：立即终止并输出 `"Too many."`

## 算法复杂度

- **时间复杂度**：最坏情况 $O(N \times M \times L)$，其中：
  - $N$：生成的字符串数量（最多 $1000$）
  - $M$：规则数量（最多 $100$）
  - $L$：字符串平均长度
- **空间复杂度**：$O(N \times L)$，存储所有不同的字符串

## 代码实现

```cpp
// Language Cardinality
// UVa ID: 10027
// Verdict: Accepted

// UVa Run Time: 0.000s

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

string extractString(const string& quoted) {
    if (quoted.size() >= 2 && quoted[0] == '"' && quoted[quoted.size() - 1] == '"')
        return quoted.substr(1, quoted.size() - 2);
    return quoted;
}

struct RuleInfo {
    string left;
    string right;
    RuleInfo(const string& l, const string& r) : left(l), right(r) {}
};

// 自定义优先队列比较函数，优先处理较短的字符串
struct cmp {
    bool operator()(const string& a, const string& b) {
        return a.length() > b.length(); // 最小堆，短字符串优先
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int caseCount;
    cin >> caseCount;
    cin.ignore();
    for (int caseNum = 0; caseNum < caseCount; ++caseNum) {
        if (caseNum > 0) cout << endl;
        string line;
        while (getline(cin, line) && line.empty()) {}
        string initialString = extractString(line);
        bool unlimited = false;
        vector<RuleInfo> rules;
        while (getline(cin, line)) {
            if (line.empty()) break;
            if (line.find("->") == string::npos) continue;
            size_t pos = line.find("->");
            string left = extractString(line.substr(0, pos));
            string right = extractString(line.substr(pos + 2));
            if (left == right) continue;
            if (left.empty() && !right.empty()) unlimited = true;
            if (right.find(left) != right.npos) unlimited = true;
            rules.emplace_back(left, right);
        }
        // 检查无限生成规则
        if (unlimited) {
            cout << "Too many." << '\n';
            continue;
        }
        set<string> generatedStrings;
        priority_queue<string, vector<string>, cmp> bfsQueue;
        generatedStrings.insert(initialString);
        bfsQueue.push(initialString);
        while (!bfsQueue.empty() && generatedStrings.size() <= 1000) {
            string current = bfsQueue.top();
            bfsQueue.pop();
            // 对每个规则进行顺序查找和替换
            for (const auto& rule : rules) {
                size_t pos = 0;
                while ((pos = current.find(rule.left, pos)) != string::npos) {
                    // 生成新字符串
                    string newString = current.substr(0, pos) + rule.right + 
                                      current.substr(pos + rule.left.length());
                    if (generatedStrings.find(newString) == generatedStrings.end()) {
                        generatedStrings.insert(newString);
                        bfsQueue.push(newString);
                        if (generatedStrings.size() > 1000) goto output;
                    }
                    pos += 1; // 继续查找下一个匹配位置
                }
            }
        }
        output:
        if (generatedStrings.size() > 1000) cout << "Too many." << '\n';
        else cout << generatedStrings.size() << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于：
1. **识别无限生成模式**并提前处理
2. **使用优先队列优化搜索顺序**，优先处理短字符串
3. **合理利用题目约束**（$1000$ 字符串限制）来控制搜索规模

这种解法在保证正确性的同时，具有良好的性能表现，能够高效处理题目给定的数据规模。
