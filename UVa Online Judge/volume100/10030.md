## 题目描述

有三台计算机通过网络连接。其中一台是服务器，另外两台是客户端。服务器上有 $N$ 个文件，每个文件都有不同的完整文件名。完整文件名由两部分组成：名称（$\texttt{name}$）和扩展名（$\texttt{extension}$）。两个客户端都知道服务器上所有文件的完整名称。

服务器从这些文件中选中一个文件，将文件名的“名称”部分发送给客户端A，将“扩展名”部分发送给客户端B。两个客户端随后开始交替通信，每次只能说“我不知道完整文件名”。他们轮流发送这条消息，直到其中一个客户端能够确定完整文件名，或者他们决定放弃。已知客户端之间总共交换了 $M$ 条这样的消息，且客户端B（收到扩展名的那一方）总是先说话。

你作为旁观者，知道服务器上所有文件的完整名称，并且听到了 $M$ 条“我不知道”的对话。你需要确定，在这样的对话之后，服务器最初可能选择了哪些文件。这些可能的文件称为“候选文件”。

**输入格式：** 第一行是测试用例数量 $T$。每个测试用例的第一行包含两个整数 $N$ 和 $M$，分别表示文件数量和交换的消息数量。接下来 $N$ 行，每行一个完整文件名（格式类似 $8.3$ 格式，名称部分 $1-8$ 个字符，扩展名部分 $0-3$ 个字符，扩展名为空时点号可省略）。测试用例之间有一个空行。

**输出格式：** 对于每个测试用例，第一行输出候选文件的数量，接下来每行输出一个候选文件的完整名称（按输入顺序，保持原格式）。测试用例之间输出一个空行。

## 题目分析与解题思路

### 问题本质

这是一个**逻辑推理模拟**问题。两个客户端各自掌握部分信息（$A$ 知道名称，$B$ 知道扩展名），通过交换“我不知道”的消息来逐步排除可能性，直到有人能确定文件或对话结束。

关键点在于：当一方说“我不知道”时，另一方可以利用这个信息来排除一些可能性。

### 推理过程分析

假设当前剩余的可能文件集合为 $S$。

1. **$B$ 的回合**（$B$ 知道扩展名）：
   - 如果 $B$ 当前知道的扩展名在 $S$ 中**只对应一个文件**，那么 $B$ 就能立刻确定是哪个文件，从而不会说“我不知道”。
   - 因此，如果 $B$ 说了“我不知道”，就意味着 $B$ 的扩展名在 $S$ 中**至少对应两个文件**。
   - 所以，我们可以从 $S$ 中排除那些扩展名在 $S$ 中**唯一**的文件（因为如果真是这些文件，$B$ 就不会说“我不知道”）。

2. **$A$ 的回合**（$A$ 知道名称）：
   - 同理，如果 $A$ 当前知道的名称在 $S$ 中**只对应一个文件**，那么 $A$ 就能立刻确定。
   - 因此，如果 $A$ 说了“我不知道”，就意味着 $A$ 的名称在 $S$ 中**至少对应两个文件**。
   - 所以，我们可以从 $S$ 中排除那些名称在 $S$ 中**唯一**的文件。

3. **模拟过程**：
   - 初始时，$S$ 包含所有文件。
   - 按照 $B$, $A$, $B$, $A$, ... 的顺序模拟 $M$ 条“我不知道”的消息。
   - 每条消息后，根据当前发言方，从 $S$ 中排除那些会使发言方**立即确定**的文件。
   - $M$ 条消息后，$S$ 中剩余的文件就是候选文件。

### 算法设计

1. **数据结构**：
   - 用结构体存储每个文件的完整名称、解析出的名称和扩展名。
   - 使用哈希表记录每个名称对应的扩展名集合、每个扩展名对应的名称集合（虽然本题解代码中未直接使用这些集合进行唯一性判断，但可用于理解问题背景）。

2. **模拟步骤**：
   - 初始化一个布尔数组 `isCandidate`，标记所有文件为候选。
   - 对于每条消息 $msg = 0, 1, ..., M-1$：
     - 统计当前候选集合中每个名称和每个扩展名的出现次数。
     - 如果 $msg$ 是偶数（$B$ 的回合），排除那些扩展名出现次数为 $1$ 的文件。
     - 如果 $msg$ 是奇数（$A$ 的回合），排除那些名称出现次数为 $1$ 的文件。
   - 最后收集所有仍被标记为候选的文件。

3. **时间复杂度**：每个测试用例为 $O(N \times M)$，在 $N \leq 1000$，$M \leq 100$ 的范围内完全可行。

### 样例分析

以题目样例为例：
- 文件总数 $N = 19$，消息数 $M = 2$。
- 第一条消息（$B$ 说“我不知道”）：排除那些扩展名在当前候选集中唯一的文件。
- 第二条消息（$A$ 说“我不知道”）：排除那些名称在当前候选集中唯一的文件。
- 最终剩余 $6$ 个文件，与输出一致。

## 代码实现

```cpp
// Computer Dialogue

#include <bits/stdc++.h>
using namespace std;

struct File {
    string fullName;
    string name;
    string ext;
};

void solve() {
    int N, M;
    cin >> N >> M;
    vector<File> files(N);
    unordered_map<string, unordered_set<string>> nameToExts;
    unordered_map<string, unordered_set<string>> extToNames;

    for (int i = 0; i < N; ++i) {
        string full;
        cin >> full;
        files[i].fullName = full;
        size_t dotPos = full.find('.');
        if (dotPos == string::npos) {
            files[i].name = full;
            files[i].ext = "";
        } else {
            files[i].name = full.substr(0, dotPos);
            files[i].ext = full.substr(dotPos + 1);
        }
        nameToExts[files[i].name].insert(files[i].ext);
        extToNames[files[i].ext].insert(files[i].name);
    }

    vector<bool> isCandidate(N, true);

    // 模拟消息交换
    for (int msg = 0; msg < M; ++msg) {
        // 检查当前候选集合，找出会被排除的文件
        unordered_map<string, int> nameCount;
        unordered_map<string, int> extCount;
        for (int i = 0; i < N; ++i) {
            if (isCandidate[i]) {
                nameCount[files[i].name]++;
                extCount[files[i].ext]++;
            }
        }

        // 决定排除哪些文件
        vector<bool> newCandidate = isCandidate;
        if (msg % 2 == 0) { // B的回合（扩展名方）
            for (int i = 0; i < N; ++i) {
                if (isCandidate[i] && extCount[files[i].ext] == 1) {
                    // B能唯一确定，所以这个文件不会在下一轮候选
                    newCandidate[i] = false;
                }
            }
        } else { // A的回合（名称方）
            for (int i = 0; i < N; ++i) {
                if (isCandidate[i] && nameCount[files[i].name] == 1) {
                    // A能唯一确定，所以这个文件不会在下一轮候选
                    newCandidate[i] = false;
                }
            }
        }
        isCandidate = move(newCandidate);
    }

    vector<string> candidates;
    for (int i = 0; i < N; ++i) {
        if (isCandidate[i]) candidates.push_back(files[i].fullName);
    }

    cout << candidates.size() << '\n';
    for (const string& name : candidates) cout << name << '\n';
}

int main() {
    int T;
    cin >> T;
    while (T--) {
        solve();
        if (T) cout << '\n'; // 测试用例之间空行
    }
    return 0;
}
```

## 总结

本题的关键在于理解“我不知道”这句话所隐含的信息：它意味着发言方**当前无法唯一确定**文件。通过模拟这一排除过程，我们可以逐步缩小可能文件的集合。算法实现较为直接，但需要仔细处理文件名的解析和模拟的逻辑顺序。
