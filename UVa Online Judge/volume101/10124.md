## 题目描述

地铁列车需要在加加速度（$\texttt{jerk}$）、加速度和速度的多重约束下，以最短时间在两个车站之间运行。列车从静止开始加速，到达某个速度后可能保持匀速运行，最后减速到静止。整个过程需要满足以下物理约束：

- 车站间距：$d$ 米
- 最大速度：$m$ 米/秒  
- 最大加速度：$a$ 米/秒$^2$
- 最大加加速度：$j$ 米/秒$^3$

加加速度是加速度的变化率，这个约束保证了加速度的平滑变化，避免对站立的乘客造成不适。

## 题目分析

这是一个典型的**运动规划问题**，需要在多重物理约束下找到时间最优的轨迹。关键难点在于：

1. **三重约束**：速度、加速度、加加速度都需要满足上限
2. **对称性**：加速和减速过程完全对称
3. **阶段转换**：需要正确处理加速、匀速、减速阶段的转换

## 物理模型与解题思路

### 运动阶段分解

列车从静止到静止的完整运动可以分为对称的加速和减速过程。对于单边加速过程，包含三个阶段：

1. **加加速度增加阶段** ($0 \rightarrow t_1$)
   - 加加速度：$j(t) = j$
   - 加速度：$a(t) = j \cdot t$ 
   - 速度：$v(t) = \frac{1}{2}j \cdot t^2$
   - 距离：$s_1(t) = \frac{1}{6}j \cdot t^3$

2. **匀加速阶段** ($t_1 \rightarrow t_2$，可能不存在)
   - 加速度保持最大值：$a(t) = a$
   - 速度线性增加
   - 距离通过积分计算

3. **加加速度减小阶段** ($t_2 \rightarrow t_3$)
   - 加加速度：$j(t) = -j$
   - 加速度线性减小到 $0$
   - **关键洞察**：此阶段速度仍在增加，增量等于第一阶段的速度增量

### 三种情况分类

根据约束条件的不同，我们需要处理三种情况：

#### 情况1：仅通过加加速度阶段就能达到最大速度
当 $j \cdot t_1^2 > m$ 时，仅通过加加速度阶段就能达到最大速度，此时：
$$t_1 = t_2 = \sqrt{\frac{m}{j}}$$

#### 情况2：需要匀加速阶段达到最大速度
当加速度限制先于速度限制起作用时：
$$t_1 = \frac{a}{j}, \quad t_2 = \frac{m - j \cdot t_1^2}{a} + t_1$$

#### 情况3：无法达到最大速度
当加速距离超过半程距离时，需要重新计算最优速度。这又分为两个子情况：

- **子情况3a**：仅通过加加速度阶段
  $$t_1 = \sqrt[3]{\frac{d}{2j}}$$

- **子情况3b**：受加速度限制，需要解二次方程
  $$t_1 = \frac{a}{j}, \quad \frac{1}{2}j \cdot t_1 \cdot t_2^2 + \frac{1}{2}j \cdot t_1^2 \cdot t_2 = \frac{d}{2}$$

### 算法流程

1. 首先尝试达到最大速度 $m$，判断属于情况1还是情况2
2. 计算对应的加速距离，检查是否超过半程距离 $\frac{d}{2}$
3. 如果超过，进入情况3处理
4. 根据是否受加速度限制，分别计算最优的 $t_1$ 和 $t_2$
5. 计算总时间，包括加速、匀速和减速阶段

## 复杂度分析

- **时间复杂度**：$O(1)$，所有计算都是常数时间操作
- **空间复杂度**：$O(1)$，只使用常数个变量

```cpp
// Subway

#include <bits/stdc++.h>
using namespace std;

int main() {
    double d, m, a, j;
    
    while (cin >> d >> m >> a >> j) {
        double halfD = d / 2.0;
        double t1, t2, finalSpeed, dist1, dist2, dist3;
        
        // 情况1和2：尝试达到最大速度
        t1 = a / j;  // 加速到最大加速度的时间
        
        // 检查是情况1还是情况2
        if (j * t1 * t1 > m) {
            // 情况1：仅通过加加速度阶段就能达到最大速度
            t1 = sqrt(m / j);
            t2 = t1;
        } else {
            // 情况2：需要匀加速阶段
            t2 = (m - j * t1 * t1) / a + t1;
        }
        
        // 计算最终速度和各段距离
        finalSpeed = j * t1 * t1 / 2.0 + j * t1 * (t2 - t1) + j * t1 * t1 / 2.0;
        dist1 = j * t1 * t1 * t1 / 6.0;
        dist2 = (j * t1 * t1 + j * t1 * (t2 - t1)) * (t2 - t1) / 2.0;
        dist3 = (j * t1 * t1 / 2.0 + j * t1 * (t2 - t1)) * t1 + 
                j * t1 * t1 * t1 / 2.0 - j * t1 * t1 * t1 / 6.0;
        
        double totalTime;
        
        if (dist1 + dist2 + dist3 > halfD) {
            // 情况3：无法达到最大速度
            
            // 先假设仅通过加加速度阶段
            t1 = pow(halfD / j, 1.0 / 3.0);
            t2 = t1;
            
            // 重新计算
            finalSpeed = j * t1 * t1 / 2.0 + j * t1 * (t2 - t1) + j * t1 * t1 / 2.0;
            dist1 = j * t1 * t1 * t1 / 6.0;
            dist2 = (j * t1 * t1 + j * t1 * (t2 - t1)) * (t2 - t1) / 2.0;
            dist3 = (j * t1 * t1 / 2.0 + j * t1 * (t2 - t1)) * t1 + 
                    j * t1 * t1 * t1 / 2.0 - j * t1 * t1 * t1 / 6.0;
            
            if (t1 * j > a) {
                // 需要匀加速阶段但受加速度限制
                t1 = a / j;
                // 解二次方程: a*t2² + b*t2 + c = 0
                double coeffA = j * t1 / 2.0;
                double coeffB = j * t1 * t1 / 2.0;
                double coeffC = -halfD;
                
                t2 = (-coeffB + sqrt(coeffB * coeffB - 4.0 * coeffA * coeffC)) / (2.0 * coeffA);
                
                // 重新计算最终结果
                finalSpeed = j * t1 * t1 / 2.0 + j * t1 * (t2 - t1) + j * t1 * t1 / 2.0;
                dist1 = j * t1 * t1 * t1 / 6.0;
                dist2 = (j * t1 * t1 + j * t1 * (t2 - t1)) * (t2 - t1) / 2.0;
                dist3 = (j * t1 * t1 / 2.0 + j * t1 * (t2 - t1)) * t1 + 
                        j * t1 * t1 * t1 / 2.0 - j * t1 * t1 * t1 / 6.0;
            }
            
            totalTime = t1 + t2 + (halfD - dist1 - dist2 - dist3) / finalSpeed;
        } else {
            // 可以达到最大速度
            totalTime = t1 + t2 + (halfD - dist1 - dist2 - dist3) / m;
        }
        
        // 总时间是前半程时间的2倍
        totalTime *= 2.0;
        totalTime = round(totalTime * 10.0) / 10.0;
        cout << fixed << setprecision(1) << totalTime << endl;
    }
    
    return 0;
}
```

## 总结

本题的关键在于深入理解加加速度约束下的运动物理，并正确分类处理各种约束组合情况。通过精确的数学推导和物理建模，我们能够在 $O(1)$ 时间内求出最优解，避免了复杂的数值积分或优化算法。这种基于物理洞察的解析解法既高效又精确，是解决此类约束优化问题的典范方法。
