[UVa 10133 Audubon's Stormy Arctic Trip](https://blog.csdn.net/metaphysis/article/details/161838188)

## 题目描述

$\texttt{autopun}$ 程序用于生成双关语（通常是糟糕的双关语）。它不直接列出某个短语的所有可能双关，而是输出一个有根有向无环图（$\texttt{DAG}$）。具体来说，该图给出短语第一个单词的一组选择。这个选择不仅决定了一个单词，还决定了下一个单词的另一个列表的名称，依此类推。每个列表是 $\texttt{DAG}$ 中的一个节点，用两位数 $00$ 到 $99$ 标记。

我们需要找到 $\texttt{autopun}$ 指定的第 $n$ 个双关语。第一个双关语是简单地从每个选择中选第一个选项构成的短语。下一个双关语是：对最后一个仍有备选的选择，选其下一个选项，之后的所有选择都选第一个选项。也就是说，双关语的顺序由 $\texttt{DAG}$ 的叶子节点的从左到右遍历决定。

## 输入格式

第一行包含一个整数，表示测试用例的数量。然后有一个空行，每个测试用例之间用一个空行分隔。

每个测试用例的输入由若干节点条目组成。一个条目的第一行包含一个两位数（$00$ 到 $99$）后跟一个冒号。条目中后续的行缩进，包含由空格分隔的 `word:node` 项。`$` 代表一个短语的结束。节点 `00` 是第一个节点。

在节点条目之后，有零行或更多行，每行包含 $1$ 到该 $\texttt{DAG}$ 的最大双关语编号范围内的整数。

## 输出格式

对每个测试用例，输出每个双关语一行，单词之间用连字符分隔。连续测试用例的输出之间打印一个空行。

## 题目分析

本题的核心是：给定一个有根有向无环图，每个节点（$00$ 到 $99$）代表一个状态。每个状态包含若干条 `word:node` 边，表示选择该单词后跳转到下一状态。如果 `node` 为 `$`，则表示短语结束。我们需要按照特定的枚举顺序（类似变进制数的进位方式，但深度优先从左到右），输出第 $n$ 个从根节点 $00$ 出发到 `$` 结束的完整路径上的单词序列。

直接枚举所有路径并排序是不可行的，因为路径总数可能非常大（题目保证不超过 $64$ 位整数范围，但实际路径数可能是指数级的）。因此需要一种方法能够在不枚举所有路径的情况下，快速定位到第 $n$ 个路径。

## 解题思路

### 图结构建模

将每个节点看作一个状态，每个状态有多条出边，每条出边包含一个单词和一个目标节点（或 `$` 表示结束）。则每个从节点 $00$ 出发到 `$` 结束的路径唯一对应一个短语。

关键观察：每个节点的出边顺序决定了路径的字典序（按照题目定义的顺序）。设 $\textit{dp}[u]$ 表示从节点 $u$ 出发到 `$` 结束的不同短语总数。则有状态转移方程：

$$
\textit{dp}[u] = \sum_{(word, v) \in \textit{edges}[u]} \begin{cases}
1 & \text{if } v = \text{\$} \\
\textit{dp}[v] & \text{otherwise}
\end{cases}
$$

边界条件：对于 `$` 节点，我们定义 $\textit{dp}[\$] = 1$（表示空后缀，但在实际处理中，我们通常将其视为叶子节点）。

### 路径定位算法

有了每个节点的 $\textit{dp}$ 值后，要找到第 $k$ 个短语（$1$ 索引），可以从根节点出发，遍历当前节点的出边：

对于当前节点 $u$ 的第 $i$ 条边 $(word, v)$，设 $cnt$ 为走这条边能产生的短语总数：

- 如果 $v$ 为叶节点，则 $cnt = 1$
- 否则 $cnt = \textit{dp}[v]$

如果 $k \le cnt$，则选择这条边，输出 $word$，然后从节点 $v$ 继续（如果 $v$ 为叶节点则结束）。
否则，令 $k = k - cnt$，继续尝试下一条边。

这个过程类似在变进制数中确定每一位的数字：每次减去当前分支的计数，直到找到包含第 $k$ 个路径的分支。

### 图的存储

由于题目中的节点编号只有 $00$ 到 $99$，但每个节点可能有多条出边，且输入中节点定义的顺序并非按编号递增，需要先解析所有节点条目，建立邻接表。

注意：节点 `$` 并不在 $00$ 到 $99$ 范围内，需要特殊处理。一种优雅的做法是将每个 `word` 也作为独立的节点，形成“状态节点 $\to$ 单词节点 $\to$ 下一状态节点”的三层结构，这样 `$` 可以统一用叶子节点表示。

### 记忆化搜索

由于 $\texttt{DAG}$ 中可能存在多个节点指向同一个子节点（即共享后缀），直接递归计算 $\textit{dp}$ 值会导致重复计算。因此需要使用记忆化搜索，将每个节点的 $\textit{dp}$ 值缓存起来，避免指数级时间复杂度。

### 输入解析

输入格式较为复杂：节点定义行以 `XX:` 开头，后续若干行以空格缩进，包含多个 `word:node` 对。节点条目结束后，可能有多行整数查询，每行可包含多个空格分隔的数字。需要正确处理空行和缩进。

## 代码实现

```cpp
// Audubon's Stormy Arctic Trip
// UVa ID: 10133
// Verdict: Accepted
// Submission Date: 2026-06-09
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10000, OFFSET = 100;

vector<int> g[MAXN];
long long dp[MAXN];

long long dfs(int u) {
    if (~dp[u]) return dp[u];
    long long r = 0;
    if (g[u].size()) for (int v : g[u]) r += dfs(v);
    else r = 1;
    return dp[u] = r;
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    string line;
    getline(cin, line);
    int t = stoi(line);
    getline(cin, line);
    for (int cs = 0; cs < t; cs++) {
        if (cs) cout << '\n';
        for (int i = 0; i < MAXN; i++) g[i].clear();
        vector<string> names;
        vector<long long> queries;
        int nodeIdx = -1, subNodeIdx = OFFSET;
        while (getline(cin, line)) {
            if (line.back() == ':') nodeIdx = stoi(line.substr(0, 2));
            else if (line.front() == ' ') {
                istringstream iss(line);
                string block;
                while (iss >> block) {
                    int p = block.find(':');
                    names.push_back(block.substr(0, p));
                    g[nodeIdx].push_back(subNodeIdx);
                    if (block.back() != '$') {
                        int v = stoi(block.substr(p + 1));
                        g[subNodeIdx].push_back(v);
                    }
                    subNodeIdx++;
                }
            } else {
                queries.push_back(stoll(line));
                while (getline(cin, line)) {
                    if (line.empty()) break;
                    queries.push_back(stoll(line));
                }
                break;
            }
        }
        memset(dp, -1, sizeof dp);
        dfs(0);
        for (long long q : queries) {
            int u = 0;
            vector<int> r;
            while (g[u].size()) {
                for (auto v : g[u]) {
                    if (q > dp[v]) q -= dp[v];
                    else {
                        u = v;
                        break;
                    }
                }
                if (u >= OFFSET) r.push_back(u);
            }
            for (int i = 0; i < r.size(); i++) {
                if (i) cout << '-';
                cout << names[r[i] - OFFSET];
            }
            cout << '\n';
        }
    }
    return 0;
}
```

## 总结

本题的核心技巧包括：

1. **图论建模**：将双关语的生成规则抽象为有向无环图，每个单词独立成节点，便于处理复用和结束标记。
2. **记忆化搜索**：利用 $\texttt{DAG}$ 的无环性质，通过 $\textit{dp}[u]$ 缓存从节点 $u$ 出发的短语总数，避免重复计算。
3. **路径定位算法**：通过前缀和思想（不断减去分支计数）快速定位第 $n$ 个路径，避免了显式枚举所有路径。
4. **输入解析技巧**：使用 `line.back()` 和 `line.front()` 判断行类型，利用 `istringstream` 分割 `word:node` 对，处理复杂的缩进格式。

这种方法的时间复杂度为 $O(V + E)$（其中 $V$ 为节点总数，$E$ 为边总数），空间复杂度为 $O(V + E)$，足以应对题目给定的数据范围。
