## 题目分析

### 问题描述

公园里有一条受欢迎的慢跑路径，路径上等间距地分布着若干广告牌（$\texttt{billboards}$），这些广告牌按路径顺序被赋予连续的整数编号（可能包含负数）。现在有一个客户想要在这些广告牌上投放广告，并希望确保每位慢跑者都能看到至少 $K$ 个广告。

每位慢跑者会选择路径上的一段区间进行跑步，他们会看到该区间内所有的广告牌（包括区间端点）。如果某位慢跑者路径上的广告牌数量少于 $K$，那么客户要求该慢跑者必须看到他路径上的所有广告牌上都投放了广告。

我们的目标是找出需要投放广告的最少广告牌数量，并输出这些广告牌的编号。

### 输入格式

- 第一行：测试用例的数量
- 每个测试用例包含：
  - 第一行：两个整数 $K$ 和 $N$（$1 \leq K, N \leq 1000$）
  - 接下来 $N$ 行：每行两个整数 $A_i$ 和 $B_i$，表示第 $i$ 位慢跑者看到的起始和结束广告牌编号

### 输出格式

- 对于每个测试用例：
  - 第一行：整数 $M$，表示需要的最少广告牌数量
  - 接下来 $M$ 行：按升序排列的广告牌编号
- 测试用例之间用空行分隔

## 解题思路

### 核心思想

这是一个**区间覆盖问题**的变种，我们可以采用**贪心算法**来解决。关键在于：

1. **区间处理**：对于每个慢跑者的路径 $[A_i, B_i]$，如果 $A_i > B_i$，需要交换两者使其成为有效区间
2. **排序策略**：将所有区间按照**右端点升序**排序（右端点相同时按左端点升序）
3. **贪心放置**：对于每个区间，从右往左放置广告，这样可以使广告牌被更多的后续区间共享

### 算法步骤

对于每个测试用例：

1. **读取输入**并规范化区间（确保 $start \leq end$）
2. **按右端点排序**所有区间
3. **遍历每个区间**：
   - 统计该区间内已放置的广告数量
   - 计算还需要放置的广告数量：
     - 如果区间长度 $\geq K$，需要补足到 $K$ 个广告
     - 如果区间长度 $< K$，需要覆盖整个区间
   - **从右往左**在空位置上放置广告，直到满足需求
4. **输出结果**：广告牌总数和按升序排列的广告牌编号

### 复杂度分析

- **时间复杂度**：$O(N \times L)$，其中 $N$ 是慢跑者数量，$L$ 是区间平均长度
- **空间复杂度**：$O(M)$，其中 $M$ 是选择的广告牌数量

由于 $N \leq 1000$，区间长度最大约 $20000$，这个复杂度在题目限制下是可接受的。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <set>

using namespace std;

// 定义慢跑者结构体，存储起始和结束广告牌编号
struct Jogger {
    int start, end;
};

// 比较函数：按右端点升序排序，右端点相同时按左端点升序
bool compareJogger(const Jogger& a, const Jogger& b) {
    if (a.end == b.end) return a.start < b.start;
    return a.end < b.end;
}

void solve() {
    int K, N;
    cin >> K >> N;
    
    vector<Jogger> joggers(N);
    for (int i = 0; i < N; i++) {
        int a, b;
        cin >> a >> b;
        // 确保区间有效（start <= end）
        if (a > b) swap(a, b);
        joggers[i] = {a, b};
    }
    
    // 按右端点排序
    sort(joggers.begin(), joggers.end(), compareJogger);
    
    // 使用集合存储已选择的广告牌位置
    set<int> advertisements;
    
    // 处理每个慢跑者的区间
    for (const auto& j : joggers) {
        int count = 0;
        // 统计当前区间内已有的广告数量
        for (int pos = j.start; pos <= j.end; pos++) {
            if (advertisements.find(pos) != advertisements.end()) {
                count++;
            }
        }
        
        // 计算还需要放置的广告数量
        int need = K - count;
        if (need > 0) {
            // 从右往左放置广告，最大化共享效果
            for (int pos = j.end; pos >= j.start && need > 0; pos--) {
                if (advertisements.find(pos) == advertisements.end()) {
                    advertisements.insert(pos);
                    need--;
                }
            }
        }
    }
    
    // 输出结果
    cout << advertisements.size() << endl;
    for (int pos : advertisements) {
        cout << pos << endl;
    }
}

int main() {
    int testCases;
    cin >> testCases;
    
    for (int t = 0; t < testCases; t++) {
        if (t > 0) cout << endl;  // 测试用例之间用空行分隔
        solve();
    }
    
    return 0;
}
```

## 代码说明

1. **数据结构**：
   - 使用 `Jogger` 结构体存储每个慢跑者的路径区间
   - 使用 `set<int>` 存储广告牌位置，自动排序且去重

2. **关键处理**：
   - `compareJogger` 函数确保区间按右端点排序
   - 从右往左放置广告的策略最大化广告牌的共享
   - 使用 `set` 的查找操作快速判断广告牌是否已被选择

3. **输出格式**：
   - 严格遵循题目要求的输出格式
   - 测试用例之间用空行分隔

该解法通过贪心策略有效地最小化了广告牌数量，同时满足了所有慢跑者的观看需求。
