## 题目分析

本题是一个结合了几何计算和物理浮力判断的综合题目。题目背景来源于科幻电影《$\texttt{Sphere}$》，描述了外星人释放的"配对球体"在有毒液体中的行为。

### 问题核心

我们需要解决两个主要问题：

1. **几何计算**：计算两个相交球体（配对球体）的总体积和总表面积
2. **物理判断**：根据阿基米德原理判断球体在液体中的浮沉状态

### 关键约束条件

- 两个球体的半径 $R_1$ 和 $R_2$ 满足 $0 < R_1, R_2 \leq 500$
- 球心距离 $d$ 满足 $\max(R_1, R_2) < d < (R_1 + R_2)$，确保两个球体相交但不包含
- 球体重量 $W < 10^{10}$ 克
- 液体比重 $0 < S < 10$

## 解题思路

### 1. 几何计算原理

对于两个相交的球体，我们需要计算：

#### 总体积计算
总体积 = 两个球体体积之和 - 相交部分的体积

- 单个球体体积公式：$V = \frac{4}{3}\pi R^3$
- 相交部分体积由两个球冠体积组成

#### 总表面积计算
总表面积 = 两个球体表面积之和 - 相交部分在两个球体上对应的球冠表面积

- 单个球体表面积公式：$A = 4\pi R^2$
- 相交部分的表面积是两个球冠的侧面积

### 2. 球冠参数计算

设两个球体半径分别为 $R$ 和 $r$，球心距离为 $d$。

#### 球冠高度计算
$$
h_1 = R - \frac{d^2 - r^2 + R^2}{2d}
$$
$$
h_2 = r - \frac{d^2 - R^2 + r^2}{2d}
$$

#### 球冠体积公式
$$
V_{\text{cap}} = \frac{\pi h^2 (3R - h)}{3}
$$

#### 球冠侧面积公式
$$
A_{\text{cap}} = 2\pi R h
$$

### 3. 浮力判断原理

根据阿基米德原理：
- 浮力 = 排开液体的重量 = 球体体积 × 液体比重
- 如果球体重量 $W \leq$ 浮力，则球体漂浮
- 如果球体重量 $W >$ 浮力，则球体沉没

### 4. 算法步骤

1. 读取输入数据组数 $N$
2. 对于每组数据：
   - 读取 $R_1$, $R_2$, $d$, $W$, $S$
   - 计算两个球冠的高度 $h_1$ 和 $h_2$
   - 计算相交部分的体积和表面积
   - 计算总体积和总表面积
   - 根据浮力原理判断浮沉状态
   - 输出结果（保留4位小数）

## 代码实现

```cpp
// Sphere

// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = 2 * acos(0.0);

int main() {
    int n;
    cin >> n;
    while (n--) {
        double r1, r2, d, w, s;
        cin >> r1 >> r2 >> d >> w >> s;

        // 计算球冠高度
        double h1 = r1 - (d * d - r2 * r2 + r1 * r1) / (2 * d);
        double h2 = r2 - (d * d - r1 * r1 + r2 * r2) / (2 * d);
        
        // 计算相交部分体积
        double capVol1 = (PI * h1 * h1 * (3 * r1 - h1)) / 3.0;
        double capVol2 = (PI * h2 * h2 * (3 * r2 - h2)) / 3.0;
        double intersectVol = capVol1 + capVol2;
        
        // 计算总体积
        double vol1 = (4.0 / 3.0) * PI * r1 * r1 * r1;
        double vol2 = (4.0 / 3.0) * PI * r2 * r2 * r2;
        double totalVol = vol1 + vol2 - intersectVol;

        // 计算表面积
        double capArea1 = 2 * PI * r1 * h1;
        double capArea2 = 2 * PI * r2 * h2;
        double totalArea = 4 * PI * (r1 * r1 + r2 * r2) - capArea1 - capArea2;

        cout << fixed << setprecision(4) << totalVol << " " << totalArea << endl;
        if (w <= totalVol * s) {
            cout << "The Paired-Sphere Floats." << endl;
        } else {
            cout << "The Paired-Sphere Sinks." << endl;
        }
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(N)$，其中 $N$ 是测试数据组数
- **空间复杂度**：$O(1)$，只使用了常数级别的额外空间

## 注意事项

1. 使用 `PI = 2 * acos(0.0)` 来精确计算 $\pi$ 值
2. 输出结果保留4位小数
3. 球冠高度公式的推导要准确，确保相交部分计算正确
4. 浮力判断时注意单位一致性（重量单位为克，体积单位为立方厘米）
