## 题目描述

计算分子生物学中的一个重要研究方向是处理基因序列。 当考虑两个序列的进化关系时， 如果它们差异不大， 则认为它们关系密切。 我们可以用树来表示这种关系， 将祖先序列置于后代序列之上。 这类树称为系统发育树。

系统发育学的任务之一是从给定序列推断树结构， 但这里我们简化问题： 提供树的结构——这是一棵 **完全二叉树** 。 给定树的 $n$ 个叶节点（ $n$ 总是 $2$ 的幂） 。 每个叶节点是一个氨基酸序列（ 使用单字母代码表示， 共 $20$ 种氨基酸） 。 所有序列长度均为 $l$ 。 你的任务是推导出 **最小成本** 下的共同祖先序列。

成本计算方式如下： 树的每个内部节点标记一个长度为 $l$ 的序列； 树的一条边的成本是该边两端序列在对应位置上不同的字符数量； 总成本是所有边成本之和。 所有序列的共同祖先序列位于树的根节点。 **最优共同祖先** 是总成本最小的共同祖先。

**输入**  
输入文件包含多个测试用例。 每个测试用例以两个整数 $n$ 和 $l$ 开始， 分别表示叶节点序列的数量和长度。 输入以 $n = l = 0$ 结束。 否则， $1 \leq n \leq 1024$ 且 $1 \leq l \leq 1000$ 。 随后是 $n$ 个长度为 $l$ 的氨基酸序列单词， 按从左到右的顺序表示完全二叉树的叶节点。

**输出**  
对于每个测试用例， 输出一行， 包含一个最优共同祖先序列和最小总成本。

## 题目分析

本题要求我们为给定的完全二叉树（ 叶节点是已知序列， 内部节点序列待确定） 寻找根节点的最优序列， 使得整棵树所有边的差异之和最小。 每条边的差异定义为两端节点序列在对应位置上不同字符的数量。

### 关键观察

1. **问题可分解**： 由于每条边的成本是逐位置独立计算的（ 比较对应位置的字符是否相同） ， 因此对于长度为 $l$ 的序列， 我们可以 **对每个位置独立求解** ， 然后将各个位置的成本相加。 这样问题就被简化为： 对于每个位置， 给定叶节点在该位置的字符（ 共 $n$ 个） ， 要为所有内部节点分配字符， 使得树中所有相邻节点字符不同的边的总数最小。

2. **完全二叉树结构**： 题目保证 $n$ 是 $2$ 的幂， 树是一棵完全二叉树。 叶节点按从左到右的顺序给出。 我们需要正确构建这棵树的结构。

3. **动态规划思路**： 对于单个位置的问题， 我们可以使用树形动态规划 解决。 对于树中的每个节点， 我们计算当该节点选择某个字符 $c$ 时， 其子树的最小成本。 然后自底向上（ 从叶节点到根节点） 递推， 最终根节点的最小成本就是该位置的最小总成本， 同时可以回溯得到该位置的最优字符。

### 动态规划状态定义

设 $dp[node][c]$ 表示当节点 $node$ 的字符为 $c$ （ $c$ 是 $0$ 到 $19$ 的整数， 对应 $20$ 种氨基酸） 时， 以 $node$ 为根的子树的最小总成本（ 即该子树内部所有边的差异之和） 。

### 状态转移方程

- 如果 $node$ 是叶节点， 那么它的字符是固定的（ 记为 $leafChar$ ） 。 因此：
  $$
  dp[node][c] = 
  \begin{cases}
  0 & \text{if } c \text{ 对应的字符等于 } leafChar \\
  \infty & \text{otherwise}
  \end{cases}
  $$
  其中 $\infty$ 用一个足够大的数表示（ 如 $INT\_MAX/2$ ） ， 避免后续加法溢出。

- 如果 $node$ 是内部节点， 设其左右子节点分别为 $left$ 和 $right$ 。 那么：
  $$
  dp[node][c] = \min_{c_l} (dp[left][c_l] + [c \neq c_l]) + \min_{c_r} (dp[right][c_r] + [c \neq c_r])
  $$
  其中 $[c \neq c_l]$ 是指示函数， 当 $c \neq c_l$ 时值为 $1$ ， 否则为 $0$ 。 即： 如果节点 $node$ 选择字符 $c$ ， 那么它需要分别从左右子树中选择最优的字符 $c_l$ 和 $c_r$ ， 使得子树成本加上与子节点相连的边的成本（ 如果字符不同则成本加 $1$ ） 最小。

### 计算过程

1. 首先将 $20$ 种氨基酸映射到 $0$ 到 $19$ 的索引， 方便处理。

2. 对于每个测试用例， 读取 $n$ 和 $l$ ， 以及 $n$ 个长度为 $l$ 的序列。

3. 对每个位置 $pos$ （ $0 \leq pos < l$ ） 独立处理：
   - 提取所有叶节点在该位置的字符， 构成一个长度为 $n$ 的数组。
   - 构建完全二叉树（ 注意叶节点顺序） ， 并进行树形动态规划。
   - 计算根节点（ 节点 $0$ ） 的所有 $dp[0][c]$ ， 取最小值得到该位置的最小成本 $minCost$ ， 同时记录对应的最优字符 $bestChar$ （ 如果有多个相同最小成本， 选择字典序最小的字符） 。
   - 将该位置的最优字符加入结果序列， 并将 $minCost$ 加入总成本。

4. 输出最终的最优共同祖先序列和总成本。

### 复杂度分析

- 对于每个位置， 我们需要遍历树的所有节点。 完全二叉树的节点总数是 $2n-1$ （ $n$ 个叶节点， $n-1$ 个内部节点） 。 对于每个节点， 我们需要枚举 $20$ 种可能的字符， 并对每个字符枚举子节点的 $20$ 种字符， 因此每个节点的计算量为 $O(20^2)$ 。 但由于 $20$ 是常数， 可以视为 $O(1)$ 。
- 因此每个位置的时间复杂度为 $O(n)$ ， 总时间复杂度为 $O(n \cdot l)$ 。
- 空间复杂度为 $O(n)$ （ 存储动态规划表需要 $O(n \cdot 20)$ ， 但 $20$ 是常数） 。

在题目限制下（ $n \leq 1024$ ， $l \leq 1000$ ） ， 该算法完全可行。

## 解题思路详细步骤

### 1. 氨基酸映射
建立从氨基酸单字母到索引 $0 \dots 19$ 的映射， 方便动态规划数组处理。

### 2. 构建完全二叉树
由于 $n$ 是 $2$ 的幂， 树的高度 $h = \log_2 n$ 。 我们可以使用数组表示树结构， 节点从 $0$ 开始编号：
- 对于节点 $i$ ， 其左子节点为 $2i+1$ ， 右子节点为 $2i+2$ 。
- 深度为 $h$ 的节点是叶节点， 深度小于 $h$ 的节点是内部节点。

叶节点按输入顺序从左到右排列。

### 3. 单个位置的动态规划实现
为了确保处理顺序正确（ 自底向上） ， 我们使用后序遍历。 可以用栈模拟递归， 避免递归深度过大。

对于每个位置：
- 初始化动态规划表， 叶节点根据实际字符设置成本为 $0$ 或 $\infty$ 。
- 后序遍历树， 对于内部节点， 根据上述状态转移方程计算 $dp[node][c]$ 。
- 遍历结束后， 根节点 $0$ 的最小 $dp[0][c]$ 就是该位置的最小成本， 对应的字符就是该位置的最优字符。

### 4. 整合所有位置
对每个位置重复上述动态规划过程， 累加成本， 并构建最优祖先序列。

## 代码实现

```cpp
// Phylogenetic Trees Inherited

#include <bits/stdc++.h>
using namespace std;

// 氨基酸到索引的映射表
const string aminoAcids = "ARNDCQEGHILKMFPSTWYV";
int aminoIndex[256];

// 初始化映射表
void initAminoIndex() {
    for (int i = 0; i < 20; ++i) aminoIndex[aminoAcids[i]] = i;
}

// 计算一个位置的最小成本和最优字符
pair<char, int> solvePosition(const vector<char>& leaves, int n) {
    // 计算树的高度
    int maxDepth = 0;
    int temp = n;
    while (temp > 1) {
        maxDepth++;
        temp >>= 1;
    }
    
    // 完全二叉树的节点总数
    int totalNodes = (1 << (maxDepth + 1)) - 1;
    vector<vector<int> > dp(totalNodes, vector<int>(20, INT_MAX / 2));
    
    // 叶节点索引顺序（从左到右）
    vector<int> leafIdx(n);
    for (int i = 0; i < n; ++i) leafIdx[i] = i;
    
    // 使用栈模拟后序遍历，避免递归
    int leafCounter = 0;
    stack<pair<int, int> > st;
    st.push(make_pair(0, 0)); // (node, depth)
    
    vector<pair<int, int> > traversalOrder;
    vector<int> parent(totalNodes, -1);
    vector<bool> processed(totalNodes, false);
    
    // 生成后序遍历的顺序
    while (!st.empty()) {
        int node = st.top().first;
        int depth = st.top().second;
        st.pop();
        
        traversalOrder.push_back(make_pair(node, depth));
        
        if (depth < maxDepth) {
            int left = node * 2 + 1;
            int right = node * 2 + 2;
            st.push(make_pair(right, depth + 1));
            st.push(make_pair(left, depth + 1));
            parent[left] = node;
            parent[right] = node;
        }
    }
    
    // 逆序处理（后序遍历）
    reverse(traversalOrder.begin(), traversalOrder.end());
    for (int i = 0; i < traversalOrder.size(); ++i) {
        int node = traversalOrder[i].first;
        int depth = traversalOrder[i].second;
        
        if (depth == maxDepth) {
            // 叶节点：字符固定
            for (int c = 0; c < 20; ++c) {
                dp[node][c] = (aminoAcids[c] == leaves[leafCounter]) ? 0 : INT_MAX / 2;
            }
            leafCounter++;
        } else {
            int left = node * 2 + 1;
            int right = node * 2 + 2;
            
            // 对于每个可能的字符c，计算dp[node][c]
            for (int c = 0; c < 20; ++c) {
                int leftBest = INT_MAX / 2;
                for (int cl = 0; cl < 20; ++cl) {
                    int cost = dp[left][cl] + (c != cl);
                    if (cost < leftBest) leftBest = cost;
                }
                
                int rightBest = INT_MAX / 2;
                for (int cr = 0; cr < 20; ++cr) {
                    int cost = dp[right][cr] + (c != cr);
                    if (cost < rightBest) rightBest = cost;
                }
                
                dp[node][c] = leftBest + rightBest;
            }
        }
    }
    
    // 根节点是0，选择最小成本的字符（字典序优先）
    int bestChar = 0;
    int minCost = dp[0][0];
    for (int c = 1; c < 20; ++c) {
        if (dp[0][c] < minCost || (dp[0][c] == minCost && aminoAcids[c] < aminoAcids[bestChar])) {
            minCost = dp[0][c];
            bestChar = c;
        }
    }
    
    return make_pair(aminoAcids[bestChar], minCost);
}

int main() {
    initAminoIndex();
    int n, l;
    while (cin >> n >> l && (n != 0 || l != 0)) {
        vector<string> leaves(n);
        for (int i = 0; i < n; ++i) cin >> leaves[i];
        
        string rootSeq(l, ' ');
        int totalCost = 0;
        
        // 对每个位置独立求解
        for (int pos = 0; pos < l; ++pos) {
            vector<char> leafChars(n);
            for (int i = 0; i < n; ++i) leafChars[i] = leaves[i][pos];
            pair<char, int> result = solvePosition(leafChars, n);
            rootSeq[pos] = result.first;
            totalCost += result.second;
        }
        
        cout << rootSeq << " " << totalCost << endl;
    }
    return 0;
}
```

## 总结

本题是一道典型的树形动态规划问题， 关键在于将原问题分解为每个位置独立的子问题， 然后利用完全二叉树的结构进行自底向上的动态规划 。 需要注意的细节包括：

1. 正确构建完全二叉树， 并按照输入顺序分配叶节点。
2. 使用后序遍历确保计算顺序正确。
3. 在多个字符成本相同时， 选择字典序最小的字符。
4. 使用足够大的数表示 $\infty$ ， 避免加法溢出。

该算法在时间和空间上都是高效的， 能够处理题目给定的最大规模数据。
