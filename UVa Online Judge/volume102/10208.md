## 题目描述

$\texttt{Macintosh}$ 先生是一位地主，他拥有的所有土地都是直角三角形，并且两条直角边的长度都是整数。他雇佣了一名员工来记录所有土地的信息，但报告只包含每块土地最长边（斜边）的平方值。也就是说，如果一块土地的三条边为 $a$ 、 $b$ 、 $c$ ，其中 $c$ 是斜边（最大边），那么报告中只记录 $c^2$ 的值。

现在 $\texttt{Macintosh}$ 先生怀疑这名员工是否诚实，他需要你根据报告中的数据判断这些值是否真的可能是某块直角三角形土地斜边的平方。

### 输入格式

输入包含若干行，每行是一个无符号整数 $N$ 或形如 $N!$ （ $N$ 的阶乘）的数，其中 $4 \le N \le 10000000$ 。每个数表示某块土地斜边的平方值。

### 输出格式

对于每行输入：

- 如果输入是 $N$ ，判断 $\sqrt{N}$ 是否可能是某块土地的最长边。如果是，输出 `He might be honest.` ，否则输出 `He is a liar.` 。
- 如果输入是 $N!$ ，除了进行上述判断外，如果 $N!$ 本身不是合法的斜边平方，还需要输出需要用哪些质数去除 $N!$ ，才能使其成为某个合法斜边的平方。如果这样的质数超过 $50$ 个，只输出最小的 $50$ 个。质数在同一行输出，用空格分隔。当然，如果 $N!$ 本身就是合法斜边的平方，则不需要输出质数。

每组输出之间用一个空行分隔。

### 样例输入

```
10
12
98
99
4!
5!
6!
120!
```

### 样例输出

```
He might be honest.

He is a liar.

He might be honest.

He is a liar.

He is a liar.
3

He is a liar.
3

He might be honest.

He is a liar.
7 23 31 67 71 79 83 103 107
```

## 题目分析

### 问题转化

题目本质上要求判断一个数 $M$ （可能是 $N$ 或 $N!$ ）是否可以表示为两个整数的平方和，即是否存在整数 $a$ 和 $b$ 使得：

$$
a^2 + b^2 = M
$$

这里 $M$ 是斜边的平方 $c^2$ ，注意 $c$ 本身不一定是整数（题目只要求两条直角边是整数）。

### 数论基础：费马平方和定理

一个经典定理（费马平方和定理）指出：

> 一个正整数 $M$ 可以表示为两个整数的平方和，当且仅当在 $M$ 的质因数分解中，所有形如 $4k+3$ 的质因子的指数都是偶数。

**证明概要**：
- 充分性：如果所有 $4k+3$ 质因子的指数都是偶数，那么 $M$ 可以写成 $2^e \times \prod p_i^{2e_i} \times \prod q_j^{2f_j}$ 的形式，其中 $p_i$ 是 $4k+1$ 质数， $q_j$ 是 $4k+3$ 质数。利用平方和恒等式 $(a^2+b^2)(c^2+d^2) = (ac+bd)^2 + (ad-bc)^2$ ，可以构造出平方和表示。
- 必要性：如果存在 $4k+3$ 质数 $q$ 使得 $q^{2k+1} \mid M$ ，假设 $M = x^2 + y^2$ ，考虑模 $q$ 可得矛盾。

### 算法设计

根据上述定理，我们只需要检查 $M$ 的质因数分解中所有 $4k+3$ 质因子的指数是否都是偶数。

#### 1. 对于普通整数 $N$

直接对 $N$ 进行质因数分解，检查每个 $4k+3$ 质因子的指数奇偶性。

#### 2. 对于阶乘 $N!$

需要计算 $N!$ 中每个 $4k+3$ 质数的指数。对于质数 $p$ ，它在 $N!$ 中的指数由勒让德公式给出：

$$
\text{exp}(p, N!) = \left\lfloor \frac{N}{p} \right\rfloor + \left\lfloor \frac{N}{p^2} \right\rfloor + \left\lfloor \frac{N}{p^3} \right\rfloor + \cdots
$$

我们只需计算这个指数的奇偶性。如果某个 $4k+3$ 质数 $p$ 在 $N!$ 中的指数是奇数，那么为了使其指数变为偶数（从而满足平方和条件），需要从 $N!$ 中除去一个 $p$ 。因此，所有指数为奇数的 $4k+3$ 质数就是我们需要输出的质数列表。

### 算法优化

1. **质数筛选**：使用线性筛法预处理所有不超过 $10^7$ 的质数，并单独记录所有 $4k+3$ 质数。
2. **指数奇偶性计算**：对于阶乘的情况，使用勒让德公式计算，但可以提前终止（当 $p^k > N$ 时）。
3. **输出限制**：只输出最小的 $50$ 个需要除去的质数。

### 时间复杂度

- 筛法预处理： $O(10^7)$ ，只需一次。
- 普通整数判断： $O(\sqrt{N} / \log N)$ ，最坏情况下需要检查所有不超过 $\sqrt{N}$ 的 $4k+3$ 质数。
- 阶乘判断：需要检查所有不超过 $N$ 的 $4k+3$ 质数，每个质数计算指数的时间为 $O(\log_p N)$ 。由于 $N \le 10^7$ ， $4k+3$ 质数大约有 $1.2 \times 10^6$ 个，但实际计算量较小，因为很多大质数的指数计算很快。

## 代码实现

```cpp
// Liar or Not Liar that is the ...
// UVa ID: 10208
// Verdict: Accepted
// Submission Date: 2025-12-16
// UVa Run Time: 0.500s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 位运算宏定义，用于质数筛的位标记
#define GET(x) (B[x >> 5] & (1 << (x & 0x1F)))
#define SET(x) (B[x >> 5] |= (1 << (x & 0x1F)))

const int MAXN = 7000000, MAXB = 10000010;

int B[MAXB >> 5];           // 位数组，用于筛法
int primes[MAXN], cnt = 0;  // 存储所有质数
vector<int> primes4k3;      // 只存储4k+3形式的质数

// 线性筛法
void sieve() {
    for (int i = 2; i < MAXB; i++) {
        if (!GET(i)) {
            primes[cnt++] = i;
            if (i % 4 == 3) primes4k3.push_back(i);  // 记录4k+3质数
        }
        for (int j = 0; j < cnt && i * primes[j] < MAXB; j++) {
            SET(i * primes[j]);
            if (i % primes[j] == 0) break;
        }
    }
}

// 判断质数p在n!中的指数是否为奇数
inline bool isExponentOdd(int n, int p) {
    int exp = 0;
    while (n) { 
        n /= p; 
        exp += n; 
    }
    return (exp & 1);
}

// 判断整数n是否可以表示为两个整数的平方和
inline bool isSquares(int n) {
    for (auto p : primes4k3) {
        int cnt = 0;
        while (n % p == 0) {
            n /= p;
            cnt++;
        }
        if (cnt & 1) return false;  // 4k+3质因子指数为奇数
    }
    return true;
}

int main() {
    cin.tie(0); 
    cout.tie(0); 
    ios::sync_with_stdio(false);
    
    sieve();  // 预处理质数表
    
    string line;
    bool firstCase = true;
    
    while (cin >> line) {
        if (!firstCase) cout << '\n';
        firstCase = false;
        
        bool isFactorial = (line.back() == '!');
        int N;
        if (isFactorial) 
            N = stoi(line.substr(0, line.size() - 1));
        else 
            N = stoi(line);
        
        if (!isFactorial) {
            // 普通整数情况
            cout << (isSquares(N) ? "He might be honest.\n" : "He is a liar.\n");
        } else {
            // 阶乘情况
            vector<int> neededPrimes;
            for (auto p : primes4k3) {
                if (p > N) break;
                // 如果p在N!中的指数为奇数，则需要除去
                if (isExponentOdd(N, p) && neededPrimes.size() < 50) 
                    neededPrimes.push_back(p);
                if (neededPrimes.size() >= 50) break;  // 最多输出50个
            }
            
            if (neededPrimes.empty()) {
                cout << "He might be honest.\n";
            } else {
                cout << "He is a liar.\n";
                for (size_t i = 0; i < neededPrimes.size(); i++) {
                    if (i > 0) cout << ' ';
                    cout << neededPrimes[i];
                }
                cout << '\n';
            }
        }
    }
    return 0;
}
```

## 总结

本题的关键在于理解费马平方和定理，将一个几何问题转化为数论问题。对于普通整数，直接检查质因数分解；对于阶乘，利用勒让德公式计算质数指数。算法的时间复杂度可以接受，主要优化在于只关注 $4k+3$ 质数，并使用位运算加速筛法。

通过本题，我们不仅复习了经典的数论定理，还学习了如何高效处理阶乘的质因数分解问题，这对解决其他数论问题也有很好的借鉴意义。
