## 题目大意

我们需要为给定的进制 $B$（ $2 < B < 500$ ）和除数 $D$（ $2 \le D < 5000$ ）**自动发现**整除性测试条件。  
题目给出了三种主要的整除性判定规则（按顺序尝试）：

1. **$\texttt{Rightmost k}$** ：取最右边的 $k$ 位（视为一个 $B$ 进制数），若其能被 $D$ 整除，则原数也能被 $D$ 整除。
2. **$\texttt{Add all t}$** ：从右开始每 $t$ 位为一组（视为一个数字），将所有组的数字相加，若和能被 $D$ 整除，则原数也能被 $D$ 整除。
3. **$\texttt{Alternate m change sign}$** ：从右开始每 $m$ 位为一组，交替进行加和减（第一组加，第二组减，第三组加，依此类推），若结果能被 $D$ 整除，则原数也能被 $D$ 整除。

如果以上三种规则中的任意一种在 $k, t, m \le 1000$ 范围内成立，就输出对应的条件；如果都不成立，则输出 `condition not found.`。  
输出时，**严格按照规则 $1$、规则 $2$、规则 $3$ 的顺序**尝试，只要所有可行规则。

## 题目分析与解题思路

### 数学原理分析

我们需要从**模运算**的角度理解这些规则。设原数为 $N$（在 $B$ 进制下表示），我们要判断 $N \bmod D = 0$ 是否成立。

#### 规则1：$\texttt{Rightmost k}$
取最后 $k$ 位数字相当于计算 $N \bmod B^k$。  
如果 $B^k \bmod D = 0$，那么 $N \bmod B^k$ 能被 $D$ 整除就等价于 $N \bmod D = 0$。  
因为 $B^k$ 是 $D$ 的倍数时，最后 $k$ 位构成的数模 $D$ 的结果就是 $N \bmod D$。  
因此，我们只需要寻找最小的 $k$（ $1 \le k \le 1000$ ），使得 $B^k \bmod D = 0$。

#### 规则2：$\texttt{Add all t}$
从右开始每 $t$ 位为一组，相当于把 $N$ 写成以 $B^t$ 为基数的形式：  
$N = a_0 + a_1 \cdot B^t + a_2 \cdot (B^t)^2 + \dots$  
其中 $a_i$ 是每 $t$ 位构成的数字。  
如果 $B^t \bmod D = 1$，那么 $N \bmod D = (a_0 + a_1 + a_2 + \dots) \bmod D$。  
因此，我们只需要寻找最小的 $t$（ $1 \le t \le 1000$ ），使得 $B^t \bmod D = 1$。

#### 规则3：$\texttt{Alternate m change sign}$
类似规则 $2$，但此时我们希望权重交替为 $+1$ 和 $-1$（模 $D$ 下 $-1$ 等价于 $D-1$）。  
即需要 $B^m \bmod D = -1 \ (\text{mod } D) = D-1$。  
此时 $N = a_0 + a_1 \cdot B^m + a_2 \cdot (B^m)^2 + \dots$，  
因为 $B^m \equiv -1$，所以 $B^{2m} \equiv 1$，权重会交替出现 $+1, -1, +1, -1, \dots$。  
因此，我们只需要寻找最小的 $m$（ $1 \le m \le 1000$ ），使得 $B^m \bmod D = D-1$。

### 算法步骤

对于每一组 $(B, D)$：

1. 按顺序尝试三种规则，每种规则从 $k/t/m = 1$ 枚举到 $1000$。
2. 使用**快速幂取模**计算 $B^k \bmod D$，检查是否满足对应条件。
3. 一旦找到满足条件的 $k$、 $t$ 或 $m$，就输出对应的字符串。
4. 如果三种规则都不满足，输出 `condition not found.`。
5. 每组输出之间输出一个空行（第一组前不输出空行）。

### 复杂度分析

- 每组数据最多尝试 $3 \times 1000 = 3000$ 次快速幂。
- 快速幂每次运算 $O(\log k)$， $k \le 1000$，因此单次幂运算约 $O(\log 1000) \approx 10$ 次乘法。
- 总计算量 $O(N \times 3000 \times \log 1000)$，在 $N \le 2000$ 时完全可行。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 快速幂取模
long long modPow(long long base, long long exp, long long mod) {
    long long r = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) r = (r * base) % mod;
        base = (base * base) % mod;
        exp >>= 1;
    }
    return r;
}

int main() {
    int N; cin >> N;
    bool firstCase = true;
    for (int caseIdx = 0; caseIdx < N; caseIdx++) {
        if (!firstCase) cout << endl;
        firstCase = false;
        long long B, D; cin >> B >> D;
        bool found = false;
        // 规则1: Rightmost k
        for (int k = 1; k <= 1000; k++) {
            if (modPow(B, k, D) == 0) {
                cout << "Rightmost " << k << endl;
                found = true;
                break;
            }
        }
        if (found) continue;
        // 规则2: Add all t
        for (int t = 1; t <= 1000; t++) {
            if (modPow(B, t, D) == 1) {
                cout << "Add all " << t << endl;
                found = true;
                break;
            }
        }
        if (found) continue;
        // 规则3: Alternate m change sign
        for (int m = 1; m <= 1000; m++) {
            if (modPow(B, m, D) == D - 1) {
                cout << "Alternate " << m << " change sign" << endl;
                found = true;
                break;
            }
        }
        if (found) continue;
        // 无规则
        cout << "condition not found." << endl;
    }
    return 0;
}
```
