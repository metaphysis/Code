## 题目描述

你站在一个无限大的树林的中心（坐标原点 $(0,0)$），树林中的树种植在所有的整数坐标点 $(x,y)$ 上，其中 $|x| \leq a$，$|y| \leq b$，且 $(x,y) \neq (0,0)$。

从原点观察一棵树，如果从原点到该树的连线上没有其他树（即没有其他整数坐标点在这条线段上），则该树是可见的。

要求计算可见树的数量 $K$ 与总树的数量 $N$ 的比值 $\frac{K}{N}$，并输出保留 $7$ 位小数的结果。

**输入**  
每组数据包含两个整数 $a$ 和 $b$（$1 \leq a \leq 2000$，$1 \leq b \leq 2 \times 10^6$），输入以 `0 0` 结束。

**输出**  
对每组数据输出 $\frac{K}{N}$，保留 $7$ 位小数，允许误差小于 $2 \times 10^{-7}$。

---

## 题目分析

### 1. 总树的数量 $N$

总树的数量为：

$$
N = (2a + 1) \times (2b + 1) - 1
$$

其中 $(2a + 1)$ 是 $x$ 坐标的取值范围（$-a$ 到 $a$），$(2b + 1)$ 是 $y$ 坐标的取值范围（$-b$ 到 $b$），减去原点 $(0,0)$。

### 2. 可见树的条件

从原点 $(0,0)$ 到树 $(x,y)$ 的连线上没有其他整数坐标点，等价于 $\gcd(|x|, |y|) = 1$。  
如果 $\gcd(|x|, |y|) > 1$，则在这条线上存在更靠近原点的整数坐标点，会挡住视线。

### 3. 对称性简化

由于坐标系的对称性，我们可以只计算第一象限（包括坐标轴正半轴但不包括原点）的可见树数量，然后乘以 $4$。

- **坐标轴上的可见树**：  
  - 正 $x$ 轴：$(1,0)$ 可见（$\gcd(1,0)=1$）  
  - 正 $y$ 轴：$(0,1)$ 可见  
  - 负 $x$ 轴：$(-1,0)$ 可见  
  - 负 $y$ 轴：$(0,-1)$ 可见  
  因此，坐标轴上共有 $4$ 棵可见树。

- **第一象限内部**（$x \geq 1, y \geq 1$）：  
  可见树的数量为：

  $$
  Q = \sum_{x=1}^{a} \sum_{y=1}^{b} [\gcd(x,y) = 1]
  $$

  其中 $[\gcd(x,y) = 1]$ 是指示函数，当 $\gcd(x,y) = 1$ 时为 $1$，否则为 $0$。

### 4. 计算 $Q$ 的方法

对于每个 $x$，我们需要计算在 $1 \leq y \leq b$ 中与 $x$ 互质的 $y$ 的数量。  
利用 $\texttt{Möbius}$ 函数的性质：

$$
\sum_{y=1}^{b} [\gcd(x,y) = 1] = \sum_{d|x} \mu(d) \left\lfloor \frac{b}{d} \right\rfloor
$$

其中 $\mu(n)$ 是 $\texttt{Möbius}$ 函数。

### 5. 最终公式

- 第一象限内部可见树数量：$Q$
- 四个象限内部可见树总数：$4Q$
- 加上坐标轴上的 $4$ 棵：$K = 4Q + 4$
- 总树数量：$N = (2a+1)(2b+1) - 1$
- 所求比值：$\frac{K}{N}$

---

## 算法步骤

1. 预计算 $\texttt{Möbius}$ 函数 $\mu(n)$ 到 $n = 2000$（因为 $a \leq 2000$）。
2. 对每组输入 $(a,b)$：
   - 计算 $Q = \sum_{x=1}^{a} \sum_{d|x} \mu(d) \lfloor b/d \rfloor$
   - 计算 $K = 4Q + 4$
   - 计算 $N = (2a+1)(2b+1) - 1$
   - 输出 $\frac{K}{N}$ 保留 $7$ 位小数

---

## 复杂度分析

- 预计算 $\texttt{Möbius}$ 函数：$O(a_{\max} \log \log a_{\max})$
- 每组数据：$O(a \sqrt{a})$（枚举 $x$ 的约数）
- 在题目限制下可行

## 代码实现

```cpp
// Trees in a Wood
// UVa ID: 10214

// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

const int MAX_A = 2000; // a 的最大值

vector<int> mobius; // Möbius 函数值
vector<int> primes; // 素数表
vector<bool> isPrime; // 标记是否为素数

// 筛法计算 Möbius 函数
void sieveMobius(int n) {
    mobius.resize(n + 1, 1);
    isPrime.resize(n + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            primes.push_back(i);
            mobius[i] = -1;
        }
        for (int p : primes) {
            if (i * p > n) break;
            isPrime[i * p] = false;
            if (i % p == 0) {
                mobius[i * p] = 0;
                break;
            } else {
                mobius[i * p] = -mobius[i];
            }
        }
    }
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    sieveMobius(MAX_A); // 预计算 Möbius 函数
    int a, b;
    while (cin >> a >> b) {
        if (a == 0 && b == 0) break;
        long long visibleCount = 0;
        // 计算第一象限内部可见树数量
        for (int x = 1; x <= a; x++) {
            long long countY = 0;
            // 枚举 x 的所有约数 d
            for (int d = 1; d * d <= x; d++) {
                if (x % d == 0) {
                    countY += mobius[d] * (b / d);
                    int d2 = x / d;
                    if (d2 != d) countY += mobius[d2] * (b / d2);
                }
            }
            visibleCount += countY;
        }
        // 四个象限内部可见树数量乘以 4，加上坐标轴上的 4 棵
        visibleCount = visibleCount * 4 + 4;
        // 计算总树数量
        long long totalTrees = (long long)(2 * a + 1) * (2 * b + 1) - 1;
        double ratio = (double)visibleCount / totalTrees;
        cout << fixed << setprecision(7) << ratio << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于利用 $\texttt{Möbius}$ 函数快速计算互质对数，并利用对称性减少计算量。  
通过预计算 $\texttt{Möbius}$ 函数，我们可以在 $O(a \sqrt{a})$ 的时间内完成每组数据的计算，满足题目要求。
