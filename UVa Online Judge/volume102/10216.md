## 题目描述

在孟加拉国，三所私立大学计划搬迁到 $\texttt{Savar}$ 地区的一片广阔空地上。这片空地非常大，三所大学的校园可以被视为三个点 $A, B, C$ 。

三所大学决定建造一个共同的咖啡店，但每个人都希望咖啡店建在自己的校园里。最终他们决定将咖啡店建在到三所大学总距离最小的位置 $P$ 。我们需要求出这个最小总距离 $PA + PB + PC$ 。

此外，三所大学分别提议将咖啡店建在三角形的内心 $I$ 、重心 $G$ 和外心 $O$ 。因此还需要输出：

- $AI + BI + CI$
- $AG + BG + CG$
- $AO + BO + CO$

### 输入格式

第一行一个整数 $S$（ $0 < S \leq 100$ ），表示测试数据组数。

接下来 $S$ 行，每行三个整数 $a, b, c$ ，分别表示三角形三边长度：
- $a$ 表示边 $BC$ 的长度
- $b$ 表示边 $CA$ 的长度
- $c$ 表示边 $AB$ 的长度

数据范围：$0 < a, b, c \leq 10000$ 。

### 输出格式

对于每组数据，输出四个浮点数 $DM, DI, DG, DO$ ，保留三位小数：
- $DM = PA + PB + PC$ （费马点最小距离和）
- $DI = AI + BI + CI$ （内心到顶点距离和）
- $DG = AG + BG + CG$ （重心到顶点距离和）
- $DO = AO + BO + CO$ （外心到顶点距离和）

若某个点不存在（三点共线时的外心），输出 `-1.000` 。

### 样例输入

```
2
3 3 3
4 4 4
```

### 样例输出

```
5.196 5.196 5.196 5.196
6.928 6.928 6.928 6.928
```

## 题目分析

本题的核心是计算三角形的几个特殊点（费马点、内心、重心、外心）到三个顶点的距离之和。

### 三角形存在的判断

给定三边 $a, b, c$ ，首先需要判断它们是否能构成一个非退化的三角形。设 $x \leq y \leq z$ 为排序后的三边长度，则：

- **构成三角形**：$x + y > z$ （严格大于）
- **三点共线（退化三角形）**：$x + y = z$ （允许浮点误差）

### 费马点 ($\texttt{Fermat Point}$)

费马点是三角形内到三个顶点距离之和最小的点。其性质如下：

- 若三角形的所有内角均小于 $120^\circ$ ，则费马点 $P$ 是三角形内一点，使得 $P$ 对三边的张角均为 $120^\circ$ 。此时最小距离和为：
  
  $$
  DM = \sqrt{ \frac{1}{2} \left( a^2 + b^2 + c^2 + 4\sqrt{3}\Delta \right) }
  $$
  
  其中 $\Delta$ 为三角形面积。

- 若三角形有一个内角 $\theta \geq 120^\circ$ ，则费马点位于该钝角的顶点，最小距离和等于该角两邻边的长度之和。

**判断方法**：利用余弦定理计算各角的余弦值。例如角 $A$ 的余弦值为：

$$
\cos A = \frac{b^2 + c^2 - a^2}{2bc}
$$

若 $\cos A \leq -0.5$ （即 $A \geq 120^\circ$ ），则 $DM = b + c$ 。

### 内心 ($\texttt{Incenter}$)

内心是三角形三条角平分线的交点，也是内切圆的圆心。内心到顶点 $A$ 的距离公式为：

$$
AI = \frac{2\sqrt{bc}}{a+b+c} \cdot \sqrt{s(s-a)}
$$

其中 $s = \frac{a+b+c}{2}$ 为半周长。

类似可得 $BI$ 和 $CI$ 。于是：

$$
DI = AI + BI + CI
$$

**退化情况**：根据 AC 代码，三点共线时内心距离和等于费马点距离和（即最长边长度）。

### 重心 ($\texttt{Centroid}$)

重心是三角形三条中线的交点。顶点 $A$ 到重心的距离等于中线 $m_a$ 的 $\frac{2}{3}$ ，其中中线公式为：

$$
m_a = \frac{1}{2}\sqrt{2b^2 + 2c^2 - a^2}
$$

因此：

$$
AG + BG + CG = \frac{2}{3}(m_a + m_b + m_c)
$$

**退化情况**：三点共线时重心仍然存在，上述公式仍然有效。

### 外心 ($\texttt{Circumcenter}$)

外心是三角形三边垂直平分线的交点，也是外接圆的圆心。外接圆半径公式为：

$$
R = \frac{abc}{4\Delta}
$$

外心到三个顶点的距离均等于外接圆半径 $R$ ，因此：

$$
DO = 3R = \frac{3abc}{4\Delta}
$$

**退化情况**：三点共线时没有外接圆，外心不存在，输出 `-1.000` 。

## 解题思路

### 步骤 1：预处理与退化判断

对每组数据：

1. 读入三边 $a, b, c$
2. 将三边排序，得到 $x \leq y \leq z$
3. 判断是否退化：`fabs(x + y - z) < 1e-9` （考虑浮点精度）

### 步骤 2：退化情况处理

若三点共线：

- $DM = z$ （最长边长度）
- $DI = DM$ （内心距离和等于费马点距离和）
- $DG = \frac{2}{3}(m_a + m_b + m_c)$ 计算重心距离和
- $DO = -1.000$

直接输出结果。

### 步骤 3：正常三角形处理

若构成三角形：

1. 计算半周长 $s = \frac{a+b+c}{2}$
2. 使用海伦公式计算面积 $\Delta = \sqrt{s(s-a)(s-b)(s-c)}$
3. 计算费马点距离 $DM$ ：
   - 利用余弦定理计算三个角的余弦值
   - 若有角 $\geq 120^\circ$ ，$DM$ 等于该角两邻边之和
   - 否则使用公式 $\sqrt{ \frac12 (a^2+b^2+c^2 + 4\sqrt{3}\Delta) }$
4. 计算内心距离和 $DI$ ：使用 $AI = \frac{2\sqrt{bc}\sqrt{s(s-a)}}{a+b+c}$ 等
5. 计算重心距离和 $DG$ ：使用中线公式
6. 计算外心距离和 $DO = \frac{3abc}{4\Delta}$

### 步骤 4：输出

所有结果保留三位小数，每组数据输出一行。

## 复杂度分析

- 每组数据仅进行常数次算术运算和开方操作
- 时间复杂度：$O(S)$
- 空间复杂度：$O(1)$

## 注意事项

1. **浮点精度**：判断角是否 $\geq 120^\circ$ 时，使用 `cosA <= -0.5` ，考虑浮点误差也可写为 `cosA <= -0.5 + 1e-9`

2. **退化判断**：使用 `fabs(x + y - z) < 1e-9` 而非严格相等

3. **输出格式**：当外心不存在时输出 `-1.000` ，注意负号和小数点后三位

#include <bits/stdc++.h>
using namespace std;

// 计算三角形面积（海伦公式）
double area(double a, double b, double c) {
    double s = (a + b + c) / 2.0;
    return sqrt(s * (s - a) * (s - b) * (s - c));
}

// 计算费马点最小距离和
double fermatDistance(double a, double b, double c, double delta) {
    double cosA = (b*b + c*c - a*a) / (2*b*c);
    double cosB = (a*a + c*c - b*b) / (2*a*c);
    double cosC = (a*a + b*b - c*c) / (2*a*b);
    
    // 若某角 >= 120度，费马点在该角顶点
    if (cosA <= -0.5) return b + c;
    if (cosB <= -0.5) return a + c;
    if (cosC <= -0.5) return a + b;
    
    // 所有角 < 120度，使用公式
    return sqrt(0.5 * (a*a + b*b + c*c + 4.0 * sqrt(3.0) * delta));
}

// 计算内心到三顶点距离和
double incenterSum(double a, double b, double c, double delta) {
    double s = (a + b + c) / 2.0;
    double AI = 2.0 * sqrt(b*c) * sqrt(s*(s-a)) / (a + b + c);
    double BI = 2.0 * sqrt(a*c) * sqrt(s*(s-b)) / (a + b + c);
    double CI = 2.0 * sqrt(a*b) * sqrt(s*(s-c)) / (a + b + c);
    return AI + BI + CI;
}

// 计算重心到三顶点距离和
double centroidSum(double a, double b, double c) {
    double ma = 0.5 * sqrt(2*b*b + 2*c*c - a*a);
    double mb = 0.5 * sqrt(2*a*a + 2*c*c - b*b);
    double mc = 0.5 * sqrt(2*a*a + 2*b*b - c*c);
    return (2.0/3.0) * (ma + mb + mc);
}

// 计算外心到三顶点距离和
double circumcenterSum(double a, double b, double c, double delta) {
    double R = (a*b*c) / (4.0 * delta);
    return 3.0 * R;
}

int main() {
    int S;
    scanf("%d", &S);
    
    while (S--) {
        double a, b, c;
        scanf("%lf %lf %lf", &a, &b, &c);
        
        // 排序便于判断退化情况
        double sides[3] = {a, b, c};
        sort(sides, sides + 3);
        double x = sides[0], y = sides[1], z = sides[2];
        
        bool degenerate = (fabs(x + y - z) < 1e-9);
        
        if (degenerate) {
            // 三点共线：费马点距离 = 最长边，内心距离 = 费马点距离，外心不存在
            double DM = z;
            double DG = centroidSum(a, b, c);
            printf("%.3f %.3f %.3f -1.000\n", DM, DM, DG);
            continue;
        }
        
        // 正常三角形
        double delta = area(a, b, c);
        double DM = fermatDistance(a, b, c, delta);
        double DI = incenterSum(a, b, c, delta);
        double DG = centroidSum(a, b, c);
        double DO = circumcenterSum(a, b, c, delta);
        
        printf("%.3f %.3f %.3f %.3f\n", DM, DI, DG, DO);
    }
    
    return 0;
}
