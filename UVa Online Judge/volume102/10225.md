## 题目分析

本题要求解离散对数问题：给定一个素数 $P$，底数 $B$ 和目标值 $N$，求最小的非负整数 $L$，使得：

$$B^L \equiv N \pmod{P}$$

如果不存在这样的 $L$，则输出 `"no solution"`。

### 数学背景

由于 $P$ 是素数，根据费马小定理：

$$B^{P-1} \equiv 1 \pmod{P}$$

这意味着 $B^L$ 在模 $P$ 下的值是周期性的，周期为 $P-1$ 的某个因子。如果 $B$ 是模 $P$ 的原根，则周期恰好为 $P-1$；否则周期是 $P-1$ 的真因子。

### 算法选择

直接枚举 $L$ 从 $0$ 到 $P-1$ 的时间复杂度为 $O(P)$，对于 $P$ 最大可达 $2^{31}$ 的情况来说不可行。因此我们需要更高效的算法。

**大步小步算法**（$\texttt{Baby-step Giant-step}$）是一种解决离散对数问题的有效方法，时间复杂度为 $O(\sqrt{P} \log \sqrt{P})$，适用于本题的数据范围。

### 算法步骤

1. **初始化**：设 $m = \lceil \sqrt{P-1} \rceil$
2. **小步**（$\texttt{Baby-step}$）：预计算并存储 $(B^j, j)$ 对于 $j = 0, 1, \dots, m-1$
3. **大步**（$\texttt{Giant-step}$）：计算 $B^{-m} \mod P$，然后对于 $i = 0$ 到 $m-1$，检查 $N \cdot (B^{-m})^i$ 是否在预计算的表中
4. **结果计算**：如果找到匹配项，则 $L = i \cdot m + j$；否则无解

### 边界情况

- 当 $N = 1$ 时，$L = 0$ 是一个解（因为 $B^0 = 1$）
- 由于 $P$ 是素数且 $2 \leq B < P$，$\gcd(B, P) = 1$ 恒成立
- 可能存在无解的情况，即 $N$ 不在由 $B$ 生成的循环子群中

```cpp
#include <iostream>
#include <cmath>
#include <unordered_map>
using namespace std;

typedef long long ll;

// 快速幂取模 (base^exponent mod modulus)
ll fastPowMod(ll base, ll exponent, ll modulus) {
    ll result = 1;
    base %= modulus;
    while (exponent > 0) {
        if (exponent & 1) {
            result = (result * base) % modulus;
        }
        base = (base * base) % modulus;
        exponent >>= 1;
    }
    return result;
}

// 使用大步小步算法求解离散对数
ll solveDiscreteLog(ll prime, ll base, ll target) {
    // 特殊情况：目标值为 1 时，对数为 0
    if (target == 1) {
        return 0;
    }
    
    // 计算步长 m = ceil(sqrt(P-1))
    ll stepSize = ceil(sqrt(prime - 1));
    unordered_map<ll, ll> valueToIndex;
    
    // 小步：预计算 base^j 对于 j = 0 到 m-1
    ll currentValue = 1;
    for (ll j = 0; j < stepSize; j++) {
        if (valueToIndex.find(currentValue) == valueToIndex.end()) {
            valueToIndex[currentValue] = j;
        }
        currentValue = (currentValue * base) % prime;
    }
    
    // 计算 base^{-m} mod prime
    ll inverseStep = fastPowMod(base, prime - 1 - stepSize, prime);
    currentValue = target;
    
    // 大步：检查 target * (base^{-m})^i 是否在预计算的表中
    for (ll i = 0; i < stepSize; i++) {
        if (valueToIndex.find(currentValue) != valueToIndex.end()) {
            return i * stepSize + valueToIndex[currentValue];
        }
        currentValue = (currentValue * inverseStep) % prime;
    }
    
    return -1; // 无解
}

int main() {
    ll prime, base, target;
    while (cin >> prime >> base >> target) {
        ll result = solveDiscreteLog(prime, base, target);
        if (result == -1) {
            cout << "no solution" << endl;
        } else {
            cout << result << endl;
        }
    }
    return 0;
}
```

## 代码说明

1. **快速幂取模**：`fastPowMod` 函数使用快速幂算法高效计算模幂，避免直接计算大指数
2. **大步小步算法**：`solveDiscreteLog` 函数实现了完整的算法流程
   - 小步阶段预计算所有可能的 $B^j$ 值
   - 大步阶段通过乘以 $B^{-m}$ 来"跳跃"检查
3. **逆元计算**：利用费马小定理 $B^{-m} \equiv B^{P-1-m} \pmod{P}$ 计算逆元
4. **哈希表优化**：使用 `unordered_map` 实现 $O(1)$ 的查找操作

该算法能够高效处理 $P$ 最大到 $2^{31}$ 的情况，是解决此类离散对数问题的标准方法。
