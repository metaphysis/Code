[A Star not a Tree?](https://blog.csdn.net/metaphysis/article/details/153401290)

## 题目描述

$\texttt{Luke}$ 要将他的 $N$ 台计算机通过一个集线器（$\texttt{hub}$）连接。计算机位置固定，集线器可以放在平面任意位置。每台计算机到集线器使用一条电缆（直线距离）。求**所有电缆总长度最小值**，结果四舍五入到最近整数毫米。

### 输入格式
- 第一行：测试用例数 $T$，后跟一个空行
- 每个测试用例：第一行整数 $N (≤ 100)$，接下来 $N$ 行每行两个整数 $(x, y)，0 ≤ x, y ≤ 10000$
- 测试用例间有一个空行

### 输出格式
- 每个测试用例输出一行：最小总长度（四舍五入）
- 测试用例间输出一个空行

### 样例输入
```
1

4
0 0
0 10000
10000 10000
10000 0
```

### 样例输出
```
28284
```

## 问题分析

这是一个经典的**几何中位数**（$\texttt{Geometric Median}$）问题，也称为**费马-韦伯问题**（$\texttt{Fermat-Weber Problem}$）：

> 给定平面上 $N$ 个点，求一点到所有点的欧氏距离之和最小。

设集线器位置为 $H = (h_x, h_y)$，目标函数：

$$
f(h_x, h_y) = \sum_{i=1}^{N} \sqrt{(h_x - x_i)^2 + (h_y - y_i)^2}
$$

该函数是**严格凸函数**（对于不共线的点），因此有唯一最小值。

与其他中心点（如质心、中位数）不同，几何中位数没有封闭解析解，需用数值方法求解。

---

## 解法一：嵌套三分搜索（$\texttt{Ternary Search in 2D}$）

### 原理

三分搜索适用于**单峰（凸）函数**。虽然 \( f \) 是二元函数，但可以通过**嵌套**方式扩展：

- 固定 $h_y$，则 $f$ 关于 $h_x$ 是凸函数 → 可以在 $x$ 方向三分求最优
- 外层对 $h_y$ 进行三分搜索，每次评估当前 $h_y$ 下的最优总距离（通过内层三分）

这样形成**三分套三分**。

### 可行域

计算中所有点坐标在 $[0, 10000]$ 内，但最优集线器位置可能略超出此范围（例如，当所有点位于一角时，最优位置在点集内部，不会超出太多）。为了安全，搜索范围可以取 $[-1000, 11000]$ 或直接使用 $[0, 10000]$ 在实践中通常足够（也可动态取 $min_x - max_x$ 并稍扩展）。

### 算法步骤

1. 外层搜索：对 $h_y$ 在 $[y_min, y_max]$ 范围进行三分
2. 内层搜索：固定 $h_y$，对 $h_x$ 在 $[x_min, x_max]$ 范围进行三分，返回该 $h_y$ 下的最小总距离
3. 外层根据内层返回值决定舍弃哪一侧
4. 迭代足够多次（如 $60$ 次），得到高精度结果
5. 最后四舍五入

### 复杂度

- 每次内层三分：$O(N \log M$
- 外层迭代次数：$O(\log M)$
- 总复杂度：$O(N \log^2 M)$，$M =$ 坐标范围
- $N ≤ 100$，完全可行

### 代码实现

```cpp
// A Star not a Tree?
// UVa ID: 10228
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point { double x, y; };

double dist(double x1, double y1, double x2, double y2) {
    return hypot(x1 - x2, y1 - y2);
}

double total(double hx, double hy, const vector<Point>& pts) {
    double sum = 0;
    for (auto& p : pts) sum += dist(hx, hy, p.x, p.y);
    return sum;
}

double searchX(double hy, const vector<Point>& pts) {
    double lo = 0, hi = 10000;
    for (int it = 0; it < 60; ++it) {
        double m1 = lo + (hi - lo) / 3;
        double m2 = hi - (hi - lo) / 3;
        if (total(m1, hy, pts) < total(m2, hy, pts)) hi = m2;
        else lo = m1;
    }
    return total((lo + hi) / 2, hy, pts);
}

double searchY(const vector<Point>& pts) {
    double lo = 0, hi = 10000;
    for (int it = 0; it < 60; ++it) {
        double m1 = lo + (hi - lo) / 3;
        double m2 = hi - (hi - lo) / 3;
        if (searchX(m1, pts) < searchX(m2, pts)) hi = m2;
        else lo = m1;
    }
    return searchX((lo + hi) / 2, pts);
}

int main() {
    int T; cin >> T;
    while (T--) {
        int n; cin >> n;
        vector<Point> pts(n);
        for (int i = 0; i < n; ++i) cin >> pts[i].x >> pts[i].y;
        double ans = searchY(pts);
        cout << int(round(ans)) << "\n";
        if (T) cout << "\n";
    }
    return 0;
}
```

### 优点与不足

| 优点 | 不足 |
|------|------|
| 实现简单，无导数 | 仅适用于低维（$\texttt{2D/3D}$） |
| 容易调试和验证 | 收敛速度较慢（对数级） |
| 无需处理分母为零 | 需固定搜索区间 |

## 解法二：$\texttt{Weiszfeld}$ 迭代算法（更高效）

### 原理

$\texttt{Weiszfeld}$ 算法（也称迭代重加权平均）是求解几何中位数的经典方法。通过迭代公式：

$$
H^{(k+1)} = \frac{\sum_{i=1}^{N} \frac{P_i}{\|H^{(k)} - P_i\|}}{\sum_{i=1}^{N} \frac{1}{\|H^{(k)} - P_i\|}}
$$

该公式来源于对目标函数求导并令导数为零得到的固定点迭代。当迭代点不与任何数据点重合时，该算法保证收敛。

### 算法步骤

1. 初始化：取所有点的质心
2. 迭代：根据公式计算新点
3. 若某次迭代点与某数据点距离极小（如 `1e-12`），则直接取该数据点（精确解）
4. 当位移小于阈值或达到最大迭代次数时停止
5. 计算最终总距离并四舍五入

### 复杂度

- 每次迭代 $O(N)$
- 通常几十次迭代即可收敛（线性收敛速度）
- 比三分搜索快得多

### 代码实现

```cpp
// A Star not a Tree?
// UVa ID: 10228
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net


#include <bits/stdc++.h>
using namespace std;

struct Point { double x, y; };

double dist(const Point& a, const Point& b) {
    return hypot(a.x - b.x, a.y - b.y);
}

Point weiszfeld(const vector<Point>& pts, int maxIter = 200) {
    int n = pts.size();
    Point median{0, 0};
    for (auto& p : pts) median.x += p.x, median.y += p.y;
    median.x /= n; median.y /= n;
    
    for (int iter = 0; iter < maxIter; ++iter) {
        Point num{0, 0};
        double den = 0;
        for (auto& p : pts) {
            double d = dist(median, p);
            if (d < 1e-12) return p; // 与数据点重合
            num.x += p.x / d;
            num.y += p.y / d;
            den += 1.0 / d;
        }
        Point newMed{num.x / den, num.y / den};
        if (dist(newMed, median) < 1e-12) break;
        median = newMed;
    }
    return median;
}

int main() {
    int T; cin >> T;
    while (T--) {
        int n; cin >> n;
        vector<Point> pts(n);
        for (int i = 0; i < n; ++i) cin >> pts[i].x >> pts[i].y;
        Point hub = weiszfeld(pts);
        double totalLen = 0;
        for (auto& p : pts) totalLen += dist(hub, p);
        cout << int(round(totalLen)) << "\n";
        if (T) cout << "\n";
    }
    return 0;
}
```

### 优点与不足

| 优点 | 不足 |
|------|------|
| 收敛很快（线性，实际很快） | 需要处理分母为零 |
| 可推广到高维空间 | 公式推导稍复杂 |
| 无需指定搜索范围 | 初始点影响收敛（但质心已足够） |

## 两种方法对比总结

| 维度 | 三分搜索 | $\texttt{Weiszfeld}$ |
|------|----------|-----------|
| 理解难度 | 低 | 中 |
| 实现难度 | 低 | 中 |
| 收敛速度 | 对数级（慢） | 线性（快） |
| 通用性 | 仅低维 | 任意维 |
| 代码长度 | 短 | 短 |
| 本题适用性 | 可通过 | 可通过 |

对于本题（$N ≤ 100$，$\texttt{2D}$），两种方法均能轻松通过，但三分搜索更易向初学者解释，$\texttt{Weiszfeld}$ 更接近数学本质且效率更高。

---

## 最终建议

- **教学或快速解题**：使用三分搜索，思路直观，不易出错
- **追求效率或扩展性**：使用 $\texttt{Weiszfeld}$ 算法，并能处理更高维问题

无论采用哪种方法，核心都是认识到：本题不是简单的平均值，而是一个需要数值求解的凸优化问题。
