## 题目描述

$\texttt{Savage}$ 先生有一个巨大的方形花园，他想要将花园划分成 $2^N \times 2^N$ 个小正方形区域，并在除他房子所在位置外的所有区域种植植物。种植方案需要满足以下要求：

- 将小正方形区域组合成 $\texttt{L}$ 形区域（每个 $\texttt{L}$ 形区域由 $3$ 个小正方形组成）
- 每个 $\texttt{L}$ 形区域种植一种植物，用字母 `'a'` 到 `'z'` 表示
- 相邻的 $\texttt{L}$ 形区域（$8$ 方向相邻）必须使用不同的字母
- 房子位置用 `'*'` 表示
- 输出任意一个可行方案

## 输入格式

输入包含多个测试用例，每个测试用例包含三个整数：
- $N$ ($1 \leq N \leq 10$)：表示花园大小为 $2^N \times 2^N$
- $X, Y$：表示房子所在的列和行（左上角为 $(1,1)$）

## 输出格式

对于每个测试用例，输出一个 $2^N \times 2^N$ 的字符矩阵：
- 房子位置输出 `'*'`
- 其他位置输出字母 `'a'` 到 `'z'`，表示 $\texttt{L}$ 形区域的植物种类
- 相邻 $\texttt{L}$ 形区域字母不同
- 每个测试用例输出后输出一个空行

## 题目分析

### 问题本质

这是一个经典的 **棋盘覆盖问题**（$\texttt{Tromino Tiling Problem}$）。问题的核心是在 $2^N \times 2^N$ 的棋盘上，去掉一个特殊格子（房子）后，用 $\texttt{L}$ 形砖块（每个覆盖 $3$ 个格子）完全覆盖剩余的所有格子，且相邻砖块标记不同。

### 数学性质

- 棋盘总格子数：$4^N$
- 需要覆盖的格子数：$4^N - 1$
- $\texttt{L}$ 形砖块数量：$\frac{4^N - 1}{3}$（因为每个砖块覆盖 $3$ 个格子）
- 这个数量必须是整数，保证了问题有解

### 解题思路

采用 **分治算法**（$\texttt{Divide and Conquer}$）来解决这个问题：

1. **递归分割**：将大棋盘不断分成四个相等的小棋盘
2. **中心填充**：在每个递归层级，在四个小棋盘的交界处放置一个 $\texttt{L}$ 形砖块
3. **空缺处理**：根据房子位置确定哪个象限需要保留空缺，其他象限在交界处创建新的空缺
4. **颜色选择**：在局部邻域内贪心选择可用的字母

## 算法详解

### 分治策略

算法的核心函数是 `fillGarden`，参数包括：
- `size`：当前处理的区域大小
- `row, col`：当前区域的左上角坐标
- `missR, missC`：当前区域中空缺位置的坐标

#### 递归过程

1. **确定空缺象限**：
   ```cpp
   int quadrant = ((missR - row) / half) * 2 + ((missC - col) / half);
   ```
   这个公式将二维坐标映射到四个象限：
   - $0$：左上象限
   - $1$：右上象限  
   - $2$：左下象限
   - $3$：右下象限

2. **放置中心 $\texttt{L}$ 形砖**：
   - 在四个象限的交界处（中心 $2 \times 2$ 区域）放置 $\texttt{L}$ 形砖
   - 避开空缺所在的象限，只在其他三个象限放置砖块
   - 在 $3 \times 3$ 邻域内选择可用的字母

3. **递归处理子问题**：
   - 对于空缺所在象限：保持原始空缺，继续递归
   - 对于其他象限：在 $\texttt{L}$ 形砖占用的位置创建新的空缺，然后递归

#### 终止条件

当区域大小为 $2 \times 2$ 时，放置 $\texttt{L}$ 形砖后直接返回，因为这是最小的可解单元。

### 颜色选择策略

使用局部贪心策略选择字母：
- 检查当前 $\texttt{L}$ 形砖所在位置的 $3 \times 3$ 邻域
- 选择第一个未被邻域使用的字母
- 由于棋盘结构和递归性质，$26$ 个字母足够使用

### 算法正确性

1. **完备性**：每次递归都将问题分解为四个相同结构的子问题
2. **终止性**：区域大小每次减半，最终达到基本情况
3. **覆盖性**：每个 $\texttt{L}$ 形砖覆盖 $3$ 个格子，所有非房子格子都被覆盖
4. **颜色约束**：局部颜色选择保证相邻砖块字母不同

## 复杂度分析

- **时间复杂度**：$O(4^N)$，每个格子被处理一次
- **空间复杂度**：$O(4^N)$，存储棋盘状态
- **递归深度**：$O(N)$

```cpp
#include <bits/stdc++.h>
using namespace std;

enum {UP_LEFT, UP_RIGHT, BOTTOM_LEFT, BOTTOM_RIGHT};

vector<string> garden;
int houseX, houseY;

// 在 L 形状所在的三乘以三大小的邻域内寻找可用颜色
char findAvailableColor(int r, int c, int size) {
    int br = max(0, r - 1), er = min(size - 1, r + 2);
    int bc = max(0, c - 1), ec = min(size - 1, c + 2);
    for (char color = 'a'; color <= 'z'; color++) {
        bool available = true;
        for (int i = br; i <= er && available; i++)
            for (int j = bc; j <= ec && available; j++)
                if (garden[i][j] == color) 
                    available = false;
        if (available) return color;
    }
    return 'a';
}

void fillGarden(int size, int row, int col, int missR, int missC) {
    int half = size / 2;
    // 确定当前的空缺在哪个象限 (0:左上, 1:右上, 2:左下, 3:右下)
    int quadrant = ((missR - row) / half) * 2 + ((missC - col) / half);
    // 正方形的中心位置坐标
    int centerR = row + half - 1, centerC = col + half - 1;
    // 先确定在中心放置 L 形砖的颜色，
    // 然后根据象限放置 L 形砖（避开当前空缺位置所在的象限）
    char color = findAvailableColor(centerR, centerC, garden.size());
    if (quadrant != UP_LEFT) garden[centerR][centerC] = color;
    if (quadrant != UP_RIGHT) garden[centerR][centerC + 1] = color;
    if (quadrant != BOTTOM_LEFT) garden[centerR + 1][centerC] = color;
    if (quadrant != BOTTOM_RIGHT) garden[centerR + 1][centerC + 1] = color;
    // 当正方形的大小为 2 时，已经填满，不需要继续递归填充
    if (size == 2) return;
    // 递归处理四个象限
    for (int i = 0; i < 4; i++) {
        // 确定象限的左上角坐标
        int newRow = row + half * (i / 2), newCol = col + half * (i % 2);
        if (i == quadrant)
            // 房子所在象限：保持原始房子所在的空缺
            fillGarden(half, newRow, newCol, missR, missC);
        else {
            // 非房子所在象限：在交界处创建新的空缺
            int newMissR = centerR + (i / 2), newMissC = centerC + (i % 2);
            fillGarden(half, newRow, newCol, newMissR, newMissC);
        }
    }
}

int main() {
    int N, X, Y;
    while (cin >> N >> X >> Y) {
        int size = 1 << N;
        garden.assign(size, string(size, ' '));
        houseX = Y - 1, houseY = X - 1;
        garden[houseX][houseY] = '*';
        fillGarden(size, 0, 0, houseX, houseY);
        for (int i = 0; i < size; i++) cout << garden[i] << '\n';
        cout << "\n";
    }
    return 0;
}
```

## 总结

本题展示了分治算法在棋盘覆盖问题中的经典应用。通过递归地将大问题分解为相同结构的小问题，并在每个层级巧妙地放置 $\texttt{L}$ 形砖块，最终实现了对棋盘的完全覆盖。算法的关键在于正确处理空缺位置的传递和局部颜色选择，保证了解决方案的正确性和可行性。
