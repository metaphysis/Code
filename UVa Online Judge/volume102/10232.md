## 题目分析

本题要求我们生成一个特殊的非负整数序列 $B_n$，排序规则如下：

1. **主要排序规则**：按照二进制表示中 $1$ 的个数从小到大排序
2. **次要排序规则**：如果 $1$ 的个数相同，则按照数值本身从小到大排序

例如，前几个数的排序为：
- $0$（二进制 `0`，$0$ 个 $1$）
- $1$（二进制 `1`，$1$ 个 $1$）
- $2$（二进制 `10`，$1$ 个 $1$）
- $4$（二进制 `100`，$1$ 个 $1$）
- $3$（二进制 `11`，$2$ 个 $1$）
- $5$（二进制 `101`，$2$ 个 $1$）

题目要求对于给定的 $n$（$0 \leq n \leq 2147483647$），输出 $B_n$ 的值。

## 解题思路

### 关键观察

1. **数值范围**：题目限定考虑的非负整数小于 $2147483648$，即 $0$ 到 $2^{31}-1$，共 $2^{31}$ 个数
2. **分组思想**：可以将所有数按照二进制中 $1$ 的个数 $k$ 分成 $32$ 组（$k = 0, 1, 2, \ldots, 31$）
3. **组合计数**：对于固定的 $k$，在 $31$ 位二进制数中恰好有 $k$ 个 $1$ 的数的个数为组合数 $C(31, k)$

### 算法设计

#### 步骤 1：确定目标数所在的组

1. 如果 $n = 0$，直接返回 $0$（这是唯一一个 $0$ 个 $1$ 的数）
2. 否则，从 $n$ 中减去 $1$（跳过 $0$ 这个数）
3. 从 $k = 1$ 开始，依次检查每个组：
   - 计算当前组的大小：$count = C(31, k)$
   - 如果 $n < count$，说明目标数在当前的 $k$ 组中，是组内的第 $n$ 个数（从 $0$ 开始编号）
   - 否则，$n = n - count$，继续检查下一个 $k$

#### 步骤 2：在组内找到第 $n$ 个数

对于确定的 $k$，我们需要在 $31$ 位中找到第 $n$ 个（按数值从小到大）恰好有 $k$ 个 $1$ 的数。

使用**组合枚举法**：
- 从高位到低位（位 $30$ 到位 $0$）依次决定是否在当前位放置 $1$
- 对于当前位 $pos$，如果放置 $1$，那么剩下的 $k-1$ 个 $1$ 需要从 $pos$ 个低位中选择，组合数为 $C(pos, k-1)$
- 如果 $n < C(pos, k-1)$，则在当前位放置 $1$，$k$ 减 $1$
- 否则，不在当前位放置 $1$，$n$ 减去 $C(pos, k-1)$

#include <iostream>
#include <vector>
using namespace std;

// 计算组合数 C(n, k)
long long comb(int n, int k) {
    if (k < 0 || k > n) return 0;
    if (k == 0 || k == n) return 1;
    long long r = 1;
    if (k > n - k) k = n - k;
    for (int i = 1; i <= k; i++) {
        r = r * (n - i + 1) / i;
    }
    return r;
}

// 在 31 位中，1 的个数 = k，找第 idx 个数（从 0 开始）
int findKth(int k, long long idx) {
    int r = 0;
    int bits = 31;
    for (int pos = 30; pos >= 0; pos--) {
        long long cnt = comb(pos, k);
        if (idx >= cnt) {
            // 在 pos 放 1
            r |= (1 << pos);
            idx -= cnt;
            k--;
            if (k == 0) break;
        }
    }
    return r;
}

int main() {
    long long n;
    while (cin >> n) {
        if (n == 0) {
            cout << 0 << endl;
            continue;
        }
        n--; // 因为我们要从 k=1 组开始找，跳过 0
        for (int k = 1; k <= 31; k++) {
            long long cnt = comb(31, k);
            if (n < cnt) {
                cout << findKth(k, n) << endl;
                break;
            } else {
                n -= cnt;
            }
        }
    }
    return 0;
}
