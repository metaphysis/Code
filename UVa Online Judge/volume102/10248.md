## 题目描述

给定两个自然数 $0 < m \leq n < 100$，要求构造一个最短的整数，使得该整数包含从 $m$ 到 $n$ 的所有整数（包括 $m$ 和 $n$）作为其子串。

例如，对于 $m = 1$ 和 $n = 13$，可能的解包括：
- `12345678910111213`（直接拼接，长度为 $17$）
- `1011213456789`（长度为 $13$）
- `1101213456789`（长度为 $13$，可接受解）

题目保证 $n < 100$，即所有数字最多为两位数。

## 题目分析

本题要求构造一个最短的数字串，使其包含指定范围内的所有数字作为子串。这是一个典型的**最短超串问题（$\texttt{Shortest Superstring Problem}$）**，在一般情况下是 $\texttt{NP-hard}$ 的。但由于题目中 $n < 100$，我们可以利用数字的特殊性质设计高效算法。

### 关键观察

1. **数字范围限制**：所有数字最多为两位数，这大大简化了问题。
2. **重叠可能性**：两个数字可以共享部分数字，如 `12` 和 `23` 可以重叠为 `123`。
3. **图论建模**：可以将数字拼接问题转化为图论中的路径覆盖问题。

## 解题思路

### 核心思想：欧拉路径建模

我们将每个数字视为图中的一条边：
- 对于两位数 $ab$，创建有向边 $a \to b$
- 对于一位数 $a$，不立即建边，而是最后处理

这样，原问题转化为：**找到一条路径，使得该路径经过图中所有边至少一次**，这正是**有向图欧拉路径**问题。

### 欧拉路径的存在条件

对于有向图，存在欧拉路径的充要条件：
1. 图是弱连通的（忽略方向后连通）
2. 满足以下度数条件之一：
   - **欧拉回路**：所有顶点入度 = 出度
   - **欧拉路径**：恰好一个顶点满足 $\text{出度} - \text{入度} = 1$（起点），恰好一个顶点满足 $\text{入度} - \text{出度} = 1$（终点），其余顶点入度 = 出度

### 算法步骤

#### 1. 建图与度数统计

遍历 $m$ 到 $n$ 的所有数字：
- 对于一位数：标记存在，但不建边
- 对于两位数 $ab$：添加边 $a \to b$，更新度数：
  - $\texttt{deg}[a] = \texttt{deg}[a] + 1$（出度增加）
  - $\texttt{deg}[b] = \texttt{deg}[b] - 1$（入度增加）

这里使用 $\texttt{deg}[i] = \text{出度} - \text{入度}$ 的表示方法。

#### 2. 度数平衡

统计所有不满足 $\text{deg}[i] = 0$ 的顶点：
- $\texttt{outNodes}$：存储 $\texttt{deg}[i] > 0$ 的顶点
- $\texttt{inNodes}$：存储 $\texttt{deg}[i] < 0$ 的顶点

通过添加虚拟边来平衡度数：
```cpp
while (outNodes.size() > 1 && inNodes.size() > 1) {
    int from = inNodes.back(); inNodes.pop_back();
    int to = outNodes.back(); outNodes.pop_back();
    g[from][to]++;
}
```

每次添加边 $from \to to$ 的效果：
- $\texttt{deg}[from] = \texttt{deg}[from] + 1$（更接近 $0$）
- $\texttt{deg}[to] = \texttt{deg}[to] - 1$（更接近 $0$）

#### 3. 寻找欧拉路径

使用 $\texttt{Hierholzer}$ 算法寻找欧拉路径：

```cpp
function<void(int, vector<int>&)> dfs = [&](int u, vector<int>& path) {
    for (int v = 0; v < 10; v++) {
        while (g[u][v] > 0) {
            g[u][v]--;
            dfs(v, path);
            path.push_back(v);
        }
    }
};
```

算法特点：
- **深度优先**遍历
- **后序**记录顶点（得到逆序路径）
- **删除访问过的边**（避免重复）

#### 4. 多起点尝试

由于图可能不连通，需要从多个起点尝试：
- 优先选择度数不平衡的顶点
- 然后尝试所有出现过的顶点

#### 5. 处理单个数字

在得到欧拉路径后，检查哪些一位数未被包含，将其添加到结果末尾。

### 算法正确性

1. **完整性**：欧拉路径覆盖所有边，即包含所有两位数
2. **最优性**：路径中相邻边自动最大化重叠，得到最短超串
3. **可行性**：度数平衡确保欧拉路径存在

### 复杂度分析

- **时间复杂度**：$O(k^2)$，其中 $k = n - m + 1 \leq 99$
- **空间复杂度**：$O(1)$，图的大小固定为 $10 \times 10$

## 代码实现

```cpp
// The Integer All-time Champ
// UVa ID: 10248
// Verdict: Accepted
// Submission Date: 2025-11-18
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

string solve(int l, int r) {
    // 图
    vector<vector<int>> g(10, vector<int>(10, 0));
    // 顶点度以及顶点是否出现
    vector<int> d(10, 0), visited(10, 0);
    // 构建图（只对两位数）
    for (int i = l; i <= r; i++) {
        // 单个数字不建边，可能已被包含
        if (i < 10) continue;
        int x = i / 10, y = i % 10;
        g[x][y]++, d[x]++, d[y]--;
        visited[x] = visited[y] = 1;
     }
    // 根据有向欧拉路径的充要条件平衡度数
    vector<int> outNodes, inNodes;
    for (int i = 0; i < 10; i++) {
        int cnt = abs(d[i]);
        if (d[i] > 0) while (cnt--) outNodes.push_back(i);
        if (d[i] < 0) while (cnt--) inNodes.push_back(i);
    }
    // 任意选择出度为正和出度为负的顶点之间建边，总平衡度不变
    while (outNodes.size() > 1 && inNodes.size() > 1) {
        int from = inNodes.back(); inNodes.pop_back();
        int to = outNodes.back(); outNodes.pop_back();
        g[from][to]++;
    }
    string result;
    // 确定可能的欧拉路径起点
    vector<int> start;
    if (outNodes.size()) start.push_back(outNodes[0]);
    for (int i = 0; i < 10; i++)
        if (visited[i])
            start.push_back(i);
    // 找欧拉路径，Hierholzer算法
    function<void(int, vector<int>&)> dfs = [&](int u, vector<int>& path) {
        for (int v = 0; v < 10; v++) {
            while (g[u][v] > 0) {
                g[u][v]--;
                dfs(v, path);
                path.push_back(v);
            }
        }
    };
    for (auto s : start) {
        vector<int> path;
        dfs(s, path);
        // 从此顶点开始的欧拉路径可能为空，也就是说之前的遍历中边已经覆盖过
        if (path.empty()) continue;
        path.push_back(s);
        reverse(path.begin(), path.end());
        for (int node : path) result += to_string(node);
    }
    // 添加未被包含的单个数字
    for (int i = l; i <= r; i++)
        if (i < 10 && !visited[i])
            result += to_string(i);
    return result;
}

int main() {
    int m, n;
    while (cin >> m >> n) cout << solve(m, n) << '\n';
    return 0;
}
```

## 总结

本题通过巧妙的图论建模，将数字拼接问题转化为欧拉路径问题，利用 $\texttt{Hierholzer}$ 算法高效求解。算法的核心在于：
- **问题转化**：数字 → 有向边
- **度数平衡**：确保欧拉路径存在
- **路径构造**：$\texttt{DFS}$ 后序遍历
- **结果优化**：自动最大化数字间重叠

这种方法不仅保证了正确性，而且在 $n < 100$ 的限制下具有很高的效率。
