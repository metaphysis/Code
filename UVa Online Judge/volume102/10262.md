## 题目描述

给定两个小写字母字符串 $a$ 和 $b$ ，要求构造一个最短的小写字母字符串 $x$ ，使得 $ax$ 和 $bx$ 这两个拼接字符串中 **恰好有一个** 是回文串（即反转后与自身相等），另一个不是。

### 输入格式

标准输入包含多组数据，每组数据包含两行，每行一个字符串。字符串由小写字母组成，长度在 $0$ 到 $1000$ 之间。

### 输出格式

对于每组数据，输出一行答案字符串 $x$ 。如果存在多个满足条件的 $x$ ，选择长度最短且字典序最小的那个。如果不存在这样的 $x$ ，输出 `No solution.` 。

### 样例输入

```
abab
ababab
abc
def
```

### 样例输出

```
baba
ba
```

## 题目分析

本题要求构造一个字符串 $x$ ，使得 $a+x$ 和 $b+x$ 中恰好一个是回文串。我们需要找到 **最短且字典序最小** 的解。

### 问题特点

1. **回文性质** ：如果 $s+x$ 是回文串，那么它的反转等于自身： $reverse(s+x) = s+x$ 。
2. **结构约束** ：设 $rev(s)$ 表示 $s$ 的反转。若 $s+x$ 是回文，则有：
   $$
   s + x = reverse(s+x) = reverse(x) + rev(s)
   $$
   这意味着 $x$ 必须与 $rev(s)$ 的某个后缀匹配。

### 关键观察

经过推导，我们可以得到一个重要结论：  
**如果 $s+x$ 是回文串，那么 $x$ 一定是 $rev(s)$ 的某个后缀，且该后缀对应的前缀是回文串**。

证明：  
设 $n = |s|$ ， $m = |x|$ 。  
由于 $s+x$ 是回文，其长度为 $n+m$ 。考虑字符串的后 $m$ 个字符，即 $x$ 。  
因为回文对称性， $x$ 必须等于 $rev(s)$ 的前 $m$ 个字符。  
同时，为了保证整个字符串是回文， $rev(s)$ 的前 $m$ 个字符（即 $x$ 的反转）必须与 $s$ 的后 $m$ 个字符匹配。  
更形式化地，可以证明： $x$ 是 $rev(s)$ 的后缀，且 $rev(s)$ 去掉这个后缀后剩下的前缀是回文串。

## 解题思路

基于上述观察，我们可以设计如下算法：

### 1. 特判

如果 $a = b$ ，那么对于任意 $x$ ， $a+x$ 和 $b+x$ 总是同时为回文或同时不为回文，因此不存在解，直接输出 `No solution.` 。

### 2. 构造候选解

对于每个字符串 $s$ （ $a$ 或 $b$ ），我们构造所有可能的 $x$ ，使得 $s+x$ 是回文串。方法如下：

1. 计算 $rev = reverse(s)$ 。
2. 枚举分割点 $i$ （从 $-1$ 到 $n-1$ ，其中 $n = |rev|$ ）：
   - 取 $prefix = rev[0 \dots i]$ （当 $i=-1$ 时为空串）
   - 如果 $prefix$ 是回文串，则 $x = rev[i+1 \dots n-1]$ 是一个候选解
3. 额外考虑一种情况：在 $rev$ 前面添加一个字符 $c$ （ $c$ 从 `'a'` 到 `'z'` ），得到 $c + rev$ 作为候选解。这对应了 $x$ 比 $rev$ 长一个字符的情况。

### 3. 合并与筛选

1. 分别计算 $a$ 和 $b$ 的候选解集合 $A$ 和 $B$ 。
2. 合并两个集合，去重并按照 **长度优先、字典序次优先** 排序。
3. 遍历排序后的候选解，检查每个 $x$ 是否满足条件（ $a+x$ 和 $b+x$ 恰好一个是回文）。
4. 输出第一个满足条件的 $x$ 。

### 4. 复杂度分析

- 回文判断： $O(n)$ ，其中 $n$ 是字符串长度。
- 构造候选解：枚举 $O(n)$ 个分割点，每个点做一次 $O(n)$ 的回文检查，共 $O(n^2)$ 。
- 候选解数量： $O(n)$ 个。
- 排序： $O(n \log n)$ 。
- 总复杂度： $O(n^2)$ ，对于 $n \leq 1000$ 完全可行。

### 5. 正确性证明

算法的正确性基于上述数学推导：我们枚举了所有可能使 $s+x$ 成为回文的 $x$ 。因此，如果存在解，它一定在候选解集合中。我们按长度和字典序排序后遍历，找到的第一个满足“恰好一个回文”条件的解就是题目要求的最优解。

## 代码实现

```cpp
// Suffidromes
// UVa ID: 10262
// Verdict: Accepted
// Submission Date: 2025-12-24
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

bool cmp(string a, string b) {
    if (a.size() != b.size()) return a.size() < b.size();
    return a < b;
}

// 判断回文
bool isPalindrome(const string& s) {
    int left = 0, right = s.size() - 1;
    while (left < right)
        if (s[left++] != s[right--]) return false;
    return true;
}

// 获取所有可能的 x，使得 s+x 是回文
vector<string> getCandidates(const string& s) {
    vector<string> result;
    string ss = s;
    reverse(ss.begin(), ss.end());
    int n = ss.size();
    // 枚举分割点 i，如果 reversed[0..i] 是回文，那么可以取 reversed[i+1,n-1] 作为 x
    for (int i = -1; i < n; ++i) {
        string x = ss.substr(0, i + 1);
        if (isPalindrome(x)) result.push_back(ss.substr(i + 1));
    }
    // 增加一个字符，构成长度为奇数的回文
    for (char i = 'a'; i <= 'z'; i++) result.push_back(i + ss);
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string a, b;
    while (getline(cin, a)) {
        getline(cin, b);
        // 两个字符串相等则不存在解
        if (a == b) {
            cout << "No solution.\n";
            continue;
        }
        if (a.size() > b.size()) swap(a, b);
        vector<string> A = getCandidates(a), B = getCandidates(b);
        for (auto s : B) A.push_back(s);
        sort(A.begin(), A.end(), cmp);
        A.erase(unique(A.begin(), A.end()));
        for (auto s : A)
            if (isPalindrome(a + s) && !isPalindrome(b + s) ||
                !isPalindrome(a + s) && isPalindrome(b + s)) {
                    cout << s << '\n';
                    break;
                }
    }
    return 0;
}
```

## 总结

本题的关键在于理解回文串的结构特性，从而直接构造候选解，避免暴力枚举。通过数学推导，我们发现 $x$ 必须是原字符串反转后的某个后缀，并且该后缀对应的前缀是回文串。基于这一性质，我们可以高效地枚举所有可能的 $x$ ，然后从中筛选出满足条件的最优解。

这种方法的时间复杂度为 $O(n^2)$ ，空间复杂度为 $O(n)$ ，对于 $n \leq 1000$ 的数据范围完全足够。
