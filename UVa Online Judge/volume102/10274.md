## 题目描述

$\texttt{Tomy}$ 喜欢玩一个叫做 **$\texttt{Fans and Gems}$** （也称为 $\texttt{Gravnic}$）的游戏。在这个游戏中，玩家使用风扇来收集宝石，但只有当使用最少步数收集所有宝石时，$\texttt{Tomy}$ 才会满意。

### 游戏规则

1. **宝石类型** ：有三种宝石：红色（用 `'1'` 表示）、绿色（用 `'2'` 表示）和蓝色（用 `'3'` 表示）。
2. **游戏元素** ：
   - 墙（`'#'`）：不可通过。
   - 飞行物（`'@'`）：可以被风扇吹动，但永远不会消失。
   - 风扇：虽然看不见，但玩家可以选择风向。
3. **操作** ：每次操作，玩家选择一个风向：上（`'U'`）、下（`'D'`）、左（`'L'`）、右（`'R'`）。
4. **移动规则** ：
   - 风扇启动后，所有可移动物体（宝石和飞行物）会同时朝选定方向移动，直到遇到障碍物（墙、其他物体或边界）。
   - 移动停止后，检查是否有同色宝石在四个方向上相邻。如果有，这些相邻的同色宝石会同时消失。
   - **关键点** ：宝石消失后，风扇仍在工作，剩余的宝石可能会继续移动，然后再检查消除。这个过程重复进行，直到所有宝石都无法移动且没有宝石可以消失为止。
5. **目标** ：使用最少的操作步数让所有宝石消失。如果有多解，输出字典序最小的操作序列。如果无法完成，输出 `-1`。

### 输入格式

- 第一行：整数 $T$（$1 \le T \le 50$），测试用例数量。
- 每个测试用例：
  - 两个整数 $N$ 和 $M$（$1 \le N \le 12$, $1 \le M \le 20$），表示地图的行数和列数。
  - 接下来 $N$ 行，每行 $M$ 个字符，描述地图。
  - 每个地图后有一空行（需忽略）。
- 地图字符含义：
  - 空格：空位置
  - `'#'`：墙
  - `'1'`：红宝石
  - `'2'`：绿宝石
  - `'3'`：蓝宝石
  - `'@'`：飞行物
- 保证地图四边都是墙，至少有一个宝石，且初始时没有同色宝石相邻。

### 输出格式

- 对于每个测试用例，输出一行。
- 如果有解：输出最短操作序列字符串（使用字符 `'U'`、`'D'`、`'L'`、`'R'`）。若有多解，输出字典序最小的。
- 如果无解：输出 `-1`。
- **保证** ：如果有解，最多只需要 $18$ 步。

## 题目分析

### 问题本质

这是一个 **状态空间搜索** 问题。我们需要在一个有限的状态空间中，找到从初始状态（所有宝石存在）到目标状态（没有宝石）的最短路径。

- **状态** ：地图上所有宝石和飞行物的位置。
- **操作** ：四个方向的风扇操作。
- **状态转移** ：根据风向模拟所有物体的移动和宝石的消除过程。
- **目标** ：所有宝石消失。
- **约束** ：最多 $18$ 步。

### 关键难点

1. **复杂的移动与消除规则** ：一次操作可能引发多次移动和消除（宝石消失后，其他宝石可能继续移动）。
2. **状态表示** ：地图最大为 $12 \times 20 = 240$ 格，但宝石和飞行物数量有限，需要高效的状态表示。
3. **搜索空间控制** ：步数限制为 $18$，但每次操作后状态变化复杂，可能产生大量状态。
4. **字典序输出** ：在找到最短路径的基础上，需要选择字典序最小的操作序列。

### 解题思路

#### 1. 状态表示

将整个地图转换为一个字符串作为状态。由于地图最多 $240$ 格，字符串长度为 $N \times M$，可以用 `string` 表示，并用 `unordered_set` 进行哈希去重。

#### 2. 搜索算法选择

由于需要找最短路径，且步数限制为 $18$，**宽度优先搜索（$\texttt{BFS}$）** 是合适的选择。$\texttt{BFS}$ 保证首次到达目标状态时路径最短。

#### 3. 模拟操作

这是本题最核心的部分。对于一个状态和一个方向，需要模拟：
1. **移动阶段** ：所有可移动物体朝风向移动，直到撞到障碍物。
2. **消除阶段** ：检查是否有同色宝石相邻，有则全部消失。
3. **重复** ：由于风扇持续工作，消除后可能还有宝石能继续移动，因此需要循环执行移动和消除，直到状态稳定。

**优化** ：根据风向调整遍历顺序，可以一次性完成移动，避免循环检查：
- 向下（`D`）：从下往上遍历
- 向上（`U`）：从上往下遍历  
- 向左（`L`）：从左往右遍历
- 向右（`R`）：从右往左遍历

这样确保在移动过程中，物体不会互相阻塞。

#### 4. 消除逻辑

需要检测所有相邻的同色宝石。注意：
- 可能有两个以上宝石连在一起（如三个红色宝石排成一行）。
- 消除是同时进行的。
- 使用一个临时数组记录要消除的位置，避免重复处理。

#### 5. 字典序处理

在 $\texttt{BFS}$ 中，按 **字典序顺序** 尝试四个方向：`D`、`L`、`R`、`U`（因为 `'D' < 'L' < 'R' < 'U'`）。这样，当 $\texttt{BFS}$ 首次到达目标状态时，路径自然就是字典序最小的最短路径。

#### 6. 剪枝

- **步数限制** ：路径长度超过 $18$ 时不再扩展。
- **状态去重** ：使用 `unordered_set` 记录已访问状态，避免重复搜索。

### 算法复杂度分析

- 状态数：理论上最多有 $(N \times M)!$ 种排列，但由于物体数量有限且步数限制为 $18$，实际可访问状态数有限。
- 每个状态尝试 $4$ 个方向，每个方向模拟复杂度为 $O(N \times M)$。
- 在题目限制下（$T \le 50$，$N \le 12$，$M \le 20$，步数 $\le 18$），$\texttt{BFS}$ 可以高效运行。

## 代码实现

```cpp
// Fans and Gems
// UVa ID: 10274
// Verdict: Accepted
// Submission Date: 2025-12-31
// UVa Run Time: 0.040s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 16;
// D, L, R, U (字典序顺序)
const int dx[4] = {1, 0, 0, -1}, dy[4] = {0, -1, 1, 0};
const char dirChar[4] = {'D', 'L', 'R', 'U'};

struct State { string board, path; };

string grid[MAXN];
int n, m;

string simulate(string board, int dir, bool &finished) {
    finished = false;
    vector<string> grid(n, string(m, ' '));

    // 从字符串转回网格
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            grid[i][j] = board[i * m + j];

    // 根据方向确定遍历顺序
    int startRow, endRow, stepRow, startCln, endCln, stepCln;
    
    if (dir == 0) { // D: 从上到下，从下到上移动
        startRow = n - 1; endRow = -1; stepRow = -1;
        startCln = 0; endCln = m; stepCln = 1;
    } else if (dir == 1) { // L: 从左到右，从左到右移动
        startRow = 0; endRow = n; stepRow = 1;
        startCln = 1; endCln = m; stepCln = 1;
    } else if (dir == 2) { // R: 从左到右，从右到左移动
        startRow = 0; endRow = n; stepRow = 1;
        startCln = m - 2; endCln = -1; stepCln = -1;
    } else { // U: 从下到上，从上到下移动
        startRow = 1; endRow = n; stepRow = 1;
        startCln = 0; endCln = m; stepCln = 1;
    }

    bool changed = true;
    while (changed) {
        changed = false;
        
        // 阶段1: 移动所有可移动物体（一次性完成）
        vector<string> newGrid = grid;
        for (int i = startRow; i != endRow; i += stepRow)
            for (int j = startCln; j != endCln; j += stepCln) {
                char ch = grid[i][j];
                if (ch == '1' || ch == '2' || ch == '3' || ch == '@') {
                    int x = i, y = j;
                    // 移动到不能移动为止
                    while (true) {
                        int nx = x + dx[dir], ny = y + dy[dir];
                        if (nx < 0 || nx >= n || ny < 0 || ny >= m) break;
                        if (grid[nx][ny] == '#' || grid[nx][ny] != ' ') break;
                        x = nx; y = ny;
                    }
                    if (x != i || y != j) {
                        grid[i][j] = ' ';
                        grid[x][y] = ch;
                        changed = true;
                    }
                }
            }
        
        // 检查是否有移动发生
        if (!changed) break;
        
        // 阶段2: 检查并消除相邻的同色宝石（可能存在 3 个或以上的同色宝石）
        vector<pair<int, int>> toRemove;

        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++) {
                char ch = grid[i][j];
                if (ch >= '1' && ch <= '3') {
                    // 检查四个方向是否有同色
                    for (int d = 0; d < 4; d++) {
                        int ni = i, nj = j;
                        vector<pair<int, int>> tmp;
                        while (true) {
                            if (ni >= 0 && ni < n && nj >= 0 && nj < m && grid[ni][nj] == ch) tmp.push_back({ni, nj});
                            else break;
                            ni += dx[d], nj += dy[d];
                        }
                        if (tmp.size() >= 2) toRemove.insert(toRemove.end(), tmp.begin(), tmp.end());
                    }
                }
            }
        
        if (!toRemove.empty()) {
            changed = true;
            for (auto &p : toRemove) grid[p.first][p.second] = ' ';
        }
    }

    // 转回字符串，并检查是否所有宝石已消失
    string result(n * m, ' ');
    int gemCount = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            result[i * m + j] = grid[i][j];
            if (grid[i][j] >= '1' && grid[i][j] <= '3') gemCount++;
        }
    
    if (gemCount == 0) finished = true;
    return result;
}

string solve() {
    string startBoard(n * m, ' ');
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            startBoard[i * m + j] = grid[i][j];

    queue<State> q;
    unordered_set<string> visited;
    q.push({startBoard, ""});
    visited.insert(startBoard);

    while (!q.empty()) {
        State u = q.front(); q.pop();
        if (u.path.size() > 18) continue;
        for (int d = 0; d < 4; d++) {
            bool finished = false;
            string nextBoard = simulate(u.board, d, finished);
            string nextPath = u.path + dirChar[d];
            if (finished) return nextPath;
            if (visited.find(nextBoard) == visited.end()) {
                visited.insert(nextBoard);
                q.push({nextBoard, nextPath});
            }
        }
    }
    return "-1";
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int T; cin >> T;
    while (T--) {
        cin >> n >> m;
        cin.ignore(128, '\n');
        for (int i = 0; i < n; i++) getline(cin, grid[i]);
        // 注意空行的处理，若不处理，会导致运行时错误，可能改行包含了某些不需要的字符
        string emptyLine;
        if (T > 0) getline(cin, emptyLine);
        cout << solve() << '\n';
    }
    return 0;
}
```

## 总结

本题是一个典型的状态空间搜索问题，关键在于：

1. **正确模拟复杂的移动和消除规则** ，特别是风扇持续工作导致的多轮移动与消除。
2. **高效的状态表示与搜索** ，使用字符串表示状态，$\texttt{BFS}$ 搜索最短路径。
3. **字典序处理** ，通过按特定顺序尝试方向来保证输出字典序最小解。

本题的难度主要在于模拟规则的实现，一旦正确实现模拟函数，剩下的就是标准的 $\texttt{BFS}$ 搜索。通过优化遍历顺序和状态表示，可以在时限内高效求解。
