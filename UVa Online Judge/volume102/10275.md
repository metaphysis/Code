## 题目描述

给定一个正整数 $T$（$1 \leq T \leq 10$）表示测试用例的数量。每个测试用例给出一个数字字符串 $S$，表示 $N^N$ 的计算结果，其中 $S$ 最多有 $500,000$ 位数字，且不包含前导零。

题目保证：如果计算错误，错误结果与正确结果**恰好只有一个数字不同**，且数字的位数是正确的。

要求：对于每个测试用例，如果存在唯一的 $N$ 使得 $N^N = S$，则输出 $N$；否则输出 $-1$。

## 题目分析

### 问题本质

我们需要找到唯一的正整数 $N$，使得 $N^N$ 等于给定的数字 $S$。由于 $S$ 可能非常大（最多 $500,000$ 位），直接枚举所有可能的 $N$ 并计算 $N^N$ 是不可行的。

### 关键观察

1. **位数限制**：$N^N$ 的位数可以通过公式 $\lfloor N \times \log_{10} N \rfloor + 1$ 计算。对于给定的 $S$，其位数 $length(S)$ 必须等于 $\lfloor N \times \log_{10} N \rfloor + 1$。

2. **$N$ 的范围估计**：虽然 $S$ 可能很大，但满足位数条件的 $N$ 的范围是有限的。通过计算可以发现，当 $N$ 在 $200,000$ 左右时，$N^N$ 的位数约为 $1,000,000$ 量级，因此我们只需要在估算值附近的小范围内搜索。

3. **验证策略**：
   - 对于较小的 $S$（在 $64$ 位整数范围内），预计算所有可能的 $N^N$ 并存表，直接查表匹配。
   - 对于较大的 $S$，先用位数公式估算 $N$，然后用试除法验证：将 $S$ 除以 $N$ 一次，如果能整除则认为匹配。

## 解题思路

### 算法步骤

1. **预处理**：预计算所有 $N^N$ 不超过 $64$ 位整数范围的值，存储在数组中。

2. **输入处理**：读取测试用例数量 $T$ 和每个测试用例的字符串 $S$。

3. **小数字处理**：如果 $S$ 长度较小（小于 $20$ 位），在预计算表中查找匹配的 $N$。

4. **大数字处理**：
   - 使用位数公式估算 $N$：解方程 $\lfloor N \times \log_{10} N \rfloor + 1 = length(S)$
   - 在估算值附近小范围搜索候选 $N$
   - 对每个候选 $N$，用试除法验证：$S$ 除以 $N$ 的余数为 $0$

5. **结果判定**：
   - 如果找到唯一的匹配 $N$，输出该 $N$
   - 否则输出 $-1$

### 复杂度分析

- **时间复杂度**：预处理 $O(1)$，每个测试用例 $O(length(S))$
- **空间复杂度**：预处理表 $O(1)$，存储 $S$ 需要 $O(length(S))$

```cpp
// Guess the Number

#include <bits/stdc++.h>
using namespace std;

const string tableOfPow[] = {
    "1", "4", "27", "256", "3125", "46656", "823543", "16777216",
    "387420489", "10000000000", "285311670611", "8916100448256",
    "302875106592253", "11112006825558016", "437893890380859375"
};

// 大数除法：a / b，返回商和余数
pair<string, int> divide(const string& a, int b) {
    string result;
    long long remainder = 0;
    for (char digit : a) {
        remainder = remainder * 10 + (digit - '0');
        int quotient = remainder / b;
        remainder %= b;
        if (!result.empty() || quotient != 0)
            result += char(quotient + '0');
    }
    if (result.empty()) result = "0";
    return {result, (int)remainder};
}

// 计算 n^n 的位数
int countDigits(int n) { return floor(n * log10(n)) + 1; }

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int t;
    cin >> t;
    while (t--) {
        string s;
        cin >> s;
        int length = s.size();
        
        // 对于小数字，直接查表
        if (length < 20) {
            bool found = false;
            for (int i = 0; i < 16; i++)
                if (s == tableOfPow[i]) {
                    found = true;
                    cout << (i + 1) << '\n';
                }
            if (!found) cout << -1 << '\n';
            continue;
        }
        
        // 通过位数估算 N
        int low = 1, high = 1000000;
        while (low <= high) {
            int middle = (low + high) / 2;
            countDigits(middle) < length ? low = middle + 1 : high = middle - 1;
        }
        
        // 在估算值附近检查候选
        bool found = false;
        for (int n = low - 3; n <= low + 3; n++) {
            if (countDigits(n) != length) continue;
            auto [quotient, remainder] = divide(s, n);
            if (!remainder) {
                found = true;
                cout << n << '\n';
                break;
            }
        }
        if (!found) cout << -1 << '\n';
    }
    return 0;
}

```

## 总结

本题通过预计算和数学分析相结合的方法，高效地解决了大数匹配问题：

1. **预计算优化**：对于小数字直接查表，避免重复计算
2. **位数估算**：利用数学公式快速缩小搜索范围
3. **试除法验证**：对于大数字，用简单的除法操作代替复杂的大数幂运算

这种分层处理的策略既保证了小数据的精确性，又保证了大数据的效率，是处理规模差异较大数据的有效方法。
