[UVa 10277 Boastin Red Socks](https://blog.csdn.net/metaphysis/article/details/154303547)

## 题目分析

抽屉中有红色和黑色两种袜子，总数量 $n$ 在 $2$ 到 $50000$ 之间。已知随机取两只袜子都是红色的概率为 $\frac{p}{q}$，要求求出红袜和黑袜的数量 $(r, b)$。如果存在多组解，输出总数量 $n$ 最小的一组；若无解则输出 `impossible`。

## 解题思路

设红袜数量为 $r$，总袜子数为 $n$，则取到两只红袜的概率为：

$$
\frac{\binom{r}{2}}{\binom{n}{2}} = \frac{r(r-1)}{n(n-1)} = \frac{p}{q}
$$

整理得：

$$
q \cdot r(r-1) = p \cdot n(n-1)
$$

我们需要找到整数 $r$ 和 $n$ 满足：
- $2 \le n \le 50000$
- $2 \le r \le n$
- $q \cdot r(r-1) = p \cdot n(n-1)$

### 特殊情况
- 当 $p = 0$ 时，概率为 $0$，意味着红袜数量 $r \le 1$。但为了能穿同色袜子，至少要有两只同色袜子。最小解为 $0$ 只红袜、$2$ 只黑袜。
- 当 $p = q$ 时，概率为 $1$，意味着全是红袜。最小解为 $2$ 只红袜、$0$ 只黑袜。

### 一般情况
遍历可能的 $n$ 从 $2$ 到 $50000$：
1. 检查 $p \cdot n(n-1)$ 是否能被 $q$ 整除
2. 计算 $k= \frac{p \cdot n(n-1)}{q}$
3. 解方程 $r(r-1) = k$：
   - 计算判别式 $d = 1 + 4 \cdot k$
   - 检查 $d$ 是否为完全平方数
   - 检查 $r = \frac{1 + \sqrt{d}}{2}$ 是否为整数且在范围内

选择满足条件且 $n$ 最小的解。

```cpp
// Boastin Red Socks
// UVa ID: 10277
// Verdict: Accepted
// Submission Date: 2025-11-01
// UVa Run Time: 0.040s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
int main() {
    unsigned long p, q;
    while (cin >> p >> q) {
        if (p == 0 && q == 0) break;
        if (p == 0) {
            // 概率为0，最少袜子且能穿同色袜：0红2黑
            cout << "0 2" << endl;
            continue;
        }
        if (p == q) {
            // 概率为1，最少袜子：2红0黑
            cout << "2 0" << endl;
            continue;
        }
        unsigned long red = 0, black = 0;
        unsigned long minTotal = ULONG_MAX;
        for (unsigned long n = 2; n <= 50000; n++) {
            unsigned long long val = (unsigned long long)p * n * (n - 1);
            if (val % q != 0) continue;
            unsigned long long k = val / q;
            // 解 r*(r-1) = k
            unsigned long long d = 1 + 4 * k;
            unsigned long long sqrtD = sqrt(d);
            if (sqrtD * sqrtD != d) continue;
            if ((1 + sqrtD) % 2 != 0) continue;
            unsigned long r = (1 + sqrtD) / 2;
            if (r < 2 || r > n) continue;
            // 找到可行解
            if (n < minTotal) {
                minTotal = n;
                red = r;
                black = n - r;
            }
        }
        if (minTotal == ULONG_MAX) cout << "impossible" << '\n';
        else cout << red << " " << black << '\n';
    }
    return 0;
}
```
