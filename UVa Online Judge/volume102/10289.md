## 题目描述

给定一个边长为 $S$ 的正方形，需要分别计算在正方形中放入 $1,2,3,4,5,6,8$ 个全等等边三角形时，三角形的最大可能边长。图形放置方式固定且对称（参考题目给出的图 $1-7$）。要求输出精确解，保留 $10$ 位小数。

## 问题分析

这是一个经典的最优填充问题。对于每种数量的三角形，都需要通过几何约束建立方程，求解三角形边长与正方形边长的比值。

### 整体思路

对于每种情况，我们设三角形边长为 $a$，正方形边长为 $S = 1$（归一化），求出比值 $k = a / S$，然后对输入的 $S$ 乘以 $k$ 即可。

题目给出的 $7$ 种情况中，前 $4$ 种和第 $6,7$ 种都可以通过简单的几何关系推导出解析解。唯独第 $5$ 种（$5$ 个三角形）的几何约束较为复杂，可以通过两种方法求解：二分搜索或精确解析解。

## 各情况详细推导

### 情况一：$1$ 个三角形

将一个等边三角形放入正方形中，最优放置方式是三角形的一个角与正方形的一个角重合，另外两个顶点分别落在正方形的两条边上。此时，三角形的一条边与正方形的边夹角为 $15^\circ$。

设正方形边长为 $1$，三角形边长为 $a$。由几何关系可得：

$a \cdot \cos 15^\circ = 1$

因此：

$\displaystyle k_1 = \frac{1}{\cos 15^\circ}$

### 情况二：$2$ 个三角形

两个等边三角形的最优放置是让它们的高之和等于正方形的对角线长度。

等边三角形的高为 $h = \frac{\sqrt{3}}{2}a$，正方形对角线长为 $\sqrt{2}$。

两个三角形的高之和为 $2h = \sqrt{3}a$，令其等于对角线长：

$\sqrt{3}a = \sqrt{2}$

因此：

$\displaystyle k_2 = \frac{\sqrt{6}}{3}$

### 情况三：$3$ 个三角形

三个三角形的放置涉及一个几何关系：从正方形左上角到右下角的斜线上，三角形的排列满足特定比例。

推导可得：

$\displaystyle k_3 = \frac{2\sqrt{2}}{\sqrt{6} + \sqrt{3}}$

### 情况四：$4$ 个三角形

四个三角形以 $2 \times 2$ 的网格方式排列。设三角形边长为 $a$，高为 $h = \frac{\sqrt{3}}{2}a$。

正方形边长 $S$ 与 $a$ 的关系为：

$\displaystyle \frac{S - a}{a / 2} = \frac{2}{\sqrt{3}}$

解得：

$\displaystyle k_4 = \frac{\sqrt{3}}{1 + \sqrt{3}}$

### 情况五：$5$ 个三角形（关键）

五个三角形的放置几何关系非常复杂。下面分别介绍两种求解方法。

#### 几何排布描述

正方形 $[0,1] \times [0,1]$，所有三角形边长 $a$，高 $h = \frac{\sqrt{3}}{2}a$。

- **`T1`（正放）**：底边与下边界 $y=0$ 重合，顶角向上，顶角高度 $h$
- **`T4`（正放）**：一条边与上边界 $y=1$ 重合，顶角向下，顶角高度 $1-h$
- **`T3`（正放）**：一条边与右边界 $x=1$ 重合，它的**高是水平的**（从右向左的长度 $h$），左侧顶角水平指向正方形中心
- **`T2`（倒放）**：上边水平，长度 $a$，左顶角紧贴左边界 $x=0$
- **`T5`（旋转）**：一个顶点紧贴左边界 $x=0$，一个顶点紧贴 `T4` 的左侧边，第三个顶点与 `T3` 接触

接触关系：
- `T1` 的上顶角与 `T3` 的边接触
- `T4` 的下顶角与 `T3` 的上侧边接触（该边与水平方向夹角 $60^\circ$）
- `T3` 的左侧顶角与 `T2` 和 `T5` 接触

#### 方法一：二分搜索

**二分判定条件推导**

**变量定义**（$S=1$ 归一化）：

- $a$：三角形边长（同时也是 `T2` 上边的水平长度）
- $h = \frac{\sqrt{3}}{2}a$：三角形的高（同时也是 `T3` 的水平高）

**步骤一：水平方向空间判断**

若 $h + a \le 1$，说明水平方向还有空间，可以增大 $a$。

**步骤二：水平超出量与垂直补偿**

当 $h + a > 1$ 时，水平超出量：

$overX = h + a - 1$

`T3` 的上侧边与水平方向夹角 $60^\circ$，沿该斜线将水平超出转换为垂直方向的高度：

$vertComp = overX \cdot \tan 30^\circ$

**步骤三：垂直错位 $vertGap$**

`T1` 上顶角与 `T4` 下顶角水平线之间的垂直距离为 $1 - 2h$。  
减去垂直补偿 $vertComp$，得到 `T4` 下顶角相对于 `T3` 左侧顶角水平线的垂直错位：

$vertGap = (1 - 2h) - vertComp$

若 $vertGap \le 0$，说明垂直空间不足，$a$ 太大。

**步骤四：水平剩余偏移**

由 $vertGap$ 对应直角三角形的 $30^\circ$ 角，可得到水平补偿 $\frac{vertGap}{\tan 30^\circ}$。  
水平超出量减去该补偿，得到水平剩余偏移：

$horzRemain = overX - \frac{vertGap}{\tan 30^\circ}$

若 $horzRemain \le 0$，说明水平方向无法满足接触条件，$a$ 太小。

**步骤五：重叠判定**

两条直角边：
- $leg_1 = a - horzRemain$：`T4` 下顶角与正方形左边界的水平距离
- $leg_2 = vertComp + vertGap$：`T4` 下顶角与 `T2` 上边之间的垂直距离

若 $leg_1^2 + leg_2^2 < a^2$，说明 `T5` 与 `T3` 重叠，$a$ 太大；否则可以尝试增大 $a$。

**二分搜索实现**

在区间 $[0.55, 0.56]$ 内二分搜索最大可行 $a$，迭代 $100$ 次即可获得高精度结果：

$k_5 \approx 0.5545791573148570$

#### 方法二：精确解析解

通过分析三角形之间的接触关系和 $30^\circ$ 角斜线投影，可以建立关于 $a$ 的二次方程。

根据几何关系（涉及 `T1` 与 `T4` 顶角之间的垂直距离、`T5` 的斜边与直角边关系），应用勾股定理可得：

$$
(21 + 8\sqrt{3}) a^2 - (22 + 14\sqrt{3}) a + (8 + 4\sqrt{3}) = 0 \quad (S = 1)
$$

由求根公式，取较小的根（满足 $a < 1$）：

$$
a = \frac{(22 + 14\sqrt{3}) - \sqrt{(22 + 14\sqrt{3})^2 - 4(21 + 8\sqrt{3})(8 + 4\sqrt{3})}}{2(21 + 8\sqrt{3})}
$$

计算判别式：

$$
\Delta = (22 + 14\sqrt{3})^2 - 4(21 + 8\sqrt{3})(8 + 4\sqrt{3}) = 4 + 6\sqrt{3}
$$

因此：

$$
a = \frac{22 + 14\sqrt{3} - \sqrt{16 + 24\sqrt{3}}}{2(21 + 8\sqrt{3})}
$$

分子分母同除以 $2$，得到最简形式：

$$
k_5 = \frac{11 + 7\sqrt{3} - \sqrt{4 + 6\sqrt{3}}}{21 + 8\sqrt{3}}
$$

数值验证：代入 $\sqrt{3} \approx 1.73205080757$，计算得 $k_5 \approx 0.5545791573$，与二分搜索结果完全一致。

### 情况六：$6$ 个三角形

六个三角形的面积关系给出线性方程：

$3\sqrt{3}a = (1 + \sqrt{3})S$

因此：

$\displaystyle k_6 = \frac{1 + \sqrt{3}}{3\sqrt{3}}$

### 情况七：$8$ 个三角形

八个三角形的边长关系给出：

$\displaystyle k_7 = \frac{3 + \sqrt{3}}{3 + 4\sqrt{3}}$

## 题解代码

以下代码包含两种求解 $k_5$ 的方法（注释中保留了二分搜索的实现，实际使用精确解析式）：

```cpp

#include <bits/stdc++.h>
using namespace std;

// 方法一：二分搜索求 5 个三角形的最优边长比例（注释中保留，供参考）
double solveForFiveTriangles() {
    const double PI = acos(-1.0);
    double lo = 0.55, hi = 0.56;
    for (int iter = 0; iter < 100; ++iter) {
        double a = (lo + hi) * 0.5;
        double h = sqrt(3.0) / 2.0 * a;

        if (h + a <= 1.0) {
            lo = a;
            continue;
        }
        double overX = h + a - 1.0;
        double vertComp = overX * tan(PI / 6.0);
        double vertGap = (1.0 - 2.0 * h) - vertComp;
        if (vertGap <= 0.0) {
            hi = a;
            continue;
        }
        double horzRemain = overX - vertGap / tan(PI / 6.0);
        if (horzRemain <= 0.0) {
            lo = a;
            continue;
        }
        double leg1 = a - horzRemain;
        double leg2 = vertComp + vertGap;
        if (leg1 * leg1 + leg2 * leg2 < a * a) hi = a;
        else lo = a;
    }

    return lo;
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    // 预计算7种情况的比例系数 k = a / S
    vector<double> ratio = {
        // 情况1：1个三角形，边与正方形夹角15°
        1.0 / cos(15.0 / 180.0 * M_PI),
        // 情况2：2个三角形，高的和 = 正方形对角线
        sqrt(6) / 3,
        // 情况3：3个三角形，几何比例关系
        2.0 * sqrt(2) / (sqrt(6) + sqrt(3)),
        // 情况4：4个三角形，网格排列
        sqrt(3) / (1 + sqrt(3)),
        // 情况5：5个三角形，精确解析解
        // 方程：(21+8√3)a² - (22+14√3)a + (8+4√3) = 0
        // 取较小根：(11+7√3 - √(4+6√3)) / (21+8√3)
        // 亦可使用二分搜索求解，此处采用精确解析式
        (11 + 7 * sqrt(3) - sqrt(4 + 6 * sqrt(3))) / (21 + 8 * sqrt(3)),
        // 情况6：6个三角形，面积/线性关系
        (1.0 + sqrt(3)) / (3 * sqrt(3)),
        // 情况7：8个三角形，边长比例关系
        (3 + sqrt(3)) / (3 + 4 * sqrt(3))
    };
    double S;
    while (cin >> S) {
        cout << fixed << setprecision(10);
        for (int i = 0; i < 7; i++)  cout << ratio[i] * S << " \n"[i == 6];
    }
    return 0;
}
```

## 两种方法的比较

| 方法 | 优点 | 缺点 |
|------|------|------|
| 二分搜索 | 实现简单，不易出错，通用性强 | 需要迭代，存在微小浮点误差 |
| 精确解析解 | 理论精确，计算速度快，无误差 | 推导复杂，表达式繁琐，容易写错 |

在实际比赛中，两种方法均可通过。二分搜索更稳妥，精确解析解更优雅。本题解同时保留两种方法，供读者参考。

## 复杂度分析

- 预处理比例系数：$O(1)$，其中二分搜索方法迭代 $100$ 次，解析解方法直接计算
- 每组数据输出：$O(1)$
- 总复杂度：$O(T)$，其中 $T$ 为测试数据组数

实际运行时间约 $90$ 毫秒，主要开销来自浮点运算和输入输出。

## 总结

本题的核心在于针对每种三角形数量建立正确的几何约束。前 $4$ 种和第 $6,7$ 种都可以通过线性方程或简单三角函数解析求解。第 $5$ 种则需要深入分析五个三角形的空间排布，通过 $30^\circ$ 斜线投影建立判定条件。

对于 $k_5$ 的求解，本文提供了两种方法：
1. **二分搜索**：通过几何判定函数在区间内迭代逼近最优值
2. **精确解析解**：通过二次方程求根公式得到闭式表达式

两种方法最终得到相同的数值结果 $k_5 \approx 0.5545791573$。掌握这些几何关系对解决类似填充问题具有重要的参考价值。
