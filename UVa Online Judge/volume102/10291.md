## 题目描述

有一张圆形桌子，桌腿均匀分布在圆周上。由于桌腿长度不完全相同，桌子放在平坦表面上可能会摇晃。有趣的是，无论桌腿长度如何差异，总是可以通过锯掉某些桌腿的一部分，使得桌子平稳放置而不摇晃。

你的任务是确定需要锯掉的最小总长度，使得桌子平稳放置。注意不要求所有桌腿都接触地面。

**输入格式**
- 多组测试数据，每组数据包含：
  - 整数 $t$ ($3 \leq t \leq 50$)，表示桌腿数量
  - $t$ 行，每行一个整数表示桌腿长度（毫米）
- 以一行 `0` 结束输入

**输出格式**
- 对于每组数据，输出需要锯掉的最小总长度
- 每组输出之间用空行分隔

## 题目分析

### 问题理解

这是一个几何稳定性问题。对于圆形桌子，要保证平稳不摇晃，必须满足：

1. **至少三条桌腿接触地面**：这是稳定性的基本要求
2. **支撑腿分布合理**：支撑腿不能全部集中在某个半圆内，即任意两条相邻支撑腿之间的夹角必须小于 $180^\circ$

### 关键观察

1. **均匀分布特性**：桌腿在圆周上均匀分布，相邻桌腿之间的夹角为 $\frac{360^\circ}{n}$
2. **高度调整策略**：我们可以选择一个目标高度，将所有高于此高度的桌腿锯到该高度，所有等于或低于此高度的桌腿保持不变
3. **稳定性判断**：对于选定的目标高度，所有高度 $\geq$ 目标高度的桌腿将成为支撑腿，需要检查这些支撑腿的分布是否满足稳定性条件

### 算法思路

1. **收集所有可能的目标高度**：即所有不同的桌腿长度
2. **从高到低尝试目标高度**：这样能保证找到锯掉量最小的解决方案
3. **对于每个目标高度**：
   - 找出所有高度 $\geq$ 目标高度的桌腿索引
   - 检查这些支撑腿的分布是否稳定
   - 如果稳定，计算需要锯掉的总长度
4. **输出第一个找到的稳定方案**：由于从高到低尝试，第一个找到的稳定方案就是锯掉量最小的方案

### 稳定性检查算法

对于 $n$ 条均匀分布的桌腿，检查支撑腿分布稳定性的方法：

- 计算相邻支撑腿之间的 `gap`（以基本夹角为单位）
- 如果任意相邻支撑腿满足 $2 \times \texttt{gap} \geq n$，则夹角 $\geq 180^\circ$，不稳定
- 否则稳定

**数学原理**：
- 基本夹角 = $\frac{360^\circ}{n}$
- 两个支撑腿之间的夹角 = $\texttt{gap} \times \frac{360^\circ}{n}$
- 稳定性条件：$\texttt{gap} \times \frac{360^\circ}{n} < 180^\circ$
- 化简得：$2 \times \texttt{gap} < n$

### 复杂度分析

- 桌腿数量 $n \leq 50$
- 不同高度数量 $\leq n$
- 稳定性检查 $O(n)$
- 总复杂度 $O(n^3)$，完全可行

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isStable(const vector<int>& indices, int total) {
    int nOfIndices = indices.size();
    if (nOfIndices < 3) return false;
    // 每个腿之间的夹角是 360/n 度
    // 检查任意相邻支撑腿之间的夹角是否小于180度
    for (int i = 0; i < nOfIndices; i++) {
        int current = indices[i];
        int next = indices[(i + 1) % nOfIndices];
        // 计算两个支撑腿之间的夹角（以基本夹角为单位）
        int gap = 0;
        if (next > current) gap = next - current;
        else gap = next + total - current;
        if (2 * gap >= total) return false;
    }
    return true;
}

int main() {
    int n;
    bool firstCase = true;
    while (cin >> n && n != 0) {
        if (!firstCase) cout << endl;
        firstCase = false;
        vector<int> legs(n);
        for (int i = 0; i < n; i++) cin >> legs[i];
        // 从高到低尝试所有目标高度
        set<int> heights;
        for (int leg : legs) heights.insert(leg);
        for (auto it = heights.rbegin(); it != heights.rend(); it++) {
            int targetHeight = *it;
            vector<int> supportIndices;
            for (int i = 0; i < n; i++)
                if (legs[i] >= targetHeight)
                    supportIndices.push_back(i);
            if (isStable(supportIndices, n)) {
                int totalCut = 0;
                for (int leg : legs)
                    if (leg > targetHeight)
                        totalCut += leg - targetHeight;
                cout << totalCut << '\n';
                break;
            }
        }
    }
    return 0;
}
```

## 总结

本题的关键在于理解圆形桌子的几何稳定性条件，并设计高效的算法来寻找最优解。通过从高到低尝试目标高度，我们能够快速找到锯掉量最小的稳定方案。稳定性检查中的边界条件处理（$2 \times \texttt{gap} \geq n$）是解决问题的核心技巧。
