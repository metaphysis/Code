## 题目描述

给定一个最多包含 $16$ 个整数项的伪等式，运算符仅包含 `+` 和 `-`，且等式中恰好有一个 `=` 运算符。这些等式在数学上是错误的，我们需要**重新排列这些整数项的顺序**（但**不能改变运算符的顺序**），使得等式成立。

**输入格式：**
- 多行伪等式，每行一个
- 每个等式最多 $16$ 个整数项，每个整数小于 $100$
- 相邻项之间用一个运算符分隔，项和运算符周围可能有空格
- 每行中恰好有一个 `=` 运算符

**输出格式：**
- 对于每个输入的等式，输出一行
- 输出应包含与原等式相同的运算符和相同的项，运算符顺序必须保持不变，但项的顺序必须重新排列使得等式成立
- 任何能使等式成立的排列都是正确的，如果有多个解，输出任意一个即可
- 如果不存在这样的排列，则输出一行 `no solution`
- 每个运算符前后应恰好有一个空格，除此之外不应有其他空格

**样例输入：**
```
1 + 2 = 4 - 5 + 6
1 + 5 = 6 + 7
```

**样例输出：**
```
6 + 2 = 4 - 1 + 5
no solution
```

## 问题分析

### 1. 问题本质

我们需要重新排列数字的顺序，但不改变运算符的顺序，使得等式成立。这看起来像是一个排列搜索问题，但直接全排列 $16!$ 显然不可行。

### 2. 数学转化

考虑等式的一般形式：
$$
a_1 \ op_1 \ a_2 \ op_2 \ \cdots \ a_k \ = \ b_1 \ op_{k+1} \ b_2 \ op_{k+2} \ \cdots \ b_m
$$
其中 $op_i$ 为 `+` 或 `-`。

将等式重写为：
$$
a_1 \ op_1 \ a_2 \ op_2 \ \cdots \ a_k \ - \ (b_1 \ op_{k+1} \ b_2 \ op_{k+2} \ \cdots \ b_m) = 0
$$

这意味着：
- 等号左边的项保持原来的符号（`+` 对应正号，`-` 对应负号）
- 等号右边的项移到左边后符号取反（`+` 对应负号，`-` 对应正号）

设所有项移到左边后，我们有 $n$ 个数字 $x_1, x_2, \ldots, x_n$，每个数字前有一个符号 $s_i$（$+1$ 或 $-1$），我们需要重新排列这些数字，使得：
$$
\sum_{i=1}^{n} s_i \cdot x_{\pi(i)} = 0
$$
其中 $\pi$ 是一个排列。

### 3. 关键观察

设：
- 正号位置的数量为 $posCount$
- 负号位置的数量为 $negCount$
- 所有数字的总和为 $total$

那么等式 $\sum s_i \cdot x_i = 0$ 意味着：
$$
\text{正号位置数字和} - \text{负号位置数字和} = 0
$$
即：
$$
\text{正号位置数字和} = \text{负号位置数字和}
$$

又因为：
$$
\text{正号位置数字和} + \text{负号位置数字和} = total
$$
所以：
$$
\text{正号位置数字和} = \text{负号位置数字和} = \frac{total}{2}
$$

因此，问题转化为：
1. 需要找到一组数字放在正号位置（或负号位置），其和恰好为 $\frac{total}{2}$
2. 由于我们可以自由选择哪些数字放在哪个符号位置，设 $m = \min(posCount, negCount)$，那么我们需要找到 $m$ 个数字，其和为 $\frac{total}{2}$
3. 将这些数字分配给较少的符号位置，剩余数字自然分配给另一种符号位置

### 4. 算法设计

基于以上分析，我们可以设计如下算法：

1. **解析输入**：
   - 读取等式，提取所有数字
   - 根据运算符确定每个位置的符号（考虑等号左右的符号取反）
   - 统计 $posCount$ 和 $negCount$

2. **可行性检查**：
   - 计算所有数字总和 $total$
   - 如果 $total$ 为奇数，直接无解（因为需要分成两个相等的整数部分）
   - 设 $target = \frac{total}{2}$
   - 设 $m = \min(posCount, negCount)$

3. **搜索子集**：
   - 使用回溯法搜索 $m$ 个数字，使其和为 $target$
   - 由于 $n \leq 16$，$m \leq 8$，搜索空间 $C_{16}^8 = 12870$，加上剪枝后实际更小
   - 剪枝策略：排序数字，当当前数字太大时提前返回

4. **分配数字**：
   - 如果找到 $m$ 个数字和为 $target$
   - 将这些数字分配给较少的符号位置（如果 $posCount \leq negCount$ 则放正号位置，否则放负号位置）
   - 剩余数字分配给另一种符号位置
   - 由于数字在组内交换不影响总和，直接按找到的顺序分配即可

5. **输出结果**：
   - 按原始运算符顺序输出数字
   - 如果找不到符合条件的子集，输出 `no solution`

## 算法复杂度分析

- **时间复杂度**：主要在于回溯搜索，最坏情况 $O(C_n^m)$，其中 $n \leq 16$，$m \leq 8$，实际加上剪枝后更快
- **空间复杂度**：$O(n)$，用于存储数字、符号和搜索结果

## 代码实现

```cpp
// Equating Equations
// UVa ID: 10317
// Verdict: Accepted

// UVa Run Time: 0.070s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

vector<int> nums;          // 存储所有数字
vector<char> ops;          // 存储所有运算符（包括=）
vector<int> signs;         // 每个数字前的符号（+1或-1）
vector<int> solution;      // 存储最终的数字排列
bool found = false;        // 是否找到解

// 解析输入的等式
void parseEquation(const string& line) {
    nums.clear();
    ops.clear();
    signs.clear();
    solution.clear();
    found = false;
    
    stringstream ss(line);
    string token;
    vector<string> tokens;
    
    // 分割 tokens
    while (ss >> token) tokens.push_back(token);
    
    // 第一个数字
    nums.push_back(stoi(tokens[0]));
    signs.push_back(1);  // 第一个数字符号为正
    
    bool onLeft = true;
    int i = 1;
    
    while (i < tokens.size()) {
        string op = tokens[i++];
        
        if (op == "=") {
            ops.push_back('=');
            onLeft = false;
            // 等号后的第一个数字
            if (i < tokens.size()) {
                nums.push_back(stoi(tokens[i++]));
                signs.push_back(-1);  // 移到左边后符号为负
            }
            continue;
        }
        
        // 读取数字
        if (i < tokens.size()) {
            int num = stoi(tokens[i++]);
            nums.push_back(num);
            
            if (onLeft) {
                // 左边：+ 为正，- 为负
                signs.push_back(op == "+" ? 1 : -1);
            } else {
                // 右边：移到左边后符号取反
                signs.push_back(op == "+" ? -1 : 1);
            }
            ops.push_back(op[0]);
        }
    }
}

// 回溯查找 count 个数字和为 target
bool findSubset(int start, int count, int sum, int target, vector<bool>& selected) {
    if (count == 0) return sum == target;
    if (start >= (int)nums.size()) return false;
    
    // 剪枝：如果当前数字太大
    if (nums[start] > target - sum) {
        return findSubset(start + 1, count, sum, target, selected);
    }
    
    // 尝试选择当前数字
    selected[start] = true;
    if (findSubset(start + 1, count - 1, sum + nums[start], target, selected)) {
        return true;
    }
    selected[start] = false;
    
    // 不选当前数字
    return findSubset(start + 1, count, sum, target, selected);
}

void solve() {
    int n = nums.size();
    if (n == 0) return;
    
    // 统计正负号数量
    int posCount = 0, negCount = 0;
    for (int sign : signs) {
        if (sign == 1) posCount++;
        else negCount++;
    }
    
    // 计算总和
    int total = 0;
    for (int num : nums) total += num;
    
    // 总和必须是偶数
    if (total % 2 != 0) return;
    
    int target = total / 2;
    int m = min(posCount, negCount);
    
    // 对数字排序便于回溯剪枝
    sort(nums.begin(), nums.end());
    
    // 回溯查找 m 个数字和为 target
    vector<bool> selected(n, false);
    if (!findSubset(0, m, 0, target, selected)) return;
    
    // 分配数字到符号位置
    vector<int> posGroup, negGroup;
    for (int i = 0; i < n; i++) {
        if (selected[i]) {
            // 这些数字将分配给较少的符号位置
            if (posCount <= negCount) {
                posGroup.push_back(nums[i]);  // 放正号位置
            } else {
                negGroup.push_back(nums[i]);  // 放负号位置
            }
        } else {
            // 剩余数字分配给另一种符号位置
            if (posCount <= negCount) {
                negGroup.push_back(nums[i]);  // 放负号位置
            } else {
                posGroup.push_back(nums[i]);  // 放正号位置
            }
        }
    }
    
    // 直接分配
    solution.resize(n);
    int posIdx = 0, negIdx = 0;
    
    for (int i = 0; i < n; i++) {
        if (signs[i] == 1) {
            solution[i] = posGroup[posIdx++];
        } else {
            solution[i] = negGroup[negIdx++];
        }
    }
    
    found = true;
}

void printSolution() {
    if (!found) {
        cout << "no solution" << endl;
        return;
    }
    
    // 按照原始格式输出
    cout << solution[0];
    int idx = 1;
    for (char op : ops) {
        cout << " " << op << " " << solution[idx++];
    }
    cout << endl;
}

int main() {
    string line;
    while (getline(cin, line)) {
        if (line.empty()) continue;
        parseEquation(line);
        solve();
        printSolution();
    }
    return 0;
}
```

## 算法正确性证明

1. **充分性**：如果找到 $m$ 个数字和为 $\frac{total}{2}$，将这些数字分配给较少的符号位置，剩余数字分配给另一种符号位置，则：
   - 较少符号位置数字和 = $\frac{total}{2}$
   - 另一种符号位置数字和 = $total - \frac{total}{2} = \frac{total}{2}$
   - 带符号和 = $\frac{total}{2} - \frac{total}{2} = 0$
   因此等式成立。

2. **必要性**：如果存在解使得等式成立，则正号位置数字和 = 负号位置数字和 = $\frac{total}{2}$。考虑较少的符号位置（假设有 $m$ 个），这 $m$ 个位置上的数字和必须为 $\frac{total}{2}$。因此这样的子集必须存在。

## 总结

本题的关键在于将等式重组问题转化为子集和问题。通过数学分析，我们发现只需要找到 $\min(posCount, negCount)$ 个数字，其和为所有数字总和的一半。由于数字数量最多 $16$ 个，使用回溯法加上剪枝即可高效解决。算法时间复杂度可接受，空间复杂度低，能够处理题目中的所有测试用例。

这种解题思路展示了如何通过数学转化将看似复杂的排列问题简化为更易处理的组合问题，是算法竞赛中常用的技巧。
