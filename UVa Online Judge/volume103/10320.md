## 题目描述

在一个无限大的草场上有一栋长方形的房子，房子的长和宽分别为 $l$ 和 $w$。一头奶牛被拴在房子一角 $B$ 的柱子上，绳子的长度为 $R$。

如果没有房子，奶牛可以吃掉半径为 $R$ 的圆形区域内的所有草。但由于房子的存在，奶牛无法进入房子，绳子也不能穿过房子，因此奶牛能吃草的区域会减少。

你需要计算奶牛能够活动并吃草的区域面积。

### 输入格式
输入包含多行，每行三个浮点数 $l$、$w$ 和 $R$，所有数字均小于 $10000$。输入以文件结束符终止。

### 输出格式
对于每行输入，输出奶牛能够覆盖的区域面积，保留小数点后 $10$ 位。

### 样例输入
```
10 5 5
10 4 8
```

### 样例输出
```
58.9048622548
163.3628179867
```

## 题目分析

这是一个几何计算问题，需要精确计算奶牛在房子限制下能够活动的区域面积。我们可以将整个区域分解为几个基本几何形状的组合。

### 区域分解

1. **基础区域**：由于房子占据了一个象限，奶牛可以在其他三个象限内活动，形成 $\frac{3}{4}$ 圆区域。

2. **额外区域**：当绳子长度足够时，奶牛可以绕过房子的两边，形成两个额外的 $\frac{1}{4}$ 圆区域。

3. **重叠区域**：当绳子长度超过房子对角线时，两个额外的 $\frac{1}{4}$ 圆区域会重叠，需要减去重叠部分。

### 分情况讨论

根据绳子长度 $R$ 与房子尺寸的关系，分为四种情况：

#### 情况 1：$R \leq w$
奶牛只能吃到基础区域：
$$\text{面积} = \frac{3}{4}\pi R^2$$

#### 情况 2：$w < R \leq l$
奶牛可以吃到基础区域加上绕过宽边的额外区域：
$$\text{面积} = \frac{3}{4}\pi R^2 + \frac{1}{4}\pi (R - w)^2$$

#### 情况 3：$l < R \leq l + w$
奶牛可以吃到基础区域加上绕过长边和宽边的两个额外区域：
$$\text{面积} = \frac{3}{4}\pi R^2 + \frac{1}{4}\pi (R - l)^2 + \frac{1}{4}\pi (R - w)^2$$

#### 情况 4：$R > l + w$
奶牛可以吃到基础区域加上两个额外区域，但需要减去重叠部分：
$$\text{面积} = \frac{3}{4}\pi R^2 + \frac{1}{4}\pi (R - l)^2 + \frac{1}{4}\pi (R - w)^2 - \text{重叠面积}$$

### 重叠面积计算

当 $R > l + w$ 时，两个额外的 $\frac{1}{4}$ 圆区域会重叠。重叠区域的计算方法如下：

设：
- $R_1 = R - l$（绕过长边形成的 $\frac{1}{4}$ 圆半径）
- $R_2 = R - w$（绕过宽边形成的 $\frac{1}{4}$ 圆半径）
- $d = \sqrt{l^2 + w^2}$（两圆心距离）

计算步骤：
1. 计算两圆心连线与水平线的夹角：$\alpha = \arctan(\frac{l}{w})$
2. 利用余弦定理计算两个圆心到交点的连线夹角：
   - $\theta_1 = \arccos\left(\frac{R_1^2 + d^2 - R_2^2}{2R_1d}\right) - \alpha$
   - $\theta_2 = \arccos\left(\frac{R_2^2 + d^2 - R_1^2}{2R_2d}\right) - \left(\frac{\pi}{2} - \alpha\right)$
3. 计算两个扇形面积：
   - $\text{sector}_1 = \frac{1}{2}R_1^2\theta_1$
   - $\text{sector}_2 = \frac{1}{2}R_2^2\theta_2$
4. 计算四边形面积：
   - $\text{triangleArea} = \frac{1}{2}R_1w\sin\theta_1 + \frac{1}{2}R_2l\sin\theta_2$
5. 重叠面积 = $\text{sector}_1 + \text{sector}_2 - \text{triangleArea}$

## 解题思路

1. **预处理**：确保 $l$ 是长边，$w$ 是短边，方便后续计算。

2. **基础面积计算**：计算 $\frac{3}{4}$ 圆的面积作为基础区域。

3. **分情况处理**：
   - 如果 $R \leq w$，直接输出基础面积
   - 如果 $w < R \leq l$，加上绕过宽边的额外区域
   - 如果 $l < R \leq l + w$，加上绕过长边和宽边的两个额外区域
   - 如果 $R > l + w$，加上两个额外区域后减去重叠面积

4. **精度控制**：使用 `fixed` 和 `setprecision(10)` 确保输出精度。

## 复杂度分析

- **时间复杂度**：$O(1)$，每个测试用例只需要常数时间计算
- **空间复杂度**：$O(1)$，只使用常数个变量

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <algorithm>

using namespace std;

const double PI = acos(-1.0);

int main() {
    double L, W, R;
    
    while (cin >> L >> W >> R) {
        double area = 0.0;
        
        // 确保L是长边，W是短边
        if (L < W) swap(L, W);
        
        // 四分之三圆的基础面积
        area = 0.75 * PI * R * R;
        
        if (R <= W) {
            cout << fixed << setprecision(10) << area << endl;
            continue;
        }
        
        // 添加两个额外的四分之一圆面积
        if (W < R && R <= L) {
            area += 0.25 * PI * (R - W) * (R - W);
        } else {
            if (L < R && R <= L + W) {
                area += 0.25 * PI * ((R - L) * (R - L) + (R - W) * (R - W));
            } else if (L + W < R) {
                area += 0.25 * PI * ((R - L) * (R - L) + (R - W) * (R - W));
                
                double R1 = R - L;  // 绕过长边的圆的半径
                double R2 = R - W;  // 绕过宽边的圆的半径
                double d = sqrt(L * L + W * W);  // 两圆心距离
                
                // 计算两个圆心连线与水平线的夹角
                double alpha = atan2(L, W);
                
                // 利用余弦定理计算两个圆心到交点的连线夹角
                double angle1 = acos((R1 * R1 + d * d - R2 * R2) / (2 * R1 * d)) - alpha;
                double angle2 = acos((R2 * R2 + d * d - R1 * R1) / (2 * R2 * d)) - (PI / 2 - alpha);
                
                // 重叠区域面积 = 两个扇形面积之和
                double sector1 = R1 * R1 * angle1 / 2.0;
                double sector2 = R2 * R2 * angle2 / 2.0;
                
                // 四边形面积（两个三角形面积之和）
                double triangleArea = 0.5 * R1 * W * sin(angle1) + 0.5 * R2 * L * sin(angle2);
                
                area -= sector1 + sector2 - triangleArea;
            }
        }
        
        cout << fixed << setprecision(10) << area << endl;
    }
    
    return 0;
}
```
