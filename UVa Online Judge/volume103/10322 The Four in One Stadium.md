
> **摘要**：本题要求根据三个两两外切小圆的面积，计算包含它们的最小外接大圆半径 $R$、与三圆均外切的记分板圆半径 $Sr$，以及由三个切点构成的中立区三角形面积 $An$。解法上，先由面积反推半径并建立坐标系，利用笛卡尔圆定理求记分板圆半径，通过切点坐标的向量叉积求中立区面积；大圆半径则需枚举与哪两个小圆相切并验证第三圆是否被包含，若均不可行再退化为三圆同时相切的情形。整体每组数据仅需常数次运算，时间复杂度与空间复杂度均为 $O(1)$。

## 题目描述

国际足联希望建造一种能够同时进行三场比赛的体育场。该体育场由一个大的圆形区域构成，其内部包含三个较小的圆形体育场，三个小圆两两外切，切点分别为 $A$、$B$、$C$。在三个小圆之间的空隙中，还存在一个圆形的记分板区域，该区域与三个小圆均外切。三角形区域 $ABC$ 被称为中立区，国际足联官员将在此处观看比赛。

给定三个小圆的面积 $Ar_1$、$Ar_2$、$Ar_3$，要求计算：
- 大圆的半径 $R$（即包含三个小圆的最小外接圆半径）；
- 记分板区域的半径 $Sr$；
- 中立区的面积 $An$。

## 题目分析

三个小圆两两外切，其半径可由面积直接求出。记分板圆与三个小圆均外切，因此可利用笛卡尔圆定理（$\texttt{Descartes Circle Theorem}$）快速得到其半径。中立区是由三个切点构成的三角形，其面积可通过坐标计算获得。

对于大圆，其定义为包含三个小圆的最小圆。该圆不一定与三个小圆都相切，通常只与其中两个最大的小圆相切。因此，不能直接使用笛卡尔定理求解大圆半径，而需要枚举大圆与哪两个小圆相切，检查第三个圆是否被完全包含，并取所有可行方案中的最小半径。若三种方案均不可行（通常出现在三个半径相等或满足特殊比例时），则大圆与三个小圆均相切，此时可使用笛卡尔定理求其半径。

## 解题思路

### 步骤 $\texttt{1}$. 由面积计算半径

利用圆面积公式 $Ar_i = \pi r_i^2$，得到  
$$
r_i = \sqrt{\frac{Ar_i}{\pi}} \quad (i=1,2,3)
$$

### 步骤 $\texttt{2}$. 建立坐标系

将圆 $1$ 的圆心置于原点 $O_1(0,0)$，圆 $2$ 的圆心置于 $O_2(r_1+r_2,0)$。设圆 $3$ 的圆心为 $O_3(x_3, y_3)$，其中 $y_3>0$。由两个距离方程：
$$
x_3^2 + y_3^2 = (r_1+r_3)^2, \quad (x_3 - (r_1+r_2))^2 + y_3^2 = (r_2+r_3)^2
$$
可解得：
$$
x_3 = \frac{(r_1+r_2)^2 + (r_1-r_2)(r_1+r_2+2r_3)}{2(r_1+r_2)}, \quad
y_3 = \sqrt{(r_1+r_3)^2 - x_3^2}
$$

### 步骤 $\texttt{3}$. 计算记分板半径 $Sr$

记三个小圆的曲率为 $k_i = 1/r_i$（$i=1,2,3$）。设记分板圆的曲率为 $k_+$，根据笛卡尔圆定理，对于四个两两相切的圆（记分板圆与三个小圆外切），有：
$$
(k_1+k_2+k_3+k_+)^2 = 2(k_1^2+k_2^2+k_3^2+k_+^2)
$$
整理可得解：
$$
k_+ = S + 2\sqrt{D}, \quad \text{其中} \quad S = k_1+k_2+k_3, \quad D = k_1k_2+k_2k_3+k_3k_1
$$
因此
$$
Sr = \frac{1}{k_+} = \frac{1}{S+2\sqrt{D}}
$$

### 步骤 $\texttt{4}$. 计算中立区面积 $An$

三个切点 $P_{12}$、$P_{13}$、$P_{23}$ 的坐标如下：
- $P_{12}$ 在 $O_1O_2$ 上，距 $O_1$ 为 $r_1$：$P_{12} = (r_1, 0)$。
- $P_{13}$ 在 $O_1O_3$ 上，距 $O_1$ 为 $r_1$：$P_{13} = \frac{r_1}{r_1+r_3} O_3$。
- $P_{23}$ 在 $O_2O_3$ 上，距 $O_2$ 为 $r_2$：$P_{23} = O_2 + \frac{r_2}{r_2+r_3}(O_3 - O_2)$。

三角形面积用向量叉积计算：
$$
An = \frac{1}{2} \left| (P_{13} - P_{12}) \times (P_{23} - P_{12}) \right|
$$

### 步骤 $\texttt{5}$. 计算大圆半径 $R$

枚举大圆与哪两个小圆相切。对于每一对 $(i,j)$（$i<j$），假设大圆与圆 $i$、圆 $j$ 相切，则大圆半径 $R' = r_i + r_j$，其圆心位于线段 $O_iO_j$ 上，距 $O_i$ 为 $r_j$（因为大圆内切于这两个小圆，圆心到圆 $i$ 的圆心距离为 $R' - r_i = r_j$）。因此大圆圆心坐标为：
$$
O' = O_i + \frac{r_j}{r_i+r_j}(O_j - O_i)
$$
检查第三个圆 $k$ 是否被完全包含，即其圆心到 $O'$ 的距离 $d$ 满足 $d + r_k \le R' + \varepsilon$（$\varepsilon$ 为允许误差）。若满足，则该方案可行。记录所有可行方案中的最小 $R'$。

若三种方案均不可行，则大圆必与三个小圆均相切。此时利用笛卡尔定理，大圆的曲率为负值，其绝对值为 $|S - 2\sqrt{D}|$，因此
$$
R = \frac{1}{|S - 2\sqrt{D}|}
$$
（实际有效数据中 $S - 2\sqrt{D} < 0$，取绝对值后即为正半径。）

最终输出 $R$、$Sr$、$An$。

## 复杂度分析

- 时间复杂度：每组输入仅进行常数次算术运算和少量枚举（$3$ 种组合），故时间复杂度为 $O(1)$。
- 空间复杂度：仅使用若干变量，空间复杂度为 $O(1)$。

## 代码实现

```cpp
// The Four in One Stadium
// UVa ID: 10322

// UVa Run Time: 0.110s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    const double PI = acos(-1.0);
    const double EPS = 1e-10;
    double Ar1, Ar2, Ar3;
    cout << fixed << setprecision(10);
    while (cin >> Ar1 >> Ar2 >> Ar3) {
        double r1 = sqrt(Ar1 / PI);
        double r2 = sqrt(Ar2 / PI);
        double r3 = sqrt(Ar3 / PI);
        double r[3] = {r1, r2, r3};

        // 计算三个圆心坐标
        double d12 = r1 + r2;
        double x3 = (d12 * d12 + (r1 - r2) * (r1 + r2 + 2 * r3)) / (2 * d12);
        double y3 = sqrt((r1 + r3) * (r1 + r3) - x3 * x3);
        double Ox[3] = {0.0, d12, x3};
        double Oy[3] = {0.0, 0.0, y3};

        // 计算记分板半径 Sr
        double k1 = 1.0 / r1, k2 = 1.0 / r2, k3 = 1.0 / r3;
        double S = k1 + k2 + k3;
        double D = k1 * k2 + k2 * k3 + k3 * k1;
        double sqrtD = sqrt(D);
        double Sr = 1.0 / (S + 2.0 * sqrtD);

        // 计算中立区面积 An
        double p12x = r1, p12y = 0.0;
        double p13x = x3 * r1 / (r1 + r3);
        double p13y = y3 * r1 / (r1 + r3);
        double p23x = d12 + (r2 / (r2 + r3)) * (x3 - d12);
        double p23y = (r2 / (r2 + r3)) * y3;
        double v1x = p13x - p12x, v1y = p13y - p12y;
        double v2x = p23x - p12x, v2y = p23y - p12y;
        double An = 0.5 * fabs(v1x * v2y - v1y * v2x);

        // 计算大圆半径 R，枚举与哪两个小圆相切
        double R = 1e100;
        for (int i = 0; i < 3; ++i) {
            for (int j = i + 1; j < 3; ++j) {
                int k = 3 - i - j;
                double Rcur = r[i] + r[j];
                double t = r[j] / (r[i] + r[j]); // 圆心在 O_iO_j 上，距 O_i 为 r[j]
                double cx = Ox[i] + t * (Ox[j] - Ox[i]);
                double cy = Oy[i] + t * (Oy[j] - Oy[i]);
                double dx = Ox[k] - cx;
                double dy = Oy[k] - cy;
                double dist = sqrt(dx * dx + dy * dy);
                if (dist + r[k] <= Rcur + EPS)
                    R = min(R, Rcur);
            }
        }
        // 若无可行方案（如三圆相等），用笛卡尔定理
        if (R > 1e90) {
            double kNeg = S - 2.0 * sqrtD;
            R = 1.0 / fabs(kNeg);
        }
        cout << R << " " << Sr << " " << An << "\n";
    }
    return 0;
}
```

## 总结

本题核心在于几何关系的建模与分类讨论。关键点包括：
- 使用笛卡尔圆定理快速求解与三个外切圆相切的内切圆（记分板圆）半径。
- 对于大圆，必须区分“与两个圆相切”和“与三个圆相切”两种情形，并通过枚举和验证确定最小半径。
- 中立区面积通过切点坐标的向量叉积计算，避免了复杂的三角函数运算。
- 使用 $\texttt{double}$ 浮点数并保留 $10$ 位小数，配合 $\texttt{EPS}$ 容差处理精度问题，能够满足特殊判题程序的要求。
