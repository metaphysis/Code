## 题目描述

在组合数学中，我们经常使用 $nCr$ 这个术语，它表示从 $n$ 个不同元素中选取 $r$ 个元素的组合数。数学上，$nCr$ 定义为：

$$C(n,r) = \frac{n!}{(n-r)! \times r!}$$

本题涉及计算一个组合表达式，该表达式仅包含 $nCr$ 的乘法和除法运算。表达式由两部分组成：分子和分母。每部分可以是多个 $nCr$ 的乘积，也可以是单个 $nCr$。

例如，一个简单的表达式可能是：$nCr \times nCr / nCr$。

你需要判断该表达式的结果是否为整数（即分子是否能被分母整除）。如果是整数且结果的位数小于 $101$，则输出该结果；否则输出 $-1$。如果不能整除，则输出 $0$。

### 输入格式

输入以两个正整数 $N$ 和 $M$（$N,M \leq 100$）开始。接下来的 $N + M$ 行每行包含两个整数 $n$ 和 $r$。前 $2 \times N$ 个整数构成分子部分，接下来的 $2 \times M$ 个整数构成分母部分。保证不会出现无效的 $nCr$（即 $0 \leq r \leq n \leq 5000$）。

输入以 `EOF` 结束。

### 输出格式

对于每个测试用例，按题目要求在一行中输出结果。

## 题目分析

### 问题难点

1. **大数计算**：由于 $n$ 最大可达 $5000$，直接计算阶乘会导致数值溢出，即使使用 $64$ 位整数也无法存储如此大的数值。

2. **精度要求**：需要精确计算组合数的乘积和商，不能使用浮点数近似计算。

3. **位数限制**：需要判断结果是否超过 $100$ 位。

### 关键思路

1. **质因数分解**：将每个 $nCr$ 表示为质因数的指数形式，通过指数运算来避免直接计算大数。

2. **预处理优化**：预先计算所有可能用到的阶乘的质因数分解，避免重复计算。

3. **大整数乘法**：将质因数指数相乘的结果转换为大整数形式，并检查位数限制。

## 解题思路详解

### 步骤 1：质因数分解基础

组合数 $C(n,r)$ 可以表示为：

$$C(n,r) = \frac{n!}{r! \times (n-r)!}$$

通过对阶乘进行质因数分解，我们可以将组合数表示为质因数的乘积形式：

$$C(n,r) = \prod p_i^{e_i}$$

其中 $p_i$ 是质数，$e_i$ 是指数。

### 步骤 2：预处理阶乘的质因数分解

为了高效计算，我们预先计算从 $0$ 到 $5000$ 的所有阶乘的质因数分解：

- 使用埃拉托斯特尼筛法生成所有质数
- 对于每个 $n!$，其质因数分解可以通过 $(n-1)!$ 的分解加上 $n$ 的质因数分解得到

### 步骤 3：计算组合表达式的质因数分解

对于输入中的每个 $nCr$：
- 从预处理的阶乘分解中获取 $n!$、$r!$ 和 $(n-r)!$ 的分解
- 计算 $C(n,r) = \frac{n!}{r! \times (n-r)!}$ 的质因数分解

将所有分子的 $nCr$ 的质因数指数相加，所有分母的 $nCr$ 的质因数指数相减。

### 步骤 4：判断整除性和计算结果

- 如果任何质因数的指数为负，说明分母不能被分子整除，输出 $0$
- 否则，将所有质因数按其指数相乘得到最终结果
- 如果结果位数超过 $100$，输出 $-1$；否则输出结果

### 步骤 5：大整数处理

由于结果可能非常大，我们使用数组来模拟大整数乘法：
- 从 $1$ 开始，依次乘以每个质因数的相应次幂
- 使用进位法处理乘法运算
- 跟踪当前数字的位数，如果超过 $100$ 位则提前终止

## 算法复杂度分析

- **预处理**：$O(n \log \log n)$ 生成质数，$O(n \times \pi(n))$ 预处理阶乘分解，其中 $\pi(n)$ 是小于等于 $n$ 的质数个数
- **每次查询**：$O(N \times \pi(n) + M \times \pi(n))$ 处理输入，$O(\pi(n) \times L)$ 计算大整数，其中 $L$ 是结果的最大位数

由于 $n \leq 5000$，$\pi(5000) \approx 669$，该算法在时间限制内是可接受的。

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <cstring>
#include <map>
using namespace std;

const int MAX_N = 5000;

vector<int> primes;
vector<vector<int>> factorialExponents;

void generatePrimesAndFactorials() {
    vector<bool> isPrime(MAX_N + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i <= MAX_N; i++) {
        if (isPrime[i]) {
            primes.push_back(i);
            for (int j = i * i; j <= MAX_N; j += i) {
                isPrime[j] = false;
            }
        }
    }
    
    factorialExponents.resize(MAX_N + 1, vector<int>(primes.size(), 0));
    for (int n = 2; n <= MAX_N; n++) {
        factorialExponents[n] = factorialExponents[n - 1];
        int temp = n;
        for (size_t i = 0; i < primes.size() && primes[i] <= temp; i++) {
            int p = primes[i];
            while (temp % p == 0) {
                factorialExponents[n][i]++;
                temp /= p;
            }
        }
    }
}

vector<int> factorizeNcr(int n, int r) {
    vector<int> exp = factorialExponents[n];
    vector<int> expR = factorialExponents[r];
    vector<int> expNR = factorialExponents[n - r];
    
    for (size_t i = 0; i < primes.size(); i++) {
        exp[i] -= (expR[i] + expNR[i]);
    }
    return exp;
}

string multiplyBigInt(const vector<int>& exp) {
    double logSum = 0.0;
    for (size_t i = 0; i < exp.size(); i++) {
        if (exp[i] > 0) {
            logSum += exp[i] * log10(primes[i]);
        }
    }
    
    int estimatedDigits = (int)logSum + 1;
    
    if (estimatedDigits > 100) {
        return "-1";
    }
    
    int maxDigits = 150;
    vector<int> digits(maxDigits, 0);
    digits[0] = 1;
    int length = 1;
    
    for (size_t i = 0; i < exp.size(); i++) {
        if (exp[i] == 0) continue;
        
        int p = primes[i];
        for (int e = 0; e < exp[i]; e++) {
            int carry = 0;
            for (int j = 0; j < length; j++) {
                long long prod = digits[j] * (long long)p + carry;
                digits[j] = prod % 10;
                carry = prod / 10;
            }
            
            while (carry > 0 && length < maxDigits) {
                digits[length] = carry % 10;
                carry /= 10;
                length++;
            }
            
            if (length >= maxDigits && carry > 0) {
                return "-1";
            }
        }
    }
    
    string result;
    for (int i = length - 1; i >= 0; i--) {
        result += to_string(digits[i]);
    }
    
    if (result.length() > 100) {
        return "-1";
    }
    
    return result;
}

int main() {
    generatePrimesAndFactorials();
    int N, M;
    
    while (cin >> N >> M) {
        vector<int> numerator(primes.size(), 0);
        vector<int> denominator(primes.size(), 0);

        for (int i = 0; i < N; i++) {
            int n, r;
            cin >> n >> r;
            vector<int> exp = factorizeNcr(n, r);
            for (size_t j = 0; j < primes.size(); j++) {
                numerator[j] += exp[j];
            }
        }

        for (int i = 0; i < M; i++) {
            int n, r;
            cin >> n >> r;
            vector<int> exp = factorizeNcr(n, r);
            for (size_t j = 0; j < primes.size(); j++) {
                denominator[j] += exp[j];
            }
        }

        bool isInteger = true;
        vector<int> resultExp(primes.size(), 0);
        for (size_t i = 0; i < primes.size(); i++) {
            resultExp[i] = numerator[i] - denominator[i];
            if (resultExp[i] < 0) {
                isInteger = false;
                break;
            }
        }

        if (!isInteger) {
            cout << 0 << endl;
        } else {
            string resultStr = multiplyBigInt(resultExp);
            cout << resultStr << endl;
        }
    }
    
    return 0;
}
```

## 总结

本题通过质因数分解和预处理技术，巧妙地避免了直接计算大数阶乘的问题。算法核心在于将组合数的乘除运算转换为质因数的指数运算，从而在保证精度的同时提高了计算效率。大整数乘法的实现则确保了对于超大结果的正确处理和位数判断。

这种质因数分解的方法在处理组合数学中的大数计算问题时非常实用，是解决类似问题的经典思路。
