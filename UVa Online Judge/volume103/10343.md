## 题目描述

本题要求实现一个 $\texttt{Base64}$ 解码器，用于解码经过 $\texttt{Base64}$ 编码的字符串。$\texttt{Base64}$ 是一种将二进制数据编码成 $\texttt{ASCII}$ 字符的编码方式，常用于在文本协议（如电子邮件）中安全地传输二进制数据。

编码规则简述如下：
- 将每 $3$ 个字节（$24$ 位）的数据分为一组。
- 将这 $24$ 位分成 $4$ 个 $6$ 位的组。
- 每个 $6$ 位组映射到一个 $\texttt{Base64}$ 字符表中（包括 `A-Z`、`a-z`、`0-9`、`+`、`/`）。
- 如果原始数据长度不是 $3$ 的倍数，使用 `=` 进行填充。

本题输入由多个数据集组成，每个数据集以 `#` 结束。要求对每个数据集进行 $\texttt{Base64}$ 解码，并在输出解码结果后紧跟一个 `#`。

## 解题思路

### $\texttt{Base64}$ 解码原理

$\texttt{Base64}$ 解码是编码的逆过程：
1. 将每个 $\texttt{Base64}$ 字符根据映射表转换为 $6$ 位二进制值。
2. 将每 $4$ 个 $6$ 位组拼接成 $24$ 位。
3. 将这 $24$ 位拆分成 $3$ 个 $8$ 位字节，即还原出原始数据。

如果编码时使用了填充符 `=`，说明原始数据长度不是 $3$ 的倍数，解码时需要忽略这些填充符对应的位。

int findIndex(char c) {
    if (c >= 'A' && c <= 'Z') return c - 'A';
    if (c >= 'a' && c <= 'z') return c - 'a' + 26;
    if (c >= '0' && c <= '9') return c - '0' + 52;
    if (c == '+') return 62;
    if (c == '/') return 63;
    return -1;
}

string base64Decode(const string& encoded) {
    string decoded;
    int len = encoded.size();
    int i = 0;
    while (i < len) {
        int chunk = 0, count = 0, euqal = 0;
        for (int j = 0; j < 4 && i < len; i++, j++) {
            char c = encoded[i];
            if (c == '=') { euqal++; continue; }
            int idx = findIndex(c);
            if (idx != -1) {
                chunk = (chunk << 6) | idx;
                count++;
            }
        }
        if (euqal) {
            if (euqal == 2) decoded += (chunk >> 4) & 0xFF;
            if (euqal == 1) decoded += (chunk >> 8) & 0xFF, decoded += (chunk >> 4) & 0xFF;
            break;
        }
        if (count >= 2) decoded += (chunk >> 16) & 0xFF;
        if (count >= 3) decoded += (chunk >> 8) & 0xFF;
        if (count >= 4) decoded += chunk & 0xFF;
    }
    return decoded;
}
