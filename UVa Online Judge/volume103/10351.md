## 题目分析

本题要求计算将椭球体切割以适应长方体盒子时所需的切割面积。关键在于理解椭球与盒子的相对位置关系以及切割平面的确定方法。

### 问题建模

- **椭球体**：方程为 $\frac{(x-a)^2}{a^2} + \frac{(y-b)^2}{b^2} + \frac{(z-c)^2}{c^2} = 1$，其中 $a$、$b$、$c$ 是椭球的半轴长度
- **长方体盒子**：范围为 $0 \le x \le L$，$0 \le y \le W$，$0 \le z \le H$，其中 $L$、$W$、$H$ 是盒子的全长尺寸
- **对齐方式**：椭球与盒子在每个坐标轴方向上都从 $0$ 开始对齐

### 解题思路

1. **尺寸比较**：对于每个坐标轴方向，比较盒子全长与椭球全长
   - 如果 $L < 2a$，则在 $x$ 方向需要切割
   - 如果 $W < 2b$，则在 $y$ 方向需要切割  
   - 如果 $H < 2c$，则在 $z$ 方向需要切割

2. **切割平面确定**：根据题目保证，最多只需要在一个方向进行切割
   - $x$ 方向切割平面：$x = L$
   - $y$ 方向切割平面：$y = W$
   - $z$ 方向切割平面：$z = H$

3. **切割面积计算**：
   - **$x$ 方向切割**：切割平面与椭球的交线是一个椭圆，其面积为：
     $$\text{Area} = \pi \cdot b \cdot c \cdot \left[1 - \frac{(L-a)^2}{a^2}\right]$$
   - **$y$ 方向切割**：面积为：
     $$\text{Area} = \pi \cdot a \cdot c \cdot \left[1 - \frac{(W-b)^2}{b^2}\right]$$
   - **$z$ 方向切割**：面积为：
     $$\text{Area} = \pi \cdot a \cdot b \cdot \left[1 - \frac{(H-c)^2}{c^2}\right]$$

4. **算法流程**：
   - 读取输入数据（盒子尺寸和椭球尺寸）
   - 计算椭球的半轴长度
   - 按顺序检查三个方向是否需要切割
   - 计算相应方向的切割面积
   - 输出结果，保留 $6$ 位小数

// Cutting Diamonds

#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

const double PI = acos(-1.0); // 定义圆周率

int main() {
    double boxLength, boxWidth, boxHeight; // 盒子的长、宽、高（全长）
    double diamondX, diamondY, diamondZ;   // 椭球的 x、y、z 轴长度（全长）
    int setNumber = 0; // 测试用例编号
    
    // 循环读取输入直到文件结束
    while (cin >> boxLength >> boxWidth >> boxHeight >> diamondX >> diamondY >> diamondZ) {
        setNumber++; // 更新测试用例编号
        
        // 计算椭球的半轴长度
        double semiAxisX = diamondX / 2.0;
        double semiAxisY = diamondY / 2.0;
        double semiAxisZ = diamondZ / 2.0;
        
        double cutArea = 0.0; // 切割面积
        
        // 检查 x 方向是否需要切割
        if (boxLength < diamondX) {
            cutArea = PI * semiAxisY * semiAxisZ * (1.0 - (boxLength - semiAxisX) * (boxLength - semiAxisX) / (semiAxisX * semiAxisX));
        }
        // 检查 y 方向是否需要切割
        else if (boxWidth < diamondY) {
            cutArea = PI * semiAxisX * semiAxisZ * (1.0 - (boxWidth - semiAxisY) * (boxWidth - semiAxisY) / (semiAxisY * semiAxisY));
        }
        // 检查 z 方向是否需要切割
        else if (boxHeight < diamondZ) {
            cutArea = PI * semiAxisX * semiAxisY * (1.0 - (boxHeight - semiAxisZ) * (boxHeight - semiAxisZ) / (semiAxisZ * semiAxisZ));
        }
        
        // 输出结果
        cout << "Set #" << setNumber << "\n";
        cout << fixed << setprecision(6) << cutArea << "\n";
    }
    
    return 0;
}
