## 题目描述

超人拥有强大的能力，飞行速度比火箭还快！即使长城挡在他的路径上，他也能直接穿透而不影响速度。但如今在大城市中，他面临一个难以忍受的问题：某些区域被污染空气覆盖。当飞过这些区域时，他几乎无法呼吸，速度也会显著降低。他想通过计算在污染区域内的路径长度来确定是否能够穿过这些区域。

超人知道每个污染区域都是球体形状，也知道污染区域的位置，但他不知道如何计算在球体内的路径长度，所以他请求你帮他完成这个计算。

### 输入格式

- 包含多个数据集，以 $EOF$ 结束
- 每个数据集包含：
  - 第一行：城市名称（$1$-$8$ 个字母数字字符）
  - 第二行：超人路径的起点和终点坐标 $(x_1, y_1, z_1, x_2, y_2, z_2)$，他总是直线飞行
  - 第三行：污染区域数量（$1$ 到 $10$ 之间）
  - 接下来每行：每个区域的中心和半径 $(x, y, z, r)$，用空格分隔
  - **没有两个区域会相交**

### 输出格式

- 对于每个数据集，输出城市名称，然后输出路径在污染区域内的百分比
- 结果保留 $2$ 位小数

### 样例输入
```
Dhaka
10 10 10 30 10 10
2
15 10 10 5
25 10 10 5
Rio
10 10 10 30 10 10
1
20 10 5 10
```

### 样例输出
```
Dhaka
100.00
Rio
86.60
```

## 题目分析

本题需要计算一条三维空间中的线段（超人飞行路径）与多个球体（污染区域）相交的总长度，然后计算这个长度占整个路径长度的百分比。

### 关键观察

1. **球体不相交**：题目明确说明没有两个区域会相交，这简化了问题，因为我们可以独立计算与每个球体的相交长度，然后直接求和。

2. **几何问题**：核心是计算线段与球体的相交情况，这是一个经典的三维计算几何问题。

3. **数值精度**：结果需要保留 $2$ 位小数，因此需要使用浮点数计算。

## 解题思路

### 数学原理

对于每个球体，我们需要判断线段是否与球体相交，如果相交，计算相交线段的长度。

设：
- 线段起点为 $P_1 = (x_1, y_1, z_1)$
- 线段终点为 $P_2 = (x_2, y_2, z_2)$  
- 球体中心为 $C = (x_c, y_c, z_c)$
- 球体半径为 $r$

**参数化方法**：

线段的参数方程为：
$$P(t) = P_1 + t \cdot (P_2 - P_1), \quad t \in [0, 1]$$

球体的方程为：
$$|P - C|^2 = r^2$$

将线段方程代入球体方程：
$$|P_1 + t \cdot (P_2 - P_1) - C|^2 = r^2$$

令 $\vec{d} = P_2 - P_1$，$\vec{oc} = P_1 - C$，则方程变为：
$$|\vec{oc} + t \cdot \vec{d}|^2 = r^2$$

展开得：
$$|\vec{d}|^2 \cdot t^2 + 2(\vec{oc} \cdot \vec{d}) \cdot t + |\vec{oc}|^2 - r^2 = 0$$

这是一个关于 $t$ 的二次方程：
$$a t^2 + b t + c = 0$$

其中：
- $a = |\vec{d}|^2$
- $b = 2(\vec{oc} \cdot \vec{d})$  
- $c = |\vec{oc}|^2 - r^2$

**求解与判断**：

1. 计算判别式：$\Delta = b^2 - 4ac$
2. 如果 $\Delta < 0$，无实数解，线段与球体不相交
3. 如果 $\Delta \geq 0$，求根：
   $$t_1 = \frac{-b - \sqrt{\Delta}}{2a}, \quad t_2 = \frac{-b + \sqrt{\Delta}}{2a}$$

4. 计算有效交点：
   - 如果 $t_1 > 1$ 或 $t_2 < 0$，线段与球体不相交
   - 否则，取 $[0,1]$ 区间内的部分：
     $$t_{start} = \max(t_1, 0), \quad t_{end} = \min(t_2, 1)$$
   - 如果 $t_{start} > t_{end}$，不相交
   - 否则，相交长度为：$(t_{end} - t_{start}) \cdot |\vec{d}|$

### 算法步骤

1. 读取城市名称
2. 读取起点和终点坐标
3. 读取球体数量
4. 读取每个球体的中心和半径
5. 计算总路径长度
6. 对于每个球体，计算线段与球体的相交长度并累加
7. 计算百分比并输出结果

### 复杂度分析

- 对于每个数据集，需要处理最多 $10$ 个球体
- 每个球体的相交计算是 $O(1)$ 的
- 总体复杂度为 $O(n)$，其中 $n$ 是球体数量
- 由于 $n \leq 10$，算法非常高效

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    double x, y, z;
    Point(double x = 0, double y = 0, double z = 0) : x(x), y(y), z(z) {}
};

struct Sphere {
    Point center;
    double radius;
    Sphere(double x = 0, double y = 0, double z = 0, double r = 0) : center(x, y, z), radius(r) {}
};

Point operator-(const Point& a, const Point& b) {
    return Point(a.x - b.x, a.y - b.y, a.z - b.z);
}

double dot(const Point& a, const Point& b) {
    return a.x * b.x + a.y * b.y + a.z * b.z;
}

double length(const Point& a) {
    return sqrt(dot(a, a));
}

double segmentSphereIntersection(const Point& p1, const Point& p2, const Sphere& s) {
    Point dir = p2 - p1;
    Point oc = p1 - s.center;
    
    double a = dot(dir, dir);
    double b = 2 * dot(oc, dir);
    double c = dot(oc, oc) - s.radius * s.radius;
    
    double discriminant = b * b - 4 * a * c;
    
    if (discriminant < 0) return 0.0;
    
    discriminant = sqrt(discriminant);
    double t1 = (-b - discriminant) / (2 * a);
    double t2 = (-b + discriminant) / (2 * a);
    
    if (t1 > 1 || t2 < 0) return 0.0;
    
    t1 = max(t1, 0.0);
    t2 = min(t2, 1.0);
    
    if (t1 > t2) return 0.0;
    
    return (t2 - t1) * length(dir);
}

int main() {
    string cityName;
    while (cin >> cityName) {
        double x1, y1, z1, x2, y2, z2;
        cin >> x1 >> y1 >> z1 >> x2 >> y2 >> z2;
        Point start(x1, y1, z1), end(x2, y2, z2);
        
        int numSpheres;
        cin >> numSpheres;
        
        vector<Sphere> spheres(numSpheres);
        for (int i = 0; i < numSpheres; i++) {
            double x, y, z, r;
            cin >> x >> y >> z >> r;
            spheres[i] = Sphere(x, y, z, r);
        }
        
        double totalPathLength = length(end - start);
        double pollutedLength = 0.0;
        
        for (const Sphere& sphere : spheres) 
            pollutedLength += segmentSphereIntersection(start, end, sphere);
        
        double percentage = (pollutedLength / totalPathLength) * 100.0;
        
        cout << cityName << endl;
        cout << fixed << setprecision(2) << percentage << endl;
    }
    
    return 0;
}
```

## 总结

本题是一个典型的三维计算几何问题，主要考察：

1. **空间几何理解**：线段与球体的相交判断和长度计算
2. **数学建模能力**：将实际问题转化为数学模型
3. **编程实现**：正确处理浮点数运算和边界情况

关键点在于理解线段与球体相交的数学原理，并正确处理各种相交情况（完全相交、部分相交、不相交等）。由于球体不相交的约束，问题得到了简化，使得我们可以独立处理每个球体。
