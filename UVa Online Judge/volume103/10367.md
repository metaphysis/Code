## 题目描述

给定两个关于变量 $x$ 和 $y$ 的方程，求解 $x$ 和 $y$ 的值。

### 输入格式

第一行输入包含一个整数 $N$，表示测试用例的数量。每个测试用例包含两个方程，每个方程占一行。测试用例之间用一个空行分隔。

一个方程由两个或更多项组成，项之间通过加法、减法或等号运算符分隔。一个项可以是一个整数，或者是一个变量名（$x$ 或 $y$），前面可以有一个可选的负号或整数系数。

每个方程中恰好有一个等号。所有运算符周围都有空格，项内部没有空格。

### 输出格式

对于每个测试用例，输出两行，分别给出 $x$ 和 $y$ 的最简分数形式的值。如果 $x$ 或 $y$ 没有唯一的有理数值使得两个方程同时成立，则输出 `don't know`。测试用例之间输出一个空行。

## 题目分析

本题是一个线性方程组求解问题，需要处理以下关键点：

1. **方程解析**：将输入的字符串形式的方程转换为标准形式 $ax + by = c$
2. **方程组求解**：使用克莱姆法则求解二元一次方程组
3. **特殊情况处理**：包括无解、无穷多解等情况
4. **分数化简**：输出结果需要化为最简分数形式

### 解题思路

#### 1. 方程解析

对于每个方程，我们需要解析出 $x$ 的系数 $a$、$y$ 的系数 $b$ 和常数项 $c$。解析过程需要注意：

- 运算符周围有空格，但项内部没有空格
- 项可以是整数、$x$、$y$，前面可能有负号或系数
- 等号将方程分为左右两部分，等号右边的项需要取负号

#### 2. 线性方程组求解

对于方程组：
$$
\begin{cases}
a_1x + b_1y = c_1 \\
a_2x + b_2y = c_2
\end{cases}
$$

我们使用克莱姆法则：

- 计算行列式：$D = a_1b_2 - a_2b_1$
- 计算 $x$ 的分子行列式：$D_x = c_1b_2 - c_2b_1$
- 计算 $y$ 的分子行列式：$D_y = a_1c_2 - a_2c_1$

#### 3. 解的判断

- **唯一解**：当 $D \neq 0$ 时，$x = \frac{D_x}{D}$，$y = \frac{D_y}{D}$
- **无解**：当 $D = 0$ 且 $(D_x \neq 0$ 或 $D_y \neq 0)$ 时
- **无穷多解**：当 $D = 0$ 且 $D_x = 0$ 且 $D_y = 0$ 时

#### 4. 无穷多解的特殊情况

在无穷多解的情况下，某些变量可能仍有唯一解：

- 如果某个变量在所有方程中系数都为 $0$，但常数项不为 $0$，这会导致无解（不会进入无穷多解分支）
- 如果某个变量只有一个方程有约束，则该变量有唯一解
- 如果两个方程分别约束不同的变量，则两个变量都有唯一解
- 如果两个方程是同一个方程的倍数（都包含 $x$ 和 $y$），则两个变量都没有唯一解

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Equation {
    long long a, b, c; // a*x + b*y = c
    Equation() : a(0), b(0), c(0) {}
};

void parseEquation(const string& line, Equation& eq) {
    vector<string> tokens;
    stringstream ss(line);
    string token;
    while (ss >> token) tokens.push_back(token);

    int side = 1;
    for (size_t i = 0; i < tokens.size(); ++i) {
        if (tokens[i] == "=") { side = -1; continue; }
        if (tokens[i] == "+" || tokens[i] == "-") continue;

        int sign = (i > 0 && tokens[i - 1] == "-") ? -1 : 1;
        string term = tokens[i];
        
        if (term[0] == '-') { sign *= -1; term = term.substr(1); }
        
        long long coeff = 1;
        if (isdigit(term[0])) {
            size_t pos = 0;
            coeff = stoll(term, &pos);
            term = term.substr(pos);
        }
        coeff *= sign * side;

        if (term == "x") eq.a += coeff;
        else if (term == "y") eq.b += coeff;
        else eq.c -= coeff;
    }
}

string formatFraction(long long num, long long den) {
    if (den == 0) return "don't know";
    if (num == 0) return "0";
    long long g = __gcd(abs(num), abs(den));
    num /= g; den /= g;
    if (den < 0) { num = -num; den = -den; }
    return den == 1 ? to_string(num) : to_string(num) + "/" + to_string(den);
}

int main() {
    int n;
    cin >> n;
    cin.ignore();
    
    for (int caseNum = 0; caseNum < n; ++caseNum) {
        Equation eq1, eq2;
        string line;
        
        getline(cin, line); parseEquation(line, eq1);
        getline(cin, line); parseEquation(line, eq2);
        
        long long a1 = eq1.a, b1 = eq1.b, c1 = eq1.c;
        long long a2 = eq2.a, b2 = eq2.b, c2 = eq2.c;
        
        long long D = a1 * b2 - a2 * b1;
        long long Dx = c1 * b2 - c2 * b1;
        long long Dy = a1 * c2 - a2 * c1;
        
        string xStr = "don't know", yStr = "don't know";
        
        if (D != 0) {
            xStr = formatFraction(Dx, D);
            yStr = formatFraction(Dy, D);
        } else if (Dx != 0 || Dy != 0) {
            // 无解
        } else {
            // 无穷多解，检查每个变量是否被唯一确定
            bool bothEquationsHaveXY = (a1 != 0 && b1 != 0 && a2 != 0 && b2 != 0);
            
            if (!bothEquationsHaveXY) {
                // 至少有一个方程只约束一个变量
                if (a1 != 0 || a2 != 0) {
                    if ((a1 == 0 || a2 == 0) || (c1 * a2 == c2 * a1)) {
                        long long num = (a1 != 0) ? c1 : c2;
                        long long den = (a1 != 0) ? a1 : a2;
                        xStr = formatFraction(num, den);
                    }
                }
                if (b1 != 0 || b2 != 0) {
                    if ((b1 == 0 || b2 == 0) || (c1 * b2 == c2 * b1)) {
                        long long num = (b1 != 0) ? c1 : c2;
                        long long den = (b1 != 0) ? b1 : b2;
                        yStr = formatFraction(num, den);
                    }
                }
            }
            // 如果两个方程都包含x和y（是同一个方程的倍数），则两个变量都没有唯一解
        }
        
        cout << xStr << "\n" << yStr << "\n";
        if (caseNum < n - 1) {
            cout << "\n";
            getline(cin, line);
        }
    }
    return 0;
}
```

## 算法复杂度分析

- **时间复杂度**：$O(N \times L)$，其中 $N$ 是测试用例数量，$L$ 是方程的平均长度
- **空间复杂度**：$O(1)$，除了输入存储外只使用了常数空间

## 总结

本题的关键在于正确处理各种边界情况，特别是无穷多解时某些变量仍有唯一解的情况。通过仔细分析方程的结构，我们可以准确判断每个变量是否有唯一解，从而给出正确的输出。
