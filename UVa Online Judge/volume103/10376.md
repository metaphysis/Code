## 题目描述

$\texttt{Bill}$ 想要穿越一个 $1000 \times 1000$ 的正方形场地。场地中有 $n$ 条蛇（$n \leq 1000$），每条蛇位于坐标 $(x, y)$，攻击半径为 $r$。任何进入蛇攻击范围内的人都会被咬。

$\texttt{Bill}$ 必须从西边界（$x = 0$，$y \in [0, 1000]$）的某点进入，从东边界（$x = 1000$，$y \in [0, 1000]$） 的某点离开。要求判断 $\texttt{Bill}$ 是否能安全穿越，如果能，给出最靠北的入口和出口坐标（即 $y$ 坐标最大）。

## 输入格式

第一行一个整数 $T$，表示测试用例数量。每个测试用例第一行是整数 $n$，接下来 $n$ 行每行三个实数 $x, y, r$。输入中每个测试用例之间有一个空行。

## 输出格式

对于每个测试用例，如果能安全穿越，输出：
```
Bill enters at (0.00, y1) and leaves at (1000.00, y2).
```
其中 $y1$ 和 $y2$ 保留两位小数。如果不能穿越，输出：
```
Bill will be bitten.
```

## 题目分析

### 问题转化

这是一个典型的**几何连通性**问题，可以通过图论中的并查集（$\texttt{Union-Find}$）解决。

核心观察：
- 每条蛇的攻击范围是一个圆。
- 如果两个圆相交（圆心距 $\leq$ 半径和），它们就“连通”了，共同形成一个障碍区域。
- 如果一条蛇的攻击范围触及上边界（$y + r \geq 1000$）或下边界（$y - r \leq 0$），则该障碍区域与边界相连。

### 关键结论

**$\texttt{Bill}$ 能否穿越的判定条件**：
> 如果存在一个连通分量同时连接了上边界和下边界，那么这个分量就形成了一道从北到南的墙，完全阻断从左到右的通道，Bill 一定会被咬。

这是因为任何从左到右的路径都必须穿过这道墙，而墙内全是蛇的攻击范围。

**如果不存在这样的墙，则 $\texttt{Bill}$ 可以穿越**。此时需要找到最靠北的入口和出口。

### 入口与出口的确定

当 Bill 可以穿越时，我们仍然需要选择安全的进入点和离开点。

观察发现：**只有与上边界连通的圆才会影响北侧通道**。原因如下：
- 与上边界连通的圆会从北边向下延伸，阻挡了北侧的部分区域。
- 与下边界连通的圆只会影响南侧通道，而 Bill 可以从北侧绕过（因为北侧没有被完全阻断）。

因此，**入口和出口应该尽可能靠北，但要避开所有与上边界连通的圆在左/右边界上的覆盖区间**。

具体做法：
1. 找出所有与上边界连通的圆。
2. 对于左边界（$x = 0$），计算这些圆在该边界上的覆盖区间（圆与左边界的交点纵坐标区间）。
3. 合并重叠区间，未被覆盖的最高点即为最靠北的入口。
4. 对右边界（$x = 1000$）做相同处理，得到最靠北的出口。

## 解题思路

### 步骤 1：建图与并查集

- 将每条蛇视为一个节点。
- 遍历所有蛇对 $(i, j)$，如果两圆相交或相切，则将 $i$ 和 $j$ 合并到同一个连通分量中。

### 步骤 2：标记边界连通性

- 遍历每条蛇 $i$，找到其所在连通分量的根 $root = \texttt{find}(i)$。
- 如果蛇 $i$ 触及上边界（$y_i + r_i \geq 1000$），则标记 $\texttt{top}[root] = \texttt{true}$。
- 如果蛇 $i$ 触及下边界（$y_i - r_i \leq 0$），则标记 $\texttt{bottom}[root] = \texttt{true}$。

### 步骤 3：判断是否被阻断

- 遍历所有连通分量的根 $i$（即 $\texttt{find}(i) = i$ 的节点）。
- 如果 $\texttt{top}[i]$ 和 $\texttt{bottom}[i]$ 同时为 $\texttt{true}$，说明该分量连接了上下边界，$\texttt{Bill}$ 无法穿越，输出 `"Bill will be bitten."`。

### 步骤 4：寻找最靠北的入口和出口

- 再次标记与上边界连通的圆：$\texttt{top}[ \texttt{find}(i) ] = \texttt{true}$ 的蛇即为与上边界连通的蛇。
- 定义一个函数 $\texttt{findHighest}(boundaryX)$，用于计算在 $x = boundaryX$ 的边界上，未被与上边界连通的圆覆盖的最高点：
  - 遍历所有与上边界连通的蛇，计算它们与给定边界的交点纵坐标区间：  
    $$y_{\min} = \max(0,\ y_i - \sqrt{r_i^2 - (boundaryX - x_i)^2})$$  
    $$y_{\max} = \min(1000,\ y_i + \sqrt{r_i^2 - (boundaryX - x_i)^2})$$
  - 将这些区间存入数组，并按 $y_{\min}$ 排序。
  - 从 $y = 1000$ 向下扫描，跳过所有被覆盖的区间，第一个未被覆盖的点即为答案。
- 分别调用 $\texttt{findHighest}(0)$ 和 $\texttt{findHighest}(1000)$ 得到入口和出口。

### 复杂度分析

- 并查集合并：$O(n^2)$，$n \leq 1000$，可接受。
- 合并区间排序：$O(n \log n)$。
- 总复杂度：$O(T \cdot n^2)$。

## 代码实现

```cpp
// Snakes

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1100;
const double EPS = 1e-6;

struct Snake { double x, y, r; } snakes[MAXN];

int n, parent[MAXN];
vector<bool> top; // 标记每个连通分量是否与上边界相连

double dist(double x1, double y1, double x2, double y2) {
    return hypot(x1 - x2, y1 - y2);
}

int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
}

void unite(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra != rb) parent[ra] = rb;
}

// 计算在 x = boundaryX 的边界上，未被与上边界连通的圆覆盖的最高点
double findHighest(double boundaryX) {
    vector<pair<double, double>> cover;
    for (int i = 0; i < n; i++) {
        int root = find(i);
        if (!top[root]) continue; // 只考虑与上边界连通的圆
        double dx = abs(boundaryX - snakes[i].x);
        if (dx > snakes[i].r + EPS) continue; // 与边界无交点
        double dy = sqrt(max(0.0, snakes[i].r * snakes[i].r - dx * dx));
        double y1 = min(1000.0, snakes[i].y + dy);
        double y2 = max(0.0, snakes[i].y - dy);
        if (y1 >= y2 - EPS) cover.push_back({y2, y1});
    }
    sort(cover.begin(), cover.end());
    double res = 1000, cur = 1000;
    for (auto& seg : cover) {
        if (cur > seg.second + EPS) res = min(res, cur);
        cur = min(cur, seg.first);
    }
    if (cur > -EPS) res = min(res, cur);
    return res;
}

int main() {
    int t;
    cin >> t;
    for (int caseNum = 0; caseNum < t; caseNum++) {
        if (caseNum > 0) cout << endl;
        cin >> n;
        for (int i = 0; i < n; i++) cin >> snakes[i].x >> snakes[i].y >> snakes[i].r;
        
        // 初始化并查集
        for (int i = 0; i < n; i++) parent[i] = i;
        
        // 合并所有相交的圆
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                if (dist(snakes[i].x, snakes[i].y, snakes[j].x, snakes[j].y) <= snakes[i].r + snakes[j].r + 1e-9)
                    unite(i, j);
        
        // 标记每个连通分量是否连接上下边界
        top.assign(n, false);
        vector<bool> bottom(n, false);
        for (int i = 0; i < n; i++) {
            int root = find(i);
            if (snakes[i].y + snakes[i].r >= 1000 - EPS) top[root] = true;
            if (snakes[i].y - snakes[i].r <= 0 + EPS) bottom[root] = true;
        }
        
        // 检查是否存在连接上下边界的连通分量
        bool blocked = false;
        for (int i = 0; i < n; i++)
            if (find(i) == i && top[i] && bottom[i]) { blocked = true; break; }
        
        if (blocked) {
            cout << "Bill will be bitten." << endl;
            continue;
        }
        
        // 找到最靠北的入口和出口
        double entryY = findHighest(0);
        double exitY = findHighest(1000);
        
        printf("Bill enters at (0.00, %.2f) and leaves at (1000.00, %.2f).\n", entryY, exitY);
    }
    return 0;
}
```

## 总结

本题的核心思想是将几何问题转化为图论连通性问题：
1. 用并查集维护圆的连通性。
2. 检查是否存在连接上下边界的障碍链，若有则无法穿越。
3. 若能穿越，则所有与上边界连通的圆会在左右边界上形成阻挡区间，剩余的最高点即为答案。

这种方法避免了复杂的几何路径搜索，代码简洁高效，是解决此类问题的经典套路。
