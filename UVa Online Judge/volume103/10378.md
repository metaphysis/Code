## 题目描述

形如 $a \pm bi$ 的数字被称为**复数**，其中 $i = \sqrt{-1}$。在这个问题中，你需要找出 $(a \pm bi)^{1/n}$ 的所有值，即计算复数的 $n$ 次方根。

### 输入格式

输入文件包含多行数据。每行有两部分：
- 第一部分是一个形如 `a+bi` 或 `a-bi` 的复数
- 第二部分是一个整数 $n$ ($0 < n \leq 100$)

其中 $a$ 和 $b$ 是整数，且 $0 \leq |a|, |b| < 100$。输入以文件结束符终止。

### 输出格式

对于每一行输入，输出 $n + 2$ 行：
1. 第一行输出用例编号，格式为 `Case X:`（其中 $X$ 从 $1$ 开始）
2. 接下来的 $n$ 行输出该输入复数的 $n$ 次方根
3. 输出的复数应为 $x \pm yi$ 的形式，其中 $x$ 和 $y$ 是浮点数，保留三位小数
4. 根按**实部降序**排序，如果实部相同，则按**虚部降序**排序
5. 当打印值为 $0.000$ 时，应解释为正零，不能输出 `-0.000`
6. 在所有输出之后，打印一个空行

### 样例输入
```
3+4i 2
5-4i 3
```

### 样例输出
```
Case 1:
2.000+1.000i
-2.000-1.000i

Case 2:
1.810-0.414i
-0.546+1.775i
-1.264-1.361i
```

## 题目分析

### 复数与棣莫弗定理

复数可以表示为**极坐标形式**：
$$
z = a + bi = r(\cos\theta + i\sin\theta)
$$
其中：
- **模长** $r = \sqrt{a^2 + b^2}$
- **幅角** $\theta = \operatorname{atan2}(b, a)$

根据**棣莫弗定理**，复数的 $n$ 次方根有 $n$ 个不同的值：
$$
z^{1/n} = r^{1/n} \left[ \cos\left( \frac{\theta + 2k\pi}{n} \right) + i\sin\left( \frac{\theta + 2k\pi}{n} \right) \right], \quad k = 0, 1, \dots, n-1
$$

### 解题思路

1. **输入解析**：读取每行输入，解析出复数的实部 $a$、虚部 $b$ 和整数 $n$
2. **极坐标转换**：计算复数的模长 $r$ 和幅角 $\theta$
3. **计算根**：对于每个 $k = 0, 1, \dots, n-1$，计算：
   - 角度：$\phi_k = \frac{\theta + 2k\pi}{n}$
   - 实部：$x = r^{1/n} \cos(\phi_k)$
   - 虚部：$y = r^{1/n} \sin(\phi_k)$
4. **排序处理**：按照实部降序、虚部降序的顺序排序所有根
5. **格式化输出**：确保输出格式正确，避免出现 `-0.000`

### 关键难点

1. **浮点数精度处理**：由于浮点数计算的精度问题，需要：
   - 在排序时设置误差范围（$10^{-6}$）
   - 处理四舍五入后的 `-0.000` 情况

2. **输入格式解析**：需要正确处理 `a+bi` 和 `a-bi` 两种格式

3. **输出格式要求**：严格按照题目要求的格式输出，包括：
   - 保留三位小数
   - 运算符与操作数之间无空格
   - 正确的正零处理

## 算法实现

### 数据结构设计

使用 `Complex` 结构体存储复数，重载 `<` 运算符实现排序规则。

### 核心步骤

1. **解析复数**：通过查找 `+` 和 `-` 符号来分离实部和虚部
2. **计算所有根**：应用棣莫弗定理公式
3. **排序和格式化**：按照题目要求排序并格式化输出

## 复杂度分析

- **时间复杂度**：$O(n \log n)$，主要来自排序操作
- **空间复杂度**：$O(n)$，存储 $n$ 个根

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <cmath>
#include <algorithm>
#include <iomanip>
#include <sstream>

using namespace std;

struct Complex {
    double real;
    double imag;

    Complex(double r, double i) : real(r), imag(i) {}

    // 用于排序：实部降序，虚部降序
    bool operator<(const Complex& other) const {
        // 注意误差，否则可能难以获得 Accepted
        if (fabs(real - other.real) > 1e-6) {
            return real > other.real; // 实部降序
        }
        return imag > other.imag; // 虚部降序
    }
};

// 解析复数字符串，返回实部和虚部
pair<int, int> parseComplex(const string& s) {
    int a = 0, b = 0;
    size_t plusPos = s.find('+');
    size_t minusPos = s.find('-', 1); // 从位置1开始找，避免第一个负号

    if (plusPos != string::npos) {
        a = stoi(s.substr(0, plusPos));
        b = stoi(s.substr(plusPos + 1, s.size() - plusPos - 2)); // 去掉最后的 'i'
    } else if (minusPos != string::npos) {
        a = stoi(s.substr(0, minusPos));
        b = -stoi(s.substr(minusPos + 1, s.size() - minusPos - 2)); // 虚部为负
    }
    return {a, b};
}

// 格式化浮点数，避免 -0.000
string format(double value) {
    stringstream ss;
    ss << fixed << setprecision(3);
    ss << value;
    string result = ss.str();
    // 检查四舍五入后是否为 -0.000
    if (result == "-0.000") return "0.000";
    return result;
}

// 格式化复数输出
string formatComplex(const Complex& c) {
    string realStr = format(c.real);
    string imagStr = format(c.imag);
    if (imagStr == "0.000" || imagStr.front() != '-') return realStr + "+" + imagStr + "i";
    else return realStr + imagStr + "i";
}

int main() {
    string line;
    int caseNum = 0;

    while (getline(cin, line)) {
        caseNum++;

        // 解析输入行
        size_t spacePos = line.find(' ');
        string complexStr = line.substr(0, spacePos);
        int n = stoi(line.substr(spacePos + 1));

        auto [a, b] = parseComplex(complexStr);

        // 计算模长和幅角
        double r = sqrt(a * a + b * b);
        double theta = atan2(b, a);

        // 计算 r^(1/n)
        double rn = pow(r, 1.0 / n);

        vector<Complex> roots;
        for (int k = 0; k < n; k++) {
            double angle = (theta + 2 * k * M_PI) / n;
            double realPart = rn * cos(angle);
            double imagPart = rn * sin(angle);
            roots.emplace_back(realPart, imagPart);
        }

        // 排序
        sort(roots.begin(), roots.end());

        // 输出
        cout << "Case " << caseNum << ":" << endl;
        for (const auto& root : roots) {
            cout << formatComplex(root) << endl;
        }
        cout << endl;
    }

    return 0;
}
```
