[UVa 10379 Pit Stop Strategy](https://blog.csdn.net/metaphysis/article/details/161890797)

## 题目描述

赛车比赛中，赛车的速度受燃油重量影响。燃油越重，单圈时间越长，同时每圈油耗也越大。因此，携带尽可能少的燃油是有利的。可以在比赛开始时加载任意数量的燃油，也可以在比赛过程中进行加油进站。进站所消耗的时间随着加油量的增加而增加。你的任务是基于赛前测量的数据，为每辆车确定最优的加油和进站策略。

## 输入格式

每行输入包含以下 $7$ 个参数：

- 比赛圈数 $L$（整数，$L \le 100$）
- 空油箱时的理论单圈时间 $t_0$（浮点数，秒）
- 每升燃油导致的单圈时间增加量 $a$（浮点数，秒/升）
- 空油箱时的理论燃油消耗量 $c_0$（浮点数，升/圈）
- 每升燃油导致的燃油消耗增加量 $b$（浮点数，升/圈/升，严格小于 $1$）
- 不加任何燃油时的进站耗时 $p_0$（浮点数，秒）
- 每加一升燃油额外增加的进站时间 $p_1$（浮点数，秒/升）

输入包含多行，每行对应一辆车的测试数据。

## 输出格式

对于每一行输入，输出以下信息：

- 一行包含输入的 $7$ 个数字（保持原顺序，浮点数保留 $3$ 位小数）
- 一行包含三个结果：
  1. 总比赛时间（浮点数，保留 $3$ 位小数）
  2. 初始加油量（浮点数，保留 $3$ 位小数）
  3. 进站次数（整数）
- 对于每次进站，输出一行包含：
  1. 进站时已完成的总圈数（整数）
  2. 加油量（浮点数，保留 $3$ 位小数）

所有数字之间用一个空格分隔。

## 题目分析

本题是一个典型的**分段决策优化问题**。赛车需要完成 $L$ 圈，可以在开始时加载一定量的燃油，并在比赛过程中多次进站加油。每段行驶中，燃油量随圈数减少，影响后续圈的时间和油耗。

核心难点在于：

1. **燃油消耗与载油量耦合**：每圈油耗 $c = c_0 + b \cdot F$，其中 $F$ 是该圈开始时的燃油量。这意味着载油量越大，油耗越快。
2. **圈时与载油量耦合**：每圈时间 $t = t_0 + a \cdot F$，同样取决于圈开始时的燃油量。
3. **进站时间与加油量线性相关**：进站耗时 $= p_0 + p_1 \cdot \text{加油量}$。

我们需要选择：
- 初始加油量 $F_0$
- 进站次数 $k$
- 每次进站的时机（已完成圈数）
- 每次进站的加油量

使得**总时间（行驶时间 + 进站时间）最小**。

## 解题思路

### 1. 问题转化

将 $L$ 圈划分为若干**连续段**，每段跑 $m$ 圈，段内不加油。每段开始时的燃油量恰好能够支撑该段跑完（最后一圈结束时油量耗尽或接近零）。每段之间（除了第一段之前）需要一次进站，加油量为下一段所需的初始油量。

因此，问题转化为：
- 决定段数 $s = k + 1$
- 决定每段的圈数 $m_1, m_2, \dots, m_s$，满足 $m_1 + m_2 + \dots + m_s = L$，且 $m_i \ge 1$
- 最小化总时间：$\displaystyle \sum_{i=1}^{s} T(m_i) + \sum_{i=2}^{s} (p_0 + p_1 \cdot F(m_i))$

其中 $F(m)$ 是跑 $m$ 圈所需初始油量，$T(m)$ 是对应的行驶时间。

### 2. 预处理每段长度对应的油量和时间

对于给定的 $m$，我们需要计算 $F(m)$ 和 $T(m)$。

**物理模型**：设 $F_j$ 为第 $j$ 圈开始时的燃油量（$j$ 从 $0$ 到 $m-1$，$F_0$ 为初始油量）。每圈消耗与圈开始油量线性相关：
$$
F_{j+1} = F_j - (c_0 + b \cdot F_j) = (1 - b) \cdot F_j - c_0
$$
这是一个线性递推式。要求 $F_m = 0$（或略大于 $0$），解出 $F_0$。

由于 $b$ 可能不为 $0$，且递推涉及离散整数步，没有简单的封闭形式（封闭形式涉及浮点幂运算，误差较大）。因此，采用**二分答案**的方法：

- 二分初始油量 $F_0$
- 模拟 $m$ 圈的消耗过程，计算最终剩余油量
- 若剩余油量 $> 0$，说明 $F_0$ 太大，减小上界；否则增大下界

当二分收敛后，$F_0$ 即为所需初始油量。

行驶时间同样通过模拟计算：
$$
T(m) = \sum_{j=0}^{m-1} (t_0 + a \cdot F_j)
$$

由于 $L \le 100$，枚举所有 $m = 1 \dots L$ 并二分计算是可行的。

### 3. 动态规划求最优分段

设 $\textit{dp}[i]$ 表示完成前 $i$ 圈的最小总时间。转移时考虑最后一段的长度 $len$：

$$
\textit{dp}[i] = \min_{1 \le len \le i} \left\{ \textit{dp}[i - len] + T(len) + \textit{pit}(i, len) \right\}
$$

其中：
$$
\textit{pit}(i, len) = \begin{cases}
0 & \text{if } i - len = 0 \quad (\text{第一段无进站}) \\
p_0 + p_1 \cdot F(len) & \text{otherwise}
\end{cases}
$$

初始条件：$\textit{dp}[0] = 0$。

同时记录 $\textit{pre}[i] = len$ 用于回溯构造方案。

### 4. 方案回溯

从 $\textit{dp}[L]$ 开始，根据 $\textit{pre}$ 数组反向获取各段长度，再正向遍历生成进站信息：
- 进站圈数 = 之前所有段长度之和
- 进站加油量 = 下一段的 $F(len)$

### 5. 复杂度分析

- 预处理：$O(L \cdot \textit{iter} \cdot L) = O(L^2 \cdot \textit{iter})$，其中 $\text{iter} = 80$，$L \le 100$，约 $8 \times 10^5$ 次操作，非常快。
- 动态规划：$O(L^2)$。
- 总复杂度：$O(L^2)$，对每组输入可轻松应对。

## 代码实现

```cpp
// Pit Stop Strategy
// UVa ID: 10379
// Verdict: Accepted
// Submission Date: 2026-06-11
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
const double EPS = 1e-9;

int main() {
    int L;
    double t0, a, c0, b, p0, p1;
    while (cin >> L >> t0 >> a >> c0 >> b >> p0 >> p1) {
        printf("%d %.3f %.3f %.3f %.3f %.3f %.3f\n", L, t0, a, c0, b, p0, p1);
        
        // 预处理每段长度对应的油量和时间
        vector<double> fuel(L + 1), cost(L + 1);
        for (int len = 1; len <= L; ++len) {
            double low = 0, high = c0 * len * 100;
            for (int it = 0; it < 80; ++it) {
                double mid = (low + high) / 2, f = mid;
                for (int lap = 0; lap < len; ++lap) f -= c0 + b * f;
                (f > EPS ? high : low) = mid;
            }
            fuel[len] = (low + high) / 2;
            double f = fuel[len], t = 0;
            for (int lap = 0; lap < len; ++lap) t += t0 + a * f, f -= c0 + b * f;
            cost[len] = t;
        }
        
        // DP
        vector<double> dp(L + 1, 1e20);
        vector<int> pre(L + 1, -1);
        dp[0] = 0;
        for (int i = 1; i <= L; ++i) for (int len = 1; len <= i; ++len) {
            double pit = (i > len) ? (p0 + p1 * fuel[len]) : 0;
            double cand = dp[i - len] + cost[len] + pit;
            if (cand < dp[i] - EPS) dp[i] = cand, pre[i] = len;
        }
        
        // 回溯段长
        vector<int> segs;
        for (int i = L; i > 0; i -= pre[i]) segs.push_back(pre[i]);
        reverse(segs.begin(), segs.end());
        
        // 生成进站信息
        vector<pair<int, double>> stops;
        for (int i = 0, sum = 0; i < (int)segs.size(); ++i) {
            if (i > 0) stops.push_back({sum, fuel[segs[i]]});
            sum += segs[i];
        }
        
        // 输出
        printf("%.3f %.3f %d\n", dp[L], fuel[segs[0]], (int)stops.size());
        for (auto &s : stops) printf("%d %.3f\n", s.first, s.second);
    }
    return 0;
}
```

## 总结

本题的关键在于：
1. **将连续过程离散化为整圈模拟**，符合题目中“圈时由该圈开始油量决定”的规则。
2. **二分答案确定每段所需初始油量**，避免复杂解析公式带来的精度问题。
3. **动态规划处理分段决策**，自然涵盖所有可能的分段方式，无需手动枚举进站次数和分段模式。
4. **预处理 + $\texttt{DP}$ 的双层结构**，将原问题拆分为独立的子问题，降低了思维和编码复杂度。

此类问题常见于 $\texttt{ICPC/UVa}$ 等竞赛中，考察对离散动态系统建模能力以及 $\texttt{DP}$ 与数值方法的结合应用。掌握预处理 + $\texttt{DP}$ 的套路，对解决类似分段优化问题有重要参考价值。
