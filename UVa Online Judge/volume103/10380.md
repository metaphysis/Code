[UVa 10380 Shogi Tournament](https://blog.csdn.net/metaphysis/article/details/156871224)

## 题目描述

题目要求我们判断在一个部分完成的将棋双循环锦标赛中，某个特定选手 $p$ 是否还能在理论上赢得比赛，并且如果可以的话，计算该选手最多能领先第二名多少分。锦标赛采用双循环赛制，每对选手之间进行两场比赛，每场比赛的结果只能是获胜或失败（没有平局，如果出现平局会重赛）。已经进行了一部分比赛，剩余的比赛可以自由安排结果。

**输入格式**：
- 第一行包含一个整数 $n$ （ $n \leq 20$ ），表示锦标赛的数量。
- 每个锦标赛描述以一个空行开始，接着一行包含两个整数 $m$ （ $2 \leq m \leq 50$ ）和 $p$ （ $1 \leq p \leq m$ ），分别表示选手数量和目标选手编号。
- 然后是 $m$ 行，每行 $m$ 个条目，表示比赛的交叉表。第 $y$ 行第 $x$ 列的条目表示选手 $y$ 与选手 $x$ 之间的两场比赛结果：
  - `1` 表示 $y$ 获胜
  - `0` 表示 $y$ 失败
  - `--` 表示比赛尚未进行
  - 对角线上的条目总是 `--` ，因为选手不与自己比赛

**输出格式**：
- 如果选手 $p$ 不可能获胜，输出 `Player p can't win!`。
- 如果可以获胜，输出 `Player p can win with d point(s).` ，其中 $d$ 是最大领先分数，并输出完整的交叉表，包含每场比赛的结果和每位选手的最终得分。

## 题目分析

这是一个典型的**网络流/最大流**问题，需要判断在给定部分比赛结果的情况下，能否安排剩余比赛使目标选手成为第一名（或并列第一），并最大化其与第二名的分差。

### 关键难点

1. **双循环赛制**：每对选手进行两场比赛，每场比赛贡献 $1$ 分给胜者。
2. **已进行比赛固定**：已完成的比赛结果不能更改，只能安排未进行的比赛。
3. **最大化领先优势**：不仅需要判断能否获胜，还要找到最大可能的领先分数 $d$。
4. **多选手互动**：其他选手之间的比赛结果会影响第二名的分数，需要全局考虑。

### 核心思路

我们可以将问题转化为**最大流问题**：

1. **预处理目标选手**：首先将选手 $p$ 所有未进行的比赛都设置为 $p$ 获胜，计算他可能获得的最大分数 $W$。如果这样都不能确保 $p$ 是第一（或并列第一），则不可能获胜。

2. **网络流建模**：
   - **源点** → **比赛节点**：对于每场未进行的比赛，从源点到该比赛节点连一条容量为 $1$ 的边（因为每场比赛贡献 $1$ 分）。
   - **比赛节点** → **选手节点**：
     - 如果比赛结果已确定，则直接连接到获胜选手，容量为 $1$。
     - 如果比赛未确定，则连接到两名选手，容量各为 $1$（表示这 $1$ 分可以分配给任意一方）。
   - **选手节点** → **汇点**：
     - 对于选手 $p$：容量为 $W$ （目标分数）
     - 对于其他选手 $i$：容量为 $W - d$ （最大允许分数，其中 $d$ 是我们要最大化的领先分数）

3. **可行性检查**：如果最大流等于总比赛场数 $m \times (m - 1)$ ，说明所有比赛都能被合理分配，当前 $d$ 值可行。

4. **二分搜索最大 $d$**：对于给定的 $W$ ，我们可以使用二分搜索找到最大的 $d$ ，使得存在一种安排方式让选手 $p$ 获胜并领先 $d$ 分。

5. **构建具体方案**：找到最大 $d$ 后，从最终的网络流中提取具体的比赛分配结果，完成输出。

## 算法细节

### 网络流节点设计

设选手数量为 $m$ ，总比赛场数为 $matches = m \times (m - 1)$ （每对选手两场比赛）。

- 节点 $0$ ：源点
- 节点 $1$ 到 $matches$ ：比赛节点（每场比赛一个节点）
- 节点 $matches + 1$ 到 $matches + m$ ：选手节点
- 节点 $matches + m + 1$ ：汇点

### 边的建立

对于选手 $i$ 和 $j$ （ $i < j$ ）之间的两场比赛（ $k = 0, 1$ ）：

1. 计算比赛节点编号：$matchIdx = 2 \times (idxer - 1) + k + 1$ ，其中 $idxer$ 是 $(i, j)$ 对的索引。
2. 从源点到比赛节点添加容量为 $1$ 的边。
3. 根据比赛状态：
   - 如果 $board[i][j][k] = '-'$ （未进行）：添加两条边，分别到选手 $i$ 和 $j$ ，容量各为 $1$。
   - 如果 $board[i][j][k] = '1'$ （ $i$ 获胜）：添加一条边到选手 $i$ ，容量为 $1$。
   - 如果 $board[i][j][k] = '0'$ （ $j$ 获胜）：添加一条边到选手 $j$ ，容量为 $1$。

### 容量限制

- 选手 $p$ 到汇点的边容量：$W$ （目标选手的目标分数）
- 其他选手 $i$ 到汇点的边容量：$W - d$ （其他选手允许的最大分数）

### 可行性判断

如果最大流等于 $matches$ ，说明所有比赛都得到了合理分配，且每位选手的分数都在允许范围内，方案可行。

### 二分搜索策略

对于目标分数 $W$ ，我们希望在 $[0, W]$ 范围内找到最大的 $d$ 使得方案可行。使用二分搜索：
- 如果 $check(W, middle)$ 返回 `true` ，说明 $d = middle$ 可行，尝试更大的 $d$。
- 如果返回 `false` ，说明 $d = middle$ 不可行，尝试更小的 $d$。

### 结果提取

找到最大 $d$ 后，重新运行一次网络流，然后根据边的流量状态确定每场比赛的结果：
- 对于未确定的比赛，检查从比赛节点到两名选手的边。
- 如果到选手 $i$ 的边容量为 $0$ （流量已使用），则选手 $i$ 获胜。
- 否则，选手 $j$ 获胜。

## 时间复杂度分析

- 选手数量 $m \leq 50$ ，比赛场数 $O(m^2)$ 。
- 网络流使用 $\texttt{Dinic}$ 算法，复杂度 $O(E \sqrt{V})$ ，其中 $V = O(m^2)$ ， $E = O(m^2)$ 。
- 二分搜索需要 $O(\log W)$ 次网络流计算， $W$ 最大为 $2(m-1)$ 。
- 总体复杂度 $O(m^2 \sqrt{m^2} \log m) = O(m^3 \log m)$ ，对于 $m \leq 50$ 完全可行。

```cpp
// Shogi Tournament
// UVa ID: 10380

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
const int MAXN = 64, MAXV = 2600, MAXE = 20010;

int m, p;
string board[MAXN][MAXN];

struct Arc { int to, capacity, next; } arcs[MAXE * 2];
int head[MAXV], idx, source, sink;
int level[MAXV], current[MAXV];

void addEdge(int from, int to, int capacity) {
    arcs[idx] = {to, capacity, head[from]};
    head[from] = idx++;
    arcs[idx] = {from, 0, head[to]};
    head[to] = idx++;
}

bool bfs() {
    memset(level, -1, sizeof level);
    queue<int> q;
    level[source] = 0;
    q.push(source);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int i = head[u]; ~i; i = arcs[i].next) {
            int v = arcs[i].to;
            if (arcs[i].capacity > 0 && level[v] == -1) {
                level[v] = level[u] + 1;
                q.push(v);
                if (v == sink) return true;
            }
        }
    }
    return level[sink] != -1;
}

int dfs(int u, int flow) {
    if (u == sink) return flow;
    int volume = 0;
    for (int& i = current[u]; ~i; i = arcs[i].next) {
        int v = arcs[i].to, r = arcs[i].capacity;
        if (level[v] == level[u] + 1 && r > 0) {
            int volume = dfs(v, min(r, flow));
            if (volume > 0) {
                arcs[i].capacity -= volume;
                arcs[i ^ 1].capacity += volume;
                return volume;
            }
        }
    }
    return 0;
}

int maxFlow() {
    int flow = 0;
    while (bfs()) {
        for (int i = 0; i < MAXV; i++) current[i] = head[i];
        while (int delta = dfs(source, INF))
            flow += delta;
    }
    return flow;
}

bool check(int W, int d) {
    idx = 0;
    memset(head, -1, sizeof head);
    int matches = m * (m - 1), players = m;
    source = 0;
    sink = matches + players + 1;
    // 在源点和比赛之间连边
    int idxer = 1;
    for (int i = 1; i <= m; i++)
        for (int j = i + 1; j <= m; j++) {
            // 根据比赛得分情况在赛事和选手之间连边
            for (int k = 0; k < 2; k++) {
                int matchIdx = 2 * idxer - 1 + k;
                // 每次比赛可以提供 1 分
                addEdge(source, matchIdx, 1);
                char c = board[i][j][k];
                // 结果未定，则选手 i 和选手 j 都可得 1 分
                if (c == '-') {
                    addEdge(matchIdx, matches + i, 1);
                    addEdge(matchIdx, matches + j, 1);
                } else {
                    // 选手 i 获胜
                    if (c == '1') addEdge(matchIdx, matches + i, 1);
                    // 选手 j 获胜
                    else addEdge(matchIdx, matches + j, 1);
                }
            }
            idxer++;
        }
    // 在选手和汇点之间建边
    for (int i = 1; i <= m; i++) {
        // 选手 p 的得分为 W
        if (i == p) addEdge(matches + i, sink, W);
        // 其他选手的得分最大为 W - d
        else addEdge(matches + i, sink, W - d);
    }
    // 检查是否可以满流
    return maxFlow() == m * (m - 1);
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int T;
    cin >> T;
    while (T--) {
        // 读入数据
        cin >> m >> p;
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= m; j++)
                cin >> board[i][j];
        // 确定选手 p 的最大可能得分
        int W = 0;
        for (int i = 1; i <= m; i++) {
            if (i == p) continue;
            // 统计选手 p 的得分
            for (int j = 0; j < 2; j++) {
                if (board[p][i][j] == '-' || board[p][i][j] == '1') W++;
                // 将选手 p 未进行的比赛设置为获胜
                if (board[p][i][j] == '-') {
                    board[p][i][j] = '1';
                    board[i][p][j] = '0';
                }
            }
        }
        // 检查选手 p 所有未进行比赛均获胜是否能够获胜
        if (!check(W, 0)) cout << "Player " << p << " can't win!\n";
        else {
            int low = 0, high = W, answer = -1;
            while (low <= high) {
                int middle = (low + high) >> 1;
                if (check(W, middle)) {
                    answer = middle;
                    low = middle + 1;
                } else high = middle - 1;
            }
            check(W, answer);
            cout << "Player " << p << " can win with " << answer << " point(s).\n";
            cout << '\n';
            // 根据最终流网络中比赛到选手的有向弧流量状态来构建输出
            int idxer = 1;
            for (int i = 1; i <= m; i++)
                for (int j = i + 1; j <= m; j++) {
                        for (int k = 0; k < 2; k++) {
                            int matchIdx = 2 * idxer - 1 + k;
                            // 只记录正向弧
                            Arc arc;
                            for (int x = head[matchIdx]; ~x; x = arcs[x].next) {
                                if (x % 2 == 1) continue;
                                if (arcs[x].to == m * (m - 1) + i) arc = arcs[x];
                            }
                            // 如果正向弧流量已使用，则表明对应的选手获胜
                            if (board[i][j][k] == '-') {
                                board[i][j][k] = arc.capacity ? '0' : '1';
                                board[j][i][k] = arc.capacity ? '1' : '0';
                            }
                        }
                    idxer++;
                }
            for (int i = 1; i <= m; i++) {
                int points = 0;
                for (int j = 1; j <= m; j++) {
                    if (j > 1) cout << ' ';
                    cout << board[i][j];
                    for (int k = 0; k < 2; k++)
                        if (board[i][j][k] == '1')
                            points++;
                }
                cout << " : " << points << '\n';
            }
        }
        if (T) cout << '\n';
    }
    return 0;
}
```

## 总结

本题的难点在于如何将比赛分配问题转化为网络流问题。通过巧妙的建模，我们将每场比赛视为一个节点，将分数分配视为流量，通过容量限制来控制选手的最终得分。算法的核心步骤包括：

1. **预处理目标选手**，确定其最大可能得分。
2. **网络流建模**，将比赛结果分配转化为最大流问题。
3. **二分搜索**，找到最大的领先分数。
4. **结果提取**，从流网络中还原具体的比赛安排。

这种网络流建模技巧在解决类似的分配、调度问题中非常有用，值得深入理解和掌握。
