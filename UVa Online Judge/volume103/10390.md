[UVa 10390 Bean Counting](https://blog.csdn.net/metaphysis/article/details/154745559)

## 题目分析

### 问题描述

$\texttt{CSC}$ 举办了一个猜豆子数量的比赛。罐子里包含多种不同类型的豆子（用小写字母 `a-z` 表示），参赛者（用大写字母 `A-Z` 表示）需要猜测特定类型豆子的数量。每次猜测花费 $$2.00$，奖励规则如下：

- 如果猜测值与实际数量相差 $1$（多 $1$ 或少 $1$），获得 $1$ 份奖金份额
- 如果猜测值完全正确，获得 $2$ 份奖金份额

### 输入格式

- 第一行：测试用例数量
- 每个测试用例：
  - 第一行：豆子字符串（小写字母序列）
  - 后续行：参赛者猜测，格式为 `[参赛者字母] [类型1]:[数量1],[类型2]:[数量2],...`
  - 测试用例之间用空行分隔

### 输出要求

按字母顺序输出所有获奖者及其奖金金额，金额保留两位小数，测试用例输出之间用空行分隔。

## 解题思路

### 核心算法

1. **数据统计阶段**
   - 统计每种豆子的实际数量
   - 记录每个参赛者的"差 $1$"和"完全正确"的猜测次数

2. **奖金计算阶段**
   - 奖池总额 = 总猜测次数 × $$2.00$
   - 总份额数 = 所有参赛者的 $(OffOne + RightOn \times 2)$ 之和
   - 每人奖金 = $\frac{奖池总额}{总份额数} \times (OffOne + RightOn \times 2)$

### 关键步骤详解

#### 步骤1：读取和解析输入
- 使用 `getline()` 逐行读取输入，正确处理空行分隔
- 使用字符串流 `istringstream` 解析复杂的输入格式
- 用 `getline(stream, token, ',')` 处理逗号分隔的猜测对

#### 步骤2：豆子数量统计
- 遍历豆子字符串，使用 `map<char, int>` 统计每种字母的出现次数
- 时间复杂度：$O(n)$，其中 $n$ 是字符串长度

#### 步骤3：处理参赛者猜测
对于每个参赛者的每行输入：
1. 提取参赛者编号
2. 分割逗号分隔的猜测对
3. 对每个"类型:数量"对：
   - 解析豆子类型和猜测数量
   - 计算与实际数量的差值
   - 更新 `OffOne` 或 `RightOn` 计数

#### 步骤4：奖金计算
- 总猜测次数 `totalGuesses`：所有有效猜测对的数量
- 总份额 `totalShares`：$\sum (OffOne + 2 \times RightOn)$
- 每人奖金：$\frac{totalGuesses \times 2.0}{totalShares} \times (OffOne + 2 \times RightOn)$

### 复杂度分析

- **时间复杂度**：$O(n + m \times k)$，其中：
  - $n$：豆子字符串长度
  - $m$：参赛者数量
  - $k$：每个参赛者的平均猜测数（最多 $5$）
- **空间复杂度**：$O(26 + 26) = O(1)$，因为豆子类型和参赛者数量都最多 $26$ 种

### 注意事项

1. **输入格式处理**：特别注意测试用例间的空行分隔
2. **逗号分隔符**：使用 `getline()` 的 delim 参数正确处理逗号分隔
3. **金额精度**：使用 `fixed` 和 `setprecision(2)` 确保输出格式正确
4. **排序输出**：按参赛者字母顺序输出结果

```cpp
// Bean Counting
// UVa ID: 10390
// Verdict: Accepted

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <vector>
#include <map>
#include <sstream>
#include <iomanip>
#include <algorithm>

using namespace std;

struct Contestant {
    int offOne;
    int rightOn;
    Contestant() : offOne(0), rightOn(0) {}
};

int main() {
    int testCases;
    cin >> testCases;
    cin.ignore(1024, '\n'); // 忽略第一行后的换行
    cin.ignore(1024, '\n'); // 忽略第二行的空行
    
    for (int caseNum = 0; caseNum < testCases; ++caseNum) {
        if (caseNum > 0) {
            cout << endl; // 测试用例间空行
        }

        string beans;
        getline(cin, beans); // 读取豆子字符串
        
        // 统计每种豆子的实际数量
        map<char, int> actualCount;
        for (char c : beans) {
            actualCount[c]++;
        }

        map<char, Contestant> contestants;
        int totalGuesses = 0;

        string line;
        while (getline(cin, line)) {
            if (line.empty()) break; // 空行表示当前用例结束
            istringstream iss(line);
            char player;
            iss >> player;
            
            string guesses;
            getline(iss, guesses); // 读取剩余部分
            istringstream guessStream(guesses);

            string pair;
            while (getline(guessStream, pair, ',')) {
                char type;
                int guess;
                char colon;
                istringstream pairStream(pair);
                pairStream >> type >> colon >> guess;
                totalGuesses++;
                int actual = actualCount[type];
                int diff = abs(actual - guess);
                if (diff == 0) {
                    contestants[player].rightOn++;
                } else if (diff == 1) {
                    contestants[player].offOne++;
                }
            }
        }

        // 计算总份额
        double totalShares = 0.0;
        for (const auto& entry : contestants) {
            totalShares += entry.second.offOne + 2 * entry.second.rightOn;
        }

        // 计算每人奖金
        double pot = totalGuesses * 2.0;
        vector<pair<char, double>> results;
        for (const auto& entry : contestants) {
            double shares = entry.second.offOne + 2 * entry.second.rightOn;
            double winnings = (pot / totalShares) * shares;
            results.push_back({entry.first, winnings});
        }

        // 按字母顺序排序并输出
        sort(results.begin(), results.end());
        for (const auto& res : results) {
            cout << res.first << " " << fixed << setprecision(2) << res.second << endl;
        }
    }

    return 0;
}
```
