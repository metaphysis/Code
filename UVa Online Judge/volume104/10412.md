[UVa 10412 Big Big Trees](https://blog.csdn.net/metaphysis/article/details/155657065)

## 题目描述

森林中有 $n$ 棵树排成一条直线，相邻两棵树相距 $m$ 米。第 $i$ 棵树高 $h_i$ 米，在每个整数高度 $x$ （ $1 \leq x \leq h_i$ ）处，树的两侧各有一片长度为 $l_{i,x}$ 的大叶子，两片叶子左右对称。所有叶子的长度都小于 $m/2$ ，因此不同树的叶子在水平方向上永远不会重叠。

一只猴子从第 $1$ 棵树的树顶出发，要到达第 $n$ 棵树的树顶。它可以在叶子上或地面上从左向右行走，也可以爬上爬下，还可以从一片叶子的**右端点**跳到下一棵树上另一片叶子的**左端点**。跳跃必须满足以下条件：

1. 跳跃距离（直线距离）不超过 $k$ 米；
2. 跳跃线段不能包含任何其他叶子的任何点（起点和终点叶子的端点除外）；
3. 不能从叶子内部或地面起跳，也不能落在叶子内部或地面。

猴子必须恰好进行 $n-1$ 次移动（跳跃或行走），目标是**最小化它行走的总距离**（在叶子上或地面上的水平移动距离，不包括垂直攀爬的距离）。

### 输入格式

第一行是一个整数 $t$ （ $1 \leq t \leq 10$ ），表示测试用例数量。

每个测试用例的第一行包含三个整数 $n, m, k$ （ $1 \leq n, m, k \leq 1000$ ），分别表示树的数量、相邻树之间的距离、允许的最大跳跃距离。

接下来 $n$ 行，每行描述一棵树：第一个整数 $h$ （ $1 \leq h \leq 20$ ）是树的高度，后面跟着 $h$ 个整数 $l_1, l_2, \ldots, l_h$ （ $0 \leq l_i < m/2$ ），表示各个高度上叶子的长度。

### 输出格式

对于每个测试用例，输出一个整数，表示猴子行走的最小总距离。

### 样例输入
```
2
5 3 0
1 0 0
3 50 40
4 15 3 16 10
8 12 12 12 21 12 15 6 14
13 15 23 20 18 14 1 21 9 9 18 23 10 4
```

### 样例输出
```
5
28
```

## 题目分析

### 关键观察

1. **行走距离独立计算** ：猴子需要从第 $1$ 棵树顶到达第 $n$ 棵树顶，恰好进行 $n-1$ 次移动。由于垂直攀爬不计入行走距离，我们可以在每棵树内免费改变高度。因此，相邻两棵树之间的最小行走距离可以独立计算，然后累加得到总距离。

2. **移动方式** ：对于相邻的两棵树 $i$ 和 $i+1$ ，猴子有两种选择：
   - **叶子间跳跃** ：从树 $i$ 高度 $a$ 的叶子右端点，跳跃到树 $i+1$ 高度 $b$ 的叶子左端点。
   - **地面行走** ：如果无法在叶子间跳跃，猴子可以从地面走到下一棵树的地面，行走距离为 $m$ 。

3. **行走距离计算** ：
   - 叶子间跳跃：行走距离 = 从树 $i$ 高度 $a$ 移动到叶子右端点的水平距离 + 从树 $i+1$ 叶子左端点移动到高度 $b$ 的水平距离 = $l_{i,a} + l_{i+1,b}$ 。
   - 地面行走：行走距离 = $m$ 。

4. **跳跃条件检查** ：
   - 距离条件：跳跃的欧几里得距离 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2} \leq k$ 。
   - 不相交条件：跳跃线段不能包含任何其他叶子的任何点（起点和终点叶子的端点除外）。

### 解题思路

对于每对相邻的树 $i$ 和 $i+1$ ：
1. 初始化最小行走距离 $minDist = m$ （地面行走）。
2. 枚举所有可能的起跳高度 $a$ （ $1 \leq a \leq h_i$ ）和着陆高度 $b$ （ $1 \leq b \leq h_{i+1}$ ）。
3. 对于每个 $(a, b)$ 对：
   - 计算起点 $A$ （树 $i$ 高度 $a$ 的叶子右端点）和终点 $B$ （树 $i+1$ 高度 $b$ 的叶子左端点）。
   - 检查跳跃距离是否 $\leq k$ （比较平方值以避免浮点数）。
   - 检查跳跃线段 $AB$ 是否与任何其他叶子相交：
     - 对于树 $i$ 的所有高度 $h_1$ （ $h_1 \neq a$ ），检查 $AB$ 是否与叶子线段 $[L_1, R_1]$ 相交。
     - 对于树 $i+1$ 的所有高度 $h_2$ （ $h_2 \neq b$ ），检查 $AB$ 是否与叶子线段 $[L_2, R_2]$ 相交。
   - 如果所有检查通过，更新 $minDist = \min(minDist, l_{i,a} + l_{i+1,b})$ 。
4. 将 $minDist$ 累加到总行走距离中。

### 线段相交判断

使用**跨立试验**判断两条线段是否相交（包括端点重合的情况）：
1. **快速排斥实验** ：检查两条线段的包围盒是否相交，不相交则一定不相交。
2. **跨立试验** ：对于线段 $AB$ 和 $CD$ ，计算：
   - $c_1 = \text{cross}(A, B, C)$
   - $c_2 = \text{cross}(A, B, D)$
   - $c_3 = \text{cross}(C, D, A)$
   - $c_4 = \text{cross}(C, D, B)$
   如果 $c_1 \cdot c_2 < 0$ 且 $c_3 \cdot c_4 < 0$ ，则线段相交。
3. **端点检查** ：如果任何端点位于另一条线段上（叉积为 $0$ 且在包围盒内），也认为相交。

其中叉积 $\text{cross}(P, Q, R) = (Q_x - P_x) \times (R_y - P_y) - (Q_y - P_y) \times (R_x - P_x)$ 。

### 复杂度分析

- 树的数量 $n \leq 1000$ ，高度 $h \leq 20$ 。
- 每对相邻树需要枚举 $O(h^2)$ 个高度组合，每个组合需要 $O(h)$ 次相交检查。
- 每次相交检查是 $O(1)$ 的。
- 总复杂度： $O(t \times n \times h^3) \approx O(10 \times 1000 \times 20^3) = O(8 \times 10^7)$ ，在合理范围内。

## 代码实现

注意：题目描述中虽然说明只能跳 $n-1$ 次，且不能从地面起跳或者落到地面，但是实际测试数据，可以从树干高度 $0$ 通过地面走到下一棵树的高度 $0$，行走距离为 $m$，因此，总存在解，而且当两棵树之间无法跳跃时，总可以选择走地面。因为这个原因，一直无法获得 $\texttt{Accepted}$。

```cpp
// Big Big Trees
// UVa ID: 10412
// Verdict: Accepted
// Submission Date: 2025-12-07
// UVa Run Time: 0.030s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
    Point(int x = 0, int y = 0) : x(x), y(y) {}
};

// 计算叉积 (p1-p0) × (p2-p0)
long long cross(const Point& p0, const Point& p1, const Point& p2) {
    return (long long)(p1.x - p0.x) * (p2.y - p0.y) - (long long)(p1.y - p0.y) * (p2.x - p0.x);
}

// 快速排斥实验：检查两个线段 bounding box 是否相交
bool boundingBoxOverlap(const Point& a1, const Point& a2, const Point& b1, const Point& b2) {
    return max(a1.x, a2.x) >= min(b1.x, b2.x) &&
           max(b1.x, b2.x) >= min(a1.x, a2.x) &&
           max(a1.y, a2.y) >= min(b1.y, b2.y) &&
           max(b1.y, b2.y) >= min(a1.y, a2.y);
}

// 检查点是否在线段上（包括端点）
bool onSegment(const Point& p, const Point& a, const Point& b) {
    // 先检查 bounding box
    if (p.x < min(a.x, b.x) || p.x > max(a.x, b.x) ||
        p.y < min(a.y, b.y) || p.y > max(a.y, b.y)) {
        return false;
    }
    // 叉积为0表示三点共线
    return cross(a, b, p) == 0;
}

// 检查线段A1A2是否与线段B1B2相交（包括端点在另一线段上）
bool segmentsIntersect(const Point& A1, const Point& A2, const Point& B1, const Point& B2) {
    // 快速排斥实验
    if (!boundingBoxOverlap(A1, A2, B1, B2)) return false;
    long long c1 = cross(A1, A2, B1);
    long long c2 = cross(A1, A2, B2);
    long long c3 = cross(B1, B2, A1);
    long long c4 = cross(B1, B2, A2);
    // 跨立试验：如果两个叉积异号，则线段相交
    if (c1 * c2 < 0 && c3 * c4 < 0) return true;
    // 检查端点是否在另一线段上
    if (c1 == 0 && onSegment(B1, A1, A2)) return true;
    if (c2 == 0 && onSegment(B2, A1, A2)) return true;
    if (c3 == 0 && onSegment(A1, B1, B2)) return true;
    if (c4 == 0 && onSegment(A2, B1, B2)) return true;
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t; cin >> t;
    while (t--) {
        int n, m, k; cin >> n >> m >> k;
        vector<vector<int>> leaf(n + 1);
        vector<int> h(n + 1);
        for (int i = 1; i <= n; i++) {
            cin >> h[i];
            leaf[i].resize(h[i] + 1);
            leaf[i][0] = 0;
            for (int j = 1; j <= h[i]; j++) cin >> leaf[i][j];
        }
        int totalWalk = 0;
        // 处理每一对相邻的树
        for (int i = 1; i < n; i++) {
            int treePos1 = (i - 1) * m;
            int treePos2 = i * m;
            int minDist = INT_MAX;
            // 枚举左侧树起跳高度和右侧树着陆高度
            for (int a = 1; a <= h[i]; a++) {
                // 起跳点：左侧树叶子的右端点
                Point A(treePos1 + leaf[i][a], a);
                for (int b = 1; b <= h[i + 1]; b++) {
                    // 着陆点：右侧树叶子的左端点
                    Point B(treePos2 - leaf[i + 1][b], b);
                    // 检查跳跃距离（平方）
                    long long dx = B.x - A.x;
                    long long dy = B.y - A.y;
                    long long distSq = dx * dx + dy * dy;
                    if (distSq > (long long)k * k) continue;
                    bool valid = true;
                    // 检查与左侧树其他叶子的相交
                    for (int height = 1; height <= h[i]; height++) {
                        if (height == a) continue; // 跳过起跳叶子
                        // 叶子的两个端点
                        Point leafLeft(treePos1 - leaf[i][height], height);
                        Point leafRight(treePos1 + leaf[i][height], height);
                        // 检查跳跃线段是否与叶子线段相交
                        if (segmentsIntersect(A, B, leafLeft, leafRight)) {
                            valid = false;
                            break;
                        }
                    }
                    if (!valid) continue;
                    // 检查与右侧树其他叶子的相交
                    for (int height = 1; height <= h[i + 1]; height++) {
                        if (height == b) continue; // 跳过着陆叶子
                        Point leafLeft(treePos2 - leaf[i + 1][height], height);
                        Point leafRight(treePos2 + leaf[i + 1][height], height);
                        if (segmentsIntersect(A, B, leafLeft, leafRight)) {
                            valid = false;
                            break;
                        }
                    }
                    if (!valid) continue;
                    // 计算行走距离
                    int walkDist = leaf[i][a] + leaf[i + 1][b];
                    minDist = min(minDist, walkDist);
                }
            }
            // 若无法跳跃，可以直接走地面。WTF！
            if (minDist == INT_MAX) minDist = m;
            totalWalk += minDist;
        }
        cout << totalWalk << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于理解猴子移动方式的独立性，以及正确处理叶子间跳跃的几何约束。通过枚举所有可能的跳跃组合，并利用跨立试验精确判断线段相交，可以在合理的时间内找到最小行走距离。当地面行走作为保底方案时，确保问题总是有解。

算法的时间复杂度为 $O(t \cdot n \cdot h^3)$ ，其中 $h \leq 20$ ，能够高效处理题目给定的数据范围。
