[UVa 10417 Gift Exchanging](https://blog.csdn.net/metaphysis/article/details/155035295)

## 题目描述

你正在参加一个圣诞派对，除了你之外，其他 $n$ 位客人都带来了一个装在盒子里的精美礼物。派对结束后，所有礼物被收集并放在桌子上，每个人可以选择一个礼物带回家。作为第一个选择礼物的人，你有机会拿到你最好朋友（即第一位客人）带来的礼物。

礼物盒子有 $5$ 种类型，分别用 $A, B, C, D, E$ 表示。你知道每位客人带来每种类型盒子的概率。你需要确定应该选择哪种类型的盒子，使得拿到最好朋友礼物的概率最大，并输出这个最大概率。

## 输入格式

- 第一行：整数 $t$ ($1 \leq t \leq 10$)，测试用例数量
- 每个测试用例：
  - 第一行：整数 $n$ ($1 \leq n \leq 12$)，客人数量
  - 第二行：$5$ 个整数，表示每种类型礼物的数量，总和为 $n$
  - 接下来 $n$ 行：每行 $5$ 个浮点数（小数点后一位），表示该客人带来每种类型盒子的概率，每行概率总和为 $1.0$
  - 第一位客人是你的最好朋友

## 输出格式

对于每个测试用例，输出一个整数（表示盒子类型编号，$A=1, B=2, C=3, D=4, E=5$），一个空格，以及保留 $3$ 位小数的概率。如果有多个最佳选择，输出编号最小的。

## 题目分析

### 问题本质

这是一个条件概率计算问题。我们需要计算在已知最终礼物分布的情况下，选择某种类型的盒子时，这个具体盒子是最好朋友带来的概率。

关键点在于：
1. 我们只能看到盒子的类型，无法看到内部
2. 我们需要考虑所有可能的礼物分配方案
3. 对于每种有效的分配方案，计算选择某类盒子时拿到朋友礼物的条件概率

### 概率计算

设我们选择类型 $g$ 的盒子，则拿到朋友礼物的概率为：

$$P_g = \frac{\sum_{\text{有效分配}} P(\text{分配}) \times \frac{\text{朋友带来的}g\text{型盒子数}}{\text{总的}g\text{型盒子数}}}{\sum_{\text{有效分配}} P(\text{分配})}$$

其中：
- 有效分配：满足给定礼物数量分布的分配方案
- $P(\text{分配})$：该分配方案出现的概率
- 分子：在所有有效分配中，我们随机选择类型 $g$ 的一个盒子，它是朋友礼物的期望概率
- 分母：所有有效分配的概率总和（归一化因子）

### 算法选择

由于 $n \leq 12$，且只有 $5$ 种礼物类型，我们可以使用深度优先搜索 ($\texttt{DFS}$) 来枚举所有可能的分配方案。

算法步骤：
1. 使用 $\texttt{DFS}$ 生成所有满足礼物数量分布的分配方案
2. 对于每种有效分配，计算其出现概率
3. 对于每种礼物类型，累计条件概率
4. 选择条件概率最大的礼物类型

## 解题思路

### 1. 状态表示

- `assignment[i]`：第 $i$ 位客人带来的礼物类型
- `currentCount[5]`：当前已分配的各类型礼物数量
- `totalProb`：所有有效分配的总概率
- `giftProb[5]`：选择各类礼物拿到朋友礼物的概率累计值

### 2. 深度优先搜索

递归函数 `dfs(person, currentCount)`：
- 如果 `person == n`：检查当前分配是否有效（`currentCount == cnt`）
  - 如果有效：计算该分配的概率，更新 `totalProb` 和 `giftProb`
- 否则：为当前客人选择所有可能的礼物类型（需满足数量限制）

### 3. 概率计算细节

对于有效分配方案：
- 分配概率 $P = \prod_{i=0}^{n-1} prob[i][assignment[i]]$
- 对于类型 $g$：朋友带来的 $g$ 型盒子数 ÷ 总的 $g$ 型盒子数 = 我们拿到朋友礼物的概率
- 累计：`giftProb[g] += P × (朋友g型盒子数 / cnt[g])`

### 4. 最终决策

对于每种礼物类型 $g$：
- 最终概率 = `giftProb[g] / totalProb`
- 选择概率最大的类型（编号最小优先）

## 复杂度分析

- 最坏情况：分配方案数为组合数，但由于 $n \leq 12$ 且只有 $5$ 种类型，实际可接受
- 空间复杂度：$O(n)$ 用于递归栈和状态存储
- 时间复杂度：与有效分配方案数成正比，在题目约束下可行

## 代码实现

```cpp
// Gift Exchanging
// UVa ID: 10417
// Verdict: Accepted
// Submission Date: 2025-11-19
// UVa Run Time: 0.440s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int t, n;
int cnt[5];
double prob[12][5];
vector<int> assignment;
double totalProb;
double giftProb[5];

void dfs(int person, vector<int>& currentCount) {
    if (person == n) {
        bool valid = true;
        for (int i = 0; i < 5; i++) {
            if (currentCount[i] != cnt[i]) {
                valid = false;
                break;
            }
        }
        if (!valid) return;
        
        double p = 1.0;
        for (int i = 0; i < n; i++) {
            p *= prob[i][assignment[i]];
        }
        totalProb += p;
        
        for (int g = 0; g < 5; g++) {
            if (cnt[g] > 0) {
                int friendGiftCount = 0;
                for (int i = 0; i < n; i++) {
                    if (assignment[i] == g && i == 0) {
                        friendGiftCount++;
                    }
                }
                giftProb[g] += p * (friendGiftCount * 1.0 / cnt[g]);
            }
        }
        return;
    }
    
    for (int g = 0; g < 5; g++) {
        if (currentCount[g] < cnt[g]) {
            assignment[person] = g;
            currentCount[g]++;
            dfs(person + 1, currentCount);
            currentCount[g]--;
        }
    }
}

int main() {
    cin >> t;
    while (t--) {
        cin >> n;
        for (int i = 0; i < 5; i++) cin >> cnt[i];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < 5; j++) cin >> prob[i][j];
        
        assignment.resize(n);
        totalProb = 0.0;
        for (int i = 0; i < 5; i++) giftProb[i] = 0.0;
        
        vector<int> currentCount(5, 0);
        dfs(0, currentCount);
        
        int bestGift = -1;
        double bestProb = -1.0;
        for (int g = 0; g < 5; g++) {
            if (cnt[g] > 0) {
                double p = giftProb[g] / totalProb;
                if (p > bestProb) {
                    bestProb = p;
                    bestGift = g;
                }
            }
        }
        
        cout << bestGift + 1 << " " << fixed << setprecision(3) << bestProb << endl;
    }
    return 0;
}
```

另外一种使用动态规划并结合备忘技巧的实现。

```cpp
// Gift Exchanging
// UVa ID: 10417
// Verdict: Accepted
// Submission Date: 2025-11-19
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int n;
int gift[5];
double probability[15][5];
double dp[13][13][13][13][13];
bool visited[13][13][13][13][13];

// 计算在剩余礼物数量和当前处理到第几个人时，符合数量分布的概率总和
double dfs(int a, int b, int c, int d, int currentPerson) {
    // 计算E类型的数量
    int e = n - currentPerson - a - b - c - d;
    // 检查记忆化
    double &result = dp[a][b][c][d][currentPerson];
    if (visited[a][b][c][d][currentPerson]) return result;
    // 所有人都分配完毕
    if (currentPerson == n) return 1.0;
    visited[a][b][c][d][currentPerson] = true;
    result = 0.0;
    int remaining[5] = {a, b, c, d, e};
    // 枚举当前人选择的所有可能礼物类型
    for (int giftType = 0; giftType < 5; giftType++)
        // 如果该类型还有剩余且当前人可能选择它
        if (remaining[giftType] > 0 && probability[currentPerson][giftType] > 0) {
            // 选择这个礼物
            remaining[giftType]--;
            // 递归计算剩余情况的概率
            result += probability[currentPerson][giftType] * dfs(remaining[0], remaining[1], remaining[2], remaining[3], currentPerson + 1);
            // 回溯
            remaining[giftType]++;
        }
    return result;
}

int main() {
    int testCases;
    cin >> testCases;
    while (testCases--) {
        cin >> n;
        // 读取各类型礼物数量
        for (int i = 0; i < 5; i++) cin >> gift[i];
        // 读取每个人的概率分布
        for (int i = 0; i < n; i++)
            for (int j = 0; j < 5; j++)
                cin >> probability[i][j];
        // 初始化记忆化数组
        memset(visited, 0, sizeof(visited));
        // 计算所有可能分配的总概率
        double totalProbability = dfs(gift[0], gift[1], gift[2], gift[3], 0);
        double maxProbability = -1.0;
        int bestGiftType = -1;
        // 枚举我们选择的各种礼物类型
        for (int giftType = 0; giftType < 5; giftType++) {
            if (gift[giftType] == 0) continue;
            // 我们拿走一个该类型的礼物
            gift[giftType]--;
            // 计算：朋友带这种类型 × 剩余人分配的概率
            double numerator = probability[0][giftType] * dfs(gift[0], gift[1], gift[2], gift[3], 1);
            // 恢复礼物数量
            gift[giftType]++;
            // 我们随机拿一个该类型的盒子，是朋友的概率 = 1/该类型总数
            numerator /= gift[giftType];
            // 计算条件概率
            double conditionalProbability = numerator / totalProbability;
            // 更新最佳选择
            if (conditionalProbability > maxProbability) {
                maxProbability = conditionalProbability;
                bestGiftType = giftType + 1;  // 转换为1-based编号
            }
        }
        // 输出结果
        cout << bestGiftType << " " << fixed << setprecision(3) << maxProbability << endl;
    }
    return 0;
}
```
## 总结

本题通过枚举所有可能的礼物分配方案，并计算条件概率，解决了在有限信息下做出最优决策的问题。$\texttt{DFS}$ 算法在此规模下完全可行，概率计算部分需要仔细处理同类型多个盒子的情况。
