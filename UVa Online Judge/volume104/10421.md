[UVa 10421 Critical Wave](https://blog.csdn.net/metaphysis/article/details/154498330)

## 题目分析

本题要求我们在二维平面上选择一系列点，构成一条特殊的"波状"曲线，使得包含的给定点数量最多。曲线需要满足以下条件：

1. 存在一条水平直线 $y = a$（称为主轴线）
2. 曲线上所有点的 $y$ 坐标只能是 $a - 1$ 或 $a + 1$
3. 曲线上任意两个点的 $x$ 坐标不能相同
4. 曲线上相邻的两个点的 $y$ 坐标必须不同（即交替出现在 $a - 1$ 和 $a + 1$ 上）

**输入格式**：多个测试用例，每个测试用例首先给出点的数量 $N$，接着 $N$ 行每行包含两个整数表示点的 $x$ 和 $y$ 坐标。

**输出格式**：对于每个测试用例，输出能够包含在曲线中的最大点数。

## 解题思路

### 关键观察

1. **主轴线 $a$ 的确定**：由于曲线上点的 $y$ 坐标只能是 $a - 1$ 或 $a + 1$，且给定的点坐标都是整数，因此 $a$ 必须是整数。对于任意一个点 $(x, y)$，可能的 $a$ 值只有 $y + 1$ 和 $y - 1$ 两种。

2. **问题转化**：对于固定的 $a$，我们只需要考虑那些 $y$ 坐标为 $a - 1$ 或 $a + 1$ 的点。然后在这些点中找出最长的交替序列，即点的 $y$ 坐标在 $a - 1$ 和 $a + 1$ 之间交替出现，且 $x$ 坐标严格递增。

3. **处理重复 $x$ 坐标**：同一个 $x$ 坐标可能同时存在 $a - 1$ 和 $a + 1$ 的两个点，但根据题目要求，我们只能选择其中一个。

### 算法设计

对于每个候选的 $a$ 值：

1. **收集有效点**：找出所有 $y = a - 1$（下线点）和 $y = a + 1$（上线点）的点。

2. **按 $x$ 坐标分组**：使用映射记录每个 $x$ 坐标是否有下线点和/或上线点。

3. **动态规划**：按 $x$ 坐标递增顺序处理，维护两个状态：
   - `lastLower`：以下线点结尾的最长序列长度
   - `lastUpper`：以上线点结尾的最长序列长度

4. **状态转移**：
   - 如果当前 $x$ 只有下线点：`newLastLower = max(lastLower, lastUpper + 1)`
   - 如果当前 $x$ 只有上线点：`newLastUpper = max(lastUpper, lastLower + 1)`
   - 如果当前 $x$ 同时有下线点和上线点：分别考虑选择下线点或上线点的情况

5. **最终答案**：取所有候选 $a$ 值对应的最长序列长度的最大值。

### 复杂度分析

- 候选 $a$ 值的数量最多为 $2N$
- 对于每个 $a$，处理时间为 $O(N \log N)$（主要是排序）
- 总时间复杂度为 $O(N^2 \log N)$，在 $N \leq 1000$ 时是可接受的

## 代码实现

```cpp
// Critical Wave

#include <iostream>
#include <vector>
#include <algorithm>
#include <map>
#include <set>

using namespace std;

struct Point {
    int x, y;
};

// 对于给定的主轴线 a，计算能选择的最长交替序列长度
int solveForAxis(const vector<Point>& points, int axisValue) {
    // 使用映射记录每个 x 坐标是否有下线点 (axisValue - 1) 和上线点 (axisValue + 1)
    map<int, pair<bool, bool>> xCoordMap;
    
    // 遍历所有点，收集符合条件的点
    for (const auto& point : points) {
        if (point.y == axisValue - 1) {
            xCoordMap[point.x].first = true;  // 标记有下线点
        } else if (point.y == axisValue + 1) {
            xCoordMap[point.x].second = true; // 标记有上线点
        }
    }
    
    // 如果没有符合条件的点，直接返回 0
    if (xCoordMap.empty()) return 0;
    
    // 动态规划状态：以下线点/上线点结尾的最长序列长度
    int lastLower = 0, lastUpper = 0;
    
    // 按 x 坐标递增顺序处理
    for (const auto& entry : xCoordMap) {
        bool hasLower = entry.second.first;   // 当前 x 是否有下线点
        bool hasUpper = entry.second.second;  // 当前 x 是否有上线点
        
        int newLastLower = lastLower;  // 新的下线点状态
        int newLastUpper = lastUpper;  // 新的上线点状态
        
        if (hasLower && hasUpper) {
            // 情况 1：当前 x 同时有下线点和上线点，只能选择其中一个
            int candidateLower = 1;  // 选择下线点的候选值
            if (lastUpper > 0) candidateLower = lastUpper + 1;
            
            int candidateUpper = 1;  // 选择上线点的候选值
            if (lastLower > 0) candidateUpper = lastLower + 1;
            
            newLastLower = max(newLastLower, candidateLower);
            newLastUpper = max(newLastUpper, candidateUpper);
        } else if (hasLower) {
            // 情况 2：只有下线点
            if (lastUpper > 0) {
                newLastLower = max(newLastLower, lastUpper + 1);
            } else {
                newLastLower = max(newLastLower, 1);
            }
        } else if (hasUpper) {
            // 情况 3：只有上线点
            if (lastLower > 0) {
                newLastUpper = max(newLastUpper, lastLower + 1);
            } else {
                newLastUpper = max(newLastUpper, 1);
            }
        }
        
        // 更新状态
        lastLower = newLastLower;
        lastUpper = newLastUpper;
    }
    
    return max(lastLower, lastUpper);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int pointCount;
    while (cin >> pointCount) {
        vector<Point> points(pointCount);
        set<int> candidateAxisValues;
        
        // 读入点数据并生成候选的 a 值
        for (int i = 0; i < pointCount; i++) {
            cin >> points[i].x >> points[i].y;
            // 对于每个点 (x, y)，可能的 a 值为 y + 1 或 y - 1
            candidateAxisValues.insert(points[i].y + 1);
            candidateAxisValues.insert(points[i].y - 1);
        }
        
        int maxPoints = 0;
        // 遍历所有候选的 a 值，找出能包含最多点的曲线
        for (int axisValue : candidateAxisValues) {
            maxPoints = max(maxPoints, solveForAxis(points, axisValue));
        }
        
        cout << maxPoints << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于将问题转化为对于每个可能的 $a$ 值，在两条平行线 $y = a - 1$ 和 $y = a + 1$ 上寻找最长的交替序列。通过动态规划的方法，我们可以在 $O(N \log N)$ 时间内对每个 $a$ 求解，最终取所有 $a$ 中的最大值作为答案。

算法的时间复杂度为 $O(N^2 \log N)$，空间复杂度为 $O(N)$，在题目给定的数据范围内能够高效运行。
