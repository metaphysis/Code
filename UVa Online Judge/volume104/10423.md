[UVa 10423 Peter Takes a Tramway](https://blog.csdn.net/metaphysis/article/details/154799084)

## 题目描述

$\texttt{Main Town}$ 拥有一个发达的有轨电车网络系统。由于该镇大多数重要建筑都位于主街沿线，几乎所有电车线路都会经过这条街。主街上的所有站点按数字编号：$0, 1, 2, \dots$。所有电车都从编号为 $0$ 的站点进入主街，并向编号更大的站点行驶。

每条电车线路（用一个数字标识）在 $0$ 号站点都贴有一个时刻表，给出该线路电车在一个小时内离开 $0$ 号站点的具体分钟数。

$\texttt{Peter}$ 在某个小时的 $m$ 分钟（$0 \leq m < 60$）到达 $0$ 号站点，并乘坐**第一辆**离开 $0$ 号站点的电车。如果 $\texttt{Peter}$ 到达 $0$ 号站点的时刻恰好有电车出发，他可以成功登上该电车。

他在**下一个站点**下车，并等待**下一辆**到达该站点的电车，然后乘坐它继续前往下一个站点。他重复这个过程，直到到达编号为 $n$ 的站点（$0 < n < 1000000000$）。

需要确定 $\texttt{Peter}$ 最终是乘坐哪条电车线路到达站点 $n$ 的。

### 输入格式

输入包含多个测试用例：
- 每个用例的第一行给出 $t$，表示电车线路的数量（$0 < t < 30$）
- 接下来的 $t$ 行，每行格式为：`线路编号: 出发分钟1 出发分钟2 ... -1`
- 然后一行给出 $m$ 和 $n$
- 输入以 $t = 0$ 结束

### 输出格式

对每个测试用例，输出：
```
Case X: Peter arrives at stop N by tram L.
```

## 题目分析

### 关键观察

1. **电车运行规律**：所有电车从 $0$ 号站出发，速度相同，向编号更大的站点行驶
2. **出发时刻唯一性**：所有电车的出发时刻都不相同，且在一个小时内循环
3. **$\texttt{Peter}$ 的乘车模式**：
   - 在 $0$ 号站：乘坐第一辆出发时间 $\geq m$ 的电车
   - 在后续每个站：下车后立即乘坐下一辆到达的电车
4. **数学规律**：由于所有电车速度相同且出发时刻固定，$\texttt{Peter}$ 的乘车序列会形成一个循环

### 解题思路

1. **数据预处理**：
   - 将所有电车的出发时刻与对应的线路编号配对
   - 按出发时间从小到大排序

2. **寻找起始电车**：
   - 在排序后的时刻表中找到第一个出发时间 $\geq m$ 的电车
   - 如果 $m$ 时刻之后没有电车，则乘坐第二天第一辆电车（即时刻表中的第一辆）

3. **计算最终电车**：
   - 从 $0$ 号站到 $n$ 号站需要乘坐 $n$ 次电车
   - 由于乘车序列是循环的，最终乘坐的电车在序列中的位置为：
     $$
     \texttt{finalIndex} = (\texttt{startIndex} + n - 1) \bmod \texttt{totalDepartures}
     $$
   - 其中 $\texttt{startIndex}$ 是起始电车在序列中的索引，$\texttt{totalDepartures}$ 是总出发时刻数

### 算法复杂度

- **时间复杂度**：$O(t \times k + k \log k)$，其中 $t$ 是电车线路数，$k$ 是总出发时刻数（最多 $29 \times 20 = 580$）
- **空间复杂度**：$O(k)$，用于存储所有出发时刻

### 为什么这样是正确的？

假设排序后的出发时刻序列为：$T_0, T_1, \dots, T_{k-1}$，对应的电车线路为 $L_0, L_1, \dots, L_{k-1}$。

- $\texttt{Peter}$ 在 $0$ 号站乘坐电车 $L_i$，其中 $i$ 是满足 $T_i \geq m$ 的最小索引
- 在 $1$ 号站，由于电车速度相同，$\texttt{Peter}$ 会乘坐序列中的下一辆电车 $L_{i+1}$（模 $k$）
- 以此类推，在 $j$ 号站，$\texttt{Peter}$ 乘坐电车 $L_{(i+j) \bmod k}$
- 因此，在 $n$ 号站下车时，他乘坐的是电车 $L_{(i+n-1) \bmod k}$

## 代码实现

```cpp
// Peter Takes a Tramway
// UVa ID: 10423

// UVa Run Time: 0.000s

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <algorithm>
#include <utility>

using namespace std;

int main() {
    int t;
    int caseNum = 1;
    
    while (cin >> t && t != 0) {
        vector<pair<int, int>> departures; // (出发时间, 电车线路)
        
        // 读取所有电车线路信息
        for (int i = 0; i < t; i++) {
            int tramId;
            char colon;
            cin >> tramId >> colon;
            int depTime;
            while (cin >> depTime && depTime != -1) departures.push_back({depTime, tramId});
        }
        
        // 按出发时间排序
        sort(departures.begin(), departures.end());
        
        int m, n;
        cin >> m >> n;
        
        // 找到Peter在0号站坐的电车
        int startIndex = -1;
        for (int i = 0; i < departures.size(); i++)
            if (departures[i].first >= m) {
                startIndex = i;
                break;
            }
        
        // 如果m时刻之后没有电车，就坐第二天第一辆
        if (startIndex == -1) startIndex = 0;
        
        // 计算最终乘坐的电车
        // 从0号站到n号站需要换乘n次
        // 每次换乘都坐时间序列中的下一辆
        int totalDepartures = departures.size();
        int finalIndex = (startIndex + n - 1) % totalDepartures;
        int finalTram = departures[finalIndex].second;
        
        cout << "Case " << caseNum << ": Peter arrives at stop " << n << " by tram " << finalTram << "." << endl;
        caseNum++;
    }
    
    return 0;
}
```

## 总结

本题的关键在于发现 $\texttt{Peter}$ 乘车行为的循环规律。通过将所有电车的出发时刻合并排序，我们可以利用模运算直接计算出 $\texttt{Peter}$ 到达目标站点时乘坐的电车，避免了对于大 $n$（最大 $10^9$）的直接模拟，从而实现了高效求解。

这种将实际问题抽象为数学规律，并利用模运算处理大范围循环问题的方法，在编程竞赛中非常常见且实用。
