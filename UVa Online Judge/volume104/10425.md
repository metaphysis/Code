## 题目描述

为了减少达卡市被盗手机的使用，警方计划在城市的两座高塔上安装两个高级移动销毁器（$\texttt{Advanced Mobile Destroyers，AMD}$）。每个 $\texttt{AMD}$ 有一个球形作用范围，如果被盗手机出现在这个球体范围内（包括边界），$\texttt{AMD}$ 会擦除手机的闪存，使其失效。

但是 $\texttt{AMD}$ 程序存在一个漏洞：如果被盗手机位于两个 $\texttt{AMD}$ 作用范围球体边界交点的平面上，则两个 $\texttt{AMD}$ 都不会采取任何行动！

给定两个 $\texttt{AMD}$ 球体的位置和半径，以及被盗手机的位置，你需要判断该手机的命运。

### 输入格式
- 多个测试用例
- 每个用例包含：用例名称（$5$ 个字母数字字符）和 $11$ 个整数
- 前 $4$ 个整数：$\texttt{AMD}$ #1 的位置 $(x_1, y_1, z_1)$ 和半径 $r_1$
- 接下来 $4$ 个整数：$\texttt{AMD}$ #2 的位置 $(x_2, y_2, z_2)$ 和半径 $r_2$
- 最后 $3$ 个整数：被盗手机的位置 $(x_p, y_p, z_p)$
- 所有整数绝对值小于 $32000$
- 两个球体总是相交

### 输出格式
对于每个测试用例输出 $4$ 行：
1. 用例名称
2. 手机是否在 $\texttt{AMD}$ #1 范围内（$\texttt{y}$ 或 $\texttt{n}$）
3. 手机是否在 $\texttt{AMD}$ #2 范围内（$\texttt{y}$ 或 $\texttt{n}$）
4. 手机是否被销毁（$\texttt{y}$ 或 $\texttt{n}$）

## 题目分析

### 问题本质
这是一个三维几何问题，需要判断点与球体的位置关系，以及点与两个球体交平面的位置关系。

### 关键点分析
1. **球体内外判断**：点 $P$ 在球体 $(C, r)$ 内（包括边界）的条件是：
   $$ \texttt{distance}(P, C) \leq r $$
   为了避免浮点误差，我们比较平方距离：
   $$ (x_p - x_c)^2 + (y_p - y_c)^2 + (z_p - z_c)^2 \leq r^2 $$

2. **公共切平面**：两个球体的交线位于一个平面上，这个平面由两个球体方程相减得到：
   - 球体 $1$ 方程：$(x - x_1)^2 + (y - y_1)^2 + (z - z_1)^2 = r_1^2$
   - 球体 $2$ 方程：$(x - x_2)^2 + (y - y_2)^2 + (z - z_2)^2 = r_2^2$
   - 两式相减得到平面方程：
     $$ 2(x_2 - x_1)x + 2(y_2 - y_1)y + 2(z_2 - z_1)z + (x_1^2 + y_1^2 + z_1^2 - r_1^2 - x_2^2 - y_2^2 - z_2^2 + r_2^2) = 0 $$

3. **销毁条件**：
   - 如果手机在公共切平面上，不会被销毁
   - 否则，如果手机在任一球体内，会被销毁

### 算法步骤
1. 读取输入数据
2. 判断手机是否在 $\texttt{AMD}$ #1 球体内
3. 判断手机是否在 $\texttt{AMD}$ #2 球体内
4. 计算手机到公共切平面的距离（通过代入平面方程）
5. 根据销毁条件输出结果

### 复杂度分析
- 每个测试用例的时间复杂度：$O(1)$
- 空间复杂度：$O(1)$
- 整体复杂度：$O(n)$，其中 $n$ 是测试用例数量

## 解题思路详解

### 数学推导
设两个球体的参数为：
- 球体 $1$：中心 $C_1 = (x_1, y_1, z_1)$，半径 $r_1$
- 球体 $2$：中心 $C_2 = (x_2, y_2, z_2)$，半径 $r_2$
- 手机位置：$P = (x_p, y_p, z_p)$

**球体内判断**：
$$ \texttt{inSphere1} = (x_p - x_1)^2 + (y_p - y_1)^2 + (z_p - z_1)^2 \leq r_1^2 $$
$$ \texttt{inSphere2} = (x_p - x_2)^2 + (y_p - y_2)^2 + (z_p - z_2)^2 \leq r_2^2 $$

**平面方程计算**：
将手机坐标代入平面方程：
$$ \text{planeValue} = 2(x_2 - x_1)x_p + 2(y_2 - y_1)y_p + 2(z_2 - z_1)z_p + (x_1^2 + y_1^2 + z_1^2 - r_1^2 - x_2^2 - y_2^2 - z_2^2 + r_2^2) $$

如果 $\texttt{planeValue} = 0$，说明手机在公共切平面上。

**销毁判断**：
$$ \texttt{destroyed} = (\texttt{inSphere1} \ \text{OR} \ \texttt{inSphere2}) \ \text{AND} \ (\text{NOT} \ \texttt{onPlane}) $$

### 实现细节
1. 使用整数运算避免浮点误差
2. 直接比较平方距离，避免开方运算
3. 平面方程计算使用整数运算，直接判断是否为 $0$

## 代码实现

```cpp
// Mobile Destroyer

#include <iostream>
#include <string>
#include <cmath>

using namespace std;

const double EPS = 1e-9;

struct Point3D {
    int x, y, z;
    Point3D(int x = 0, int y = 0, int z = 0) : x(x), y(y), z(z) {}
};

struct Sphere {
    Point3D center;
    int radius;
    Sphere(int x = 0, int y = 0, int z = 0, int r = 0) : center(x, y, z), radius(r) {}
};

// 计算两点距离平方
int squaredDistance(const Point3D& a, const Point3D& b) {
    int dx = a.x - b.x;
    int dy = a.y - b.y;
    int dz = a.z - b.z;
    return dx * dx + dy * dy + dz * dz;
}

// 判断点是否在球内（包括边界）
bool isInsideSphere(const Point3D& p, const Sphere& s) {
    return squaredDistance(p, s.center) <= s.radius * s.radius;
}

int main() {
    string caseName;
    while (cin >> caseName) {
        int x1, y1, z1, r1, x2, y2, z2, r2, xp, yp, zp;
        cin >> x1 >> y1 >> z1 >> r1 >> x2 >> y2 >> z2 >> r2 >> xp >> yp >> zp;

        Sphere s1(x1, y1, z1, r1);
        Sphere s2(x2, y2, z2, r2);
        Point3D phone(xp, yp, zp);

        bool inSphere1 = isInsideSphere(phone, s1);
        bool inSphere2 = isInsideSphere(phone, s2);

        // 计算公共切平面方程的值
        int planeValue = 2 * (x2 - x1) * xp +
                         2 * (y2 - y1) * yp +
                         2 * (z2 - z1) * zp +
                         (x1*x1 + y1*y1 + z1*z1 - r1*r1 -
                          x2*x2 - y2*y2 - z2*z2 + r2*r2);

        bool onPlane = (planeValue == 0); // 整数运算，直接判断是否为0

        bool destroyed = (inSphere1 || inSphere2) && !onPlane;

        // 输出
        cout << caseName << endl;
        cout << (inSphere1 ? "y" : "n") << endl;
        cout << (inSphere2 ? "y" : "n") << endl;
        cout << (destroyed ? "y" : "n") << endl;
    }

    return 0;
}
```

## 总结

本题考察了三维几何中的球体与点的位置关系，以及两个球体交平面的计算。关键在于理解：

1. 使用平方距离判断点球关系，避免浮点误差
2. 通过球体方程相减得到交平面方程
3. 正确处理销毁条件的逻辑关系

该解法时间复杂度优秀，空间复杂度恒定，能够高效处理大规模输入。
