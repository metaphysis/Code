## 题目背景

你可能听说过阿基米德的名字。相传，叙拉古的希罗王要求阿基米德判断他的新王冠是否为纯金时，阿基米德发现了浮力定律。如果他无法完成这个任务，就会受到惩罚。有一天，他在洗澡时思考如何解决这个问题。当他将自己浸入一个装满水的浴缸时，一些水溢了出来。突然间，他开始大喊“尤里卡，尤里卡”，并赤裸着跑向国王，因为他从这一事件中找到了解决问题的方法。从此，浮力定律得以确立。

阿基米德在公元前三世纪发现的浮力定律是：

> 浸入流体中的物体受到一个垂直向上的浮力，该浮力等于该物体排开的流体的重量。浮体排开与其自身重量相等的流体。

这些浮力定律的发现使许多复杂的分析成为可能。在这个问题中，我们考虑一种比重计，它利用浮力定律提供的简单方法来测量任何流体的比重。

## 问题描述

比重计漂浮的高度是液体比重的度量。杆身具有恒定直径 $D$ ，底部的重物使主体稳定地垂直漂浮，如图所示。如果位置 $h = 0$ 对应纯水（比重 $SG = 1.0$ ），则根据输入中未给出的参数，求出 $h$ 或 $SG$。

**输入**：包含三行，每行对应给定的四个常数中的任意一个。输入必须包含 $W$ （克，$0 < W \leq 5000$ ）和 $D$ （毫米，$0 < D \leq 100$ ）的值。除此之外，还可能包含 $h$ （厘米，$0 < h \leq 50$ ）或 $SG$ （ $0 < SG \leq 25$ ）。使用水的容重 $\gamma_w = 9806.65 \, N/m^3$ ，重力加速度 $g = 9.80665 \, m/s^2$ ，水的密度 $\rho = 1000 \, kg/m^3$。

**输出**：对于每组输入，处理输入中不存在的变量（ $h$ 或 $SG$ ）的值。 $h$ 的输出应以厘米（ $\texttt{cm}$ ）为单位。将每个浮点值四舍五入到小数点后两位。

## 样例分析

**样例输入**：
```
W=3307.00
D=81.00
h=32.00
W=3665.00
D=74.00
SG=1.29
```

**样例输出**：
```
SG=1.99
h=19.16
```

## 物理模型分析

### 1. 浮力平衡方程

根据阿基米德浮力定律，比重计漂浮在液体中时，其重量等于排开液体的重量。设比重计的总重量为 $W$ （单位：克），液体的比重为 $SG$ ，水的密度 $\rho = 1 \, \text{g/cm}^3$（因为 $1000 \, \text{kg/m}^3 = 1 \, \text{g/cm}^3$）。

当比重计在比重为 $SG$ 的液体中时：
- 排开液体的体积为 $V$
- 排开液体的质量为 $SG \times \rho \times V = SG \times V$ （因为 $\rho = 1$）
- 根据浮力定律：$W = SG \times V$

因此，排开液体的体积为：
$$ V = \frac{W}{SG} $$

### 2. 参考状态（纯水）

当比重计在纯水中时（ $SG = 1.0$ ， $h = 0$ ）：
- 排开水的体积 $V_0 = W$ （因为 $W = 1 \times V_0$）

### 3. 体积变化与高度的关系

当液体比重从 $1.0$ 变为 $SG$ 时，排开液体的体积从 $V_0$ 变为 $V$ ，体积变化量为：
$$ \Delta V = V_0 - V = W - \frac{W}{SG} = W \times \left(1 - \frac{1}{SG}\right) = W \times \frac{SG - 1}{SG} $$

这个体积变化量正好对应于杆身露出液面的部分。由于杆身直径恒定，体积变化与高度变化 $h$ 的关系为：
$$ \Delta V = A \times h $$

其中 $A$ 是杆身的横截面积：
$$ A = \pi \times \left(\frac{D}{2}\right)^2 $$

### 4. 单位统一

输入中 $D$ 的单位是毫米（ $\texttt{mm}$ ），需要转换为厘米（ $\texttt{cm}$ ）以保持单位一致（ $W$ 对应体积 $\texttt{cm}^3$ ， $h$ 单位是 $\texttt{cm}$ ）：
$$ D_{\text{cm}} = \frac{D}{10} $$
$$ A = \pi \times \left(\frac{D_{\text{cm}}}{2}\right)^2 = \frac{\pi \times D_{\text{cm}}^2}{4} \, \text{cm}^2 $$

### 5. 核心公式推导

由体积变化关系：
$$ A \times h = W \times \frac{SG - 1}{SG} $$

由此可推导出两种情况的公式：

**情况 1**：已知 $h$ ，求 $SG$
$$ A \times h \times SG = W \times (SG - 1) $$
$$ A \times h \times SG = W \times SG - W $$
$$ W = SG \times (W - A \times h) $$
$$ SG = \frac{W}{W - A \times h} $$

**情况 2**：已知 $SG$ ，求 $h$
$$ h = \frac{W \times (SG - 1)}{SG \times A} $$

## 解题思路

### 步骤 1：解析输入

题目输入格式特殊：每组测试数据包含三行，每行包含一个参数（如 $\texttt{W=3307.00}$）。我们需要读取三行，分别提取 $W$ 、 $D$ 和（ $h$ 或 $SG$ ）的值。

关键点：
- $W$ 和 $D$ 总是存在
- $h$ 和 $SG$ 只会出现其中一个
- 使用布尔变量标记哪个参数存在

### 步骤 2：单位转换

将 $D$ 从毫米转换为厘米：
$$ D_{\text{cm}} = \frac{D}{10} $$

计算横截面积 $A$：
$$ A = \frac{\pi \times D_{\text{cm}}^2}{4} $$

### 步骤 3：根据已知参数计算未知参数

使用推导出的公式：
- 如果已知 $h$ ： $SG = \frac{W}{W - A \times h}$
- 如果已知 $SG$ ： $h = \frac{W \times (SG - 1)}{SG \times A}$

### 步骤 4：输出结果

- 保留两位小数
- 输出格式为 $\texttt{SG=1.99}$ 或 $\texttt{h=19.16}$
- 注意样例输出中两个结果在同一行，用空格分隔

## 代码实现

```cpp
// Working With Specific Gravity
// UVa ID: 10434
// Verdict: Accepted
// Submission Date: 2026-02-27
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    string line;
    const double pi = acos(-1.0);
    
    while (getline(cin, line)) {
        if (line.empty()) continue;
        
        double W = 0, D = 0, h = -1, SG = -1;
        bool hasH = false, hasSG = false;
        
        // 读取三行输入，每行包含一个参数
        std::vector<string> lines;
        lines.push_back(line);
        for (int i = 2; i <= 3; i++) {
            getline(cin, line);
            lines.push_back(line);
        }
        
        // 解析三行参数
        for (int i = 0; i < 3; i++) {
            string token = lines[i];
            if (token.find("W=") == 0) {
                W = stod(token.substr(2));
            } else if (token.find("D=") == 0) {
                D = stod(token.substr(2));
            } else if (token.find("h=") == 0) {
                h = stod(token.substr(2));
                hasH = true;
            } else if (token.find("SG=") == 0) {
                SG = stod(token.substr(3));
                hasSG = true;
            }
        }
        
        // 单位转换：D从mm转换为cm
        double D_cm = D / 10.0;
        double A = pi * D_cm * D_cm / 4.0;  // 横截面积，单位：cm²
        
        if (hasH) {
            // 已知h，计算SG
            SG = W / (W - A * h);
            cout << fixed << setprecision(2) << "SG=" << SG << endl;
        } else if (hasSG) {
            // 已知SG，计算h
            h = W * (SG - 1) / (SG * A);
            cout << fixed << setprecision(2) << "h=" << h << endl;
        }
    }
    
    return 0;
}
```

- **空间复杂度**： $O(1)$ ，仅使用常数个变量

1. 正确理解浮力定律：浮体排开液体的重量等于浮体自身重量
