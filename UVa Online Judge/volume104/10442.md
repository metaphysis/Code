## 题目描述

$\texttt{Ada}$ 语言中的整数常量有两种形式：
1. **十进制整数**：由一个或多个数字组成，如 `123`
2. **进制表示**：格式为 `base#digits#`，其中：
   - `base` 表示进制，必须是 $2$ 到 $16$ 之间的整数
   - `digits` 是该进制下的有效数字序列
   - 小写字母 `a` 到 `f` 表示数字 $10$ 到 $15$

**特殊规则**：在本题中，`base` 本身也可以是任何合法的 $\texttt{Ada}$ 整数常量，只要其最终表示的数值在 $2$ 到 $16$ 范围内。

### 输入格式
- 第一行：整数 $n$，表示测试用例数量
- 接下来 $n$ 行：每行一个字符串，长度在 $1$ 到 $80$ 之间

### 输出格式
- 对于每个测试用例，输出 `yes` 或 `no`，表示是否为合法的 $\texttt{Ada}$ 整数常量

### 样例
```
输入：
5
2#101#
2#101##123#
17#abc#
16#123456789abcdef#
16#123456789abcdef#123456789abcdef#

输出：
yes
yes
no
yes
no
```

## 题目分析

本题的核心难点在于处理**嵌套的进制表示**。考虑样例 `2#101##123#`：

1. 最外层结构：`base#digits#`，其中：
   - `base` = `2#101#`
   - `digits` = `123`

2. 内层结构：`2#101#` 本身也是一个合法的 Ada 常量：
   - `base` = `2`（十进制）
   - `digits` = `101`（二进制）

3. 数值计算：
   - 内层：二进制 `101` = 十进制 $5$
   - 外层：五进制 `123` = 十进制 $1×25 + 2×5 + 3 = 38$

这种嵌套结构需要使用**递归解析**的方法。

## 解题思路

### 关键观察

1. **递归结构**：每个 `base#digits#` 形式的常量中，`base` 部分本身可能又是一个 `base#digits#` 形式的常量
2. **数值范围限制**：
   - 作为 `base` 使用时，数值必须在 $[2, 16]$ 范围内
   - 作为普通常量时，数值没有上限限制
3. **边界条件**：
   - 字符串不能为空
   - 进制表示必须以 `#` 结尾
   - `digits` 部分不能为空
   - 每个数字必须小于当前进制

### 算法设计

使用递归函数 `isAda(s, depth)`，其中：
- `s`：待解析的字符串
- `depth`：递归深度，用于区分当前解析的是外层常量还是内层 `base`

**函数返回值**：`pair<bool, int>`，包含：
- 第一个元素：是否合法
- 第二个元素：解析出的数值（仅对 `base` 部分需要）

#### 递归解析过程

1. **基本情况**：字符串不包含 `#`
   - 检查是否全为数字字符
   - 如果 `depth > 0`（即作为 `base` 使用），检查数值是否在 $[2, 16]$ 范围内

2. **进制表示情况**：
   - 检查是否以 `#` 结尾
   - 找到最后一个 `#` 和它前面的 `#`
   - 递归解析 `base` 部分：`isAda(base_str, depth + 1)`
   - 解析 `digits` 部分，检查每个数字是否小于 `base` 值
   - 如果 `depth > 0`，检查最终数值是否在 $[2, 16]$ 范围内

### 复杂度分析

- **时间复杂度**：$O(n × L)$，其中 $n$ 是测试用例数，$L$ 是字符串长度
- **空间复杂度**：$O(L)$，递归深度与嵌套层数相关

## 代码实现

```cpp
// Basic

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

pair<bool, int> isAda(const string& s, int depth) {
    if (s.empty()) return {false, 0};
    if (s.find('#') == s.npos) {
        for (auto c : s) if (!isdigit(c)) return {false, 0};
        if (depth) {
            int base = 0;
            for (auto c : s) {
                base = base * 10 + c - '0';
                if (base > 16) return {false, 0};
            }
            if (base < 2) return {false, 0};
            return {true, base};
        }
        return {true, 0};
    }
    if (s.back() != '#') return {false, 0};
    int firstHash = -1, lastHash = (int)s.length() - 1;
    for (int i = (int)s.length() - 2; i >= 0; i--)
        if (s[i] == '#') {
            firstHash = i;
            break;
        }
    if (firstHash == -1) return {false, 0};
    pair<bool, int> base = isAda(s.substr(0, firstHash), depth + 1);
    if (!base.first) return {false, 0};
    string digit = s.substr(firstHash + 1, lastHash - firstHash - 1);
    if (digit.empty()) return {false, 0};
    int value = 0;
    for (auto c : digit) {
        int v;
        if (isdigit(c)) v = c - '0';
        else if (c >= 'a' && c <= 'f') v = c - 'a' + 10;
        else return {false, 0};
        if (v >= base.second) return {false, 0};
        value = value * base.second + v;
        if (depth && value > 16) return {false, 0};
    }
    if (depth && value < 2) return {false, 0};
    return {true, value};
}

int main() {
    int n;
    cin >> n;
    cin.ignore(128, '\n');
    for (int i = 0; i < n; i++) {
        string line;
        getline(cin, line);
        pair<bool, int> r = isAda(line, 0);
        cout << (r.first ? "yes" : "no") << '\n';
    }
    return 0;
}
```

## 总结

本题通过递归解析的方法，优雅地处理了 $\texttt{Ada}$ 整数常量的嵌套结构。关键技巧在于：
- 使用 `depth` 参数区分内外层解析
- 从右向左查找 `#` 来正确分割字符串
- 在解析过程中同时进行合法性检查和数值计算

这种方法能够正确处理所有边界情况，包括多层嵌套的进制表示，确保了算法的正确性和健壮性。
