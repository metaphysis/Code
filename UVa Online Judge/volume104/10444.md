## 题目描述

这是一个多柱汉诺塔问题的变种。在经典的三柱汉诺塔问题中，移动 $n$ 个盘子需要 $2^n - 1$ 步。但当柱子数量 $p > 3$ 时，问题变得更加复杂，虽然任务变得更容易（需要的步数更少），但找到最优策略却很困难。

题目采用了一种被称为 **$\texttt{Presumed Optimal Solution (POS)}$** 的策略。该策略的核心思想是：
- 将 $n$ 个盘子中的 $n_1$ 个先移到中间柱
- 然后用剩下的 $p-1$ 个柱子移动剩余的 $n-n_1$ 个盘子到目标柱
- 最后再把 $n_1$ 个盘子移到目标柱

关键洞察是：在 $\texttt{POS}$ 策略中，每个盘子到达目标柱所需的步数是 $2^k$ 的形式，且需要 $2^k$ 步的盘子数量等于组合数 $C(p-3+k, k)$。

## 题目分析

### 问题重述
给定 $n$ 个盘子和 $p$ 个柱子 ($0 \leq n \leq 200$, $3 < p \leq 20$)，按照 $\texttt{POS}$ 策略计算将全部盘子从源柱移动到目标柱所需的最少步数。

### 关键观察
1. **步数分布规律**：每个盘子需要的步数是 $2^k$，其中 $k$ 是非负整数
2. **盘子分组**：需要 $2^k$ 步的盘子数量为 $C(p-3+k, k)$
3. **贪心分配**：从 $k=0$ 开始，依次分配盘子，直到分配完所有 $n$ 个盘子

### 数学推导
总步数计算公式：
$$\text{总步数} = \sum_{k=0}^{\infty} \min(\text{剩余盘子数}, C(p-3+k, k)) \times 2^k$$

其中：
- $C(n, k)$ 是组合数，表示从 $n$ 个元素中取 $k$ 个的组合数
- 当剩余盘子数为 $0$ 时停止累加

### 算法选择
直接模拟上述分配过程：
1. 初始化 $k = 0$，剩余盘子数 = $n$，总步数 = $0$
2. 当剩余盘子数 $> 0$ 时循环：
   - 计算当前 $k$ 对应的盘子数量：$\texttt{count} = \min(\text{剩余盘子数}, C(p-3+k, k))$
   - 累加步数：$\text{总步数} += \texttt{count} \times 2^k$
   - 更新剩余盘子数
   - $k$ 增加 $1$

## 解题思路详解

### 组合数计算
使用迭代方法计算组合数 $C(n, k)$，避免递归带来的性能问题。注意处理边界情况：
- $k < 0$ 或 $k > n$ 时返回 $0$
- $k = 0$ 或 $k = n$ 时返回 $1$
- 利用对称性 $C(n, k) = C(n, n-k)$ 优化计算

### 步数计算
由于 $n \leq 200$，$p \leq 20$，最大的 $k$ 值不会太大，算法效率很高。使用 `long long` 类型存储结果，防止整数溢出。

### 样例验证
以样例 $n=3, p=4$ 为例：
- $p-3 = 1$
- $k=0$: $C(1,0)=1$，步数 $1 \times 2^0 = 1$，剩余 $2$ 个盘子
- $k=1$: $C(2,1)=2$，步数 $2 \times 2^1 = 4$，剩余 $0$ 个盘子
- 总步数 = $1 + 4 = 5$ ✓

## 复杂度分析
- **时间复杂度**：$O(n)$，每个盘子最多被处理一次
- **空间复杂度**：$O(1)$，只使用常数额外空间

```cpp
#include <iostream>
#include <vector>
#include <cstring>
using namespace std;

// 计算组合数 C(n, k)
long long comb(int n, int k) {
    if (k < 0 || k > n) return 0;
    if (k == 0 || k == n) return 1;
    long long res = 1;
    if (k > n - k) k = n - k;
    for (int i = 1; i <= k; i++) {
        res = res * (n - k + i) / i;
    }
    return res;
}

long long solve(int n, int p) {
    long long moves = 0;
    int k = 0;
    int remaining = n;
    while (remaining > 0) {
        long long count = comb(p - 3 + k, k);
        if (count > remaining) count = remaining;
        moves += count * (1LL << k);  // 2^k
        remaining -= count;
        k++;
    }
    return moves;
}

int main() {
    int n, p;
    int caseNo = 1;
    while (cin >> n >> p) {
        if (n == 0 && p == 0) break;
        long long ans = solve(n, p);
        cout << "Case " << caseNo << ": " << ans << endl;
        caseNo++;
    }
    return 0;
}
```

## 总结
本题的关键在于理解多柱汉诺塔的 $\texttt{POS}$ 策略中盘子步数的分布规律。通过组合数学的方法，我们可以直接计算出最优步数，而不需要使用动态规划。这种方法既高效又直观，充分体现了数学在算法优化中的重要作用。
