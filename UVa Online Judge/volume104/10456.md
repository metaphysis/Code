## 题目描述

给定一个 $N$ 个顶点的凸多边形（顶点按逆时针顺序给出），表示一块披萨。在多边形的边界上给定一个固定点 $P$，要求在边界上找到另一个点 $Q$，使得线段 $PQ$ 将多边形分成面积相等的两部分。

输入包含多组数据。每组数据第一行为顶点数 $N$，接下来 $N$ 行是顶点坐标。然后是一个整数 $K$，表示固定点的数量，接下来 $K$ 行是固定点的坐标。输出时，对于每个固定点，输出另一个点的坐标，以约分后的分数形式表示。

## 题目分析

本题的核心是一个几何分割问题。由于多边形是凸的，且固定点 $P$ 在边界上，那么存在唯一的点 $Q$ 在边界上使得 $PQ$ 平分多边形面积。随着点 $Q$ 沿边界从 $P$ 出发逆时针移动，左侧部分的面积单调递增，因此可以通过遍历边界找到 $Q$ 所在的边。

### 关键难点

1. **面积计算**：需要精确计算多边形面积，避免浮点数误差。使用叉积公式计算面积的 $2$ 倍（整数运算）。

2. **点在线段上的判定**：需要正确判断固定点位于哪条边上，注意处理端点情况。

3. **精确分数求解**：当确定 $Q$ 所在的边后，需要精确求解 $Q$ 的坐标，以分数形式输出。

## 解题思路

### 第一步：预处理多边形

将顶点存储在数组 $x[0..N-1]$、$y[0..N-1]$ 中，为了方便处理循环，复制第一个顶点到 $x[N]$、$y[N]$。

计算整个多边形面积的 $2$ 倍：
$$S_{total} = \sum_{i=0}^{N-1} (x_i y_{i+1} - x_{i+1} y_i)$$

由于多边形是逆时针给出的，此值为正。目标半面积为 $S_{target} = S_{total} / 2$。

### 第二步：定位固定点所在的边

对于固定点 $(x_1, y_1)$，遍历每一条边 $i$（从顶点 $i$ 到 $i+1$），判断点是否在线段上。判断条件为：
$$(x_{i+1} - x_i)(y_1 - y_i) = (x_1 - x_i)(y_{i+1} - y_i)$$

这表示向量 $\overrightarrow{v_i v_{i+1}}$ 与 $\overrightarrow{v_i P}$ 共线。同时需要检查点是否在线段范围内（可以通过边界判断，由于凸多边形特性，共线即在线段上）。

代码中从后向前遍历，取第一个满足条件的边，记录边索引 $p$（$P$ 位于边 $v_p \to v_{p+1}$ 上）。

### 第三步：构建顶点序列并寻找平分边

从固定点 $P$ 开始，沿着多边形逆时针方向构建顶点序列。序列构造方式如下：

1. 将固定点 $P$ 加入序列
2. 将顶点 $v_{p+1}$ 加入序列
3. 依次加入后续顶点 $v_{p+2}, v_{p+3}, \dots$，每加入一个顶点后，将固定点 $P$ 再次加入序列，形成一个闭合多边形

对于每次构造的多边形，计算其面积的 $2$ 倍：
$$area = \sum_{j=0}^{len-1} (tx_j \cdot ty_{j+1} - tx_{j+1} \cdot ty_j)$$

当 $2 \cdot area \ge S_{total}$ 时，说明分割点 $Q$ 位于当前添加的边上（即顶点 $v_{i-1} \to v_i$ 上）。

### 第四步：精确求解分割点坐标

设当前边为 $v_{last} \to v_{curr}$，其中 $v_{last} = (lx, ly)$，$v_{curr} = (x_i, y_i)$，方向向量为 $(dx, dy) = (x_i - lx, y_i - ly)$。

设 $Q = v_{last} + t \cdot (dx, dy)$，$t \in [0, 1]$，需要求解 $t$。

设当前多边形（$P \to v_{p+1} \to \cdots \to v_{last} \to Q \to P$）的面积为 $S_{current}$，它应该等于 $S_{target}$。

这个多边形可以看作三部分的和：
- 固定多边形部分（顶点序列中前 $len-2$ 个点形成的多边形）的面积，记为 $sum_1$
- 三角形 $v_{last} \to Q \to P$ 的面积

通过叉积展开，可以得到关于 $t$ 的线性方程：
$$sum_1 + \frac{1}{2} \cdot t \cdot sum_2 = \frac{1}{2} S_{target}$$

其中：
$$sum_2 = lx \cdot dy - ly \cdot dx + dx \cdot ty_0 - dy \cdot tx_0$$

这里 $(tx_0, ty_0)$ 是固定点 $P$ 的坐标。

整理得：
$$2 \cdot sum_1 + t \cdot sum_2 = S_{target}$$

即：
$$t = \frac{S_{target} - 2 \cdot sum_1}{sum_2}$$

代入 $S_{target} = S_{total} / 2$：
$$t = \frac{S_{total} - 4 \cdot sum_1}{2 \cdot sum_2}$$

令：
$$need = S_{total} - 2 \cdot sum_1$$
$$denominator = 2 \cdot sum_2$$

则：
$$t = \frac{need}{denominator}$$

于是 $Q$ 的坐标为：
$$Q_x = lx + dx \cdot \frac{need}{denominator} = \frac{lx \cdot denominator + dx \cdot need}{denominator}$$
$$Q_y = ly + dy \cdot \frac{need}{denominator} = \frac{ly \cdot denominator + dy \cdot need}{denominator}$$

### 第五步：分数约分与输出

将分子和分母用 $\gcd$ 约分，确保分母为正。若分子为 $0$，输出 $(0/1)$。输出格式为 $(num/den)$，多个点之间用逗号和空格分隔。

## 算法复杂度

- 对于每个固定点，最多遍历 $N$ 条边，每次计算面积需要 $O(N)$ 时间
- 总时间复杂度：$O(K \cdot N^2)$，其中 $N \le 30$，$K$ 未明确给出但范围合理，可以接受
- 空间复杂度：$O(N)$

## 注意事项

1. 使用整数运算避免浮点数误差
2. 注意处理固定点在顶点上的情况（共线且坐标相等）
3. 分数约分时需处理分母为负的情况，统一转换为分母为正
4. 输出格式严格遵循题目要求

// Intelligent Cats

#include <bits/stdc++.h>
using namespace std;

int x[31], y[31], fixedX, fixedY, n, tempX[31], tempY[31], len, totalArea;

int gcd(int a, int b) {
    return (b == 0) ? a : gcd(b, a % b);
}

int main() {
    while (scanf("%d", &n) == 1) {
        // 读入多边形顶点
        for (int i = 0; i < n; i++) {
            scanf("%d %d", x + i, y + i);
        }
        x[n] = x[0];  // 方便循环处理
        y[n] = y[0];
        
        // 计算多边形面积的两倍
        totalArea = 0;
        for (int i = 0; i < n; i++) {
            totalArea += x[i] * y[i + 1] - x[i + 1] * y[i];
        }
        
        int k;
        scanf("%d", &k);
        while (k--) {
            scanf("%d %d", &fixedX, &fixedY);
            int p = 0;
            len = 0;
            
            // 找到固定点所在的边
            for (int i = n - 1; i >= 0; i--) {
                if ((x[i + 1] - x[i]) * (fixedY - y[i]) == (fixedX - x[i]) * (y[i + 1] - y[i])) {
                    p = i;
                }
            }
            
            // 构建顶点序列
            tempX[len] = fixedX;
            tempY[len++] = fixedY;
            tempX[len] = x[p + 1];
            tempY[len++] = y[p + 1];
            
            // 遍历后续顶点，寻找分割点所在的边
            for (int i = (p + 2) % n; i != p; i = (i + 1) % n) {
                tempX[len] = x[i];
                tempY[len++] = y[i];
                tempX[len] = fixedX;
                tempY[len] = fixedY;
                
                // 计算当前多边形面积的两倍
                int temp = 0;
                for (int j = 0; j < len; j++) {
                    temp += tempX[j] * tempY[j + 1] - tempX[j + 1] * tempY[j];
                }
                if (2 * temp < totalArea) {
                    continue;  // 面积未达到一半，继续
                }
                
                // 找到分割边，计算分割点坐标
                int lastX = x[(i + n - 1) % n], lastY = y[(i + n - 1) % n];
                int dx = x[i] - lastX, dy = y[i] - lastY;
                int sum1 = 0, sum2 = 0;
                
                for (int j = 0; j < len; j++) {
                    if (j < len - 2) {
                        sum1 += tempX[j] * tempY[j + 1] - tempX[j + 1] * tempY[j];
                    } else if (j == len - 2) {
                        sum2 += lastX * dy - lastY * dx;
                    } else {
                        sum1 += lastX * tempY[0] - lastY * tempX[0];
                        sum2 += dx * tempY[0] - dy * tempX[0];
                    }
                }
                
                sum1 = (totalArea - 2 * sum1);
                int numeratorX = lastX * 2 * sum2 + dx * sum1;
                int denominatorX = 2 * sum2;
                int d = gcd(numeratorX, denominatorX);
                numeratorX /= d;
                denominatorX /= d;
                if (denominatorX < 0) {
                    numeratorX *= -1;
                    denominatorX *= -1;
                }
                printf("(%d/%d),", numeratorX, denominatorX);
                
                int numeratorY = lastY * 2 * sum2 + dy * sum1;
                int denominatorY = 2 * sum2;
                int dd = gcd(numeratorY, denominatorY);
                numeratorY /= dd;
                denominatorY /= dd;
                if (denominatorY < 0) {
                    numeratorY *= -1;
                    denominatorY *= -1;
                }
                printf("(%d/%d)\n", numeratorY, denominatorY);
                break;
            }
        }
    }
    return 0;
}
