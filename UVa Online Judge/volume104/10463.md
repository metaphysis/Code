# 题目分析

## 问题描述

阿兹特克骑士是一种特殊的骑士，其移动方式与国际象棋中的普通骑士有所不同。普通骑士每次移动走“日”字形（即沿一个方向移动 $2$ 格，再沿垂直方向移动 $1$ 格），而阿兹特克骑士的移动方式为：沿一个方向移动 $3$ 格，再沿垂直方向移动 $1$ 格，或者沿一个方向移动 $1$ 格，再沿垂直方向移动 $3$ 格。也就是说，从当前位置 $(x, y)$ 出发，阿兹特克骑士可以移动到以下 $8$ 个位置之一： $(x \pm 3, y \pm 1)$ 或 $(x \pm 1, y \pm 3)$ 。

阿兹特克骑士有一个特殊的停留规则： **只有当骑士用素数步数到达某个格子时，才会停下来** 。如果到达某个格子的步数是合数，它会继续移动，不会停留。此外，骑士 **不能重复访问已经访问过的格子** （即不能走回头路）。

给定棋盘大小、起始位置和目标位置，需要判断骑士能否到达目标并在目标位置停下（即用素数步数到达）。如果无法用素数步到达，但可以用合数步到达，则输出所需的最小合数步数。如果根本无法到达，则输出不可达。

## 输入格式

* 输入包含多组测试数据。
* 每组数据以两个整数 $m$ 和 $n$ 开头（ $4 \le m, n \le 15$ ），表示棋盘的行数和列数。
* 接下来四个整数： $srow$ , $scol$ （起始位置）和 $drow$ , $dcol$ （目标位置）。
* 棋盘左上角坐标为 $(0, 0)$ 。
* 输入以 `EOF` 结束。

## 输出格式

* 对于每组数据，输出 `CASE# X: ` ，其中 $X$ 为测试用例编号。
* 如果可以用素数步到达目标，输出 `The knight takes l prime moves.` ，其中 $l$ 是最小的素数步数。
* 如果不能用素数步到达，但可以用合数步到达，输出 `The knight takes l composite move(s).` ，其中 $l$ 是最小的合数步数。
* 如果无法到达，输出 `Destination is not reachable.` 。

# 解题思路

## 问题本质

本题是一个 **带约束的棋盘最短路径搜索问题** ，其核心约束如下：

1.  **移动方式特殊** ：骑士的移动是 $( \pm 3, \pm 1 )$ 和 $( \pm 1, \pm 3 )$ 的组合，共 $8$ 个方向。
2.  **步数类型约束** ：只有在素数步数到达目标时，骑士才会停下；若以合数步数到达，骑士会继续移动。
3.  **路径无环** ：骑士不能重复访问已经访问过的格子。

因此，我们需要找到从起点到目标的一条路径，使得步数 $l$ 满足：
*   若存在路径使得 $l$ 为素数，则输出最小的这样的 $l$ 。
*   否则，若存在路径使得 $l$ 为合数，则输出最小的这样的 $l$ 。
*   若不存在任何路径，则输出不可达。

## 算法设计

由于棋盘最大为 $15 \times 15$ ，状态空间有限，我们可以采用 **广度优先搜索（$\texttt{BFS}$）** 来解决问题。 $\texttt{BFS}$ 能够保证我们首次到达目标状态时的步数是最小的。但需要注意的是，由于“素数步停下”的约束，我们不能简单地在第一次到达目标时就结束搜索。

### 关键点分析

1.  **素数步优先** ：我们需要优先寻找素数步到达目标的路径。因为 $\texttt{BFS}$ 是按层扩展的，所以当我们首次以素数步到达目标时，该步数一定是最小的素数步数。
2.  **合数步处理** ：如果 $\texttt{BFS}$ 搜索完成后没有找到素数步的路径，那么我们需要重新进行一次 $\texttt{BFS}$，寻找合数步到达目标的路径。注意，这次 $\texttt{BFS}$ 中，当以合数步到达目标时，应该立即停止，因为此时步数是最小的合数步数。
3.  **状态表示** ：每个状态可以用 $(x, y, steps)$ 表示，其中 $(x, y)$ 是当前位置， $steps$ 是已经走过的步数。为了满足“不重复访问”的约束，我们需要一个 $visited[m][n]$ 数组来记录每个格子是否已经被访问过。
4.  **起点即终点的特殊情况** ：当起点和终点相同时，步数为 $0$ 。根据题目示例， $0$ 被视为合数，因此应输出 `The knight takes 0 composite move(s).` 。

### 算法步骤

1.  **预处理** ：生成一个足够大的素数表，用于快速判断一个数是否为素数。由于棋盘最大为 $15 \times 15$ ，最多有 $225$ 个格子，步数不会超过 $225$ ，因此素数表大小设为 $250$ 即可。
2.  **处理每组测试数据** ：
    *   若起点等于终点，直接输出对应结果。
    *   否则，进行两次 $\texttt{BFS}$：
        *   **第一次 $\texttt{BFS}$** ：寻找素数步到达目标的路径。在扩展状态时，如果下一个位置是目标，且步数（当前步数 $+1$ ）为素数，则记录结果并结束搜索；如果步数为合数，则 **不** 将该目标位置标记为已访问，也不停止搜索，因为后续可能以素数步再次到达。
        *   **第二次 $\texttt{BFS}$** ：仅在第一次 $\texttt{BFS}$ 未找到素数步路径时执行。这次寻找合数步到达目标的路径。当以合数步到达目标时，记录结果并结束搜索。
3.  **输出结果** ：根据两次 $\texttt{BFS}$ 的结果，按照题目要求格式化输出。

### 时间复杂度分析

*   每次 $\texttt{BFS}$ 最多访问 $O(m \times n)$ 个状态，每个状态扩展 $8$ 个方向。
*   因此，每次 $\texttt{BFS}$ 的时间复杂度为 $O(m \times n)$ 。
*   在最坏情况下，需要进行两次 $\texttt{BFS}$，总时间复杂度仍为 $O(m \times n)$ ，对于 $m, n \le 15$ 的范围，完全可以在时限内完成。

```cpp
// Aztec Knights

#include <bits/stdc++.h>
using namespace std;

// 素数表
vector<bool> getPrimeTable(int maxN) {
    vector<bool> isPrime(maxN + 1, true);
    if (maxN >= 0) isPrime[0] = false;
    if (maxN >= 1) isPrime[1] = false;
    for (int i = 2; i * i <= maxN; ++i)
        if (isPrime[i])
            for (int j = i * i; j <= maxN; j += i)
                isPrime[j] = false;
    return isPrime;
}

// Aztec Knight 的移动偏移量：移动3步和1步的组合
const int dx[] = {3, 3, -3, -3, 1, 1, -1, -1};
const int dy[] = {1, -1, 1, -1, 3, -3, 3, -3};

struct State {
    int x, y, steps;
    State(int x, int y, int steps) : x(x), y(y), steps(steps) {}
};

int main() {
    int m, n, srow, scol, drow, dcol;
    int caseNo = 0;
    vector<bool> isPrime = getPrimeTable(250);
    
    while (cin >> m >> n >> srow >> scol >> drow >> dcol) {
        caseNo++;
        // 特殊情况：起点就是终点
        if (srow == drow && scol == dcol) {
            cout << "CASE# " << caseNo << ": ";
            // 根据题目示例，0步视为合数
            cout << "The knight takes 0 composite move(s)." << '\n';
            continue;
        }
        // 第一次BFS：寻找素数步数
        vector<vector<bool>> visited(m, vector<bool>(n, false));
        queue<State> q;
        q.push(State(srow, scol, 0));
        visited[srow][scol] = true;
        int primeResult = -1;
        bool foundPrime = false;
        while (!q.empty() && !foundPrime) {
            State cur = q.front(); q.pop();
            for (int i = 0; i < 8; ++i) {
                int nx = cur.x + dx[i], ny = cur.y + dy[i];
                int nextSteps = cur.steps + 1;
                if (nx >= 0 && nx < m && ny >= 0 && ny < n) {
                    if (nx == drow && ny == dcol) {
                        if (isPrime[nextSteps]) {
                            primeResult = nextSteps;
                            foundPrime = true;
                            break;
                        }
                        // 如果是合数步到达目标，不停止，继续搜索
                        // 也不标记visited，因为可能以素数步再次到达
                    } else if (!visited[nx][ny]) {
                        visited[nx][ny] = true;
                        q.push(State(nx, ny, nextSteps));
                    }
                }
            }
        }
        // 输出结果
        cout << "CASE# " << caseNo << ": ";
        if (foundPrime) cout << "The knight takes " << primeResult << " prime moves." << '\n';
        else {
            // 第二次BFS：寻找合数步数
            visited = vector<vector<bool>>(m, vector<bool>(n, false));
            queue<State> q2;
            q2.push(State(srow, scol, 0));
            visited[srow][scol] = true;
            int compositeResult = -1;
            bool foundComposite = false;
            while (!q2.empty() && !foundComposite) {
                State cur = q2.front(); q2.pop();
                for (int i = 0; i < 8; ++i) {
                    int nx = cur.x + dx[i], ny = cur.y + dy[i];
                    int nextSteps = cur.steps + 1;
                    if (nx >= 0 && nx < m && ny >= 0 && ny < n) {
                        if (nx == drow && ny == dcol) {
                            // 合数步到达目标，记录并停止
                            compositeResult = nextSteps;
                            foundComposite = true;
                            break;
                        } else if (!visited[nx][ny]) {
                            visited[nx][ny] = true;
                            q2.push(State(nx, ny, nextSteps));
                        }
                    }
                }
            }
            if (foundComposite) cout << "The knight takes " << compositeResult << " composite move(s)." << endl;
            else cout << "Destination is not reachable." << endl;
        }
    }
    return 0;
}
```

## 总结

本题的关键在于理解阿兹特克骑士的特殊移动规则和停留规则，并设计合适的 $\texttt{BFS}$ 策略来处理素数步和合数步的不同要求。通过两次 $\texttt{BFS}$ 分别寻找素数步和合数步的最短路径，可以有效地解决问题。代码实现时需要注意边界条件、状态标记和搜索终止条件的处理，尤其是当以合数步到达目标时不应立即停止搜索，以免错过后续可能的素数步路径。
