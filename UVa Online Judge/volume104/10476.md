## 题目描述

我们需要编写一个垃圾邮件过滤器程序，该程序读取由常规 $\texttt{ASCII}$ 字符（$32$-$127$）组成的电子邮件消息，并判断每条消息是否为垃圾邮件。

### 三字母组（$\texttt{Trigram}$）方法

一个有效的垃圾邮件检测方法是使用**三字母组**（$\texttt{trigram}$）。三字母组是消息中出现的三个相邻字符序列，区分大小写。通过比较消息的三字母组频率与已知垃圾邮件和非垃圾邮件的三字母组频率，我们可以判断消息是否为垃圾邮件。

### 分类方法

1. **样本分析**：
   - 分析大量垃圾邮件样本，计算每个三字母组 $t$ 在垃圾邮件中的频率$f_{spam}(t)$
   - 分析大量非垃圾邮件样本，计算每个三字母组 $t$ 在非垃圾邮件中的频率$f_{non-spam}(t)$

2. **相似度计算**：
   - 对于待分类的消息，计算其每个三字母组$t$的频率 $f_{message}(t)$
   - 使用余弦相似度计算消息与垃圾邮件样本、非垃圾邮件样本的相似度：
   
$$
   similarity(f_1,f_2) = \frac{\sum_{t}f_1(t)\cdot f_2(t)}{\sqrt{\sum_{t}[f_1(t)]^{2}}\cdot\sqrt{\sum_{t}[f_2(t)]^{2}}}
$$

3. **分类决策**：
   - 如果$similarity(f_{message},f_{spam}) > similarity(f_{message},f_{non-spam})$，则判定为垃圾邮件
   - 否则判定为非垃圾邮件

### 输入格式

输入包含多组测试数据（少于 $10$ 组）。每组数据格式如下：

- 第一行：三个整数 $s$、$n$、$c$ ：
  - $s$ $(0 < s < 5)$：垃圾邮件样本数量
  - $n$ $(0 < n < 5)$：非垃圾邮件样本数量
  - $c$ $(0 < c < 10)$：待分类消息数量
- 接下来是 $s$ 条垃圾邮件样本
- 然后是 $n$ 条非垃圾邮件样本
- 最后是 $c$ 条待分类消息

每条消息由多行文本组成，以包含 $\texttt{ENDMESSAGE}$ 的行结束。该行不会出现在消息内容中，也不被视为消息的一部分。每行不超过 $1000$ 个字符。

输入以 $s=0$、$n=0$、$c=0$ 结束，该组数据不应处理。

### 输出格式

对于每组测试数据：

1. 输出一行：$\texttt{Set X:}$（其中 $X$ 是测试组编号）
2. 对于每条待分类消息，输出两行：
   - 第一行：$similarity(f_{message},f_{spam})$ 和 $similarity(f_{message},f_{non-spam})$，保留 $5$ 位小数
   - 第二行：$\texttt{spam}$ 或 $\texttt{non-spam}$

### 重要注意事项

- 提取三字母组时**不包含换行符**
- **不提取跨越多行的三字母组**
- 每条消息的三字母组应从每行文本中单独提取

## 题目分析

### 核心思路

本题的核心是**文本相似度计算**。我们需要：

1. **特征提取**：将文本转换为数值特征（三字母组频率）
2. **向量表示**：将每条消息表示为高维空间中的向量
3. **相似度比较**：使用余弦相似度衡量向量间的相似性
4. **分类决策**：基于相似度比较结果进行分类

### 解题步骤

#### 步骤1：三字母组提取

对于每条消息，我们需要逐行处理：
- 对于每行文本，提取所有长度为 $3$ 的子串
- 不处理长度小于 $3$ 的行
- 不创建跨行的三字母组

#### 步骤2：频率统计

使用哈希表（$\texttt{unordered\_map}$）统计每个三字母组的出现次数：
- 键：三字母组字符串
- 值：出现次数

#### 步骤3：样本训练

- 读取 $s$ 条垃圾邮件样本，合并统计三字母组频率
- 读取 $n$ 条非垃圾邮件样本，合并统计三字母组频率

#### 步骤4：分类处理

对于每条待分类消息：
1. 提取其三字母组频率
2. 计算与垃圾邮件样本的余弦相似度
3. 计算与非垃圾邮件样本的余弦相似度
4. 比较两个相似度值，进行分类决策

### 余弦相似度计算细节

余弦相似度衡量两个向量在方向上的相似性，公式为：

$$
\cos\theta = \frac{\mathbf{A}\cdot\mathbf{B}}{\|\mathbf{A}\|\|\mathbf{B}\|} = \frac{\sum_{i=1}^{n}A_iB_i}{\sqrt{\sum_{i=1}^{n}A_i^2}\sqrt{\sum_{i=1}^{n}B_i^2}}
$$

在我们的问题中：
- $A_i$：消息中第 $i$ 个三字母组的频率
- $B_i$：样本中第 $i$ 个三字母组的频率

**注意**：实际计算时，我们只计算两个频率映射中共同存在的三字母组对点积的贡献。如果一个三字母组只出现在一个映射中，其频率为 $0$，对点积的贡献为 $0$，因此可以忽略。

### 算法复杂度

假设：
- $L$：单条消息的平均长度
- $M$：三字母组总数

1. **三字母组提取**：$O(L)$，因为每个字符最多被访问一次
2. **频率统计**：$O(M)$，需要遍历所有三字母组
3. **余弦相似度计算**：$O(\min(|f_1|, |f_2|))$，只需遍历较小的频率映射

总体复杂度对于题目规模是完全可行的。

### 关键实现细节

1. **逐行处理**：题目要求不创建跨行三字母组，必须逐行提取
2. **大小写敏感**：三字母组区分大小写
3. **频率累加**：样本消息的频率需要累加，不是覆盖
4. **精度要求**：输出保留 $5$ 位小数
5. **边界情况**：空消息、短消息（长度小于 $3$）的处理

## 解题思路详解

### 为什么使用三字母组？

三字母组是 $n\texttt{-gram}$（$n$ 元语法）的一种特例（$n=3$）。使用三字母组的原因包括：

1. **捕获局部模式**：能够捕获短距离的字符组合模式
2. **抗噪声能力**：相比单个字符，三字母组对拼写错误和变体更有抵抗力
3. **计算效率**：相比更长的 $n\texttt{-gram}$，三字母组的数量可控

### 为什么使用余弦相似度？

余弦相似度是文本相似度计算中常用的度量，其优点包括：

1. **长度归一化**：不受文本长度影响，只关注特征分布
2. **范围明确**：结果在$[-1, 1]$之间，$1$表示完全相同，$0$表示无关
3. **计算简单**：只需要点积和范数计算

### 为什么逐行处理很重要？

题目明确要求"不包含换行符"和"不创建跨行三字母组"。这是因为：

1. **真实场景**：邮件中的换行通常是格式需要，不是语义的一部分
2. **公平比较**：避免因换行位置不同导致不合理的相似度
3. **实现一致性**：确保所有实现采用相同的处理方式

### 如何处理短行？

对于长度小于 $3$ 的行，无法提取完整的三字母组。我们的实现通过循环条件 `i <= len - 3` 自动处理这种情况：当 `len < 3` 时，循环不会执行，不会产生三字母组。

### 多组数据处理的注意事项

1. **重置状态**：每组数据开始前，需要清空频率映射
2. **编号递增**：测试组编号从 $1$ 开始，每组递增
3. **终止条件**：遇到 $s=n=c=0$ 时终止程序
4. **输入缓冲**：使用 `cin.ignore()` 清除数字后的换行符（在代码中通过 `while (cin >> s >> n >> c && s)` 隐含处理）

## 代码实现

```cpp
// Spam or Not Spam

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

void process(unordered_map<string, int>& freq) {
    string line;
    while (getline(cin, line) && line != "ENDMESSAGE") {
        int len = line.length();
        for (int i = 0; i <= len - 3; ++i) {
            string trigram = line.substr(i, 3);
            ++freq[trigram];
        }
    }
}

// 计算两个频率映射之间的余弦相似度
double cosineSimilarity(const unordered_map<string, int>& f1, const unordered_map<string, int>& f2) {
    double dotProduct = 0.0, norm1 = 0.0, norm2 = 0.0;
    // 计算点积
    for (const auto& p : f1) {
        auto it = f2.find(p.first);
        if (it != f2.end()) 
            dotProduct += p.second * it->second;
    }
    // 计算 f1 的范数平方
    for (const auto& p : f1) norm1 += p.second * p.second;
    // 计算 f2 的范数平方
    for (const auto& p : f2) norm2 += p.second * p.second;
    if (norm1 == 0.0 || norm2 == 0.0) return 0.0;
    return dotProduct / (sqrt(norm1) * sqrt(norm2));
}

int main() {
    int s, n, c;
    int setNumber = 1;
    while (cin >> s >> n >> c && s) {
        // 读取垃圾邮件样本并合并频率
        unordered_map<string, int> spamFreq, nonSpamFreq;
        for (int i = 0; i < s; ++i) process(spamFreq);
        // 读取非垃圾邮件样本并合并频率
        for (int i = 0; i < n; ++i) process(nonSpamFreq);
        // 输出当前组编号
        cout << "Set " << setNumber++ << ":\n";
        // 处理待分类消息
        for (int i = 0; i < c; ++i) {
            unordered_map<string, int> messageFreq;
            process(messageFreq);
            // 计算相似度
            double simSpam = cosineSimilarity(messageFreq, spamFreq);
            double simNonSpam = cosineSimilarity(messageFreq, nonSpamFreq);
            // 输出相似度（保留五位小数）
            cout << fixed << setprecision(5) << simSpam << " " << simNonSpam << "\n";
            // 分类并输出结果
            if (simSpam > simNonSpam) cout << "spam\n";
            else cout << "non-spam\n";
        }
    }
    return 0;
}
```

### 本题要点总结

1. **特征选择**：三字母组是有效的文本特征
2. **相似度度量**：余弦相似度适合文本向量比较
3. **实现细节**：逐行处理、频率累加、边界处理

### 算法拓展

1. **特征加权**：可以为不同的三字母组赋予不同权重
2. **平滑处理**：使用拉普拉斯平滑处理未见过的三字母组
3. **多分类器组合**：结合多种特征和分类器提高准确率
4. **在线学习**：根据分类结果动态更新样本频率

本题的算法在实际垃圾邮件过滤中有一定应用，但现代系统通常使用更复杂的特征（如词袋模型、$\texttt{TF-IDF}$）和机器学习算法（如朴素贝叶斯、支持向量机、深度学习）。不过，三字母组方法作为基础方法，仍有助于理解文本分类的基本原理。
