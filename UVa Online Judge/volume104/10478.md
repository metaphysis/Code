[UVa 10478 The Falling Pillars](https://blog.csdn.net/metaphysis/article/details/163575111)

# 题目描述

有 $n$ 根宽度相同、高度相同的矩形柱子，柱子从左到右依次排列，相邻柱子对应基准点之间的水平距离为 $d$。所有柱子最初都竖直放置，并且只能向右倒下，倒下过程中不发生滑动或抬起。

当一根柱子倒下时，它的上部会接触右侧已经倒下的柱子。需要从右到左计算每根柱子倒下后与地面之间的夹角，并判断当前场景是否存在不稳定情况。

若相邻柱子的右侧面之间的距离小于柱子宽度，则柱子发生重叠，场景不可能实现。若右侧面之间的距离达到柱子高度，则柱子倒下后直接与地面接触，夹角为 $0$。

# 输入格式

第一行输入测试数据组数 $T$。

接下来有 $T$ 行，每行包含四个整数 $n$、$d$、$h$ 和 $w$，分别表示：

- $n$：柱子的数量。
- $d$：相邻柱子基准点之间的距离。
- $h$：柱子的高度。
- $w$：柱子的宽度。

数据满足 $0 < n \le 8$，$0 < d,h,w < 1001$，并且 $h \ge w$。

# 输出格式

对于每组数据，首先输出：

```text
Case k:
```

其中 $k$ 为测试数据的编号。

如果场景不可能实现，只输出：

```text
Impossible.
```

否则，当场景存在不稳定情况时，在角度之前输出：

```text
Unstable Situation.
```

接下来输出 $n-1$ 行角度。角度按照从右到左的顺序输出，保留小数点后三位。

# 题目分析

将最右侧柱子的右下角设为坐标原点。最右侧柱子的左侧面位于直线 $x=-w$ 上，其下端点为 $(-w,0)$，上端点为 $(-w,h)$。

处理任意一根尚未倒下的柱子时，只需要关注它的右下角和右侧已经倒下柱子的左侧面。设当前柱子的右下角为 $C$，已倒下柱子的左侧面起点为 $P$，该侧面从下端指向上端的单位方向向量为 $u$。

接触点 $A$ 位于这条侧面线段上，因此可以表示为：

$$
A = P + t u
$$

其中 $t$ 表示接触点到侧面下端点的距离，满足 $0 \le t \le h$。

由于柱子的长度为 $h$，当前柱子的右下角到接触点的距离等于 $h$，所以有：

$$
\lvert A-C \rvert = h
$$

将 $A=P+tu$ 代入距离方程，并利用 $u$ 是单位向量，可以得到关于 $t$ 的一元二次方程：

$$
\lvert P+tu-C \rvert^2=h^2
$$

展开后得到：

$$
t^2+2((P-C)\cdot u)t+\lvert P-C\rvert^2-h^2=0
$$

设：

$$
b=2((P-C)\cdot u)$$

$$
c=\lvert P-C\rvert^2-h^2$$

则方程为：

$$
t^2+bt+c=0
$$

根据求根公式得到两个候选参数：

$$
t_1=\frac{-b-\sqrt{b^2-4c}}{2}$$

$$
t_2=\frac{-b+\sqrt{b^2-4c}}{2}$$

题目保证经过特殊情况处理后一定存在合法接触点，因此计算两个交点后，选择满足 $x<0$ 且 $y>0$ 的交点即可。代码中使用 $\texttt{EPS}$ 处理浮点误差，将条件写成 $x<\texttt{EPS}$ 和 $y>\texttt{EPS}$。

得到接触点 $A$ 后，当前柱子从右下角 $C$ 指向接触点 $A$ 的方向就是柱子倒下后的方向。设该方向向量为 $A-C$，将其单位化得到：

$$
v=\frac{A-C}{\lvert A-C\rvert}
$$

柱子与地面之间的夹角由该方向向量计算：

$$
\theta=\operatorname{atan2}(v_y,v_x)\times\frac{180}{\pi}
$$

当前柱子倒下后，它的右侧面方向就是 $v$。将该方向沿左侧法线方向平移宽度 $w$，即可得到当前柱子的左侧面，作为下一根柱子求接触点时的支撑面。

向量 $v=(v_x,v_y)$ 的左侧单位法向量为：

$$
(-v_y,v_x)
$$

因此，当前柱子的左侧面下端点为：

$$
P_{new}=C+(-v_y,v_x)w
$$

下一根柱子继续使用这个新的支撑面进行相同计算。由于柱子从右到左处理，前一次计算得到的信息恰好可以作为后一次计算的输入。

# 解题思路

首先处理三种特殊情况。

当 $d<w$ 时，相邻柱子的右侧面距离小于柱子宽度，柱子之间会发生重叠，直接输出 `Impossible.`。

当 $d=w$ 时，柱子倒下后接触右侧柱子的底部位置，所有输出角度均为 $90$ 度。

当 $d-w\ge h$ 时，柱子倒下时无法接触右侧柱子，会直接落到地面，所有输出角度均为 $0$ 度。

对于剩余情况，先使用几何条件判断不稳定状态。接触后柱子的重心在地面上的投影必须位于右下角支撑点的左侧，才能保持稳定。根据题目几何关系，判定式为：

$$
\arccos\left(\frac{d-w}{h}\right)+\arctan\left(\frac{w}{h}\right)>\frac{\pi}{2}
$$

满足该条件时输出 `Unstable Situation.`，但仍然需要继续计算全部柱子的倒下状态。

随后初始化最右侧柱子的左侧面：

- 左侧面下端点为 $(-w,0)$。
- 左侧面方向向量为 $(0,1)$。

从右到左枚举其余柱子。第 $i$ 根待处理柱子的右下角坐标为：

$$
C_i=(-i \times d,0)
$$

使用当前支撑面的起点 $P$、单位方向向量 $u$ 和柱子高度 $h$ 建立圆与线段的交点方程，得到接触点 $A$。

计算 $A-C_i$ 的单位向量，利用 $\texttt{atan2}$ 得到当前柱子角度并输出。然后利用左侧法向量将当前柱子的右侧面平移 $w$，更新支撑面的起点和方向，继续处理左侧柱子。

# 代码实现


```cpp
// The Falling Pillars
// UVa ID: 10478
// Verdict: Accepted
// Submission Date: 2026-08-08
// UVa Run Time: 0.000s

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);
const double EPS = 1e-7;

struct Point {
    double x, y;
    Point operator + (const Point &p) const { return {x + p.x, y + p.y}; }
    Point operator - (const Point &p) const { return {x - p.x, y - p.y}; }
    Point operator * (double k) const { return {x * k, y * k}; }
};

double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }

double len(Point a) { return sqrt(dot(a, a)); }

Point unit(Point a) {
    double l = len(a);
    return a * (1.0 / l);
}

void getContact(Point c, Point p, Point u, double h, Point &a) {
    double b = 2.0 * dot(p - c, u);
    double cc = dot(p - c, p - c) - h * h;
    double delta = b * b - 4.0 * cc;
    double root = sqrt(max(0.0, delta));
    double t1 = (-b - root) / 2.0;
    double t2 = (-b + root) / 2.0;
    Point a1 = p + u * t1, a2 = p + u * t2;
    if (a1.x < EPS && a1.y > EPS) a = a1;
    else a = a2;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, d, h, w, tc;
    cin >> tc;
    cout << fixed << setprecision(3);
    for (int cs = 1; cs <= tc; cs++) {
        cin >> n >> d >> h >> w;
        cout << "Case " << cs << ":\n";
        if (n <= 1) continue;
        if (d < w) {
            cout << "Impossible.\n";
            continue;
        }
        if (d == w) {
            for (int i = 1; i < n; i++) cout << "90.000\n";
            continue;
        }
        if (d - w >= h) {
            for (int i = 1; i < n; i++) cout << "0.000\n";
            continue;
        }
        bool unstable = false;
        double value = (double)(d - w) / h;
        value = max(-1.0, min(1.0, value));
        double check = acos(value) + atan((double)w / h);
        unstable = check > PI / 2.0 + EPS;
        if (unstable) cout << "Unstable Situation.\n";
        Point side = {(double)-w, 0.0}, dir = {0.0, 1.0};
        for (int i = 1; i < n; i++) {
            Point base = {(double)-i * d, 0.0}, contact;
            getContact(base, side, dir, h, contact);
            Point axis = unit(contact - base);
            double angle = atan2(axis.y, axis.x) * 180.0 / PI;
            if (fabs(angle) < EPS) angle = 0.0;
            cout << angle << "\n";
            Point leftNormal = {-axis.y, axis.x};
            side = base + leftNormal * w;
            dir = axis;
        }
    }
    return 0;
}
```

# 总结

本题的核心是把柱子接触问题转化为圆与支撑线段的交点问题。每次处理时，当前柱子的右下角是圆心，柱子的高度是半径，右侧倒下柱子的左侧面是待求交点所在的线段。

通过一元二次方程求出接触点后，使用接触点与当前柱子右下角确定倒下方向，再利用法向量平移柱子宽度，便能递推得到下一根柱子的支撑面。

实现时必须优先处理不可能、垂直倒下和直接落地三种特殊情况，并使用 $\texttt{EPS}$ 控制浮点误差。整个过程只需从右到左遍历柱子，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。
