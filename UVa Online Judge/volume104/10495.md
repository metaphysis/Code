## 题目分析

本题要求计算圆锥表面上两点之间的最短距离。圆锥的底面半径为 $r$，位于 $z=0$ 平面，圆心在 $(0,0,0)$，顶点在 $(0,0,h)$。圆锥表面上的点使用圆锥坐标 $(d,A)$ 表示，其中：

- $d$ 是从顶点到该点沿着圆锥表面的距离
- $A$ 是从 $y=0$ 平面开始逆时针测量的角度（以度为单位）

我们需要找到在圆锥表面上连接两点的最短路径长度。

## 解题思路

### 关键观察

圆锥是一个**可展曲面**，这意味着我们可以将其展开成一个平面扇形，而不改变表面的度量性质。在展开图上，两点之间的最短路径就是连接它们的直线段。

### 数学推导

1. **计算圆锥的母线长度**：
   $$
   L = \sqrt{r^2 + h^2}
   $$
   这是从顶点到底面边缘的最长可能距离。

2. **计算展开扇形的圆心角**：
   $$
   \theta_{\text{sector}} = \frac{2\pi r}{L}
   $$
   这个公式来源于：底面周长 $2\pi r$ 等于扇形弧长 $L \cdot \theta_{\text{sector}}$。

3. **将圆锥坐标映射到展开图**：
   - 极径：$\rho = d$（直接使用距离 $d$）
   - 极角：$\psi = \frac{A}{360} \cdot \theta_{\text{sector}}$

4. **处理角度环绕**：
   由于圆锥展开后是一个扇形而非完整的圆，两点之间可能有两条路径。我们需要选择角度差较小的那条路径：
   $$
   \Delta\psi = \min(|\psi_1 - \psi_2|, \theta_{\text{sector}} - |\psi_1 - \psi_2|)
   $$

5. **计算直线距离**：
   使用极坐标下的余弦定理：
   $$
   \texttt{distance} = \sqrt{d_1^2 + d_2^2 - 2d_1d_2\cos(\Delta\psi)}
   $$

### 算法步骤

1. 读取输入数据：$r$, $h$, $d_1$, $A_1$, $d_2$, $A_2$
2. 计算母线长度 $L = \sqrt{r^2 + h^2}$
3. 计算扇形圆心角 $\theta_{\text{sector}} = 2\pi r / L$
4. 将角度转换为弧度：$\psi_1 = (A_1/360) \cdot \theta_{\text{sector}}$, $\psi_2 = (A_2/360) \cdot \theta_{\text{sector}}$
5. 计算最小角度差 $\Delta\psi$
6. 使用余弦定理计算距离
7. 输出结果，保留两位小数

## 复杂度分析

- **时间复杂度**：$O(1)$，仅涉及基本算术运算
- **空间复杂度**：$O(1)$，只使用常数个变量

## 代码实现

```cpp
// Conic Distance
// UVa ID: 10495
// Verdict: Accepted

//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <cmath>
#include <iomanip>

using namespace std;

int main() {
    double r, h, d1, A1, d2, A2;
    const double PI = acos(-1.0);  // 精确计算π值
    
    // 读取多组测试数据
    while (cin >> r >> h >> d1 >> A1 >> d2 >> A2) {
        // 计算圆锥的母线长度
        double L = sqrt(r * r + h * h);
        
        // 计算展开扇形的圆心角
        double sector_angle = 2.0 * PI * r / L;
        
        // 将角度转换为展开图上的极角
        double psi1 = (A1 / 360.0) * sector_angle;
        double psi2 = (A2 / 360.0) * sector_angle;
        
        // 计算角度差，考虑圆锥的环绕特性
        double delta_psi = fabs(psi1 - psi2);
        delta_psi = min(delta_psi, sector_angle - delta_psi);
        
        // 使用余弦定理计算最短距离
        double dist = sqrt(d1 * d1 + d2 * d2 - 2.0 * d1 * d2 * cos(delta_psi));
        
        // 输出结果，保留两位小数
        cout << fixed << setprecision(2) << dist << endl;
    }
    
    return 0;
}
```

## 代码说明

- 使用 `acos(-1.0)` 来精确计算 $\pi$ 值，避免硬编码带来的精度问题
- 通过 `while (cin >> ...)` 循环处理多组输入数据
- 关键步骤是计算最小角度差 `delta_psi`，这确保了我们选择的是圆锥表面上的最短路径
- 使用 `fixed` 和 `setprecision(2)` 保证输出格式符合题目要求

这个解法充分利用了圆锥的可展曲面特性，将三维空间中的最短路径问题转化为二维平面上的直线距离计算，既高效又准确。
