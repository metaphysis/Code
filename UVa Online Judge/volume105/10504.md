## 题目描述

给定一个 $n \times n$ 的网格，每个格子包含一个大写字母。对于每个指定的字母，我们需要统计在网格中能够形成的正方形的数量，其中正方形的四个顶点都必须出现在该字母所在的位置。

**输入格式**：
- 第一行：网格尺寸 $n$
- 第二行：需要统计的字母数量 $m$
- 接下来 $n$ 行：网格内容，每行一个字符串
- 接下来 $m$ 行：需要统计的字母
- 以 $0$ 作为输入结束标志

**输出格式**：
- 对于每个字母，输出字母和对应的正方形数量
- 不同问题之间用空行分隔

## 题目分析

这是一个几何计数问题，我们需要找到所有可能的正方形，这些正方形的顶点必须：
1. 位于网格的整数坐标位置
2. 所有顶点位置的字母都是目标字母
3. 正方形可以是任意大小和方向（不限于与坐标轴平行）

### 关键观察

对于平面上的任意两个点 $P_1 = (x_1, y_1)$ 和 $P_2 = (x_2, y_2)$，如果它们作为正方形的一条边，那么可以唯一确定另外两个顶点：

设向量 $\vec{v} = (dx, dy) = (x_2 - x_1, y_2 - y_1)$，那么另外两个顶点为：
- $P_3 = (x_1 - dy, y_1 + dx)$
- $P_4 = (x_2 - dy, y_2 + dx)$

或者另一个方向：
- $P_3 = (x_1 + dy, y_1 - dx)$  
- $P_4 = (x_2 + dy, y_2 - dx)$

### 算法思路

对于每个目标字母：
1. **收集坐标**：遍历网格，收集所有该字母出现的位置坐标
2. **枚举点对**：对于每对不同的点 $(P_i, P_j)$，计算可能的另外两个顶点
3. **验证正方形**：检查计算出的顶点是否也在该字母的坐标集合中
4. **去重处理**：由于每个正方形会被计数多次，最后需要除以 $4$

### 复杂度分析

- 网格最大尺寸：$n \leq 100$，最多 $10,000$ 个格子
- 最坏情况下，某个字母占据大部分格子，点集大小 $S \approx n^2$
- 枚举点对复杂度：$O(S^2)$，最坏约 $10^8$ 次操作
- 由于常数较小且实际数据不会达到最坏情况，算法可以接受

## 解题思路详解

### 1. 数据结构选择

使用 `set<Point>` 来存储某个字母的所有位置坐标，这样可以实现 $O(\log n)$ 的查找操作，便于快速验证顶点是否存在。

### 2. 正方形计数原理

对于每对点 $(P_1, P_2)$，我们考虑它们作为正方形的一条边。根据向量旋转的性质，可以计算出两个可能的正方形：

- **顺时针旋转**：$P_3 = P_1 + (-dy, dx)$，$P_4 = P_2 + (-dy, dx)$
- **逆时针旋转**：$P_3 = P_1 + (dy, -dx)$，$P_4 = P_2 + (dy, -dx)$

如果两个计算出的顶点都在目标字母的坐标集合中，就找到了一个有效的正方形。

### 3. 去重机制

每个正方形有 $4$ 条边，每条边会被枚举 $2$ 次（两个方向），因此每个正方形总共会被计数 $8$ 次。但实际上，我们的枚举方式只考虑 $i < j$，并且每个正方形有 $4$ 条边，所以每个正方形会被计数 $4$ 次，最后需要除以 $4$。

```cpp
#include <iostream>
#include <vector>
#include <set>
#include <string>
using namespace std;

// 坐标点结构体
struct Point {
    int x, y;
    Point(int x_, int y_) : x(x_), y(y_) {}
    // 重载小于运算符，用于set排序
    bool operator<(const Point& other) const {
        if (x != other.x) return x < other.x;
        return y < other.y;
    }
};

/**
 * 统计给定点集中可以形成的正方形数量
 * @param points 目标字母的所有坐标集合
 * @return 正方形数量
 */
int countSquares(const set<Point>& points) {
    int cnt = 0;
    // 将set转换为vector便于遍历
    vector<Point> vec(points.begin(), points.end());
    int n = vec.size();
    
    // 枚举所有点对
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            int x1 = vec[i].x, y1 = vec[i].y;
            int x2 = vec[j].x, y2 = vec[j].y;
            
            // 计算两点之间的向量
            int dx = x2 - x1, dy = y2 - y1;
            
            // 第一种可能的正方形（顺时针旋转）
            Point p3(x1 - dy, y1 + dx);
            Point p4(x2 - dy, y2 + dx);
            if (points.count(p3) && points.count(p4)) {
                cnt++;
            }
            
            // 第二种可能的正方形（逆时针旋转）
            Point p5(x1 + dy, y1 - dx);
            Point p6(x2 + dy, y2 - dx);
            if (points.count(p5) && points.count(p6)) {
                cnt++;
            }
        }
    }
    
    // 每个正方形被计数4次（4条边）
    return cnt / 4;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int n;
    bool firstProblem = true;
    
    // 处理多个测试用例，直到遇到0
    while (cin >> n && n != 0) {
        // 问题之间输出空行
        if (!firstProblem) {
            cout << "\n";
        }
        firstProblem = false;
        
        int m;
        cin >> m;
        vector<string> grid(n);
        
        // 读入网格
        for (int i = 0; i < n; ++i) {
            cin >> grid[i];
        }
        
        // 处理每个目标字母
        for (int letterIdx = 0; letterIdx < m; ++letterIdx) {
            char target;
            cin >> target;
            set<Point> points;
            
            // 收集目标字母的所有位置
            for (int i = 0; i < n; ++i) {
                for (int j = 0; j < n; ++j) {
                    if (grid[i][j] == target) {
                        points.insert(Point(i, j));
                    }
                }
            }
            
            // 统计并输出结果
            int squares = countSquares(points);
            cout << target << " " << squares << "\n";
        }
    }
    
    return 0;
}
```

## 算法特点

1. **全面性**：能够找到所有方向的正方形，包括不与坐标轴平行的
2. **高效性**：利用哈希集合实现快速查找，优化了验证过程
3. **正确性**：通过数学推导确保正方形计算的准确性
4. **鲁棒性**：处理了重复计数问题，保证结果的正确性

## 总结

本题的关键在于理解平面几何中正方形的向量表示方法，通过枚举边和向量旋转来寻找所有可能的正方形。算法的时间复杂度在题目约束范围内是可接受的，且实现相对简洁明了。这种基于向量运算的方法可以推广到其他类似的几何计数问题中。
