## 题目描述

给定两个整数 $X$ 和 $Y$，满足 $X \geq Y$，并且它们的取值范围在 $16$ 位有符号整数内（即 $-2^{15} \leq X, Y \leq 2^{15}-1$）。  
定义：
$$
P = (X + Y) \cdot Y  \\
Q = |X - Y| \cdot X
$$
由于 $X \geq Y$，所以 $|X - Y| = X - Y$，因此：
$$
Q = (X - Y) \cdot X
$$

现在给出 $P$ 和 $Q$ 的值，要求找出 $X$ 和 $Y$。  
如果有多组解，输出 $X$ 最小的那组；如果无解，输出 `Impossible.`。

---

## 题目分析

我们有两个方程：
$$
\begin{cases}
(X + Y) \cdot Y = P \quad &(1) \\
(X - Y) \cdot X = Q \quad &(2)
\end{cases}
$$
其中 $X, Y$ 是整数，且 $X \geq Y$。

---

## 解题思路

### 1. 分类讨论

为了方便推导和避免遗漏边界情况，我们根据 $P$ 和 $Q$ 是否为零分为四种情况：

#### 情况 1：$P = 0$，$Q = 0$

由 $(1)$ 得：
$$
(X + Y) \cdot Y = 0
$$
由 $(2)$ 得：
$$
(X - Y) \cdot X = 0
$$
联立可得：
- $Y = 0$ 或 $X = -Y$
- $X = 0$ 或 $X = Y$

唯一满足所有条件的解是：
$$
X = 0, \quad Y = 0
$$

---

#### 情况 2：$P = 0$，$Q \neq 0$

由 $(1)$ 得：
$$
(X + Y) \cdot Y = 0 \Rightarrow Y = 0 \text{ 或 } X = -Y
$$

- **子情况 2.1：$Y = 0$**  
  代入 $(2)$：
$$
  (X - 0) \cdot X = X^2 = Q
$$
  所以 $X = \pm \sqrt{Q}$，要求 $Q \geq 0$ 且为完全平方数。

- **子情况 2.2：$X = -Y$**  
  代入 $(2)$：
$$
  (-Y - Y) \cdot (-Y) = (-2Y)(-Y) = 2Y^2 = Q
$$
  所以 $Y^2 = Q/2$，要求 $Q$ 为非负偶数且 $Q/2$ 为完全平方数。

---

#### 情况 3：$P \neq 0$，$Q = 0$

由 $(2)$ 得：
$$
(X - Y) \cdot X = 0 \Rightarrow X = 0 \text{ 或 } X = Y
$$

- **子情况 3.1：$X = 0$**  
  代入 $(1)$：
$$
  (0 + Y) \cdot Y = Y^2 = P
$$
  所以 $Y = \pm \sqrt{P}$，要求 $P \geq 0$ 且为完全平方数。

- **子情况 3.2：$X = Y$**  
  代入 $(1)$：
$$
  (X + X) \cdot X = 2X^2 = P
$$
  所以 $X^2 = P/2$，要求 $P$ 为非负偶数且 $P/2$ 为完全平方数。

---

#### 情况 4：$P \neq 0$，$Q \neq 0$

我们可以将 $(1)$ 和 $(2)$ 展开：
$$
XY + Y^2 = P \quad (1') \\
X^2 - XY = Q \quad (2')
$$

将 $(1')$ 和 $(2')$ 相加：
$$
X^2 + Y^2 = P + Q
$$

我们也可以从 $(1')$ 解出 $X$：
$$
X = \frac{P}{Y} - Y
$$
代入 $(2')$ 并整理，得到一个关于 $Y^2$ 的二次方程：
$$
2(Y^2)^2 - (3P + Q)(Y^2) + P^2 = 0
$$
令 $u = Y^2$，则：
$$
2u^2 - (3P + Q)u + P^2 = 0
$$
判别式为：
$$
\Delta = (3P + Q)^2 - 8P^2 = P^2 + 6PQ + Q^2
$$
解得：
$$
u = \frac{3P + Q \pm \sqrt{\Delta}}{4}
$$
要求 $\Delta \geq 0$ 且为完全平方数，$u$ 为非负整数且为完全平方数，$Y = \pm \sqrt{u}$，且 $P$ 能被 $Y$ 整除。

---

### 2. 筛选与输出

- 所有解必须满足 $X \geq Y$ 且在 $16$ 位有符号整数范围内。
- 如果有多个解，选择 $X$ 最小的那个。
- 如果没有解，输出 `Impossible.`。

## 代码实现

```cpp
// A Day in Math-land
// UVa ID: 10512
// Verdict: Accepted
// Submission Date: 2025-11-17
// UVa Run Time: 0.130s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int caseNum = 1; caseNum <= n; caseNum++) {
        long long p, q;
        cin >> p >> q;
        
        vector<pair<long long, long long>> solutions;
        
        // 情况1: P = 0, Q = 0
        if (p == 0 && q == 0) {
            solutions.push_back({0, 0});
        }
        // 情况2: P = 0, Q ≠ 0
        else if (p == 0 && q != 0) {
            // 子情况2.1: Y = 0
            if (q >= 0) {
                long long x = sqrt(q);
                if (x * x == q) {
                    if (x >= 0) solutions.push_back({x, 0});
                    if (-x >= 0 && x != 0) solutions.push_back({-x, 0});
                }
            }
            // 子情况2.2: X = -Y
            if (q % 2 == 0 && q >= 0) {
                long long ySq = q / 2;
                long long y = sqrt(ySq);
                if (y * y == ySq) {
                    solutions.push_back({-y, y});
                    if (y != 0) solutions.push_back({y, -y});
                }
            }
        }
        // 情况3: P ≠ 0, Q = 0
        else if (p != 0 && q == 0) {
            // 子情况3.1: X = 0
            if (p >= 0) {
                long long y = sqrt(p);
                if (y * y == p) {
                    if (0 >= y) solutions.push_back({0, y});
                    if (0 >= -y && y != 0) solutions.push_back({0, -y});
                }
            }
            // 子情况3.2: X = Y
            if (p % 2 == 0 && p >= 0) {
                long long xSq = p / 2;
                long long x = sqrt(xSq);
                if (x * x == xSq) {
                    solutions.push_back({x, x});
                    if (x != 0) solutions.push_back({-x, -x});
                }
            }
        }
        // 情况4: P ≠ 0, Q ≠ 0
        else {
            long long delta = p * p + 6 * p * q + q * q;
            if (delta >= 0) {
                long long sqrtDelta = sqrt(delta);
                if (sqrtDelta * sqrtDelta == delta) {
                    for (int sign = -1; sign <= 1; sign += 2) {
                        long long numerator = 3 * p + q + sign * sqrtDelta;
                        if (numerator % 4 == 0) {
                            long long u = numerator / 4;
                            if (u >= 0) {
                                long long y = sqrt(u);
                                if (y * y == u && y != 0) {
                                    for (int ySign = -1; ySign <= 1; ySign += 2) {
                                        long long yy = y * ySign;
                                        if (p % yy == 0) {
                                            long long xx = p / yy - yy;
                                            if (xx >= yy && xx * (xx - yy) == q) {
                                                solutions.push_back({xx, yy});
                                            }
                                        }
                                    }
                                }
                            }
                        }
                    }
                }
            }
        }
        
        // 过滤有效解（在16位有符号整数范围内且满足 X ≥ Y）
        vector<pair<long long, long long>> validSolutions;
        for (auto sol : solutions) {
            if (sol.first >= -32768 && sol.first <= 32767 &&
                sol.second >= -32768 && sol.second <= 32767 &&
                sol.first >= sol.second) {
                validSolutions.push_back(sol);
            }
        }
        
        // 去重和排序
        if (validSolutions.empty()) {
            cout << "Case " << caseNum << ":\nImpossible.\n";
        } else {
            sort(validSolutions.begin(), validSolutions.end());
            auto uniqueEnd = unique(validSolutions.begin(), validSolutions.end());
            validSolutions.erase(uniqueEnd, validSolutions.end());
            cout << "Case " << caseNum << ":\n" << validSolutions[0].first << " " << validSolutions[0].second << "\n";
        }
    }
    return 0;
}
```

## 复杂度分析

- 对于每个测试用例，我们最多尝试有限个候选解（常数级别）。
- 主要时间开销在于求解二次方程和验证解的有效性。
- 总复杂度为 $O(N)$，可以轻松处理 $N \leq 75000$ 的数据规模。

## 总结

本题的关键在于将问题分为四种情况分别处理，避免遗漏边界条件。通过数学推导和分类讨论，我们可以高效地找到所有可能的解，并按要求输出最优解或判断无解。
