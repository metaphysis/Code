## 题目分析

### 问题描述

一群热爱和平的人们决定回归原始生活，不使用任何现代设备（除了太阳能计算机）。他们需要确定自己所在位置的纬度，使用的方法是：

从地点 $A$ 出发：
1. 向北走 $n$ 公里
2. 向东走 $n$ 公里  
3. 向南走 $n$ 公里
4. 向西走 $m$ 公里

最终回到起点 $A$。根据 $n$ 和 $m$ 的值，可以计算出地点 $A$ 的纬度。

### 约束条件

- 纬度范围：$0^\circ$ 到 $70^\circ$ 北纬
- $n < 1001$ 公里
- $n < m$
- 地球半径：$6378$ 公里
- $\pi = 2 \times \cos^{-1}(0)$

## 解题思路

### 几何建模

将地球视为完美球体，半径为 $R = 6378$ 公里。设地点 $A$ 的纬度为 $\phi$（弧度制）。

1. **向北移动**：移动 $n$ 公里后，纬度增加 $\Delta\phi = \frac{n}{R}$ 弧度
2. **向东移动**：在纬度 $\phi + \Delta\phi$ 处，纬线圈半径为 $R\cos(\phi + \Delta\phi)$，向东移动 $n$ 公里对应的经度变化为 $\frac{n}{R\cos(\phi + \Delta\phi)}$ 弧度
3. **向南移动**：回到原始纬度 $\phi$
4. **向西移动**：在纬度 $\phi$ 处，纬线圈半径为 $R\cos(\phi)$，向西移动 $m$ 公里对应的经度变化为 $\frac{m}{R\cos(\phi)}$ 弧度

### 关键方程

为了回到起点，向东和向西移动的经度变化必须相等（模 $2\pi$ 的整数倍）：

$$
\frac{n}{R\cos(\phi + \frac{n}{R})} = \frac{m}{R\cos(\phi)} + 2\pi k
$$

其中 $k$ 为整数。由于 $n < m$ 且纬度范围有限，通常 $k = 0$，得到简化方程：

$$
\frac{n}{\cos(\phi + \frac{n}{R})} = \frac{m}{\cos(\phi)}
$$

整理得：

$$
\cos\left(\phi + \frac{n}{R}\right) = \frac{n}{m} \cos(\phi)
$$

### 求解方法

这是一个关于$\phi$的超越方程，无法直接解析求解。我们采用**二分法**在 $[0, 70^\circ]$ 范围内数值求解。

**二分法步骤**：
1. 定义函数 $f(\phi) = \cos(\phi + \frac{n}{R}) - \frac{n}{m}\cos(\phi)$
2. 在区间 $[0, 70^\circ]$ 内，$f(\phi)$ 是单调的
3. 通过二分法找到 $f(\phi) = 0$ 的解

### 有效性检查

在计算前需要检查：
1. $n \geq 1001$：违反约束条件
2. $n \geq m$：违反输入条件
3. 计算出的纬度不在 $[0, 70^\circ]$ 范围内：无解

### 输出格式

将计算出的纬度（弧度）转换为度、分、秒：
- 度：取整数部分
- 分：取小数部分 $\times 60$ 的整数部分  
- 秒：剩余小数部分 $\times 60$ 并四舍五入

## 算法复杂度

- 时间复杂度：$O(N \times \text{迭代次数})$，其中 $N \leq 5000$，迭代次数为 $100$
- 空间复杂度：$O(1)$

```cpp
#include <bits/stdc++.h>
using namespace std;

const double earthRadius = 6378.0;
const double pi = 2 * acos(0.0);

double toRadians(double degrees) {
    return degrees * pi / 180.0;
}

double toDegrees(double radians) {
    return radians * 180.0 / pi;
}

int main() {
    int numCases;
    cin >> numCases;
    for (int caseNum = 1; caseNum <= numCases; caseNum++) {
        double n, m;
        cin >> n >> m;
        if (n >= 1001.0 || n >= m) {
            cout << "Case " << caseNum << ": Invalid or impossible." << endl;
            continue;
        }
        double ratio = n / m;
        double low = 0.0, high = toRadians(70.0), mid;
        bool found = false;
        for (int iter = 0; iter < 100; iter++) {
            mid = (low + high) / 2.0;
            double left = cos(mid + n / earthRadius);
            double right = ratio * cos(mid);
            if (left > right) low = mid;
            else high = mid;
        }
        double latitude = toDegrees(mid);
        if (latitude < 0.0 || latitude > 70.0) {
            cout << "Case " << caseNum << ": Invalid or impossible." << endl;
            continue;
        }
        int degrees = static_cast<int>(latitude);
        double minutesFloat = (latitude - degrees) * 60.0;
        int minutes = static_cast<int>(minutesFloat);
        double secondsFloat = (minutesFloat - minutes) * 60.0;
        int seconds = static_cast<int>(secondsFloat + 0.5);
        if (seconds == 60) {
            seconds = 0;
            minutes++;
        }
        if (minutes == 60) {
            minutes = 0;
            degrees++;
        }
        cout << "Case " << caseNum << ": " << degrees << " deg " << minutes << " min " << seconds << " sec" << endl;
    }
    return 0;
}
```
