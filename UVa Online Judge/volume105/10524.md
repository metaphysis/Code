## 题目描述

$\texttt{Moni}$ 在观看了电影《$\texttt{MATRIX RELOADED}$》后对矩阵产生了浓厚兴趣，决定编写一个计算矩阵逆的程序。题目要求我们实现一个程序，对于输入的多个矩阵，计算它们的逆矩阵。如果矩阵可逆，则输出其逆矩阵；如果矩阵是奇异的（没有逆矩阵），则输出 `Not possible`。

### 输入格式

输入包含多个测试用例。每个测试用例的格式如下：

1. 第一行是一个整数 $n$ ，表示矩阵的阶数。
2. 接下来 $n$ 行，每行包含 $n$ 个浮点数，表示矩阵的元素。
3. 连续的测试用例之间用一个空行分隔。
4. 输入以 $n = 0$ 结束。

### 输出格式

对于每个测试用例：

1. 如果矩阵可逆，输出其逆矩阵，每行元素之间用空格分隔，保留 $6$ 位小数。
2. 如果矩阵不可逆，输出一行 `Not possible`。
3. **每个测试用例输出后都要输出一个空行**。

### 重要约束

- **不允许选主元（$\texttt{No pivoting is allowed}$）** ：这意味着在消元过程中不能交换行。
- 奇异矩阵没有逆矩阵。
- 矩阵元素可能是浮点数，需要处理精度问题。

## 题目分析

这是一个典型的数值线性代数问题，核心是计算矩阵的逆。我们需要考虑以下几个关键点：

### 1. 矩阵可逆性的判定

一个 $n \times n$ 矩阵 $A$ 可逆的充分必要条件是它的行列式不为零，或者说它是非奇异的。在计算过程中，如果消元时遇到零主元，则说明矩阵是奇异的，不可逆。

### 2. 高斯-约当消元法

计算矩阵逆最常用的方法是**高斯-约当消元法（$\texttt{Gauss-Jordan elimination}$）** 。基本思想是：

1. 构造增广矩阵 $[A \mid I]$ ，其中 $I$ 是 $n \times n$ 的单位矩阵。
2. 通过对增广矩阵进行行变换，将 $A$ 部分化为单位矩阵。
3. 此时增广矩阵的右半部分就是 $A$ 的逆矩阵 $A^{-1}$ 。

具体步骤：
- 对于每一列 $i$ （$i$ 从 $0$ 到 $n-1$ ）：
  1. 如果 $a_{ii} = 0$ ，矩阵奇异，无法求逆。
  2. 将第 $i$ 行除以 $a_{ii}$ ，使主元变为 $1$ 。
  3. 对于所有其他行 $j \neq i$ ，将第 $j$ 行减去 $a_{ji}$ 倍的第 $i$ 行，使第 $i$ 列的其他元素变为 $0$ 。

### 3. 不允许选主元的处理

题目明确要求 “$\texttt{No pivoting is allowed}$”，这意味着：
- 不能交换行来避免零主元。
- 如果遇到 $a_{ii} = 0$ ，直接判定矩阵奇异，输出 `Not possible`。
- 这可能会导致一些实际上可逆的矩阵被判定为不可逆（比如置换矩阵），但这是题目要求。

### 4. 浮点数精度处理

由于矩阵元素是浮点数，需要设置一个合适的精度阈值 $EPS$ （如 $10^{-9}$ ）来判断一个数是否为零。在比较时使用 $|a_{ii}| < EPS$ 来判断主元是否为零。

### 5. 输入输出细节

- 输入可能包含多个测试用例，需要循环读取直到 $n = 0$ 。
- 连续测试用例之间有空行，但 $\texttt{C++}$ 的 `cin` 会自动跳过空白字符，因此可以直接读取。
- 输出格式要求严格：每行元素空格分隔，保留 $6$ 位小数，每个测试用例后输出空行。

## 解题思路

### 算法设计

1. **读取输入**：循环读取 $n$ ，直到 $n = 0$ 。对于每个测试用例，读取 $n \times n$ 的矩阵。
2. **复制矩阵**：由于高斯-约当消元会修改原矩阵，需要先复制一份。
3. **高斯-约当消元求逆**：
   - 初始化一个单位矩阵作为逆矩阵的初始值。
   - 对于每一列 $i$ ：
     - 检查主元 $a_{ii}$ 是否为零（绝对值小于 $EPS$ ）。如果是，返回失败。
     - 将第 $i$ 行除以 $a_{ii}$ ，同时更新逆矩阵的对应行。
     - 对于所有其他行 $j \neq i$ ，消去第 $i$ 列的元素，同时更新逆矩阵。
   - 消元完成后，原矩阵部分变为单位矩阵，而初始的单位矩阵变为逆矩阵。
4. **输出结果**：
   - 如果求逆成功，输出逆矩阵（每行元素空格分隔，保留 $6$ 位小数）。
   - 如果失败，输出 `Not possible`。
   - 每个测试用例后输出一个空行。

### 时间复杂度

高斯-约当消元法的时间复杂度为 $O(n^3)$ ，其中 $n$ 是矩阵的阶数。对于每个测试用例，都需要执行 $O(n^3)$ 次浮点运算。题目没有给出 $n$ 的范围，但考虑到是数值计算，通常 $n$ 不会太大。

### 空间复杂度

需要存储两个 $n \times n$ 的矩阵：原矩阵（或消元过程中的矩阵）和逆矩阵。空间复杂度为 $O(n^2)$ 。

```cpp
#include <bits/stdc++.h>
using namespace std;

const double EPS = 1e-9; // 浮点数比较精度

// 高斯-约当消元求逆，不允许选主元
bool gaussJordanInverseNoPivoting(vector<vector<double>>& a) {
    int n = a.size();
    vector<vector<double>> inv(n, vector<double>(n, 0.0));
    // 初始化单位矩阵
    for (int i = 0; i < n; i++) inv[i][i] = 1.0;
    // 高斯消元，不允许选主元
    for (int i = 0; i < n; i++) {
        // 检查主元是否接近0（不允许交换行）
        if (fabs(a[i][i]) < EPS) return false;
        // 归一化当前行
        double divisor = a[i][i];
        for (int j = 0; j < n; j++) {
            a[i][j] /= divisor;
            inv[i][j] /= divisor;
        }
        // 消去其他行的当前列
        for (int j = 0; j < n; j++) {
            if (j != i && fabs(a[j][i]) > EPS) {
                double factor = a[j][i];
                for (int k = 0; k < n; k++) {
                    a[j][k] -= factor * a[i][k];
                    inv[j][k] -= factor * inv[i][k];
                }
            }
        }
    }
    // 将逆矩阵复制回a
    a = inv;
    return true;
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n;
    while (cin >> n && n != 0) {
        vector<vector<double>> matrix(n, vector<double>(n));
        // 读入矩阵
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                cin >> matrix[i][j];
        // 复制矩阵用于计算
        vector<vector<double>> original = matrix;
        // 计算逆矩阵（不允许选主元）
        bool possible = gaussJordanInverseNoPivoting(matrix);
        if (!possible) cout << "Not possible\n";
        else {
            // 输出逆矩阵，每行元素用空格分隔
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (j > 0) cout << " ";
                    cout << fixed << setprecision(6) << matrix[i][j];
                }
                cout << "\n";
            }
        }
        // 每个测试用例后输出空行
        cout << "\n";
    }
    return 0;
}
```

## 代码说明

### 1. 常量定义

`EPS = 1e-9` 用于浮点数比较，判断主元是否为零。

### 2. 高斯-约当消元函数

`gaussJordanInverseNoPivoting` 函数实现了不允许选主元的高斯-约当消元：

- 参数 `a` 是原矩阵，函数会修改它，最终存储逆矩阵。
- 初始化一个单位矩阵 `inv` 。
- 对于每一列：
  - 检查主元是否为零，如果是则返回 `false` 。
  - 归一化当前行（主元变为 $1$ ）。
  - 消去其他行的当前列元素。
- 将计算得到的逆矩阵复制回 `a` 。
- 成功返回 `true` ，失败返回 `false` 。

### 3. 主函数

- 使用 `ios::sync_with_stdio(false)` 和 `cin.tie(0)` 加速输入输出。
- 循环读取测试用例，直到 $n = 0$ 。
- 读取矩阵，调用消元函数。
- 根据返回值输出逆矩阵或“Not possible”。
- 每个测试用例后输出空行。

### 4. 输出格式控制

- `fixed` 和 `setprecision(6)` 保证输出 $6$ 位小数。
- 每行元素之间用空格分隔，每行末尾换行。
- 每个测试用例后输出空行。
