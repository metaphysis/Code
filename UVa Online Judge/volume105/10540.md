## 题目描述

一位数学家 $\texttt{Determinant}$ 在相交的圆中发现了美丽的鲜花图案。给定 $N$ 个半径均为 $R$ 的圆，它们相交于一个公共点，且相邻圆之间的角度相等。这些圆形成了多层花瓣结构，每层花瓣数量相等。

我们需要计算每层花瓣的总面积和可见面积。其中：
- 总面积：不考虑本层花瓣间重叠的面积之和
- 可见面积：扣除上层遮挡后的实际可见面积

## 输入格式

输入包含多组数据，每组数据包含两个整数 $R$ 和 $N$，其中 $50 \geq R > 0$，$100 \geq N \geq 3$。输入以 $0\ 0$ 结束。

## 输出格式

对于每组数据，首先输出集合编号，然后输出层数 $L$，接着输出 $L$ 行，每行包含该层的总面积和可见面积（保留 $4$ 位小数）。

## 题目分析

### 几何背景

这个问题涉及多个相交圆的几何计算。关键观察点：

1. **层数计算**：层数 $L = \lfloor (N + 1) / 2 \rfloor$
2. **花瓣形成**：第 $i$ 层花瓣由相距 $k = L - 1 - i$ 个位置的圆相交形成
3. **底层特殊处理**：最底层（$k = 0$）的花瓣就是完整的圆

### 核心思路

解题的关键在于理解三层面积概念：

1. **总面积** ($totalArea[i]$)：不考虑重叠时该层所有花瓣的面积和
2. **重叠面积** ($overlapArea[i]$)：该层实际占据的区域面积
3. **可见面积** ($visibleArea[i]$)：最终可见的区域面积

### 面积计算推导

#### 1. 单个花瓣面积计算

对于非底层花瓣（$k > 0$）：

- 两个圆的圆心距离：$d = 2R \cdot \sin(\frac{\pi k}{N})$
- 圆心角：$\theta = 2 \cdot \arccos(\frac{d}{2R})$
- 弓形面积：$segmentArea = \frac{1}{2} R^2 (\theta - \sin\theta)$
- 单个花瓣面积：$petalArea = 2 \cdot segmentArea$
- 该层总面积：$totalArea[i] = N \cdot petalArea$

对于底层花瓣（$k = 0$）：
- $totalArea[i] = N \cdot \pi R^2$

#### 2. 重叠面积计算

重叠面积反映了该层实际占据的空间：

- 顶层：$overlapArea[0] = totalArea[0]$
- 其他层：$overlapArea[i] = totalArea[i] - totalArea[i-1]$

#### 3. 可见面积计算

可见面积考虑了上层的遮挡效应：

- 顶层：$visibleArea[0] = overlapArea[0]$
- 其他层：$visibleArea[i] = overlapArea[i] - overlapArea[i-1]$

### 算法步骤

1. 读取 $R$ 和 $N$
2. 计算层数 $L = (N + 1) / 2$
3. 对于每层 $i$，计算 $k = L - 1 - i$
4. 根据 $k$ 值计算该层总面积
5. 计算重叠面积和可见面积
6. 输出结果

## 复杂度分析

- 时间复杂度：$O(N)$，其中 $N$ 是圆的个数
- 空间复杂度：$O(1)$，使用固定大小的数组

## 参考代码

```cpp
// Flowers of a Beautiful Mind
// UVa ID: 10540
// Verdict: Accepted

// UVa Run Time: 0.020s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = 2 * acos(0.0);

int main() {
    int R, N;
    int setNum = 1;
    double totalArea[64], overlapArea[64], visibleArea[64];
    while (cin >> R >> N && (R != 0 || N != 0)) {
        int layers = (N + 1) / 2;
        for (int i = 0; i < layers; i++) {
            int k = layers - 1 - i;
            if (k == 0) totalArea[i] = N * PI * R * R;
            else {
                double angleBetween = 2 * PI * k / N;
                double d = 2 * R * sin(angleBetween / 2);
                double theta = 2 * acos(d / (2 * R));
                double segmentArea = 0.5 * R * R * (theta - sin(theta));
                double petalArea = 2 * segmentArea;
                totalArea[i] = N * petalArea;
            }
        }
        cout << "Set " << setNum++ << ":\n";
        cout << layers << "\n";
        cout << fixed << setprecision(4);
        visibleArea[0] = overlapArea[0] = totalArea[0];
        cout << totalArea[0] << " " << visibleArea[0] << "\n";
        for (int i = 1; i < layers; i++) {
            overlapArea[i] = totalArea[i] - totalArea[i - 1];
            visibleArea[i] = overlapArea[i] - overlapArea[i - 1];
            cout << totalArea[i] << " " << visibleArea[i] << "\n";
        }
    }
    return 0;
}
```

## 总结

本题的关键在于理解多层花瓣的几何关系和遮挡效应。通过分析总面积、重叠面积和可见面积之间的关系，我们能够准确地计算出每层的可见区域。这种分层计算的方法既保证了正确性，又具有较高的效率。
