## 题目分析

### 问题描述
在 $n$ 维空间中，给定两个点 $P(p_1, p_2, \ldots, p_n)$ 和 $Q(q_1, q_2, \ldots, q_n)$。空间被划分为单位超立方体（$1 \times 1 \times \cdots \times 1$ 的 $n$ 维立方体）。需要计算从 $P$ 到 $Q$ 的直线穿过的**不同**单位超立方体的数量，这个数量就是“移动成本”。

### 关键理解
1. **单位超立方体**：每个维度的坐标都是整数的 $n$ 维立方体。
2. **直线穿过**：直线从点 $P$ 到点 $Q$，会穿过一系列单位超立方体。
3. **不同**：相同的单位超立方体只计数一次。

### 输入输出
- **输入**：多组测试数据，每组包含维度 $D$ 和两个点的坐标。
- **输出**：每组数据的移动成本。

## 解题思路

### 1. 问题转化
设第 $i$ 个维度的坐标差为 $\Delta_i = |p_i - q_i|$。问题转化为计算直线 $PQ$ 穿过的网格数量。

### 2. 一维情况分析
在一维空间中（一条直线），直线 $PQ$ 穿过的单位区间数量为 $|\Delta_1|$。例如，从坐标 $10$ 到 $20$，穿过的单位区间为 $[10,11], [11,12], \ldots, [19,20]$，共 $10$ 个。

### 3. 二维情况分析
在二维平面中，从点 $P$ 到点 $Q$ 的直线会穿过一些单位正方形。直觉上，穿过的正方形数量等于 $\Delta_x + \Delta_y$，但这样会重复计算一些情况。

考虑更一般的情况：
- 如果 $\Delta_x$ 或 $\Delta_y$ 为 $0$，直线沿着网格线移动，不进入任何正方形内部，成本为 $0$。
- 否则，直线会进入一些正方形。实际上，成本为 $\Delta_x + \Delta_y - \gcd(\Delta_x, \Delta_y)$。

为什么减去 $\gcd$？
- 直线会经过一些网格线的交点，这些交点位于多个正方形的公共顶点。
- 在计算 $\Delta_x + \Delta_y$ 时，这些交点被重复计数了。
- $\gcd(\Delta_x, \Delta_y)$ 表示直线在网格中经过的“整点”（坐标都是整数的点）数量减 $1$（不包括起点）。

### 4. 多维推广
对于 $n$ 维空间，使用**容斥原理**（$\texttt{Inclusion-Exclusion Principle}$）计算成本。

设 $\Delta_i = |p_i - q_i|$，则成本为：
$$
cost = \sum_{i} \Delta_i  - \sum_{i < j} \gcd(\Delta_i, \Delta_j) + \sum_{i < j < k} \gcd(\Delta_i, \Delta_j, \Delta_k) - \cdots + (-1)^{n+1} \gcd(\Delta_1, \Delta_2, \ldots, \Delta_n)
$$

**解释**：
- 第一项 $\sum \Delta_i$：每个维度上穿过的边界总数。
- 第二项 $\sum \gcd(\Delta_i, \Delta_j)$：减去两个维度交点处的重复计数。
- 第三项 $\sum \gcd(\Delta_i, \Delta_j, \Delta_k)$：三个维度交点处被多减了，需要加回来。
- 以此类推，符号交替变化。

### 5. 特殊情况的处理
- **如果有某个 $\Delta_i = 0$**：这意味着直线在该维度上没有移动，完全沿着超立方体的边界。此时，直线不会进入任何超立方体内部，成本为 $0$。
- **一维情况**：按照上述公式，当 $n = 1$ 时，成本为 $\Delta_1$。

### 6. 算法步骤
1. 读入维度 $n$ 和点 $P$ 的坐标。
2. 读入点 $Q$ 的坐标，计算每个维度的坐标差绝对值 $\Delta_i$。
3. 如果任何 $\Delta_i = 0$，输出 $0$。
4. 否则，使用容斥原理计算：
   - 遍历所有非空子集（$2^n - 1$ 个子集）。
   - 对每个子集，计算子集中所有 $\Delta_i$ 的最大公约数。
   - 根据子集大小的奇偶性决定加或减。
5. 输出结果。

### 7. 复杂度分析
- 维度 $n \leq 10$，子集数量为 $2^n - 1 \leq 1023$。
- 每个子集计算最大公约数，时间复杂度为 $O(n \cdot 2^n)$，完全可行。

## 代码实现

```cpp
// Hyper-drive
// UVa ID: 10542
// Verdict: Accepted
// Submission Date: 2025-12-01
// UVa Run Time: 0.050s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

ll n, a[12];  // a[i]存储第i个维度的坐标差绝对值

ll solve() {
    // 检查是否有任何维度差为0
    for (int i = 0; i < n; i++)
        if (a[i] == 0) return 0;
    
    ll r = 0;
    // 遍历所有非空子集 (2^n - 1 个子集)
    for (int S = 1; S < (1 << n); S++) {
        int cnt = 0;  // 子集中元素个数
        ll d = 0;     // 子集中所有元素的最大公约数
        
        for (int i = 0; i < n; i++) {
            if (S & (1 << i)) {
                cnt++;
                d = __gcd(a[i], d);
            }
        }
        
        // 容斥原理：奇数个元素加，偶数个元素减
        if (cnt & 1) r += d;    // 奇数个元素，加
        else r -= d;    // 偶数个元素，减
    }
    return r;
}

int main() {
    int T;
    cin >> T;
    
    for (int cs = 1; cs <= T; cs++) {
        cin >> n;
        for (int i = 0; i < n; i++) cin >> a[i];
        
        // 读取Q点，计算坐标差的绝对值
        for (int i = 0, x; i < n; i++) {
            cin >> x;
            a[i] = abs(a[i] - x);
        }
        
        cout << "Case " << cs << ": " << solve() << '\n';
    }
    return 0;
}
```

## 示例验证

### 示例1
输入：
```
2
2
10 10
10 13
1
10
20
```
计算过程：
1. 第一组：$n=2$，$\Delta_1 = 0$，$\Delta_2 = 3$。由于 $\Delta_1 = 0$，返回 $0$。
2. 第二组：$n=1$，$\Delta_1 = 10$。只有一个子集 $\{1\}$，$d = \gcd(10) = 10$，$cnt=1$（奇数），结果 $r=10$。

输出：
```
Case 1: 0
Case 2: 10
```

### 示例2
假设输入：
```
1
3
1 1 1
4 5 6
```
计算过程：
- $\Delta_1 = 3$，$\Delta_2 = 4$，$\Delta_3 = 5$
- 所有 $\Delta_i > 0$，使用容斥原理：
  - 单元素子集：$3 + 4 + 5 = 12$
  - 两元素子集：$\gcd(3,4)=1$，$\gcd(3,5)=1$，$\gcd(4,5)=1$，减去 $3$
  - 三元素子集：$\gcd(3,4,5)=1$，加上 $1$
  - 结果：$12 - 3 + 1 = 10$

因此，从 $(1,1,1)$ 到 $(4,5,6)$ 穿过的单位立方体数量为 $10$。

## 总结
本题的关键是将几何问题转化为数论问题，使用容斥原理和最大公约数计算直线穿过的网格数量。虽然维度最高为 $10$，但由于使用了容斥原理，算法效率仍然很高。通过本题，我们可以学习到如何将几何直觉与组合数学相结合，解决复杂的高维空间问题。
