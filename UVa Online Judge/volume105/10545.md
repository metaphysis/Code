[UVa 10545 Maximal Quadrilateral](https://blog.csdn.net/metaphysis/article/details/154956672)

## 题目描述

一个圆内切于一个四边形，并且该圆与四边形的四条边都相切。给定四边形的周长和两条相邻边的长度，我们需要找出圆的最大可能半径。

**输入格式：**
- 第一行包含一个整数 $N$ ($N \leq 100$)，表示测试用例的数量
- 接下来的 $N$ 行每行包含三个整数 $P, A, B$，其中 $P$ 是周长，$A, B$ 是四边形两条相邻边的长度

**输出格式：**
- 对于每个测试用例，输出 `Case i: ` 后跟最大可能半径（保留6位小数）
- 如果无法构成这样的四边形，输出 `Eta Shombhob Na.`（孟加拉语，意为"这是不可能的"）

## 题目分析

### 关键性质

这是一个关于圆外切四边形（ $\texttt{tangential quadrilateral}$ ）的问题。圆外切四边形有一个重要性质：

**对边和相等性质**：如果一个四边形有内切圆，那么它的对边之和相等。

设四边形的四条边分别为 $a, b, c, d$，其中 $a = A$, $b = B$（已知的两条相邻边），则有：
$$a + c = b + d$$

### 数学推导

已知周长 $P = a + b + c + d$，结合对边和相等性质：
$$a + c = b + d = \frac{P}{2}$$

由此可以求出另外两条边：
$$c = \frac{P}{2} - a$$
$$d = \frac{P}{2} - b$$

设半周长 $s = \frac{P}{2}$，则：
$$c = s - A,\quad d = s - B$$

### 有效性检查

要构成有效的四边形，必须满足以下条件：
1. 所有边长必须为正数：$A > 0$, $B > 0$, $c > 0$, $d > 0$
2. 四边形必须存在内切圆（由我们的推导过程保证）

### 最大半径计算

对于圆外切四边形，面积 $S$ 与内切圆半径 $r$ 的关系为：
$$S = r \cdot s$$

其中 $s = \frac{P}{2}$ 是半周长。

要最大化半径 $r$，就需要最大化面积 $S$。对于给定的四条边，当四边形是双心四边形（既有内切圆又有外接圆）时面积最大，此时面积可由**布拉马古普塔公式**计算：
$$S = \sqrt{(s-a)(s-b)(s-c)(s-d)}$$

因此最大半径为：
$$r_{\text{max}} = \frac{S}{s} = \frac{\sqrt{(s-A)(s-B)(s-c)(s-d)}}{s}$$

其中 $c = s - A$, $d = s - B$。

## 算法步骤

1. 读入测试用例数量 $N$
2. 对于每个测试用例：
   - 读入 $P, A, B$
   - 计算半周长 $s = \frac{P}{2}$
   - 计算另外两条边 $c = s - A$, $d = s - B$
   - 检查有效性：如果 $A \leq 0$ 或 $B \leq 0$ 或 $c \leq 0$ 或 $d \leq 0$，输出 `Eta Shombhob Na.`
   - 否则，计算面积 $S = \sqrt{(s-A)(s-B)(s-c)(s-d)}$
   - 计算半径 $r = \frac{S}{s}$
   - 输出结果，保留 $6$ 位小数

## 复杂度分析

- 时间复杂度：$O(N)$，每个测试用例只需要常数时间计算
- 空间复杂度：$O(1)$，只需要几个变量存储中间结果

## 代码实现

```cpp
// Maximal Quadrilateral
// UVa ID: 10545
// Verdict: Accepted
// Submission Date: 2025-11-17
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        int p, a, b;
        cin >> p >> a >> b;
        double s = p / 2.0;
        double c = s - a;
        double d = s - b;
        if (a <= 0 || b <= 0 || c <= 0 || d <= 0) {
            cout << "Case " << i << ": Eta Shombhob Na.\n";
            continue;
        }
        double area = sqrt((s - a) * (s - b) * (s - c) * (s - d));
        double radius = area / s;
        cout << "Case " << i << ": " << fixed << setprecision(6) << radius << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于理解圆外切四边形的性质，特别是对边和相等的特性。通过这个性质，我们可以从已知的两条相邻边和周长推导出所有四条边的长度，然后利用布拉马古普塔公式计算最大面积，从而得到最大内切圆半径。

需要注意的边界情况是当计算出的边长不满足正数条件时，四边形无法构成，此时需要输出相应的错误信息。
