## 题目描述

给定一个递归函数，定义如下：

- $f(0,0) = 1$
- 当 $n > 0$ 且 $0 \leq r < n(k-1)+1$ 时：
  $$f(n,r) = \sum_{i=0}^{k-1} f(n-1, r-i)$$
- 其他情况下 $f(n,r) = 0$

需要计算：
$$x = \left( \sum_{i=0}^{n(k-1)} f(n,i) \right) \bmod m, \quad \text{其中 } m = 10^t$$

### 输入格式
输入包含多组测试数据（不超过 $1001$ 行），每行包含三个整数：
- $k$ ($0 < k < 10^{19}$)
- $n$ ($0 < n < 10^{19}$)  
- $t$ ($0 < t < 10$)

输入以 `0 0 0` 结束。

### 输出格式
对于每组测试数据，输出 `Case #i: x`，其中 `i` 是测试用例编号，`x` 是计算结果。

## 题目分析

### 递归函数的含义
这个递归函数 $f(n,r)$ 实际上计算的是：
- 从 $n$ 个位置中，每个位置可以取 $0$ 到 $k-1$ 之间的值
- 所有位置值的总和等于 $r$ 的方案数

初始条件 $f(0,0) = 1$ 表示没有位置且总和为 $0$ 时只有 $1$ 种方案。

### 生成函数方法
我们可以用生成函数来理解这个问题：

每个位置的生成函数为：
$$1 + x + x^2 + \cdots + x^{k-1}$$

那么 $n$ 个位置的生成函数为：
$$F_n(x) = (1 + x + x^2 + \cdots + x^{k-1})^n$$

在这个生成函数中，$f(n,r)$ 就是 $x^r$ 的系数。

### 关键简化
我们需要计算所有系数的和：
$$S = \sum_{r=0}^{n(k-1)} f(n,r)$$

根据生成函数的性质，所有系数之和等于生成函数在 $x=1$ 处的值：
$$S = F_n(1) = (1 + 1 + \cdots + 1)^n = k^n$$

因此，原问题简化为计算：
$$x = k^n \bmod 10^t$$

### 算法选择
由于 $k$ 和 $n$ 的最大值可达 $10^{19}$，直接计算 $k^n$ 显然不可行。我们需要使用**快速幂算法**结合模运算：

1. 计算模数 $m = 10^t$
2. 使用快速幂计算 $(k \bmod m)^n \bmod m$
3. 时间复杂度为 $O(\log n)$，可以处理大指数情况

## 解题思路

### 步骤详解

1. **读取输入**：循环读取 $k$, $n$, $t$，直到遇到 `0 0 0`
2. **计算模数**：$m = 10^t$
3. **快速幂取模**：
   - 将 $k$ 对 $m$ 取模，避免大数乘法
   - 使用快速幂算法计算 $(k \bmod m)^n \bmod m$
4. **输出结果**：按照要求格式输出

### 快速幂算法原理
快速幂算法的核心思想是：
- 将指数 $n$ 用二进制表示
- 通过平方和乘法来减少计算次数
- 例如：$a^{13} = a^{8} \times a^{4} \times a^{1}$

### 复杂度分析
- **时间复杂度**：$O(\log n)$，其中 $n$ 是指数
- **空间复杂度**：$O(1)$
- 可以高效处理 $n$ 和 $k$ 高达 $10^{19}$ 的情况

```cpp
#include <iostream>
#include <cstdio>
using namespace std;

// 快速幂取模 (base^exp) % mod
long long powMod(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) {
            result = (result * base) % mod;
        }
        base = (base * base) % mod;
        exp >>= 1;
    }
    return result;
}

int main() {
    long long k, n;
    int t;
    int caseNum = 1;
    
    while (cin >> k >> n >> t) {
        if (k == 0 && n == 0 && t == 0) {
            break;
        }
        
        long long mod = 1;
        for (int i = 0; i < t; i++) {
            mod *= 10;
        }
        
        long long ans = powMod(k, n, mod);
        
        printf("Case #%d: %lld\n", caseNum++, ans);
    }
    
    return 0;
}
```

## 总结

本题的关键在于发现递归函数与组合数学的关联，通过生成函数的方法将复杂的递归求和问题转化为简单的模幂运算问题。使用快速幂算法可以高效解决大数取模问题，使得算法能够在规定时间内处理极大的输入值。

这种将复杂问题转化为简单数学公式的思路在竞赛编程中非常常见，需要培养对问题的数学洞察力和抽象能力。
