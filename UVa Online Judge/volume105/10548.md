[UVa 10548 Find the Right Changes](https://blog.csdn.net/metaphysis/article/details/155551430)

## 题目描述

在早期没有货币概念时，人们通过交换货物进行交易。假设某个社会中存在两种货物 $A$ 和 $B$ 。买家需要支付相当于 $c > 0$ 的金额。如果他可以选择同时使用 $A$ 和 $B$ 两种货物来支付，它们的单位价值分别为 $a > 0$ 、 $b > 0$ 。然而，如果 $a$ 和 $b$ 中有一个为负数，则表示卖家拥有该货物用于交换。 $a$ 和 $b$ 中至多有一个为负数。现在的问题是，如果可能的话，找出买家使用货物 $A$ 和 $B$ 支付 $c > 0$ 的交换方式有多少种。

### 输入格式

第一行包含一个整数 $n$ （ $0 < n < 1001$ ），表示测试用例的数量。接下来的 $n$ 行每行包含三个整数 $a$ 、 $b$ 和 $c$ 。可以假设 $|a|, |b|, |c| < 2^{31}$ 且 $a$ 、 $b$ 或 $c$ 均不为零。

### 输出格式

对于每个测试用例，如果存在若干种使用货物 $A$ 和 $B$ 来支付 $c$ 的组合，则输出组合的数量。如果不可能，则输出 `Impossible` 。如果有无穷多种组合，则输出 `Infinitely many solutions` 。

### 样例输入
```
3
3 5 17
7 -23 571
10 36 7
```

### 样例输出
```
1
Infinitely many solutions
Impossible
```

## 题目分析

本题实际上是一个线性丢番图方程的**非负整数解计数问题** 。我们可以将问题抽象为求解以下方程：
$$
a \cdot x + b \cdot y = c
$$
其中 $x, y \ge 0$ 为整数（表示货物 $A$ 和 $B$ 的数量）， $a, b, c$ 为给定的整数，且满足 $a, b, c \neq 0$ ， $a$ 和 $b$ 中**至多有一个为负数** 。

题目中有一个关键说明：如果 $a$ 或 $b$ 为负数，表示卖家持有该货物用于交换。这意味着当系数为负时，买家实际上是**获得**该货物，而不是付出。因此，我们仍然要求 $x, y \ge 0$ ，只是系数可正可负。

### 解题思路

我们需要根据 $a, b$ 的正负情况分类讨论：

#### 情况 $1$：$a > 0$ 且 $b > 0$ 
这是标准形式：
$$
a x + b y = c
$$
要求 $x \ge 0, y \ge 0$ 的整数解个数。  
**步骤：**
1. 使用扩展欧几里得算法检查方程是否有整数解，即判断 $g = \gcd(a, b)$ 是否能整除 $c$ 。若不能，则输出 `Impossible` 。
2. 若 $c < 0$ ，由于 $a>0, b>0$ ，左边非负，右边为负，显然无解，输出 `Impossible` 。
3. 否则，求出一组特解 $(x_0, y_0)$ ，通解为：
   $$
   x = x_0 + k \cdot \frac{b}{g}, \quad y = y_0 - k \cdot \frac{a}{g}, \quad k \in \mathbb{Z}
   $$
4. 为使 $x, y \ge 0$ ，解出 $k$ 的范围：
   $$
   k \ge \lceil -x_0 / (b/g) \rceil, \quad k \le \lfloor y_0 / (a/g) \rfloor
   $$
5. 若该范围内有整数，则输出整数个数；否则输出 `Impossible` 。

#### 情况 $2$：$a > 0$ 且 $b < 0$ （或 $a < 0$ 且 $b > 0$ ）
不失一般性，设 $a > 0, b < 0$ 。方程为：
$$
a x + b y = c
$$
令 $b' = -b > 0$ ，方程可重写为：
$$
a x - b' y = c
$$
**关键观察**：  
通过扩展欧几里得算法求出通解形式为（设 $g = \gcd(a, b')$ ）：
$$
x = x_0 + k \cdot \frac{b'}{g}, \quad y = y_0 + k \cdot \frac{a}{g}, \quad k \in \mathbb{Z}
$$
注意，这里 $x$ 和 $y$ 都随着 $k$ 的增加而增加。  
因此，如果存在一组非负整数解 $(x_0 \ge 0, y_0 \ge 0)$ ，那么对于所有 $k \ge 0$ ，解 $(x, y)$ 都是非负的，从而得到无穷多解。  
反之，如果没有任何整数解，则输出 `Impossible` 。  
因此，**此情况只有两种可能**：
- 若 $g \mid c$ ，则输出 `Infinitely many solutions` 。
- 否则输出 `Impossible` 。

#### 情况 $3$：$a < 0$ 且 $b < 0$ 
题目规定 $a$ 和 $b$ 至多一个为负数，因此此情况不会出现。

#### 情况 $4$：$c < 0$ 的特殊处理
- 当 $a>0, b>0$ 时，左边非负，右边为负，直接输出 `Impossible` 。
- 当 $a>0, b<0$ 或 $a<0, b>0$ 时， $c$ 的正负不影响解的存在性判断，仍按情况 2 处理。

### 算法步骤总结
1. 读入 $n$ 。
2. 对于每组 $a, b, c$ ：
   - 如果 $a>0$ 且 $b>0$ ：
     - 若 $c<0$ ，输出 `Impossible` 。
     - 否则，计算非负解个数（可能为 0、有限个）。
   - 如果 $a>0$ 且 $b<0$ 或 $a<0$ 且 $b>0$ ：
     - 检查 $\gcd(|a|, |b|)$ 是否整除 $c$ ，若是则输出 `Infinitely many solutions` ，否则输出 `Impossible` 。

---

## 时间复杂度分析
- 扩展欧几里得算法求 $\gcd$ 的时间复杂度为 $O(\log \max(|a|, |b|))$ 。
- 每组数据只需常数次运算，总时间复杂度为 $O(n \log M)$ ，其中 $M = 2^{31}$ ，完全可行。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 扩展欧几里得算法，返回 gcd(a,b)，并解出 ax + by = gcd(a,b) 的一组整数解 (x,y)
long long extendedGcd(long long a, long long b, long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long g = extendedGcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

// 计算 a>0, b>0, c>0 时方程 ax + by = c 的非负整数解的个数
long long countNonnegSolutions(long long a, long long b, long long c) {
    long long x0, y0;
    long long g = extendedGcd(a, b, x0, y0);
    if (c % g != 0) return 0; // 无整数解
    x0 *= c / g;
    y0 *= c / g;
    long long A = a / g, B = b / g;
    // 通解: x = x0 + k*B, y = y0 - k*A
    // 需要 x >= 0 且 y >= 0
    long long low = ceil((-x0) / (double)B);
    long long high = floor(y0 / (double)A);
    if (low > high) return 0;
    return high - low + 1;
}

int main() {
    int n; scanf("%d", &n);
    while (n--) {
        long long a, b, c; scanf("%lld %lld %lld", &a, &b, &c);
        
        // 情况 1: a>0, b>0
        if (a > 0 && b > 0) {
            if (c < 0) puts("Impossible"); // 左边非负，右边为负，无解
            else {
                long long cnt = countNonnegSolutions(a, b, c);
                if (cnt == 0) puts("Impossible");
                else printf("%lld\n", cnt);
            }
        }
        // 情况 2: a<0, b>0
        else if (a < 0 && b > 0) {
            // 化为正系数方程判断解的存在性
            long long g = __gcd(llabs(a), llabs(b));
            if (c % g == 0) puts("Infinitely many solutions");
            else puts("Impossible");
        }
        // 情况 3: a>0, b<0
        else if (a > 0 && b < 0) {
            long long g = __gcd(llabs(a), llabs(b));
            if (c % g == 0) puts("Infinitely many solutions");
            else puts("Impossible");
        }
        // 情况 4: a<0, b<0 不会出现（题目约束）
    }
    return 0;
}
```
