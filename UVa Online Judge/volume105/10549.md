## 题目描述

俄罗斯套娃是一种彩绘的空心木制玩偶。一套中的玩偶形状大致相同（通常是人形），但尺寸不同。当组装成套时，最大的玩偶包含第二大的，第二大的包含第三大的，依此类推。

我们可以将玩偶的形状近似为一个圆柱体，高度为 $h$，直径为 $d$，壁厚为 $w$。这样的玩偶会有一个空心部分，高度为 $h - 2w$，直径为 $d - 2w$。

$\texttt{Boris}$ 和 $\texttt{Natasha}$ 各有一套玩偶。这两套几乎完全相同；每套有相同数量的玩偶，外观相同但尺寸不同。昨晚他们玩完玩偶后放在客厅，他们的母亲把所有玩偶都收拾到一个盒子里。请你帮助 $\texttt{Boris}$ 和 $\texttt{Natasha}$ 分开他们的套娃。

### 输入格式

标准输入包含多个测试用例。每个测试用例的第一行包含 $n$，表示每套中的玩偶数量（$1 < n \leq 100$）。接下来有 $2n$ 行；每行给出一个玩偶的尺寸 $h, d, w$（$h, d \geq 2w > 0$）。最后一个测试用例后有一行包含 `0`。

### 输出格式

对于每个测试用例，将玩偶分成两套嵌套玩偶，使得在每套内部，玩偶可以按照描述的方式直立嵌套。输出的前 $n$ 行应给出第一套玩偶的尺寸，按高度降序排列。接下来一行应包含一个连字符 `-`。接下来的 $n$ 行应给出第二套玩偶的尺寸，也按高度降序排列。总是存在解决方案。如果有多个解决方案，输出任意一个即可。测试用例之间输出一个空行。

## 题目分析

### 问题理解

这是一个典型的组合优化问题，我们需要将 $2n$ 个玩偶分成两个集合，每个集合包含 $n$ 个玩偶，并且每个集合内的玩偶必须能够按照大小顺序相互嵌套。

### 嵌套条件分析

关键是要理解一个玩偶能够包含另一个玩偶的条件。对于两个玩偶 $A$ 和 $B$，其中 $A$ 是外层玩偶，$B$ 是内层玩偶：

- $A$ 的空心高度必须 $\geq B$ 的高度
- $A$ 的空心直径必须 $\geq B$ 的直径

空心尺寸计算公式：
- 空心高度 = $h - 2w$
- 空心直径 = $d - 2w$

### 解题思路

#### 方法选择

这个问题可以使用回溯法（$\texttt{Backtracking}$）来解决。由于 $n \leq 100$，总玩偶数为 $200$，回溯法在合理剪枝的情况下是可行的。

#### 算法步骤

1. **数据预处理**：
   - 读取所有玩偶的尺寸
   - 计算每个玩偶的空心尺寸
   - 按高度降序排序所有玩偶

2. **回溯搜索**：
   - 从第一个玩偶开始，尝试将其放入集合 $1$ 或集合 $2$
   - 对于每个玩偶，检查能否放入当前集合的末尾（即能否被集合中最后一个玩偶包含）
   - 如果两个集合都尝试失败，则回溯到上一步

3. **终止条件**：
   - 当所有玩偶都成功分配到两个集合时，找到解
   - 由于题目保证总有解，回溯法最终会找到合法分配

#### 复杂度分析

- 时间复杂度：最坏情况 $O(2^{2n})$，但由于良好的剪枝和题目约束，实际运行效率很高
- 空间复杂度：$O(n)$，主要用于存储回溯路径

```cpp
// Russian Dolls

#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>

using namespace std;

struct Doll {
    int h, d, w;
    int hollow_h, hollow_d;
};

bool compareDolls(const Doll& a, const Doll& b) {
    return a.h > b.h;
}

bool canContain(const Doll& outer, const Doll& inner) {
    return (outer.hollow_h >= inner.h) && (outer.hollow_d >= inner.d);
}

int main() {
    int n;
    bool firstCase = true;
    
    while (cin >> n && n != 0) {
        if (!firstCase) {
            cout << endl;
        }
        firstCase = false;
        
        int total = 2 * n;
        vector<Doll> dolls(total);
        
        for (int i = 0; i < total; i++) {
            cin >> dolls[i].h >> dolls[i].d >> dolls[i].w;
            dolls[i].hollow_h = dolls[i].h - 2 * dolls[i].w;
            dolls[i].hollow_d = dolls[i].d - 2 * dolls[i].w;
        }
        
        sort(dolls.begin(), dolls.end(), compareDolls);
        
        vector<Doll> set1, set2;
        
        function<bool(int)> backtrack = [&](int idx) {
            if (idx == total) {
                return true;
            }
            
            if (set1.size() < n) {
                if (set1.empty() || canContain(set1.back(), dolls[idx])) {
                    set1.push_back(dolls[idx]);
                    if (backtrack(idx + 1)) return true;
                    set1.pop_back();
                }
            }
            
            if (set2.size() < n) {
                if (set2.empty() || canContain(set2.back(), dolls[idx])) {
                    set2.push_back(dolls[idx]);
                    if (backtrack(idx + 1)) return true;
                    set2.pop_back();
                }
            }
            
            return false;
        };
        
        bool success = backtrack(0);
        
        if (!success) {
            set1.clear();
            set2.clear();
            for (int i = 0; i < total; i++) {
                if (i % 2 == 0) {
                    set1.push_back(dolls[i]);
                } else {
                    set2.push_back(dolls[i]);
                }
            }
        }
        
        for (const auto& doll : set1) {
            cout << doll.h << " " << doll.d << " " << doll.w << endl;
        }
        cout << "-" << endl;
        for (const auto& doll : set2) {
            cout << doll.h << " " << doll.d << " " << doll.w << endl;
        }
    }
    
    return 0;
}
```

## 总结

本题的关键在于正确理解嵌套条件和选择合适的搜索策略。通过回溯法系统地尝试所有可能的分配方案，并在每一步进行可行性剪枝，最终能够找到满足条件的解。算法的时间复杂度在最坏情况下较高，但由于问题规模较小且剪枝有效，实际运行效率可以接受。

注意点：
1. 嵌套条件是"能够容纳"而非"严格大于"，因此使用 $\geq$ 而不是 $>$
2. 玩偶需要按高度降序排列，这样每个集合自然形成从大到小的顺序
3. 回溯时优先尝试一个集合，失败后再尝试另一个集合，避免重复搜索
