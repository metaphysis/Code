## 题目描述

本题要求我们实现一个家谱管理系统，能够处理以下五种命令：

1. **$\texttt{BIRTH}$** 命令：记录一个人的出生信息，包括姓名、出生日期、母亲姓名和父亲姓名。
2. **$\texttt{DEATH}$** 命令：记录一个人的死亡日期。
3. **$\texttt{ANCESTORS}$** 命令：查询一个人的祖先，并按特定格式输出家族树。
4. **$\texttt{DESCENDANTS}$** 命令：查询一个人的后代，并按特定格式输出反向家族树。
5. **$\texttt{QUIT}$** 命令：结束程序。

输入保证每个人的名字是唯一的，且 `DEATH` 、 `ANCESTORS` 和 `DESCENDANTS` 命令中引用的名字都已经通过 `BIRTH` 命令给出。

## 题目分析

### 核心问题

这是一个典型的数据结构设计与树形遍历问题。我们需要：

1. **设计合适的数据结构** 来存储人物信息和他们之间的亲属关系。
2. **高效解析输入命令** ，处理名字可能包含空格和标点的复杂情况。
3. **实现祖先和后代查询** ，这本质上是树的遍历问题：
   - 祖先查询：从指定节点向上遍历父母链
   - 后代查询：从指定节点向下遍历子女链
4. **严格按照格式要求输出** ，包括缩进、日期信息和空行分隔。

### 关键难点

1. **名字解析** ：名字可以包含任意字符（除了开头/结尾的空格和冒号），这增加了字符串处理的复杂度。
2. **字母顺序要求** ：题目要求按字母顺序打印父母和子女，而不是按照输入顺序或性别顺序。
3. **部分信息缺失** ：有些人可能只有名字记录而没有完整的出生信息（如样例中的 $\texttt{Adam Doe}$ 和 $\texttt{Jane Doe}$）。
4. **递归输出的格式控制** ：需要精确控制缩进层级，并在适当位置输出日期信息。

## 解题思路

### 数据结构设计

我们使用一个结构体 `Person` 来存储每个人的信息：

```cpp
struct Person {
    string name;                // 姓名
    string birthDate;           // 出生日期
    string deathDate;           // 死亡日期
    vector<string> children;    // 子女列表
    string mother;              // 母亲姓名
    string father;              // 父亲姓名
};
```

使用 `unordered_map<string, Person>` 来存储所有人，以姓名为键，便于快速查找。

### 算法流程

#### 1. 输入解析

**$\texttt{BIRTH}$ 命令解析** ：
- 按冒号分割字符串得到四个部分：孩子姓名、出生日期、母亲姓名、父亲姓名。
- 去除各部分首尾的空格。
- 创建或更新孩子的 `Person` 记录。
- 将孩子添加到父母的孩子列表中（如果父母记录不存在，则先创建基本记录）。

**$\texttt{DEATH}$ 命令解析** ：
- 按冒号分割字符串得到两个部分：人物姓名和死亡日期。
- 去除首尾空格。
- 更新对应人物的死亡日期。

#### 2. 祖先查询（$\texttt{ANCESTORS}$）

**递归策略** ：
1. 从查询人物开始，收集其父母姓名。
2. 对父母姓名按字母顺序排序。
3. 对于每个父母：
   - 按当前深度输出缩进（ $2 \times depth$ 个空格）。
   - 输出父母姓名。
   - 如果该父母有出生记录，则输出出生日期和（如果有）死亡日期。
   - 递归调用该函数处理该父母的祖先（深度加 $1$ ）。

**终止条件** ：当没有父母信息可查询时递归结束。

#### 3. 后代查询（$\texttt{DESCENDANTS}$）

**递归策略** ：
1. 从查询人物开始，获取其子女列表。
2. 对子女姓名按字母顺序排序。
3. 对于每个子女：
   - 按当前深度输出缩进（ $2 \times depth$ 个空格）。
   - 输出子女姓名。
   - 如果该子女有出生记录，则输出出生日期和（如果有）死亡日期。
   - 递归调用该函数处理该子女的后代（深度加 $1$ ）。

**终止条件** ：当没有子女信息可查询时递归结束。

### 复杂度分析

- **时间复杂度** ：
  - 每次查询的时间复杂度为 $O(n \log n)$ ，其中 $n$ 是相关人物数量（主要是排序开销）。
  - 总体复杂度为 $O(m \log n)$ ，其中 $m$ 是命令数量， $n$ 是人物数量。
  - 考虑到输入限制（不超过 $250$ 行），这个复杂度是完全可接受的。

- **空间复杂度** ：
  - 需要存储所有人物信息，空间复杂度为 $O(n)$ ，其中 $n$ 是人物数量。
  - 递归调用的栈深度最多为家族树的高度，在合理范围内。

### 注意事项

1. **名字处理** ：名字中可能包含空格和标点，解析时需要仔细处理。
2. **边界情况** ：
   - 有些人只有名字记录而没有出生信息（如样例中的 $\texttt{Adam Doe}$ 和 $\texttt{Jane Doe}$）。
   - 同一个人可能被多次提及（作为父母或子女）。
3. **输出格式** ：
   - 严格按题目要求控制缩进。
   - 命令输出之间要有空行。
   - 日期信息的正确格式：出生日期 + ` - ` + （如果有）死亡日期。

```cpp

#include <bits/stdc++.h>
using namespace std;

struct Person {
    string name;
    string birthDate;
    string deathDate;
    vector<string> children;
    string mother;
    string father;
    Person() {}
    Person(string n, string b, string m, string f) : name(n), birthDate(b), mother(m), father(f) {}
};

unordered_map<string, Person> people;

string getRidOfSpace(string s) {
    while (!s.empty() && s.front() == ' ') s.erase(s.begin());
    while (!s.empty() && s.back() == ' ') s.pop_back();
    return s;
}

// 解析 BIRTH 命令
void processBirth(const string& line) {
    stringstream ss(line);
    string token;
    vector<string> tokens;
    while (getline(ss, token, ':')) tokens.push_back(getRidOfSpace(token));
    if (tokens.size() < 4) return;
    string child = tokens[0].substr(6); // 去掉 "BIRTH "
    string date = tokens[1];
    string mother = tokens[2];
    string father = tokens[3];
    people[child] = Person(child, date, mother, father);
    if (!mother.empty()) {
        if (people.find(mother) == people.end()) {
            people[mother] = Person();
            people[mother].name = mother;
        }
        people[mother].children.push_back(child);
    }
    if (!father.empty()) {
        if (people.find(father) == people.end()) {
            people[father] = Person();
            people[father].name = father;
        }
        people[father].children.push_back(child);
    }
}

// 解析 DEATH 命令
void processDeath(const string& line) {
    stringstream ss(line);
    string token;
    vector<string> tokens;
    while (getline(ss, token, ':')) tokens.push_back(getRidOfSpace(token));
    if (tokens.size() < 2) return;
    string person = tokens[0].substr(6); // 去掉 "DEATH "
    string date = tokens[1];
    if (people.find(person) != people.end()) people[person].deathDate = date;
}

// 递归打印祖先（按字母顺序）
void printAncestors(const string& name, int depth) {
    if (people.find(name) == people.end()) return;
    Person p = people[name];
    // 收集父母名字，按字母顺序打印
    vector<string> parents;
    if (!p.father.empty()) parents.push_back(p.father);
    if (!p.mother.empty()) parents.push_back(p.mother);
    sort(parents.begin(), parents.end());
    for (const string& parentName : parents) {
        cout << string(depth * 2, ' ') << parentName;
        // 检查父母是否有出生记录
        if (people.find(parentName) != people.end()) {
            Person parent = people[parentName];
            if (!parent.birthDate.empty()) {
                cout << ' ' << parent.birthDate << " -";
                if (!parent.deathDate.empty()) cout << ' ' << parent.deathDate;
            }
        }
        cout << '\n';
        // 递归打印该父母的祖先
        printAncestors(parentName, depth + 1);
    }
}

// 递归打印后代（按字母顺序）
void printDescendants(const string& name, int depth) {
    if (people.find(name) == people.end()) return;
    Person p = people[name];
    sort(p.children.begin(), p.children.end());
    for (const string& childName : p.children) {
        cout << string(depth * 2, ' ') << childName;
        if (people.find(childName) != people.end()) {
            Person child = people[childName];
            if (!child.birthDate.empty()) {
                cout << ' ' << child.birthDate << " -";
                if (!child.deathDate.empty()) cout << ' ' << child.deathDate;
            }
        }
        cout << '\n';
        printDescendants(childName, depth + 1);
    }
}

int main() {
    string line;
    bool firstOutput = true;
    while (getline(cin, line)) {
        if (line.empty()) continue;
        if (line.find("BIRTH") == 0) processBirth(line);
        else if (line.find("DEATH") == 0) processDeath(line);
        else if (line.find("ANCESTORS") == 0) {
            if (!firstOutput) cout << '\n';
            firstOutput = false;
            string name = getRidOfSpace(line.substr(10));
            cout << "ANCESTORS of " << name << '\n';
            printAncestors(name, 1);
        }
        else if (line.find("DESCENDANTS") == 0) {
            if (!firstOutput) cout << '\n';
            firstOutput = false;
            string name = getRidOfSpace(line.substr(12));
            cout << "DESCENDANTS of " << name << '\n';
            printDescendants(name, 1);
        }
        else if (line == "QUIT") break;
    }
    return 0;
}
```
