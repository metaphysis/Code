## 题目描述

你获得了一张海盗地图，地图上给出了一系列从登陆点到宝藏位置 **$\texttt{X}$** 的步骤。每一步包含一个罗盘方向和步数。当你按照地图指示使用 $\texttt{GPS}$（基于真北）行走后，却没有找到宝藏。回家后发现，海盗使用的是磁罗盘（基于磁北），而磁北与真北之间存在 $d$ 度的夹角。

给定地图上的 $n$ 个步骤和磁偏角 $d$，需要计算在按照地图行走的过程中，你与宝藏之间的最小距离。

### 输入格式

- 多个测试用例，每个以 $n \leq 1000$ 开始
- 接下来 $n$ 行，每行包含一个罗盘方向和一个步数
- 最后一行是磁偏角 $d$（正数表示磁北在真北东侧）
- 输入以 $0$ 结束

### 输出格式

对于每个测试用例，输出在行走过程中与宝藏的最小距离（保留两位小数）

## 题目分析

### 核心问题理解

这个问题本质上是坐标系转换和路径模拟问题：

1. **海盗的认知与现实**：海盗认为磁北就是真北，所以他们绘制的地图方向是基于磁北的
2. **实际物理情况**：海盗实际行走的方向是相对于磁北的，但由于磁北与真北有夹角，海盗实际行走的真北方向 = 磁北方向 + 磁偏角
3. **寻宝者的认知**：寻宝者认为地图上的方向是基于真北的，所以会直接按地图方向行走
4. **坐标系定义**：在直角坐标系中，真北方向对应 $+Y$ 轴方向，角度从真北顺时针增加

### 关键数学关系

- 海盗实际方向（真北坐标系）：$\theta_{\text{pirate}} = d + \theta_{\text{map}}$
- 寻宝者方向（真北坐标系）：$\theta_{\text{seeker}} = \theta_{\text{map}}$
- 坐标计算：
  - $x$ 坐标变化：$\Delta x = \text{pace} \times \sin(\theta)$
  - $y$ 坐标变化：$\Delta y = \text{pace} \times \cos(\theta)$

### 罗盘方向系统

题目使用 $32$ 个罗盘点，每个点之间的角度差为 $11.25^\circ$（$360^\circ / 32$）。方向名称使用 N、E、S、W、b 的组合，如 "NbE" 表示北偏东。

## 解题思路

### 算法步骤

1. **建立方向映射**：将 $32$ 个方向名称映射到对应的角度值（$0^\circ$ 到 $348.75^\circ$）

2. **计算宝藏最终位置**：
   - 模拟海盗实际行走路径
   - 对于每一步：实际方向 = 磁偏角 + 地图方向
   - 计算最终宝藏坐标 $(treasureX, treasureY)$

3. **模拟寻宝者行走**：
   - 从原点 $(0, 0)$ 开始
   - 对于每一步：方向 = 地图方向（认为基于真北）
   - 记录每一步的起点和终点坐标

4. **计算最小距离**：
   - 初始距离：原点到宝藏位置的距离
   - 对于每一步移动：
     - 计算宝藏到当前线段的垂直距离
     - 计算宝藏到线段端点的距离
     - 更新最小距离

5. **输出结果**：保留两位小数

### 距离计算细节

使用点到线段的距离公式：
- 计算投影参数 $t = \frac{(p - a) \cdot (b - a)}{|b - a|^2}$
- 如果 $t < 0$，距离为 $|p - a|$
- 如果 $t > 1$，距离为 $|p - b|$
- 否则，距离为 $|p - (a + t(b - a))|$

## 复杂度分析

- 时间复杂度：$O(n)$，其中 $n$ 是步数
- 空间复杂度：$O(1)$，只存储常数个变量

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <cmath>
#include <iomanip>
#include <map>
#include <algorithm>

using namespace std;

// 建立方向名称到角度的映射（基于磁北，0度=磁北）
void buildDirectionMap(map<string, double>& directionMap) {
    vector<string> directions = {
        "N", "NbE", "NNE", "NEbN", "NE", "NEbE", "ENE", "EbN",
        "E", "EbS", "ESE", "SEbE", "SE", "SEbS", "SSE", "SbE",
        "S", "SbW", "SSW", "SWbS", "SW", "SWbW", "WSW", "WbS",
        "W", "WbN", "WNW", "NWbW", "NW", "NWbN", "NNW", "NbW"
    };
    double angleStep = 360.0 / 32.0;
    for (size_t i = 0; i < directions.size(); ++i) {
        directionMap[directions[i]] = i * angleStep;
    }
}

// 将角度转换为弧度
double toRadians(double degrees) {
    return degrees * M_PI / 180.0;
}

// 计算点到线段的距离
double pointToSegmentDistance(double px, double py, double x1, double y1, double x2, double y2) {
    double dx = x2 - x1;
    double dy = y2 - y1;
    
    // 如果线段长度为0，直接返回点到端点的距离
    if (dx == 0 && dy == 0) {
        return sqrt((px - x1) * (px - x1) + (py - y1) * (py - y1));
    }
    
    // 计算投影参数 t
    double t = ((px - x1) * dx + (py - y1) * dy) / (dx * dx + dy * dy);
    
    // 检查投影点是否在线段上
    if (t < 0.0) {
        // 投影点在线段起点之前，返回点到起点的距离
        return sqrt((px - x1) * (px - x1) + (py - y1) * (py - y1));
    } else if (t > 1.0) {
        // 投影点在线段终点之后，返回点到终点的距离
        return sqrt((px - x2) * (px - x2) + (py - y2) * (py - y2));
    } else {
        // 投影点在线段上，计算垂直距离
        double projX = x1 + t * dx;
        double projY = y1 + t * dy;
        return sqrt((px - projX) * (px - projX) + (py - projY) * (py - projY));
    }
}

int main() {
    map<string, double> directionMap;
    buildDirectionMap(directionMap);

    int n;
    while (cin >> n && n != 0) {
        vector<pair<string, double>> steps(n);
        for (int i = 0; i < n; ++i) {
            cin >> steps[i].first >> steps[i].second;
        }
        double magneticDeclination;
        cin >> magneticDeclination;

        // 计算宝藏的最终位置（海盗实际到达的位置）
        // 海盗基于磁北行走：实际真北方向 = 磁北方向(磁偏角) + 地图方向
        double treasureX = 0.0, treasureY = 0.0;
        for (int i = 0; i < n; ++i) {
            string direction = steps[i].first;
            double paces = steps[i].second;
            
            // 海盗实际方向 = 磁偏角 + 地图方向
            double pirateTrueAngle = magneticDeclination + directionMap[direction];
            treasureX += paces * sin(toRadians(pirateTrueAngle));
            treasureY += paces * cos(toRadians(pirateTrueAngle));
        }
        
        // 模拟寻宝者行走过程
        double seekerX = 0.0, seekerY = 0.0;
        double prevSeekerX = 0.0, prevSeekerY = 0.0;
        double minDistance = 1e9;
        
        // 初始位置的距离
        minDistance = sqrt(treasureX * treasureX + treasureY * treasureY);
        
        for (int i = 0; i < n; ++i) {
            string direction = steps[i].first;
            double paces = steps[i].second;
            
            // 保存上一步位置
            prevSeekerX = seekerX;
            prevSeekerY = seekerY;
            
            // 寻宝者认为地图方向就是真北方向
            double seekerAngle = directionMap[direction];
            seekerX += paces * sin(toRadians(seekerAngle));
            seekerY += paces * cos(toRadians(seekerAngle));
            
            // 计算当前线段与宝藏最终位置的最小距离
            double segmentDistance = pointToSegmentDistance(
                treasureX, treasureY, prevSeekerX, prevSeekerY, seekerX, seekerY);
            
            if (segmentDistance < minDistance) {
                minDistance = segmentDistance;
            }
            
            // 检查寻宝者当前位置与宝藏最终位置的距离
            double currentDistance = sqrt(
                (seekerX - treasureX) * (seekerX - treasureX) + 
                (seekerY - treasureY) * (seekerY - treasureY));
            
            if (currentDistance < minDistance) {
                minDistance = currentDistance;
            }
        }

        cout << fixed << setprecision(2) << minDistance << endl;
    }

    return 0;
}
```

## 总结

本题的关键在于理解磁北与真北的坐标系转换，以及正确模拟两个不同的行走路径。通过分别计算海盗实际到达的宝藏位置和寻宝者基于错误认知的行走路径，然后计算两者之间的最小距离，即可得到正确答案。算法的时间复杂度为线性，能够高效处理题目给定的数据规模。
