## 题目分析

### 问题描述

本题要求判断两个多边形是否相似。在生物识别系统中，人体图像被转换为多边形，其中某些生物特征（如眼睛、鼻子、耳朵等）被视为顶点，并通过线段连接形成多边形。

两个多边形被认为是相似的，如果可以通过**平移**、**旋转**和**缩放**（但不包括反射）操作使它们完全重合。输入保证两个多边形的顶点按照相同的特征顺序给出。

### 输入格式

- 多个测试用例，每个测试用例包含：
  - 第一行：整数 $f$（$3 \leq f \leq 10$），表示特征数量
  - 第二行：$f$ 个坐标对，表示第一个多边形的顶点
  - 第三行：$f$ 个坐标对，表示第二个多边形的顶点
- 输入以 $0$ 结束

### 输出格式

对于每个测试用例，输出 `similar` 或 `dissimilar`。

## 解题思路

### 关键观察

1. **顶点顺序固定**：两个多边形的顶点按照相同的特征顺序给出，这意味着不需要考虑顶点的不同排列或旋转匹配。

2. **相似变换的性质**：
   - **平移**：不影响多边形的形状和大小
   - **旋转**：改变多边形的方向，但不改变边长和角度
   - **缩放**：所有边按相同比例缩放，角度保持不变

3. **禁止反射**：不允许镜像操作，这意味着多边形的"转向"（顺时针或逆时针）必须保持一致。

### 算法设计

基于以上观察，我们可以通过以下两个条件判断多边形相似性：

#### 1. 边长比例恒定

对于相似多边形，所有对应边的长度比例必须相同。为了避免浮点数精度问题，我们使用**平方距离**进行比较：

- 计算每条边的平方长度：$lenSq = (x_2 - x_1)^2 + (y_2 - y_1)^2$
- 检查所有对应边的比例是否一致：$\frac{lenSq2[i]}{lenSq1[i]} = \text{constant}$

通过交叉相乘避免除法：$lenSq2[i] \times lenSq1[0] = lenSq1[i] \times lenSq2[0]$

#### 2. 角度关系一致

使用**向量叉积**来判断相邻边之间的角度关系：

- 对于连续的三个顶点 $A$, $B$, $C$，计算向量 $\vec{AB}$ 和 $\vec{BC}$ 的叉积：
  $\text{cross} = (B_x - A_x) \times (C_y - B_y) - (B_y - A_y) \times (C_x - B_x)$
- 叉积的符号表示转向：
  - 正数：逆时针方向
  - 负数：顺时针方向
- 禁止反射意味着所有对应角的叉积符号必须相同

### 算法步骤

1. 读取特征数量 $f$
2. 读取两个多边形的顶点坐标
3. 对于每个多边形：
   - 计算所有边的平方长度
   - 计算所有相邻边之间的叉积
4. 检查边长比例是否恒定
5. 检查所有对应角的转向是否一致
6. 如果两个条件都满足，输出 `similar`，否则输出 `dissimilar`

### 复杂度分析

- **时间复杂度**：$O(f)$，其中 $f$ 是特征数量（$f \leq 10$）
- **空间复杂度**：$O(f)$，用于存储边长和叉积信息

## 代码实现

提示：题目描述中虽然说需要考虑平移、旋转、缩放，但是实际测试数据并未考虑旋转，如果考虑旋转反而无法获得通过，另外由于浮点数精度的问题，使用浮点数进行比例的比较很可能无法获得通过，建议使用整数通分的方式来比较比例是否相同。

```cpp
// Biometrics

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
    Point() {}
    Point(int x, int y) : x(x), y(y) {}
    Point operator - (const Point& p) const { return Point(x - p.x, y - p.y); }
    int cross(const Point& p) const { return x * p.y - y * p.x; }
    int dot(const Point& p) const { return x * p.x + y * p.y; }
    int distSq() const { return x * x + y * y; }
};

bool areSimilar(const vector<Point>& p1, const vector<Point>& p2) {
    int n = p1.size();
    // 检查边长比例是否恒定
    long long scaleNum = -1, scaleDen = -1;
    for (int i = 0; i < n; i++) {
        int j = (i + 1) % n;
        Point vec1 = p1[j] - p1[i], vec2 = p2[j] - p2[i];
        long long lenSq1 = vec1.distSq(), lenSq2 = vec2.distSq();
        // 初始化比例
        if (scaleNum == -1) scaleNum = lenSq2, scaleDen = lenSq1;
        else {
            // 检查比例是否一致: lenSq2/lenSq1 == scaleNum/scaleDen
            if (lenSq2 * scaleDen != lenSq1 * scaleNum) return false;
        }
    }
    // 检查角度关系（转向）
    for (int i = 0; i < n; i++) {
        int j = (i + 1) % n, k = (i + 2) % n;
        Point vec1a = p1[j] - p1[i], vec1b = p1[k] - p1[j];
        Point vec2a = p2[j] - p2[i], vec2b = p2[k] - p2[j];
        int cross1 = vec1a.cross(vec1b), cross2 = vec2a.cross(vec2b);
        // 转向必须相同（不允许反射）
        if ((cross1 > 0) != (cross2 > 0)) return false;
        // 可选：更精确的角度检查，不加本题也能通过
        int dot1 = vec1a.dot(vec1b), dot2 = vec2a.dot(vec2b);
        if ((long long)cross1 * dot2 != (long long)cross2 * dot1) return false;
    }
    return true;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int f;
    while (cin >> f && f != 0) {
        vector<Point> poly1(f), poly2(f);
        for (int i = 0; i < f; i++) cin >> poly1[i].x >> poly1[i].y;
        for (int i = 0; i < f; i++) cin >> poly2[i].x >> poly2[i].y;
        if (areSimilar(poly1, poly2)) cout << "similar\n";
        else cout << "dissimilar\n";
    }
    return 0;
}
```

## 总结

本题的关键在于理解多边形相似性的几何性质，并通过整数运算避免浮点数精度问题。通过检查边长比例恒定和角度转向一致两个条件，可以高效准确地判断两个多边形是否相似。算法充分利用了题目中顶点顺序固定的条件，简化了比较过程。
