[UVa 10560 Minimum Weight](https://blog.csdn.net/metaphysis/article/details/154567849)

## 题目描述

你需要称出从 $1$ 到 $N$ 的所有整数重量。你可以在天平的两个盘中都放置砝码。例如，如果你有重量为 $2$ 和 $3$ 的砝码，你可以将 $3$ 放在一个盘，$2$ 放在另一个盘来称出 $1$（因为 $3 - 2 = 1$）。你也可以称出 $5$（$3 + 2 = 5$），但不能称出 $4$。

对于给定的 $N$，你需要找出最少需要多少个砝码，才能称出 $1$ 到 $N$ 的所有整数重量。

### 输入格式

输入文件包含多组数据。每组数据格式如下：

- 第一行：两个整数 $N$（在 $64$ 位有符号整数范围内）和 $K$（$0 \le K \le 100$）。
- 第二行：$K$ 个小于 $N$ 的正整数，表示需要你展示如何称出的目标重量。

输入以 $N = 0, K = 0$ 结束，不处理该情况。

### 输出格式

对于每组数据，输出 $K + 1$ 行：

- 第一行：输出所需砝码的总数，以及这些砝码（按升序排列）。如果有多种可能，选择包含最大砝码的组合。
- 接下来的 $K$ 行：对于每个查询重量，输出称重方案，砝码按降序排列（不论符号）。

## 题目分析与解题思路

### 1. 问题本质与数学模型

这是一个经典的**三进制砝码问题**（平衡三进制表示问题）。  
由于砝码可以放在两个盘中，每个砝码有三种状态：

- 放在左盘（与被称物同侧）：系数 $-1$
- 不放：系数 $0$
- 放在右盘（与被称物异侧）：系数 $+1$

因此，每个砝码的贡献可以是 $ -w_i, 0, +w_i $。

### 2. 最少砝码数的确定

假设我们使用 $m$ 个砝码，重量分别为 $1, 3, 9, 27, \dots, 3^{m-1}$，那么可以称出的最大重量为：

$$
maxWeight = 1 + 3 + 9 + \dots + 3^{m-1} = \frac{3^m - 1}{2}
$$

这是因为每个砝码有三种选择，并且所有系数的组合可以唯一表示从 $-\frac{3^m - 1}{2}$ 到 $\frac{3^m - 1}{2}$ 的所有整数。

我们需要找到最小的 $m$ 使得：

$$
\frac{3^m - 1}{2} \ge N
$$

### 3. 砝码组合的唯一性

在平衡三进制表示中，使用 $1, 3, 9, \dots, 3^{m-1}$ 这些砝码是**唯一最优解**，可以连续覆盖 $1$ 到 $N$，并且数量最少。题目要求“如果多种输出可能，选择包含最大砝码的组合”，这里恰好只有一种最优组合。

### 4. 平衡三进制转换算法

对于每个查询重量 $x$，我们需要将其表示为：

$$
x = \sum_{i=0}^{m-1} a_i \cdot 3^i, \quad a_i \in \{-1, 0, 1\}
$$

转换算法如下：

1. 初始化系数数组 $a_i = 0$。
2. 从低位到高位（$i = 0$ 到 $m-1$）：
   - 计算 $r = x \bmod 3$
   - 如果 $r = 2$，则 $a_i = -1$，并且 $x = x / 3 + 1$（进位）
   - 如果 $r = 1$，则 $a_i = 1$，并且 $x = x / 3$
   - 如果 $r = 0$，则 $a_i = 0$，并且 $x = x / 3$

### 5. 输出格式处理

- 第一行：砝码数 $m$，然后按升序输出砝码 $1, 3, 9, \dots$
- 对于每个查询重量：
  - 按砝码**降序**输出表达式
  - 系数 $+1$ 输出 `+wi`，系数 $-1$ 输出 `-wi`
  - 第一个非零系数前不加 `+`

## 复杂度分析

- 计算 $m$：最多 $O(\log_3 N)$ 次循环
- 生成砝码：$O(m)$
- 每个查询的平衡三进制转换：$O(m)$
- 总复杂度：$O(K \cdot m)$，在本题限制下非常高效

## 参考代码

```cpp
// Minimum Weight
// UVa ID: 10560
// Verdict: Accepted
// Submission Date: 2025-11-08
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
using namespace std;

int main() {
    long long N;
    int K;
    while (cin >> N >> K && (N || K)) {
        // 计算最少砝码数 m
        int m = 1;
        long long maxW = 1; // (3^1 - 1)/2 = 1
        while (maxW < N) {
            m++;
            maxW = (maxW * 3 + 1); // 递推: maxW(m) = 3 * maxW(m-1) + 1
        }
        
        // 生成砝码
        vector<long long> weights(m);
        long long p = 1;
        for (int i = 0; i < m; i++) {
            weights[i] = p;
            p *= 3;
        }
        
        // 输出砝码
        cout << m;
        for (auto w : weights) cout << " " << w;
        cout << endl;
        
        // 处理每个查询
        for (int k = 0; k < K; k++) {
            long long x;
            cin >> x;
            vector<int> coeff(m, 0);
            long long n = x;
            
            // 正确的平衡三进制转换
            for (int i = 0; i < m; i++) {
                long long remainder = n % 3;
                if (remainder == 2) {
                    coeff[i] = -1;
                    n = n / 3 + 1;  // 进位
                } else if (remainder == 1) {
                    coeff[i] = 1;
                    n = n / 3;
                } else { // remainder == 0
                    coeff[i] = 0;
                    n = n / 3;
                }
            }
            
            // 输出表达式（降序）
            bool first = true;
            for (int i = m - 1; i >= 0; i--) {
                if (coeff[i] != 0) {
                    if (!first) {
                        cout << (coeff[i] > 0 ? "+" : "-");
                    } else {
                        if (coeff[i] < 0) cout << "-";
                        first = false;
                    }
                    cout << weights[i];
                }
            }
            if (first) cout << "0";
            cout << endl;
        }
    }
    return 0;
}
```

## 总结

本题的关键在于理解**平衡三进制**的数学原理：

- 每个砝码重量为 $3^i$ 可以覆盖最大连续范围
- 平衡三进制转换算法能正确表示任意整数
- 输出格式要严格遵循题目要求的顺序

这个解法在数学上是严谨的，在实现上是高效的，能够正确处理 $N$ 在 $64$ 位整数范围内的所有情况。
