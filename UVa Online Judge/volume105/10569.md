## 题目描述

给定一个正整数 $n$，需要找到一个整数 $f$，使得：

$$f^3 = a_1^3 + a_2^3 + \cdots + a_n^3$$

其中 $a_1, a_2, \ldots, a_n$ 是互不相同的正整数。

例如：
- 当 $n = 3$ 时，$f = 71$，因为 $71^3 = 14^3 + 23^3 + 70^3 = 357911$
- 当 $n = 4$ 时，$f = 100$，因为 $100^3 = 56^3 + 58^3 + 67^3 + 69^3 = 1000000$

$f$ 最多可能有 $250$ 位数字。

### 输入格式
第一行包含测试用例数 $t$（$1 \leq t \leq 20$）。  
每个测试用例包含一个正整数 $n$（$1 \leq n \leq 100$）。

### 输出格式
对于每个测试用例，输出用例编号和 $n + 1$ 个数字：$f, a_1, a_2, \ldots, a_n$。  
如果不存在这样的 $f$，输出 `-1` 和 $n$ 个 $0$。

## 题目分析

这是一个**立方和分解**问题，需要将一个大整数的立方表示为 $n$ 个不同正整数的立方和。

### 关键观察

1. **$n = 1$ 的情况**：平凡解，$f = a_1$ 即可
2. **$n = 2$ 的情况**：根据费马大定理，不存在正整数解（除了平凡解）
3. **$n \geq 3$ 的情况**：存在解，可以通过构造方法生成

### 数学基础

本解法基于一个重要的数学恒等式：

$$(6k)^3 = (3k)^3 + (4k)^3 + (5k)^3$$

验证：
- 左边：$(6k)^3 = 216k^3$
- 右边：$(3k)^3 + (4k)^3 + (5k)^3 = 27k^3 + 64k^3 + 125k^3 = 216k^3$

## 解题思路

### 构造方法

对于 $n \geq 5$，我们可以从 $n-2$ 的解构造出 $n$ 的解：

**已知**：$n-2$ 的解为 $f^3 = a_1^3 + a_2^3 + \cdots + a_{n-2}^3$（假设 $a_1$ 是最小的数）

**构造**：
- 新 $F = 6f$
- 新序列：$3a_1, 4a_1, 5a_1, 6a_2, 6a_3, \ldots, 6a_{n-2}$

**数学验证**：
$$F^3 = (6f)^3 = 216f^3 = 216(a_1^3 + a_2^3 + \cdots + a_{n-2}^3)$$
$$= 216a_1^3 + 216a_2^3 + \cdots + 216a_{n-2}^3$$
$$= (6a_1)^3 + (6a_2)^3 + \cdots + (6a_{n-2})^3$$

根据恒等式 $(6a_1)^3 = (3a_1)^3 + (4a_1)^3 + (5a_1)^3$：
$$F^3 = (3a_1)^3 + (4a_1)^3 + (5a_1)^3 + (6a_2)^3 + \cdots + (6a_{n-2})^3$$

**项数变化**：原来有 $n-2$ 项，用 $3$ 项替换 $1$ 项，得到 $n$ 项。

### 基础解

我们需要几个已知的基础解来开始递归构造：
- $n = 1$: $1^3 = 1^3$
- $n = 2$: 无解
- $n = 3$: $71^3 = 14^3 + 23^3 + 70^3$
- $n = 4$: $100^3 = 56^3 + 58^3 + 67^3 + 69^3$

### 大数处理

由于 $f$ 最多可能有 $250$ 位数字，不能使用普通的整数类型。我们需要实现高精度计算，但幸运的是，我们只需要乘以小整数（$3$、$4$、$5$、$6$），所以可以实现一个简化的高精度类。

## 算法步骤

1. **预处理**：预先计算所有 $n = 1$ 到 $n = 100$ 的解
2. **基础情况**：设置 $n = 1, 2, 3, 4$ 的已知解
3. **递归构造**：对于 $n \geq 5$，从 $n-2$ 的解构造
4. **查询输出**：对于每个测试用例，直接输出预计算的解

## 复杂度分析

- **时间复杂度**：$O(100 \times M)$，其中 $M$ 是数字的最大位数
- **空间复杂度**：$O(100 \times 100 \times 250)$，存储所有解

```cpp
#include <bits/stdc++.h>
using namespace std;

// 高精度整数类（简化版，仅支持需要的操作）
class BigInt {
public:
    string digits;
    
    BigInt() {}
    BigInt(string s) : digits(s) {}
    BigInt(long long n) : digits(to_string(n)) {}
    
    // 转换为字符串
    string str() const { return digits; }
    
    // 乘法：仅实现乘以小整数（<=6）
    BigInt multiply(int n) const {
        string result;
        int carry = 0;
        for (int i = digits.size() - 1; i >= 0; i--) {
            int product = (digits[i] - '0') * n + carry;
            result.push_back('0' + product % 10);
            carry = product / 10;
        }
        while (carry) {
            result.push_back('0' + carry % 10);
            carry /= 10;
        }
        reverse(result.begin(), result.end());
        return BigInt(result);
    }
};

vector<vector<string>> precomputed(101);

void precompute() {
    // n = 1: 平凡解
    precomputed[1] = {"1", "1"};
    // n = 2: 无解（费马大定理）
    precomputed[2] = {"-1", "0", "0"};
    // n = 3: 已知解
    precomputed[3] = {"71", "14", "23", "70"};
    // n = 4: 已知解
    precomputed[4] = {"100", "56", "58", "67", "69"};
    
    // 对于 n >= 5，从 n-2 的解构造
    for (int n = 5; n <= 100; n++) {
        vector<string> prev = precomputed[n - 2];
        BigInt minVal(prev[1]);  // 第一个 a_i 就是最小的
        BigInt f(prev[0]);
        
        vector<string> current;
        current.push_back(f.multiply(6).str());  // F = 6f
        current.push_back(minVal.multiply(3).str());  // 3a₁
        current.push_back(minVal.multiply(4).str());  // 4a₁
        current.push_back(minVal.multiply(5).str());  // 5a₁
        
        // 其余 a_i 都乘以 6
        for (int i = 2; i < prev.size(); i++) {
            BigInt val(prev[i]);
            current.push_back(val.multiply(6).str());
        }
        
        precomputed[n] = current;
    }
}

int main() {
    precompute();  // 预先计算所有解
    
    int t;
    cin >> t;
    for (int caseNum = 1; caseNum <= t; caseNum++) {
        int n;
        cin >> n;
        cout << "Case " << caseNum << ":";
        // 输出对应 n 的解
        for (const string& s : precomputed[n]) cout << " " << s;
        cout << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于发现数学构造规律，利用恒等式 $(6k)^3 = (3k)^3 + (4k)^3 + (5k)^3$ 进行递归构造。通过预处理所有可能的解，可以在查询时直接输出，达到最优的时间复杂度。同时，由于数字可能很大，需要实现简单的高精度计算来处理大数乘法。
