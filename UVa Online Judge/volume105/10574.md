## 题目分析

### 问题描述
给定 $n$ 个在 $XY$ 平面上的点，要求计算其中能够组成多少个 **$\texttt{regular rectangles}$**（规则矩形）。规则矩形定义为所有边都平行于坐标轴的矩形。

### 输入格式
- 第一行包含测试用例数量 $t$（$1 \leq t \leq 10$）
- 每个测试用例：
  - 第一行：点的数量 $n$（$1 \leq n \leq 5000$）
  - 接下来 $n$ 行：每行两个整数 $x, y$（$0 \leq x, y \leq 10^9$），表示点的坐标

### 输出格式
对于每个测试用例，输出用例编号和找到的规则矩形数量。

## 解题思路

### 矩形构成条件
一个平行于坐标轴的矩形由两条不同的水平边和两条不同的垂直边唯一确定。具体来说，如果固定：
- 两个不同的 $x$ 坐标 $x_1, x_2$（$x_1 < x_2$）
- 两个不同的 $y$ 坐标 $y_1, y_2$（$y_1 < y_2$）

那么矩形的四个顶点应为：
- $(x_1, y_1)$
- $(x_1, y_2)$
- $(x_2, y_1)$
- $(x_2, y_2)$

如果这四个点都存在于给定的点集中，就构成了一个规则矩形。

### 高效算法
直接枚举所有可能的矩形需要 $O(n^4)$ 的时间复杂度，对于 $n \leq 5000$ 不可行。

我们采用以下优化方法：

1. **按 $y$ 坐标分组**：将具有相同 $y$ 坐标的点分组存储
2. **枚举水平线段**：对于每个 $y$ 坐标，将其对应的所有 $x$ 坐标排序，然后枚举所有可能的 $(x_1, x_2)$ 对（$x_1 < x_2$）
3. **统计线段出现次数**：使用映射记录每个 $(x_1, x_2)$ 对出现的次数
4. **计算矩形数量**：对于出现 $k$ 次的 $(x_1, x_2)$ 对，可以形成 $C(k, 2) = \frac{k(k-1)}{2}$ 个矩形

### 算法复杂度
- 最坏情况下所有点具有相同的 $y$ 坐标，需要枚举所有点对，时间复杂度为 $O(n^2)$
- 对于 $n = 5000$，$n^2 = 25 \times 10^6$ 在合理范围内

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int testCount;
    cin >> testCount;
    
    for (int caseNum = 1; caseNum <= testCount; caseNum++) {
        int pointCount;
        cin >> pointCount;
        
        // 按 y 坐标分组存储 x 坐标
        map<int, vector<int>> yToXMap;
        
        for (int i = 0; i < pointCount; i++) {
            int x, y;
            cin >> x >> y;
            yToXMap[y].push_back(x);
        }
        
        // 统计水平线段 (x1, x2) 的出现次数
        map<pair<int, int>, int> segmentCount;
        
        // 遍历每个 y 坐标对应的点集
        for (auto& yGroup : yToXMap) {
            vector<int>& xList = yGroup.second;
            // 对 x 坐标排序
            sort(xList.begin(), xList.end());
            int xSize = xList.size();
            
            // 枚举所有可能的水平线段
            for (int i = 0; i < xSize; i++) {
                for (int j = i + 1; j < xSize; j++) {
                    // x1 < x2
                    segmentCount[{xList[i], xList[j]}]++;
                }
            }
        }
        
        // 计算矩形总数
        long long totalRectangles = 0;
        for (auto& segment : segmentCount) {
            long long count = segment.second;
            // 每 k 条相同水平线段可形成 C(k, 2) 个矩形
            totalRectangles += count * (count - 1) / 2;
        }
        
        cout << "Case " << caseNum << ": " << totalRectangles << "\n";
    }
    
    return 0;
}
```

## 代码说明

### 主要数据结构
- `yToXMap`：将点按 $y$ 坐标分组，值为该 $y$ 坐标对应的所有 $x$ 坐标列表
- `segmentCount`：记录水平线段 $(x_1, x_2)$ 的出现次数

### 算法步骤
1. **输入处理**：读取测试用例数量和每个测试用例的点数据
2. **分组存储**：将点按 $y$ 坐标分组存储
3. **枚举线段**：对每个 $y$ 坐标对应的 $x$ 坐标列表排序后，枚举所有可能的水平线段
4. **统计计数**：记录每个水平线段的出现次数
5. **计算结果**：根据组合数学公式计算矩形总数

### 关键优化
- 通过按 $y$ 坐标分组，避免了不必要的点对枚举
- 利用映射结构快速统计和查询线段出现次数
- 组合数计算直接使用公式，避免重复计算

该方法充分利用了规则矩形的几何特性，在合理的时间复杂度内解决了问题。
