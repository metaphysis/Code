## 题目描述

铝制壁板、门窗业巨头吉尔伯特·贝茨被绑架了。你需要帮助罪犯制作一封勒索信。你的原材料是一份报纸的文本和勒索信的文本。勒索信需要通过从报纸上剪下字母或字母串（可能包含空格），然后将它们粘贴到一张空白纸上形成。你的工作是确定制作这封信所需的最少剪贴片段数量。

在信中每两个单词之间，剪贴的内容必须包含一个空格，或者剪贴之间必须有边界（以便空白背景能显示出来）。

### 输入格式

标准输入由勒索信的文本和报纸的文本组成。勒索信的文本是单独一行，长度小于 $20\texttt{KB}$ ，全部小写，没有标点符号。报纸的文本包含大小写字母、标点符号和换行符。大小写可以忽略（就像任何标准的勒索信那样），标点符号和换行符不应该被剪贴。绑匪已经获得了大量相同的报纸副本，因此可以按需多次剪贴相同或重叠的文本。报纸中每个字母至少出现一次。报纸长度小于 $100\texttt{KB}$ 。

### 输出格式

输出剪贴片段的数量，然后按正确顺序输出这些片段，每行一个，以组成勒索信。报纸文本的大小写应保留。

### 样例输入

information from the program under study) are done using cumbersome

"rain" can be used on arbitrary programs, more development work needs

## 题目分析

### 问题本质

这是一个**字符串匹配问题**，但有几个特殊约束：

1. 勒索信只包含小写字母和空格，没有标点
2. 报纸包含大小写字母、标点符号和换行符
3. 匹配时忽略大小写
4. 可以重复使用报纸（有多个副本）
5. 目标是使用最少的剪贴片段

### 关键观察

1. **贪心策略有效**：每次选择能匹配的最长连续字母/空格序列，可以得到最少剪贴片段数
2. **标点符号处理**：虽然报纸中有标点符号，但：
   - 标点符号不应该被剪贴
   - 标点符号会中断剪贴片段（因为剪贴片段只能是连续的字母和空格）
3. **重复使用报纸**：由于有多个报纸副本，我们可以从报纸的任何位置开始匹配，不需要考虑字符是否已被使用

## 解题思路

### 暴力解法（不可行）

最直观的想法是对于勒索信的每个位置，在报纸中搜索最长的匹配。然而，勒索信最长 $20\texttt{KB}$ ，报纸最长 $100\texttt{KB}$ ，暴力搜索的时间复杂度为 $O(n \times m)$ ，在最坏情况下达到 $2 \times 10^9$ 次操作，显然不可行。

### 高效算法设计

我们需要一种高效的方法来查找勒索信每个后缀在报纸中的最长匹配。这正是**后缀数组（$\texttt{Suffix Array}$）** 的典型应用场景。

#### 后缀数组简介

后缀数组是字符串所有后缀按字典序排序后的数组。对于长度为 $n$ 的字符串，后缀数组 $sa[i]$ 表示排名第 $i$ 的后缀的起始位置。

与后缀数组配套的还有**高度数组（$\texttt{Height Array}$）** $height[i]$ ，表示 $sa[i]$ 和 $sa[i-1]$ 这两个后缀的最长公共前缀（$\texttt{LCP}$）长度。

#### 算法步骤

1. **文本预处理**：
   - 将勒索信和报纸用特殊字符连接：`note + "$" + paper + "#"`
   - `$` 和 `#` 是特殊分隔符，确保后缀排序时不会越界比较
   - 将报纸文本转换为小写以便匹配（但输出时保留原始大小写）
   - 标记每个位置的来源（$0$ 表示勒索信，$1$ 表示报纸，$2$ 表示分隔符）

2. **构建后缀数组**：
   - 使用**倍增算法**构建后缀数组，时间复杂度 $O(n \log n)$
   - 构建高度数组，用于快速计算任意两个后缀的 $\texttt{LCP}$

3. **贪心匹配**：
   - 从勒索信开头开始，设当前位置为 $idx$
   - 找到勒索信后缀 $note[idx:]$ 在后缀数组中的位置 $suffixRank$
   - 在 $suffixRank$ 前后搜索最近的报纸后缀：
     - 向前搜索：对于每个 $i$ 从 $suffixRank-1$ 向下到 $0$ ，维护最小 $height$ 值
     - 向后搜索：对于每个 $i$ 从 $suffixRank$ 向上到 $n-1$ ，维护最小 $height$ 值
     - 选择 $\texttt{LCP}$ 最长的报纸后缀作为最佳匹配
   - 提取匹配片段，更新 $idx$

4. **输出结果**：
   - 输出剪贴片段数量
   - 按顺序输出每个剪贴片段

### 算法正确性证明

1. **贪心选择最优性**：
   - 每次选择最长的匹配不会使总片段数增加
   - 假设存在更优解，在某个位置选择了较短的匹配，那么后续需要更多片段，总片段数不会减少

2. **后缀数组查找正确性**：
   - 在后缀数组中，相似的后缀会相邻排列
   - 对于勒索信后缀 $note[idx:]$ ，与它 $\texttt{LCP}$ 最长的报纸后缀一定在它的邻近位置
   - 通过维护 $height$ 数组的最小值，可以快速找到最佳匹配

### 复杂度分析

- **时间复杂度**：
  - 构建后缀数组：$O(n \log n)$ ，其中 $n = |note| + |paper| + 2 \approx 120\texttt{KB}$
  - 查询阶段：对于勒索信每个位置，需要向前后搜索，最坏情况 $O(n)$ ，但实践中由于 $height$ 值快速递减，接近 $O(1)$
  - 总复杂度大约 $O(n \log n + |note| \times$ 平均搜索深度$)$

- **空间复杂度**：$O(n)$ ，主要存储后缀数组和辅助数组

```cpp
// Ransom Note
// UVa ID: 10580

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 140010;

// 计数排序，用于后缀数组构建
void countSort(int *s, int *ranks, int *sa, int n, int m) {
    static int cnt[MAXN];
    memset(cnt, 0, sizeof(cnt));
    for (int i = 0; i < n; i++) cnt[s[ranks[i]]]++;
    for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
    for (int i = n - 1; i >= 0; i--) sa[--cnt[s[ranks[i]]]] = ranks[i];
}

// 构建后缀数组（倍增算法）
void buildSA(int *s, int *sa, int n, int m) {
    static int ranks[MAXN] = {}, higher[MAXN] = {}, lower[MAXN] = {};
    iota(ranks, ranks + MAXN, 0);
    countSort(s, ranks, sa, n, m);
    ranks[sa[0]] = 0;
    for (int i = 1; i < n; i++) {
        ranks[sa[i]] = ranks[sa[i - 1]];
        ranks[sa[i]] += (s[sa[i]] != s[sa[i - 1]]);
    }
    for (int i = 0; (1 << i) < n; i++) {
        for (int j = 0; j < n; j++) {
            higher[j] = ranks[j] + 1;
            lower[j] = (j + (1 << i) >= n) ? 0 : (ranks[j + (1 << i)] + 1);
            sa[j] = j;
        }
        countSort(lower, sa, ranks, n, n);
        countSort(higher, ranks, sa, n, n);
        ranks[sa[0]] = 0;
        for (int j = 1; j < n; j++) {
            ranks[sa[j]] = ranks[sa[j - 1]];
            ranks[sa[j]] += (higher[sa[j - 1]] != higher[sa[j]] ||
                lower[sa[j - 1]] != lower[sa[j]]);
        }
    }
}

// 构建高度数组（LCP数组）
void getHeight(int *s, int *sa, int *height, int n) {
    static int ranks[MAXN] = {};
    height[0] = 0;
    for (int i = 0; i < n; i++) ranks[sa[i]] = i;
    for (int i = 0, k = 0; i < n; i++, (k ? k-- : 0)) {
        if (ranks[i])
            while (s[i + k] == s[sa[ranks[i] - 1] + k]) k++;
        height[ranks[i]] = k;
    }
}

int main(int argc, char *argv[]) {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    
    // 读入数据
    string note, paper, line;
    getline(cin, note);
    while (getline(cin, line)) paper += line + "\n";
    
    // 连接文本，标记来源
    // 格式：note + "$" + paper + "#"
    int s[MAXN], original[MAXN];
    int n = 0;
    
    // 1. 添加勒索信部分
    for (int i = 0; i < note.length(); i++) {
        s[i] = note[i];           // 勒索信保持原样（都是小写字母）
        original[i] = 0;          // 标记为勒索信部分
    }
    n = note.length();
    
    // 2. 添加分隔符'$'
    s[n] = '$';
    original[n] = 2;              // 标记为分隔符
    n++;
    
    // 3. 添加报纸部分（转换为小写以便匹配）
    for (int i = 0; i < paper.length(); i++) {
        s[n + i] = tolower(paper[i]);  // 转换为小写
        original[n + i] = 1;            // 标记为报纸部分
    }
    n += paper.length();
    
    // 4. 添加结束符'#'
    s[n] = '#';
    original[n] = 2;              // 标记为分隔符
    n++;
    
    // 构建后缀数组
    int sa[MAXN];
    buildSA(s, sa, n, 128);       // ASCII字符集大小为128
    
    // 构建高度数组
    int height[MAXN];
    getHeight(s, sa, height, n);
    
    // 计算每个后缀的排名（rank数组是sa的逆）
    int rank[MAXN];
    for (int i = 0; i < n; i++) rank[sa[i]] = i;
    
    // 贪心匹配
    vector<string> clips;
    int idx = 0;
    while (idx < note.length()) {
        // 跳过空格 - 空格通过剪贴边界实现
        if (note[idx] == ' ') {
            idx++;
            continue;
        }
        
        // 找到当前后缀在sa中的位置
        int notePos = idx;
        int suffixRank = rank[notePos];
        
        // 向前查找最近的报纸后缀
        int bestLen = 0;
        int bestPos = -1;
        int minLCP = INT_MAX;
        
        // 向前搜索
        for (int i = suffixRank - 1; i >= 0; i--) {
            // 更新最小LCP
            if (height[i + 1] < minLCP) minLCP = height[i + 1];
            if (minLCP == 0) break;
            
            // 检查是否是报纸后缀
            if (original[sa[i]] == 1) {
                if (minLCP > bestLen) {
                    bestLen = minLCP;
                    bestPos = sa[i];
                }
            }
        }
        
        // 向后查找最近的报纸后缀
        minLCP = INT_MAX;
        for (int i = suffixRank; i < n - 1; i++) {
            // 更新最小LCP
            if (height[i + 1] < minLCP) minLCP = height[i + 1];
            if (minLCP == 0) break;
            
            // 检查是否是报纸后缀
            if (original[sa[i + 1]] == 1) {
                if (minLCP > bestLen) {
                    bestLen = minLCP;
                    bestPos = sa[i + 1];
                }
            }
        }
        
        // 从bestPos提取bestLen个字符作为剪贴片段
        // 需要转换为原始报纸中的位置
        int paperPos = bestPos - (note.length() + 1);
        string clip = paper.substr(paperPos, bestLen);
        clips.push_back(clip);
        idx += bestLen;
    }
    
    // 输出结果
    cout << clips.size() << '\n';
    for (const string& clip : clips) cout << clip << '\n';
    
    return 0;
}
```

## 算法亮点

1. **高效的后缀数组构建**：使用倍增算法，时间复杂度 $O(n \log n)$
2. **巧妙的文本连接**：使用特殊字符连接勒索信和报纸，避免越界比较
3. **贪心匹配的优化**：通过后缀数组快速找到最长匹配，避免暴力搜索
4. **空间优化**：使用静态数组，减少动态内存分配的开销

## 总结

本题展示了后缀数组在字符串匹配问题中的强大威力。通过将勒索信和报纸文本连接并构建后缀数组，我们可以在对数时间内找到任意两个后缀的最长公共前缀。结合贪心策略，每次选择最长的匹配片段，最终得到最少的剪贴片段数。

这个问题的解决思路具有普适性，可以应用于其他需要快速查找字符串间相似度的场景。后缀数组作为字符串处理的重要工具，值得深入学习和掌握。
