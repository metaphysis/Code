## 题目描述

将一个正整数 $m$ 划分为 $n$ 个元素（$n \leq m$）是一个由正整数组成的序列 $a_1, \dots, a_n$，满足：
- $a_1 + \dots + a_n = m$
- $a_1 \leq a_2 \leq \dots \leq a_n$

你的任务是找到 $m$ 的一个划分，该划分在所有 $n$ 元素划分的字典序排列中位于第 $k$ 个位置。

字典序定义如下：对于两个划分 $a = [a_1, \dots, a_n]$ 和 $b = [b_1, \dots, b_n]$，如果存在一个 $1 \leq i \leq n$，使得对所有 $j < i$ 有 $a_j = b_j$，且 $a_i < b_i$，则 $a < b$。所有划分按字典序递增排列，第一个划分是：
$$1, 1, \dots, 1, m - n + 1$$

**输入格式：**
- 第一行包含一个整数 $c$，表示测试用例的数量
- 接下来的 $c$ 行每行包含三个整数：$1 \leq m \leq 220$、$1 \leq n \leq 10$ 和 $1 \leq k$（不超过 $m$ 的 $n$ 元素划分数）

**输出格式：**
- 对每个测试用例，输出 $m$ 的第 $k$ 个 $n$ 元素划分，每个元素占一行

## 题目分析

这是一个典型的组合计数与构造问题。我们需要在按字典序排列的所有可能划分中找到第 $k$ 个划分。

### 关键观察

1. **划分的性质**：由于划分必须是非递减序列，且所有元素都是正整数，这大大减少了搜索空间
2. **数据范围**：$m \leq 220$，$n \leq 10$，虽然 $m$ 可能较大，但 $n$ 很小，使得我们可以使用动态规划来计数
3. **字典序构造**：我们可以通过确定每一位的值来逐步构造答案，类似于在字典树中搜索

### 解题思路

#### 1. 计数函数设计

定义 `countPartitions(m, n, minVal)` 表示：
- 将 $m$ 划分为 $n$ 个正整数
- 每个数至少为 `minVal`
- 序列是非递减的

这个函数的递归关系为：
$$\texttt{countPartitions}(m, n, \texttt{minVal}) = \sum_{x = \text{minVal}}^{\lfloor m/n \rfloor} \texttt{countPartitions}(m - x, n - 1, x)$$

边界条件：
- 如果 $n = 0$ 且 $m = 0$，返回 $1$（成功找到一个划分）
- 如果 $n = 0$ 且 $m \neq 0$，返回 $0$（划分失败）
- 如果 $m < \texttt{minVal} \times n$，返回 $0$（剩余值太小，无法满足最小值和数量要求）

#### 2. 记忆化搜索

由于 $m \leq 220$，$n \leq 10$，$\text{minVal} \leq m$，状态空间大小为 $220 \times 10 \times 220 \approx 5 \times 10^5$，可以使用三维数组进行记忆化。

#### 3. 构造第 $k$ 个划分

从第一位开始，依次确定每个位置的值：
1. 从当前允许的最小值开始尝试
2. 对于每个候选值 $x$，计算以 $x$ 开头的划分数量
3. 如果 $k$ 大于这个数量，说明第 $k$ 个划分以更大的值开头，将 $k$ 减去这个数量
4. 如果 $k$ 小于等于这个数量，说明第 $k$ 个划分以当前值开头，递归处理剩余部分

## 算法复杂度分析

- **时间复杂度**：$O(c \times m^2 \times n)$，对于每个测试用例，最坏情况下需要计算所有状态
- **空间复杂度**：$O(m \times n \times m)$，用于存储动态规划状态

由于 $m \leq 220$，$n \leq 10$，这个复杂度是可以接受的。

```cpp
// Partitioning for Fun and Profit

#include <bits/stdc++.h>
using namespace std;

long long dp[221][11][221];

long long countPartitions(int m, int n, int minVal) {
  if (n == 0) return m == 0 ? 1 : 0;
  if (m < minVal * n) return 0;
  if (dp[m][n][minVal] != -1) return dp[m][n][minVal];
  long long res = 0;
  for (int x = minVal; x * n <= m; x++)
    res += countPartitions(m - x, n - 1, x);
  return dp[m][n][minVal] = res;
}

void findKthPartition(int m, int n, long long k, int minVal, vector<int>& result) {
  if (n == 0) return;
  for (int x = minVal; x <= m; x++) {
    long long cnt = countPartitions(m - x, n - 1, x);
    if (k > cnt) k -= cnt;
    else {
      result.push_back(x);
      findKthPartition(m - x, n - 1, k, x, result);
      return;
    }
  }
}

int main() {
  memset(dp, -1, sizeof(dp));
  int c; cin >> c;
  while (c--) {
    int m, n; long long k;
    cin >> m >> n >> k;
    vector<int> result;
    findKthPartition(m, n, k, 1, result);
    for (int x : result) cout << x << endl;
  }
  return 0;
}
```

## 总结

本题的关键在于将组合计数与字典序构造相结合。通过动态规划预先计算各种情况下的划分数，我们可以在构造答案时快速确定每一位的值。这种方法避免了暴力枚举所有可能划分的低效做法，在给定的数据范围内能够高效解决问题。

这种"计数+构造"的思路在很多组合数学问题中都很常见，特别是在需要按特定顺序输出第 $k$ 个解的问题中。
