[UVa 10588 Queuing at the Doctors](https://blog.csdn.net/metaphysis/article/details/156694944)

## 题目描述

由于越来越多的奇怪病毒传播，国际左轮手枪爱好者协会（$\texttt{ICORE}$）的所有成员都被老板要求每季度在总医院进行体检。所有体检都由老板安排，并在同一天进行。每位 $\texttt{ICORE}$ 成员会收到指示，其中包含：

- 他们的编号（从集合 $\{1\ldots n\}$ 中给出）
- 他们应该在当天何时到达总医院的时间
- 他们需要按顺序就诊的医生办公室列表。

总医院中的医生办公室编号为集合 $\{1\ldots m\}$ 。

所有 $\texttt{ICORE}$ 成员都非常守纪律，遵守以下就诊规则：

1. 如果 $\texttt{ICORE}$ 成员应在时间 $t$ 到达医院，则在时间 $t$ 他们出现在其列表中的第一个医生办公室；
2. 如果多人在时间 $t$ 出现在某个医生办公室，则他们按照编号递增的顺序排队，并加入已经由更早到达的人形成的队尾；
3. 如果在时间 $t$ 办公室 $x$ 前有更早或同一时间到达的人排队，则队列中的第一个人进入办公室 $x$ 。此人在一个时间单位后离开办公室，并在时间 $t+1$ 出现在他们下一个要就诊的办公室。此时，队列中的第一个人进入办公室 $x$；
4. 如果在时间 $t$ 在办公室 $x$ 的就诊是给定访问者的最后一次就诊，则在时间 $t+1$ 该访问者离开医院。

你的任务是找出**最后一位访问者离开医院的时间**。

## 输入格式

第一行输入包含一个自然数 $c$ 给出要处理的案例数量。接下来的行构成 $c$ 个案例的输入，每个案例的格式如下所述。

案例的第一行数据包含两个自然数 $n$ 和 $m$ ，$1 \leq n,m \leq 1000$ ，分别表示访问者数量和医生办公室数量。接下来的 $n$ 行每行包含一个自然数序列。

在这些行中，第 $i$ 行（$1 \leq i \leq n$）具有以下格式：

$t \ k \ g_1 \ g_2 \ldots g_k$

表示第 $i$ 位访问者在时间 $t$ 到达，需要按顺序访问 $k$ 个办公室 $g_1 \ g_2 \ldots g_k$ ，其中每个 $g_j$ 是医生办公室的编号，$1 \leq g_j \leq m$ 。 $0 \leq t \leq 1000000$ ，并且一天中安排的访问次数不超过 $1000000$。

## 输出格式

对于每个输入案例，输出一行，表示最后一位访问者离开医院的时间。

## 样例输入

```
2
5 3
1 3 3 2 1
0 7 2 3 1 1 1 1 2
2 1 1
1 2 3 3
4 3 1 1 1
5 10
3 1 6

```

## 题目分析

### 问题本质

这是一个典型的**离散事件模拟**问题，模拟医院中病人按规则就诊的整个过程。问题需要我们跟踪多个病人按照特定规则在多个医生办公室间的移动，直到所有病人都完成就诊并离开医院。

### 关键规则理解

1. **时间单位** ：医生处理一个病人需要恰好 $1$ 个时间单位。
2. **队列规则** ：每个医生办公室有一个队列，遵循先到先服务（$\texttt{FCFS}$）原则，同时间到达的病人按编号从小到大排序。
3. **状态转移** ：
   - 病人在时间 $t$ 到达第一个办公室
   - 病人在时间 $t$ 进入医生办公室，在时间 $t+1$ 离开该办公室
   - 如果还有下一个办公室，病人在时间 $t+1$ 到达下一个办公室
   - 如果没有下一个办公室，病人在时间 $t+1$ 离开医院
4. **并发处理** ：同一时刻可能有多个事件同时发生（到达、离开等），需要按正确顺序处理。

### 数据范围分析

- $n, m \leq 1000$ ：病人和医生办公室数量都在 $1000$ 以内
- $t \leq 1000000$ ：时间值可能较大
- 总就诊次数 $\leq 1000000$ ：事件总数有限

## 解题思路

### 方法选择：事件驱动模拟

由于时间范围可能很大（$t$ 可达 $1000000$），如果采用按时间步进模拟（从 $t=0$ 开始每次加 $1$），在空闲时间段会有大量无意义的循环。因此，我们采用**事件驱动模拟**的方法。

### 核心数据结构设计

1. **病人结构体** ：存储每个病人的信息
   - `id` ：病人编号
   - `arriveTime` ：到达医院时间
   - `offices` ：需要就诊的办公室顺序列表
   - `currentPos` ：当前就诊进度（下一个要就诊的办公室索引）

2. **事件结构体** ：表示系统中的事件
   - `time` ：事件发生时间
   - `type` ：事件类型（$0$ 表示到达事件，$1$ 表示离开医生事件）
   - `patientId` ：相关病人编号
   - `office` ：相关医生办公室（对于离开事件）

3. **医生状态** ：
   - `doctorAvailable[m+1]` ：布尔数组，表示医生是否空闲
   - `queues[m+1]` ：每个办公室的等待队列，存储 `{到达时间, 病人ID}` 对

4. **事件优先队列** ：使用小顶堆管理所有事件，按时间、类型、病人编号的优先级排序

### 算法流程

1. **初始化**
   - 读取所有病人信息，创建病人对象
   - 初始化所有医生为空闲状态
   - 创建初始到达事件，加入事件队列

2. **事件循环** （直到所有病人都离开医院）
   a. **获取当前时间** ：从事件队列取出最早的事件
   b. **收集同时刻事件** ：取出所有相同时间的事件
   c. **处理到达事件** ：将到达的病人加入其第一个办公室的队列
   d. **处理离开事件** ：病人完成就诊
     - 如果还有下一个办公室：加入下一个办公室的队列
     - 如果是最后一次就诊：标记病人离开，更新最后离开时间
     - 释放医生（设为空闲状态）
   e. **队列排序** ：对每个办公室的队列按规则排序（先按到达时间，同时间按病人编号）
   f. **医生开始新就诊** ：对于空闲医生，如果有等待病人，开始就诊并创建离开事件
   g. **继续循环** ：重复直到所有病人都离开

3. **输出结果** ：输出最后离开时间

### 时间复杂度分析

- 每个病人最多产生 $k+1$ 个事件（$k$ 次就诊，$1$ 次初始到达）
- 总事件数 $O(V)$ ，其中 $V$ 是总就诊次数（$\leq 1000000$）
- 每个事件处理涉及队列排序 $O(m \log q)$ ，其中 $q$ 是队列长度
- 总体复杂度可以接受题目数据范围

### 关键难点与解决

1. **同时间事件处理顺序** ：题目要求同时间到达的病人按编号排序，这需要在队列中正确维护顺序
2. **医生空闲与忙碌状态** ：需要准确跟踪医生何时可以开始下一个病人的就诊
3. **时间跳跃** ：事件驱动模拟避免了无效的时间步进，提高了效率

## 实现代码

```cpp
// Queuing at the Doctors
// UVa ID: 10588

// Submission Date: 2026-01-07
// UVa Run Time: 0.350s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Patient {
    int id;
    int arriveTime;
    vector<int> offices;
    int currentPos;  // 在offices中的索引
    Patient(int i, int t, const vector<int>& off) : id(i), arriveTime(t), offices(off), currentPos(0) {}
};

struct Event {
    int time;
    int type;  // 0:到达事件，1:离开医生事件
    int patientId;
    int office;  // 对于type=1，表示离开的办公室
    bool operator>(const Event& other) const {
        if (time != other.time) return time > other.time;
        if (type != other.type) return type > other.type;
        return patientId > other.patientId;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int c;
    cin >> c;
    while (c--) {
        int n, m;
        cin >> n >> m;
        vector<Patient> patients;
        for (int i = 0; i < n; ++i) {
            int t, k;
            cin >> t >> k;
            vector<int> offices(k);
            for (int j = 0; j < k; ++j) cin >> offices[j];
            patients.emplace_back(i, t, offices);
        }
        // 每个办公室的队列，存储{到达时间, 病人ID}
        vector<vector<pair<int, int>>> queues(m + 1);
        // 医生是否空闲
        vector<bool> doctorAvailable(m + 1, true);
        // 事件优先队列
        priority_queue<Event, vector<Event>, greater<Event>> events;
        // 初始化所有到达事件
        for (int i = 0; i < n; ++i) events.push({patients[i].arriveTime, 0, i, -1});
        int finished = 0;
        int lastLeaveTime = 0;
        while (finished < n) {
            Event e = events.top();
            events.pop();
            int currentTime = e.time;
            // 处理当前时间的所有事件
            vector<Event> sameTimeEvents;
            sameTimeEvents.push_back(e);
            while (!events.empty() && events.top().time == currentTime) {
                sameTimeEvents.push_back(events.top());
                events.pop();
            }
            // 先处理到达事件
            for (const Event& ev : sameTimeEvents) {
                if (ev.type == 0) {  // 到达事件
                    Patient& p = patients[ev.patientId];
                    if (p.currentPos < (int)p.offices.size()) {
                        int office = p.offices[p.currentPos];
                        queues[office].push_back({currentTime, ev.patientId});
                    }
                }
            }
            // 再处理离开事件
            for (const Event& ev : sameTimeEvents) {
                if (ev.type == 1) {  // 离开医生事件
                    Patient& p = patients[ev.patientId];
                    p.currentPos++;
                    // 医生空闲
                    doctorAvailable[ev.office] = true;
                    if (p.currentPos >= (int)p.offices.size()) {
                        // 病人离开医院
                        finished++;
                        lastLeaveTime = currentTime;  // 在当前时间完成最后一次就诊
                    } else {
                        // 前往下一个办公室
                        int nextOffice = p.offices[p.currentPos];
                        queues[nextOffice].push_back({currentTime, ev.patientId});
                    }
                }
            }
            // 对每个办公室的队列排序：按到达时间，同时间按病人ID
            for (int office = 1; office <= m; ++office) {
                sort(queues[office].begin(), queues[office].end(), [](const pair<int, int>& a, const pair<int, int>& b) {
                    if (a.first != b.first) return a.first < b.first;
                    return a.second < b.second;
                });
            }
            // 医生开始处理病人
            for (int office = 1; office <= m; ++office) {
                if (doctorAvailable[office] && !queues[office].empty()) {
                    // 取出队列第一个病人
                    int patientId = queues[office][0].second;
                    queues[office].erase(queues[office].begin());
                    // 安排离开事件
                    events.push({currentTime + 1, 1, patientId, office});
                    doctorAvailable[office] = false;
                }
            }
        }
        
        // 病人离开发生在完成最后一次就诊后的下一个时间单位
        cout << lastLeaveTime << "\n";
    }
    
    return 0;
}
```

## 总结

本题是一个典型的事件驱动模拟问题，主要考察对复杂规则的理解和实现能力。关键点包括：

1. **正确理解题目规则** ：特别是同时间到达的排序规则和状态转移时序
2. **选择合适的数据结构** ：优先队列管理事件，向量数组管理医生队列
3. **高效的时间处理** ：避免无效的时间步进，直接跳转到下一个事件时间
4. **正确处理并发事件** ：同时间事件的正确处理顺序

通过本题，我们可以学习到如何处理复杂的离散事件模拟问题，这在许多实际应用场景中（如操作系统调度、网络模拟等）都有广泛应用。
