## 题目描述

给定一个 $n \times n$ 的网格，每个格子可能是 `x`（可用）或 `.`（多孔，不可用）。要求统计网格中所有可能的“风筝”数量。

“风筝”定义为：
1. **正方形风筝**：边平行于网格的正方形区域，且内部全部为 `x`
2. **菱形风筝**：旋转 $45^\circ$ 的正方形区域，且内部全部为 `x`

**重要限制**：风筝的尺寸必须大于等于 $2$（即边长至少为 $2$ 的正方形，或尺寸至少为 $2$ 的菱形）。

## 输入格式

- 第一行：整数 $n$ ($n \leq 500$)，表示网格大小
- 接下来 $n$ 行：每行 $n$ 个字符（`x` 或 `.`）

## 输出格式

- 对于每个测试用例，输出一个整数表示风筝总数

## 题目分析

### 问题难点

1. **双重几何形状**：需要同时处理正方形和菱形两种不同形状的区域
2. **实心约束**：风筝内部不能有任何多孔部分（`.`）
3. **尺寸限制**：只统计尺寸 $\geq 2$ 的风筝
4. **时间复杂度**：$n \leq 500$，需要 $O(n^2)$ 的算法

### 关键观察

1. **正方形检测**：可以使用经典的动态规划方法计算以每个点为右下角的最大正方形边长
2. **菱形检测**：菱形可以看作旋转 $45^\circ$ 的正方形，可以通过类似的动态规划方法处理
3. **尺寸统计**：对于最大尺寸为 $k$ 的风筝，尺寸从 $2$ 到 $k$ 的风筝数量为 $k - 1$

## 解题思路

### 正方形风筝的统计

定义 $s[i][j]$ 表示以 $(i,j)$ 为右下角的最大正方形风筝的边长。

**状态转移方程**：
- 如果 $g[i][j] = \text{'x'}$：
  $$
  s[i][j] = \min(s[i-1][j], s[i][j-1]) + 1
  $$
- 否则：$s[i][j] = 0$

**优化技巧**：AC 代码中使用了一个巧妙的检查：
```cpp
if (g[i - s[i][j]][j - s[i][j]] == 'x') s[i][j]++;
```
这个检查确保正方形的左上角也是 `x`，从而保证整个正方形区域都是实心的。

### 菱形风筝的统计

定义 $d[i][j]$ 表示以 $(i,j)$ 为最下顶点的最大菱形风筝的尺寸。

**状态转移方程**：
- 如果 $g[i][j] = \text{'x'}$：
  $$
  d[i][j] = \min(d[i-1][j-1], d[i-1][j], d[i-1][j+1]) + 1
  $$
- 否则：$d[i][j] = 0$

**优化技巧**：同样使用检查：
```cpp
if (g[i - 2 * d[i][j]][j] == 'x') d[i][j]++;
```
这个检查确保菱形的顶部顶点也是 `x`，保证整个菱形区域都是实心的。

### 最终统计

对于每个格子 $(i,j)$：
- 正方形风筝贡献：$s[i][j] - 1$
- 菱形风筝贡献：$d[i][j] - 1$
- 总贡献：$(s[i][j] - 1) + (d[i][j] - 1) = s[i][j] + d[i][j] - 2$

```cpp
// Kites
// UVa ID: 10593
// Verdict: Accepted
// Submission Date: 2025-11-03
// UVa Run Time: 0.040s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
const int MAXN = 510;
char g[MAXN][MAXN];
int s[MAXN][MAXN], d[MAXN][MAXN];
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int n;
    while (cin >> n) {
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                cin >> g[i][j];
        memset(s, 0, sizeof s);
        memset(d, 0, sizeof d);
        int r = 0;
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (g[i][j] == 'x') {
                    // 正方形：以(i,j)为右下角的最大正方形边长
                    s[i][j] = min({s[i - 1][j], s[i][j - 1]});
                    if (g[i - s[i][j]][j - s[i][j]] == 'x') s[i][j]++;
                    // 菱形：以(i,j)为最下顶点的最大菱形尺寸
                    d[i][j] = min({d[i - 1][j - 1], d[i - 1][j], d[i - 1][j + 1]});
                    if (g[i - 2 * d[i][j]][j] == 'x') d[i][j]++;
                    // 统计边长大于 1 的正方形和菱形数量
                    r += s[i][j] + d[i][j] - 2;
                }
        cout << r << '\n';
    }
    return 0;
}
```
