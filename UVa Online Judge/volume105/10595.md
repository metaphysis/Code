## 题目描述

**蜂巢棋盘上的骑士问题** 是一个在六边形网格上的最短路径搜索问题。与传统国际象棋棋盘不同，蜂巢棋盘由六边形格子组成，最多可包含 $10000$ 个格子。棋盘格子的编号方式为：任意选择一个六边形作为 $1$ 号格子，然后按顺时针方向向外螺旋编号。

骑士的走法与国际象棋类似，但它在六边形棋盘上可以朝 $12$ 个不同的方向移动。例如，从 $1$ 号格子出发，骑士可以移动到编号为 $20, 21, 23, 24, 26, 27, 29, 30, 32, 33, 35, 36$ 的格子。

### 输入格式

输入包含多个测试用例。每个测试用例的第一行包含两个整数 $N \leq 10000$ 和 $M \leq N$ ，其中 $N$ 表示棋盘上的格子总数， $M$ 表示障碍物的数量。接下来的 $M$ 行每行包含一个障碍物所在的格子编号。每个测试用例的最后一行包含两个整数，分别表示骑士的起点和终点。每个测试用例后跟一个空行。输入直到文件结束（ `EOF` ）。

### 输出格式

对于每个测试用例，输出一行。如果可以从起点到达终点，则输出最小步数；否则输出 `Impossible.` 。

### 样例输入

```
70 2
5
1
14 2
70 2
5
1
14 2
```

### 样例输出

```
1
1
```

## 题目分析

本题的核心挑战在于如何处理六边形网格的几何结构。与传统方形网格不同，六边形网格中每个格子有 $6$ 个邻居，这使得骑士的移动规则更为复杂。题目中给出的示例（从 $1$ 号格子可以跳到 $12$ 个特定的格子）暗示了骑士在六边形棋盘上的移动模式： **先沿某个方向移动两步，然后向左或向右转 $60$ 度移动一步** 。

解决本题需要完成以下步骤：

1. **建立坐标系统** ：将螺旋编号映射到六边形网格的坐标，以便计算邻居关系和骑士移动。
2. **生成网格映射** ：预计算所有编号对应的坐标，以及坐标对应的编号，建立双向映射。
3. **计算骑士移动** ：对于任意格子，根据六边形几何规则计算其可达的 $12$ 个目标格子。
4. **广度优先搜索（ $\texttt{BFS}$ ）** ：在考虑障碍物的情况下，搜索从起点到终点的最短路径。

## 解题思路

### 1. 坐标系统选择

我们使用一个简单的二维坐标系统表示六边形格子。设中心 $1$ 号格子的坐标为 $(0, 0)$ ，六个邻居方向对应的坐标偏移为：

- 方向 $0$ : $(0, 1)$
- 方向 $1$ : $(-1, 1)$
- 方向 $2$ : $(-1, 0)$
- 方向 $3$ : $(0, -1)$
- 方向 $4$ : $(1, -1)$
- 方向 $5$ : $(1, 0)$

这 $6$ 个方向按顺时针排列，覆盖了六边形的所有相邻方向。

### 2. 螺旋编号与坐标映射

我们需要实现一个算法，将螺旋编号映射到上述坐标系统。观察编号规律可以发现，编号的分布呈螺旋状向外扩展。我们采用以下方法生成映射：

- 从中心开始，第 $k$ 圈（ $k \geq 0$ ）有 $6 \times k$ 个格子（ $k=0$ 时为 $1$ 个格子）。
- 通过循环生成每一圈的坐标，并分配递增的编号。

具体实现中，我们使用两个映射表：
- `idToPoint` ：编号 → 坐标
- `pointToId` ：坐标 → 编号

### 3. 骑士移动计算

在六边形棋盘上，骑士的移动规则为： **先沿某个方向移动两步，然后向左或向右转 $60$ 度移动一步** 。这会产生 $12$ 种可能的移动（ $6$ 个方向 × $2$ 种转向）。

对于给定格子 $u$ ，其坐标为 $(x, y)$ ，骑士移动的计算步骤如下：
1. 对于每个方向 $i$ （ $0 \leq i < 6$ ），计算两步后的中间坐标：
   $$
   (x', y') = (x + 2 \cdot dx[i], y + 2 \cdot dy[i])
   $$
   其中 $(dx[i], dy[i])$ 是方向 $i$ 的坐标偏移。
2. 从中间坐标向左转 $60$ 度（方向 $(i+1) \mod 6$ ）和向右转 $60$ 度（方向 $(i+5) \mod 6$ ）各移动一步，得到两个目标坐标。
3. 将目标坐标转换为编号，并检查是否在棋盘范围内。

### 4. 广度优先搜索

使用 $\texttt{BFS}$ 求最短路径：
- 从起点开始，逐层扩展可到达的格子。
- 使用队列维护待访问的格子。
- 记录每个格子的最短步数，避免重复访问。
- 遇到终点时停止搜索。

注意障碍物的处理：骑士不能移动到有障碍物的格子。

### 5. 复杂度分析

- 预计算坐标映射： $O(N)$ ， $N \leq 10000$ ，可以接受。
- $\texttt{BFS}$ ：每个格子最多访问一次，每次需要计算 $12$ 种移动，总复杂度 $O(N)$ 。
- 空间复杂度： $O(N)$ 用于存储坐标映射和搜索状态。

```cpp
// Knight on the Bee Board

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 20010, INF = 0x3f3f3f3f;

// 双向映射：编号<->坐标
map<int, pair<int, int>> idToPoint;
map<pair<int, int>, int> pointToId;

// 建立坐标和编号之间的双向映射
void initialize() {
    // 五个方向的偏移量，用于生成螺旋网格
    int offset[5][2] = {{-1, 0}, {0, -1}, {1, -1}, {1, 0}, {0, 1}};
    // i: 当前圈的起始编号, j: 当前圈的格子数, k: 当前圈数
    for (int i = 1, j = 1, k = 0; i < MAXN; i += j, j += 6, k++) {
        // 设置当前圈起始点的坐标
        idToPoint[i] = {0, k};
        pointToId[{0, k}] = i;
        // 填充起始点所在的对角线
        for (int m = 0; m < k; m++) {
            idToPoint[i - m] = {m, k - m};
            pointToId[{m, k - m}] = i - m;
        }
        int current = i;
        // 填充当前圈的其余部分（5条边）
        for (int m = 0; m < 5; m++)
            for (int n = 0; n < k; n++) {
                int x = idToPoint[current].first + offset[m][0];
                int y = idToPoint[current].second + offset[m][1];
                idToPoint[current + 1] = {x, y};
                pointToId[{x, y}] = current + 1;
                current++;
            }
    }
}

// 获取骑士从编号id可以跳到的所有格子（不超过N）
vector<int> getKnightMoves(int id, int N) {
    vector<int> moves;
    if (id < 1 || id > N) return moves;
    pair<int, int> p = idToPoint[id];
    // 六个方向的坐标偏移
    int offset[6][2] = {{0, 1}, {-1, 1}, {-1, 0}, {0, -1}, {1, -1}, {1, 0}};
    for (int i = 0; i < 6; i++) {
        // 先走两步
        int x = p.first, y = p.second;
        x += 2 * offset[i][0], y += 2 * offset[i][1];
        // 向左转60度和向右转60度
        int d1 = (i + 1) % 6, d2 = (i + 5) % 6;
        int n1 = pointToId[{x + offset[d1][0], y + offset[d1][1]}];
        int n2 = pointToId[{x + offset[d2][0], y + offset[d2][1]}];
        if (n1 <= N) moves.push_back(n1);
        if (n2 <= N) moves.push_back(n2);
    }
    return moves;
}

int main() {
    int N, M;
    initialize(); // 预计算坐标映射
    while (cin >> N >> M) {
        vector<bool> obstacle(N + 1, false);
        vector<int> dist(N + 1, INF);
        // 读取障碍物
        for (int i = 0; i < M; ++i) {
            int x;
            cin >> x;
            if (x >= 1 && x <= N) obstacle[x] = true;
        }
        int start, target;
        cin >> start >> target;
       
        // BFS求最短路径
        queue<int> q;
        if (start >= 1 && start <= N && !obstacle[start]) {
            dist[start] = 0;
            q.push(start);
        }
        while (!q.empty()) {
            int u = q.front(); q.pop();
            if (u == target) break; // 到达终点
            vector<int> nextMoves = getKnightMoves(u, N);
            for (int next : nextMoves)
                if (next >= 1 && next <= N && !obstacle[next] && dist[next] == INF) {
                    dist[next] = dist[u] + 1;
                    q.push(next);
                }
        }
        if (dist[target] == INF) cout << "Impossible.";
        else cout << dist[target];
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于正确处理六边形网格的几何结构。通过建立螺旋编号与坐标的双向映射，我们可以方便地计算骑士的移动。 $\texttt{BFS}$ 算法确保找到最短路径。预计算坐标映射使得每次移动计算的时间复杂度为常数，整体算法效率较高。

注意点：
- 障碍物需要提前标记，骑士不能移动到障碍物格子。
- 每个测试用例后有空行，需要正确处理输入格式。
- 坐标映射的生成算法需要仔细验证，确保与题目描述的螺旋编号一致。

通过以上方法，我们可以高效地解决蜂巢棋盘上的骑士最短路径问题。
