## 题目描述

一个人住在一个小屋中。某天早晨，他向北走 $n$ 公里，接着向东走 $n$ 公里，最后向南走 $n$ 公里，回到了起点。你需要确定他小屋所在的纬度。假设该星球是一个完美的球体，半径为 $R$，且整个表面都是可通行的平地。

如果存在多个解，你需要输出前 $10$ 个最小的解（按纬度从小到大）。其中一个显然的解是南极，但题目要求我们不输出它。

**输入格式**  
每行包含两个整数 $R$（$0 < R < 100000$）和 $n$（$R/100 \leq n \leq R/8$），分别表示星球半径（公里）和每次行走的距离（公里）。输入以 $R = 0$ 和 $n = 0$ 结束。

**输出格式**  
对于每组输入，先输出 `Case X:`，接着输出最多 $10$ 行，每行是一个纬度值（度数），保留五位小数。

## 题目分析与解题思路

### 1. 问题理解

这是一个球面几何问题。关键在于理解：从某点出发，向北、向东、向南各走 $n$ 公里后能回到原点，这样的路径只有在特定的纬度上才可能实现。

### 2. 数学模型

设小屋所在的纬度为 $\phi$（弧度制，北纬为正），星球半径为 $R$。

- **第一步：向北走 $n$ 公里**  
  向北移动的弧长为 $n$，对应的纬度变化为：
  $$
  \Delta = \frac{n}{R}
  $$
  因此，新纬度为：
  $$
  \phi_1 = \phi + \Delta
  $$

- **第二步：向东走 $n$ 公里**  
  在纬度 $\phi_1$ 上，纬圈的半径为 $R \cos(\phi_1)$，周长为 $2\pi R \cos(\phi_1)$。  
  向东走 $n$ 公里意味着绕这个纬圈走了整数圈，设圈数为 $k$（$k$ 为正整数），则有：
  $$
  n = k \cdot 2\pi R \cos(\phi_1)
  $$
  即：
  $$
  \cos(\phi_1) = \frac{n}{2\pi R k}
  $$

- **第三步：向南走 $n$ 公里**  
  向南移动 $n$ 公里后，纬度回到 $\phi$，因此：
  $$
  \phi_1 - \frac{n}{R} = \phi
  $$
  这实际上与第一步的 $\phi_1 = \phi + \frac{n}{R}$ 是一致的。

### 3. 核心方程

将 $\phi_1 = \phi + \frac{n}{R}$ 代入 $\cos(\phi_1) = \frac{n}{2\pi R k}$，得到：
$$
\cos\left(\phi + \frac{n}{R}\right) = \frac{n}{2\pi R k}
$$

解得：
$$
\phi = \arccos\left(\frac{n}{2\pi R k}\right) - \frac{n}{R}
$$

### 4. 解的筛选

- 我们只考虑北半球的解，即 $\phi > 0$。
- 对于每个正整数 $k$，计算 $\phi$，并保留有效的解。
- 题目要求输出前 $10$ 个最小的解（即纬度最接近 $0$ 的 $10$ 个解），因此我们需要将解按升序排序后输出前 $10$ 个。

### 5. 算法步骤

1. 读取 $R$ 和 $n$。
2. 对 $k = 1, 2, \dots$ 循环，直到收集到 $10$ 个有效解或 $k$ 超过某个上限（例如 $10$）。
3. 对于每个 $k$，计算：
   - $\cos(\phi_1) = \frac{n}{2\pi R k}$
   - 若 $\cos(\phi_1) > 1$ 或 $n > 2\pi R k$，则跳过（无解）
   - 否则计算 $\phi = \arccos(\cos(\phi_1)) - \frac{n}{R}$
   - 若 $\phi > 0$，则将其转换为度数并保存
4. 将所有有效解按升序排序。
5. 输出前 $10$ 个解，保留五位小数。

## 参考代码

```cpp
// Find the Latitude
// UVa ID: 10598
// Verdict: Accepted

//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
const double PI = acos(-1.0);
int main() {
    int caseNumber = 1;
    double R, n;
    while (cin >> R >> n) {
        if (R == 0 && n == 0) break;
        cout << "Case " << caseNumber++ << ":" << endl;
        vector<double> latitudes;
        // k 是向东走的圈数
        for (int k = 1; k <= 10; ++k) {
            double denominator = 2.0 * PI * R * k;
            double cosValue = n / denominator;
            double phiRad = acos(cosValue) - (n / R);
            double phiDeg = phiRad * 180.0 / PI;
            latitudes.push_back(phiDeg);
        }
        // 按纬度从大到小排序（题目要求前10个最小的解，即纬度最大的）
        sort(latitudes.begin(), latitudes.end());
        // 输出前10个
        for (size_t i = 0; i < latitudes.size() && i < 10; ++i) {
            cout << fixed << setprecision(5) << latitudes[i] << endl;
        }
    }
    return 0;
}
```
## 总结

本题是一个典型的球面几何问题，关键在于理解“向东走 $n$ 公里”意味着在某个纬圈上绕整数圈。通过数学推导得到纬度公式后，枚举可能的圈数 $k$，计算并排序即可得到答案。注意排除无效解和南极解，并按题目要求输出前 $10$ 个最小的解。
