## 题目描述

在一个山脉中，有一个位于同一地质层中的钻石矿藏需要开采。对该地层进行了网格化地震勘探，网格中的每个格子可能是以下几种类型：

- `*`：表示钻石矿点
- `.`：表示普通网格
- `#`：表示边界或障碍物

为了开采钻石，需要从地层外部沿着该层挖掘矿井。使用现有机械，矿井只能从一个网格向相邻的北、东、南、西方向延伸。出于安全原因，矿井不允许分叉，即在一个矿井中，任何网格不能有超过两个直接相连的网格。注意，因此仍然允许两条矿井平行挖掘。

需要经济地进行钻探。要求找到一种方案，能够到达所有钻石矿点，同时使用尽可能少的网格数（包括矿点本身）。

### 输入格式

第一行包含一个整数 $T \leq 10$，表示测试用例数。每个测试用例格式如下：

1. 第一行：两个整数 $n, m$（$3 \leq n, m \leq 11$）
2. 接下来 $n$ 行：每行 $m$ 个字符，字符集为 `{*, ., #}`

可以假定每个图中矿点数量在 $1$ 到 $10$ 之间，且整个图被 `#` 包围。

### 输出格式

对每个测试用例，输出一行，表示能够访问所有钻石矿点的最少网格数。可以假定总是存在解，且最多需要 $20$ 个网格。

## 题目分析

### 问题本质

这是一个在网格图中寻找覆盖所有特殊点（矿点）的最小路径集合问题，且每条路径必须满足以下条件：

1. 路径必须从边界开始（因为矿井要从外部挖掘）
2. 路径是简单路径（无分支、不自交）
3. 允许多条路径并行（即可以有多条矿井）

### 关键观察

1. **矿点数量很少**：最多只有 $10$ 个矿点，这提示我们可以使用状态压缩动态规划
2. **路径限制严格**：由于路径不能有分支，每条路径实际上是一条简单链
3. **边界起始**：每条链必须从边界开始，所以需要考虑矿点到边界的距离
4. **并行性**：允许多条链同时存在，这意味着我们可以将矿点划分为若干组，每组用一条链覆盖

### 算法思路

将问题分解为两个子问题：

1. **单链问题**：对于给定的一组矿点，求覆盖这些矿点的一条简单链的最小长度
2. **多链划分问题**：将矿点划分为若干组，每组用一条链覆盖，求总长度的最小值

## 解题思路详解

### 步骤1：预处理距离信息

对于每个矿点，我们需要知道它到最近边界的距离，因为每条矿井必须从边界开始。这可以通过从每个矿点进行 $\texttt{BFS}$ 搜索实现。

```cpp
// BFS计算矿点到最近边界的距离
int bfs(int sx, int sy) {
    bool visited[MAXN][MAXN] = {false};
    queue<pair<Point, int>> q;
    q.push({{sx, sy}, 0});
    visited[sx][sy] = true;
    
    while (!q.empty()) {
        auto [pos, dist] = q.front(); q.pop();
        for (int d = 0; d < 4; ++d) {
            int nx = pos.x + dirs[d][0], ny = pos.y + dirs[d][1];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            if (visited[nx][ny]) continue;
            if (grid[nx][ny] == '#') return dist + 1;  // 找到边界
            visited[nx][ny] = true;
            q.push({{nx, ny}, dist + 1});
        }
    }
    return 0;
}
```

### 步骤2：定义状态和动态规划

设矿点数量为 $k$（$k \leq 10$），我们用位掩码 $mask$ 表示一个矿点子集。

#### 2.1 单链动态规划 $dp[mask][i]$

定义 $dp[mask][i]$ 表示访问 $mask$ 中的矿点，形成一条简单链，且最后一个访问的矿点是 $i$ 的最小长度。

**状态转移方程**：
$$
dp[mask \cup \{j\}][j] = \min_{i \in mask} \{dp[mask][i] + dist(i,j)\}
$$

其中 $dist(i,j)$ 是矿点 $i$ 和 $j$ 之间的曼哈顿距离。为什么用曼哈顿距离？因为路径是简单链且不能分叉，矿点之间的最优连接就是直线连接。

**初始化**：
$$
dp[\{i\}][i] = dist[i]
$$
其中 $dist[i]$ 是矿点 $i$ 到最近边界的距离。

#### 2.2 单链最优值 $g[mask]$

定义 $g[mask]$ 为覆盖 $mask$ 中所有矿点的一条简单链的最小长度：
$$
g[mask] = \min_{i \in mask} dp[mask][i]
$$

### 步骤3：多链划分动态规划 $f[mask]$

定义 $f[mask]$ 为覆盖 $mask$ 中所有矿点的最优解（可以有多条链）。

**状态转移方程**：
$$
f[mask] = \min_{sub \subseteq mask} \{f[mask \setminus sub] + g[sub]\}
$$

这个方程的含义是：将矿点集合 $mask$ 划分为两个部分，一部分 $sub$ 用一条链覆盖，剩下的 $mask \setminus sub$ 用最优方式覆盖。

**初始化**：
$$
f[\emptyset] = 0
$$

### 步骤4：算法流程

1. 读取输入，提取所有矿点位置
2. 对每个矿点，计算到最近边界的距离
3. 初始化 $dp$ 数组，计算所有 $dp[mask][i]$
4. 计算所有 $g[mask]$
5. 使用子集枚举计算所有 $f[mask]$
6. 输出 $f[$全集$]$

### 时间复杂度分析

- 矿点数量 $k \leq 10$，状态总数 $2^k \leq 1024$
- $dp$ 计算：$O(2^k \cdot k^2)$
- $f$ 计算：$O(3^k)$（子集枚举）
- 总复杂度在 $k=10$ 时是可接受的

### 空间复杂度分析

- $dp$ 数组：$O(2^k \cdot k)$
- $g$ 和 $f$ 数组：$O(2^k)$
- 总空间复杂度在可接受范围内

## 算法正确性证明

### 单链最优性

对于一组矿点，如果要用一条简单链覆盖它们，那么：
1. 链必须从边界开始，所以加上第一个矿点到边界的距离
2. 链上的矿点必须按某种顺序排列
3. 相邻矿点之间用直线连接是最优的（曼哈顿距离）

$dp[mask][i]$ 精确计算了这种情况下的最小长度。

### 多链划分最优性

由于允许矿井并行，我们可以将矿点划分为多个组，每组用一条链覆盖。$f[mask]$ 通过枚举所有可能的划分方式，找到了全局最优解。

### 边界情况处理

1. **没有矿点**：输出 $0$
2. **单个矿点**：只需要从边界到该矿点的一条链，长度为 $dist[i]$
3. **所有矿点无法用单链覆盖**：自动通过多链划分找到最优解

```cpp
// Mines For Diamonds
// UVa ID: 10605

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 15;
const int INF = 0x3f3f3f3f;
const int dirs[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

int n, m, cnt;
char grid[MAXN][MAXN];
struct Point { int x, y; };
Point deposits[MAXN];

// 计算曼哈顿距离
inline int manhattan(Point a, Point b) { return abs(a.x - b.x) + abs(a.y - b.y);}

// BFS计算矿点到最近边界的距离
int bfs(int sx, int sy) {
    bool visited[MAXN][MAXN] = {false};
    queue<pair<Point, int>> q;
    q.push({{sx, sy}, 0});
    visited[sx][sy] = true;
    while (!q.empty()) {
        auto [pos, dist] = q.front(); q.pop();
        for (int d = 0; d < 4; ++d) {
            int nx = pos.x + dirs[d][0], ny = pos.y + dirs[d][1];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            if (visited[nx][ny]) continue;
            if (grid[nx][ny] == '#') return dist + 1;
            visited[nx][ny] = true;
            q.push({{nx, ny}, dist + 1});
        }
    }
    return 0;  // 应该不会发生，因为网格被#包围
}

void solve() {
    // 读取输入
    scanf("%d%d", &n, &m);
    cnt = 0;
    for (int i = 1; i <= n; ++i) {
        scanf("%s", grid[i] + 1);
        for (int j = 1; j <= m; ++j)
            if (grid[i][j] == '*')
                deposits[cnt++] = {i, j};
    }
    if (cnt == 0) {
        printf("0\n");
        return;
    }
    // 1. 计算每个矿点到边界的距离
    int dist[MAXN];
    for (int i = 0; i < cnt; ++i)
        dist[i] = bfs(deposits[i].x, deposits[i].y);
    // 2. 初始化DP数组
    int dp[1 << MAXN][MAXN], g[1 << MAXN], f[1 << MAXN];
    memset(dp, INF, sizeof(dp)); memset(g, INF, sizeof(g)); memset(f, INF, sizeof(f));
    // 初始化：单个矿点的链
    for (int i = 0; i < cnt; ++i) dp[1 << i][i] = dist[i];
    // 3. 计算dp[mask][i]：访问mask中的矿点，最后是i，形成一条链
    for (int mask = 1; mask < (1 << cnt); ++mask)
        for (int j = 0; j < cnt; ++j) {
            if (!(mask & (1 << j))) continue;
            if (dp[mask][j] == INF) continue;
            // 尝试从j扩展到其他矿点k
            for (int k = 0; k < cnt; ++k) {
                if (mask & (1 << k)) continue;  // k不在mask中
                int newMask = mask | (1 << k);
                int newDist = dp[mask][j] + manhattan(deposits[j], deposits[k]);
                if (newDist < dp[newMask][k]) {
                    dp[newMask][k] = newDist;
                }
            }
        }
    // 4. 计算g[mask]：mask中的矿点形成一条链的最小长度
    for (int mask = 1; mask < (1 << cnt); ++mask)
        for (int j = 0; j < cnt; ++j)
            if (mask & (1 << j))
                g[mask] = min(g[mask], dp[mask][j]);
    // 5. 计算f[mask]：访问mask中的矿点的最优解（可多条链）
    f[0] = 0;
    for (int mask = 1; mask < (1 << cnt); ++mask)
        // 枚举子集
        for (int sub = mask; sub > 0; sub = (sub - 1) & mask)
            f[mask] = min(f[mask], f[mask ^ sub] + g[sub]);
    printf("%d\n", f[(1 << cnt) - 1]);
}

int main() {
    int t;
    scanf("%d", &t);
    while (t--) solve();
    return 0;
}
```

## 总结

本题的关键在于将复杂的最优化问题分解为两个层次：
1. 单条链的最优化（ $\texttt{TSP}$ 问题的变种）
2. 多条链的划分问题（集合划分问题）

通过状态压缩动态规划，我们能够在矿点数量较少的情况下高效求解。算法的时间复杂度和空间复杂度都在可接受范围内，能够处理题目给出的最大数据规模。

这个问题的解决展示了如何将复杂的约束条件转化为可计算的数学模型，以及如何使用动态规划处理组合优化问题。
