## 题目描述

在一个 $size \times size$ 的网格中，每个格子是 $1 \times 1$ 的正方形。有 $n$ 个蘑菇（圆形个体），每个蘑菇由圆心坐标 $(x, y)$ 和半径 $r$ 给出。如果一个格子的正方形区域与圆有交集（仅触碰边界不算），则认为该格子被“影响”。需要计算被影响的格子总数。

**输入**：第一行 $N$ 为测试用例数。每个测试用例第一行为网格大小 $size$ 和蘑菇数量 $n$，接下来 $n$ 行每行三个浮点数 $x, y, r$。

**输出**：每个测试用例一行，输出被影响的格子数。

**数据范围**：$size \leq 10^6$，$n \leq 1000$，答案 $< 10^9$。

## 题目分析

本题是一个典型的**圆与整数格子的相交计数**问题。最直接的思路是枚举所有格子判断是否被覆盖，但 $size$ 可达 $10^6$，网格总格子数 $size^2$ 可达 $10^{12}$，完全不可行。

我们需要利用 $n \leq 1000$ 这一约束，从蘑菇的角度出发，只处理可能受影响的格子。

### 朴素思路

对于每个蘑菇，它覆盖的 $x$ 范围是 $[x - r, x + r]$，$y$ 范围类似。直接枚举这个矩形内的所有格子并判断，时间复杂度约为 $O(n \cdot r^2)$。当 $r$ 很大（接近 $size$）时，单个蘑菇可能覆盖 $10^{12}$ 量级的格子，显然不可行。

### 关键观察

1. **答案限制**：题目保证答案 $< 10^9$，意味着实际被覆盖的格子数量有限。
2. **每行独立**：对于固定的整数行 $y$（格子 $[y, y+1]$），圆在该行上覆盖的 $x$ 范围是一个连续区间 $[x_c - \Delta, x_c + \Delta]$，其中 $\Delta = \sqrt{r^2 - d^2}$，$d$ 为圆心到该行格子的垂直距离。
3. **行扫描法**：我们可以枚举每个蘑菇覆盖的所有行，生成该行上的 $x$ 区间线段，然后按行合并区间，累加长度。

### 为什么按行扫描更高效？

- 每个蘑菇影响的 $y$ 行数约为 $2r$，而不是 $r^2$。
- 生成的线段总数等于实际被影响的格子数（每行每个连续区间贡献一条线段），由于答案 $< 10^9$，线段总数也在可接受范围内，但实际运行时远远小于此（本题数据较友好）。
- 排序后按行合并区间，复杂度 $O(M \log M)$，其中 $M$ 为线段总数。

## 解题思路详解

### 第一步：将圆切割成水平线段

对于给定的蘑菇 $(cx, cy, r)$，我们需要找出它覆盖的所有整数行 $y$，以及每行上的 $x$ 区间。

考虑圆与水平线 $y = Y$ 的交点，实际上，格子 $[y, y+1]$ 是一个 $1$ 单位高的矩形。圆与该格子相交的条件是：圆与线段 $\{(x, y) \mid y \in [y, y+1]\}$ 有交点。

为了简化，我们可以将圆与格子上下边界的交点作为判断依据。设格子行索引为 $y$，其 $y$ 坐标范围为 $[y, y+1]$。圆心 $(cx, cy)$ 到该行的最近距离 `dy` 计算如下：

- 若 $cy < y$，则 $dy = y - cy$（圆心在行下方）
- 若 $cy > y + 1$，则 $dy = cy - (y + 1)$（圆心在行上方）
- 否则 $dy = 0$（圆心在行内部）

然后 $\Delta x = \sqrt{r^2 - dy^2}$，当 $dy < r$ 时有效。

为了生成线段，我们遍历 $y$ 从 `floor(cy - r)` 到 `ceil(cy + r)`，但需要分为三部分处理：

1. **圆心下方的行**（$y < floor(cy)$）：使用格子**上边界** $y+1$ 与圆心的垂直距离。
2. **圆心所在行**（$y = floor(cy)$）：直接使用 $\Delta x = r$。
3. **圆心上方的行**（$y > floor(cy)$）：使用格子**下边界** $y$ 与圆心的垂直距离。

具体实现中，使用浮点数计算 $\Delta x$，然后取 `floor(cx - dx)` 和 `ceil(cx + dx)` 作为区间的整数边界，再裁剪到 $[0, size]$ 范围内。

### 第二步：存储所有线段

每个线段是一个三元组 `(st, ed, y)`，表示在第 $y$ 行上，$x$ 坐标在 $[st, ed)$ 范围内的格子被覆盖（注意 $ed$ 是开区间边界，便于区间合并）。

### 第三步：排序与区间合并

将所有线段按 `y` 为主关键字、`st` 为次关键字排序。然后分组处理同一 `y` 的线段：

- 初始化当前合并区间的左右边界为第一条线段的 `st, ed`。
- 遍历后续线段：
  - 如果当前线段左端 $\leq$ 当前右边界，则扩展右边界（取最大值）。
  - 否则，将当前合并区间的长度累加到答案，并开始新的合并区间。
- 处理完同一 `y` 的所有线段后，加上最后一个合并区间的长度。

### 第四步：累加结果

每行上合并后的区间总长度就是该行被覆盖的格子数。将所有行累加得到最终答案。

## 复杂度分析

- **时间复杂度**：设生成的线段总数为 $M$，排序为 $O(M \log M)$，合并为 $O(M)$。$M$ 约等于所有蘑菇影响的格子数，受答案限制，实际运行很快。
- **空间复杂度**：$O(M)$。

## 注意事项

1. **浮点精度**：使用 `double` 类型，比较时注意容差（代码中通过边界判断隐含处理了）。
2. **边界处理**：格子索引从 $0$ 到 $size-1$，区间裁剪到 $[0, size]$ 保证边界正确。
3. **相切不算**：题目规定仅触碰边界不算覆盖，代码中通过 `st < ed` 确保区间非空，若仅相切则 `st == ed`，不生成线段。

```cpp
// Mushroom Misery

#include <bits/stdc++.h>
using namespace std;

// 线段结构体：表示某一行(y)上被覆盖的x区间[st, ed)
struct Seg {
    int st, ed, y;
};

// 全局线段数组（使用vector动态扩展）
vector<Seg> segs;

// 比较函数：先按y排序，再按左端点排序
bool cmp(const Seg& a, const Seg& b) {
    if (a.y != b.y) return a.y < b.y;
    return a.st < b.st;
}

// 添加一条线段（如果有效）
inline void addSeg(int st, int ed, int y) {
    if (st < ed) segs.push_back({st, ed, y});
}

// 将圆切割成水平线段
void cutToSegments(double cx, double cy, double r, int sz) {
    int y0 = (int)floor(cy);                     // 圆心所在的行索引
    int yMin = max(0, (int)floor(cy - r));       // 影响的最小行
    int yMax = min(sz, (int)ceil(cy + r));       // 影响的最大行（注意sz是网格边界）
    
    // 处理圆心下方的行（y < y0）
    for (int y = yMin; y < y0; ++y) {
        double dy = cy - (y + 1);                // 圆心到格子上边界的垂直距离
        double dx = sqrt(r * r - dy * dy);       // 半宽
        int st = max(0, (int)floor(cx - dx));
        int ed = min(sz, (int)ceil(cx + dx));
        addSeg(st, ed, y);
    }
    
    // 处理圆心所在的行
    int st = max(0, (int)floor(cx - r));
    int ed = min(sz, (int)ceil(cx + r));
    addSeg(st, ed, y0);
    
    // 处理圆心上方的行（y > y0）
    for (int y = y0 + 1; y < yMax; ++y) {
        double dy = y - cy;                      // 圆心到格子下边界的垂直距离
        double dx = sqrt(r * r - dy * dy);
        int st = max(0, (int)floor(cx - dx));
        int ed = min(sz, (int)ceil(cx + dx));
        addSeg(st, ed, y);
    }
}

int main() {
    int t, sz, n;
    scanf("%d", &t);                             // 测试用例数
    while (t--) {
        segs.clear();                            // 清空全局线段数组
        scanf("%d%d", &sz, &n);                  // 读取网格大小和蘑菇数量
        
        // 处理每个蘑菇
        for (int i = 0; i < n; ++i) {
            double x, y, r;
            scanf("%lf%lf%lf", &x, &y, &r);
            cutToSegments(x, y, r, sz);
        }
        
        // 按行排序
        sort(segs.begin(), segs.end(), cmp);
        
        long long ans = 0;
        // 按行分组，合并区间
        for (size_t i = 0, j = 0; i <= segs.size(); ++i) {
            // 当行号变化或到达末尾时，处理当前组
            if (i == segs.size() || segs[i].y != segs[j].y) {
                int L = segs[j].st, R = segs[j].ed;
                // 合并同一行内的所有区间
                for (size_t k = j + 1; k < i; ++k) {
                    if (segs[k].st <= R) {
                        R = max(R, segs[k].ed);
                    } else {
                        ans += R - L;
                        L = segs[k].st;
                        R = segs[k].ed;
                    }
                }
                ans += R - L;                    // 加上最后一个区间
                j = i;                           // 移动到下一组
            }
        }
        
        printf("%lld\n", ans);                   // 输出结果
    }
    return 0;
}
```

## 总结

本题的核心技巧是**将圆切割成水平线段**，然后通过**排序合并**统计总覆盖格子数。这种方法避免了逐格判断，充分运用了 $n$ 较小的特点，将问题转化为区间合并问题。

- 若网格较小（如 $size \leq 1000$），可以直接使用二维标记数组。
- 若 $n$ 较大但 $r$ 很小，也可直接枚举每格。
- 本题给出的解法是平衡了时空效率的最优解之一，在 $n=1000$ 时可达到 0ms 运行时间。
