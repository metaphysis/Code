[UVa UVa 10621 Jack and Jill](https://blog.csdn.net/metaphysis/article/details/156457407)

## 题目描述

自从在山上发生那件事后，$\texttt{Jack}$ 和 $\texttt{Jill}$ 互相讨厌，希望在上学途中尽可能保持距离。$\texttt{Jack}$ 和 $\texttt{Jill}$ 每天都要上学；$\texttt{Jack}$ 上男校，$\texttt{Jill}$ 上女校，两所学校同时开始上课。你受他们的律师委托，安排他们的路线和时间表，使得在他们上学途中的任何时刻，他们之间的直线距离的最小值尽可能大。

$\texttt{Jack}$ 和 $\texttt{Jill}$ 居住的小镇是一个 $n \times n$ 的网格（ $n \leq 30$ ）。从一个位置走到相邻位置需要 $1$ 分钟。在最大化两人之间的距离时，只需考虑他们所在网格位置之间的距离（即不需要考虑从一格到另一格路径上的中间点）。有些位置因为河流、建筑物等而无法通行。$\texttt{Jack}$ 必须从他的家出发，连续走到学校。$\texttt{Jill}$ 必须在与 $\texttt{Jack}$ 相同的时间从她家出发，连续走到她的学校。$\texttt{Jack}$ 的家和学校对 $\texttt{Jill}$ 是不可通行的，$\texttt{Jill}$ 的家和学校对 $\texttt{Jack}$ 也是不可通行的。其他对两人都不可通行的网格位置在输入中给出。

## 输入格式

输入包含多个测试用例。每个测试用例首先给出 $n$ ，随后是 $n$ 行，每行 $n$ 个字符，表示小镇的地图。在地图中：

- $\texttt{Jack}$ 的家用 `'H'` 表示
- $\texttt{Jack}$ 的学校用 `'S'` 表示  
- $\texttt{Jill}$ 的家用 `'h'` 表示
- $\texttt{Jill}$ 的学校用 `'s'` 表示
- 不可通行的位置用 `'*'` 表示
- 其他可通行位置用 `'.'` 表示

假设地图遵循常规的制图约定：北在上方，西在左侧。最后一个测试用例之后是一个包含 `'0'` 的行。

## 输出格式

对于每个输入用例，输出三行：

1. 在安排的时间表中，$\texttt{Jack}$ 和 $\texttt{Jill}$ 之间的最近距离（保留 $2$ 位小数）
2. $\texttt{Jack}$ 的路线
3. $\texttt{Jill}$ 的路线

每条路线是一个方向序列，表示从出发开始每分钟 $\texttt{Jack}$ 或 $\texttt{Jill}$ 应该走的方向。每个方向是 `'N'` 、 `'S'` 、 `'E'` 或 `'W'` 之一。如果存在多组可能的路线，输出任意一组即可。连续测试用例的输出之间用一个空行分隔。

## 题目分析

### 问题本质

这是一个**双人路径规划**问题，需要在网格地图上为 $\texttt{Jack}$ 和 $\texttt{Jill}$ 分别找到从各自起点到各自终点的路径，使得**两人在任何时刻的欧几里得距离的最小值**最大化。

**关键约束条件**：

1. 网格大小 $n \leq 30$ ，时间最多约 $60$ （曼哈顿距离最大为 $2n-2$ ）
2. 两人必须同时出发，同时每分钟走一步
3. 需要计算的是**位置之间的欧几里得距离**，不是曼哈顿距离
4. 某些位置对特定人物不可通行
5. 到达终点后可以停留在终点位置

### 解题思路

#### 核心思想：二分答案 + $\texttt{BFS}$ 验证

1. **二分搜索最小距离**  
   由于距离是连续的实数，直接搜索不可行。观察到如果存在一个最小距离 $D$ ，那么对于任意 $d < D$ ，也应该存在满足最小距离 $d$ 的路径对。因此问题具有单调性，可以使用二分搜索。

2. **使用平方距离避免浮点数运算**  
   为了精度和效率，我们使用**平方距离**进行二分搜索，只在最后输出时开方计算实际距离。  
   最大可能的平方距离为 $(n-1)^2 + (n-1)^2 = 2(n-1)^2$ ，所以二分范围是 $[0, 2n^2]$ 。

3. **$\texttt{BFS}$ 验证**  
   对于给定的平方距离阈值 $limit$ ，使用 $\texttt{BFS}$ 在状态空间（$\texttt{Jack}$ 位置, $\texttt{Jill}$ 位置）中搜索：
   - 状态转移：两人各自可向四个方向移动，或停留在终点
   - 约束条件：任意时刻两人的平方距离 $\geq limit$
   - 目标状态：两人都到达各自的学校

4. **路径记录**  
   在 $\texttt{BFS}$ 过程中直接记录路径字符串，避免后续重建。

### 算法设计

#### 状态表示

状态可以用四元组 $(x_1, y_1, x_2, y_2)$ 表示，其中 $(x_1, y_1)$ 是 $\texttt{Jack}$ 的位置， $(x_2, y_2)$ 是 $\texttt{Jill}$ 的位置。

#### 状态空间大小

状态数为 $n^4 \leq 30^4 = 810,000$ ，对于每个状态，我们需要考虑最多 $4 \times 4 = 16$ 种移动组合（每人 $4$ 个方向），因此每次 $\texttt{BFS}$ 的最坏时间复杂度约为 $13$ 百万次操作。

#### 预计算优化

由于需要频繁计算两点间的平方距离，我们可以预先计算所有点对之间的平方距离，存储在一个四维数组 $dist[a][b][c][d]$ 中，其中 $dist[a][b][c][d] = (a-c)^2 + (b-d)^2$ 。这样在 $\texttt{BFS}$ 验证时可以直接查表，避免重复计算。

#### 二分搜索过程

```cpp
int left = 0, right = 2 * n * n, best = 0;
while (left <= right) {
    limit = (left + right) / 2;
    if (bfs()) {  // 验证是否存在满足最小平方距离limit的路径
        best = limit;  // 更新最优解
        left = limit + 1;  // 尝试更大的距离
    } else {
        right = limit - 1;  // 减小距离阈值
    }
}
```

#### $\texttt{BFS}$ 验证算法

```cpp
bool bfs() {
    // 检查初始状态是否满足距离要求
    if (dist[jackStart][jillStart] < limit) return false;
    
    初始化visited数组为0;
    创建队列q;
    将初始状态加入队列;
    标记初始状态为已访问;
    
    while (!q.empty()) {
        取出队首状态u;
        
        // 检查是否到达终点
        if (u.Jack到达学校且u.Jill到达学校) {
            记录最终状态;
            return true;
        }
        
        // 生成Jack的可能移动
        for Jack的四个方向 {
            if (Jack已到达学校) 停留在原地;
            else 计算新位置，检查边界和障碍;
            
            // 生成Jill的可能移动  
            for Jill的四个方向 {
                if (Jill已到达学校) 停留在原地;
                else 计算新位置，检查边界和障碍;
                
                // 检查距离条件
                if (新位置的平方距离 >= limit && 新状态未访问) {
                    标记为已访问;
                    更新路径字符串;
                    加入队列;
                }
            }
        }
    }
    return false;  // 未找到满足条件的路径
}
```

### 复杂度分析

- **预计算**： $O(MAXN^4)$ ，其中 $MAXN=32$ ，约 $32^4 = 1,048,576$ 次计算
- **每次 BFS**： $O(n^4 \times 16)$ ，最坏约 $30^4 \times 16 = 12,960,000$ 次操作
- **二分次数**： $O(\log(2n^2)) \approx O(\log n)$ ，约 $10-15$ 次
- **总时间复杂度**：约 $2 \times 10^8$ 次操作，在合理优化下可以通过
- **空间复杂度**： $O(n^4)$ 用于存储访问标记，约 $30^4 \times 4 \text{字节} \approx 8.1 \text{MB}$

### 关键细节

1. **停留处理**：当一人到达学校后，他可以停留在那里等待另一人到达。这是必要的，因为两人可能需要不同的时间到达终点。

2. **障碍处理**：$\texttt{Jack}$ 不能进入 $\texttt{Jill}$ 的家和学校（ `'h'` 和 `'s'` ），$\texttt{Jill}$ 不能进入 $\texttt{Jack}$ 的家和学校（ `'H'` 和 `'S'` ），两人都不能进入 `'*'` 区域。

3. **路径输出**：在 $\texttt{BFS}$ 中直接构建路径字符串，当找到解时路径已经完整记录。

4. **浮点数精度**：使用平方距离进行二分，只在最后输出时计算一次平方根，避免浮点数误差累积。

### 示例分析

#### 样例输入

```
10
..........
...H......
.**...s...
.**.......
.**.......
.**.......
.**.......
.**.......
...S..h..*
..........
```

#### 算法执行过程

1. 读取地图，识别 $\texttt{Jack}$ 的家在 $(1, 3)$ ，学校在 $(8, 3)$ ；$\texttt{Jill}$ 的家在 $(8, 6)$ ，学校在 $(2, 6)$ 。
2. 预计算所有点对的平方距离。
3. 二分搜索：
   - 尝试 $limit = 45$ ，$\texttt{BFS}$ 找到路径，更新 $best = 45$
   - 尝试 $limit = 68$ ，$\texttt{BFS}$ 找到路径，更新 $best = 68$
   - 尝试 $limit = 79$ ，$\texttt{BFS}$ 未找到路径
   - ... 继续二分直到找到最大可行的 $limit$
4. 最终 $best = 45$ ，计算 $\sqrt{45} \approx 6.71$ ，输出结果。

#### 样例输出

```
6.71
WWWSSSSSSSEEE
NEEENNNNNWWW
```

解释：
- $\texttt{Jack}$ 的路线：向西 $3$ 步，向南 $8$ 步，向东 $3$ 步
- $\texttt{Jill}$ 的路线：向北 $1$ 步，向东 $3$ 步，向北 $5$ 步，向西 $3$ 步

### 实现注意事项

1. **数组大小**：由于 $n \leq 30$ ，但为了安全，数组应稍微开大一点（如 $32$ ）。
2. **初始化**：每个测试用例需要清空访问数组。
3. **输出格式**：连续测试用例之间需要空行，距离保留两位小数。
4. **路径对称性**：如果存在多组解，任意输出一组即可。

## 总结

本题是一个典型的**双人路径规划**问题，通过**二分答案**和**$\texttt{BFS}$ 验证**的结合，可以有效解决。关键点在于：

1. 使用**平方距离**进行二分搜索，避免浮点数精度问题
2. **预计算**所有点对的平方距离，提高查询效率
3. 在 $\texttt{BFS}$ 中直接记录路径，避免后续重建
4. 正确处理**停留**情况，允许先到达终点的人等待

该算法在 $n \leq 30$ 的范围内是可行的，时间复杂度约为 $2 \times 10^8$ 次操作，在实际评测中表现良好。

```cpp
// Jack and Jill

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 方向数组：N, E, S, W
const int MAXN = 32;
const int dx[] = {-1, 0, 1, 0}, dy[] = {0, 1, 0, -1};
const char dirChar[] = {'N', 'E', 'S', 'W'};

struct Point {
    int x, y;
    Point() : x(0), y(0) {}
    Point(int x, int y) : x(x), y(y) {}
} jackStart, jackEnd, jillStart, jillEnd;

struct State {
    int x1, y1, x2, y2;
    string s1, s2;
} last;

string g[MAXN];
int visited[MAXN][MAXN][MAXN][MAXN], dist[MAXN][MAXN][MAXN][MAXN];
int n, limit;

bool bfs() {
    if (dist[jackStart.x][jackStart.y][jillStart.x][jillStart.y] < limit) return false;
    memset(visited, 0, sizeof visited);
    queue<State> q;
    q.push({jackStart.x, jackStart.y, jillStart.x, jillStart.y, "", ""});
    visited[jackStart.x][jackStart.y][jillStart.x][jillStart.y] = 1;
    while (!q.empty()) {
        State u = q.front(); q.pop();
        if (u.x1 == jackEnd.x && u.y1 == jackEnd.y && u.x2 == jillEnd.x && u.y2 == jillEnd.y) {
            last = u;
            return true;
        }
        int d1, d2;
        for (int i = 0; i < 4; i++) {
            int nx1, ny1;
            if (u.x1 == jackEnd.x && u.y1 == jackEnd.y) nx1 = u.x1, ny1 = u.y1, d1 = -1;
            else {
                nx1 = u.x1 + dx[i], ny1 = u.y1 + dy[i];
                if (nx1 < 0 || nx1 >= n || ny1 < 0 || ny1 >= n) continue;
                if (g[nx1][ny1] == '*' || g[nx1][ny1] == 'h' || g[nx1][ny1] == 's') continue;
                d1 = i;
            }
            for (int j = 0; j < 4; j++) {
                int nx2, ny2;
                if (u.x2 == jillEnd.x && u.y2 == jillEnd.y) nx2 = u.x2, ny2 = u.y2, d2 = -1;
                else {
                    nx2 = u.x2 + dx[j], ny2 = u.y2 + dy[j];
                    if (nx2 < 0 || nx2 >= n || ny2 < 0 || ny2 >= n) continue;
                    if (g[nx2][ny2] == '*' || g[nx2][ny2] == 'H' || g[nx2][ny2] == 'S') continue;
                    d2 = j;
                }
                if (dist[nx1][ny1][nx2][ny2] >= limit && !visited[nx1][ny1][nx2][ny2]) {
                    visited[nx1][ny1][nx2][ny2] = 1;
                    string ns1 = u.s1, ns2 = u.s2;
                    if (d1 >= 0) ns1 += dirChar[d1];
                    if (d2 >= 0) ns2 += dirChar[d2];
                    q.push({nx1, ny1, nx2, ny2, ns1, ns2});
                }
            }
        }
    }
    return false;
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    bool firstCase = true;
    // 预计算平方距离表
    for (int a = 0; a < MAXN; a++)
        for (int b = 0; b < MAXN; b++)
            for (int c = 0; c < MAXN; c++)
                for (int d = 0; d < MAXN; d++)
                    dist[a][b][c][d] = (a - c) * (a - c) + (b - d) * (b - d);
    while (cin >> n && n) {
        if (!firstCase) cout << '\n';
        firstCase = false;
        // 读取地图并定位关键点
        for (int i = 0; i < n; ++i) {
            cin >> g[i];
            for (int j = 0; j < n; ++j) {
                if (g[i][j] == 'H') jackStart = Point(i, j);
                else if (g[i][j] == 'S') jackEnd = Point(i, j);
                else if (g[i][j] == 'h') jillStart = Point(i, j);
                else if (g[i][j] == 's') jillEnd = Point(i, j);
            }
        }
        // 二分搜索，最大化最小平方距离
        int left = 0, right = 2 * n * n, best;
        while (left <= right) {
            limit = (left + right) / 2;
            if (bfs()) { best = limit; left = limit + 1; }
            else right = limit - 1;
        }
        // 输出结果
        cout << fixed << setprecision(2) << sqrt(best) << '\n';
        cout << last.s1 << '\n' << last.s2 << '\n';
    }
    return 0;
}
```
