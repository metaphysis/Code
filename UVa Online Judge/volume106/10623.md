## 题目描述

这是一个关于平面分割问题的反向思考题目。通常我们研究$m$个相同类型的图形最多能将平面分割成多少区域，例如：

- $m$ 个圆：$m^2 - m + 2$ 个区域
- $m$ 个椭圆：$2m^2 - 2m + 2$ 个区域  
- $m$ 个三角形：$\frac{m^3 + 12m^2 - 7m + 6}{6}$ 个区域

当多种类型图形混合相交时，最大区域数也不难计算。

本题要求反向思考：给定最大区域数 $N$，求出是由多少个椭圆 ($m$)、圆 ($n$) 和三角形 ($p$) 产生的。

### 输入格式
- 输入包含不超过 $300$ 行
- 每行一个 $32$ 位无符号整数 $N$，表示最大区域数
- 输入以 $1$ 结束（实际测试用例以 $-1$ 结束）

### 输出格式
对于每个 $N$：
- 第一行输出 `Case X:`（ $X$ 为序号）
- 之后每行输出三个整数 $m\ n\ p$，表示一个有效组合
- 多个解按 $m$ 升序，$m$ 相同时按 $n$ 升序排列
- 若无解，输出 `Impossible.`

### 约束条件
- $0 \leq m < 100$
- $0 \leq n < 20000$
- $0 \leq p < 100$

### 示例
输入：
```
20
10
-1
```
输出：
```
Case 1:
0 0 3
0 1 2
1 0 2
1 3 0
Case 2:
Impossible.
```

## 题目分析

### 1. 正向问题：混合图形的最大区域数公式

首先需要推导出 $m$ 个椭圆、$n$ 个圆和 $p$ 个三角形混合相交时，最多能产生的区域数公式。

#### 已知的独立公式：
- **圆**：$R_{\text{circle}}(n) = n^2 - n + 2$
- **椭圆**：$R_{\text{ellipse}}(m) = 2m^2 - 2m + 2$
- **三角形**：$R_{\text{triangle}}(p) = \frac{p^3 + 12p^2 - 7p + 6}{6}$

#### 混合相交公式推导：
通过几何分析和测试数据验证，混合图形的区域数公式为：
$$F(m, n, p) = 2m^2 - 2m + n^2 - n + 3p^2 - 3p + 6mp + 4mn + 6np + 2$$

**公式验证**：
1. 只有圆($m=0, p=0$)：
   $$F(0, n, 0) = n^2 - n + 2 \quad \checkmark$$
   
2. 只有椭圆($n=0, p=0$)：
   $$F(m, 0, 0) = 2m^2 - 2m + 2 \quad \checkmark$$
   
3. 只有三角形($m=0, n=0$)：
   $$F(0, 0, p) = 3p^2 - 3p + 2$$
   验证 $p=1,2,3$：
   - $p=1$: $3-3+2=2$ ✓
   - $p=2$: $12-6+2=8$ ✓  
   - $p=3$: $27-9+2=20$ ✓

4. 混合情况 ($m=1, n=3, p=0$)：
   $$F(1, 3, 0) = 2-2 + 9-3 + 0 + 4\times3 + 0 + 2 = 0+6+0+12+2=20 \quad \checkmark$$

### 2. 反向问题：已知$N$求$(m, n, p)$

给定 $N$，需要求解方程：
$$2m^2 - 2m + n^2 - n + 3p^2 - 3p + 6mp + 4mn + 6np + 2 = N$$

#### 解题思路：
直接枚举三个变量会超时，因为$n$的范围很大($0 \leq n < 20000$)。但观察到：
1. $m$ 和 $p$ 的范围很小($<100$)
2. 方程可以整理为关于 $n$ 的二次方程

将方程按 $n$ 整理：
$$n^2 + (4m + 6p - 1)n + (2m^2 - 2m + 3p^2 - 3p + 6mp + 2 - N) = 0$$

对于每一对 $(m, p)$，这是一个关于 $n$ 的一元二次方程：
$$An^2 + Bn + C = 0$$
其中：
- $A = 1$
- $B = 4m + 6p - 1$
- $C = 2m^2 - 2m + 3p^2 - 3p + 6mp + 2 - N$

#### 算法步骤：
1. 枚举所有可能的 $m$($0$到$99$) 和 $p$($0$到$99$)
2. 对于每对 $(m, p)$：
   - 计算判别式 $D = B^2 - 4AC$
   - 若 $D < 0$ 或 $D$ 不是完全平方数，跳过
   - 计算 $n = \frac{-B \pm \sqrt{D}}{2}$
   - 若 $n$ 为整数且在 $[0, 20000)$ 范围内，则 $(m, n, p)$ 是一个有效解
3. 收集所有解，按 $m$ 升序、$m$ 相同时按 $n$ 升序排序
4. 按要求格式输出

#### 时间复杂度：
- 枚举 $m$ 和 $p$：$100 \times 100 = 10000$次
- 每次计算 $O(1)$
- 总复杂度 $O(10^4)$，非常高效

#### 特殊情况：
- 当 $N = 1$ 时，显然有解 $(0, 0, 0)$
- 根据实际测试，输入以 $-1$ 结束

## 代码实现

```cpp
// Thinking Backward
// UVa ID: 10623
// Verdict: Accepted
// Submission Date: 2025-12-03
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 计算区域数的函数
long long computeRegions(long long m, long long n, long long p) {
    return 2 * m * m - 2 * m + n * n - n + 3 * p * p - 3 * p + 6 * m * p + 4 * m * n + 6 * n * p + 2;
}

int main() {
    unsigned int N;
    int caseNo = 1;
    while (cin >> N && N != -1) {
        cout << "Case " << caseNo++ << ":\n";
        if (N == 1) {
            cout << "0 0 0\n";
            continue;
        }
        vector<tuple<int, int, int>> solutions;
        // 枚举m和p
        for (int m = 0; m < 100; ++m)
            for (int p = 0; p < 100; ++p) {
                // 二次方程系数
                // n² + (4m+6p-1)n + (2m²-2m+3p²-3p+6mp+2-N) = 0
                long long A = 1;
                long long B = 4 * m + 6 * p - 1;
                long long C = 2LL * m * m - 2 * m + 3LL * p * p - 3 * p + 6LL * m * p + 2 - N;
                // 判别式
                long long discriminant = B * B - 4 * A * C;
                if (discriminant < 0) continue;
                // 求平方根
                long long sqrt_disc = sqrt(discriminant);
                if (sqrt_disc * sqrt_disc != discriminant) continue;
                // 解1: n = (-B + sqrt_disc) / 2
                if ((-B + sqrt_disc) % 2 == 0) {
                    long long n = (-B + sqrt_disc) / 2;
                    if (n >= 0 && n < 20000)
                        solutions.push_back(make_tuple(m, n, p));
                }
            }
        // 排序：按m升序，然后按n升序
        sort(solutions.begin(), solutions.end());
        if (solutions.empty()) cout << "Impossible.\n";
        else {
            for (const auto& sol : solutions)
                cout << get<0>(sol) << ' ' << get<1>(sol) << ' ' << get<2>(sol) << '\n';
        }
    }
    return 0;
}
```

## 关键点总结

1. **公式推导**：混合图形的区域数公式是关键，通过验证已知数据确保正确性
2. **算法优化**：将三重循环优化为二重循环+解方程，显著降低时间复杂度
3. **边界处理**：注意 $N=1$ 的特殊情况，以及 $n$ 的范围限制
4. **实现细节**：使用 `long long` 防止溢出，检查判别式是否为完全平方数
5. **格式要求**：严格按照题目要求的输出格式，包括排序顺序

本题展示了如何将数学推导与算法设计结合，通过数学变换将看似复杂的枚举问题转化为高效的二次方程求解问题。
