[UVa 10627 Infinite Race](https://blog.csdn.net/metaphysis/article/details/155916523)

## 题目描述

有一条长度为 $L$ 的无摩擦跑道 $AB$ ，两端分别是 $A$ 和 $B$ 。两名运动员分别从两端出发：

- **运动员 $1$** 从 $A$ 出发，速度恒为 $u$ 。
- **运动员 $2$** 从 $B$ 出发，速度恒为 $v$ 。

两人到达另一端时立即掉头（不计掉头时间），并持续无限比赛。在比赛过程中，他们会在途中相遇（迎面相遇或超越时），也可能在端点相遇。给定比赛时间 $t$ ，求在时间 $t$ 内他们相遇的总次数（包括途中相遇和端点相遇）。

### 输入格式

每个测试用例包含四个 $32$ 位有符号非负整数：
$L$ $u$ $v$ $t$
其中 $L \neq 0$ 。输入以一行 `0 0 0 0` 结束（不处理）。输入文件共有 $10018$ 行数据。

### 输出格式

对每个测试用例，输出相遇次数。

### 样例输入
```
10 5 5 4
10 5 10 4
10 10 10 4
0 0 0 0
```

### 样例输出
```
2
3
4
```

## 题目分析

### 问题本质

这是一个典型的相遇问题，但有以下特殊之处：

1. **无限往返运动**：运动员到达端点后立即掉头继续运动。
2. **多种相遇方式**：包括迎面相遇、同向超越、端点相遇。
3. **无限时间内的有限时间统计**：需要计算在给定时间 $t$ 内的总相遇次数。

### 关键观察

1. **相对运动视角**：将两个运动员的运动分解为相对运动。
2. **两种相遇模式**：
   - **迎面相遇**：当两人相向而行时相遇。
   - **同向超越**：当速度较快的运动员追上速度较慢的运动员时。
3. **端点相遇的特殊性**：在端点相遇同时满足两种相遇模式的条件，需要特殊处理。

### 数学模型推导

#### 1. 迎面相遇的条件

设第 $k$ 次迎面相遇的时间为 $t_k$ ，则有：
$$
(u + v) \cdot t_k = (2k + 1) \cdot L
$$
其中 $k = 0, 1, 2, \ldots$

推导：第一次迎面相遇发生在相对运动距离为 $L$ 时，之后每次迎面相遇需要相对运动 $2L$ 的距离。

在时间 $t$ 内，满足条件的 $k$ 的最大值为：
$$
k_{\max} = \left\lfloor \frac{(u+v) \cdot t - L}{2L} \right\rfloor
$$
但更好的表达方式是直接计算次数：
$$
\text{迎面相遇次数} = \left\lfloor \frac{(u+v) \cdot t + L}{2L} \right\rfloor
$$

#### 2. 同向超越的条件

假设 $u \ge v$ （速度较大者在前或在后都可能发生超越）。设第 $k$ 次同向超越的时间为 $s_k$ ，则有：
$$
(u - v) \cdot s_k = (2k + 1) \cdot L
$$
其中 $k = 0, 1, 2, \ldots$

在时间 $t$ 内，同向超越次数为：
$$
\text{同向超越次数} = \left\lfloor \frac{(u-v) \cdot t + L}{2L} \right\rfloor
$$

#### 3. 重复计算的端点相遇

当两个运动员在端点相遇时，这个时间点同时满足：
$$
(u+v) \cdot t = (2k_1+1) \cdot L \quad \text{和} \quad (u-v) \cdot t = (2k_2+1) \cdot L
$$
这意味着端点相遇被计算了两次（一次作为迎面相遇，一次作为同向超越），需要减去一次。

端点相遇发生的条件是：
$$
\frac{u-v}{\gcd(u,v)} \text{ 是奇数}
$$
此时需要减去的次数为：
$$
\left\lfloor \frac{\gcd(u,v) \cdot t + L}{2L} \right\rfloor
$$

#### 4. 特殊情况处理

- 当 $u = 0$ 且 $v = 0$ 时，两个运动员都不动，永远不会相遇（除了初始时分别在两端，不算相遇），答案为 $0$ 。
- 当 $u = v$ 时，没有同向超越，只有迎面相遇。此时 $(u-v) = 0$ ，公式依然适用。
- 当 $u < v$ 时，交换 $u$ 和 $v$ ，保证 $u \ge v$ ，公式依然成立。

### 最终公式

总相遇次数为：
$$
\texttt{ans} = \left\lfloor \frac{(u+v) \cdot t + L}{2L} \right\rfloor + \left\lfloor \frac{(u-v) \cdot t + L}{2L} \right\rfloor - \text{重复部分}
$$
其中重复部分为：
$$
\text{重复部分} = 
\begin{cases}
\left\lfloor \frac{\gcd(u,v) \cdot t + L}{2L} \right\rfloor & \text{如果 } \frac{u-v}{\gcd(u,v)} \text{ 是奇数} \\
0 & \text{否则}
\end{cases}
$$

## 解题思路

### 算法步骤

1. **读入数据**：循环读入 $L, u, v, t$ ，直到 $L = 0$ 。
2. **特判零速度**：如果 $u = 0$ 且 $v = 0$ ，输出 $0$ ，继续下一组数据。
3. **确保 $u \ge v$**：如果 $u < v$ ，交换两者的值。
4. **计算迎面相遇次数**：
   $$
   \texttt{ans} = \left\lfloor \frac{(u+v) \cdot t + L}{2L} \right\rfloor
   $$
5. **加上同向超越次数**：
   $$
   \texttt{ans} += \left\lfloor \frac{(u-v) \cdot t + L}{2L} \right\rfloor
   $$
6. **减去重复计算的端点相遇**：
   - 计算 $d = \gcd(u, v)$
   - 如果 $(u-v)/d$ 是奇数，则减去 $\left\lfloor \frac{d \cdot t + L}{2L} \right\rfloor$
7. **输出结果**

### 时间复杂度

- 每组数据只需要 $O(1)$ 时间计算。
- 主要操作是整数运算和一次 $\gcd$ 计算。
- 总时间复杂度为 $O(n \log \min(u,v))$ ，其中 $n$ 是数据组数。

### 空间复杂度

- 只需要常数空间存储变量。

### 注意事项

1. **使用 $64$ 位整数**： $(u+v) \cdot t$ 可能超过 $32$ 位整数范围，需要使用 `long long` 类型。
2. **整数除法**：$\texttt{C++}$ 中的整数除法是向零取整，但公式中的除法是向下取整。由于所有值都是非负整数，直接使用整数除法即可。
3. $\gcd$ **计算**：可以使用 `__gcd` 函数（C++ 标准库）或自己实现。

```cpp
// Infinite Race

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long L, u, v, t;
    while (cin >> L >> u >> v >> t) {
        if (L == 0) break;
        if (u == 0 && v == 0) {
            cout << 0 << endl;
            continue;
        }
        // 确保 u >= v
        if (u < v) swap(u, v);
        long long ans = 0;
        // 迎面相遇次数
        ans += ((u + v) * t + L) / (2 * L);
        // 同向超越次数
        ans += ((u - v) * t + L) / (2 * L);
        // 减去重复计算的端点相遇
        long long d = __gcd(u, v);
        if ((u - v) / d % 2 != 0) ans -= (d * t + L) / (2 * L);
        cout << ans << endl;
    }
    return 0;
}
```

## 总结

本题是一个经典的相遇问题，但加入了往返运动和端点相遇的复杂情况。解题的关键在于：

1. **分离两种相遇模式**：迎面相遇和同向超越。
2. **数学建模**：将相遇时间表示为等差数列的形式。
3. **处理重复计算**：端点相遇同时满足两种模式的条件，需要减去重复计数。

通过数学推导得到简洁的公式，再结合整数运算实现高效的计算。代码实现简洁明了，时间复杂度低，能够快速处理大量输入数据。
