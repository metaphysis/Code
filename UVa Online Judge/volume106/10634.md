[UVa 10634 Say NO to Memorization](https://blog.csdn.net/metaphysis/article/details/154336525)

## 题目描述

给定两个整数 $n$（度数）和 $v$（变量个数），要求计算满足特定条件的多项式项数：

- 如果 $n$ 是偶数，计算 $v$ 元 $n$ 次多项式中**只包含偶数次项**的项数
- 如果 $n$ 是奇数，计算 $v$ 元 $n$ 次多项式中**只包含奇数次项**的项数

多项式的每一项是各变量的幂次乘积，所有变量的指数之和不超过 $n$，且每个变量的指数满足奇偶性要求。

## 输入格式

输入包含最多 $5000$ 行，每行两个整数 $n$ ($0 \leq n \leq 1000$) 和 $v$ ($0 < v \leq 1000$)。输入以 $n = 0$ 且 $v = 0$ 结束。

## 输出格式

对于每组输入，输出一个整数表示满足条件的项数。

## 题目分析

### 数学建模

对于一个 $v$ 元多项式，每个变量的指数可以是 $0$ 到 $n$，但所有变量的指数之和不超过 $n$。我们需要统计满足特定奇偶性条件的项数。

设每个变量的指数为 $e_1, e_2, \ldots, e_v$，则满足：
- $\sum_{i=1}^v e_i \leq n$
- 所有 $e_i$ 的奇偶性与 $n$ 相同（即同为奇数或同为偶数）

### 组合数学推导

使用生成函数和奇偶性过滤的方法，可以得到项数的计算公式：

$$
T = \sum_{k \equiv n \ (\text{mod } 2),\ 0 \leq k \leq v} \binom{v}{k} \binom{\lfloor (n-k)/2 \rfloor + v}{v}
$$

**公式解释**：
- $k$ 表示选择 $k$ 个变量的指数为奇数（当 $n$ 为奇数时）或选择 $k$ 个变量的指数为偶数（当 $n$ 为偶数时）
- $\binom{v}{k}$ 表示从 $v$ 个变量中选择 $k$ 个满足特定奇偶性的方式数
- $\binom{\lfloor (n-k)/2 \rfloor + v}{v}$ 表示在满足奇偶性约束下的非负整数解个数

### 解题思路

#### 方法一：直接计算（存在溢出风险）

直接使用组合数公式计算：

```cpp
long long result = comb(v, k) * comb(m + v, v);
```

其中 $m = \lfloor (n-k)/2 \rfloor$。

**问题**：当 $v$ 较大时（如 $v = 747$），组合数值可能非常大，两个大数相乘会导致中间结果溢出，即使最终答案在 $64$ 位整数范围内。

#### 方法二：预计算组合数表（推荐）

使用动态规划预计算所有可能的组合数值：

$$
C[i][j] = C[i-1][j] + C[i-1][j-1]
$$

其中 $C[i][j]$ 表示组合数 $\binom{i}{j}$。

**优势**：
1. 避免中间计算溢出
2. 查询时间复杂度为 $O(1)$
3. 数学上精确可靠

```cpp
// Say NO to Memorization

#include <bits/stdc++.h>
using namespace std;
const int MAX = 2005; // 最大可能用到的组合数下标
long long combTable[MAX][MAX]; // 组合数表
// 预计算组合数表
void precomputeCombinations() {
    for (int i = 0; i < MAX; i++) {
        combTable[i][0] = combTable[i][i] = 1; // 边界条件
        for (int j = 1; j < i; j++) {
            // 使用组合数递推公式
            combTable[i][j] = combTable[i - 1][j] + combTable[i - 1][j - 1];
        }
    }
}
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    cin.tie(NULL);
    precomputeCombinations(); // 预计算组合数
    int degree, varCount;
    while (cin >> degree >> varCount) {
        if (degree == 0 && varCount == 0) break;
        long long totalTerms = 0;
        int parity = degree % 2; // 奇偶性
        for (int k = parity; k <= varCount; k += 2) {
            int m = (degree - k) / 2; // 计算中间变量
            if (m < 0) continue; // 负值跳过
            // 累加满足条件的项数
            totalTerms += combTable[varCount][k] * combTable[m + varCount][varCount];
        }
        cout << totalTerms << "\n";
    }
    return 0;
}
```
