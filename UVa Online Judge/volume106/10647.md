[UVa 10647 Optimal House Placement](https://blog.csdn.net/metaphysis/article/details/157844168)

## 题目描述

$\texttt{G. Enerous}$ 先生有很多朋友，所有朋友都住在同一条街上。每年圣诞节， $\texttt{Enerous}$ 先生都要给所有朋友送包裹。为了便于送包裹，他决定搬到这条街上住。

当 $\texttt{Enerous}$ 先生拿着一个包裹从一间房子送到另一间房子时，如果两间房子之间的距离为 $x$ ，他会消耗 $x^2$ 单位的能量。如果不拿包裹，能量消耗可忽略。由于包裹很大，他一次只能拿一个包裹，并且他不想在房子外面停留，以免包裹变脏。因此，如果他要把包裹送给某个朋友，他会从自己家出发，朝朋友家方向走，但为了最小化能量消耗，他会在途中经过的每个朋友家停留。

请你告诉他，应该把房子建在街上的哪个位置，才能使送完所有包裹所需的能量最小？

你可以假设对于任何合理的房屋位置（合理的房屋位置是指位于最小坐标和最大坐标之间的任意位置），送完所有包裹所需的能量四舍五入到下一个整数后，可以放入一个有符号 $64$ 位整数中。

**输入格式**

输入包含多个测试用例。每个测试用例的第一行是一个正整数 $n$ $(2 \leq n \leq 10000)$ ，表示 $\texttt{Enerous}$ 先生的朋友数量。接下来 $n$ 行按递增顺序给出每个朋友家的位置，每个位置是一个非负整数 $< 1000000$ 。

输入以 $n = 0$ 结束。

**输出格式**

对于每个测试用例，输出一个浮点数，精确到小数点后三位，表示 $\texttt{Enerous}$ 先生应该放置房屋的位置，以使送完所有包裹所需的能量最小。如果有多个位置都能达到最小能量值，则输出最小的那个位置。

## 题目分析

### 问题理解

本题的核心是找到一个最优的房屋位置 $x$ ，使得将包裹送到所有朋友家所需的总能量最小。关键约束条件包括：

1. 一次只能携带一个包裹
2. 空手移动不消耗能量
3. 从起点到目的地必须经过途中的所有朋友家（即不能跳过中间的朋友家直接到达远处）
4. 能量消耗与移动距离的平方成正比

### 策略分析

由于可以空手移动且不消耗能量， $\texttt{Enerous}$ 先生可以采用**蚂蚁搬家**的策略：

- **对于右侧的朋友** ：假设有 $m$ 个右侧朋友，位置为 $a_1, a_2, \ldots, a_m$ （按距离递增排序）
  1. 先将所有 $m$ 个包裹从起点 $x$ 一个一个搬到最近的朋友家 $a_1$
  2. 然后将剩余的 $m-1$ 个包裹从 $a_1$ 一个一个搬到 $a_2$
  3. 依此类推，直到最后一个包裹送到 $a_m$

- **对于左侧的朋友** ：采用类似的策略，但方向相反

### 数学模型

设朋友位置排序后为 $p_0 \leq p_1 \leq \ldots \leq p_{n-1}$ ，假设 $\texttt{Enerous}$ 的房屋位置 $x$ 在区间 $[p_i, p_{i+1}]$ 内。

#### 左侧能量计算

左侧有 $i+1$ 个朋友（包括 $p_i$ ），采用蚂蚁搬家策略：

- 从 $x$ 送 $i+1$ 个包裹到 $p_i$ ：需要 $(i+1)$ 次往返，能量为 $(i+1) \times (x - p_i)^2$
- 从 $p_i$ 向左继续送包裹的能量是固定的，记为 $leftE[i]$

#### 右侧能量计算

右侧有 $n-i-1$ 个朋友（从 $p_{i+1}$ 开始），采用蚂蚁搬家策略：

- 从 $x$ 送 $n-i-1$ 个包裹到 $p_{i+1}$ ：需要 $(n-i-1)$ 次往返，能量为 $(n-i-1) \times (p_{i+1} - x)^2$
- 从 $p_{i+1}$ 向右继续送包裹的能量是固定的，记为 $rightE[i+1]$

#### 总能量函数

总能量函数为：

$$
E(x) = (i+1)(x - p_i)^2 + (n-i-1)(p_{i+1} - x)^2 + leftE[i] + rightE[i+1]
$$

这是一个关于 $x$ 的二次函数：

$$
E(x) = n \cdot x^2 - 2[(i+1)p_i + (n-i-1)p_{i+1}]x + \text{常数项}
$$

#### 最小值点

二次函数 $E(x) = ax^2 + bx + c$ 的最小值点在 $x = -\frac{b}{2a}$ 处，代入系数得：

$$
x_{\text{opt}} = \frac{(i+1)p_i + (n-i-1)p_{i+1}}{n}
$$

### 算法设计

#### 预处理

1. 计算相邻朋友家距离的平方： $gap[i] = (p_i - p_{i-1})^2$ ，其中 $i = 1, 2, \ldots, n-1$
2. 预处理 $leftE[i]$ ：从位置 $p_i$ 向左送包裹的固定能量
   - $leftE[0] = 0$
   - 递推公式： $leftE[i] = leftE[i-1] + i \times gap[i]$
3. 预处理 $rightE[i]$ ：从位置 $p_i$ 向右送包裹的固定能量
   - $rightE[n-1] = 0$
   - 递推公式： $rightE[i] = rightE[i+1] + (n-i-1) \times gap[i+1]$

#### 候选位置

最优位置只可能出现在以下两种情况：

1. **恰好位于朋友家** ： $x = p_i$ ，能量为 $leftE[i] + rightE[i]$
2. **在两个朋友家之间** ： $x = \frac{(i+1)p_i + (n-i-1)p_{i+1}}{n}$ ，能量按公式计算

#### 算法步骤

1. 读入朋友位置并排序（题目已保证有序）
2. 预处理 $gap$ 、 $leftE$ 、 $rightE$ 数组
3. 遍历所有候选位置，计算能量并记录最小值
4. 输出能量最小的位置（如有多个取最小的位置）

#### 时间复杂度

- 预处理： $O(n)$
- 候选位置检查： $O(n)$
- 总时间复杂度： $O(n)$ ，对于 $n \leq 10000$ 完全可行

#### 空间复杂度

- 需要存储 $p$ 、 $gap$ 、 $leftE$ 、 $rightE$ 数组
- 空间复杂度： $O(n)$

### 边界条件处理

1. 当 $n=1$ 时，直接输出该朋友位置
2. 计算区间内候选位置时，需确保 $x$ 在 $[p_i, p_{i+1}]$ 内（公式计算的点天然在此区间内）
3. 使用 $\texttt{EPS} = 10^{-10}$ 处理浮点数比较误差

### 算法正确性证明

1. **最优策略的正确性** ：蚂蚁搬家策略是最优的，因为：
   - 分段运输比直接运输更节省能量（平方函数的凸性）
   - 必须经过所有中间朋友家的约束使得蚂蚁搬家成为唯一可行策略
2. **候选位置的完备性** ：能量函数在每个区间上是二次函数，最小值点要么在端点（朋友家），要么在区间内部（由公式给出）
3. **递推公式的正确性** ： $leftE$ 和 $rightE$ 的递推正确反映了蚂蚁搬家的能量累加

## 代码实现

```cpp
// Optimal House Placement
// UVa ID: 10647
// Verdict: Accepted
// Submission Date: 2026-02-07
// UVa Run Time: 0.020s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double EPS = 1e-10;
const int MAXN = 10010;

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int n;
    double p[MAXN], gap[MAXN], leftE[MAXN], rightE[MAXN];
    while (scanf("%d", &n) == 1 && n) {
        // 读入位置
        for (int i = 0; i < n; i++) scanf("%lf", &p[i]);
        // 计算相邻两个朋友家需要消耗的能量
        for (int i = 1; i < n; i++) gap[i] = (p[i] - p[i - 1]) * (p[i] - p[i - 1]);
        leftE[0] = 0;
        for (int i = 1; i < n; i++) leftE[i] = leftE[i - 1] + i * gap[i];
        rightE[n - 1] = 0;
        for (int i = n - 2; i >= 0; i--) rightE[i] = rightE[i + 1] + (n - i - 1) * gap[i + 1];
        double bestX = p[0], minE = 1e18, x, E;
        // 从左至右考虑所有可能的最佳候选位置
        for (int i = 0; i < n - 1; i++) {
            int leftCnt = i + 1, rightCnt = n - i - 1;
            x = (leftCnt * p[i] + rightCnt * p[i + 1]) / n;
            E = leftE[i] + rightE[i + 1]
                          + leftCnt * (x - p[i]) * (x - p[i])
                          + rightCnt * (p[i + 1] - x) * (p[i + 1] - x);
            if (E < minE - EPS) {
                minE = E;
                bestX = x;
            }
        }
        printf("%.3f\n", bestX);
    }
    return 0;
}
```

### 样例输入

### 样例输出
```

```

### 样例解释

1. 第一个测试用例：朋友位置为 $1, 2, 3$
   - 最优位置在 $[1, 2]$ 区间内： $x = \frac{(1+1)\times 1 + (3-1-1)\times 2}{3} = \frac{5}{3} \approx 1.667$
   
2. 第二个测试用例：朋友位置为 $1, 2, 4, 5$
   - 最优位置在 $[2, 4]$ 区间内： $x = \frac{(2+1)\times 2 + (4-2-1)\times 4}{4} = \frac{6+4}{4} = 3.000$
   
3. 第三个测试用例：朋友位置为 $0, 1, 2, 999999$
   - 最优位置在 $[2, 999999]$ 区间内： $x = \frac{(2+1)\times 2 + (4-2-1)\times 999999}{4} = \frac{6+999999}{4} = 250001.250$

## 总结

本题通过分析蚂蚁搬家策略，将问题转化为在每个区间上求解二次函数最小值的问题。关键点在于：

1. 认识到最优位置只可能出现在朋友家或两个朋友家之间的特定点
2. 通过预处理 $leftE$ 和 $rightE$ 数组，可以 $O(1)$ 计算每个候选位置的能量
3. 算法时间复杂度为 $O(n)$ ，空间复杂度为 $O(n)$ ，完全满足题目要求
