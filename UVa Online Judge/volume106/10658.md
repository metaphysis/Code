## 题目描述

小鲍勃有 $n$ 个弹珠，他可以将它们排列成一个序列，并按照顺序编号（可以是 $1, 2, 3, \dots, n$ 或 $n, n-1, n-2, \dots, 1$）。之后，他可以将这个序列拆分成若干个子序列，但每个子序列中弹珠的相对顺序必须保持不变。

接下来，他需要将**奇数编号**的弹珠与**偶数编号**的弹珠完全分开。此外，他必须满足以下约束条件：

- 子序列的数量**少于 $4$**（即最多只能使用 $3$ 条序列）；
- 每次操作只能将**一个弹珠**从某条序列的**最右端**移动到另一条序列的**最右端**（目标序列可以为空）。

题目保证可以完成分离任务，要求求出**最少移动次数**。

---

## 输入格式

第一行输入测试用例数 $T < 101$。  
接下来 $T$ 行，每行一个整数 $n < 66$。

---

## 输出格式

对于每个 $n$，输出对应的最少移动次数。

---

## 样例输入
```
2
3
15
```

## 样例输出
```
3
14043
```

---

## 题目分析

这是一个典型的**奇偶分离排序**问题，限制在最多 $3$ 条序列（栈）的情况下，使用最少的“弹出‑压入”操作完成排序。

### 问题转化

我们可以将问题抽象为：

- 初始时所有弹珠在一条序列中；
- 目标是将所有奇数弹珠放到一条序列，所有偶数弹珠放到另一条序列；
- 可以使用 $3$ 条序列进行中转；
- 每次只能移动序列末尾的弹珠。

这实际上是一个**三栈奇偶排序**问题，属于栈排序（$\texttt{Stack Sorting}$）的一个变种。该问题也等价于：**将一座汉诺塔（$\texttt{Tower of Hanoi}$）按照石块编号的奇偶性分离成两座独立塔所需的最少移动次数**（参见 $\texttt{OEIS}$ `A033129` 的注释）。

---

## 解题思路

### 1. 动态规划思路（理论）

我们可以用动态规划来求解：

设 $dp[i][a][b][c]$ 表示处理完前 $i$ 个弹珠，且三条序列末尾的奇偶状态分别为 $a, b, c$ 时的最小移动次数。  
状态编码：$0$ 表示空序列，$1$ 表示末尾是奇数，$2$ 表示末尾是偶数。

转移时，对于第 $i+1$ 个弹珠（奇偶性为 $p = (i+1) \% 2$），尝试将其放到某条序列末尾：

- 如果目标序列为空或末尾奇偶性与当前弹珠相同，则不需要额外移动；
- 如果目标序列非空且末尾奇偶性与当前弹珠不同，则需要 $1$ 次移动。

最终答案为所有合法状态（奇偶分离完成）中的最小值。

### 2. 数学规律

通过小规模数据打表或推导，可以发现该问题的最优解与 **$\texttt{OEIS}$ 序列 `A033129`** 完全一致。

根据 $\texttt{OEIS}$ `A033129` 的官方描述：

> `Base‑2 digits are, in order, the first $n$ terms of the periodic sequence with initial period [1,1,0].`

翻译为：**二进制数字依次是周期序列 $[1,1,0]$ 的前 $n$ 项**。

设数列 $a(n)$ 表示 $\texttt{OEIS}$ `A033129` 的第 $n$ 项（$n$ 从 $0$ 开始），则 $a(n)$ 的二进制表示恰好由周期序列 $[1,1,0]$ 的前 $n$ 位构成。例如：

- $a(1) = 1_2 = 1$
- $a(2) = 11_2 = 3$
- $a(3) = 110_2 = 6$
- $a(4) = 1101_2 = 13$
- $a(5) = 11011_2 = 27$
- $a(6) = 110110_2 = 54$
- $a(7) = 1101101_2 = 109$
- $a(14) = 110110110110110_2 = 14043$

而本题中的答案，经过验证，恰好等于 $a(n-1)$。即对于输入 $n$，最少移动次数为：

$$
ans(n) = a(n-1)
$$

其中 $a(k) = \left\lfloor \dfrac{3 \times 2^{k+1}}{7} \right\rfloor$（根据 $\texttt{OEIS}$ 提供的封闭公式）。

因此，我们可以直接写出本题的封闭形式：

$$
ans(n) = \left\lfloor \frac{3 \times 2^{n}}{7} \right\rfloor
$$

验证：

- $n = 1$：$\lfloor 3 \times 2 / 7 \rfloor = \lfloor 6/7 \rfloor = 0$
- $n = 2$：$\lfloor 3 \times 4 / 7 \rfloor = \lfloor 12/7 \rfloor = 1$
- $n = 3$：$\lfloor 3 \times 8 / 7 \rfloor = \lfloor 24/7 \rfloor = 3$
- $n = 4$：$\lfloor 3 \times 16 / 7 \rfloor = \lfloor 48/7 \rfloor = 6$
- $n = 15$：$\lfloor 3 \times 32768 / 7 \rfloor = \lfloor 98304/7 \rfloor = 14043$

结果与样例完全一致。

## 大数处理

当 $n = 65$ 时，$3 \times 2^{65} = 3 \times 36893488147419103232 = 110680464442257309696$，这个数值超过了 $64$ 位无符号整数的表示范围（最大值为 $18446744073709551615$），因此需要使用 $128$ 位整数类型（`__int128`）来存储中间结果。

---

## 算法实现

利用上述封闭公式，我们只需对每个查询计算 $\left\lfloor \dfrac{3 \times 2^{n}}{7} \right\rfloor$ 即可。使用 `__int128` 来避免溢出。

## 参考代码

```cpp
// reArrange
// UVa ID: 10658

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        __int128 power = (__int128)1 << n;   // 2^n
        __int128 ans = (3 * power) / 7;       // floor(3*2^n / 7)
        unsigned long long result = (unsigned long long)ans;
        cout << result << endl;
    }
    return 0;
}
```

## 总结

本题的答案对应 $\texttt{OEIS}$ 序列 `A033129`，其二进制表示由周期序列 $[1,1,0]$ 的前 $n$ 位构成。通过 $\texttt{OEIS}$ 提供的封闭公式，我们得到简洁解：

$$
ans(n) = \left\lfloor \frac{3 \times 2^{n}}{7} \right\rfloor
$$

其中 $n$ 是题目输入的弹珠数量。  
由于 $n$ 最大为 $65$，$3 \times 2^{n}$ 会超过 $64$ 位整数的范围，因此需要使用 `__int128` 进行中间计算。

这个优美的结果揭示了该问题与**汉诺塔奇偶分离问题**的深刻联系，同时也展示了将实际问题抽象为数列递推后，往往能得到惊人的简洁解。
