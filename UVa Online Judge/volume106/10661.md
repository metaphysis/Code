## 题目描述

透视绘图仪是一种古老的机械装置，由若干木片组成。 有些木片是固定的，有些可以移动，且有些木片会相互重叠。 相互重叠的木片必须放置在不同的高度层级。 给定木片总数和所有重叠的木片对，求建造该机器所需的最小层级数。

**输入格式**  
第一行是测试用例数 $N$ 。  
每个测试用例的第一行有两个整数 $M$ 和 $P$ ：  
- $M$ 表示木片数量，木片用字母 `A`, `B`, `C`, … 表示， $M < 20$ 。  
- $P$ 表示重叠的木片对数。  

接下来 $P$ 行，每行两个字母，表示一对重叠的木片。

**输出格式**  
对每个测试用例，输出一个整数，表示所需的最小层级数。

**示例输入**
```
2
3 2
A C
B C
6 4
A B
C A
C B
F E
```

**示例输出**
```
2
3
```

## 题目分析

### 问题抽象

将每个木片看作图的一个顶点，如果两个木片重叠，则在它们之间连一条无向边。 这样我们得到一个无向图 $G$ 。  
要求给每个顶点分配一个“颜色”（对应层级），使得任意相邻顶点颜色不同，且使用的颜色总数最少。  
这就是经典的**图着色问题（$\texttt{Graph Coloring}$）**，所求的是图的**色数（$\texttt{chromatic number}$）**。

### 数据规模与复杂度

- 顶点数 $M < 20$ ，非常小，允许使用指数级算法。
- 直接暴力尝试所有颜色分配方案是不可行的（ $M^M$ 过大）。
- 由于色数最多为 $M$ ，可以尝试从 $1$ 到 $M$ 枚举颜色数 $k$ ，检查是否能用 $k$ 种颜色完成着色。

---

## 解题思路

### 基本方法：$\texttt{DFS}$ 回溯

对给定的颜色数 $k$ ，使用深度优先搜索（$\texttt{DFS}$）尝试为每个顶点分配颜色。 从第一个顶点开始，依次尝试颜色 $0$ 到 $k-1$ ，若与已着色邻居不冲突，则递归处理下一个顶点；若所有颜色都冲突，则回溯。

### 关键优化

#### 1. 二分搜索颜色数
如果 $k$ 种颜色可行，那么 $k+1$ 种颜色一定可行；如果 $k$ 种颜色不可行，那么 $k-1$ 种颜色一定不可行。  
因此可以对 $k$ 进行**二分搜索**，而不是线性枚举。 将尝试次数从 $O(M)$ 降为 $O(\log M)$ 。

#### 2. 最大团大小作为下界
一个**团（$\texttt{clique}$）** 是图中两两相连的顶点集合，团中所有顶点必须互不相同色，因此**最大团的大小**就是色数的一个下界。  
我们可以先计算最大团大小 $c$ ，然后只需从 $k=c$ 开始尝试，避免从 $1$ 开始的无效尝试。

计算最大团使用经典的 **$\texttt{Bron–Kerbosch}$ 算法**，配合位运算优化，可在 $M \leq 20$ 时快速完成。

#### 3. 顶点处理顺序
优先处理**度大**的顶点（邻居多、约束强），可以更早地暴露冲突，减少搜索树的分支。  
在 $\texttt{DFS}$ 前将顶点按度从大到小排序。

#### 4. 颜色尝试策略
在 $\texttt{DFS}$ 中尝试颜色时，优先尝试**已经使用过的颜色**，这有助于减少实际使用的颜色数，更容易满足 $k$ 的限制。

---

## 算法步骤

1. 读入图，构建邻接表。
2. 计算最大团大小 $c$ （使用 $\texttt{Bron–Kerbosch}$ 算法）。
3. 将顶点按度从大到小排序，确定 $\texttt{DFS}$ 顺序。
4. 从 $k = c$ 到 $M$ 依次尝试，找到第一个可行的 $k$ 即为答案。
   - 对每个 $k$ ，用 $\texttt{DFS}$ 回溯尝试着色：
     - 按排序顺序处理顶点。
     - 对当前顶点，优先尝试已用颜色，再尝试新颜色（不超过 $k$）。
     - 若所有顶点成功着色，则 $k$ 可行。

```cpp
// The Perspectographer
// UVa ID: 10661

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int m;
vector<int> graph[20];
int color[20];
int nodeOrder[20];
int maxCliqueSize;  // 最大团大小，作为颜色数的下界

// 计算最大团大小（Bron–Kerbosch算法）
int maxClique() {
    int maxSize = 0;
    // 使用位掩码表示集合
    vector<int> adjMask(m);
    for (int i = 0; i < m; ++i) {
        int mask = 0;
        for (int v : graph[i]) mask |= (1 << v);
        adjMask[i] = mask;
    }
    
    function<void(int, int, int)> dfsClique = [&](int r, int p, int x) {
        if (p == 0 && x == 0) {
            maxSize = max(maxSize, r);
            return;
        }
        // 选择度最大的顶点作为枢轴
        int u = -1, maxDeg = -1;
        int unionSet = p | x;
        while (unionSet) {
            int v = __builtin_ctz(unionSet);
            int deg = __builtin_popcount(adjMask[v] & p);
            if (deg > maxDeg) {
                maxDeg = deg;
                u = v;
            }
            unionSet &= unionSet - 1;
        }
        
        int candidates = p & ~adjMask[u];
        while (candidates) {
            int v = __builtin_ctz(candidates);
            dfsClique(r + 1, p & adjMask[v], x & adjMask[v]);
            p &= ~(1 << v);
            x |= (1 << v);
            candidates &= candidates - 1;
        }
    };
    
    dfsClique(0, (1 << m) - 1, 0);
    return maxSize;
}

// 检查节点v能否染颜色c
bool canColor(int v, int c) {
    for (int u : graph[v]) if (color[u] == c) return false;
    return true;
}

// 尝试用k种颜色着色
bool dfs(int idx, int k) {
    if (idx == m) return true;
    int v = nodeOrder[idx];
    
    // 剪枝：如果已经用了太多颜色，或者不可能在k种颜色内完成
    int usedColors = 0;
    bool colorUsed[20] = {false};
    for (int i = 0; i < m; ++i) if (color[i] != -1) colorUsed[color[i]] = true;
    for (int i = 0; i < k; ++i) if (colorUsed[i]) usedColors++;
    
    // 如果剩下的节点数 > (k - usedColors) * 某个上界，可以剪枝，但这里简化
    // 优先尝试已用过的颜色（减少颜色数）
    for (int c = 0; c < k; ++c) {
        if (!colorUsed[c] && usedColors >= k) continue;  // 颜色数已达上限
        if (canColor(v, c)) {
            color[v] = c;
            bool newColor = !colorUsed[c];
            if (dfs(idx + 1, k)) return true;
            color[v] = -1;
        }
    }
    return false;
}

// 检查k种颜色是否可行
bool check(int k) {
    memset(color, -1, sizeof(color));
    return dfs(0, k);
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        cin >> m;
        int p;
        cin >> p;
        
        for (int i = 0; i < m; ++i) graph[i].clear();
        
        // 读入图
        while (p--) {
            char a, b;
            cin >> a >> b;
            int u = a - 'A';
            int v = b - 'A';
            graph[u].push_back(v);
            graph[v].push_back(u);
        }
        
        // 计算最大团大小作为下界
        maxCliqueSize = maxClique();
        
        // 按度从大到小排序节点
        int degree[20] = {0};
        for (int i = 0; i < m; ++i) degree[i] = graph[i].size();
        iota(nodeOrder, nodeOrder + m, 0);
        sort(nodeOrder, nodeOrder + m, [&](int a, int b) {
            return degree[a] > degree[b];
        });
        
        // 从最大团大小开始尝试
        int ans = m;
        for (int k = maxCliqueSize; k <= m; ++k) {
            if (check(k)) {
                ans = k;
                break;
            }
        }
        cout << ans << endl;
    }
    return 0;
}
```

## 复杂度分析

- **最大团计算**：$\texttt{Bron–Kerbosch}$ 算法在最坏情况下为 $O(3^{M/3})$ ，但 $M \leq 20$ ，实际很快。
- **着色检查**：$\texttt{DFS}$ 回溯，由于 $M$ 小且剪枝强，实际运行效率高。
- 整体可在线性时间内处理每个测试用例。

## 总结

本题将实际模型转化为图着色问题，通过多种优化策略（最大团下界、顶点排序、颜色尝试顺序）在 $M \leq 20$ 的限制下高效求解。 关键点在于理解**最大团大小是色数的下界**，并利用回溯搜索配合剪枝找到最小色数。
