## 题目分析

### 问题描述

本题要求计算一个指数塔表达式对给定模数 $m$ 取模的结果：

$$
a_1^{a_2^{a_3^{\cdots^{a_N}}}} \bmod m
$$

其中指数运算遵循**从右向左结合**的规则，这与常规的四则运算不同。例如：

- $2^{3^2} = 2^{(3^2)} = 2^9 = 512$，而不是 $(2^3)^2 = 64$

### 输入格式

- 多组测试数据（不超过 $100$ 组）
- 每组数据格式：$M\ N\ a_1\ a_2\ \ldots\ a_N$
- 其中 $2 \leq M \leq 10000$，$1 \leq N \leq 10$，$1 \leq a_i \leq 1000$
- 输入以 `#` 结束

### 输出格式

对于每组数据，输出：
```
Case #k: result
```
其中 $k$ 为测试用例编号，$\texttt{result}$ 为计算结果。

## 算法思路

### 核心挑战

直接计算指数塔的值是不可行的，因为数值会极其巨大（远超计算机表示范围）。必须利用模运算的性质和数论知识来简化计算。

### 关键工具：欧拉定理

欧拉定理指出：若 $\gcd(a, m) = 1$，则
$$
a^{\phi(m)} \equiv 1 \pmod{m}
$$
其中 $\phi(m)$ 是欧拉函数，表示小于 $m$ 且与 $m$ 互质的正整数的个数。

这个定理允许我们对指数进行模 $\phi(m)$ 的化简。

### 降幂公式

对于任意 $a, k, m$，通用的降幂公式为：

- 当 $k < \phi(m)$ 时，直接计算 $a^k \bmod m$
- 当 $k \geq \phi(m)$ 时，$a^k \bmod m = a^{k \bmod \phi(m) + \phi(m)} \bmod m$

这个公式在 $\gcd(a, m) \neq 1$ 时也成立。

### 递归求解策略

定义递归函数 $\texttt{tower}(i, m)$ 表示计算：
$$
a_i^{a_{i+1}^{\cdots^{a_N}}} \bmod m
$$

递归过程：

1. **基准情况**：当 $i = N$（最后一个数），直接返回 $a_N \bmod m$
2. **递归情况**：
   - 计算 $\phi(m)$
   - 递归计算指数部分：$\text{exp\_val} = \texttt{tower}(i+1, \phi(m))$
   - 如果递归返回的指数 $\geq \phi(m)$，则指数加上 $\phi(m)$
   - 使用快速幂计算 $a_i^{\text{exp\_val}} \bmod m$

### 边界情况处理

- 当 $m = 1$ 时，任何数模 $1$ 都是 $0$
- 在快速幂过程中，需要跟踪结果是否 $\geq$ 当前模数，以便在递归中正确判断

## 复杂度分析

- **时间复杂度**：$O(N \log^2 m)$，每次递归需要计算欧拉函数和快速幂
- **空间复杂度**：$O(N)$，递归深度为 $N$

```cpp
// Huge Mod

#include <iostream>
#include <vector>
#include <string>
#include <cmath>
#include <sstream>
using namespace std;

// 计算欧拉函数 phi(n)
int phi(int n) {
    int result = n;
    for (int p = 2; p * p <= n; ++p) {
        if (n % p == 0) {
            while (n % p == 0)
                n /= p;
            result -= result / p;
        }
    }
    if (n > 1)
        result -= result / n;
    return result;
}

// 递归计算指数塔模 m 的值
// 返回 pair(计算结果, 是否 >= mod)
pair<int, bool> tower(const vector<int>& a, int idx, int mod) {
    // 模数为1时，任何数模1都是0，且指数>=1
    if (mod == 1) return make_pair(0, true);
    
    // 基准情况：最后一个数
    if (idx == a.size() - 1) {
        if (a[idx] >= mod) return make_pair(a[idx] % mod, true);
        else return make_pair(a[idx] % mod, false);
    }
    
    // 递归计算指数部分
    int p = phi(mod);
    pair<int, bool> next = tower(a, idx + 1, p);
    int exp_val = next.first;
    bool exp_ge = next.second;
    
    // 如果指数 >= phi(mod)，加上 phi(mod)
    if (exp_ge) exp_val += p;
    
    // 使用快速幂计算 a[idx]^exp_val % mod
    long long result = 1;
    long long base = a[idx];
    long long exp = exp_val;
    bool ge_flag = false;
    
    // 快速幂算法
    while (exp > 0) {
        if (exp & 1) {
            result = result * base;
            if (result >= mod) {
                result %= mod;
                ge_flag = true;
            }
        }
        base = base * base;
        if (base >= mod) {
            base %= mod;
            ge_flag = true;
        }
        exp >>= 1;
    }
    
    // 特殊情况：底数 >= mod 且指数 > 0，则结果 >= mod
    if (!ge_flag && a[idx] >= mod && exp_val > 0) {
        ge_flag = true;
    }
    
    return make_pair(result, ge_flag);
}

int main() {
    string line;
    int case_num = 1;
    
    while (true) {
        getline(cin, line);
        if (line == "#") break;
        
        int m, n;
        vector<int> a;
        
        // 使用 stringstream 解析输入
        stringstream ss(line);
        ss >> m >> n;
        for (int i = 0; i < n; i++) {
            int x;
            ss >> x;
            a.push_back(x);
        }
        
        // 计算并输出结果
        pair<int, bool> res = tower(a, 0, m);
        cout << "Case #" << case_num << ": " << res.first << endl;
        case_num++;
    }
    
    return 0;
}
```

## 总结

本题通过结合欧拉定理和递归思想，巧妙地解决了大数指数塔的模运算问题。关键在于理解并应用降幂公式，将巨大的指数逐步化简到可计算的范围。这种方法不仅高效，而且能够处理极大的指数值，是数论在算法竞赛中的经典应用。
