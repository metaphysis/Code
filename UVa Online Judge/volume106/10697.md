## 题目描述

巴西联邦的所有州以及联邦首都均设有立法、行政和司法三大权力机关的代表机构。在这些机构中工作的雇员都是极其宝贵且重要的专业人员，因此首批消防员将始终由直升机派遣。但由于三大权力机关同等重要，因此决定每个首都的消防站应建在到三大权力机关所在地距离相等的位置。

巴西消防总队司令委托你编写一个程序，确定新建消防站的最佳位置，使其到三大权力机关的距离完全相同。

### 输入格式

输入包含一个整数 $N$ ，随后 $N$ 行，每行表示一个城市中三大权力机关的位置。每个位置由一对浮点数坐标表示，精度为十分位。因此每行包含六个这样的数字。

### 输出格式

对于每个给定的配置，输出一行，表明有多少个可能的位置：

1. 如果只有一个可能位置，则输出： `The equidistant location is (x, y).` ，其中 $(x, y)$ 为该位置的坐标。
2. 如果没有可能位置，则输出： `There is no possible location.`
3. 如果有无穷多个可能位置，则输出： `There is an infinity of possible locations.`

注意：输出中不应出现 `-0.0` 坐标，因此答案 `(-0.0, 1.1)` 应改为 `(0.0, 1.1)` 。

### 样例输入

```
3
0.0 1.0 0.0 3.0 1.0 2.0
0.0 -1.0 0.0 3.0 0.0 2.0
0.0 -1.0 0.0 -1.0 0.0 2.0
```

### 样例输出

```
The equidistant location is (0.0, 2.0).
There is no possible location.
There is an infinity of possible locations.
```

## 题目分析

本题本质上是一个几何问题：给定平面上的三个点，求一个到这三个点距离相等的点（即三角形的外心）。但是需要特别考虑各种边界情况。

### 几何基础

在平面几何中：

1. **三点不共线且互不重合** ：存在唯一的一个点（三角形的外心）到三点的距离相等，这个点是三角形三条垂直平分线的交点。
2. **三点共线但互不重合** ：不存在到三点距离相等的点（除非考虑无穷远点，但题目不要求）。
3. **有两点重合** ：有无数个点满足条件，这些点位于以该点为圆心的任意圆上（题目中视为有无穷多解）。
4. **三点重合** ：同样有无穷多解。

### 解题思路

基于以上几何原理，我们可以按照以下步骤设计算法：

1. **输入处理** ：读取每个测试用例的三个点 $A(x_1, y_1)$ 、 $B(x_2, y_2)$ 、 $C(x_3, y_3)$ 。
2. **特殊情况判断** ：
   - 如果任意两点重合（ $A = B$ 或 $A = C$ 或 $B = C$ ），则输出有无穷多解。
   - 如果三点共线（通过叉积 $(B - A) \times (C - A) = 0$ 判断），则输出无解。
3. **一般情况** ：三点不共线且互不重合，计算三角形的外心。
   - 计算 $AB$ 边的中点 $M_{AB} = \left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$ 。
   - 计算 $AB$ 边的垂直平分线方向向量（即法向量） $v_{AB} = (y_2 - y_1, x_1 - x_2)$ 。
   - 同理计算 $AC$ 边的中点 $M_{AC}$ 和垂直平分线方向向量 $v_{AC}$ 。
   - 求两条垂直平分线的交点，即为外心。直线参数方程形式：
     $$
     \begin{cases}
     P = M_{AB} + t \cdot v_{AB} \\
     P = M_{AC} + s \cdot v_{AC}
     \end{cases}
     $$
     通过解方程得到交点坐标。
4. **输出处理** ：为避免输出 `-0.0` ，对坐标值进行微小调整，当坐标绝对值非常接近 $0$ 时，将其设为 $0.0$ 。

### 浮点数精度处理

由于题目要求输出精度为十分位，但计算过程中会产生浮点数误差，因此：

- 定义误差容忍度 $EPS = 10^{-7}$ 。
- 使用符号函数 `sgn` 判断浮点数是否为零。
- 比较点是否相等时使用 `sgn(x1 - x2) == 0 && sgn(y1 - y2) == 0` 。
- 判断共线时使用 `sgn((B - A).cross(C - A)) == 0` 。

### 算法复杂度

- 时间复杂度：每个测试点 $O(1)$ ，总复杂度 $O(N)$ 。
- 空间复杂度： $O(1)$ 。

```cpp
// Firemen Barracks
// UVa ID: 10697

#include <bits/stdc++.h>
using namespace std;

const double EPS = 1e-7;  // 精度误差

// 符号函数：判断浮点数正负或零
int sgn(double x) {
    if (fabs(x) < EPS) return 0;   // 视为0
    if (x > 0) return 1;           // 正数
    return -1;                     // 负数
}

// 二维点结构体
struct Point {
    double x, y;
    Point(double x = 0.0, double y = 0.0) : x(x), y(y) {}
    
    // 向量运算
    Point operator+(const Point& p) const { return Point(x + p.x, y + p.y); }
    Point operator-(const Point& p) const { return Point(x - p.x, y - p.y); }
    Point operator*(double t) const { return Point(x * t, y * t); }
    Point operator/(double t) const { return Point(x / t, y / t); }
    
    // 点积和叉积
    double dot(const Point& p) const { return x * p.x + y * p.y; }
    double cross(const Point& p) const { return x * p.y - y * p.x; }
    
    // 重载相等运算符，考虑精度误差
    bool operator==(const Point& p) { 
        return sgn(x - p.x) == 0 && sgn(y - p.y) == 0; 
    }
};

// 求两条直线的交点（假设不平行）
Point lineIntersect(Point p1, Point v1, Point p2, Point v2) {
    double t = (p2 - p1).cross(v2) / v1.cross(v2);
    return p1 + v1 * t;
}

int main() {
    int n; 
    cin >> n;
    cout << fixed << setprecision(1);
    
    while (n--) {
        Point a, b, c;
        cin >> a.x >> a.y >> b.x >> b.y >> c.x >> c.y;
        
        // 情况1：有两点重合 → 无穷多解
        if (a == b || a == c || b == c) {
            cout << "There is an infinity of possible locations.\n";
            continue;
        }
        
        // 情况2：三点共线 → 无解
        if (sgn((b - a).cross(c - a)) == 0) {
            cout << "There is no possible location.\n";
            continue;
        }
        
        // 情况3：三点不共线 → 有唯一外心
        // 求ab边的垂直平分线
        Point abMid = (a + b) / 2.0;
        Point abPerp(b.y - a.y, a.x - b.x);  // 法向量（旋转90度）
        
        // 求ac边的垂直平分线
        Point acMid = (a + c) / 2.0;
        Point acPerp(c.y - a.y, a.x - c.x);
        
        // 求两条垂直平分线的交点（外心）
        Point center = lineIntersect(abMid, abPerp, acMid, acPerp);
        
        // 处理输出，避免出现 -0.0
        if (center.x < 0.05 - EPS && center.x > -0.05 + EPS) center.x = 0;
        if (center.y < 0.05 - EPS && center.y > -0.05 + EPS) center.y = 0;
        
        cout << "The equidistant location is (" 
             << center.x << ", " << center.y << ").\n";
    }
    
    return 0;
}
```

## 总结

本题是一个典型的计算几何问题，重点在于理解三角形外心的几何性质，并正确处理各种边界情况。关键点包括：

1. **几何分类** ：明确不同情况下的解的数量。
2. **浮点数精度** ：合理设置误差容忍度，避免因精度问题导致错误判断。
3. **输出格式** ：按要求处理 `-0.0` 问题。
