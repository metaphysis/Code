## 题目分析

### 问题描述

在经典的二进制补码表示中，最高位的权重为 $-2^{k-1}$，其余位的权重为 $2^i$（$i$ 为位置索引）。本题中的 **$\texttt{Fun}$ 数字系统** 是一种扩展，允许任意位为 **$\texttt{negabit}$**（负权重）或 **$\texttt{posibit}$**（正权重）。

具体来说：
- 给定一个长度为 $k$ 的字符串，由字符 `'p'` 和 `'n'` 组成：
  - `'p'` 表示该位是 **$\texttt{posibit}$**，权重为 $+2^i$
  - `'n'` 表示该位是 **$\texttt{negabit}$**，权重为 $-2^i$
- 我们需要找到一个 $k$ 位二进制串（每位为 $0$ 或 $1$），使得该二进制串按给定权重计算的值等于目标整数 $N$
- 如果无法表示，输出 `Impossible`

### 输入格式
- 第一行：测试用例数 $t$ ($0 < t \leq 100$)
- 每个测试用例包含三行：
  1. 整数 $k$ ($1 \leq k \leq 64$)
  2. 长度为 $k$ 的字符串，由 `'p'` 和 `'n'` 组成
  3. 目标整数 $N$ ($-2^{63} \leq N < 2^{63}$)

### 输出格式
- 对于每个测试用例，输出一个 $k$ 位二进制串或 `Impossible`

### 样例分析

**样例输入：**
```
2
3
pnp
6
4
ppmn
10
```

**样例输出：**
```
Impossible
1110
```

对于第一个测试用例：
- $k = 3$，权重模式为 `pnp`
- 权重分别为：$+2^2, -2^1, +2^0$ 即 $+4, -2, +1$
- 需要表示 $N = 6$，但无法找到满足条件的二进制串

对于第二个测试用例：
- $k = 4$，权重模式为 `ppmn`
- 权重分别为：$+2^3, +2^2, -2^1, +2^0$ 即 $+8, +4, -2, +1$
- $1110$ 的计算结果为：$1\times8 + 1\times4 + 1\times(-2) + 0\times1 = 10$，符合要求

## 解题思路

### 贪心构造法

从最低位（$i = 0$）到最高位（$i = k-1$）依次确定每一位的值：

1. **检查当前 $N$ 的奇偶性**：
   - 如果 $N$ 是奇数，当前位必须设为 $1$（因为更高位都是 $2$ 的更高次幂，不会影响最低位）
   - 如果 $N$ 是偶数，当前位设为 $0$

2. **根据当前位的类型调整 $N$**：
   - 如果当前位是 `'p'`（正权重）且设为 $1$：$N = (N - 1) / 2$
   - 如果当前位是 `'n'`（负权重）且设为 $1$：$N = (N + 1) / 2$
   - 如果当前位设为 $0$：$N = N / 2$

3. **最终检查**：
   - 处理完所有位后，如果 $N = 0$，则找到解
   - 否则无解，输出 `Impossible`

### 算法正确性

该算法的核心思想是：通过逐位处理，确保在每一步之后，剩余的值能被更高位正确表示。由于每个位的权重都是 $2$ 的幂次，通过除以 $2$ 的操作，我们将问题规模不断减小，最终检查是否能完全表示目标值。

### 复杂度分析
- 时间复杂度：$O(k)$，每个位处理一次
- 空间复杂度：$O(k)$，存储结果二进制串

```cpp
// The Fun Number System

#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    int t;
    cin >> t;  // 读取测试用例数量
    while (t--) {
        int k;
        string type;
        long long N;
        cin >> k >> type >> N;  // 读取位数、权重类型和目标值
        
        vector<int> bits(k, 0);  // 存储结果的二进制位
        bool possible = true;    // 标记是否可表示
        
        // 从最低位(i=0)到最高位(i=k-1)处理
        for (int i = 0; i < k; i++) {
            if (N % 2 != 0) {    // 当前N为奇数，必须在该位放1
                bits[i] = 1;
                if (type[k - 1 - i] == 'p') {  // 正权重位
                    N = (N - 1) / 2;
                } else {  // 负权重位
                    N = (N + 1) / 2;
                }
            } else {             // 当前N为偶数，该位放0
                bits[i] = 0;
                N = N / 2;
            }
        }
        
        // 检查是否完全表示
        if (N != 0) {
            cout << "Impossible" << endl;
        } else {
            // 从高位到低位输出结果
            for (int i = k - 1; i >= 0; i--) {
                cout << bits[i];
            }
            cout << endl;
        }
    }
    return 0;
}
```

### 代码说明

1. **输入处理**：依次读取测试用例数、每个测试用例的位数 $k$、权重类型字符串和目标值 $N$
2. **位确定过程**：
   - 使用 `bits` 数组存储结果二进制位
   - 通过 `N % 2` 判断当前最低位奇偶性，决定该位取值
   - 根据权重类型调整 $N$ 的值
3. **结果输出**：
   - 如果最终 $N \neq 0$，输出 `Impossible`
   - 否则从高位到低位输出二进制串

**注意**：`type[k - 1 - i]` 是因为输入字符串是从高位到低位排列，而我们的处理顺序是从低位到高位，需要进行索引转换。
