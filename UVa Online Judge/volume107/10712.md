## 题目描述

给定三个非负整数 $N$ ($0 \leq N \leq 999$), $A$, $B$ ($0 \leq A \leq B \leq 2000000000$)，统计在区间 $[A, B]$ 内，有多少个整数的十进制表示包含 $N$ 作为子序列。

**子序列定义**：不需要连续出现，但必须保持相对顺序。例如，数字 $13$ 包含 $3$ 作为子序列，因为可以从 $13$ 中选出数字 $3$。

**示例**：
- 输入：$N = 3$, $A = 3$, $B = 17$
- 输出：$2$（数字 $3$ 和 $13$）

## 题目分析

### 问题难点

1. **大范围统计**：$B$ 最大可达 $2 \times 10^9$，无法直接枚举所有数字
2. **子序列匹配**：需要高效判断数字是否包含目标子序列
3. **边界处理**：需要处理 $N = 0$ 的特殊情况

### 解题思路

本题采用**数位动态规划（数位 $\texttt{DP}$）** 结合**记忆化搜索**的方法，将问题转化为统计 $[0, x]$ 区间内满足条件的数字个数，然后利用前缀和思想计算区间结果。

### 核心算法：数位 $\texttt{DP}$ + 记忆化搜索

#### 状态设计

记忆化数组定义为：
```cpp
int dp[2][12][12][2];  // isTight × currentPos × matchPos × hasStarted
```

四个状态维度：
- `isTight`：是否受到上界限制（$1$ 表示受限，$0$ 表示不受限）
- `currentPos`：当前处理的数字位置（从高位到低位）
- `matchPos`：在目标子序列中的匹配位置
- `hasStarted`：是否已经开始构造非零数字（用于处理前导零）

#### 状态转移

##### 1. 递归终止条件
```cpp
if (currentPos == numLen) return (matchPos == subSeqLen);
```
当处理完所有数位时，检查是否完全匹配目标子序列。

##### 2. 数字枚举与边界控制
```cpp
int upperBound = isTight ? (numberStr[currentPos] - '0') : 9;
for (digit = 0; digit <= upperBound; digit++) {
    if (isTight && digit > (numberStr[currentPos] - '0')) break;
    // ...
}
```
- 如果受到上界限制，当前位只能枚举到上界对应位的数字
- 否则可以枚举 $0$ 到 $9$

##### 3. 子序列匹配逻辑

**基础匹配**：
```cpp
newMatchPos = matchPos;
if (digit == (subSeqStr[newMatchPos] - '0')) 
    newMatchPos++;
```
如果当前数字匹配子序列的对应位置，推进匹配位置。

**$\texttt{KMP}$ 式回退优化**：
```cpp
if (matchPos != subSeqLen && matchPos != 0 && matchPos == newMatchPos) {
    newMatchPos = 0;
    while (digit == (subSeqStr[newMatchPos] - '0')) 
        newMatchPos++;
}
```
当匹配无法推进时，回退到最长可能的前缀匹配位置，避免重复计算。

##### 4. 前导零处理
```cpp
if (hasStarted == 0 && targetSubSeq == 0 && digit == 0) 
    newMatchPos = 0;
```
在前导零阶段且目标子序列为 $0$ 时，重置匹配位置，防止前导零误匹配。

##### 5. 状态更新
```cpp
int newIsTight = (isTight == 1 && digit == (numberStr[currentPos] - '0'));
int newHasStarted = hasStarted || (digit != 0);
result += dfs(newIsTight, currentPos + 1, newMatchPos, newHasStarted);
```
- 新受限状态：只有原状态受限且当前数字等于上界对应位时才继续受限
- 新开始状态：当前数字非零或之前已开始则标记为已开始

### 特殊处理：$N = 0$ 的情况

```cpp
return dfs(1, 0, 0, 0) + (targetSubSeq == 0);
```
当目标子序列为 $0$ 时，额外加上数字 $0$ 本身，因为数字 $0$ 包含子序列 $0$。

### 主函数逻辑

```cpp
int result = countNumbersUpTo(upperBound) - countNumbersUpTo(lowerBound - 1);
```
利用前缀和思想计算区间 $[A, B]$ 的结果。

## 算法正确性分析

### 状态完备性
- `isTight` 确保不超出上界范围
- `currentPos` 跟踪处理进度
- `matchPos` 精确记录子序列匹配状态
- `hasStarted` 正确处理前导零问题

四个状态维度完整描述了所有必要信息，确保无重复无遗漏。

### 时间复杂度
- 状态数：$2 \times 12 \times 12 \times 2 = 576$
- 每个状态最多尝试 $10$ 个数字
- 总操作数约 $5760$ 次，完全满足题目要求

### 边界情况处理
- $A = 0$ 或 $B = 0$：通过 `countNumbersUpTo` 正确处理
- $N = 0$：特殊处理数字 $0$
- 大范围输入：数位DP高效处理

## 总结

通过精巧的状态设计和 $\texttt{KMP}$ 式匹配优化，可以实现了高效的数字子序列统计。数位 $\texttt{DP}$ 将大范围统计问题转化为可控的状态搜索，记忆化避免了重复计算，使得算法在时间和空间上都能满足题目要求。

关键优化点：
1. **状态精简**：用最少的维度描述完整匹配过程
2. **智能回退**：$\texttt{KMP}$ 思想避免重复匹配尝试
3. **前导零处理**：防止零的误匹配
4. **边界完善**：覆盖所有特殊情况

这种解法是数位 $\texttt{DP}$ 问题的经典应用，展示了如何将复杂的匹配问题转化为可管理的状态搜索。

#include <bits/stdc++.h>

char numberStr[12], subSeqStr[12];  // 数字字符串和子序列字符串
int targetSubSeq, numLen, subSeqLen;  // 目标子序列，数字长度，子序列长度
int dp[2][12][12][2];  // 记忆化数组：flag × 位置 × 匹配位置 × 是否开始

// 递归记忆化搜索函数
int dfs(int isTight, int currentPos, int matchPos, int hasStarted) {
    // 递归终止条件：处理完所有数位
    if (currentPos == numLen) return (matchPos == subSeqLen);
    
    // 记忆化检查
    if (dp[isTight][currentPos][matchPos][hasStarted] != -1) 
        return dp[isTight][currentPos][matchPos][hasStarted];

    int newMatchPos, digit, result = 0;
    int upperBound = isTight ? (numberStr[currentPos] - '0') : 9;
    
    // 枚举当前位所有可能的数字
    for (digit = 0; digit <= upperBound; digit++) {
        // 如果受限且当前数字超过上界，跳出循环
        if (isTight && digit > (numberStr[currentPos] - '0')) break;

        newMatchPos = matchPos;
        
        // 尝试匹配子序列
        if (digit == (subSeqStr[newMatchPos] - '0')) 
            newMatchPos++;
        
        // KMP思想：处理匹配失败时的回退
        if (matchPos != subSeqLen && matchPos != 0 && matchPos == newMatchPos) {
            newMatchPos = 0;
            // 寻找最长可能的前缀匹配
            while (digit == (subSeqStr[newMatchPos] - '0')) 
                newMatchPos++;
        }
        
        // 处理前导零情况：如果还在前导零阶段且目标子序列是0且当前位是0
        if (hasStarted == 0 && targetSubSeq == 0 && digit == 0) 
            newMatchPos = 0;
        
        // 递归搜索下一位
        int newIsTight = (isTight == 1 && digit == (numberStr[currentPos] - '0'));
        int newHasStarted = hasStarted || (digit != 0);
        result += dfs(newIsTight, currentPos + 1, newMatchPos, newHasStarted);
    }

    // 记忆化存储结果
    return dp[isTight][currentPos][matchPos][hasStarted] = result;
}

// 统计 [0, x] 范围内包含目标子序列的数字个数
int countNumbersUpTo(int upperBound) {
    if (upperBound < 0) return 0;
    
    // 将数字和子序列转换为字符串
    sprintf(numberStr, "%d", upperBound);
    sprintf(subSeqStr, "%d", targetSubSeq);
    numLen = strlen(numberStr);
    subSeqLen = strlen(subSeqStr);
    
    // 初始化记忆化数组
    memset(dp, -1, sizeof(dp));
    
    // 开始搜索，初始状态：受限、位置0、匹配位置0、未开始
    // 如果目标子序列是0，额外加上数字0本身
    return dfs(1, 0, 0, 0) + (targetSubSeq == 0);
}

int main() {
    int lowerBound, upperBound;
    
    // 处理多组测试数据，直到输入-1 -1 -1
    while (scanf("%d %d %d", &lowerBound, &upperBound, &targetSubSeq) != EOF) {
        if (lowerBound == -1 && upperBound == -1 && targetSubSeq == -1) break;
        
        // 计算区间 [lowerBound, upperBound] 内的结果
        int result = countNumbersUpTo(upperBound) - countNumbersUpTo(lowerBound - 1);
        printf("%d\n", result);
    }
    return 0;
}
