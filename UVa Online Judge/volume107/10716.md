## 题目描述

给定一个由小写字母组成的字符串，你可以通过 **交换相邻的两个字符** 来调整字符串。目标是使用最少的交换次数将字符串变成回文串。如果无法做到，则输出 `Impossible`。

**交换** 的定义是：反转两个相邻字符的顺序。

例如：`"mamad"` 可以通过 $3$ 次交换变成 `"madam"`：

1. 交换 `"ad"` → `"mamda"`
2. 交换 `"md"` → `"madma"`
3. 交换 `"ma"` → `"madam"`

---

## 输入格式

- 第一行：$n$（测试用例数量）
- 接下来 $n$ 行：每行一个长度不超过 $100$ 的小写字母字符串

## 输出格式

- 每个测试用例一行：最少交换次数 或 `Impossible`

---

## 题目分析

### 1. 可行性判断

一个字符串能重排成回文串的条件是：

- 如果长度为偶数：**所有字符的出现次数必须都是偶数**。
- 如果长度为奇数：**恰好有一个字符的出现次数为奇数**，其余均为偶数。

如果不满足这个条件，直接输出 `Impossible`。

---

### 2. 贪心交换策略

我们可以用双指针法从外向内构造回文：

- 左指针 $l$ 从 $0$ 开始，右指针 $r$ 从 $n-1$ 开始。
- 对于每个 $l$，在区间 $[l, r]$ 中寻找与 $s[l]$ 相同的字符位置 $k$：
  - 如果 $k = r$，说明已经匹配，直接 $l++, r--$。
  - 如果 $k$ 在中间，则通过相邻交换将 $s[k]$ 移动到 $s[r]$ 的位置，并累加交换次数 $(r - k)$。
  - 如果 $k = l$，说明这个字符是中心字符（奇数长度情况），此时我们把它与右边相邻字符交换一次，累加一次交换，然后继续匹配（不移动 $l$ 和 $r$，因为中心字符还未匹配）。

---

### 3. 复杂度分析

- 可行性检查：$O(n)$
- 贪心构造：最坏情况下每次寻找匹配需要 $O(n)$，总复杂度 $O(n^2)$
- 由于 $n \leq 100$，完全可行

## 代码实现

```cpp
// Evil Straw Warts Live
// UVa ID: 10716
// Verdict: Accepted
// Submission Date: 2025-10-21
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <vector>

using namespace std;

int minSwapsToPalindrome(string s) {
    int n = s.length();
    vector<int> count(26, 0);
    for (char c : s) {
        count[c - 'a']++;
    }
    // 检查是否可以构成回文
    int oddCount = 0;
    for (int i = 0; i < 26; i++) {
        if (count[i] % 2 != 0) {
            oddCount++;
        }
    }
    if ((n % 2 == 0 && oddCount > 0) || (n % 2 == 1 && oddCount != 1)) {
        return -1;
    }
    int swaps = 0;
    int l = 0, r = n - 1;
    while (l < r) {
        // 在 [l, r] 中寻找与 s[l] 匹配的字符
        int k = r;
        while (k > l && s[k] != s[l]) {
            k--;
        }
        if (k == l) {
            // 没有找到匹配，这个字符应该是中心字符
            // 交换一次，把它向右移动一位
            swap(s[l], s[l + 1]);
            swaps++;
            continue;
        } else {
            // 把 s[k] 移动到 s[r] 的位置
            for (int i = k; i < r; i++) {
                swap(s[i], s[i + 1]);
                swaps++;
            }
            l++;
            r--;
        }
    }
    return swaps;
}
int main() {
    int t;
    cin >> t;
    while (t--) {
        string s;
        cin >> s;
        int result = minSwapsToPalindrome(s);
        if (result == -1) {
            cout << "Impossible" << endl;
        } else {
            cout << result << endl;
        }
    }
    return 0;
}
```

## 总结

本题的关键在于：

1. **回文可行性** 的频次检查
2. **贪心匹配** 从两端向中间构造，每次匹配最远的相同字符
3. **相邻交换次数** 等于字符移动的距离

这种方法保证了最小交换次数，并且时间复杂度在给定约束下是可接受的。
