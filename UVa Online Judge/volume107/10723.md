## 题目描述

在 $\text{2132}$ 年的未来世界，半机械人（$\texttt{Cyborg}$）掌握了基因合成的技术。给定两个半机械人的基因序列（由字母 A 到 X 组成的字符串），需要构造一个新的基因序列，满足：
1. 新序列必须包含两个原序列作为子序列（即保持原序列字符的相对顺序）；
2. 新序列的长度要尽可能短；
3. 在满足最短长度的前提下，统计不同的新序列的数量。

**输入**：第一行是测试用例数 $T$ ($1 \leq T \leq 15$)，每个测试用例包含两行，分别是两个基因字符串（长度不超过 $30$）。

**输出**：对每个测试用例，输出最短长度和不同序列的数量（保证数量小于 $2^{32}$）。

---

## 题目分析

### 问题本质
本题要求的是两个字符串的**最短公共超序列**（$\texttt{Shortest Common Supersequence, SCS}$）及其计数。

设两个字符串为 $s_1$ 和 $s_2$，长度分别为 $n$ 和 $m$。

### 最短长度公式
最短公共超序列的长度公式为：
$$
\text{最短长度} = n + m - \text{LCS长度}
$$
其中 $\text{LCS}$ 是最长公共子序列的长度。

### 动态规划思路
我们可以用动态规划同时计算**最短长度**和**方案数**。

定义：
- $dp\_len[i][j]$：$s_1$ 前 $i$ 个字符与 $s_2$ 前 $j$ 个字符的最短公共超序列长度。
- $dp\_cnt[i][j]$：对应的不同最短公共超序列的数量。

#### 初始化
- 当 $s_2$ 为空时，超序列就是 $s_1$ 的前 $i$ 个字符：
 $$
  dp\_len[i][0] = i,\quad dp\_cnt[i][0] = 1
$$
- 当 $s_1$ 为空时，超序列就是 $s_2$ 的前 $j$ 个字符：
$$
  dp\_len[0][j] = j,\quad dp\_cnt[0][j] = 1
$$
- 两个都为空时：
$$
  dp\_cnt[0][0] = 1
$$

#### 状态转移
1. **当前字符相同**（$s_1[i-1] == s_2[j-1]$）：
   - 该字符在超序列中只需出现一次：
 $$
     dp\_len[i][j] = dp\_len[i-1][j-1] + 1
 $$
   - 方案数继承自去掉这个字符的状态：
 $$
     dp\_cnt[i][j] = dp\_cnt[i-1][j-1]
$$

2. **当前字符不同**（$s_1[i-1] \neq s_2[j-1]$）：
   - 有两种选择：取 $s_1$ 的当前字符或取 $s_2$ 的当前字符。
   - 计算两种选择得到的超序列长度：
$$
     len_1 = dp\_len[i-1][j] + 1,\quad len_2 = dp\_len[i][j-1] + 1
$$
   - 比较 $len_1$ 和 $len_2$：
     - 如果 $len_1 < len_2$：选择 $s_1$ 的字符更优
$$
       dp\_len[i][j] = len_1,\quad dp\_cnt[i][j] = dp\_cnt[i-1][j]
$$
     - 如果 $len_2 < len_1$：选择 $s_2$ 的字符更优
$$
       dp\_len[i][j] = len_2,\quad dp\_cnt[i][j] = dp\_cnt[i][j-1]
$$
     - 如果 $len_1 = len_2$：两种选择都能得到最短长度
$$
       dp\_len[i][j] = len_1,\quad dp\_cnt[i][j] = dp\_cnt[i-1][j] + dp\_cnt[i][j-1]
$$

#### 最终结果
- 最短长度：$dp\_len[n][m]$
- 方案数：$dp\_cnt[n][m]$

---

## 算法复杂度
- 时间复杂度：$O(n \times m)$，其中 $n, m \leq 30$，完全可行。
- 空间复杂度：$O(n \times m)$，可用滚动数组优化，但本题数据规模小，无需优化。

// Cyborg Genes

#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int T;
    cin >> T;
    cin.ignore(); // 忽略换行符
    
    for (int t = 1; t <= T; t++) {
        string s1, s2;
        getline(cin, s1);
        getline(cin, s2);
        
        int n = s1.length();
        int m = s2.length();
        
        // dp_len[i][j] 表示 s1[0..i-1] 和 s2[0..j-1] 的最短公共超序列长度
        vector<vector<int>> dp_len(n + 1, vector<int>(m + 1, 0));
        // dp_cnt[i][j] 表示对应的不同最短公共超序列的数量
        vector<vector<long long>> dp_cnt(n + 1, vector<long long>(m + 1, 0));
        
        // 初始化：当其中一个字符串为空时
        for (int i = 0; i <= n; i++) {
            dp_len[i][0] = i;  // 超序列就是 s1 的前 i 个字符
            dp_cnt[i][0] = 1;  // 只有一种方式
        }
        for (int j = 0; j <= m; j++) {
            dp_len[0][j] = j;  // 超序列就是 s2 的前 j 个字符
            dp_cnt[0][j] = 1;  // 只有一种方式
        }
        
        // 动态规划填表
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (s1[i - 1] == s2[j - 1]) {
                    // 字符相同，只需在超序列中出现一次
                    dp_len[i][j] = dp_len[i - 1][j - 1] + 1;
                    dp_cnt[i][j] = dp_cnt[i - 1][j - 1];
                } else {
                    // 字符不同，比较两种选择
                    int len1 = dp_len[i - 1][j] + 1; // 取 s1 的当前字符
                    int len2 = dp_len[i][j - 1] + 1; // 取 s2 的当前字符
                    
                    if (len1 < len2) {
                        // 取 s1 的字符更优
                        dp_len[i][j] = len1;
                        dp_cnt[i][j] = dp_cnt[i - 1][j];
                    } else if (len2 < len1) {
                        // 取 s2 的字符更优
                        dp_len[i][j] = len2;
                        dp_cnt[i][j] = dp_cnt[i][j - 1];
                    } else {
                        // 两种选择都能得到最短长度，方案数相加
                        dp_len[i][j] = len1;
                        dp_cnt[i][j] = dp_cnt[i - 1][j] + dp_cnt[i][j - 1];
                    }
                }
            }
        }
        
        // 输出结果
        cout << "Case #" << t << ": " << dp_len[n][m] << " " << dp_cnt[n][m] << endl;
    }
    
    return 0;
}
