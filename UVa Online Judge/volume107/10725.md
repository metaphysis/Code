[UVa 10725 Triangular Square](https://blog.csdn.net/metaphysis/article/details/156274436)

## 题目描述

给定一个三角形，要求在其内部放置一个正方形，使得正方形的四个顶点都在三角形的内部或边上，求这个正方形面积的最大值。

输入的第一行是一个整数 $T$（$T < 10000$），表示测试用例的数量。随后 $T$ 行，每行包含三个以空格分隔的整数（每个整数小于 $1000$），表示一个合法三角形的三条边长。

对于每个三角形，输出其内部能够容纳的最大内接正方形的面积。每个输出占一行，结果保留六位小数。

**样例输入**：
```
2
6  6  6
2  2  2
```

**样例输出**：
```
7.754051
0.861561
```

---

## 题目分析

这是一道几何优化问题，需要在三角形内部找到一个面积最大的内接正方形。所谓“内接正方形”是指正方形的一个边在三角形的某一条边上，另外两个顶点分别在三角形的另外两条边上（或延长线上）。需要注意的是，当三角形为钝角三角形时，正方形可能只能贴在最大边上，否则会导致正方形的顶点超出三角形范围。

### 关键几何原理

设三角形 $ABC$ 的三边长分别为 $a$、$b$、$c$，其中 $a$ 为边 $BC$ 的长度，$b$ 为边 $CA$ 的长度，$c$ 为边 $AB$ 的长度。

#### 1. 基本思路
假设我们要将正方形贴在边 $c$（即 $AB$）上。设正方形的边长为 $x$，其底边在 $AB$ 上，两个上顶点分别在 $AC$ 和 $BC$ 上。用 $d_1$ 和 $d_2$ 表示正方形底边将边 $c$ 分成的三段中左右两段的长度（中间段为 $x$），则有：
$$
d_1 + x + d_2 = c
$$
设角 $A$（对边 $a$）的正切为 $\tan A$，角 $B$（对边 $b$）的正切为 $\tan B$。由相似三角形可得：
$$
\frac{x}{d_1} = \tan A, \quad \frac{x}{d_2} = \tan B
$$
即：
$$
d_1 = \frac{x}{\tan A} = x \cdot \cot A, \quad d_2 = \frac{x}{\tan B} = x \cdot \cot B
$$
代入得：
$$
x + x \cdot \cot A + x \cdot \cot B = c
$$
$$
x \cdot (1 + \cot A + \cot B) = c
$$
所以：
$$
x = \frac{c}{1 + \cot A + \cot B}
$$

#### 2. 钝角情况的处理
如果角 $A$ 或角 $B$ 为钝角（即 $\cos A \le 0$ 或 $\cos B \le 0$），则正方形的对应上顶点不会落在该角的邻边上，而是在延长线上，因此该角对应的 $\cot$ 值不应计入分母。在实际计算中，我们可以通过余弦值的正负来判断角是否为锐角：若 $\cos > 0$，则为锐角，需要加入 $\cot$；否则为直角或钝角，不加入（相当于 $\cot = 0$）。

#### 3. 计算步骤
对于给定的三边长 $a$、$b$、$c$：
1. 计算角 $A$ 和角 $B$ 的余弦值：
$$
   \cos A = \frac{b^2 + c^2 - a^2}{2bc}, \quad \cos B = \frac{a^2 + c^2 - b^2}{2ac}
$$
2. 判断 $\cos A$ 和 $\cos B$ 的正负：
   - 若两者均大于 $0$（均为锐角），则
$$
     x = \frac{c}{1 + \cot A + \cot B}
$$
   - 若仅 $\cos A > 0$，则
$$
     x = \frac{c}{1 + \cot A}
$$
   - 若仅 $\cos B > 0$，则
$$
     x = \frac{c}{1 + \cot B}
$$
   - 若两者均不大于 $0$（理论上不会在非退化三角形中发生），则取 $x = c$。
3. 由于我们事先不知道正方形应贴在哪条边上，因此需要尝试所有六种可能的边角对应关系（即每条边作为底边，其余两条边作为邻边），计算对应的正方形边长，取最大值。
4. 最大正方形面积即为 $x_{\text{max}}^2$。

## 解题思路

1. **读取输入**：首先读取测试用例数 $T$，然后循环读取每个三角形的三边长。
2. **定义核心函数**：
   - 函数 `work(a, b, c)`：假设正方形贴在边 $c$ 上，邻边为 $a$ 和 $b$，计算可能的最大正方形边长。
   - 函数 `solve(a, b, c)`：通过六种排列调用 `work`，找到所有可能的最大边长，并返回面积。
3. **处理每个测试用例**：对于每组输入，调用 `solve` 函数计算最大面积，并按照格式输出。
4. **精度控制**：使用 `double` 类型进行计算，输出时保留六位小数。

**算法复杂度**：每个测试用例进行常数次计算，总复杂度为 $O(T)$，满足题目要求。

## 代码实现

```cpp
// Triangular Square
// UVa ID: 10725
// Verdict: Accepted
// Submission Date: 2025-12-25
// UVa Run Time: 0.020s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double EPS = 1e-9;

double work(double a, double b, double c) {
    double cosA = (b * b + c * c - a * a) / (2 * b * c);
    double cosB = (a * a + c * c - b * b) / (2 * a * c);
    if (cosA > EPS && cosB > EPS) {
        double cotA = cosA / sqrt(1 - cosA * cosA);
        double cotB = cosB / sqrt(1 - cosB * cosB);
        return c / (1 + cotA + cotB);
    } else if (cosA > EPS) {
        double cotA = cosA / sqrt(1 - cosA * cosA);
        return c / (1 + cotA);
    } else if (cosB > EPS) {
        double cotB = cosB / sqrt(1 - cosB * cosB);
        return c / (1 + cotB);
    } else {
        return c;
    }
}

double solve(double a, double b, double c) {
    double r = work(a, b, c);
    r = max(r, work(a, c, b));
    r = max(r, work(b, a, c));
    r = max(r, work(b, c, a));
    r = max(r, work(c, a, b));
    r = max(r, work(c, b, a));
    return r * r;
}

int main() {
    int T; cin >> T;
    while (T--) {
        double a, b, c; cin >> a >> b >> c;
        cout << fixed << setprecision(6) << solve(a, b, c) << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于理解正方形内接于三角形的几何条件，并正确处理钝角三角形的情况。通过余弦值的正负自动判断邻角是否为锐角，从而决定是否在分母中加入 $\cot$ 值，这一方法简洁且有效。算法尝试所有可能的底边选择，确保找到全局最优解。代码实现简单，效率高，能够满足题目的大数据量要求。
