## 题目描述

这是一个关于水手与椰子的经典数学故事。 有 $S$ 个水手流落荒岛，他们收集了 $C$ 个椰子。晚上他们决定把椰子藏起来，等第二天早上平分。但到了半夜，第一个水手忍不住去挖出椰子，他发现如果把椰子平分给 $S$ 个人，会多出 $M$ 个椰子（这 $M$ 个椰子分给 $M$ 只猴子）。于是他自己拿走一份（即平分后的一份），把剩下的椰子重新埋好。接着第二个水手也做了同样的事情，第三个、第四个……直到第 $S$ 个水手。当所有水手都偷偷分过一次后，第二天早上他们一起挖出剩下的椰子，发现这次平分后恰好没有多余的椰子给猴子了。

给定水手数 $S$（$1 < S \leq 100$）、猴子数 $M$（$0 \leq M < S$）和一个区间 $[low, high]$（$0 \leq low \leq high \leq 10^8$），你需要计算在这个区间内有多少个可能的初始椰子数 $C$ 能够满足上述过程。

### 输入格式

第一行是测试用例数 $T$（$1 \leq T \leq 15$）。  
接下来 $T$ 行，每行四个整数：$S$ $M$ $low$ $high$。

### 输出格式

对于每个测试用例，输出一行 "Case X: Y"，其中 $X$ 是测试用例编号，$Y$ 是满足条件的 $C$ 的个数。

## 题目分析

### 问题本质

这是一个典型的逆向推理问题。我们需要找到一个初始椰子数 $C$，使得经过 $S$ 次“偷分”操作后，最后剩余的椰子能够被 $S$ 整除（即没有多余的给猴子）。

每次操作的过程是：
1. 当前有 $C_{\text{current}}$ 个椰子。
2. 减去 $M$ 个给猴子：$C_{\text{current}} - M$。
3. 如果 $C_{\text{current}} - M$ 能被 $S$ 整除，则继续。
4. 水手拿走 $\frac{C_{\text{current}} - M}{S}$ 个椰子。
5. 剩下的椰子数为 $(S-1) \times \frac{C_{\text{current}} - M}{S}$。

### 直接模拟的困境

最直观的想法是枚举区间内的每个 $C$，模拟整个过程检查是否有效。但区间长度可达 $10^8$，每个 $C$ 需要 $O(S)$ 次操作，总复杂度约为 $15 \times 10^8 \times 100 = 1.5 \times 10^{11}$，显然会超时。

### 逆向思维

我们可以从最后的状态开始逆向推导。设最后剩余的椰子数为 $X$，根据题意，$X$ 必须能被 $S$ 整除，即 $X = k \times S$（$k$ 为正整数）。

现在考虑最后一次操作（即第 $S$ 个水手的操作）之前的情况。设当时有 $C_{S-1}$ 个椰子，根据操作规则：

1. $C_{S-1} - M$ 能被 $S$ 整除，设商为 $q$，即 $C_{S-1} - M = q \times S$。
2. 水手拿走 $q$ 个椰子。
3. 剩下的椰子数为 $(S-1) \times q = X$。

由此可得：
$$
q = \frac{X}{S-1}
$$
$$
C_{S-1} = q \times S + M = \frac{X}{S-1} \times S + M
$$

注意：这里 $X$ 必须能被 $S-1$ 整除，否则 $q$ 就不是整数，不符合题意。

继续向前推导，设第 $i$ 次操作前的椰子数为 $C_i$，则有递推关系：
$$
C_{i-1} = \frac{C_i}{S-1} \times S + M
$$
且 $C_i$ 必须能被 $S-1$ 整除。

### 算法设计

基于上述分析，我们可以设计算法：

1. 枚举最后的剩余椰子数 $X = k \times S$（$k = 1, 2, 3, \dots$）。
2. 从 $X$ 开始，逆向回推 $S$ 步，得到初始椰子数 $C$。
3. 如果每一步都满足整除条件（$C_i$ 能被 $S-1$ 整除），且最终得到的 $C$ 在 $[low, high]$ 区间内，则计数加一。
4. 当 $C$ 超过 $high$ 时，停止枚举（因为 $k$ 增大会使 $C$ 单调递增）。

### 复杂度分析

由于 $C$ 增长很快（每次回推大约乘以 $\frac{S}{S-1}$），枚举的 $k$ 值不会太多。对于 $S=100$，$\frac{S}{S-1} \approx 1.0101$，经过 $100$ 次回推后，$C$ 大约是 $X$ 的 $e \approx 2.718$ 倍。而 $X$ 从 $S$ 开始增长，当 $C$ 超过 $10^8$ 时，$k$ 大约为 $10^8 / (S \times e) \approx 3.68 \times 10^5$。对于 $S$ 较小的情况，$k$ 会更小。因此总计算量是可接受的。

## 解题思路总结

1. **理解操作过程**：每个水手的操作是固定的“减 $M$、整除 $S$、拿走一份、剩下 $(S-1)$ 倍”。
2. **逆向推导**：从最后的状态（剩余椰子能被 $S$ 整除）开始，逆向回推 $S$ 步。
3. **枚举终止条件**：最后的剩余椰子数为 $k \times S$，枚举 $k$ 直到回推出的初始 $C$ 超过 $high$。
4. **检查条件**：回推的每一步都要满足整除条件，且最终 $C$ 在给定区间内。

## 代码实现

```cpp
// Coco Monkey
// UVa ID: 10726
// Verdict: Accepted
// Submission Date: 2025-12-14
// UVa Run Time: 0.650s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; caseNo++) {
        int S, M, low, high;
        cin >> S >> M >> low >> high;
        int cnt = 0;
        // 枚举最后的剩余椰子数：k * S
        for (int k = 1; ; k++) {
            long long C = k * S; // 最后剩余椰子数
            bool valid = true;
            // 逆向回推 S 步
            for (int i = 0; i < S; i++) {
                // 回推公式：C_prev = S * C / (S-1) + M，且必须整除
                if (C % (S - 1) != 0) {
                    valid = false;
                    break;
                }
                C = C / (S - 1) * S + M;
                // 提前退出：如果已经超过 high，再回推只会更大
                if (C > high) break;
            }
            if (valid && C >= low && C <= high) cnt++;
            // 如果回推后的 C 已经大于 high，再增大 k 只会更大，可以停止
            if (C > high) break;
        }
        cout << "Case " << caseNo << ": " << cnt << endl;
    }
    return 0;
}
```

## 代码说明

- 使用 `long long` 防止计算溢出。
- 变量名采用驼峰命名法。
- 每次回推检查 $C$ 是否能被 $S-1$ 整除，不能则直接判定无效。
- 当回推过程中 $C$ 超过 $high$ 时，可以提前退出循环，因为继续回推只会使 $C$ 更大。
- 外层循环的终止条件是回推出的初始 $C$ 超过 $high$。

## 总结

本题的关键在于逆向思维：从最后的状态出发，逆向推导初始值。这种思路在解决类似“多步操作后满足某条件”的问题中非常有效。通过数学推导得到递推公式，并利用整除条件进行剪枝，可以在可接受的时间内完成计算。

对于 $S$ 接近 $100$、区间上界达到 $10^8$ 的情况，算法依然高效，这得益于 $C$ 的快速增长使得枚举次数有限。
