## 题目描述

$\texttt{MegaFirm}$ 公司创建了一套模式（$\texttt{pattern}$）来帮助其电话客服人员回复客户。一个模式是由单词和占位符组成的短语：

- **单词**：由小写字母组成的字符串
- **占位符**：被尖括号括起来的单词（例如 `<word>`）

一个短语与模式匹配，当且仅当模式中的每个占位符可以被**系统地替换**为一个单词，使得替换后的模式与短语完全相同。这里的"系统地替换"意味着：**所有相同的占位符必须替换为相同的单词**。

给定两个模式，你需要找到一个短语同时匹配这两个模式。如果存在多个匹配短语，输出任意一个即可；如果不存在匹配短语，输出单个减号 `-`。

### 输入格式

- 第一行：测试用例数量 $n$
- 每个测试用例包含两行，每行是一个模式
- 模式长度不超过 $100$ 字符
- 单词最多包含 $16$ 个字符
- 相邻的单词和占位符之间用单个空格分隔

### 输出格式

对于每个测试用例，输出一个匹配两个模式的短语，或者 `-`。

## 题目分析

### 核心问题理解

这个问题本质上是一个**约束满足问题**。我们需要找到满足以下所有条件的短语：

1. **模式内一致性**：在每个模式内部，相同的占位符必须映射到相同的单词
2. **跨模式一致性**：生成的短语必须同时满足两个模式的约束
3. **位置对应**：两个模式对应位置的元素必须兼容

### 关键观察

考虑样例：
```
<a> <c> <c>
<b> ok <b>
```

- 第一个模式要求：位置 $2$ 和位置 $3$ 相同（因为都是 `<c>`）
- 第二个模式要求：位置 $1$ 和位置 $3$ 相同（因为都是 `<b>`），且位置 $2$ 必须是 `"ok"`
- 可能的解：`"ok ok ok"` 满足所有约束

### 难点分析

1. **占位符命名空间隔离**：两个模式使用不同的占位符名称，但它们可能表示相同的语义约束
2. **约束传播**：一个模式中的约束可能通过共享的单词值间接影响另一个模式
3. **循环依赖**：可能存在复杂的约束链需要多次迭代解决

## 解题思路

### 算法设计

我们采用**迭代约束传播**的方法来解决这个问题：

#### 步骤 1：预处理
将两个模式字符串按空格分割成单词/占位符列表，检查长度是否相等。

#### 步骤 2：建立映射表
为每个模式分别维护一个映射表：
- `bindA`：模式 $A$ 中占位符到单词的映射
- `bindB`：模式 $B$ 中占位符到单词的映射

#### 步骤 3：直接约束处理
遍历两个模式的对应位置，处理以下情况：

1. **单词 $\texttt{vs}$ 单词**：必须完全相同，否则无解
2. **占位符 $\texttt{vs}$ 单词**：用单词约束占位符的映射
3. **单词 $\texttt{vs}$ 占位符**：用单词约束占位符的映射
4. **占位符 $\texttt{vs}$ 占位符**：暂时不处理（等待间接约束）

#### 步骤 4：约束传播
通过迭代传播间接约束：
- 如果模式 A 中的占位符 `<x>` 映射到单词 `w`，且模式 B 中的占位符 `<y>` 与 `<x>` 在同一位置，则 `<y>` 也应映射到 `w`
- 反之亦然

#### 步骤 5：验证和生成
1. 使用第一个模式的映射生成候选短语
2. 验证该短语是否匹配第二个模式
3. 对于未约束的占位符，赋予任意值（如 `"x"`）

### 算法正确性证明

该算法能够找到解（如果存在）的原因：

1. **完备性**：通过迭代约束传播，能够发现所有间接约束关系
2. **一致性**：在每一步都检查约束冲突，确保最终解满足所有条件
3. **终止性**：每次迭代至少解决一个占位符的映射，最多 $O(n)$ 次迭代

### 复杂度分析

- 时间复杂度：$O(n^2)$，其中 $n$ 是模式中的单词数量
- 空间复杂度：$O(n)$，用于存储映射表

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPlaceholder(const string& s) {
    return s.length() > 2 && s[0] == '<' && s.back() == '>';
}

vector<string> split(const string& s) {
    vector<string> res;
    stringstream ss(s);
    string token;
    while (ss >> token) {
        res.push_back(token);
    }
    return res;
}

string solve(const string& p1, const string& p2) {
    vector<string> a = split(p1);
    vector<string> b = split(p2);
    if (a.size() != b.size()) return "-";

    int n = a.size();
    
    // 为每个模式分别建立映射
    map<string, string> bindA, bindB;
    
    // 第一遍：处理单词约束
    for (int i = 0; i < n; i++) {
        string s1 = a[i];
        string s2 = b[i];
        bool ph1 = isPlaceholder(s1);
        bool ph2 = isPlaceholder(s2);
        
        if (!ph1 && !ph2) {
            // 两个都是单词，必须相同
            if (s1 != s2) return "-";
        } else if (ph1 && !ph2) {
            // s1是占位符，s2是单词
            if (bindA.count(s1) && bindA[s1] != s2) return "-";
            bindA[s1] = s2;
        } else if (!ph1 && ph2) {
            // s1是单词，s2是占位符
            if (bindB.count(s2) && bindB[s2] != s1) return "-";
            bindB[s2] = s1;
        }
        // 两个都是占位符：暂时没有约束
    }
    
    // 第二遍：传播约束
    bool changed;
    do {
        changed = false;
        for (int i = 0; i < n; i++) {
            string s1 = a[i];
            string s2 = b[i];
            bool ph1 = isPlaceholder(s1);
            bool ph2 = isPlaceholder(s2);
            
            if (ph1 && ph2) {
                // 如果s1已经映射到某个单词
                if (bindA.count(s1) && !bindB.count(s2)) {
                    bindB[s2] = bindA[s1];
                    changed = true;
                }
                // 如果s2已经映射到某个单词
                if (bindB.count(s2) && !bindA.count(s1)) {
                    bindA[s1] = bindB[s2];
                    changed = true;
                }
                // 如果两个都映射了但不同
                if (bindA.count(s1) && bindB.count(s2) && bindA[s1] != bindB[s2]) {
                    return "-";
                }
            }
        }
    } while (changed);
    
    // 生成最终短语（使用第一个模式）
    vector<string> result;
    for (int i = 0; i < n; i++) {
        if (isPlaceholder(a[i])) {
            if (bindA.count(a[i])) {
                result.push_back(bindA[a[i]]);
            } else {
                // 未约束的占位符可以任意赋值，这里用"x"
                result.push_back("x");
            }
        } else {
            result.push_back(a[i]);
        }
    }
    
    // 验证生成的短语是否匹配第二个模式
    for (int i = 0; i < n; i++) {
        if (isPlaceholder(b[i])) {
            if (bindB.count(b[i]) && bindB[b[i]] != result[i]) {
                return "-";
            }
        } else {
            if (b[i] != result[i]) {
                return "-";
            }
        }
    }
    
    // 输出结果
    string output;
    for (int i = 0; i < n; i++) {
        if (i > 0) output += " ";
        output += result[i];
    }
    return output;
}

int main() {
    int n;
    cin >> n;
    cin.ignore();
    for (int i = 0; i < n; i++) {
        string p1, p2;
        getline(cin, p1);
        getline(cin, p2);
        cout << solve(p1, p2) << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于理解占位符映射的**局部一致性**和**全局兼容性**。通过分别维护两个模式的映射表，并采用迭代约束传播的方法，我们能够有效地找到满足所有条件的解。算法的时间复杂度在合理范围内，能够处理题目给定的约束条件。

这种约束传播的方法在解决类似的模式匹配和一致性（$\texttt{unification}$）问题时非常有效，是编译原理和逻辑编程中常用的技术。
