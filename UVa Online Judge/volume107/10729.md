## 题目描述

给定一种用于描述带标签（标签可能重复）的树的文本表示法，语法如下：

```
tree ::= label
tree ::= label ( subtrees )
subtrees ::= tree
subtrees ::= subtrees , tree
label ::= A | B | C | ... | Z
```

即，一棵树可以表示为一个单独的标签（一个大写字母），或者一个标签后跟一个用括号括起来的、逗号分隔的子树有序列表。

为了在纸上绘制这样一棵树，我们需要将每个标签写在纸上，并且满足：
- 一个顶点的子树的标签按逆时针方向排列在该顶点周围。
- 用不相交的线段连接每个顶点与其各子树。
- 保持子树的顺序不变。

换句话说，我们需要绘制树的平面表示，且子树的顺序必须保持，但表示的位置、形状和大小可以任意。

给定两个树的文本表示，判断它们是否等价，即是否存在一种平面绘制方式使得两个树的图形表示完全相同。

**输入格式**
- 第一行一个整数 $t$ 表示测试用例数量。
- 每个测试用例包含两行，每行一个树的文本表示。
- 每行最多 $200$ 个字符，且不含空格。

**输出格式**
- 对每个测试用例，输出一行 `same` 或 `different`。

## 题目分析

这道题的核心是判断两棵树在平面绘制下是否等价。关键点在于：

1. **根节点可变性**：可以从任意节点开始绘制树。这意味着在比较两棵树时，我们需要考虑所有可能的根节点选择。
2. **子树顺序的约束**：
   - 对于**根节点**，其子节点的顺序可以**循环移位**（$\texttt{rotate}$）。例如，子节点顺序 $(A,B,C)$ 与 $(B,C,A)$ 等价，但与 $(A,C,B)$ 不等价。
   - 对于**非根节点**，子节点顺序必须严格保持**逆时针顺序**，不能随意重排。
3. **平面绘制的几何特性**：当选择一个新根节点时，原父节点成为新根的子节点，并且原父节点的子节点顺序需要按照逆时针规则调整。

## 解题思路

### 核心观察

题目等价于：是否存在一种根节点选择，使得第一棵树在允许根节点子节点循环移位的条件下，与第二棵树的结构完全相同？

### 算法设计

基于上述观察，我们可以采用以下策略：

1. **解析第一棵树**：将字符串解析为树结构，记录每个节点的父节点、子节点列表和标签。
2. **枚举所有可能的根节点**：对于第一棵树的每个节点，尝试将其作为新根。
3. **生成等价字符串**：对于每个候选根节点 $x$：
   - 以 $x$ 为根，按照逆时针规则生成树的字符串表示。
   - 特别地，对于 $x$ 的原父节点 $P$，其子节点顺序需要调整：从 $x$ 在原顺序中的下一个开始，到末尾，再从头到 $x$ 的前一个。
   - 对于其他节点，子节点顺序保持不变（排除父节点）。
4. **字符串比较**：将生成的字符串与第二棵树的字符串直接比较。如果相等，则两棵树等价。

### 关键函数

- **`build`**：递归解析字符串，构建树结构，记录父子关系。
- **`dfs`**：深度优先遍历生成子树字符串，排除指定的父节点。
- **`getRotation`**：生成从某个节点看向其子节点方向的子树字符串，保持逆时针顺序。这是算法的核心，正确处理了父节点插入位置和子节点顺序调整。
- **`validate`**：主验证函数，枚举所有可能的根节点，生成字符串并与第二棵树比较。

### 时间复杂度

- 解析树：$O(n)$，其中 $n$ 是字符串长度（≤ $200$）。
- 枚举根节点：最多 $O(n)$ 个节点。
- 生成字符串：每个节点 $O(n)$。
- 总时间复杂度：$O(n^2)$，对于 $n ≤ 200$ 完全可行。

### 空间复杂度

- 存储树结构：$O(n)$。
- 递归深度：$O(n)$。

```cpp
// Treequivalence
// UVa ID: 10729

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 256;
vector<int> g[256];       // 邻接表，存储每个节点的子节点
int parent[MAXN], label[MAXN], cnt;  // 父节点，节点标签，节点计数
string s1, s2;            // 输入的两个字符串

// 递归解析字符串构建树，返回当前节点的索引
int build(int& p, int father) {
    int idx = cnt++;                     // 分配新节点ID
    label[idx] = s1[p++], parent[idx] = father;  // 记录标签和父节点
    if (p < s1.size() && s1[p] == '(') { // 如果有子节点
        p++;                              // 跳过'('
        while (true) {
            int childIdx = build(p, idx); // 递归构建子节点
            g[idx].push_back(childIdx);   // 添加到邻接表
            char c = s1[p];
            if (c == ',' || c == ')') p++; // 跳过分隔符
            if (c == ')') break;          // 子节点列表结束
        }
    }
    return idx;
}

// DFS生成子树字符串，forbidden表示要排除的父节点
string dfs(int u, int forbidden) {
    string self = string(1, label[u]), child;
    for (auto v : g[u])
        if (v != forbidden) {            // 排除父节点
            if (child.size()) child += ',';
            child += dfs(v, u);          // 递归生成子节点字符串
        }
    if (child.size()) return self + '(' + child + ')';  // 有子节点时加括号
    return self;                         // 叶子节点
}

// 生成从节点u看向其子节点child方向的子树字符串（逆时针顺序）
string getRotation(int u, int child) {
    string self = string(1, label[u]), father;
    if (parent[u] != -1) father = getRotation(parent[u], u);  // 递归处理父节点
    vector<string> left, right;          // 存储child左边和右边的子树字符串
    for (auto v : g[u]) {
        string tmp = dfs(v, -1);         // 生成子树完整字符串
        if (v < child) left.push_back(tmp);   // child之前的子节点
        if (v > child) right.push_back(tmp);  // child之后的子节点
    }
    right.push_back(father);             // 父节点放在right末尾
    for (auto s : left) right.push_back(s); // left部分接在最后
    string children;
    for (auto s : right)
        if (s.size()) {
            if (children.size()) children += ',';
            children += s;
        }
    if (children.size()) self = self + '(' + children + ')';  // 拼接结果
    return self;
}

// 验证两棵树是否等价
bool validate() {
    for (int i = 0; i < MAXN; i++) g[i].clear();  // 清空邻接表
    cnt = 0;                     // 重置节点计数
    int idx = 0;
    build(idx, -1);              // 构建第一棵树
    for (int i = 0; i < cnt; i++) {  // 枚举每个节点作为新根
        string self = string(1, label[i]), father;
        if (parent[i] != -1) father = getRotation(parent[i], i);  // 生成父节点方向字符串
        vector<string> children;      // 存储所有子节点（包括可能的父节点）
        for (auto v : g[i]) {
            string tmp = dfs(v, -1);  // 生成子节点字符串
            children.push_back(tmp);
        }
        if (father.size()) children.push_back(father);  // 添加父节点（如果存在）
        if (children.size()) {
            int n = children.size();
            // 尝试所有循环移位顺序（根节点的子节点可以旋转）
            for (int start = 0; start < n; start++) {
                string s3;
                for (int j = 0; j < n; j++) {
                    if (s3.size()) s3 += ',';
                    s3 += children[(start + j) % n];  // 循环移位
                }
                if (s3.size()) s3 = self + '(' + s3 + ')';  // 构造完整字符串
                if (s3 == s2) return true;           // 与第二棵树匹配
            }
        } else if (self == s2) return true;          // 单节点树的情况
    }
    return false;  // 所有可能性都不匹配
}

int main() {
    int T;
    cin >> T;
    while (T--) {
        cin >> s1 >> s2;
        cout << (validate() ? "same" : "different") << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于理解平面绘制中树的等价条件：根节点可变且其子节点顺序可循环移位，而非根节点的子节点顺序必须严格保持逆时针顺序。通过枚举所有可能的根节点，并按照逆时针规则生成字符串进行比较，可以高效解决该问题。算法的时间复杂度为 $O(n^2)$，空间复杂度为 $O(n)$，对于 $n ≤ 200$ 的约束完全可行。
