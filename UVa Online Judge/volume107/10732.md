## 题目翻译

$\texttt{A. Karim}$ 教授正在研究一个测量未知外星物体表面积的项目。 经过大量计算，他发现该物体的表面积为 $(a+b)*(1-a*b)$ ，其中 $a$ 和 $b$ 是与该物体表面积相关的两个参数。 通过一些更先进的实验，他发现了 $N$ 个浮点数，这些数可能是 $a$ 和 $b$ 的值。 从这 $N$ 个数中， 他可以用 $N \choose 2$ 种方式选择两个值分别作为 $a$ 和 $b$ （注意， 选择 $a=2$ , $b=3$ 和 $a=3$ , $b=2$ 被视为相同， 因为 $(a+b)*(1-a*b)$ 等于 $(b+a)*(1-b*a)$ ）。 Karim 需要进行更多昂贵的实验才能找出 $a$ 和 $b$ 的真实值， 但在进行这些实验之前， 他想只保留那些明显的选择： 即使得物体表面积为正（大于零）的选择。 你的工作是帮助 Karim 教授计算有多少种 $N \choose 2$ 选择（即 $a$ 和 $b$ 的值）会导致 $(a+b)*(1-a*b)$ 为正。 请注意， 你的方法必须是高效的（ $O(N^{2})$ 的解法不行）。

## 题目分析

我们需要从 $N$ 个给定的浮点数中， 统计所有无序对 $(a, b)$ （ $a$ 和 $b$ 来自这 $N$ 个数， 索引需不同） 的数量， 使得表达式 $E = (a+b) \times (1 - a \times b) > 0$ 。

一个朴素的解法是枚举所有 $N^2$ 对组合， 判断条件， 时间复杂度为 $O(N^2)$ 。 对于 $N \le 10000$ ， 这显然会超时。 因此， 我们需要一个更高效的方法， 目标复杂度为 $O(N \log N)$ 。

---

## 解题思路

### $1$. 条件转化

表达式 $E > 0$ 等价于两项 $(a+b)$ 和 $(1-ab)$ **同号**。 这分为两种情况：

*   **情况 $1$** : $a + b > 0$ 且 $1 - ab > 0$ (即 $ab < 1$ )。
*   **情况 $2$** : $a + b < 0$ 且 $1 - ab < 0$ (即 $ab > 1$ )。

### $2$. 分情况讨论， 确定 $b$ 的范围

我们固定 $a$ ， 分析 $b$ 需要满足的条件。

**情况 $1$ ( $a+b > 0$ 且 $ab < 1$ )**

*   $a+b > 0$ $\Rightarrow$ $b > -a$。
*   $ab < 1$ $\Rightarrow$ 需要根据 $a$ 的符号讨论：
    *   若 $a > 0$ ， 则 $b < \frac{1}{a}$。
    *   若 $a = 0$ ， 则 $0 < 1$ 恒成立， 无额外约束。
    *   若 $a < 0$ ， 不等式两边除以负数 $a$ 需变号， 得 $b > \frac{1}{a}$。

    综合 $b > -a$ 的条件：
    *   $a > 0$ : $b$ 需满足 $-a < b < \frac{1}{a}$。 注意此时 $\frac{1}{a} > 0 > -a$。
    *   $a = 0$ : $b$ 只需满足 $b > 0$。
    *   $a < 0$ : 需要同时满足 $b > -a$ 和 $b > \frac{1}{a}$。 因为 $a<0$ 时， $-a > 0$ ， $\frac{1}{a} < 0$ ， 所以更强条件是 $b > -a$。

**情况 $2$ ( $a+b < 0$ 且 $ab > 1$ )**

*   $a+b < 0$ $\Rightarrow$ $b < -a$。
*   $ab > 1$ $\Rightarrow$ 根据 $a$ 的符号讨论：
    *   若 $a > 0$ ， 则 $b > \frac{1}{a}$。
    *   若 $a = 0$ ， 则 $ab=0$ 不可能 $>1$ ， 此情况无解。
    *   若 $a < 0$ ， 不等式两边除以负数 $a$ 需变号， 得 $b < \frac{1}{a}$。

    综合 $b < -a$ 的条件：
    *   $a > 0$ : 需要同时满足 $b > \frac{1}{a}$ 和 $b < -a$。 但 $a>0$ 时， $-a < 0$ ， $\frac{1}{a} > 0$ ， 区间 $(\frac{1}{a}, -a)$ 不存在（因为上界小于下界）， 故此情况无解。
    *   $a < 0$ : 需要同时满足 $b < -a$ 和 $b < \frac{1}{a}$。 因为 $a<0$ 时， $-a > 0$ ， $\frac{1}{a} < 0$ ， 所以更强条件是 $b < \frac{1}{a}$。

### $3$. 总结有效情况

将以上分析汇总， 对于每个固定的 $a$ ， 合法的 $b$ 需满足：

$1$.  **当 $a > 0$ 时** : 仅来自情况 $1$， $b$ 在区间 $(-a, \frac{1}{a})$ 内。
$2$.  **当 $a = 0$ 时** : 仅来自情况 $1$， $b > 0$。
$3$.  **当 $a < 0$ 时** :
    *   来自情况 $1$: $b > -a$。
    *   来自情况 $2$: $b < \frac{1}{a}$。

注意， $b$ 可以是数组中任意一个数， 包括 $a$ 本身（但要求索引不同）。 我们在统计时需要小心处理， 如果 $a$ 自身也落在合法区间内， 需要减去它（因为它代表 $a$ 和它自己配对， 而我们需要的是两个不同的数）。

### $4$. 高效统计算法

$1$.  **排序** : 首先将输入的 $N$ 个数字存入数组 `vals` 并排序。 排序后， 我们可以用二分查找快速统计落在某个区间内的元素数量。
$2$.  **枚举 $a$** : 遍历排序后的数组， 将当前元素视为 $a$。
$3$.  **二分统计** : 根据 $a$ 的符号， 使用 `upper_bound` 和 `lower_bound` 找出满足上述条件的 $b$ 的**数量**。
    *   `upper_bound(first, last, value)` 返回第一个 **大于** `value` 的元素位置。
    *   `lower_bound(first, last, value)` 返回第一个 **大于等于** `value` 的元素位置。
    *   利用这两个函数可以方便地统计开区间和闭区间内的元素个数。
$4$.  **去重与最终计算** : 在统计时， 如果 $a$ 自身也落在合法区间内， 需要将数量减 $1$ ， 排除 $(a, a)$ 这对（但题目允许数字值相同， 只要索引不同。 这里减 $1$ 是排除 $b$ 恰好取到 $a$ 本身这个索引的情况）。 由于我们遍历了每一个 $a$ ， 每一对合法的 $(a, b)$ 都会被统计两次（一次以 $a$ 为主元， 一次以 $b$ 为主元）， 所以最后将总数除以 $2$ 得到最终答案。

该算法时间复杂度为 $O(N \log N)$ ， 主要来自排序和 $N$ 次二分查找。

## 代码实现

```cpp
// The Strange Research
// UVa ID: 10732
// Verdict: Accepted
// Submission Date: 2025-12-05
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int caseNo = 1;
    int N;
    while (cin >> N && N != 0) {
        vector<double> vals(N);
        for (int i = 0; i < N; ++i) cin >> vals[i];
        sort(vals.begin(), vals.end());
        long long ans = 0;
        for (int i = 0; i < N; ++i) {
            double a = vals[i];
            if (a > 0) {
                // 情况1: b > -a 且 b < 1/a
                double low = -a;
                double high = 1.0 / a;
                auto itLow = upper_bound(vals.begin(), vals.end(), low);
                auto itHigh = lower_bound(vals.begin(), vals.end(), high);
                long long cnt = max(0LL, (long long)(itHigh - itLow));
                if (low < a && a < high) cnt--;
                ans += cnt;
            }
            else if (a == 0) {
                // 情况1: b > 0
                auto it = upper_bound(vals.begin(), vals.end(), 0.0);
                ans += (vals.end() - it);
            }
            else { // a < 0
                // 情况1: b > -a
                double low1 = -a;
                auto itLow1 = upper_bound(vals.begin(), vals.end(), low1);
                ans += (vals.end() - itLow1);

                // 情况2: b < 1/a
                double high2 = 1.0 / a;
                auto itHigh2 = lower_bound(vals.begin(), vals.end(), high2);
                long long cnt2 = itHigh2 - vals.begin();
                if (a < high2) cnt2--; // 去掉自身
                ans += cnt2;
            }
        }
        // 每个无序对被统计两次
        ans /= 2;
        cout << "Case " << caseNo++ << ": " << ans << "\n";
    }
    return 0;
}
```
