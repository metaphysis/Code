## 题目描述

$\pi$ 是数学中最重要的常数之一，定义为同一圆的周长与直径之比。数学家们一直致力于尽可能精确地计算 $\pi$ 的值，为此发明了许多 $\pi$ 的级数展开式。

其中一个经典的级数是莱布尼茨级数：

$$\pi = \frac{4}{1} - \frac{4}{3} + \frac{4}{5} - \frac{4}{7} + \frac{4}{9} - \frac{4}{11} + \dots$$

然而这个级数收敛非常缓慢。要精确到小数点后 $5$ 位，需要计算前 $130658$ 项，这在实践中是不可行的。

一个更好的级数可以从 $\arcsin x$ 的泰勒展开得到。由 $\frac{\pi}{6} = \arcsin(0.5)$，展开得：

$$\frac{\pi}{6} = \frac{1}{2} + \frac{1}{48} + \frac{3}{1280} + \frac{5}{14336} + \dots$$

两边乘以 $6$ 得到：

$$\pi = \frac{6}{2} + \frac{6}{48} + \frac{18}{1280} + \frac{30}{14336} + \dots$$

这个级数收敛非常快。例如，要精确到小数点后 $5$ 位，只需要前 $7$ 项。

**问题**：给定阈值 $10^{-n}$，求需要累加多少项，使得**下一项**的值低于该阈值。

## 输入格式

- 多组测试数据，每行一个整数 $n$（$1 \le n \le 600000$）
- 输入以负数结束，该行不处理
- 最多 $1000$ 行输入

## 输出格式

对于每个 $n$，输出一个整数，表示累加的项数。

## 样例

输入：
```
1
5
100000
-1
```

输出：
```
2
7
166084
```

## 题目分析

### 1. 寻找通项公式

首先需要推导出级数的通项公式。已知：

$$\frac{\pi}{6} = \arcsin\left(\frac12\right) = \sum_{k=0}^{\infty} \frac{(2k)!}{4^k (k!)^2 (2k+1)} \cdot \left(\frac12\right)^{2k+1}$$

整理后得到：

$$T_k = \frac{6 \cdot (2k)!}{4^k (k!)^2 (2k+1) \cdot 2^{2k+1}}$$

但这样形式较复杂。通过观察前几项：

- 第 $1$ 项：$3$
- 第 $2$ 项：$\frac{6}{48} = 0.125$
- 第 $3$ 项：$\frac{18}{1280} = 0.0140625$

可以归纳出递推关系。设第 $m$ 项为 $a_m$（$m \ge 1$），则：

$$a_{m+1} = a_m \cdot \frac{(2m-1)^2}{2m(2m+1)} \cdot \frac14$$

验证：
- $a_2 = 3 \times \frac{1^2}{2 \times 3} \times \frac14 = \frac{3}{24} = 0.125$
- $a_3 = 0.125 \times \frac{3^2}{4 \times 5} \times \frac14 = 0.125 \times \frac{9}{20} \times 0.25 = 0.0140625$

### 2. 精度问题

$n$ 最大为 $600000$，即阈值 $10^{-600000}$，是一个非常小的数。直接使用浮点数存储项的值会导致下溢（变为 $0$），无法正确比较。

**解决方案**：使用对数。比较 $a_m < 10^{-n}$ 等价于：

$$\ln a_m < -n \cdot \ln 10$$

这样我们只需要存储和计算 $\ln a_m$，值的范围大约在 $\ln 3 \approx 1.1$ 到 $-600000 \times 2.3026 \approx -1.38 \times 10^6$ 之间，完全在 `double` 的表示范围内。

### 3. 对数递推公式

对递推关系两边取自然对数：

$$\ln a_{m+1} = \ln a_m + 2\ln(2m-1) - \ln(2m) - \ln(2m+1) - \ln 4$$

初始值：$\ln a_1 = \ln 3$。

### 4. 时间复杂度问题

如果对每个 $n$ 从第 $1$ 项开始逐项计算直到找到答案，最坏情况下 $n=600000$ 时大约需要 $10^6$ 次递推，乘以最多 $1000$ 个查询，总计算量达到 $10^9$ 量级，会超时。

**优化方法**：二分搜索。

观察到 $\ln a_m$ 随着 $m$ 增加而单调递减（因为每一项都是正数且递减）。因此对于固定的阈值 $\ln a_m < -n\ln 10$，满足条件的 $m$ 具有单调性：存在一个分界点 $M$，使得当 $m \ge M$ 时不等式成立，当 $m < M$ 时不成立。

于是我们可以：
1. 预处理出前足够多项的 $\ln a_m$ 值
2. 对每个查询，在预处理数组上二分查找最小的 $m$ 使得 $\ln a_m < -n\ln 10$
3. 答案即为 $m-1$（因为要输出的是“下一项低于阈值之前已加的项数”）

### 5. 预处理上界的确定

需要预处理到多大的 $m$？根据样例，$n=100000$ 时答案是 $166084$，$n=600000$ 时答案会更大。经过分析，当 $n=600000$ 时答案大约在 $1.2 \times 10^6$ 左右。为了保险，我们设定预处理上界为 $2000000$，这个量级的计算在时间上是可行的。

## 解题思路

1. **预处理阶段**：
   - 开辟数组 `termLog[1..MAX_M]`，其中 `termLog[m]` 存储 $\ln a_m$
   - 初始化 `termLog[1] = log(3.0)`
   - 对于 $m$ 从 $1$ 到 $\texttt{MAX\_M}-1$，计算：
     $$\texttt{termLog}[m+1] = \texttt{termLog}[m] + 2\ln(2m-1) - \ln(2m) - \ln(2m+1) - \ln 4$$

2. **查询阶段**：
   - 读取所有有效的 $n$ 值，存储到 `queries` 向量中
   - 对于每个 $n$，计算阈值对数 `thresholdLog = -n * log(10.0)`
   - 在 `termLog` 数组上二分查找最小的 $m$ 使得 `termLog[m] < thresholdLog`
   - 输出 `m - 1`

3. **二分查找细节**：
   - 初始化左边界 `l = 1`，右边界 `r = MAX_M`
   - 当 `l <= r` 时循环：
     - 计算中点 `mid = l + (r - l) / 2`
     - 如果 `termLog[mid] < thresholdLog`，则记录答案并继续向左搜索（`r = mid - 1`）
     - 否则向右搜索（`l = mid + 1`）
   - 最终答案为记录的答案减 $1$

---

## 复杂度分析

- **预处理**：$O(\texttt{MAX\_M})$，$\texttt{MAX\_M} = 2 \times 10^6$，约 $2 \times 10^6$ 次对数运算，时间可接受
- **每个查询**：$O(\log \texttt{MAX\_M})$，约 $21$ 次比较
- **总复杂度**：$O(\texttt{MAX\_M} + Q \log \texttt{MAX\_M})$，$Q \le 1000$，完全满足要求

## 代码实现

```cpp
// Series of PI
// UVa ID: 10736
// Verdict: Accepted
// Submission Date: 2026-05-23
// UVa Run Time: 0.040s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAX_M = 2000000;  // 预处理上界，足够覆盖 n=600000 的情况
vector<double> termLog(MAX_M + 1);

// 预处理所有项的自然对数
void preprocess() {
    termLog[1] = log(3.0);  // 第一项 ln(3)
    for (int k = 1; k < MAX_M; ++k) {
        // 递推公式：ln(a_{k+1}) = ln(a_k) + 2ln(2k-1) - ln(2k) - ln(2k+1) - ln4
        termLog[k + 1] = termLog[k] + 2.0 * log(2.0 * k - 1.0) 
                        - log(2.0 * k) - log(2.0 * k + 1.0) - log(4.0);
    }
}

int main() {
    preprocess();
    
    vector<int> queries;
    int n;
    while (cin >> n && n >= 0) queries.push_back(n);
    
    const double log10 = log(10.0);
    
    for (int n : queries) {
        double thresholdLog = -n * log10;  // ln(10^{-n})
        int l = 1, r = MAX_M;
        int ans = MAX_M;
        
        // 二分查找最小的 m 使得第 m 项小于阈值
        while (l <= r) {
            int mid = l + (r - l) / 2;
            if (termLog[mid] < thresholdLog) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        // 输出答案：加到第 ans-1 项时，下一项（第 ans 项）低于阈值
        cout << ans - 1 << "\n";
    }
    
    return 0;
}
```

## 总结

本题的核心难点在于：
1. 推导出级数的递推公式
2. 使用对数比较避免浮点下溢
3. 通过预处理 + 二分查找优化时间复杂度

掌握这些技巧后，即使 $n$ 高达 $600000$ 也能高效求解。
