## 题目描述

如果你玩过“俄罗斯方块”，可能对以下图形很熟悉：这些图形由若干行方块组成。每一行的方块必须是连续的一段。相邻的两行之间必须至少共享一个方块的边。给定方块的总数 $n$ ，计算不同的合法图形数量。由于答案可能非常大，如果答案超过 $9999$ ，则仅输出其**最后 $4$ 位数字**（不足 $4$ 位时前面补 $0$）；否则输出完整的数字。

**输入格式**  
第一行包含一个整数 $t$（$1 \leq t \leq 20$），表示测试用例的数量。  
每个测试用例包含一个整数 $n$（$1 \leq n \leq 1,000,000,000$），表示方块总数。

**输出格式**  
对于每个测试用例，输出 `Case i: ` 后跟所求的数字（按上述规则截断或补零）。

**样例输入**
```
3
3
5
7
```

**样例输出**
```
Case 1: 6
Case 2: 61
Case 3: 629
```

## 题目分析

这是一个组合计数问题，要求计算满足特定堆叠规则的 $n$ 个方块可以形成的不同图形数量。规则可以总结为：
1. 图形由若干行组成，每行方块是连续的一段；
2. 相邻两行必须至少共享一个方块的一条边（即不能悬空，也不能错开不接触）。

这是一个经典的递推问题。通过枚举小规模情况，我们可以发现前几项为：
- $n = 1$：$1$ 种
- $n = 2$：$2$ 种
- $n = 3$：$6$ 种
- $n = 4$：$19$ 种
- $n = 5$：$61$ 种
- $n = 6$：$196$ 种
- $n = 7$：$629$ 种

进一步分析可以发现递推关系：当 $n \geq 5$ 时，

$$
a_n = 5a_{n-1} - 7a_{n-2} + 4a_{n-3}
$$

其中初始条件为 $a_1 = 1$，$a_2 = 2$，$a_3 = 6$，$a_4 = 19$。

## 解题思路

### 1. 递推关系的验证

我们可以验证这个递推关系：
- $a_5 = 5 \times 19 - 7 \times 6 + 4 \times 2 = 95 - 42 + 8 = 61$ 
- $a_6 = 5 \times 61 - 7 \times 19 + 4 \times 6 = 305 - 133 + 24 = 196$ 
- $a_7 = 5 \times 196 - 7 \times 61 + 4 \times 19 = 980 - 427 + 76 = 629$ 

这个递推关系是正确的。

### 2. 矩阵快速幂优化

由于 $n$ 最大可达 $10^9$，直接递推显然不可行。我们可以使用矩阵快速幂将时间复杂度优化到 $O(\log n)$。

将递推式转化为矩阵形式：
$$
\begin{bmatrix} a_n \\ a_{n-1} \\ a_{n-2} \end{bmatrix} = 
\begin{bmatrix} 5 & -7 & 4 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix} \cdot
\begin{bmatrix} a_{n-1} \\ a_{n-2} \\ a_{n-3} \end{bmatrix}
$$

定义转移矩阵：
$$
M = \begin{bmatrix} 5 & -7 & 4 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix}
$$

初始向量：
$$
V_4 = \begin{bmatrix} a_4 \\ a_3 \\ a_2 \end{bmatrix} = \begin{bmatrix} 19 \\ 6 \\ 2 \end{bmatrix}
$$

对于 $n \geq 5$：
$$
V_n = M^{n-4} \cdot V_4
$$

其中 $a_n$ 是 $V_n$ 的第一个分量。

### 3. 模运算处理

题目要求当答案超过 $9999$ 时只输出最后 $4$ 位，这等价于对 $10000$ 取模。由于递推式中有负数系数，在矩阵运算中需要正确处理负数取模：
- 计算 $(a \cdot b) \bmod m$ 时，先计算乘积，再取模；
- 对于负数，取模后加上 $m$ 再取模，确保结果在 $[0, m-1]$ 范围内。

### 4. 输出格式处理

根据题目要求：
- 如果 $n \geq 10$，则答案一定超过 $9999$，需要输出最后 $4$ 位（不足补零）；
- 如果 $n < 10$，则直接输出计算结果（不需要补零）。

## 算法步骤

1. 读入测试用例数 $t$。
2. 对于每个测试用例：
   - 读入 $n$；
   - 如果 $n \leq 3$，直接输出预计算的结果；
   - 如果 $n = 4$，直接输出 $19$；
   - 如果 $n \geq 5$：
     - 计算 $M^{n-4}$（使用矩阵快速幂）；
     - 计算 $a_n = M^{n-4}[0][0] \times 19 + M^{n-4}[0][1] \times 6 + M^{n-4}[0][2] \times 2$；
     - 对结果取模 $10000$；
     - 根据 $n$ 的大小决定输出格式。

## 复杂度分析

- 矩阵快速幂的时间复杂度为 $O(3^3 \log n) = O(27 \log n)$。
- 对于 $t \leq 20$，$n \leq 10^9$，完全可以在时限内完成。
- 空间复杂度为 $O(1)$。

```cpp
// Blocks on Blocks

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MOD = 10000;  // 只需要最后4位

// 矩阵乘法 (3x3) 模 MOD
void mul(int a[3][3], int b[3][3], int r[3][3]) {
    ll t[3][3] = {0};
    for (int i = 0; i < 3; ++i)
    for (int j = 0; j < 3; ++j)
    for (int k = 0; k < 3; ++k)
        t[i][j] += (ll)a[i][k] * b[k][j];
    for (int i = 0; i < 3; ++i)
    for (int j = 0; j < 3; ++j)
        r[i][j] = ((t[i][j] % MOD) + MOD) % MOD;  // 处理负数
}

// 矩阵快速幂
void powM(int m[3][3], ll n, int r[3][3]) {
    int b[3][3], t[3][3];
    memcpy(b, m, sizeof(b));  // 复制矩阵
    // 初始化结果矩阵为单位矩阵
    for (int i = 0; i < 3; ++i)
    for (int j = 0; j < 3; ++j)
        r[i][j] = (i == j);
    while (n) {
        if (n & 1) memcpy(t, r, sizeof(t)), mul(t, b, r);  // r = r * b
        memcpy(t, b, sizeof(t)), mul(t, t, b);  // b = b * b
        n >>= 1;
    }
}

int main() {
    ios::sync_with_stdio(false), cin.tie(0);
    int t, cs = 0; cin >> t;
    // 转移矩阵
    int M[3][3] = {{5, -7, 4}, {1, 0, 0}, {0, 1, 0}};
    // 前3项的初始值
    int base[4] = {0, 1, 2, 6};
    
    while (t--) {
        ll n; cin >> n;
        cout << "Case " << ++cs << ": ";
        
        // 处理前4项
        if (n <= 3) { cout << base[n] << "\n"; continue; }
        if (n == 4) { cout << "19\n"; continue; }
        
        // 计算 M^(n-4)
        int Mp[3][3];
        powM(M, n - 4, Mp);
        
        // 计算 a_n = Mp[0][0]*19 + Mp[0][1]*6 + Mp[0][2]*2
        ll fn = (Mp[0][0] * 19LL + Mp[0][1] * 6 + Mp[0][2] * 2) % MOD;
        fn = (fn + MOD) % MOD;  // 确保非负
        
        // 输出规则：如果 n >= 10，答案一定超过9999，输出最后4位（补0）
        if (n >= 10) cout << setw(4) << setfill('0') << fn << "\n";
        else cout << fn << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于发现正确的递推关系 $a_n = 5a_{n-1} - 7a_{n-2} + 4a_{n-3}$，并通过矩阵快速幂高效计算大 $n$ 的情况。需要注意负数系数的模运算处理，以及根据 $n$ 的大小确定输出格式（是否需要补零）。

这种将线性递推转化为矩阵幂运算的方法是处理大 $n$ 递推问题的常用技巧，在组合计数问题中尤其有用。
