## 题目描述

在名为 $\texttt{Culabura}$ 的国家中，有大约 $20000$ 个重要地点。总统希望建造一条超级高速公路，该公路是一条直线，满足以下条件：

1. 必须平行于连接两个最重要城市 $A$ 和 $B$ 的道路
2. 所有重要地点到该直线的距离之和必须最小

你的任务是计算这个最小距离和 $sum\_d\_min$。

**输入格式：**
- 第一行两个整数 $N$（重要地点数，$0 < N < 20001$）和 $Q$（查询数，$0 < Q < 101$）
- 接下来 $N$ 行，每行一个坐标 $(x_i, y_i)$，其中 $|x_i|, |y_i| \leq 100$
- 接下来 $Q$ 行，每行四个整数 $A_x, A_y, B_x, B_y$，表示城市 $A$ 和 $B$ 的坐标

**输出格式：**
对每个查询输出一行：`Case i: sum_d_min`，其中 $sum\_d\_min$ 四舍五入到整数。

## 题目分析

### 问题理解

我们需要找到一条与 $AB$ 平行的直线，使得所有重要地点到这条直线的距离之和最小。这是一个优化问题，关键在于理解如何高效地找到最优的直线位置。

### 关键观察

1. **平行约束**：由于超级公路必须平行于 $AB$，所以所有可能的候选直线都有相同的方向向量 $\vec{v} = (B_x - A_x, B_y - A_y)$

2. **距离计算**：点 $P(x_i, y_i)$ 到方向向量为 $\vec{v}$ 的直线的距离公式为：
   $$
   d = \frac{|(P - A) \times \vec{v}|}{\|\vec{v}\|}
   $$
   其中 $\times$ 表示二维叉积：$(x_1 \cdot y_2 - x_2 \cdot y_1)$

3. **优化原理**：当直线可以沿着法线方向平移时，最小化总距离的问题等价于在投影轴上找到最优位置。数学上可以证明，当直线位于所有点的有向距离的中位数位置时，总距离最小

### 算法思路

对于每个查询：

1. 计算方向向量 $\vec{v} = (dx, dy) = (B_x - A_x, B_y - A_y)$ 和其长度 $len = \sqrt{dx^2 + dy^2}$

2. 对于每个重要地点 $P_i$，计算有向距离：
   $$
   dist_i = \frac{(P_i - A) \times \vec{v}}{len} = \frac{(x_i - A_x) \cdot dy - (y_i - A_y) \cdot dx}{len}
   $$

3. 找到所有有向距离的中位数

4. 计算总距离：$sum = \sum |dist_i - median|$

5. 将结果四舍五入到整数输出

### 复杂度分析

- 预处理：$O(N)$ 读取坐标
- 每个查询：
  - $O(N)$ 计算有向距离
  - $O(N)$ 使用 `nth_element` 找中位数
  - $O(N)$ 计算总距离
- 总体复杂度：$O(Q \cdot N)$，对于 $N \leq 20000$ 和 $Q \leq 100$ 是可接受的

### 为什么选择中位数？

这是一个经典的优化问题：对于一维数据，要使所有点到某个位置的距离之和最小，该位置应该选择数据的中位数。这是因为：

- 如果选择均值，最小化的是平方距离和
- 如果选择中位数，最小化的是绝对距离和

## 代码实现

```cpp
// The Optimal Super-Highway

// Verdict: Accepted
// Submission Date: 2025-11-25
// UVa Run Time: 0.150s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;

    vector<int> x(n), y(n);
    for (int i = 0; i < n; i++)
        cin >> x[i] >> y[i];

    for (int qi = 1; qi <= q; qi++) {
        int ax, ay, bx, by;
        cin >> ax >> ay >> bx >> by;

        int dx = bx - ax, dy = by - ay;
        double len = sqrt(dx * dx + dy * dy);

        vector<double> dists(n);
        for (int i = 0; i < n; i++) {
            int vx = x[i] - ax, vy = y[i] - ay;
            dists[i] = (vx * dy - vy * dx) / len; // 有向距离
        }

        nth_element(dists.begin(), dists.begin() + n / 2, dists.end());
        double median = dists[n / 2];

        double sum = 0;
        for (double d : dists)
            sum += fabs(d - median);

        cout << "Case " << qi << ": " << (int)round(sum) << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于将二维的直线放置问题转化为一维的优化问题。通过计算所有重要地点相对于参考直线的有向距离，我们利用中位数的性质在 $O(N)$ 时间内找到最优解。这种将几何问题转化为统计问题的方法是解决此类优化问题的常用技巧。
