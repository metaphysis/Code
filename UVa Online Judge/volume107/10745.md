[UVa 10745 Dominant Strings](https://blog.csdn.net/metaphysis/article/details/153868531)

## 题目描述

给定一组字符串，定义**支配关系**如下：  
字符串 $s_1$ 支配 $s_2$ 当且仅当 $s_1$ 的字符多重集是 $s_2$ 的字符多重集的**真超集**。  
换句话说：
- $s_1$ 包含 $s_2$ 中的所有字符（考虑出现次数）；
- 并且 $s_1$ 至少有一个字符的出现次数严格大于 $s_2$ 中该字符的出现次数。

对于一个字符串集合 $S$，**$\texttt{dominant strings}$** 指的是 $S$ 中不被任何其他字符串支配的字符串。  
要求找出输入集合中的所有 $\texttt{dominant strings}$，并按字典序输出。

---

## 输入格式

- 每个输入文件包含一组字符串，每行一个字符串。
- 每个字符串由 $1$ 到 $10$ 个小写字母组成。
- 字符串总数不超过 $15000$，且没有重复字符串。
- 输入以 $\texttt{EOF}$ 结束。

---

## 输出格式

- 输出所有 $\texttt{dominant strings}$，按字典序排列，每行一个。

---

## 样例

**输入**
```
acmiope
cccp
macpac
chimp
camp
```

**输出**
```
acmiope
chimp
macpac
```

## 题目分析

### 1. 支配关系的判断

要判断字符串 $A$ 是否支配字符串 $B$，我们需要比较它们的字符出现次数（即字符的多重集）。  
具体来说：
- 对于每个字符 $ch$（从 `'a'` 到 `'z'`），$A$ 中 $ch$ 的出现次数必须不少于 $B$ 中 $ch$ 的出现次数；
- 并且至少存在一个字符 $ch$，$A$ 中的出现次数严格大于 $B$ 中的出现次数。

这可以通过两个长度为 $26$ 的计数数组来实现。

---

### 2. 算法设计

#### 暴力方法
最直接的方法是：
1. 对每个字符串，计算其字符计数数组；
2. 对于每一对字符串 $(i, j)$，检查 $j$ 是否支配 $i$；
3. 标记所有被支配的字符串；
4. 输出未被支配的字符串，按字典序排序。

时间复杂度：$O(n^2 \times 26)$，其中 $n \leq 15000$，最坏情况下约为 $5.85 \times 10^9$ 次操作，在一般 $\texttt{OJ}$ 上可能超时。

#### 优化思路
- 由于字符串长度最多为 $10$，且字符种类有限，实际运行可能通过；
- 可以按长度分组，只比较长度 $\geq$ 当前字符串的组，因为支配关系要求支配者的长度不小于被支配者；
- 在比较过程中，一旦发现当前字符串被支配，立即跳出内层循环。

---

### 3. 实现细节

- 使用 `vector<vector<int>>` 存储每个字符串的字符计数；
- 使用 `vector<bool>` 标记每个字符串是否被支配；
- 双重循环比较所有字符串对，检查支配关系；
- 最后收集未被支配的字符串，排序输出。

## 代码实现

```cpp
// Dominant Strings
// UVa ID: 10745
// Verdict: Accepted
// Submission Date: 2025-10-25
// UVa Run Time: 0.690s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

// 检查 countA 是否支配 countB
bool checkDomination(const vector<int>& countA, const vector<int>& countB) {
    bool hasStrictlyGreater = false;
    for (int i = 0; i < 26; i++) {
        if (countA[i] < countB[i]) return false;
        if (countA[i] > countB[i]) hasStrictlyGreater = true;
    }
    return hasStrictlyGreater;
}

int main() {
    vector<string> wordList;
    string inputStr;
    
    // 读取输入
    while (cin >> inputStr) {
        wordList.push_back(inputStr);
    }
    
    int totalWords = wordList.size();
    
    // 计算每个单词的字符计数
    vector<vector<int>> charCount(totalWords, vector<int>(26, 0));
    for (int i = 0; i < totalWords; i++) {
        for (char ch : wordList[i]) {
            charCount[i][ch - 'a']++;
        }
    }
    
    vector<bool> isDominated(totalWords, false);
    
    // 比较所有单词对
    for (int i = 0; i < totalWords; i++) {
        if (isDominated[i]) continue;
        for (int j = 0; j < totalWords; j++) {
            if (i == j) continue;
            // 如果 j 支配 i，则标记 i 被支配
            if (checkDomination(charCount[j], charCount[i])) {
                isDominated[i] = true;
                break;
            }
        }
    }
    
    // 收集未被支配的单词
    vector<string> resultList;
    for (int i = 0; i < totalWords; i++) {
        if (!isDominated[i]) {
            resultList.push_back(wordList[i]);
        }
    }
    
    // 按字典序排序
    sort(resultList.begin(), resultList.end());
    
    // 输出结果
    for (const string& word : resultList) {
        cout << word << endl;
    }
    
    return 0;
}
```

## 总结

本题的核心在于理解**支配关系**的定义，并通过字符计数数组高效判断。  
虽然暴力方法在最坏情况下复杂度较高，但由于数据规模的实际限制和字符串长度较短，该解法在 $\texttt{OJ}$ 上可以通过。  
如果需要进一步优化，可以按长度分组减少比较次数，或利用位运算和预处理技巧加速比较过程。
