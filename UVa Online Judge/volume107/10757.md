## 题目描述

巴塞罗那市政府最近将有轨电车纳入了其 “高效” 的公共交通系统。结果可想而知，发生了一系列极具原创性和美感的交通事故。出于减少美学方面的考虑，巴塞罗那市长决定减少事故造成的延误。经过深入研究，建立了以下模型：

每辆电车必须从起点 $P_0$ 出发，依次经过中间点 $P_1, \dots, P_{n-1}$，最后到达终点 $P_n$。对于每个 $1 \le i \le n$，设 $S_i$ 是从 $P_{i-1}$ 到 $P_i$ 的路段。每个路段必须以匀速 $v_i$ 行驶，速度由司机在 $P_{i-1}$ 处选择。设 $M_i$ 是电车在 $S_i$ 上的最大可能速度，所选速度满足 $0 < v_i \le M_i$。那么在 $S_i$ 上发生事故的概率为 $v_i / M_i$。

发生事故时，电车使用一个高效恢复系统，只需 $10$ 秒。之后，电车使用辅助（慢速但安全）发动机到达 $P_i$，速度为 $5$ 米/秒，并且保证在 $S_i$ 上不再发生事故。

例如，假设路段长度为 $300$ 米，当前最大速度为 $25$ 米/秒。如果司机选择以 $25$ 米/秒行驶，电车一定会发生事故。由于事故可能发生在 $P_{i-1}$ 和 $P_i$ 之间的任何位置，为计算方便，我们假设事故恰好发生在中点（$150$ 米处）。因此，平均而言，电车需要 $6$ 秒到达中点，$10$ 秒恢复，$30$ 秒到达 $P_i$，总共 $46$ 秒。相比之下，如果电车以 $15$ 米/秒行驶，则有 $0.6$ 的概率发生事故，花费 $10 + 10 + 30 = 50$ 秒，有 $0.4$ 的概率不发生事故，$20$ 秒到达 $P_i$。此时的平均时间为 $0.6 \times 50 + 0.4 \times 20 = 38$ 秒。

当电车到达每个 $P_i$ 时，无论 $S_i$ 上是否发生事故，都会停靠几秒钟（为简单起见，我们认为停靠时间为 $0$）。这些时间足以（几乎）修复电车：每次事故后，最大速度降低 $1$ 米/秒。设初始最大速度为 $M_0$，则有 $M_i = M_0 - C_i$，其中 $0 \le C_i \le i-1$ 是在 $S_1, \dots, S_{i-1}$ 中发生的事故总数。

编写一个程序，给定初始最大速度和每个路段的长度，输出最优的平均旅行时间。

## 输入格式

输入包含零个或多个测试用例。每个测试用例一行，包含 $M_0$（$5$ 到 $25$ 之间的实数）、$n$（$1$ 到 $M_0-1$ 之间的整数），以及每个路段的长度（$100$ 到 $1000$ 之间的实数）。

## 输出格式

对于每个测试用例，输出一行，表示最优平均旅行时间，保留四位小数。

## 样例

输入

```
25 1 900
25 2 900 900
25 2 305.15 980.76
5 1 1000
```

输出

```
102.0000

210.0000
```

## 题目分析

本题的核心是：在每条路段上，司机需要根据当前的最大速度（受之前事故次数影响）选择一个行驶速度，以最小化从起点到终点的**期望总时间**。

与普通的最短路径问题不同，这里的决策会影响两个层面：
1. **当前路段的期望时间**：速度越快，路段行驶时间越短，但事故概率越高，事故后需要额外的恢复时间和慢速行驶时间。
2. **未来路段的最大速度**：发生事故会导致后续所有路段的最大速度永久降低 $1$ 米/秒，这会影响后续路段的决策和期望时间。

因此，这是一个**带状态依赖的随机动态规划**问题。状态包括：当前处理到第几个路段，以及已经发生的事故次数。在每个状态下，需要优化选择行驶速度 $v$，使得当前及未来的期望总时间最小。

## 解题思路

### 状态定义

设 $\textit{dp}[i][c]$ 表示：当前准备处理第 $i$ 个路段（$0$ 索引），且已经发生了 $c$ 次事故时，从该路段到终点的最小期望时间。

其中 $0 \le i \le n$，$0 \le c \le M_0$（因为最多发生 $M_0$ 次事故后最大速度会降为 $0$，但题目保证 $n \le M_0-1$，所以 $c$ 不会超过 $M_0$）。

边界条件：当 $i = n$ 时，没有剩余路段，$\textit{dp}[n][c] = 0$。

### 状态转移

在第 $i$ 个路段，当前最大速度 $M = M_0 - c$，路段长度为 $L_i$。设司机选择速度 $v$（$0 < v \le M$），则：

- 不发生事故的概率为 $1 - v/M$，此时该路段花费时间 $T_{\text{no}} = L_i / v$，且事故次数不变，后续期望时间为 $\textit{dp}[i+1][c]$。
- 发生事故的概率为 $v/M$，此时该路段花费时间 $T_{\text{crash}} = L_i / (2v) + 10 + L_i / 10$，且事故次数增加 $1$，后续期望时间为 $\textit{dp}[i+1][c+1]$。

因此，期望总时间为：
$$
f(v) = \left(1 - \frac{v}{M}\right) \left( \frac{L_i}{v} + \textit{dp}[i+1][c] \right) + \frac{v}{M} \left( \frac{L_i}{2v} + 10 + \frac{L_i}{10} + \textit{dp}[i+1][c+1] \right)
$$

整理得：
$$
f(v) = \frac{L_i}{v} + \textit{dp}[i+1][c] - \frac{L_i}{2M} + \frac{v}{M} \left( 10 + \frac{L_i}{10} + \textit{dp}[i+1][c+1] - \textit{dp}[i+1][c] \right)
$$

令：
$$
\Delta = 10 + \frac{L_i}{10} + \textit{dp}[i+1][c+1] - \textit{dp}[i+1][c]
$$
则：
$$
f(v) = \frac{L_i}{v} + \textit{dp}[i+1][c] - \frac{L_i}{2M} + \frac{v}{M} \cdot \Delta
$$

### 最优速度的求解

$f(v)$ 对 $v$ 求导：
$$
f'(v) = -\frac{L_i}{v^2} + \frac{\Delta}{M}
$$
令 $f'(v) = 0$，得：
$$
v^* = \sqrt{ \frac{L_i \cdot M}{\Delta} }
$$
由于 $v$ 不能超过最大速度 $M$，且必须为正数，因此实际最优速度为：
$$
v_{\text{opt}} = \min\left( M,\ \sqrt{ \frac{L_i \cdot M}{\Delta} } \right)
$$

### 动态规划求解

由于后面的状态依赖于前面的状态（$\textit{dp}[i+1][\cdot]$ 先计算），我们采用**逆序递推**：
- 初始化 $\textit{dp}[n][c] = 0$ 对所有 $c$。
- 从 $i = n-1$ 递减到 $0$，对于每个可能的 $c$（$0 \le c \le M_0$）：
  - 如果 $M = M_0 - c \le 0$，则 $\textit{dp}[i][c] = +\infty$（不可达）。
  - 否则，计算 $\Delta$，然后得到 $v_{\text{opt}}$，最后代入 $f(v)$ 计算 $\textit{dp}[i][c]$。

最终答案即为 $\textit{dp}[0][0]$。

### 复杂度分析

- 状态数：$O(n \cdot M_0)$。
- 每个状态的计算为 $O(1)$（仅包含基本算术运算）。
- 总时间复杂度：$O(n \cdot M_0)$，在本题约束下（$M_0 \le 25$，$n \le 24$）非常快。
- 空间复杂度：$O(n \cdot M_0)$，也可以优化到 $O(M_0)$ 因为只依赖下一层，但为清晰起见保留二维数组。

```cpp
#include <bits/stdc++.h>
using namespace std;

double solveTestCase(double M0, int n, const vector<double>& lengths) {
    // dp[i][c] = 从路段 i 开始，已发生 c 次事故的最小期望时间
    vector<vector<double>> dp(n + 1, vector<double>(M0 + 2, 0.0));
    
    for (int i = n - 1; i >= 0; --i) {
        double L = lengths[i];
        for (int c = 0; c <= M0; ++c) {
            double M = M0 - c;
            if (M <= 0) {
                dp[i][c] = 1e18;
                continue;
            }
            double Ec = dp[i + 1][c];
            double Ec1 = dp[i + 1][c + 1];
            double delta = 10.0 + L / 10.0 + Ec1 - Ec;
            double v = sqrt(L * M / delta);
            if (v > M) v = M;
            dp[i][c] = L / v + Ec - L / (2.0 * M) + v / M * delta;
        }
    }
    return dp[0][0];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string line;
    while (getline(cin, line)) {
        if (line.empty()) continue;
        stringstream ss(line);
        double M0;
        int n;
        ss >> M0 >> n;
        if (ss.fail()) break;
        
        vector<double> lengths(n);
        for (int i = 0; i < n; ++i) {
            ss >> lengths[i];
            if (ss.fail()) return 0;
        }
        
        double result = solveTestCase(M0, n, lengths);
        cout << fixed << setprecision(4) << result << '\n';
    }
    return 0;
}
```

## 总结

本题的关键点在于：

1. **状态设计**：事故次数作为状态，因为它直接影响后续所有路段的最大速度。
2. **期望时间建模**：正确写出包含概率权和后续期望的 $\texttt{Bellman}$ 方程。
3. **连续优化**：对速度 $v$ 求导得到解析最优解，避免了数值搜索。
4. **逆序递推**：由于后续期望先于当前计算，采用从后往前的动态规划顺序。

本题是**随机动态规划**与**连续决策变量优化**结合的一个典型例子。通过解析求导得到最优速度的闭式表达式，使得动态规划的每个状态转移可以在 $O(1)$ 时间内完成，从而高效求解。这种技巧在处理带有连续决策变量的随机优化问题时非常有用。
