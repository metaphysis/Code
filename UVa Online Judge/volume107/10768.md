## 题目描述

如果一个图可以在平面上绘制，且没有任何边交叉，则该图被称为 **平面图** 。在图的绘制中，节点对应于平面上的点，边对应于连接对应端点的线。在绘制中，边不允许与其他边或节点交叉。

回忆一下 **库拉托夫斯基定理** ，它提供了一个判断平面图的简单方法：一个图是平面图 **当且仅当** 它不同胚于任何包含子图 $K_{3,3}$ 或子图 $K_{5}$ 的图。

可以通过重复以下过程来获得与给定图同胚的最简单图（如果可能的话）：

*   删除一个度为 $1$ 的顶点及其关联的边。
*   删除一个度为 $2$ 的顶点 $v$ 及其关联的两条边，并用一条连接 $v$ 的两个相邻顶点的新边替代它们。

注意：如果边 $\{u,w\}$ 已经存在于图中，则不会再次添加。

编写一个程序，判断给定的无向图是否为平面图。

### 输入格式

输入包含零个或多个测试用例。每个测试用例包含一个图。

图的给出方式如下：首先，一行包含两个整数 $n$ 和 $m$ ，其中 $n$ 表示图的顶点数， $m$ 表示边数（ $1 \le n \le 20$ 且 $0 \le m$ ）。接下来是 $m$ 行，每行代表图的一条边，包含两个整数 $u$ 和 $v$ （ $u \ne v$ ），表示图中存在边 $\{u,v\}$ 。图中的顶点标记为从 $1$ 到 $n$ 。没有重复的边。

### 输出格式

对于每个测试用例，如果图是平面图，则输出一行字符串 `YES` ，否则输出 `NO` 。

### 样例输入
```
7 10
5 7
7 4
3 1
5 1
2 4
2 1
2 6
5 6
3 4
3 6
4 6
1 2
1 3
1 4
2 3
3 4
2 4
```

### 样例输出
```
NO
YES
```

## 题目分析

本题要求我们根据 **库拉托夫斯基定理** 判断一个无向图是否为平面图。这是一个经典的图论判定问题。库拉托夫斯基定理指出：

> 一个图是平面图当且仅当它不包含任何与 $K_5$ （完全图， $5$ 个顶点）或 $K_{3,3}$ （完全二分图，两边各 $3$ 个顶点）同胚的子图。

其中 **同胚操作** 允许我们：
*   删除度为 $1$ 的顶点及其边（悬挂点）。
*   将度为 $2$ 的顶点“压缩”掉，并将其两条边合并为一条新边（如果新边不存在则添加）。

我们的核心任务就是 **模拟简化过程**（不断进行同胚简化），然后在简化后的图中检查是否存在 $K_5$ 或 $K_{3,3}$ 的子图结构。

---

## 解题思路

### 1. 图表示与数据范围
由于顶点数 $n \le 20$ ，非常小，我们可以使用 **邻接矩阵** 来存储图，方便进行边的查询和修改。同时，我们需要一个数组来标记哪些顶点在简化过程中被移除了。

### 2. 同胚简化过程
这是一个循环过程，直到无法再进行任何简化为止：

$1$.  **计算度数**：对于每个未被移除的顶点，计算其在当前图中（只考虑未被移除的顶点之间的边）的度数。
$2$.  **删除度为 $1$ 的顶点**：将所有度数为 $1$ 的顶点标记为移除。这不会影响图中其他部分的连接性，也不会引入新边。
$3$.  **删除度为 $2$ 的顶点**：
    *   对于每个度数为 $2$ 且未被移除的顶点 $v$ ，找到它的两个邻居 $a$ 和 $b$ 。
    *   如果 $a$ 和 $b$ 之间没有边，则在它们之间添加一条新边。
    *   将顶点 $v$ 标记为移除。
    *   **注意**：如果 $a$ 和 $b$ 之间已经有边，则不需要重复添加。
$4$.  **循环**：重复步骤 $1-3$，直到某一轮中没有顶点被移除。

### 3. 检查 $K_5$ 和 $K_{3,3}$
在简化后的图中（只考虑未被移除的顶点）：

*   **检查 $K_5$**：我们需要找到 $5$ 个顶点，它们之间两两都有边相连（即构成一个 $5$ 阶完全图）。由于剩余顶点数最多 $20$ ，我们可以直接枚举所有可能的 $5$ 元组进行判断。
*   **检查 $K_{3,3}$**：我们需要找到 $6$ 个顶点，可以将它们分成两个集合 $A$ 和 $B$ ，每个集合 $3$ 个顶点，并且 $A$ 中的每个顶点都与 $B$ 中的所有顶点相连（ $A$ 和 $B$ 内部可以任意连接）。这同样可以通过枚举来实现：先选出 $6$ 个顶点，然后检查这 $6$ 个顶点的所有划分方式（前 $3$ 个作为 $A$ ，后 $3$ 个作为 $B$ ），看是否存在一种划分满足条件。

### 4. 判断结果
*   如果在简化后的图中找到了 $K_5$ 或 $K_{3,3}$ 结构，根据库拉托夫斯基定理，原图 **不是平面图**。
*   否则，原图 **是平面图**。

### 5. 算法复杂度分析
*   **简化过程**：每次循环至少移除一个顶点，最多循环 $O(n)$ 次，每次循环需要 $O(n^2)$ 的时间计算度数和处理删除，因此总时间为 $O(n^3)$。
*   **检查 $K_5$**：枚举 $5$ 个顶点组合，复杂度为 $O(C_k^5)$，其中 $k$ 是剩余顶点数（ $\le 20$ ），最多 $15504$ 种，可以接受。
*   **检查 $K_{3,3}$**：先选 $6$ 个顶点（ $O(C_k^6)$ ），再对选出的 $6$ 个顶点进行排列检查（ $O(6!)$ ），最坏情况组合数在可接受范围内。
*   总体复杂度对于 $n \le 20$ 是完全可行的。

```cpp
// Planarity

#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 21; // 最大顶点数

int n, m; // 顶点数和边数
bool adj[MAX_N][MAX_N]; // 邻接矩阵
bool removed[MAX_N]; // 标记顶点是否被删除
int degree[MAX_N]; // 每个顶点的度数

// 计算每个顶点的度数
void computeDegrees() {
    for (int i = 1; i <= n; i++) {
        degree[i] = 0;
        for (int j = 1; j <= n; j++)
            if (adj[i][j] && !removed[j])
                degree[i]++;
    }
}

// 移除度数为1的顶点
bool removeDegreeOne() {
    bool changed = false;
    for (int i = 1; i <= n; i++) {
        if (!removed[i] && degree[i] == 1) {
            removed[i] = true;
            changed = true;
        }
    }
    return changed;
}

// 移除度数为2的顶点，并用新边替代
bool removeDegreeTwo() {
    bool changed = false;
    for (int v = 1; v <= n; v++) {
        if (removed[v] || degree[v] != 2) continue;
        // 找到两个相邻顶点
        int neighbors[2], idx = 0;
        for (int u = 1; u <= n && idx < 2; u++)
            if (adj[v][u] && !removed[u])
                neighbors[idx++] = u;
        if (idx != 2) continue;
        int a = neighbors[0], b = neighbors[1];
        // 如果a和b之间没有边，则添加一条新边
        if (!adj[a][b]) {
            adj[a][b] = adj[b][a] = true;
            changed = true;
        }
        removed[v] = true; // 移除顶点v
    }
    return changed;
}

// 检查是否包含 K5 子图
bool hasK5() {
    // 选择5个未被删除的顶点
    vector<int> verts;
    for (int i = 1; i <= n; i++)
        if (!removed[i]) verts.push_back(i);
    if (verts.size() < 5) return false;
    // 检查所有5元组
    int sz = verts.size();
    for (int i1 = 0; i1 < sz; i1++)
        for (int i2 = i1 + 1; i2 < sz; i2++)
            for (int i3 = i2 + 1; i3 < sz; i3++)
                for (int i4 = i3 + 1; i4 < sz; i4++)
                    for (int i5 = i4 + 1; i5 < sz; i5++) {
                        int v1 = verts[i1], v2 = verts[i2], v3 = verts[i3], v4 = verts[i4], v5 = verts[i5];
                        if (adj[v1][v2] && adj[v1][v3] && adj[v1][v4] && adj[v1][v5] &&
                            adj[v2][v3] && adj[v2][v4] && adj[v2][v5] &&
                            adj[v3][v4] && adj[v3][v5] &&
                            adj[v4][v5])
                            return true;
                    }
    return false;
}

// 检查是否包含 K3,3 子图
bool hasK33() {
    vector<int> verts;
    for (int i = 1; i <= n; i++)
        if (!removed[i]) verts.push_back(i);
    if (verts.size() < 6) return false;
    int sz = verts.size();
    // 尝试所有划分为两个集合的方式，每个集合3个顶点
    vector<int> perm(sz);
    for (int i = 0; i < sz; i++) perm[i] = verts[i];
    do {
        // 前3个作为集合A，后3个作为集合B
        bool ok = true;
        for (int i = 0; i < 3 && ok; i++)
            for (int j = 3; j < 6 && ok; j++)
                if (!adj[perm[i]][perm[j]]) ok = false;
        if (ok) return true;
    } while (next_permutation(perm.begin(), perm.end()));
    return false;
}

// 判断图是否为平面图
bool isPlanar() {
    memset(removed, 0, sizeof removed);
    while (true) {
        computeDegrees();
        if (removeDegreeOne()) continue;
        if (removeDegreeTwo()) continue;
        break; // 无法继续简化
    }
    // 根据 Kuratowski 定理检查
    if (hasK5() || hasK33()) return false;
    return true;
}

int main() {
    while (cin >> n >> m) {
        if (n == 0 && m == 0) break;
        memset(adj, 0, sizeof adj);
        for (int i = 0; i < m; i++) {
            int u, v; cin >> u >> v;
            adj[u][v] = adj[v][u] = true;
        }
        if (isPlanar()) cout << "YES\n";
        else cout << "NO\n";
    }
    return 0;
}
```
