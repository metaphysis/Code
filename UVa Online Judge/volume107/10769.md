## 题目描述

著名的建筑师 $\texttt{Mr. Fruí}$ 计划建造一个高度为 $H$ 的巨大柱子。他有 $n$ 个黑色块，高度分别为 $b_1, \dots, b_n$，以及 $m$ 个白色块，高度分别为 $w_1, \dots, w_m$。

根据设计要求，柱子必须由四块组成，按照以下顺序堆叠：
- 底部：黑色块
- 第二层：白色块  
- 第三层：黑色块
- 顶部：白色块

$\texttt{Mr. Fruí}$ 想要找到所有总高度恰好等于 $H$ 的四块组合中**最稳定**的那个。稳定性的比较规则如下：

给定两个组合 $A = [a_1, a_2, a_3, a_4]$ 和 $B = [b_1, b_2, b_3, b_4]$（其中 $a_1$ 表示柱子 $A$ 底部黑色块的高度，依此类推），$A$ 比 $B$ 更稳定当且仅当：
- $a_1 > b_1$，或者
- $a_1 = b_1$ 且 $a_2 > b_2$，或者  
- $a_1 = b_1$ 且 $a_2 = b_2$ 且 $a_3 > b_3$，或者
- $a_1 = b_1$ 且 $a_2 = b_2$ 且 $a_3 = b_3$ 且 $a_4 > b_4$

换句话说，就是按照**字典序**比较两个四元组。

## 输入格式

输入包含多个测试用例。每个测试用例包含：
- 第一行：整数 $H$（$1 \leq H \leq 4 \times 10^8$）
- 第二行：黑色块高度序列 $b_1, \dots, b_n$
- 第三行：白色块高度序列 $w_1, \dots, w_m$

测试用例之间用空行分隔。保证 $2 \leq n \leq 100$，$2 \leq m \leq 100$，且每块高度不超过 $10^8$。

## 输出格式

对于每个测试用例，输出最稳定柱子的四块高度序列，如果没有解则输出 `no solution`。

## 题目分析

### 问题本质

我们需要从黑色块中选出两块（分别作为第一层和第三层），从白色块中选出两块（分别作为第二层和第四层），满足：
1. 总高度：$b_1 + w_1 + b_2 + w_2 = H$
2. 四元组 $(b_1, w_1, b_2, w_2)$ 在所有可行解中字典序最大

### 关键难点

1. **组合数量**：直接四重循环枚举所有可能的 $(b_1, w_1, b_2, w_2)$ 组合，时间复杂度为 $O(n^2 m^2)$，在最坏情况下（$n = m = 100$）需要 $10^8$ 次操作，可能超时。

2. **字典序比较**：需要找到所有可行解中字典序最大的那个，而不是简单地找到任意解。

3. **去重与优化**：同一块不能被重复使用，需要确保选出的四块来自不同的位置。

## 解题思路

### 优化策略

我们可以将问题分解为两个部分：

1. **预处理白色组合**：预先计算所有可能的白色块配对 $(w_1, w_2)$，并按它们的和进行分组。对于每个和值，我们存储所有可能的配对，并按照 $(w_1, w_2)$ 的字典序降序排列。

2. **枚举黑色组合**：对于每对黑色块 $(b_1, b_2)$，计算需要的白色块和：$need = H - b_1 - b_2$。如果存在这样的白色组合，直接取该和值对应的最大字典序白色配对。

### 算法步骤

1. **预处理白色块**：
   - 枚举所有 $i \neq j$ 的白色块配对 $(w_i, w_j)$
   - 将配对按和值分组存储到哈希表中
   - 对每个和值对应的配对列表按字典序降序排序

2. **寻找最优解**：
   - 枚举所有 $i \neq j$ 的黑色块配对 $(b_i, b_j)$
   - 计算需要的白色块和 $need = H - b_i - b_j$
   - 如果存在对应的白色配对，取字典序最大的那个
   - 比较所有可行解，选择字典序最大的四元组

3. **输出结果**：
   - 如果找到解，输出四块高度
   - 否则输出 `no solution`

### 复杂度分析

- **预处理白色块**：$O(m^2 \log m)$，包括枚举所有配对和对每个和值的配对列表排序
- **枚举黑色组合**：$O(n^2)$，每次查找白色配对为 $O(1)$
- **总体复杂度**：$O(n^2 + m^2 \log m)$，在 $n, m \leq 100$ 时完全可行

### 字典序处理技巧

为了确保找到字典序最大的解，我们采用以下策略：
1. 白色配对按 $(w_1, w_2)$ 字典序降序排列，这样对于给定的和值，第一个配对就是字典序最大的
2. 在枚举黑色组合时，维护当前找到的最佳解，遇到字典序更大的解时更新

```cpp
// Pillars

#include <iostream>
#include <vector>
#include <algorithm>
#include <map>

using namespace std;

struct Pillar {
    int b1, w1, b2, w2;
    Pillar(int b1, int w1, int b2, int w2) : b1(b1), w1(w1), b2(b2), w2(w2) {}
    bool operator<(const Pillar& other) const {
        if (b1 != other.b1) return b1 < other.b1;
        if (w1 != other.w1) return w1 < other.w1;
        if (b2 != other.b2) return b2 < other.b2;
        return w2 < other.w2;
    }
};

void solveTestCase(int H, vector<int>& blacks, vector<int>& whites) {
    map<int, vector<pair<int, int>>> whiteSums;
    for (size_t i = 0; i < whites.size(); ++i) {
        for (size_t j = 0; j < whites.size(); ++j) {
            if (i != j) {
                int sum = whites[i] + whites[j];
                whiteSums[sum].push_back({whites[i], whites[j]});
            }
        }
    }
    
    // 对每个 whiteSums 的 vector 按字典序排序
    for (auto& p : whiteSums) {
        sort(p.second.begin(), p.second.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
            if (a.first != b.first) return a.first > b.first;
            return a.second > b.second;
        });
    }
    
    Pillar best(-1, -1, -1, -1);
    
    for (size_t i = 0; i < blacks.size(); ++i) {
        for (size_t j = 0; j < blacks.size(); ++j) {
            if (i != j) {
                int needed = H - blacks[i] - blacks[j];
                if (whiteSums.count(needed)) {
                    auto& bestWhite = whiteSums[needed][0]; // 已经按字典序排好，第一个最大
                    Pillar candidate(blacks[i], bestWhite.first, blacks[j], bestWhite.second);
                    if (best < candidate) {
                        best = candidate;
                    }
                }
            }
        }
    }
    
    if (best.b1 == -1) {
        cout << "no solution" << endl;
    } else {
        cout << best.b1 << " " << best.w1 << " " << best.b2 << " " << best.w2 << endl;
    }
}

int main() {
    int H;
    while (cin >> H) {
        cin.ignore();
        string line;
        
        vector<int> blacks;
        getline(cin, line);
        size_t pos = 0;
        while (pos < line.length()) {
            size_t end = line.find(' ', pos);
            if (end == string::npos) end = line.length();
            blacks.push_back(stoi(line.substr(pos, end - pos)));
            pos = end + 1;
        }
        
        vector<int> whites;
        getline(cin, line);
        pos = 0;
        while (pos < line.length()) {
            size_t end = line.find(' ', pos);
            if (end == string::npos) end = line.length();
            whites.push_back(stoi(line.substr(pos, end - pos)));
            pos = end + 1;
        }
        
        solveTestCase(H, blacks, whites);
        
        // 跳过空行
        if (!getline(cin, line)) break;
    }
    return 0;
}
```

## 总结

本题的关键在于如何高效地找到满足高度约束且字典序最大的四块组合。通过将问题分解为黑色组合枚举和白色组合预处理两个部分，我们成功将时间复杂度从 $O(n^2 m^2)$ 优化到 $O(n^2 + m^2 \log m)$。

这种"预处理+查找"的思路在很多组合优化问题中都非常有效，特别是当我们需要频繁查询某种特定和的配对时。字典序比较的处理也展示了如何通过合适的排序策略来简化后续的比较操作。
