## 题目描述

$\texttt{Arnold Gerald Nostik}$ 先生负责设计镇上新大教堂的玫瑰窗。 玫瑰窗是圆形的，宽 $2r$ 单位。 $\texttt{Nostik}$ 先生选择使用几何图案：设 $n$ 为一个至少为 $4$ 的偶数整数。 他在距离窗中心 $r$ 的圆周上选取 $n$ 个点，构成一个正 $n$ 边形的顶点。 这些点用直线连接，形成的区域按示例着色。 对于 $n=8$ 的情况，有 $4$ 个区域，从中心向外编号为 $1, 2, 3, 4$。 一般情况下，有 $n/2$ 个区域。

你需要编写程序帮助 Nostik 先生计算建造给定玫瑰窗时，每个颜色区域所需的玻璃面积。

### 输入格式

输入以一个整数 $0 \leq m \leq 100000$ 开始； 接下来 $m$ 行，每行包含三个值： $r$ （一个 $1$ 到 $100$ 之间的实数）、 $n$ （一个 $4$ 到 $40$ 之间的偶数整数）、 $k$ （ $1 \leq k \leq n / 2$ ）。

### 输出格式

对于每组 $r$ 、 $n$ 、 $k$ ，输出半径为 $r$ 、有 $n$ 个点的玫瑰窗的第 $k$ 个区域的面积（平方单位），结果四舍五入到四位小数。

### 样例输入

```
4
50 8 3
9.238794 8 2
10 4 1
20 4 1
```

### 样例输出

```
2928.9322
100.0000
200.0000
800.0000
```

## 题目分析

这是一道几何计算问题。 我们需要理解玫瑰窗的构造方式并计算从中心向外第 $k$ 个环形区域的面积。

### 构造过程分析

1. **基础框架**： 画一个半径为 $r$ 的圆，在圆周上均匀取 $n$ 个点，构成正 $n$ 边形。

2. **连线规则**： 将圆周上相对的点用直线连接。 具体来说，对于 $n$ 个点（编号 $0$ 到 $n-1$ ），点 $i$ 与点 $i + n/2$ 连接（模 $n$ 运算）。 这样会形成 $n/2$ 条对角线，它们都经过圆心。

3. **区域形成**： 这些对角线将圆形区域分割成 $n/2$ 个嵌套的环形区域，从中心向外编号为 $1$ 到 $n/2$ 。

4. **关键观察**： 每个环形区域的边界是由两个相似的正 $n$ 边形组成的。 第 $k$ 个区域的外边界是第 $k$ 个正 $n$ 边形，内边界是第 $k-1$ 个正 $n$ 边形（对于 $k=1$ ，内边界退化为中心点）。

### 解题思路

问题的核心转化为：如何确定这些嵌套正 $n$ 边形的半径？ 一旦知道每个正 $n$ 边形的半径，就可以计算其面积，然后通过相邻多边形面积相减得到环形区域的面积。

#### 1. 确定嵌套正多边形的半径

观察对角线交点：
- 从顶点 $0$ 出发的对角线连接点 $0$ 和点 $n/2$ 。
- 从顶点 $1$ 出发的对角线连接点 $1$ 和点 $n/2+1$ 。
- 这两条对角线相交于一点，这个点恰好位于从中心向外第 $1$ 个正 $n$ 边形的顶点上。 该点到圆心的距离就是第 $1$ 个正 $n$ 边形的半径 $r_1$ 。

更一般地，对于第 $i$ 个正 $n$ 边形（从内向外编号， $i=1$ 为最内层）：
- 考虑从顶点 $0$ 到顶点 $n/2 + i$ 的直线 $L_1$ 。
- 考虑从顶点 $1$ 到顶点 $(n/2 + i + 1) \mod n$ 的直线 $L_2$ 。
- 计算 $L_1$ 和 $L_2$ 的交点 $P$ 。
- 第 $i$ 个正 $n$ 边形的半径 $r_i = |OP|$ ，即点 $P$ 到圆心 $O$ 的距离。

特殊值：
- $r_0 = 0$ （对应中心点）
- $r_{n/2} = r$ （对应最外层的圆）

#### 2. 计算正 $n$ 边形面积

已知正 $n$ 边形的半径 $R$ （即其外接圆半径），其面积公式为：
$$
S = \frac{n}{2} \cdot R^2 \cdot \sin\left(\frac{2\pi}{n}\right)
$$
这个公式可以通过将正 $n$ 边形分解为 $n$ 个全等的等腰三角形推导得出。

#### 3. 计算第 $k$ 个区域面积

- 对于 $k = n/2$ （最外层区域）：  
  面积 = 圆面积 - 第 $(n/2-1)$ 个正 $n$ 边形面积  
$$
  A_k = \pi r^2 - S_{n/2-1}
$$
- 对于 $1 \leq k < n/2$ （内层区域）：  
  面积 = 第 $k$ 个正 $n$ 边形面积 - 第 $(k-1)$ 个正 $n$ 边形面积  
$$
  A_k = S_k - S_{k-1}
$$
  其中 $S_k$ 表示半径为 $r_k$ 的正 $n$ 边形面积。

### 算法步骤

1. 读入数据组数 $m$ 。
2. 对于每组数据 $(r, n, k)$ ：
   a. 生成圆周上 $n$ 个等分点的坐标。
   b. 通过计算对角线交点，确定 $r_1, r_2, ..., r_{n/2-1}$ 。
   c. 设置 $r_0 = 0$ ， $r_{n/2} = r$ 。
   d. 计算每个 $r_i$ 对应的正 $n$ 边形面积 $S_i$ 。
   e. 根据 $k$ 的值，按上述公式计算第 $k$ 个区域的面积。
   f. 输出结果，保留四位小数。

### 复杂度分析

- 时间复杂度： 对于每组数据，需要计算最多 $n/2-1$ 个交点，每个交点计算为常数时间。 由于 $n \leq 40$ ， $m \leq 100000$ ，总计算量大约为 $O(m \cdot n)$ ，在合理范围内。
- 空间复杂度： $O(n)$ ，用于存储点坐标和半径。

### 注意事项

1. **精度处理**： 使用 `double` 类型进行计算，输出时使用 `printf` 控制小数位数。
2. **几何计算**： 使用复数类 `std::complex` 可以方便地进行向量运算。
3. **交点计算**： 确保使用稳定的直线交点公式，避免除零错误（在本题构造中，对角线不会平行）。

## 代码实现

```cpp
// Rose Windows

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);  // 圆周率
const int MAX_N = 40;          // n的最大值

// 使用复数表示二维点，方便进行向量运算
typedef complex<double> Point;

// 生成圆周上的n等分点（从正上方开始逆时针）
// 参数：r - 圆的半径，n - 等分数，points - 存储点坐标的数组
void generatePoints(double r, int n, Point points[]) {
    for (int i = 0; i < n; i++) {
        double angle = 2 * PI * i / n;  // 第i个点的角度
        // 计算点的坐标：x = r*cos(angle), y = r*sin(angle)
        points[i] = Point(cos(angle) * r, sin(angle) * r);
    }
}

// 计算两条直线的交点
// 参数：两条直线分别通过点a1-a2和点b1-b2
// 返回：交点坐标
Point lineIntersection(const Point& a1, const Point& a2, 
                       const Point& b1, const Point& b2) {
    // 计算向量
    Point a = a2 - a1;
    Point b = b2 - b1;
    
    // 使用参数方程求交点：a1 + t*a = b1 + s*b
    // 通过解线性方程组得到t
    double t = ((b1.real() - a1.real()) * b.imag() - 
                (b1.imag() - a1.imag()) * b.real()) /
               (a.real() * b.imag() - a.imag() * b.real());
    
    return a1 + t * a;
}

// 计算正n边形面积（n为偶数）
// 参数：r - 正n边形的半径（外接圆半径），n - 边数（偶数）
// 公式：S = (n/2) * r² * sin(2π/n)
double regularPolygonArea(double r, int n) {
    return (n / 2.0) * r * r * sin(2.0 * PI / n);
}

int main() {
    int m;  // 数据组数
    scanf("%d", &m);
    
    for (int tc = 0; tc < m; tc++) {
        double r;  // 圆的半径
        int n, k;  // n: 点数，k: 区域编号
        scanf("%lf %d %d", &r, &n, &k);
        
        Point points[MAX_N];  // 存储圆周上的点
        generatePoints(r, n, points);
        
        // 存储每一层正多边形的半径
        // radii[i] 表示第i个正多边形的半径，i从0到n/2
        double radii[MAX_N / 2 + 1];
        radii[0] = 0.0;            // 第0层：中心点
        radii[n / 2] = r;          // 第n/2层：外接圆
        
        // 计算第1层到第n/2-1层的半径
        for (int i = 1; i < n / 2; i++) {
            // 第一条直线：从顶点0到对面的顶点(n/2 + i)
            Point a1 = points[0];
            Point a2 = points[n / 2 + i];
            
            // 第二条直线：从顶点1到对面的顶点((n/2 + i + 1) % n)
            Point b1 = points[1];
            Point b2 = points[(n / 2 + i + 1) % n];
            
            // 计算两条直线的交点
            Point intersection = lineIntersection(a1, a2, b1, b2);
            
            // 交点到圆心的距离就是第i个正多边形的半径
            radii[i] = abs(intersection);
        }
        
        // 计算第k个区域的面积
        double area;
        if (k == n / 2) {
            // 最外层：圆面积 - 内层正多边形面积
            area = PI * r * r - regularPolygonArea(radii[n / 2 - 1], n);
        } else {
            // 内层：第k层正多边形面积 - 第(k-1)层正多边形面积
            area = regularPolygonArea(radii[k], n) - 
                   regularPolygonArea(radii[k - 1], n);
        }
        
        // 输出结果，保留4位小数
        printf("%.4lf\n", area);
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解玫瑰窗的几何构造，特别是通过对角线交点来确定嵌套正多边形的半径。 通过将问题分解为以下几个步骤：

1. 生成圆周等分点
2. 计算对角线交点得到各层正多边形的半径
3. 使用正多边形面积公式计算面积
4. 通过面积差得到每个区域的面积

这种方法避免了复杂的公式推导，直接通过几何计算得到结果，代码简洁且易于理解。 使用复数类进行向量运算可以大大简化几何计算的代码实现。
