## 题目描述

神秘矩阵是一个 $3$ 行 $N$ 列的矩阵，其中包含数字 $1, 2, \dots, 3N$，每个数字恰好出现一次。此外，所有行的和相等，所有列的和也相等。给定 $N$（$N$ 是 $3$ 的倍数且小于 $1000$），要求构造这样一个矩阵。若不存在，输出 $\texttt{IMPOSSIBLE}$。

## 题目分析

### 1. 必要条件推导

设矩阵有 $3$ 行 $N$ 列，总和为：

$$
S = \sum_{k=1}^{3N} k = \frac{3N(3N+1)}{2}
$$

设每行的和为 $R$，则 $3R = S$，解得：

$$
R = \frac{N(3N+1)}{2}
$$

设每列的和为 $C$，则 $N \cdot C = S$，解得：

$$
C = \frac{3(3N+1)}{2}
$$

由于 $C$ 必须是整数，因此 $3(3N+1)$ 为偶数 $\Rightarrow$ $3N+1$ 为偶数 $\Rightarrow$ $N$ 为奇数。又已知 $N$ 是 $3$ 的倍数，故令 $N = 3n$，则 $n$ 必须为奇数。即：

$$
N \equiv 3 \pmod{6}
$$

当 $N$ 不满足此条件时，直接输出 $\texttt{IMPOSSIBLE}$。

### 2. 问题转化

将 $3 \times N$ 矩阵看作 $n$ 个并排的 $3 \times 3$ 子矩阵（块），每个块有 $3$ 列。设每个块内使用一个固定的 $3 \times 3$ 幻方作为“模板”，然后对不同的块施加不同的平移量，使得全局行和与列和相等。

## 解题思路

### 1. 固定模板的选择

选用经典的洛书幻方：

$$
A = \begin{bmatrix}
8 & 1 & 6 \\
3 & 5 & 7 \\
4 & 9 & 2
\end{bmatrix}
$$

该矩阵满足每行和、每列和均为 $15$。

### 2. 平移基数的引入

对于第 $j$ 个块（$0 \le j < n$），定义平移基数 $G[i][j]$ 表示第 $i$ 行第 $j$ 块的整体偏移量。则块内第 $i$ 行、第 $k$ 列（$0 \le k < 3$）的最终数值为：

$$
value = A[i][k] + 9 \times G[i][j]
$$

由于 $A[i][k] \in [1, 9]$，加上 $9 \times G[i][j]$ 后，不同块使用不同的 $G[i][j]$ 即可覆盖 $1 \dots 9n$ 且不重复。实际上，要求 $G$ 是一个 $3 \times n$ 的矩阵，其所有元素构成 $\{0, 1, \dots, n-1\}$ 的一个排列（每列三个数互异，整体覆盖所有值）。

### 3. 列和相等的条件

对于固定的块 $j$ 和块内列 $k$，该列的三个数分别来自三行，列和为：

$$
\big(A[0][k] + A[1][k] + A[2][k]\big) + 9 \big(G[0][j] + G[1][j] + G[2][j]\big)
$$

已知 $\sum_{i=0}^2 A[i][k] = 15$，因此列和 $= 15 + 9 \times S_j$，其中 $S_j = G[0][j] + G[1][j] + G[2][j]$。要使所有列和相等，$S_j$ 必须是与 $j$ 无关的常数 $T$：

$$
G[0][j] + G[1][j] + G[2][j] = T, \quad \forall j
$$

### 4. 行和相等的条件

第 $i$ 行的总和为：

$$
\sum_{j=0}^{n-1} \sum_{k=0}^2 \big(A[i][k] + 9 G[i][j]\big) = 15n + 9 \sum_{j=0}^{n-1} G[i][j]
$$

令 $R_i = \sum_{j} G[i][j]$，则行和 $= 15n + 9 R_i$。要使三行和相等，需满足 $R_0 = R_1 = R_2$。

### 5. 构造 $G$ 矩阵

设 $n$ 为奇数。令常数 $T = \frac{3n-1}{2}$（这是整数，因为 $n$ 为奇数）。构造如下：

- 第 $0$ 行：$G[0][j] = j$，$j = 0, 1, \dots, n-1$
- 第 $1$ 行与第 $2$ 行通过递推生成：

$$
\begin{aligned}
G[1][0] &= \lfloor n/2 \rfloor \\
G[2][0] &= n-1 \\
G[1][i] &= G[2][i-1], \quad i \ge 1 \\
G[2][i] &= T - G[0][i] - G[1][i], \quad i \ge 1
\end{aligned}
$$

可以验证：
- 每列和 $G[0][j] + G[1][j] + G[2][j] = T$ 恒成立
- 每行和 $\sum_j G[i][j] = \frac{n(n-1)}{2}$ 均相等
- 所有 $G[i][j]$ 取遍 $0 \dots n-1$ 且每列三数互异

### 6. 最终数值生成

对于每个块 $j$ 和块内列 $k$，输出：

$$
A[i][k] + 9 \times G[i][j]
$$

按照行优先顺序输出三行，每行 $N = 3n$ 个数。

## 算法复杂度

时间复杂度 $O(N)$，空间复杂度 $O(N)$，完全满足 $N < 1000$ 的限制。

## 正确性验证（以 $N=3$ 为例）

此时 $n=1$，$T = (3 \times 1 - 1)/2 = 1$。

$G[0][0] = 0$，$G[1][0] = 0$，$G[2][0] = 0$（因为 $n-1=0$）。

最终矩阵：

- 第 $0$ 行：$A[0][0]+0, A[0][1]+0, A[0][2]+0 = 8, 1, 6$
- 第 $1$ 行：$3, 5, 7$
- 第 $2$ 行：$4, 9, 2$

行和均为 $15$，列和均为 $15$，正确。

## 参考代码

```cpp
// Mystical Matrix
// UVa ID: 10775
// Verdict: Accepted
// Submission Date: 2026-05-24
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 固定的 3x3 幻方模板
const int A[3][3] = {{8, 1, 6}, {3, 5, 7}, {4, 9, 2}};
int G[3][350];  // 平移基数矩阵，n <= 333 时够用

int main() {
    int n;
    while (cin >> n && n) {
        n /= 3;                     // N = 3n
        if (n % 2 == 0) {           // n 必须是奇数
            cout << "IMPOSSIBLE" << '\n';
            continue;
        }
        // 构造 G 矩阵
        for (int i = 0; i < n; ++i) G[0][i] = i;
        G[1][0] = n / 2, G[2][0] = n - 1;
        for (int i = 1; i < n; ++i) {
            G[1][i] = G[2][i - 1];
            G[2][i] = (n / 2 * 3) - G[0][i] - G[1][i];
        }
        // 输出最终矩阵
        for (int i = 0; i < 3; ++i) {
            for (int j = 0; j < n; ++j) {
                for (int k = 0; k < 3; ++k) {
                    if (j + k) cout << ' ';
                    cout << A[i][k] + 9 * G[i][j];
                }
            }
            cout << '\n';
        }
    }
    return 0;
}
```

## 总结

本题的核心在于将大矩阵分解为若干个 $3 \times 3$ 幻方块，并通过构造一个满足特定行和、列和条件的平移基数矩阵 $G$，巧妙地保证了全局行和与列和相等。该构造方法充分利用了 $n$ 为奇数的性质，通过简单的递推公式避免了复杂的搜索，是组合设计思想在编程竞赛中的典型应用。
