[UVa 10787 Modular Equations](https://blog.csdn.net/metaphysis/article/details/154302952)

## 题目分析

我们需要找到满足以下条件的整数三元组 $(a, b, m)$ 的数量：

$$(a + b) \bmod m = (a - b) \bmod m$$

其中：
- $a \in [amin, amax]$
- $b \in [bmin, bmax]$  
- $m \in [mmin, mmax]$

## 解题思路

### 关键化简

将原方程化简：
$$(a + b) \equiv (a - b) \pmod{m}$$

两边同时减去 $a$：
$$b \equiv -b \pmod{m}$$

即：
$$2b \equiv 0 \pmod{m}$$

这意味着：
$$m \mid 2b$$

### 算法优化

关键观察：**变量 $a$ 在条件中完全消失**，因此对于任意满足 $m \mid 2b$ 的 $(b, m)$ 对，所有 $a \in [amin, amax]$ 都构成有效解。

因此：
- 对于每个 $b$，找出所有满足 $m \mid 2b$ 且 $m \in [mmin, mmax]$ 的 $m$
- 有效三元组数量 = 满足条件的 $(b, m)$ 对数 × $(amax - amin + 1)$

### 特殊情况处理

- 当 $b = 0$ 时，$2b = 0$，任何 $m$ 都满足条件
- 对于其他 $b$，枚举 $|2b|$ 的所有正因数，检查是否在 $m$ 的范围内

#include <bits/stdc++.h>
using namespace std;

vector<int> getDivisors(int n) {
    vector<int> divisors;
    int absN = abs(n);
    for (int i = 1; i * i <= absN; ++i) {
        if (absN % i == 0) {
            divisors.push_back(i);
            if (i != absN / i) {
                divisors.push_back(absN / i);
            }
        }
    }
    return divisors;
}

int main() {
    int T;
    cin >> T;
    for (int t = 1; t <= T; ++t) {
        int amin, amax, bmin, bmax, mmin, mmax;
        cin >> amin >> amax >> bmin >> bmax >> mmin >> mmax;
        
        long long aCount = amax - amin + 1;
        long long validPairs = 0;
        
        for (int b = bmin; b <= bmax; ++b) {
            int x = 2 * b;
            if (x == 0) {
                validPairs += (mmax - mmin + 1);
            } else {
                vector<int> divisors = getDivisors(x);
                for (int d : divisors) {
                    if (d >= mmin && d <= mmax && (abs(x) % d == 0)) {
                        validPairs++;
                    }
                }
            }
        }
        
        long long result = validPairs * aCount;
        cout << "Case " << t << ": " << result << endl;
    }
    return 0;
}
