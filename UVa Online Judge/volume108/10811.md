## 题目分析

本题是一个概率动态规划问题，需要计算在特定下注策略下，在给定轮次范围内实现盈利的概率。

### 游戏规则理解

$\texttt{Stan}$ 和 $\texttt{Ollie}$ 玩“皇冠与船锚” ($\texttt{Crown \& Anchor}$) 赌博游戏：
- 有 $6$ 种符号：皇冠 (`Crown`)、船锚 (`Anchor`)、梅花 (`Club`)、方块 (`Diamond`)、红心 (`Heart`)、黑桃 (`Spade`)
- 轮盘有 $28$ 个可能的停止位置，只有 $14$ 种不同的符号组合，每种组合出现两次
- $14$ 种组合的具体构成如下：
  - $6$ 种三个相同符号的组合
  - $6$ 种两个相同符号、一个不同符号的组合
  - $2$ 种三个不同符号的组合

根据题目给出的具体组合，我们可以计算出对于任意指定符号：
- 出现 $3$ 次的位置数：$2$ 个
- 出现 $2$ 次的位置数：$2$ 个
- 出现 $1$ 次的位置数：$4$ 个
- 出现 $0$ 次的位置数：$20$ 个

因此，单轮游戏中指定符号出现次数的概率分布为：
- $P_0 = \frac{20}{28} = \frac{5}{7}$ （出现 $0$ 次）
- $P_1 = \frac{4}{28} = \frac{1}{7}$ （出现 $1$ 次）
- $P_2 = \frac{2}{28} = \frac{1}{14}$ （出现 $2$ 次）
- $P_3 = \frac{2}{28} = \frac{1}{14}$ （出现 $3$ 次）

### 下注策略

$\texttt{Stan}$ 使用蒙特卡洛下注策略的变种：
- 初始赌注为 $1$（最小赌注）
- 如果赢了，下一轮赌注重置为 $1$
- 如果输了，下一轮赌注加倍
- 如果加倍后的赌注超过赌场上限 $l$，则重置为 $1$

这个策略的目的是通过一次赢利来弥补之前的连续亏损。但需要注意的是，每次赢利只收回之前的损失并赚取最小赌注的利润，而连续亏损会导致赌注指数级增长。

### 获胜条件

$\texttt{Stan}$ 赢得赌局的条件是：**在进行了至少 $k$ 轮之后，且在 $m+1$ 轮之前，他的净收益为正**。也就是说，从第 $k$ 轮到第 $m$ 轮之间的任何时刻，一旦净收益变为正数，$\texttt{Stan}$ 立即获胜。

注意：第 $k$ 轮之前净收益为正不算获胜，必须等到第 $k$ 轮及之后。

## 解题思路

### 状态定义

使用深度优先搜索 ($\texttt{DFS}$) 加备忘录的方法来求解。定义状态为三元组 $(net, round, stage)$：
- $net$：当前净收益（可正可负）
- $round$：当前轮数（从 $1$ 开始）
- $stage$：当前阶段，表示连续输的次数，决定了当前赌注为 $2^{stage}$

### 状态转移

对于当前状态 $(net, round, stage)$：
1. 首先检查赌注是否超过上限。如果 $2^{stage} > l$，则将 $stage$ 重置为 $0$，表示本轮使用最小赌注
2. 计算当前赌注 $bet = 2^{stage}$（如果超过上限则 $bet = 1$）
3. 根据四种可能的游戏结果进行转移：
   - 出现 $0$ 次（输）：净收益减少 $bet$，$stage$ 增加 $1$（连续输次数加 $1$）
   - 出现 $1$ 次（赢 $1$ 倍）：净收益增加 $bet$，$stage$ 重置为 $0$
   - 出现 $2$ 次（赢 $2$ 倍）：净收益增加 $2 \times bet$，$stage$ 重置为 $0$
   - 出现 $3$ 次（赢 $3$ 倍）：净收益增加 $3 \times bet$，$stage$ 重置为 $0$

### 终止条件

- 如果 $round > k$ 且 $net > 0$：说明在第 $k$ 轮之后净收益为正，$\texttt{Stan}$ 获胜，返回 $1.0$
- 如果 $round > m$：说明已经超过最大轮数仍未获胜，返回 $0.0$

### 备忘录优化

由于状态空间有限（$net$ 范围有限，$round \leq 30$，$stage \leq \log_2 l \leq 10$），可以使用备忘技巧记录已计算过的状态，避免重复递归，大大提高效率。

### 概率计算

当前状态 $(net, round, stage)$ 的获胜概率为：
$$P = P_0 \times dfs(net - bet, round+1, stage+1) + P_1 \times dfs(net + bet, round+1, 0) + P_2 \times dfs(net + 2 \times bet, round+1, 0) + P_3 \times dfs(net + 3 \times bet, round+1, 0)$$

其中 $P_0, P_1, P_2, P_3$ 为前面推导的概率分布。

## 代码实现

```cpp
// Up the Ante
// UVa ID: 10811
// Verdict: Accepted
// Submission Date: 2026-03-01
// UVa Run Time: 0.060s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double P0 = 5.0 / 7.0;  // 20/28
const double P1 = 1.0 / 7.0;  // 4/28
const double P2 = 1.0 / 14.0; // 2/28
const double P3 = 1.0 / 14.0; // 2/28

int k, m, l;
map<tuple<int, int, int>, double> dp;

double dfs(int net, int round, int stage) {
    if (round > k && net > 0) return 1.0;
    if (round > m) return 0.0;
    auto key = make_tuple(net, round, stage);
    if (dp.count(key)) return dp[key];
     // 检查赌注是否超限，如果超限则重置stage
    int currentStage = stage;
    if ((1 << currentStage) > l) currentStage = 0;
    int bet = 1 << currentStage;
    double r = 0.0;
    // 输：净收益减少bet，stage+1
    r += P0 * dfs(net - bet, round + 1, currentStage + 1);
    // 赢1次：净收益增加bet，stage重置为0
    r += P1 * dfs(net + bet, round + 1, 0);
    // 赢2次：净收益增加2*bet，stage重置为0
    r += P2 * dfs(net + 2 * bet, round + 1, 0);
    // 赢3次：净收益增加3*bet，stage重置为0
    r += P3 * dfs(net + 3 * bet, round + 1, 0);
    return dp[key] = r;
}

int main() {
    int n;
    scanf("%d", &n);
    while (n--) {
        scanf("%d %d %d", &k, &m, &l);
        dp.clear();
        printf("%.4f\n", dfs(0, 1, 0));
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(m \times \log l \times range(net))$，其中 $range(net)$ 是净收益的可能范围。由于 $m \leq 30$，$\log l \leq 10$，$net$ 范围有限，实际运行速度很快。
- **空间复杂度**：$O(m \times \log l \times range(net))$，使用备忘录存储已计算的状态。

## 总结

本题的关键点在于：
1. 正确推导每个符号出现次数的概率分布
2. 准确理解获胜条件：必须在第 $k$ 轮及之后净收益为正
3. 正确处理赌注上限：当赌注超过上限时，重置为最小赌注
4. 使用 $\texttt{DFS}$ 加备忘录的方法避免重复计算

通过以上分析和实现，我们可以得到符合题目要求的答案。对于样例输入 $k=3, m=4, l=10$，输出为 $0.5835$。
