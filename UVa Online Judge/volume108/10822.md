## 题目描述

在二十五世纪，太空探索已经成熟。科学家在一个邻近的螺旋臂中的绿色行星上发现了一个未知物种。根据星际法律，科学家只能通过望远镜观察这些物种，不能干涉它们的行为。

研究发现以下关键信息：

- 每个个体属于三个种族之一："石头"($\texttt{Rock}$)、"布"($\texttt{Paper}$)或"剪刀"($\texttt{Scissors}$)
- 不同种族个体相遇时，支配关系遵循：
  - 石头支配剪刀
  - 剪刀支配布  
  - 布支配石头
- 同一种族个体不会相遇
- 个体生活在封闭社区中，不同社区个体不相遇

你的任务是编写程序，读取相遇记录并判断：在任意给一个个体分配种族后，是否能唯一确定社区中所有个体的种族。

## 输入格式

第一行是社区数量 $T$ ($T \leq 1000$)

对于每个社区：
- 一行包含个体数 $n$ ($n \leq 5000$) 和相遇记录数 $m$
- 随后是多行相遇记录，格式为 $(M>N)$，表示个体 $M$ 支配个体 $N$
- 记录每行最多 $10$ 个，除换行外无其他空白字符

## 输出格式

对于每个社区输出：
- $\texttt{Observation Complete}$：可唯一确定所有个体种族
- $\texttt{Not Enough Data}$：无法确定一个或多个个体的种族  
- $\texttt{Conflicting Records}$：存在冲突的记录

**优先级**：冲突 > 数据不足 > 观察完成

## 题目分析

### 问题本质

这是一个图论问题，我们需要：

1. **构建有向图**：节点代表个体，边 $(u,v)$ 表示 $u$ 支配 $v$
2. **种族分配约束**：如果 $u$ 支配 $v$，那么：
   - 若 $u$ 是石头，则 $v$ 必须是剪刀
   - 若 $u$ 是布，则 $v$ 必须是石头
   - 若 $u$ 是剪刀，则 $v$ 必须是布

### 关键洞察

1. **连通性决定唯一性**：
   - 如果图的**无向底图**连通，则从一个节点的种族可以唯一确定所有节点的种族
   - 如果无向底图不连通，不同连通分量可以独立选择起始种族，无法唯一确定

2. **冲突检测**：
   - 在种族分配传播过程中，如果出现矛盾则存在冲突
   - 冲突检测优先级最高

### 算法思路

1. **构建无向底图**：将有向图转换为无向图来检测连通分量
2. **寻找连通分量**：使用 $\texttt{DFS}$ 找到所有连通分量
3. **种族分配与冲突检测**：对每个连通分量进行 $\texttt{BFS}$ 种族分配
4. **结果判断**：
   - 存在冲突 → $\texttt{Conflicting Records}$
   - 无冲突且连通分量数为 $1$ → $\texttt{Observation Complete}$  
   - 无冲突但连通分量数 $>1$ → $\texttt{Not Enough Data}$

## 解题步骤详解

### 步骤 1：图构建

读取输入并构建两个图：
- $\texttt{graph}$：原始有向图，存储支配关系
- $\texttt{undirectedGraph}$：无向底图，用于连通性分析

### 步骤 2：连通分量检测

使用 $\texttt{DFS}$ 遍历无向底图，找到所有连通分量。这帮助我们理解图的结构。

### 步骤 3：种族分配算法

对每个连通分量：
1. 任意选择起始节点，分配为石头（种族 $1$）
2. 使用 $\texttt{BFS}$ 传播种族分配：
   - 对于边 $(u,v)$：根据 $u$ 的种族计算 $v$ 的预期种族
   - 如果 $v$ 未分配，则分配预期种族
   - 如果 $v$ 已分配但与预期不符，则发现冲突
3. 同时处理反向边以确保完整性

### 步骤 4：结果判定

按照优先级判断：
1. 冲突检测优先
2. 连通分量数决定唯一性
3. 连通则观察完成，否则数据不足

## 复杂度分析

- **时间复杂度**：$O(n + m)$，其中 $n$ 是节点数，$m$ 是边数
- **空间复杂度**：$O(n + m)$，用于存储图结构

## 代码实现

```cpp
// Planet of the Rock Paper and Scissors

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 5005;

vector<int> graph[MAXN];      // 有向图的邻接表
vector<int> undirectedGraph[MAXN];  // 无向图的邻接表（底图）
int race[MAXN];               // 记录每个节点的种族：0=未确定，1=石头，2=布，3=剪刀
bool visited[MAXN];           // 记录节点是否被访问
int n, m;                     // 节点数和边数

// 根据当前种族和支配关系确定下一个种族
int getNextRace(int currentRace) {
    if (currentRace == 1) return 3;  // 石头支配剪刀
    if (currentRace == 2) return 1;  // 布支配石头
    if (currentRace == 3) return 2;  // 剪刀支配布
    return 0;
}

// 构建无向底图
void buildUndirectedGraph() {
    for (int i = 1; i <= n; i++) {
        undirectedGraph[i].clear();
    }
    for (int u = 1; u <= n; u++) {
        for (int v : graph[u]) {
            undirectedGraph[u].push_back(v);
            undirectedGraph[v].push_back(u);
        }
    }
}

// DFS遍历无向图找到连通分量
void dfsUndirected(int u, vector<int>& component) {
    visited[u] = true;
    component.push_back(u);
    for (int v : undirectedGraph[u]) {
        if (!visited[v]) {
            dfsUndirected(v, component);
        }
    }
}

// 在连通分量内进行BFS种族分配，返回是否发现冲突
bool bfsInComponent(const vector<int>& component) {
    if (component.empty()) return false;
    
    queue<int> q;
    int start = component[0];
    q.push(start);
    
    // 任意分配起始节点为石头
    race[start] = 1;
    
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        
        for (int v : graph[u]) {
            int expectedRace = getNextRace(race[u]);
            
            if (race[v] == 0) {
                // 如果邻居未分配，根据支配关系分配
                race[v] = expectedRace;
                q.push(v);
            } else if (race[v] != expectedRace) {
                // 如果邻居已分配但与预期不符，发现冲突
                return true;
            }
        }
        
        // 处理指向当前节点的边（反向传播）
        for (int w : component) {
            for (int v : graph[w]) {
                if (v == u) {  // 如果w指向u
                    // 根据u的种族推断w应该是什么（反向推理）
                    int expectedRaceForW;
                    if (race[u] == 1) expectedRaceForW = 2;  // 石头被布支配
                    else if (race[u] == 2) expectedRaceForW = 3;  // 布被剪刀支配
                    else if (race[u] == 3) expectedRaceForW = 1;  // 剪刀被石头支配
                    else expectedRaceForW = 0;
                    
                    if (expectedRaceForW != 0) {
                        if (race[w] == 0) {
                            race[w] = expectedRaceForW;
                            q.push(w);
                        } else if (race[w] != expectedRaceForW) {
                            return true;
                        }
                    }
                }
            }
        }
    }
    return false;
}

int main() {
    int communities;
    cin >> communities;
    
    for (int comm = 1; comm <= communities; comm++) {
        cin >> n >> m;
        
        // 初始化
        for (int i = 1; i <= n; i++) {
            graph[i].clear();
            race[i] = 0;
            visited[i] = false;
        }
        
        // 读取边信息
        string line;
        getline(cin, line);  // 读取换行符
        
        int edgesRead = 0;
        while (edgesRead < m) {
            getline(cin, line);
            for (int i = 0; i < line.length(); i++) {
                if (line[i] == '(') {
                    int u = 0, v = 0;
                    i++;  // 跳过 '('
                    
                    // 读取第一个数字
                    while (isdigit(line[i])) {
                        u = u * 10 + (line[i] - '0');
                        i++;
                    }
                    
                    i++;  // 跳过 '>'
                    
                    // 读取第二个数字  
                    while (isdigit(line[i])) {
                        v = v * 10 + (line[i] - '0');
                        i++;
                    }
                    
                    graph[u].push_back(v);
                    edgesRead++;
                }
            }
        }
        
        // 构建无向底图并找到所有连通分量
        buildUndirectedGraph();
        for (int i = 1; i <= n; i++) visited[i] = false;
        
        vector<vector<int>> components;
        for (int i = 1; i <= n; i++) {
            if (!visited[i]) {
                vector<int> component;
                dfsUndirected(i, component);
                components.push_back(component);
            }
        }
        
        // 重置种族状态
        for (int i = 1; i <= n; i++) race[i] = 0;
        
        bool hasConflict = false;
        
        // 对每个连通分量进行检查，优先检测冲突
        for (const auto& component : components) {
            if (hasConflict) break;
            if (bfsInComponent(component)) {
                hasConflict = true;
            }
        }
        
        // 输出结果（冲突检测优先级最高）
        cout << "Community " << comm << ": ";
        if (hasConflict) 
            cout << "Conflicting Records" << endl;
        else if (components.size() == 1) 
            cout << "Observation Complete" << endl;
        else 
            cout << "Not Enough Data" << endl;
    }
    
    return 0;
}
```

## 总结

本题通过图论建模和连通性分析，巧妙地解决了种族唯一确定性问题。关键在于理解：

1. **无向底图的连通性**决定种族分配的唯一性
2. **支配关系的传递性**用于种族分配传播  
3. **冲突检测的优先级**高于其他判断条件

算法结合了 $\texttt{DFS}$ 的连通分量检测和 $\texttt{BFS}$ 的种族分配传播，确保了正确性和高效性。
