## 题目描述

给定两个整数 $M$ ($3 \leq M \leq 6$) 和 $N$ ($4 \leq N \leq 400$)，我们需要找到一个 $M$ 位的 $N$ 进制数 $X$，使得当 $X$ 乘以 $2, 3, \ldots, M$ 时，得到的结果都是 $X$ 的一个**重排**（$\texttt{anagram}$）。也就是说，这些乘积结果的各位数字与 $X$ 的各位数字完全相同，只是顺序不同。

### 示例
对于 $M = 6$, $N = 10$（十进制），数字 $142857$ 满足条件：
- $2 \times 142857 = 285714$
- $3 \times 142857 = 428571$  
- $4 \times 142857 = 571428$
- $5 \times 142857 = 714285$
- $6 \times 142857 = 857142$

这些乘积结果都是 $142857$ 的数字重排。

题目保证对于每对 $(M, N)$，最多只有一个这样的数字存在。如果不存在，输出 `Not found.`。

## 题目分析

### 关键观察

1. **数字唯一性**：从示例可以看出，这类神奇数字的所有数字都是不同的。如果存在重复数字，重排验证会变得复杂，且题目示例也支持这一观察。

2. **个位数约束**：设原数的个位数为 $d$，那么：
   - $2X$ 的个位数 = $(2d) \mod N$
   - $3X$ 的个位数 = $(3d) \mod N$
   - $\ldots$
   - $MX$ 的个位数 = $(Md) \mod N$
   
   由于这些都是 $X$ 的重排，所以集合 $\{d, 2d \mod N, 3d \mod N, \ldots, Md \mod N\}$ 必须包含在 $X$ 的数字集合中，且这些个位数必须互不相同。

3. **首位约束**：由于乘以 $M$ 后仍然是 $M$ 位数，原数的首位数字 $d_0$ 必须满足 $M \times d_0 < N$。

### 解题思路

基于以上观察，我们可以采用以下策略：

1. **枚举个位数**：遍历所有可能的个位数字 $d$ ($1 \leq d < N$)。

2. **收集必需数字**：对于每个个位数 $d$，计算 $2d \mod N, 3d \mod N, \ldots, Md \mod N$，将这些数字与 $d$ 一起构成必需的数字集合。

3. **验证集合大小**：如果必需数字集合的大小正好等于 $M$，说明这个个位数候选是可行的。

4. **生成排列验证**：对于每个可行的个位数候选，生成其数字集合的所有排列，对于每个排列：
   - 检查首位不为 $0$ 且满足首位约束
   - 将排列转换为实际的 $N$ 进制数
   - 验证该数乘以 $2, 3, \ldots, M$ 后是否都是原数的重排

5. **输出结果**：找到满足条件的数字后，输出其各位数字（从最高位到最低位）；如果遍历完所有可能性都没有找到，输出 `Not found.`。

### 算法优化

- **剪枝策略**：在生成排列时，如果首位不满足约束条件，可以立即跳过。
- **提前终止**：一旦找到满足条件的数字，立即返回结果。
- **高效验证**：通过排序比较来验证两个数字是否是重排，时间复杂度为 $O(M \log M)$。

### 复杂度分析

- 个位数候选数量：$O(N)$
- 每个候选的排列数量：$O(M!)$
- 每个排列的验证：$O(M^2 \log M)$

由于 $M \leq 6$，$M! = 720$，$N \leq 400$，总操作量在可接受范围内。

#include <bits/stdc++.h>
using namespace std;

vector<int> findAmazingNumber(int m, int n) {
    for (int lastDigit = 1; lastDigit < n; lastDigit++) {
        set<int> digitsSet;
        digitsSet.insert(lastDigit);
        for (int k = 2; k <= m; k++) digitsSet.insert((lastDigit * k) % n);
        
        if (digitsSet.size() == m) {
            vector<int> digits(digitsSet.begin(), digitsSet.end());
            do {
                if (digits[0] == 0 || digits[0] * m >= n) continue;
                
                long long num = 0;
                for (int d : digits) num = num * n + d;
                
                vector<int> sortedOrig = digits;
                sort(sortedOrig.begin(), sortedOrig.end());
                bool valid = true;
                
                for (int k = 2; k <= m && valid; k++) {
                    long long product = num * k;
                    if (product >= (long long)pow(n, m)) { valid = false; break; }
                    
                    vector<int> prodDigits(m);
                    long long temp = product;
                    for (int i = m - 1; i >= 0; i--) {
                        prodDigits[i] = temp % n;
                        temp /= n;
                    }
                    
                    sort(prodDigits.begin(), prodDigits.end());
                    if (sortedOrig != prodDigits) valid = false;
                }
                
                if (valid) return digits;
            } while (next_permutation(digits.begin(), digits.end()));
        }
    }
    return vector<int>();
}

int main() {
    int m, n;
    while (cin >> m >> n && (m || n)) {
        vector<int> result = findAmazingNumber(m, n);
        if (result.empty()) cout << "Not found." << endl;
        else {
            for (int i = 0; i < m; i++) cout << (i ? " " : "") << result[i];
            cout << endl;
        }
    }
    return 0;
}

## 总结

本题的关键在于利用个位数的数学性质来大幅缩小搜索空间。通过分析个位数在乘法运算中的行为，我们可以预先确定数字必须包含哪些数字，从而避免枚举所有可能的 $M$ 位 $N$ 进制数。这种结合数学洞察力和算法优化的方法，使得我们能够在合理时间内解决问题。

算法的时间复杂度主要取决于 $M$ 的大小，由于 $M \leq 6$，排列生成和验证的开销是可接受的。这种思路在解决类似的数学组合问题时非常有用。
