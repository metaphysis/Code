## 题目描述

$\texttt{Gerg}$ 正在举办派对，他邀请了朋友们参加。目前已有 $p$ 个朋友到达，但还有 $a$ 个朋友迟到。为了招待已到达的客人，$\texttt{Gerg}$ 尝试组织团队游戏，但他发现无法将这 $p$ 个客人分成**人数相等且大于 $1$ 人**的组。

幸运的是，他准备了备用计划——一个正方形蛋糕。$\texttt{Gerg}$ 希望将蛋糕切成**大小相等的正方形小块**。他需要为每个迟到的朋友保留一块蛋糕，剩下的蛋糕块必须**平均分配**给 $p$ 个在场的客人。$\texttt{Gerg}$ 自己不需要蛋糕。

问题是：是否存在一种切分蛋糕的方式，使得上述分配要求得到满足？

### 输入格式
输入包含多个测试用例。每个测试用例一行，包含两个整数：非负整数 $a$ 和正整数 $p$。$a$ 和 $p$ 都在 $32$ 位有符号整数范围内。输入以 `-1 -1` 结束。

### 输出格式
对于每个测试用例，如果可以公平分配蛋糕，输出 `Yes`，否则输出 `No`。

## 题目分析

### 关键条件分析

首先，题目中提到一个重要条件：**无法将 $p$ 个客人分成人数相等且大于 $1$ 人的组**。这个条件意味着：

- 如果 $p > 1$，那么 $p$ 必须是**质数**
- 如果 $p = 1$，自然无法分组（只有一个人）

这是因为只有当 $p$ 是质数时，才没有除了 $1$ 和 $p$ 本身之外的因子，因此无法分成人数相等且大于 $1$ 人的组。

### 数学模型建立

设蛋糕被切成 $n \times n$ 个小正方形块，总块数为 $n^2$。

分配要求：
1. 为 $a$ 个迟到朋友保留 $a$ 块蛋糕
2. 剩下的 $n^2 - a$ 块蛋糕要能被 $p$ 整除

因此，我们需要找到整数 $n \geq 1$，使得：
$$n^2 \equiv a \pmod{p}$$

换句话说，$a$ 必须是模 $p$ 的**平方剩余**。

### 数学解法

由于 $p$ 是质数（或 $1$），我们可以使用**欧拉准则**来判断 $a$ 是否是模 $p$ 的平方剩余：

对于奇质数 $p$，$a$ 是模 $p$ 的平方剩余当且仅当：
$$a^{(p-1)/2} \equiv 1 \pmod{p}$$

特殊情况处理：
- 如果 $p = 1$，总是有解（只有一个人）
- 如果 $a \equiv 0 \pmod{p}$，总是有解（$n = kp$ 是解）
- 如果 $p = 2$，总是有解（模 $2$ 下只有 $0$ 和 $1$，都是平方数）

## 算法设计

### 解题步骤

1. **特殊情况处理**：
   - 如果 $p = 1$，直接返回 `Yes`
   - 对 $a$ 取模 $p$ 简化计算
   - 如果简化后的 $a = 0$，返回 `Yes`
   - 如果 $p = 2$，返回 `Yes`

2. **一般情况**：
   - 使用欧拉准则计算 $a^{(p-1)/2} \bmod p$
   - 如果结果为 $1$，返回 `Yes`，否则返回 `No`

### 复杂度分析

- **时间复杂度**：$O(\log p)$，主要来自快速幂运算
- **空间复杂度**：$O(1)$，只使用常数额外空间

该算法能够高效处理 $p$ 的最大值（$2^{31}-1$）。

#include <iostream>
using namespace std;

long long modPow(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) {
            result = (result * base) % mod;
        }
        base = (base * base) % mod;
        exp >>= 1;
    }
    return result;
}

bool canShareCake(long long a, long long p) {
    if (p == 1) return true;
    a %= p;
    if (a == 0) return true;
    if (p == 2) return true;
    return modPow(a, (p - 1) / 2, p) == 1;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    long long a, p;
    while (cin >> a >> p) {
        if (a == -1 && p == -1) break;
        if (canShareCake(a, p)) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    return 0;
}
```

```

### 样例 2
```

输出：Yes
解释：1024 ÷ 17 = 60余4，4是模17的平方剩余（2² ≡ 4 mod 17）

输出：No
解释：2不是模101的平方剩余
```

输出：Yes
解释：p=1，总是有解

## 总结

本题的关键在于理解题目中关于分组条件的隐含信息：$p$ 必须是 $1$ 或质数。基于这一洞察，我们可以使用欧拉准则高效判断平方剩余问题，从而解决蛋糕分配问题。

算法的时间复杂度和空间复杂度都很优秀，能够处理题目给定的数据范围。
