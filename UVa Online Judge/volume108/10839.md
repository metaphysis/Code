## 题目描述

杰克船长刚刚击败巴博萨船长，夺回了黑珍珠号，但发现自己还受困于巴博萨的最后一个诅咒。诅咒将杰克困在三座岛屿之间（我们称之为岛屿 $1$、$2$、$3$）。杰克必须从岛屿 $1$ 出发，按照特定规则访问这三座岛屿若干次，最后回到岛屿 $1$ 才能解除诅咒。

### 访问规则
1. 总访问次数为 $N$，且 $N = 3M + 1$ 的形式，其中岛屿 $1$ 访问 $M+1$ 次，岛屿 $2$ 和 $3$ 各访问 $M$ 次。
2. 不允许在同一个岛屿上连续访问（即不能有 $i$ → $i$ 的移动）。
3. 一旦使用了某个方向的边（如 $1$ → $2$），就不能再使用其反向边（$2$ → $1$）。

### 任务
给定 $N$，计算满足条件的不同路径数量。杰克船长需要这个数字来解除诅咒。

### 输入格式
- 第一行：测试用例数量 $T$（$T \leq 40$）。
- 接下来 $T$ 行：每行一个整数 $N$（$N \leq 100$），保证 $N = 3M + 1$。

### 输出格式
对于每个测试用例，输出一行：`Case i: answer`，其中 $i$ 为用例编号，$answer$ 为路径数量。

## 题目分析

### 问题本质
这是一个**有向图中的路径计数问题**，需要计算从节点 $1$ 出发，经过特定次数访问各节点后回到节点 $1$ 的路径数，且每条有向边最多只能使用一次。

### 关键约束解析
1. **边使用限制**：每条有向边（$1$→$2$、$2$→$1$、$1$→$3$、$3$→$1$、$2$→$3$、$3$→$2$）最多使用一次。这意味着路径中不能出现"往返"现象。
2. **访问次数要求**：岛屿 $1$ 需要访问 $M+1$ 次，岛屿 $2$ 和 $3$ 各访问 $M$ 次。
3. **起点和终点**：必须从岛屿 $1$ 出发并回到岛屿 $1$。

### 问题简化
由于每条边只能使用一次，且有三座岛屿，实际上路径可以看作是按照某种"单调"顺序遍历岛屿。通过分析样例和推导，可以发现这个问题可以通过**递归+记忆化搜索**解决。

## 解题思路

### 状态定义
定义递归函数 $f(a, b, c)$，表示：
- 当前所在位置**隐含为岛屿 $1$**
- 还需要访问岛屿 $1$ $a$ 次
- 还需要访问岛屿 $2$ $b$ 次  
- 还需要访问岛屿 $3$ $c$ 次

时的路径数量。

### 状态转移
#### 基础情况（$a = 1$）
当只剩下最后一次访问岛屿 $1$ 时：
- 如果 $b = 0$ 且 $c = 0$，无法形成有效路径，返回 $0$
- 如果 $b = c$，有两种对称的路径，返回 $2$
- 如果 $|b - c| = 1$，只有一种路径，返回 $1$
- 其他情况返回 $0$

#### 递归情况（$a > 1$）
1. **对称减少**：同时访问岛屿 $2$ 和 $3$ $i$ 次（$i \geq 1$）
   $$f(a, b, c) += 2 \times f(a-1, b-i, c-i)$$
   乘以 $2$ 是因为有两种对称的访问模式。

2. **非对称减少**：分别访问岛屿 $2$ 或 $3$
   - 多访问一次岛屿 $2$：$f(a, b, c) += f(a-1, b-1-i, c-i)$
   - 多访问一次岛屿 $3$：$f(a, b, c) += f(a-1, b-i, c-1-i)$

### 最终答案计算
设 $M = N / 3$（注意不是 $(N-1)/3$）：
- 当 $N = 1$ 时，答案为 $1$
- 当 $M$ 为奇数时：$ans = f(M, M, M) / 2$
- 当 $M$ 为偶数时：$ans = [f(M, M, M) + f(M/2, M/2, M/2)] / 2$

这里除以 $2$ 是因为路径的对称性，需要避免重复计数。

### 大整数处理
由于答案可能非常大（最多 $40$ 位数字），需要使用高精度整数。我们实现一个简单的万进制（$\texttt{BASE} = 10000$）大整数类，支持加、乘、除操作。

### 时间复杂度
状态数最多为 $O(M^3)$，其中 $M \leq 33$，加上记忆化搜索，可以在规定时间内完成计算。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int BASE = 10000;
struct BigInt {
    vector<int> d;
    BigInt(long long x = 0) {
        if (!x) d.push_back(0);
        while (x) d.push_back(x % BASE), x /= BASE;
    }
    BigInt operator+(const BigInt& b) const {
        BigInt r;
        r.d.clear();
        int carry = 0, sz = max(d.size(), b.d.size());
        for (int i = 0; i < sz || carry; ++i) {
            int sum = carry;
            if (i < d.size()) sum += d[i];
            if (i < b.d.size()) sum += b.d[i];
            r.d.push_back(sum % BASE);
            carry = sum / BASE;
        }
        while (r.d.size() > 1 && !r.d.back()) r.d.pop_back();
        return r;
    }
    BigInt operator*(long long x) const {
        BigInt r;
        r.d.resize(d.size() + 10, 0);
        long long carry = 0;
        for (int i = 0; i < d.size() || carry; ++i) {
            long long sum = carry;
            if (i < d.size()) sum += 1LL * d[i] * x;
            r.d[i] = sum % BASE;
            carry = sum / BASE;
        }
        while (r.d.size() > 1 && !r.d.back()) r.d.pop_back();
        return r;
    }
    BigInt operator/(long long x) const {
        BigInt r;
        r.d.clear();
        vector<int> tmp = d;
        reverse(tmp.begin(), tmp.end());
        long long rr = 0;
        for (int v : tmp) {
            rr = rr * BASE + v;
            r.d.push_back(rr / x);
            rr %= x;
        }
        reverse(r.d.begin(), r.d.end());
        while (r.d.size() > 1 && !r.d.back()) r.d.pop_back();
        return r;
    }
    friend ostream& operator<<(ostream& os, const BigInt& b) {
        os << b.d.back();
        for (int i = b.d.size() - 2; i >= 0; --i)
            os << setw(4) << setfill('0') << b.d[i];
        return os;
    }
};

const int MAX = 35;
BigInt dp[MAX][MAX][MAX];
bool visited[MAX][MAX][MAX];

BigInt dfs(int a, int b, int c) {
    if (a == 0 && b == 0 && c == 0) return BigInt(0);
    if (visited[a][b][c]) return dp[a][b][c];
    if (a == 1) {
        if (b == 0 && c == 0) return dp[a][b][c] = BigInt(0);
        if (b == c) return dp[a][b][c] = BigInt(2);
        if (abs(b - c) == 1) return dp[a][b][c] = BigInt(1);
        return dp[a][b][c] = BigInt(0);
    }
    visited[a][b][c] = true;
    BigInt r(0);
    for (int i = 1; b - i >= 0 && c - i >= 0; ++i)
        r = r + dfs(a - 1, b - i, c - i) * 2;
    for (int i = 0; b - i >= 0 && c - i >= 0; ++i) {
        if (b - i - 1 >= 0) r = r + dfs(a - 1, b - i - 1, c - i);
        if (c - i - 1 >= 0) r = r + dfs(a - 1, b - i, c - i - 1);
    }
    return dp[a][b][c] = r;
}

int main() {
    int T; cin >> T;
    for (int tc = 1; tc <= T; ++tc) {
        int N; cin >> N;
        if (N == 1) { cout << "Case " << tc << ": 1\n"; continue; }
        int M = N / 3;
        memset(visited, 0, sizeof visited);
        BigInt r = (M % 2 == 0) ? (dfs(M, M, M) + dfs(M / 2, M / 2, M / 2)) / 2 : dfs(M, M, M) / 2;
        cout << "Case " << tc << ": " << r << "\n";
    }
    return 0;
}
```

## 算法总结

本题的难点在于正确理解"反向路线"限制，并将其转化为可计算的数学模型。通过定义合理的状态和转移方程，结合记忆化搜索和高精度整数处理，可以高效解决此问题。

### 关键点
1. **状态设计**：将问题转化为递归形式，减少状态维度。
2. **对称性处理**：利用路径的对称性简化计算。
3. **大整数运算**：万进制实现提高了计算效率。
4. **边界条件**：正确处理 $N = 1$ 和 $M$ 的奇偶性。

### 复杂度分析
- 时间复杂度：$O(M^4)$（最坏情况），但由于 $M \leq 33$，实际运行很快。
- 空间复杂度：$O(M^3)$，用于存储记忆化结果。

这个解法充分利用了问题的特殊结构，避免了暴力枚举所有路径，是解决此类计数问题的典型方法。
