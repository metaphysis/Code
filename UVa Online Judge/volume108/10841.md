## 题目描述

你位于一栋摩天大楼的 $0$ 层，目标是尽快到达第 $k$ 层。大楼有 $n$ 部电梯（ $1 \leq n \leq 50$ ），每部电梯以不同的速度运行：电梯 $i$ 在相邻楼层间移动需要 $T_i$ 秒（ $1 \leq T_i \leq 100$ ）。每部电梯只停靠特定楼层，且不一定每层都停靠。更复杂的是，你不知道电梯的初始位置——每部电梯可能停在其可达的任何楼层。

你只能乘坐停靠当前楼层的电梯，并且可以在任何楼层换乘电梯，前提是两部电梯都在该楼层停靠。换乘需要 $5$ 秒（退出电梯并按下另一个电梯按钮）。你不能同时呼叫多部电梯：按下某个电梯按钮后，其他按钮将被禁用，直到该电梯到达。

**核心问题**： 在最坏情况下（电梯初始位置对你最不利），计算从 $0$ 层到 $k$ 层所需的最短时间。如果无法到达，输出 `IMPOSSIBLE`。

## 题目分析

### 1. 关键约束条件

1. **电梯初始位置未知**： 这是问题最核心的难点。当你第一次呼叫电梯 $e$ 时，它可能位于其可达楼层中的任意一个，且会选择离你最远的位置（最坏情况）。
2. **换乘成本**： 每次换乘电梯需要额外 $5$ 秒。
3. **电梯停靠限制**： 电梯只停靠特定楼层，你只能在其停靠楼层上下或换乘。
4. **单次呼叫**： 一次只能呼叫一部电梯，必须等待它到达后才能进行下一步操作。

### 2. 问题本质

这是一个 **带约束的最短路径问题** ，但需要计算 **最坏情况下的最小时间** 。我们需要找到一个策略（电梯使用序列），使得在所有可能的电梯初始位置中，该策略的最大完成时间最小。

## 解题思路

### 1. 核心观察

**每部电梯最多被使用一次**

*证明*： 假设最优路径中电梯 $e$ 被使用了两次。第一次使用时，电梯从最坏位置 $S_1$ 到达楼层 $A$ ，然后我们乘坐它到楼层 $B$ 。第二次使用时，电梯从位置 $B$ （我们离开它的地方）到达楼层 $C$ ，然后乘坐到楼层 $D$ 。我们可以调整策略：第一次直接乘坐电梯 $e$ 从 $A$ 到 $D$ （可能经过 $B$ 和 $C$ ），这样总时间不会增加（可能减少换乘时间和额外等待时间）。因此，任何最优路径中，每部电梯最多被使用一次。

这个观察极大地简化了问题：我们不需要记录电梯的当前位置，只需要知道哪些电梯已经被使用过。

### 2. 状态定义

由于每部电梯最多使用一次，我们可以用 **状态压缩** 来表示电梯使用情况。定义状态为：

- $floor$ ：当前所在楼层（ $0$ 到 $99$ ）
- $elev$ ：当前正在使用的电梯编号（ $-1$ 表示无电梯）
- $mask$ ：位掩码（ $long\\ long$ 类型），表示已经使用过的电梯集合
- $time$ ：当前已花费的时间

状态总数：楼层数（ $100$ ）× 电梯数（ $n+1$ ）× 状态数（ $2^n$ ）。虽然理论状态数很大，但实际可达状态很少，可以使用优先队列进行剪枝。

### 3. 状态转移

#### 3.1 预计算首次等待时间

对于电梯 $e$ 和楼层 $f$ ，当第一次在楼层 $f$ 呼叫电梯 $e$ 时，最坏等待时间为：

$$firstWait[e][f] = \max_{s \in stops[e]} |f - s| \times T[e]$$

其中 $stops[e]$ 是电梯 $e$ 停靠的楼层集合。

#### 3.2 初始状态

在 $0$ 层，如果没有电梯停靠，直接输出 “IMPOSSIBLE” 。否则，初始状态为 $(0, -1, 0, 0)$ （在 $0$ 层，无电梯，未使用任何电梯，时间 $0$ ）。

#### 3.3 状态转移规则

1. **当前无电梯**（ $elev = -1$ ）：
   - 可以呼叫任何停靠当前楼层且未使用过的电梯 $e$ 。
   - 新时间 = 当前时间 $+ firstWait[e][floor]$ （第一次呼叫，无换乘时间）。
   - 新状态：楼层不变，电梯变为 $e$ ，掩码加入 $e$ 。

2. **当前有电梯**（ $elev \geq 0$ ）：
   - **在电梯内移动**：可以乘坐当前电梯到其停靠的任何其他楼层。
     - 新时间 = 当前时间 $+ |nextFloor - curFloor| \times T[elev]$
     - 新状态：楼层变为 $nextFloor$ ，其他不变。
   - **换乘到新电梯**：在当前楼层，可以换乘到其他停靠该楼层且未使用过的电梯 $e$ 。
     - 新时间 = 当前时间 $+ 5 + firstWait[e][floor]$ （ $5$ 秒换乘时间）
     - 新状态：楼层不变，电梯变为 $e$ ，掩码加入 $e$ 。

### 4. 算法流程

1. **预处理**：计算 $firstWait$ 数组。
2. **初始化**：将初始状态加入优先队列（按时间最小排序）。
3. **$\texttt{Dijkstra}$ 搜索**：
   - 每次取出时间最小的状态。
   - 如果当前楼层为 $k$ ，更新答案。
   - 根据当前状态（有无电梯）进行状态转移。
   - 使用 $dist$ 数组记录每个状态的最短时间，进行剪枝。
4. **输出结果**：如果找到解，输出最小时间；否则输出 `IMPOSSIBLE`。

### 5. 复杂度分析

- **时间复杂度**： 状态数最多 $O(100 \times n \times 2^n)$ ，但实际远远达不到。使用优先队列和剪枝，在实际数据中可接受。
- **空间复杂度**： 使用哈希表存储 $dist$ ，只保存实际访问的状态。

## 代码实现

```cpp
// Lift Hopping in the Real World
// UVa ID: 10841
// Verdict: Accepted
// Submission Date: 2025-12-30
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int MAX_F = 100;
const int MAX_N = 50;

int n, k;
int T[MAX_N];
vector<int> stops[MAX_N];
bool reachable[MAX_F][MAX_N];
int firstWait[MAX_N][MAX_F];  // 电梯e第一次在楼层f被呼叫的最坏等待时间

// 预处理：计算每部电梯在每个楼层的首次等待时间
void precomputeFirstWait() {
    for (int e = 0; e < n; e++) {
        for (int f = 0; f < MAX_F; f++) {
            int maxWait = 0;
            for (int s : stops[e]) {
                maxWait = max(maxWait, abs(f - s) * T[e]);
            }
            firstWait[e][f] = maxWait;
        }
    }
}

struct State {
    int floor;
    int elev;       // 当前使用的电梯，-1表示无电梯
    long long mask; // 已使用过的电梯集合
    int time;
    State(int f, int e, long long m, int t) : floor(f), elev(e), mask(m), time(t) {}
    bool operator>(const State& other) const {
        return time > other.time;  // 小顶堆
    }
};

void solve() {
    // 目标楼层就是0层
    if (k == 0) {
        cout << 0 << endl;
        return;
    }
    
    // 检查是否有电梯停靠0层
    bool hasElevatorAt0 = false;
    for (int e = 0; e < n; e++) {
        if (reachable[0][e]) {
            hasElevatorAt0 = true;
            break;
        }
    }
    if (!hasElevatorAt0) {
        cout << "IMPOSSIBLE" << endl;
        return;
    }
    
    precomputeFirstWait();
    
    // dist[floor][elev+2][mask] 使用unordered_map减少内存
    // elev索引：-1 -> n+1, 其他 -> elev
    vector<vector<unordered_map<long long, int>>> dist(
        MAX_F, vector<unordered_map<long long, int>>(n + 2));
    priority_queue<State, vector<State>, greater<State>> pq;
    
    // 初始状态：在0层，无电梯
    dist[0][n + 1][0] = 0;  // n+1表示无电梯（对应elev=-1）
    pq.push(State(0, -1, 0, 0));
    
    int answer = INF;
    
    while (!pq.empty()) {
        State cur = pq.top(); pq.pop();
        int curFloor = cur.floor;
        int curElev = cur.elev;
        long long curMask = cur.mask;
        int curTime = cur.time;
        
        // 剪枝：如果当前时间已经超过已知最优解
        if (curTime >= answer) continue;
        
        // 验证当前状态是否最优
        int elevIdx = (curElev == -1) ? n + 1 : curElev;
        auto& distMap = dist[curFloor][elevIdx];
        auto it = distMap.find(curMask);
        if (it != distMap.end() && curTime > it->second) continue;
        
        // 到达目标楼层，更新答案
        if (curFloor == k) {
            answer = curTime;
            continue;
        }
        
        if (curElev == -1) {
            // 情况1：无电梯，可以呼叫停靠当前楼层的新电梯
            for (int e = 0; e < n; e++) {
                if (reachable[curFloor][e] && !((curMask >> e) & 1)) {
                    long long newMask = curMask | (1LL << e);
                    int waitTime = firstWait[e][curFloor];
                    int newTime = curTime + waitTime;  // 第一次呼叫，没有换乘时间
                    
                    auto& newDistMap = dist[curFloor][e];
                    if (newDistMap.find(newMask) == newDistMap.end() || newTime < newDistMap[newMask]) {
                        newDistMap[newMask] = newTime;
                        pq.push(State(curFloor, e, newMask, newTime));
                    }
                }
            }
        } else {
            // 情况2：有电梯，可以在电梯内移动
            for (int nextFloor : stops[curElev]) {
                if (nextFloor == curFloor) continue;
                
                int moveTime = abs(nextFloor - curFloor) * T[curElev];
                int newTime = curTime + moveTime;
                
                auto& newDistMap = dist[nextFloor][curElev];
                if (newDistMap.find(curMask) == newDistMap.end() || newTime < newDistMap[curMask]) {
                    newDistMap[curMask] = newTime;
                    pq.push(State(nextFloor, curElev, curMask, newTime));
                }
            }
            
            // 情况3：有电梯，可以换乘到新电梯
            for (int e = 0; e < n; e++) {
                if (e != curElev && reachable[curFloor][e] && !((curMask >> e) & 1)) {
                    long long newMask = curMask | (1LL << e);
                    int waitTime = firstWait[e][curFloor];
                    int newTime = curTime + 5 + waitTime;  // 5秒换乘时间
                    
                    auto& newDistMap = dist[curFloor][e];
                    if (newDistMap.find(newMask) == newDistMap.end() || newTime < newDistMap[newMask]) {
                        newDistMap[newMask] = newTime;
                        pq.push(State(curFloor, e, newMask, newTime));
                    }
                }
            }
        }
    }
    
    if (answer == INF) {
        cout << "IMPOSSIBLE" << endl;
    } else {
        cout << answer << endl;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string line;
    while (getline(cin, line)) {
        if (line.empty()) continue;
        stringstream ss(line);
        if (!(ss >> n >> k)) break;
        
        // 读取电梯运行时间
        getline(cin, line);
        stringstream ss2(line);
        for (int i = 0; i < n; i++) ss2 >> T[i];
        
        // 初始化
        memset(reachable, 0, sizeof reachable);
        for (int i = 0; i < n; i++) stops[i].clear();
        
        // 读取电梯停靠楼层
        for (int i = 0; i < n; i++) {
            getline(cin, line);
            stringstream ss3(line);
            int floor;
            while (ss3 >> floor) {
                stops[i].push_back(floor);
                reachable[floor][i] = true;
            }
        }
        
        solve();
    }
    
    return 0;
}
```

## 总结

本题的关键在于 **发现每部电梯最多使用一次** 这一性质，从而可以使用状态压缩动态规划。通过预计算电梯首次等待时间，并结合 $\texttt{Dijkstra}$ 算法进行状态搜索，我们能够在合理的时间内求解最坏情况下的最小时间。虽然状态空间理论很大，但实际剪枝效果很好，能够通过所有测试数据。

**算法核心**： 状态压缩 + 优先队列搜索 + 最坏情况预处理。

**时间复杂度**： $O(100 \times n \times 2^n)$ 理论最坏，实际远小于。

**空间复杂度**： $O(100 \times n \times 2^n)$ 理论最坏，实际使用哈希表存储访问状态。
