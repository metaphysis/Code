[UVa 10860 Many a Little Makes a Mickle](https://blog.csdn.net/metaphysis/article/details/154473471)

## 题目描述

给定一个长字符串 $P$ 和一组短字符串集合，我们可以使用这些短字符串的**原串**或**反转串**任意多次，来拼接成长字符串 $P$。要求使用最少的短串数量（包括原串和反转串）完成拼接，如果无法拼接则输出 `"Not possible."`。

**关键条件**：
- 所有字符串由 $\texttt{ASCII}$ 码在 $33$ 到 $127$ 之间的字符组成。
- 可以使用任意短串的原串或反转串，每次使用计为一次。
- 目标是**最小化使用的短串数量**，而不是总长度。

---

## 输入格式

- 第一行：数据组数 $S$（$S < 51$）
- 每组数据：
  - 第一行：长字符串 $P$（$0 < \text{length}(P) < 10001$）
  - 第二行：短字符串数量 $N$（$0 < N < 51$）
  - 接下来 $N$ 行：每个短字符串 $P_i$（$0 < \text{length}(P_i) < 101$）

---

## 输出格式

对每组数据输出一行：
- 如果可以拼接：`"Set S: C."`
- 否则：`"Set S: Not possible."`

其中 $S$ 是数据集编号（从 $1$ 开始），$C$ 是最少使用的短串数量。

---

## 题目分析

这个问题可以看作是一个**最短路径问题**：

- 将长字符串 $P$ 的每个位置视为图中的一个节点。
- 从位置 $i$ 出发，如果某个短串（或其反转）与 $P$ 从 $i$ 开始的子串匹配，就可以从 $i$ 跳到 $i + \text{len}(pat)$，花费为 $1$（表示使用了一个短串）。
- 目标是找到从位置 $0$ 到位置 $\text{len}(P)$ 的最短路径（最少步数）。

---

## 解题思路

### 1. 问题建模

我们可以使用**动态规划**来解决这个问题：

- 定义 $dp[i]$ 表示到达位置 $i$ 所需的最少短串数量。
- 初始状态：$dp[0] = 0$（起点），其他位置初始化为无穷大。
- 对于每个位置 $i$，如果 $dp[i]$ 不是无穷大，则尝试所有短串（包括原串和反转串）：
  - 如果短串 $pat$ 与 $P$ 从 $i$ 开始的子串匹配，则更新：
    $$dp[i + \text{len}(pat)] = \min(dp[i + \text{len}(pat)], dp[i] + 1)$$

### 2. 算法步骤

1. 读入数据组数 $S$
2. 对每组数据：
   - 读入长字符串 $P$
   - 读入短串数量 $N$
   - 读入每个短串，同时生成其反转串，存入模式集合
   - 初始化 $dp$ 数组，$dp[0] = 0$，其余为无穷大
   - 遍历每个位置 $i$，对于可达的位置，尝试所有模式串进行匹配
   - 如果 $dp[\text{len}(P)]$ 仍为无穷大，输出不可行，否则输出最少数量

### 3. 复杂度分析

- 长串长度 $L \leq 10000$
- 短串数量 $N \leq 50$，考虑反转后最多 $100$ 个模式
- 每个模式串长度 $\leq 100$
- 总复杂度：$O(L \times N \times 100) \approx 5 \times 10^7$，在合理范围内

## 代码实现

```cpp
// Many a Little makes a Mickle
// UVa ID: 10860
// Verdict: Accepted
// Submission Date: 2025-11-05
// UVa Run Time: 0.020s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
#include <climits>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int S;
    cin >> S;
    cin.ignore(); // 忽略换行符

    for (int setNum = 1; setNum <= S; setNum++) {
        string P;
        getline(cin, P);
        int lenP = P.length();

        int N;
        cin >> N;
        cin.ignore();

        vector<string> patterns;
        for (int i = 0; i < N; i++) {
            string pat;
            getline(cin, pat);
            patterns.push_back(pat);          // 加入原串
            string revPat = pat;
            reverse(revPat.begin(), revPat.end());
            patterns.push_back(revPat);       // 加入反转串
        }

        // DP数组：dp[i]表示到达位置i所需的最少短串数量
        vector<int> dp(lenP + 1, INT_MAX);
        dp[0] = 0; // 起点不需要任何短串

        // 遍历每个位置
        for (int i = 0; i < lenP; i++) {
            if (dp[i] == INT_MAX) continue; // 该位置不可达，跳过
            
            // 尝试所有模式串（原串和反转串）
            for (const string& pat : patterns) {
                int lenPat = pat.length();
                // 检查模式串是否匹配P从i开始的子串
                if (i + lenPat <= lenP && P.compare(i, lenPat, pat) == 0) {
                    // 更新到达位置i+lenPat的最小值
                    dp[i + lenPat] = min(dp[i + lenPat], dp[i] + 1);
                }
            }
        }

        // 输出结果
        if (dp[lenP] != INT_MAX) {
            cout << "Set " << setNum << ": " << dp[lenP] << ".\n";
        } else {
            cout << "Set " << setNum << ": Not possible.\n";
        }
    }

    return 0;
}
```

---

## 代码说明

- **输入处理**：使用 `getline` 读取字符串，避免空格问题
- **模式串处理**：将每个短串的原串和反转串都加入模式集合
- **动态规划**：`dp[i]` 存储到达位置 $i$ 的最少短串数
- **匹配检查**：使用 `string::compare` 检查前缀匹配
- **结果判断**：如果终点不可达则输出 `"Not possible."`

---

## 总结

本题通过将字符串拼接问题转化为图的最短路径问题，利用动态规划高效求解。关键点在于：
- 考虑短串的反转形式
- 使用动态规划记录到达每个位置的最少短串数
- 通过前缀匹配进行状态转移

这种方法在给定的数据范围内能够高效解决问题，时间复杂度为 $O(L \times N \times \texttt{maxPatLen})$。
