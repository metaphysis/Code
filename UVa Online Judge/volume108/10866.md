## 题目翻译

一个比特串，若其长度比某个质数小 $1$ ，则它可能是**魔法的**。例如 $1001$ 就是一个魔法串。为了理解“魔法”的含义，我们在其末尾添加一个非比特字符 $x$ ，将得到的新序列视为一个**循环串**，并按照以下规则构建一个比特方阵：

*   第一行取原串的每一位（即原串本身）；
*   第二行从原串的第二位开始，每隔一位取一个比特；
*   第三行从原串的第三位开始，每隔两位取一个比特；
*   ……
*   第 $k$ 行从原串的第 $k$ 位开始，每隔 $k-1$ 位取一个比特。

矩阵的行数等于原比特串的长度。由于扩展后的序列长度为质数，追加的 $x$ 永远不会被用到。

如果这个矩阵的**每一行**要么是原比特串，要么是原比特串的补串（即 $0$ 变 $1$ ， $1$ 变 $0$ ），那么原比特串就被称为**魔法的**。

### 输入格式

输入包含多组数据。每组数据一行，包含一个质数 $p$ （ $p \le 100000$ ）。输入以一行单独的数字 $0$ 结束，该行无需处理。

### 输出格式

对于每个输入的质数 $p$ ，输出一行。如果存在长度为 $p-1$ 的非常数（即不是全 $0$ 或全 $1$ ）魔法比特串，则输出其中**字典序最小**的一个。否则，输出字符串 `Impossible` 。

### 样例输入

```
5
3
17
47
2
79
0
```

### 样例输出

```
0110
01
0010111001110100
0000100001101010001101100100111101111
Impossible
0010011000010110100000010011110011101010101000110000110111110100111110011011
```

## 题目分析与解题思路

本题初看非常抽象，关键在于理解“魔法”条件的数学本质，并找到构造方法。

### 1. 数学建模与规律转化

设原比特串为 $a_1a_2...a_{n}$ ，其中 $n = p-1$ ， $p$ 为质数。
“每 $m$ 个取一个比特”这个操作，在循环串的意义下，相当于取下标模 $p$ 同余的序列。

矩阵的第 $m$ 行（ $1 \le m \le n$ ）由比特 $a_m, a_{2m \mod p}, a_{3m \mod p}, ..., a_{nm \mod p}$ 构成。

“每一行是原串或原串的补串”这一条件，意味着对于任意 $m$ ，序列 $\{a_{km \mod p}\}$ （ $k=1..n$ ）必须要么完全等于 $\{a_k\}$ ，要么完全等于 $\{a_k\}$ 的逐位取反。

通过数论分析（涉及有限域上原根的性质），可以推导出这个条件等价于：

比特串 $a_i$ （ $i=1..n$ ）必须满足性质：对于任意 $i$ ， $a_i = a_1$ 当且仅当 $i$ 是模 $p$ 的**二次剩余**；否则 $a_i \ne a_1$ 。

> **补充说明**：模 $p$ 的二次剩余是指存在整数 $x$ 使得 $x^2 \equiv i \pmod{p}$ 成立的 $i$ 。 $1$ 总是二次剩余。

### 2. 存在性结论与构造方法

根据上述等价条件，我们可以得出重要结论：
1.  **对于奇质数 $p$（ $p > 2$ ）**：总是存在非常数的魔法串。因为模 $p$ 的二次剩余和非二次剩余的数量都是 $(p-1)/2$ ，既不全为 $0$ 也不全为 $1$ 。
2.  **对于 $p = 2$**：此时 $n = 1$ ，长度为 $1$ 的非常数字符串只能是 `"0"` 或 `"1"` 。但根据规则，矩阵只有一行（原串本身），它既等于原串也等于其补串的条件是矛盾的（除非串为空，但长度不为 $0$ ），因此不存在非常数的魔法串，输出 `Impossible`。

为了得到**字典序最小**的串，我们令 $a_1 = 0$ （因为 $1$ 是二次剩余，且 `0` 的字典序小于 `1`）。
那么构造规则就非常清晰了：
- 对于 $i = 1$ ， $a_1 = 0$ 。
- 对于 $i = 2, 3, ..., p-1$ ：
    - 如果 $i$ 是模 $p$ 的二次剩余，则 $a_i = 0$ 。
    - 如果 $i$ 是模 $p$ 的**非**二次剩余，则 $a_i = 1$ 。

### 3. 如何高效判断二次剩余？

判断一个数 $i$ 是否为模奇质数 $p$ 的二次剩余，可以使用**欧拉判别准则**：

计算 $i^{(p-1)/2} \mod p$ 。
- 如果结果为 $1$ ，则 $i$ 是模 $p$ 的二次剩余。
- 如果结果为 $p-1$ （即 $-1 \mod p$ ），则 $i$ 是模 $p$ 的非二次剩余。

由于 $p$ 可高达 $10^5$ ，我们需要快速计算这个幂。这可以通过**快速幂取模**算法在 $O(\log p)$ 时间内完成。

### 4. 算法流程总结

1.  读入质数 $p$ 。
2.  若 $p == 2$ ，直接输出 `"Impossible"` 。
3.  初始化一个长度为 $p-1$ 的字符串 `result` ，全部填充为 `'0'` （因为 $1$ 是二次剩余，且我们设 $a_1=0$ ）。
4.  对于 $i$ 从 $2$ 到 $p-1$ ：
    - 使用快速幂计算 `leg = powMod(i, (p-1)/2, p)` 。
    - 如果 `leg == 1` ，则 `result[i-1] = '0'` （ $i$ 是二次剩余）。
    - 否则（ `leg == p-1` ）， `result[i-1] = '1'` （ $i$ 是非二次剩余）。
5.  输出 `result` 。

该算法的时间复杂度为 $O(p \log p)$ ，对于 $p \le 10^5$ 可以在规定时间内完成。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 快速幂取模：计算 (a^b) % mod
long long powMod(long long a, long long b, long long mod) {
    long long result = 1;
    while (b > 0) {
        if (b & 1) result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}

// 判断是否存在并构造魔法比特串
string solve(int p) {
    // 根据数论结论，当 p = 2 时是特殊情况，没有非平凡的魔法串
    if (p == 2) return "Impossible";
    string result(p - 1, '0'); // 初始化全0串
    // 根据原根的性质，当 p 为奇素数时，存在非平凡的魔法串
    // 构造方法：result[i] = (powMod(i+1, p-2, p) > 1) ? '0' : '1'
    // 但这里采用更直接的构造：对于 i 从 1 到 p-1，如果 i 是模 p 的二次剩余，则对应位置为 0，否则为 1
    // 而 1 总是二次剩余，所以 result[0] 固定为 0
    result[0] = '0';
    for (int i = 2; i <= p - 1; i++) {
        // 利用勒让德符号判断 i 是否为模 p 的二次剩余
        // 当 i^((p-1)/2) % p == 1 时，i 是二次剩余，对应位为 0
        if (powMod(i, (p - 1) / 2, p) == 1) result[i - 1] = '0';
        else result[i - 1] = '1';
    }
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int p;
    while (cin >> p and p != 0) cout << solve(p) << "\n";
    return 0;
}
```
