## 题目描述

詹姆斯·邦德需要从一座桥上跳下逃生，他使用了一根蹦极绳。绳子的一端固定在桥上，另一端系在身上。我们需要判断他是否能安全落地。

**三种可能的结果：**
- 绳子太短或太强，永远无法到达地面：输出 `"Stuck in the air."`
- 绳子太长或太弱，落地速度超过 $10 , \text{m/s}$：输出 `"Killed by the impact."`
- 绳子合适，安全落地：输出 `"James Bond survives."`

**物理参数：**
- 重力：$9.81 , \text{m/s}^2$
- 体重：$w , \text{kg}$
- 绳子的弹性系数：$k$
- 绳子的原长：$l , \text{m}$
- 桥的高度：$s , \text{m}$

## 题目分析

这是一个基于物理的能量守恒问题。我们需要计算邦德落地时的速度，并根据速度判断结果。

### 关键物理原理

1. **能量守恒定律**：在整个下落过程中，机械能守恒
2. **重力势能**：$E_p = mgh$
3. **弹性势能**：$E_e = \frac{1}{2} k (\Delta l)^2$
4. **动能**：$E_k = \frac{1}{2} mv^2$

### 两种情况分析

#### 情况一：绳子从未拉直 ($l \geq s$)

如果绳子的原长大于等于桥高，邦德将一直自由落体直到地面。

**速度计算：**
$$v = \sqrt{2gs}$$

**判断条件：**
- 如果 $v > 10$：`"Killed by the impact."`
- 否则：`"James Bond survives."`
#### 情况二：绳子会拉直 ($l < s$)

邦德先自由落体 $l$ 米，然后绳子开始拉伸，在弹性力和重力的共同作用下继续下落。

**能量守恒方程：**
在桥顶（初始状态）的能量等于在地面时的能量：

$$mgs = \frac{1}{2} k (s - l)^2 + \frac{1}{2} mv^2$$

**解得速度平方：**
$$v^2 = 2gs - \frac{k}{w} (s - l)^2$$

**判断条件：**
1. 如果 $v^2 < 0$：无法到达地面，`"Stuck in the air."`
2. 如果 $v > 10$：速度过快，`"Killed by the impact."`
3. 否则：安全落地，`"James Bond survives."`

## 解题思路

1. **读取输入**：持续读取四个浮点数 $k, l, s, w$
2. **终止条件**：当输入为四个 $0$ 时结束程序
3. **情况判断**：
   - 如果 $l \geq s$：按自由落体计算
   - 如果 $l < s$：按弹性运动计算
4. **结果输出**：根据物理计算的结果输出相应字符串

## 算法复杂度

- **时间复杂度**：$O(1)$，每个测试用例只需常数时间计算
- **空间复杂度**：$O(1)$，只使用常数空间

## 代码实现

```cpp
// Bungee Jumping
// UVa ID: 10868
// Verdict: Accepted
// Submission Date: 2025-11-06
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <cmath>
#include <iomanip>

using namespace std;

const double g = 9.81;

int main() {
    double k, l, s, w;
    
    while (cin >> k >> l >> s >> w) {
        if (k == 0 && l == 0 && s == 0 && w == 0) {
            break;
        }
        
        // 绳子从未拉直的情况（自由落体）
        if (l >= s) {
            double v = sqrt(2 * g * s);
            if (v > 10.0) {
                cout << "Killed by the impact." << endl;
            } else {
                cout << "James Bond survives." << endl;
            }
            continue;
        }
        
        // 绳子拉直后的情况
        // 正确的能量守恒公式：m*g*s = 0.5*k*(s-l)² + 0.5*m*v²
        double v_squared = 2 * g * s - (k / w) * (s - l) * (s - l);
        
        // 如果速度为虚数，说明无法到达地面
        if (v_squared < 0) {
            cout << "Stuck in the air." << endl;
        } else {
            double v = sqrt(v_squared);
            if (v > 10.0) {
                cout << "Killed by the impact." << endl;
            } else {
                cout << "James Bond survives." << endl;
            }
        }
    }
    
    return 0;
}
```

## 样例验证

以第一个样例 `350 20 30 75` 为例：

- $l = 20 < s = 30$，属于情况二
- $v^2 = 2 \times 9.81 \times 30 - \frac{350}{75} \times (30-20)^2$
- $v^2 = 588.6 - 4.6667 \times 100 = 121.93$
- $v = \sqrt{121.93} \approx 11.04 > 10$
- 输出：`"Killed by the impact."`

与题目给出的样例输出完全一致。

## 总结

本题通过物理能量守恒原理，将复杂的运动过程简化为能量计算问题。关键在于正确理解两种不同情况下的能量转换关系，并准确应用能量守恒方程。这种方法避免了复杂的微分方程求解，使问题变得简洁明了。
