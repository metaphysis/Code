## 题目描述

斯坦（$\texttt{Stan}$）和奥利（$\texttt{Ollie}$）玩一个叫做“奇数布朗尼点”（$\texttt{Odd Brownie Points}$）的游戏。平面上有 $n$ 个布朗尼点，坐标为整数。斯坦先手，在平面上画一条垂直线，这条线必须穿过一个布朗尼点，并且可以穿过多个具有相同 $x$ 坐标的点。然后奥利画一条水平线，这条线必须穿过已经被垂直线穿过的某个布朗尼点。

这两条线将平面分成四个象限。包含任意大正坐标点的象限是右上象限。

玩家根据象限中的布朗尼点数得分。如果一个布朗尼点被某条线穿过，则不计分。斯坦获得右上和左下象限中（未被穿过的）布朗尼点的分数；奥利获得左上和右下象限中（未被穿过的）布朗尼点的分数。

斯坦和奥利都试图最大化自己的分数。斯坦出手时，他会考虑奥利的应对，选择一条能最大化自己最小可能得分的线。

**输入**： 包含多个测试用例。每个测试用例的第一行包含一个正奇数 $1 < n < 200000$，表示布朗尼点的数量。接下来的 $n$ 行每行包含两个整数，表示布朗尼点的 $x$ 和 $y$ 坐标。没有两个布朗尼点在同一位置。输入以一行包含 $0$ 结束。

**输出**： 对于每个测试用例，输出一行。第一个数字是斯坦能确保自己的最大得分。剩余的数字是奥利可能的（高）得分，按递增顺序排列。

## 题目分析

这是一个博弈论与计算几何相结合的问题。斯坦先选择一条垂直线 $x = X$，奥利后选择一条水平线 $y = Y$，且点 $(X, Y)$ 必须存在。两条线将平面分为四个象限：

1. **右上象限**：$x > X$ 且 $y > Y$
2. **右下象限**：$x > X$ 且 $y < Y$
3. **左上象限**：$x < X$ 且 $y > Y$
4. **左下象限**：$x < X$ 且 $y < Y$

**斯坦得分**：右上 + 左下  
**奥利得分**：左上 + 右下

**关键点**：被任意一条线穿过的点都不计入任何象限。因此：
- 所有 $x = X$ 的点被垂直线穿过，不计分
- 所有 $y = Y$ 的点被水平线穿过，不计分

### 博弈过程

1. 斯坦选择垂直线 $x = X$（必须穿过至少一个点）
2. 奥利选择水平线 $y = Y$（必须满足点 $(X, Y)$ 存在）
3. 奥利会选择最大化自己得分的 $Y$
4. 斯坦在选择 $X$ 时，会考虑奥利的最优应对，然后选择能让自己得分最大化的 $X$

更形式化地说：
- 对于每个可能的 $X$（每个不同的 $x$ 坐标）：
  - 对于该 $X$ 上的每个 $Y$（即每个在该竖线上的点）：
    - 计算如果奥利选择这个 $Y$ 时，斯坦的得分和奥利的得分
  - 奥利会选择 **最大化自己得分** 的 $Y$（可能多个 $Y$ 使得奥利得分相同且都是最大）
  - 在这些奥利的最优选择中，斯坦会得到 **最小的** 得分
  - 记录这个 $X$ 对应的：斯坦的最小可能得分，以及奥利在最优选择下可能得到的分数
- 斯坦会选择 **最大化自己最小可能得分** 的 $X$
- 最终输出：斯坦的最大保证得分，以及所有能使斯坦达到该得分的 $X$ 对应的奥利可能得分（去重排序）

### 问题转化

对于点 $(X, Y)$ 作为交点时：
- 斯坦得分 = （右侧且 $y > Y$ 的点数）+（左侧且 $y < Y$ 的点数）
- 奥利得分 = （左侧且 $y > Y$ 的点数）+（右侧且 $y < Y$ 的点数）

设：
- $right\_above(Y)$ = 右侧且 $y > Y$ 的点数
- $right\_below(Y)$ = 右侧且 $y < Y$ 的点数
- $left\_above(Y)$ = 左侧且 $y > Y$ 的点数
- $left\_below(Y)$ = 左侧且 $y < Y$ 的点数

则：
- $stan = right\_above(Y) + left\_below(Y)$
- $ollie = left\_above(Y) + right\_below(Y)$

### 高效计算方法

直接对每个点 $(X, Y)$ 计算四个值的时间复杂度是 $O(n^2)$，不可行。我们需要 $O(n \log n)$ 的算法。

**关键观察**：
- 斯坦得分 + 奥利得分 + 被线穿过的点数 = 总点数 $n$
- 被线穿过的点数 = 同一 $x$ 坐标的点数 + 同一 $y$ 坐标的点数 - $1$（交点重复计算）

因此：
- $ollie = n - stan - sameX - sameY + 1$

其中 $sameX$ 是与当前点 $x$ 坐标相同的点数，$sameY$ 是与当前点 $y$ 坐标相同的点数。

这样我们只需要计算每个点的斯坦得分，然后可以用公式推导奥利得分。

### 算法步骤

1. **预处理**：
   - 读取所有点，离散化 $y$ 坐标
   - 计算每个点的 $sameX$（同一 $x$ 坐标的点数）
   - 计算每个点的 $sameY$（同一 $y$ 坐标的点数）

2. **计算斯坦得分**：
   - 斯坦得分 = 右侧且 $y > Y$ 的点数 + 左侧且 $y < Y$ 的点数
   - 可以使用两次扫描 + 树状数组（$\texttt{BIT}$）高效计算：
     - 第一次扫描（按 $x$ 升序，$y$ 降序）：计算右侧且 $y > Y$ 的点数
     - 第二次扫描（按 $x$ 降序，$y$ 升序）：计算左侧且 $y < Y$ 的点数

3. **计算每个 $x$ 坐标的斯坦最小得分**：
   - 对于每个 $x$ 坐标，取该 $x$ 上所有点的斯坦得分的最小值
   - 这是奥利最优应对时，斯坦在该竖线下的最小得分

4. **找出斯坦的最大保证得分**：
   - 遍历所有点，找到那些斯坦得分等于其所在 $x$ 坐标的最小斯坦得分的点
   - 在这些点中，斯坦得分的最大值就是斯坦能保证的最大得分

5. **收集奥利可能得分**：
   - 对于所有能使斯坦达到最大保证得分的点
   - 用公式 $ollie = n - stan - sameX - sameY + 1$ 计算奥利得分
   - 去重排序后输出

### 时间复杂度

- 离散化：$O(n \log n)$
- 计算 $sameX$ 和 $sameY$：$O(n \log n)$（排序时间）
- 两次 $\texttt{BIT}$ 扫描：$O(n \log n)$
- 总体：$O(n \log n)$，满足 $n \leq 200000$ 的要求

### 空间复杂度

- 存储点：$O(n)$
- $\texttt{BIT}$：$O(n)$
- 总体：$O(n)$

## 代码实现

```cpp
// Brownie Points II
// UVa ID: 10869
// Verdict: Accepted
// Submission Date: 2026-01-20
// UVa Run Time: 0.070s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y, sameX, sameY, stan, minStanX; // sameX: 同一x坐标点数, sameY: 同一y坐标点数, stan: 斯坦得分, minStanX: 该x坐标上斯坦得分的最小值
};

int main() {
    int n;
    while (scanf("%d", &n) && n) {
        vector<Point> p(n);
        vector<int> ys(n);
        
        // 读取输入
        for (int i = 0; i < n; ++i) {
            scanf("%d%d", &p[i].x, &p[i].y);
            ys[i] = p[i].y;
        }
        
        // 离散化y坐标
        sort(ys.begin(), ys.end());
        ys.erase(unique(ys.begin(), ys.end()), ys.end());
        int m = ys.size();
        auto yid = [&](int y) { return lower_bound(ys.begin(), ys.end(), y) - ys.begin(); };
        
        // 计算sameX: 同一x坐标的点数
        sort(p.begin(), p.end(), [](const Point& a, const Point& b) { 
            return a.x < b.x || (a.x == b.x && a.y < b.y); 
        });
        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && p[j].x == p[i].x) ++j;
            int cnt = j - i;
            for (int k = i; k < j; ++k) p[k].sameX = cnt;
            i = j;
        }
        
        // 计算sameY: 同一y坐标的点数
        sort(p.begin(), p.end(), [](const Point& a, const Point& b) { 
            return a.y < b.y || (a.y == b.y && a.x < b.x); 
        });
        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && p[j].y == p[i].y) ++j;
            int cnt = j - i;
            for (int k = i; k < j; ++k) p[k].sameY = cnt;
            i = j;
        }
        
        // 树状数组操作
        vector<int> bit(m + 2, 0);
        auto add = [&](int idx, int v) { 
            for (++idx; idx <= m; idx += idx & -idx) bit[idx] += v; 
        };
        auto sum = [&](int idx) { 
            int s = 0; 
            for (++idx; idx > 0; idx -= idx & -idx) s += bit[idx]; 
            return s; 
        };
        auto query = [&](int l, int r) { 
            return l > r ? 0 : sum(r) - sum(l - 1); 
        };
        
        // 第一次扫描: 计算右侧且y>当前y的点数（右上象限）
        sort(p.begin(), p.end(), [](const Point& a, const Point& b) { 
            return a.x < b.x || (a.x == b.x && a.y > b.y); 
        });
        // 初始所有点都在右侧
        for (auto& pt : p) add(yid(pt.y), 1);
        for (auto& pt : p) {
            int idx = yid(pt.y);
            add(idx, -1); // 将当前点从右侧移除
            pt.stan = query(idx + 1, m - 1); // 右侧且y>当前y的点数
        }
        
        // 第二次扫描: 计算左侧且y<当前y的点数（左下象限）
        sort(p.begin(), p.end(), [](const Point& a, const Point& b) { 
            return a.x > b.x || (a.x == b.x && a.y < b.y); 
        });
        fill(bit.begin(), bit.end(), 0);
        // 初始所有点都在左侧
        for (auto& pt : p) add(yid(pt.y), 1);
        for (auto& pt : p) {
            int idx = yid(pt.y);
            add(idx, -1); // 将当前点从左侧移除
            pt.stan += query(0, idx - 1); // 左侧且y<当前y的点数
        }
        
        // 计算每个x坐标上斯坦得分的最小值
        sort(p.begin(), p.end(), [](const Point& a, const Point& b) { 
            return a.x < b.x || (a.x == b.x && a.y < b.y); 
        });
        for (int i = 0; i < n; ) {
            int j = i, mn = INT_MAX;
            while (j < n && p[j].x == p[i].x) {
                mn = min(mn, p[j].stan);
                ++j;
            }
            for (int k = i; k < j; ++k) p[k].minStanX = mn;
            i = j;
        }
        
        // 找出斯坦的最大保证得分
        int maxStan = 0;
        for (auto& pt : p) {
            if (pt.stan == pt.minStanX) {
                maxStan = max(maxStan, pt.stan);
            }
        }
        
        // 收集奥利可能得分
        set<int> ollie;
        for (auto& pt : p) {
            if (pt.stan == pt.minStanX && pt.stan == maxStan) {
                // ollie = n - stan - sameX - sameY + 1
                ollie.insert(n - pt.stan - pt.sameX - pt.sameY + 1);
            }
        }
        
        // 输出结果
        printf("Stan: %d; Ollie:", maxStan);
        for (int s : ollie) printf(" %d", s);
        printf(";\n");
    }
    return 0;
}
```

## 算法正确性证明

1. **斯坦得分计算正确性**：
   - 第一次扫描时，按 $x$ 升序处理，当处理点 $(X, Y)$ 时，BIT 中包含的是 $x > X$ 的所有点（右侧点）
   - 查询 $y > Y$ 的点数，得到右上象限点数
   - 第二次扫描时，按 $x$ 降序处理，当处理点 $(X, Y)$ 时，BIT 中包含的是 $x < X$ 的所有点（左侧点）
   - 查询 $y < Y$ 的点数，得到左下象限点数
   - 两者相加即为斯坦得分

2. **奥利得分公式正确性**：
   - 总点数 $n = stan + ollie + crossed$
   - $crossed$ = 被线穿过的点数
   - 被垂直线穿过的点数 = $sameX$
   - 被水平线穿过的点数 = $sameY$
   - 交点 $(X, Y)$ 被重复计算，所以 $crossed = sameX + sameY - 1$
   - 因此 $ollie = n - stan - sameX - sameY + 1$

3. **博弈策略正确性**：
   - 对于每个 $x$ 坐标，斯坦的最小可能得分是该 $x$ 上所有点的斯坦得分的最小值（因为奥利会选择最大化自己得分的 $y$）
   - 斯坦选择最大化这个最小得分的 $x$ 坐标
   - 输出所有能使斯坦达到该最大得分的 $x$ 对应的奥利得分

## 总结

本题是一道结合博弈论和计算几何的题目，关键点在于：
1. 理解斯坦和奥利的博弈过程
2. 将问题转化为计算每个点作为交点时的斯坦得分
3. 利用公式 $ollie = n - stan - sameX - sameY + 1$ 避免直接计算奥利得分
4. 使用树状数组高效计算斯坦得分
5. 正确处理每个 $x$ 坐标上斯坦得分的最小值

算法时间复杂度 $O(n \log n)$，空间复杂度 $O(n)$，可以处理 $n \leq 200000$ 的数据规模。
