## 题目描述

三角形是一个具有三条边且面积为正（大于零）的多边形。两个不同的三角形可以拥有相同的周长。例如，两个不同的三角形 $(3, 4, 6)$ 和 $(3, 5, 5)$ 的周长都是 $13$。

在这个问题中，你将得到一个整数周长 $N$。你的任务是找出有多少个不同的三角形，其周长等于 $N$，并且三角形的所有边长均为整数。如果两个三角形的三条边长分别相等，则认为它们是相同的三角形。

**输入格式**
- 输入文件包含少于 $2001$ 行输入
- 每行包含一个正整数 $N$ ($N \leq 2^{31}-1$)，表示三角形的周长
- 输入以一行包含单个 $0$ 结束，该行不应被处理

**输出格式**
- 对于每行输入，输出一行结果，格式为：`Case i: T`
- 其中 $i$ 是输出序号，$T$ 表示周长为 $N$ 的不同三角形的数量
- 保证 $T$ 可以容纳在 $64$ 位有符号整数中

## 题目分析

这是一个组合计数问题，需要计算满足以下条件的整数三元组 $(a, b, c)$ 的数量：

1. $a + b + c = N$（周长条件）
2. $a, b, c$ 均为正整数（边长条件）  
3. $a + b > c$, $a + c > b$, $b + c > a$（三角形不等式）
4. 考虑三角形的不变性，我们假设 $a \leq b \leq c$ 来避免重复计数

## 解题思路

### 关键观察

根据三角形不等式和周长约束，我们可以推导出最大边 $c$ 的范围：

- 由 $a + b > c$ 和 $a + b + c = N$ 得：$N - c > c \Rightarrow c < \frac{N}{2}$
- 由 $a \leq b \leq c$ 和 $a \geq 1$ 得：$3c \geq N \Rightarrow c \geq \frac{N}{3}$

因此，最大边 $c$ 的取值范围为：
$$\lceil \frac{N}{3} \rceil \leq c \leq \lfloor \frac{N-1}{2} \rfloor$$

### 组合计数方法

对于每个可能的 $c$，我们需要计算满足条件的 $(a, b)$ 对的数量：

- $a + b = N - c$
- $1 \leq a \leq b \leq c$
- $b = N - c - a \leq c \Rightarrow a \geq N - 2c$

因此，对于固定的 $c$，$a$ 的取值范围为：
$$\max(1, N - 2c) \leq a \leq \lfloor \frac{N - c}{2} \rfloor$$

满足条件的 $a$ 的数量为：
$$f(c) = \lfloor \frac{N - c}{2} \rfloor - \max(1, N - 2c) + 1$$

### 数学公式推导

通过对 $f(c)$ 求和并简化，我们可以得到闭合公式：

**当 $N$ 为偶数时：**
$$T(N) = \frac{N^2 + 24}{48}$$

**当 $N$ 为奇数时：**
$$T(N) = \frac{(N + 3)^2 + 24}{48}$$

这里的 $+24$ 是为了修正整数除法的舍入误差，相当于实现了四舍五入的效果。

### 算法复杂度

- **时间复杂度**：$O(1)$，直接计算公式结果
- **空间复杂度**：$O(1)$，只使用常数空间

这种方法可以瞬间处理最大的 $N = 2^{31}-1$，完全满足题目要求。

```cpp

#include <iostream>

using namespace std;

long long countTriangles(long long n) {
    if (n < 3) return 0;
    
    if (n % 2 == 0) {
        return (n * n + 24) / 48;
    } else {
        return ((n + 3) * (n + 3) + 24) / 48;
    }
}

int main() {
    long long n;
    int caseNum = 1;
    while (cin >> n && n != 0) {
        long long result = countTriangles(n);
        cout << "Case " << caseNum++ << ": " << result << endl;
    }
    return 0;
}
```

本题通过数学推导得到了计算不同三角形数量的闭合公式，避免了暴力枚举，实现了最优的时间复杂度。关键在于：

1. 利用三角形不等式确定边长的取值范围
2. 通过组合数学方法推导出通用公式
3. 使用整数运算技巧处理边界情况
