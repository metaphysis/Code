## 题目描述

这里我们有若干类骰子状物体（$\texttt{diceoids}$），可以通过适当的旋转比较来进行分类。你得到一袋骰子状物体，你的任务是对它们进行分类，并报告有多少个类别。**你的任务不是判断哪些是标准的骰子。**

为了方便在文本中描述骰子状物体，我们标记立方体的各个面：

```
    A
    B  C  F  E
    D
```

一个骰子状物体被编码为一个包含六个数字的序列 $d_A, \dots, d_F$，表示面 $i$ 上有 $d_i$ 个点。

**示例**：`5 3 6 2 1 4` 表示：
- 面 $A$ 有 $5$ 个点
- 面 $B$ 有 $3$ 个点  
- 面 $C$ 有 $6$ 个点
- 面 $D$ 有 $2$ 个点
- 面 $E$ 有 $1$ 个点
- 面 $F$ 有 $4$ 个点

**注意**：完全有可能不同的面有相同数量的点，例如 `2 2 2 3 3 3`，但每个面至少有 $1$ 个点，最多有 $6$ 个点。

### 输入格式
输入文件包含多个测试用例。每个测试用例以骰子状物体的数量 $n$ ($n \leq 1000$) 开始，然后是 $n$ 个骰子状物体的描述。

### 输出格式
对于每个测试用例，输出类别的数量。

### 样例输入
```
7
5 3 6 2 1 4
4 1 5 3 2 6
5 6 3 2 4 1
4 5 1 3 6 2
2 2 2 3 3 3
2 3 2 3 3 2
1 1 1 1 1 1
```

### 样例输出
```
4
```

## 题目分析

### 问题理解
本题要求我们对多个骰子状物体进行分类，判断哪些物体在旋转后是相同的。两个骰子状物体如果可以通过旋转变得完全相同，则属于同一类。

**关键点**：
1. 每个骰子状物体有 $6$ 个面，分别标记为 $A, B, C, D, E, F$
2. 立方体有 $24$ 种不同的旋转方式
3. 我们需要找到所有不同的旋转下的表示，并以此作为判断依据

### 面定义与输入映射
根据题目描述的面标记：
```
    A
    B  C  F  E
    D
```

实际的面对应关系为：
- $A$: 顶面 ($\texttt{Top}$)
- $B$: 前面 ($\texttt{Front}$)  
- $C$: 右侧面 ($\texttt{Right}$)
- $D$: 底面 ($\texttt{Bottom}$)  ← **注意：$D$ 是底面！**
- $E$: 左侧面 ($\texttt{Left}$)
- $F$: 后面 ($\texttt{Back}$)    ← **注意：$F$ 是后面！**

在代码中，我们使用数组索引 $0$-$5$ 来表示这 $6$ 个面：
- 索引 $0$: 顶面 ($A$)
- 索引 $1$: 前面 ($B$)  
- 索引 $2$: 右侧面 ($C$)
- 索引 $3$: 后面 ($F$)  ← **注意映射关系**
- 索引 $4$: 左侧面 ($E$)
- 索引 $5$: 底面 ($D$)  ← **注意映射关系**

### 解题思路

#### 1. 旋转表示
立方体有 $24$ 种不同的旋转方式。我们可以预先定义好所有旋转的映射关系，即对于每种旋转，原始面的 $0$-$5$ 分别对应到新的哪些面。

#### 2. 规范表示
对于每个骰子状物体，我们生成其所有 $24$ 种旋转下的表示，然后选择其中**字典序最小**的字符串作为该物体的规范表示。这样，两个物体如果可以通过旋转变得相同，那么它们的规范表示必定相同。

#### 3. 分类计数
使用集合（$\texttt{set}$）来存储所有不同的规范表示，集合的大小即为类别的数量。

#### 4. 算法步骤
1. 读取输入数据
2. 对于每个骰子状物体，根据实际面定义重新映射输入数据
3. 生成该物体的所有旋转表示，找到字典序最小的规范形式
4. 将规范形式加入集合
5. 输出集合的大小

## 复杂度分析
- 每个测试用例有 $n$ 个骰子状物体 ($n \leq 1000$)
- 每个物体需要尝试 $24$ 种旋转
- 每次旋转需要构建长度为 $6$ 的字符串
- 总时间复杂度：$O(n \times 24 \times 6) = O(144n)$，对于 $n \leq 1000$ 完全可行

```cpp
// Diceoids

#include <bits/stdc++.h>
using namespace std;

// 修正后的面序号定义（根据题目实际定义）：
// 0: 顶面 (Top)     - A
// 1: 前面 (Front)   - B  
// 2: 右侧面 (Right) - C
// 3: 后面 (Back)    - F  ← 注意：F是后面
// 4: 左侧面 (Left)  - E
// 5: 底面 (Bottom)  - D  ← 注意：D是底面

// 预定义所有 24 种旋转的映射关系
// 每种旋转是一个长度为 6 的数组，表示原始面 0-5 分别映射到的新面索引
const int rotations[24][6] = {
    {0, 1, 2, 3, 4, 5}, {0, 2, 3, 4, 1, 5}, {0, 3, 4, 1, 2, 5}, {0, 4, 1, 2, 3, 5},
    {1, 0, 4, 5, 2, 3}, {1, 2, 0, 4, 5, 3}, {1, 5, 2, 0, 4, 3}, {1, 4, 5, 2, 0, 3},
    {2, 0, 1, 5, 3, 4}, {2, 1, 5, 3, 0, 4}, {2, 5, 3, 0, 1, 4}, {2, 3, 0, 1, 5, 4},
    {3, 0, 2, 5, 4, 1}, {3, 2, 5, 4, 0, 1}, {3, 5, 4, 0, 2, 1}, {3, 4, 0, 2, 5, 1},
    {4, 0, 3, 5, 1, 2}, {4, 3, 5, 1, 0, 2}, {4, 5, 1, 0, 3, 2}, {4, 1, 0, 3, 5, 2},
    {5, 1, 4, 3, 2, 0}, {5, 4, 3, 2, 1, 0}, {5, 3, 2, 1, 4, 0}, {5, 2, 1, 4, 3, 0}
};

// 获取一个骰子状物体的规范表示（最小表示）
string getCanonicalForm(vector<int>& dice) {
    string minForm = "999999";
    for (int i = 0; i < 24; i++) {
        string currentForm = "";
        for (int j = 0; j < 6; j++)
            currentForm += to_string(dice[rotations[i][j]]);
        if (currentForm < minForm) minForm = currentForm;
    }
    return minForm;
}

int main() {
    int n;
    while (cin >> n, n) {
        set<string> classes;
        for (int i = 0; i < n; i++) {
            vector<int> dice(6);
            // 输入顺序：A(顶), B(前), C(右), D(底), E(左), F(后)
            // 对应索引：0,    1,    2,    5,    4,    3
            // 但输入是按 A, B, C, D, E, F 的顺序，所以我们需要重新映射
            int a, b, c, d, e, f;
            cin >> a >> b >> c >> d >> e >> f;
            // 根据题目实际定义重新映射：
            dice[0] = a; // A = 顶面
            dice[1] = b; // B = 前面  
            dice[2] = c; // C = 右侧面
            dice[3] = f; // F = 后面  ← 注意：输入的第 6 个是 F，对应后面
            dice[4] = e; // E = 左侧面
            dice[5] = d; // D = 底面  ← 注意：输入的第 4 个是 D，对应底面
            string canonicalForm = getCanonicalForm(dice);
            classes.insert(canonicalForm);
        }
        cout << classes.size() << endl;
    }
    return 0;
}
```

## 总结
本题的关键在于理解立方体的旋转对称性，以及正确处理题目中面的定义。通过预定义所有可能的旋转映射，并为每个骰子状物体找到其字典序最小的规范表示，我们可以高效地完成分类任务。注意题目中面的标记顺序与常规理解可能不同，这是解题时需要特别注意的地方。
