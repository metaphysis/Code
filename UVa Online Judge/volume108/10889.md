## 题目分析

$\texttt{Stan}$ 收到了 $\texttt{Olie}$ 送的两个盒子，一个装红球，一个装黑球。$\texttt{Olie}$ 告诉他：如果把两个盒子里的球混合后随机取两个球，两个球颜色相同的概率是 $1/2$。在回家的路上，黑球盒子掉在地上，$\texttt{Stan}$ 只找回了部分黑球。题目给出红球总数 $R$ 和找到的黑球数 $B$，要求计算丢失的黑球数量。

### 概率条件分析

设：
- $R$ = 红球总数
- $T$ = 原始黑球总数
- $B$ = 找到的黑球数
- $L = T - B$ = 丢失的黑球数

从 $R + T$ 个球中随机取两个球，颜色相同的概率为 $1/2$。

总的选择方式数为：
$$\binom{R+T}{2} = \frac{(R+T)(R+T-1)}{2}$$

同色的情况：
- 两个红球：$\binom{R}{2} = \frac{R(R-1)}{2}$
- 两个黑球：$\binom{T}{2} = \frac{T(T-1)}{2}$

概率公式：
$$\frac{\frac{R(R-1)}{2} + \frac{T(T-1)}{2}}{\frac{(R+T)(R+T-1)}{2}} = \frac{1}{2}$$

化简得：
$$\frac{R(R-1) + T(T-1)}{(R+T)(R+T-1)} = \frac{1}{2}$$
$$2[R(R-1) + T(T-1)] = (R+T)(R+T-1)$$
$$2R^2 - 2R + 2T^2 - 2T = R^2 + 2RT + T^2 - R - T$$
$$R^2 - R + T^2 - T = 2RT$$
$$R^2 - 2RT + T^2 = R + T$$
$$(R - T)^2 = R + T$$

### 关键方程求解

设 $D = R - T$，则：
$$D^2 = R + T$$

又因为 $T = R - D$，代入得：
$$D^2 = R + (R - D) = 2R - D$$
$$D^2 + D - 2R = 0$$

解这个一元二次方程：
$$D = \frac{-1 \pm \sqrt{1 + 8R}}{2}$$

因此 $D$ 有两个可能的解：
- $D_1 = \frac{-1 + \sqrt{1+8R}}{2}$
- $D_2 = \frac{-1 - \sqrt{1+8R}}{2}$

对应的黑球总数分别为：
- $T_1 = R - D_1$
- $T_2 = R - D_2$

### 约束条件

1. **红球数有效性**：$1 + 8R$ 必须是完全平方数，且 $D$ 必须是整数
2. **黑球数有效性**：$B$ 必须满足 $B \ge \lceil 0.7T \rceil$ 且 $B \le T$
3. **黑球数为正**：$T > 0$

## 解题思路

1. 对于每个输入的 $R$ 和 $B$：
   - 检查 $1 + 8R$ 是否为完全平方数
   - 如果不是，输出 `No. of red balls invalid`
   - 如果是，计算两个可能的 $D$ 值

2. 对于每个有效的 $D$ 值：
   - 计算对应的 $T = R - D$
   - 检查 $T > 0$
   - 检查 $B$ 是否在 $[\lceil 0.7T \rceil, T]$ 范围内

3. 如果至少有一个 $T$ 满足条件：
   - 计算所有可能的 $L = T - B$
   - 排序后输出

4. 如果没有 $T$ 满足条件：
   - 输出 `No. of black balls invalid`

## 代码实现

```cpp
// The Lost Gift
// UVa ID: 10889
// Verdict: Accepted
// Submission Date: 2025-11-21
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int r, b;
    while (cin >> r >> b && (r || b)) {
        long long delta = 1 + 8LL * r;
        long long sqrtDelta = sqrt(delta);
        if (sqrtDelta * sqrtDelta != delta) {
            cout << "No. of red balls invalid" << endl;
            continue;
        }
        vector<int> possibleLost;
        // 第一种情况: D = (-1 + sqrtDelta)/2
        if ((-1 + sqrtDelta) % 2 == 0) {
            long long d = (-1 + sqrtDelta) / 2;
            long long totalBlack = r - d;
            if (totalBlack > 0 && b >= ceil(0.7 * totalBlack) && b <= totalBlack) {
                possibleLost.push_back(totalBlack - b);
            }
        }
        // 第二种情况: D = (-1 - sqrtDelta)/2
        if ((-1 - sqrtDelta) % 2 == 0) {
            long long d = (-1 - sqrtDelta) / 2;
            long long totalBlack = r - d;
            if (totalBlack > 0 && b >= ceil(0.7 * totalBlack) && b <= totalBlack) {
                possibleLost.push_back(totalBlack - b);
            }
        }
        if (possibleLost.empty()) {
            cout << "No. of black balls invalid" << endl;
        } else {
            sort(possibleLost.begin(), possibleLost.end());
            for (size_t i = 0; i < possibleLost.size(); i++) {
                if (i > 0) cout << " ";
                cout << possibleLost[i];
            }
            cout << endl;
        }
    }
    return 0;
}
```
