## 题目描述

**完美数**是指其所有正因数之和等于该数自身两倍的数。例如，$28$ 是一个完美数，因为 $28$ 的因数之和为：
$$
1 + 2 + 4 + 7 + 14 + 28 = 56 = 2 \times 28
$$
符号 $\sigma$ 用于表示所有正因数之和的函数，因此我们可以写作 $\sigma(28) = 56$。如果 $n$ 是一个完美数，那么 $\sigma(n) - 2n = 0$。

**几乎奇素数**是指满足以下条件的偶数：
- 它只有一个奇数因数（除了 $1$ 以外）

例如，$6$ 和 $24$ 都是几乎奇素数。设 $X$ 表示所有几乎奇素数的集合，定义**丰度函数** $abun()$ 为：
$$
abun(n) = \sum_{\substack{a_i \in X \\ a_i \leq n}} (\sigma(a_i) - 2a_i)
$$
对于任意正整数 $n$，给定 $n$ 的值，你的任务是计算 $abun(n)$ 的值。

### 输入格式
- 输入文件最多包含 $1001$ 行
- 每行包含一个整数 $n$ $(1 \leq n \leq 10000000)$
- 输入以 $n = 0$ 的行结束，该行不应被处理

### 输出格式
- 对于每个输入行，输出一行包含两个整数：$n$ 和 $abun(n)$，用空格分隔

### 样例输入
```
10
20
1000000
0
```

### 样例输出
```
10 -2
20 0
1000000 -13478901222
```

## 题目分析

### 关键概念理解

1. **完美数**：$\sigma(n) = 2n$
2. **几乎奇素数**：偶数且只有一个奇数因数（除 $1$ 外）
3. **丰度函数**：计算所有满足条件的几乎奇素数的 $(\sigma(a_i) - 2a_i)$ 之和

### 几乎奇素数的数学特征

通过分析题目描述，我们可以发现：
- 几乎奇素数必须是偶数
- 它只能有一个奇数质因数（除了 $1$）
- 因此，几乎奇素数的形式为：$m = 2^k \times p$，其中：
  - $p$ 是奇素数
  - $k \geq 1$

### 推导 $\sigma(m) - 2m$ 的简化公式

对于 $m = 2^k \times p$，其所有正因数为：
$$
1, 2, 2^2, \dots, 2^k, \quad p, 2p, 2^2p, \dots, 2^kp
$$

因此：
$$
\sigma(m) = (1 + 2 + 2^2 + \dots + 2^k) \times (1 + p) = (2^{k+1} - 1)(p + 1)
$$

那么：
$$
\begin{aligned}
& \sigma(m) - 2m \\ 
& = (2^{k+1} - 1)(p + 1) - 2 \cdot 2^kp \\
& = 2^{k+1}p + 2^{k+1} - p - 1 - 2^{k+1}p \\
& = 2^{k+1} - p - 1
\end{aligned}
$$


**重要结论**：对于几乎奇素数 $m = 2^k \times p$，有：
$$
\sigma(m) - 2m = 2^{k+1} - p - 1
$$

## 解题思路

### 算法设计

基于上述数学推导，我们可以设计高效算法：

1. **预处理阶段**：
   - 使用筛法找出所有 $\leq 10^7$ 的素数
   - 对于每个奇素数 $p$ 和每个 $k \geq 1$，计算 $m = 2^k \times p$
   - 如果 $m > 10^7$，停止增加 $k$
   - 计算 $abunVal = 2^{k+1} - p - 1$
   - 将 $abunVal$ 累加到前缀和数组中

2. **查询处理**：
   - 对于每个查询 $n$，直接输出前缀和数组中的值

### 复杂度分析

- **预处理**：
  - 筛法：$O(n \log \log n)$
  - 生成几乎奇素数：每个素数 $p$ 最多 $\log_2(\frac{MAX\_N}{p})$ 次
- **查询**：$O(1)$ 每查询
- 总体复杂度在 $n \leq 10^7$ 范围内可行

## 代码实现

```cpp
// Abundance and Perfect Numbers

#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

const int MAX_N = 10000000;

vector<long long> precomputeAbunPrefixSum() {
    // 筛法标记素数
    vector<bool> isPrime(MAX_N + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i * i <= MAX_N; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= MAX_N; j += i) {
                isPrime[j] = false;
            }
        }
    }

    vector<long long> prefixSum(MAX_N + 1, 0);

    // 遍历所有奇素数 p
    for (int p = 2; p <= MAX_N; p++) {
        if (!isPrime[p] || p == 2) continue; // 跳过偶素数 2
        long long powerOfTwo = 2;
        for (int k = 1; ; k++) {
            long long num = powerOfTwo * p;
            if (num > MAX_N) break;
            // 计算 abunVal = 2^(k+1) - p - 1
            long long abunVal = (powerOfTwo * 2) - p - 1;
            prefixSum[num] += abunVal;
            powerOfTwo *= 2;
            if (powerOfTwo > MAX_N) break;
        }
    }

    // 构建前缀和
    for (int i = 1; i <= MAX_N; i++) {
        prefixSum[i] += prefixSum[i - 1];
    }

    return prefixSum;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    vector<long long> prefixSum = precomputeAbunPrefixSum();

    int n;
    while (cin >> n && n != 0) {
        cout << n << " " << prefixSum[n] << "\n";
    }

    return 0;
}
```
