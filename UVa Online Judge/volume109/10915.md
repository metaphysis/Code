## 题目描述

$\texttt{Glorious Warrior}$ 拥有 $k$ 个卫星，分布在太空中不同位置。已知有 $m$ 个热带低气压目标分布在地球表面。每个卫星可以攻击任意数量的目标，只要卫星与目标之间存在**视线**（$\texttt{line of sight}$）。地球是一个以 $(0,0,0)$ 为中心的球体，周长为 $40,000$ km。所有目标都位于地球表面（距离地心 $10^{-9}$ km 范围内），所有卫星至少位于地表以上 $50$ km。

要求计算能够被击中的目标总数。

## 输入格式

输入包含多个测试用例。每个测试用例以一行包含两个整数 $0 < k, m \leq 100$ 开始，接着是 $k$ 行卫星坐标，然后是 $m$ 行目标坐标。输入以一行 `0 0` 结束。

## 输出格式

对于每个测试用例，输出一行，给出可以被击中的目标总数。

## 题目分析

### 关键问题：视线判断

本题的核心在于判断卫星与目标之间是否存在视线。由于地球是一个球体，视线被阻挡的条件是卫星与目标之间的连线穿过地球内部。

### 几何推导

设：
- 地球中心 $O = (0,0,0)$
- 地球半径 $R = \frac{40000}{2\pi}$ km
- 卫星位置 $S = (x_s, y_s, z_s)$
- 目标位置 $T = (x_t, y_t, z_t)$

由于目标位于地球表面，有 $|OT| = R$。

**视线判断的关键观察**：

从卫星 $S$ 看目标 $T$ 时，视线被地球阻挡的条件是：从 $S$ 到 $T$ 的连线与地球相交于某点 $P$（$P \neq T$）。这等价于 $\angle SOT$（卫星-地心-目标的夹角）大于某个临界值。

考虑从卫星 $S$ 出发与地球相切的情况：在切点处，向量 $\overrightarrow{OS}$ 与 $\overrightarrow{SP}$ 垂直，其中 $P$ 是切点。此时：

$$
\cos \angle SOP = \frac{R}{|OS|}
$$

如果目标 $T$ 与卫星 $S$ 的夹角 $\angle SOT$ 满足：

$$
\cos \angle SOT \geq \frac{R}{|OS|}
$$

则目标 $T$ 位于切点锥内，视线不被阻挡。

将余弦定义展开：

$$
\cos \angle SOT = \frac{\overrightarrow{OS} \cdot \overrightarrow{OT}}{|OS| \cdot |OT|} = \frac{S \cdot T}{|S| \cdot R}
$$

代入不等式：

$$
\frac{S \cdot T}{|S| \cdot R} \geq \frac{R}{|S|}
$$

化简得到最终判断条件：

$$
S \cdot T \geq R^2
$$

**结论**：卫星 $S$ 可以看到目标 $T$ 当且仅当它们的位置向量点积满足 $S \cdot T \geq R^2$。

### 算法设计

1. 计算地球半径 $R = \frac{40000}{2\pi}$
2. 对于每个测试用例：
   - 读取 $k$ 和 $m$
   - 读取所有卫星坐标
   - 读取所有目标坐标
   - 对于每个目标，检查是否存在至少一个卫星满足 $S \cdot T \geq R^2 - 10^{-8}$（考虑题目允许的误差）
   - 统计可击中的目标数量
3. 输出结果

### 复杂度分析

- 每个测试用例需要 $O(k \cdot m)$ 次点积运算
- 由于 $k, m \leq 100$，算法效率完全可接受

## 代码实现

```cpp
// War on Weather

#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

// 地球半径，根据周长40,000km计算
const double R = 40000.0 / (2 * M_PI);

// 三维点结构体
struct Point {
    double x, y, z;
    Point(double x = 0, double y = 0, double z = 0) : x(x), y(y), z(z) {}
    
    // 点积运算
    double dot(const Point& p) const {
        return x * p.x + y * p.y + z * p.z;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int k, m;
    
    // 处理多个测试用例，直到遇到 0 0
    while (cin >> k >> m && (k != 0 || m != 0)) {
        vector<Point> satellites(k);
        vector<Point> targets(m);

        // 读取卫星坐标
        for (int i = 0; i < k; i++) {
            cin >> satellites[i].x >> satellites[i].y >> satellites[i].z;
        }
        
        // 读取目标坐标
        for (int i = 0; i < m; i++) {
            cin >> targets[i].x >> targets[i].y >> targets[i].z;
        }

        int count = 0;  // 可击中目标计数器
        
        // 检查每个目标是否能被至少一个卫星击中
        for (const Point& target : targets) {
            bool can_hit = false;
            
            // 遍历所有卫星，检查视线
            for (const Point& satellite : satellites) {
                // 使用点积判断是否存在视线
                // 添加容差 1e-8 处理边界情况
                if (satellite.dot(target) >= R * R - 1e-8) {
                    can_hit = true;
                    break;  // 找到一个可见卫星即可
                }
            }
            
            if (can_hit) {
                count++;
            }
        }

        // 输出当前测试用例的结果
        cout << count << "\n";
    }

    return 0;
}
```

## 代码说明

1. **地球半径计算**：根据题目给出的地球周长 $40,000$ km，计算半径 $R = \frac{40000}{2\pi}$。

2. **数据结构**：使用 `Point` 结构体存储三维坐标，并包含点积运算方法。

3. **输入处理**：使用快速输入输出优化，提高效率。

4. **视线判断**：核心条件是 `satellite.dot(target) >= R * R - 1e-8`，其中 $1e^{-8}$ 是题目允许的误差范围。

5. **优化**：一旦发现某个目标可以被一个卫星击中，立即停止检查其他卫星。

## 总结

本题的关键在于将视线判断问题转化为几何点积计算。通过分析卫星与地球的相切条件，推导出简洁的数学公式 $S \cdot T \geq R^2$，使得问题可以在 $O(k \cdot m)$ 时间内高效解决。这种将几何问题转化为代数计算的方法在计算几何中非常常见，能够显著简化代码实现。
