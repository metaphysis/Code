## 题目分析

本题要求实现一个支持变量存储和表达式求值的计算器。主要特点包括：

- 支持 $26$ 个变量（$a$ 到 $z$）的存储和读取
- 支持四则运算（$+$, $-$, $*$, $/$）和括号
- 遵循数学运算优先级：先乘除后加减
- 输入分为赋值表达式和询问表达式
- 输出结果需要四舍五入到两位小数

**输入格式特点：**
- 赋值表达式格式：`变量=表达式`（如 `x=10`, `y=5/3`）
- 询问表达式格式：直接是表达式（如 `x+10`, `x*y`）
- 表达式中没有空格

## 解题思路

### 1. 核心算法选择

由于需要处理运算符优先级和括号，我们采用**递归下降分析法**（$\texttt{Recursive Descent Parsing}$）。这种方法能够自然地处理运算符优先级，并且代码结构清晰。

### 2. 表达式解析设计

我们将表达式解析分为三个层次：

1. **`parseExpression()`**：处理加减运算（最低优先级）
2. **`parseTerm()`**：处理乘除运算（中等优先级）  
3. **`parseFactor()`**：处理基本单元（最高优先级）

这种分层设计确保了运算的正确优先级：
- 括号和基本单元最先计算
- 然后是乘除运算
- 最后是加减运算

### 3. 变量存储

使用 `std::map<char, double>` 来存储 $26$ 个变量的值，键为字符 $a$-$z$，值为双精度浮点数。

### 4. 处理流程

1. 读取每一行输入
2. 判断是否为赋值表达式（检查是否包含 `=`）
3. 如果是赋值：
   - 提取变量名（第一个字符）
   - 计算等号右边的表达式
   - 将结果存入变量映射表
4. 如果是询问：
   - 直接计算整个表达式
   - 输出结果（保留两位小数）

## 关键实现细节

### 递归下降解析器

```cpp
// 表达式 → 项 (( '+' | '-' ) 项)*
double parseExpression();

// 项 → 因子 (( '*' | '/' ) 因子)*  
double parseTerm();

// 因子 → 数字 | 变量 | '(' 表达式 ')'
double parseFactor();
```

### 变量处理

当解析器遇到字母时，从 `vars` 映射中查找对应的值。如果变量未被赋值过，`std::map` 会自动初始化为 $0.0$。

### 精度处理

使用 `printf("%.2f\n", result)` 自动进行四舍五入到两位小数。

## 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 是表达式长度，每个字符只被处理一次
- **空间复杂度**：$O(1)$，除了存储变量的映射表外，只需要常数空间

```cpp
// Calculator

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

map<char, double> vars;
string expr;
int pos;

void skipSpaces() {
	while (pos < expr.size() && expr[pos] == ' ') pos++;
}

double parseExpression();

double parseFactor() {
	skipSpaces();
	if (expr[pos] == '(') {
		pos++;
		double result = parseExpression();
		skipSpaces();
		pos++;
		return result;
	}
	if (isdigit(expr[pos])) {
		double num = 0;
		while (pos < expr.size() && isdigit(expr[pos])) {
			num = num * 10 + (expr[pos] - '0');
			pos++;
		}
		return num;
	}
	if (isalpha(expr[pos])) {
		char var = expr[pos++];
		return vars[var];
	}
	return 0;
}

double parseTerm() {
	double left = parseFactor();
	skipSpaces();
	while (pos < expr.size() && (expr[pos] == '*' || expr[pos] == '/')) {
		char op = expr[pos++];
		double right = parseFactor();
		if (op == '*') left *= right;
		else left /= right;
		skipSpaces();
	}
	return left;
}

double parseExpression() {
	double left = parseTerm();
	skipSpaces();
	while (pos < expr.size() && (expr[pos] == '+' || expr[pos] == '-')) {
		char op = expr[pos++];
		double right = parseTerm();
		if (op == '+') left += right;
		else left -= right;
		skipSpaces();
	}
	return left;
}

double evaluate(const string& e) {
	expr = e;
	pos = 0;
	return parseExpression();
}

int main() {
	string line;
	while (getline(cin, line)) {
		if (line.find('=') != string::npos) {
			char var = line[0];
			string rest = line.substr(2);
			vars[var] = evaluate(rest);
		} else {
			double result = evaluate(line);
			printf("%.2f\n", result);
		}
	}
	return 0;
}
```

这个解法通过递归下降分析器优雅地处理了运算符优先级问题，代码简洁且易于理解，能够正确处理题目中的所有测试用例。
