## 题目分析

### 问题描述

本题要求我们根据排球比赛的规则，对参加杯赛的各支队伍进行排名。每个杯赛有若干支队伍参加，已经进行了一定数量的比赛。我们需要根据比赛结果，按照特定的排名规则对队伍进行排序。

### 输入格式

- 首先输入队伍数量 $T$ ($2 < T < 1000$)
- 接下来 $T$ 行，每行一个队伍名称（可能包含空格，长度不超过 $20$ 字符）
- 然后输入比赛场数 $M$ ($1 < M < 1000$)
- 接下来 $M$ 行，每行描述一场比赛，格式为：
  `队伍A-队伍B: 得分A-得分B 得分A-得分B ...`
- 输入以 $T = 0$ 结束

### 比赛规则

1. **比赛胜负**：一支队伍赢得比赛需要赢得 $3$ 局，每场比赛最多进行 $5$ 局
2. **单局胜负**：一队赢得一局的条件是：
   - 得分达到 $25$ 分或以上
   - 且领先对手至少 $2$ 分

### 排名规则

按照以下优先级顺序对队伍进行排名：

1. **获胜场数**（降序）
2. **净胜局数**（获胜局数 $-$ 失败局数，降序）
3. **总得分**（降序）
4. **队伍名称**（字典序升序）

## 解题思路

### 数据结构设计

我们需要为每个队伍维护以下信息：

- `name`：队伍名称
- `wins`：获胜场数
- `setsWon`：获胜局数
- `setsLost`：失败局数
- `points`：总得分

### 算法流程

1. **数据读取与存储**
   - 使用 `map<string, Team>` 存储队伍数据，便于通过名称快速查找
   - 同时维护 `vector<string> teamNames` 保存原始输入顺序

2. **比赛结果处理**
   - 解析每场比赛的两支队伍名称和各局比分
   - 对于每一局：
     - 判断哪支队伍赢得该局（得分 ≥ $25$ 且领先 ≥ $2$ 分）
     - 累加各队的总得分
   - 根据赢得的局数确定比赛胜负，更新获胜场数

3. **队伍排名**
   - 将 `map` 中的数据转换到 `vector` 中以便排序
   - 使用自定义比较函数按照题目要求的优先级排序

4. **结果输出**
   - 按照指定格式输出排名结果
   - 使用 `setw()` 控制输出对齐

### 关键点分析

1. **局胜负判断**：必须同时满足两个条件：
   - 得分 ≥ $25$
   - 领先对手至少 $2$ 分

2. **比赛胜负判断**：赢得 $3$ 局的队伍获胜，但题目输入保证最多 $5$ 局

3. **多条件排序**：严格按照题目给定的优先级顺序进行比较

4. **输入处理**：队伍名称可能包含空格，需要正确处理

## 复杂度分析

- **时间复杂度**：$O(T \log T + M \times S)$，其中 $S$ 是每场比赛的局数（最多 $5$）
- **空间复杂度**：$O(T)$，用于存储队伍信息

#include <bits/stdc++.h>
using namespace std;

struct Team {
    string name;
    int wins;
    int setsWon;
    int setsLost;
    int points;
    // 默认构造函数
    Team() : wins(0), setsWon(0), setsLost(0), points(0) {}
    // 带参数的构造函数
    Team(const string& n) : name(n), wins(0), setsWon(0), setsLost(0), points(0) {}
};

void processMatch(const string& teamA, const string& teamB, const vector<pair<int, int>>& sets, map<string, Team>& teams) {
    int winA = 0, winB = 0;
    int pointsA = 0, pointsB = 0;
    
    for (auto& s : sets) {
        pointsA += s.first;
        pointsB += s.second;
        if (s.first >= 25 && s.first - s.second >= 2) {
            winA++;
        } else if (s.second >= 25 && s.second - s.first >= 2) {
            winB++;
        }
    }
    
    teams[teamA].setsWon += winA;
    teams[teamA].setsLost += winB;
    teams[teamA].points += pointsA;
    
    teams[teamB].setsWon += winB;
    teams[teamB].setsLost += winA;
    teams[teamB].points += pointsB;
    
    if (winA > winB) {
        teams[teamA].wins++;
    } else {
        teams[teamB].wins++;
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    while (cin >> T && T != 0) {
        
        cin.ignore();
        map<string, Team> teamsMap;
        vector<string> teamNames;
        
        for (int i = 0; i < T; i++) {
            string name;
            getline(cin, name);
            teamsMap[name] = Team(name);
            teamNames.push_back(name);
        }
        
        int M;
        cin >> M;
        cin.ignore();
        
        for (int i = 0; i < M; i++) {
            string line;
            getline(cin, line);
            size_t dashPos = line.find('-');
            size_t colonPos = line.find(':', dashPos);
            string teamA = line.substr(0, dashPos);
            string teamB = line.substr(dashPos + 1, colonPos - dashPos - 1);
            
            string setsStr = line.substr(colonPos + 1);
            vector<pair<int, int>> sets;
            istringstream iss(setsStr);
            string setResult;
            while (iss >> setResult) {
                size_t pos = setResult.find('-');
                int a = stoi(setResult.substr(0, pos));
                int b = stoi(setResult.substr(pos + 1));
                sets.push_back({a, b});
            }
            
            processMatch(teamA, teamB, sets, teamsMap);
        }
        
        vector<Team> teams;
        for (auto& name : teamNames) {
            teams.push_back(teamsMap[name]);
        }
        
        sort(teams.begin(), teams.end(), [](const Team& a, const Team& b) {
            if (a.wins != b.wins) return a.wins > b.wins;
            int diffA = a.setsWon - a.setsLost;
            int diffB = b.setsWon - b.setsLost;
            if (diffA != diffB) return diffA > diffB;
            if (a.points != b.points) return a.points > b.points;
            return a.name < b.name;
        });
        
        for (auto& t : teams) {
            int diff = t.setsWon - t.setsLost;
            cout << t.name << right << setw(25 - t.name.length()) << t.wins;
            cout << right << setw(5) << diff;
            cout << right << setw(10) << t.points << "\n";
        }
        cout << '\n';
    }
    
    return 0;
}
