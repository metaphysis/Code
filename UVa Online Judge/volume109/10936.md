[UVa 10936 Land Surveyor's Job](https://blog.csdn.net/metaphysis/article/details/158264869)

## 题目分析

这道题模拟了土地测量中的导线网闭合计算。在二维平面上，有 $n$ 个站点组成一个闭合的导线网，每个站点 $i$ 有两个测量数据：

- **前视距离** $d_i$：从站点 $i$ 到下一个站点 $i+1$ 的距离（对于站点 $n$，则是到站点 $1$ 的距离）
- **顺时针夹角** $\theta_i$：从后视方向（站点 $i$ 到 $i-1$ 的线段）顺时针旋转到前视方向（站点 $i$ 到 $i+1$ 的线段）的角度。对于站点 $1$，因为没有前一个站点，角度设为 $0$

已知站点 $1$ 的实际坐标为 $(0,0)$，站点 $2$ 的实际坐标为 $(d_1, 0)$（即从站点 $1$ 沿 $x$ 轴正方向走 $d_1$ 距离）。然后根据每个站点的测量数据，可以依次推算出后续所有站点的坐标。

由于测量存在误差，当推算完所有站点后，再根据最后一个站点的数据反向推算站点 $1$ 的预测位置，并与实际位置比较。如果两者距离小于导线总长度的 $0.1\%$，则认为该导线网是 **可接受的**，否则是 **不可接受的**。

## 解题思路

### $1$. 坐标递推公式

假设已知站点 $i$ 和 $i+1$ 的坐标，要计算站点 $i+2$ 的坐标。设：

- $P_i$ 为站点 $i$ 的坐标
- $P_{i+1}$ 为站点 $i+1$ 的坐标
- 后视向量 $\vec{b} = P_i - P_{i+1}$（从 $i+1$ 指向 $i$）
- 站点 $i+1$ 的测量角度 $\theta_{i+1}$（后视到前视的顺时针夹角）
- 前视距离 $d_{i+1}$（从 $i+1$ 到 $i+2$ 的距离）

前视方向向量 $\vec{f}$ 的长度为 $d_{i+1}$，方向由 $\vec{b}$ 顺时针旋转 $\theta_{i+1}$ 得到。

顺时针旋转 $\theta$ 角的变换公式为：
$$
(x, y) \to (x\cos\theta + y\sin\theta, -x\sin\theta + y\cos\theta)
$$

因此：
$$
\vec{f} = d_{i+1} \cdot \frac{(b_x\cos\theta_{i+1} + b_y\sin\theta_{i+1}, -b_x\sin\theta_{i+1} + b_y\cos\theta_{i+1})}{\|\vec{b}\|}
$$

于是：
$$
P_{i+2} = P_{i+1} + \vec{f}
$$

### $2$. 递推过程

从已知的 $P_1$ 和 $P_2$ 出发，利用站点 $2$ 的数据计算 $P_3$，再用站点 $3$ 的数据计算 $P_4$，依次类推，直到计算出 $P_n$。

### $3$. 闭合检查

当计算出 $P_n$ 后，再根据站点 $n$ 的数据推算站点 $1$ 的预测位置 $P_1'$：

- 后视向量 $\vec{b} = P_{n-1} - P_n$
- 顺时针旋转角度 $\theta_n$
- 前视距离 $d_n$
- 计算 $\vec{f}$，得到 $P_1' = P_n + \vec{f}$

然后计算实际站点 $1$ 与预测站点 $1'$ 的距离：
$$
error = \|P_1 - P_1'\|
$$

计算导线总长度：
$$
totalLen = \sum_{i=1}^{n} d_i
$$

判断条件：
$$
error < totalLen \times 0.001
$$

若成立，输出 $\texttt{Acceptable}$，否则输出 $\texttt{Not acceptable}$。

### 4. 角度解析

输入中除了站点 $1$ 的角度为 $0$ 外，其他站点的角度以度、分、秒格式给出，如 $90d00'00"$。需要转换为弧度制：
$$
\theta = (\text{度} + \frac{\text{分}}{60} + \frac{\text{秒}}{3600}) \times \frac{\pi}{180}
$$

## 注意事项

- 站点 $1$ 的角度固定为 $0$，输入格式特殊，需要单独处理
- 角度是顺时针测量的，与数学上通常的逆时针方向不同，旋转公式需要正确实现
- 浮点运算精度足够满足题目要求，直接使用 $\texttt{double}$ 即可
- 总长度是所有前视距离之和，包括站点 $n$ 到站点 $1$ 的那一段

## 代码实现

```cpp
// Land Surveyor's Job
// UVa ID: 10936
// Verdict: Accepted
// Submission Date: 2026-02-21
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point {
    double x, y;
    Point(double x_ = 0, double y_ = 0) : x(x_), y(y_) {}
};

double toRadians(int deg, int min, int sec) {
    return (deg + min / 60.0 + sec / 3600.0) * M_PI / 180.0;
}

double distance(Point a, Point b) {
    double dx = a.x - b.x, dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);
}

int main() {
    int n;
    while (scanf("%d", &n) == 1 && n) {
        vector<double> dist(n), ang(n);
        vector<int> deg(n), min(n), sec(n);
        
        for (int i = 0; i < n; ++i) {
            if (i == 0) {
                scanf("%lf %d", &dist[0], &deg[0]);  // 站点 1 角度为 0
                min[0] = sec[0] = 0;
                ang[0] = 0;
            } else {
                scanf("%lf %d%*c%d%*c%d%*c", &dist[i], &deg[i], &min[i], &sec[i]);
                ang[i] = toRadians(deg[i], min[i], sec[i]);
            }
        }
        
        // 站点 1 实际坐标 (0,0)，站点 2 实际坐标 (dist[0], 0)
        vector<Point> P(n);
        P[0] = Point(0, 0);
        P[1] = Point(dist[0], 0);
        
        // 从站点 2 开始递推
        for (int i = 1; i < n - 1; ++i) {
            // 后视向量 P[i-1] - P[i]
            double bx = P[i-1].x - P[i].x;
            double by = P[i-1].y - P[i].y;
            double lenB = sqrt(bx * bx + by * by);
            // 顺时针旋转角度 ang[i]
            double fx = (bx * cos(ang[i]) + by * sin(ang[i])) / lenB * dist[i];
            double fy = (-bx * sin(ang[i]) + by * cos(ang[i])) / lenB * dist[i];
            P[i+1] = Point(P[i].x + fx, P[i].y + fy);
        }
        
        // 计算预测的站点 1
        int last = n - 1;
        double bx = P[last-1].x - P[last].x;
        double by = P[last-1].y - P[last].y;
        double lenB = sqrt(bx * bx + by * by);
        double fx = (bx * cos(ang[last]) + by * sin(ang[last])) / lenB * dist[last];
        double fy = (-bx * sin(ang[last]) + by * cos(ang[last])) / lenB * dist[last];
        Point P1_pred(P[last].x + fx, P[last].y + fy);
        
        // 总长度
        double totalLen = 0;
        for (int i = 0; i < n; ++i) totalLen += dist[i];
        
        double err = distance(P[0], P1_pred);
        if (err < totalLen * 0.001)
            printf("Acceptable\n");
        else
            printf("Not acceptable\n");
    }
    return 0;
}
```
