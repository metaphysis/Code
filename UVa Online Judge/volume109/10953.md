[UVa 10953 Stochastic Digit Generator](https://blog.csdn.net/metaphysis/article/details/155538554)

## 题目翻译

一个 **随机数字生成器** （$\texttt{Stochastic Digit Generator，SDG}$）以特定概率生成一个十进制数字。 每个数字的生成概率可能不同。 假设该生成器被允许从右到左（从最低位到最高位）依次生成一个数的 $N$ 位数字。 问题是： “当这个数除以 $11$ 时， 余数为特定值的概率是多少？ ” 在这个问题中， 你需要在一些额外约束下计算这样的概率。

### 输入格式

输入文件最多包含 $51$ 组数据。 每组数据的描述如下：

1.  第一行是一个整数 $10$ ， 表示这是有效输入集， 且接下来会给出生成 $10$ 个十进制数字的概率。
2.  接下来 $10$ 行， 每行包含一个十进制数字 $d_i$ 和一个浮点数 $p_i$ （ $1 \le i \le 10$ ）。 表示生成器以概率 $p_i$ 生成数字 $d_i$ 。 所有 $d_i$ 的值互不相同， 且 $\sum_{i=1}^{10} p_i = 1$ 。
3.  接下来一行包含一个整数 $Q$ （ $0 < Q < 21$ ）， 表示该组的查询数量。
4.  接下来的 $Q$ 行， 每行包含一个格式字符串 $S_i$ （ $1 \le i \le Q$ ） 和一个整数 $r_i$ （ $0 \le r_i \le 10$ ） 。 格式字符串的每个字符要么是 `*` （星号）， 要么是一个十进制数字。 星号表示该位置生成器可以生成任何数字； 十进制数字表示该位置生成器不工作， 只生成该特定数字。 格式字符串最多有 $50$ 个字符。 整数 $r_i$ 表示生成的数字除以 $11$ 后余数应为 $r_i$ 。

输入以一个第一行为 $0$ 的块结束。

### 输出格式

对于每个输入块， 输出 $Q + 1$ 行。 输出格式如下：

1.  第一行输出 `Case X:` ， 其中 $X$ 是块的编号， 从 $1$ 开始。
2.  接下来的 $Q$ 行， 每行输出一个浮点数， 表示按照格式字符串 $S_i$ 生成的数字除以 $11$ 后余数为 $r_i$ 的概率。 结果保留八位小数。

## 题目分析与解题思路

### 问题本质

本题的核心是 **概率计算** 与 **模运算** 的结合。 给定一个数字的生成规则： 一个固定长度的字符串中， 某些位置（用数字表示）必须生成特定数字， 某些位置（用 `*` 表示）可以随机生成数字（遵循给定的概率分布）。 我们需要计算最终生成的完整数字 **除以 $11$ 后余数为指定值** 的概率。

### 关键观察

1.  **从右向左处理** ： 题目说明数字是从右向左（最低位到最高位）生成的。 这提示我们在计算过程中也应该按照这个顺序进行， 因为这样便于处理进位和模运算。 但输入的格式字符串是从左向右书写的（即最高位在最左）。 因此， 在算法实现中， 我们需要将格式字符串 **反向** 或 **从右向左访问** 。
2.  **模 $11$ 的性质** ： 我们需要计算一个数字 $N$ 除以 $11$ 的余数。 设数字 $N$ 的十进制表示为 $a_{k-1}a_{k-2} \dots a_1 a_0$ ， 其中 $a_0$ 是最低位。 则：
    $$
    N = \sum_{i=0}^{k-1} a_i \times 10^i
    $$
    因此，
    $$
    N \bmod 11 = \left( \sum_{i=0}^{k-1} a_i \times (10^i \bmod 11) \right) \bmod 11
    $$
    这里的关键是计算 $10^i \bmod 11$ 。
3.  **计算 $10^i \bmod 11$** ：
    由于 $10 \equiv -1 \pmod{11}$ ， 因此：
    $$
    10^i \bmod 11 \equiv (-1)^i \pmod{11}
    $$
    具体来说：
    - 当 $i$ 为偶数时， $10^i \bmod 11 = 1$ 。
    - 当 $i$ 为奇数时， $10^i \bmod 11 = 10$ （因为 $-1 \bmod 11 = 10$ ）。
    这是一个重要的简化， 避免了直接计算大幂次可能导致的溢出问题， 也使动态规划的状态转移更简单。

### 动态规划解法

我们可以使用 **动态规划** （$\texttt{Dynamic Programming}$） 来系统地计算所有可能的余数及其概率。

1.  **状态定义** ： 定义 $dp[pos][rem]$ 表示处理到 **从右数第 $pos$ 位** （即已经处理了最低的 $pos$ 位）时， 当前已生成的数字部分除以 $11$ 的余数为 $rem$ 的概率。
    -   $pos$ 的范围是 $0$ 到 $len$ ， 其中 $len$ 是格式字符串的长度。
    -   $rem$ 的范围是 $0$ 到 $10$ 。
2.  **初始状态** ： 当还没有处理任何位时（ $pos = 0$ ）， 数字为 $0$ ， 余数为 $0$ ， 概率为 $1.0$ 。 即 $dp[0][0] = 1.0$ ， 其余 $dp[0][\cdot] = 0.0$ 。
3.  **状态转移** ： 假设当前状态为 $dp[pos][rem]$ ， 我们要处理第 $pos$ 位（从右数， $\texttt{0-based}$）。 对应到格式字符串中的字符索引为 $charIndex = len - 1 - pos$ 。
    -   计算该位置对余数的贡献系数： $powerMod = (pos \% 2 == 0) ? 1 : 10$ 。
    -   根据格式字符串中该位置的字符 $c$ 进行转移：
        -   **如果 $c$ 是数字** （例如 `'5'` ）： 则该位置只能生成这个固定数字 $d = c - \text{‘0’}$ 。 新的余数 $newRem$ 计算方式为：
            $$
            newRem = (rem + d \times powerMod) \bmod 11
            $$
            转移方程为：
            $$
            dp[pos+1][newRem] \mathrel{+}= dp[pos][rem] \times 1.0
            $$
        -   **如果 $c$ 是 `*`** ： 则该位置可以生成任意数字 $d$ ， 每个数字 $d$ 有其生成概率 $prob[d]$ （来自输入）。 对于每个可能的数字 $d$ ， 计算：
            $$
            newRem = (rem + d \times powerMod) \bmod 11
            $$
            转移方程为：
            $$
            dp[pos+1][newRem] \mathrel{+}= dp[pos][rem] \times prob[d]
            $$
4.  **最终答案** ： 处理完所有 $len$ 位后， $dp[len][targetRem]$ 就是最终数字余数等于目标值 $targetRem$ 的概率。

### 算法复杂度分析

-   设格式字符串最大长度为 $L = 50$ 。
-   余数状态数为 $11$ 。
-   每个 `*` 位置需要枚举 $10$ 个可能的数字。
-   每个查询的时间复杂度为 $O(L \times 11 \times 10) = O(5500)$ ， 非常小。
-   最多有 $51$ 组数据， 每组最多 $20$ 个查询， 总计算量完全可以接受。

### 代码实现注意事项

1.  **输入处理** ： 注意输入块以 $10$ 开头（表示数字种类）， 但题目保证总是 $10$ 种数字（ $0$ ~ $9$ ）。
2.  **浮点数精度** ： 使用 `double` 类型存储概率， 输出时用 `fixed << setprecision(8)` 确保八位小数。
3.  **索引转换** ： 由于格式字符串从左到右是最高位到最低位， 而动态规划从最低位开始， 所以需要小心处理索引映射。

## 参考代码

```cpp
// Stochastic Digit Generator
// UVa ID: 10953
// Verdict: Accepted
// Submission Date: 2025-12-03
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int caseNo = 1;
    int D;
    while (cin >> D && D != 0) {
        vector<int> digits(D);
        vector<double> prob(D);
        for (int i = 0; i < D; i++) cin >> digits[i] >> prob[i];

        int Q;
        cin >> Q;
        vector<string> format(Q);
        vector<int> remainder(Q);
        for (int i = 0; i < Q; i++) cin >> format[i] >> remainder[i];

        cout << "Case " << caseNo++ << ":\n";
        cout << fixed << setprecision(8);

        for (int q = 0; q < Q; q++) {
            string s = format[q];
            int targetRem = remainder[q];
            int len = s.size();

            // dp[pos][rem]：处理到第pos位（从右往左数），当前余数为rem的概率
            vector<vector<double>> dp(len + 1, vector<double>(11, 0.0));
            dp[0][0] = 1.0; // 初始：0位数字，余数为0的概率为1

            for (int pos = 0; pos < len; pos++) {
                int charIndex = len - 1 - pos; // 从右往左对应字符串下标
                char c = s[charIndex];
                
                // 计算 10^pos mod 11 的值
                int powerMod;
                if (pos % 2 == 0) powerMod = 1;  // 偶数位置
                else powerMod = 10;              // 奇数位置
                
                for (int rem = 0; rem < 11; rem++) {
                    if (dp[pos][rem] == 0.0) continue;
                    
                    if (c == '*') {
                        // 可以生成任意数字
                        for (int i = 0; i < D; i++) {
                            int d = digits[i];
                            double p = prob[i];
                            // 计算新余数：(rem + d * (10^pos % 11)) % 11
                            int newRem = (rem + d * powerMod) % 11;
                            dp[pos + 1][newRem] += dp[pos][rem] * p;
                        }
                    } else {
                        // 固定数字
                        int d = c - '0';
                        int newRem = (rem + d * powerMod) % 11;
                        dp[pos + 1][newRem] += dp[pos][rem];
                    }
                }
            }

            cout << dp[len][targetRem] << "\n";
        }
    }
    return 0;
}
```

## 总结

本题是一个结合了 **概率论** 、 **模运算** 和 **动态规划** 的有趣题目。 其核心在于：
1.  理解数字的十进制表示与模 $11$ 余数的关系。
2.  发现 $10^i \bmod 11$ 的简单规律（奇偶性决定）， 这大大简化了计算。
3.  设计合适的状态表示和转移方程， 逐步累加概率。
4.  注意输入输出的细节和浮点数的精度控制。

掌握这类问题有助于加深对模运算性质的理解， 以及如何将概率模型与动态规划结合解决复杂计数/概率问题。
