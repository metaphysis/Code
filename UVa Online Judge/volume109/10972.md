## 题目描述

$\texttt{Basm}$ 想要将 $\texttt{RevolC FacLoN}$ 地区的道路改为单向行驶，以降低骆驼事故率。他希望改造后的道路系统满足：从任意一个城市都可以到达其他任意城市。现在给定 $n$ 个城市和 $m$ 条双向道路，请你计算最少需要额外修建多少条单向道路，才能实现 $\texttt{Basm}$ 的目标。

**注意**：在修建新道路时，可以在已经存在道路的两个城市之间再修建新的道路。

### 输入格式
输入包含多个测试用例。每个测试用例首先给出两个整数 $n$ ($1 \leq n \leq 1000$) 和 $m$，分别表示城市数量和道路数量。接下来 $m$ 行，每行两个整数 $u$ 和 $v$，表示城市 $u$ 和 $v$ 之间有一条双向道路。输入以 EOF 结束。

### 输出格式
对于每个测试用例，输出需要修建的最少单向道路数量。

### 样例输入
```
3 2
1 2
2 3
10 11
1 2
2 3
3 1
3 7
4 5
5 6
6 4
7 9
6 3
9 8
7 8
```

### 样例输出
```
1
```

## 题目分析

本题要求将无向图转换为强连通的有向图，并求出需要添加的最少边数。这是一个经典的图论问题，关键在于理解无向图与有向图强连通性之间的关系。

### 核心洞察

1. **问题转化**：将无向图转换为强连通有向图的问题，等价于将原无向图转换为**边双连通图**的问题。对于边双连通的无向图，总存在一种边定向方式，使其成为强连通有向图。

2. **边双连通分量**：如果一个无向连通图中没有**桥**（即删除该边后图不再连通的边），则该图是边双连通的。边双连通分量是极大的边双连通子图。

3. **缩点技术**：将每个边双连通分量缩成一个点，原图就变成了一棵树（如果原图连通）或森林（如果原图不连通）。

### 解题思路

1. **寻找边双连通分量**：使用 $\texttt{Tarjan}$ 算法找出所有的桥，然后通过 $\texttt{DFS}$ 找出所有的边双连通分量。

2. **构建缩点图**：将每个边双连通分量视为一个节点，桥视为连接这些节点的边，形成一个森林。

3. **统计度数**：在缩点后的森林中，统计每个节点的度数：
   - **孤立节点**：度数为 $0$ 的分量（与其他分量无连接）
   - **叶子节点**：度数为 $1$ 的分量

4. **计算结果**：
   - 如果整个图已经是一个边双连通分量，答案为 $0$
   - 否则，答案为：$\text{孤立分量数} + \frac{\text{叶子分量数} + 1}{2}$

### 算法正确性分析

- **孤立分量**：每个孤立分量至少需要一条边与其他分量连接
- **叶子分量**：叶子分量需要配对连接，$\frac{\text{叶子数} + 1}{2}$ 确保了最优配对
- **综合处理**：这个公式同时处理了图连通和不连通的情况

## 复杂度分析

- **时间复杂度**：$\texttt{Tarjan}$ 算法的时间复杂度为 $O(n + m)$，其中 $n$ 是节点数，$m$ 是边数。
- **空间复杂度**：$O(n + m)$，用于存储图结构和算法所需的辅助数组。

```cpp
// RevolC FacLoN

#include <iostream>
#include <vector>
#include <cstring>
#include <algorithm>
using namespace std;

const int MAXN = 1005;
const int MAXM = 1000005;

struct Edge {
    int u, v;
    Edge(int u = 0, int v = 0) : u(u), v(v) {}
};

vector<int> graph[MAXN];
Edge edges[MAXM * 2];
int n, m, stamp;
int dfn[MAXN], low[MAXN], bccno[MAXN], bccCnt;
bool isBridge[MAXM * 2];

void tarjan(int u, int fa) {
    dfn[u] = low[u] = ++stamp;
    for (int i = 0; i < graph[u].size(); i++) {
        int edgeId = graph[u][i];
        int v = edges[edgeId].v;
        
        if (!dfn[v]) {
            tarjan(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) {
                isBridge[edgeId] = isBridge[edgeId ^ 1] = true;
            }
        } else if (dfn[v] < dfn[u] && v != fa) {
            low[u] = min(low[u], dfn[v]);
        }
    }
}

void dfs(int u) {
    dfn[u] = 1;
    bccno[u] = bccCnt;
    for (int i = 0; i < graph[u].size(); i++) {
        int edgeId = graph[u][i];
        if (isBridge[edgeId]) continue;
        int v = edges[edgeId].v;
        if (!dfn[v]) {
            dfs(v);
        }
    }
}

void findEdgeBcc() {
    bccCnt = stamp = 0;
    memset(dfn, 0, sizeof(dfn));
    memset(low, 0, sizeof(low));
    memset(bccno, 0, sizeof(bccno));
    memset(isBridge, false, sizeof(isBridge));
    
    // 第一遍Tarjan找桥
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, -1);
        }
    }
    
    // 第二遍DFS找边双连通分量
    memset(dfn, 0, sizeof(dfn));
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            bccCnt++;
            dfs(i);
        }
    }
}

int main() {
    while (cin >> n >> m) {
        // 初始化
        for (int i = 1; i <= n; i++) {
            graph[i].clear();
        }
        
        // 读入图
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            edges[i * 2] = Edge(u, v);
            edges[i * 2 + 1] = Edge(v, u);
            graph[u].push_back(i * 2);
            graph[v].push_back(i * 2 + 1);
        }
        
        findEdgeBcc();
        
        if (bccCnt == 1) {
            cout << "0\n";
        } else {
            // 统计每个边双连通分量的度数
            vector<int> degree(bccCnt + 1, 0);
            for (int i = 0; i < m * 2; i += 2) {
                int u = edges[i].u, v = edges[i].v;
                if (bccno[u] != bccno[v]) {
                    degree[bccno[u]]++;
                    degree[bccno[v]]++;
                }
            }
            
            // 统计孤立分量和叶子分量
            int isolatedCount = 0;  // 度数为0的分量
            int leafCount = 0;      // 度数为1的分量
            
            for (int i = 1; i <= bccCnt; i++) {
                if (degree[i] == 0) {
                    isolatedCount++;
                } else if (degree[i] == 1) {
                    leafCount++;
                }
            }
            
            // 结果 = 孤立分量数 + (叶子分量数 + 1) / 2
            int result = isolatedCount + (leafCount + 1) / 2;
            cout << result << "\n";
        }
    }
    
    return 0;
}
```

## 总结

本题通过将问题转化为边双连通分量问题，利用 $\texttt{Tarjan}$ 算法高效地解决了最小加边使图强连通的问题。关键在于理解边双连通分量与强连通有向图之间的关系，以及如何通过缩点技术将复杂问题简化为树的叶子节点计数问题。

这种思路不仅适用于本题，还可以推广到其他需要增强图连通性的问题中，是图论中一个重要的解题技巧。
