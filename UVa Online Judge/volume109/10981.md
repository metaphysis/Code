## 题目大意

我们被给予一个特殊的乘法运算表，该运算作用于两个字符 $a$、$b$、$c$ 之间，运算规则如下表：

| 右\左 | $a$ | $b$ | $c$ |
|-------|-----|-----|-----|
| $a$   | $b$ | $b$ | $a$ |
| $b$   | $c$ | $b$ | $a$ |
| $c$   | $a$ | $c$ | $c$ |

例如：
- $ab = b$
- $ba = c$
- $bc = a$
- $cb = c$

现在给定一个初始字符串（长度不超过 $100$ ，字符只包含 $a$、$b$、$c$ ）和一个目标字符（ $a$、$b$ 或 $c$ ），我们可以通过不断选择相邻的两个字符，根据上表合并为一个新字符，最终将整个字符串变为单个字符。

**要求**：如果能够通过某种合并顺序将字符串变为目标字符，则输出每一步合并后的字符串（每一步选择合并位置时，应优先从左侧开始合并）。如果无法变为目标字符，则输出 `None exist!` 。多个测试用例之间用空行分隔。

## 题目分析与解题思路

### 问题本质

这是一个典型的 **区间合并问题** ，类似于矩阵链乘或表达式求值，但合并规则是给定的非结合性运算。我们需要判断一个字符串能否通过相邻合并最终得到目标字符，并输出合并过程。

### 关键点分析

1. **合并运算的确定性**：给定两个字符，合并结果是唯一确定的（由表格定义）。
2. **合并顺序的影响**：由于运算不满足结合律，不同的括号化（即不同的合并顺序）可能导致不同的最终结果。
3. **输出要求**：要求输出具体合并步骤，且在有多种可能时优先从左侧开始合并。
4. **数据规模**：字符串长度 $\leq 100$ ，允许 $O(n^3)$ 的动态规划算法。

### 解题思路概述

我们可以将问题拆分为两个子任务：

1. **可行性判断**：判断给定字符串能否合并为目标字符。
2. **构造方案**：在可行的基础上，构造出从左侧优先合并的步骤序列。

#### 子任务一：可行性判断（区间动态规划）

定义 $dp[i][j]$ 为一个位掩码，表示子串 $s[i..j]$ 能够合并成的字符集合。例如：
- 如果 $dp[i][j]$ 的第 $0$ 位为 $1$ ，表示该子串可以合并为 $a$ 。
- 如果第 $1$ 位为 $1$ ，则可以合并为 $b$ 。
- 如果第 $2$ 位为 $1$ ，则可以合并为 $c$ 。

**状态转移**：  
对于区间 $[i, j]$ ，枚举分割点 $k$ （ $i \le k < j$ ），将区间分为 $[i, k]$ 和 $[k+1, j]$ 。设左区间能合并成的字符集合为 $L$ ，右区间为 $R$ 。对于 $L$ 中的每个字符 $lc$ 和 $R$ 中的每个字符 $rc$ ，计算 $res = mult(lc, rc)$ ，将 $res$ 对应的位加入到 $dp[i][j]$ 中。

初始条件：对于长度为 $1$ 的区间 $[i, i]$ ， $dp[i][i]$ 就是 $s[i]$ 对应的位掩码。

最终，如果 $dp[0][n-1]$ 中包含目标字符对应的位，则说明可行。

**同时记录路径**：在枚举分割点 $k$ 时，记录第一个能够合并出某个字符 $ch$ 的分割点以及左右子区间对应的字符。用 $par[i][j][ch]$ 存储三元组 $(k, lc, rc)$ ，其中 $lc$ 和 $rc$ 分别是左右子区间合并成的字符，且 $mult(lc, rc) = ch$ 。

#### 子任务二：构造左侧优先合并步骤

已知整个字符串可以合并为目标字符，我们需要模拟合并过程，且每次合并时优先选择最左侧的可行位置。

**策略**：  
从当前字符串出发，从左到右枚举相邻的两个字符 $s[i]$ 和 $s[i+1]$ ，计算合并结果 $res = mult(s[i], s[i+1])$ 。将这两个字符替换为 $res$ ，得到新字符串 $s'$ 。然后判断 $s'$ 是否能够继续合并为目标字符（即调用上面的区间 DP 判断）。如果能够，则选择这个位置进行合并，记录步骤，并继续。如果枚举完所有相邻位置都无法继续，则说明无法构造（但此时已知可行，所以不会发生）。

**为什么这样做正确**：  
因为要求“优先从左侧开始合并”，我们只需要在每一步都选择最左侧的、合并后仍然能够到达目标字符的位置即可。这相当于在所有的可行合并顺序中，选择了一种最左侧优先的贪心顺序。

### 算法复杂度

- 区间 DP 部分：状态数 $O(n^2)$ ，转移枚举分割点 $O(n)$ ，枚举左右字符组合 $O(3 \times 3) = O(9)$ ，总复杂度 $O(9 \cdot n^3)$ ，在 $n \leq 100$ 时可行。
- 构造步骤部分：最多合并 $n-1$ 次，每次需要 $O(n)$ 枚举位置并调用一次区间 DP 判断，总复杂度 $O(n^4)$ ，在 $n=100$ 时可能接近极限，但实际常数较小，可以接受。

## 代码实现

```cpp
// String Morphing
// UVa ID: 10981
// Verdict: Accepted

#include <bits/stdc++.h>
using namespace std;

// 特殊乘法表
char mult(char left, char right) {
    static const string table = "abc";
    static const char res[3][3] = {
        {'b', 'b', 'a'},
        {'c', 'b', 'a'},
        {'a', 'c', 'c'}
    };
    int li = left - 'a';
    int ri = right - 'a';
    return res[li][ri];
}

// 记录每个区间能变成的字符集合（用位掩码表示）
// 同时记录合并路径：par[i][j][ch] = 分割点k，左右子区间的结果字符
const int MAXN = 105;
int dp[MAXN][MAXN]; // 位掩码：1<<0='a', 1<<1='b', 1<<2='c'
pair<int, pair<char, char>> par[MAXN][MAXN][3]; // par[i][j][c] = (k, leftChar, rightChar)

bool solve(const string& s, char target) {
    int n = s.size();
    memset(dp, 0, sizeof(dp));

    // 初始化长度为1的区间
    for (int i = 0; i < n; i++) {
        int idx = s[i] - 'a';
        dp[i][i] = (1 << idx);
    }

    // 区间DP
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len <= n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                int leftMask = dp[i][k];
                int rightMask = dp[k + 1][j];
                if (leftMask == 0 || rightMask == 0) continue;

                // 枚举左右可能的字符组合
                for (int li = 0; li < 3; li++) if (leftMask & (1 << li))
                    for (int ri = 0; ri < 3; ri++) if (rightMask & (1 << ri)) {
                        char lc = 'a' + li;
                        char rc = 'a' + ri;
                        char res = mult(lc, rc);
                        int ridx = res - 'a';
                        dp[i][j] |= (1 << ridx);
                        // 记录第一个可行的分割点（因为从左到右枚举k）
                        if (par[i][j][ridx].first == -1) {
                            par[i][j][ridx] = {k, {lc, rc}};
                        }
                    }
            }
        }
    }

    int tidx = target - 'a';
    return (dp[0][n - 1] & (1 << tidx)) != 0;
}

// 递归构造并输出变换步骤
vector<string> steps;
void buildPath(const string& s, int i, int j, char target) {
    if (i == j) return;
    int tidx = target - 'a';
    auto& p = par[i][j][tidx];
    int k = p.first;
    char lc = p.second.first;
    char rc = p.second.second;
    char res = mult(lc, rc); // 应等于target
    // 递归处理左区间
    buildPath(s, i, k, lc);
    // 递归处理右区间
    buildPath(s, k + 1, j, rc);
    // 构造当前步骤字符串
    string cur;
    for (int idx = i; idx <= j; idx++) cur += s[idx];
    steps.push_back(cur);
}

// 每次合并后更新字符串
string mergeString(const string& s, int i, int j, char target) {
    int tidx = target - 'a';
    auto& p = par[i][j][tidx];
    int k = p.first;
    char lc = p.second.first;
    char rc = p.second.second;
    // 递归合并左右区间
    string leftStr = (i == k) ? string(1, lc) : mergeString(s, i, k, lc);
    string rightStr = (k + 1 == j) ? string(1, rc) : mergeString(s, k + 1, j, rc);
    return leftStr + rightStr;
}

void outputSteps(const string& s, char target) {
    steps.clear();
    int n = s.size();
    // 先记录原始字符串
    steps.push_back(s);
    string cur = s;
    // 逐步合并，每次合并最左边可合并的两个字符
    while (cur.size() > 1) {
        // 从左到右找第一个可合并的位置，使得合并后仍可能达到target
        bool found = false;
        for (int i = 0; i < cur.size() - 1; i++) {
            char lc = cur[i];
            char rc = cur[i + 1];
            char res = mult(lc, rc);
            // 临时构造新字符串
            string nextStr = cur.substr(0, i) + res + cur.substr(i + 2);
            // 判断新字符串是否能变成target
            memset(dp, 0, sizeof(dp));
            if (solve(nextStr, target)) {
                cur = nextStr;
                steps.push_back(cur);
                found = true;
                break;
            }
        }
        if (!found) break;
    }
    // 输出步骤
    for (const string& step : steps) cout << step << endl;
}

int main() {
    int t; cin >> t;
    bool firstCase = true;
    while (t--) {
        if (!firstCase) cout << endl;
        firstCase = false;

        string s; cin >> s;
        char target; cin >> target;

        // 初始化par数组
        for (int i = 0; i < MAXN; i++)
            for (int j = 0; j < MAXN; j++)
                for (int ch = 0; ch < 3; ch++)
                    par[i][j][ch].first = -1;

        if (solve(s, target)) outputSteps(s, target);
        else cout << "None exist!" << endl;
    }
    return 0;
}
```

## 总结

本题是一道结合了 **区间动态规划** 与 **构造性输出** 的经典题目。通过区间动态规划我们可以高效判断可行性并记录合并路径，再通过贪心策略模拟合并过程，得到符合要求的步骤序列。需要注意的细节包括：

1. 运算表的存储与调用。
2. 区间动态规划中位掩码的使用，减少状态数。
3. 路径记录数组的初始化与更新。
4. 输出格式中测试用例之间的空行。

最终算法在时间和空间上均满足题目要求，且能够正确输出左侧优先的合并步骤。
