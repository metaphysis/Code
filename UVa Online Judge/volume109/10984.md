[UVa 10984 Double NP-hard](https://blog.csdn.net/metaphysis/article/details/156533172)

## 题目描述

### 问题背景

在图论中，给定一个包含 $n$ 个顶点和 $m$ 条边的无向图 $G$ ，我们需要找到满足以下条件的顶点集合 $C$ ：

1. $C$ 是一个**最小顶点覆盖**：即每条边至少有一个端点在 $C$ 中，且 $C$ 的大小是所有顶点覆盖中最小的。
2. $C$ 是一个**最大独立集**：即 $C$ 中没有边（任意两个顶点不相邻），且 $C$ 的大小是所有独立集中最大的。

这是一个被称为 **“$\texttt{Double NP-hard}$”** 的问题，因为它结合了两个经典的 $\texttt{NP-hard}$ 问题。

### 输入格式

- 第一行：测试用例数量 $N$ 。
- 每个测试用例：
  - 第一行：$n$ （$0 \le n \le 1000$） 和 $m$ （$0 \le m \le 100000$）。
  - 接下来的 $m$ 行：每行两个整数 $u$ 和 $v$ ，表示一条边。

### 输出格式

对于每个测试用例：
- 如果无解，输出 `Case #x: Impossible` 。
- 如果有解：
  - 第一行： `Case #x: k` ，其中 $k$ 是集合 $C$ 的大小。
  - 第二行：按升序输出 $C$ 中的顶点，如果有多个解，输出字典序最小的。

## 题目分析

### 核心观察

设：
- $\tau(G)$ 表示最小顶点覆盖的大小
- $\alpha(G)$ 表示最大独立集的大小

对于任意图，有以下重要关系：

$$
\tau(G) + \alpha(G) = n
$$

这是因为一个集合是独立集当且仅当它的补集是顶点覆盖。因此，如果 $C$ 要同时满足两个条件，必须有：

$$
\tau(G) = \alpha(G) = \frac{n}{2}
$$

由此得到第一个必要条件：

**条件1：$n$ 必须是偶数**。

### 二分图必要性

考虑一个奇数长度的环（长度为 $2k+1$ ）：
- 在奇数环中，最大独立集的大小最多为 $k$（不能取相邻顶点）
- 最小顶点覆盖的大小至少为 $k+1$（覆盖所有边）

因此 $\tau(G) \ge k+1 > k \ge \alpha(G)$ ，两者不可能相等。这证明了：

**条件2：图必须是二分图**（不含奇数环）。

### 二分图的性质

设二分图划分为 $X$ 部和 $Y$ 部，大小为 $|X|$ 和 $|Y|$ 。我们知道：

1. 最小顶点覆盖大小 = 最大匹配数 $\le \min(|X|, |Y|)$
2. 最大独立集大小 = $n$ - 最大匹配数 $\ge \max(|X|, |Y|)$

要满足 $\tau(G) = \alpha(G) = \frac{n}{2}$ ，必须有：

- $|X| = |Y| = \frac{n}{2}$
- 最大匹配数 = $\frac{n}{2}$（即完美匹配）

因此得到：

**条件3：$X$ 部和 $Y$ 部必须大小相等**。
**条件4：图必须存在完美匹配**。

### 解的性质

如果满足以上条件，那么 $X$ 部和 $Y$ 部中的任意一个都是符合条件的解：
- $X$ 是顶点覆盖：因为每条边连接 $X$ 和 $Y$ ，所以至少有一个端点在 $X$ 中
- $X$ 是独立集：因为 $X$ 内部没有边
- $X$ 是最小的：因为任何顶点覆盖必须至少包含 $|X|$ 个顶点（由 $\texttt{Kőnig}$ 定理）
- $X$ 是最大的：因为任何独立集最多包含 $|X|$ 个顶点

同理， $Y$ 也满足条件。我们需要输出字典序较小的那个。

### 算法步骤总结

1. **检查 $n$ 是否为偶数**：如果不是，输出 `Impossible` 。
2. **判断是否为二分图**：使用 $\texttt{BFS}$ 或 $\texttt{DFS}$ 进行染色。
3. **检查两部分大小是否相等**：如果不等，输出 `Impossible` 。
4. **检查是否存在完美匹配**：使用匈牙利算法或 $\texttt{Hopcroft-Karp}$ 算法。
5. **输出结果**：选择字典序较小的部分，按升序输出。

## 解题思路详解

### 步骤1：二分图判断

使用 $\texttt{BFS}$ 进行二染色：
- 初始化所有顶点颜色为 $-1$（未染色）
- 遍历每个顶点，如果未染色，则将其染为颜色 $0$ ，并加入队列
- $\texttt{BFS}$ 过程中，对于每个顶点 $u$ ，遍历其邻接点 $v$ ：
  - 如果 $v$ 未染色，将其染为与 $u$ 相反的颜色
  - 如果 $v$ 已染色且颜色与 $u$ 相同，说明存在奇数环，不是二分图

同时，我们将颜色为 $0$ 的顶点放入 `partX` ，颜色为 $1$ 的顶点放入 `partY` 。

### 步骤2：完美匹配检查

在二分图中，我们需要检查是否存在大小为 $\frac{n}{2}$ 的完美匹配。这里使用 **$\texttt{Hopcroft-Karp}$ 算法** ，它是匈牙利算法的优化版本，时间复杂度为 $O(E\sqrt{V})$ ，适合本题的数据范围。

算法关键点：
- **$\texttt{BFS}$ 分层**：从 $X$ 部所有未匹配点开始，构建分层图
- **$\texttt{DFS}$ 增广**：沿分层图寻找增广路
- 重复上述过程直到无法增广

### 步骤3：字典序处理

由于 `partX` 和 `partY` 都是解，我们只需要选择字典序较小的那个：
- 使用 `min(partX, partY)` 进行比较
- 注意要先排序，因为染色过程不一定按顶点顺序

### 特殊情况的处理

- **$n = 0$** ：空图，解为空集，输出 $0$
- **$m = 0$** ：无边图，如果 $n > 0$ 且为偶数，是否是二分图？
  - 无边图可以划分为任意两个部分
  - 但不存在完美匹配（因为根本没有边），所以输出 `Impossible`

## 时间复杂度分析

1. **二分图判断**：$O(n + m)$
2. **$\texttt{Hopcroft-Karp}$ 算法**：$O(m\sqrt{n})$
3. **排序输出**：$O(n\log n)$

总时间复杂度：$O(m\sqrt{n})$ ，在 $n \le 1000, m \le 100000$ 范围内完全可行。

## 空间复杂度分析

- 邻接表：$O(n + m)$
- 染色数组：$O(n)$
- $\texttt{Hopcroft-Karp}$ 算法相关数组：$O(n)$

总空间复杂度：$O(n + m)$

```cpp
// Double NP-hard

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
vector<int> graph[MAXN];
int color[MAXN];
int n, m;

// 染色判断二分图
bool isBipartite(vector<int>& partX, vector<int>& partY) {
    memset(color, -1, sizeof(color));
    for (int i = 1; i <= n; i++) {
        if (color[i] == -1) {
            queue<int> q;
            q.push(i);
            color[i] = 0;
            while (!q.empty()) {
                int u = q.front(); q.pop();
                if (color[u] == 0) partX.push_back(u);
                else partY.push_back(u);
                for (int v : graph[u]) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        q.push(v);
                    } else if (color[v] == color[u]) return false;
                }
            }
        }
    }
    return true;
}

// Hopcroft-Karp 最大匹配
class HopcroftKarp {
    vector<int> graph[MAXN];
    int matchX[MAXN], matchY[MAXN];
    int distX[MAXN], distY[MAXN];
    int n;
    
public:
    HopcroftKarp(int size) : n(size) {
        memset(matchX, -1, sizeof(matchX));
        memset(matchY, -1, sizeof(matchY));
    }
    
    void addEdge(int u, int v) {
        graph[u].push_back(v);
    }
    
    bool bfs() {
        queue<int> q;
        memset(distX, -1, sizeof(distX));
        memset(distY, -1, sizeof(distY));
        
        for (int u = 1; u <= n; u++) 
            if (matchX[u] == -1) {
                distX[u] = 0;
                q.push(u);
            }
        
        bool found = false;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : graph[u]) {
                if (distY[v] == -1) {
                    distY[v] = distX[u] + 1;
                    if (matchY[v] == -1) found = true;
                    else {
                        distX[matchY[v]] = distY[v] + 1;
                        q.push(matchY[v]);
                    }
                }
            }
        }
        return found;
    }
    
    bool dfs(int u) {
        for (int v : graph[u]) {
            if (distY[v] == distX[u] + 1) {
                distY[v] = 0;  // 标记已访问
                if (matchY[v] == -1 || dfs(matchY[v])) {
                    matchX[u] = v;
                    matchY[v] = u;
                    return true;
                }
            }
        }
        return false;
    }
    
    int maxMatch() {
        int matching = 0;
        while (bfs()) {
            for (int u = 1; u <= n; u++) 
                if (matchX[u] == -1 && dfs(u)) matching++;
        }
        return matching;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    
    for (int caseNum = 1; caseNum <= T; caseNum++) {
        cin >> n >> m;
        
        // 初始化
        for (int i = 1; i <= n; i++) graph[i].clear();
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            graph[u].push_back(v);
            graph[v].push_back(u);
        }
        
        cout << "Case #" << caseNum << ": ";
        
        // 特殊情况：空图
        if (n == 0) {
            cout << "0\n\n";
            continue;
        }
        
        // n必须是偶数
        if (n % 2 != 0) {
            cout << "Impossible\n";
            continue;
        }
        
        // 检查是否为二分图
        vector<int> partX, partY;
        if (!isBipartite(partX, partY)) {
            cout << "Impossible\n";
            continue;
        }
        
        // 检查两部分大小是否相等
        if (partX.size() != partY.size()) {
            cout << "Impossible\n";
            continue;
        }
        
        // 检查是否存在完美匹配
        HopcroftKarp hk(n);
        // 构建二分图的单向边（从X部到Y部）
        for (int u : partX) 
            for (int v : graph[u]) 
                if (color[v] == 1) hk.addEdge(u, v);  // v在Y部
        
        int matching = hk.maxMatch();
        
        if (matching * 2 != n) {  // 需要完美匹配
            cout << "Impossible\n";
            continue;
        }
        
        // 选择字典序小的部分
        vector<int> result = min(partX, partY);
        cout << result.size() << '\n';
        
        // 输出结果
        if (!result.empty()) {
            sort(result.begin(), result.end());
            for (size_t i = 0; i < result.size(); i++) {
                if (i > 0) cout << ' ';
                cout << result[i];
            }
            cout << '\n';
        }
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解 **最小顶点覆盖** 和 **最大独立集** 之间的关系，以及二分图的相关性质。通过严谨的数学推导，我们将一个看似复杂的 **“$\texttt{Double NP-hard}$”** 问题转化为判断图是否为 **具有完美匹配的平衡二分图** 的问题。

解题步骤清晰：
1. 检查 $n$ 的奇偶性
2. 判断是否为二分图
3. 检查两部分是否平衡
4. 检查是否存在完美匹配

算法实现上，使用 $\texttt{BFS}$ 进行二染色判断二分图，使用 $\texttt{Hopcroft-Karp}$ 算法高效求解最大匹配，最终输出字典序较小的解。
