## 题目描述

卡尔加里大学的 $\texttt{ACM}$ 队伍（队员 $\texttt{Alec}$, $\texttt{Celly}$ 和 $\texttt{Monny}$ 的缩写）获得了 $\texttt{ACM ICPC}$ 世界总决赛的资格。为了准备比赛，他们决定前往埃德蒙顿向 $\texttt{Alberta}$ 省著名的顶级编程高手 $\texttt{Dilbert}$ 请教。

由于沟通失误， $A$ （$\texttt{Alec}$）、 $C$ （$\texttt{Celly}$）和 $M$ （$\texttt{Monny}$）三人分别驾驶三辆车从卡尔加里出发前往埃德蒙顿。更糟糕的是，他们与 $D$ （$\texttt{Dilbert}$）也沟通失误了， $D$ 决定从埃德蒙顿出发前往卡尔加里，以节省团队北上严寒的旅程。所有事件都发生在同一天，每辆车都以恒定速度（速度不一定相同）在 $\texttt{Alberta}$ $2$ 号公路上行驶。

已知以下五个事件的发生时间（按递增顺序给出）：

- $t_1$ ： $A$ 超过 $C$ 的时间
- $t_2$ ： $A$ 超过 $M$ 的时间  
- $t_3$ ： $A$ 与 $D$ 相遇的时间
- $t_4$ ： $D$ 与 $C$ 相遇的时间
- $t_5$ ： $D$ 与 $M$ 相遇的时间

所有时间都以 `hh:mm:ss` 格式的 $24$ 小时制给出。问题是： $C$ 超过 $M$ 的时间是什么？

## 输入格式

输入包含多行，每行包含五个时间 $t_1, t_2, t_3, t_4, t_5$ ，用空白字符分隔。所有时间都不同且按递增顺序给出。以一行只包含 `-1` 的行结束输入。

## 输出格式

对于每一行输入，输出 $C$ 超过 $M$ 的时间，格式与输入相同，秒数按标准方式四舍五入到整数。

## 样例输入

```
10:00:00 11:00:00 12:00:00 13:00:00 14:00:00
10:20:00 10:58:00 14:32:00 14:59:00 16:00:00
10:20:00 12:58:00 14:32:00 14:59:00 16:00:00
08:00:00 09:00:00 10:00:00 12:00:00 14:00:00
-1
```

## 样例输出

```
12:00:00
11:16:54
13:37:32
10:40:00
```

## 题目分析

### 物理模型建立

这是一个**相对运动**问题。我们可以建立以下模型：

1. **路线**：卡尔加里（起点，位置 $0$ ）到埃德蒙顿（终点，位置 $L$ ），距离为 $L$ 。
2. **车辆与方向**：
   - $M$ 、 $C$ 、 $A$ 从卡尔加里出发，向埃德蒙顿行驶（正方向）。
   - $D$ 从埃德蒙顿出发，向卡尔加里行驶（负方向）。
3. **出发时间**：由于 $A$ 能追上 $C$ 和 $M$ ，说明 $A$ 的速度最快且出发最晚。因此出发时间顺序为： $T_M < T_C < T_A$ 。
4. **速度**： $v_A > v_C > v_M > 0$ ， $v_D > 0$ （ $v_D$ 表示 $D$ 向卡尔加里方向行驶的速度大小）。
5. **匀速运动**：所有车辆都以恒定速度行驶。

### 位置函数

设 $T_X$ 为车辆 $X$ 的出发时间， $v_X$ 为其速度。位置函数为：

- $x_M(t) = v_M (t - T_M)$
- $x_C(t) = v_C (t - T_C)$
- $x_A(t) = v_A (t - T_A)$
- $x_D(t) = L - v_D (t - T_D)$

### 事件方程

五个已知事件对应以下方程：

1. $A$ 与 $C$ 在 $t_1$ 相遇： $v_A (t_1 - T_A) = v_C (t_1 - T_C)$
2. $A$ 与 $M$ 在 $t_2$ 相遇： $v_A (t_2 - T_A) = v_M (t_2 - T_M)$
3. $A$ 与 $D$ 在 $t_3$ 相遇： $v_A (t_3 - T_A) = L - v_D (t_3 - T_D)$
4. $D$ 与 $C$ 在 $t_4$ 相遇： $v_C (t_4 - T_C) = L - v_D (t_4 - T_D)$
5. $D$ 与 $M$ 在 $t_5$ 相遇： $v_M (t_5 - T_M) = L - v_D (t_5 - T_D)$

所求 $C$ 追上 $M$ 的时间 $t_{CM}$ 满足：
$$
v_C (t_{CM} - T_C) = v_M (t_{CM} - T_M)
$$

## 解题思路

### 关键简化

为了简化问题，我们可以进行归一化处理：

1. **设 $A$ 的速度为 $1$** ： $v_A = 1$ 。这不会影响相对时间关系，因为所有速度都是相对的。
2. **设 $M$ 的出发时间为 $0$** ： $T_M = 0$ 。这相当于以 $M$ 的出发时间为时间原点。

### 相对速度的计算

从事件 $1$ 和 $3$ 、 $4$ 可以推导出 $C$ 的相对速度 $v_C$ ：

从 $A$ 与 $C$ 在 $t_1$ 相遇，到 $A$ 与 $D$ 在 $t_3$ 相遇， $A$ 行驶了 $t_3 - t_1$ 的距离（因为 $v_A = 1$ ）。

在同一时间段，从 $A$ 与 $C$ 相遇到 $D$ 与 $C$ 相遇（ $t_4$ ）， $C$ 行驶了 $v_C \cdot (t_4 - t_1)$ 的距离。

由于 $A$ 和 $D$ 相向而行，这两个距离存在比例关系。实际上，经过推导可得：
$$
v_C = \frac{t_3 - t_1}{t_4 - t_1}
$$

类似地，从事件 $2$ 、 $3$ 、 $5$ 可以推导出 $M$ 的相对速度 $v_M$ ：
$$
v_M = \frac{t_3 - t_2}{t_5 - t_2}
$$

### $C$ 追上 $M$ 的时间推导

设 $A$ 与 $C$ 在 $t_1$ 相遇时， $M$ 在 $A$ 前方距离为 $d$ 。

在 $t_1$ 时刻， $A$ 和 $C$ 在同一位置。 $A$ 与 $M$ 在 $t_2$ 时刻相遇，因此在 $t_1$ 到 $t_2$ 这段时间内：

- $A$ 行驶了 $t_2 - t_1$ 的距离（因为 $v_A = 1$ ）。
- $M$ 行驶了 $v_M \cdot (t_2 - t_1)$ 的距离。

由于 $A$ 在 $t_2$ 追上 $M$ ，所以在 $t_1$ 时刻， $M$ 在 $A$ 前方的距离为：
$$
d = (1 - v_M) \cdot (t_2 - t_1)
$$

$C$ 要追上 $M$ ，需要弥补这个距离差 $d$ 。 $C$ 相对于 $M$ 的速度为 $v_C - v_M$ ，所以所需时间为：
$$
\Delta t = \frac{d}{v_C - v_M} = \frac{(1 - v_M) \cdot (t_2 - t_1)}{v_C - v_M}
$$

因此 $C$ 追上 $M$ 的时间为：
$$
t_{CM} = t_1 + \Delta t = t_1 + \frac{(1 - v_M) \cdot (t_2 - t_1)}{v_C - v_M}
$$

### 算法步骤

1. 读入五个时间 $t_1, t_2, t_3, t_4, t_5$ ，将其转换为秒数。
2. 计算相对速度：
$$
   v_C = \frac{t_3 - t_1}{t_4 - t_1}, \quad v_M = \frac{t_3 - t_2}{t_5 - t_2}
$$
3. 计算 $C$ 追上 $M$ 的时间：
$$
   t_{CM} = t_1 + \frac{(1 - v_M) \cdot (t_2 - t_1)}{v_C - v_M}
$$
4. 将 $t_{CM}$ 四舍五入到整数秒，转换回 `hh:mm:ss` 格式输出。

### 边界情况处理

- 输入保证所有时间不同且递增，所以分母 $t_4 - t_1$ 、 $t_5 - t_2$ 、 $v_C - v_M$ 都不为零。
- 由于 $v_A > v_C > v_M$ ，所以 $v_C - v_M > 0$ ，公式有效。
- 四舍五入时需要注意浮点数精度，可以加上一个小常数（如 $10^{-6}$ ）避免舍入误差。

## 复杂度分析

- **时间复杂度**： $O(1)$ ，每个测试用例只需常数次算术运算。
- **空间复杂度**： $O(1)$ ，只需存储几个变量。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 将时间字符串转换为秒数
int timeToSeconds(const string& t) {
    int h, m, s;
    sscanf(t.c_str(), "%d:%d:%d", &h, &m, &s);
    return h * 3600 + m * 60 + s;
}

// 将秒数转换为时间字符串，四舍五入到整数秒
string secondsToTime(double sec) {
    sec = round(sec);
    int total = (int)sec;
    int h = total / 3600;
    int m = (total % 3600) / 60;
    int s = total % 60;
    char buf[10];
    sprintf(buf, "%02d:%02d:%02d", h, m, s);
    return string(buf);
}

int main() {
    string line;
    while (getline(cin, line)) {
        if (line == "-1") break;
        
        vector<string> tokens;
        stringstream ss(line);
        string token;
        while (ss >> token) tokens.push_back(token);
        
        if (tokens.size() != 5) continue;
        
        // 转换为秒
        double t1 = timeToSeconds(tokens[0]);  // A passed C
        double t2 = timeToSeconds(tokens[1]);  // A passed M
        double t3 = timeToSeconds(tokens[2]);  // A met D
        double t4 = timeToSeconds(tokens[3]);  // D met C
        double t5 = timeToSeconds(tokens[4]);  // D met M
        
        // 计算相对速度
        double vc = (t3 - t1) / (t4 - t1);
        double vm = (t3 - t2) / (t5 - t2);
        
        // 计算C追上M的时间
        double t_cm = t1 + (1.0 - vm) * (t2 - t1) / (vc - vm);
        
        // 输出结果
        cout << secondsToTime(t_cm) << endl;
    }
    return 0;
}
```
