
> **摘要**：本题要求完整模拟一局围棋对局，在 $n \times n$（$3 \le n \le 19$，$n$ 为奇数）的棋盘上按给定顺序落子，准确处理“提子”与“领地”两大核心机制。解题时用整数数组维护棋盘状态，每步落子后以 $\texttt{BFS}$ 扫描对手连通块，按“同时判定、统一移除”原则提掉无气块并累加提子数；终局再对空点连通块做 $\texttt{BFS}$，依据相邻棋子颜色判定领地归属。最终得分 = 本方领地空点数 + 本方提子数。整体复杂度 $O(m \cdot n^2)$，棋盘规模小，朴素 $\texttt{BFS}$ 即可通过。

## 题目描述

本题要求模拟一局围棋对局，棋盘大小为 $n \times n$（$3 \le n \le 19$，$n$ 为奇数），坐标范围为 $[-(n-1)/2,\ (n-1)/2]$，中心点为 $(0,0)$。黑棋与白棋轮流落子，黑棋先行。玩家可随时选择停手，若双方连续停手则对局结束。输入仅给出所有落子步骤（不含停手），保证每一步合法。

规则要点如下：

- 棋子只能放在空交叉点上。
- 当一方落子后，若导致对方若干棋子组成的连通块完全没有“气”（即该连通块内无任一棋子与空点相邻），则该连通块被提掉，从棋盘移除。
- 若落子方棋子与对方棋子同时形成无气状态，则仅对方棋子被提掉（落子方棋子不会被提）。
- 终局时，一个由空点组成的连通块，若其所有相邻棋子均为同一颜色，且该连通块不包含对方棋子，则该连通块被视为该颜色的领地。
- 最终得分 = 本方领地中的空点数 + 本方在整个对局中提掉的对方棋子总数。

## 输入格式

输入包含多个测试用例。每个测试用例的第一行包含两个整数 $n$ 和 $m$，分别表示棋盘大小和落子次数。接下来 $m$ 行，每行一个字符串，格式为 `P(x,y)`，其中 $P$ 为 `B` 或 `W`，$x$、$y$ 为整数坐标。输入以 `0 0` 结束。

## 输出格式

对于每个测试用例，输出一行两个整数，分别为黑方得分和白方得分，中间用空格隔开。

## 样例

**输入**
```text
7 6
B(-2,-2)
W(2,2)
B(-2,-3)
W(2,3)
B(-3,-2)
W(3,2)
7 6
B(-2,-3)
W(-3,-3)
B(-2,-2)
W(3,2)
B(-3,-2)
W(2,3)
0 0
```

**输出**
```text
1 1

```

## 题目分析

本题本质上是围棋规则的完整模拟，需要准确处理“提子”和“领地”两个核心机制。棋盘规模最大为 $19 \times 19$，棋子总数最多为 $361$，$m$ 也不超过棋盘总交叉点数。每一步落子后，可能触发对方棋子的提子操作，且一次落子可能同时提掉多个互不相连的连通块，因此必须逐个连通块独立判断气数，并将所有无气块统一移除。

终局得分计算依赖于棋盘上最终的空点分布。空点被分割成若干个四连通区域，每个区域需要判定其归属。判定依据是该区域相邻棋子的颜色：若仅与黑棋相邻则归黑方，仅与白棋相邻则归白方，若同时与双方相邻或完全无相邻棋子（实际上不存在，因为棋盘边界不视作棋子）则该区域为“公共地”，不计入任何一方。此外，棋盘边界本身并不阻碍包围，在判定气时，超出边界的格子视为不存在，不影响气数计算；在领地判定中，边界上的空点仍可能被单色棋子包围（例如角上的空点被两颗同色棋子夹住），因此领地计算无需排除边界空点。

## 解题思路

处理每个测试用例时，按照输入顺序逐个落子，并维持一个 $n \times n$ 的整数数组表示棋盘状态（$0$ 空，$1$ 黑，$2$ 白）。坐标映射采用偏移量 $k = (n-1)/2$，将原坐标 $(x,y)$ 映射到数组下标 $(x+k,\ y+k)$。

**落子处理流程**

步骤 $\texttt{1}$. 将棋子置于指定位置。

步骤 $\texttt{2}$. 确定对手颜色（若当前落子为黑，则对手为白，反之为黑）。

步骤 $\texttt{3}$. 扫描整个棋盘，对每个属于对手颜色的连通块执行广度优先搜索（$\texttt{BFS}$）。搜索时统计该连通块包含的棋子数量以及相邻的空点数量（即“气”）。若气数为 $0$，则标记该连通块所有棋子为待移除。

步骤 $\texttt{4}$. 将所有标记的棋子从棋盘清除，并累加提子数到当前落子方的得分记录中（例如黑方落子提掉白子，则黑方提子数增加该块大小）。

**注意**：必须一次性找出所有无气块并统一移除，不能边找边移除，否则会影响其他连通块的气数判定（因为移除一块后可能让另一块获得新的气，但实际规则中应同时判定）。

**终局得分计算流程**

对棋盘上的每个空点进行遍历，若未访问，则开启一个新的连通块 $\texttt{BFS}$，收集该块内所有空点，并记录该块四邻接的棋子颜色集合（使用位标记：$\texttt{1}$ 表示有黑邻，$\texttt{2}$ 表示有白邻）。遍历结束后，若颜色集合只含黑，则黑方领地增加该块大小；若只含白，则白方领地增加相应大小；若同时含两种或为空，则不计入任何一方。

最后，黑方总得分 = 黑方领地大小 + 黑方提子数，白方总得分 = 白方领地大小 + 白方提子数。

**复杂度分析**  
时间复杂度：每次落子后需扫描全盘寻找对手连通块，最多 $O(n^2)$，而 $n \le 19$，故每次落子 $O(n^2)$ 可接受；终局领地计算同样 $O(n^2)$。总复杂度 $O(m \cdot n^2)$。  
空间复杂度：棋盘数组 $O(n^2)$，辅助标记数组 $O(n^2)$。

```cpp
// Go

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 19;
int board[MAXN][MAXN];      // 0空, 1黑, 2白
int n, m;
int blackCaptures, whiteCaptures;
int dx[4] = {1, -1, 0, 0};
int dy[4] = {0, 0, 1, -1};

// 坐标映射：将题目坐标 [-k, k] 映射到数组下标 [0, n-1]
int toBoardX(int x) { return x + (n - 1) / 2; }
int toBoardY(int y) { return y + (n - 1) / 2; }

// 解析落子字符串，如 "B(-2,-3)" 或 "W(3,2)"
struct Move {
    int color; // 1黑 2白
    int x, y;
};
Move parseMove(const string& s) {
    char c = s[0];
    size_t lp = s.find('('), rp = s.find(')');
    string inside = s.substr(lp + 1, rp - lp - 1);
    inside.erase(remove(inside.begin(), inside.end(), ' '), inside.end());
    int x, y;
    sscanf(inside.c_str(), "%d,%d", &x, &y);
    return {(c == 'B' || c == 'b') ? 1 : 2, x, y};
}

// 移除对手所有无气连通块，并累加提子数
void removeCaptured(int opponent) {
    bool visited[MAXN][MAXN] = {false};
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) {
            if (board[i][j] == opponent && !visited[i][j]) {
                vector<pair<int,int>> group;
                queue<pair<int,int>> q;
                q.push({i, j});
                visited[i][j] = true;
                int liberties = 0;
                while (!q.empty()) {
                    auto p = q.front(); q.pop();
                    group.push_back(p);
                    int x = p.first, y = p.second;
                    for (int d = 0; d < 4; ++d) {
                        int nx = x + dx[d], ny = y + dy[d];
                        if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                        if (board[nx][ny] == 0) liberties++;
                        else if (board[nx][ny] == opponent && !visited[nx][ny]) {
                            visited[nx][ny] = true;
                            q.push({nx, ny});
                        }
                    }
                }
                if (liberties == 0) {
                    for (auto& p : group) board[p.first][p.second] = 0;
                    if (opponent == 1) whiteCaptures += group.size(); // 白方提黑
                    else blackCaptures += group.size();               // 黑方提白
                }
            }
        }
}

// 计算最终得分（领地 + 提子）
pair<int,int> calculateScore() {
    bool visited[MAXN][MAXN] = {false};
    int blackScore = 0, whiteScore = 0;
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) {
            if (board[i][j] == 0 && !visited[i][j]) {
                queue<pair<int,int>> q;
                q.push({i, j});
                visited[i][j] = true;
                vector<pair<int,int>> points;
                int colorSet = 0;   // 位1:黑, 位2:白
                while (!q.empty()) {
                    auto p = q.front(); q.pop();
                    points.push_back(p);
                    int x = p.first, y = p.second;
                    for (int d = 0; d < 4; ++d) {
                        int nx = x + dx[d], ny = y + dy[d];
                        if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                        if (board[nx][ny] == 0 && !visited[nx][ny]) {
                            visited[nx][ny] = true;
                            q.push({nx, ny});
                        } else if (board[nx][ny] != 0) {
                            if (board[nx][ny] == 1) colorSet |= 1;
                            else colorSet |= 2;
                        }
                    }
                }
                if (colorSet == 1) blackScore += points.size();
                else if (colorSet == 2) whiteScore += points.size();
            }
        }
    blackScore += blackCaptures;
    whiteScore += whiteCaptures;
    return {blackScore, whiteScore};
}

int main() {
    while (cin >> n >> m) {
        if (n == 0 && m == 0) break;
        memset(board, 0, sizeof(board));
        blackCaptures = whiteCaptures = 0;
        for (int i = 0; i < m; ++i) {
            string s;
            cin >> s;
            Move mv = parseMove(s);
            int bx = toBoardX(mv.x);
            int by = toBoardY(mv.y);
            board[bx][by] = mv.color;
            int opponent = (mv.color == 1) ? 2 : 1;
            removeCaptured(opponent);
        }
        pair<int,int> ans = calculateScore();
        cout << ans.first << " " << ans.second << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于准确实现围棋提子规则中的“同时判定、统一移除”原则，避免因移除顺序影响气数计算。领地判定相对直接，只需按连通块检查相邻棋子颜色。由于棋盘规模小，采用最朴素的 $\texttt{BFS}$ 扫描即可通过。注意坐标映射和输入解析的细节处理，以及提子计数需正确归属到落子方。本题是模拟类问题的典型代表，要求对规则理解透彻，并严格按步骤实现。
