## 题目描述

有一个矩形，其边与 $x-y$ 轴平行，左下角位于 $(0,0)$。该矩形可以被视为一个分辨率几乎无限的显示屏，初始时整个矩形为黑色。

给定两个数字 $0 < h, v < 1$，然后执行以下操作：

1. 画一条垂直线，将矩形的水平边按比例 $h : 1 - h$ 从左到右分割
2. 画一条水平线，将矩形的垂直边按比例 $v : 1 - v$ 从下到上分割
3. 这两条线将矩形分成四个小矩形
4. 左上和右下的小矩形保持不变
5. 另外两个小矩形的颜色被翻转（黑色变白色，白色变黑色），并且每个翻转后的小矩形将再次执行相同的操作
6. 这个过程理论上会无限进行下去

给定原始矩形中的一个点（该点不在任何一次分割的边界上），确定该点的颜色。

### 输入格式

输入包含多个测试用例。每个测试用例的第一行包含 $4$ 个数字：矩形的长度 $H$、高度 $V$，以及数字 $h$ 和 $v$。下一行包含一个整数 $n$，表示要考虑的点的数量。接下来的 $n$ 行每行包含两个数字，表示一个点的 $x$ 和 $y$ 坐标。

### 输出格式

对于每个测试用例，首先输出 `Case X:`（其中 $X$ 是案例编号），然后对于每个点输出其颜色（`black` 或 `white`）。

## 题目分析

### 问题理解

这个问题描述了一个无限递归的矩形分割与颜色翻转过程。关键在于理解每次分割后四个子矩形的处理方式：

- **左上子矩形**：保持不变
- **右上下矩形**：保持不变  
- **左下子矩形**：颜色翻转，并继续递归分割
- **右上下矩形**：颜色翻转，并继续递归分割

初始颜色为黑色，每次颜色翻转都会改变当前颜色（黑色 ↔ 白色）。

### 关键观察

点的最终颜色取决于它在递归过程中经历了**奇数次还是偶数次颜色翻转**：

- **偶数次翻转**：最终颜色为黑色（与初始颜色相同）
- **奇数次翻转**：最终颜色为白色

### 递归思路

我们可以设计一个递归函数来跟踪翻转次数：

1. **确定分割线位置**：
   - 垂直分割线：$xSplit = h \times H$
   - 水平分割线：$ySplit = v \times V$

2. **判断点所在区域**：
   - **左下区域** $(x < xSplit$ 且 $y < ySplit)$：进入递归，翻转次数加 $1$
   - **右上区域** $(x \geq xSplit$ 且 $y \geq ySplit)$：进入递归，翻转次数加 $1$
   - **左上区域** $(x < xSplit$ 且 $y \geq ySplit)$：停止递归，返回当前翻转次数
   - **右下区域** $(x \geq xSplit$ 且 $y < ySplit)$：停止递归，返回当前翻转次数

3. **递归终止**：当点落在左上或右下区域时，递归停止

### 算法复杂度

由于每次递归都将矩形尺寸缩小，且题目保证点不在边界上，递归深度是有限的。最坏情况下，递归深度与浮点数精度相关，在实际应用中深度可控。

## 解题代码

```cpp
// Flipping Colors
// UVa ID: 10998
// Verdict: Accepted
// Submission Date: 2025-11-08
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <cstdio>
using namespace std;

bool getColor(double H, double V, double h, double v, double x, double y, int flipCount) {
    double xSplit = h * H;
    double ySplit = v * V;

    if (x < xSplit && y < ySplit) {
        // 左下区域：继续递归，颜色翻转一次
        return getColor(xSplit, ySplit, h, v, x, y, flipCount + 1);
    } else if (x >= xSplit && y >= ySplit) {
        // 右上区域：继续递归，颜色翻转一次
        return getColor(H - xSplit, V - ySplit, h, v, x - xSplit, y - ySplit, flipCount + 1);
    } else {
        // 左上或右下区域：停止递归，当前翻转次数决定颜色
        return (flipCount % 2 == 0);
    }
}

int main() {
    double H, V, h, v;
    int caseNum = 1;

    while (cin >> H >> V >> h >> v) {
        if (H == 0 && V == 0 && h == 0 && v == 0) break;

        int n;
        cin >> n;

        cout << "Case " << caseNum++ << ":" << endl;
        for (int i = 0; i < n; i++) {
            double x, y;
            cin >> x >> y;
            bool isBlack = getColor(H, V, h, v, x, y, 0);
            cout << (isBlack ? "black" : "white") << endl;
        }
    }

    return 0;
}
```

## 总结

本题通过递归模拟无限分割过程，利用翻转次数的奇偶性来确定最终颜色。关键在于理解只有左下和右上区域会继续递归并增加翻转次数，而左上和右下区域直接返回当前结果。这种递归思路避免了实际进行无限次操作，而是通过数学规律在有限步骤内解决问题。
