## 题目描述

$\texttt{Jennifer}$ 正在为 $\texttt{Crabbles}$ 锦标赛做准备。她从袋子里拿出一把 $\texttt{Crabbles}$ 拼块，试图组成得分最高的单词。每个拼块包含一个字母（用于组成单词）和一个数字（其分数值）。她可以在单词中最多使用每个拼块一次，并且不需要使用所有拼块。她组成的单词必须出现在她的词典中。得分是单词中使用的拼块分数值之和。

注意：在 $\texttt{Crabbles}$ 中，相同字母的不同拼块可能具有不同的分数值。

## 输入格式

- 第一行：整数 $1 \leq N \leq 100,000$，表示词典中的单词数量
- 接下来 $N$ 行：每行一个词典单词（仅包含小写字母）
- 接下来一行：整数 $1 \leq M \leq 1000$，表示 $\texttt{Jennifer}$ 想要玩的手牌数量
- 接下来 $M$ 组手牌数据：
  - 第一行：整数 $1 \leq P \leq 10$，表示手牌中的拼块数量
  - 接下来 $P$ 行：每行包含一个小写字母和一个整数 $0 \leq V \leq 10$，表示拼块的字母和分数值

## 输出格式

对于每组手牌，输出一行，表示使用该手牌可以获得的最大分数。

## 题目分析

### 核心问题

我们需要解决的核心问题是：对于每组手牌，找到词典中能够由手牌拼出的单词，并计算该单词能够获得的最大分数。

### 关键观察

1. **相同字母不同分值**：这是本题的关键难点。同一个字母可能有多个拼块，且分值不同。为了最大化分数，对于单词中每个字母，我们应该选择可用拼块中分值最高的那些。

2. **拼块使用限制**：每个拼块最多使用一次，不需要使用所有拼块。

3. **单词长度限制**：由于手牌最多只有 $10$ 个拼块，因此长度超过 $10$ 的单词可以直接忽略。

4. **效率考虑**：词典最多有 $100,000$ 个单词，手牌最多 $1000$ 组，每组最多 $10$ 个拼块。直接暴力匹配可能超时，需要合理优化。

### 解题思路

1. **预处理词典**：
   - 过滤掉长度超过 $10$ 的单词（因为无法用最多 $10$ 个拼块组成）
   - 将每个单词转换为字母频率表（长度为 $26$ 的数组）

2. **处理每组手牌**：
   - 按字母分组存储所有拼块的分值
   - 对每个字母的分值列表进行降序排序

3. **计算最大分数**：
   - 遍历词典中的每个单词
   - 检查手牌是否能够组成该单词（每个字母的数量足够）
   - 如果能够组成，计算使用最高分值拼块时的分数
   - 记录所有可行单词中的最大分数

#include <bits/stdc++.h>
using namespace std;

// 将单词转换为字母频率表
vector<int> convertToLetterCount(const string& word) {
    vector<int> letterCount(26, 0);
    for (char currentChar : word) {
        letterCount[currentChar - 'a']++;
    }
    return letterCount;
}

// 检查手牌是否能组成给定单词
bool canFormWord(const vector<int>& wordCount, const map<char, vector<int>>& handTiles) {
    for (int i = 0; i < 26; i++) {
        if (wordCount[i] > 0) {
            char currentLetter = 'a' + i;
            auto it = handTiles.find(currentLetter);
            if (it == handTiles.end() || it->second.size() < wordCount[i]) {
                return false;
            }
        }
    }
    return true;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int dictionarySize;
    cin >> dictionarySize;
    
    vector<vector<int>> dictionaryWords;
    vector<string> originalWords;
    
    // 读取并预处理词典
    for (int i = 0; i < dictionarySize; i++) {
        string currentWord;
        cin >> currentWord;
        // 只保留长度不超过 10 的单词
        if (currentWord.length() <= 10) {
            dictionaryWords.push_back(convertToLetterCount(currentWord));
            originalWords.push_back(currentWord);
        }
    }
    
    int handCount;
    cin >> handCount;
    
    // 处理每组手牌
    for (int handIndex = 0; handIndex < handCount; handIndex++) {
        int tileCount;
        cin >> tileCount;
        
        // 按字母分组存储拼块分值
        map<char, vector<int>> tileValues;
        
        for (int i = 0; i < tileCount; i++) {
            char tileLetter;
            int tileValue;
            cin >> tileLetter >> tileValue;
            tileValues[tileLetter].push_back(tileValue);
        }
        
        // 对每个字母的分值按降序排序
        for (auto& letterGroup : tileValues) {
            sort(letterGroup.second.rbegin(), letterGroup.second.rend());
        }
        
        int maxScore = 0;
        
        // 遍历词典中的每个单词
        for (int wordIndex = 0; wordIndex < dictionaryWords.size(); wordIndex++) {
            const vector<int>& wordLetterCount = dictionaryWords[wordIndex];
            
            // 检查是否能组成该单词
            if (!canFormWord(wordLetterCount, tileValues)) {
                continue;
            }
            
            // 计算该单词的最大可能分数
            int currentScore = 0;
            for (int letterIndex = 0; letterIndex < 26; letterIndex++) {
                int requiredCount = wordLetterCount[letterIndex];
                if (requiredCount == 0) continue;
                
                char currentLetter = 'a' + letterIndex;
                const vector<int>& values = tileValues.at(currentLetter);
                
                // 取前 requiredCount 个最高分值
                for (int k = 0; k < requiredCount; k++) {
                    currentScore += values[k];
                }
            }
            
            maxScore = max(maxScore, currentScore);
        }
        
        cout << maxScore << "\n";
    }
    
    return 0;
}
