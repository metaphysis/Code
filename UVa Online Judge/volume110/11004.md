[UVa 11004 Changing Roadmap](https://blog.csdn.net/metaphysis/article/details/154691476)

## 题目描述

德克萨斯州面临交通拥堵问题，计划修建新道路。现有道路可视为二维笛卡尔坐标系中的直线，且满足**一般位置**条件：没有两条道路平行，也没有三条道路共点。每条道路由方程 $a x + b y + c = 0$ 表示，其中 $a, b, c$ 为整数。

新道路修建计划如下：

1. 城市管理部门确定了 $PP$ 个重要地点（视为二维坐标点）。
2. 从所有现有道路的交叉口（即两条道路的交点）向所有重要地点修建新道路，共修建 $JJ \times PP$ 条新道路，其中 $JJ$ 是交叉口数量。
3. 对于第 $i$ 条和第 $j$ 条道路（$j > i$），连接它们的交叉口与某个重要地点 $P$ 的新道路方程为：
   $$
   a_i x + b_i y + c_i + k(a_j x + b_j y + c_j) = 0
   $$
   其中 $k$ 为实数：
   - 若 $k > 0$，道路由 **$\texttt{Positive Builders Ltd}$** 修建；
   - 若 $k < 0$，道路由 **$\texttt{Negative Builders Ltd}$** 修建。

**任务**：给定 $N$ 条现有道路的方程和 $PP$ 个重要地点的坐标，计算由 **$\texttt{Negative Builders Ltd}$** 修建的新道路数量。

---

## 输入格式

- 多组数据，每组数据：
  - 整数 $N$（$0 < N \leq 3000$）表示道路数量；
  - 接下来 $N$ 行，每行三个整数 $a_i, b_i, c_i$；
  - 整数 $PP$（$1 \leq PP \leq 100$）表示重要地点数量；
  - 接下来 $PP$ 行，每行两个整数 $x_i, y_i$ 表示坐标。
- 输入以 $N = 0$ 结束。

---

## 输出格式

每组数据输出两行：

```
Roadmap X:
Negative Builders Ltd. will build Y New Roads.
```

其中 $X$ 为数据编号，$Y$ 为答案。

## 题目分析

### 1. 交叉口数量

$N$ 条互不平行且无三线共点的直线，交叉口数量为：
$$
JJ = \binom{N}{2} = \frac{N(N-1)}{2}
$$

新道路总数为：
$$
\text{Total} = JJ \times PP = \frac{N(N-1)}{2} \times PP
$$

### 2. 判断修建公司

对于道路 $i, j$（$j > i$）和重要地点 $P(x_p, y_p)$，新道路方程为：
$$
a_i x_p + b_i y_p + c_i + k(a_j x_p + b_j y_p + c_j) = 0
$$

解得：
$$
k = -\frac{a_i x_p + b_i y_p + c_i}{a_j x_p + b_j y_p + c_j}
$$

我们需要判断 $k$ 的符号：

- 若 $k < 0$，则 $\frac{a_i x_p + b_i y_p + c_i}{a_j x_p + b_j y_p + c_j} > 0$；
- 即分子分母同号：
  $$
  (a_i x_p + b_i y_p + c_i) \cdot (a_j x_p + b_j y_p + c_j) > 0
  $$

因此，**只需判断两个线性函数值是否同号**。

### 3. 直接枚举的复杂度

- 道路对数量：$\frac{N(N-1)}{2} \approx 4.5 \times 10^6$（当 $N = 3000$）；
- 重要地点数量：$PP \leq 100$；
- 总操作数：$\approx 4.5 \times 10^6 \times 100 = 4.5 \times 10^8$，可能超时。

---

## 优化思路

### 核心观察

对于固定道路 $i, j$，每个重要地点 $P$ 对两个线性函数值的符号组合有四种情况：

| 符号组合 | 对应模式 | 是否由 $\texttt{Negative Builders Ltd}$ 修建 |
|----------|----------|----------------------------------|
| (正, 正) | `(1, 1)` | 是（同号） |
| (正, 负) | `(1, 0)` | 否 |
| (负, 正) | `(0, 1)` | 否 |
| (负, 负) | `(0, 0)` | 是（同号） |

### 优化方法

1. **预处理**：对每条道路 $i$ 和每个地点 $p$，预先计算符号：
   $$
   \texttt{sign}[i][p] = \begin{cases}
   1 & \text{if } a_i x_p + b_i y_p + c_i > 0 \\
   0 & \text{if } a_i x_p + b_i y_p + c_i < 0
   \end{cases}
   $$

2. **位运算压缩**：使用 `bitset<100>` 存储每个道路对所有地点的符号向量。

3. **批量判断**：对于道路对 $(i, j)$：
   - 同号情况 = `(sign[i] & sign[j])`（全为正） + `(~sign[i] & ~sign[j])`（全为负）；
   - 使用 `bitset::count()` 快速统计 1 的个数。

### 复杂度分析

- 预处理：$O(N \times PP)$
- 主循环：$O(N^2)$，但每次操作为常数时间（位运算）
- 总操作数大幅减少，可高效运行

## 参考代码

```cpp
// Changing Roadmap
// UVa ID: 11004
// Verdict: Accepted
// Submission Date: 2025-11-11
// UVa Run Time: 0.150s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net


#include <iostream>
#include <vector>
#include <algorithm>
#include <bitset>

using namespace std;

struct Road {
    int a, b, c;
    Road(int a, int b, int c) : a(a), b(b), c(c) {}
};

struct Point {
    int x, y;
    Point(int x, int y) : x(x), y(y) {}
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int roadmapCount = 0;
    int N;
    while (cin >> N && N != 0) {
        roadmapCount++;
        vector<Road> roads;
        for (int i = 0; i < N; i++) {
            int a, b, c;
            cin >> a >> b >> c;
            roads.emplace_back(a, b, c);
        }

        int PP;
        cin >> PP;
        vector<Point> importantPlaces;
        for (int i = 0; i < PP; i++) {
            int x, y;
            cin >> x >> y;
            importantPlaces.emplace_back(x, y);
        }

        // 使用bitset进一步优化
        vector<bitset<100>> signBits(N);
        for (int i = 0; i < N; i++) {
            for (int p = 0; p < PP; p++) {
                long long value = (long long)roads[i].a * importantPlaces[p].x + 
                                 (long long)roads[i].b * importantPlaces[p].y + 
                                 roads[i].c;
                signBits[i][p] = (value > 0);
            }
        }

        long long negativeCount = 0;

        // 对于每对道路，使用位运算批量计算
        for (int i = 0; i < N; i++) {
            for (int j = i + 1; j < N; j++) {
                // 同号的情况：两个bitset相同的位置
                bitset<100> sameSign = (signBits[i] & signBits[j]) | (~signBits[i] & ~signBits[j]);
                negativeCount += sameSign.count();
            }
        }

        cout << "Roadmap " << roadmapCount << ":\n";
        cout << "Negative Builders Ltd. will build " << negativeCount << " New Roads.\n";
    }

    return 0;
}
```

## 总结

本题的关键在于：

1. 将 $k$ 的符号判断转化为两个线性函数值的同号判断；
2. 使用 `bitset` 对符号向量进行压缩和批量运算；
3. 通过位运算大幅降低常数，使 $O(N^2)$ 的算法在 $N \leq 3000$ 时可行。

该解法充分利用了几何性质与位运算优化，是典型的**空间换时间**与**批量处理**思想的结合。
