## 题目描述

### 问题背景

在许多大学的 **数值方法** 课程中，教师常常为那些不擅长编程的学生提供便利。因此，在涉及 **牛顿-拉夫森法** 、 **割线法** 、 **二分法** 、 **插值** 或 **数值积分** 等内容的课程中，试卷上常出现这样的题目： “用 **割线法** 求下列方程的根” （允许使用计算器），或 “手动使用 **高斯-乔丹消元法** 求解以下线性方程组” 。虽然要求手动解题可以确保学生以 **人类的方式** 理解该方法，但并不能确保他们以 **程序员的方式** 理解。因此，很容易找到在数值方法课程中成绩优异、却无法通过编写程序来解决相关问题的学生。这种让编程能力差的学生也能及格的教学体系，是编程竞赛至今未能如预期那样普及的主要原因之一。

**$\texttt{Samuel}$** 现在正在教授数值方法课程，为了让非编程学生 “吃点苦头”，他要求他们找出 **第 $6$ 阶差分** ，并将其打印出来附在试卷上。 **第 $n$ 阶差分** 的递归定义如下：

$$
f[x_{0},x_{1},\ldots,x_{n}] = \frac{f[x_{0},x_{1},\ldots,x_{n-1}]-f[x_{1},x_{2},\ldots,x_{n}]}{x_ {0}-x_{n}},\text{ if }n>1
$$

$$
\text{and }f[x_{0},x_{1}] = \frac{f(x_{0})-f(x_{1})}{x_{0}-x_{1}},\text{ if }n=1.
$$

给定 $n$ 的值，你的任务是打印出 **第 $n$ 阶差分** ，其形式中不包含任何可以通过上述递归定义展开的部分。

### 输入输出格式

#### 输入
输入文件最多包含 $15$ 组输入。每组输入包含一个整数 $n$ $(1 \leq n \leq 12)$ 。输入以 $n=0$ 的一组结束。

#### 输出
对每组输入的 $n$ ，输出序号后跟第 $n$ 阶差分。每组输出后应有一个空行。严格遵循样例输出格式。同时注意以下几点：

*   $a)$ 水平横线由 **下划线** 构成。
*   $b)$ 所有后缀都有 **两位数字** 。
*   $c)$ 每个差分的水平横线长度与其 **宽度** 完全相同。
*   $d)$ 所有空白字符应打印为 `'.'` （ASCII $46$ ）。
*   $e)$ $n=1$ 时差分宽度为 $13$ 。
*   $f)$ $n=1$ 时差分高度为 $5$ 。
*   $g)$ 如果差分表达式适合一个 $(l \times w)$ 的轴对齐包围盒，则包围盒内的所有空位应填充为 `'.'` （$\texttt{ASCII}$ $46$ ）。
*   $h)$ 不应打印包围盒外的任何字符。
*   $i)$ 分母中的表达式应 **居中对齐** 。

## 解题思路分析

本题本质上是一个 **复杂格式的输出模拟题** 。我们需要根据给定的 $n$ ，按照特定的递归格式生成一个分式表达式。观察样例可以发现以下规律：

1.  **结构递归性** ：第 $n$ 阶差分由两个第 $n-1$ 阶差分通过 **减法** 连接，然后除以一个新的分母构成。
2.  **宽度和高度增长** ：宽度和高度随着 $n$ 的增大而 **指数增长** 。
3.  **数字下标规律** ：所有下标都是两位数，且按照从左到右、从上到下的顺序递增。

### 关键观察

*   **基本单元** ：当 $n=1$ 时，输出是一个固定的 $5$ 行 $13$ 列的格式。
*   **递归构建** ：对于 $n>1$ ，我们可以将输出看作由两个 $n-1$ 的输出并排组成（中间用减号连接），然后在下方添加新的 **水平分隔线** 和 **分母行** 。
*   **宽度计算** ：设 $W_n$ 为第 $n$ 阶差分的宽度， $H_n$ 为高度，则有：
$$
    W_1 = 13,\quad W_n = 2W_{n-1} + 1 \quad (n>1) 
$$
$$
    H_1 = 5,\quad H_n = H_{n-1} + 3 \quad (n>1)
$$
*   **数字更新** ：当复制右半部分时，所有数字下标需要 $+1$ ，以保持正确的索引关系。

### 算法设计

我们可以采用 **动态规划（记忆化）** 的思路，预先计算出所有 $n$ 从 $1$ 到 $12$ 的输出，存储在一个三维数组 $g[n][x][y]$ 中，表示第 $n$ 阶差分的第 $x$ 行第 $y$ 列的字符。

#### 初始化（ $n=1$ ）

直接存储样例中 $n=1$ 的 $5$ 行字符串。

#### 递推构建（ $n \geq 2$ ）

对于每个 $n$ ：

1.  **复制左半部分** ：将 $g[n-1]$ 的内容复制到当前输出的左侧。
2.  **添加中间分隔符** ：在中间列（位置 $W_{n-1}$ ）的特定行（高度减去 $3$ 的行）添加减号 `'-'` ，其他行的中间位置添加点 `'.'` 。
3.  **复制右半部分** ：再次复制 $g[n-1]$ 的内容到右侧，但所有 **数字下标** 需要 $+1$ 。
4.  **添加新行** ：
    *   在下方添加一行 **全下划线** 作为分隔线。
    *   再添加两行作为新的分母：第一行是 `x00-xNN` 格式，第二行是对应的数字行 `..00..NN.` ，其中 `NN` 是当前 $n$ 的两位数表示。
5.  **更新宽度和高度** ：按照递推公式更新 $W_n$ 和 $H_n$ 。

#### 输出处理

输出时，直接遍历 $g[n]$ 的前 $H_n$ 行、每行的前 $W_n$ 列即可。由于在构建过程中已经处理了所有空白字符（填充为点），因此输出非常简单。

### 时间复杂度与空间复杂度

*   **时间复杂度** ：预处理需要构建 $12$ 个输出，每个输出的字符数约为 $O(W_n \times H_n)$ 。由于 $W_n$ 和 $H_n$ 呈指数增长，但 $n$ 最大为 $12$ ，因此总操作次数在可接受范围内。
*   **空间复杂度** ：使用三维数组存储所有输出，大小约为 $13 \times 40 \times 30000 \approx 15.6 \text{ MB}$ ，在合理范围内。

## 参考代码

```cpp
// Numerical Methods A Satire
// UVa ID: 11011

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

char g[13][40][30010];

void initialize() {
    string line[5] = {
        "f(x..)-f(x..)",
        "...00.....01.",
        "_____________",
        "...x..-x.....",
        "....00..01..."
    };
    for (int i = 0; i < 5; i++)
        for (int j = 0; j < 13; j++)
            g[1][i][j] = line[i][j];
    int height = 5, width = 13;
    for (int i = 2; i <= 12; i++) {
        for (int x = 0; x < height; x++) {
            for (int y = 0; y < width; y++)
                g[i][x][y] = g[i - 1][x][y];
            g[i][x][width] = '.';
        }
        g[i][height - 3][width] = '-';
        for (int x = 0; x < height; x++)
            for (int y = 0; y < width; y++) {
                char c1 = g[i - 1][x][y];
                if (!isdigit(c1)) g[i][x][y + width + 1] = c1;
                else {
                    char c2 = g[i - 1][x][y + 1];
                    int n = (c1 - '0') * 10 + (c2 - '0');
                    n += 1;
                    string s = to_string(n);
                    if (n < 10) s = '0' + s;
                    g[i][x][y + width + 1] = s[0];
                    g[i][x][y + width + 2] = s[1];
                    y++;
                }
            }
        for (int y = 0; y < 2 * width + 1; y++) {
            g[i][height][y] = '_';
            g[i][height + 1][y] = g[i][height + 2][y] = '.';
        }
        g[i][height + 1][width] = '-';
        g[i][height + 1][width + 1] = g[i][height + 1][width - 3] = 'x';
        g[i][height + 2][width - 1] = g[i][height + 2][width - 2] = '0';
        string s = to_string(i);
        if (i < 10) s = '0' + s;
        g[i][height + 2][width + 2] = s[0];
        g[i][height + 2][width + 3] = s[1];
        height += 3;
        width = 2 * width + 1;
    }
}

int main() {
    initialize();
    int d[13][2];
    d[1][0] = 5, d[1][1] = 13;
    for (int i = 2; i <= 12; i++) {
        d[i][0] = d[i - 1][0] + 3;
        d[i][1] = 2 * d[i - 1][1] + 1;
    }
    int n, caseNum = 1;
    while (cin >> n && n) {
        cout << "Case " << caseNum << ":\n";
        for (int x = 0; x < d[n][0]; x++) {
            for (int y = 0; y < d[n][1]; y++) cout << g[n][x][y];
            cout << '\n';
        }
        cout << '\n';
        caseNum++;
    }
    return 0;
}
```

### 代码说明

1.  **全局数组** `g[13][40][30010]` ：第一维表示 $n$ ，第二维表示行号，第三维表示列号。大小经过计算，足以容纳 $n=12$ 的最大输出。
2.  **`initialize()` 函数** ：预先计算所有 $n$ 从 $1$ 到 $12$ 的输出格式。
3.  **主函数** ：
    *   首先调用 `initialize()` 进行预处理。
    *   然后计算每个 $n$ 的实际高度和宽度，存储在数组 `d` 中。
    *   读入 $n$ ，对于每个测试用例，直接输出 `g[n]` 中相应范围的字符。
4.  **数字更新技巧** ：在复制右半部分时，遇到数字就解析为两位数，加 $1$ 后再写回，确保下标正确递增。

## 总结

本题是一道典型的 **复杂格式输出** 题目，虽然题目背景带有讽刺意味，但实际考察的是选手对 **递归结构** 的理解和 **精细化输出控制** 的能力。通过 **预处理** 所有可能的输出，我们可以避免在每次查询时重新计算，从而满足时间限制。关键点在于发现宽度和高度的递推关系，以及正确处理数字下标的更新。最终的代码简洁高效，顺利通过了在线评测系统的所有测试用例。
