[UVa 11024 Circular Lock](https://blog.csdn.net/metaphysis/article/details/155194272)

## 题目描述

这是本月第四次，心不在焉的数学教授 $\texttt{Bolkas}$ 丢失了他的钥匙。意识到改变个性来记住这些琐事似乎不太可能，他开始发明一种不需要实体钥匙的锁。他设计的锁是一个 $2 \times 2$ 的阵列，包含四个模数设备。

每个模数设备是一个离散计数器，显示当前状态，并有一个触发器。每个计数器可以处于状态 $0, 1, \ldots, p-1$ 中的任何一个，其中 $p \geq 1$ 是计数器的周期。触发计数器时，计数器的状态从 $i$ 变为 $i+1$，除非状态是 $p-1$，在这种情况下新状态为 $0$。

对于阵列的每一行和每一列，教授在锁的面板上放置了一个增加按钮：
- 按下行的增加按钮：该行中的两个计数器都被触发
- 按下列的增加按钮：该列中的两个计数器都被触发

当所有四个模数设备都处于状态 $0$ 时，锁被解除。

## 关键观察

教授发现了一个重要的简化方法：一个锁（周期为 $p_{11}, p_{12}, p_{21}, p_{22}$，状态为 $s_{11}, s_{12}, s_{21}, s_{22}$）可以被解除当且仅当所有模数设备具有相同周期 $p = \gcd(p_{11}, p_{12}, p_{21}, p_{22})$，且状态为 $s'_{ij} = s_{ij} \bmod p$ 的锁可以被解除。

## 问题分析

### 数学模型

设：
- $r_1$ = 按第 $1$ 行按钮的次数
- $r_2$ = 按第 $2$ 行按钮的次数
- $c_1$ = 按第 $1$ 列按钮的次数
- $c_2$ = 按第 $2$ 列按钮的次数

每个位置的值变化为（模 $p$ 运算）：
- 位置 $(1,1)$：$s'_{11} + r_1 + c_1 \equiv 0$
- 位置 $(1,2)$：$s'_{12} + r_1 + c_2 \equiv 0$
- 位置 $(2,1)$：$s'_{21} + r_2 + c_1 \equiv 0$
- 位置 $(2,2)$：$s'_{22} + r_2 + c_2 \equiv 0$

### 推导过程

从上述方程中，我们可以进行如下推导：

1. 从位置 $(1,1)$ 和 $(1,2)$ 的方程相减：
   $$
   (s'_{11} + r_1 + c_1) - (s'_{12} + r_1 + c_2) \equiv 0
   $$
   简化得：
   $$
   s'_{11} - s'_{12} + c_1 - c_2 \equiv 0
   $$
   即：
   $$
   c_1 - c_2 \equiv s'_{12} - s'_{11}
   $$

2. 从位置 $(1,1)$ 和 $(2,1)$ 的方程相减：
   $$
   (s'_{11} + r_1 + c_1) - (s'_{21} + r_2 + c_1) \equiv 0
   $$
   简化得：
   $$
   s'_{11} - s'_{21} + r_1 - r_2 \equiv 0
   $$
   即：
   $$
   r_1 - r_2 \equiv s'_{21} - s'_{11}
   $$

3. 现在考虑所有四个方程的一致性条件。将四个方程相加：
   $$
   (s'_{11} + r_1 + c_1) + (s'_{12} + r_1 + c_2) + (s'_{21} + r_2 + c_1) + (s'_{22} + r_2 + c_2) \equiv 0
   $$
   简化得：
   $$
   s'_{11} + s'_{12} + s'_{21} + s'_{22} + 2(r_1 + r_2) + 2(c_1 + c_2) \equiv 0
   $$

4. 另一种更有用的推导：从位置 $(1,1)$ 减去位置 $(1,2)$ 减去位置 $(2,1)$ 加上位置 $(2,2)$：
   $$
   (s'_{11} + r_1 + c_1) - (s'_{12} + r_1 + c_2) - (s'_{21} + r_2 + c_1) + (s'_{22} + r_2 + c_2) \equiv 0
   $$
   简化后，所有的 $r_i$ 和 $c_j$ 项都相互抵消，得到：
   $$
   s'_{11} - s'_{12} - s'_{21} + s'_{22} \equiv 0
   $$

### 关键结论

锁可以被解除的**充分必要条件**是：
$$
s'_{11} - s'_{12} - s'_{21} + s'_{22} \equiv 0 \pmod{p}
$$
其中 $p = \gcd(p_{11}, p_{12}, p_{21}, p_{22})$，且 $s'_{ij} = s_{ij} \bmod p$。

## 算法步骤

1. 读取测试用例数量 $n$
2. 对于每个测试用例：
   - 读取四个设备的初始状态和周期
   - 计算四个周期的最大公约数 $p$
   - 将所有状态对 $p$ 取模
   - 检查条件 $(s'_{11} - s'_{12} - s'_{21} + s'_{22}) \bmod p = 0$
   - 如果条件满足，输出 `Yes`，否则输出 `No`

## 复杂度分析

- 时间复杂度：$O(n \cdot \log M)$，其中 $M$ 是周期的最大值（$10000$）
- 空间复杂度：$O(1)$

## 代码实现

```cpp
// Circular Lock

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int gcd(int a, int b) {
    while (b != 0) {
        int temp = a % b;
        a = b;
        b = temp;
    }
    return a;
}

int main() {
    int n;
    cin >> n;
    
    while (n-- > 0) {
        int s11, s12, p11, p12;
        int s21, s22, p21, p22;
        cin >> s11 >> s12 >> p11 >> p12;
        cin >> s21 >> s22 >> p21 >> p22;
        
        int p = gcd(gcd(p11, p12), gcd(p21, p22));
        
        int a = s11 % p;
        int b = s12 % p;
        int c = s21 % p;
        int d = s22 % p;
        
        if ((a - b - c + d) % p == 0) cout << "Yes" << endl;
        else cout << "No" << endl;
    }
    
    return 0;
}
```

这个解决方案利用了教授发现的关键数学洞察，将复杂的问题简化为一个简单的模运算检查，从而高效地解决了问题。
