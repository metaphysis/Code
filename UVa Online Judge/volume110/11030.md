## 题目描述

捕食者再次进入房间，但这次房间的类型不同。 房间是一个 $10000 \times 10000$ 的正方形，内部有若干个不同形状和尺寸的隔间。 不同隔间的墙壁不会重叠，但一个隔间可以完全位于另一个隔间内部。

这次捕食者学会了跳过墙壁，但每次最多只能跳过一堵墙。 给定捕食者的起点和终点坐标，以及所有隔间的位置，你的任务是找出捕食者从起点到达终点所需的最小跳跃次数。

**输入格式**：
- 第一行是整数 $T \le 20$ ，表示测试用例的数量。
- 每个测试用例以一个整数 $n \le 20$ 开始，表示隔间的数量。
- 接下来的 $n$ 行描述隔间。 每个隔间是一个简单多边形。 每行以整数 $S \le 10$ 开始，表示多边形的边数，后跟按顺序给出的 $S$ 对 $x, y$ 坐标。
- 接下来是一个整数 $Q$ ，表示该场景下的查询数量。
- 接下来的 $Q$ 行每行包含 $4$ 个整数 $x_1, y_1, x_2, y_2$ 。 $(x_1, y_1)$ 是起点， $(x_2, y_2)$ 是终点。

房间的左下角和右上角坐标分别是 $(0, 0)$ 和 $(10000, 10000)$ 。

**输出格式**：
对于每个测试用例，首先输出一行 `"Case X:"` ，其中 $X$ 是测试用例编号。 然后对于每个查询，输出所需的最小跳跃次数。

**注意**：起点和终点永远不会在任何隔间的边界上。

## 题目分析与解题思路

### 关键问题转化

本题的核心是计算两点之间需要穿过的多边形墙壁的最小数量。 由于捕食者一次最多只能跳过一堵墙，因此 **最小跳跃次数就等于需要穿过的墙壁数量** 。

那么如何计算两点之间需要穿过的墙壁数量呢？ 我们可以从几何角度来思考这个问题。

### 几何模型建立

想象一下，每个隔间（多边形）将平面划分为“内部”和“外部”两个区域。 如果捕食者从一个点移动到另一个点，它每次穿越多边形的边界（即墙壁），就意味着它进入了该多边形或从该多边形中出来。

**关键观察**：
- 如果两个点都在同一个多边形内部，那么从起点到终点就不需要穿过该多边形的边界。
- 如果起点在一个多边形内部而终点不在，那么从起点到终点就必须穿越该多边形的边界一次（从内到外）。
- 如果起点不在多边形内部而终点在，那么也必须穿越边界一次（从外到内）。
- 如果两个点都在多边形内部或都不在，那么穿越该多边形边界的净次数为 $0$ 。

因此，对于任意一个多边形：
- 如果起点在内部而终点不在，贡献 $1$ 次穿越。
- 如果起点不在内部而终点在，贡献 $1$ 次穿越。
- 其他情况，贡献 $0$ 次穿越。

### 数学公式推导

设：
- $A$ = 包含起点的多边形集合
- $B$ = 包含终点的多边形集合
- $C$ = $A \cap B$ （同时包含起点和终点的多边形集合）

则总穿越次数为：
$$
\texttt{hops} = |A \setminus C| + |B \setminus C| = (|A| - |C|) + (|B| - |C|) = |A| + |B| - 2|C|
$$

其中 $|A|$ 表示起点在内部的多边形数量， $|B|$ 表示终点在内部的多边形数量， $|C|$ 表示两点同时在内部的多边形数量。

### 算法步骤

1. 对于每个测试用例，读取所有多边形。
2. 对于每个查询 $(x_1, y_1, x_2, y_2)$ ：
   a. 计算起点在多少个多边形内部（得到 $|A|$）。
   b. 计算终点在多少个多边形内部（得到 $|B|$）。
   c. 计算起点和终点同时在多少个多边形内部（得到 $|C|$）。
   d. 根据公式计算跳跃次数： $hops = |A| + |B| - 2 \times |C|$。
   e. 输出结果。

### 点是否在多边形内部的判断

我们需要一个准确判断点是否在简单多边形内部（不包括边界）的算法。 这里采用经典的 **射线法** ，并特别处理边界情况和整数运算精度问题。

**射线法原理**：
从点 $P$ 向右作一条水平射线，统计该射线与多边形边的交点数量。 如果交点数量为奇数，则点在多边形内部；如果为偶数，则在外部。

**实现细节**：
1. **处理点在边上的情况**： 根据题目要求，点在边界上不算内部，因此如果检测到点在边上，直接返回 `false`。
2. **使用整数运算避免精度误差**： 所有坐标都是整数，因此计算交点时使用整数运算。
3. **叉积判断**： 使用叉积判断三点共线和点在线段上的情况。

### 复杂度分析

- 多边形数量 $n \le 20$，每个多边形边数 $S \le 10$。
- 查询数量 $Q$ 未明确给出，但根据题目惯例，不会很大。
- 对于每个查询，需要检查点与每个多边形的关系，复杂度为 $O(n \times S)$。
- 总复杂度为 $O(T \times Q \times n \times S)$，在给定限制下完全可行。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAX = 10000;

struct Point {
    int x, y;
    Point(int x = 0, int y = 0) : x(x), y(y) {}
};

typedef vector<Point> Polygon;

// 计算向量叉积 (a->b) × (a->c)
long long cross(const Point& a, const Point& b, const Point& c) {
    return 1LL * (b.x - a.x) * (c.y - a.y) - 1LL * (b.y - a.y) * (c.x - a.x);
}

// 判断点c是否在线段ab上
bool onSegment(const Point& a, const Point& b, const Point& c) {
    // 首先判断点c在线段ab的边界框内
    if (min(a.x, b.x) > c.x || c.x > max(a.x, b.x)) return false;
    if (min(a.y, b.y) > c.y || c.y > max(a.y, b.y)) return false;
    // 然后判断叉积是否为0（三点共线）
    return cross(a, b, c) == 0;
}

// 射线法判断点是否在多边形内部（不包括边界）
bool pointInPolygon(const Point& p, const Polygon& poly) {
    int n = poly.size();
    bool inside = false;
    
    // 遍历多边形的每条边
    for (int i = 0, j = n - 1; i < n; j = i++) {
        const Point& p1 = poly[i];
        const Point& p2 = poly[j];
        
        // 检查点是否在当前边上
        if (onSegment(p1, p2, p)) return false;
        
        // 检查射线是否与边相交
        // 条件1: 边的两个端点分别在射线上下两侧
        // 条件2: 交点在点p的右侧
        if ((p1.y > p.y) != (p2.y > p.y)) {
            // 计算交点x坐标（使用整数运算避免浮点误差）
            // 由直线两点式推导：x = x1 + (y - y1) * (x2 - x1) / (y2 - y1)
            long long xinters = 1LL * (p.y - p1.y) * (p2.x - p1.x) / (p2.y - p1.y) + p1.x;
            
            // 如果交点在点p的右侧
            if (p.x < xinters) inside = !inside;
        }
    }
    
    return inside;
}

int main() {
    int T, caseNo = 1;
    cin >> T;

    while (T--) {
        int n;
        cin >> n;
        vector<Polygon> polygons(n);

        // 读取多边形
        for (int i = 0; i < n; ++i) {
            int S;
            cin >> S;
            polygons[i].resize(S);
            for (int j = 0; j < S; ++j) cin >> polygons[i][j].x >> polygons[i][j].y;
        }

        int Q;
        cin >> Q;
        cout << "Case " << caseNo++ << ":" << endl;

        // 处理每个查询
        for (int q = 0; q < Q; ++q) {
            Point start, end;
            cin >> start.x >> start.y >> end.x >> end.y;

            int startInside = 0, endInside = 0, common = 0;

            // 统计起点和终点在每个多边形内部的情况
            for (const auto& poly : polygons) {
                bool sIn = pointInPolygon(start, poly);
                bool eIn = pointInPolygon(end, poly);
                if (sIn) startInside++;
                if (eIn) endInside++;
                if (sIn && eIn) common++;
            }

            // 计算最小跳跃次数
            int hops = startInside + endInside - 2 * common;
            cout << hops << endl;
        }
    }

    return 0;
}
```

## 总结

本题的核心是将几何问题转化为集合计数问题。 通过分析点与多边形的位置关系，我们发现最小跳跃次数可以通过简单的公式计算得到，而不需要进行复杂的路径搜索。 这种 **问题转化** 的技巧在解决几何相关问题时非常有用。

**关键要点**：
1. 将"穿越墙壁"问题转化为"点是否在多边形内部"的计数问题。
2. 使用射线法判断点与多边形的位置关系，注意处理边界情况和精度问题。
3. 利用集合运算公式 $|A| + |B| - 2|A \cap B|$ 高效计算结果。

通过本题，我们不仅学习了几何算法的实现技巧，更重要的是掌握了如何将看似复杂的问题简化为数学模型的能力。
