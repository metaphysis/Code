[UVa 11031 Looking for a Subset](https://blog.csdn.net/metaphysis/article/details/156359491)

## 题目描述

给定一个集合 $S = \{a_1, a_2, a_3, \ldots, a_n\}$ ，需要找到一个子集 $P = \{a_{x_1}, a_{x_2}, a_{x_3}, \ldots, a_{x_m}\}$ ，满足以下条件：

1. 索引严格递增： $x_1 < x_2 < \ldots < x_m$
2. 值严格递增： $a_{x_1} < a_{x_2} < \ldots < a_{x_m}$

如果存在多个满足条件的子集，则选择 $x_1$ 最小的子集；如果 $x_1$ 相同，则比较 $x_2$ ，以此类推。

### 输入格式

输入包含多组测试数据（不超过 $25$ 组）。每组数据格式如下：
- 第一行两个整数 $n$ （ $1 \leq n \leq 10000$ ）和 $q$ （ $1 \leq q \leq 100$ ）
- 第二行包含 $n$ 个整数，表示 $a_1, a_2, \ldots, a_n$
- 接下来 $q$ 行，每行一个整数 $m$ （ $1 \leq m \leq n$ ）

输入以 $n = q = 0$ 结束。

### 输出格式

对于每组数据：
1. 首先输出 `Set X:` ，其中 $X$ 从 $1$ 开始编号
2. 对于每个查询，输出 `Subset Y:` ，其中 $Y$ 从 $1$ 开始编号
3. 如果存在符合条件的子集，在一行中输出子集元素，空格分隔
4. 否则输出 `Impossible`

## 题目分析

### 问题本质

本题要求寻找**字典序索引最小**的**最长递增子序列（$\texttt{LIS}$）** 。难点在于：

1. **双重约束** ：需要同时满足索引递增和值递增
2. **字典序要求** ：当存在多个相同长度的 $\texttt{LIS}$ 时，需要选择索引字典序最小的
3. **效率要求** ： $n$ 最大为 $10000$ ， $O(n^2)$ 的动态规划会超时

### 关键洞察

通过观察可以发现一个重要的性质： **如果我们从后往前处理数组，将递增问题转化为递减问题，就可以在构造答案时自然满足索引字典序最小的要求** 。

具体来说：
- 原问题：从前向后找递增序列，需要保证索引递增
- 转换后：从后向前找递减序列（按特定映射），这样从前向后构造时索引自然递增

## 解题思路

### 步骤 1：离散化与反向映射

由于数组值可能很大（最多 $8$ 位数字），我们需要对值进行离散化。更重要的是，我们需要**反向映射**：

```cpp
// 将数组值排序去重
sort(vec.begin(), vec.end());
vec.erase(unique(vec.begin(), vec.end()), vec.end());

// 创建反向映射：值越大，映射值越小
for (size_t i = 0; i < vec.size(); ++i)
    mp[vec[i]] = vec.size() - i;
```

例如，对于数组 `[3, 4, 1, 2, 3, 6]` ：
- 排序去重： `[1, 2, 3, 4, 6]`
- 反向映射： $1 \rightarrow 5, 2 \rightarrow 4, 3 \rightarrow 3, 4 \rightarrow 2, 6 \rightarrow 1$

这样做的目的是： **原数组中的递增关系 $a[i] < a[j]$ 等价于映射后的递减关系 $mp[a[i]] > mp[a[j]]$** 。

### 步骤 2：从后往前计算 $\texttt{LDS}$

我们定义 $lds[i]$ 为： **从位置 $i$ 开始（包含 $i$ ）能够形成的最长递减子序列的长度** （这里的递减是按映射值比较的，实际上是原值的递增）。

使用树状数组（ $\texttt{Fenwick Tree}$ ）优化计算：

```cpp
for (int i = n - 1; i >= 0; --i) {
    int pos = mp[a[i]];          // 获取映射值
    lds[i] = query(pos - 1) + 1; // 查询比当前值大的位置的最大LDS
    modify(pos, lds[i], vec.size()); // 更新树状数组
    maxLen = max(maxLen, lds[i]);
}
```

**解释** ：
- `query(pos - 1)` ：查询所有映射值比当前大的位置（即原值比当前小的位置）的最大 $\texttt{LDS}$ 长度
- `lds[i] = query(pos - 1) + 1` ：当前位置的 $\texttt{LDS}$ 长度等于比它小的元素的最大 $\texttt{LDS}$ 加 $1$
- `modify(pos, lds[i], ...)` ：将当前 $\texttt{LDS}$ 长度更新到树状数组中

### 步骤 3：贪心构造答案

对于每个查询长度 $m$ ，我们从前向后扫描数组：

```cpp
int last = INT_MIN;
for (int i = 0; i < n && m; ++i) {
    if (lds[i] >= m && a[i] > last) {
        // 选择这个元素
        printf("%d ", a[i]);
        last = a[i];
        --m;
    }
}
```

**贪心策略的正确性证明** ：
1. **条件 $lds[i] \geq m$** ：保证从位置 $i$ 开始至少能选出 $m$ 个递增元素
2. **条件 $a[i] > last$** ：保证值严格递增
3. **从前向后扫描** ：当有多个位置满足条件时，我们选择索引最小的，这正好满足了字典序最小的要求

### 算法复杂度分析

1. **离散化** ： $O(n \log n)$
2. **$\texttt{LDS}$ 计算** ： $O(n \log n)$ ，每个位置一次树状数组查询和更新
3. **查询处理** ：最坏 $O(q \times n)$ ，但实际运行很快，因为一旦找到 $m$ 个元素就停止
4. **总复杂度** ： $O((n + q) \log n)$ ，在题目限制内完全可行

## 代码实现

```cpp
// Looking for a Subset
// UVa ID: 11031
// Verdict: Accepted
// Submission Date: 2025-12-28
// UVa Run Time: 0.060s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;
int n, q, a[MAXN], lds[MAXN], bit[MAXN];

inline int lowbit(int x) { return x & -x; }

void modify(int x, int val, int n) {
    while (x <= n) bit[x] = max(bit[x], val), x += lowbit(x);
}

int query(int x) {
    int ret = 0;
    while (x) ret = max(ret, bit[x]), x -= lowbit(x);
    return ret;
}

int main() {
    int caseNo = 1;
    while (scanf("%d %d", &n, &q) == 2 && (n || q)) {
        // 读入并离散化
        vector<int> vec;
        for (int i = 0; i < n; ++i) scanf("%d", &a[i]), vec.push_back(a[i]);
        sort(vec.begin(), vec.end());
        vec.erase(unique(vec.begin(), vec.end()), vec.end());
        map<int, int> mp;
        for (size_t i = 0; i < vec.size(); ++i) mp[vec[i]] = vec.size() - i; // 反向映射
        
        // 计算LDS（从后往前的最长递减子序列）
        memset(bit, 0, sizeof(bit));
        int maxLen = 0;
        for (int i = n - 1; i >= 0; --i) {
            int pos = mp[a[i]];
            lds[i] = query(pos - 1) + 1;  // 查询比当前值大的位置
            modify(pos, lds[i], vec.size());
            maxLen = max(maxLen, lds[i]);
        }
        
        printf("Set %d:\n", caseNo++);
        for (int queryNo = 1; queryNo <= q; ++queryNo) {
            int m; scanf("%d", &m);
            printf("    Subset %d:\n", queryNo);
            if (m > maxLen) { printf("    Impossible\n"); continue; }
            
            // 贪心构造字典序最小的序列
            printf("    ");
            int last = INT_MIN, first = 1;
            for (int i = 0; i < n && m; ++i) {
                if (lds[i] >= m && a[i] > last) {
                    if (!first) printf(" ");
                    printf("%d", a[i]);
                    last = a[i];
                    --m;
                    first = 0;
                }
            }
            printf("\n");
        }
    }
    return 0;
}
```

## 总结

本题的解题关键在于**问题转换**和**贪心构造**：

1. **反向映射** 将递增问题转化为递减问题，简化了处理
2. **从后往前计算 $\texttt{LDS}$** 利用树状数组优化效率
3. **贪心构造** 从前向后扫描，自然满足字典序最小的要求

这种解法的时间复杂度为 $O((n + q) \log n)$ ，空间复杂度为 $O(n)$ ，完全满足题目要求。算法精妙之处在于通过简单的映射转换，将原本复杂的问题变得易于处理。
