
> **摘要**：本题要求在 $4 \times 4$ 的棋盘中填入 $1 \sim 7$ 的整数，使每行、每列及两条对角线之和均为 $N$，且 $16$ 个数乘积对 $M$ 取模的余数不超过 $P$。文章通过预生成所有合法行向量、枚举前三行并由列和唯一确定第四行，将搜索空间从 $7^{16}$ 压缩到 $O(R^3)$，在保证字典序的前提下统计方案总数并输出前两个方案。

## 题目描述

小 $\texttt{Tuhin}$ 在玩一个 $4 \times 4$ 的棋盘，他有很多编号为 $1$ 到 $7$（包含）的卡片。他可以将任意卡片放在棋盘的任意空位。由于他擅长数学，他摆放 $16$ 张卡片，使得**每一行、每一列、两条对角线**上的数字之和都等于同一个给定的数 $N$。

他带着棋盘和所有卡片来找“我”，说：“我会给你三个数 $N$、$M$ 和 $P$。你需要像我一样摆放卡片。此外，如果这 $16$ 个数的乘积除以 $M$ 的余数**不超过** $P$，则这种摆放方式有效。请你告诉我**有效方案的总数**，并输出**前两个字典序最小**的方案（按行优先顺序比较）。如果只有一种方案，只输出那一种；如果没有方案，输出 `0`。”

“我”第二天有考试，无法立即帮助他，因此需要编写程序解决这个问题。

## 输入格式

输入文件包含多组测试数据。每组数据包含三个整数 $N$、$M$（$0 < M < 100000$）和 $P$（$0 \le P < M$），以空格分隔。

输入以一行 `0 0 0` 结束，该行不作处理。

## 输出格式

对于每组数据，首先输出 `Set X:`，其中 $X$ 从 $1$ 开始编号。

第二行输出有效方案的总数。

如果有效方案数大于等于 $1$，则按字典序（按行优先）输出前两个方案（若方案数 $\ge 2$ 输出两个，否则输出一个）。每个方案输出 $4$ 行，每行连续输出 $4$ 个数字（数字间无空格），方案结束后输出一行 `....`。

## 题目分析

本题要求在一个 $4 \times 4$ 的方格中填入 $1 \sim 7$ 的整数，使得每行、每列及两条对角线上的和均为 $N$。此外，还需满足所有 $16$ 个数的乘积对 $M$ 取模后的余数不大于 $P$。我们需要统计所有满足条件的方案数量，并按字典序输出前两个方案。

棋盘规模很小（$4 \times 4$），每个位置有 $7$ 种可能，直接暴力枚举所有 $7^{16}$ 种填法不可行。但约束条件（行、列、对角线之和为 $N$）极强，可以大幅缩小搜索空间。

一种自然的思路是枚举前三行，第四行由列和条件唯一确定，然后验证对角线条件即可。前三行中每一行都是一个长度为 $4$、元素在 $1 \sim 7$、和为 $N$ 的四元组。$1 \sim 7$ 中选 $4$ 个数和为 $N$ 的组合数量有限（$N$ 范围未知，但最大为 $28$，最小为 $4$）。我们可以预先枚举所有可能的行向量，并按字典序排序。然后按字典序枚举前三行的组合（可重复），这样找到的第一个、第二个有效方案即为字典序最小的前两个方案。

因为 $4 \times 4$ 棋盘只有 $16$ 个格子，且数字范围小，所以枚举所有行向量并三重循环是完全可行的。复杂度为 $O(R^3)$，其中 $R$ 为候选行向量个数，最坏情况 $R$ 大约为 $7^4 = 2401$，但受限于和为 $N$，实际远小于此。在最坏情况下 $N=16$ 时，组合数较多，但仍在可接受范围内。

乘积取模判断可在构造完整矩阵后直接计算，无需预先剪枝。

## 解题思路

### 步骤一：生成候选行向量

遍历所有四元组 $(a,b,c,d)$，其中 $a,b,c,d \in [1,7]$，若 $a+b+c+d = N$，则将该四元组按字典序（即 $a$ 优先、$b$ 次之、$c$ 再次）存入数组 `rows`。由于我们直接使用多重循环，`a` 从 $1$ 到 $7$，`b` 从 $1$ 到 $7$，`c` 从 $1$ 到 $7$，并计算 $d = N - a - b - c$，检查 $1 \le d \le 7$，这样生成的顺序自然就是字典序升序。

### 步骤二：枚举前三行

三重循环遍历 `rows` 的所有下标 $i_1, i_2, i_3$（允许重复），分别作为第 $1$、$2$、$3$ 行。由于 `rows` 本身按字典序排列，按 $i_1,i_2,i_3$ 从小到大枚举时，整个棋盘的字典序也是严格升序的（第一行优先，其次第二行，其次第三行）。因此我们找到的第一个有效方案即为全局字典序最小的方案，第二个为次小方案。

### 步骤三：由列和确定第四行

对于每一列 $j$（$0 \le j < 4$），第四行的值 $r_4[j] = N - (rows[i_1][j] + rows[i_2][j] + rows[i_3][j])$。若该值不在 $[1,7]$ 内，则跳过该组合。

### 步骤四：验证对角线条件

计算主对角线之和 $d_1 = rows[i_1][0] + rows[i_2][1] + rows[i_3][2] + r_4[3]$，副对角线之和 $d_2 = rows[i_1][3] + rows[i_2][2] + rows[i_3][1] + r_4[0]$。若 $d_1 = N$ 且 $d_2 = N$，则构成一个完整的合法棋盘。

### 步骤五：乘积取模判断

构造完整的 $4 \times 4$ 矩阵后，计算所有 $16$ 个数的乘积对 $M$ 取模的值。乘积可能很大，但我们在计算过程中每一步都取模，使用 `long long` 类型安全。若最终余数 $\le P$，则该方案有效。

### 步骤六：统计与输出

维护有效方案总数 `total` 以及前两个方案的矩阵副本。由于枚举顺序就是字典序，第一个和第二个满足条件的方案即为需要输出的前两个。最后按照输出格式打印结果。

### 复杂度分析

- 生成行向量：最坏情况下需遍历 $7^3 = 343$ 种组合（因为 $d$ 由 $a,b,c$ 唯一确定），实际很少。
- 枚举前三行：$O(R^3)$，$R$ 为行向量个数，最大不超过 $343$（实际上由于 $N$ 限制，$R$ 更小）。$343^3 \approx 4\times 10^7$，对于单个测试用例尚可接受，但题目可能有多组数据，不过由于 $4\times4$ 固定，每组数据独立，总时间在合理范围内。
- 乘积计算：$16$ 次乘法取模，常数极低。
- 空间复杂度：$O(R)$ 存储行向量，$O(1)$ 存储矩阵。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M, P;
    int caseNum = 1;
    while (cin >> N >> M >> P) {
        if (N == 0 && M == 0 && P == 0) break;
        // 生成所有行向量（四元组，和为N，元素1~7），按字典序排列
        vector<array<int, 4>> rows;
        for (int a = 1; a <= 7; ++a)
            for (int b = 1; b <= 7; ++b)
                for (int c = 1; c <= 7; ++c) {
                    int d = N - a - b - c;
                    if (d >= 1 && d <= 7)
                        rows.push_back({a, b, c, d});
                }
        int total = 0;
        int ans1[4][4], ans2[4][4];
        // 枚举前三行
        for (size_t i1 = 0; i1 < rows.size(); ++i1)
            for (size_t i2 = 0; i2 < rows.size(); ++i2)
                for (size_t i3 = 0; i3 < rows.size(); ++i3) {
                    int row4[4];
                    bool ok = true;
                    // 由列和确定第四行
                    for (int j = 0; j < 4; ++j) {
                        int val = N - rows[i1][j] - rows[i2][j] - rows[i3][j];
                        if (val < 1 || val > 7) { ok = false; break; }
                        row4[j] = val;
                    }
                    if (!ok) continue;
                    // 检查两条对角线
                    int diag1 = rows[i1][0] + rows[i2][1] + rows[i3][2] + row4[3];
                    int diag2 = rows[i1][3] + rows[i2][2] + rows[i3][1] + row4[0];
                    if (diag1 != N || diag2 != N) continue;
                    // 构建完整矩阵
                    int mat[4][4];
                    for (int j = 0; j < 4; ++j) mat[0][j] = rows[i1][j];
                    for (int j = 0; j < 4; ++j) mat[1][j] = rows[i2][j];
                    for (int j = 0; j < 4; ++j) mat[2][j] = rows[i3][j];
                    for (int j = 0; j < 4; ++j) mat[3][j] = row4[j];
                    // 计算乘积模 M
                    long long prod = 1;
                    for (int i = 0; i < 4; ++i)
                        for (int j = 0; j < 4; ++j)
                            prod = (prod * mat[i][j]) % M;
                    if (prod <= P) {
                        ++total;
                        if (total == 1) memcpy(ans1, mat, sizeof(ans1));
                        else if (total == 2) memcpy(ans2, mat, sizeof(ans2));
                    }
                }
        // 输出
        cout << "Set " << caseNum << ":" << endl;
        cout << total << endl;
        if (total >= 1) {
            for (int i = 0; i < 4; ++i) {
                for (int j = 0; j < 4; ++j) cout << ans1[i][j];
                cout << endl;
            }
            cout << "...." << endl;
        }
        if (total >= 2) {
            for (int i = 0; i < 4; ++i) {
                for (int j = 0; j < 4; ++j) cout << ans2[i][j];
                cout << endl;
            }
            cout << "...." << endl;
        }
        ++caseNum;
    }
    return 0;
}
```

## 总结

本题利用了棋盘规模固定且约束条件强的特点，通过枚举所有合法的行向量，再枚举前三行，由列和唯一确定第四行，从而将搜索空间从 $7^{16}$ 压缩到 $O(R^3)$，使得暴力求解成为可能。

关键点在于：
- 利用字典序枚举顺序，直接得到前两个最小方案，无需额外排序。
- 由列和推导第四行，减少一层枚举。
- 乘积取模在计算过程中进行，避免大整数溢出。

这种“枚举部分行 + 推导剩余行”的思想在类似方格填充问题中非常实用，只要约束条件能够推导出剩余变量，就可以大幅降低复杂度。同时，本题也提醒我们，在数据范围极小时，直接暴力结合简单剪枝往往是最直接有效的解法。
