## 题目分析

### 问题描述

$\texttt{Jim}$ 需要高效存储多个卡牌手牌。每张牌有一个花色（$\texttt{C}$、$\texttt{D}$、$\texttt{H}$、$\texttt{S}$）和一个点数（$\texttt{A}$、$2$-$10$、$\texttt{J}$、$\texttt{Q}$、$\texttt{K}$）。每手牌按以下规范顺序存储：
- 先按花色排序：$\texttt{C}$ → $\texttt{D}$ → $\texttt{H}$ → $\texttt{S}$
- 同花色内按点数排序：$\texttt{A}$ → $2$ → $3$ → $\dots$ → $10$ → $\texttt{J}$ → $\texttt{Q}$ → $\texttt{K}$

关键优化：**如果两个链表共享相同的尾部，可以合并共享部分**，从而节省内存。

### 问题转化

这是一个**最长公共后缀**问题。共享尾部意味着从末尾开始有连续的相同卡片序列。

**核心思路**：将问题转化为**前缀匹配**问题
- 将每手牌**逆序**处理
- 公共后缀变为公共前缀
- 使用 $\texttt{Trie}$（字典树）数据结构高效解决

## 解题思路

### $\texttt{Trie}$ 数据结构

$\texttt{Trie}$ 是一种树形结构，用于高效存储字符串集合。在这里，我们将每手牌看作一个"字符串"（卡片序列），但需要从后往前插入。

### 算法步骤

1. **读取输入**：存储所有手牌
2. **逆序构建 $\texttt{Trie}$**：对每手牌从最后一张牌开始向前插入
3. **统计节点**：每次创建新节点时计数器加一
4. **输出结果**：节点总数即为答案

### 复杂度分析

- **时间复杂度**：$O(N)$，其中 $N$ 是总卡片数
- **空间复杂度**：$O(N)$，最坏情况下每个节点存储一张牌

### 样例分析

输入：
```
3
3 7D AH 5S
4 9C 3D 4D 5S  
2 AH 5S
```

处理过程：
- 手牌1逆序：`5S → AH → 7D`
- 手牌2逆序：`5S → 4D → 3D → 9C`
- 手牌3逆序：`5S → AH`

构建的 $\texttt{Trie}$ 结构：
```
根节点
│
└── 5S (节点1)
    ├── AH (节点2)
    │   └── 7D (节点3)
    └── 4D (节点4)
        └── 3D (节点5)
            └── 9C (节点6)
```

总节点数：$6$

## 代码实现

```cpp
// Card Hands
// UVa ID: 11035
// Verdict: Accepted
// Submission Date: 2025-11-15
// UVa Run Time: 0.050s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct TrieNode {
    unordered_map<string, TrieNode*> children;
};

int main() {
    int n;
    while (cin >> n && n) {
        TrieNode* root = new TrieNode();
        int nodeCount = 0;
        
        vector<vector<string>> hands(n);
        
        // 读取所有手牌
        for (int i = 0; i < n; i++) {
            int k;
            cin >> k;
            hands[i].resize(k);
            for (int j = 0; j < k; j++) {
                cin >> hands[i][j];
            }
        }
        
        // 从每手牌的末尾开始插入到Trie中
        for (int i = 0; i < n; i++) {
            TrieNode* curr = root;
            // 从最后一张牌开始向前插入
            for (int j = hands[i].size() - 1; j >= 0; j--) {
                string card = hands[i][j];
                if (curr->children.find(card) == curr->children.end()) {
                    curr->children[card] = new TrieNode();
                    nodeCount++;
                }
                curr = curr->children[card];
            }
        }
        
        cout << nodeCount << endl;
    }
    return 0;
}
```

## 关键点总结

1. **逆序处理**：将后缀匹配转化为前缀匹配是解题的关键
2. **$\texttt{Trie}$ 应用**：高效检测和共享公共前缀
3. **节点计数**：只在创建新节点时计数，自动处理共享

这种方法确保了最小化的内存使用，完美符合题目要求的共享尾部优化策略。
