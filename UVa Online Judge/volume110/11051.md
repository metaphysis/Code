## 题目描述

考虑单位圆上的 $n$ 个点，编号为 $0,1,\ldots,n-1$。初始时，点 $k$ 与 $x$ 轴的夹角为 $360 \cdot k/n$ 度（按逆时针方向测量）。我们可以对该点集执行两种操作：

- **顺时针旋转** $360/n$ 度（用字符 $\texttt{r}$ 表示）
- **关于 $x$ 轴反射**（用字符 $\texttt{m}$ 表示）

给定一个操作序列的缩写形式，要求找到具有最少操作次数的等价序列。在多个最优解的情况下，输出任意一个即可。

## 题目分析

本题涉及**二面体群** $D_n$ 的理论，即正 $n$ 边形的对称群。二面体群由旋转和反射生成，具有以下重要性质：

### 群元素表示
任何操作序列都可以表示为标准形式 $r^a m^b$，其中：
- $a \in [0, n-1]$ 表示旋转次数
- $b \in \{0, 1\}$ 表示反射次数（模 $2$）

### 群运算规则
1. **旋转复合**：$r^a \cdot r^c = r^{a+c \mod n}$
2. **反射自逆**：$m^2 = e$（单位元）
3. **非交换性**：$m \cdot r = r^{-1} \cdot m$

### 关键等价关系
对于化简和寻找最短序列，以下等价关系至关重要：

1. **纯旋转的简化**：
   - $r^a = r^{a \mod n}$
   - $r^a = r^{n-a}$（旋转方向不同但效果相同）

2. **通过反射改变方向**：
   - $r^a = m \cdot r^{n-a} \cdot m$
   - $r^a \cdot m = m \cdot r^{n-a}$

## 解题思路

### 步骤1：解析输入序列
将输入的缩写序列解析为基本操作，维护当前状态 $(a, b)$，表示当前序列等价于 $r^a m^b$。

### 步骤2：应用群运算规则
对于每个新操作：
- 如果是 $\texttt{r}^k$：
  - 当 $b = 0$ 时：$r^a \cdot r^k = r^{a+k}$
  - 当 $b = 1$ 时：$r^a m \cdot r^k = r^a (m r^k) = r^a (r^{-k} m) = r^{a-k} m$
- 如果是 $\texttt{m}^k$：
  - $r^a m^b \cdot m^k = r^a m^{b+k \mod 2}$

### 步骤3：生成所有等价表示
对于最终状态 $(a, b)$，考虑所有可能的等价表示：

**情况1：$b = 0$（纯旋转）**
- $r^a$ - 操作次数：$a$
- $m \cdot r^{n-a} \cdot m$ - 操作次数：$(n-a) + 2$

**情况2：$b = 1$（旋转加反射）**
- $r^a m$ - 操作次数：$a + 1$
- $m \cdot r^{n-a}$ - 操作次数：$(n-a) + 1$

### 步骤4：选择最优解
比较所有等价表示的操作次数，选择操作次数最少的表示。在操作次数相同的情况下，可以任意选择。

## 算法复杂度
- **时间复杂度**：$O(k)$，其中 $k$ 是输入序列中的操作令牌数量
- **空间复杂度**：$O(1)$，仅使用常数额外空间

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    while (cin >> n && n) {
        string line;
        getline(cin, line);
        getline(cin, line);
        
        long long a = 0;
        int b = 0;
        stringstream ss(line);
        string token;
        
        while (ss >> token) {
            char op = token[0];
            int num = stoi(token.substr(1));
            if (op == 'r') b ? a -= num : a += num;
            else b = (b + num) % 2;
        }
        
        a %= n;
        if (a < 0) a += n;
        
        vector<pair<int, string>> candidates;
        if (b == 0) {
            if (a == 0) candidates.push_back({0, ""});
            else candidates.push_back({a, "r" + to_string(a)});
            if (n - a > 0) candidates.push_back({n - a + 2, "m1 r" + to_string(n - a) + " m1"});
        } else {
            if (a == 0) candidates.push_back({1, "m1"});
            else candidates.push_back({a + 1, "r" + to_string(a) + " m1"});
            if (n - a == 0) candidates.push_back({1, "m1"});
            else candidates.push_back({n - a + 1, "m1 r" + to_string(n - a)});
        }
        
        auto best = candidates[0];
        for (size_t i = 1; i < candidates.size(); i++)
            if (candidates[i].first < best.first) best = candidates[i];
        
        cout << (best.second.empty() ? "\n" : best.second + "\n");
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解二面体群的代数结构，特别是旋转和反射操作的复合规则。通过将任意操作序列化为标准形式 $r^a m^b$，并利用群的等价关系生成所有可能的简短表示，可以有效地找到操作次数最少的最优解。

这种将几何对称性问题转化为代数群论问题的方法，在计算几何和组合数学中有着广泛的应用。
