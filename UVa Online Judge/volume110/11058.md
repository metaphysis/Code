## 题目描述

你有一个字符串 $S$，需要对其中的字母进行编码替换。每个字母（$a$-$z$）根据编码策略进行替换。编码策略会随着处理位置的变化而改变。

初始时，有一个**初始编码策略**：$26$ 行输入，分别表示字母 $a$ 到 $z$ 在初始时被替换成哪个字母。

然后有 $R$ 条额外规则，每条规则的格式为 $P~X~Y$，表示**从位置 $P$ 开始**，字母 $X$ 被替换成 $Y$。规则按 $P$ 非递减顺序给出，如果同一位置同一字母有多个规则，以后出现的为准。

你需要对 $S$ 的每个位置 $i$，根据**在该位置生效的编码策略**，将 $S[i]$ 替换成对应的字母，得到最终编码字符串 $E$。

### 输入格式
- 字符串 $S$（长度 $\leq 100$）
- $26$ 行，每行一个字符，表示初始编码策略
- 整数 $R$（$0 \leq R \leq 1000$）
- $R$ 行规则，每行格式为 $P~X~Y$
- 测试用例之间用空行分隔

### 输出格式
对于每个测试用例，输出：
```
Case #N: The encoding string is E.
```
（$N$ 为测试用例编号，$E$ 为编码后的字符串）

## 题目分析

### 问题核心
这个问题要求我们根据位置相关的规则对字符串进行编码。关键在于：**每个位置的编码映射可能不同**，规则从某个位置开始生效，并覆盖之前的映射。

### 难点分析
1. **动态变化的编码表**：编码规则随着处理位置的变化而更新
2. **规则优先级**：同一位置同一字母的多个规则，以后出现的为准
3. **高效处理**：需要在 $O(|S| + R)$ 时间内完成处理

### 关键观察
- 规则按位置 $P$ 非递减排序，这让我们可以顺序处理规则
- 对于每个位置 $i$，我们需要应用所有 $P \leq i$ 的规则
- 由于规则可能覆盖之前的映射，我们需要维护一个当前编码表

## 解题思路

### 算法设计
我们可以采用**顺序处理**的方法：

1. **初始化编码表**：读取 $26$ 个初始映射，存储在数组中
2. **存储规则**：将所有规则存储在数组中
3. **处理每个字符**：
   - 对于位置 $i$，应用所有 $P \leq i$ 的规则（按输入顺序）
   - 使用当前编码表对 $S[i]$ 进行替换
4. **规则指针优化**：使用指针记录已应用的规则，避免重复处理

## 参考代码

```cpp
// Encoding
// UVa ID: 11058
// Verdict: Accepted
// Submission Date: 2025-10-30
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct rule {
    int p;
    char x, y;
};

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    string s;
    int T = 0;
    while (cin >> s) {
        T++;
        char table[128];
        for (int i = 0; i < 26; i++) cin >> table['a' + i];
        int R;
        cin >> R;
        vector<rule> rules(R);
        for (int i = 0; i < R; i++) cin >> rules[i].p >> rules[i].x >> rules[i].y;
        string encoding;
        for (int i = 0, j = 0; i < (int)s.length(); i++) {
            while (j < R && rules[j].p <= i) {
                table[rules[j].x] = rules[j].y;
                j++;
            }
            encoding += table[s[i]];
        }
        cout << "Case #" << T << ": The encoding string is " << encoding << "." << "\n\n";
    }
    return 0;
}
```

## 代码解释

### 数据结构
- `table[128]`：编码映射表，索引为 ASCII 字符
- `rule` 结构体：存储规则的起始位置 $P$、原字符 $X$、目标字符 $Y$
- `vector<rule> rules`：存储所有规则

### 主要逻辑
1. **读取输入**：
   - 读取字符串 $S$
   - 读取 $26$ 个初始映射到 `table` 数组中
   - 读取规则数量 $R$ 和所有规则

2. **处理字符串**：
   - 使用双指针：`i` 遍历字符串位置，`j` 遍历规则
   - 对于每个位置 $i$，应用所有 $P \leq i$ 的规则
   - 使用当前编码表替换字符并构建结果字符串

3. **输出结果**：按格式输出编码后的字符串

### 优化技巧
- **规则指针**：`j` 指针确保每个规则只被应用一次
- **原地更新**：直接在 `table` 数组中更新映射，避免创建临时数组
- **快速 `I/O`**：使用 `cin.tie(0)` 和 `ios::sync_with_stdio(false)` 加速输入输出

这个解法充分利用了题目中规则按位置排序的特性，实现了高效且简洁的解决方案。
