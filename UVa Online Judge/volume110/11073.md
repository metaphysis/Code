## 题目描述

欧拉函数 $\phi(n)$ 定义为小于等于 $n$ 且与 $n$ 互质的正整数的个数。 两个数互质意味着它们的最大公约数为 $1$ 。 如果已知 $n$ 的质因数分解为 $n = p_1^{e_1}p_2^{e_2}\ldots p_j^{e_j}$ ， 那么 $\phi(n)$ 的值可以通过以下公式计算：

$$
\phi(n) = \prod_{i=1}^{j}(p_i - 1)p_i^{e_i-1}
$$

现在给定一个正整数 $x$ ， 要求计算出所有满足方程 $\phi(n) = x$ 的正整数 $n$ 。

### 输入格式

输入包含多行， 每行一个正整数 $x$ （没有前导零）。 所有 $x$ 都是小于 $100000000$ 的正整数。

### 输出格式

对于每个 $x$ ， 输出一行结果。 如果方程有解， 按升序输出所有解， 用空格分隔； 如果无解， 输出 `No solution.`。

### 样例输入

```
1
3
6
```

### 样例输出

```
1 2
No solution.
7 9 14 18
```

（注意： 样例中三个数在同一行输入， 输出也对应在同一行， 但实际测试中通常是每行一个输入）

## 题目分析

这是一个经典的**逆欧拉函数**问题。 给定 $\phi(n)$ 的值 $x$ ， 求所有可能的 $n$ 。 问题的难点在于 $x$ 的最大值可达 $10^8$ ， 需要高效的算法。

### 欧拉函数的关键性质

1. **积性函数**： 如果 $a$ 和 $b$ 互质， 那么 $\phi(ab) = \phi(a)\phi(b)$
2. **质数幂形式**： 对于质数 $p$ 和正整数 $k$ ， $\phi(p^k) = p^{k-1}(p-1)$
3. **特殊值**： $\phi(1) = 1$ ， 对于质数 $p$ ， $\phi(p) = p-1$

### 问题转化

设 $n$ 的质因数分解为 $n = p_1^{e_1}p_2^{e_2}\cdots p_m^{e_m}$ ， 根据欧拉函数的公式：

$$
\phi(n) = \prod_{i=1}^m p_i^{e_i-1}(p_i - 1) = x
$$

我们需要找到所有可能的质数 $p_i$ 和指数 $e_i$ ， 使得它们的欧拉函数值的乘积等于 $x$ 。 这实际上是一个因式分解问题。

## 解题思路

### 核心算法：深度优先搜索（$\texttt{DFS}$）

由于欧拉函数的积性性质， 我们可以将 $x$ 分解为若干形如 $p^{k-1}(p-1)$ 的因子的乘积。 采用 $\texttt{DFS}$ 回溯搜索所有可能的分解方式。

#### 搜索状态设计

每个搜索状态包含三个参数：
- $x$ ： 当前还需要分解的剩余值
- $n$ ： 已经构造出的部分 $n$ 的值
- $idx$ ： 当前从第几个质数开始尝试（ 避免重复排列 ）

#### 搜索过程

1. **终止条件**： 当 $x = 1$ 时， 说明已经成功分解完毕， 当前 $n$ 是一个解。 此外， 如果 $n$ 是奇数， 那么 $2n$ 也是一个解（ 因为 $\phi(2n) = \phi(n)$ 当 $n$ 为奇数时 ）。
2. **直接解**： 如果 $x+1$ 是质数， 且该质数大于之前考虑过的所有质数， 那么 $n \times (x+1)$ 也是一个解（ 因为 $\phi(x+1) = x$ ）。
3. **枚举质因子**： 从第 $idx$ 个质数开始， 尝试每个质数 $p$ ：
   - 剪枝： 如果 $(p-1)^2 > x$ ， 则停止枚举（ 因为不可能再有更大的质因子满足条件 ）。
   - 检查： 如果 $p-1$ 能整除 $x$ ， 则：
     a. 处理 $p^1$ 的情况： 递归搜索 $(x/(p-1), n \times p, i+1)$
     b. 处理 $p^k$ （ $k \ge 2$ ）的情况： 继续除 $p$ 并递归搜索

#### 关键优化

1. **质数表预计算**： 预处理 $10^5$ 以内的所有质数， 用于快速判断质数和试除。
2. **剪枝策略**： $(p-1)^2 > x$ 时停止枚举， 大大减少搜索空间。
3. **避免重复**： 通过 $idx$ 参数确保质数按递增顺序选择， 避免不同的排列产生相同的解。
4. **高效位运算筛法**： 使用位数组存储质数表， 节省空间。

### 算法复杂度分析

- **时间复杂度**： 最坏情况下是指数级的， 但由于 $x$ 的范围有限且剪枝充分， 实际运行效率很高， 能够处理 $x < 10^8$ 的所有测试数据。
- **空间复杂度**： 主要消耗在存储质数表和结果集上， 均为 $O(\sqrt{x})$ 级别。

## 注意事项

1. **数据类型**： 由于 $n$ 可能超过 $10^9$ ， 需要使用 `long long` 类型。
2. **边界情况**： 特别注意 $x = 1$ 的情况， 有两个解： $1$ 和 $2$ 。
3. **输出格式**： 解需要按升序排序， 且用空格分隔。 如果没有解， 输出 `No solution.` 。
4. **质数判断**： 对于大数的质数判断， 需要使用预计算的质数表进行试除。

```cpp
// Euler‘s Totient Function
// UVa ID: 11073

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// 位运算宏定义，用于高效质数筛
#define GET(x) (M[(x) >> 5] & (1 << ((x) & 0x1F)))
#define SET(x) (M[(x) >> 5] |= (1 << ((x) & 0x1F)))

const int MAXN = 100010;  // 质数筛范围
int primes[MAXN >> 3], cnt, M[MAXN >> 5] = {3};  // 位数组存储质数信息

// 线性筛法，预处理所有质数
void sieve() {
    for (int i = 2; i < MAXN; i++) {
        if (!GET(i)) primes[cnt++] = i;  // i是质数
        for (int j = 0; j < cnt && i * primes[j] < MAXN; j++) {
            SET(i * primes[j]);  // 标记合数
            if (i % primes[j] == 0) break;  // 保证每个数只被最小质因子标记
        }
    }
}

// 判断一个数是否为质数
bool isPrime(ll n) {
    if (n < 2) return false;
    if (n <= primes[cnt - 1]) return binary_search(primes, primes + cnt, n);
    // 使用预计算的质数表进行试除
    for (int p : primes) {
        if ((ll)p * p > n) break;
        if (n % p == 0) return false;
    }
    return true;
}

const int MAXX = 100000000;  // x的最大值
vector<ll> answers;  // 存储所有解

// 深度优先搜索函数
void dfs(ll x, ll n, int idx) {
    if (x == 1) {
        answers.push_back(n);  // 找到解
        if (n % 2 == 1) answers.push_back(n * 2);  // n为奇数时，2n也是解
        return;
    }
    // 如果x+1是质数且大于之前考虑的所有质数
    if (isPrime(x + 1) && (x + 1) > (idx ? primes[idx - 1] : 1))
        answers.push_back(n * (x + 1));
    
    // 枚举可能的质因子
    for (int i = idx; i < cnt; i++) {
        int p = primes[i];
        if (1LL * (p - 1) * (p - 1) > x) break;  // 剪枝
        
        if (x % (p - 1) == 0) {
            ll r = x / (p - 1), m = n * p;
            dfs(r, m, i + 1);  // 处理p^1的情况
            
            // 处理p^k (k>=2)的情况
            while (r % p == 0) {
                r /= p, m *= p;
                dfs(r, m, i + 1);
            }
        }
    }
}

// 主求解函数
void solve(ll x) {
    answers.clear();
    dfs(x, 1, 0);
    // 排序和去重
    sort(answers.begin(), answers.end());
    answers.erase(unique(answers.begin(), answers.end()), answers.end());
}

int main() {
    sieve();  // 预处理质数表
    
    ll x;
    while (cin >> x) {
        solve(x);
        if (answers.empty()) 
            cout << "No solution.\n";
        else {
            for (size_t i = 0; i < answers.size(); i++) {
                if (i) cout << ' ';
                cout << answers[i];
            }
            cout << '\n';
        }
    }
    return 0;
}
```

## 总结

本题是一个典型的数论与搜索结合的问题。 通过深入理解欧拉函数的性质， 我们可以将逆欧拉函数问题转化为一个搜索问题。 关键点在于：

1. **利用积性性质分解问题**： 将大问题分解为多个子问题， 每个子问题处理一个质因子的贡献。
2. **高效的搜索策略**： 通过深度优先搜索系统地探索所有可能的分解方式。
3. **精心设计的剪枝**： 利用数学性质大幅减少搜索空间。
4. **预处理优化**： 预计算质数表， 加速质数判断和因子枚举。

该算法对于 $x < 10^8$ 的数据范围完全可行， 在实际测试中能够快速得出正确结果。 通过本题， 我们不仅学习了欧拉函数的性质， 也掌握了如何将数学问题转化为高效的搜索算法。
