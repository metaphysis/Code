## 题目分析

本题要求计算长度为 $N$ 的排列中，**最少需要恰好 $K$ 次交换** 才能将其变为升序排列的排列个数。

### 关键概念

1. **排列的最少交换次数**  
   对于任意一个排列，将其变为升序排列所需的最少交换次数等于 $N - c$，其中 $c$ 是该排列的循环分解中的循环个数。

2. **循环分解**  
   每个排列都可以唯一分解为若干个不相交的循环。例如，排列 $(2, 1, 4, 3)$ 可以分解为两个循环 $(1\ 2)$ 和 $(3\ 4)$。

3. **第一类斯特林数**  
   第一类无符号斯特林数 $c(n, k)$ 表示 $n$ 个元素恰好形成 $k$ 个循环的排列数。其递推公式为：
   $$
   c(n, k) = c(n-1, k-1) + (n-1) \cdot c(n-1, k)
   $$
   边界条件：$c(0, 0) = 1$，$c(n, 0) = 0$（当 $n > 0$）。

### 问题转化

题目要求最少交换次数恰好为 $K$ 的排列数，即：
$$
N - c = K \quad \Rightarrow \quad c = N - K
$$
因此，答案就是第一类斯特林数 $c(N, N-K)$。

### 算法设计

1. **预处理**：使用动态规划计算所有 $n \leq 21$，$k \leq n$ 的 $c(n, k)$ 值。
2. **查询处理**：对于每个 $(N, K)$ 查询，直接输出 $c(N, N-K)$。
3. **终止条件**：当输入为 $(0, 0)$ 时结束程序。

### 复杂度分析

- **预处理**：$O(N^2)$，其中 $N = 21$，计算量很小。
- **查询**：$O(1)$ 直接查表。
- **总复杂度**：完全可行，满足题目要求。

## 代码实现

```cpp
// Find the Permutations
// UVa ID: 11077
// Verdict: Accepted

// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
using ull = unsigned long long;
int main() {
    const int maxN = 21;
    // 斯特林数表，stirlingTable[n][k] 表示 n 个元素恰好 k 个循环的排列数
    vector<vector<ull>> stirlingTable(maxN + 1, vector<ull>(maxN + 1, 0));
    // 初始化：0 个元素 0 个循环只有 1 种情况（空排列）
    stirlingTable[0][0] = 1;
    // 递推计算斯特林数
    for (int n = 1; n <= maxN; n++)
        for (int k = 1; k <= n; k++) {
            // 新元素单独成循环，或者插入到已有的 n-1 个元素的某个循环中
            stirlingTable[n][k] = stirlingTable[n - 1][k - 1] + (n - 1) * stirlingTable[n - 1][k];
        }
    int n, k;
    while (cin >> n >> k) {
        if (n == 0 && k == 0) break;
        // 最少交换次数 = n - 循环数 = k → 循环数 = n - k
        cout << stirlingTable[n][n - k] << endl;
    }
    return 0;
}
```

### 代码说明

- **数据类型**：使用 `unsigned long long` 防止溢出，因为 $21!$ 在 `ull` 范围内。
- **预处理**：`stirlingTable` 存储所有需要的斯特林数值。
- **查询处理**：直接输出对应的斯特林数 $c(N, N-K)$。
- **终止条件**：检测到 `0 0` 输入时结束程序。

该算法高效且正确，能够快速处理所有测试用例。
