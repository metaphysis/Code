## 题目描述

所有有经验的参赛者都知道，在阶乘 $n!$ 中质数 $p$ 的出现次数可以用以下公式计算：

$$f(n,p) = \left\lfloor \frac{n}{p} \right\rfloor + \left\lfloor \frac{n}{p^2} \right\rfloor + \left\lfloor \frac{n}{p^3} \right\rfloor + \left\lfloor \frac{n}{p^4} \right\rfloor + \cdots$$

这个公式可以有效地用于计算任意进制下 $n!$ 的尾随零的个数。设 $z(n,b)$ 是一个函数，表示在进制 $b$ 下 $n!$ 的尾随零的个数。定义一个新函数 $soz(n,b)$ 如下：

$$soz(n,b) = \sum_{i=1}^{n} z(i,b)$$

给定 $n$ 和基数 $b$，你的任务是求出 $soz(n,b)$ 的值。

**输入限制：**
- $0 \leq n \leq 4000000000$
- $1 < b \leq 100000$
- $b$ 是无平方因子数（不能被任何平方数整除，除了 $1$）
- 最多 $1200$ 行输入

## 题目分析

### 关键观察

1. **无平方因子数的性质**：由于 $b$ 是无平方因子数，它的质因数分解形式为 $b = p_1 \times p_2 \times \cdots \times p_k$，其中每个质因子的指数都是 $1$。

2. **尾随零的计算**：在 $b$ 进制下，$n!$ 的尾随零个数由质因数分解中各个质因子在 $n!$ 中出现次数的最小值决定：
   $$z(n,b) = \min\{f(n,p_1), f(n,p_2), \ldots, f(n,p_k)\}$$

3. **关键优化**：对于无平方因子数，尾随零个数实际上由 $b$ 的**最大质因子**决定。这是因为较大的质因子在阶乘中出现的次数总是小于或等于较小质因子出现的次数：
   $$z(n,b) = f(n, p_{\max}) \quad \text{其中 } p_{\max} \text{ 是 } b \text{ 的最大质因子}$$

### 数学推导

我们需要计算：
$$soz(n,b) = \sum_{i=1}^n z(i,b) = \sum_{i=1}^n f(i, p_{\max})$$

展开 $f(i, p_{\max})$：
$$soz(n,b) = \sum_{i=1}^n \left( \left\lfloor \frac{i}{p_{\max}} \right\rfloor + \left\lfloor \frac{i}{p_{\max}^2} \right\rfloor + \left\lfloor \frac{i}{p_{\max}^3} \right\rfloor + \cdots \right)$$

交换求和顺序：
$$soz(n,b) = \sum_{k=1}^{\infty} \sum_{i=1}^n \left\lfloor \frac{i}{p_{\max}^k} \right\rfloor$$

令 $S(n, m) = \sum_{i=1}^n \lfloor i/m \rfloor$，则：
$$soz(n,b) = \sum_{k=1}^{\infty} S(n, p_{\max}^k)$$

### 高效计算 $S(n, m)$

对于 $S(n, m) = \sum_{i=1}^n \lfloor i/m \rfloor$，我们可以用数学公式直接计算：

设 $q = \lfloor n/m \rfloor$（完整周期的个数），$r = n \% m$（最后一个不完整周期的元素个数）。

- 前 $q-1$ 个完整周期：每个周期贡献 $0 + 1 + 2 + \cdots + (m-1) = \frac{m(m-1)}{2}$
- 最后一个不完整周期：贡献 $q \times (r + 1)$

因此：
$$S(n, m) = m \times \frac{(q-1)q}{2} + q \times (r + 1)$$

## 算法步骤

1. **寻找最大质因子**：对 $b$ 进行质因数分解，找到最大的质因子 $p_{\max}$
2. **计算总和**：对于 $k = 1, 2, 3, \ldots$，计算 $S(n, p_{\max}^k)$ 并累加，直到 $p_{\max}^k > n$
3. **输出结果**：对于每个测试用例输出计算得到的 $soz(n,b)$

## 复杂度分析

- **寻找最大质因子**：$O(\sqrt{b})$，由于 $b \leq 100000$，这是可接受的
- **计算总和**：$O(\log_{p_{\max}} n)$，由于 $n \leq 4 \times 10^9$，这非常高效
- **总体复杂度**：对于 $1200$ 个测试用例，总复杂度是可接受的

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// 获取b的最大质因子
ll getMaxPrimeFactor(ll b) {
    ll maxPrime = 1;
    for (ll p = 2; p * p <= b; ++p) {
        if (b % p == 0) {
            maxPrime = max(maxPrime, p);
            while (b % p == 0) b /= p;
        }
    }
    return max(maxPrime, b);
}

// 计算 ∑_{i=1}^n ⌊i/m⌋
ll sumFloor(ll n, ll m) {
    ll quotient = n / m;
    ll remainder = n % m;
    return m * (quotient - 1) * quotient / 2 + quotient * (remainder + 1);
}

// 计算 soz(n, b)
ll soz(ll n, ll b) {
    if (n == 0) return 0;
    ll maxPrime = getMaxPrimeFactor(b);
    ll sum = 0;
    ll power = maxPrime;
    while (power <= n) {
        sum += sumFloor(n, power);
        if (power > n / maxPrime) break;
        power *= maxPrime;
    }
    return sum;
}

int main() {
    ll n, b;
    while (cin >> n >> b && (n || b)) {
        cout << soz(n, b) << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于利用无平方因子数的性质和数学推导，将问题转化为计算 $\sum_{i=1}^n f(i, p_{\max})$，然后通过数学公式直接计算，避免了低效的遍历和二分查找。这种数学优化的方法在处理大范围数据时非常有效。
