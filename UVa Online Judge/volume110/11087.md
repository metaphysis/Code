[UVa 11087 Divisibility Testing](https://blog.csdn.net/metaphysis/article/details/154434799)

## 题目描述

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$ 和一个整数 $k$，要求统计满足以下条件的不同有序对 $(a_i, a_j)$ 的数量：

1. $a_i \le a_j$
2. $1 \le i, j \le n$ 且 $i \neq j$
3. $(a_i + a_j)$ 能被 $k$ 整除
4. 两个有序对 $(a, b)$ 和 $(c, d)$ 被认为是相同的，当且仅当 $a = c$ 且 $b = d$

**注意**：这里统计的是**不同的值对**，而不是索引对。即使原数组中有多个相同的值，只要值对 $(a_i, a_j)$ 相同，就只计算一次。

---

## 输入格式

- 第一行：整数 $T$，表示测试用例的数量
- 每个测试用例包含两行：
  - 第一行：两个整数 $n$ 和 $k$
  - 第二行：$n$ 个整数 $a_1, a_2, \dots, a_n$

---

## 输出格式

对于每个测试用例，输出 `"Case X: Y"`，其中 $X$ 是测试用例编号，$Y$ 是满足条件的对数。

---

## 约束条件

- $T < 100$
- $1 < n < 100001$
- $0 < k < 501$
- $|a_i| < 10000001$ 对于任意 $i$

---

## 样例分析

### 样例 1
```
输入：
2
5 1
4 1 2 2 3
5 2
4 1 2 2 3

输出：
Case 1: 7
Case 2: 3
```

**解释**：
- 对于 $k = 1$，所有数对的和都能被 $1$ 整除，满足 $a_i \le a_j$ 的不同值对有 $7$ 个
- 对于 $k = 2$，只有特定的数对满足条件，共有 $3$ 个

---

## 解题思路

### 关键观察

1. **模运算性质**：如果 $(a_i + a_j)$ 能被 $k$ 整除，那么：
   $$
   (a_i \mod k) + (a_j \mod k) \equiv 0 \pmod{k}
   $$
   即 $a_j \mod k = (k - (a_i \mod k)) \mod k$

2. **处理负数**：由于 $a_i$ 可能为负数，计算余数时需要使用：
   $$
   r = ((a_i \mod k) + k) \mod k
   $$

3. **值对唯一性**：题目要求统计不同的值对，因此需要去重处理

### 算法步骤

1. **统计频率**：使用 `map` 记录每个值出现的次数，用于处理相同值的配对情况

2. **去重处理**：对原数组排序并去重，得到所有不同的值

3. **按余数分组**：将去重后的值按照对 $k$ 的余数分组

4. **分类统计**：
   - **余数为 $0$ 的组**：组内元素可以互相配对
     - 相同值配对：需要该值出现次数 $\ge 2$
     - 不同值配对：所有不同的值对都满足条件
   - **余数为 $k/2$ 的组**（当 $k$ 为偶数时）：处理方式与余数 $0$ 相同
   - **其他互补余数对**：对于余数 $r$ 和 $k-r$，两组间的所有值对都满足条件

5. **避免重复计数**：通过控制循环范围 $r < (k+1)/2$ 来确保每对互补余数只被处理一次

### 时间复杂度

- 排序和去重：$O(n \log n)$
- 分组和统计：$O(n)$
- 总体复杂度：$O(n \log n)$，在 $n \le 10^5$ 时可行

### 空间复杂度

- $O(n)$ 用于存储分组信息

## 代码实现

```cpp
// Divisibility Testing
// UVa ID: 11087
// Verdict: Accepted
// Submission Date: 2025-11-05
// UVa Run Time: 0.140s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    for (int caseNum = 1; caseNum <= T; ++caseNum) {
        int n, k;
        cin >> n >> k;
        vector<int> a(n);
        map<int, int> freq;  // 统计每个值的出现次数
        for (int i = 0; i < n; ++i) {
            cin >> a[i];
            freq[a[i]]++;
        }
        // 排序并去重，得到不同的值
        sort(a.begin(), a.end());
        a.erase(unique(a.begin(), a.end()), a.end());
        // 按余数分组
        vector<vector<int>> groups(k);
        for (int val : a) {
            int r = ((val % k) + k) % k;  // 处理负数情况
            groups[r].push_back(val);
        }
        long long count = 0;
        // 处理余数为0的组
        if (!groups[0].empty()) {
            // 相同值配对：需要该值出现次数 >= 2
            for (int val : groups[0])
                if (freq[val] >= 2)
                    count++;  // (val, val) 算一次
            // 不同值之间的配对
            for (int i = 0; i < groups[0].size(); ++i)
                for (int j = i + 1; j < groups[0].size(); ++j)
                    count++;
        }
        // 处理k为偶数时的余数k/2组
        if (k % 2 == 0) {
            int r = k / 2;
            if (!groups[r].empty()) {
                // 相同值配对
                for (int val : groups[r])
                    if (freq[val] >= 2)
                        count++;  // (val, val) 算一次
                // 不同值之间的配对
                for (int i = 0; i < groups[r].size(); ++i)
                    for (int j = i + 1; j < groups[r].size(); ++j)
                        count++;
            }
        }
        // 处理其他互补余数对
        for (int r = 1; r < (k + 1) / 2; ++r) {
            int comp = k - r;
            if (r == comp) continue;  // 避免重复处理k/2
            // 两组间的所有值对都满足条件
            count += (long long)groups[r].size() * groups[comp].size();
        }
        cout << "Case " << caseNum << ": " << count << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于理解题目要求统计的是**不同的值对**而非索引对，以及利用模运算的性质将问题转化为按余数分组处理。通过分类讨论余数为 $0$、$k/2$（当 $k$ 为偶数时）和其他互补余数的情况，可以高效地统计出所有满足条件的数对。

算法的时间复杂度为 $O(n \log n)$，空间复杂度为 $O(n)$，在给定的约束条件下能够高效运行。
