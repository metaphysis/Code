[UVa 11091 How Many Knight Placing](https://blog.csdn.net/metaphysis/article/details/156148529)

## 题目描述

你有一个 $6 \times n$ 的棋盘（注意列数 $n$ 是变量）。 在每一列中必须恰好放置 $2$ 个骑士，因此总共需要放置 $2n$ 个骑士。 需要计算这些 $2n$ 个骑士的 **有效放置** 的数量。 如果一个放置中任意两个骑士可以互相攻击，则该放置无效。 骑士的攻击规则为：位于格子 $(x, y)$ 的骑士可以攻击位于 $(x \pm 2, y \pm 1)$ 和 $(x \pm 1, y \pm 2)$ 的骑士。

**输入格式**  
第一行包含一个整数 $T$ 表示测试用例的数量。 每个测试用例包含一个整数 $n$。

**输出格式**  
对每个测试用例输出一个整数，表示有效放置的数量模 $10007$ 的结果。

**约束条件**  
- $T \leq 15$
- $1 \leq n < 10^9$

**样例输入**  
```
4
1
10
100
1000
```

**样例输出**  
```
15
178
30
8141
```

## 题目分析

### 问题特点

1. **棋盘规格**： $6$ 行 $n$ 列， $n$ 可达 $10^9$ ，不能直接枚举。
2. **放置要求**： 每列必须恰好放 $2$ 个骑士。
3. **攻击规则**： 骑士的攻击范围为“日”字形，可能跨列攻击。
4. **数据范围**： $n$ 非常大，需要使用高效算法。

### 关键观察

由于棋盘只有 $6$ 行，我们可以用状态压缩表示一列的放置情况（哪些行有骑士）。 从 $6$ 行中选 $2$ 行放骑士，共有 $C(6,2) = 15$ 种单列状态。

骑士攻击范围涉及跨列：
- 与相邻列（列差 $1$ ）：需要行差 $2$ 才会攻击
- 与隔一列（列差 $2$ ）：需要行差 $1$ 才会攻击

因此，第 $k$ 列的放置不仅受第 $k-1$ 列影响，还受第 $k-2$ 列影响，这是一个 **二阶线性递推** 问题。

---

## 解题思路

### 1. 状态定义

设 $dp[k][s_1][s_2]$ 表示前 $k$ 列中，第 $k-1$ 列状态为 $s_1$ 、第 $k$ 列状态为 $s_2$ 的方案数。  
其中 $s_1, s_2$ 是单列状态（ $0$ 到 $14$ ，共 $15$ 种）。

为了简化，我们将状态对 $(s_1, s_2)$ 编码为一个整数：
$$
\texttt{idx} = s_1 \times 15 + s_2
$$
总状态数为 $15 \times 15 = 225$ 。

### 2. 状态转移

当我们要添加第 $k+1$ 列（状态为 $s_3$ ）时，需要检查：
1. $s_2$ 与 $s_3$ 是否攻击（列差 $1$ ，检查行差 $2$ ）
2. $s_1$ 与 $s_3$ 是否攻击（列差 $2$ ，检查行差 $1$ ）

如果都不攻击，则可以从状态 $(s_1, s_2)$ 转移到状态 $(s_2, s_3)$ 。

### 3. 矩阵表示

将状态转移表示为矩阵形式：
- 状态向量 $v_k$ ：长度为 $225$ ， $v_k[i]$ 表示前 $k$ 列以状态 $i$ 结束的方案数。
- 转移矩阵 $M$ ： $225 \times 225$ ， $M[j][i] = 1$ 当且仅当可以从状态 $i$ 转移到状态 $j$ 。

则有递推关系：
$$
v_{k+1} = M \times v_k
$$
特别地，对于 $n$ 列棋盘：
$$
v_n = M^{n-2} \times v_2
$$
其中 $v_2$ 是所有合法的两列状态（即 $s_1$ 与 $s_2$ 不攻击）。

### 4. 初始状态

- $n = 1$ ：答案为 $15$ （所有单列状态）。
- $n = 2$ ：答案为满足 $s_1$ 与 $s_2$ 不攻击的状态对数量，通过暴力枚举可得为 $69$ 。
- $n \ge 3$ ：使用矩阵快速幂计算 $M^{n-2}$ ，然后乘以初始向量 $v_2$ ，最后对所有状态求和。

### 5. 模运算

由于结果可能非常大，题目要求输出结果模 $10007$ ，在矩阵运算过程中始终保持模 $10007$ 。

### 6. 时间复杂度

- 矩阵大小： $225 \times 225$
- 矩阵乘法： $O(225^3) \approx 1.1 \times 10^7$ 次运算
- 矩阵快速幂： $O(\log n)$ 次矩阵乘法
- 对于 $n = 10^9$ ， $\log_2(10^9) \approx 30$ ，总运算量约 $3.3 \times 10^8$ ，在合理范围内。

## 代码实现

```cpp
// How Many Knight Placing
// UVa ID: 11091
// Verdict: Accepted
// Submission Date: 2025-12-22
// UVa Run Time: 0.050s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MOD = 10007;
const int NUM_STATES = 15;      // C(6,2)=15
const int TOTAL_STATES = 225;   // 15*15

int colStates[NUM_STATES];      // 所有单列状态
int M[TOTAL_STATES][TOTAL_STATES];  // 转移矩阵
int v2[TOTAL_STATES];           // 初始向量（n=2）

// 生成所有列状态
void generateColumnStates() {
    int idx = 0;
    for (int i = 0; i < (1 << 6); ++i)
        if (__builtin_popcount(i) == 2) colStates[idx++] = i;
}

// 检查攻击
bool statesAttack(int stateA, int colA, int stateB, int colB) {
    int dc = colB - colA;
    if (dc < 0) dc = -dc;
    for (int r1 = 0; r1 < 6; ++r1) {
        if (!(stateA >> r1 & 1)) continue;
        for (int r2 = 0; r2 < 6; ++r2) {
            if (!(stateB >> r2 & 1)) continue;
            int dr = abs(r1 - r2);
            if (dc == 1 && dr == 2) return true;
            if (dc == 2 && dr == 1) return true;
        }
    }
    return false;
}

// 初始化转移矩阵和初始向量
void initialize() {
    generateColumnStates();
    // 初始化转移矩阵为0
    memset(M, 0, sizeof(M));
    // 构建转移矩阵
    for (int pIdx = 0; pIdx < NUM_STATES; ++pIdx) {
        for (int cIdx = 0; cIdx < NUM_STATES; ++cIdx) {
            int fromIdx = pIdx * NUM_STATES + cIdx;
            for (int nIdx = 0; nIdx < NUM_STATES; ++nIdx) {
                int toIdx = cIdx * NUM_STATES + nIdx;
                if (statesAttack(colStates[cIdx], 1, colStates[nIdx], 2)) continue;
                if (statesAttack(colStates[pIdx], 0, colStates[nIdx], 2)) continue;
                M[toIdx][fromIdx] = 1;
            }
        }
    }
    // 构建初始向量v2
    memset(v2, 0, sizeof(v2));
    for (int i = 0; i < NUM_STATES; ++i) {
        for (int j = 0; j < NUM_STATES; ++j) {
            if (!statesAttack(colStates[i], 0, colStates[j], 1)) {
                v2[i * NUM_STATES + j] = 1;
            }
        }
    }
}

// 矩阵乘法: C = A * B
void matMul(int A[TOTAL_STATES][TOTAL_STATES], int B[TOTAL_STATES][TOTAL_STATES], int C[TOTAL_STATES][TOTAL_STATES]) {
    static int temp[TOTAL_STATES][TOTAL_STATES];
    memset(temp, 0, sizeof(temp));
    for (int i = 0; i < TOTAL_STATES; ++i) {
        for (int k = 0; k < TOTAL_STATES; ++k) {
            if (A[i][k] == 0) continue;
            for (int j = 0; j < TOTAL_STATES; ++j) {
                temp[i][j] = (temp[i][j] + A[i][k] * B[k][j]) % MOD;
            }
        }
    }
    memcpy(C, temp, sizeof(temp));
}

// 矩阵向量乘法: result = M * vec
void matVecMul(int mat[TOTAL_STATES][TOTAL_STATES], int vec[TOTAL_STATES], int result[TOTAL_STATES]) {
    memset(result, 0, TOTAL_STATES * sizeof(int));
    for (int i = 0; i < TOTAL_STATES; ++i) {
        if (vec[i] == 0) continue;
        for (int j = 0; j < TOTAL_STATES; ++j)
            result[j] = (result[j] + mat[j][i] * vec[i]) % MOD;
    }
}

// 矩阵快速幂: result = M^power
void matPow(int base[TOTAL_STATES][TOTAL_STATES], long long power, int result[TOTAL_STATES][TOTAL_STATES]) {
    // 初始化为单位矩阵
    memset(result, 0, sizeof(int) * TOTAL_STATES * TOTAL_STATES);
    for (int i = 0; i < TOTAL_STATES; ++i) result[i][i] = 1;
    static int temp[TOTAL_STATES][TOTAL_STATES];
    memcpy(temp, base, sizeof(temp));
    while (power > 0) {
        if (power & 1) matMul(result, temp, result);
        matMul(temp, temp, temp);
        power >>= 1;
    }
}

int main() {
    initialize();
    int T;
    scanf("%d", &T);
    while (T--) {
        long long n;
        scanf("%lld", &n);
        if (n == 1) {
            printf("%d\n", NUM_STATES % MOD);
            continue;
        }
        if (n == 2) {
            int sum = 0;
            for (int i = 0; i < TOTAL_STATES; ++i) sum = (sum + v2[i]) % MOD;
            printf("%d\n", sum);
            continue;
        }
        // n >= 3
        int MPow[TOTAL_STATES][TOTAL_STATES];
        matPow(M, n - 2, MPow);
        int result[TOTAL_STATES];
        matVecMul(MPow, v2, result);
        int ans = 0;
        for (int i = 0; i < TOTAL_STATES; ++i) ans = (ans + result[i]) % MOD;
        printf("%d\n", ans);
    }
    return 0;
}
```

## 算法总结

本题是一个典型的状态压缩动态规划结合矩阵快速幂的问题。 核心步骤包括：

1. **状态压缩**： 利用棋盘只有 $6$ 行的特点，将每列的放置状态压缩为 $15$ 种。
2. **状态扩展**： 由于骑士攻击跨两列，需要记录连续两列的状态，共 $225$ 种。
3. **矩阵建模**： 将状态转移关系编码为 $225 \times 225$ 的矩阵。
4. **快速幂加速**： 利用矩阵快速幂在 $O(\log n)$ 时间内计算 $M^{n-2}$ 。
5. **模运算处理**： 在计算过程中始终保持模 $10007$ 。

这种 **状态压缩动态规划 + 矩阵快速幂** 的方法适用于具有固定记忆长度的线性递推问题，是解决大 $n$ 计数问题的有效手段。
