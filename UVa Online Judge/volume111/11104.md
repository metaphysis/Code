## 题目描述

给定两个字符串 $a$ 和 $b$ ，如果它们可以通过各自删除不超过一半的字符后变得相同，则称它们为 **一阶姐妹** 。例如，字符串 "$\texttt{abcdef}$" 和 "$\texttt{axcyd}$" 是一阶姐妹，因为可以从第一个字符串中删除 $\texttt{b}$ 、 $\texttt{e}$ 、 $\texttt{f}$ （ $\frac{3}{6} \le \frac{1}{2}$ ） ，从第二个字符串中删除 $\texttt{x}$ 、 $\texttt{y}$ （ $\frac{2}{5} \le \frac{1}{2}$ ） ，得到相同的子序列 "$\texttt{acd}$" 。

进一步定义：两个字符串 $c$ 和 $d$ 是 $n+1$ 阶姐妹，如果存在一个字符串 $e$ ，使得 $e$ 是 $c$ 的一阶姐妹，并且 $e$ 是 $d$ 的 $n$ 阶姐妹。

给定两个字符串 $x$ 和 $y$ ，要求找出最小的 $n \ge 1$ ，使得 $x$ 是 $y$ 的 $n$ 阶姐妹。如果不存在这样的 $n$ ，则输出 "$\texttt{not related}$" 。

## 输入格式

输入包含多个测试用例。每个测试用例由两行组成，分别表示字符串 $x$ 和 $y$ 。每个字符串的长度在 $1$ 到 $100$ 之间，且只包含小写字母。最后一个测试用例之后有两行，每行只包含一个字符 '$\texttt{0}$' ，表示输入结束。

## 输出格式

对于每个测试用例，输出一行，包含最小的 $n$ 。如果 $x$ 和 $y$ 不是任何 $n$ 阶姐妹，则输出 "$\texttt{not related}$" 。

## 样例输入

```
a
b
abb
baa
abcdef
axcyd
0
0
```

## 样例输出

```
2
2
1
```

## 题目分析

### 核心定义理解

首先，我们需要准确理解题目中 "姐妹" 关系的定义：

1. **一阶姐妹** ：字符串 $a$ 和 $b$ 可以通过各自删除不超过一半的字符后变得相同。
   - 设 $|a|$ 表示字符串 $a$ 的长度。
   - 设 $L = LCS(a, b)$ 表示 $a$ 和 $b$ 的最长公共子序列的长度。
   - 要使得 $a$ 和 $b$ 删除不超过一半字符后相同，需要存在一个公共子序列 $c$ ，使得：
     - $c$ 的长度 $|c| \ge |a| - \lfloor \frac{|a|}{2} \rfloor = \lceil \frac{|a|}{2} \rceil$
     - $c$ 的长度 $|c| \ge |b| - \lfloor \frac{|b|}{2} \rfloor = \lceil \frac{|b|}{2} \rceil$
   - 由于 $L$ 是最大可能的公共子序列长度，因此 **$a$ 和 $b$ 是一阶姐妹当且仅当** ：
     $$
     L \ge \lceil \frac{|a|}{2} \rceil \quad \text{且} \quad L \ge \lceil \frac{|b|}{2} \rceil
     $$
     等价于：
     $$
     L \times 2 > |a| \quad \text{且} \quad L \times 2 > |b|
     $$
     （注意：由于 $L$ 和长度都是整数， $L > \frac{|a|}{2}$ 等价于 $L \times 2 > |a|$ ）

2. **$n$ 阶姐妹** ：这是一个递归定义。 $x$ 是 $y$ 的 $n$ 阶姐妹，意味着存在一个字符串链 $x = s_0, s_1, s_2, \ldots, s_n = y$ ，其中每一对相邻的字符串 $(s_i, s_{i+1})$ 都是一阶姐妹。 $n$ 就是这个链的长度。

因此，我们的目标是找到从 $x$ 到 $y$ 的最短 "姐妹链" 的长度。

### 关键观察

1. **自反性** ：每个字符串都是自己的一阶姐妹（删除 $0$ 个字符， $0 \le \frac{|s|}{2}$ ） 。
2. **对称性** ：如果 $a$ 是 $b$ 的一阶姐妹，那么 $b$ 也是 $a$ 的一阶姐妹。
3. **问题的图论模型** ：将每个字符串看作图中的一个结点，如果两个字符串是一阶姐妹，则在它们之间连一条边。那么问题就转化为：在图中找到从结点 $x$ 到结点 $y$ 的最短路径长度。

但是，字符串的可能数量是无穷的（因为可以任意构造中间字符串），我们不能显式地构建整个图。我们需要一种更聪明的方法来计算最短路径长度。

### 深入分析姐妹链的构造

考虑如何构造一个从 $x$ 到 $y$ 的姐妹链。设 $|x| \le |y|$ （如果不满足，交换两者即可）。设 $L = LCS(x, y)$ 。

**情况一** ：如果 $L \times 2 > |y|$ ，那么根据一阶姐妹的条件， $x$ 和 $y$ 已经是一阶姐妹，所以 $n = 1$ 。

**情况二** ：如果 $L \times 2 \le |y|$ ，那么 $x$ 和 $y$ 不是一阶姐妹。我们需要构造中间字符串。

构造中间字符串 $z_1$ 如下：
- $z_1$ 由两部分组成：任意 $L$ 个字符（这些字符可以任意选择，因为后续可以删除），然后拼接上完整的字符串 $x$ 。
- 那么 $LCS(x, z_1) \ge |x|$ （因为 $z_1$ 包含完整的 $x$ ） 。
- 如果 $|x| \times 2 > |z_1|$ ，那么 $x$ 和 $z_1$ 是一阶姐妹。
- 同时， $z_1$ 与 $y$ 的最长公共子序列长度至少为 $L + |x|$ （因为 $z_1$ 包含原来的 $L$ 个字符和 $x$ ，而 $x$ 与 $y$ 有 $L$ 的公共子序列） 。

现在，我们检查 $z_1$ 和 $y$ 是否为一阶姐妹。如果 $(L + |x|) \times 2 > |y|$ ，那么 $z_1$ 和 $y$ 是一阶姐妹，于是 $x$ 和 $y$ 是二阶姐妹（ $x \to z_1 \to y$ ） 。

如果不满足，我们继续构造 $z_2$ ：
- $z_2$ 由任意 $L$ 个字符加上两个 $x$ 组成。
- $LCS(z_1, z_2) \ge |x|$ （因为 $z_2$ 包含 $x$ ，而 $z_1$ 也包含 $x$ ） ，如果 $|x| \times 2 > |z_2|$ ，那么 $z_1$ 和 $z_2$ 是一阶姐妹。
- $z_2$ 与 $y$ 的 $LCS$ 至少为 $L + 2|x|$ 。

重复这个过程，直到构造出 $z_k$ ，使得 $(L + k \cdot |x|) \times 2 > |y|$ 。此时 $z_k$ 和 $y$ 是一阶姐妹，而 $x$ 到 $z_k$ 经过 $k$ 步（ $x \to z_1 \to z_2 \to \cdots \to z_k$ ） ， $z_k$ 到 $y$ 再经过 $1$ 步，所以总步数为 $k + 1$ 。

### 算法步骤总结

1. 读入字符串 $x$ 和 $y$ 。
2. 计算 $L = LCS(x, y)$ 。
3. 确保 $|x| \le |y|$ （如果不满足，交换两者的长度值，字符串内容不需要交换，因为我们只关心长度和 $LCS$ ） 。
4. 初始化答案 $cousin = 1$ 。
5. 如果 $L \times 2 > |y|$ ，输出 $1$ 。
6. 否则，进行迭代：
   - 每次迭代中，令 $L = L + |x|$ ， $|x| = |x| \times 2$ ， $cousin = cousin + 1$ 。
   - 检查是否满足 $L \times 2 > |y|$ ，如果满足，跳出循环。
7. 输出 $cousin$ 。

这个迭代过程模拟了不断将 $x$ 翻倍并添加到 $L$ 中，直到 $L$ 足够大（大于 $|y|/2$ ） ，从而使得最终构造的字符串与 $y$ 成为一阶姐妹。

### 算法正确性证明

我们需要证明：按照上述迭代过程得到的结果就是最小的 $n$ 。

- **充分性** ：上述构造方法确实给出了一个从 $x$ 到 $y$ 的姐妹链，长度为 $cousin$ 。
- **必要性** ：可以证明，任何从 $x$ 到 $y$ 的姐妹链，其长度至少为 $cousin$ 。因为每次沿着姐妹链移动，当前字符串与 $y$ 的 $LCS$ 最多增加当前字符串长度的一半（由于一阶姐妹的条件要求 $LCS$ 大于等于两个字符串长度的一半） 。而我们的迭代过程每次将 $L$ 增加 $|x|$ ，将 $|x|$ 翻倍，这正好是可能的最快增长方式。因此，我们的算法得到了最小的 $n$ 。

### 时间复杂度分析

- 计算 $LCS$ 需要 $O(|x| \times |y|)$ 时间，由于字符串长度最多为 $100$ ，所以最多 $100 \times 100 = 10000$ 次操作。
- 迭代过程最多进行 $O(\log |y|)$ 次，因为每次 $|x|$ 翻倍，很快会超过 $|y|$ 。
- 因此，每个测试用例的时间复杂度为 $O(|x| \times |y|)$ ，完全可以接受。

## 代码实现

```cpp
// Cousin
// UVa ID: 11104
// Verdict: Accepted
// Submission Date: 2026-01-22
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 计算最长公共子序列长度
int lcsLength(const string& a, const string& b) {
    int m = a.length(), n = b.length();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (a[i - 1] == b[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
            else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[m][n];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    while (true) {
        string x, y;
        cin >> x >> y;
        if (x == "0" && y == "0") break;
        int lcs = lcsLength(x, y);
        int cousin = 1;
        int lenx = x.length(), leny = y.length();
        if (lenx > leny) swap(lenx, leny);
        while (lcs + lcs < leny) {
            lcs += lenx, lenx <<= 1;
            cousin++;
        }
        cout << cousin << '\n';
    }
    return 0;
}
```

## 代码解释

1. **`lcsLength` 函数** ：使用动态规划计算两个字符串的最长公共子序列长度。创建一个二维数组 `dp` ，其中 `dp[i][j]` 表示 `a` 的前 `i` 个字符和 `b` 的前 `j` 个字符的 $LCS$ 长度。状态转移方程：
   - 如果 `a[i-1] == b[j-1]` ，则 `dp[i][j] = dp[i-1][j-1] + 1` 。
   - 否则， `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` 。

2. **主函数** ：
   - 使用 `ios::sync_with_stdio(false)` 和 `cin.tie(nullptr)` 加速输入输出。
   - 循环读入测试用例，直到遇到两个 "$\texttt{0}$" 。
   - 对于每个测试用例：
     - 计算 $LCS(x, y)$ 。
     - 初始化 `cousin = 1` 。
     - 确保 `lenx` 是较小的长度， `leny` 是较大的长度。
     - 循环条件 `lcs + lcs < leny` 对应 $L \times 2 < |y|$ ，即不满足一阶姐妹条件。
     - 循环体内： `lcs += lenx` 模拟将 $|x|$ 添加到 $L$ 中； `lenx <<= 1` 将 $|x|$ 翻倍； `cousin++` 增加姐妹阶数。
     - 当循环结束时， `cousin` 就是最小的 $n$ 。

## 总结

本题的关键在于理解姐妹关系的本质：两个字符串是一阶姐妹当且仅当它们的最长公共子序列长度大于等于各自长度的一半。通过构造中间字符串，可以逐步增加与目标字符串的 $LCS$ ，直到满足一阶姐妹条件。迭代过程模拟了这一构造，并且可以证明这是最优的构造方法，从而得到最小的 $n$ 。算法的时间复杂度为 $O(|x| \times |y|)$ ，空间复杂度为 $O(|x| \times |y|)$ （用于计算 $LCS$ ） ，完全在题目限制范围内。
