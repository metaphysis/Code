## 题目描述

巴比伦人热衷于一种特殊的轮盘赌游戏。轮盘上有六个标签：$-3, -2, -1, 1, 2, 3$。游戏规则如下：

- 游戏按轮次进行，每轮一个玩家参与
- 初始奖池金额为 $P_0$，赌注金额为 $B$（固定不变）
- 第 $t$ 轮玩家转动轮盘，根据球停的格子标签 $L$：
  - 如果 $L > 0$，玩家**输掉** $L \times B$ 金额（奖池增加）
  - 如果 $L < 0$，玩家**赢得** $|L| \times B$ 金额（奖池减少）
- 游戏过程中奖池不能为负，如果计算出的新奖池为负，则玩家只能赢得不导致负奖池的最大金额
- 如果某轮开始时奖池金额小于赌注 $B$，游戏立即结束

考古学家发现了一些泥板，每行包含三个数字：初始奖池 $P_0$、赌注 $B$、最终奖池 $P_f$。需要判断这些数据是否可能是一天的游戏结果，如果可能，求出该天**最少**的玩家数量。

## 输入格式

多个测试用例，每行三个非负整数 $P_0, B, P_f$。  
$P_0 > 0, B > 0$，所有输入数字小于 $10^8$。  
以 `0 0 0` 结束输入。

## 输出格式

对每个测试用例：
- 如果数据不可能，输出 `No accounting tablet`
- 否则输出最少玩家数（正整数）

## 题目分析

### 关键观察

1. **整除条件**：由于每轮变化量都是 $B$ 的整数倍，总变化量 $P_f - P_0$ 必须是 $B$ 的整数倍，否则不可能。

2. **目标值计算**：定义 $T = \frac{P_f - P_0}{B}$，表示需要用轮盘结果累加得到的目标值。

3. **轮盘结果范围**：每轮结果 $L \in \{-3, -2, -1, 1, 2, 3\}$。

### 分类讨论

#### 情况 1：$T = 0$
- 初始奖池等于最终奖池
- **最少玩家数为 $0$**（可能没有人玩游戏）

#### 情况 2：$T > 0$
- 奖池增加，玩家总体输钱
- 使用正标签 $(1, 2, 3)$
- 最少轮数 = $\lceil \frac{T}{3} \rceil$（尽量用 $3$）

#### 情况 3：$T < 0$
- 奖池减少，玩家总体赢钱  
- 使用负标签 $(-1, -2, -3)$
- 最少轮数 = $\lceil \frac{|T|}{3} \rceil$（尽量用 $-3$）

### 算法选择

使用**贪心算法**：
- 对于非零 $T$，尽量使用最大步长 $3$ 或 $-3$
- 计算 $\lceil \frac{|T|}{3} \rceil$ 的简洁方法：`(|T| + 2) / 3`

### 复杂度分析
- 每个测试用例 $O(1)$ 时间
- 空间复杂度 $O(1)$

## 解题思路详解

### 步骤 1：基础检查
首先检查 $(P_f - P_0) \mod B = 0$，如果不成立直接输出不可能。

### 步骤 2：计算目标值
$T = \frac{P_f - P_0}{B}$

### 步骤 3：分类处理
- $T = 0$：输出 $0$（无人参与）
- $T > 0$：输出 $\lceil \frac{T}{3} \rceil = \frac{T + 2}{3}$
- $T < 0$：输出 $\lceil \frac{|T|}{3} \rceil = \frac{|T| + 2}{3}$

### 为什么这样是最优的？
由于系统会自动调整赢钱金额来避免负奖池，我们不需要考虑中间过程的奖池约束，只需要纯粹用贪心选择最大步长即可得到最少轮数。

## 代码实现

```cpp
// Babylonian Roulette
// UVa ID: 11112
// Verdict: Accepted
// Submission Date: 2025-11-18
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long P0, B, Pf;
    while (cin >> P0 >> B >> Pf && (P0 || B || Pf)) {
        // 检查整除条件
        if ((Pf - P0) % B != 0) {
            cout << "No accounting tablet" << endl;
            continue;
        }
        long long T = (Pf - P0) / B;
        // 实际上可以合并到普通情况一起处理
        if (T == 0) {
            // 奖池无变化，可能无人参与
            cout << 0 << endl;
        } else {
            // 使用贪心：尽量用最大步长3或-3
            long long absT = abs(T);
            cout << (absT + 2) / 3 << endl;
        }
    }
    return 0;
}
```

## 样例验证

| `24 13 2` | `No accounting tablet` | $(2-24) \mod 13 \neq 0$ |
| `5100 700 200` | `3` | $T = -7$, $\lceil 7/3 \rceil = 3$ |
| `54 16 158` | `No accounting tablet` | $(158-54) \mod 16 \neq 0$ |
| `360 6 72` | `16` | $T = -48$, $\lceil 48/3 \rceil = 16$ |
| `25 10 5` | `1` | $T = -2$, $\lceil 2/3 \rceil = 1$ |
| `100 10 100` | `0` | 奖池无变化，无人参与 |

## 总结

本题的关键在于理解：
1. **整除条件**是必要前提
2. **贪心选择最大步长**可以得到最少轮数
3. **奖池约束由系统自动处理**，不影响最少轮数的计算

通过简单的数学分析和分类讨论，可以在 $O(1)$ 时间内解决每个测试用例。
