## 题目描述

$\texttt{Little Quilt}$ 是一种由 $\texttt{Ravi Sethi}$ 在《$\texttt{Programming}$ 语言》一书中引入的小型语言。题目要求实现该语言的一个受限版本的解释器。该语言通过 BNF 文法定义：

$$
\langle \mathrm{QUILT} \rangle \coloneqq \mathrm{A} \mid \mathrm{B} \mid \mathrm{turn}(\langle \mathrm{QUILT} \rangle) \mid \mathrm{sew}(\langle \mathrm{QUILT} \rangle, \langle \mathrm{QUILT} \rangle)
$$

其中 $\mathrm{A}$ 和 $\mathrm{B}$ 代表两种基本被子图案，每个基本被子对应一个 $2 \times 2$ 的字符矩阵。操作 $\mathrm{turn}()$ 表示顺时针旋转 $90$ 度， $\mathrm{sew}()$ 表示将两个被子水平拼接。

### 基本规则

1. **基本图案**：
   - $\mathrm{A}$ ：矩阵为 $\begin{bmatrix} / & / \\ / & + \end{bmatrix}$
   - $\mathrm{B}$ ：矩阵为 $\begin{bmatrix} - & - \\ - & - \end{bmatrix}$

2. **旋转操作** $\mathrm{turn}(x)$ ：将被子 $x$ 顺时针旋转 $90$ 度，旋转时字符按以下规则变换：
   - `/` 变为 `\`
   - `\` 变为 `/`
   - `+` 保持不变
   - `-` 变为 `|`
   - `|` 变为 `-`

3. **拼接操作** $\mathrm{sew}(x, y)$ ：将被子 $x$ 缝在被子 $y$ 的左侧。要求 $x$ 和 $y$ 必须具有相同的高度，否则会产生错误。

### 输入输出格式

- **输入**：包含多个 $\texttt{Little Quilt}$ 表达式的文本文件，每个表达式以分号 `;` 结尾。空格和换行符必须被忽略，表达式可以跨越多行。
- **输出**：对于每个表达式，输出其解释结果。每个被子前输出一行 `Quilt i:` （$i$ 从 $1$ 开始编号），如果表达式解释出错，则输出 `error` 。

## 题目分析

本题的核心是实现一个递归下降解析器来解释 $\texttt{Little Quilt}$ 语言。需要处理的主要问题包括：

1. **语法解析**：表达式是递归定义的，需要实现递归下降解析来构建语法树。
2. **数据表示**：每个被子是一个二维字符矩阵，高度和宽度可能变化。
3. **操作实现**：
   - 旋转操作：矩阵旋转 $90$ 度，同时字符按规则变换。
   - 拼接操作：水平拼接两个矩阵，检查高度是否一致。
4. **错误处理**：当拼接操作的两个被子高度不一致时，需要输出错误信息。

### 解题思路

#### 1. 数据结构设计

使用 `Quilt` 结构体来表示一个被子，包含：
- 一个 `vector<string>` 存储字符矩阵，每行一个字符串。
- 静态方法 `makeA()` 和 `makeB()` 返回基本图案。
- 成员方法：
  - `turn()`：实现顺时针旋转 $90$ 度，同时变换字符。
  - `sew(const Quilt& other, Quilt& result)`：拼接两个被子，通过返回值表示是否成功。
  - `toString()`：将被子转换为字符串输出格式。

#### 2. 语法解析器设计

设计 `Parser` 类来解析输入：
- 读取整个输入到字符串，忽略空格和换行符。
- 递归下降解析表达式：
  - 遇到 `A` 或 `B`：返回对应的基本被子。
  - 遇到 `turn(`：递归解析内部表达式，然后应用旋转。
  - 遇到 `sew(`：递归解析两个表达式，然后尝试拼接。
- 使用指针跟踪当前位置，跳过空白字符。
- 遇到分号 `;` 表示一个表达式结束。

#### 3. 旋转操作实现

旋转矩阵 $90$ 度的同时，需要处理字符变换：
- 原始位置 $(i, j)$ 旋转后到 $(j, h-1-i)$，其中 $h$ 是高度。
- 字符变换规则：
  ```
  / → \
  \ → /
  + → +（不变）
  - → |
  | → -
  ```

#### 4. 拼接操作实现

水平拼接两个矩阵：
- 检查两个被子的高度是否相等，不等则返回失败。
- 将两个矩阵的对应行连接起来。

#### 5. 错误处理

- 解析错误（如缺少括号、逗号等）：直接返回失败。
- 拼接高度不匹配： `sew` 方法返回 `false`。
- 遇到错误时输出 `error` 。

### 算法复杂度分析

- 时间复杂度：$O(n \cdot m)$，其中 $n$ 是表达式长度，$m$ 是最终被子的像素总数（每个字符处理一次）。
- 空间复杂度：$O(m)$，存储被子矩阵。

```cpp
// Little Quilt
// UVa ID: 11117

#include <bits/stdc++.h>
using namespace std;

struct Quilt {
    vector<string> grid;
    
    // 默认构造函数
    Quilt() = default;
    
    // 构造函数
    Quilt(const vector<string> &g) : grid(g) {}
    
    // 创建基本被子 A
    static Quilt makeA() {
        return Quilt({"//", "/+"});
    }
    
    // 创建基本被子 B
    static Quilt makeB() {
        return Quilt({"--", "--"});
    }
    
    // 顺时针旋转 90 度
    Quilt turn() const {
        int h = grid.size();
        int w = grid[0].size();
        vector<string> res(w, string(h, ' '));
        for (int i = 0; i < h; i++) {
            for (int j = 0; j < w; j++) {
                char c = grid[i][j];
                if (c == '/') c = '\\';
                else if (c == '\\') c = '/';
                else if (c == '-') c = '|';
                else if (c == '|') c = '-';
                // + 保持不变
                res[j][h-1-i] = c;
            }
        }
        return Quilt(res);
    }
    
    // 拼接两个被子，将当前被子缝在左侧
    bool sew(const Quilt &other, Quilt &result) const {
        if (grid.size() != other.grid.size()) return false;
        int h = grid.size();
        vector<string> res(h);
        for (int i = 0; i < h; i++)
            res[i] = grid[i] + other.grid[i];
        result = Quilt(res);
        return true;
    }
    
    // 转换为字符串输出
    string toString() const {
        string s;
        for (size_t i = 0; i < grid.size(); i++) {
            if (i > 0) s += '\n';
            s += grid[i];
        }
        return s;
    }
};

class Parser {
    string input;
    size_t pos;
    int quiltId;
    
    // 跳过空白字符
    void skipSpaces() {
        while (pos < input.size() && isspace(input[pos])) pos++;
    }
    
    // 解析表达式
    bool parseExpr(Quilt &result) {
        skipSpaces();
        if (pos >= input.size()) return false;
        
        // 处理基本图案 A 或 B
        if (input[pos] == 'A' || input[pos] == 'B') {
            result = input[pos] == 'A' ? Quilt::makeA() : Quilt::makeB();
            pos++;
            return true;
        }
        
        // 读取函数名
        string func;
        while (pos < input.size() && isalpha(input[pos])) func += input[pos++];
        
        skipSpaces();
        if (pos >= input.size() || input[pos] != '(') return false;
        pos++;
        
        // 处理 turn 操作
        if (func == "turn") {
            Quilt q;
            if (!parseExpr(q)) return false;
            skipSpaces();
            if (pos >= input.size() || input[pos] != ')') return false;
            pos++;
            result = q.turn();
            return true;
        } 
        // 处理 sew 操作
        else if (func == "sew") {
            Quilt left, right;
            if (!parseExpr(left)) return false;
            skipSpaces();
            if (pos >= input.size() || input[pos] != ',') return false;
            pos++;
            if (!parseExpr(right)) return false;
            skipSpaces();
            if (pos >= input.size() || input[pos] != ')') return false;
            pos++;
            return left.sew(right, result);
        }
        
        return false;
    }
    
public:
    Parser(const string &s) : input(s), pos(0), quiltId(1) {}
    
    // 解析所有表达式
    void parseAll() {
        while (pos < input.size()) {
            Quilt q;
            if (parseExpr(q)) {
                cout << "Quilt " << quiltId++ << ":" << endl;
                cout << q.toString() << endl;
            } else {
                cout << "Quilt " << quiltId++ << ":" << endl;
                cout << "error" << endl;
            }
            
            // 跳过表达式后的分号
            skipSpaces();
            if (pos < input.size() && input[pos] == ';') {
                pos++;
                skipSpaces();
            } else break;
        }
    }
};

int main() {
    // 读取整个输入
    string input, line;
    while (getline(cin, line)) input += line + " ";
    Parser parser(input);
    parser.parseAll();
    return 0;
}
```
