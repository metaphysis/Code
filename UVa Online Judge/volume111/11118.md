## 题目描述

有 $n$ 个囚犯（$n$ 为偶数）和 $n$ 个黑盒子，每个盒子中随机放有一个囚犯的名字。游戏规则如下：

- 囚犯事先可以商量策略，但不知道盒子的排列。
- 狱警随机排列盒子，然后依次叫囚犯进入房间 $A$。
- 每个囚犯最多可以打开 $n/2$ 个盒子，如果找到自己的名字则进入房间 $C$（无法与外界通信），否则本轮立即失败。
- 如果所有囚犯都找到了自己的名字，本轮获胜，全体释放。
- 如果失败，第二天重新开始新的一轮。

求：  
1. 最优策略下一轮游戏获胜的概率。  
2. 获胜所需轮数的期望值。

## 题目分析

这是一个经典的“囚犯与盒子”谜题（$\texttt{100 prisoners problem}$）。若囚犯随机选择盒子，获胜概率为 $(1/2)^n$，几乎为 $0$。但存在一个巧妙的策略，将获胜概率提高到约 $1 - \ln 2 \approx 0.30685$。

### 最优策略描述

囚犯事先将盒子从 $1$ 到 $n$ 编号，每个人也有一个唯一的编号（例如从 $1$ 到 $n$）。  
当囚犯 $i$ 进入房间时，他首先打开编号为 $i$ 的盒子，查看里面的名字（假设名字对应编号 $j$）。然后他打开编号为 $j$ 的盒子，以此类推，直到找到自己的名字或打开 $n/2$ 个盒子为止。

这相当于：将盒子视为一个映射 $f: \{1,\dots,n\} \to \{1,\dots,n\}$，其中 $f(k)$ 表示第 $k$ 个盒子中放的是哪个囚犯的名字。由于名字互不相同，这个映射是 $\texttt{置换}$（$\texttt{permutation}$）。每个囚犯 $i$ 从 $i$ 出发，沿着置换的边 $i \to f(i) \to f(f(i)) \to \cdots$ 行走，寻找自己。

### 获胜条件

囚犯 $i$ 能成功找到自己的名字，当且仅当 $i$ 所在的循环长度 $\le n/2$。因为沿着循环走，最多走完整个循环就会回到 $i$，而 $i$ 允许走 $n/2$ 步，所以只要循环长度不超过 $n/2$，就能找到。

因此，**所有囚犯都成功** $\iff$ **置换中不存在长度大于 $n/2$ 的循环**。

### 失败概率计算

随机置换中，包含一个长度恰好为 $k$ 的循环的概率是多少？  
长度为 $k$ 的循环有 $(k-1)!$ 种内部排列，选择 $k$ 个元素有 $\binom{n}{k}$ 种方式，剩余 $n-k$ 个元素可任意排列（$(n-k)!$ 种）。所以包含一个特定长度为 $k$ 的循环的排列数为：
$$
\binom{n}{k} \cdot (k-1)! \cdot (n-k)! = \frac{n!}{k}
$$
因此，随机排列中**存在**一个长度为 $k$ 的循环的概率为 $1/k$（注意，这里“存在”指的是某个特定循环？实际上要小心，不同 $k$ 的循环可能同时存在，但长度 > n/2 的循环至多只有一个，因为两个这样的循环长度和 > n，不可能）。所以长度为 $k > n/2$ 的循环存在的概率恰好是 $1/k$。

于是：
$$
P_{\text{lose}} = \sum_{k = n/2 + 1}^{n} \frac{1}{k}
$$
获胜概率：
$$
P_{\text{win}} = 1 - \sum_{k = n/2 + 1}^{n} \frac{1}{k}
$$

### 期望轮数

每一轮是独立的，获胜概率为 $P_{\text{win}}$，因此获胜所需轮数服从几何分布，期望为：
$$
E = \frac{1}{P_{\text{win}}}
$$

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        int n;
        scanf("%d", &n);
        double loseProb = 0.0;
        // 累加长度大于 n/2 的循环的概率
        for (int k = n / 2 + 1; k <= n; ++k)
            loseProb += 1.0 / k;
        double winProb = 1.0 - loseProb;
        double expectedRounds = 1.0 / winProb;
        // 输出，精度保证 8 位小数
        printf("Case #%d: %.8f %.8f\n", caseNo, winProb, expectedRounds);
    }
    return 0;
}
