[UVa 11123 Counting Trapezoid](https://blog.csdn.net/metaphysis/article/details/161544741)

## 题目描述

给定平面上的 $N$ 个点（$N \le 200$），问这些点能够构成多少个 **梯形**。梯形的定义如下：

1. 是四边形（四条边）；
2. 恰好有一组对边平行，另一组对边不平行；
3. 面积严格为正。

注意：四点必须互异且无三点共线，面积大于 $0$ 自然保证不是退化四边形。

## 输入格式

多组数据，每组数据第一行一个整数 $N$，接下来 $N$ 行每行两个整数 $x_i, y_i$。输入以一行一个 $0$ 结束。

## 输出格式

每组数据输出 `Case i: ans`，其中 `ans` 为梯形个数。

## 样例

输入：
```
4
0 0
1 0
0 1
1 1
4
0 0
1 1
2 0
0 1
0
```

输出：
```
Case 1: 0
Case 2: 1
```

## 题目分析

本题 $N \le 200$，最直接的想法是枚举所有四点组合，检查是否构成梯形。四点组合数为 $\binom{200}{4} \approx 6.5 \times 10^7$，再对每个组合进行一系列向量判断，在时间上不可接受（约 $10^8$ 到 $10^9$ 量级），必须采用更高效的计数方法。

### 梯形的本质

梯形只有一组对边平行。因此，如果从“平行对边”的角度出发，我们可以：

- 先计数 **至少有一组对边平行** 的四边形（包括平行四边形）；
- 再减去 **平行四边形**（因为平行四边形有两组对边平行，不符合梯形定义）。

这样，问题转化为两个子问题：

1. 计数至少有一组对边平行的四边形数量；
2. 计数平行四边形的数量。

### 关键优化

由于 $N$ 不大，我们可以从 **枚举所有点对** 开始，因为梯形的平行边一定是一个点对，另一个点对在另一条平行线上。

- 总共点对数为 $\binom{N}{2} \approx 2 \times 10^4$，完全可枚举。
- 每个点对有方向（斜率）和所在直线（用标准形式表示）。

## 解题思路

### 第一步：计数至少有一组对边平行的四边形

将点对按 **方向（斜率）** 分组。对于某个方向 $d$，设该方向上有 $m$ 条不同的直线，第 $i$ 条直线上有 $k_i$ 个点。

从该方向中任选两条不同的直线 $p$ 和 $q$，再从直线 $p$ 上任选 2 个点，从直线 $q$ 上任选 2 个点，这 4 个点构成一个四边形，且以 $d$ 方向为平行对边。

这样的四边形数量为：

$$
\sum_{1 \le p < q \le m} \binom{k_p}{2} \cdot \binom{k_q}{2}
$$

对所有方向求和，得到 **至少有一组对边平行的四边形总数**，记作 $S_1$。

**注意**：每个平行四边形有两组平行边，因此会在两个不同的方向下各被计数一次，即平行四边形在 $S_1$ 中被重复计数了 $2$ 次。

### 第二步：计数平行四边形

平行四边形除了两组对边平行外，还满足 **对边相等**。因此，我们可以枚举所有线段，按 `(方向, 长度)` 进行分组。

对于某个方向 $d$ 和长度 $l$，设该组有 $t$ 条线段，从这 $t$ 条线段中任选两条，如果它们不共线且四点互异，则这 $4$ 个点构成一个平行四边形。

这样的平行四边形数量为：

$$
\sum \binom{t}{2}
$$

但注意，一个平行四边形有两组对边，每一组对边具有相同的 `(方向, 长度)`，因此每个平行四边形会在上述统计中被 **两次** 选到（一次作为长边对，一次作为短边对）。记平行四边形总数为 $S_2$。

### 第三步：计算梯形数

由于每个平行四边形在 $S_1$ 中被计数 2 次，在 $S_2$ 中也被计数 $2$ 次，所以：

$$
\text{梯形数} = S_1 - S_2
$$

无需再除以 $2$，因为重复次数正好抵消。

### 算法复杂度

- 点对枚举：$O(N^2)$。
- 方向分组：使用 `map`，总复杂度 $O(N^2 \log N)$。
- 线段分组：同样 $O(N^2 \log N)$。
- 总体可接受。

## 代码实现

```cpp
// Counting Trapezoid

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

pair<int, int> normDir(int dx, int dy) {
    if (dx == 0 && dy == 0) return {0, 0};
    int g = __gcd(abs(dx), abs(dy));
    dx /= g; dy /= g;
    if (dx < 0 || (dx == 0 && dy < 0)) { dx = -dx; dy = -dy; }
    return {dx, dy};
}

struct Line {
    ll a, b, c;
    Line(ll a_, ll b_, ll c_) : a(a_), b(b_), c(c_) {
        ll g = __gcd(__gcd(abs(a), abs(b)), abs(c));
        if (g) { a /= g; b /= g; c /= g; }
        if (a < 0 || (a == 0 && b < 0)) { a = -a; b = -b; c = -c; }
    }
    bool operator<(const Line& o) const {
        if (a != o.a) return a < o.a;
        if (b != o.b) return b < o.b;
        return c < o.c;
    }
};

struct Segment {
    int i, j;
    ll len2;
    pair<int, int> dir;
    Segment(int i_, int j_, ll len2_, pair<int, int> dir_)
        : i(i_), j(j_), len2(len2_), dir(dir_) {}
    bool operator<(const Segment& o) const {
        if (dir != o.dir) return dir < o.dir;
        return len2 < o.len2;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, caseNo = 0;
    while (cin >> n, n) {
        vector<pair<ll, ll>> pts(n);
        for (int i = 0; i < n; ++i)
            cin >> pts[i].first >> pts[i].second;

        sort(pts.begin(), pts.end());
        pts.erase(unique(pts.begin(), pts.end()), pts.end());
        n = pts.size();

        if (n < 4) {
            cout << "Case " << ++caseNo << ": 0\n";
            continue;
        }

        // Step 1: count all quads with at least one pair of parallel sides
        map<pair<int, int>, map<Line, set<int>>> dirLines;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j) {
                ll dx = pts[j].first - pts[i].first;
                ll dy = pts[j].second - pts[i].second;
                auto dir = normDir(dx, dy);
                ll a = dy, b = -dx;
                ll c = a * pts[i].first + b * pts[i].second;
                Line line(a, b, c);
                dirLines[dir][line].insert(i);
                dirLines[dir][line].insert(j);
            }

        ll totalParallel = 0;
        for (auto& de : dirLines) {
            vector<int> cnts;
            for (auto& li : de.second)
                cnts.push_back(li.second.size());
            int m = cnts.size();
            for (int i = 0; i < m; ++i)
                for (int j = i + 1; j < m; ++j)
                    totalParallel += (ll)cnts[i] * (cnts[i] - 1) / 2 * cnts[j] * (cnts[j] - 1) / 2;
        }

        // Step 2: count parallelograms via same direction & same length
        vector<Segment> segs;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j) {
                ll dx = pts[j].first - pts[i].first;
                ll dy = pts[j].second - pts[i].second;
                ll len2 = dx * dx + dy * dy;
                auto dir = normDir(dx, dy);
                segs.emplace_back(i, j, len2, dir);
            }

        sort(segs.begin(), segs.end());

        ll totalPara = 0;
        int sz = segs.size();
        for (int i = 0; i < sz; ++i) {
            int j = i;
            while (j < sz && segs[j].dir == segs[i].dir && segs[j].len2 == segs[i].len2)
                ++j;
            int cnt = j - i;
            if (cnt >= 2) {
                for (int p = i; p < j; ++p)
                    for (int q = p + 1; q < j; ++q) {
                        int a = segs[p].i, b = segs[p].j;
                        int c = segs[q].i, d = segs[q].j;
                        set<int> quad = {a, b, c, d};
                        if (quad.size() != 4) continue;
                        ll area = (pts[b].first - pts[a].first) * (pts[c].second - pts[a].second)
                                - (pts[b].second - pts[a].second) * (pts[c].first - pts[a].first);
                        if (area != 0) ++totalPara;
                    }
            }
            i = j - 1;
        }

        // Each parallelogram is counted twice in totalParallel and twice in totalPara
        cout << "Case " << ++caseNo << ": " << totalParallel - totalPara << "\n";
    }

    return 0;
}
```

## 总结

本题的核心是利用 **平行对边** 作为计数切入点，将问题分解为 “至少一对平行边的四边形” 减去 “平行四边形”。通过枚举点对并利用 `map` 对直线、方向、长度进行分组，可以在 $O(N^2 \log N)$ 的复杂度内完成计数。这种思路不仅适用于梯形计数，也适用于其他需要统计几何构型的问题。
