## 题目描述

$\texttt{Colin}$ 喜欢玩角色扮演游戏，这类游戏通常需要各种不同面数的骰子。不幸的是，他忘记带骰子袋，只有一个装满硬币的罐子。他需要通过硬币的正反面来模拟骰子的投掷结果。

### 输入格式
- 多组测试数据，每组包含：
  - 骰子描述：格式为 `xDy`，表示投掷 $x$ 个 $y$ 面的骰子
  - 硬币序列：一行由 `H`（正面）和 `T`（反面）组成的字符串，无空格
- 最后一组为 `0D0`，表示输入结束

### 输出格式
- 对于每组数据，输出模拟骰子的点数之和
- 如果硬币不足，输出 $-1$

## 题目分析

### 核心问题
我们需要用硬币序列来模拟投掷指定面数的骰子。关键在于：
1. 确定每个骰子需要的硬币数量
2. 将硬币序列转换为骰子点数
3. 处理无效组合的情况

### 关键洞察
- 对于 $s$ 面的骰子，需要 $k$ 个硬币，其中 $k$ 是满足 $2^k \geq s$ 的最小整数
- 每 $k$ 个硬币组成一个二进制数（$\texttt{H=0, T=1}$）
- 如果该数值小于 $s$，则骰子点数为 `数值 + 1`
- 如果数值大于等于 $s$，则跳过这 $k$ 个硬币，继续处理后面的硬币

### 算法思路
1. **解析输入**：读取骰子数量和面数
2. **计算所需硬币数**：对于 $s$ 面骰子，计算最小的 $k$ 使得 $2^k \geq s$
3. **处理硬币序列**：
   - 每次取 $k$ 个硬币
   - 转换为二进制数值
   - 如果数值有效（$< s$），记录点数并移动 $k$ 位
   - 如果无效，跳过 $k$ 个硬币继续尝试
4. **检查硬币是否充足**：如果在处理过程中硬币用完，返回 $-1$

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <cmath>

using namespace std;

// 计算模拟一个 s 面骰子需要的最少硬币数
int coinsNeeded(int sides) {
    int k = 0;
    while ((1 << k) < sides) {
        k++;
    }
    return k;
}

// 将硬币序列（H/T）转换为二进制数值（H=0, T=1）
int coinToValue(const string& coins, int start, int length) {
    int val = 0;
    for (int i = 0; i < length; i++) {
        val = (val << 1) | (coins[start + i] == 'T' ? 1 : 0);
    }
    return val;
}

// 模拟一次掷骰子
int simulateDie(const string& coins, int sides, int& index) {
    int k = coinsNeeded(sides);
    int n = coins.length();
    
    while (index + k <= n) {
        int val = coinToValue(coins, index, k);
        if (val < sides) {
            index += k;
            return val + 1;
        }
        // 跳过整个k个硬币，而不是只跳1个
        index += k;
    }
    return -1; // 硬币不够
}

int main() {
    string line;
    while (getline(cin, line)) {
        if (line == "0D0") break;
        
        // 解析骰子数量和面数
        int dPos = line.find('D');
        int numDice = stoi(line.substr(0, dPos));
        int sides = stoi(line.substr(dPos + 1));
        
        // 读取硬币序列
        getline(cin, line);
        
        int index = 0;
        int total = 0;
        bool valid = true;
        
        for (int i = 0; i < numDice; i++) {
            int result = simulateDie(line, sides, index);
            if (result == -1) {
                valid = false;
                break;
            }
            total += result;
        }
        
        if (valid) {
            cout << total << endl;
        } else {
            cout << -1 << endl;
        }
    }
    
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n \times k)$，其中 $n$ 是硬币序列长度，$k$ 是单个骰子所需的最大硬币数
- **空间复杂度**：$O(1)$，只使用了常数级别的额外空间

## 总结

本题的关键在于理解如何用最少的硬币来模拟骰子投掷，以及如何处理无效的硬币组合。通过将硬币序列视为二进制数，并采用"跳过整个 $k$ 个硬币"的策略，我们能够正确模拟骰子的随机性。这种处理方法既高效又符合题目的要求。
