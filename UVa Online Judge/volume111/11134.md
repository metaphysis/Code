## 题目分析

### 问题描述

我们需要在一个 $n \times n$ 的棋盘上放置 $n$ 个车（$\texttt{rook}$），每个车 $i$ 只能被放置在一个特定的矩形区域内，该区域由左上角 $(x_i, y_i)$ 和右下角 $(x_{ri}, y_{ri})$ 定义。此外，还需要满足以下条件：

- 任意两个车不能互相攻击，即不能在同一行或同一列。
- 需要输出每个车的具体位置，如果无法满足条件则输出 $\texttt{IMPOSSIBLE}$。

### 关键观察

这个问题可以**分解为两个独立的一维问题**：

$1$. **行分配问题**：为每个车分配一个唯一的行号，且该行号必须在区间 $[x_i, x_{ri}]$ 内。
$2$. **列分配问题**：为每个车分配一个唯一的列号，且该列号必须在区间 $[y_i, y_{ri}]$ 内。

如果这两个一维问题都能解决，那么将它们组合起来就得到了二维问题的解。

### 贪心策略

对于每个一维问题（行或列），我们使用经典的**区间分配贪心算法**：

$1$. 将所有区间按照**右端点升序**排序，右端点相同时按左端点升序排序。
$2$. 从 $1$ 到 $n$ 依次考虑每个位置，对于每个位置，选择**包含该位置且右端点最小且尚未分配**的区间。
$3$. 如果某个区间无法分配任何位置，则问题无解。

**贪心正确性证明**：按右端点排序后，优先满足右端点较小的区间，可以避免占用后面更紧迫区间所需的位置，从而最大化分配成功率。

### 算法步骤

$1$. 读取输入数据，包括棋盘大小 $n$ 和每个车的矩形区域。
$2$. 分别提取行区间和列区间。
$3$. 对行区间和列区间分别执行贪心分配算法。
$4$. 如果两者都分配成功，按输入顺序输出每个车的 $(行, 列)$ 位置；否则输出 $\texttt{IMPOSSIBLE}$。

### 复杂度分析

- 排序：$O(n \log n)$
- 分配：$O(n^2)$（简单实现）或可优化到 $O(n \log n)$
- 对于 $n \leq 5000$，该复杂度是可接受的。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>

using namespace std;

// 区间结构体：l左边界，r右边界，id在输入中的序号
struct Interval {
    int l, r, id;
    // 按右端点升序排序，右端点相同时按左端点升序
    bool operator<(const Interval& other) const {
        return r < other.r || (r == other.r && l < other.l);
    }
};

// 贪心分配函数：为每个区间分配一个唯一的位置
bool assign(vector<Interval>& intervals, int n, int result[]) {
    sort(intervals.begin(), intervals.end());  // 按右端点排序
    bool used[5005] = {false};  // 标记位置是否已被使用
    
    for (const auto& iv : intervals) {
        bool found = false;
        // 从左边界开始找到第一个可用的位置
        for (int pos = iv.l; pos <= iv.r; pos++) {
            if (!used[pos]) {
                used[pos] = true;      // 标记为已使用
                result[iv.id] = pos;   // 记录分配结果
                found = true;
                break;
            }
        }
        if (!found) return false;  // 如果找不到可用位置，分配失败
    }
    return true;
}

int main() {
    int n;
    while (cin >> n && n) {
        vector<Interval> rows(n), cols(n);
        
        // 读取输入数据
        for (int i = 0; i < n; i++) {
            int x1, y1, x2, y2;
            cin >> x1 >> y1 >> x2 >> y2;
            // 分别存储行区间和列区间
            rows[i] = {x1, x2, i};
            cols[i] = {y1, y2, i};
        }
        
        int row_pos[5005], col_pos[5005];  // 存储分配结果
        
        // 分别对行和列进行分配
        if (assign(rows, n, row_pos) && assign(cols, n, col_pos)) {
            // 输出每个车的最终位置
            for (int i = 0; i < n; i++) {
                cout << row_pos[i] << " " << col_pos[i] << "\n";
            }
        } else {
            cout << "IMPOSSIBLE\n";
        }
    }
    return 0;
}
```

### 代码说明

- **`Interval` 结构体**：存储每个车的行或列区间信息，重载 `<` 运算符用于排序。
- **`assign` 函数**：实现贪心分配算法，为每个区间分配唯一位置。
- **主函数**：读取输入，分别处理行和列的分配，最后输出结果。

该解法通过将二维问题分解为两个独立的一维问题，并运用贪心算法高效解决了原本复杂的位置约束问题。
