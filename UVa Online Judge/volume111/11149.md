## 题目描述

给定一个 $n \times n$ 的矩阵 $A$ 和一个整数 $k$，要求计算矩阵的和：

$$S = A + A^2 + A^3 + \dots + A^k$$

其中矩阵乘法采用标准的矩阵乘法运算。由于结果可能非常大，只需要输出每个元素的**最后一位**（即对 $10$ 取模的结果）。

**输入限制：**
- 测试用例不超过 $20$ 个
- $n \leq 40$
- $k \leq 1000000$
- 矩阵元素为非负整数

## 题目分析

### 直接计算法的局限性

最直观的方法是直接计算每个 $A^i$ 然后累加。矩阵乘法的时间复杂度为 $O(n^3)$，需要计算 $k$ 次幂并求和，总时间复杂度为 $O(kn^3)$。

当 $k$ 达到 $10^6$，$n$ 达到 $40$ 时：
- $kn^3 = 10^6 \times 40^3 = 10^6 \times 64000 = 6.4 \times 10^{10}$
- 这个计算量在时间限制内是无法完成的

### 分治优化策略

我们可以使用分治的方法来优化计算。定义：
- $B(k) = A^k$（矩阵的 $k$ 次幂）
- $F(k) = A + A^2 + \dots + A^k$（要求的矩阵和）

通过分治思想，我们可以推导出递归关系：

1. **基本情况**：当 $k = 1$ 时
   - $B(1) = A$
   - $F(1) = A$

2. **偶数情况**：当 $k$ 是偶数时，设 $m = k/2$
   - $B(k) = B(m) \times B(m)$
   - $F(k) = F(m) + B(m) \times F(m)$

3. **奇数情况**：当 $k$ 是奇数时，设 $m = \lfloor k/2 \rfloor$
   - $B(k) = B(m) \times B(m) \times A$
   - $F(k) = F(m) + B(m) \times F(m) + B(k)$

### 复杂度分析

使用这种分治方法：
- 递归深度为 $O(\log k)$
- 每层需要进行 $O(1)$ 次矩阵乘法
- 每次矩阵乘法的时间复杂度为 $O(n^3)$
- 总时间复杂度为 $O(n^3 \log k)$

对于 $n = 40$，$k = 10^6$：
- $n^3 \log k = 64000 \times \log_2(10^6) \approx 64000 \times 20 = 1.28 \times 10^6$
- 这个计算量是完全可行的

### 模 $10$ 处理

由于只需要最后一位，所有矩阵运算都在模 $10$ 下进行，这样可以避免大数运算，同时保证结果的正确性。

```cpp
// Power of Matrix

#include <iostream>
#include <vector>
using namespace std;

typedef vector<vector<int>> Matrix;
int n;

// 矩阵乘法，结果对10取模
Matrix multiply(const Matrix &a, const Matrix &b) {
    Matrix res(n, vector<int>(n, 0));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            for (int k = 0; k < n; k++) {
                res[i][j] = (res[i][j] + a[i][k] * b[k][j]) % 10;
            }
        }
    }
    return res;
}

// 矩阵加法，结果对10取模
Matrix add(const Matrix &a, const Matrix &b) {
    Matrix res(n, vector<int>(n, 0));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            res[i][j] = (a[i][j] + b[i][j]) % 10;
        }
    }
    return res;
}

// 分治求解：返回 {B(k), F(k)}，其中B(k)=A^k, F(k)=A+A^2+...+A^k
pair<Matrix, Matrix> solve(const Matrix &A, int k) {
    // 基本情况：k=1
    if (k == 1) {
        return {A, A};
    }
    
    if (k % 2 == 0) {
        // 偶数情况：k = 2m
        auto [Bm, Fm] = solve(A, k / 2);  // 递归求解子问题
        Matrix Bk = multiply(Bm, Bm);     // B(k) = B(m) * B(m)
        Matrix Fk = add(Fm, multiply(Bm, Fm));  // F(k) = F(m) + B(m) * F(m)
        return {Bk, Fk};
    } else {
        // 奇数情况：k = 2m + 1
        auto [Bm, Fm] = solve(A, k / 2);  // 递归求解子问题
        Matrix Bk = multiply(multiply(Bm, Bm), A);  // B(k) = B(m) * B(m) * A
        Matrix Fk = add(add(Fm, multiply(Bm, Fm)), Bk);  // F(k) = F(m) + B(m) * F(m) + B(k)
        return {Bk, Fk};
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    while (true) {
        int k;
        cin >> n >> k;
        if (n == 0) break;
        
        Matrix A(n, vector<int>(n));
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                cin >> A[i][j];
                A[i][j] %= 10;  // 输入时直接取模
            }
        }
        
        // 调用分治算法求解
        auto [_, res] = solve(A, k);
        
        // 输出结果
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                cout << res[i][j];
                if (j < n - 1) cout << " ";
            }
            cout << "\n";
        }
        cout << "\n";
    }
    
    return 0;
}
```

## 关键点总结

1. **分治思想**：将大问题分解为小问题，通过递归求解并合并结果
2. **数学推导**：正确推导出 $B(k)$ 和 $F(k)$ 的递归关系是算法正确性的关键
3. **模运算**：所有运算在模 $10$ 下进行，避免大数问题
4. **时间复杂度**：$O(n^3 \log k)$，能够处理题目给出的最大数据规模

这种分治方法不仅适用于矩阵幂和问题，还可以推广到其他类似的求和问题，是算法竞赛中常用的优化技巧。
