## 题目描述

你正在度假，作为一个文化爱好者，决定参观一些博物馆。你有一本《博物馆指南书》，其中包含了所有博物馆的详细信息。你为每个博物馆分配了一个“乐趣指数”，范围从 $1$ 到 $9$，表示该博物馆的有趣程度。

然而，你面临两个限制：
1. **预算有限**：你只能花费 $d$ 美元（不超过 $100$）。
2. **时间有限**：你的行程总时间不能超过 $t$ 分钟（不超过 $600$）。

你需要规划一条从家出发并最终回到家的路线，使得：
- 参观的博物馆总乐趣指数最大。
- 每个博物馆最多参观一次（但可以经过多次）。
- 每个博物馆参观时间至少为 $15$ 分钟（用于欣赏展品）。
- 交通时间为道路上的行驶时间，交通费用为 $0$。

给定 $n$ 个博物馆（编号 $1$ 到 $n$）的信息（入场费和乐趣指数），以及 $m$ 条双向道路（连接两个节点，包括家，编号为 $0$），你的任务是计算在预算和时间限制下能获得的最大乐趣值。如果无法参观任何博物馆，输出 `No possible trip.`。

---

## 输入格式

输入包含多个测试用例。第一行是一个整数，表示测试用例的数量。

每个测试用例的第一行包含四个正整数： $d$、$t$、$n$、$m$。
- $d$：可用预算（美元），不超过 $100$。
- $t$：时间限制（分钟），不超过 $600$。
- $n$：博物馆数量，不超过 $12$。
- $m$：道路数量，不超过 $n(n+1)/2$。

接下来 $n$ 行，每行两个整数：入场费（不超过 $50$）和乐趣指数。

接下来 $m$ 行，每行三个整数：$i$、$j$、$k$，表示一条连接节点 $i$ 和 $j$ 的双向道路，行驶时间为 $k$ 分钟（不超过 $200$）。

对于每个测试用例，输出一行：

```
Case X: Y
```
其中 $X$ 是测试用例编号， $Y$ 是最大乐趣值或 `No possible trip.`。

## 题目分析

### 问题本质

这是一个**带约束的旅行规划问题**，需要在有限的预算和时间下，选择一组博物馆进行参观，使得总乐趣最大。关键点在于：
1. **起点和终点都是家**（节点 $0$）。
2. **每个博物馆只能参观一次**。
3. **参观时间固定为 $15$ 分钟**。
4. **道路可能不连通**，需要检查可达性。

### 数据范围分析

- 博物馆数量 $n \leq 12$：可以使用**状态压缩动态规划**（$\texttt{bitmask DP}$）。
- 预算 $d \leq 100$：较小，可以作为 $\texttt{DP}$ 状态的一维或通过掩码预处理。
- 时间 $t \leq 600$：较小，可以作为 $\texttt{DP}$ 状态的一维。
- 道路数量 $m \leq n(n+1)/2$：完全图级别，但 $n$ 很小。

---

## 解题思路

### 1. 图论预处理

由于道路可能不连通，且需要计算任意两点之间的最短时间（用于规划路线），首先使用 **$\texttt{Floyd-Warshall}$ 算法** 计算所有节点之间的最短路径。

- 节点编号： $0$ 表示家， $1$ 到 $n$ 表示博物馆。
- 使用邻接矩阵 `dist[i][j]` 存储最短时间，初始不可达设为无穷大（ `INF`）。

### 2. 状态压缩动态规划

由于 $n \leq 12$，可以用一个 $n$ 位二进制数 `mask` 表示已参观的博物馆集合。例如， `mask` 的第 $i$ 位为 $1$ 表示已参观博物馆 $i$（注意编号转换：博物馆 $i$ 对应 `mask` 的第 $i-1$ 位）。

#### 状态定义

定义 `dp[mask][u]` 表示：
- 已参观的博物馆集合为 `mask`。
- 当前位于节点 $u$（ $0 \leq u \leq n$）。
- 值表示达到该状态的**最小累计时间**（包括行驶时间和参观时间）。

#### 状态转移

从状态 `(mask, u)` 出发，可以尝试参观一个新的博物馆 $v$（ $1 \leq v \leq n$）：
1. **检查是否已参观**：`mask & (1 << (v-1)) == 0`。
2. **检查是否可达**：`dist[u][v] < INF`。
3. **计算新状态**：
   - 新掩码：`newMask = mask | (1 << (v-1))`。
   - 新时间：`newTime = dp[mask][u] + dist[u][v] + 15`。
4. **检查时间限制**：还需要从 $v$ 返回家的时间，即 `backHomeTime = newTime + dist[v][0]`，必须满足 `backHomeTime ≤ t`。
5. **检查预算限制**：新掩码对应的总入场费必须 `≤ d`。

#### 预算处理优化

由于每个博物馆的入场费是固定的，我们可以**预处理每个掩码的总费用和总乐趣**：
- `maskCost[mask]`：掩码对应博物馆的总入场费。
- `maskFun[mask]`：掩码对应博物馆的总乐趣。

这样，在转移时只需检查 `maskCost[newMask] ≤ d`，避免了在 $\texttt{DP}$ 状态中多维护一维。

#### 初始状态

- `dp[0][0] = 0`：未参观任何博物馆，位于家。
- 其他状态初始为 `INF`。

#### 答案更新

每当成功转移到一个新状态 `(newMask, v)` 且满足所有限制时，更新答案：
`answer = max(answer, maskFun[newMask])`。

### 3. 算法复杂度

- **$\texttt{Floyd-Warshall}$**：$O((n+1)^3)$， $n \leq 12$，可忽略。
- **$\texttt{DP}$ 状态数**：$2^n \times (n+1) \leq 2^{12} \times 13 = 8192 \times 13 \approx 10^5$。
- **转移次数**：每个状态最多尝试 $n$ 个新博物馆，总复杂度 $O(2^n \times n^2) \approx 1.4 \times 10^6$。
- **预处理掩码费用和乐趣**：$O(2^n \times n)$。

总复杂度在合理范围内。

## 代码实现

```cpp
// Museums
// UVa ID: 11153
// Verdict: Accepted
// Submission Date: 2026-01-02
// UVa Run Time: 0.020s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;

int main() {
    int cases;
    cin >> cases;
    for (int caseNo = 1; caseNo <= cases; caseNo++) {
        int d, t, n, m;
        cin >> d >> t >> n >> m;
        vector<int> fee(n + 1), fun(n + 1);
        fee[0] = fun[0] = 0;
        for (int i = 1; i <= n; i++) cin >> fee[i] >> fun[i];
        vector<vector<int>> dist(n + 1, vector<int>(n + 1, INF));
        for (int i = 0; i <= n; i++) dist[i][i] = 0;
        for (int i = 0; i < m; i++) {
            int u, v, w;
            cin >> u >> v >> w;
            dist[u][v] = min(dist[u][v], w);
            dist[v][u] = min(dist[v][u], w);
        }
        // Floyd 最短路
        for (int k = 0; k <= n; k++)
            for (int i = 0; i <= n; i++)
                for (int j = 0; j <= n; j++)
                    if (dist[i][k] < INF && dist[k][j] < INF)
                        dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
        int totalStates = 1 << n;
        // 预处理每个掩码的总花费和总乐趣
        vector<int> maskCost(totalStates, 0), maskFun(totalStates, 0);
        for (int mask = 0; mask < totalStates; mask++)
            for (int i = 0; i < n; i++)
                if (mask & (1 << i)) {
                    maskCost[mask] += fee[i + 1];
                    maskFun[mask] += fun[i + 1];
                }
        // dp[mask][u] = 最小时间
        vector<vector<int>> dp(totalStates, vector<int>(n + 1, INF));
        dp[0][0] = 0;
        int answer = 0;
        for (int mask = 0; mask < totalStates; mask++)
            for (int u = 0; u <= n; u++) {
                if (dp[mask][u] == INF) continue;
                // 尝试访问新博物馆 v
                for (int v = 1; v <= n; v++) {
                    if (mask & (1 << (v - 1))) continue;  // 已访问
                    if (dist[u][v] == INF) continue;  // 不可达
                    int newMask = mask | (1 << (v - 1));
                    // 检查新掩码的总花费是否超预算
                    if (maskCost[newMask] > d) continue;
                    int newTime = dp[mask][u] + dist[u][v] + 15;
                    int backHomeTime = newTime + dist[v][0];
                    if (backHomeTime <= t) {
                        if (newTime < dp[newMask][v]) dp[newMask][v] = newTime;
                        answer = max(answer, maskFun[newMask]);
                    }
                }
            }
        cout << "Case " << caseNo << ": ";
        if (answer == 0) cout << "No possible trip.";
        else cout << answer;
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题是一道典型的状态压缩动态规划题目，结合了图论的最短路计算。关键点在于：
1. 利用 $n$ 较小的特点，使用二进制掩码表示博物馆集合。
2. 预处理掩码的总费用和总乐趣，简化状态转移。
3. 使用 $\texttt{Floyd-Warshall}$ 计算任意两点间最短路，确保可达性判断。
4. 在转移时同时检查时间和预算限制。

通过合理设计状态和转移，可以在规定时间内求出最大乐趣值。
