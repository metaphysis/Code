## 题目描述

给定一个整数序列 $X$，其生成规则如下：

- $X_0 = A$
- $X_i = ((X_{i-1} \times B + C) \bmod M) + 1 \quad \text{其中 } i = 1, 2, \dots, N-1$

输入参数为 $A, B, C, M, N$，要求计算该序列中**有多少个连续子序列的和是 $M$ 的倍数**。

**注意**：连续子序列必须是原序列中连续的一段，且至少包含一个元素。

### 输入格式

- 第一行：整数 $T$ ($T < 500$)，表示测试用例数量
- 每个测试用例一行，包含 $5$ 个整数：$A, B, C, M, N$
- $0 \le A, B, C \le 1000$，$1 \le N, M \le 10000$

### 输出格式

对于每个测试用例，输出 `Case i:`，其中 $i$ 从 $1$ 开始编号，接着输出结果。

---

## 题目分析

### 暴力解法不可行

最直观的方法是枚举所有可能的连续子序列，计算它们的和并判断是否能被 $M$ 整除。

连续子序列的数量为 $\frac{N(N+1)}{2}$，当 $N = 10000$ 时，这大约是 $5 \times 10^7$ 个子序列。对于每个测试用例来说，这个计算量在时间限制内通常无法完成。

### 关键思路：前缀和与同余定理

我们引入**前缀和**的概念：

- 定义 $S_0 = 0$
- $S_i = X_0 + X_1 + \dots + X_{i-1} \quad (i = 1, 2, \dots, N)$

那么，任意连续子序列 $[i, j]$ 的和可以表示为：
$$\text{sum}(i, j) = S_{j+1} - S_i$$

我们要找的是满足 $\text{sum}(i, j) \bmod M = 0$ 的子序列，即：
$$(S_{j+1} - S_i) \bmod M = 0$$

根据同余定理，这等价于：
$$S_{j+1} \equiv S_i \pmod{M}$$

其中 $0 \le i \le j \le N-1$。

### 转化为计数问题

问题转化为：在 $S_0, S_1, \dots, S_N$ 这些前缀和中，有多少对 $(i, j)$ 满足：

1. $i < j$（因为 $j+1 > i$ 且 $j \ge i$ 推导出 $j \ge i$）
2. $S_i \equiv S_{j+1} \pmod{M}$

实际上，更准确的说法是：对于每个 $j$ ($0 \le j \le N-1$)，我们统计有多少个 $i$ ($0 \le i \le j$) 满足 $S_i \equiv S_{j+1} \pmod{M}$。

### 高效算法

我们可以使用一个计数数组在遍历过程中动态统计：

1. 初始化 `cnt[0] = 1`（因为 $S_0 = 0$）
2. 对于 $j = 0$ 到 $N-1$：
   - 计算 $r = S_{j+1} \bmod M$
   - 将 `cnt[r]` 的值加到答案中（这些对应了所有满足条件的 $i$）
   - 将 `cnt[r]` 加 $1$（为后续的 $j$ 做准备）

这样，我们只需要 $O(N)$ 的时间复杂度就能解决问题。

### 算法正确性说明

当我们在位置 $j$ 时，`cnt[r]` 记录了在 $S_0$ 到 $S_j$ 中余数为 $r$ 的前缀和数量。这些前缀和对应的 $i$ 值都小于等于 $j$，因此区间 $[i, j]$ 是有效的连续子序列。

## 复杂度分析

- **时间复杂度**：$O(N)$，每个测试用例只需要线性时间
- **空间复杂度**：$O(N + M)$，用于存储序列和计数数组

## 代码实现

```cpp
// Be Efficient
// UVa ID: 11155
// Verdict: Accepted
// Submission Date: 2025-10-29
// UVa Run Time: 0.030s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int T, X[10010], cnt[10010];
    long long prefix[10010] = {0};
    cin >> T;
    for (int cs = 1; cs <= T; cs++) {
        int A, B, C, M, N;
        cin >> A >> B >> C >> M >> N;
        X[0] = A;
        for (int i = 1; i < N; i++) X[i] = ((X[i - 1] * B + C) % M) + 1;
        for (int i = 1; i <= N; i++) prefix[i] = (prefix[i - 1] + X[i - 1]) % M;
        memset(cnt, 0, sizeof cnt);
        cnt[0] = 1;
        long long r = 0;
        for (int j = 0; j < N; j++) r += cnt[prefix[j + 1]]++;
        cout << "Case " << cs << ": " << r << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于将**连续子序列和是 $M$ 的倍数**这一条件转化为**前缀和同余**的问题，然后利用计数技巧在 $O(N)$ 时间内求解。这种方法避免了暴力枚举，是处理此类"子序列和模 $M$"问题的经典技巧。

**核心公式**：
$$\text{sum}(i, j) \bmod M = 0 \iff S_{j+1} \equiv S_i \pmod{M}$$

掌握这一转化思路，可以解决许多类似的子序列和问题。
