[UVa 11158 Elegant Permuted Sum](https://blog.csdn.net/metaphysis/article/details/154389016)

## 题目描述

给定 $n$ 个整数 $A_1, A_2, A_3, \ldots, A_n$，需要找到这些整数的一个排列，使得相邻元素之间的绝对差之和最大化。

例如，当 $n = 4$，给定整数为 $<4, 2, 1, 5>$ 时，排列 $<2, 5, 1, 4>$ 能够产生最大和：
$$
\text{abs}(2-5) + \text{abs}(5-1) + \text{abs}(1-4) = 3 + 4 + 3 = 10
$$
我们将这个最大值 $10$ 称为 **优雅排列和**（$\texttt{Elegant Permuted Sum}$）。

## 输入格式

- 第一行：整数 $T$ ($T < 100$)，表示测试用例的数量
- 每个测试用例：以 $n$ ($1 < n < 51$) 开头，后面跟着 $n$ 个非负整数，用空格分隔
- 所有整数都不超过 $1000$

## 输出格式

对于每个测试用例，输出用例编号和对应的优雅排列和。

## 题目分析

### 问题本质

这是一个经典的排列优化问题，目标是在所有可能的 $n!$ 个排列中，找到使相邻元素绝对差之和最大的那个排列。由于 $n$ 最大为 $50$，直接枚举所有排列是不可行的（$50!$ 是一个巨大的数字）。

### 关键观察

通过分析问题，我们可以发现几个重要性质：

1. **排序的重要性**：为了最大化相邻差，我们应该让大的数和小的数交替出现
2. **贪心策略**：每次选择能够产生最大差异的元素添加到序列的头部或尾部
3. **局部最优性**：每次选择当前能产生最大差异的放置方式，可以逐步构建出全局最优解

### 算法思路

基于贪心策略的算法步骤如下：

1. **特殊情况处理**：
   - 如果 $n = 1$，结果为 $0$（没有相邻元素）
   - 如果 $n = 2$，结果为两个数的绝对差

2. **初始化阶段**：
   - 将输入数组排序
   - 用最小值和最大值初始化结果序列
   - 从剩余数组中移除这两个元素

3. **贪心构建阶段**：
   - 在每一步中，考虑剩余数组中的最小值和最大值
   - 计算四种可能的放置方式：
     - 最小值放在序列头部
     - 最小值放在序列尾部
     - 最大值放在序列头部
     - 最大值放在序列尾部
   - 选择能够产生最大绝对差的放置方式
   - 重复此过程直到没有剩余元素

4. **结果计算**：
   - 计算最终序列中所有相邻元素的绝对差之和

### 算法正确性证明

该贪心算法的正确性基于以下观察：
- 每次选择都保证了当前步骤的局部最优
- 由于绝对差函数的性质，将差异大的元素放在相邻位置能够贡献更大的值
- 通过维护序列的两端，我们能够充分利用极值（最小值和最大值）来创造大的差异

具体的证明可以参考以下论文：[$\texttt{Curtis, Sharon A.. “Darts and hoopla board design.” Inf. Process. Lett. 92 (2004): 53-56.}$](https://people.cs.nycu.edu.tw/~sctsai/complexity/ShortReading/Dartboard-design.pdf)

```cpp
// Elegant Permuted Sum

#include <bits/stdc++.h>

using namespace std;

int main() {
    int testCases;
    cin >> testCases;
    
    for (int caseNum = 1; caseNum <= testCases; ++caseNum) {
        int n;
        cin >> n;
        vector<int> numbers(n);
        for (int i = 0; i < n; ++i) {
            cin >> numbers[i];
        }
        
        // 处理特殊情况：只有一个元素时，没有相邻元素，和为 0
        if (n == 1) {
            cout << "Case " << caseNum << ": 0" << endl;
            continue;
        }
        
        // 对数组进行排序，便于后续的贪心选择
        sort(numbers.begin(), numbers.end());
        deque<int> remainingNumbers(numbers.begin(), numbers.end());
        deque<int> resultSequence;
        
        // 初始化：用最小值和最大值开始构建序列
        resultSequence.push_back(remainingNumbers.front());
        resultSequence.push_back(remainingNumbers.back());
        remainingNumbers.pop_front();
        remainingNumbers.pop_back();
        
        // 贪心构建序列：每次选择能产生最大差异的放置方式
        while (!remainingNumbers.empty()) {
            int currentMin = remainingNumbers.front();
            int currentMax = remainingNumbers.back();
            
            // 计算四种可能的放置方式产生的差异
            int diffMinFront = abs(currentMin - resultSequence.front());
            int diffMinBack = abs(currentMin - resultSequence.back());
            int diffMaxFront = abs(currentMax - resultSequence.front());
            int diffMaxBack = abs(currentMax - resultSequence.back());
            
            // 选择能产生最大差异的放置方式
            int maxDifference = max({diffMinFront, diffMinBack, diffMaxFront, diffMaxBack});
            
            if (maxDifference == diffMinFront) {
                // 将最小值放在序列头部
                resultSequence.push_front(currentMin);
                remainingNumbers.pop_front();
            } else if (maxDifference == diffMinBack) {
                // 将最小值放在序列尾部
                resultSequence.push_back(currentMin);
                remainingNumbers.pop_front();
            } else if (maxDifference == diffMaxFront) {
                // 将最大值放在序列头部
                resultSequence.push_front(currentMax);
                remainingNumbers.pop_back();
            } else {
                // 将最大值放在序列尾部
                resultSequence.push_back(currentMax);
                remainingNumbers.pop_back();
            }
        }
        
        // 计算最终序列的相邻元素绝对差之和
        int totalSum = 0;
        for (int i = 1; i < n; i++) {
            totalSum += abs(resultSequence[i] - resultSequence[i - 1]);
        }
        
        cout << "Case " << caseNum << ": " << totalSum << endl;
    }
    
    return 0;
}
```
