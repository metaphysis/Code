## 题目描述

有一个包含 $n$ 个房屋的小镇，需要建造一个机场。机场本质上是一条无限长的直线跑道。要求：

1. 所有房屋必须位于跑道的同一侧（可以紧贴跑道）
2. 使得所有房屋到跑道的平均距离最小

**输入**：多个测试用例，每个用例给出房屋坐标（整数，绝对值不超过 $80,000$）

**输出**：对于每个测试用例，输出最小的平均距离，保留 $3$ 位小数

---

## 题目分析

### 关键约束分析

题目要求所有房屋必须在跑道同一侧，这个约束非常关键。这意味着：

- 跑道不能穿过点集形成的凸包
- 最优跑道必然是凸包某条边所在的直线

### 几何直觉

考虑点集的凸包（包含所有点的最小凸多边形）：

- 如果跑道是凸包某条边所在的直线，那么所有点自然位于该直线的同一侧（凸包内部）
- 如果选择其他直线，要么无法满足"同侧"要求，要么距离和不会更优

### 特殊情况

- 当所有点共线时，凸包退化为线段，平均距离为 $0$
- 当 $n \leq 2$ 时，也必然可以找到平均距离为 $0$ 的跑道

---

## 解题思路

### 算法步骤

1. **计算凸包**
   - 使用 $\texttt{Andrew's monotone chain}$ 算法
   - 时间复杂度：$O(n \log n)$

2. **处理退化情况**
   - 如果凸包点数 $\leq 2$，直接输出 $0.000$

3. **枚举凸包边**
   - 对于凸包的每条边 $(A, B)$
   - 计算所有点到直线 $AB$ 的距离之和
   - 更新最小平均距离

4. **输出结果**
   - 保留 $3$ 位小数

### 距离计算

点 $P$ 到直线 $AB$ 的距离公式：
$$
\texttt{distance} = \frac{|(B - A) \times (P - A)|}{\|B - A\|}
$$

其中 $\times$ 表示二维叉积：$(B-A)_x \cdot (P-A)_y - (B-A)_y \cdot (P-A)_x$

---

## 复杂度分析

- 凸包计算：$O(n \log n)$
- 枚举边并计算距离：$O(n \times m)$，其中 $m$ 是凸包点数
- 最坏情况下 $m = n$，但实际数据中凸包点数通常远小于 $n$
- 对于 $n \leq 10000$ 可以接受

#include <bits/stdc++.h>

using namespace std;

struct Point {
    int x, y;
    Point(int x = 0, int y = 0) : x(x), y(y) {}
    // 点减法
    Point operator - (const Point& p) const {
        return Point(x - p.x, y - p.y);
    }
    // 用于排序
    bool operator < (const Point& p) const {
        return x < p.x || (x == p.x && y < p.y);
    }
};

// 二维叉积
long long cross(const Point& a, const Point& b) {
    return (long long)a.x * b.y - (long long)a.y * b.x;
}

// 凸包算法 (Andrew's monotone chain)
vector<Point> convexHull(vector<Point>& points) {
    int n = points.size();
    if (n <= 1) return points;

    // 按 x 坐标排序，x 相同时按 y 排序
    sort(points.begin(), points.end());

    vector<Point> hull(2 * n);
    int k = 0;

    // 构建下凸包
    for (int i = 0; i < n; ++i) {
        while (k >= 2 && cross(hull[k - 1] - hull[k - 2], points[i] - hull[k - 2]) <= 0) {
            k--;
        }
        hull[k++] = points[i];
    }

    // 构建上凸包
    for (int i = n - 2, t = k + 1; i >= 0; --i) {
        while (k >= t && cross(hull[k - 1] - hull[k - 2], points[i] - hull[k - 2]) <= 0) {
            k--;
        }
        hull[k++] = points[i];
    }

    // 移除重复的起点
    hull.resize(k - 1);
    return hull;
}

// 计算点 p 到直线 ab 的距离
double pointToLineDistance(const Point& p, const Point& a, const Point& b) {
    Point ab = b - a;      // 向量 AB
    Point ap = p - a;      // 向量 AP
    double area = abs(cross(ab, ap));  // 平行四边形面积
    double len = hypot(ab.x, ab.y);    // AB 的长度
    return area / len;                 // 高 = 面积 / 底边
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    int T;
    cin >> T;

    for (int caseNum = 1; caseNum <= T; ++caseNum) {
        int n;
        cin >> n;
        vector<Point> houses(n);

        for (int i = 0; i < n; ++i) cin >> houses[i].x >> houses[i].y;

        double minAvgDist = 1e20;  // 初始化为一个大数
        
        if (n <= 2) {
            // 点数为 1 或 2 时，总能找到平均距离为 0 的直线
            minAvgDist = 0.0;
        } else {
            // 计算凸包
            vector<Point> hull = convexHull(houses);
            int m = hull.size();
            
            if (m <= 2) {
                // 凸包退化，所有点共线
                minAvgDist = 0.0;
            } else {
                // 枚举凸包的每条边
                for (int i = 0; i < m; ++i) {
                    const Point& a = hull[i];
                    const Point& b = hull[(i + 1) % m];  // 循环到第一条边
                    
                    double totalDist = 0.0;
                    // 计算所有点到当前边的距离之和
                    for (const Point& p : houses) {
                        totalDist += pointToLineDistance(p, a, b);
                    }
                    
                    double avgDist = totalDist / n;
                    if (avgDist < minAvgDist) {
                        minAvgDist = avgDist;
                    }
                }
            }
        }
        
        // 输出结果，保留 3 位小数
        cout << "Case #" << caseNum << ": "
             << fixed << setprecision(3) << minAvgDist << "\n";
    }
    
    return 0;
}

## 总结

本题的核心在于理解几何约束并将其转化为凸包问题。通过计算凸包并枚举其边，我们能够高效地找到最优解。算法在保证正确性的同时，也具有较好的时间复杂度，能够处理题目给出的数据规模。

关键要点：
- 利用凸包性质保证"同侧"约束
- 使用叉积计算点到直线距离
- 注意处理退化情况（共线点）
