## 题目描述

在古老的手机（如 $\texttt{Ericsson T65}$）上，每个数字键对应多个字母，映射关系如下：

- $2 \rightarrow \texttt{ABC}$
- $3 \rightarrow \texttt{DEF}$
- $4 \rightarrow \texttt{GHI}$
- $5 \rightarrow \texttt{JKL}$
- $6 \rightarrow \texttt{MNO}$
- $7 \rightarrow \texttt{PQRS}$
- $8 \rightarrow \texttt{TUV}$
- $9 \rightarrow \texttt{WXYZ}$

此外，$1$ 键用于输入空格，$0$ 键用于输入标点符号（本题未使用）。

手机内置一个词典，单词按常见程度从高到低排序。当用户按下一串数字时，手机会先显示该数字串对应的最常用单词。用户可以通过按 “上” 键（$\texttt{U}$）或 “下” 键（$\texttt{D}$）在同数字串的单词列表中循环切换。具体规则如下：

- 按 “上” 键切换到下一个单词（常见程度更低）
- 按 “下” 键切换到上一个单词（常见程度更高）
- 列表是循环的，即在最后一个单词按 “上” 会回到第一个单词
- 初始时显示第一个单词（最常见）

如果要输入的单词不在词典中，需要将其拆分成若干部分，每部分都是词典中的单词，并在各部分之间按 “右” 键（$\texttt{R}$）切换。

目标是：给定词典和若干待输入的单词，求出**最少按键次数**，并输出任意一种最优的按键序列。

## 输入格式

- 多组数据，每组数据以 $N = 0$ 结束
- 每组数据第一行：$N$（$1 \le N \le 10000$），表示词典大小
- 接下来 $N$ 行：词典中的单词，按常见程度从高到低排列，单词只含小写字母，长度不超过 $10$
- 接下来一行：$Q$（$Q \ge 1$），表示待输入的单词数量
- 接下来 $Q$ 行：每个待输入的单词，保证可以用词典中的单词拆分得到，所有待输入单词的总长度不超过 $250000$

## 输出格式

对于每个查询，输出一行最优按键序列。其中：

- 数字键 $2$ ~ $9$ 直接输出对应数字
- 按 $\texttt{R}$ 键输出 `R`
- 按 $\texttt{U}$ 或 $\texttt{D}$ 键时，如果只按一次，输出 `U` 或 `D`；如果按 $k$ 次（$k > 1$），输出 `U(k)` 或 `D(k)`

## 题目分析

### 核心问题拆解

本题可以分解为三个子问题：

1. **单词编码**：将字母串映射为数字串
2. **切换代价**：在相同数字串的单词列表中，从第一个单词切换到目标单词所需的最少按键次数
3. **最优拆分**：将待输入单词拆分成若干词典单词，使得总按键次数最少

### 1. 单词编码

根据按键映射，可以将任意单词转换为对应的数字串。例如：

- `abc` $\rightarrow$ `222`
- `def` $\rightarrow$ `333`
- `hello` $\rightarrow$ `43556`

### 2. 切换代价

对于某个数字串 $S$，假设词典中有 $m$ 个单词映射到 $S$，按常见程度从高到低排列，索引为 $0, 1, \dots, m-1$。当前要输入的是第 $r$ 个单词（$0 \le r < m$），初始显示第 $0$ 个单词。

切换方式有两种：

- 按 “上” 键 $r$ 次：从 $0$ 到 $r$
- 按 “下” 键 $m - r$ 次：从 $0$ 往下循环到 $r$

因此，最少切换次数为：

$$
switchCost = \min(r, m - r)
$$

特别地，当 $r = 0$ 时，切换代价为 $0$。

例如：某数字串有 $5$ 个单词，目标单词排在第 $2$ 位（$r=2$），则：

- 按上 $2$ 次：$2$ 次按键
- 按下 $3$ 次：$3$ 次按键

最优选择是按上 $2$ 次，代价为 $2$。

### 3. 总按键代价

对于单词 $W$，其输入代价为：

$$
wordCost = |W| + switchCost
$$

其中 $|W|$ 是单词长度，即需要按的数字键个数。

对于拆分后的单词序列 $W_1, W_2, \dots, W_k$，总代价为：

$$
totalCost = \sum_{i=1}^{k} wordCost(W_i) + (k - 1)
$$

其中 $(k-1)$ 是单词之间的 $\texttt{R}$ 键次数。

### 4. 动态规划求解最优拆分

定义 $dp[i]$ 为输入待查询单词前缀 $[0, i)$ 的最小总按键次数（$i$ 从 $0$ 到 $L$，$L$ 为单词长度）。初始化 $dp[0] = 0$，$dp[i] = \infty$（$i > 0$）。

转移方程：

$$
dp[j] = \min_{i < j \wedge \text{substr}[i:j] \in \text{dict}} \left( dp[i] + wordCost(\texttt{substr}[i:j]) + [j < L] \right)
$$

其中 $[j < L]$ 表示如果当前单词不是最后一个（即 $j \ne L$），则需要额外加 $1$ 表示 $\texttt{R}$ 键。

由于单词长度不超过 $10$，因此对于每个位置 $i$，只需要枚举 $j = i+1, i+2, \dots, \min(L, i+10)$，复杂度为 $O(L \cdot 10 \cdot \text{查字典代价})$。

```cpp
// SMS
// UVa ID: 11171

// UVa Run Time: 0.080s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

// 字母到数字的映射
int charToDigit(char c) {
    if (c <= 'c') return 2;
    if (c <= 'f') return 3;
    if (c <= 'i') return 4;
    if (c <= 'l') return 5;
    if (c <= 'o') return 6;
    if (c <= 's') return 7;
    if (c <= 'v') return 8;
    return 9;
}

// 将单词转换为数字串
string encode(const string& word) {
    string res;
    for (char c : word) res += char('0' + charToDigit(c));
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int N;
    while (cin >> N, N) {
        // 按数字串分组存储单词
        unordered_map<string, vector<string>> dict;
        vector<string> words(N);
        for (int i = 0; i < N; ++i) {
            cin >> words[i];
            dict[encode(words[i])].push_back(words[i]);
        }

        // 构建单词 -> (数字串, (排名, 总单词数)) 的映射
        unordered_map<string, pair<string, pair<int, int>>> rankMap;
        for (auto& p : dict) {
            string code = p.first;
            auto& lst = p.second;
            int total = lst.size();
            for (int i = 0; i < total; ++i) {
                rankMap[lst[i]] = {code, {i, total}};
            }
        }

        int Q;
        cin >> Q;
        while (Q--) {
            string target;
            cin >> target;
            int L = target.size();

            // dp[i]: 前缀 [0, i) 的最小代价
            vector<int> dp(L + 1, INF);
            // pre[i]: 上一段的起始位置
            vector<int> pre(L + 1, -1);
            // partLen[i]: 当前段的长度
            vector<int> partLen(L + 1, 0);
            dp[0] = 0;

            // 动态规划
            for (int i = 0; i < L; ++i) {
                if (dp[i] == INF) continue;
                string cur;
                // 枚举单词长度，最长 10
                for (int j = i; j < min(L, i + 10); ++j) {
                    cur += target[j];
                    auto it = rankMap.find(cur);
                    if (it != rankMap.end()) {
                        int rank = it->second.second.first;
                        int total = it->second.second.second;
                        // 切换代价
                        int switchCost = (rank > 0) ? min(rank, total - rank) : 0;
                        int wordCost = (int)cur.size() + switchCost;
                        // R 键代价（最后一段不加）
                        int rCost = (j + 1 == L) ? 0 : 1;
                        int totalCost = dp[i] + wordCost + rCost;
                        if (totalCost < dp[j + 1]) {
                            dp[j + 1] = totalCost;
                            pre[j + 1] = i;
                            partLen[j + 1] = j - i + 1;
                        }
                    }
                }
            }

            // 回溯得到拆分方案
            vector<string> parts;
            int pos = L;
            while (pos > 0) {
                int start = pre[pos];
                string w = target.substr(start, partLen[pos]);
                parts.push_back(w);
                pos = start;
            }
            reverse(parts.begin(), parts.end());

            // 输出结果
            for (size_t idx = 0; idx < parts.size(); ++idx) {
                string& w = parts[idx];
                string code = rankMap[w].first;
                int rank = rankMap[w].second.first;
                int total = rankMap[w].second.second;

                // 输出数字串
                cout << code;

                // 输出 U/D 操作
                if (rank > 0) {
                    int upCnt = rank;
                    int downCnt = total - rank;
                    if (upCnt <= downCnt) {
                        if (upCnt == 1) cout << "U";
                        else cout << "U(" << upCnt << ")";
                    } else {
                        if (downCnt == 1) cout << "D";
                        else cout << "D(" << downCnt << ")";
                    }
                }

                // 输出 R（最后一段不加）
                if (idx + 1 < parts.size()) cout << "R";
            }
            cout << "\n";
        }
    }
    return 0;
}
```
