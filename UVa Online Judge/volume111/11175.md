## 题目描述

给定一个有向图 $\mathbf{E}$，判断是否存在某个有向图 $\mathbf{D}$，使得 $\mathbf{E}$ 是 $\mathbf{D}$ 的 $\texttt{Lying graph}$（也称为有向线图）。

**$\texttt{Lying graph}$ 的构造规则**：
- $\mathbf{E}$ 的每个顶点对应 $\mathbf{D}$ 的一条有向边
- 如果 $\mathbf{D}$ 中有两条边 $u \to v$ 和 $v \to w$，那么在 $\mathbf{E}$ 中，从顶点 $uv$ 到顶点 $vw$ 有一条有向边

## 输入格式

- 第一行：测试用例数 $N$ ($N < 220$)
- 每个测试用例：
  - 第一行：顶点数 $m$ ($0 \leq m \leq 300$)
  - 第二行：边数 $k$
  - 接下来 $k$ 行：每行两个整数 $x$ 和 $y$，表示从 $x$ 到 $y$ 的有向边
  - 顶点编号从 $0$ 到 $m-1$

## 输出格式

对于每个测试用例，输出一行 `Case #z: Yes` 或 `Case #z: No`，表示 $\mathbf{E}$ 是否是有效的 $\texttt{Lying graph}$。

## 题目分析

### 问题理解

我们需要判断给定的有向图 $\mathbf{E}$ 是否可以通过某个有向图 $\mathbf{D}$ 按照 $\texttt{Lying graph}$ 的规则构造出来。

**关键观察**：
- 在 $\mathbf{E}$ 中，每个顶点对应 $\mathbf{D}$ 的一条边 $(s_i, t_i)$，其中 $s_i$ 是起点，$t_i$ 是终点
- $\mathbf{E}$ 中的边 $x \to y$ 存在当且仅当在 $\mathbf{D}$ 中 $t_x = s_y$

### 充要条件

经过图论分析，$\mathbf{E}$ 是有向线图的**充要条件**是：

> 对于 $\mathbf{E}$ 中的任意三个顶点 $i$, $j$, $k$，如果存在边 $i \to k$ 和 $j \to k$，那么顶点 $i$ 和 $j$ 必须有完全相同的出邻接集合。

**理论解释**：
- 如果 $i \to k$ 和 $j \to k$ 都存在，意味着在 $\mathbf{D}$ 中：
  - 边 $i$ 的终点 = 边 $k$ 的起点
  - 边 $j$ 的终点 = 边 $k$ 的起点
- 因此边 $i$ 和边 $j$ 在 $\mathbf{D}$ 中有相同的终点
- 相同的终点意味着它们在 $\mathbf{E}$ 中必须有相同的出边集合

### 算法设计

基于上述充要条件，我们可以设计如下算法：

1. **读取输入**：构建图的邻接矩阵
2. **预计算**：使用 $\texttt{bitset}$ 存储每个顶点的出邻接集合，便于快速比较
3. **验证条件**：对于每个目标顶点 $k$，检查所有指向 $k$ 的顶点是否有相同的出邻接集合
4. **输出结果**：根据验证结果输出 `Yes` 或 `No`

// From D to E and Back

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int T;
    cin >> T;
    for (int caseNum = 1; caseNum <= T; caseNum++) {
        int m, k;
        cin >> m >> k;
        vector<bitset<300>> adj(m);  // 直接使用bitset存储邻接矩阵
        for (int i = 0; i < k; i++) {
            int x, y;
            cin >> x >> y;
            adj[x][y] = true;
        }
        bool valid = true;
        // 对于每个目标顶点k
        for (int k = 0; k < m && valid; k++) {
            bitset<300> reference;  // 参考出邻接集合
            bool reference_set = false;
            // 找出所有指向k的顶点
            for (int i = 0; i < m; i++) {
                if (adj[i][k]) {
                    if (!reference_set) {
                        reference = adj[i];  // 设置参考集合
                        reference_set = true;
                    } else {
                        // 直接比较bitset
                        if (adj[i] != reference) {
                            valid = false;
                            break;
                        }
                    }
                }
            }
        }
        cout << "Case #" << caseNum << ": " << (valid ? "Yes" : "No") << "\n";
    }
    return 0;
}
