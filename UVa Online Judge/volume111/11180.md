## 题目描述

给定一个复数 $n = a + bi$，其中 $a$ 和 $b$ 都是整数，$i$ 是虚数单位（满足 $i^2 = -1$）。我们需要将这个复数表示为基数为 $i-1$ 的数字序列，其中每个数字只能是 $0$ 或 $1$，且表示是唯一的，没有前导零。

表示形式满足以下等式：
$$n = b_0 + b_1(i-1) + b_2(i-1)^2 + b_3(i-1)^3 + \cdots$$

**输入格式**：  
- 第一行是测试用例数量 $N$（最多 $20000$）
- 接下来 $N$ 行，每行包含两个整数 $a$ 和 $b$

**输出格式**：  
对于每个测试用例，输出 `Case #x:` 后跟该复数在 $\texttt{base}$ $i-1$ 下的表示

## 题目分析

这是一个关于**复数进制转换**的问题。与传统的正整数进制转换不同，这里的基数是复数 $i-1$。我们需要找到一种方法，将任意复数 $a + bi$ 唯一地表示为 $0$ 和 $1$ 组成的序列。

### 关键观察

1. **基数的性质**：$i-1$ 的模平方为：
   $$|i-1|^2 = (i-1)(-i-1) = -i^2 + i - i + 1 = 1 + 1 = 2$$

2. **复数除法**：要将复数 $a + bi$ 除以 $i-1$，我们可以使用公式：
   $$\frac{a + bi}{i-1} = \frac{(a + bi)(-i-1)}{2} = \frac{(b-a) + (-a-b)i}{2}$$

3. **余数的选择**：在每一步中，我们需要选择余数 $r$（只能是 $0$ 或 $1$），使得商是一个高斯整数（即实部和虚部都是整数）。

### 解题思路

我们可以模仿传统进制转换的方法，但需要适应复数的特性：

1. **迭代过程**：当 $a$ 和 $b$ 不全为 $0$ 时，重复以下步骤：
   - 计算余数 $r = (a - b) \mod 2$，确保 $r$ 为 $0$ 或 $1$
   - 将余数记录下来
   - 更新 $a$ 和 $b$ 为新的商

2. **更新公式**：通过数学推导，我们可以得到更新公式：
   - $a' = \dfrac{b - a + r}{2}$
   - $b' = \dfrac{-a - b + r}{2}$

3. **结果构建**：将收集到的余数反向排列，就得到了 $\texttt{base}$ $i-1$ 的表示。

### 算法正确性

这个算法的正确性基于以下数学原理：
- 每次迭代都确保余数为 $0$ 或 $1$
- 更新后的 $a'$ 和 $b'$ 仍然是整数
- 过程最终会收敛到 $(0, 0)$
- 表示是唯一的

### 复杂度分析

- **时间复杂度**：$O(kN)$，其中 $k$ 是表示的长度，$N$ 是测试用例数量。由于表示长度与输入值的大小对数相关，这在题目约束下是高效的。
- **空间复杂度**：$O(k)$，用于存储中间的数字序列。

```cpp
// Base i-1

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

string toBaseMinusI(int a, int b) {
    if (a == 0 && b == 0) {
        return "0";
    }
    
    vector<int> digits;
    while (a != 0 || b != 0) {
        int remainder = (a - b) % 2;
        if (remainder < 0) remainder += 2; // 保证余数为 0 或 1
        
        digits.push_back(remainder);
        
        // 更新 a 和 b
        int newA = (b - a + remainder) / 2;
        int newB = (-a - b + remainder) / 2;
        a = newA;
        b = newB;
    }
    
    // 反转 digits 得到正确顺序
    string result;
    for (int i = digits.size() - 1; i >= 0; --i) {
        result += to_string(digits[i]);
    }
    return result;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int numCases;
    cin >> numCases;
    
    for (int caseNum = 1; caseNum <= numCases; ++caseNum) {
        int a, b;
        cin >> a >> b;
        
        string representation = toBaseMinusI(a, b);
        cout << "Case #" << caseNum << ": " << representation << "\n";
    }
    
    return 0;
}
```
