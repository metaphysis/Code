## 题目描述

给定两个整数 $n$ $(1 \leq n \leq 1000000)$ 和 $b$ $(2 \leq b \leq 10000)$ ，定义以下函数：

- 阶乘 $n! = 1 \times 2 \times 3 \times \cdots \times n$
- $F_1(n) = 1! \times 2! \times 3! \times \cdots \times n!$
- $F_2(n) = F_1(1) \times F_1(2) \times F_1(3) \times \cdots \times F_1(n)$

要求计算 $F_2(n)$ 在 $b$ 进制下末尾连续零的个数。

输入包含约 $2000$ 行，每行两个整数 $n$ 和 $b$ ，以 `0 0` 结束。 对于每行输入，输出一个整数表示答案。

## 题目分析

### 1. 进制转换与末尾零

在 $b$ 进制下，一个数末尾连续零的个数等于该数能被 $b$ 的多少次幂整除。 例如，在十进制（ $b = 10$ ）中，末尾零的个数等于该数能被 $10^k$ 整除的最大 $k$ ，而 $10 = 2 \times 5$ ，所以需要同时考虑因子 $2$ 和 $5$ 的指数。

推广到一般进制 $b$ ，设 $b$ 的质因数分解为：

$$
b = p_1^{e_1} \times p_2^{e_2} \times \cdots \times p_k^{e_k}
$$

那么 $F_2(n)$ 在 $b$ 进制下末尾零的个数为：

$$
Z = \min_{i=1}^{k} \left\lfloor \frac{\text{exp}_{p_i}(F_2(n))}{e_i} \right\rfloor
$$

其中 $\text{exp}_{p}(X)$ 表示 $X$ 中质因子 $p$ 的指数（即 $p$ 的幂次）。

### 2. 问题转化

因此，问题转化为：

1. 对 $b$ 进行质因数分解，得到所有质因子 $p_i$ 及其指数 $e_i$ 。
2. 对每个质因子 $p_i$ ，计算 $F_2(n)$ 中 $p_i$ 的总指数 $\text{exp}_{p_i}(F_2(n))$ 。
3. 对每个 $i$ ，计算 $\lfloor \text{exp}_{p_i}(F_2(n)) / e_i \rfloor$ ，取最小值作为答案。

### 3. 计算 $F_2(n)$ 中质因子 $p$ 的指数

我们需要计算：

$$
\text{exp}_p(F_2(n)) = \sum_{i=1}^{n} \text{exp}_p(F_1(i))
$$

而 $F_1(i) = \prod_{j=1}^{i} j!$ ，所以：

$$
\text{exp}_p(F_1(i)) = \sum_{j=1}^{i} \text{exp}_p(j!)
$$

代入上式得到：

$$
\text{exp}_p(F_2(n)) = \sum_{i=1}^{n} \sum_{j=1}^{i} \text{exp}_p(j!)
$$

交换求和顺序：

$$
\text{exp}_p(F_2(n)) = \sum_{j=1}^{n} \text{exp}_p(j!) \times (n - j + 1)
$$

这里 $(n - j + 1)$ 是因为 $j!$ 出现在 $F_1(j), F_1(j+1), \ldots, F_1(n)$ 中，共 $n - j + 1$ 次。

### 4. 计算 $j!$ 中质因子 $p$ 的指数

根据勒让德定理， $j!$ 中质因子 $p$ 的指数为：

$$
\text{exp}_p(j!) = \left\lfloor \frac{j}{p} \right\rfloor + \left\lfloor \frac{j}{p^2} \right\rfloor + \left\lfloor \frac{j}{p^3} \right\rfloor + \cdots
$$

### 5. 直接计算公式

我们需要计算：

$$
S = \sum_{j=1}^{n} \text{exp}_p(j!) \times (n - j + 1) = \sum_{k=1}^{\infty} \sum_{j=1}^{n} \left\lfloor \frac{j}{p^k} \right\rfloor \times (n - j + 1)
$$

固定 $k$ ，令 $m = p^k$ ， $M = \lfloor n/m \rfloor$ ，计算内层和：

$$
T_k = \sum_{j=1}^{n} \left\lfloor \frac{j}{m} \right\rfloor \times (n - j + 1)
$$

将 $j$ 表示为 $j = q \cdot m + r$ ，其中 $0 \le r < m$ ， $\lfloor j/m \rfloor = q$ 。 则：

$$
T_k = \sum_{q=0}^{M} \sum_{r=0}^{L_q-1} q \times (n - (q \cdot m + r) + 1)
$$

其中 $L_q = \min(m, n - q \cdot m + 1)$ 是 $r$ 的取值范围。

经过推导（详细过程略），可得：

$$
T_k = \frac{m M (M-1)}{2} \left[ (n+1) - \frac{m-1}{2} \right] - \frac{m^2 M (M-1) (2M-1)}{6} + \frac{M (n - M m + 1) (n - M m + 2)}{2}
$$

其中 $m = p^k$ ， $M = \lfloor n/m \rfloor$ 。

总指数为：

$$
\text{exp}_p(F_2(n)) = \sum_{k=1}^{\infty} T_k
$$

当 $p^k > n$ 时停止求和。

### 6. 算法步骤

1. 对 $b$ 进行质因数分解。
2. 对每个质因子 $p$ 及其指数 $e$ ：
   - 如果 $p > n$ ，则 $F_2(n)$ 中不含因子 $p$ ，答案直接为 $0$ 。
   - 否则，利用上述公式计算 $\text{exp}_p(F_2(n))$ ，再计算 $\lfloor \text{exp}_p(F_2(n)) / e \rfloor$ 。
3. 对所有质因子取最小值作为答案。

### 7. 复杂度分析

- 质因数分解 $b$ ： $O(\sqrt{b})$ ，由于 $b \le 10000$ ，很快。
- 对每个质因子 $p$ ，计算 $\text{exp}_p(F_2(n))$ ：循环 $k$ 从 $1$ 到 $p^k \le n$ ，即 $O(\log_p n)$ 次，每次 $O(1)$ 。
- 总复杂度： $O(k \cdot \log n)$ ，其中 $k$ 为 $b$ 的质因子个数（最多约 $4$ 个），对于 $2000$ 个测试用例完全可接受。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 质因数分解
vector<pair<int, long long>> primeFactorization(int x) {
    vector<pair<int, long long>> f;
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) {
            long long cnt = 0;
            while (x % i == 0) cnt++, x /= i;
            f.push_back({i, cnt});
        }
    }
    if (x > 1) f.push_back({x, 1});
    return f;
}

// 计算 F2(n) 中质因子 p 的总指数
long long computeTotalExponent(int n, int p) {
    long long total = 0, pk = p;
    while (pk <= n) {
        long long M = n / pk;
        long long L = n - M * pk + 1;
        if (M > 0) {
            // 第一部分：q=1..M-1
            if (M > 1) {
                long long part1 = pk * M * (M - 1) / 2 * (2 * (n + 1) - (pk - 1)) / 2;
                long long part2 = pk * pk * M * (M - 1) * (2 * M - 1) / 6;
                total += part1 - part2;
            }
            // 第二部分：q=M
            total += M * L * (L + 1) / 2;
        }
        if (pk > n / p) break;
        pk *= p;
    }
    return total;
}

int main() {
    int n, b;
    while (cin >> n >> b && b) {
        auto factors = primeFactorization(b);
        long long answer = LLONG_MAX;
        for (auto& [p, expB] : factors) {
            if (p > n) {
                answer = 0;
                break;
            }
            long long totalExp = computeTotalExponent(n, p);
            answer = min(answer, totalExp / expB);
        }
        cout << answer << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于将 $b$ 进制下末尾零的问题转化为质因子指数的问题，并通过数学推导得到高效的计算公式。 直接暴力计算会导致超时，而使用上述 $O(\log n)$ 的公式可以在规定时间内完成所有测试用例。
