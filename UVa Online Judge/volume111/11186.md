## 题目描述

给定 $N$ 个位于圆心在原点的圆周上的互不相同的点，所有点都在同一个圆上，半径为 $R$。由于这些点都在同一个圆上，所以任意三点不共线，因此任意三个点都能构成一个有效的三角形。需要计算所有可能的 $C(N,3)$ 个三角形的面积之和。

**输入格式**：
- 多组数据，最多 $16$ 组
- 每组数据第一行包含两个整数 $N$ ($0 \leq N \leq 500$) 和 $R$ ($0 < R \leq 100$)
- 接下来 $N$ 行，每行一个浮点数 $\theta$ ($0.0 \leq \theta < 360.0$)，表示点的角度（度数）
- 输入以 $N = 0$ 且 $R = 0$ 结束

**输出格式**：
- 对于每组数据，输出一个整数，表示所有三角形面积之和（四舍五入到最接近的整数）

## 题目分析

### 问题难点

1. **数据规模**：$N$ 最大为 $500$，直接三重循环计算所有三角形面积的时间复杂度为 $O(N^3)$，会达到 $1.25 \times 10^8$ 次计算，在时间限制内难以通过。

2. **几何计算**：需要高效计算所有三角形的面积之和，而不是单个三角形的面积。

3. **精度处理**：结果需要四舍五入到整数，需要注意浮点数精度问题。

### 关键观察

对于圆上的三角形面积计算，有一个重要的数学性质：三角形面积与弦的位置和相对角度有关。我们可以通过**固定弦**的方法来优化计算。

## 解题思路

### 数学原理

对于圆上的三点 $A, B, C$，三角形 $ABC$ 的面积可以用有向面积公式表示：

$$
\texttt{Area}_{ABC} = \frac{R^2}{2} \left[ \sin(\theta_B - \theta_A) + \sin(\theta_C - \theta_B) + \sin(\theta_A - \theta_C) \right]
$$

当我们固定一条弦 $(i,j)$ 时，可以分析所有以该弦为边的三角形的面积贡献。

### 核心算法

1. **弦的贡献分析**：
   - 对于每条弦 $(i,j)$，它将圆分成两段弧：劣弧（角度小于 $180^\circ$）和优弧（角度大于 $180^\circ$）
   - 在劣弧侧的点构成的三角形面积为正，在优弧侧的点构成的三角形面积为负
   - 但实际面积是绝对值，所以劣弧侧和优弧侧的贡献都要考虑

2. **向量判断法**：
   - 使用向量叉积来判断点位于弦的哪一侧
   - 对于弦 $(i,j)$，计算法向量指向劣弧侧
   - 对于其他点 $k$，通过点积判断其位于法向量的哪一侧

3. **面积计算公式**：
   - 对于弦 $(i,j)$，设劣弧侧点数为 $m$，优弧侧点数为 $M$
   - 该弦对总面积的贡献为：$\sin(\theta_j - \theta_i) \times (m - M) \times \frac{R^2}{2}$
   - 其中 $m + M = N - 2$（排除点 $i$ 和 $j$）

### 算法步骤

1. 将输入的角度转换为弧度并排序
2. 预计算所有点的笛卡尔坐标
3. 对于每对点 $(i,j)$（$i < j$）：
   - 计算弦对应的圆心角（取 $[0, \pi]$ 范围内的值）
   - 确定指向劣弧侧的法向量方向
   - 统计在劣弧侧的点数 $m$
   - 计算该弦的贡献并累加
4. 输出四舍五入后的结果

### 时间复杂度

- 排序：$O(N \log N)$
- 双重循环：$O(N^2)$
- 总时间复杂度：$O(N^2)$，对于 $N = 500$ 完全可行

### 空间复杂度

- $O(N)$，用于存储点的坐标信息

```cpp
// Circum Triangle

#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <iomanip>

using namespace std;

const double PI = 2.0 * acos(0.0);

double degToRad(double deg) {
    return deg * PI / 180.0;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int pointCount;
    double radius;
    while (cin >> pointCount >> radius && (pointCount != 0 || radius != 0)) {
        vector<double> angles(pointCount);
        for (int i = 0; i < pointCount; ++i) {
            cin >> angles[i];
        }
        
        if (pointCount < 3) {
            cout << "0\n";
            continue;
        }
        
        vector<double> radians(pointCount);
        for (int i = 0; i < pointCount; ++i) {
            radians[i] = degToRad(angles[i]);
        }
        sort(radians.begin(), radians.end());
        
        vector<double> xCoord(pointCount), yCoord(pointCount);
        for (int i = 0; i < pointCount; ++i) {
            xCoord[i] = cos(radians[i]);
            yCoord[i] = sin(radians[i]);
        }
        
        double totalArea = 0.0;
        
        for (int i = 0; i < pointCount; ++i) {
            for (int j = i + 1; j < pointCount; ++j) {
                double angleIJ = radians[j] - radians[i];
                if (angleIJ > PI) angleIJ = 2 * PI - angleIJ;
                
                double xi = xCoord[i], yi = yCoord[i];
                double xj = xCoord[j], yj = yCoord[j];
                
                // 选择指向劣弧侧的法向量
                double normalX, normalY;
                double rawAngle = radians[j] - radians[i];
                if (rawAngle > 0 && rawAngle <= PI) {
                    normalX = yi - yj;
                    normalY = xj - xi;
                } else {
                    normalX = yj - yi;
                    normalY = xi - xj;
                }
                
                int minorArcCount = 0;
                for (int k = 0; k < pointCount; ++k) {
                    if (k == i || k == j) continue;
                    
                    double xk = xCoord[k], yk = yCoord[k];
                    double deltaX = xk - xi, deltaY = yk - yi;
                    
                    if (deltaX * normalX + deltaY * normalY > 0) {
                        minorArcCount++;
                    }
                }
                
                int majorArcCount = (pointCount - 2) - minorArcCount;
                totalArea += sin(angleIJ) * (minorArcCount - majorArcCount);
            }
        }
        
        totalArea = totalArea * radius * radius / 2.0;
        cout << fixed << setprecision(0) << totalArea << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于发现圆上三角形面积计算的几何性质，通过固定弦的方法将三重循环优化为双重循环。使用向量运算准确判断点的相对位置，避免了复杂的角度计算。算法的时间复杂度为 $O(N^2)$，能够高效处理最大数据规模。
