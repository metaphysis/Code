[UVa 11190 Series of Powers](https://blog.csdn.net/metaphysis/article/details/161947775)

## 题目描述

本题定义幂级数求和如下：

$$
S(l, h, k) = l^k + (l + 1)^k + (l + 2)^k + \ldots + (h - 1)^k + h^k
$$

给定 $l$、$h$ 和 $k$ 的值，要求计算 $S(l, h, k)$ 的值，并以科学计数法输出。

## 输入格式

输入文件包含大约 $1500$ 行。每行包含三个整数 $l$、$h$（$0 \leq l \leq h \leq 15000000$ 且 $|l - h| \leq 1000$）和 $k$（$1 \leq k \leq 15000000$）。输入以一行三个 $-1$ 结束。

## 输出格式

对于每一行输入，输出一行。该行包含输出序号（宽度为 $4$，前置补零）以及 $S(l, h, k)$ 的近似值。该近似值的格式应为：`0.dddddde` 后跟 $10$ 位指数（前置补零）。尾数值始终小于 $1$，小数点后有 $6$ 位数字。如果指数值不影响数值（即和为 $0$），则将其设为 $1$。尾数的微小精度误差（小于 $10^{-4}$）是允许的。

## 样例

输入

```
1 10 10
10 15 100
-1 -1 -1
```

输出

```
Case 0001: 0.149143e0000000011
Case 0002: 0.406971e0000000118
```

## 题目分析

本题的核心是计算从 $l$ 到 $h$ 的整数的 $k$ 次幂之和，但数据范围非常大：$l$、$h$、$k$ 均可达到 $1.5 \times 10^7$。若直接计算 $n^k$，结果会溢出 $64$ 位整数，也无法用常规浮点数存储。

然而，题目给出了一个关键约束：$|l - h| \leq 1000$。这意味着求和项数最多只有 $1001$ 项。因此，我们不能直接计算幂值，而需要一种能够处理极大或极小数值的方法。

### 数值表示方式

科学计数法是一种合适的表示方式：将每个 $n^k$ 表示为 $M \times 10^{E}$，其中 $1 \leq M < 10$，$E$ 为整数。这样，我们可以将对数值的计算转化为浮点运算，然后通过指数对齐进行求和。

### 核心难点

1. **指数对齐**：不同项的数量级可能相差极大，直接相加时小数量级项会被大数量级项淹没。需要将所有项按最大指数对齐，再进行尾数求和。
2. **精度控制**：题目允许 $10^{-4}$ 的尾数误差，这为浮点运算提供了容错空间。
3. **边界情况**：当 $l = h = 0$ 且 $k \geq 1$ 时，和为 $0$，此时指数应设为 $1$。

## 解题思路

### 对数分离法

对于每个 $n = l + i$（$0 \leq i \leq h - l$），计算：

$$
\log_{10}(n^k) = k \cdot \log_{10}(n)
$$

设 $x = k \cdot \log_{10}(n)$，则：

$$
E = \lfloor x \rfloor, \quad M = 10^{x - E}
$$

此时 $M$ 满足 $1 \leq M < 10$。

### 指数对齐求和

设所有项的最大指数为 $E_{\max}$。对于第 $j$ 项，其指数为 $E_j$，尾数为 $M_j$，则对齐后的贡献为：

$$
M_j \times 10^{E_j - E_{\max}}
$$

将所有贡献相加得到累加尾数 $S$：

$$
S = \sum_{j} M_j \times 10^{E_j - E_{\max}}
$$

### 归一化

累加后的 $S$ 可能不在 $[1, 10)$ 范围内。通过不断除以 $10$（同时 $E_{\max}$ 加 $1$）或乘以 $10$（同时 $E_{\max}$ 减 $1$），将 $S$ 调整到 $[0.1, 1)$ 区间，以满足输出格式“尾数小于 $1$”的要求。

### 零值处理

若累加后 $S$ 接近 $0$（如 $l = h = 0$ 时），直接输出 `0.000000e0000000001`，指数固定为 $1$。

### 复杂度分析

- 每项的计算：一次对数、一次幂运算、一次取整，均为 $O(1)$。
- 项数最多 $1001$，因此单次查询的时间复杂度为 $O(h - l)$。
- 总查询约 $1500$ 组，总操作量约为 $1.5 \times 10^6$ 次浮点运算，完全可行。

## 代码实现

```cpp
// Series of Powers
// UVa ID: 11190
// Verdict: Accepted
// Submission Date: 2026-06-13
// UVa Run Time: 0.040s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int l, h, k, caseNo = 0;
    while (scanf("%d %d %d", &l, &h, &k) == 3) {
        if (l == -1 && h == -1 && k == -1) break;
        ++caseNo;

        // 存储每项的尾数和指数（科学计数法）
        vector<pair<double, int>> terms;
        int maxExp = -1e9;
        bool allZero = true;

        for (int i = l; i <= h; ++i) {
            if (i == 0) {
                // 0^k = 0，当 k > 0 时
                terms.push_back({0.0, 0});
                if (0 > maxExp) maxExp = 0;
                continue;
            }
            allZero = false;
            double logVal = k * log10(i);
            int expPart = floor(logVal);
            double mantissa = pow(10, logVal - expPart);
            // mantissa 在 [1, 10)
            if (mantissa >= 10.0) {
                mantissa /= 10.0;
                expPart++;
            }
            terms.push_back({mantissa, expPart});
            if (expPart > maxExp) maxExp = expPart;
        }

        // 如果所有项都是 0（即 l = h = 0）
        if (allZero && l == 0 && h == 0) {
            printf("Case %04d: 0.000000e0000000001\n", caseNo);
            continue;
        }

        // 对齐到 maxExp 并求和
        double sumMantissa = 0.0;
        for (auto& term : terms) {
            if (term.first == 0.0) continue;
            int expDiff = maxExp - term.second;
            sumMantissa += term.first * pow(10, -expDiff);
        }

        // 如果和为 0
        if (fabs(sumMantissa) < 1e-12) {
            printf("Case %04d: 0.000000e0000000001\n", caseNo);
            continue;
        }

        // 归一化尾数到 [0.1, 1)
        int finalExp = maxExp;
        while (sumMantissa >= 1.0) {
            sumMantissa /= 10.0;
            finalExp++;
        }
        while (sumMantissa > 0 && sumMantissa < 0.1) {
            sumMantissa *= 10.0;
            finalExp--;
        }

        // 输出，尾数保留6位小数
        printf("Case %04d: 0.%06de%010d\n", caseNo, (int)round(sumMantissa * 1e6), finalExp);
    }
    return 0;
}
```

## 总结

本题的解题技巧主要体现在以下几个方面：

1. **利用对数降维**：将巨大的幂运算转化为对数乘法，再用指数还原，有效避开了数值溢出。
2. **科学计数法对齐**：通过指数对齐实现不同数量级浮点数的累加，这是处理超大/超小数值的标准方法。
3. **浮点精度容忍**：题目明确允许 $10^{-4}$ 的尾数误差，降低了实现难度，只需注意归一化过程中的舍入即可。
4. **边界处理**：对 $0$ 的幂、和为 $0$ 的情况进行特殊处理，确保输出格式正确。

本题是一个典型的“数值过大无法直接计算”的问题，通过科学计数法和对数技巧，将问题转化为可浮点计算的形式。掌握这种技巧对于处理类似问题（如求大数幂的和、积等）非常有帮助。
