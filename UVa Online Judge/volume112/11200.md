## 题目描述

在遥远的 $\texttt{Omicron Persei 8}$ 行星上，有一个被腐烂黑水海洋包围的 $\texttt{Nevreturn}$ 岛，岛上建有一个复杂迷宫。$\texttt{Omicronian}$ 囚犯被送到这里，只有成功逃出迷宫的人才能获得"仁慈的死亡"。迷宫周围是深渊，里面住着半蛙半牛的 $\texttt{Sapitaur}$，它会吃掉所有在迷宫中走错路的囚犯。

迷宫由 $N \times M$ 的单元格矩阵组成，每个单元格有两种类型：

- **$\texttt{NOWSE}$**（用字符 `\` 表示）：墙壁从西北（左上）延伸到东南（右下）
- **$\texttt{NESOW}$**（用字符 `/` 表示）：墙壁从东北（右上）延伸到西南（左下）

迷宫的入口在北边（第一行），出口在南边（最后一行），深渊位于迷宫两侧（第一列之前和最后一列之后）。

你需要计算从入口到出口的不同路径数量，路径不能穿过深渊。

**输入格式**：
- 第一行：整数 $M$，表示测试用例数量
- 每个测试用例：
  - 第一行：两个整数 $N$ $M$（$1 \leq N, M \leq 500$），$N$ 是宽度（列数），$M$ 是高度（行数）
  - 接下来 $M$ 行：每行 $N$ 个字符（`\` 或 `/`）

**输出格式**：
- 每个测试用例输出一个整数，表示不同路径数量

## 题目分析

### 单元格连通性分析

理解两种单元格类型的连通性是解决问题的关键：

对于 `\`（$\texttt{NOWSE}$）单元格：
- 从**左边**进入只能去**下方**
- 从**上方**进入只能去**右方** 
- 从**右边**进入只能去**上方**
- 从**下方**进入只能去**左方**

对于 `/`（$\texttt{NESOW}$）单元格：
- 从**左边**进入只能去**上方**
- 从**上方**进入只能去**左方**
- 从**右边**进入只能去**下方**
- 从**下方**进入只能去**右方**

### 关键观察

1. **状态表示**：我们需要跟踪当前位置和进入方向，因为同一个单元格从不同方向进入会导致不同的出口方向。

2. **图建模**：可以将问题建模为在有向图中寻找路径，其中：
   - 节点是三元组 (行, 列, 进入方向)
   - 边由单元格类型决定

3. **边界条件**：
   - 入口：第一行的所有单元格从上方进入
   - 出口：从最后一行的单元格向下离开
   - 深渊：移动到迷宫边界外即进入深渊

## 解题思路

### 算法选择

使用 **广度优先搜索（$\texttt{BFS}$）** 来探索所有可能的路径：

1. **状态定义**：$(r, c, dir)$ 表示当前在单元格 $(r, c)$，从方向 $dir$ 进入
2. **方向编码**：$0$ = 上, $1$ = 右, $2$ = 下, $3$ = 左
3. **状态转移**：根据单元格类型和进入方向计算出口方向，然后移动到相邻单元格
4. **路径计数**：统计从不同入口出发能到达出口的路径数量

### 算法步骤

1. 对于每个测试用例：
   - 读取迷宫布局
   - 初始化访问标记数组
   
2. 对于第一行的每个单元格：
   - 从上方进入该单元格，开始 $\texttt{BFS}$
   - 如果从该入口能到达出口，增加路径计数
   
3. 输出路径数量

### 复杂度分析

- **时间复杂度**：$O(N \times M)$，每个状态最多被访问一次
- **空间复杂度**：$O(N \times M)$，用于存储访问标记和 $\texttt{BFS}$ 队列

```cpp
// Sapitaur's Labyrinth

#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
#include <tuple>
using namespace std;

const int MAX = 505;

int rows, cols;
char grid[MAX][MAX];
bool visited[MAX][MAX][4]; // (r, c, dir)

// 方向: 0=上, 1=右, 2=下, 3=左
int dr[4] = {-1, 0, 1, 0};
int dc[4] = {0, 1, 0, -1};

// 根据单元格类型和进入方向，得到出口方向
int getOutDirection(int dir, char cell) {
    if (cell == '\\') {
        // NOWSE: 左→下, 上→右, 右→上, 下→左
        switch (dir) {
            case 3: return 2; // 左→下
            case 0: return 1; // 上→右
            case 1: return 0; // 右→上
            case 2: return 3; // 下→左
        }
    } else {
        // NESOW: 左→上, 上→左, 右→下, 下→右
        switch (dir) {
            case 3: return 0; // 左→上
            case 0: return 3; // 上→左
            case 1: return 2; // 右→下
            case 2: return 1; // 下→右
        }
    }
    return -1;
}

int bfs() {
    memset(visited, 0, sizeof(visited));
    int pathCount = 0;
    
    // 从第一行每个单元格的上方进入
    for (int startCol = 0; startCol < cols; startCol++) {
        if (visited[0][startCol][0]) continue;
        
        queue<tuple<int, int, int>> q;
        visited[0][startCol][0] = true;
        q.push(make_tuple(0, startCol, 0));
        
        bool reachedExit = false;
        
        while (!q.empty()) {
            auto current = q.front();
            q.pop();
            int r = get<0>(current);
            int c = get<1>(current);
            int inDir = get<2>(current);
            
            int outDir = getOutDirection(inDir, grid[r][c]);
            
            int nr = r + dr[outDir];
            int nc = c + dc[outDir];
            
            // 检查是否到达出口（从最后一行向下离开）
            if (r == rows - 1 && outDir == 2) {
                reachedExit = true;
                continue;
            }
            
            // 检查边界
            if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) {
                continue; // 进入深渊
            }
            
            // 计算进入相邻单元格的方向（与outDir相反）
            int newInDir = (outDir + 2) % 4;
            
            if (!visited[nr][nc][newInDir]) {
                visited[nr][nc][newInDir] = true;
                q.push(make_tuple(nr, nc, newInDir));
            }
        }
        
        if (reachedExit) {
            pathCount++;
        }
    }
    
    return pathCount;
}

int main() {
    int testCases;
    cin >> testCases;
    
    while (testCases--) {
        cin >> cols >> rows;
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                cin >> grid[i][j];
            }
        }
        
        int result = bfs();
        cout << result << endl;
    }
    
    return 0;
}
```

## 总结

本题的关键在于正确理解两种单元格类型的连通性规则，并通过状态（行, 列, 进入方向）来精确跟踪在迷宫中的移动。使用 $\texttt{BFS}$ 可以高效地探索所有可能的路径，同时避免重复访问相同状态。

算法的时间复杂度和空间复杂度都在合理范围内，能够处理题目给出的最大数据规模（$500 \times 500$）。
