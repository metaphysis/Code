## 题目分析

### 问题背景
麻将是一种源自中国的游戏，通常由四名玩家使用类似多米诺骨牌的牌进行游戏。本题中，我们考虑的是**简化版的中国麻将**，只使用 $136$ 张牌（不含花牌），共有 $34$ 种牌型，每种牌型有 $4$ 张。

### 牌型分类
麻将牌分为以下几类：
- **筒子（Dots）**：$1\texttt{T}$ 到 $9\texttt{T}$，共 $9$ 种
- **条子（Bams）**：$1\texttt{S}$ 到 $9\texttt{S}$，共 $9$ 种  
- **万子（Craks）**：$1\texttt{W}$ 到 $9\texttt{W}$，共 $9$ 种
- **风牌（Winds）**：$\texttt{DONG}$、$\texttt{NAN}$、$\texttt{XI}$、$\texttt{BEI}$，共 $4$ 种
- **箭牌（Dragons）**：$\texttt{ZHONG}$、$\texttt{FA}$、$\texttt{BAI}$，共 $3$ 种

总计：$9 \times 3 + 4 + 3 = 34$ 种牌型。

### 胡牌规则
一个标准的胡牌手牌由以下部分组成：
- $1$ 个 **眼（Eyes）**：两张相同的牌
- $4$ 个 **面子（Melds）**：可以是以下两种形式之一：
  - **碰（Pong）**：三张相同的牌
  - **吃（Chow）**：同花色的三张连续数字牌（仅适用于筒子、条子、万子）

### 听牌判断
**听牌（Ready Hand）** 是指手牌有 $13$ 张，只差 $1$ 张牌就能胡牌的状态。我们需要找出所有能让玩家胡牌的那张"听牌"。

### 输入输出格式
**输入**：最多 $50$ 个测试用例，每个用例一行 $13$ 张牌，最后一个用例后跟一个 $0$ 表示结束。

**输出**：对于每个测试用例，输出用例编号和所有听牌（按题目规定的牌型顺序），如果没有听牌则输出 `Not ready`。

## 算法思路

### 核心思想
本题的核心是**听牌检测**，即枚举所有可能的牌，检查加入该牌后是否能组成合法的胡牌牌型。

### 解题步骤
1. **牌型编码**：将 $34$ 种牌型编号为 $0$ 到 $33$，方便处理
2. **胡牌判断**：采用递归方法检查 $14$ 张牌是否能胡牌
   - 先找**眼**（两张相同牌）
   - 剩下的 $12$ 张牌递归判断是否能组成 $4$ 个面子
3. **听牌检测**：枚举所有 $34$ 种牌型，如果当前手牌中该牌数量小于 $4$，则尝试加入一张，然后判断是否能胡牌
4. **结果输出**：按牌型顺序输出所有听牌

### 胡牌判断算法
使用深度优先搜索（$\texttt{DFS}$）来递归判断：
- **找眼**：遍历所有牌型，如果有两张以上相同牌，尝试将其作为眼
- **组面子**：对于剩下的 $12$ 张牌：
  - 先尝试**碰**（三张相同牌）
  - 再尝试**吃**（三张同花色连续数字牌）

### 复杂度分析
- 牌型数量：$34$ 种
- 听牌检测需要枚举 $34$ 种可能的听牌
- 每次胡牌判断最坏情况下需要遍历所有可能的眼和面子组合
- 由于牌的数量固定为 $14$ 张，实际运行效率可以接受

```cpp
// Chinese Mahjong

#include <bits/stdc++.h>

using namespace std;

// 牌型映射表
string tiles[34] = {
    "1T", "2T", "3T", "4T", "5T", "6T", "7T", "8T", "9T",
    "1S", "2S", "3S", "4S", "5S", "6S", "7S", "8S", "9S",
    "1W", "2W", "3W", "4W", "5W", "6W", "7W", "8W", "9W",
    "DONG", "NAN", "XI", "BEI", "ZHONG", "FA", "BAI"
};

map<string, int> tileToId;  // 牌名到编号的映射

// 初始化牌名映射表
void initializeMap() { for (int i = 0; i < 34; i++) tileToId[tiles[i]] = i; }

// 递归判断剩下的牌能否组成指定数量的面子
bool canMeld(int hand[], int meldsNeeded) {
    if (meldsNeeded == 0) return true;  // 所有面子都已组成
    
    // 尝试碰（三张相同的牌）
    for (int i = 0; i < 34; i++) {
        if (hand[i] >= 3) {
            hand[i] -= 3;
            if (canMeld(hand, meldsNeeded - 1)) {
                hand[i] += 3;
                return true;
            }
            hand[i] += 3;
        }
    }
    
    // 尝试吃（三张同花色连续数字牌）
    for (int i = 0; i <= 24; i++) {  // 只考虑筒子、条子、万子
        if (i % 9 <= 6 && hand[i] >= 1 && hand[i + 1] >= 1 && hand[i + 2] >= 1) {
            hand[i]--; hand[i + 1]--; hand[i + 2]--;
            if (canMeld(hand, meldsNeeded - 1)) {
                hand[i]++; hand[i + 1]++; hand[i + 2]++;
                return true;
            }
            hand[i]++; hand[i + 1]++; hand[i + 2]++;
        }
    }
    
    return false;
}

// 判断当前 14 张牌是否能胡牌
bool canWin(int hand[]) {
    // 枚举所有可能的眼（一对）
    for (int i = 0; i < 34; i++) {
        if (hand[i] >= 2) {
            hand[i] -= 2;  // 取出眼
            if (canMeld(hand, 4)) {  // 判断剩下的 12 张牌能否组成 4 个面子
                hand[i] += 2;
                return true;
            }
            hand[i] += 2;
        }
    }
    return false;
}

int main() {
    initializeMap();  // 初始化牌名映射
    
    string tile;
    int caseNo = 1;
    
    while (true) {
        vector<string> handStr(13);  // 存储输入的 13 张牌
        for (int i = 0; i < 13; i++) {
            cin >> handStr[i];
            if (handStr[i] == "0") return 0;  // 遇到 0 结束程序
        }
        
        int hand[34] = {0};  // 手牌统计数组
        for (const string& t : handStr) hand[tileToId[t]]++;  // 统计每种牌的数量
        
        vector<int> waiting;  // 存储听牌列表
        for (int i = 0; i < 34; i++) {
            if (hand[i] >= 4) continue;  // 该牌已满 4 张，不能再加
            hand[i]++;  // 尝试加入这张牌
            if (canWin(hand)) waiting.push_back(i);  // 如果能胡牌，加入听牌列表
            hand[i]--;  // 回溯
        }
        
        // 输出结果
        cout << "Case " << caseNo++ << ":";
        if (waiting.empty()) {
            cout << " Not ready" << '\n';
        } else {
            for (int id : waiting) cout << " " << tiles[id];  // 输出听牌名称
            cout << '\n';
        }
    }
    
    return 0;
}
```

## 关键点说明

1. **牌型编码**：将字符串牌名映射为数字编号，便于数组操作
2. **递归回溯**：胡牌判断采用递归回溯，尝试所有可能的眼和面子组合
3. **吃牌限制**：只有筒子、条子、万子可以组成吃牌，且数字必须连续
4. **牌数限制**：每种牌最多 $4$ 张，听牌检测时需要跳过已满 $4$ 张的牌型

该算法通过系统的枚举和递归判断，能够准确找出所有可能的听牌，符合题目要求。
