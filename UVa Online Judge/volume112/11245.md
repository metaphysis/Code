## 题目描述

一个反等差数列是指其中不存在长度为 $p$ 的子序列构成等差数列。等差数列是指一个数列中任意连续两项的差是常数。

对于给定的素数 $p$ ，我们按以下方式构造一个无限的反等差数列：

$1$. 序列仅包含正整数且严格递增
$2$. 前 $p-1$ 个数为 $1, 2, \ldots, p-1$
$3$. 之后每次添加最小的数，使得没有长度为 $p$ 的子序列构成等差数列

例如，当 $p = 3$ 时，序列为：$1, 2, 4, 5, 10, 11, 13, 14, 28, 29, \ldots$

给定 $T$ 个测试用例，每个用例包含两个整数 $n$ $(1 \leq n \leq 2 \times 10^{10})$ 和 $p$ $(3 \leq p \leq 30$ 且 $p$ 为素数$)$ ，求该序列的第 $n$ 项的值。保证结果在 64 位有符号整数范围内。

## 输入格式

第一行一个整数 $T$ $(1 \leq T \leq 1000)$ 表示测试用例数。

接下来 $T$ 行，每行两个整数 $n$ 和 $p$ 。

## 输出格式

对于每个测试用例，输出一个整数表示答案。

## 样例输入
```
3
10 3
10 5
100 7
```

## 样例输出
```
29
12
130
```

## 题目分析

### 关键观察与规律发现

首先我们分析 $p = 3$ 时的序列：$1, 2, 4, 5, 10, 11, 13, 14, 28, 29, \ldots$

如果我们尝试寻找序列项 $a_n$ 与 $n$ 之间的数学关系，可以发现一个有趣的模式。让我们计算几个值：

- 当 $n=1$ 时，$a_1=1$
- 当 $n=2$ 时，$a_2=2$
- 当 $n=3$ 时，$a_3=4$
- 当 $n=4$ 时，$a_4=5$
- 当 $n=5$ 时，$a_5=10$
- 当 $n=6$ 时，$a_6=11$
- 当 $n=7$ 时，$a_7=13$
- 当 $n=8$ 时，$a_8=14$
- 当 $n=9$ 时，$a_9=28$
- 当 $n=10$ 时，$a_{10}=29$

观察这些值，我们发现可以通过以下方式计算 $a_n$ ：
$1$. 令 $m = n - 1$
$2$. 将 $m$ 转换为二进制（因为 $p-1=2$）
$3$. 将这个二进制数解释为三进制数
$4$. 结果加 $1$

验证：
- $n=3$：$m=2$，二进制 $10_2$，解释为三进制 $10_3=3$，加 $1$ 得 $4$ ✓
- $n=4$：$m=3$，二进制 $11_2$，解释为三进制 $11_3=4$，加 $1$ 得 $5$ ✓
- $n=10$：$m=9$，二进制 $1001_2$，解释为三进制 $1001_3=1\times27+0\times9+0\times3+1=28$，加 $1$ 得 $29$ ✓

### 数学原理

为什么这种转换能保证不出现长度为 $p$ 的等差数列呢？

#### 核心思想：进制转换与模运算

考虑一个关键的数学事实：如果 $p$ 个不同的数在模 $p$ 意义下构成等差数列，那么它们在每个数位（在 $p$ 进制表示下）上的数字序列也必须满足某种等差关系。

具体来说，对于素数 $p$ ，如果 $p$ 个数 $x_1, x_2, \ldots, x_p$ 构成等差数列，那么在 $p$ 进制的每一位上，这些数的数字序列必须是模 $p$ 的等差数列。由于 $p$ 是素数，这样的序列会遍历所有可能的余数 $0, 1, \ldots, p-1$ 。

#### 构造的巧妙之处

我们的构造方法本质上创建了一个映射：将 $(p-1)$ 进制数映射到 $p$ 进制数。

设 $f(n)$ 是序列的第 $n$ 项，我们有：
$$
f(n) = 1 + \sum_{i=0}^{k} d_i \cdot p^i
$$
其中 $(d_k d_{k-1} \cdots d_0)_{(p-1)}$ 是 $(n-1)$ 的 $(p-1)$ 进制表示。

这个映射的关键特性是：**它不是一个满射**。在 $p$ 进制的每一位上，数字 $d_i$ 的取值范围是 $\{0, 1, \ldots, p-2\}$ ，而不是完整的 $\{0, 1, \ldots, p-1\}$ 。

#### 为什么这样能避免等差数列？

假设存在 $p$ 个数 $f(n_1), f(n_2), \ldots, f(n_p)$ 构成等差数列。考虑它们在 $p$ 进制表示下的最低位（个位）。

由于这些数构成等差数列，它们的个位数字序列在模 $p$ 意义下也是等差数列。对于素数 $p$ ，这样的等差数列会包含所有 $p$ 种可能的余数。也就是说，个位数字必须包含 $0, 1, \ldots, p-1$ 中的所有数字。

但是，根据我们的构造，所有 $f(n)$ 的个位数字都来自集合 $\{0, 1, \ldots, p-2\}$ （因为 $d_0 \in \{0,1,\ldots,p-2\}$ ，且 $f(n)=1+\sum d_i p^i$ 的个位由 $d_0$ 决定）。这个集合的大小只有 $p-1$ ，不可能包含所有 $p$ 种可能的数字。

因此，不可能存在这样的 $p$ 个数构成等差数列。对于更高数位，论证是类似的。

### 算法推导

从上面的分析，我们可以直接得到计算第 $n$ 项的算法：

$1$. 计算 $m = n - 1$
$2$. 将 $m$ 转换为 $(p-1)$ 进制
$3$. 将这个 $(p-1)$ 进制数解释为 $p$ 进制数
$4$. 结果加 $1$

在实现时，我们可以直接计算，不需要显式存储进制转换结果：

- 初始化 $result = 0$ , $base = 1$
- 当 $m > 0$ 时：
  - 取 $digit = m \mod (p-1)$
  - $result = result + digit \times base$
  - $base = base \times p$
  - $m = m / (p-1)$
- 返回 $result + 1$

### 算法正确性证明

**引理 $1$** ：对于素数 $p$ ，如果 $p$ 个数构成等差数列，那么在 $p$ 进制的每一位上，这些数的数字序列必须包含所有 $p$ 种可能的余数。

**证明概要** ：考虑等差数列 $a, a+d, a+2d, \ldots, a+(p-1)d$ 。由于 $p$ 是素数且 $d \neq 0 \pmod{p}$ ，序列 $\{a+kd \pmod{p}\}$ 是 $\{0,1,\ldots,p-1\}$ 的一个排列。

**引理 $2$** ：对于任意 $n$ ，序列项 $f(n)$ 在 $p$ 进制表示下的每一位数字都来自集合 $\{0,1,\ldots,p-2\}$ 。

**证明** ：根据构造，$f(n) = 1 + \sum_{i} d_i p^i$ ，其中 $d_i$ 是 $(n-1)$ 的 $(p-1)$ 进制数字，因此 $d_i \in \{0,1,\ldots,p-2\}$ 。所以 $f(n)$ 在 $p$ 进制下的每一位数字就是相应的 $d_i$ 。

**定理** ：序列 $\{f(n)\}$ 中不存在长度为 $p$ 的等差数列。

**证明** ：假设存在 $p$ 个数 $f(n_1), \ldots, f(n_p)$ 构成等差数列。根据引理 1，在某个数位上，这些数的数字必须包含所有 $p$ 种可能。但根据引理 2，每个 $f(n)$ 在该数位上的数字都 $\leq p-2$ ，矛盾。

因此，我们的构造确实产生了反等差数列，且算法正确计算了第 $n$ 项。

## 代码实现

```cpp
// Anti-Arithmetic-Sequence

// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 计算反等差数列的第n项
long long solve(long long n, int p) {
    if (n == 1) return 1;  // 特殊情况：第一项为1
    
    long long m = n - 1;     // 转换为0-based索引
    long long result = 0;    // 存储结果
    long long base = 1;      // p进制基数
    
    // 将m转换为(p-1)进制，同时解释为p进制数
    while (m > 0) {
        int digit = m % (p - 1);  // 获取(p-1)进制下的当前位
        result += digit * base;   // 按p进制累加到结果
        base *= p;                // 基数乘以p
        m /= (p - 1);            // 移除已处理的位
    }
    
    return result + 1;  // 最终加1得到答案
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    
    while (T--) {
        long long n;
        int p;
        cin >> n >> p;
        cout << solve(n, p) << "\n";
    }
    
    return 0;
}
```

## 复杂度分析

- **时间复杂度** ：$O(T \cdot \log_{p-1} n)$ 。对于每个测试用例， while 循环的次数等于 $n-1$ 的 $(p-1)$ 进制表示的位数，即 $\lceil \log_{p-1} (n) \rceil$ 。由于 $n \leq 2 \times 10^{10}$ 且 $p \geq 3$ ，最大循环次数约为 $\log_2 (2 \times 10^{10}) \approx 35$ 。
- **空间复杂度** ：$O(1)$ ，只使用了常数个变量。

   - $m = 9$
   - $9$ 的二进制（$p-1=2$）为 $1001_2$
   - 解释为三进制：$1\times3^3 + 0\times3^2 + 0\times3^1 + 1\times3^0 = 27+0+0+1=28$

与样例输出完全一致。

## 总结

本题的核心在于发现反等差数列与进制转换之间的巧妙关系。通过将 $n-1$ 转换为 $(p-1)$ 进制，然后将这个 $(p-1)$ 进制数解释为 $p$ 进制数，再加 $1$ ，我们可以直接计算出序列的第 $n$ 项。

这种解法的优美之处在于：
$1$. 它避免了模拟构造序列的 $O(n)$ 复杂度的低效方法
$2$. 它利用了素数 $p$ 的模运算性质，确保了不会出现长度为 $p$ 的等差数列
$3$. 算法的时间复杂度与 $n$ 的对数相关，可以高效处理 $n$ 高达 $2 \times 10^{10}$ 的大数据

这道题展示了数学思维在算法竞赛中的重要性：一个看似需要复杂构造的序列问题，实际上可以通过深入分析其数学本质，转化为简洁高效的进制转换问题。
