## 题目描述

在整个欧洲，我们的基站编号从 $1$ 到 $N$ 目前正在通过无线信道运行。我们急需将 $C$ 个秘密消息片段从总部（基站 $1$）发送到第 $N$ 个基站。德国人已经开发了一种名为 $\texttt{Zämmhätm}$ 的机器，该机器会在基站发送消息片段后干扰该基站之间的频率信道。因此，基站必须为每个消息片段使用不同的频率信道进行传输。

目前，基站之间已经建立了多个单向信道。我们只能在两个基站之间安排一定数量的频率信道。你的任务是检查是否可以在不增加任何两个特定基站之间的频率信道的情况下，将所有消息片段发送到目标基站。如果需要在两个基站之间增加频率信道，你必须给出所有可能的选择。

### 输入格式

输入包含多个测试用例。每个测试用例的第一行包含三个数字 $N$、$E$ 和 $C$，其中：
- $N$ ($0 < N < 101$) 表示基站的数量
- $E$ ($E < 10000$) 表示基站之间可用连接的数量  
- $C$ ($C < 20000000000$) 表示需要从基站 $1$ 发送到基站 $N$ 的秘密消息片段的数量

接下来有 $E$ 行，每行包含 $3$ 个数字：$b_1$、$b_2$ 和 $f_p$，表示从 $b_1$ 到 $b_2$ 当前可用的频率信道数量。

当 $N = E = C = 0$ 时，输入终止。

### 输出格式

对于每个测试用例，输出一行。首先输出用例编号。如果从当前状态可以发送 $C$ 个秘密消息片段，则输出 $\texttt{possible}$。否则，如果通过增加任意一对基站之间的频率信道可以发送所需的消息片段，则输出所有可能的基站对（按升序排列）。如果仍然不可能，则输出 $\texttt{not possible}$。

## 题目分析

这是一个典型的**网络流最大流问题**。我们可以将问题建模如下：

- **节点**：基站，编号从 $1$ 到 $N$
- **边**：基站之间的单向连接，容量为可用的频率信道数
- **源点**：基站 $1$
- **汇点**：基站 $N$
- **目标**：判断从源点到汇点的最大流是否至少为 $C$

### 问题难点

1. **大规模数据**：$C$ 可以达到 $2 \times 10^{10}$，需要使用 $\texttt{long long}$ 类型
2. **高效算法**：$N \leq 100$，$E \leq 10000$，需要高效的网络流算法
3. **边增强分析**：需要找出哪些边的容量增加能够使最大流达到 $C$

### 关键观察

1. **最大流-最小割定理**：网络的最大流等于最小割的容量
2. **边增强的有效性**：只有**最小割中的边**的容量增加才可能增加最大流
3. **优化策略**：只需检查最小割中的边，而不是所有边

## 解题思路

### 算法选择

我们使用 **$\texttt{Dinic}$ 算法** 来计算最大流，因为：
- 时间复杂度为 $O(V^2E)$，对于 $V \leq 100$，$E \leq 10000$ 是可接受的
- 实现相对简单且效率较高

### 解题步骤

1. **构建网络流图**：
   - 将基站作为节点
   - 将连接作为有向边，容量为频率信道数

2. **计算初始最大流**：
   - 如果 $maxFlow \geq C$，输出 $\texttt{possible}$

3. **寻找最小割中的边**：
   - 使用 $\texttt{BFS}$ 从源点标记可达节点
   - 最小割是从可达侧到不可达侧的边集合

4. **检查边增强可能性**：
   - 只对最小割中的边尝试增加容量
   - 对于每条边，快速检查增加 $(C - maxFlow)$ 的容量是否足够
   - 如果足够，将该边加入候选集合

5. **输出结果**：
   - 如果有候选边，按升序输出
   - 否则输出 $\texttt{not possible}$

### 时间复杂度分析

- **$\texttt{Dinic}$ 算法**：$O(V^2E) = O(100^2 \times 10000) = O(10^8)$
- **边增强检查**：最多 $E$ 条边，每次检查一次最大流计算
- **总体复杂度**：在可接受范围内

```cpp
// Frequency Hopping

#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>
#include <climits>
#include <set>
#include <cstring>
#include <map>

using namespace std;

typedef long long ll;

struct Edge {
    int to, rev;
    ll cap, flow;
    int originalFrom, originalTo;
};

class Dinic {
private:
    int n;
    vector<vector<Edge>> graph;
    vector<int> level, ptr;

    bool bfs(int s, int t) {
        level.assign(n, -1);
        queue<int> q;
        q.push(s);
        level[s] = 0;
        while (!q.empty() && level[t] == -1) {
            int u = q.front();
            q.pop();
            for (Edge &e : graph[u]) {
                if (level[e.to] == -1 && e.flow < e.cap) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] != -1;
    }

    ll dfs(int u, int t, ll pushed) {
        if (u == t || pushed == 0) return pushed;
        for (int &cid = ptr[u]; cid < graph[u].size(); ++cid) {
            Edge &e = graph[u][cid];
            if (level[e.to] == level[u] + 1 && e.flow < e.cap) {
                ll tr = dfs(e.to, t, min(pushed, e.cap - e.flow));
                if (tr > 0) {
                    e.flow += tr;
                    graph[e.to][e.rev].flow -= tr;
                    return tr;
                }
            }
        }
        return 0;
    }

public:
    Dinic(int n) : n(n), graph(n), level(n), ptr(n) {}

    void addEdge(int from, int to, ll cap, int originalFrom, int originalTo) {
        graph[from].push_back({to, (int)graph[to].size(), cap, 0, originalFrom, originalTo});
        graph[to].push_back({from, (int)graph[from].size() - 1, 0, 0, originalFrom, originalTo});
    }

    ll maxFlow(int s, int t) {
        ll totalFlow = 0;
        while (bfs(s, t)) {
            ptr.assign(n, 0);
            while (ll pushed = dfs(s, t, LLONG_MAX)) {
                totalFlow += pushed;
            }
        }
        return totalFlow;
    }

    void resetFlow() {
        for (int i = 0; i < n; i++) {
            for (Edge &e : graph[i]) {
                e.flow = 0;
            }
        }
    }

    vector<pair<int, int>> getMinCutEdges(int s) {
        vector<pair<int, int>> minCutEdges;
        vector<bool> visited(n, false);
        queue<int> q;
        q.push(s);
        visited[s] = true;
        
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (Edge &e : graph[u]) {
                if (!visited[e.to] && e.flow < e.cap) {
                    visited[e.to] = true;
                    q.push(e.to);
                }
            }
        }

        for (int u = 1; u < n; u++) {
            if (visited[u]) {
                for (Edge &e : graph[u]) {
                    if (e.cap > 0 && !visited[e.to] && e.originalFrom != -1) {
                        minCutEdges.push_back(make_pair(e.originalFrom, e.originalTo));
                    }
                }
            }
        }

        return minCutEdges;
    }

    void updateCapacity(int from, int to, ll newCap) {
        for (Edge &e : graph[from]) {
            if (e.to == to && e.cap > 0) {
                e.cap = newCap;
                return;
            }
        }
    }

    ll getCapacity(int from, int to) {
        for (Edge &e : graph[from]) {
            if (e.to == to && e.cap > 0) {
                return e.cap;
            }
        }
        return 0;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int caseNum = 1;
    int n, e;
    ll c;
    
    while (cin >> n >> e >> c, n != 0 || e != 0 || c != 0) {
        Dinic dinic(n + 1);
        
        map<pair<int, int>, ll> originalEdges;
        
        for (int i = 0; i < e; i++) {
            int b1, b2, fp;
            cin >> b1 >> b2 >> fp;
            dinic.addEdge(b1, b2, fp, b1, b2);
            originalEdges[make_pair(b1, b2)] = fp;
        }

        cout << "Case " << caseNum++ << ": ";
        
        ll maxFlow = dinic.maxFlow(1, n);
        
        if (maxFlow >= c) {
            cout << "possible\n";
            continue;
        }

        vector<pair<int, int>> minCutEdges = dinic.getMinCutEdges(1);
        set<pair<int, int>> options;

        for (auto &edge : minCutEdges) {
            int u = edge.first;
            int v = edge.second;
            ll originalCap = originalEdges[make_pair(u, v)];
            
            dinic.resetFlow();
            dinic.updateCapacity(u, v, originalCap + (c - maxFlow));
            ll newFlow = dinic.maxFlow(1, n);
            dinic.updateCapacity(u, v, originalCap);
            
            if (newFlow >= c) {
                options.insert(make_pair(u, v));
            }
        }

        if (!options.empty()) {
            cout << "possible option:";
            bool first = true;
            
            vector<pair<int, int>> sortedOptions(options.begin(), options.end());
            sort(sortedOptions.begin(), sortedOptions.end());
            
            for (auto &p : sortedOptions) {
                if (!first) cout << ",";
                cout << "(" << p.first << "," << p.second << ")";
                first = false;
            }
            cout << "\n";
        } else {
            cout << "not possible\n";
        }
    }

    return 0;
}
```

## 总结

本题是一个典型的网络流应用问题，主要考察：
1. **网络流建模能力**：将实际问题转化为图论模型
2. **最大流算法**：熟练掌握 $\texttt{Dinic}$ 算法
3. **最小割理论**：理解最大流-最小割定理及其应用
4. **优化技巧**：通过只检查最小割中的边来减少计算量

关键优化点在于利用最小割的性质，避免对所有边进行不必要的检查，这在边数较多时能显著提高效率。
