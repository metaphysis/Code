[UVa 11256 Repetitive Multiple](https://blog.csdn.net/metaphysis/article/details/157102344)

## 题目描述

如果一个整数可以写成另一个不以零开头的整数的多个（至少两个）副本的拼接，则称其为 **重复整数** 。例如， $11$ 、 $123123$ 、 $454545$ 都是重复整数。

注意：不允许以零开头的整数，因此 $101$ 不能视为 $0101$ ，所以 $101$ 不是重复整数。

给定一个正整数 $n$ ，求最小的重复整数且是 $n$ 的倍数。

### 输入格式

输入以整数 $N$ （ $\leq 100$ ）开始，表示测试用例的数量。接下来每行一个正整数 $n$ ，其中 $n < 10^{9}$ 。

### 输出格式

对于每个测试用例，在一行中输出 $n$ 的最小重复倍数。

### 样例输入

```
5
7
101
123
999999
6339673
```

### 样例输出

```
77
1010
33333
999999
114114114
```

## 题目分析

### 重复整数的数学表示

设重复整数的 **重复单元** 为 $base$ ，其十进制位数为 $len$ ，重复次数为 $k$ （ $k \ge 2$ ），则该重复整数可以表示为：

$$
R = base \times \frac{10^{k \cdot len} - 1}{10^{len} - 1}
$$

其中 $base$ 是一个 $len$ 位数，且不以零开头（即 $10^{len-1} \le base \le 10^{len} - 1$ ）。

### 问题转化

我们需要找到最小的 $R$ ，使得 $R$ 是 $n$ 的倍数，即 $R \equiv 0 \pmod{n}$ 。

代入上式，得到：

$$
base \times \frac{10^{k \cdot len} - 1}{10^{len} - 1} \equiv 0 \pmod{n}
$$

设 $y = \frac{10^{totalLen} - 1}{10^{len} - 1}$ ，其中 $totalLen = k \cdot len$ 是重复整数的总位数。则条件简化为：

$$
base \times y \equiv 0 \pmod{n}
$$

### 关键观察

1. **长度的限制** ：  
   如果将 $n$ 本身重复一次（即两个 $n$ 拼接），得到的数一定是重复数且是 $n$ 的倍数。因此，最小的重复倍数长度不会超过 $2L$ ，其中 $L$ 是 $n$ 的位数。  
   同时，如果 $n$ 本身就是重复数，那么答案就是 $n$ 本身。  
   因此，我们只需要搜索总位数 $totalLen$ 在 $[L, 2L]$ 之间。

2. **数学推导** ：  
   由 $base \times y \equiv 0 \pmod{n}$ ，设 $g = \gcd(y, n)$ ，则：
   - 令 $n_1 = n / g$ ， $y_1 = y / g$ （此时 $y_1$ 与 $n_1$ 互质）
   - 条件变为 $base \times y_1 \equiv 0 \pmod{n_1}$  
   - 由于 $\gcd(y_1, n_1) = 1$ ，必有 $base \equiv 0 \pmod{n_1}$  

   因此， $base$ 必须是 $n_1$ 的倍数。

3. **寻找最小的 $base$** ：  
   对于给定的 $len$ 和 $totalLen$ （即给定的 $y$ 和 $k$ ），我们需要找满足以下条件的 $len$ 位数 $base$ ：
   - $base$ 是 $n_1$ 的倍数
   - $10^{len-1} \le base \le 10^{len} - 1$  

   最小的 $base$ 可以通过上取整除法直接计算：
   $$
   base = \left\lceil \frac{10^{len-1}}{n_1} \right\rceil \times n_1
   $$
   若 $base \le 10^{len} - 1$ ，则找到一组解。

### 算法步骤

1. 计算 $n$ 的位数 $L$ 。
2. 枚举总位数 $totalLen$ 从 $L$ 到 $2L$ （从小到大，保证找到最小解）。
3. 对于每个 $totalLen$ ，枚举其因子 $len$ （ $1 \le len \le totalLen/2$ ），使得 $k = totalLen / len \ge 2$ 。
4. 对于每组 $(len, k)$ ：
   - 计算 $y = (10^{totalLen} - 1) / (10^{len} - 1)$
   - 计算 $g = \gcd(y, n)$ ， $n_1 = n / g$
   - 计算最小 $len$ 位数 $least = 10^{len-1}$
   - 计算 $base = \lceil least / n_1 \rceil \times n_1$
   - 若 $base \le 10^{len} - 1$ ，则构造重复数 $R$ （将 $base$ 重复 $k$ 次拼接）
   - 更新最小解
5. 一旦找到解，立即退出（因为 $totalLen$ 从小到大枚举，第一个找到的解就是最小的）。

### 复杂度分析

- 枚举 $totalLen$ ：最多 $L+1$ 个值（ $L \le 9$ ，因为 $n < 10^9$ ）
- 对于每个 $totalLen$ ，枚举其因子 $len$ ：最多 $O(\sqrt{totalLen})$ 个
- 每个 $(len, k)$ 的计算都是 $O(1)$ 的
- 总复杂度极低，可以轻松处理 $100$ 个测试用例

### 注意事项

- 使用整数幂函数计算 $10^x$ ，避免浮点误差
- 使用 `__gcd` 计算最大公约数
- 字符串拼接构造重复数，避免大数计算

## 代码实现

```cpp
// Repetitive Multiple
// UVa ID: 11256
// Verdict: Accepted
// Submission Date: 2026-01-18
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

string solve(ll n) {
    // 计算 n 的位数 L
    int L = to_string(n).size();
    string best; // 存储最小解
    // 枚举总位数 totalLen，从 L 到 2L
    for (int x = L; x <= 2 * L; x++) {
        // 枚举重复单元的长度 len
        for (int y = 1; y <= x / 2; y++) {
            if (x % y != 0) continue; // len 必须是 totalLen 的因子
            int k = x / y; // 重复次数
            if (k < 2) continue; // 至少重复两次
            // 计算 y = (10^totalLen - 1) / (10^len - 1)
            ll z = (pow(10, x) - 1) / (pow(10, y) - 1);
            // 计算 n1 = n / gcd(y, n)
            ll nn = n / __gcd(n, z);
            // len 位数的范围
            ll least = pow(10, y - 1);      // 最小 len 位数
            ll greatest = pow(10, y) - 1;   // 最大 len 位数
            // 计算最小的 base = ceil(least / nn) * nn
            ll base = ((least + nn - 1) / nn) * nn;
            if (base > greatest) continue; // base 超出范围
            // 构造重复数：将 base 重复 k 次拼接
            string s;
            for (int i = 0; i < k; i++) s += to_string(base);
            // 更新最小解（字符串比较即数值比较）
            if (best.empty() || s < best) best = s;
        }
        // 一旦找到解就退出，因为 totalLen 从小到大枚举
        if (best.size()) break;
    }
    return best;
}

int main() {
    int N;
    cin >> N;
    while (N--) {
        ll n;
        cin >> n;
        cout << solve(n) << '\n';
    }
    return 0;
}
```
## 总结

本题的关键在于将问题转化为数学表达式，并通过数论知识简化条件。利用重复倍数长度不超过 $2L$ 的性质，将搜索范围大幅缩小。通过最大公约数的分解，直接计算满足条件的最小 $base$ ，从而高效找到答案。

算法时间复杂度极低，可以轻松处理所有测试用例，是一道结合数论和构造的好题目。
