[UVa 11260 Odd Root Sum](https://blog.csdn.net/metaphysis/article/details/155257559)

## 题目描述

给定一个 $64$ 位有符号整数 $n$，要求计算以下表达式对 $100000000$ 取模的结果：

$$
[\sqrt{1}] + [\sqrt{3}] + [\sqrt{5}] + \ldots + [\sqrt{2i-1}] + \ldots + [\sqrt{m}]
$$

其中 $m$ 是不超过 $n$ 的最大奇数，$[x]$ 表示对 $x$ 向下取整。

换句话说，需要计算：

$$
S = \left([\sqrt{1}] + [\sqrt{3}] + [\sqrt{5}] + \ldots + [\sqrt{m}]\right) \bmod 100000000
$$

**输入格式**
- 输入最多包含 $30000$ 行
- 每行包含一个 $64$ 位有符号整数 $n$
- 输入以单个 $0$ 结束，不应处理该行

**输出格式**
- 对于每个输入行，输出一行结果 $S$

## 题目分析

### 问题本质

我们需要计算所有不超过 $n$ 的奇数的平方根向下取整之和。直接遍历每个奇数并计算平方根对于大 $n$（如 $10^7$）会超时，因为时间复杂度为 $O(n)$。

### 关键观察

1. **平方根的分段特性**：对于任意整数 $k$，所有满足 $k^2 \leq x < (k+1)^2$ 的 $x$，其平方根向下取整都是 $k$

2. **奇数分布规律**：在区间 $[k^2, (k+1)^2)$ 内，奇数的个数有规律：
   - 当 $k$ 为奇数时，区间内奇数个数为 $k+1$
   - 当 $k$ 为偶数时，区间内奇数个数为 $k$

3. **数学优化**：我们可以按 $k$ 的值分组计算，而不是逐个计算每个奇数

### 解题思路

1. **确定范围**：首先找到不超过 $n$ 的最大奇数 $m$

2. **确定最大 $k$ 值**：计算 $K = \lfloor \sqrt{m} \rfloor$

3. **分组计算**：
   - 对于 $k = 1$ 到 $K-1$，计算每个完整区间 $[k^2, (k+1)^2)$ 内奇数的贡献
   - 对于最后一个不完整区间 $[K^2, m]$，单独计算

4. **数学公式**：
   - 前 $K-1$ 个完整区间的和可以通过数学公式直接计算
   - 最后一个区间通过计算区间内奇数个数乘以 $K$ 得到

5. **防止溢出**：使用 `__int128` 处理中间计算结果，避免溢出

## 算法实现

### 核心公式推导

对于前 $K-1$ 个完整区间：

设：
- $\texttt{oddCount} = \lfloor K/2 \rfloor$（奇数 $k$ 的个数）
- $\texttt{evenCount} = \lfloor (K-1)/2 \rfloor$（偶数 $k$ 的个数）

则总贡献为：
- 奇数 $k$ 的贡献：$\sum_{i=1}^{\texttt{oddCount}} ((2i-1)^2 + (2i-1)) = 4\sum i^2 - 2\sum i$
- 偶数 $k$ 的贡献：$\sum_{i=1}^{\texttt{evenCount}} (2i)^2 = 4\sum i^2$

### 复杂度分析

- **时间复杂度**：$O(1)$，每组输入只需常数时间计算
- **空间复杂度**：$O(1)$，只使用常数个变量

```cpp
// Odd Root Sum
// UVa ID: 11260

#include <bits/stdc++.h>
using namespace std;

const long long MOD = 100000000;

long long calculateSum(long long n) {
    if (n <= 0) return 0;
    long long m = (n % 2 == 1) ? n : n - 1;  // 不超过n的最大奇数
    if (m < 1) return 0;
    
    long long K = sqrt(m);
    __int128 result = 0;
    
    // 计算前K-1个完整区间
    if (K > 1) {
        __int128 oddCount = K / 2;      // 奇数k的个数：1,3,5,...,≤K-1
        __int128 evenCount = (K - 1) / 2;  // 偶数k的个数：2,4,6,...,≤K-1
        
        // 奇数k的贡献：Σ((2i-1)² + (2i-1)) = 4Σi² - 2Σi
        if (oddCount > 0) {
            // Σi = oddCount * (oddCount + 1) / 2
            __int128 sumI = oddCount * (oddCount + 1) / 2;
            // Σi² = oddCount * (oddCount + 1) * (2 * oddCount + 1) / 6
            __int128 sumI2 = oddCount * (oddCount + 1) * (2 * oddCount + 1) / 6;
            
            __int128 oddContrib = 4 * sumI2 - 2 * sumI;
            result += oddContrib;
        }
        
        // 偶数k的贡献：Σ(2i)² = 4Σi²
        if (evenCount > 0) {
            // Σi² = evenCount * (evenCount + 1) * (2 * evenCount + 1) / 6
            __int128 sumJ2 = evenCount * (evenCount + 1) * (2 * evenCount + 1) / 6;
            
            __int128 evenContrib = 4 * sumJ2;
            result += evenContrib;
        }
    }
    
    // 处理最后一个区间[K², m]
    long long start = K * K;
    if (start <= m) {
        long long firstOdd = (start % 2 == 1) ? start : start + 1;  // 区间内第一个奇数
        if (firstOdd <= m) {
            long long lastOdd = (m % 2 == 1) ? m : m - 1;  // 区间内最后一个奇数
            long long count = (lastOdd - firstOdd) / 2 + 1;  // 区间内奇数个数
            result += (__int128)count * K;
        }
    }
    
    return (long long)(result % MOD);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    long long n;
    while (cin >> n && n != 0) cout << calculateSum(n) << '\n';
    
    return 0;
}
```

## 总结

本题的关键在于发现平方根的分段特性和奇数分布的规律，通过数学公式将 $O(n)$ 的时间复杂度优化到 $O(1)$。使用 `__int128` 处理大数运算避免了中间结果的溢出问题，使得算法能够高效处理 $64$ 位整数范围内的所有输入。
