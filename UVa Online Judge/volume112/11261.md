## 题目描述

小苏丹有一个 $n \times n$ 的国际象棋棋盘，他在棋盘上放置了 $m$ 个象（$\texttt{bishop}$）。象在国际象棋中沿对角线移动，因此每个象会攻击其所在的两个对角线（主对角线和副对角线）上的所有格子。现在需要计算棋盘上有多少个格子没有被任何象攻击。

**输入格式**：
- 第一行输入 $L$，表示测试用例的数量。
- 对于每个测试用例：
  - 第一行包含两个整数 $n$ 和 $m$。
  - 接下来的 $m$ 行，每行包含两个整数 $r_i$ 和 $c_i$，表示第 $i$ 个象的行和列位置（从 1 开始计数）。

**约束条件**：
- $1 \leq n \leq 40000$
- $0 \leq m \leq 10000$
- 象的位置互不相同
- $1 \leq r_i, c_i \leq n$

**输出格式**：
对于每个测试用例，输出 `Case #i: result`，其中 $i$ 为用例编号（从 $1$ 开始），`result` 为没有被任何象攻击的格子数。

## 题目分析

这是一个计算几何与集合运算结合的问题。国际象棋的象沿对角线移动，因此每个象会攻击其所在的两条对角线上的所有格子。我们的目标是计算没有被任何象攻击的格子数量。

### 关键观察

1. **对角线的表示**：
   - 主对角线（从左上到右下）：同一主对角线上的格子满足 $r - c$ 为常数，记作 $d_1 = r - c$。
   - 副对角线（从右上到左下）：同一副对角线上的格子满足 $r + c$ 为常数，记作 $d_2 = r + c$。

2. **对角线长度**：
   - 对于主对角线 $d_1$，其长度为 $n - |d_1|$。
   - 对于副对角线 $d_2$，其长度为 $n - |d_2 - (n+1)|$。

3. **被攻击格子的计算**：
   - 被攻击的格子集合 = 所有被占主对角线上的格子 ∪ 所有被占副对角线上的格子。
   - 使用容斥原理：$|A \cup B| = |A| + |B| - |A \cap B|$。
   - 其中 $A$ 表示所有被占主对角线上的格子集合，$B$ 表示所有被占副对角线上的格子集合。
   - $A \cap B$ 表示既在被占主对角线上又在被占副对角线上的格子，即两条对角线的交点。

4. **交点计算**：
   - 两条对角线相交的条件是：主对角线 $d_1$ 和副对角线 $d_2$ 满足方程组：
     $$
     \begin{cases}
     r - c = d_1 \\
     r + c = d_2
     \end{cases}
     $$
   - 解得：$r = \frac{d_1 + d_2}{2}$，$c = \frac{d_2 - d_1}{2}$。
   - 交点存在的条件：
     - $d_1$ 和 $d_2$ 必须同奇偶（保证 $r$ 和 $c$ 为整数）。
     - $1 \leq r \leq n$ 且 $1 \leq c \leq n$（交点在棋盘内）。

## 解题思路

基于上述分析，我们可以设计如下算法：

1. **收集对角线信息**：
   - 遍历所有象的位置，收集被占用的主对角线集合（$d_1$ 值）和副对角线集合（$d_2$ 值）。
   - 为了后续高效计算交点，可以将副对角线按奇偶性分组存储。

2. **计算主对角线上的被攻击格子数**：
   - 对于每条被占用的主对角线 $d_1$，计算其长度 $n - |d_1|$，并累加到总和中。

3. **计算副对角线上的被攻击格子数**：
   - 对于每条被占用的副对角线 $d_2$，计算其长度 $n - |d_2 - (n+1)|$，并累加到总和中。

4. **计算交点数量**：
   - 对于每条被占用的主对角线 $d_1$：
     - 确定其奇偶性。
     - 遍历所有与被占主对角线 $d_1$ 同奇偶的被占副对角线 $d_2$。
     - 计算交点坐标 $(r, c)$。
     - 如果交点在棋盘内，则交点计数加 1。

5. **计算最终结果**：
   - 被攻击的格子数 = 主对角线上的被攻击格子数 + 副对角线上的被攻击格子数 - 交点数量。
   - 没有被攻击的格子数 = 总格子数 $n^2$ - 被攻击的格子数。

### 时间复杂度分析

- 收集对角线信息：$O(m)$。
- 计算主对角线上的被攻击格子数：$O(k_1)$，其中 $k_1$ 为不同的 $d_1$ 数量，$k_1 \leq m$。
- 计算副对角线上的被攻击格子数：$O(k_2)$，其中 $k_2$ 为不同的 $d_2$ 数量，$k_2 \leq m$。
- 计算交点数量：最坏情况 $O(k_1 \times k_2)$，即 $O(m^2)$。但由于 $m \leq 10000$，且我们可以通过奇偶性过滤，实际运行时间通常可以接受。
- 总时间复杂度为 $O(m^2)$，在题目约束下是可行的。

### 空间复杂度分析

- 存储对角线集合需要 $O(m)$ 的空间。
- 总体空间复杂度为 $O(m)$。

```cpp
// Bishops

#include <bits/stdc++.h>
using namespace std;

int main() {
    int L;
    scanf("%d", &L);
    for (int caseId = 1; caseId <= L; ++caseId) {
        int n, m;
        scanf("%d %d", &n, &m);
        
        // 存储被占用的主对角线
        unordered_set<int> mainDiagSet;
        // 按奇偶性分组存储被占用的副对角线
        unordered_map<int, unordered_set<int>> antiDiagByParity;
        
        // 读入象的位置并收集对角线信息
        for (int i = 0; i < m; ++i) {
            int r, c;
            scanf("%d %d", &r, &c);
            // 主对角线：r - c
            mainDiagSet.insert(r - c);
            
            // 副对角线：r + c
            int d2 = r + c;
            // 计算奇偶性（0 或 1）
            int parity = (d2 % 2 + 2) % 2;
            antiDiagByParity[parity].insert(d2);
        }
        
        // 棋盘总格子数
        long long totalCells = (long long)n * n;
        
        // 计算主对角线上的被攻击格子数
        long long attackedByMain = 0;
        for (int d1 : mainDiagSet) {
            int len = n - abs(d1);
            attackedByMain += len;
        }
        
        // 计算副对角线上的被攻击格子数
        long long attackedByAnti = 0;
        for (auto& entry : antiDiagByParity) {
            for (int d2 : entry.second) {
                int len = n - abs(d2 - (n + 1));
                attackedByAnti += len;
            }
        }
        
        // 计算交点数量
        long long intersections = 0;
        for (int d1 : mainDiagSet) {
            // 获取主对角线的奇偶性
            int parity = ((d1 % 2) + 2) % 2;
            // 如果没有同奇偶的副对角线，跳过
            if (antiDiagByParity.find(parity) == antiDiagByParity.end()) continue;
            
            // 遍历所有同奇偶的副对角线
            for (int d2 : antiDiagByParity[parity]) {
                // 计算交点坐标
                int r = (d1 + d2) / 2;
                int c = (d2 - d1) / 2;
                
                // 检查交点是否在棋盘内
                if (r >= 1 && r <= n && c >= 1 && c <= n) {
                    intersections++;
                }
            }
        }
        
        // 计算最终结果
        long long attacked = attackedByMain + attackedByAnti - intersections;
        long long safe = totalCells - attacked;
        printf("Case #%d: %lld\n", caseId, safe);
    }
    return 0;
}
```

## 总结

本题的关键在于理解象的攻击范围是对角线，并运用容斥原理计算被攻击的格子数。需要特别注意主对角线和副对角线可能相交于多个点，而不仅仅是象所在的位置。通过按奇偶性分组处理对角线，可以有效地计算交点数量，从而得到正确的结果。

该算法在题目约束条件下是高效的，能够处理 $n$ 达到 $40000$、$m$ 达到 $10000$ 的大规模输入。
