
> **摘要**：本文讨论「可靠网络」问题——在 $n$ 个路由器中构造通信链路，使得任意 $m$ 个路由器失效后剩余路由器仍保持连通，且总边数不超过 $\lceil (m+1)n/2 \rceil$。文章将该问题转化为构造一个 $k = m+1$ 连通图并精确达到边数下界，给出基于循环图（环形连接）的构造方法：$k$ 为偶数时直接环形连边，$k$ 为奇数时在基础环上补充完美匹配或近完美匹配加一条额外边。配套 $\texttt{C++}$ 代码使用 `std::set` 去重存边，时间复杂度 $O(n^2)$，适用于 $n \le 50$ 的数据规模。

## 题目描述

一个网络中有 $n$ 个路由器，编号为 $1$ 到 $n$ 。两个路由器可以通信，当且仅当它们直接相连，或者其中一个与某个能同另一个通信的路由器相连（即间接相连）。现在需要连接这些 $n$ 个路由器，使得在任意 $m$ 个路由器失效后，所有仍然活跃的路由器之间仍能互相通信（直接或通过其他活跃路由器）。同时，连接的总数不能超过 $\lceil (m + 1) \cdot n / 2 \rceil$ 。所有通信链路都是双向的。

## 输入格式

第一行包含一个整数 $T$ ，表示测试用例的数量。每个测试用例占一行，包含两个整数 $n$（$1 \le n \le 50$）和 $m$（$1 \le m \le 10$ 且 $m < n - 2$）。

## 输出格式

对于每个测试用例，输出 $e + 2$ 行，其中 $e$ 为所需的连接数量。第一行输出 $e$ 。接下来的 $e$ 行每行输出两个整数 $i$ 和 $j$ ，表示路由器 $i$ 和 $j$ 之间需要建立一条连接。最后一行输出一个空行。

## 样例

输入

```
1
4 1
```

输出

```
4
1 2
2 3
3 4
4 1

```

## 题目分析

题目要求构造一个 $n$ 个顶点的无向简单图，使得删除任意 $m$ 个顶点后，剩余图仍然连通。这等价于要求该图的顶点连通度至少为 $m + 1$ 。记 $k = m + 1$ ，则图必须是 $k$ 连通的。

根据图论中的基本定理，一个 $k$ 连通图的最小可能边数至少为 $\lceil k n / 2 \rceil$ ，因为每个顶点的度数至少为 $k$ ，所以总度数至少为 $k n$ ，边数至少为 $k n / 2$ 。题目给出的上限恰好是这个下界，因此我们必须在满足连通度要求的前提下，精确构造出边数等于 $\lceil k n / 2 \rceil$ 的图。

当 $k$ 为偶数时，可以构造循环图：将顶点按顺序编号为 $0, 1, \dots, n-1$ ，对于距离 $d = 1, 2, \dots, k/2$ ，连接每个顶点 $i$ 与 $(i + d) \bmod n$ 。这样每个顶点的度数为 $2 \cdot (k/2) = k$ ，总边数为 $n k / 2$ ，且该图是 $k$ 连通的。

当 $k$ 为奇数时，$k = 2r + 1$ 。先连接距离 $d = 1, 2, \dots, r$ 的边，每个顶点度数为 $2r = k - 1$ 。为了将度数提升至至少 $k$ ，需要额外添加一个完美匹配（当 $n$ 为偶数时）或一个近完美匹配加上一条额外边（当 $n$ 为奇数时），使得每个顶点度数增加 $1$ ，总边数达到 $\lceil k n / 2 \rceil$ 。这种构造方式同样保证了图的 $k$ 连通性。

## 解题思路

对于每个测试用例，按以下步骤构造图：

1. 令 $k = m + 1$ 。
2. 使用一个集合（如 `std::set` ）存储无向边，自动去重并保证每条边以较小端点在前。
3. 执行基础连接：
   - 令 $r = \lfloor k / 2 \rfloor$ 。
   - 对于 $d = 1, 2, \dots, r$ ，对每个顶点 $i$ （$0 \le i < n$），连接 $i$ 与 $(i + d) \bmod n$ 。
4. 若 $k$ 为奇数：
   - 若 $n$ 为偶数：添加完美匹配，对于 $i = 0, 1, \dots, n/2 - 1$ ，连接 $i$ 与 $(i + n/2) \bmod n$ 。
   - 若 $n$ 为奇数：添加近完美匹配，对于 $i = 0, 1, \dots, (n-3)/2$ ，连接 $i$ 与 $(i + (n-1)/2) \bmod n$ 。然后寻找一条尚未存在的边，连接顶点 $n-1$ 与某个顶点 $v$（$0 \le v < n-1$），使得该边不与已有边重复。由于 $k < n - 1$ ，该边总能找到。
5. 输出边数 $e$ 以及每条边的两个端点（编号加 $1$），最后输出一个空行。

上述构造保证图是 $k$ 连通的，且边数恰好等于 $\lceil k n / 2 \rceil$ ，从而满足题目要求。

时间复杂度：每个测试用例的边数不超过 $\lceil (m+1)n/2 \rceil \le 275$ ，构造过程中遍历的顶点对数量级为 $O(n^2)$ ，但由于 $n \le 50$ ，完全可行。空间复杂度为 $O(n^2)$ ，用于存储边集。

## 代码实现

```cpp
// Reliable Network

//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

void solveCase(int n, int m) {
    int k = m + 1;
    set<pair<int,int>> edges;
    auto addEdge = [&](int u, int v) {
        if (u > v) swap(u, v);
        if (u != v) edges.insert({u, v});
    };
    int r = k / 2;
    for (int d = 1; d <= r; ++d)
        for (int i = 0; i < n; ++i)
            addEdge(i, (i + d) % n);
    if (k % 2 == 1) {
        if (n % 2 == 0) {
            int half = n / 2;
            for (int i = 0; i < half; ++i)
                addEdge(i, (i + half) % n);
        } else {
            int s = (n - 1) / 2;
            for (int i = 0; i < s; ++i)
                addEdge(i, (i + s) % n);
            bool found = false;
            for (int v = 0; v < n - 1; ++v) {
                int a = v, b = n - 1;
                if (a > b) swap(a, b);
                if (edges.find({a, b}) == edges.end()) {
                    addEdge(v, n - 1);
                    found = true;
                    break;
                }
            }
            if (!found) addEdge(0, n - 1);
        }
    }
    cout << edges.size() << "\n";
    for (auto &p : edges)
        cout << p.first + 1 << " " << p.second + 1 << "\n";
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n, m;
        cin >> n >> m;
        solveCase(n, m);
    }
    return 0;
}
```

## 总结

本题的核心是构造一个指定连通度的图，并精确达到边数的下界。利用循环图（环形连接）可以方便地构造出高连通度的图。对于奇数连通度，通过添加匹配来补齐度数，从而保证每个顶点的度数至少为 $k$ 。该构造方法简洁有效，且易于实现。关键点在于：

- 理解连通度与边数下界的关系；
- 掌握循环图的连通性性质；
- 对奇数 $k$ 处理匹配的细节，特别是 $n$ 为奇数时的额外边选择。

该解法适用于 $n$ 较小的情况，但思想具有一般性。
