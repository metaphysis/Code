## 题目描述

给定一个循环多边形（所有顶点在同一个圆上）的 $n$ 条边长，边长顺序任意，求该多边形的面积。如果给定的边长无法构成一个有效的循环多边形（即退化情况），则输出 $0.000$。所有三角形都是循环多边形，其面积可以用海伦公式计算，但对于 $n > 3$ 的循环多边形，面积需要借助外接圆半径来求解。

## 输入格式

第一行一个整数 $t$（$t < 10001$），表示测试用例的数量。  
每个测试用例的第一行是一个整数 $n$（$n < 51$），接下来 $n$ 行每行一个浮点数，表示边长。边长均为正数，小数点后最多 $3$ 位，所有边长之和不超过 $1000.000$。

## 输出格式

对于每个测试用例，输出一行一个浮点数，表示该循环多边形的面积，四舍五入保留三位小数。若多边形无效，输出 `0.000`。

## 样例

输入

```
1
3
3.000
4.000
5.000
```

输出

```
6.000
```

## 题目分析

循环多边形的所有顶点都在同一个圆上，设该圆的半径为 $R$。对于边长为 $a_i$ 的边，它所对的圆心角为 $\theta_i$，根据正弦定理有：

$$
a_i = 2R \sin\left(\frac{\theta_i}{2}\right)
$$

因此

$$
\theta_i = 2 \arcsin\left(\frac{a_i}{2R}\right)
$$

由于多边形是封闭的，所有圆心角之和等于 $2\pi$：

$$
\sum_{i=1}^{n} \theta_i = 2\pi
$$

代入得：

$$
\sum_{i=1}^{n} 2 \arcsin\left(\frac{a_i}{2R}\right) = 2\pi
$$

两边同时除以 $2$：

$$
\sum_{i=1}^{n} \arcsin\left(\frac{a_i}{2R}\right) = \pi \tag{1}
$$

定义函数

$$
F(R) = \sum_{i=1}^{n} \arcsin\left(\frac{a_i}{2R}\right)
$$

由于 $\arcsin$ 在其定义域 $[0,1]$ 上是单调递增的，而 $\frac{a_i}{2R}$ 随着 $R$ 的增大而减小，因此 $F(R)$ 是 $R$ 的**单调递减函数**。

- 当 $R$ 趋近于 $\frac{\max(a_i)}{2}$ 时，最大的 $\frac{a_i}{2R}$ 趋近于 $1$，$\arcsin(1) = \frac{\pi}{2}$，其他项为正，所以 $F(R) > \pi$。
- 当 $R \to +\infty$ 时，$\frac{a_i}{2R} \to 0$，$\arcsin(0) = 0$，所以 $F(R) \to 0 < \pi$。

由介值定理，存在唯一的 $R$ 使得 $F(R) = \pi$。可以通过**二分查找**求解 $R$。

一旦求出 $R$，多边形面积等于所有三角形（圆心与每条边构成的三角形）面积之和：

$$
S = \sum_{i=1}^{n} \frac{1}{2} R^2 \sin\theta_i
$$

其中 $\theta_i = 2 \arcsin\left(\frac{a_i}{2R}\right)$。

## 解题思路

### 步骤 1：确定二分边界

- 下界：$low = \frac{\max(a_i)}{2}$，因为 $R$ 必须至少等于最大边长的一半，否则该边的 $\frac{a_i}{2R} > 1$，$\arcsin$ 无定义。
- 上界：可以取一个足够大的数，例如 $10^6$ 或所有边长之和（因为 $R$ 不会超过半周长）。

### 步骤 2：二分查找 $R$

对于当前中点 $mid$，计算 $F(mid) = \sum \arcsin\left(\frac{a_i}{2 \cdot mid}\right)$。需要注意：

- 若任意 $\frac{a_i}{2 \cdot mid} > 1$，说明 $mid$ 太小，应将下界提高。
- 否则，比较 $F(mid)$ 与 $\pi$ 的大小：
  - 若 $F(mid) > \pi$，说明 $R$ 太小（$F$ 递减），应增大 $R$，令 $low = mid$。
  - 若 $F(mid) < \pi$，说明 $R$ 太大，应减小 $R$，令 $high = mid$。

重复约 $100$ 次迭代（或直到区间足够小）以获得高精度。

### 步骤 3：验证有效性

最终取 $R = \frac{low + high}{2}$，重新计算 $\sum \arcsin\left(\frac{a_i}{2R}\right)$。若与 $\pi$ 的绝对误差超过 $10^{-5}$（或 $10^{-6}$），则多边形无效，输出 $0.000$。

### 步骤 4：计算面积

利用公式 $S = \sum \frac{1}{2} R^2 \sin\left(2 \arcsin\left(\frac{a_i}{2R}\right)\right)$。注意 $\sin(2\arcsin x) = 2x\sqrt{1-x^2}$，但直接调用 $\sin$ 和 $\arcsin$ 也是可行的。

### 特殊情况

- 若 $n = 1$ 或 $n = 2$，无法构成多边形，输出 $0.000$。
- 若某条边长大于等于剩余边长之和（对于循环多边形实际上是外接圆直径的限制），也可能无效。

## 复杂度分析

- 每个测试用例进行 $O(iterations \cdot n)$ 次计算，其中 $iterations \approx 50$，$n < 51$。
- 总复杂度 $O(t \cdot n \cdot iterations)$，在 $t \le 10000$ 时完全可行。

## 代码实现

```cpp
// Cyclic Polygons
// UVa ID: 11277
// Verdict: Accepted
// Submission Date: 2026-06-10
// UVa Run Time: 0.210s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);
const double EPS = 1e-8;

double solveOne(int n, vector<double>& a) {
    double maxSide = *max_element(a.begin(), a.end());
    double low = maxSide / 2.0;
    double high = 1000;
    
    for (int iter = 0; iter < 50; ++iter) {
        double mid = (low + high) / 2.0;
        double sumAngles = 0.0;
        bool valid = true;
        for (int i = 0; i < n; ++i) {
            double ratio = a[i] / (2.0 * mid);
            if (ratio > 1.0 + EPS) { valid = false; break; }
            sumAngles += asin(min(ratio, 1.0));
        }
        if (!valid) { low = mid; continue; }
        if (sumAngles < PI) high = mid;
        else low = mid;
    }
    
    double R = (low + high) / 2.0;
    double totalAngle = 0.0;
    for (int i = 0; i < n; ++i) {
        double ratio = a[i] / (2.0 * R);
        if (ratio > 1.0 + EPS) return 0.0;
        totalAngle += asin(min(ratio, 1.0));
    }
    if (fabs(totalAngle - PI) > 1e-5) return 0.0;
    
    double area = 0.0;
    for (int i = 0; i < n; ++i) {
        double theta = 2.0 * asin(min(a[i] / (2.0 * R), 1.0));
        area += 0.5 * R * R * sin(theta);
    }
    return area;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        vector<double> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];
        double ans = solveOne(n, a);
        if (ans < 0) ans = 0.0;
        cout << fixed << setprecision(3) << ans << '\n';
    }
    return 0;
}
```

## 总结

本题的核心是通过**二分查找外接圆半径** $R$，利用循环多边形圆心角之和为 $2\pi$ 的约束建立方程。关键点包括：

- 正确推导 $\sum \arcsin\left(\frac{a_i}{2R}\right) = \pi$ 这一单调递减函数关系。
- 注意二分方向的正确性：$F(R)$ 随 $R$ 增大而减小。
- 对 $\frac{a_i}{2R} > 1$ 的情况及时处理，避免 $\arcsin$ 参数越界。
- 利用 $\min(\textit{ratio}, 1.0)$ 保证数值稳定性，因为浮点误差可能导致 $\textit{ratio}$ 略大于 $1$。
- 最终通过三角形面积求和得到多边形面积。

该方法不仅适用于循环多边形，也体现了通过物理或几何约束进行数值求解的通用技巧。对于 $n=3$ 的情况，结果与海伦公式一致，验证了方法的正确性。
