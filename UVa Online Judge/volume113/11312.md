## 问题描述

$\texttt{Wolfgang Puck}$ 需要从食谱书的第 $1$ 页翻到第 $t$ 页，他每次只能选择两种操作之一：
- 向左（向后）精确地翻 $l$ 页
- 向右（向前）精确地翻 $r$ 页

书的总页数为 $n$ ，要求判断能否从第 $1$ 页到达第 $t$ 页，并且如果可达，求出最少的翻页次数。

**输入格式**
第一行给出测试用例数 $c$ $(1 \le c \le 100)$ 。
每个测试用例给出四个整数 $n \ l \ r \ t$ $(2 \le n \le 10^7, \ 1 \le l, r \le n-1, \ 1 \le t \le n)$ ，分别表示总页数、向左翻的页数、向右翻的页数、目标页码。

**输出格式**
对于每个测试用例，如果可达则输出最少翻页次数，否则输出 `uh-oh!` （注意短横线是英文短横）。

## 解题思路

### 1. 数学模型建立

设向右翻的次数为 $x$ ，向左翻的次数为 $y$ ，则从第 $1$ 页出发，经过 $x$ 次向右翻和 $y$ 次向左翻后，页码为：
$$
\text{页码} = 1 + r \cdot x - l \cdot y
$$
我们需要这个页码等于 $t$ ，即：
$$
r \cdot x - l \cdot y = t - 1
$$
其中 $x, y$ 为非负整数。

### 2. 可解性判定

上述方程是一个线性丢番图方程。根据数论知识，方程有整数解的条件是：
$$
(t - 1) \ \text{能被} \ \gcd(l, r) \ \text{整除}
$$
即：
$$
(t - 1) \bmod \gcd(l, r) = 0
$$
如果不满足这个条件，直接输出 `uh-oh!` 。

### 3. 求解最小非负解

令 $d = \gcd(l, r)$ ，设 $a = r/d$ ， $b = l/d$ ， $c = (t - 1)/d$ ，则原方程化为：
$$
a \cdot x - b \cdot y = c
$$
使用扩展欧几里得算法求出方程 $a \cdot x_0 - b \cdot y_0 = 1$ 的一组整数解 $(x_0, y_0)$ ，那么原方程的一组特解为：
$$
x_1 = c \cdot x_0, \quad y_1 = c \cdot y_0
$$
通解为：
$$
x = x_1 + b \cdot k, \quad y = y_1 + a \cdot k \quad (k \in \mathbb{Z})
$$
我们需要 $x \ge 0$ 且 $y \ge 0$ ，由此可确定 $k$ 的取值范围：
$$
k \ge \max\left( \lceil -x_1 / b \rceil, \ \lceil -y_1 / a \rceil \right)
$$
由于总翻页次数为 $x + y = (x_1 + y_1) + (a + b) \cdot k$ ，并且 $a + b > 0$ ，所以最小值在最小的可行 $k$ 处取得。我们只需检查 $k_{\min}$ 及其附近几个整数值，找出使 $x + y$ 最小的非负解 $(x, y)$ 。

### 4. 模拟验证可行性

得到 $x$ 和 $y$ 后，我们需要验证是否能在实际翻页过程中执行这么多次向右翻和向左翻，并且中间页码始终在 $[1, n]$ 范围内。

采用贪心策略： **尽可能先向右翻，不能向右翻时才向左翻** 。这样能最大化当前页码，为后续的向左翻留出空间。

为了提高模拟效率，我们不一步步模拟，而是用除法计算每次能连续翻多少页：
- 向右翻：当前页码为 $curr$ ，最多能连续向右翻 $\min\left( rightCnt, \ \lfloor (n - curr) / r \rfloor \right)$ 次
- 向左翻：最多能连续向左翻 $\min\left( leftCnt, \ \lfloor (curr - 1) / l \rfloor \right)$ 次

重复这个过程直到完成所有 $x$ 次向右翻和 $y$ 次向左翻。如果过程中某一步既不能向右也不能向左，则说明无解。

### 5. 时间复杂度分析

- 扩展欧几里得算法： $O(\log \min(l, r))$
- 寻找最优 $k$ ：常数时间
- 模拟过程：每次循环至少完成一次翻页操作，且使用除法加速，循环次数很少

对于 $c \le 100$ ， $n \le 10^7$ 的数据范围完全可行。

## 代码实现

```cpp
// Flipping Frustration
// UVa ID: 11312
// Verdict: Accepted
// Submission Date: 2026-01-03
// UVa Run Time: 0.070s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 扩展欧几里得算法，返回 (g, x, y) 满足 a*x + b*y = g = gcd(a, b)
tuple<long long, long long, long long> extendedGcd(long long a, long long b) {
    if (b == 0) return {a, 1, 0};
    auto [g, x1, y1] = extendedGcd(b, a % b);
    return {g, y1, x1 - (a / b) * y1};
}

int main() {
    int c;
    cin >> c;
    while (c--) {
        long long n, l, r, t;
        cin >> n >> l >> r >> t;
        
        // 特判：目标页就是起始页
        if (t == 1) {
            cout << 0 << endl;
            continue;
        }
        
        // 判定是否有解
        long long d = __gcd(l, r);
        if ((t - 1) % d != 0) {
            cout << "uh-oh!\n";
            continue;
        }
        
        // 解方程 r*x - l*y = t-1
        // 令 a = r/d, b = l/d, c = (t-1)/d
        long long a = r / d, b = l / d, c = (t - 1) / d;
        
        // 求 a*x0 + b*y0 = 1 的解，注意我们实际需要 a*x0 - b*y0 = 1
        auto [g, x0, y0] = extendedGcd(a, b);
        long long x1 = c * x0, y1 = c * (-y0);  // 调整符号得到 a*x1 - b*y1 = c
        
        // 找最小非负解
        long long kLower = max(ceil((-x1) / (double)b), ceil((-y1) / (double)a));
        long long bestK = kLower;
        long long bestSum = x1 + b * kLower + y1 + a * kLower;
        
        // 检查 kLower 附近的值，确保找到最小 x+y
        for (long long k = kLower - 1; k <= kLower + 1; k++) {
            long long xTry = x1 + b * k, yTry = y1 + a * k;
            if (xTry >= 0 && yTry >= 0) {
                long long sum = xTry + yTry;
                if (sum < bestSum) {
                    bestSum = sum;
                    bestK = k;
                }
            }
        }
        
        // 确定最终解
        long long x = x1 + b * bestK, y = y1 + a * bestK;
        if (x < 0 || y < 0 || r * x - l * y != t - 1) {
            cout << "uh-oh!\n";
            continue;
        }
        
        // 贪心模拟：优先向右翻，使用除法加速
        long long current = 1, rightCnt = x, leftCnt = y, flips = 0;
        bool changed = true;
        while (changed) {
            changed = false;
            
            // 尝试向右翻
            if (rightCnt > 0) {
                long long steps = min(rightCnt, (n - current) / r);
                if (steps > 0) {
                    current += steps * r;
                    flips += steps;
                    rightCnt -= steps;
                    changed = true;
                }
            }
            
            // 尝试向左翻
            if (leftCnt > 0) {
                long long steps = min(leftCnt, (current - 1) / l);
                if (steps > 0) {
                    current -= steps * l;
                    flips += steps;
                    leftCnt -= steps;
                    changed = true;
                }
            }
        }
        
        // 检查是否成功到达目标页
        if (current == t) cout << flips << '\n';
        else cout << "uh-oh!\n";
    }
    return 0;
}
```

## 总结

本题综合运用了数论（扩展欧几里得算法）、线性丢番图方程求解和贪心模拟。关键点在于：
1. 将翻页问题转化为线性丢番图方程
2. 利用 $\gcd$ 判断可解性
3. 使用扩展欧几里得算法求通解，并寻找最小非负解
4. 通过贪心策略模拟验证可行性，并用除法加速模拟过程

这种解法高效且正确，能够处理 $n$ 高达 $10^7$ 的大数据范围。
