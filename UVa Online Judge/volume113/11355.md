## 题目描述

我们有一个半径为 $R$ 的圆，圆心位于原点 $(0, 0)$ 。圆内有 $N$ 条线段，所有线段都在圆内且不经过原点。定义“酷点”为圆周上的一点 $P$ ，使得连接点 $P$ 和圆心 $O$ 的线段 $OP$ 不与任何给定的线段相交。

你的任务是：对于所有可能的圆周上的点（即 $360$ 度圆周），计算酷点所占的百分比，并输出结果，保留两位小数。

**输入格式**  
- 第一行：整数 $T$ （ $T < 1000$ ），表示测试用例的数量。  
- 每个测试用例：  
  - 第一行：两个整数 $N$ （ $0 \le N < 100$ ）和 $R$ （ $0 < R < 1001$ ）。  
  - 接下来 $N$ 行：每行四个整数 $x_1, y_1, x_2, y_2$ ，表示一条线段 $(x_1, y_1)$ 到 $(x_2, y_2)$ 。  

**输出格式**  
对于每个测试用例，输出一行：`Case i: p%` ，其中 $i$ 为用例编号， $p$ 为酷点的百分比，保留两位小数。

**样例输入**  
```
2
1 10
2 0 0 2
0 5
```

**样例输出**  
```
Case 1: 75.00%
Case 2: 100.00%
```

## 题目分析

我们需要判断从圆心到圆周上某点的线段是否与给定线段相交。由于所有线段都在圆内且不经过原点，我们可以将问题转化为**角度区间覆盖问题**。

### 核心思路

1. **极角表示**  
   圆周上的点可以用极角 $\theta$ （ $0 \le \theta < 2\pi$ ）唯一表示。从原点出发的射线方向为 $\theta$ 时，该射线与圆周的交点即为一个候选点。

2. **线段阻挡的条件**  
   对于一条线段 $AB$ ，从原点 $O$ 到 $A$ 和 $B$ 的极角分别为 $\alpha$ 和 $\beta$ 。如果线段 $AB$ 与射线 $OP$ （方向 $\theta$ ）相交，那么 $\theta$ 必须位于 $\alpha$ 和 $\beta$ 形成的**较小角度区间**内。这是因为线段 $AB$ 在圆内，且不经过原点，所以它阻挡的角度区间是连续的，且长度不超过 $\pi$ 。

3. **区间合并**  
   每条线段对应一个角度区间（或两个，如果跨越 $2\pi$ 边界）。将所有线段的阻挡区间合并，得到总的阻挡角度范围。  
   **酷点对应的角度** = 总角度 $2\pi$ − 阻挡角度总和。  
   **百分比** = （酷点角度 / $2\pi$ ）× $100\%$ 。

4. **特殊情况**  
   - 如果线段两端点极角相差 $\pi$ 以上，说明它阻挡的区间跨越 $2\pi$ 边界，需要拆分为两个区间。  
   - 如果线段两端点极角非常接近（差值小于 $\epsilon$ ），可视为退化线段，忽略不计。

### 算法步骤

1. 对于每条线段 $(x_1, y_1, x_2, y_2)$ ：  
   a. 计算两端点的极角 $\alpha, \beta$ 。  
   b. 如果 $|\alpha - \beta| < \epsilon$ ，忽略（退化）。  
   c. 确保 $\alpha < \beta$ 。  
   d. 如果 $\beta - \alpha < \pi$ ，则区间为 $[\alpha, \beta]$ 。  
   e. 否则，区间为 $[0, \alpha]$ 和 $[\beta, 2\pi]$ 。  

2. 将所有区间按左端点排序，合并重叠或相邻的区间。  

3. 计算合并后区间的总长度（阻挡角度）。  

4. 酷点百分比 = $(2\pi - \text{阻挡角度}) / (2\pi) \times 100\%$ 。

## 代码实现

```cpp
// Cool Points
// UVa ID: 11355
// Verdict: Accepted
// Submission Date: 2026-01-10
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);
const double EPS = 1e-9;

// 计算点 (x, y) 的极角 [0, 2*PI)
double getAngle(double x, double y) {
    double angle = atan2(y, x);
    if (angle < 0) angle += 2 * PI;
    return angle;
}

int main() {
    int T; cin >> T;
    for (int t = 1; t <= T; ++t) {
        int N, R; cin >> N >> R;
        vector<pair<double, double>> segs;
        for (int i = 0; i < N; ++i) {
            int x1, y1, x2, y2; cin >> x1 >> y1 >> x2 >> y2;
            double a1 = getAngle(x1, y1);
            double a2 = getAngle(x2, y2);
            double diff = fabs(a1 - a2);
            if (diff < EPS) continue; // 忽略退化为点的线段
            if (a1 > a2) swap(a1, a2);
            if (diff < PI) segs.emplace_back(a1, a2);
            else {
                segs.emplace_back(0, a1);
                segs.emplace_back(a2, 2 * PI);
            }
        }
        // 合并区间
        vector<pair<double, double>> merged;
        sort(segs.begin(), segs.end());
        for (auto& seg : segs) {
            if (merged.empty() || seg.first > merged.back().second + EPS)
                merged.push_back(seg);
            else merged.back().second = max(merged.back().second, seg.second);
        }
        // 计算总阻挡角度
        double blocked = 0;
        for (auto& seg : merged) blocked += seg.second - seg.first;
        double cool = 2 * PI - blocked;
        double percentage = (cool / (2 * PI)) * 100.0;
        printf("Case %d: %.2lf%%\n", t, percentage);
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**： $O(N \log N)$ ，主要来自排序区间。  
- **空间复杂度**： $O(N)$ ，存储区间。

## 总结

本题的关键在于将几何相交问题转化为角度区间覆盖问题。通过计算每条线段阻挡的角度区间，合并这些区间后得到总阻挡范围，从而求出酷点的比例。注意处理角度跨越 $2\pi$ 边界的情况，以及忽略退化的线段。
