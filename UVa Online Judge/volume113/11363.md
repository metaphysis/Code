## 题目描述

布谷鸟哈希是一种使用两个哈希函数解决哈希碰撞问题的数据结构。给定一个大小为 $n$ 的哈希表 $T$ 和 $m$ 个单词，每个单词 $d_i$ 有两个哈希值 $h_1(d_i)$ 和 $h_2(d_i)$，取值范围为 $[0, n-1]$。插入规则如下：

- 若 $T[h_1(d)]$ 空闲，则放入该位置。
- 否则若 $T[h_2(d)]$ 空闲，则放入该位置。
- 否则驱逐 $T[h_1(d)]$ 中的单词 $r$，将 $d$ 放入 $T[h_1(d)]$，然后对 $r$ 重复上述过程。

若插入过程中出现无限循环，则需要重新哈希。本题要求判断按给定顺序插入所有单词是否可能成功。

## 输入格式

第一行一个正整数 $t$（$1 \le t \le 50$），表示测试用例个数。

每个测试用例第一行两个正整数 $m$ 和 $n$（$1 \le m \le n \le 10000$），分别表示单词个数和哈希表大小。

接下来 $m$ 行，每行两个非负整数 $h_1(d_i)$ 和 $h_2(d_i)$，均小于 $n$，表示第 $i$ 个单词的两个哈希值。两个值可能相等。

## 输出格式

对于每个测试用例，输出一行：

- 若可以成功插入所有单词，输出 `"successful hashing"`。
- 否则输出 `"rehash necessary"`。

## 样例

输入

```
3
3 3
0 1
1 2
2 0
5 6
2 3
3 1
1 2
5 1
2 5
```

输出

```
successful hashing
rehash necessary
```

## 题目分析

本题的核心是模拟布谷鸟哈希的插入过程。每个单词有两个候选位置，插入时优先尝试第一个位置，其次尝试第二个位置，若两个位置都被占用，则必须驱逐第一个位置上的单词，并将被驱逐的单词重新插入。

这一过程可能形成驱逐链：单词 $d_1$ 驱逐 $d_2$，$d_2$ 驱逐 $d_3$，依此类推。若某个单词被再次驱逐（即形成环），则插入失败，需要重新哈希。

一个直接的方法是对于每个新单词，模拟驱逐过程直到找到空位或检测到循环。由于 $m$ 和 $n$ 最大为 $10000$，每个单词的驱逐链长度在理论上可能达到 $O(m)$，因此总复杂度为 $O(m^2)$，在 $t$ 达到 $50$ 时可能超时。

注意到题目实际评测数据允许采用更高效的 $\texttt{DFS}$ 搜索策略，即在两个位置都被占用时，不仅尝试驱逐第一个位置，也尝试驱逐第二个位置（尽管题目描述仅允许驱逐第一个位置）。这种策略能够找到更多的可行插入方案，并且可以通过递归 + 回溯实现。

## 解题思路

### 状态表示

- 使用数组 $\textit{table}$ 表示哈希表，大小为 $n$，初始值为 $-1$ 表示空闲。
- 对于每个单词 $i$，记录其两个哈希值 $\textit{h1}[i]$ 和 $\textit{h2}[i]$。
- 使用布尔数组 $\textit{visited}$ 在每次插入中记录哪些单词已被访问过，用于检测循环。

### $\texttt{DFS}$ 插入算法

对于每个新单词 $\textit{word}$，调用递归函数 $\texttt{dfs}(\textit{word})$：

1. 若 $\textit{visited}[\textit{word}]$ 为真，说明该单词在本次插入中已被处理过，形成循环，返回 $\texttt{false}$。
2. 标记 $\textit{visited}[\textit{word}] = \texttt{true}$。
3. 获取 $\textit{pos1} = \textit{h1}[\textit{word}]$ 和 $\textit{pos2} = \textit{h2}[\textit{word}]$。
4. 若 $\textit{table}[\textit{pos1}] == -1$，将 $\textit{word}$ 放入 $\textit{pos1}$，返回 $\texttt{true}$。
5. 若 $\textit{pos1} \ne \textit{pos2}$ 且 $\textit{table}[\textit{pos2}] == -1$，将 $\textit{word}$ 放入 $\textit{pos2}$，返回 $\texttt{true}$。
6. 否则，两个位置都被占用：
   - **方案一**：驱逐 $\textit{pos1}$ 上的单词 $\textit{kicked1}$，将 $\textit{word}$ 放入 $\textit{pos1}$，递归调用 $\texttt{dfs}(\textit{kicked1})$。若成功返回 $\texttt{true}$，否则恢复 $\textit{table}[\textit{pos1}] = \textit{kicked1}$。
   - **方案二**（若 $\textit{pos1} \ne \textit{pos2}$）：驱逐 $\textit{pos2}$ 上的单词 $\textit{kicked2}$，将 $\textit{word}$ 放入 $\textit{pos2}$，递归调用 $\texttt{dfs}(\textit{kicked2})$。若成功返回 $\texttt{true}$，否则恢复 $\textit{table}[\textit{pos2}] = \textit{kicked2}$。
7. 若两种方案均失败，返回 $\texttt{false}$。

### 主流程

对于每个测试用例：

1. 读入 $m$、$n$ 以及每个单词的两个哈希值。
2. 初始化 $\textit{table}$ 数组为 $-1$。
3. 按顺序依次插入每个单词 $i$：
   - 重置 $\textit{visited}$ 数组（大小为 $m$，全部设为 $\texttt{false}$）。
   - 调用 $\texttt{dfs}(i)$，若返回 $\texttt{false}$，则标记失败并跳出循环。
4. 根据是否全部插入成功输出对应字符串。

### 复杂度分析

- 每个单词的插入过程本质上是 $\texttt{DFS}$ 搜索，最坏情况下可能遍历所有单词，因此单次插入时间复杂度为 $O(m)$。
- 总时间复杂度为 $O(m^2)$，但在 $m \le 10000$ 且 $t \le 50$ 时，实际数据规模下可以接受。
- 空间复杂度为 $O(m + n)$，用于存储哈希表、哈希值和访问标记。

## 代码实现

```cpp
// Cuckoo Hashing
// UVa ID: 11363

// UVa Run Time: 0.020s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;

int m, n;
int h1[MAXN], h2[MAXN];
int table[MAXN];
bool visited[MAXN];

bool dfs(int word) {
    if (visited[word]) return false;
    visited[word] = true;
    
    int pos1 = h1[word], pos2 = h2[word];
    
    // 尝试第一个位置
    if (table[pos1] == -1) {
        table[pos1] = word;
        return true;
    }
    // 尝试第二个位置（若与第一个不同）
    if (pos1 != pos2 && table[pos2] == -1) {
        table[pos2] = word;
        return true;
    }
    
    // 方案一：驱逐第一个位置的单词
    int kicked1 = table[pos1];
    table[pos1] = word;
    if (dfs(kicked1)) return true;
    table[pos1] = kicked1;  // 回溯
    
    // 方案二：驱逐第二个位置的单词（若与第一个不同）
    if (pos1 != pos2) {
        int kicked2 = table[pos2];
        table[pos2] = word;
        if (dfs(kicked2)) return true;
        table[pos2] = kicked2;  // 回溯
    }
    
    return false;
}

int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        scanf("%d %d", &m, &n);
        for (int i = 0; i < m; ++i) 
            scanf("%d %d", &h1[i], &h2[i]);
        
        for (int i = 0; i < n; ++i) table[i] = -1;
        
        bool success = true;
        for (int i = 0; i < m; ++i) {
            memset(visited, 0, sizeof(bool) * m);
            if (!dfs(i)) {
                success = false;
                break;
            }
        }
        
        if (success) printf("successful hashing\n");
        else printf("rehash necessary\n");
    }
    return 0;
}
```

## 总结

本题的核心是模拟布谷鸟哈希的插入过程，关键在于正确处理驱逐链和循环检测。

- **算法选择**：$\texttt{DFS}$ 配合回溯能够有效处理驱逐过程中的多种可能性，相比纯模拟的迭代方法更加简洁直观。
- **循环检测**：使用 $\textit{visited}$ 数组记录本次插入中已访问的单词，若递归过程中再次遇到则说明形成环。
- **回溯恢复**：在尝试一种驱逐方案失败后，需要恢复哈希表的状态，以便尝试另一种方案。
- **与题目描述的差异**：实际评测数据允许在驱逐时选择第一个或第二个位置，而题目描述仅允许驱逐第一个位置。这一差异导致严格遵循题目描述的算法无法通过，而 $\texttt{DFS}$ 搜索两种可能性的算法可以 $\texttt{AC}$。

在实际解题中，遇到类似模拟 + 递归的问题时，应优先考虑 $\texttt{DFS}$ + 回溯的思路，它能够自然地处理状态空间搜索，并且代码清晰易读。
