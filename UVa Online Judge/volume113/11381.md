## 题目描述

给定两个字符串 $S$ 和 $T$ ，它们都由小写字母组成。

首先，定义 $P$ 为 $S$ 中所有 **长度为 $2$ 的不同子串** 的集合。对于 $P$ 中的每个元素（一个长度为 $2$ 的子串），其 **优雅值** 定义为：该子串在 $S$ 中 **第一次出现** 时，其 **第一个字符的索引（$1$-based）的平方** 。如果同一个子串在 $S$ 中出现多次，只考虑第一次出现的位置。

例如，若 $S = \text{abcabd}$ ，则长度为 $2$ 的不同子串有： $\text{ab}$ , $\text{bc}$ , $\text{ca}$ , $\text{bd}$ 。它们的优雅值计算如下：
- $\text{ab}$ 第一次出现在 $S[0]$ ，索引为 $1$ ，优雅值为 $1^2 = 1$ 。
- $\text{bc}$ 第一次出现在 $S[1]$ ，索引为 $2$ ，优雅值为 $2^2 = 4$ 。
- $\text{ca}$ 第一次出现在 $S[2]$ ，索引为 $3$ ，优雅值为 $3^2 = 9$ 。
- $\text{bd}$ 第一次出现在 $S[4]$ ，索引为 $5$ ，优雅值为 $5^2 = 25$ 。

---

接下来，我们需要将字符串 $T$ 分割成若干个 **子序列**（每个子序列是 $T$ 的一个子序列，即从 $T$ 中按原序取出若干字符组成），并满足以下条件：

1.  $T$ 中的每个字符必须恰好属于一个分割后的字符串。
2.  分割后的每个字符串中，所有 **长度为 $2$ 的子串** 都必须属于 $P$（即必须在 $S$ 中出现过）。
3.  要求分割出的字符串数量 $K$ **最小**。
4.  在满足 $K$ 最小的前提下，使得 **总优雅值** $C$ 最小。

对于一个分割后的字符串，其 **优雅值** 定义为：该字符串中所有 **长度为 $2$ 的相邻子串** 的优雅值之和。如果字符串长度为 $1$ ，则其优雅值为 $0$ 。总优雅值 $C$ 是所有分割后字符串的优雅值之和。

---

## 输入与输出

**输入**

第一行包含一个整数 $X$ （ $\le 20$ ），表示测试用例的数量。  
每个测试用例包含两行：
- 第一行：字符串 $S$ （长度 $\le 1000$ ，只包含小写字母）
- 第二行：字符串 $T$ （长度 $\le 100$ ，只包含小写字母）

**输出**

对于每个测试用例，输出两个整数 $K$ 和 $C$ ，用空格分隔：
- $K$ ：最小分割字符串数量。
- $C$ ：在 $K$ 最小的前提下，最小的总优雅值。

---

## 样例

**输入**
```
1
abcabd
bcadzb
```

**输出**
```
3 14
```

**解释**

$S = \text{abcabd}$ , $T = \text{bcadzb}$ 。  
一种最优分割方案为： $\{\text{bcab}, \text{z}, \text{d}\}$ 。
- 字符串 $\text{bcab}$ 包含相邻对 $\text{bc}$ 、 $\text{ca}$ 、 $\text{ab}$ ，优雅值分别为 $4$ 、 $9$ 、 $1$ ，总和为 $14$ 。
- 字符串 $\text{z}$ 和 $\text{d}$ 长度均为 $1$ ，优雅值为 $0$ 。
总优雅值 $C = 14 + 0 + 0 = 14$ ，且分割数 $K = 3$ 是最小的。

## 题目分析

### 关键点

1.  **分割的本质** ：将 $T$ 的字符分配到若干个序列中，每个序列是 $T$ 的一个子序列（保持原序），且每个字符只能属于一个序列。这等价于用若干条 **路径** 覆盖 $T$ 的所有字符。
2.  **合法转移条件** ：在一个序列内部，任意相邻的两个字符（即长度为 $2$ 的子串）必须在 $S$ 中出现过（即属于 $P$）。
3.  **优化目标** ：首先最小化路径数量（即分割出的字符串数），其次最小化所有路径上相邻字符对的优雅值之和。

### 问题转化

我们可以将 $T$ 的每个位置看作一个节点，编号 $0$ 到 $n-1$（ $n = |T|$ ）。  
如果位置 $i$ 的字符后面可以接位置 $j$ 的字符（ $i < j$ ），且字符对 $(T[i], T[j])$ 在 $P$ 中（即在 $S$ 中出现过），那么我们就有一条从 $i$ 到 $j$ 的有向边，边的 **费用** 为该字符对的优雅值。

于是，问题转化为：  
在一个 **有向无环图**（ $i < j$ 保证无环）中，用若干条路径覆盖所有节点，要求：
- 路径数最少。
- 在路径数最少的前提下，路径上所有边的费用之和最小。

这是一个典型的 **$\texttt{DAG}$ 上的最小路径覆盖** 问题，但加入了 **费用最小化** 的次级目标。

### 图论模型

对于 **最小路径覆盖** 问题，有一个经典结论：  
> 在有向无环图中，最小路径覆盖数 = 节点数 - 最大匹配数。

证明思路：  
将每个节点拆成 **出点** 和 **入点** ，原图中的边 $i \to j$ 转化为从 $i$ 的出点连向 $j$ 的入点的边。这样原图的路径覆盖问题就转化为了二分图上的匹配问题。每匹配一条边，就相当于将两个节点连接在同一条路径中，路径数减少 $1$ 。初始时每个节点单独成一条路径，共 $n$ 条；每进行一次匹配，路径数减 $1$ 。因此，最小路径覆盖数 = $n$ - 最大匹配数。

在我们的问题中，不仅要求最大匹配，还要求 **在最大匹配的前提下，匹配边的总费用最小** 。这便是一个 **最小费用最大流** 问题。

## 算法设计

### 步骤

1.  **预处理 $S$** ：  
    遍历 $S$ ，记录所有长度为 $2$ 的不同子串及其第一次出现时第一个字符的索引（ 从 $1$ 开始计数 ），计算优雅值，存入二维数组 `elegance[26][26]` ，并标记合法字符对 `validPair[26][26]` 。

2.  **建图** ：  
    - 将 $T$ 的每个位置 $i$ 拆成两个节点：出点 $i$ 和入点 $i+n$（ $n = |T|$ ）。
    - 建立源点 $src = 2n$ 和汇点 $sink = 2n+1$ 。
    - 连接边：
        - 源点 $src \to$ 出点 $i$ ：容量 $1$ ，费用 $0$ 。
        - 入点 $i+n \to$ 汇点 $sink$ ：容量 $1$ ，费用 $0$ 。
        - 对于所有 $i < j$ ，若 `validPair[T[i]][T[j]]` 为真，则连边 出点 $i \to$ 入点 $j+n$ ：容量 $1$ ，费用为 `elegance[T[i]][T[j]]` 。

3.  **运行最小费用最大流** ：  
    使用 $\texttt{SPFA}$（或 $\texttt{Bellman-Ford}$）寻找增广路，每次沿最短路增广，直到无法增广为止。  
    最终得到的 **最大流** 即为最大匹配数 $match$ ， **最小费用** 即为在最大匹配下的最小总优雅值 $minCost$ 。

4.  **计算结果** ：  
    - 最小路径覆盖数（即最小分割字符串数） $K = n - match$ 。
    - 最小总优雅值 $C = minCost$ 。

5.  **输出答案** ：  
    对每个测试用例输出 $K$ 和 $C$ 。

### 复杂度分析

- 节点数： $O(n)$ ， $n \le 100$ ，拆点后最多 $2n+2 = 202$ 个点。
- 边数：最多 $O(n^2)$ 条合法边，加上源汇边，总边数约 $O(n^2)$ 。
- 费用流复杂度： $O(\text{VE})$ 的 $\texttt{SPFA}$ 实现，在本题规模下完全可以接受。

```cpp
// Elegant Strings

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int MAXN = 205; // 拆点后最多 200 个点

struct Edge {
    int to, cap, cost, rev;
};

vector<Edge> graph[MAXN];
int dist[MAXN], prevv[MAXN], preve[MAXN];
bool inQueue[MAXN];

void addEdge(int from, int to, int cap, int cost) {
    graph[from].push_back({to, cap, cost, (int)graph[to].size()});
    graph[to].push_back({from, 0, -cost, (int)graph[from].size() - 1});
}

// 最小费用最大流
pair<int, int> minCostMaxFlow(int s, int t, int n) {
    int flow = 0, cost = 0;
    while (true) {
        fill(dist, dist + n, INF);
        fill(inQueue, inQueue + n, false);
        dist[s] = 0;
        queue<int> q;
        q.push(s);
        inQueue[s] = true;
        while (!q.empty()) {
            int v = q.front(); q.pop();
            inQueue[v] = false;
            for (int i = 0; i < (int)graph[v].size(); ++i) {
                Edge &e = graph[v][i];
                if (e.cap > 0 && dist[e.to] > dist[v] + e.cost) {
                    dist[e.to] = dist[v] + e.cost;
                    prevv[e.to] = v;
                    preve[e.to] = i;
                    if (!inQueue[e.to]) {
                        q.push(e.to);
                        inQueue[e.to] = true;
                    }
                }
            }
        }
        if (dist[t] == INF) break;
        int d = INF;
        for (int v = t; v != s; v = prevv[v]) {
            d = min(d, graph[prevv[v]][preve[v]].cap);
        }
        flow += d;
        cost += d * dist[t];
        for (int v = t; v != s; v = prevv[v]) {
            Edge &e = graph[prevv[v]][preve[v]];
            e.cap -= d;
            graph[v][e.rev].cap += d;
        }
    }
    return {flow, cost};
}

int main() {
    int testCases;
    cin >> testCases;
    while (testCases--) {
        string S, T;
        cin >> S >> T;
        int n = T.size();
        
        // 清理图
        for (int i = 0; i < MAXN; ++i) graph[i].clear();
        
        // 预处理优雅值
        int elegance[26][26] = {0};
        bool validPair[26][26] = {false};
        map<pair<char, char>, bool> appeared;
        for (int i = 0; i + 1 < (int)S.size(); ++i) {
            char a = S[i], b = S[i + 1];
            if (!appeared[{a, b}]) {
                appeared[{a, b}] = true;
                validPair[a - 'a'][b - 'a'] = true;
                elegance[a - 'a'][b - 'a'] = (i + 1) * (i + 1);
            }
        }
        
        // 拆点：i 对应出点，i+n 对应入点
        int src = 2 * n, sink = 2 * n + 1;
        int totalNodes = 2 * n + 2;
        
        // 源点到出点，入点到汇点
        for (int i = 0; i < n; ++i) {
            addEdge(src, i, 1, 0);
            addEdge(i + n, sink, 1, 0);
        }
        
        // 添加合法边
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                if (validPair[T[i] - 'a'][T[j] - 'a']) {
                    addEdge(i, j + n, 1, elegance[T[i] - 'a'][T[j] - 'a']);
                }
            }
        }
        
        // 运行最小费用最大流
        auto [maxFlow, minCost] = minCostMaxFlow(src, sink, totalNodes);
        int minPaths = n - maxFlow;
        
        cout << minPaths << " " << minCost << endl;
    }
    return 0;
}
```

## 总结

本题的核心在于将字符串分割问题转化为图论中的 **最小路径覆盖** 问题，并进一步通过 **拆点 + 最小费用最大流** 来求解。  
关键点包括：
- 理解分割后每个字符串是 $T$ 的子序列，且相邻字符对必须在 $S$ 中出现。
- 利用 $\texttt{DAG}$ 最小路径覆盖的经典结论，结合费用流在保证路径数最小的前提下最小化总优雅值。

通过这种转化，我们可以在 $O(n^3)$ 的复杂度内解决每个测试用例，完全满足题目数据范围的要求。
