## 题目描述

给定一个包含 $N$ 个正整数的序列，计算满足条件 $x + y = z$ 的三元组 $(x, y, z)$ 的数量。其中 $x$, $y$, $z$ 都是序列中的元素（允许重复使用同一个元素，只要它们在序列中存在）。

**输入格式**
- 输入以 $\texttt{EOF}$ 结束
- 每组数据第一行是整数 $N$，接下来一行包含 $N$ 个正整数

**输出格式**
- 对于每组数据，输出满足条件的三元组数量

**约束条件**
- $3 \leq N \leq 5000$

## 样例分析

**样例 1**
```
输入：
6
1 2 3 4 5 6
输出：
6
```
解释：满足条件的三元组有 $(1,2,3)$, $(1,3,4)$, $(1,4,5)$, $(1,5,6)$, $(2,3,5)$, $(2,4,6)$

**样例 2**
```
输入：
5
1 1 1 2 2
输出：
6
```
解释：由于存在重复数字，组合方式更多

## 解题思路

### 暴力法分析
最直接的方法是使用三重循环枚举所有可能的三元组，检查是否满足 $x + y = z$。这种方法的时间复杂度为 $O(N^3)$，对于 $N = 5000$ 的情况，计算量约为 $1250$ 亿次，显然会超时。

### 优化思路

#### 关键观察
1. **利用频率统计**：同一个数字可能出现多次，我们可以统计每个数字出现的频率
2. **避免重复计算**：通过枚举不同的数值对而不是下标对来减少计算量
3. **哈希表加速查找**：使用哈希表可以快速判断 $z = x + y$ 是否存在于序列中

#### 算法步骤
1. **频率统计**：使用哈希表记录每个数字出现的次数
2. **去重排序**：获取所有不同的数字并排序，便于枚举
3. **枚举数值对**：
   - 对于每对 $(x, y)$，计算 $z = x + y$
   - 如果 $z$ 存在于哈希表中，则根据 $x$ 和 $y$ 的关系计算贡献：
     - 如果 $x = y$：贡献为 $C(freq[x], 2) \times freq[z]$
     - 如果 $x \neq y$：贡献为 $freq[x] \times freq[y] \times freq[z]$
4. **累加计数**：将所有贡献累加得到最终结果

## 参考代码

```cpp
// Triples
// UVa ID: 11386
// Verdict: Accepted
// Submission Date: 2025-11-04
// UVa Run Time: 2.170s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <unordered_map>
#include <algorithm>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int numCount;
    // 循环读取输入直到 EOF
    while (cin >> numCount) {
        vector<int> numbers(numCount);
        unordered_map<int, long long> frequency;
        
        // 读取数字并统计频率
        for (int i = 0; i < numCount; i++) {
            cin >> numbers[i];
            frequency[numbers[i]]++;
        }
        
        // 获取唯一数字并排序
        vector<int> uniqueNumbers;
        for (auto& pair : frequency) {
            uniqueNumbers.push_back(pair.first);
        }
        sort(uniqueNumbers.begin(), uniqueNumbers.end());
        
        long long totalTriples = 0;
        int uniqueCount = uniqueNumbers.size();
        
        // 枚举所有可能的数值对 (x, y)
        for (int i = 0; i < uniqueCount; i++) {
            int x = uniqueNumbers[i];
            for (int j = i; j < uniqueCount; j++) {
                int y = uniqueNumbers[j];
                int z = x + y;
                
                // 检查 z 是否存在于序列中
                if (frequency.count(z)) {
                    if (x == y) {
                        // x 和 y 相同的情况：组合数 C(freq[x], 2)
                        long long combination = frequency[x] * (frequency[x] - 1) / 2;
                        totalTriples += combination * frequency[z];
                    } else {
                        // x 和 y 不同的情况：直接相乘
                        totalTriples += frequency[x] * frequency[y] * frequency[z];
                    }
                }
            }
        }
        
        cout << totalTriples << "\n";
    }
    
    return 0;
}
```

## 代码解释

1. **输入处理**：使用 `ios_base::sync_with_stdio(false)` 和 `cin.tie(nullptr)` 加速输入
2. **频率统计**：`frequency` 哈希表记录每个数字的出现次数
3. **去重排序**：`uniqueNumbers` 存储所有不同的数字并排序，便于枚举
4. **枚举计算**：
   - 外层循环枚举 $x$，内层循环从 $i$ 开始枚举 $y$，避免重复计算
   - 计算 $z = x + y$，检查 $z$ 是否存在于频率表中
   - 根据 $x$ 和 $y$ 是否相同，采用不同的计数方式
5. **输出结果**：每组数据输出后换行

## 总结

本题通过频率统计和哈希表优化，将时间复杂度从 $O(N^3)$ 降低到 $O(M^2)$，其中 $M$ 是不同数字的数量。这种优化方法在处理包含重复元素的组合计数问题时非常有效，值得学习和掌握。
