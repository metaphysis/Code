## 题目描述

$\texttt{Mahbub}$ 认为他发现了一个有趣的现象：对于每个整数，他都能找到一个它的倍数，这个倍数只由数字 $3$ 和 $0$ 组成，并且数字按非递增顺序排列（即所有 $3$ 在前，$0$ 在后）。现在需要你验证这个猜想。

给定一个正整数 $K$，找到一个 $K$ 的正倍数，满足：
1. 只包含数字 $3$ 和 $0$
2. 数字按非递增顺序排列
3. 如果存在多个这样的倍数，选择长度最短的
4. 如果仍有多个，选择字典序最大的（即 $3$ 尽可能多）

输出该倍数的长度、$3$ 的个数和 $0$ 的个数。

**约束条件**：$K \leq 1000000$

## 题目分析

### 问题形式化

我们需要找到形如 $\underbrace{333\ldots3}_{a\text{个}}\underbrace{000\ldots0}_{b\text{个}}$ 的数 $M$，使得：
1. $M$ 是 $K$ 的倍数
2. $a \geq 1$（至少有一个 $3$）
3. $b \geq 0$（可以有零个或多个 $0$）

### 数学建模

数 $M$ 可以表示为：
$$M = 3 \times \frac{10^a - 1}{9} \times 10^b$$

我们需要 $K \mid M$，即：
$$K \mid 3 \times \frac{10^a - 1}{9} \times 10^b$$

### 关键观察

1. **因子分离**：由于 $10^b$ 只包含因子 $2$ 和 $5$，我们可以将 $K$ 分解为：
   $$K = 2^p \cdot 5^q \cdot K'$$
   其中 $K'$ 与 $10$ 互质（即不含因子 $2$ 和 $5$）

2. **末尾零处理**：为了满足 $2^p \cdot 5^q$ 的整除条件，$M$ 的末尾必须有至少 $\max(p, q)$ 个零。因此：
   $$b = \max(p, q)$$

3. **核心问题**：现在问题简化为找到最小的 $a$，使得：
   $$K' \mid 3 \times \frac{10^a - 1}{9}$$
   即 $a$ 个 $3$ 组成的数能被 $K'$ 整除。

### 算法设计

1. **预处理**：
   - 计算 $K$ 中因子 $2$ 的个数 $p$ 和因子 $5$ 的个数 $q$
   - 计算 $b = \max(p, q)$
   - 计算 $K' = K / (2^p \cdot 5^q)$

2. **特殊情况**：
   - 如果 $K' = 1$，说明 $K$ 只包含因子 $2$ 和 $5$，此时最小的倍数是 $3$ 后跟 $b$ 个 $0$

3. **一般情况**：
   - 使用模运算模拟构造 $a$ 个 $3$ 组成的数
   - 从 $a = 1$ 开始，计算 $R_a = (R_{a-1} \times 10 + 3) \mod K'$
   - 当 $R_a = 0$ 时，找到满足条件的 $a$

4. **输出结果**：
   - 总长度 = $a + b$
   - $3$ 的个数 = $a$
   - $0$ 的个数 = $b$

### 复杂度分析

- 由于我们使用模运算，避免了处理大数
- 根据鸽笼原理，余数最多有 $K'$ 种可能，因此循环最多执行 $K'$ 次
- 总体复杂度为 $O(K)$，满足 $K \leq 1000000$ 的约束

## 解题思路总结

1. **分离因子**：将 $K$ 分解为 $2^p \cdot 5^q \cdot K'$ 的形式
2. **确定零的个数**：$b = \max(p, q)$ 确保能被 $2^p \cdot 5^q$ 整除
3. **寻找三的个数**：通过模运算找到最小的 $a$，使得 $a$ 个 $3$ 能被 $K'$ 整除
4. **组合结果**：将 $a$ 个 $3$ 和 $b$ 个 $0$ 组合得到最终答案

这种方法确保了：
- 找到的倍数满足数字只包含 $3$ 和 $0$ 且非递增
- 长度最短（通过寻找最小的 $a$）
- 字典序最大（在长度相同的情况下，$3$ 越多字典序越大）

## 代码实现

```cpp
// Binary*3 Type Multiple
// UVa ID: 11392
// Verdict: Accepted
// Submission Date: 2025-11-12
// UVa Run Time: 0.580s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int k;
    while (cin >> k) {
        int kTemp = k;
        int twoCount = 0, fiveCount = 0;
        
        // 去除因子 2
        while (kTemp % 2 == 0) {
            kTemp /= 2;
            twoCount++;
        }
        // 去除因子 5
        while (kTemp % 5 == 0) {
            kTemp /= 5;
            fiveCount++;
        }
        
        int trailingZeros = max(twoCount, fiveCount);
        
        if (kTemp == 1) {
            // 如果 K' = 1，那么只需要 trailingZeros 个 0 和一个 3
            cout << (1 + trailingZeros) << " " << 1 << " " << trailingZeros << endl;
            continue;
        }
        
        // 寻找最小的 a 使得 a 个 3 能被 kTemp 整除
        int remainder = 0;
        int length = 0;
        while (true) {
            remainder = (remainder * 10 + 3) % kTemp;
            length++;
            if (remainder == 0) {
                break;
            }
        }
        
        // 总长度 = length + trailingZeros
        // 3 的个数 = length
        // 0 的个数 = trailingZeros
        cout << (length + trailingZeros) << " " << length << " " << trailingZeros << endl;
    }
    return 0;
}
```

该代码通过巧妙的因子分离和模运算，高效地解决了问题，能够在约束条件下快速得出正确结果。
