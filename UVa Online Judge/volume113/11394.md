## 题目描述

题目描述了一种用于儿童数字教学的积木块。 每组积木包含许多块，每块上印有一个数字的形状。 通过将这些积木块排成一行，可以组成各种大小的数字。 给定可用数字块的信息，你的任务是找出使用这些积木块可以组成多少个不同的能被 $5$ 整除的十六进制数。 为了避免前导零的问题，可以假设没有任何一块的形状是零。 可用的积木块形状可能为 `'1'` 、 `'2'` 、 `'3'` 、 `'4'` 、 `'5'` 、 `'6'` 、 `'7'` 、 `'8'` 、 `'9'` 、 `'A'` 、 `'B'` 、 `'C'` 、 `'D'` 、 `'E'` 或 `'F'` ，这些实际上是十六进制数字系统的数字。

## 输入格式

输入文件最多包含 $501$ 行输入。 每行包含一个仅包含十六进制数字系统数字的字符串（但不会包含零）。 这些数字表示可用的积木块。 例如，如果字符串是 `"A1BBBS"` ，那么你需要假设总共有六块积木可用。 其中三块形状为 `'B'` ，一块形状为 `'A'` ，另一块形状为 `'1'` ，最后一块形状为 `'S'` 。 字符串长度最多为 $16$ 个字符。

输入以一行仅包含 `'#'` 的行结束。

## 输出格式

对于每行输入，输出一行。 该行包含一个十进制整数 $N$ 。 这里 $N$ 是使用给定数字可以组成的十六进制 $5$ 的倍数的数量。 注意，你可以使用部分或全部给定数字来组成数字。 你可以放心地假设 $N$ 可以放入 $64$ 位有符号整数中。

## 样例输入

```
A1BBBS
B
#
```

## 样例输出

```
4
0
```

## 题目分析与解题思路

### 关键点分析

1. **数字表示**：题目涉及十六进制数字，使用的数字字符包括 `1` 到 `9` 和 `A` 到 `F` （分别对应十进制值 $10$ 到 $15$ ），且保证不会出现数字 $0$ 。

2. **组成规则**：
   * 可以从给定的积木块中选择任意数量的块来组成一个数字。
   * 积木块的排列顺序任意。
   * 由于不存在数字 $0$ ，因此不需要考虑前导零的问题。

3. **目标**：计算所有可能的数字（即所有可能的排列组合）中，能被 $5$ 整除的数字的数量。

### 核心难点

直接枚举所有可能的排列组合是不可行的。 对于长度为 $n$ 的字符串，即使数字不重复，所有可能的排列数（包括不同长度）也高达 $\sum_{k=1}^{n} \frac{n!}{(n-k)!}$ ，这在大 $n$ （本题 $n \leq 16$ ）时计算量巨大。 此外，题目中数字可以重复，这进一步增加了问题的复杂性。

### 数学洞察：判断十六进制数能被 $5$ 整除的条件

这是解题的关键。 对于一个十六进制数：
$$
N = \sum_{i=0}^{L-1} a_i \times 16^i
$$
其中 $a_i$ 是第 $i$ 位的十六进制数字值（从最低位 $i=0$ 开始）。

我们需要判断 $N \mod 5 = 0$ 的条件。 由于 $16 \equiv 1 \pmod{5}$ ，因此对于任意 $i \geq 0$ ，有 $16^i \equiv 1 \pmod{5}$ 。 于是：
$$
N \mod 5 \equiv \left( \sum_{i=0}^{L-1} a_i \times 16^i \right) \mod 5 \equiv \left( \sum_{i=0}^{L-1} a_i \times 1 \right) \mod 5 \equiv \left( \sum_{i=0}^{L-1} a_i \right) \mod 5
$$

**结论**：一个十六进制数 $N$ 能被 $5$ 整除，当且仅当其各位数字之和（在十进制意义下）能被 $5$ 整除。

这个结论将问题从“判断一个数的整除性”简化为了“判断所选数字之和的整除性”，并且与数字的排列顺序无关，大大降低了问题复杂度。

### 问题转化

现在，问题转化为：
> 给定一个数字多重集（每个数字有一个出现次数），我们可以从中选择任意数量的数字（考虑数量，顺序任意排列）来组成一个数。 计算所有可能的组合（数字选择 + 排列）中，使得所选数字之和模 $5$ 等于 $0$ 的方案总数（需排除空数字，即不选任何数字的情况）。

### 动态规划设计

我们采用动态规划来统计所有可能的选择与排列。

#### 状态定义

设 $dp[r][k]$ 表示：考虑完前若干种数字后，所选数字之和模 $5$ 为 $r$ ，且恰好选择了 $k$ 个数字的**所有排列方案的总数**。

初始状态： $dp[0][0] = 1$ （表示不选任何数字，和为 $0$ ，有 $1$ 种方案）。

#### 状态转移

我们逐个处理每种数字（值记为 $d$ ，可用数量记为 $cnt$ ）。

假设当前状态为 $dp[r][k]$ ，表示已经处理了某些数字，形成了 $k$ 个数字的排列，数字和模 $5$ 为 $r$ 。

现在考虑当前数字 $d$ ，我们可以选择在其中加入 $t$ 个该数字（ $0 \leq t \leq cnt$ 且 $k + t \leq n$ ， $n$ 为总积木块数）。

*   **新的数字和模 $5$**： $r' = (r + d \times t) \mod 5$ 。
*   **新的数字总数**： $k' = k + t$ 。
*   **排列方案数计算**： 我们已经有一个由 $k$ 个数字组成的排列。 现在要加入 $t$ 个**完全相同**的数字 $d$ 。 这 $t$ 个数字需要插入到总共 $k'$ 个位置中。 相当于在 $k'$ 个位置中选择 $t$ 个位置来放置这些新数字 $d$ ，剩下的 $k$ 个位置留给原来的排列。 因此，排列组合数为组合数 $C(k', t)$ 。 注意，由于新加入的数字彼此相同，所以不需要再除以 $t!$ 。
*   **转移方程**：
$$
    dp_{new}[r'][k'] \mathrel{+}= dp[r][k] \times C(k', t)
$$
    这里 $dp_{new}$ 是处理完当前数字后的新状态数组。

我们依次处理所有 $15$ 种可能的数字（ $1$ 到 $15$ ），最终得到的 $dp[0][k]$ （ $k \geq 1$ ）就是所有数字和模 $5$ 为 $0$ 且由 $k$ 个数字组成的排列方案数。

#### 最终答案

将所有 $k$ 从 $1$ 到 $n$ 的 $dp[0][k]$ 求和，即得到总的满足条件的数字个数：
$$
answer = \sum_{k=1}^{n} dp[0][k]
$$

### 算法复杂度

*   **时间复杂度**： 我们需要处理最多 $15$ 种数字。 对于每种数字，需要遍历所有可能的状态 $dp[r][k]$ ，其中 $0 \leq r < 5$ ， $0 \leq k \leq n$ （ $n \leq 16$ ）。 对于每个状态，需要考虑选择当前数字的个数 $t$ （ $0 \leq t \leq cnt$ ）。 总体复杂度约为 $O(15 \times 5 \times n \times n) = O(n^2)$ ，在 $n=16$ 时非常高效。
*   **空间复杂度**： 使用了滚动数组思想，主要存储两个 $5 \times (n+1)$ 的数组，空间复杂度为 $O(n)$ 。

### 代码实现细节

1.  **字符转换**： 编写辅助函数 `hexCharToInt` ，将字符 `'0'-'9'` 和 `'A'-'F'` 转换为对应的整数值（ $1$ 到 $15$ ）。
2.  **组合数预处理**： 由于 $n$ 很小，可以预先计算好组合数 $C[i][j]$ 供动态规划使用。
3.  **输入处理**： 题目说明每行输入是一个字符串，但示例输入中似乎有空格。 实际上，根据题目描述，每行就是一个连续的字符串。 我们直接读取整行即可，行末的 `'#'` 作为结束标志。

```cpp
// Digit Blocks
// UVa ID: 11394
// Verdict: Accepted
// Submission Date: 2026-01-19
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

long long C[20][20];

void initialize() {
    for (int i = 0; i < 20; i++) {
        C[i][0] = C[i][i] = 1;
        for (int j = 1; j < i; j++)
            C[i][j] = C[i - 1][j - 1] + C[i - 1][j];
    }
}

// 将十六进制字符转换为数值
int hexCharToInt(char c) {
    if (isdigit(c)) return c - '0';
    return c - 'A' + 10;
}

long long solve(const string& blocks) {
    int n = blocks.size();
    // 统计每种数字的出现次数（1-15）
    vector<int> cnt(16, 0);
    for (char c : blocks) cnt[hexCharToInt(c)]++;
    // dp[j][k] = 当前和模5为j，选了k个数字的排列总数
    vector<vector<long long>> dp(5, vector<long long>(n + 1, 0));
    dp[0][0] = 1;
    // 处理每种数字
    for (int d = 1; d <= 15; d++) {
        if (cnt[d] == 0) continue;
        // 临时数组
        vector<vector<long long>> newDp(5, vector<long long>(n + 1, 0));
        // 遍历当前所有状态
        for (int r = 0; r < 5; r++) {
            for (int k = 0; k <= n; k++) {
                if (dp[r][k] == 0) continue;
                // 对于这种数字，可以选择t个（0 <= t <= cnt[d]）
                int maxT = min(cnt[d], n - k);
                for (int t = 0; t <= maxT; t++) {
                    int newR = (r + d * t) % 5;
                    int newK = k + t;
                    // 在newK个位置中选t个位置放数字d
                    newDp[newR][newK] += dp[r][k] * C[newK][t];
                }
            }
        }
        dp = move(newDp);
    }
    // 计算答案：所有模5为0且至少选1个数字的情况
    long long r = 0;
    for (int k = 1; k <= n; k++) r += dp[0][k];
    return r;
}

int main() {
    initialize(); // 预处理组合数
    string line;
    while (getline(cin, line)) {
        if (line == "#") break;
        cout << solve(line) << '\n';
    }
    return 0;
}
```
