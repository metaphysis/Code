## 题目描述

$\texttt{Petr}$ 想向他的朋友 $\texttt{ACRush}$ 发送一条消息。由于频繁使用键盘，某些按键已经损坏无法使用。他们约定了一种方法，使用可用的按键（工作正常的字母）来发送消息。

给定一个字母表，该字母表中 $\texttt{ASCII}$ 顺序的第一个字符被称为 **特殊 $\texttt{LA}$ 字符**。对于一个字母表，$\texttt{LA}$ 可编码字符串可以是任意长度（包括空串），但特殊 $\texttt{LA}$ 字符 **不能作为字符串的起始字母**。

$\texttt{Petr}$ 发送的消息是由大写字母 `A` – `Z` 组成的字符串，并且是字母表 `A` – `Z` 的一个 $\texttt{LA}$ 可编码字符串（因此消息的首字母不可能是 `A`）。

为了编码消息，$\texttt{Petr}$ 首先按 **字典序** 写出字母表 `A` – `Z` 的所有可能 $\texttt{LA}$ 可编码字符串，找到他的消息所在的位置 `i`。然后，他对于受限字母表（仅包含可用的按键）写出所有可能的 $\texttt{LA}$ 可编码字符串（同样按字典序），并选择该列表中位置 `i` 处的字符串作为编码后的结果发送。

你需要根据给定的原始消息和损坏的按键列表，输出编码后的字符串。

### 字典序规则

- 长度较短的字符串排在前面
- 相同长度的字符串按字母顺序排列

### 输入格式

- 第一行包含一个整数 $t$，表示测试用例的数量。
- 接下来的 $t$ 行，每行包含两个由空格分隔的字符串：第一个是原始消息 `msg`，第二个是损坏的按键字符串 `broken`（无空格分隔）。

### 输出格式

对于每个测试用例，输出一行，包含编码后的字符串。

### 约束条件

- 原始消息的长度：$1 \le |msg| \le 12$
- 损坏按键的数量：$1 \le |broken| \le 24$
- 所有字符均为大写英文字母 `A` – `Z`

### 样例

#### 输入

```text
3
Z Z
CMBWJOJ BCMJOW
CMBWJOJ ADEZLY
```

#### 输出

```text
BA
QXXXHLN
UGMKSKM
```

## 题目分析

### $1$. $\texttt{LA}$ 可编码字符串的定义

对于一个给定的字母表，例如 $\Sigma$，设其第一个字符（按 $\texttt{ASCII}$ 顺序）为 $\texttt{special}$。则一个字符串 $s$ 被称为 $\texttt{LA}$ 可编码字符串当且仅当：

- $s$ 可以为空串
- 若 $s$ 非空，则 $s[0] \neq \texttt{special}$

也就是说，**只有首字母不能是特殊字符**，其余位置没有限制。

### $2$. 字典序排序规则

题目明确说明：**长度较短的字符串排在前面**，相同长度时按字母顺序排列。这与通常的字典序有所不同（通常字典序是先比较第一个字符，再比较后续字符，而不优先考虑长度）。因此需要特别注意排序方式。

例如，对于字母表 $\Sigma = \{\texttt{A}, \texttt{B}\}$，$\texttt{special} = \texttt{A}$，所有 $\texttt{LA}$ 可编码字符串按规则排序如下：

| 长度 | 字符串  | 排名 |
|------|---------|------|
| 0    | `""`    | 1    |
| 1    | `B`     | 2    |
| 2    | `BA`    | 3    |
| 2    | `BB`    | 4    |
| 3    | `BAA`   | 5    |
| 3    | `BAB`   | 6    |
| 3    | `BBA`   | 7    |
| 3    | `BBB`   | 8    |
| ...  | ...     | ...  |

### $3$. 问题的本质

这是一个典型的 **双射排名问题**：

1. 给定一个字符串 $msg$ 在全字母表 $\Sigma_{\text{full}} = \texttt{A}..\texttt{Z}$ 的 $\texttt{LA}$ 可编码字符串序列中的排名 $i$。
2. 在受限字母表 $\Sigma_{avail}$（可用按键）的 $\texttt{LA}$ 可编码字符串序列中，找到排名为 $i$ 的字符串。

因此，我们需要实现两个核心函数：

- $\texttt{getRank}(s, \Sigma, \texttt{special})$：计算字符串 $s$ 在字母表 $\Sigma$ 中的排名（从 $1$ 开始，空串排名为 $1$）。
- $\texttt{buildString}(rank, \Sigma, \texttt{special})$：根据排名构造对应的字符串。

### $4$. 排列数量的计算

设字母表大小为 $m$，特殊字符为 $\texttt{special}$。长度为 $L$ 的 $\texttt{LA}$ 可编码字符串的数量为：

$$
count(L) =
\begin{cases}
1, & L = 0 \text{（空串）} \\[4pt]
m - 1, & L = 1 \\[4pt]
(m - 1) \times m^{L-1}, & L \ge 2
\end{cases}
$$

解释：
- 长度为 $0$：只有空串 $1$ 个。
- 长度为 $1$：首字母不能是 $\texttt{special}$，所以有 $m-1$ 种选择。
- 长度 $L \ge 2$：首字母有 $m-1$ 种选择，后面 $L-1$ 个位置各有 $m$ 种选择。

### $5$. 排名计算

对于给定的字符串 $s$（长度为 $L$），其排名由三部分组成：

#### $5.1$ 所有长度小于 $L$ 的字符串数量

$$
rank_{shorter} = \sum_{len = 1}^{L-1} count(len)
$$

注意这里从 $len = 1$ 开始，**不包括空串**，因为空串我们在后面单独处理。

#### $5.2$ 相同长度内，字典序小于 $s$ 的字符串数量

##### 第 $1$ 位（不能是 $\texttt{special}$）

设 $s[0]$ 在字母表中的索引为 $\texttt{firstIdx}$，$\texttt{special}$ 的索引为 $\texttt{specialIdx}$。则比 $s[0]$ 小且可用的字符数量为：

$$
cntBefore = \#\{i \mid 0 \le i < \texttt{firstIdx},\ i \neq \texttt{specialIdx}\}
$$

每个这样的字符作为首字母时，后面 $L-1$ 个位置可以任意选择（共 $m^{L-1}$ 种组合）。因此贡献为：

$$
cntBefore \times m^{L-1}
$$

然后加上 $s[0]$ 本身，贡献 $1$。

##### 第 $2$ 位到第 $L$ 位

对于第 $pos$ 位（$1 \le pos < L$），设当前字符在字母表中的索引为 $\texttt{idx}$，则所有比它小的字符（$0 \sim \texttt{idx}-1$）作为该位时，后面 $L - pos - 1$ 个位置可以任意选择。贡献为：

$$
idx \times m^{L - pos - 1}
$$

#### $5.3$ 加上空串

由于排名从空串开始，最终排名为：

$$
rank = 1 + rank_{shorter} + rank_{sameLength}
$$

其中 $rank_{sameLength}$ 是第 $5.2$ 节计算的所有贡献之和（包括第 $1$ 位的 $cntBefore \times m^{L-1} + 1$ 以及后续各位的贡献）。

### $6$. 构造字符串

给定排名 $rank$，我们需要反向构造出对应的字符串。

1. **去掉空串**：令 $remain = rank - 1$（因为空串占用了第 $1$ 名）。
2. **确定长度 $L$**：从 $L = 1$ 开始，依次减去 $count(L)$，直到 $remain \le count(L)$。此时 $L$ 即为所求长度，且 $remain$ 表示在当前长度内的序号（从 $1$ 开始计数）。
3. **逐位构造**：
   - 第 $1$ 位：有 $m-1$ 种可能（排除 $\texttt{special}$）。每 $m^{L-1}$ 个连续字符串对应同一个首字母。因此首字母的索引为 $\displaystyle pos = \lfloor \frac{remain- 1}{m^{L-1}} \rfloor$。然后在字母表中跳过 $\texttt{special}$，找到第 $pos$ 个非 $\texttt{special}$ 字符。
   - 更新 $remain = (remain - 1) \bmod m^{L-1} + 1$。
   - 对于第 $2$ 位到第 $L$ 位，每 $m^{L - pos - 1}$ 个连续字符串对应同一个字符，直接用 $remain$ 计算索引即可，**无需跳过任何字符**（因为后续位可以任意选择，包括 $\texttt{special}$）。

## 算法步骤

### 步骤 $1$：预处理全集和可用字母表

- 全集 $\Sigma_{full} = \texttt{"ABCDEFGHIJKLMNOPQRSTUVWXYZ"}$，$\texttt{special} = \texttt{'A'}$。
- 可用字母表 $\Sigma_{avail}$：从全集中删除所有损坏的按键，保持原有顺序。

### 步骤 $2$：计算原始消息在全集中的排名

调用 $\texttt{getRank}(msg, \Sigma_{full}, \texttt{'A'})$，得到排名 $i$。

### 步骤 $3$：在可用字母表中构造第 $i$ 个 $\texttt{LA}$ 可编码字符串

调用 $\texttt{buildString}(i, \Sigma_{avail}, \Sigma_{avail}[0])$，得到编码后的字符串。

## 复杂度分析

- 消息长度最大为 $12$，因此排名计算和构造过程中涉及到的幂运算次数很少，可以忽略不计。
- 字母表大小最大为 $26$，循环次数很少。

```cpp
// LA Encoding

#include <bits/stdc++.h>
using namespace std;

// 计算长度为 L 的 LA 可编码字符串数量
// L = 0 时返回 1（空串）
long long countLen(int L, int alphaSize) {
    if (L == 0) return 1;
    if (L == 1) return alphaSize - 1;
    long long res = alphaSize - 1;
    for (int i = 1; i < L; ++i) res *= alphaSize;
    return res;
}

// 计算字符串 s 在字母表 alpha 中的排名（排名从 1 开始，空串为第 1）
long long getRank(const string &s, const string &alpha, char special) {
    int m = alpha.size();
    int L = s.size();
    long long rank = 1; // 空串
    
    // 所有长度小于 L 的字符串数量
    for (int len = 1; len < L; ++len) {
        rank += countLen(len, m);
    }
    
    // 计算后缀的组合数：m^(L-1)
    long long suffix = 1;
    for (int i = L - 1; i >= 1; --i) suffix *= m;
    
    int specialIdx = alpha.find(special);
    int firstIdx = alpha.find(s[0]);
    
    // 第 1 位：统计比 s[0] 小且不是 special 的字符个数
    int cntBefore = 0;
    for (int i = 0; i < firstIdx; ++i) {
        if (i != specialIdx) cntBefore++;
    }
    rank += cntBefore * suffix; // 所有比 s[0] 小的首字母对应的字符串
    rank++; // s[0] 本身
    
    // 第 2 位及以后
    for (int pos = 1; pos < L; ++pos) {
        suffix /= m;
        int idx = alpha.find(s[pos]);
        rank += idx * suffix;
    }
    
    return rank;
}

// 根据排名构造字符串（排名从 1 开始，空串为第 1）
string buildString(long long rank, const string &alpha, char special) {
    if (rank == 1) return "";
    
    int m = alpha.size();
    long long remain = rank - 1; // 去掉空串
    
    // 确定长度
    int len = 1;
    while (true) {
        long long cnt = countLen(len, m);
        if (remain <= cnt) break;
        remain -= cnt;
        len++;
    }
    
    string res;
    
    // 构造第 1 位（不能是 special）
    long long block = 1;
    for (int i = 1; i < len; ++i) block *= m;
    int pos = (remain - 1) / block;
    int cnt2 = 0;
    for (int i = 0; i < m; ++i) {
        if (alpha[i] == special) continue;
        if (cnt2 == pos) {
            res += alpha[i];
            break;
        }
        cnt2++;
    }
    remain = (remain - 1) % block + 1;
    
    // 构造第 2 位及以后（可以任意选，包括 special）
    for (int i = 1; i < len; ++i) {
        block /= m;
        int idx = (remain - 1) / block;
        res += alpha[idx];
        remain = (remain - 1) % block + 1;
    }
    
    return res;
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        string msg, broken;
        cin >> msg >> broken;
        
        string full = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
        string avail;
        for (char c : full) {
            if (broken.find(c) == string::npos) avail += c;
        }
        
        long long r = getRank(msg, full, 'A');
        string ans = buildString(r, avail, avail[0]);
        cout << ans << endl;
    }
    return 0;
}
```

## 总结

本题的核心在于理解 **按长度优先的字典序排序** 以及 **双射排名** 的构造方法。通过预先计算每个长度下的字符串数量，我们可以高效地将字符串映射为排名，再反向映射回来。关键点包括：

1. 空串排在第 $1$ 位。
2. 长度 $L$ 的 LA 可编码字符串数量为 $(m-1) \times m^{L-1}$（$L \ge 1$）。
3. 排名计算时需要正确处理第一位的特殊限制。
4. 构造时需要根据排名确定长度，再逐位确定字符。

掌握这种排名方法对于解决字符串组合计数类问题非常有帮助。
