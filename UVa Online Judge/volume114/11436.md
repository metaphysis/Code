## 题目描述

给定一个正整数 $N$，要求找到两个正整数 $x$ 和 $y$，使得：

$$N = x^3 - y^3$$

**输入格式：**
- 最多 $2500$ 行输入
- 每行一个正整数 $N$（$0 < N \leq 25 \times 10^{12}$）
- 输入以单独一行的 $0$ 结束

**输出格式：**
- 对于每个 $N$，输出满足条件的 $x$ 和 $y$（用空格分隔）
- 如果无解，输出 `No solution`
- 如果有多解，输出 $y$ 值最小的解

## 题目分析

这是一个数论问题，需要求解立方差方程。由于 $N$ 的最大值达到 $25 \times 10^{12}$，直接暴力枚举 $x$ 和 $y$ 是不可行的。

### 关键数学洞察

利用立方差公式：
$$x^3 - y^3 = (x - y)(x^2 + xy + y^2)$$

设 $d = x - y$（$d > 0$），则：
$$N = d \cdot (x^2 + xy + y^2)$$

由于 $x = y + d$，代入得：
$$N = d \cdot [(y + d)^2 + (y + d)y + y^2]$$
$$N = d \cdot (3y^2 + 3dy + d^2)$$

令 $m = \frac{N}{d}$，则：
$$m = 3y^2 + 3dy + d^2$$

整理为关于 $y$ 的二次方程：
$$3y^2 + 3dy + (d^2 - m) = 0$$

### 求解策略

对于每个可能的 $d$（$N$ 的因子），我们可以：

1. 计算 $m = \frac{N}{d}$
2. 计算判别式 $\Delta = 9d^2 - 12(d^2 - m) = 12m - 3d^2$
3. 检查 $\Delta$ 是否为完全平方数
4. 如果是，计算 $y = \frac{-3d + \sqrt{\Delta}}{6}$
5. 验证 $y$ 是否为正整数，且 $x = y + d$ 满足原方程

### 算法优化

1. **枚举范围**：$d$ 只需枚举到约 $\sqrt[3]{2N}$，因为当 $y = 1$ 时，$x^3 - 1 \approx N$
2. **提前检查**：只有当 $d$ 是 $N$ 的因子时才进行后续计算
3. **最优解选择**：记录所有解中 $y$ 值最小的那个

## 解题思路详解

### 步骤 1：数学推导

从立方差公式出发：
$$x^3 - y^3 = (x - y)(x^2 + xy + y^2) = N$$

设 $d = x - y$，则 $x = y + d$，代入得：
$$N = d[(y + d)^2 + (y + d)y + y^2]$$
$$N = d[y^2 + 2dy + d^2 + y^2 + dy + y^2]$$
$$N = d[3y^2 + 3dy + d^2]$$

### 步骤 2：二次方程求解

令 $m = \frac{N}{d}$，则：
$$3y^2 + 3dy + d^2 = m$$
$$3y^2 + 3dy + (d^2 - m) = 0$$

这是一个关于 $y$ 的二次方程，判别式为：
$$\Delta = (3d)^2 - 4 \cdot 3 \cdot (d^2 - m) = 9d^2 - 12d^2 + 12m = 12m - 3d^2$$

解为：
$$y = \frac{-3d \pm \sqrt{\Delta}}{6}$$

由于 $y > 0$，我们取：
$$y = \frac{-3d + \sqrt{\Delta}}{6}$$

### 步骤 3：算法实现

1. 枚举所有可能的 $d$ 值
2. 检查 $d$ 是否是 $N$ 的因子
3. 计算判别式并检查是否为完全平方数
4. 计算 $y$ 并验证是否为正整数
5. 更新最优解（$y$ 最小的解）

### 步骤 4：复杂度分析

- $d$ 的枚举范围：$O(\sqrt[3]{N})$
- 对于每个 $d$，计算都是 $O(1)$ 的
- 总体复杂度：$O(\sqrt[3]{N})$，对于 $N \leq 25 \times 10^{12}$ 是可接受的

```cpp
// Cubes EXTREME

#include <iostream>
#include <cmath>
#include <algorithm>
#include <climits>
using namespace std;

typedef long long ll;

void findSolution(ll n) {
    ll bestX = -1, bestY = -1;
    
    // 枚举差值 d = x - y，从小到大枚举
    // d 的范围：1 <= d <= ∛(2N) 左右
    ll maxD = pow(2.0 * n, 1.0/3.0) + 1000;
    
    for (ll d = 1; d <= maxD; d++) {
        // 检查 d 是否是 N 的因子
        if (n % d != 0) continue;
        
        ll m = n / d;
        
        // 解方程：3y² + 3dy + (d² - m) = 0
        ll discriminant = 12LL * m - 3LL * d * d;
        if (discriminant < 0) continue;
        
        ll sqrtDisc = sqrt(discriminant);
        if (sqrtDisc * sqrtDisc != discriminant) continue;
        
        // y = (-3d + sqrtDisc) / 6 必须为正整数
        ll numerator = -3LL * d + sqrtDisc;
        if (numerator > 0 && numerator % 6 == 0) {
            ll y = numerator / 6;
            ll x = y + d;
            
            // 验证解
            if (x * x * x - y * y * y == n) {
                // 更新最优解（y 最小的）
                if (bestY == -1 || y < bestY) {
                    bestY = y;
                    bestX = x;
                }
            }
        }
    }
    
    if (bestY == -1) {
        cout << "No solution" << endl;
    } else {
        cout << bestX << " " << bestY << endl;
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    ll n;
    while (cin >> n && n != 0) {
        findSolution(n);
    }
    
    return 0;
}
```

## 总结

本题的关键在于将立方差问题转化为二次方程求解问题，通过数学推导大大减少了需要枚举的范围。算法的时间复杂度为 $O(\sqrt[3]{N})$，能够高效处理 $N$ 达到 $25 \times 10^{12}$ 的大数据情况。

**核心技巧：**
1. 利用立方差公式进行因式分解
2. 设 $d = x - y$ 减少变量数量
3. 通过二次方程求解 $y$
4. 枚举所有可能的 $d$ 并选择最优解

这种将高次方程转化为低次方程求解的思路，在解决类似的数论问题时非常有用。
