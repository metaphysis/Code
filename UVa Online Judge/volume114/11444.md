## 题目描述

给定一个长度为 $n$ 的序列 $\mathrm{seq}[i]$（$i = 1$ 到 $n$）。定义函数

$$
F(k,a,b) = \sum_{i=a}^{b} \mathrm{seq}[i] \times (i - a + 1)^{k}
$$

其中 $0 \le k \le 20$，$1 \le a \le b \le n$。需要回答 $q$ 个查询，输出 $F(k,a,b) \bmod 1000000009$ 的值。

## 输入格式

第一行包含整数 $T$（$1 \le T \le 5$），表示测试用例的数量。

每个测试用例的第一行包含整数 $n$（$1 \le n \le 10^5$）。

第二行包含 $n$ 个整数 $\mathrm{seq}[1], \mathrm{seq}[2], \dots, \mathrm{seq}[n]$，每个整数在 $0$ 到 $10^8$ 之间。

第三行包含整数 $q$（$q \le 10^4$），表示查询数量。

接下来 $q$ 行，每行包含三个整数 $k, a, b$，其中 $0 \le k \le 20$，$1 \le a \le b \le n$。

## 输出格式

对于每个查询，输出一行一个整数，表示 $F(k,a,b) \bmod 1000000009$ 的值。

## 题目分析

本题的核心是高效计算多个区间查询 $F(k,a,b)$，其中 $k$ 的范围很小（$0$ 到 $20$）。直接按照定义计算每个查询，需要遍历区间 $[a,b]$ 内的每个元素，复杂度为 $O(nq)$，在 $n = 10^5$，$q = 10^4$ 时会达到 $10^9$ 量级，无法接受。

观察 $F(k,a,b)$ 的表达式：

$$
F(k,a,b) = \sum_{i=a}^{b} \mathrm{seq}[i] \times (i - a + 1)^{k}
$$

定义 $j = i - a + 1$，则 $j$ 从 $1$ 变化到 $b-a+1$，此时 $i = a + j - 1$。代入得：

$$
F(k,a,b) = \sum_{j=1}^{b-a+1} \mathrm{seq}[a+j-1] \times j^{k}
$$

这是关于 $j$ 的 $k$ 次幂加权和。然而 $a$ 在变化，直接预处理所有 $j^k$ 并不方便，因为 $j$ 的起始位置依赖于 $a$。

另一种思路是将 $(i - a + 1)^{k}$ 用二项式定理展开：

$$
(i - a + 1)^{k} = \sum_{t=0}^{k} \binom{k}{t} i^{t} (-a+1)^{k-t}
$$

代入 $F(k,a,b)$：

$$
F(k,a,b) = \sum_{t=0}^{k} \binom{k}{t} (-a+1)^{k-t} \sum_{i=a}^{b} \mathrm{seq}[i] \cdot i^{t}
$$

令 $S_t(x) = \sum_{i=1}^{x} \mathrm{seq}[i] \cdot i^{t}$，则 $\sum_{i=a}^{b} \mathrm{seq}[i] \cdot i^{t} = S_t(b) - S_t(a-1)$。

因此，如果我们能快速得到 $S_t(x)$ 的值，每个查询就可以在 $O(k)$ 时间内计算完毕。由于 $k \le 20$，$q \le 10^4$，总复杂度 $O(20 \cdot q)$ 是可行的。

## 解题思路

### 预处理

对于每个 $t = 0, 1, \dots, 20$，计算 $S_t(x)$ 对于所有 $x = 1, 2, \dots, n$ 的值：

$$
S_t(x) = \sum_{i=1}^{x} \mathrm{seq}[i] \cdot i^{t}
$$

其中 $i^{t}$ 需要模 $1000000009$ 计算。由于 $n$ 最大 $10^5$，$t$ 最大 $20$，预处理的复杂度为 $O(21 \cdot n)$，完全可行。

具体实现时，可以预先计算出所有 $i^t$ 的值，也可以每次用快速幂计算。由于 $t$ 很小，直接循环乘幂或使用 `std::pow` 并取模均可。

### 查询处理

对于每个查询 $(k, a, b)$，按公式计算：

$$
ans = \sum_{t=0}^{k} \binom{k}{t} \cdot (-a+1)^{k-t} \cdot (S_t(b) - S_t(a-1)) \pmod{MOD}
$$

其中 $\binom{k}{t}$ 是组合数，可以预处理出 $0 \le k \le 20$ 的所有组合数。

注意 $-a+1$ 可能为负数，需要先取模使其变为非负数：$(-a+1) \bmod MOD = ((-a+1) \% MOD + MOD) \% MOD$，然后使用快速幂计算其幂次。

### 复杂度分析

- **预处理组合数**：$O(21^2) = O(400)$，可忽略。
- **预处理 $S_t(x)$**：$O(21 \cdot n)$，约 $2.1 \times 10^6$ 次运算。
- **每个查询**：$O(k)$，$k \le 20$，$q \le 10^4$，最坏 $2 \times 10^5$ 次运算。
- **总复杂度**：$O(21 \cdot n + 20 \cdot q)$，完全可行。

### 模运算注意事项

- 模数 $MOD = 1000000009$ 是质数。
- 减法运算后需要加 $MOD$ 再取模，确保结果非负。
- 乘法运算使用 `long long` 暂存，防止溢出。

## 代码实现

```cpp
// Sum
// UVa ID: 11444
// Verdict: Accepted
// Submission Date: 2026-06-10
// UVa Run Time: 0.110s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int MOD = 1000000009;
const int MAX_N = 100005;
const int MAX_K = 21;

ll seq[MAX_N];
ll prefixSum[MAX_K][MAX_N]; // prefixSum[t][i] = sum_{j=1..i} seq[j] * j^t
ll comb[MAX_K][MAX_K];      // 组合数

void initComb() {
    for (int i = 0; i < MAX_K; i++) {
        comb[i][0] = comb[i][i] = 1;
        for (int j = 1; j < i; j++)
            comb[i][j] = (comb[i-1][j-1] + comb[i-1][j]) % MOD;
    }
}

ll modPow(ll a, ll e) {
    ll res = 1;
    a %= MOD;
    while (e) {
        if (e & 1) res = res * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    initComb();
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> seq[i];
            seq[i] %= MOD;
        }

        // 预处理前缀和
        for (int t = 0; t < MAX_K; t++) {
            prefixSum[t][0] = 0;
            for (int i = 1; i <= n; i++) {
                ll powI = modPow(i, t);
                prefixSum[t][i] = (prefixSum[t][i-1] + seq[i] * powI) % MOD;
            }
        }

        int q;
        cin >> q;
        while (q--) {
            int k, a, b;
            cin >> k >> a >> b;
            ll ans = 0;
            for (int t = 0; t <= k; t++) {
                ll sumT = (prefixSum[t][b] - prefixSum[t][a-1]) % MOD;
                if (sumT < 0) sumT += MOD;
                ll term = comb[k][t] * sumT % MOD;
                // 计算 (-a+1)^(k-t)
                ll base = (-a + 1) % MOD;
                if (base < 0) base += MOD;
                ll powVal = modPow(base, k - t);
                ans = (ans + term * powVal) % MOD;
            }
            cout << ans << "\n";
        }
    }
    return 0;
}
```

## 总结

本题的核心技巧是：

1. **利用二项式展开**将 $(i - a + 1)^k$ 转化为 $i$ 的多项式，分离出与 $a$ 无关的部分，从而可以用前缀和预处理。
2. **注意到 $k$ 很小**（$0 \le k \le 20$），使得我们可以对每个幂次 $t$ 分别维护前缀和，将每个查询的复杂度从 $O(n)$ 降为 $O(k)$。
3. **模运算细节**：注意负数取模和中间结果使用 `long long` 防止溢出。

这种方法适用于一类区间求和问题，其中被加项可以分解为 $f(i)$ 与 $g(a,i)$ 的乘积，且 $g$ 可以展开为 $i$ 的多项式。当多项式次数较低时，预处理不同幂次的前缀和是常见且高效的策略。
