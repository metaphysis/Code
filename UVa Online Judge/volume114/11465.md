[UVa 11465 Count the Polygons](https://blog.csdn.net/metaphysis/article/details/160718365)

## 题目描述

给定 $N$ 根长度各异的棍子，问有多少种方式从中选出 $K$ 根，并以它们为边构成一个 $K$ 边形。多边形构成的条件是：**最长边的长度小于其余 $K-1$ 条边的长度之和**。

### 输入格式
- 第一行：测试用例数 $T$（$T < 100$）
- 每个测试用例：
  - 第一行：$N$ 和 $K$（$3 \leq N \leq 30$，$3 \leq K \leq N$）
  - 第二行：$N$ 个整数，表示棍子长度（范围 $[1, 2^{31}]$）

### 输出格式
每个用例输出 `Case X: Y`，其中 $X$ 为用例编号，$Y$ 为合法多边形数量。

### 样例输入
```
4
4 3
10 10 20 20
6 4
1 1 1 1 1 1
4 3
10 20 30 10000000
6 6
2 3 4 5 6 7
```
### 样例输出
```
Case 1: 2
Case 2: 15
Case 3: 0
Case 4: 1
```

## 问题分析

### 多边形判定定理
对于 $K$ 条边，设其长度为 $a_1 \leq a_2 \leq \cdots \leq a_K$，则它们能构成多边形的充要条件是：
$$
a_K < a_1 + a_2 + \cdots + a_{K-1}
$$
等价地，设总和为 $S$，最长边为 $a_K$，则：
$$
2 \cdot a_K < S
$$

因此，问题转化为：从 $N$ 个数中选 $K$ 个，求满足 $2 \cdot \max(selected) < sum(selected)$ 的方案数。

### 数据规模约束
- $N \leq 30$，$K \leq N$
- 直接枚举所有组合：最坏情况 $C(30, 15) \approx 1.55 \times 10^8$，再乘以 $T=100$ 会严重超时（$2000\text{ms}$ 时限）
- 需要更高效的算法

## 解法一：折半搜索 + 双指针

### 核心思想
对于每个固定的最长边 $a_{\text{max}}$，我们需要在它之前的棍子中选 $K-1$ 根，使其和大于 $a_{\text{max}}$。这是一个子集和计数问题，可以用折半搜索（$\texttt{Meet-in-the-Middle}$）优化。

### 算法步骤

1. **排序**：将棍子长度升序排序，记为 $S[0..N-1]$
2. **枚举最长边**：对于每个下标 $i$（$i \geq K-1$），令 $a_{\text{max}} = S[i]$
3. **取前缀**：考虑下标 $[0, i-1]$ 的棍子（共 $i$ 根）
4. **折半**：将前缀分为左半 $L$ 和右半 $R$
5. **枚举子集**：
   - 枚举 $L$ 的所有子集（包括空集），记录 `(cntL, sumL)`
   - 枚举 $R$ 的所有子集（包括空集），记录 `(cntR, sumR)`
6. **预处理右半**：对右半按 `cnt` 分组，每组内按 `sum` 排序
7. **统计**：对于左半的每个 `(cntL, sumL)`：
   - 计算需要的右半数量 `need = K-1 - cntL`
   - 若 `need < 0` 或 `need > R.size()`，跳过
   - 在右半 `need` 组中二分查找第一个 `sumR > maxLen - sumL` 的位置，累加后续数量
8. **去重**：每个组合只会被其最大值统计一次，不会重复

### 复杂度分析
- 对每个 $i$，子集枚举量为 $2^{i/2} + 2^{i-i/2} \approx 2 \cdot 2^{i/2}$
- $i$ 最大为 $29$，$2^{15} = 32768$，乘以常数 $2$ 约为 $65536$
- 排序复杂度 $O(2^{i/2} \log 2^{i/2})$
- 总操作约 $10^7$ 级别，对于 $T=100$ 可控制在 $2000\text{ms}$ 内

### 折半搜索代码

```cpp
// Count the Polygons
// UVa ID: 11465
// Verdict: Accepted
// Submission Date: 2026-05-02
// UVa Run Time: 0.110s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int n, K;
vector<long long> len;
long long ans;

// 计算组合数
long long C[31][31];
void initC() {
    for (int i = 0; i <= 30; ++i) {
        C[i][0] = C[i][i] = 1;
        for (int j = 1; j < i; ++j)
            C[i][j] = C[i - 1][j - 1] + C[i - 1][j];
    }
}

void solve() {
    sort(len.begin(), len.end());
    ans = 0;
    
    // 枚举最长边
    for (int maxIdx = K - 1; maxIdx < n; ++maxIdx) {
        long long maxLen = len[maxIdx];
        int m = maxIdx;  // 前面有 m 根棍子
        
        if (m < K - 1) continue;
        
        // 折半
        int mid = m / 2;
        vector<long long> leftArr(len.begin(), len.begin() + mid);
        vector<long long> rightArr(len.begin() + mid, len.begin() + m);
        
        // 枚举左半所有子集 (cnt, sum)
        vector<pair<int, long long>> leftSub;
        int leftSz = leftArr.size();
        for (int mask = 0; mask < (1 << leftSz); ++mask) {
            int cnt = 0;
            long long sum = 0;
            for (int j = 0; j < leftSz; ++j) if (mask >> j & 1) {
                cnt++;
                sum += leftArr[j];
            }
            leftSub.emplace_back(cnt, sum);
        }
        
        // 枚举右半所有子集 (cnt, sum)，并按 cnt 分组
        int rightSz = rightArr.size();
        vector<vector<long long>> rightSumByCnt(K + 1);
        for (int mask = 0; mask < (1 << rightSz); ++mask) {
            int cnt = 0;
            long long sum = 0;
            for (int j = 0; j < rightSz; ++j) if (mask >> j & 1) {
                cnt++;
                sum += rightArr[j];
            }
            if (cnt <= K - 1) rightSumByCnt[cnt].push_back(sum);
        }
        
        // 对每组排序，便于二分
        for (int c = 0; c <= K - 1; ++c)
            sort(rightSumByCnt[c].begin(), rightSumByCnt[c].end());
        
        // 统计
        for (auto &p : leftSub) {
            int cntL = p.first;
            long long sumL = p.second;
            int need = K - 1 - cntL;
            if (need < 0 || need > rightSz) continue;
            
            auto &vec = rightSumByCnt[need];
            long long target = maxLen - sumL;
            // 找第一个 > target 的位置
            int pos = upper_bound(vec.begin(), vec.end(), target) - vec.begin();
            ans += (vec.size() - pos);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    initC();
    
    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        cin >> n >> K;
        len.resize(n);
        for (int i = 0; i < n; ++i) cin >> len[i];
        
        solve();
        
        cout << "Case " << caseNo << ": " << ans << "\n";
    }
    return 0;
}
```

## 解法二：回溯法 + 强力剪枝（最优解）

### 核心思想
采用 $\texttt{DFS}$ 回溯，配合以下剪枝策略，可以将搜索复杂度降至可接受范围：

1. **逆序选择**：从大到小选棍子，可以更快触发剪枝条件
2. **条件转化**：设 `remain = maxLen - curSum`，则合法条件 `curSum > maxLen` 等价于 `remain < 0`
3. **上界剪枝**：如果 `remain >= S[last] * cnt`，说明即使选剩余中最大的 `cnt` 根，也无法使 `remain` 变成负数，直接剪枝
4. **下界剪枝**：如果 `remain < S[0] * cnt`，说明即使选剩余中最小的 `cnt` 根，也会使 `remain` 变成负数，此时剩余所有选法都合法，直接用组合数累加

### 递归函数设计
```cpp
void dfs(long long remain, int last, int cnt)
```
- `remain`：当前还需要减少多少才能满足条件（`maxLen - curSum`）
- `last`：当前可选的棍子最大下标（已排序，逆序选择）
- `cnt`：还需要选多少根棍子

### 剪枝说明

| 剪枝条件 | 含义 | 处理方式 |
|---------|------|----------|
| `cnt == 0` | 已选满 $K-1$ 根 | 若 `remain < 0` 则合法，答案加 $1$ |
| `remain >= S[last] * cnt` | 即使选最大的 `cnt` 根也无法满足 | 直接返回 |
| `remain < S[0] * cnt` | 即使选最小的 `cnt` 根也能满足 | 直接用组合数 $C_{last+1}^{cnt}$ 加到答案 |
| 否则 | 无法直接判断 | 枚举选或不选当前棍子 |

### 复杂度分析
- 最坏情况（所有长度相等且条件难满足）仍可能枚举所有组合
- 但由于剪枝强力且数据随机，实际运行极快，本例中达到 $0\text{ms}$
- 这是本题的最优解法

### 回溯剪枝代码

```cpp
// Count the Polygons
// UVa ID: 11465
// Verdict: Accepted
// Submission Date: 2026-05-02
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int n, K;
vector<long long> S;
long long ans;
long long C[31][31];

// remain = maxLen - curSum, last为当前可选的最大下标, cnt为还需选的数量
void dfs(long long remain, int last, int cnt) {
    if (cnt == 0) {
        ans += (remain < 0);  // remain < 0 表示 curSum > maxLen
        return;
    }
    // 剪枝1：即使选最大的cnt根也无法使remain < 0
    if (remain >= S[last] * cnt) return;
    // 剪枝2：即使选最小的cnt根也能使remain < 0，直接组合数
    if (remain < S[0] * cnt) {
        ans += C[last + 1][cnt];
        return;
    }
    // 枚举选择当前棍子（从大到小选）
    for (int i = last; i >= cnt - 1; --i)
        dfs(remain - S[i], i - 1, cnt - 1);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    // 预计算组合数 C[n][m]
    for (int i = 0; i <= 30; ++i) {
        C[i][0] = C[i][i] = 1;
        for (int j = 1; j < i; ++j)
            C[i][j] = C[i - 1][j - 1] + C[i - 1][j];
    }
    
    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        cin >> n >> K;
        S.resize(n);
        for (int i = 0; i < n; ++i) cin >> S[i];
        sort(S.begin(), S.end());  // 升序排序
        
        ans = 0;
        // 枚举最长边，其他边从 [0, i-1] 中选 K-1 根
        for (int i = K - 1; i < n; ++i)
            dfs(S[i], i - 1, K - 1);
        
        cout << "Case " << caseNo << ": " << ans << "\n";
    }
    return 0;
}
```

## 两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 编码难度 | 实际速度 |
|-----|-----------|-----------|---------|---------|
| 折半搜索 + 双指针 | $O(N \cdot 2^{N/2} \log(2^{N/2}))$ | $O(2^{N/2})$ | 中等 | 较快 |
| 回溯 + 剪枝 | 平均远优于枚举，最坏 $O(C(N,K))$ | $O(K)$ | 简单 | 极快（$0\text{ms}$） |

## 总结

两种方法均能通过本题，但回溯 + 剪枝以其简洁性和极致的效率成为首选。核心在于将判定条件转化为 `remain` 形式，并利用排序后的数组特性设计了上下界双重剪枝，使得搜索空间大幅缩减。

对于 $N \leq 30$ 的数据范围：
- 折半搜索提供了稳定的理论保证
- 回溯剪枝则利用数据特性达到了实际最优

建议优先掌握回溯剪枝的写法，它在同类组合计数问题中具有广泛的适用性。
