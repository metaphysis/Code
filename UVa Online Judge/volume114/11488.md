## 题目描述

我们定义一个字符串集合的 **前缀优度（$\texttt{prefix goodness}$）** 为：

> 该集合中所有字符串的 **最长公共前缀的长度** 乘以 **集合中字符串的个数**

例如，集合 $\{\texttt{000}, \texttt{001}, \texttt{0011}\}$ 的最长公共前缀是 $\texttt{00}$，长度为 $2$，集合大小为 $3$，因此前缀优度为 $2 \times 3 = 6$。

给定 $T$ 个测试用例，每个测试用例给出 $n$ 个只包含 $\texttt{0}$ 和 $\texttt{1}$ 的二进制字符串，要求找出所有可能的子集中，最大的前缀优度。

**输入限制：**
- $T \leq 20$
- $n \leq 50000$
- 每个字符串长度不超过 $200$

---

## 题目分析

### 问题转化

我们需要在所有可能的子集中找到最大的前缀优度。直接枚举所有子集显然不可行（$2^n$ 太大），因此需要寻找更高效的方法。

**关键观察：**
- 对于任意一个子集，它的最长公共前缀（$\texttt{LCP}$）就是该子集中所有字符串的公共前缀。
- 如果我们固定一个前缀 $P$，那么所有 **以 $P$ 开头** 的字符串组成的子集，其最长公共前缀长度至少为 $|P|$。
- 因此，对于每个可能的前缀 $P$，我们可以计算：
  $$
  goodness = |P| \times count(P)
  $$
  其中 $count(P)$ 是以 $P$ 为前缀的字符串数量。

### 高效解法：$\texttt{Trie}$（前缀树）

$\texttt{Trie}$ 是处理前缀相关问题的理想数据结构：

1. **构建 $\texttt{Trie}$**：将所有字符串插入到 $\texttt{Trie}$ 中
2. **节点信息**：每个 $\texttt{Trie}$ 节点记录经过该节点的字符串数量 $cnt$
3. **计算优度**：对于深度为 $d$ 的节点，$depth \times cnt$ 就是一个候选的前缀优度
4. **取最大值**：遍历 $\texttt{Trie}$ 中所有节点，记录最大的 $depth \times cnt$

**为什么这样正确？**
- 深度为 $d$ 的节点对应长度为 $d$ 的前缀
- 经过该节点的字符串数量 $cnt$ 就是以该前缀开头的字符串数量
- 这些字符串组成的任意子集，其最长公共前缀长度至少为 $d$，因此优度至少为 $d \times cnt$

### 复杂度分析

- **时间复杂度**：$O($总字符数$)$，即 $O(n \times L)$，其中 $L$ 是字符串平均长度
- **空间复杂度**：$O($总字符数$)$，$\texttt{Trie}$ 节点数不超过总字符数

在题目限制下（$n \leq 50000$，$L \leq 200$），总字符数最多约 $10^7$，完全可行。

## 算法实现
```cpp
// Hyper Prefix Sets
// UVa ID: 11488
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.070s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

// Trie 节点结构
struct TrieNode {
    TrieNode* child[2];  // 子节点，0 和 1 两个分支
    int cnt;             // 经过该节点的字符串数量
    TrieNode() {
        child[0] = child[1] = nullptr;
        cnt = 0;
    }
};

int ans;  // 记录最大前缀优度

// DFS 遍历 Trie，计算每个节点的 depth * cnt
void dfs(TrieNode* node, int depth) {
    if (node == nullptr) return;
    // 更新最大前缀优度
    ans = max(ans, depth * node->cnt);
    // 递归遍历两个子节点
    for (int i = 0; i < 2; i++) {
        if (node->child[i] != nullptr) {
            dfs(node->child[i], depth + 1);
        }
    }
}

void solve() {
    int n;
    cin >> n;
    TrieNode* root = new TrieNode();  // 创建 Trie 根节点
    // 插入所有字符串到 Trie 中
    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;
        TrieNode* cur = root;
        for (char ch : s) {
            int idx = ch - '0';  // 将字符 '0'/'1' 转换为索引 0/1
            // 如果子节点不存在，则创建
            if (cur->child[idx] == nullptr) {
                cur->child[idx] = new TrieNode();
            }
            cur = cur->child[idx];  // 移动到子节点
            cur->cnt++;  // 增加经过该节点的计数
        }
    }
    ans = 0;
    dfs(root, 0);  // 从根节点开始 DFS，深度为 0
    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```

## 代码说明

1. **$\texttt{TrieNode}$ 结构**：
   - `child[2]` 存储 $\texttt{0}$ 和 $\texttt{1}$ 两个分支
   - `cnt` 记录经过该节点的字符串数量

2. **插入过程**：
   - 遍历字符串的每个字符
   - 沿着对应分支向下，创建不存在的节点
   - 每经过一个节点就增加其 `cnt`

3. **$\texttt{DFS}$ 遍历**：
   - 对于每个节点，计算 `depth × cnt` 并更新最大值
   - 递归遍历所有子节点

4. **主函数**：
   - 处理多个测试用例
   - 对每个测试用例构建 $\texttt{Trie}$ 并计算答案

## 总结

本题展示了 $\texttt{Trie}$ 在解决前缀相关问题中的强大能力。通过将字符串组织成 $\texttt{Trie}$ 结构，我们能够高效地统计任意前缀的出现次数，从而快速计算出所有可能子集的最大前缀优度。

关键思路是将问题转化为 **对于每个前缀，计算前缀长度 × 拥有该前缀的字符串数量**，而 $\texttt{Trie}$ 正是实现这一思路的理想数据结构。
