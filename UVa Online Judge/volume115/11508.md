[UVa 11508 Life on Mars](https://blog.csdn.net/metaphysis/article/details/154350151)

## 题目描述

$\texttt{Stardust}$ 探测器发送回地球的消息是一个由自然数组成的非空序列 $S = S(0) S(1) \ldots S(n-1)$。科学家们担心这些消息可能被火星人拦截并篡改。

一个消息被认为是**有效的**，如果存在它的一个排列 $S'$，使得对于所有 $0 \leq i < |S'|$，都满足：

$$
S'[S'[i]] = S'[i]
$$

这个性质称为**幂等性**（$\texttt{idempotent}$）。如果不存在这样的排列，则消息被认为是**被黑客攻击的**。

## 输入格式

输入包含多个测试用例，每行一个。每个测试用例是一个 $\texttt{Stardust}$ 消息：一个自然数的非空序列，数字之间用空格分隔。输入以单独一行的 `0` 结束。

## 输出格式

对于每个测试用例：
- 如果消息有效，输出任意一个幂等排列（按输入格式）
- 如果消息无效，输出 `Message hacked by the Martians!!!`

## 题目分析

### 理解幂等性条件

幂等性条件 $S'[S'[i]] = S'[i]$ 意味着：对于数组中的每个位置 $i$，如果我们把 $S'[i]$ 作为下标去访问数组，得到的值必须等于 $S'[i]$。

这可以转化为更直观的理解：
- 如果值 $v$ 出现在数组中，那么位置 $v$ 的值必须是 $v$
- 换句话说：对于每个出现在数组中的值 $v$，如果 $v < n$（$n$ 是数组长度），那么 $S'[v]$ 必须等于 $v$

### 关键观察

1. **必要条件**：如果数组中存在任何大于等于 $n$ 的值，那么该消息一定是无效的。因为如果 $v \geq n$，那么 $S'[v]$ 会越界，无法满足幂等性条件。

2. **充分条件**：如果所有值都小于 $n$，那么总是可以构造一个幂等排列：
   - 对于每个值 $v$，将位置 $v$ 设置为 $v$
   - 剩余的位置可以用剩下的值任意填充

### 构造算法

对于有效的消息（所有值 $< n$）：

1. **固定必要位置**：对于每个值 $v$，如果 $v$ 在输入中出现过，那么位置 $v$ 必须设置为 $v$

2. **填充剩余位置**：将剩余的值填充到未被固定的位置中

这种构造方法保证：
- 如果位置 $i$ 被固定为 $i$，显然满足 $S'[S'[i]] = S'[i]$
- 如果位置 $i$ 没有被固定，设 $S'[i] = v$，那么 $S'[v] = v$（因为位置 $v$ 被固定），所以 $S'[S'[i]] = S'[v] = v = S'[i]$

## 解题思路

1. **读取输入**：逐行读取输入，直到遇到 `0`
2. **验证条件**：检查是否存在大于等于数组长度的值
3. **构造排列**：
   - 统计每个数字的出现频率
   - 首先固定必要的位置（$ans[v] = v$）
   - 然后将剩余的数字填充到空位中
4. **输出结果**：根据验证结果输出相应的消息

```cpp
// Life on Mars

#include <bits/stdc++.h>
using namespace std;

int main() {
    string inputLine;
    while (getline(cin, inputLine)) {
        // 检查结束条件
        if (inputLine == "0") break;
        
        istringstream inputStream(inputLine);
        vector<int> message;
        int number;
        
        // 读取消息序列
        while (inputStream >> number) {
            message.push_back(number);
        }
        
        int messageLength = message.size();
        bool isValid = true;
        
        // 检查是否存在大于等于数组长度的值
        for (int num : message) {
            if (num >= messageLength) {
                isValid = false;
                break;
            }
        }
        
        if (!isValid) {
            cout << "Message hacked by the Martians!!!" << endl;
            continue;
        }
        
        // 统计每个数字的出现频率
        vector<int> frequency(messageLength, 0);
        for (int num : message) {
            frequency[num]++;
        }
        
        // 初始化结果数组
        vector<int> resultArray(messageLength, -1);
        
        // 第一步：固定必要的位置
        for (int value = 0; value < messageLength; value++) {
            if (frequency[value] > 0) {
                resultArray[value] = value;
                frequency[value]--;
            }
        }
        
        // 第二步：填充剩余的数字
        for (int value = 0; value < messageLength; value++) {
            while (frequency[value] > 0) {
                // 找到空位置
                for (int position = 0; position < messageLength; position++) {
                    if (resultArray[position] == -1) {
                        resultArray[position] = value;
                        frequency[value]--;
                        break;
                    }
                }
            }
        }
        
        // 输出结果
        for (int i = 0; i < messageLength; i++) {
            if (i > 0) cout << " ";
            cout << resultArray[i];
        }
        cout << endl;
    }
    return 0;
}
```
