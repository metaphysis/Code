## 题目描述

考古学家在分析金字塔中的象形文字时发现了一种特殊的数字模式，称之为“金字塔数”。一个正整数 $n$ 被称为**金字塔数**，如果它可以被拆分为 $k$ 个正整数 $x_{1},x_{2},\dots ,x_{k}$，使得这些数的倒数之和等于 $1$ ，即

$$
\sum_{i=1}^{k} \frac{1}{x_i} = 1 。
$$

例如， $1 = \frac{1}{2} + \frac{1}{2}$ ，因此 $4$ （即 $2+2$ ）是一个金字塔数。

若上述拆分中所有 $x_i$ 互不相同，则称 $n$ 为**严格金字塔数**。例如， $1 = \frac{1}{2} + \frac{1}{3} + \frac{1}{6}$ ，因此 $11$ （即 $2+3+6$ ）是严格金字塔数，而 $4$ 只是金字塔数但不是严格金字塔数。

现在给定 $T$ 组询问，每组询问给出两个正整数 $a$ 和 $b$ ，要求计算区间 $[a,b]$ 内（包含端点）严格金字塔数的个数。

**输入格式**  
第一行一个整数 $T$ （ $T \le 100$ ），表示测试用例的数量。  
接下来 $T$ 行，每行两个整数 $a,b$ （ $1 \le a,b \le 10^6$ ）。

**输出格式**  
对于每组询问，输出一个整数，表示区间 $[a,b]$ 内严格金字塔数的个数。

## 题目分析

本题的核心是判断一个整数 $n$ 是否可以表示为若干**互不相同**的正整数的倒数之和为 $1$ 的形式。换句话说，我们需要找到一组互异的正整数 $x_1,x_2,\dots ,x_k$ ，满足

$$
\sum_{i=1}^{k} \frac{1}{x_i} = 1 \quad \text{且} \quad \sum_{i=1}^{k} x_i = n 。
$$

### 关键观察

通过数学研究（或查阅数论资料）可以得知一个非常重要的结论：**所有大于等于 $78$ 的整数都是严格金字塔数**。  
这一结论的证明思路是构造性的：对于任意 $n \ge 78$ ，总可以找到一组互不相同的正整数，使得它们的倒数之和为 $1$ ，且它们的和恰好为 $n$ 。

因此，问题的规模大大缩小：我们只需要关心 $n \le 77$ 的情况。对于 $n \le 77$ ，严格金字塔数的数量是有限的，可以通过枚举或打表得到。

### 打表得到的小规模严格金字塔数

通过枚举（或参考已有的数学结果）可以得到，在 $1$ 到 $77$ 之间，只有以下 $30$ 个数是严格金字塔数：

$$
\begin{aligned}
&1, 11, 24, 30, 31, 32, 37, 38, 43, 45, \\
&50, 52, 53, 54, 55, 57, 59, 60, 61, 62, \\
&64, 65, 66, 67, 69, 71, 73, 74, 75, 76 。
\end{aligned}
$$

注意： $1$ 是一个特殊的严格金字塔数（可以视为 $k=1$ 且 $x_1=1$ 的情形，虽然题目例子中没有给出，但根据定义是成立的）。

### 解题思路

基于以上观察，我们可以设计如下算法：

1. **预处理**：将 $n \le 77$ 的所有严格金字塔数存入一个数组。
2. **查询函数**：定义一个函数 $\texttt{countStrictPyramid}(n)$ ，用于计算不超过 $n$ 的严格金字塔数的个数。
   - 如果 $n \ge 78$ ，则 $78$ 到 $n$ 之间的所有整数都是严格金字塔数，这部分共有 $n-77$ 个。
   - 对于 $n \le 77$ 的部分，直接遍历预处理的数组，统计其中不超过 $n$ 的数的个数。
3. **回答询问**：对于每组询问 $[a,b]$ ，答案为  
   $$\texttt{countStrictPyramid}(b) - \texttt{countStrictPyramid}(a-1)。$$
   注意在计算前确保 $a \le b$ （若不满足则交换）。

### 复杂度分析

- **预处理**： $O(1)$ ，因为只需要存储 $30$ 个数。
- **每次查询**：对于 $n \le 77$ 的情况，最多遍历 $30$ 个数；对于 $n \ge 78$ 的情况，直接计算。因此单次查询时间复杂度为 $O(1)$ 。
- **总体复杂度**： $O(T)$ ，完全满足题目限制。

## 代码实现

```cpp
// Pyramid Number
// UVa ID: 11522

//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 小于78的严格金字塔数（打表）
const vector<int> strictPyramidUnder78 = {
    1, 11, 24, 30, 31, 32, 37, 38, 43, 45, 
    50, 52, 53, 54, 55, 57, 59, 60, 61, 62, 
    64, 65, 66, 67, 69, 71, 73, 74, 75, 76
};

// 统计不超过n的严格金字塔数个数
int countStrictPyramid(int n) {
    if (n <= 0) return 0;
    int count = 0;
    // 对于大于等于78的部分
    if (n >= 78) {
        count += n - 77;  // 78到n都是严格金字塔数
        n = 77;           // 只处理小于78的部分
    }
    // 统计小于78的严格金字塔数
    for (int x : strictPyramidUnder78) if (x <= n) count++;
    return count;
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int a, b;
        scanf("%d %d", &a, &b);
        // 确保a <= b
        if (a > b) swap(a, b);
        // 计算[a, b]区间内的严格金字塔数个数
        int result = countStrictPyramid(b) - countStrictPyramid(a - 1);
        printf("%d\n", result);
    }
    return 0;
}
```

## 总结

本题的关键在于发现 **所有大于等于 $78$ 的整数都是严格金字塔数** 这一数学结论。利用这一结论，我们只需要对 $n \le 77$ 的情况进行打表，即可在 $O(1)$ 时间内回答每次查询。这种结合数学结论与打表的方法，在编程竞赛中处理具有特殊性质的数论问题时非常高效。
