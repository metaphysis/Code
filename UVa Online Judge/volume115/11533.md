## 题目描述

一个 $N$ 进制正整数，其最后一位（个位）数字为 $X$。将该数字的最后一位 $X$ 移动到最左边，得到的新数字是原数字的 $Y$ 倍。给定 $N$、$X$ 和 $Y$，求满足条件的最小正整数。若无解，输出 `No solution`。

## 输入格式

输入包含不超过 $1000$ 个测试用例。每个测试用例一行，包含三个整数 $N$、$X$、$Y$，其中 $2 \le N \le 256$，$0 \le X < N$，$Y \ge 0$。

## 输出格式

对于每个测试用例，输出 `Case i:`，后跟目标数字的各位数字，每个数字之间用一个空格分隔。若无解，输出 `No solution`。

## 样例

输入

```
0 6 4
10 3 1
123 31 3
```

输出

```
Case 1: 1 5 3 8 4 6
Case 2: 3
Case 3: 10 44 55 100 74 65 103 116 79 108 77 25 90 71 23 89 111 119 39 95 31 92 71 105 117 39 13 4 42 55 18 47 15 87 29 9 85 28 50 57 101 33 93 31
```

## 题目分析

本题是一个经典的循环移位乘法问题。设原数字为 $A$，其 $N$ 进制表示为：

$$
A = d_{k-1} d_{k-2} \dots d_1 X
$$

其中 $k$ 为数字的位数，$X$ 是个位数字。去掉最后一位 $X$ 后剩下的部分记为 $M$，则：

$$
A = M \cdot N + X
$$

将 $X$ 移动到最左边后得到新数字 $B$：

$$
B = X \cdot N^{k-1} + M
$$

根据题意，$B = Y \cdot A$，代入得：

$$
X \cdot N^{k-1} + M = Y \cdot (M \cdot N + X)
$$

整理可得：

$$
X \cdot N^{k-1} - Y X = Y M N - M
$$

$$
X (N^{k-1} - Y) = M (Y N - 1)
$$

令 $D = Y N - 1$，则：

$$
M = \frac{X (N^{k-1} - Y)}{D}
$$

要求 $M$ 为整数且 $0 \le M < N^{k-1}$，同时 $A$ 的 $N$ 进制表示中允许最高位为 $0$（即允许前导零）。

## 解题思路

### 方法一：$\texttt{BSGS}$ 离散对数法

由 $M$ 为整数的条件可知：

$$
D \mid X (N^{k-1} - Y)
$$

设 $g = \gcd(X, D)$，$D' = D / g$，则上述整除条件等价于：

$$
N^{k-1} \equiv Y \pmod{D'}
$$

这是一个标准的离散对数问题：求最小的非负整数 $e = k-1$ 使得 $N^e \equiv Y \pmod{D'}$。

当 $D' = 1$ 时，同余式恒成立，取 $e = 0$，此时 $k = 1$，原数字即为一位数 $X$。

当 $D' > 1$ 时，需要使用扩展 $\texttt{BSGS}$ 算法求解。扩展 $\texttt{BSGS}$ 能处理模数与底数不互质的情况，其核心思想是：

1. 若 $\gcd(N, D') = 1$，直接使用普通 $\texttt{BSGS}$。
2. 否则，不断提取公因子 $g = \gcd(N, D')$，直到互质。每次提取时检查 $Y$ 是否能被 $g$ 整除，否则无解。

求出 $e$ 后，即可计算 $M$ 的数值，进而构造原数字。由于 $N^e$ 可能极大，需要使用高精度整数。最后输出时需注意保留前导零，确保输出位数为 $k$。

**时间复杂度**：$O(\sqrt{D'})$，其中 $D' = (Y N - 1) / \gcd(X, Y N - 1)$。

### 方法二：竖式乘法模拟法

方法一虽然严谨，但实现复杂且需要高精度运算。实际上，本题有更简洁的解法 —— 直接模拟竖式乘法过程。

考虑原数字的构造过程。设原数字从高位到低位为 $d_0, d_1, \dots, d_{k-2}, X$，其中 $d_0$ 为最高位。新数字为 $X, d_0, d_1, \dots, d_{k-2}$，且满足新数字是原数字的 $Y$ 倍。

从个位开始模拟乘法：个位已知为 $X$，计算 $Y \times X$，其个位即为 $d_{k-2}$，进位为 $c_1 = \lfloor Y \times X / N \rfloor$。然后计算 $Y \times d_{k-2} + c_1$，其个位即为 $d_{k-3}$，依此类推。

这个过程本质上是在做一次竖式乘法，不断产生新的高位数字。当某一步计算得到的新数字等于 $X$ 且当前进位为 $0$ 时，说明已经完成了一个完整的循环，此时已构造出的所有数字（除最后一位外）即为原数字的各位。

因此，算法流程如下：

1. 初始化数字列表 $\textit{digits} = [X]$，进位 $\textit{carry} = 0$。
2. 重复以下步骤：
   - 计算 $\textit{val} = \textit{carry} + \textit{digits}.\textit{back}() \times Y$。
   - 新数字 $\textit{newDigit} = \textit{val} \bmod N$。
   - 更新 $\textit{carry} = \lfloor \textit{val} / N \rfloor$。
   - 将 $\textit{newDigit}$ 加入 $\textit{digits}$。
   - 若 $\textit{carry} = 0$ 且 $\textit{newDigit} = X$，则找到解，跳出循环。
3. 移除 $\textit{digits}$ 的最后一位（重复的 $X$），反转后输出。

该算法无需高精度，也无需复杂的数论推导，仅需 $O(k)$ 时间和 $O(1)$ 额外空间。循环次数上界为 $D = Y N - 1$，在实际数据范围内可以接受。

**时间复杂度**：$O(k)$，其中 $k$ 为结果数字的位数。

    while (cin >> N >> X >> Y) {
        cout << "Case " << caseNum++ << ":";
        
        // 特殊处理 X = 0
        if (X == 0) {
            cout << " 0\n";
            continue;
        }
        // 特殊处理 Y = 0
        if (Y == 0) {
            cout << " No solution\n";
            continue;
        }
        
        vector<int> digits;
        digits.push_back(X);  // 个位
        long long carry = 0;
        bool found = false;
        
        // 模拟乘法过程，最多尝试 100000 次
        for (int step = 1; step <= 100000; ++step) {
            long long val = carry + (long long)digits.back() * Y;
            int newDigit = val % N;
            carry = val / N;
            digits.push_back(newDigit);
            
            // 检查是否回到起点：进位为 0 且当前位等于 X
            if (carry == 0 && newDigit == X) {
                digits.pop_back();  // 去掉重复的 X
                found = true;
                break;
            }
        }
        
        if (!found) {
            cout << " No solution\n";
            continue;
        }
        
        // 反转得到从高位到低位的顺序
        reverse(digits.begin(), digits.end());
        for (int d : digits) cout << " " << d;
        cout << "\n";
    }
    return 0;
}

## 参考代码（$\texttt{BSGS}$ 算法）

```cpp
// Special Number
// UVa ID: 11533
// Verdict: Accepted
// Submission Date: 2026-06-05
// UVa Run Time: 0.150s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

long long invMod(long long a, long long mod) {
    long long x, y;
    exgcd(a, mod, x, y);
    return (x % mod + mod) % mod;
}

long long mulMod(long long a, long long b, long long mod) {
    if (mod <= 1000000000) return a * b % mod;
    long long res = 0;
    a %= mod;
    while (b) {
        if (b & 1) res = (res + a) % mod;
        a = (a + a) % mod;
        b >>= 1;
    }
    return res;
}

long long powMod(long long a, long long b, long long mod) {
    long long res = 1 % mod;
    a %= mod;
    while (b) {
        if (b & 1) res = mulMod(res, a, mod);
        a = mulMod(a, a, mod);
        b >>= 1;
    }
    return res;
}

long long bsgs(long long a, long long b, long long p) {
    a %= p; b %= p;
    if (p == 1) return (b == 0) ? 0 : -1;
    if (b == 1) return 0;
    
    long long m = (long long)ceil(sqrt(p));
    unordered_map<long long, long long> baby;
    baby.reserve(m + 5);
    
    long long e = 1;
    for (long long i = 0; i < m; ++i) {
        if (baby.find(e) == baby.end()) baby[e] = i;
        e = mulMod(e, a, p);
    }
    
    long long am = powMod(a, m, p);
    long long inv_am = invMod(am, p);
    long long gamma = b;
    for (long long i = 0; i <= m; ++i) {
        auto it = baby.find(gamma);
        if (it != baby.end()) return i * m + it->second;
        gamma = mulMod(gamma, inv_am, p);
    }
    return -1;
}

long long exBSGS(long long a, long long b, long long p) {
    a %= p; b %= p;
    if (p == 1) return (b == 0) ? 0 : -1;
    if (b == 1) return 0;
    
    long long g = __gcd(a, p);
    if (g == 1) return bsgs(a, b, p);
    
    if (b % g != 0) return -1;
    
    long long na = a / g;
    long long nb = b / g;
    long long np = p / g;
    
    long long inv_na = invMod(na, np);
    long long new_b = mulMod(nb, inv_na, np);
    
    long long res = exBSGS(a, new_b, np);
    if (res == -1) return -1;
    return res + 1;
}

// 构造原数字：通过模拟竖式乘法从低位向高位递推
// 返回原数字的各位（从最高位到最低位），包含前导零
vector<int> constructNumber(int N, int X, int Y, long long k) {
    vector<int> digits(k);
    digits[k - 1] = X;  // 个位
    
    long long carry = 0;
    for (int i = k - 1; i >= 1; --i) {
        long long val = carry + (long long)digits[i] * Y;
        digits[i - 1] = val % N;
        carry = val / N;
    }
    
    // 验证：最终进位应该等于 X
    // 如果 carry != X，说明无解（但理论上不会发生）
    return digits;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int N, X, Y, caseNum = 1;
    while (cin >> N >> X >> Y) {
        cout << "Case " << caseNum++ << ":";
        
        if (X == 0) {
            cout << " 0\n";
            continue;
        }
        if (Y == 0) {
            cout << " No solution\n";
            continue;
        }
        
        long long D = (long long)Y * N - 1;
        if (D <= 0) {
            cout << " No solution\n";
            continue;
        }
        
        long long g = __gcd((long long)X, D);
        long long Dprime = D / g;
        
        if (Dprime == 1) {
            cout << " " << X << "\n";
            continue;
        }
        
        long long e = exBSGS(N, Y % Dprime, Dprime);
        if (e == -1) {
            cout << " No solution\n";
            continue;
        }
        
        long long k = e + 1;
        vector<int> digits = constructNumber(N, X, Y, k);
        
        for (int d : digits) cout << " " << d;
        cout << "\n";
    }
    return 0;
}
```

## 总结

本题看似复杂，涉及进制转换和倍数关系，但通过将问题转化为竖式乘法模拟，可以极其简洁地求解。

**核心技巧**：
1. 将数字的构造过程视为从个位开始不断乘 $Y$ 并取模的过程。
2. 当进位为 $0$ 且当前位等于初始的 $X$ 时，即找到了一个完整的循环。
3. 模拟法避免了
4. 高精度运算和复杂的数论推导，代码简洁且效率高。

**两种方法对比**：
- **$\texttt{BSGS}$ 法**：理论完备，适用于更一般的离散对数问题，但实现复杂，需要高精度支持。
- **模拟法**：针对本题的特殊结构，充分利用了循环移位乘法的性质，简单高效，是竞赛中的首选。

本题提醒我们：在解决算法问题时，不要一开始就陷入复杂的数学模型，有时从问题本身的结构出发，寻找更直接的构造方法，会有意想不到的收获。
