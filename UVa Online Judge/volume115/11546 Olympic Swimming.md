
> **摘要**：本题要求在 $K$ 条泳道的栏架分布中，找出两个长度标记 $a<b$，使得区间内每条泳道的栏架数量都相同，并最大化区间长度 $b-a$。核心思路是构造每条泳道的前缀和，将公平条件转化为「差异向量 $D[x]=(S_1[x]-S_2[x],\dots,S_1[x]-S_K[x])$ 相等」，再用哈希表记录每个差异向量首次出现的位置，线性扫描求最远相同状态，时间复杂度 $O(K\cdot L)$。

## 题目描述

在游泳跨栏项目中，泳池长度为 $L$ 米，被划分成 $K$ 条等宽泳道。沿长度方向，从一端 $0$ 开始，每隔 $1$ 米有一个长度标记。每个泳道内，在任意两个相邻长度标记之间至多放置一个栏架（即栏架只可能位于区间 $[p, p+1)$ 内，其中 $p$ 为整数标记）。不同泳道的栏架分布可以不同。

为了保证公平，需要选择两个长度标记 $a$ 和 $b$（$a < b$），使得从 $a$ 到 $b$ 的区间内，每一个泳道所包含的栏架数量都相同。题目保证所选路线一定起始于某个长度标记。要求找出满足条件的最长区间长度 $b - a$。

## 输入格式

每个测试用例的第一行包含两个整数 $L$ 和 $K$（$0 < L \le 50000$，$1 \le K \le 30$）。接下来 $K$ 行，每行描述一个泳道的栏架分布。每行以一个整数 $n$（$0 \le n \le 5000$）开头，表示该泳道的栏架数量，随后给出 $n$ 个整数 $p_i$（$0 \le p_i < L$），每个 $p_i$ 表示该泳道在长度标记 $p_i$ 与 $p_i + 1$ 之间有一个栏架。

输入以一行 `0 0` 结束。测试用例数量不超过 $60$。

## 输出格式

对于每个测试用例，输出一行 `Case #X: Y meter(s)`，其中 $X$ 为测试用例编号（从 $1$ 开始），$Y$ 为所求的最长比赛距离（即满足条件的最长区间长度）。

## 样例

输入

```
5 2
2 1 3
1 0
5 3
3 0 3 4
2 0 3
2 3 4
0 0
```

输出

```
Case #1: 3 meter(s)
Case #2: 3 meter(s)
```

## 题目分析

对于任意两个标记 $a$ 和 $b$，设第 $i$ 条泳道在区间 $(a, b)$ 内的栏架数量为 $C_i(a, b)$。公平条件要求对所有 $i$，$C_i(a, b)$ 都相等，即  
$$
C_1(a, b) = C_2(a, b) = \dots = C_K(a, b).
$$

定义第 $i$ 条泳道的前缀和 $S_i[x]$ 表示从 $0$ 到标记 $x$（不包含 $x$）之间的栏架总数，即位置 $< x$ 的栏架个数。那么  
$$
C_i(a, b) = S_i[b] - S_i[a].
$$

于是公平条件等价于对任意两条泳道 $i, j$：  
$$
S_i[b] - S_i[a] = S_j[b] - S_j[a] \quad\Longleftrightarrow\quad S_i[b] - S_j[b] = S_i[a] - S_j[a].
$$

这说明，如果我们固定某一条泳道（例如第 $1$ 条）作为参考，定义差异向量  
$$
D[x] = \bigl(S_1[x] - S_2[x],\; S_1[x] - S_3[x],\; \dots,\; S_1[x] - S_K[x]\bigr),
$$
那么 $a$ 和 $b$ 满足公平条件当且仅当 $D[a] = D[b]$。

因此，问题转化为：在标记点 $0, 1, \dots, L$ 中，找到两个不同的标记 $a < b$，使得它们的差异向量相等，并最大化 $b - a$。

## 解题思路

### 1. 前缀和计算

对于每个泳道，我们首先将栏架位置转换为长度为 $L$ 的布尔数组 `mark[p]`，表示区间 $[p, p+1)$ 是否有栏架。然后计算前缀和 `prefixSum[i][x]`（$x$ 从 $0$ 到 $L$），其中  
$$
\textit{prefixSum}[i][0] = 0,\quad \textit{prefixSum}[i][x] = \textit{prefixSum}[i][x-1] + \textit{mark}[x-1].
$$

这样，$S_i[x]$ 即为上述前缀和。

### 2. 差异向量与哈希

依次扫描 $x = 0, 1, \dots, L$，构造差异向量 $D[x]$。该向量长度为 $K-1$（当 $K=1$ 时为空向量）。使用一个 `map<vector<int>, int>` 记录每个差异向量首次出现的标记位置。若当前向量已经出现过，则用当前标记减去该首次出现标记，更新答案最大值。

由于 $K \le 30$，向量长度不超过 $29$，比较成本可接受。扫描复杂度为 $O(L \cdot K)$，而 $L \le 50000$，总数据量较小。

### 3. 边界情况

- 当 $K = 1$ 时，只有一条泳道，任意两个标记之间的栏架数都相同（因为只有一条泳道），因此最长距离就是 $L$。此时差异向量为空，`map` 会认为所有标记的向量都相同，故答案自然为 $L$。
- 若没有任何两个标记的差异向量相同，则答案为 $0$（但题目保证至少存在一个可行区间，实际上总可以取 $a=b$ 但长度为 $0$，题目要求最长，所以至少为 $0$）。

### 4. 正确性说明

前缀和与差异向量的构造将多泳道的约束转化为单一向量相等条件，严格等价于原始公平条件。扫描过程中，第一次出现某个向量时记录其位置，后续再出现时，该区间内所有泳道的栏架数差为零，即满足公平。取所有可行区间的最长者即为答案。

### 5. 复杂度分析

- 时间：对每个泳道构建前缀和 $O(K \cdot L)$，扫描标记 $O(L \cdot K)$（向量比较开销为 $O(K)$），总复杂度 $O(K \cdot L)$，在给定范围内完全可行。
- 空间：存储前缀和需要 $O(K \cdot L)$，存储差异向量的 `map` 在最坏情况下有 $O(L)$ 个不同向量，每个向量长度 $K-1$，总空间 $O(K \cdot L)$。

## 代码实现

```cpp
// Olympic Swimming
// UVa ID: 11546
// Verdict: Accepted
// Submission Date: 2026-07-
// UVa Run Time: s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int L, K;
    int caseNo = 1;
    while (cin >> L >> K && (L || K)) {
        // 读取每个泳道的栏架位置
        vector<vector<int>> laneHurdles(K);
        for (int i = 0; i < K; ++i) {
            int n;
            cin >> n;
            laneHurdles[i].resize(n);
            for (int j = 0; j < n; ++j) cin >> laneHurdles[i][j];
        }

        // 计算每个泳道的前缀和 S[i][x]：标记 x 之前（<x）的栏架总数
        vector<vector<int>> prefixSum(K, vector<int>(L + 1, 0));
        for (int i = 0; i < K; ++i) {
            vector<int> mark(L, 0);                 // mark[p]=1 表示区间 [p,p+1) 有栏架
            for (int p : laneHurdles[i]) if (p >= 0 && p < L) mark[p] = 1;
            prefixSum[i][0] = 0;
            for (int x = 1; x <= L; ++x)
                prefixSum[i][x] = prefixSum[i][x - 1] + mark[x - 1];
        }

        // 扫描每个标记，记录差异向量首次出现的位置
        map<vector<int>, int> firstPos;   // 差异向量 -> 最早出现标记
        int ans = 0;
        for (int x = 0; x <= L; ++x) {
            vector<int> diff;
            diff.reserve(K - 1);
            for (int i = 1; i < K; ++i)
                diff.push_back(prefixSum[0][x] - prefixSum[i][x]);

            auto it = firstPos.find(diff);
            if (it == firstPos.end()) firstPos[diff] = x;
            else ans = max(ans, x - it->second);
        }

        cout << "Case #" << caseNo << ": " << ans << " meter(s)" << endl;
        ++caseNo;
    }
    return 0;
}
```

## 总结

本题的核心在于将多泳道的公平条件转化为差异向量的相等性，从而将问题简化为寻找相同向量的最远距离。前缀和的使用使得区间查询变为常数时间，而哈希表（`map`）则高效地记录了向量的首次出现位置。该解法充分利用了数据范围较小的特点（$L \le 50000$，$K \le 30$），具有清晰的数学转换和良好的工程实现。

关键技巧：
- 用前缀和将区间计数转化为端点差值。
- 用差异向量消除泳道间的差异，将多条件约束转化为单条件相等。
- 用哈希表记录历史状态，实现线性扫描求最远相同状态。

此类“寻找两个位置使得某种差值相等”的问题，常常可以借助前缀和与哈希表在线性时间内解决。
