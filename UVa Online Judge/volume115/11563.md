## 题目描述

在一个分布式系统中，数据通常不在你需要的位置，通过网络获取数据既耗时又消耗带宽。 为了解决这个问题，可以在节点上添加缓存，将一些资源存储在本地。 当需要再次使用这些资源时，可以直接从缓存中获取，而不必请求其他节点。

然而，缓存空间有限，最终需要淘汰一些对象以腾出空间给新对象。 选择淘汰哪个对象并不简单，有多种算法可供选择。

题目引入了一种新的缓存替换算法——自省缓存算法。 该算法的核心是一个可以预见未来的“小猴子”，她知道所有对象未来的访问顺序。 利用这些信息，她可以做出最优的淘汰决策，即**最小化将对象读入缓存的次数**。

**所有访问都必须经过缓存**：如果访问的对象不在缓存中，则必须将其加载到缓存中。 所有对象大小相同，且只有读操作，因此缓存中的对象始终有效。 系统启动时，缓存为空。

**你的任务**：给定缓存容量、对象总数和访问序列，计算出处理这些访问所需的最小缓存未命中次数。

---

## 输入格式

输入包含多个测试用例。 每个测试用例格式如下：

- 第一行：三个整数 $c$, $n$, $a$，用空格分隔。
    - $c$: 缓存容量 $(0 < c \le 10000)$
    - $n$: 系统中不同对象的数量 $(c \le n \le 100000)$
    - $a$: 访问次数 $(0 \le a \le 100000)$
- 接下来 $a$ 行：每行一个整数 $obj$ $(0 \le obj \le n-1)$，表示被访问的对象 $\texttt{ID}$。 按访问顺序给出。

## 输出格式

对于每个测试用例，输出一行，表示处理所有访问所需的最小缓存未命中次数。

## 题目分析与解题思路

### 问题本质

这是一个**缓存替换问题**，目标是找到**最优的淘汰策略**，使得**缓存未命中次数最少**。 这相当于经典的**最优页面置换算法**或 **$\texttt{Belady}$ 算法**。

**核心思想**：当缓存满且需要加载新对象时，淘汰**未来最晚被再次访问**的对象。 如果一个对象将来永远不会被访问，那么它就是优先淘汰的候选者。

### 关键点

1. **最优性证明**：已知未来所有访问序列，$\texttt{Belady}$ 算法被证明是最优的离线缓存替换算法。
2. **数据结构需求**：我们需要快速知道缓存中每个对象的**下一次访问时间**，并能快速找到其中**下一次访问时间最晚**的对象。
3. **处理细节**：
    - 当一个对象被访问时，如果它在缓存中，需要更新它下一次的访问时间。
    - 当缓存满时，需要淘汰一个对象并插入新对象。
    - 需要高效地添加、删除和查找“下一次访问时间最晚”的对象。

### 算法步骤

1. **预处理**：计算访问序列中每个位置的下一次访问时间。
    - 从后往前遍历访问序列，记录每个对象最近一次出现的位置。
    - 对于位置 $i$ 上的对象 $obj$，如果它后面还会出现，则 $nextPos[i]$ 为下一次出现的索引；否则设为无穷大（如 $\texttt{INF} = 10^9$）。

2. **模拟最优缓存替换**：
    - 维护当前缓存中的对象集合（使用 `unordered_set` 实现 $O(1)$ 查找）。
    - 维护一个按下一次访问时间排序的集合（使用 `set<pair<int, int>>`），存储 `(next_time, object)` 对，便于找到下一次访问时间最晚的对象。
    - 维护一个映射（`unordered_map<int, iterator>`），记录每个对象在排序集合中的迭代器，以便在对象被访问时能快速定位并更新其下一次访问时间。
    - 遍历访问序列：
        a. **缓存命中**：更新该对象在排序集合中的下一次访问时间。
        b. **缓存未命中**：
            - 如果缓存未满：直接加入缓存，并记录其下一次访问时间。
            - 如果缓存已满：从排序集合中选出下一次访问时间最晚的对象（即集合中最大的元素），将其从缓存和排序集合中移除，然后加入新对象。

3. **统计结果**：统计缓存未命中的总次数。

### 时间复杂度分析

- **预处理**：$O(a)$，遍历访问序列一次。
- **模拟过程**：每个访问最多涉及一次集合的插入、删除或查找操作，这些操作在 `set` 和 `unordered_set` 中的时间复杂度为 $O(\log c)$ 或 $O(1)$。 总时间复杂度为 $O(a \log c)$。
- 由于 $c \le 10000$，$a \le 100000$，该算法完全可行。

### 空间复杂度分析

- 需要存储访问序列 $O(a)$。
- 需要存储缓存对象 $O(c)$。
- 需要存储排序集合和映射 $O(c)$。
- 总空间复杂度为 $O(a + c)$，在题目限制下可以接受。

## 示例解析

### 样例输入 1

```
1 2 3
0
0
1
```

**解释**：
- 缓存容量 $c = 1$，对象数 $n = 2$，访问次数 $a = 3$。
- 访问序列：`[0, 0, 1]`。

**模拟过程**：
1. 访问对象 $0$：未命中，加载到缓存。
2. 访问对象 $0$：命中。
3. 访问对象 $1$：未命中，缓存满，淘汰对象 $0$（不再访问），加载对象 $1$。

**未命中次数**：$2$。

### 样例输入 2

```
3 4 8
0
1
2
3
3
2
1
0
```

**解释**：
- 缓存容量 $c = 3$，对象数 $n = 4$，访问次数 $a = 8$。
- 访问序列：`[0, 1, 2, 3, 3, 2, 1, 0]`。

**最优替换序列**（未命中次数为 $5$）：
1. 加载 $0$
2. 加载 $1$
3. 加载 $2$
4. 加载 $3$（淘汰 $2$，因为 $2$ 下次访问最晚）
5. 访问 $3$（命中）
6. 加载 $2$（淘汰 $1$，因为 $1$ 下次访问比 $0$ 晚）
7. 访问 $2$（命中）
8. 访问 $1$（命中）
9. 访问 $0$（命中）

**未命中次数**：$5$。

## 代码实现

```cpp
// Introspective Caching
// UVa ID: 11563
// Verdict: Accepted
// Submission Date: 2026-01-06
// UVa Run Time: 0.240s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9; // 表示未来不会再次访问

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int c, n, a;
    while (cin >> c >> n >> a) {
        vector<int> accesses(a);
        for (int i = 0; i < a; i++) cin >> accesses[i];

        // 预计算每个位置的下一次出现位置
        vector<int> nextPos(a, INF);
        unordered_map<int, int> lastPos; // 对象 -> 上一次出现的位置
        for (int i = a - 1; i >= 0; i--) {
            int obj = accesses[i];
            if (lastPos.count(obj)) nextPos[i] = lastPos[obj];
            lastPos[obj] = i;
        }

        unordered_set<int> cache;           // 当前缓存中的对象
        // 使用set而不是priority_queue，以便删除特定元素
        // 存储 (next_access_time, object)
        set<pair<int, int>> nextAccessSet;
        // 对象 -> 它在nextAccessSet中的迭代器（用于删除）
        unordered_map<int, set<pair<int, int>>::iterator> objToIterator;

        int missCount = 0;

        for (int i = 0; i < a; i++) {
            int obj = accesses[i];
            
            if (cache.find(obj) != cache.end()) {
                // 缓存命中，需要更新该对象的下一次访问位置
                auto it = objToIterator[obj];
                nextAccessSet.erase(it);
                
                int nextTime = (nextPos[i] == INF) ? INF : nextPos[i];
                auto newIt = nextAccessSet.insert({nextTime, obj}).first;
                objToIterator[obj] = newIt;
                continue;
            }

            // 缓存未命中
            missCount++;

            if (cache.size() < c) {
                // 缓存未满，直接加入
                cache.insert(obj);
                int nextTime = (nextPos[i] == INF) ? INF : nextPos[i];
                auto it = nextAccessSet.insert({nextTime, obj}).first;
                objToIterator[obj] = it;
            } else {
                // 缓存已满，需要替换
                // 选择未来最晚访问的对象（set中最大的，因为INF表示永不访问）
                auto lastIt = prev(nextAccessSet.end());
                int removeObj = lastIt->second;
                
                // 从缓存和set中移除
                cache.erase(removeObj);
                nextAccessSet.erase(lastIt);
                objToIterator.erase(removeObj);
                
                // 插入新对象
                cache.insert(obj);
                int nextTime = (nextPos[i] == INF) ? INF : nextPos[i];
                auto newIt = nextAccessSet.insert({nextTime, obj}).first;
                objToIterator[obj] = newIt;
            }
        }

        cout << missCount << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于实现最优缓存替换算法（$\texttt{Belady}$ 算法）。 通过预计算每个对象的未来访问时间，并利用有序集合来维护缓存中对象的下一次访问时间，我们可以在 $O(a \log c)$ 的时间内找到最优解。 算法实现中需要注意数据结构的选择，特别是当需要更新对象信息时，要能够快速定位并修改集合中的元素。 使用 `set` 配合迭代器映射是一种有效的解决方案。
