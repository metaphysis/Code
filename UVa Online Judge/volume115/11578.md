## 题目描述

阿尔伯塔大学健身房有两台相同的仰卧起坐凳，并排放置。每台凳子可以在 $10$ 度到 $50$ 度之间以 $10$ 度为增量进行倾斜，具体角度取决于用户期望的难度级别。每天结束时，工作人员会将每台机器的倾斜度调整为 $10$ 度，这意味着每天开始时两台机器都处于 $10$ 度倾斜状态。

每次使用凳子会产生 $15$ 美分的维护费用。此外，每次调整凳子的倾斜度时，会产生与调整度数相等的维护费用（单位：美分）。例如，如果将凳子从 $40$ 度调整到 $20$ 度，则需要支付 $20$ 美分的维护费。

工作人员要求学生提前一天报名使用凳子。报名时，学生提供使用时间槽和期望的倾斜度。同一时间槽最多只能有两名学生使用同一台凳子（即每个时间槽每台凳子最多一人）。

在健身房开放之前，工作人员希望将学生分配到两台凳子上，使得当天的总维护费用最小。你需要编写一个程序来完成这个分配。

## 输入格式

输入的第一行包含测试用例的数量 $T$。

每个测试用例的第一行包含一个整数 $n$（$1 \le n \le 10000$），表示报名的学生人数。接下来的 $n$ 行，每行包含两个整数：`time_slot` 和 `incline`。`time_slot` 表示学生到达的时间（数值越小越早），`incline` 表示该学生期望的倾斜度（取值为 $10$、$20$、$30$、$40$ 或 $50$）。同一时间槽的学生同时到达，且较小的时间槽先于较大的时间槽发生。时间槽编号范围为 $0$ 到 $20000$。

## 输出格式

对于每个测试用例，第一行输出总维护费用（单位：美分）。接下来 $n$ 行，按照输入顺序，每行输出一个数字 $1$ 或 $2$，表示该学生被分配到的凳子编号。任何能使总费用最小的分配方案都是可接受的。

## 样例

输入

```
1
3
2 40
2 50
1 40
```

输出

```
185
1
2
1
```

## 题目分析

本题的核心是在满足约束条件的前提下，最小化维护总费用。维护费用由两部分组成：

1. **使用费用**：每个学生固定产生 $15$ 美分。
2. **调整费用**：每次调整凳子的倾斜度时，产生与调整度数相等的费用。

调整费用需要考虑三个环节：
- 每天开始时凳子处于 $10$ 度。
- 学生使用时，如果凳子的当前角度与该学生期望角度不同，则产生调整费用。
- **每天结束时，工作人员会将凳子调整回 $10$ 度**，这部分调整费用也需要计入当天的总费用。

因此，每个凳子上的总调整费用为：

$$
\textit{adjustCost} = |10 - \textit{first}| + \sum_{i=1}^{k-1} |\textit{angle}_i - \textit{angle}_{i-1}| + |\textit{last} - 10|
$$

其中 $\textit{angle}_1, \textit{angle}_2, \dots, \textit{angle}_k$ 是该凳子上按时间顺序排列的学生角度。

## 解题思路

### 约束条件

- 同一时间槽内最多两人（题目保证不超过两人）。
- 同一时间槽内的两人必须分配到**不同凳子**，否则会造成冲突。

### 状态设计

由于角度只有 $5$ 种可能（$10$、$20$、$30$、$40$、$50$），我们可以用动态规划来追踪两台凳子的当前角度。定义：

$$
\textit{dp}[i][a][b] = \text{处理完前 } i \text{ 个学生后，凳子1角度为 } a \text{，凳子2角度为 } b \text{ 的最小调整成本}
$$

其中 $a$ 和 $b$ 的取值范围是 $5$ 种角度，因此状态总数为 $O(n \times 25)$，在 $n \le 10000$ 时可以接受。

### 转移策略

将学生按时间槽排序后，同一时间槽的学生需要一起处理。对于当前时间槽：

- 如果只有 $1$ 个学生，他可以分配到任意凳子上，产生对应的调整费用。
- 如果有 $2$ 个学生，他们必须分配到不同的凳子上，因此有 $2$ 种分配方式（学生 $1$ 到凳子 $1$、学生 $2$ 到凳子 $2$，或者相反）。我们同时处理这两个学生，枚举两种分配方案。

### 最终费用计算

完成所有学生的分配后，我们得到 $\textit{dp}[n][a][b]$ 的最小值。此时还需加上两台凳子当天结束时的回调费用：

$$
\textit{finalCost} = \min_{a,b} \big( \textit{dp}[n][a][b] + |a - 10| + |b - 10| \big) + n \times 15
$$

### 方案回溯

为了输出每个学生的分配结果，我们需要在动态规划过程中记录前驱状态和分配选择。在完成计算后，从最优的最终状态反向回溯即可得到完整的分配方案。

### 复杂度分析

- 时间复杂度：$O(n \times 25 \times 2)$，因为每个状态最多有两种转移（选凳子 $1$ 或凳子 $2$），实际上由于同时间槽处理，常数略有增加但仍可行。
- 空间复杂度：$O(n \times 25)$，使用滚动数组可优化到 $O(25)$，但为了回溯方便，这里保留了完整的状态表。

## 代码实现

```cpp
// Situp Benches
// UVa ID: 11578
// Verdict: Accepted
// Submission Date: 2026-06-04
// UVa Run Time: 0.890s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;
const int ANGLES[] = {10, 20, 30, 40, 50};
const int ANGLE_CNT = 5;

struct Student {
    int idx, timeSlot, angle;
};

void solve() {
    int n;
    cin >> n;
    vector<Student> stu(n);
    for (int i = 0; i < n; ++i) {
        cin >> stu[i].timeSlot >> stu[i].angle;
        stu[i].idx = i;
    }
    // 按时间槽排序
    sort(stu.begin(), stu.end(), [](const Student& a, const Student& b) {
        return a.timeSlot < b.timeSlot;
    });

    int angleToIdx[60] = {0};
    for (int i = 0; i < ANGLE_CNT; ++i) angleToIdx[ANGLES[i]] = i;

    // dp[pos][a][b] = 最小调整成本
    vector<map<pair<int, int>, int>> dp(n + 1);
    vector<map<pair<int, int>, pair<int, int>>> pre(n + 1);
    vector<map<pair<int, int>, int>> choice(n + 1);

    dp[0][{angleToIdx[10], angleToIdx[10]}] = 0;

    int pos = 0;
    while (pos < n) {
        int curTime = stu[pos].timeSlot;
        int nextPos = pos + 1;
        while (nextPos < n && stu[nextPos].timeSlot == curTime) nextPos++;
        int cnt = nextPos - pos; // 当前时间槽的学生数: 1或2

        if (cnt == 1) {
            // 只有一个学生，可任选凳子
            int curAngle = angleToIdx[stu[pos].angle];
            for (auto& kv : dp[pos]) {
                int a = kv.first.first, b = kv.first.second;
                int curCost = kv.second;
                // 选凳1
                int cost1 = curCost + abs(ANGLES[curAngle] - ANGLES[a]);
                pair<int, int> state1 = {curAngle, b};
                if (!dp[pos + 1].count(state1) || dp[pos + 1][state1] > cost1) {
                    dp[pos + 1][state1] = cost1;
                    pre[pos + 1][state1] = {a, b};
                    choice[pos + 1][state1] = 1;
                }
                // 选凳2
                int cost2 = curCost + abs(ANGLES[curAngle] - ANGLES[b]);
                pair<int, int> state2 = {a, curAngle};
                if (!dp[pos + 1].count(state2) || dp[pos + 1][state2] > cost2) {
                    dp[pos + 1][state2] = cost2;
                    pre[pos + 1][state2] = {a, b};
                    choice[pos + 1][state2] = 2;
                }
            }
        } else { // cnt == 2
            int angle1 = angleToIdx[stu[pos].angle];
            int angle2 = angleToIdx[stu[pos + 1].angle];
            for (auto& kv : dp[pos]) {
                int a = kv.first.first, b = kv.first.second;
                int curCost = kv.second;
                // 分配方式1: 学生1凳1, 学生2凳2
                int cost1 = curCost + abs(ANGLES[angle1] - ANGLES[a]) 
                                   + abs(ANGLES[angle2] - ANGLES[b]);
                pair<int, int> state1 = {angle1, angle2};
                if (!dp[pos + 2].count(state1) || dp[pos + 2][state1] > cost1) {
                    dp[pos + 2][state1] = cost1;
                    pre[pos + 2][state1] = {a, b};
                    choice[pos + 2][state1] = 1; // 第一个学生凳1, 第二个凳2
                }
                // 分配方式2: 学生1凳2, 学生2凳1
                int cost2 = curCost + abs(ANGLES[angle1] - ANGLES[b]) 
                                   + abs(ANGLES[angle2] - ANGLES[a]);
                pair<int, int> state2 = {angle2, angle1};
                if (!dp[pos + 2].count(state2) || dp[pos + 2][state2] > cost2) {
                    dp[pos + 2][state2] = cost2;
                    pre[pos + 2][state2] = {a, b};
                    choice[pos + 2][state2] = 2; // 第一个学生凳2, 第二个凳1
                }
            }
        }
        pos = nextPos;
    }

    // 找最优，加上结束时调回10度的费用
    int minAdjust = INF;
    pair<int, int> bestState;
    for (auto& kv : dp[n]) {
        int a = kv.first.first, b = kv.first.second;
        int totalAdjust = kv.second + abs(ANGLES[a] - 10) + abs(ANGLES[b] - 10);
        if (totalAdjust < minAdjust) {
            minAdjust = totalAdjust;
            bestState = kv.first;
        }
    }

    // 回溯分配方案
    vector<int> assign(n);
    pair<int, int> curState = bestState;
    int curPos = n;
    while (curPos > 0) {
        int timeSlot = stu[curPos - 1].timeSlot;
        int start = curPos - 1;
        while (start > 0 && stu[start - 1].timeSlot == timeSlot) start--;
        int cnt = curPos - start;
        
        if (cnt == 1) {
            int ch = choice[curPos][curState];
            assign[stu[start].idx] = ch;
            curState = pre[curPos][curState];
            curPos = start;
        } else {
            int ch = choice[curPos][curState];
            if (ch == 1) {
                assign[stu[start].idx] = 1;
                assign[stu[start + 1].idx] = 2;
            } else {
                assign[stu[start].idx] = 2;
                assign[stu[start + 1].idx] = 1;
            }
            curState = pre[curPos][curState];
            curPos = start;
        }
    }

    int totalCost = minAdjust + n * 15;
    cout << totalCost << "\n";
    for (int i = 0; i < n; ++i) cout << assign[i] << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) solve();
    return 0;
}
```

## 总结

本题的关键点在于：

1. **理解费用构成**：除了每次使用的固定费用 $15$ 美分和每次调整的费用外，**每天结束时的回调整理费用也要计入当天总费用**，这是容易遗漏的地方。

2. **状态设计**：由于角度只有 $5$ 种，可以用有限状态动态规划来追踪两台凳子的当前角度，将问题转化为路径选择问题。

3. **约束处理**：同一时间槽的学生必须分配到不同凳子，需要将同一时间槽的学生**打包处理**，枚举所有合法的分配方式。

4. **方案回溯**：通过记录前驱状态和选择信息，可以在动态规划完成后还原完整的分配方案。

5. **复杂度优化**：使用 $\texttt{map}$ 存储状态是因为角度只有 $25$ 种，实际常数很小；若需要进一步优化，可以用二维数组固定大小 $5 \times 5$。

本题是经典动态规划与状态压缩思想的结合，同时考察了对题目细节的理解能力。掌握这种多状态动态规划的建模方法，对解决类似的资源分配问题有很好的借鉴意义。
