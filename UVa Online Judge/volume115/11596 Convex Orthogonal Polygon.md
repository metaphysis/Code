
> **摘要**：本题给定正交凸格点多边形（$\texttt{OCLP}$）的初始面积 $A_0$、包围盒面积 $B_0$ 以及扩展 $n$ 步后的面积 $A_n$，要求反推出所有可能的步数 $n$。核心思路是利用正交凸多边形周长恒等于其包围盒周长这一不变量，推导出面积关于步数的二次关系 $A_n = A_0 + nP_0 + 4n^2$，再枚举 $B_0$ 的因子对 $(W, H)$ 并借助判别式判断整数解，配合面积上下界过滤与 $128$ 位整数防溢出，即可高效求解。

## 题目描述

在笛卡尔坐标系中，格点是指横纵坐标均为整数的点。如果一个多边形的所有顶点都是格点，则称其为格点多边形。本题中，一个格点多边形称为 **正交多边形** ，当且仅当其所有边都平行于 $x$ 轴或 $y$ 轴。一个正交格点多边形是 **凸的** （在本题定义下，即正交凸），当且仅当不存在一条水平或竖直线段，其两个端点都在多边形内部，但线段的某一部分位于多边形外部。一个正交凸多边形的 **包围盒** 是包含整个多边形的最小轴对齐矩形。

给定一个正交凸格点多边形（简称 $\texttt{OCLP}$），在第 $0$ 步时的面积为 $A_0$，其包围盒面积为 $B_0$。之后每一步，多边形在水平和竖直方向均向外扩展 $1$ 个单位（如图 3 所示），第 $n$ 步后的面积变为 $A_n$。现在给定 $A_0$、$A_n$ 和 $B_0$，要求输出所有可能的步数 $n$，若无解则输出 `-1`。

## 输入格式

输入文件包含多组数据，每组数据占一行，包含三个正整数 $A_0$（$0 < A_0 \le 10000$）、$A_n$（$A_0 \le A_n \le 10^{18}$）和 $B_0$（$0 < B_0 < 20000$）。  
输入以一行 `0 0 0` 结束，该行不需处理。

## 输出格式

对于每组输入，输出一行或多行，每行一个可能的 $n$ 值。若存在多个可能值，按升序输出。若输入数据不可能，输出 `-1`。  
每组输出后打印一个空行。

## 样例

输入

```
1 25 1
7 20 7
7 21 7
8 20 7
0 0 0
```

输出

```
2

-1

-1

-1

```

## 题目分析

本题给定正交凸多边形初始面积 $A_0$ 和包围盒面积 $B_0$，以及经过 $n$ 步扩展后的面积 $A_n$，要求反推出步数 $n$。由于多边形的形状未知，只能利用正交凸多边形的通用性质来建立方程。

对于任意正交凸多边形，其周长 $P$ 恒等于其包围盒的周长。设包围盒的宽度为 $W$，高度为 $H$，则 $B_0 = W \cdot H$，且 $P = 2(W + H)$。

每一步向外扩展 $1$ 个单位时，面积增量等于当前周长加 $4$，且周长每次增加 $8$。因此，面积关于步数 $n$ 的变化是一个二次函数。通过枚举所有可能的 $(W, H)$ 因子对，并利用判别式判断是否存在整数解 $n$，即可筛选出所有可行的步数。

本题数据范围中 $B_0 < 20000$，因子枚举可行；$A_n$ 可达 $10^{18}$，需使用 $128$ 位整数进行判别式计算，避免溢出。

## 解题思路

### 面积增长公式推导

设第 $k$ 步时的面积为 $A_k$，周长为 $P_k$。扩展一步时，新多边形等于原多边形向外平移 $1$ 个单位，其面积增量为原周长 $P_k$ 加上四个角上的 $1 \times 1$ 小方块（共 $4$ 个），即  
$$
A_{k+1} - A_k = P_k + 4
$$

同时，每一步扩展使得周长增加 $8$（因为每条边向外平移 $1$ 后，水平与竖直方向各增加 $2$，总周长增加 $8$），所以  
$$
P_k = P_0 + 8k
$$

于是得到递推关系：  
$$
A_{k+1} = A_k + (P_0 + 8k) + 4 = A_k + P_0 + 8k + 4
$$

从 $0$ 累加到 $n-1$，可得  
$$
A_n = A_0 + \sum_{k=0}^{n-1} (P_0 + 8k + 4) = A_0 + n(P_0 + 4) + 8 \cdot \frac{n(n-1)}{2}
$$

化简得  
$$
A_n = A_0 + n \cdot P_0 + 4n^2
$$

其中 $P_0 = 2(W + H)$。

### 转化为一元二次方程

给定 $A_0$、$A_n$ 和 $B_0$，对于每个可能的 $(W, H)$ 满足 $W \cdot H = B_0$，计算 $P = 2(W + H)$，则方程变为  
$$
4n^2 + P \cdot n + (A_0 - A_n) = 0
$$

其判别式为  
$$
\Delta = P^2 - 4 \cdot 4 \cdot (A_0 - A_n) = P^2 + 16(A_n - A_0)
$$

若 $\Delta$ 为完全平方数，设 $s = \sqrt{\Delta}$，则  
$$
n = \frac{-P \pm s}{8}
$$

由于 $n \ge 0$，取正号：  
$$
n = \frac{s - P}{8}
$$

要求 $s - P$ 能被 $8$ 整除且 $n$ 为非负整数，该 $n$ 即为一个可行解。

### 可行性附加条件

并非所有满足上述方程的解都对应真实存在的 $\texttt{OCLP}$。对于一个给定的包围盒 $(W, H)$，$\texttt{OCLP}$ 的面积 $A$ 必须满足  
$$
W + H - 1 \le A \le W \cdot H
$$

这是因为正交凸多边形的面积最小为一条宽度为 $1$ 的对角折线所围成的面积（即 $W + H - 1$），最大为整个矩形面积 $W H$。题目给定 $A_0 \le B_0$，但还需检查 $A_0 \ge W + H - 1$，否则该 $(W, H)$ 不可能作为初始多边形的包围盒。

### 算法流程

1. 读入每组 $A_0, A_n, B_0$。
2. 枚举 $B_0$ 的所有因子对 $(W, H)$，其中 $W \le H$（因 $W$ 与 $H$ 交换不改变周长和面积条件，只需枚举一次）。
3. 对每个因子对，检查 $A_0 \ge W + H - 1$，若不满足则跳过。
4. 计算 $P = 2(W + H)$ 和判别式 $\Delta = P^2 + 16(A_n - A_0)$。
5. 使用 $128$ 位整数判断 $\Delta$ 是否为完全平方数，若能开方得整数 $s$，且 $(s - P) \% 8 == 0$，则计算 $n = (s - P) / 8$，若 $n \ge 0$ 则将 $n$ 加入答案集合。
6. 对答案集合去重后升序输出；若为空则输出 `-1`。每组后输出一个空行。

### 复杂度分析

- 枚举因子：对每个 $B_0$，枚举 $W$ 从 $1$ 到 $\sqrt{B_0}$，复杂度 $O(\sqrt{B_0})$，$B_0 < 20000$，单组最多约 $141$ 次枚举。
- 每次判别式计算为常数时间。
- 总输入最多 $50000$ 组，最坏情况下计算量约为 $50000 \times 141 \approx 7 \times 10^6$，完全可接受。
- 使用 $128$ 位整数确保 $A_n$ 达 $10^{18}$ 时判别式不溢出。

```cpp
// Convex Orthogonal Polygon

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
typedef __int128 i128;

// 判断 x 是否为完全平方数，若是则返回 sqrt(x)
bool isSquare(i128 x, i128 &r) {
    if (x < 0) return false;
    i128 lo = 0, hi = 5000000000LL; // 5e9，足够覆盖最大值 sqrt(1.6e19)
    while (lo <= hi) {
        i128 mid = (lo + hi) / 2;
        i128 sq = mid * mid;
        if (sq == x) { r = mid; return true; }
        else if (sq < x) lo = mid + 1;
        else hi = mid - 1;
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    ll A0, An, B0;
    while (cin >> A0 >> An >> B0) {
        if (A0 == 0 && An == 0 && B0 == 0) break;
        set<ll> ans;
        // 枚举 B0 的所有因子对 (W, H)，W <= H
        for (ll w = 1; w * w <= B0; ++w) {
            if (B0 % w) continue;
            ll h = B0 / w;
            // 可行性检查
            if (A0 < w + h - 1) continue;
            ll P = 2 * (w + h);
            i128 D = (i128)P * P + (i128)16 * (An - A0);
            i128 sqrtD;
            if (isSquare(D, sqrtD)) {
                if ((sqrtD - P) % 8 == 0) {
                    ll n = (ll)((sqrtD - P) / 8);
                    if (n >= 0) ans.insert(n);
                }
            }
        }
        if (ans.empty()) cout << -1 << '\n';
        else for (ll n : ans) cout << n << '\n';
        cout << '\n'; // 每组后空行
    }
    return 0;
}
```

## 总结

本题的关键在于抓住正交凸多边形的周长恒等于其包围盒周长的性质，从而将复杂的几何生长过程转化为简单的二次方程求解。枚举包围盒的因子对，结合判别式判断整数解，是处理此类反问题的常用手段。

**技巧提炼：**
- 将几何问题代数化，利用不变量（周长）建立递推关系。
- 利用整数分解枚举所有可能的包围盒尺寸。
- 使用 $128$ 位整数避免大数乘法溢出。
- 通过面积上下界过滤无效因子对，减少不必要的计算。

本题数据规模适中，但 $A_n$ 较大，故使用 $128$ 位整型是必要的。该算法在时间和空间上均高效，能够轻松应对 $50000$ 组输入。
