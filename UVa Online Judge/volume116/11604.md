## 题目描述

战争再次爆发！我们敬爱的苏丹将军需要为他的新武器系统分配二进制编码。每种武器有一个唯一的二进制编码，指挥官通过发送二进制信号序列来指挥部队使用对应的武器。

然而，问题出现了：如果编码方案存在歧义，同一个二进制信号序列可能被解释为多种不同的武器组合，导致错误的指令执行。

**任务** ：在战争开始前，判断给定的编码方案是否存在歧义。

### 输入格式

- 多组测试数据，约 $100$ 组
- 每组以整数 $N$ ($1 \leq N \leq 100$) 开始，表示武器种类数
- 接下来 $N$ 行，每行包含武器名称（少于 $21$ 字符）和对应的二进制编码（少于 $21$ 字符）
- 输入以单独的 $0$ 结束

### 输出格式

对于每组测试：
- 输出 `Case #x: ` ，其中 $x$ 是测试编号
- 如果编码方案存在歧义，输出 `Ambiguous.`
- 否则输出 `Not ambiguous.`

### 样例输入
```
3
FordCannon 1
EdmondMortar 10
HopcroftRifle 00
3
FordCannon 01
EdmondMortar 001
HopcroftRifle 01001
0
```

### 样例输出
```
Case #1: Not ambiguous.
Case #2: Ambiguous.
```

## 题目分析

### 问题本质

这是一个**唯一可解码性检验**问题。给定一组二进制编码，我们需要判断是否存在一个二进制串可以由不止一种方式分解成这些编码的拼接。

### 关键难点

简单的"前缀检查"是不充分的。考虑以下反例：
- 编码：$A = 01$, $B = 001$, $C = 01001$
- 简单前缀检查：$A$ 是 $B$ 的前缀（`01` 是 `001` 的前缀），但仅凭这个还不能完全确定歧义
- 实际验证：信号 `01001` 可以解释为：
  1. 直接作为 $C$ 的编码
  2. 作为 $A$ (`01`) + $B$ (`001`) 的拼接

### 数学形式化

设编码集合 $S = \{c_1, c_2, \ldots, c_n\}$ ，我们需要判断是否存在字符串 $w$ 和两种不同的分解方式：
$$ w = c_{i_1}c_{i_2}\cdots c_{i_k} = c_{j_1}c_{j_2}\cdots c_{j_m} $$
其中 $c_{i_t}, c_{j_s} \in S$ ，且两个序列不完全相同。

## 解题思路

### $\texttt{Sardinas-Patterson}$ 算法

这是一个专门用于检验唯一可解码性的经典算法，时间复杂度为 $O(n^2 \cdot L)$ ，其中 $n$ 是编码数量，$L$ 是编码最大长度。

#### 算法步骤

1. **初始化**
   - 设原始编码集合为 $S_0$
   - 初始剩余集合 $S_1 = S_0$

2. **迭代计算剩余集合**
   对于第 $i$ 次迭代（$i \geq 1$）：
   - 计算新的剩余集合 $S_{i+1}$ ，包含所有满足以下条件的字符串 $w$ ：
     - 存在 $x \in S_0$ 和 $y \in S_i$ （或 $x \in S_i$ 和 $y \in S_0$）
     - $x$ 是 $y$ 的前缀
     - $w$ 是 $y$ 去掉前缀 $x$ 后的剩余部分
   - 公式表示：$S_{i+1} = \{w \mid \exists x \in S_0, y \in S_i: xw = y \text{ 或 } yw = x\}$

3. **终止条件**
   - 如果 $S_{i+1}$ 包含 $S_0$ 中的某个编码 → **存在歧义**
   - 如果 $S_{i+1} = \emptyset$ → **无歧义**
   - 如果 $S_{i+1} = S_i$ （出现循环）→ **无歧义**

#### 算法正确性证明（简要）

该算法基于以下观察：如果存在歧义，那么必定存在一个"最小歧义串"，这个串的某种分解会产生一个剩余部分，而这个剩余部分本身也是原始编码之一。算法通过不断生成可能的剩余部分来检查这种情况。

### 算法示例

以样例 $2$ 为例：
- $S_0 = \{01, 001, 01001\}$
- 计算 $S_1$：
  - $01$ 是 $001$ 的前缀 → 剩余 `1`
  - $01$ 是 $01001$ 的前缀 → 剩余 `001`
  - 所以 $S_1 = \{1, 001\}$
- 检查 $S_1$ 包含 $S_0$ 中的编码  `001` ∈ $S_0$ → **存在歧义**

## 时间复杂度分析

- 每次迭代需要检查所有编码对：$O(n^2)$
- 字符串比较和子串操作：$O(L)$
- 迭代次数受限于编码长度和数量：$O(n \cdot L)$
- 总复杂度：$O(n^3 \cdot L^2)$ ，但实际运行很快，因为 $n \leq 100$, $L \leq 20$

## 空间复杂度分析

- 存储编码集合：$O(n \cdot L)$
- 存储中间剩余集合：同样 $O(n \cdot L)$
- 总空间：$O(n \cdot L)$

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int caseNum = 1;
    int n;
    while (cin >> n && n) {
        cout << "Case #" << caseNum++ << ": ";
        string name, code;
        set<string> codes[3];  // codes[0]: 原始编码, codes[1]: 当前Si, codes[2]: 新的Si+1
        bool ambiguous = false;
        
        // 读入所有编码
        for (int i = 0; i < n; ++i) {
            cin >> name >> code;
            if (codes[0].count(code)) ambiguous = true;  // 检查是否有重复编码
            codes[0].insert(code);
            codes[1].insert(code);  // S0也作为初始S1
        }
        
        if (ambiguous) {
            cout << "Ambiguous.\n";
            continue;
        }
        
        // Sardinas-Patterson算法
        while (true) {
            codes[2].clear();  // 清空用于存储新生成的剩余部分
            
            // 生成新的剩余字符串集合
            for (auto c0 : codes[0])  // 原始编码集合
                for (auto c1 : codes[1]) {  // 当前Si集合
                    if (c0 == c1) continue;
                    if (c0.length() > c1.length()) swap(c0, c1);
                    // 检查是否是前缀关系
                    if (c0 == c1.substr(0, c0.length()))
                        codes[2].insert(c1.substr(c0.length()));  // 添加剩余部分
                }
            
            if (codes[2].empty()) break;  // 没有新的剩余部分，无歧义
            
            // 检查新生成的剩余部分是否包含原始编码
            for (auto c2 : codes[2]) {
                if (codes[0].count(c2)) {
                    ambiguous = true;
                    break;
                }
            }
            if (ambiguous) break;
            
            // 检查是否出现循环
            if (codes[2] == codes[1]) break;
            
            codes[1].swap(codes[2]);  // 继续下一轮迭代
        }
        
        cout << (ambiguous ? "Ambiguous." : "Not ambiguous.") << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于理解编码歧义的本质，并掌握检验唯一可解码性的经典算法。 $\texttt{Sardinas-Patterson}$ 算法虽然理论上不是最高效的（有更优的 $O(n \cdot L)$ 算法），但对于本题的规模完全足够，且实现相对简单。

### 学习要点

1. **唯一可解码性问题** 在实际编码理论中有重要应用
2. **前缀码** 是唯一可解码编码的子集，但不是全部
3. **$\texttt{Sardinas-Patterson}$ 算法** 是检验唯一可解码性的标准方法
4. 注意处理**重复编码**的特殊情况
