## 题目描述

$\texttt{Acme Corporation}$ 生产一种秘密元素 $\texttt{X}$，需要在 $M$ 个月内制定生产和销售策略以最大化利润。每个月有以下参数：

- $m_i$：单位生产成本
- $n_i$：最大生产量
- $p_i$：单位售价
- $s_i$：最大销售量
- $E_i$：最大存储时间（第 $i$ 月生产的产品可以在第 $i$ 到第 $i+E_i$ 月销售）

此外，每月每单位元素的库存成本为 $I$。目标是在 $M$ 个月结束后，最大化总利润。

## 题目分析

这是一个典型的多期生产销售问题，具有以下特点：

1. **时间跨度**：考虑 $M$ 个月的生产和销售决策
2. **生产限制**：每月有最大产量限制 $n_i$
3. **销售限制**：每月有最大销售量限制 $s_i$
4. **时间约束**：产品有保质期，生产后必须在 $E_i$ 个月内售出
5. **库存成本**：存储会产生额外成本 $I$ 每月每单位

## 解题思路

### 网络流建模

我们可以将这个问题建模为**最小费用最大流**问题：

#### 节点设计
- **源点** ($0$)：表示生产的起点
- **生产节点** ($1$ 到 $M$)：每个月的生产决策
- **销售节点** ($M+1$ 到 $2M$)：每个月的销售机会
- **汇点** ($2M+1$)：表示销售的终点

#### 边设计

1. **源点到生产节点**：
   - 容量：$n_i$（最大产量）
   - 费用：$m_i$（生产成本）

2. **生产节点到销售节点**：
   - 容量：$\infty$（理论上可以存储任意数量）
   - 费用：$I \times (j-i)$（从第 $i$ 月生产到第 $j$ 月销售的库存成本）
   - 连接条件：$i \leq j \leq \min(M, i+E_i)$（在保质期内）

3. **销售节点到汇点**：
   - 容量：$s_i$（最大销售量）
   - 费用：$-p_i$（负的售价，因为我们要最小化费用）

### 算法选择

使用 **$\texttt{Bellman-Ford}$** 算法实现的最小费用流，原因如下：
- 图中存在负费用边（销售边的费用为 $-p_i$）
- $\texttt{Bellman-Ford}$ 可以处理负权边
- $M \leq 100$，节点数量为 $2M+2 \leq 202$，在可接受范围内

### 关键优化

在最小费用流算法中，当找到的增广路费用 $\geq 0$ 时提前终止：
- 费用 $\geq 0$ 意味着继续流会增加总成本（减少利润）
- 这是最大化利润的关键优化

### 利润计算

最终利润 = $-$总费用，因为我们在模型中：
- 生产成本和库存成本作为正费用
- 销售收入作为负费用（在最小化问题中）

## 复杂度分析

- **节点数**：$2M+2 = O(M)$
- **边数**：每个生产节点连接到最多 $E_i+1$ 个销售节点，总边数 $O(M^2)$
- **时间复杂度**：$O(M^3 \cdot \text{流量})$，在本题约束下可接受

```cpp
// Acme Corporation

#include <bits/stdc++.h>
using namespace std;

typedef long long LL;
const LL INF = 1e18;

struct MinCostMaxFlow {
    struct Edge {
        int to, rev;
        LL cap, cost, flow;
    };
    int n;
    vector<vector<Edge>> graph;
    vector<LL> dist, pot;
    vector<pair<int, int>> parent;
    vector<bool> inQueue;

    MinCostMaxFlow(int n) : n(n), graph(n), dist(n), pot(n, 0), parent(n), inQueue(n) {}

    void addEdge(int u, int v, LL cap, LL cost) {
        graph[u].push_back({v, (int)graph[v].size(), cap, cost, 0});
        graph[v].push_back({u, (int)graph[u].size() - 1, 0, -cost, 0});
    }

    bool bellmanFord(int s, int t) {
        fill(dist.begin(), dist.end(), INF);
        dist[s] = 0;
        queue<int> q;
        q.push(s);
        inQueue[s] = true;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            inQueue[u] = false;
            for (int i = 0; i < graph[u].size(); i++) {
                Edge &e = graph[u][i];
                if (e.cap - e.flow > 0 && dist[e.to] > dist[u] + e.cost + pot[u] - pot[e.to]) {
                    dist[e.to] = dist[u] + e.cost + pot[u] - pot[e.to];
                    parent[e.to] = {u, i};
                    if (!inQueue[e.to]) {
                        inQueue[e.to] = true;
                        q.push(e.to);
                    }
                }
            }
        }
        return dist[t] < INF;
    }

    pair<LL, LL> minCostMaxFlow(int s, int t) {
        LL totalFlow = 0, totalCost = 0;
        while (bellmanFord(s, t)) {
            for (int i = 0; i < n; i++) pot[i] += dist[i];
            if (pot[t] >= 0) break; // 关键优化：当增广路费用非负时停止
            
            LL f = INF;
            for (int v = t; v != s; v = parent[v].first) {
                int u = parent[v].first, i = parent[v].second;
                f = min(f, graph[u][i].cap - graph[u][i].flow);
            }
            for (int v = t; v != s; v = parent[v].first) {
                int u = parent[v].first, i = parent[v].second;
                graph[u][i].flow += f;
                graph[v][graph[u][i].rev].flow -= f;
            }
            totalFlow += f;
            totalCost += f * pot[t];
        }
        return {totalFlow, totalCost};
    }
};

int main() {
    int T; cin >> T;
    for (int caseNo = 1; caseNo <= T; caseNo++) {
        int M, I; cin >> M >> I;
        int source = 0, sink = 2 * M + 1;
        MinCostMaxFlow mcmf(2 * M + 2);
        for (int i = 1; i <= M; i++) {
            int mi, ni, pi, si, Ei; cin >> mi >> ni >> pi >> si >> Ei;
            mcmf.addEdge(source, i, ni, mi);
            mcmf.addEdge(M + i, sink, si, -pi);
            for (int j = i; j <= min(M, i + Ei); j++)
                mcmf.addEdge(i, M + j, INF, I * (j - i));
        }
        pair<LL, LL> result = mcmf.minCostMaxFlow(source, sink);
        cout << "Case " << caseNo << ": " << -result.second << endl;
    }
    return 0;
}
```

## 总结

本题通过巧妙的网络流建模，将复杂的多期生产销售问题转化为标准的最小费用流问题。关键点在于：

1. 合理设计节点和边来表示生产、存储和销售关系
2. 使用负费用表示收入，将利润最大化问题转化为费用最小化问题
3. 利用 $\texttt{Bellman-Ford}$ 算法处理负权边
4. 通过提前终止优化算法性能

这种建模方法在运筹学和组合优化中有着广泛的应用，是解决复杂约束下资源分配问题的有力工具。
