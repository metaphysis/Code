## 题目描述

井字棋游戏在一个 $n \times n$ 的棋盘上进行（ $1 \leq m \leq n \leq 1000$ ）。两名玩家轮流在棋盘格子上放置符号，一人放 $\texttt{X}$ ，另一人放 $\texttt{O}$ 。放 $\texttt{X}$ 的玩家总是先手。当棋盘上出现至少 $m$ 个连续的相同符号（垂直、水平或对角线）时，游戏结束，且**最后落子的玩家**获胜。当棋盘所有格子都被填满且无人获胜时，游戏以平局结束。

你的任务是分析一个井字棋棋盘的状态，判断游戏是否仍在进行，或者是否已经结束，谁赢了，还是平局。你还需要检测那些在实际游戏中不可能出现的错误棋盘状态。

### 输入格式

第一行输入一个整数 $t$ ，表示测试用例的数量。每个测试用例的第一行包含两个整数 $n$ 和 $m$ ，用空格分隔。接下来 $n$ 行每行包含棋盘的一行，每行恰好 $n$ 个字符，字符是 `X` 、 `O` 或 `.` （表示空格）。

### 输出格式

对于每个测试用例，输出一行：
- 如果游戏已结束且 $\texttt{X}$ 赢，输出 `X WINS`
- 如果游戏已结束且 $\texttt{O}$ 赢，输出 `O WINS`
- 如果棋盘已满且无人赢，输出 `DRAW`
- 如果游戏未结束，输出 `IN PROGRESS`
- 如果棋盘状态不可能出现，输出 `ERROR`

### 样例输入
```
1
3 3
..X
OOX
..X
```
### 样例输出
```
X WINS
```

## 题目分析

本题的核心在于**判断棋盘状态的合法性**，而不仅仅是判断胜负。一个合法的棋盘状态必须满足井字棋游戏的基本规则，并且符合“游戏在出现连珠时立即结束”的前提。

### 合法性约束

我们需要检查以下条件，任何一条不满足即为 `ERROR` ：

1. **棋子数量关系**  
   设 $countX$ 为 $\texttt{X}$ 的数量， $countO$ 为 $\texttt{O}$ 的数量。由于 $\texttt{X}$ 先手，所以只有两种情况合法：
   - $countX = countO$ （此时轮到 $\texttt{O}$ 下）
   - $countX = countO + 1$ （此时轮到 $\texttt{X}$ 下）

2. **不能双方同时获胜**  
   游戏一旦有一方获胜立即结束，不可能双方都获胜。

3. **获胜方与棋子数量的匹配**  
   - 如果 $\texttt{X}$ 赢，则必须满足 $countX = countO + 1$ （最后一步是 $\texttt{X}$ 下的）。
   - 如果 $\texttt{O}$ 赢，则必须满足 $countX = countO$ （最后一步是 $\texttt{O}$ 下的）。

4. **获胜段的唯一性**  
   如果一方获胜，那么棋盘上所有长度 $\geq m$ 的连续同色棋子段（称为“获胜段”）必须**共享唯一的一个最后落子位置**。换句话说：
   - 所有获胜段的交集不能为空。
   - 必须存在一个格子 $g$ ，使得 $g$ 在所有获胜段中，并且**如果将 $g$ 改为空格**，那么所有获胜段都会消失（即所有获胜段都依赖于这个格子）。
   
   这个条件确保了所有获胜段是在**最后一次落子**中同时形成的，而不是在不同回合中分别形成的。

5. **连续棋子长度限制**  
   如果存在长度 $\geq 2m$ 的连续同色棋子，那么该玩家获胜时一定不合法。因为长度 $\geq 2m$ 的连续棋子包含至少两个不相交的长度 $\geq m$ 的子段，这两个子段无法通过一次落子同时形成（除非它们共享一个格子，但这在长度 $\geq 2m$ 时不可能）。

### 解题思路

我们可以按以下步骤进行判断：

1. **统计棋子数量**  
   遍历棋盘，统计 $countX$ 和 $countO$ ，检查数量关系是否合法。

2. **检查获胜情况**  
   对 $\texttt{X}$ 和 $\texttt{O}$ 分别检查是否有长度 $\geq m$ 的连续棋子。同时收集所有获胜段。

3. **检查获胜段的合法性**  
   对于获胜的一方：
   - 检查是否有长度 $\geq 2m$ 的连续棋子。
   - 计算所有获胜段的交集。
   - 如果交集为空，则不合法。
   - 否则，对交集中的每个格子（候选最后落子位置），临时将其改为空格，检查是否还有获胜段存在。如果存在一个格子，使得修改后所有获胜段都消失，则该格子是有效的最后落子位置；否则不合法。

4. **综合判断**  
   根据上述检查结果，结合棋子数量、获胜情况，输出最终结果。

### 时间复杂度

棋盘最大为 $1000 \times 1000$ ，每个格子检查四个方向，收集获胜段和检查交集的操作在获胜段数量有限的情况下可以接受。总体时间复杂度约为 $O(n^2)$ ，可以在时间限制内完成。

### 注意事项

- 检查连续棋子时，为了避免重复计算，只从每个连续段的起始位置开始检查（即该位置在前一个格子的对应方向上不是同色棋子）。
- 注意边界条件： $n = 1$ 或 $m = 1$ 的情况。
- 注意输入中可能包含空格，需要正确处理。

```cpp
// Tic Tac Toe

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
char board[MAXN][MAXN];
int n, m;

int dr[4] = {0, 1, 1, 1}, dc[4] = {1, 0, 1, -1};

// 检查从 (r,c) 方向 (dr,dc) 的连续同色棋子长度
int getLength(int r, int c, int dir, char symbol) {
    int length = 0;
    int rr = r, cc = c;
    while (rr >= 0 && rr < n && cc >= 0 && cc < n && board[rr][cc] == symbol) {
        length++;
        rr += dr[dir], cc += dc[dir];
    }
    return length;
}

bool firstSet = true;
set<pair<int, int>> intersection;

void getIntersection(int i, int j, int length, int dir) {
    set<pair<int,int>> current;
    int rr = i, cc = j;
    for (int k = 0; k < length; k++) {
        current.insert({rr, cc});
        rr += dr[dir], cc += dc[dir];
    }
    if (firstSet) {
        intersection = current;
        firstSet = false;
    } else {
        set<pair<int,int>> next;
        for (auto &p : intersection)
            if (current.count(p)) next.insert(p);
        intersection = next;
    }
}

pair<bool, bool> checkWinner(char symbol) {
    firstSet = true;
    intersection.clear();
    int winCount = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) {
            if (board[i][j] != symbol) continue;
            for (int dir = 0; dir < 4; dir++) {
                // 限制起始位置，不重复检查
                if (dir == 0 && j && board[i][j - 1] == symbol) continue;
                if (dir == 1 && i && board[i - 1][j] == symbol) continue;
                if (dir == 2 && i && j && board[i - 1][j - 1] == symbol) continue;
                if (dir == 3 && i && j <= n - 2 && board[i - 1][j + 1] == symbol) continue;
                int length = getLength(i, j, dir, symbol);
                // 连续同色棋子长度约束
                if (length >= 2 * m) return {true, false};
                // 检查交集
                if (length >= m) {
                    winCount++;
                    getIntersection(i, j, length, dir);
                    if (winCount >= 2 && intersection.size() != 1) return {true, false};
                }
            }
        }
    // 检查去除公共棋子后是否还存在获胜段
    if (winCount >= 2) {
        int r, c;
        for (auto p : intersection) r = p.first, c = p.second;
        char original = board[r][c];
        board[r][c] = '.';
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (board[i][j] == symbol)
                    for (int dir = 0; dir < 4; dir++)
                        if (getLength(i, j, dir, symbol) >= m) {
                            board[r][c] = original;
                            return {true, winCount};
                        }
        board[r][c] = original;
    }
    return {false, winCount};
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int t;
    cin >> t;
    while (t--) {
        cin >> n >> m;
        int countX = 0, countO = 0;
        // 统计两种棋子的数量
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) {
                cin >> board[i][j];
                if (board[i][j] == 'X') countX++;
                else if (board[i][j] == 'O') countO++;
            }
        bool error = false, xWin, oWin;
        // 棋子数量需要满足约束
        if (countX != countO && countX != countO + 1) error = true;
        if (!error) {
            // 检查 X 胜利是否符合约束
            auto [xError, xxWin] = checkWinner('X');
            xWin = xxWin;
            if (xError) error = true;
            if (xWin && countX != countO + 1) error = true;
            if (!error) {
                // 检查 O 胜利是否符合约束
                auto [oError, ooWin] = checkWinner('O');
                oWin = ooWin;
                if (oError) error = true;
                if (xWin && oWin) error = true;
                if (oWin && countX != countO) error = true;
            }
        }
        // 输出结果
        if (error) cout << "ERROR";
        else if (xWin) cout << "X WINS";
        else if (oWin) cout << "O WINS";
        else if (countX + countO == n * n) cout << "DRAW";
        else cout << "IN PROGRESS";
        cout << '\n';
    }
    return 0;
}
```
