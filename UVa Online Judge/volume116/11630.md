[UVa 11630 Cyclic Antimonotonic Permutations](https://blog.csdn.net/metaphysis/article/details/156543131)

## 题目描述

一个排列是指一个包含 $1$ 到 $n$ 所有整数的序列，每个整数恰好出现一次。本题要求寻找满足以下两个特殊性质的排列：

1. **反单调性 ($\texttt{Antimonotonic}$)**：对于任意三个连续的位置 $p_{i-1}$， $p_i$， $p_{i+1}$（其中 $1 < i < n$）， $p_i$ 必须是这三个数中的最大值或最小值。也就是说，排列中不能出现连续的单调递增或递减的三个数，每个中间位置必须是“峰”或“谷”。

2. **循环性 ($\texttt{Cyclic}$)**：该排列必须构成一个单一的循环。这意味着如果将排列 $p$ 视为一个置换，其中 $p_i$ 表示从位置 $i$ 指向位置 $p_i$ 的指针，那么从位置 $1$ 出发，沿着指针移动，可以在回到位置 $1$ 之前访问到所有 $n$ 个位置。用数学语言来说，这个排列作为一个置换，必须是一个长度为 $n$ 的循环。

**输入格式**：输入包含多个测试用例，每个测试用例一行，包含一个整数 $n$（$3 \leq n \leq 10^6$）。输入以 $n = 0$ 结束。

**输出格式**：对于每个测试用例，输出任意一个满足上述两个条件的 $1$ 到 $n$ 的排列，数字之间用空格分隔。

## 题目分析与解题思路

### 关键性质理解

1. **反单调性**：这要求排列呈现出“峰-谷-峰-谷”交替的模式。对于任意连续三个数 $(a, b, c)$， $b$ 要么大于 $a$ 和 $c$（峰），要么小于 $a$ 和 $c$（谷）。这排除了连续的单调子序列。

2. **循环性**：这要求排列对应的有向图（$i \to p_i$）是一个单一的环。这意味着从任何位置出发，沿着 $p$ 走 $n$ 步后都能回到起点，且中途不重复访问（除了回到起点）。这等价于排列的循环分解只有一个循环。

### 构造思路

直接枚举所有排列显然不可行（$n$ 最大可达 $10^6$）。因此，我们需要一种确定的构造方法。

通过观察样例和尝试小规模 $n$，我们可以发现一种可行的模式。对于前几个位置，我们可以尝试固定一些值，然后根据奇偶性确定后续位置的取值。

**核心构造策略**：
1. **固定前两个位置**：令 $p_1 = 3$， $p_2 = 1$。这确保了开头部分满足反单调性（$3$ 是峰，接着 $1$ 是谷）。
2. **处理中间位置（$i = 3$ 到 $i = n-1$）**：根据当前位置 $i$ 的奇偶性决定 $p_i$ 的值。
   - 如果 $i$ 是奇数，则令 $p_i = i + 2$。
   - 如果 $i$ 是偶数，则令 $p_i = i - 2$。
   这样构造可以保持反单调性，因为相邻位置的数值交替增减。
3. **特殊处理最后两个位置**：为了确保整个排列构成一个单一的循环，需要对最后两个位置的值进行调整。
   - 如果 $n$ 是奇数，则令 $p_n = n - 1$。
   - 如果 $n$ 是偶数，则令 $p_n = n - 2$，并且令 $p_{n-1} = n$。
   这种调整是闭合循环的关键，它保证了从位置 $1$ 出发可以遍历所有位置并回到 $1$。

### 正确性验证（以 $n=6$ 为例）

按照上述构造方法：
- $p_1 = 3$， $p_2 = 1$。
- $i=3$（奇数）：$p_3 = 5$。
- $i=4$（偶数）：$p_4 = 2$。
- $i=5$（奇数）：$p_5 = 7$（注意：这个值在后续会被覆盖）。
- $n=6$ 是偶数：所以 $p_6 = 4$， $p_5 = 6$（覆盖掉之前的 $7$）。

最终排列为：$3, 1, 5, 2, 6, 4$。

**检查反单调性**：
- $(3, 1, 5)$：$1$ 是谷。
- $(1, 5, 2)$：$5$ 是峰。
- $(5, 2, 6)$：$2$ 是谷。
- $(2, 6, 4)$：$6$ 是峰。
满足条件。

**检查循环性**：
- 映射关系：$1 \to 3$， $2 \to 1$， $3 \to 5$， $4 \to 2$， $5 \to 6$， $6 \to 4$。
- 从 $1$ 出发：$1 \to 3 \to 5 \to 6 \to 4 \to 2 \to 1$。
形成了一个长度为 $6$ 的循环，满足条件。

### 算法复杂度分析

- **时间复杂度**：对于每个测试用例，我们只需要一个 $O(n)$ 的循环来构造排列，总时间复杂度为 $O(\sum n)$，在题目限制下可以接受。
- **空间复杂度**：我们使用一个大小为 $n+1$ 的数组来存储排列，空间复杂度为 $O(n)$。

### 注意事项

1. 当 $n=3$ 时，上述构造方法中 $p_1 = 3$， $p_2 = 1$， $i=3$ 不进入循环，然后 $n$ 是奇数，所以 $p_3 = 2$。结果为 $3, 1, 2$，经验证也满足条件。
2. 在实现时，对于 $i$ 从 $3$ 到 $n-1$ 的循环，当 $i$ 接近 $n$ 时，$i+2$ 可能会暂时超过 $n$，但最后两个位置的特殊处理会覆盖掉这些越界的值，因此不会影响最终结果。
3. 题目要求输出任意一个解即可，因此这种确定的构造方法是可行的。

```cpp
// Cyclic Antimonotonic Permutations
// UVa ID: 11630
// Verdict: Accepted
// Submission Date: 2026-01-03
// UVa Run Time: 0.020s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;
int d[MAXN];

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n;
    while (cin >> n && n) {
        // 前两个固定
        d[1] = 3, d[2] = 1;
        // 中间部分
        for (int i = 3; i < n; ++i) {
            if (i & 1) d[i] = i + 2;  // 奇数位置
            else d[i] = i - 2;        // 偶数位置
        }
        // 最后两个特殊处理
        if (n & 1) d[n] = n - 1;
        else d[n] = n - 2, d[n - 1] = n;
        // 输出
        for (int i = 1; i <= n; ++i) cout << d[i] << " \n"[i == n];
    }
    return 0;
}
```

**代码说明**：
1. 使用 `d` 数组存储排列（从 $1$ 开始计数）。
2. `cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);` 用于加速输入输出。
3. 循环 `for (int i = 3; i < n; ++i)` 构造中间部分。
4. 条件表达式 `" \n"[i == n]` 用于在输出时判断是输出空格还是换行，这是一个简洁的技巧。
5. 该代码简洁高效，直接实现了上述构造算法。
