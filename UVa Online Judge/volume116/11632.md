## 题目描述

$\texttt{Elias Gamma}$ 编码是一种用于编码正整数序列的编码方法。本题使用一种修改后的版本，可以编码零。编码一个整数 $n$ 的原始规则是：

1. 令 $k$ 为 $n$ 的二进制位数
2. 先写 $k-1$ 个零，然后写一个 1（这部分称为前缀，长度为 $k$）
3. 再写 $n$ 的二进制表示（长度为 $k$）

因此一个整数 $n$ 在原始编码下的总长度为 $2k$。

对于整数序列，将每个整数的编码按顺序拼接即得整个序列的编码。

本题允许两种优化操作：

1. **前缀重映射**：如果某个前缀长度 $p$ 对应的二进制长度 $p$ 在原始序列中不存在（即没有位数为 $p$ 的整数），则这个前缀可以用于表示一个更大的二进制长度 $b > p$ 的整数。此时前缀长度仍为 $p$，但后面跟随的二进制部分长度为 $b$。
2. **加前导零**：可以把一个二进制长度为 $i$ 的整数前面添加若干个零，使其二进制长度变为 $b > i$，从而它可以与更短的前缀匹配。

通过合理组合这两种优化，可以缩短整个序列的编码长度。

输入给出 $n$ 和 $c_1, c_2, \dots, c_n$，其中 $c_i$ 表示二进制长度为 $i$ 的整数个数。要求输出最小可能的总编码长度。

## 问题分析

### 1. 核心观察

首先注意到，如果某种二进制长度 $i$ 在原始数据中根本没有出现（$c_i = 0$），那么：
- 它对应的前缀长度 $i$ 的原始模式不会被任何整数使用，因此可以被重新映射
- 通过加前导零，我们无法凭空创造出二进制长度为 $i$ 的整数（因为加零只能使长度增加，不能创造中间长度）

因此，**只有原始数据中实际出现的二进制长度才需要被编码**。设这些长度为 $L_1 < L_2 < \dots < L_m$，对应的个数为 $cnt_1, cnt_2, \dots, cnt_m$。题目中 $n \le 128$，但实际出现的种类 $m$ 可能更少。

### 2. 编码结构

在最终编码中，前缀长度必须从 1 开始连续使用（解码器按顺序读取前缀）。设我们使用了 $p$ 个不同的前缀，长度分别为 $1, 2, \dots, p$。

每个前缀 $i$ 会被分配给一个二进制长度 $L_j$（即该前缀后面跟随 $L_j$ 位二进制数）。由于前缀与二进制长度一一对应，且解码时需要区分，分配必须是单射。又因为前缀长度连续且 $L_j$ 互不相同，实际上我们是对出现的二进制长度进行了一个**顺序分配**：第 $i$ 个前缀对应第 $j_i$ 种长度，且 $j_1 < j_2 < \dots < j_p = m$（最后必须覆盖所有 $m$ 种长度）。

### 3. 区间覆盖模型

假设第 $i$ 个前缀对应第 $j$ 种长度 $L_j$，而前一个前缀（第 $i-1$ 个）对应第 $k$ 种长度 $L_k$（$k < j$）。那么：

- 前 $i-1$ 个前缀已经覆盖了第 $1 \dots k$ 种长度
- 第 $i$ 个前缀需要覆盖第 $k+1, k+2, \dots, j$ 种长度
- 这些长度的整数，通过加前导零，全部统一为最终长度 $L_j$
- 每个这样的整数编码长度为：前缀长度 $i$ + 最终二进制长度 $L_j$ = $i + L_j$

因此，第 $i$ 个前缀覆盖的区间 $[k+1, j]$ 的代价为：
$$
(i + L_j) \times \sum_{t=k+1}^{j} cnt_t
$$

这是一个典型的**区间覆盖 $\texttt{DP}$**：将 $m$ 种长度划分成若干连续段，第 $p$ 段（对应前缀 $p$）覆盖 $[l, r]$，代价为 $(p + L_r) \times \text{区间整数个数}$，总代价最小化。

### 4. 动态规划状态设计

设 $dp[i][j]$ 表示：已经使用了前缀长度 $1 \dots i$，且第 $i$ 个前缀对应第 $j$ 种二进制长度 $L_j$ 时，覆盖前 $j$ 种长度的所有整数所需的最小总编码长度。

边界条件：$dp[0][0] = 0$，表示未使用任何前缀时，覆盖 0 种长度。

转移方程：
$$
dp[i][j] = \min_{0 \le k < j} \left\{ dp[i-1][k] + (i + L_j) \times \sum_{t=k+1}^{j} cnt_t \right\}
$$

这里：
- $k = 0$ 表示前一个状态尚未覆盖任何长度
- 必须满足 $i \le j$，因为至少需要 $i$ 种不同的长度才能分配 $i$ 个前缀
- 实际编程时，$k$ 的起始值取 $\max(0, i-1)$，因为第 $i-1$ 个前缀至少对应第 $i-1$ 种长度（否则无法满足 $i-1$ 个不同的二进制长度）

最终答案：
$$
ans = \min_{1 \le i \le m} dp[i][m]
$$

### 5. 复杂度

状态数 $O(m^2)$，转移 $O(m)$，总复杂度 $O(m^3)$。由于 $m \le n \le 128$，$128^3 \approx 2 \times 10^6$，完全可行。

## 代码实现

```cpp
// Elias Gamma Coding
// UVa ID: 11632
// Verdict: Accepted
// Submission Date: 2026-05-30
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
const int INF = 1e9;

int main() {
    int n;
    while (cin >> n, n) {
        vector<int> c(n + 1);
        for (int i = 1; i <= n; ++i) cin >> c[i];
        
        // 提取实际出现的二进制长度
        vector<int> L, cnt;
        for (int i = 1; i <= n; ++i) if (c[i] > 0) {
            L.push_back(i);
            cnt.push_back(c[i]);
        }
        
        int m = L.size();
        // 前缀和，便于快速计算区间整数个数
        vector<int> pre(m + 1, 0);
        for (int i = 1; i <= m; ++i) pre[i] = pre[i - 1] + cnt[i - 1];
        
        // dp[i][j]: 用了 i 个前缀，最后一个前缀对应第 j 种长度
        vector<vector<int>> dp(m + 2, vector<int>(m + 2, INF));
        dp[0][0] = 0;
        
        for (int i = 1; i <= m; ++i) {
            for (int j = i; j <= m; ++j) {
                // k 是前一个前缀对应的种类，至少为 i-1（保证有 i-1 个不同长度）
                int startK = (i == 1) ? 0 : i - 1;
                for (int k = startK; k < j; ++k) {
                    if (dp[i - 1][k] == INF) continue;
                    int sum = pre[j] - pre[k];  // 区间 [k+1, j] 的整数个数
                    dp[i][j] = min(dp[i][j], dp[i - 1][k] + (i + L[j - 1]) * sum);
                }
            }
        }
        
        int ans = INF;
        for (int i = 1; i <= m; ++i) ans = min(ans, dp[i][m]);
        cout << ans << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于：
1. 发现只有原始数据中实际出现的二进制长度才需要处理
2. 将问题转化为**区间覆盖 + 前缀分配**的 DP 模型
3. 每个前缀覆盖一个连续区间，区间内所有整数统一提升到右端点长度
4. 使用 $dp[i][j]$ 表示用 $i$ 个前缀覆盖前 $j$ 种长度的最小代价

这种模型也可以推广到其他类似的前缀码优化问题中。
