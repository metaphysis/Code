[UVa 11633 Food Portion Size](https://blog.csdn.net/metaphysis/article/details/156766419)

## 题目描述

大学食堂希望确保没有学生饿着离开，因此只要学生仍感到饥饿，就可以免费再取一份食物。 食堂使用固定的食物分量大小 $S$ ，因为如果先询问每个学生想要多少食物会花费太多时间。 可能会出现学生吃不完最后一份食物的情况，剩余的食物将被丢弃。

为了最小化成本，食堂经理希望确定一个食物分量大小 $S$ ，使得浪费的食物量 $x$ 尽可能小，同时学生需要取餐的次数 $y$ 也不会太大。 注意这两个目标可能是冲突的：

- 选择非常小的 $S$ 不会浪费食物，但学生需要多次取餐。
- 选择较大的 $S$ 可以确保每个学生只取一次餐，但可能导致大量食物浪费。

经理收集了每个学生食量的数据。 问题可以形式化为：给定 $n$ 个学生的食量 $y_i$ ，权重 $a$ 和 $b$ ，寻找 $S$ 使得在 **每个学生取餐次数不超过 $3$ 次** 的前提下，最小化总成本 $a \times x + b \times y$ 。 其中 $x$ 是浪费的食物总量， $y$ 是总取餐次数。

### 输入格式
多组测试数据。 每组数据以整数 $n$ （ $1 \leq n \leq 1000$ ）开始，表示学生数。 接下来一行是两个整数 $a, b$ （ $1 \leq a, b \leq 10$ ）。 第三行包含 $n$ 个整数 $y_1, ..., y_n$ （ $1 \leq y_i \leq 100$ ），表示每个学生的食量。 输入以 $n = 0$ 结束。

### 输出格式
对于每组测试数据，输出一行，表示在最优 $S$ 下的最小成本，以 **最简分数** 形式输出。 如果结果为整数，则只输出分子（不输出分母 $1$ ）。

## 题目分析与解题思路

### 关键观察

1. **取餐次数约束**： 每个学生最多取 $3$ 次餐。 因此，对于食量为 $y_i$ 的学生，必须有 $S \geq \frac{y_i}{3}$ 。 否则，即使取 $3$ 次也无法满足食量需求。

2. **最优 $S$ 的可能位置**：
   - 如果 $S$ 恰好等于某个学生的食量 $y_i$ ，那么该学生取 $1$ 次餐，无浪费。
   - 如果 $S$ 等于 $\frac{y_i}{2}$ ，那么该学生取 $2$ 次餐，可能无浪费（若 $y_i$ 是偶数）或浪费 $S - y_i\%S$ 。
   - 如果 $S$ 等于 $\frac{y_i}{3}$ ，那么该学生取 $3$ 次餐，可能无浪费（若 $y_i$ 是 $3$ 的倍数）或浪费 $3S - y_i$ 。
   - 最优 $S$ 还可能位于两个学生食量之间，例如 $\frac{y_i + y_j}{2}$ ，此时 $S$ 对于两个学生来说可能产生不同的浪费和取餐次数。

3. **目标函数**： 成本为 $a \times x + b \times y$ ，其中 $x$ 和 $y$ 都依赖于 $S$ 。 由于 $S$ 可以是分数，为了避免浮点数精度问题，我们应使用 **分数（有理数）** 来表示 $S$ 和成本。

### 算法设计

基于以上观察，我们可以通过 **枚举候选 $S$** 来求解。 候选 $S$ 应包括：
- 每个学生的食量 $y_i$ （对应取 $1$ 次）。
- 每个学生食量的一半 $\frac{y_i}{2}$ （对应取 $2$ 次）。
- 每个学生食量的三分之一 $\frac{y_i}{3}$ （对应取 $3$ 次）。
- 每两个学生食量的平均值 $\frac{y_i + y_j}{2}$ （因为最优 $S$ 可能位于两者之间）。

**步骤**：
1. 收集所有候选 $S$ ，用分数表示（分子和分母）。
2. 对每个候选 $S$ ：
   - 检查是否满足约束：对于每个学生，计算所需取餐次数 $ \lceil \frac{y_i}{S} \rceil $ ，若大于 $3$ 则跳过。
   - 计算总浪费食物 $x$ 和总取餐次数 $y$ 。
   - 计算成本 $cost = a \times x + b \times y$ 。
3. 在所有满足约束的候选 $S$ 中，选择成本最小的一个。
4. 输出最小成本的最简分数形式。

### 复杂度分析
- 候选 $S$ 的数量最多为 $O(n^2)$ （主要来自两两平均值）。
- 对每个候选 $S$ 需要 $O(n)$ 时间计算总浪费和取餐次数。
- 总时间复杂度 $O(n^3)$ ，但 $n \leq 1000$ ，且实际候选数远小于 $n^2$ ，在合理范围内可以通过。

## 代码实现

```cpp
// Food Portion Size
// UVa ID: 11633
// Verdict: Accepted
// Submission Date: 2026-01-09
// UVa Run Time: 0.870s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Fraction {
    long long num, den; // 分子、分母
    Fraction(long long n = 0, long long d = 1) {
        long long g = __gcd(n, d);
        num = n / g;
        den = d / g;
        if (den < 0) num = -num, den = -den; // 保证分母为正
    }
    bool operator<(const Fraction& other) const {
        return num * other.den < other.num * den;
    }
};

int main() {
    int n;
    while (cin >> n, n) {
        int a, b;
        cin >> a >> b;
        vector<int> food(n);
        for (int i = 0; i < n; ++i) cin >> food[i];

        // 存储所有可能的分量值 S 的候选
        set<Fraction> candidates;

        // 对于每个学生，将其食量 y_i 的 1/1、1/2、1/3 作为 S 的可能取值
        for (int yi : food) {
            candidates.insert(Fraction(yi, 1));
            candidates.insert(Fraction(yi, 2));
            candidates.insert(Fraction(yi, 3));
        }

        // 对于每两个学生的食量，计算它们和的一半（即可能的最优 S 在中间的情况）
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                candidates.insert(Fraction(food[i] + food[j], 2));

        Fraction bestCost(LLONG_MAX, 1); // 初始化最优成本为无穷大
        Fraction bestS(0, 1);

        // 遍历所有候选 S
        for (const Fraction& S : candidates) {
            if (S.num <= 0) continue; // S 必须为正
            long long totalWaste = 0;
            long long totalTrips = 0;
            bool valid = true;

            for (int yi : food) {
                // 计算该学生需要的份数（向上取整）
                long long portions = (yi * S.den + S.num - 1) / S.num;
                if (portions > 3) { valid = false; break; } // 超过 3 次，不满足约束
                long long totalFood = portions * S.num;
                long long waste = totalFood - yi * S.den; // 浪费的食物（乘以分母后的整数）
                totalWaste += waste;
                totalTrips += portions;
            }

            if (!valid) continue; // 该 S 不满足约束，跳过

            // 计算总成本：a * waste + b * trips
            Fraction cost(a * totalWaste + b * totalTrips * S.den, S.den);
            if (cost < bestCost) {
                bestCost = cost;
                bestS = S;
            }
        }

        // 输出最优成本
        if (bestCost.den == 1) cout << bestCost.num << "\n";
        else cout << bestCost.num << " / " << bestCost.den << "\n";
    }
    return 0;
}
```
## 优化实现：

```cpp
// Food Portion Size
// UVa ID: 11633
// Verdict: Accepted
// Submission Date: 2026-01-09
// UVa Run Time: 0.030s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef pair<long long, long long> Frac;

// 比较两个分数的大小，a < b
bool cmp(const Frac& a, const Frac& b) {
    return a.first * b.second < b.first * a.second;
}

// 约分分数
Frac reduce(const Frac& f) {
    long long g = __gcd(f.first, f.second);
    return {f.first / g, f.second / g};
}

int main() {
    int n;
    while (cin >> n, n) {
        int a, b;
        cin >> a >> b;
        vector<int> food(n);
        // 收集所有候选S：每个食量的1, 1/2, 1/3
        set<Frac> candidates;
        for (int i = 0; i < n; ++i) {
            cin >> food[i];
            for (int k = 1; k <= 3; ++k) {
                long long g = __gcd(food[i], k);
                candidates.insert({food[i] / g, k / g});
            }
        }
        // 排序食量用于提前剪枝
        sort(food.begin(), food.end());
        Frac bestCost = {LLONG_MAX, 1};
        for (const auto& s : candidates) {
            long long u = s.first, d = s.second;
            // 提前剪枝：检查最大食量的学生
            if ((food.back() * d + u - 1) / u > 3) continue;
            long long totalWaste = 0;
            long long totalTrips = 0;
            bool valid = true;
            for (int yi : food) {
                long long portions = (yi * d + u - 1) / u;
                if (portions > 3) {
                    valid = false;
                    break;
                }
                totalTrips += portions;
                totalWaste += portions * u - yi * d;
            }
            if (!valid) continue;
            // 计算成本
            Frac cost = {a * totalWaste + b * totalTrips * d, d};
            cost = reduce(cost);
            if (cmp(cost, bestCost)) bestCost = cost;
        }
        // 输出结果
        if (bestCost.second == 1) cout << bestCost.first;
        else cout << bestCost.first << " / " << bestCost.second;
        cout << '\n';
    }
    return 0;
}
```

## 总结

本题通过 **枚举候选分量大小 $S$** 并利用 **分数运算避免精度问题** 的方法，在满足取餐次数约束的前提下，最小化由浪费食物和取餐次数构成的加权成本。 关键点在于理解最优 $S$ 只会出现在某些特殊位置（学生食量的 $1$、$\frac{1}{2}$、$\frac{1}{3}$ 或两食量平均值），从而将无限搜索空间缩小为有限候选集。 使用分数表示和比较，确保了计算的准确性。
