## 题目描述

给定一个整数 $N$ ($0 \leq N \leq 2^{63}-2$)，要求计算从 $0$ 到 $N$ 的所有整数的二进制表示中，相邻两个比特都是 $1$ (即 `11`) 出现的总次数。

例如：
- 数字 $12$ 的二进制是 $1100$，包含 $1$ 个相邻的 $1$ 比特对
- 数字 $15$ 的二进制是 $1111$，包含 $3$ 个相邻的 $1$ 比特对
- 数字 $27$ 的二进制是 $11011$，包含 $2$ 个相邻的 $1$ 比特对

对于每个测试用例，输出格式为 `Case X: Y`，其中 $X$ 是测试用例编号，$Y$ 是从 $0$ 到 $N$ 的所有数字中相邻 $1$ 比特对的总数。

## 题目分析

### 问题规模分析

$N$ 的最大值可达 $2^{63}-2$，这意味着：
- 直接枚举 $0$ 到 $N$ 的所有数字并检查其二进制表示是不可行的
- 二进制位数最多为 $63$ 位（因为 $2^{63}-2$ 需要 $63$ 位二进制表示）
- 相邻 $1$ 比特对的总数可能非常大，需要使用 $128$ 位整数来避免溢出

### 关键观察

我们需要统计的是**所有数字中相邻 $1$ 比特对的出现次数**，而不是简单统计有多少个数字包含相邻 $1$ 比特对。例如：
- 数字 $15$ ($1111$) 贡献 $3$ 次计数（位置 $0$-$1$，$1$-$2$，$2$-$3$）
- 数字 $12$ ($1100$) 贡献 $1$ 次计数（位置 $0$-$1$）

## 解题思路

### 为什么选择数位 $\texttt{DP}$？

数位 $\texttt{DP}$ 非常适合这类"统计某个范围内数字的某种特性"的问题，原因如下：

1. **避免枚举**：不需要逐个检查 $0$ 到 $N$ 的所有数字
2. **按位处理**：二进制表示天然适合按位处理
3. **状态压缩**：可以通过有限的状态记录关键信息
4. **记忆化搜索**：重复子问题可以避免重复计算

### 数位 $\texttt{DP}$ 状态设计

我们定义 $\texttt{dp[pos][prev][tight][count]}$ 表示：

- $\texttt{pos}$：当前处理的二进制位位置（从高位到低位）
- $\texttt{prev}$：前一位的值（$0$ 或 $1$）
- $\texttt{tight}$：是否受到上界 $N$ 的限制（$1$ 表示受限，$0$ 表示不受限）
- $\texttt{count}$：到当前位置为止已经出现的相邻 $1$ 比特对数量

状态的含义是：在二进制表示的前 $\texttt{pos}$ 位已经确定，且前一位的值为 $\texttt{prev}$，是否受上界限制为 $\texttt{tight}$，已经统计到 $\texttt{count}$ 个相邻 $1$ 比特对的情况下，剩余位数能够产生的相邻 $1$ 比特对总数。

### 状态转移

对于每个状态 $\texttt{(pos, prev, tight, count)}$：

1. 确定当前位可选的数字范围：
   - 如果 $\texttt{tight} = 1$，当前位最大可取 $N$ 的对应位值
   - 如果 $\texttt{tight} = 0$，当前位可取 $0$ 或 $1$

2. 对于每个可选数字 $d$：
   - 计算新的 $\texttt{count}$：如果 $\texttt{prev} = 1$ 且 $d = 1$，则 $\texttt{count}$ 加 $1$
   - 计算新的 $\texttt{tight}$：如果原来的 $\texttt{tight} = 1$ 且 $d$ 等于 $N$ 的对应位值，则新的 $\texttt{tight} = 1$，否则为 $0$
   - 递归处理下一位：$\texttt{dfs(pos+1, d, new\_tight, new\_count)}$

3. 将所有可选数字的结果累加，即为当前状态的结果

### 边界条件

当 $\texttt{pos}$ 等于总位数时，说明所有位都已处理完毕，直接返回当前统计的 $\texttt{count}$ 值。

### 算法正确性证明

数位 $\texttt{DP}$ 能够正确计数的原因：

1. **完整性**：通过 $\texttt{tight}$ 参数确保不会超过上界 $N$
2. **无重复**：每个数字的二进制表示唯一对应一条搜索路径
3. **无遗漏**：通过遍历所有可能的数字组合，确保统计了所有 $0$ 到 $N$ 的数字
4. **高效性**：通过记忆化避免重复计算相同状态

### 时间复杂度

状态数为 $O(\log N \times 2 \times 2 \times \log N) = O((\log N)^2)$，对于 $N \leq 2^{63}-2$，$\log N \leq 63$，状态数约为 $63 \times 2 \times 2 \times 63 \approx 15,876$，完全可行。

```cpp
#include <iostream>
#include <cstring>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

using ll = long long;
using i128 = __int128;

i128 dp[64][2][2][64];
vector<int> digits;

i128 dfs(int pos, int prev, int tight, int cnt) {
    if (pos == (int)digits.size()) {
        return cnt;
    }
    if (dp[pos][prev][tight][cnt] != -1) {
        return dp[pos][prev][tight][cnt];
    }
    i128 res = 0;
    int up = tight ? digits[pos] : 1;
    for (int d = 0; d <= up; d++) {
        int new_cnt = cnt;
        if (prev == 1 && d == 1) {
            new_cnt++;
        }
        res += dfs(pos + 1, d, tight && (d == up), new_cnt);
    }
    return dp[pos][prev][tight][cnt] = res;
}

string i128_to_string(i128 num) {
    if (num == 0) return "0";
    string s;
    bool negative = false;
    if (num < 0) {
        negative = true;
        num = -num;
    }
    while (num > 0) {
        s += '0' + (num % 10);
        num /= 10;
    }
    if (negative) {
        s += '-';
    }
    reverse(s.begin(), s.end());
    return s;
}

i128 solve(ll n) {
    if (n < 0) return 0;
    digits.clear();
    ll temp = n;
    while (temp > 0) {
        digits.push_back(temp & 1);
        temp >>= 1;
    }
    if (digits.empty()) {
        digits.push_back(0);
    }
    reverse(digits.begin(), digits.end());
    memset(dp, -1, sizeof dp);
    return dfs(0, 0, 1, 0);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    ll n;
    int caseNo = 1;
    while (cin >> n) {
        if (n < 0) break;
        i128 result = solve(n);
        cout << "Case " << caseNo++ << ": " << i128_to_string(result) << "\n";
    }
    return 0;
}
```

## 总结

本题通过数位 $\texttt{DP}$ 高效地解决了大范围内统计二进制特征的问题。关键点在于：

1. 合理设计状态，包含位置、前一位值、限制条件和当前计数
2. 使用记忆化搜索避免重复计算
3. 使用 $\_\_\texttt{int128}$ 处理大数避免溢出
4. 正确实现状态转移和边界条件处理

这种方法可以扩展到其他类似的数位统计问题，如统计特定比特模式的出现次数等。
