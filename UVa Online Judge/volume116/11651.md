[UVa 11651 Krypton Number System](https://blog.csdn.net/metaphysis/article/details/156953678)

### 问题描述

氪星（$\texttt{Krypton}$）的数字系统与我们熟知的进制系统有很大不同，主要特点如下：

1.  **基数未知**：系统的基数 $base$ 在 $2$ 到 $6$ 之间（包含端点）。
2.  **数字约束**：一个有效的数字不能包含两个**相邻的相同数字**（例如，$112$ 无效），且不能有**前导零**（例如，$012$ 无效）。
3.  **分数计算**：每个数字都有一个“分数”（$\texttt{score}$）。计算方法是求其**相邻数字差值的平方和**。例如数字 $1241$ 的分数为：
    $(1-2)^2 + (2-4)^2 + (4-1)^2 = 1 + 4 + 9 = 14$。
4.  **问题目标**：给定基数 $base$ 和目标分数 $score$ ($1 \le score \le 10^9$)，求在满足上述约束的所有数字中，分数恰好等于 $score$ 的数字有多少个。由于答案可能非常大，要求输出结果对 $2^{32}$ 取模的值。

**输入格式**：第一行一个整数 $T$ ($\le 200$) 表示测试用例数。之后每行两个整数 $base$ 和 $score$。

**输出格式**：对于每个测试用例，输出 `Case i: result`，其中 `result` 是答案对 $2^{32}$ 取模的结果。

### 题目分析与核心难点

这道题初看是一个计数问题，但约束条件使其变得极具挑战性。

首先，我们考虑最直观的动态规划（$\texttt{DP}$）方法。我们可以定义状态 $dp[s][last]$：表示当前数字的总分数为 $s$，且最后一位数字是 $last$ 的有效数字的个数。

*   **初始状态**：对于所有非零数字 $d$ ($1 \le d < base$)，长度为 $1$ 的数字是合法的，因此 $dp[0][d] = 1$。$dp[0][0] = 0$，因为不能有前导零。
*   **状态转移**：为了得到一个分数为 $s$，末位为 $last$ 的数字，我们可以在一个末位为 $prev$，分数为 $s-d$ 的数字后面追加 $last$。其中 $d = (last - prev)^2$ 是新增的分数，且必须满足 $prev \neq last$（相邻数字不同）。因此，转移方程为：
    $dp[s][last] = \sum_{prev=0, prev \neq last}^{base-1} dp[s-d][prev]$，其中 $d = (last-prev)^2$。
*   **最终答案**：目标分数为 $score$，答案为所有可能的末位数字的方案数之和，即 $ans = \sum_{last=0}^{base-1} dp[score][last]$。

**难点**：目标分数 $score$ 的上限高达 $10^9$。如果直接进行上述 $\texttt{DP}$，我们需要迭代 $s$ 从 $0$ 到 $score$，时间复杂度为 $O(score \cdot base^2)$，这显然是不可接受的。

**突破口**：观察到每次转移时，分数增量 $d = (last-prev)^2$ 的取值范围是有限的。由于 $last$ 和 $prev$ 都在 $[0, base-1]$ 之间，且 $last \neq prev$，所以 $d$ 的取值范围是 $\{1^2, 2^2, ..., (base-1)^2\}$。记 $maxSq = (base-1)^2$，$d \in [1, maxSq]$。

这个性质意味着，分数 $s$ 的状态 $dp[s][*]$ **仅依赖于**前面最多 $maxSq$ 个分数的状态，即 $dp[s-1][*], dp[s-2][*], ..., dp[s-maxSq][*]$。这揭示了一个重要特性：**该动态规划序列满足一个常系数线性递推关系**。

### 解题思路：矩阵快速幂优化线性递推

一旦我们识别出 $\texttt{DP}$ 序列是线性递推的，就可以使用**矩阵快速幂**来高效计算第 $score$ 项，将时间复杂度从 $O(score)$ 降为 $O(\log(score))$。

**1. 构建状态向量**

我们需要用一个向量来封装“最近”的、足以决定未来所有状态的一段 $\texttt{DP}$ 历史。由于 $dp[s][last]$ 只依赖于前 $maxSq$ 个分数，我们需要记录对于每个可能的末位数字 $last$，从 $dp[s][last]$ 到 $dp[s-maxSq+1][last]$ 的所有值。

定义状态向量 $\vec{V}_s$，其长度为 $L = base \times maxSq$。我们按以下规则组织向量：
向量索引 $idx = last \times maxSq + offset$，其中 $0 \le last < base$，$0 \le offset < maxSq$。
该位置存储的值是 $dp[s - offset][last]$。

特别地，当 $offset = 0$ 时，存储的就是当前最新的状态 $dp[s][last]$。

**2. 构造转移矩阵**

我们的目标是找到一个 $L \times L$ 的矩阵 $M$，使得 $\vec{V}_s = M \times \vec{V}_{s-1}$。

如何构造 $M$？我们需要根据 $\texttt{DP}$ 的转移方程，从 $\vec{V}_{s-1}$ 计算出 $\vec{V}_s$ 的每一个分量。

*   **计算最新状态 ($offset = 0$)**：
    对于 $\vec{V}_s$ 中 $idx_{new} = last \times maxSq + 0$ 的位置，它对应 $dp[s][last]$。
    根据 $\texttt{DP}$ 方程：$dp[s][last] = \sum_{prev \neq last} dp[s-d][prev]$，其中 $d=(last-prev)^2$。
    在 $\vec{V}_{s-1}$ 中，$dp[s-d][prev]$ 位于索引 $idx_{old} = prev \times maxSq + (d-1)$ 的位置。因为 $\vec{V}_{s-1}$ 存储的是 $dp[(s-1)-?][*]$，为了找到 $dp[s-d][*]$，偏移量应为 $(s-1) - (s-d) = d-1$。
    因此，对于每一对 $(prev, last)$，我们在矩阵 $M$ 的 $[idx_{old}][idx_{new}]$ 位置加上 $1$。

*   **平移历史状态 ($offset > 0$)**：
    对于 $\vec{V}_s$ 中 $idx_{new} = last \times maxSq + offset$ ($offset \ge 1$) 的位置，它对应 $dp[s - offset][last]$。
    这个值其实就是 $\vec{V}_{s-1}$ 中 $dp[(s-1) - (offset-1)][last]$，也就是 $\vec{V}_{s-1}$ 中索引为 $idx_{old} = last \times maxSq + (offset-1)$ 的值。
    因此，我们在矩阵 $M$ 的 $[idx_{old}][idx_{new}]$ 位置设为 $1$，实现历史数据的“平移”。

通过上述规则，我们可以构造出完整的转移矩阵 $M$。

**3. 设置初始向量**

初始时，$s=0$。向量 $\vec{V}_0$ 表示 $dp[0][*]$ 以及 $dp[负数][*]$。
*   根据定义，$dp[0][last] = 1$ 当且仅当 $last \neq 0$（有效的单数字）。
*   所有 $dp[$负数$][*]$ 以及 $dp[0][0]$ 都为 $0$。
因此，在 $\vec{V}_0$ 中，对于 $last = 1$ 到 $base-1$，设置 $idx = last \times maxSq + 0$ 的位置为 $1$，其余位置为 $0$。

**4. 计算答案与取模**

我们要计算 $dp[score][*]$，即 $\vec{V}_{score}$ 中所有 $offset=0$ 的分量。
根据递推关系，$\vec{V}_{score} = M^{score} \times \vec{V}_0$。
我们通过矩阵快速幂计算 $M^{score}$，然后左乘初始向量 $\vec{V}_0$，得到 $\vec{V}_{score}$。
最后，求和 $\vec{V}_{score}$ 中所有 $last \times maxSq + 0$ 位置的值，即为答案。
题目要求对 $2^{32}$ 取模，而 C++ 中的 `unsigned int` 类型在溢出时自动等价于模 $2^{32}$ 操作，因此使用 `unsigned int` 进行计算即可。

### 代码实现

```cpp
// Krypton Number System
// UVa ID: 11651
// Verdict: Accepted
// Submission Date: 2026-01-14
// UVa Run Time: 0.690s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 使用 unsigned int，运算溢出时自动实现对 2^32 取模
typedef unsigned int uint;

// 矩阵结构体，用于矩阵快速幂
struct Matrix {
    int n; // 矩阵维度
    vector<vector<uint>> m; // 矩阵数据
    Matrix(int sz = 0): n(sz), m(sz, vector<uint>(sz, 0)) {}

    // 矩阵乘法
    Matrix operator*(const Matrix& b) const {
        Matrix r(n);
        for (int i = 0; i < n; i++) {
            for (int k = 0; k < n; k++) {
                if (m[i][k]) { // 稀疏性优化，跳过0值
                    for (int j = 0; j < n; j++) {
                        r.m[i][j] += m[i][k] * b.m[k][j];
                    }
                }
            }
        }
        return r;
    }
};

// 矩阵快速幂，计算 a^p
Matrix matPow(Matrix a, int p) {
    Matrix r(a.n);
    // 初始化为单位矩阵
    for (int i = 0; i < a.n; i++) r.m[i][i] = 1;
    while (p) {
        if (p & 1) r = r * a;
        a = a * a;
        p >>= 1;
    }
    return r;
}

int main() {
    int T, base, score;
    scanf("%d", &T);
    for (int tc = 1; tc <= T; tc++) {
        scanf("%d%d", &base, &score);

        // maxSq 是相邻数字差值的最大平方
        int maxSq = (base - 1) * (base - 1);
        // 状态向量长度 L = base * maxSq
        int L = base * maxSq;

        // ---------- 1. 构造转移矩阵 M (L x L) ----------
        Matrix M(L);
        // 索引规则: idx = last * maxSq + offset
        // V_s[idx] 存储 dp[s - offset][last]
        for (int last = 0; last < base; last++) {
            for (int prev = 0; prev < base; prev++) {
                if (last == prev) continue; // 相邻数字不能相同
                int d = (last - prev) * (last - prev); // 分数增量
                // 遍历所有偏移量 offset
                for (int offset = 0; offset < maxSq; offset++) {
                    if (offset == 0) {
                        // 计算新的 dp[s][last]
                        // 它依赖于旧的 dp[s-d][prev]，该值位于 V_{s-1} 的特定位置
                        int fromRow = prev * maxSq + (d - 1); // V_{s-1} 中的源索引
                        int toCol = last * maxSq + 0;         // V_s 中的目标索引
                        M.m[fromRow][toCol] = 1;
                    } else {
                        // 平移历史数据：V_s[last,offset] = V_{s-1}[last, offset-1]
                        int shiftFrom = last * maxSq + (offset - 1);
                        int shiftTo = last * maxSq + offset;
                        M.m[shiftFrom][shiftTo] = 1;
                    }
                }
            }
        }

        // ---------- 2. 构造初始向量 V0 ----------
        // V0 对应 s=0 时的状态向量
        vector<uint> V0(L, 0);
        // 初始化：dp[0][last] = 1 (last != 0)
        for (int last = 1; last < base; last++) {
            int idx = last * maxSq + 0; // offset = 0
            V0[idx] = 1;
        }

        // ---------- 3. 计算 V_score = M^score * V0 ----------
        Matrix Mp = matPow(M, score);
        vector<uint> Vscore(L, 0);
        // 模拟矩阵 Mp 与列向量 V0 的乘法，结果存入 Vscore
        for (int i = 0; i < L; i++) {
            if (V0[i] == 0) continue; // 优化：跳过0值
            for (int j = 0; j < L; j++) {
                Vscore[j] += V0[i] * Mp.m[i][j];
            }
        }

        // ---------- 4. 提取答案 ----------
        // 答案 = sum_{last=0}^{base-1} dp[score][last]
        // dp[score][last] 存储在 Vscore 中索引为 (last * maxSq + 0) 的位置
        uint ans = 0;
        for (int last = 0; last < base; last++) {
            int idx = last * maxSq + 0;
            ans += Vscore[idx];
        }
        printf("Case %d: %u\n", tc, ans);
    }
    return 0;
}
```

### 算法复杂度分析

*   **时间复杂度**：主要开销在于矩阵快速幂。矩阵 $M$ 的维度 $L = base \times (base-1)^2$。当 $base=6$ 时，$L=6 \times 25 = 150$。一次矩阵乘法的复杂度为 $O(L^3)$。矩阵快速幂需要进行 $O(\log score)$ 次乘法。整体复杂度约为 $O((base^3 \cdot maxSq^3) \log score)$，对于本题数据范围可以接受。
*   **空间复杂度**：主要为存储 $L \times L$ 的矩阵，即 $O(L^2)$。

### 总结

本题的解决过程展示了如何将一类复杂的计数问题，通过分析其状态转移的局部依赖性，转化为线性递推模型，并利用矩阵快速幂进行高效求解。关键在于：
1.  识别出由于分数增量有限， $\texttt{DP}$ 满足线性递推。
2.  巧妙地设计状态向量，以容纳足够的历史信息。
3.  正确构造出对应的转移矩阵。

这种方法（$\texttt{DP}$ + 矩阵快速幂）是解决许多具有线性递推性质的大规模计数问题的有力武器。
