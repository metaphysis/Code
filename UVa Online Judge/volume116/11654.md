[UVa 11654 Arithmetic Subsequence](https://blog.csdn.net/metaphysis/article/details/154878506)

## 题目描述

给定一个包含 $n$ 个数字的集合，我们需要计算有多少个**真子集**构成**算术序列**。算术序列是指序列中连续元素之间的差为常数的序列。例如，$\{1,5,9\}$ 是一个算术序列，因为相邻元素的差都是 $4$。

**重要规则**：
- 子集中的元素必须保持它们在原集合中的相对顺序
- 真子集包括所有非空子集（包括整个集合本身）
- 单个元素也被认为是算术序列

### 输入格式
- 第一行：测试用例数量 $T$ ($T \leq 100$)
- 每个测试用例：
  - 第一行：整数 $n$ ($n \leq 250$)
  - 接下来 $n$ 行：$n$ 个非负整数（每个小于 $100000001$）

### 输出格式
对于每个测试用例，输出构成算术序列的子集数量，结果对 $10000007$ 取模。

## 题目分析

### 关键观察

1. **算术序列的定义**：
   - 长度为 $1$ 的序列：总是算术序列（没有差值要求）
   - 长度为 $2$ 的序列：总是算术序列（只有一个差值）
   - 长度 $\geq 3$ 的序列：需要所有相邻元素的差相等

2. **顺序要求**：子集元素必须保持原序列中的相对顺序，但不要求连续

3. **计数目标**：我们需要统计所有满足条件的真子集数量

### 样例分析

**样例 1**：$\{1, 2, 4\}$
- 长度为 $1$：$\{1\}, \{2\}, \{4\}$ → $3$ 个
- 长度为 $2$：$\{1,2\}, \{1,4\}, \{2,4\}$ → $3$ 个  
- 长度为 $3$：$\{1,2,4\}$（不是算术序列）→ $0$ 个
- 总计：$3 + 3 = 6$

**样例 2**：$\{1\}$
- 长度为 $1$：$\{1\}$ → $1$ 个
- 总计：$1$

**样例 3**：$\{1, 2, 2\}$
- 长度为 $1$：$\{1\}, \{2\}, \{2\}$ → $3$ 个
- 长度为 $2$：$\{1,2\}, \{1,2\}, \{2,2\}$ → $3$ 个
- 长度为 $3$：$\{1,2,2\}$（不是算术序列）→ $0$ 个
- 总计：$3 + 3 = 6$

## 解题思路

### 动态规划方法

我们使用动态规划来高效地统计所有算术序列：

#### 状态定义
设 $dp[i][d]$ 表示以第 $i$ 个元素结尾、公差为 $d$ 的算术序列的数量。

#### 状态转移
对于每个位置 $i$，我们遍历所有 $j < i$：
1. 计算差值 $d = a[i] - a[j]$
2. 更新 $dp[i][d] = dp[i][d] + dp[j][d] + 1$
   - $dp[j][d]$：以 $j$ 结尾、公差为 $d$ 的序列数量
   - $+1$：新形成的长度为 $2$ 的序列 $\{a[j], a[i]\}$
3. 统计答案：将 $dp[j][d] + 1$ 加入总结果

#### 最终计算
- 动态规划过程统计了所有长度 $\geq 2$ 的算术序列
- 再加上 $n$ 个长度为 $1$ 的序列
- 结果对 $10000007$ 取模

### 算法复杂度
- **时间复杂度**：$O(n^2)$，对于每个 $i$ 遍历所有 $j < i$
- **空间复杂度**：$O(n^2)$，使用哈希表存储公差

### 优化细节
- 使用 `unordered_map` 存储公差，避免开过大数组
- 及时取模防止整数溢出

## 代码实现

```cpp
// Arithmetic Subsequence
// UVa ID: 11654
// Verdict: Accepted
// Submission Date: 2025-11-15
// UVa Run Time: 0.150s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MOD = 10000007;

int main() {
    int T;
    cin >> T;
    for (int cs = 1; cs <= T; cs++) {
        int n;
        cin >> n;
        vector<long long> a(n);
        for (int i = 0; i < n; i++) cin >> a[i];

        vector<unordered_map<long long, int>> dp(n);
        long long r = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                long long d = a[i] - a[j];
                dp[i][d] = (dp[i][d] + dp[j][d] + 1) % MOD;
                r = (r + dp[j][d] + 1) % MOD;
            }
        }
        // 在线测试数据将整个序列也认为是真子集，只要符合算术序列的定义，所以不需特判
        cout << "Case " << cs << ": " << r + n << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于理解算术序列的定义和子集的顺序要求。通过动态规划方法，我们能够高效地统计所有满足条件的子集。算法的时间复杂度和空间复杂度都在可接受范围内，能够处理题目给出的最大数据规模。

**核心技巧**：
- 使用哈希表存储不同公差的序列数量
- 动态规划状态表示以某个元素结尾的特定公差序列
- 及时取模处理大数运算

这种解法既保证了正确性，又具有较好的效率，是解决此类组合计数问题的典型方法。
