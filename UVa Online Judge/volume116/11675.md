## 题目描述

在一个由 $N$ 个朋友组成的友谊网络中，每个人有一个快乐度。初始时，只有一个人（编号 $K$）的快乐度为 $1$，其余人快乐度为 $0$。每天，每个人的快乐度按照如下规则变化：

*   如果某人在前一天**快乐度增加了**，那么今天他的快乐度保持不变。
*   如果某人在前一天**快乐度没有增加**，那么今天他的快乐度会增加，增加的量等于他所有朋友的快乐度之和（取前一天的值）。

这里的“增加”是指快乐度数值相比前一天**严格变大**。

给定网络结构（$N$ 个点，$M$ 条无向边），以及天数 $D$（$0 \le D \le 10^8$），求 $D$ 天后每个人的快乐度，结果对 $10^9+7$ 取模。

## 题目分析

### 规则重述

设第 $d$ 天结束时（即经过 $d$ 天更新后）第 $i$ 个人的快乐度为 $h_d[i]$，并定义标志位 $inc_d[i]$ 表示第 $d$ 天结束时快乐度是否**增长了**（即 $h_d[i] > h_{d-1}[i]$）。

根据规则：

*   若 $inc_{d-1}[i] = 1$，则 $h_d[i] = h_{d-1}[i]$（不变）。
*   若 $inc_{d-1}[i] = 0$，则 $h_d[i] = h_{d-1}[i] + \sum_{j \in \text{friends}(i)} h_{d-1}[j]$（增长）。

而 $inc_d[i]$ 由 $h_d[i]$ 和 $h_{d-1}[i]$ 的比较自然得出：$inc_d[i] = 1$ 当且仅当 $h_d[i] \neq h_{d-1}[i]$。

初始条件（第 $0$ 天）：$h_0[K] = 1$，其余为 $0$。由于 $K$ 从 $0$ 变为 $1$，所以 $inc_0[K] = 1$，其余 $inc_0[i] = 0$。

### 关键观察

1. **快乐度的增长是单向的**：快乐度永远不会减少，只会增加或保持不变。这是一个单调非降的过程。

2. **首次激活时间**：定义 $t[i]$ 为第 $i$ 个人快乐度第一次变为正数的天数。由于网络是连通的（题目保证 $M \ge N-1$），所有点最终都会被激活。$t[i]$ 就是从 $K$ 到 $i$ 的最短路径长度（BFS 可求）。

3. **稳定期**：当所有点都被激活后（即 $d \ge \max t[i]$），每个点的 $inc$ 标志会进入周期为 $2$ 的交替模式。这是因为：
   * 当一个点的邻居快乐度都为正且足够大时，它是否增长完全由其前一日的 $inc$ 决定，不再受具体数值影响。
   * 由于 $inc$ 每天翻转（增长日之后是不增长日，不增长日之后是增长日），最终每个点的 $inc$ 状态会稳定下来，仅与 $d$ 的奇偶性有关。

4. **线性化**：在稳定期内，每个点的更新可以写成**线性变换**：
   * 若 $inc[i] = 1$：$h'[i] = h[i]$（对应单位矩阵 $I$ 的第 $i$ 行）。
   * 若 $inc[i] = 0$：$h'[i] = h[i] + \sum_j A[i][j] \cdot h[j]$（对应矩阵 $I + A$ 的第 $i$ 行，其中 $A$ 是邻接矩阵）。

   由于 $inc$ 已知且周期为 $2$，我们可以将两天合并为一个线性变换矩阵 $M_2$，然后使用**矩阵快速幂**加速计算。

## 解题思路

### 总体框架

1. **特殊情况处理**：若 $D = 0$，直接输出初始状态。

2. **模拟到稳定期**：
   * 由于 $N \le 30$，且 $t[i]$ 最大不超过 $N-1$，我们可以模拟前 $\min(D, N \times 10)$ 天（实际 $N \times 2$ 就足够，取 $N \times 10$ 保险）。
   * 在模拟过程中，如果提前到达第 $D$ 天，直接输出结果。

3. **构造两步转移矩阵**：
   * 设当前 $inc$ 为已知向量（经过模拟后，所有点均已激活，$inc$ 已进入周期模式）。
   * 定义 $P_0$ 为“今天增长”的点的模式（即 $inc = 0$ 的点今天会增长，$inc = 1$ 的点今天不变）。
   * 定义 $P_1$ 为“明天增长”的点的模式（即 $inc$ 取反后的模式）。
   * 分别构造 $T_0$（对应 $P_0$）和 $T_1$（对应 $P_1$）：
     * $T_0[i][i] = 1$，且若 $P_0[i] = 0$（即今天要增长），则对每个邻居 $j$，$T_0[i][j] \mathrel{+}= 1$。
     * $T_1$ 同理，但使用 $P_1$。
   * 两天合并矩阵 $M_2 = T_1 \times T_0$（注意矩阵乘法顺序：先应用 $T_0$，再应用 $T_1$）。

4. **快速幂处理剩余天数**：
   * 剩余天数 $rem = D - sim$，其中 $sim$ 是已模拟的天数。
   * 计算 $pairs = \lfloor rem / 2 \rfloor$，用矩阵快速幂计算 $M_2^{pairs}$，乘以当前 $h$ 向量。
   * 若 $rem$ 为奇数，再单独应用一次 $T_0$（因为经过偶数步后 $inc$ 状态回到当前状态）。

### 复杂度分析

*   模拟部分：$O(N^3)$ 或 $O(N^2 \cdot \text{sim})$，其中 $sim \le 300$，可忽略。
*   矩阵快速幂：矩阵大小为 $N \times N$，快速幂 $O(\log D)$ 次矩阵乘法，每次 $O(N^3)$。
*   总复杂度 $O(N^3 \log D)$，$N \le 30$，$D \le 10^8$，完全可行。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MOD = 1e9 + 7;

// 矩阵乘法 (方阵)
vector<vector<int>> matMul(const vector<vector<int>>& A, const vector<vector<int>>& B) {
    int n = A.size();
    vector<vector<int>> C(n, vector<int>(n, 0));
    for (int i = 0; i < n; ++i)
        for (int k = 0; k < n; ++k) if (A[i][k])
            for (int j = 0; j < n; ++j)
                C[i][j] = (C[i][j] + (ll)A[i][k] * B[k][j]) % MOD;
    return C;
}

// 矩阵向量乘法
vector<int> matVecMul(const vector<vector<int>>& M, const vector<int>& v) {
    int n = M.size();
    vector<int> res(n, 0);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            res[i] = (res[i] + (ll)M[i][j] * v[j]) % MOD;
    return res;
}

// 矩阵快速幂
vector<vector<int>> matPow(vector<vector<int>> M, int e) {
    int n = M.size();
    vector<vector<int>> R(n, vector<int>(n, 0));
    for (int i = 0; i < n; ++i) R[i][i] = 1;
    while (e) {
        if (e & 1) R = matMul(R, M);
        M = matMul(M, M);
        e >>= 1;
    }
    return R;
}

int main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    int T; cin >> T;
    for (int cs = 1; cs <= T; ++cs) {
        int N, M, K, D; cin >> N >> M >> K >> D;
        // 邻接矩阵
        vector<vector<int>> A(N, vector<int>(N, 0));
        for (int i = 0, u, v; i < M; ++i) {
            cin >> u >> v;
            A[u][v] = A[v][u] = 1;
        }
        
        // 初始状态
        vector<int> h(N, 0), inc(N, 0);
        h[K] = inc[K] = 1;
        
        // D = 0 直接输出
        if (D == 0) {
            cout << "Case " << cs << ":";
            for (int x : h) cout << ' ' << x;
            cout << '\n'; continue;
        }
        
        // 第一阶段：模拟到稳定期 (最多 N*10 天)
        int sim = min(D, N * 10);
        bool done = false;
        for (int day = 1; day <= sim; ++day) {
            vector<int> hn = h;
            // 根据 inc 计算下一天的快乐度
            for (int i = 0; i < N; ++i) if (!inc[i]) {
                ll s = 0;
                for (int j = 0; j < N; ++j) if (A[i][j]) s += h[j];
                hn[i] = (h[i] + s) % MOD;
            }
            // 计算下一天的 inc
            vector<int> incn(N, 0);
            for (int i = 0; i < N; ++i) if (hn[i] != h[i]) incn[i] = 1;
            h = hn, inc = incn;
            if (day == D) {
                cout << "Case " << cs << ":";
                for (int x : h) cout << ' ' << x;
                cout << '\n';
                done = true;
                break;
            }
        }
        if (done) continue;
        
        // 第二阶段：构造两天合并矩阵
        auto build = [&](const vector<int>& pat) {
            vector<vector<int>> T(N, vector<int>(N, 0));
            for (int i = 0; i < N; ++i) {
                T[i][i] = 1;                     // 自身保留
                if (!pat[i]) {                   // 该点今天要增长
                    for (int j = 0; j < N; ++j) if (A[i][j])
                        T[i][j] = (T[i][j] + 1) % MOD;
                }
            }
            return T;
        };
        // nxt 是 inc 取反 (明天的模式)
        vector<int> nxt(N);
        for (int i = 0; i < N; ++i) nxt[i] = 1 - inc[i];
        auto M2 = matMul(build(nxt), build(inc));  // 两天合并矩阵
        
        int rem = D - sim, pairs = rem / 2;
        h = matVecMul(matPow(M2, pairs), h);       // 应用 pairs 个两天
        if (rem & 1) {                             // 剩余奇数天，再走一步
            vector<int> hn = h;
            for (int i = 0; i < N; ++i) if (!inc[i]) {
                ll s = 0;
                for (int j = 0; j < N; ++j) if (A[i][j]) s += h[j];
                hn[i] = (h[i] + s) % MOD;
            }
            h = hn;
        }
        
        cout << "Case " << cs << ":";
        for (int x : h) cout << ' ' << x;
        cout << '\n';
    }
    return 0;
}
```

## 注意事项

1. **模运算**：所有加法、乘法均在模 $10^9+7$ 下进行，使用 `long long` 防止中间结果溢出。

2. **稳定期的判断**：代码中采用固定模拟 $N \times 10$ 天来确保进入稳定期。实际上，由于 $N \le 30$，大部分情况下 $2N$ 天就足够，$10N$ 作为上界是安全的。

3. **矩阵构造的顺序**：两天合并矩阵 $M_2 = T_1 \times T_0$，其中 $T_0$ 对应当前 $inc$ 模式，$T_1$ 对应取反后的模式。矩阵乘法的顺序很重要，因为先应用 $T_0$ 再应用 $T_1$。

4. **边界情况**：当 $D$ 很小时（$D \le \text{sim}$），直接模拟输出，避免矩阵运算带来的额外开销。

## 总结

本题的核心在于发现快乐度增长由 $inc$ 标志控制，而 $inc$ 在激活期后会进入周期为 $2$ 的稳定模式。利用这一性质，将两天内的更新合并为一个线性变换，然后用矩阵快速幂处理剩余的大量天数，从而在 $O(N^3 \log D)$ 时间内解决问题。这种“先模拟到稳定态，再矩阵快速幂”的思路在图论与线性递推结合的问题中非常常见。
