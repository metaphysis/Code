[UVa 11688 Rotate to Root](https://blog.csdn.net/metaphysis/article/details/161972828)

## 题目描述

给定一棵有 $N$ 个节点的二叉树，节点编号为 $1$ 到 $N$。对于每个节点 $X$，需要求出：将节点 $X$ 通过反复执行旋转操作移动到根之后，整棵树的高度。

旋转规则：
- 若 $X$ 是其父节点 $P$ 的左子，则执行**右旋**：$X$ 上升为 $P$ 的父节点，$P$ 成为 $X$ 的右子，$X$ 的原右子树成为 $P$ 的左子树。
- 若 $X$ 是其父节点 $P$ 的右子，则执行**左旋**：$X$ 上升为 $P$ 的父节点，$P$ 成为 $X$ 的左子，$X$ 的原左子树成为 $P$ 的右子树。

树的高度定义为从根到最远叶子的路径长度（空树高度为 $0$）。

## 输入格式

每个测试用例第一行一个整数 $N$（$1 \le N \le 10^5$）。  
接下来 $N$ 行，第 $i$ 行两个整数 $l_i$ 和 $r_i$，分别表示节点 $i$ 的左孩子和右孩子编号。若为 $0$ 表示空。  
输入保证是一棵合法的二叉树。  
最后一行输入 $0$ 表示输入结束。

## 输出格式

对于每个测试用例，输出 $N$ 行，第 $i$ 行为节点 $i$ 旋转到根后树的高度。

## 样例

输入

```
4
2 3
4 0
0 0
0 0
0
```

输出

```
3
3
4
3
```

## 题目分析

本题要求对每个节点独立回答：如果将该节点反复旋转直至成为根，最终整棵树的高度是多少。

直接模拟每个节点的旋转过程复杂度为 $O(N^2)$，在 $N \le 10^5$ 时不可接受。必须寻找一种方法，能够在 $O(N)$ 或 $O(N \log N)$ 时间内计算出所有节点的答案。

观察旋转操作的性质：
- 一次旋转只改变被旋转节点 $X$ 及其父节点 $P$ 的父子关系，以及它们的子树归属。
- $X$ 的原始子树（以 $X$ 为根的子树）在旋转过程中结构不变，但它的深度会随着 $X$ 上升而减小。
- 不在 $X$ 原始子树中的其他部分（即“外部”）会被逐渐“拉近”到 $X$ 的旁边，其相对于 $X$ 的深度会增加。

关键规律（以右旋为例）：
- $X$ 的高度 $-$ $1$
- $X$ 的左子树全体 $-$ $1$
- 父节点 $P$ 的高度 $+$ $1$
- $P$ 的右子树全体 $+$ $1$
- $X$ 的原右子树高度不变

这表明：**每向上旋转一步，与 $X$ 同级的兄弟子树的高度会增加 $1$**。

因此，当 $X$ 最终成为根时，整棵树的高度可以表示为：

$$
answer[X] = 1 + \max(\text{左子树高度}, \text{右子树高度})
$$

其中左右子树分别来自：
- $X$ 的原始左、右子树（高度不变）
- 从 $X$ 向上路径上所有“兄弟”子树，它们的高度需要加上从 $X$ 到它们祖先的旋转次数

## 解题思路

### 状态设计

设：
- $\textit{h}[u]$：原始树中，以 $u$ 为根的子树的高度。
- $\textit{answer}[u]$：将 $u$ 旋转到根后整棵树的高度。

定义一次深度优先搜索 $\texttt{dfs2}(u, hl, hr, dl, dr)$，其中：
- $hl$：当前节点 $u$ 所有将来会成为其**左子树**的外部部分当前能提供的最大深度。
- $hr$：当前节点 $u$ 所有将来会成为其**右子树**的外部部分当前能提供的最大深度。
- $dl$：从根到 $u$ 的路径上，$u$ 作为**左链**的长度（即它是左子、左子的左子 … 的次数）。
- $dr$：从根到 $u$ 的路径上，$u$ 作为**右链**的长度。

### 转移公式

对于节点 $u$，其原始左子树高度为 $\textit{h}[\textit{lch}[u]]$，原始右子树高度为 $\textit{h}[\textit{rch}[u]]$。  
由于 $u$ 旋转到根的过程中，它自身会成为根，它的左右子树分别来自：
- 原始左子树，抬升 $dl$ 次 → 新高度为 $\textit{h}[\textit{lch}[u]] + dl$
- 原始右子树，抬升 $dr$ 次 → 新高度为 $\textit{h}[\textit{rch}[u]] + dr$
- 从上方传来的左外部最大深度 $hl$
- 从上方传来的右外部最大深度 $hr$

因此：

$$
\textit{answer}[u] = 1 + \max\big( hl,\ hr,\ \textit{h}[\textit{lch}[u]] + dl,\ \textit{h}[\textit{rch}[u]] + dr \big)
$$

### 向下传递

当从 $u$ 走向左孩子 $\textit{lch}[u]$ 时：
- $hl$ 保持不变，因为左孩子的左外部仍然是原来的左外部。
- $hr$ 需要更新：左孩子的右外部包括原来的右外部 $hr$，以及 $u$ 的右兄弟子树（高度 $\textit{h}[\textit{rch}[u]]$）经过 $dr$ 次抬升后再加一层 $u$ 本身，即 $dr + \textit{h}[\textit{rch}[u]] + 1$。取最大值。
- $dl$ 不变，$dr$ 增加 $1$（因为 $u$ 是父节点的左子，对左孩子来说多了一次右转）。

对称地，走向右孩子时：
- $hr$ 不变，$hl$ 更新为 $\max(hl,\ dl + \textit{h}[\textit{lch}[u]] + 1)$
- $dl$ 增加 $1$，$dr$ 不变

### 根的处理

根节点没有父节点，其 $hl = hr = 0$，$dl = dr = 0$。此时公式退化为：

$$
\textit{answer}[\textit{root}] = 1 + \max(\textit{h}[\textit{lch}[\textit{root}]],\ \textit{h}[\textit{rch}[\textit{root}]])
$$

即原始树的高度，符合预期。

### 算法步骤

1. 读入每个节点的左右孩子，同时记录是否有父节点（用于找根）。
2. 从根开始执行第一次 $\texttt{DFS}$，计算每个节点的原始高度 $\textit{h}[u]$。
3. 从根开始执行第二次 $\texttt{DFS}$，按照上述转移公式和传递规则，计算每个节点的 $\textit{answer}[u]$。
4. 输出所有 $\textit{answer}[i]$。

### 复杂度分析

- 时间：每个节点访问常数次，$O(N)$。
- 空间：$O(N)$。

## 代码实现

```cpp
// Rotate to Root

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e5 + 100;
int lch[MAXN], rch[MAXN], isChild[MAXN];
int h[MAXN], answer[MAXN];

int dfs1(int u) {
    if (u == 0) return h[u] = 0;
    h[u] = max(dfs1(lch[u]), dfs1(rch[u])) + 1;
    return h[u];
}

void dfs2(int u, int hl, int hr, int dl, int dr) {
    if (u == 0) return;
    int dL = h[lch[u]], dR = h[rch[u]];
    answer[u] = 1 + max(max(hl, hr), max(dL + dl, dR + dr));
    dfs2(lch[u], hl, max(hr, dr + dR + 1), dl, dr + 1);
    dfs2(rch[u], max(hl, dl + dL + 1), hr, dl + 1, dr);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n;
    while (cin >> n, n) {
        memset(lch, 0, sizeof lch);
        memset(rch, 0, sizeof rch);
        memset(isChild, 0, sizeof isChild);
        for (int i = 1; i <= n; ++i) {
            int l, r;
            cin >> l >> r;
            lch[i] = l;
            rch[i] = r;
            isChild[l] = isChild[r] = 1;
        }
        int root = 1;
        while (root <= n && isChild[root]) root++;
        dfs1(root);
        dfs2(root, 0, 0, 0, 0);
        for (int i = 1; i <= n; ++i) cout << answer[i] << '\n';
    }
    return 0;
}
```

## 总结

本题的核心难点在于：旋转操作改变了树的结构，但只影响路径上的节点及其兄弟子树。通过引入两个累积变量 $dl$ 和 $dr$ 记录旋转次数，并传递 $hl$ 和 $hr$ 表示外部部分的最大深度，可以在一次深度优先遍历中计算出所有节点的答案。

**关键技巧**：
- 将动态的旋转过程转化为静态的深度累加。
- 使用四个参数分别维护来自不同方向的外部信息和路径累积次数。
- 利用兄弟子树高度加旋转次数来模拟旋转后的新高度。

这种方法体现了树形动态规划中“从根向下传递信息”的经典思想，值得深入掌握。
