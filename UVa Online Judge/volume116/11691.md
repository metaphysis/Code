[UVa 11691 Allergy Test](https://blog.csdn.net/metaphysis/article/details/155159106)

## 题目描述

你正在进行一项过敏测试，测试会在若干天内进行，每天早晨最多应用一种过敏原，每天晚上检查是否有过敏反应。每个过敏原有一个存活期 $D$（整数天），表示如果你对该过敏原过敏，从应用当天开始会连续 $D$ 天晚上出现过敏反应。

测试方案必须是非自适应的，即方案必须提前固定，不能根据之前的反应结果调整。目标是在保证能够唯一确定对哪些过敏原过敏的前提下，找出最短的测试天数。

**输入格式**  
- 第一行：测试用例数 $N$（$N < 30$）
- 每个测试用例：
  - 第一行：过敏原数量 $k$（$1 \leq k \leq 20$）
  - 接下来 $k$ 行：每个过敏原的存活期 $D$（$1 \leq D \leq 7$）

**输出格式**  
- 对每个测试用例，输出最短的测试天数

---

## 解题思路分析

### 问题本质

我们需要安排 $k$ 个过敏原的应用时间，每个过敏原对应一个长度为 $D$ 的区间（从应用日开始连续 $D$ 天晚上会产生反应）。要求任意两个过敏原的活跃区间不完全相同（即不能有相同的起止日期），这样才能根据反应模式唯一确定过敏原。目标是在满足该条件下，最小化总测试天数。

---

## 方法一：动态规划（$\texttt{DP}$）

### 思路分析

我们使用状态压缩动态规划来解决这个问题。

#### 状态定义

设 $dp[mask][free]$ 表示：
- $mask$：已经安排的过敏原集合（二进制位表示）
- $free$：最后一个过敏原结束后剩余的"自由空间"天数（即最后一个过敏原独有的向右延伸天数）

$dp[mask][free]$ 的值表示在这种状态下所需的最少总天数。

#### 状态转移

从状态 $dp[mask][free]$ 出发，尝试加入一个新的过敏原 $i$（不在 $mask$ 中）：
- 枚举重叠天数 $overlap$（$0 \leq overlap \leq \min(free, D[i]-1)$）
- 新过敏原必须至少有一天是独有的，所以 $newFree = D[i] - overlap - 1 \geq 0$
- 新增天数 = $D[i] - overlap$（重叠部分不增加总长度）
- 新状态：$dp[mask | (1 \ll i)][newFree]$

#### 初始化

- $dp[0][0] = 0$
- 对于每个过敏原 $i$，$dp[1 \ll i][D[i]-1] = D[i]$

#### 复杂度分析

- 状态数：$O(2^k \times 7)$（因为 $free \leq 7$）
- 转移：$O(k \times 7)$
- 总复杂度：$O(2^k \times k \times 7)$，在 $k \leq 20$ 时可行

---

## 方法二：贪心算法

### 思路分析

基于动态规划的思路，我们可以发现一个贪心性质：**通过合理分配第一个过敏原的左右空间，并让后续过敏原尽可能与前面重叠，可以找到最优解**。

#### 算法步骤

1. **排序**：将过敏原按存活期从大到小排序
2. **枚举第一个过敏原的分配**：对于第一个过敏原（存活期最大的），枚举其左右分配方案
   - $leftLen$：向左的独有天数
   - $rightLen = D[0] - leftLen - 1$：向右的独有天数
3. **依次安排后续过敏原**：
   - 对于每个新过敏原，计算能向左/向右重叠的最大天数
   - 选择能重叠更多的一侧，减少新增天数
   - 更新剩余的左右空间
4. **取最小值**：所有枚举方案中的最小总天数即为答案

#### 正确性分析

由于存活期 $D \leq 7$，第一个过敏原的分配方案有限，枚举是可行的。后续的贪心选择基于"最大化重叠"的原则，这保证了局部最优性。

#### 复杂度分析

- 枚举第一个过敏原：$O(D_{\max})$
- 安排后续过敏原：$O(k)$
- 总复杂度：$O(k \times D_{\max})$，非常高效

---

## 两种方法对比

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 动态规划 | 保证找到最优解，思路清晰 | 状态数较多，实现稍复杂 | 通用性强，适合各种情况 |
| 贪心算法 | 实现简洁，运行高效 | 需要问题具有贪心性质 | 存活期较小的情况 |

## 完整代码

### 动态规划解法

```cpp
// Allergy Test
// UVa ID: 11691
// Verdict: Accepted
// Submission Date: 2025-11-23
// UVa Run Time: 1.540s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

int main() {
    int numCases;
    cin >> numCases;
    while (numCases--) {
        int k;
        cin >> k;
        vector<int> d(k);
        for (int i = 0; i < k; i++) cin >> d[i];
        
        int totalStates = 1 << k;
        vector<vector<int>> dp(totalStates, vector<int>(8, INF));
        
        for (int i = 0; i < k; i++) 
            dp[1 << i][d[i] - 1] = d[i];
        
        for (int mask = 0; mask < totalStates; mask++) {
            for (int free = 0; free < 8; free++) {
                if (dp[mask][free] == INF) continue;
                for (int i = 0; i < k; i++) {
                    if (mask >> i & 1) continue;
                    for (int overlap = 0; overlap <= min(free, d[i] - 1); overlap++) {
                        int newFree = d[i] - overlap - 1;
                        if (newFree < 0) continue;
                        int addedDays = d[i] - overlap;
                        int newMask = mask | (1 << i);
                        dp[newMask][newFree] = min(dp[newMask][newFree], dp[mask][free] + addedDays);
                    }
                }
            }
        }
        
        int ans = INF;
        for (int free = 0; free < 8; free++) 
            ans = min(ans, dp[totalStates - 1][free]);
        cout << ans << endl;
    }
    return 0;
}
```

### 贪心解法

```cpp
// Allergy Test
// UVa ID: 11691
// Verdict: Accepted
// Submission Date: 2025-11-23
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int numCases;
    cin >> numCases;
    while (numCases--) {
        int k;
        cin >> k;
        vector<int> d(k);
        for (int i = 0; i < k; i++) cin >> d[i];
        
        sort(d.begin(), d.end(), greater<int>());
        
        int ans = INT_MAX;
        for (int leftLen = 0; leftLen < d[0]; leftLen++) {
            int rightLen = d[0] - leftLen - 1;
            int totalDays = d[0];
            int leftSpace = leftLen;
            int rightSpace = rightLen;
            
            for (int i = 1; i < k; i++) {
                int useLeft = min(leftSpace, d[i] - 1);
                int useRight = min(rightSpace, d[i] - 1);
                
                if (useLeft > useRight) {
                    leftSpace = d[i] - useLeft - 1;
                    totalDays += leftSpace + 1;
                } else {
                    rightSpace = d[i] - useRight - 1;
                    totalDays += rightSpace + 1;
                }
            }
            ans = min(ans, totalDays);
        }
        
        cout << ans << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于理解"非自适应测试"的要求，即必须保证任何过敏组合产生的反应模式都是唯一的。通过将问题转化为区间安排问题，我们可以用动态规划或贪心算法高效求解。两种方法各有优势，在实际应用中可以根据具体情况选择。
