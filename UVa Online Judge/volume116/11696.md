## 题目描述

在古老的战争中，通信速度极为缓慢。当王国面临敌人威胁时，集结所有武装力量需要数月时间。然而，通过在战略位置设置点燃的烽火台，仍然可以快速传递紧急信号。

当第一个烽火台被点燃时，所有它能直接看到的烽火台也会被点燃。这些烽火台能看到的其他烽火台同样会被点燃，依此类推，直到所有烽火台都被点燃 —— 当然，这要求所有烽火台之间直接或间接地都能互相看到。如果它们不能互相全部看到，那么某些烽火台之间必须由骑手骑马传递消息。

给定王国中所有烽火台的位置以及所有山峰的位置和大小，编写一个程序，确定当敌人威胁国家时，需要由骑手传递多少条消息，才能让所有烽火台都被点燃。

为简单起见，我们按以下方式建模：烽火台表示为 $xy$ 平面上的点，山峰表示为圆。两个烽火台被认为能够互相看到，当且仅当连接它们的直线不被任何山峰阻挡。

输入保证：任意两个烽火台之间的直线不会与山峰的圆周相切，除非它穿过另一个山峰的内部。山峰不会重叠或相切，任何烽火台也不会位于山峰上或其圆周上。

## 输入格式

第一行包含一个整数 $N$（$N < 25$），表示测试用例的数量。

每个测试用例的第一行包含两个整数 $n$（$1 \leq n \leq 1000$）和 $m$（$0 \leq m \leq 1000$），分别表示烽火台的数量和山峰的数量。

接下来 $n$ 行指定烽火台的位置，每行两个整数 $x$ 和 $y$（$0 \leq x, y \leq 10000$）。

然后 $m$ 行描述山峰，每行三个整数 $x$、$y$ 和 $r$（$0 \leq x, y \leq 10000$，$1 \leq r \leq 5000$），分别表示圆心的坐标和半径。

## 输出格式

对于每个测试用例，输出一行一个整数：为了点燃所有烽火台，必须由骑手传递的消息数量。

## 题目分析

本题的核心问题是：给定平面上的 $n$ 个点（烽火台）和 $m$ 个圆（山峰），如果两个点之间的线段不与任何圆相交（即没有山峰阻挡视线），则这两个点之间有一条边。点燃一个烽火台后，火焰会沿着可见关系传播到所有能直接或间接看到的烽火台。属于同一个连通分量的烽火台可以被一次点燃事件全部点燃，而不同连通分量之间则需要通过骑手传递消息。因此，需要的消息数量等于**连通分量数减 $1$**。

这实际上是一个**图论建模**问题：
- 将每个烽火台视为图中的一个节点。
- 如果两个烽火台之间的视线不被任何山峰阻挡，则在它们之间建立一条无向边。
- 计算出图中有多少个连通分量，答案即为：连通分量数$- 1$。

问题的难点在于：如何高效地判断两个烽火台之间的视线是否被某个圆阻挡。

## 解题思路

### 视线阻挡判断

给定两个点 $A$ 和 $B$，以及一个圆 $C$（圆心 $O$，半径 $r$），线段 $AB$ 与圆相交（即被阻挡）的条件是：**圆心到线段 $AB$ 的最短距离小于半径 $r$**。

计算点到线段的最短距离：
- 设向量 $\overrightarrow{AB} = (B_x - A_x, B_y - A_y)$。
- 计算参数 $t = \frac{(O_x - A_x)(B_x - A_x) + (O_y - A_y)(B_y - A_y)}{|\overrightarrow{AB}|^2}$。
- 如果 $t < 0$，则最近点为 $A$，距离为 $|OA|$。
- 如果 $t > 1$，则最近点为 $B$，距离为 $|OB|$。
- 否则，最近点为 $A + t \cdot \overrightarrow{AB}$，距离为该点到 $O$ 的距离。

由于题目保证不会出现相切情况，只需判断距离是否小于 $r$（严格小于），即可判定线段被该圆阻挡。

### 图的构建

对于每一对烽火台 $(i, j)$，需要检查所有 $m$ 个圆。只要存在任意一个圆阻挡了 $i$ 和 $j$ 之间的视线，则 $i$ 和 $j$ 之间没有边；只有当所有圆都不阻挡时，才在它们之间建立一条边。

### 连通分量计数

使用 $\texttt{BFS}$ 或 $\texttt{DFS}$ 或并查集统计连通分量个数。由于 $n \leq 1000$，$m \leq 1000$，最坏情况下需要检查 $O(n^2 \cdot m) = 10^9$ 次距离计算，可能稍慢，但考虑到 $N < 25$ 且实际数据不一定达到上界，该复杂度在时限内通常可接受。

### 复杂度分析

- 判断一对烽火台是否可见：$O(m)$。
- 共有 $O(n^2)$ 对烽火台，总时间复杂度 $O(n^2 \cdot m)$。
- 空间复杂度 $O(n^2)$ 用于存储邻接表或邻接矩阵。

```cpp
// Beacons

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
    Point() {}
    Point(int _x, int _y) : x(_x), y(_y) {}
};

struct Circle {
    int x, y, r;
    Circle() {}
    Circle(int _x, int _y, int _r) : x(_x), y(_y), r(_r) {}
};

double dist2(const Point& a, const Point& b) {
    int dx = a.x - b.x, dy = a.y - b.y;
    return dx * dx + dy * dy;
}

// 点到线段的最短距离平方
double pointToSegmentDist2(const Point& p, const Point& a, const Point& b) {
    double ax = b.x - a.x, ay = b.y - a.y;
    double t = ((p.x - a.x) * ax + (p.y - a.y) * ay) / (ax * ax + ay * ay);
    if (t < 0) return dist2(p, a);
    if (t > 1) return dist2(p, b);
    double projX = a.x + t * ax, projY = a.y + t * ay;
    double dx = p.x - projX, dy = p.y - projY;
    return dx * dx + dy * dy;
}

// 判断线段AB是否被圆C阻挡
bool blockedByCircle(const Point& a, const Point& b, const Circle& c) {
    double d2 = pointToSegmentDist2(Point(c.x, c.y), a, b);
    return d2 < 1.0 * c.r * c.r - 1e-8;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    while (N--) {
        int n, m;
        cin >> n >> m;
        vector<Point> beacons(n);
        for (int i = 0; i < n; ++i)
            cin >> beacons[i].x >> beacons[i].y;

        vector<Circle> peaks(m);
        for (int i = 0; i < m; ++i)
            cin >> peaks[i].x >> peaks[i].y >> peaks[i].r;

        // 构建邻接表
        vector<vector<int>> adj(n);
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                bool visible = true;
                for (int k = 0; k < m; ++k) {
                    if (blockedByCircle(beacons[i], beacons[j], peaks[k])) {
                        visible = false;
                        break;
                    }
                }
                if (visible) {
                    adj[i].push_back(j);
                    adj[j].push_back(i);
                }
            }
        }

        // BFS 求连通分量数
        vector<bool> visited(n, false);
        int components = 0;
        for (int i = 0; i < n; ++i) {
            if (!visited[i]) {
                components++;
                queue<int> q;
                q.push(i);
                visited[i] = true;
                while (!q.empty()) {
                    int u = q.front(); q.pop();
                    for (int v : adj[u]) {
                        if (!visited[v]) {
                            visited[v] = true;
                            q.push(v);
                        }
                    }
                }
            }
        }

        cout << components - 1 << '\n';
    }
    return 0;
}
```

## 优化实现

```cpp
// Beacons
// UVa ID: 11696
// Verdict: Accepted
// Submission Date: 2026-06-04
// UVa Run Time: 3.720s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
    Point() {}
    Point(int _x, int _y) : x(_x), y(_y) {}
};

struct Circle {
    int x, y, r;
    Circle() {}
    Circle(int _x, int _y, int _r) : x(_x), y(_y), r(_r) {}
};

// 返回两点距离平方
inline long long dist2(const Point& a, const Point& b) {
    long long dx = a.x - b.x, dy = a.y - b.y;
    return dx * dx + dy * dy;
}

// 判断线段AB是否被圆C阻挡（纯整数版本）
inline bool blockedByCircle(const Point& a, const Point& b, const Circle& c) {
    long long ax = b.x - a.x, ay = b.y - a.y;
    long long cx = c.x - a.x, cy = c.y - a.y;
    long long dot = cx * ax + cy * ay;
    long long len2 = ax * ax + ay * ay;
    
    // 投影点参数 t = dot / len2
    long long dist2ToLine;
    if (dot <= 0) {
        // 投影在 A 左侧
        dist2ToLine = cx * cx + cy * cy;
    } else if (dot >= len2) {
        // 投影在 B 右侧
        long long dx = c.x - b.x, dy = c.y - b.y;
        dist2ToLine = dx * dx + dy * dy;
    } else {
        // 投影在线段上，计算垂直距离平方
        // 使用叉积：|AB × AC|^2 / |AB|^2
        long long cross = cx * ay - cy * ax;
        dist2ToLine = (cross * cross) / (long double)len2; // 需要浮点除法保持精度
        // 为避免浮点，可以用整数比较：cross^2 < r^2 * len2
        // 但这里直接使用整数比较更精确
        return cross * cross < 1LL * c.r * c.r * len2;
    }
    return dist2ToLine < 1LL * c.r * c.r;
}

// 使用整数比较的版本（推荐，完全避免浮点）
inline bool blockedByCircleInt(const Point& a, const Point& b, const Circle& c) {
    long long ax = b.x - a.x, ay = b.y - a.y;
    long long cx = c.x - a.x, cy = c.y - a.y;
    long long dot = cx * ax + cy * ay;
    long long len2 = ax * ax + ay * ay;
    long long r2 = 1LL * c.r * c.r;
    
    if (dot <= 0) {
        // 投影在 A 左侧
        return (cx * cx + cy * cy) < r2;
    }
    if (dot >= len2) {
        // 投影在 B 右侧
        long long dx = c.x - b.x, dy = c.y - b.y;
        return (dx * dx + dy * dy) < r2;
    }
    // 投影在线段上，用叉积比较：|AB × AC|^2 < r^2 * |AB|^2
    long long cross = cx * ay - cy * ax;
    return cross * cross < r2 * len2;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int N;
    cin >> N;
    while (N--) {
        int n, m;
        cin >> n >> m;
        vector<Point> beacons(n);
        for (int i = 0; i < n; ++i)
            cin >> beacons[i].x >> beacons[i].y;
        
        vector<Circle> peaks(m);
        for (int i = 0; i < m; ++i)
            cin >> peaks[i].x >> peaks[i].y >> peaks[i].r;
        
        // 预计算每个山峰的半径平方
        vector<long long> r2(m);
        for (int i = 0; i < m; ++i)
            r2[i] = 1LL * peaks[i].r * peaks[i].r;
        
        // 构建邻接表
        vector<vector<int>> adj(n);
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                // 快速包围盒筛选：计算线段的外接矩形
                int minX = min(beacons[i].x, beacons[j].x);
                int maxX = max(beacons[i].x, beacons[j].x);
                int minY = min(beacons[i].y, beacons[j].y);
                int maxY = max(beacons[i].y, beacons[j].y);
                
                bool visible = true;
                for (int k = 0; k < m; ++k) {
                    // 包围盒预筛选：山峰圆心必须在线段矩形向外扩展半径的区域内
                    if (peaks[k].x + peaks[k].r < minX || peaks[k].x - peaks[k].r > maxX ||
                        peaks[k].y + peaks[k].r < minY || peaks[k].y - peaks[k].r > maxY) {
                        continue;  // 不可能阻挡，跳过
                    }
                    if (blockedByCircleInt(beacons[i], beacons[j], peaks[k])) {
                        visible = false;
                        break;
                    }
                }
                if (visible) {
                    adj[i].push_back(j);
                    adj[j].push_back(i);
                }
            }
        }
        
        // BFS 求连通分量数
        vector<bool> visited(n, false);
        int components = 0;
        for (int i = 0; i < n; ++i) {
            if (!visited[i]) {
                components++;
                queue<int> q;
                q.push(i);
                visited[i] = true;
                while (!q.empty()) {
                    int u = q.front(); q.pop();
                    for (int v : adj[u]) {
                        if (!visited[v]) {
                            visited[v] = true;
                            q.push(v);
                        }
                    }
                }
            }
        }
        
        cout << components - 1 << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于将实际问题转化为图论模型，并正确实现几何判断。

**关键点总结**：
1. **建模思想**：烽火台之间的可见性构成一张无向图，火焰传播等价于图的连通性，消息数量等于连通分量数减一。
2. **几何判断**：线段与圆相交的判定需要计算圆心到线段的最短距离，并注意浮点精度问题（使用 `1e-8` 避免边界情况）。
3. **复杂度权衡**：$O(n^2 \cdot m)$ 的算法在 $n=m=1000$ 时理论上较大，但实际数据通常稀疏，且可通过提前退出（一旦发现阻挡立即 `break`）优化。

**技巧提炼**：
- 在几何问题中，优先使用距离平方比较，避免开根号运算，提高精度和效率。
- 当输入保证没有相切情况时，可直接使用严格小于判断，无需处理等于的情况。
- 对于中等规模的数据，暴力枚举所有点对并逐个检查障碍物是可行的工程实践。
