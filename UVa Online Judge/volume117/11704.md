[UVa 11704 Caper Pizza](https://blog.csdn.net/metaphysis/article/details/156766043)

## 题目大意

给定一个圆心在原点的圆形披萨，上面散布着 $c$ 个酸豆（$\texttt{caper}$）和 $p$ 个胡椒粒（$\texttt{peppercorn}$），其中 $c$ 和 $p$ 均为偶数，且所有点均严格位于圆内，不会与原点共线或形成极小夹角。我们需要判断是否存在一条通过原点的直线，将披萨平分为两个面积相等的半圆，并且**每个半圆中恰好包含 $c/2$ 个酸豆和 $p/2$ 个胡椒粒**。

## 题目分析

这是一个**几何划分**问题，核心在于寻找一条通过原点的直线，使得两侧点的数量满足特定要求。由于披萨是圆形的，且切割线必须通过圆心，问题可以转化为在**极坐标系**下的角度选择问题。

### 关键观察

1. **直线由角度决定**：通过原点的直线可由其法线方向（或与 $x$ 轴正方向的夹角）$\theta$ 唯一确定。
2. **点的分类**：每个点对应一个极角 $\alpha = \operatorname{atan2}(y, x)$。当直线方向为 $\theta$ 时，点位于直线的哪一侧取决于 $\alpha$ 与 $\theta$ 的相对位置（更准确地说，取决于点是否在角度区间 $[\theta, \theta+\pi)$ 内）。
3. **数量约束**：由于 $c$ 和 $p$ 都是偶数，我们需要每个半圆中恰好有 $c/2$ 个酸豆和 $p/2$ 个胡椒粒。
4. **连续性**：当 $\theta$ 连续变化时，点的归属（在左侧半圆还是右侧半圆）只在其极角 $\alpha$ 与 $\theta$ 或 $\theta+\pi$ 重合时发生变化。由于题目保证没有点与原点共线，我们可以安全地考虑这些临界角度。

### 问题转化

问题等价于：是否存在一个角度 $\theta$，使得在角度区间 $[\theta, \theta+\pi)$ 内恰好有 $c/2$ 个酸豆和 $p/2$ 个胡椒粒。由于圆是 $2\pi$ 周期的，我们可以将角度映射到 $[0, 2\pi)$ 区间，并利用**滑动窗口**技巧在环形数组上检查所有可能的 $\theta$。

## 解题思路

### 步骤一：角度计算与预处理

1. 对于每个点 $(x_i, y_i)$，计算其极角：
$$
   \alpha_i = \operatorname{atan2}(y_i, x_i)
$$
   将结果调整到 $[0, 2\pi)$ 范围（若为负则加 $2\pi$）。
2. 为每个点标记类型：酸豆为 $0$，胡椒粒为 $1$。
3. 将所有点按极角从小到大排序。

### 步骤二：环形数组处理

由于角度是环形的，直接处理区间 $[\theta, \theta+\pi)$ 需要处理跨越 $2\pi$ 的情况。一个常用技巧是：
- 将排序后的点数组复制一份，并将每个副本的角度增加 $2\pi$，得到长度为 $2n$ 的扩展数组。
- 这样，对于任意起点 $i$（$0 \le i < n$），区间 $[i, i+n)$ 内的点对应角度范围 $[\alpha_i, \alpha_i + 2\pi)$。我们需要在其中找到一个长度为 $\pi$ 的子区间（即半圆），使其包含恰好 $c/2$ 个酸豆和 $p/2$ 个胡椒粒。

### 步骤三：滑动窗口检查

我们可以使用双指针（滑动窗口）来高效检查所有可能的半圆区间：
1. 设目标酸豆数 $targetC = c/2$，目标胡椒粒数 $targetP = p/2$。
2. 初始化指针 $right = 0$，并统计扩展数组前 $right$ 个点中，有多少落在区间 $[\alpha_0, \alpha_0 + \pi)$ 内（即极角小于 $\alpha_0 + \pi$），同时计数酸豆和胡椒粒。
3. 检查该初始窗口是否满足要求。
4. 然后，将窗口起点 $left$ 从 $1$ 逐步移动到 $n-1$：
   - 将点 $left-1$ 移出窗口（更新计数）。
   - 移动 $right$ 指针，直到窗口右边界再次达到 $\alpha_{left} + \pi$（即包含所有角度小于该值的点）。
   - 检查当前窗口内的酸豆数和胡椒粒数是否等于目标值。
5. 若在任意窗口找到满足条件的划分，则答案为 `YES`，否则为 `NO`。

### 算法复杂度

- 角度计算：$O(n)$。
- 排序：$O(n \log n)$。
- 滑动窗口：每个点最多被加入和移出窗口各一次，$O(n)$。
- 总复杂度：$O(n \log n)$，对于 $n \le 30000$ 的数据规模完全可行。

## 注意事项

1. 浮点数比较需小心，使用一个很小的 $\epsilon$（如 $10^{-12}$）来处理边界情况。
2. 题目保证没有点与原点共线，且任意两点与原点形成的夹角不会极小，这避免了在排序和滑动窗口时出现难以处理的退化情况。
3. 由于 $c$ 和 $p$ 都是偶数，目标值 $c/2$ 和 $p/2$ 一定是整数，无需处理分数情况。

## 代码实现

```cpp
// Caper Pizza
// UVa ID: 11704
// Verdict: Accepted
// Submission Date: 2026-01-09
// UVa Run Time: 0.150s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);
const double EPS = 1e-12;

struct Point {
    double angle;
    int type;  // 0 表示酸豆, 1 表示胡椒粒
    Point(double a = 0, int t = 0) : angle(a), type(t) {}
    bool operator < (const Point& other) const {
        return angle < other.angle;
    }
};

bool solve(int c, int p, vector<Point>& points) {
    int targetC = c / 2, targetP = p / 2;
    int n = c + p;
    vector<Point> sorted;
    for (const auto& pt : points) sorted.push_back(pt);
    sort(sorted.begin(), sorted.end());
    // 复制一份并偏移 2π，便于处理循环
    for (int i = 0; i < n; ++i) sorted.push_back(Point(sorted[i].angle + 2 * PI, sorted[i].type));
    int cntC = 0, cntP = 0;
    int right = 0;
    // 初始化窗口 [0, right) 内的计数
    while (right < n && sorted[right].angle < sorted[0].angle + PI + EPS) {
        if (sorted[right].type == 0) cntC++;
        else cntP++;
        right++;
    }
    // 检查初始窗口
    if (cntC == targetC && cntP == targetP) return true;
    // 滑动窗口
    for (int left = 1; left < n; ++left) {
        // 移出 left-1 点
        if (sorted[left - 1].type == 0) cntC--;
        else cntP--;
        // 移入 right 点
        while (right < left + n && sorted[right].angle < sorted[left].angle + PI + EPS) {
            if (sorted[right].type == 0) cntC++;
            else cntP++;
            right++;
        }
        if (cntC == targetC && cntP == targetP) return true;
    }
    return false;
}

int main() {
    int c, p;
    while (cin >> c >> p, c != -1 || p != -1) {
        vector<Point> points;
        double x, y;
        for (int i = 0; i < c; ++i) {
            cin >> x >> y;
            double angle = atan2(y, x);
            if (angle < 0) angle += 2 * PI;  // 转换到 [0, 2π)
            points.push_back(Point(angle, 0));
        }
        for (int i = 0; i < p; ++i) {
            cin >> x >> y;
            double angle = atan2(y, x);
            if (angle < 0) angle += 2 * PI;
            points.push_back(Point(angle, 1));
        }
        bool r = solve(c, p, points);
        cout << (r ? "YES" : "NO") << '\n';
    }
    return 0;
}
```

## 总结

本题通过将几何划分问题转化为极角排序与滑动窗口问题，巧妙地避免了复杂的几何计算。核心在于理解**通过原点的直线可由一个角度参数化**，以及**半圆对应的角度区间长度为 $\pi$**。利用环形数组扩展和双指针滑动窗口，我们可以在 $O(n \log n)$ 时间内高效解决该问题。这种将几何问题转化为序列问题的方法，在计算几何中十分常见，值得掌握。
