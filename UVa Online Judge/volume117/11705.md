## 题目描述

我们来到游乐场，看到一个名为“蚱蜢迷宫”的蹦床阵列。每个蹦床上标有一个非负整数 $z$，表示从该蹦床起跳后，必须在同一行或同一列上，恰好跳过 $z$ 个蹦床到达另一个蹦床（即距离为 $z$）。迷宫的出口位于西北角 $(0, 0)$ 位置，用星号 * 标记。

我们需要为每个蹦床标记出**最优的跳跃方向**，使得从该蹦床出发，按照标记的方向跳跃，能够以**最短的路径**到达出口。路径的比较规则如下：

1.  优先选择**跳跃次数最少**的路径；
2.  若次数相同，选择**第一步能够到达最北**（行号最小）的路径；
3.  若仍然相同，选择**第一步能够到达最西**（列号最小）的路径。

输出一个字符矩阵，每个位置可以是：

*   `N`, `S`, `E`, `W`：表示从该位置向该方向跳跃是最优的；
*   `X`：表示该位置无法到达出口；
*   `*`：表示出口位置本身。

## 输入格式

包含多个测试用例。每个用例第一行是两个整数 $R$ 和 $C$（$1 \leq R, C \leq 50$），表示矩阵的行数和列数。接下来 $R$ 行，每行 $C$ 个非负整数，表示每个蹦床上的数值。以 $0\ 0$ 结束输入。

## 输出格式

对于每个测试用例，输出一个 $R \times C$ 的字符矩阵，每个字符代表该位置的最优跳跃方向。每个用例后跟一个空行。

## 题目分析

这是一个典型的**最短路径**问题，但移动规则比较特殊：从位置 $(i, j)$ 出发，如果该位置的值为 $z$，则可以跳到：

*   同一行：$(i, j - z)$ 或 $(i, j + z)$
*   同一列：$(i - z, j)$ 或 $(i + z, j)$

前提是目标位置在矩阵范围内。

如果从每个位置正向 $\texttt{BFS}$ 到出口，时间复杂度较高。更优的做法是**从出口反向 $\texttt{BFS}$**。反向 $\texttt{BFS}$ 的好处是：当我们第一次访问到一个位置时，就找到了从该位置到出口的最短距离。

然而，反向搜索时，我们需要考虑的问题变为：哪些位置可以**跳到当前点**？假设当前点为 $(r, c)$，值为 $v$ 的点 $(nr, nc)$ 能跳到 $(r, c)$ 的条件是：

*   $nr = r$ 且 $|nc - c| = v$（同一行）
*   或者 $nc = c$ 且 $|nr - r| = v$（同一列）

也就是说，我们需要遍历同一行或同一列的所有点，检查它们是否能一步跳到当前点。

## 解题思路

### 第一步：反向 $\texttt{BFS}$ 求最短距离

我们从出口 $(0, 0)$ 开始进行 $\texttt{BFS}$，使用队列 $q$。对于队列中取出的每个点 $(r, c)$，我们检查所有可能跳到该点的位置：

1.  同一列上，对于每个行 $nr$（$0 \leq nr < R$，$nr \neq r$），如果 $grid[nr][c] = |nr - r|$，则说明 $(nr, c)$ 可以一步跳到 $(r, c)$。
2.  同一行上，对于每个列 $nc$（$0 \leq nc < C$，$nc \neq c$），如果 $grid[r][nc] = |nc - c|$，则说明 $(r, nc)$ 可以一步跳到 $(r, c)$。

将这些满足条件且尚未访问过的点加入队列，并记录它们到出口的距离（即当前点距离 $+1$）。

这样，$\texttt{BFS}$ 结束后，我们就得到了每个位置到出口的最短距离 $dist[i][j]$。如果某个位置的 $dist$ 仍为 $-1$，则表示它无法到达出口。

### 第二步：根据规则确定方向

对于每个可以到达出口的位置 $(i, j)$（除了出口本身），我们需要确定最优的跳跃方向。我们有四个候选方向，分别对应跳到：

*   北：$(i - z, j)$
*   南：$(i + z, j)$
*   西：$(i, j - z)$
*   东：$(i, j + z)$

其中 $z = grid[i][j]$。

由于我们已经知道每个位置的最短距离 $dist$，那么从 $(i, j)$ 出发，最优的下一步应该满足：

1.  目标位置可达（在矩阵范围内）；
2.  $dist[目标] = dist[i][j] - 1$（保证是最短路径上的下一步）；
3.  在满足上述条件的所有候选方向中，按照题目规则选择最优的：优先选择目标位置最北的（行号最小）；如果行号相同，选择最西的（列号最小）。

注意，这里比较的是**目标位置**的坐标，而不是方向本身。这符合题意：当路径长度相同时，比较的是**第一步到达的位置**。

### 第三步：处理无法到达的位置

对于 $dist[i][j] = -1$ 的位置，直接标记为 `X`。

### 第四步：输出

最后，按照格式输出字符矩阵即可。

## 复杂度分析

*   时间复杂度：$\texttt{BFS}$ 过程中，对于每个出队的点，我们需要遍历同一行和同一列的所有点，因此最坏情况下的时间复杂度为 $O(R \times C \times (R + C))$。在 $R, C \leq 50$ 的情况下，这是完全可以接受的（约 $50^3 = 125,000$ 次操作）。
*   空间复杂度：$O(R \times C)$，用于存储距离矩阵和方向矩阵。

## 注意事项

*   反向 $\texttt{BFS}$ 是本题的核心思想，可以避免为每个位置都进行一次正向搜索。
*   方向选择时，必须严格按照“最北、最西”的优先级进行比较，而不是简单地按照 $\texttt{N,W,S,E}$ 的顺序尝试。
*   输入可能包含多个测试用例，记得处理到 $0\ 0$ 结束。

```cpp
// Grasshopper
// UVa ID: 11705
// Verdict: Accepted

// UVa Run Time: 0.000s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int r, c;
    Point(int r, int c) : r(r), c(c) {}
};

int main() {
    int rows, cols;
    while (cin >> rows >> cols && (rows || cols)) {
        vector<vector<int>> grid(rows, vector<int>(cols));
        for (int i = 0; i < rows; i++)
            for (int j = 0; j < cols; j++)
                cin >> grid[i][j];
        
        // BFS 从出口开始反向搜索
        vector<vector<int>> dist(rows, vector<int>(cols, -1));
        vector<vector<char>> direction(rows, vector<char>(cols, 'X'));
        queue<Point> q;
        
        // 出口位置
        dist[0][0] = 0;
        direction[0][0] = '*';
        q.push(Point(0, 0));
        
        while (!q.empty()) {
            Point p = q.front(); q.pop();
            
            // 检查同一列上哪些点可以跳到 p
            for (int r = 0; r < rows; r++) {
                if (r == p.r) continue;
                if (abs(r - p.r) == grid[r][p.c] && dist[r][p.c] == -1) {
                    dist[r][p.c] = dist[p.r][p.c] + 1;
                    q.push(Point(r, p.c));
                }
            }
            
            // 检查同一行上哪些点可以跳到 p
            for (int c = 0; c < cols; c++) {
                if (c == p.c) continue;
                if (abs(c - p.c) == grid[p.r][c] && dist[p.r][c] == -1) {
                    dist[p.r][c] = dist[p.r][p.c] + 1;
                    q.push(Point(p.r, c));
                }
            }
        }
        
        // 确定每个位置的方向
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (i == 0 && j == 0) continue;
                if (dist[i][j] == -1) {
                    direction[i][j] = 'X';
                    continue;
                }
                
                int bestR = rows, bestC = cols;
                char bestDir = 'X';
                int val = grid[i][j];
                
                // 北方向：跳到 (i - val, j)
                if (i - val >= 0 && dist[i - val][j] == dist[i][j] - 1) {
                    if (i - val < bestR || (i - val == bestR && j < bestC)) {
                        bestR = i - val;
                        bestC = j;
                        bestDir = 'N';
                    }
                }
                
                // 西方向：跳到 (i, j - val)
                if (j - val >= 0 && dist[i][j - val] == dist[i][j] - 1) {
                    if (i < bestR || (i == bestR && j - val < bestC)) {
                        bestR = i;
                        bestC = j - val;
                        bestDir = 'W';
                    }
                }
                
                // 南方向：跳到 (i + val, j)
                if (i + val < rows && dist[i + val][j] == dist[i][j] - 1) {
                    if (i + val < bestR || (i + val == bestR && j < bestC)) {
                        bestR = i + val;
                        bestC = j;
                        bestDir = 'S';
                    }
                }
                
                // 东方向：跳到 (i, j + val)
                if (j + val < cols && dist[i][j + val] == dist[i][j] - 1) {
                    if (i < bestR || (i == bestR && j + val < bestC)) {
                        bestR = i;
                        bestC = j + val;
                        bestDir = 'E';
                    }
                }
                
                direction[i][j] = bestDir;
            }
        }
        
        // 输出结果
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++)
                cout << direction[i][j];
            cout << endl;
        }
        cout << endl;
    }
    return 0;
}
```
