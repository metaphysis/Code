[UVa 11725 Colorful Board](https://blog.csdn.net/metaphysis/article/details/157550183)

## 题目描述

给定一个棋盘，你需要在棋盘上画 $M$ 条水平线和 $N$ 条垂直线，从而将整个棋盘分成 $(M + 1) \times (N + 1)$ 个格子。棋盘共有 $M + 1$ 行，每行包含 $N + 1$ 个格子。

现在你需要为每个格子涂色，共有四种颜色：红、绿、蓝、橙。

为了使棋盘更美观，必须确保任意两个相邻的格子颜色不同。两个格子如果共享一条边，则视为相邻。

此外，题目还会给出一些**禁止格子**，这些格子不允许涂色，但其余所有非禁止格子都必须涂上一种颜色。

你需要计算有多少种不同的涂色方案。由于结果可能很大，输出结果对 $1000000007$ 取模。

### 输入格式

- 第一行包含一个整数 $T$（$T \leq 50$），表示测试用例的数量。
- 每个测试用例：
  - 第一行包含两个整数 $M$ 和 $N$（$0 \leq M, N \leq 6$），表示水平线和垂直线的数量。
  - 第二行包含一个整数 $K$（$0 \leq K \leq (M + 1) \times (N + 1)$），表示禁止格子的数量。
  - 接下来 $K$ 行，每行包含两个整数 $x$ 和 $y$（$1 \leq x \leq M + 1$，$1 \leq y \leq N + 1$），表示第 $x$ 行第 $y$ 列的格子是禁止格子。所有禁止格子互不相同。

### 输出格式

对于每个测试用例，输出一行 `Case #: P`，其中 `#` 替换为用例编号（从 $1$ 开始），`P` 替换为有效涂色方案数对 $1000000007$ 取模的结果。

---

## 题目分析

本题是一个**带约束的图着色计数问题**。棋盘大小为 $R = M + 1$ 行，$C = N + 1$ 列，其中 $0 \leq M, N \leq 6$，因此 $R, C \leq 7$，最多有 $7 \times 7 = 49$ 个格子。

约束条件如下：

1. 每个非禁止格子必须涂四种颜色之一。
2. 相邻格子（上下左右）颜色不能相同。
3. 禁止格子不允许涂色。

由于棋盘较小，我们可以使用**状态压缩动态规划** 逐行求解。

---

## 解题思路

### 1. 状态表示

由于 $C \leq 7$，我们可以用一个整数（位掩码）表示一行的颜色状态。每个格子用 $2$ 位表示颜色（`0` 表示红色，`1` 表示绿色，`2` 表示蓝色，`3` 表示橙色），一行最多需要 $2 \times 7 = 14$ 位，因此状态总数最多为 $2^{14} = 16384$。

**关键点**：禁止格子不涂色，但在状态表示中，我们仍然为它们分配 $2$ 位，只是在检查有效性时跳过它们。

### 2. 生成有效行状态

对于每一行，我们需要生成所有可能的颜色组合，并排除以下无效情况：
- 同一行内相邻的非禁止格子颜色相同。
- 禁止格子被涂色（即颜色值不为 `0`）。

我们可以使用深度优先搜索（$\texttt{DFS}$）逐列生成所有有效状态。

### 3. 状态转移

设 $dp[r][mask]$ 表示涂到第 $r$ 行，且该行状态为 $mask$ 时的方案数。

状态转移方程为：

$$
dp[r][mask] = \sum_{prevMask \in S_{r-1}} dp[r-1][prevMask]
$$

其中 $S_{r-1}$ 是第 $r-1$ 行的所有有效状态，且 $prevMask$ 与 $mask$ 必须**兼容**，即对于每一列，如果第 $r-1$ 行和第 $r$ 行的该列都是非禁止格子，则它们的颜色必须不同。

### 4. 兼容性检查与优化

直接对每行状态进行 $O(S^2)$ 的兼容性检查会超时（$S$ 最多约为 $16384$）。我们需要进行优化：

- **预处理兼容性**：对于每一对相邻行，预先计算每个状态与下一行哪些状态兼容，存储为邻接表。这样在动态规划转移时可以直接遍历兼容状态，而不需要重复检查。
- **状态索引映射**：由于状态掩码可能很大，我们使用数组记录每个状态在有效状态列表中的索引，便于快速访问。

### 5. 最终计算

初始化 $dp[0][mask] = 1$ 对于所有第一行的有效状态 $mask$。

逐行递推后，最终答案为：

$$
result = \sum_{mask \in S_{R-1}} dp[R-1][mask]
$$

其中 $R = M + 1$ 是总行数。

---

## 算法步骤

1. 读取输入，标记禁止格子。
2. 对每一行，使用 $\texttt{DFS}$ 生成所有有效颜色状态。
3. 为每行状态建立索引映射，便于快速查找。
4. 预处理相邻行之间的状态兼容性（存储为下一行状态的索引列表）。
5. 执行动态规划，使用预处理的兼容性列表进行快速转移。
6. 累加最后一行的所有状态方案数，输出结果。

---

## 时间复杂度

- 生成有效状态：$O(4^C)$，其中 $C \leq 7$，最多 $16384$ 个状态。
- 预处理兼容性：$O(R \times S^2)$，但在实际数据中，有效状态数远少于 $16384$，且 $R \leq 7$，可以接受。
- DP 转移：$O(R \times S \times avgCompat)$，其中 $avgCompat$ 是平均兼容状态数。

由于棋盘很小，该算法可以在时限内通过所有测试用例。

```cpp
// Colorful Board
// UVa ID: 11725
// Verdict: Accepted
// Submission Date: 2026-01-30
// UVa Run Time: 0.370s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;
const int MAXR = 7;
const int MAXC = 7;

int M, N, R, C;
bool forbidden[MAXR][MAXC];
vector<int> validStates[MAXR];
vector<int> compat[MAXR][1 << 14]; // 兼容状态列表
int dp[MAXR][1 << 14]; // 状态数最多 4^7 = 16384
int stateMap[MAXR][1 << 21]; // 从编码到索引的映射

// 使用4种颜色编码：每列2位，0-3表示颜色
// 禁止格子用特殊值4表示，但实际不存储在状态中

void dfs(int row, int col, int mask, vector<int>& states) {
    if (col == C) {
        states.push_back(mask);
        return;
    }
    
    if (forbidden[row][col]) {
        // 禁止格子：标记为特殊值4（不在mask中，通过额外检查）
        dfs(row, col + 1, mask, states);
        return;
    }
    
    // 尝试4种颜色
    for (int color = 1; color <= 4; ++color) {
        // 检查左侧颜色是否相同
        if (col > 0 && !forbidden[row][col - 1]) {
            int leftColor = (mask >> (2 * (col - 1))) & 3;
            if (leftColor == color - 1) continue; // 颜色编号0-3
        }
        int newMask = mask | ((color - 1) << (2 * col));
        dfs(row, col + 1, newMask, states);
    }
}

// 检查两个状态是否兼容（考虑禁止格子）
bool checkCompat(int row1, int mask1, int row2, int mask2) {
    for (int col = 0; col < C; ++col) {
        if (forbidden[row1][col] || forbidden[row2][col]) continue;
        int c1 = (mask1 >> (2 * col)) & 3;
        int c2 = (mask2 >> (2 * col)) & 3;
        if (c1 == c2) return false;
    }
    return true;
}

void solve(int caseNo) {
    cin >> M >> N;
    R = M + 1;
    C = N + 1;
    memset(forbidden, 0, sizeof(forbidden));
    int K; cin >> K;
    for (int i = 0; i < K; ++i) {
        int x, y; cin >> x >> y;
        --x; --y;
        forbidden[x][y] = true;
    }
    // 生成所有有效状态
    for (int r = 0; r < R; ++r) {
        validStates[r].clear();
        dfs(r, 0, 0, validStates[r]);
    }
    // 为每行状态建立索引映射
    for (int r = 0; r < R; ++r)
        for (int i = 0; i < (int)validStates[r].size(); ++i)
            stateMap[r][validStates[r][i]] = i;
    // 预处理兼容性（只存下一行状态的索引）
    for (int r = 0; r < R - 1; ++r) {
        int size1 = validStates[r].size();
        int size2 = validStates[r + 1].size();
        for (int i = 0; i < size1; ++i) {
            compat[r][i].clear();
            for (int j = 0; j < size2; ++j)
                if (checkCompat(r, validStates[r][i], r + 1, validStates[r + 1][j]))
                    compat[r][i].push_back(j);
        }
    }
    // 动态规划
    memset(dp, 0, sizeof(dp));
    for (int i = 0; i < (int)validStates[0].size(); ++i) dp[0][i] = 1;
    for (int r = 0; r < R - 1; ++r) {
        int nextSize = validStates[r + 1].size();
        vector<int> nextDP(nextSize, 0);
        for (int i = 0; i < (int)validStates[r].size(); ++i) {
            if (dp[r][i] == 0) continue;
            int curVal = dp[r][i];
            for (int j : compat[r][i]) nextDP[j] = (nextDP[j] + curVal) % MOD;
        }
        for (int j = 0; j < nextSize; ++j) dp[r + 1][j] = nextDP[j];
    }
    // 计算结果
    long long result = 0;
    for (int i = 0; i < (int)validStates[R - 1].size(); ++i) 
        result = (result + dp[R - 1][i]) % MOD;
    cout << "Case " << caseNo << ": " << result << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T; cin >> T;
    for (int t = 1; t <= T; ++t) solve(t);
    return 0;
}
```
