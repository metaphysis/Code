## 题目分析

本题要求计算三角形 $ABC$ 的三个旁切圆圆心构成的三角形 $DEF$ 的面积，以及三个旁切圆中未被三角形 $ABC$ 覆盖的灰色扇形区域的总面积。 题目输入为多组三角形三边长 $a$, $b$, $c$ ，每组数据输出对应的两个面积值，均保留两位小数。

### 核心概念

- **旁切圆** ：与三角形一边内切，与另外两边的延长线外切的圆。 一个三角形有三个旁切圆，其圆心称为旁心，分别记为 $D$, $E$, $F$ 。
- **旁切圆半径公式** ：若三角形三边长为 $a$, $b$, $c$ ，半周长 $s = \frac{a+b+c}{2}$ ，面积为 $S$ ，则对应边 $a$ 的旁切圆半径 $r_a = \frac{S}{s-a}$ ，类似可得 $r_b$, $r_c$ 。
- **外接圆半径公式** ：$R = \frac{abc}{4S}$ 。
- **灰色区域** ：指三个旁切圆中，位于三角形 $ABC$ 外部的扇形部分。 这些扇形并非整个旁切圆，而是由旁切圆与三角形两边延长线所夹的部分。

### 解题思路

#### 1. 计算三角形 $DEF$ 的面积

三个旁心 $D$, $E$, $F$ 构成的三角形面积有一个简洁公式：
$$
S_{DEF} = 2R \cdot s
$$
其中 $R$ 为三角形 $ABC$ 的外接圆半径，$s$ 为半周长。 此公式可通过几何性质推导得出，代码中直接使用该公式计算。

#### 2. 计算灰色区域总面积

灰色区域由三个扇形组成，每个扇形属于一个旁切圆，其圆心角与三角形的一个内角有关。 具体关系如下：

对于边 $a$ 对应的旁切圆，其扇形的圆心角 $\theta_a$ 满足：
$$
\theta_a + \frac{\angle A}{2} = 90^\circ
$$
即
$$
\theta_a = 90^\circ - \frac{\angle A}{2}
$$
同理：
$$
\theta_b = 90^\circ - \frac{\angle B}{2}, \quad \theta_c = 90^\circ - \frac{\angle C}{2}
$$

**推导思路** ：旁切圆与边 $a$ 相切，与边 $b$ 和 $c$ 的延长线相切。 连接旁心 $D$ 与切点，可形成两个直角三角形，利用角平分线性质和三角形内角和为 $180^\circ$ ，可推得上述关系。

**计算步骤** ：

1. 由三边长 $a$, $b$, $c$ ，利用余弦定理求三个内角 $\angle A$, $\angle B$, $\angle C$ （弧度制）：
$$
   \cos A = \frac{b^2 + c^2 - a^2}{2bc}, \quad \cos B = \frac{a^2 + c^2 - b^2}{2ac}, \quad \cos C = \frac{a^2 + b^2 - c^2}{2ab}
$$
   再通过反余弦函数 $\arccos$ 得到角度值。

2. 计算三个扇形对应的圆心角（弧度制）：
$$
   \theta_a = \frac{\pi}{2} - \frac{A}{2}, \quad \theta_b = \frac{\pi}{2} - \frac{B}{2}, \quad \theta_c = \frac{\pi}{2} - \frac{C}{2}
$$

3. 计算三个扇形面积并求和：
$$
   S_{\text{gray}} = \frac{1}{2} r_a^2 \theta_a + \frac{1}{2} r_b^2 \theta_b + \frac{1}{2} r_c^2 \theta_c
$$

#### 3. 算法流程

对于每组输入 $(a, b, c)$ ：

1. 计算半周长 $s$ 和三角形面积 $S$ （海伦公式）。
2. 计算三个旁切圆半径 $r_a$, $r_b$, $r_c$ 。
3. 计算三个内角 $A$, $B$, $C$ （余弦定理）。
4. 计算三个扇形圆心角 $\theta_a$, $\theta_b$, $\theta_c$ 。
5. 计算灰色区域总面积 $S_{\text{gray}}$ 。
6. 计算外接圆半径 $R$ ，进而得到 $S_{DEF} = 2R \cdot s$ 。
7. 输出结果，保留两位小数。

### 复杂度分析

- 每组数据仅需常数次数学运算，时间复杂度 $O(1)$ 。
- 输入最多 $6000$ 组，总时间复杂度 $O(N)$ ，完全可行。
- 主要涉及浮点数运算，注意使用 `double` 类型保证精度，输出时四舍五入到两位小数。

### 关键点

- 理解旁切圆扇形的圆心角与三角形内角的关系。
- 熟练运用三角形几何中的常用公式（海伦公式、余弦定理、外接圆半径公式、旁切圆半径公式）。
- 注意角度与弧度的转换，在代码中统一使用弧度制计算。

### 代码实现

```cpp
// Ex-circles
// UVa ID: 11731
// Verdict: Accepted
// Submission Date: 2026-01-09
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);  // 精确的π值

int main() {
    int caseNum = 1;
    double a, b, c;
    while (cin >> a >> b >> c, a > 0) {
        // 计算半周长和三角形面积
        double s = (a + b + c) / 2.0;
        double areaABC = sqrt(s * (s - a) * (s - b) * (s - c));
        // 使用余弦定理求三个角（弧度制）
        double cosA = (b * b + c * c - a * a) / (2 * b * c);
        double cosB = (a * a + c * c - b * b) / (2 * a * c);
        double cosC = (a * a + b * b - c * c) / (2 * a * b);
        double angleA = acos(cosA);  // 角A的弧度值
        double angleB = acos(cosB);  // 角B的弧度值
        double angleC = acos(cosC);  // 角C的弧度值
        // 计算三个旁切圆半径
        double ra = areaABC / (s - a);
        double rb = areaABC / (s - b);
        double rc = areaABC / (s - c);
        // 计算三个扇形对应的角度（弧度制）
        // 扇形角度 = π/2 - 对应角的一半
        double sectorAngleA = PI / 2.0 - angleA / 2.0;
        double sectorAngleB = PI / 2.0 - angleB / 2.0;
        double sectorAngleC = PI / 2.0 - angleC / 2.0;
        // 计算三个扇形面积之和（灰色区域总面积）
        double grayArea = 0.5 * (ra * ra * sectorAngleA + 
                                 rb * rb * sectorAngleB + 
                                 rc * rc * sectorAngleC);
        // 计算三角形DEF的面积（公式：S_DEF = 2Rs）
        double R = a * b * c / (4.0 * areaABC);  // 外接圆半径
        double areaDEF = 2.0 * R * s;
        // 输出结果
        printf("Case %d: %.2lf %.2lf\n", caseNum++, areaDEF, grayArea);
    }
    return 0;
}
```

**代码说明** ：
- 使用 `acos(-1.0)` 获得高精度 $\pi$ 值。
- 循环读取直到 $a = 0$ （输入终止条件）。
- 严格按照上述推导公式计算各个中间值和最终结果。
- 使用 `printf` 控制输出格式，保留两位小数。
