## 题目分析
### 游戏规则分析

$\texttt{Corner the Queen}$ 是一个双人回合制博弈游戏，规则如下：

- 棋盘大小为 $n \times n$（实际为无限大）
- 皇后初始位置不在 $(0,0)$
- 每次移动必须朝向 $(0,0)$ 方向（新位置 $(a_2,b_2)$ 满足 $a_2 \leq a_1$ 且 $b_2 \leq b_1$）
- 皇后可以沿水平、垂直、对角线移动任意格
- 先将皇后移动到 $(0,0)$ 的玩家获胜
- 双方都采取最优策略

### 博弈论模型

这是一个**有向图博弈**，可以用 $\texttt{P-position}$（必败局面）和 $\texttt{N-position}$（必胜局面）来分析：

- $(0,0)$ 是 $\texttt{P-position}$（终局）
- 如果从某个位置可以**一步**走到 $\texttt{P-position}$，则该位置是 $\texttt{N-position}$
- 如果所有合法移动都走到 $\texttt{N-position}$，则该位置是 $\texttt{P-position}$

## 方法一：数学公式法（基于 $\texttt{Wythoff}$ 游戏）

### $\texttt{Wythoff}$ 游戏理论

这个游戏实际上是著名的 **$\texttt{Wythoff}$ 游戏**，其 $\texttt{P-position}$ 由 $\texttt{Beatty}$ 序列给出：

$$
A_k = \lfloor k\phi \rfloor, \quad B_k = \lfloor k\phi^2 \rfloor
$$

其中 $\phi = \frac{1+\sqrt{5}}{2}$ 是黄金比例，且满足 $\phi^2 = \phi + 1$。

因此 $\texttt{P-position}$ 可以表示为：

$$
(\lfloor k\phi \rfloor, \lfloor k\phi \rfloor + k), \quad k = 0,1,2,\ldots
$$

以及它们的对称位置 $(B_k, A_k)$。

### 算法实现思路

对于给定的矩形区域 $[x_1,x_2] \times [y_1,y_2]$：

1. **计算 $\texttt{P-position}$ 数量**：
   - 对于每个 $k$，计算 $A_k = \lfloor k\phi \rfloor$，$B_k = A_k + k$
   - 检查 $(A_k, B_k)$ 是否在矩形内
   - 检查对称位置 $(B_k, A_k)$ 是否在矩形内

2. **计算概率**：
   - 总格子数：$C = (x_2-x_1+1) \times (y_2-y_1+1)$
   - $\texttt{P-position}$ 数量：$P$
   - 先手必胜位置数：$A = C - P$
   - 概率：$\frac{A}{C}$（约分后）

### 枚举 $k$ 的暴力方法

最直接的想法是枚举 $k$，检查每个 $\text{P-position}$ 是否在矩形内：

```cpp
long long pCount = 0;
for (long long k = 1; ; k++) {
    long long ak = (long long)(k * phi);
    long long bk = ak + k;
    
    if (ak > x2 && bk > y2) break;
    
    // 检查 (ak, bk) 是否在矩形内
    if (ak >= x1 && ak <= x2 && bk >= y1 && bk <= y2) {
        pCount++;
    }
    
    // 检查对称情况 (bk, ak)
    if (ak != bk && bk >= x1 && bk <= x2 && ak >= y1 && ak <= y2) {
        pCount++;
    }
}
```

**复杂度分析**：
- 对于每个测试用例，需要枚举的 $k$ 数量约为 $\max(x_2, y_2) / \phi \approx 6 \times 10^5$
- 总操作数：$15000 \times 6 \times 10^5 = 9 \times 10^9$，会超时

### 数学优化：直接计算 $k$ 的范围

我们可以通过解不等式来直接确定 $k$ 的有效范围，避免枚举。

对于 $\texttt{P-position}$ $(A_k, B_k)$ 在矩形 $[x_1,x_2] \times [y_1,y_2]$ 内，需要满足：

$$
\begin{cases}
x_1 \leq \lfloor k\phi \rfloor \leq x_2 \\
y_1 \leq \lfloor k\phi \rfloor + k \leq y_2
\end{cases}
$$

这等价于：

$$
\begin{cases}
x_1 \leq k\phi - \{k\phi\} < x_2 + 1 \\
y_1 \leq k\phi + k - \{k\phi^2\} < y_2 + 1
\end{cases}
$$

其中 $\{\cdot\}$ 表示小数部分。

忽略小数部分的影响，我们得到 $k$ 的近似范围：

$$
\begin{cases}
\frac{x_1}{\phi} \leq k < \frac{x_2 + 1}{\phi} \\
\frac{y_1}{\phi^2} \leq k < \frac{y_2 + 1}{\phi^2}
\end{cases}
$$

取这两个范围的交集，就得到了 $k$ 的有效范围：

$$
k_{\min} = \max\left(1, \left\lceil \frac{x_1}{\phi} \right\rceil, \left\lceil \frac{y_1}{\phi^2} \right\rceil\right)
$$

$$
k_{\max} = \min\left(\left\lfloor \frac{x_2 + 1}{\phi} \right\rfloor, \left\lfloor \frac{y_2 + 1}{\phi^2} \right\rfloor\right)
$$

**优化后的算法**：

```cpp
long long countPrimaryPPositions(long long x1, long long x2, long long y1, long long y2) {
    if (x1 > x2 || y1 > y2) return 0;
    
    long long k_min = max(1LL, (long long)ceil(max(x1 / phi, y1 / phi2)));
    long long k_max = min((long long)floor((x2 + 1) / phi - 1e-12), 
                         (long long)floor((y2 + 1) / phi2 - 1e-12));
    
    if (k_min > k_max) return 0;
    return k_max - k_min + 1;
}
```

**复杂度分析**：
- 每个测试用例 $O(1)$ 时间
- 总复杂度 $O(T)$，$T \leq 15000$

### 浮点精度处理

由于浮点运算可能存在精度问题，我们需要注意：

1. 使用 `1e-12` 偏移量避免边界情况
2. 使用 `ceil` 和 `floor` 函数时注意方向
3. 对于对称情况，交换 $x$ 和 $y$ 的角色重新计算

### 复杂度分析

- 每个测试用例 $O(1)$ 时间
- 总复杂度 $O(T)$，$T \leq 15000$

## 方法二：预处理 $+$ 二分查找法

### 算法思路

1. **预处理**：
   - 生成所有可能的 $\texttt{P-position}$ 直到最大坐标
   - 存储为两个数组：$pX$ 和 $pY$

2. **查询处理**：
   - 使用二分查找统计矩形内的 $\text{P-position}$ 数量
   - 分别处理 $(A_k, B_k)$ 和 $(B_k, A_k)$ 两种情况

### 关键函数

```cpp
int countPPositionsInRect(int x1, int x2, int y1, int y2) {
    // 找到同时满足 x1 ≤ pX[i] ≤ x2 且 y1 ≤ pY[i] ≤ y2 的范围
    int left = max(lower_bound(pX, x1), lower_bound(pY, y1));
    int right = min(upper_bound(pX, x2), upper_bound(pY, y2));
    return max(0, right - left);
}
```

### 复杂度分析

- 预处理：$O(N)$，$N \approx 10^6$
- 每个查询：$O(\log N)$
- 总复杂度：$O(N + T\log N)$

## 两种方法对比

| 方面 | 数学公式法 | 预处理+二分法 |
|------|------------|---------------|
| 时间复杂度 | $O(T)$ | $O(N + T\log N)$ |
| 空间复杂度 | $O(1)$ | $O(N)$ |
| 精度 | 可能有浮点误差 | 整数运算，无误差 |
| 实现难度 | 较高 | 较低 |
| 适用性 | 需要数学推导 | 通用性强 |

## 代码实现

### 方法一：数学公式法

```cpp
// Corner the Queens
// UVa ID: 11735
// Verdict: Accepted
// Submission Date: 2025-10-27
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

// 黄金比例 φ = (1+√5)/2，用于生成Wythoff游戏的P位置
const double goldenRatio = (1.0 + sqrt(5.0)) / 2.0;
// φ² = φ + 1
const double goldenRatioSquared = goldenRatio * goldenRatio;

/**
 * 计算矩形区域内第一种P位置的数量
 * P位置格式: (floor(k*φ), floor(k*φ²)) = (floor(k*φ), floor(k*φ)+k)
 * 这些是先手必败的位置
 */
long long countPrimaryPPositions(long long xMin, long long xMax, long long yMin, long long yMax) {
    // 检查矩形是否有效
    if (xMin > xMax || yMin > yMax) return 0;
    
    // 计算k的取值范围：需要同时满足x和y的约束条件
    long long kLowerBound = max(1LL, (long long)ceil(max(xMin / goldenRatio, yMin / goldenRatioSquared)));
    long long kUpperBound = min((long long)floor((xMax + 1) / goldenRatio - 1e-12), 
                               (long long)floor((yMax + 1) / goldenRatioSquared - 1e-12));
    
    // 如果无有效k值，返回0
    if (kLowerBound > kUpperBound) return 0;
    
    // 返回满足条件的k值数量
    return kUpperBound - kLowerBound + 1;
}

/**
 * 计算矩形区域内第二种P位置的数量（对称情况）
 * P位置格式: (floor(k*φ²), floor(k*φ)) = (floor(k*φ)+k, floor(k*φ))
 * 这些也是先手必败的位置
 */
long long countSymmetricPPositions(long long xMin, long long xMax, long long yMin, long long yMax) {
    // 检查矩形是否有效
    if (xMin > xMax || yMin > yMax) return 0;
    
    // 计算k的取值范围：交换x和y的角色
    long long kLowerBound = max(1LL, (long long)ceil(max(yMin / goldenRatio, xMin / goldenRatioSquared)));
    long long kUpperBound = min((long long)floor((yMax + 1) / goldenRatio - 1e-12), 
                               (long long)floor((xMax + 1) / goldenRatioSquared - 1e-12));
    
    // 如果无有效k值，返回0
    if (kLowerBound > kUpperBound) return 0;
    
    // 返回满足条件的k值数量
    return kUpperBound - kLowerBound + 1;
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    
    int testCaseCount;
    cin >> testCaseCount;
    
    for (int caseIndex = 1; caseIndex <= testCaseCount; caseIndex++) {
        long long xMin, yMin, xMax, yMax;
        cin >> xMin >> yMin >> xMax >> yMax;
        
        // 处理无效矩形（输入保证有效，但为了健壮性保留）
        if (xMin > xMax || yMin > yMax) {
            cout << "Board " << caseIndex << ": 0 / 1\n";
            continue;
        }
        
        // 计算矩形内总格子数
        long long totalCells = (xMax - xMin + 1) * (yMax - yMin + 1);
        
        // 处理空矩形情况
        if (totalCells == 0) {
            cout << "Board " << caseIndex << ": 0 / 1\n";
            continue;
        }
        
        // 计算所有P位置（先手必败位置）的数量
        long long pPositionCount = countPrimaryPPositions(xMin, xMax, yMin, yMax) + 
                                  countSymmetricPPositions(xMin, xMax, yMin, yMax);
        
        // 计算先手必胜位置的数量
        long long winningPositionCount = totalCells - pPositionCount;
        
        // 约分分数
        long long commonDivisor = __gcd(winningPositionCount, totalCells);
        
        // 输出结果
        cout << "Board " << caseIndex << ": " << winningPositionCount / commonDivisor 
             << " / " << totalCells / commonDivisor << "\n";
    }
    
    return 0;
}
```

### 方法二：预处理 $+$ 二分查找法

```cpp
// Corner the Queens
// UVa ID: 11735
// Verdict: Accepted
// Submission Date: 2025-10-27
// UVa Run Time: 0.020s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

typedef long long LL;
const int MAXN = 2000005;  // 因为坐标最大10^6，P位置数量大约也是这个量级

vector<int> pX, pY;  // 存储P位置的x坐标和y坐标
bool used[MAXN];     // 标记数字是否已被使用

// 生成所有P位置 (a_k, b_k) 其中 a_k = floor(k*φ), b_k = floor(k*φ²) = a_k + k
void generatePPositions() {
    // 使用近似的黄金比例来生成序列
    // 实际是通过递推关系：每个新P位置 (a, b) 满足 b = a + k
    int k = 1;
    for (int a = 1; a < MAXN; a++) {
        if (used[a]) continue;
        int b = a + k;
        k++;
        
        if (b >= MAXN) break;
        
        used[a] = used[b] = true;
        pX.push_back(a);
        pY.push_back(b);
    }
}

// 计算矩形[x1,x2]×[y1,y2]内P位置的数量
LL countPPositionsInRect(int x1, int x2, int y1, int y2) {
    if (x1 > x2 || y1 > y2) return 0;
    
    // 找到第一个满足 pX[i] >= x1 且 pY[i] >= y1 的位置
    int left = max(
        lower_bound(pX.begin(), pX.end(), x1) - pX.begin(),
        lower_bound(pY.begin(), pY.end(), y1) - pY.begin()
    );
    
    // 找到第一个满足 pX[i] > x2 或 pY[i] > y2 的位置
    int right = min(
        upper_bound(pX.begin(), pX.end(), x2) - pX.begin(),
        upper_bound(pY.begin(), pY.end(), y2) - pY.begin()
    );
    
    return (left < right) ? (right - left) : 0;
}

int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    
    // 预处理生成所有P位置
    generatePPositions();
    
    int testCaseCount;
    cin >> testCaseCount;
    
    for (int caseIndex = 1; caseIndex <= testCaseCount; caseIndex++) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        
        // 计算矩形内总格子数
        LL totalCells = (LL)(x2 - x1 + 1) * (y2 - y1 + 1);
        
        // 统计P位置数量
        LL pCount = 0;
        
        // 统计 (a_k, b_k) 类型的P位置
        pCount += countPPositionsInRect(x1, x2, y1, y2);
        
        // 统计 (b_k, a_k) 类型的P位置（对称情况）
        pCount += countPPositionsInRect(y1, y2, x1, x2);
        
        // 计算先手必胜位置数量
        LL winningPositions = totalCells - pCount;
        
        // 约分
        LL commonDivisor = __gcd(winningPositions, totalCells);
        
        cout << "Board " << caseIndex << ": " 
             << winningPositions / commonDivisor << " / " 
             << totalCells / commonDivisor << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于识别出这是 **$\texttt{Wythoff}$ 游戏**，并利用其数学性质。两种方法各有优劣：

- **数学公式法**：理论优美，时间复杂度最优，但需要注意浮点精度
- **预处理 $+$ 二分法**：实现简单，稳健可靠，适合竞赛环境

在实际比赛中，推荐使用第二种方法，因为它更不容易出错，且代码易于调试和维护。
