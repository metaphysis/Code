## 题目描述

现代赛车都配备了精密的电子设备。一种新型视觉传感器与车载计算机相连，能够实时显示在你前方和后方各有多少辆车。赛道上共有 $N$ 辆车，每辆车都装有这种新型计算机。在某一时刻，每辆车的计算机都会显示两个整数：$a$（前方车辆数）和 $b$（后方车辆数）。在某些时刻，可能存在多辆车并排行驶（处于同一位置），此时它们不会将彼此视为前车或后车。

现在怀疑部分传感器在高速环境下工作不正常。你将收到某个时间戳下所有车辆的报告数据。你需要确定数据有误的最小车辆数。

### 输入格式

每个测试用例以整数 $N$（$1 \le N \le 1000$）开始，表示赛道上的车辆数。接下来 $N$ 行每行包含两个整数 $a$ 和 $b$（$0 \le a, b \le 1500$）。输入以一行单独的 $0$ 结束。

### 输出格式

对于每个测试用例，输出一行 `Case X: Y`，其中 $X$ 是测试用例编号，$Y$ 是数据有误的最小车辆数。

### 样例输入

```
4
2 2
0 0
2 3
1 1
1
1 0
0
```

### 样例输出

```
Case 1: 3
Case 2: 1
```

## 题目分析

这是一个典型的**逻辑推理与区间分配**问题。我们需要从给定的 $a$ 和 $b$ 值中推断出最多有多少辆车的数据是相互一致的，然后用总车辆数减去这个值就得到了最少有问题的车辆数。

### 关键观察

1. **数据有效性检查**：对于一辆车 $(a, b)$，如果 $a + b \ge N$，那么这辆车的数据肯定有问题。因为前方 $a$ 辆车 + 后方 $b$ 辆车 + 自己 $1$ 辆车的总和超过了总车辆数 $N$。

2. **车辆位置区间确定**：如果 $a + b < N$，那么这辆车必须位于区间 $[a+1, N-b]$ 内（假设位置从 $1$ 到 $N$ 编号）：
   - 车辆前面至少有 $a$ 辆车，所以位置编号至少是 $a+1$
   - 车辆后面至少有 $b$ 辆车，所以位置编号最多是 $N-b$

3. **区间容量限制**：对于任何区间 $[L, R]$，最多只能容纳 $R-L+1$ 辆车（因为每辆车需要一个位置，即使并排行驶也是在同一位置）。

### 解题思路

基于以上观察，我们可以将问题转化为**区间选择与优化**问题：

1. **预处理**：对于每辆车的有效数据 $(a, b)$，计算其可能的区间 $[L, R] = [a+1, N-b]$，并统计每个区间可能容纳的车辆数。

2. **动态规划**：设 $dp[i]$ 表示考虑前 $i$ 个位置（从 $1$ 到 $i$）时，最多能安排多少辆数据一致的车。状态转移方程为：

   $$ dp[i] = \max\{dp[j] + \min(cnt[j+1][i], i-j) \mid 0 \le j < i\} $$

   其中：
   - $cnt[L][R]$ 表示区间 $[L, R]$ 内可能存在的车辆数
   - $i-j$ 是区间 $[j+1, i]$ 的长度
   - $\min(cnt[j+1][i], i-j)$ 表示该区间最多能容纳的车辆数（不能超过区间长度）

3. **答案计算**：最小故障车数 = $N - dp[N]$

### 算法正确性证明

该算法的正确性基于以下事实：

1. **完备性**：算法考虑了所有可能的区间划分方式。对于任何有效的车辆安排，都可以对应一个区间划分，其中每个区间内的车辆都在该区间内。

2. **最优子结构**：如果前 $i$ 个位置的最优安排是 $dp[i]$，那么对于任何 $j < i$，$dp[j]$ 也必须是前 $j$ 个位置的最优安排。

3. **无后效性**：$dp[i]$ 的值只依赖于 $j < i$ 的 $dp[j]$ 值和区间 $[j+1, i]$ 的信息，满足动态规划的要求。

### 时间复杂度分析

- **预处理**：$O(N^2)$，需要更新二维数组 $cnt$
- **动态规划**：$O(N^2)$，双重循环
- **总复杂度**：$O(N^2)$，对于 $N \le 1000$ 完全可行

## 代码实现

```cpp
// Racing Car Computer
// UVa ID: 11766

//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
int main() {
    int caseNum = 1;
    int n;
    while (cin >> n && n) {
        vector<vector<int>> cnt(n + 2, vector<int>(n + 2, 0));
        // 步骤1：预处理，统计每个区间内可能的车辆数
        for (int i = 0; i < n; i++) {
            int a, b;
            cin >> a >> b;
            // 如果 a+b >= n，数据肯定有问题
            if (a + b >= n) continue;
            // 计算合法区间
            int L = a + 1;          // 最小可能位置
            int R = n - b;          // 最大可能位置
            // 区间内的车数不能超过区间长度
            if (cnt[L][R] < R - L + 1) cnt[L][R]++;
        }
        // 步骤2：动态规划
        vector<int> dp(n + 1, 0);
        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i - 1];  // 不选择任何以i结尾的区间
            for (int j = 0; j < i; j++) {
                // 考虑区间 [j+1, i]
                int length = i - j;  // 区间长度
                int canPlace = min(cnt[j + 1][i], length);  // 最多能放的车数
                dp[i] = max(dp[i], dp[j] + canPlace);
            }
        }
        // 步骤3：输出结果
        int minFaulty = n - dp[n];
        cout << "Case " << caseNum++ << ": " << minFaulty << '\n';
    }
    return 0;
}
```

## 示例解析

### 样例 $1$ 解析

输入：
```
4
2 2
0 0
2 3
1 1
```

分析：
1. 第一辆车：$a+b=4 \ge 4$，无效
2. 第二辆车：$a+b=0 < 4$，区间 $[1, 4]$，$cnt[1][4]=1$
3. 第三辆车：$a+b=5 \ge 4$，无效
4. 第四辆车：$a+b=2 < 4$，区间 $[2, 3]$，$cnt[2][3]=1$

动态规划计算：
- $dp[1] = 0$
- $dp[2] = \max(dp[1] + \min(cnt[2][2], 1), dp[0] + \min(cnt[1][2], 2)) = 1$
- $dp[3] = 1$
- $dp[4] = 1$

结果：$4 - 1 = 3$

## 总结

本题通过巧妙的区间建模将复杂的车辆排列问题转化为经典的区间选择问题，再使用动态规划高效求解。关键点在于：

1. 识别出每辆车的可能位置区间
2. 理解区间长度对车辆数的限制
3. 设计合适的状态转移方程

这种**从数据约束推导出几何/区间限制，再转化为优化问题**的思维方式在竞赛编程中非常常见，值得学习和掌握。
