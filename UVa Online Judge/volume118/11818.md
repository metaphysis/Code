[UVa 11818 Game Mouse and Cheese](https://blog.csdn.net/metaphysis/article/details/156732874)

## 题目描述

$\texttt{SOHA}$ 和 $\texttt{TARA}$ 发明了一个名为 “老鼠与奶酪” 的新游戏。 游戏在一个 $3 \times 3$ 的棋盘上进行，棋盘上的每个格子用 $1$ 到 $9$ 的整数唯一编号。 棋盘上共有 $12$ 根木棍（连接相邻格子的边），初始时老鼠和奶酪被放置在不同的格子上。

游戏规则如下： 这是一个双人游戏，玩家轮流行动， $\texttt{SOHA}$ 先手。 在每个回合中，玩家选择一根剩余的木棍并将其移走。 移走木棍后，如果老鼠能够在不碰到任何剩余木棍的情况下到达奶酪所在的格子（即老鼠与奶酪在剩余边构成的图中连通），那么当前玩家获胜。 双方都采取最优策略，问谁获胜。

在游戏开始前，部分木棍已经被移走。 输入会给出这些已移除木棍的坐标，以及老鼠和奶酪的位置。

## 输入格式

第一行一个整数 $T$ （ $T < 1000$ ），表示测试用例的数量。

每个测试用例的第一行包含三个整数 $S, C$ 和 $R$ 。 $S$ 和 $C$ 分别表示老鼠和奶酪所在的格子编号（ $1 \leq S, C \leq 9$ ， $S \neq C$ ）。 $R$ 表示游戏开始前已被移除的木棍数量（ $0 \leq R \leq 12$ ）。 接下来的 $R$ 行每行包含四个整数 $x_1, y_1, x_2, y_2$ ，表示一根被移除木棍的两个端点坐标（坐标以网格左下角为原点 $(0,0)$ ，木棍的端点可以以任意顺序给出）。

## 输出格式

对于每个测试用例，首先输出 `Case i: ` ，其中 $i$ 从 $1$ 开始编号。 如果游戏开始前老鼠已经能够到达奶酪（即初始状态下两者连通），则输出 `No Cheese!` 。 否则输出获胜玩家的名字： `SOHA` 或 `TARA` 。

## 题目分析

本题是一个典型的 **博弈论（$\texttt{Game Theory}$）** 问题，结合了 **图论（$\texttt{Graph Theory}$）** 和 **状态压缩（$\texttt{State Compression}$）** 技术。

### 核心问题转化

我们可以将棋盘建模为一个图：

- **节点** ： $9$ 个格子，编号 $1$ 到 $9$ 。
- **边** ： $12$ 根木棍，每条边连接两个相邻的格子。

游戏过程可以理解为： 初始时图中已经移除了 $R$ 条边（输入给定的木棍）。 两名玩家轮流从剩余的边中选择一条删除。 如果某玩家删除一条边后，老鼠节点 $S$ 和奶酪节点 $C$ 在剩余的边构成的子图中连通，则该玩家获胜。

因此，我们需要判断在双方都采取最优策略的情况下，先手玩家（$\texttt{SOHA}$）是否必胜。

### 关键观察

1. **初始状态检查** ： 首先检查在初始边集合下 $S$ 和 $C$ 是否连通。 如果连通，则游戏尚未开始就已满足条件，输出 `No Cheese!` 。
2. **博弈状态** ： 如果不连通，则进入博弈过程。 游戏的状态可以用一个 $12$ 位的二进制数 $mask$ 表示，第 $i$ 位为 $1$ 表示第 $i$ 条边还存在（未被移除），为 $0$ 表示已被移除。
3. **状态空间大小** ： $2^{12} = 4096$ ，非常小，适合进行 **记忆化搜索（$\texttt{Memoization}$）** 或 **动态规划（$\texttt{Dynamic Programming}$）** 。
4. **胜负判定** ： 这是一个 **无偏博弈（$\texttt{Impartial Game}$）** ，可以用 **$\texttt{DFS}$** 递归计算每个状态的胜负。
   - 当前状态 $mask$ （轮到当前玩家行动）：
     - 如果存在一条边 $i$ （ $mask$ 的第 $i$ 位为 $1$ ），使得移除后得到的新状态 $newMask = mask \oplus (1 \ll i)$ 满足：
       - $S$ 和 $C$ 在 $newMask$ 下连通 → 当前玩家 **立即获胜** 。
       - 或者，对手在 $newMask$ 状态下是必败态（即 $dfs(newMask)$ 返回 `false` ） → 当前玩家 **必胜** 。
     - 如果所有可移除的边都导致对手必胜，则当前玩家 **必败** 。

### 算法设计

1. **预处理** ： 将棋盘上的 $12$ 条边编号，并建立坐标到边编号的映射，便于输入处理。
2. **连通性检查** ： 实现函数 `isConnected(mask)` ，通过 $\texttt{BFS}$ 或 $\texttt{DFS}$ 检查在给定边集合 $mask$ 下 $S$ 和 $C$ 是否连通。 注意： $mask$ 中位为 $1$ 表示边存在，为 $0$ 表示边已被移除。
3. **记忆化搜索** ： 使用数组 $dp[mask]$ 记录状态 $mask$ 的胜负结果（ $1$ 表示必胜， $0$ 表示必败， $-1$ 表示未计算）。
   - 递归函数 $dfs(mask)$ ：
     - 如果 $dp[mask] \neq -1$ ，直接返回。
     - 遍历所有存在的边（ $mask$ 中为 $1$ 的位）：
       - 移除该边得到 $newMask$ 。
       - 如果 $isConnected(newMask)$ 为真，则 $dp[mask] = 1$ （当前玩家获胜）。
       - 否则，如果 $dfs(newMask)$ 为假，则 $dp[mask] = 1$ 。
     - 如果上述条件均不满足，则 $dp[mask] = 0$ 。
4. **主流程** ：
   - 读入 $S, C, R$ 。
   - 根据输入的 $R$ 条边，计算初始状态 $initialMask$ （所有边存在，然后清除被移除的边对应的位）。
   - 如果 $isConnected(initialMask)$ 为真，输出 `No Cheese!` 。
   - 否则，计算 $dfs(initialMask)$ ，若为真则 `SOHA` 获胜，否则 `TARA` 获胜。

### 时间复杂度分析

- 状态数： $O(2^{12}) = 4096$ 。
- 每个状态需要遍历最多 $12$ 条边，每条边需要进行一次连通性检查（ $\texttt{BFS}$ ， $O(9+12)$ ）。
- 总时间复杂度： $O(2^{12} \times 12 \times (9+12)) \approx 10^6$ ，完全可行。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 12条边的定义，每条边连接两个格子编号
const pair<int, int> edges[12] = {
    {1, 2}, {2, 3}, {4, 5}, {5, 6}, {7, 8}, {8, 9},
    {1, 4}, {2, 5}, {3, 6}, {4, 7}, {5, 8}, {6, 9}
};

// 坐标到边编号的映射，便于输入处理
map<pair<int, int>, int> magic = {
    {{10, 11}, 0}, {{20, 21}, 1}, {{11, 12}, 2},
    {{21, 22}, 3}, {{12, 13}, 4}, {{22, 23}, 5},
    {{1, 11}, 6}, {{11, 21}, 7}, {{21, 31}, 8},
    {{2, 12}, 9}, {{12, 22}, 10}, {{22, 32}, 11}
};

int S, C, R;  // 老鼠位置、奶酪位置、初始移除边数
int dp[1 << 12];  // 记忆化数组，-1表示未计算，1表示必胜，0表示必败

// 检查在边集合mask下，S和C是否连通
// mask中位为1表示边存在，为0表示边已被移除
bool isConnected(int edgeMask) {
    vector<vector<int>> g(10);  // 邻接表，1-indexed
    for (int i = 0; i < 12; i++) {
        if (!((edgeMask >> i) & 1)) {  // 边存在（未被移除）
            int u = edges[i].first, v = edges[i].second;
            g[u].push_back(v); 
            g[v].push_back(u);
        }
    }
    // BFS检查连通性
    vector<bool> visited(10, false);
    queue<int> q;
    q.push(S);
    visited[S] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (!visited[v]) {
                if (v == C) return true;  // 找到奶酪
                visited[v] = true;
                q.push(v);
            }
        }
    }
    return false;  // 不连通
}

// 记忆化搜索，判断当前状态（剩余边集合edgeMask）下，当前玩家是否必胜
bool dfs(int edgeMask) {
    if (~dp[edgeMask]) return dp[edgeMask];  // 已计算过
    // 尝试所有可移除的边
    for (int i = 0; i < 12; i++) {
        if ((edgeMask >> i) & 1) {  // 第i条边存在
            int newMask = edgeMask ^ (1 << i);  // 移除该边
            if (isConnected(newMask)) return dp[edgeMask] = 1;  // 移除后连通，获胜
            if (!dfs(newMask)) return dp[edgeMask] = 1;  // 对手必败，我方必胜
        }
    }
    return dp[edgeMask] = 0;  // 所有走法都导致对手必胜，我方必败
}

int main() {
    int T; cin >> T;
    for (int caseNo = 1; caseNo <= T; caseNo++) {
        cin >> S >> C >> R;
        // 初始所有边都存在（12位全1）
        int initialMask = (1 << 12) - 1;
        // 移除初始给定的R条边
        for (int i = 0; i < R; i++) {
            int x1, y1, x2, y2;
            cin >> x1 >> y1 >> x2 >> y2;
            int t1 = x1 * 10 + y1, t2 = x2 * 10 + y2;
            if (t1 > t2) swap(t1, t2);
            initialMask &= ~(1 << magic[{t1, t2}]);
        }
        cout << "Case " << caseNo << ": ";
        // 检查初始状态是否已连通
        if (isConnected(initialMask)) {
            cout << "No Cheese!\n";
            continue;
        }
        // 记忆化搜索求解博弈
        memset(dp, -1, sizeof dp);
        bool sohaWins = dfs(initialMask);
        cout << (sohaWins ? "SOHA" : "TARA") << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于将游戏过程建模为图上的删边博弈，并利用状态压缩和记忆化搜索高效求解。 棋盘规模很小（ $12$ 条边），状态空间有限，使得我们可以直接枚举所有可能的状态转移。 通过 $\texttt{BFS}$ 检查连通性，再结合递归计算每个状态的胜负，最终得到答案。 此题是一个很好的博弈论与图论结合的练习题目，考察了对状态空间的建模和搜索能力。
