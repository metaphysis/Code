[UVa 11843 Guessing Game](https://blog.csdn.net/metaphysis/article/details/156019669)

## 题目描述

$\texttt{Alice}$ 和 $\texttt{Bob}$ 设计了一个双人猜数游戏。游戏开始前，他们约定两个正整数：**范围** $N$ 和 **允许的失误次数上限** $S$。$\texttt{Alice}$ 秘密选择一个整数 $X$（$0 \le X < N$），然后 $\texttt{Bob}$ 轮流猜测整数。对于 $\texttt{Bob}$ 的每次猜测，$\texttt{Alice}$ 会给出以下三种回应之一：

- **$\texttt{strike}$**：如果猜测的数字大于 $X$；
- **$\texttt{smile}$**：如果猜测的数字小于 $X$；
- **$\texttt{stop}$**：如果猜测的数字等于 $X$（此时游戏结束，$\texttt{Bob}$ 获胜）。

如果 $\texttt{Bob}$ 累计收到 $S$ 次 **$\texttt{strike}$**，则游戏结束，$\texttt{Alice}$ 获胜。

$\texttt{Bob}$ 希望在正式比赛前进行训练。他需要知道，对于给定的 $N$ 和 $S$，**在最坏情况下**，他需要多少次猜测才能确保猜中 $\texttt{Alice}$ 选择的任意数字 $X$，并且在此过程中他最多收到 $S-1$ 次 $\texttt{strike}$（否则他会输掉游戏）。

**输入格式**：第一行包含一个整数 $C$，表示测试用例的数量。接下来 $C$ 行，每行包含两个整数 $N$ 和 $S$，分别表示数字范围和允许的 $\texttt{strike}$ 次数上限。保证 $1 \le N \le 1000$，$1 \le S \le 20$。

**输出格式**：对于每个测试用例，输出一行一个整数，表示 $\texttt{Bob}$ 在最坏情况下所需的最少猜测次数。

## 题目分析

这是一个典型的**最坏情况下的最优策略问题**，类似于带有限制的二分搜索。我们可以从以下几个关键点理解题目：

1. **游戏目标**：$\texttt{Bob}$ 需要保证无论 $\texttt{Alice}$ 选择哪个数字 $X$，他都能在收到少于 $S$ 次 $\texttt{strike}$ 的情况下猜中。
2. **策略限制**：每次猜测如果得到 **$\texttt{strike}$**，会消耗一次“允许的失误机会”；如果得到 **$\texttt{smile}$**，则不消耗。
3. **最坏情况**：我们需要考虑在所有可能的 $X$ 下，$\texttt{Bob}$ 所需猜测次数的最大值，并最小化这个最大值。

## 解题思路

### 1. 问题建模

设 $dp[n][s]$ 表示当数字范围为 $[0, n-1]$（即共有 $n$ 个可能的数字），且 $\texttt{Bob}$ 最多还能承受 $s$ 次 $\texttt{strike}$ 时，**在最坏情况下**需要的最少猜测次数。

#### 初始条件：
- 如果没有数字需要猜（$n = 0$），则不需要猜测：$dp[0][s] = 0$。
- 如果不能承受任何 $\texttt{strike}$（$s = 0$），那么 $\texttt{Bob}$ 只能从最小的数字开始逐个猜测，最坏情况需要猜 $n$ 次（当 $X = n-1$ 时）：$dp[n][0] = n$。

#### 状态转移：
假设当前范围大小为 $n$，我们选择猜测位置 $k$（$0 \le k < n$）。猜测后有三种可能：
1. **猜中**：游戏结束，本次猜测计数为 $1$。
2. **得到 $\texttt{strike}$**（猜大了）：说明 $X < k$，剩余范围大小为 $k$，剩余可承受 $\texttt{strike}$ 次数为 $s-1$，后续需要的最少猜测次数为 $dp[k][s-1]$。
3. **得到 $\texttt{smile}$**（猜小了）：说明 $X > k$，剩余范围大小为 $n-k-1$，剩余可承受 $\texttt{strike}$ 次数仍为 $s$，后续需要的最少猜测次数为 $dp[n-k-1][s]$。

由于我们要保证**最坏情况**，所以对于固定的 $k$，需要的猜测次数为：
$$
\texttt{guesses}(k) = 1 + \max(dp[k][s-1],\ dp[n-k-1][s])
$$
其中 $1$ 表示当前这次猜测。

为了最小化最坏情况，我们选择最优的 $k$：
$$
dp[n][s] = \min_{k=0}^{n-1} \left(1 + \max(dp[k][s-1],\ dp[n-k-1][s])\right)
$$

### 2. 算法实现

由于 $N \le 1000$，$S \le 20$，我们可以使用动态规划预先计算所有可能的 $dp[n][s]$ 值。对于每个测试用例，直接查表输出结果即可。

- **时间复杂度**：$O(N^2 \cdot S)$，对于给定范围是可接受的。
- **空间复杂度**：$O(N \cdot S)$。

### 3. 注意事项

- 题目中给出的 $S$ 是 $\texttt{Alice}$ 获胜所需的 $\texttt{strike}$ 次数，因此 $\texttt{Bob}$ 最多能承受 $S-1$ 次 $\texttt{strike}$。我们在计算时实际使用的 $s = S-1$。
- 当 $S = 1$ 时，$\texttt{Bob}$ 不能承受任何 $\texttt{strike}$（$s=0$），此时只能顺序猜测，需要 $N$ 次。

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 1005;
const int MAX_S = 25;
const int INF = 0x3f3f3f3f;

int dp[MAX_N][MAX_S];

// 预处理所有 dp[n][s] 的值
void precompute() {
    // 初始化：没有数字需要猜的情况
    for (int s = 0; s < MAX_S; ++s) dp[0][s] = 0;
    // 初始化：不能承受任何 strike 的情况
    for (int n = 1; n < MAX_N; ++n) dp[n][0] = n;
    
    // 动态规划递推
    for (int n = 1; n < MAX_N; ++n) {
        for (int s = 1; s < MAX_S; ++s) {
            int best = INF;
            // 尝试所有可能的猜测位置 k
            for (int k = 0; k < n; ++k) {
                int strikePart = dp[k][s - 1];      // 猜大后的情况
                int smilePart = dp[n - k - 1][s];   // 猜小后的情况
                int worst = 1 + max(strikePart, smilePart);
                if (worst < best) best = worst;
            }
            dp[n][s] = best;
        }
    }
}

int main() {
    precompute();  // 预先计算
    int c, n, S;
    cin >> c;
    while (c--) {
        cin >> n >> S;
        int s = S - 1;  // Bob 最多能承受的 strike 次数
        if (s < 0) s = 0;  // 安全处理边界
        cout << dp[n][s] << endl;
    }
    return 0;
}
```

## 样例解析

### 样例输入
```
2
3 2
4 1
```

### 样例输出
```
2
4
```

#### 解释：
1. $N=3,\ S=2$：$\texttt{Bob}$ 最多能承受 $1$ 次 $\texttt{strike}$。最优策略是先猜 $1$：
   - 若得 $\texttt{strike}$，则 $X=0$，下一轮猜 $0$，共 $2$ 次。
   - 若得 $\texttt{smile}$，则 $X=2$，下一轮猜 $2$，共 $2$ 次。
   - 若猜中，则只需 $1$ 次。
   最坏情况为 $2$ 次。

2. $N=4,\ S=1$：$\texttt{Bob}$ 不能承受任何 $\texttt{strike}$（$s=0$）。只能从 $0$ 开始顺序猜测，最坏情况（$X=3$）需要猜 $0,1,2,3$ 共 $4$ 次。

## 总结

本题通过动态规划巧妙地处理了带有 $\texttt{strike}$ 限制的猜数策略问题。关键在于定义状态 $dp[n][s]$ 并找到正确的状态转移方程，即每次猜测后根据反馈（$\texttt{strike}$ 或 $\texttt{smile}$）进入不同的子问题。预处理所有状态后，即可快速回答每个测试用例。该算法在给定数据范围内效率良好，是解决此类“最坏情况最优策略”问题的典型方法。
