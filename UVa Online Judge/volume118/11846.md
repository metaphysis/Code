## 题目描述

有 $n^2$ 名计算机科学家去看电影，电影院是一个 $n \times n$ 的正方形布局。这些科学家分为 $K$ 个独立的研究小组（$K \leq 26$），每个小组有一位组长。每个小组必须坐在一个矩形的座位区域内，且该区域必须包含该组的组长。组长已经购买了整个小组的门票，并确保了所有小组成员可以坐在一个矩形区域内。

引座员需要在座位图上标注一个满意的座位安排。他在图上标记了每个组长的位置以及该小组的人数（用一位十进制数字表示）。你需要帮助引座员找出一种安排方式，使得：

1. 每个小组占据一个矩形区域
2. 矩形区域的大小等于该小组的人数
3. 矩形必须包含该小组的组长
4. 矩形区域之间不能重叠
5. 所有座位都必须被覆盖

输入包含多个测试用例。每个测试用例的第一行包含两个整数 $n$ 和 $K$（$0 < n < 20$, $K \leq 26$）。接下来的 $n$ 行描述座位图，其中数字表示组长的位置和小组人数，点（`.`）表示该位置没有组长。输入以 `0 0` 结束。

对于每个测试用例，输出 $n$ 行，每行 $n$ 个字符，表示座位的分配情况。每个小组用一个不同的大写字母表示，该小组的所有成员都用该字母标识。

## 题目分析

### 问题本质

这是一个**矩形填充问题**：给定一个 $n \times n$ 的网格，其中某些格子有数字（表示组长位置和小组人数），我们需要用矩形覆盖整个网格，使得：

1. 每个矩形对应一个小组
2. 矩形大小等于小组人数
3. 矩形包含对应的组长
4. 矩形之间不重叠
5. 矩形内不能有其他组长

### 数据范围分析

- $n < 20$：网格最多 $19 \times 19 = 361$ 个格子
- $K \leq 26$：最多 $26$ 个小组，对应 $26$ 个大写字母

这个数据范围允许使用**回溯搜索（$\texttt{DFS}$）** 算法，但需要合理的剪枝策略。

### 关键约束

1. **矩形必须包含组长**：这限制了矩形的可能位置
2. **矩形大小固定**：小组人数决定了矩形的面积
3. **矩形不能重叠**：这是搜索过程中的主要约束
4. **矩形内不能有其他组长**：防止小组之间的干扰

## 解题思路

### 核心算法：深度优先搜索（$\texttt{DFS}$）

我们采用**从左到右、从上到下**的顺序填充网格。这种顺序填充策略有以下几个优点：

1. **确定性**：搜索顺序固定，便于实现和调试
2. **避免空洞**：确保不会出现无法填充的空隙
3. **尽早决策**：遇到未填充的格子时立即决定如何填充

### 搜索过程

搜索函数 `dfs(r, c)` 从位置 $(r, c)$ 开始寻找下一个未填充的格子：

1. **找到下一个未填充格子**：使用函数 `getNextEmpty(r, c)` 从左到右、从上到下查找第一个 `.` 格子
2. **判断格子类型**：
   - 如果是组长位置：必须放置包含该组长的矩形
   - 如果是普通点：必须被某个未放置的矩形覆盖
3. **尝试放置矩形**：枚举所有可能的矩形尺寸和位置，检查是否合法
4. **递归搜索**：放置成功后继续搜索下一个位置
5. **回溯**：如果当前选择导致无解，撤销选择，尝试其他可能性

### 矩形放置策略

对于一个小组，其矩形必须满足：
- 面积等于小组人数 $size$
- 包含组长位置 $(r, c)$
- 不与其他矩形重叠
- 不包含其他组长

对于面积为 $size$ 的矩形，可能的尺寸 $(h, w)$ 需要满足 $h \times w = size$。由于 $size \leq 9$（一位数字），可能的组合很少。

### 剪枝优化

1. **顺序剪枝**：按行优先顺序填充，确保不会出现空洞
2. **矩形尺寸枚举**：只枚举 $h \times w = size$ 的合法尺寸
3. **位置限制**：矩形必须包含组长，因此左上角位置有限制
4. **冲突检查**：放置前检查矩形内是否有其他组长或被占用格子

### 数据结构设计

- `grid[20][20]`：当前填充状态，`.` 表示未填充，字母表示已填充
- `orig[20][20]`：原始输入地图
- `leaders[26]`：组长信息数组
- `leaderMap[20][20]`：记录每个位置的组长索引，$-1$ 表示无组长

## 算法步骤

### 1. 初始化
- 读取 $n$ 和 $K$
- 初始化网格和组长信息
- 构建 `leaderMap` 便于快速查找

### 2. 深度优先搜索
- 从 $(0, 0)$ 开始搜索
- 对于每个未填充格子：
  - 如果是组长且未放置：尝试所有可能的矩形放置
  - 如果是普通点：尝试所有未放置小组的矩形来覆盖该点
- 递归搜索直到所有格子被填充或所有可能性尝试完毕

### 3. 输出结果
- 将填充好的网格按格式输出

## 时间复杂度

最坏情况下需要尝试所有可能的矩形组合。但由于：
- 小组人数最多 $9$，矩形尺寸组合有限
- 矩形必须包含组长，位置选择有限
- $n$ 最大 $19$，$K$ 最大 $26$

实际搜索空间远小于理论最坏情况，可以在 $20ms$ 内完成。

## 空间复杂度

主要空间用于存储网格和组长信息：
- 网格：$O(n^2)$
- 组长信息：$O(K)$
- 递归栈深度：$O(n^2)$

总空间复杂度为 $O(n^2 + K)$，完全在可接受范围内。

```cpp
// Finding Seats Again
// UVa ID: 11846
// Verdict: Accepted
// Submission Date: 2026-01-20
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Leader {
    int r, c, size;  // 组长位置和小组人数
    bool placed;     // 该组是否已放置
    char letter;     // 分配给该组的字母
};

int n, K;
char grid[20][20];   // 当前填充状态
char orig[20][20];   // 原始输入地图
Leader leaders[26];  // 组长信息数组
int leaderMap[20][20]; // 位置到组长索引的映射，-1表示无组长

// 获取下一个未填充的位置（从左到右、从上到下）
pair<int, int> getNextEmpty(int r, int c) {
    for (int i = r; i < n; i++)
        for (int j = (i == r ? c : 0); j < n; j++)
            if (grid[i][j] == '.')
                return {i, j};
    return {-1, -1};  // 所有位置都已填充
}

// 尝试放置矩形
bool tryPlace(int g, int sr, int sc, int h, int w) {
    Leader& l = leaders[g];
    // 检查矩形是否包含组长
    if (l.r < sr || l.r >= sr + h || l.c < sc || l.c >= sc + w) return false;
    
    // 检查矩形内是否有冲突
    for (int i = sr; i < sr + h; i++)
        for (int j = sc; j < sc + w; j++)
            if (grid[i][j] != '.' || (leaderMap[i][j] != -1 && leaderMap[i][j] != g))
                return false;
    
    // 放置矩形
    for (int i = sr; i < sr + h; i++)
        for (int j = sc; j < sc + w; j++)
            grid[i][j] = l.letter;
    l.placed = true;
    return true;
}

// 移除矩形
void removeRect(int sr, int sc, int h, int w) {
    for (int i = sr; i < sr + h; i++)
        for (int j = sc; j < sc + w; j++)
            grid[i][j] = '.';
}

// 深度优先搜索
bool dfs(int r, int c) {
    auto next = getNextEmpty(r, c);
    if (next.first == -1) return true;  // 所有位置已填充
    int cr = next.first, cc = next.second;
    
    // 如果当前位置已被填充，继续下一个位置
    if (grid[cr][cc] != '.') return dfs(cr, cc);
    
    // 检查当前位置是否是组长
    int g = leaderMap[cr][cc];
    if (g != -1) {
        // 当前位置是组长
        if (leaders[g].placed) return dfs(cr, cc);  // 组长已放置
        
        int size = leaders[g].size;
        // 枚举所有可能的矩形尺寸
        for (int h = 1; h <= size; h++) {
            if (size % h != 0) continue;
            int w = size / h;
            // 枚举矩形左上角位置（必须包含组长）
            for (int sr = max(0, cr - h + 1); sr <= cr && sr + h <= n; sr++)
                for (int sc = max(0, cc - w + 1); sc <= cc && sc + w <= n; sc++)
                    if (tryPlace(g, sr, sc, h, w)) {
                        if (dfs(cr, cc)) return true;
                        // 回溯
                        removeRect(sr, sc, h, w);
                        leaders[g].placed = false;
                    }
        }
        return false;
    } else {
        // 当前位置是普通点，必须被某个矩形覆盖
        for (int g = 0; g < K; g++) {
            if (leaders[g].placed) continue;  // 该组已放置
            
            int size = leaders[g].size;
            for (int h = 1; h <= size; h++) {
                if (size % h != 0) continue;
                int w = size / h;
                // 矩形必须能覆盖当前点且包含组长
                for (int sr = max(0, cr - h + 1); sr <= cr && sr + h <= n; sr++)
                    for (int sc = max(0, cc - w + 1); sc <= cc && sc + w <= n; sc++)
                        if (leaders[g].r >= sr && leaders[g].r < sr + h &&
                            leaders[g].c >= sc && leaders[g].c < sc + w &&
                            tryPlace(g, sr, sc, h, w)) {
                            if (dfs(cr, cc)) return true;
                            // 回溯
                            removeRect(sr, sc, h, w);
                            leaders[g].placed = false;
                        }
            }
        }
        return false;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    while (cin >> n >> K, n) {
        // 初始化
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) {
                grid[i][j] = '.';
                leaderMap[i][j] = -1;
            }
        
        // 读取输入
        for (int i = 0; i < n; i++) {
            string line; cin >> line;
            for (int j = 0; j < n; j++)
                orig[i][j] = line[j];
        }
        
        // 处理组长信息
        int cnt = 0;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (isdigit(orig[i][j])) {
                    leaders[cnt] = {i, j, orig[i][j] - '0', false, 'A' + cnt};
                    leaderMap[i][j] = cnt;
                    cnt++;
                }
        
        // 开始搜索
        dfs(0, 0);
        
        // 输出结果
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) cout << grid[i][j];
            cout << '\n';
        }
    }
    
    return 0;
}
```

## 总结

本题的关键在于**顺序填充策略**和**合理的剪枝**。通过从左到右、从上到下的填充顺序，我们确保了搜索的确定性和高效性。对于每个未填充的格子，根据其类型（组长或普通点）采取不同的放置策略，并通过约束条件大幅减少搜索空间。

算法的时间复杂度和空间复杂度都在可接受范围内，能够快速解决题目给定的数据规模。这种顺序填充的回溯搜索方法在类似的矩形填充问题中具有很好的通用性。
