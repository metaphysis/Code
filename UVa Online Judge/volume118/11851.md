[UVa 11851 Celebrity Split](https://blog.csdn.net/metaphysis/article/details/161379959)

## 题目描述

$\texttt{Jack}$ 和 $\texttt{Jill}$ 决定分家，并平分他们的财产。他们拥有 $N$ 栋豪宅，每栋价值在 $1,000,000$ 到 $40,000,000$ 美元之间。$\texttt{Jack}$ 将获得其中一些豪宅，$\texttt{Jill}$ 获得一些，剩下的豪宅将被出售，出售所得两人平分。

$\texttt{Jack}$ 和 $\texttt{Jill}$ 都不能容忍对方获得的房产总价值比自己高，因此 $\texttt{Jack}$ 获得的房产总价值必须等于 $\texttt{Jill}$ 获得的房产总价值。在两人所得价值相等的前提下，他们希望每人获得的房产总价值尽可能高。

给定 $N$ 栋豪宅的价值，计算必须出售的房产的总价值，使得剩余的房产可以按上述方式平分给 $\texttt{Jack}$ 和 $\texttt{Jill}$。

### 输入格式

输入包含多个测试用例。每个测试用例的第一行是一个整数 $N$（$N \leq 24$），表示豪宅数量。接下来 $N$ 行，每行给出一个豪宅的价值。最后一行是整数 $0$，表示输入结束，不处理。

### 输出格式

对每个测试用例，输出一行一个整数，即必须出售的豪宅总价值。

### 样例

**输入**

```text
5
6000000
30000000
3000000
11000000
3000000
0
```

**输出**

```text
41000000
```

**样例解释**：$\texttt{Jack}$ 或 $\texttt{Jill}$ 得到价值 $6,000,000$ 的豪宅，另一方得到两栋价值 $3,000,000$ 的豪宅。价值 $11,000,000$ 和 $30,000,000$ 的豪宅被出售，总价值为 $41,000,000$ 美元。

## 题目分析

### 问题本质

设 $N$ 栋豪宅的价值为 $a_1, a_2, \dots, a_N$，总价值为 $S = \sum_{i=1}^N a_i$。我们需要找到两个**不相交**的非空子集 $A$ 和 $B$，使得：

$$
\sum_{x \in A} x = \sum_{y \in B} y = T
$$

并且 $T$ 尽可能大。最终答案为：

$$
ans = S - 2T
$$

如果不存在这样的两个子集，则 $T = 0$，答案为 $S$（全部出售）。

### 约束条件分析

- $N \leq 24$，直接枚举所有子集的复杂度为 $2^N = 2^{24} \approx 16.8 \times 10^6$，单纯枚举可行，但需要进一步处理子集间的比较。
- 每个价值在 $10^6$ 到 $4 \times 10^7$ 之间，总和最大约为 $24 \times 4 \times 10^7 = 9.6 \times 10^8$，不能用数组直接做和的下标映射。
- 需要找到两个和相等且不相交的子集，这是一个经典的 $\texttt{Meet-in-the-Middle}$ 问题。

### 难点分析

1. **子集数量大**：$2^{24}$ 个子集枚举是可行的，但若对每个子集再枚举另一子集进行匹配，则复杂度为 $O(2^N \cdot 2^N) = O(2^{2N})$，不可接受。
2. **不相交约束**：两个子集不能包含同一元素，这比单纯找两个和相等的子集更难。
3. **哈希表开销**：使用 `unordered\_map` 存储 $16M$ 个状态会导致大量内存和哈希冲突开销。

## 解题思路

### 核心思想：折半搜索（$\texttt{Meet-in-the-Middle}$）

将 $N$ 个数分成两半：

- 左半：前 $n_1 = \lfloor N/2 \rfloor$ 个数
- 右半：后 $n_2 = N - n_1$ 个数

枚举左半的所有**不相交子集对** $(L_1, L_2)$，其中 $L_1 \cap L_2 = \varnothing$。记录三个信息：

- $diff = sum(L_1) - sum(L_2)$
- $mask_L$：$L_1 \cup L_2$ 在左半中的占用掩码（用于保证不相交，但实际后续无需使用）
- $sum_1 = sum(L_1)$

对右半做同样的枚举，记录 $(diff', mask_R, sum_1')$。

### 关键优化发现

**左右半的掩码天然不重叠**

- 左半的掩码使用位 $0 \dots n_1-1$
- 右半的掩码使用位 $0 \dots n_2-1$

由于左右半对应不同的元素集合，左半的 $mask_L$ 和右半的 $mask_R$ 永远不会在同一个位上冲突。因此，当我们将左半的 $(L_1, L_2)$ 与右半的 $(R_1, R_2)$ 组合时，两个整体子集：

$$
A = L_1 \cup R_1,\quad B = L_2 \cup R_2
$$

自动满足 $A \cap B = \varnothing$，无需额外检查。

### 条件匹配

我们需要：

$$
sum(A) = sum(B) \implies sum(L_1) + sum(R_1) = sum(L_2) + sum(R_2)
$$

整理得：

$$
\big(sum(L_1) - sum(L_2)\big) + \big(sum(R_1) - sum(R_2)\big) = 0
$$

即：

$$
diff_L + diff_R = 0
$$

因此，对于左半的每个状态，我们只需要在右半中查找 $diff_R = -diff_L$ 的状态，然后候选答案为：

$$
T_{cand} = sum_1^{(L)} + sum_1^{(R)}
$$

我们要在所有匹配中找到最大的 $T_{cand}$。

### 进一步优化：压缩右半状态

由于我们只需要每个 $diff$ 值对应的最大 $sum_1$（因为掩码不冲突，不需要保留多个），可以对右半按 $diff$ 排序，然后对每个 $diff$ 只保留最大的 $sum_1$。这样右半从 $3^{n_2}$ 个状态压缩为至多 $3^{n_2}$ 个不同的 $diff$ 值，但实际远少于该数。

左半枚举时，用二分查找在压缩后的右半数组中定位目标 $diff$，取对应的 $sum_1$ 最大值计算候选答案。

### 复杂度分析

- 左半枚举：$3^{n_1}$ 种状态（每个元素有三种可能：属于 $L_1$，属于 $L_2$，或都不属于）。$n_1 = 12$ 时，$3^{12} = 531,441$。
- 右半枚举：$3^{n_2} \le 3^{12} = 531,441$。
- 右半排序：$O(3^{n_2} \log 3^{n_2})$，约 $531k \times 19 \approx 10M$ 次比较。
- 左半匹配：对左半每个状态做一次二分查找，$O(3^{n_1} \log 3^{n_2})$，同样约 $10M$ 次操作。
- 总操作量约 $2 \times 10^7$ 量级，远优于 $2^N$ 的枚举方式。

## 算法步骤

1. 读入 $N$ 和数组 $a$，计算总价值 $S$。
2. 令 $n_1 = N / 2$，$n_2 = N - n_1$。
3. 枚举左半所有三进制状态（$0$：不选，$1$：选入 $L_1$，$2$：选入 $L_2$），对每个状态计算：
   - $sum_1$：$L_1$ 的和
   - $sum_2$：$L_2$ 的和
   - $diff = sum_1 - sum_2$
   - $mask$：$L_1 \cup L_2$ 的位掩码（实际上后续未使用，但保留便于理解）
   - 将状态存入左半数组 `left`。
4. 同理枚举右半，存入右半数组 `right`。
5. 将右半按 `diff` 排序。
6. 压缩右半：遍历排序后的 `right`，对每个 `diff` 保留最大的 `sum1`，存入 `rightBest` 数组。
7. 遍历左半每个状态，用二分查找在 `rightBest` 中寻找目标 `diff = -left.diff`：
   - 若找到，计算 `cand = left.sum1 + rightBest.sum1`，更新全局最大值 `maxSameSum`。
8. 输出 `S - 2 * maxSameSum`。

## 代码实现

```cpp
// Celebrity Split
// UVa ID: 11851
// Verdict: Accepted
// Submission Date: 2026-05-25
// UVa Run Time: 0.680s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Node {
    int diff, mask, sum1;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    while (cin >> n && n != 0) {
        vector<int> a(n);
        int total = 0;
        for (int i = 0; i < n; ++i) {
            cin >> a[i];
            total += a[i];
        }
        
        int n1 = n / 2, n2 = n - n1;
        
        // 枚举左半所有不相交子集对 (L1, L2)
        int limit1 = 1;
        for (int i = 0; i < n1; ++i) limit1 *= 3;
        vector<Node> left;
        left.reserve(limit1);
        
        for (int state = 0; state < limit1; ++state) {
            int sum1 = 0, sum2 = 0, mask = 0, tmp = state;
            for (int i = 0; i < n1; ++i) {
                int t = tmp % 3;
                tmp /= 3;
                if (t == 1) {
                    sum1 += a[i];
                    mask |= (1 << i);
                } else if (t == 2) {
                    sum2 += a[i];
                    mask |= (1 << i);
                }
            }
            left.push_back({sum1 - sum2, mask, sum1});
        }
        
        // 枚举右半所有不相交子集对 (R1, R2)
        int limit2 = 1;
        for (int i = 0; i < n2; ++i) limit2 *= 3;
        vector<Node> right;
        right.reserve(limit2);
        
        for (int state = 0; state < limit2; ++state) {
            int sum1 = 0, sum2 = 0, mask = 0, tmp = state;
            for (int i = 0; i < n2; ++i) {
                int t = tmp % 3;
                tmp /= 3;
                if (t == 1) {
                    sum1 += a[n1 + i];
                    mask |= (1 << i);
                } else if (t == 2) {
                    sum2 += a[n1 + i];
                    mask |= (1 << i);
                }
            }
            right.push_back({sum1 - sum2, mask, sum1});
        }
        
        // 对右半按 diff 排序
        sort(right.begin(), right.end(), [](const Node& x, const Node& y) {
            return x.diff < y.diff;
        });
        
        // 压缩右半：每个 diff 只保留最大的 sum1
        vector<pair<int, int>> rightBest;
        for (size_t i = 0; i < right.size(); ) {
            int curDiff = right[i].diff;
            int maxSum1 = 0;
            while (i < right.size() && right[i].diff == curDiff) {
                if (right[i].sum1 > maxSum1) maxSum1 = right[i].sum1;
                ++i;
            }
            rightBest.emplace_back(curDiff, maxSum1);
        }
        
        // 匹配左半与右半
        int maxSameSum = 0;
        for (const Node& node : left) {
            int target = -node.diff;
            auto it = lower_bound(rightBest.begin(), rightBest.end(), make_pair(target, 0));
            if (it != rightBest.end() && it->first == target) {
                maxSameSum = max(maxSameSum, node.sum1 + it->second);
            }
        }
        
        cout << total - 2 * maxSameSum << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于将原问题转化为寻找两个不相交且和相等的子集，并利用折半搜索将指数级复杂度降低到可接受范围。关键优化点包括：

1. **折半枚举**：将 $2^N$ 的枚举转化为 $3^{N/2}$ 的枚举，状态数从 $16M$ 降至 $1M$。
2. **掩码天然不重叠**：利用分半特性，省去了复杂的相交检查，使得右半可以压缩到每个 $diff$ 只保留最大 $sum_1$。
3. **排序 + 二分查找**：替代哈希表，避免了哈希冲突和动态内存分配的开销。
4. **结构体与预分配**：使用 `vector::reserve` 减少动态扩容，使用轻量级结构体替代元组。
