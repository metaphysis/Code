[UVa 11863 Prime Game](https://blog.csdn.net/metaphysis/article/details/158425566)

## 题目描述

$\texttt{Soha}$ 和 $\texttt{Tara}$ 玩一个游戏。初始时，$\texttt{Soha}$ 在纸上写下 $N$ 个整数。游戏规则如下：

- 玩家轮流行动，$\texttt{Soha}$ 先手。
- 每轮，玩家必须从当前列表的 **最左边或最右边** 移除 **一个或多个连续的** 数字。
- 被移除的数字之和必须是一个 **质数**。
- 数字 $42$ 是特殊的：它可以被玩家当作 **任意整数** 使用（用来凑质数）。
- 玩家可以在自己的回合选择 **`pass`**，即不删除任何数字。但每个玩家最多只能 `pass` $K$ 次。
- 如果某玩家用完了所有 `pass` 次数，且没有任何合法移动，则该玩家输。
- 双方都 **完美发挥**，问谁获胜。

## 输入格式

- 第一行：$T$（$T < 100$），测试用例数。
- 每个测试用例：
  - 第一行：$N$（$0 < N < 100$）和 $K$（$0 \leq K < 1000$）。
  - 第二行：$N$ 个整数，范围 $[-1000, 1000]$。

## 输出格式

对于每个测试用例，输出 `Case x: Soha` 或 `Case x: Tara`。

## 题目分析

这是一个 **双人博弈问题**，类似于从两端取连续数字的游戏。关键点在于：

1. **只能从两端取**：剩余的数字始终是一个连续区间 $[l, r]$。
2. **和必须是质数**：需要快速判断一个子区间的和是否为质数。
3. **$42$ 的特殊性**：包含 $42$ 的区间总是合法的，因为我们可以把 $42$ 调整成任意值来凑质数。
4. **pass 机制**：每个玩家有 $K$ 次 `pass` 机会，`pass` 不改变区间，但消耗一次机会并交换玩家。
5. **状态空间**：区间有 $O(N^2)$ 种，每个区间还需要考虑双方剩余 `pass` 次数，最坏情况 $O(N^2 \times K^2)$，但 $K$ 可达 $1000$，不能直接枚举。

## 解题思路

### 状态定义

我们定义：

$$
\texttt{win}[l][r][p] = \text{区间 }[l, r] \text{ 中，当前玩家还有 } p \text{ 次 pass 可用时，是否必胜}
$$

这里 $p$ 是 **当前玩家的剩余 `pass` 次数**，而不是双方的剩余次数。为什么可以这样定义？因为游戏是交替进行的，知道当前玩家剩余 `pass` 次数，就知道对方剩余次数了吗？不完全对，但我们可以这样处理：

实际上，初始时 $\texttt{Soha}$ 有 $K$ 次，$\texttt{Tara}$ 有 $K$ 次。在游戏过程中，当前玩家的剩余 `pass` 次数是确定的，对方剩余次数 = 总剩余次数 - 当前玩家剩余次数。但总剩余次数是递减的，我们可以在状态中只记录当前玩家的剩余次数，因为对方次数可以通过总次数推算。但为了简化，我们直接在状态中记录 **当前玩家** 的剩余 `pass` 次数 $p$，并认为 $p$ 的取值范围是 $0 \sim 2K$（因为总次数最多 $2K$），但实际有效值不超过 $2N$（因为最多进行 $N$ 步）。

### 状态转移

当前玩家在区间 $[l, r]$ 且有 $p$ 次 `pass` 可用时，可以采取以下行动：

1. **`pass`**：如果 $p > 0$，可以选择 `pass`，将相同的区间 $[l, r]$ 交给对方，但对方的剩余 `pass` 次数变为 $p-1$（因为消耗一次）。如果对方在 $(l, r, p-1)$ 是必败，则当前玩家必胜。
2. **从左边取**：选择一个 $i$（$l \le i \le r$），移除 $[l, i]$，要求这个子区间的和是质数（或包含 $42$）。移除后剩余区间为 $[i+1, r]$，交给对方，且对方的剩余 `pass` 次数仍为 $p$（因为没使用 `pass`）。如果对方在 $(i+1, r, p)$ 是必败，则当前玩家必胜。
3. **从右边取**：选择一个 $i$（$l \le i \le r$），移除 $[i, r]$，要求合法。剩余区间为 $[l, i-1]$，交给对方，剩余 `pass` 次数仍为 $p$。如果对方在 $(l, i-1, p)$ 是必败，则当前玩家必胜。

如果以上所有选择都不能让对方进入必败态，则当前玩家必败。

### 边界条件

- 空区间 $[l, r]$ 且 $l > r$：没有数字可拿，当前玩家无法行动，如果还有 `pass` 可用，理论上可以 `pass`，但 `pass` 后对方也无行动，实际上当前玩家输。所以我们定义空区间为 **必败态**。
- 当 $p = 0$ 时，不能选择 `pass`。

### 预处理

- **质数筛**：由于数字范围 $[-1000, 1000]$，$N \le 100$，最大和为 $100 \times 1000 = 100000$，最小和为 $-100000$。但质数必须是正数且 $\ge 2$，所以我们只需要判断 $[2, 100000]$ 内的质数。用埃氏筛预处理。
- **合法移动判断**：对于每个区间 $[l, r]$，检查是否包含 $42$，如果包含，则直接合法；否则计算区间和，判断是否为质数。预处理出 $\texttt{isValidMove}[l][r]$。

### 动态规划顺序

我们按区间长度从小到大进行 $\texttt{DP}$：

- 长度 $1$ 的区间：检查是否合法，如果合法则可以直接取走，必胜；否则只能依赖 `pass`。
- 长度递增：计算所有可能的 $l, r$ 和 $p$。

### 复杂度分析

- 区间数：$O(N^2)$
- 每个区间的 $p$ 范围：$O(\min(2K, 2N)) \le O(2N) = O(200)$
- 每个状态转移：需要遍历 $i$ 从 $l$ 到 $r$ 检查左右取法，$O(N)$
- 总复杂度：$O(N^3 \times \min(K, N)) \approx 100^3 \times 200 = 2 \times 10^8$ 次操作，在时限内可接受。

## 代码实现

```cpp
// Prime Game
// UVa ID: 11863
// Verdict: Accepted
// Submission Date: 2026-02-26
// UVa Run Time: 0.250s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
const int MAXSUM = 200005;

int arr[MAXN];
int prefixSum[MAXN];
bool isValidMove[MAXN][MAXN];
bool isPrime[MAXSUM];
int N, K;

void initPrime() {
    memset(isPrime, true, sizeof(isPrime));
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i < MAXSUM; i++) {
        if (isPrime[i]) {
            for (long long j = (long long)i * i; j < MAXSUM; j += i)
                isPrime[j] = false;
        }
    }
}

int getSum(int l, int r) {
    return prefixSum[r] - prefixSum[l - 1];
}

void preprocess() {
    for (int l = 1; l <= N; l++) {
        for (int r = l; r <= N; r++) {
            isValidMove[l][r] = false;
            
            bool hasFortyTwo = false;
            for (int i = l; i <= r; i++) {
                if (arr[i] == 42) {
                    hasFortyTwo = true;
                    break;
                }
            }
            
            if (hasFortyTwo) {
                isValidMove[l][r] = true;
            } else {
                int sum = getSum(l, r);
                if (sum >= 2 && sum < MAXSUM && isPrime[sum])
                    isValidMove[l][r] = true;
            }
        }
    }
}

// win[l][r][p] 表示区间[l,r]，当前玩家还有p次pass可用时的胜负
bool win[MAXN + 2][MAXN + 2][MAXN * 2 + 5];  // 增加边界

void solve() {
    int maxPass = min(2 * K, 2 * N);
    
    // 初始化：长度为0的区间，没有数字可拿，必败
    for (int p = 0; p <= maxPass; p++) {
        for (int i = 1; i <= N + 1; i++) {
            win[i][i - 1][p] = false;  // 空区间，必败
        }
    }
    
    // 按区间长度从小到大DP
    for (int len = 1; len <= N; len++) {
        for (int l = 1; l + len - 1 <= N; l++) {
            int r = l + len - 1;
            
            for (int p = 0; p <= maxPass; p++) {
                bool canWin = false;
                
                // 尝试pass
                if (p > 0 && !win[l][r][p - 1]) {
                    canWin = true;
                } else {
                    // 尝试从左边取
                    for (int i = l; i <= r && !canWin; i++) {
                        if (isValidMove[l][i] && !win[i + 1][r][p])
                            canWin = true;
                    }
                    
                    // 尝试从右边取
                    for (int i = r; i >= l && !canWin; i--) {
                        if (isValidMove[i][r] && !win[l][i - 1][p])
                            canWin = true;
                    }
                }
                
                win[l][r][p] = canWin;
            }
        }
    }
}

int main() {
    initPrime();
    
    int T;
    scanf("%d", &T);
    
    for (int caseNum = 1; caseNum <= T; caseNum++) {
        scanf("%d %d", &N, &K);
        
        for (int i = 1; i <= N; i++) {
            scanf("%d", &arr[i]);
            prefixSum[i] = prefixSum[i - 1] + arr[i];
        }
        
        preprocess();
        solve();
        
        int maxPass = min(2 * K, 2 * N);
        bool sohaWins = win[1][N][maxPass];
        
        printf("Case %d: %s\n", caseNum, sohaWins ? "Soha" : "Tara");
    }
    
    return 0;
}
```

## 总结

本题是一个典型的区间博弈问题，结合了质数判断、特殊数字 $42$ 的处理以及 `pass` 机制。核心在于设计合适的状态 $(l, r, p)$ 并利用记忆化搜索或 $\texttt{DP}$ 求解。由于 $N$ 较小，$O(N^3 \times \min(K, N))$ 的复杂度在 $1000 \ \texttt{ms}$ 内可以通过。
