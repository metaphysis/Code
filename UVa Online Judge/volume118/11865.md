[UVa 11865 Stream My Contest](https://blog.csdn.net/metaphysis/article/details/154865175)

## 题目描述

在 $2009$ 年和 $2010$ 年的 $\texttt{ICPC}$ 世界总决赛期间，比赛通过网络进行了直播。受到这一启发，$\texttt{Ajobdesh}$ 的比赛组织者决定向他们国家的每所大学提供比赛的实时流媒体服务。然而，他们面临两个主要问题：

1. 大学之间没有现有的网络，需要建立新网络，但建网预算不能超过 $C$
2. 网络中的每条链路都有特定的带宽，如果流的带宽超过任何链路的可用带宽，通过该链路连接的观众将无法观看

由于流媒体协议的限制，一个观众只能从一个其他用户（或比赛组织的服务器）接收流。也就是说，如果有两个 $128\text{kbps}$ 的链路，不能获得 $256\text{kbps}$ 的带宽；但如果有一个 $128\text{kbps}$ 的流，可以以该带宽向任意数量的用户进行流传输。

给定预算 $C$，**需要最大化任何用户的最小带宽**。

### 输入格式

第一行包含整数 $T$（$\leq 50$），表示测试用例数量。接下来是 $T$ 个测试用例。

每个测试用例以三个整数 $N, M, C$（$1 \leq N \leq 60$，$1 \leq M \leq 10^4$，$1 \leq C \leq 10^9$）开始，分别表示大学数量、可能链路数量和建网预算。每所大学用 $0$ 到 $N-1$ 的整数标识，其中 $0$ 是服务器。

接下来的 $M$ 行，每行包含四个整数 $u, v, b, c$（$0 \leq u,v < N$，$1 \leq b,c \leq 10^6$，$u \neq v$），描述从大学 $u$ 到大学 $v$ 的可能链路，带宽为 $b$ $\text{kbps}$，成本为 $c$。所有链路都是单向的。

每个测试用例前有一个空行。

### 输出格式

对于每个测试用例，输出可以传输的最大带宽。如果不可能，输出 `streaming not possible.`。

## 题目分析

### 问题本质

我们需要在给定的预算 $C$ 内，构建一个以服务器（节点 $0$）为根的有向生成树，使得从根到所有叶节点的路径上的最小带宽最大化。

这实际上是一个**有向图的最小生成树**问题，但带有额外的带宽约束和成本限制。

### 关键观察

1. **带宽的单调性**：如果带宽 $B$ 可行，那么所有小于 $B$ 的带宽也都可行；如果 $B$ 不可行，那么所有大于 $B$ 的带宽也都不可行。这种单调性提示我们可以使用二分查找。

2. **有向生成树**：由于链路是单向的，我们需要找到以节点 $0$ 为根的有向生成树（即每个非根节点恰好有一条入边）。

3. **双重约束**：需要同时满足带宽要求（所有边带宽 $\geq$ 目标值）和成本约束（总成本 $\leq C$）。

### 解题思路

#### 1. 二分答案框架

由于带宽具有单调性，我们可以使用二分查找来确定最大可行带宽：

- 下界：所有边中的最小带宽
- 上界：所有边中的最大带宽

对于每个中间值 $mid$，检查是否存在满足以下条件的有向生成树：
- 所有边的带宽 $\geq mid$
- 总成本 $\leq C$

#### 2. 可行性检查

对于给定的带宽阈值 $B$，检查可行性的步骤：

**步骤 1：连通性检查**
使用 $\texttt{BFS}$ 或 $\texttt{DFS}$ 检查在只考虑带宽 $\geq B$ 的边时，从节点 $0$ 是否能到达所有其他节点。如果不能，直接返回不可行。

**步骤 2：最小树形图计算**
使用**朱刘算法**（$\texttt{Chu-Liu/Edmonds}$ 算法）在满足带宽要求的边上计算以节点 $0$ 为根的最小有向生成树。

**步骤 3：成本检查**
如果找到的有向生成树总成本 $\leq C$，则带宽 $B$ 可行。

#### 3. 朱刘算法原理

朱刘算法是解决有向图最小生成树问题的经典算法，主要步骤：

1. **选择最小入边**：为每个非根节点选择成本最小的入边
2. **检测环**：检查当前选择的边是否形成环
3. **若无环**：当前选择即为最小树形图
4. **若有环**：
   - 将环收缩为超级节点
   - 调整相关边的权值
   - 在收缩后的图上递归求解
   - 将解展开还原

### 算法复杂度分析

- **二分查找**：$O(\log(\text{maxBandwidth}))$，最多 $20$ 次迭代
- **每次检查**：
  - 连通性检查：$O(N + M)$
  - 朱刘算法：$O(N \times M)$
- **总复杂度**：$O(T \times \log B \times N \times M)$，在题目约束下可接受

```cpp
// Stream My Contest

#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>
#include <climits>
using namespace std;

struct Edge {
    int u, v, b, c;
};

// 可靠的朱刘算法实现
class DirectedMST {
private:
    int n;
    vector<Edge> edges;
    vector<vector<int>> adj;
    
public:
    DirectedMST(int n, const vector<Edge>& edges, const vector<vector<int>>& adj) 
        : n(n), edges(edges), adj(adj) {}

    // 连通性检查
    bool checkConnectivity(int root, int minBandwidth) {
        vector<bool> visited(n, false);
        queue<int> q;
        q.push(root);
        visited[root] = true;
        int count = 1;
        
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int idx : adj[u]) {
                const Edge& e = edges[idx];
                if (e.b >= minBandwidth && !visited[e.v]) {
                    visited[e.v] = true;
                    q.push(e.v);
                    count++;
                }
            }
        }
        return count == n;
    }

    // 朱刘算法求解最小树形图
    int solve(int root, int minBandwidth) {
        // 首先检查连通性
        if (!checkConnectivity(root, minBandwidth)) {
            return -1;
        }
        
        int m = edges.size();
        
        // 构建有效边集
        vector<int> from, to, cost;
        for (int i = 0; i < m; i++) {
            if (edges[i].b >= minBandwidth) {
                from.push_back(edges[i].u);
                to.push_back(edges[i].v);
                cost.push_back(edges[i].c);
            }
        }
        
        if (from.empty()) return -1;
        
        return chuLiuEdmonds(root, n, from, to, cost);
    }

private:
    // 朱刘算法核心实现
    int chuLiuEdmonds(int root, int n, const vector<int>& from, 
                     const vector<int>& to, const vector<int>& cost) {
        int m = from.size();
        if (m == 0) return -1;
        
        vector<int> minIncoming(n, -1);
        vector<int> minCost(n, INT_MAX);
        
        // Step 1: 为每个节点找到最小入边
        for (int i = 0; i < m; i++) {
            int u = from[i], v = to[i], c = cost[i];
            if (u == v) continue; // 跳过自环
            
            if (c < minCost[v]) {
                minCost[v] = c;
                minIncoming[v] = i;
            }
        }
        
        minCost[root] = 0;
        minIncoming[root] = -1;
        
        // 检查是否所有节点都有入边（除了根节点）
        for (int i = 0; i < n; i++) {
            if (i != root && minIncoming[i] == -1) {
                return -1; // 有节点不可达
            }
        }
        
        // Step 2: 检测环
        vector<int> comp(n, -1);
        vector<int> vis(n, -1);
        int compCount = 0;
        
        for (int i = 0; i < n; i++) {
            if (comp[i] != -1) continue;
            
            int cur = i;
            while (cur != -1 && comp[cur] == -1) {
                if (vis[cur] == i) { // 找到环
                    int start = cur;
                    do {
                        comp[cur] = compCount;
                        cur = from[minIncoming[cur]];
                    } while (cur != start);
                    compCount++;
                    break;
                }
                
                vis[cur] = i;
                if (minIncoming[cur] == -1) {
                    comp[cur] = compCount++;
                    break;
                }
                cur = from[minIncoming[cur]];
            }
            
            if (cur == -1) continue;
            
            // 标记路径上的其他节点
            cur = i;
            while (cur != -1 && comp[cur] == -1) {
                comp[cur] = compCount++;
                cur = from[minIncoming[cur]];
            }
        }
        
        // 如果没有环，直接返回总成本
        if (compCount == n) {
            int total = 0;
            for (int i = 0; i < n; i++) {
                if (i != root) {
                    total += minCost[i];
                }
            }
            return total;
        }
        
        // Step 3: 缩点并构建新图
        vector<int> newFrom, newTo, newCost;
        
        // 添加跨组件边
        for (int i = 0; i < m; i++) {
            int u = from[i], v = to[i], c = cost[i];
            if (comp[u] == comp[v]) continue; // 组件内边跳过
            
            newFrom.push_back(comp[u]);
            newTo.push_back(comp[v]);
            // 关键：权值调整
            int adjustedCost = c;
            if (minIncoming[v] != -1) {
                adjustedCost -= minCost[v];
            }
            newCost.push_back(adjustedCost);
        }
        
        // 递归求解
        int newRoot = comp[root];
        int subCost = chuLiuEdmonds(newRoot, compCount, newFrom, newTo, newCost);
        if (subCost == -1) return -1;
        
        // 计算总成本
        int total = subCost;
        for (int i = 0; i < n; i++) {
            if (i != root && minIncoming[i] != -1) {
                total += minCost[i];
            }
        }
        return total;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    
    while (T--) {
        int N, M, C;
        cin >> N >> M >> C;
        
        vector<Edge> edges(M);
        vector<vector<int>> adj(N);
        
        int minB = INT_MAX, maxB = 0;
        
        for (int i = 0; i < M; i++) {
            cin >> edges[i].u >> edges[i].v >> edges[i].b >> edges[i].c;
            adj[edges[i].u].push_back(i);
            minB = min(minB, edges[i].b);
            maxB = max(maxB, edges[i].b);
        }
        
        // 二分答案
        int left = minB, right = maxB;
        int answer = -1;
        
        DirectedMST mst(N, edges, adj);
        
        // 检查最小带宽是否可行
        if (mst.solve(0, minB) == -1) {
            cout << "streaming not possible." << endl;
            continue;
        }
        
        // 二分查找最大可行带宽
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int cost = mst.solve(0, mid);
            if (cost != -1 && cost <= C) {
                answer = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        if (answer == -1) {
            cout << "streaming not possible." << endl;
        } else {
            cout << answer << " kbps" << endl;
        }
    }
    
    return 0;
}
```

## 总结

本题结合了二分查找和有向图最小生成树算法，主要难点在于：

1. **问题建模**：将实际问题转化为图论问题
2. **算法选择**：识别出需要使用朱刘算法
3. **实现细节**：朱刘算法的正确实现需要处理很多边界情况

关键成功因素包括：
- 在运行昂贵的朱刘算法前进行连通性检查
- 正确处理自环和重边
- 准确的权值调整计算

这个解决方案在题目约束下是高效的，能够正确处理最大规模的数据。
