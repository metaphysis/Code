## 题目描述

从前有一位睿智的老国王。他只有一个儿子。王子认为自己是未来的国王，因此变得日益懒惰。这使老国王有些担忧，因为他懒惰的儿子不适合继承王位。他夜不能寐，因为他的王国需要一位完美的国王，而不是懒惰的国王。

老国王日渐衰老。一天，他在处理日常事务时，想到了一个好主意。第二天，他召见儿子。他告诉王子，他希望王子拥有自己的王国。王子欣喜若狂。国王继续说，王子可以从国王的王国中获得一块土地，但他必须在日出后开始步行，并在日落前围成一个矩形区域。然后这块土地就会赐给王子。

懒惰的王子想：“这任务很简单！” 因此他想在国王的土地上找到面积最大的矩形。但王国中有一些岩石，王子不希望他的新领地里有任何岩石。他宁愿什么都不要，也不要岩石。

国王的王国可以看作一个 $m \times n$ 的网格，其中 $m$ 是行数，$n$ 是列数。网格中的每个单元格是一块面积为 $1$ 的小矩形。如果一块土地有岩石，则标记为 $1$，否则标记为 $0$。王子可以沿着单元格的边行走，他可以选择取用或忽略一个单元格，但不能只取单元格的一部分。现在你的任务是找到王子能覆盖的最大矩形面积。

## 输入格式

输入以一个整数 $T$（$T \leq 50$）开始，表示测试用例数量。

每个用例以一个空行开始。下一行包含两个整数 $m$ 和 $n$（$1 \leq m, n \leq 2000$），分别表示王国的行数和列数。

接下来的 $m$ 行，每行包含以下形式的整数：

$k \quad c \quad p_1 \quad p_2 \quad p_3 \quad \ldots \quad p_k$

表示在该行中，前 $p_1$ 列的类型为 $c$，接下来 $p_2$ 列的类型为 $c$ 的相反数，接下来 $p_3$ 列的类型为 $c$，以此类推。可以假设 $c$ 是 $0$ 或 $1$，$0$ 的相反数是 $1$，反之亦然。也可以假设 $p_1 + p_2 + \ldots + p_k = n$，且 $p_i > 0$。

## 输出格式

对于每个用例，输出一行 `Case X: Y`，其中 $X$ 是用例编号（从 $1$ 开始），$Y$ 是王子能覆盖的最大矩形面积。

## 题目分析

本题的核心是：在给定的 $m \times n$ 的 $0$-$1$ 矩阵中，找到所有元素均为 $0$ 的最大全 $0$ 子矩形的面积。

直接枚举所有可能的子矩形并检查是否全 $0$，时间复杂度为 $O(m^3 n^3)$，显然不可接受。即使利用前缀和优化到 $O(m^2 n^2)$，在 $m, n \leq 2000$ 时仍然会超时。

输入采用游程编码（$\texttt{Run-Length Encoding}$）格式，需要先将编码解码为完整的矩阵。由于 $m \times n \leq 4 \times 10^6$，可以直接存储整个矩阵。

经典的求解最大全 $0$ 子矩形问题可以在 $O(m n)$ 时间内解决，这依赖于一个巧妙的转化：将问题转化为**在每一行上求解直方图的最大矩形面积**。

## 解题思路

### 转化为直方图问题

对于矩阵中的每一行，我们可以定义一个高度数组 $\textit{height}[j]$，表示从当前行向上连续 $0$ 的个数（即当前格子是 $0$ 时高度加 $1$，遇到 $1$ 时高度重置为 $0$）。这样，每一行及其上方的部分就形成了一个直方图，其中第 $j$ 列的柱子的高度为 $\textit{height}[j]$。

问题转化为：对于每一行形成的直方图，找出最大的矩形面积。所有行中得到的最大值即为答案。

### 直方图最大矩形面积的单调栈解法

对于一个直方图，要找到面积最大的矩形，等价于：对于每个柱子，找到它左边和右边第一个高度小于它的柱子，那么以该柱子高度为高的最大矩形宽度就是这两个边界之间的距离。

我们可以使用单调栈在 $O(n)$ 时间内完成：

1. **计算左边界**：从左到右遍历，维护一个单调递增栈（存储柱子下标）。对于当前位置 $j$，不断弹出栈顶高度大于等于 $\textit{height}[j]$ 的元素，弹出后栈顶元素的下标即为左边第一个小于 $\textit{height}[j]$ 的位置（若栈为空，则左边界为 $0$），左边界为该位置 $+1$。
2. **计算右边界**：从右到左遍历，类似地找到右边第一个小于 $\textit{height}[j]$ 的位置（若栈为空，则右边界为 $n-1$），右边界为该位置 $-1$。
3. **计算面积**：对于每个 $j$，面积为 $\textit{height}[j] \times (\textit{right}[j] - \textit{left}[j] + 1)$，更新全局最大值。

### 整体算法流程

1. 读入 $T$，对每个测试用例：
2. 读入 $m, n$，根据游程编码解码得到完整的 $m \times n$ 矩阵。
3. 初始化高度数组 $\textit{height}[n]$ 全为 $0$。
4. 逐行处理：
   - 更新高度数组：若当前格子为 $0$，则高度加 $1$；否则高度重置为 $0$。
   - 对该行的高度数组使用单调栈计算最大矩形面积，并更新全局答案。
5. 输出结果。

### 正确性说明

- 高度数组 $\textit{height}[j]$ 准确记录了从当前行向上连续 $0$ 的个数，因此当前行及上方形成的直方图反映了所有以当前行为底边的全 $0$ 子矩阵的高度信息。
- 单调栈算法能正确找出每个柱子左右第一个比它矮的柱子，从而保证不会遗漏任何可能的矩形。
- 遍历所有行后，一定能找到全局最大的全 $0$ 子矩形。

### 复杂度分析

- 解码矩阵：需要遍历所有 $m \times n$ 个格子，时间复杂度 $O(m n)$。
- 逐行处理：
  - 更新高度数组：$O(n)$。
  - 单调栈计算：$O(n)$。
  - 每行总复杂度 $O(n)$，共 $m$ 行，故 $O(m n)$。
- 总时间复杂度：$O(m n)$。
- 空间复杂度：存储矩阵需要 $O(m n)$，高度数组和辅助栈需要 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve(int caseNum) {
    int m, n;
    scanf("%d %d", &m, &n);
    
    // 解码矩阵
    vector<vector<int>> mat(m, vector<int>(n, 0));
    for (int i = 0; i < m; ++i) {
        int k, c;
        scanf("%d %d", &k, &c);
        int col = 0;
        int current = c; // 当前块的值
        for (int j = 0; j < k; ++j) {
            int p;
            scanf("%d", &p);
            for (int t = 0; t < p; ++t) {
                mat[i][col++] = current;
            }
            current = 1 - current; // 切换值
        }
    }
    
    vector<int> height(n, 0); // 每列向上连续0的高度
    int maxArea = 0;
    
    for (int i = 0; i < m; ++i) {
        // 更新高度数组
        for (int j = 0; j < n; ++j) {
            if (mat[i][j] == 0) height[j] = height[j] + 1;
            else height[j] = 0;
        }
        
        // 单调栈求每行的最大矩形面积
        vector<int> left(n), right(n);
        stack<int> st;
        
        // 计算左边界（左边第一个比当前高度小的位置）
        for (int j = 0; j < n; ++j) {
            while (!st.empty() && height[st.top()] >= height[j]) st.pop();
            left[j] = st.empty() ? 0 : st.top() + 1;
            st.push(j);
        }
        
        while (!st.empty()) st.pop();
        
        // 计算右边界（右边第一个比当前高度小的位置）
        for (int j = n - 1; j >= 0; --j) {
            while (!st.empty() && height[st.top()] >= height[j]) st.pop();
            right[j] = st.empty() ? n - 1 : st.top() - 1;
            st.push(j);
        }
        
        // 计算面积并更新最大值
        for (int j = 0; j < n; ++j) {
            int area = height[j] * (right[j] - left[j] + 1);
            if (area > maxArea) maxArea = area;
        }
    }
    
    printf("Case %d: %d\n", caseNum, maxArea);
}

int main() {
    int T;
    scanf("%d", &T);
    for (int t = 1; t <= T; ++t) {
        solve(t);
    }
    return 0;
}
```

## 总结

本题是经典的最大全 $0$ 子矩形问题的变体，主要考察以下知识点：

1. **问题转化**：将二维矩阵的最大全 $0$ 子矩形问题转化为一维直方图的最大矩形面积问题，这是解决此类问题的常用技巧。
2. **单调栈的应用**：单调栈可以在 $O(n)$ 时间内解决直方图最大矩形面积问题，其核心思想是找到每个柱子左右两侧第一个比它矮的位置。
3. **游程编码解码**：输入采用压缩格式，需要正确解码为原始矩阵。解码时通过交替切换当前块的值即可。
4. **时间复杂度优化**：$O(m n)$ 的解法能够处理 $2000 \times 2000$ 的数据规模，体现了算法设计对效率的追求。

**技巧总结**：
- 遇到子矩形问题，可优先考虑转化为直方图问题。
- 单调栈常用于处理“寻找左右第一个更小/更大元素”的问题。
- 解码压缩输入时，注意边界条件和状态切换的正确性。
