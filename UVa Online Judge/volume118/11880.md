[UVa 11880 Ball in a Rectangle](https://blog.csdn.net/metaphysis/article/details/157354117)

## 题目描述

在笛卡尔平面上有一个矩形，左下角位于 $(0,0)$ ，右上角位于 $(L,W)$ 。有一个球，圆心位于 $(x,y)$ ，半径为 $R$ 。在时刻 $0$ ，球开始沿着一条极角为 $a$ （从正 $x$ 轴逆时针旋转到射线的角度）的射线运动。当球碰到矩形边界时，反射角等于入射角（完全弹性反射）。球的速度始终保持为 $v$ （碰撞后速度大小不变）。求在时刻 $s$ 时，球的圆心位于何处？

### 输入格式

最多 $25$ 组测试用例，每行包含 $8$ 个整数： $L,W,x,y,R,a,v,s$ （ $100 \le L,W \le 10^9$ ， $1 \le R \le 5$ ， $R \le x \le L - R$ ， $R \le y \le W - R$ ， $0 \le a < 360$ ， $1 \le v$ ， $s \le 10^9$ ）。输入以 $L = W = x = y = R = a = v = s = 0$ 结束，不处理该行。

### 输出格式

对于每个测试用例，输出一行，包含两个保留两位小数的浮点数 $x$ 和 $y$ ，表示在时刻 $s$ 时球的圆心位置。

### 样例输入

```
100 100 80 10 5 90 2 23
110 100 70 10 5 180 1 9999
0 0 0 0 0 0 0 0
```

### 样例输出

```
80.00 56.00
71.00 10.00
```

## 题目分析

本题要求计算一个在矩形内做完全弹性反射运动的小球在给定时间后的位置。这是一个经典的**反射运动**问题，通常可以通过**反射法**（也称为镜像法）来高效求解，避免直接模拟时间步长（ $v$ 和 $s$ 可能高达 $10^9$ ，直接模拟会超时）。

### 关键点

1. **球的半径 $R$ 的处理** ：由于球有半径，且题目保证初始时球心位于 $[R, L-R] \times [R, W-R]$ 内，因此球的运动可以等价为一个**点**在缩小的矩形 $[R, L-R] \times [R, W-R]$ 内的反射运动。我们只需考虑这个点的运动，最后将坐标加回 $R$ 即可。
2. **反射法原理** ：将矩形沿边界无限反射展开，则点的运动在无界空间中对应一条直线。这条直线上的运动是匀速直线运动，很容易计算任意时刻的位置。然后，通过周期性和对称性，可以将无界空间中的坐标映射回原始矩形。
3. **映射公式** ：设有效宽度 $L_x = L - 2R$ ，有效高度 $L_y = W - 2R$ 。无界空间中水平坐标 $x'$ 映射回有效区间的过程如下：
   - 计算 $x'$ 对 $2L_x$ 取模，将其归化到 $[0, 2L_x)$ 。
   - 若归化后的值大于 $L_x$ ，则说明当前处于镜像区域，需要对称映射回 $[0, L_x]$ ，即 $x_{\text{final}} = 2L_x - x'$ 。
   - 垂直方向同理。
4. **初始位置调整** ：由于有效区域是 $[R, L-R]$ ，我们先将初始球心坐标减去 $R$ ，使其在 $[0, L_x] \times [0, L_y]$ 内运动，处理完反射后再加回 $R$ 。

### 算法步骤

1. 读入 $L, W, x, y, R, a, v, s$ 。
2. 若全为 $0$ ，则结束。
3. 计算有效宽度 $L_x = L - 2R$ 和有效高度 $L_y = W - 2R$ 。
4. 将角度 $a$ 转换为弧度： $rad = a \times \pi / 180$ 。
5. 计算速度分量： $dx = v \times \cos(rad)$ ， $dy = v \times \sin(rad)$ 。
6. 计算无界空间中的位置：
   - $tx = (x - R) + dx \times s$
   - $ty = (y - R) + dy \times s$
7. 通过反射映射将 $tx$ 归化到 $[0, L_x]$ ， $ty$ 归化到 $[0, L_y]$ 。
8. 最终球心坐标： $(x_{\text{final}}, y_{\text{final}}) = (tx + R, ty + R)$ 。
9. 输出保留两位小数的结果。

### 时间复杂度

每个测试用例仅需常数时间计算，总时间复杂度 $O(1)$ 每组，足以处理最大 $25$ 组数据。

## 代码实现

```cpp
// Ball in a Rectangle
// UVa ID: 11880
// Verdict: Accepted
// Submission Date: 2026-01-25
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);

double normalize(double pos, double length) {
    // 将pos映射到[0, 2*length]内
    pos = fmod(pos, 2 * length);
    if (pos < 0) pos += 2 * length;
    // 对称映射到[0, length]
    if (pos > length) pos = 2 * length - pos;
    return pos;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout << fixed << setprecision(2);

    int L, W, R, a, v, s;
    double x, y;
    while (cin >> L >> W >> x >> y >> R >> a >> v >> s) {
        if (L == 0 && W == 0 && x == 0 && y == 0 && R == 0 && a == 0 && v == 0 && s == 0) break;

        double rad = a * PI / 180.0;
        double dx = v * cos(rad);
        double dy = v * sin(rad);

        // 有效运动区域
        double Lx = L - 2 * R;
        double Ly = W - 2 * R;

        // 无界空间中的位置
        double tx = x - R + dx * s;
        double ty = y - R + dy * s;

        // 映射回有效区域
        double px = normalize(tx, Lx);
        double py = normalize(ty, Ly);

        // 加回半径偏移
        double finalX = px + R;
        double finalY = py + R;

        cout << finalX << " " << finalY << "\n";
    }
    return 0;
}
```

## 总结

本题是一道经典的几何与运动学结合的问题，通过反射法将有限区域内的反射运动转化为无限平面上的直线运动，从而简化计算。关键在于理解如何将坐标通过周期性和对称性映射回原始区域，并正确处理半径带来的偏移。这种方法不仅高效，而且代码简洁，适合处理大范围数据。
