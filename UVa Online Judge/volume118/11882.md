## 题目描述

你有一个包含障碍物和非零数字的迷宫。你可以从任意一个格子出发，在迷宫中行走，每一步只能向上下左右四个方向移动，且不能进入障碍物或重复经过同一个格子。当你停止时，将经过的数字按顺序连接起来，就得到了一个数字。你的任务是找出能够得到的最大数字。

**输入格式**

- 包含最多 $25$ 组测试数据。
- 每组数据以两个整数 $R$ 和 $C$ 开始 ($2 \leq R, C \leq 15$, $R \times C \leq 30$)，表示迷宫的行数和列数。
- 接下来 $R$ 行，每行包含 $C$ 个字符，字符为 `#`（表示障碍）或 `1`~`9`（表示数字）。
- 输入以 $R = 0$ 且 $C = 0$ 结束。

**输出格式**

- 对于每组测试数据，输出能够得到的最大数字。

**样例输入**
```
3 7
##9784#
##123##
##45###
0 0
```

**样例输出**
```
791452384
```

## 题目分析与解题思路

### 问题分析

这是一个在网格上的路径搜索问题，要求找到一条不重复访问且不经过障碍物的路径，使得路径上数字连接形成的数字最大。由于 $R \times C \leq 30$，网格规模较小，但直接暴力搜索所有可能的路径仍然不可行，因为路径数量是指数级的。

### 关键观察

1. **数字比较规则**：比较两个数字时，首先比较长度（位数多的更大），长度相同时按字典序比较。
2. **搜索空间剪枝**：需要通过有效的剪枝策略减少搜索空间。

### 解题思路

#### 1. 深度优先搜索（$\texttt{DFS}$）

从每个非障碍格子出发，使用 $\texttt{DFS}$ 探索所有可能的路径。在搜索过程中维护当前路径形成的数字字符串。

#### 2. 剪枝策略

这是算法效率的关键，包含两种主要剪枝：

**剪枝一：长度剪枝**

- 计算从当前位置出发还能访问的格子数量（使用 $\texttt{floodFill}$）。
- 如果 `当前路径长度 + 剩余可访问格子数 - 1 < 当前最佳数字长度`，则剪枝。
- **注意**：这里要减 $1$ 是因为 $\texttt{floodFill}$ 统计了当前位置，但当前位置已经在当前路径中。

**剪枝二：字典序剪枝**

- 如果 `当前路径长度 + 剩余可访问格子数 - 1 == 当前最佳数字长度`，构造理论最大值进行比较。
- 理论最大值 = 当前路径 + 剩余所有数字按降序排列。
- 如果理论最大值仍小于当前最佳数字，则剪枝。
- 实际实现中使用 `当前路径 + "z"` 作为理论最大值的上界，因为 `'z'` 的 ASCII 码大于 `'9'`。

#### 3. 算法流程

1. 初始化最佳数字为空字符串。
2. 对于每个非障碍格子作为起点：
   - 标记该格子已访问。
   - 调用 $\texttt{DFS}$ 进行搜索。
   - 回溯，取消该格子的访问标记。
3. 在 $\texttt{DFS}$ 中：
   - 更新当前路径。
   - 检查剪枝条件。
   - 更新最佳数字。
   - 向四个方向递归搜索。
4. 输出最佳数字。

### 复杂度分析

- 最坏情况下需要搜索所有路径，但由于有效的剪枝策略，实际运行效率很高。
- 空间复杂度为 $O(R \times C)$，主要用于存储访问状态。

## 代码实现

```cpp
// Biggest Number
// UVa ID: 11882
// Verdict: Accepted
// Submission Date: 2025-11-09
// UVa Run Time: 0.120s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 全局变量定义
int rowCount, colCount;          // 迷宫的行数和列数
char grid[20][20];               // 存储迷宫网格
int deltaX[4] = {0, 0, 1, -1};   // 四个方向的x偏移量
int deltaY[4] = {1, -1, 0, 0};   // 四个方向的y偏移量
int reachableCount;              // 记录可达格子数量
bool visited[20][20];            // 记录DFS访问状态
bool tempVisited[20][20];        // 临时访问状态，用于floodFill
string bestNumber, currentString; // 最佳数字和当前字符串

// 洪水填充算法，计算从(x,y)出发能到达的格子数量
void floodFill(int x, int y) {
    reachableCount++;                    // 统计当前格子
    tempVisited[x][y] = 1;               // 标记为已访问
    for (int i = 0; i < 4; i++) {        // 遍历四个方向
        int nextX = x + deltaX[i];
        int nextY = y + deltaY[i];
        // 边界检查
        if (nextX < 1 || nextX > rowCount || nextY < 1 || nextY > colCount) continue;
        // 访问检查
        if (tempVisited[nextX][nextY]) continue;
        // 障碍物检查
        if (grid[nextX][nextY] == '#') continue;
        floodFill(nextX, nextY);         // 递归填充
    }
}

// 深度优先搜索函数
void dfs(int x, int y, string currentPath, int pathLength) {
    // 计算剩余可达格子数
    reachableCount = 0;
    memcpy(tempVisited, visited, sizeof(visited)); // 复制当前访问状态
    floodFill(x, y);
    
    // 剪枝1：长度不可能超过当前最佳数字
    if (pathLength + reachableCount - 1 < bestNumber.size()) return;
    
    // 剪枝2：长度相等但字典序不可能更大
    // 使用"z"作为占位符，因为'z' > '9'（ASCII码比较）
    if (pathLength + reachableCount - 1 == bestNumber.size() && bestNumber > currentPath + "z") return;
    
    // 更新最佳数字
    if (pathLength > bestNumber.size() || (pathLength == bestNumber.size() && currentPath > bestNumber)) 
        bestNumber = currentPath;
    
    // 向四个方向继续搜索
    for (int i = 0; i < 4; i++) {
        int nextX = x + deltaX[i];
        int nextY = y + deltaY[i];
        // 边界检查
        if (nextX < 1 || nextX > rowCount || nextY < 1 || nextY > colCount) continue;
        // 访问检查
        if (visited[nextX][nextY]) continue;
        // 障碍物检查
        if (grid[nextX][nextY] == '#') continue;
        
        // 递归搜索
        visited[nextX][nextY] = 1;
        dfs(nextX, nextY, currentPath + grid[nextX][nextY], pathLength + 1);
        visited[nextX][nextY] = 0; // 回溯
    }
}

int main() {
    while (1) {
        scanf("%d %d", &rowCount, &colCount);
        if (rowCount == 0 && colCount == 0) return 0; // 输入结束
        
        bestNumber = ""; // 重置最佳数字
        // 读入迷宫
        for (int i = 1; i <= rowCount; i++) 
            scanf("%s", grid[i] + 1);
        
        // 从每个非障碍格子出发进行搜索
        for (int i = 1; i <= rowCount; i++) {
            for (int j = 1; j <= colCount; j++) {
                currentString = grid[i][j]; // 当前起始字符
                if (grid[i][j] != '#') {    // 非障碍格子
                    memset(visited, 0, sizeof(visited)); // 重置访问状态
                    visited[i][j] = 1;      // 标记起点为已访问
                    dfs(i, j, currentString, 1); // 开始DFS
                }
            }
        }
        
        cout << bestNumber << endl; // 输出结果
    }
}
```

## 总结

本题通过深度优先搜索配合巧妙的剪枝策略，有效地解决了在迷宫中寻找最大数字的问题。关键的剪枝技巧包括基于连通性的长度剪枝和基于字典序的理论最大值剪枝，这些策略显著减少了搜索空间，使算法能够在合理时间内解决问题。

这个解法展示了在搜索问题中，合理的剪枝策略对于提高算法效率的重要性，同时也体现了对问题特性的深入理解如何转化为有效的优化手段。
