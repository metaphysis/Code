[UVa 11903 e-Friends](https://blog.csdn.net/metaphysis/article/details/160555498)

## 题目描述

在社交网络中，有 $n$ 个人（编号 $1$ 到 $n$），每个人可以认为其他某些人是他的敌人（关系不一定是相互的）。现在要求这些人排成一个队列，如果 $x$ 认为 $y$ 是他的敌人，并且 $y$ 恰好排在 $x$ 的前面一位（即 $y$ 的位置是 $i-1$，$x$ 的位置是 $i$），则产生一次不满。每次不满的代价为 $k$，总不满指数 = 不满次数 × $k$。对于每个查询，给定一个允许的最大总不满指数 $r$，求有多少种排列使得总不满指数不超过 $r$。

### 输入格式

- 第一行：测试用例数 $T$（$T \le 30$）
- 每个测试用例：
  - 第一行：$n, k, q$（$1 \le n \le 12$，$0 \le k \le 10^6$，$1 \le q \le 1000$）
  - 接下来 $n$ 行，第 $i$ 行：$t_i$ 和 $t_i$ 个敌人编号
  - 接下来 $q$ 行：每行一个整数 $r$（$0 \le r \le 10^8$）

### 输出格式

对于每个测试用例，先输出 `Case X:` 然后换行，接着输出 $q$ 行，每行一个整数表示答案。

### 样例输入

```
1
2 10 2
1 2
0
10
5
```

### 样例输出
```
Case 1:
2
1
```

解释：$n = 2$，$k = 10$。第 $1$ 个人认为第 $2$ 个人是敌人。所有排列：
- $(1, 2)$：第 $2$ 个人排在第 $1$ 个人后面，检查第 $2$ 个人是否认为第 $1$ 个人是敌人？第 $2$ 个人没有敌人，所以不满次数 $= 0$，总不满指数 $= 0$
- $(2, 1)$：第 $1$ 个人在第 $2$ 个人后面，第 $1$ 个人认为第 $2$ 个人是敌人，所以不满次数 $= 1$，总不满指数 $= 10$

查询 $r = 10$：总不满指数 $\le 10$ 的排列有 $(1,2)$ 和 $(2,1)$，共 $2$ 种  
查询 $r = 5$：总不满指数 $\le 5$ 的排列只有 $(1,2)$，共 $1$ 种

## 题目分析

### 关键点

1. **$n$ 的范围很小**：$n \le 12$，这提示我们可以使用状态压缩动态规划（$\texttt{DP}$）或者枚举排列。
2. **不满次数的范围有限**：队列长度为 $n$，相邻位置有 $n-1$ 对，因此不满次数最大为 $n-1 \le 11$。这意味着我们可以在状态中记录不满次数。
3. **$k$ 可能为 $0$**：当 $k = 0$ 时，不满指数始终为 $0$，任何 $r \ge 0$ 都满足条件，答案就是 $n!$。
4. **多个查询**：$q$ 最多为 $1000$，我们可以预处理所有不满次数的排列数量，然后对每个查询 $O(1)$ 或 $O(\log n)$ 回答。

### 暴力方法不可行

如果直接枚举所有排列，$12! = 479001600$，约 $4.79 \times 10^8$，在时间上不可接受（尤其是在 $T$ 可以达到 $30$ 的情况下）。

### 状态压缩 $\texttt{DP}$ 的思路

我们考虑逐步构造队列：

- 已经放置了哪些人？用二进制掩码 `mask` 表示（`mask` 的第 $i$ 位为 $1$ 表示第 $i$ 个人已经在队列中）
- 队列的最后一个人是谁？用 `last` 表示（$0$ 到 $n-1$）
- 当前已经产生了多少次不满？用 `cnt` 表示

于是我们可以定义：

$$
dp[mask][last][cnt] = \text{已经放置了 mask 中的人，最后一个人是 last，恰好产生了 cnt 次不满的排列数}
$$

### 状态转移

当我们从状态 `(mask, last, cnt)` 出发，尝试在队列末尾添加一个新人 `nxt`（`nxt` 不在 `mask` 中）：

- 新的掩码：`newMask = mask | (1 << nxt)`
- 新的最后一个人：`nxt`
- 新的不满次数：`newCnt = cnt + (isEnemy[nxt][last] ? 1 : 0)`

因为 `nxt` 现在是队尾，它前面的人是 `last`。检查 `nxt` 是否认为 `last` 是敌人，如果是，则新增一次不满。

转移方程：

$$
dp[newMask][nxt][newCnt] += dp[mask][last][cnt]
$$

### 初始化

任何一个单独的人都可以作为队列的第一个人，此时不满次数为 $0$：

$$
dp[1 << i][i][0] = 1, \quad \forall i \in [0, n-1]
$$

### 最终统计

当所有 $n$ 个人都放置完毕，即 `mask = (1 << n) - 1` 时，对最后一个人 `last` 求和，得到不满次数恰好为 `cnt` 的总排列数：

$$
\text{count}[cnt] = \sum_{last=0}^{n-1} dp[fullMask][last][cnt]
$$

### 回答查询

- 如果 $k = 0$：不满指数始终为 $0$，只要 $r \ge 0$，所有排列都满足，答案为 $n!$
- 如果 $k > 0$：允许的最大不满次数为 $\lfloor r / k \rfloor$。如果这个值 $\ge n-1$，则所有排列都满足；否则，答案为 $\sum_{c=0}^{\lfloor r/k \rfloor} \text{count}[c]$

我们可以预处理 `count` 的前缀和数组 `prefix`，使得：
$$
prefix[x] = \sum_{c=0}^{x-1} \text{count}[c]
$$
则答案为 `prefix[最多允许的不满次数 + 1]`。

---

## 复杂度分析

- 状态总数：$O(2^n \cdot n \cdot n) = O(2^n \cdot n^2)$，当 $n = 12$ 时，$2^{12} \times 12^2 = 4096 \times 144 \approx 5.9 \times 10^5$
- 每个状态的转移：枚举 $n$ 个新人，总转移数 $O(2^n \cdot n^3) \approx 4096 \times 1728 \approx 7 \times 10^6$，完全可行
- 空间复杂度：$O(2^n \cdot n^2)$，存储 `dp` 数组需要 $4096 \times 12 \times 12 \times 8 \text{ 字节} \approx 4.7 \text{ MB}$，加上其他辅助数组，仍在合理范围内

---

## 注意事项

1. **敌人关系存储**：输入中的编号是 $1$-based，内部处理时转为 $0$-based，方便位运算。
2. **$k = 0$ 的特殊处理**：如果不特殊处理，`r / k` 会导致除以零错误。
3. **数据类型**：排列数量可能很大（$12! = 479001600$），但仍在 $32$ 位整数范围内。不过为了保险和扩展，使用 `long long`。
4. **输出格式**：每个测试用例先输出 `Case X:` 然后换行，接着每个查询结果独占一行。

## 代码实现

```cpp
// e-Friends
// UVa ID: 11903
// Verdict: Accepted
// Submission Date: 2026-04-27
// UVa Run Time: 0.080s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        int n, k, q;
        cin >> n >> k >> q;
        
        // 敌人关系矩阵，isEnemy[i][j] 表示 i 认为 j 是敌人
        vector<vector<bool>> isEnemy(n, vector<bool>(n, false));
        for (int i = 0; i < n; ++i) {
            int t;
            cin >> t;
            for (int j = 0; j < t; ++j) {
                int enemy;
                cin >> enemy;
                isEnemy[i][enemy - 1] = true;  // 转为 0-based
            }
        }
        
        int fullMask = (1 << n) - 1;
        int maxCnt = n - 1;  // 最多 n-1 次不满
        
        // dp[mask][last][cnt]
        vector<vector<vector<long long>>> dp(1 << n, vector<vector<long long>>(n, vector<long long>(maxCnt + 1, 0)));
        
        // 初始化：每个人作为第一个
        for (int i = 0; i < n; ++i)
            dp[1 << i][i][0] = 1;
        
        // DP 转移
        for (int mask = 1; mask <= fullMask; ++mask) {
            for (int last = 0; last < n; ++last) {
                if (!(mask & (1 << last))) continue;
                for (int cnt = 0; cnt <= maxCnt; ++cnt) {
                    long long ways = dp[mask][last][cnt];
                    if (ways == 0) continue;
                    for (int nxt = 0; nxt < n; ++nxt) {
                        if (mask & (1 << nxt)) continue;
                        int newCnt = cnt + (isEnemy[nxt][last] ? 1 : 0);
                        if (newCnt > maxCnt) continue;
                        dp[mask | (1 << nxt)][nxt][newCnt] += ways;
                    }
                }
            }
        }
        
        // 统计每种不满次数的总排列数
        vector<long long> cntArr(maxCnt + 1, 0);
        for (int last = 0; last < n; ++last)
            for (int c = 0; c <= maxCnt; ++c)
                cntArr[c] += dp[fullMask][last][c];
        
        // 预处理前缀和
        vector<long long> prefix(maxCnt + 2, 0);
        for (int c = 0; c <= maxCnt; ++c)
            prefix[c + 1] = prefix[c] + cntArr[c];
        
        // 计算 n!
        long long fact = 1;
        for (int i = 2; i <= n; ++i) fact *= i;
        
        cout << "Case " << caseNo << ":\n";
        
        for (int queryIdx = 0; queryIdx < q; ++queryIdx) {
            int r;
            cin >> r;
            
            if (k == 0) {
                cout << fact << "\n";
                continue;
            }
            
            int maxAllowedCnt = r / k;
            if (maxAllowedCnt >= maxCnt) {
                cout << fact << "\n";
            } else {
                cout << prefix[maxAllowedCnt + 1] << "\n";
            }
        }
    }
    
    return 0;
}
```

## 总结

本题的核心是利用 $n$ 很小的特点，使用状态压缩动态规划预处理所有排列的不满次数分布，然后对每个查询 $O(1)$ 回答。关键在于：

- 设计合适的状态 `(mask, last, cnt)`
- 正确理解不满的判定条件：新加入的人是否认为前一个人是敌人
- 处理 $k = 0$ 的边界情况

这种方法在 $n \le 12$ 时运行效率很高，足以通过所有测试数据。
