## 题目描述

$\texttt{OUM(One Unit Machine)}$ 是一种处理作业的单单元机器。由于它无法处理重量级作业，作业需要被分割成多个单元。初始时，所有作业信息和单元划分作为输入给出。然后机器分配必要的时间槽。在每个时间槽中，它向用户询问要处理的作业名称。获取名称后，机器确定该作业的下一个未处理单元，并在该时间槽中处理该单元。如果没有这样的单元，机器崩溃。如果一个作业的所有单元都完成，则该作业完成。

$\texttt{Sam}$ 有 $n$ 个作业要用 $\texttt{OUM}$ 完成。他希望按顺序完成作业，即 $Job_i$ 在 $Job_{i+1}$ 之前完成，其中 $1 \leq i < n$。他想知道有多少种方式可以在不导致 $\texttt{OUM}$ 崩溃的情况下完成这些作业。

## 输入格式

- 第一行：$T$（$\leq 100$）表示测试用例数
- 每个用例以一个整数 $n$（$1 \leq n \leq 1000$）开始
- 下一行包含 $n$ 个正整数 $k_1, k_2, \dots, k_n$，表示每个作业的单元数
- 所有用例的总单元数不超过 $10^6$

## 输出格式

对于每个用例，输出用例编号和结果对 $1000000007$ 取模的值。

## 题目分析

### 问题理解

我们需要计算满足以下条件的序列数量：

1. 每个作业 $i$ 有 $k_i$ 个单元，必须按顺序完成
2. 序列总长度为所有 $k_i$ 之和
3. 在任意时刻，不能尝试处理一个作业的不存在的单元
4. 作业必须按顺序完成：$Job_i$ 的所有单元必须在 $Job_{i+1}$ 的任何单元之前完成

关键约束是：**$Job_i$ 的最后一个单元必须在 $Job_{i+1}$ 的第一个单元之前**

### 组合数学解法

这是一个经典的组合数学问题。我们可以使用动态规划和组合数来求解。

**核心思路：**

- 设 $dp[i]$ 表示前 $i$ 个作业的有效序列数
- 初始状态：$dp[0] = 1$（没有作业时只有一种空序列）
- 对于第 $i$ 个作业，设前 $i$ 个作业的总单元数为 $S_i = \sum_{j=1}^i k_j$
- 转移方程：$dp[i] = dp[i-1] \times C(S_i - 1, k_i - 1)$

**为什么这个公式成立？**

当我们添加第 $i$ 个作业时：
- 已有前 $i-1$ 个作业的序列，长度为 $S_{i-1}$
- 需要将第 $i$ 个作业的 $k_i$ 个单元插入到总序列中
- 由于 $Job_i$ 必须在 $Job_{i+1}$ 之前完成（这里 $i+1$ 还没加入），实际上我们只需要保证 $Job_i$ 的最后一个单元放在序列的最后位置
- 因此，我们固定第 $i$ 个作业的最后一个单元在总序列的最后一个位置
- 剩下的 $k_i - 1$ 个单元可以插入到前 $S_i - 1$ 个位置中的任意位置
- 插入方式的数量就是组合数 $C(S_i - 1, k_i - 1)$

### 验证样例

**样例 1：** $n=2, k=[2,2]$

- $S_1 = 2$, $dp[1] = 1 \times C(1,1) = 1$
- $S_2 = 4$, $dp[2] = 1 \times C(3,1) = 3$ ✓

**样例 2：** $n=3, k=[2,2,3]$

- $S_1 = 2$, $dp[1] = 1 \times C(1,1) = 1$
- $S_2 = 4$, $dp[2] = 1 \times C(3,1) = 3$
- $S_3 = 7$, $dp[3] = 3 \times C(6,2) = 3 \times 15 = 45$ ✓

## 算法实现

### 技术要点

1. **模运算**：结果需要对 $1000000007$ 取模
2. **组合数计算**：需要预处理阶乘和逆元来快速计算组合数
3. **大数处理**：总单元数最多 $10^6$，需要高效算法

### 复杂度分析

- 预处理阶乘和逆元：$O(MAX)$，其中 $MAX = 10^6$
- 每个测试用例：$O(n)$
- 总复杂度：$O(MAX + \sum n)$，在题目限制内可行

## 代码实现

```cpp
// One Unit Machine
// UVa ID: 11904
// Verdict: Accepted
// Submission Date: 2025-11-17
// UVa Run Time: 0.020s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;
const int MAX = 1000000;

long long fact[MAX + 1], invFact[MAX + 1];

long long modPow(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

void precompute() {
    fact[0] = 1;
    for (int i = 1; i <= MAX; i++)
        fact[i] = fact[i - 1] * i % MOD;
    invFact[MAX] = modPow(fact[MAX], MOD - 2);
    for (int i = MAX - 1; i >= 0; i--)
        invFact[i] = invFact[i + 1] * (i + 1) % MOD;
}

long long nCr(int n, int r) {
    if (r < 0 || r > n) return 0;
    return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
}

int main() {
    precompute();
    int T;
    cin >> T;
    for (int caseNum = 1; caseNum <= T; caseNum++) {
        int n;
        cin >> n;
        vector<int> k(n);
        for (int i = 0; i < n; i++)
            cin >> k[i];
        long long res = 1;
        int total = 0;
        for (int i = 0; i < n; i++) {
            total += k[i];
            res = res * nCr(total - 1, k[i] - 1) % MOD;
        }
        cout << "Case " << caseNum << ": " << res << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于将作业完成的顺序约束转化为组合数学问题。通过固定每个作业的最后一个单元位置，我们可以将问题分解为独立的组合数计算，从而高效求解。预处理阶乘和逆元使得组合数计算可以在常数时间内完成，保证了算法的高效性。

这种将约束条件转化为组合数学模型的方法在编程竞赛中很常见，掌握这种思维方式对于解决类似问题非常有帮助。
