[11920 0s 1s and ? Marks](https://blog.csdn.net/metaphysis/article/details/155420543)

## 题目描述

给定一个仅包含字符 `0`、`1` 和 `?` 的字符串，将所有 `?` 替换为 `0` 或 `1`，使得最大连续相同字符组的长度最小化。一个组是指一个全部由 `0` 或全部由 `1` 组成的连续子串。

**输入格式**  
第一行输入是一个整数 $T$（$T \leq 5000$），表示测试用例的数量。每个测试用例是一行包含 `0`、`1` 和 `?` 的字符串。字符串长度在 $[1, 1000]$ 范围内。

**输出格式**  
对于每个测试用例，首先输出用例编号，然后输出最小化后的最大组大小。

### 样例输入
```
4
011?01???
???
000111
00000000000000
```

### 样例输出
```
Case 1: 2
Case 2: 1
Case 3: 3
Case 4: 14
```

## 题目分析

### 问题理解

我们需要将字符串中的所有 `?` 替换为 `0` 或 `1`，目标是**最小化最长连续相同字符段的长度**。换句话说，我们希望让字符串中连续的 `0` 或 `1` 尽可能短，避免出现很长的连续相同字符段。

### 关键观察

1. **固定字符段的约束**：字符串中已有的 `0` 和 `1` 段无法改变，它们的最小长度就是答案的下界。

2. **问号段的作用**：`?` 段可以作为"缓冲器"，帮助我们打断长的连续相同字符段。

3. **分段处理策略**：将连续的相同字符合并处理可以简化问题：
   - 连续的 `0` 组成一个段
   - 连续的 `1` 组成一个段  
   - 连续的 `?` 组成一个段

4. **问号段的填充策略**：
   - 如果问号段前后的字符**相同**：
     - 问号个数为**奇数**：可以完美交替填充，连接前后段
     - 问号个数为**偶数**：会产生一个额外的相同字符，可能形成长度为 $2$ 的段
   - 如果问号段前后的字符**不同**：
     - 问号个数为**偶数**：可以完美交替，不会延长任何一侧
     - 问号个数为**奇数**：特别是单个问号时，需要选择延长较短的一侧

### 解题思路

1. **预处理**：将输入字符串分段，记录每段的类型和长度。

2. **处理固定段**：对于 `0` 或 `1` 段，直接取其长度作为候选答案。

3. **处理问号段**：
   - 边界问号段（开头或结尾）对答案影响较小，可以忽略
   - 中间问号段根据前后字符关系分类处理：
     - 前后字符相同 + 偶数个问号 → 可能产生长度为 $2$ 的段
     - 前后字符不同 + 奇数个问号 → 需要特殊处理，特别是单个问号时要延长较短的一侧

4. **贪心选择**：在填充问号时，优先选择能避免形成长连续段的字符。

## 算法复杂度

- **时间复杂度**：$O(n)$，其中 $n$ 是字符串长度。只需要一次线性扫描进行分段，然后一次线性处理所有段。
- **空间复杂度**：$O(n)$，用于存储分段信息。

## 代码实现

```cpp
// 0s 1s and ? Marks
// UVa ID: 11920
// Verdict: Accepted
// Submission Date: 2025-11-30
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1010;
char s[MAXN], segmentType[MAXN];
int segmentLength[MAXN];

int main() {
    int testCases, caseNumber = 0;
    scanf("%d", &testCases);
    while (testCases--) {
        scanf("%s", s);
        int length = strlen(s), segmentCount = 0;
        // 将字符串分段处理
        segmentType[segmentCount] = s[0];
        segmentLength[segmentCount] = 0;
        for (int i = 0; i < length; ++i) {
            if (s[i] != segmentType[segmentCount]) {
                ++segmentCount;
                segmentType[segmentCount] = s[i];
                segmentLength[segmentCount] = 0;
            }
            ++segmentLength[segmentCount];
        }
        ++segmentCount;
        int answer = 1;
        for (int i = 0; i < segmentCount; ++i) {
            // 处理固定字符段
            if (segmentType[i] != '?') {
                answer = max(answer, segmentLength[i]);
                continue;
            }
            // 处理问号段（不在边界的情况）
            if (i == 0 || i == segmentCount - 1) continue;
            if (segmentType[i - 1] == segmentType[i + 1]) {
                // 前后字符相同，偶数个问号会产生长度为2的段
                if ((segmentLength[i] & 1) == 0) answer = max(answer, 2);
            } else {
                // 前后字符不同，奇数个问号需要特殊处理
                if (segmentLength[i] & 1) {
                    if (segmentLength[i] != 1) answer = max(answer, 2);
                    else {
                        // 单个问号，选择延长较短的一侧
                        if (segmentLength[i - 1] > segmentLength[i + 1]) {
                            ++segmentLength[i + 1];
                        } else answer = max(answer, segmentLength[i - 1] + 1);
                    }
                }
            }
        }
        printf("Case %d: %d\n", ++caseNumber, answer);
    }
    return 0;
}
```

## 总结

本题的关键在于发现可以通过分段处理来简化问题，然后针对不同类型的段采用不同的处理策略。特别是对于问号段，根据其前后字符的关系和问号数量的奇偶性，可以确定最优的填充方式。这种贪心策略能够在 $O(n)$ 时间内解决问题，效率很高。

这种分段处理的思想在很多字符串问题中都很实用，能够将复杂的问题分解为简单的子问题，是算法竞赛中常用的技巧之一。
