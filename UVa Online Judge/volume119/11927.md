## 题目描述

给定一个有向无环图（$\texttt{DAG}$），每个节点上初始有若干石子。两名玩家轮流操作，每次选择任意一个石子，将其沿着一条有向边移动到相邻节点。无法移动任何石子的玩家输。多石子可共占一节点。

问：在双方最优策略下，先手（$\texttt{First}$）还是后手（$\texttt{Second}$）获胜？

---

## 题目分析

这是一个典型的**不偏组合博弈**问题，多个石子相互独立，整个游戏是这些独立子游戏的**和**。根据博弈论中的 **$\texttt{SG}$ 定理**：

> 一个不偏组合游戏的和的 $\texttt{SG}$ 值为各个子游戏 $\texttt{SG}$ 值的异或（$\texttt{XOR}$）。若异或结果非 $0$，则先手胜；否则后手胜。

因此，我们需要：

1. **为每个节点计算一个 $\texttt{SG}$ 值**，表示单颗石子从该节点出发的游戏的 $\texttt{Grundy}$ 数。
2. **合并所有石子**：每个石子的 $\texttt{SG}$ 值等于它所在节点的 $\texttt{SG}$ 值。多个石子位于同一节点时，该节点的 $\texttt{SG}$ 值需要异或多次（即：若有偶数个石子，异或结果为 $0$；奇数个则为该节点 $\texttt{SG}$ 值本身）。
3. **计算总 $\texttt{XOR}$**，判断胜负。

---

## 解题思路

### 1. $\texttt{SG}$ 值的定义与计算

对于 $\texttt{DAG}$ 上的一个节点 $u$，其 $\texttt{SG}$ 值定义为：

$$
SG[u] = \operatorname{mex} \{ SG[v] \mid (u \to v) \in E \}
$$

其中 $\operatorname{mex}$ 表示最小的、不在集合中的非负整数。

- 出度为 $0$ 的节点（无后继），$\texttt{SG}$ 值为 $0$。
- 其他节点取决于所有后继节点的 $\texttt{SG}$ 值集合。

由于图是 $\texttt{DAG}$，我们可以通过 **记忆化搜索（$\texttt{DFS}$）** 或 **逆拓扑序** 来计算所有节点的 $\texttt{SG}$ 值。

#### 举例（题目样例 $1$）：
图结构：$0 \to 1 \to 2 \to 3$  
初始石子：节点 $0$ 有 $1$ 个，其余为 $0$。

- 节点 $3$ 无后继，$SG[3] = 0$
- 节点 $2$ 后继 $\texttt{SG}$ 集合 $\{0\}$，$\operatorname{mex}\{0\} = 1$，得 $SG[2] = 1$
- 节点 $1$ 后继 $\texttt{SG}$ 集合 $\{1\}$，$\operatorname{mex}\{1\} = 0$，得 $SG[1] = 0$
- 节点 $0$ 后继 $\texttt{SG}$ 集合 $\{0\}$，$\operatorname{mex}\{0\} = 1$，得 $SG[0] = 1$

总 $\texttt{XOR}$ 为 $1 \oplus 0 \oplus 0 \oplus 0 = 1 \neq 0$，因此先手（$\texttt{First}$）获胜。

### 2. 合并多个石子

若节点 $i$ 上有 $s_i$ 个石子，每个石子的 $\texttt{SG}$ 值为 $SG[i]$，则这些石子对总 $\texttt{XOR}$ 的贡献为：

$$
\underbrace{SG[i] \oplus SG[i] \oplus \cdots \oplus SG[i]}_{s_i \text{ 次}}
$$

由于 $x \oplus x = 0$，因此当 $s_i$ 为偶数时贡献为 $0$，奇数时为 $SG[i]$。

所以实际只需判断每个 $s_i$ 的奇偶性。

### 3. 算法步骤

1. 读入 $n, m$，若均为 $0$ 则结束。
2. 建立邻接表。
3. 用 $\texttt{DFS}$ 计算每个节点的 $\texttt{SG}$ 值（初始化 $\texttt{SG}$ 数组为 $-1$ 表示未计算）。
4. 读入 $s_0 \dots s_{n-1}$，对每个 $i$，若 $s_i$ 为奇数则 $xorSum \oplus= SG[i]$。
5. 输出 $xorSum \neq 0$ 时 $\texttt{First}$，否则 $\texttt{Second}$。

---

## 复杂度分析

- **时间复杂度**：每个节点和边在 $\texttt{DFS}$ 中访问一次。对于每个节点 $u$，计算 $\operatorname{mex}$ 时需要遍历其后继节点的 $\texttt{SG}$ 值，并借助布尔数组标记已出现的值。设节点 $u$ 的出度为 $d_u$，则单次计算开销为 $O(d_u + \operatorname{mex})$。由于 $\operatorname{mex}$ 不会超过 $d_u$，因此总复杂度为 $O(n + m)$。
- **空间复杂度**：邻接表存储边需要 $O(n + m)$，$\texttt{SG}$ 数组需要 $O(n)$，递归调用栈深度不超过 $n$，因此总空间复杂度为 $O(n + m)$。

## 注意事项

- 输入中每个测试用例后有一个空行，使用 $\texttt{cin.peek()}$ 检查并跳过换行符，避免影响下一个测试用例的读取。
- 多石子在同一节点时，由于异或运算满足结合律且 $x \oplus x = 0$，因此仅需判断石子数量的奇偶性，无需循环异或，可显著降低常数。
- 图是有向无环图（$\texttt{DAG}$），保证 $\texttt{DFS}$ 不会出现无限递归，无需额外标记访问状态。
- 节点编号从 $0$ 到 $n-1$，建图和访问时保持一致。
- 当 $m = 0$ 时，所有节点出度为 $0$，$\texttt{SG}$ 值全为 $0$，此时总异或和为 $0$，后手胜（$\texttt{Second}$）。

```cpp
// Games Are Important

#include <bits/stdc++.h>
using namespace std;

vector<int> sg;

int computeSG(int u, const vector<vector<int>>& graph) {
    if (sg[u] != -1) return sg[u];
    vector<bool> seen(graph[u].size() + 1, false);
    for (int v : graph[u]) {
        int sgv = computeSG(v, graph);
        if (sgv < (int)seen.size()) seen[sgv] = true;
    }
    int mex = 0;
    while (seen[mex]) ++mex;
    return sg[u] = mex;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    while (cin >> n >> m, n || m) {
        vector<vector<int>> graph(n);
        for (int i = 0; i < m; ++i) {
            int a, b;
            cin >> a >> b;
            graph[a].push_back(b);
        }
        
        sg.assign(n, -1);
        for (int i = 0; i < n; ++i)
            if (sg[i] == -1) computeSG(i, graph);
        
        int xorSum = 0;
        for (int i = 0; i < n; ++i) {
            int stones;
            cin >> stones;
            if (stones & 1) xorSum ^= sg[i];
        }
        
        cout << (xorSum ? "First" : "Second") << '\n';
        
        if (cin.peek() == '\n') cin.ignore();
    }
    return 0;
}
```
