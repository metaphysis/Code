## 题目分析

### 问题描述
你被困在一个 $n \times m$ 的迷宫网格中，需要通过最少的步数逃出迷宫。迷宫中有以下元素：

- **起点** ($\texttt{@}$)：你的初始位置
- **箱子** ($\texttt{x}$)：需要推动的物体
- **按钮** ($\texttt{b}$)：箱子的目标位置
- **门** ($\texttt{d}$)：逃生出口
- **墙壁** ($\texttt{\#}$)：不可通过的障碍物
- **空地** ($\texttt{.}$)：可自由移动的区域

### 游戏规则
1. 你可以在四个方向（上、下、左、右）移动，但不能穿过墙壁或**关闭的门**
2. 推箱子时，你需要站在箱子相邻的一侧，且箱子另一侧必须是可进入的格子
3. 推箱子算作一步操作（你和箱子同时移动一格）
4. 当箱子被推到按钮上时，门会打开，此时可以通过门逃出迷宫
5. 箱子初始位置不在按钮上，门初始状态为关闭

### 胜利条件
你成功到达门的位置，并且此时箱子在按钮上（即门处于打开状态）。

## 解题思路

### 状态表示
由于人和箱子都会移动，我们需要同时记录两者的位置。状态可以表示为：
$$(playerY, playerX, boxY, boxX)$$

其中：
- $(playerY, playerX)$ 表示你的坐标
- $(boxY, boxX)$ 表示箱子的坐标

### 状态空间分析
迷宫最大尺寸为 $20 \times 20 = 400$ 个格子，状态空间大小为 $400 \times 400 = 160,000$，在可接受范围内。

### 搜索算法选择
由于要求最少步数，我们使用**广度优先搜索**（$\texttt{BFS}$）算法。$\texttt{BFS}$ 保证第一次到达目标状态时的步数就是最小步数。

### 关键逻辑处理

#### 1. 门的开关状态
门的可通过性取决于箱子是否在按钮上：
- 当 $(boxY, boxX) = (buttonY, buttonX)$ 时，门打开，可通过
- 否则门关闭，不可通过

#### 2. 移动类型
从当前状态出发，有两种可能的移动：

**普通移动**：
- 移动到相邻的非墙壁格子
- 不能移动到关闭的门
- 如果目标位置是箱子，则转为推箱子操作

**推箱子**：
- 你与箱子相邻，且移动方向与箱子位置一致
- 箱子目标位置必须是可进入的（非墙壁，且不是关闭的门）
- 推箱子后，你和箱子都移动一格

#### 3. 胜利条件检查
在每次从队列中取出状态时检查：
$$(playerY, playerX) = (doorY, doorX) \ \text{且} \ (boxY, boxX) = (buttonY, buttonX)$$

### 算法复杂度
- 时间复杂度：$O(n^2 \times m^2)$，其中 $n, m \leq 20$
- 空间复杂度：$O(n^2 \times m^2)$，用于存储访问状态

## 代码实现

```cpp
// Maze Escape
// UVa ID: 11931

#include <bits/stdc++.h>

using namespace std;

// 状态结构体：记录玩家位置、箱子位置和步数
struct State {
    int playerY, playerX; // 玩家坐标
    int boxY, boxX;       // 箱子坐标
    int steps;            // 已走步数
};

int mazeRows, mazeCols;                // 迷宫行列数
vector<string> mazeLayout;             // 迷宫布局
int startY, startX;                    // 起点坐标
int boxStartY, boxStartX;              // 箱子初始坐标
int doorY, doorX;                      // 门坐标
int buttonY, buttonX;                  // 按钮坐标
bool visited[20][20][20][20];          // 访问标记数组

// 方向数组：上、下、左、右
const int dirY[4] = {-1, 1, 0, 0};
const int dirX[4] = {0, 0, -1, 1};

// 检查坐标是否在迷宫范围内
bool isInBounds(int y, int x) {
    return y >= 0 && y < mazeRows && x >= 0 && x < mazeCols;
}

// 检查格子是否可进入（考虑门的开关状态）
bool isCellPassable(int y, int x, int boxY, int boxX) {
    // 墙壁永远不可通过
    if (mazeLayout[y][x] == '#') return false;
    // 如果是门，检查是否打开（箱子在按钮上时门打开）
    if (y == doorY && x == doorX) {
        return (boxY == buttonY && boxX == buttonX);
    }
    // 其他情况（空地、按钮、起点、箱子位置）都可进入
    return true;
}

// BFS 搜索最短路径
int findShortestPath() {
    // 初始化访问数组
    memset(visited, 0, sizeof(visited));
    queue<State> stateQueue;
    
    // 将初始状态加入队列
    stateQueue.push({startY, startX, boxStartY, boxStartX, 0});
    visited[startY][startX][boxStartY][boxStartX] = true;
    
    while (!stateQueue.empty()) {
        State current = stateQueue.front(); 
        stateQueue.pop();
        
        // 检查是否到达胜利条件：玩家在门位置且箱子在按钮上
        if (current.playerY == doorY && current.playerX == doorX && 
            current.boxY == buttonY && current.boxX == buttonX) {
            return current.steps;
        }
        
        // 尝试四个方向的移动
        for (int direction = 0; direction < 4; direction++) {
            int newPlayerY = current.playerY + dirY[direction];
            int newPlayerX = current.playerX + dirX[direction];
            
            // 检查新位置是否在迷宫范围内
            if (!isInBounds(newPlayerY, newPlayerX)) continue;
            
            // 如果移动目标是箱子位置，尝试推箱子
            if (newPlayerY == current.boxY && newPlayerX == current.boxX) {
                int newBoxY = current.boxY + dirY[direction];
                int newBoxX = current.boxX + dirX[direction];
                
                // 检查箱子目标位置是否合法
                if (!isInBounds(newBoxY, newBoxX)) continue;
                if (!isCellPassable(newBoxY, newBoxX, current.boxY, current.boxX)) continue;
                
                // 推箱子操作有效，创建新状态
                if (!visited[newPlayerY][newPlayerX][newBoxY][newBoxX]) {
                    visited[newPlayerY][newPlayerX][newBoxY][newBoxX] = true;
                    stateQueue.push({newPlayerY, newPlayerX, newBoxY, newBoxX, current.steps + 1});
                }
            } else {
                // 普通移动：检查目标位置是否可进入
                if (!isCellPassable(newPlayerY, newPlayerX, current.boxY, current.boxX)) continue;
                
                // 移动有效，创建新状态（箱子位置不变）
                if (!visited[newPlayerY][newPlayerX][current.boxY][current.boxX]) {
                    visited[newPlayerY][newPlayerX][current.boxY][current.boxX] = true;
                    stateQueue.push({newPlayerY, newPlayerX, current.boxY, current.boxX, current.steps + 1});
                }
            }
        }
    }
    
    // 无解情况
    return -1;
}

int main() {
    while (cin >> mazeRows >> mazeCols) {
        if (mazeRows == 0 && mazeCols == 0) break;
        
        // 读取迷宫布局
        mazeLayout.resize(mazeRows);
        for (int i = 0; i < mazeRows; i++) {
            cin >> mazeLayout[i];
        }
        
        // 定位特殊格子的位置
        for (int i = 0; i < mazeRows; i++) {
            for (int j = 0; j < mazeCols; j++) {
                switch (mazeLayout[i][j]) {
                    case '@': 
                        startY = i; startX = j; 
                        break;
                    case 'x': 
                        boxStartY = i; boxStartX = j; 
                        break;
                    case 'b': 
                        buttonY = i; buttonX = j; 
                        break;
                    case 'd': 
                        doorY = i; doorX = j; 
                        break;
                }
            }
        }
        
        // 执行 BFS 搜索
        int result = findShortestPath();
        if (result == -1) {
            cout << "No Way!" << endl;
        } else {
            cout << result << endl;
        }
    }
    return 0;
}
```

## 总结

本题是一个典型的**状态空间搜索**问题，关键在于：

1. **合理的状态表示**：同时记录玩家和箱子的位置
2. **动态的门状态**：门的可通过性依赖于箱子位置
3. **两种移动方式**：区分普通移动和推箱子操作
4. **BFS 的应用**：保证找到最短路径

通过精心设计状态表示和移动规则，我们能够高效地解决这个推箱子变种问题。
