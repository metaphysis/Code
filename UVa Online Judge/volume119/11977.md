### 题目描述

现在是公元 $2150$ 年，出题人们被一个来自过去的出题人 $\texttt{Tomisu}$ 先生的幽灵所困扰。他有一个未完成的梦想：他一生出了 $999$ 道题，但没能出第 $1000$ 道。作为幽灵，他无法亲自出题，于是他随机找现在的出题人，要求他们完成他未完成的问题之一。

其中一道问题是这样的：
> 在 $b$ 进制数系统中， $n!$ （$n$ 的阶乘）至少有 $t$ 个尾随零。给定 $n$ 和 $t$ 的值，求 $b$ 的最大可能值。

**输入**
- 第一行包含一个整数 $T$ （$\leq 4000$），表示测试用例的数量。
- 每个测试用例包含两个整数 $n$ （$1 < n \leq 10^5$）和 $t$ （$0 < t \leq 1000$）。输入均为十进制。

**输出**
- 对于每个测试用例，输出 `Case i: ` 后接答案。
- 答案应为最大的 $b$。由于 $b$ 可能非常大，请输出 $b$ 对 $10000019$ 取模的结果。
- 如果不存在这样的 $b$ ，则输出 `-1`。

### 问题分析

问题的核心是理解**在不同进制下，阶乘尾随零的含义**。

1.  **尾随零的本质** ：在 $b$ 进制下，一个数的尾随零意味着这个数能被 $b$ 整除。$t$ 个尾随零意味着这个数能被 $b^t$ 整除，但不能被 $b^{t+1}$ 整除（严格来说，题目要求是“至少 $t$ 个”，所以至少要能被 $b^t$ 整除）。

2.  **阶乘的质因数分解与整除性** ：判断 $n!$ 是否能被 $b^t$ 整除，等价于判断 $b^t$ 的所有质因子在 $n!$ 中的指数是否足够大。
    - 设 $b = p_1^{k_1} \times p_2^{k_2} \times \dots \times p_m^{k_m}$，其中 $p_i$ 是质数。
    - 那么 $b^t = p_1^{k_1t} \times p_2^{k_2t} \times \dots \times p_m^{k_mt}$。
    - $n!$ 要被 $b^t$ 整除，对于每个质因子 $p_i$，$n!$ 中 $p_i$ 的指数 $cnt_{p_i}(n!)$ 必须满足：
      $cnt_{p_i}(n!) \ge k_i \times t$。

3.  **最大化 $b$** ：题目要求**最大**的 $b$。在满足尾随零个数 $\ge t$ 的条件下，要最大化 $b$，我们需要：
    - **选择尽可能多的质因子**： $b$ 的质因子可以来自所有不超过 $n$ 的质数。
    - **给每个质因子分配尽可能高的指数**：对于每个质数 $p$，我们计算 $n!$ 中包含 $p$ 的指数 $cnt$。为了满足条件，我们最多可以取 $k = \lfloor \frac{cnt}{t} \rfloor$。这个 $k$ 就是我们在 $b$ 中能分配给 $p$ 的最大指数（因为 $k \times t \le cnt$）。
    - **构造 $b$**：最终的 $b$ 就是所有满足条件的质数 $p$ 的 $p^k$ 的乘积，即 $b = \prod_{p \le n} p^{\lfloor cnt_p(n!) / t \rfloor}$。

4.  **无解情况** ：如果对于所有质数 $p$，都有 $cnt_p(n!) < t$，那么任何质因子的指数 $k$ 都将是 $0$（因为 $\lfloor cnt / t \rfloor = 0$）。这意味着我们无法构造出一个 $b^1$ 使得 $n!$ 能被其整除，也就无法产生至少 $1$ 个尾随零。因此，输出 `-1`。

5.  **计算与取模** ：由于 $n$ 最大为 $10^5$，我们可以用筛法预处理所有质数。对于每个质数 $p$，使用**勒让德公式**快速计算 $cnt_p(n!) = \sum_{i=1}^{\infty} \lfloor n / p^i \rfloor$。最终结果 $b$ 可能极大，需要在每次乘法时对 $10000019$ 取模，并使用**快速幂**计算 $p^k \mod 10000019$。

### 算法步骤

1.  **预处理**：使用埃拉托斯特尼筛法，生成所有不超过 $100000$ 的质数，存储于数组 `primes` 中。
2.  **处理每个测试用例**：
    a. 初始化答案 `ans = 1`，标志 `found = false`。
    b. 遍历 `primes` 中的每个质数 `p`，如果 `p > n` 则终止循环。
    c. 计算 `cnt`： `n!` 中质因子 `p` 的个数。
        - `cnt = 0; temp = n;`
        - `while (temp > 0) { cnt += temp / p; temp /= p; }`
    d. 如果 `cnt >= t`，则将 `found` 置为 `true`，并计算 `k = cnt / t`。
    e. 将 `ans` 乘以 `(p^k) mod MOD`，即 `ans = (ans * modPow(p, k)) % MOD`。
3.  **输出结果**：
    - 如果 `found` 为 `true`，输出 `ans`。
    - 否则，输出 `-1`。

### 复杂度分析

- **预处理筛法**： $O(N \log \log N)$，$N = 10^5$，可以接受。
- **单次测试计算**：需要遍历所有 $\le n$ 的质数，大约有 $O(\frac{n}{\log n})$ 个。对每个质数计算 `cnt` 的复杂度为 $O(\log_p n)$。总复杂度约为 $O(\frac{n}{\log n} \cdot \log n) = O(n)$。
- **总复杂度**： $O(T \cdot n)$，在最坏情况下 $T=4000, n=10^5$ 时，理论计算量很大，但由于 $n$ 是变化的，且大多数质数在 `p > n` 时循环会提前终止，实际运行效率足以通过本题。

```cpp
// Story of Tomisu Ghost

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int MOD = 10000019;
vector<int> primes;
bool isPrime[MAXN];

// 筛法生成所有质数
void sieve() {
    fill(isPrime, isPrime + MAXN, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i < MAXN; ++i) {
        if (isPrime[i]) {
            primes.push_back(i);
            for (int j = i + i; j < MAXN; j += i) {
                isPrime[j] = false;
            }
        }
    }
}

// 快速幂取模 (a^b % MOD)
long long modPow(long long a, long long b) {
    long long res = 1;
    a %= MOD;
    while (b > 0) {
        if (b & 1) res = (res * a) % MOD;
        a = (a * a) % MOD;
        b >>= 1;
    }
    return res;
}

int main() {
    sieve(); // 预处理质数表
    int T;
    scanf("%d", &T);
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        int n, t;
        scanf("%d %d", &n, &t);
        long long ans = 1;
        bool found = false; // 标记是否存在至少一个质数满足条件
        for (int p : primes) {
            if (p > n) break; // 质数超过n，不再对n!有贡献
            // 计算 n! 中质因子 p 的个数 (勒让德公式)
            long long cnt = 0;
            long long temp = n;
            while (temp > 0) {
                cnt += temp / p;
                temp /= p;
            }
            // 如果该质因子的个数足够支持至少t个尾随零
            if (cnt >= t) {
                found = true;
                long long k = cnt / t; // 在b中，p的指数最大可以为k
                ans = (ans * modPow(p, k)) % MOD; // 将 p^k 乘入答案
            }
        }
        if (found) printf("Case %d: %lld\n", caseNo, ans);
        else printf("Case %d: -1\n", caseNo);
    }
    return 0;
}
```

### 总结

本题的关键在于**数论转化**：
1.  将“$b$ 进制下 $t$ 个尾随零”转化为“$n!$ 能被 $b^t$ 整除”。
2.  将整除性条件转化为对 $b$ 的每个质因子指数的约束。
3.  为了最大化 $b$，对每个质数独立地取其最大可行指数。
4.  最终结果由所有质数的贡献乘积得到，并注意取模。

通过预处理质数、使用勒让德公式高效计算阶乘中质因子的指数、以及快速幂取模，我们可以在时间限制内解决这个问题。理解尾随零在不同进制下的本质，是解决此类数论计数问题的核心。
