[UVa 11981 Corrupted Friendship](https://blog.csdn.net/metaphysis/article/details/157358681)

## 题目描述

本题描述了一个特殊的邀请过程。初始时，$\texttt{Mr. Haba}$ 拥有 $N$ 张邀请卡，对应编号为 $1$ 到 $N$ 的 $N$ 个人。邀请过程遵循以下递归规则：

1. 如果 $X$ 有一些卡片，他会保留一张卡片，然后邀请一个尚未收到卡的朋友 $Y$ ，并将剩余的所有卡片交给 $Y$ 。我们称 $Y$ 被 $X$ 邀请。
2. $Y$ 收到卡片后，会承担起同样的分发责任：保留一张卡片，并尝试继续邀请自己的朋友。
3. 当 $Y$ 找不到更多可以邀请的朋友时，他将剩余的卡片返还给 $X$ 。
4. $X$ 继续检查是否还有未收到卡的朋友。如果有，则重复上述过程；否则，如果 $X$ 是被 $Z$ 邀请的， $X$ 将卡片返还给 $Z$ ；如果没有这样的人， $X$ 保留卡片。

已知初始时 $\texttt{Mr. Haba}$ 有 $N$ 张卡片，且邀请过程结束后，每个人都恰好拥有一张卡片。

**输入** 给出 $T$ 个测试用例。每个用例第一行是 $N$ ，接下来 $N-1$ 行每行两个整数 $X$ 和 $Y$ ，表示 $Y$ 的卡片是从 $X$ 那里获得的（即 $Y$ 被 $X$ 邀请）。

**要求输出** 每个用例的编号、总邀请次数以及 **确定不是朋友** 的不同人对了数量。

---

## 题目分析

### 1. 邀请次数

由于最终每个人恰好拥有一张卡片，且除了 $\texttt{Mr. Haba}$（编号 $1$ ）外，每个人都**被邀请了一次**。因此，总邀请次数就是 $N-1$ 。这个结论非常直接，无需任何复杂计算。

### 2. “确定不是朋友”的对数

这是本题的核心难点。我们需要从给定的邀请关系中推断出哪些人**一定不是**朋友。

#### 2.1 关键观察

- 如果 $X$ 邀请了 $Y$ ，那么 $X$ 和 $Y$ 一定是朋友。
- 邀请过程本质上是一个 **深度优先搜索（$\texttt{DFS}$）** 过程：一个人会尽可能邀请所有朋友，只有当某个朋友**已经拥有卡片**时才不会邀请他。
- 题目**隐含了一个重要条件**：每个人邀请朋友的**顺序是固定的**，即按照输入边在邻接表中的顺序进行 $\texttt{DFS}$ 。如果没有这个固定顺序，问题将变得非常复杂（需要考虑所有可能的邀请排列）。

#### 2.2 推理过程

考虑 $\texttt{DFS}$ 的遍历过程：

1. 从根节点（ $\texttt{Mr. Haba}$ ）开始遍历。
2. 当访问一个节点 $u$ 时，意味着 $u$ 已经获得了卡片。
3. 节点 $u$ 会按照固定顺序（输入顺序）依次邀请其子节点（即朋友中尚未获得卡片的人）。
4. 当 $u$ 的所有子节点都被处理完后， $u$ 的子树遍历完成。

在 $\texttt{DFS}$ 的任一时刻，我们可以将所有人分为两类：
- **已访问节点**：已经获得卡片并完成邀请过程的人。
- **未访问节点**：尚未获得卡片的人。

**重要结论**：在 $\texttt{DFS}$ 的某个时刻，如果一个节点 $x$ 在已访问集合中，而节点 $y$ 在未访问集合中，那么 $x$ 和 $y$ **一定不是朋友**。

**证明**：假设 $x$ 和 $y$ 是朋友。当 $x$ 获得卡片时， $y$ 还没有卡片。按照邀请规则， $x$ 会立即邀请 $y$ 。但根据给定的邀请关系， $y$ 并没有被 $x$ 邀请（ $y$ 将在后面被其他人邀请）。这就产生了矛盾。因此， $x$ 和 $y$ 不可能是朋友。

#### 2.3 转化为算法

在 $\texttt{DFS}$ 过程中，每当一个节点 $u$ 的整个子树被遍历完成时，我们可以确定：
- **已访问集合**：节点 $u$ 及其所有后代。
- **未访问集合**：所有尚未被 $\texttt{DFS}$ 访问的节点。

此时，**已访问集合**中的每个节点与**未访问集合**中的每个节点都确定不是朋友。为了避免重复计算，我们采用一种巧妙的计数方法：

- 使用全局变量 `cnt` 表示当前**还未访问**的节点数量，初始值为 $N$ 。
- 在 $\texttt{DFS}$ 中，每当进入一个节点 $u$ ，执行 `cnt--` ，表示 $u$ 被访问。
- 当 $u$ 的所有子节点递归完成后，执行 `r += cnt` 。此时的 `cnt` 值就是**还未访问**的节点数量，而 $u$ 及其所有后代都已访问。因此， `r` 累加了 $u$ 的整个子树与所有未访问节点之间的“非朋友”对数。

由于 $\texttt{DFS}$ 的递归结构，每个节点都会在其子树遍历完成时贡献一次 `cnt` 的累加，且不会重复计算。

### 3. 算法步骤总结

1. 读取 $N$ 和 $N-1$ 条有向边，建立邻接表 `g` 。
2. 从根节点 $1$ 开始执行 $\texttt{DFS}$ 。
3. $\texttt{DFS}$ 过程中：
   - 进入节点时， `cnt--` 。
   - 递归处理所有子节点。
   - 返回前， `r += cnt` 。
4. 总邀请次数为 $N-1$ ，确定不是朋友的对数为 `r` 。

---

## 时间复杂度分析

- 每个测试用例需要读取 $N-1$ 条边，并进行一次 $\texttt{DFS}$ 遍历。
- $\texttt{DFS}$ 访问每个节点恰好一次，因此时间复杂度为 $O(N)$ 。
- 由于 $N \leq 10^5$ ，且 $T \leq 30$ ，总时间复杂度 $O(T \cdot N)$ 在合理范围内。

## 代码实现

```cpp
// Corrupted Friendship
// UVa ID: 11981
// Verdict: Accepted
// Submission Date: 2026-01-25
// UVa Run Time: 0.040s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

vector<int> g[100005];  // 邻接表，存储每个节点的子节点（被邀请者）
long long r, cnt;       // r: 确定不是朋友的对数，cnt: 当前未访问节点数

// DFS遍历
void dfs(int u) {
    cnt--;  // 当前节点被访问，未访问节点数减1
    for (int i = 0; i < g[u].size(); i++)
        dfs(g[u][i]);      // 递归处理子节点
    r += cnt;              // 关键：累加当前未访问节点数
}

int main() {
    int T, cs = 0, N, x, y;
    scanf("%d", &T);
    while (T--) {
        scanf("%d", &N);
        for (int i = 1; i <= N; i++) g[i].clear();
        for (int i = 1; i < N; i++) {
            scanf("%d %d", &x, &y);
            g[x].push_back(y);  // 建立有向边 x -> y
        }
        r = 0, cnt = N;  // 初始化
        dfs(1);          // 从根节点1开始DFS
        printf("Case %d: %d %lld\n", ++cs, N - 1, r);
    }
    return 0;
}
```

## 示例说明

### 样例输入
```
2
2
1 2
3
1 2
1 3
```

### 样例输出
```
Case 1: 1 0
Case 2: 2 1
```

**解释**：
- **Case $1$**： $N=2$ ，只有一条边 $1 \rightarrow 2$ 。总邀请次数为 $1$ 。在 $\texttt{DFS}$ 中，遍历完节点 $2$ 后未访问节点数为 $0$ ，因此确定不是朋友的对数为 $0$ 。
- **Case $2$**： $N=3$ ，边为 $1 \rightarrow 2$ 和 $1 \rightarrow 3$ 。 $\texttt{DFS}$ 顺序为先 $2$ 后 $3$ 。当遍历完节点 $2$ 时，未访问节点有 $3$ ，因此累加 $1$ 。最终确定不是朋友的对数为 $1$ ，即 $(2,3)$ 这对一定不是朋友。

## 总结

本题的关键在于理解邀请过程与 $\texttt{DFS}$ 的等价性，并利用 $\texttt{DFS}$ 的遍历顺序来推断“确定不是朋友”的关系。通过维护一个全局未访问节点计数器，可以在 $\texttt{DFS}$ 返回时高效地累加非朋友对数。题目隐含的“固定邀请顺序”假设是算法正确性的基础，也是竞赛中常见的简化问题的手段。
