## 问题描述

$\texttt{Jerry}$ 在玩水果忍者游戏，他有一个特殊能力：可以在任意时刻切割屏幕上所有的水果。每次切割时，如果切割的水果数量超过 $2$ 个，他就能获得等同于切割水果数量的分数。每个水果有出现时间 $X_i$ 和消失时间 $Y_i$ ， $\texttt{Jerry}$ 只能在 $[X_i, Y_i]$ 时间段内切割该水果。每个水果被切割后就会消失，不能再被切割。给定 $N$ 个水果的时间区间，求 $\texttt{Jerry}$ 能获得的最大分数。

数据范围： $1 \leq N \leq 1000$ ， $0 \leq X_i \leq Y_i \leq 10^9$ 。

## 解题思路

### 关键观察

1. **切割决策点** ：由于 $\texttt{Jerry}$ 切割时会切掉屏幕上所有水果，我们需要选择一些时间点进行切割。一个重要的优化是：存在一个最优解，其中所有切割时间点都是某个水果的**出现时间**。

2. **排序与连续性** ：将水果按出现时间排序后，如果我们在某个时间点 $t$ 切割，那么被切割的水果在排序后的数组中一定是**连续的一段**。

### 正确性证明

#### 引理 1 ：切割时间点可以限定为水果的出现时间

**证明** ：假设在最优解中存在一个切割时间 $t$ ，它不是一个水果的出现时间。设这次切割覆盖的水果集合为 $S$ 。令 $t' = \max\{X_i \mid i \in S\}$ ，即 $S$ 中水果最晚的出现时间。由于所有 $i \in S$ 都满足 $X_i \leq t \leq Y_i$ ，且 $t' \leq t$ ，所以对于任意 $i \in S$ ，仍有 $X_i \leq t' \leq Y_i$ 。因此，将切割时间从 $t$ 提前到 $t'$ 不会减少被切割的水果数量，且 $t'$ 是某个水果的出现时间。由此，所有切割时间都可以调整为水果的出现时间。

#### 引理 2 ：被切割的水果在排序后连续

**证明** ：将水果按出现时间升序排序，设排序后的数组为 $a_1, a_2, \ldots, a_n$ 。假设在时间 $t$ 切割，且 $t$ 是某个水果 $a_k$ 的出现时间。设被切割的水果集合为 $S$ 。对于任意 $i, j \in S$ 且 $i < j$ ，假设存在 $m$ 满足 $i < m < j$ 但 $m \notin S$ 。由于 $a_m$ 的出现时间 $X_m \leq X_j \leq t$ （因为排序后 $X_m \leq X_j$ ），且 $a_m$ 没有被切割，说明 $Y_m < t$ 。但 $a_i$ 被切割意味着 $Y_i \geq t$ ，而 $X_m \leq X_j \leq t$ 且 $Y_m < t$ ，与排序性质矛盾。因此， $S$ 在排序数组中必须是连续的一段。

### 动态规划设计

基于以上观察，我们设计动态规划算法：

- **状态定义** ：令 $dp[i]$ 表示考虑前 $i+1$ 个水果（下标从 $0$ 开始）时能获得的最大分数。
- **状态转移** ：
  1. 不切割第 $i$ 个水果的出现时间： $dp[i] = dp[i-1]$ 。
  2. 以第 $i$ 个水果的出现时间 $t = X_i$ 进行切割：从 $i$ 往前遍历，统计在时间 $t$ 仍然存在（即 $Y_j \geq t$ ）的水果数量 $cnt$ 。如果 $cnt > 2$ ，则可以从 $dp[j-1]$ 转移，其中 $j$ 是这组连续水果的起始下标： $dp[i] = \max(dp[i], dp[j-1] + cnt)$ 。
- **边界条件** ： $dp[-1] = 0$ （没有水果时分数为 $0$ ）。
- **最终答案** ： $dp[n-1]$ 。

### 复杂度分析

- 时间复杂度： $O(N^2)$ ，对于每个水果 $i$ ，需要向前遍历统计可切割的水果数量。 $N \leq 1000$ ，因此总计算量在可接受范围内。
- 空间复杂度： $O(N)$ ，用于存储 $dp$ 数组和水果数据。

## 代码实现

```cpp
// Juice Extractor
// UVa ID: 12018

// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1010;
struct Fruit { int start, end; } fruits[MAXN];
int dp[MAXN], n;

int dfs(int p) {
    if (p == -1) return 0;
    if (~dp[p]) return dp[p];
    // 第 p 个水果的出现时间不切割
    int r = dfs(p - 1);
    // 第 p 个水果的出现时间作为切割时间
    int cnt = 0;
    for (int i = p; i >= 0; i--) {
        if (fruits[i].end >= fruits[p].start) cnt++;
        if ((!i || fruits[i - 1].start != fruits[i].start) && cnt > 2)
            r = max(r, dfs(i - 1) + cnt);
    }
    return dp[p] = r;
}

int main() {
    int t; cin >> t;
    for (int caseId = 1; caseId <= t; ++caseId) {
        cin >> n;
        for (int i = 0; i < n; i++) cin >> fruits[i].start >> fruits[i].end;
        sort(fruits, fruits + n, [](const Fruit& a, const Fruit& b) {
            if (a.start != b.start) return a.start < b.start;
            return a.end < b.end;
        });
        memset(dp, -1, sizeof dp);
        cout << "Case #" << caseId << ": " << dfs(n - 1) << '\n';
    }
    return 0;
}
```

### 代码说明

1. **排序** ：将水果按出现时间升序排序，如果出现时间相同则按消失时间升序排序。
2. **记忆化搜索** ：函数 `dfs(p)` 计算前 $p+1$ 个水果的最大分数，使用 $dp$ 数组记忆化结果。
3. **转移细节** ：在统计可切割水果数量时，通过条件 `fruits[i - 1].start != fruits[i].start` 确保只在连续相同开始时间的最后一个水果处进行转移，避免重复计算。
4. **输出** ：按照题目要求输出每个测试用例的结果。

## 总结

本题的关键在于将切割时间点优化为水果的出现时间，并利用排序后的连续性简化动态规划转移。通过 $O(N^2)$ 的动态规划，可以在规定时间内求解 $N \leq 1000$ 的问题。代码实现简洁，记忆化搜索使状态转移更加直观。
