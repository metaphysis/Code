
> **摘要**：给定一个 $N \times N$ 的方格网，数值为 $0$ 的格子放置雷达，其影响半径由上下左右四个有效邻居数值的平均值决定，所有欧几里得距离不超过该半径的格子都会被该雷达控制。本文从题意出发，先分析边界雷达有效邻居的处理方式，再通过平方变形把浮点比较转化为整数不等式 $dis \times cnt^2 \le sum^2$ 以规避精度误差，最后给出 $O(R \times N^2)$ 的 $\texttt{C++}$ 实现，并统计未被任何雷达控制的区域数量。

# 题目描述

国家的空域被划分为一个 $N \times N$ 的方格网，每个区域中有一个非负整数。数值为 $0$ 的区域放置了雷达。对于位于 $(i,j)$ 的雷达，只考虑网格内与它上下左右相邻的区域，这些区域数值的平均值决定雷达的影响范围。所有到该雷达的欧几里得距离不超过该平均值的区域都受到该雷达控制。求没有被任何雷达控制的区域数量。

# 输入格式

输入第一行包含测试用例数量 $T$。每个测试用例首先输入网格边长 $N$，随后输入 $N$ 行，每行包含 $N$ 个非负整数。

数值为 $0$ 的位置表示雷达所在位置，其余数值用于计算相邻雷达的影响范围。

# 输出格式

对于每个测试用例，输出一个整数，表示没有被任何雷达控制的区域数量。每个测试用例的答案占一行。

# 样例输入

```text
2
4
1 2 0 0
0 1 1 0
1 1 2 0
0 1 1 1
5
1 1 0 1 1
2 1 2 0 1
2 2 1 0 0
1 2 0 1 1
1 0 2 1 1
```

# 样例输出

```text
2
7
```

# 题目分析

网格中的每个 $0$ 都对应一个雷达。雷达影响范围的半径并不是固定值，而是由它的有效邻居决定。位于边界或角落的雷达，其网格外方向不存在邻居，因此不能将网格外的位置计入平均值的分母。

设当前雷达位于 $(i,j)$，有效邻居数为 $cnt$，这些邻居数值的总和为 $sum$，则雷达的影响半径为：

$$
mean = \frac{sum}{cnt}
$$

对于网格中的任意位置 $(x,y)$，它到雷达的欧几里得距离为：

$$
dist = \sqrt{(x-i)^2 + (y-j)^2}
$$

当 $dist \le mean$ 时，位置 $(x,y)$ 会被当前雷达控制。直接使用浮点数计算平均值和距离会产生精度误差，因此将判定式进行变形。由于 $cnt$ 为正数，满足：

$$
\sqrt{(x-i)^2 + (y-j)^2} \le \frac{sum}{cnt}
$$

等价于：

$$
\left((x-i)^2 + (y-j)^2\right) \times cnt^2 \le sum^2
$$

这样整个判定过程只使用整数运算。网格边长为 $1$ 时，唯一位置同时是雷达位置，虽然没有有效邻居，但该位置到雷达的距离为 $0$，仍然会被标记为已控制。

# 解题思路

使用二维数组保存网格数值，再使用同样大小的布尔数组记录每个区域是否已经被控制。

对于每个位置 $(i,j)$，当网格数值不为 $0$ 时跳过；当网格数值为 $0$ 时，执行以下过程：

步骤 $\texttt{1}$. 分别检查 $(i-1,j)$、$(i+1,j)$、$(i,j-1)$ 和 $(i,j+1)$ 是否位于网格内。对每个有效邻居累加其数值到 $sum$，并将 $cnt$ 增加 $1$。

步骤 $\texttt{2}$. 枚举所有位置 $(x,y)$，计算平方距离：

$$
dis = (x-i)^2 + (y-j)^2
$$

步骤 $\texttt{3}$. 使用整数不等式 $dis \times cnt^2 \le sum^2$ 判断 $(x,y)$ 是否处于当前雷达的影响范围内。满足条件时，将对应位置标记为已控制。

步骤 $\texttt{4}$. 所有雷达处理结束后，遍历布尔数组，统计未被标记的位置数量。

每个雷达都需要遍历整个网格来判断覆盖范围。设雷达数量为 $R$，则时间复杂度为 $O(R \times N^2)$。由于 $R \le N^2$，也可以写成最坏情况下的 $O(N^4)$。网格数组和控制标记数组均占用 $O(N^2)$ 的空间。

# 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int solve() {
    int n, ans = 0;
    cin >> n;
    vector<vector<int> > mat(n, vector<int>(n));
    vector<vector<bool> > vis(n, vector<bool>(n, false));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> mat[i][j];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) {
            if (mat[i][j] != 0)
                continue;
            long long sum = 0, cnt = 0;
            if (i > 0) {
                sum += mat[i - 1][j];
                cnt++;
            }
            if (i + 1 < n) {
                sum += mat[i + 1][j];
                cnt++;
            }
            if (j > 0) {
                sum += mat[i][j - 1];
                cnt++;
            }
            if (j + 1 < n) {
                sum += mat[i][j + 1];
                cnt++;
            }
            for (int x = 0; x < n; x++)
                for (int y = 0; y < n; y++) {
                    long long dx = x - i, dy = y - j;
                    long long dis = dx * dx + dy * dy;
                    if (dis * cnt * cnt <= sum * sum)
                        vis[x][y] = true;
                }
        }
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (!vis[i][j])
                ans++;
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    int t;
    cin >> t;
    while (t--)
        cout << solve() << endl;
    return 0;
}
```

# 总结

本题的关键在于正确处理边界雷达的有效邻居，并根据有效邻居数计算平均值。覆盖判断使用平方距离和交叉相乘，将浮点数比较转换为整数比较，避免了精度误差。遍历所有雷达并统一标记覆盖区域，最后统计未标记位置即可得到答案。
