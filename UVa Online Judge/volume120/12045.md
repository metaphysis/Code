## 题目描述

$\texttt{Zibon}$ 开始玩字符串实验。他首先构造一个只包含字符 `a` 和 `b` 的字符串作为第 $1$ 个字符串，然后按照以下规则生成后续字符串：

- 将当前字符串中的所有 `a` 替换为 `b`
- 将当前字符串中的所有 `b` 替换为 `ab`

例如，第 $i$ 个字符串为 `abab`，则第 $i + 1$ 个字符串为 `b(ab)b(ab) = babbab`。

已知第 $N$ 个字符串的长度为 $X$，第 $M$ 个字符串的长度为 $Y$，求第 $K$ 个字符串的长度，结果对 $10^9+7$ 取模。如果输入数据不可能成立，输出 `Impossible`。

### 输入格式

第一行一个整数 $T$（$T \leq 1000$）表示测试用例数。  
接下来 $T$ 行，每行五个整数 $N, X, M, Y, K$，满足 $0 < N, X, M, Y, K < 10^9$ 且 $N \neq M$。

### 输出格式

对于每个测试用例，输出一行：要么是第 $K$ 个字符串的长度模 $10^9+7$，要么是 `Impossible`。

### 样例

输入：
```
2
3 16 5 42 6
5 1 6 10 9
```

输出：
```
68
Impossible
```

## 题目分析

### 1. 长度递推关系

设第 $i$ 个字符串中字符 `a` 的个数为 $a_i$，字符 `b` 的个数为 $b_i$，长度 $L_i = a_i + b_i$。

根据变换规则：
- 每个 `a` 变成 `b`，贡献 $1$ 个 `b`
- 每个 `b` 变成 `ab`，贡献 $1$ 个 `a` 和 $1$ 个 `b`

因此：
$$
a_{i+1} = b_i
$$
$$
b_{i+1} = a_i + b_i
$$

于是：
$$
L_{i+1} = a_{i+1} + b_{i+1} = b_i + (a_i + b_i) = a_i + 2b_i
$$

又因为 $a_i = L_i - b_i$，代入得：
$$
L_{i+1} = (L_i - b_i) + 2b_i = L_i + b_i
$$

而 $b_i = a_{i-1} + b_{i-1} = L_{i-1}$，所以：
$$
L_{i+1} = L_i + L_{i-1}
$$

**结论**：字符串长度序列满足斐波那契递推关系：
$$
L_{i+2} = L_{i+1} + L_i
$$

### 2. 通项公式

设 $L_1 = A$，$L_2 = B$，则根据斐波那契数列性质（$F_1 = 1, F_2 = 1$）：
$$
L_n = F_{n-2} \cdot A + F_{n-1} \cdot B \quad (n \ge 2)
$$

其中 $F_n$ 为斐波那契数列：
$$
F_1 = 1,\ F_2 = 1,\ F_3 = 2,\ F_4 = 3,\ F_5 = 5,\ \dots
$$

对于 $n = 1$，规定 $F_{-1} = 1, F_0 = 0$，则公式同样成立，但代码中需单独处理 $n = 1, 2$ 的情况。

### 3. 利用已知条件求解 $A, B$

已知 $L_N = X$，$L_M = Y$（不妨设 $M > N$），则有方程组：
$$
\begin{cases}
F_{N-2} \cdot A + F_{N-1} \cdot B = X \\[2mm]
F_{M-2} \cdot A + F_{M-1} \cdot B = Y
\end{cases}
$$

令：
$$
\Delta = F_{N-2}F_{M-1} - F_{N-1}F_{M-2}
$$

由斐波那契恒等式：
$$
F_{N-2}F_{M-1} - F_{N-1}F_{M-2} = (-1)^{N-2} F_{M-N}
$$
故 $\Delta \neq 0$（因为 $M \neq N$）。

解方程组得：
$$
A = \frac{X \cdot F_{M-1} - Y \cdot F_{N-1}}{\Delta}, \quad
B = \frac{Y \cdot F_{N-2} - X \cdot F_{M-2}}{\Delta}
$$

### 4. 可行解的条件

$A$ 和 $B$ 必须满足以下条件：

1. **为正整数**：$A > 0$，$B > 0$，且分子能被 $\Delta$ 整除。
2. **变换约束**：第一个字符串由 $a$ 个 `a` 和 $b$ 个 `b` 构成，其中：
   - $b = L_2 - L_1 = B - A$（从 $L_2 = A + b$ 推出）
   - $a = L_1 - b = 2A - B$
   
   由于 $a \ge 0$，$b \ge 0$，得到：
   $$
   B \ge A \quad \text{且} \quad B \le 2A
   $$

   同时 $a, b$ 为整数（自动满足，因为 $A, B$ 为整数）。

3. **长度增长速度限制**：由于 $X, Y < 10^9$，而斐波那契数列增长极快（$F_{45} \approx 1.13 \times 10^9$，$F_{46} \approx 1.83 \times 10^9$），因此 $M$ 不能太大。若 $M \ge 46$，则 $L_M \ge F_{M-2} \cdot A + F_{M-1} \cdot B \ge F_{M-2} + F_{M-1} = F_M > 10^9$，与 $Y < 10^9$ 矛盾。故 $M \le 45$。

### 5. 计算第 $K$ 项

求出 $A, B$ 后，第 $K$ 个字符串的长度为：
$$
L_K = F_{K-2} \cdot A + F_{K-1} \cdot B
$$

其中 $K$ 可能达到 $10^9$，因此需要用**矩阵快速幂**计算 $F_{K-2}$ 和 $F_{K-1}$ 对 $10^9+7$ 取模的值，然后与 $A, B$ 相乘后取模。

---

## 解题步骤

1. **输入处理**：保证 $M > N$，否则交换 $N, M$ 并交换 $X, Y$。
2. **可行性判断**：若 $M > 45$，直接输出 `Impossible`（因为长度已超过 $10^9$）。
3. **计算斐波那契系数**：
   - 对于 $n \le 45$，用循环精确计算 $F_n$（`long long` 足够）。
   - 对于 $n = 1$ 或 $n = 2$，特殊处理系数。
4. **解方程组求 $A, B$**：计算 $\Delta$、分子，检查整除性，得到 $A, B$。
5. **验证 $A, B$**：
   - 检查 $A > 0, B > 0$。
   - 检查变换约束 $B \ge A$ 且 $B \le 2A$。
   - 将 $A, B$ 代回原方程验证（防止溢出错误）。
6. **计算 $L_K$**：
   - 若 $K = 1$，直接输出 $A \bmod (10^9+7)$。
   - 若 $K = 2$，直接输出 $B \bmod (10^9+7)$。
   - 否则用矩阵快速幂计算 $F_{K-2}$ 和 $F_{K-1}$ 模 $10^9+7$，然后计算 $L_K$ 取模。
7. **输出结果**。

---

## 复杂度分析

- 每个测试用例中，$M \le 45$，因此精确计算斐波那契数只需 $O(45)$ 时间。
- 矩阵快速幂计算 $F_{K-2}, F_{K-1}$ 复杂度为 $O(\log K)$。
- 总复杂度 $O(T \cdot \log K)$，$T \le 1000$，$K \le 10^9$，可在 1 秒内完成。

```cpp

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll MOD = 1000000007;

// 2x2 矩阵乘法
void matMul(ll a[2][2], ll b[2][2], ll res[2][2]) {
    ll tmp[2][2] = {{0, 0}, {0, 0}};
    for (int i = 0; i < 2; ++i)
        for (int j = 0; j < 2; ++j)
            for (int k = 0; k < 2; ++k)
                tmp[i][j] = (tmp[i][j] + a[i][k] * b[k][j]) % MOD;
    for (int i = 0; i < 2; ++i)
        for (int j = 0; j < 2; ++j)
            res[i][j] = tmp[i][j];
}

// 矩阵快速幂
void matPow(ll base[2][2], ll exp, ll res[2][2]) {
    ll ans[2][2] = {{1, 0}, {0, 1}};
    ll cur[2][2];
    for (int i = 0; i < 2; ++i)
        for (int j = 0; j < 2; ++j)
            cur[i][j] = base[i][j];
    while (exp > 0) {
        if (exp & 1) matMul(ans, cur, ans);
        matMul(cur, cur, cur);
        exp >>= 1;
    }
    for (int i = 0; i < 2; ++i)
        for (int j = 0; j < 2; ++j)
            res[i][j] = ans[i][j];
}

// 快速计算第 n 个斐波那契数模 MOD (F1=1, F2=1)
ll fibMod(ll n) {
    if (n <= 0) return 0;
    if (n == 1 || n == 2) return 1;
    ll base[2][2] = {{1, 1}, {1, 0}};
    ll res[2][2];
    matPow(base, n - 2, res);
    return (res[0][0] + res[0][1]) % MOD;
}

// 精确计算第 n 个斐波那契数 (n ≤ 45 时使用)
ll fibExact(ll n) {
    if (n <= 0) return 0;
    if (n == 1 || n == 2) return 1;
    ll a = 1, b = 1, c;
    for (ll i = 3; i <= n; ++i) {
        c = a + b;
        a = b;
        b = c;
    }
    return b;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int T;
    cin >> T;
    while (T--) {
        ll N, X, M, Y, K;
        cin >> N >> X >> M >> Y >> K;
        
        if (N > M) { swap(N, M); swap(X, Y); }
        
        // 长度增长极快，M 过大则不可能
        if (M > 45) { cout << "Impossible\n"; continue; }
        
        // 获取斐波那契系数 Ln = Fn-2 * L1 + Fn-1 * L2
        auto getF = [&](ll n, ll& f1, ll& f2) {
            if (n == 1) { f1 = 1; f2 = 0; }
            else if (n == 2) { f1 = 0; f2 = 1; }
            else { f1 = fibExact(n - 2); f2 = fibExact(n - 1); }
        };
        
        ll FN2, FN1, FM2, FM1;
        getF(N, FN2, FN1);
        getF(M, FM2, FM1);
        
        ll delta = FN2 * FM1 - FN1 * FM2;
        if (delta == 0) { cout << "Impossible\n"; continue; }
        
        ll numL1 = X * FM1 - Y * FN1;
        ll numL2 = Y * FN2 - X * FM2;
        
        if (numL1 % delta != 0 || numL2 % delta != 0) { cout << "Impossible\n"; continue; }
        
        ll L1 = numL1 / delta;
        ll L2 = numL2 / delta;
        
        // 检查正整数及变换约束：a = 2L1 - L2 >= 0, b = L2 - L1 >= 0
        if (L1 <= 0 || L2 <= 0 || L2 < L1 || L2 > 2 * L1) { cout << "Impossible\n"; continue; }
        
        // 验证原始方程
        if (FN2 * L1 + FN1 * L2 != X || FM2 * L1 + FM1 * L2 != Y) { cout << "Impossible\n"; continue; }
        
        // 计算 L_K
        ll FK2, FK1;
        if (K == 1) { FK2 = 1; FK1 = 0; }
        else if (K == 2) { FK2 = 0; FK1 = 1; }
        else { FK2 = fibMod(K - 2); FK1 = fibMod(K - 1); }
        
        ll ans = (FK2 * (L1 % MOD) + FK1 * (L2 % MOD)) % MOD;
        cout << ans << "\n";
    }
    return 0;
}
```

## 总结

本题的核心在于：
1. 发现长度序列满足斐波那契递推。
2. 利用已知的两项反推出首两项 $A, B$。
3. 通过变换规则得到 $A, B$ 必须满足的约束 $B \in [A, 2A]$。
4. 利用 $X, Y < 10^9$ 这一条件，将 $M$ 的范围缩小到 $M \le 45$，避免了高精度计算。
5. 对于 $K$ 很大时的斐波那契计算，使用矩阵快速幂模 $10^9+7$。

掌握这些技巧后，类似的问题也可以迎刃而解。
