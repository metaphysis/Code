## 题目描述

在这个问题中，我们需要计算长度为 $n$ 的"伟大数字"的数量。一个伟大数字必须满足以下条件：

1. 该数字必须能被其所有十进制数字整除
2. 它不能包含任何大于 $6$ 的数字（即只能使用数字 $0$-$6$，但实际不能包含 $0$）

**重要说明**：如果数字中包含 $0$，则会出现除以 $0$ 的情况，因此伟大数字实际上只能包含数字 $1$-$6$。

### 输入格式
- 第一行包含一个整数 $T$ ($T \leq 40$)，表示测试用例的数量
- 每个测试用例包含一个整数 $N$ ($1 \leq N \leq 40$)

### 输出格式
对于每个测试用例，输出一行，表示伟大数字的数量，结果对 $1000007$ 取模。

### 样例输入
```
2
1
2
```

### 样例输出
```
6
10
```

## 题目分析

### 问题理解
我们需要统计所有长度为 $N$ 的数字（允许前导零）中满足以下条件的数量：
- 数字中只包含 $1$-$6$ 的数码
- 数字能被其所有数码整除

### 关键观察
1. **除零问题**：数字不能包含 $0$，因为除以 $0$ 无意义
2. **数码范围**：数字只能使用 $1$-$6$ 的数码
3. **整除条件**：一个数能被其所有数码整除 ⇔ 该数能被这些数码的最小公倍数（LCM）整除

### 数学性质
- 可能的数码集合是 $\{1,2,3,4,5,6\}$ 的子集
- 这些数码的 $\texttt{LCM}$ 值有限，最大 $\texttt{LCM}$ 是 $LCM(1,2,3,4,5,6) = 60$
- 所有可能的 $\texttt{LCM}$ 值只有 $12$ 个：$1,2,3,4,5,6,10,12,15,20,30,60$

### 算法选择：动态规划
由于 $N$ 最大为 $40$，直接枚举所有 $6^N$ 种可能不可行，因此采用动态规划方法。

## 解题思路

### 状态设计
我们使用三维动态规划数组：
- $dp[pos][rem][lcmIdx]$ 表示处理到第 $pos$ 位，当前数字模 $60$ 的余数为 $rem$，当前数字集合的 $\texttt{LCM}$ 为 $lcmValues[lcmIdx]$ 时的方案数

### 状态转移
对于每个状态 $(pos, rem, lcmIdx)$，枚举下一位数字 $d$ ($1 \leq d \leq 6$)：
1. 计算新的余数：$newRem = (rem \times 10 + d) \mod 60$
2. 计算新的 $\texttt{LCM}$：$newLCM = LCM(currentLCM, d)$
3. 找到新的 $\texttt{LCM}$ 在预计算数组中的索引 $newLCMIdx$
4. 更新状态：$dp[pos+1][newRem][newLCMIdx] += dp[pos][rem][lcmIdx]$

### 初始化
- 第一位数字：对于 $d = 1$ 到 $6$，设置 $dp[1][d \mod 60][lcmIndex[d]] = 1$

### 结果计算
对于所有最终状态 $(n, rem, lcmIdx)$，如果 $rem \mod currentLCM = 0$，则将对应的 $dp[n][rem][lcmIdx]$ 累加到结果中。

### 复杂度分析
- 状态数：$40 \times 60 \times 12 = 28,800$
- 转移：每个状态最多 $6$ 种转移
- 总操作数：约 $28,800 \times 6 \approx 172,800$，完全可行

## 代码实现

```cpp
// Great Numbers
// UVa ID: 12046
// Verdict: Accepted
// Submission Date: 2025-11-25
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000007;
const int MAX_LCM = 60;

// 预计算所有可能的LCM值
int lcmValues[] = {1,2,3,4,5,6,10,12,15,20,30,60};
int lcmIndex[61];
int lcmCount = 12;

// 计算两个数的LCM
int calcLCM(int a, int b) {
    return a / __gcd(a, b) * b;
}

int dp[41][MAX_LCM][12];

int countGreatNumbers(int n) {
    memset(dp, 0, sizeof dp);
    
    // 初始化：第一位数字
    for (int d = 1; d <= 6; d++) {
        int rem = d % MAX_LCM;
        int lcmIdx = lcmIndex[d];
        dp[1][rem][lcmIdx] = (dp[1][rem][lcmIdx] + 1) % MOD;
    }
    
    // 动态规划
    for (int pos = 1; pos < n; pos++) {
        for (int rem = 0; rem < MAX_LCM; rem++) {
            for (int idx = 0; idx < lcmCount; idx++) {
                if (dp[pos][rem][idx] == 0) continue;
                int currentLCM = lcmValues[idx];
                
                for (int d = 1; d <= 6; d++) {
                    int newRem = (rem * 10 + d) % MAX_LCM;
                    int newLCM = calcLCM(currentLCM, d);
                    int newLCMIdx = lcmIndex[newLCM];
                    
                    dp[pos + 1][newRem][newLCMIdx] = 
                        (dp[pos + 1][newRem][newLCMIdx] + dp[pos][rem][idx]) % MOD;
                }
            }
        }
    }
    
    // 统计结果：余数能被当前LCM整除
    int result = 0;
    for (int rem = 0; rem < MAX_LCM; rem++) {
        for (int idx = 0; idx < lcmCount; idx++) {
            int currentLCM = lcmValues[idx];
            if (rem % currentLCM == 0) {
                result = (result + dp[n][rem][idx]) % MOD;
            }
        }
    }
    return result;
}

int main() {
    // 初始化LCM索引
    memset(lcmIndex, -1, sizeof lcmIndex);
    for (int i = 0; i < lcmCount; i++) {
        lcmIndex[lcmValues[i]] = i;
    }
    
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        cout << countGreatNumbers(n) << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于发现伟大数字的整除性质可以转化为对数字集合 $\texttt{LCM}$ 的整除关系。通过动态规划跟踪当前数字模 $60$ 的余数和当前数字集合的 $\texttt{LCM}$，我们能够高效地统计所有满足条件的数字数量。算法的时间复杂度和空间复杂度都在可接受范围内，能够正确处理 $N$ 最大为 $40$ 的情况。
