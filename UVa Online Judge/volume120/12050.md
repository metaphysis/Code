## 题目分析

题目要求我们按升序找出第 $i$ 个回文数。回文数是指正着读和反着读都一样的数字，例如 $1$、$121$、$1331$ 等。不允许前导零，因此 $010$ 不被视为回文数。

输入给出多个 $i$（$1 \leq i \leq 2 \times 10^9$），要求输出第 $i$ 个回文数。输入以 $0$ 结束。

## 解题思路

由于 $i$ 最大可达 $2 \times 10^9$，不能枚举所有回文数，必须找到数学构造方法。

### 回文数的分布规律

我们可以按回文数的长度分组：

- 长度为 $1$：$1$ 到 $9$，共 $9$ 个
- 长度为 $2$：$11, 22, \dots, 99$，共 $9$ 个
- 长度为 $3$：形式为 $aba$，共 $9 \times 10 = 90$ 个
- 长度为 $4$：形式为 $abba$，共 $9 \times 10 = 90$ 个
- 长度为 $5$：形式为 $abcba$，共 $9 \times 10 \times 10 = 900$ 个
- 依此类推…

**规律**：
- 偶数长度 $2k$：个数为 $9 \times 10^{k-1}$
- 奇数长度 $2k+1$：个数为 $9 \times 10^{k}$

### 构造方法

1. 先确定第 $i$ 个回文数的长度 $len$ 和组内偏移量 $idx$。
2. 计算基数 $power$：
   - 若 $len$ 为奇数，$power = 10^{(len-1)/2}$
   - 若 $len$ 为偶数，$power = 10^{len/2 - 1}$
3. 前一半数字为 $power + idx - 1$。
4. 回文数 = 前一半数字 + 前一半数字去掉最后一位（若长度为奇数）的反转。

### 举例

$i = 12$：
- 长度 $1$ 共 $9$ 个，剩余 $3$
- 长度 $2$ 共 $9$ 个，说明在长度 $2$ 内，偏移 $idx = 3$
- 基数 $power = 10^{0} = 1$
- 前一半 = $1 + 3 - 1 = 3$
- 回文数 = $3$ 拼接 $3$ 的反转 = $33$

$i = 24$：
- 长度 $1$ 共 $9$ 个，剩余 $15$
- 长度 $2$ 共 $9$ 个，剩余 $6$
- 长度 $3$ 共 $90$ 个，说明在长度 $3$ 内，偏移 $idx = 6$
- 基数 $power = 10^{1} = 10$
- 前一半 = $10 + 6 - 1 = 15$
- 回文数 = $15$ 拼接 $1$（去掉最后一位 $5$ 后反转） = $151$

#include <bits/stdc++.h>
using namespace std;
string getPalindrome(long long idx) {
    if (idx <= 9) return to_string(idx);
    long long len = 1, count = 9, power = 1;
    while (idx > count) {
        idx -= count;
        len++;
        if (len % 2 == 1) power *= 10;
        count = 9 * power;
    }
    string half = to_string(power + idx - 1);
    string rev = half.substr(0, half.length() - (len % 2));
    reverse(rev.begin(), rev.end());
    return half + rev;
}
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    long long i;
    while (cin >> i && i) cout << getPalindrome(i) << "\n";
    return 0;
}
