[UVa 12081 Reduced ID Numbers](https://blog.csdn.net/metaphysis/article/details/161460391)

## 题目描述

$\texttt{T. Chur}$ 在大学 $\texttt{U}$ 教授多个学生小组。每个 $\texttt{U}$ 学生都有一个唯一的学生识别号（$\texttt{SIN}$）。$\texttt{SIN}$ $s$ 是一个整数，范围在 $0 \leq s \leq MaxSIN$，其中 $MaxSIN = 10^6 - 1$。$\texttt{T. Chur}$ 发现这个 $\texttt{SIN}$ 范围对于她小组内的身份识别来说太大了。对于每个小组，她希望找到最小的正整数 $m$，使得在该小组内，所有 $\texttt{SIN}$ 对 $m$ 取模后的结果都是唯一的。

### 输入格式

输入的第一行是一个正整数 $N$，表示接下来有 $N$ 个测试用例（小组）。每个测试用例的第一行包含一个整数 $G$（$1 \leq G \leq 300$）：该小组的学生人数。接下来的 $G$ 行每行包含一个 $\texttt{SIN}$。同一小组内的 $\texttt{SIN}$ 互不相同，但不一定有序。

### 输出格式

对于每个测试用例，输出一行，包含最小的模数 $m$，使得所有 $\texttt{SIN}$ 对 $m$ 取模后的结果互不相同。

### 样例输入

```
2
1
124866
3
124866
111111
987651
```

### 样例输出

```
1
8
```

## 题目分析

### 问题本质

给定 $G$ 个互不相同的整数（$\texttt{SIN}$），需要找到一个最小的正整数 $m$，使得这 $G$ 个整数分别对 $m$ 取模后得到 $G$ 个余数，且这 $G$ 个余数两两不同。

换句话说，对于任意两个不同的 $\texttt{SIN}$ $a$ 和 $b$，必须有：

$$a \bmod m \neq b \bmod m$$

这等价于要求 $m$ 不能整除任意两个 $\texttt{SIN}$ 的差：

$$m \nmid (a - b) \quad \text{对于任意 } a \neq b$$

### 数据范围分析

- $G$ 最大为 $300$，因此两两组合的差值最多有 $\binom{300}{2} \approx 44850$ 个。
- $\texttt{SIN}$ 的范围是 $[0, 10^6 - 1]$，所以差值的绝对值最大约为 $10^6$。
- $m$ 的最小值可能是 $1$，最大可能值理论上不超过 $\max(SIN) + 1$，但实际可以更紧地估计。

### 特殊情况

- 当 $G = 1$ 时，只有一个学生，任何 $m$ 都能保证唯一性。最小的正整数 $m = 1$。
- 当 $G > 1$ 时，$m$ 至少为 $G$（因为余数只有 $m$ 种可能，要得到 $G$ 个不同的余数，必须有 $m \geq G$）。但由于 $\texttt{SIN}$ 的分布，实际答案可能更大。

## 解题思路

### 朴素做法

从 $m = 1$ 开始递增尝试，对于每个 $m$：
1. 依次计算每个 $\texttt{SIN}$ 对 $m$ 取模的结果。
2. 使用一个布尔数组（长度为 $m$）记录每个余数是否出现过。
3. 如果某个余数已经出现过，则这个 $m$ 不满足条件，尝试下一个 $m$。
4. 如果所有余数都唯一，则输出当前的 $m$。

时间复杂度：最坏情况下需要尝试 $O(M \times G)$ 次取模和判断，其中 $M$ 是答案的大小。由于 $G \leq 300$ 且 $M$ 通常不会太大（样例中 $M = 8$），这种朴素做法在实际测试中可以通过。

### 优化思路

虽然朴素做法已经足够通过本题，但我们可以思考更高效的优化：

- **预计算差值**：所有 $\texttt{SIN}$ 两两之间的差值 $d = |a - b|$。如果 $m$ 整除某个 $d$，那么 $a$ 和 $b$ 对 $m$ 取模的结果必然相同。因此 $m$ 不能是任何差值的约数。
- **标记禁止的模数**：对于每个差值 $d$，将其所有因子（小于等于 $\max(SIN)$）标记为“禁止”。然后从 $G$ 开始递增查找第一个未被禁止的 $m$。
- 这种方法需要处理因子的计算，对于 $G=300$ 时差值数量约 $4.5 \times 10^4$，每个差值的因子个数平均在 $O(\sqrt{d})$ 量级，总运算量较大但也可行。不过由于本题数据规模较小，朴素方法已经足够。

### 正确性证明

假设对于某个 $m$，存在两个不同的 $\texttt{SIN}$ $a$ 和 $b$ 使得 $a \bmod m = b \bmod m$，则 $m \mid (a - b)$。因此如果我们找到一个 $m$ 使得对所有不同的 $a,b$ 都有 $m \nmid (a - b)$，则 $m$ 就是可行的。

我们从 $m = 1$ 开始递增检查，第一个通过检查的 $m$ 显然就是最小的可行模数，因为所有更小的 $m$ 都已经失败。

## 复杂度分析

- **时间复杂度**：设答案为 $M$，则外层循环最多执行 $M$ 次。每次循环内部：
  - 创建长度为 $m$ 的布尔数组，开销 $O(m)$。
  - 遍历 $G$ 个 $\texttt{SIN}$，进行 $G$ 次取模和判断。
  - 总时间复杂度 $O\left(\sum_{m=1}^{M} (m + G)\right) = O(M^2 + M \cdot G)$。
- **空间复杂度**：$O(M)$，用于布尔数组。

由于 $M$ 在实际测试中通常较小（对于随机数据 $M$ 约为 $O(G)$），该算法运行效率很高。

## 代码实现

```cpp
// Reduced ID Numbers
// UVa ID: 12081
// Verdict: Accepted
// Submission Date: 2026-05-27
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    cin >> N;
    while (N--) {
        int G;
        cin >> G;
        vector<int> sins(G);
        for (int i = 0; i < G; ++i) cin >> sins[i];
        
        int m = 1;
        while (true) {
            vector<bool> seen(m, false); // 记录模 m 的结果是否出现过
            bool ok = true;
            for (int i = 0; i < G; ++i) {
                int r = sins[i] % m;
                if (seen[r]) { ok = false; break; }
                seen[r] = true;
            }
            if (ok) break;
            ++m;
        }
        cout << m << endl;
    }
    return 0;
}
```

## 总结

本题是一个典型的“最小模数使得集合元素取模后两两不同”的问题。解法直观：从 $1$ 开始递增尝试每个可能的模数，利用布尔数组检测重复余数。虽然理论上 $m$ 可能达到 $10^6$ 量级，但由于 $G$ 很小，实际答案往往远小于此，朴素枚举即可在时限内通过。该思路体现了暴力枚举与即时验证的有效结合，是解决此类问题的常用方法。
