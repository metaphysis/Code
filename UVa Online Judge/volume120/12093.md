## 题目描述

在遥远的星系中，有两个星球： $\texttt{Zonq}$ 和 $\texttt{Clunq}$ 。 $\texttt{Zonq}$ 是一个和平的星球，拥有丰富的自然资源和高度发达的数学文明，而 $\texttt{Clunq}$ 则是一个资源匮乏、崇尚武力的星球。当 $\texttt{Clunq}$ 的居民发明太空探索技术后，他们计划入侵 $\texttt{Zonq}$ 。

$\texttt{Zonq}$ 由 $N$ 个村庄组成，这些村庄通过 $N-1$ 条道路连接，形成一棵树形结构。入侵者会降落在某条道路的中点，然后沿着道路扩散。为了防御， $\texttt{Zonq}$ 可以在村庄中放置两种守卫机器人：

1.  **士兵机器人** （ $\texttt{soldier-bot}$ ） ：放置在某个村庄，保护与该村庄直接相连的所有道路。
2.  **中士机器人** （ $\texttt{sergeant-bot}$ ） ：放置在某个村庄，不仅保护与该村庄直接相连的所有道路，还保护与该村庄相邻村庄直接相连的所有道路。

每种机器人都有不同的成本：士兵机器人成本为 $C_1$ ，中士机器人成本为 $C_2$ 。你的任务是分配机器人到各个村庄，使得所有道路都被保护，并且总成本最小。

### 输入格式

输入包含多个测试用例。每个测试用例的第一行包含三个整数：
- $N$ （ $1 \leq N \leq 10000$ ）：村庄数量
- $C_1$ （ $0 \leq C_1 \leq 1000$ ）：士兵机器人成本
- $C_2$ （ $0 \leq C_2 \leq 1000$ ）：中士机器人成本

接下来 $N-1$ 行，每行包含两个整数 $V_1$ 和 $V_2$ ，表示一条连接村庄 $V_1$ 和 $V_2$ 的道路。

输入以一行 `0 0 0` 结束。

### 输出格式

对于每个测试用例，输出一行，包含一个整数：保护所有道路的最小总成本。

## 题目分析

这是一个典型的**树形动态规划**（ $\texttt{Tree DP}$ ）问题。我们需要在树上选择一些节点放置机器人，确保每条边（道路）至少被一个机器人覆盖。覆盖规则如下：

- 士兵机器人覆盖**所在节点的所有邻边**。
- 中士机器人覆盖**所在节点的所有邻边**以及**相邻节点的所有邻边**（即覆盖距离不超过 $2$ 的所有边）。

问题的难点在于中士机器人的覆盖范围更大，这使得我们不能简单地使用传统的顶点覆盖或支配集模型。我们需要设计一个状态定义，能够精确描述节点与父节点之间的覆盖关系。

## 解题思路

### 1. 状态定义

我们使用树形 $\texttt{DFS}$ 从叶子节点向根节点进行动态规划。对于每个节点 $u$ ，我们定义四个状态 $dp[u][0], dp[u][1], dp[u][2], dp[u][3]$ ，其含义如下：

- $dp[u][0]$ ：以 $u$ 为根的子树中所有边都被覆盖，且 $u$ **不提供向上覆盖**。这意味着 $u$ 没有放置机器人，但 $u$ 与父节点的边已经被覆盖（通过 $u$ 的子节点或兄弟节点），同时 $u$ 也不依赖父节点提供覆盖。
- $dp[u][1]$ ：以 $u$ 为根的子树中所有边都被覆盖，且 $u$ **提供一条边的向上覆盖**。这可以通过两种方式实现：要么 $u$ 自己放置士兵机器人，要么 $u$ 的某个子节点放置中士机器人。
- $dp[u][2]$ ： $u$ 放置了**中士机器人**，提供两条边的向上覆盖（覆盖 $u$ 的所有邻边以及邻居的邻边）。
- $dp[u][3]$ ：以 $u$ 为根的子树中所有边都被覆盖，且 $u$ **需要父节点提供覆盖**。这意味着 $u$ 没有放置机器人，且 $u$ 与父节点的边未被覆盖，需要父节点或祖父节点的机器人来覆盖。

### 2. 状态转移

设 $u$ 为当前节点， $v$ 为 $u$ 的子节点。

#### (1) 状态 $0$ 的转移： $dp[u][0]$

状态 $0$ 表示 $u$ 不提供向上覆盖，且 $u$ 与父节点的边已被覆盖。因此：
- $u$ 没有机器人。
- $u$ 与父节点的边已被覆盖（通过其他方式）。
- 对于边 $(u, v)$ ，必须由子节点 $v$ 来覆盖（因为 $u$ 没有机器人）。

由于 $u$ 与父节点的边已被覆盖， $u$ 可以接受子节点 $v$ 提供覆盖。但 $v$ 不能是状态 $0$ （状态 $0$ 表示 $v$ 不提供向上覆盖，但 $v$ 需要覆盖 $(u, v)$ 边，所以 $v$ 必须有机器人）或状态 $3$ （状态 $3$ 表示 $v$ 需要父节点覆盖，但 $u$ 没有机器人）。

因此， $v$ 必须是状态 $1$ （士兵或子节点有中士）或状态 $2$ （中士）。

转移方程：
$$
dp[u][0] = \sum_{v \in \text{children}(u)} \min(dp[v][1], dp[v][2])
$$

#### (2) 状态 $1$ 的转移： $dp[u][1]$

状态 $1$ 表示 $u$ 提供一条边的向上覆盖。有两种实现方式：
1.  $u$ 自己放置士兵机器人（成本 $C_1$ ）。
2.  $u$ 的某个子节点 $v$ 放置中士机器人（ $v$ 是状态 $2$ ），中士可以覆盖到 $u$ 的父节点。

我们首先计算基础部分：对于每个子节点 $v$ ，选择最便宜的状态，可以是状态 $0, 1, 2$ 。
$$
\text{tmp} = \min(dp[v][0], dp[v][1], dp[v][2])
$$
$$
dp[u][1]_{\text{base}} = \sum_{v \in \text{children}(u)} \text{tmp}
$$

然后，我们需要考虑向上覆盖的需求：
- 如果 $u$ 自己放士兵，额外成本为 $C_1$ 。
- 如果选择某个子节点 $v$ 放中士，额外成本为 $dp[v][2] - \text{tmp}$ （因为我们已经计算了 $\text{tmp}$ ，现在需要补足差额）。

我们取两者中的最小值：
$$
dp[u][1] = dp[u][1]_{\text{base}} + \min\left(C_1, \min_{v \in \text{children}(u)}(dp[v][2] - \text{tmp})\right)
$$

#### (3) 状态 $2$ 的转移： $dp[u][2]$

状态 $2$ 表示 $u$ 放置中士机器人，成本为 $C_2$ 。中士覆盖了 $u$ 的所有邻边以及邻居的邻边，因此：
- 子节点 $v$ 可以是任意状态，包括状态 $3$ （ $v$ 需要父节点覆盖，而 $u$ 的中士正好可以提供这种覆盖）。

转移方程：
$$
dp[u][2] = C_2 + \sum_{v \in \text{children}(u)} \min(\text{tmp}, dp[v][3])
$$
其中 $\text{tmp} = \min(dp[v][0], dp[v][1], dp[v][2])$ 。

#### (4) 状态 $3$ 的转移： $dp[u][3]$

状态 $3$ 表示 $u$ 需要父节点提供覆盖。这意味着：
- $u$ 没有机器人。
- $u$ 与父节点的边未被覆盖，需要父节点帮助。
- 对于边 $(u, v)$ ，必须由子节点 $v$ 来覆盖（因为 $u$ 没有机器人）。

子节点 $v$ 可以是状态 $0, 1, 2$ ，但不能是状态 $3$ （状态 $3$ 表示 $v$ 需要父节点覆盖，但 $u$ 没有机器人，无法覆盖 $v$ ）。

转移方程：
$$
dp[u][3] = \sum_{v \in \text{children}(u)} \text{tmp}
$$
其中 $\text{tmp} = \min(dp[v][0], dp[v][1], dp[v][2])$ 。

### 3. 边界条件（叶子节点）

对于叶子节点 $u$ （没有子节点）：
- $dp[u][0]$ ： $0$ 。叶子节点没有子节点，不需要覆盖任何向下的边，且不提供向上覆盖。
- $dp[u][1]$ ：如果 $u$ 是叶子节点，要提供向上覆盖，只能自己放士兵（成本 $C_1$ ）。转移会自动处理为 $C_1$ 。
- $dp[u][2]$ ： $C_2$ 。
- $dp[u][3]$ ：无效（设为 $\infty$ ），因为叶子节点没有子节点来覆盖它与父节点的边，而它又需要父节点覆盖，这种状态不可行。

### 4. 根节点处理

根节点（编号为 $1$ ）没有父节点，因此：
- **可以**是状态 $0$ ：不提供也不需覆盖。对于单节点树（没有边），这是合法状态，成本为 $0$ 。
- **可以**是状态 $1$ ：提供一条边的向上覆盖。
- **可以**是状态 $2$ ：提供两条边的向上覆盖。
- **不能**是状态 $3$ ：需要父节点覆盖但根没有父节点。

因此，最终答案为：
$$
\text{ans} = \min(dp[1][0], dp[1][1], dp[1][2])
$$

### 5. 算法复杂度

- 每个节点处理一次，每次处理所有子节点。
- 总时间复杂度： $O(N)$ ， $N \leq 10000$ ，完全可行。
- 空间复杂度： $O(N)$ 。

## 代码实现

```cpp
// Protecting Zonk
// UVa ID: 12093
// Verdict: Accepted
// Submission Date: 2025-12-05
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
const int MAXN = 10005;

vector<int> graph[MAXN];
int costSoldier, costSergeant;
int dp[MAXN][4];

void dfs(int u, int parent) {
    // 初始化
    dp[u][0] = 0;
    dp[u][1] = 0;
    dp[u][2] = costSergeant;
    dp[u][3] = 0;
    int minDiff = INF;
    for (int v : graph[u]) {
        if (v == parent) continue;
        dfs(v, u);
        // 状态0：需要子节点是状态1或2
        dp[u][0] += min(dp[v][1], dp[v][2]);
        // 计算tmp = min(dp(v,0), dp(v,1), dp(v,2))
        int tmp = min(dp[v][0], min(dp[v][1], dp[v][2]));
        // 状态1
        dp[u][1] += tmp;
        // 更新minDiff
        minDiff = min(minDiff, dp[v][2] - tmp);
        // 状态2
        dp[u][2] += min(tmp, dp[v][3]);
        // 状态3
        dp[u][3] += tmp;
    }
    // 状态1加上min(c1, minDiff)
    dp[u][1] += min(minDiff, costSoldier);
    // 处理叶子节点特殊情况
    if (graph[u].size() == 1 && parent != -1) dp[u][3] = INF;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n >> costSoldier >> costSergeant) {
        if (n == 0 && costSoldier == 0 && costSergeant == 0) break;
        for (int i = 1; i <= n; ++i) graph[i].clear();
        for (int i = 0; i < n - 1; ++i) {
            int a, b;
            cin >> a >> b;
            graph[a].push_back(b);
            graph[b].push_back(a);
        }
        dfs(1, -1);
        cout << min(dp[1][0], min(dp[1][1], dp[1][2])) << endl;
    }
    return 0;
}
```

## 总结

本题是一个经典的树形动态规划问题，难点在于中士机器人的覆盖范围更大，需要设计合适的状态来表示节点与父节点之间的覆盖关系。通过定义四种状态，并仔细推导状态转移方程，我们可以高效地求解最小总成本。

关键点在于理解状态 $0$ 和状态 $3$ 的区别：
- 状态 $0$ ： $u$ 不提供向上覆盖，但 $u$ 与父节点的边已被覆盖（通过其他方式）。
- 状态 $3$ ： $u$ 需要父节点提供覆盖， $u$ 与父节点的边未被覆盖。

根节点可以是状态 $0$ （不提供也不需覆盖），这在单节点树或某些特殊情况下是最优解。

该算法时间复杂度为 $O(N)$ ，足以处理 $N \leq 10000$ 的数据规模。理解本题的解法对于掌握树形 $\texttt{DP}$ 和覆盖类问题具有重要意义。
