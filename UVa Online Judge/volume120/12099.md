## 题目描述

汤姆的书架在他堆起的大量书籍下倒塌了，他需要建造一个新的三层书架来容纳所有的书。出于实用性和美观性考虑，他希望书架尽可能小，并且恰好有三层。

汤姆将问题建模如下：他测量了每本书 $i$ 的高度 $h_i$ 和厚度 $t_i$，需要将书籍划分为三个非空集合 $S_1, S_2, S_3$，使得以下值最小化：

$$(\sum_{j=1}^{3} \max_{i \in S_j} h_i) \times (\max_{j=1}^{3} \sum_{i \in S_j} t_i)$$

这个值表示从书架正面看去的面积（高度乘以宽度）。

### 输入格式

- 第一行：测试用例数量 $T$（最多 $20$ 个）
- 每个测试用例：
  - 第一行：书籍数量 $N$（$3 \leq N \leq 70$）
  - 接下来 $N$ 行：每行两个整数 $h_i, t_i$（$150 \leq h_i \leq 300$, $5 \leq t_i \leq 30$）

### 输出格式

对于每个测试用例，输出能够容纳所有书籍的三层书架的最小面积。

## 题目分析

### 问题理解

我们需要将 $N$ 本书分配到三个非空书架层，使得：
- **总高度** = 三层各自最大高度之和
- **总宽度** = 三层中总厚度的最大值
- **目标**：最小化 **总高度 × 总宽度**

### 关键观察

1. **高度特性**：每层的最大高度由该层中最高的书决定
2. **厚度特性**：总宽度由三层中厚度和最大的那层决定
3. **非空约束**：每层必须至少有一本书
4. **数据范围**：
   - $N \leq 70$，但厚度总和可能达到 $70 \times 30 = 2100$
   - 高度范围较小（$150$-$300$）

### 解题思路

#### 核心洞察

由于高度范围有限，我们可以利用**高度排序**来简化问题：
- 将书籍按高度**降序排列**
- 最高的书必定在某一层，且该层的最大高度就是这本书的高度
- 我们可以固定最高的书在第一层，这样第一层的最大高度就确定了

#### 动态规划设计

定义状态：$dp[j][k]$ 表示处理了前若干本书后：
- 第二层总厚度为 $j$
- 第三层总厚度为 $k$
- 此时第二层和第三层的**最大高度之和的最小值**

**状态转移**：
对于每本书（从第二本开始），考虑放入第二层或第三层：
- 如果放入第二层：
  - 若第二层之前为空（$j = 0$），则第二层最大高度增加当前书的高度
  - 否则，第二层最大高度不变
- 如果放入第三层：
  - 若第三层之前为空（$k = 0$），则第三层最大高度增加当前书的高度
  - 否则，第三层最大高度不变

**初始化**：
- $dp[0][0] = 0$（初始状态，第二、三层都为空）
- 其他状态初始化为无穷大

**最终计算**：
遍历所有可能的 $j, k$（确保三层都非空）：
- 第一层厚度 = 总厚度 - $j$ - $k$
- 总高度 = 第一本书高度 + $dp[j][k]$
- 总宽度 = $\max($第一层厚度, $j$, $k)$
- 面积 = 总高度 × 总宽度
- 取最小面积作为答案

## 算法复杂度分析

- **排序**：$O(N \log N)$
- **动态规划**：状态数 $O(\texttt{totalThickness}^2)$ ≈ $2100^2$ ≈ $4.4 \times 10^6$
- **总复杂度**：$O(N \times \texttt{totalThickness}^2)$，在题目约束下可接受

```cpp
// Bookcase

#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>
#include <climits>

using namespace std;

struct Book {
    int height;
    int thickness;
};

bool compareByHeight(const Book& a, const Book& b) {
    return a.height > b.height;
}

int main() {
    int numTestCases;
    cin >> numTestCases;

    while (numTestCases--) {
        int numBooks;
        cin >> numBooks;

        vector<Book> books(numBooks);
        int totalThickness = 0;

        for (int i = 0; i < numBooks; i++) {
            cin >> books[i].height >> books[i].thickness;
            totalThickness += books[i].thickness;
        }

        sort(books.begin(), books.end(), compareByHeight);

        const int INF = INT_MAX / 2;
        vector<vector<int>> dp(totalThickness + 1, vector<int>(totalThickness + 1, INF));
        dp[0][0] = 0;

        int prefixThickness = books[0].thickness;

        for (int idx = 1; idx < numBooks; idx++) {
            int h = books[idx].height;
            int t = books[idx].thickness;

            for (int j = totalThickness; j >= 0; j--) {
                for (int k = totalThickness; k >= 0; k--) {
                    if (dp[j][k] >= INF) continue;

                    // 放入第二层
                    int newJ = j + t;
                    int newHeightSum = dp[j][k] + (j == 0 ? h : 0);
                    if (newJ <= totalThickness) {
                        dp[newJ][k] = min(dp[newJ][k], newHeightSum);
                    }

                    // 放入第三层
                    int newK = k + t;
                    newHeightSum = dp[j][k] + (k == 0 ? h : 0);
                    if (newK <= totalThickness) {
                        dp[j][newK] = min(dp[j][newK], newHeightSum);
                    }
                }
            }
            prefixThickness += t;
        }

        int minArea = INT_MAX;
        for (int j = 1; j <= totalThickness; j++) {
            for (int k = 1; k <= totalThickness; k++) {
                if (dp[j][k] >= INF) continue;
                int thickness1 = totalThickness - j - k;
                if (thickness1 <= 0) continue;
                int totalHeight = books[0].height + dp[j][k];
                int maxWidth = max(thickness1, max(j, k));
                minArea = min(minArea, totalHeight * maxWidth);
            }
        }

        cout << minArea << endl;
    }

    return 0;
}
```

## 总结

本题通过巧妙的排序和动态规划设计，解决了三层书架的最优分配问题。关键点在于：
1. 按高度降序排序，固定最高书的位置
2. 使用动态规划跟踪两层厚度和对应的高度和
3. 确保三层都非空的约束条件

这种解法充分利用了数据范围的特性，在合理的时间内找到了最优解。
