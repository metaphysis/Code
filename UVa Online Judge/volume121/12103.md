## 题目描述

收藏家 $\texttt{Stan Ucker}$ 声称购买到了莱昂纳多·达·芬奇的秘密笔记本。调查员 $\texttt{Sarah Keptic}$ 对此表示怀疑，她发现笔记本使用了一种替换密码，每个字母都被另一个字母替换。

在笔记本的最后一页，他们发现了一行字母：`QWERTYUIOPASDFGHJKLZXCVBNM`。Stan 提出一个假设：这行字母可能是莱昂纳多原本写下的替换字母表，但被助手按照相同的加密规则处理了两次。

换句话说，给定的字母排列可能是对原始字母表 `ABCDEFGHIJKLMNOPQRSTUVWXYZ` 应用某个排列两次的结果。

## 问题分析

我们需要判断一个给定的排列 $G$ 是否等于某个排列 $P$ 的平方，即是否存在排列 $P$ 使得 $P^2 = G$。

### 排列的循环分解

任何排列都可以分解为若干个不相交的循环。例如，排列：
```
位置: 0 1 2 3 4
字母: C A E D B
```
可以分解为循环 $(0 \rightarrow 2 \rightarrow 4 \rightarrow 1 \rightarrow 0)$。

### 排列平方的循环结构

关键观察：当对一个排列进行平方运算时（即应用两次），其循环结构会发生变化：

- **奇数长度循环**：平方后仍保持相同长度
- **偶数长度循环**：平方后会分裂成两个长度减半的循环

例如：
- 长度为 $3$ 的循环 $(a\ b\ c)$ 平方后仍是长度为 $3$ 的循环 $(a\ c\ b)$
- 长度为 $4$ 的循环 $(a\ b\ c\ d)$ 平方后会分裂成两个长度为 $2$ 的循环 $(a\ c)$ 和 $(b\ d)$

### 判定条件

基于以上观察，我们可以得出判定条件：

**一个排列 $G$ 是某个排列 $P$ 的平方，当且仅当在 $G$ 的循环分解中，每个偶数长度的循环都出现偶数次。**

这是因为：
- 奇数长度循环在平方前后长度不变，没有限制
- 偶数长度循环在平方时分裂，所以原始排列 $P$ 中必须有两个相同长度的偶数循环才能产生 $G$ 中的一个偶数长度循环

## 算法设计

1. **循环分解**：对给定的排列进行循环分解，找出所有循环
2. **统计循环长度**：记录每个长度出现的次数
3. **检查条件**：验证所有偶数长度的循环是否都出现偶数次
4. **输出结果**：满足条件输出 `Yes`，否则输出 `No`

## 复杂度分析

- 循环分解的时间复杂度为 $O(26)$
- 对于最多 $500$ 个测试用例，总时间复杂度为 $O(500 \times 26) = O(13000)$
- 空间复杂度为 $O(26)$ 用于标记访问状态和统计循环长度

#include <iostream>
#include <string>
#include <vector>
#include <cstring>

using namespace std;

bool canBeSquare(const string& perm) {
    int n = perm.size();
    vector<bool> visited(n, false);
    int count[27] = {0}; // 统计各长度循环出现的次数

    for (int i = 0; i < n; ++i) {
        if (!visited[i]) {
            int len = 0;
            int cur = i;
            while (!visited[cur]) {
                visited[cur] = true;
                cur = perm[cur] - 'A';
                len++;
            }
            count[len]++;
        }
    }

    // 检查偶数长度循环是否成对出现
    for (int len = 2; len <= n; len += 2) {
        if (count[len] % 2 != 0) {
            return false;
        }
    }
    return true;
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        string perm;
        cin >> perm;
        if (canBeSquare(perm)) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    return 0;
}
```

输出: No
```
分析：该排列的循环结构不满足条件，存在某些偶数长度的循环出现了奇数次。

### 示例 2
```
输入: ABCDEFGHIJKLMNOPQRSTUVWXYZ  
输出: Yes
```
分析：恒等排列可以看作是任何排列的平方，特别地，它也是恒等排列自身的平方。

## 总结

本题的关键在于理解排列的循环分解和平方运算对循环结构的影响。通过分析排列的循环结构特征，我们可以高效地判断一个排列是否可能是另一个排列的平方，而不需要实际尝试所有可能的 $26!$ 种排列。
