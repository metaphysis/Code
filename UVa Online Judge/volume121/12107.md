## 题目描述

### 问题背景

数字谜题是通过隐藏整数等式中的某些数字而创建的一种谜题。题目会给出一个形如 $a \times b = c$ 的等式，其中某些数字被隐藏（用 `*` 表示），其余数字正常显示。所有数字都是正整数，且没有前导零。

如果一个数字谜题有**唯一解**，我们称之为**好谜题**。例如：

- $7 \times \square = 8\square$ 的唯一解是 $7 \times 12 = 84$
- $\square \square \times \square \square= 1\square 1$ 的唯一解是 $11 \times 11 = 121$

### 任务要求

给定一些数字谜题（可能不是好谜题），你需要将它们转换为好谜题。转换规则如下：

1. 可以进行的修改操作：
   - 将通配符 `*` 改为真实数字
   - 将真实数字改为通配符 `*`
   - 将一个真实数字改为另一个真实数字

2. **限制条件**：
   - 不能插入或删除任何字符
   - 字符串长度保持不变
   - 修改的字符数应**最小化**

3. **输出要求**：
   - 如果存在多个最优解（相同的最小修改次数），输出**字典序最小**的解
   - 字典序比较时，`*` 的 $\texttt{ASCII}$ 码小于 `0`，因此 `*` < `0`

### 输入格式

输入包含多个测试用例。每个测试用例包含三个非空字符串 $x$、$y$、$z$，分别表示 $a$、$b$、$c$ 的模式，长度最多为 $2$、$2$、$4$ 个字符。每个字符是数字或通配符 `*`，且 $x$ 不会以 `0` 开头。最后一个测试用例后跟一个单独的 `0`，表示输入结束。

### 输出格式

对于每个测试用例，输出用例编号和转换后的谜题。

### 样例输入

```
7 ** 8*
** ** ***
0
```

### 样例输出

```
Case 1: 7 ** 8*
Case 2: ** ** 1*1
```

## 题目分析

### 核心挑战

本题的主要挑战在于如何在满足**最小修改次数**的前提下，找到**字典序最小**的好谜题。这涉及到三个关键问题：

1. **如何判断一个谜题是否是好谜题？**
   - 需要验证是否存在唯一的 $(a, b, c)$ 满足 $a \times b = c$ 且与模式匹配

2. **如何最小化修改次数？**
   - 需要找到从原始模式到某个好谜题的最小编辑距离

3. **如何在相同修改次数下选择字典序最小的解？**
   - 需要设计搜索顺序，确保优先找到字典序小的解

### 问题规模

- $a$ 最多 $2$ 位 → 取值范围：$1$ 到 $99$
- $b$ 最多 $2$ 位 → 取值范围：$1$ 到 $99$
- $c$ 最多 $4$ 位 → 取值范围：$1$ 到 $9999$
- 可能的等式总数：约 $100 \times 100 = 10000$ 个
- 模式总长度最多：$2 + 2 + 4 = 8$ 个字符

### 解题思路

#### 1. 暴力搜索的不可行性

最直接的思路是枚举所有可能的修改方案：
- 每个位置可以是 `*` 或 $0$-$9$，共 $11$ 种可能
- 最多 $8$ 个位置，总共有 $11^8 \approx 2.15 \times 10^8$ 种可能
- 对于每种可能，需要检查是否是**好谜题**（验证约 $10000$ 个等式）
- 总计算量过大，不可行

#### 2. 优化思路：迭代加深搜索（$\texttt{IDDFS}$）

**关键观察**：我们关心的是**最小修改次数**。可以采用**迭代加深搜索**策略：
- 从修改次数 $0$ 开始尝试
- 如果找不到解，将允许的修改次数增加 $1$
- 继续搜索，直到找到解

**优势**：
- 保证找到的第一个解就是**修改次数最少**的
- 在搜索过程中可以加入剪枝，减少无效搜索

#### 3. 字典序最小的实现

为了在相同修改次数下找到字典序最小的解，需要设计**特定的搜索顺序**：

1. **位置顺序**：从左到右依次处理每个位置
2. **字符尝试顺序**：对于每个位置，按以下顺序尝试字符：
   - 先尝试 `*`（$\texttt{ASCII}$ $42$，最小）
   - 然后尝试 `0`（$\texttt{ASCII}$ $48$）
   - 最后尝试 `1` 到 `9`

**原理**：由于采用深度优先搜索，先尝试字典序小的字符，并且一旦找到完整解就立即返回，这样找到的第一个解就是字典序最小的。

#### 4. 验证好谜题的高效方法

验证一个模式是否是好谜题需要：
1. 找出所有可能的 $(a, b, c)$ 满足模式
2. 检查是否只有唯一解

由于 $a$ 和 $b$ 最多 $2$ 位，可以采用递归填充法：
- 从左到右递归填充所有 `*` 位置
- 一旦发现超过一个解就提前终止（剪枝）
- 只返回解的数量（$0$、$1$ 或 $>1$）

## 算法设计

### 算法框架

1. **预处理**：读取输入模式，计算各部分长度
2. **迭代加深搜索**：
   - 设允许的最大修改次数为 $limit$，从 $0$ 开始
   - 在每个 $limit$ 下进行深度优先搜索
   - 如果找到好谜题，输出并结束
   - 否则 $limit$ 增加 $1$，继续搜索
3. **深度优先搜索**：
   - 按位置顺序尝试修改字符
   - 维护已修改次数，不超过 $limit$
   - 达到 $limit$ 后验证是否是**好谜题**
4. **验证函数**：
   - 递归填充所有 `*` 位置
   - 统计解的数量，提前终止优化

```cpp
// Digit Puzzle

#include <bits/stdc++.h>
using namespace std;

int a, b, c;
string s;

int validate(int depth) {
    if (depth == a + b) {
        int x = stoi(s.substr(0, a)), y = stoi(s.substr(a, b));
        string z = to_string(x * y);
        if (z.length() != c) return 0;
        for (int i = 0; i < c; i++) {
            if (s[a + b + i] == '*') continue;
            if (s[a + b + i] != z[i]) return 0;
        }
        return 1;
    }
    if (s[depth] != '*') return validate(depth + 1);
    int cnt = 0;
    for (int d = 0; d <= 9; d++) {
        // 不能有前导0
        if (!d && (!depth || depth == a)) continue;
        s[depth] = '0' + d;
        cnt += validate(depth + 1);
        s[depth] = '*';
        if (cnt > 1) break;
    }
    return cnt;
}

const string replaced = "*0123456789";

bool iddfs(int depth, int changed, int limit) {
    if (changed == limit) {
        if (validate(0) == 1) {
            cout << s.substr(0, a) << ' ' << s.substr(a, b) << ' ' << s.substr(a + b, c) << '\n';
            return true;
        }
        return false;
    }
    if (depth == s.length()) return false;
    for (auto c : replaced) {
        if (c == '0' && (!depth || depth == a || depth == (a + b))) continue;
        char backup = s[depth];
        s[depth] = c;
        if (iddfs(depth + 1, changed + (backup != c), limit)) return true;
        s[depth] = backup;
    }
    return false;
}

int main() {
	string x, y, z;
	int cases = 1;
	while (cin >> x) {
	    if (x.front() == '0') break;
	    cout << "Case " << cases++ << ": ";
	    cin >> y >> z;
	    a = x.length(), b = y.length(), c = z.length();
	    s = x + y + z;
	    for (int limit = 0; limit <= s.length(); limit++)
            if (iddfs(0, 0, limit))
                break;
	}
	return 0;
}
```

## 总结

### 算法亮点

1. **迭代加深搜索（$\texttt{IDDFS}$）**：保证找到**最小修改次数**的解
2. **特定搜索顺序**：保证在相同修改次数下找到**字典序最小**的解
3. **高效验证**：通过递归填充和提前终止，快速验证谜题的唯一性
4. **剪枝优化**：多种剪枝策略大幅减少搜索空间

### 关键技巧

1. **字符尝试顺序**：`*` → `0` → `1` → ... → `9`，确保字典序最小
2. **修改次数统计**：只有在字符实际改变时才计数
3. **提前终止**：一旦发现多个解就停止验证
4. **前导零处理**：正确排除非法数字

### 适用场景

这种算法设计适用于以下类型的问题：
- 搜索空间大但解较浅的问题
- 需要保证找到最优解（最小代价、字典序等）
- 可以设计有效的剪枝策略

本题通过巧妙的搜索策略，在有限的时间内找到了满足所有约束的最优解，展示了深度优先搜索与迭代加深搜索的强大组合能力。
