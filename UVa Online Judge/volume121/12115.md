## 题目描述

给定一个特征字符串 $S$ （仅包含字母和数字），它可以生成一个巨大的嵌套正方形图案。正方形的边长为 $N = 2 \times |S| - 1$ 。图案由一系列嵌套的正方形组成：最外层的正方形由 $S[0]$ 填充，下一层由 $S[1]$ 填充，依此类推，直到最内层由 $S[|S|-1]$ 填充。

我们需要回答 $Q$ 个查询，每个查询给出一个矩形区域（边界框），要求输出该区域内所有位置的字符。矩形区域的坐标满足 $1 \leq r_1, c_1, r_2, c_2 \leq N$ ，且矩形的高度和宽度均不超过 $100$ 。

## 题目分析

### 1. 图案生成规则

设正方形边长为 $N$ ，位置 $(r, c)$ 的字符由该位置所在的“层数”决定。层数定义为该位置到正方形四条边界的最小距离：

- 到上边界的距离： $distUp = r - 1$
- 到下边界的距离： $distDown = N - r$
- 到左边界的距离： $distLeft = c - 1$
- 到右边界的距离： $distRight = N - c$

则层数 $level = \min(distUp, distDown, distLeft, distRight)$ 。该位置的字符即为 $S[level]$ 。

例如，对于特征字符串 $S = "abca"$ ， $N = 2 \times 4 - 1 = 7$ 。位置 $(3,2)$ 的层数计算如下：

- $distUp = 3 - 1 = 2$
- $distDown = 7 - 3 = 4$
- $distLeft = 2 - 1 = 1$
- $distRight = 7 - 2 = 5$
- $level = \min(2,4,1,5) = 1$
- 字符为 $S[1] = 'b'$

### 2. 查询特点

每个查询给出的矩形区域大小有限： $0 \leq r_2 - r_1 \leq 100$ 且 $0 \leq c_2 - c_1 \leq 100$ ，即最多包含 $101 \times 101 = 10201$ 个位置。因此，我们不需要预先生成整个 $N \times N$ 的正方形（ $N$ 最大可达 $2 \times 50000 - 1 = 99999$ ，存储整个正方形不可行），而是对于每个查询，直接遍历矩形区域内的每个位置，根据上述规则计算其字符即可。

### 3. 时间复杂度

每个查询需要遍历最多 $101 \times 101 = 10201$ 个位置，每个位置的计算是 $O(1)$ 的。总共有最多 $30$ 组数据，每组最多 $50$ 个查询，因此总计算量大约为 $30 \times 50 \times 10201 \approx 1.53 \times 10^7$ 次操作，在合理范围内。

## 解题思路

1. 读入测试用例数 $numCases$ 。
2. 对每个测试用例：
   - 读入特征字符串 $S$ 和查询数 $Q$ 。
   - 计算正方形边长 $N = 2 \times |S| - 1$ 。
   - 输出当前测试用例的标题 `Square caseNo:`。
   - 对每个查询：
     - 读入矩形坐标 $r_1, c_1, r_2, c_2$ 。
     - 输出查询标题 `Query queryNo:`。
     - 遍历 $r = r_1$ 到 $r_2$ ， $c = c_1$ 到 $c_2$ ：
       - 计算当前位置 $(r, c)$ 的层数 $level$ 。
       - 输出字符 $S[level]$ 。
       - 每输出完一行（即固定 $r$ ，遍历完所有 $c$ 后）输出换行符。
   - 每个测试用例输出结束后，输出一个空行。

## 注意事项

- 字符串下标从 $0$ 开始，层数 $level$ 也对应 $S$ 的下标。
- 输入格式中每组数据之间有一个空行，但输出格式中仅要求每个测试用例的输出后有一个空行。
- 坐标范围保证在 $[1, N]$ 内，且矩形区域合法。

## 代码实现

```cpp
// Nested Squares
// UVa ID: 12115
// Verdict: Accepted
// Submission Date: 2025-12-
// UVa Run Time: 0.040s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int numCases;
    cin >> numCases;
    for (int caseNo = 1; caseNo <= numCases; caseNo++) {
        string s;
        int q;
        cin >> s >> q;
        int n = 2 * s.length() - 1; // 正方形边长
        
        cout << "Square " << caseNo << ":\n";
        for (int queryNo = 1; queryNo <= q; queryNo++) {
            int r1, c1, r2, c2;
            cin >> r1 >> c1 >> r2 >> c2;
            cout << "Query " << queryNo << ":\n";
            
            for (int r = r1; r <= r2; r++) {
                for (int c = c1; c <= c2; c++) {
                    // 计算到四个边界的最小距离
                    int distUp = r - 1;
                    int distDown = n - r;
                    int distLeft = c - 1;
                    int distRight = n - c;
                    int level = min(min(distUp, distDown), min(distLeft, distRight));
                    cout << s[level];
                }
                cout << "\n";
            }
        }
        cout << "\n";
    }
    return 0;
}
```
