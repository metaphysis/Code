## 题目描述

$\texttt{ACM}$（儿童机器协会）计划为儿童设计一种新型拼图。所有拼图的尺寸都是 $3 \times N$ ，并使用 $22$ 种特定的拼图块（某些块可以重复使用）。为了防止假冒产品，$\texttt{ACM}$ 生产的拼图在出售时只会保留某些特定的解法。给定 $N$ （ $0 < N < 2001$ ），计算使用给定拼图块可以组成多少种不同的解法。不允许旋转拼图块，但每种块可以使用任意多次。有些块只是其他块的旋转版本，但也不能通过旋转使其变成另一种块。

### 输入格式

输入文件包含多行，每行一个整数 $N$ （ $0 < N < 2001$ ）。输入以一行单独的 $0$ 结束。

### 输出格式

对于每个 $N$ ，输出一行，格式为 `Case k: ans` ，其中 $answer = S \mod 10^{12}$ ，$S$ 是 $3 \times N$ 拼图的解法总数。

### 样例输入

```
5
100
0
```

### 样例输出

```
Case 1: 26
Case 2: 584039302899
```

## 题目分析

### 问题本质

这是一个 **铺砖问题** （$\texttt{Tiling Problem}$）的变种：用 $22$ 种给定的、不可旋转的拼图块填满 $3 \times N$ 的矩形区域。由于 $N$ 最大可达 $2000$ ，需要设计一个高效的动态规划算法。

### 关键难点

1. **块形状复杂** ： $22$ 种块形状各异，宽度可能是 $1$ 、 $2$ 或 $3$ 列。
2. **不允许旋转** ：即使某些块看起来是旋转对称的，也被视为不同的块。
3. **大数取模** ：结果需要对 $10^{12}$ 取模，说明结果可能非常大。

### 解题思路分析

#### 1. 状态定义

观察到拼图块的宽度最多为 $3$ 列，我们可以采用 **列轮廓线动态规划** 的思路。定义状态为：

$dp[i][p][q][r]$ 表示：
- 已经填充到第 $i$ 列
- 第 $i+1$ 列的三行分别有 $p$ 、 $q$ 、 $r$ 个格子已被占用（从之前的块延伸过来的部分）
- 其中 $p, q, r \in \{0, 1, 2\}$ ，表示第 $i+1$ 列有多少个格子已被占据

这个状态表示当前填充的前沿位置以及下一列的“欠债”情况（即有多少格子已经被之前的块占用）。

#### 2. 状态转移

对于每个状态 $(i, p, q, r)$ ，我们尝试放置 $22$ 种拼图块中的一种。每个拼图块被定义为一个 $3 \times 3$ 的字符数组，其中：
- `'*'` 表示该位置被块占用
- `' '` （空格）表示该位置为空

转移时需要检查：
1. 块的左侧三列是否与当前偏移 $(p, q, r)$ 匹配（即对应位置必须是 `'*'`）
2. 块的左侧不能有额外的填充超出边界
3. 计算放置块后新的偏移量

#### 3. 偏移归一化

放置一个块后，可能会产生新的偏移。为了保持状态空间的大小可控，我们进行 **偏移归一化** ：计算新的 $p', q', r'$ 值后，将它们减去最小值，使至少一个值为 $0$ ，其他值在 $0$ 到 $2$ 之间。这样状态数量被限制在合理的范围内。

#### 4. 算法流程

1. 初始化 $dp[0][0][0][0] = 1$ （空棋盘一种方案）
2. 对于每个 $i$ 从 $0$ 到 $2000$ ，遍历所有 $(p, q, r)$ 状态
3. 对于每个状态，尝试放置 $22$ 种块中的每一种
4. 检查放置是否合法，计算新状态并更新 $dp$ 值
5. 对于输入的 $N$ ，答案就是 $dp[N][0][0][0]$ （完全填满 $N$ 列且无偏移）

#### 5. 复杂度分析

- **时间复杂度** ： $O(N \times 3^3 \times 22) \approx O(600N)$ ，对于 $N \leq 2000$ 可以接受
- **空间复杂度** ： $O(N \times 3^3) \approx O(27N)$ ，可以通过滚动数组优化，但本题 $N$ 较小，直接开数组即可

### 为什么这种方法有效？

1. **状态压缩** ：通过偏移量表示未完成的部分，避免了记录整个棋盘状态
2. **完全性** ：枚举所有块和所有可能的位置，不会遗漏任何合法解
3. **高效性** ：状态数有限，转移代价小，适合 $N$ 较大的情况

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const ll MOD = 1000000000000LL;

// 22种拼图块的定义
char puzzleBlocks[22][3][4] = {
    {"*  ", "*  ", "*  "}, {"*  ", "** ", "*  "}, {"** ", " * ", "** "},
    {" * ", "** ", "** "}, {" * ", "***", " * "}, {"** ", "*  ", "** "},
    {" * ", "** ", " * "}, {"  *", " **", "** "}, {"** ", " **", "  *"},
    {" * ", "** ", "*  "}, {"*  ", "** ", " * "}, {"** ", "** ", "*  "},
    {"** ", "** ", " * "}, {"** ", "*  ", "*  "}, {"** ", " * ", " * "},
    {" **", "** ", "*  "}, {"*  ", "** ", " **"}, {"*  ", "*  ", "** "},
    {" * ", " * ", "** "}, {"***", " * ", " * "}, {" * ", " * ", "***"},
    {"*  ", "** ", "** "}
};

ll dp[2005][3][3][3];  // dp[i][p][q][r]

void initialize() {
    // 初始化dp数组为0
    memset(dp, 0, sizeof(dp));
    dp[0][0][0][0] = 1;  // 起始状态

    for (int i = 0; i <= 2000; i++) {
        for (int p = 0; p < 3; p++)
        for (int q = 0; q < 3; q++)
        for (int r = 0; r < 3; r++) {
            ll currentVal = dp[i][p][q][r];
            if (currentVal == 0) continue;

            // 尝试放置22种块中的每一种
            for (int blockIdx = 0; blockIdx < 22; blockIdx++) {
                // 检查块左侧三列是否与当前偏移匹配
                if (puzzleBlocks[blockIdx][0][p] != '*' ||
                    puzzleBlocks[blockIdx][1][q] != '*' ||
                    puzzleBlocks[blockIdx][2][r] != '*') continue;

                // 检查左侧是否有额外填充（不能超出边界）
                if (p > 0 && puzzleBlocks[blockIdx][0][p-1] != ' ') continue;
                if (q > 0 && puzzleBlocks[blockIdx][1][q-1] != ' ') continue;
                if (r > 0 && puzzleBlocks[blockIdx][2][r-1] != ' ') continue;

                // 计算放置后的新偏移
                int newP = i + p, newQ = i + q, newR = i + r;
                for (int k = 0; k < 3; k++) {
                    if (puzzleBlocks[blockIdx][0][k] == '*') newP++;
                    if (puzzleBlocks[blockIdx][1][k] == '*') newQ++;
                    if (puzzleBlocks[blockIdx][2][k] == '*') newR++;
                }

                // 标准化偏移（减去最小值）
                int minVal = min({newP, newQ, newR});
                int offsetP = newP - minVal;
                int offsetQ = newQ - minVal;
                int offsetR = newR - minVal;

                // 更新dp值
                dp[minVal][offsetP][offsetQ][offsetR] += currentVal;
                if (dp[minVal][offsetP][offsetQ][offsetR] >= MOD)
                    dp[minVal][offsetP][offsetQ][offsetR] %= MOD;
            }
        }
    }
}

int main() {
    initialize();
    int n, caseNo = 1;
    while (cin >> n && n != 0)
        cout << "Case " << caseNo++ << ": " << dp[n][0][0][0] << "\n";
    return 0;
}
```

## 总结

本题是一个经典的 **状态压缩动态规划** 问题，通过巧妙的状态设计将复杂的铺砖问题转化为可管理的动态规划。关键点在于：

1. **偏移量状态表示** ：用 $p, q, r$ 表示下一列的占用情况
2. **偏移归一化** ：通过减去最小值控制状态空间大小
3. **完全枚举** ：尝试所有 $22$ 种块的放置方式

这种解法具有通用性，可以应用于类似的拼图或铺砖问题。理解这种状态表示和转移方法对于解决复杂的组合计数问题非常有帮助。
