[UVa 12128 Escape from Enemy Territory](https://blog.csdn.net/metaphysis/article/details/161970714)

## 题目描述

在一个 $X \times Y$ 的矩形网格上（坐标 $0 \le x < X$，$0 \le y < Y$），给定突击队员的起点、终点以及 $N$ 个敌军基地的坐标。每次移动只能沿水平或垂直方向走一步（曼哈顿距离）。需要找出一条从起点到终点的路径，使得路径上每个格子到最近敌军基地的曼哈顿距离的最小值尽可能大。如果有多个这样的路径，选择其中长度最短的一条。输出这个最大化的最小距离以及对应最短路径的长度。

## 输入格式

第一行一个正整数 $T$（$T \le 100$），表示测试用例数量。  
每个测试用例：  
- 第一行三个正整数 $N, X, Y$，$1 \le N \le 10000$，$1 \le X, Y \le 1000$。  
- 第二行四个整数 $x_i, y_i, x_r, y_r$，分别表示起点和终点的坐标。  
- 接下来 $N$ 行，每行两个整数 $x, y$，表示一个敌军基地的坐标。所有坐标均在网格内且互不相同。

## 输出格式

对于每个测试用例，输出一行两个整数，用空格隔开：  
第一个是路径上所有点到最近敌军基地的曼哈顿距离的最小值的最大值，第二个是在该最小值下最短路径的长度。

## 样例

输入

```
2
1 2 2
0 0 1 1
0 1
2 5 6
0 0 4 0
2 1
2 3
```

输出

```
2 14
```

## 题目分析

本题的核心在于两个目标的平衡：  
- **最大化**路径上所有格子到最近敌军基地的**最小距离**（称为“安全距离”）。  
- 在安全距离最大的前提下，**最小化**路径长度（步数）。

直接枚举所有可能的路径是不可能的，因为网格规模最大可达 $10^6$ 个格子，路径数量爆炸。

我们需要一种方法，能够针对一个给定的安全距离 $D$，快速判断是否存在一条从起点到终点的路径，使得路径上所有格子的最近敌军距离都 $\ge D$，并在存在时求出最短路径长度。

这类似于在带权图上找一条路径，使得路径上边权的最小值最大化，然后在该条件下取最短路径。这里每个格子的“权值”就是它到最近敌军基地的距离。

## 解题思路

### 第一步：计算每个格子的最近敌军距离

由于敌军基地可能有多个，我们需要计算每个格子到**所有敌军基地**的曼哈顿距离的最小值。这是典型的多源最短路问题，可以使用 $\texttt{BFS}$ 一次性完成：

- 将所有敌军基地作为初始源点，距离设为 $0$ 并入队。
- 进行 $\texttt{BFS}$，每次向四个方向扩展一步，得到每个格子到最近敌军基地的曼哈顿距离。

因为曼哈顿距离在网格上的 $\texttt{BFS}$ 等价于按层扩展，这个 $\texttt{BFS}$ 的复杂度是 $O(X \times Y)$，在 $X, Y \le 1000$ 时可行。

### 第二步：二分安全距离

设 $\textit{dist}[x][y]$ 为格子 $(x, y)$ 到最近敌军基地的距离。题目要求我们最大化路径上的最小 $\textit{dist}$ 值。

定义函数 $\texttt{can}(D)$：是否存在一条从起点到终点的路径，使得路径上所有格子的 $\textit{dist} \ge D$。  
如果 $\texttt{can}(D)$ 为真，那么安全距离至少可以取到 $D$；否则必须降低。

由于安全距离不会超过网格中任意两点间的最大曼哈顿距离（即 $X + Y$），我们可以在这个范围内进行二分查找：

- 下界 $low = 0$（可能紧邻敌军基地）。
- 上界 $high = X + Y$（理论上最大可能距离）。
- 每次取 $mid = (low + high) / 2$，检查 $\texttt{can}(mid)$。
- 如果成立，则尝试更大的 $mid$；否则减小 $mid$。

二分结束后得到最大安全距离 $\textit{bestDist}$。

### 第三步：在最佳安全距离下求最短路径

已知最大安全距离 $\textit{bestDist}$，我们再次进行 $\texttt{BFS}$，但这次只允许进入满足 $\textit{dist} \ge \textit{bestDist}$ 的格子。从起点开始 $\texttt{BFS}$，记录步数，到达终点时即得最短路径长度。

### 复杂度分析

- 多源 $\texttt{BFS}$ 求 $\textit{dist}$：$O(X \times Y)$。
- 二分查找：$\log(X+Y)$ 次，每次 $\texttt{can}(D)$ 的检查是另一个 $\texttt{BFS}$，复杂度 $O(X \times Y)$。  
  总复杂度 $O(X \times Y \times \log(X+Y))$，在 $X, Y \le 1000$ 时可行（约 $10^6 \times 10$ 次操作）。

## 代码实现

```cpp
// Escape from Enemy Territory
// UVa ID: 12128
// Verdict: Accepted
// Submission Date: 2026-06-14
// UVa Run Time: 0.150s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int dx[4] = {0, 1, 0, -1};
const int dy[4] = {1, 0, -1, 0};

struct Point {
    int x, y;
    Point(int x_, int y_) : x(x_), y(y_) {}
};

// 多源 BFS 计算每个格子到最近敌军基地的距离
vector<vector<int>> computeNearestDist(int X, int Y, const vector<Point>& enemies) {
    vector<vector<int>> dist(X, vector<int>(Y, -1));
    queue<Point> q;
    for (const auto& e : enemies) {
        dist[e.x][e.y] = 0;
        q.push(e);
    }
    while (!q.empty()) {
        Point p = q.front(); q.pop();
        for (int i = 0; i < 4; ++i) {
            int nx = p.x + dx[i], ny = p.y + dy[i];
            if (nx >= 0 && nx < X && ny >= 0 && ny < Y && dist[nx][ny] == -1) {
                dist[nx][ny] = dist[p.x][p.y] + 1;
                q.push(Point(nx, ny));
            }
        }
    }
    return dist;
}

// 检查在安全距离 >= minDist 的情况下，从起点到终点是否可达，并返回最短路径长度（如果可达）
int bfsWithMinDist(int X, int Y, const Point& start, const Point& goal, 
                   const vector<vector<int>>& nearestDist, int minDist) {
    if (nearestDist[start.x][start.y] < minDist || nearestDist[goal.x][goal.y] < minDist)
        return -1;
    vector<vector<int>> step(X, vector<int>(Y, -1));
    queue<Point> q;
    step[start.x][start.y] = 0;
    q.push(start);
    while (!q.empty()) {
        Point p = q.front(); q.pop();
        if (p.x == goal.x && p.y == goal.y)
            return step[p.x][p.y];
        for (int i = 0; i < 4; ++i) {
            int nx = p.x + dx[i], ny = p.y + dy[i];
            if (nx >= 0 && nx < X && ny >= 0 && ny < Y && step[nx][ny] == -1 && nearestDist[nx][ny] >= minDist) {
                step[nx][ny] = step[p.x][p.y] + 1;
                q.push(Point(nx, ny));
            }
        }
    }
    return -1;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int T;
    cin >> T;
    while (T--) {
        int N, X, Y;
        cin >> N >> X >> Y;
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        Point start(x1, y1), goal(x2, y2);
        
        vector<Point> enemies;
        for (int i = 0; i < N; ++i) {
            int ex, ey;
            cin >> ex >> ey;
            enemies.emplace_back(ex, ey);
        }
        
        // 计算每个格子到最近敌军基地的距离
        vector<vector<int>> nearestDist = computeNearestDist(X, Y, enemies);
        
        // 二分查找最大安全距离
        int low = 0, high = X + Y, bestDist = 0;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (bfsWithMinDist(X, Y, start, goal, nearestDist, mid) != -1) {
                bestDist = mid;
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        
        // 在最佳安全距离下，找最短路径长度
        int shortestPath = bfsWithMinDist(X, Y, start, goal, nearestDist, bestDist);
        cout << bestDist << " " << shortestPath << "\n";
    }
    
    return 0;
}
```

## 总结

本题是典型的“最大化最小值 + 最短路径”二合一问题，解题关键点如下：

1. **多源 $\texttt{BFS}$** 高效计算每个格子到最近敌军基地的曼哈顿距离。
2. **二分答案** 用来找到可达到的最大安全距离，避免直接枚举。
3. **条件 $\texttt{BFS}$** 用于检查给定安全距离下路径的存在性，以及最终求最短路径。
4. 时间复杂度 $O(X \times Y \times \log(X+Y))$ 在给定约束下完全可行。

这种“最大化最小值”的思想在路径规划、网络流、资源分配等问题中非常常见，通常与二分查找结合使用。掌握此技巧对解决类似的优化问题有很大帮助。
