## 题目描述

停车场有一个塔式结构，高度为 $h$ 层，每层有一个长度为 $l$ 的环形传送带。电梯位于第一层入口（位置 $0$ ），可以在各层之间垂直移动，到达某一层后会与该层的传送带连接。每层传送带可以顺时针或逆时针旋转，将车辆移动到电梯位置。

取车规则：按车辆编号 $1, 2, 3, \dots$ 的顺序依次取车。每取一辆车的过程如下：

1. 电梯从当前位置移动到目标车辆所在楼层
2. 该层传送带旋转，将目标车辆送到电梯位置
3. 车辆进入电梯，电梯返回第一层入口

**移动时间**：

- 电梯每移动一层：$10$ 秒
- 传送带每移动一个车位：$5$ 秒

输入初始停车布局（ $-1$ 表示空位，正数表示车辆编号），求取完所有车辆所需的总时间。

## 题目分析

### 关键点解析

1. **环形传送带**  
   每层传送带是环形的，长度为 $l$ ，位置编号从 $0$ 到 $l-1$ 。传送带可以顺时针或逆时针旋转，因此从当前位置 $p$ 移动到目标位置 $q$ 的最短距离为：
$$
   \min\big((q - p + l) \bmod l,\ (p - q + l) \bmod l\big)
$$
   乘以 $5$ 即为旋转时间。

2. **电梯与传送带的连接位置**  
   电梯每次到达某一层时，并不是固定连接该层的 $0$ 号位置。实际上，电梯在该层有一个“当前连接位置”，这个位置会随着取车操作而改变：  
   当电梯在该层取走位置 $x$ 上的车辆后，电梯本身占据了该位置（因为车辆从传送带移到电梯上），所以下一次电梯再来到这一层时，它连接的是上次取车时车辆原来的位置 $x$ 。  
   因此需要为每一层单独维护一个变量 $\texttt{elevatorPos[floor]}$ ，表示电梯下一次到达该层时所连接的位置。

3. **初始状态**  
   - 所有层的 $\texttt{elevatorPos[floor]} = 0$ （电梯初始在第一层位置 $0$ ，其他层虽然没有电梯，但可以理解为该层传送带的 $0$ 位置与电梯井对齐）
   - 电梯当前所在楼层 $\texttt{currentFloor} = 0$ （第 $1$ 层索引为 $0$ ）

4. **取车流程**  
   对于编号为 $car$ 的车辆，设其位于 $\texttt{targetFloor}$ 层的 $\texttt{targetPos}$ 位置：
   - **电梯移动时间**： $\lvert \texttt{targetFloor} - \texttt{currentFloor} \rvert \times 10$
   - **传送带旋转时间**：  
     该层当前连接位置为 $\texttt{elevatorPos[targetFloor]}$ ，将目标车辆旋转到此位置的最短距离为：
$$
     \min\big((\texttt{targetPos} - \texttt{elevatorPos[targetFloor]} + l) \bmod l,\ (\texttt{elevatorPos[targetFloor]} - \texttt{targetPos} + l) \bmod l\big) \times 5
$$
   - **更新该层电梯位置**：取车后，电梯在该层的位置变为 $\texttt{targetPos}$  
$$
     \texttt{elevatorPos[targetFloor]} = \texttt{targetPos}
$$
   - **电梯返回第一层**：时间 $\texttt{targetFloor} \times 10$ （第一层返回时间为 $0$ ）
   - **更新当前楼层**： $\texttt{currentFloor} = 0$

5. **关于最后一辆车**  
   最后一辆车也需要返回第一层，因为客户是在第一层入口取车。题目示例也印证了这一点（若最后一辆车不返回，总时间会减少）。

### 时间复杂度

每个测试用例需要处理 $N$ 辆车（ $N \le h \times l \le 2500$ ），每辆车的处理为 $O(1)$ ，因此总时间复杂度 $O(h \times l)$ ，在给定约束下完全可以接受。

## 解题步骤

1. 读取测试用例个数 $T$ 。
2. 对每个测试用例：
   - 读取 $h$ 和 $l$ 。
   - 遍历 $h \times l$ 的停车布局，对每个正数 $val$ ，记录：
     - $\texttt{carFloor[val]} = i$ （车辆所在楼层， $i$ 从 $0$ 开始）
     - $\texttt{carPos[val]} = j$ （车辆在传送带上的位置）
     - $\texttt{maxCar} = \max(\texttt{maxCar},\ val)$ （最大编号，即车辆总数）
   - 初始化：
     - $\texttt{elevatorPos}$ 数组，长度为 $h$ ，全部赋值为 $0$
     - $\texttt{currentFloor} = 0$
     - $\texttt{totalTime} = 0$
   - 从 $car = 1$ 到 $\texttt{maxCar}$ 依次处理：
     - 计算电梯移动时间并累加
     - 计算传送带旋转时间并累加
     - 更新 $\texttt{elevatorPos[targetFloor]}$
     - 累加返回第一层的时间
     - 设置 $\texttt{currentFloor} = 0$
   - 输出 $\texttt{totalTime}$

## 示例验证

### 示例输入

```
2
1 5
-1 2 1 -1 3
3 6
-1 5 6 -1 -1 3
-1 -1 7 -1 2 9
-1 10 4 1 8 -1
```

### 示例输出

```
25
320
```

**解析**：

- 第一个测试用例： $h=1,\ l=5$ ，只有一层。取车顺序 $1 \to 2 \to 3$ 。电梯无需移动，只需旋转传送带。初始 $\texttt{elevatorPos[0]}=0$ 。取车 $1$ （位置 $2$ ）：顺时针 $2$ 步 $=10$ 秒，返回 $0$ 秒，总 $10$ 秒，更新位置为 $2$ 。取车 $2$ （位置 $1$ ）：逆时针 $1$ 步 $=5$ 秒，总 $15$ 秒，更新位置为 $1$ 。取车 $3$ （位置 $4$ ）：顺时针 $3$ 步 $=15$ 秒，总 $30$ 秒？但输出为 $25$ —— 检查发现：取车 $2$ 后位置为 $1$ ，取车 $3$ 在位置 $4$ ：顺时针距离 $(4-1+5)\%5=3$ ，逆时针距离 $(1-4+5)\%5=2$ ，取最小值 $2 \times 5 = 10$ 秒，所以 $10+5+10=25$ 。正确。

```cpp
// Tower Parking

// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int testcases;
    scanf("%d", &testcases);
    while (testcases--) {
        int h, l;
        scanf("%d %d", &h, &l);
        
        // 记录每辆车所在的楼层和位置，车辆编号最大为 h*l
        vector<int> carFloor(2505, -1);
        vector<int> carPos(2505, -1);
        int maxCar = 0;
        
        for (int i = 0; i < h; ++i) {
            for (int j = 0; j < l; ++j) {
                int val;
                scanf("%d", &val);
                if (val != -1) {
                    carFloor[val] = i;
                    carPos[val] = j;
                    if (val > maxCar) maxCar = val;
                }
            }
        }
        
        // elevatorPos[floor] 表示电梯在该层当前连接的位置
        vector<int> elevatorPos(h, 0);
        int currentFloor = 0;  // 电梯当前所在楼层
        int totalTime = 0;
        
        for (int car = 1; car <= maxCar; ++car) {
            int targetFloor = carFloor[car];
            int targetPos = carPos[car];
            
            // 1. 电梯移动到目标楼层
            totalTime += abs(targetFloor - currentFloor) * 10;
            
            // 2. 传送带将目标车旋转到电梯位置
            int distClockwise = (targetPos - elevatorPos[targetFloor] + l) % l;
            int distCounterClockwise = (elevatorPos[targetFloor] - targetPos + l) % l;
            totalTime += min(distClockwise, distCounterClockwise) * 5;
            
            // 3. 更新该层电梯连接位置（车被取走后，电梯占据该位置）
            elevatorPos[targetFloor] = targetPos;
            
            // 4. 电梯返回第一层
            totalTime += targetFloor * 10;
            
            // 5. 更新当前楼层
            currentFloor = 0;
        }
        
        printf("%d\n", totalTime);
    }
    return 0;
}
```

## 注意事项

- 使用 $0$ 索引表示楼层和位置，便于取模运算
- 环形距离计算需要加 $l$ 再取模，避免负数
- 最后一辆车也需要返回第一层，因为客户在第一层入口取车
- 每层的电梯连接位置必须独立维护，不能假设总是 $0$
