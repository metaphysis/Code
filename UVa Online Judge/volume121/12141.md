## 题目描述

$\texttt{ACRush}$ 正在分析他在 $\texttt{Supercoder}$ 平台上的评分历史数据。在 $\texttt{Supercoder}$ 中，每次算法竞赛被称为单轮锦标赛（$\texttt{SRT}$）。每次 SRT 结束后，参赛者的评分会根据相对表现进行更新。

$\texttt{ACRush}$ 收集了所有评分信息，并绘制了一条折线图。绘制规则如下：
- 第 $i$ 场 $\texttt{SRT}$ 后，在坐标 $(i, \texttt{rating}_i)$ 处标记点 $r_i$
- 将所有相邻点用直线连接，形成折线图

折线图中有两种峰值：
- **上峰**：该点的前一个点和后一个点的 $y$ 坐标都比它小
- **下峰**：该点的前一个点和后一个点的 $y$ 坐标都比它大

现在 $\texttt{ACRush}$ 想知道：通过忽略 $0$ 场或多场 $\texttt{SRT}$，可以得到多少个**不同的**恰好有 $K$ 个峰值的折线图？在 $K$-峰值折线图中，不允许两个连续点有相同的 $y$ 坐标。

**输入格式**
- 第一行：整数 $T$ ($T \leq 12$)，测试用例数
- 每个测试用例：
  - 第一行：$N$ ($1 \leq N \leq 10000$) 和 $K$ ($0 \leq K \leq 50$)
  - 接下来 $N$ 行：每行两个整数 $\text{SRT}$ ($1 \leq \text{SRT} \leq 10^9$) 和 $\text{Rating}$ ($1 \leq \text{Rating} \leq 10^9$)

**输出格式**
- 对每个测试用例输出：`Case #: W`，其中 $W$ 是满足条件的折线图数量模 $1000000$ 的结果

## 题目分析

### 问题本质

这个问题要求统计所有可能的子序列（保持原顺序）中，恰好包含 $K$ 个峰值的**不同折线图**数量。关键在于理解：

1. **不同的折线图**：如果两个子序列产生的折线图形状相同（即评分序列相同），即使选择的点集不同，也只算作一个折线图
2. **峰值定义**：一个点是峰值需要三个点 - 前一个点、当前点、后一个点
3. **趋势变化**：峰值出现在趋势发生变化的位置（从上升到下降产生上峰，从下降到上升产生下峰）

### 样例分析

以样例 2 为例：
```
4 1
101 3
102 2
103 2
104 4
```

排序后的评分序列：$3, 2, 2, 4$

虽然选择点 $\{101,102,104\}$ 和 $\{101,103,104\}$ 是不同的子序列，但它们产生的折线图都是 $3 \to 2 \to 4$，因此只算作一个不同的折线图。

## 解题思路

### 动态规划状态设计

我们使用三维动态规划状态：

$dp[i][k][s]$ 表示以第 $i$ 个点结尾，有 $k$ 个峰值，并且下一个点应该接：

- $s = 0$：较低的 $y$ 值（当前处于下降趋势）
- $s = 1$：较高的 $y$ 值（当前处于上升趋势）  
- $s = 2$：相等的 $y$ 值（虽然题目不允许连续相等，但用于特殊状态处理）

### 状态转移

对于当前点 $i$，枚举所有 $j < i$：

**从状态 $s=2$ 转移**（接相等值，实际用于延续趋势）：
- 接较低值 $\to$ $s=0$，峰值数不变
- 接较高值 $\to$ $s=1$，峰值数 $+1$（产生新峰值）
- 接相等值 $\to$ $s=2$，峰值数不变

**从状态 $s=1$ 转移**（接较高值）：
- 接较低值 $\to$ $s=0$，峰值数 $+1$（产生新峰值）
- 接较高值 $\to$ $s=1$，峰值数不变
- 接相等值 $\to$ $s=2$，峰值数 $+1$（产生新峰值）

### 算法优化

直接 $O(N^2K)$ 的 $\texttt{DP}$ 会超时，我们使用以下优化：

1. **树状数组优化**：维护 $6$ 个树状数组（$3$ 种状态 $\times$ $2$ 个方向）来快速查询和更新状态
2. **坐标压缩**：将评分值映射到连续整数范围
3. **去重机制**：使用 `shift` 数组确保相同评分的点不会产生重复计数

### 复杂度分析

- **时间复杂度**：$O(NK \log N)$
- **空间复杂度**：$O(NK)$

```cpp
// Line Chart

#include <stdio.h> 
#include <vector>
#include <string.h>
#include <algorithm>
#include <map>
using namespace std;

#define MAXN 10050
const int MOD = 1000000;

int U[64][3][MAXN], D[64][3][MAXN];
int shift[64][3][MAXN];

int query(int A[], int idx) {
    int sum = 0;
    while (idx) 
        sum = (sum + A[idx]) % MOD, idx -= idx & -idx;
    return sum;
}

void update(int A[], int idx, int val, int L) {
    while (idx <= L) 
        A[idx] = (A[idx] + val) % MOD, idx += idx & -idx;
}

int main() {
    int T, n, k, x, y;
    int cases = 0;
    scanf("%d", &T);
    
    while (T--) {
        scanf("%d %d", &n, &k);
        vector<pair<int, int>> v;
        map<int, int> mp;
        
        for (int i = 0; i < n; i++) {
            scanf("%d %d", &x, &y);
            mp[y] = 0;
            v.push_back(make_pair(x, y));
        }
        
        sort(v.begin(), v.end());
        int L = 1;
        for (auto &it : mp) it.second = L++;
        for (int i = 0; i < n; i++) 
            v[i].second = mp[v[i].second];
        
        memset(U, 0, sizeof(U));
        memset(D, 0, sizeof(D));
        memset(shift, 0, sizeof(shift));
        
        int used[10005] = {};
        for (int i = 0; i < n; i++) {
            if (!used[v[i].second]) {
                shift[0][0][v[i].second] = -1;
                used[v[i].second] = 1;
            }
        }
        
        update(U[0][1], 1, 1, L);
        update(U[0][2], 1, 1, L);
        
        int ans = 0;
        if (k == 0) ans++;
        
        for (int i = 0; i < n; i++) {
            int r = v[i].second;
            
            for (int j = 0; j <= k; j++) {
                int s0 = (query(U[j][0], r) + query(D[j][0], L - r - 1) - shift[j][0][r]) % MOD;
                int s1 = (query(U[j][1], r) + query(D[j][1], L - r - 1) - shift[j][1][r]) % MOD;
                int s2 = (query(U[j][2], r) + query(D[j][2], L - r - 1) - shift[j][2][r]) % MOD;
                
                shift[j][0][r] = (shift[j][0][r] + s0) % MOD;
                shift[j][1][r] = (shift[j][1][r] + s1) % MOD;
                shift[j][2][r] = (shift[j][2][r] + s2) % MOD;
                
                if (j == k) ans = (ans + s0) % MOD;
                
                if (s2) {
                    update(U[j][0], r + 1, s2, L);
                    update(U[j][2], r + 1, s2, L);
                    if (j + 1 <= k) 
                        update(U[j + 1][1], r + 1, s2, L);
                }
                
                if (s1) {
                    update(D[j][0], L - r, s1, L);
                    update(D[j][1], L - r, s1, L);
                    if (j + 1 <= k)
                        update(D[j + 1][2], L - r, s1, L);
                }
            }
        }
        
        printf("Case %d: %d\n", ++cases, (ans + MOD) % MOD);
    }
    return 0;
}
```

## 总结

本题的关键在于理解"不同的折线图"统计的是不同的评分序列，而不是不同的点选择方案。通过精细的状态设计和树状数组优化，我们能够在合理的时间内解决这个看似复杂的问题。

算法核心思想：
1. 使用三维状态记录趋势信息
2. 通过树状数组优化状态转移
3. 利用去重机制确保统计的是不同的折线图

这种结合动态规划和数据结构优化的方法，在处理大规模数据时非常有效。
