## 题目描述

$\texttt{Thomas}$ 是一位研究 $\texttt{DNA}$ 序列的计算机科学家，他需要计算给定字符串对的最长公共子序列。但是，这里有一个额外的要求：这个公共子序列必须由**长度至少为 $K$** 的公共连续段构成。

### 基本概念

- **子序列**：从原字符串中删除零个或多个字符后得到的序列，字符的相对顺序保持不变。
- **连续段/子串**：在原字符串中连续出现的字符序列。
- **公共子序列**：同时是两个字符串的子序列的字符串。
- **最长公共子序列**：具有最大长度的公共子序列。

### 额外要求

在本题中，公共子序列必须满足以下条件：
- 它可以被划分为若干个"段"
- 每个段在两个原始字符串中都是连续出现的（作为子串）
- 每个段的长度都至少为 $K$

### 输入格式

输入包含多个测试用例：
- 每个测试用例的第一行是一个整数 $K$ $(1 \leq K \leq 100)$
- 接下来两行各包含一个由小写字母组成的字符串，长度 $l$ $(1 \leq l \leq 10^3)$
- 输入的结束以一行包含一个 $0$ 表示

### 输出格式

对于每个测试用例，输出一行，表示满足条件的最长子序列的长度。如果不存在这样的子序列，则输出 $0$。

### 样例输入

```
3
lovxxelyxxxxx
xxxxxxxlovely
1
lovxxelyxxxxx
xxxxxxxlovely
3
lovxxxelxyxxxx
xxxlovelyxxxxxxx
4
lovxxxelyxxx
xxxxxxlovely
0
```

### 样例输出

```
6
7
10
0
```

## 题目分析

### 问题理解

首先，我们需要理解题目中的关键概念。普通的**最长公共子序列**（$\texttt{LCS}$）问题允许我们选择任意位置的字符，只要它们相对顺序一致。但本题增加了一个约束：选择的字符序列必须由若干个**长度至少为 $K$ 的公共连续段**组成。

举个例子，假设 $K = 3$，字符串 $A = \texttt{"lovxxelyxxxxx"}$ 和 $B = \texttt{"xxxxxxxlovely"}$：
- 子序列 $\texttt{"lovely"}$ 是可接受的：它可以看作是由长度至少为 $3$ 的连续段组成：$\texttt{"lov"}$ 和 $\texttt{"ely"}$
- 子序列 $\texttt{"xxxxxxx"}$（长度为 $7$）虽然也是公共子序列，但不可接受：它可以由 $\texttt{"xx"}$ 和 $\texttt{"xxxxx"}$ 组成，第一个"段"的长度只有 $2$，小于 $K = 3$

### 关键洞察

1. **段的概念**：每个段在两个原始字符串中都必须连续出现，但不同的段可以在字符串的不同位置。
2. **最小长度约束**：每个段的长度必须至少为 $K$。
3. **组合性**：我们可以将多个这样的段组合起来形成一个更长的子序列。

### 与普通 $\texttt{LCS}$ 的区别

普通 $\texttt{LCS}$ 的状态转移方程是：
$$
dp[i][j] = 
\begin{cases}
dp[i-1][j-1] + 1, & \text{if } A[i] = B[j] \\
\max(dp[i-1][j], dp[i][j-1]), & \texttt{otherwise}
\end{cases}
$$

但在本题中，当 $A[i] = B[j]$ 时，我们不能简单地将 $dp[i][j]$ 设为 $dp[i-1][j-1] + 1$，因为这样可能会产生长度小于 $K$ 的段。我们需要确保每次添加的字符都至少是一个长度 $\geq K$ 的连续段的一部分。

## 解题思路

### 动态规划设计

我们定义两个二维数组：

1. **$dp[i][j]$**：表示考虑字符串 $A$ 的前 $i$ 个字符和字符串 $B$ 的前 $j$ 个字符时，能够获得的最大长度。
2. **$matched[i][j]$**：表示以 $A[i]$ 和 $B[j]$ 结尾的最长公共子串的长度。

### 状态转移

#### 计算 $matched$ 数组

$matched[i][j]$ 的计算相对简单：
- 如果 $A[i-1] = B[j-1]$，那么 $matched[i][j] = matched[i-1][j-1] + 1$
- 否则 $matched[i][j] = 0$

这个数组告诉我们，以当前位置结尾的最长公共子串有多长。

#### 计算 $dp$ 数组

对于 $dp[i][j]$，我们需要考虑几种情况：

1. **不选择当前字符**：
   - 我们可以从 $dp[i-1][j]$ 或 $dp[i][j-1]$ 转移
   - $dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$

2. **选择当前字符作为某个段的结尾**：
   - 只有当 $A[i-1] = B[j-1]$ 时才有可能
   - 如果 $matched[i][j] \geq K$，说明我们可以选择一个以 $(i,j)$ 结尾的长度至少为 $K$ 的连续段
   - 对于每个可能的段长度 $k$（从 $K$ 到 $matched[i][j]$）：
     - $dp[i][j] = \max(dp[i][j], dp[i-k][j-k] + k)$
   - 这里的关键是：当我们选择一个长度为 $k$ 的段时，这个段占据了 $A$ 的 $i-k+1$ 到 $i$ 位置，以及 $B$ 的 $j-k+1$ 到 $j$ 位置，所以我们应该从 $dp[i-k][j-k]$ 转移过来，并加上这个段的长度 $k$

### 算法复杂度

- **时间复杂度**：$O(n^3)$，其中 $n$ 是字符串的最大长度（$1000$）。虽然理论上这是三次方复杂度，但由于 $K$ 的限制（$1 \leq K \leq 100$），内层循环的实际长度通常不会太大，在实践中可以通过测试。
- **空间复杂度**：$O(n^2)$，需要存储两个 $n \times n$ 的二维数组。

### 算法正确性证明

1. **完备性**：我们的动态规划考虑了所有可能的情况：不选择当前字符，或者选择当前字符作为某个长度 $\geq K$ 的连续段的结尾。
2. **最优子结构**：如果 $dp[i][j]$ 是最优解，那么它要么不包含当前位置的字符，要么包含在一个以当前位置结尾的长度 $\geq K$ 的连续段中。这两种情况都被我们的状态转移覆盖了。
3. **无后效性**：$dp[i][j]$ 的值只依赖于 $i$ 和 $j$ 更小的状态，符合动态规划的要求。

## 代码实现


```cpp
// DNA Subsequences

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1010;

int dp[MAXN][MAXN], matched[MAXN][MAXN];

int main() {
	cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
	int K;
	string A, B;
	while (cin >> K && K) {
		int answer = 0;
		cin >> A >> B;
		int n = A.length(), m = B.length();
		for (int i = 1; i <= n; ++i) {
			for (int j = 1; j <= m; ++j) {
				dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
				if (A[i - 1] == B[j - 1]) matched[i][j] = matched[i - 1][j - 1] + 1;
				else matched[i][j] = 0;
				for (int k = K; k <= matched[i][j]; k++)
				    dp[i][j] = max(dp[i][j], dp[i - k][j - k] + k);
			}
		}
		cout << dp[n][m] << '\n';
	}
	return 0;
}
```

## 代码解释

1. **数组定义**：
   - `dp[MAXN][MAXN]`：存储动态规划状态
   - `matched[MAXN][MAXN]`：存储以当前位置结尾的最长公共子串长度

2. **主循环**：
   - 读取每个测试用例，直到遇到 $K = 0$
   - 对于每个测试用例，初始化动态规划数组（$\texttt{C++}$ 全局变量自动初始化为 $0$）

3. **动态规划过程**：
   - 外层循环遍历字符串 $A$ 的所有位置
   - 内层循环遍历字符串 $B$ 的所有位置
   - 首先考虑不选择当前字符的情况
   - 然后计算 `matched[i][j]`
   - 如果 `matched[i][j] >= K`，尝试所有可能的段长度

4. **输出结果**：
   - 最终答案存储在 `dp[n][m]` 中

## 总结

本题是一个带约束的**最长公共子序列**问题。与普通 $\texttt{LCS}$ 相比，增加了一个约束条件：子序列必须由长度至少为 $K$ 的公共连续段组成。

解决这个问题的关键是设计合适的状态表示和状态转移方程。我们使用两个二维数组：
- `dp[i][j]` 表示考虑前 $i$ 个和前 $j$ 个字符时的最优解
- `matched[i][j]` 表示以当前位置结尾的最长公共子串长度

当发现一个长度 $\geq K$ 的公共子串时，我们可以选择它作为一个"段"，并从该段开始之前的位置转移过来。

虽然算法的时间复杂度是 $O(n^3)$，但由于 $K$ 的限制和字符串长度最大为 $1000$，在实际测试中可以通过。这个问题的难点在于理解"由连续段组成"的概念，并设计出正确的状态转移方程。
