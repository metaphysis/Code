## 题目翻译

在 $\texttt{Treedom}$ 国家中，城镇通过双向道路连接成一棵树。这意味着任意两个不同的城镇 $u$ 和 $v$ 之间恰好存在一条简单路径（不重复经过同一条道路）可以互相到达。

国王是一位体育爱好者，他打算举办一场铁人三项赛。比赛路线将是两个城镇之间唯一的简单路径。比赛期间，属于比赛路线的道路禁止民用车辆通行，这会对经济造成损害。每条道路都有一个预估的损害值 $D$ 和长度 $L$ 。国王不希望比赛造成过多损害，因此比赛路线的总损害值不能超过给定的上限 $m$ 。但为了让比赛尽可能刺激，在满足损害值约束的前提下，比赛路线的总长度应最大化。

你需要编写程序，计算在总损害值不超过 $m$ 的条件下，比赛路线的最大总长度。

### 输入格式

第一行包含一个整数 $T$ （ $1 \leq T \leq 10$ ），表示测试用例的数量。每个测试用例的第一行包含两个整数 $n$ 和 $m$ （ $1 \leq n \leq 30000$ , $1 \leq m \leq 10^8$ ），分别表示城镇数量和最大允许的损害值。接下来 $n-1$ 行，每行包含四个整数 $a$ , $b$ , $D$ , $L$ ，表示城镇 $a$ 和 $b$ 之间有一条道路，其损害值为 $D$ ，长度为 $L$ （ $1 \leq D, L \leq 1000$ ）。保证输入构成一棵树，且至少存在一条可行的比赛路线。

### 输出格式

对于每个测试用例，输出格式为： `Case i: ans` ，其中 $i$ 从 $1$ 开始编号， $ans$ 是最大长度。

### 样例输入

```
2
4 2
1 2 1 1
1 3 1 2
1 4 2 3
4 3
1 2 1 1
1 3 1 2
1 4 2 3
```

### 样例输出

```
Case 1: 3
Case 2: 5
```

## 题目分析

本题要求在一棵带双权值（损害值 $D$ 和长度 $L$ ）的树中，找到一条简单路径，使得路径上所有边的损害值之和不超过 $m$ ，并且长度之和最大。

### 数据范围分析

- 城镇数量 $n \leq 30000$ 
- 损害值上限 $m \leq 10^8$ 
- 每条边的 $D, L \leq 1000$ 

如果直接枚举所有点对，复杂度为 $O(n^2)$ ，在 $n=30000$ 时显然会超时（约 $9 \times 10^8$ 次操作）。因此需要设计更高效的算法，目标复杂度应在 $O(n \log n)$ 或 $O(n \log^2 n)$ 级别。

### 关键观察

1. 路径是树上的简单路径。
2. 路径可以由其两个端点唯一确定。
3. 我们需要在约束条件（总损害值 $\leq m$ ）下最大化总长度。

### 解题思路

**核心思想：点分治（重心分解）**

点分治是一种处理树上路径问题的经典方法。基本步骤为：

1. 选择当前子树的重心作为根节点。
2. 处理所有经过该重心的路径。
3. 递归处理重心的各个子树。

对于本题，在每一步分治过程中，我们需要处理所有经过当前重心 $u$ 的路径。一条经过 $u$ 的路径可以看作由两条从 $u$ 出发的路径拼接而成（其中一条可能为空，即路径只包含 $u$ 本身）。

**具体步骤：**

1. **选择重心** ：通过两次 $\texttt{DFS}$ 计算子树大小并找到重心。
2. **收集路径** ：对于重心的每个邻接子树，收集从重心出发到子树内各点的路径信息（累积损害值 $damage$ 和累积长度 $length$）。
3. **合并路径** ：将来自不同子树的路径信息合并，找到满足 $damage_1 + damage_2 \leq m$ 的最大 $length_1 + length_2$ 。
4. **递归处理** ：对重心的每个子树递归执行上述过程。

**合并路径的优化：**

假设我们有两个路径集合 $A$ 和 $B$ ，我们需要找到 $a \in A$ , $b \in B$ ，使得 $a.damage + b.damage \leq m$ 且 $a.length + b.length$ 最大。

我们可以将其中一个集合（例如 $A$ ）按 $damage$ 排序，并计算前缀最大长度。然后遍历另一个集合 $B$ 的每个元素 $b$ ，在 $A$ 中使用双指针或二分查找找到满足 $a.damage \leq m - b.damage$ 的最大长度。这样合并的复杂度为 $O(|A| \log |A| + |B| \log |B|)$ 。

为了避免重复合并来自同一子树的路径，我们采用逐步合并的方式：维护一个已合并的路径集合 $combined$ ，每次将一个新子树的路径集合与 $combined$ 合并，然后将新子树的路径加入 $combined$ 。这样确保我们只合并来自不同子树的路径。

**时间复杂度分析：**

点分治的深度为 $O(\log n)$ ，每层处理的总路径数为 $O(n)$ ，每个路径集合需要排序，因此总复杂度为 $O(n \log^2 n)$ 。对于 $n \leq 30000$ 是可行的。

### 算法细节

- 使用全局变量 $bestLength$ 记录当前找到的最优长度。
- 在合并路径时，单独考虑从重心出发的路径（即长度为 $0$ ，损害值为 $0$ 的路径）。
- 注意去重：只合并来自不同子树的路径。
- 使用 $\texttt{visited}$ 数组标记已处理过的节点，避免重复访问。

```cpp
// Ironman Race in Treeland

#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 30005;
const long long INF = 1e18;

struct Edge {
    int to, damage, length;
    Edge(int t, int d, int l) : to(t), damage(d), length(l) {}
};

vector<Edge> tree[MAX_N];
bool visited[MAX_N];
int subtreeSize[MAX_N];
int maxSubtree[MAX_N];
int center;
long long globalM;
long long bestLength;

void dfsSize(int u, int parent) {
    subtreeSize[u] = 1;
    maxSubtree[u] = 0;
    for (Edge &e : tree[u]) {
        if (e.to == parent || visited[e.to]) continue;
        dfsSize(e.to, u);
        subtreeSize[u] += subtreeSize[e.to];
        maxSubtree[u] = max(maxSubtree[u], subtreeSize[e.to]);
    }
}

void dfsCenter(int u, int parent, int total) {
    maxSubtree[u] = max(maxSubtree[u], total - subtreeSize[u]);
    if (center == -1 || maxSubtree[u] < maxSubtree[center]) center = u;
    for (Edge &e : tree[u]) {
        if (e.to == parent || visited[e.to]) continue;
        dfsCenter(e.to, u, total);
    }
}

void collectPaths(int u, int parent, long long curDamage, long long curLength, vector<pair<long long, long long>> &paths) {
    paths.push_back({curDamage, curLength});
    for (Edge &e : tree[u]) {
        if (e.to == parent || visited[e.to]) continue;
        collectPaths(e.to, u, curDamage + e.damage, curLength + e.length, paths);
    }
}

void processPaths(vector<pair<long long, long long>> &paths, vector<pair<long long, long long>> &sortedWithMax) {
    sort(paths.begin(), paths.end());
    long long maxLen = -INF;
    for (auto &p : paths) {
        maxLen = max(maxLen, p.second);
        sortedWithMax.push_back({p.first, maxLen});
    }
}

void combinePaths(vector<pair<long long, long long>> &pathsA, vector<pair<long long, long long>> &pathsB) {
    vector<pair<long long, long long>> sortedA, sortedB;
    processPaths(pathsA, sortedA);
    processPaths(pathsB, sortedB);
    
    int j = sortedA.size() - 1;
    for (int i = 0; i < sortedB.size(); ++i) {
        long long damageB = sortedB[i].first;
        long long lengthB = sortedB[i].second;
        if (damageB <= globalM) bestLength = max(bestLength, lengthB);
        while (j >= 0 && sortedA[j].first + damageB > globalM) j--;
        if (j >= 0) bestLength = max(bestLength, sortedA[j].second + lengthB);
    }
}

void solve(int u) {
    visited[u] = true;
    vector<vector<pair<long long, long long>>> allPaths;
    
    for (Edge &e : tree[u]) {
        if (visited[e.to]) continue;
        vector<pair<long long, long long>> paths;
        collectPaths(e.to, u, e.damage, e.length, paths);
        allPaths.push_back(paths);
    }
    
    vector<pair<long long, long long>> combined;
    for (auto &paths : allPaths) {
        combinePaths(combined, paths);
        for (auto &p : paths) combined.push_back(p);
    }
    
    bestLength = max(bestLength, 0LL);
    for (auto &p : combined) if (p.first <= globalM) bestLength = max(bestLength, p.second);
    
    for (Edge &e : tree[u]) {
        if (visited[e.to]) continue;
        center = -1;
        dfsSize(e.to, u);
        dfsCenter(e.to, u, subtreeSize[e.to]);
        solve(center);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        int n;
        long long m;
        cin >> n >> m;
        globalM = m;
        
        for (int i = 1; i <= n; ++i) {
            tree[i].clear();
            visited[i] = false;
        }
        
        for (int i = 0; i < n - 1; ++i) {
            int a, b, D, L;
            cin >> a >> b >> D >> L;
            tree[a].emplace_back(b, D, L);
            tree[b].emplace_back(a, D, L);
        }
        
        bestLength = 0;
        center = -1;
        dfsSize(1, -1);
        dfsCenter(1, -1, n);
        solve(center);
        
        cout << "Case " << caseNo << ": " << bestLength << "\n";
    }
    return 0;
}
```

## 总结

本题是一个典型的树上路径最值问题，通过点分治将问题分解为若干子问题，并利用排序和双指针技巧高效合并路径信息。算法的时间复杂度为 $O(n \log^2 n)$ ，能够处理 $n \leq 30000$ 的数据规模。关键点在于正确处理路径合并时的去重，以及高效地找到满足损害值约束的最大长度。
