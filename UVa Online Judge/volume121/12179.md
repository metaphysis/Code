## 题目描述

中世纪晚期，欧洲已经建立了许多大学。新学期开始，很多情侣因为被不同大学录取而分居两座城镇。为了相见，他们与马车夫达成了一项特殊的票价协议：每次乘车费用不是固定价格，而是从 $1$ 到 $R$ 之间**均匀随机**抽取一个整数作为票价。

如果两座城镇之间没有直达的马车线路，他们需要经过多个城镇中转，每次乘车都会独立地重新随机抽取一次票价。因此，一次旅程的总费用等于沿途所有乘车段票价之和，是一个随机变量。

给定城镇数量 $N$（$1 \leq N \leq 100$）、最大单程票价 $R$（$1 \leq R \leq 30$）、城镇间的直达连接矩阵，以及 $C$（$1 \leq C \leq 1000$）对情侣的查询（每对给出起点 $a$、终点 $b$ 和预算 $m$，$1 \leq m \leq 10000$），问对于每对情侣，他们选择**期望总费用最小**的路径时，能够负担得起（总费用 $\leq m$）的概率是多少。

## 题目分析

### 关键点拆解

1. **每次乘车费用**是 $[1, R]$ 上的整数均匀分布，期望值为 $\frac{R+1}{2}$。
2. **多段旅程**：若从 $u$ 到 $v$ 需要经过 $k$ 次乘车（即路径包含 $k$ 条边），则总费用 $S = X_1 + X_2 + \dots + X_k$，其中 $X_i$ 独立同分布，服从 $\texttt{Uniform}\{1, 2, \dots, R\}$。
3. **路径选择规则**：情侣会选择**期望总费用最小**的路径。因为每条边的期望费用 $E[X] = \frac{R+1}{2}$ 是常数，所以期望总费用最小等价于**边数最少**的路径（边权视为 $1$）。
4. **可达性**：题目保证任意两个城镇之间都存在路径（不一定是直达）。
5. **概率计算**：给定最少乘车次数 $k$，需要计算 $P(S \leq m)$，其中 $S$ 是 $k$ 个独立 $\texttt{Uniform}\{1, \dots, R\}$ 随机变量之和。

### 数学建模

设 $f(i, s)$ 表示 $i$ 次乘车总费用**恰好**为 $s$ 的概率。则有：

- 边界：$f(0, 0) = 1$，$f(0, s) = 0$ for $s > 0$。
- 转移方程：  
  $$f(i, s) = \frac{1}{R} \sum_{x=1}^{R} f(i-1, s-x)$$
  解释：第 $i$ 次乘车抽出 $x$ 元的概率为 $1/R$，前面 $i-1$ 次总费用必须为 $s-x$。

那么 $i$ 次乘车总费用 $\leq m$ 的概率为：
$$P(i, m) = \sum_{s=1}^{m} f(i, s)$$

由于 $m \leq 10000$，$i \leq N-1 \leq 99$，$R \leq 30$，完全可以预先计算 $f$ 和累积概率 $P$。

### 算法步骤

1. **建图**：$N$ 个点，若有直达边则距离为 $1$，否则为无穷大。
2. **全源最短路**：使用 $\texttt{Floyd-Warshall}$ 算法计算任意两点间的最少乘车次数 $dist[u][v]$。因为边权均为 $1$，时间复杂度 $O(N^3)$，$N \leq 100$ 完全可行。
3. **概率预处理**：
   - 用动态规划计算 $f(i, s)$，$i$ 从 $0$ 到 $N-1$，$s$ 从 $0$ 到 $10000$。
   - 然后对每个 $i$ 计算前缀和得到 $prob[i][m]$。
4. **回答查询**：对于每对 $(a, b, m)$，取出 $k = dist[a][b]$，输出 $prob[k][m]$。若 $m \geq 10000$ 则概率为 $1$（因为最大可能总费用为 $k \times R \leq 99 \times 30 = 2970 < 10000$，实际上当 $m$ 超过可能的最大总费用时也是 $1$，但为了边界安全统一判断）。

### 复杂度分析

- 最短路：$O(N^3) = 10^6$ 量级，很小。
- DP 预处理：$O(N \cdot M \cdot R) = 100 \times 10000 \times 30 = 3 \times 10^7$，可接受。
- 查询：$O(1)$ 每个，总 $O(C)$。
- 空间：存储 $f$ 和 $prob$ 各约 $100 \times 10001 \times 8$ 字节 $\approx 16\text{MB}$，安全。

### 精度说明

题目允许绝对误差 $\leq 0.001$。使用 $\texttt{double}$ 浮点数计算概率完全满足要求。

## 解题代码

```cpp
// Randomly-Priced Tickets
// UVa ID: 12179
// Verdict: Accepted
// Submission Date: 2026-05-05
// UVa Run Time: 0.410s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;        // 最大城镇数
const int MAXM = 10005;      // 最大预算 + 边界
const int INF = 1e9;         // 无穷大

int main() {
    int T;
    cin >> T;
    for (int caseNum = 1; caseNum <= T; ++caseNum) {
        int N, R;
        cin >> N >> R;
        
        // 读入邻接矩阵
        vector<string> graph(N);
        for (int i = 0; i < N; ++i) cin >> graph[i];
        
        // ---------- Floyd-Warshall 求最少乘车次数 ----------
        vector<vector<int>> dist(N, vector<int>(N, INF));
        for (int i = 0; i < N; ++i) {
            dist[i][i] = 0;
            for (int j = 0; j < N; ++j) {
                if (graph[i][j] == 'Y') dist[i][j] = 1;
            }
        }
        
        for (int k = 0; k < N; ++k)
            for (int i = 0; i < N; ++i)
                for (int j = 0; j < N; ++j)
                    if (dist[i][k] < INF && dist[k][j] < INF)
                        dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
        
        // ---------- 概率预处理 ----------
        int maxK = N - 1;   // 最多需要 maxK 次乘车
        // dp[i][s] = i次乘车总费用恰好为s的概率
        vector<vector<double>> dp(maxK + 1, vector<double>(MAXM, 0.0));
        // prob[i][s] = i次乘车总费用 <= s 的概率
        vector<vector<double>> prob(maxK + 1, vector<double>(MAXM, 0.0));
        
        dp[0][0] = 1.0;
        
        // 动态规划计算恰好概率
        for (int i = 1; i <= maxK; ++i) {
            for (int s = 1; s < MAXM; ++s) {
                double sum = 0.0;
                for (int x = 1; x <= R; ++x) {
                    if (s - x >= 0) sum += dp[i - 1][s - x];
                }
                dp[i][s] = sum / R;
            }
        }
        
        // 累积得到 <= 概率
        for (int i = 1; i <= maxK; ++i) {
            double cum = 0.0;
            for (int s = 1; s < MAXM; ++s) {
                cum += dp[i][s];
                prob[i][s] = cum;
            }
        }
        
        // ---------- 回答查询 ----------
        int C;
        cin >> C;
        cout << "Case " << caseNum << "\n";
        for (int q = 0; q < C; ++q) {
            int a, b, m;
            cin >> a >> b >> m;
            --a; --b;
            int k = dist[a][b];
            double r = (m >= MAXM - 1) ? 1.0 : prob[k][m];
            cout << fixed << setprecision(6) << r << "\n";
        }
        cout << "\n";
    }
    return 0;
}
```

## 总结

本题的核心在于两点：

1. **将期望最小路径转化为最少边数路径** —— 因为每条边的期望票价相同，问题退化为无权最短路。
2. **多个独立均匀随机变量之和的概率计算** —— 使用动态规划按费用累加概率，避免组合数爆炸和整数溢出。

通过 $\texttt{Floyd-Warshall}$ 预处理距离，再对乘车次数进行概率 $\texttt{DP}$，最终每个查询可以在 $O(1)$ 时间内回答，完美满足题目限制。
