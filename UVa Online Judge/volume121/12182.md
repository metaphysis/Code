## 题目描述

国王理查德四世通过战争和联姻获得了一些新领土。为了从这些新领地获利，他计划在某些道路上设置收费站。对于每个新区域，皇家地图提供了简单的地图：城镇和主要道路，其中任意两个城镇之间恰好有一条路径（即道路构成一棵树）。每条道路有一个预期收益 $p$（可能为负数，表示设置收费站的成本高于收入）。

我们需要选择一组道路，使得总收益最大，且选中的道路必须连通（即从任何一条选中道路可以沿选中道路到达任意其他选中道路）。

### 输入格式
- 多组测试数据，每组以一个整数 $n$（$1 \leq n \leq 100000$）开始，表示道路数量。
- 接下来 $n$ 行，每行三个整数 $a, b, p$（$1 \leq a, b \leq 200000$，$-1000 \leq p \leq 1000$），表示连接城镇 $a$ 和 $b$ 的道路及其收益 $p$。
- 输入以一行单独的一个 `0` 结束。

### 输出格式
对于每组测试数据，输出一行，包含能获得的最大总收益。

### 样例输入
```
4
1 2 -7
3 2 10
2 4 2
5 4 -2
3
1 2 -8
2 3 -8
3 4 -1000
5
14 15 0
15 92 10
92 65 -5
65 35 10
35 89 -30
0
```

### 样例输出
```
12
0
15
```

## 问题分析

### 核心观察
1. **图结构**：题目保证任意两个城镇之间有且仅有一条路径，这意味着整个图是一棵树。不过城镇编号不连续，最大编号可达 $200000$，但边数 $n \leq 100000$，所以实际上是一棵有 $n+1$ 个节点的树。

2. **目标**：选择一组边，使边权和最大，且选中的边必须连通。

3. **关键转化**：由于边权可能为负，且要求连通，这类似于在树中找一棵**最大权连通子图**。因为树中连通子图一定是一棵子树（不一定包含根），问题转化为：找一棵子树（连续节点集）使得边权和最大。

### 边权转点权技巧
经典树形动态规划往往处理点权问题。这里可以将每条边的权值转移到其子节点上：任选一个根（如最小节点 $1$），对于每条边 $(u, v, w)$，若 $v$ 是 $u$ 的子节点，则定义 $val[v] = w$。这样，树上任意一个连通子图的边权和等于子图中所有节点的 $val$ 之和（根节点 $val=0$）。

因此，问题变为：给定一棵有根树，每个节点有一个权值（可能为负），选择一棵连通子树（必须包含根？不，可以不包含根），使得节点权值和最大。

### 进一步简化
实际上，由于连通子图可以不包含原始根，我们需要考虑所有节点作为子树的根的情形。但树形 DP 可以一次遍历解决：设 $dp[u]$ 表示以 $u$ 为根的子树中，**选择 $u$ 以及子树中若干节点**所能获得的最大收益（必须包含 $u$，因为连通性要求）。那么：
- 初始化 $dp[u] = 0$（不考虑任何子节点）。
- 对于每个子节点 $v$，如果 $dp[v] + weight(u, v) > 0$，则将其加入，即 $dp[u] += dp[v] + weight(u, v)$。
- 最终答案 $ans = \max\limits_{u} dp[u]$。

### 为什么这样可行？
考虑任意一个最优连通子图 $S$。在树中， $S$ 必然是一棵子树（可能不包含树根）。取 $S$ 中任意一个节点作为根，那么 $S$ 中每个节点 $x$ 的父节点（在 $S$ 的视角）与它的连边必然被选中。上述 DP 过程中，当我们枚举到 $S$ 的“实际根” $r$ 时， $dp[r]$ 恰好等于 $S$ 的总边权和，因为：
- 对 $r$ 的子节点 $v$，如果 $v$ 在 $S$ 中，那么边 $(r, v)$ 的权值会被加入，同时 $v$ 的子节点也会递归加入。
- 若某个子树贡献为负， DP 会通过 `max(0, dp[v]+w)` 将其丢弃，这正是最优策略——不选负收益的子分支。

因此，一次 $\texttt{DFS}$ 即可得到全局最优解。

### 特殊情况
如果所有边权均为负，那么最优策略是**不选任何边**，收益为 $0$。因为题目允许不选任何道路。

## 算法步骤
1. 读入边数 $n$，若 $n=0$ 则结束。
2. 建图：无向边，记录边权。
3. 任选一个根（比如第一个节点）进行树形 $\texttt{DFS}$，但注意树可能不是以 $1$ 为根，且节点编号不连续。为了处理森林情况（虽然题目说是一个连通树），我们遍历所有节点，对每个未访问且有邻边的节点启动 $\texttt{DFS}$。
4. $\texttt{DFS}$ 过程中，对于当前节点 $u$，初始化 $dp[u] = 0$，遍历所有邻接点 $v$，若 $v$ 不是父节点，则递归计算 $dp[v]$，然后如果 $dp[v] + w > 0$，则累加到 $dp[u]$。
5. 更新全局最大值 $ans = \max(ans, dp[u])$。
6. 输出 $\max(0, ans)$。

## 复杂度分析
- 每个节点被访问一次，每条边被处理两次，总复杂度 $O(n)$。
- 空间复杂度 $O(n)$。

## 注意事项
- 节点编号最大 $200000$，但边最多 $100000$，所以节点数最多 $100001$，数组大小要开够。
- 多组测试数据，需要及时清空图和标记数组。
- 答案可能为负数，但可以选择空集，因此最终输出要与 $0$ 取最大值。

## 代码实现

```cpp
// Toll Road
// UVa ID: 12182

// UVa Run Time: 0.210s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;

vector<pair<int, int>> graph[MAXN];
bool visited[MAXN];
long long dp[MAXN];
long long ans;

void dfs(int u, int parent) {
    visited[u] = true;
    dp[u] = 0; // 不包含父边，初始为0
    for (auto &edge : graph[u]) {
        int v = edge.first;
        int w = edge.second;
        if (v == parent) continue;
        dfs(v, u);
        if (dp[v] + w > 0) dp[u] += dp[v] + w;
    }
    ans = max(ans, dp[u]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    while (true) {
        int n;
        cin >> n;
        if (n == 0) break;

        for (int i = 0; i < MAXN; ++i) graph[i].clear();
        memset(visited, false, sizeof(visited));
        ans = -1e18;

        int maxNode = 0;
        vector<tuple<int, int, int>> edges;
        for (int i = 0; i < n; ++i) {
            int a, b, p;
            cin >> a >> b >> p;
            edges.emplace_back(a, b, p);
            maxNode = max(maxNode, max(a, b));
        }

        for (auto &e : edges) {
            int a = get<0>(e), b = get<1>(e), p = get<2>(e);
            graph[a].emplace_back(b, p);
            graph[b].emplace_back(a, p);
        }

        for (int i = 1; i <= maxNode; ++i) {
            if (!graph[i].empty() && !visited[i]) {
                dfs(i, -1);
            }
        }

        cout << max(0LL, ans) << '\n';
    }

    return 0;
}
```

## 总结
本题是经典的树形动态规划求最大权连通子图问题。关键在于：
- 识别出输入图是树结构。
- 将边权转化为子节点的点权。
- 设计状态 $dp[u]$ 表示必须包含 $u$ 的最大连通子图权值。
- 通过贪心取舍子分支（取正舍负）得到最优解。
- 注意空集（收益 $0$）的边界处理。

该算法时间复杂度 $O(n)$，空间复杂度 $O(n)$，可轻松通过 $n \leq 10^5$ 的数据范围。
