## 题目描述

在古腾堡发明活字印刷术之前，书籍都是由僧侣手工抄写的。各个修道院希望能够确认一本书是由他们（而不是其他修道院）抄写的。虽然水印纸是一种选择，但修道院更倾向于使用一种难以伪造的序列号系统来识别他们的抄本。

每个序列号由 $10$ 个数字 $a_1, a_2, \ldots, a_{10}$ 组成。有效的序列号满足：
$$a_1 + a_2 + \ldots + a_9 \equiv a_{10} \ (\text{mod} \ N)$$
其中 $0 \leq a_{10} < N$。这个 $N$ 是特定于并仅由抄写这本书的修道院所知的，因此他们能够检查其来源。

现在你面对一堆书，这些书大概是由同一个修道院抄写的。你需要编写一个程序来确定那个修道院，即计算使得这些书的序列号都有效的最大可能的 $N$。显然，没有修道院会选择 $N = 1$。所以如果你的计算结果是 $N = 1$，那一定是出了什么问题。

### 输入格式
- 第一行：整数 $t$，表示测试用例的数量（$1 \leq t \leq 100$）
- 每个测试用例：
  - 第一行：整数 $c$，表示序列号数量（$2 \leq c \leq 1000$）
  - 接下来 $c$ 行：每行包含 $10$ 个整数 $a_1, a_2, \ldots, a_{10}$（$0 \leq a_i < 2^{28}$）

### 输出格式
对于每个测试用例，输出最大的可能 $N$，使得所有序列号都有效。如果找不到 $N > 1$ 或者序列号对任意 $N$ 都有效，输出 `impossible`。

## 题目分析

### 数学建模
对于每个序列号，定义：
- 前 $9$ 位数字之和：$S = a_1 + a_2 + \dots + a_9$
- 第 $10$ 位数字：$a_{10}$

验证条件为：
$$S \equiv a_{10} \ (\text{mod} \ N)$$

这等价于：
$$S - a_{10} \equiv 0 \ (\text{mod} \ N)$$
即：
$$N \mid (S - a_{10})$$

### 关键约束条件
题目中有一个重要约束：$0 \leq a_{10} < N$

这意味着：
1. $a_{10}$ 必须小于 $N$
2. $a_{10}$ 是非负整数

### 多序列号情况
对于 $c$ 个序列号，我们需要找到最大的 $N > 1$，使得：
$$N \mid (S_i - a_{10}^{(i)}) \quad \text{对所有 } i = 1, 2, \ldots, c$$

换句话说，$N$ 必须是所有差值 $d_i = S_i - a_{10}^{(i)}$ 的公约数。

### 解题思路
1. **计算差值**：对于每个序列号，计算 $d_i = (a_1 + \dots + a_9) - a_{10}$
2. **求最大公约数**：计算所有 $d_i$ 的绝对值的最大公约数 $\gcd(|d_1|, |d_2|, \ldots, |d_c|)$
3. **特殊情况处理**：
   - 如果 $\gcd = 0$：所有差值都为 $0$，序列号对任意 $N$ 都有效，输出 `impossible`
   - 如果 $\gcd = 1$：没有 $N > 1$ 满足条件，输出 `impossible`
4. **验证约束**：检查是否满足 $a_{10}^{(i)} < \gcd$ 对所有 $i$，如果不满足则输出 `impossible`

## 算法实现细节

### 时间复杂度
- 每个测试用例需要 $O(c)$ 时间计算差值和求 $\gcd$
- 总体复杂度为 $O(t \cdot c)$，在题目约束下完全可行

### 注意事项
1. 使用 `long long` 类型防止整数溢出（$a_i < 2^{28}$，$9$ 个数的和可能很大）
2. 使用绝对值计算 $\gcd$，避免负数影响
3. 必须检查 $a_{10} < N$ 的约束条件

## 代码实现

```cpp
// Transcribed Books
// UVa ID: 12184
// Verdict: Accepted
// Submission Date: 2025-11-16
// UVa Run Time: 0.180s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int c;
        cin >> c;
        vector<long long> diffs;
        vector<long long> a10s;
        
        for (int i = 0; i < c; i++) {
            long long sum = 0;
            for (int j = 0; j < 9; j++) {
                long long x;
                cin >> x;
                sum += x;
            }
            long long a10;
            cin >> a10;
            diffs.push_back(sum - a10);
            a10s.push_back(a10);
        }
        
        long long g = 0;
        for (long long d : diffs) {
            g = __gcd(g, abs(d));
        }
        
        if (g == 0 || g == 1) {
            cout << "impossible\n";
            continue;
        }
        
        // 检查 g 是否大于所有的 a10
        bool valid = true;
        for (long long a10 : a10s) {
            if (a10 >= g) {
                valid = false;
                break;
            }
        }
        
        if (valid) {
            cout << g << "\n";
        } else {
            cout << "impossible\n";
        }
    }
    return 0;
}
```

## 总结

本题的关键在于将模运算条件转化为整除关系，然后利用最大公约数的性质找到满足所有序列号的最大 $N$。特别需要注意 $a_{10} < N$ 的约束条件，这是容易被忽略但至关重要的细节。
