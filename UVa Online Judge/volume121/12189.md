## 题目描述

大学计划新建一个餐厅大厅，需要估算所需座位数。为了测量现有餐厅大厅在任意时刻的最大客户数，他们进行了一次实验：在现有餐厅的每个入口和出口安排一名调查员，记录每位客户进入（`E`）或离开（`X`）大厅的时间，格式为 `HH:MM:SS`。实验开始前和结束后大厅均为空。

收集到的卡片存在两个问题：
1. 卡片顺序混乱（需要排序）；
2. 部分卡片的事件标记缺失（记为 `?`）。

已知所有时间都是有效的，且同一测试用例中没有两个时间相同。给定一组卡片（每张包含时间和可能缺失的事件标记），要求确定在**合理分配**未知事件（`?` 分配为 `E` 或 `X`）的情况下，大厅内在某个时刻可能达到的**最大客户数**。

## 输入格式

多个测试用例，每个测试用例格式如下：
- 第一行：整数 $N$（$2 \le N \le 64800$），表示卡片数量。
- 接下来 $N$ 行：每行格式为 `HH:MM:SS c`，其中 `c` 为 `E`、`X` 或 `?`。
- 输入以 $N = 0$ 结束。

## 输出格式

对每个测试用例，输出一个整数，表示可能的最大同时在场客户数。

## 样例输入

## 题目分析

### 核心约束条件
1. 每个客户恰好对应一次进入和一次离开。
2. 实验开始前和结束后大厅人数为 $0$。
3. 任何时刻大厅人数不能为负。
4. 已知事件（`E`/`X`）不可更改，未知事件（`?`）可自由分配为 `E` 或 `X`。
5. 目标是**最大化**某个时刻的人数。

### 关键难点
- 如何合理分配 `?` 以最大化峰值人数，同时满足上述约束。
- 因为时间点是离散且唯一的，我们需要按时间顺序处理事件。

---

## 解题思路

### 第一步：问题转化
将时间转换为秒数以便排序和比较。设：
- $knownE$ = 已知进入事件数
- $knownX$ = 已知离开事件数
- $unknown$ = 未知事件数

因为每个客户一进一出，所以总进入数 = 总离开数：
$$
knownE + e = knownX + (unknown - e)
$$
其中 $e$ 是未知事件中分配为进入的数量。解得：
$$
e = \frac{knownX - knownE + unknown}{2}
$$
**注意**： $e$ 必须是非负整数，且 $0 \le e \le unknown$。题目保证输入合法，因此该式必然成立。

### 第二步：贪心分配策略
为了最大化峰值人数，我们希望让进入事件尽可能早发生（以增加人数），离开事件尽可能晚发生（以延迟减少人数）。因此：
1. 将最早的 $e$ 个 `?` 分配为 `E`。
2. 将剩余的 $unknown - e$ 个 `?` 分配为 `X`。

这种分配方式在题目给定的合法输入下，能够保证模拟过程中人数不会为负（因为已知事件本身是自洽的，且我们按最早进入、最晚离开分配，不会违反约束）。

### 第三步：模拟计算最大值
按时间顺序处理所有事件：
- 遇到 `E` 或分配为 `E` 的 `?`：当前人数 $+1$。
- 遇到 `X` 或分配为 `X` 的 `?`：当前人数 $-1$。

记录过程中人数的最大值，即为所求答案。

---

## 算法步骤
1. 读入 $N$，若为 $0$ 则结束。
2. 将每张卡片的时间转换为秒，存储时间和事件标记。
3. 按时间排序所有卡片。
4. 统计 $knownE$、$knownX$、$unknown$。
5. 计算 $e = (knownX - knownE + unknown) / 2$。
6. 遍历排序后的卡片，将前 $e$ 个 `?` 标记为 `E`，其余 `?` 标记为 `X`。
7. 模拟过程，维护当前人数和最大人数。
8. 输出最大人数。

---

## 时间复杂度
- 排序：$O(N \log N)$
- 统计和模拟：$O(N)$
- 总复杂度：$O(N \log N)$，对于 $N \le 64800$ 可接受。

## 代码实现

```cpp
// Dinner Hall
// UVa ID: 12189
// Verdict: Accepted
// Submission Date: 2026-01-19
// UVa Run Time: 0.080s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Card {
    int time; // 转换为秒，方便比较
    char event;
};

bool compareCard(const Card& a, const Card& b) { return a.time < b.time; }

int main() {
    int n;
    while (cin >> n && n != 0) {
        vector<Card> cards(n);
        for (int i = 0; i < n; ++i) {
            int h, m, s;
            char colon;
            cin >> h >> colon >> m >> colon >> s;
            cards[i].time = h * 3600 + m * 60 + s;
            cin >> cards[i].event;
        }
        // 按时间排序
        sort(cards.begin(), cards.end(), compareCard);
        // 统计已知事件
        int knownE = 0, knownX = 0, unknown = 0;
        for (const auto& card : cards) {
            if (card.event == 'E') knownE++;
            else if (card.event == 'X') knownX++;
            else unknown++;
        }
        // 计算未知事件中应分配为 'E' 的数量
        int eCount = (knownX - knownE + unknown) / 2;
        // 最早的一些 '?' 分配为 'E'，其余为 'X'
        int eUsed = 0;
        vector<char> assigned(n);
        for (int i = 0; i < n; ++i) {
            if (cards[i].event == '?') {
                if (eUsed < eCount) {
                    assigned[i] = 'E';
                    eUsed++;
                } else assigned[i] = 'X';
            } else assigned[i] = cards[i].event;
        }
        // 模拟过程，计算最大人数
        int current = 0, maxPeople = 0;
        for (int i = 0; i < n; ++i) {
            if (assigned[i] == 'E') current++;
            else current--;
            maxPeople = max(maxPeople, current);
        }
        cout << maxPeople << endl;
    }
    return 0;
}
```

## 总结
本题的关键在于**通过数量关系确定未知事件的分配数量**，并采用**贪心策略**（早进入、晚离开）来最大化峰值人数。题目保证输入合法，因此贪心分配不会导致人数为负或结束时不归零。排序后模拟即可得到答案。
