## 题目描述

学校的一台 $\texttt{Web}$ 服务器硬盘分区表损坏，所有文件的组织信息丢失。硬盘数据是一个字节序列，每个字节可以存储 $64$ 种字符之一（大小写字母、数字、点、逗号）。文件系统将每个文件保存在连续区域，并且每个文件有多个副本。现在需要找出所有**出现至少两次**的**不同**连续字节子序列（子串），并统计其数量。

**输入**：多个测试用例，每个用例一行字符串（长度 $\leq 10^5$），最后一行为 `*`。

**输出**：每个用例输出一个整数，表示出现至少两次的不同子串数量。

## 样例分析

```
输入：
ababcabb
输出：
3
解释：重复子串为 "a", "b", "ab"
```

## 问题抽象

给定一个字符串 $S$，求所有出现次数 $\geq 2$ 的不同子串的数量。

**关键限制**：
- 字符串长度 $n \leq 10^5$
- 字符集大小 $|\Sigma| = 64$
- 需要 $O(n)$ 或 $O(n \log n)$ 算法，不能 $O(n^2)$ 枚举子串。

## 解题思路

### 1. 暴力枚举不可行

枚举所有子串需要 $O(n^2)$，对于 $n=10^5$ 不可接受。

### 2. 后缀自动机（$\texttt{Suffix Automaton}$）介绍

后缀自动机（$\texttt{SAM}$）是一个能接受字符串所有后缀的有限状态自动机。它可以在 $O(n)$ 时间内构建，并高效处理子串相关问题。

**$\texttt{SAM}$ 的关键性质**：
- 从起始状态出发的每条路径对应一个子串。
- 每个状态代表一组**结束位置集合相同**的子串（这些子串的出现位置完全相同）。
- 状态 $st$ 包含的子串长度范围是 $[\texttt{len}(\texttt{link}[st]) + 1, \texttt{len}(st)]$。
- 每个状态 $st$ 代表的**不同子串数量**为 $\texttt{len}(st) - \texttt{len}(\texttt{link}[st])$。
- 状态 $st$ 的**出现次数** $\texttt{occ}[st]$ 可以通过拓扑排序计算。

### 3. 算法设计

1. **构建 $\texttt{SAM}$** ：逐个字符插入，维护自动机结构。
2. **计算出现次数**：
   - 每个终止状态（对应原串的一个后缀）初始 $\texttt{occ}=1$。
   - 按 $\texttt{len}$ 从大到小拓扑排序，将 $\texttt{occ}[st]$ 累加到 $\texttt{occ}[\texttt{link}[st]]$。
   - 这样每个状态的出现次数就是它代表的子串在字符串中的出现次数。
3. **统计答案**：
   - 遍历所有状态（除初始状态）。
   - 如果 $\texttt{occ}[st] \geq 2$，则该状态对应的所有子串都至少出现两次。
   - 该状态贡献的子串数量为 $\texttt{len}(st) - \texttt{len}(\texttt{link}[st])$。
   - 累加所有满足条件的状态的贡献。

### 4. 时间复杂度

- 构建 $\texttt{SAM}$：$O(n)$
- 拓扑排序与统计：$O(n)$
- 总复杂度：$O(n)$，满足题目要求。

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

// 后缀自动机节点
struct State {
    int len;          // 该状态能接受的最长子串长度
    int link;         // 后缀链接
    int occ;          // 出现次数
    map<char, int> next; // 转移边
    State() : len(0), link(-1), occ(0) {}
};

// 后缀自动机类
class SuffixAutomaton {
private:
    vector<State> st;  // 状态数组
    int last;          // 最后一个状态
    long long answer;  // 答案

public:
    SuffixAutomaton() {
        st.push_back(State()); // 初始状态
        st[0].len = 0;
        st[0].link = -1;
        last = 0;
        answer = 0;
    }

    // 扩展字符
    void extend(char c) {
        int cur = st.size();
        st.push_back(State());
        st[cur].len = st[last].len + 1;
        st[cur].occ = 1;
        int p = last;
        // 为路径上的状态添加转移，同时寻找第一个有c转移的状态
        while (p != -1 && !st[p].next.count(c)) {
            st[p].next[c] = cur;
            p = st[p].link;
        }
        if (p == -1) {
            st[cur].link = 0;
        } else {
            int q = st[p].next[c];
            if (st[p].len + 1 == st[q].len) {
                st[cur].link = q;
            } else {
                int clone = st.size();
                st.push_back(st[q]); // 复制状态
                st[clone].len = st[p].len + 1;
                st[clone].occ = 0;   // 新状态的出现次数初始为0
                // 重定向p到q的路径到clone
                while (p != -1 && st[p].next[c] == q) {
                    st[p].next[c] = clone;
                    p = st[p].link;
                }
                st[q].link = st[cur].link = clone;
            }
        }
        last = cur;
    }

    // 计算答案
    long long computeAnswer() {
        int n = st.size();
        // 按len排序，用于拓扑统计出现次数
        vector<int> cnt(n + 1, 0), order(n, 0);
        for (int i = 0; i < n; i++) cnt[st[i].len]++;
        for (int i = 1; i <= n; i++) cnt[i] += cnt[i - 1];
        for (int i = 0; i < n; i++) order[--cnt[st[i].len]] = i;
        // 按len从大到小累加出现次数
        for (int i = n - 1; i > 0; i--) {
            int v = order[i];
            st[st[v].link].occ += st[v].occ;
        }
        // 统计出现次数>=2的状态贡献的子串数
        for (int i = 1; i < n; i++) {
            if (st[i].occ >= 2) answer += st[i].len - st[st[i].link].len;
        }
        return answer;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    while (cin >> s, s != "*") {
        SuffixAutomaton sam;
        for (char c : s) sam.extend(c);
        cout << sam.computeAnswer() << "\n";
    }
    return 0;
}
```

## 代码说明

- **状态结构**：`State` 存储自动机状态信息，使用 `map` 存储转移边以支持 $64$ 字符集。
- **构建过程**：`extend` 函数实现 $\texttt{SAM}$ 的标准构建算法，处理状态分裂。
- **统计答案**：先计数排序得到拓扑序，再反向传递出现次数，最后累加符合条件的子串数。
- **主程序**：循环读入测试用例，构建 $\texttt{SAM}$ 并输出答案。

## 复杂度分析

- 时间：$O(n \log |\Sigma|)$，由于使用 `map` 存储转移边，每次转移查找 $O(\log 64) \approx O(1)$，整体接近线性。
- 空间：$O(n)$。

## 总结

本题是一个典型的子串统计问题，后缀自动机提供了最优的线性解法。关键在于理解 $\texttt{SAM}$ 的状态与子串的对应关系，以及如何通过拓扑排序计算每个子串的出现次数。掌握 $\texttt{SAM}$ 不仅能解决此题，还能处理大量字符串匹配、统计、最值等问题。
