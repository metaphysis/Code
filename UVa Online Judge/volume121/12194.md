## 题目描述

给定一个在 $XY$ 平面上的点集，所有点都具有不同的整数坐标，且任意三点不共线。你需要计算有多少个三点子集能够构成等腰三角形的顶点。

等腰三角形的定义是：至少有两条边长度相等。需要注意的是，所有顶点都是整数坐标的点不能构成等边三角形，因此我们不需要担心等边三角形的特殊情况。

### 输入格式

- 多个测试用例
- 每个测试用例第一行是整数 $N$ ($3 \leq N \leq 1000$)，表示点数
- 接下来 $N$ 行，每行两个整数 $X$ 和 $Y$ ($1 \leq X, Y \leq 10^6$)，表示点的坐标
- 输入以一行单独的 $0$ 结束

### 输出格式

对于每个测试用例，输出一个整数，表示能构成等腰三角形的三点子集数量。

## 题目分析

### 问题本质

我们需要从 $N$ 个点中找出所有能构成等腰三角形的三元组。等腰三角形的关键特征是至少有两条边长度相等。

### 暴力法的局限性

最直接的想法是枚举所有三元组，检查是否能构成等腰三角形。这种方法的时间复杂度是 $O(N^3)$，对于 $N = 1000$ 的情况，计算量约为 $10^9$ 级别，显然会超时。

### 优化思路

我们可以换个角度思考：对于每个可能的等腰三角形，总有一个顶点是两条相等边的公共端点。基于这个观察，我们可以设计更高效的算法：

1. **以每个点作为顶点**：遍历每个点，将其作为等腰三角形的顶点（即两条相等边的交点）

2. **距离统计**：对于当前顶点，计算它到其他所有点的距离

3. **组合计数**：对于每个距离值，如果有 $k$ 个点与该顶点的距离相同，那么这些点可以组成 $\binom{k}{2} = \frac{k(k-1)}{2}$ 个等腰三角形

### 算法细节

#### 距离计算

为了避免浮点数精度问题，我们使用距离的平方而不是实际距离。两点 $(x_1, y_1)$ 和 $(x_2, y_2)$ 之间的距离平方为：
$$d^2 = (x_1 - x_2)^2 + (y_1 - y_2)^2$$

#### 重复计数问题

我们的方法会正确统计所有等腰三角形：
- 对于普通的等腰三角形（只有两条边相等），它只会被顶点（两条相等边的交点）统计一次
- 对于等边三角形，题目已经说明整数坐标点无法构成等边三角形，所以不需要特殊处理

#### 时间复杂度

- 外层循环：$O(N)$
- 内层距离计算和排序：$O(N \log N)$
- 总复杂度：$O(N^2 \log N)$

对于 $N \leq 1000$，这个复杂度是可以接受的。

## 解题思路总结

1. **输入处理**：读取多个测试用例，直到遇到 $0$

2. **对于每个测试用例**：
   - 读取所有点的坐标
   - 初始化结果计数器

3. **核心算法**：
   - 对于每个点 $i$，作为等腰三角形的顶点
   - 计算点 $i$ 到其他所有点的距离平方
   - 对距离数组排序
   - 统计相同距离的数量，计算组合数并累加到结果中

4. **输出结果**：处理完所有点后输出计数结果

## 代码实现

```cpp
// Isosceles Triangles
// UVa ID: 12194
// Verdict: Accepted
// Submission Date: 2025-11-29
// UVa Run Time: 0.630s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
    Point(int x = 0, int y = 0) : x(x), y(y) {}
};

// 计算两点间距离的平方（避免浮点数）
long long distSquared(const Point& a, const Point& b) {
    long long dx = a.x - b.x;
    long long dy = a.y - b.y;
    return dx * dx + dy * dy;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    while (cin >> n && n != 0) {
        vector<Point> points(n);
        for (int i = 0; i < n; i++) 
            cin >> points[i].x >> points[i].y;
        
        long long result = 0;
        
        // 对于每个点作为等腰三角形的顶点
        for (int i = 0; i < n; i++) {
            vector<long long> distances;
            
            // 计算该点到所有其他点的距离平方
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                distances.push_back(distSquared(points[i], points[j]));
            }
            
            // 排序距离以便统计
            sort(distances.begin(), distances.end());
            
            // 统计相同距离的数量
            int count = 1;
            for (int j = 1; j < distances.size(); j++) {
                if (distances[j] == distances[j - 1]) {
                    count++;
                } else {
                    // 对于有count个相同距离的情况，可以形成C(count,2)个等腰三角形
                    result += (long long)count * (count - 1) / 2;
                    count = 1;
                }
            }
            // 处理最后一组
            result += (long long)count * (count - 1) / 2;
        }
        
        cout << result << "\n";
    }
    
    return 0;
}
```

## 算法亮点

1. **避免浮点数**：使用距离平方代替实际距离，避免了精度问题
2. **高效统计**：通过排序和线性扫描来统计相同距离的数量
3. **组合数学**：利用组合公式直接计算可能的三角形数量
4. **正确性保证**：算法自然地处理了所有等腰三角形情况，无需特殊处理等边三角形

这个解决方案充分利用了等腰三角形的几何特性，通过巧妙的距离统计方法，将时间复杂度从 $O(N^3)$ 优化到 $O(N^2 \log N)$，是典型的通过数学洞察优化算法复杂度的例子。
