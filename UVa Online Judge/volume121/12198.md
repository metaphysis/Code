## 题目描述

$\texttt{Tom}$ 在餐厅工作，负责在服务员和洗碗工之间传递盘子。盘子必须按照从餐桌送来的顺序进行清洗（即先进先出）。$\texttt{Tom}$ 只有一张桌子，桌子上只能放两摞盘子（分别称为堆 $1$ 和堆 $2$）。给定一系列 `DROP m`（服务员送来 $m$ 个盘子）和 `TAKE m`（洗碗工需要 $m$ 个盘子）指令，你需要输出 $\texttt{Tom}$ 的操作序列，使得：

1. 盘子按正确顺序传递；
2. 输出行数不超过 $6N$（$N$ 为指令数）；
3. 总操作次数（输出中所有 $m$ 之和）不超过 $6M$（$M$ 为所有 `DROP` 指令的 $m$ 之和）。

允许的操作有三种：

* `DROP 1 m` / `DROP 2 m`：将 $m$ 个盘子放到堆 $1$ / 堆 $2$ 顶部。
* `TAKE 1 m` / `TAKE 2 m`：从堆 $1$ / 堆 $2$ 顶部取 $m$ 个盘子传递给洗碗工。
* `MOVE 1->2 m` / `MOVE 2->1 m`：将 $m$ 个盘子从堆 $1$ 顶部移到堆 $2$ 顶部（或反向）。

## 题目分析与解题思路

这是一个**模拟题**，核心问题是如何用两个栈（后进先出）来模拟一个队列（先进先出）。因为盘子必须按接收顺序清洗，而 $\texttt{Tom}$ 只有两个栈结构可用。

### 关键点分析

1. **两个栈模拟队列**：这是经典的数据结构问题。我们可以将堆 $1$ 作为“输入栈”，所有新盘子都放到堆 $1$；将堆 $2$ 作为“输出栈”，当需要取盘子时从堆 $2$ 顶部取。
2. **顺序保证**：当堆 $2$ 为空时，需要将堆 $1$ 中的所有盘子移到堆 $2$。这样，堆 $1$ 底部的盘子（最早来的）就会成为堆 $2$ 顶部的盘子，从而保证先进先出的顺序。
3. **操作合并**：题目允许一次操作处理多个盘子（如 `DROP 1 100` 表示连续放 $100$ 个盘子到堆 $1$）。这可以帮助我们减少输出行数，满足 $6N$ 的限制。
4. **边界条件**：题目保证 `TAKE m` 时桌上至少有 $m$ 个盘子，因此无需检查不足的情况。

### 具体策略

1. 初始化：堆 $1$ 和堆 $2$ 的盘子数均为 $0$。
2. 对于每条指令：
   * 如果是 `DROP m`：
     * 输出 `DROP 1 m`（所有新盘子都放到堆 $1$）。
     * 堆 $1$ 增加 $m$。
   * 如果是 `TAKE m`：
     * 如果堆 $2$ 有盘子，先从堆 $2$ 取（输出 `TAKE 2 k`，$k$ 为可取的数量）。
     * 如果还需要更多盘子（此时堆 $2$ 为空），则将堆 $1$ 的所有盘子移到堆 $2$（输出 `MOVE 1->2 stack1`），然后从堆 $2$ 取剩余所需盘子（输出 `TAKE 2 remaining`）。

### 正确性证明

* **$\texttt{FIFO}$ 顺序**：盘子到达顺序是：先到堆 $1$ 底部，后到堆 $1$ 顶部。当需要取盘子时，将堆 $1$ 全部移到堆 $2$，这样堆 $1$ 底部（最早）的盘子就到了堆 $2$ 顶部，最先被取走。后续到达的盘子在堆 $1$ 中，只有当堆 $2$ 为空时才会被移到堆 $2$，从而保证了全局先进先出。
* **操作次数界限**：每个盘子最多被操作三次（`DROP`、`MOVE`、`TAKE`），总操作数不超过 $3M$，满足 $≤6M$ 的要求。
* **输出行数**：每个 `DROP` 指令输出一行，每个 `TAKE` 指令最多输出两行（先取堆 $2$，再移动并取堆 $2$），总行数不超过 $3N$，满足 $≤6N$ 的要求。

### 复杂度分析

* 时间复杂度：$O(N)$，每个指令处理时间是常数。
* 空间复杂度：$O(1)$，只需要记录两个堆的盘子数量。

```cpp
// Working at the Restaurant

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, cases = 0;
    while (cin >> n, n) { // 读取 N，为 0 则结束
        if (cases++) cout << '\n';
        int stack1 = 0, stack2 = 0; // 两个堆的盘子数量
        for (int i = 0; i < n; ++i) {
            string cmd;
            int m;
            cin >> cmd >> m;
            if (cmd == "DROP") {
                // 总是将新盘子放到堆1
                cout << "DROP 1 " << m << '\n';
                stack1 += m;
            } else { // cmd == "TAKE"
                // 先从堆2取（如果堆2有盘子）
                if (stack2 > 0) {
                    int takeFromStack2 = min(m, stack2);
                    if (takeFromStack2 > 0) {
                        cout << "TAKE 2 " << takeFromStack2 << '\n';
                        stack2 -= takeFromStack2;
                        m -= takeFromStack2;
                    }
                }
                // 如果还需要更多盘子（此时堆2一定为空）
                if (m > 0) {
                    // 将堆1所有盘子移动到堆2
                    if (stack1 > 0) {
                        cout << "MOVE 1->2 " << stack1 << '\n';
                        stack2 = stack1; // 移动后堆2的数量变为原来的堆1数量
                        stack1 = 0;
                    }
                    // 从堆2取需要的数量
                    cout << "TAKE 2 " << m << '\n';
                    stack2 -= m;
                }
            }
        }
    }
    return 0;
}
```

### 代码说明

1. **变量命名**：使用 `stack1` 和 `stack2` 表示两个堆的盘子数。
2. **输出格式**：
   * 每个测试用例之间输出空行（通过 `cases` 变量控制，第一个用例前不输出空行）。
   * 使用 `'\n'` 而不是 `endl` 以提高效率。
3. **操作合并**：
   * `DROP` 指令直接输出一行，合并了所有 $m$ 个盘子。
   * `TAKE` 指令可能分为两步：先取堆 $2$ 的存量，再移动并取剩余所需。
4. **边界处理**：
   * 当堆 $2$ 有盘子时，先取堆 $2$。
   * 移动操作只在必要时进行（堆 $2$ 为空且还需取盘子）。

## 总结

本题的关键在于理解如何用两个栈模拟队列，并利用题目允许的批量操作来减少输出。通过将堆 $1$ 作为输入栈、堆 $2$ 作为输出栈，可以保证先进先出的顺序。实现时注意操作合并和输出格式即可顺利通过。
