
> **摘要**：本文讨论一道双人飞镖随机博弈问题。玩家 $\texttt{A}$ 随机投掷，命中 $1$ 至 $20$ 等概率；玩家 $\texttt{B}$ 可瞄准扇区，命中目标及其左右相邻扇区各 $1/3$ 概率，并选择使自身胜率最大的目标。文章以 $f(s_A,s_B)$、$g(s_A,s_B)$ 表示轮到 $\texttt{A}$、$\texttt{B}$ 投掷时 $\texttt{A}$ 的获胜概率，将自环转移分离为 $f=C_A+P_A g$ 与 $g=\min_t(C_t+P_t f)$，通过枚举 $\texttt{B}$ 的 $20$ 个目标联立求解线性方程组，按分数递增顺序递推，时间复杂度 $O(N^2\cdot 20)$，并给出 $\texttt{C++}$ 实现与精度处理要点。

## 题目描述

两名玩家 $\texttt{A}$ 和 $\texttt{B}$ 进行飞镖游戏，初始分数均为 $N$（$1 \le N \le 501$）。  
玩家 $\texttt{A}$ 采用**随机投掷**策略：每次命中的扇区等概率地为 $1$ 到 $20$ 中的任意一个分值。  
玩家 $\texttt{B}$ 采用**瞄准**策略：他可以选择任意一个扇区作为目标，但实际命中的扇区以 $1/3$ 的概率落在目标扇区，以及各 $1/3$ 的概率落在其左右相邻的两个扇区。$\texttt{B}$ 完全了解自己的命中分布，并会选择使自身获胜概率最大的目标。

游戏规则：  
- 玩家轮流投掷，$\texttt{A}$ 先投或 $\texttt{B}$ 先投。  
- 每次投掷后，若当前玩家的分数减去命中分值后**非负**，则分数减少该分值；否则分数不变。  
- 率先将分数减至 $0$ 的玩家获胜。

给定初始分数 $N$，要求分别计算：
1. 若 $\texttt{A}$ 先投，$\texttt{A}$ 获胜的概率；
2. 若 $\texttt{B}$ 先投，$\texttt{B}$ 获胜的概率。

## 输入格式

输入包含若干行，每行一个整数 $N$（$1 \le N \le 501$）。  
输入以一行 $0$ 结束，该行不处理。

## 输出格式

对于每个 $N$，输出一行两个实数：  
- 第一个数为 $\texttt{A}$ 先投时 $\texttt{A}$ 的获胜概率；  
- 第二个数为 $\texttt{B}$ 先投时 $\texttt{B}$ 的获胜概率。  
答案允许绝对或相对误差不超过 $10^{-8}$。

## 样例

输入
```
5
100
0
```
输出
```
0.136363636364 0.909090909091
0.072504908290 0.950215081962
```

## 题目分析

这是一个典型的**随机博弈**问题，状态空间较小（分数 $0 \sim 501$）。每名玩家的行动影响自身分数，且游戏具有**马尔可夫性**：当前胜负概率仅依赖于双方的剩余分数和当前轮到谁。

玩家 $\texttt{A}$ 的策略固定（随机），而玩家 $\texttt{B}$ 的策略是**最优选择**。因此，我们需要为 $\texttt{B}$ 的所有可能行动计算对应的胜率，并取使 $\texttt{B}$ 胜率最大（即 $\texttt{A}$ 胜率最小）的行动。

由于游戏过程分数只会减少（不变的情况仅在投掷分数大于当前分数时发生），因此状态转移是**有向无环**的：从状态 $(s_A, s_B)$ 出发，无论谁投掷，新的状态要么 $(s_A - v, s_B)$ 或 $(s_A, s_B)$（当 $v > s_A$ 时），要么 $(s_A, s_B - v)$，其中 $v$ 为正。注意到当投掷分数大于当前分数时，分数不变，这会产生自环，即当前状态可能转移到自身。但我们可以通过联立方程的方法处理自环，而不是依赖拓扑顺序。

## 解题思路

### 状态定义

设：
- $f(s_A, s_B)$：当前轮到 $\texttt{A}$ 投掷时，$\texttt{A}$ 最终获胜的概率；
- $g(s_A, s_B)$：当前轮到 $\texttt{B}$ 投掷时，$\texttt{A}$ 最终获胜的概率。

目标：
- 若 $\texttt{A}$ 先手，答案为 $f(N, N)$；
- 若 $\texttt{B}$ 先手，$\texttt{B}$ 的胜率为 $1 - g(N, N)$。

边界条件：
- 若 $s_A = 0$，$\texttt{A}$ 已获胜：$f(0, s_B) = g(0, s_B) = 1$；
- 若 $s_B = 0$，$\texttt{B}$ 已获胜：$f(s_A, 0) = g(s_A, 0) = 0$。

### 转移方程

#### 当轮到 $\texttt{A}$ 投掷时

$\texttt{A}$ 等概率命中 $1 \sim 20$ 中的某个分值 $v$，概率为 $1/20$。

- 若 $v = s_A$：$\texttt{A}$ 直接获胜，贡献 $1$；
- 若 $v < s_A$：$\texttt{A}$ 分数变为 $s_A - v$，轮到 $\texttt{B}$，状态转移为 $g(s_A - v, s_B)$；
- 若 $v > s_A$：分数不变，仍轮到 $\texttt{B}$，状态转移为 $g(s_A, s_B)$。

因此：
$$
f(s_A, s_B) = \sum_{v=1}^{20} \frac{1}{20} \cdot 
\begin{cases}
1 & v = s_A \\
g(s_A - v, s_B) & v < s_A \\
g(s_A, s_B) & v > s_A
\end{cases}
$$

将常数项和自环系数分离，得到：
$$
f = C_A + P_A \cdot g
$$
其中
$$
C_A = \frac{1}{20}\sum_{v < s_A} g(s_A - v, s_B) + \frac{1}{20}\mathbf{1}_{s_A \in [1,20]}
,\quad
P_A = \frac{1}{20} \cdot \#\{v \in [1,20] \mid v > s_A\}
$$

#### 当轮到 $\texttt{B}$ 投掷时

$\texttt{B}$ 可以选择目标扇区 $t$（$0 \le t < 20$），命中分值为 $scores[t]$、$scores[(t-1+20)\%20]$、$scores[(t+1)\%20]$，各 $1/3$。

对于每个目标 $t$，设命中分值为 $v$，转移如下：
- 若 $v = s_B$：$\texttt{B}$ 直接获胜，$\texttt{A}$ 胜率为 $0$；
- 若 $v < s_B$：$\texttt{B}$ 分数变为 $s_B - v$，轮到 $\texttt{A}$，状态转移为 $f(s_A, s_B - v)$；
- 若 $v > s_B$：$\texttt{B}$ 分数不变，仍轮到 $\texttt{A}$，状态转移为 $f(s_A, s_B)$。

则对于目标 $t$，$\texttt{A}$ 的胜率 $y_t$ 满足：
$$
y_t = C_t + P_t \cdot f
$$
其中
$$
C_t = \frac{1}{3}\sum_{\substack{v \text{命中}\\ v < s_B}} f(s_A, s_B - v)
,\quad
P_t = \frac{1}{3} \cdot \#\{v \text{命中} \mid v > s_B\}
$$

$\texttt{B}$ 会选择使 $\texttt{A}$ 胜率最小的目标，因此：
$$
g(s_A, s_B) = \min_{0 \le t < 20} \left( C_t + P_t \cdot f(s_A, s_B) \right)
$$

### 联立求解

对于固定的 $(s_A, s_B)$，我们有：
$$
\begin{cases}
f = C_A + P_A \cdot g \\
g = \min_t (C_t + P_t \cdot f)
\end{cases}
$$

由于 $P_A \ge 0$ 且 $P_t \ge 0$，并且 $P_A P_t < 1$（因为 $P_A$ 是分数大于 $s_A$ 的概率，最多 $\frac{20 - s_A}{20}$，当 $s_A \ge 1$ 时 $P_A < 1$；$P_t$ 类似），所以可以直接枚举每个目标 $t$，解对应的线性方程组：
$$
f_t = \frac{C_A + P_A C_t}{1 - P_A P_t}, \quad
g_t = \frac{C_t + P_t C_A}{1 - P_A P_t}
$$
然后取使 $g_t$ 最小的 $t$，得到 $f(s_A, s_B) = f_t$，$g(s_A, s_B) = g_t$。

### 计算顺序

由于 $f(s_A, s_B)$ 的转移依赖 $g(s_A - v, s_B)$ 和 $g(s_A, s_B)$（自环），而 $g$ 又依赖 $f(s_A, s_B - v)$。所有依赖的状态中，分数要么减小（$s_A - v$ 或 $s_B - v$），要么保持不变（自环）。因此，若按 $s_A$ 从小到大、$s_B$ 从小到大顺序计算，则所有非自环依赖的状态已经计算完毕。自环通过联立方程组直接处理，无需依赖其他未计算状态。因此递推顺序可行。

复杂度：对于每个 $(s_A, s_B)$，需要枚举 $20$ 个目标，每个目标计算常数项 $C_t$ 和系数 $P_t$，常数项需要累加三个命中分值的转移，均为 $O(1)$。总体时间复杂度 $O(501^2 \times 20)$，空间 $O(501^2)$，完全满足要求。

## 代码实现

```cpp
// Darts
// UVa ID: 12200
// Verdict: Accepted
// Submission Date: 2026-07-12
// UVa Run Time: 0.030s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 标准飞镖盘顺序（从顶部顺时针）
    const int scores[20] = {20, 1, 18, 4, 13, 6, 10, 15, 2, 17, 3, 19, 7, 16, 8, 11, 14, 9, 12, 5};
    
    vector<int> queries;
    int N;
    while (cin >> N && N != 0) queries.push_back(N);
    if (queries.empty()) return 0;
    
    int maxN = *max_element(queries.begin(), queries.end());
    
    // f[sA][sB]: 轮到A投时A的胜率；g[sA][sB]: 轮到B投时A的胜率
    vector<vector<double>> f(maxN + 1, vector<double>(maxN + 1, 0.0));
    vector<vector<double>> g(maxN + 1, vector<double>(maxN + 1, 0.0));
    
    // 边界条件
    for (int sB = 0; sB <= maxN; ++sB) {
        f[0][sB] = 1.0;
        g[0][sB] = 1.0;
    }
    for (int sA = 0; sA <= maxN; ++sA) {
        f[sA][0] = 0.0;
        g[sA][0] = 0.0;
    }
    f[0][0] = 1.0; // 实际上不会用到
    
    // 按 sA, sB 递增递推
    for (int sA = 1; sA <= maxN; ++sA) {
        for (int sB = 1; sB <= maxN; ++sB) {
            // 计算 A 投掷时的 C_A 和 P_A
            double CA = 0.0, PA = 0.0;
            for (int v = 1; v <= 20; ++v) {
                if (sA == v) {
                    CA += 1.0 / 20.0;
                } else if (sA < v) {
                    PA += 1.0 / 20.0;
                } else { // sA > v
                    CA += g[sA - v][sB] / 20.0;
                }
            }
            
            double bestX = 0.0, bestY = 1e100;
            // 枚举 B 的所有瞄准目标
            for (int target = 0; target < 20; ++target) {
                int left = (target - 1 + 20) % 20;
                int right = (target + 1) % 20;
                int hits[3] = {scores[target], scores[left], scores[right]};
                
                double Ct = 0.0, Pt = 0.0;
                for (int i = 0; i < 3; ++i) {
                    int v = hits[i];
                    if (sB == v) {
                        // B 获胜，贡献 0
                        continue;
                    } else if (sB < v) {
                        Pt += 1.0 / 3.0;
                    } else { // sB > v
                        Ct += f[sA][sB - v] / 3.0;
                    }
                }
                
                double denom = 1.0 - PA * Pt;
                double xt = (CA + PA * Ct) / denom;
                double yt = (Ct + Pt * CA) / denom;
                
                if (yt < bestY) {
                    bestY = yt;
                    bestX = xt;
                }
            }
            
            f[sA][sB] = bestX;
            g[sA][sB] = bestY;
        }
    }
    
    cout << fixed << setprecision(12);
    for (int n : queries) {
        double ansAFirst = f[n][n];
        double ansBFirst = 1.0 - g[n][n];
        cout << ansAFirst << ' ' << ansBFirst << '\n';
    }
    
    return 0;
}
```

## 总结

- 本题通过**动态规划**与**最优策略枚举**相结合，解决了具有自环的随机博弈问题。
- 关键在于将 $\texttt{B}$ 的每个可能目标视为一个线性关系，并通过枚举取最小值，将博弈问题转化为确定性的方程组求解。
- 状态空间较小（$501 \times 501$），使得 $O(N^2 \cdot M)$（$M=20$）的复杂度可行。
- 技巧点：自环处理采用联立方程而非迭代，避免了收敛性问题，且保证精确性。
- 输出精度要求较高，使用 `double` 并设置 `setprecision(12)` 即可满足 $10^{-8}$ 误差。
