### **题目描述**

给定三个整数 $N$、$M$ 和 $T$，要求计算有多少个整数基数 $B$（$B \ge 2$），使得在 $B$ 进制下，$N^{M}$ 的末尾恰好有 $T$ 个零。

**输入格式**：最多 $10000$ 行，每行三个整数 $N$、$M$、$T$。输入以三个 $0$ 结束。

**输出格式**：对于每个测试用例，输出一行 `Case i: X`，其中 $X$ 是满足条件的基数数量对 $100000007$ 取模的结果。

**数据范围**：
- $1 \le N \le 10^{8}$
- $0 < M \le 10^{7}$
- $0 < T \le 10^{4}$

---

### **题目分析**

#### **1. 问题转化**

在 $B$ 进制下，一个数末尾零的个数表示它能被 $B$ 整除多少次。因此，题目要求等价于：
$$
B^{T} \mid N^{M} \quad \text{且} \quad B^{T+1} \nmid N^{M}
$$
其中 $\mid$ 表示“整除”。

设 $B$ 的质因数分解为：
$$
B = p_1^{e_1} p_2^{e_2} \dots
$$
那么 $B^{T} = p_1^{T e_1} p_2^{T e_2} \dots$。

对于每个质因数 $p$，设 $a_p = M \cdot v_p(N)$，其中 $v_p(N)$ 表示 $N$ 中 $p$ 的指数，即 $N$ 能整除 $p^{v_p(N)}$ 的最大次数。

条件 $B^{T} \mid N^{M}$ 等价于：
$$
\forall p: T \cdot e_p \le a_p
$$
条件 $B^{T+1} \nmid N^{M}$ 等价于：
$$
\exists p: (T+1) \cdot e_p > a_p
$$
即至少存在一个质因数 $p$ 使得 $e_p$ 足够大，以至于 $B^{T+1}$ 无法整除 $N^{M}$。

---

#### **2. 确定每个质因数的可选指数范围**

对于给定的质因数 $p$，我们需要找到整数 $e_p \ge 0$ 满足：
1. $e_p \cdot T \le a_p$。
2. 在整体上，至少有一个 $p$ 满足 $e_p \cdot (T+1) > a_p$。

先分析单个 $p$ 的约束：
- 由条件 $1$ 得：$e_p \le \lfloor a_p / T \rfloor$。
- 由条件 $2$ 的严格部分（即满足 $e_p \cdot (T+1) > a_p$）得：$e_p \ge \lfloor a_p / (T+1) \rfloor + 1$。

因此，对于单个 $p$：
- **全部满足条件 $1$** 的 $e_p$ 集合 $\texttt{good}_p$ 大小为：
$$
  g_p = \lfloor a_p / T \rfloor + 1
$$
  因为 $e_p$ 可以取 $0, 1, \dots, \lfloor a_p / T \rfloor$。
- **不满足严格条件 $2$** 的 $e_p$ 集合 $\texttt{nonstrict}_p$ 大小为：
$$
  n_p = \lfloor a_p / (T+1) \rfloor + 1
$$
  因为当 $e_p$ 取 $0, 1, \dots, \lfloor a_p / (T+1) \rfloor$ 时，$e_p \cdot (T+1) \le a_p$，不满足严格不等式。

注意：$n_p$ 是 $g_p$ 的子集（即所有不满足严格条件的 $e_p$ 一定满足条件 $1$）。

---

#### **3. 使用容斥原理计算总方案数**

设 $S$ 为 $N$ 的所有质因数集合。我们需要为每个 $p \in S$ 选择一个非负整数 $e_p$。

- 如果只要求满足条件 $1$（即 $B^{T} \mid N^{M}$），那么总方案数为：
$$
  \prod_{p \in S} g_p
$$
- 在这些方案中，我们需要排除那些所有 $p$ 都不满足严格条件 $2$ 的情况，即所有 $p$ 的 $e_p$ 都属于 $\texttt{nonstrict}_p$。这样的方案数为：
$$
  \prod_{p \in S} n_p
$$

因此，同时满足两个条件的总方案数为：
$$
\texttt{ans} = \prod_{p \in S} g_p - \prod_{p \in S} n_p
$$
结果需要对 $100000007$ 取模。

---

#### **4. 边界情况处理**

- 如果 $N = 1$，则 $S$ 为空集，此时 $\prod g_p = \prod n_p = 1$，答案为 $0$，因为无法满足严格条件 $2$（没有质因数可选）。
- 如果某个 $g_p = 0$（即 $\lfloor a_p / T \rfloor < 0$），这不可能发生，因为 $a_p \ge 0$ 且 $T > 0$。
- 最终答案可能为负数，取模后需调整到 $[0, \text{MOD})$ 范围内。

---

### **算法步骤**

1. 读入 $N$、$M$、$T$。
2. 若 $N = M = T = 0$，结束。
3. 若 $N = 1$，输出 $0$。
4. 对 $N$ 进行质因数分解，得到每个质因数 $p$ 及其指数 $v_p(N)$。
5. 对每个质因数 $p$：
   - 计算 $a_p = M \cdot v_p(N)$。
   - 计算 $g_p = \lfloor a_p / T \rfloor + 1$。
   - 计算 $n_p = \lfloor a_p / (T+1) \rfloor + 1$。
6. 计算 $\prod g_p \bmod \text{MOD}$ 和 $\prod n_p \bmod \text{MOD}$。
7. 输出 $(\prod g_p - \prod n_p) \bmod \text{MOD}$，确保结果非负。

**时间复杂度**：每个 $N$ 的质因数分解需要 $O(\sqrt{N})$，总复杂度可接受，因为 $N \le 10^8$。

### **代码实现**

```cpp
// How Many Bases
// UVa ID: 12216
// Verdict: Accepted
// Submission Date: 2025-12-06
// UVa Run Time: 0.050s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const long long MOD = 100000007;

// 质因数分解
vector<pair<long long, int>> factorize(long long n) {
    vector<pair<long long, int>> factors;
    for (long long p = 2; p * p <= n; p++) {
        if (n % p == 0) {
            int cnt = 0;
            while (n % p == 0) n /= p, cnt++;
            factors.emplace_back(p, cnt);
        }
    }
    if (n > 1) factors.emplace_back(n, 1);
    return factors;
}

int main() {
    long long N, M, T;
    int caseNo = 1;
    while (cin >> N >> M >> T) {
        if (N == 0 && M == 0 && T == 0) break;
        if (N == 1) { // 没有质因数，无法满足严格条件
            cout << "Case " << caseNo++ << ": " << 0 << endl;
            continue;
        }
        auto factors = factorize(N);
        long long totalGood = 1, totalNonStrict = 1;
        for (auto& [p, exp] : factors) {
            long long a = M * exp;
            long long g = a / T + 1; // |good_p|
            long long n = a / (T + 1) + 1; // |nonstrict_p|
            totalGood = (totalGood * g) % MOD;
            totalNonStrict = (totalNonStrict * n) % MOD;
        }
        long long ans = (totalGood - totalNonStrict) % MOD;
        if (ans < 0) ans += MOD;
        cout << "Case " << caseNo++ << ": " << ans << endl;
    }
    return 0;
}
```

### **样例解释**

**样例输入**：
```
24 1 1
100 200 10
23 18 2
0 0 0
```

**样例输出**：
```
Case 1: 6
Case 2: 312
Case 3: 3
```

以第一个样例 `24 1 1` 为例：
- $N = 24 = 2^3 \cdot 3^1$
- $M = 1$，$T = 1$
- 对 $p=2$：$a = 3$，$g = 3/1+1=4$，$n = 3/2+1=2$
- 对 $p=3$：$a = 1$，$g = 1/1+1=2$，$n = 1/2+1=1$
- 答案 = $4 \times 2 - 2 \times 1 = 8 - 2 = 6$

### **总结**

本题的核心在于将“末尾恰好 $T$ 个零”转化为整除条件，并通过质因数分解和容斥原理，将全局约束分解为每个质因数的独立计数问题。最终公式简洁，只需计算每个质因数的两个整数除法的结果即可。

通过 $O(\sqrt{N})$ 的质因数分解，可以在时限内解决 $N \le 10^8$ 的情况。
