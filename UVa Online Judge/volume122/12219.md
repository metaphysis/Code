[UVa 12219 Common Subexpression Elimination](https://blog.csdn.net/metaphysis/article/details/154576861)

## 题目描述

给定一个由 $1$ 到 $4$ 个小写字母组成的单词集合 $\Sigma$（例如 `"a"`、`"b"`、`"f"`、`"aa"`、`"fun"`、`"kvqf"`），考虑由以下两条规则定义的表达式语法：

$$
E \to f
$$
$$
E \to f(E, E)
$$

其中 $f \in \Sigma$。

每个表达式都可以表示为一棵语法树。例如，表达式  
`"a(b(f(a,a),b(f(a,a),f)),f(b(f(a,a),b(f(a,a),f)),f))"`  
对应的语法树在题目附图中给出。

为了减少存储空间，我们可以使用**有向无环图（$\texttt{DAG}$）** 来表示表达式，使得相同的子树只存储一次。例如，上述表达式的树表示有 $21$ 个节点，而图表示只有 $7$ 个节点。

由于树本身也是一种图，因此图表示并不唯一。本题要求：给定一个表达式，找到一个节点数最少的图表示，并用特定格式输出。

**输出格式**：  
- 将重复出现的子树用数字替换，数字指向该子树的根节点在输出中第一次出现的位置。
- 节点编号从 $1$ 开始，按输出顺序依次分配。
- 数字必须指向之前已经输出的节点（不能向前引用）。

例如，上述表达式的一个最优图表示为：  
`a(b(f(a,4),b(3,f)),f(2,6))`

---

## 输入格式

第一行一个整数 $c$（$1 \leq c \leq 200$），表示表达式个数。  
接下来 $c$ 行，每行一个表达式，不含空格，其树表示最多包含 $50,000$ 个节点。

---

## 输出格式

对每个表达式，输出一行，表示节点数最少的图表示。

---

## 样例输入

```

this(is(a,tiny),tree)
a(b(f(a,a),b(f(a,a),f)),f(b(f(a,a),b(f(a,a),f)),f))
z(zz(zzzz(zz,z),zzzz(zz,z)),zzzz(zz(zzzz(zz,z),zzzz(zz,z)),z))
```

## 样例输出

```
this(is(a,tiny),tree)
a(b(f(a,4),b(3,f)),f(2,6))
z(zz(zzzz(zz,z),3),zzzz(2,5))
```

## 题目分析

### 问题本质

我们需要将表达式树转换为 **$\texttt{DAG}$**，使得相同的子树只存储一次，从而最小化节点数。  
输出时，对于重复出现的子树，用其第一次出现时分配的编号代替。

### 关键难点

1. **识别相同子树**：  
   两棵子树相同，当且仅当它们的根节点名称相同，且左右子树分别相同。
   
2. **输出编号顺序**：  
   编号必须按输出顺序分配，且只能指向之前已经输出的节点。

3. **输出格式控制**：  
   在第一次完整输出某子树的结构后，才为其分配编号，后续遇到相同子树时直接输出该编号。

---

## 解题思路

### 步骤一：解析表达式

表达式由函数名和可选的两个参数组成，可以用递归下降法解析：

- 读取 $1$ 到 $4$ 个小写字母作为函数名。
- 如果下一个字符是 `'('`，则递归解析左右两个参数（用逗号分隔），否则为叶子节点。

### 步骤二：规范化子树

为了判断两棵子树是否相同，我们为每个子树分配一个唯一的 `treeId`。  
定义子树的三元组：`(name, leftId, rightId)`，其中：
- `name` 是根节点名称。
- `leftId`、`rightId` 是左右子树的 `treeId`（叶子节点为 $0$）。

使用 `map<tuple<string, int, int>, int>` 存储三元组到 `treeId` 的映射，避免重复分配。

### 步骤三：输出并分配输出编号

在输出过程中：
- 如果当前子树的 `treeId` 已经分配过输出编号，则直接输出该编号。
- 否则：
  1. 输出当前节点的名称。
  2. **立即分配输出编号**（因为该节点已经输出）。
  3. 如果该节点有参数，则输出 `'('`，递归输出左子树，输出 `','`，递归输出右子树，输出 `')'`。

注意：**编号分配必须在输出节点名称之后、输出子节点之前**，这样才能保证后续引用时该节点已经输出。

---

## 算法复杂度

- **时间复杂度**：$O(n \log n)$，其中 $n$ 是节点数，主要来自 `map` 的插入与查找。
- **空间复杂度**：$O(n)$，存储树结构和映射表。

## 参考代码

```cpp
// Common Subexpression Elimination
// UVa ID: 12219

// Submission Date: 2025-11-08

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <map>
#include <vector>
#include <tuple>
using namespace std;

struct Node {
    string name;
    Node* left;
    Node* right;
    int treeId; // 规范化id，用于判断子树是否相同

    Node(const string& n) : name(n), left(nullptr), right(nullptr), treeId(0) {}
};

// 解析表达式
Node* parse(const string& s, int& p) {
    int start = p;
    while (p < s.length() && islower(s[p])) p++;
    string name = s.substr(start, p - start);
    Node* node = new Node(name);

    if (p < s.length() && s[p] == '(') {
        p++; // '('
        node->left = parse(s, p);
        p++; // ','
        node->right = parse(s, p);
        p++; // ')'
    }
    return node;
}

// 规范化子树，分配 treeId
void normalize(Node* node, map<tuple<string, int, int>, int>& treeIdMap, int& idCounter) {
    if (!node) return;
    normalize(node->left, treeIdMap, idCounter);
    normalize(node->right, treeIdMap, idCounter);

    int leftId = node->left ? node->left->treeId : 0;
    int rightId = node->right ? node->right->treeId : 0;
    auto key = make_tuple(node->name, leftId, rightId);

    if (treeIdMap.count(key)) {
        node->treeId = treeIdMap[key];
    } else {
        node->treeId = ++idCounter;
        treeIdMap[key] = node->treeId;
    }
}

// 输出表达式，分配输出编号
void print(Node* node, map<int, int>& outputIdMap, int& outputIdCounter) {
    if (!node) return;

    // 检查该子树是否已经分配输出编号
    if (outputIdMap.count(node->treeId)) {
        cout << outputIdMap[node->treeId];
        return;
    }

    // 第一次输出该子树
    cout << node->name;
    // 立即分配输出编号，这样后续引用时这个节点已经输出
    outputIdMap[node->treeId] = ++outputIdCounter;
    if (node->left) {
        cout << '(';
        print(node->left, outputIdMap, outputIdCounter);
        cout << ',';
        print(node->right, outputIdMap, outputIdCounter);
        cout << ')';
    }
}

int main() {
    int c;
    cin >> c;
    while (c--) {
        string s;
        cin >> s;
        int p = 0;
        Node* root = parse(s, p);

        // 规范化
        map<tuple<string, int, int>, int> treeIdMap;
        int treeIdCounter = 0;
        normalize(root, treeIdMap, treeIdCounter);

        // 输出
        map<int, int> outputIdMap; // treeId -> outputId
        int outputIdCounter = 0;
        print(root, outputIdMap, outputIdCounter);
        cout << endl;

        // 清理内存（略）
    }
    return 0;
}
```

## 总结

本题的关键在于：
- 使用**规范化三元组**识别相同子树。
- 在输出过程中**动态分配输出编号**，并确保编号指向之前已输出的节点。
- 注意**编号分配时机**：在输出节点名称之后、输出子节点之前。

通过递归解析、规范化与输出控制，我们可以在 $O(n \log n)$ 时间内完成公共子表达式消除，并输出符合要求的图表示。
