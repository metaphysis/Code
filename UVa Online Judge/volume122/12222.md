## 问题描述

在弗兰肯瑞士地区，有一条狭窄的山路，该路只有**单车道**，是双向交通的瓶颈。你的任务是**调度从两端驶入的车辆**，使得**最后一辆车离开山路的时间尽可能早**。

### 车辆信息

每辆车由三个值描述：
- **方向**（`A` 或 `B`）
- **到达时间** $t$ （到达对应方向入口的时刻，单位：秒）
- **行驶时间** $d$ （在没有前车阻碍的情况下，完全通过山路所需的时间，单位：秒）

### 约束规则

1. **不允许超车**：山路上车辆不能相互超车。
2. **不允许重新排序**：每端等待队列中的车辆顺序必须保持不变（按输入顺序）。
3. **安全车距**：同方向行驶的两辆连续车辆，**不能在同一路段上相距少于 $10$ 秒**。这意味着如果前车急刹车，后车不会追尾。
4. **例外情况**：如果在两辆同向车辆之间**有对向车辆通过**，则道路被视为空置，此时上述安全车距规则不适用。

### 输入格式

- 第一行：整数 $c$ （$1 \leq c \leq 200$），测试用例数量。
- 每个测试用例：
  - 第一行：整数 $n$ （$1 \leq n \leq 200$），车辆数。
  - 接下来 $n$ 行：每行描述一辆车：一个大写字母（`A` 或 `B`）表示方向，两个整数 $t$ （$0 \leq t \leq 100000$）和 $d$ （$1 \leq d \leq 100000$）。车辆按到达时间升序给出，且没有两辆车同时到达。

### 输出格式

对每个测试用例，输出一个整数，表示在**最优调度下**最后一辆车离开山路的时刻（秒）。

### 样例输入

```
2
4
A 0 60
B 19 10
B 80 20
A 85 100
4
A 0 100
B 50 100
A 100 1
A 170 100
```

### 样例输出

```
200
270
```

## 题目分析

本题是一个**单车道双向调度**问题，具有以下特点：

1. **道路资源唯一**：同一时间只能有一个方向的车辆在道路上行驶。
2. **顺序固定**：车辆必须按输入顺序调度，不能重新排序。
3. **安全距离约束**：连续同向车辆必须保持至少 $10$ 秒的时间间隔。
4. **方向切换自由**：可以在任意时刻切换行驶方向，但切换后道路被视为空置，无需考虑前一方向车辆的安全距离。

问题的核心在于**决定何时切换行驶方向**，以最小化最后一辆车的离开时间。

## 解题思路

### 关键洞察

1. **状态表示**：由于车辆必须按顺序调度，我们可以用 $dp[i][j][dir]$ 表示状态，其中：
   - $i$：已调度的 $A$ 方向车辆数
   - $j$：已调度的 $B$ 方向车辆数  
   - $dir$：当前道路状态（$0$ 表示道路刚被 $A$ 车清空，下一辆可进入的是 $B$ 车；$1$ 表示道路刚被 $B$ 车清空，下一辆可进入的是 $A$ 车）

2. **状态转移**：
   - 当道路刚被 $A$ 车清空（$dir=0$）时，我们可以**连续调度一批 $B$ 车**。
   - 当道路刚被 $B$ 车清空（$dir=1$）时，我们可以**连续调度一批 $A$ 车**。
   - 连续调度同向车辆时，每辆车必须在前一辆车**进入后至少 $10$ 秒**才能进入（安全距离约束）。
   - 车辆的实际离开时间需要考虑**可能被前车阻挡**的情况（不能超车）。

3. **阻挡处理**：如果后车进入时前车还在路上，后车必须跟随前车，其实际离开时间至少是前车的离开时间。

### 动态规划算法

定义 $dp[i][j][0]$ 和 $dp[i][j][1]$ 分别表示调度了 $i$ 辆 $A$ 车和 $j$ 辆 $B$ 车，且道路状态为 $0$ 或 $1$ 时的最早完成时间。

#### 状态转移方程

对于状态 $dp[i][j][0]$（道路刚被 $A$ 车清空）：
- 我们可以连续调度 $B$ 方向的车辆 $B_{j+1}, B_{j+2}, \dots$
- 对于第 $k$ 辆 $B$ 车（$k > j$）：
  - 进入时间 $s = \max(\text{当前时间}, B_k.\text{arrive})$
  - 离开时间 $\text{end} = \max(s + B_k.\text{drive}, \text{前车离开时间})$
  - 更新 $dp[i][k][1] = \min(dp[i][k][1], \text{end})$
  - 为下一辆 $B$ 车预留 $10$ 秒安全间隔：$s += 10$, $\text{end} += 10$

对于状态 $dp[i][j][1]$（道路刚被 $B$ 车清空）：
- 我们可以连续调度 $A$ 方向的车辆 $A_{i+1}, A_{i+2}, \dots$
- 计算方式与上述对称。

#### 初始化
- $dp[0][0][0] = dp[0][0][1] = 0$

#### 最终答案
- $\min(dp[ca][cb][0], dp[ca][cb][1])$，其中 $ca$ 和 $cb$ 分别是 $A$ 和 $B$ 方向的车辆总数。

### 时间复杂度

状态数：$O(n^2)$
每个状态的转移：$O(n)$
总复杂度：$O(n^3)$，对于 $n \leq 200$ 可以接受。

## 示例分析

以第二个测试用例为例：
```
4
A 0 100
B 50 100
A 100 1
A 170 100
```

### 最优调度方案

1. **`B` 车**（$50$ 到达，$100$ 行驶）：$50$ 进入 → $150$ 离开
2. **`A1` 车**（$0$ 到达，$100$ 行驶）：$150$ 进入 → $250$ 离开
3. **`A2` 车**（$100$ 到达，$1$ 行驶）：$160$ 进入，被 `A1` 车阻挡
   - 由于不能超车，必须跟随 `A1` 车
   - 考虑 $10$ 秒安全距离：$250$ 离开（`A1` 离开）→ $260$ 离开（`A2` 离开）
4. **`A3` 车**（$170$ 到达，$100$ 行驶）：$170$ 进入，被 `A2` 车阻挡
   - 跟随 `A2` 车，考虑 $10$ 秒安全距离：$260$ 离开（`A2` 离开）→ $270$ 离开（`A3` 离开）

### 总时间：$270$ 秒

## 代码实现

```cpp
// Mountain Road
// UVa ID: 12222
// Verdict: Accepted
// Submission Date: 2026-01-21
// UVa Run Time: 0.170s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;

struct Car { int arrive, drive; };

int main() {
    int c; cin >> c;
    while (c--) {
        int n; cin >> n;
        vector<Car> carsA(1), carsB(1);
        for (int i = 0; i < n; i++) {
            char dir; cin >> dir;
            if (dir == 'A') {
                Car car; cin >> car.arrive >> car.drive;
                carsA.push_back(car);
            } else {
                Car car; cin >> car.arrive >> car.drive;
                carsB.push_back(car);
            }
        }
        int ca = carsA.size() - 1, cb = carsB.size() - 1;
        vector<vector<vector<int>>> dp(ca + 1, vector<vector<int>>(cb + 1, vector<int>(2, INF)));
        dp[0][0][0] = dp[0][0][1] = 0;
        for (int i = 0; i <= ca; i++) {
            for (int j = 0; j <= cb; j++) {
                // 状态0：道路最后被A车占用，下一辆可以进入的是B车
                // 所以我们可以连续调度多辆B车
                if (dp[i][j][0] < INF) {
                    int s = dp[i][j][0];  // 当前时间
                    int end = 0;          // 最后结束时间
                    // 尝试连续调度B车：从j+1到cb
                    for (int k = j + 1; k <= cb; k++) {
                        // 当前B车进入时间 = max(到达时间, 当前时间)
                        s = max(s, carsB[k].arrive);
                        // 当前B车离开时间 = 进入时间 + 行驶时间
                        end = max(s + carsB[k].drive, end);
                        // 更新状态：调度了i辆A车，k辆B车，道路最后被B车占用[1]
                        dp[i][k][1] = min(dp[i][k][1], end);
                        // 下一辆B车必须至少10秒后进入（安全间隔）
                        s += 10;
                        end += 10;
                    }
                }
                // 状态1：道路最后被B车占用，下一辆可以进入的是A车
                // 所以我们可以连续调度多辆A车
                if (dp[i][j][1] < INF) {
                    int s = dp[i][j][1];
                    int end = 0;
                    // 尝试连续调度A车：从i+1到ca
                    for (int k = i + 1; k <= ca; k++) {
                        s = max(s, carsA[k].arrive);
                        end = max(s + carsA[k].drive, end);
                        dp[k][j][0] = min(dp[k][j][0], end);
                        s += 10;
                        end += 10;
                    }
                }
            }
        }
        int r = min(dp[ca][cb][0], dp[ca][cb][1]);
        cout << r << '\n';
    }
    return 0;
}
```

## 总结

本题通过动态规划巧妙地解决了单车道双向调度问题。关键点在于：
1. 将道路状态分为两种：刚被 $A$ 车清空和刚被 $B$ 车清空。
2. 在每种状态下，可以连续调度同一方向的多个车辆。
3. 通过 $\max(s + drive, end)$ 处理车辆阻挡效应。
4. 通过 $s += 10, end += 10$ 保证安全距离。

算法的时间复杂度为 $O(n^3)$，空间复杂度为 $O(n^2)$，在题目限制范围内可以高效运行。
