## 题目描述

本题要求我们在一个树形的地铁网络中选择一个最佳的居住地，使得一年内往返于各个目标站点（工作、朋友家、圣诞市场等）的总通勤时间最小。

**关键点**：
- 地铁网络是一棵有 $n$ 个节点、$n-1$ 条边的树，边权为通行时间 $t$（单位：秒）。
- 有 $m$ 个目标站点，每个站点 $a$ 每年要访问 $f$ 次。
- 每次出行都是**往返**（从家出发到目标再回家）。
- 需要找到所有使总时间最小的居住地节点，并按递增顺序输出。

## 题目分析

### 问题本质

对于一棵树，每个节点 $u$ 有一个“权重” $f_u$（访问频率，未出现的目标站点权重为 $0$），边有长度 $w$。定义**总代价**为：

$$
cost(u) = 2 \times \sum_{v=1}^{n} f_v \times dist(u, v)
$$

其中 $dist(u, v)$ 是树上 $u$ 到 $v$ 的最短路径长度（唯一路径）。因为每次往返是两倍的单程距离，所以总代价是单程加权距离和的 $2$ 倍。

我们的目标：求 $\min\limits_{1 \le u \le n} cost(u)$，并输出所有达到最小值的 $u$。

### 数据范围与复杂度

- $n \le 50000$，$c \le 200$，总节点数可能达到 $10^7$，因此每个测试用例需要 $O(n)$ 或 $O(n \log n)$ 算法。
- $t \le 300$，$f \le 500$，总代价最大约为 $2 \times 50000 \times 500 \times 300 \approx 1.5 \times 10^{10}$，需要用 `long long`（即 $64$ 位整数）存储。

### 朴素做法不可行

如果对每个节点 $u$ 都进行一次 $\texttt{BFS}$ 或 $\texttt{DFS}$ 计算距离和，复杂度为 $O(n^2)$，无法承受。

## 解题思路

### 核心技巧：换根动态规划（$\texttt{Rerooting DP}$）

这是树形 $\texttt{DP}$ 中经典的一类问题：先选定一个根（比如节点 $1$）计算出以它为根的答案，然后通过**换根**操作，利用父子节点之间的关系在 $O(1)$ 时间内计算出相邻节点为根的答案。

---

### 状态定义

设：

- $freq[u]$：节点 $u$ 的访问频率（题目输入给出，未出现则为 $0$）。
- $totalFreq = \sum_{u=1}^{n} freq[u]$。
- $subFreq[u]$：以 $u$ 为根的子树中所有节点的 $freq$ 之和。
- $dpDown[u]$：以 $u$ 为根的子树中，所有目标节点到 $u$ 的**单程加权距离和**。即：

$$
dpDown[u] = \sum_{v \in \text{subtree}(u)} freq[v] \times \text{dist}(u, v)
$$

- $dpUp[u]$：以 $u$ 为根时，**整棵树**中所有目标节点到 $u$ 的单程加权距离和。即我们最终需要的值（乘以 $2$ 后得到总时间）。

---

### 第一次 $\texttt{DFS}$：计算 $subFreq$ 和 $dpDown$

从任意根（如节点 $1$）开始 $\texttt{DFS}$。

对于当前节点 $u$，遍历其所有子节点 $v$（$v$ 不是父节点）：

1. 先递归处理子节点 $v$，得到 $subFreq[v]$ 和 $dpDown[v]$。
2. 合并到 $u$：
   - $subFreq[u] += subFreq[v]$
   - $dpDown[u] += dpDown[v] + subFreq[v] \times w(u, v)$

解释：$v$ 子树中所有目标节点到 $v$ 的距离和已经算好（$dpDown[v]$），但我们需要它们到 $u$ 的距离，每条从 $v$ 到 $u$ 的边 $w$ 都要额外走一次，并且 $v$ 子树中共有 $subFreq[v]$ 次访问，因此增加 $subFreq[v] \times w$。

边界条件：$subFreq[u] = freq[u]$（自身频率也要计入）。

---

### 第二次 $\texttt{DFS}$：换根计算 $dpUp$

我们已经知道 $dpUp[1] = dpDown[1]$（因为以 $1$ 为根时，整棵树就是它的子树）。

现在考虑从父节点 $p$ 移动到子节点 $c$，边权为 $w$。

当根从 $p$ 变为 $c$ 时：
- 对于原来在 $c$ 子树中的目标节点（共 $subFreq[c]$ 个），它们到 $c$ 的距离比到 $p$ 的距离**少** $w$。
- 对于原来在 $c$ 子树外的目标节点（共 $totalFreq - subFreq[c]$ 个），它们到 $c$ 的距离比到 $p$ 的距离**多** $w$。

因此：

$$
dpUp[c] = dpUp[p] - subFreq[c] \times w + (totalFreq - subFreq[c]) \times w
$$

化简得：

$$
dpUp[c] = dpUp[p] + (totalFreq - 2 \times subFreq[c]) \times w
$$

这个公式是换根 $\texttt{DP}$ 的核心。我们可以在 $\texttt{DFS}$ 中 $O(1)$ 计算出每个子节点的 $dpUp$。

---

### 最终答案

对于每个节点 $u$，一年总通勤时间：

$$
ans[u] = 2 \times dpUp[u]
$$

找出最小值 `minTime`，然后遍历所有节点，输出所有满足 $2 \times dpUp[u] = minTime$ 的 $u$，按升序排列。

---

### 特殊情况

如果 $m = 0$（没有任何目标站点），则 $totalFreq = 0$，所有 $dpUp[u] = 0$，总时间为 $0$，所有节点都是最优解。此时需要输出 $1$ 到 $n$ 的所有节点编号。我们的算法自然能处理这种情况。

---

## 复杂度分析

- 时间：两次 $\texttt{DFS}$ 各遍历所有节点一次，每次处理 $O(1)$ 条边，总复杂度 $O(n)$。
- 空间：存储邻接表 $O(n)$，辅助数组 $O(n)$。

---

```cpp
// Moving to Nuremberg

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXN = 50005;

struct Edge {
    int to, weight;
};

vector<Edge> graph[MAXN];
ll freq[MAXN];          // 每个站点的访问频率
ll subFreq[MAXN];       // 子树中的总访问频率
ll dpDown[MAXN];        // 以u为根的子树中所有目标节点到u的距离和
ll dpUp[MAXN];          // 以u为根时所有目标节点到u的距离和
ll totalFreq;           // 所有站点的总访问频率
int n, m;

void dfs1(int u, int parent) {
    subFreq[u] = freq[u];
    dpDown[u] = 0;
    for (const Edge& e : graph[u]) {
        int v = e.to, w = e.weight;
        if (v == parent) continue;
        dfs1(v, u);
        subFreq[u] += subFreq[v];
        dpDown[u] += dpDown[v] + subFreq[v] * w;
    }
}

void dfs2(int u, int parent) {
    for (const Edge& e : graph[u]) {
        int v = e.to, w = e.weight;
        if (v == parent) continue;
        // 换根：从u移动到v
        dpUp[v] = dpUp[u] + (totalFreq - 2 * subFreq[v]) * w;
        dfs2(v, u);
    }
}

void solve() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        graph[i].clear();
        freq[i] = 0;
    }
    for (int i = 0; i < n - 1; i++) {
        int a, b, t;
        cin >> a >> b >> t;
        graph[a].push_back({b, t});
        graph[b].push_back({a, t});
    }
    cin >> m;
    totalFreq = 0;
    for (int i = 0; i < m; i++) {
        int a, f;
        cin >> a >> f;
        freq[a] = f;
        totalFreq += f;
    }
    
    // 第一次DFS：以1为根
    dfs1(1, -1);
    // 初始化dpUp[1] = dpDown[1]
    dpUp[1] = dpDown[1];
    // 第二次DFS：换根
    dfs2(1, -1);
    
    // 找到最小总时间（往返距离 = 2 * 单程距离和）
    ll minTime = LLONG_MAX;
    for (int i = 1; i <= n; i++) {
        ll cur = 2 * dpUp[i];
        if (cur < minTime) minTime = cur;
    }
    cout << minTime << "\n";
    
    // 输出所有最优解的车站编号
    vector<int> ans;
    for (int i = 1; i <= n; i++)
        if (2 * dpUp[i] == minTime) ans.push_back(i);
    for (size_t i = 0; i < ans.size(); i++) {
        if (i > 0) cout << " ";
        cout << ans[i];
    }
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int c;
    cin >> c;
    while (c--) solve();
    return 0;
}
```
