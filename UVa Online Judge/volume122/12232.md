[UVa 12232 Exclusive-OR](https://blog.csdn.net/metaphysis/article/details/155913403)

## 题目描述

我们有一组 $n$ 个非负整数 $X_0, X_1, \ldots, X_{n-1}$ ，它们的值都小于 $2^{20}$ ，且永远不会改变。我们不知道这些整数的具体值，但系统会逐步给出两种类型的事实信息，并询问一些问题。

### 输入格式

每组测试用例以两个整数 $n$ 和 $Q$ 开始（ $1 \leq n \leq 20000$ , $2 \leq Q \leq 40000$ ）。接下来的 $Q$ 行每行是一个事实或一个问题：

1. **事实类型**：
   - `I p v` ：表示 $X_p = v$
   - `I p q v` ：表示 $X_p \oplus X_q = v$ （其中 $\oplus$ 表示异或运算）

2. **问题类型**：
   - `Q k p₁ p₂ ... pₖ` ：询问 $X_{p_1} \oplus X_{p_2} \oplus \ldots \oplus X_{p_k}$ 的值

问题中的 $k$ 是一个不超过 $15$ 的正整数，事实中的 $v$ 是一个小于 $2^{20}$ 的非负整数。

### 输出要求

对于每个测试用例：
1. 首先输出 `Case i:` （ $i$ 为用例编号）
2. 对于每个问题：
   - 如果能从该问题之前提供的事实推断出答案，则输出答案
   - 否则输出 `I don't know.`
3. 如果第 $i$ 个事实（不计算问题）与之前的所有事实矛盾，则输出 `The first i facts are conflicting.` ，然后不再处理该用例后续的任何内容
4. 每个测试用例的输出后输出一个空行

## 题目分析与解题思路

### 问题本质

这个问题本质上是维护一组变量之间的**异或关系**，并在这些关系的基础上回答变量异或和的查询。变量之间的异或关系具有以下重要性质：

1. **传递性**：如果已知 $X_a \oplus X_b = v_1$ 和 $X_b \oplus X_c = v_2$ ，则可以推导出 $X_a \oplus X_c = v_1 \oplus v_2$
2. **可逆性**：如果 $X_a \oplus X_b = v$ ，则 $X_b = X_a \oplus v$
3. **自反性**： $X_a \oplus X_a = 0$

这些性质使得我们可以将变量组织成**连通分量**，分量内的变量通过异或关系相互关联。

### 核心数据结构：带权并查集

我们使用**带权并查集**来维护变量之间的异或关系，这是解决此类问题的经典方法。

#### 数据结构定义

```cpp
int parent[MAXN];    // 父节点数组
int diff[MAXN];      // diff[x] = X[x] ⊕ X[parent[x]]
int rootValue[MAXN]; // rootValue[r] = X[r] 的值，-1 表示未知
```

这里的关键是 `diff[x]` 的定义：它表示变量 $X_x$ 与其父节点变量 $X_{parent[x]}$ 的异或值。

#### 查找操作（路径压缩）

```cpp
int find(int x) {
    if (parent[x] != x) {
        int root = find(parent[x]);
        diff[x] ^= diff[parent[x]];  // 更新异或值
        parent[x] = root;
    }
    return parent[x];
}
```

查找操作不仅找到根节点，还更新了 `diff[x]` 的值，使得路径压缩后 `diff[x]` 直接表示 $X_x \oplus X_{root}$ 。

#### 合并操作

当接收到事实 `I p q v` （ $X_p \oplus X_q = v$ ）时：

1. 找到 $p$ 和 $q$ 的根节点 $r_p$ 和 $r_q$
2. 如果 $r_p = r_q$ ，检查一致性： $(diff[p] \oplus diff[q])$ 必须等于 $v$
3. 如果 $r_p \neq r_q$ ，合并两个集合：
   - 将 $r_q$ 的父节点设为 $r_p$
   - 设置 $diff[r_q] = diff[p] \oplus diff[q] \oplus v$

**推导过程**：
已知 $X_p \oplus X_q = v$
由定义： $X_p = X_{r_p} \oplus diff[p]$ , $X_q = X_{r_q} \oplus diff[q]$
代入得： $(X_{r_p} \oplus diff[p]) \oplus (X_{r_q} \oplus diff[q]) = v$
整理得： $X_{r_p} \oplus X_{r_q} = v \oplus diff[p] \oplus diff[q]$
因此 $diff[r_q] = X_{r_q} \oplus X_{r_p} = v \oplus diff[p] \oplus diff[q]$

#### 已知值处理

当接收到事实 `I p v` （ $X_p = v$ ）时：
1. 找到 $p$ 的根节点 $r$
2. 计算 $X_r$ 的期望值： $X_r = X_p \oplus diff[p] = v \oplus diff[p]$
3. 如果 $rootValue[r]$ 未知，则设置 $rootValue[r] = v \oplus diff[p]$
4. 如果 $rootValue[r]$ 已知，检查是否一致

### 查询处理

对于查询 `Q k p₁ p₂ ... pₖ` ，我们需要计算 $X_{p_1} \oplus X_{p_2} \oplus \ldots \oplus X_{p_k}$ 。

#### 关键观察

对于每个变量 $X_x$ ，我们可以表示为： $X_x = X_{root} \oplus diff[x]$ ，其中 $root$ 是 $x$ 所在连通分量的根节点。

对于查询中的一组变量，我们按连通分量分组。设一个连通分量的根为 $r$ ，该分量中的查询变量集合为 $S_r$ ，则：

$$
\bigoplus_{x \in S_r} X_x = \bigoplus_{x \in S_r} (X_r \oplus diff[x])
$$

根据异或运算的性质：
- 如果 $|S_r|$ 为奇数：结果为 $X_r \oplus \left( \bigoplus_{x \in S_r} diff[x] \right)$
- 如果 $|S_r|$ 为偶数：结果为 $\bigoplus_{x \in S_r} diff[x]$ （ $X_r$ 被消去）

#### 查询算法步骤

1. 将查询变量按连通分量分组
2. 对于每个连通分量：
   - 计算该分量中所有查询变量的 $diff[x]$ 的异或和
   - 统计该分量中查询变量的个数奇偶性
3. 对于每个分量：
   - 如果查询变量个数为奇数且 $rootValue[r]$ 未知，则无法确定答案
   - 否则，根据上述公式计算该分量的贡献
4. 将所有分量的贡献异或起来得到最终答案

### 冲突检测

在以下情况下会发生冲突：

1. 合并两个已在同一集合的变量时，新的异或关系与已有关系矛盾
2. 设置变量已知值时，与已有的已知值矛盾
3. 合并时，如果两个集合的根都有已知值，但这两个已知值不满足合并后的异或关系

一旦检测到冲突，记录冲突发生的事实编号，之后不再处理任何事实和问题。

### 时间复杂度分析

- 每个查找/合并操作：接近 $O(\alpha(n))$ ，其中 $\alpha(n)$ 是反阿克曼函数，实际可视为常数
- 查询操作： $O(k \log k)$ ，主要开销在于按连通分量分组（使用 map）
- 总体复杂度： $O(Q \cdot \alpha(n) + Q \cdot k \log k)$ ，在题目限制下完全可行

## 代码实现

```cpp
// Exclusive-OR
// UVa ID: 12232
// Verdict: Accepted
// Submission Date: 2025-12-14
// UVa Run Time: 0.060s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 20010;
int parent[MAXN];      // 并查集父节点
int diff[MAXN];        // diff[x] = X[x] ^ X[parent[x]]
int rootValue[MAXN];   // rootValue[r] = X[r] 的值，-1 表示未知
int n, q;              // n 个变量，q 条询问/事实
int caseId;            // 测试用例编号

// 查找根节点，同时更新 diff 值
int find(int x) {
    if (parent[x] != x) {
        int root = find(parent[x]);
        diff[x] ^= diff[parent[x]];
        parent[x] = root;
    }
    return parent[x];
}

// 合并两个集合，已知 x ^ y = val
bool merge(int x, int y, int val) {
    int rx = find(x), ry = find(y);
    if (rx == ry) {
        // 如果已经在同一集合，检查一致性
        return (diff[x] ^ diff[y]) == val;
    }
    // 总是将小根作为父亲
    if (rx > ry) {
        swap(rx, ry);
        swap(x, y);
    }
    parent[ry] = rx;
    diff[ry] = diff[x] ^ diff[y] ^ val;
    
    // 传播已知值
    if (rootValue[rx] != -1 && rootValue[ry] != -1) {
        return rootValue[ry] == (rootValue[rx] ^ diff[ry]);
    }
    if (rootValue[ry] != -1) {
        rootValue[rx] = rootValue[ry] ^ diff[ry];
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    while (cin >> n >> q && n) {
        caseId++;
        cout << "Case " << caseId << ":\n";
        
        // 初始化
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            diff[i] = 0;
            rootValue[i] = -1;
        }
        
        int facts = 0;            // 已处理的事实数量
        bool conflict = false;    // 是否已发现冲突
        int conflictFact = 0;     // 冲突发生的事实编号
        
        cin.ignore();  // 忽略换行符
        for (int i = 0; i < q; i++) {
            string line;
            getline(cin, line);
            if (conflict) continue;
            
            if (line[0] == 'I') {
                facts++;
                istringstream iss(line);
                char type;
                int p, q, v;
                iss >> type >> p;
                
                if (iss >> q >> v) {
                    // 格式: I p q v
                    if (!merge(p, q, v)) {
                        conflict = true;
                        conflictFact = facts;
                    }
                } else {
                    // 格式: I p v
                    v = q;
                    int r = find(p);
                    int expected = diff[p] ^ v;  // X[r] = X[p] ^ diff[p]
                    
                    if (rootValue[r] != -1) {
                        if (rootValue[r] != expected) {
                            conflict = true;
                            conflictFact = facts;
                        }
                    } else {
                        rootValue[r] = expected;
                    }
                }
            } else if (line[0] == 'Q') {
                istringstream iss(line);
                char type;
                int k;
                iss >> type >> k;
                
                vector<int> vars(k);
                for (int j = 0; j < k; j++) iss >> vars[j];
                
                // 统计每个连通分量的信息
                map<int, int> compXor;  // 分量内查询变量的 diff 异或和
                map<int, int> compCnt;  // 分量内查询变量个数奇偶性
                
                for (int j = 0; j < k; j++) {
                    int x = vars[j];
                    int r = find(x);
                    compXor[r] ^= diff[x];
                    compCnt[r] ^= 1;  // 切换奇偶性
                }
                
                int ans = 0;
                bool unknown = false;
                
                for (auto& entry : compCnt) {
                    int r = entry.first;
                    int parity = entry.second;
                    int diffSum = compXor[r];
                    
                    if (parity) {  // 奇数个变量
                        if (rootValue[r] == -1) {
                            unknown = true;
                            break;
                        }
                        ans ^= rootValue[r] ^ diffSum;
                    } else {  // 偶数个变量
                        ans ^= diffSum;  // X[r] 被消去，只需要 diff 的异或和
                    }
                }
                
                if (unknown) cout << "I don't know.\n";
                else cout << ans << "\n";
            }
        }
        
        if (conflict) {
            cout << "The first " << conflictFact << " facts are conflicting.\n";
        }
        cout << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解异或关系的传递性，并使用带权并查集来维护这些关系。通过维护每个变量与其父节点的异或值（ `diff` 数组），我们可以高效地处理变量之间的异或关系和已知值信息。

查询处理时需要特别注意：当连通分量中的查询变量个数为偶数时，根节点的值会被消去，因此不需要知道根节点的具体值也能计算答案。这一观察是正确解决本题的关键。

该算法时间复杂度优秀，能够处理题目中 $n \leq 20000$ , $Q \leq 40000$ 的大规模数据。
