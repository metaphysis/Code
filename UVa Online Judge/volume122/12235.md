## 题目描述

$\texttt{Bubu}$ 的书架上有 $n$ 本书，每本书都有一个高度。我们定义书架的**混乱值**为**连续相同高度书籍的段数**。例如：

- 书的高度为 $[30, 30, 31, 31, 32]$，混乱值为 $3$
- 书的高度为 $[30, 32, 32, 31]$，混乱值为 $3$
- 书的高度为 $[31, 32, 31, 32, 31]$，混乱值为 $5$

$\texttt{Bubu}$ 想要减少书架的混乱值，他最多可以取出 $k$ 本书，然后将它们放回书架的任意位置。你需要帮助他找到操作后可能的最小混乱值。

## 输入格式

最多有 $20$ 个测试用例。每个用例包含：

- 两个整数 $n$ 和 $k$ ($1 \leq k \leq n \leq 100$)
- 一行 $n$ 个整数，表示书的高度（每个高度在 $25$ 到 $32$ 之间）

以 $n = k = 0$ 结束输入。

## 输出格式

对于每个测试用例，输出用例编号和最小混乱值，每个输出后跟一个空行。

## 题目分析

### 问题本质

这个问题看似简单，但实际上需要深入理解动态规划和状态压缩。关键点在于：

1. **取出和放回的操作**：我们可以取出最多 $k$ 本书，然后以任意顺序放回任意位置
2. **保留书的相对顺序**：没有被取出的书必须保持原来的相对顺序
3. **重新排列的自由**：取出的书可以自由排列，这给了我们优化段数的机会

### 核心观察

经过分析，我们可以得出以下重要观察：

1. **最优策略**：在最优解中，相同高度的书应该放在一起形成连续的段
2. **段数下界**：最小混乱值不可能少于不同高度的种类数
3. **动态规划状态**：我们需要跟踪以下信息：
   - 处理了多少本书
   - 保留了多少本书
   - 已经出现了哪些高度
   - 最后一本保留书的高度

### 解题思路

我们使用动态规划结合状态压缩来解决这个问题：

1. **状态定义**：
   - $dp[i][j][mask][last]$ 表示考虑前 $i$ 本书，保留了 $j$ 本书，出现的高度集合为 $mask$，最后一本保留书的高度为 $last$ 时的最小段数

2. **状态转移**：
   - 对于第 $i$ 本书（高度为 $h$）：
     - **不保留**：直接跳过，状态不变
     - **保留**：如果 $h = last$，段数不变；否则段数加 $1$

3. **最终答案计算**：
   - 对于所有有效的最终状态（保留 $j$ 本书，且 $n - j \leq k$）：
     - 基础段数 = $dp[n][j][mask][last]$
     - 额外段数 = 那些在保留书中没有出现，但在原书中存在的高度数量
     - 总段数 = 基础段数 + 额外段数

## 算法复杂度

- **时间复杂度**：$O(n^2 \times 2^8 \times 8)$，对于 $n \leq 100$ 是可接受的
- **空间复杂度**：$O(n^2 \times 2^8 \times 8)$，使用滚动数组可以优化

## 代码实现

```cpp
// Help Bubu
// UVa ID: 12235

// UVa Run Time: 0.370s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
int dp[105][105][1 << 8][9];
int books[105];
int heightCount[8];

int main() {
    int n, k, caseNum = 1;
    
    while (cin >> n >> k && (n || k)) {
        memset(heightCount, 0, sizeof(heightCount));
        for (int i = 0; i < n; i++) {
            cin >> books[i];
            books[i] -= 25;
            heightCount[books[i]]++;
        }
        
        memset(dp, INF, sizeof(dp));
        dp[0][0][0][8] = 0;
        
        for (int i = 0; i < n; i++) {
            int h = books[i];
            for (int j = 0; j <= i; j++) {
                for (int mask = 0; mask < (1 << 8); mask++) {
                    for (int last = 0; last <= 8; last++) {
                        if (dp[i][j][mask][last] == INF) continue;
                        
                        int val = dp[i][j][mask][last];
                        
                        // 选择1: 不保留当前书
                        dp[i + 1][j][mask][last] = min(dp[i + 1][j][mask][last], val);
                        
                        // 选择2: 保留当前书
                        int newMask = mask | (1 << h);
                        int newVal = val;
                        if (h != last) newVal++;
                        
                        dp[i + 1][j + 1][newMask][h] = min(dp[i + 1][j + 1][newMask][h], newVal);
                    }
                }
            }
        }
        
        int answer = INF;
        for (int j = max(1, n - k); j <= n; j++) {
            int removed = n - j;  // 实际取出的书数量
            if (removed > k) continue;
            
            for (int mask = 0; mask < (1 << 8); mask++) {
                for (int last = 0; last < 8; last++) {
                    if (dp[n][j][mask][last] == INF) continue;
                    
                    int baseSegments = dp[n][j][mask][last];
                    int extraSegments = 0;
                    
                    // 计算必须创建新段的高度
                    for (int h = 0; h < 8; h++) {
                        if (!(mask & (1 << h))) {  // 这个高度在保留书中没有
                            if (heightCount[h] > 0) {  // 但这个高度在原书中存在
                                // 说明这个高度的书都被取出了，需要创建新段
                                extraSegments++;
                            }
                        }
                    }
                    
                    answer = min(answer, baseSegments + extraSegments);
                }
            }
        }
        
        cout << "Case " << caseNum++ << ": " << answer << endl << endl;
    }
    
    return 0;
}
```

这道题是一个典型的动态规划与状态压缩结合的问题。关键在于理解：

1. 保留书的相对顺序约束
2. 重新排列取出的书的自由度
3. 如何通过状态压缩来跟踪高度集合

通过合理的状态设计和转移，我们能够高效地解决这个问题，找到最优的整理策略。
