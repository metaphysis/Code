## 题目描述

给定 $N$ 个二维平面上的点 $(X_i, Y_i)$ ，求其中最大的共圆子集的大小。所谓共圆子集，是指存在一个圆，使得该子集中的所有点都恰好在这个圆的圆周上。

**输入格式：**
- 多组测试数据，每组数据以 $N$ 开始。
- 接下来 $N$ 行每行两个整数 $X, Y$。
- $N = 0$ 表示输入结束。
- $1 \le N \le 100$， $-10^4 \le X, Y \le 10^4$。
- 同一个测试点中不会出现重复坐标。

**输出格式：**
对于每组数据，输出一个整数，表示最大共圆子集的大小。

## 题目分析

这是一个计算几何问题，需要找到平面点集中最大的共圆子集。由于 $N$ 最大为 $100$ ，我们可以考虑枚举所有可能确定一个圆的三元组，然后检查有多少个点位于这个圆上。

**关键难点：**
1. **如何确定一个圆**：不共线的三点唯一确定一个圆。
2. **如何判断点是否在圆上**：计算点到圆心的距离是否等于半径。
3. **精度问题**：直接使用浮点数计算圆心、半径和距离时，比较是否相等会因浮点误差而导致错误判断。

**解题思路：**
- 枚举所有三元组 $(i, j, k)$ 。
- 如果三点共线，则跳过（无法唯一确定一个圆）。
- 否则，计算通过这三点的圆的圆心和半径（使用整数运算避免浮点误差）。
- 遍历所有点，统计有多少个点在这个圆上。
- 记录最大值。

**为什么至少为 $2$ ？**
- 当 $N \ge 2$ 时，任意两点都可以找到无数个圆同时经过它们，所以任意两个点总是“共圆”的。因此答案至少为 $2$（除非 $N = 1$ ，答案为 $1$）。
- 当 $N \ge 3$ 且所有点共线时，不可能有三个点共圆（因为共线的三点无法确定一个圆，除非它们在同一条直线上，而圆不可能包含三个共线的点），此时最大共圆子集大小仍然是 $2$。

**如何避免浮点误差？**
使用有理数（分数）精确表示圆心坐标和半径平方：
- 圆心 $(x_c, y_c)$ 表示为 $\left(\frac{N_x}{D}, \frac{N_y}{D}\right)$。
- 半径平方 $R^2$ 表示为 $\frac{R_n}{D^2}$。
- 点 $P(x, y)$ 到圆心的距离平方为 $\frac{(Dx - N_x)^2 + (Dy - N_y)^2}{D^2}$。
- 比较点是否在圆上：比较分子 $(Dx - N_x)^2 + (Dy - N_y)^2$ 是否等于 $R_n$（分母相同，都是 $D^2$）。

**算法复杂度：**
- 枚举三元组： $O(N^3)$。
- 每个三元组检查所有点： $O(N)$。
- 总复杂度： $O(N^4)$，在 $N \le 100$ 时是可接受的（最坏 $100^4 = 10^8$ 次操作，但实际远达不到，且常数很小）。

## 算法步骤

1. 读入点集。
2. 初始化答案 $answer = \min(N, 2)$。
3. 如果 $N \ge 3$，枚举所有三元组 $(i, j, k)$：
   - 判断三点是否共线（叉积为零）。
   - 如果不共线，使用公式计算圆心和半径（整数形式）。
   - 遍历所有点，统计在圆上的点的数量。
   - 更新最大值。
4. 输出答案。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
    Point() {}
    Point(int x, int y) : x(x), y(y) {}
};

// 判断三点是否共线（叉积为零）
bool isCollinear(const Point& a, const Point& b, const Point& c) {
    return (b.y - a.y) * (c.x - b.x) == (c.y - b.y) * (b.x - a.x);
}

// 计算通过不共线三点的圆的参数（整数精确计算）
// 圆心 (cxNum/cxDen, cyNum/cyDen)，半径平方的分子 rsqNum，分母 rsqDen = cxDen^2
bool findCircleExact(const Point& p1, const Point& p2, const Point& p3,
                     long long& cxNum, long long& cxDen,
                     long long& cyNum, long long& cyDen,
                     long long& rsqNum, long long& rsqDen) {
    long long A1 = 2LL * (p2.x - p1.x);
    long long B1 = 2LL * (p2.y - p1.y);
    long long C1 = (1LL * p2.x * p2.x - 1LL * p1.x * p1.x) + 
                   (1LL * p2.y * p2.y - 1LL * p1.y * p1.y);
    
    long long A2 = 2LL * (p3.x - p1.x);
    long long B2 = 2LL * (p3.y - p1.y);
    long long C2 = (1LL * p3.x * p3.x - 1LL * p1.x * p1.x) + 
                   (1LL * p3.y * p3.y - 1LL * p1.y * p1.y);
    
    long long D = A1 * B2 - A2 * B1;
    if (D == 0) return false; // 三点共线
    
    cxNum = C1 * B2 - C2 * B1;
    cyNum = A1 * C2 - A2 * C1;
    cxDen = cyDen = D;
    
    // 计算半径平方：R^2 = (x1 - cx)^2 + (y1 - cy)^2
    // 通分到分母 D^2
    long long dx = cxDen * p1.x - cxNum;
    long long dy = cyDen * p1.y - cyNum;
    rsqNum = dx * dx + dy * dy;
    rsqDen = cxDen * cxDen;  // D^2
    
    return true;
}

// 判断点 p 是否在圆上（精确比较）
bool isOnCircle(const Point& p, 
                long long cxNum, long long cxDen,
                long long cyNum, long long cyDen,
                long long rsqNum, long long rsqDen) {
    long long dx = cxDen * p.x - cxNum;
    long long dy = cyDen * p.y - cyNum;
    long long distSqNum = dx * dx + dy * dy;
    // 分母相同（都是 rsqDen），只需比较分子
    return distSqNum == rsqNum;
}

int main() {
    int n;
    while (cin >> n && n) {
        vector<Point> points(n);
        for (int i = 0; i < n; ++i) cin >> points[i].x >> points[i].y;

        int answer = min(n, 2); // 至少为 2（如果 n>=2），否则为 1
        
        if (n >= 3) {
            for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
            for (int k = j + 1; k < n; ++k) {
                if (isCollinear(points[i], points[j], points[k])) continue;
                
                long long cxNum, cxDen, cyNum, cyDen, rsqNum, rsqDen;
                if (!findCircleExact(points[i], points[j], points[k],
                                     cxNum, cxDen, cyNum, cyDen, rsqNum, rsqDen)) continue;
                
                int cnt = 3; // 三点本身在圆上
                for (int m = 0; m < n; ++m) {
                    if (m == i || m == j || m == k) continue;
                    if (isOnCircle(points[m], cxNum, cxDen, cyNum, cyDen, rsqNum, rsqDen)) cnt++;
                }
                answer = max(ans, cnt);
            }
        }
        
        cout << answer << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于**避免浮点误差**。通过将圆心和半径用分数（有理数）精确表示，我们可以用整数运算判断点是否在圆上，从而得到正确结果。算法的时间复杂度为 $O(N^4)$，在 $N \le 100$ 时完全可行。注意处理 $N < 3$ 的边界情况，并理解“至少两个点总可以共圆”这一几何事实。
