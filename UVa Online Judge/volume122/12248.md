## 题目描述

有 $K$ 个孩子（$3 \leq K \leq 10^9$）要围成一个圆圈，每个孩子恰好有两个邻居（左邻和右邻）。给出 $W$ 条愿望（$0 \leq W \leq 10^5$），每条愿望表示某两个孩子希望相邻。每个孩子最多有 $2$ 条愿望（因为只有两个邻居）。要求判断是否存在一种围成圆圈的方式，使得**所有愿望同时被满足**。

输入包含多组测试数据，每组数据第一行是 $K$ 和 $W$，接下来 $W$ 行每行两个不同的整数 $A$ 和 $B$，表示孩子 $A$ 希望与孩子 $B$ 相邻。最后一行 `0 0` 表示输入结束。

对每组数据输出一行 `Y`（可行）或 `N`（不可行）。

## 问题分析

### 图论建模

把每个孩子看作图的一个顶点，每条愿望看作一条无向边。由于每个孩子在圆桌上恰好有两个邻居，因此**最终构造出的圆桌排列对应一个包含所有 $K$ 个顶点的哈密顿环**。

题目要求：**必须使用所有给定的愿望边**（如果一条愿望存在，那么在最终环中，这两个顶点必须相邻）。其余顶点之间的相邻关系可以自由安排。

因此问题转化为：给定一个度数不超过 $2$ 的无向图（每个顶点最多有两个愿望），问能否**在原图的基础上添加一些边**，使得整个图变成一个包含所有 $K$ 个顶点的简单环。

### 度数限制的意义

每个顶点在最终环中的度数恰好为 $2$。原图已经给出了每个顶点的一部分邻接关系（$0$、$1$ 或 $2$ 条边）。如果某个顶点在原图中已经达到度数 $2$，则它的两个邻居就被**固定**了，不能再连接其他顶点。如果某个顶点在原图中度数为 $1$，则它还需要恰好 $1$ 个新邻居；度数为 $0$ 的顶点则需要 $2$ 个新邻居。

### 核心观察：环与链

由于每个顶点的度数 $\leq 2$，原图由若干连通分量组成，每个连通分量只能是以下三种形态之一：

1. **孤立点**（度数为 $0$）
2. **链**（路径）：两个端点的度数为 $1$，中间所有点的度数为 $2$
3. **环**（简单环）：所有点的度数都为 $2$

**关键性质**：如果存在一个环（大小 $< K$），那么环上的每个顶点度数已经达到 $2$，不能再连接环外的任何顶点。这意味着**所有不在该环上的顶点（包括孤立点和其他链）都无法连接到这个环上**，因此不可能形成包含所有 $K$ 个顶点的环。唯一的例外是：当这个环本身就包含了**所有 $K$ 个顶点**时，它是可行的。

### 结论性条件

经过以上分析，我们可以得到判断的充要条件：

1. 如果原图中存在某个顶点的度数 $> 2$，直接不可行（输入数据可能因重复边导致度数虚高，需要先去重）。
2. 对去重后的图进行连通分量分析：
   - 如果存在一个环，则该环必须包含**所有 $K$ 个顶点**（即图中只有一个环且没有链，且该环的顶点数等于 $K$）。
   - 否则（没有环），所有连通分量都是链（包括长度为 $0$ 的孤立点），此时一定可以将它们首尾连接成一个包含所有 $K$ 个顶点的大环。

## 解题思路

### 步骤 1：处理输入和去重

由于 $K$ 可达 $10^9$，不能开大小为 $K$ 的数组。但 $W \leq 10^5$，实际出现在愿望中的顶点数最多为 $2W \leq 2 \times 10^5$。因此需要**坐标压缩**：将顶点编号映射到 $[1, cnt]$ 范围内。

同时，输入中可能存在重复的愿望（同一条边出现多次），这会导致度数虚高。使用 $\texttt{set}$ 存储邻接关系，自动完成去重。

### 步骤 2：度数检查

遍历所有出现过的顶点，检查其真实度数（去重后的度数）是否 $\leq 2$。若存在度数 $> 2$ 的顶点，直接输出 $\texttt{N}$。

### 步骤 3：连通分量分析

使用 $\texttt{DFS}$ 遍历每个连通分量，并区分它是**链**还是**环**。

区分方法：
- 在 $\texttt{DFS}$ 过程中，如果遇到一个已经访问过的邻居（且不是父节点），则说明发现了环。
- 如果整个连通分量遍历结束都没有遇到上述情况，则说明它是链（或孤立点）。

同时，用 $\texttt{chain}$ 和 $\texttt{cycle}$ 分别统计链和环的数量。

### 步骤 4：根据规则判断

根据前面推导的结论：

- 如果存在**环**（$\texttt{cycle} > 0$）：
  - 环的数量必须为 $1$（$\texttt{cycle} = 1$）
  - 不能同时有链（$\texttt{chain} = 0$）
  - 环必须包含所有 $K$ 个顶点（$\text{cnt} = K$，其中 $cnt$ 是实际出现过的顶点数）
  
- 如果没有环（$\texttt{cycle} = 0$）：
  - 总是可行（因为所有连通分量都是链 / 孤立点，可以连接成一个大环）

## 复杂度分析

- 时间复杂度：$O(W \log W)$，主要来自 $\texttt{set}$ 的去重操作和 $\texttt{DFS}$ 遍历。
- 空间复杂度：$O(W)$，存储邻接表和标记数组。

## 代码实现

```cpp
// Kids' Wishes
// UVa ID: 12248

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int N = 200005;
set<int> g[N];      // 邻接表，使用 set 自动去重
bool vis[N];        // DFS 访问标记
int deg[N];         // 每个顶点的度数
map<int, int> mp;   // 坐标压缩映射

// DFS 遍历连通分量
// u: 当前顶点，p: 父节点，cycle: 引用参数，标记是否发现环
bool dfs(int u, int p, bool &cycle) {
    vis[u] = 1;
    for (int v : g[u]) {
        if (v == p) continue;
        if (vis[v]) {
            cycle = 1;      // 遇到已访问且非父节点的顶点 → 发现环
            continue;
        }
        if (!dfs(v, u, cycle)) return 0;
    }
    return 1;
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0);
    long long K; int W;
    while (cin >> K >> W, K || W) {
        // 清空数据结构
        mp.clear();
        for (int i = 1; i <= W * 2; ++i) {
            g[i].clear();
            deg[i] = vis[i] = 0;
        }
        
        int cnt = 0;    // 实际出现过的不同顶点数
        for (int i = 0; i < W; ++i) {
            int a, b; cin >> a >> b;
            if (a == b) continue;           // 自环无效
            // 坐标压缩
            if (!mp.count(a)) mp[a] = ++cnt;
            if (!mp.count(b)) mp[b] = ++cnt;
            int u = mp[a], v = mp[b];
            // 去重
            if (g[u].count(v)) continue;
            g[u].insert(v); g[v].insert(u);
            deg[u]++; deg[v]++;
        }
        
        // 检查度数是否超过 2
        bool ok = 1;
        for (int i = 1; i <= cnt; ++i) {
            if (deg[i] > 2) { ok = 0; break; }
        }
        if (!ok) { cout << "N\n"; continue; }
        
        // 没有边的情况：所有孩子都是孤立点，总能排成环
        if (cnt == 0) { cout << "Y\n"; continue; }
        
        int chain = 0, cycle = 0;
        for (int i = 1; i <= cnt; ++i) {
            if (!vis[i] && deg[i]) {
                bool isCycle = 0;
                if (!dfs(i, -1, isCycle)) { ok = 0; break; }
                if (isCycle) cycle++;
                else chain++;
            }
        }
        
        if (!ok) cout << "N\n";
        else if (cycle == 1 && cnt == K && chain == 0) cout << "Y\n";
        else if (cycle == 0) cout << "Y\n";
        else cout << "N\n";
    }
    return 0;
}
```

## 总结

本题的关键在于**将愿望关系建模为图**，并利用每个顶点度数不超过 $2$ 的性质，将问题简化为判断图中是否存在「不包含所有顶点的小环」。通过坐标压缩处理大范围的顶点编号，使用 $\texttt{DFS}$ 区分链和环，最后根据环的数量和是否包含所有顶点做出决策。这种分析方法同样适用于其他类似的「度数受限图的可扩展环问题」。
