## 题目描述

今天是朋友的生日，你和一些朋友决定一起买一份《星际争霸 $\texttt{II}$》作为礼物。你们同意尽可能公平地分摊费用，并且考虑到每个人的经济状况，没有人需要支付超过他能力范围的钱。每个人的支付金额必须是 $1$ 分的整数倍。

每个人都写下了自己能支付的最高金额。根据这些最高金额，你们需要尽可能公平地分摊礼物费用。公平性的定义是：最小化每个人的支付金额与总费用的 $\frac{1}{n}$ 之间的最大差距。如果存在多个方案的最大差距相同，则比较第二大的差距，依此类推，直到分出优劣。由于支付金额必须是整数分，可能存在多个最优解。在这种情况下，最高支付能力更高的人应该支付更多。如果仍然存在平局，则列表中靠前的人支付更多。

你的任务是计算出每个人（包括你自己）需要支付多少钱。

### 输入格式

第一行包含一个正整数 $T$ ，表示测试用例的数量（最多 $100$ 个）。每个测试用例包含：

- 一行两个整数 $p$ 和 $n$ ：礼物的价格（以分为单位， $1 \le p \le 10^6$ ）和分摊费用的人数（ $2 \le n \le 100$ ，包括你自己）。
- 一行 $n$ 个整数 $a_i$ （ $1 \le a_i \le 10^6$ ），表示第 $i$ 个人能够支付的最高金额（以分为单位）。

### 输出格式

对于每个测试用例，输出一行 $n$ 个整数，表示根据规则每个人需要支付的金额。如果无法按照规则分摊费用（即所有人的最高支付金额之和小于 $p$ ），则输出 `IMPOSSIBLE` 。

### 样例输入

```
3
20 4
10 10 4 4
7 3
1 1 4
34 5
9 8 9 9 4
```

### 样例输出

```
6 6 4 4
IMPOSSIBLE
8 7 8 7 4
```

## 题目分析

### 问题本质

我们需要找到支付方案 $x_1, x_2, \ldots, x_n$ ，满足：

1. $0 \le x_i \le a_i$ （不超过个人能力上限）
2. $\sum_{i=1}^n x_i = p$ （支付总金额等于礼物价格）
3. 定义差距 $d_i = |x_i - \frac{p}{n}|$ ，我们需要最小化差距向量 $sorted(d,$ 降序$)$ 的字典序
4. 如果存在多个方案的差距向量完全相同，则比较支付金额：支付能力 $a_i$ 更高的人应该支付更多
5. 如果仍然平局，则列表中序号更小的人支付更多

这是一个多目标优化问题，但可以通过巧妙的贪心算法解决。

### 关键难点

1. **支付金额必须是整数**：这增加了问题的离散性
2. **多级优化目标**：首先最小化最大差距，然后第二、第三大差距，形成字典序比较
3. **平局处理**：需要按照能力高低和序号先后打破平局

### 核心观察

1. **可行性判断**：如果所有人的最高支付能力之和小于 $p$ ，则直接输出 `IMPOSSIBLE`
2. **最优结构**：最优解中，每个人的支付金额应尽可能接近平均值 $\frac{p}{n}$
3. **约束处理**：对于支付能力较低的人，他们只能支付到自己的能力上限
4. **差距最小化**：让支付金额分布尽可能均匀，这样可以最小化最大差距

## 解题思路

### 方法一：逐分贪心（暴力但清晰）

最简单的思路是每次分配 $1$ 分钱，总是给当前支付最少且有能力增加的人分配。这样做的理由是：

- 给支付最少的人增加 $1$ 分，可以最小化最大差距
- 当多人支付相同时，按照题目规则（能力高者优先，序号小者优先）决定谁先增加

**算法步骤**：

1. 检查可行性：如果 $\sum a_i < p$ ，输出 `IMPOSSIBLE`
2. 初始化所有人支付金额为 $0$
3. 当还有剩余金额时：
   - 将人员按当前支付金额升序排序
   - 如果支付金额相同，按支付能力降序排序
   - 如果支付能力也相同，按序号升序排序
   - 找到第一个还能增加支付的人，给他增加 $1$ 分
4. 输出最终支付方案

**时间复杂度**： $O(p \cdot n \log n)$ ，在 $p=10^6, n=100$ 时约为 $10^8$ 次操作，可能会超时

### 方法二：批量分配（高效算法）

我们需要更高效的方法。核心思路是：

1. **二分确定最小最大差距**：
   - 对于候选的最大差距 $D$ ，检查是否存在方案使得所有 $|x_i - \frac{p}{n}| \le D$
   - 这等价于每个 $x_i$ 需要在区间 $[L_i, R_i]$ 内，其中：
     - $L_i = \max(0, \lceil \frac{p}{n} - D \rceil)$
     - $R_i = \min(a_i, \lfloor \frac{p}{n} + D \rfloor)$
   - 检查是否满足 $\sum L_i \le p \le \sum R_i$

2. **构造最优方案**：
   - 找到最小的 $D$ 后，先让每个人支付 $L_i$
   - 还有剩余金额 $p - \sum L_i$ 需要分配
   - 在不超过 $R_i$ 的前提下，尽量均匀分配剩余金额
   - 按照题目规则（能力高者优先，序号小者优先）打破平局

3. **算法步骤**：
   - 可行性检查
   - 二分搜索最小最大差距 $D$
   - 计算每个人的支付区间 $[L_i, R_i]$
   - 先支付 $L_i$ ，然后分配剩余金额
   - 输出最终方案

**时间复杂度**： $O(n \log p + n^2)$ ，可以高效处理所有测试用例

## 算法细节与实现

### 1. 可行性检查

这是最简单的部分：计算所有 $a_i$ 的总和，如果小于 $p$ ，则直接输出 `IMPOSSIBLE` 。

### 2. 二分搜索最小最大差距

设平均值为 $\text{avg} = \frac{p}{n}$ 。对于给定的差距上限 $D$ ，每个人的支付区间为：

- 下界： $L_i = \max(0, \lceil \text{avg} - D \rceil)$
- 上界： $R_i = \min(a_i, \lfloor \text{avg} + D \rfloor)$

需要满足 $L_i \le R_i$ ，否则该 $D$ 不可行。同时需要满足 $\sum L_i \le p \le \sum R_i$ ，否则无法凑出总金额 $p$ 。

通过二分搜索找到满足条件的最小 $D$ 。

### 3. 构造支付方案

找到最小 $D$ 后，我们按以下步骤构造方案：

1. **初始化支付**：令 $x_i = L_i$ ，计算剩余金额 $\text{remain} = p - \sum L_i$
2. **分配剩余金额**：
   - 对每个人，最多还能增加 $R_i - L_i$
   - 按照题目规则决定分配顺序：优先给能力高的人增加，能力相同则给序号小的人增加
   - 但要注意：增加后不能使差距超过 $D$
3. **处理平局**：按照题目要求，如果多人能力相同且当前支付相同，应让序号小的人支付更多

### 4. 实现技巧

- 使用结构体存储每个人的信息：序号、最大支付能力、当前支付金额
- 排序时使用自定义比较函数，实现题目要求的优先级
- 注意整数和浮点数的转换，避免精度误差

## 代码实现

```cpp
// Fair Division
// UVa ID: 12259
// Verdict: Accepted
// Submission Date: 2026-01-26
// UVa Run Time: 0.130s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net


#include <bits/stdc++.h>
using namespace std;

struct Person {
    int id;        // 原始顺序
    int maxPay;    // 最大支付能力
    int curPay;    // 当前支付
    
    Person(int i, int m) : id(i), maxPay(m), curPay(0) {}
};

// 检查是否存在方案使得最大差距不超过maxDiff
bool canAchieveDiff(int maxDiff, int p, int n, const vector<Person>& people, 
                   long long& minSum, long long& maxSum) {
    minSum = 0, maxSum = 0;
    double avg = (double)p / n;
    
    for (const auto& person : people) {
        // 理论支付区间 [avg - maxDiff, avg + maxDiff]
        int lower = (int)ceil(avg - maxDiff);
        int upper = (int)floor(avg + maxDiff);
        
        // 与能力限制取交集
        lower = max(lower, 0);
        upper = min(upper, person.maxPay);
        
        if (lower > upper) return false;
        
        minSum += lower;
        maxSum += upper;
    }
    
    return minSum <= p && p <= maxSum;
}

void solve() {
    int p, n;
    cin >> p >> n;
    
    vector<Person> people;
    long long totalMax = 0;
    for (int i = 0; i < n; i++) {
        int maxPay;
        cin >> maxPay;
        people.emplace_back(i, maxPay);
        totalMax += maxPay;
    }
    
    if (totalMax < p) {
        cout << "IMPOSSIBLE\n";
        return;
    }
    
    // 按规则要求的顺序排序：支付能力降序，id升序
    // 这样在分配时会优先分配能力高的人
    sort(people.begin(), people.end(), [](const Person& a, const Person& b) {
        if (a.maxPay != b.maxPay) return a.maxPay > b.maxPay;
        return a.id < b.id;
    });
    
    // 二分搜索最小的最大差距
    int left = 0, right = p;
    int bestDiff = p;
    
    while (left <= right) {
        int mid = (left + right) / 2;
        long long minSum, maxSum;
        
        if (canAchieveDiff(mid, p, n, people, minSum, maxSum)) {
            bestDiff = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    
    // 现在 bestDiff 是最小的最大差距
    // 我们需要构造字典序最小的方案
    
    // 先分配下限
    double avg = (double)p / n;
    vector<int> lower(n), upper(n);
    long long sumL = 0;
    
    for (int i = 0; i < n; i++) {
        lower[i] = max((int)ceil(avg - bestDiff), 0);
        lower[i] = min(lower[i], people[i].maxPay);
        
        upper[i] = min((int)floor(avg + bestDiff), people[i].maxPay);
        upper[i] = max(upper[i], 0);
        
        people[i].curPay = lower[i];
        sumL += lower[i];
    }
    
    // 还需要分配的金额
    int remain = p - sumL;
    
    // 按规则分配剩余金额：在允许范围内，让支付尽量均匀
    // 优先给能增加且增加后仍不超过上限的人
    while (remain > 0) {
        bool assigned = false;
        
        // 尝试让每个人的支付增加，但保持最大差距不变
        for (int i = 0; i < n && remain > 0; i++) {
            if (people[i].curPay < upper[i] && people[i].curPay < people[i].maxPay) {
                // 计算如果增加1，新的差距是否超过bestDiff
                int newPay = people[i].curPay + 1;
                double newDiff = abs(newPay - avg);
                
                if (newDiff <= bestDiff + 1e-9) {  // 考虑浮点误差
                    people[i].curPay++;
                    remain--;
                    assigned = true;
                }
            }
        }
        
        // 如果一轮分配后还有剩余，放宽条件
        if (!assigned && remain > 0) {
            // 给支付最少且有能力的人增加
            sort(people.begin(), people.end(), [](const Person& a, const Person& b) {
                if (a.curPay != b.curPay) return a.curPay < b.curPay;
                if (a.maxPay != b.maxPay) return a.maxPay > b.maxPay;
                return a.id < b.id;
            });
            
            for (auto& person : people) {
                if (person.curPay < person.maxPay && remain > 0) {
                    person.curPay++;
                    remain--;
                    break;
                }
            }
        }
    }
    
    // 按原始id排序输出
    sort(people.begin(), people.end(), [](const Person& a, const Person& b) {
        return a.id < b.id;
    });
    
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << people[i].curPay;
    }
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) solve();
    return 0;
}
```

## 复杂度分析

### 时间复杂度

1. **可行性检查**： $O(n)$
2. **二分搜索**： $O(\log p)$ 次迭代，每次 $O(n)$ ，共 $O(n \log p)$
3. **构造方案**：最坏情况下需要 $O(n^2)$ 次调整
4. **总复杂度**： $O(t \cdot (n \log p + n^2))$ ，对于 $t \le 100, n \le 100, p \le 10^6$ ，完全可接受

### 空间复杂度

- 主要存储 $n$ 个人的信息： $O(n)$
- 辅助数组： $O(n)$
- 总空间复杂度： $O(n)$

## 总结

本题是一个具有挑战性的公平分配问题，主要考察对多目标优化问题的理解和贪心算法的设计能力。关键点在于：

1. **理解题目要求的多级优化目标**：首先最小化最大差距，然后比较后续差距，形成字典序比较
2. **掌握二分搜索技巧**：用于确定最小可达到的最大差距
3. **实现复杂的排序规则**：按照能力高低和序号先后打破平局
4. **注意整数约束**：支付金额必须是整数，这增加了问题的离散性

通过二分确定差距上限，然后在允许范围内构造最优方案，是解决此类问题的通用思路。本题的难点在于实现细节，特别是平局处理部分的正确性。
