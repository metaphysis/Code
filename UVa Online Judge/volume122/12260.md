## 题目描述

$\texttt{Petra}$ 和 $\texttt{Jan}$ 收到 $n$ 个礼物，每个礼物对 $\texttt{Petra}$ 的价值为 $p_i$ ，对 $\texttt{Jan}$ 的价值为 $j_i$ 。两人轮流挑选礼物，通过抛硬币决定谁先开始。 $\texttt{Petra}$ 采用贪心策略：每次选择对自己价值 $p_i$ 最高的礼物，如果有多个礼物 $p_i$ 相同，则选择对 $\texttt{Jan}$ 价值 $j_i$ 最低的礼物。 $\texttt{Jan}$ 的策略则是最优化自己的总价值，并且在多个选择获得相同价值时，让 $\texttt{Petra}$ 的总价值尽可能大。

给定初始的抛硬币结果（谁先手）以及每个礼物对两人的价值，求最终两人各自获得的总价值（按各自的评估标准）。

## 输入格式

- 第一行：测试用例数量 $T$ （最多 $100$ 个）。
- 每个测试用例：
  - 一行：整数 $n$ （ $1 \le n \le 1000$ ），礼物数量。
  - 一行：字符串， $\texttt{Petra}$ 或 $\texttt{Jan}$ ，表示先手的人。
  - $n$ 行：每行两个整数 $p_i$ 和 $j_i$ （ $0 \le p_i, j_i \le 1000$ ），分别表示 $\texttt{Petra}$ 和 $\texttt{Jan}$ 对第 $i$ 个礼物的评估价值。

## 输出格式

每个测试用例输出一行，包含两个整数： $\texttt{Petra}$ 获得的总价值和 $\texttt{Jan}$ 获得的总价值。

## 题目分析

本题的关键在于理解两人的策略差异并设计合适的状态转移方程。

### 1. 策略分析

- **$\texttt{Petra}$ 的贪心策略**：她的选择顺序是固定的，总是选择当前剩余礼物中对自己价值最高（ $p$ 最大）的礼物， $p$ 相同时选对 $\texttt{Jan}$ 价值最低（ $j$ 最小）的礼物。因此，我们可以将所有礼物按照 $\texttt{Petra}$ 的优先级排序： $p$ 降序， $p$ 相同时 $j$ 升序。排序后， $\texttt{Petra}$ 总是从前往后依次选取礼物。
- **$\texttt{Jan}$ 的最优策略**： $\texttt{Jan}$ 知道 $\texttt{Petra}$ 的选取顺序，他可以在自己的回合中选择任意一个礼物，目标是在游戏结束时最大化自己的总价值，并且在多个最优方案中选择让 $\texttt{Petra}$ 总价值最大的那个。

### 2. 问题转化

由于 $\texttt{Petra}$ 的选取顺序固定，问题可以转化为：在排序后的礼物列表中， $\texttt{Jan}$ 可以选择“抢占”某些 $\texttt{Petra}$ 将要拿的礼物。具体来说，每个礼物有两个状态：被 $\texttt{Jan}$ 拿走或被 $\texttt{Petra}$ 拿走。

$\texttt{Jan}$ 的决策可以看作：对于排序后的第 $i$ 个礼物， $\texttt{Jan}$ 可以选择是否抢占它。如果抢占， $\texttt{Jan}$ 获得 $j_i$ 价值， $\texttt{Petra}$ 失去 $p_i$ 价值（因为她拿不到这个礼物了）；如果不抢占， $\texttt{Petra}$ 正常拿走该礼物，获得 $p_i$ 价值。

### 3. 动态规划设计

定义状态：
- $dp[i][k]$ ：考虑前 $i$ 个礼物， $\texttt{Jan}$ 抢占了 $k$ 个时， $\texttt{Jan}$ 能获得的最大总价值。
- $val[i][k]$ ：在上述情况下， $\texttt{Jan}$ 抢占的礼物的 $\texttt{Petra}$ 价值之和（即 $\texttt{Petra}$ 因此损失的价值）。

状态转移：
对于第 $i$ 个礼物（排序后）：
1. **$\texttt{Jan}$ 不抢占**： $\texttt{Petra}$ 拿走该礼物。此时 $\texttt{Jan}$ 的价值不变， $\texttt{Petra}$ 的损失不变。
   - $dp[i][k] = dp[i-1][k]$
   - $val[i][k] = val[i-1][k]$
2. **$\texttt{Jan}$ 抢占**： $\texttt{Jan}$ 拿走该礼物。此时 $\texttt{Jan}$ 的价值增加 $j_i$ ， $\texttt{Petra}$ 的损失增加 $p_i$ 。
   - $dp[i][k] = dp[i-1][k-1] + j_i$
   - $val[i][k] = val[i-1][k-1] + p_i$

决策时优先最大化 $dp[i][k]$ （ $\texttt{Jan}$ 的价值），如果 $dp[i][k]$ 相同，则选择 $val[i][k]$ 较小的方案（让 $\texttt{Petra}$ 损失更小，即 $\texttt{Petra}$ 最终价值更大）。

### 4. 先手影响

$\texttt{Jan}$ 最多能抢占的礼物数量取决于谁先手：
- **$\texttt{Petra}$ 先手**：两人轮流， $\texttt{Jan}$ 最多能抢占 $\lfloor n/2 \rfloor$ 个礼物。
- **$\texttt{Jan}$ 先手**： $\texttt{Jan}$ 可能多抢一个，最多能抢占 $\lceil n/2 \rceil$ 个礼物。

在动态规划过程中，对于前 $i$ 个礼物， $\texttt{Jan}$ 最多能抢占的数量 $num$ 为：
- $\texttt{Petra}$ 先手： $num = i/2$
- $\texttt{Jan}$ 先手： $num = (i+1)/2$

### 5. 结果计算

设所有礼物的 $\texttt{Petra}$ 价值总和为 $totalP$ 。在动态规划结束后，我们遍历所有可能的 $k$ （ $\texttt{Jan}$ 抢占的数量），找到 $dp[n][k]$ 最大的方案，如果多个方案 $dp[n][k]$ 相同，选择 $val[n][k]$ 最小的。

最终：
- $\texttt{Jan}$ 的总价值 = $dp[n][k]$
- $\texttt{Petra}$ 的总价值 = $totalP - val[n][k]$

## 时间复杂度

排序复杂度 $O(n \log n)$ ，动态规划状态数 $O(n^2)$ ，总时间复杂度 $O(n^2)$ ，在 $n \le 1000$ 时可行。

```cpp
// Free Goodies

#include <bits/stdc++.h>
using namespace std;

struct Candy {
    int p, j;
};

bool cmp(const Candy& a, const Candy& b) {
    if (a.p != b.p) return a.p > b.p;
    return a.j < b.j;
}

int main() {
    int t; cin >> t;
    while (t--) {
        int n; cin >> n;
        string first; cin >> first;
        vector<Candy> candies(n);
        int totalP = 0;
        
        for (int i = 0; i < n; i++) {
            cin >> candies[i].p >> candies[i].j;
            totalP += candies[i].p;
        }
        
        sort(candies.begin(), candies.end(), cmp);
        
        vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));
        vector<vector<int>> val(n + 1, vector<int>(n + 1, 0));
        
        for (int i = 1; i <= n; i++) {
            int num;
            if (first == "Petra") {
                num = i / 2;
            } else {
                num = (i + 1) / 2;
            }
            
            for (int j = 1; j <= num; j++) {
                dp[i][j] = dp[i - 1][j];
                val[i][j] = val[i - 1][j];
                
                int candJan = dp[i - 1][j - 1] + candies[i - 1].j;
                int candVal = val[i - 1][j - 1] + candies[i - 1].p;
                
                if (candJan > dp[i][j]) {
                    dp[i][j] = candJan;
                    val[i][j] = candVal;
                } else if (candJan == dp[i][j] && candVal < val[i][j]) {
                    val[i][j] = candVal;
                }
            }
        }
        
        int maxJan = 0, minVal = 0;
        int maxTake;
        if (first == "Petra") {
            maxTake = n / 2;
        } else {
            maxTake = (n + 1) / 2;
        }
        
        for (int j = 1; j <= maxTake; j++) {
            if (dp[n][j] > maxJan) {
                maxJan = dp[n][j];
                minVal = val[n][j];
            }
        }
        
        int petraVal = totalP - minVal;
        cout << petraVal << " " << maxJan << endl;
    }
    return 0;
}
```
