## 题目描述

在游戏中获得最高分后，你需要使用摇杆输入你的名字。屏幕初始显示一个仅由字符 `'A'` 组成的字符串，长度与目标名字相同。初始时第一个字母被选中。

**操作规则：**
- **垂直移动（向前/向后）** ：改变当前选中字母。向前移动变为字母表中的下一个字母，向后移动变为上一个字母。字母表是循环的，即 `'Z'` 之后是 `'A'` ， `'A'` 之前是 `'Z'` 。
- **水平移动（向左/向右）** ：改变选中的位置。向左移动选中左边一个字母，向右移动选中右边一个字母。选择位置也是循环的，即第一个字母左边是最后一个字母，最后一个字母右边是第一个字母。

**目标：** 计算将初始字符串（全 `'A'` ）转换为目标名字所需的最少摇杆移动次数。过程结束时选中哪个字母无关紧要。

**输入：** 第一行一个整数 $T$ （ $T \leq 100$ ），表示测试用例数量。之后每行一个字符串 $s$ （ $1 \leq |s| \leq 1000$ ），仅包含大写字母，表示目标名字。

**输出：** 每个测试用例输出一行，包含最少移动次数。

**样例输入：**
```
2
JEROEN
JAN
```
**样例输出：**
```
56
23
```

## 题目分析

本题的核心是将摇杆移动分为两部分：
1. **垂直移动次数** ：将每个字母从 `'A'` 修改为目标字母所需的最小步数。
2. **水平移动次数** ：在字符串中移动光标，访问所有需要修改的字母位置所需的最小步数。

总移动次数 = 垂直移动次数 + 水平移动次数。

### 垂直移动次数计算
对于每个字母 $c$ ，从 `'A'` 到 $c$ 的最小移动步数为：
$$
vertical(c) = \min(c - 'A', 26 - (c - 'A'))
$$
其中 $c - 'A'$ 表示字母 $c$ 在字母表中的索引（ `'A'` = 0, `'B'` = 1, ..., `'Z'` = 25）。

### 水平移动次数计算
水平移动的关键在于如何以最少的步数访问所有需要修改的位置（即目标字母不是 `'A'` 的位置）。字符串是循环的，光标可以从任意位置开始，向左或向右移动。

#### 基本策略
设字符串长度为 $n$ ，需要修改的位置集合为 $P = \{ i \mid s[i] \neq 'A' \}$ 。令 $first$ 为 $P$ 中的最小索引， $last$ 为 $P$ 中的最大索引。

1. **策略一：一直向右移动**  
   从位置 $0$ 出发，向右走到 $last$ ，移动步数为 $last$ 。

2. **策略二：一直向左移动**  
   从位置 $0$ 出发，向左走到 $first$ （通过循环），移动步数为 $n - first$ 。

3. **策略三：先向右后向左**  
   从位置 $0$ 出发，先向右走到某个位置 $i$ ，然后折返向左走到某个位置 $j$ （ $j > i$ ）。这种策略可以跳过中间的连续 `'A'` 段。移动步数为 $i \times 2 + (n - j)$ 。

4. **策略四：先向左后向右**  
   从位置 $0$ 出发，先向左走到某个位置 $i$ ，然后折返向右走到某个位置 $j$ （ $j < i$ ）。移动步数为 $(n - j) \times 2 + i$ 。

#### 连续 `'A'` 段的影响
连续 `'A'` 段的长度直接影响最优策略的选择：
- 如果连续 `'A'` 段很长，绕过它（使用策略三或四）可能比直接穿过更节省步数。
- 如果连续 `'A'` 段很短，直接穿过（策略一或二）可能更优。

因此，我们需要枚举所有可能的折返点 $i$ ，计算对应策略的移动步数，取最小值。

### 算法步骤
1. 计算垂直移动总次数。
2. 如果字符串全是 `'A'` ，水平移动次数为 $0$ ，直接返回垂直移动次数。
3. 找到第一个和最后一个非 `'A'` 的位置 $first$ 和 $last$ 。
4. 初始化最小水平移动步数为 $\min(last, n - first)$ 。
5. 枚举每个位置 $i$ 作为折返点：
   - 找到 $i$ 之后第一个非 `'A'` 的位置 $j$ 。
   - 计算策略三的步数： $i \times 2 + (n - j)$ 。
   - 计算策略四的步数： $(n - j) \times 2 + i$ 。
   - 更新最小步数。
6. 特殊处理开头和结尾的连续 `'A'` 段：
   - 如果开头有连续 `'A'` ，可以直接从结尾向左走，步数为 $n - startA$ ，其中 $startA$ 是开头连续 `'A'` 的长度。
   - 如果结尾有连续 `'A'` ，可以只走到最后一个非 `'A'` 位置，步数为 $last$ 。
7. 返回垂直移动次数 + 最小水平移动次数。

### 时间复杂度
- 垂直移动次数计算： $O(n)$ 。
- 水平移动次数计算：最坏情况下需要枚举每个位置 $i$ ，并对每个 $i$ 向后查找非 `'A'` 位置，总时间复杂度为 $O(n^2)$ 。
- 由于 $n \leq 1000$ ， $O(n^2)$ 的算法在可接受范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;

int calculateMinMoves(const string& name) {
    int n = name.size();
    // 1. 计算垂直移动总次数
    int verticalMoves = 0;
    for (char c : name) {
        int diff = c - 'A';
        verticalMoves += min(diff, 26 - diff);
    }
    // 2. 计算最小横向移动
    // 基本移动：从第一个走到最后一个非'A'
    int firstNonA = n, lastNonA = -1;
    for (int i = 0; i < n; ++i)
        if (name[i] != 'A') {
            firstNonA = min(firstNonA, i);
            lastNonA = max(lastNonA, i);
        }
    // 如果全是'A'，返回0
    if (firstNonA == n) return 0;
    // 初始最小移动次数
    int minMove = min(lastNonA, n - firstNonA);
    // 3. 枚举所有可能的折返策略
    // 关键思想：对于每个位置i，考虑以它为转折点
    for (int i = 0; i < n; ++i) {
        // 找到i之后第一个非'A'
        int j = i + 1;
        while (j < n && name[j] == 'A') j++;
        // 方案1: 先向右走到i，再向左走到j
        if (j < n) minMove = min(minMove, i * 2 + (n - j));
        // 方案2: 先向左走到i，再向右走到j
        // 注意：向左走到i相当于走到n-i位置（因为循环）
        if (j < n) minMove = min(minMove, (n - j) * 2 + i);
    }
    // 4. 特殊处理：连续A段在开头或结尾的情况
    // 计算开头连续A的长度
    int startA = 0;
    while (startA < n && name[startA] == 'A') startA++;
    // 如果开头有A，可以直接从结尾开始向左走
    if (startA > 0) minMove = min(minMove, n - startA);
    // 计算结尾连续A的长度
    int endA = 0;
    while (endA < n && name[n - 1 - endA] == 'A') endA++;
    // 如果结尾有A，可以少走到最后
    if (endA > 0) minMove = min(minMove, lastNonA);
    return verticalMoves + minMove;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        string name;
        cin >> name;
        cout << calculateMinMoves(name) << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于将问题分解为垂直移动和水平移动两部分，并重点解决水平移动的最小化问题。通过分析四种基本移动策略，并考虑连续 `'A'` 段的影响，我们可以通过枚举所有可能的折返点来找到全局最优解。算法的时间复杂度为 $O(n^2)$ ，对于 $n \leq 1000$ 的数据规模完全可行。
