## 题目描述

在 $\texttt{Absurdistan}$ 国家，土地被划分为单位方格，每个方格要么是草地（`.`），要么是沼泽（`#`）。$\texttt{Per}$ 拥有一块土地，他想将其部分或全部出售。该国的官僚机构有一个特殊的规定：

- 每次只能出售一个矩形区域
- 矩形内不能包含任何沼泽
- 土地的价格与矩形的周长成正比
- 每个矩形必须有一个唯一的东南角（右下角）坐标
- 矩形可以重叠，只要它们的东南角坐标不同

$\texttt{Per}$ 想知道，为了最大化利润，他需要出售多少块不同周长的土地。你需要输出每种周长对应的出售数量，按周长从小到大排序。

## 题目分析

### 问题转化

这个问题可以转化为：对于地图上的每个草地位置 $(i, j)$，找到以它为**右下角**的最大周长矩形（不包含沼泽），然后统计各个周长值的出现次数。

### 关键观察

1. **唯一性约束**：每个位置 $(i, j)$ 只能作为一个矩形的右下角
2. **周长最大化**：对于每个位置，我们选择以它为右下角的**最大周长**矩形
3. **重叠允许**：矩形可以重叠，这简化了问题，因为我们可以独立处理每个位置

### 暴力方法的局限性

最直接的方法是对于每个位置 $(i, j)$，向左扫描所有可能的左边界 $k$，计算矩形 $[k, j] \times [i-h+1, i]$ 的周长，其中 $h$ 是区间 $[k, j]$ 的最小高度。这种方法的时间复杂度为 $O(n \times m^2)$，对于 $n, m \leq 1000$ 来说太慢。

## 解题思路

### 单调栈优化

我们使用**单调栈**来高效维护候选矩形集合。算法的核心思想是：

对于每一行，我们维护一个栈，栈中存放的是"可能产生新周长的矩形"。每个栈元素包含两个信息：
- $\texttt{start}$：矩形的起始列
- $\texttt{height}$：矩形的高度

### 算法步骤

1. **预处理高度数组**：对于每个位置 $(i, j)$，计算从该位置向上连续的草地高度 $\texttt{height}[j]$

2. **逐行处理**：对于每一行 $i$：
   - 初始化空栈
   - 对于每一列 $j$：
     - 更新当前列的高度
     - 如果是沼泽，清空栈并跳过
     - 创建当前矩形 $(j, \texttt{height}[j])$
     - 维护单调栈：弹出所有高度 $\geq$ 当前高度的矩形
     - 根据潜力判断是否压入当前矩形
     - 统计栈顶矩形的半周长

3. **输出结果**：将半周长转换为实际周长并输出

### 关键技巧

#### 潜力比较条件

```cpp
if (top < 0 || cur.height - cur.start > stk[top].height - stk[top].start)
```

这里比较的是 $\texttt{height} - \texttt{start}$，这个值代表了矩形的"潜力"（如果矩形能无限向右延伸，它能达到的最大半周长）。

#### 统计时机

我们在处理每个列 $j$ 时统计当前栈顶矩形，因为栈顶矩形代表了以当前列 $j$ 为右边界的"最佳"矩形。

### 复杂度分析

- **时间复杂度**：$O(n \times m)$，每个元素入栈出栈一次
- **空间复杂度**：$O(m)$，用于存储高度数组和栈

## 代码实现

```cpp
// Selling Land
// UVa ID: 12265

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;

// 矩形结构体：start 表示起始列，height 表示矩形高度
struct rect { int start, height; };

int n, m;
char grid[MAXN][MAXN];    // 存储地图，'.' 表示草地，'#' 表示沼泽
int height[MAXN];         // 记录每列向上连续的草地高度
int answer[2 * MAXN];     // 统计半周长出现的次数，半周长 = 宽度 + 高度
rect stk[MAXN];           // 单调栈，用于维护候选矩形

void solve() {
    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> grid[i];
    
    // 初始化高度数组和答案数组
    memset(height, 0, sizeof(height));
    memset(answer, 0, sizeof(answer));
    
    // 逐行处理
    for (int i = 0; i < n; i++) {
        int top = -1;  // 栈顶指针，-1 表示栈空
        
        // 逐列处理当前行
        for (int j = 0; j < m; j++) {
            // 更新当前列的高度：如果是沼泽则重置为 0，否则高度加 1
            height[j] = (grid[i][j] == '#') ? 0 : height[j] + 1;
            
            // 如果当前是沼泽，清空栈并跳过
            if (grid[i][j] == '#') {
                top = -1;
                continue;
            }
            
            // 创建当前矩形：起始列为 j，高度为 height[j]
            rect cur{j, height[j]};
            
            // 维护单调栈：弹出所有高度大于等于当前高度的矩形
            // 同时更新当前矩形的起始列为弹出矩形的最左起始列
            while (top >= 0 && stk[top].height >= cur.height) cur.start = stk[top--].start;
            
            // 压栈条件：栈为空 或 当前矩形比栈顶矩形有更大潜力
            // 潜力计算公式：height - start，表示矩形可能达到的最大半周长
            if (top < 0 || cur.height - cur.start > stk[top].height - stk[top].start) stk[++top] = cur;
            
            // 统计当前栈顶矩形的半周长
            // 宽度 = 当前列 - 起始列 + 1
            // 半周长 = 宽度 + 高度
            int width = j - stk[top].start + 1;
            answer[width + stk[top].height]++;
        }
    }
    // 输出结果：将半周长转换为实际周长（乘以2）
    for (int i = 1; i <= n + m; i++)
        if (answer[i])
            cout << answer[i] << " x " << 2 * i << endl;
}

int main() {
    // 加速IO
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) solve();

    return 0;
}
```

## 总结

本题的难点在于如何高效地为每个位置找到以其为右下角的最大周长矩形。通过使用单调栈维护候选矩形集合，并结合巧妙的潜力比较条件，我们能够在 $O(n \times m)$ 的时间内解决问题。

这种方法的优势在于：
1. 避免了为每个位置单独计算最大矩形的重复工作
2. 利用栈的性质高效维护候选解
3. 通过潜力比较确保不会漏掉任何可能的更优解

该算法是解决此类"以每个位置为右下角的最大矩形"问题的经典方法，值得深入理解和掌握。
