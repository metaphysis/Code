## 题目描述

本题要求模拟一个简化的股票交易系统。在这个系统中，我们需要处理买入（$\texttt{buy}$）和卖出（$\texttt{sell}$）两种订单，并实时更新以下三种价格：

*   **卖出价（$\texttt{ask price}$）** ：当前所有未成交的卖出订单中的最低价格。如果有人愿意以更低的价格卖出，这个价格就会降低。
*   **买入价（$\texttt{bid price}$）** ：当前所有未成交的买入订单中的最高价格。如果有人愿意以更高的价格买入，这个价格就会升高。
*   **股票价格（$\texttt{stock price}$）** ：最近一次成功交易的价格。

**交易规则** ：当存在一个买入订单的最高出价（买入价）大于或等于一个卖出订单的最低要价（卖出价）时，交易就会发生。交易会匹配这两个订单，并以**卖出订单的价格（$\texttt{ask price}$）** 成交。成交数量为两个订单中较小的份额数。如果一个订单在部分成交后仍有剩余份额，它会被保留在订单簿中等待下一次匹配。

**任务** ：给定一系列按顺序到达的订单，在每处理完一个订单（并完成所有可能发生的即时交易）后，输出当前的卖出价、买入价和股票价格。如果某个价格在此时没有定义（例如，没有任何卖出订单时卖出价未定义），则输出 `-`。

## 题目分析与解题思路

这是一个典型的 **订单簿（$\texttt{Order Book}$）** 模拟问题。核心在于如何高效地维护两类订单集合（买入和卖出），并能在新订单到达时快速找到可匹配的对手订单进行交易。

### 关键点分析

1.  **订单的优先级** ：
    *   对于卖出订单，价格**越低**的优先级越高，因为买家总希望以更低的价格买入。因此，在所有卖出订单中，我们需要能**快速获取价格最低的订单**。
    *   对于买入订单，价格**越高**的优先级越高，因为卖家总希望以更高的价格卖出。因此，在所有买入订单中，我们需要能**快速获取价格最高的订单**。
    *   成交只发生在当前最高买入价 >= 当前最低卖出价时。

2.  **数据结构的选择** ：
    *   **优先队列（堆，$\texttt{Heap}$）** 是解决此问题的完美数据结构。它能保证我们始终在 $O(1)$ 时间内访问到队列中的极值元素，并在 $O(\log n)$ 时间内完成插入和删除操作。
    *   我们需要维护两个优先队列：
        *   `sellBook`（卖出订单簿）：一个小顶堆，堆顶元素是价格最低的卖出订单。
        *   `buyBook`（买入订单簿）：一个大顶堆，堆顶元素是价格最高的买入订单。

3.  **交易匹配的逻辑** ：
    1.  每当新订单被添加到对应的队列后，就需要检查是否满足交易条件：`buyBook.top().price >= sellBook.top().price`。
    2.  只要条件满足，就进行循环匹配：
        *   从两个队列中分别取出堆顶订单（当前最优的买入和卖出订单）。
        *   确定成交数量 `tradeShares = min(buyOrder.shares, sellOrder.shares)`。
        *   更新**最后一次成交价格** `lastDealPrice` 为卖出订单的价格（根据题目规则）。
        *   分别减少两个订单的份额数。
        *   如果某个订单份额仍有剩余，则将其重新放回对应的优先队列。
    3.  循环继续，直到没有订单可以匹配为止。

4.  **输出处理** ：
    *   每次匹配循环结束后，当前的状态就是处理完第 $i$ 个订单后的最终状态。
    *   卖出价 `askPrice`：如果 `sellBook` 为空则未定义，否则为 `sellBook.top().price`。
    *   买入价 `bidPrice`：如果 `buyBook` 为空则未定义，否则为 `buyBook.top().price`。
    *   股票价 `stockPrice`：即 `lastDealPrice`，如果没有发生过交易则未定义。

### 算法流程

1.  读取测试用例数量 $T$。
2.  对每个测试用例：
    1.  读取订单数量 $n$。
    2.  初始化空的 `sellBook`（小顶堆）、`buyBook`（大顶堆）和 `lastDealPrice = -1`。
    3.  循环处理 $n$ 个订单：
        *   读取订单类型、份额 `shares` 和价格 `price`。
        *   根据订单类型将其加入对应的优先队列。
        *   **执行交易匹配循环**（如上所述）。
        *   根据当前两个优先队列的状态和 `lastDealPrice` 输出一行结果。
3.  处理所有测试用例后结束。

**时间复杂度** ：每个订单最多进入和离开优先队列一次，每次操作是 $O(\log n)$，因此总时间复杂度约为 $O(n \log n)$，对于 $n \leq 1000$ 的数据范围完全足够。
**空间复杂度** ：$O(n)$，用于存储未成交的订单。

```cpp
// Stock Prices

#include <bits/stdc++.h>
using namespace std;

// 定义订单结构体
struct Order {
    int shares; // 订单份额
    int price;  // 订单价格
};

// 比较器：用于卖出订单簿（小顶堆，价格低的优先）
struct SellCompare {
    bool operator()(const Order& a, const Order& b) const {
        return a.price > b.price; // 注意：优先队列默认是大顶堆，用大于号实现小顶堆
    }
};

// 比较器：用于买入订单簿（大顶堆，价格高的优先）
struct BuyCompare {
    bool operator()(const Order& a, const Order& b) const {
        return a.price < b.price; // 默认就是大顶堆比较方式
    }
};

// 处理单个测试用例
void processTestCase() {
    int n;
    cin >> n;
    // 卖出订单簿（小顶堆）
    priority_queue<Order, vector<Order>, SellCompare> sellBook;
    // 买入订单簿（大顶堆）
    priority_queue<Order, vector<Order>, BuyCompare> buyBook;
    int lastDealPrice = -1; // 最后一次成交价，初始未定义

    for (int i = 0; i < n; ++i) {
        string type, dummy1, dummy2; // dummy1 和 dummy2 用于读取 "shares at"
        int shares, price;
        cin >> type >> shares >> dummy1 >> dummy2 >> price;

        // 将新订单加入对应的订单簿
        if (type == "buy") {
            buyBook.push({shares, price});
        } else { // type == "sell"
            sellBook.push({shares, price});
        }

        // 核心：检查并执行所有可能的交易
        while (!buyBook.empty() && !sellBook.empty() && buyBook.top().price >= sellBook.top().price) {
            // 取出当前最优的买入和卖出订单
            Order buyOrder = buyBook.top(); buyBook.pop();
            Order sellOrder = sellBook.top(); sellBook.pop();

            // 计算成交数量
            int tradeShares = min(buyOrder.shares, sellOrder.shares);
            // 更新最后一次成交价格为卖出价
            lastDealPrice = sellOrder.price;

            // 更新订单剩余份额
            buyOrder.shares -= tradeShares;
            sellOrder.shares -= tradeShares;

            // 如果订单还有剩余，重新放回订单簿
            if (buyOrder.shares > 0) buyBook.push(buyOrder);
            if (sellOrder.shares > 0) sellBook.push(sellOrder);
        }

        // 输出处理完当前订单后的状态
        // 当前卖出价：卖出订单簿顶部的价格（若无则 -1）
        int askPrice = sellBook.empty() ? -1 : sellBook.top().price;
        // 当前买入价：买入订单簿顶部的价格（若无则 -1）
        int bidPrice = buyBook.empty() ? -1 : buyBook.top().price;

        // 格式化输出
        if (askPrice == -1) cout << "- ";
        else cout << askPrice << " ";

        if (bidPrice == -1) cout << "- ";
        else cout << bidPrice << " ";

        if (lastDealPrice == -1) cout << "-\n";
        else cout << lastDealPrice << "\n";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) processTestCase();
    return 0;
}
```
