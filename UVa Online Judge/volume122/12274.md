## 题目描述

你是一名猎人在森林中追捕一只猴子，试图用全自动机枪射中它。猴子躲在某棵树的枝叶后面，你看不到它。你可以瞄准一棵树射击；如果你的子弹穿过枝叶且猴子恰好在树上，猴子会立即被杀死。如果不在，猴子会利用你重新装填的时间跳到相邻的树上（你不会注意到）。开枪后猴子永远不会留在原地。你需要判断是否存在一种策略，无论猴子的初始位置和后续跳跃如何，都能保证捕获它。如果存在，需要确定保证捕获的最短射击序列。

## 输入格式

输入包含多个测试用例，用空行分隔。每个测试用例首行包含两个整数 $n$ 和 $m$ $(1 \leq n \leq 21)$； $n$ 是森林中树的数量， $m$ 是树之间的相邻关系数。接下来的 $m$ 行每行包含两个不同的整数（在 $0$ 到 $n-1$ 之间，包含端点），表示一对相邻的树。一对树中两个树的顺序没有意义，且没有重复的对。你可以进一步假设没有树与自身相邻，并且森林中任意两棵树之间总是存在路径。

测试用例以一行包含两个零结束（前面也有空行）。

## 输出格式

对于每个测试用例，打印一行。如果任务不可能完成，则该行应包含单词 `Impossible` 。否则，它必须包含具有所需属性的最短射击序列，格式为 $L: V_1 V_2 \ldots V_L$ ，其中 $L$ 是序列的长度，而 $V_1, V_2, \ldots, V_L$ 是按正确顺序射击的树的标识符，用空格分隔。如果存在多个最短序列，则打印字典序最小的序列。

```
0 1
```


## 问题分析

这是一个经典的确定性追捕问题，需要找到一种射击策略，无论猴子如何移动，都能保证最终被击中。问题的关键在于理解猴子的移动规律和猎人的射击策略之间的相互作用。

### 核心观察

1. **猴子必须移动**：每次射击后，如果猴子没有被击中，它必须跳到相邻的树上，不能停留在原地。
2. **状态表示**：我们可以用一个二进制掩码来表示猴子当前可能的位置集合。初始时，猴子可能在任意树上，所以状态为全 $1$（所有位都置为 $1$）。
3. **状态转移**：当猎人射击树 $i$ 时：
   - 如果猴子在树 $i$ 上，则被击中，该可能性被消除
   - 如果猴子在树 $j$（$j \neq i$）上，则它会跳到树 $j$ 的所有邻居上
4. **目标状态**：状态 $0$ 表示猴子不可能在任何树上（已被捕获）

### 关键性质

我们发现了一个重要性质：**只有当图是无环图（即树或森林）时，问题才有解**。如果图中存在环，则无法保证捕获猴子。

**为什么有环时无解？**
当图中存在环时，猴子可以沿着环的某个方向不断跳跃，始终避开猎人的射击。考虑一个简单的三角形环（三个节点相互连接），无论猎人射击哪个节点，猴子总有两个可能的位置，可以永远避免被击中。

**为什么树结构有解？**
对于树结构，我们可以从叶子节点开始，逐渐缩小猴子可能的位置范围。由于树没有环，我们可以找到一种射击顺序，确保每次射击都能减少猴子可能的位置集合，最终将其缩小为空集。

### 算法思路

#### 1. 环检测
使用并查集（$\texttt{Union-Find}$）检测图中是否存在环：
- 初始化每个节点为自己的父节点
- 对于每条边 $(u, v)$，如果 $u$ 和 $v$ 已经在同一连通分量中，则添加这条边会形成环
- 如果检测到环，直接输出 `Impossible`

#### 2. 状态压缩 $\texttt{BFS}$
如果图是无环的，使用 $\texttt{BFS}$ 搜索最短射击序列：

- **状态定义**：$dp[mask]$ 表示从状态 $mask$ 到捕获猴子所需的最短射击次数
- **初始状态**：$mask = (1 \ll n) - 1$（所有树都可能）
- **目标状态**：$mask = 0$（猴子不可能在任何树上）
- **状态转移**：对于当前状态 $mask$，尝试射击树 $i$（要求 $i$ 在 $mask$ 中）：
  $$
  newMask = \bigcup_{j \in mask, j \neq i} \text{neighbors}(j)
  $$
  其中 $\text{neighbors}(j)$ 表示树 $j$ 的所有邻居
- **$\texttt{BFS}$ 搜索**：从初始状态开始 $\texttt{BFS}$，直到找到目标状态
- **路径记录**：记录每个状态的前驱状态和射击的树，用于重建射击序列

#### 3. 字典序最小序列
由于 $\texttt{BFS}$ 按节点编号从小到大的顺序尝试射击，且 $\texttt{BFS}$ 保证找到的是最短路径，因此当找到目标状态时，重建的序列自然就是字典序最小的最短序列。

### 算法复杂度分析

- **状态数**：最多 $2^n$ 个状态，$n \leq 21$，最多约 $2^{21} \approx 2.1 \times 10^6$ 个状态
- **每个状态的转移**：最多尝试 $n$ 种射击，每种射击计算新状态需要 $O(n)$ 时间
- **总时间复杂度**：$O(2^n \times n^2)$，在 $n=21$ 时约为 $2.1 \times 10^6 \times 441 \approx 9.3 \times 10^8$ 次操作
- **空间复杂度**：$O(2^n)$ 存储 $dp$ 数组和前驱信息

虽然理论复杂度较高，但由于实际访问的状态数远少于理论最大值，且 $\texttt{BFS}$ 在找到解后立即终止，该算法在实际测试中可以通过。

### 代码实现

```cpp
// Jumping Monkey
// UVa ID: 12274
// Verdict: Accepted
// Submission Date: 2026-01-03
// UVa Run Time: 0.280s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 21;

int n, m;
int neighborMask[MAXN];  // 每个节点的邻居掩码

// 并查集
int parent[MAXN];
int findSet(int x) {
    return parent[x] == x ? x : parent[x] = findSet(parent[x]);
}
bool unionSet(int x, int y) {
    x = findSet(x);
    y = findSet(y);
    if (x == y) return false;  // 已经连通，有环
    parent[x] = y;
    return true;
}

// BFS求解
void solve() {
    int fullMask = (1 << n) - 1;
    // dp[mask] = 最小步数，-1表示未访问
    vector<int> dp(1 << n, -1);
    // link[mask][0] = 前驱状态，link[mask][1] = 射击的树
    vector<pair<int, int>> link(1 << n);
    queue<int> q;
    dp[fullMask] = 0;
    q.push(fullMask);
    while (!q.empty()) {
        int mask = q.front(); q.pop();
        int steps = dp[mask];
        // 尝试射击每个可能的目标
        for (int i = 0; i < n; i++) {
            if (!(mask & (1 << i))) continue;  // 猴子不可能在i上
            // 计算新状态
            int newMask = 0;
            for (int j = 0; j < n; j++)
                if (mask & (1 << j))
                    if (j != i)
                        newMask |= neighborMask[j]; // 猴子从j跳到所有邻居
            if (dp[newMask] == -1) {
                dp[newMask] = steps + 1;
                link[newMask] = {mask, i};
                if (newMask == 0) {
                    // 找到解，输出
                    cout << dp[newMask] << ":";
                    stack<int> path;
                    int current = newMask;
                    while (current != fullMask) {
                        path.push(link[current].second);
                        current = link[current].first;
                    }
                    while (!path.empty()) {
                        cout << ' ' << path.top();
                        path.pop();
                    }
                    cout << '\n';
                    return;
                }
                q.push(newMask);
            }
        }
    }
    // 没有找到解
    cout << "Impossible\n";
}

int main() {
    while (cin >> n >> m, n) {
        // 初始化
        for (int i = 0; i < n; i++) {
            neighborMask[i] = 0;
            parent[i] = i;
        }
        bool hasCycle = false;
        // 读入图
        for (int i = 0; i < m; i++) {
            int a, b;
            cin >> a >> b;
            neighborMask[a] |= (1 << b);
            neighborMask[b] |= (1 << a);
            // 检测是否有环
            if (!unionSet(a, b)) hasCycle = true;
        }
        // 特殊情况：只有一棵树
        if (n == 1) {
            cout << "1: 0\n";
            continue;
        }
        // 如果有环，不可能
        if (hasCycle) {
            cout << "Impossible\n";
            continue;
        }
        // 否则求解
        solve();
    }
    return 0;
}
```

### 代码说明

1. **数据结构**：
   - `neighborMask[i]`：用位掩码表示树 $i$ 的所有邻居
   - `parent[i]`：并查集的父节点数组
   - `dp[mask]`：从状态 $mask$ 到目标状态的最短步数
   - `link[mask]`：记录状态 $mask$ 的前驱状态和射击的树

2. **主要函数**：
   - `findSet(x)`：并查集的查找操作，带路径压缩
   - `unionSet(x, y)`：并查集的合并操作，返回 `false` 表示检测到环
   - `solve()`：执行 $\texttt{BFS}$ 搜索最短射击序列

3. **算法流程**：
   - 读取输入，构建邻接关系
   - 使用并查集检测图中是否有环
   - 如果有环，输出 `Impossible`
   - 否则，执行 $\texttt{BFS}$ 搜索
   - 找到解后，使用栈反向重建射击序列并输出

### 样例解析

#### 样例 1
```
2 1
0 1
```
图是两棵树相连（无环）。$\texttt{BFS}$ 找到的最短序列是射击两次树 $0$，输出 `2: 0 0`。

#### 样例 2
```
3 3
0 1
1 2
2 0
```
这是一个三角形环（有环），直接输出 `Impossible`。

#### 样例 3
```
4 3
0 1
2 3

```
这是一个无环图。$\texttt{BFS}$ 找到的最短序列是 `1 3 3 1`，长度为 $4$。

### 总结

本题的关键在于理解图的结构对问题可解性的影响：
1. 有环图：猴子可以永远躲避，问题无解
2. 无环图：存在保证捕获的策略

通过状态压缩 $\texttt{BFS}$，我们可以找到最短的射击序列。算法的时间复杂度虽然理论较高，但由于状态空间的特殊性和 $\texttt{BFS}$ 的提前终止，在实际测试中可以高效运行。

对于 $n \leq 21$ 的限制，状态压缩是可行的，因为状态数为 $2^{21} \approx 2.1 \times 10^6$，在现代计算机上可以接受。
