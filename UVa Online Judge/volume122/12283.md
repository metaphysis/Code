## 题目描述

$\texttt{Gappu}$ 即将迎来一个忙碌的周末，因为下周末是万圣节，他计划参加尽可能多的派对。这些派对都是化妆舞会，$\texttt{Gappu}$ 会根据不同的派对选择相应的服装。例如，参加漫画迷朋友举办的派对时，他会穿超人服装；而参加比赛伙伴举办的派对时，他会穿"中国邮递员"服装。

由于他要参加多个派对，需要多次更换服装。为了方便，他可以将服装一件套在另一件外面（比如在超人服装外面穿上邮递员制服）。在每次派对前，他可以脱掉一些服装或穿上新服装。

**重要约束条件：**
- 脱掉的服装不能再次使用（因为他不穿未清洗的服装）
- 脱服装时必须从外到内依次脱掉
- 可以随时在外面穿上新服装

给定派对序列和每个派对需要的服装类型，求 $\texttt{Gappu}$ 需要的最小服装数量。

## 输入格式

- 第一行：$T$ ($T \leq 2500$)，测试用例数量
- 每个测试用例：
  - 第一行：$N$ 和 $M$ ($1 \leq N, M \leq 100$)，派对数量和服装类型数
  - 第二行：$N$ 个整数 $c_i$ ($1 \leq c_i \leq M$)，表示每个派对需要的服装类型
  - 测试用例间用空行分隔

## 输出格式

对于每个测试用例，输出 `Case i: x`，其中 $x$ 是最小需要的服装数量。

## 解题思路

### 问题分析

这是一个典型的**区间动态规划**问题。关键在于理解服装的叠穿规则和重复利用的可能性。

**核心观察：**
- 如果同一件服装在多个派对上需要，$\texttt{Gappu}$ 可以在第一次穿上后保持不脱，直到最后一次使用
- 脱衣服必须从外到内，这意味着服装的穿着顺序很重要
- 脱掉的服装不能重复使用，因此需要精心规划穿衣策略

### 动态规划定义

定义 $dp[i][j]$ 表示参加第 $i$ 到第 $j$ 个派对所需的最小服装数量。

### 状态转移方程

1. **基础情况**：对于单个派对，至少需要 $1$ 件服装
   $$
   dp[i][i] = 1
   $$

2. **一般情况**：考虑区间 $[i, j]$
   - **选项 $1$**：为第 $i$ 个派对穿新服装，然后处理剩下的派对
     $$
     dp[i][j] = dp[i+1][j] + 1
     $$
   
   - **选项 $2$**：如果在 $[i+1, j]$ 中存在位置 $k$，使得第 $i$ 个派对和第 $k$ 个派对需要相同的服装，那么可以：
     - 在第 $i$ 个派对穿上该服装
     - 保持不脱直到第 $k$ 个派对
     - 这样第 $k$ 个派对就不需要新服装
     $$
     dp[i][j] = \min(dp[i][j], dp[i][k-1] + dp[k+1][j])
     $$

**$\texttt{DP}$ 计算过程：**
- $dp[0][2] = \min(dp[1][2] + 1, dp[0][1] + dp[3][2])$
- $dp[1][2] = 2$（两个不同服装）
- $dp[0][1] = 2$（两个不同服装）
- 当 $k=2$ 时，$costume[0] = costume[2] = 1$
- $dp[0][2] = \min(3, 2 + 0) = 2$

### 时间复杂度分析

算法使用三重循环：
- 外层循环：区间长度 $O(N)$
- 中层循环：区间起点 $O(N)$
- 内层循环：分割点 $O(N)$

总时间复杂度：$O(N^3)$，在 $N \leq 100$ 时完全可行。

```cpp
// Halloween Costumes

#include <bits/stdc++.h>
using namespace std;

int main() {
	int t;
	cin >> t;
	for (int caseNum = 1; caseNum <= t; caseNum++) {
		int n, m;
		cin >> n >> m;
		vector<int> costume(n);
		for (int i = 0; i < n; i++) cin >> costume[i];
		vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));
		for (int i = 0; i < n; i++) dp[i][i] = 1;
		for (int len = 2; len <= n; len++)
			for (int i = 0; i + len <= n; i++) {
				int j = i + len - 1;
				dp[i][j] = dp[i + 1][j] + 1;
				for (int k = i + 1; k <= j; k++)
					if (costume[i] == costume[k])
						dp[i][j] = min(dp[i][j], dp[i][k - 1] + dp[k + 1][j]);
			}
		cout << "Case " << caseNum << ": " << dp[0][n - 1] << '\n';
	}
	return 0;
}
```

## 总结

本题通过区间动态规划巧妙地解决了服装叠穿和重复利用的问题。关键在于识别出当同一件服装在多个派对上需要时，可以通过保持不脱来节省服装数量。这种思路在很多区间优化问题中都有应用，是动态规划中一个经典的技巧。
