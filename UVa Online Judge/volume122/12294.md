## 题目描述

在典型的 $\texttt{RPG}$ 游戏中，玩家按顺序与 $n$ 场敌人战斗，每场战斗结束后会获得两种药水：力量药水和双倍药水。力量药水使当前力量值增加 $1$，双倍药水使当前力量值翻倍。玩家可以在任意战斗前使用已获得的药水（战斗中不可使用），目标是最小化完成所有战斗的总时间。

每场战斗由六个参数描述：$p_1$、$p_2$、$t_1$、$t_2$、$w_1$、$w_2$。设进入该战斗时的力量值为 $x$，则战斗时间计算方式如下：

- 若 $x < p_1$，玩家被击败（无法继续）。
- 若 $x > p_2$，战斗时间为 $t_2$。
- 若 $p_1 \le x \le p_2$，战斗时间从 $t_1$ 线性递减到 $t_2$：

$$
\textit{time} = t_1 - (t_1 - t_2) \times \frac{x - p_1}{p_2 - p_1}
$$

战斗胜利后，玩家获得 $w_1$ 瓶力量药水和 $w_2$ 瓶双倍药水，可以留到以后的战斗前使用。药水可以任意顺序使用，但最优策略总是先使用所有力量药水再进行翻倍（因为加法满足交换律且翻倍会放大加法的效果）。

## 输入格式

输入包含至多 $25$ 个测试用例。每个测试用例的第一行包含两个整数 $n$ 和 $p$，分别表示战斗场数和初始力量值。接下来 $n$ 行，每行六个整数 $p_1$、$p_2$、$t_1$、$t_2$、$w_1$、$w_2$，含义如上所述。输入以 `n = p = 0` 结束，该行不作处理。

数据范围：

- $1 \le n \le 1000$
- $1 \le p \le 100$
- $1 \le p_1 < p_2 \le 100$
- $1 \le t_2 < t_1 \le 100$
- $0 \le w_1, w_2 \le 10$

## 输出格式

对于每个测试用例，输出完成所有战斗的最短总时间，保留两位小数。如果无法通过所有战斗，输出 `Impossible`。

## 题目分析

本题是一个典型的**顺序决策问题**，且具有动态规划的子结构性质。每个阶段（战斗）的决策包括：在进入本场战斗前，从已获得的药水中选择若干瓶使用，以改变当前力量值，从而影响本场战斗时间和后续状态。战斗结束后获得的新药水会累积到库存中，供后续使用。

直接模拟所有药水使用方案是不可行的。每场战斗结束后最多获得 $10$ 瓶力量药水和 $10$ 瓶双倍药水，$n$ 最大为 $1000$，若将库存数量作为状态维度，状态数会爆炸。

但是我们可以利用问题的两个关键性质进行大幅剪枝：

1. **力量上限**：$p_2 \le 100$，当力量超过 $100$ 时，战斗时间恒为 $t_2$，再大的力量不会进一步减少时间。因此我们只需关心力量值在 $[1, 100]$ 的范围，超过 $100$ 的可统一视为 $100$。
2. **双倍药水上限**：初始力量最小为 $1$，翻 $k$ 次后的力量为 $2^k$，要超过 $100$ 只需要 $k \ge 7$（因为 $2^7 = 128 > 100$）。因此任何战斗中，最多使用 $7$ 瓶双倍药水即可达到力量上限，多余的翻倍药水是浪费的，可以丢弃。

力量药水则不同：它每次只增加 $1$，且加法与乘法交换后，最优策略一定是先使用力量药水再翻倍。因此力量药水可以在获得后**立即使用**，不需要存入状态，这样状态中就只需记录当前力量值和剩余的双倍药水瓶数。

## 解题思路

### 状态定义

设 $\textit{dp}[i][\textit{power}][d]$ 表示**完成前 $i$ 场战斗后**，当前力量值为 $\textit{power}$，且库存中还有 $d$ 瓶双倍药水（未使用）时的最小总时间。

- $0 \le i \le n$
- $1 \le \textit{power} \le 100$
- $0 \le d \le 7$

初始状态：$\textit{dp}[0][p][0] = 0$，其余为无穷大。

### 状态转移

考虑从状态 $\textit{dp}[i][\textit{powerPrev}][dPrev]$ 转移到第 $i+1$ 场战斗。

1. **使用双倍药水**：从库存中取出 $b$ 瓶双倍药水（$0 \le b \le dPrev$），翻倍 $b$ 次后的力量值为：
$$
   \textit{powerBefore} = \textit{powerPrev} \times 2^b
$$
   若中途超过 $100$，则直接截断为 $100$。

2. **计算战斗时间**：根据 $\textit{powerBefore}$ 和该场战斗的参数，按线性插值公式计算战斗时间 $t$。若 $\textit{powerBefore} < p_1$，则无法胜利，跳过该转移。

3. **使用力量药水**：战斗胜利后获得 $w_1$ 瓶力量药水，立即全部使用，力量变为：
$$
   \textit{powerAfter} = \min(100,\ \textit{powerBefore} + w_1)
$$

4. **更新双倍药水库存**：原有库存减去使用掉的 $b$ 瓶，再加上本场获得的 $w_2$ 瓶，并截断到上限 $7$：
$$
   dAfter = \min(7,\ dPrev - b + w_2)
$$

5. **更新 $\texttt{DP}$ 值**：
$$
   \textit{dp}[i+1][\textit{powerAfter}][dAfter] = \min(\textit{dp}[i+1][\textit{powerAfter}][dAfter],\ \textit{dp}[i][\textit{powerPrev}][dPrev] + t)
$$

### 最终答案

完成所有 $n$ 场战斗后，答案即为：
$$
\min_{\textit{power}, d} \textit{dp}[n][\textit{power}][d]
$$
若该最小值为无穷大，则输出 `Impossible`。

### 复杂度分析

- 状态总数：$n \times 100 \times 8 = O(800n)$。
- 每个状态转移需要枚举 $b$（$0$ 到 $7$），即常数 $O(8)$。
- 总复杂度：$O(n \times 800 \times 8) = O(6400n)$，当 $n \le 1000$ 时约为 $6.4 \times 10^6$ 次操作，非常高效。

## 代码实现

```cpp
// RPG Battles
// UVa ID: 12294
// Verdict: Accepted
// Submission Date: 2026-06-05
// UVa Run Time: 0.050s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const double INF = 1e20;
const int MAX_POWER = 100;
const int MAX_DOUBLE = 7;

struct Battle {
    int p1, p2, t1, t2, w1, w2;
};

double battleTime(int power, const Battle& b) {
    if (power < b.p1) return INF;
    if (power > b.p2) return b.t2;
    return b.t1 - (b.t1 - b.t2) * (power - b.p1) / (double)(b.p2 - b.p1);
}

int main() {
    int n, p;
    while (cin >> n >> p && (n || p)) {
        vector<Battle> battles(n);
        for (int i = 0; i < n; ++i) 
            cin >> battles[i].p1 >> battles[i].p2 >> battles[i].t1 >> battles[i].t2 >> battles[i].w1 >> battles[i].w2;

        // dp[战斗场次][力量][双倍药水数] = 最小时间
        vector<vector<vector<double>>> dp(n + 1, vector<vector<double>>(MAX_POWER + 1, vector<double>(MAX_DOUBLE + 1, INF)));
        dp[0][min(p, MAX_POWER)][0] = 0.0;

        for (int i = 0; i < n; ++i) {
            const Battle& b = battles[i];
            for (int powerPrev = 1; powerPrev <= MAX_POWER; ++powerPrev) {
                for (int dPrev = 0; dPrev <= MAX_DOUBLE; ++dPrev) {
                    if (dp[i][powerPrev][dPrev] >= INF) continue;

                    // 尝试使用 bUsed 瓶双倍药水（0 ≤ bUsed ≤ dPrev）
                    for (int bUsed = 0; bUsed <= dPrev; ++bUsed) {
                        // 计算使用 bUsed 瓶双倍药水后的力量
                        int powerBefore = powerPrev;
                        for (int k = 0; k < bUsed; ++k) {
                            powerBefore *= 2;
                            if (powerBefore > MAX_POWER) {
                                powerBefore = MAX_POWER;
                                break;
                            }
                        }

                        double timeCost = battleTime(powerBefore, b);
                        if (timeCost >= INF) continue;

                        // 战斗后立即用掉所有力量药水（加法无损失）
                        int powerAfter = powerBefore + b.w1;
                        if (powerAfter > MAX_POWER) powerAfter = MAX_POWER;

                        // 剩余双倍药水 = 之前剩余的(dPrev - bUsed) + 新获得的b.w2
                        int dAfter = dPrev - bUsed + b.w2;
                        if (dAfter > MAX_DOUBLE) dAfter = MAX_DOUBLE;

                        dp[i + 1][powerAfter][dAfter] = min(dp[i + 1][powerAfter][dAfter], dp[i][powerPrev][dPrev] + timeCost);
                    }
                }
            }
        }

        double ans = INF;
        for (int power = 1; power <= MAX_POWER; ++power)
            for (int d = 0; d <= MAX_DOUBLE; ++d)
                ans = min(ans, dp[n][power][d]);

        if (ans >= INF) cout << "Impossible" << endl;
        else printf("%.2f\n", ans);
    }
    return 0;
}
```

## 总结

本题的关键技巧在于：

- **状态压缩**：利用力量值上限 $100$ 和双倍药水有效数量上限 $7$ 大幅缩减状态空间。
- **贪心简化**：力量药水可立即使用，避免将其纳入状态。
- **线性插值**：战斗时间公式直接实现，注意浮点数计算精度。
- **边界处理**：力量超过 $100$ 时截断，药水超过 $7$ 时丢弃。

这类“顺序决策 + 资源累积”的问题，通常需要寻找有效的状态上界进行剪枝，否则状态空间会指数级增长。本题的剪枝思路具有一般性：**当资源的效果存在饱和上限时，可以大胆截断超过上限的部分**。
