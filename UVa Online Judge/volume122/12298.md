## 题目分析

### 问题描述

我们有一套"超级扑克"牌，包含所有**合数**（$\texttt{composite number}$）的正整数。每个合数有四种花色：黑桃（$S$）、红心（$H$）、梅花（$C$）、方块（$D$）。合数的定义是大于 $1$ 且不是质数的正整数。

题目要求：从四种花色中各选一张牌（数值必须为合数），使得四张牌的数值之和等于给定的 $n$。但是有些牌丢失了，这些牌不能使用。

输入包含多个测试用例，每个测试用例给出：
- $a$, $b$, $c$：需要计算 $n = a, a+1, \ldots, b$ 的答案，$c$ 是丢失的牌的数量
- $c$ 张丢失的牌，格式如 `4S`、`6H` 等

要求输出从 $n = a$ 到 $n = b$ 的每个 $n$ 对应的方案数。

### 数据范围

- 最多 $25$ 个测试用例
- 最多一个测试用例满足 $a = 1$, $b = 50000$, $c \leq 10000$
- 其他测试用例满足 $1 \leq a \leq b \leq 100$, $0 \leq c \leq 10$

## 解题思路

### 方法选择

本题可以使用两种方法解决：

1. **快速傅里叶变换（$\texttt{FFT}$）** 或 **数论变换（$\texttt{NTT}$）**：将问题转化为多项式乘法，时间复杂度 $O(b \log b)$
2. **动态规划（$\texttt{DP}$）**：直接计数，时间复杂度 $O(4 \times b^2)$

虽然 $\texttt{FFT/NTT}$ 在理论复杂度上更优，但考虑到实现复杂度和精度问题，我们选择更直观的动态规划解法。

### 动态规划思路

我们定义状态：
- $dp[i][j]$：使用前 $i$ 种花色，凑出总和 $j$ 的方案数

状态转移采用"先加后减"的策略：

1. **初始假设**：假设所有数（包括质数）都可以使用
2. **修正非法情况**：减去使用了质数或丢失牌的方案

具体步骤：
- 对于第 $i$ 种花色，先计算前 $i-1$ 种花色的前缀和
- 初始时假设所有数值都可以用：$dp[i][j] = \sum_{k=0}^{j-1} dp[i-1][k]$
- 然后对于每个数值 $val$：
  - 如果 $val$ 是质数：减去所有包含 $val$ 的方案
  - 如果 $val$ 对应的牌丢失：减去所有包含 $val$ 的方案

### 算法正确性

这种"先加后减"的方法确保了：
- 所有合法的方案（只使用合数且不使用丢失牌）都被正确计数
- 不会重复计数或漏计数
- 时间复杂度为 $O(4 \times b^2)$，在 $b = 50000$ 时虽然理论较慢，但实际常数小且实现简单

// Super Poker II

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAX_B = 50000;

bool isComposite[MAX_B + 10];  // 标记合数，true 表示是合数
bool isLost[5][MAX_B + 10];    // 标记丢失的牌，isLost[i][j] 表示第 i 种花色数值 j 的牌是否丢失
ll dp[5][MAX_B + 10];          // dp[i][j] 表示前 i 种花色凑出总和 j 的方案数
ll prefixSum[MAX_B + 10];      // 前缀和数组

// 筛法预处理合数
void sieve() {
    memset(isComposite, 0, sizeof(isComposite));
    // 标记合数
    for (int i = 2; i * i <= MAX_B; i++) {
        if (!isComposite[i]) {
            for (int j = i * i; j <= MAX_B; j += i) {
                isComposite[j] = true;
            }
        }
    }
    // 1 不是合数
    isComposite[1] = false;
}

int main() {
    sieve();
    
    int start, end, lostCount;
    while (scanf("%d%d%d", &start, &end, &lostCount) && (start || end || lostCount)) {
        // 初始化
        memset(isLost, 0, sizeof(isLost));
        memset(dp, 0, sizeof(dp));
        
        // 花色映射表
        int suitMap[256] = {0};
        suitMap['S'] = 1;
        suitMap['H'] = 2; 
        suitMap['C'] = 3;
        suitMap['D'] = 4;
        
        // 读取丢失的牌
        while (lostCount--) {
            char inputStr[20];
            scanf("%s", inputStr);
            int value = 0, index = 0;
            // 解析数值部分
            while (inputStr[index] >= '0' && inputStr[index] <= '9') {
                value = value * 10 + (inputStr[index] - '0');
                index++;
            }
            // 解析花色
            int suit = suitMap[inputStr[index]];
            if (value <= end) {
                isLost[suit][value] = true;
            }
        }
        
        // 动态规划初始化
        dp[0][0] = 1;
        
        // 对每种花色进行动态规划
        for (int suit = 1; suit <= 4; suit++) {
            // 计算前一种花色的前缀和
            prefixSum[0] = dp[suit - 1][0];
            for (int j = 1; j <= end; j++) {
                prefixSum[j] = prefixSum[j - 1] + dp[suit - 1][j];
            }
            
            // 初始假设：所有数都可以使用
            for (int j = suit; j <= end; j++) {
                dp[suit][j] = prefixSum[j - 1];
            }
            
            // 修正：减去使用质数或丢失牌的方案
            for (int value = 1; value <= end; value++) {
                // 如果是质数或者牌丢失
                if (!isComposite[value] || isLost[suit][value]) {
                    // 从大到小更新，避免重复计算
                    for (int k = end; k >= value; k--) {
                        dp[suit][k] -= dp[suit - 1][k - value];
                    }
                }
            }
        }
        
        // 输出结果
        for (int n = start; n <= end; n++) {
            printf("%lld\n", dp[4][n]);
        }
        printf("\n");
    }
    
    return 0;
}
