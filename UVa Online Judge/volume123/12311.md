[UVa 12311 All-Pair Farthest Points](https://blog.csdn.net/metaphysis/article/details/154114800)

## 题目描述

给定一个二维平面上的**凸多边形**，顶点按**逆时针顺序**给出。  对于每个顶点 $i$，找出离它**最远**的顶点 $j$（欧几里得距离）。  如果存在多个相同距离的顶点，则输出**编号最小**的那个。  顶点编号从 $1$ 到 $n$。

**输入格式**  
- 最多 $10$ 组测试数据。
- 每组数据第一行是 $n$（$3 \leq n \leq 30000$）。
- 接下来 $n$ 行，每行两个整数 $x, y$（$0 \leq x, y \leq 10^8$），表示顶点坐标。
- 输入以 $n = 0$ 结束。

**输出格式**  
- 对于每个测试数据，输出 $n$ 行，第 $i$ 行是顶点 $i$ 的最远顶点编号。

---

## 题目分析

### 1. 问题性质

对于凸多边形，有一个重要性质：

> 对于每个顶点 $i$，其最远顶点 $p(i)$ 在顶点序列中随着 $i$ 的逆时针移动，$p(i)$ 也是**逆时针单调移动**的。

这意味着我们可以利用**单调性**来优化查找过程，而不需要对每个顶点都做 $O(n)$ 的扫描。

---

### 2. 暴力做法与复杂度

最直接的方法是：  
对每个顶点 $i$，枚举所有其他顶点 $j$，计算距离并比较。  
这样时间复杂度为 $O(n^2)$，当 $n = 30000$ 时，计算量约为 $9 \times 10^8$，会超时。

---

### 3. 优化思路

利用上述单调性，我们可以使用**分治法**来求解：

- 设 $idx[i]$ 表示顶点 $i$ 的最远顶点索引（在扩展后的数组中的位置）。
- 已知 $idx[L]$ 和 $idx[R]$ 的范围，可以确定中间点 $M$ 的最远点一定在 $[idx[L], idx[R]]$ 之间。
- 这样递归下去，每个区间的最远点候选范围会大大缩小。

为了处理环形结构，我们将顶点数组复制一份接在后面，形成一个长度为 $2n$ 的数组，这样就将环形问题转化为线性问题。

---

### 4. 算法步骤

1. 读入 $n$ 个顶点坐标。
2. 将顶点数组复制一份，形成长度为 $2n$ 的数组。
3. 调用分治函数 $\texttt{dfs}(0, n-1, 0, 2n-1)$：
   - $\texttt{left}, \texttt{right}$：当前处理的原始顶点区间。
   - $\texttt{low}, \texttt{high}$：当前区间对应的最远点候选范围。
   - 对中间点 $\texttt{middle}$，在 $[\texttt{low}, \texttt{high}]$ 中寻找最远点。
   - 递归处理左右子区间，并缩小候选范围。
4. 输出结果时，将索引取模 $n$ 并转换为以 $1$ 为起点的编号。

## 参考代码

```cpp
// All-Pair Farthest Points
// UVa ID: 12311
// Verdict: Accepted
// Submission Date: 2020-06-29
// UVa Run Time: 0.050s
//
// 版权所有（C）2020，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>

using namespace std;

int n, idx[30010];
double px[100000], py[100000];

// 计算顶点 i 和 j 的平方距离（避免开方）
// 如果 j 超出有效范围（距离超过半圈），返回 0
double f(int i, int j)
{
    if (j >= i + n || j < i) return 0;
    return pow(px[i] - px[j], 2) + pow(py[i] - py[j], 2);
}

// 分治函数：在原始顶点区间 [left, right] 中，最远点候选范围在 [low, high] 内
void dfs(int left, int right, int low, int high)
{
    int middle = (left + right) / 2;
    idx[middle] = low;  // 初始候选最远点为 low
    double d1, d2;
    
    // 在候选范围内寻找最远点
    for (int i = low + 1; i <= high; i++)
    {
        d1 = f(middle, i);
        d2 = f(middle, idx[middle]);
        // 如果距离更大，或距离相等但编号更小，则更新
        if (d1 > d2 || (d1 == d2 && (i % n) < (idx[middle] % n)))
            idx[middle] = i;
    }
    
    // 递归处理左右子区间
    if (left < right)
    {
        // 左区间 [left, middle - 1] 的候选范围是 [low, idx[middle]]
        dfs(left, middle - 1, low, idx[middle]);
        // 右区间 [middle + 1, right] 的候选范围是 [idx[middle], high]
        dfs(middle + 1, right, idx[middle], high);
    }
}

int main(int argc, char *argv[])
{
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);

    while (cin >> n, n > 0)
    {
        for (int i = 0; i < n; i++)
        {
            cin >> px[i] >> py[i];
            // 复制一份顶点，形成两倍数组，方便处理环形
            px[n + i] = px[i];
            py[n + i] = py[i];
        }
        
        // 分治求解
        dfs(0, n - 1, 0, 2 * n - 1);
        
        // 输出结果，转换为 1-based 编号
        for (int i = 0; i < n; i++)
            cout << idx[i] % n + 1 << '\n';
    }

    return 0;
}
```

## 总结

本题的关键在于利用**凸多边形最远点的单调性**，结合**分治法**将复杂度从 $O(n^2)$ 优化到 $O(n \log n)$。  通过**复制顶点数组**化环为链，简化了环形结构的处理。  代码实现简洁高效，适合作为凸多边形经典问题的练习。
