## 题目描述

$\texttt{Eloi}$ 来到北半球与祖母一起过冬，并学习缝扣子的手艺。他发现了一个有趣的数学问题：给定 $k$ 种不同颜色的扣子，其中第 $i$ 种颜色有 $n_i$ 个，要将 $m$ 个扣子分配到 $m$ 个不同的扣眼上（每个扣眼放一个扣子），问有多少种不同的分配方案。

**输入格式**：
- 多组测试数据，每组数据：
  - 第一行：两个整数 $m$ 和 $k$ ($1 \le m \le 50$, $1 \le k \le 50$)
  - 接下来 $k$ 行：每行一个整数 $n_i$ ($1 \le n_i \le 50$)
- 输入以 `0 0` 结束

**输出格式**：
- 每组数据一行：分配方案数

**样例输入**：
```
1 3
3
1
1
3 2
4
2
3 2
1
1
0 0
```

**样例输出**：
```
3
7
0
```

## 题目分析

这是一个**有重复元素的排列组合**问题，具体来说：

1. **扣眼有区别**：$m$ 个扣眼是不同的位置，因此顺序重要。
2. **扣子颜色有区别**：不同颜色的扣子视为不同的种类。
3. **同色扣子无区别**：相同颜色的扣子之间不可区分。
4. **数量限制**：每种颜色的扣子有数量限制 $n_i$。

我们需要从 $k$ 种颜色的扣子中选出 $m$ 个（满足数量限制），然后排列到 $m$ 个不同的扣眼上。

## 解题思路

### 数学模型

设我们选择 $x_i$ 个第 $i$ 种颜色的扣子，其中 $0 \le x_i \le n_i$，且 $\sum_{i=1}^k x_i = m$。

对于一组固定的 $(x_1, x_2, \dots, x_k)$，将这 $m$ 个扣子排列到 $m$ 个扣眼上的方案数是一个**多重集排列数**：

$$
\frac{m!}{x_1! x_2! \cdots x_k!}
$$

总方案数就是所有满足条件的 $(x_1, \dots, x_k)$ 对应的多重集排列数之和：

$$
\text{答案} = \sum_{\substack{0 \le x_i \le n_i \\ \sum x_i = m}} \frac{m!}{x_1! x_2! \cdots x_k!}
$$

### 动态规划解法

直接枚举所有可能的 $(x_1, \dots, x_k)$ 组合（最多 $51^k$ 种）不可行。我们可以使用动态规划。

定义状态 $dp[i][t]$：考虑前 $i$ 种颜色，选择了 $t$ 个扣子，这些扣子排列在 $t$ 个位置上的方案数。

**状态转移**：
- 假设我们已经处理了前 $i-1$ 种颜色，选了 $t$ 个扣子（已有排列方案 $dp[i-1][t]$）。
- 现在考虑第 $i$ 种颜色，我们可以从中选择 $j$ 个扣子，其中 $0 \le j \le \min(n_i, m-t)$。
- 当我们新增 $j$ 个同色扣子时，需要将这 $j$ 个相同的扣子插入到已有的 $t$ 个扣子中。
- 这相当于在 $t+j$ 个位置中选出 $j$ 个位置给新扣子，方案数为组合数 $C(t+j, j)$。

因此转移方程为：

$$
dp[i][t+j] = \sum_{j=0}^{\min(n_i, m-t)} dp[i-1][t] \times C(t+j, j)
$$

**初始状态**：
- $dp[0][0] = 1$（空排列）
- 其他为 $0$

**最终答案**：$dp[k][m]$

### 空间优化

注意到 $dp[i]$ 只依赖于 $dp[i-1]$，我们可以使用滚动数组优化空间，只保留一维数组 $dp[t]$。

### 高精度需求

由于 $m \le 50$，方案数可能非常大（最大约为 $50! \approx 3 \times 10^{64}$），远超 $64$ 位整数范围，因此需要实现**高精度整数运算**。

```cpp
// Sewing Buttons with Grandma

#include <bits/stdc++.h>
using namespace std;

class BigInt {
private:
    vector<int> digits;
    static const int BASE = 10000;
    static const int WIDTH = 4;
    
public:
    BigInt() : digits(1, 0) {}
    BigInt(long long num) {
        if (num == 0) digits.push_back(0);
        while (num > 0) {
            digits.push_back(num % BASE);
            num /= BASE;
        }
    }
    
    bool isZero() const { return digits.size() == 1 && digits[0] == 0; }
    
    void trim() {
        while (digits.size() > 1 && digits.back() == 0) digits.pop_back();
    }
    
    BigInt operator+(const BigInt& other) const {
        BigInt res;
        res.digits.clear();
        int carry = 0;
        int maxSize = max(digits.size(), other.digits.size());
        for (int i = 0; i < maxSize || carry; i++) {
            if (i == res.digits.size()) res.digits.push_back(0);
            int sum = carry + res.digits[i];
            if (i < digits.size()) sum += digits[i];
            if (i < other.digits.size()) sum += other.digits[i];
            res.digits[i] = sum % BASE;
            carry = sum / BASE;
        }
        return res;
    }
    
    BigInt operator*(const BigInt& other) const {
        if (isZero() || other.isZero()) return BigInt(0);
        BigInt res(0);
        vector<long long> temp(digits.size() + other.digits.size(), 0);
        for (int i = 0; i < digits.size(); i++)
            for (int j = 0; j < other.digits.size(); j++)
                temp[i + j] += 1LL * digits[i] * other.digits[j];
        long long carry = 0;
        for (int i = 0; i < temp.size(); i++) {
            carry += temp[i];
            if (i < res.digits.size()) res.digits[i] = carry % BASE;
            else res.digits.push_back(carry % BASE);
            carry /= BASE;
        }
        while (carry) {
            res.digits.push_back(carry % BASE);
            carry /= BASE;
        }
        res.trim();
        return res;
    }
    
    friend ostream& operator<<(ostream& os, const BigInt& num) {
        os << num.digits.back();
        for (int i = (int)num.digits.size() - 2; i >= 0; i--)
            os << setw(WIDTH) << setfill('0') << num.digits[i];
        return os;
    }
};

BigInt comb[55][55];
void initComb() {
    comb[0][0] = BigInt(1);
    for (int i = 1; i < 55; i++) {
        comb[i][0] = comb[i][i] = BigInt(1);
        for (int j = 1; j < i; j++) comb[i][j] = comb[i - 1][j - 1] + comb[i - 1][j];
    }
}

int main() {
    initComb();
    int m, k;
    while (cin >> m >> k and (m != 0 or k != 0)) {
        vector<int> n(k);
        for (int i = 0; i < k; i++) cin >> n[i];
        vector<BigInt> dp(m + 1, BigInt(0));
        dp[0] = BigInt(1);
        for (int i = 0; i < k; i++) {
            vector<BigInt> newDp(m + 1, BigInt(0));
            for (int used = 0; used <= m; used++) {
                if (dp[used].isZero()) continue;
                int maxJ = min(n[i], m - used);
                for (int j = 0; j <= maxJ; j++)
                    newDp[used + j] = newDp[used + j] + (dp[used] * comb[used + j][j]);
            }
            dp = newDp;
        }
        cout << dp[m] << endl;
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(k \cdot m^2 \cdot L)$，其中 $L$ 是高精度整数的位数。对于 $m \le 50$，实际运行速度很快。
- **空间复杂度**：$O(m \cdot L)$，主要是存储动态规划状态和高精度数。

## 总结

本题的关键在于：
1. 识别问题为**有重复元素的多重集排列**。
2. 使用动态规划避免指数级枚举。
3. 正确推导状态转移方程中的组合数 $C(t+j, j)$。
4. 实现高精度整数运算处理大数。

通过将组合数学与动态规划结合，并配合高精度运算，可以高效解决这类组合计数问题。
