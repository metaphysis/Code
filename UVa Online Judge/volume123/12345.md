[UVa 12345 Dynamic len(set(a[L:R]))](https://blog.csdn.net/metaphysis/article/details/153462917)

## 题目描述

给定一个长度为 $n$ 的数组 $a$，需要支持两种操作：

- $\texttt{M x y}$：将 $a[x]$ 修改为 $y$
- $\texttt{Q x y}$：查询区间 $[x, y)$ 内不同数值的个数（即 $\texttt{len(set(a[x:y]))}$）

其中 $1 \leq n, m \leq 50000$，数组元素的值在 $[1, 10^6]$ 范围内。

## 题目分析

这是一个典型的**动态区间不同数个数**问题，需要在支持单点修改的情况下快速回答区间不同数值的查询。

### 暴力方法的局限性

最直接的方法是对于每个查询，遍历区间 $[x, y)$ 并用哈希表统计不同数值：
- 查询时间复杂度：$O(n)$
- 修改时间复杂度：$O(1)$
- 总复杂度：$O(n \times m)$，对于 $n, m \leq 50000$ 会超时

### 带修莫队算法

**带修莫队**（$\texttt{Mo's algorithm with updates}$）是解决此类问题的有效方法，它将时间也作为一维进行考虑。

#### 算法核心思想

1. **分块处理**：将数组分成大小为 $sn = n^{2/3}$ 的块
2. **三维排序**：对查询按照以下优先级排序：
   - 左端点所在的块
   - 右端点所在的块  
   - 时间戳（修改操作的顺序）
3. **奇偶排序优化**：对于右端点，奇数块内右端点递增，偶数块内右端点递减，减少指针移动

#### 复杂度分析

- 块大小：$sn = n^{2/3}$
- 时间复杂度：$O(n^{5/3})$
- 对于 $n = 50000$，$50000^{5/3} \approx 1.4 \times 10^8$，在优化良好的情况下可以通过

#### 关键操作

- $\texttt{add(x)}$：将数值 $x$ 加入当前区间，更新不同数计数
- $\texttt{del(x)}$：将数值 $x$ 移出当前区间，更新不同数计数
- 指针移动：按顺序调整左、右、时间指针，保持数据一致性

## 参考代码

```cpp
// Dynamic len(set(a[L:R]))
// UVa ID: 12345
// Verdict: Accepted
// Submission Date: 2025-10-17
// UVa Run Time: 0.150s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int M = 50005;
int n, m, sn, a[M], bL[M], t[M*20], l, r, ans[M], AMS, p, q;
char s[5];

// 查询结构体：x-左端点, y-右端点, z-时间戳, id-查询编号
struct node { int x, y, z, id; } A[M], B[M];

// 带修莫队排序函数
bool cmp(node a, node b) {
    if (bL[a.x] == bL[b.x]) {  // 左端点在同一块
        if (bL[a.y] == bL[b.y]) // 右端点在同一块
            return bL[a.y] & 1 ? a.z > b.z : a.z < b.z;  // 奇偶排序优化
        return bL[a.x] & 1 ? a.y < b.y : a.y > b.y;  // 奇偶排序优化
    }
    return a.x < b.x;  // 按左端点所在块排序
}

// 添加元素到当前区间
void add(int x) { if (!t[x]++) ++AMS; }

// 从当前区间删除元素
void del(int x) { if (!--t[x]) --AMS; }

int main() {
    scanf("%d%d", &n, &m);
    sn = pow(n, 2.0 / 3);  // 计算块大小
    // 预处理每个位置所在的块
    for (int i = 1; i <= n; i++) {
        bL[i] = (i - 1) / sn + 1;
        scanf("%d", &a[i]);
    }
    
    // 读入操作
    for (int i = 1; i <= m; i++) {
        int x, y;
        scanf("%s%d%d", s, &x, &y);
        if (s[0] == 'Q') {  // 查询操作
            ++q;
            A[q] = {x + 1, y, p, q};  // 转换为1-indexed，区间[x+1, y]
        } else {  // 修改操作
            ++p;
            B[p] = {x + 1, a[x + 1], y, p};  // 记录修改信息
            a[x + 1] = y;  // 直接应用修改
        }
    }
    
    // 恢复初始数组状态
    for (int i = p; i >= 1; i--) a[B[i].x] = B[i].y;
    
    // 对查询排序
    sort(A + 1, A + q + 1, cmp);
    l = 1; r = 0; p = 0;  // 初始化指针
    
    // 处理每个查询
    for (int i = 1; i <= q; i++) {
        // 调整右指针
        while (r < A[i].y) add(a[++r]);
        while (l > A[i].x) add(a[--l]);
        while (r > A[i].y) del(a[r--]);
        while (l < A[i].x) del(a[l++]);
        
        // 调整时间指针（应用修改）
        while (p < A[i].z) {
            ++p;
            if (l <= B[p].x && B[p].x <= r) {  // 修改位置在当前区间内
                del(a[B[p].x]);  // 删除旧值
                a[B[p].x] = B[p].z;  // 应用修改
                add(a[B[p].x]);  // 添加新值
            } else {
                a[B[p].x] = B[p].z;  // 直接修改，不影响当前统计
            }
        }
        // 调整时间指针（回滚修改）
        while (p > A[i].z) {
            if (l <= B[p].x && B[p].x <= r) {  // 修改位置在当前区间内
                del(a[B[p].x]);  // 删除当前值
                a[B[p].x] = B[p].y;  // 恢复旧值
                add(a[B[p].x]);  // 添加旧值
            } else {
                a[B[p].x] = B[p].y;  // 直接恢复，不影响当前统计
            }
            --p;
        }
        
        // 记录答案
        ans[A[i].id] = AMS;
    }
    
    // 输出所有查询结果
    for (int i = 1; i <= q; i++) printf("%d\n", ans[i]);
    return 0;
}
```

## 算法特点

1. **高效性**：通过分块和奇偶排序优化，将复杂度从 $O(n^2)$ 降低到 $O(n^{5/3})$
2. **离线处理**：所有查询一次性处理，利用排序优化访问模式
3. **空间优化**：使用数组而非复杂数据结构，减少常数因子
4. **实用性**：对于 $n, m \leq 50000$ 的数据规模具有很好的实际效果

## 总结

带修莫队算法巧妙地将时间维度引入莫队算法，使得能够处理带修改的区间查询问题。通过合理选择块大小和优化排序策略，可以在较大的数据规模下获得良好的性能表现。这种算法思想也可以推广到其他需要支持修改的区间查询问题中。
