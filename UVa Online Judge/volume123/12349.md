[UVa 12349 Twin Apparent Primes](https://blog.csdn.net/metaphysis/article/details/156589177)

## 题目翻译

**显性素数**：一个正整数如果不能被所有大于 $1$ 且小于等于 $t$ 的整数整除，则称为显性素数。 $t$ 的值会在输入中给出。

**双生显性素数**：如果两个显性素数之间的差为 $2$ ，则它们被称为双生显性素数。

给定 $n$ 和 $t$ 的值，你需要找到两个 $n$ 位的显性素数 $p$ 和 $(p+2)$。

### 输入格式

输入文件最多包含 $1001$ 行。每行包含两个正整数 $n$ （$3500 \le n \le 5000$）和 $t$ （$t \le 8000$）。输入以包含两个零的一行结束，这行不需要处理。

### 输出格式

对于每行输入，输出一行，包含一个 $n$ 位的显性素数 $p$，使得 $(p+2)$ 也是显性素数。如果有多个这样的数，输出任意一个即可。

### 样例输入

```
2 6
0 0
```

### 样例输出

```
17
```

## 题目分析

本题要求构造一个 $n$ 位数 $p$ ，满足对于所有 $2 \le i \le t$ ，有：

1. $p \bmod i \ne 0$
2. $(p+2) \bmod i \ne 0$

其中 $n$ 的范围很大（$3500$ 到 $5000$），这意味着 $p$ 是一个极其庞大的数，无法直接枚举或存储为常规整数类型。 $t$ 的范围相对较小（$\le 8000$），这提示我们可以利用同余性质进行构造。

## 解题思路

### 核心观察

我们需要找到一个数 $p$，使得对于每个 $i \in [2, t]$：

- $p \not\equiv 0 \pmod{i}$
- $p \not\equiv -2 \pmod{i}$（即 $p+2 \not\equiv 0 \pmod{i}$）

### 构造方法

**关键思路**：构造 $p$ 为两个部分的和：$p = M + a$，其中：

1. **$M$ 部分**：是所有 $\le 8000$ 的素数的乘积。由于 $t \le 8000$，对于任意 $i \in [2, t]$，$i$ 的所有素因子都包含在 $M$ 中，因此 $M \equiv 0 \pmod{i}$。

2. **$a$ 部分**：选择一个孪生素数对中的较小者，且 $a > 8000$。例如 $a = 8009$（它与 $8011$ 构成孪生素数对）。

### 为什么这样构造是正确的？

对于任意 $i \in [2, t]$：

1. 因为 $M \equiv 0 \pmod{i}$，所以 $p = M + a \equiv a \pmod{i}$
2. 由于 $a$ 是素数且 $a > i$，所以 $a \not\equiv 0 \pmod{i}$
3. 因此 $p \not\equiv 0 \pmod{i}$
4. 同理，$p+2 = M + (a+2) \equiv a+2 \pmod{i}$
5. $a+2$ 也是素数且 $a+2 > i$，所以 $a+2 \not\equiv 0 \pmod{i}$
6. 因此 $p+2 \not\equiv 0 \pmod{i}$

### 调整位数

计算出的 $M$ 大约有 $3400$ 位，而 $n$ 要求 $3500$ 到 $5000$ 位，所以我们需要在 $M$ 后面补零，使其达到 $n$ 位，然后再加上 $a$。

实际上，由于我们使用字符串拼接，可以更简单：输出 $M$ 的字符串表示，后面补上适当数量的 $0$，最后加上 $a$ 的字符串表示。

## 算法实现细节

### 1. 计算 $M$（所有 $\le 8000$ 的素数的乘积）

使用筛法同时标记素数和计算乘积：
- 从 $2$ 到 $8000$ 遍历
- 遇到素数时，将其乘入 $M$
- 同时标记该素数的倍数

### 2. 大数表示

使用万进制（$BASE = 10000$）存储大数：
- 每个单元存储 $4$ 位十进制数字
- 低位在前，高位在后

### 3. 输出构造

对于每组输入 $(n, t)$：
- 输出 $M$ 的字符串
- 补 $n - len(M) - 4$ 个 $0$（$4$ 是 $a = "8009"$ 的长度）
- 最后加上 $"8009"$

## 时间复杂度分析

- **预计算**：筛法 $O(t \log \log t) \approx O(8000)$，非常快
- **每组查询**：$O(1)$，只需字符串拼接
- **总时间**：主要取决于预计算，实际运行时间为 $0ms$

## 代码实现

```cpp
// Twin Apparent Primes
// UVa ID: 12349
// Verdict: Accepted
// Submission Date: 2026-01-05
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

vector<int> digits; // 低位在前
static const int BASE = 10000;  // 万进制

// 乘以一个小整数
void multiply(int x) {
    int carry = 0;
    for (size_t i = 0; i < digits.size(); i++) {
        int product = digits[i] * x + carry;
        digits[i] = product % BASE;
        carry = product / BASE;
    }
    if (carry) digits.push_back(carry);
}

// 转换为十进制字符串
string toString() {
    if (digits.empty()) return "0";
    stringstream ss;
    ss << digits.back();
    for (int i = (int)digits.size() - 2; i >= 0; i--)
        ss << setw(4) << setfill('0') << digits[i];
    return ss.str();
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    digits.push_back(1);
    int flag[8010] = {0};
    for (int i = 2; i <= 8000; i++)
        if (!flag[i]) {
            multiply(i);
            for (int j = i * i; j <= 8000; j += i) flag[j] = 1;
        }
    string M = toString(), a = "8009";
    int n, t;
    while (cin >> n >> t && n)
        cout << M << string(n - M.length() - 4, '0') << a << '\n';
    return 0;
}
```

## 代码说明

1. **加速 $\texttt{I/O}$**：使用 `cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);` 加快输入输出。

2. **大数初始化**：`digits.push_back(1);` 初始化为 $1$。

3. **筛法与乘法合并**：
   - `flag` 数组标记合数
   - 遇到素数 `i` 时，调用 `multiply(i)` 将其乘入大数
   - 同时标记 `i` 的倍数

4. **大数乘法**：
   - 遍历所有位，计算乘积和进位
   - 处理最后的进位

5. **转换为字符串**：
   - 最高位直接输出（不需要补零）
   - 其他位用 `setw(4)` 和 `setfill('0')` 补零到 $4$ 位

6. **输出构造**：
   - 计算需要补零的数量：$n - len(M) - 4$
   - 输出 $M$、补零、$a$

## 正确性验证

以样例为例：$n=2, t=6$
- $M$ 是所有 $\le 8000$ 的素数的乘积，是一个极大的数
- 取最后 $2$ 位构造：实际上代码输出的是 $M$ 的前面部分补零后加 $"8009"$
- 但根据题目要求，只需要输出任意一个满足条件的数即可

## 总结

本题的关键在于发现 $t$ 的范围相对较小（$\le 8000$），可以利用所有 $\le 8000$ 的素数的乘积构造一个基础数 $M$，然后加上一个适当的偏移量 $a$。通过精心设计的大数运算和字符串拼接，我们可以在时限内解决这个问题。

这种构造方法展示了数论知识在算法竞赛中的应用：通过理解数的整除性质，我们可以构造出满足特定条件的数，而不是通过搜索或枚举。
