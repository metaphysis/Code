[UVa 12355 Consecutive Sums](https://blog.csdn.net/metaphysis/article/details/161161487)

## 题目描述

给定一个正整数 $q$，求有多少个正整数 $p$，使得存在某个整数 $a$（可正可负），满足：从 $a$ 开始的连续 $p$ 个整数之和，等于接下来的连续 $q$ 个正整数之和。

形式化地说，求满足下式的 $p>0$ 的个数：

$$
\sum_{k=0}^{p-1} (a+k) = \sum_{k=p}^{p+q-1} (a+k)
$$

其中右边 $\sum_{k=p}^{p+q-1} (a+k)$ 的每一项都必须是正整数（即 $a+p>0$），左边可以是任意整数（包括负数和零）。

## 输入格式

输入包含至多 $1500$ 行，每行一个正整数 $q < 10^{14}$，以一行单独的 $0$ 结束。

## 输出格式

对每个 $q$，输出一行一个整数，表示满足条件的 $p$ 的个数。

## 样例分析

**输入**
```
5
1
0
```

**输出**
```
6
2
```

对于 $q=5$，有 $6$ 个 $p$ 满足条件：$p=6,7,10,15,30,55$。  
对于 $q=1$，有 $2$ 个 $p$ 满足条件：$p=2,3$。

## 题目分析

### 第一步：代数推导

设左边 $p$ 个数的首项为 $a$，则左边和为：

$$
S_L = pa + \frac{p(p-1)}{2}
$$

右边 $q$ 个数的首项为 $a+p$，和为：

$$
S_R = q(a+p) + \frac{q(q-1)}{2}
$$

令 $S_L = S_R$，得：

$$
pa + \frac{p(p-1)}{2} = qa + qp + \frac{q(q-1)}{2}
$$

移项整理：

$$
(p-q)a = qp + \frac{q(q-1) - p(p-1)}{2}
$$

设 $d = p - q$，则 $p = q + d$，代入得：

$$
d \cdot a = \frac{2q^2 - d^2 + d}{2}
$$

解得：

$$
a = \frac{2q^2 - d(d-1)}{2d}
$$

### 第二步：整数条件

$a$ 必须是整数。由上式知，$2d$ 必须整除分子 $2q^2 - d^2 + d$，即：

$$
2d \mid (2q^2 - d^2 + d)
$$

这等价于两个条件：

1. $d \mid 2q^2$（因为 $d \mid d^2$，所以 $d \mid 2q^2 - d^2 + d \iff d \mid 2q^2$）
2. $\frac{2q^2}{d} - d + 1$ 是偶数

条件 2 等价于 $\frac{2q^2}{d}$ 与 $d$ 的奇偶性不同。

### 第三步：奇偶性分类

设 $q = 2^{e_0} \cdot m$，其中 $m$ 为奇数。则：

$$
2q^2 = 2^{2e_0+1} \cdot m^2
$$

**情况 1：$d$ 为奇数**  
此时 $d \mid m^2$，且 $\frac{2q^2}{d} = 2^{2e_0+1} \cdot \frac{m^2}{d}$ 为偶数，奇偶性条件自动满足。每个 $m^2$ 的奇数因子 $f$ 对应一个解 $d = f$。

**情况 2：$\frac{2q^2}{d}$ 为奇数**  
设 $X = \frac{2q^2}{d}$，则 $X$ 为奇数，所以 $X \mid m^2$。此时 $d = \frac{2q^2}{X}$ 为偶数。每个 $m^2$ 的奇数因子 $f$ 对应另一个解 $d = \frac{2q^2}{f}$。

因此，**$m^2$ 的每个奇数因子对应两个不同的 $d$ 值**（一个奇数 $d=f$，一个偶数 $d=2q^2/f$）。

### 第四步：因子计数

$m^2$ 的奇数因子个数等于 $m$ 的因子个数的平方。设 $m$ 的质因数分解为：

$$
m = \prod_{i=1}^{k} p_i^{e_i}
$$

则 $m^2$ 的因子个数为 $\prod_{i=1}^{k} (2e_i + 1)$。

由于每个奇数因子对应两个 $d$，且 $d$ 与 $p = q+d$ 一一对应，所以：

$$
\boxed{\text{答案} = 2 \times \prod_{i=1}^{k} (2e_i + 1)}
$$

### 第五步：边界情况

- 若 $q$ 是 $2$ 的幂（即 $m=1$），则空乘积为 $1$，答案为 $2$。例如 $q=1,2,4,8,\dots$ 都有 $2$ 个解。
- $p = q + d$ 必须为正，由于 $d$ 为正因子，$p > q > 0$ 自动满足。
- 右边为正整数的条件 $a + p > 0$ 对所有正 $d$ 自动成立（可验证 $a+p = \frac{X+d+1}{2} + q > 0$）。

## 算法设计

根据上述结论，我们只需：

1. 读入 $q$。
2. 去除 $q$ 中所有的因子 $2$，得到奇数部分 $m$。
3. 对 $m$ 进行质因数分解。
4. 计算 $\prod (2e_i + 1)$，然后乘以 $2$。

由于 $q < 10^{14}$，$\sqrt{q} < 10^7$。我们可以预处理 $10^7$ 以内的所有素数，然后用这些素数快速分解 $q$ 的奇数部分。

### 时间复杂度

- 线性筛法预处理素数表：$O(10^7)$。
- 对每个 $q$，只用素数试除，最多试除到 $\sqrt{q}$，素数密度约为 $\frac{\sqrt{q}}{\ln \sqrt{q}} \approx 3 \times 10^5$。但实际只需要试除到 $q$ 的平方根，且 $q$ 每次除法后迅速减小，平均很快。
- 总复杂度约为 $O(10^7 + T \cdot 10^4)$，足以通过。

## 代码实现

```cpp
// Consecutive Sums
// UVa ID: 12355
// Verdict: Accepted
// Submission Date: 2026-05-17
// UVa Run Time: 0.780s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MAXB = 10000001;
bool isComp[MAXB];
int primes[700000], cnt;

// 线性筛法，预处理 1e7 以内的所有素数
void sieve() {
    for (int i = 2; i < MAXB; ++i) {
        if (!isComp[i]) primes[cnt++] = i;
        for (int j = 0; j < cnt && i * primes[j] < MAXB; ++j) {
            isComp[i * primes[j]] = true;
            if (i % primes[j] == 0) break;
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    sieve();
    ll q;
    while (cin >> q && q) {
        // 去除所有因子 2，位运算加速
        while ((q & 1) == 0) q >>= 1;
        ll r = 2;
        // 用素数试除奇数部分
        for (int i = 0; i < cnt; ++i) {
            int p = primes[i];
            if ((ll)p * p > q) break;
            if (q % p == 0) {
                int e = 0;
                do {
                    q /= p;
                    ++e;
                } while (q % p == 0);
                r *= (2 * e + 1);
            }
        }
        // 剩余部分为大于 1e7 的奇质数
        if (q > 1) r *= 3;
        cout << r << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于将等式转化为对 $d=p-q$ 的约束，然后利用数论推导出 $d$ 与 $q$ 的奇数部分 $m$ 的平方的奇数因子之间的关系，最终得到一个非常简洁的结论：答案等于 $2$ 乘以 $m$ 的所有质因子指数 $(2e_i+1)$ 的乘积。

这种方法将原问题从枚举 $p$ 的搜索问题，转化为了简单的质因数分解计数问题，时间复杂度从指数级降到了亚线性，从而能够处理 $q$ 高达 $10^{14}$ 的输入规模。
