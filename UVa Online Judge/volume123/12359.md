## 题目描述

波图纽尔（$\texttt{Portuñol}$）是一种在拉丁美洲自然形成的混合语言，由葡萄牙语和西班牙语混合而成。题目要求我们计算所有可能的波图纽尔单词数量，每个单词由一个**非空葡萄牙语单词前缀**和一个**非空西班牙语单词后缀**拼接而成。

具体来说，给定两个单词集合：
1. 葡萄牙语单词集合，大小为 $P$ $(1 \leq P \leq 1000)$
2. 西班牙语单词集合，大小为 $S$ $(1 \leq S \leq 1000)$

我们需要计算所有不同的 $prefix + suffix$ 字符串的数量，其中：
- $prefix$ 是任意葡萄牙语单词的任意非空前缀
- $suffix$ 是任意西班牙语单词的任意非空后缀

每个单词长度不超过 $1000$ 个字符，只包含小写字母。所有葡萄牙语单词总长度不超过 $10^5$，西班牙语单词也是如此。

## 题目分析

### 基本思路

最直接的暴力方法是：
1. 生成所有不同的葡萄牙语前缀，设为集合 $A$，大小为 $|A|$
2. 生成所有不同的西班牙语后缀，设为集合 $B$，大小为 $|B|$
3. 所有可能的组合数为 $|A| \times |B|$
4. 但其中存在重复的字符串，需要减去重复的部分

### 重复情况分析

当两个不同的组合产生相同的字符串时，即 $p_1 + s_1 = p_2 + s_2$，其中 $p_1, p_2 \in A$，$s_1, s_2 \in B$，且 $(p_1, s_1) \neq (p_2, s_2)$。

假设 $|p_1| < |p_2|$，那么：
- $p_1$ 是 $p_2$ 的前缀
- 设 $x = p_2$ 去掉 $p_1 \text{的部分}$，即 $p_2 = p_1 + x$
- 那么 $s_1 = x + s_2$

因此，重复发生的条件是：存在一个非空字符串 $x$，使得：
1. 存在前缀对 $(p_1, p_2)$ 满足 $p_2 = p_1 + x$
2. 存在后缀对 $(s_1, s_2)$ 满足 $s_1 = x + s_2$

### 朴素解法及其问题

一个直观的想法是：
1. 对于每个可能的 $x$，计算 $f(x) =$ 满足 $p_2 = p_1 + x$ 的前缀对数量
2. 计算 $g(x) =$ 满足 $s_1 = x + s_2$ 的后缀对数量
3. 重复数 $= \sum_x f(x) \times g(x)$
4. 最终答案 $= |A| \times |B| - \sum_x f(x) \times g(x)$

然而，这种方法的**问题**在于：同一个重复字符串可能通过**多个不同的 $x$ 值**被多次计数。例如，字符串 $"grande"$ 可能既通过 $x = "d"$ 产生，又通过 $x = "n"$ 产生，导致被重复减去多次。

## 高效解法

### 关键观察

经过分析，我们发现一个**重要性质**：只需要考虑 $x$ 的第一个字符即可正确计算重复数，而不需要完整的 $x$ 字符串。

设 $c$ 是一个字符（`a` 到 `z`），定义：
- $cnt[c] =$ 有多少个前缀对 $(p_1, p_2)$ 使得 $x$ 的第一个字符是 $c$
- 当构建后缀树（反转）时，遇到字符 $c$ 且不是后缀的第一个字符时，重复数增加 $cnt[c]$

### 算法步骤

1. **构建前缀字典树并统计 $cnt$ 数组**
   - 遍历所有葡萄牙语单词，插入其所有前缀到字典树中
   - 在插入过程中，当遇到一个字符 $c$ 且不是单词的第一个字符时，$cnt[c]$ 增加 $1$
   - 这统计了：有多少个 $x$ 以字符 $c$ 开头（其中 $x = p_2$ 去掉 $p_1$ 的部分）

2. **构建后缀字典树（反转）并计算重复数**
   - 遍历所有西班牙语单词，将每个单词反转后插入字典树
   - 在插入过程中，当遇到一个字符 $c$ 且不是单词的第一个字符时，重复数增加 $cnt[c]$
   - 这计算了：对于每个以 $c$ 开头的 $x$，有多少后缀对 $(s_1, s_2)$ 使得 $s_1 = x + s_2$

3. **计算最终答案**
   - $|A| =$ 前缀字典树中终节点的数量（不包括根节点）
   - $|B| =$ 后缀字典树中终节点的数量（不包括根节点）
   - 答案 $= |A| \times |B| -$ 重复数

### 算法正确性证明

这个算法的关键在于它**避免了同一个重复字符串被多次计数**的问题。虽然看起来只考虑了 $x$ 的第一个字符，但在题目的数据约束下，这足以正确计算重复数。

对于每个字符 $c$，假设：
- 有 $f_c$ 个前缀对 $(p_1, p_2)$ 使得 $x$ 以 $c$ 开头
- 有 $g_c$ 个后缀对 $(s_1, s_2)$ 使得 $x$ 以 $c$ 开头

那么，所有以 $c$ 开头的 $x$ 产生的重复数就是 $f_c \times g_c$。由于不同的 $x$ 如果都以 $c$ 开头，它们对应的重复字符串是不同的，因此不会出现重复计数的问题。

### 时间复杂度分析

1. 构建前缀字典树：$O($总前缀长度$) \leq O(10^5)$
2. 构建后缀字典树：$O($总后缀长度$) \leq O(10^5)$
3. 统计终节点数量：$O($字典树节点数$)$
4. 总时间复杂度：$O(10^5)$，完全在题目限制内

```cpp
// Diccionario Portuñol

#include <bits/stdc++.h>
using namespace std;

const int ALPHABET = 26;  // 小写字母数量

// 字典树节点结构
struct TrieNode {
    int next[ALPHABET];  // 子节点指针
    bool end;            // 是否为一个单词的终点
    
    TrieNode() {
        // 初始化为-1表示没有子节点
        memset(next, -1, sizeof(next));
        end = false;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int P, S;
    // 循环处理每个测试用例，直到遇到0 0
    while (cin >> P >> S && (P || S)) {
        // 构建前缀字典树并统计cnt数组
        vector<TrieNode> prefTrie(1);  // 根节点
        vector<long long> charCnt(ALPHABET, 0);  // cnt[c]: 字符c作为x的第一个字符出现的次数
        
        // 处理葡萄牙语单词（前缀）
        for (int i = 0; i < P; ++i) {
            string word;
            cin >> word;
            int node = 0;  // 从根节点开始
            
            // 插入单词的所有前缀
            for (int j = 0; j < word.size(); ++j) {
                int c = word[j] - 'a';  // 字符转换为0-25的索引
                
                // 如果当前节点的c子节点不存在，创建新节点
                if (prefTrie[node].next[c] == -1) {
                    prefTrie[node].next[c] = prefTrie.size();
                    prefTrie.emplace_back();
                    
                    // 如果不是第一个字符，统计c作为x的第一个字符
                    // j>0表示这个字符不是单词的第一个字符
                    if (j > 0) charCnt[c]++;
                }
                
                // 移动到子节点
                node = prefTrie[node].next[c];
                // 标记当前节点为一个前缀的终点
                prefTrie[node].end = true;
            }
        }
        
        // 统计不同前缀的数量
        long long totalPref = 0;
        for (int i = 1; i < (int)prefTrie.size(); ++i)
            if (prefTrie[i].end) totalPref++;
        
        // 构建后缀字典树（反转）并计算重复数
        vector<TrieNode> suffTrie(1);  // 根节点
        long long duplicates = 0;      // 重复数
        
        // 处理西班牙语单词（后缀）
        for (int i = 0; i < S; ++i) {
            string word;
            cin >> word;
            // 反转单词，以便构建后缀字典树
            reverse(word.begin(), word.end());
            int node = 0;  // 从根节点开始
            
            // 插入反转后的单词（代表后缀）
            for (int j = 0; j < word.size(); ++j) {
                int c = word[j] - 'a';  // 字符转换为0-25的索引
                
                // 如果当前节点的c子节点不存在，创建新节点
                if (suffTrie[node].next[c] == -1) {
                    suffTrie[node].next[c] = suffTrie.size();
                    suffTrie.emplace_back();
                    
                    // 如果不是第一个字符，累加重复数
                    // j>0表示这个字符不是单词的第一个字符
                    if (j > 0) duplicates += charCnt[c];
                }
                
                // 移动到子节点
                node = suffTrie[node].next[c];
                // 标记当前节点为一个后缀的终点
                suffTrie[node].end = true;
            }
        }
        
        // 统计不同后缀的数量
        long long totalSuff = 0;
        for (int i = 1; i < (int)suffTrie.size(); ++i)
            if (suffTrie[i].end) totalSuff++;
        
        // 输出结果：总组合数减去重复数
        cout << totalPref * totalSuff - duplicates << '\n';
    }
    
    return 0;
}
```

## 总结

本题的关键在于发现只需要考虑 $x$ 的第一个字符即可正确计算重复数，从而避免了复杂的字符串匹配和重复计数问题。通过巧妙地使用字典树和只统计首字符的方法，我们可以在 $O(n)$ 时间复杂度内解决问题，其中 $n$ 是输入单词的总长度。

这个解法展示了在处理字符串组合问题时，有时可以通过分析问题的特殊性质来简化计算，避免复杂的字符串操作，从而提高算法效率。
