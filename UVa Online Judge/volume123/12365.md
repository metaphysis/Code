## 题目描述

木星正在入侵地球！主要城市已被木星飞船摧毁，人类正在奋力反击。$\texttt{Nlogonia}$ 通过入侵飞船的控制系统来领导这次反击。

与地球计算机不同（地球计算机的一个字节通常有 $2^8$ 种可能值），木星计算机使用具有 $B$ 种可能值的字节，取值范围为 $\{0,1,\ldots,B-1\}$。$\texttt{Nlogonia}$ 的软件工程师已经逆向工程了木星飞船的固件，并计划破坏它，使飞船最终自毁。

然而，作为安全措施，木星飞船运行着一个监控程序，通过哈希计算固件的部分内容并将结果与已知的正确值进行比较，来定期检查固件的完整性。

对于从位置 $i$ 到位置 $j$ 的固件字节，监控程序使用以下哈希函数：

$$H(f_i,\ldots,f_j) = \sum_{k=0}^{j-i} B^k f_{j-k} \pmod{P}$$

其中 $P$ 是一个质数。

**示例**：如果 $B = 20$，$P = 139$，而固件字节 $2$ 到 $5$ 的值为 $f_2 = 14$，$f_3 = 2$，$f_4 = 2$，$f_5 = 4$，那么：

$$H(f_2,\ldots,f_5) = 20^0 \times 4 + 20^1 \times 2 + 20^2 \times 2 + 20^3 \times 14 \pmod{139}$$
$$= 4 + 40 + 800 + 112000 \pmod{139}$$
$$= 112844 \pmod{139}$$
$$= 115$$

$\texttt{Nlogonia}$ 的密码学家需要找到一种方法破坏固件而不触发监控程序。作为第一步，你需要编写一个程序来模拟两种命令的交错执行：Nlogonia 软件工程师编辑固件字节，以及木星监控程序计算固件部分的哈希值。在模拟开始时，固件中的每个字节值都为零。

## 输入格式

每个测试用例包含多行：
- 第一行：四个整数 $B$，$P$，$L$ 和 $N$，其中 $B$ 是木星字节的可能取值数，$P$ 是哈希模数（质数，满足 $2 \leq B < P \leq 10^9$），$L$ 是固件长度（字节数），$N$ 是要模拟的命令数（满足 $1 \leq L,N \leq 10^5$）
- 接下来 $N$ 行：每行描述一个命令：
  - `E I V`：编辑命令，将位置 $I$ 的字节值改为 $V$（$1 \leq I \leq L$，$0 \leq V \leq B-1$）
  - `H I J`：哈希命令，计算 $H(f_I,\ldots,f_J)$
- 最后一个测试用例后跟一行包含四个零

## 输出格式

对于每个测试用例，按输入顺序输出每个哈希命令的结果（每行一个整数）。每个测试用例输出结束后，输出一行包含单个字符 `-`（连字符）。

## 题目分析

### 问题理解

我们需要处理两种操作：
1. **单点更新**：修改固件中某个位置的字节值
2. **区间查询**：计算固件某个区间的哈希值

哈希函数的定义可以看作一个多项式哈希：
$$H(I,J) = f_I \cdot B^{J-I} + f_{I+1} \cdot B^{J-I-1} + \cdots + f_J \cdot B^0 \pmod{P}$$

### 暴力方法的局限性

如果直接按照定义计算每个哈希查询，每次需要 $O(n)$ 时间，对于 $n$ 个查询，总时间复杂度为 $O(n^2)$。考虑到 $n$ 最大可达 $10^5$，这种方法显然不可行。

### 优化思路

我们需要一种数据结构来高效支持单点更新和区间查询。线段树是解决这类问题的经典数据结构。

**关键观察**：
哈希函数具有可合并性。如果我们知道两个相邻区间的哈希值，可以合并它们得到整个区间的哈希值。

具体来说，对于区间 $[l, r]$，如果我们将其分成 $[l, mid]$ 和 $[mid+1, r]$，那么：
$$hash_{[l,r]} = hash_{[l,mid]} \cdot B^{len_{[mid+1,r]}} + hash_{[mid+1,r]} \pmod{P}$$

其中 $len_{[mid+1,r]}$ 是右区间的长度。

### 线段树设计

每个线段树节点存储：
- 该节点对应区间的哈希值
- 该节点对应区间的长度

**操作**：
1. **更新操作**：修改单个位置的值，然后自底向上更新所有受影响的节点
2. **查询操作**：查询区间哈希值，可能需要合并多个节点的信息

### 算法复杂度

- **预处理**：计算 $B$ 的幂次模 $P$，时间复杂度 $O(L)$
- **每次操作**：线段树的更新和查询都是 $O(\log L)$
- **总复杂度**：$O(N \log L)$，对于 $L, N \leq 10^5$ 是可接受的

### 实现细节

1. **幂次预处理**：预先计算 $B^0, B^1, B^2, \ldots, B^L \pmod{P}$，避免重复计算
2. **模运算**：所有运算都要对 $P$ 取模，防止溢出
3. **线段树构建**：使用标准的线段树实现，支持单点更新和区间查询

```cpp
// Jupiter Attacks

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;

long long base, mod;
int len, n;

long long powBase[MAXN];

struct SegmentTree {
    vector<long long> tree;
    vector<int> length;
    
    SegmentTree(int size) {
        tree.resize(4 * size);
        length.resize(4 * size);
        build(1, 1, size);
    }
    
    void build(int node, int l, int r) {
        if (l == r) {
            tree[node] = 0;
            length[node] = 1;
            return;
        }
        int mid = (l + r) / 2;
        build(node * 2, l, mid);
        build(node * 2 + 1, mid + 1, r);
        length[node] = length[node * 2] + length[node * 2 + 1];
        tree[node] = 0;
    }
    
    void update(int node, int l, int r, int pos, long long val) {
        if (l == r) {
            tree[node] = val % mod;
            return;
        }
        int mid = (l + r) / 2;
        if (pos <= mid) update(node * 2, l, mid, pos, val);
        else update(node * 2 + 1, mid + 1, r, pos, val);
        
        tree[node] = (tree[node * 2] * powBase[length[node * 2 + 1]] + tree[node * 2 + 1]) % mod;
    }
    
    pair<long long, int> query(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return {tree[node], length[node]};
        
        int mid = (l + r) / 2;
        if (qr <= mid) return query(node * 2, l, mid, ql, qr);
        if (ql > mid) return query(node * 2 + 1, mid + 1, r, ql, qr);
        
        auto leftRes = query(node * 2, l, mid, ql, qr);
        auto rightRes = query(node * 2 + 1, mid + 1, r, ql, qr);
        
        long long hashVal = (leftRes.first * powBase[rightRes.second] + rightRes.first) % mod;
        int totalLen = leftRes.second + rightRes.second;
        return {hashVal, totalLen};
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    while (true) {
        cin >> base >> mod >> len >> n;
        if (base == 0 && mod == 0 && len == 0 && n == 0) break;
        
        powBase[0] = 1;
        for (int i = 1; i <= len; i++)
            powBase[i] = powBase[i - 1] * base % mod;
        
        SegmentTree segTree(len);
        
        for (int i = 0; i < n; i++) {
            char cmd;
            cin >> cmd;
            if (cmd == 'E') {
                int pos; long long val;
                cin >> pos >> val;
                segTree.update(1, 1, len, pos, val);
            } else {
                int l, r;
                cin >> l >> r;
                auto res = segTree.query(1, 1, len, l, r);
                cout << res.first << "\n";
            }
        }
        cout << "-\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于认识到哈希函数的可合并性，从而可以使用线段树来高效处理区间查询。通过预处理 $B$ 的幂次模 $P$，我们可以在 $O(1)$ 时间内完成区间合并时的权重计算，使得每次线段树操作的时间复杂度为 $O(\log L)$。

这种将多项式哈希与线段树结合的方法在字符串处理和区间哈希查询问题中非常常见，是一个值得掌握的重要技巧。
