## 题目描述

今天是 $\texttt{Animesh}$ 父亲的 $68$ 岁生日，他来到达卡 $\texttt{Banani}$ 地区的“$\texttt{Archie}$ 礼品店”购买蜡烛。他意识到买 $68$ 根普通蜡烛不是个好主意，但店里有一种数字形状的蜡烛。他发现只需要买两根蜡烛（一个‘$6$’和一个‘$8$’）就可以在蛋糕上拼出父亲的年龄 $68$ 。现在，他想购买数字形状的蜡烛，以便在家庭所有成员生日时都能拼出他们的年龄。他最少需要买多少根蜡烛？他必须遵守以下限制：

1. 店里只有 $10$ 根蜡烛，形状分别是 $0$ ~ $9$ 十个数字。因此他每种形状的蜡烛最多只能买一根。家里已经有一个“$+$”形状的蜡烛，所以不需要再买。他可以买全部十根数字蜡烛，但他希望买的数量最少，因为这些蜡烛不便宜。
2. 他只能用数字蜡烛来展示年龄，但也可以使用家里已有的“$+$”蜡烛将年龄表示为两个数字之和。例如，如果有人 $12$ 岁，他可以展示为 $2+10$ 、 $3+9$ 、 $4+8$ 、 $5+7$ 、 $7+5$ 、 $8+4$ 、 $9+3$ 、 $10+2$ 或直接写 $12$ 。

### 输入格式

输入文件包含不超过 $10000$ 行。每行以一个整数 $n$ （ $1 \leq n \leq 10$ ）开始，表示 $\texttt{Animesh}$ 家庭成员的数量。随后是 $n$ 个整数，每个都在 $1$ 到 $100$ （含）之间，表示家庭成员下一个生日的年龄。一行只包含一个 $0$ 时表示输入结束，该行不应被处理。

### 输出格式

对于每行输入，输出一行。该行包含输出序号，后跟一些数字，表示 $\texttt{Animesh}$ 必须购买的蜡烛形状（数字），以便他能拼出所有家庭成员的生日年龄。这些数字按降序打印，形成一个数字串，记作 $T$ 。假设生日不在同一天，同一根蜡烛可用于多个生日。如果有多组购买方案都能达到最小数量，则选择 $T$ 最小的方案。可以保证总有解。

### 样例输入

```
2 10 11
1 30
0
```

### 样例输出

```
Case 1: 654
Case 2: 30
```

## 题目分析

### 问题本质

这是一个**组合覆盖问题**：我们需要选择一个最小的数字集合（ $0$ ~ $9$ 的子集），使得对于每个给定的年龄 $age$ ，要么：

1. 直接用选中的数字蜡烛拼出 $age$ （年龄的每一位数字都必须在集合中），或者
2. 用选中的数字蜡烛拼出两个数 $a$ 和 $b$ ，使得 $a + b = age$ ，并用“$+$”连接（ $a$ 和 $b$ 的每一位数字也必须在集合中）。

**关键限制**：每种数字蜡烛最多只有一根，因此：
- 如果一个数字在多位数中重复出现（如 $11$ 中的两个 $1$ ），则不能直接表示。
- 在加法表示中， $a$ 和 $b$ 也不能有重复数字。

### 解题思路

#### 1. 暴力枚举所有可能的数字集合

由于只有 $10$ 种数字蜡烛，我们可以用 $10$ 位二进制掩码表示选择了哪些数字。掩码的取值范围是 $1$ 到 $2^{10} - 1 = 1023$ （不能为空集）。对于每个掩码 $mask$ ，我们需要检查它是否能表示所有年龄。

#### 2. 检查一个年龄能否用给定掩码表示

对于年龄 $age$ ，有两种表示方式：

**A. 直接表示**  
将 $age$ 转换为字符串，检查：
1. 字符串中不能有重复数字（因为每种数字蜡烛只有一根）
2. 字符串中的每个数字对应的位在 $mask$ 中必须为 $1$

**B. 加法表示**  
枚举 $a$ 从 $1$ 到 $\lfloor age/2 \rfloor$ ，令 $b = age - a$ 。对于每一对 $(a, b)$ ，分别检查 $a$ 和 $b$ 是否都能用 $mask$ 中的数字表示（规则同直接表示），并且 $a$ 和 $b$ 使用的数字不能冲突（即不能重复使用同一根蜡烛）。

#### 3. 优化策略

- **预计算**：由于年龄范围很小（ $1$ ~ $100$ ），我们可以预计算对于每个掩码 $mask$ ，哪些年龄可以被表示。这样每个测试用例只需查表，无需重复计算。
- **剪枝**：在枚举掩码时，按蜡烛数量从小到大枚举。一旦找到可行解，记录当前最小数量，后续只检查蜡烛数量不超过该值的掩码。
- **字典序最小**：当蜡烛数量相同时，选择 $mask$ 值较小的掩码。由于数字 $0$ ~ $9$ 对应比特位 $0$ ~ $9$ ， $mask$ 值小意味着选择的数字偏小，降序排列后得到的数字串 $T$ 也更小。

#### 4. 算法步骤

1. **预计算阶段**：  
   对于每个掩码 $mask$ （ $1 \leq mask < 1024$ ）和每个年龄 $age$ （ $1 \leq age \leq 100$ ），计算 $canFormWithMask[mask][age]$ ，表示能否用 $mask$ 中的数字表示 $age$ 。
   
2. **查询阶段**：  
   对于每个测试用例：
   - 读取 $n$ 和 $n$ 个年龄
   - 枚举所有掩码 $mask$ ，按蜡烛数量从小到大
   - 如果某个 $mask$ 能表示所有年龄（通过查表判断），则更新最优解
   - 输出最优掩码对应的降序数字串

### 时间复杂度分析

- **预计算**： $1023 \times 100 \times 50 \approx 5 \times 10^6$ 次操作，在可接受范围内
- **每个测试用例**：最多检查 $1023$ 个掩码，每个掩码检查 $n$ （ $n \leq 10$ ）个年龄，总操作数约 $10^4$ 量级
- **总体复杂度**：适合在线评测系统

### 样例解释

**样例 1**：年龄 $10$ 和 $11$  
- 最小数字集合为 $\{4,5,6\}$  
- $10 = 4 + 6$ ，需要数字 $4$ 和 $6$  
- $11 = 5 + 6$ ，需要数字 $5$ 和 $6$  
- 输出降序数字串： $654$

**样例 2**：年龄 $30$  
- 最小数字集合为 $\{3,0\}$  
- $30$ 可以直接表示，需要数字 $3$ 和 $0$  
- 输出降序数字串： $30$

```cpp
// Candles

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

bool canFormWithMask[1024][110];

int cnt[10];
void add(int mask, int age, string s) {
    memset(cnt, 0, sizeof cnt);
    bool valid = true;
    for (auto c : s) {
        if (cnt[c - '0']) {
            valid = false;
            break;
        }
        cnt[c - '0']++;
    }
    if (valid) {
        for (int i = 0; i < 10; i++)
            if (cnt[i] && !(mask & (1 << i))) {
                valid = false;
                break;
            }
    }
    canFormWithMask[mask][age] |= valid;
}

void initialize() {
    for (int mask = 1; mask < 1024; mask++) {
        for (int age = 1; age <= 100; age++) {
            add(mask, age, to_string(age));
            if (canFormWithMask[mask][age]) continue;
            for (int x = 1; x <= age / 2; x++) {
                add(mask, age, to_string(x) + to_string(age - x));
                if (canFormWithMask[mask][age]) break;
            }
        }
    }
}

int main() {
    initialize();
    int caseNum = 1;
    int n;
    while (cin >> n && n) {
        vector<int> ages(n);
        for (int i = 0; i < n; i++) cin >> ages[i];
        int minCount = 11, bestMask = 0;
        for (int mask = 1; mask < 1024; mask++) {
            int cnt = __builtin_popcount(mask);
            if (cnt > minCount) continue;
            bool ok = true;
            for (int age : ages)
                if (!canFormWithMask[mask][age]) {
                    ok = false;
                    break;
                }
            if (ok) {
                if (cnt < minCount || (cnt == minCount && mask < bestMask)) {
                    minCount = cnt;
                    bestMask = mask;
                }
            }
        }
        string result;
        for (int d = 9; d >= 0; d--)
            if (bestMask & (1 << d))
                result += char('0' + d);
        cout << "Case " << caseNum++ << ": " << result << '\n';
    }
    return 0;
}
```

### 代码说明

1. **预计算函数 `initialize`**  
   对于每个掩码和年龄，首先尝试直接表示，如果不行再尝试加法表示。加法表示时只需枚举 $x \leq age/2$ 避免重复，并且找到一种表示方式后就立即停止。

2. **辅助函数 `add`**  
   检查字符串 $s$ 中的数字是否重复，并且所有出现的数字是否都在掩码 $mask$ 中。使用 `|=` 操作确保只要有一种表示方式成功就标记为 $true$ 。

3. **主函数 `main`**  
   - 调用 `initialize` 进行预计算
   - 读取每个测试用例，枚举所有掩码
   - 使用 `__builtin_popcount` 快速计算掩码中 $1$ 的个数（蜡烛数量）
   - 按蜡烛数量从小到大，蜡烛数量相同时按掩码值从小到大选择最优解
   - 输出时按降序（ $9$ 到 $0$ ）输出数字

该算法充分利用了题目数据范围小的特点，通过预计算和状态压缩实现了高效的求解。
