
> **摘要**：本题要求在一条由大写字母表示颜色的球链中，仅发射一个可自选颜色的球，求最多能触发的连锁爆炸次数。核心思路是先将连续同色球压缩为颜色块序列，把爆炸过程抽象为压缩序列上的奇数长度回文匹配，再用 $\texttt{Manacher}$ 算法在 $O(L)$ 时间内求出最大回文半径，即为答案。整体时间复杂度 $O(L)$，空间复杂度 $O(L)$，可轻松应对 $L \le 10^5$、$T \le 100$ 的数据规模。

## 题目描述

$\texttt{Morteza}$ 正在玩一款球类爆炸游戏。游戏中有一条由不同颜色球组成的链，颜色用大写字母（`'A'` – `'Z'`）表示。玩家可以向链中的任意位置射入一个新球，并可以自由选择该球的颜色。如果新球与其左右相邻的球（或合并后的新邻居）形成至少两个连续同色球，则该连续同色段会爆炸并从链中移除，剩余的两部分会重新连接。若连接处再次出现同色连续段，则会继续爆炸，直到不再有新的匹配产生。每次连续的爆炸过程称为一次“连锁爆炸”的序列，爆炸次数等于整个连锁过程中发生的爆炸次数（每次爆炸对应一段同色球的消除）。

给定一条初始链，玩家只能发射一个球，但颜色可任意选择。问：通过合理选择插入位置和颜色，最多能触发多少次连续爆炸？

## 输入格式

第一行包含一个整数 $T$（$T \le 100$），表示测试用例的数量。  
接下来 $T$ 行，每行一个由大写字母组成的字符串，长度不超过 $100,000$，代表一条球链。

## 输出格式

对于每个测试用例，输出一行一个整数，表示能够获得的最大连续爆炸次数。

## 样例

输入

```
3
GGGBWWRRWRR
XAABCBAXAAAA
CCC
```

输出

```
2
4
1
```

## 题目分析

直接模拟插入过程并尝试所有位置和颜色显然不可行。我们需要深入理解爆炸的数学结构。

首先，将初始链中所有连续相同颜色的球压缩为一个“颜色块”，因为只要两个相邻块颜色不同，它们之间就不会发生自发爆炸。压缩后的序列长度为 $n$，每个元素表示一个连续同色段（块）。

现在考虑插入一个新球。新球可以插入任意两个块之间，或者某个块内部（但插入块内部会将该块分裂，实际上等价于在某个位置新增一个块，其颜色与相邻块可能相同或不同）。因为我们可以自由选择新球的颜色，所以最优策略是选择一个插入点，并让新球的颜色等于该点左右两侧相邻块的颜色，从而触发第一次爆炸。

第一次爆炸会消除三个连续的同色块（新球及其左右两个同色块），然后左右两侧剩余的块会靠近并形成新的相邻关系。若新的相邻块颜色相同，则会触发下一次爆炸，以此类推。

观察发现：每爆炸一次，就会从压缩序列中删除一对关于插入点对称的相同颜色块。因此，爆炸次数等于从插入点开始，向左右两边扩展，能形成的最长“对称匹配”的块对数。也就是说，我们需要在压缩序列中找一个位置（可以是块之间的间隙，也可以是块本身），使得左右两侧的块序列形成尽可能长的回文。

由于新球本身作为一个块位于中心，因此整个爆炸过程的中心就是新球所在位置。因此，我们只需要关注压缩序列中所有可能的奇数长度回文子串：以某个块为中心，左右对称扩展，直到遇到颜色不匹配为止。该回文半径（即匹配的对数）就是从这个中心插入新球所能获得的爆炸次数。

因此，问题转化为：给定一个长度为 $n$ 的字符串（压缩后的颜色序列），求其所有奇数长度回文子串的最大半径（半径定义为从中心到一侧的块数，即 `(回文长度 - 1) / 2`）。如果原字符串为空（实际上不会发生），答案为 $0$。

## 解题思路

### 压缩步骤

对输入字符串进行一次线性扫描，合并所有连续相同字符，得到压缩序列 $s$。例如 `"GGGBWWRRWRR"` 压缩为 `"GBWRWR"`（长度 $6$）。注意，压缩不会改变可能的最大爆炸次数，因为连续同色块内部插入新球只会增加一个同色块，但爆炸时整个连续段一起消除，等价于在压缩后的块上进行操作。

### 最长奇数回文半径 – $\texttt{Manacher}$ 算法

我们需要高效地计算每个位置作为中心的奇数回文半径。经典 $\texttt{Manacher}$ 算法可以在 $O(n)$ 时间内求出所有奇数长度回文半径数组 `d1[i]`，其中 `d1[i]` 表示以 `i` 为中心，向左右扩展的最大半径（包括中心本身，例如单字符回文半径为 $1$）。那么从这个位置插入新球能触发的爆炸次数就是 `d1[i]`（因为半径减 $1$ 即为匹配的块对数，但半径本身等于爆炸次数，因为第一次爆炸消除中心块和左右各一个，共三个块，对应半径 $1$ 时爆炸 $1$ 次；半径 $2$ 对应五块，爆炸 $2$ 次，以此类推）。因此答案即为 $\max(d1[i])$。

为什么不需要考虑偶数回文？因为插入的新球作为一个独立的块，总是位于回文中心，回文长度必为奇数。若考虑在块间插入，新球与左右两块同色，构成奇数长度回文（新球为中心）。因此仅需奇数回文半径。

### 算法步骤

1. 对于每个测试字符串，扫描压缩得到颜色块序列 $s$。
2. 使用 $\texttt{Manacher}$ 算法计算 `d1` 数组。
3. 取 `d1` 中的最大值输出。

### 复杂度分析

- 压缩过程：$O(L)$，$L$ 为原字符串长度。
- $\texttt{Manacher}$ 算法：$O(|s|)$，$|s| \le L$。
- 每个测试用例总时间复杂度 $O(L)$，空间复杂度 $O(L)$，满足 $L \le 10^5$ 且 $T \le 100$ 的限制。

```cpp

#include <bits/stdc++.h>
using namespace std;

// 计算单个测试用例的最大爆炸次数
int maxExplosions(const string& str) {
    // 压缩连续同色块，只保留颜色序列
    string s;
    for (char c : str)
        if (s.empty() || s.back() != c)
            s.push_back(c);
    int n = s.size();
    if (n == 0) return 0; // 防御性
    // Manacher 算法计算以每个位置为中心的奇数长度回文半径
    vector<int> d1(n);
    int l = 0, r = -1;
    for (int i = 0; i < n; ++i) {
        int k = (i > r) ? 1 : min(d1[l + r - i], r - i + 1);
        while (i - k >= 0 && i + k < n && s[i - k] == s[i + k])
            ++k;
        d1[i] = k;
        if (i + k - 1 > r) {
            l = i - k + 1;
            r = i + k - 1;
        }
    }
    // 最大半径即为最大爆炸次数
    return *max_element(d1.begin(), d1.end());
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        string str;
        cin >> str;
        cout << maxExplosions(str) << '\n';
    }
    return 0;
}
```

## 总结

- 本题的关键在于将物理爆炸过程抽象为压缩序列上的回文匹配问题。
- 连续同色块的合并压缩是减少状态量的有效手段。
- $\texttt{Manacher}$ 算法提供了线性时间求解最长回文半径的能力，是处理此类对称性问题的利器。
- 注意理解爆炸次数与回文半径的等价关系，避免误用回文长度。
- 算法实现简洁，时间复杂度优秀，能够轻松应对 $10^5$ 级别的数据规模。
