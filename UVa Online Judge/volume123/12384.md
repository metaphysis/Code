## 题目描述

给定一个包含 $n$ 个整数的数组 $X_{1 \leq i \leq n}$，定义数组 $X$ 的 **`span`** $S$ 为一个长度为 $n$ 的整数数组，其中 $S_i$ 表示在 $X_i$ **之前**（包括 $X_i$ 自身）连续满足所有元素都 $\leq X_i$ 的最大元素个数。数学表示如下：

$$
S_i = |A_i|, \quad 
A_i = \{j \leq i \mid \forall k (j \leq k \leq i) \ (X_k \leq X_i)\}.
$$

例如，$X = [40,2,10,50,30,15]$ 的 span 为 $S = [1,1,2,4,1,1]$。

本题的特殊设定是：$X_i = P_i \bmod m$，其中 $P_i$ 是第 $i$ 个素数。我们需要计算 $S$ 的所有元素之和 **模 $m$** 的结果。

### 输入格式

- 第一行一个整数 $T$，表示测试用例个数。
- 接下来 $T$ 行，每行两个整数 $n, m$，满足 $1 \leq n, m \leq 10^5$。

### 输出格式

对于每个测试用例，输出一行一个整数：$\left(\sum_{i=1}^n S_i\right) \bmod m$。

### 样例输入

```
3
7 10
10 16
10 7
```

（实际格式应为每行两个数，这里只是紧凑写法）

### 样例输出

```
0
5
6
```

## 题目分析

### 1. 直接计算的复杂度

若直接按照定义计算 $S_i$，需要向前扫描直到遇到一个大于 $X_i$ 的数，时间复杂度 $O(n^2)$，当 $n$ 达到 $10^5$ 时不可接受。

### 2. 素数的获取

我们需要前 $n$ 个素数。第 $10^5$ 个素数大约是 $1.3 \times 10^6$，因此可以预先用埃氏筛（$\texttt{Sieve of Eratosthenes}$）生成 $2 \times 10^6$ 以内的所有素数，并存储到全局数组中。由于 $T$ 最多可能为 $10^5$，必须 **只预处理一次**。

### 3. `Span` 的计算优化

观察 $S_i$ 的含义：它等于从 $i$ 向左数，直到遇到第一个大于 $X_i$ 的元素为止，这中间的元素个数（包括 $X_i$ 自己）。这是一个经典的 **左边第一个更大元素** 问题，可以用 **单调栈** 在 $O(n)$ 时间内解决。

具体方法：
- 维护一个单调递减栈（栈内元素的值从栈底到栈顶严格递减）。
- 遍历 $i = 0 \dots n-1$：
  - 当栈非空且栈顶元素的值 $\leq X_i$ 时，弹出栈顶（因为这些元素无法成为比 $X_i$ 大的左边界）。
  - 如果栈为空，说明左边所有元素都 $\leq X_i$，则 $S_i = i + 1$。
  - 否则，栈顶元素的下标 $j$ 是左边第一个大于 $X_i$ 的元素，则 $S_i = i - j$。
  - 将 $i$ 入栈。

这个过程保证了每个元素最多入栈和出栈一次，因此总复杂度 $O(n)$。

### 4. 模运算的注意点

最终需要输出 $totalSum \bmod m$。注意 $totalSum$ 可能很大（最大约 $n^2$ 级别），应使用 $64$ 位整数（如 $\texttt{long long}$）累加，避免溢出。

## 解题思路

### 整体流程

1. **预处理素数**  
   使用埃氏筛，生成 $2 \times 10^6$ 以内的所有素数，存入全局数组 $\texttt{primes}$。

2. **对每个测试用例**  
   - 读取 $n, m$。
   - 取前 $n$ 个素数对 $m$ 取模，得到数组 $X$。
   - 使用单调栈计算 $S_i$ 并累加求和。
   - 输出 $\text{sum} \bmod m$。

### 为什么素数范围取 $2 \times 10^6$

第 $10^5$ 个素数约为 $1299709$，因此 $2 \times 10^6$ 足够生成前 $10^5$ 个素数，且不会造成过多的时间开销。

### 时间复杂度

- 筛法：$O(L \log \log L)$，其中 $L = 2 \times 10^6$。
- 每个测试用例：$O(n)$。
- 总复杂度：$O(L \log \log L + \sum n)$，在 $10^5$ 级别内可接受。

### 空间复杂度

- 素数列表：约 $10^5$ 个整数。
- 每个测试用例临时数组 $X$ 和 $S$：$O(n)$。

## 实现细节

- 使用 $\texttt{vector<bool>}$ 进行布尔标记以节省内存。
- 使用 $\texttt{stack<int>}$ 存储下标，维护单调性。
- 输入输出使用 $\texttt{scanf}$ / $\texttt{printf}$ 提高效率。
- 累加和用 $\texttt{long long}$ 类型。

## 代码实现

```cpp
// Span
// UVa ID: 12384
// Verdict: Accepted
// Submission Date: 2026-05-25
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net


#include <bits/stdc++.h>
using namespace std;

// 全局素数列表
vector<int> primes;

// 埃氏筛，生成所有不超过 limit 的素数
void sieve(int limit) {
    vector<bool> isPrime(limit + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i <= limit; ++i) {
        if (isPrime[i]) {
            primes.push_back(i);
            if ((long long)i * i <= limit) {
                for (int j = i * i; j <= limit; j += i)
                    isPrime[j] = false;
            }
        }
    }
}

int main() {
    // 预先生成足够多的素数（第 100000 个素数约 1299709，取 2e6 安全）
    const int MAX_PRIME_LIMIT = 2000000;
    sieve(MAX_PRIME_LIMIT);

    int T;
    scanf("%d", &T);
    while (T--) {
        int n, m;
        scanf("%d %d", &n, &m);

        // 步骤1：生成 X 数组
        vector<int> X(n);
        for (int i = 0; i < n; ++i) X[i] = primes[i] % m;

        // 步骤2：单调栈计算 span
        vector<int> S(n);
        stack<int> st; // 存下标，维护 X[st] 递减
        long long totalSum = 0;

        for (int i = 0; i < n; ++i) {
            while (!st.empty() && X[st.top()] <= X[i]) st.pop();
            if (st.empty()) S[i] = i + 1;
            else S[i] = i - st.top();
            st.push(i);
            totalSum += S[i];
        }

        // 输出 sum % m
        printf("%lld\n", totalSum % m);
    }
    return 0;
}
```

## 总结

本题综合了 **素数筛法** 与 **单调栈** 两个经典算法。关键在于：
- 一次性预处理素数，避免重复计算。
- 利用单调栈将 `span` 的计算从 $O(n^2)$ 优化到 $O(n)$。
- 注意累加和的数据范围，防止溢出。

掌握这些技巧后，不仅能解决本题，也能应对许多与 “左边第一个更大 / 更小元素” 相关的题目。
