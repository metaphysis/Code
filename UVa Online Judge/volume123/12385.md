## 题目描述

对于一个整数序列 $<x_1, x_2, \ldots, x_n>$，其中连续子序列 $<x_i, x_{i+1}, \ldots, x_j>$（其中 $i < j \leq n$）被称为"有趣的"，如果它的第一个和最后一个元素相等（即 $x_i = x_j$）。

两个有趣的子序列 $S_1 = <x_i, x_{i+1}, \ldots, x_j>$ 和 $S_2 = <x_a, x_{a+1}, \ldots, x_b>$ 被称为"无冲突的"，如果满足 $a \geq j$ 或 $i \geq b$。

对于给定的大小已知的序列，找出最大数量的成对无冲突的有趣子序列。

### 输入格式
第一行包含整数 $T \leq 100$ 表示测试用例数量。每个测试用例以单独一行的整数 $1 \leq N \leq 100,000$ 开始，表示序列大小。下一行包含 $N$ 个正整数，每个数在 $1$ 到 $100,000$ 之间。

### 输出格式
对于每个测试用例，输出一行，表示最大数量的成对无冲突的有趣子序列。

### 样例输入
```
3
6
1 2 1 3 1 2
4
2 4 2 4
9
10 2 2 10 3 4 5 4 3
```

### 样例输出
```
2
1
2
```

## 题目分析

### 问题理解

本题要求我们在一个序列中找到尽可能多的"有趣子序列"，这些子序列需要满足：

1. **有趣性**：子序列的第一个元素和最后一个元素相等
2. **无冲突性**：任意两个选中的子序列不能重叠

关键是要理解"无冲突"条件的含义。两个区间 $[i, j]$ 和 $[a, b]$ 无冲突意味着：
- 要么第二个区间在第一个区间结束后开始：$a \geq j$
- 要么第一个区间在第二个区间结束后开始：$i \geq b$

这实际上等价于**区间不重叠**的条件。

### 问题转化

我们可以将问题重新表述为：

- 对于序列中的每个数值，找出所有可能的区间 $[i, j]$，其中 $arr[i] = arr[j]$ 且 $i < j$
- 从所有这些区间中，选择尽可能多的互不重叠的区间

这本质上是一个**区间调度问题**（$\texttt{Interval Scheduling Problem}$）。

### 关键观察

1. **区间生成**：对于每个数值，我们只需要考虑相邻出现位置形成的区间，因为这是最优的选择策略
2. **贪心策略**：经典的区间调度问题可以使用贪心算法解决 - 按照区间结束位置排序，然后选择结束最早的且不与已选区间重叠的区间

### 算法思路

1. **预处理**：记录每个数值在序列中出现的所有位置
2. **生成候选区间**：对于每个数值，生成所有相邻位置对形成的区间
3. **贪心选择**：
   - 将所有候选区间按照结束位置升序排序
   - 初始化选择计数为 $1$（第一个区间）
   - 遍历排序后的区间，如果当前区间的开始位置大于等于上一个选中区间的结束位置，则选择该区间

### 复杂度分析

- **时间复杂度**：$O(n \log n)$
  - 预处理：$O(n)$
  - 生成区间：$O(n)$（每个数值最多生成 $n-1$ 个区间）
  - 排序：$O(n \log n)$
  - 贪心选择：$O(n)$
- **空间复杂度**：$O(n)$

## 解题代码

```cpp
// Interesting Sequences

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int testCases;
    cin >> testCases;
    
    while (testCases--) {
        int n;
        cin >> n;
        vector<int> sequence(n);
        
        // 读取序列
        for (int i = 0; i < n; i++) cin >> sequence[i];
        
        // 存储每个数值出现的位置
        unordered_map<int, vector<int>> positions;
        for (int i = 0; i < n; i++) positions[sequence[i]].push_back(i);
        
        vector<pair<int, int>> intervals;
        
        // 为每个数值生成所有可能的区间
        for (auto& entry : positions) {
            const vector<int>& pos = entry.second;
            int size = pos.size();
            // 对于每个数值，生成所有可能的区间 [i, j]
            for (int i = 0; i < size; i++) 
                for (int j = i + 1; j < size; j++) 
                    intervals.emplace_back(pos[i], pos[j]);
        }
        
        // 如果没有区间，直接输出0
        if (intervals.empty()) {
            cout << 0 << "\n";
            continue;
        }
        
        // 按照区间结束位置排序
        sort(intervals.begin(), intervals.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
            return a.second < b.second;
        });
        
        // 贪心选择不重叠的区间
        int count = 1;
        int lastEnd = intervals[0].second;
        
        for (int i = 1; i < intervals.size(); i++) 
            if (intervals[i].first >= lastEnd) {
                count++;
                lastEnd = intervals[i].second;
            }
        
        cout << count << "\n";
    }
    
    return 0;
}
```

## 总结

本题通过将问题转化为区间调度问题，利用贪心算法高效地解决了寻找最大数量无冲突有趣子序列的问题。关键点在于理解无冲突条件等价于区间不重叠，以及采用结束时间最早的贪心选择策略来最大化区间数量。

算法的时间复杂度为 $O(n \log n)$，能够高效处理题目中 $n \leq 100,000$ 的数据规模。
