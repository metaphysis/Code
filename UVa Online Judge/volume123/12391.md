## 题目描述

本题需要计算网球比赛中 $\texttt{Rafa}$ 获胜的概率。网球比赛的计分系统分为四个层次：分、局、盘和比赛。

**分（$\texttt{Point}$）** ：每一分由一名选手发球开始，$\texttt{Rafa}$ 赢得每一分的概率为 $p$ ，无论发球还是接发球。

**局（$\texttt{Game}$）** ：一局的计分采用 $\texttt{0（love）}$、$\texttt{15}$、$\texttt{30}$、$\texttt{40}$ 的计分方式。获胜条件是：
- 至少赢得 $4$ 分
- 至少领先对手 $2$ 分
- 当比分为 $\texttt{40-40（deuce）}$ 时，需要连续赢得 $2$ 分才能获胜

**盘（$\texttt{Set}$）** ：一盘的获胜条件是：
- 至少赢得 $6$ 局
- 至少领先对手 $2$ 局
- 当局分达到 $\texttt{6-6}$ 时，进行抢七（$\texttt{tie-break}$）

**抢七（$\texttt{Tie-break}$）** ：抢七的获胜条件是：
- 至少赢得 $7$ 分
- 至少领先对手 $2$ 分

**比赛（$\texttt{Match}$）** ：比赛采用三盘两胜制，先赢得 $2$ 盘的选手获胜。

## 输入输出

**输入** ：每个测试用例包含一个浮点数 $p$ （$0 \le p \le 1$），表示 $\texttt{Rafa}$ 赢得一分的概率。输入以 $p = -1$ 结束。

**输出** ：对于每个测试用例，输出一行三个概率值，分别表示 $\texttt{Rafa}$ 赢得一局、一盘和整场比赛的概率。结果需精确到绝对误差 $10^{-6}$ 以内。

## 解题思路

### 1. 问题分析

本题需要计算三个层次的获胜概率：
1. **赢得一局的概率** $P_g$
2. **赢得一盘的概率** $P_s$
3. **赢得比赛的概率** $P_m$

这三个概率之间存在依赖关系：
- $P_s$ 依赖于 $P_g$ 和抢七获胜概率 $P_t$
- $P_m$ 依赖于 $P_s$

### 2. 赢得一局的概率计算

一局的获胜有两种情况：

**(1) 直接获胜** ：在比分未达到 $\texttt{deuce}$ 前获胜，即 $\texttt{Rafa}$ 赢得 $4$ 分，对手赢得 $0$ 、$1$ 或 $2$ 分：

$$
P_{\text{direct}} = p^4 + \binom{4}{1} p^4 q + \binom{5}{2} p^4 q^2
$$

其中 $q = 1-p$ 。

**(2) 通过 $\texttt{deuce}$ 获胜** ：比分达到 $\texttt{40-40}$ 后，需要连续赢得 $2$ 分：
- 达到 $\texttt{deuce}$ 的概率：$\binom{6}{3} p^3 q^3$
- $\texttt{deuce}$ 后获胜的概率：$\frac{p^2}{p^2 + q^2}$

$$
P_{\text{deuce}} = \binom{6}{3} p^3 q^3 \times \frac{p^2}{p^2 + q^2}
$$

**总概率** ：

$$
P_g = P_{\text{direct}} + P_{\text{deuce}}
$$

### 3. 赢得抢七的概率计算

抢七的获胜也有两种情况：

**(1) 直接获胜** ：$\texttt{Rafa}$ 赢得 $7$ 分，对手赢得 $0$ 到 $5$ 分：

$$
P_{\text{tie-direct}} = \sum_{k=0}^{5} \binom{6+k}{k} p^7 q^k
$$

**(2) 通过 $\texttt{6-6}$ 后获胜** ：比分达到 $\texttt{6-6}$ 后，需要连续赢得 $2$ 分：
- 达到 $\texttt{6-6}$ 的概率：$\binom{12}{6} p^6 q^6$
- 之后获胜的概率：$\frac{p^2}{p^2 + q^2}$

$$
P_{\text{tie-66}} = \binom{12}{6} p^6 q^6 \times \frac{p^2}{p^2 + q^2}
$$

**总概率** ：

$$
P_t = P_{\text{tie-direct}} + P_{\text{tie-66}}
$$

### 4. 赢得一盘的概率计算

一盘的获胜情况较为复杂，需要使用动态规划。设状态 $dp[i][j]$ 表示 $\texttt{Rafa}$ 赢得 $i$ 局，对手赢得 $j$ 局的概率。

**状态转移** ：
1. 如果 $i \ge 6$ 且 $i-j \ge 2$ ，则 $\texttt{Rafa}$ 获胜
2. 如果 $j \ge 6$ 且 $j-i \ge 2$ ，则 $\texttt{Rafa}$ 失败
3. 如果 $i = 6$ 且 $j = 6$ ，则进入抢七，获胜概率为 $P_t$
4. 否则，继续比赛：
   - 以概率 $P_g$ 转移到 $(i+1, j)$
   - 以概率 $1-P_g$ 转移到 $(i, j+1)$

通过动态规划累加所有获胜路径的概率，即可得到 $P_s$ 。

### 5. 赢得比赛的概率计算

比赛为三盘两胜制，设赢得一盘的概率为 $P_s$ ，则：
- 以 $\texttt{2-0}$ 获胜的概率：$P_s^2$
- 以 $\texttt{2-1}$ 获胜的概率：$2 \times P_s^2 \times (1-P_s)$

**总概率** ：

$$
P_m = P_s^2 + 2 \times P_s^2 \times (1-P_s) = P_s^2 \times (3 - 2P_s)
$$

### 6. 算法实现细节

1. **组合数计算** ：使用函数 `comb(n, k)` 计算组合数，注意使用浮点数避免溢出
2. **动态规划** ：使用二维数组 `dp[13][13]` ，因为最多进行 $12$ 局（抢七前）
3. **精度控制** ：使用 `double` 类型，输出时设置精度为 $11$ 位小数

## 时间复杂度

- 每个测试用例的计算复杂度为 $O(1)$ ，因为组合数和动态规划的状态数都是常数级别
- 可以处理大量测试用例

#include <bits/stdc++.h>
using namespace std;

// 计算组合数 C(n, k)
double comb(int n, int k) {
    if (k < 0 || k > n) return 0;
    double res = 1.0;
    for (int i = 1; i <= k; i++) {
        res = res * (n - k + i) / i;
    }
    return res;
}

// 计算赢一局的概率
double winGame(double p) {
    double q = 1 - p;
    
    // 直接获胜的情况
    double directWin = 0;
    directWin += pow(p, 4);                    // 4:0
    directWin += 4 * pow(p, 4) * q;            // 4:1
    directWin += 10 * pow(p, 4) * pow(q, 2);   // 4:2
    
    // 达到 deuce 的情况
    double reachDeuce = 20 * pow(p, 3) * pow(q, 3);  // C(6,3)=20
    double winAfterDeuce = pow(p, 2) / (pow(p, 2) + pow(q, 2));
    
    return directWin + reachDeuce * winAfterDeuce;
}

// 计算赢抢七的概率
double winTiebreak(double p) {
    double q = 1 - p;
    
    // 直接获胜（对手得分 0-5）
    double directWin = 0;
    directWin += pow(p, 7);                     // 7:0
    directWin += 7 * pow(p, 7) * q;             // 7:1
    directWin += 28 * pow(p, 7) * pow(q, 2);    // 7:2
    directWin += 84 * pow(p, 7) * pow(q, 3);    // 7:3
    directWin += 210 * pow(p, 7) * pow(q, 4);   // 7:4
    directWin += 462 * pow(p, 7) * pow(q, 5);   // 7:5
    
    // 达到 6-6 后继续比赛的情况
    double reach66 = 924 * pow(p, 6) * pow(q, 6);  // C(12,6)=924
    double winAfter66 = pow(p, 2) / (pow(p, 2) + pow(q, 2));
    
    return directWin + reach66 * winAfter66;
}

// 计算赢一盘的概率（使用DP）
double winSetDP(double pg, double pt) {
    // dp[i][j]: Rafa赢i局，对手赢j局的概率
    vector<vector<double>> dp(13, vector<double>(13, 0.0));
    dp[0][0] = 1.0;
    
    double winProb = 0.0;
    
    for (int total = 0; total < 24; total++) {  // 最多12+12局
        for (int i = 0; i <= min(12, total); i++) {
            int j = total - i;
            if (j > 12 || dp[i][j] == 0) continue;
            
            // 检查是否已结束
            if (i >= 6 && i - j >= 2) {
                winProb += dp[i][j];
                continue;
            }
            if (j >= 6 && j - i >= 2) {
                continue;  // 已输，不再转移
            }
            if (i == 6 && j == 6) {
                // 进入抢七
                winProb += dp[i][j] * pt;
                continue;
            }
            
            // 继续比赛
            if (i < 12 && j < 12) {
                dp[i+1][j] += dp[i][j] * pg;
                dp[i][j+1] += dp[i][j] * (1 - pg);
            }
        }
    }
    
    return winProb;
}

int main() {
    double p;
    while (cin >> p, p != -1) {
        double pg = winGame(p);
        double pt = winTiebreak(p);
        double ps = winSetDP(pg, pt);
        double pm = ps * ps * (3 - 2 * ps);
        
        cout << fixed << setprecision(11) 
             << pg << " " << ps << " " << pm << endl;
    }
    return 0;
}
