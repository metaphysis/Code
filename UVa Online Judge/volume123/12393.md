[UVa 12393 Non-negative Partial Sums](https://blog.csdn.net/metaphysis/article/details/154993742)

## 题目描述

给定一个包含 $n$ 个数字的序列 $a_0, a_1, \ldots, a_{n-1}$。一个循环右移 $k$ 位（$0 \leq k \leq n-1$）会得到如下序列：

$$a_k, a_{k+1}, \ldots, a_{n-1}, a_0, a_1, \ldots, a_{k-1}$$

问题是：有多少个循环移位满足对于所有 $i$（$1 \leq i \leq n$），前 $i$ 个数的和都大于等于零？

### 输入格式

每个测试用例包含两行：
- 第一行：整数 $n$（$1 \leq n \leq 10^6$），表示序列长度
- 第二行：$n$ 个整数 $a_0, a_1, \ldots, a_{n-1}$（$-1000 \leq a_i \leq 1000$）
- 输入以一行包含 $0$ 结束

### 输出格式

对每个测试用例，输出一行，表示满足条件的循环移位的个数。

### 样例输入
```
3
2 2 1
3
-1 1 1
1
-1
0
```

### 样例输出
```
3
2
0
```

## 题目分析

本题需要统计所有循环移位中，满足**所有前缀和都非负**的移位个数。

### 关键观察

1. **循环移位转化为线性问题**：将原序列复制一份接在后面，形成长度为 $2n$ 的数组，这样每个循环移位就对应新数组中的一个长度为 $n$ 的连续子数组

2. **前缀和条件**：对于移位 $k$，我们需要检查：
   - 前 $1$ 个数的和：$a_k \geq 0$
   - 前 $2$ 个数的和：$a_k + a_{k+1} \geq 0$
   - ...
   - 前 $n$ 个数的和：$a_k + \cdots + a_{k+n-1} \geq 0$

3. **数学转化**：定义前缀和数组 $S$，其中 $S[i] = a_0 + a_1 + \cdots + a_i$，并约定 $S[-1] = 0$。那么对于移位 $k$，需要满足：
   $$\min_{k \leq j < k+n} S[j] \geq S[k-1]$$

### 解题思路

1. **构造扩展数组**：将原数组复制一份，形成长度为 $2n$ 的数组
2. **计算前缀和**：计算扩展数组的前缀和
3. **使用单调队列**：维护一个滑动窗口大小为 $n$ 的最小值队列
4. **统计有效移位**：对于每个可能的移位 $k$，检查窗口内的最小前缀和是否满足条件

### 算法步骤

1. 如果 $n = 1$，直接判断单个元素是否非负
2. 构造长度为 $2n$ 的扩展数组
3. 计算扩展数组的前缀和
4. 初始化单调队列，维护前 $n-1$ 个元素的最小值
5. 对于每个移位位置，维护队列并检查条件：
   - 移除不在当前窗口的元素
   - 维护队列的单调性
   - 检查最小值条件

### 时间复杂度

- 每个元素最多入队和出队一次
- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

## 代码实现

```cpp
// Non-negative Partial Sums
// UVa ID: 12393
// Verdict: Accepted
// Submission Date: 2025-11-18
// UVa Run Time: 0.210s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2e6 + 10;
int n;
int a[MAXN];
long long prefixSum[MAXN];

int main() {
    while (scanf("%d", &n) == 1 && n != 0) {
        for (int i = 0; i < n; i++) {
            scanf("%d", &a[i]);
            a[i + n] = a[i];
        }
        
        // 单独处理 n = 1 的情况
        if (n == 1) {
            printf("%d\n", a[0] >= 0 ? 1 : 0);
            continue;
        }
        
        int len = 2 * n;
        prefixSum[0] = a[0];
        for (int i = 1; i < len; i++)
            prefixSum[i] = prefixSum[i - 1] + a[i];
        
        deque<int> dq;
        // 初始化前 n-1 个元素
        for (int i = 0; i < n - 1; i++) {
            while (!dq.empty() && prefixSum[dq.back()] >= prefixSum[i])
                dq.pop_back();
            dq.push_back(i);
        }
        
        int count = 0;
        for (int i = n - 1; i < len - 1; i++) {
            // 维护单调队列：移除队尾比当前大的元素
            while (!dq.empty() && prefixSum[dq.back()] >= prefixSum[i])
                dq.pop_back();
            dq.push_back(i);
            
            // 移除不在窗口内的元素 [i-n+1, i]
            while (!dq.empty() && dq.front() < i - n + 1)
                dq.pop_front();
            
            // 检查移位 k = i - n + 1 是否满足条件
            // 条件：min_{j=k}^{k+n-1} prefixSum[j] >= prefixSum[k-1]
            long long base = (i - n + 1 == 0) ? 0 : prefixSum[i - n];
            if (prefixSum[dq.front()] >= base)
                count++;
        }
        printf("%d\n", count);
    }
    return 0;
}
```

## 总结

本题通过将循环问题转化为线性问题，利用单调队列高效维护滑动窗口最小值，从而在 $O(n)$ 时间内解决问题。关键在于理解前缀和条件与单调队列的结合应用，以及边界情况的特殊处理。
