## 题目描述

在 $\texttt{Remoteland}$ 共和国，人们每年庆祝独立日，但已经没人记得确切日期。唯一记得的是：自独立至今的天数 $D$ 是一个**完全平方数**，并且它是所有小于等于 $n$ 的**不同整数**的乘积中**最大**的完全平方数。

由于 Remoteland 的一年有 $1000000007$ 天，他们只需要 $D$ 对 $1000000007$ 取模的结果。注意，他们关心的是最大的 $D$ 本身，而不是取模后的最大值。

**输入**  
每个测试用例包含一个整数 $n$（$1 \leq n \leq 10000000$），输入以一行 `0` 结束。

**输出**  
对每个 $n$，输出 $D \bmod 1000000007$。

---

## 题目分析

我们需要从 $1$ 到 $n$ 中选择若干个不同的整数，使它们的乘积是尽可能大的完全平方数。

### 关键观察

1. **完全平方数的性质**  
   一个数是完全平方数，当且仅当它的所有质因子的指数都是偶数。

2. **问题转化**  
   考虑所有 $1$ 到 $n$ 的数的乘积 $n!$。  
   我们想从 $n!$ 中移除一些因子，使得剩下的乘积是完全平方数，并且尽可能大。  
   这等价于：  
   对 $n!$ 做质因数分解，将每个质因子的指数调整为**不大于它的最大偶数**，然后计算这个新乘积。

3. **数学形式**  
   设 $n! = \prod p^{e_p}$，则  
   $$
   D = \prod p^{e_p - (e_p \bmod 2)}
   $$
   即如果 $e_p$ 是偶数，保留 $p^{e_p}$；如果是奇数，保留 $p^{e_p - 1}$。

---

## 解题思路

### 1. 计算 $n!$ 的质因数分解

使用 **$\texttt{Legendre}$ 公式**计算质数 $p$ 在 $n!$ 中的指数：
$$
e_p = \left\lfloor \frac{n}{p} \right\rfloor + \left\lfloor \frac{n}{p^2} \right\rfloor + \left\lfloor \frac{n}{p^3} \right\rfloor + \dots
$$

### 2. 优化处理范围

- 对于 $p > n$，显然不需要考虑。
- 对于 $p > n/2$，有 $e_p = 1$（奇数），所以这些质数不会出现在最终结果中（指数变为 0）。
- 因此，我们只需要处理 $p \leq n/2$ 的质数。

### 3. 算法步骤

1. 预处理所有 $\leq 5000000$ 的质数（因为 $n \leq 10^7$，所以 $n/2 \leq 5000000$）。
2. 对每个质数 $p \leq n/2$：
   - 用 $\texttt{Legendre}$ 公式计算 $e_p$。
   - 如果 $e_p$ 是奇数，则 $e_p \gets e_p - 1$。
   - 将 $p^{e_p}$ 乘到结果中（模 $10^9+7$）。
3. 输出结果。

---

## 复杂度分析

- **筛法**：$O(N \log \log N)$，$N = 5\\,000\\,000$，可接受。
- **质因数指数计算**：对每个质数 $p$，需要 $O(\log_p n)$ 次除法，总复杂度约为 $O(\pi(n/2) \cdot \log n) \approx O(\frac{n}{\log n} \cdot \log n) = O(n)$。
- 整体在 $n \leq 10^7$ 范围内可行。

## 代码实现

```cpp
// Remoteland

#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;
const int MAXN = 5000000;

vector<int> primes;
bool isPrime[MAXN + 1];

void sieve() {
    fill(isPrime, isPrime + MAXN + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i <= MAXN; i++) {
        if (isPrime[i]) {
            primes.push_back(i);
            for (long long j = (long long)i * i; j <= MAXN; j += i)
                isPrime[j] = false;
        }
    }
}

long long modPow(long long a, long long b, long long mod) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

int solve(int n) {
    long long result = 1;
    for (int p : primes) {
        if (2 * p > n) break;
        long long exp = 0;
        long long tmp = n;
        while (tmp >= p) {
            tmp /= p;
            exp += tmp;
        }
        if (exp % 2 == 1) exp--;
        result = result * modPow(p, exp, MOD) % MOD;
    }
    return result;
}

int main() {
    sieve();
    int n;
    while (scanf("%d", &n) == 1 && n != 0) {
        printf("%d\n", solve(n));
    }
    return 0;
}
```

## 总结

本题的关键在于将“最大完全平方数乘积”问题转化为**对阶乘进行质因数分解并调整指数为偶数**的问题。通过质数筛法和 $\texttt{Legendre}$ 公式，我们可以高效地计算出结果，并利用数学观察优化处理范围，使得算法在 $n \leq 10^7$ 的范围内可行。
