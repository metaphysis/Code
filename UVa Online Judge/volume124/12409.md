## 题目描述

本题来源于一个有趣的游戏。给定一个 $R \times C$ 的网格，每个格子中放有若干硬币（数量范围为 $[0, 10^9]$）。两名玩家轮流操作，每次操作选择一个**非空**的格子，从中取出**一枚或多枚硬币**，将这些硬币全部移动到该格子**正右方**或**正下方**的相邻格子中（不能拆分移动）。最右边一列的格子不能向右移动，最下面一行的格子不能向下移动，右下角的格子无法进行任何操作。无法进行任何操作的玩家输掉游戏。$\texttt{Pinky}$ 先手，双方都采取最优策略，判断 $\texttt{Pinky}$ 是否能获胜。

## 题目分析

### 游戏性质

首先需要理解这个游戏的基本结构。游戏进行的过程中，硬币只能向右或向下移动，这意味着硬币的移动方向是**单向的**——它们只会越来越靠近右下角。最终，所有硬币都会聚集到右下角格子，因为只有那里无法再移动。

这是一个典型的**公平组合博弈**问题，我们可以尝试将其转化为已知的博弈模型。注意每次操作只能从**一个**格子移动**若干**硬币到**一个**相邻格子（右或下），这种“从一个堆中取走若干物品放到另一个堆”的模型，往往与 **$\texttt{Nim}$ 游戏** 或其变种有关。

### 关键观察

考虑从某个格子 $(i, j)$ 到达终点 $(R-1, C-1)$（下标从 $0$ 开始）所需要的**最小步数**。由于只能向右或向下移动，这个最小步数就是曼哈顿距离：

$$
d(i, j) = (R - 1 - i) + (C - 1 - j)
$$

这个距离 $d(i, j)$ 的**奇偶性**是解决问题的核心。

为什么奇偶性如此重要？因为每一次移动都会改变硬币所在格子的 $d$ 值：

- 如果从 $(i, j)$ 移动到 $(i, j+1)$（向右），新的 $d = d(i, j) - 1$
- 如果从 $(i, j)$ 移动到 $(i+1, j)$（向下），新的 $d = d(i, j) - 1$

也就是说，**每次操作都会使被移动硬币的 $d$ 值减少恰好 $1$**。因此，一枚硬币从起点到终点的过程中，$d$ 值会从初始值逐渐递减到 $0$。每移动一次，$d$ 的奇偶性就会改变一次。

### 博弈转化

设 $S_{\text{odd}}$ 为所有 $d(i, j)$ 为奇数的格子集合，$S_{\text{even}}$ 为所有 $d(i, j)$ 为偶数的格子集合。

观察一次操作的影响：

- 如果从 $S_{\text{odd}}$ 中的一个格子移动硬币到 $S_{\text{even}}$ 中的一个格子（因为减少 $1$ 改变奇偶性），那么这些硬币离开了 $S_{\text{odd}}$，进入了 $S_{\text{even}}$。
- 如果从 $S_{\text{even}}$ 中的一个格子移动硬币，它们会进入 $S_{\text{odd}}$。

但这还不是 $\texttt{Nim}$ 游戏。我们需要一个更巧妙的观点：

实际上，我们可以将每个 $S_{\text{odd}}$ 格子中的硬币数量视为一个独立的 **$\texttt{Nim}$ 堆**。理由如下：

1. 当玩家从 $S_{\text{odd}}$ 格子移动硬币时，这些硬币离开了 $S_{\text{odd}}$（进入 $S_{\text{even}}$），相当于**从对应的 $\texttt{Nim}$ 堆中取出任意正数量的物品**（这些物品被“丢弃”出 $\texttt{Nim}$ 游戏）。
2. 当玩家从 $S_{\text{even}}$ 格子移动硬币时，这些硬币进入了 $S_{\text{odd}}$，相当于**向对应的 $\texttt{Nim}$ 堆中添加物品**。但在公平博弈中，允许“增加”操作会破坏 $\texttt{Nim}$ 模型。然而，这里有一个关键：如果一个玩家从 $S_{\text{even}}$ 向 $S_{\text{odd}}$ 添加硬币，对方在下一次回合**一定可以**将这些新添加的硬币再次移回 $S_{\text{even}}$（因为从 $S_{\text{odd}}$ 移动一步必然进入 $S_{\text{even}}$）。这种对称性使得 $S_{\text{even}}$ 中的硬币可以被视作“安全的”——它们不会真正影响胜负，因为任何增加都可以被对方立即撤销。

3. 更严格的分析（$\texttt{Sprague–Grundy}$ 定理）可以证明：每个格子的 $\texttt{Grundy}$ 数等于其到终点的曼哈顿距离的奇偶性决定的值。对于 $d$ 为偶数的格子，$\texttt{Grundy}$ 数为 $0$；对于 $d$ 为奇数的格子，$\texttt{Grundy}$ 数等于该格子中的硬币数量。因此，整个游戏的 $\texttt{Grundy}$ 数就是所有 $d$ 为奇数的格子中硬币数量的异或和。

### 结论

游戏胜负由以下规则判定：

$$
\text{胜负} = \bigoplus_{(i,j) \in S_{\text{odd}}} coins[i][j] \neq 0
$$

即：对所有曼哈顿距离 $d(i, j)$ 为奇数的格子中的硬币数量进行**异或运算**，如果结果不为 $0$，则先手（$\texttt{Pinky}$）获胜；否则先手失败。

## 解题思路

根据上述结论，解题步骤非常简单：

1. 对于每个测试用例，读取网格的行数 $R$ 和列数 $C$。
2. 遍历所有格子 $(i, j)$，$i$ 从 $0$ 到 $R-1$，$j$ 从 $0$ 到 $C-1$。
3. 对于每个格子，计算到右下角的曼哈顿距离：
$$
   d = (R - 1 - i) + (C - 1 - j)
$$
4. 如果 $d$ 是奇数，将该格子中的硬币数量与当前的异或和进行异或运算。
5. 遍历结束后，若异或和不为 $0$，则输出 $\texttt{win}$，否则输出 $\texttt{lose}$。

### 复杂度分析

- 时间复杂度：$O(R \times C)$，每个格子仅处理一次。
- 空间复杂度：$O(1)$ 额外空间（输入可以边读边处理，无需存储整个网格）。

由于题目保证 $R \times C \leq 50000$，这个复杂度是完全可行的。

### 注意事项

- 硬币数量最大可达 $10^9$，需要使用 $\texttt{long long}$ 类型存储。
- 异或运算可以直接应用在 $\texttt{long long}$ 类型上。
- 输入量较大，建议使用 $\texttt{scanf}$ 提高读取效率。

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    for (int caseNum = 1; caseNum <= T; ++caseNum) {
        int R, C;
        scanf("%d %d", &R, &C);
        
        long long xorSum = 0;
        
        for (int i = 0; i < R; ++i) {
            for (int j = 0; j < C; ++j) {
                long long coins;
                scanf("%lld", &coins);
                
                // 计算到右下角的曼哈顿距离
                int distToEnd = (R - 1 - i) + (C - 1 - j);
                
                // 只考虑距离为奇数的单元格
                if (distToEnd % 2 == 1) {
                    xorSum ^= coins;
                }
            }
        }
        
        if (xorSum != 0)
            printf("Case %d: win\n", caseNum);
        else
            printf("Case %d: lose\n", caseNum);
    }
    return 0;
}
