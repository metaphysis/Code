## 题目描述

本题要求实现一个 **$\texttt{mini-lua}$** 语言的词法分析器。 $\texttt{mini-lua}$ 是 $\texttt{Lua 5.1}$ 的一个子集，主要设计用于算法实现。词法分析器的任务是将输入的 $\texttt{mini-lua}$ 程序分解为一系列 **词法单元 ($\texttt{token}$)** ，并按照指定格式输出（注释除外）。

### 词法单元类型

$\texttt{mini-lua}$ 中共定义了六种词法单元：

1.  **保留字 ($\texttt{RESERVED}$)** ：包括 `and` , `break` , `do` , `else` , `elseif` , `end` , `false` , `for` , `function` , `if` , `in` , `local` , `nil` , `not` , `or` , `repeat` , `return` , `then` , `true` , `until` , `while` 。注意区分大小写。

2.  **数字 ($\texttt{NUMBER}$)** ：分为整数和浮点数。
    *   整数：十进制（如 $123$ ）或十六进制（如 $0x\texttt{abcF}$ ，前缀 $\texttt{0x}$ 或 $\texttt{0X}$ ，十六进制数字不区分大小写）。前导零被忽略。
    *   浮点数：十进制表示，支持科学计数法（如 $1.23e2$ ， $4e-3$ ， $.2e3$ ）。必须有小数点或指数部分。若省略整数部分（如 $.2$ ），则小数点后必须有数字。不支持十六进制浮点数。

3.  **字符串 ($\texttt{STRING}$)** ：由双引号 `"` 或单引号 `'` 包围，支持四种转义序列： `\"` , `\'` , `\\` , `\n` 。字符串中不能包含实际的换行符。

4.  **符号 ($\texttt{SYMBOL}$)** ：包括各种运算符和分隔符，如 `+` , `-` , `*` , `/` , `%` , `~` , `#` , `==` , `~=` , `<=` , `>=` , `<` , `>` , `=` , `(` , `)` , `{` , `}` , `[` , `]` , `;` , `:` , `,` , `.` , `..` , `...` 。

5.  **名称 ($\texttt{NAME}$)** ：标识符，以字母或下划线 `_` 开头，后跟字母、数字或下划线。保留字不能用作名称。

6.  **行结束 ($\texttt{EOL}$)** ：物理行的结束（换行符）。注释后的换行符也产生 `EOL` 词法单元。

7.  **注释 ($\texttt{COMMENT}$)** ：以 `--` 开始，持续到行尾，不产生输出词法单元。

### 重要规则

*   **贪婪匹配**：当输入可被多种方式分割时，总是优先匹配尽可能长的词法单元。例如， `abc123<=x` 应被分割为 `abc123` （$\texttt{NAME}$）、 `<=` （$\texttt{SYMBOL}$）、 `x` （$\texttt{NAME}$），而不是 `abc` 、 `123` 、 `<` 、 `=` 、 `x` 等。
*   **空格忽略**：空格、制表符等空白字符在词法分析中被忽略，不产生词法单元。
*   **负数处理**：像 `-34` 这样的表达式被分解为两个词法单元： `-` （$\texttt{SYMBOL}$）和 `34` （$\texttt{NUMBER}$）。同样， `+7e8` 被分解为 `+` （$\texttt{SYMBOL}$）和 `7e8` （$\texttt{NUMBER}$）。
*   **输入保证**：输入程序只包含 $\texttt{ASCII}$ 字符，且是合法的 $\texttt{mini-lua}$ 程序。

### 输入输出格式

**输入**：一个有效的 $\texttt{mini-lua}$ 程序。

**输出**：所有非注释词法单元，每行一个，格式为 `[TYPE] token` 。其中 `TYPE` 是词法单元类型（ `RESERVED` , `NUMBER` , `STRING` , `SYMBOL` , `NAME` , `EOL` ）， `token` 是词法单元的内容。对于 `EOL` 类型，只输出 `[EOL]` ， `token` 部分为空。

## 题目分析

本题是一个典型的 **词法分析 ($\texttt{Lexical Analysis}$)** 问题，也称为 **扫描 ($\texttt{Scanning}$)** 或 **分词 ($\texttt{Tokenization}$)** 。我们需要根据给定的词法规则，将字符序列转换为有意义的词法单元序列。

### 核心难点

1.  **词法单元的多样性**：有七种主要类型（包括注释），每种都有特定的构成规则，尤其是数字和字符串的规则比较复杂。
2.  **贪婪匹配原则**：要求匹配尽可能长的词法单元，这对匹配顺序和逻辑提出了要求。例如，符号 `.` , `..` , `...` 需要正确处理，避免将 `..` 误识别为两个 `.` 。
3.  **上下文敏感**：某些字符的含义取决于上下文。例如，单独的 `-` 是符号，但 `-` 后面跟着数字时，它们分别属于两个词法单元。注释 `--` 也容易与单个 `-` 混淆。
4.  **状态管理**：分析过程中需要跟踪当前状态，例如是否在字符串中、是否在注释中、是否在匹配一个数字等。

### 解题思路

我们可以采用 **手工编码的确定有限自动机 ($\texttt{DFA}$)** 方法，即编写一个循环，逐个字符读取输入，根据当前字符和上下文决定进入何种匹配模式。

**整体流程**：

1.  **初始化**：设置当前位置指针 `i = 0` ，准备存储词法单元的列表 `tokens` 。
2.  **主循环**：当 `i` 未到达输入末尾时，执行以下步骤：
    *   **跳过空白字符**：空格、制表符等。
    *   **处理注释**：如果当前字符是 `-` 且下一个字符也是 `-` ，则跳过直到行尾（换行符前）。
    *   **处理换行符 ($\texttt{EOL}$)**：直接产生 `[EOL]` 词法单元。
    *   **处理字符串**：以 `"` 或 `'` 开头，持续读取直到匹配到对应的结束引号，并处理转义序列。
    *   **处理数字**：以数字或 `.`（且后面跟着数字）开头，根据规则匹配整数（十进制或十六进制）或浮点数（含科学计数法）。
    *   **处理符号**：尝试匹配预定义的符号列表。 **关键是符号列表必须按长度降序排列** ，以确保贪婪匹配（例如先尝试 `...` ，再尝试 `..` ，最后尝试 `.` ）。
    *   **处理名称/保留字**：以字母或下划线开头，读取连续的字母、数字、下划线，然后判断是否为保留字。
3.  **输出**：遍历收集到的 `tokens` ，按格式输出。

**数据结构设计**：

*   使用 `unordered_set<string>` 存储保留字，便于 $O(1)$ 时间判断。
*   使用 `vector<string>` 存储符号列表，并按长度降序排列。
*   使用 `vector<pair<string, string>>` 存储词法单元，每个元素是（类型，内容）对。

**细节处理**：

*   **字符串转义**：遇到反斜杠 `\` 时，检查下一个字符是否为允许的转义字符（ `\` , `"` , `'` , `n` ），如果是则跳过两个字符，否则按普通字符处理（题目保证输入合法）。
*   **数字识别**：需要区分几种情况：
    *   以 `0x` 或 `0X` 开头的十六进制整数。
    *   十进制整数。
    *   十进制浮点数（可能包含小数点）。
    *   科学计数法（可能包含 `e` 或 `E` 及可选的 `+` / `-` 符号）。
    *   注意 `.` 开头且后面跟着数字的情况（如 `.123` ）。
*   **符号匹配顺序**：将多字符符号（ `...` , `..` , `==` , `~=` , `<=` , `>=` ）放在单字符符号之前，确保优先匹配更长的序列。

## 算法复杂度

*   **时间复杂度**： $O(n)$ ，其中 $n$ 是输入程序的字符数。每个字符最多被处理一次。
*   **空间复杂度**： $O(n)$ ，主要用于存储词法单元列表。

```cpp
// (Jiandan) Mua(I)

#include <bits/stdc++.h>
using namespace std;

// 保留字集合
const unordered_set<string> reservedWords = {
    "and", "break", "do", "else", "elseif", "end",
    "false", "for", "function", "if", "in", "local",
    "nil", "not", "or", "repeat", "return", "then",
    "true", "until", "while"
};

// 符号集合（按长度降序排列，确保贪婪匹配）
const vector<string> symbols = {
    "...", "..",      // 三字符和两字符符号在前
    "==", "~=", "<=", ">=",
    "+", "-", "*", "/", "%", "~", "#",
    "<", ">", "=",
    "(", ")", "{", "}", "[", "]",
    ";", ":", ",", "."
};

// 辅助函数：判断字符是否为字母
bool isAlpha(char ch) {
    return (ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z');
}

// 辅助函数：判断字符是否为数字
bool isDigit(char ch) {
    return ch >= '0' && ch <= '9';
}

// 辅助函数：判断字符是否为十六进制数字
bool isHexDigit(char ch) {
    return isDigit(ch) || (ch >= 'a' && ch <= 'f') || (ch >= 'A' && ch <= 'F');
}

// 辅助函数：判断字符是否为空白（不包括换行）
bool isSpace(char ch) {
    return ch == ' ' || ch == '\t' || ch == '\r';
}

// 主词法分析函数
vector<pair<string, string>> lex(const string& program) {
    vector<pair<string, string>> tokens;
    int n = program.size();
    int i = 0;

    while (i < n) {
        // 跳过空白
        if (isSpace(program[i])) {
            i++;
            continue;
        }

        // 处理注释
        if (i + 1 < n && program[i] == '-' && program[i + 1] == '-') {
            while (i < n && program[i] != '\n') i++;
            // 注释后的换行符由后续循环处理
            continue;
        }

        // 处理换行（EOL）
        if (program[i] == '\n') {
            tokens.emplace_back("EOL", "");
            i++;
            continue;
        }

        // 处理字符串
        if (program[i] == '"' || program[i] == '\'') {
            char quote = program[i];
            int start = i;
            i++; // 跳过开头的引号
            while (i < n && program[i] != quote) {
                if (program[i] == '\\') {
                    // 处理转义字符
                    if (i + 1 < n && (program[i + 1] == '\\' || program[i + 1] == '"' ||
                                      program[i + 1] == '\'' || program[i + 1] == 'n'))
                        i += 2;
                    else
                        i++; // 非法转义，按普通字符处理（根据题目，输入合法）
                } else
                    i++;
            }
            if (i < n) i++; // 跳过结尾的引号
            tokens.emplace_back("STRING", program.substr(start, i - start));
            continue;
        }

        // 处理数字（整数、浮点数、十六进制）
        if (isDigit(program[i]) || (program[i] == '.' && i + 1 < n && isDigit(program[i + 1]))) {
            int start = i;
            bool isHex = false;
            bool isFloat = false;

            // 检查十六进制前缀
            if (program[i] == '0' && i + 1 < n && (program[i + 1] == 'x' || program[i + 1] == 'X')) {
                isHex = true;
                i += 2;
                while (i < n && isHexDigit(program[i])) i++;
            } else {
                // 十进制整数或浮点数
                while (i < n && isDigit(program[i])) i++;
                if (i < n && program[i] == '.') {
                    isFloat = true;
                    i++;
                    while (i < n && isDigit(program[i])) i++;
                }
                if (i < n && (program[i] == 'e' || program[i] == 'E')) {
                    isFloat = true;
                    i++;
                    if (i < n && (program[i] == '+' || program[i] == '-')) i++;
                    while (i < n && isDigit(program[i])) i++;
                }
            }
            tokens.emplace_back("NUMBER", program.substr(start, i - start));
            continue;
        }

        // 处理符号（按长度降序匹配，确保贪婪）
        bool foundSymbol = false;
        for (const string& sym : symbols) {
            if (program.compare(i, sym.size(), sym) == 0) {
                tokens.emplace_back("SYMBOL", sym);
                i += sym.size();
                foundSymbol = true;
                break;
            }
        }
        if (foundSymbol) continue;

        // 处理名称和保留字
        if (isAlpha(program[i]) || program[i] == '_') {
            int start = i;
            while (i < n && (isAlpha(program[i]) || isDigit(program[i]) || program[i] == '_')) i++;
            string name = program.substr(start, i - start);
            string type = reservedWords.count(name) ? "RESERVED" : "NAME";
            tokens.emplace_back(type, name);
            continue;
        }

        // 如果遇到无法识别的字符，跳过（根据题目，输入合法，不会发生）
        i++;
    }

    return tokens;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string line;
    string program;
    while (getline(cin, line)) {
        program += line + '\n'; // 保留换行符以识别 EOL
    }

    auto tokens = lex(program);
    for (const auto& [type, token] : tokens) {
        if (type == "EOL")
            cout << "[EOL]\n";
        else
            cout << "[" << type << "] " << token << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于 **理解各种词法单元的构成规则** 并 **实现贪婪匹配** 。通过手工编写状态机，按优先级处理不同情况，我们可以高效地完成词法分析任务。注意符号匹配顺序和数字、字符串的边界条件处理是容易出错的地方。本题为后续的语法分析等环节奠定了基础。
