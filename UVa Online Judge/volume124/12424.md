[UVa 12424 Answering Queries on a Tree]()

## 题目概述

给定一棵有 $N$ 个节点的树，节点编号从 $1$ 到 $N$ ，每个节点初始有一个颜色 $C_i$ （颜色值为 $1$ 到 $10$ 之间的整数）。需要处理 $M$ 个操作，操作有两种类型：

1. **修改操作** `0 u c` ：将节点 $u$ 的颜色改为 $c$ 。
2. **查询操作** `1 u v` ：输出从节点 $u$ 到节点 $v$ 的**唯一路径**上，出现次数最多的颜色的出现次数。

**数据范围**：
* $1 \le T \le 10$ （测试用例数量）
* $1 \le N, M \le 10^5$
* $1 \le C_i, c \le 10$
* 树是无向连通图，保证输入是一棵树。

## 题目分析与解题思路

### 问题本质

这是一个**树上动态路径查询**问题，需要支持：
* **单点更新**：修改某个节点的颜色。
* **路径查询**：查询一条路径上所有颜色出现次数的最大值。

颜色种类很少，只有 $10$ 种，这是本题的关键突破口。

### 核心思路

由于颜色种类固定且很少（ $10$ 种），我们可以对**每种颜色独立维护其是否在某个节点出现**。对于查询操作，我们只需要知道路径上每种颜色的出现次数，然后取最大值即可。

因此，我们可以将问题转化为：**维护 $10$ 个二进制数组，每个数组表示该颜色在 $\texttt{DFS}$ 序上的出现情况（$1$ 表示出现，$0$ 表示未出现）** 。然后：
* **修改颜色**：在旧颜色对应的数组中，将该节点位置设为 $0$ ；在新颜色对应的数组中，将该节点位置设为 $1$ 。
* **查询路径**：对每种颜色，查询该颜色数组在路径上的 $1$ 的个数（即该颜色在路径上的出现次数），然后取 $10$ 个结果中的最大值。

### 关键技术选择

我们需要一种数据结构来高效地维护**路径上的区间和**（即 $1$ 的个数），并支持**单点更新**。常用的方法是**树链剖分（$\texttt{Heavy-Light Decomposition, HLD}$） + 线段树**。

**树链剖分**可以将树上的任意一条路径拆分成 $O(\log N)$ 个连续的 DFS 序区间（这些区间对应树上的“重链”）。之后，我们就可以用线段树在 $O(\log N)$ 的时间内处理每个区间的查询/更新。

由于有 $10$ 种颜色，我们可以建立 $10$ 棵线段树，每棵线段树对应一种颜色。这样：
* **空间复杂度**： $O(10 \times N \times 4) \approx O(40N)$ ，可以接受。
* **时间复杂度**：
  * 预处理树链剖分： $O(N)$
  * 单点更新： $O(\log N)$ （更新两棵线段树）
  * 路径查询：对每种颜色做一次路径查询，每次路径查询需要拆成 $O(\log N)$ 个区间，每个区间查询复杂度 $O(\log N)$ ，所以单次查询总复杂度为 $O(10 \times \log^2 N)$ 。在 $N, M \le 10^5$ 的情况下可以接受。

### 算法步骤详解

1. **预处理**：
   * 读入树结构，建立邻接表。
   * 进行**两遍 $\texttt{DFS}$** 完成树链剖分：
     * 第一遍 `DFS1` 计算每个节点的父亲 `fa` 、深度 `dep` 、子树大小 `siz` 和重儿子 `son` 。
     * 第二遍 `DFS2` 进行重链剖分，为每个节点分配 DFS 序编号 `dfn` ，并记录所在链的顶端 `top` 。
   * 初始化 $10$ 棵线段树，并根据初始颜色在对应线段树的 `dfn` 位置置 $1$ 。

2. **处理操作**：
   * **修改操作** `0 u c`：
     * 获取节点 $u$ 的旧颜色 `oldC` 。
     * 在 `oldC` 对应的线段树中，将 `dfn[u]` 位置更新为 $0$ 。
     * 在 `c` 对应的线段树中，将 `dfn[u]` 位置更新为 $1$ 。
     * 更新节点 $u$ 的颜色为 `c` 。
   * **查询操作** `1 u v`：
     * 初始化答案 `ans = 0` 。
     * 对每种颜色 `c` （从 $1$ 到 $10$）：
       * 调用 `queryPath(c, u, v)` 函数，计算颜色 `c` 在路径 $u \to v$ 上的出现次数。
       * 该函数通过树链剖分将路径拆分为若干连续区间，在线段树 `c` 上查询区间和。
       * 用该次数更新 `ans` （取最大值）。
     * 输出 `ans` 。

### 复杂度分析

* **时间复杂度**：
  * 预处理： $O(N)$
  * 单次修改： $O(\log N)$
  * 单次查询： $O(10 \times \log^2 N)$
  * 总复杂度： $O(N + M \times 10 \times \log^2 N)$ ，在 $N, M \le 10^5$ 时可行。
* **空间复杂度**： $O(N + 10 \times N \times 4) \approx O(50N)$ 。

## 代码实现

```cpp
// Answering Queries on a Tree
// UVa ID: 12424
// Verdict: Accepted
// Submission Date: 2025-12-06
// UVa Run Time: 1.290s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int MAXC = 11; // 颜色最多10种，索引1~10

int n, m;
int color[MAXN]; // 当前节点颜色
vector<int> g[MAXN]; // 邻接表

// 树链剖分相关数组
int fa[MAXN], dep[MAXN], siz[MAXN], son[MAXN];
int top[MAXN], dfn[MAXN], rnk[MAXN], timer;

// 线段树（对每个颜色建一棵）
struct SegTree {
    int sum[MAXN << 2];
    void build(int c, int l, int r) {
        sum[c] = 0;
        if (l == r) return;
        int mid = (l + r) >> 1;
        build(c << 1, l, mid);
        build(c << 1 | 1, mid + 1, r);
    }
    void update(int c, int l, int r, int pos, int val) {
        if (l == r) { sum[c] = val; return; }
        int mid = (l + r) >> 1;
        if (pos <= mid) update(c << 1, l, mid, pos, val);
        else update(c << 1 | 1, mid + 1, r, pos, val);
        sum[c] = sum[c << 1] + sum[c << 1 | 1];
    }
    int query(int c, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return sum[c];
        int mid = (l + r) >> 1, res = 0;
        if (ql <= mid) res += query(c << 1, l, mid, ql, qr);
        if (qr > mid) res += query(c << 1 | 1, mid + 1, r, ql, qr);
        return res;
    }
} segTree[MAXC]; // 每种颜色一个线段树

// 树链剖分第一遍DFS
void dfs1(int u, int f) {
    fa[u] = f; dep[u] = dep[f] + 1; siz[u] = 1; son[u] = 0;
    for (int v : g[u]) if (v != f) {
        dfs1(v, u);
        siz[u] += siz[v];
        if (siz[v] > siz[son[u]]) son[u] = v;
    }
}

// 树链剖分第二遍DFS
void dfs2(int u, int tp) {
    top[u] = tp; dfn[u] = ++timer; rnk[timer] = u;
    if (son[u]) dfs2(son[u], tp);
    for (int v : g[u]) if (v != fa[u] && v != son[u]) dfs2(v, v);
}

// 路径查询（对某种颜色）
int queryPath(int c, int u, int v) {
    int res = 0;
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        res += segTree[c].query(1, 1, n, dfn[top[u]], dfn[u]);
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    res += segTree[c].query(1, 1, n, dfn[u], dfn[v]);
    return res;
}

int main() {
    int T; scanf("%d", &T);
    while (T--) {
        scanf("%d %d", &n, &m);
        for (int i = 1; i <= n; i++) g[i].clear();
        for (int i = 1; i <= n; i++) scanf("%d", &color[i]);
        for (int i = 1; i < n; i++) {
            int a, b; scanf("%d %d", &a, &b);
            g[a].push_back(b); g[b].push_back(a);
        }

        timer = 0;
        dfs1(1, 0); dfs2(1, 1);

        // 初始化每种颜色的线段树
        for (int c = 1; c <= 10; c++) segTree[c].build(1, 1, n);
        for (int i = 1; i <= n; i++) segTree[color[i]].update(1, 1, n, dfn[i], 1);

        while (m--) {
            int op, u, v; scanf("%d %d %d", &op, &u, &v);
            if (op == 0) { // 更新操作
                int oldC = color[u]; color[u] = v;
                segTree[oldC].update(1, 1, n, dfn[u], 0);
                segTree[v].update(1, 1, n, dfn[u], 1);
            } else { // 查询操作
                int ans = 0;
                for (int c = 1; c <= 10; c++) {
                    int cnt = queryPath(c, u, v);
                    if (cnt > ans) ans = cnt;
                }
                printf("%d\n", ans);
            }
        }
    }
    return 0;
}
```

## 总结

本题的巧妙之处在于**颜色种类很少**这一特殊条件，使得我们可以为每种颜色单独建立一棵线段树，从而将“求路径上颜色出现次数最大值”的问题，转化为 $10$ 次“求路径上该颜色出现次数”的问题。结合**树链剖分**高效处理路径查询和单点更新，即可在时间限制内解决。

这种**对每种属性独立维护**的思想，在处理属性种类有限的问题时非常有效，例如颜色、小权值状态等。同时，树链剖分 + 线段树是解决树上路径问题的经典组合，值得熟练掌握。
