## 题目描述

给定一个整数 $N$，对于每个查询 $X$，需要找出有多少个满足 $1 \leq I \leq N$ 的整数 $I$，使得 $\gcd(I, N) \leq X$。

**输入格式**
- 第一行：整数 $T$ ($1 \leq T \leq 10$)，测试用例数量
- 每个测试用例：
  - 第一行：$N$ ($0 < N \leq 10^{12}$) 和 $Q$ ($0 < Q \leq 50,000$)
  - 接下来 $Q$ 行：每行一个 $X$ ($64$ 位有符号整数)

**输出格式**
- 对于每个测试用例：
  - 第一行：`Case C`（$C$ 为用例编号）
  - 接下来 $Q$ 行：每行一个整数 $R$，表示满足条件的 $I$ 的数量

## 题目分析

### 问题转化

我们需要计算满足 $\gcd(I, N) \leq X$ 的 $I$ 的数量。设 $d = \gcd(I, N)$，则：

1. $d$ 必须是 $N$ 的约数
2. $I$ 可以表示为 $I = d \times k$，其中 $\gcd(k, N/d) = 1$
3. 对于固定的 $d$，满足 $\gcd(I, N) = d$ 的 $I$ 的数量等于 $\varphi(N/d)$，其中 $\varphi$ 是欧拉函数

### 数学推导

设 $D$ 是 $N$ 的所有约数的集合，则：

$$
R = \sum_{\substack{d \in D \\ d \leq X}} \varphi\left(\frac{N}{d}\right)
$$

其中：
- $d$ 遍历 $N$ 的所有约数
- $\varphi(m)$ 表示欧拉函数，即小于等于 $m$ 且与 $m$ 互质的正整数的个数

### 算法设计

由于 $N$ 最大可达 $10^{12}$，我们需要高效的算法：

1. **质因数分解**：首先分解 $N$ 的质因数
2. **生成约数**：根据质因数生成 $N$ 的所有约数
3. **计算欧拉函数**：对于每个约数 $d$，计算 $\varphi(N/d)$
4. **前缀和预处理**：将约数按值排序，计算前缀和数组
5. **查询处理**：对于每个查询 $X$，使用二分查找找到最大的 $d \leq X$，输出对应的前缀和

### 复杂度分析

- 质因数分解：$O(\sqrt{N})$，在 $N \leq 10^{12}$ 时可行
- 约数个数：$N$ 的约数个数约为 $O(\sqrt[3]{N})$，在 $10^{12}$ 范围内最多约 $10^4$ 个
- 查询处理：每个查询 $O(\log(\text{约数个数}))$

## 解题思路详解

### 步骤1：质因数分解

```cpp
vector<ll> factors;
ll temp = n;
for (ll i = 2; i * i <= temp; i++) {
    if (temp % i == 0) {
        factors.push_back(i);
        while (temp % i == 0) temp /= i;
    }
}
if (temp > 1) factors.push_back(temp);
```

这里使用试除法分解质因数，时间复杂度 $O(\sqrt{N})$。

### 步骤2：生成所有约数

```cpp
vector<ll> getDivisors(ll n, const vector<ll>& factors) {
    vector<ll> divisors = {1};
    for (auto p : factors) {
        ll prime = p;
        int count = 0;
        while (n % p == 0) {
            n /= p;
            count++;
        }
        int sz = divisors.size();
        ll multiplier = 1;
        for (int i = 0; i < count; i++) {
            multiplier *= prime;
            for (int j = 0; j < sz; j++) {
                divisors.push_back(divisors[j] * multiplier);
            }
        }
    }
    return divisors;
}
```

通过质因数生成所有约数，使用组合方法避免重复计算。

### 步骤3：计算欧拉函数

```cpp
ll eulerPhi(ll n, const vector<ll>& factors) {
    ll ans = n;
    for (auto p : factors) {
        if (n % p == 0) {
            ans -= ans / p;
            while (n % p == 0) n /= p;
        }
    }
    if (n > 1) ans -= ans / n;
    return ans;
}
```

利用公式 $\varphi(n) = n \times \prod_{p|n}(1 - \frac{1}{p})$ 计算欧拉函数。

### 步骤4：预处理和查询处理

```cpp
// 生成约数并计算对应的欧拉函数值
vector<pair<ll, ll>> pairs;
for (ll d : divisors) {
    pairs.emplace_back(d, eulerPhi(n / d, factors));
}
sort(pairs.begin(), pairs.end());

// 构建前缀和数组
vector<ll> preSum(pairs.size() + 1, 0);
for (int i = 0; i < pairs.size(); i++) {
    preSum[i + 1] = preSum[i] + pairs[i].second;
}

// 处理查询
while (q--) {
    ll x;
    cin >> x;
    auto it = upper_bound(pairs.begin(), pairs.end(), make_pair(x, LLONG_MAX));
    int idx = it - pairs.begin();
    cout << preSum[idx] << "\n";
}
```

## 样例分析

### 样例1：$N = 30$

$30$ 的约数：$1, 2, 3, 5, 6, 10, 15, 30$

对应的 $\varphi(N/d)$ 值：
- $d=1$: $\varphi(30) = 8$
- $d=2$: $\varphi(15) = 8$
- $d=3$: $\varphi(10) = 4$
- $d=5$: $\varphi(6) = 2$
- $d=6$: $\varphi(5) = 4$
- $d=10$: $\varphi(3) = 2$
- $d=15$: $\varphi(2) = 1$
- $d=30$: $\varphi(1) = 1$

前缀和数组：
- $X=1$: $d \leq 1$ 的和 = $8$
- $X=2$: $d \leq 2$ 的和 = $8 + 8 = 16$
- $X=10$: $d \leq 10$ 的和 = $8 + 8 + 4 + 2 + 4 + 2 = 28$

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

vector<ll> getDivisors(ll n, const vector<ll>& factors) {
    vector<ll> divisors = {1};
    for (auto p : factors) {
        ll prime = p;
        int count = 0;
        while (n % p == 0) {
            n /= p;
            count++;
        }
        int sz = divisors.size();
        ll multiplier = 1;
        for (int i = 0; i < count; i++) {
            multiplier *= prime;
            for (int j = 0; j < sz; j++) {
                divisors.push_back(divisors[j] * multiplier);
            }
        }
    }
    return divisors;
}

ll eulerPhi(ll n, const vector<ll>& factors) {
    ll ans = n;
    for (auto p : factors) {
        if (n % p == 0) {
            ans -= ans / p;
            while (n % p == 0) n /= p;
        }
    }
    if (n > 1) ans -= ans / n;
    return ans;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    for (int caseNo = 1; caseNo <= t; caseNo++) {
        ll n, q;
        cin >> n >> q;

        vector<ll> factors;
        ll temp = n;
        for (ll i = 2; i * i <= temp; i++) {
            if (temp % i == 0) {
                factors.push_back(i);
                while (temp % i == 0) temp /= i;
            }
        }
        if (temp > 1) factors.push_back(temp);

        vector<ll> divisors = getDivisors(n, factors);
        sort(divisors.begin(), divisors.end());

        vector<pair<ll, ll>> pairs;
        for (ll d : divisors) {
            pairs.emplace_back(d, eulerPhi(n / d, factors));
        }
        sort(pairs.begin(), pairs.end());

        vector<ll> preSum(pairs.size() + 1, 0);
        for (int i = 0; i < pairs.size(); i++) {
            preSum[i + 1] = preSum[i] + pairs[i].second;
        }

        cout << "Case " << caseNo << "\n";
        while (q--) {
            ll x;
            cin >> x;
            auto it = upper_bound(pairs.begin(), pairs.end(), make_pair(x, LLONG_MAX));
            int idx = it - pairs.begin();
            cout << preSum[idx] << "\n";
        }
    }

    return 0;
}
