
> **摘要**：本题给定一张无向带权图，要求为每个交叉口决定是否安排卫兵，使得每条道路恰好有一个端点有卫兵（即保留子图必须是二分图），同时允许按长度阈值 $K$ 拆除所有长度 $\ge K$ 的道路。目标是求出满足条件时尽可能大的 $K$：无需拆除输出 $0$，必须拆除则输出最大阈值，无法完成输出 $-1$。解法将问题转化为二分图判定，用带权并查集动态维护奇偶性，按边长分组从小到大加边，取冲突前一组长度作为答案，并单独处理自环与边界情况，时间复杂度 $O(M \log M)$。

## 题目描述

苏丹大婚在即，王国所有道路必须由皇家卫兵把守。卫兵部署在道路交叉口，一个卫兵能监视其所在交叉口的所有道路。  
条件如下：

规则 $\texttt{1}$. 每条道路的至少一个端点必须安排卫兵。  
规则 $\texttt{2}$. 任何一条道路的两个端点不能同时安排卫兵，否则两名卫兵会隔着道路聊天而失职。  
规则 $\texttt{3}$. 允许拆除部分道路，且拆除方式为：选定一个长度阈值 $K$，拆除所有长度 **大于或等于** $K$ 的道路，保留长度小于 $K$ 的道路。  
规则 $\texttt{4}$. 若必须拆除道路，则需最大化 $K$；若无需拆除，则输出 $0$；若无论如何也无法满足规则 $\texttt{1}$ 和规则 $\texttt{2}$（即便可以删除任意道路），则输出 $-1$。

给定无向带权图，求满足条件的最大的 $K$。

## 输入格式

第一行包含一个整数 $T$，表示测试用例数。  
每个测试用例的第一行包含两个整数 $N$ 和 $M$，分别表示交叉口数目和道路数目。交叉口编号为 $1$ 至 $N$。  
接下来 $M$ 行，每行三个整数 $a, b, w$，表示交叉口 $a$ 与 $b$ 之间有一条长度为 $w$ 的无向道路。  
输入保证无向边不重复，但可能存在自环（$a = b$）。

## 输出格式

对于每个测试用例，输出一行一个整数：  
- 若无需拆除任何道路，输出 $0$；  
- 若必须拆除，输出可达到的最大阈值 $K$；  
- 若无法完成，输出 $-1$。

## 样例

### 输入
```text
1
4 5
1 2 1
3 1 7
2 3 3
2 4 11
3 4 5
```

### 输出
```text
5
```

## 题目分析

规则 $\texttt{1}$ 要求每条边至少一个端点有卫兵，规则 $\texttt{2}$ 禁止一条边两端同时有卫兵，两者合起来等价于：**每条边恰好有一个端点有卫兵**。  
将“有卫兵”的状态看作颜色 $0$，“无卫兵”看作颜色 $1$，则每条边必须连接异色顶点。这正是二分图的定义。因此，在保留的道路子图上，存在合法部署方案当且仅当该子图是二分图。

删除规则为按长度阈值 $K$ 切除所有长度 $\ge K$ 的边，保留的是长度 $< K$ 的边。随着 $K$ 增大，保留下来的边越来越少，图更容易成为二分图。故问题转化为：求一个尽可能大的 $K$，使得由长度小于 $K$ 的边构成的子图是二分图。若原图本身已是二分图，则 $K$ 可取任意大（无需拆除），输出 $0$。若永远无法成为二分图，则输出 $-1$。

不可能完成的情况主要出现在**自环**上。自环的起点终点相同，不可能满足“恰好一个端点有卫兵”的条件（同一点不能同时既有人又没人）。因此，只要存在自环，就必须将其删除，即阈值 $K$ 必须小于或等于所有自环长度的最小值，否则至少一个自环会被保留而导致无解。若强制要求 $K \le \min$ 自环长度，而所有可保留的边（长度小于该值的非自环边）构成的集合非空且为二分图，则答案可以是该最小值；否则无解。

另外，当所有非自环边为空时，若存在自环，则无论 $K$ 取何值，必须删除所有边，此时保留图为空图，但规则 $\texttt{1}$ 要求每条道路都被守卫，空图没有道路，条件自动满足。然而，根据规则 $\texttt{4}$，“若任何道路需被拆除”，此处若没有道路可保留（所有道路均为自环或需全部删除），其实可以取 $K$ 大于最大边长，此时所有道路被删，但此时是否合法？实际上，只要所有道路都被删，空图是二分图，且条件满足，但题目要求“最大化 $K$ 如果任何道路需要被拆除”。若所有道路都必须被删除，则 $K$ 可以任意大（大于所有边），但输出要求的是“最大 $K$”，无穷大无法表示，因此题目规定这种情况下输出 $-1$。仔细分析题目的输出定义：输出 $-1$ 仅在“不可能”时。但空图总是可行，所以按题意，若必须删除所有道路，实际上可以做到，但 $K$ 无上界，故应输出 $-1$ 或特殊处理。官方解法认定：若没有可保留的非空边且存在自环，则输出 $-1$。同样，若没有自环但所有非自环边构成非二分图，且无法通过删除部分边使之二分（即必须删到空集），此时空图可行但 $K$ 可以无限大，也输出 $-1$。结合通过代码，判定逻辑为：当尝试所有边后，若候选答案不存在，则输出 $-1$。因此，正确实现需处理上述边界。

## 解题思路

采用带权并查集（扩展域或带奇偶性）动态判定二分性。将边按长度分组，从小到大处理。维护一个“当前最佳答案”变量，其含义是：在已经成功加入的边（长度小于当前组长度）构成的子图是二分图的前提下，若已加入的边数非空，则当前组的长度可作为候选 $K$（因为取 $K$ 等于该长度，会删除本组及之后所有边，保留已加入的前缀，该前缀二分且非空）。随后尝试将当前组所有边加入并查集，若出现冲突，则无法保留本组，答案即为候选值（若候选存在），否则无解。若整组成功加入，则继续下一组。

对于自环的处理：

- 若无自环，则按上述流程处理所有非自环边。若全部加入后无冲突，则原图本身是二分图，输出 $0$。
- 若有自环，则必须删除所有自环，因此 $K$ 不能超过自环的最小长度 $L_{\min}$。故只考虑长度小于 $L_{\min}$ 的非自环边。若这部分边为空，则无法保留任何道路，输出 $-1$。否则，对该部分边执行同样的分组处理，取候选答案。若全部加入后仍二分，则答案可取 $L_{\min}$（因为前缀非空）；若过程中冲突，则输出候选答案；若无候选则输出 $-1$。

## 复杂度分析

- 时间复杂度：对每条边排序 $O(M \log M)$，并查集操作几乎为常数，总体 $O(M \log M + M \alpha(N))$。
- 空间复杂度：$O(N)$。

```cpp
// Grand Wedding

#include <bits/stdc++.h>
using namespace std;

struct Edge {
    int u, v, w;
};

class DSU {
public:
    vector<int> parent, diff;
    DSU(int n) {
        parent.resize(n + 1);
        diff.resize(n + 1, 0);
        for (int i = 1; i <= n; ++i) parent[i] = i;
    }
    int find(int x) {
        if (parent[x] != x) {
            int p = parent[x];
            parent[x] = find(p);
            diff[x] ^= diff[p];
        }
        return parent[x];
    }
    bool unite(int u, int v) {
        int ru = find(u), rv = find(v);
        int du = diff[u], dv = diff[v];
        if (ru == rv) return (du ^ dv) == 1;
        parent[ru] = rv;
        diff[ru] = du ^ dv ^ 1;
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int N, M;
        cin >> N >> M;
        vector<Edge> edges;
        int minSelf = INT_MAX;
        bool hasSelf = false;
        for (int i = 0; i < M; ++i) {
            int a, b, w;
            cin >> a >> b >> w;
            if (a == b) {
                hasSelf = true;
                minSelf = min(minSelf, w);
            } else {
                edges.push_back({a, b, w});
            }
        }
        int limit = hasSelf ? minSelf : INT_MAX;
        vector<Edge> valid;
        for (const auto& e : edges)
            if (e.w < limit) valid.push_back(e);
        if (valid.empty()) {
            if (hasSelf) cout << -1 << '\n';
            else cout << 0 << '\n';
            continue;
        }
        sort(valid.begin(), valid.end(), [](const Edge& x, const Edge& y) {
            return x.w < y.w;
        });
        DSU dsu(N);
        int cnt = 0;
        int ans = -1;
        int i = 0, m = valid.size();
        while (i < m) {
            int L = valid[i].w;
            if (cnt > 0) ans = L;
            int j = i;
            bool conflict = false;
            while (j < m && valid[j].w == L) {
                if (!dsu.unite(valid[j].u, valid[j].v)) {
                    conflict = true;
                    break;
                }
                ++j;
            }
            if (conflict) {
                cout << (ans == -1 ? -1 : ans) << '\n';
                break;
            }
            cnt += (j - i);
            i = j;
        }
        if (i == m) {
            if (hasSelf) cout << limit << '\n';
            else cout << 0 << '\n';
        }
    }
    return 0;
}
```

## 总结

本题的核心是将卫兵部署问题转化为二分图判定，利用并查集动态维护二分性，并利用按长度分组、取冲突前一组长度作为答案的技巧。关键点在于自环的特殊处理和边界条件（无候选答案时输出 $-1$）。通过分组处理等长边，避免了简单取第一条冲突边可能遗漏的可行答案，保证了答案的正确性。该解法时间复杂度为 $O(M \log M)$，空间消耗极小，适合处理大规模数据。
