## 题目简述

给定四个整数 $n$、$b$、$d$、$M$，构造一个在 $b$ 进制下由 $n$ 个相同数字 $d$ 组成的数 $X$，要求计算 $X \bmod M$ 的值，结果以十进制输出。

其中：
- $2 \le b \le 100$
- $1 \le n, M \le 10^{12}$
- $d < b$，保证数字合法

例如：$b = 10,\ n = 3,\ d = 2$，则 $X = 222$，若 $M = 10$，则 $222 \bmod 10 = 2$。

## 题目分析

### 1. 将 $X$ 表示为数学公式

在 $b$ 进制下，$n$ 个 $d$ 组成的数为：

$$
X = d \cdot b^{n-1} + d \cdot b^{n-2} + \dots + d \cdot b^0
$$

这是一个等比数列求和：

$$
X = d \cdot \frac{b^n - 1}{b - 1}
$$

因此我们要求：

$$
\text{ans} = \left( d \cdot \frac{b^n - 1}{b - 1} \right) \bmod M
$$

### 2. 问题难点

- $n$ 和 $M$ 最大可达 $10^{12}$，不能直接循环累加。
- 不能直接计算 $b^n$，因为 $b^n$ 会极大溢出。
- 需要处理模运算中的除法，即 $\frac{b^n - 1}{b - 1}$ 对 $M$ 取模。

### 3. 模运算下的除法处理

在模 $M$ 意义下，除法不能直接做，除非 $b-1$ 与 $M$ 互质且可求逆元。但题目并未保证互质，因此不能使用乘法逆元。

**正确方法**：对 $M \cdot (b-1)$ 取模后，再除以 $b-1$。

原理如下：

设 $S = \frac{b^n - 1}{b - 1}$，我们要计算 $S \bmod M$。

令 $K = M \cdot (b-1)$，则：

$$
S = \frac{b^n - 1}{b - 1}
$$

考虑 $b^n - 1$ 对 $K$ 取模：

$$
(b^n - 1) \bmod K = (b^n \bmod K - 1 + K) \bmod K
$$

记这个值为 $r$。由于 $b^n - 1$ 是 $b-1$ 的倍数，因此 $r$ 也一定能被 $b-1$ 整除。

那么：

$$
S \bmod M = \frac{r}{b-1} \bmod M
$$

因此：

$$
ans = \left( d \cdot \frac{r}{b-1} \right) \bmod M
$$

### 4. 快速幂取模

我们需要计算 $b^n \bmod K$，其中 $K = M \cdot (b-1)$ 最大约为 $10^{14}$，仍在 64 位整数范围内。但在快速幂的乘法过程中，两个数相乘最大可达 $(K-1)^2 \approx 10^{28}$，会超出 $64$ 位范围（$2^{63}-1 \approx 9.22 \times 10^{18}$）。

因此，必须使用 $\texttt{\_\_int128}$ 进行中间乘法，防止溢出。

## 解题步骤

1. 读入 $T$。
2. 对每个测试用例：
   - 若 $M = 1$，直接输出 $0$（任何数模 $1$ 都为 $0$）。
   - 计算 $K = M \times (b - 1)$。
   - 用快速幂计算 $b^n \bmod K$，其中乘法使用 $\texttt{\_\_int128}$ 过渡。
   - 计算 $r = (b^n \bmod K - 1 + K) \bmod K$。
   - 计算 $S = r / (b - 1)$（整数除法，保证整除）。
   - 计算 $ans = (d \bmod M) \times (S \bmod M) \bmod M$。
   - 输出 $ans$。

## 时间复杂度

- 每个测试用例需要一次快速幂，复杂度 $O(\log n)$。
- $T \le 1000$，$n \le 10^{12}$，完全可行。

## 注意事项

- 使用 $\texttt{scanf}$ 和 $\texttt{printf}$ 提高输入输出效率。
- 使用 $\texttt{long long}$ 存储中间结果，乘法时强制转换为 $\texttt{\_\_int128}$。
- 注意取模时的负数处理：$(bn - 1 + K) \bmod K$。

```cpp

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// 快速幂取模：计算 (a^b) % mod，使用 __int128 避免乘法溢出
ll powMod(ll a, ll b, ll mod) {
    ll res = 1 % mod;
    a %= mod;
    while (b > 0) {
        if (b & 1) res = (ll)((__int128)res * a % mod);
        a = (ll)((__int128)a * a % mod);
        b >>= 1;
    }
    return res;
}

int main() {
    int T;
    scanf("%d", &T);
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        ll n, b, d, M;
        scanf("%lld %lld %lld %lld", &n, &b, &d, &M);
        
        if (M == 1) {
            printf("Case %d: 0\n", caseNo);
            continue;
        }
        
        // 模数扩大 (b-1) 倍
        ll mod = M * (b - 1);
        ll bn = powMod(b, n, mod);
        ll numerator = (bn - 1 + mod) % mod;  // (b^n - 1) mod (M*(b-1))
        
        // 整除 (b-1) 得到等比数列和
        ll sum = numerator / (b - 1);
        ll ans = (d % M) * (sum % M) % M;
        
        printf("Case %d: %lld\n", caseNo, ans);
    }
    return 0;
}
```

## 总结

本题的核心在于将 $b$ 进制下的重复数字转化为等比数列求和，然后利用模运算技巧“扩大模数再除”来避免求逆元。同时，由于 $n$ 和 $M$ 的上限很大，必须使用快速幂，并在乘法时借助 $\texttt{\_\_int128}$ 防止溢出。掌握这种方法，可以解决一类形如“全由相同数字构成的数取模”的问题。
