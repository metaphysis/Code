## 题目描述

在二维平面上有 $N$ 个人，每人手中有一把枪。平面非常大，因此可以将这些人视为点，他们的位置用笛卡尔坐标给出。这 $N$ 个人每人恰好开一次枪，并且没有两个人同时或几乎同时开枪（因此没有人会因为同时听到枪声而错过任何声音）。所有这些人的听力完全相同。

这 $N$ 个人编号从 $1$ 到 $N$。在所有枪声结束后，他们每个人都被问及听到了多少声枪响（不包括自己的枪声），并给出他们的判断。你无法判断他们的判断是否真实，但你可以判断他们的判断是否一致。

给定 $N$ 个人的位置，你的任务是找出该场景下所有不同的一致判断的数量。如果至少有一个人的意见不同，则两个判断被视为不同。

## 题目分析

### 关键观察

1. **听力范围的一致性**：所有人的听力范围相同，设为 $R$。如果两个人之间的距离 $\leq R$，那么他们可以互相听到对方的枪声。

2. **一致的判断条件**：对于给定的听力范围 $R$，每个人 $i$ 能听到的枪声数等于距离 $\leq R$ 的其他人的数量。一个判断是一致的，当且仅当存在某个 $R$ 使得每个人的听到枪声数等于距离 $\leq R$ 的其他人数量。

3. **距离的离散性**：由于 $R$ 是连续的，不同的 $R$ 值区间会产生相同的"听到枪声数"向量。具体来说，当 $R$ 在两个相邻的不同距离值之间变化时，每个人的听到枪声数保持不变。

### 解题思路

1. **计算所有点对距离**：我们需要计算所有 $\frac{N \times (N-1)}{2}$ 对点之间的距离。

2. **找出不同距离**：不同的距离值决定了 $R$ 的可能阈值。每个不同的距离对应一个可能的 $R$ 临界值。

3. **统计一致判断数量**：
   - 每个不同的距离对应一个 $R$ 的临界值
   - 当 $R$ 在不同距离区间内变化时，产生不同的听到枪声数向量
   - 额外考虑 $R = 0$ 的情况（所有人都听不到任何枪声）

4. **结论**：不同的一致判断数量等于不同距离的数量加 $1$。

### 算法复杂度

- **时间复杂度**：$O(N^2 \log N)$，主要来自排序不同距离
- **空间复杂度**：$O(N^2)$，存储所有点对距离

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);
    
    int t;
    cin >> t;
    for (int caseNum = 1; caseNum <= t; caseNum++) {
        int n;
        cin >> n;
        vector<int> x(n), y(n);
        for (int i = 0; i < n; i++)
            cin >> x[i] >> y[i];
        
        vector<long long> dist;
        dist.reserve(n * (n - 1) / 2);
        
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++) {
                long long dx = x[i] - x[j];
                long long dy = y[i] - y[j];
                dist.push_back(dx * dx + dy * dy);
            }
        
        sort(dist.begin(), dist.end());
        int uniqueCount = unique(dist.begin(), dist.end()) - dist.begin();
        
        cout << "Case " << caseNum << ": " << uniqueCount + 1 << endl;
    }
    return 0;
}
```

## 代码说明

1. **输入处理**：使用 `ios_base::sync_with_stdio(false)` 和 `cin.tie(0)` 加速输入输出。

2. **距离计算**：计算所有点对之间的平方距离，避免浮点数运算。

3. **去重统计**：使用 `sort` 和 `unique` 找出不同距离的数量。

4. **结果输出**：不同距离数量加 $1$ 即为答案，考虑 $R = 0$ 的情况。

## 样例分析

### 样例 1
```
输入：
2
3
1 1
2 2
4 4
2
1 1

输出：
Case 1: 4
Case 2: 2
```

**解释**：
- 第一个测试用例有 $3$ 个点，距离为：$\sqrt{2}$、$2\sqrt{2}$、$3\sqrt{2}$，共 $3$ 个不同距离，加上 $R=0$ 的情况，总共 $4$ 个一致判断。
- 第二个测试用例有 $2$ 个点，只有 $1$ 个距离 $\sqrt{32}$，加上 $R=0$ 的情况，总共 $2$ 个一致判断。

## 总结

本题的关键在于理解听力范围 $R$ 与距离阈值的关系，通过统计不同距离的数量来确定可能的一致判断数量。算法实现简单高效，主要挑战在于对问题本质的理解。
