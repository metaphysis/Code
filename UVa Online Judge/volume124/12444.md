## 题目描述

给定两个非负整数 $C$ 和 $D$，要求找到两个非负整数 $A$ 和 $B$，满足以下条件：

1. $A \& B = C$（按位与等于 $C$）
2. $A | B = D$（按位或等于 $D$）
3. $A \leq B$
4. 在所有满足条件的 $(A, B)$ 对中，$B - A$ 的值最小

如果不存在这样的 $A$ 和 $B$，则输出 `-1`。

**输入格式**：  
第一行是测试用例数量 $T$（$T \leq 100$），接下来 $T$ 行每行包含两个整数 $C$ 和 $D$（$0 \leq C, D < 2^{31}$）。

**输出格式**：  
对于每个测试用例，输出满足条件的 $A$ 和 $B$，或者 `-1`。

---

## 题目分析

### 1. 可行性条件

根据按位运算的性质：

- 如果某一位在 $C$ 中是 $1$，那么在 $A$ 和 $B$ 中该位都必须是 $1$
- 如果某一位在 $D$ 中是 $0$，那么在 $A$ 和 $B$ 中该位都必须是 $0$
- 如果某一位在 $C$ 中是 $0$ 但在 $D$ 中是 $1$，那么在 $A$ 和 $B$ 中该位恰好有一个为 $1$

由此可得必要条件：$C$ 的 $1$ 位集合必须是 $D$ 的 $1$ 位集合的子集，即：
$$(C \& (\sim D)) = 0$$

如果不满足这个条件，则直接输出 `-1`。

### 2. 自由位的概念

定义自由位集合：
$$X = D \& (\sim C)$$

$X$ 表示那些在 $A$ 和 $B$ 中只能有一个为 $1$ 的位。我们需要将这些位合理地分配给 $A$ 和 $B$，使得 $|A - B|$ 最小。

### 3. 最小化差值的策略

设我们将自由位 $X$ 拆分为两个不相交的部分 $P$ 和 $Q$（即 $P \& Q = 0$，$P | Q = X$），然后：
- $A = C | P$
- $B = C | Q$

这样自动满足 $A \& B = C$ 和 $A | B = D$。

我们的目标是最小化 $|A - B| = |P - Q|$。

**关键观察**：在二进制表示中，一个高位权重大于所有低位权重之和。因此，为了最小化 $|P - Q|$，我们应该：

1. 将 $X$ 的最高位分配给 $B$
2. 将 $X$ 的所有剩余低位分配给 $A$

这样分配后，由于最高位的权重大于所有低位之和，我们自动得到 $B \geq A$，且 $B - A$ 最小。

### 4. 特殊情况处理

- 如果 $X = 0$，说明没有自由位，此时 $A = B = C = D$
- 如果 $(C \& (\sim D)) \neq 0$，说明存在矛盾，输出 `-1`

// Bits and Pieces

#include <iostream>
using namespace std;

int main() {
    int testCaseCount;
    cin >> testCaseCount;
    while (testCaseCount--) {
        unsigned int cValue, dValue;
        cin >> cValue >> dValue;
        
        // 检查可行性条件：C 的 1 位必须是 D 的 1 位的子集
        if ((cValue & (~dValue)) != 0) {
            cout << -1 << endl;
            continue;
        }
        
        // 计算自由位集合
        unsigned int freeBits = dValue & (~cValue);
        
        // 如果没有自由位，则 A = B = C = D
        if (freeBits == 0) {
            cout << cValue << " " << cValue << endl;
            continue;
        }
        
        // 找到自由位中的最高位
        unsigned int highBit = 1;
        while (highBit <= freeBits / 2) {
            highBit <<= 1;
        }
        
        // 分配自由位：最高位给 B，其余给 A
        unsigned int lowBits = freeBits & (~highBit);
        unsigned int aResult = cValue | lowBits;
        unsigned int bResult = cValue | highBit;
        
        cout << aResult << " " << bResult << endl;
    }
    return 0;
}
