[UVa 12446 How Many in 3D](https://blog.csdn.net/metaphysis/article/details/156819850)

## 题目描述

给定一个尺寸为 $2 \times 2 \times N$ 的长方体盒子，使用尺寸为 $1 \times 1 \times 2$ 的长方体砖块进行填充。砖块可以任意旋转（即可以沿着 $x$ , $y$ , $z$ 三个方向放置），但必须完整放入盒子内，不能重叠，也不能超出边界。求填充盒子的不同方法数。

**输入格式**：  
第一行包含一个整数 $T$（$T \leq 10{,}000$），表示测试用例的数量。  
接下来 $T$ 行，每行包含一个整数 $N$（$1 \leq N \leq 1{,}000{,}000$）。

**输出格式**：  
对于每个测试用例，输出填充方法数对 $1{,}000{,}000{,}007$ 取模的结果。

## 题目分析

这是一个经典的三维铺砖问题。由于盒子在 $x$ 和 $y$ 方向上的尺寸很小（均为 $2$ ），我们可以将问题转化为一维递推问题。

### 1. 问题简化

考虑盒子的横截面为 $2 \times 2$ 的正方形。砖块 $1 \times 1 \times 2$ 可以看作：
- 竖着放：占据高度 $2$ ，横截面为 $1 \times 1$
- 横着放（沿着 $x$ 或 $y$ 方向）：占据高度 $1$ ，横截面为 $1 \times 2$ 或 $2 \times 1$

由于盒子在 $x$ 和 $y$ 方向对称，我们可以只考虑高度方向 $N$ 的变化。

### 2. 已知结论（$\texttt{OEIS A006253}$）

这个问题在 $\texttt{OEIS}$（整数数列在线百科全书）中对应序列 **$\texttt{A006253}$**，其递推公式为：
$$
f(n) = 3f(n-1) + 3f(n-2) - f(n-3)
$$
其中初始条件：
$$
f(0) = 1, \quad f(1) = 2, \quad f(2) = 9, \quad f(3) = 32
$$
注意：这里的 $a(0) = 1$ 表示空盒子的填充方式为 $1$ 种（不放置任何砖块）。

### 3. 递推关系推导（简要说明）
$$
f(n) = 3f(n-1) + 3f(n-2) - f(n-3)
$$
验证前几项：
- $f(0) = 1$
- $f(1) = 2$
- $f(2) = 9 = 3 \times 2 + 3 \times 1 - 0 = 6 + 3 = 9$ ✓
- $f(3) = 32 = 3 \times 9 + 3 \times 2 - 1 = 27 + 6 - 1 = 32$ ✓
- $f(4) = 121 = 3 \times 32 + 3 \times 9 - 2 = 96 + 27 - 2 = 121$ ✓

### 4. 算法设计

由于 $N$ 最大可达 $1{,}000{,}000$，而 $T$ 最大为 $10{,}000$，我们需要高效的算法。

**方案选择**：  
预计算所有 $N$ 对应的 $f(N)$，然后 $O(1)$ 查询。

**时间复杂度**：
- 预计算：$O(\max N) = O(10^6)$，完全可以接受
- 每个查询：$O(1)$

**空间复杂度**：
- 存储数组：$O(10^6)$，约 $8$ MB（`long long` 类型）

**取模处理**：
- 所有计算对 $MOD = 1{,}000{,}000{,}007$ 取模
- 注意递推式中涉及减法，结果可能为负数，需要调整为正数

## 解题思路

1. **预处理**：  
   使用递推式 $f(n) = 3f(n-1) + 3f(n-2) - f(n-3)$ 计算 $f(0)$ 到 $f(1{,}000{,}000)$ 的所有值。

2. **查询**：  
   对于每个输入的 $N$，直接输出 $f[N]$。

3. **边界情况**：
   - $N = 0$：虽然题目中 $N \geq 1$，但递推需要 $f(0) = 1$
   - 负数的处理：在取模运算后，如果结果为负数，则加上 $MOD$

## 代码实现

```cpp
// How Many in 3D
// UVa ID: 12446
// Verdict: Accepted
// Submission Date: 2026-01-11
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int MOD = 1000000007;
// f数组存储f(0)到f(1000000)
ll f[1000010] = {1, 2, 9, 32}; // 初始化前4项

int main() {
    // 预计算所有f(n)
    for (int i = 4; i <= 1000000; i++) {
        // 递推公式：f(n) = 3f(n-1) + 3f(n-2) - f(n-3)
        f[i] = (3 * f[i - 1] + 3 * f[i - 2] - f[i - 3]) % MOD;
        // 处理负数
        if (f[i] < 0) f[i] += MOD;
    }
    int T, n;
    cin >> T;
    while (T--) {
        cin >> n;
        cout << f[n] << '\n';
    }
    return 0;
}
```

## 代码说明

1. **数组初始化**：  
   `f[1000010] = {1, 2, 9, 32}` 初始化了前 $4$ 项，这是递推的基础。

2. **递推计算**：  
   `for (int i = 4; i <= 1000000; i++)` 循环计算从 $f(4)$ 到 $f(1{,}000{,}000)$ 的所有值。

3. **取模运算**：  
   `% MOD` 确保结果在模 $1{,}000{,}000{,}007$ 下计算，避免溢出。

4. **负数处理**：  
   由于递推式中包含减法，`f[i]` 可能为负数，使用 `if (f[i] < 0) f[i] += MOD` 调整为正数。

5. **输入输出**：  
   使用 `cin` 和 `cout` 进行输入输出，在本题数据范围内效率足够。

## 复杂度分析

- **时间复杂度**：预处理 $O(10^6)$，每次查询 $O(1)$，总复杂度 $O(10^6 + T)$
- **空间复杂度**：$O(10^6)$，用于存储 $f$ 数组

## 扩展思考

1. **为什么是 $2 \times 2 \times N$ 而不是其他尺寸**：  
   因为 $2 \times 2$ 的横截面使得砖块的摆放方式有限，可以通过状态压缩或递推求解。如果横截面更大，问题会变得更加复杂。

2. **其他解法**：  
   除了预计算，还可以使用矩阵快速幂在 $O(\log N)$ 时间内求解单个 $N$。但当 $T$ 很大时，预计算更优。

3. **序列性质**：  
   该序列在 $\texttt{OEIS}$ 中为 $\texttt{A006253}$，除了铺砖问题外，还出现在其他组合问题中。

## 总结

本题的关键在于：
1. 识别出这是经典的 $2 \times 2 \times N$ 铺砖问题
2. 知道对应的递推公式 $f(n) = 3f(n-1) + 3f(n-2) - f(n-3)$
3. 采用预计算 + 查表的方法，以应对大数据量的查询

通过预处理，我们可以在 $O(1)$ 时间内回答每个查询，完美解决了 $N$ 最大 $1{,}000{,}000$，$T$ 最大 $10{,}000$ 的限制条件。
