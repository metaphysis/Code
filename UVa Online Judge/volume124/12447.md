## 题目描述

给定一个偶数 $N$ ，要求构造一个长度为 $2^{N}$ 的序列，序列中的每个元素都是一个 $N$ 位的二进制数（以十进制形式输出），且序列需要满足以下条件：

1. 序列中所有 $2^{N}$ 个 $N$ 位二进制数必须互不相同；
2. 对于序列中除第一个元素外的每个元素，它与其前一个元素相比，**恰好只有一位相同**（其余 $N-1$ 位都不同）。

### 输入格式

输入以整数 $T$ 开始，表示测试用例的数量 $(1 \leq T \leq 8)$ 。
随后 $T$ 行，每行包含一个整数 $N$ $(2 \leq N \leq 16)$ ，保证 $N$ 为偶数。

### 输出格式

对于每个测试用例，输出一个满足条件的序列，每行输出一个十进制整数。任何符合条件的序列都会被判为正确。

### 样例输入
```
1
2
```

### 样例输出
```
0
1
3
2
```

**样例解释** ：当 $N=2$ 时，输出的四个十进制数对应的二进制表示为：
- $0 \rightarrow 00$
- $1 \rightarrow 01$
- $3 \rightarrow 11$
- $2 \rightarrow 10$

相邻两个二进制数之间恰好只有一位相同：
- $00$ 与 $01$ ：第 1 位相同（都是 $0$ ）
- $01$ 与 $11$ ：第 0 位相同（都是 $1$ ）
- $11$ 与 $10$ ：第 1 位相同（都是 $1$ ）

## 题目分析

### 问题本质

本题要求构造一个特殊的序列，其中相邻两个 $N$ 位二进制数**恰好只有一位相同**。这等价于在 $N$ 维超立方体（每个顶点是一个 $N$ 位二进制数）上找一条**哈密顿路径**，且路径上相邻顶点的**汉明相似度**为 $1$ （即只有一个位相同）。

### 关键观察

1. **相邻条件转换** ：设两个 $N$ 位二进制数 $A$ 和 $B$ ，它们“恰好只有一位相同”意味着：
   - 相同位数 = $1$
   - 不同位数 = $N-1$
   
   换句话说，它们的**汉明距离**为 $N-1$ 。

2. **与格雷码的关系** ：标准的**格雷码**（$\texttt{Gray Code}$）要求相邻两个数**恰好只有一位不同**（汉明距离为 $1$ ）。这与题目要求恰好相反。但是我们可以通过一个巧妙的变换来利用格雷码的性质：

   对于任意一个数 $x$ ，如果我们保留它的某一位 $i$ 不变，而将其他所有位取反，那么得到的新数 $x'$ 与 $x$ 的关系是：
   - 第 $i$ 位相同
   - 其余 $N-1$ 位都不同
   
   这正是题目要求的“恰好只有一位相同”！

3. **构造方法** ：我们可以从一个数开始（例如 $0$ ），每次通过“保留某一位，翻转其他所有位”的方式生成下一个未访问的数，直到遍历完所有 $2^{N}$ 个数。

---

## 解题思路

### 算法设计

我们采用**贪心构造法**来生成序列：

1. **初始化** ：从 $0$ 开始，使用一个访问标记数组 `visited[]` 记录已经输出过的数。
2. **生成下一个数** ：对于当前数 `bit` ，尝试所有可能的位 $i$ $(0 \leq i < N)$ ，计算候选数：
   ```
   nxt = (bit ^ ((1 << N) - 1)) ^ (1 << i)
   ```
   这个表达式的含义是：
   - `(1 << N) - 1` ：得到 $N$ 位全 $1$ 的掩码
   - `bit ^ mask` ：将 `bit` 的所有位取反
   - `^ (1 << i)` ：再将第 $i$ 位翻转一次（相当于恢复为 `bit` 的第 $i$ 位）
   - 最终结果：第 $i$ 位与 `bit` 相同，其余位都与 `bit` 相反
3. **选择策略** ：按顺序检查每个 $i$ 对应的候选数 `nxt` ，如果 `nxt` 未被访问过，则选择它作为下一个数。
4. **终止条件** ：当输出了 $2^{N}$ 个数后结束。

### 正确性证明

1. **满足相邻条件** ：由构造方法可知，相邻两个数确实恰好只有一位相同。
2. **不会重复** ：使用 `visited` 数组确保每个数只出现一次。
3. **总能找到下一个数** ：在构造过程中，每个数都有 $N$ 个可能的“邻居”（对应 $N$ 个不同的保留位）。由于序列需要包含所有 $2^{N}$ 个数，且图是连通的，贪心选择总能找到未访问的邻居（实际上构造出的是一条哈密顿路径）。
4. **时间复杂度** ：每个数需要检查最多 $N$ 个邻居，总时间复杂度为 $O(N \times 2^{N})$ 。对于 $N \leq 16$ ，最大操作次数约为 $16 \times 65536 = 1,048,576$ ，完全可行。

### 样例推演（N=2）

1. 初始：`bit = 0 (00)`
2. 输出 $0$ ，标记已访问
   - $i=0$：`nxt = (00^11)^01 = 11^01 = 10 (2)` ，未访问 → 选择
3. 输出 $2 (10)$ ，标记已访问
   - $i=0$：`nxt = (10^11)^01 = 01^01 = 00 (0)` ，已访问
   - $i=1$：`nxt = (10^11)^10 = 01^10 = 11 (3)` ，未访问 → 选择
4. 输出 $3 (11)$ ，标记已访问
   - $i=0$：`nxt = (11^11)^01 = 00^01 = 01 (1)` ，未访问 → 选择
5. 输出 $1 (01)$ ，结束

最终序列：$0, 2, 3, 1$ ，对应的二进制序列为 $00, 10, 11, 01$ ，验证可知满足相邻条件。

## 代码实现

```cpp
// Pieces and Bits
// UVa ID: 12447
// Verdict: Accepted
// Submission Date: 2026-01-15
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    int visited[1 << 16]; // 访问标记数组，最多 2^16 = 65536 个元素
    
    while (t--) {
        int n;
        cin >> n;
        int bit = 0;              // 当前数，从 0 开始
        int cnt = 0;              // 已输出的数的个数
        int total = (1 << n);     // 总个数 2^n
        
        memset(visited, 0, sizeof visited); // 初始化访问标记
        
        while (cnt < total) {
            cout << bit << '\n';      // 输出当前数
            visited[bit] = 1;         // 标记已访问
            cnt++;
            
            // 尝试所有可能的位，寻找下一个未访问的数
            for (int i = 0; i < n; i++) {
                // 保留第 i 位，其他位取反
                int nxt = (bit ^ ((1 << n) - 1)) ^ (1 << i);
                if (visited[nxt]) continue; // 已访问过，跳过
                bit = nxt;                  // 找到下一个数
                break;
            }
        }
    }
    
    return 0;
}
```

### 代码说明

1. **位运算技巧** ：
   - `(1 << n) - 1` 生成 $N$ 位全 $1$ 的掩码
   - `bit ^ mask` 实现按位取反
   - `^ (1 << i)` 将第 $i$ 位再翻转一次，相当于恢复原值
   - 整体效果：保留第 $i$ 位，其他位取反

2. **贪心策略** ：按顺序检查 $i$ 从 $0$ 到 $N-1$ ，选择第一个未访问的候选数作为下一个数。

3. **空间优化** ：`visited` 数组大小为 $2^{16}$ ，使用 `memset` 快速初始化。

4. **输出格式** ：直接输出十进制数，每行一个。

---

## 复杂度分析

- **时间复杂度** ：$O(T \times N \times 2^{N})$ ，对于每个测试用例，需要生成 $2^{N}$ 个数，每个数最多检查 $N$ 个邻居。
- **空间复杂度** ：$O(2^{N})$ ，主要用于 `visited` 数组。

在题目限制 $N \leq 16$ 下，该算法完全可行。

## 总结

本题的关键在于理解“恰好只有一位相同”的条件，并将其转化为位运算操作。通过“保留一位，翻转其他位”的构造方法，我们可以贪心地生成整个序列。这种方法不仅保证了正确性，而且实现简单、效率高，是位运算与构造算法结合的经典例子。

**核心技巧** ：`(bit ^ mask) ^ (1 << i)` 实现“保留第 $i$ 位，其他取反”的操作，这是解决本题的关键位运算表达式。
