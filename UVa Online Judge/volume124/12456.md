## 题目描述

许多儿童“计算机”使用穿孔卡片来选择游戏。 卡片有正反两面，每面编码一个不同的游戏。 读卡器有 $d$ 个位置，每个位置有一个开关，其状态（开/关）由卡片对应位置是否有孔决定。 每个位置使用不同的进制（所有进制 $>1$ ），且整个进制序列是镜像对称的：$b_1 = b_d$, $b_2 = b_{d-1}$, $\dots$。

一张卡片的正面编码和反面编码是镜像关系（即数字顺序反转）。 为了保证能唯一确定玩家想玩哪个游戏（即能区分卡片哪一面朝上），**一个有效的游戏编码不能等于它自己的镜像**（即不能是回文编码）。

给定进制序列，计算可以编码的有效游戏总数。

**输入格式**  
每个测试用例一行：第一个整数 $d$ （位数），接着 $d$ 个整数表示进制 $b_1, b_2, \dots, b_d$。 输入以 $d = 0$ 结束。

**输出格式**  
对于每个测试用例，输出有效游戏数。

**数据范围**  
- $d \ge 0$
- 所有进制 $>1$
- 结果保证在 $32$ 位整数范围内

## 题目分析

### 核心约束

$1$. **进制对称性**：由于 $b_i = b_{d+1-i}$ ，一个编码的镜像编码仍是合法编码（不会出现某位数字超出进制范围的情况）。
$2$. **唯一性要求**：游戏编码不能是回文的，即 $code \neq reverse(code)$ 。 因为如果正反面编码相同，就无法通过翻转卡片来选择不同的游戏。

### 问题转化

我们需要计算在给定对称进制序列下，所有可能的编码中，**非回文编码**的数量。 因为每个非回文编码可以作为某个游戏出现在一张卡片的一面。

设：
- $total$ ：所有可能的编码总数。
- $palindrome$ ：回文编码的数量。

则有效游戏数（即非回文编码数）为：
$$
games = total - palindrome
$$

### 公式推导

#### $1$. 总编码数 $total$
每一位独立取值，总数为各位进制的乘积：
$$
total = \prod_{i=1}^{d} b_i
$$

#### $2$. 回文编码数 $palindrome$
回文编码要求前一半数字确定后，后一半由镜像对称决定。

- **当 $d$ 为偶数时**：只需确定前 $d/2$ 位：
$$
  palindrome = \prod_{i=1}^{d/2} b_i
$$
- **当 $d$ 为奇数时**：需确定前 $(d+1)/2$ 位，中间位可以任意取：
$$
  palindrome = \left( \prod_{i=1}^{(d-1)/2} b_i \right) \times b_{(d+1)/2}
$$

#### $3$. 有效游戏数
$$
games = total - palindrome
$$

### 举例验证

**例 $1$**：输入 `2 2 2` （$d=2$, $b=[2,2]$）
- $total = 2 \times 2 = 4$
- $palindrome = b_1 = 2$
- $games = 4 - 2 = 2$

解释：所有可能编码：$00, 01, 10, 11$。 其中回文编码：$00, 11$。 非回文编码：$01, 10$。 这两个非回文编码分别作为两个游戏，可以印在一张卡片的正反面。

**例 $2$**：输入 `4 2 2 2 2` （$d=4$, $b=[2,2,2,2]$）
- $total = 2^4 = 16$
- $palindrome = b_1 \times b_2 = 2 \times 2 = 4$
- $games = 16 - 4 = 12$

## 算法实现

直接按公式计算即可：
$1$. 读入 $d$ 和进制序列。
$2$. 计算 $total$ ：所有进制相乘。
$3$. 计算 $palindrome$ ：前一半进制相乘，若 $d$ 为奇数则再乘中间位的进制。
$4$. 输出 $total - palindrome$。

时间复杂度：$O(d)$，空间复杂度：$O(d)$。

## 代码实现

```cpp
// Mirror Codes

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int d;
    while (cin >> d && d != 0) {
        vector<int> bases(d);
        for (int i = 0; i < d; i++) cin >> bases[i];

        // 计算总编码数
        long long total = 1;
        for (int b : bases) total *= b;

        // 计算回文编码数
        long long palindrome = 1;
        int half = d / 2;
        for (int i = 0; i < half; i++) palindrome *= bases[i];
        if (d % 2 == 1) palindrome *= bases[half];  // 奇数时中间位

        // 有效游戏数 = 总编码数 - 回文编码数
        long long games = total - palindrome;
        cout << games << '\n';
    }

    return 0;
}
```

## 总结

本题的关键在于理解进制序列的镜像对称性，并正确区分回文编码与非回文编码。 通过简单的组合计数公式即可快速求解。 注意使用 `long long` 防止乘法溢出，尽管题目保证结果在 $32$ 位整数范围内，但中间计算可能超出。
