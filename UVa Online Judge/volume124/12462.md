## 题目描述

给定一个直方图，由 $N$ 个宽度为 $1$ 的竖直矩形条组成，第 $i$ 个矩形条的高度为 $h_i$ ，颜色为 $c_i$ 。颜色用 $0$ 到 $C-1$ 的整数表示，且每种颜色至少出现一次。 

定义一个矩形为 **好矩形** ，当且仅当：

1. 矩形完全位于直方图内部；
2. 矩形覆盖的区域内，**每种颜色** 的覆盖面积都严格大于 $0$ （仅仅接触边界不算）。

要求找出所有好矩形中面积的最大值，并保证结果为整数。

**数据范围** ：
- $1 \le N \le 10^5$
- $1 \le C \le \min(30, N)$
- $1 \le h_i \le 10^9$

## 题目分析

### 基本观察

一个好矩形由其在水平轴上的投影区间 $[l, r]$ 和其高度 $H$ 决定。由于矩形必须完全位于直方图内部，因此对于给定的区间 $[l, r]$ ，矩形的高度 $H$ 不能超过该区间内所有矩形条的最小高度，即：

$$ H \le \min\{h_l, h_{l+1}, \dots, h_r\} $$

为了使面积最大，显然应取 $H = \min\{h_l, h_{l+1}, \dots, h_r\}$ 。因此，矩形的面积可表示为：

$$ Area = (r-l+1) \times \min_{l \le i \le r} h_i $$

同时，区间 $[l, r]$ 必须包含所有 $C$ 种颜色（因为每种颜色的覆盖面积都要大于 $0$ ，等价于区间内至少有一个该颜色的矩形条）。

于是问题转化为：

> 在所有包含全部 $C$ 种颜色的区间 $[l, r]$ 中，求 $(r-l+1) \times \min_{l \le i \le r} h_i$ 的最大值。

### 困难与思路

直接枚举所有区间是 $O(N^2)$ 的，不可行。我们需要更高效的方法。

一个经典技巧是：**枚举最小值的位置**。对于每个位置 $i$ ，令 $h_i$ 作为区间的最小值，那么区间 $[l, r]$ 必须满足：

$1$. $l \le i \le r$
$2$. $\forall j \in [l, r],\ h_j \ge h_i$ 
$3$. $[l, r]$ 包含所有颜色

条件 $2$ 意味着 $[l, r]$ 必须在 $i$ 的 **左右边界** 内，这个边界可以通过单调栈 $O(N)$ 预处理得到。设 $L[i]$ 表示左边第一个高度小于 $h_i$ 的位置 $+1$ （如果没有则为 $0$ ），$R[i]$ 表示右边第一个高度小于 $h_i$ 的位置 $-1$ （如果没有则为 $N-1$ ）。那么在区间 $[L[i], R[i]]$ 内，$h_i$ 是最小值。

于是对于每个 $i$ ，问题变为：

> 在区间 $[L[i], R[i]]$ 中，找一个包含位置 $i$ 且包含所有 $C$ 种颜色的最短子区间 $[l, r]$ （ $l \le i \le r$ ），则面积候选值为 $h_i \times (r-l+1)$ 。

如果对每个 $i$ 都暴力枚举 $l$ 和 $r$ ，复杂度仍可能达到 $O(N^2)$ 。由于 $C \le 30$ ，我们可以利用颜色数少的特点进行优化。

### 高效算法设计

我们考虑按 **高度从大到小** 的顺序处理矩形条，并使用 **并查集** 维护当前高度下的连通块（连续区间）。

**算法流程**：

$1$. 将所有矩形条按高度降序排序。
$2$. 初始化并查集，每个位置独立，颜色集合为自身颜色对应的位掩码（ $1 \ll c_i$ ）。
$3$. 按高度从高到低依次“激活”每个矩形条。激活一个位置时，将其与左右相邻的已激活位置合并（如果存在）。
$4$. 合并时，更新连通块的大小和颜色集合（位掩码的或运算）。
$5$. 当某个连通块首次包含所有颜色（即颜色掩码等于 $(1 \ll C) - 1$ ）时，由于我们是从高到低处理，当前高度就是该连通块中所有矩形条的最小高度。此时，以当前高度为矩形高度、以连通块大小为宽度构成的矩形就是一个好矩形，其面积为 **当前高度 × 连通块大小** 。记录最大值。

**正确性证明**：
- 当我们从高到低处理时，被激活的位置组成若干个连通块，每个连通块内的所有矩形条高度都 **不小于** 当前处理的高度。
- 当连通块首次包含所有颜色时，该连通块的最小高度恰好就是当前高度（因为如果再降低高度，连通块可能会扩大，但最小高度会变小；而在当前高度下，它是首次满足颜色条件的连通块）。
- 该连通块对应一个连续的区间 $[l, r]$ ，且区间内所有高度 $\ge$ 当前高度，因此以当前高度为矩形高度可以完全包含在该区间内。
- 由于连通块是连续的，且包含所有颜色，因此对应的矩形是好矩形。
- 我们枚举了所有可能的最小高度，因此不会漏掉最优解。

**复杂度分析**：
- 排序： $O(N \log N)$
- 并查集操作：近似 $O(N \alpha(N))$
- 总复杂度： $O(N \log N)$ ，可以接受。

## 代码实现

```cpp
// Rectangle

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;

int n, c;
int h[MAXN], col[MAXN];
long long ans;

struct Bar {
    int height, pos, color;
    bool operator<(const Bar& other) const {
        return height > other.height; // 降序排序
    }
};

Bar bars[MAXN];
int parent[MAXN], setSize[MAXN], mask[MAXN];
bool activated[MAXN];

int findSet(int x) {
    if (parent[x] != x) parent[x] = findSet(parent[x]);
    return parent[x];
}

// 合并两个集合，返回合并后的根
int unionSet(int a, int b) {
    a = findSet(a); b = findSet(b);
    if (a == b) return a;
    if (setSize[a] < setSize[b]) swap(a, b);
    parent[b] = a;
    setSize[a] += setSize[b];
    mask[a] |= mask[b];
    return a;
}

void solve() {
    // 构建Bar数组
    for (int i = 0; i < n; i++) {
        bars[i].height = h[i];
        bars[i].pos = i;
        bars[i].color = col[i];
    }
    sort(bars, bars + n);
    
    // 初始化并查集
    for (int i = 0; i < n; i++) {
        parent[i] = i;
        setSize[i] = 1;
        mask[i] = (1 << col[i]);
        activated[i] = false;
    }
    
    ans = 0;
    int fullMask = (1 << c) - 1;
    
    for (int idx = 0; idx < n; ) {
        int currentHeight = bars[idx].height;
        vector<int> rootsToCheck;
        
        // 处理所有高度相同的条
        while (idx < n && bars[idx].height == currentHeight) {
            int pos = bars[idx].pos;
            activated[pos] = true;
            rootsToCheck.push_back(pos);
            
            // 如果左边已激活，合并
            if (pos > 0 && activated[pos - 1]) {
                int newRoot = unionSet(pos, pos - 1);
                rootsToCheck.push_back(newRoot);
            }
            // 如果右边已激活，合并
            if (pos + 1 < n && activated[pos + 1]) {
                int newRoot = unionSet(pos, pos + 1);
                rootsToCheck.push_back(newRoot);
            }
            idx++;
        }
        
        // 去重检查可能的新连通块
        sort(rootsToCheck.begin(), rootsToCheck.end());
        rootsToCheck.erase(unique(rootsToCheck.begin(), rootsToCheck.end()), rootsToCheck.end());
        
        for (int root : rootsToCheck) {
            root = findSet(root);
            if (mask[root] == fullMask) {
                long long area = (long long)currentHeight * setSize[root];
                if (area > ans) ans = area;
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    while (cin >> n >> c, n || c) {
        for (int i = 0; i < n; i++) cin >> h[i];
        for (int i = 0; i < n; i++) cin >> col[i];
        solve();
        cout << ans << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于将问题转化为 **寻找包含所有颜色的区间，并求区间最小值与区间长度的乘积的最大值** 。通过 **按高度降序处理** 和 **并查集维护连通块** ，我们巧妙地避免了直接枚举区间的高复杂度，利用颜色数少的特点高效求解。最终算法的时间复杂度为 $O(N \log N)$ ，空间复杂度为 $O(N)$ ，能够处理 $N$ 高达 $10^5$ 的数据规模。
