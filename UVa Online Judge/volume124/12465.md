[UVa 12465 The Turanga Leela Problem](https://blog.csdn.net/metaphysis/article/details/154957755)

## 题目描述

$\texttt{Turanga Leela}$ 正在与 $\texttt{Bender}$ 和 $\texttt{Philip J. Fry}$ 玩一个游戏。$\texttt{Philip J. Fry}$ 选择一个正整数 $a$，$\texttt{Bender}$ 选择一个正整数 $b$，$\texttt{Leela}$ 需要计算满足以下条件的正整数 $m$ 的数量：$a$ 和 $b$ 除以 $m$ 的余数相同。

换句话说，需要找出集合 $\{m \in \mathbb{Z}_{>0} \mid a \equiv b \ (\text{mod} \ m)\}$ 的大小。

## 输入格式

输入包含多个测试用例（最多 $150$ 个）。每个测试用例在一行中包含两个不同的整数 $a$ 和 $b$（$1 \leq a, b \leq 10^9$）。

最后一行包含两个零，表示输入结束。

## 输出格式

对于每个测试用例，输出一个整数，表示满足条件的正整数 $m$ 的数量。

## 题目分析

### 数学转化

首先，我们需要理解条件 $a \equiv b \ (\text{mod} \ m)$ 的数学含义。这个同余关系等价于：

$$m \mid (a - b)$$

即 $m$ 整除 $a$ 与 $b$ 的差。

### 关键观察

1. 如果 $a = b$，那么对于任意正整数 $m$，都有 $a \equiv b \ (\text{mod} \ m)$。但题目说明输入的是两个不同的整数，因此我们不需要考虑这种情况。

2. 如果 $a \neq b$，设 $d = |a - b|$，那么满足条件的 $m$ 就是 $d$ 的所有正因数。

### 证明

为什么满足条件的 $m$ 恰好是 $|a - b|$ 的所有正因数？

- 如果 $m$ 整除 $(a - b)$，那么存在整数 $k$ 使得 $a - b = k \cdot m$
- 这意味着 $a$ 和 $b$ 除以 $m$ 的余数相同
- 反之，如果 $a$ 和 $b$ 除以 $m$ 的余数相同，那么 $m$ 必定整除 $(a - b)$

因此，问题转化为：**计算 $|a - b|$ 的正因数个数**。

### 算法设计

要计算一个正整数 $n$ 的因数个数，我们可以使用以下方法：

1. 初始化计数器 $\texttt{count} = 0$
2. 遍历 $i$ 从 $1$ 到 $\sqrt{n}$：
   - 如果 $n$ 能被 $i$ 整除：
     - 增加计数器（$i$ 是一个因数）
     - 如果 $i \neq n/i$，再增加计数器（$n/i$ 是另一个因数）
3. 返回计数器的值

这种方法的时间复杂度为 $O(\sqrt{n})$，对于 $n \leq 10^9$ 来说是完全可行的。

### 特殊情况处理

- 当 $a = 0$ 且 $b = 0$ 时，程序结束
- 由于 $a$ 和 $b$ 是不同的整数，$|a - b| > 0$，我们不需要担心除零错误

## 解题思路总结

1. 读取输入 $a$ 和 $b$
2. 如果 $a = 0$ 且 $b = 0$，结束程序
3. 计算 $d = |a - b|$
4. 计算 $d$ 的正因数个数
5. 输出结果

## 复杂度分析

- **时间复杂度**：$O(\sqrt{d})$，其中 $d = |a - b|$，对于每个测试用例
- **空间复杂度**：$O(1)$，只使用了常数级别的额外空间

## 代码实现

```cpp
// The Turanga Leela Problem

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int countDivisors(int n) {
    int count = 0;
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            count++;
            if (i != n / i) count++;
        }
    }
    return count;
}

int main() {
    int a, b;
    while (cin >> a >> b && (a || b)) {
        int diff = abs(a - b);
        cout << countDivisors(diff) << endl;
    }
    return 0;
}
```
