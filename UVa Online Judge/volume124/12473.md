# 题目翻译

回文是指从左到右读和从右到左读都相同的字符串。给定两个字符串 $A$ 和 $B$ ，你需要找到最长的回文字符串，该字符串同时是 $A$ 和 $B$ 的子序列。子序列是指通过从字符串中删除零个或多个字符后得到的序列。

例如，假设 $A = \texttt{"cfcfaafc"}$ ， $B = \texttt{"efagfc"}$ 。那么同时是 $A$ 和 $B$ 子序列的最长回文是 $\texttt{"faf"}$ 。因此答案是 $3$ 。

### 输入
输入的第一行包含一个正整数 $T$ （ $T \leq 100$ ）。接下来的 $T$ 组测试数据每组包含 $2$ 行。这两行分别是字符串 $A$ 和 $B$ 。 $A$ 和 $B$ 的长度不超过 $60$ 。所有字符串都只包含小写字母（`a` - `z` ）。输入中不会出现空字符串。

### 输出
对于每组测试数据，输出一行 `Case < x > : < y >` ，其中 $x$ 是测试用例编号， $y$ 是最长公共回文子序列的长度。

### 示例输入
```
3
cfcfaafc
efagfc
afbcdfca
bcadfcgxfka
palin
drome
```
### 示例输出
```
Case 1: 3
Case 2: 5
Case 3: 0
```

# 题解：最长公共回文子序列

## 问题分析
本题要求我们找出两个字符串 $A$ 和 $B$ 的最长公共子序列（$\texttt{LCS}$），且这个子序列必须是**回文**。这本质上是 **最长公共子序列（$\texttt{LCS}$）** 问题的一个变种，但增加了回文约束。

### 难点
1.  **双重约束**：既要满足是 $A$ 和 $B$ 的公共子序列，又要满足是回文。
2.  **直接暴力不可行**：如果枚举所有可能的公共子序列再检查回文，复杂度是指数级的，在 $n, m \leq 60$ 的情况下无法承受。

### 解题思路
既然不能暴力枚举，我们考虑使用**动态规划（$\texttt{DP}$）**，结合**记忆化搜索（$\texttt{Memoization}$）** 来系统地搜索所有可能的状态。

我们定义状态：
$$ dp[i][j][k][l] $$
表示在字符串 $A$ 的区间 $[i, j]$ 和字符串 $B$ 的区间 $[k, l]$ 内，能够构成的最长公共回文子序列的长度。

这个状态的定义非常直观，它完整地刻画了当前在两个字符串中分别考虑的区间范围。

#### 状态转移
我们需要考虑如何从当前状态转移到更小的子问题。对于一个回文子序列，其两端字符必须相同。因此，我们主要围绕**如何匹配两端的字符**来进行状态转移：

1.  **基础情况**：如果区间无效（ $i > j$ 或 $k > l$ ），则长度为 $0$ 。
2.  **单个字符作为回文中心**：当 $i == j$ 时，我们只需要检查 $A[i]$ 这个字符是否出现在 $B$ 的区间 $[k, l]$ 中。如果存在，则长度为 $1$，否则为 $0$。
3.  **一般情况（ $i < j$ ）**：
    *   **不匹配 $A[i]$ 或 $A[j]$**：我们可以选择忽略 $A[i]$ 或 $A[j]$，从子区间 $[i+1, j]$ 或 $[i, j-1]$ 中寻找答案。即：
        $$ r = \max(r, dfs(i+1, j, k, l),\ dfs(i, j-1, k, l)) $$
    *   **匹配 $A[i]$ 和 $A[j]$ 作为回文两端**：这需要 $A[i] == A[j]$。然后，我们需要在 $B$ 的区间 $[k, l]$ 中找到**两个位置 $p$ 和 $q$** （ $k \leq p < q \leq l$ ），使得 $B[p] == B[q] == A[i]$ 。这两个字符将作为 $B$ 中对应回文的两端。找到后，回文长度增加 $2$ ，问题转化为在内部的子区间寻找最长公共回文子序列：
        $$ inner = dfs(i+1, j-1, p+1, q-1) $$
        $$ r = \max(r, inner + 2) $$

通过以上转移，我们能够枚举所有可能的回文构建方式。由于状态数量为 $O(n^2 m^2)$ ，在 $n, m \leq 60$ 时最大约为 $60^4 \approx 1.3 \times 10^7$ ，配合记忆化搜索的剪枝，可以在规定时间内求解。

## 算法流程
1.  读取测试用例数 $T$。
2.  对于每个测试用例：
    a. 读取字符串 $A$ 和 $B$。
    b. 初始化四维 $dp$ 数组为 $-1$ （表示未计算）。
    c. 调用记忆化搜索函数 $dfs(0, n-1, 0, m-1)$ 计算答案。
    d. 按格式输出结果。

## 时间复杂度
*   **状态数**： $O(n^2 m^2)$ ，即 $O(60^4)$ 。
*   **每个状态的转移**：在最坏情况下，需要遍历 $B$ 区间内所有可能的字符对 $(p, q)$ ，复杂度为 $O(m^2)$。
*   **总复杂度上界**： $O(n^2 m^4)$ ，在极限情况下理论值很大。但在实际运行中，由于以下几个原因，算法通常能快速完成：
    *   记忆化避免了重复计算。
    *   只有当 $A[i] == A[j]$ 时才会进入双重循环，很多状态不会执行该操作。
    *   字符串长度仅为 $60$ ，常数较小。

## 空间复杂度
*   主要用于存储四维 $dp$ 数组，空间复杂度为 $O(n^2 m^2)$ ，即 $O(60^4 \times 4\ \texttt{bytes}) \approx 300\ \texttt{MB}$ 。这在现代竞赛环境的内存限制（通常 $256$ $\texttt{MB}$ 或 $512$ $\texttt{MB}$）内是可行的，但已经接近边界。这也是此解法能通过但并非最优的主要原因。

## 代码实现

```cpp
// Common Palindrome
// UVa ID: 12473
// Verdict: Accepted
// Submission Date: 2026-01-01
// UVa Run Time: 4.600s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int dp[61][61][61][61];
string A, B;
int n, m;

int dfs(int i, int j, int k, int l) {
    if (i > j || k > l) return 0;
    int &r = dp[i][j][k][l];
    if (~r) return r;
    r = 0;
    // 尝试匹配 A[i] 和 A[j]（如果 i != j）作为回文的两端
    if (i == j) {
        // 单个字符
        char ch = A[i];
        for (int p = k; p <= l; ++p)
            if (B[p] == ch) return r = 1;
        return r = 0;
    } else {
        // 情况1：不使用 A[i] 和 A[j]
        r = max(r, dfs(i + 1, j, k, l));
        r = max(r, dfs(i, j - 1, k, l));
        // 情况2：如果 A[i] == A[j]，尝试在 B 中找到匹配的相同字符作为两端
        if (A[i] == A[j]) {
            // 在 B 中寻找两个位置 p, q (k <= p < q <= l) 使得 B[p] == B[q] == A[i]
            for (int p = k; p <= l; ++p) {
                if (B[p] == A[i]) {
                    for (int q = p + 1; q <= l; ++q) {
                        if (B[q] == A[i]) {
                            // 找到一对匹配
                            int inner = dfs(i + 1, j - 1, p + 1, q - 1);
                            r = max(r, inner + 2);
                        }
                    }
                }
            }
        }
        // 情况3：尝试用 A[i] 匹配 B 中的某个字符，或者用 A[j] 匹配 B 中的某个字符
        // 这里通过递归已经覆盖
    }
    return r;
}

int main() {
    int T;
    cin >> T;
    for (int t = 1; t <= T; ++t) {
        cin >> A >> B;
        n = A.size(), m = B.size();
        memset(dp, -1, sizeof(dp));
        cout << "Case " << t << ": " << dfs(0, n - 1, 0, m - 1) << '\n';
    }
    return 0;
}
```

## 代码要点注释
*   `dp[61][61][61][61]` ：四维记忆化数组，初始化为 $-1$。
*   `dfs(i, j, k, l)` ：核心递归函数，计算状态 $dp[i][j][k][l]$。
*   `if (~r)` ：利用位运算判断 $r$ 是否为 $-1$，是 $\texttt{C/C++}$ 中常见的判断 `int` 是否为 $-1$ 的简洁写法。
*   状态转移逻辑严格按照前述分析实现，清晰地将回文构建分解为“匹配两端”和“忽略一端”的情况。

## 总结
本题通过定义四维 $\texttt{DP}$ 状态，并利用记忆化搜索实现状态转移，巧妙地解决了“最长公共回文子序列”这一复杂问题。尽管状态空间较大，但由于数据范围小，且实际搜索树被大量剪枝，该解法能够在时限内正确运行。它体现了将复杂约束分解、并通过动态规划系统化枚举的思想。对于希望进一步挑战的读者，可以思考如何优化状态表示或转移过程，以降低时间或空间复杂度。
