## 题目描述

中国正在建造一座太空电梯，这将大大降低发射探测器和卫星的成本。然而，中国人非常迷信，因此对电梯楼层编号有特殊要求：他们不使用任何包含数字 “$4$” 或数字序列 “$13$” 的编号。例如，他们不使用第 $4$ 层、第 $13$ 层、第 $134$ 层或第 $113$ 层，但会使用第 $103$ 层。因此，前几个楼层的编号依次是：

$1$, $2$, $3$, $5$, $6$, $7$, $8$, $9$, $10$, $11$, $12$, $15$, $16$, $\dots$

现在给定楼层序号 $N$ （即第 $N$ 个吉利楼层），需要输出对应的楼层编号。

**输入格式** ： 输入包含多个测试用例，每行一个整数 $N$ 。  
**输出格式** ： 对于每个测试用例，输出一行，表示第 $N$ 个吉利楼层编号。  
**数据范围** ： $1 \leq N \leq 10^{18}$ 。

## 题目分析

这是一个典型的 **数位动态规划** 问题，也可以看作是在一个特殊进制下的计数问题。题目要求我们找出第 $N$ 个“吉利数”，即不包含数字 $4$ 且不包含子串 $13$ 的正整数。

### 难点
1. **数据范围巨大** ： $N$ 最大可达 $10^{18}$ ，不能使用暴力枚举（逐个检查数字是否吉利）。
2. **双重限制** ： 既要排除数字 $4$ ，又要排除子串 $13$ ，这增加了计数的复杂度。

### 核心思路

我们可以将问题分解为两个子问题：
1. **计数问题** ： 给定一个数 $x$ ，如何快速计算区间 $[1, x]$ 内有多少个吉利数？
2. **查找问题** ： 如何找到第 $N$ 个吉利数？

对于第一个子问题，可以使用 **数位动态规划** 来解决。对于第二个子问题，由于吉利数的数量随着 $x$ 增大而单调递增，我们可以使用 **二分查找** 来找到满足条件的 $x$ 。

## 解题思路详解

### 1. 数位动态规划设计

我们定义 `countValid(x)` 函数，用于计算 $[1, x]$ 内吉利数的个数。实现这个函数需要使用数位动态规划。

**状态定义** ：  
设数字 $x$ 的十进制表示为 $digits[0\dots length-1]$ 。我们使用记忆化搜索，状态为：
- `pos` ：当前处理到第几位（从最高位开始）。
- `hasOne` ：前一位是否是 $1$ （用于判断是否形成 $13$ ）。
- `isLimit` ：当前位是否受到 $x$ 的限制（即前面的位是否都与 $x$ 对应位相等）。

**状态转移** ：  
对于当前位置，我们可以选择的数字是 $0$ 到 $upper$ ，其中 $upper$ 在受到限制时为 $digits[pos]$ ，否则为 $9$ 。在选择数字时：
- 跳过数字 $4$ 。
- 如果前一位是 $1$ （即 `hasOne` 为真），则跳过数字 $3$ （避免形成 $13$ ）。

**记忆化** ：  
只有当 `isLimit` 为假时，才可以将结果存入缓存，因为限制状态下的结果不能复用。

**边界条件** ：  
当 `pos == len` 时，说明成功构造了一个有效数字（包括 $0$ ），返回 $1$ 。最后，我们需要减去 $0$ ，因为题目要求从 $1$ 开始计数。

### 2. 二分查找

由于 `countValid(x)` 是单调不减的，我们可以使用二分查找来找到第 $N$ 个吉利数。具体来说，我们寻找最小的 $x$ ，使得 `countValid(x) >= N` 。

**二分范围** ：  
- 下界： $1$ 。
- 上界：需要足够大。由于 $N$ 最大为 $10^{18}$ ，而吉利数大约占所有数的 $80\%$ （跳过 $4$ 和 $13$ ），所以第 $10^{18}$ 个吉利数大约在 $1.25 \times 10^{18}$ 左右。为安全起见，可以将上界设为 $10^{19}$ 。

### 3. 时间复杂度分析

- **数位动态规划** ： 状态数为 $O(\texttt{length} \times 2)$ ，其中 $\texttt{lentgth}$ 为数字的位数（最大 $19$ ），每个状态最多枚举 $10$ 个数字，所以每次 `countValid` 调用复杂度约为 $O(19 \times 2 \times 10) = O(380)$ 。
- **二分查找** ： 最多需要 $O(\log(10^{19})) \approx O(63)$ 次 `countValid` 调用。
- **总复杂度** ： $O(380 \times 63) \approx O(24000)$ ，完全可以在时限内完成。

```cpp
// Space Elevator

#include <bits/stdc++.h>
using namespace std;

// 使用 unsigned long long 避免溢出
typedef unsigned long long ULL;

// 记忆化数组：dp[pos][hasOne] 和 visited[pos][hasOne]
ULL dp[25][2];
bool visited[25][2];
string digits;
int len;

// 数位 DP：统计 [0, x] 中吉利数的个数
ULL dfs(int pos, bool hasOne, bool isLimit) {
    // 到达最后一位，成功构造一个数（包括 0）
    if (pos == len) return 1;
    
    // 非限制状态才能使用记忆化
    if (!isLimit && visited[pos][hasOne]) {
        return dp[pos][hasOne];
    }
    
    // 当前位可选数字的上限
    int upper = isLimit ? digits[pos] - '0' : 9;
    ULL res = 0;
    
    // 枚举当前位的所有可能数字
    for (int d = 0; d <= upper; d++) {
        if (d == 4) continue; // 跳过数字 4
        if (hasOne && d == 3) continue; // 前一位是 1 时跳过 3（避免 13）
        
        // 递归处理下一位，更新 hasOne 状态
        res += dfs(pos + 1, d == 1, isLimit && (d == upper));
    }
    
    // 只在非限制状态保存结果
    if (!isLimit) {
        dp[pos][hasOne] = res;
        visited[pos][hasOne] = true;
    }
    
    return res;
}

// 计算 [1, x] 中吉利数的个数
ULL countValid(ULL x) {
    if (x == 0) return 0;
    
    // 将 x 转换为字符串，便于按位处理
    digits = to_string(x);
    len = digits.length();
    
    // 重置 visited 数组
    memset(visited, 0, sizeof(visited));
    
    // 计算 [0, x] 的吉利数个数，然后减去 0（因为题目从 1 开始）
    return dfs(0, false, true) - 1;
}

// 二分查找第 n 个吉利数
ULL findNthValid(ULL n) {
    // 二分查找范围：下界 1，上界 1e19（足够大）
    ULL left = 1, right = 10000000000000000000ULL;
    
    while (left < right) {
        ULL mid = left + (right - left) / 2;
        if (countValid(mid) >= n)
            right = mid;
        else
            left = mid + 1;
    }
    
    return left;
}

int main() {
    ULL n;
    while (cin >> n) {
        cout << findNthValid(n) << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于将问题转化为数位动态规划的计数问题，然后通过二分查找找到第 $N$ 个满足条件的数。数位动态规划的状态设计需要同时考虑数字 $4$ 和子串 $13$ 的限制，记忆化搜索可以大大提升效率。二分查找的范围需要设置得足够大，以覆盖 $N$ 最大时的情形。

这种 **数位动态规划+ 二分查找** 的组合是解决“第 $N$ 个满足某种条件的数”这类问题的经典方法，值得掌握。
