## 题目描述

$\texttt{Nlogonia}$ 城市的道路系统由 $N$ 个环形交叉路口和 $N-1$ 条街道组成，构成一棵树。城市有两家酒店：廉价酒店位于路口 $B$ ，昂贵酒店位于路口 $C$ 。游客参加完在路口 $A$ 举办的派对后，决定随机游走寻找酒店，并入住找到的第一家酒店。在每个路口，他以均匀概率随机选择一条连接的街道离开（可能走回头路）。求他先到达廉价酒店（而非昂贵酒店）的概率。

**输入格式**： 多个测试用例。每个用例第一行四个整数 $N, A, B, C$ ，接着 $N-1$ 行每行两个整数 $X, Y$ 表示一条边。

**输出格式**： 对于每个用例输出概率，保留 $6$ 位小数。

**限制**： $3 \le N \le 100$ ， $B \ne C$ ， $A \ne B$ ， $A \ne C$ 。

## 题目分析

本题是一个 **树上随机游走** 的概率问题。由于游客在每个节点随机选择出边（包括可能走回父节点），这是一个马尔可夫过程，不能通过简单的 $\texttt{DFS}$ 或递推解决，需要建立线性方程组求解。

### 关键点理解

1. **状态定义**： 设 $p[u]$ 表示从节点 $u$ 出发， **先到达** 节点 $B$ （廉价酒店）的概率。
   
2. **边界条件**：
   - 若 $u = B$ ，则 $p[u] = 1$ ，因为已经到达廉价酒店。
   - 若 $u = C$ ，则 $p[u] = 0$ ，因为已经到达昂贵酒店，不符合“先到达廉价酒店”的条件。

3. **状态转移**： 对于普通节点 $u$ （既不是 $B$ 也不是 $C$ ），设其度数（相邻节点数）为 $\text{deg}(u)$ 。在 $u$ 处，游客以 $\frac{1}{\text{deg}(u)}$ 的概率走到每个邻居 $v$ ，然后从 $v$ 继续游走。因此：
   $$
   p[u] = \frac{\sum_{v \in \text{neighbors}(u)} p[v]}{\text{deg}(u)}
   $$

4. **方程形式**： 将上式变形为：
   $$
   \text{deg}(u) \cdot p[u] - \sum_{v \in \text{neighbors}(u)} p[v] = 0
   $$
   加上边界条件的两个方程（ $p[B]=1$ ， $p[C]=0$ ），我们得到 $N$ 个方程、 $N$ 个未知数的线性方程组。

## 解题思路

1. **建立线性方程组**：
   - 对每个节点 $u$ ，根据其身份（ $B$ 、 $C$ 或普通节点）填写增广矩阵的一行。
   - 矩阵大小为 $N \times (N+1)$ ，最后一列是常数项。

2. **高斯消元求解**：
   - 由于 $N \le 100$ ，直接使用高斯消元即可。
   - 注意处理浮点数精度问题（使用 $\text{EPS}=10^{-8}$ 判断零）。

3. **输出结果**：
   - 消元后得到解向量 $p[1 \dots N]$ ，输出 $p[A]$ 即为所求概率。

## 算法步骤

1. 读入 $N, A, B, C$ 和 $N-1$ 条边，构建邻接表。
2. 初始化 $N \times (N+1)$ 的增广矩阵：
   - 若 $u = B$ ： `mat[u][u]=1.0; mat[u][N+1]=1.0`
   - 若 $u = C$ ： `mat[u][u]=1.0; mat[u][N+1]=0.0`
   - 否则： `mat[u][u]=deg(u);` 对每个邻居 $v$ ： `mat[u][v] = -1.0; mat[u][N+1]=0.0`
3. 执行高斯消元：
   - 选主元以增强数值稳定性。
   - 消元得到上三角矩阵。
   - 回代求解 $p[u]$ 。
4. 输出 $p[A]$ ，保留 $6$ 位小数。

## 时间复杂度

- 建图： $O(N)$ 。
- 高斯消元： $O(N^3)$ ，由于 $N \le 100$ ，完全可行。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 105;
const double EPS = 1e-8;
vector<int> graph[MAX_N];      // 邻接表存储树
double mat[MAX_N][MAX_N + 1];  // 增广矩阵
double prob[MAX_N];            // 概率解

// 高斯消元求解线性方程组
void gaussElimination(int n) {
    for (int i = 1; i <= n; i++) {
        // 寻找主元（最大绝对值）
        int pivot = i;
        for (int j = i + 1; j <= n; j++)
            if (fabs(mat[j][i]) > fabs(mat[pivot][i]))
                pivot = j;
        
        // 交换当前行与主元行
        if (pivot != i)
            for (int j = 1; j <= n + 1; j++)
                swap(mat[i][j], mat[pivot][j]);
        
        // 如果主元接近零，跳过（实际上在本题中不会发生）
        if (fabs(mat[i][i]) > EPS) {
            // 消去下方行的第i列
            for (int j = i + 1; j <= n; j++) {
                double factor = mat[j][i] / mat[i][i];
                for (int k = i; k <= n + 1; k++)
                    mat[j][k] -= factor * mat[i][k];
            }
        }
    }
    
    // 回代求解
    for (int i = n; i >= 1; i--) {
        if (fabs(mat[i][i]) < EPS) continue;  // 零行，解不唯一（本题不会）
        double sum = 0.0;
        for (int j = i + 1; j <= n; j++)
            sum += mat[i][j] * prob[j];
        prob[i] = (mat[i][n + 1] - sum) / mat[i][i];
    }
}

int main() {
    int N, A, B, C;
    // 处理多个测试用例直到文件结束
    while (cin >> N >> A >> B >> C) {
        // 初始化邻接表
        for (int i = 1; i <= N; i++)
            graph[i].clear();
        
        // 读入N-1条边，构建树
        for (int i = 0; i < N - 1; i++) {
            int X, Y;
            cin >> X >> Y;
            graph[X].push_back(Y);
            graph[Y].push_back(X);
        }
        
        // 初始化增广矩阵为零
        for (int i = 1; i <= N; i++)
            for (int j = 1; j <= N + 1; j++)
                mat[i][j] = 0.0;
        
        // 根据每个节点的类型建立方程
        for (int u = 1; u <= N; u++) {
            int deg = graph[u].size();  // 度数（邻居数）
            
            if (u == B) {
                // p[B] = 1
                mat[u][u] = 1.0;
                mat[u][N + 1] = 1.0;
            } else if (u == C) {
                // p[C] = 0
                mat[u][u] = 1.0;
                mat[u][N + 1] = 0.0;
            } else {
                // 普通节点：deg(u)*p[u] - sum(p[neighbors]) = 0
                mat[u][u] = deg;
                for (int v : graph[u])
                    mat[u][v] = -1.0;    // 邻居系数为-1
                mat[u][N + 1] = 0.0;     // 常数项为0
            }
        }
        
        // 高斯消元求解
        gaussElimination(N);
        
        // 输出从起点A出发先到B的概率
        cout << fixed << setprecision(6) << prob[A] << endl;
    }
    return 0;
}
```
## 总结

本题的关键在于识别出这是一个 **随机游走** 问题，需要建立线性方程组求解概率。由于树结构保证了方程组有唯一解，且规模小，直接高斯消元即可。注意边界条件的处理（酒店节点概率固定）和浮点数精度控制。
