## 题目翻译

来自抗癌基金会（$\texttt{FCC}$）的研究人员宣布了一项化学领域的革命性发现：他们发现了如何让碳原子与任意数量的其他碳原子结合，从而能够制造出比四价碳形成的分子更复杂的分子。据 $\texttt{FCC}$ 称，这将有助于开发新药，可能在对抗癌症中起到关键作用。

你需要编写一个程序，给定两个分子的结构，判断它们是否等价。

### 输入

输入包含多个测试用例。每个测试用例的第一行包含一个整数 $N$ ，表示两个分子中的原子数量。原子用从 $1$ 到 $N$ 的整数标识。接下来的 $2N-2$ 行描述化学键：前 $N-1$ 行描述第一个分子的化学键，后 $N-1$ 行描述第二个分子的化学键。每行包含两个整数 $A$ 和 $B$ ，表示原子 $A$ 和 $B$ 之间存在化学键。

### 输出

对于每个测试用例，你的程序必须输出一行，包含一个字符：如果分子等价则输出 `S` ，否则输出 `N` 。

### 限制条件

* $1 \leq A, B \leq N$

## 题目分析与解题思路

### 问题本质

本题要求判断两个分子结构是否等价。根据题目描述：

1.  分子结构是由原子（节点）和化学键（边）组成的。
2.  结构中不含环，即每个分子是一个**无向无环连通图** —— 也就是一棵**树**。
3.  两个分子等价，意味着它们的树结构可以通过“移动原子”（即重排节点编号）而变得完全相同，同时保持边的连接关系不变。这在图论中被称为**树同构**问题。

因此，本题的核心是**判断给定的两棵无根树是否同构**。

### 树同构简介

两棵树 $T_1$ 和 $T_2$ 同构，意味着存在一个一一映射（双射） $f$ 从 $T_1$ 的节点集到 $T_2$ 的节点集，使得对于 $T_1$ 中的任意一条边 $(u, v)$ ，在 $T_2$ 中都存在边 $(f(u), f(v))$ ，反之亦然。简单说，就是它们的“形状”完全相同，只是节点编号不同。

### 解题策略：$\texttt{AHU}$ 算法与重心分解

判断无根树同构的一个经典且高效的方法是 **$\texttt{AHU}$ 算法** （以发明者 $\texttt{Aho, Hopcroft, Ullman}$ 命名）。该算法的核心思想是为每棵树生成一个**唯一的、与节点编号无关的字符串编码**。如果两棵树的编码相同，则它们同构。

然而，由于树是无根的，选择不同的根节点可能会产生不同的编码。为了解决这个问题，我们结合**树的重心**：

1.  **树的重心** ：树中删除某节点后，使得剩余最大连通分量（子树）最小的节点。一棵树最多有两个重心。
    *   性质：以重心为根时，树的高度最小，编码更平衡。
    *   关键：**以不同重心为根生成的编码是等价的**。因此，如果两棵树同构，那么一棵树的某个重心为根的编码，必定会与另一棵树的某个重心为根的编码相同。

2.  **算法步骤** ：
    a.  对第一棵树 $T_1$ ，找出其所有重心（最多两个）。
    b.  对 $T_1$ 的每个重心，以其为根，运行 $\texttt{DFS}$ 生成 $\texttt{AHU}$ 编码。将所有编码存入一个集合 $S$ 中。
    c.  对第二棵树 $T_2$ ，同样找出其所有重心。
    d.  对 $T_2$ 的每个重心，以其为根，生成 $\texttt{AHU}$ 编码。
    e.  检查 $T_2$ 的任一重心编码是否存在于集合 $S$ 中。若存在，则两棵树同构，输出 `S` ；否则输出 `N` 。

### $\texttt{AHU}$ 编码生成细节（递归）

对于一个以节点 $u$ 为根的子树，其 $\texttt{AHU}$ 编码生成过程如下：

1.  如果 $u$ 是叶子节点（没有子节点），则其编码为最简单的 `()` 。
2.  否则，递归计算 $u$ 的所有子节点 $v$ 的编码 $code(v)$ 。
3.  将所有子节点的编码 $code(v)$ 收集到一个列表中，并对该列表进行**字典序排序**。排序至关重要，它确保了无论子树的顺序如何，只要结构相同，最终编码就相同。
4.  节点 $u$ 的编码为： `(` + 排序后的子节点编码按顺序拼接 + `)` 。

例如，一个节点有两个叶子子节点，其编码为 `(()())` 。排序保证了两个子节点的顺序不会影响最终编码。

### 复杂度分析

*   **寻找重心** ：通过一次 $\texttt{DFS}$ 即可完成，时间复杂度 $O(N)$ 。
*   **生成编码** ：对于每个重心，需要遍历整棵树。每个节点生成编码时，需要对其子节点的编码列表进行排序。在最坏情况下，如果树退化成链，根节点的子节点编码列表长度为 $O(N)$ ，排序复杂度为 $O(N \log N)$ 。但考虑到树的结构，整体平均复杂度可以接受。对于 $N \leq 10^4$ 的数据范围，该算法可以通过。
*   **总体复杂度** ：由于最多有两个重心，整体复杂度约为 $O(N \log N)$ ，在限制范围内是可行的。

### 边界情况与注意事项

1.  $N=2$ ：两棵树都只有一条边，显然同构。
2.  单重心与双重心：算法已经涵盖了这两种情况。
3.  输入可能有多个测试用例，需要持续读取直到文件结束。
4.  编码使用 `string` 类型，可能较长，但 $N \leq 10^4$ 时，编码长度也在可控范围内。

### 为什么这种方法有效？

1.  **确定性** ：$\texttt{AHU}$ 编码是树结构的唯一表示（在同构意义下）。只要两棵树同构，无论选择哪个重心作为根，其编码集合必定有交集。
2.  **无根树处理** ：通过考虑所有重心，我们覆盖了无根树所有可能的“根视角”。
3.  **实现简洁** ：算法主要包含 $\texttt{DFS}$ 和字符串排序，易于实现。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;

class Tree {
private:
    vector<vector<int>> adj; // 邻接表
    int n; // 节点数
    vector<int> parent, depth, subtreeSize; // DFS 相关数组

    // DFS 计算父节点、深度和子树大小
    void dfs(int u, int p) {
        parent[u] = p;
        subtreeSize[u] = 1;
        for (int v : adj[u]) {
            if (v == p) continue;
            depth[v] = depth[u] + 1;
            dfs(v, u);
            subtreeSize[u] += subtreeSize[v];
        }
    }

    // 寻找树的所有重心
    vector<int> findCentroids() {
        dfs(1, -1); // 从节点1开始DFS，假设树是连通的
        vector<int> centroids;
        int minMax = n + 1; // 记录最小的最大子树大小
        
        for (int i = 1; i <= n; ++i) {
            int maxSubtree = n - subtreeSize[i]; // 考虑父节点方向的子树
            for (int v : adj[i]) {
                if (v == parent[i]) continue;
                maxSubtree = max(maxSubtree, subtreeSize[v]);
            }
            
            if (maxSubtree < minMax) {
                minMax = maxSubtree;
                centroids.clear();
                centroids.push_back(i);
            } else if (maxSubtree == minMax) {
                centroids.push_back(i);
            }
        }
        
        return centroids;
    }

    // 生成以 u 为根的子树 AHU 编码
    string encodeTree(int u, int parent) {
        vector<string> childrenCodes;
        for (int v : adj[u]) {
            if (v == parent) continue;
            childrenCodes.push_back(encodeTree(v, u));
        }
        
        // 排序是关键，确保结构相同的子树编码一致
        sort(childrenCodes.begin(), childrenCodes.end());
        
        string code = "(";
        for (const string& childCode : childrenCodes) {
            code += childCode;
        }
        code += ")";
        
        return code;
    }

public:
    Tree(int size) : n(size) {
        adj.resize(n + 1);
        parent.resize(n + 1);
        depth.resize(n + 1);
        subtreeSize.resize(n + 1);
    }

    // 从输入构建树
    void build() {
        for (int i = 0; i < n - 1; ++i) {
            int a, b;
            cin >> a >> b;
            adj[a].push_back(b);
            adj[b].push_back(a);
        }
    }

    // 判断当前树是否与另一棵树同构
    bool isIsomorphicTo(Tree& other) {
        if (n != other.n) return false; // 节点数不同肯定不同构
        
        vector<int> centroids1 = findCentroids();
        vector<int> centroids2 = other.findCentroids();
        
        set<string> codes1;
        for (int root : centroids1) {
            string code = encodeTree(root, -1);
            codes1.insert(code);
        }
        
        for (int root : centroids2) {
            string code = other.encodeTree(root, -1);
            if (codes1.count(code)) {
                return true;
            }
        }
        
        return false;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int N;
    while (cin >> N) {
        Tree tree1(N);
        Tree tree2(N);
        
        tree1.build();
        tree2.build();
        
        if (tree1.isIsomorphicTo(tree2)) cout << "S\n";
        else cout << "N\n";
    }
    
    return 0;
}
```

## 总结

本题将化学分子结构等价性问题转化为图论中的树同构问题，通过经典的 $\texttt{AHU}$ 算法结合重心分解，可以高效、准确地判断两棵无根树是否同构。算法的核心在于为树生成与节点编号无关的唯一编码，并通过考虑所有重心来适应无根的情况。实现时需要注意递归生成编码时的排序步骤，这是保证编码一致性的关键。该算法的时间复杂度为 $O(N \log N)$ ，能够满足题目 $N \leq 10^4$ 的要求。
