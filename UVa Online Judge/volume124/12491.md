## 题目描述

给定两个由 $0$ 和 $1$ 组成的字符串集合 $A$ 和 $B$，每个集合中的字符串称为“单词”。你需要判断是否存在一个非空的字符串 $S$，使得 $S$ 可以分别由 $A$ 中的若干个单词（至少一个）拼接而成，也可以由 $B$ 中的若干个单词（至少一个）拼接而成。如果存在这样的 $S$，输出 `'S'`，否则输出 `'N'`。

### 输入格式

每个测试用例第一行包含两个整数 $N_1$ 和 $N_2$，分别表示集合 $A$ 和 $B$ 的单词数量。接下来 $N_1$ 行是 $A$ 中的单词，再接下来 $N_2$ 行是 $B$ 中的单词。

### 输出格式

对于每个测试用例，输出一行一个字符：`'S'` 或 `'N'`。

### 限制条件

- $1 \leq N_1, N_2 \leq 20$
- 每个单词长度至少为 $1$，至多为 $40$，只包含字符 `'0'` 和 `'1'`。

### 样例输入

```
2 2
010
11
0
101
3 1
1
00
000
01
1 1
00
000
```

### 样例输出

```
S
N
S
```

## 题目分析

本题是一个典型的 **$\texttt{Post Correspondence Problem（PCP）}$** 的简化变种。经典的 $\texttt{PCP}$ 问题判断是否存在一个索引序列，使得两个字符串序列的拼接相等。本题中，两个集合的单词可以重复使用任意多次（包括同一个单词多次使用），并且每次拼接至少使用一个单词。

### 问题本质

设集合 $A = \{a_1, a_2, \ldots, a_{N_1}\}$，集合 $B = \{b_1, b_2, \ldots, b_{N_2}\}$。我们需要判断是否存在两个非空序列（长度不限）：
$$
a_{i_1} a_{i_2} \cdots a_{i_p} = b_{j_1} b_{j_2} \cdots b_{j_q}
$$
其中 $p \ge 1$，$q \ge 1$。

### 为什么不是简单匹配？

由于两个集合的单词长度不同，直接枚举拼接结果是不可能的——拼接长度可以无限增长。例如，如果 $A = \{"0", "1"\}$，$B = \{"01"\}$，那么我们可以不断地拼接 `"0"` 和 `"1"` 来匹配 `"01"` 的重复。因此，我们必须设计一个能够在有限状态空间内搜索的算法。

---

## 解题思路

### 核心思想：差值搜索（$\texttt{Difference Search}$）

考虑两个字符串 $s$ 和 $t$，它们分别由 $A$ 和 $B$ 的单词拼接而成但目前尚未完全相等。将 $s$ 和 $t$ 对齐到公共前缀，那么较长的字符串会多出一段“剩余部分”。这个剩余部分就是我们需要在下一步用另一个集合的单词来匹配的。

**关键观察**：我们可以用一对字符串 $(u, v)$ 来表示当前状态，其中 $u$ 是当前 $A$ 侧尚未匹配的多余部分，$v$ 是 $B$ 侧尚未匹配的多余部分。如果某时刻 $u = v$，则找到了一个公共串。

### 状态表示

定义状态 $(remainA, remainB)$ 表示：当前已经匹配了公共前缀，$A$ 侧还有剩余未匹配部分 $remainA$，$B$ 侧还有剩余未匹配部分 $remainB$。

**初始状态**：任意一对单词 $(a_i, b_j)$ 构成初始状态。如果 $a_i = b_j$，则直接找到解。否则，较短的字符串成为空字符串，较长的字符串的剩余部分成为新状态。

### 状态转移

假设当前状态为 $(x, y)$：

1. 如果 $x = y$，则找到解。
2. 如果 $|x| < |y|$，说明 $B$ 侧还有多余部分。我们需要用 $A$ 中的单词扩展 $x$，使其匹配 $y$ 的前缀。具体地：
   - 对于 $A$ 中的每个单词 $w$，构造 $x' = x + w$。
   - 设 $len = \min(|x'|, |y|)$。如果 $x'[0:len] = y[0:len]$，则公共前缀长度为 $len$。
   - 新的状态为 $(x'[len:], \; y[len:])$。
   - 如果新状态的两个字符串相等，则找到解。
3. 如果 $|x| > |y|$，则对称地用 $B$ 中的单词扩展 $y$。

### 为什么状态有限

每个单词长度 $\le 40$，因此任何剩余部分 $remainA$ 或 $remainB$ 一定是某个单词的后缀（因为它是从完整单词中切掉前缀得到的）。两个集合总共有 $N_1 + N_2$ 个单词，每个单词的后缀最多有 $40$ 种。因此，不同状态的总数 ≤ $(40 \times (N_1 + N_2))^2$，对于 $N_1, N_2 \le 20$ 来说，状态数在万级别，完全可以承受。

### 算法选择：$\texttt{BFS}$ 或 $\texttt{DFS}$

由于我们只需判断是否存在解，并且状态图可能有环（例如反复使用相同的单词），使用 $\texttt{BFS}$ 可以避免深度优先的栈溢出，同时保证在有限步内找到解或遍历完所有可达状态。

---

## 算法步骤

1. 读入两个集合 $A$ 和 $B$。
2. 初始化队列和访问集合，将所有初始状态 $(a_i, b_j)$ 入队。
3. 执行 $\texttt{BFS}$：
   - 弹出队首状态 $(x, y)$。
   - 若 $x = y$，返回 $\texttt{true}$。
   - 若 $|x| < |y|$：
     - 遍历 $A$ 中每个单词 $w$，计算 $x' = x + w$。
     - 检查 $x'$ 和 $y$ 的最长公共前缀长度 $len$。
     - 若前缀相等，得到新状态 $(x'[len:], y[len:])$，未访问则入队。
   - 若 $|x| > |y|$，对称处理。
4. 若队列为空未找到，返回 $\texttt{false}$。

---

## 正确性证明

**完整性**：若存在解 $S = a_{i_1}\cdots a_{i_p} = b_{j_1}\cdots b_{j_q}$，考虑从第一个字符开始的匹配过程。每一步我们将 $A$ 和 $B$ 的当前剩余部分对齐，较短的被扩展，直到完全相等。这个过程对应 $\texttt{BFS}$ 中的一条路径，因此 $\texttt{BFS}$ 一定能找到该解。

**终止性**：由于状态数量有限，且 $\texttt{BFS}$ 不会重复访问相同状态，算法必然在有限步内终止。

## 代码实现

```cpp
// Words

// UVa Run Time: 0.010s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

bool puedeConcatenar(const vector<string>& A, const vector<string>& B) {
    // (剩余A串, 剩余B串)
    queue<pair<string, string>> q;
    set<pair<string, string>> visitado;

    // 初始状态：任意两个单词的组合作为起点
    for (const string& a : A) {
        for (const string& b : B) {
            if (a == b) return true;
            q.push({a, b});
            visitado.insert({a, b});
        }
    }

    while (!q.empty()) {
        auto [sa, sb] = q.front(); q.pop();

        if (sa == sb) return true;

        if (sa.size() < sb.size()) {
            // 尝试用A中的单词扩展sa
            for (const string& w : A) {
                string nuevaSa = sa + w;
                // 比较 nuevaSa 和 sb 的公共前缀
                int len = min(nuevaSa.size(), sb.size());
                if (nuevaSa.substr(0, len) == sb.substr(0, len)) {
                    string restaA = nuevaSa.substr(len);
                    string restaB = sb.substr(len);
                    if (restaA == restaB) return true;
                    if (!visitado.count({restaA, restaB})) {
                        visitado.insert({restaA, restaB});
                        q.push({restaA, restaB});
                    }
                }
            }
        } else {
            // 尝试用B中的单词扩展sb
            for (const string& w : B) {
                string nuevaSb = sb + w;
                int len = min(sa.size(), nuevaSb.size());
                if (sa.substr(0, len) == nuevaSb.substr(0, len)) {
                    string restaA = sa.substr(len);
                    string restaB = nuevaSb.substr(len);
                    if (restaA == restaB) return true;
                    if (!visitado.count({restaA, restaB})) {
                        visitado.insert({restaA, restaB});
                        q.push({restaA, restaB});
                    }
                }
            }
        }
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N1, N2;
    while (cin >> N1 >> N2) {
        vector<string> A(N1), B(N2);
        for (int i = 0; i < N1; ++i) cin >> A[i];
        for (int i = 0; i < N2; ++i) cin >> B[i];

        cout << (puedeConcatenar(A, B) ? 'S' : 'N') << '\n';
    }
    return 0;
}
```

## 复杂度分析

- 时间复杂度：$O(\text{状态数} \times (N_1 + N_2) \times L)$，其中 $L \le 40$ 为单词长度。状态数上界为 $O((N_1 \cdot 40) \cdot (N_2 \cdot 40)) = O(1600 \cdot N_1 N_2)$，实际远小于此。
- 空间复杂度：$O(\text{状态数})$，用于存储访问过的状态对。

## 总结

本题通过将问题转化为剩余字符串的匹配状态，并在有限状态空间上进行广度优先搜索，巧妙地避免了无限拼接的困境。这种“差值搜索”的思想在字符串拼接、文法等价性等问题的求解中具有广泛的应用价值。
