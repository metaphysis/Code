## 题目描述

魔方是一个经典的 $3$ 维拼图游戏，它有 $6$ 个面，每个面有 $9$ 个贴纸，总共 $54$ 个贴纸。初始状态下，每个面的 $9$ 个贴纸颜色相同。通过旋转各个面，可以打乱贴纸的位置。

每个面用一个字母表示： $\texttt{F}$（前面）、 $\texttt{B}$（后面）、 $\texttt{U}$（上面）、 $\texttt{D}$（下面）、 $\texttt{L}$（左面）、 $\texttt{R}$（右面） 。

旋转操作的定义如下：
- 大写字母（如 $\texttt{F}$）表示对应面顺时针旋转 $90^\circ$
- 小写字母（如 $\texttt{f}$）表示对应面逆时针旋转 $90^\circ$

一个有趣的性质：任何操作序列，如果重复足够多次，最终会使魔方回到初始状态。例如，序列 $\texttt{B}$ 重复 $4$ 次后，魔方回到初始状态。

给定一个操作序列，求使魔方回到初始状态所需的最少重复次数。

## 题目分析

这是一个典型的**排列群阶**问题。我们可以将魔方的 $54$ 个贴纸进行编号，每个操作序列对应一个排列 $P$。我们需要找到最小的正整数 $k$，使得 $P^k = I$（ $I$ 是恒等排列）。

根据群论知识，排列的阶等于其循环分解中所有循环长度的最小公倍数（$\texttt{LCM}$）。例如，如果一个排列可以分解为长度为 $3$、$5$、$7$ 的循环，那么它的阶就是 $\text{lcm}(3,5,7)=105$。

## 解题思路

### 1. 贴纸编号

首先需要为魔方的 $54$ 个贴纸进行编号。常见的编号方案有从 $0$ 开始编号和从 $1$ 开始编号两种。本题解采用从 $1$ 开始编号的方案，编号 $1$ 到 $54$，每个面的 $9$ 个贴纸按固定顺序编号。

### 2. 基本旋转的表示

每个基本旋转（ $\texttt{F}$、 $\texttt{f}$、 $\texttt{B}$、 $\texttt{b}$ 等）都是一个长度为 $54$ 的排列。我们需要精确描述每次旋转后，每个贴纸的新位置。

旋转的实质是 $4$ 个贴纸的轮换。例如，顺时针旋转一个面时， $4$ 个角块会循环轮换， $4$ 个边块也会循环轮换，同时相邻面的贴纸也会发生 $4$ 个一组的位置交换。

### 3. 核心算法

**步骤 1：初始化**
- 将排列 $P$ 初始化为恒等排列，即 $P[i] = i$（ $1 \le i \le 54$）

**步骤 2：应用操作序列**
- 遍历输入序列中的每个字符
- 根据字符调用对应的旋转函数，更新排列 $P$

**步骤 3：循环分解**
- 遍历所有贴纸 $i$（ $1$ 到 $54$）
- 如果贴纸 $i$ 未被访问过，沿着 $i \to P[i] \to P[P[i]] \to \cdots$ 追踪，直到回到 $i$，记录循环长度
- 标记访问过的贴纸，避免重复计算

**步骤 4：计算 $\texttt{LCM}$**
- 计算所有循环长度的最小公倍数，即为答案

### 4. 时间复杂度分析

- 每个测试用例需要遍历整个操作序列（长度 $\le 80$），每次操作更新 $54$ 个贴纸的位置
- 循环分解需要遍历 $54$ 个贴纸
- 总体时间复杂度 $O(54 \times L)$，其中 $L$ 是序列长度，完全满足题目限制

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// 1-indexed 编号方案，共54个贴纸
int p[55], t;  // 全局变量用于交换

// 最大公约数
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

// 4个贴纸轮换函数
// e=1: 顺时针轮换 a->b->c->d->a
// e=0: 逆时针轮换 a->d->c->b->a
void x(int a, int b, int c, int d, int e) {
    if (e) {  // 顺时针
        t = p[a];
        p[a] = p[b];
        p[b] = p[c];
        p[c] = p[d];
        p[d] = t;
    } else {  // 逆时针
        t = p[d];
        p[d] = p[c];
        p[c] = p[b];
        p[b] = p[a];
        p[a] = t;
    }
}

// F面旋转
void F(int e) {
    x(1, 7, 9, 3, e);   // 角块
    x(4, 8, 6, 2, e);   // 边块
    x(12, 30, 37, 27, e); // 相邻面调整
    x(15, 29, 40, 26, e);
    x(18, 28, 43, 25, e);
}

// B面旋转
void B(int e) {
    x(10, 21, 39, 36, e);
    x(13, 20, 42, 35, e);
    x(16, 19, 45, 34, e);
    x(54, 52, 46, 48, e);
    x(53, 49, 47, 51, e);
}

// U面旋转
void U(int e) {
    x(19, 25, 27, 21, e);
    x(22, 26, 24, 20, e);
    x(10, 1, 43, 52, e);
    x(11, 2, 44, 53, e);
    x(12, 3, 45, 54, e);
}

// D面旋转
void D(int e) {
    x(9, 18, 48, 39, e);
    x(8, 17, 47, 38, e);
    x(7, 16, 46, 37, e);
    x(30, 36, 34, 28, e);
    x(29, 33, 35, 31, e);
}

// L面旋转
void L(int e) {
    x(10, 16, 18, 12, e);
    x(13, 17, 15, 11, e);
    x(1, 19, 48, 30, e);
    x(4, 22, 51, 33, e);
    x(7, 25, 54, 36, e);
}

// R面旋转
void R(int e) {
    x(21, 3, 28, 46, e);
    x(24, 6, 31, 49, e);
    x(27, 9, 34, 52, e);
    x(45, 43, 37, 39, e);
    x(44, 40, 38, 42, e);
}

// 计算排列的阶
ll findOrder() {
    vector<bool> visited(55, false);
    ll lcm = 1;
    
    for (int i = 1; i <= 54; i++) {
        if (!visited[i]) {
            int len = 0;
            int cur = i;
            while (!visited[cur]) {
                visited[cur] = true;
                cur = p[cur];
                len++;
            }
            if (len > 0) {
                lcm = lcm / gcd(lcm, len) * len;
            }
        }
    }
    return lcm;
}

int main() {
    char s[85];
    
    while (~scanf("%s", s)) {
        int len = strlen(s);
        
        // 初始化排列为恒等排列
        for (int i = 1; i <= 54; i++) p[i] = i;
        
        // 应用序列中的每个旋转
        for (int i = 0; i < len; i++) {
            switch (s[i]) {
                case 'f': F(0); break;
                case 'F': F(1); break;
                case 'b': B(0); break;
                case 'B': B(1); break;
                case 'u': U(0); break;
                case 'U': U(1); break;
                case 'd': D(0); break;
                case 'D': D(1); break;
                case 'l': L(0); break;
                case 'L': L(1); break;
                case 'r': R(0); break;
                case 'R': R(1); break;
                default: break;  // 忽略非字母字符（如样例中的'1'）
            }
        }
        
        // 计算并输出结果
        ll result = findOrder();
        printf("%lld\n", result);
    }
    return 0;
}
