## 题目描述

$\texttt{Fernando}$ 喜欢画星星：他首先在圆周上标记 $N$ 个点，将圆周分成 $N$ 等份。然后，他将每个点连接到其之后的第 $k$ 个点（在模 $N$ 意义下），直到回到起点。

如果在这个过程中，$\texttt{Fernando}$ 经过了所有 $N$ 个点，那么这个星星被称为**完全星**（$\texttt{complete star}$）。

题目要求：给定 $N$，计算可以画出的不同完全星的数量。

**限制条件**：$3 \leq N < 2^{31}$

---

## 题目分析

### 1. 问题抽象

- 圆周上有 $N$ 个等分点，编号 $0$ 到 $N-1$。
- 从点 $0$ 出发，每次移动到 $(0 + k) \bmod N$，再移动到 $(0 + 2k) \bmod N$，依此类推。
- 这个过程会形成一个循环，循环的长度由 $k$ 和 $N$ 的最大公约数决定。

### 2. 数学推导

从点 $0$ 出发，经过的点序列为：
$$0, k, 2k, 3k, \dots \ (\text{mod } N)$$

这个序列会形成一个循环，循环的长度为：
$$\frac{N}{\gcd(N, k)}$$

要遍历所有 $N$ 个点，必须满足：
$$\frac{N}{\gcd(N, k)} = N$$

即：
$$\gcd(N, k) = 1$$

所以，**完全星**的条件就是 $k$ 与 $N$ 互质。

### 3. 不同星星的计数

$k$ 的取值范围是 $1 \leq k \leq N-1$，其中满足 $\gcd(N, k) = 1$ 的 $k$ 的个数就是**欧拉函数** $\varphi(N)$。

但是，$k$ 和 $N-k$ 会产生相同的星星（只是方向不同），因此我们只计算 $k \leq N/2$ 的情况。

由于与 $N$ 互质的数总是成对出现（$k$ 和 $N-k$ 同时与 $N$ 互质），所以不同星星的数量为：
$$\frac{\varphi(N)}{2}$$

---

## 算法设计

### 1. 欧拉函数计算

欧拉函数 $\varphi(N)$ 的计算公式：
$$\varphi(N) = N \times \prod_{p|N} \left(1 - \frac{1}{p}\right)$$
其中 $p$ 是 $N$ 的质因数。

### 2. 算法步骤

1. 对于每个输入的 $N$
2. 计算 $\varphi(N)$
3. 输出 $\varphi(N)/2$

#include <iostream>
#include <cmath>
using namespace std;

// 计算欧拉函数 φ(n)
long long eulerPhi(long long n) {
    long long result = n;
    // 质因数分解
    for (long long p = 2; p * p <= n; ++p) {
        if (n % p == 0) {
            // 去除所有 p 因子
            while (n % p == 0) {
                n /= p;
            }
            // 应用公式 φ(n) = n × ∏(1 - 1/p)
            result -= result / p;
        }
    }
    // 处理剩余的质因数
    if (n > 1) {
        result -= result / n;
    }
    return result;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    long long n;
    while (cin >> n) {
        // 完全星的数量 = φ(n) / 2
        cout << eulerPhi(n) / 2 << "\n";
    }
    return 0;
}
