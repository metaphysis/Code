[UVa 12501 Bulky Process of Bulk Reduction](https://blog.csdn.net/metaphysis/article/details/160558936)

## 题目分析

本题的核心问题是维护一个长度为 $N$ 的数组 $A$（下标从 $1$ 开始），初始时 $A[i] = 100$。我们需要支持两种操作：

1. **区间修改**：给定 $i, j, u$，使区间 $[i, j]$ 内的每一个元素增加 $u$（$u$ 可以为负数）。
2. **区间查询**：给定 $i, j$，计算 $\displaystyle \sum_{k=i}^{j} (k - i + 1) \times A[k]$。

其中 $N$ 和操作次数 $Q$ 均可达 $10^5$，$T$ 最多为 $10$，因此总复杂度必须控制在 $O((N + Q) \log N)$ 级别。

直接暴力模拟显然不可行，需要一种支持 **区间加** 和 **区间加权和** 的数据结构。这里的“加权”不是固定权重，而是查询时动态依赖于查询左端点 $i$ 的 **系数** $(k - i + 1)$。

观察查询公式：
$$
ans = \sum_{k=i}^{j} (k - i + 1) \cdot A[k]
$$

注意到 $(k - i + 1) = (k + 1) - i$，因此：
$$
ans = \sum_{k=i}^{j} (k + 1) \cdot A[k] - i \cdot \sum_{k=i}^{j} A[k]
$$

令：
- $S_1(i, j) = \sum_{k=i}^{j} A[k]$（普通区间和）
- $S_2(i, j) = \sum_{k=i}^{j} k \cdot A[k]$（带下标权重的区间和）

则：
$$
ans = S_2(i, j) + (1 - i) \cdot S_1(i, j)
$$

因此，我们只需要在线段树中维护每个节点所对应区间的两个值：
- `sumA`：区间内 $A[k]$ 的和
- `sumKA`：区间内 $k \cdot A[k]$ 的和

查询时返回一对 `(sumA, sumKA)`，然后根据上式计算出答案。由于 $N$ 最大为 $10^5$，$A[k]$ 的绝对值可能达到 $10^5 \times 1000 = 10^8$，乘积后可能达到 $10^{13}$，因此需要使用 `long long` 类型。

## 解题思路

### 1. 线段树节点设计

每个节点存储：
- `sumA`：区间内所有 $A[k]$ 的和
- `sumKA`：区间内所有 $k \cdot A[k]$ 的和
- `lazy`：区间加的懒惰标记

### 2. 建树时如何初始化

初始时 $A[k] = 100$，因此：
- 对于区间 $[l, r]$，长度为 `len = r - l + 1`：
  - `sumA = 100 * len`
  - `sumKA = 100 * (l + r) * len / 2`

其中 $(l + r) \times len / 2$ 正是区间 $[l, r]$ 内所有下标之和，记作 `getSumK(l, r)`。

### 3. 区间更新时的信息维护

当对区间 $[l, r]$ 内的每个元素 $A[k]$ 增加 $u$ 时：
- `sumA` 增加 `len * u`
- `sumKA` 增加 `u * sumK`，其中 `sumK` 是区间 $[l, r]$ 的下标和（因为每个 $k \cdot A[k]$ 变为 $k \cdot (A[k] + u) = k \cdot A[k] + k \cdot u$，求和后得到 `sumKA + u * sumK`）。

懒惰标记 `lazy` 累加 `u`，表示该区间的所有元素还需要额外增加 `lazy`。

### 4. 查询操作

查询区间 $[ql, qr]$ 时，返回 `(sumA, sumKA)` 的二元组。合并左右儿子时，`sumA = left.sumA + right.sumA`，`sumKA = left.sumKA + right.sumKA`。

### 5. 懒惰标记的下传

在更新或查询需要向下深入时，需要调用 `pushDown`：
- 将当前节点的 `lazy` 值传给左右儿子
- 更新左右儿子的 `sumA` 和 `sumKA`
- 将当前节点的 `lazy` 清零

### 6. 复杂度分析

- 建树：$O(N)$
- 每次更新或查询：$O(\log N)$
- 总复杂度：$O((N + Q) \log N)$，可以满足题目要求。

## 代码实现

```cpp
// Bulky Process of Bulk Reduction
// UVa ID: 12501

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MAXN = 100010;

struct Node {
    ll sumA, sumKA, lazy;
} tree[MAXN << 2];

int n, q;

// 计算区间 [l, r] 的下标和
ll getSumK(int l, int r) {
    return (ll)(l + r) * (r - l + 1) / 2;
}

void build(int idx, int l, int r) {
    tree[idx].lazy = 0;
    if (l == r) {
        tree[idx].sumA = 100;
        tree[idx].sumKA = 100LL * l;
        return;
    }
    int mid = (l + r) >> 1;
    build(idx << 1, l, mid);
    build(idx << 1 | 1, mid + 1, r);
    tree[idx].sumA = tree[idx << 1].sumA + tree[idx << 1 | 1].sumA;
    tree[idx].sumKA = tree[idx << 1].sumKA + tree[idx << 1 | 1].sumKA;
}

void pushDown(int idx, int l, int r) {
    if (tree[idx].lazy != 0) {
        ll val = tree[idx].lazy;
        int mid = (l + r) >> 1;
        int leftLen = mid - l + 1, rightLen = r - mid;
        
        // 更新左儿子
        tree[idx << 1].sumA += leftLen * val;
        tree[idx << 1].sumKA += val * getSumK(l, mid);
        tree[idx << 1].lazy += val;
        
        // 更新右儿子
        tree[idx << 1 | 1].sumA += rightLen * val;
        tree[idx << 1 | 1].sumKA += val * getSumK(mid + 1, r);
        tree[idx << 1 | 1].lazy += val;
        
        tree[idx].lazy = 0;
    }
}

void update(int idx, int l, int r, int ql, int qr, ll u) {
    if (ql <= l && r <= qr) {
        int len = r - l + 1;
        tree[idx].sumA += len * u;
        tree[idx].sumKA += u * getSumK(l, r);
        tree[idx].lazy += u;
        return;
    }
    pushDown(idx, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) update(idx << 1, l, mid, ql, qr, u);
    if (qr > mid) update(idx << 1 | 1, mid + 1, r, ql, qr, u);
    tree[idx].sumA = tree[idx << 1].sumA + tree[idx << 1 | 1].sumA;
    tree[idx].sumKA = tree[idx << 1].sumKA + tree[idx << 1 | 1].sumKA;
}

pair<ll, ll> query(int idx, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return {tree[idx].sumA, tree[idx].sumKA};
    pushDown(idx, l, r);
    int mid = (l + r) >> 1;
    ll sumA = 0, sumKA = 0;
    if (ql <= mid) {
        auto left = query(idx << 1, l, mid, ql, qr);
        sumA += left.first;
        sumKA += left.second;
    }
    if (qr > mid) {
        auto right = query(idx << 1 | 1, mid + 1, r, ql, qr);
        sumA += right.first;
        sumKA += right.second;
    }
    return {sumA, sumKA};
}

void solve() {
    static int caseNo = 0;
    cin >> n >> q;
    build(1, 1, n);
    
    cout << "Case " << ++caseNo << ":\n";
    
    while (q--) {
        string op;
        cin >> op;
        if (op == "change") {
            int i, j, u;
            cin >> i >> j >> u;
            update(1, 1, n, i, j, u);
        } else {
            int i, j;
            cin >> i >> j;
            auto res = query(1, 1, n, i, j);
            ll sumA = res.first, sumKA = res.second;
            ll ans = sumKA + (1 - i) * sumA;
            cout << ans << "\n";
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int T;
    cin >> T;
    while (T--) solve();
    
    return 0;
}
```

## 总结

本题的核心技巧在于 **将动态权重的区间求和问题转化为两个静态信息的区间维护问题**：

- 利用 $(k - i + 1) = (k + 1) - i$ 将系数拆解为与下标 $k$ 有关的部分和与查询左端点 $i$ 有关的部分
- 线段树同时维护 `sumA` 和 `sumKA` 两个值
- 区间加时，`sumKA` 的更新需要借助预处理的下标和公式

这种 **拆系数** 的思想在区间加权求和类问题中非常常见，值得熟练掌握。
