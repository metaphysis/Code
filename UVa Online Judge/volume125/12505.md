[UVa 12505 Searching in sqrt(n)](https://blog.csdn.net/metaphysis/article/details/161976879)

## 题目描述

给定一个整数 $n$（$2 \le n \le 10^6$）和一个二进制字符串 $S$（长度不超过 $20$），需要在 $\sqrt{n}$ 的二进制表示的小数部分中，找到 $S$ 第一次出现的位置。小数部分第一位的位置为 $0$。答案保证不超过 $100$。

若 $\sqrt{n}$ 为整数，则小数部分为无限个 $0$。

## 输入格式

第一行包含一个整数 $T$（$T \le 100$），表示测试用例的数量。  
接下来 $T$ 行，每行包含一个整数 $n$ 和一个二进制字符串 $S$。

## 输出格式

对于每个测试用例，输出一行一个整数，表示 $S$ 在 $\sqrt{n}$ 二进制小数部分第一次出现的位置。

## 样例

输入

```
2
2 101
1202 110011
```

输出

```
2
58
```

## 题目分析

本题的核心是计算 $\sqrt{n}$ 的二进制小数表示，并在其中查找子串 $S$。

一个直观的思路是：先计算 $\sqrt{n}$ 的十进制小数，再转换为二进制。但十进制转二进制需要高精度运算，且题目中 $n$ 最大为 $10^6$，答案位置不超过 $100$，这意味着我们只需要计算前 $120$ 位左右的二进制小数即可。

直接使用浮点数（如 `double`）计算会因精度不足而失败，因为 $120$ 位二进制小数对应的精度要求远超 `double` 的 $53$ 位有效数字。因此，必须使用**高精度整数运算**来模拟开平方过程。

## 解题思路

### 手工开平方的原理

手工开平方（竖式开平方）是一种逐位确定平方根的方法。对于十进制，每次确定一位小数；对于二进制，同样适用。

本题可以采用**二进制直接开平方**的思路，避免十进制与二进制之间的转换。

### 二进制手工开平方的数学基础

设当前已经确定的平方根为 $y$（二进制表示），余数为 $r = n - y^2$。要确定下一位二进制小数 $b \in \{0, 1\}$，我们需要判断：

$$
\left(y + \frac{b}{2^{k+1}}\right)^2 \le n
$$

其中 $k$ 是已确定的小数位数。将不等式两边乘以 $2^{2k+2}$，得到：

$$
(2y + b)^2 \le n \cdot 4 \cdot 2^{2k}
$$

在实现中，我们可以每确定一位，就将 $n$ 左移 $2$ 位（相当于乘以 $4$），将 $y$ 左移 $1$ 位，然后尝试将最低位设为 $1$，计算其平方并与 $n$ 比较。

### 算法流程

1. **计算整数部分**  
   使用 `sqrt(n)` 得到整数部分 $r = \lfloor \sqrt{n} \rfloor$，并转为二进制字符串 `rb`。

2. **处理完全平方数**  
   若 $r^2 = n$，则 $\sqrt{n}$ 为整数，小数部分全为 $0$。直接判断 $S$ 是否全为 `'0'` 并输出 $0$（题目保证有解，此处直接输出 $0$ 即可）。

3. **初始化**  
   将 $n$ 转为二进制字符串 `nb`，小数部分字符串 `fb` 初始为空。

4. **逐位确定小数**  
   循环 $120$ 次（足够覆盖答案范围）：
   - 将 `nb` 末尾添加 `"00"`（相当于左移 $2$ 位）。
   - 构造候选根：`rb + fb + '1'`。
   - 计算候选根的平方（高精度二进制乘法）。
   - 若 `nb` 不小于该平方，则当前小数位为 $1$，否则为 $0$。
   - 将确定的位追加到 `fb` 末尾。

5. **查找子串**  
   在 `fb` 中查找 $S$ 第一次出现的位置，输出结果。

### 高精度运算的实现

由于二进制数字的位数最多约 $120$ 位，平方后的位数约为 $240$ 位，完全可以在 `string` 上手动模拟二进制运算：

- **比较**：先比较长度，长度相同则按字典序比较。
- **平方**：模拟二进制竖式乘法，使用 `vector<int>` 暂存中间结果，最后转换为 `string`。

## 复杂度分析

- 每个测试用例需要计算 $120$ 位小数。
- 每次迭代需要进行一次二进制平方运算，复杂度为 $O(L^2)$，其中 $L$ 为当前二进制数的长度（约 $O(120)$）。
- 总时间复杂度：$O(T \cdot 120 \cdot 120^2) = O(T \cdot 1.7 \times 10^6)$，对于 $T \le 100$ 完全可行。
- 空间复杂度：$O(L)$，用于存储二进制字符串。

## 代码实现

```cpp
// Searching in sqrt(n)
// UVa ID: 12505

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

bool ge(const string& a, const string& b) {
    if (a.length() != b.length()) return a.length() > b.length();
    return a >= b;
}

string square(const string& a) {
    vector<int> r(2 * a.length(), 0);
    for (int i = a.length() - 1; i >= 0; i--)
        for (int j = a.length() - 1; j >= 0; j--) {
            int p = (a[i] - '0') * (a[j] - '0');
            r[i + j + 1] += p;
            r[i + j] += r[i + j + 1] >> 1;
            r[i + j + 1] &= 1;
        }
    string s;
    bool lead = true;
    for (int v : r) {
        if (lead && v == 0) continue;
        lead = false;
        s += char(v + '0');
    }
    return s.empty() ? "0" : s;
}

string binary(int n) {
    if (n == 0) return "0";
    string s;
    while (n) {
        s += char((n & 1) + '0');
        n >>= 1;
    }
    reverse(s.begin(), s.end());
    return s;
}

int main() {
    int T;
    cin >> T;
    while (T--) {
        int n;
        string S;
        cin >> n >> S;
        int r = (int)sqrt(n);
        if (r * r == n) {
            cout << "0\n";
            continue;
        }
        string rb = binary(r), nb = binary(n), fb;
        for (int i = 0; i < 120; ++i) {
            nb += "00";
            if (ge(nb, square(rb + fb + '1'))) fb += '1';
            else fb += '0';
        }
        cout << (int)fb.find(S) << '\n';
    }
    return 0;
}
```

## 总结

本题的核心技巧是**二进制手工开平方**，通过高精度整数运算逐位确定平方根的小数部分。关键点如下：

1. **避免浮点数**：使用高精度整数模拟二进制运算，完全避免精度问题。
2. **平方运算的优化**：只实现平方而非通用乘法，简化代码。
3. **逐位构造候选根**：每次尝试将当前根最低位设为 $1$，判断其平方是否超过 $n$ 的放大版本。
4. **处理完全平方数**：直接输出 $0$，符合题目保证。

这种方法不仅适用于本题，还可推广到任意精度的平方根计算场景，是学习高精度算法的一个良好范例。
