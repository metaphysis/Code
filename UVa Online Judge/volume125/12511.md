 ## 题目分析

### 问题背景
我们有两个被病毒感染的日志文件，它们原本来自同一个原始日志文件。病毒随机插入了一些记录，但**原始事件的顺序保持不变**。由于病毒是随机修改的，两个日志现在变得不同。

### 关键约束条件
1. **原始日志的时间戳严格递增**（没有重复时间戳）
2. **病毒感染后**：
   - 可能插入任意记录
   - 两个日志变得不同
   - 但原始事件的相对顺序在两个日志中保持不变
3. 可能有重复时间戳出现在感染后的日志中

### 问题转化
我们需要找到**两个日志中公共的、且保持原始顺序的最长子序列**，并且这个子序列必须**严格递增**。

这实际上就是经典的最长公共递增子序列（$\texttt{LCIS}$）问题。

### 样例分析
```
Log1: 1 4 2 6 3 8 5 9 1
Log2: 2 7 6 3 5 1
```

公共元素：$2, 6, 3, 5, 1$

可能的 $\texttt{LCIS}$：
- $2, 6, 3$ ❌（不递增，因为 $3 < 6$）
- $2, 3, 5$ ✅
  - 在 $\texttt{Log1}$ 中：位置 $3, 5, 7$ ✅ 顺序保持
  - 在 $\texttt{Log2}$ 中：位置 $1, 4, 5$ ✅ 顺序保持  
  - 并且 $2 < 3 < 5$ ✅ 严格递增
- 长度 = $3$

## 算法设计

### 动态规划解法
使用 $O(n·m)$ 的动态规划算法：

定义：
- $A[0..n-1]$：第一个日志
- $B[0..m-1]$：第二个日志
- $dp[j]$：以 $B[j]$ 结尾的 $\texttt{LCIS}$ 长度

算法步骤：
1. 初始化 $dp[0..m-1] = 0$
2. 对每个 $i = 0..n-1$：
   - $current = 0$
   - 对每个 $j = 0..m-1$：
     - 如果 $A[i] == B[j]$，更新 $dp[j] = \max(dp[j], current + 1)$
     - 如果 $A[i] > B[j]$ 且 $current < dp[j]$，更新 $current = dp[j]$
3. 答案就是 $\max(dp[0..m-1])$

### 算法正确性
- 当 $A[i] == B[j]$ 时，我们可以在之前找到的以小于 $A[i]$ 的值结尾的 $\texttt{LCIS}$ 基础上延长
- $current$ 变量记录了到目前为止，以小于 $A[i]$ 的值结尾的最长 $\texttt{LCIS}$ 长度
- 这样保证了找到的公共子序列既是递增的，又保持了原始顺序

### 复杂度分析
- 时间复杂度：$O(n·m)$，其中 $n, m ≤ 1000$，最多 $10^6$ 次操作
- 空间复杂度：$O(m)$

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int LCIS(const vector<int>& A, const vector<int>& B) {
    int n = A.size();
    int m = B.size();
    vector<int> dp(m, 0);  // dp[j] 表示以 B[j] 结尾的 LCIS 长度
    
    for (int i = 0; i < n; i++) {
        int current = 0;  // 记录当前小于 A[i] 的 LCIS 的最大长度
        for (int j = 0; j < m; j++) {
            if (A[i] == B[j]) {
                // 找到公共元素，可以扩展 LCIS
                dp[j] = max(dp[j], current + 1);
            } else if (A[i] > B[j]) {
                // 如果 A[i] 更大，可以用于后续扩展
                if (dp[j] > current) {
                    current = dp[j];
                }
            }
        }
    }
    
    return *max_element(dp.begin(), dp.end());
}

int main() {
    int T;
    cin >> T;
    
    while (T--) {
        int n1;
        cin >> n1;
        vector<int> log1(n1);
        for (int i = 0; i < n1; i++) {
            cin >> log1[i];
        }
        
        int n2;
        cin >> n2;
        vector<int> log2(n2);
        for (int i = 0; i < n2; i++) {
            cin >> log2[i];
        }
        
        int ans = LCIS(log1, log2);
        cout << ans << endl;
    }
    
    return 0;
}
```

## 总结
本题的关键在于将病毒感染日志恢复问题转化为**最长公共递增子序列**问题。通过动态规划方法，我们可以在 $O(n·m)$ 时间内高效求解，满足题目给定的数据范围要求。算法利用了原始日志严格递增的特性，确保了找到的公共子序列既保持了原始顺序又是严格递增的。
