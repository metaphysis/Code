## 题目分析

本题要求计算从 $M$ 到 $N$ 的所有整数的十进制数字之和。例如，当 $M = 3$，$N = 8$ 时，需要计算序列 $3, 4, 5, 6, 7, 8$ 的各位数字之和：$3 + 4 + 5 + 6 + 7 + 8 = 33$。

### 直接方法的局限性
最直接的方法是遍历 $M$ 到 $N$ 的每个数，分解其各位数字并求和。然而，题目中 $N$ 最大可达 $10^9$，这种方法的时间复杂度为 $O(N-M)$，在极端情况下会超时。

### 高效解法思路
我们可以采用**数位动态规划**的思想，通过计算前缀和来快速求解。定义函数 $\texttt{sum\_digits\_up\_to(x)}$ 表示从 $1$ 到 $x$ 的所有整数的十进制数字之和。那么，对于区间 $[M, N]$ 的数字和，可以通过以下公式计算：
$$
\text{答案} = \texttt{sum\_digits\_up\_to(N)} - \texttt{sum\_digits\_up\_to(M-1)}
$$

### 数位统计原理
关键在于高效计算 $\texttt{sum\_digits\_up\_to(x)}$。我们可以按位（个位、十位、百位等）统计每个数字 $0$ 到 $9$ 出现的次数，然后乘以对应的数字值并求和。

对于第 $k$ 位（从低位到高位，$k=0$ 表示个位）：
- **完整周期**：每 $10^{k+1}$ 个数构成一个完整周期，每个数字 $0$ 到 $9$ 在该位出现 $10^k$ 次。
- **不完整周期**：剩余部分需要单独计算。

具体计算步骤：
1. **完整周期贡献**：完整周期数 = $\lfloor x / 10^{k+1} \rfloor$，每个完整周期的数字和贡献为 $10^k \times 45$（因为 $0+1+\cdots+9=45$）。
2. **不完整周期贡献**：剩余部分 $r = x \% 10^{k+1}$，当前位数字 $d = \lfloor r / 10^k \rfloor$：
   - 数字 $0$ 到 $d-1$ 各出现 $10^k$ 次。
   - 数字 $d$ 出现 $(r \% 10^k) + 1$ 次。

### 算法复杂度
该算法的时间复杂度为 $O(\log_{10} N)$，能够高效处理 $N$ 最大为 $10^9$ 的情况。

## 代码实现
```cpp
// Digit Sum
// UVa ID: 12517
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
using namespace std;
// 计算从1到x的所有数的十进制数字之和
long long sum_digits_up_to(long long x) {
    if (x <= 0) return 0; // 如果x<=0，直接返回0
    long long ans = 0;    // 存储结果
    long long factor = 1; // 当前位的权重（1, 10, 100, ...）
    while (factor <= x) { // 遍历每一位
        long long full_cycles = x / (factor * 10); // 完整周期数
        long long remainder = x % (factor * 10);   // 剩余部分
        // 完整周期的贡献：每个周期数字0-9各出现factor次，和为45
        ans += full_cycles * factor * 45;
        long long digit = remainder / factor; // 当前位的数字
        // 数字0到digit-1各出现factor次
        for (int d = 0; d < digit; d++) {
            ans += factor * d;
        }
        // 数字digit出现(remainder % factor) + 1次
        ans += digit * (remainder % factor + 1);
        factor *= 10; // 移动到下一位
    }
    return ans;
}
int main() {
    long long M, N;
    while (cin >> M >> N) {
        if (M == 0 && N == 0) break; // 输入0 0时结束
        // 输出[M, N]区间的数字和
        cout << sum_digits_up_to(N) - sum_digits_up_to(M - 1) << endl;
    }
    return 0;
}
```

## 总结
本题通过数位统计的方法，将问题转化为计算前缀数字和，避免了直接遍历的高时间复杂度。核心在于按位分析数字出现的规律，利用周期性和剩余部分处理来高效计算。这种方法在数位统计问题中非常典型，值得掌握。
