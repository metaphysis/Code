## 题目描述

弗里恩教授在一次失败的实验中意外创造出了一些奇怪的盒子，这些盒子可以通往平行宇宙。每个盒子连接两个不同的平行宇宙，并且具有时间位移的特性：

- 当从宇宙 $A$ 直接使用 $(A,B)$-盒子时，会到达宇宙 $B$，并且时间向前推进 $t$ 个单位
- 当从宇宙 $B$ 反向使用 $(A,B)$-盒子时，会到达宇宙 $A$，并且时间向后倒退 $t$ 个单位

弗里恩教授想知道是否存在一个**回路**（从原始宇宙出发并回到原始宇宙），使得总时间变化为负值，即能够回到过去。这种现象被称为"弗里恩悖论"。

## 题目分析

### 问题转化

我们可以将这个问题建模为一个图论问题：

- 每个平行宇宙对应图中的一个节点
- 每个 $(i,j,t)$-盒子对应两条有向边：
  - 从 $i$ 到 $j$，权值为 $+t$（时间前进）
  - 从 $j$ 到 $i$，权值为 $-t$（时间倒退）

### 核心问题

我们需要判断在构建的有向图中，从节点 $1$（原始宇宙）出发，是否存在一个总权值为负的环。如果存在这样的负环，就意味着我们可以通过这个环路回到过去，即弗里恩悖论成立。

### 算法选择

这是一个典型的**带负权边的单源负环检测**问题。由于图中可能存在负权边，我们不能使用 $\texttt{Dijkstra}$ 算法，而应该使用 $\texttt{Bellman-Ford}$ 算法。

**$\texttt{Bellman-Ford}$ 算法原理**：
1. 初始化所有节点到源点的距离为无穷大，源点距离为 $0$
2. 进行 $N-1$ 次松弛操作，更新最短路径
3. 再进行一次松弛操作，如果还能更新某些节点的距离，说明存在从源点可达的负环

**时间复杂度**：$O(N \cdot E)$，其中 $N$ 是节点数，$E$ 是边数
**空间复杂度**：$O(N + E)$

对于本题的数据范围（$N \leq 100$，$B \leq 4950$），该算法完全可行。

## 代码实现

```cpp
// The Farnsworth Parabox
// UVa ID: 12519
// Verdict: Accepted
// Submission Date: 2025-10-17
// UVa Run Time: 0.030s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <climits>
using namespace std;

// 定义边结构体
struct Edge {
    int u, v, w;  // 起点u，终点v，权值w
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int N, B;
    while (cin >> N >> B && (N != 0 || B != 0)) {
        vector<Edge> edges;
        
        // 读取所有盒子信息，构建有向图
        for (int k = 0; k < B; k++) {
            int i, j, t;
            cin >> i >> j >> t;
            // 每个盒子产生两条有向边：
            // 从i到j，权值为+t（直接使用，时间前进）
            edges.push_back({i, j, t});
            // 从j到i，权值为-t（反向使用，时间倒退）
            edges.push_back({j, i, -t});
        }
        
        // 初始化距离数组，dist[i]表示从节点1到节点i的最短距离
        vector<int> dist(N + 1, INT_MAX);
        dist[1] = 0;  // 源点（原始宇宙）距离为0
        
        // Bellman-Ford算法：进行N-1次松弛操作
        for (int i = 1; i <= N - 1; i++) {
            for (const Edge& e : edges) {
                // 如果从u可达，且通过u到v能获得更短路径，则更新
                if (dist[e.u] != INT_MAX && dist[e.u] + e.w < dist[e.v]) {
                    dist[e.v] = dist[e.u] + e.w;
                }
            }
        }
        
        // 检测负环：如果第N次松弛还能更新距离，说明存在负环
        bool hasNegativeCycle = false;
        for (const Edge& e : edges) {
            if (dist[e.u] != INT_MAX && dist[e.u] + e.w < dist[e.v]) {
                hasNegativeCycle = true;
                break;
            }
        }
        
        // 输出结果：存在负环输出'Y'，否则输出'N'
        cout << (hasNegativeCycle ? 'Y' : 'N') << '\n';
    }
    
    return 0;
}
```

## 总结

本题的关键在于将物理世界的时间旅行问题转化为图论中的负环检测问题。通过 $\texttt{Bellman-Ford}$ 算法，我们能够高效地判断是否存在可以回到过去的时空回路。算法的时间复杂度为 $O(N \cdot E)$，在题目给定的数据范围内完全可行。

这个问题的巧妙之处在于它展示了如何用图论模型解决看似复杂的时空旅行问题，体现了计算机科学在解决跨学科问题中的强大能力。
