## 题目描述

$\texttt{Rick}$ 有一个边长为 $L$ 米的正方形花园，被划分为 $L^2$ 个边长为 $1$ 米的正方形模块。他需要选择 $N$ 个模块进行种植，并希望所选区域的周长尽可能大，因为更大的周长意味着更好的灌溉效果。灌溉软管沿着所选区域的外围铺设。

需要求出在 $L \times L$ 的网格中选择 $N$ 个格子，所能得到的最大周长。
## 输入格式

输入包含多组测试数据，每组一行，包含两个整数 $L$ 和 $N$，分别表示花园边长和需要种植的格子数，满足 $1 \le L \le 10^6$，$0 \le N \le L^2$。输入以一行 `0 0` 结束。

## 输出格式

对于每组数据，输出一行一个整数，表示能达到的最大周长。

## 样例

输入

```
1 0
1 1
2 3
3 8
0 0
```

输出

```
0
4
8
16
```

## 题目分析

本题的核心是：在 $L \times L$ 的网格中选取 $N$ 个格子，使得这些格子组成的图形周长最大。

周长计算方式：每个格子的 $4$ 条边中，如果相邻格子也被选中，则共享的边不计入周长。因此总周长为：

$$
\text{周长} = 4N - 2 \times (\text{相邻格子对数})
$$

其中相邻定义为共享一条边（四连通）。

要最大化周长，就需要最小化相邻格子对数。换句话说，我们希望选中的格子尽可能分散，避免相互接触。

但是，随着 $N$ 的增大，格子必然会出现相邻，因此需要找到一个最优的排列方式。

## 解题思路

### 贪心策略

一个经典的贪心思路是：将格子按照对周长的“贡献”分类。每增加一个格子，它对周长的贡献可以是 $+4$、$0$、$-2$ 或 $-4$，取决于它与已选格子的相邻情况。

具体地，可以将格子分为四类：

1. **孤立格子**：按“跳棋”方式选取，每个格子与四周格子都不相邻。这类格子每选一个，周长增加 $4$。
2. **角点格子**：四个角上的格子。在最优排列中，选角点不会改变周长（净贡献 $0$）。
3. **边界格子（非角）**：位于边界但不是角的格子。每选一个，周长减少 $2$。
4. **内部格子**：完全被包围的格子。每选一个，周长减少 $4$。

因此，最优策略是**按照贡献从大到小的顺序选取格子**：先尽可能多地选孤立格子，再选角点，再选边界格子，最后才选内部格子。

### 关键参数的计算

孤立格子的最大数量 $a$ 取决于 $L$ 的奇偶性，因为网格的“棋盘染色”性质决定了最大独立集的大小。

#### 情况一：$L$ 为偶数

网格可以完美划分为两个颜色类，每类恰好 $L^2 / 2$ 个格子。一类中的格子互不相邻，因此：

- $a = L^2 / 2$（孤立格子数）
- $b = 2$（贡献为 $0$ 的角点可额外选的数量）
- $c = (L/2 - 1) \times 4$（边界格子可额外选的数量）

#### 情况二：$L$ 为奇数

奇数的棋盘染色不均等，两类格子数相差 $1$。最优排列有两种可能，需要取最大值：

**方式一**（选较少的那一类作为孤立格子）：

- $a = \lfloor L^2 / 2 \rfloor$
- $b = 1$（当 $L=1$ 时）或 $4$
- $c = (L - 3) / 2 \times 4$

**方式二**（选较多的那一类作为孤立格子）：

- $a = \lfloor L^2 / 2 \rfloor + 1$
- $b = 0$
- $c = (L - 1) / 2 \times 4$

### 周长计算函数

给定 $a, b, c$，设当前需要选取 $N$ 个格子，则最大周长可以通过如下分段函数计算：

$$
\text{周长}(N) = 
\begin{cases}
4N & \text{if } N \le a \\
4a & \text{if } a < N \le a + b \\
4a - 2(N - a - b) & \text{if } a + b < N \le a + b + c \\
4a - 2c - 4(N - a - b - c) & \text{if } N > a + b + c
\end{cases}
$$

解释：
- 第一阶段只选孤立格子，每个贡献 $+4$。
- 第二阶段选角点，贡献为 $0$，周长不变。
- 第三阶段选边界格子，每个贡献 $-2$。
- 第四阶段选内部格子，每个贡献 $-4$。

### 复杂度分析

- 每组数据仅需常数次运算，时间复杂度 $O(1)$。
- 空间复杂度 $O(1)$。
- 非常适合 $L$ 高达 $10^6$ 的情况。

## 代码实现

```cpp
// Square Garden

//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// 计算最大周长的函数
ll calcularMaxPerimetro(ll a, ll b, ll c, ll N) {
    if (N <= a) return N * 4;
    if (N <= a + b) return a * 4;
    if (N <= a + b + c) return a * 4 - (N - a - b) * 2;
    return a * 4 - c * 2 - (N - a - b - c) * 4;
}

int main() {
    ll L, N;
    while (cin >> L >> N, L || N) {
        ll ans = 0;
        // L为偶数的情况
        if (L % 2 == 0) {
            ll a = L * L / 2;
            ll b = 2;
            ll c = (L / 2 - 1) * 4;
            ans = calcularMaxPerimetro(a, b, c, N);
        } 
        // L为奇数的情况，分两种排列方式取最大值
        else {
            // 方式1
            ll a1 = L * L / 2;
            ll b1 = (L == 1) ? 1 : 4;
            ll c1 = (L - 3) / 2 * 4;
            ll ans1 = calcularMaxPerimetro(a1, b1, c1, N);
            
            // 方式2
            ll a2 = L * L / 2 + 1;
            ll b2 = 0;
            ll c2 = (L - 1) / 2 * 4;
            ll ans2 = calcularMaxPerimetro(a2, b2, c2, N);
            
            ans = max(ans1, ans2);
        }
        cout << ans << endl;
    }
    return 0;
}
```

## 总结

本题的关键洞察在于：

1. **将问题转化为最小化相邻对数**：周长 $= 4N - 2 \times \text{相邻对数}$。
2. **贪心分类思想**：按照格子对周长的贡献（$+4, 0, -2, -4$）从大到小选取。
3. **分奇偶性讨论**：棋盘染色的性质决定了最大孤立集的大小，需要根据 $L$ 的奇偶性分别处理。
4. **封闭形式计算**：最终得到一个 $O(1)$ 的分段公式，高效解决了 $L$ 高达 $10^6$ 的大数据问题。

这种“分类贡献”的贪心思路在很多网格选择问题中都具有通用性，值得深入理解和掌握。
