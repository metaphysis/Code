## 题目翻译与分析

### 问题背景

砷与氰化物矿业公司（$\texttt{ACM}$）计划在你的家乡附近开采矿物。作为公民监督委员会的成员，你需要控制公司的开采深度，以便在保护环境和居民健康的同时保留就业机会。

### 问题描述

$\texttt{ACM}$ 计划开采若干矩形地块，每个地块具有以下特征：
- 宽度 $W$ （ $1 \leq W \leq 8$ ）
- 最大挖掘深度 $D$ （ $1 \leq D \leq 10$ ）
- 地表深度为 $0$ ，向下为负深度

矿物分为三层，两层边界由两个有理函数描述：
- $y_1(x)$ ：顶层与中层之间的边界
- $y_2(x)$ ：中层与底层之间的边界

其中：
$$
y_i(x) = \frac{p_i(x)}{q_i(x)}, \quad i = 1, 2
\\
p_i(x) = \sum_{k=0}^K P_{i,k} x^k, \quad q_i(x) = \sum_{k=0}^K Q_{i,k} x^k
$$

对于 $0 \leq x \leq W$ ，始终满足：
$$
-D < y_2(x) < y_1(x) < 0
$$

### 开采规则

$\texttt{ACM}$ 将挖掘深度不超过 $d$ 的所有矿物，但只有中层矿物有价值。利润与剖面中深度不超过 $d$ 的中层面积 $A$ 成正比。

**任务** ：给定地块描述和整数 $A$ ，求挖掘深度 $d$ ，使得深度不超过 $d$ 的中层面积恰好为 $A$ 。

### 输入格式

每个测试用例包含 $5$ 行：
1. $W\ D\ A\ K$ 
2. $p_1(x)$ 的系数 $P_{1,0}$ 到 $P_{1,K}$ 
3. $q_1(x)$ 的系数 $Q_{1,0}$ 到 $Q_{1,K}$ 
4. $p_2(x)$ 的系数 $P_{2,0}$ 到 $P_{2,K}$ 
5. $q_2(x)$ 的系数 $Q_{2,0}$ 到 $Q_{2,K}$ 

系数范围： $[-10^8, 10^8]$ 
保证存在唯一的 $d$ 满足条件，且 $A$ 严格小于中层总面积。

### 输出格式

对于每个测试用例，输出一行一个有理数，表示挖掘深度 $d$ ，精确到小数点后 $5$ 位。

## 解题思路详解

### 1. 面积函数的数学建模

我们需要理解“深度不超过 $d$ 的中层面积”这一概念。

设挖掘深度为 $d$ （ $d \in [-D, 0]$ ，负值表示地表以下的深度）。对于每个横坐标 $x$ ，中层位于深度区间 $[y_2(x), y_1(x)]$ 内。

当挖掘深度为 $d$ 时，我们实际上挖掘的是深度范围 $[d, 0]$ 与 $[y_2(x), y_1(x)]$ 的交集。

由于 $y_1(x) < 0$ ， $y_2(x) < 0$ ，且 $d \leq 0$ ，需要考虑三种情况：

1. **完全挖掘** ：当 $d \leq y_2(x)$ 时，整个中层被挖掘，贡献长度为 $y_1(x) - y_2(x)$ 
2. **部分挖掘** ：当 $y_2(x) < d \leq y_1(x)$ 时，只挖掘深度在 $[d, y_1(x)]$ 的部分，贡献长度为 $y_1(x) - d$ 
3. **无挖掘** ：当 $d > y_1(x)$ 时，没有中层被挖掘，贡献为 $0$ 

可以用一个公式统一表示：
$$
\text{贡献长度}(x, d) = \max(0,\ y_1(x) - \max(y_2(x),\ d))
$$

因此，总面积函数为：
$$
S(d) = \int_0^W \max(0,\ y_1(x) - \max(y_2(x),\ d))\ dx
$$

### 2. 函数性质分析

**单调性** ： $S(d)$ 关于 $d$ 单调递减。因为 $d$ 增大（向上移动）时，被挖掘的中层区域减少。

**值域** ：
- 当 $d = -D$ （最大深度）时， $d \leq y_2(x)$ 对所有 $x$ 成立（因为 $y_2(x) > -D$ ），此时 $S(d)$ 等于整个中层总面积
- 当 $d = 0$ （地表）时，由于 $y_1(x) < 0$ ， $d > y_1(x)$ 对所有 $x$ 成立，此时 $S(d) = 0$ 

因此，对于给定的 $A$ （ $0 < A < S(-D)$ ），存在唯一的 $d \in [-D, 0]$ 使得 $S(d) = A$ 。

### 3. 数值计算方法

由于面积函数涉及 $\max$ 操作和有理函数积分，无法直接解析求解，需要采用数值方法。

#### 3.1 数值积分

对于固定的 $d$ ，需要计算定积分：
$$
S(d) = \int_0^W f(x, d) dx, \quad f(x, d) = \max(0,\ y_1(x) - \max(y_2(x),\ d))
$$

由于 $f(x, d)$ 可能不光滑（在 $d = y_2(x)$ 或 $d = y_1(x)$ 处导数不连续），使用自适应辛普森法（$\texttt{Adaptive Simpson's Method}$）较为合适。

自适应辛普森法的核心思想：
1. 用辛普森公式计算整个区间的积分近似值
2. 将区间二等分，分别计算左右两半的积分近似值
3. 如果总误差在可接受范围内，则返回结果
4. 否则，递归地对左右两半进行更精确的计算

#### 3.2 二分搜索

由于 $S(d)$ 单调递减，我们可以使用二分搜索在区间 $[-D, 0]$ 上查找满足 $S(d) = A$ 的 $d$ 。

二分搜索步骤：
1. 初始化 $l = -D$ ， $r = 0$ 
2. 重复以下步骤足够多次（如 $100$ 次）以确保精度：
   - 计算中点 $m = (l + r) / 2$ 
   - 计算 $S(m)$ 
   - 如果 $S(m) > A$ ，说明 $d$ 需要增大（向上移动），更新 $l = m$ 
   - 否则，更新 $r = m$ 
3. 输出 $l$ （或 $r$ ）作为答案

### 4. 精度控制

题目要求输出精确到小数点后 $5$ 位，因此需要：
- 二分搜索的精度至少达到 $10^{-7}$ 
- 数值积分的精度至少达到 $10^{-8}$ 
- 使用 `double` 类型进行计算

在实际代码中，我们设置：
- 二分搜索迭代 $100$ 次，精度可达 $2^{-100} \approx 10^{-30}$ 
- 自适应辛普森法设置绝对误差容限 $10^{-8}$ 
- 递归深度限制为 $20$ 层，防止无限递归

### 5. 算法复杂度

设二分搜索迭代次数为 $I$ ，数值积分递归深度为 $L$ ：
- 每次二分搜索需要计算一次数值积分
- 每次数值积分在最坏情况下需要 $O(2^L)$ 次函数求值
- 每次函数求值需要计算两个有理函数

由于 $W \leq 8$ ， $D \leq 10$ ， $K \leq 8$ ，且 $I = 100$ ， $L \leq 20$ ，计算量完全可接受。

## 代码实现

```cpp
// Environment Protection
// UVa ID: 12528
// Verdict: Accepted
// Submission Date: 2026-01-01
// UVa Run Time: 0.050s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int W, D, A, K;
vector<int> P1, Q1, P2, Q2;
double leftBound, rightBound;

// 计算多项式值
double polyEval(const vector<int>& coeffs, double x) {
    double result = 0, power = 1;
    for (int c : coeffs) {
        result += c * power;
        power *= x;
    }
    return result;
}

// 计算 y1(x) 和 y2(x)
double y1(double x) { return polyEval(P1, x) / polyEval(Q1, x); }
double y2(double x) { return polyEval(P2, x) / polyEval(Q2, x); }

// 被积函数
double integrand(double x, double d) {
    double upper = y1(x);
    double lower = max(y2(x), d);
    return max(0.0, upper - lower);
}

// 自适应辛普森积分
double adaptiveSimpson(double a, double b, double d, double eps) {
    function<double(double)> f = [&](double x) { return integrand(x, d); };
    function<double(double, double, double, double, double, double, double, int)> simpson =
        [&](double l, double r, double fl, double fr, double fm, double whole, double eps, int depth) {
        double mid = (l + r) / 2;
        double fml = f((l + mid) / 2);
        double fmr = f((mid + r) / 2);
        double left = (mid - l) * (fl + 4 * fml + fm) / 6;
        double right = (r - mid) * (fm + 4 * fmr + fr) / 6;
        double delta = left + right - whole;
        if (abs(delta) <= 15 * eps || depth >= 20) return left + right + delta / 15;
        return simpson(l, mid, fl, fm, fml, left, eps / 2, depth + 1) +
               simpson(mid, r, fm, fr, fmr, right, eps / 2, depth + 1);
    };
    double fl = f(a), fr = f(b), fm = f((a + b) / 2);
    double whole = (b - a) * (fl + 4 * fm + fr) / 6;
    return simpson(a, b, fl, fr, fm, whole, eps, 0);
}

// 计算面积
double area(double d) { return adaptiveSimpson(0, W, d, 1e-8); }

int main() {
    while (cin >> W >> D >> A >> K) {
        P1.resize(K + 1); Q1.resize(K + 1); P2.resize(K + 1); Q2.resize(K + 1);
        for (int i = 0; i <= K; i++) cin >> P1[i];
        for (int i = 0; i <= K; i++) cin >> Q1[i];
        for (int i = 0; i <= K; i++) cin >> P2[i];
        for (int i = 0; i <= K; i++) cin >> Q2[i];

        leftBound = -D, rightBound = 0;
        // 二分搜索
        for (int iter = 0; iter < 100; iter++) {
            double mid = (leftBound + rightBound) / 2;
            if (area(mid) > A) leftBound = mid;
            else rightBound = mid;
        }
        cout << fixed << setprecision(5) << -leftBound << endl; // 输出正值深度
    }
    return 0;
}
```

## 代码说明

1. **数据结构** ：使用 `vector<int>` 存储多项式系数
2. **函数设计** ：
   - `polyEval` ：计算多项式值
   - `y1` 、 `y2` ：计算边界函数值
   - `integrand` ：计算被积函数值
   - `adaptiveSimpson` ：自适应辛普森积分
   - `area` ：计算面积 $S(d)$ 
3. **主算法** ：
   - 读取输入数据
   - 在 $[-D, 0]$ 上进行二分搜索
   - 每次迭代计算 $S(mid)$ 
   - 根据比较结果更新搜索边界
4. **输出处理** ：由于计算中使用负深度，输出时取绝对值得到正深度

## 注意事项

1. 题目中的 $d$ 实际上是负值（地表以下深度），但输出要求正值深度
2. 自适应辛普森法设置了递归深度限制，防止函数在接近不连续点时无限递归
3. 由于 $W$ 较小，数值积分效率很高
4. 二分搜索迭代 $100$ 次足够达到要求的精度

## 总结

本题综合了数值积分和二分搜索两种数值计算方法，关键在于：
1. 正确建立面积函数的数学模型
2. 理解函数的单调性以便使用二分搜索
3. 选择合适的数值积分方法处理可能的不连续函数
4. 合理设置精度参数以满足题目要求

通过本题，我们可以学习到如何将实际问题转化为数学模型，并使用数值方法求解无法解析计算的积分方程。
