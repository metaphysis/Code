[UVa 12530 Game of Tiles](https://blog.csdn.net/metaphysis/article/details/161460792)

## 题目描述

这是一个双人博弈游戏，在一个 $R \times C$ 的棋盘上进行。棋盘中的每个格子称为瓷砖（tile），初始时有些瓷砖被涂黑（用 `X` 表示），其余为白色（用 `.` 表示）。游戏规则如下：

1. 玩家 $1$ 先手，选择一个白色瓷砖，在上面写上数字 $1$。
2. 随后双方轮流操作，在第 $i$ 步时，当前玩家必须选择一个**未被使用过**的白色瓷砖，且该瓷砖与编号为 $i-1$ 的瓷砖**水平或垂直相邻**（不能对角相邻），并在上面写上数字 $i$。
3. 玩家 $1$ 永远写奇数，玩家 $2$ 永远写偶数。
4. 无法进行合法移动的玩家输掉游戏。

双方都采取最优策略，问最终谁获胜。

## 题目分析

### 博弈模型的转化

这个游戏本质上是在一个**无向图**上进行的。图的每个节点代表一个白色瓷砖，如果两个白色瓷砖相邻（上下左右），则它们之间有一条边。游戏过程就是从某个节点出发，沿着边移动，且每个节点只能访问一次。这正是图论中的 **$\texttt{Geography}$** 游戏（又称“地理游戏”）的变种。

$\texttt{Geography}$ 游戏在一个有向图上进行，玩家轮流移动棋子到相邻的未访问节点，无法移动者输。本题的棋盘是网格图，且移动是双向的（无向边），因此这是一个**无向图上的 $\texttt{Geography}$ 游戏**。

### 二分图性质

网格图具有天然的二分性质：将棋盘按照 $(i + j)$ 的奇偶性染色，$(i + j)$ 为偶数的格子与 $(i + j)$ 为奇数的格子之间才有边相连（因为只有上下左右移动，奇偶性必然改变）。因此，白色瓷砖构成的图是一个**二分图**。

### 核心定理

对于二分图上的无向 $\texttt{Geography}$ 游戏，有经典的博弈结论：

> **定理**：在二分图 $G$ 上，如果 $G$ 存在完美匹配（即匹配边覆盖了所有顶点），则后手必胜；否则先手必胜。

这个结论的直观理解如下：

- **后手必胜的情况（存在完美匹配）**：后手可以采用“跟随策略”。无论先手从哪个节点出发走到哪个相邻节点，后手总是沿着匹配边走到与当前节点匹配的那个节点。由于图存在完美匹配，后手永远有合法的移动，且不会重复访问节点。先手最终将无路可走。

- **先手必胜的情况（不存在完美匹配）**：先手可以选择一个**不在某个最大匹配中**的节点作为起点。此时后手无法应用上述跟随策略，先手可以迫使后手陷入困境。

因此，问题的关键转化为：**判断白色瓷砖构成的二分图是否存在完美匹配**。

### 匹配的大小判断

需要注意的是，完美匹配要求匹配边的数量等于总节点数的一半，即 $2 \times |matching| = |V|$。

在二分图中，左右两部的大小可能不相等。设左部节点数为 $L$，右部节点数为 $R$，总节点数为 $N = L + R$。完美匹配存在的必要条件是 $L = R$，且匹配边数等于 $L$（或 $R$）。

由于我们只需要判断“匹配是否能覆盖所有节点”，等价于判断**最大匹配的大小是否等于 $L$ 且同时等于 $R$**（即匹配边数等于 $\frac{N}{2}$）。

## 解题思路

### 步骤一：建图

1. 遍历整个棋盘，对所有白色瓷砖进行编号。
2. 根据 $(i + j)$ 的奇偶性将白色瓷砖分为左部（偶）和右部（奇）。
3. 对于每个左部节点，检查其四个方向相邻的白格，若存在则连边（从左边指向右边）。

### 步骤二：求最大匹配

使用匈牙利算法（增广路算法）求解二分图的最大匹配。

匈牙利算法的核心思想是：对于每个左部节点，尝试寻找一条增广路，若能找到则增加匹配数。

### 步骤三：判断完美匹配

设匹配边数为 $M$，总白格数为 $N$。若 $2 \times M = N$，则存在完美匹配，后手（玩家 $2$）获胜；否则先手（玩家 $1$）获胜。

**注意**：本题保证至少有一个白色瓷砖，因此 $N \geq 1$。

### 复杂度分析

- 节点数最多为 $R \times C \leq 2500$。
- 边数最多约为 $2 \times R \times C$（每个格子最多 $4$ 条边）。
- 匈牙利算法的时间复杂度为 $O(V \times E)$，最坏情况下约 $2500 \times 10000 = 2.5 \times 10^7$，在时限内可接受。

## 代码实现

```cpp
// Game of Tiles
// UVa ID: 12530
// Verdict: Accepted
// Submission Date: 2026-05-27
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int dx[] = {1, -1, 0, 0};
const int dy[] = {0, 0, 1, -1};

int R, C;
vector<string> board;
vector<vector<int>> leftId;
vector<vector<int>> rightId;
vector<vector<int>> adj;
vector<int> matchL, matchR;
vector<bool> vis;

int leftCnt, rightCnt;

bool dfs(int u) {
    if (vis[u]) return false;
    vis[u] = true;
    for (int v : adj[u]) {
        if (matchR[v] == -1 || dfs(matchR[v])) {
            matchL[u] = v;
            matchR[v] = u;
            return true;
        }
    }
    return false;
}

int solve() {
    // 给白格编号
    leftId.assign(R, vector<int>(C, -1));
    rightId.assign(R, vector<int>(C, -1));
    leftCnt = rightCnt = 0;
    for (int i = 0; i < R; ++i) {
        for (int j = 0; j < C; ++j) {
            if (board[i][j] == '.') {
                if ((i + j) % 2 == 0)
                    leftId[i][j] = leftCnt++;
                else
                    rightId[i][j] = rightCnt++;
            }
        }
    }
    
    // 建图
    adj.assign(leftCnt, vector<int>());
    for (int i = 0; i < R; ++i) {
        for (int j = 0; j < C; ++j) {
            if (board[i][j] == '.' && (i + j) % 2 == 0) {
                int u = leftId[i][j];
                for (int d = 0; d < 4; ++d) {
                    int ni = i + dx[d], nj = j + dy[d];
                    if (ni >= 0 && ni < R && nj >= 0 && nj < C && board[ni][nj] == '.') {
                        int v = rightId[ni][nj];
                        adj[u].push_back(v);
                    }
                }
            }
        }
    }
    
    // 匈牙利算法求最大匹配
    matchL.assign(leftCnt, -1);
    matchR.assign(rightCnt, -1);
    for (int u = 0; u < leftCnt; ++u) {
        vis.assign(leftCnt, false);
        dfs(u);
    }
    
    // 统计匹配边数
    int matchSize = 0;
    for (int u = 0; u < leftCnt; ++u)
        if (matchL[u] != -1) matchSize++;
    
    // 如果最大匹配覆盖所有白格（完美匹配），后手胜
    if (matchSize * 2 == leftCnt + rightCnt)
        return 2;
    return 1;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    while (cin >> R >> C) {
        board.resize(R);
        for (int i = 0; i < R; ++i)
            cin >> board[i];
        cout << solve() << '\n';
    }
    return 0;
}
```

## 总结

本题的核心是将棋盘游戏转化为二分图上的 $\texttt{Geography}$ 博弈，并利用“完美匹配 $\Rightarrow$ 后手胜”的经典结论。解题的关键步骤是：

1. 识别出图的二分性质；
2. 熟练运用匈牙利算法求解最大匹配；
3. 正确判断完美匹配的存在性。

这一解法不仅适用于本题的网格图，也适用于任意二分图上的类似博弈问题。
