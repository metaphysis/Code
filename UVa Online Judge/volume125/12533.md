## 题目描述

$\texttt{Nlognia}$ 国的航空规定要求每个城市必须恰好注册一个出港航班到另一个城市。乘客只能按注册方向使用该航班，也就是说，可能存在从城市 $X$ 到城市 $Y$ 的航班，但没有从 $Y$ 到 $X$ 的航班。因此，注册的航班数量等于城市数量 $N$ 。这个规定使得航空旅行变得有些复杂。

“配对协会”（$\texttt{ACM}$）正在推出一项新服务，帮助客户找到他们的长久灵魂伴侣：互联网配对连接计划（$\texttt{ICPC}$）。该服务包括计算一对情侣见面所需的最小总航班数（可能在两人都不居住的城市）。假设情侣的起始城市是 $A$ 和 $B$ ，机构将尝试找到一个城市 $C$ ，使得 $C$ 可以从 $A$ 和 $B$ 通过航空旅行到达，并且从 $A$ 到 $C$ 所需的航班数与从 $B$ 到 $C$ 所需的航班数之和最小。注意 $C$ 可以等于 $A$ 或 $B$ 或两者。

你将获得所有可用航班的列表，以及一系列查询，每个查询包含一对情侣居住的城市。对于每个查询，你必须计算他们见面所需的最小总航班数；如果无法通过航空旅行见面，则输出 `-1`。

### 输入格式

每个测试用例由若干行描述：

- 第一行包含一个整数 $N$ 表示城市数量（ $2 \leq N \leq 10^{5}$ ）
- 第二行包含 $N$ 个整数 $F_{i}$ ，其中 $F_{i}$ 表示从城市 $i$ 注册的出港航班目的地是城市 $F_{i}$ （ $1 \leq F_{i} \leq N$ ）
- 第三行包含一个整数 $Q$ 表示查询数量（ $1 \leq Q \leq 10^{5}$ ）
- 接下来的 $Q$ 行每行描述一个查询，包含两个整数 $A$ 和 $B$ ，表示情侣的起始城市（ $1 \leq A, B \leq N$ ）

在每个测试用例中，如果可以从城市 $X$ 飞到城市 $Y$ ，则所需的最大航班数为 $10^{4}$ 。

### 输出格式

对于每个测试用例输出 $Q$ 行。在第 $i$ 行写入一个整数，表示第 $i$ 个查询的答案。

### 样例输入

```
3 2 1 2 3 1 2 1 3 1 1 7 2 1 4 5 3 5 6 5 1 3
4 7 7 4 6 2 2 1
```

### 样例输出

```
1
2
0
-1
3
3
-1
1
```

## 题目分析

### 图的性质

每个城市只有一个出边，因此整个图是由若干个**基环树**（每个弱连通分量是一个基环树）组成的森林。基环树由两部分组成：

1. **环**：图中的强连通分量，每个节点都在环上
2. **树（枝）**：从环上节点延伸出去的有向树，方向指向环

具体来说：
- 每个节点要么在环上，要么在某个枝上
- 枝上的节点最终都会走到环上节点
- 枝上的边方向是从子节点指向父节点（父节点更靠近环）

### 问题转化

给定起点 $A$ 和 $B$ ，我们需要找到某个可达的城市 $C$ ，使得 $dist(A, C) + dist(B, C)$ 最小，其中 $dist(X, Y)$ 是沿着有向边的步数。

关键观察：
1. 如果 $A$ 和 $B$ 不在同一个基环树中，则不可达，输出 `-1`
2. 如果 $A$ 和 $B$ 在同一个基环树中，最小汇合点可能是：
   - 它们在同一个枝上：$C$ 是它们的最近公共祖先（$\texttt{LCA}$）
   - 它们都在环上：$C$ 是环上两点间的最短路径上的某点
   - 一个在环上一个在枝上：$C$ 是环上的点
   - 在不同枝上：需要先走到环上，再在环上汇合

### 解题思路

#### 1. 预处理阶段

我们需要为每个节点计算以下信息：

- **所属基环树编号**：通过 $\texttt{DFS}$ 或拓扑排序标记连通分量
- **是否在环上**：通过拓扑排序（计算入度）找出所有环上节点
- **到环的距离**：对于枝上的节点，记录到环上节点的距离（深度）
- **环上位置**：对于环上节点，记录在环中的顺序位置
- **环的大小**：每个环的节点数量
- **父节点关系**：用于 $\texttt{LCA}$ 查询的倍增表

#### 2. 拓扑排序找环

由于每个节点只有一个出边，我们可以通过计算入度并使用拓扑排序来找出所有环上节点：
- 初始入度为 $0$ 的节点一定在枝上
- 不断删除入度为 $0$ 的节点及其出边
- 最终剩余的节点都在环上

#### 3. 标记枝上节点

对于每个环上节点，通过反向边 $\texttt{DFS}$ 遍历其枝上的所有节点，同时记录：
- 深度（到环的距离）
- 所属环的编号
- 环上位置（继承自环上父节点）
- 父节点信息（用于 $\texttt{LCA}$ ）

#### 4. 查询处理

对于每个查询 $(A, B)$ ：

1. **检查连通性**：如果 $compId[A] \neq compId[B]$ ，输出 $-1$

2. **都在环上**：计算环上两点间的最短距离
   - 设 $p_1 = ringPos[A]$, $p_2 = ringPos[B]$, $sz = ringSize[ringId[A]]$
   - 距离 $d = \min(|p_1 - p_2|, sz - |p_1 - p_2|)$

3. **都在枝上**：
   - 如果它们在同一个枝上（$\texttt{LCA}$ 不是环上节点），距离为 $depth[A] + depth[B] - 2 \times depth[LCA]$
   - 如果在不同枝上，需要各自走到环上再在环上汇合：
     - $dist = depth[A] + depth[B] +$ 环上最短距离

4. **一个在环上一个在枝上**：
   - 设环上节点为 $A$ ，枝上节点为 $B$
   - 先让 $B$ 走到环上节点 $B'$
   - $dist = depth[B] +$ 环上距离$(A, B')$

#### 5. 时间复杂度

- 预处理：$O(N \log N)$ （主要是 $\texttt{LCA}$ 的倍增表）
- 每个查询：$O(\log N)$
- 总体：$O((N+Q) \log N)$ ，可以处理 $N, Q \leq 10^5$

## 代码实现

```cpp
// Joining Couples
// UVa ID: 12533
// Verdict: Accepted
// Submission Date: 2026-01-16
// UVa Run Time: 0.110s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int LOGN = 17; // 2^17 > 1e5

int n, q;
int to[MAXN];
int compId[MAXN]; // 所属基环树编号
int ringId[MAXN]; // 所属环编号（如果在环上）
int depth[MAXN];  // 在树上的深度（到环的距离）
int parent[MAXN][LOGN];
int ringPos[MAXN]; // 在环上的位置（0..环长-1）
int ringSize[MAXN]; // 环的大小
bool onRing[MAXN];
vector<int> revGraph[MAXN]; // 反向边，用于拓扑找枝

// 清空全局数据结构
void clearData() {
    for (int i = 1; i <= n; i++) {
        compId[i] = ringId[i] = depth[i] = ringPos[i] = ringSize[i] = 0;
        onRing[i] = false;
        revGraph[i].clear();
        for (int j = 0; j < LOGN; j++) parent[i][j] = 0;
    }
}

void dfs(int u, int cid, int rid, int d, int pos) {
    compId[u] = cid;
    ringId[u] = rid;
    depth[u] = d;
    ringPos[u] = pos;
    for (int v : revGraph[u]) {
        if (onRing[v] || compId[v]) continue;
        parent[v][0] = u;
        dfs(v, cid, rid, d + 1, pos);
    }
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    int diff = depth[u] - depth[v];
    for (int i = 0; i < LOGN; i++)
        if (diff & (1 << i)) u = parent[u][i];
    if (u == v) return u;
    for (int i = LOGN - 1; i >= 0; i--)
        if (parent[u][i] != parent[v][i]) {
            u = parent[u][i];
            v = parent[v][i];
        }
    return parent[u][0];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    // 循环读取直到文件结束
    while (cin >> n) {
        clearData(); // 清空上一组数据
        
        for (int i = 1; i <= n; i++) cin >> to[i];
        
        // 初始化入度数组
        vector<int> inDegree(n + 1, 0);
        for (int i = 1; i <= n; i++) inDegree[to[i]]++;
        
        // 构建反向图
        for (int i = 1; i <= n; i++) revGraph[to[i]].push_back(i);
        
        // 拓扑排序，标记不在环上的节点
        queue<int> qq;
        for (int i = 1; i <= n; i++)
            if (inDegree[i] == 0) qq.push(i);
        while (!qq.empty()) {
            int u = qq.front(); qq.pop();
            int v = to[u];
            inDegree[v]--;
            if (inDegree[v] == 0) qq.push(v);
        }
        
        // 标记环
        int compCnt = 0, ringCnt = 0;
        for (int i = 1; i <= n; i++) {
            if (inDegree[i] > 0 && compId[i] == 0) {
                compCnt++;
                vector<int> ring;
                int cur = i;
                while (inDegree[cur] > 0 && compId[cur] == 0) {
                    compId[cur] = compCnt;
                    ring.push_back(cur);
                    onRing[cur] = true;
                    cur = to[cur];
                }
                ringCnt++;
                for (size_t j = 0; j < ring.size(); j++) {
                    int u = ring[j];
                    ringId[u] = ringCnt;
                    depth[u] = 0;
                    ringPos[u] = j;
                    parent[u][0] = 0;
                }
                ringSize[ringCnt] = ring.size();
            }
        }
        
        // 对环上每个节点，DFS 标记枝上的节点
        for (int i = 1; i <= n; i++) {
            if (onRing[i]) {
                for (int v : revGraph[i]) {
                    if (!onRing[v]) {
                        parent[v][0] = i;
                        dfs(v, compId[i], ringId[i], 1, ringPos[i]);
                    }
                }
            }
        }
        
        // 预处理 LCA 的倍增表
        for (int j = 1; j < LOGN; j++)
            for (int i = 1; i <= n; i++)
                if (parent[i][j - 1] != 0)
                    parent[i][j] = parent[parent[i][j - 1]][j - 1];
        
        // 处理查询
        cin >> q;
        while (q--) {
            int a, b;
            cin >> a >> b;
            if (compId[a] != compId[b]) {
                cout << "-1\n";
                continue;
            }
            if (ringId[a] != ringId[b]) {
                // 不同环，但在同一基环树？不可能，因为基环树只有一个环
                // 所以这里意味着在不同基环树，上面已经判断
                cout << "-1\n";
                continue;
            }
            if (onRing[a] && onRing[b]) {
                // 都在环上
                int p1 = ringPos[a], p2 = ringPos[b];
                int sz = ringSize[ringId[a]];
                int d = abs(p1 - p2);
                d = min(d, sz - d);
                cout << d << "\n";
            } else if (!onRing[a] && !onRing[b]) {
                // 都在枝上
                int l = lca(a, b);
                if (l != 0) {
                    // 在同一个枝上
                    cout << depth[a] + depth[b] - 2 * depth[l] << "\n";
                } else {
                    // 在不同枝上，LCA 是环上某个节点
                    int na = a, nb = b;
                    while (!onRing[na]) na = parent[na][0];
                    while (!onRing[nb]) nb = parent[nb][0];
                    int p1 = ringPos[na], p2 = ringPos[nb];
                    int sz = ringSize[ringId[na]];
                    int d = abs(p1 - p2);
                    d = min(d, sz - d);
                    cout << depth[a] + depth[b] + d << "\n";
                }
            } else {
                // 一个在环上一个在枝上
                if (!onRing[a]) swap(a, b); // 确保 a 在环上，b 在枝上
                // a 在环上，b 在枝上
                int nb = b;
                while (!onRing[nb]) nb = parent[nb][0];
                int p1 = ringPos[a], p2 = ringPos[nb];
                int sz = ringSize[ringId[a]];
                int d = abs(p1 - p2);
                d = min(d, sz - d);
                cout << depth[b] + d << "\n";
            }
        }
    }
    return 0;
}
```

## 总结

本题的关键在于理解图的特殊结构：每个节点只有一个出边，形成基环树森林。通过拓扑排序识别环，然后使用 $\texttt{DFS}$ 和 $\texttt{LCA}$ 处理枝上的查询。需要注意处理多种情况：

1. 不同基环树：不可达
2. 同一环上：计算环上最短距离
3. 同一枝上：使用 $\texttt{LCA}$ 计算距离
4. 不同枝上：先到环上再汇合
5. 环上+枝上：枝上节点先到环上

该算法的时间复杂度为 $O((N+Q) \log N)$ ，空间复杂度为 $O(N \log N)$ ，可以高效处理大规模数据。
