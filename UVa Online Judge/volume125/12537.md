## 题目描述

有两个核电站，分别位于平面坐标 $(ax, ay)$ 和 $(bx, by)$ 处。每个核电站有一个防护半径 $R_1$ 和 $R_2$ ，距离核电站不超过相应半径的房子属于该核电站的高风险区，会收到一套防护设备。

如果一个房子同时位于两个核电站的高风险区内，它会收到两套设备，但只需要一套。多余的一套可以送给低风险区（即两个高风险区之外）的房子。

给定 $N$ 个房子的坐标 $(x_i, y_i)$ ，以及 $q$ 组查询，每组查询给出 $(R_1, R_2)$ ，要求计算对于每组半径，低风险区中最终仍然没有防护设备的房子数量。

**数据范围**：
- $0 < N \leq 200000$
- $0 \leq x_i, y_i, ax, ay, bx, by \leq 20000$
- $0 < q \leq 20000$
- $0 < R_1, R_2 \leq 13000$

## 问题分析

### 1. 关键观察

设：
- $A$ = 在核电站 $1$ 高风险区的房子数（即 $dist_1 \leq R_1^2$）
- $B$ = 在核电站 $2$ 高风险区的房子数（即 $dist_2 \leq R_2^2$）
- $C$ = 同时在两个高风险区的房子数（即 $dist_1 \leq R_1^2$ 且 $dist_2 \leq R_2^2$）

### 2. 设备分配推导

- 高风险区总房子数（并集）：$A + B - C$
- 低风险区房子数：$N - (A + B - C)$
- 多余设备数：$C$（每个重叠房子多出一套）
- 能拿到设备的低风险房子数：$\min(C, N - (A + B - C))$
- 最终无设备的低风险房子数：$[N - (A + B - C)] - \min(C, N - (A + B - C))$

### 3. 公式简化

令 $L = N - (A + B - C)$ 表示低风险房子数，$E = C$ 表示多余设备数。

- 如果 $E \geq L$ ，则所有低风险房子都能拿到设备，答案为 $0$。
- 如果 $E < L$ ，则答案为 $L - E$。

将 $L = N - A - B + C$ 和 $E = C$ 代入：
$$
\text{答案} = \max(0, (N - A - B + C) - C) = \max(0, N - A - B)
$$

**重要发现**：答案只与 $N$ 、$A$ 、$B$ 有关，与 $C$ 无关！这意味着我们不需要计算重叠部分。

### 4. 验证公式

通过几个例子验证：

1. **例1**：$N=5$，所有房子在低风险区（$A=0, B=0$）
   - 低风险房子数 $=5$，多余设备 $=0$
   - 无设备数 $=5$
   - 公式：$\max(0, 5-0-0)=5$ ✓

2. **例2**：$N=5$，$A=2, B=2, C=1$
   - 高风险区并集 $=2+2-1=3$，低风险 $=2$
   - 多余设备 $=1$，分配后剩余无设备 $=1$
   - 公式：$\max(0, 5-2-2)=1$ ✓

3. **例3**：$N=5$，$A=4, B=4, C=4$
   - 高风险区并集 $=4$，低风险 $=1$
   - 多余设备 $=4$，全部分配，剩余 $0$
   - 公式：$\max(0, 5-4-4)=0$ ✓

## 解题思路

### 1. 核心任务

对于每个查询 $(R_1, R_2)$ ，需要快速计算：
- $A$ = 满足 $dist_1 \leq R_1^2$ 的房子数
- $B$ = 满足 $dist_2 \leq R_2^2$ 的房子数

然后计算 $\max(0, N - A - B)$ 。

### 2. 距离计算优化

由于 $R_1, R_2 \leq 13000$ ，且坐标范围为 $[0, 20000]$ ，直接计算欧几里得距离需要开方，比较耗时。注意到我们只需要比较距离平方，因此可以避免开方运算：
$$
dist_1 = (x - ax)^2 + (y - ay)^2
$$
$$
dist_2 = (x - bx)^2 + (y - by)^2
$$

### 3. 查询优化

对于 $q$ 最多 $20000$ 次查询，$N$ 最多 $200000$ ，需要 $O(\log N)$ 的查询复杂度。

预处理策略：
1. 计算每个房子的 $dist_1$ 和 $dist_2$
2. 将所有 $dist_1$ 值排序，用于二分查找 $A$
3. 将所有 $dist_2$ 值排序，用于二分查找 $B$

### 4. 算法步骤

1. **输入处理**：读取 $N$ 个房子的坐标
2. **距离计算**：对于每个房子，计算到两个核电站的平方距离
3. **预处理**：
   - 创建 $dist_1$ 数组并排序
   - 创建 $dist_2$ 数组并排序
4. **查询处理**：对于每个查询 $(R_1, R_2)$
   - 计算 $r_1 = R_1^2$，$r_2 = R_2^2$
   - 使用 `upper_bound` 在 $dist_1$ 数组中找到第一个大于 $r_1$ 的位置，得到 $A$
   - 使用 `upper_bound` 在 $dist_2$ 数组中找到第一个大于 $r_2$ 的位置，得到 $B$
   - 输出 $\max(0, N - A - B)$

### 5. 时间复杂度分析

- 预处理：$O(N \log N)$
- 每次查询：$O(\log N)$
- 总时间复杂度：$O(N \log N + q \log N)$，满足大数据量要求

## 代码实现

```cpp
// Radiation

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct House {
    int x, y;
    int dist1, dist2; // 到两个核电站的平方距离
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int caseNo = 1;
    int n;
    while (cin >> n && n) {
        vector<House> houses(n);
        for (int i = 0; i < n; i++) cin >> houses[i].x >> houses[i].y;

        int ax, ay, bx, by, q;
        cin >> ax >> ay >> bx >> by >> q;

        // 计算每个房子到两个核电站的平方距离
        for (int i = 0; i < n; i++) {
            int dx1 = houses[i].x - ax, dy1 = houses[i].y - ay;
            int dx2 = houses[i].x - bx, dy2 = houses[i].y - by;
            houses[i].dist1 = dx1 * dx1 + dy1 * dy1;
            houses[i].dist2 = dx2 * dx2 + dy2 * dy2;
        }

        // 按 dist1 排序，用于二分查找 A
        vector<int> dist1Sorted(n);
        for (int i = 0; i < n; i++) dist1Sorted[i] = houses[i].dist1;
        sort(dist1Sorted.begin(), dist1Sorted.end());

        // 收集所有 dist2，用于二分查找 B
        vector<int> dist2Sorted(n);
        for (int i = 0; i < n; i++) dist2Sorted[i] = houses[i].dist2;
        sort(dist2Sorted.begin(), dist2Sorted.end());

        cout << "Case " << caseNo++ << ":\n";

        while (q--) {
            int r1, r2;
            cin >> r1 >> r2;
            r1 *= r1; // 转换为平方距离
            r2 *= r2;

            // A: dist1 <= r1 的房子数
            int A = upper_bound(dist1Sorted.begin(), dist1Sorted.end(), r1) - dist1Sorted.begin();
            // B: dist2 <= r2 的房子数
            int B = upper_bound(dist2Sorted.begin(), dist2Sorted.end(), r2) - dist2Sorted.begin();

            int answer = max(0, n - A - B);
            cout << answer << "\n";
        }
    }

    return 0;
}
```

## 总结

本题的关键在于通过数学推导简化问题，发现最终答案只与 $N$ 、$A$ 、$B$ 有关，而与重叠部分 $C$ 无关。这一发现大大简化了问题，使得我们只需要分别计算在各自高风险区内的房子数量，而不需要处理复杂的重叠情况。

实现时需要注意：
1. 使用平方距离避免浮点运算
2. 预处理排序后的距离数组以实现快速查询
3. 使用 `upper_bound` 进行二分查找
4. 注意数据范围，使用快速输入输出

该解法时间复杂度为 $O(N \log N + q \log N)$，空间复杂度为 $O(N)$，完全满足题目要求。
