## 题目描述

“倒计时”是英国一档电视节目中的一个游戏环节。参赛者从 $24$ 张数字牌中选出 $6$ 张，其中大数牌为 $\{25, 50, 75, 100\}$（共 $4$ 张），小数牌为 $1$ 至 $10$ 每个数字各两张。参赛者可以自由选择大数牌的数量（$0$ 至 $4$ 个），其余为小数牌。

选定的 $6$ 张牌通过加、减、乘、除四则运算组合，在 $30$ 秒内得到一个尽可能接近随机目标数 $T$（$1 \le T \le 999$）的结果。具体要求如下：

- 不必使用所有数字。
- 每个数字只能使用它出现的次数。
- 运算过程中不允许出现分数，中间结果必须为正整数。
- 除法必须为整除（即能除尽）。
- 运算顺序由括号隐含决定，每一步只能使用已经计算得到的数或原始数。

题目要求编写程序，对每组输入数据输出得到目标数 $T$ 的最佳运算序列。如果无法精确得到 $T$，则给出最接近 $T$ 的解。

## 输入格式

第一行包含一个整数 $C$（$1 \le C \le 50$），表示测试用例的数量。

接下来 $C$ 行，每行包含 $7$ 个整数：前 $6$ 个整数为选中的 $6$ 张牌（来自集合 $\{1,2,\dots,10,25,50,75,100\}$），第 $7$ 个整数为目标数 $T$（$1 \le T \le 999$）。

## 输出格式

对每个测试用例，输出若干行：

- 第一行：`Target: T`
- 接下来若干行：每一步运算，格式为 `操作数1 运算符 操作数2 = 结果`，运算符与操作数之间用一个空格隔开。
- 最后一行：`Best approx: 得到的数值`
- 一个空行。

如果有多个最优解（与 $T$ 的差值相同），任选一个输出即可。

## 样例

**输入**

```
3
1 75 100 5 3 25 25
100 100 100 100 100 75 345
1 3 1 10 100 75 345
```

**输出**

```
Target: 25
Best approx: 25

Target: 345
100 + 100 = 200
75 + 100 = 175
200 * 175 = 35000
35000 - 100 = 34900
34900 / 100 = 349
Best approx: 349

Target: 345
100 - 10 = 90
3 * 90 = 270
270 + 75 = 345
Best approx: 345
```

## 题目分析

本题本质上是一个**组合搜索与表达式求值**问题，类似于经典的“$24$ 点”游戏，但有如下区别：

1. 数字个数固定为 $6$ 个，且允许使用部分数字。
2. 目标是一个三位数，需要找到最接近的值。
3. 运算结果必须是正整数，且除法必须整除。
4. 需要输出完整的运算步骤，而不仅仅是最终结果。

直接暴力枚举所有可能的运算顺序和括号组合，其状态空间非常庞大。对于 $6$ 个数字，可能的二叉树结构数量为卡特兰数 $C_5 = 42$，每个内部节点有 $4$ 种运算符选择，数字排列有 $6! = 720$ 种，总状态数约为 $42 \times 720 \times 4^5 \approx 1.2 \times 10^8$，再加上中间结果的正整数约束，直接搜索在时间上尚可接受，但需要高效的状态表示和剪枝。

## 解题思路

### 核心思想：子集动态规划（$\texttt{DP}$） + 记忆化

考虑到数字个数很少（$n = 6$），我们可以用**二进制掩码**（$mask$）来表示哪些原始数字已经被使用。对每个掩码 $mask$，我们维护一个从数值到表达式及其运算步骤的映射。

#### 状态定义

令 $\textit{dp}[\textit{mask}]$ 为一个哈希表（或 `map`），键为整数 $v$，值为一个结构体，包含：

- $v$ 本身
- 表达式字符串（带括号）
- 生成 $v$ 所需的运算步骤序列

其中 $mask$ 是一个 $6$ 位二进制数，第 $i$ 位为 $1$ 表示原始的第 $i$ 个数已经被使用。

#### 初始化

对于每个单元素掩码 $mask = 1 \ll i$，其状态为：

$$
dp[mask][nums[i]] = \{nums[i],\text{to\_string}(nums[i]), \{\}\}
$$

即该数值本身，表达式就是数字本身，没有运算步骤。

#### 合并过程

对于任意掩码 $mask$，我们将其分解为两个不相交的非空子集 $sub$ 和 $other = mask \oplus sub$，且要求 $sub \le other$ 以避免重复枚举（因为加法和乘法满足交换律，减法和除法需要双向考虑）。

对 $dp[sub]$ 中的每个状态 $(a, state_a)$ 和 $dp[other]$ 中的每个状态 $(b, state_b)$，尝试四种运算：

- **加法** $a + b$
- **乘法** $a \times b$
- **减法** $a - b$（仅当 $a > b$）
- **减法** $b - a$（仅当 $b > a$）
- **除法** $a / b$（仅当 $b \neq 0$ 且 $a \% b = 0$）
- **除法** $b / a$（仅当 $a \neq 0$ 且 $b \% a = 0$）

每次合并得到新值 $v$，对应的表达式为 `"(" + expr_a + " op " + expr_b + ")"`，运算步骤为 $state_a.steps$ 与 $state_b.steps$ 的拼接，再加上当前步骤 `"a op b = v"`。

#### 去重与优化

对每个 $(mask, v)$ 保留步骤数最少的表达式（因为更长的步骤不会改善结果且浪费输出）。这可以通过在插入时检查 $dp[mask]$ 中是否已存在键 $v$，若存在则比较步骤数量，只保留较短的。

#### 最优解搜索

完成所有掩码的 $\texttt{DP}$ 后，遍历所有 $mask \ge 1$ 中的所有状态 $(v, state)$，计算 $|v - T|$，选择差值最小、差值相同时数值最大的解（题目样例暗示偏好更大的近似值）。记录该状态对应的步骤序列。

#### 复杂度分析

- **状态数**：掩码总数 $2^6 = 64$，每个掩码产生的不同数值个数在 $6$ 个数字的限制下非常有限（实测每个掩码的状态数通常不超过几十个）。
- **合并次数**：对每个掩码，枚举其子集分割的数量约为 $3^n$ 量级（因为每个元素可以属于左子集、右子集或不选）。对于 $n = 6$，$3^6 = 729$，非常小。
- **总复杂度**：$O(3^n \cdot K^2)$，其中 $K$ 是每个子集的状态数。实际运行时间远小于 $1$ 秒。

## 代码实现

```cpp
// Countdown
// UVa ID: 12553
// Verdict: Accepted
// Submission Date: 2026-06-05
// UVa Run Time: 1.530s
//
// 版权所有（C）2016，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct State {
    int value;
    string expr;
    vector<string> steps;
};

int target, bestDiff, bestValue;
vector<string> bestSteps;

// dp[mask][value] = 该子集能产生该value的最佳表达式及步骤
map<int, State> dp[1 << 6];

void updateBest(int value, const vector<string>& steps) {
    int diff = abs(value - target);
    if (diff < bestDiff || (diff == bestDiff && value > bestValue)) {
        bestDiff = diff;
        bestValue = value;
        bestSteps = steps;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int C;
    cin >> C;
    while (C--) {
        vector<int> nums(6);
        for (int i = 0; i < 6; ++i) cin >> nums[i];
        cin >> target;
        
        int n = 6;
        int totalMask = 1 << n;
        for (int i = 0; i < totalMask; ++i) dp[i].clear();
        
        // 初始化单数字状态
        for (int i = 0; i < n; ++i) {
            int mask = 1 << i;
            dp[mask][nums[i]] = {nums[i], to_string(nums[i]), {}};
        }
        
        // 枚举所有子集
        for (int mask = 1; mask < totalMask; ++mask) {
            // 枚举mask的非平凡子集分割
            for (int sub = (mask - 1) & mask; sub > 0; sub = (sub - 1) & mask) {
                int other = mask ^ sub;
                if (sub > other) continue; // 避免重复枚举
                if (dp[sub].empty() || dp[other].empty()) continue;
                
                // 合并sub和other的所有可能值
                for (auto& p1 : dp[sub]) {
                    for (auto& p2 : dp[other]) {
                        int a = p1.first, b = p2.first;
                        State& s1 = p1.second, s2 = p2.second;
                        
                        // 加法
                        int v = a + b;
                        string expr = "(" + s1.expr + " + " + s2.expr + ")";
                        vector<string> steps = s1.steps;
                        steps.insert(steps.end(), s2.steps.begin(), s2.steps.end());
                        steps.push_back(to_string(a) + " + " + to_string(b) + " = " + to_string(v));
                        if (dp[mask].find(v) == dp[mask].end() || steps.size() < dp[mask][v].steps.size())
                            dp[mask][v] = {v, expr, steps};
                        
                        // 乘法
                        v = a * b;
                        expr = "(" + s1.expr + " * " + s2.expr + ")";
                        steps = s1.steps;
                        steps.insert(steps.end(), s2.steps.begin(), s2.steps.end());
                        steps.push_back(to_string(a) + " * " + to_string(b) + " = " + to_string(v));
                        if (dp[mask].find(v) == dp[mask].end() || steps.size() < dp[mask][v].steps.size())
                            dp[mask][v] = {v, expr, steps};
                        
                        // 减法 a - b
                        if (a > b) {
                            v = a - b;
                            expr = "(" + s1.expr + " - " + s2.expr + ")";
                            steps = s1.steps;
                            steps.insert(steps.end(), s2.steps.begin(), s2.steps.end());
                            steps.push_back(to_string(a) + " - " + to_string(b) + " = " + to_string(v));
                            if (dp[mask].find(v) == dp[mask].end() || steps.size() < dp[mask][v].steps.size())
                                dp[mask][v] = {v, expr, steps};
                        }
                        
                        // 减法 b - a
                        if (b > a) {
                            v = b - a;
                            expr = "(" + s2.expr + " - " + s1.expr + ")";
                            steps = s2.steps;
                            steps.insert(steps.end(), s1.steps.begin(), s1.steps.end());
                            steps.push_back(to_string(b) + " - " + to_string(a) + " = " + to_string(v));
                            if (dp[mask].find(v) == dp[mask].end() || steps.size() < dp[mask][v].steps.size())
                                dp[mask][v] = {v, expr, steps};
                        }
                        
                        // 除法 a / b
                        if (b != 0 && a % b == 0) {
                            v = a / b;
                            expr = "(" + s1.expr + " / " + s2.expr + ")";
                            steps = s1.steps;
                            steps.insert(steps.end(), s2.steps.begin(), s2.steps.end());
                            steps.push_back(to_string(a) + " / " + to_string(b) + " = " + to_string(v));
                            if (dp[mask].find(v) == dp[mask].end() || steps.size() < dp[mask][v].steps.size())
                                dp[mask][v] = {v, expr, steps};
                        }
                        
                        // 除法 b / a
                        if (a != 0 && b % a == 0) {
                            v = b / a;
                            expr = "(" + s2.expr + " / " + s1.expr + ")";
                            steps = s2.steps;
                            steps.insert(steps.end(), s1.steps.begin(), s1.steps.end());
                            steps.push_back(to_string(b) + " / " + to_string(a) + " = " + to_string(v));
                            if (dp[mask].find(v) == dp[mask].end() || steps.size() < dp[mask][v].steps.size())
                                dp[mask][v] = {v, expr, steps};
                        }
                    }
                }
            }
        }
        
        // 找最优解（考虑所有子集，不一定用完所有数字）
        bestDiff = INT_MAX;
        bestValue = -1;
        bestSteps.clear();
        
        for (int mask = 1; mask < totalMask; ++mask) {
            for (auto& p : dp[mask]) {
                int val = p.first;
                State& st = p.second;
                updateBest(val, st.steps);
            }
        }
        
        cout << "Target: " << target << "\n";
        for (const string& step : bestSteps) cout << step << "\n";
        cout << "Best approx: " << bestValue << "\n\n";
    }
    return 0;
}
```

## 总结

本题的关键技巧包括：

1. **二进制掩码表示集合**：用 $\textit{mask}$ 高效表示哪些原始数字已被使用，避免了对数组的频繁复制和排序。
2. **分治法合并子集**：将问题分解为两个不相交子集的合并，通过枚举所有子集分割实现了系统的状态递推。
3. **带步骤记录的动态规划**：在状态中不仅保存数值，还保存完整的运算步骤，使得最终输出可以直接获得，无需重新构造。
4. **去重与剪枝**：对相同的 $(\textit{mask}, v)$ 只保留步骤最少的表达式，减少状态膨胀。
5. **对称性优化**：枚举子集时要求 $\textit{sub} \le \textit{other}$，避免重复处理交换律带来的冗余。

本题的 $n = 6$ 规模使得基于子集枚举的 $\texttt{DP}$ 方法既简洁又高效，是解决此类“数字组合游戏”问题的经典范式。对于更大规模的 $n$，可以进一步引入启发式剪枝或迭代加深搜索，但在本题限制下，上述解法已足够完美通过。
