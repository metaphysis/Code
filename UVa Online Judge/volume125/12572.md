## 题目描述

给定一个长度为 $N$（$1 \leq N \leq 10000$）的非负整数序列，每个元素的值小于 $10$。对于所有满足 $0 \leq i \leq j < N$ 的子区间 $(i, j)$，求出该区间的最小值，然后将所有这些最小值求和，最后对 $1000000007$ 取模输出。

输入包含多组测试用例（不超过 $120$ 组），每组用例第一行是 $N$，第二行是一个长度为 $N$ 的数字字符串。

## 样例分析

**样例输入**
```
3
143
3
413
3
121
```

**样例输出**
```
13
11
7
```

以第一个样例 `143` 为例：

- 子区间 $(0,0)$ 最小值 $1$
- 子区间 $(0,1)$ 最小值 $1$
- 子区间 $(0,2)$ 最小值 $1$
- 子区间 $(1,1)$ 最小值 $4$
- 子区间 $(1,2)$ 最小值 $3$
- 子区间 $(2,2)$ 最小值 $3$

总和 $= 1 + 1 + 1 + 4 + 3 + 3 = 13$。

## 题目分析

### 直接做法的复杂度

最直接的想法是枚举所有子区间，对每个子区间扫描求最小值。子区间的数量为：

$$\frac{N(N+1)}{2}$$

当 $N = 10000$ 时，子区间数量约为 $5 \times 10^7$，对每个区间求最小值又会增加 $O(N)$ 的时间，显然会超时。

### 核心思路：贡献计数法

我们不能枚举区间，而应该换个角度：**枚举每个元素，计算它作为最小值出现在多少个区间中**。

对于位置 $i$ 上的元素 $a[i]$，如果我们可以知道：

- 向左最多能延伸到多远，使得 $a[i]$ 仍然是该区间的最小值
- 向右最多能延伸到多远，使得 $a[i]$ 仍然是该区间的最小值

那么包含 $i$ 且以 $a[i]$ 为最小值的子区间数量 = (左侧可延伸长度) × (右侧可延伸长度)。

### 边界处理技巧（去重）

当数组中有相同元素时，需要小心处理，避免同一个区间的最小值被重复计算。

**常用策略**：

- 向左找**第一个严格小于** $a[i]$ 的元素（遇到相等的就停下）
- 向右找**第一个小于等于** $a[i]$ 的元素（遇到相等的继续）

这样每个子区间的最小值只会被最左边那个最小值元素统计到，保证不重不漏。

### 图解说明

假设数组为 `[2, 5, 3, 3, 1]`，考虑中间的 $3$（下标 $2$）：

```cpp
下标:   0   1   2   3   4
值:     2   5   3   3   1
```

- 向左找第一个**严格小于** $3$ 的元素：下标 $0$ 的 $2$，所以左边界是 $0$（实际左侧延伸从 $1$ 开始）
- 向右找第一个**小于等于** $3$ 的元素：下标 $4$ 的 $1$，所以右边界是 $4$（实际右侧延伸到 $3$）

那么包含下标 $2$ 且以 $3$ 为最小值的区间：
- 左端点可选：$1, 2$（共 $2$ 种）
- 右端点可选：$2, 3$（共 $2$ 种）
- 总区间数 $= 2 \times 2 = 4$

验证：$(1,2)$、$(1,3)$、$(2,2)$、$(2,3)$ 最小值都是 $3$。

## 高效算法：单调栈

单调栈可以在 $O(N)$ 时间内找到每个元素左右两侧第一个比它小（或小等于）的元素位置。

### 算法步骤

1. **左侧扫描**：维护一个单调递增栈（栈底到栈顶递增），找左边第一个严格小于当前元素的位置
2. **右侧扫描**：维护一个单调递增栈，找右边第一个小于等于当前元素的位置
3. **计算贡献**：对每个 $i$，累加 $a[i] \times (i - left[i]) \times (right[i] - i)$
4. **取模**：对 $10^9+7$ 取模

### 时间复杂度

- 每个元素入栈出栈各一次，$O(N)$
- 总复杂度 $O(N)$，可以轻松应对 $N=10000$ 且 $120$ 组数据

## 完整代码

```cpp
// RMQ Overkill
// UVa ID: 12572
// Verdict: Accepted
// Submission Date: 2026-05-21
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    string s;
    while (cin >> n >> s) {
        // 将字符数组转换为整数数组
        vector<int> a(n);
        for (int i = 0; i < n; ++i)
            a[i] = s[i] - '0';
        
        vector<int> left(n), right(n);
        stack<int> st;
        
        // 第一步：找左边第一个严格小于 a[i] 的位置
        for (int i = 0; i < n; ++i) {
            while (!st.empty() && a[st.top()] >= a[i])
                st.pop();
            left[i] = st.empty() ? -1 : st.top();
            st.push(i);
        }
        
        // 清空栈，准备右侧扫描
        while (!st.empty()) st.pop();
        
        // 第二步：找右边第一个小于等于 a[i] 的位置
        for (int i = n - 1; i >= 0; --i) {
            while (!st.empty() && a[st.top()] > a[i])
                st.pop();
            right[i] = st.empty() ? n : st.top();
            st.push(i);
        }
        
        // 第三步：累加每个元素作为最小值的贡献
        long long ans = 0;
        for (int i = 0; i < n; ++i) {
            long long cnt = (long long)(i - left[i]) * (right[i] - i);
            ans = (ans + a[i] * cnt) % MOD;
        }
        
        cout << ans << '\n';
    }
    
    return 0;
}
```

## 总结

| 方法 | 时间复杂度 | 空间复杂度 | 是否可行 |
|------|------------|------------|----------|
| 暴力枚举 | $O(N^3)$ | $O(1)$ | ❌ 超时 |
| 预处理区间最小值 | $O(N^2)$ | $O(N^2)$ | ❌ 内存超限 |
| 单调栈贡献计数 | $O(N)$ | $O(N)$ | ✅ 完美通过 |

本题的核心技巧是 **“贡献计数”** 与 **“单调栈”** 的结合。通过将问题从“枚举所有区间”转化为“统计每个元素作为最小值的次数”，再利用单调栈快速找到左右边界，成功将复杂度降至线性。

这种思维方式在区间最值相关问题中非常常见，例如 **“直方图最大矩形”**、**“所有子数组最小值之和”** 等经典题目都使用了类似的思想。
