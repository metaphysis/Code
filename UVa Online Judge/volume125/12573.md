### **问题描述**

$\texttt{Sohel}$ 老师布置了一项作业，每位学生需要根据以下公式确定出题的章节编号 $y$ ：

$$
y = (Roll \% 4) + 2
$$

其中 $Roll$ 是学号。即学生需要从第 $y$ 章出题并给出答案。

现给定两个整数 $x$ 和 $y$ ，要求找到一个正整数 $m$ ，使得

$$
(x \% m) + 2 = y
$$

成立。如果存在多个满足条件的 $m$ ，输出最小的一个；如果不存在这样的 $m$ ，则输出 `Impossible` 。

**输入**：第一行一个整数 $T$（ $T \le 125$ ），表示测试用例个数。接下来 $T$ 行，每行两个整数 $x$（ $0 \le x \le 10^{12}$ ）和 $y$（ $2 \le y \le x + 2$ ）。

**输出**：对于每个测试用例，输出一行，为对应的 $m$ 或 `Impossible` 。

---

### **题目分析**

本题的核心是求解一个关于取模运算的方程：

$$
(x \% m) + 2 = y
$$

将其移项，可得：

$$
x \% m = y - 2
$$

令 $r = y - 2$ ，则原方程简化为：

$$
x \% m = r
$$

其中 $r$ 是一个非负整数（因为 $y \ge 2$ ），且 $r \le x$（因为 $y \le x + 2$ ）。

我们需要寻找正整数 $m$ 满足上述条件。

---

### **解题思路**

根据模运算的定义， $x \% m = r$ 意味着存在一个非负整数 $k$ ，使得：

$$
x = k \cdot m + r
$$

且 $0 \le r < m$ 。

由此可得：

$$
x - r = k \cdot m
$$

即 $m$ 必须是 $d = x - r$ 的约数，并且必须满足 $m > r$ （因为余数 $r$ 必须小于除数 $m$ ）。

因此，问题转化为：**在 $d = x - r$ 的所有正约数中，寻找大于 $r$ 的最小约数**。

接下来我们根据 $r$ 的不同情况分别讨论。

#### **情况一：$r > x$**

此时 $y - 2 > x$ ，即 $y > x + 2$ ，与输入约束 $y \le x + 2$ 矛盾。虽然输入可能保证不会出现这种情况，但为了代码健壮性，我们直接判定为 `Impossible` 。

#### **情况二：$r = 0$**

此时方程变为 $x \% m = 0$ ，即 $m$ 整除 $x$ 。

- 如果 $x = 0$ ，任何正整数 $m$ 都满足 $0 \% m = 0$ ，取最小的 $m = 1$ 。
- 如果 $x > 0$ ，我们需要 $x$ 的最小正约数（大于 $0$ ）。但注意，题目要求 $m$ 是正整数，且 $r = 0$ 时， $m$ 必须大于 $0$ ，但不必大于 $r$ 。实际上，当 $r = 0$ 时， $m$ 可以是 $1$ ，因为 $x \% 1 = 0$ 恒成立。因此直接输出 $1$ 即可。

#### **情况三：$r = x$**

此时要求 $x \% m = x$ ，这意味着 $m > x$ （因为余数必须小于除数）。最小的 $m$ 是 $x + 1$ 。

#### **情况四：$0 < r < x$**

此时 $d = x - r > 0$ 。我们需要在 $d$ 的所有约数中，寻找大于 $r$ 的最小约数。

**高效寻找方法**：
- 约数是成对出现的：若 $i$ 是 $d$ 的约数，则 $d / i$ 也是 $d$ 的约数。
- 我们只需要从 $1$ 遍历到 $\sqrt{d}$ ，检查每个 $i$ 和 $d / i$ 是否满足 $i > r$ 或 $d / i > r$ ，并记录最小值。
- 时间复杂度为 $O(\sqrt{d})$ ，在 $d \le 10^{12}$ 时可行。

若遍历完所有约数仍未找到满足 $m > r$ 的约数，则输出 `Impossible` 。

---

### **算法步骤**

对于每个测试用例 $(x, y)$ ：

1. 计算 $r = y - 2$ 。
2. 若 $r > x$ ，输出 `Impossible` 。
3. 若 $r = 0$ ，输出 $1$ 。
4. 若 $r = x$ ，输出 $x + 1$ 。
5. 否则，计算 $d = x - r$ 。
6. 初始化答案 $m$ 为一个极大值（例如 $2^{60}$ ）。
7. 从 $i = 1$ 遍历到 $\sqrt{d}$ ：
   - 若 $d \% i == 0$ ：
     - 如果 $i > r$ ，更新 $m = \min(m, i)$ 。
     - 如果 $d / i > r$ ，更新 $m = \min(m, d / i)$ 。
8. 若 $m$ 仍为初始极大值，输出 `Impossible` ；否则输出 $m$ 。

### **代码实现**

```cpp
// Sohel Sir's Assignment

//

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        long long x, y;
        cin >> x >> y;
        long long remainder = y - 2;
        if (remainder > x) {
            cout << "Impossible\n";
            continue;
        }
        if (remainder == 0) {
            cout << "1\n";
            continue;
        }
        if (remainder == x) {
            cout << x + 1 << '\n';
            continue;
        }
        long long d = x - remainder, m = (1LL << 60);
        for (long long i = 1; i * i <= d; i++)
            if (d % i == 0) {
                if (i > remainder) m = min(m, i);
                if ((d / i) > remainder) m = min(m, d / i);
            }
        if (m == (1LL << 60)) cout << "Impossible";
        else cout << m;
        cout << '\n';
    }
    return 0;
}
```

### **复杂度分析**

- 对于每个测试用例，主要开销在于寻找 $d$ 的约数，需要 $O(\sqrt{d})$ 的时间。
- 由于 $d \le x \le 10^{12}$ ，$\sqrt{d} \le 10^6$ 。
- 总时间复杂度为 $O(T \cdot \sqrt{x})$ ，在 $T \le 125$ 时完全可行。

### **总结**

本题是一道数论与模运算结合的基础题，关键在于将原方程 $x \% m = r$ 转化为寻找 $d = x - r$ 的约数，并注意 $m > r$ 的条件。通过分类讨论和高效约数枚举，即可在合理时间内求解。
