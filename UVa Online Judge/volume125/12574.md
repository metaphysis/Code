## 题目描述

$\texttt{VOID}$ 战队成员需要根据新规则更改他们的昵称。 规则如下：

1. 有 $N$ 个单词列表，第 $i$ 个列表包含 $W_i$ 个不同的单词。
2. 成员从列表 $1$ 到列表 $N$ 按顺序选择单词，每个列表最多选择一个单词（也可以不选）。
3. 最终的名字必须由至少 $2$ 个单词组成。

现在给定 $N$ 和每个列表的单词数量 $W_1, W_2, \dots, W_N$，我们需要计算所有可能的不同名字的数量。由于结果可能很大，请输出结果对 $1000000007$ 取模的值。

**输入格式**
- 第一行：测试用例数 $T$（$T \le 20$）。
- 每个测试用例包含两行：
  - 第一行：整数 $N$（$2 \le N \le 5000$）。
  - 第二行：$N$ 个空格分隔的整数 $W_i$（$1 \le W_i \le 10^9$）。

**输出格式**
- 对于每个测试用例，输出一行一个整数，表示可能的名字数量对 $1000000007$ 取模的结果。

**示例**
输入：
```
3
3
2 1 2
3
2 2 3
3
2 3 2
```
输出：
```
12
20
39
```

## 题目分析

这个问题本质上是一个组合计数问题。 我们需要统计所有满足条件的单词选择序列。

### 关键约束条件
1. **顺序性**：必须从列表 $1$ 开始，按顺序到列表 $N$。
2. **可选性**：每个列表可以选择 $0$ 个或 $1$ 个单词。
3. **最小长度**：最终名字至少包含 $2$ 个单词。

## 解题思路

### 第一步：不考虑最小长度限制
如果先不考虑“至少 $2$ 个单词”的限制，只考虑规则 $1$ 和规则 $2$，那么每个列表 $i$ 都有 $(W_i + 1)$ 种选择方式（选一个单词有 $W_i$ 种，不选有 $1$ 种）。由于各列表的选择是独立的，所有可能的选择方式总数为：
$$
S = \prod_{i=1}^{N} (W_i + 1)
$$
这里 $S$ 包括了所有可能的选择，包括一个单词都不选的情况。

### 第二步：排除不满足最小长度的情况
根据要求，名字必须至少包含 $2$ 个单词。 因此，我们需要从 $S$ 中排除以下两种情况：
$1$. **单词数为 $0$**：即所有列表都不选。这种情况只有 $1$ 种。
$2$. **单词数为 $1$**：即恰好从一个列表中选一个单词，其他列表都不选。对于列表 $i$，选择方式有 $W_i$ 种（选一个单词），其他列表不选。因此，总共有 $\sum_{i=1}^{N} W_i$ 种情况。

### 第三步：最终公式
因此，满足条件的选择方式总数为：
$$
r = S - 1 - \sum_{i=1}^{N} W_i
$$
其中 $S = \prod_{i=1}^{N} (W_i + 1)$。

### 第四步：取模运算
由于 $W_i$ 可以达到 $10^9$，$S$ 可能非常大，我们需要在计算过程中不断取模 $M = 1000000007$。 注意：
- 计算 $S$ 时，对于每个 $(W_i + 1)$ 先取模 $M$，再相乘。
- 计算总和 $\sum W_i$ 时，也需取模 $M$。
- 最后计算 $r = (S - 1 - \sum W_i + M) \% M$，其中 $+M$ 是为了避免负数结果。

### 算法复杂度
- 时间复杂度：$O(N)$ 每个测试用例，因为只需要一次遍历计算乘积和总和。
- 空间复杂度：$O(1)$ 额外空间。

## 示例验证

以第一个样例为例：$N=3$，$W=[2,1,2]$。
- $S = (2+1) \times (1+1) \times (2+1) = 3 \times 2 \times 3 = 18$。
- $\sum W_i = 2 + 1 + 2 = 5$。
- $r = 18 - 1 - 5 = 12$，与输出一致。

```cpp

#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007; // 定义模数

int main() {
    ios_base::sync_with_stdio(false); // 关闭同步，提高输入输出效率
    cin.tie(nullptr); // 解除 cin 和 cout 的绑定
    int T; // 测试用例数
    cin >> T;
    while (T--) {
        int N;
        cin >> N;
        long long product = 1; // 存储 (W_i + 1) 的乘积
        long long sumW = 0;    // 存储 W_i 的总和
        for (int i = 0; i < N; i++) {
            long long W;
            cin >> W;
            product = product * ((W + 1) % MOD) % MOD; // 累乘并取模
            sumW = (sumW + W) % MOD; // 累加并取模
        }
        // 计算最终答案：product - 1 - sumW，注意处理负数
        long long r = (product - 1 - sumW + MOD) % MOD;
        cout << r << '\n'; // 输出结果
    }
    return 0;
}
```

## 总结

本题是一个简洁的组合计数问题，关键在于推导出排除不合法情况的公式。 通过先计算所有可能的选择方式，再减去单词数不足 $2$ 的情况，我们可以在 $O(N)$ 时间内解决每个测试用例。 注意在计算过程中及时取模，避免溢出。 代码实现简单高效，适合作为组合数学入门题目。
