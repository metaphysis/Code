[UVa 12575 Sin Cos Problem](https://blog.csdn.net/metaphysis/article/details/154878804)

## 题目描述

给定整数 $A$ 和 $B$，要求确定函数：

$$F(\theta) = A \cdot \sin\theta + B \cdot \cos\theta$$

的最大值，并找出使该最大值成立的**最小非负** $\theta$（单位为弧度），以及最大值本身。

**输入格式**  
第一行是测试用例数 $T \leq 2000$。  
接下来 $T$ 行，每行两个整数 $A$ 和 $B$，用空格分隔。$A$ 和 $B$ 在 $32$ 位有符号整数范围内。

**输出格式**  
对每个测试用例，输出一行两个实数，用空格分隔，保留两位小数。  
第一个数是使 $F(\theta)$ 最大的**最小非负** $\theta$，第二个数是最大值。

**注意**：$\pi$ 取 $\arccos(-1)$。

## 题目分析

### 数学推导

我们需要分析函数 $F(\theta) = A \sin\theta + B \cos\theta$ 的性质。这是一个典型的三角函数线性组合，可以通过三角恒等式进行简化。

#### 方法一：使用正弦函数形式

将函数重写为：

$$F(\theta) = R \sin(\theta + \phi)$$

其中：
- $R = \sqrt{A^2 + B^2}$（振幅）
- $\sin\phi = \frac{B}{R}$，$\cos\phi = \frac{A}{R}$
- 因此 $\phi = \operatorname{atan2}(B, A)$

在这种形式下，函数的最大值为 $R$，当且仅当：

$$\sin(\theta + \phi) = 1$$

即：

$$\theta + \phi = \frac{\pi}{2} + 2k\pi, \quad k \in \mathbb{Z}$$

解得：

$$\theta = \frac{\pi}{2} - \phi + 2k\pi$$

我们需要找到满足条件的最小非负 $\theta$ 值。

#### 方法二：使用余弦函数形式

同样可以写成：

$$F(\theta) = R \cos(\theta - \theta_0)$$

其中：
- $R = \sqrt{A^2 + B^2}$
- $\cos\theta_0 = \frac{B}{R}$，$\sin\theta_0 = \frac{A}{R}$
- 因此 $\theta_0 = \operatorname{atan2}(A, B)$

最大值 $R$ 在 $\theta - \theta_0 = 2k\pi$ 时取得，即：

$$\theta = \theta_0 + 2k\pi$$

### 特殊情况处理

1. **当 $A = 0$ 且 $B = 0$ 时**：  
   函数 $F(\theta) = 0$ 对所有 $\theta$ 都相同，最大值始终为 $0$。根据题目要求，应该输出**最小非负**的 $\theta$，即 $0.00$。

2. **数值稳定性**：  
   由于 $A$ 和 $B$ 可能很大，直接计算 $A^2 + B^2$ 可能导致溢出。因此我们将输入直接读取为 `double` 类型以避免这个问题。

### 算法步骤

对于每个测试用例 $(A, B)$：

1. 如果 $A = 0$ 且 $B = 0$，直接输出 `0.00 0.00`
2. 否则：
   - 计算 $R = \sqrt{A^2 + B^2}$（最大值）
   - 计算 $\phi = \operatorname{atan2}(B, A)$
   - 计算 $\theta = \frac{\pi}{2} - \phi$
   - 调整 $\theta$ 到 $[0, 2\pi)$ 范围内
3. 输出保留两位小数的 $\theta$ 和 $R$

### 时间复杂度

每个测试用例只需要常数时间计算，总体时间复杂度为 $O(T)$，对于 $T \leq 2000$ 完全可行。

## 代码实现

```cpp
// Sin Cos Problem
// UVa ID: 12575
// Verdict: Accepted
// Submission Date: 2025-11-15
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net


#include <bits/stdc++.h>
using namespace std;

const double PI = acos(-1.0);

int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        double a, b;
        scanf("%lf %lf", &a, &b);
        double r = sqrt(a * a + b * b);
        
        if (r == 0) {
            // 当 A 和 B 都为 0 时，任何 θ 都得到最大值 0
            // 取最小非负 θ = 0
            printf("0.00 0.00\n");
        } else {
            double phi = atan2(b, a);
            double theta = PI / 2 - phi;
            
            // 确保 theta 在 [0, 2π) 范围内
            if (theta < 0) theta += 2 * PI;
            if (theta >= 2 * PI) theta -= 2 * PI;
            
            printf("%.2lf %.2lf\n", theta, r);
        }
    }
    return 0;
}
```

## 总结

本题的关键在于将三角函数的线性组合转化为单一三角函数形式，从而轻松找到最大值和对应的角度。通过数学推导和特殊情况处理，我们得到了一个简洁高效的解决方案。数值稳定性的考虑确保了代码在各种边界情况下的正确性。
