[UVa 12586 Overlapping Characters](https://blog.csdn.net/metaphysis/article/details/155461848)

## 题目描述
给定 $36$ 个大写字母和数字的字符，每个字符由一个 $16$ 行 $43$ 列的像素网格表示，其中像素为 `'.'`（空）或 `'*'`（黑）。已知其中 $N$ 个字符的网格表示。你的朋友可以从给定的 $M$ 个字符（$M \le 18$）中任意选择若干个，按任意顺序叠加在一起（无缩放、平移、旋转），形成一个叠加层。

你的任务是判断哪些字符可以通过**检查单个像素是否被涂黑**来确定其是否存在于叠加层中。具体地，对于每个查询给出的 $M$ 个字符，你需要输出一个长度为 $M$ 的字符串，其中第 $i$ 个字符为：
- `'Y'`：如果可以通过检查某个像素是否涂黑来推断第 $i$ 个字符是否存在。
- `'N'`：否则。

**注意**：我们只关心“该像素是黑色能推断字符存在”的情况，不考虑“该像素是白色能推断字符不存在”的情况。

## 题目分析

### 问题转化
叠加操作可以看作逻辑“或”运算：只要有一个字符在某个像素位置是 `'*'`，叠加后该位置就是黑色。因此，要判断一个字符 $c$ 是否能通过单个像素被检测到，需要找到这样一个像素位置 $(r, c)$，使得：
1. 字符 $c$ 在该位置是 `'*'`。
2. 查询中**其他所有字符**在该位置都是 `'.'`。

如果存在这样的位置，那么只要叠加层中该位置是黑色，就说明字符 $c$ 一定存在（因为其他字符都不会在该位置涂黑）。

### 关键点
- 查询中的字符数量 $M$ 最大为 $18$，但 $N$ 最大为 $36$。
- 网格大小为 $16 \times 43 = 688$ 个像素，相对较小。
- 需要高效处理多个查询（最多 $1000$ 个）。

## 解题思路

### 朴素方法
对于每个查询，我们可以对每个字符 $c$ 遍历所有 $688$ 个像素，检查是否存在满足上述条件的位置。但这样时间复杂度为 $O(Q \cdot M^2 \cdot 16 \cdot 43)$，在 $Q=1000, M=18$ 的情况下约为 $1000 \times 18^2 \times 688 \approx 2.2 \times 10^8$，可能超时。

### 高效方法
我们可以利用“字符叠加”的思想，模拟所有查询字符同时叠加的效果：

1. **读取存储**：将每个字符的网格读入内存，方便快速访问。
2. **处理查询**：
   - 创建一个 $16 \times 43$ 的叠加层 `overlay`，初始所有位置为空（用 `'.'` 表示）。
   - 遍历查询中的每个字符 $c$：
     - 将其网格中的所有 `'*'` 位置叠加到 `overlay` 上。
     - 如果 `overlay` 中该位置是 `'.'`，则标记为字符 $c$。
     - 如果 `overlay` 中该位置已经是其他字符，则标记为重叠（用 `'#'` 表示）。
   - 叠加完成后，`overlay` 中每个位置有三种可能：
     - `'.'`：没有字符涂黑。
     - `'c'`：只有字符 $c$ 涂黑。
     - `'#'`：多个字符重叠。
3. **判断每个字符**：
   - 对于查询中的字符 $c$，检查其网格中所有 `'*'` 位置。
   - 如果存在某个位置，在 `overlay` 中对应位置是 `'c'`（即没有被其他字符覆盖），则字符 $c$ 可检测，输出 `'Y'`，否则输出 `'N'`。

### 时间复杂度
- 预处理：$O(N \cdot 16 \cdot 43)$
- 每个查询：$O(M \cdot 16 \cdot 43)$
- 总复杂度：$O(N \cdot 688 + Q \cdot M \cdot 688)$，在极限情况下约为 $36 \times 688 + 1000 \times 18 \times 688 \approx 1.24 \times 10^7$，完全可以接受。

### 空间复杂度
- 存储所有字符网格：$O(N \cdot 16 \cdot 43)$
- 每个查询的叠加层：$O(16 \cdot 43)$
- 总空间：约 $36 \times 688 \approx 25000$ 个字符，非常小。

## 代码实现

```cpp
// Overlapping Characters
// UVa ID: 12586
// Verdict: Accepted
// Submission Date: 2025-12-01
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    string order;
    cin >> order;

    // 将字符映射到其在order中的索引
    unordered_map<char, int> charToIndex;
    for (int i = 0; i < n; ++i)
        charToIndex[order[i]] = i;

    // 存储每个字符的网格
    vector<vector<string>> grids(n);
    for (int chIdx = 0; chIdx < n; ++chIdx) {
        vector<string> grid(16);
        for (int row = 0; row < 16; ++row)
            cin >> grid[row];
        grids[chIdx] = grid;
        // 跳过每个字符描述后的空行
        string emptyLine;
        getline(cin, emptyLine); // 处理可能的换行符残留
        getline(cin, emptyLine); // 读取真正的空行
    }

    // 处理每个查询
    for (int queryId = 1; queryId <= q; ++queryId) {
        string queryStr;
        cin >> queryStr;
        int m = queryStr.size();

        // 叠加层，用字符填充，'#'表示重叠，'.'表示空
        vector<vector<char>> overlay(16, vector<char>(43, '.'));

        // 叠加所有字符
        for (int i = 0; i < m; ++i) {
            char ch = queryStr[i];
            int idx = charToIndex[ch];
            const vector<string>& grid = grids[idx];
            for (int row = 0; row < 16; ++row)
                for (int col = 0; col < 43; ++col)
                    if (grid[row][col] == '*') {
                        if (overlay[row][col] == '.') // 空，标记为当前字符
                            overlay[row][col] = ch;
                        else if (overlay[row][col] != ch) // 已被其他字符占据
                            overlay[row][col] = '#'; // 标记为重叠
                    }
        }

        // 判断每个字符是否能被检测
        string result(m, 'N');
        for (int i = 0; i < m; ++i) {
            char ch = queryStr[i];
            int idx = charToIndex[ch];
            const vector<string>& grid = grids[idx];
            bool canDetect = false;
            // 检查该字符的每个'*'位置，在叠加层中是否仍然是该字符（未被覆盖）
            for (int row = 0; row < 16; ++row) {
                for (int col = 0; col < 43; ++col)
                    if (grid[row][col] == '*' && overlay[row][col] == ch) {
                        canDetect = true;
                        break;
                    }
                if (canDetect) break;
            }
            if (canDetect) result[i] = 'Y';
        }

        cout << "Query " << queryId << ": " << result << endl;
    }

    return 0;
}
```

## 总结
本题的关键在于理解“通过单个像素检测字符存在”的条件，并通过模拟叠加过程高效地检查每个字符是否具有独占的黑色像素。使用字符直接填充叠加层的方法直观且高效，避免了复杂的集合运算。注意处理输入格式中的空行，这是常见的细节问题。
