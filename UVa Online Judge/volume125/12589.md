## 题目描述

$\texttt{Vector}$ 想要教他 $7$ 岁的儿子学习向量这一数学工具。他的儿子已经掌握了坐标、在网格中画线等概念。$\texttt{Vector}$ 给了儿子 $N$ 个非负向量（即 $x$ 和 $y$ 分量都非负），要求他从中选择 $K$ 个不同的向量并按顺序绘制。

绘制规则为：从原点 $(0,0)$ 开始，按顺序将每个向量首尾相接。最终，这条折线与 $x$ 轴围成的区域面积就是儿子能获得的蛋糕大小。为了避免浮点数计算，题目要求输出最大面积的两倍。

## 输入格式

- 第一行：整数 $T$ ($1 \leq T \leq 110$)，表示测试用例数量
- 每个测试用例：
  - 第一行：两个整数 $N$ 和 $K$ ($1 \leq K \leq N \leq 50$)
  - 接下来 $N$ 行：每行两个整数 $x$ 和 $y$ ($0 \leq x,y \leq 50$)，表示一个向量

## 输出格式

对于每个测试用例，输出 `"Case X: Y"`，其中 $X$ 是测试用例编号，$Y$ 是最大面积的两倍。

## 题目分析

### 面积计算原理

当我们按顺序绘制向量时，每个向量对总面积的贡献可以分为两部分：

1. **矩形部分**：当前累计高度 × 向量宽度
2. **三角形部分**：$\frac{1}{2} \times \text{宽度} \times \text{高度}$

对于第 $i$ 个向量 $(x_i, y_i)$，其面积贡献为：
$$\texttt{area}_i = \texttt{currentHeight} \times x_i + \frac{1}{2} \times x_i \times y_i$$

由于题目要求输出面积的两倍，所以：
$$2 \times \texttt{area}_i = 2 \times \texttt{currentHeight} \times x_i + x_i \times y_i$$

其中 $\texttt{currentHeight}$ 是之前所有向量的高度之和。

### 关键观察

1. **向量顺序的重要性**：向量的绘制顺序会影响总面积，因为每个向量的矩形部分贡献取决于之前所有向量的累计高度。

2. **贪心策略**：为了最大化总面积，我们应该优先绘制斜率（$\frac{y}{x}$）较大的向量。这样可以让后续向量在更高的基础上绘制，从而获得更大的矩形面积贡献。

3. **动态规划状态设计**：我们需要同时跟踪两个信息：
   - 已选择的向量数量
   - 当前的总高度

### 算法设计

#### 1. 预处理：向量排序
首先将所有向量按斜率降序排列：
```cpp
bool operator<(const Vector& other) const {
    return y * other.x > other.y * x;  // 避免浮点数，使用交叉相乘
}
```

#### 2. 动态规划状态定义
定义 $dp[j][h]$ 表示选择 $j$ 个向量，总高度为 $h$ 时的最大两倍面积。

- $j$：已选择的向量数量 ($0 \leq j \leq K$)
- $h$：当前总高度 ($0 \leq h \leq \texttt{maxHeight}$)
- 初始状态：$dp[0][0] = 0$，其余为 $-1$（表示不可达）

#### 3. 状态转移
对于每个向量 $(x, y)$，从后往前更新 $\texttt{DP}$ 表：
```cpp
for (int j = K; j >= 1; --j) {
    for (int h = maxHeight; h >= y; --h) {
        if (dp[j - 1][h - y] != -1) {
            int newArea = dp[j - 1][h - y] + 2 * (h - y) * x + x * y;
            if (dp[j][h] < newArea) {
                dp[j][h] = newArea;
            }
        }
    }
}
```

**状态转移方程解释**：
- $dp[j-1][h-y]$：选择当前向量之前的状态
- $2 \times (h-y) \times x$：矩形部分的两倍面积（当前累计高度为 $h-y$）
- $x \times y$：三角形部分的两倍面积

#### 4. 结果提取
最终答案为所有 $dp[K][h]$ 中的最大值：
$$\text{answer} = \max_{0 \leq h \leq \text{maxHeight}} dp[K][h]$$

### 复杂度分析

- 时间复杂度：$O(N \times K \times \texttt{maxHeight})$，其中 $\texttt{maxHeight} \leq N \times 50 = 2500$
- 空间复杂度：$O(K \times \texttt{maxHeight})$

在题目约束下 ($N \leq 50, K \leq 50$)，该算法完全可行。

## 代码实现

```cpp
// Learning Vector
// UVa ID: 12589
// Verdict: Accepted
// Submission Date: 2025-11-09
// UVa Run Time: 0.080s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>
using namespace std;

struct Vector {
    int x, y;
    bool operator<(const Vector& other) const {
        return y * other.x > other.y * x;
    }
};

int main() {
    int T;
    cin >> T;
    for (int caseNum = 1; caseNum <= T; ++caseNum) {
        int N, K;
        cin >> N >> K;
        vector<Vector> vectors(N);
        for (int i = 0; i < N; ++i) {
            cin >> vectors[i].x >> vectors[i].y;
        }
        
        // 按斜率降序排序
        sort(vectors.begin(), vectors.end());
        
        // 计算最大可能高度
        int maxHeight = 0;
        for (int i = 0; i < N; ++i) {
            maxHeight += vectors[i].y;
        }
        
        // dp[j][h]: 选择j个向量，总高度为h时的最大两倍面积
        vector<vector<int>> dp(K + 1, vector<int>(maxHeight + 1, -1));
        dp[0][0] = 0;
        
        for (int i = 0; i < N; ++i) {
            int x = vectors[i].x, y = vectors[i].y;
            
            // 从后往前更新，避免重复使用同一个向量
            for (int j = K; j >= 1; --j) {
                for (int h = maxHeight; h >= y; --h) {
                    if (dp[j - 1][h - y] != -1) {
                        int newArea = dp[j - 1][h - y] + 2 * (h - y) * x + x * y;
                        if (dp[j][h] < newArea) {
                            dp[j][h] = newArea;
                        }
                    }
                }
            }
        }
        
        int maxArea = 0;
        for (int h = 0; h <= maxHeight; ++h) {
            if (dp[K][h] > maxArea) {
                maxArea = dp[K][h];
            }
        }
        
        cout << "Case " << caseNum << ": " << maxArea << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于理解向量顺序对面积的影响，以及如何通过贪心排序和动态规划来找到最优解。排序确保我们优先选择斜率大的向量，动态规划则精确计算所有可能的组合情况。这种结合贪心策略的动态规划方法在解决此类优化问题时非常有效。
