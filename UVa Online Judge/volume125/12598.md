## 题目描述

开学第一天，学生们排队领取学号。老师疯狂地随机给前 $K$ 个学生分配了学号（学号是 $1$ 到 $10^9$ 之间的正整数，且互不相同）。$\texttt{Po}$ 提出，剩下的学生应该按照“从未分配的最小正整数开始依次分配”的规则来获得学号。例如，若 $K = 4$ ，总人数 $N = 10$ ，前 $K$ 个学号为 $1, 3, 5, 10$ ，那么剩下的学号应为 $2, 4, 6, 7, 8, 9$ 。

老师生气了，开始询问第 $p$ 个位置学生的学号。你需要帮助 $\texttt{Po}$ 回答这些询问。

### 输入格式
第一行一个整数 $T$ （ $T \leq 30$ ），表示测试用例数量。  
每个测试用例第一行三个整数 $N$ （ $0 < N \leq 10^9$ ）、 $K$ （ $0 < K \leq 50000$ 且 $K \leq N$ ）、 $Q$ （ $0 < Q \leq 50000$ ）。  
第二行 $K$ 个不同的整数，表示老师分配的前 $K$ 个学号。  
第三行 $Q$ 个整数，每个整数表示一个询问的位置 $p$ （ $1 \leq p \leq N$ ）。

### 输出格式
对每个测试用例，先输出一行 `Case X:` （ $X$ 从 $1$ 开始），然后对每个询问输出一行，表示该位置学生的学号。

## 题目分析

### 核心难点
- $N$ 最大可达 $10^9$ ，无法显式存储所有学生的学号。
- $K$ 和 $Q$ 不超过 $50000$ ，相对较小。
- 学号范围很大（ $1$ 到 $10^9$ ），但已分配的学号只有 $K$ 个。

### 关键观察
1. **前 $K$ 个学生**的学号已经由老师随机分配，因此对于 $p \leq K$ 的询问，答案就是输入的第二行中第 $p$ 个数。
2. **对于 $p > K$ 的学生**，其学号是“从未分配的最小正整数”中按顺序选取的。我们需要找到第 $(p-K)$ 个未分配的学号。
3. 已分配的学号集合是已知的（ $K$ 个数），我们可以在**数值范围**上二分搜索答案。

### 二分搜索思路
设我们需要第 $t$ 个未分配的学号（ $t = p-K$ ）。  
考虑一个候选值 $middle$ ，计算在 $[1, middle]$ 范围内有多少个学号已被分配（记为 $cnt$ ）。  
那么 $[1, middle]$ 范围内未分配的学号数量为 $middle- cnt$ 。  
- 若 $middle- cnt \geq t$ ，说明 $middle$ 可能过大（或恰好是答案），我们尝试缩小 $mid$ 。
- 若 $middle- cnt < t$ ，说明 $middle$ 太小，需要增大 $middle$ 。

通过二分搜索找到**最小的 $middle$** 使得 $middle- cnt \geq t$ ，这个 $middle$ 就是第 $t$ 个未分配的学号。

### 计算 $cnt$
由于已分配的学号集合是静态的，我们可以先将其排序，然后使用 `upper_bound` 快速计算在 $[1, middle]$ 范围内的已分配学号数量。  
因为 $K \leq 50000$ ，每次 `upper_bound` 的时间是 $O(\log K)$ ，可以接受。

### 时间复杂度
- 排序： $O(K \log K)$ 。
- 每个询问二分搜索 $O(\log M)$ （ $M$ 为搜索上界，可取 $2 \times 10^9$ ），每次二分内调用 `upper_bound` $O(\log K)$ 。
- 总复杂度： $O(K \log K + Q \log M \log K)$ ，在题目限制下完全可以接受。

## 代码实现

```cpp
// Starting School
// UVa ID: 12598
// Verdict: Accepted
// Submission Date: 2026-01-16
// UVa Run Time: 0.280s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 50010;
typedef long long ll;
ll assigned[MAXN], sorted[MAXN];

int main() {
    int T;
    scanf("%d", &T);
    for (int cs = 1; cs <= T; ++cs) {
        ll n, k, q;
        scanf("%lld %lld %lld", &n, &k, &q);
        for (int i = 0; i < k; ++i) scanf("%lld", &assigned[i]);
        memcpy(sorted, assigned, k * sizeof(long long));
        sort(sorted, sorted + k);
        printf("Case %d:\n", cs);
        while (q--) {
            ll p;
            scanf("%lld", &p);
            if (p <= k) printf("%lld\n", assigned[p - 1]);
            else {
                ll needed = p - k;
                ll left = 1, right = 2e9, answer = -1;
                while (left <= right) {
                    ll middle = (left + right) / 2;
                    ll cnt = upper_bound(sorted, sorted + k, middle) - sorted;
                    ll available = middle - cnt;
                    if (available >= needed) {
                        answer = middle;
                        right = middle - 1;
                    } else left = middle + 1;
                }
                printf("%lld\n", answer);
            }
        }
    }
    return 0;
}
```

---

## 代码说明
1. **变量定义**：
   - `assigned[]` 存储老师分配的学号（原始顺序）。
   - `sorted[]` 存储排序后的学号，用于二分查找。
2. **处理询问**：
   - 若 $p \leq K$ ，直接输出 `assigned[p - 1]` 。
   - 否则，计算 `needed = p - k` ，然后在 $[1, 2\times10^9]$ 范围内二分搜索第 `needed` 个未分配的学号。
3. **二分搜索**：
   - 计算 `cnt` ：小于等于 `middle` 的已分配学号数量。
   - 计算 `available = middle - cnt` ：小于等于 `middle` 的未分配学号数量。
   - 若 `available >= needed` ，说明答案可能是 `middle` 或更小，记录并缩小右边界；否则增大左边界。
4. **搜索上界**：
   - 由于 $N \leq 10^9$ 且 $K \leq 50000$ ，最大未分配学号不会超过 $N + K$ ，因此上界设为 $2\times10^9$ 是安全的。

---

## 总结
本题通过**二分搜索**结合**已分配学号的排序数组**，巧妙地解决了大规模 $N$ 下的学号分配查询问题。核心在于将“第 $t$ 个未分配的学号”转化为在数值范围上的判定问题，利用 `upper_bound` 快速计算已分配数量，从而在合理时间内完成查询。
