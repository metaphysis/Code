## 题目描述

$\texttt{Macaw Prince}$ 有 $N$ 张卡片排成一行，每张卡片是黑色（`B`）或白色（`W`）。他每次可以移除一个**非空子序列**（不要求连续），但必须满足以下条件：

$1$. 子序列中至少有一张黑卡和至少一张白卡；
$2$. 子序列中不能有黑卡出现在白卡之后（即所有黑卡必须在所有白卡之前）。

目标是用最少的操作次数移除所有卡片。如果无法完成，输出 `IMPOSSIBLE`。

**输入格式**  
第一行一个整数 $T$（$T \le 50$）表示测试用例数。接下来 $T$ 行，每行一个仅由 `B` 和 `W` 组成的字符串，长度不超过 $10000$。

**输出格式**  
对于每个测试用例：
- 若可解，先输出最小操作次数 $N$，接着输出 $N$ 行，每行描述一次操作：先输出该次移除的卡片数量 $X$，然后按升序输出这些卡片的 $1$-起始索引。
- 若不可解，输出 `IMPOSSIBLE`。

## 题目分析

### 条件转化

每次操作移除的子序列必须形如：

$$
\texttt{B...B W...W}
$$

即若干张黑卡（至少一张）后跟若干张白卡（至少一张），中间不能出现 `W` 后再出现 `B`。

### 关键观察

$1$. **不可解条件**  
   由于每次操作必须有黑卡和白卡，且黑卡必须在白卡之前，因此：
   - 如果第一张卡片是 `W`，则第一次操作无法包含黑卡（因为黑卡不能在白卡之后）；
   - 如果最后一张卡片是 `B`，则最后一次操作无法包含白卡（因为白卡不能在黑卡之前）。
   
   因此，**当且仅当第一个字符是 `B` 且最后一个字符是 `W` 时才有可能有解**。

$2$. **可解情况分类**
   - **情况一**：字符串形如 `BBB...WWW`（前面全是 `B`，后面全是 `W`）。  
     此时只需一次操作：选择所有卡片即可满足条件。
   - **情况二**：字符串中 `B` 和 `W` 交替出现。  
     此时需要两次操作，具体构造方法如下：
     - **第一次操作**：选择最后一个 `W` 之前的所有 `B`（除了第一个 `B`），并选择最后一个 `W`。
     - **第二次操作**：选择第一个 `B` 和剩余的所有 `W`。

   这样构造的理由是：
   - 第一次操作移除了一部分 `B` 和一个 `W`，使得剩余卡片形成 `B...W...` 的形式（第一个 `B` 保留，后面是若干 `W`）；
   - 第二次操作可以安全地移除剩余的卡片。

### 算法步骤

对于每个测试用例：
$1$. 检查首字符是否为 `B`、尾字符是否为 `W`，若不是则输出 `IMPOSSIBLE`。
$2$. 检查是否前面全是 `B`、后面全是 `W`：
   - 找到第一个 `W` 的位置 `left`；
   - 找到最后一个 `B` 的位置 `right`（从后往前找第一个不是 `W` 的位置）；
   - 若 `left > right`，说明 `B` 和 `W` 没有交错，即全 `B` 后全 `W`，属于情况一。

$3$. 情况一：输出一次操作，选择所有卡片。
$4$. 情况二：输出两次操作，按上述构造方法输出索引。

### 时间复杂度

每个测试用例只需线性扫描字符串，时间复杂度 $O(n)$，空间复杂度 $O(n)$（用于存储操作序列）。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int T;
    cin >> T;
    while (T--) {
        string s;
        cin >> s;
        // 检查是否不可解
        if (s.front() != 'B' || s.back() != 'W') {
            cout << "IMPOSSIBLE\n";
            continue;
        }
        // 检查是否前面全是B，后面全是W
        bool allBThenAllW = true;
        int n = s.length();
        int left = 0, right = n - 1;
        while (s[left] == 'B') left++;
        while (s[right] == 'W') right--;
        // 一次操作
        if (left > right) {
            cout << "1\n" << n;
            for (int i = 1; i <= n; i++) cout << ' ' << i;
            cout << '\n';
            continue;
        }
        // 两次操作
        cout << "2\n";
        vector<int> op1;
        int lastW = n - 1;
        for (int i = 1; i < lastW; i++)
            if (s[i] == 'B')
                op1.push_back(i + 1);
        op1.push_back(n);
        cout << op1.size();
        for (int idx : op1) cout << ' ' << idx;
        cout << '\n';
        vector<int> op2;
        op2.push_back(1);
        for (int i = 1; i < n - 1; i++)
            if (s[i] == 'W')
                op2.push_back(i + 1);
        cout << op2.size();
        for (int idx : op2) cout << ' ' << idx;
        cout << '\n';
    }
    return 0;
}
```

## 样例分析

### 样例输入
```
2
BWBW
BWW
```

### 样例输出
```
2
2 1 2
2 3 4
1
3 1 2 3
```

**解释**：

$1$. 对于 `BWBW`：
   - 首字符 `B`，尾字符 `W`，可解；
   - 不是全 `B` 后全 `W`，需要两次操作；
   - 第一次操作选择索引 `1, 2`（第一个 `B` 以及第一个 `W`）；
   - 第二次操作选择索引 `3, 4`（第二个 `B` 和所有剩余的 `W`）。

$2$. 对于 `BWW`：
   - 首字符 `B`，尾字符 `W`，可解；
   - 前面全是 `B`（只有一个），后面全是 `W`，只需一次操作选择所有卡片。

本题的关键在于发现**可解的必要条件**（首 `B` 尾 `W`）以及**最优解的构造方法**。通过分类讨论，我们可以将问题简化为最多两次操作即可解决，从而避免了复杂的动态规划或贪心策略。代码实现简洁高效，适合在竞赛中快速编写并通过。
