## 题目大意

**$\texttt{Ripple Effect}$** 是一种在网格上进行的谜题。网格被划分为若干个 **多联骨牌**（由单位方格边相连构成的连通块）。每个格子需要填入一个正整数，满足：

1. 每个多联骨牌中，数字 $1$ 到该骨牌的格子数恰好出现一次。
2. 在同一行或同一列中，如果两个相同的数字 $k$ 出现，那么它们之间至少要有 $k$ 个其他数字的格子。

本题中，骨牌大小不超过 $8$，网格大小 $R, C$ 满足 $4 \le R, C \le 15$。

输入给出一个完整的填数结果，以及每个格子与四个方向相邻格子的连通信息（通过位掩码编码）。要求判断这个结果是否合法。

## 题目分析

题目包含三个核心部分：

- **根据连通信息重建多联骨牌**：每个格子与上、下、左、右的连通关系由 `descr` 矩阵给出，编码方式为：
  - 上：加 $1$
  - 右：加 $2$
  - 下：加 $4$
  - 左：加 $8$
  通过位与运算即可得知某方向是否连通。连通关系是双向的，利用并查集或 BFS 可得到所有连通分量，每个分量对应一个多联骨牌。

- **骨牌内部数字合法性检查**：每个骨牌的大小为 $s$，其中的数字必须是 $1$ 到 $s$ 的一个排列，不能多、不能少、不能重复。

- **行与列的间距约束检查**：对每一行和每一列，对每个数字 $k$，找到所有出现 $k$ 的列（或行）位置，检查相邻两个位置之间间隔的格子数是否 $\ge k$。如果两个相同数字之间只有少于 $k$ 个格子，则非法。

由于骨牌大小最大为 $8$，数字范围有限，行和列约束的检查可以暴力进行，复杂度足够。

## 解题思路

1. **读入数据**：先读 $T$，然后对每个测试用例读入 $R, C$，接着读入 $R$ 行字符串（填数结果），再读入 $R$ 行 $C$ 个整数（连通掩码）。

2. **建立并查集**：初始化每个格子为一个独立集合。遍历每个格子，根据 `descr` 的四个位，若某方向有连通，则将当前格子与相邻格子合并。

3. **收集连通分量**：遍历所有格子，找到每个格子的根节点，将格子坐标存入对应的分量列表中。

4. **检查每个骨牌**：
   - 获取该骨牌包含的格子数 $sz$。
   - 取出每个格子中的数字，排序后检查是否恰好为 $1, 2, \dots, sz$。
   - 若不符合，标记非法。

5. **检查行约束**：对每一行，对每个数字 $k$（$1$ 到 $8$），记录该数字出现的列下标，然后检查任意相邻两个列下标之间（不含这两个位置本身）的格子数是否 $\ge k$。

6. **检查列约束**：类似行检查，对每一列，对每个数字 $k$，记录出现的行下标，检查间隔。

7. **输出结果**：所有检查通过输出 `valid`，否则输出 `invalid`。

## 复杂度分析

- 并查集操作：$O(R \times C \times \alpha(R \times C))$，接近线性。
- 骨牌检查：每个格子参与一次，总格子数 $R \times C \le 225$，排序开销可忽略。
- 行和列约束检查：每行检查 $C \times 8$ 次比较，每列 $R \times 8$ 次比较，总复杂度 $O((R+C) \times \max(R,C) \times 8)$，非常小。

整体时间复杂度 $O(T \times R \times C)$，完全可行。

## 注意事项

- 连通信息是双向的，但输入只给了一次，需要在合并时双向处理（代码中通过检查掩码位来合并，并查集自动保证对称）。
- 行和列检查时，间隔是指 **中间格子的数量**，即位置差减 $1$。
- 数字 $k$ 的取值范围是 $1$ 到骨牌大小，但最大不超过 $8$，因此行列检查时遍历 $1$ 到 $8$ 即可。
- 题目保证骨牌大小不超过 $8$，但代码中也可以不依赖此限制做通用处理。

## 参考代码

```cpp
// Ripple Effect
// UVa ID: 12605
// Verdict: Accepted
// Submission Date: 2026-06-01
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 方向数组：上、右、下、左
const int dr[4] = {-1, 0, 1, 0};
const int dc[4] = {0, 1, 0, -1};
// 对应 descr 的位：UP=1, RIGHT=2, DOWN=4, LEFT=8
const int dirMask[4] = {1, 2, 4, 8};

void solve() {
    int T;
    cin >> T;
    while (T--) {
        int R, C;
        cin >> R >> C;
        
        vector<string> grid(R);
        for (int i = 0; i < R; ++i) 
            cin >> grid[i];
        
        vector<vector<int>> descr(R, vector<int>(C));
        for (int i = 0; i < R; ++i)
            for (int j = 0; j < C; ++j)
                cin >> descr[i][j];
        
        // 并查集：连通分量
        vector<int> parent(R * C);
        for (int i = 0; i < R * C; ++i) parent[i] = i;
        
        function<int(int)> find = [&](int x) -> int {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        };
        
        auto unite = [&](int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa != pb) parent[pa] = pb;
        };
        
        // 根据 descr 合并连通格子
        for (int r = 0; r < R; ++r) {
            for (int c = 0; c < C; ++c) {
                int val = descr[r][c];
                int idx = r * C + c;
                // 检查四个方向
                for (int d = 0; d < 4; ++d) {
                    if (val & dirMask[d]) { // 有连通
                        int nr = r + dr[d], nc = c + dc[d];
                        if (nr >= 0 && nr < R && nc >= 0 && nc < C) {
                            int nidx = nr * C + nc;
                            unite(idx, nidx);
                        }
                    }
                }
            }
        }
        
        // 收集每个连通分量的格子
        map<int, vector<pair<int, int>>> components;
        for (int r = 0; r < R; ++r) {
            for (int c = 0; c < C; ++c) {
                int root = find(r * C + c);
                components[root].emplace_back(r, c);
            }
        }
        
        bool valid = true;
        
        // 检查每个多联骨牌
        for (auto& [root, cells] : components) {
            int sz = cells.size();
            vector<int> nums;
            for (auto& [r, c] : cells) {
                nums.push_back(grid[r][c] - '0');
            }
            sort(nums.begin(), nums.end());
            // 检查是否是 1..sz 的排列
            for (int i = 0; i < sz; ++i) {
                if (nums[i] != i + 1) { valid = false; break; }
            }
            if (!valid) break;
        }
        
        if (!valid) {
            cout << "invalid\n";
            continue;
        }
        
        // 检查行约束
        for (int r = 0; r < R; ++r) {
            // 对每个数字 1..8
            for (int num = 1; num <= 8; ++num) {
                vector<int> cols;
                for (int c = 0; c < C; ++c) {
                    if (grid[r][c] - '0' == num)
                        cols.push_back(c);
                }
                // 检查间隔
                for (size_t i = 1; i < cols.size(); ++i) {
                    int gap = cols[i] - cols[i - 1] - 1;
                    if (gap < num) { valid = false; break; }
                }
                if (!valid) break;
            }
            if (!valid) break;
        }
        
        if (!valid) {
            cout << "invalid\n";
            continue;
        }
        
        // 检查列约束
        for (int c = 0; c < C; ++c) {
            for (int num = 1; num <= 8; ++num) {
                vector<int> rows;
                for (int r = 0; r < R; ++r) {
                    if (grid[r][c] - '0' == num)
                        rows.push_back(r);
                }
                for (size_t i = 1; i < rows.size(); ++i) {
                    int gap = rows[i] - rows[i - 1] - 1;
                    if (gap < num) { valid = false; break; }
                }
                if (!valid) break;
            }
            if (!valid) break;
        }
        
        cout << (valid ? "valid" : "invalid") << "\n";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```
