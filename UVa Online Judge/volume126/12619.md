## 题目描述

你有一个朋友 $\texttt{Po}$ ，他有一个神奇的精灵。精灵每天会告诉 $\texttt{Po}$ 一个整数 $G$ 。如果 $G$ 为正数，那么 $\texttt{Po}$ 的土地面积会乘以 $G$ ；如果 $G$ 为负数，那么 $\texttt{Po}$ 的土地面积会除以 $|G|$ （保证能整除）。初始土地面积为 $1$ 。每天，你需要计算出当前土地面积对应的“不同矩形”的数量，即面积的正整数因子个数（因为矩形边长必须是正整数，且 $a \times b$ 与 $b \times a$ 视为不同，除非 $a = b$ ）。在 $D$ 天结束后，输出每天因子个数的总和，并对 $10^9+7$ 取模。

**输入格式**
- 第一行是测试用例数 $T$ （ $T \le 10$ ）。
- 每个测试用例第一行是天数 $D$ （ $1 \le D \le 10^6$ ）。
- 接下来 $D$ 行，每行一个整数 $G$ （ $0 < |G| \le 10^6$ ）。

**输出格式**
- 对于每个测试用例，输出一行 `Case X: sum` ，其中 $X$ 是测试用例编号， $sum$ 是 $D$ 天因子个数总和对 $10^9+7$ 取模的结果。

## 题目分析

### 问题转化

每天我们需要计算当前面积 $A$ 的正整数因子个数。  
设 $A$ 的质因数分解为：
$$
A = p_1^{e_1} p_2^{e_2} \dots p_k^{e_k}
$$
则 $A$ 的因子个数为：
$$
\texttt{div\_count}(A) = \prod_{i=1}^k (e_i + 1)
$$
因为每个质因子 $p_i$ 的指数可以从 $0$ 到 $e_i$ 选择，共有 $e_i+1$ 种选择，组合起来就是乘积。

### 动态维护

如果我们每天重新分解 $A$ ，复杂度会非常高（因为 $A$ 可能极大）。  
注意到每天 $A$ 只会乘以或除以一个数 $|G|$ ，我们可以动态维护 $A$ 的质因数分解（即每个质因子的指数），并相应地更新因子个数。

#### 更新方法
- 当乘以 $x$ 时，对 $x$ 分解质因数，对于每个质因子 $p$ 及其指数 $e$ ：
  - 设 $p$ 原来的指数为 $old\_exp$ ，新的指数 $new\_exp = old\_exp + e$ 。
  - 因子个数需要乘以 $\frac{new\_exp+1}{old\_exp+1}$ 。
- 当除以 $x$ 时，对 $x$ 分解质因数，对于每个质因子 $p$ 及其指数 $e$ ：
  - 设 $p$ 原来的指数为 $old\_exp$ ，新的指数 $new\_exp = old\_exp - e$ 。
  - 因子个数需要乘以 $\frac{new\_exp+1}{old\_exp+1}$ 。

由于我们需要对 $10^9+7$ 取模，而模数是质数，因此可以用模逆元来处理除法。

### 算法步骤

1. **预处理**
   - 使用线性筛法求出每个数的最小质因子（ $\texttt{Least Prime Factor, LPF }$），以便快速分解 $|G|$ 。
   - 预处理 $1$ 到 $2\times 10^6$ 的模逆元（因为指数可能很大，但指数不会超过 $2\times 10^6$ ）。

2. **对每个测试用例**
   - 初始化一个哈希表 `expMap` 存储当前面积的质因子指数，初始为空（面积 $1$ 时所有指数为 $0$ ）。
   - 初始化因子个数 `divCount = 1` （ $1$ 的因子个数为 $1$ ）。
   - 初始化总和 `sumWays = 0` 。
   - 对于每一天的 $G$ ：
     - 计算 $val = |G|$ 。
     - 使用 LPF 快速分解 $val$ 。
     - 根据 $G$ 的正负，更新 `expMap` 和 `divCount` 。
     - 将当天的 `divCount` 累加到 `sumWays` （取模）。
   - 输出结果。

### 复杂度分析

- 预处理 $\texttt{LPF}$ 和逆元： $O(MAX \log \log MAX)$ ，其中 $MAX = 2\times 10^6$ 。
- 每天分解 $|G|$ ： $O(\log |G|)$ 。
- 总复杂度： $O(T \cdot D \cdot \log |G|)$ ，在 $D \le 10^6$ 时可接受。

## 代码实现

```cpp
// Just Make A Wish
// UVa ID: 12619

// Submission Date: 2025-12-17
// UVa Run Time: 0.200s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long LL;
const int MAX = 2000005; // 足够大，因为 G 最大 1e6，但面积质因子可能更大
const LL MOD = 1000000007LL;

vector<int> lpf; // 最小质因子 Least Prime Factor
vector<LL> inv; // 模逆元

// 快速幂取模
LL modPow(LL a, LL b) {
    LL res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

// 预处理最小质因子和逆元
void init() {
    lpf.resize(MAX, 0);
    inv.resize(MAX, 0);
    for (int i = 2; i < MAX; i++) {
        if (lpf[i] == 0) { // i 是质数
            lpf[i] = i;
            for (int j = i + i; j < MAX; j += i) {
                if (lpf[j] == 0) lpf[j] = i;
            }
        }
    }
    // 预处理逆元： inv[x] = x^(-1) mod MOD
    for (int i = 1; i < MAX; i++) inv[i] = modPow(i, MOD - 2);
}

// 分解 x，返回质因子-指数的映射
vector<pair<int, int>> factorize(int x) {
    vector<pair<int, int>> res;
    while (x > 1) {
        int p = lpf[x];
        int cnt = 0;
        while (x % p == 0) {
            x /= p;
            cnt++;
        }
        res.push_back({p, cnt});
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init(); // 预处理

    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; caseNo++) {
        int D;
        cin >> D;

        unordered_map<int, int> expMap; // 当前面积的质因子指数
        LL divCount = 1; // 当前面积的因子个数
        LL sumWays = 0;

        for (int day = 0; day < D; day++) {
            int G;
            cin >> G;
            int val = abs(G);
            vector<pair<int, int>> factors = factorize(val);

            if (G > 0) { // 乘以 val
                for (auto &pf : factors) {
                    int p = pf.first, e = pf.second;
                    int oldExp = expMap[p];
                    int newExp = oldExp + e;
                    // 更新因子个数：除以(oldExp+1)，乘以(newExp+1)
                    divCount = divCount * inv[oldExp + 1] % MOD;
                    divCount = divCount * (newExp + 1) % MOD;
                    expMap[p] = newExp;
                }
            } else { // 除以 val
                for (auto &pf : factors) {
                    int p = pf.first, e = pf.second;
                    int oldExp = expMap[p];
                    int newExp = oldExp - e;
                    divCount = divCount * inv[oldExp + 1] % MOD;
                    divCount = divCount * (newExp + 1) % MOD;
                    expMap[p] = newExp;
                }
            }

            sumWays = (sumWays + divCount) % MOD;
        }

        cout << "Case " << caseNo << ": " << sumWays << "\n";
    }

    return 0;
}
```

## 关键点总结

1. **因子个数的公式**： $\prod (e_i + 1)$ 。
2. **动态维护**：通过维护质因子指数，避免对大数直接分解。
3. **模逆元**：因为模数是质数，可以用费马小定理求逆元，从而在模意义下做除法。
4. **预处理 $\texttt{LPF}$**：快速分解 $|G|$ ，是算法高效的关键。

这样，即使 $D$ 高达 $10^6$ ，算法也能在合理时间内运行完毕。
