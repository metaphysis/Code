## 题目分析

### 问题描述

$\texttt{Piotr}$ 发现了一个神奇的盒子，其魔法规则如下：
- 初始时（第 $0$ 小时）盒子中有 $1$ 个红气球
- 每个红气球经过 $1$ 小时会繁殖成：
  - $3$ 个红气球（位于左上、右上、左下位置）
  - $1$ 个蓝气球（位于右下位置）
- 每个蓝气球经过 $1$ 小时会繁殖成：
  - $4$ 个蓝气球（位于左上、右上、左下、右下位置）

网格大小每小时翻倍（长宽都 $\times 2$），以容纳新增的气球。

题目要求：在第 $K$ 小时，统计从第 $A$ 行到第 $B$ 行中红气球的总数。

### 关键观察

#### 1. 红气球总数的递推关系

设 $R(K)$ 表示第 $K$ 小时整个网格中的红气球总数。

- 初始条件：$R(0) = 1$
- 递推关系：$R(K) = 3 \times R(K-1)$

推导过程：
- 每个红气球繁殖产生 $3$ 个新的红气球
- 蓝气球繁殖只产生蓝气球，不会产生新的红气球

因此：
$$R(K) = 3^K$$

#### 2. 部分行红气球数的计算

我们需要计算从第 $A$ 行到第 $B$ 行的红气球数，这可以转化为：
$$\text{答案} = F(K, B) - F(K, A-1)$$

其中 $F(K, r)$ 表示第 $K$ 小时前 $r$ 行的红气球总数。

#### 3. 递归计算 $F(K, r)$

第 $K$ 小时的网格可以看作由 $4$ 个第 $K-1$ 小时的网格组成：

```
[左上] [右上]
[左下] [右下]
```

其中：
- 左上、右上、左下：由红气球繁殖而来（红气球网格）
- 右下：由蓝气球繁殖而来（蓝气球网格，红气球数为 $0$）

每个小网格的大小为 $2^{K-1} \times 2^{K-1}$。

递归计算规则：
- 如果 $r \leq 2^{K-1}$（只在上半部分）：
  $$F(K, r) = 2 \times F(K-1, r)$$
  因为上半部分包含左上和右上两个红气球网格的前 $r$ 行
- 如果 $r > 2^{K-1}$（跨越上下两部分）：
  $$F(K, r) = 2 \times R(K-1) + F(K-1, r - 2^{K-1})$$
  其中：
  - $2 \times R(K-1)$：上半部分（左上+右上）的总红气球数
  - $F(K-1, r - 2^{K-1})$：下半部分前 $r - 2^{K-1}$ 行中，左下网格的红气球数（右下网格红气球数为 $0$）

边界条件：
- $F(0, 0) = 0$
- $F(0, 1) = 1$（第 $0$ 小时只有 $1$ 行 $1$ 个红气球）

### 算法复杂度

- 递归深度最多为 $K \leq 30$
- 状态数为 $O(K^2)$ 级别（因为 $r$ 在递归中不断折半）
- 每次递归计算时间为 $O(1)$
- 总体复杂度对于题目约束非常高效

## 代码实现

```cpp
// Erratic Expansion
// UVa ID: 12627
// Verdict: Accepted

//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <cstring>
#include <map>
using namespace std;

map<pair<int, int>, long long> memo; // 记忆化存储

long long R(int K) {
    // 计算第K小时整个网格的红气球总数
    static long long pow3[31]; // 预计算3的幂次
    if (pow3[0] == 0) {
        pow3[0] = 1;
        for (int i = 1; i <= 30; i++)
            pow3[i] = pow3[i-1] * 3;
    }
    return pow3[K];
}

long long F(int K, int r) {
    if (r == 0) return 0; // 前0行没有气球
    if (K == 0) return 1; // 第0小时只有1行1个红气球
    if (memo.count({K, r})) return memo[{K, r}]; // 记忆化
    
    int half = 1 << (K-1); // 2^(K-1)
    long long res;
    
    if (r <= half) {
        // 只在上半部分
        res = 2 * F(K-1, r);
    } else {
        // 跨越上下两部分
        res = 2 * R(K-1) + F(K-1, r - half);
    }
    
    memo[{K, r}] = res; // 存储结果
    return res;
}

int main() {
    int T;
    cin >> T;
    for (int t = 1; t <= T; t++) {
        int K, A, B;
        cin >> K >> A >> B;
        long long ans = F(K, B) - F(K, A-1); // 计算[A,B]行的红气球数
        cout << "Case " << t << ": " << ans << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于发现红气球繁殖的规律性和网格的递归结构。通过定义 $F(K, r)$ 表示前 $r$ 行的红气球数，并利用递归分治的思想，可以高效地计算出任意行区间的红气球数量。记忆化技术的使用避免了重复计算，确保了算法的高效性。

这种递归分治的方法在解决类似具有自相似结构的问题时非常有效，是算法竞赛中的常用技巧。
