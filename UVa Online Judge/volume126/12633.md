## 题目描述

假设有一种新的棋子叫做“超级车” 。当它放在棋格的某一格时，它会攻击 **同一行** 或 **同一列** 的所有格子。此外，它还会攻击 **从左上到右下** 方向穿过该格子的 **整条对角线** 上的所有格子。

现在有 $N$ 个超级车被放在一个 $R \times C$ 的棋盘上。行从上到下编号为 $1$ 到 $R$ ，列从左到右编号为 $1$ 到 $C$ 。你需要找出棋盘上 **没有被任何超级车攻击** 的格子数量。

**输入格式**  
第一行包含一个整数 $T$ （ $1 \leq T \leq 20$ ），表示测试用例的数量。  
每个测试用例的第一行包含三个整数 $R$ , $C$ 和 $N$ （ $1 \leq R, C, N \leq 50,000$ ）。  
接下来的 $N$ 行每行包含两个整数 $r$ , $c$ ，表示一个超级车所在的行和列（ $1 \leq r \leq R$ ， $1 \leq c \leq C$ ）。  
你可以假设两个超级车不会放在同一个格子。

**输出格式**  
对于每个测试用例，输出用例编号，后接 **没有被任何超级车攻击** 的格子数量。

## 题目分析

### 攻击范围分析

超级车的攻击范围包括：

1. **整行**：所在行的所有格子。
2. **整列**：所在列的所有格子。
3. **整条主对角线**：从左上到右下方向，即满足 $r - c$ 为常数的所有格子。

我们需要计算棋盘上 **完全不在任何攻击范围** 内的格子数量。

### 问题转化

一个格子 $(r, c)$ 被攻击当且仅当满足以下至少一个条件：

- 行 $r$ 上有车（即该行被占用）。
- 列 $c$ 上有车。
- 对角线 $d = r - c$ 上有车（即该对角线上至少有一个车）。

因此，一个格子 **安全** （未被攻击）的条件是：

1. 行 $r$ 上没有车。
2. 列 $c$ 上没有车。
3. 对角线 $d = r - c$ 上没有车。

设：

- $A$ = 未被占用的行集合（行上没有车）。
- $B$ = 未被占用的列集合（列上没有车）。
- $D$ = 未被占用的对角线集合（对角线上没有车）。

则安全格子数等于满足 $r \in A$ , $c \in B$ 且 $d = r - c \in D$ 的格子 $(r, c)$ 的数量。

### 直接枚举的不可行性

最直接的想法是枚举所有 $r \in A$ 和 $c \in B$ ，检查 $r - c$ 是否属于 $D$ 。但 $|A|$ 和 $|B|$ 最大可达 $50,000$ ，乘积为 $2.5 \times 10^9$ ，显然会超时。

### 卷积思路

我们需要计算：

$$
\text{安全格子数} = \sum_{r \in A} \sum_{c \in B} [r - c \in D]
$$

其中 $[P]$ 表示条件 $P$ 成立时为 $1$ ，否则为 $0$ 。

定义两个数组：

- $x[r] = 1$ 如果行 $r$ 未被占用，否则 $0$ 。（ $r = 1 \dots R$ ）
- $y[c] = 1$ 如果列 $c$ 未被占用，否则 $0$ 。（ $c = 1 \dots C$ ）

则上述求和式可以写为：

$$
\text{安全格子数} = \sum_{d \in D} \sum_{r=1}^{R} x[r] \cdot y[r - d]
$$

其中内层求和 $\sum_{r} x[r] \cdot y[r - d]$ 正是 **卷积** 的形式。具体来说，对于每个差值 $d$ ，我们希望计算有多少对 $(r, c)$ 满足 $r - c = d$ 且 $x[r] = y[c] = 1$ 。

### 卷积的计算

设多项式：

$$
P(t) = \sum_{r=1}^{R} x[r] \cdot t^{r}
\\
Q(t) = \sum_{c=1}^{C} y[c] \cdot t^{c}
$$

则乘积 $P(t) \cdot Q(t)$ 中 $t^{k}$ 的系数为：

$$
\sum_{r+c = k} x[r] \cdot y[c]
$$

但我们需要的是 $r - c = d$ ，而不是 $r + c = k$ 。为了得到减法，我们可以将 $Q$ 中的列索引反转。定义：

$$
Q'(t) = \sum_{c=1}^{C} y[c] \cdot t^{C-c+1}
$$

则 $P(t) \cdot Q'(t)$ 中 $t^{k}$ 的系数为：

$$
\sum_{r + (C-c+1) = k} x[r] \cdot y[c] = \sum_{r - c = k - (C+1)} x[r] \cdot y[c]
$$

因此，对于差值 $d = r - c$ ，对应的卷积系数在索引 $k = d + (C+1)$ 处。

### 算法步骤

1. 读入 $R, C, N$ 。
2. 初始化标记数组：
   - `rowUsed[r]` 表示行 $r$ 是否有车。
   - `colUsed[c]` 表示列 $c$ 是否有车。
   - `diagUsed[d + SHIFT]` 表示对角线 $d = r - c$ 是否有车（使用偏移 `SHIFT` 使下标非负）。
3. 读入 $N$ 个车的坐标，更新标记数组。
4. 构建多项式系数数组：
   - $P$ ：长度为 $R+1$ ， $P[r] = 1$ 如果行 $r$ 未被占用，否则 $0$ 。
   - $Q$ ：长度为 $C+1$ ， $Q[c] = 1$ 如果列 $c$ 未被占用，否则 $0$ 。
5. 反转 $Q$ 得到 $Q'$ ： $Q'[c] = Q[C-c+1]$ 。
6. 使用 **$\texttt{FFT}$** 计算卷积 $conv = P * Q'$ 。
7. 对于每个可能的差值 $d$ （从 $-(C-1)$ 到 $R-1$ ）：
   - 计算卷积中的索引 $k = d + (C+1)$ 。
   - 如果对角线 $d$ 未被占用（即 `diagUsed[d + SHIFT] == false` ），则将 $conv[k]$ 加入安全格子数。
8. 输出结果。

### 复杂度分析

- 标记数组： $O(N)$ 。
- 构建多项式： $O(R + C)$ 。
- $\texttt{FFT}$ 卷积： $O((R+C) \log (R+C))$ 。
- 遍历差值： $O(R + C)$ 。

总复杂度为 $O((R+C) \log (R+C) + N)$ ，对于 $R, C, N \leq 50,000$ 完全可行。

### 边界情况

- 对角线差值 $d = r - c$ 的范围是 $[-(C-1), R-1]$ 。
- 卷积结果数组长度可能超过 $R+C$ ，需要确保索引在范围内。
- 使用偏移量 `SHIFT = 50000` 使对角线下标非负，避免负数索引。

### 示例验证

以样例输入为例：

```
2
6 6 1
5 3
6 6 3
3 4
5 3
5 6
```

第一个测试用例：
- 未被占行： $1,2,3,4,6$ （行 $5$ 被占）。
- 未被占列： $1,2,4,5,6$ （列 $3$ 被占）。
- 未被占对角线：除 $d = 5-3 = 2$ 外，其余对角线均未被占。
通过卷积计算满足条件的 $(r,c)$ 对，得到 $22$ 个安全格子。

第二个测试用例类似，得到 $9$ 个安全格子。

## 代码实现

```cpp
// Super Rooks on a Chessboard
// UVa ID: 12633
// Verdict: Accepted
// Submission Date: 2026-01-02
// UVa Run Time: 0.180s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef complex<double> Complex;
const double PI = acos(-1.0);

// 快速傅里叶变换
void FFT(vector<Complex>& a, bool invert) {
    int n = a.size();
    for (int i = 1, j = 0; i < n; ++i) {
        int bit = n >> 1;
        for (; j & bit; bit >>= 1) j ^= bit;
        j ^= bit;
        if (i < j) swap(a[i], a[j]);
    }
    for (int len = 2; len <= n; len <<= 1) {
        double ang = 2 * PI / len * (invert ? -1 : 1);
        Complex wlen(cos(ang), sin(ang));
        for (int i = 0; i < n; i += len) {
            Complex w(1);
            for (int j = 0; j < len / 2; ++j) {
                Complex u = a[i + j];
                Complex v = a[i + j + len / 2] * w;
                a[i + j] = u + v;
                a[i + j + len / 2] = u - v;
                w *= wlen;
            }
        }
    }
    if (invert) for (Complex& x : a) x /= n;
}

// 多项式乘法（卷积）
vector<long long> multiply(const vector<int>& a, const vector<int>& b) {
    int n = 1;
    while (n < a.size() + b.size()) n <<= 1;
    vector<Complex> fa(n), fb(n);
    for (int i = 0; i < a.size(); ++i) fa[i] = a[i];
    for (int i = 0; i < b.size(); ++i) fb[i] = b[i];
    FFT(fa, false);
    FFT(fb, false);
    for (int i = 0; i < n; ++i) fa[i] *= fb[i];
    FFT(fa, true);
    vector<long long> result(n);
    for (int i = 0; i < n; ++i) result[i] = llround(fa[i].real());
    return result;
}

const int MAXRC = 50000;
const int SHIFT = MAXRC; // 对角线差值偏移量，使下标非负

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        int R, C, N;
        cin >> R >> C >> N;
        
        // 标记数组
        vector<bool> rowUsed(R + 1, false);
        vector<bool> colUsed(C + 1, false);
        vector<bool> diagUsed(2 * MAXRC + 5, false); // 对角线 d = r-c，偏移后索引 d+SHIFT
        
        for (int i = 0; i < N; ++i) {
            int r, c;
            cin >> r >> c;
            rowUsed[r] = true;
            colUsed[c] = true;
            int d = r - c;
            diagUsed[d + SHIFT] = true;
        }
        
        // 构建多项式 P 和 Q
        // P 对应行：P[r] = 1 如果行 r 未被占用
        // Q 对应列：Q[c] = 1 如果列 c 未被占用
        vector<int> P(R + 1, 0), Q(C + 1, 0);
        for (int r = 1; r <= R; ++r) if (!rowUsed[r]) P[r] = 1;
        for (int c = 1; c <= C; ++c) if (!colUsed[c]) Q[c] = 1;
        
        // 反转 Q 以便卷积计算差值
        vector<int> Qrev(C + 1, 0);
        for (int c = 1; c <= C; ++c) Qrev[c] = Q[C - c + 1];
        
        // 卷积 P * Qrev
        vector<long long> conv = multiply(P, Qrev);
        
        // 计算安全格子数
        long long safeCells = 0;
        int offset = C + 1; // 卷积索引偏移量
        for (int d = -(C - 1); d <= R - 1; ++d) {
            int k = d + offset; // 卷积中的索引
            if (k < 0 || k >= conv.size()) continue;
            if (!diagUsed[d + SHIFT]) {
                safeCells += conv[k];
            }
        }
        
        cout << "Case " << caseNo << ": " << safeCells << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于将安全格子的计数问题转化为卷积计算，从而利用 $\texttt{FFT}$ 在 $O((R+C) \log (R+C))$ 时间内求解。传统的枚举方法会超时，而卷积方法能够高效处理最大规模的数据。通过构造适当的多项式并利用 $\texttt{FFT}$ 加速卷积，我们可以在时限内得到正确答案。
