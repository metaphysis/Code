## 题目描述

$\texttt{Technopark}$ 是一个大型工业园，周围环绕着一些小居民镇，居民主要是园区工人。  
$\texttt{Technopark}$ 拥有一座水坝，可以为园区设施和一些居民镇提供电力和清洁饮用水。  
其他镇则从井中取水。

最近，一些工人及其家人患上了一种由某些井中细菌引起的疾病，因此决定扩建供水网络，  
将来自 $\texttt{Technopark}$ 水坝的水送到所有居民镇。  有些镇之间已经存在一些管道，但可能需要额外铺设管道。  管道是**有向**的，即它们只允许水沿一个方向流动，每条管道恰好连接两个镇。

你的任务是计算**最少需要铺设多少条新管道**，才能让水坝的水送到**所有居民镇**。

---

## 输入格式

输入包含多个测试用例。  
每个测试用例的第一行有两个空格分隔的整数 $N$ 和 $M$：  
- $N$ 是居民镇的数量（$1 \leq N \leq 1000$）  
- $M$ 是已有管道的数量（$0 \leq M \leq 100000$）  
镇编号从 $0$ 到 $N$，其中 Technopark 是 $0$ 号镇。  
接下来的 $M$ 行，每行包含两个空格分隔的整数 $a$ 和 $b$（$0 \leq a \leq N, 0 \leq b \leq N$），  
表示有一条从镇 $a$ 到镇 $b$ 的管道。

---

## 输出格式

对每个测试用例，输出需要建造的最少管道数量。

---

## 样例输入

```
4 5
0 1
1 2
2 1
0 4
3 4
4 2
3 1
2 1
```

---

## 样例输出

```
1
3
```

## 题目分析

### 问题抽象

我们有一个有向图，节点 $0$ 是水源（$\texttt{Technopark}$），节点 $1$ 到 $N$ 是居民镇。  
现有 $M$ 条有向边（管道）。  
目标：从节点 $0$ 出发能到达所有节点（$1$ 到 $N$）。  
可以添加新的有向边（从任意节点到任意节点）。  
问最少添加多少条边。

---

### 关键观察

1. **强连通分量（$\texttt{SCC}$）**：  
   有向图中，强连通分量内的节点互相可达。  
   如果水源能到达某个 $\texttt{SCC}$ 中的一个节点，那么该 $\texttt{SCC}$ 中所有节点都能获得水。

2. **缩点成 $\texttt{DAG}$**：  
   将原图进行 $\texttt{SCC}$ 缩点后，得到一个有向无环图（$\texttt{DAG}$）。  
   在这个 $\texttt{DAG}$ 中，除了包含水源 $0$ 的 $\texttt{SCC}$ 外，  
   其他**入度为 $0$ 的 $\texttt{SCC}$** 都需要至少一条来自外部（已供水部分）的入边，才能获得水。

3. **最少加边数**：  
   因此，答案就是**在缩点后的 $\texttt{DAG}$ 中，除了水源 $\texttt{SCC}$ 外，入度为 $0$ 的 $\texttt{SCC}$ 的数量**。

---

### 算法步骤

1. 使用 **$\texttt{Kosaraju}$ 算法** 或 $\texttt{Tarjan}$ 算法求出所有 $\texttt{SCC}$。
2. 对每个 $\texttt{SCC}$ 编号，并标记哪个 $\texttt{SCC}$ 包含节点 $0$。
3. 建立 $\texttt{SCC}$ 之间的边（即 $\texttt{DAG}$ 的边），并统计每个 $\texttt{SCC}$ 的入度。
4. 统计除了水源 $\texttt{SCC}$ 外，入度为 $0$ 的 $\texttt{SCC}$ 数量，即为答案。

---

### 复杂度分析

- 图节点数 $N \leq 1000$，边数 $M \leq 100000$。
- $\texttt{Kosaraju}$ 算法时间复杂度为 $O(N + M)$，可以接受。

## 代码实现

```cpp
// Water Supply
// UVa ID: 12645

// Submission Date: 2025-11-13
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <algorithm>
#include <stack>
#include <cstring>

using namespace std;

const int MAXN = 1005;

vector<int> graph[MAXN];
vector<int> reverseGraph[MAXN];
bool visited[MAXN];
int comp[MAXN];
int inDegreeComp[MAXN];
bool sourceComp[MAXN];
int compCount;

void dfsOrder(int u, vector<int>& order) {
    visited[u] = true;
    for (int v : graph[u]) {
        if (!visited[v]) {
            dfsOrder(v, order);
        }
    }
    order.push_back(u);
}

void dfsScc(int u, int id) {
    comp[u] = id;
    if (u == 0) {
        sourceComp[id] = true;
    }
    for (int v : reverseGraph[u]) {
        if (comp[v] == -1) {
            dfsScc(v, id);
        }
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    while (cin >> N >> M) {
        // 初始化
        for (int i = 0; i <= N; i++) {
            graph[i].clear();
            reverseGraph[i].clear();
        }
        memset(visited, false, sizeof(visited));
        memset(comp, -1, sizeof(comp));
        memset(inDegreeComp, 0, sizeof(inDegreeComp));
        memset(sourceComp, false, sizeof(sourceComp));
        compCount = 0;

        // 建图
        for (int i = 0; i < M; i++) {
            int a, b;
            cin >> a >> b;
            graph[a].push_back(b);
            reverseGraph[b].push_back(a);
        }

        // Kosaraju算法第一步：在原图DFS得到完成顺序
        vector<int> order;
        for (int i = 0; i <= N; i++) {
            if (!visited[i]) {
                dfsOrder(i, order);
            }
        }

        // Kosaraju算法第二步：在反图按逆序DFS找SCC
        for (int i = order.size() - 1; i >= 0; i--) {
            int u = order[i];
            if (comp[u] == -1) {
                dfsScc(u, compCount);
                compCount++;
            }
        }

        // 计算SCC之间的边，统计入度
        for (int u = 0; u <= N; u++) {
            for (int v : graph[u]) {
                if (comp[u] != comp[v]) {
                    inDegreeComp[comp[v]]++;
                }
            }
        }

        // 统计除了包含水源的SCC外，其他入度为0的SCC数量
        int result = 0;
        for (int i = 0; i < compCount; i++) {
            if (!sourceComp[i] && inDegreeComp[i] == 0) {
                result++;
            }
        }

        cout << result << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于将原图缩点为 $\texttt{DAG}$，并利用 $\texttt{DAG}$ 中入度为 $0$ 的 $\texttt{SCC}$ 必须获得外部水源这一性质，  统计需要新建的管道数量。  使用 $\texttt{Kosaraju}$ 算法可以高效地完成 $\texttt{SCC}$ 分解，  最终算法的时间复杂度为 $O(N + M)$，适合本题的数据范围。
