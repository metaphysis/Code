## 题目描述

$\texttt{Nlogonia}$ 的主要出口产品 $\texttt{Nlogs}$ 装在港口的集装箱中准备运出。所有集装箱尺寸相同，均为立方体。集装箱在货运站按 $L$ 行 $C$ 列排列，总计 $L \times C$ 个集装箱。每个集装箱标有唯一的识别号，从 $1$ 到 $L \times C$ 。

每行集装箱将装入不同的船只。为方便目的国卸货，每行集装箱必须按识别号顺序排列：第一行包含编号 $1$ 到 $C$ 的集装箱（升序），第二行包含编号 $C+1$ 到 $2C$ 的集装箱（升序），依此类推，最后一行包含编号 $(L-1)C+1$ 到 $LC$ 的集装箱（升序）。

起重机只能移动**整行**或**整列**的集装箱。在装货前一天晚上，工人为抗议低薪操作起重机交换了一些行和列。给定抗议后每个集装箱的位置信息，判断是否**仅用起重机**就能将每个集装箱放回正确位置。如果可行，计算所需的最少行交换和列交换次数。

### 输入格式

输入包含多个测试用例。每个测试用例第一行包含两个整数 $L$  ͏和 $C$  ，分别表示行数和列数。接下来 $L$ 行显示抗议后的集装箱配置，每行包含 $C$ 个整数 $X_{l,c}$ ，表示集装箱编号。 $1$ 到 $LC$ 之间的每个整数在输入中恰好出现一次。

### 输出格式

对于每个测试用例，输出一行一个整数，表示恢复原始位置所需的最少行交换和列交换次数。如果无法仅用起重机完成恢复，则输出一个星号 `*` 。

### 限制条件

- $1 \leq L \leq 300$
- $1 \leq C \leq 300$
- $1 \leq X_{l,c} \leq LC$

### 样例输入

```
2 2
3 4
1 2
3 3
9 2 4
5 8 7
6 1 3
5 4
13 15 14 16
5 7 6 8
9 11 10 12
1 3 2 4
17 19 18 20
```

### 样例输出

```
1
*
2
```

## 题目分析

本题的核心在于理解起重机操作的特性：只能整行或整列交换。这意味着：

1. **行操作**：交换两行时，每行内部的**相对顺序**保持不变。
2. **列操作**：交换两列时，每列内部的**相对顺序**保持不变。

由此我们可以得出两个重要性质：

### 性质 1：行的特征
原始矩阵中，每行包含 $C$ 个连续的整数，且该行最小值为 $k \times C + 1$ 的形式（其中 $k$ 是从 $0$ 编号的行号）。经过任意次行、列交换后，每一行仍然必须保持这个特征：该行数字集合必须是连续的 $C$ 个整数，且最小值模 $C$ 余 $1$ （以 $1$ 开始编号计算）。

### 性质 2：列的特征
原始矩阵中，每列的数字对 $C$ 取模的结果相同（考虑 $1$ 开始编号时，结果为 $1, 2, \dots, C$ 中的一个）。经过交换后，每一列仍然必须保持这个特征：该列所有数字对 $C$ 取模的结果必须相等。

### 可行性判断

基于上述性质，我们可以通过以下步骤判断是否能够恢复原始排列：

1. **检查每一行**：
   - 找到该行的最小值 $minVal$ 。
   - 检查 $(minVal - 1) \mod C == 0$ ，即最小值必须是 $k \times C + 1$ 的形式。
   - 计算该行对应的原始行号 $rowId = (minVal - 1) / C$ （$0$ 开始编号）。
   - 验证该行是否包含连续的 $C$ 个整数：排序后检查是否为 $\{base, base+1, \dots, base+C-1\}$ ，其中 $base = minVal$ 。

2. **检查行号集合**：
   - 所有行的 $rowId$ 必须恰好是集合 $\{0, 1, \dots, L-1\}$ 的一个排列。

3. **检查每一列**：
   - 取该列第一个元素 $val$ （可以是任意元素，通常取第一行元素）。
   - 计算模值 $modVal = (val - 1) \mod C$ （$0$ 开始编号）。
   - 验证该列所有元素是否都满足 $(x - 1) \mod C == modVal$ 。
   - 记录 $colId[j] = modVal$ 。

4. **检查列模值集合**：
   - 所有列的 $colId$ 必须恰好是集合 $\{0, 1, \dots, C-1\}$ 的一个排列。

5. **整体验证公式**：
   - 对于任意位置 $(i, j)$ ，必须满足： $grid[i][j] == rowId[i] \times C + colId[j] + 1$ （其中 $+1$ 是因为编号从 $1$ 开始）。

如果以上任何一步失败，则无法通过仅交换整行/整列恢复到原始排列，输出 `*` 。

### 最少交换次数计算

如果恢复可行，问题转化为两个独立的排序问题：

1. **行交换次数**：将 $rowId$ 数组通过**相邻交换**排序为 $[0, 1, \dots, L-1]$ 的最少次数。
2. **列交换次数**：将 $colId$ 数组通过**相邻交换**排序为 $[0, 1, \dots, C-1]$ 的最少次数。

计算最少相邻交换次数可以通过模拟**选择排序**过程实现：对于位置 $i$ ，如果当前元素不是 $i$ ，则找到值为 $i$ 的位置 $pos$ ，交换 $arr[i]$ 和 $arr[pos]$ ，计数一次。由于每次交换都是相邻的（通过相邻交换实现任意两个元素的交换需要多次操作，但这里我们实际上是在模拟冒泡排序的过程），这种方法得到的就是最少相邻交换次数。

总最少交换次数为行交换次数与列交换次数之和。

## 算法复杂度分析

- 检查每行： $O(L \times C)$
- 检查每列： $O(L \times C)$
- 整体验证： $O(L \times C)$
- 计算行交换次数： $O(L^2)$
- 计算列交换次数： $O(C^2)$
- 总复杂度： $O(L \times C + L^2 + C^2)$ ，在 $L, C \leq 300$ 时完全可行。

```cpp
// Lines of Containers
// UVa ID: 12652
// Verdict: Accepted
// Submission Date: 2025-12-31
// UVa Run Time: 0.020s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int L, C;
    while (cin >> L >> C) {
        vector<vector<int>> grid(L, vector<int>(C));
        for (int i = 0; i < L; i++) 
            for (int j = 0; j < C; j++) 
                cin >> grid[i][j];

        vector<int> rowId(L, -1), colId(C, -1);
        bool possible = true;

        // 1. 检查每一行
        for (int i = 0; i < L && possible; i++) {
            int minVal = *min_element(grid[i].begin(), grid[i].end());
            // 检查最小值是否是 k*C + 1 的形式
            if ((minVal - 1) % C != 0) {
                possible = false;
                break;
            }
            int base = (minVal - 1) / C; // 转换为0-based行号
            // 检查该行是否包含连续C个数
            vector<int> sortedRow = grid[i];
            sort(sortedRow.begin(), sortedRow.end());
            for (int j = 0; j < C; j++) {
                if (sortedRow[j] != base * C + 1 + j) {
                    possible = false;
                    break;
                }
            }
            if (!possible) break;
            rowId[i] = base;
        }

        // 2. 检查行号集合是否为 {0..L-1}
        if (possible) {
            vector<bool> rowUsed(L, false);
            for (int i = 0; i < L; i++) {
                if (rowId[i] < 0 || rowId[i] >= L || rowUsed[rowId[i]]) {
                    possible = false;
                    break;
                }
                rowUsed[rowId[i]] = true;
            }
        }

        // 3. 检查每一列
        if (possible) {
            for (int j = 0; j < C && possible; j++) {
                int modVal = (grid[0][j] - 1) % C; // 转换为0-based模值
                // 检查整列同余
                for (int i = 0; i < L; i++) {
                    if ((grid[i][j] - 1) % C != modVal) {
                        possible = false;
                        break;
                    }
                }
                if (!possible) break;
                colId[j] = modVal;
            }
        }

        // 4. 检查列模值集合是否为 {0..C-1}
        if (possible) {
            vector<bool> colUsed(C, false);
            for (int j = 0; j < C; j++) {
                if (colId[j] < 0 || colId[j] >= C || colUsed[colId[j]]) {
                    possible = false;
                    break;
                }
                colUsed[colId[j]] = true;
            }
        }

        // 5. 整体验证公式
        if (possible) {
            for (int i = 0; i < L && possible; i++) {
                for (int j = 0; j < C; j++) {
                    int expected = rowId[i] * C + colId[j] + 1; // 转回1-based
                    if (grid[i][j] != expected) {
                        possible = false;
                        break;
                    }
                }
            }
        }

        if (!possible) {
            cout << "*\n";
            continue;
        }

        // 6. 计算最少行交换次数
        int rowSwaps = 0;
        vector<int> rowTemp = rowId;
        for (int i = 0; i < L; i++) {
            if (rowTemp[i] != i) {
                int pos = i;
                while (rowTemp[pos] != i) pos++;
                swap(rowTemp[i], rowTemp[pos]);
                rowSwaps++;
            }
        }

        // 7. 计算最少列交换次数
        int colSwaps = 0;
        vector<int> colTemp = colId;
        for (int i = 0; i < C; i++) {
            if (colTemp[i] != i) {
                int pos = i;
                while (colTemp[pos] != i) pos++;
                swap(colTemp[i], colTemp[pos]);
                colSwaps++;
            }
        }

        cout << rowSwaps + colSwaps << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于理解起重机操作的限制条件，并从中推导出矩阵必须满足的结构特征。通过检查这些特征，我们可以判断恢复是否可行。如果可行，问题被分解为两个独立的排序问题，分别计算行和列的最少相邻交换次数。算法的时间复杂度完全满足题目数据范围的要求。
