## 题目描述

在编程竞赛期间，选手需要乘坐公交车和小巴前往赛场。$\texttt{Ricardinho}$ 注意到所有车辆都来自同一家公司，但涂装颜色不同。他想知道：给定队列的总长度（单位：米），以及小巴和公交车可涂的不同颜色数，可以组成多少种不同的队列排列方案？由于答案可能非常大，只需要输出方案数的**最后 $6$ 位数字**。

**车辆长度**：
- 每辆小巴长度为 $5$ 米。
- 每辆公交车长度为 $10$ 米。

**输入**：
- 多个测试用例，每行三个整数 $N$, $K$, $L$。
- $N$：队列总长度（米），保证是 $5$ 的倍数。
- $K$：小巴的颜色数。
- $L$：公交车的颜色数。

**输出**：
- 对每个测试用例，输出一行 $6$ 位数字（不足补前导零），表示方案数的最后 $6$ 位。

**数据范围**：
- $5 \leq N \leq 10^{15}$，且 $N$ 是 $5$ 的倍数。
- $1 \leq K, L \leq 10^{15}$。

## 题目分析

本题要求计算在给定总长度下，使用不同颜色的小巴和公交车排列成一列的方案数。由于 $N$ 最大可达 $10^{15}$，直接枚举或普通动态规划会超时，需要寻找更高效的数学方法。

### 关键点
1. **长度单位归一化**：以小巴长度 $5$ 米为单位，则：
   - 小巴长度为 $1$ 单位。
   - 公交车长度为 $2$ 单位。
   因此总长度 $N$（米）转换为 $n = N / 5$ 单位。

2. **递推关系**：设 $dp[x]$ 表示总长度为 $x$ 单位时的方案数。
   - 最后放一辆小巴：有 $K$ 种颜色，贡献 $K \cdot dp[x-1]$。
   - 最后放一辆公交车：有 $L$ 种颜色，贡献 $L \cdot dp[x-2]$。
   于是得到递推式：
   $$
   dp[x] = K \cdot dp[x-1] + L \cdot dp[x-2]
   $$
   初始条件：$dp[0] = 1$（空队列），$dp[1] = K$（只能放一辆小巴）。

3. **快速计算**：由于 $n$ 极大，直接递推不可行。观察到递推式是线性常系数递推，可以用**矩阵快速幂**在 $O(\log n)$ 时间内求出 $dp[n]$。

4. **取模**：我们只关心最后 $6$ 位数字，相当于对 $10^6$ 取模。

### 矩阵形式

将递推式写成矩阵形式：

$$
\begin{bmatrix} dp[x-1] \\ dp[x] \end{bmatrix} =
\begin{bmatrix} 0 & 1 \\ L & K \end{bmatrix}
\cdot
\begin{bmatrix} dp[x-2] \\ dp[x-1] \end{bmatrix}
$$

设转移矩阵：
$$
M = \begin{bmatrix} 0 & 1 \\ L & K \end{bmatrix}
$$

则：
$$
\begin{bmatrix} dp[n-1] \\ dp[n] \end{bmatrix}
= M^{n-1} \cdot \begin{bmatrix} dp[0] \\ dp[1] \end{bmatrix}
$$

其中 $dp[0] = 1$，$dp[1] = K$。计算 $M^{n-1}$ 后即可得到 $dp[n]$。

### 算法步骤
1. 读入 $N, K, L$，令 $n = N / 5$。
2. 如果 $n = 1$，直接输出 $K \bmod 10^6$。
3. 构造转移矩阵 $M$，元素对 $10^6$ 取模。
4. 计算 $M^{n-1}$（矩阵快速幂）。
5. 利用 $dp[0]$ 和 $dp[1]$ 计算 $dp[n]$。
6. 输出 $dp[n] \bmod 10^6$，格式化为 $6$ 位数字。

## 时间复杂度
- 矩阵快速幂：$O(\log n)$，其中 $n = N/5$。
- 每个测试用例可在极短时间内完成。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const ll MOD = 1000000; // 我们只关心最后6位，因此取模 10^6

// 矩阵乘法，返回 a*b，结果对 MOD 取模
vector<vector<ll>> matMul(const vector<vector<ll>> &a, const vector<vector<ll>> &b) {
    int n = a.size();
    vector<vector<ll>> res(n, vector<ll>(n, 0));
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            for (int k = 0; k < n; ++k)
                res[i][j] = (res[i][j] + a[i][k] * b[k][j]) % MOD;
    return res;
}

// 矩阵快速幂，返回 mat^p
vector<vector<ll>> matPow(vector<vector<ll>> mat, ll p) {
    int n = mat.size();
    vector<vector<ll>> res(n, vector<ll>(n, 0));
    for (int i = 0; i < n; ++i) res[i][i] = 1; // 单位矩阵
    while (p) {
        if (p & 1) res = matMul(res, mat);
        mat = matMul(mat, mat);
        p >>= 1;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ll n, k, l;
    while (cin >> n >> k >> l) {
        n /= 5; // 将长度单位转换为“5米块”，这样 minibus 长度为1，bus 长度为2

        // dp[n] = l*dp[n-2] + k*dp[n-1]
        // 构造转移矩阵
        vector<vector<ll>> trans = {
            {0, l % MOD},
            {1, k % MOD}
        };

        // 初始状态：dp[0] = 1, dp[1] = k
        // 我们要求 dp[n]
        if (n == 1) {
            // 只有 minibus 一种情况
            ll ans = k % MOD;
            printf("%06lld\n", ans);
            continue;
        }

        // 计算 trans^(n-1)
        auto powMat = matPow(trans, n - 1);
        // 初始向量 [dp[0], dp[1]] = [1, k]
        ll dp0 = 1;
        ll dp1 = k % MOD;
        // dp[n] = powMat[0][1]*dp[0] + powMat[1][1]*dp[1]   （实际上我们只需要第二列）
        ll ans = (powMat[0][1] * dp0 + powMat[1][1] * dp1) % MOD;
        printf("%06lld\n", ans);
    }

    return 0;
}
```

### 代码说明
- 使用 `long long` 存储大整数。
- 矩阵乘法与快速幂均对 $10^6$ 取模。
- 输出使用 `printf("%06lld")` 保证 $6$ 位数字并补零。

## 总结
本题通过归一化长度、建立递推关系，并利用矩阵快速幂高效求解，巧妙地处理了极大 $N$ 的情况，同时取模操作避免了高精度运算。核心在于将线性递推转换为矩阵幂运算，这是处理大指数递推问题的常用技巧。
