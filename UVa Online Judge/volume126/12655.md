## 题目描述

$\texttt{Nlogonia}$ 是一个由若干岛屿组成的群岛，岛屿之间通过桥梁连接。每个桥梁有一个最大承重限制 $W$（单位：吨）。$\texttt{Subtle Balloons Company (SBC)}$ 需要将气球从仓库运送到各个比赛场地。对于每个查询 $(L, H)$，其中 $L$ 是比赛场地所在岛屿，$H$ 是仓库所在岛屿，需要找出从 $H$ 到 $L$ 的所有路径中，路径上最小边权（即桥梁承重）的最大值。

### 输入格式
- 第一行：$N$（岛屿数），$M$（桥梁数），$S$（查询数）
- 接下来 $M$ 行：每行 $A, B, W$，表示连接岛屿 $A$ 和 $B$ 的桥梁最大承重为 $W$
- 接下来 $S$ 行：每行 $L, H$，表示一个查询

### 输出格式
对每个查询，输出一个整数，表示可运输的最大重量。

### 数据范围
- $2 \leq N \leq 2 \times 10^4$
- $1 \leq M \leq 10^5$
- $1 \leq S \leq 5 \times 10^4$
- $0 \leq W \leq 10^5$

## 题目分析

这个问题本质上是**最大瓶颈路问题**（$\texttt{Maximum Bottleneck Path}$）：在无向连通图中，对于两个节点 $u$ 和 $v$，找到从 $u$ 到 $v$ 的所有路径中，路径上最小边权的最大值。

### 关键观察

1. **最大生成树性质**：在任意连通无向图中，两点间的最大瓶颈路径一定存在于该图的最大生成树（$\texttt{Maximum Spanning Tree}$）上。
2. **问题转化**：因此我们可以先构建图的最大生成树，然后在树上回答每个查询 $(L, H)$，即求树上两点间路径上的最小边权。

### 算法选择

考虑到数据规模：
- $N \leq 2 \times 10^4$，$S \leq 5 \times 10^4$，不能对每个查询都执行一次 $\texttt{BFS}$ 或 $\texttt{DFS}$（$O(N)$ 会超时）
- 需要使用**树上倍增**（$\texttt{Binary Lifting}$）技术，预处理后每个查询可在 $O(\log N)$ 时间内完成

### 解题步骤

1. **构建最大生成树**
   - 使用 $\texttt{Kruskal}$ 算法，按边权从大到小排序
   - 使用并查集维护连通性

2. **预处理树上信息**
   - 通过 $\texttt{DFS}$ 计算每个节点的深度、父节点和父边权重
   - 使用二进制提升预处理：
     - $\texttt{up}[u][k]$：节点 $u$ 的 $2^k$ 级祖先
     - $\texttt{minEdge}[u][k]$：从 $u$ 到 $\texttt{up}[u][k]$ 路径上的最小边权

3. **处理查询**
   - 对于查询 $(L, H)$，使用 $\texttt{LCA}$（最近公共祖先）方法
   - 在提升节点到同一深度和共同上升过程中，记录路径上的最小边权

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 20005;
const int MAXM = 100005;
const int MAXLOG = 16; // 因为 N <= 20000, 2^15 > 20000

struct Edge {
    int u, v, w;
    bool operator<(const Edge& other) const {
        return w > other.w; // 按权值从大到小排序，用于最大生成树
    }
};

Edge edges[MAXM];
vector<pair<int, int>> tree[MAXN]; // 最大生成树 (to, weight)
int parent[MAXN];
int depth[MAXN];
int up[MAXN][MAXLOG];
int minEdge[MAXN][MAXLOG];

int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);
    return parent[x];
}

bool unite(int x, int y) {
    int rx = find(x), ry = find(y);
    if (rx == ry) return false;
    parent[rx] = ry;
    return true;
}

void dfs(int u, int p, int w, int d) {
    depth[u] = d;
    up[u][0] = p;
    minEdge[u][0] = w;
    for (int i = 1; i < MAXLOG; i++) {
        up[u][i] = up[up[u][i-1]][i-1];
        minEdge[u][i] = min(minEdge[u][i-1], minEdge[up[u][i-1]][i-1]);
    }
    for (auto& e : tree[u]) {
        int v = e.first, weight = e.second;
        if (v != p) {
            dfs(v, u, weight, d + 1);
        }
    }
}

int query(int a, int b) {
    if (depth[a] < depth[b]) swap(a, b);
    int res = 1e9;
    // 提升 a 到与 b 同一深度
    int diff = depth[a] - depth[b];
    for (int i = 0; i < MAXLOG; i++) {
        if (diff & (1 << i)) {
            res = min(res, minEdge[a][i]);
            a = up[a][i];
        }
    }
    if (a == b) return res;
    // 一起向上跳
    for (int i = MAXLOG - 1; i >= 0; i--) {
        if (up[a][i] != up[b][i]) {
            res = min(res, minEdge[a][i]);
            res = min(res, minEdge[b][i]);
            a = up[a][i];
            b = up[b][i];
        }
    }
    res = min(res, minEdge[a][0]);
    res = min(res, minEdge[b][0]);
    return res;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M, S;
    while (cin >> N >> M >> S) {
        for (int i = 0; i < M; i++) {
            cin >> edges[i].u >> edges[i].v >> edges[i].w;
        }
        // Kruskal 最大生成树
        sort(edges, edges + M);
        for (int i = 1; i <= N; i++) {
            parent[i] = i;
            tree[i].clear();
        }
        for (int i = 0; i < M; i++) {
            int u = edges[i].u, v = edges[i].v, w = edges[i].w;
            if (unite(u, v)) {
                tree[u].push_back({v, w});
                tree[v].push_back({u, w});
            }
        }
        // DFS 预处理
        memset(up, 0, sizeof(up));
        memset(minEdge, 0x3f, sizeof(minEdge));
        dfs(1, 1, 1e9, 0); // 根节点为1，父节点为1，边权设为无穷大（实际不会用到根节点的minEdge）
        // 处理查询
        for (int i = 0; i < S; i++) {
            int L, H;
            cin >> L >> H;
            cout << query(L, H) << "\n";
        }
    }
    return 0;
}
