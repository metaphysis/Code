[UVa 12663 High Bridge Low Bridge](https://blog.csdn.net/metaphysis/article/details/156204506)

## 题目描述

河上有 $n$ 座桥，每座桥有一个高度 $h_i$ 。河水会泛滥 $m$ 次，每次洪水会将水位从上次洪水结束后的高度 $b_{i-1}$ 上升到 $a_i$ ，然后回落到 $b_i$ 。初始水位为 $1$ 。

题目规定：如果一座桥在洪水结束后仍然在水下（即水位不低于桥的高度），那么下次洪水时它**不会**被视为再次被淹。也就是说，每次洪水只记录**上升阶段**（水位从 $b_{i-1}$ 上升到 $a_i$ 期间）被淹的桥。

给定 $n$ 座桥的高度和 $m$ 次洪水的数据，求有多少座桥至少被淹了 $k$ 次。

## 输入格式

输入最多包含 $25$ 个测试用例。每个测试用例的第一行包含三个整数 $n, m, k$ （ $1 \leq n, m, k \leq 10^5$ ）。第二行包含 $n$ 个整数 $h_i$ ，表示每座桥的高度（ $2 \leq h_i \leq 10^8$ ）。接下来的 $m$ 行每行包含两个整数 $a_i$ 和 $b_i$ （ $1 \leq b_i < a_i \leq 10^8, a_i > b_{i-1}$ ）。整个输入的文件大小不超过 $5\text{MB}$ 。

## 输出格式

对于每个测试用例，输出至少被淹了 $k$ 次的桥的数量。

## 题目分析

### 核心逻辑

对于第 $i$ 次洪水：
- 洪水开始前的水位是 $b_{i-1}$ （第一次洪水前 $b_0 = 1$ ）
- 水位上升到 $a_i$
- 然后回落到 $b_i$

桥被淹的条件：在上升阶段，水位超过了桥的高度，即 $b_{i-1} < h \leq a_i$ 。  
**为什么不是 $b_i$ ？** 因为下降阶段不影响本次是否被淹的记录，只影响下次洪水是否算作“再次被淹”。

### 关键点

1. **只考虑上升阶段**：题目描述中的文字游戏关键就在于，下降阶段不影响计数，只影响下次判断。
2. **区间更新**：对于每次洪水，需要给所有高度在 $(b_{i-1}, a_i]$ 范围内的桥的计数 $+1$ 。
3. **高效处理**：直接遍历每座桥更新会超时（ $O(nm)$ ），需要使用差分技巧。

### 算法步骤

1. 将桥的高度排序，以便二分查找。
2. 使用差分数组记录每座桥被淹的次数。
3. 遍历每次洪水：
   - 用二分查找找到高度 $> b_{i-1}$ 的第一个桥的索引 $left$
   - 用二分查找找到高度 $\leq a_i$ 的最后一个桥的索引 $right$
   - 如果 $left \leq right$ ，则在差分数组中标记区间 $[left, right]$ 加 $1$
4. 通过差分数组前缀和计算每座桥的实际被淹次数。
5. 统计次数 $\geq k$ 的桥的数量。

### 时间复杂度

- 排序桥高度： $O(n \log n)$
- 每次洪水二分查找： $O(\log n)$ ，总 $O(m \log n)$
- 前缀和统计： $O(n)$
- 总复杂度： $O((n+m) \log n)$ ，可以处理 $10^5$ 的数据规模。

### 空间复杂度

- 存储桥高度和差分数组： $O(n)$

## 代码实现

```cpp
// High Bridge Low Bridge
// UVa ID: 12663
// Verdict: Accepted
// Submission Date: 2025-12-23
// UVa Run Time: 0.040s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int caseNo = 1;
    int n, m, k;
    int bridgeHeight[MAXN], diff[MAXN];
    int a, b;
    while (cin >> n >> m >> k) {
        for (int i = 0; i < n; i++) {
            cin >> bridgeHeight[i];
            diff[i] = 0;
        }
        sort(bridgeHeight, bridgeHeight + n);
        int lastWaterLevel = 1; // 初始水位为1，也是第一次洪水前的b₀
        for (int i = 0; i < m; i++) {
            cin >> a >> b;
            // 本次洪水影响：高度在 (lastWaterLevel, a] 范围内的桥
            // 使用 upper_bound 找到第一个 > lastWaterLevel 的桥
            // 使用 upper_bound 找到第一个 > a 的桥，然后-1得到最后一个 ≤ a 的桥
            int left = upper_bound(bridgeHeight, bridgeHeight + n, lastWaterLevel) - bridgeHeight;
            int right = upper_bound(bridgeHeight, bridgeHeight + n, a) - bridgeHeight - 1;
            if (left <= right) {
                diff[left]++;
                diff[right + 1]--;
            }
            lastWaterLevel = b; // 更新为本次洪水结束后的水位
        }
        // 计算每座桥被淹的次数
        int currentFloodCount = 0;
        int answer = 0;
        for (int i = 0; i < n; i++) {
            currentFloodCount += diff[i];
            if (currentFloodCount >= k) answer++;
        }
        cout << "Case " << caseNo++ << ": " << answer << '\n';
    }
    return 0;
}
```

## 样例解释

### 样例 $1$
```
输入：
2 2 2
2 5
6 2
8 3
```
- 桥高度： $2, 5$
- 第 $1$ 次洪水：影响 $(1, 6]$ → 桥 $2, 5$ 各 $+1$
- 第 $2$ 次洪水：影响 $(2, 8]$ → 桥 $5$ $+1$ （桥 $2$ 高度为 $2$ ，不在 $(2,8]$ 区间）
- 统计：桥 $2$ 被淹 $1$ 次，桥 $5$ 被淹 $2$ 次
- 输出： $1$ （只有桥 $5$ 被淹 $\geq 2$ 次）

### 样例 $2$
```
输入：
5 3 2
2 3 4 5 6
5 3
4 2
5 2
```
- 桥高度： $2, 3, 4, 5, 6$
- 第 $1$ 次洪水：影响 $(1, 5]$ → 桥 $2,3,4,5$ 各 $+1$
- 第 $2$ 次洪水：影响 $(3, 4]$ → 桥 $4$ $+1$
- 第 $3$ 次洪水：影响 $(2, 5]$ → 桥 $3,4,5$ 各 $+1$
- 统计：桥 $2:1$ 次，桥 $3:2$ 次，桥 $4:3$ 次，桥 $5:2$ 次，桥 $6:0$ 次
- 输出： $3$ （桥 $3,4,5$ 被淹 $\geq 2$ 次）

## 总结

本题的关键在于理解题目描述中的文字游戏：**每次洪水只记录上升阶段被淹的桥，下降阶段只影响下次是否算作“再次被淹”** 。  
通过将桥高度排序并使用差分技巧，可以高效地处理区间更新问题。  
注意数据范围较大，需要使用 $O((n+m) \log n)$ 的算法才能通过。
