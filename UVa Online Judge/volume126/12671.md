## 题目描述

$\texttt{Nlogonia}$ 是一个由位于大山上的若干城市组成的女王国度。首都是 $\texttt{Logville}$ （城市 $1$ ），位于山顶。 $\texttt{Logville}$ 有一个巨大且形状完美的圆形湖泊，这是整个王国唯一拥有可饮用水的湖泊，因此用于供应所有城市。 $\texttt{Nlogonia}$ 中的一些城市通过水管连接，以便分配水。由于没有水泵，每根水管利用重力将水从一个城市输送到海拔更低的另一个城市。

一条 **供水路径** 是一系列按海拔降序排列的城市，从 $\texttt{Logville}$ 开始，并且序列中每对连续城市之间都有水管连接。当且仅当存在两条供水路径，每条路径分别以两个城市为终点，并且 $\texttt{Logville}$ 是唯一同时出现在两条路径中的城市时，这两个城市具有 **不重叠供水** 。注意 $\texttt{Logville}$ 本身与每个其他城市都具有不重叠供水。

女王下令调查整个王国当前供水不重叠的状况。作为女王宫廷中最聪明的顾问，你需要帮助计算具有不重叠供水的 **不同城市对** 的数量。

### 输入格式

输入文件包含多个测试用例。每个测试用例描述如下：

第一行包含两个整数 $C$ $(2 \le C \le 1000)$ 和 $P$ $(1 \le P \le 10^5)$ ，分别代表 $\texttt{Nlogonia}$ 中的城市数量和供水管道数量。城市用 $1$ 到 $C$ 的不同整数标识，按海拔严格降序排列（没有两个城市海拔相同）； $\texttt{Logville}$ 是城市 $1$ 。接下来的 $P$ 行每行描述一条管道，包含两个整数 $U$ 和 $V$ $(1 \le U < V \le C)$ ，表示管道连接城市 $U$ 和城市 $V$ 。你可以假设没有两条管道连接同一对城市，并且对于 $\texttt{Nlogonia}$ 中的每个城市，至少存在一条以该城市为终点的供水路径。

### 输出格式

对于每个测试用例，输出一行一个整数，表示具有不重叠供水的不同城市对的数量。

## 题目分析与解题思路

### 1. 问题本质的理解

首先，我们需要理解“不重叠供水”的严格定义：对于两个不同的城市 $i$ 和 $j$ ，存在两条供水路径 $P_i$ 和 $P_j$ ，分别从城市 $1$ （ $\texttt{Logville}$ ）到城市 $i$ 和 $j$ ，使得城市 $1$ 是这两条路径 **唯一** 的公共节点。

这意味着：从 $1$ 到 $i$ 的所有可能路径，与从 $1$ 到 $j$ 的所有可能路径，它们的交集只能是 $\{1\}$ 。换句话说，不存在一个城市 $k$ （ $k \neq 1$ ），使得 $k$ 同时出现在 **所有** 从 $1$ 到 $i$ 的路径和 **所有** 从 $1$ 到 $j$ 的路径上。

### 2. 图论模型建立

根据题目描述：
- 城市编号从 $1$ 到 $C$ ，编号越小海拔越高。
- 管道连接 $(U, V)$ 满足 $U < V$ ，说明水只能从高海拔流向低海拔，因此整个供水网络是一个 **有向无环图** （ $\texttt{DAG}$ ）。
- 从城市 $1$ 到每个城市至少有一条路径，因此以 $1$ 为根，整个图是连通的（在可达意义上）。

题目要求我们计算所有城市对 $(i, j)$ （ $i \neq j$ ）中，满足“不重叠供水”的对数。

### 3. 转化为支配点问题

在图论中，如果从源点 $s$ 到节点 $v$ 的 **所有** 路径都必须经过节点 $d$ ，那么 $d$ 被称为 $v$ 的 **支配点** （$\texttt{dominator}$）。特别地，最近支配点（$\texttt{immediate dominator}$）是指除 $v$ 自身外，离 $v$ 最近的支配点。

在本题中：
- 源点是城市 $1$ 。
- 对于城市 $v$ ，它的支配点集合就是从 $1$ 到 $v$ 的所有路径上的公共节点集合。
- 两个城市 $i$ 和 $j$ 具有不重叠供水，当且仅当它们 **没有除 $1$ 以外的公共支配点** 。也就是说，在支配树中， $i$ 和 $j$ 的最近公共祖先（ $\texttt{LCA}$ ）是 $1$ 。

这是因为：
- 如果存在一个节点 $k$ （ $k \neq 1$ ）同时支配 $i$ 和 $j$ ，那么从 $1$ 到 $i$ 和从 $1$ 到 $j$ 的所有路径都必须经过 $k$ ，违反了“不重叠”的条件。
- 反之，如果 $i$ 和 $j$ 没有除 $1$ 以外的公共支配点，那么我们可以找到两条路径，它们只在 $1$ 处相交。

### 4. 算法设计

由于图是 $\texttt{DAG}$ ，计算支配点有相对简单的算法：

1. **计算最近支配点** ：
   - 对于每个节点 $v$ ，设其前驱节点集合为 $pred(v)$ （即所有满足 $(u, v)$ 是边的 $u$ ）。
   - 节点 $v$ 的最近支配点 $idom(v)$ 是 $pred(v)$ 中所有节点的最近支配点在支配树中的 $\texttt{LCA}$ 。
   - 特别地， $idom(1) = 0$ （表示没有支配点或作为根）。
   - 由于节点编号就是拓扑序（ $u < v$ ），我们可以按编号从小到大计算。

2. **构建支配树** ：
   - 以 $idom(v)$ 作为 $v$ 的父节点，构建一棵树（支配树）。
   - 树根是 $1$ （实际上 $1$ 的父节点设为 $0$ ）。

3. **判断条件** ：
   - 在支配树中，两个节点 $i$ 和 $j$ 的 $\texttt{LCA}$ 是 $1$ ，当且仅当它们位于 $1$ 的 **不同子树** 中。
   - 因此，我们可以通过一次 $\texttt{DFS}$ 标记每个节点属于 $1$ 的哪个直接子节点的子树。
   - 如果两个节点标记不同，或者至少有一个是 $1$ 的直接子节点而另一个不在同一子树，那么它们的 $\texttt{LCA}$ 就是 $1$ 。

4. **计数** ：
   - 首先，城市 $1$ 与所有其他 $C-1$ 个城市都满足条件。
   - 然后，对于其他城市对 $(i, j)$ （ $i, j \ge 2$ ），如果它们属于不同的子树，则计数加一。

### 5. 复杂度分析

- 计算支配点： $O(C + P)$ 。
- 构建支配树并进行 $\text{DFS}$ 标记： $O(C)$ 。
- 枚举城市对： $O(C^2)$ ，但 $C \le 1000$ ， $C^2 = 10^6$ 可接受。
- 总复杂度： $O(C^2 + P)$ ，对于题目限制是可行的。

```cpp
// Disjoint Water Supply
// UVa ID: 12671

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXC = 1005;

vector<int> graph[MAXC];  // 有向图
vector<int> pred[MAXC];   // 前驱
int idom[MAXC];           // 最近支配点
vector<int> domTree[MAXC]; // 支配树

// 快速计算最近支配点
void computeDominators(int C) {
    // 初始化
    for (int i = 1; i <= C; i++) {
        idom[i] = -1;
        domTree[i].clear();
    }
    idom[1] = 0; // 1 的支配点是 0（表示没有支配点或根）
    
    // 按拓扑序处理（编号顺序就是拓扑序）
    for (int v = 2; v <= C; v++) {
        if (pred[v].empty()) {
            idom[v] = 1;
            continue;
        }
        
        // 找所有前驱的公共最近支配点
        int common = pred[v][0];
        for (size_t i = 1; i < pred[v].size(); i++) {
            int a = common, b = pred[v][i];
            // 找 a 和 b 在支配树中的 LCA
            while (a != b) {
                if (a > b) a = idom[a];
                else b = idom[b];
            }
            common = a;
        }
        idom[v] = common;
    }
    
    // 构建支配树
    for (int i = 1; i <= C; i++) {
        if (idom[i] > 0) {
            domTree[idom[i]].push_back(i);
        }
    }
}

// DFS 标记子树
void dfsMark(int u, int root, vector<int>& mark) {
    mark[u] = root;
    for (int v : domTree[u]) {
        dfsMark(v, root, mark);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int C, P;
    while (cin >> C >> P) {
        // 初始化
        for (int i = 1; i <= C; i++) {
            graph[i].clear();
            pred[i].clear();
        }
        
        // 读入图
        for (int i = 0; i < P; i++) {
            int U, V;
            cin >> U >> V;
            graph[U].push_back(V);
            pred[V].push_back(U);
        }
        
        // 计算支配点
        computeDominators(C);
        
        // 方法：对于支配树中 1 的每个直接子节点，标记它的整个子树
        // 如果两个节点在不同的子树中，或者一个是 1，那么它们就是 disjoint 的
        
        vector<int> subtreeRoot(C + 1, 0);
        
        // 标记每个节点的子树
        for (int child : domTree[1]) {
            dfsMark(child, child, subtreeRoot);
        }
        // 1 本身标记为 0
        subtreeRoot[1] = 0;
        
        // 计算答案
        int count = 0;
        
        // 1 与所有其他城市
        count += (C - 1);
        
        // 其他城市对
        for (int i = 2; i <= C; i++) {
            for (int j = i + 1; j <= C; j++) {
                // 如果 i 和 j 在不同的子树中，或者至少有一个是 1 的直接子节点且另一个不在同一子树
                if (subtreeRoot[i] != subtreeRoot[j]) {
                    count++;
                }
            }
        }
        
        cout << count << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于将“不重叠供水”的条件转化为图论中的 **支配点** 问题。通过构建支配树，我们可以高效地判断两个城市是否满足条件。算法的主要步骤包括计算最近支配点、构建支配树、标记子树以及枚举计数。由于城市数 $C$ 不超过 $1000$ ， $O(C^2 + P)$ 的复杂度完全可行。

此解法充分利用了 $\texttt{DAG}$ 的性质和支配点的理论，是图论知识在实际问题中的一个典型应用。
