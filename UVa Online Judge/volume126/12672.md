## 题目描述

给定一个正整数 $N$（$1 \le N \le 10^{100}$），其**数字**定义为十进制表示下不带前导零的各位数字。一个正整数 $M$ 被称为 $N$ 的 **$\texttt{eleven‑multiple‑anagram}$** 当且仅当：

1. $M$ 的数字是 $N$ 的数字的一个排列（即重排）。
2. $M$ 是 $11$ 的倍数。

要求计算 $N$ 的 $\texttt{eleven‑multiple‑anagram}$ 的个数，结果对 $10^9+7$ 取模。

### 样例

| 输入 | 输出 |
|------|------|
| $2090$ | $2$ |
| $16510$ | $12$ |
| $201400000000000000000000000000$ | $0$ |

## 问题分析

### 1. $11$ 的倍数判定法则

一个数的十进制表示中，从**个位**（最低位）开始编号为第 $1$ 位，则：

- 奇数位（第 $1,3,5,\dots$ 位）的权重为 $+1$。
- 偶数位（第 $2,4,6,\dots$ 位）的权重为 $-1$。

该数是 $11$ 的倍数当且仅当：
$$
\sum_{i=1}^{n} (\text{第 } i \text{ 位数字}) \times (\text{权重}_i) \equiv 0 \pmod{11}
$$

例如，$2090$ 从个位起：第 $1$ 位 $0$（$+1$），第 $2$ 位 $9$（$-1$），第 $3$ 位 $0$（$+1$），第 $4$ 位 $2$（$-1$），总和为 $0-9+0-2=-11 \equiv 0$，因此是 $11$ 的倍数。

### 2. 重排问题转化为位置分组

设原数字 $N$ 的长度为 $n$。  
当我们重排数字时，每个数字将占据某一个位置。从低位数起，每个位置有一个固定的权重符号 $+1$ 或 $-1$。因此，$n$ 个位置被划分为两组：

- **奇数位组**（权重 $+1$）：个数为 $\lceil n/2 \rceil = \frac{n+1}{2}$。
- **偶数位组**（权重 $-1$）：个数为 $\lfloor n/2 \rfloor = \frac{n}{2}$。

数字 $d$ 在奇数位出现 $x$ 次，在偶数位出现 $cnt[d] - x$ 次。则它对总和的贡献为：
$$
d \cdot x \cdot (+1) + d \cdot (cnt[d] - x) \cdot (-1) = 2d \cdot x - d \cdot cnt[d]
$$

总和的模 $11$ 条件即为：
$$
\sum_{d=0}^{9} \bigl(2d \cdot x_d - d \cdot cnt[d]\bigr) \equiv 0 \pmod{11}
$$
其中 $x_d$ 是数字 $d$ 分配到奇数位的个数，且满足：
$$
0 \le x_d \le cnt[d], \quad \sum_{d=0}^{9} x_d = \lceil n/2 \rceil
$$

### 3. 排列计数

对于一组固定的分配 $\{x_d\}$：

- 奇数位上的排列数为：
$$
  \frac{(\lceil n/2 \rceil)!}{\prod_{d=0}^{9} x_d!}
$$
- 偶数位上的排列数为：
$$
  \frac{(\lfloor n/2 \rfloor)!}{\prod_{d=0}^{9} (\text{cnt}[d] - x_d)!}
$$

因此该分配对应的合法 $M$ 的个数为两者乘积。

### 4. 前导零处理

最高位（高位第 $1$ 位）不能为 $0$。  
从低位起，最高位对应第 $n$ 位。若 $n$ 为奇数，则最高位属于奇数位组；若 $n$ 为偶数，则属于偶数位组。

我们采用**容斥**方法：

1. 先计算**允许前导零**的所有合法重排数 $total$。
2. 再计算**最高位固定为 $0$** 的合法重排数 $invalid$。
3. 最终答案 $ans = total - invalid$。

当最高位固定为 $0$ 时，剩余 $n-1$ 个位置需要安排剩下的数字，且奇偶位置数各减少 $1$（取决于 $n$ 的奇偶性）。这可以用同样的 $\texttt{DP}$ 框架解决。

## 算法设计

### 动态规划状态定义

由于直接枚举所有 $x_d$ 的组合（最多 $\prod (cnt[d]+1)$ 种）在 $n \le 100$ 时可能过大，我们采用按数字种类转移的动态规划。

设：
- $dp[odd][mod]$ = 处理完前若干种数字后，已经使用了 $odd$ 个奇数位，当前贡献总和模 $11$ 为 $mod$ 的方案数（已经乘入了组合系数）。

初始状态：$dp[0][0] = 1$。

转移时，对于当前数字 $d$，枚举它放入奇数位的个数 $k$（$0 \le k \le cnt[d]$），则放入偶数位的个数为 $cnt[d] - k$。需要保证：
- $k \le$ 剩余奇数位数
- $cnt[d] - k \le$ 剩余偶数位数

转移公式：
$$
dp'[odd+k][mod'] += dp[odd][mod] \times \binom{remainOdd}{k} \times \binom{remainEven}{cnt[d]-k}
$$
其中 $mod' = (mod + d \cdot k - d \cdot (cnt[d]-k)) \bmod 11$。

最终 $total = dp[\lceil n/2 \rceil][0]$。

### 复杂度分析

数字种类固定为 $10$，奇数位个数最多 $50$，模数 $11$。对于每个数字，内层循环枚举 $k$ 最多 $cnt[d]$ 次（总和 $n$）。  
总时间复杂度：$O(10 \times 50 \times 11 \times n) \approx 5.5 \times 10^5$，非常快。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MOD = 1e9 + 7;

ll modPow(ll a, ll e) {
    ll res = 1;
    while (e) {
        if (e & 1) res = res * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return res;
}

ll inv(ll x) { return modPow(x, MOD - 2); }

// 计算给定数字频次下，所有排列（允许前导0）中满足模11条件的个数
ll solveWithCnt(vector<int> cnt, int oddLen, int evenLen) {
    int n = oddLen + evenLen;
    vector<ll> fact(n + 5, 1), invFact(n + 5, 1);
    for (int i = 1; i <= n + 4; i++) fact[i] = fact[i - 1] * i % MOD;
    invFact[n + 4] = inv(fact[n + 4]);
    for (int i = n + 3; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;

    auto C = [&](int n, int m) -> ll {
        if (m < 0 || m > n) return 0;
        return fact[n] * invFact[m] % MOD * invFact[n - m] % MOD;
    };

    vector<vector<ll>> dp(oddLen + 1, vector<ll>(11, 0));
    dp[0][0] = 1;
    int total = 0;  // 已分配的总数字个数（奇+偶）

    for (int d = 0; d < 10; d++) {
        if (cnt[d] == 0) continue;
        vector<vector<ll>> ndp(oddLen + 1, vector<ll>(11, 0));

        for (int odd = 0; odd <= oddLen; odd++) {
            for (int mod = 0; mod < 11; mod++) {
                if (dp[odd][mod] == 0) continue;
                int even = total - odd;
                int remainOdd = oddLen - odd;
                int remainEven = evenLen - even;

                for (int k = 0; k <= cnt[d]; k++) {
                    if (k > remainOdd) break;
                    int toEven = cnt[d] - k;
                    if (toEven > remainEven) continue;

                    ll ways = C(remainOdd, k) * C(remainEven, toEven) % MOD;
                    int newMod = (mod + d * k - d * toEven) % 11;
                    if (newMod < 0) newMod += 11;

                    ndp[odd + k][newMod] = (ndp[odd + k][newMod] + dp[odd][mod] * ways) % MOD;
                }
            }
        }
        total += cnt[d];
        dp = move(ndp);
    }
    return dp[oddLen][0];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    while (cin >> s) {
        int n = s.size();
        vector<int> cnt(10, 0);
        for (char c : s) cnt[c - '0']++;

        int oddLen = (n + 1) / 2;
        int evenLen = n / 2;

        // 1. 允许前导0的所有合法重排数
        ll ans = solveWithCnt(cnt, oddLen, evenLen);

        // 2. 减去最高位为0的非法重排数
        if (cnt[0] > 0) {
            cnt[0]--;
            int n2 = n - 1;
            int oddLen2 = (n2 + 1) / 2;
            int evenLen2 = n2 / 2;
            ll invalid = solveWithCnt(cnt, oddLen2, evenLen2);
            ans = (ans - invalid + MOD) % MOD;
        }

        cout << ans << "\n";
    }
    return 0;
}
```

## 总结

本题的核心在于：

1. 利用 $11$ 的倍数判定法则，将位置按权重分为奇偶两组。
2. 将排列问题转化为“每个数字分配到两组中”的组合计数问题。
3. 使用动态规划按数字种类转移，避免直接枚举所有分配组合。
4. 用容斥原理处理最高位不能为 $0$ 的限制。

该算法时间复杂度 $O(10 \cdot n \cdot maxLen)$，空间复杂度 $O(n \cdot 11)$，能够轻松处理 $N \le 10^{100}$ 的极端情况。
