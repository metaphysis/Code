## 问题描述

给定一个山脉的二维剖面，由 $N$ 个点组成，每个点有一个海拔高度 $H_i$ （单位：厘米）。 我们需要找出所有 **$\texttt{Ultras}$** 山峰，即那些地形突出度（$\texttt{topographic prominence}$）大于等于 $150000$ 厘米的山峰。

### 地形突出度的定义

对于海拔为 $h$ 的山峰 $p$ ，其突出度定义为最大的 $d$ ，使得从 $p$ 到任意**更高**山峰的任何路径都必须经过一个海拔为 $h-d$ 的点。 如果没有更高的山峰，则突出度就是 $h$ 本身。

### 输入格式

- 第一行：整数 $N$ （ $3 \leq N \leq 10^5$ ），表示点数。
- 第二行： $N$ 个整数 $H_i$ （ $0 \leq H_i \leq 10^6$ ），表示按顺序排列的各点海拔。
- 相邻点海拔不同（ $H_i \neq H_{i+1}$ ）。
- 第一个和最后一个点在海平面（ $H_1 = H_N = 0$ ）。
- 保证至少有一个 $\texttt{Ultra}$ 。

### 输出格式

输出所有 $\texttt{Ultras}$ 的索引（按出现顺序， 从 $1$ 开始编号）。

## 题目分析

这个问题本质上是计算每个山峰的**地形突出度**，然后筛选出满足条件的山峰。 关键在于如何高效地计算突出度。

### 突出度计算的核心

对于位置 $i$ 的山峰（海拔 $H[i]$ ）：

1. **向左寻找**：找到左边第一个**严格更高**的山峰位置 $L$ 。 在区间 $(L, i)$ 中找到最低海拔点，记为 $leftMin$ 。 如果左边没有更高山峰，则 $leftMin = 0$ （可以下降到海平面）。
2. **向右寻找**：找到右边第一个**严格更高**的山峰位置 $R$ 。 在区间 $(i, R)$ 中找到最低海拔点，记为 $rightMin$ 。 如果右边没有更高山峰，则 $rightMin = 0$ 。
3. **计算突出度**： 
   - 如果左右都没有更高山峰（即 $L$ 和 $R$ 都不存在），则突出度 $prominence = H[i]$ 。
   - 否则，突出度 $prominence = H[i] - \max(leftMin, rightMin)$ 。
4. **判断 $\texttt{Ultra}$**：如果 $prominence \geq 150000$ ，则 $i$ 是 $\texttt{Ultra}$。

### 算法设计要点

1. **寻找左右第一个更高山峰**：
   - 可以使用**单调栈**。 从左到右扫描，维护一个单调递减栈（严格来说是非递增，但要注意是“严格更高”，所以弹出条件是 $H[栈顶] \leq H[i]$ ）。
   - 同理，从右到左扫描得到右边第一个更高山峰。

2. **查询区间最小值**：
   - 需要快速查询任意区间 $[l, r)$ 的最小海拔值。
   - 由于 $N$ 最大为 $10^5$ ，不能使用 $O(n^2)$ 的暴力方法。
   - 可以使用 **$\texttt{RMQ（Range Minimum Query）}$** 预处理，实现 $O(1)$ 查询。
   - 这里采用 **稀疏表（$\texttt{Sparse Table}$）** 实现 $\texttt{RMQ}$ ，预处理 $O(n \log n)$ ，查询 $O(1)$ 。

3. **边界处理**：
   - 第一个和最后一个点是海平面（高度 $0$ ），不计入山峰。
   - 注意“严格更高”意味着海拔必须大于当前山峰，相等不算。
   - 当左右都没有更高山峰时，突出度等于自身高度。

### 算法步骤

1. 读入数据。
2. 使用单调栈计算每个位置左边第一个更高山峰的位置 $leftHigher[i]$ 和右边第一个更高山峰的位置 $rightHigher[i]$ 。
3. 构建稀疏表，用于快速查询任意区间的最小海拔值。
4. 遍历每个位置 $i$ （从 $1$ 到 $N-2$ ，排除首尾海平面点）：
   - 查询 $leftMin$ ：如果 $leftHigher[i] \neq -1$ ，查询区间 $(leftHigher[i], i)$ 的最小值；否则 $leftMin = 0$ 。
   - 查询 $rightMin$ ：如果 $rightHigher[i] \neq N$ ，查询区间 $(i, rightHigher[i])$ 的最小值；否则 $rightMin = 0$ 。
   - 计算突出度。
   - 如果突出度 $\geq 150000$ ，记录索引。
5. 输出结果。

### 复杂度分析

- 单调栈扫描： $O(N)$
- 稀疏表构建： $O(N \log N)$
- 查询与遍历： $O(N)$
- 总复杂度： $O(N \log N)$ ，可以处理 $N \leq 10^5$ 的数据规模。

## 代码实现

```cpp
// Go up the Ultras
// UVa ID: 12674
// Verdict: Accepted
// Submission Date: 2025-12-24
// UVa Run Time: 0.100s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    while (cin >> n) {
        vector<int> h(n);
        for (int i = 0; i < n; i++) cin >> h[i];
        
        // 左边第一个严格更高的位置
        vector<int> leftHigher(n, -1);
        stack<int> st;
        for (int i = 0; i < n; i++) {
            while (!st.empty() && h[st.top()] <= h[i]) st.pop();
            if (!st.empty()) leftHigher[i] = st.top();
            st.push(i);
        }
        
        // 右边第一个严格更高的位置
        while (!st.empty()) st.pop();
        vector<int> rightHigher(n, n);
        for (int i = n - 1; i >= 0; i--) {
            while (!st.empty() && h[st.top()] <= h[i]) st.pop();
            if (!st.empty()) rightHigher[i] = st.top();
            st.push(i);
        }
        
        // 构建稀疏表（RMQ）用于快速查询区间最小值
        int logn = 1;
        while ((1 << logn) <= n) logn++;
        vector<vector<int>> minTable(logn, vector<int>(n));
        for (int i = 0; i < n; i++) minTable[0][i] = h[i];
        for (int k = 1; k < logn; k++)
            for (int i = 0; i + (1 << k) <= n; i++)
                minTable[k][i] = min(minTable[k-1][i], minTable[k-1][i + (1 << (k-1))]);
        
        // 区间最小值查询函数
        auto rangeMin = [&](int l, int r) {
            if (l >= r) return INT_MAX;
            int k = 31 - __builtin_clz(r - l);
            return min(minTable[k][l], minTable[k][r - (1 << k)]);
        };
        
        // 计算每个山峰的突出度并找出 Ultras
        vector<int> ultras;
        for (int i = 1; i < n - 1; i++) {
            int leftMin = 0;
            if (leftHigher[i] != -1) leftMin = rangeMin(leftHigher[i] + 1, i);
            
            int rightMin = 0;
            if (rightHigher[i] != n) rightMin = rangeMin(i + 1, rightHigher[i]);
            
            int prominence;
            if (leftHigher[i] == -1 && rightHigher[i] == n) prominence = h[i];
            else prominence = h[i] - max(leftMin, rightMin);
            
            if (prominence >= 150000) ultras.push_back(i + 1);
        }
        
        // 输出结果
        if (!ultras.empty()) {
            cout << ultras[0];
            for (size_t i = 1; i < ultras.size(); i++) cout << " " << ultras[i];
        }
        cout << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于理解地形突出度的定义，并将其转化为可计算的算法。 通过单调栈快速找到每个山峰左右第一个更高山峰，再结合 $\texttt{RMQ}$ 快速查询区间最小值，即可高效计算出每个山峰的突出度。 算法复杂度 $O(N \log N)$ ，完全满足题目要求。

需要注意的细节包括：
1. “严格更高”意味着海拔必须大于，不能等于。
2. 当没有更高山峰时，突出度等于自身高度。
3. 海平面点（高度 $0$ ）不计入山峰。
4. 区间查询时注意边界处理。

这个问题的解法综合运用了单调栈和稀疏表两种数据结构，是一道很好的练习题目。
