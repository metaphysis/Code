## 题目描述

两个王国 $\texttt{Nlognia}$ 和 $\texttt{Quadradonia}$ 各自拥有 $N$ 和 $Q$ 座城市，且各自内部的道路系统构成一棵树。所谓“规模”，指的是树中任意两点间最长路径的长度，即 **树的直径** 。

现在要在两个王国之间修建一条新路，连接 $\texttt{Nlognia}$ 的某座城市和 $\texttt{Quadradonia}$ 的某座城市。由于具体连接哪两座城市尚未确定，我们需要计算 **所有可能连接方式下**，新道路系统（仍是一棵树）的直径的 **期望值** 。

输入给出两棵树的结构，输出期望值，保留三位小数。

**关键约束：** $1 \leq N, Q \leq 4 \times 10^{4}$ ，因此必须设计 $O(N \log N + Q \log Q)$ 或更优的算法。

---

## 问题分析与转化

### 1. 新直径的构成

设：
- 树 $A$ （$\texttt{Nlognia}$）的直径为 $D_A$ 。
- 树 $B$ （$\texttt{Quadradonia}$）的直径为 $D_B$ 。
- 连接 $u \in A$ 和 $v \in B$ 。

连接后，新树的直径只可能来源于以下三者之一：
1.  原树 $A$ 的直径 $D_A$ 。
2.  原树 $B$ 的直径 $D_B$ 。
3.  一条经过新边 $(u, v)$ 的路径，其长度为：
    $$
    depth_A(u)+ depth_B(v) + 1
    $$
    其中 $depth_A(u)$ 表示在树 $A$ 中，点 $u$ 到离它最远的点的距离（即 $u$ 的 **偏心率 $\texttt{eccentricity}$** ）。同理定义 $depth_B(v)$ 。

因此，新直径 $d_{\text{new}}$ 为：
$$
d_{\text{new}}(u, v) = \max(D_A, D_B, depth_A(u) + depth_B(v) + 1)
$$

### 2. 期望值的表达式

总共有 $N \times Q$ 种等可能的连接方式。期望值 $E$ 为：
$$
E = \frac{1}{N \times Q} \sum_{u=1}^{N} \sum_{v=1}^{Q} \max(D_A, D_B, depth_A(u) + depth_B(v) + 1)
$$

令 $T = \max(D_A, D_B)$ ，则上式可写为：
$$
E = \frac{1}{N \times Q} \sum_{u=1}^{N} \sum_{v=1}^{Q} \max(T, depth_A(u) + depth_B(v) + 1)
$$

---

## 算法设计

### 1. 计算偏心率 $depth$

对于一棵树，如何高效求出每个点到离它最远点的距离（偏心率）？

**定理**：对于树上任意一点，离它最远的点一定是树的某一条直径的端点。

因此，可以：
1.  通过两次 $\texttt{BFS/DFS}$ 求出树的一条直径的两个端点 $p$ 和 $q$ 。
2.  分别计算每个点到 $p$ 和 $q$ 的距离 $dist_p[i]$ 和 $dist_q[i]$ 。
3.  对于点 $i$ ，其偏心率 $depth[i] = \max(dist_p[i], dist_q[i])$ 。

该过程对每棵树只需三次 $\texttt{BFS}$，时间复杂度 $O(N + Q)$ 。

### 2. 高效计算期望值

我们需要计算：
$$
\text{总和} = \sum_{u=1}^{N} \sum_{v=1}^{Q} \max(T, a_u + b_v + 1)
$$
其中 $a_u = depth_A(u)$ , $b_v = depth_B(v)$ 。

将 $\max$ 拆开：
$$
\text{总和} = \sum_{u,v} \left[ T + \max(0, a_u + b_v + 1 - T) \right]
$$
但这样并不方便，因为 $T$ 会被重复加多次。更好的方式是：
- 如果 $a_u + b_v + 1 \leq T$ ，贡献为 $T$ 。
- 否则，贡献为 $a_u + b_v + 1$ 。

于是：
$$
\text{总和} = N \cdot Q \cdot T + \sum_{u,v} \max(0, a_u + b_v + 1 - T)
$$
令 $c = T - 1$ ，则 $\max(0, a_u + b_v - c)$ 。

对于固定的 $a_u$ ，我们需要找到所有满足 $b_v > c - a_u$ 的 $v$ ，并计算它们的 $(b_v + a_u + 1)$ 之和。

**高效做法**：
1.  将数组 $b$ （即 $depth_B$）排序。
2.  计算 $b$ 的前缀和 $prefixSum[i] = \sum_{k=1}^{i} b_k$ 。
3.  对于每个 $a_u$ ：
    - 使用二分查找找到第一个大于 $c - a_u$ 的 $b_v$ 的位置 $pos$ 。
    - 令 $cnt = m - pos + 1$ ，即满足 $b_v > c - a_u$ 的元素个数。
    - 这些 $b_v$ 的和为 $prefixSum[m] - prefixSum[pos-1]$ 。
    - 贡献为：
        - 对于 $b_v \leq c - a_u$ 的部分，贡献为 $T$ ，共 $(m - cnt)$ 个。
        - 对于 $b_v > c - a_u$ 的部分，贡献为 $(a_u + b_v + 1)$ ，总和为 $sum_b + cnt \cdot (a_u + 1)$ 。

这样，每个 $a_u$ 的处理时间为 $O(\log m)$ ，总时间复杂度为 $O(N \log Q + Q \log Q)$ ，完全可行。

---

## 算法步骤总结

1.  **输入**两棵树。
2.  **计算偏心率**：对每棵树：
    - 第一次 $\texttt{BFS}$ 找直径一端。
    - 第二次 $\texttt{BFS}$ 从该端出发，记录距离并找到直径另一端。
    - 第三次 $\texttt{BFS}$ 从另一端出发，记录距离。
    - 每个点的偏心率取两次距离的最大值。
3.  **计算原直径** $D_A$ 和 $D_B$ ，并令 $T = \max(D_A, D_B)$ 。
4.  **排序与预处理**：将树 $B$ 的偏心率数组 $b$ 排序，并计算前缀和。
5.  **计算总和**：遍历树 $A$ 的偏心率数组 $a$ ，对每个 $a_u$ 二分查找并累加贡献。
6.  **计算期望**：$E = \frac{\text{总和}}{N \times Q}$ ，输出保留三位小数。

// Join Two Kingdoms

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 40005;

vector<int> adjA[MAXN], adjB[MAXN];
int dist1[MAXN], dist2[MAXN];
int depthA[MAXN], depthB[MAXN];
int n, m;

void bfs(int start, vector<int> adj[], int dist[], int n) {
    for (int i = 1; i <= n; ++i) dist[i] = -1;
    queue<int> q;
    dist[start] = 0;
    q.push(start);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}

void computeEccentricity(vector<int> adj[], int n, int ecc[]) {
    // 第一次 BFS 找直径一端
    bfs(1, adj, dist1, n);
    int far = 1;
    for (int i = 2; i <= n; ++i) if (dist1[i] > dist1[far]) far = i;
    // 第二次 BFS 从 far 出发，得到 dist1 为到 far 的距离
    bfs(far, adj, dist1, n);
    // 找直径另一端
    int far2 = far;
    for (int i = 1; i <= n; ++i) if (dist1[i] > dist1[far2]) far2 = i;
    // 第三次 BFS 从 far2 出发，得到 dist2 为到 far2 的距离
    bfs(far2, adj, dist2, n);
    // 偏心率 = max(dist1, dist2)
    for (int i = 1; i <= n; ++i) ecc[i] = max(dist1[i], dist2[i]);
}

int main() {
    while (cin >> n >> m) {
        // 清空邻接表
        for (int i = 1; i <= n; ++i) adjA[i].clear();
        for (int i = 1; i <= m; ++i) adjB[i].clear();
        // 读入树 A
        for (int i = 0; i < n - 1; ++i) {
            int a, b; cin >> a >> b;
            adjA[a].push_back(b);
            adjA[b].push_back(a);
        }
        // 读入树 B
        for (int i = 0; i < m - 1; ++i) {
            int c, d; cin >> c >> d;
            adjB[c].push_back(d);
            adjB[d].push_back(c);
        }
        // 计算偏心率
        computeEccentricity(adjA, n, depthA);
        computeEccentricity(adjB, m, depthB);
        // 计算原直径
        int da = *max_element(depthA + 1, depthA + n + 1);
        int db = *max_element(depthB + 1, depthB + m + 1);
        int T = max(da, db);
        // 对 depthB 排序并计算前缀和
        sort(depthB + 1, depthB + m + 1);
        vector<long long> prefixSum(m + 2, 0);
        for (int i = 1; i <= m; ++i) prefixSum[i] = prefixSum[i - 1] + depthB[i];
        long long total = 0;
        int c = T - 1;  // 偏移量
        for (int i = 1; i <= n; ++i) {
            int x = depthA[i];
            // 找到第一个 > c - x 的位置
            int pos = upper_bound(depthB + 1, depthB + m + 1, c - x) - depthB;
            int cnt = m - pos + 1;
            long long sum = prefixSum[m] - prefixSum[pos - 1];
            total += (long long)(m - cnt) * T;  // 贡献为 T 的部分
            total += sum + (long long)cnt * (x + 1);  // 贡献为 x + b + 1 的部分
        }
        double ans = (double)total / (n * m);
        printf("%.3lf\n", ans);
    }
    return 0;
}
