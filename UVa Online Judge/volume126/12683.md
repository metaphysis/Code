[UVa 12683 Odd and Even Zeroes](https://blog.csdn.net/metaphysis/article/details/158381255)

## 题目描述

给定一个非负整数 $n$，定义 $Z(k)$ 为 $k!$ 末尾零的个数，即：
$$Z(k) = \left\lfloor \frac{k}{5} \right\rfloor + \left\lfloor \frac{k}{25} \right\rfloor + \left\lfloor \frac{k}{125} \right\rfloor + \cdots$$

要求计算在 $0!, 1!, 2!, \dots, n!$ 中，满足 $Z(k)$ 为偶数的 $k$ 的个数。

输入包含多组数据，每组一个整数 $n$（$0 \le n \le 10^{18}$），以 $-1$ 结束。

## 题目分析

### 问题规模
$n$ 最大可达 $10^{18}$，显然不能直接计算阶乘或枚举每个 $k$ 的 $Z(k)$ 值。需要寻找数学规律或高效的数位 $\texttt{DP}$ 方法。

### 关键观察
$Z(k)$ 的奇偶性只与 $k$ 的五进制表示有关。我们可以通过严格的数学推导得到精确的判定条件。

## 解题思路

### 1. 五进制展开
将 $k$ 写成五进制形式：
$$k = a_m 5^m + a_{m-1} 5^{m-1} + \cdots + a_1 5 + a_0$$
其中 $0 \le a_i \le 4$，$a_0$ 是最低位。

### 2. $Z(k)$ 的表达式
根据定义：
$$\left\lfloor \frac{k}{5^j} \right\rfloor = a_m 5^{m-j} + a_{m-1} 5^{m-1-j} + \cdots + a_j$$

所以：
$$Z(k) = \sum_{j=1}^m \sum_{i=j}^m a_i 5^{i-j}$$

交换求和顺序：
$$Z(k) = \sum_{i=1}^m a_i \sum_{j=1}^i 5^{i-j} = \sum_{i=1}^m a_i (5^{i-1} + 5^{i-2} + \cdots + 5^0)$$
$$= \sum_{i=1}^m a_i \frac{5^i - 1}{4}$$

记 $T_i = \frac{5^i - 1}{4}$，则：
$$Z(k) = \sum_{i=1}^m a_i T_i$$

### 3. 奇偶性分析
我们关心 $Z(k) \bmod 2$。

首先，$5 \equiv 1 \pmod{2}$，所以 $5^i \equiv 1 \pmod{2}$，$5^i - 1$ 是偶数。

需要分析 $T_i$ 的奇偶性。已知 $v_2(5^i - 1) = v_2(5-1) + v_2(i) = 2 + v_2(i)$，所以除以 $4$ 后：
$$T_i = \frac{5^i - 1}{4} = 2^{v_2(i)} \times (\text{奇数})$$

因此：
$$T_i \bmod 2 = 1 \iff v_2(i) = 0 \iff i \text{ 是奇数}$$

即：
$$T_i \bmod 2 = \begin{cases}
1 & i \text{ 为奇数} \\
0 & i \text{ 为偶数}
\end{cases}$$

### 4. 最终判定条件
代入 $Z(k)$ 的表达式：
$$Z(k) \bmod 2 = \left( \sum_{i=1}^m a_i T_i \right) \bmod 2 = \left( \sum_{\substack{i=1 \\ i \text{ odd}}}^m a_i \right) \bmod 2$$

所以：
$$Z(k) \text{ 是偶数} \iff \sum_{\substack{i=1 \\ i \text{ odd}}}^m a_i \equiv 0 \pmod{2}$$

即：**在 $k$ 的五进制表示中，所有奇数位（第 $1, 3, 5, \dots$ 位）上的数字之和为偶数**。

注意：这里“奇数位”是从最低位开始编号，最低位是第 $0$ 位（$a_0$），第 $1$ 位是 $a_1$，第 $2$ 位是 $a_2$，依此类推。

### 5. 数位 $\texttt{DP}$ 设计
现在问题转化为：
> 统计 $0 \le k \le n$ 中，五进制表示里所有奇数位数字之和为偶数的数的个数。

这是一个典型的数位 $\texttt{DP}$ 问题。

**状态定义**：
- $\texttt{pos}$：当前处理到哪一位（从最低位 $0$ 开始）
- $\texttt{parity}$：当前奇数位数字之和的奇偶性（$0$ 偶，$1$ 奇）
- $\texttt{tight}$：当前是否受到上界限制（$1$ 表示受限制，$0$ 表示无限制）

**转移**：
- 枚举当前位数字 $d$（$0 \le d \le \texttt{up}$，其中 $\texttt{up}$ 由 $\texttt{tight}$ 决定）
- 如果当前位 $\texttt{pos}$ 是奇数（即 $\texttt{pos} \bmod 2 = 1$），则新奇偶性 $\texttt{newParity} = \texttt{parity} \oplus (d \& 1)$
- 否则 $\texttt{newParity} = \texttt{parity}$
- 新 $\texttt{tight}$ 为 $\texttt{tight} \&\& (d == \texttt{up})$

**递归边界**：
- 当 $\texttt{pos} = -1$ 时，所有位处理完毕，返回 $\texttt{parity} == 0$ 的计数（$1$ 表示符合条件，$0$ 表示不符合）

**初始状态**：
- $\texttt{pos}$ 从最高位开始
- $\texttt{parity} = 0$
- $\texttt{tight} = 1$

### 6. 复杂度分析
五进制位数最多 $\log_5(10^{18}) \approx 27$，状态数为 $30 \times 2 \times 2$，每次转移枚举 $5$ 种数字，总复杂度可以忽略不计，完全可行。

## 代码实现

```cpp
// Odd and Even Zeroes
// UVa ID: 12683
// Verdict: Accepted
// Submission Date: 2026-02-25
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

vector<int> digits;          // 存储 n 的五进制表示，低位在前
ll dp[30][2][2];             // dp[pos][parity][tight]

// 数位 DFS
ll dfs(int pos, int parity, int tight) {
    if (pos == -1) return (parity == 0) ? 1 : 0;
    if (dp[pos][parity][tight] != -1) return dp[pos][parity][tight];

    int up = tight ? digits[pos] : 4;   // 当前位能取的最大值
    ll res = 0;

    for (int d = 0; d <= up; ++d) {
        int newParity = parity;
        // 如果当前位是奇数位（从 1 开始计数，即 pos 为奇数）
        if (pos % 2 == 1) {
            newParity ^= (d & 1);       // 更新奇偶性
        }
        res += dfs(pos - 1, newParity, tight && d == up);
    }

    return dp[pos][parity][tight] = res;
}

// 计算答案
ll countEvenZ(ll n) {
    if (n < 0) return 0;
    digits.clear();
    ll m = n;
    while (m > 0) {
        digits.push_back(m % 5);
        m /= 5;
    }
    if (digits.empty()) digits.push_back(0);   // n = 0 的情况

    memset(dp, -1, sizeof dp);
    return dfs(digits.size() - 1, 0, 1);
}

int main() {
    ll n;
    while (cin >> n) {
        if (n == -1) break;
        cout << countEvenZ(n) << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于通过数学推导将 $Z(k)$ 的奇偶性转化为五进制表示中奇数位数字之和的奇偶性，然后用数位 $\texttt{DP}$ 高效求解。推导过程中用到了五进制展开、交换求和顺序、模 $2$ 下的奇偶性分析等技巧，是一道很好的数学与 $\texttt{DP}$ 结合的题目。
