## 题目描述

$\texttt{VivoParc}$ 动物园新增了一个由大平原热带草原组成的区域，该区域被划分为多个围栏。现在需要将 $4$ 种不同的动物（狮子、豹子、老虎、黑豹）分配到这些围栏中，每个围栏分配一种动物。

这些动物具有很强的领地意识，因此必须确保**没有动物能从自己的围栏中看到同类的其他动物**。动物园经理提供了一个文件，其中包含了不同围栏之间的可见性关系。

### 输入格式
- 第一行：围栏数量 $N$（$N \leq 100$）
- 后续行：可见性限制，格式为 `a-b`，表示围栏 $a$ 和围栏 $b$ 相互可见
- 多个数据集之间用空行分隔

### 输出格式
- 每个围栏一行，格式为：围栏编号 + 物种编号（$1$=狮子，$2$=豹子，$3$=老虎，$4$=黑豹）
- 围栏按编号升序排列
- 数据集输出之间用空行分隔

## 问题分析

这是一个典型的**图着色问题**，我们可以将问题建模如下：

- **节点**：每个围栏作为一个节点
- **边**：可见性关系作为无向边
- **颜色**：$4$ 种动物物种作为 $4$ 种颜色
- **约束**：相邻节点（相互可见的围栏）不能着相同颜色

由于 $N \leq 100$ 且只有 $4$ 种颜色，这个问题可以使用**回溯算法**（深度优先搜索）来解决。

## 解题思路

### 1. 图建模
首先需要将输入数据构建成一个无向图：
- 使用邻接表存储图结构
- 注意处理可能的重复边（题目说明数据可能有冗余）

### 2. 回溯搜索
采用深度优先搜索策略为每个围栏分配物种：
1. 从第一个围栏开始，尝试分配 $4$ 种可能的物种
2. 对于每种分配，检查是否与相邻围栏冲突
3. 如果有效，则递归处理下一个围栏
4. 如果找到完整解，立即返回

### 3. 剪枝优化
- **可行性剪枝**：在分配颜色前检查是否与已着色的相邻节点冲突
- **找到即返回**：一旦找到可行解就立即终止搜索

### 4. 算法复杂度
- 最坏情况时间复杂度：$O(4^N)$，但由于 $N \leq 100$ 且实际剪枝效果很好，可以在合理时间内求解
- 空间复杂度：$O(N + E)$，其中 $E$ 是边的数量

## 关键实现细节

### 有效性检查
```cpp
bool isValid(int enclosure, int c) {
    for (int neighbor : graph[enclosure])
        if (color[neighbor] == c) return false;
    return true;
}
```
这个函数检查当前围栏能否分配物种 $c$，即检查所有相邻围栏是否已经分配了相同的物种。

### 回溯框架
```cpp
void backtrack(int current) {
    if (foundSolution) return;
    
    if (current > n) {
        foundSolution = true;
        return;
    }
    
    for (int c = 1; c <= 4; c++) {
        if (isValid(current, c)) {
            color[current] = c;
            backtrack(current + 1);
            if (foundSolution) return;
            color[current] = 0;
        }
    }
}
```
这是标准的回溯算法框架，按顺序处理每个围栏，尝试所有可能的颜色分配。

## 完整代码

```cpp
// VivoParc
// UVa ID: 12684
// Verdict: Accepted
// Submission Date: 2025-11-29
// UVa Run Time: 0.050s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 105;
vector<int> graph[MAX_N];  // 邻接表存储图
int n;  // 围栏数量
int color[MAX_N];  // 每个围栏的颜色（物种）
bool foundSolution;  // 是否已找到解

// 检查当前围栏能否涂色c
bool isValid(int enclosure, int c) {
    for (int neighbor : graph[enclosure])
        if (color[neighbor] == c) return false;
    return true;
}

// 回溯搜索
void backtrack(int current) {
    if (foundSolution) return;  // 已找到解，直接返回
    
    if (current > n) {  // 所有围栏都已着色
        foundSolution = true;
        return;
    }
    
    // 尝试4种颜色
    for (int c = 1; c <= 4; c++) {
        if (isValid(current, c)) {
            color[current] = c;  // 选择颜色c
            backtrack(current + 1);  // 处理下一个围栏
            if (foundSolution) return;  // 已找到解，直接返回
            color[current] = 0;  // 回溯
        }
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    string line;
    bool firstDataSet = true;
    
    while (cin >> n) {
        // 读取空行（除了第一个数据集）
        if (!firstDataSet) getline(cin, line);
        firstDataSet = false;
        
        // 初始化
        for (int i = 1; i <= n; i++) {
            graph[i].clear();
            color[i] = 0;
        }
        foundSolution = false;
        
        // 读取可见性限制
        getline(cin, line);  // 读取第一行后的换行符
        while (getline(cin, line)) {
            if (line.empty()) break;  // 空行表示数据集结束
            
            // 解析 "a-b" 格式
            int a, b;
            sscanf(line.c_str(), "%d-%d", &a, &b);
            
            // 添加到图中（避免重复边）
            if (find(graph[a].begin(), graph[a].end(), b) == graph[a].end()) {
                graph[a].push_back(b);
                graph[b].push_back(a);
            }
        }
        
        // 回溯搜索
        backtrack(1);
        
        // 输出结果
        for (int i = 1; i <= n; i++)
            cout << i << " " << color[i] << endl;
        
        cout << endl;  // 数据集间输出空行
    }
    
    return 0;
}
```

## 总结

本题通过将实际问题转化为图着色问题，并运用回溯算法成功解决了动物分配的需求。算法的关键在于：
1. 正确的图建模
2. 有效的约束检查
3. 合理的剪枝策略

这种解法保证了在合理时间内找到满足所有约束条件的可行解，即使对于最大规模 $N = 100$ 的情况也能有效处理。
