## 题目描述

二叉树是一种树形数据结构，其中每个节点最多有两个子节点，通常区分为左子节点和右子节点。

一个指令字符串是由字母 $\texttt{L}$、$\texttt{R}$ 和 $\texttt{U}$ 组成的字符串。$\texttt{L}$ 表示向左移动，$\texttt{R}$ 表示向右移动，$\texttt{U}$ 表示向上移动到父节点。

在一棵无限大的二叉树中，每个节点恰好有两个子节点（左子节点和右子节点），并且每个子节点都有一个父节点。对于这个问题，规定根节点的父节点就是根节点本身。

从根节点开始，按照指令字符串 $S$ 移动。然后从执行完 $S$ 后到达的节点开始，执行指令字符串 $T$。但这一次，可以选择跳过 $T$ 中的任意指令（甚至可能全部丢弃）。问最终可能停留在多少个不同的节点上。答案对 $21092013$ 取模。

## 输入格式

第一行包含一个整数 $N$（$N \leq 20$），表示测试用例的数量。

接下来是 $N$ 个测试用例，每个测试用例包含两行：
- 第一行是指令字符串 $S$
- 第二行是指令字符串 $T$

字符串中只包含 $\texttt{L}$、$\texttt{R}$ 或 $\texttt{U}$，长度不超过 $100000$。

## 输出格式

对于每个测试用例，输出格式为 `Case X: Y`，其中 $X$ 是测试用例编号（从 $1$ 开始），$Y$ 是最终可以到达的节点数量对 $21092013$ 取模的结果。

## 样例

### 样例输入
```
2
L
LU
L
L
```

### 样例输出
```
Case 1: 3
Case 2: 2
```

## 题目分析

### 问题本质

这个问题可以转化为：给定起始节点（通过 $S$ 到达），以及一个指令序列 $T$，我们可以选择执行或跳过 $T$ 中的每个指令，问最终可能到达多少个不同的节点。

由于二叉树是无限的，并且是完全对称的，起始节点的具体位置（在左子树还是右子树）不影响最终可达节点的数量。影响最终结果的关键因素是：
1. 起始节点的深度（距离根节点的距离）
2. $T$ 中的指令序列

### 关键观察

考虑从起始节点出发，在执行 $T$ 的过程中，可达节点的集合具有以下性质：

1. **向下移动（$\texttt{L}$ 或 $\texttt{R}$）** ：当执行向下移动时，并不是所有当前可达节点都能产生新节点。只有那些在该方向上"未被阻塞"的节点，向该方向移动才能到达一个不在当前集合中的新节点。

2. **向上移动（$\texttt{U}$）** ：当执行向上移动时，可以恢复某些方向的"可扩展性"。具体恢复哪个方向，取决于从根节点到起始节点的路径。

### 状态定义

根据上述观察，可以维护三个关键变量：

- $total$：当前可达节点的总数
- $leftSon$：当前可达节点中，可以向左移动而不产生重复节点的数量
- $rightSon$：当前可达节点中，可以向右移动而不产生重复节点的数量

初始状态：从起始节点开始，只有 $1$ 个节点，它可以向左也可以向右，因此 $total = 1$，$leftSon = 1$，$rightSon = 1$。

### 状态转移

#### 1. 执行 $\texttt{L}$ 指令

当遇到 $\texttt{L}$ 指令时：
- 当前有 $leftSon$ 个节点可以向左移动产生新节点
- 每个这样的节点向左移动一步，到达一个新节点
- 这些新节点同时具有向左和向右的扩展能力（因为是二叉树，每个新节点都有两个子节点）
- 原来的 $leftSon$ 个节点在向左方向上的扩展能力被"消耗"（因为它们的左子节点已经在集合中了）

因此状态更新为：
- $total = total + leftSon$（新增 $leftSon$ 个节点）
- $rightSon = rightSon + leftSon$（新节点可以向右扩展）
- $leftSon$ 保持不变？注意：新节点也可以向左扩展，但由于原来的 $leftSon$ 个节点已经不能向左扩展了，所以一增一减，$leftSon$ 保持不变。

#### 2. 执行 $\texttt{R}$ 指令

对称地，当遇到 $\texttt{R}$ 指令时：
- $total = total + rightSon$
- $leftSon = leftSon + rightSon$
- $rightSon$ 保持不变

#### 3. 执行 $\texttt{U}$ 指令

当遇到 $\texttt{U}$ 指令时，情况稍微复杂。向上移动可以恢复之前被阻塞的扩展能力，但具体恢复哪个方向，取决于从根节点到起始节点的路径。

为此，需要预处理 $S$，使用一个栈记录从根节点到起始节点的路径（反向存储，即栈顶是最后一步移动）。当执行 $\texttt{U}$ 指令时：
- 如果栈非空，说明可以向上移动（回到祖先节点）
- 向上移动后，会增加 $1$ 个可达节点（祖先节点本身，如果它不在当前集合中的话）
- 根据来时的方向，恢复相应方向的扩展能力：
  - 如果来时是向左（$\texttt{L}$），则恢复向右的扩展能力（$rightSon = rightSon + 1$）
  - 如果来时是向右（$\texttt{R}$），则恢复向左的扩展能力（$leftSon = leftSon + 1$）
- 弹出栈顶元素

### 为什么这样是正确的？

这个算法的精妙之处在于它抓住了问题的本质特征：

1. **扩展能力的对称性**：在无限二叉树中，每个节点都有左右两个子节点。当我们从某个节点向下移动到一个方向时，该节点在这个方向上的扩展能力被消耗，但新节点在两个方向上都获得了扩展能力。

2. **路径的可逆性**：向上移动（$\texttt{U}$）是向下移动的逆操作。通过记录从根节点到起始节点的路径，我们可以知道向上移动时会恢复哪个方向的扩展能力。

3. **状态压缩**：不需要显式维护所有可达节点的集合，只需要维护"可扩展性"的数量。由于二叉树的对称性，这些数量足以计算最终的可达节点总数。

### 时间复杂度

- 预处理 $S$ 的时间复杂度：$O(|S|)$
- 处理 $T$ 的时间复杂度：$O(|T|)$
- 总时间复杂度：$O(|S| + |T|)$，对于每个测试用例都可以在线性时间内完成

### 空间复杂度

- 存储路径栈的空间复杂度：$O(|S|)$
- 总空间复杂度：$O(|S| + |T|)$

```cpp
// Binary Tree

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MOD = 21092013;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int testcase;
    cin >> testcase;
    for (int caseNo = 1; caseNo <= testcase; ++caseNo) {
        string S, T;
        cin >> S >> T;
        
        // 记录从根到起始节点的路径（反向存储，栈顶是最后一步）
        stack<char> pathStack;
        for (char c : S) {
            if (c == 'L' || c == 'R') pathStack.push(c);
            else if (!pathStack.empty()) pathStack.pop();
        }
        
        int total = 1;      // 可达节点总数
        int leftSon = 1;    // 可以向左扩展的节点数
        int rightSon = 1;   // 可以向右扩展的节点数
        
        for (char c : T) {
            if (c == 'L') {
                total = (total + leftSon) % MOD;
                rightSon = (rightSon + leftSon) % MOD;
            } else if (c == 'R') {
                total = (total + rightSon) % MOD;
                leftSon = (leftSon + rightSon) % MOD;
            } else { // 'U'
                if (!pathStack.empty()) {
                    total = (total + 1) % MOD;
                    if (pathStack.top() == 'L') rightSon = (rightSon + 1) % MOD;
                    else leftSon = (leftSon + 1) % MOD;
                    pathStack.pop();
                }
            }
        }
        
        cout << "Case " << caseNo << ": " << total << '\n';
    }
    return 0;
}
```
