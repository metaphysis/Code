## 题目描述

给定来自多个博客的文本数据，文本按天组织。需要维护最近 $7$ 天中出现频率最高的 $N$ 个单词（热门话题）。当遇到查询时，输出当前滑动窗口内的 $\texttt{Top}$ $N$ 单词。

单词仅由小写字母组成，长度小于 $4$ 的单词不计入统计。不同单词总数不超过 $20000$，每天单词数不超过 $20000$，天数不超过 $1000$，$1 \le N \le 20$。

## 输入格式

每个输入文件包含一个测试用例。文本内容由 `<text>` 和 `</text>` 标签界定，可以跨越多行。查询格式为 `<top N />`，可出现在任意两天之间。输入以文件结束符结束。

## 输出格式

对于每个查询，首先输出一行 `<top N>`，随后每行输出一个单词及其出现次数（格式为 **单词 次数**），最后输出一行 `</top>`。单词按出现次数降序排列，次数相同时按字典序升序排列。若第 $N$ 个单词的频次与后续单词相同，则一并输出（即输出可能超过 $N$ 个）。

## 题目分析

本题的核心是维护一个**滑动窗口**（最近 $7$ 天）内的词频统计，并支持**动态查询** $\texttt{Top}$ $N$ 单词。

**关键约束**：
- 每天最多 $20000$ 个单词，不同单词总数最多 $20000$，天数最多 $1000$。
- 查询可能出现在任意两天之间，且 $N \le 20$ 较小。
- 单词长度小于 $4$ 的需过滤。

**主要挑战**：
1. 正确解析跨多行的 `<text>` 和 `</text>` 标签。
2. 高效维护滑动窗口，避免每次查询都重新统计所有历史数据。
3. 查询时需要快速得到 $\texttt{Top}$ $N$ 结果，且要处理并列情况。

## 解题思路

### 1. 输入解析

由于 `<text>` 和 `</text>` 可能不在同一行，需要使用**状态机**进行解析：
- 设置布尔标志 $\textit{inText}$ 表示当前是否在文本块内部。
- 遇到 `<text>` 时，将 $\textit{inText}$ 设为 $\texttt{true}$，并提取同一行中标签后的内容（如果有）。
- 遇到 `</text>` 时，将 $\textit{inText}$ 设为 $\texttt{false}$，并处理当前累积的文本内容。
- 处于 $\textit{inText} = \texttt{true}$ 状态时，将每一行内容累加到当前文本中。
- 独立检测 `<top N />` 查询，可在任何位置出现。

为了正确分隔单词，在不同行文本之间插入空格，避免行末行首单词意外粘连。

### 2. 词频统计与滑动窗口

**数据结构选择**：
- `queue<unordered_map<string, int>>` $\textit{dayQueue}$：存储每一天的单词频次，用于滑动窗口。
- `unordered_map<string, int>` $\textit{globalFreq}$：存储当前窗口内所有单词的累计频次。

**处理一天的文本**：
- 遍历文本字符，提取长度 $\ge 4$ 的单词，统计当天频次。
- 将当天频次加入队列，并更新 $\textit{globalFreq}$。
- 若队列大小超过 $7$，则取出最早一天的频次，从 $\textit{globalFreq}$ 中减去对应计数。若某个单词频次变为 $0$，则从 $\textit{globalFreq}$ 中删除。

**时间复杂度**：每天处理单词 $O(L \cdot \log M)$，$L$ 为当天单词数，$M$ 为不同单词数。滑动窗口维护 $O(1)$ 均摊。

### 3. 查询处理

当遇到 `<top N />` 时：
- 将 $\textit{globalFreq}$ 中的所有 (单词, 频次) 对存入 `vector`。
- 按**频次降序**、**字典序升序**排序。
- 遍历排序后的列表，输出前 $N$ 个，但若第 $N$ 个的频次与后续相同，则继续输出，直到频次变化。

由于 $N \le 20$，且不同单词总数不超过 $20000$，排序复杂度 $O(M \log M)$ 可以接受。

### 4. 输出格式

严格按照题目要求：
- 每个查询先输出 `<top N>`（单独一行）
- 每行输出 **单词 频次**
- 最后输出 `</top>`（单独一行）

## 代码实现

```cpp
// Trending Topic
// UVa ID: 12686
// Verdict: Accepted
// Submission Date: 2026-06-10
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 处理一天内的文本，统计该天每个单词的频次
unordered_map<string, int> processDay(const string& text) {
    unordered_map<string, int> dayFreq;
    string word;
    for (char c : text) {
        if (islower(c)) {
            word += c;
        } else {
            if (word.size() >= 4) dayFreq[word]++;
            word.clear();
        }
    }
    if (word.size() >= 4) dayFreq[word]++;
    return dayFreq;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    queue<unordered_map<string, int>> dayQueue; // 存储每一天的词频
    unordered_map<string, int> globalFreq;      // 最近7天的总词频

    string line;
    string currentText;
    bool inText = false;

    while (getline(cin, line)) {
        // 处理 <text> 开始标签
        if (line.find("<text>") != string::npos) {
            inText = true;
            size_t pos = line.find("<text>");
            string remaining = line.substr(pos + 6);
            // 如果同一行内还有内容
            if (!remaining.empty() && remaining.find("</text>") == string::npos) {
                currentText += ' ' + remaining;
            }
            continue;
        }

        // 处理 </text> 结束标签
        if (line.find("</text>") != string::npos && inText) {
            size_t pos = line.find("</text>");
            string beforeEnd = line.substr(0, pos);
            currentText += ' ' + beforeEnd;

            // 处理这一天的文本
            auto dayFreq = processDay(currentText);
            dayQueue.push(dayFreq);
            for (auto& p : dayFreq) globalFreq[p.first] += p.second;

            // 超过7天，移除最早一天
            if (dayQueue.size() > 7) {
                auto& oldest = dayQueue.front();
                for (auto& p : oldest) {
                    globalFreq[p.first] -= p.second;
                    if (globalFreq[p.first] == 0) globalFreq.erase(p.first);
                }
                dayQueue.pop();
            }

            // 重置状态
            currentText.clear();
            inText = false;
            continue;
        }

        // 在 <text> 和 </text> 之间，累加内容
        if (inText) {
            currentText += ' ' + line;
        }

        // 处理 <top N /> 查询（可能出现在文本之间或之后）
        if (line.find("<top") != string::npos && line.find("/>") != string::npos) {
            int N = 0;
            stringstream ss(line);
            string token;
            while (ss >> token) {
                if (token == "<top") {
                    ss >> N;
                    break;
                }
            }
            if (N == 0) continue;

            // 将 globalFreq 转为 vector 排序
            vector<pair<string, int>> freqList(globalFreq.begin(), globalFreq.end());
            sort(freqList.begin(), freqList.end(), [](const pair<string, int>& a, const pair<string, int>& b) {
                if (a.second != b.second) return a.second > b.second;
                return a.first < b.first;
            });

            // 输出结果
            cout << "<top " << N << ">\n";
            int lastFreq = -1;
            int printed = 0;
            for (size_t i = 0; i < freqList.size(); i++) {
                if (printed >= N && freqList[i].second != lastFreq) break;
                cout << freqList[i].first << " " << freqList[i].second << '\n';
                lastFreq = freqList[i].second;
                printed++;
            }
            cout << "</top>\n";
        }
    }

    return 0;
}
```

## 总结

本题综合考察了以下几个方面的能力：

1. **输入解析**：处理标签化、跨多行的文本输入，需要使用状态机。
2. **滑动窗口**：维护一个时间窗口（最近 $7$ 天）内的累计数据，利用队列实现窗口的推进。
3. **词频统计**：合理使用哈希表进行高效的单词计数。
4. **动态排序**：查询时对当前窗口数据排序并处理并列输出。
5. **输出格式**：严格按照题目要求的格式输出，包括换行和标签。

**关键技巧**：
- 用空格拼接多行文本，避免单词粘连。
- 用 `unordered_map` 存储词频，查询时转为 `vector` 排序。
- 滑动窗口利用 `queue` 存储每天数据，窗口滑动时逐词减少计数，频次归零时及时删除。

**时间复杂度**：每天处理 $O(L \cdot \log M)$，查询排序 $O(M \log M)$，其中 $L$ 为每天单词数，$M$ 为不同单词数。最坏情况下 $L = 20000$，$M = 20000$，可满足时限要求。

**空间复杂度**：$O(M + 7 \cdot L)$，存储全局词频和每天的词频。
