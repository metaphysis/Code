
> **摘要**：本题要求在宽度为 $W$ 的大盒子中，按从左到右、不留空隙的规则依次放入 $n$ 个给定宽度的盒子，统计所有满足“停止条件”的合法放置方式数，并对 $10007$ 取模。核心思路是将相同宽度的盒子归为一类，把“排列”与“组合选择”分离：先用后缀动态规划 $\textit{dp}[i][s][k]$ 统计更大宽度类的选择方案权重，配合前缀和实现 $O(1)$ 区间查询；再枚举“未放置的最小宽度”所在类别，累加各类贡献，并单独处理全部盒子都能放入的情况。算法利用模逆元预处理阶乘，时间复杂度约为 $O(t \cdot W \cdot n \cdot \overline{cnt})$，可高效通过全部测试数据。

## 题目描述

给定 $n$ 个盒子，宽度分别为 $w_1, w_2, \ldots, w_n$，以及一个宽度为 $W$ 的大盒子。求将盒子放入大盒子的不同放置方式数。约束条件如下：

1. 所放盒子的宽度之和不得超过 $W$。
2. 盒子必须从左到右依次放置，中间不留空隙。大盒子末尾可能留有空余，但若某个未放置的盒子能放入该空余中，则该放置顺序视为无效。
3. 若在一种放置顺序中某个盒子位于第 $i$ 个位置，而在另一种顺序中它不在该位置，则认为两种顺序不同。
4. 若两个盒子宽度相同，则视为相同。

## 输入格式

第一行包含一个整数 $T$（$1 \le T \le 100$），表示测试用例数。  
每个测试用例的第一行包含两个整数 $n$（$1 \le n \le 100$）和 $W$（$1 \le W \le 1000$）。  
第二行包含 $n$ 个整数 $w_1, w_2, \ldots, w_n$（$1 \le w_i \le W$）。

## 输出格式

对于每个测试用例，输出 `Case x: ` 后接方案数对 $10007$ 取模的结果。

## 样例

**输入**
```text
2
3 5
1 2 3
5 10
1 2 2 4 5
```

**输出**
```text
Case 1: 6
Case 2: 30
```

## 题目分析

该问题的本质是统计所有满足“停止条件”的盒子序列数目。

放置过程从左到右依次取序列中的盒子放入，直到加入下一个盒子会超过大盒宽度 $W$ 时停止。设已放置盒子的总宽度为 $S$，剩余空间为 $R = W - S$。若停止时还有未放置的盒子，那么这些未放置盒子的最小宽度 $m$ 必须严格大于 $R$，否则该放置顺序非法。

根据约束条件 $\texttt{3}$ 和 $\texttt{4}$，相同宽度的盒子被视为同一类，因此只需关心每一类宽度中被选中的个数。对于一个确定的每类选取个数 $a_1, a_2, \ldots, a_t$，其对应的放置序列数为从 $n$ 个盒子中选出 $K = \sum a_i$ 个盒子进行全排列，同时同一类内盒子相同，因此排列数为：

$$
\frac{K! \cdot (n-K)!}{\prod_i a_i! \cdot (cnt_i - a_i)!}
$$

其中 $cnt_i$ 为宽度第 $i$ 类的总个数。

计数时需要枚举“未放置的最小宽度”是哪一类，并保证所有更小宽度的盒子必须全部放置，当前宽度至少留下一个未放置，更大宽度的盒子任意放置（可为空），且总宽度 $S$ 必须落在区间 $(W - m, W]$ 内，其中 $m$ 为未放置的最小宽度。

## 解题思路

### 状态定义与动态规划

为了高效处理“更大宽度任意选择”的部分，从后向前进行动态规划。

设所有不同宽度按升序排列为 $c_1 < c_2 < \cdots < c_t$，对应的数量为 $cnt_1, cnt_2, \ldots, cnt_t$。

定义 $\textit{dp}[i][s][k]$ 表示从第 $i$ 类宽度（即 $c_i$）到第 $t$ 类宽度中，选择若干个盒子放置，总宽度为 $s$，总个数为 $k$ 时，所有选择方案的权重之和。其中权重定义为：

$$
\prod_{j=i}^{t} \frac{1}{a_j!}
$$

其中 $a_j$ 是第 $j$ 类被选中的数量。该权重用于后续乘以 $K!$ 得到实际排列数。

边界条件：$\textit{dp}[t+1][0][0] = 1$。  
转移时枚举第 $i$ 类放置 $a$ 个盒子（$0 \le a \le cnt_i$），则有：

$$
\textit{dp}[i][s + a \cdot c_i][k + a] += \textit{dp}[i+1][s][k] \cdot \frac{1}{a!}
$$

所有运算均在模 $10007$ 下进行。

为了快速查询“宽度落在某个区间内”的权重和，对每个 $i$ 和每个 $k$，对 $s$ 维度做前缀和，使得查询 $\sum_{s=L}^{R} \textit{dp}[i][s][k]$ 可在 $O(1)$ 时间内完成。

### 枚举未放置的最小宽度

对于每一类宽度 $c_i$，将其视为“未放置的最小宽度”。此时：

- 所有宽度小于 $c_i$ 的盒子必须全部放置。记其总宽度为 $preW$，总个数为 $preK$，权重为 $\prod_{j<i} \frac{1}{cnt_j!}$。
- 第 $i$ 类宽度中，放置个数 $a$ 必须满足 $0 \le a < cnt_i$（至少留下一个未放置）。贡献因子为 $\frac{1}{a!}$。
- 宽度大于 $c_i$ 的盒子任意选择，其选择方案由 $\textit{dp}[i+1]$ 给出。

设当前已放置的总宽度为 $curW = preW + a \cdot c_i$，总个数为 $curK = preK + a$。为了满足剩余空间 $R = W - curW - sufW$ 小于 $c_i$（$sufW$ 为更大宽度类贡献的宽度），必须有：

$$
W - curW - sufW < c_i \quad \Longrightarrow \quad sufW > W - curW - c_i
$$

同时总宽度不能超过 $W$，即 $curW + sufW \le W$。因此 $sufW$ 需满足：

$$
\max(0,\; W - curW - c_i + 1) \le sufW \le W - curW
$$

于是对于每个可能的 $sufK$（即更大宽度类放置的总个数），查询 $\textit{dp}[i+1]$ 中宽度区间内的权重和 $sum$。那么该情况对答案的贡献为：

$$
preWeight \cdot \frac{1}{a!} \cdot sum \cdot (curK + sufK)! \cdot (n - (curK + sufK))!
$$

其中 $preWeight = \prod_{j<i} \frac{1}{cnt_j!}$。

### 全部放置的情况

若所有盒子总宽度 $preSumW = \sum_{j=1}^t cnt_j \cdot c_j \le W$，则存在一种方案将所有盒子都放入大盒。此时序列数为所有不同排列数，即：

$$
\frac{n!}{\prod_{j=1}^t cnt_j!}
$$

该情况单独累加到答案中。

### 复杂度分析

- 宽度种类数 $t \le W \le 1000$。
- $\texttt{DP}$ 状态数为 $O(t \cdot W \cdot n)$，每个状态枚举放置个数 $a$，总复杂度约为 $O(t \cdot W \cdot n \cdot \max cnt_i)$。由于 $n \le 100$，$W \le 1000$，最坏情况下 $t \le 100$，但实际可接受。
- 前缀和优化使查询为 $O(1)$。
- 总时间复杂度 $O(t \cdot W \cdot n \cdot \overline{cnt})$，空间复杂度 $O(t \cdot W \cdot n)$，其中 $t$ 为不同宽度数。

```cpp
// Boxes

#include <bits/stdc++.h>
using namespace std;

const int MOD = 10007;

int modPow(int a, int e) {
    int r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    int T;
    scanf("%d", &T);
    for (int tc = 1; tc <= T; ++tc) {
        int n, W;
        scanf("%d %d", &n, &W);
        vector<int> cnt(W + 1, 0);
        for (int i = 0; i < n; ++i) {
            int w;
            scanf("%d", &w);
            cnt[w]++;
        }

        vector<int> widths;
        for (int w = 1; w <= W; ++w)
            if (cnt[w] > 0) widths.push_back(w);
        int K = (int)widths.size();
        vector<int> cnts(K);
        for (int i = 0; i < K; ++i) cnts[i] = cnt[widths[i]];

        vector<int> fac(n + 1), invFac(n + 1);
        fac[0] = 1;
        for (int i = 1; i <= n; ++i) fac[i] = fac[i - 1] * i % MOD;
        invFac[n] = modPow(fac[n], MOD - 2);
        for (int i = n; i >= 1; --i) invFac[i - 1] = invFac[i] * i % MOD;

        vector<vector<vector<int>>> dp(K + 1, vector<vector<int>>(W + 1, vector<int>(n + 1, 0)));
        dp[K][0][0] = 1;
        for (int i = K - 1; i >= 0; --i) {
            int c = widths[i], num = cnts[i];
            for (int s = 0; s <= W; ++s)
                for (int k = 0; k <= n; ++k) {
                    if (dp[i + 1][s][k] == 0) continue;
                    for (int a = 0; a <= num; ++a) {
                        int ns = s + a * c;
                        if (ns > W) break;
                        int nk = k + a;
                        if (nk > n) break;
                        int add = (long long)dp[i + 1][s][k] * invFac[a] % MOD;
                        dp[i][ns][nk] = (dp[i][ns][nk] + add) % MOD;
                    }
                }
        }

        for (int i = 0; i <= K; ++i)
            for (int k = 0; k <= n; ++k)
                for (int s = 1; s <= W; ++s)
                    dp[i][s][k] = (dp[i][s][k] + dp[i][s - 1][k]) % MOD;

        vector<int> preWeight(K + 1, 1), preSumW(K + 1, 0), preSumK(K + 1, 0);
        for (int i = 0; i < K; ++i) {
            preWeight[i + 1] = preWeight[i] * invFac[cnts[i]] % MOD;
            preSumW[i + 1] = preSumW[i] + cnts[i] * widths[i];
            preSumK[i + 1] = preSumK[i] + cnts[i];
        }

        long long ans = 0;

        for (int mid = 0; mid < K; ++mid) {
            int c = widths[mid], num = cnts[mid];
            int baseW = preSumW[mid], baseK = preSumK[mid];
            int baseWeight = preWeight[mid];

            for (int a = 0; a < num; ++a) {
                int addW = a * c;
                int addK = a;
                int factor = invFac[a];
                int curW = baseW + addW;
                int curK = baseK + addK;

                int L = W - c + 1 - curW;
                int R = W - curW;
                if (L < 0) L = 0;
                if (R > W) R = W;
                if (L > R) continue;

                for (int sufK = 0; sufK <= n - curK; ++sufK) {
                    int totalK = curK + sufK;
                    int sum = dp[mid + 1][R][sufK];
                    if (L > 0) sum = (sum - dp[mid + 1][L - 1][sufK] + MOD) % MOD;
                    if (sum == 0) continue;
                    long long contrib = (long long)fac[totalK] * baseWeight % MOD;
                    contrib = contrib * factor % MOD;
                    contrib = contrib * sum % MOD;
                    ans = (ans + contrib) % MOD;
                }
            }
        }

        if (preSumW[K] <= W) {
            long long all = (long long)fac[n] * preWeight[K] % MOD;
            ans = (ans + all) % MOD;
        }

        printf("Case %d: %lld\n", tc, ans % MOD);
    }
    return 0;
}
```

## 总结

本题的核心在于将“排列”和“组合选择”分离，通过动态规划统计各类盒子被选中的数量，并利用逆元处理组合计数，最后枚举未放置的最小宽度进行累加。关键技术包括：

- 将相同宽度盒子视为一类，避免重复计数。
- 使用模逆元预处理阶乘，高效计算排列数。
- 利用后缀 $\texttt{DP}$ 和前缀和加速区间查询，将复杂度控制在可接受范围。
- 注意边界条件：全部放置的情况需要单独处理。

该解法能正确通过所有测试数据，且代码实现清晰，符合题目对模数 $10007$ 的要求。
