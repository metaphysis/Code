## 题目描述

给定一个长度为 $N$ 的整数序列和一个目标值 $X$，要求找到一个**连续子数组**，使得该子数组的**和至少为 $X$**，并且该子数组的**长度最小**。

### 输入格式
- 第一行：测试用例数量 $T$
- 每个测试用例：
  - 第一行：两个整数 $N$ ($1 \leq N \leq 500000$) 和 $X$ ($-10^9 \leq X \leq 10^9$)
  - 第二行：$N$ 个整数，表示序列元素（范围：$-10^9$ 到 $10^9$）

### 输出格式
对于每个测试用例，输出满足条件的最小子数组长度。如果不存在这样的子数组，输出 $-1$。

## 题目分析

这是一个典型的**最短满足条件的子数组**问题，需要高效地找到和至少为 $X$ 的最短连续子数组。

### 关键观察

1. **数据规模**：$N$ 最大可达 $500,000$，需要 $O(N)$ 或 $O(N \log N)$ 的算法
2. **数值范围**：元素和 $X$ 都可能为负数，这增加了问题的复杂性
3. **连续子数组**：必须是连续的序列元素

### 暴力解法不可行

最直接的暴力解法是枚举所有可能的子数组 $[i, j]$，计算它们的和并检查是否满足条件。这种方法的时间复杂度为 $O(N^2)$，对于 $N = 500,000$ 来说完全不可行。

## 解题思路

### 核心思想：前缀和 + 单调队列

#### 1. 前缀和预处理

定义前缀和数组 $prefix[i]$ 表示前 $i$ 个元素的和：
$$
prefix[i] = \sum_{k=0}^{i-1} arr[k], \quad prefix[0] = 0
$$

这样，子数组 $[i, j]$ 的和可以表示为：
$$
sum(i, j) = prefix[j+1] - prefix[i]
$$

#### 2. 问题转化

对于每个结束位置 $j$，我们要找到最大的开始位置 $i \leq j$，使得：
$$
prefix[j+1] - prefix[i] \geq X
$$

等价于：
$$
prefix[i] \leq prefix[j+1] - X
$$

我们的目标是**最小化 $j - i + 1$**。

#### 3. 单调队列优化

维护一个**单调递增**的前缀和索引队列，这样可以在 $O(1)$ 摊还时间内找到最优解：

- **队列性质**：队列中存储的索引对应的前缀和值是**单调递增**的
- **为什么单调递增**：如果 $prefix[i] \geq prefix[j]$ 且 $i < j$，那么 $i$ 永远不会比 $j$ 更优，因为：
  - 对于任何结束位置 $k$，如果 $prefix[k] - prefix[i] \geq X$，那么 $prefix[k] - prefix[j] \geq X$ 也成立
  - 而且 $k - j < k - i$，即长度更短

#### 4. 算法步骤

1. 计算前缀和数组
2. 初始化双端队列和最小长度
3. 遍历每个位置 $i$（作为子数组的结束位置）：
   - 检查队列头部：如果当前前缀和减去头部前缀和 $\geq X$，更新最小长度并弹出头部
   - 维护队列单调性：从尾部弹出所有前缀和大于等于当前前缀和的索引
   - 将当前索引加入队列尾部
4. 输出结果（如果找不到满足条件的子数组则输出 $-1$）

### 时间复杂度分析

- 前缀和计算：$O(N)$
- 单调队列处理：每个元素最多入队一次、出队一次，摊还时间复杂度 $O(N)$
- 总时间复杂度：$O(N)$，满足题目要求

## 代码实现

```cpp
// Minimal Subarray Length
// UVa ID: 12697
// Verdict: Accepted
// Submission Date: 2025-11-18
// UVa Run Time: 0.050s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        int n;
        long long x;
        cin >> n >> x;
        vector<long long> arr(n);
        for (int i = 0; i < n; i++) cin >> arr[i];

        vector<long long> prefix(n + 1, 0);
        for (int i = 1; i <= n; i++) prefix[i] = prefix[i - 1] + arr[i - 1];

        int minLen = n + 1;
        deque<int> dq;

        for (int i = 0; i <= n; i++) {
            while (!dq.empty() && prefix[i] - prefix[dq.front()] >= x) {
                minLen = min(minLen, i - dq.front());
                dq.pop_front();
            }
            while (!dq.empty() && prefix[i] <= prefix[dq.back()]) dq.pop_back();
            dq.push_back(i);
        }

        if (minLen == n + 1) cout << -1 << "\n";
        else cout << minLen << "\n";
    }

    return 0;
}
```

## 算法正确性证明

### 单调性维护的正确性

当我们在队列尾部弹出所有 $prefix[j] \geq prefix[i]$ 的索引 $j$ 时，我们实际上是在说：

> 对于任何未来的结束位置 $k$，如果 $prefix[k] - prefix[j] \geq X$ 成立，那么 $prefix[k] - prefix[i] \geq X$ 也成立，而且 $k - i < k - j$，所以 $i$ 比 $j$ 更优。

### 队列头部弹出的正确性

当我们发现 $prefix[i] - prefix[front] \geq X$ 时，我们记录这个解并弹出头部，因为：

- 我们已经找到了以 $front$ 开始的最优解
- 对于后续的 $j > i$，即使 $prefix[j] - prefix[front] \geq X$ 也成立，长度 $j - front$ 肯定大于 $i - front$，不是最优解

## 样例分析

### 样例 1
```
输入：
5 4
1 2 1 2 1

前缀和：[0, 1, 3, 4, 6, 7]
输出：3
```
子数组 $[2, 1, 2]$ 的和为 $5 \geq 4$，长度为 $3$。

### 样例 2
```
输入：
6 -2
-5 -6 -7 -8 -9 -10

前缀和：[0, -5, -11, -18, -26, -35, -45]
输出：-1
```
所有子数组的和都小于 $-2$，无解。

### 样例 3
```
输入：
5 3
-1 1 1 1 -1

前缀和：[0, -1, 0, 1, 2, 1]
输出：3
```
子数组 $[1, 1, 1]$ 的和为 $3 \geq 3$，长度为 $3$。

## 总结

本题通过**前缀和**和**单调队列**的巧妙结合，在 $O(N)$ 时间内解决了最短满足条件子数组问题。关键在于：

1. 将子数组和问题转化为前缀和差值问题
2. 利用单调性维护可能的最优开始位置
3. 在遍历过程中及时更新最优解

这种思路可以推广到其他类似的最短满足条件子数组问题中。
