## 题目描述

本题要求模拟形态学图像处理中的膨胀操作。给定一个二值图像 $B$（仅包含 $0$ 和 $1$）和一个结构元素 $S$（同样由 $0$ 和 $1$ 组成的矩阵），膨胀操作的规则如下：

$1$. 结构元素 $S$ 具有一个“原点”，其坐标通过公式计算：  
$$
   origin = \lfloor \frac{size(S)}{2} \rfloor
$$
   即原点的行索引为 $\lfloor q/2 \rfloor$，列索引为 $\lfloor r/2 \rfloor$，其中 $q$ 和 $r$ 分别是结构元素的行数和列数。

$2$. 对于二值图像 $B$ 中的每一个值为 $1$ 的像素，将结构元素 $S$ 的**原点**对齐到该像素位置。

$3$. 将结构元素 $S$ 中所有值为 $1$ 的位置，通过逻辑或（$\texttt{OR}$）操作，写入输出图像的对应位置。  
   具体来说，若 $B[i][j] = 1$，则对于 $S$ 中每个 $S[sr][sc] = 1$ 的位置，输出图像中位置  
$$
   (i + sr - originRow,\ j + sc - originCol)
$$
   应被置为 $1$。

**重要约束**：
- 输入保证原始图像的边界（即第一行、最后一行、第一列、最后一列）不含 $1$。
- 结构元素的尺寸不超过图像尺寸。
- 输出时，每行末尾不得有多余空格。

## 输入格式

- 第一行：整数 $T$（$T < 25$），表示测试用例数量。
- 每个测试用例包含：
  $1$. 两个整数 $m$ 和 $n$（$2 \leq m, n \leq 100$），表示图像的行数和列数。
  $2$. 一个 $m \times n$ 的矩阵，元素为 $0$ 或 $1$，表示二值图像。
  $3$. 两个整数 $q$ 和 $r$（$1 \leq q, r \leq 10$），表示结构元素的行数和列数。
  $4$. 一个 $q \times r$ 的矩阵，元素为 $0$ 或 $1$，表示结构元素。

## 输出格式

对于每个测试用例，输出膨胀后的二值图像，格式与输入类似，但需在开头标注 `Case X:`（`X` 为测试用例编号，从 `1` 开始）。

## 题目分析与解题思路

### $1$. 问题本质

本题是**二维卷积的简化版**，但不是加权求和，而是逻辑或操作。核心在于：

- 当图像中某个像素为 $1$ 时，以该像素为中心（实际上是结构元素原点对齐），将结构元素中所有 $1$ 的位置“投射”到输出图像上。
- 由于多个 $1$ 像素可能影响重叠区域，最终输出是这些影响的并集。

### $2$. 关键步骤分解

**步骤一：计算结构元素原点**  
根据公式，原点坐标为：
$$
(originRow, originCol) = \left( \lfloor \frac{q}{2} \rfloor,\ \lfloor \frac{r}{2} \rfloor \right)
$$
在 $\texttt{C++}$ 中，整数除法 `/` 默认向下取整，因此直接使用 `q/2` 和 `r/2` 即可。

**步骤二：遍历图像，寻找值为 $1$ 的像素**  
对每个 $B[i][j] = 1$ 的位置，执行下一步。

**步骤三：将结构元素“贴”到输出图像**  
对于结构元素 $S$ 中的每个位置 $(sr, sc)$：
- 如果 $S[sr][sc] = 1$，则计算对应输出图像位置：
$$
  ni = i + sr - originRow
\\
  nj = j + sc - originCol
$$
- 检查 $(ni, nj)$ 是否在图像范围内（$0 \leq ni < m$ 且 $0 \leq nj < n$），若是，则将输出图像该位置设为 $1$。

**步骤四：处理多个 $1$ 像素的重叠影响**  
由于输出图像初始为全 $0$，每次遇到 $1$ 像素就将结构元素投射上去，多个投射可能重叠，但逻辑或操作保证只要有一次投射到该位置，该位置最终就是 $1$。

### $3$. 边界处理

虽然题目保证输入图像边界没有 $1$，但膨胀操作可能使边界出现 $1$（例如结构元素较大时）。因此，在将结构元素投射到输出图像时，必须检查计算出的位置是否在 $[0, m) \times [0, n)$ 范围内，否则忽略。

### $4$. 时间复杂度分析

设图像大小为 $m \times n$，结构元素大小为 $q \times r$。  
最坏情况下，每个像素都为 $1$，则对每个像素都需要遍历整个结构元素。  
总操作次数为 $O(m \times n \times q \times r)$。  
在题目给定的数据范围（$m, n \leq 100$，$q, r \leq 10$）下，最坏情况约为 $10^6$ 量级，完全可行。

### $5$. 注意事项

- 输出格式要求严格：每行末尾不能有空格，每个测试用例后是否空行取决于题目示例（本题示例中无空行）。
- 原点计算是向下取整，对于偶数尺寸的结构元素，原点会偏向左上角。

## 代码实现

```cpp
// Dilation

// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;  // 测试用例数
    for (int caseNo = 1; caseNo <= t; caseNo++) {
        int m, n;
        cin >> m >> n;  // 图像尺寸
        vector<vector<int>> image(m, vector<int>(n));
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                cin >> image[i][j];  // 读取图像
        
        int q, r;
        cin >> q >> r;  // 结构元素尺寸
        vector<vector<int>> structure(q, vector<int>(r));
        for (int i = 0; i < q; i++)
            for (int j = 0; j < r; j++)
                cin >> structure[i][j];  // 读取结构元素
        
        // 计算结构元素原点
        int originRow = q / 2;
        int originCol = r / 2;
        
        // 初始化输出图像，全0
        vector<vector<int>> output(m, vector<int>(n, 0));
        
        // 遍历原图每个像素
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (image[i][j] == 1) {  // 如果当前像素为1
                    // 将结构元素覆盖到输出图像
                    for (int sr = 0; sr < q; sr++) {
                        for (int sc = 0; sc < r; sc++) {
                            if (structure[sr][sc] == 1) {
                                int ni = i + sr - originRow;
                                int nj = j + sc - originCol;
                                // 检查是否在图像范围内
                                if (ni >= 0 && ni < m && nj >= 0 && nj < n)
                                    output[ni][nj] = 1;
                            }
                        }
                    }
                }
            }
        }
        
        // 输出结果
        cout << "Case " << caseNo << ":\n";
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                cout << output[i][j];
                if (j < n - 1) cout << " ";  // 行末无空格
            }
            cout << "\n";
        }
    }
    return 0;
}
```

## 总结

本题通过模拟形态学膨胀操作，考察了对二维矩阵的遍历、坐标变换和边界检查的基本编程能力。关键在于理解结构元素原点的定义，以及如何将结构元素中的 $1$ 映射到输出图像的正确位置。虽然题目涉及图像处理概念，但本质上是一个矩阵操作问题，适合用循环和条件判断直接模拟。代码实现时需注意输出格式的细节，尤其是行末空格的处理。
