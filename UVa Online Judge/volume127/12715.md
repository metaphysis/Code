## 题目描述

为了保护日益减少的袋鼠数量，管理员建立了一个直线型的保护区，其长度为 $1000000000$ 个单位，最左端位置为 $0$ ，最右端位置为 $1000000000$ 。在保护区内安装了最多 $100000$ 个摄像头，每个摄像头覆盖一个区间 $[L, R]$ ，并在保护区外设有对应的显示屏供游客观看。

当袋鼠出现在某个位置 $x$ 时，系统会选择最佳的屏幕来显示。屏幕对位置 $x$ 的 **覆盖值** 定义如下：

- 若 $x$ 不在屏幕覆盖范围内（即 $x < L$ 或 $x > R$ ），则覆盖值为 $0$ 。
- 否则，覆盖值为 $\min(x - L, R - x)$ 。

给定 $N$ 个屏幕的覆盖区间和 $M$ 次袋鼠出现的位置，对于每次出现，求出所有屏幕中能达到的最大覆盖值。

### 输入格式

第一行包含测试用例数 $T$ （ $T \le 3$ ）。每个测试用例格式如下：

- 第一行： $N$ 和 $M$ （ $1 \le N, M \le 100000$ ）
- 接下来 $N$ 行：每行两个整数 $L$ 和 $R$ （ $0 \le L \le R \le 1000000000$ ）
- 接下来 $M$ 行：每行一个整数 $x$ （ $0 \le x \le 1000000000$ ）

### 输出格式

对于每个测试用例，首先输出 `Case X:` ，然后输出 $M$ 行，每行包含对应查询的最大覆盖值。

### 样例输入

```
1
3 2
7 15
14 100
1 11
10
120
```

### 样例输出

```
Case 1:
3
0
```

**说明**：对于 $x = 10$ ，最佳屏幕是 $(7, 15)$ ，覆盖值为 $3$ ；对于 $x = 120$ ，没有屏幕覆盖，覆盖值为 $0$ 。

## 题目分析

本题的核心在于高效计算对于任意位置 $x$ ，所有区间 $[L, R]$ 中 $\min(x - L, R - x)$ 的最大值。直接对每个查询遍历所有区间的时间复杂度为 $O(NM)$ ，在 $N, M$ 最大为 $100000$ 的情况下显然不可行。

### 覆盖值的数学性质

对于区间 $[L, R]$ 和位置 $x$ ，定义覆盖值：

$$
C = \min(x - L, R - x)
$$

令 $S = L + R$ 为区间端点和， $D = R - L$ 为区间长度，则 $C$ 可重写为：

$$
C = \frac{D - |S - 2x|}{2}
$$

**推导过程**：
由 $\min(a, b) = \frac{(a+b) - |a-b|}{2}$ ，代入 $a = x - L$ ， $b = R - x$ ：
- $a + b = (x - L) + (R - x) = R - L = D$
- $|a - b| = |(x - L) - (R - x)| = |2x - (L+R)| = |2x - S|$

因此：

$$
C = \frac{D - |S - 2x|}{2}
$$

此公式的几何意义更清晰：覆盖值 $C$ 在区间中点 $x = \frac{S}{2}$ 处取得最大值 $\frac{D}{2}$ ，并随着 $x$ 远离中点而线性减小，当 $|S - 2x| \ge D$ 时（即 $x$ 超出区间范围）， $C$ 降为 $0$ 。

### 问题转化

对于查询点 $x$ ，令 $y = 2x$ 。则：

$$
2C = D - |S - y|
$$

我们需要最大化 $2C$ ，即最大化 $D - |S - y|$ ，且需满足 $x$ 在区间内，即 $L \le x \le R$ ，等价于：

$$
S - D \le y \le S + D
$$

### 分情况讨论

由于 $|S - y|$ 的存在，根据 $y$ 与 $S$ 的相对位置，可分为两种情况：

1. **当 $y \le S$ 时**（即 $x$ 在区间左半部分）：
   $$
   2C = D - (S - y) = (D + S) - y = 2R - y
   $$
   条件： $y \ge S - D = 2L$ 且 $y \le S$ ，即 $2L \le y \le S$ 。

2. **当 $y \ge S$ 时**（即 $x$ 在区间右半部分）：
   $$
   2C = D - (y - S) = (D - S) + y = y - 2L
   $$
   条件： $y \le S + D = 2R$ 且 $y \ge S$ ，即 $S \le y \le 2R$ 。

注意：以上两种情况的条件正好对应区间 $[L, R]$ 的左半部分 $[L, \frac{L+R}{2}]$ 和右半部分 $[\frac{L+R}{2}, R]$ 。

### 查询策略

对于每个查询 $y = 2x$ ，我们分别考虑两种情况：

1. **左候选值**：从所有满足 $2L \le y \le S$ 的区间中，最大化 $y - 2L$ 。由于 $y$ 固定，这等价于最小化 $2L$ 。
2. **右候选值**：从所有满足 $S \le y \le 2R$ 的区间中，最大化 $2R - y$ 。由于 $y$ 固定，这等价于最大化 $2R$ 。

因此，问题转化为：

- 对每个查询 $y$ ，快速找到：
  - 所有满足 $S \ge y$ 且 $2L \le y$ 的区间中的最小 $2L$
  - 所有满足 $S \le y$ 且 $2R \ge y$ 的区间中的最大 $2R$

### 预处理数据结构

我们可以预处理两个有序数组来加速查询：

1. **左数组**：存储所有区间的 $(S, 2L)$ 对，按 $S$ **降序**排序。
   - 对于查询 $y$ ，使用二分查找找到第一个 $S < y$ 的位置，则所有 $S \ge y$ 的区间都在此位置之前。
   - 对这些区间维护最小的 $2L$ 前缀值，即可快速得到最小 $2L$ （需检查是否满足 $2L \le y$ ）。

2. **右数组**：存储所有区间的 $(S, 2R)$ 对，按 $S$ **升序**排序。
   - 对于查询 $y$ ，使用二分查找找到最后一个 $S \le y$ 的位置，则所有 $S \le y$ 的区间都在此位置之前。
   - 对这些区间维护最大的 $2R$ 前缀值，即可快速得到最大 $2R$ （需检查是否满足 $2R \ge y$ ）。

### 算法步骤

1. **预处理**：
   - 读取所有区间 $[L, R]$ ，计算 $S = L+R$ ， $2L$ ， $2R$ 。
   - 构建左数组 `leftEvents` （存储 $(S, 2L)$ ）和右数组 `rightEvents` （存储 $(S, 2R)$ ）。
   - 左数组按 $S$ 降序排序，并计算前缀最小 $2L$ 数组 `minDoubleL` 。
   - 右数组按 $S$ 升序排序，并计算前缀最大 $2R$ 数组 `prefixMaxR` 。

2. **查询处理**：
   - 对于每个查询位置 $x$ ，计算 $y = 2x$ 。
   - **左候选值**：
     - 在左数组中二分查找第一个 $S < y$ 的位置 `idx` 。
     - 若 `idx > 0` ，则取 `minDoubleL[idx-1]` 作为最小 $2L$ 。
     - 若该值 $\le y$ ，则左候选值 = $y - \text{min}2L$ 。
   - **右候选值**：
     - 在右数组中二分查找最后一个 $S \le y$ 的位置 `idx` 。
     - 若找到，则取 `prefixMaxR[idx]` 作为最大 $2R$ 。
     - 若该值 $\ge y$ ，则右候选值 = $\text{max}2R - y$ 。
   - 最终答案 = $\max(\text{左候选值}, \text{右候选值}) / 2$ 。

### 时间复杂度

- 预处理排序： $O(N \log N)$
- 预处理前缀最值数组： $O(N)$
- 每个查询两次二分查找： $O(\log N)$
- 总复杂度： $O((N+M) \log N)$ ，满足题目要求。

### 空间复杂度

- 存储区间信息： $O(N)$
- 前缀数组： $O(N)$
- 总空间： $O(N)$

```cpp
// Watching the Kangaroo

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        int n, m;
        cin >> n >> m;
        vector<pair<int, int>> screens(n);
        for (int i = 0; i < n; ++i) cin >> screens[i].first >> screens[i].second;
        vector<int> queries(m);
        for (int i = 0; i < m; ++i) cin >> queries[i];
        // 准备左半部分和右半部分的数据
        vector<pair<int, int>> leftEvents;  // (sum, 2L) 其中 sum = L+R
        vector<pair<int, int>> rightEvents; // (sum, 2R) 其中 sum = L+R
        for (auto& screen : screens) {
            int L = screen.first, R = screen.second, sum = L + R;
            leftEvents.emplace_back(sum, 2 * L);
            rightEvents.emplace_back(sum, 2 * R);
        }
        // 左半部分：按 sum 降序排序
        sort(leftEvents.begin(), leftEvents.end(), greater<pair<int, int>>());
        // 预处理左半部分：对于每个位置，维护最小的 2L
        vector<int> minDoubleL(leftEvents.size());
        if (!leftEvents.empty()) {
            minDoubleL[0] = leftEvents[0].second;
            for (int i = 1; i < (int)leftEvents.size(); ++i)
                minDoubleL[i] = min(minDoubleL[i - 1], leftEvents[i].second);
        }
        // 右半部分：按 sum 升序排序
        sort(rightEvents.begin(), rightEvents.end());
        // 预处理右半部分：对于每个位置，维护最大的 2R
        // 由于我们需要前缀最大值（从开始到当前位置的最大值）
        vector<int> prefixMaxR(rightEvents.size());
        if (!rightEvents.empty()) {
            prefixMaxR[0] = rightEvents[0].second;
            for (int i = 1; i < (int)rightEvents.size(); ++i)
                prefixMaxR[i] = max(prefixMaxR[i - 1], rightEvents[i].second);
        }
        cout << "Case " << caseNo << ":\n";
         for (int x : queries) {
            int y = 2 * x;
            int answer = 0;
            // 处理左半部分：找到所有 sum >= y 的区间
            if (!leftEvents.empty()) {
                // 二分查找：找到第一个 sum < y 的位置
                // 由于是降序排列，所有 sum >= y 的区间在 [0, idx)
                auto it = lower_bound(leftEvents.begin(), leftEvents.end(), 
                                     make_pair(y, INT_MIN), greater<pair<int, int>>());
                int idx = it - leftEvents.begin();
                if (idx > 0) {
                    int minL = minDoubleL[idx - 1];
                    if (minL <= y) answer = max(answer, y - minL);
                }
            }
            // 处理右半部分：找到所有 sum <= y 的区间
            if (!rightEvents.empty()) {
                // 二分查找：找到最后一个 sum <= y 的位置
                auto it = upper_bound(rightEvents.begin(), rightEvents.end(), 
                                     make_pair(y, INT_MAX));
                if (it != rightEvents.begin()) {
                    --it;
                    int idx = it - rightEvents.begin();
                    int maxR = prefixMaxR[idx];
                    if (maxR >= y) answer = max(answer, maxR - y);
                }
            }
            cout << answer / 2 << '\n';
        }
    }
    return 0;
}
```

## 总结

本题通过数学推导将覆盖值公式转化为更易处理的形式，并利用二分查找和前缀最值优化，将每次查询的复杂度从 $O(N)$ 降为 $O(\log N)$ 。关键点在于：

1. 将 $\min(x-L, R-x)$ 重写为 $\frac{D - |S - 2x|}{2}$ ，揭示其线性变化的本质。
2. 根据 $x$ 相对于区间中点的位置，分情况讨论，将最大化问题转化为寻找最小 $2L$ 或最大 $2R$ 。
3. 通过预处理有序数组和前缀最值，实现快速查询。

这种结合数学推导与数据结构的优化方法，在处理大规模区间查询问题时非常有效。
