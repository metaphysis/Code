## 题目描述

给定一个整数 $N$，计算有多少个数对 $(A,B)$ 满足以下条件：

- $1 \leq B \leq A \leq N$
- $\gcd(A,B) = A \oplus B$

其中 $\gcd(A,B)$ 表示 $A$ 和 $B$ 的最大公约数，$A \oplus B$ 表示它们的按位异或（$\texttt{XOR}$）值。

---

## 题目分析

### 初步观察

题目要求：
$$
\gcd(A,B) = A \oplus B
$$

设：
$$
d = \gcd(A,B)
$$
那么 $A = d \cdot m$，$B = d \cdot n$，其中 $\gcd(m,n) = 1$ 且 $m > n \geq 1$。

代入条件：
$$
d = A \oplus B = (d \cdot m) \oplus (d \cdot n)
$$

这里不能直接提取 $d$，因为异或运算不满足分配律。我们需要更深入地推导。

---

### 关键性质推导

设 $g = \gcd(A,B)$，且 $g = A \oplus B$。

由于 $g \mid A$ 且 $g \mid B$，我们可以写出：
$$
A = g \cdot x,\quad B = g \cdot y,\quad \gcd(x,y) = 1,\quad x > y
$$

**重要发现**：  
如果 $x \oplus y = 1$，那么：
$$
(gx) \oplus (gy) = g \cdot (x \oplus y) = g \cdot 1 = g
$$
此时条件成立。

---

### 分析 $x \oplus y = 1$

$x \oplus y = 1$ 意味着 $x$ 和 $y$ 的二进制表示只有最低位不同。  
这等价于：
$$
y = x - 1
$$
因为 $(x) \oplus (x-1) = 1$ 对所有 $x \geq 2$ 成立。

此时：
$$
\gcd(x, x-1) = 1
$$
自动满足。

---

### 得到解的形式

由 $y = x - 1$，$A = gx$，$B = gy$，可得：
$$
A = g \cdot x,\quad B = g \cdot (x - 1)
$$
其中 $x \geq 2$，$g \geq 1$。

条件 $A \leq N$ 即：
$$
g \cdot x \leq N
$$

---

### 常规解法及其弊端

根据上述推导，对于每个 $g \geq 1$，$x$ 可以从 $2$ 取到 $\lfloor N/g \rfloor$，因此：
$$
count(g) = \lfloor N/g \rfloor - 1
$$

总答案为：
$$
ans(N) = \sum_{g=1}^N (\lfloor N/g \rfloor - 1) = \left( \sum_{g=1}^N \lfloor N/g \rfloor \right) - N
$$

这个公式虽然简洁，但在实际应用中存在严重问题：

$1$. **时间复杂度高**：$N$ 最大可达 $3 \times 10^7$，$T$ 最多 $10000$
$2$. **无法直接计算**：即使使用整除分块 $O(\sqrt{N})$ 计算单个 $\sum \lfloor N/g \rfloor$，最坏情况下也需要 $10^4 \times 5500 \approx 5.5 \times 10^7$ 次操作
$3$. **常数因子大**：实际运行可能超时

---

## 优化思路：预处理法

既然无法对每个测试用例单独计算，我们考虑**预处理**所有可能的答案。

### 重新审视解的结构

解的形式为：
$$
A = g \cdot x,\quad B = g \cdot (x - 1)
$$

其中 $x \geq 2$，$g \geq 1$。

观察发现：
- $A - B = g$
- $A \oplus B = g$
- 因此 $A - B = A \oplus B$

这意味着在二进制表示中，$A$ 和 $B$ 的差异恰好在于 $A$ 比 $B$ 多了一个因子 $g$，且没有进位发生。

### 关键优化洞察

对于固定的 $A$，我们可以统计有多少个 $g$ 满足：
- $g$ 是 $A$ 的约数
- $g = A \oplus (A - g)$
- $A - g \geq 1$

通过数学推导可以发现：**当 $g$ 是奇数时**，上述条件自动满足（因为奇数与偶数的异或操作有特殊性质）。

### 巧妙实现

通过的代码采用了以下预处理策略：

```cpp
for (int i = 3; i <= 30000000; i++)
    if ((i ^ (i - 1)) == 1) {
        sum[i]++;
        for (int j = i << 1, k = 2; j <= 30000000; j += i, k++)
            if (k == (j ^ (j - k))) sum[j]++;
    }
```

#### 外层循环逻辑：
- 遍历所有可能的 $g$ 值（从 $3$ 开始）
- 条件 `(i ^ (i - 1)) == 1` 检测 $i$ 是否为奇数
- 对于奇数 $g$，数对 $(g, g-1)$ 本身就是一个解，所以 `sum[g]++`

#### 内层循环逻辑：
- 对于每个奇数 $g$，遍历其倍数 $A = g \cdot x$（$x \geq 2$）
- $j = g \cdot x$，$k = x$
- $B = j - k = gx - x = x(g - 1)$
- 条件 `k == (j ^ (j - k))` 验证 $(j, j-k)$ 是否为解

**数学证明**：对于奇数 $g$ 和任意 $x \geq 2$：
$$
(gx) \oplus (gx - x) = x \cdot (g \oplus (g-1)) = x \cdot 1 = x
$$
且 $\gcd(gx, gx - x) = x \cdot \gcd(g, g-1) = x$（因为 $g$ 是奇数，$\gcd(g,g-1)=1$）。

因此条件总是成立，内层循环实际上可以省略判断条件。

---

## 算法流程

$1$. **预处理阶段**：
   - 对于每个奇数 $g \geq 3$，标记 $(g, g-1)$ 为解
   - 对于每个奇数 $g$ 和 $x \geq 2$，标记 $(gx, gx - x)$ 为解
   - 使用前缀和数组累计答案

$2$. **查询阶段**：
   - 直接输出预处理好的结果

---

## 复杂度分析

- **预处理**：$O(N \log N)$
  - 每个奇数 $g$ 的倍数个数约为 $N/g$
  - 总操作数约为 $\sum_{\text{odd } g} N/g = O(N \log N)$
- **查询**：$O(1)$
- **空间**：$O(N)$

```cpp
#include<stdio.h>
int sum[30000005];
void precompute() {
    for (int i = 3; i <= 30000000; i++)
        if ((i ^ (i - 1)) == 1) {
            sum[i]++;
            for (int j = i << 1, k = 2; j <= 30000000; j += i, k++)
                if (k == (j ^ (j - k))) sum[j]++;
        }
    for (int i = 1; i <= 30000000; i++) sum[i] += sum[i - 1];
}
int main() {
    precompute();
    int T, n;
    scanf("%d", &T);
    for (int t = 1; t <= T; t++) {
        scanf("%d", &n);
        printf("Case %d: %d\n", t, sum[n]);
    }
    return 0;
}
```

## 总结

本题展示了如何通过深入分析数学性质来优化算法：

1. **理论分析**：将 $\gcd(A,B) = A \oplus B$ 转化为 $A = gx$，$B = g(x-1)$ 的形式
2. **常规解法的局限**：直接计算公式在大量查询时效率不足
3. **优化思路**：利用奇数因子的特殊性质，设计高效的预处理算法
4. **实践技巧**：前缀和累计、倍数遍历等优化手段

这种"预处理加查询"的模式在竞赛编程中非常常见，特别适用于多测试用例的场景。
