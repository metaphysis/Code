# 题目描述

给定一个大小为 $a \times b \times c$ 的长方体。长方体由 $a \times b \times c$ 个单位格子组成，需要使用若干个立方体将其中所有未填充的格子恰好覆盖。

每个立方体的边长为正整数 $p$，因此立方体的大小为 $p \times p \times p$。立方体之间可以接触，但不能重叠，并且每个格子必须恰好被一个立方体覆盖。

长方体中有 $m$ 个格子已经被填充，这些格子不能再次被任何立方体覆盖。需要求出所有可能的立方体数量 $n$，并按照升序输出。

# 输入格式

输入包含多组测试数据。

每组测试数据的第一行包含四个整数 $a$、$b$、$c$、$m$，满足：

- $2 \le a,b,c \le 20$；
- $a \times b \times c \le 125$；
- $0 \le m < a \times b \times c$。

接下来有 $m$ 行，每行包含三个整数 $x$、$y$、$z$，表示坐标为 $(x,y,z)$ 的格子已经被填充，其中：

$$
1 \le x \le a,\quad 1 \le y \le b,\quad 1 \le z \le c
$$

输入以一行 `0 0 0 0` 结束。

# 输出格式

对于每组测试数据，输出一行：

```text
Case k: ans1 ans2 ...
```

其中 $k$ 表示测试数据编号，所有可能的立方体数量按照升序输出，每个答案前输出一个空格。

# 样例输入

```text
2 2 3 0
2 2 3 2
1 1 1
2 2 3
0 0 0 0
```

# 样例输出

```text
Case 1: 5 12
Case 2: 10
```

# 题目分析

将长方体中的每个格子看作一个元素。已经填充的格子属于初始占用集合，剩余格子需要被若干个不重叠的轴对齐立方体覆盖。

题目要求输出所有可能的立方体数量，而不是只求最少数量或最多数量。因此，搜索过程中必须保留每种可行方案对应的立方体数量。

长方体最多包含 $125$ 个格子，可以使用两个 $64$ 位整数表示一个格子集合：

- 第 $0$ 位到第 $63$ 位保存在 `low` 中；
- 第 $64$ 位及之后保存在 `high` 中；
- 某一位为 $1$ 表示对应格子已经被占用；
- 某一位为 $0$ 表示对应格子仍未被覆盖。

对于一个立方体，也使用相同的位集合表示。判断立方体能否放置时，只需要判断它的占用掩码是否与当前状态产生交集：

$$
(state.low \mathbin{\&} cube.low) = 0
$$

并且：

$$
(state.high \mathbin{\&} cube.high) = 0
$$

如果两个条件同时成立，说明该立方体没有越界，也没有覆盖已经占用的格子，可以进行放置。

直接按照固定顺序选择第一个未覆盖格子，虽然能够保证不重复搜索，但搜索效率较低。某些格子可能对应很多种立方体，而另一些格子由于障碍物较多，只对应很少的合法立方体。优先处理候选数量最少的格子，可以尽早发现无法继续填充的状态，从而大幅减少搜索分支。

# 解题思路

## 预处理所有立方体

枚举每个格子 $(x,y,z)$，将它作为立方体的起始位置，再枚举边长 $p$。

当立方体满足以下条件时，将其加入候选集合：

$$
p \le a-x
$$

$$
p \le b-y
$$

$$
p \le c-z
$$

对于每个合法立方体，预先计算它覆盖的所有格子的位掩码，并记录该立方体覆盖哪些格子。

数组 `places[i]` 保存所有覆盖格子 $i$ 的立方体编号。这样在搜索时，只需要从 `places[i]` 中枚举候选立方体，不需要重新生成立方体。

## 选择分支最少的格子

对于当前状态，遍历所有尚未占用的格子。

对每个未占用格子，统计能够覆盖它且不会与当前状态冲突的立方体数量。选择合法候选数量最少的格子作为本次搜索位置。

设选中的格子为 $s$。若其合法候选数量为 $0$，说明当前状态无法完成覆盖，直接返回空集合。

若所有格子都已经被占用，说明找到一种完整覆盖方案。此时可以使用 $1$ 个立方体完成当前状态，因此返回只包含数量 $1$ 的结果集合。

## 记忆化搜索

搜索状态由两个位掩码唯一确定，因此使用哈希表 `memo` 记录每个状态可以得到的立方体数量集合。

对于当前选中的格子，依次尝试每个可以覆盖它的立方体。设该立方体覆盖了 $v$ 个格子，放置后得到新状态 `next`。

如果新状态可以使用 $k$ 个立方体完成，那么当前状态可以使用：

$$
k+1
$$

个立方体完成。

由于所有立方体的边长均为正整数，放置一个立方体后至少会占用一个新格子，因此搜索一定会结束。

## 结果集合的位表示

剩余格子数量最多为 $125$，所以可能的答案范围为 $1$ 到 $125$。使用两个 $64$ 位整数保存结果集合：

- `low` 的第 $i$ 位表示是否可以使用 $i$ 个立方体；
- `high` 的第 $i-64$ 位表示是否可以使用 $i$ 个立方体。

递归返回子状态的结果集合后，将整个集合左移一位即可表示当前多使用了一个立方体。

左移操作为：

$$
result.low = child.low \ll 1
$$

$$
result.high = (child.high \ll 1) \mid (child.low \gg 63)
$$

然后将所有分支的结果集合进行按位或合并。

## 正确性证明

首先，预处理过程枚举了每个可能的起始格子和所有合法边长，因此所有可能放置的立方体都会被加入候选集合。

其次，对于任意一个当前未覆盖的格子，它在任何完整覆盖方案中都必须被某个立方体覆盖。搜索会枚举所有覆盖该格子的候选立方体，因此不会遗漏任何合法方案。选择候选数量最少的格子只改变搜索顺序，不会改变可行方案集合。

再次，搜索只会放置不与已占用格子重叠的立方体。初始状态包含所有预先填充的格子，之后每次放置都会将新立方体覆盖的格子加入占用集合，因此任意搜索状态都满足立方体之间不重叠，且不会覆盖预先填充的格子。

最后，当所有格子都被占用时，当前方案已经完成整个长方体的覆盖，并且结果集合中加入了当前使用的立方体数量。所有分支结果经过按位或合并，因此最终结果包含且只包含所有合法覆盖方案对应的立方体数量。

因此，算法能够正确输出所有可能的答案。

## 复杂度分析

设搜索过程中产生的不同状态数量为 $S$，长方体格子总数为：

$$
N = a \times b \times c
$$

设单个格子对应的候选立方体数量上界为 $Q$。

每个状态需要遍历最多 $N$ 个格子，并检查候选立方体，因此时间复杂度为：

$$
O(S \times (N + NQ))
$$

其中 $S$ 在最坏情况下呈指数级增长，但记忆化搜索和最少候选格子策略会显著减少实际搜索状态。

预处理所有立方体需要保存其位掩码以及每个格子对应的候选立方体编号，空间复杂度为：

$$
O(S + C + NQ)
$$

其中 $C$ 表示所有可能立方体的数量。由于 $N \le 125$，位掩码结构可以高效保存状态和立方体信息。

# 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Mask {
    uint64_t low, high;
};

struct Bits {
    uint64_t low, high;
};

struct State {
    uint64_t low, high;
    bool operator == (const State &other) const {
        return low == other.low && high == other.high;
    }
};

struct StateHash {
    size_t operator () (const State &state) const {
        uint64_t value = state.low + 0x9e3779b97f4a7c15ULL;
        value ^= state.high + 0x9e3779b97f4a7c15ULL + (value << 6) + (value >> 2);
        value ^= value >> 30;
        value *= 0xbf58476d1ce4e5b9ULL;
        value ^= value >> 27;
        value *= 0x94d049bb133111ebULL;
        value ^= value >> 31;
        return (size_t)value;
    }
};

int a, b, c, total;
vector<Mask> cubes;
vector<int> places[125];
unordered_map<State, Bits, StateHash> memo;

int getId(int x, int y, int z) {
    return x * b * c + y * c + z;
}

void setBit(Mask &mask, int id) {
    if (id < 64) mask.low |= 1ULL << id;
    else mask.high |= 1ULL << (id - 64);
}

void setBit(State &state, int id) {
    if (id < 64) state.low |= 1ULL << id;
    else state.high |= 1ULL << (id - 64);
}

bool isUsed(const State &state, int id) {
    if (id < 64) return (state.low >> id) & 1ULL;
    return (state.high >> (id - 64)) & 1ULL;
}

bool canPlace(const State &state, const Mask &mask) {
    if ((state.low & mask.low) != 0) return false;
    if ((state.high & mask.high) != 0) return false;
    return true;
}

State putCube(const State &state, const Mask &mask) {
    State next = state;
    next.low |= mask.low;
    next.high |= mask.high;
    return next;
}

Bits shiftBits(const Bits &bits) {
    Bits result;
    result.low = bits.low << 1;
    result.high = (bits.high << 1) | (bits.low >> 63);
    return result;
}

void buildCubes() {
    cubes.clear();
    for (int i = 0; i < 125; i++) places[i].clear();
    for (int x = 0; x < a; x++)
        for (int y = 0; y < b; y++)
            for (int z = 0; z < c; z++) {
                int maxSize = min(a - x, min(b - y, c - z));
                for (int size = 1; size <= maxSize; size++) {
                    Mask mask = {0, 0};
                    for (int dx = 0; dx < size; dx++)
                        for (int dy = 0; dy < size; dy++)
                            for (int dz = 0; dz < size; dz++)
                                setBit(mask, getId(x + dx, y + dy, z + dz));
                    int cubeId = (int)cubes.size();
                    cubes.push_back(mask);
                    for (int dx = 0; dx < size; dx++)
                        for (int dy = 0; dy < size; dy++)
                            for (int dz = 0; dz < size; dz++)
                                places[getId(x + dx, y + dy, z + dz)].push_back(cubeId);
                }
            }
}

Bits search(const State &state, int freeCount) {
    auto it = memo.find(state);
    if (it != memo.end()) return it->second;
    if (freeCount == 0) {
        Bits result = {1, 0};
        memo[state] = result;
        return result;
    }
    int selected = -1, best = INT_MAX;
    for (int cell = 0; cell < total; cell++) {
        if (isUsed(state, cell)) continue;
        int count = 0;
        for (int cubeId : places[cell])
            if (canPlace(state, cubes[cubeId])) count++;
        if (count == 0) {
            Bits result = {0, 0};
            memo[state] = result;
            return result;
        }
        if (count < best) {
            best = count;
            selected = cell;
            if (best == 1) break;
        }
    }
    Bits answer = {0, 0};
    for (int cubeId : places[selected]) {
        const Mask &mask = cubes[cubeId];
        if (!canPlace(state, mask)) continue;
        State next = putCube(state, mask);
        int cubeVolume = __builtin_popcountll(mask.low) + __builtin_popcountll(mask.high);
        Bits child = search(next, freeCount - cubeVolume);
        Bits shifted = shiftBits(child);
        answer.low |= shifted.low;
        answer.high |= shifted.high;
    }
    memo[state] = answer;
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, caseId = 1;
    while (cin >> a >> b >> c >> m) {
        if (a == 0 && b == 0 && c == 0 && m == 0) break;
        total = a * b * c;
        State initial = {0, 0};
        for (int i = 0; i < m; i++) {
            int x, y, z;
            cin >> x >> y >> z;
            setBit(initial, getId(x - 1, y - 1, z - 1));
        }
        buildCubes();
        memo.clear();
        memo.reserve(1 << 18);
        Bits answer = search(initial, total - m);
        cout << "Case " << caseId++ << ":";
        for (int i = 1; i <= total; i++) {
            bool possible;
            if (i < 64) possible = (answer.low >> i) & 1ULL;
            else possible = (answer.high >> (i - 64)) & 1ULL;
            if (possible) cout << " " << i;
        }
        cout << "\n";
    }
    return 0;
}
```

# 总结

本题的核心是将立方体填充过程转化为带障碍的精确覆盖搜索。

关键技巧包括：

- 使用两个 $64$ 位整数压缩最多 $125$ 个格子的占用状态；
- 预处理所有合法立方体的占用掩码；
- 为每个格子保存能够覆盖它的立方体列表；
- 使用记忆化搜索避免重复计算相同状态；
- 每次选择合法候选数量最少的未覆盖格子，降低搜索树规模；
- 使用位集合保存所有可能的立方体数量，并通过左移操作完成数量转移。

这些优化共同保证了程序能够在在线测试数据范围内高效完成搜索。
