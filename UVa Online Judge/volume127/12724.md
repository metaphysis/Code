## 题目分析

这道题描述了一个有趣的**网络现象**：人们喜欢把单词的中间字母打乱，只保留第一个和最后一个字母不变，这样写出来的文字仍然可以读懂。但是，主角 $\texttt{Andre}$ 无法理解这种打乱的文字，需要我们的帮助。

**核心问题**：给定一个正确单词的字典，以及若干行被打乱过的文本（每行由空格分隔的单词组成），需要将每个打乱的单词还原成字典中对应的正确单词。

**关键约束**：
- 每个打乱后的单词在字典中有**且只有一个**匹配的正确单词。
- 单词只包含小写字母，长度不超过 $40$。
- 字典大小 $N \leq 100$，文本行数 $M \leq 20$，每行最多 $50$ 个单词。

## 解题思路

### 1. 匹配规则分析

题目中描述的打乱规则是：**保留第一个和最后一个字母，中间字母随机打乱**。这意味着，对于一个打乱后的单词 $w$ 和字典中的正确单词 $correct$，它们匹配当且仅当满足以下条件：

1. **长度相等**：$|w| = |correct|$
2. **首字母相同**：$w[0] = correct[0]$
3. **尾字母相同**：$w[|w|-1] = correct[|correct|-1]$
4. **中间字母的组成相同**：将 $w$ 去掉首尾后的中间部分排序后，与 $correct$ 去掉首尾后的中间部分排序后相同。

第 4 条是核心，因为打乱只改变顺序，不改变字母的**多集**（$\texttt{multiset}$）。排序是比较两个字符串是否为同一字母多集的最简单方法。

### 2. 算法设计

基于上述匹配规则，我们可以设计如下算法：

#### 步骤 1：预处理字典
对于字典中的每个单词 $dict[i]$：
- 计算其去掉首尾后的中间部分 $mid = dict[i].substr(1, len-2)$
- 对 $mid$ 进行排序，得到 $sortedMid$
- 将 $sortedMid$ 存储起来，供后续匹配时使用

这样，对于每个字典单词，我们只需要计算一次中间部分的排序结果，避免在匹配时重复计算。

#### 步骤 2：处理每一行文本
对于输入中的每一行文本：
- 按空格分割成单词
- 对每个单词 $word$：
  - 遍历字典，找到第一个满足以下条件的 $dict[i]$：
    - 长度相等
    - 首字母相同
    - 尾字母相同
    - $word$ 的中间部分排序后与 $dict[i]$ 的中间部分排序后相同
  - 输出匹配到的正确单词

由于题目保证有唯一匹配，找到第一个即可停止。

### 3. 时间复杂度分析

- 预处理字典：$O(N \cdot L \log L)$，其中 $L$ 是单词平均长度，$L \leq 40$。
- 处理每个单词：最坏情况下需要遍历整个字典，$O(N \cdot L \log L)$。
- 总复杂度：$O(T \cdot (N \cdot L \log L + M \cdot 50 \cdot N \cdot L \log L))$，在给定约束下完全可行。

### 4. 实现细节

- 使用 $\texttt{vector<string>}$ 存储字典和预处理结果。
- 使用 $\texttt{sort}$ 对中间部分排序。
- 注意输入格式：读完 $N$ 和 $M$ 后，要用 $\texttt{cin.ignore()}$ 吸收换行符，否则 $\texttt{getline}$ 会读到空行。
- 输出格式：每个测试用例先输出 `Case  #X:`，然后每行修复后的文本，单词之间用空格分隔。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 计算单词去掉首尾后中间部分排序后的字符串
string middleSorted(const string &s) {
    if (s.length() <= 2) return "";
    string mid = s.substr(1, s.length() - 2);
    sort(mid.begin(), mid.end());
    return mid;
}

int main() {
    int T;
    cin >> T;
    for (int caseNum = 1; caseNum <= T; ++caseNum) {
        int N, M;
        cin >> N >> M;
        vector<string> dict(N);
        for (int i = 0; i < N; ++i) cin >> dict[i];

        // 预处理字典中每个单词的中间部分排序后的结果
        vector<string> midSortedDict(N);
        for (int i = 0; i < N; ++i)
            midSortedDict[i] = middleSorted(dict[i]);

        cout << "Case #" << caseNum << ":\n";

        // 读掉第一行末尾的换行符
        cin.ignore();

        for (int line = 0; line < M; ++line) {
            string lineStr;
            getline(cin, lineStr);
            istringstream iss(lineStr);
            string word;
            bool firstWord = true;
            while (iss >> word) {
                if (!firstWord) cout << ' ';
                firstWord = false;

                // 在字典中找匹配的单词
                for (int i = 0; i < N; ++i) {
                    if (dict[i].length() != word.length()) continue;
                    if (dict[i][0] != word[0]) continue;
                    if (dict[i].back() != word.back()) continue;
                    if (middleSorted(word) != midSortedDict[i]) continue;
                    // 匹配成功
                    cout << dict[i];
                    break;
                }
            }
            cout << '\n';
        }
    }
    return 0;
}
```

## 总结

本题的核心是利用**排序**来比较两个字符串是否为同一字母多集，这是处理打乱、重排类问题的常用技巧。通过预处理字典中的中间部分排序结果，可以避免重复计算，提高匹配效率。输入输出处理时注意换行符的吸收，是这类多行输入问题的常见陷阱。
