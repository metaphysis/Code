[UVa 12729 Squares Game](https://blog.csdn.net/metaphysis/article/details/161728278)

## 题目描述

$\texttt{Ana}$ 和 $\texttt{Bob}$ 在世界毁灭之际依然在玩游戏。游戏在一个 $N$ 行 $M$ 列的矩形棋盘上进行，共有 $N \times M$ 个格子。$\texttt{Ana}$ 先手，她可以选择任意一个由 $2 \times 2$ 未标记格子组成的正方形区域，并将这 $4$ 个格子全部标记。随后 $\texttt{Bob}$ 可以选择任意一个未标记的格子进行标记。如果某玩家没有合法移动，则跳过其回合，直到所有格子都被标记为止。最终标记格子数多者获胜。双方均采用最优策略，若无法获胜则争取平局。

## 输入格式

第一行包含一个整数 $T$（$T \le 10^4$），表示测试用例的数量。接下来 $T$ 行，每行包含两个整数 $N$ 和 $M$（$1 \le N, M \le 100$），分别表示棋盘的行数和列数。

## 输出格式

对于每个测试用例，输出一行 `Case #X: Y`，其中 $X$ 为从 $1$ 开始的编号，$Y$ 为 `Ana`、`Bob` 或 `Draw`，表示在双方最优策略下的游戏结果。

## 样例

输入

```cpp
3
2 3
2 4
3 3
```

输出

```cpp
Case #1: Ana
Case #2: Draw
Case #3: Bob
```

## 题目分析

本题是一个双人零和博弈问题，棋盘规模 $N, M \le 100$，$T \le 10^4$，要求 $O(1)$ 或 $O(\log)$ 的单用例解法。

直接进行博弈树搜索不可行，因为状态空间为 $2^{NM}$ 量级。必须寻找数学规律。

### 关键观察

- $\texttt{Ana}$ 的每次操作占据 $4$ 个格子，且必须是一个完整的 $2 \times 2$ 正方形。
- $\texttt{Bob}$ 的每次操作只占据 $1$ 个格子，位置任意。
- 若棋盘某行或某列无法形成任何 $2 \times 2$ 正方形（即 $N = 1$ 或 $M = 1$），则 $\texttt{Ana}$ 无法进行任何操作，所有格子将被 $\texttt{Bob}$ 占据。
- 当棋盘至少有两行两列时，$2 \times 2$ 正方形才可能存在。

### 博弈结构

可以将棋盘划分为三部分：

1. **核心区**：最大的偶数 $\times$ 偶数子棋盘，尺寸为 $n' \times m'$，其中 $n' = N - (N \bmod 2)$，$m' = M - (M \bmod 2)$。
2. **边缘行**：若 $N$ 为奇数，则最后一行（$1 \times m'$）。
3. **边缘列**：若 $M$ 为奇数，则最后一列（$n' \times 1$）。

核心区可以被完整划分为若干个互不重叠的 $2 \times 2$ 方块，总数为 $k = (n'/2) \times (m'/2)$。每个方块有 $4$ 个格子。

边缘行和边缘列中的格子无法构成任何 $2 \times 2$ 方块，因此 $\texttt{Ana}$ 永远无法标记它们，它们最终全部属于 $\texttt{Bob}$。

## 解题思路

### 核心区争夺

在核心区内，$k$ 个 $2 \times 2$ 方块是双方争夺的对象。关键性质：

- 若一个方块中有一个格子被 $\texttt{Bob}$ 标记，则该方块永远无法被 $\texttt{Ana}$ 使用。
- $\texttt{Ana}$ 必须先手选择一个完整方块标记。
- $\texttt{Bob}$ 每次只能标记一个格子，至多破坏一个方块（若他标记的是某个方块中的一格）。

通过**配对策略**可以证明：$\texttt{Ana}$ 能确保占据 $\lceil k/2 \rceil$ 个完整方块。

**证明思路**：
- 将 $k$ 个方块两两配对。若 $k$ 为奇数，则多出一个方块。
- $\texttt{Ana}$ 先手占据多出的那个方块（若存在）或任意一个方块。
- 此后，无论 $\texttt{Bob}$ 破坏哪个方块，$\texttt{Ana}$ 就在同一配对中占据另一个方块。
- 这样每个配对中 $\texttt{Ana}$ 至少得到一个完整方块，因此总数至少为 $\lceil k/2 \rceil$。

### 格子数计算

设：
- 总格子数 $\textit{total} = N \times M$。
- 核心区方块数 $k = (n'/2) \times (m'/2)$。
- $\texttt{Ana}$ 占据的方块数 $\textit{anaBlocks} = \lceil k/2 \rceil = (k + 1) / 2$（整数除法向上取整）。
- $\texttt{Ana}$ 占据的格子数 $\textit{anaCells} = \textit{anaBlocks} \times 4$。
- $\texttt{Bob}$ 占据的格子数 $\textit{bobCells} = \textit{total} - \textit{anaCells}$。

### 胜负判定

- 若 $\textit{anaCells} > \textit{bobCells}$，输出 `Ana`。
- 若 $\textit{anaCells} = \textit{bobCells}$，输出 `Draw`。
- 若 $\textit{anaCells} < \textit{bobCells}$，输出 `Bob`。

### 边界情况

- 当 $N = 1$ 或 $M = 1$ 时，$n' = 0$ 或 $m' = 0$，核心区大小为 $0$，$\textit{anaCells} = 0$，$\textit{bobCells} = \textit{total}$，$\texttt{Bob}$ 必胜。
- 当 $N, M \ge 2$ 且均为偶数时，$n' = N$，$m' = M$，$k = (N/2) \times (M/2)$。此时 $\textit{anaCells}$ 与 $\textit{bobCells}$ 的关系取决于 $k$ 的奇偶性。

### 复杂度分析

- 时间复杂度：$O(1)$ 每测试用例，总体 $O(T)$。
- 空间复杂度：$O(1)$。

## 代码实现

```cpp
// Squares Game
// UVa ID: 12729
// Verdict: Accepted
// Submission Date: 2026-06-05
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    for (int caseNum = 1; caseNum <= T; ++caseNum) {
        int N, M;
        scanf("%d %d", &N, &M);
        
        int total = N * M;                      // 总格子数
        
        // 核心区：最大的偶数×偶数子棋盘
        int evenN = N - (N % 2);                // N为奇数时减1，偶数不变
        int evenM = M - (M % 2);                // M为奇数时减1，偶数不变
        
        int blockRows = evenN / 2;              // 核心区有多少行2×2方块
        int blockCols = evenM / 2;              // 核心区有多少列2×2方块
        int totalBlocks = blockRows * blockCols; // 核心区2×2方块总数
        
        // 安娜能占的方块数 = 总方块数的一半（向上取整）
        int anaBlocks = (totalBlocks + 1) / 2;
        int anaCells = anaBlocks * 4;            // 安娜标记的格子数
        
        int bobCells = total - anaCells;         // 鲍勃标记的格子数
        
        if (anaCells > bobCells)
            printf("Case #%d: Ana\n", caseNum);
        else if (anaCells == bobCells)
            printf("Case #%d: Draw\n", caseNum);
        else
            printf("Case #%d: Bob\n", caseNum);
    }
    return 0;
}
```

## 总结

本题的核心技巧在于**将棋盘分解为可争夺的核心区与不可争夺的边缘区**，并利用**配对策略**证明 $\texttt{Ana}$ 在核心区内能占据超过半数的 $2 \times 2$ 方块。通过简单的算术运算即可得到最终结果，无需任何搜索或 $\texttt{DP}$。

**关键点总结**：
1. 当棋盘存在单行或单列时，$\texttt{Ana}$ 无法行动，$\texttt{Bob}$ 必胜。
2. 核心区面积为偶数 $\times$ 偶数，可被 $2 \times 2$ 方块完全平铺。
3. 通过配对策略，$\texttt{Ana}$ 能保证获得 $\lceil k/2 \rceil$ 个方块。
4. 边缘区格子全部归 $\texttt{Bob}$，用于平衡核心区的优势。
5. 最终结果由简单的算术比较得出，时间复杂度 $O(1)$。

本题展示了如何将复杂博弈问题转化为数学公式，是分析型解题的典型范例。
