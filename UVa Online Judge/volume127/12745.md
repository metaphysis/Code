## 题目描述

$\texttt{Wismaster}$ 是一个恶魔精灵，他回到了 $\texttt{Byteland}$ 城市来实现市民的愿望。城市里有 $N$ 条路线（编号 $1$ 到 $N$），每条路线需要建造一个设施：要么是天桥（$\texttt{flyover}$），要么是地铁（$\texttt{subway}$），不能同时建两种。有 $M$ 个人，每个人恰好许下两个愿望。一个愿望是在某条路线上建天桥或建地铁。如果 $\texttt{Wismaster}$ 实现了某个人的两个愿望，他就会变成天使，但他想保持恶魔身份，因此需要避免这种情况。给定所有人的愿望，判断是否存在一种建造方案，使得没有任何一个人的两个愿望同时被满足。

## 输入格式

第一行一个整数 $T$（$T \le 100$），表示测试用例数。  
每个测试用例的第一行包含两个整数 $N$（$1 \le N \le 100000$）和 $M$（$0 \le M \le 100000$），分别表示路线数量和人数。  
接下来 $M$ 行，每行两个非零整数 $W_{i1}$ 和 $W_{i2}$（$-N \le W_{i1}, W_{i2} \le N$），表示第 $i$ 个人的两个愿望。  
- 如果 $W_{ij} > 0$，表示希望在第 $W_{ij}$ 条路线上建天桥。  
- 如果 $W_{ij} < 0$，表示希望在第 $|W_{ij}|$ 条路线上建地铁。

## 输出格式

对于每个测试用例，输出一行 `Case X: Yes` 或 `Case X: No`，表示是否存在满足要求的建造方案。

## 样例

输入

```
2
3 5
-1 2
1 3
3 -2
1 -3
-2 -3
4 4
-1 2
1 3
-2 4
-3 -4
```

输出

```
Case 1: No
Case 2: Yes
```

## 题目分析

本题本质上是一个 **约束满足问题**。对于每条路线 $i$，有两种状态：建天桥（记为真）或建地铁（记为假）。每个市民的两个愿望可以看作两个文字（$\texttt{literal}$），其中正数 $w$ 表示文字 $x_w$（建天桥），负数 $w$ 表示文字 $\lnot x_{|w|}$（建地铁）。

约束条件为：不能同时满足一个人的两个愿望。用逻辑表达式表示为：

$$
\lnot (L_1 \land L_2) \quad \Leftrightarrow \quad (\lnot L_1) \lor (\lnot L_2)
$$

这等价于两个蕴含式：

$$
L_1 \rightarrow \lnot L_2, \quad L_2 \rightarrow \lnot L_1
$$

因此，每个市民产生两条有向边：从 $L_1$ 的真节点指向 $\lnot L_2$ 的真节点，从 $L_2$ 的真节点指向 $\lnot L_1$ 的真节点。这就是经典的 **$\texttt{2-SAT}$ 问题**。

## 解题思路

### $\texttt{2-SAT}$ 问题建模

$\texttt{2-SAT}$ 问题是指给定若干个二元逻辑约束（每个约束是两个文字的或），判断是否存在一组变量赋值使得所有约束成立。本题的约束形式为 $(\lnot L_1) \lor (\lnot L_2)$，是 $\texttt{2-SAT}$ 的标准形式。

我们为每个变量 $x_i$（$1 \le i \le N$）建立两个节点：
- 节点 $i$ 表示 $x_i = \texttt{True}$（建天桥）
- 节点 $i + N$ 表示 $x_i = \texttt{False}$（建地铁）

对于每个市民的两个愿望对应的文字 $L_1$ 和 $L_2$，我们添加两条有向边：
- 从 $L_1$ 的真节点到 $\lnot L_2$ 的真节点
- 从 $L_2$ 的真节点到 $\lnot L_1$ 的真节点

其中，文字到节点的映射规则为：
- 若文字为正 $w$，则其真节点为 $w$，其否定（$\lnot w$）的真节点为 $w + N$
- 若文字为负 $w$，则其真节点为 $|w| + N$，其否定（$\lnot w$）的真节点为 $|w|$

### 判定方法

在 $\texttt{2-SAT}$ 的图模型中，如果存在某个变量 $x_i$，使得节点 $i$ 和节点 $i + N$ 在同一个强连通分量（$\texttt{Strongly Connected Component，SCC}$）中，则无解。这是因为在同一 $\texttt{SCC}$ 中的节点必须同时为真，但 $x_i$ 和 $\lnot x_i$ 不能同时为真。否则，可以构造出一组满足所有约束的解。

因此，问题转化为：**在 $2N$ 个节点的有向图中，判断是否存在 $i$ 使得 $i$ 和 $i+N$ 属于同一个 $\texttt{SCC}$**。

### 算法选择

求 $\texttt{SCC}$ 的常用算法有 $\texttt{Kosaraju}$（两次 $\texttt{DFS}$）和 $\texttt{Tarjan}$（一次 $\texttt{DFS}$）。本题中 $N$ 最大为 $100000$，节点数为 $2N$，边数为 $2M$，均在可接受范围内。我们采用 $\texttt{Tarjan}$ 算法，它具有线性时间复杂度 $O(V + E)$，且常数较小。

### 复杂度分析

- 建图：$O(M)$ 边
- $\texttt{Tarjan}$ 算法：$O(N + M)$
- 总时间复杂度：$O(N + M)$，空间复杂度：$O(N + M)$

对于 $T \le 100$ 且 $N, M \le 100000$ 的数据规模，完全可行。

## 代码实现

```cpp
// Wishmaster
// UVa ID: 12745
// Verdict: Accepted
// Submission Date: 2026-06-11
// UVa Run Time: 0.130s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;

int n, m;
vector<int> graph[2 * MAXN];
int dfn[2 * MAXN], low[2 * MAXN], scc[2 * MAXN], stk[2 * MAXN];
bool inStack[2 * MAXN];
int dfsClock, sccCnt, top;

// 将文字转换为节点编号
// 正数 x 表示 x 为真 -> 节点 x
// 负数 x 表示 -x 为真 -> 节点 (-x) + n
inline int litToNode(int x) {
    if (x > 0) return x;
    else return -x + n;
}

// 取反
inline int negNode(int node, int n) {
    if (node <= n) return node + n;
    else return node - n;
}

void tarjan(int u) {
    dfn[u] = low[u] = ++dfsClock;
    stk[++top] = u;
    inStack[u] = true;
    for (int v : graph[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (inStack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (low[u] == dfn[u]) {
        ++sccCnt;
        int v;
        do {
            v = stk[top--];
            inStack[v] = false;
            scc[v] = sccCnt;
        } while (v != u);
    }
}

bool solve() {
    dfsClock = sccCnt = top = 0;
    for (int i = 1; i <= 2 * n; ++i) {
        dfn[i] = low[i] = scc[i] = inStack[i] = 0;
        graph[i].clear();
    }
    for (int i = 0; i < m; ++i) {
        int a, b;
        cin >> a >> b;
        int na = litToNode(a), nb = litToNode(b);
        int notNa = negNode(na, n), notNb = negNode(nb, n);
        // a -> not b
        graph[na].push_back(notNb);
        // b -> not a
        graph[nb].push_back(notNa);
    }
    for (int i = 1; i <= 2 * n; ++i) if (!dfn[i]) tarjan(i);
    for (int i = 1; i <= n; ++i) if (scc[i] == scc[i + n]) return false;
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int T;
    cin >> T;
    for (int cas = 1; cas <= T; ++cas) {
        cin >> n >> m;
        bool ok = solve();
        cout << "Case " << cas << ": " << (ok ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

## 总结

本题的关键点在于：

1. **问题转化**：将“不能同时满足两个愿望”转化为逻辑蕴含式，从而建模为 $\texttt{2-SAT}$ 问题。
2. **图论建模**：每个路线对应两个节点，每个愿望对应一个文字，每个市民产生两条有向边。
3. **强连通分量判定**：利用 $\texttt{Tarjan}$ 算法高效判断冲突的存在性。
4. **数值处理技巧**：通过正负号区分天桥和地铁，用简单的映射函数将文字转换为节点编号。

$\texttt{2-SAT}$ 是一类经典的逻辑约束求解问题，常用于处理“二选一”类型的约束，如本题的每条路线两种建造方式、每个人的两个愿望不能同时成立等。掌握 $\texttt{Tarjan}$ 算法和 $\texttt{2-SAT}$ 的建模方法，能够高效解决类似问题。
