
> **摘要**：本题要求把由数字串描述的火柴人动画还原成字符画——共 $\texttt{10}$ 个固定帧（每帧 $\texttt{3}$ 行 × $\texttt{4}$ 字符），按数字串顺序水平拼接，帧间以单个空格分隔，输出 $\texttt{3}$ 行内容并在每部电影后空一行。核心是纯模拟：预存帧数据、把点号替换为空格、正确处理反斜杠转义，并严格控制行末无多余空格。时间复杂度 $O(M \cdot N)$，实现简洁高效。

## 题目描述

本题需要制作一个正在做运动的火柴人的电影。电影由一系列帧组成，共有 $10$ 个固定的字符帧，编号为 $0$ 到 $9$。每个帧的尺寸为宽 $4$ 字符、高 $3$ 字符。帧中的点（`.`）实际表示空格，其作用仅为占位以显示所有帧具有相同尺寸。

```
0: \./. 	1: .o.. 	2: .... 	3: .... 	4: _o_.
   .|..    	   /|\.        ....        ....        .|..
   /o\.        /.\.        __\o        \_\o        /.\.

5: \o/. 	6: \o_. 	7: \o/. 	8: .... 	9: .o..
   .|..        \|..        \|/.        .__o        (.).
   /.\.        .|..        ....        /..|        /.\.
```

给定若干部电影，每部电影由一个长度不超过 $72$ 的数字串描述，数字串中的每个数字代表该位置使用的帧编号。要求将每部电影的所有帧按顺序水平拼接，帧之间用一个空格分隔，输出拼接后的 $3$ 行内容，并在每部电影输出结束后打印一个空行。

## 输入格式

第一行包含一个整数 $M$（$1 \le M \le 100$），表示电影的数量。  
接下来 $M$ 行，每行一个由十进制数字组成的字符串，长度至少为 $1$ 且不超过 $72$，表示该电影使用的帧序列。

## 输出格式

对于每部电影，输出 $3$ 行，每行是拼接后的帧内容，帧之间用单个空格分隔，行末无多余空格。每个电影的输出后跟一个空行。帧中的点需被替换为实际空格，反斜杠需正确转义输出。

## 样例

### 输入

```
2
171
151415
```

### 输出

```

/|\  \|/  /|\ 
/ \       / \ 

 o   \o/   o   _o_   o   \o/ 
/|\   |   /|\   |   /|\   |  
/ \  / \  / \  / \  / \  / \ 
```

## 题目分析

本题属于纯粹的模拟题型，不涉及复杂算法或数据结构。题目的核心要求是将给定的帧编号序列映射为对应的字符图案，并按固定格式输出。由于帧的数量仅为 $10$ 个，且每个帧的尺寸固定（$3$ 行 $\times$ $4$ 字符），可以直接将所有帧的数据预存储在程序中。

处理过程中需要特别注意两个细节：
- 帧中的点（`.`）在输出时必须显示为空格，而不是字面字符 `.`。
- 反斜杠 `\` 在 $\texttt{C++}$ 字符串字面量中是转义字符，因此存储帧数据时必须使用 `"\\"` 来表示单个反斜杠字符，以保证输出正确。

每个电影的输出必须满足总字符数的精确要求：由于每个帧宽度为 $4$，$N$ 个帧之间共有 $N-1$ 个分隔空格，因此每行总字符数为 $4N + (N-1) = 5N - 1$。该约束在拼接过程中自然满足。

## 解题思路

1. **帧数据的存储与预处理**  
   使用一个二维字符串数组 `frame[10][3]` 存储所有帧的三行内容，其中第一维为帧编号（$0 \sim 9$），第二维为行号（$0 \sim 2$）。将题目给出的帧图案（含点号）直接写入数组，并在读入后立即将每个字符串中的所有点号替换为空格字符。这样在输出时无需额外判断，直接拼接即可。

2. **每部电影的处理流程**  
   - 读取电影的数字串 `seq`，获取其长度 $N$。
   - 初始化三个空字符串 `line0`、`line1`、`line2`，分别对应最终输出的三行。
   - 遍历数字串的每个字符 `seq[i]`，将其转换为整数 `d = seq[i] - '0'`。
   - 对于非首个帧（即 `i > 0`），在三个行字符串末尾各追加一个空格字符，作为帧间分隔。
   - 将 `frame[d][0]`、`frame[d][1]`、`frame[d][2]` 分别追加到 `line0`、`line1`、`line2` 的末尾。
   - 遍历结束后，依次输出 `line0`、`line1`、`line2`，并在最后输出一个空行。

3. **复杂度分析**  
   每部电影的数字串长度 $N \le 72$，电影数量 $M \le 100$，总处理字符数不超过 $7200$。时间复杂度为 $O(M \cdot N)$，空间复杂度为 $O(1)$（不计输出缓冲区）。该复杂度完全满足题目限制。

## 代码实现

```cpp
// Exercising Emoticons
// UVa ID: 12764

// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 10个帧，每个帧3行，每行4个字符（点表示空格）
string frame[10][3] = {
    {"\\./.", ".|..", "/o\\."}, // 0
    {".o..", "/|\\.", "/.\\."}, // 1
    {"....", "....", "__\\o"}, // 2
    {"....", "....", "\\_\\o"}, // 3
    {"_o_.", ".|..", "/.\\."}, // 4
    {"\\o/.", ".|..", "/.\\."}, // 5
    {"\\o_.", "\\|..", ".|.."}, // 6
    {"\\o/.", "\\|/.", "...."}, // 7
    {"....", ".__o", "/..|"}, // 8
    {".o..", "(.).", "/.\\."} // 9
};

int main() {
    // 将帧中的点替换为空格
    for (int i = 0; i < 10; i++)
        for (int j = 0; j < 3; j++)
            for (int k = 0; k < frame[i][j].size(); k++)
                if (frame[i][j][k] == '.')
                    frame[i][j][k] = ' ';
    
    int M;
    cin >> M;
    while (M--) {
        string seq;
        cin >> seq;
        int N = seq.size();
        string line0, line1, line2;
        for (int i = 0; i < N; ++i) {
            int d = seq[i] - '0';
            if (i > 0) { // 帧间加空格
                line0 += ' ';
                line1 += ' ';
                line2 += ' ';
            }
            line0 += frame[d][0];
            line1 += frame[d][1];
            line2 += frame[d][2];
        }
        cout << line0 << '\n';
        cout << line1 << '\n';
        cout << line2 << '\n';
        cout << '\n'; // 每部电影后空行
    }
    return 0;
}
```

本题通过直接存储帧数据并逐帧拼接的方式解决了问题，展现了模拟类题目的典型处理手法。关键技巧包括：
- 将帧中的点号预先替换为空格，避免在输出阶段重复判断。
- 正确使用转义序列 `"\\"` 表示反斜杠字符。
- 严格控制帧间分隔符的添加位置，保证行末无多余空格，从而满足格式要求。

该解法简洁高效，充分利用了题目数据规模小的特点，是处理固定图案拼接问题的标准范式。
