## 题目描述

### 问题定义

在本题中，"阶乘乘积"被定义为**多个个位数字的阶乘相乘**的结果。

例如，表达式 $5! \times 3! \times 4! \times 3!$ 就是一个包含四个因子的阶乘乘积，其中每个阶乘的底数都是个位数字。

给定两个阶乘乘积，需要判断它们是否相等。

### 输入格式

输入包含多个测试用例（最多 $450$ 个）。每个测试用例的格式如下：

- 第一行：两个整数 $N$ 和 $M$（$1 \leq N, M \leq 1,000$），分别表示两个阶乘乘积中因子的个数
- 第二行：$N$ 个数字（$0$ 到 $9$），表示第一个乘积中每个阶乘的底数
- 第三行：$M$ 个数字（$0$ 到 $9$），表示第二个乘积中每个阶乘的底数

输入以一行两个 $0$ 结束。

### 输出格式

对于每个测试用例，输出一行 $\texttt{YES}$ 或 $\texttt{NO}$，表示两个阶乘乘积是否相等。

### 样例输入

```
1 1
9
9
1 2
5
3 6
0 0
```

### 样例输出

```
YES
NO
```

## 题目分析

### 问题本质

本题需要比较两个阶乘乘积是否相等。最直接的想法是分别计算两个乘积的值，然后进行比较。然而，这种方法在实际中不可行，原因如下：

1. **数值过大**：$9! = 362,880$，当多个这样的阶乘相乘时，结果会变得极其庞大，超出任何标准数据类型的表示范围
2. **计算效率**：即使使用高精度计算，对于最多 $2,000$ 个因子（$N + M \leq 2,000$）的情况，计算效率也会很低

### 关键观察

要解决这个问题，我们需要找到一个更聪明的方法来比较两个乘积，而不需要实际计算它们的值。

**核心思路**：两个数相等当且仅当它们的质因数分解完全相同。

对于阶乘乘积，我们可以：
1. 将每个阶乘分解为质因数的乘积
2. 分别累加两个乘积中所有质因数的指数
3. 比较两个乘积的质因数分解结果是否相同

### 数学基础

由于题目中的阶乘底数都是 $0$ 到 $9$ 的数字，我们只需要考虑这些数字的阶乘。重要的是注意到：

- $0! = 1$ 和 $1! = 1$ 对乘积没有影响
- 对于 $n \geq 2$，$n!$ 可以分解为质因数的乘积
- 由于 $n \leq 9$，我们只需要考虑质数 $2$、$3$、$5$、$7$

### 算法设计

1. **预计算**：预先计算 $0$ 到 $9$ 的阶乘的质因数分解（$2$、$3$、$5$、$7$ 的指数）
2. **处理输入**：对于每个测试用例
   - 读取第一个乘积的所有数字，累加对应的质因数指数
   - 读取第二个乘积的所有数字，累加对应的质因数指数
3. **比较结果**：如果两个乘积的质因数分解完全相同，输出 $\texttt{YES}$，否则输出 $\texttt{NO}$

### 复杂度分析

- **预计算**：$O(1)$，因为只需要计算 $10$ 个数字的阶乘分解
- **每个测试用例**：$O(N + M)$，其中 $N$ 和 $M$ 是因子个数
- **总复杂度**：$O(T \cdot (N + M))$，其中 $T$ 是测试用例数量

这种方法高效且不会溢出，完美解决了直接计算可能遇到的问题。

## 解题思路详解

### 步骤 1：预计算阶乘的质因数分解

我们需要为每个数字 $0$ 到 $9$ 计算其阶乘的质因数分解。具体来说，对于每个数字 $n$，我们需要知道 $n!$ 中包含多少个质因数 $2$、$3$、$5$、$7$。

计算方法：
- 对于 $n = 0$ 和 $n = 1$：$0! = 1! = 1$，所有质因数指数都为 $0$
- 对于 $n \geq 2$：$n! = 1 \times 2 \times 3 \times \cdots \times n$，我们可以通过分解每个因子并累加来得到总的质因数指数

更高效的方法是使用递推关系：
- $n!$ 的质因数分解 = $(n-1)!$ 的质因数分解 + $n$ 的质因数分解

### 步骤 2：处理输入数据

对于每个测试用例：
1. 读取 $N$ 和 $M$
2. 初始化两个数组 $\texttt{totalA}$ 和 $\texttt{totalB}$，分别记录两个乘积的质因数指数
3. 读取第一个乘积的 $N$ 个数字，对于每个数字 $d$：
   - 如果 $d \leq 1$，跳过（因为 $0! = 1! = 1$ 不影响乘积）
   - 否则，将预计算的 $d!$ 的质因数指数加到 $\texttt{totalA}$ 中
4. 读取第二个乘积的 $M$ 个数字，同样处理并更新 $\texttt{totalB}$

### 步骤 3：比较结果

比较 $\texttt{totalA}$ 和 $\texttt{totalB}$ 是否完全相等：
- 如果相等，输出 $\texttt{YES}$
- 否则，输出 $\texttt{NO}$

### 为什么这种方法有效？

根据算术基本定理，每个大于 $1$ 的自然数都可以唯一地分解为质因数的乘积。因此，两个数相等当且仅当它们的质因数分解完全相同。通过比较质因数指数，我们实际上是在比较两个乘积的"数学本质"，而不需要计算它们的具体数值。

```cpp
// Factorial Products

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

// 预计算 0~9 的阶乘的质因数分解（2, 3, 5, 7 的指数）
vector<vector<int>> precomputeFactorialFactors() {
    vector<vector<int>> factors(10, vector<int>(4, 0)); // 索引 0~9，每个有 4 个质数指数
    for (int n = 2; n <= 9; ++n) {
        int num = n;
        // 分解 num
        for (int p : {2, 3, 5, 7}) {
            while (num % p == 0) {
                factors[n][p == 2 ? 0 : (p == 3 ? 1 : (p == 5 ? 2 : 3))]++;
                num /= p;
            }
        }
    }
    // 计算 n! 的质因数分解
    for (int n = 2; n <= 9; ++n) {
        for (int i = 0; i < 4; ++i) {
            factors[n][i] += factors[n - 1][i];
        }
    }
    return factors;
}

int main() {
    auto factors = precomputeFactorialFactors();
    int n, m;
    
    while (cin >> n >> m) {
        if (n == 0 && m == 0) break;
        
        vector<int> totalA(4, 0); // 2,3,5,7 的指数
        vector<int> totalB(4, 0);
        
        // 读取第一个乘积
        for (int i = 0; i < n; ++i) {
            int digit;
            cin >> digit;
            if (digit <= 1) continue; // 0! = 1! = 1，不影响
            for (int j = 0; j < 4; ++j) {
                totalA[j] += factors[digit][j];
            }
        }
        
        // 读取第二个乘积
        for (int i = 0; i < m; ++i) {
            int digit;
            cin >> digit;
            if (digit <= 1) continue;
            for (int j = 0; j < 4; ++j) {
                totalB[j] += factors[digit][j];
            }
        }
        
        // 比较质因数指数
        if (totalA == totalB) {
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    }
    
    return 0;
}
```

## 总结

本题通过质因数分解的方法，巧妙地避免了直接计算大数的问题。关键在于认识到：

1. 不需要计算具体的乘积值，只需要比较它们的数学本质
2. 利用算术基本定理，通过比较质因数分解来判断两个数是否相等
3. 预计算技术可以显著提高效率

这种思路在很多涉及大数比较的问题中都有应用，是一个很有用的技巧。
