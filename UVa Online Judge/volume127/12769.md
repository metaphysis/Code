## 题目描述

市议会希望增加主要街道上建筑物的高度以吸引更多商业，但担心建设过快会导致资金耗尽，因此他们计划分阶段建设。

假设街道长度为 $n$ 个单位，每个建筑物宽度为 $1$ 个单位。在每个阶段，议会会选择两个端点（$1 \leq a \leq b \leq 100,000$），并将区间 $[a, b]$ 内每栋建筑物的高度增加 $y$ 个单位。例如，下面是变更前后的城市天际线：$a=2, b=10, y=1$。

随时间推移，跟踪建筑物高度变得相当复杂，因此需要你的帮助。

## 输入格式

输入文件最多包含 $8$ 个测试用例。每个测试用例的第一行是一个正整数 $T$，表示指令数量。接下来的 $T$ 行（$T \leq 100,000$）是以下两种格式之一：

- `B a b y`：建造指令 —— 将区间 $[a, b]$ 内每栋建筑的高度增加 $y$ 单位。
- `Q a`：查询指令 —— 输出此时建筑 $a$ 的高度。

输入行总是合法的，即 $1 \leq a \leq b \leq 100,000$。$y$ 是正整数，最多为 $1,000$。假设在第一个阶段之前，所有建筑的高度均为 $0$。输入以 $T=0$ 结束。

## 输出格式

对于每个测试用例的每个查询指令，在一行中输出指定建筑的高度。

## 样例

输入

```
9
B 5 5 2
B 8 8 2
B 10 13 1
Q 8
B 8 13 1
Q 8
B 15 16 1
B 2 10 1
Q 8
0
```

输出

```
2
3
4
```

## 题目分析

本题的核心是：维护一个长度为 $100,000$ 的数组（初始全为 $0$），支持两种操作：

1. **区间加**：将区间 $[a, b]$ 内的所有元素增加 $y$。
2. **单点查询**：查询位置 $a$ 的当前值。

直接模拟：对于每个 `B` 指令，遍历区间 $[a, b]$ 逐个增加，时间复杂度为 $O(T \cdot n)$，其中 $n$ 为区间长度，最坏情况下 $n=10^5$，$T=10^5$，总操作量可达 $10^{10}$，不可接受。

我们需要一种支持**高效区间更新和单点查询**的数据结构。

## 解题思路

### 差分数组 + 前缀和

差分数组的思想：设原数组为 $\textit{height}[1..n]$，定义差分数组 $\textit{diff}[i] = \textit{height}[i] - \textit{height}[i-1]$（约定 $\textit{height}[0]=0$）。那么：

- 对原数组区间 $[a, b]$ 增加 $y$，等价于：
  - $\textit{diff}[a] \ += y$
  - $\textit{diff}[b+1] \ -= y$
- 查询原数组位置 $a$ 的值，等价于求 $\textit{diff}[1..a]$ 的前缀和：$\textit{height}[a] = \sum_{i=1}^{a} \textit{diff}[i]$

这样，每次更新是 $O(1)$ 的，但查询需要 $O(n)$ 计算前缀和，当查询很多时仍会超时。

### 树状数组（$\texttt{Fenwick Tree}$）

树状数组支持**单点加**和**前缀和查询**，均为 $O(\log n)$。结合差分思想：

- **区间加 $[a, b]$ 增加 $y$**：执行两次单点加：`add(a, y)` 和 `add(b+1, -y)`
- **单点查询 $a$**：执行前缀和查询 `sum(a)`

这样每次操作均为 $O(\log N)$，$N=100,000$，总复杂度 $O(T \log N)$，完全可接受。

### 算法流程

1. 初始化大小为 $100,002$ 的树状数组（因为 $b+1$ 可能等于 $100,001$）。
2. 对于每个测试用例：
   - 读入 $T$，若 $T=0$ 则结束。
   - 循环 $T$ 次：
     - 读入指令类型。
     - 若为 `B`，读入 $a,b,y$，执行 `add(a, y)` 和 `add(b+1, -y)`。
     - 若为 `Q`，读入 $a$，输出 `sum(a)`。
3. 每个测试用例结束后，重置树状数组（或直接覆盖）。

### 复杂度分析

- 时间复杂度：每个操作 $O(\log N)$，总操作次数 $T \leq 10^5$，故总复杂度 $O(T \log N)$。
- 空间复杂度：$O(N)$，$N=100,002$。

## 代码实现

```cpp
// Kool Konstructions
// UVa ID: 12769
// Verdict: Accepted
// Submission Date: 2026-06-04
// UVa Run Time: 0.080s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 100002;

int bit[MAX_N]; // 树状数组

// 单点加
void add(int idx, int val) {
    while (idx < MAX_N) {
        bit[idx] += val;
        idx += idx & -idx;
    }
}

// 前缀和
int sum(int idx) {
    int res = 0;
    while (idx > 0) {
        res += bit[idx];
        idx -= idx & -idx;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    while (cin >> T && T != 0) {
        memset(bit, 0, sizeof(bit)); // 每个测试用例重置树状数组
        
        while (T--) {
            char op;
            cin >> op;
            
            if (op == 'B') {
                int a, b, y;
                cin >> a >> b >> y;
                add(a, y);
                add(b + 1, -y);
            } else { // op == 'Q'
                int a;
                cin >> a;
                cout << sum(a) << '\n';
            }
        }
    }
    
    return 0;
}
```

## 总结

本题的关键点在于：

1. **将区间更新转化为差分数组的两个单点更新**，再通过树状数组维护前缀和。
2. **树状数组**是实现单点加和前缀和的高效工具，代码简洁且常数小。
3. 注意边界：$b+1$ 可能超出 $n$，因此树状数组大小需要设为 $n+2$。

这类“区间加、单点查询”问题是树状数组的经典应用场景。如果问题变为“区间加、区间查询”，则需要使用两个树状数组或线段树。掌握差分思想与树状数组的结合，可以高效解决许多区间维护问题。
