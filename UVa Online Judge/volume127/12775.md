## 题目分析

本题是一道经典的**三元线性丢番图方程非负整数解计数**问题。题目背景是 $\texttt{Sheldon}$ 需要购买三种商品（魔方、口琴和巧克力），价格分别为 $A$, $B$, $C$，恰好花费总价 $P$。我们需要计算方程 $xA + yB + zC = P$ 的非负整数解 $(x, y, z)$ 的数量。

### 关键约束条件

题目给出了一个重要条件：$\frac{C}{\gcd(A,B,C)} \geq 200$。这个条件暗示 $C$ 相对于三者的最大公约数来说比较大，这为我们提供了算法优化的方向。

### 数学化简

1. **最大公约数化简**：
   设 $g = \gcd(A,B,C)$，如果 $P$ 不能被 $g$ 整除，则方程无解。
   否则，令：
   $$
   A' = \frac{A}{g},\quad B' = \frac{B}{g},\quad C' = \frac{C}{g},\quad P' = \frac{P}{g}
   $$
   原方程简化为：$xA' + yB' + zC' = P'$

2. **进一步化简**：
   设 $d = \gcd(A',B')$，令：
   $$
   A'' = \frac{A'}{d},\quad B'' = \frac{B'}{d}
   $$
   方程变为：$xA'' + yB'' + zC' = \frac{P'}{d}$（但这里要小心处理）

### 核心优化思路

直接枚举三个变量会超时，我们利用 $C'$ 较大的特性：

- 枚举 $z$ 从 $0$ 到 $\lfloor P'/C' \rfloor$
- 对于每个 $z$，解方程：$xA' + yB' = R$，其中 $R = P' - zC'$
- 使用数论方法快速计算该二元方程的非负整数解数量

### 二元方程解法

对于方程 $xA'' + yB'' = R''$，其中 $\gcd(A'',B'') = 1$：

1. 使用扩展欧几里得算法求 $A''X + B''Y = 1$ 的解
2. 计算 $x_0 = (R'' \bmod B'') \cdot X \bmod B''$
3. 解的数量为：$\max\left(0, \left\lfloor \frac{\lfloor R''/A''\rfloor - x_0}{B''} \right\rfloor + 1\right)$

## 算法步骤

1. 计算 $g = \gcd(A,B,C)$，检查 $P$ 是否能被 $g$ 整除
2. 对价格和总价进行归一化处理
3. 计算 $A', B'$ 的最大公约数 $d$ 及其相关量
4. 预处理 $A''$ 在模 $B''$ 下的逆元
5. 枚举 $z$，对每个 $z$ 使用数论方法计算解的数量
6. 累加所有 $z$ 对应的解数

## 复杂度分析

- 时间复杂度：$O\left(\frac{P}{C}\right)$，由于 $C$ 较大，实际运行很快
- 空间复杂度：$O(1)$

```cpp
#include <bits/stdc++.h>
using namespace std;
// 计算最大公约数
long long computeGcd(long long a, long long b) {
    while (b != 0) {
        long long temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
// 扩展欧几里得算法，求解 ax + by = gcd(a, b)
void extendedGcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return;
    }
    extendedGcd(b, a % b, y, x);
    y -= a / b * x;
}
// 计算 a 在模 m 下的逆元，要求 gcd(a, m) = 1
long long modularInverse(long long a, long long m) {
    long long x, y;
    extendedGcd(a, m, x, y);
    return (x % m + m) % m;
}
int main() {
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(false);
    int testCases; cin >> testCases;
    for (int caseNum = 1; caseNum <= testCases; caseNum++) {
        long long priceA, priceB, priceC, totalPrice;
        cin >> priceA >> priceB >> priceC >> totalPrice;
        // 计算最大公约数并检查是否有解
        long long gcdABC = computeGcd(computeGcd(priceA, priceB), priceC);
        if (totalPrice % gcdABC != 0) {
            cout << "Case " << caseNum << ": 0\n";
            continue;
        }
        // 归一化处理
        priceA /= gcdABC; priceB /= gcdABC; priceC /= gcdABC; totalPrice /= gcdABC;
        // 计算 A 和 B 的最大公约数
        long long gcdAB = computeGcd(priceA, priceB);
        long long normalizedA = priceA / gcdAB, normalizedB = priceB / gcdAB;
        // 预处理逆元
        long long inverseA = modularInverse(normalizedA, normalizedB);
        long long solutionCount = 0;
        // 枚举 z 的可能取值
        for (long long z = 0; z * priceC <= totalPrice; z++) {
            long long remaining = totalPrice - z * priceC;
            // 检查剩余金额是否能被 gcdAB 整除
            if (remaining % gcdAB != 0) continue;
            long long reducedRemaining = remaining / gcdAB;
            // 计算特解 x0
            long long remainder = reducedRemaining % normalizedB;
            long long x0 = (remainder * inverseA) % normalizedB;
            // 计算 x 的最大可能值
            long long maxX = reducedRemaining / normalizedA;
            // 如果特解超出范围，则无解
            if (x0 > maxX) continue;
            // 计算解的数量
            long long count = (maxX - x0) / normalizedB + 1;
            if (count > 0) solutionCount += count;
        }
        cout << "Case " << caseNum << ": " << solutionCount << "\n";
    }
    return 0;
}
```

## 总结

本题通过数学化简和数论技巧，将三元方程转化为二元方程求解，利用 $C$ 较大的特性优化枚举过程。核心在于使用扩展欧几里得算法和模逆元来快速计算二元线性丢番图方程的非负整数解数量。算法在给定的约束条件下高效可靠，能够处理大范围输入数据。
