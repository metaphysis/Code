## 题目描述

爱丽丝发现了一个奇特的现象：当她说出一个数字时，别人可能会将其理解成它的镜像。例如，说 “$51$” 可能被理解为 “$15$”，说 “$43$” 可能被理解为 “$34$”。为了避免这种误解，她决定只说出那些在某种进制下呈回文形式的数字——因为回文数从左往右读和从右往左读是一样的，不会产生歧义。

给定一个十进制整数 $n$（$1 \leq n \leq 10^6$），要求找到最小的进制 $b \geq 2$，使得 $n$ 在 $b$ 进制下的表示是一个回文数。如果不存在这样的 $b$，则输出 $0$。

### 输入格式

输入包含多个测试用例，每行一个整数 $n$。

### 输出格式

对于每个测试用例，输出一行：最小的满足条件的进制 $b$，如果不存在则输出 $0$。

### 样例输入

```
51
43
7
19
```

### 样例输出

```
2
6
2
18
```

### 样例解释

- $51_{10} = 110011_2$，是回文，进制为 $2$。
- $43_{10} = 111_6$，是回文，进制为 $6$。
- $7_{10} = 111_2$，是回文，进制为 $2$。
- $19_{10} = 11_{18}$，是回文，进制为 $18$。

---

## 题目分析

### 问题的本质

这是一个“进制转换 + 回文判定”的问题。我们需要对每个 $n$ 从小到大枚举进制 $b$，检查 $n$ 在 $b$ 进制下的数字序列是否构成回文。

### 解的存在性

对于任意 $n \geq 2$，取 $b = n-1$：

$$n = 1 \cdot (n-1) + 1$$

在 $n-1$ 进制下，$n$ 的表示为 $"11"$，这是一个两位回文数。因此对于所有 $n \geq 2$，至少存在一个解 $b = n-1$。对于 $n = 1$，它在任何进制下都是一位数字，也是回文，最小进制为 $2$。

所以答案永远不会是 $0$（原题描述中“如果不存在则输出 0”实际上不会发生，但保留这一输出规则以符合题意）。

### 直接枚举的瓶颈

最直接的想法是：从 $b = 2$ 开始，依次检查到 $b = n-1$。对于每个 $b$，判断回文需要 $O(\log_b n)$ 的时间，总复杂度为：

$$\sum_{b=2}^{n-1} O(\log_b n) \approx O(n \log n)$$

当 $n = 10^6$ 时，这个复杂度大约在 $10^7$ 量级，虽然理论上可接受，但实际运行时间约为 $600$-$700$ 毫秒，在在线评测系统中属于较慢的实现。

---

## 优化思路

### 核心观察：进制分界点 $\sqrt{n}$

设 $k$ 为 $n$ 在 $b$ 进制下的位数。当 $b > \sqrt{n}$ 时，$k \leq 2$，因为：

$$b^2 > n \Rightarrow \text{位数} \leq 2$$

这意味着我们可以将进制分为两类分别处理：

#### 第一类：$b \leq \sqrt{n}$（小进制）

此时位数较多，直接模拟进制转换并判断回文即可。由于 $b$ 最多只有 $\sqrt{n} \approx 1000$ 个，这部分的总复杂度为 $O(\sqrt{n} \cdot \log n)$，约 $2 \times 10^4$ 次操作。

#### 第二类：$b > \sqrt{n}$（大进制）

此时 $n$ 在 $b$ 进制下最多有 2 位。设：

$$n = a \cdot b + c$$

回文要求 $a = c$，因此：

$$n = a \cdot b + a = a(b+1)$$

且必须满足 $1 \leq a < b$。整理得：

$$b = \frac{n}{a} - 1$$

对于每个 $a$，如果 $n$ 能被 $a$ 整除，则计算 $b$，并检查是否满足 $b > \sqrt{n}$ 且 $a < b$。由于 $a$ 的范围是 $1 \leq a \leq \sqrt{n}$（因为当 $a > \sqrt{n}$ 时，$b = n/a - 1 < \sqrt{n}$，会落入第一类），我们只需枚举 $a$ 从 1 到 $\sqrt{n}$ 即可。

### 优化效果对比

| 方法 | 枚举范围 | 时间复杂度 | $n=10^6$ 时操作数 |
|------|----------|------------|-------------------|
| 直接枚举 | $b = 2 \sim n-1$ | $O(n \log n)$ | $\approx 2 \times 10^7$ |
| 分界优化 | $b \leq \sqrt{n}$ + $a \leq \sqrt{n}$ | $O(\sqrt{n} \log n)$ | $\approx 2 \times 10^4$ |

优化后的操作数减少到原来的千分之一，运行时间从约 $670$ 毫秒降至 $1$ 毫秒以内。

## 算法步骤

1. 读取整数 $n$。
2. 处理边界情况：
   - 若 $n = 1$，输出 $2$。
   - 若 $n = 2$，输出 $3$。
3. 计算分界点 $limit = \lfloor \sqrt{n} \rfloor$。
4. **第一类**：枚举 $b$ 从 $2$ 到 $limit$：
   - 将 $n$ 转换为 $b$ 进制，判断是否为回文。
   - 若是，输出 $b$ 并结束。
5. **第二类**：枚举 $a$ 从 $limit$ 到 $1$（从大到小枚举是为了优先找到更小的 $b$？注意：$b = n/a - 1$，$a$ 越大 $b$ 越小，所以应从大到小枚举 $a$）：
   - 若 $n \% a \neq 0$，跳过。
   - 计算 $b = n / a - 1$。
   - 若 $b > limit$ 且 $a < b$，输出 $b$ 并结束。
6. 理论上不会执行到这一步，但作为安全返回，输出 $n-1$。

## 回文判定函数

对于小进制的情况，使用数组存储每一位数字，然后双指针比较：

```cpp
bool isPalindrome(int n, int b) {
    int digits[32], len = 0;
    while (n > 0) {
        digits[len++] = n % b;
        n /= b;
    }
    for (int i = 0; i < len / 2; ++i)
        if (digits[i] != digits[len - 1 - i]) return false;
    return true;
}
```

## 时间复杂度分析

- **第一类循环**：最多 $\sqrt{n}$ 次迭代，每次迭代转换的位数最多为 $\log_2 n \approx 20$，总操作数 $O(\sqrt{n} \log n)$。
- **第二类循环**：最多 $\sqrt{n}$ 次迭代，每次迭代只做常数次取模、除法和比较，总操作数 $O(\sqrt{n})$。
- **总体**：$O(\sqrt{n} \log n)$，对于 $n \leq 10^6$ 完全可行。

---

## 空间复杂度分析

仅使用了常数个变量和一个大小为 $32$ 的临时数组（因为 $2$ 进制下 $10^6$ 的位数不超过 $20$），空间复杂度 $O(1)$。

## 正确性证明

**引理 1**：对于任意整数 $n \geq 2$，$b = n-1$ 进制下 $n$ 的表示一定是回文数。

证明：$n = 1 \cdot (n-1) + 1$，在 $n-1$ 进制下表示为 $"11"$，是两位回文数。$\square$

**引理 2**：当 $b > \sqrt{n}$ 时，$n$ 在 $b$ 进制下的位数 $k \leq 2$。

证明：若 $k \geq 3$，则 $n \geq b^2 > n$，矛盾。$\square$

由引理 2，将进制分为 $b \leq \sqrt{n}$ 和 $b > \sqrt{n}$ 两类是完备的。第一类直接模拟，第二类通过枚举 $a$ 求解，覆盖了所有可能。由引理 1，解一定存在，算法必然返回一个结果。

## 参考代码

```cpp
// Looking-Glass House

#include <bits/stdc++.h>
using namespace std;

// 判断 n 在 b 进制下是否为回文（b <= sqrt(n) 时使用）
bool isPalindrome(int n, int b) {
    int digits[32], len = 0;
    while (n > 0) {
        digits[len++] = n % b;
        n /= b;
    }
    for (int i = 0; i < len / 2; ++i)
        if (digits[i] != digits[len - 1 - i]) return false;
    return true;
}

int smallestBase(int n) {
    if (n == 1) return 2;
    if (n == 2) return 3;
    
    int limit = sqrt(n);
    
    // 第一类：枚举小进制 b <= sqrt(n)
    for (int b = 2; b <= limit; ++b)
        if (isPalindrome(n, b)) return b;
    
    // 第二类：枚举大进制 b > sqrt(n)，此时 n = a*(b+1)
    // b = n/a - 1，需要 b > limit 且 a < b
    for (int a = limit; a >= 1; --a) {
        if (n % a == 0) {
            int b = n / a - 1;
            if (b > limit && a < b) return b;
        }
    }
    
    // 理论上不会到这里，因为 b = n-1 总是解
    return n - 1;
}

int main() {
    int n;
    while (cin >> n) {
        cout << smallestBase(n) << endl;
    }
    return 0;
}
```

## 总结

本题的核心在于理解“回文数在不同进制下的表示”这一概念，并通过**数学分类优化**将枚举范围从 $O(n)$ 降至 $O(\sqrt{n})$。

### 关键点回顾

| 知识点 | 说明 |
|--------|------|
| 解的存在性 | $b = n-1$ 时表示为 $"11"$，保证有解 |
| 分界点 $\sqrt{n}$ | 当 $b > \sqrt{n}$ 时位数 $\leq 2$，可分类讨论 |
| 小进制处理 | 直接模拟转换并判断回文 |
| 大进制处理 | 转化为 $n = a(b+1)$，枚举 $a$ 求解 |
| 边界情况 | $n = 1$ 和 $n = 2$ 需特殊处理 |

### 时间复杂度对比

- **朴素枚举**：$O(n \log n)$，约 $2 \times 10^7$ 次操作，耗时约 $670$ 毫秒
- **分类优化**：$O(\sqrt{n} \log n)$，约 $2 \times 10^4$ 次操作，耗时约 $1$ 毫秒

这种“根据位数分界”的优化思想，在进制、根号相关的问题中非常常见，值得掌握。
