## 题目描述

给定一个整数数组 $a_1, a_2, \ldots, a_n$ ，定义其 **平滑因子** 为：最长的连续子数组 $a_p, \ldots, a_q$ 的长度，其中至多存在一个位置 $i$ （ $p < i \leq q$ ）满足 $a_{i-1} > a_i$ 。换句话说，该子数组要么是完全非递减的，要么只包含一次“下降”。

要求对于多个测试用例，分别输出每个数组的平滑因子。

**输入格式**
- 多个测试用例，每个用例两行。
- 第一行：整数 $n$ （ $1 \leq n \leq 10^5$ ）。
- 第二行： $n$ 个整数 $a_1, \ldots, a_n$ （ $0 \leq |a_i| < 10^8$ ）。

**输出格式**
- 每个测试用例一行，输出对应数组的平滑因子。

**样例输入**
```
3
1 2 3
1
0
8
1 2 1 2 1 2 3 1
4
1 -10 -100 -100
```

**样例输出**
```
3
1
5
3
```

## 题目分析

本题要求寻找满足“至多包含一次下降”的最长连续子数组的长度。这里的“下降”指的是 $a_{i-1} > a_i$ 。换句话说，在子数组中，最多只能有一个位置使得前一个元素大于后一个元素。

### 关键点
1. **连续性**：子数组必须是原数组的连续一段。
2. **至多一次下降**：允许 $0$ 次或 $1$ 次下降。
3. **高效计算**： $n$ 最大可达 $10^5$ ，需要 $O(n)$ 或 $O(n \log n)$ 的算法。

### 思路推导

我们可以将问题转化为一个 **滑动窗口** 问题：
- 维护一个窗口 $[left, right]$ 。
- 用计数器 $dropCount$ 记录窗口内下降的次数。
- 当 $dropCount \leq 1$ 时，窗口有效，可以扩展右边界。
- 当 $dropCount > 1$ 时，窗口无效，需要移动左边界直到 $dropCount \leq 1$ 。
- 在移动左边界时，如果移出的位置原本是一个下降点，则 $dropCount$ 需要减 $1$ 。
- 每次窗口有效时，用当前窗口长度更新答案。

这样，我们通过一次遍历就能找到最长满足条件的子数组。

---

## 算法步骤

1. 初始化 $left = 0$ ， $maxLen = 1$ （至少长度为 $1$ ）， $dropCount = 0$ 。
2. 遍历右边界 $right$ 从 $1$ 到 $n-1$ ：
   - 判断 $a[right-1] > a[right]$ ？如果是，则 $dropCount$ 加 $1$ 。
   - 当 $dropCount > 1$ 时：
     - 若 $a[left] > a[left+1]$ ，则 $dropCount$ 减 $1$ 。
     - $left$ 加 $1$ 。
   - 计算当前窗口长度 $right - left + 1$ ，更新 $maxLen$ 。
3. 输出 $maxLen$ 。

**时间复杂度**： $O(n)$ ，每个元素至多被访问两次。
**空间复杂度**： $O(1)$ （不计输入数组）。

## 代码实现

```cpp
// Smooth Factor
// UVa ID: 12788
// Verdict: Accepted
// Submission Date: 2025-12-15
// UVa Run Time: 0.010s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    while (cin >> n) {
        vector<int> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];

        int left = 0, maxLen = 1; // 至少长度为1
        int dropCount = 0; // 窗口中下降的次数

        for (int right = 1; right < n; ++right) {
            // 判断 right 是否为下降点
            if (a[right - 1] > a[right]) dropCount++;

            // 如果下降次数超过1，移动左边界直到满足条件
            while (dropCount > 1) {
                // 如果 left 是下降点，移出窗口时减少计数
                if (a[left] > a[left + 1]) dropCount--;
                left++;
            }

            // 更新最大长度
            maxLen = max(maxLen, right - left + 1);
        }

        cout << maxLen << "\n";
    }

    return 0;
}
```

## 示例分析

以样例 `1 2 1 2 1 2 3 1` 为例：
- 最长满足条件的子数组为 `1 2 1 2 3` ，长度为 $5$ 。
- 其中只有一次下降（ $2 > 1$ ），其余位置均非递减。

算法过程：
- 窗口滑动过程中，当遇到第二次下降时（例如 $3 > 1$ ），左边界移动，直到窗口中只保留一次下降，从而找到最长窗口。

## 总结

本题通过 **滑动窗口** 维护一个至多包含一次下降的连续子数组，在 $O(n)$ 时间内求解。关键在于用 $dropCount$ 记录下降次数，并通过移动左边界保持条件成立。代码简洁高效，适用于大数据范围。
