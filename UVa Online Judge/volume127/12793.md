## 题目概述

银河邦联为优化资源管理，将空间划分为多个区域。划分方式是使用 $M$ 个平面切割空间，形成若干区域（有些无限大，有些有限）。已知行星轨道不会与任何平面相交，因此每颗行星始终处于同一区域内。给定 $M$ 个平面方程（形式为 $Ax + By + Cz = D$ ）和 $N$ 颗行星的三维坐标，要求找出**包含最多行星的区域**中的行星数量。

**输入**  
- 多组测试数据。
- 每组第一行： $M$ （平面数， $1 \leq M \leq 500$ ）和 $N$ （行星数， $1 \leq N \leq 10000$ ）。
- 接下来 $M$ 行：每行四个整数 $A, B, C, D$ （ $-10000 \leq A, B, C, D \leq 10000$ ），表示平面方程系数。
- 接下来 $N$ 行：每行三个整数 $X, Y, Z$ （ $-10000 \leq X, Y, Z \leq 10000$ ），表示行星坐标。

**输出**  
对于每组数据，输出一个整数，表示**包含最多行星的区域**中的行星数量。

---

## 问题分析

### 核心思路

每一个平面 $Ax + By + Cz = D$ 将整个三维空间划分为两个**半空间**：  
- 满足 $Ax + By + Cz > D$ 的点在平面的“正侧”  
- 满足 $Ax + By + Cz \leq D$ 的点在平面的“负侧”（包含平面上）

一颗行星 $(X, Y, Z)$ 相对于每个平面都有一个“侧向”关系。由于行星不会穿过平面，它在整个运行期间与每个平面的相对关系保持不变。因此，**所有 $M$ 个平面对该行星的“正/负”判定组合，唯一确定了它所在的区域**。

换句话说，我们可以用一个长度为 $M$ 的**二进制串**来表示一个区域：
- 对于第 $j$ 个平面（ $0 \leq j < M$ ），若行星在该平面正侧，则对应位为 `'1'` ，否则为 `'0'` 。

于是：
1. 同一区域内的所有行星，其对应的二进制串完全相同。
2. 不同区域的二进制串不同。

因此，问题转化为：
- 为每颗行星计算其对应的二进制串（ $M$ 位）。
- 统计相同二进制串的出现次数。
- 找出最大出现次数，即为答案。

### 复杂度分析

- 每颗行星需要计算 $M$ 次点积（ $Ax + By + Cz - D$ ），每次计算为 $O(1)$ 。
- 因此生成所有行星的二进制串总复杂度为 $O(NM)$ 。
- 使用 `map<string, int>` 统计，每次插入/查询的复杂度为 $O(M)$ （字符串比较）。
- 总体复杂度 $O(NM \log N)$ ，在 $M \leq 500$ ， $N \leq 10000$ 的情况下是可接受的（约 $5 \times 10^6$ 次操作）。

### 注意事项

1. **数值范围**： $A, B, C, D, X, Y, Z$ 的范围都在 $-10000$ 到 $10000$ 之间，乘积 $A \times X$ 最大可能达到 $10^8$ ，三个乘积相加可能达到 $3 \times 10^8$ ，使用 `int` 可能溢出。因此计算 $Ax + By + Cz$ 时应使用 `long long` 。
2. **边界处理**：题目明确行星不会在平面上，因此 $Ax + By + Cz - D$ 不会等于 $0$ ，我们可以直接用正负判断。
3. **多组数据**：注意输入直到 $\texttt{EOF}$ 。

---

## 算法步骤

1. 读取 $M$ 和 $N$ 。
2. 存储 $M$ 个平面的系数 $A, B, C, D$ 。
3. 初始化一个 `map<string, int>` ，用于统计每个区域编码出现的次数。
4. 对每颗行星：
   - 读取坐标 $(X, Y, Z)$ 。
   - 初始化一个空字符串 `key` 。
   - 对每个平面 $j$ ：
     - 计算 `val = A*X + B*Y + C*Z - D` （用 `long long` 防止溢出）。
     - 若 `val > 0` ，在 `key` 后追加 `'1'` ，否则追加 `'0'` 。
   - 将 `key` 在 $\texttt{map}$ 中的计数加一。
5. 遍历 $\texttt{map}$ ，找出最大计数。
6. 输出该最大计数。

## 代码实现

```cpp
// Confederation
// UVa ID: 12793
// Verdict: Accepted
// Submission Date: 2026-02-02
// UVa Run Time: 0.050s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int m, n;
    while (cin >> m >> n) {
        // 存储 M 个平面的系数 A, B, C, D
        vector<vector<int>> planes(m, vector<int>(4));
        for (int i = 0; i < m; ++i) 
            for (int j = 0; j < 4; ++j) 
                cin >> planes[i][j];

        // 统计每个区域编码出现的次数
        map<string, int> regionCount;
        for (int i = 0; i < n; ++i) {
            int x, y, z;
            cin >> x >> y >> z;
            string key = "";
            // 对每个平面计算行星在哪一侧
            for (int j = 0; j < m; ++j) {
                // 使用 long long 防止乘法溢出
                long long val = (long long)planes[j][0] * x + 
                                (long long)planes[j][1] * y + 
                                (long long)planes[j][2] * z - 
                                planes[j][3];
                // 大于 0 为正侧，否则为负侧
                key.push_back(val > 0 ? '1' : '0');
            }
            // 该区域计数加一
            ++regionCount[key];
        }

        // 找出最大行星数
        int maxPlanets = 0;
        for (auto &p : regionCount) 
            maxPlanets = max(maxPlanets, p.second);
        cout << maxPlanets << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于**将几何区域编码为字符串**，利用“行星不穿过平面”的性质，将三维空间的位置关系转化为 $M$ 位二进制编码，从而将问题简化为**字符串计数与求最大值**的问题。该方法思路清晰，实现简单，且效率足以通过题目给定的数据范围。
