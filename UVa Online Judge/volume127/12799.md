## 题目描述

$\texttt{RSA}$ 是目前最常用的加密算法之一，也被认为是现有最安全的加密方案之一。其基本工作原理如下：

首先选择两个奇质数 $p$ 和 $q$，计算 $n = p \times q$。然后计算欧拉函数 $\phi(n) = (p-1)(q-1)$，选择一个整数 $e$ 满足 $1 < e < \phi(n)$ 且 $\gcd(\phi(n), e) = 1$。最后计算整数 $d$，即 $e$ 模 $\phi(n)$ 的乘法逆元，满足 $d \times e \equiv 1 \bmod \phi(n)$。

这样就得到了公钥 $(n, e)$ 和私钥 $(n, d)$。

加密消息 $m$（其中 $0 < m < n$）时，计算 $c = m^e \bmod n$，$c$ 即为加密后的消息。解密时，计算 $m = c^d \bmod n$ 即可恢复原始消息。

**本题任务**：给定 $\texttt{RSA}$ 公钥和加密消息，破解加密并恢复原始消息。

## 输入输出格式

### 输入格式
输入包含多个测试用例，每行包含三个整数 $N$、$E$ 和 $C$：
- $15 \leq N \leq 10^9$
- $1 \leq E < N$ 
- $1 \leq C < N$

其中 $N$ 和 $E$ 构成 $\texttt{RSA}$ 公钥，$C$ 是使用该公钥加密的消息。

### 输出格式
对于每个测试用例，输出一行包含整数 $M$（$1 \leq M < N$），即原始消息。

## 题目分析

### $\texttt{RSA}$ 解密原理
要破解 $\texttt{RSA}$ 加密，我们需要理解其数学基础：

1. **质因数分解**：已知 $N = p \times q$，需要找到两个质数 $p$ 和 $q$
2. **欧拉函数计算**：$\phi(N) = (p-1) \times (q-1)$
3. **求乘法逆元**：找到 $d$ 使得 $d \times E \equiv 1 \bmod \phi(N)$
4. **解密计算**：$M = C^d \bmod N$

### 关键挑战
- **质因数分解**：由于 $N \leq 10^9$，可以使用试除法在合理时间内完成分解
- **大数运算**：需要处理模幂运算，防止数值溢出

### 算法选择
1. **质因数分解**：采用试除法，时间复杂度 $O(\sqrt{N})$，对于 $10^9$ 的数据规模可行
2. **模逆元计算**：使用扩展欧几里得算法
3. **模幂运算**：使用快速幂算法，时间复杂度 $O(\log d)$

## 解题思路

### 步骤详解

#### 步骤 1：质因数分解
由于 $N$ 是两个质数的乘积，我们可以从 $2$ 开始逐个尝试，直到找到能整除 $N$ 的数：
```cpp
for (long long i = 2; i <= sqrt(n); i++) {
    if (n % i == 0) {
        p = i;
        q = n / i;
        return;
    }
}
```

#### 步骤 2：计算欧拉函数
得到 $p$ 和 $q$ 后，直接计算：
$$\phi(N) = (p-1) \times (q-1)$$

#### 步骤 3：计算乘法逆元
使用扩展欧几里得算法求解 $d$，满足：
$$E \times d \equiv 1 \bmod \phi(N)$$

#### 步骤 4：解密计算
使用快速幂算法计算：
$$M = C^d \bmod N$$

### 时间复杂度分析
- 质因数分解：$O(\sqrt{N})$，最坏情况下约 $3 \times 10^4$ 次操作
- 扩展欧几里得：$O(\log \phi(N))$
- 快速幂：$O(\log d)$
总体复杂度在可接受范围内。

```cpp
#include <iostream>
#include <cmath>

using namespace std;

// 使用试除法分解 n 为 p 和 q
void factorize(long long n, long long &p, long long &q) {
    for (long long i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) {
            p = i;
            q = n / i;
            return;
        }
    }
    p = n;
    q = 1;
}

// 扩展欧几里得算法求逆元
long long modInverse(long long a, long long m) {
    long long m0 = m, t, q;
    long long x0 = 0, x1 = 1;
    if (m == 1) return 0;
    while (a > 1) {
        q = a / m;
        t = m;
        m = a % m;
        a = t;
        t = x0;
        x0 = x1 - q * x0;
        x1 = t;
    }
    if (x1 < 0) x1 += m0;
    return x1;
}

// 快速幂取模
long long modPow(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) {
            result = (result * base) % mod;
        }
        base = (base * base) % mod;
        exp >>= 1;
    }
    return result;
}

int main() {
    long long n, e, c;
    while (cin >> n >> e >> c) {
        long long p, q;
        factorize(n, p, q);
        long long phiN = (p - 1) * (q - 1);
        long long d = modInverse(e, phiN);
        long long m = modPow(c, d, n);
        cout << m << endl;
    }
    return 0;
}
```

## 总结

本题展示了 $\texttt{RSA}$ 加密算法的基本原理和破解方法。通过质因数分解、欧拉函数计算、模逆元求解和模幂运算四个步骤，我们能够成功恢复加密前的原始消息。虽然在实际应用中，$N$ 的规模远大于 $10^9$，使得质因数分解变得极其困难，但本题的数据规模允许我们使用相对简单的方法完成破解。

这个解法体现了数论在密码学中的重要应用，也帮助我们更好地理解 $\texttt{RSA}$ 算法的安全性和局限性。
