
> **摘要**：给定平面上 $N$ 个点（$N \le 100$），统计能构成的等腰三角形数量，其中等腰要求**恰好**两条边相等，等边三角形不计入，三点共线也不构成三角形。由于数据规模很小，三点组合数最多约 $1.6 \times 10^5$，可直接 $O(N^3)$ 暴力枚举每个三元组：先用叉积排除共线情况，再用浮点数计算三条边长，借助 $10^{-6}$ 的误差阈值统计三对边中相等的对数，恰好为 $1$ 时答案加一。

## 题目描述

给定平面上 $N$ 个点，问这些点能组成多少个**等腰三角形**。  
等腰三角形的定义是：**恰好**有两条边长度相等。三点共线不能构成三角形。

## 输入格式

输入包含多组测试用例。  
每个测试用例第一行为一个整数 $N$（$1 \le N \le 100$），接下来 $N$ 行，每行两个整数 $X_i, Y_i$（$-100 \le X_i, Y_i \le 100$），表示点的坐标。  
输入以 $\texttt{EOF}$ 结束。

## 输出格式

对于每个测试用例，输出一行一个整数，表示等腰三角形的总数。

## 样例

### 输入
```
6
-4 1
-3 3
-2 1
-2 0
-1 1
1 -1
3
-4 1
-2 1
-1 1
```

### 输出
```
4
0
```

## 题目分析

本题数据规模很小，$N \le 100$，所有三点组合数为 $\binom{100}{3} = 161700$，完全可以在 $O(N^3)$ 时间内暴力枚举每个三元组并判定。

对于任意三个点，首先需要判断它们是否共线。若共线则面积为 $0$，不能构成三角形。共线判定可使用叉积：  
设三点为 $A(x_1,y_1)$，$B(x_2,y_2)$，$C(x_3,y_3)$，则叉积  
$$
\textit{cross} = (x_2 - x_1)(y_3 - y_1) - (y_2 - y_1)(x_3 - x_1)
$$
若 $|\textit{cross}| < 10^{-6}$，则认为三点共线。

若不共线，则计算三条边的长度（欧氏距离），使用浮点数 $\texttt{double}$ 存储。  
等腰三角形的判定标准是：恰好有两边长度相等。注意等边三角形（三边相等）不符合题意，因为等腰要求“恰好”两条边相等。因此，我们需要统计三对长度比较中相等的对数。若相等对数为 $1$，则三角形是等腰非等边，计数加一。

由于坐标都是整数，边长可能为无理数，因此比较时需要允许误差。题目要求两个长度 $L_a, L_b$ 视为相等当且仅当 $|L_a - L_b| < 10^{-6}$。

## 解题思路

直接枚举所有三元组 $(i, j, k)$，其中 $i < j < k$，对每个三元组执行以下步骤：

1. 计算叉积 $\textit{cross}$，若 $|\textit{cross}| < \epsilon$，则三点共线，跳过。
2. 计算三条边长 $d_{12}, d_{13}, d_{23}$。
3. 统计三对长度比较中相等的次数：
   - 若 $|d_{12} - d_{13}| < \epsilon$，相等计数加一；
   - 若 $|d_{12} - d_{23}| < \epsilon$，相等计数加一；
   - 若 $|d_{13} - d_{23}| < \epsilon$，相等计数加一。
4. 若相等计数恰好为 $1$，则说明该三角形有且仅有一对边相等，即恰有两边相等，答案加一。

该方法的时间复杂度为 $O(N^3)$，对于 $N=100$ 完全可行，空间复杂度 $O(N)$ 存储点集。

## 代码实现

```cpp
// Isosceles Triangles
// UVa ID: 1816
// Verdict: Accepted
// Submission Date: 2026-07-13
// UVa Run Time: 0.010s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point { double x, y; };

double dist(const Point& a, const Point& b) {
    double dx = a.x - b.x, dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);
}

int main() {
    int N;
    while (scanf("%d", &N) == 1) {
        vector<Point> pts(N);
        for (int i = 0; i < N; ++i) scanf("%lf %lf", &pts[i].x, &pts[i].y);
        int ans = 0;
        const double EPS = 1e-6;
        for (int i = 0; i < N; ++i)
            for (int j = i + 1; j < N; ++j)
                for (int k = j + 1; k < N; ++k) {
                    // 叉积判断共线
                    double cross = (pts[j].x - pts[i].x) * (pts[k].y - pts[i].y)
                                 - (pts[j].y - pts[i].y) * (pts[k].x - pts[i].x);
                    if (fabs(cross) < EPS) continue;
                    double d12 = dist(pts[i], pts[j]);
                    double d13 = dist(pts[i], pts[k]);
                    double d23 = dist(pts[j], pts[k]);
                    int eq = 0;
                    if (fabs(d12 - d13) < EPS) ++eq;
                    if (fabs(d12 - d23) < EPS) ++eq;
                    if (fabs(d13 - d23) < EPS) ++eq;
                    if (eq == 1) ++ans;
                }
        printf("%d\n", ans);
    }
    return 0;
}
```

## 总结

本题是一道经典的几何计数问题，由于数据规模小，暴力枚举所有三点组合是最高效且最直接的做法。关键点在于：

- 利用叉积排除共线情况；
- 使用浮点数及误差阈值比较边长，避免精度问题；
- 严格区分等腰三角形（恰好一对等边）与等边三角形（三边相等），只统计相等对数为 $1$ 的情况。

该解法思路清晰，代码简洁，时间复杂度 $O(N^3)$ 足以应对 $N=100$ 的限制。在实际比赛中，此类小数据题目应优先考虑暴力枚举，确保正确性。
