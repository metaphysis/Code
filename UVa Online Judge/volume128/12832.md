[UVa 12832 Chicken Lover](https://blog.csdn.net/metaphysis/article/details/161688157)

## 题目描述

$\texttt{Abir}$ 很喜欢吃鸡肉。每天他会依次访问 $m$ 家餐馆。第 $i$ 家餐馆可以制作 $n_i$ 种不同的菜品，其中恰好有 $1$ 种是鸡肉菜品。每天每家餐馆会从中随机选择 $k_i$ 种菜品（等概率选择，所有 $\binom{n_i}{k_i}$ 种组合等可能）。求 $\texttt{Abir}$ 在一天内能吃到的鸡肉菜品的期望数量。

## 输入格式

第一行一个整数 $T$（$T \leq 125$），表示测试用例数。  
每个测试用例第一行一个整数 $m$（$1 \le m \le 10000$），表示餐馆数量。  
接下来一行有 $m$ 对整数 $n_i, k_i$（$1 \le n_i \le 20$，$1 \le k_i \le n_i$）。

## 输出格式

对于每个测试用例，输出一行 `Case X: P/Q`，其中 $P$ 和 $Q$ 互质，表示期望值的最简分数形式。

## 样例

输入

```
3
1
1 1
2
2 1 2 1
1
3 2
```

输出

```
Case 1: 1/1
Case 2: 1/1
Case 3: 2/3
```

## 题目分析

本题的核心是计算多个独立随机事件的期望之和。

每家餐馆的菜品选择是独立的。对于第 $i$ 家餐馆，总共有 $n_i$ 种菜品，其中恰好 $1$ 种是鸡肉。餐馆随机选择 $k_i$ 种菜品，那么鸡肉被选中的概率为：

$$
p_i = \frac{k_i}{n_i}
$$

这是因为选择过程是均匀随机的，每种菜品被选中的概率相同，且鸡肉是其中特定的一种。由组合数学可知，从 $n_i$ 个物品中随机选取 $k_i$ 个，某个特定物品被选中的概率就是 $k_i / n_i$。

令随机变量 $X_i$ 表示在第 $i$ 家餐馆吃到鸡肉的数量（显然 $X_i$ 只能取 $0$ 或 $1$），则：

$$
E[X_i] = 1 \cdot p_i + 0 \cdot (1 - p_i) = p_i = \frac{k_i}{n_i}
$$

由于不同餐馆的选择相互独立，总期望为各家期望之和：

$$
E = \sum_{i=1}^{m} E[X_i] = \sum_{i=1}^{m} \frac{k_i}{n_i}
$$

因此问题转化为：求 $\displaystyle \sum_{i=1}^{m} \frac{k_i}{n_i}$ 的最简分数表示。

## 解题思路

### 分数加法

直接模拟分数加法即可。设当前累积结果为 $\frac{P}{Q}$，加入一个新的分数 $\frac{k_i}{n_i}$：

$$
\frac{P}{Q} + \frac{k_i}{n_i} = \frac{P \cdot n_i + k_i \cdot Q}{Q \cdot n_i}
$$

### 约分与溢出处理

由于 $m$ 最大可达 $10^4$，$n_i \le 20$，分子和分母在累加过程中可能会变得很大。最大可能的分子约为：

$$
\sum_{i=1}^{m} \frac{k_i}{n_i} \le \sum_{i=1}^{m} \frac{n_i}{n_i} = m \le 10^4
$$

但注意，这是分数的真实值，而我们用分数形式表示时，通分后的分母是 $\prod n_i$。由于 $n_i \le 20$，$m$ 最大 $10^4$，分母会大到无法用标准整型存储。例如，当所有 $n_i = 20$ 时，分母为 $20^{10000}$，远超 64 位整数范围。

**但题目中 $n_i$ 很小（$\le 20$），$k_i \le n_i$，且要求输出最简分数。** 实际上，累加过程中分子和分母的公共因子会频繁出现，我们通过每步立即约分，可以有效地控制数值范围。

然而，直接使用 `long long`（约 $9 \times 10^{18}$）仍然可能不够，因为分母的最大值可能达到 $\operatorname{lcm}(1,2,\dots,20)$ 的幂次，而 $\operatorname{lcm}(1,\dots,20) = 232792560$，远小于 $10^9$。实际上，每步约分后，分母始终是 $1$ 到 $20$ 中某些数的最小公倍数及其幂次的因子，不会无限增长。经验证，使用 64 位整数可以安全通过。

### 算法步骤

1. 初始化分子 $\textit{numerator} = 0$，分母 $\textit{denominator} = 1$。
2. 对每个餐馆：
   - 读入 $n_i, k_i$。
   - 计算新分子：$\textit{newNum} = \textit{numerator} \times n_i + k_i \times \textit{denominator}$。
   - 计算新分母：$\textit{newDen} = \textit{denominator} \times n_i$。
   - 令 $g = \gcd(\textit{newNum}, \textit{newDen})$，然后 $\textit{numerator} = \textit{newNum} / g$，$\textit{denominator} = \textit{newDen} / g$。
3. 输出 $\textit{numerator} / \textit{denominator}$，注意分母为 $1$ 时也应输出 `1/1`（但题目保证分母为正）。

### 复杂度分析

- 每个测试用例需要 $O(m)$ 次分数加法，每次加法包含一次乘法和一次求最大公约数。
- 求最大公约数使用欧几里得算法，复杂度 $O(\log(\max(\textit{numerator}, \textit{denominator})))$。
- 总时间复杂度 $O(T \cdot m \cdot \log M)$，其中 $M$ 为中间结果的最大值，在本题范围内完全可接受。

## 代码实现

```cpp
// Chicken Lover
// UVa ID: 12832

// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

long long gcd(long long a, long long b) {
    while (b) { long long t = b; b = a % b; a = t; }
    return a;
}

int main() {
    int T; scanf("%d", &T);
    for (int caseNum = 1; caseNum <= T; caseNum++) {
        int m; scanf("%d", &m);
        long long numerator = 0, denominator = 1;
        for (int i = 0; i < m; i++) {
            int n, k; scanf("%d %d", &n, &k);
            // 当前项 = k / n
            // 分数加法： numerator/denominator + k/n
            long long newNumerator = numerator * n + k * denominator;
            long long newDenominator = denominator * n;
            numerator = newNumerator;
            denominator = newDenominator;
            // 约分，防止溢出
            long long g = gcd(numerator, denominator);
            numerator /= g; denominator /= g;
        }
        printf("Case %d: %lld/%lld\n", caseNum, numerator, denominator);
    }
    return 0;
}
```

## 总结

本题的关键点在于：

1. **概率模型的简化**：每个餐馆中鸡肉被选中的概率为 $k_i / n_i$，期望可加。
2. **分数运算的精确性**：使用分数形式保持精度，每步约分控制数值范围。
3. **注意数值范围**：虽然 $n_i$ 很小，但累积的分母可能很大，通过每步约分可有效避免溢出，使用 $64$ 位整数足够。
4. **输入输出格式**：严格按照题目要求输出最简分数，分子分母互质。

本题是一个典型的期望线性性的应用，同时考察了分数运算和最大公约数的使用，代码简洁但需要仔细处理数据范围。
