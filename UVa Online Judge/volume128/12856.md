[UVa 12856 Counting Substhreengs](https://blog.csdn.net/metaphysis/article/details/154599847)

## 题目描述

**子字符串**是从一个字符串中选择一组连续字符形成的字符串。而 **$\texttt{substhreeng}$** 的定义则稍微特殊一些，它需要满足以下两个条件：

1. 它是非空的，且完全由十进制数字组成
2. 将其解释为十进制数（允许额外的前导零）后，得到的整数是 $3$ 的倍数

例如，字符串 $\texttt{"130a303"}$ 包含 $9$ 个 $\texttt{substhreeng}$：
- 子字符串 $\texttt{'3'}$ 出现三次
- 子字符串 $\texttt{'30'}$ 和 $\texttt{'0'}$ 各出现两次  
- 子字符串 $\texttt{'303'}$ 和 $\texttt{'03'}$ 各出现一次

注意：两个 $\texttt{substhreeng}$ 如果长度不同或起始位置不同，即使选择的字符相同，也被视为不同的 $\texttt{substhreeng}$。

## 输入格式

输入包含多个测试用例，每个测试用例占一行，包含一个非空字符串 $S$，长度最多为 $10^6$ 个字符。$S$ 中的每个字符要么是数字，要么是小写字母。

## 输出格式

对于每个测试用例，输出一行，包含一个整数，表示 $S$ 中包含的 $\texttt{substhreeng}$ 的数量。

## 题目分析

### 关键观察

1. **数字整除 $3$ 的性质**：一个数字是 $3$ 的倍数，当且仅当它的各位数字之和是 $3$ 的倍数
2. **前缀和思想**：对于连续的数字段，我们可以计算前缀和模 $3$ 的值
3. **同余定理**：如果两个前缀和模 $3$ 的值相同，那么它们之间的子串数字和模 $3$ 为 $0$

### 解题思路

我们需要统计所有满足以下条件的子字符串数量：
- 完全由数字组成
- 对应的数字是 $3$ 的倍数

**暴力解法不可行**：由于字符串长度可达 $10^6$，$O(n^2)$ 的暴力枚举会超时。

**高效解法**：
1. 遍历字符串，识别连续的数字段
2. 对于每个连续数字段，使用一个数组 $count[3]$ 记录当前前缀和模 $3$ 为 $0$、$1$、$2$ 的数量
3. 初始时，$count[0] = 1$（表示前缀和为 $0$ 的初始状态）
4. 对于每个新数字：
   - 更新当前前缀和模 $3$ 的值
   - 累加对应 $count$ 的值到答案中（因为两个前缀和模 $3$ 相同的位置之间的子串数字和模 $3$ 为 $0$）
   - 更新 $count$ 数组

### 算法正确性证明

设当前前缀和为 $sum$，模 $3$ 的结果为 $r$。如果之前存在某个前缀和模 $3$ 也为 $r$，设为位置 $i$，那么从位置 $i+1$ 到当前位置的子串数字和模 $3$ 为：
$$(sum - prev\_sum) \mod 3 = (r - r) \mod 3 = 0$$
因此该子串是 $3$ 的倍数。

### 复杂度分析

- **时间复杂度**：$O(n)$，每个字符只处理一次
- **空间复杂度**：$O(1)$，只使用固定大小的数组

## 代码实现

```cpp
// Counting Substhreengs

// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <string>
#include <cstring>
using namespace std;

long long countSubsthreengs(const string& s) {
    long long totalCount = 0;
    int n = s.length();
    
    for (int i = 0; i < n; ) {
        if (isdigit(s[i])) {
            int count[3] = {1, 0, 0}; // 前缀和模3的计数，初始前缀和0出现1次
            int sumMod = 0;
            
            int j = i;
            while (j < n && isdigit(s[j])) {
                int digit = s[j] - '0';
                sumMod = (sumMod + digit) % 3;
                totalCount += count[sumMod];
                count[sumMod]++;
                j++;
            }
            i = j;
        } else {
            i++;
        }
    }
    
    return totalCount;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string line;
    while (getline(cin, line)) {
        cout << countSubsthreengs(line) << "\n";
    }
    
    return 0;
}
```

## 示例分析

以样例 $\texttt{"130a303"}$ 为例：

连续数字段 $\texttt{"130"}$：
- 处理 $\texttt{'1'}$：$sumMod = 1$，$count[1] = 0$，不加
- 处理 $\texttt{'3'}$：$sumMod = (1+3)\%3 = 1$，$count[1] = 1$，加 $1$
- 处理 $\texttt{'0'}$：$sumMod = (1+0)\%3 = 1$，$count[1] = 2$，加 $2$

连续数字段 $\texttt{"303"}$：
- 处理 $\texttt{'3'}$：$sumMod = 0$，$count[0] = 1$，加 $1$
- 处理 $\texttt{'0'}$：$sumMod = 0$，$count[0] = 2$，加 $2$  
- 处理 $\texttt{'3'}$：$sumMod = 0$，$count[0] = 3$，加 $3$

总计：$0 + 1 + 2 + 1 + 2 + 3 = 9$，与样例输出一致。

这种方法巧妙地利用了数论性质和前缀和思想，在 $O(n)$ 时间内解决了问题。
