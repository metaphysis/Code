## 题目描述

天文学家预测仙女座星系将在约 $38$ 亿年后与我们的银河系发生碰撞。 实际上， 这种碰撞更可能是两个星系的合并， 因为恒星间的距离非常遥远， 任意两颗恒星都不会发生实际碰撞。 $\texttt{Andrew}$ 教授正在构建一个计算模型来预测碰撞的可能结果， 并需要你的帮助！ 

给定二维平面上的一组点， 代表已合并星系中某个区域的恒星。 教授不知道哪些恒星最初来自哪个星系； 但他知道， 对于这个区域， 如果两颗恒星来自同一个星系， 那么它们之间的距离大于 $5$ 光年。 由于该区域的每颗恒星要么来自仙女座， 要么来自银河系， 教授还知道给定的点集可以分成两个不相交的子集， 一个包含来自仙女座的恒星， 另一个包含来自银河系的恒星， 并且两个子集都具有以下性质： 子集中任意两点之间的最小距离大于 $5$ 光年。 他称这是一个好的分离， 但坏消息是可能存在许多不同的好的分离。 然而， 在所有可能的好的分离中， 存在一个子集必须包含的最小恒星数量， 这正是你的程序需要计算的数字。

### 输入格式

输入包含多个测试用例； 每个测试用例的格式如下。 第一行包含一个整数 $N$ （ $1 \leq N \leq 5 \times 10^4$ ） 表示集合中的点数。 接下来的 $N$ 行每行用两个整数 $X$ 和 $Y$ （ $1 \leq X, Y \leq 5 \times 10^5$ ） 描述一个不同的点， 表示其坐标（以光年为单位）。 没有重合的点， 并且该集合至少允许一个好的分离。

### 输出格式

对于输入中的每个测试用例， 输出一行包含一个整数， 表示在一个好的分离中子集可能包含的最小点数。

## 题目分析

### 问题转化

题目要求将 $N$ 个点划分为两个子集 $A$ 和 $B$ ， 满足以下条件：

1. 对于任意两点 $p, q \in A$ 或 $p, q \in B$ ， 有 $dist(p, q) > 5$ 。
2. $A \cap B = \emptyset$ ， $A \cup B = S$ （ $S$ 为所有点的集合）。

换句话说， 同一子集内的任意两点距离必须大于 $5$ 。 我们需要在所有可能的合法划分中， 找到 $\min(|A|, |B|)$ 的最小可能值。

### 关键观察

将距离约束转化为图论模型：

- 对于任意两点 $p, q$ ， 如果 $dist(p, q) \le 5$ ， 则它们不能属于同一个子集（否则违反条件）。
- 如果 $dist(p, q) > 5$ ， 则它们可以属于相同或不同子集， 没有约束。

因此， 我们可以构建一个无向图 $G = (V, E)$ ， 其中：
- 顶点 $V$ 对应 $N$ 个点。
- 边 $E$ ： 当且仅当两点距离 $\le 5$ 时， 在它们之间连一条边。

这样， 问题的约束条件等价于： 图 $G$ 必须是一个二分图， 并且我们要求的是所有二染色方案中， 两种颜色的点数差异的最小值（取颜色较少的一方）。

### 算法步骤

1. **建图** ： 对于所有点， 找出所有距离 $\le 5$ 的点对并连边。 由于 $N$ 最大为 $5 \times 10^4$ ， 直接 $O(N^2)$ 检查不可行， 需要优化。

2. **二分图染色与连通分量统计** ： 对图 $G$ 进行二染色（使用 $\texttt{BFS}$ 或 $\texttt{DFS}$）。 由于题目保证至少存在一个合法划分， 所以 $G$ 一定是二分图。 染色过程中， 统计每个连通分量中两种颜色的点数， 记为 $(a_i, b_i)$ 。

3. **动态规划求最小子集** ： 对于每个连通分量， 我们可以选择将颜色 $1$ 的点归入子集 $A$ （颜色 $2$ 归入 $B$ ）， 或者反过来。 问题转化为： 选择每个分量的分配方式， 使得 $|A|$ 尽可能小（对称地， $|B|$ 也会小）， 最终目标是 $\min(|A|, |B|)$ 最小。

   设 $dp[i]$ 表示是否可能使 $|A| = i$ 。 初始 $dp[0] = 1$ 。 对于每个分量 $(a, b)$ ， 状态转移为：
   $$
   dp' = (dp \ll a) \mid (dp \ll b)
   $$
   其中 $\ll$ 表示左移（相当于增加 $a$ 或 $b$ 个点到 $A$ ）。 可以使用 `bitset` 加速这一过程。

4. **计算答案** ： 遍历所有可能的 $i$ （ $0 \le i \le N$ ）， 若 $dp[i] = 1$ ， 则计算 $\min(i, N-i)$ ， 取最小值输出。

### 建图优化

直接枚举所有点对需要 $O(N^2)$ ， 不可接受。 由于距离阈值 $5$ 很小， 我们可以采用以下优化：

- **按 $x$ 坐标分组** ： 因为如果两点距离 $\le 5$ ， 那么它们的 $x$ 坐标差一定不超过 $5$ 。 因此， 对于每个点， 只需检查 $x$ 坐标在 $[x-5, x+5]$ 范围内的其他点。
- **进一步剪枝** ： 对于 $x$ 坐标相同的点， 再检查 $y$ 坐标差是否 $\le 5$ ， 并计算实际距离平方是否 $\le 25$ （避免开方）。

具体实现时， 可以用一个数组 `vector<int> groupByX[500005]` 存储每个 $x$ 坐标对应的点的索引。 对于每个 $x$ ， 检查 $x-5$ 到 $x+5$ 范围内的所有点， 并过滤掉 $y$ 坐标差大于 $5$ 的点对， 这样可以将检查次数降到接近 $O(11 \times$平均每个 $x$ 的点数$\times N)$ ， 在坐标范围较大且点分布稀疏时效率很高。

### 复杂度分析

- **建图** ： 每个点最多检查 $11$ 个 $x$ 坐标范围， 每个 $x$ 坐标内的点数平均很少， 因此接近 $O(N)$ 。
- **染色** ： $O(N + M)$ ， $M$ 为边数， 最坏情况下 $M$ 可能达到 $O(N)$ 。
- **动态规划** ： 使用 `bitset` 加速， 每个分量操作为 $O(N/64)$ ， 分量个数通常远小于 $N$ ， 总体 $O(N^2/64)$ ， 在 $N=5\times10^4$ 时约 $4\times10^7$ 次位运算， 可以接受。

## 代码实现

```cpp
// Galaxy Collision
// UVa ID: 12860
// Verdict: Accepted
// Submission Date: 2026-01-
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 50005;

struct Point {
    int x, y, id;
    Point(int x = 0, int y = 0, int id = 0) : x(x), y(y), id(id) {}
    bool operator<(const Point& other) const { return x < other.x; }
};

vector<Point> points;
vector<int> g[MAXN];
int color[MAXN];

inline long long getDist(const Point& a, const Point& b) {
    long long dx = a.x - b.x, dy = a.y - b.y;
    return dx * dx + dy * dy;
}

// 分组优化：按x坐标分组，每组内按y排序
vector<int> groupByX[500005];

int main() {
    int n;
    while (scanf("%d", &n) == 1) {
        points.resize(n);
        for (int i = 0; i < n; ++i) {
            g[i].clear();
            color[i] = 0;
        }
        for (int i = 0; i <= 500000; ++i) groupByX[i].clear();
        for (int i = 0; i < n; ++i) {
            scanf("%d%d", &points[i].x, &points[i].y);
            points[i].id = i;
            groupByX[points[i].x].push_back(i);
        }
        for (int x = 1; x <= 500000; ++x) {
            if (groupByX[x].empty()) continue;
            for (int dx = -5; dx <= 5; ++dx) {
                int nx = x + dx;
                if (nx < 1 || nx > 500000) continue;
                for (int i : groupByX[x]) {
                    Point& p1 = points[i];
                    for (int j : groupByX[nx]) {
                        if (j <= i) continue;
                        Point& p2 = points[j];
                        if (abs(p1.y - p2.y) > 5) continue;
                        if (getDist(p1, p2) <= 25) {
                            g[i].push_back(j);
                            g[j].push_back(i);
                        }
                    }
                }
            }
        }
        vector<pair<int, int>> components;
        for (int i = 0; i < n; ++i)
            if (color[i] == 0) {
                int cnt1 = 0, cnt2 = 0;
                queue<int> q;
                q.push(i);
                color[i] = 1;
                cnt1++;
                while (!q.empty()) {
                    int u = q.front(); q.pop();
                    int c = color[u];
                    for (int v : g[u]) {
                        if (color[v] == 0) {
                            color[v] = 3 - c;
                            if (color[v] == 1) cnt1++;
                            else cnt2++;
                            q.push(v);
                        }
                    }
                }
                components.push_back({cnt1, cnt2});
            }
        bitset<50005> dp;
        dp[0] = 1;
        for (auto& [a, b] : components) dp = (dp << a) | (dp << b);
        int r = n;
        for (int i = 0; i <= n; ++i)
            if (dp[i]) {
                r = min(r, min(i, n - i));
                if (r == 0) break;
            }
        printf("%d\n", r);
    }
    return 0;
}
```

## 总结

本题的关键在于将几何距离约束转化为图论中的二分图问题， 并通过优化建图来满足大规模数据的要求。 使用分组和剪枝技术可以有效减少需要检查的点对数量， 而 `bitset` 加速的动态规划则高效地解决了组合优化部分。 最终算法能够在 $N \le 5\times10^4$ 的规模下高效运行， 得出正确结果。
