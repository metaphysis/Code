## 题目描述

给定一个字母算术谜题（$\texttt{Alphametic Puzzle}$） ，类似于经典的 $\texttt{SEND + MORE = MONEY}$ 问题。 在这个问题中，每个大写字母代表一个数字（$0$ 到 $9$） ，不同的字母必须对应不同的数字，并且每个单词的首字母不能为 $0$ 。 题目给出 $n$ 个单词，其中前 $n-1$ 个是加数，最后一个单词是结果。 单词按右对齐方式排列（即从最低位对齐） 。 你需要计算满足加法等式的不同数字分配方案的数量。

**输入格式**： 第一行一个整数 $n$ （ $3 \le n \le 10$ ） ，接下来 $n$ 行每行一个由大写字母组成的单词，单词长度不超过 $10$ 。 问题中最多包含 $10$ 个不同的字母。

**输出格式**： 对于每个测试用例，输出一个整数，表示满足条件的方案数。

**样例输入**：
```
3
GREAT
SWERC
PORTO
3
SEND
MORE
MONEY
5
TOO
GOOD
TO
BE
TRUE
```

**样例输出**：
```
6
1
93
```

## 题目分析

这是一个典型的 **字母算术谜题** ，需要通过回溯搜索来枚举所有可能的数字分配方案。 由于最多只有 $10$ 个不同的字母，理论上最多有 $10! = 3,628,800$ 种排列，但通过剪枝可以大幅减少搜索空间。

### 问题特点

1. **右对齐**： 单词按最低位对齐，这与我们通常的加法计算方式一致。
2. **唯一性约束**： 每个字母必须对应唯一的数字。
3. **首字母非零**： 每个单词的首字母（最高位）不能为 $0$ 。
4. **进位处理**： 需要正确处理加法中的进位。

### 解题思路

我们采用 **深度优先搜索（$\texttt{DFS}$）** 回溯算法，从最低位开始逐列分配数字，并在搜索过程中进行剪枝。

#### 核心思想

1. **反转单词**： 为了便于从最低位开始处理，我们将所有单词反转。 这样，原单词的最高位（最左侧）在反转后位于最后一位，而最低位（最右侧）在反转后位于第一位。 在代码中，我们通过 `reverse(words[i].begin(), words[i].end())` 实现。
   
2. **逐列计算**： 从第 $0$ 列（最低位）开始，依次处理每一列。 对于每一列，我们：
   - 处理所有加数在该列上的字母（如果存在）
   - 计算当前列的部分和（包含来自低位的进位）
   - 处理结果在该列上的字母，检查是否匹配部分和的个位数
   - 将进位传递到下一列

3. **剪枝策略**：
   - **高位非零**： 如果当前列是某个单词的最高位（在反转后，最高位是 `words[row].size() - 1`），则该字母不能为 $0$。
   - **结果长度限制**： 结果的位数不可能小于最大加数的位数，也不可能大于最大加数位数加 $1$（因为最大进位为 $1$）。
   - **提前验证**： 在分配数字时，如果一列的所有字母都已分配，可以立即验证该列是否可能满足条件。

4. **优化技巧**：
   - **排序**： 对加数单词按长度排序，短单词优先处理，可以减少搜索深度。
   - **状态压缩**： 使用数组 `value[26]` 记录每个字母分配的数字（ $-1$ 表示未分配），使用 `used[10]` 记录数字是否已被使用。

#### 算法步骤

1. 读取所有单词并反转。
2. 对加数单词排序（短单词优先）。
3. 检查结果长度是否合理（剪枝）。
4. 初始化搜索状态，开始 $\texttt{DFS}$。
5. 在 $\texttt{DFS}$ 中：
   - 如果所有列处理完毕且进位为 $0$ ，找到一个解。
   - 如果当前行处理完毕，转到下一列。
   - 如果当前列超出当前单词长度，跳过该单词。
   - 处理当前字母：
     - 如果是加数：尝试分配数字或使用已分配数字，更新部分和。
     - 如果是结果：检查部分和的个位数是否匹配，处理进位。
6. 统计解的数量并输出。

## 代码实现

```cpp
// GREAT + SWERC = PORTO
// UVa ID: 12877
// Verdict: Accepted
// Submission Date: 2026-01-18
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

string words[16];  // 存储单词
int n, cnt;        // n: 单词数量, cnt: 解的数量
int value[26];     // 字母对应的数字，-1表示未分配
int used[10];      // 数字是否已被使用

// DFS搜索函数
// row: 当前处理的单词索引
// cln: 当前处理的列（从最低位0开始）
// sum: 当前列的累积和（包含进位）
void dfs(int row, int cln, int sum) {
    // 所有列处理完毕
    if (cln == words[n - 1].length()) {
        if (sum == 0) cnt++;  // 进位为0，找到一个解
        return;
    }
    // 当前列所有单词处理完毕，进入下一列
    if (row == n) {
        dfs(0, cln + 1, sum);
        return;
    }
    // 当前单词在当前列没有字母，跳过
    if (cln >= words[row].length()) {
        dfs(row + 1, cln, sum);
        return;
    }
    // 获取当前字母的索引（0-25对应A-Z）
    int c = words[row][cln] - 'A';
    // 处理加数（前n-1个单词）
    if (row < n - 1) {
        if (value[c] != -1) {
            // 字母已分配数字，检查是否是最高位且为0
            if (cln == words[row].size() - 1 && value[c] == 0) return;
            dfs(row + 1, cln, sum + value[c]);
        } else {
            // 字母未分配数字，尝试所有可能
            // 如果是最高位，不能为0（cln == words[row].size() - 1）
            for (int i = (cln == (words[row].size() - 1)); i < 10; i++)
                if (!used[i]) {
                    used[i] = 1;
                    value[c] = i;
                    dfs(row + 1, cln, sum + i);
                    value[c] = -1;  // 回溯
                    used[i] = 0;
                }
        }
    } else {
        // 处理结果（最后一个单词）
        int d = sum % 10;  // 当前列需要的数字
        // 结果单词的最高位不能为0
        if (cln == (words[n - 1].size() - 1) && d == 0) return;
        if (value[c] != -1) {
            // 结果字母已分配，检查是否匹配
            if (d == value[c])
                dfs(row + 1, cln, sum / 10);  // 处理进位
        } else {
            // 结果字母未分配，检查数字d是否可用
            if (!used[d]) {
                used[d] = 1;
                value[c] = d;
                dfs(row + 1, cln, sum / 10);  // 处理进位
                value[c] = -1;  // 回溯
                used[d] = 0;
            }
        }
    }
}

void solve() {
    // 读取单词并反转（从最低位开始处理）
    for (int i = 0; i < n; i++) {
        cin >> words[i];
        reverse(words[i].begin(), words[i].end());
    }
    // 对加数单词排序（短单词优先，减少搜索深度）
    sort(words, words + n - 1, [](string a, string b) {
        if (a.size() != b.size()) return a.size() < b.size();
        return a < b;
    });
    // 剪枝：结果长度不可能小于最大加数长度，也不可能大于最大加数长度+1
    if (words[n - 1].size() < words[n - 2].size() ||
        words[n - 2].size() + 2 <= words[n - 1].size()) {
        // 直接返回，输出0（在主函数中初始化cnt为0）
        return;
    }
    // 初始化
    cnt = 0;
    memset(value, -1, sizeof value);
    memset(used, 0, sizeof used);
    // 开始搜索
    dfs(0, 0, 0);
    // 输出结果
    cout << cnt << '\n';
}

int main() {
    // 加速输入输出
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    // 处理多个测试用例
    while (cin >> n) solve();
    return 0;
}
```

## 复杂度分析

- **时间复杂度**： 最坏情况下需要枚举所有字母的排列，即 $10! = 3,628,800$ 种可能。 但通过剪枝，实际搜索空间远小于此。 对于每个测试用例，在合理时间内可以完成。
- **空间复杂度**： 主要消耗在递归调用栈和状态数组，为 $O(L + n)$，其中 $L$ 是单词总长度， $n$ 是单词数量。

## 总结

本题的关键在于如何高效地搜索所有可能的数字分配方案。 通过 **反转单词实现从低位到高位处理** 、 **排序加数优化搜索顺序** 以及 **多种剪枝策略** ，我们可以在可接受的时间内找到所有解。 这个问题展示了回溯搜索在组合问题中的应用，以及如何通过巧妙的剪枝提高算法效率。
