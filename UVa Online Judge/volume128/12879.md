## 题目描述

你正在建造一个高尔夫机器人，它的旋钮上有 $N$ 种不同的击球距离 $k_i$。球场上共有 $M$ 个洞，每个洞距离机器人 $d_j$。

机器人可以：
- 一次击球直接进洞（如果 $d_j$ 等于某个 $k_i$）
- 两次击球进洞（如果 $d_j = k_a + k_b$，其中 $k_a, k_b$ 可以是相同的距离）

注意：不允许先打过洞再回打，必须正好在两次击球内到达洞口。

**约束条件**：
- $1 \leq N, M \leq 200,000$
- $1 \leq k_i, d_j \leq 200,000$

## 题目分析

这是一个典型的"两数之和"问题，但规模很大，需要高效算法。

### 暴力解法不可行

最直接的想法是：
- 用布尔数组标记所有可用的距离
- 对于每个洞的距离 $d$：
  - 检查是否存在 $k_i = d$（一次击球）
  - 或者检查是否存在 $k_a + k_b = d$（两次击球）

但检查两次击球时，如果对每个洞都遍历所有可能的 $k_a, k_b$ 组合，复杂度是 $O(N^2)$，在 $N=200,000$ 时完全不可行。

### 关键观察

我们需要快速知道：对于任意距离 $t$，是否存在 $k_a + k_b = t$，其中 $k_a$ 和 $k_b$ 都是可用的击球距离。

这等价于多项式乘法：如果定义多项式 $P(x) = \sum c_i x^i$，其中 $c_i = 1$ 当且仅当 $i$ 是可用距离，那么 $P(x) \cdot P(x)$ 的系数就表示两数之和等于对应指数的方案数。

## 解题思路

### 使用快速傅里叶变换（$\texttt{FFT}$）

$\texttt{FFT}$ 可以在 $O(L \log L)$ 时间内计算两个多项式的乘积，其中 $L$ 是多项式的次数。

**算法步骤**：
1. 创建布尔数组 $has[x]$，标记所有可用的击球距离
2. 使用 $\texttt{FFT}$ 计算 $has$ 与自身的卷积，得到 $sumCount$ 数组
3. 对于每个洞的距离 $d$：
   - 如果 $has[d] = \text{true}$，计数（一次击球）
   - 否则如果 $sumCount[d] > 0$，计数（两次击球）
4. 输出总计数

### 复杂度分析
- $\texttt{FFT}$ 卷积复杂度：$O(L \log L)$，其中 $L \approx 400,000$
- 总复杂度：$O(L \log L + N + M)$，完全可行

### 技术细节
- 数组大小需要开到 $2 \times \max(k_i)$ 以上
- $\texttt{FFT}$ 计算的是有序对 $(k_a, k_b)$，但这不影响我们判断是否存在解
- 注意处理数值精度问题，$\texttt{FFT}$ 结果需要四舍五入到整数

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <complex>

using namespace std;

typedef complex<double> Complex;

const double PI = acos(-1.0);

// 快速傅里叶变换
void fft(vector<Complex>& a, bool invert) {
    int n = a.size();
    // 位逆序置换
    for (int i = 1, j = 0; i < n; i++) {
        int bit = n >> 1;
        for (; j >= bit; bit >>= 1) j -= bit;
        j += bit;
        if (i < j) swap(a[i], a[j]);
    }
    
    // 迭代FFT
    for (int len = 2; len <= n; len <<= 1) {
        double ang = 2 * PI / len * (invert ? -1 : 1);
        Complex wlen(cos(ang), sin(ang));
        for (int i = 0; i < n; i += len) {
            Complex w(1);
            for (int j = 0; j < len / 2; j++) {
                Complex u = a[i + j], v = a[i + j + len / 2] * w;
                a[i + j] = u + v;
                a[i + j + len / 2] = u - v;
                w *= wlen;
            }
        }
    }
    
    // 逆变换需要除以n
    if (invert) {
        for (int i = 0; i < n; i++) a[i] /= n;
    }
}

// 多项式乘法（卷积）
vector<int> multiply(const vector<int>& a, const vector<int>& b) {
    vector<Complex> fa(a.begin(), a.end()), fb(b.begin(), b.end());
    int n = 1;
    // 扩展为2的幂次
    while (n < a.size() + b.size()) n <<= 1;
    fa.resize(n);
    fb.resize(n);
    
    // 正向FFT
    fft(fa, false);
    fft(fb, false);
    
    // 点值相乘
    for (int i = 0; i < n; i++) fa[i] *= fb[i];
    
    // 逆向FFT
    fft(fa, true);
    
    // 取实部并四舍五入
    vector<int> res(n);
    for (int i = 0; i < n; i++) res[i] = round(fa[i].real());
    return res;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    while (cin >> N) {
        vector<int> k(N);
        int max_dist = 0;
        
        // 读取可用的击球距离
        for (int i = 0; i < N; i++) {
            cin >> k[i];
            if (k[i] > max_dist) max_dist = k[i];
        }

        // 创建标记数组，has[x] = 1 表示距离x可用
        int size = 1;
        while (size <= 2 * max_dist) size <<= 1;
        vector<int> has(size, 0);
        for (int i = 0; i < N; i++) {
            has[k[i]] = 1;
        }

        // 计算两数之和的计数
        vector<int> sum_count = multiply(has, has);

        // 读取洞的距离并统计可完成的洞数
        cin >> M;
        int ans = 0;
        for (int i = 0; i < M; i++) {
            int d;
            cin >> d;
            // 检查一次击球或两次击球是否可能
            if (d < has.size() && has[d]) {
                ans++;
            } else if (d < sum_count.size() && sum_count[d] > 0) {
                ans++;
            }
        }
        cout << ans << "\n";
    }

    return 0;
}
```

## 总结

本题展示了如何将实际问题转化为多项式乘法问题，并利用 FFT 在 $O(L \log L)$ 时间内高效解决。关键点在于：

1. **问题转化**：将"两数之和"问题转化为多项式乘法
2. **算法选择**：使用 $\texttt{FFT}$ 加速卷积计算
3. **实现细节**：注意数组大小、数值精度和边界条件

这种思路还可以应用于其他需要快速统计两数之和的问题，特别是在数据规模较大时效果显著。
