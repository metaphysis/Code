## 题目描述

**$\texttt{LCM}$** 是数学中最小公倍数（$\texttt{Least Common Multiple}$）的缩写。我们说 $\text{LCM}(a,b) = L$ 当且仅当 $L$ 是能被 $a$ 和 $b$ 整除的最小整数。

给定两个整数 $N$ 和 $M$，你需要计算满足 $\text{LCM}(i,j) = i \times j$ 的数对 $(i,j)$ 的数量，其中 $1 \leq i \leq N$ 且 $1 \leq j \leq M$。

### 输入格式

输入以一个整数 $T$ ($T \leq 1000$) 开始，表示测试用例的数量。

每个测试用例包含一行两个整数 $N$ 和 $M$ ($1 \leq N,M \leq 10^9$，且 $\min(N,M) \leq 10^6$)。

### 输出格式

对于每个测试用例，输出满足条件的数对数量。

### 样例输入
```
3
1 2
4 2
3 5
```

### 样例输出
```
2
6
12
```

## 题目分析

### 关键条件转化

题目要求计算满足 $\text{LCM}(i,j) = i \times j$ 的数对 $(i,j)$ 的数量。

根据数论知识，我们知道对于任意两个正整数 $i$ 和 $j$，有：
$$
\text{LCM}(i,j) \times \text{GCD}(i,j) = i \times j
$$

其中 $\text{GCD}(i,j)$ 表示 $i$ 和 $j$ 的最大公约数。

由此可得：
$$
\text{LCM}(i,j) = i \times j \iff \text{GCD}(i,j) = 1
$$

因此，原问题转化为：计算满足 $1 \leq i \leq N$，$1 \leq j \leq M$，且 $\text{GCD}(i,j) = 1$ 的数对 $(i,j)$ 的数量。

### 问题重述

我们需要计算：
$$
\sum_{i=1}^{N} \sum_{j=1}^{M} [\gcd(i,j) = 1]
$$

其中 $[P]$ 是艾弗森括号，当命题 $P$ 为真时值为 $1$，否则为 $0$。

## 解题思路

### 莫比乌斯反演

为了计算互质对的数量，我们可以使用莫比乌斯反演公式。

设 $n = \min(N,M)$，$m = \max(N,M)$，则：
$$
\sum_{i=1}^{N} \sum_{j=1}^{M} [\gcd(i,j) = 1] = \sum_{d=1}^{n} \mu(d) \left\lfloor \frac{N}{d} \right\rfloor \left\lfloor \frac{M}{d} \right\rfloor
$$

其中 $\mu(d)$ 是莫比乌斯函数，定义为：
- $\mu(1) = 1$
- 如果 $d$ 是 $k$ 个不同质数的乘积，则 $\mu(d) = (-1)^k$
- 如果 $d$ 有平方因子，则 $\mu(d) = 0$

### 算法步骤

1. **预处理莫比乌斯函数**：使用线性筛法在 $O(n)$ 时间内预处理出 $[1, 10^6]$ 范围内的莫比乌斯函数值。

2. **计算答案**：对于每个测试用例，使用公式：
   $$
   \text{答案} = \sum_{d=1}^{\min(N,M)} \mu(d) \cdot \left\lfloor \frac{N}{d} \right\rfloor \cdot \left\lfloor \frac{M}{d} \right\rfloor
   $$

3. **时间复杂度分析**：
   - 预处理：$O(10^6)$
   - 每个测试用例：$O(\min(N,M))$
   - 总体：在题目约束下可行

### 算法优化

虽然直接计算的时间复杂度为 $O(\min(N,M))$，但可以使用整除分块技术将其优化到 $O(\sqrt{\min(N,M)})$。不过由于题目条件 $\min(N,M) \leq 10^6$，直接计算已经足够高效。

## 代码实现

```cpp
// Count LCM
// UVa ID: 12888

// Submission Date: 2025-11-25
// UVa Run Time: 0.700s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e6 + 10;

vector<int> primes;
bool isPrime[MAXN];
int mu[MAXN];

void sieve() {
    fill(isPrime, isPrime + MAXN, true);
    isPrime[0] = isPrime[1] = false;
    mu[1] = 1;
    
    for (int i = 2; i < MAXN; i++) {
        if (isPrime[i]) {
            primes.push_back(i);
            mu[i] = -1;
        }
        for (int p : primes) {
            if (i * p >= MAXN) break;
            isPrime[i * p] = false;
            if (i % p == 0) {
                mu[i * p] = 0;
                break;
            } else {
                mu[i * p] = -mu[i];
            }
        }
    }
}

long long solve(int n, int m) {
    if (n > m) swap(n, m);
    long long res = 0;
    for (int d = 1; d <= n; d++) 
        res += (long long)mu[d] * (n / d) * (m / d);
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    sieve();
    
    int t;
    cin >> t;
    while (t--) {
        int n, m;
        cin >> n >> m;
        cout << solve(n, m) << "\n";
    }
    
    return 0;
}
```

## 代码说明

1. **筛法预处理**：
   - `sieve()` 函数使用线性筛法同时标记素数和计算莫比乌斯函数
   - `mu[1] = 1` 是莫比乌斯函数的定义
   - 对于素数 $p$，有 $\mu(p) = -1$
   - 如果 $i$ 能被 $p$ 整除，则 $\mu(i \times p) = 0$（因为有平方因子）
   - 否则，$\mu(i \times p) = -\mu(i)$

2. **计算答案**：
   - `solve(n, m)` 函数计算互质对的数量
   - 通过交换确保 $n \leq m$，减少循环次数
   - 使用公式 $\sum \mu(d) \cdot \lfloor n/d \rfloor \cdot \lfloor m/d \rfloor$ 计算结果

3. **输入输出优化**：
   - 使用 `ios::sync_with_stdio(false)` 和 `cin.tie(0)` 加速输入输出

该解法充分利用了题目条件 $\min(N,M) \leq 10^6$，通过预处理和直接计算在合理时间内解决问题。
