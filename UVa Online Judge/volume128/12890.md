## 题目描述

给定一个整数数组，统计所有不包含重复整数的连续子数组（即子段）的数量。例如，数组 $\{1, 2, 1\}$ 中不包含重复整数的子数组数量是 $5$ 。在从 $0$ 索引下，这些子数组分别是 $(0,1)$ 、$(1,2)$ 、$(0)$ 、$(1)$ 、$(2)$ 。

### 输入格式

输入以 $T$（ $T \leq 20$ ）开始，表示测试用例的数量。  
每个测试用例的第一行是一个整数 $N$（ $1 \leq N \leq 100000$ ），表示数组长度。  
第二行包含 $N$ 个整数，用空格分隔，第 $i$ 个整数 $arr[i]$ 满足 $0 \leq arr[i] \leq 10^9$ 。

### 输出格式

对于每个测试用例，输出不包含重复整数的子数组数量。

### 样例输入

```
2
3
1 2 1
5
1 2 3 1 2
```

### 样例输出

```
5
12
```

## 题目分析

本题要求统计数组中所有不包含重复整数的连续子数组的个数。  
暴力枚举所有子数组并检查是否重复的时间复杂度为 $O(N^2)$ ，在 $N$ 最大可达 $10^5$ 的情况下显然会超时。  
因此，我们需要寻找一种能在 $O(N)$ 或 $O(N \log N)$ 时间复杂度内解决的方法。

### 关键观察

1. **子数组是连续的** ：这是我们可以使用滑动窗口（双指针）方法的基础。
2. **重复的判断** ：在一个子数组中，如果某个整数出现两次或以上，则子数组非法。
3. **以右端点计数的思想** ：对于每个位置 $right$ ，我们计算以 $arr[right]$ 为结尾且不包含重复整数的子数组个数，然后将它们累加。

### 滑动窗口思路

我们维护一个窗口 $[left, right]$ ，保证窗口内的所有整数都不重复。  
为了快速判断一个整数是否已经在窗口中出现，我们可以使用一个哈希表 $lastPos$ 来记录每个整数最后一次出现的位置（索引）。

- 当 $right$ 向右移动时，将 $arr[right]$ 加入窗口。
- 如果 $arr[right]$ 已经在窗口中（即 $lastPos[arr[right]] \geq left$ ），说明出现了重复，此时需要将 $left$ 移动到 $lastPos[arr[right]] + 1$ ，以保证窗口内不重复。
- 更新 $lastPos[arr[right]] = right$ 。
- 此时，以 $right$ 结尾且不重复的子数组个数就是 $right - left + 1$ ，将它们累加到答案中。

**为什么这样做是正确的？**  
因为对于每个固定的 $right$ ，所有以 $right$ 结尾且不重复的子数组的左端点必须 $\geq left$ ，且由于 $left$ 是满足不重复条件的最小索引，所以左端点可以在 $[left, right]$ 之间任意选择，共有 $right - left + 1$ 种选择。

### 时间复杂度分析

- 每个元素最多被 $left$ 和 $right$ 指针访问一次。
- 哈希表的插入和查询操作平均为 $O(1)$ 。
- 总时间复杂度为 $O(N)$ ，满足题目要求。

### 空间复杂度分析

- 哈希表最多存储 $N$ 个键值对，空间复杂度为 $O(N)$ 。

## 解题步骤（算法流程）

1. 读入测试用例数 $T$ 。
2. 对于每个测试用例：
   1. 读入数组长度 $N$ 和数组 $arr$ 。
   2. 初始化哈希表 $lastPos$ ，用于记录每个整数最近一次出现的位置。
   3. 初始化 $left = 0$ ，$ans = 0$ 。
   4. 遍历 $right$ 从 $0$ 到 $N-1$ ：
      1. 若 $arr[right]$ 在 $lastPos$ 中存在且其位置 $\geq left$ ，则更新 $left = lastPos[arr[right]] + 1$ 。
      2. 更新 $lastPos[arr[right]] = right$ 。
      3. $ans$ 增加 $right - left + 1$ 。
   5. 输出 $ans$ 。

## 代码实现

```cpp
// Easy Peasy
// UVa ID: 12890
// Verdict: Accepted
// Submission Date: 2026-02-02
// UVa Run Time: 0.070s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n; cin >> n;
    vector<long long> arr(n);
    for (int i = 0; i < n; ++i) cin >> arr[i];
    unordered_map<long long, int> lastPos;
    long long ans = 0;
    int left = 0;
    for (int right = 0; right < n; ++right) {
        if (lastPos.find(arr[right]) != lastPos.end() && lastPos[arr[right]] >= left)
            left = lastPos[arr[right]] + 1;
        lastPos[arr[right]] = right;
        ans += right - left + 1;
    }
    cout << ans << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T; cin >> T;
    while (T--) solve();
    return 0;
}
```

## 总结

本题是一道经典的滑动窗口应用题，关键在于理解“以右端点计数”的思想以及如何高效地判断重复。通过维护一个不包含重复整数的窗口，我们可以在 $O(N)$ 时间内得到答案。该算法不仅高效，而且代码简洁，易于实现。
