## 题目分析

本题要求计算从 $A$ 到 $B$ 的连续整数序列的**按位或**和**按位与**结果。给定 $T$ 组测试数据，每组包含两个整数 $A$ 和 $B$，其中 $1 \leq A \leq B \leq 10^{18}$。

### 关键挑战
- **数据范围极大**：$B$ 最大可达 $10^{18}$，不能使用暴力循环
- **时间复杂度要求**：$T$ 最多 $10^5$，每组必须 $O(1)$ 解决
- **位运算性质**：需要利用位运算的数学性质来优化

## 解题思路

### 1. 区间按位与的性质

对于连续整数序列 $A, A+1, A+2, \dots, B$：
- 从二进制角度看，随着数字递增，低位会不断变化
- 任何一位只要在序列中出现过 $0$，该位在 $\texttt{AND}$ 结果中就是 $0$
- 只有 $A$ 和 $B$ 的**公共二进制前缀**在 $\texttt{AND}$ 中保持不变

**实现方法**：
```cpp
// 不断右移 A 和 B 直到相等，记录右移次数
// 然后将公共前缀左移回原来的位置
```

### 2. 区间按位或的性质

对于连续整数序列 $A, A+1, A+2, \dots, B$：
- 从 $A$ 到 $B$ 的连续变化会导致某些位必然出现 $1$
- 找到 $A$ 和 $B$ 第一个不同的二进制位
- 从该位开始往右的所有位在 $\texttt{OR}$ 结果中都是 $1$

**实现方法**：
```cpp
// 计算 A XOR B 找到第一个不同的位
// 构造一个掩码，将该位及右边所有位置为 1
// 将 A 或 B 与掩码进行 OR 运算
```

## 算法步骤

1. **区间按位与计算**：
   - 不断右移 $A$ 和 $B$ 直到它们相等
   - 记录右移的次数 $\texttt{shift}$
   - 返回 $A \ll \texttt{shift}$（左移回原位）

2. **区间按位或计算**：
   - 如果 $A = B$，直接返回 $A$
   - 计算 $A \oplus B$ 找到第一个不同的位
   - 构造掩码 $(1 \ll (\texttt{shift} + 1)) - 1$
   - 返回 $(A \& \sim \texttt{mask}) | \texttt{mask}$

#include <iostream>
using namespace std;

typedef unsigned long long ull;

// 计算区间按位与
ull rangeAnd(ull a, ull b) {
    int shiftCount = 0;
    // 找到 a 和 b 的公共前缀
    while (a != b) {
        a >>= 1;
        b >>= 1;
        shiftCount++;
    }
    // 将公共前缀左移回原位
    return a << shiftCount;
}

// 计算区间按位或
ull rangeOr(ull a, ull b) {
    if (a == b) return a;
    // 找到第一个不同的位
    int firstDiffBit = 63 - __builtin_clzll(a ^ b);
    // 构造掩码：从第一个不同位往右全部置 1
    ull mask = (1ULL << (firstDiffBit + 1)) - 1;
    // 保留高位，低位全置 1
    ull highBits = (a >> (firstDiffBit + 1)) << (firstDiffBit + 1);
    return highBits | mask;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int testCases;
    cin >> testCases;
    for (int caseNum = 1; caseNum <= testCases; caseNum++) {
        ull start, end;
        cin >> start >> end;
        ull orResult = rangeOr(start, end);
        ull andResult = rangeAnd(start, end);
        cout << "Case " << caseNum << ": " << orResult << " " << andResult << "\n";
    }
    return 0;
}
