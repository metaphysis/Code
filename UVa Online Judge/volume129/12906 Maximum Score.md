
> **摘要**：本题给定若干「值–频数」对，可任意重排，每个元素的分数为包含它的最长单峰子序列长度。文章证明每个元素的分数上限为不大于它的元素总数，且当排列整体呈单峰形状时所有元素可同时达到上限，从而最大总分为 $\sum f_i \cdot F_i$；达到最大值的排列数为 $\prod_{i=1}^{p-1}(f_i+1) \bmod (10^9+7)$。最终算法只需排序后求前缀和与连乘，时间复杂度 $O(p\log p)$。

## 题目描述

$\texttt{Ron}$ 喜欢玩整数游戏。给定 $n$ 个整数，$\texttt{Ron}$ 可以任意排列它们。对于某个排列，每个位置上的元素都有一个“分数”：以该位置为中心的最长“单峰”子序列的长度，该子序列先非递减后非递增，且必须包含该元素。$\texttt{Ron}$ 的总分等于所有元素分数之和。  
现在需要计算出**最大可能的总分**，以及**能够达到该最大总分的不同排列个数**（对 $10^9+7$ 取模）。  

输入中给出的是值 – 频数对，所有值互不相同。两个排列不同定义为至少存在一个位置上的数值不同。

## 输入格式

第一行一个整数 $T$（$1 \le T \le 200$），表示测试用例数。  
每个测试用例第一行一个整数 $p$（$1 \le p \le 10^5$）。  
第二行包含 $p$ 对整数，每对 $(v_i, f_i)$ 表示数值 $v_i$ 出现 $f_i$ 次，其中 $1 \le v_i, f_i \le 10^5$，所有 $v_i$ 互不相同，且 $\sum f_i = n$。

## 输出格式

对于每个测试用例，输出一行：  
`Case x: maxSum ways`  
其中 `maxSum` 是最大总分（适合 64 位无符号整数），`ways` 是达到该总分的排列数对 $10^9+7$ 取模的结果。

## 样例

输入
```text
2
2
121 1 22 1
2
71 2 35 1
```
输出
```text
Case 1: 3 2
Case 2: 7 2
```

## 题目分析

给定一组数，其值可重复，我们可任意重排。对于某个排列，定义一个元素 $x$ 的分数为包含该元素的最长“单峰”子序列的长度。该子序列需满足：存在一个中心位置为该元素，左侧元素值非递减，右侧元素值非递增。换言之，子序列先升后降（允许相等），且必须包含该元素。

目标是最大化所有元素分数之和，并统计达到此最大值的排列数。

首先，考虑任意一个元素 $a$。若其值为 $v$，则任何包含它的单峰子序列中，所有元素的值都必须 $\le v$（因为左侧不大于中心，右侧不大于中心）。因此，该元素的分数不可能超过**全体不大于 $v$ 的元素总个数**。设所有值按升序排列为 $v_1 < v_2 < \cdots < v_p$，频数为 $f_i$，定义前缀和 $F_i = \sum_{j=1}^i f_j$。则任意一个值为 $v_i$ 的元素，其分数上限为 $F_i$。

我们能否让所有元素同时达到这个上限？这要求排列本身满足：对于每个元素，存在一个包含它的单峰子序列，且该子序列可以包含所有不大于该元素的值。当整个排列呈现“先非递减后非递增”的单峰形状时，对于任意一个元素，取整个排列作为子序列即可满足条件（左侧非递减，右侧非递增），并且该子序列包含的元素个数恰好是整个排列中不大于该元素的所有元素（即 $F_i$）。因此，最大值即为所有元素的上界之和：

$$
\textit{maxSum} = \sum_{i=1}^p f_i \cdot F_i
$$

接下来需要统计能形成单峰排列的排列个数，使得每个元素的分数都达到其上限。要保证所有元素分数达到上限，排列必须是单峰的：即存在一个峰值位置（可能多个最大值相邻），左侧按非递减排列，右侧按非递增排列。由于所有最大值 $v_p$ 必须放在峰值区域，且它们之间可以任意顺序（但数值相同，交换无区别），为了唯一计数，我们固定所有最大值连续放在峰值中心。对于其他每个值 $v_i$（$i < p$），它的 $f_i$ 个元素需要被分配到左侧（升序部分）和右侧（降序部分）。左侧的顺序必须按值升序，右侧按值降序，因此一旦决定每个值有多少个元素放在左侧，整个排列就唯一确定。对于 $v_i$，可选择放在左侧的个数为 $0,1,\dots,f_i$，共 $f_i+1$ 种选择。各值之间的选择相互独立，所以总排列数为

$$
\textit{ways} = \prod_{i=1}^{p-1} (f_i+1) \pmod{10^9+7}
$$

其中最大值 $v_p$ 不参与分配，因为全部放在中间。

综上，问题简化为：按值排序，计算前缀频数和累积贡献，以及除最后一个值外所有 $(f_i+1)$ 的乘积。

## 解题思路

根据上述分析，算法步骤明确：

1. 读入每个测试用例的 $p$ 对 $(v_i, f_i)$。
2. 按照 $v_i$ 升序排序。
3. 初始化前缀和 $\textit{pref} = 0$，最大总分 $\textit{maxSum} = 0$（使用 `unsigned long long`）。
4. 遍历排序后的数组：
   - $\textit{pref} \leftarrow \textit{pref} + f_i$
   - $\textit{maxSum} \leftarrow \textit{maxSum} + f_i \times \textit{pref}$
5. 初始化方案数 $\textit{ways} = 1$。
6. 对 $i$ 从 $0$ 到 $p-2$（即除最大值外）：
   - $\textit{ways} \leftarrow \textit{ways} \times (f_i + 1) \bmod (10^9+7)$
7. 按格式输出结果。

复杂度：排序 $O(p\log p)$，遍历 $O(p)$，总体 $O(p\log p)$，空间 $O(p)$。$p$ 最大 $10^5$，$T$ 最大 $200$，但总输入量有限，可以接受。

## 代码实现

```cpp
// Maximum Score

#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;
const int MOD = 1000000007;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int T;
    cin >> T;
    for (int tc = 1; tc <= T; ++tc) {
        int p;
        cin >> p;
        vector<pair<int,int>> a(p);
        for (int i = 0; i < p; ++i)
            cin >> a[i].first >> a[i].second;

        sort(a.begin(), a.end());

        ull maxSum = 0;
        ull pref = 0;
        for (int i = 0; i < p; ++i) {
            pref += a[i].second;
            maxSum += (ull)a[i].second * pref;
        }

        long long ways = 1;
        for (int i = 0; i < p - 1; ++i)
            ways = ways * (a[i].second + 1) % MOD;

        cout << "Case " << tc << ": " << maxSum << " " << ways << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于识别“单峰”结构与分数上界的关系。通过分析，我们发现最大总分就是每个元素所能达到的最大可能分数之和，而达到该最大值要求排列必须为单峰形状。该结论大大简化了问题，将原问题转化为排序、前缀和与简单乘积运算。

解题的启示：
- 当需要最大化多个元素的得分时，先找出每个元素的独立上限，然后判断能否同时达到。
- 计数时注意去除重复计数，利用相同值元素的无差别性，通过分配左侧个数来唯一确定排列。
- 大整数使用 $64$ 位无符号整数存储，取模运算使用 $10^9+7$。

该解法思路清晰，时空效率优秀，适用于给定的数据范围。
