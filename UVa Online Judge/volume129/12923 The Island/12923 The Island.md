
> **摘要**：本文讨论一个经典的二分图最大权完美匹配问题——将 $n$ 把武器分配给 $n$ 名幸存者，使总能力值最大。文章从题意出发，把幸存者与武器分别建模为二分图左右部顶点、能力值作为边权，指出问题本质是求最大权完美匹配；随后详细讲解 $\texttt{KM}$ 算法的顶标、相等边、松弛数组与顶标调整机制，并给出时间复杂度 $O(n^3)$、空间复杂度 $O(n^2)$ 的 $\texttt{C++11}$ 完整实现，可直接用于多组测试数据。

# 题目描述

末日之后，岛上有 $n$ 名幸存者和 $n$ 把武器。每名幸存者使用不同武器的能力值不同，需要将所有武器分配给所有幸存者，使每名幸存者恰好获得一把武器，并且每把武器恰好分配给一名幸存者。

求所有分配方案中能力值总和的最大值。

# 输入格式

输入包含多组测试数据，每组测试数据的格式如下：

第一行包含一个整数 $n$，表示幸存者数量和武器数量，满足 $1 \le n \le 100$。

接下来有 $n$ 行，每行包含 $n$ 个整数 $q_{ij}$，其中 $q_{ij}$ 表示第 $i$ 名幸存者使用第 $j$ 把武器时的能力值，满足 $0 \le q_{ij} \le 1000$。

输入持续到文件结束。

# 输出格式

对于每组测试数据，输出一行一个整数，表示最优分配方案得到的最大能力值。

# 样例输入

```text
5
1 2 7 3 0
3 4 1 0 2
2 3 6 0 0
0 6 1 1 0
2 0 0 4 5
2
1 3
5 9
2
1 6
5 9
```

# 样例输出

```text
23
10
11
```

# 题目分析

将每名幸存者看作二分图左部的一个顶点，将每把武器看作二分图右部的一个顶点。若第 $i$ 名幸存者使用第 $j$ 把武器，则在左部顶点 $i$ 和右部顶点 $j$ 之间连接一条边，边权为 $q_{ij}$。

由于每名幸存者必须获得一把武器，并且每把武器只能分配给一名幸存者，所以最终需要选择 $n$ 条边，使左部和右部的每个顶点都恰好被选择一次。这正是一个二分图最大权完美匹配问题。

设第 $i$ 名幸存者最终获得第 $p_i$ 把武器，则分配方案的总能力值为：

$$
\sum_{i=1}^{n} q_{i,p_i}
$$

其中 $p_i$ 互不相同。题目要求最大化上述总和。

普通匈牙利算法主要解决二分图最大基数匹配，而本题的边具有权值，因此需要使用带权匹配算法。代码采用 $\texttt{KM}$ 算法解决最大权完美匹配问题。

# 解题思路

$\texttt{KM}$ 算法为每个左部顶点维护一个顶标 $lx$，为每个右部顶点维护一个顶标 $ly$，并始终满足：

$$
lx_i + ly_j \ge q_{ij}
$$

当某条边满足：

$$
lx_i + ly_j = q_{ij}
$$

这条边称为相等边。算法只在相等边上寻找增广路，从而逐步构造最大权匹配。

初始时，将每个左部顶点的顶标设置为该顶点关联边权的最大值，将所有右部顶点的顶标设置为 $0$。此时所有边均满足顶标条件。

对于每个左部顶点，算法执行以下过程：

- 初始化左部顶点访问标记、右部顶点访问标记和松弛数组。
- 在当前相等边构成的子图中寻找增广路。
- 如果找到增广路，则更新匹配关系，继续处理下一个左部顶点。
- 如果找不到增广路，则计算所有未访问右部顶点对应松弛值的最小值 $d$。
- 对所有已访问的左部顶点，将顶标减去 $d$。
- 对所有已访问的右部顶点，将顶标加上 $d$。
- 对所有未访问的右部顶点，将松弛值减去 $d$。
- 顶标调整后会产生新的相等边，再次寻找增广路。

松弛值表示当前左部搜索树到某个未访问右部顶点的最小顶标差：

$$
slack_j = \min_{i \in S} (lx_i + ly_j - q_{ij})
$$

其中 $S$ 表示当前已经访问到的左部顶点集合。取所有未访问右部顶点的最小松弛值作为顶标调整量，可以保证顶标条件不会被破坏，并且至少产生一条新的相等边。

在寻找增广路时，如果右部顶点 $j$ 尚未匹配，则可以直接将其匹配给当前左部顶点。如果右部顶点 $j$ 已经匹配给其他左部顶点，则递归尝试为原匹配的左部顶点寻找新的武器。该过程与增广路匹配过程一致。

当所有左部顶点都成功匹配后，右部匹配数组中记录了完整的分配方案。遍历所有右部顶点，将对应匹配边的权值累加，即可得到最大能力值。

设左部顶点数量为 $n$。每个左部顶点可能进行多次增广和顶标调整，每次搜索需要遍历 $O(n^2)$ 条关系，整体时间复杂度为：

$$
O(n^3)
$$

算法使用权值矩阵、顶标数组、匹配数组、访问标记和松弛数组，空间复杂度为：

$$
O(n^2)
$$

# 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int maxN = 105;
const int inf = 0x3f3f3f3f;

int n, w[maxN][maxN], lx[maxN], ly[maxN], matchY[maxN], slack[maxN];
bool visX[maxN], visY[maxN];

bool findPath(int x) {
    visX[x] = true;
    for (int y = 1; y <= n; y++) {
        if (visY[y]) continue;
        int gap = lx[x] + ly[y] - w[x][y];
        if (gap == 0) {
            visY[y] = true;
            if (!matchY[y] || findPath(matchY[y])) {
                matchY[y] = x;
                return true;
            }
        } else if (slack[y] > gap) {
            slack[y] = gap;
        }
    }
    return false;
}

int kmSolve() {
    fill(lx + 1, lx + n + 1, 0);
    fill(ly + 1, ly + n + 1, 0);
    fill(matchY + 1, matchY + n + 1, 0);
    for (int x = 1; x <= n; x++) {
        lx[x] = w[x][1];
        for (int y = 2; y <= n; y++) lx[x] = max(lx[x], w[x][y]);
    }
    for (int x = 1; x <= n; x++) {
        fill(slack + 1, slack + n + 1, inf);
        while (true) {
            fill(visX + 1, visX + n + 1, false);
            fill(visY + 1, visY + n + 1, false);
            if (findPath(x)) break;
            int d = inf;
            for (int y = 1; y <= n; y++) if (!visY[y]) d = min(d, slack[y]);
            for (int i = 1; i <= n; i++) if (visX[i]) lx[i] -= d;
            for (int y = 1; y <= n; y++) {
                if (visY[y]) ly[y] += d;
                else slack[y] -= d;
            }
        }
    }
    int ans = 0;
    for (int y = 1; y <= n; y++) ans += w[matchY[y]][y];
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    while (cin >> n) {
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                cin >> w[i][j];
        cout << kmSolve() << '\n';
    }
    return 0;
}
```

# 总结

本题的本质是二分图最大权完美匹配问题。将幸存者和武器分别建模为二分图的两侧顶点，将能力值作为边权后，可以使用 $\texttt{KM}$ 算法求解。

算法的关键点如下：

- 使用顶标保证所有边满足 $lx_i + ly_j \ge q_{ij}$。
- 只在满足 $lx_i + ly_j = q_{ij}$ 的相等边上寻找增广路。
- 使用松弛数组记录未访问右部顶点与当前搜索树之间的最小差值。
- 找不到增广路时调整顶标，使新的相等边产生。
- 当所有左部顶点均完成匹配时，匹配边权值总和就是最大能力值。

该实现符合 $\texttt{C++11}$ 标准，时间复杂度为 $O(n^3)$，能够满足题目数据范围。
