[UVa 12946 Peanoland Contacting Gaussland](https://blog.csdn.net/metaphysis/article/details/156241328)

## 题目重述

$\texttt{Peanoland}$ 使用自然数 $p \in \mathbb{N}$ ，而 $\texttt{Gaussiand}$ 使用高斯整数 $g = a + b i \in \mathbb{Z}[i]$ 。它们之间的对应关系由**相同的二进制系数** $b_k \in \{0,1\}$ 决定：

$$
p = \sum_{k=0}^{n} b_k \cdot 2^{k}
$$

$$
g = \sum_{k=0}^{n} b_k \cdot (i-1)^{k}
$$

给定 $p$ ，求对应的 $g = a + b i$ ，即输出 $a$ 和 $b$ 。

**输入格式**  
多组测试数据，每组一行一个自然数 $p$ （ $0 \le p < 10^9$ ）。

**输出格式**  
每组输出两个整数 $a$ 和 $b$ ，用空格隔开。

---

## 题目分析

本题的核心是理解 **二进制表示** 与 **复数进制展开** 之间的对应关系。

### 1. 理解转换规则

对于同一个 $n$ 和相同的二进制系数序列 $b_0, b_1, \dots, b_n$ ，我们有两种展开：

- 在 **$\texttt{Peanoland}$** 系统中，基数是 $2$ ，所以 $p = b_0 \cdot 2^0 + b_1 \cdot 2^1 + \dots + b_n \cdot 2^n$ 。
- 在 **$\texttt{Gaussiand}$** 系统中，基数是 $(i-1)$ ，所以 $g = b_0 \cdot (i-1)^0 + b_1 \cdot (i-1)^1 + \dots + b_n \cdot (i-1)^n$ 。

因此，如果我们能求出 $p$ 的二进制表示（即 $b_k$ 序列），那么 $g$ 就可以直接通过计算上述复数多项式得到。

### 2. 计算 $(i-1)^k$ 的实部与虚部

设 $(i-1)^k = a_k + b_k i$ ，其中 $a_k, b_k \in \mathbb{Z}$ 。  
我们有递推关系：

$$
(i-1)^{k+1} = (i-1)^k \cdot (i-1)
$$

将 $(i-1)^k = a_k + b_k i$ 代入：

$$
(a_k + b_k i)(-1 + i) = -a_k - b_k i + a_k i + b_k i^2
$$

因为 $i^2 = -1$ ，所以：

$$
= -a_k - b_k i + a_k i - b_k
$$

合并实部与虚部：

- 实部：$-a_k - b_k$
- 虚部：$a_k - b_k$

因此：

$$
a_{k+1} = -a_k - b_k
$$

$$
b_{k+1} = a_k - b_k
$$

初始条件： $k=0$ 时， $(i-1)^0 = 1$ ，所以 $a_0 = 1$ ， $b_0 = 0$ 。

### 3. 算法步骤

对于给定的 $p$ ：

1. 初始化 $a_{total} = 0$ ， $b_{total} = 0$ （用于累加 $g$ 的实部与虚部）。
2. 初始化 $a_k = 1$ ， $b_k = 0$ （对应 $k=0$ 的 $(i-1)^0$ ）。
3. 从 $k=0$ 开始，每次检查 $p$ 的最低位（ $p \bmod 2$ ）：
   - 如果最低位为 $1$ ，则将当前的 $(a_k, b_k)$ 加到 $(a_{total}, b_{total})$ 上。
4. 更新 $(a_k, b_k)$ 为 $(a_{k+1}, b_{k+1})$ （使用上述递推公式）。
5. 将 $p$ 右移一位（即 $p = \lfloor p/2 \rfloor$ ），重复步骤 3~5 直到 $p=0$ 。
6. 输出 $a_{total}$ 和 $b_{total}$ 。

### 4. 时间复杂度

$p$ 的二进制位数是 $O(\log p)$ ，每个位处理 $O(1)$ 时间，因此总时间复杂度 $O(\log p)$ ，可以轻松处理 $p < 10^9$ 的情况。

## 示例验证

以样例 $p = 292$ 为例：

$292$ 的二进制是 $100100100_2$ （从低到高：位 $k=2, 5, 8$ 为 $1$ ）。

计算 $(i-1)^k$ ：

- $k=0$ ： $1$
- $k=1$ ： $-1 + i$
- $k=2$ ： $-2i$
- $k=3$ ： $2 + 2i$
- $k=4$ ： $-4$
- $k=5$ ： $4 - 4i$
- $k=6$ ： $8i$
- $k=7$ ： $-8 - 8i$
- $k=8$ ： $16$

$g = (i-1)^2 + (i-1)^5 + (i-1)^8 = (-2i) + (4 - 4i) + 16 = 20 - 6i$ 。

输出： $20$ $-6$ ，与样例一致。

## 代码实现

```cpp
// Peanoland Contacting Gaussland
// UVa ID: 12946
// Verdict: Accepted
// Submission Date: 2025-12-24
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long p;
    while (cin >> p) {
        long long aTotal = 0, bTotal = 0; // 总和 a + bi
        long long ak = 1, bk = 0;         // (i-1)^k 的实部和虚部系数

        while (p > 0) {
            if (p & 1) { // 当前二进制位为1
                aTotal += ak;
                bTotal += bk;
            }
            // 更新 (i-1)^(k+1) = (i-1)^k * (i-1)
            long long aNext = -ak - bk;
            long long bNext = ak - bk;
            ak = aNext;
            bk = bNext;

            p >>= 1; // 移到下一位
        }

        cout << aTotal << " " << bTotal << "\n";
    }

    return 0;
}
```

## 总结

本题的关键在于理解 **二进制系数在两个不同基数下的展开对应同一个系数序列** 。通过递推计算 $(i-1)^k$ 的实部与虚部，并在遍历 $p$ 的二进制位时累加，即可得到对应的高斯整数。算法高效，适合题目范围。

---

**注意**：题目中 $p$ 可以达到 $10^9$ ，二进制位数最多约 $30$ 位， $(i-1)^k$ 的系数可能较大，因此使用 `long long` 存储以避免溢出。
