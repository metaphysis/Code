[UVa 12953 Puzzle](https://blog.csdn.net/metaphysis/article/details/161461690)

## 题目描述

给定一个 $L \times C$ 的网格，每个格子包含一个变量名（由两个小写字母组成）。已知每行所有变量的和以及每列所有变量的和，要求确定每个变量的值。题目保证解唯一，且所有变量值为 $[-10^6, 10^6]$ 内的整数，同时保证总是存在某一行或某一列，其中只有一个变量的值未知。因此可以采用逐步求解的方式，每次确定一个变量的值。

### 输入格式
- 第一行：两个整数 $L$ 和 $C$
- 接下来 $L$ 行：每行 $C$ 个变量名，随后一个整数表示该行的和
- 最后一行：$C$ 个整数表示每列的和

### 输出格式
- 按字典序（$\texttt{aa}, \texttt{ab}, \dots, \texttt{zz}$）输出每个变量及其值，每行一个

## 题目分析

本题的关键在于理解“总是可以找到一行或一列，其中只有一个变量的值未知”这一性质。这意味着我们可以像解方程组一样，每次找到一个只包含一个未知变量的方程，解出该变量，然后代入其他方程，重复此过程直到所有变量都确定。

需要注意的是，同一个变量名可能在网格中出现多次。当我们解出一个变量时，该变量在网格中的所有出现位置都应被标记为已知，并更新这些位置所在的行和列的已知和。

## 解题思路

### 1. 数据结构设计

- `grid`：存储每个格子的变量名
- `rowSum`、`colSum`：存储每行和每列的目标总和
- `varPos`：映射从变量名到其所有出现位置（行，列）的列表
- `solved`：记录每个变量是否已经求解
- `value`：存储每个变量的解
- `cellKnown`：标记每个格子是否已被确定（即其变量的值已知）
- `rowKnownSum`、`colKnownSum`：存储每行和每列当前已知部分的和
- `rowUnknownVars`、`colUnknownVars`：存储每行和每列中还有多少个格子的变量未知

### 2. 求解过程

#### 2.1 确定可解的行或列

对于每一行，统计其中所有未知格子对应的变量名及其出现次数。如果这些未知格子对应的变量名只有一种，那么该行只有一个未知变量（即使该变量多次出现），可以用该行的和减去已知部分的和，再除以该变量出现的次数，得到该变量的值。

同理处理每一列。

#### 2.2 求解变量

当确定某行或某列只有一个未知变量时，计算该变量的值：

- 设该行（列）的总和为 $S$
- 已知部分的和为 $K$
- 未知变量出现的次数为 $cnt$
- 则变量值 $val = (S - K) / cnt$

由于题目保证有整数解，此处除法一定是整除。

#### 2.3 更新状态

解出一个变量后：
1. 标记该变量为已求解
2. 遍历该变量的所有出现位置：
   - 标记对应格子为已知
   - 将该变量的值累加到所在行的已知和
   - 将该变量的值累加到所在列的已知和
   - 减少该行和该列的未知变量计数

#### 2.4 循环求解

重复上述过程，直到所有变量都被求解。由于题目保证每一步都存在可解的行或列，该过程必然终止。

### 3. 复杂度分析

- 每次求解一个变量，最多需要扫描 $O(L \times C)$ 个格子来更新状态
- 总共有 $O(L \times C)$ 个格子，但变量数不超过 $26 \times 26 = 676$ 个
- 每次迭代需要检查所有行和列，共 $O(L + C)$ 次检查
- 总体复杂度 $O((L + C) \times \text{变量数} \times \text{平均出现次数})$，在给定数据范围内可以接受

## 代码实现

```cpp
// Puzzle
// UVa ID: 12953
// Verdict: Accepted
// Submission Date: 2026-05-27
// UVa Run Time: 0.330s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int L, C;
    while (cin >> L >> C) {
        vector<vector<string>> grid(L, vector<string>(C));
        vector<long long> rowSum(L), colSum(C);
        
        // 读入网格和行和
        for (int i = 0; i < L; ++i) {
            for (int j = 0; j < C; ++j)
                cin >> grid[i][j];
            cin >> rowSum[i];
        }
        
        // 读入列和
        for (int j = 0; j < C; ++j)
            cin >> colSum[j];
        
        // 记录每个变量出现的位置
        map<string, vector<pair<int, int>>> varPos;
        for (int i = 0; i < L; ++i)
            for (int j = 0; j < C; ++j)
                varPos[grid[i][j]].emplace_back(i, j);
        
        // 记录每个变量是否已求解
        map<string, bool> solved;
        map<string, long long> value;
        
        // 记录每个格子是否已确定值
        vector<vector<bool>> cellKnown(L, vector<bool>(C, false));
        
        // 记录每行/列当前已知值的和
        vector<long long> rowKnownSum(L, 0), colKnownSum(C, 0);
        
        // 记录每行/列中还有多少个格子的变量未知
        vector<int> rowUnknownVars(L), colUnknownVars(C);
        for (int i = 0; i < L; ++i) rowUnknownVars[i] = C;
        for (int j = 0; j < C; ++j) colUnknownVars[j] = L;
        
        // 用于判断某行/列是否只有一个不同的未知变量
        // 返回该变量名和出现次数
        auto getUniqueUnknownVar = [&](int row, bool isRow) {
            map<string, int> varCount;
            if (isRow) {
                for (int j = 0; j < C; ++j) {
                    if (!cellKnown[row][j]) {
                        string var = grid[row][j];
                        varCount[var]++;
                    }
                }
            } else {
                int col = row; // 复用参数
                for (int i = 0; i < L; ++i) {
                    if (!cellKnown[i][col]) {
                        string var = grid[i][col];
                        varCount[var]++;
                    }
                }
            }
            if (varCount.size() == 1)
                return make_pair(varCount.begin()->first, varCount.begin()->second);
            return make_pair(string(""), 0);
        };
        
        // 求解变量
        auto solveVariable = [&](string var, long long val) {
            if (solved[var]) return;
            solved[var] = true;
            value[var] = val;
            
            // 更新所有包含该变量的格子
            for (auto& pos : varPos[var]) {
                int r = pos.first, c = pos.second;
                if (!cellKnown[r][c]) {
                    cellKnown[r][c] = true;
                    rowKnownSum[r] += val;
                    colKnownSum[c] += val;
                    rowUnknownVars[r]--;
                    colUnknownVars[c]--;
                }
            }
        };
        
        // 不断求解直到所有变量都解出
        bool progress = true;
        while (progress) {
            progress = false;
            
            // 检查每一行
            for (int i = 0; i < L; ++i) {
                if (rowUnknownVars[i] == 0) continue;
                
                auto [varName, cnt] = getUniqueUnknownVar(i, true);
                if (varName.empty()) continue;
                
                // 该行只有一个未知变量
                if (cnt == rowUnknownVars[i]) {
                    long long totalUnknown = rowSum[i] - rowKnownSum[i];
                    if (cnt > 1) {
                        // 变量出现多次，需要确保能整除
                        if (totalUnknown % cnt == 0) {
                            solveVariable(varName, totalUnknown / cnt);
                            progress = true;
                        }
                    } else {
                        solveVariable(varName, totalUnknown);
                        progress = true;
                    }
                }
            }
            
            // 检查每一列
            for (int j = 0; j < C; ++j) {
                if (colUnknownVars[j] == 0) continue;
                
                auto [varName, cnt] = getUniqueUnknownVar(j, false);
                if (varName.empty()) continue;
                
                // 该列只有一个未知变量
                if (cnt == colUnknownVars[j]) {
                    long long totalUnknown = colSum[j] - colKnownSum[j];
                    if (cnt > 1) {
                        if (totalUnknown % cnt == 0) {
                            solveVariable(varName, totalUnknown / cnt);
                            progress = true;
                        }
                    } else {
                        solveVariable(varName, totalUnknown);
                        progress = true;
                    }
                }
            }
        }
        
        // 按字典序输出
        for (auto& p : varPos) {
            cout << p.first << " " << value[p.first] << "\n";
        }
    }
    return 0;
}
```

## 总结

本题的核心是利用题目保证的“每一步存在只有一个未知变量的行或列”这一性质，采用类似高斯消元但更简单的逐步代入法求解。实现时需要注意：

1. 变量可能多次出现，求解后要更新所有出现位置
2. 行或列中的未知变量即使出现多次，仍视为一个变量
3. 使用 $\texttt{map}$ 存储变量信息方便按字典序输出
4. 使用 $\texttt{long long}$ 避免整数溢出（求和范围可达 $10^8 \times 100 = 10^{10}$）
