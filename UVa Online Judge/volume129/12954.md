## 题目描述

给定一个 $N \times N$ 的网格，从左上角坐标 $(1,1)$ 开始，按顺时针螺旋方向（右→下→左→上）在每个格子中放置一颗豆子。重复这个螺旋过程，直到放置 $B$ 颗豆子。给定 $N$ 和 $B$ ，要求输出最后一颗豆子的坐标 $(R, C)$ 。

**输入**  
多个测试用例，每行包含两个整数 $N$ 和 $B$ ，其中 $2 \leq N \leq 2^{30}$ ， $1 \leq B \leq N^2$ 。

**输出**  
对于每个测试用例，输出一行，包含两个整数 $R$ 和 $C$ ，表示最后一颗豆子的坐标。

**样例输入**  
```
8 53
1073741824 1152921504603393520
```

**样例输出**  
```
4 6
536871276 536869983
```

## 题目分析

这道题的关键在于如何高效地定位第 $B$ 颗豆子在螺旋路径上的位置。 $N$ 最大可达 $2^{30}$ ，因此不能直接模拟螺旋过程（那样会超时）。我们需要一个数学或公式化的方法，在 $O(1)$ 或 $O(\log N)$ 时间内计算出坐标。

### 螺旋层结构

观察螺旋过程，可以将网格看作由多个同心正方形层（$\texttt{layer}$）组成：

- 最外层为第 $0$ 层，边长 $s_0 = N$ 。
- 向内一层为第 $1$ 层，边长 $s_1 = N - 2$ 。
- 第 $k$ 层的边长 $s_k = N - 2k$ 。
- 当 $N$ 为奇数时，最内层是一个 $1 \times 1$ 的格子（中心点）；当 $N$ 为偶数时，最内层是一个 $2 \times 2$ 的区块。

每一层的格子数为：

$$
cells(k) =
\begin{cases}
1 & \texttt{if } s_k = 1 \\
4s_k - 4 & \texttt{if } s_k > 1
\end{cases}
$$

因为当 $s_k > 1$ 时，该层有上下左右四条边，但四个角不重复计算，所以总格子数为 $4(s_k - 1)$ 。

### 定位目标层

设第 $k$ 层之前（即外层所有层）的总格子数为 $before(k)$ 。显然：

$$
before(k) = N^2 - s_k^2
$$

因为 $s_k = N - 2k$ ，所以：

$$
before(k) = N^2 - (N - 2k)^2
$$

我们需要找到满足以下条件的 $k$ ：

$$
before(k) < B \leq before(k) + cells(k)
$$

即第 $B$ 颗豆子位于第 $k$ 层。

由于 $k$ 的范围是 $0 \leq k \leq \lfloor (N-1)/2 \rfloor$ ，我们可以用二分查找快速定位 $k$ 。

### 计算层内坐标

找到目标层 $k$ 后，设该层起始坐标为：

$$
(R_{start}, C_{start}) = (k+1, k+1)
$$

该层边长 $s = N - 2k$ ，该层之前已有 $before(k)$ 颗豆子，因此第 $B$ 颗豆子在该层内的偏移量（从 $0$ 开始）为：

$$
offset = B - before(k) - 1
$$

接下来按照螺旋顺序确定坐标：

1. **上边**（从左到右）：若 $offset < s-1$ ，则  
   $R = R_{start}$ ， $C = C_{start} + offset$ 。

2. **右边**（从上到下）：若 $offset < 2s - 2$ ，则  
   $R = R_{start} + (offset - (s-1))$ ， $C = C_{start} + s - 1$ 。

3. **下边**（从右到左）：若 $offset < 3s - 3$ ，则  
   $R = R_{start} + s - 1$ ， $C = C_{start} + s - 1 - (offset - (2s-2))$ 。

4. **左边**（从下到上）：否则，  
   $R = R_{start} + s - 1 - (offset - (3s-3))$ ， $C = C_{start}$ 。

注意：当 $s = 1$ 时，该层只有一个格子，直接输出起始坐标即可。

---

## 算法步骤

1. 读入 $N$ 和 $B$ 。
2. 如果 $B = N^2$ ，可直接根据 $N$ 的奇偶性输出中心或对应坐标，但为了统一，我们仍然使用下面的通用方法。
3. 用二分查找找到目标层 $k$ ，使得 $before(k) < B \leq before(k) + cells(k)$ 。
4. 计算该层起始坐标 $(R_{start}, C_{start})$ 和边长 $s$ 。
5. 计算偏移量 $offset$ 。
6. 根据 $offset$ 落在哪条边，计算最终坐标 $(R, C)$ 。
7. 输出结果。

**时间复杂度**：每个测试用例 $O(\log N)$ 。  
**空间复杂度**： $O(1)$ 。

## 代码实现

```cpp
// Spiral
// UVa ID: 12954
// Verdict: Accepted
// Submission Date: 2026-01-17
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, b;
    while (cin >> n >> b) {
        // 找到层数 k
        long long L = 0, R = (n - 1) / 2, k = 0;
        while (L <= R) {
            long long mid = (L + R) / 2;
            long long s = n - 2 * mid;
            long long before = n * n - s * s; // mid 层之前的总数
            if (b > before) {
                k = mid;
                L = mid + 1;
            } else {
                R = mid - 1;
            }
        }
        
        long long s = n - 2 * k;
        long long before = n * n - s * s;
        long long off = b - before - 1;
        long long sr = k + 1, sc = k + 1;
        long long r = sr, c = sc;
        
        if (s == 1) {
            // 中心点
            cout << r << " " << c << endl;
            continue;
        }
        
        if (off < s - 1) c += off;
        else if (off < 2 * s - 2) { r += off - (s - 1); c += s - 1; }
        else if (off < 3 * s - 3) { r += s - 1; c += s - 1 - (off - (2 * s - 2)); }
        else { r += s - 1 - (off - (3 * s - 3)); c = sc; }
        
        cout << r << " " << c << endl;
    }
    return 0;
}
```

## 总结

本题通过将螺旋路径分解为同心正方形层，利用数学公式快速计算每层之前的豆子总数，再通过二分查找定位目标层，最后根据层内偏移计算坐标。这种方法避免了模拟螺旋过程，将时间复杂度从 $O(N^2)$ 降为 $O(\log N)$ ，能够高效处理 $N$ 高达 $2^{30}$ 的大数据范围。
