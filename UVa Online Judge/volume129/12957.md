## 题目描述

在平面直角坐标系中给定 $N$ 个点（历史路灯柱），要求统计所有**轴对齐矩形**的数量，这些矩形需满足：

1. 矩形的**两个对角顶点**必须是给定的两个点
2. 矩形的另外两个顶点**不是**给定的点
3. 其余 $N-2$ 个点**不能严格位于矩形内部**（边界上的点允许）

矩形边界必须与坐标轴平行。

### 输入格式

多组测试数据。每组第一行一个整数 $N$（$1 \leq N \leq 3000$），接下来 $N$ 行每行两个整数 $X, Y$（$-10^8 \leq X, Y \leq 10^8$）。

### 输出格式

每组数据输出一行，表示满足条件的矩形数量。

## 问题分析

### 初步思考

最朴素的想法是枚举所有点对 $(i, j)$ 作为矩形的对角顶点，然后检查矩形内部是否包含其他点。直接实现的时间复杂度为 $O(N^3)$，对于 $N=3000$ 显然不可接受。

### 关键观察

由于矩形必须轴对齐，当固定两个对角顶点 $(x_1, y_1)$ 和 $(x_2, y_2)$（假设 $x_1 < x_2$）时，矩形的另外两个角坐标已确定：$(x_1, y_2)$ 和 $(x_2, y_1)$。题目并不关心这两个角是否为给定点，只关心**内部**是否有其他给定点。

因此，我们需要判断：是否存在另一个点 $(x_k, y_k)$ 满足 $x_1 < x_k < x_2$ 且 $\min(y_1, y_2) < y_k < \max(y_1, y_2)$。

### 优化方向

先对所有点按 $x$ 坐标排序。固定左边界点 $i$ 后，我们只需要考虑 $x$ 坐标大于 $x_i$ 的点作为右边界。此时，问题转化为：对于固定的 $i$，随着 $j$ 向右扫描，如何快速判断在开区间 $(x_i, x_j)$ 内的点中，是否存在 $y$ 落在 $(\min(y_i, y_j), \max(y_i, y_j))$ 范围内。

## 解题思路

### 极值维护法

对于固定的 $i$，我们扫描所有 $j > i$。在扫描过程中维护两个变量：

- $maxVal$：在已扫描的点中（即 $x$ 坐标介于 $x_i$ 和 $x_j$ 之间），所有**大于** $y_i$ 的 $y$ 坐标的**最小值**
- $minVal$：在已扫描的点中，所有**小于** $y_i$ 的 $y$ 坐标的**最大值**

初始值：$maxVal = +\infty$，$minVal = -\infty$。

### 判断逻辑

当扫描到点 $j$ 时，分两种情况讨论：

#### 情况一：$y_j > y_i$

此时矩形的 $y$ 区间为 $(y_i, y_j)$。要使矩形内部无点，需要所有位于 $(x_i, x_j)$ 内且 $y > y_i$ 的点的 $y$ 坐标都**大于** $y_j$。等价条件为：

$$ y_j < maxVal $$

因为 $maxVal$ 是这些点中最小的 $y$ 值，如果 $y_j$ 比这个最小值还小，说明区间 $(y_i, y_j)$ 内没有任何点的 $y$ 坐标。

#### 情况二：$y_j < y_i$

此时矩形的 $y$ 区间为 $(y_j, y_i)$。要使矩形内部无点，需要所有位于 $(x_i, x_j)$ 内且 $y < y_i$ 的点的 $y$ 坐标都**小于** $y_j$。等价条件为：

$$ y_j > minVal $$

因为 $minVal$ 是这些点中最大的 $y$ 值，如果 $y_j$ 比这个最大值还大，说明区间 $(y_j, y_i)$ 内没有任何点的 $y$ 坐标。

### 极值更新

完成判断后，需要用当前点 $j$ 的 $y_j$ 更新极值：

- 若 $y_j > y_i$，更新 $maxVal = \min(maxVal, y_j)$
- 若 $y_j < y_i$，更新 $minVal = \max(minVal, y_j)$
- 若 $y_j = y_i$，跳过（无法构成矩形且不影响极值）

### 正确性证明

**充分性**：若 $y_j > y_i$ 且 $y_j < maxVal$，由于 $maxVal$ 是区间内所有大于 $y_i$ 的 $y$ 的最小值，所以区间内不存在任何点的 $y$ 在 $(y_i, y_j)$ 之间，矩形内部无点。

**必要性**：若矩形内部无点，则区间内所有大于 $y_i$ 的点的 $y$ 必然都大于等于 $y_j$（不能等于，因为等于 $y_j$ 的点会落在矩形上边界，边界允许）。因此 $y_j \leq \min\{y_k \mid y_k > y_i\} = maxVal$。又因为 $y_j \neq maxVal$（否则存在点恰好在右边界），故 $y_j < maxVal$。

情况二同理可证。

### 复杂度分析

- 排序：$O(N \log N)$
- 外层循环 $i$：$O(N)$
- 内层循环 $j$：$O(N)$，每次循环 $O(1)$ 操作
- 总时间复杂度：$O(N^2)$
- 空间复杂度：$O(N)$

当 $N=3000$ 时，运算量约为 $9 \times 10^6$，远优于 $O(N^3)$ 或 $O(N^2 \log N)$ 的做法。

## 实现细节

1. 使用 `ios::sync_with_stdio(false)` 和 `cin.tie(nullptr)` 加速输入输出
2. 坐标范围 $-10^8 \leq X, Y \leq 10^8$，极值初始化为 $10^9+5$ 和 $-10^9-5$ 即可
3. 注意排除 $y_i = y_j$ 的情况（水平线无法构成矩形）
4. 使用 `long long` 存储答案（最多约 $\binom{3000}{2} \approx 4.5 \times 10^6$，32位整数足够，但为安全起见使用64位）

## 参考代码

```cpp
// Rectangle Park
// UVa ID: 12957

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
};

bool cmpX(const Point& a, const Point& b) {
    if (a.x != b.x) return a.x < b.x;
    return a.y < b.y;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int N;
    while (cin >> N) {
        vector<Point> pts(N);
        for (int i = 0; i < N; ++i) 
            cin >> pts[i].x >> pts[i].y;
        
        sort(pts.begin(), pts.end(), cmpX);
        
        long long ans = 0;
        const int INF = 1e9 + 5;
        
        for (int i = 0; i < N; ++i) {
            int maxVal = INF;   // 记录已扫描的、y > y_i 的点中，最小的 y 值
            int minVal = -INF;  // 记录已扫描的、y < y_i 的点中，最大的 y 值
            
            for (int j = i + 1; j < N; ++j) {
                int yI = pts[i].y, yJ = pts[j].y;
                
                if (yI != yJ) {
                    // 判断矩形内部是否无点：yJ 在 (yI, yJ) 区间内没有其他点
                    if ((yJ > yI && yJ < maxVal) || (yJ < yI && yJ > minVal))
                        ++ans;
                }
                
                // 用当前点更新极值
                if (yJ > yI) maxVal = min(maxVal, yJ);
                else if (yJ < yI) minVal = max(minVal, yJ);
                // yJ == yI 时不更新
            }
        }
        
        cout << ans << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于将二维几何问题转化为一维区间极值维护问题。通过排序固定 $x$ 方向，利用 $maxVal$ 和 $minVal$ 两个变量实时维护 $y$ 方向的信息，实现了 $O(N^2)$ 的高效算法。

这种“固定一维、扫描另一维并维护极值”的思路在平面统计问题中具有普遍意义，值得深入理解和掌握。
