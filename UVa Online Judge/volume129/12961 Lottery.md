
> **摘要**：本题要求判断是否存在一组目标向量 $W$，使得没有任何非空参与者子集能与之奇偶性完全匹配。核心思路是把每个投注数字压缩为奇偶位，将问题转化为 $\mathbb{F}_2^K$ 上的向量空间问题，用线性基在 $O(N \cdot K)$ 时间内求出 $N$ 个向量的秩，再结合秩与 $N, K$ 的关系给出 `'S'` / `'N'` 的判定。

## 题目描述

彩票 $\texttt{BWS}$ 每年举行一次。有 $N$ 个人参与，每人投注 $K$ 个正整数。形式化地，记 $B_{ij}$ 为第 $i$ 个人投注的第 $j$ 个数字。 组织者随后选出 $K$ 个正整数 $W_1, W_2, \ldots, W_K$。  

获奖判定方式如下：  
从 $N$ 名参与者中随机**非空**地选出一个子集。对于该子集中的每一个人，计算  
$S_1$ = 所选人第一个投注数字之和（即 $\sum B_{i1}$），同理得到 $S_2, \ldots, S_K$。  
接着逐一比较 $W_j$ 与 $S_j$ 的**奇偶性**是否相同。若全部相同，则这个子集中的所有人即为获胜者。

组织者想知道：是否存在一种选择 $W_1, \ldots, W_K$ 的方法，使得**不存在任何非空参与者子集能够获胜**。

## 输入格式

输入包含多个测试用例。每个测试用例的第一行包含两个整数 $N$（$1 \le N \le 30000$）和 $K$（$3 \le K \le 50$），分别表示参与者人数和每人投注的数字个数。  
接下来 $N$ 行，每行包含 $K$ 个整数，表示该参与者的投注号码，数值范围为 $[1, 10^9]$。  
输入以文件结束符终止。

## 输出格式

对于每个测试用例，输出一行一个字符：若存在满足条件的 $W$ 则输出 `'S'`，否则输出 `'N'`。

## 样例

输入
```
2 3
1 2 3
5 6 7
3 3
3 2 1
6 5 4
4 4 4
4 4 3
9 4 7
4 4 4
2 7 2
2 2 1
```
输出
```
S
S
N
```

## 题目分析

本题只关心每个投注数字的**奇偶性**，因为比较 $W_j$ 与 $S_j$ 的奇偶性时，$S_j$ 的奇偶性完全由所选参与者第 $j$ 个数字的奇偶性之和决定，即模 $2$ 的和。因此，每个参与者的投注可以压缩为一个长度为 $K$ 的 $0/1$ 向量（奇数为 $1$，偶数为 $0$）。

对于任意一个非空参与者子集，其对应的 $S_j$ 的奇偶性等于该子集中所有向量的按位异或（$\mathrm{XOR}$）结果。因此，所有可能产生的 $S$ 向量（即所有非空子集的异或和）构成一个向量空间 $V \subseteq \mathbb{F}_2^K$。而组织者可以选择任意 $K$ 位目标向量 $W$（仅考虑奇偶性）。

问题转化为：是否存在一个 $K$ 位向量 $W \in \mathbb{F}_2^K$，使得 $W$ 不属于由 $N$ 个行向量生成的非空子集异或集合？注意，空集的异或和为 $\mathbf{0}$，但题目要求子集**非空**，因此需要特别处理零向量。

如果行向量张成的整个空间 $\mathbb{F}_2^K$ 的维数小于 $K$，则存在向量不在该空间中，那么这些向量无法由任何子集（包括空集）得到，所以一定存在满足条件的 $W$，答案为 `'S'`。

如果行向量张成整个 $K$ 维空间（即秩为 $K$），则空间中所有向量都可以由**某个子集**表示，但空集表示零向量，非空子集是否也能表示零向量呢？这取决于行向量组是否线性相关。若 $N > K$，则必然线性相关，存在非空子集异或和为 $\mathbf{0}$，于是零向量可由非空子集得到，空间中所有向量（包括零向量）都能由非空子集得到，因此不存在 $W$ 能避开所有非空子集，答案为 `'N'`。若 $N = K$ 且秩为 $K$，则行向量组线性无关，零向量只能由空集得到，因此取 $W = \mathbf{0}$ 即可避免所有非空子集，答案为 `'S'`。若 $N < K$ 则秩不可能为 $K$，已归入第一种情况。

综上，只需计算给定 $N$ 个 $K$ 位向量的秩 $\mathrm{rank}$，然后根据如下规则判定：
- 若 $\mathrm{rank} < K$，输出 `'S'`；
- 若 $\mathrm{rank} = K$，则当 $N = K$ 时输出 `'S'`，否则输出 `'N'`。

## 解题思路

### 奇偶性压缩

每个投注数字 $B_{ij}$ 只影响其奇偶性，所以读入时直接取模 $2$。将每个参与者的 $K$ 个奇偶位打包成一个 $K$ 位的二进制数（使用 `unsigned long long`，因为 $K \le 50$ 远小于 $64$ 位）。按输入顺序将第 $j$ 个数字的奇偶值放在该二进制数的第 $j$ 位（从 $0$ 开始计数，或任意固定顺序，只要一致即可）。

### 线性基求秩

在 $\mathbb{F}_2$ 上，一组向量的秩可以通过高斯消元（或线性基）求得。我们维护一个数组 `basis[0..K-1]`，其中 `basis[j]` 表示最高位（最高有效位）为 $j$ 的一个基向量。对于每个新插入的向量 $x$，从高位 $K-1$ 向低位 $0$ 扫描，若 $x$ 的第 $j$ 位为 $1$：
- 若 `basis[j]` 为空，则将 $x$ 存入，秩加 $1$，并终止插入；
- 否则，令 $x \gets x \oplus \textit{basis}[j]$，继续消去低位。

最终 `rankVal` 即为这些向量的秩。

### 判定输出

根据前面分析，若 `rankVal < K` 则输出 `'S'`；若 `rankVal == K` 则比较 $N$ 与 $K$，若相等则输出 `'S'`，否则输出 `'N'`。注意，`rankVal` 不可能超过 $K$，且当 `rankVal == K` 时必有 $N \ge K$，所以只需判断相等情况。

### 复杂度

每个测试用例中，读入 $N \times K$ 个整数，每个数只需进行按位与操作，插入线性基的循环复杂度为 $O(K)$。故总时间复杂度为 $O(N \cdot K)$，空间复杂度为 $O(K)$。$N \le 30000$，$K \le 50$，完全可行。

## 代码实现

```cpp

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, K;
    while (cin >> N >> K) {
        unsigned long long basis[50] = {0}; // K <= 50
        int rankVal = 0;
        for (int i = 0; i < N; ++i) {
            unsigned long long mask = 0;
            for (int j = 0; j < K; ++j) {
                long long val;
                cin >> val;
                if (val & 1) mask |= (1ULL << j); // 按输入顺序放置位
            }
            // 将 mask 插入线性基（高斯消元求秩）
            unsigned long long x = mask;
            for (int j = K - 1; j >= 0; --j) {
                if ((x >> j) & 1ULL) {
                    if (basis[j] == 0) {
                        basis[j] = x;
                        ++rankVal;
                        break;
                    } else x ^= basis[j];
                }
            }
        }
        if (rankVal < K) cout << 'S' << '\n';
        else { // rankVal == K
            if (N == K) cout << 'S' << '\n';
            else cout << 'N' << '\n';
        }
    }
    return 0;
}
```

## 总结

本题的核心在于将奇偶性比较转化为 $\mathbb{F}_2$ 上的向量空间问题，并利用线性基快速求秩。关键技巧有：
- 忽略数字的具体值，仅保留奇偶性，大幅压缩信息。
- 将“是否存在某向量不能被任何非空子集表示”转化为空间维数与向量个数的关系。
- 利用线性基在 $O(N \cdot K)$ 时间内求秩，高效解决 $N$ 较大时的计算。

本题也体现了组合数学与线性代数的结合，是处理异或相关问题的典型方法。在实际编码中，注意使用 `unsigned long long` 保证位操作安全，并正确处理输入结束条件。
