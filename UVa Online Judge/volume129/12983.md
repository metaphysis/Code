[UVa 12983 The Battle of Chibi](https://blog.csdn.net/metaphysis/article/details/153398021)

## 问题重述

给定一个长度为 $N$ 的数组 $a$，求**严格递增子序列**的数量，且子序列长度恰好为 $M$。

- 子序列必须保持原顺序。
- 严格递增：$a[i] < a[j]$ 对于子序列中相邻元素成立。
- 输出结果对 $10^9+7$ 取模。

---

## 思路分析

### $1$. 定义状态

设  
$$
dp[i][l] = \text{以 } a[i] \text{ 结尾的长度为 } l \text{ 的严格递增子序列的数量}
$$

那么最终答案是：
$$
ans = \sum_{i=1}^{N} dp[i][M]
$$

---

### $2$. 状态转移

对于每个 $i$，长度为 $l$ 的子序列可以由所有 $j < i$ 且 $a[j] < a[i]$ 的 $dp[j][l-1]$ 转移而来：
$$
dp[i][l] = \sum_{j < i, \ a[j] < a[i]} dp[j][l-1]
$$

初始条件：
$$
dp[i][1] = 1 \quad \text{（每个元素本身构成一个长度为 } 1 \text{ 的递增序列）}
$$

---

### $3$. 直接实现的复杂度

直接三重循环（枚举 $i$，枚举 $l$，枚举 $j$）是 $O(N^2 M)$，在 $N \leq 1000, M \leq N$ 时可能达到 $10^9$ 级别，会超时。

---

### $4$. 优化

我们需要快速计算：
$$
\sum_{j < i, \ a[j] < a[i]} dp[j][l-1]
$$

这是一个**前缀和**问题，但 $a[i]$ 的值很大（最大 $10^9$），所以需要离散化。

我们可以对每个长度 $l$，维护一个**树状数组 ($\texttt{Fenwick Tree}$)** 或**线段树**，键是离散化后的 $a[i]$ 值，值是 $dp[i][l]$。

这样：
- 计算 $dp[i][l]$ 时，查询树状数组中 $[1, pos(a[i])-1]$ 的区间和（即所有值小于 $a[i]$ 的 $dp[j][l-1]$ 之和）。
- 然后更新树状数组在 $pos(a[i])$ 位置加上 $dp[i][l]$。

这样复杂度降为：
$$
O(T \cdot M \cdot N \log N)
$$
在 $T \leq 100, M \leq N \leq 1000$ 时可行。

---

### 5. 离散化

因为 $a_i$ 很大，但 $N \leq 1000$，我们可以对每个测试用例的 $a$ 数组单独离散化。

---

## 算法步骤

1. 读入 $T$。
2. 对每个测试用例：
   - 读入 $N, M$ 和数组 $a$。
   - 离散化 $a$。
   - 初始化 $dp[N+1][M+1]$ 为 $0$，且 $dp[i][1] = 1$。
   - 对 $l = 2$ 到 $M$：
     - 初始化树状数组（大小为 $N$）。
     - 对 $i = 1$ 到 $N$：
       - 查询树状数组中 $[1, pos(a[i])-1]$ 的和，作为 $dp[i][l]$。
       - 更新树状数组在 $pos(a[i])$ 位置加上 $dp[i][l-1]$（注意这里加的是上一层的 $\texttt{dp}$ 值）。
   - 答案 $\text{ans} = \sum_{i=1}^N dp[i][M]$，取模输出。

## 参考代码

```cpp
// The Battle of Chibi
// UVa ID: 12983
// Verdict: Accepted
// Submission Date: 2025-10-16
// UVa Run Time: 0.520s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>
using namespace std;

const int MOD = 1000000007;
const int MAXN = 1005;

int T, N, M;
int a[MAXN];
int dp[MAXN][MAXN];

// Fenwick Tree
class Fenwick {
    int n;
    vector<int> bit;
public:
    Fenwick(int n) : n(n), bit(n+1, 0) {}
    void update(int idx, int delta) {
        for (; idx <= n; idx += idx & -idx) {
            bit[idx] = (bit[idx] + delta) % MOD;
        }
    }
    int query(int idx) {
        int sum = 0;
        for (; idx > 0; idx -= idx & -idx) {
            sum = (sum + bit[idx]) % MOD;
        }
        return sum;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> T;
    for (int t = 1; t <= T; t++) {
        cin >> N >> M;
        vector<int> vals;
        for (int i = 1; i <= N; i++) {
            cin >> a[i];
            vals.push_back(a[i]);
        }

        // 离散化
        sort(vals.begin(), vals.end());
        vals.erase(unique(vals.begin(), vals.end()), vals.end());
        int sz = vals.size();
        for (int i = 1; i <= N; i++) {
            a[i] = lower_bound(vals.begin(), vals.end(), a[i]) - vals.begin() + 1;
        }

        // 初始化 dp
        memset(dp, 0, sizeof(dp));
        for (int i = 1; i <= N; i++) {
            dp[i][1] = 1;
        }

        // DP
        for (int l = 2; l <= M; l++) {
            Fenwick ft(sz);
            for (int i = 1; i <= N; i++) {
                dp[i][l] = ft.query(a[i] - 1); // 所有小于 a[i] 的 dp[j][l-1] 之和
                ft.update(a[i], dp[i][l-1]);   // 加入 dp[i][l-1] 到树状数组
            }
        }

        // 计算结果
        int ans = 0;
        for (int i = 1; i <= N; i++) {
            ans = (ans + dp[i][M]) % MOD;
        }
        cout << "Case #" << t << ": " << ans << "\n";
    }
    return 0;
}
```
