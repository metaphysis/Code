## 题目描述

$\texttt{Yi Sima}$（司马懿）是曹操的最佳谋士之一。他喜欢玩一个有趣的游戏，类似于现代的数独，但规模更小。

实际上，司马懿的玩法有所不同。他先生成一个 $4 \times 4$ 的棋盘，要求：
- 每一行都包含数字 $1$ 到 $4$
- 每一列都包含数字 $1$ 到 $4$  
- 如果将棋盘切成四个 $2 \times 2$ 的小块，每个小块也包含数字 $1$ 到 $4$

然后，他从棋盘上移除若干数字（用 `'*'` 表示），并将其交给另一个人来恢复。由于其他谋士不如司马懿聪明，司马懿总是确保棋盘只有一种恢复方式。

你需要恢复棋盘，让司马懿高兴并获得晋升。

## 输入格式

第一行输入测试用例的数量 $T$ $(1 \leq T \leq 100)$。随后是 $T$ 个测试用例。每个测试用例以一个空行开始，然后是 $4$ 行，每行包含 $4$ 个字符。每个字符代表对应单元格中的数字（`'1'`、`'2'`、`'3'`、`'4'` 之一）。`'*'` 表示该数字被司马懿移除了。

保证棋盘只有一种恢复方式。

## 输出格式

对于每个测试用例，输出一行 `"Case #x:"`，其中 $x$ 是测试用例编号（从 $1$ 开始）。然后输出 $4$ 行，每行 $4$ 个字符，表示恢复后的棋盘。

## 题目分析

这是一个 $4 \times 4$ 的数独变种问题，需要同时满足三个约束条件：

1. **行约束**：每行必须包含数字 $1$-$4$ 且不重复
2. **列约束**：每列必须包含数字 $1$-$4$ 且不重复
3. **子块约束**：四个 $2 \times 2$ 子块必须包含数字 $1$-$4$ 且不重复

由于题目保证只有唯一解，我们可以使用回溯法（$\texttt{DFS}$）来系统地尝试所有可能的数字填充。

## 解题思路

### 核心算法：回溯搜索

回溯法是解决此类约束满足问题的经典方法。基本思想是：

1. **找到空单元格**：首先记录所有需要填充的 `'*'` 位置
2. **尝试填充数字**：对于每个空单元格，依次尝试数字 $1$-$4$
3. **验证有效性**：检查当前数字是否满足所有约束条件
4. **递归搜索**：如果当前数字有效，递归处理下一个空单元格
5. **回溯撤销**：如果当前选择导致无解，回溯到上一步尝试其他数字

### 有效性检查

对于位置 $(row, col)$ 填入数字 $num$，需要检查三个方面的有效性：

1. **行检查**：检查第 $row$ 行是否已经存在相同的数字
2. **列检查**：检查第 $col$ 列是否已经存在相同的数字  
3. **$2 \times 2$ 子块检查**：检查对应的 $2 \times 2$ 子块是否已经存在相同的数字

子块的起始位置计算方式为：
- 起始行：$startRow = \lfloor row / 2 \rfloor \times 2$
- 起始列：$startCol = \lfloor col / 2 \rfloor \times 2$

### 算法优化

由于题目规模较小（只有 $4 \times 4 = 16$ 个单元格），且保证有唯一解，回溯法能够高效地找到解。最坏情况下，每个空单元格尝试 $4$ 种可能，但实际搜索过程中会因约束条件而大幅剪枝。

## 复杂度分析

- **时间复杂度**：最坏情况下为 $O(4^n)$，其中 $n$ 是空单元格的数量。但由于约束条件严格，实际运行时间远小于此。
- **空间复杂度**：$O(1)$，除了存储棋盘外，只使用了常数级别的额外空间。

```cpp
// Sudoku

#include <bits/stdc++.h>
using namespace std;

vector<string> board(4);
vector<pair<int, int>> emptyCells;

bool isValid(int row, int col, char num) {
    // 检查行
    for (int i = 0; i < 4; i++) {
        if (board[row][i] == num && i != col) return false;
        if (board[i][col] == num && i != row) return false;
    }
    
    // 检查2x2子块
    int startRow = (row / 2) * 2;
    int startCol = (col / 2) * 2;
    for (int i = startRow; i < startRow + 2; i++)
        for (int j = startCol; j < startCol + 2; j++)
            if (board[i][j] == num && !(i == row && j == col)) return false;
    
    return true;
}

bool solve(int index) {
    // 所有空单元格都已填充，找到解
    if (index == emptyCells.size()) return true;
    
    int row = emptyCells[index].first;
    int col = emptyCells[index].second;
    
    // 尝试所有可能的数字
    for (char num = '1'; num <= '4'; num++) {
        if (isValid(row, col, num)) {
            board[row][col] = num;
            if (solve(index + 1)) return true;
            board[row][col] = '*';  // 回溯
        }
    }
    return false;
}

int main() {
    int T;
    cin >> T;
    
    for (int caseNum = 1; caseNum <= T; caseNum++) {
        emptyCells.clear();
        
        // 读取输入并记录空单元格位置
        for (int i = 0; i < 4; i++) {
            cin >> board[i];
            for (int j = 0; j < 4; j++)
                if (board[i][j] == '*') emptyCells.push_back({i, j});
        }
        
        // 解决数独
        solve(0);
        
        // 输出结果
        cout << "Case #" << caseNum << ":" << endl;
        for (int i = 0; i < 4; i++) cout << board[i] << endl;
    }
    
    return 0;
}
```

## 总结

本题通过回溯法系统地搜索所有可能的解空间，利用约束条件进行剪枝，最终找到满足所有条件的唯一解。这种方法对于小规模的约束满足问题非常有效，代码实现简洁且易于理解。
