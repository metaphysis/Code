## 题目描述

在公元 $2115$ 年，星际商业规划中心（$\texttt{ICPC}$）由自治通信部（$\texttt{ACM}$）支持。商业操作通过在整个银河系中相互连接的 $\texttt{ACM}$ 办公室之间执行交易来完成。

在两个相连的 $\texttt{ACM}$ 办公室之间执行一笔交易会涉及一笔**非负税收**，其值随时间 $t$ 呈线性函数 $A \times t + B$ 连续变化，其中 $t$ 是当天以分钟为单位的实数（$0 \leq t \leq 24 \times 60$）。

在某个时间 $t$，从源 $\texttt{ACM}$ 办公室（编号为 $1$）到目标 $\texttt{ACM}$ 办公室（编号为 $N$）执行的商业操作的**总税收**，定义为沿从源到目标的某条路径所执行的交易税收之和的**最小值**。每条交易的税收都在同一时间 $t$ 计算。

由于税收随时间变化，$\texttt{ACM}$ 希望选择最佳时间执行操作以最大化税收。你的任务是计算 $\texttt{ACM}$ 在一天中可以收取的最大总税收。

### 输入格式

输入包含多个测试用例，每个测试用例格式如下：

- 第一行：两个整数 $N$ 和 $M$（$2 \leq N \leq 1000$，$1 \leq M \leq 10^4$），表示办公室数量和连接数。
- 接下来 $M$ 行：每行四个整数 $I, J, A, B$，表示办公室 $I$ 和 $J$ 之间有一条双向连接，税收公式为 $A \times t + B$（$-100 \leq A \leq 100$，$0 \leq B \leq 10^6$）。
- 保证对于 $0 \leq t \leq 1440$，税收非负（$A \times t + B \geq 0$）。
- 每对办公室之间最多有一条连接，且源和目标之间至少有一条路径。

### 输出格式

对每个测试用例，输出一个保留五位小数的实数，表示最大总税收。

## 题目分析

### 问题本质

这个问题可以形式化为：

- 给定一个无向图 $G = (V, E)$，其中 $|V| = N$，$|E| = M$。
- 每条边 $e \in E$ 有一个权值函数 $w_e(t) = A_e \times t + B_e$，表示在时间 $t$ 通过该边的税收。
- 定义路径 $P$ 在时间 $t$ 的总税收为 $\sum_{e \in P} w_e(t)$。
- 定义 $f(t)$ 为从节点 $1$ 到节点 $N$ 的所有路径中，在时间 $t$ 的最小总税收（即最短路长度）。
- 目标：找到 $t^* \in [0, 1440]$ 使得 $f(t^*)$ 最大，并输出 $f(t^*)$。

### 关键观察

1. **$f(t)$ 的函数性质**：
   - 对于每条固定路径，其总税收是 $t$ 的线性函数（各边线性函数的和）。
   - $f(t)$ 是这些线性函数的最小值，因此是分段线性函数。
   - 更重要的是，$f(t)$ 是一个**凹函数（上凸函数）**。这是因为：
     - 每条路径的税收是线性函数（凸函数）。
     - 多个凸函数的最小值仍然是凸函数。
     - 但注意：这里我们需要最大化 $f(t)$，而 $f(t)$ 是凸函数意味着它有唯一的极大值点（或一段连续的极大值区间）。

2. **凸函数的优化**：
   - 凸函数（或凹函数）在闭区间上的最大值可以通过三分法高效找到。
   - 三分法的时间复杂度为 $O(\log(\frac{L}{\epsilon}))$，其中 $L$ 是区间长度，$\epsilon$ 是精度要求。

3. **计算 $f(t)$**：
   - 对于固定的 $t$，所有边权 $w_e(t)$ 都是常数。
   - 计算从节点 $1$ 到节点 $N$ 的最短路径就是标准的单源最短路问题。
   - 由于边权非负，可以使用 $\texttt{Dijkstra}$ 算法，时间复杂度 $O((N+M)\log N)$。

### 解题思路

基于以上分析，解题步骤如下：

1. **读取图结构**：存储为邻接表，每条边记录终点、斜率 $A$、截距 $B$。

2. **实现 $f(t)$ 的计算**：
   - 对于给定的 $t$，计算每条边的权值 $w = A \times t + B$。
   - 使用 $\texttt{Dijkstra}$ 算法求从节点 $1$ 到节点 $N$ 的最短路径长度。

3. **三分法搜索最优时间**：
   - 在区间 $[0, 1440]$ 上执行三分搜索。
   - 每次计算两个分界点 $m_1 = l + \frac{r-l}{3}$ 和 $m_2 = r - \frac{r-l}{3}$。
   - 比较 $f(m_1)$ 和 $f(m_2)$：
     - 若 $f(m_1) \leq f(m_2)$，则最大值在 $[m_1, r]$ 区间。
     - 否则，最大值在 $[l, m_2]$ 区间。
   - 当区间长度小于预设精度 $\epsilon$ 时停止。

4. **输出结果**：计算最终时间点的 $f(t)$ 值，保留五位小数。

### 算法复杂度

- 每次 $\texttt{Dijkstra}$：$O((N+M)\log N)$。
- 三分法迭代次数：约 $\log_{1.5}(\frac{1440}{\epsilon})$，取 $\epsilon = 10^{-12}$ 时约 $100$ 次。
- 总复杂度：$O(T \times 100 \times (M\log N))$，在题目限制下可行。

### 注意事项

1. **精度设置**：
   - 最终输出要求五位小数，但三分法需要更高精度以保证正确性。
   - 代码中使用 $\epsilon = 10^{-12}$ 可以满足要求。

2. **浮点数比较**：
   - 直接比较 $f(m_1) \leq f(m_2)$ 而不加 $\epsilon$ 容差，因为 $\texttt{Dijkstra}$ 本身是精确算法。

3. **边权非负保证**：
   - 题目保证对于所有 $t \in [0, 1440]$，$A \times t + B \geq 0$，因此无需额外检查。

### 为什么三分法有效？

三分法适用于单峰函数（$\texttt{unimodal function}$）。对于凸函数 $f(t)$：
- 在最大值点左侧，函数递增。
- 在最大值点右侧，函数递减。
- 通过比较两个分界点的函数值，可以确定最大值所在的子区间。

这种性质使得我们可以在对数时间内缩小搜索区间。

```cpp
// Galactic Taxes

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;           // 最大节点数
const int MAXM = 10005;          // 最大边数
const double EPS = 1e-12;        // 精度
const double MINUTES = 1440;     // 一天的总分钟数

struct Edge {
    int to, a, b;                // 终点、斜率A、截距B
};

int n, m;                        // 节点数、边数
vector<Edge> graph[MAXN];       // 邻接表
double dist[MAXN];              // 最短路距离数组

// 检查给定时间t下，从源点到汇点的最短路径长度
double dijkstra(double t) {
    priority_queue<pair<double, int>, vector<pair<double, int>>, greater<pair<double, int>>> pq;
    fill(dist, dist + n + 1, 1e18);
    dist[1] = 0;
    pq.push({0, 1});
    while (!pq.empty()) {
        double d = pq.top().first;
        int u = pq.top().second;
        pq.pop();
        if (d > dist[u]) continue;
        for (const Edge& e : graph[u]) {
            double w = e.a * t + e.b;    // 边权在时间t下的值
            if (dist[u] + w < dist[e.to]) {
                dist[e.to] = dist[u] + w;
                pq.push({dist[e.to], e.to});
            }
        }
    }
    return dist[n];
}

int main() {
    while (scanf("%d %d", &n, &m) == 2) {
        for (int i = 1; i <= n; i++) graph[i].clear();
        for (int i = 0; i < m; i++) {
            int u, v, a, b;
            scanf("%d %d %d %d", &u, &v, &a, &b);
            graph[u].push_back({v, a, b});
            graph[v].push_back({u, a, b});
        }
        // 三分法寻找最优时间点
        double left = 0, right = MINUTES;
        while (right - left > EPS) {
            double m1 = left + (right - left) / 3;
            double m2 = right - (right - left) / 3;
            if (dijkstra(m1) <= dijkstra(m2)) left = m1;
            else right = m2;
        }
        double answer = dijkstra((left + right) / 2);
        printf("%.5f\n", answer);
    }
    return 0;
}
```

## 总结

本题是一个典型的**凸函数最优化**与**最短路算法**结合的问题。关键点在于：

1. 认识到 $f(t)$（最短路长度关于时间的函数）是凸函数。
2. 利用三分法在连续区间上寻找凸函数的最大值。
3. 对于每个固定的 $t$，使用 $\texttt{Dijkstra}$ 算法高效计算 $f(t)$。

这种将动态权值问题转化为静态权值序列计算，再结合函数优化技巧的方法，在图论问题中十分常见。
