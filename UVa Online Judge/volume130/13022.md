## 问题描述

根据《生活大爆炸》中 $\texttt{Sheldon Cooper}$ 的理论，他最喜欢的数字是 $73$ 。他认为 $73$ 的二进制表示 $1001001$ 具有非常特殊的模式： $1$ 个 $1$ ，接着 $2$ 个 $0$ ，再接着 $1$ 个 $1$ ，再接着 $2$ 个 $0$ ，再接着 $1$ 个 $1$ 。这种模式可以推广为： $N$ 个 $1$ 后面跟着 $M$ 个 $0$ ，再后面又是 $N$ 个 $1$ ，再后面又是 $M$ 个 $0$ ，依此类推，最后以 $N$ 个 $1$ 或 $M$ 个 $0$ 结束。我们将具有这种二进制表示模式的数称为 **$\texttt{Sheldon}$ 数** 。

更形式化地，一个正整数被称为 $\texttt{Sheldon}$ 数，当且仅当它的二进制表示匹配以下两种模式之一：

1. 模式 $1$ ： $(1^N 0^M)^k$ ，其中 $k \ge 1$ ，即 $N$ 个 $1$ 和 $M$ 个 $0$ 交替出现 $k$ 次。
2. 模式 $2$ ： $(1^N 0^M)^k 1^N$ ，其中 $k \ge 0$ ，即 $N$ 个 $1$ 和 $M$ 个 $0$ 交替出现 $k$ 次后，再以 $N$ 个 $1$ 结尾。

其中 $N > 0$ ， $M \ge 0$ ，且二进制表示的总长度不超过 $64$ 位（因为题目给定的 $Y \le 2^{63}$ ）。

题目要求给定多组查询，每组查询给出两个整数 $X$ 和 $Y$ ，需要输出在区间 $[X, Y]$ 内 $\texttt{Sheldon}$ 数的个数。

## 解题思路

### 关键观察

1. **有限性** ：由于 $Y \le 2^{63}$ ，即二进制表示最多 $64$ 位（最高位为 $1$ ），因此可能的 $\texttt{Sheldon}$ 数数量是有限的。我们可以预先生成所有可能的 $\texttt{Sheldon}$ 数，然后对于每个查询，在预生成的列表中进行区间计数。

2. **模式枚举** ：生成所有 $\texttt{Sheldon}$ 数需要枚举所有可能的 $N$ 、 $M$ 和 $k$ 。由于二进制长度有限，枚举量是可接受的。

3. **位运算优化** ：在生成过程中，使用位运算来构造二进制模式对应的数值，可以避免字符串操作，提高效率。

### 详细算法步骤

#### 第一步：生成所有 $\texttt{Sheldon}$ 数

1. **枚举 $N$ 和 $M$** ：
   - $N$ 表示连续 $1$ 的个数， $N$ 的取值范围为 $[1, 64]$ 。
   - $M$ 表示连续 $0$ 的个数， $M$ 的取值范围为 $[0, 64 - N]$ ，确保二进制总长度不超过 $64$ 位。

2. **生成模式 $1$ 的数** ：
   - 对于给定的 $N$ 和 $M$ ，计算单位长度 $L = N + M$ 。
   - 枚举重复次数 $k$ ，满足 $k \times L \le 64$ 。
   - 通过位运算构造数值：每次左移 $N$ 位并添加 $N$ 个 $1$ （即 $(1 \ll N) - 1$ ），如果不是最后一次，再左移 $M$ 位。
   - 将生成的数值加入集合。

3. **生成模式 $2$ 的数** ：
   - 对于给定的 $N$ 和 $M$ ，计算单位长度 $L = N + M$ 。
   - 枚举重复次数 $k$ ，满足 $k \times L + N \le 64$ （注意 $k$ 可以为 $0$ ，此时就是单纯的 $N$ 个 $1$ ）。
   - 通过位运算构造数值：先重复 $k$ 次添加 $N$ 个 $1$ 和 $M$ 个 $0$ ，最后再添加 $N$ 个 $1$ 。
   - 将生成的数值加入集合。

4. **去重与排序** ：由于不同的 $N$ 、 $M$ 、 $k$ 组合可能生成相同的数值，因此需要去重并排序，以便后续二分查找。

#### 第二步：处理查询

对于每个查询 $[X, Y]$ ：
1. 使用 `lower_bound` 找到第一个大于等于 $X$ 的 $\texttt{Sheldon}$ 数的位置。
2. 使用 `upper_bound` 找到第一个大于 $Y$ 的 $\texttt{Sheldon}$ 数的位置。
3. 两个位置的差值即为区间内 $\texttt{Sheldon}$ 数的个数。

### 复杂度分析

- **生成阶段** ：枚举 $N$ 、 $M$ 、 $k$ 的总复杂度约为 $O(64^3)$ ，但实际有效的组合数远小于此。实测生成的 $\texttt{Sheldon}$ 数数量约为 $3000$ 个左右，因此生成过程非常快。
- **查询阶段** ：每个查询使用两次二分查找，复杂度为 $O(\log K)$ ，其中 $K$ 为 $\texttt{Sheldon}$ 数的总数（约 $3000$ ），因此每次查询几乎可以视为常数时间。

### 边界情况与注意事项

1. **数值范围** ：所有生成的数值必须满足 $val \le 2^{63}$ ，因为 $Y$ 的最大值为 $2^{63}$ 。
2. **去重** ：必须对生成的数值进行去重，因为不同的模式可能对应相同的数值（例如， $N=1, M=0, k=2$ 和 $N=2, M=0, k=1$ 都对应二进制 $111$ ，即十进制 $7$ ）。
3. ** $k$ 的取值范围** ：对于模式 $2$ ， $k$ 可以为 $0$ ，这对应了只有 $N$ 个 $1$ 的情况（例如， $N=3$ 对应二进制 $111$ ，即十进制 $7$ ）。
4. **输入处理** ：输入可能包含多组测试用例，直到文件结束。

```cpp
// Sheldon Numbers
// UVa ID: 13022

#include <bits/stdc++.h>
using namespace std;

vector<unsigned long long> sheldonNumbers; // 存储所有Sheldon数

// 生成所有Sheldon数
void generateSheldonNumbers() {
    for (int N = 1; N <= 64; ++N) { // N: 连续1的个数
        for (int M = 0; M <= 64 - N; ++M) { // M: 连续0的个数，且总长度不超过64位
            int segmentLen = N + M; // 一个完整段(1^N 0^M)的长度
            
            // 模式1: (1^N 0^M)^k, k>=1
            if (segmentLen > 0) { // 防止除零错误
                int maxK1 = 64 / segmentLen; // 最大重复次数
                for (int k = 1; k <= maxK1; ++k) {
                    unsigned long long val = 0;
                    for (int i = 0; i < k; ++i) {
                        // 添加N个1: (1<<N)-1 表示N个1的二进制值
                        val = (val << N) | ((1ULL << N) - 1);
                        // 如果不是最后一次，添加M个0
                        if (i != k - 1 || M > 0) val <<= M;
                    }
                    // 检查是否在范围内
                    if (val > 0 && val <= (1ULL << 63)) {
                        sheldonNumbers.push_back(val);
                    }
                }
            }
            
            // 模式2: (1^N 0^M)^k 1^N, k>=0
            // 总长度 = k*(N+M) + N <= 64
            int maxK2 = (64 - N) / (segmentLen > 0 ? segmentLen : 1);
            for (int k = 0; k <= maxK2; ++k) {
                unsigned long long val = 0;
                // 添加k个 (1^N 0^M)
                for (int i = 0; i < k; ++i) {
                    val = (val << N) | ((1ULL << N) - 1);
                    val <<= M;
                }
                // 最后添加一个 1^N
                val = (val << N) | ((1ULL << N) - 1);
                if (val > 0 && val <= (1ULL << 63)) {
                    sheldonNumbers.push_back(val);
                }
            }
        }
    }
    
    // 去重并排序，便于二分查找
    sort(sheldonNumbers.begin(), sheldonNumbers.end());
    sheldonNumbers.erase(unique(sheldonNumbers.begin(), sheldonNumbers.end()), sheldonNumbers.end());
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    // 预生成所有Sheldon数
    generateSheldonNumbers();
    
    unsigned long long X, Y;
    while (cin >> X >> Y) {
        // 使用二分查找统计区间[X, Y]内的Sheldon数个数
        auto left = lower_bound(sheldonNumbers.begin(), sheldonNumbers.end(), X);
        auto right = upper_bound(sheldonNumbers.begin(), sheldonNumbers.end(), Y);
        cout << (right - left) << endl;
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解 $\texttt{Sheldon}$ 数的二进制模式特征，并利用数值范围的限制，通过枚举所有可能的模式来预生成所有 $\texttt{Sheldon}$ 数。预生成的方法虽然看起来需要枚举多个参数，但由于二进制长度有限，实际生成的数值数量并不多（约 $3000$ 个），因此效率非常高。处理查询时，只需在有序列表中进行二分查找即可快速得到答案。这种 **预计算 + 二分查找** 的策略是解决此类区间计数问题的常用且有效的方法。
