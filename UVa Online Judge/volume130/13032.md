[UVa 13032 Marbles in Jars](https://blog.csdn.net/metaphysis/article/details/157102467)

## 题目描述

有 $N$ 个罐子，分别标记为 $1$ 到 $N$ 。每个罐子里都有一些弹珠，第 $i$ 个罐子中的弹珠数为 $M_i$ 。所有弹珠的重量都是 $1$ 克，**除了一个罐子** 中的弹珠重量为 $1.1$ 克，我们称这个特殊的罐子为“重罐子”。

你有一个天平，但只能使用**恰好一次**。你需要找出哪个罐子是重罐子。

一种经典的方法是（假设每个罐子都有足够多的弹珠）：  
从第 $1$ 个罐子取 $1$ 颗弹珠，第 $2$ 个罐子取 $2$ 颗，第 $3$ 个罐子取 $3$ 颗，……，第 $N$ 个罐子取 $N$ 颗。  
将所有取出的弹珠一起称重。  
如果总重量比正常重量多出 $\Delta$ 克，由于每个重弹珠比正常多重 $0.1$ 克，那么多出的重量 $\Delta$ 对应的重罐子就是第 $\frac{\Delta}{0.1}$ 个罐子。  
例如，$N = 4$ 时，正常总重量应为 $10$ 克。如果称得 $10.3$ 克，那么多出 $0.3$ 克，对应重罐子是第 $3$ 个罐子。

我们将每一种取弹珠的方案称为一个“策略”。  
形式化地说，一个策略是一个长度为 $N$ 的正整数数组 $X = [X_1, X_2, \ldots, X_N]$ ，表示从第 $i$ 个罐子取 $X_i$ 颗弹珠。  
我们称量所有取出的弹珠（总数为 $\sum_{i=1}^N X_i$ ），然后根据总重量推断重罐子。  
如果一个策略**总是**能唯一确定重罐子，则称它为“获胜策略”。

现在的问题是：  
给定每个罐子中的弹珠数 $M_1, M_2, \ldots, M_N$ ，问有多少种不同的获胜策略？  
两个策略不同，当且仅当存在某个下标 $i$ 使得 $X_i$ 不同。

由于答案可能很大，请输出答案对 $1,000,000,007$ 取模的结果。

## 输入格式

- 第一行：整数 $T$ $(0 < T \le 100)$ ，表示测试用例的数量。
- 每个测试用例：
  - 第一行：整数 $N$ $(1 \le N \le 100)$ 。
  - 第二行：$N$ 个整数 $M_1, M_2, \ldots, M_N$ $(0 \le M_i \le 100)$ 。

## 输出格式

对于每个测试用例，输出一行：`Case C: A` ，其中 $C$ 是测试用例编号（从 $1$ 开始）， $A$ 是该测试用例的答案。

## 题目分析

### 关键条件

1. **只能称一次**：我们必须通过一次称重的总重量来唯一确定重罐子。
2. **策略定义**：$X_i$ 是正整数，且 $X_i \le M_i$ （不能取超过罐子中实际有的弹珠数）。
3. **获胜策略**：无论重罐子是哪一个，通过一次称重都能唯一确定。

### 如何保证唯一确定？

假设重罐子是第 $j$ 个，那么实际称得的重量为：

$$
\text{总重量} = \left( \sum_{i=1}^N X_i \right) + 0.1 \cdot X_j
$$

即正常总重量加上 $0.1 \times X_j$ 。

因此，**多出的重量**为 $\Delta = 0.1 \times X_j$ 。  
如果我们称得的总重量比正常总重量多出 $\Delta$ ，那么：

$$
X_j = \frac{\Delta}{0.1} = 10 \times \Delta
$$

也就是说，通过多出的重量 $\Delta$ ，我们可以直接反推出 $X_j$ 的值。

### 获胜策略的必要条件

假设有两个不同的罐子 $j$ 和 $k$ ，如果 $X_j = X_k$ ，那么当称重结果多出 $0.1 \times X_j$ 时，我们无法区分是罐子 $j$ 还是罐子 $k$ 是重的。  
因此，**获胜策略必须满足**：所有 $X_i$ 两两不同。

反过来，如果所有 $X_i$ 两两不同，那么根据多出的重量 $\Delta$ ，我们可以唯一确定是哪个罐子（因为只有那个罐子的 $X_j$ 满足 $10\Delta = X_j$）。

所以，问题转化为：

> 计算有多少个数组 $X = [X_1, \ldots, X_N]$ 满足：
> 1. $1 \le X_i \le M_i$ （每个罐子取的数量不超过其弹珠数）。
> 2. $X_i$ 是正整数。
> 3. $X_i$ 两两不同。

### 计数方法

这是一个经典的“受限排列”计数问题。  
我们可以将罐子按照 $M_i$ 从小到大排序，设排序后的上限为 $b_1 \le b_2 \le \cdots \le b_N$ 。  
然后依次为每个罐子分配一个不同的正整数 $X_i$ 。

对于第 $i$ 个罐子（排序后）：
- 它可选的 $X$ 值必须是正整数。
- 不能超过 $b_i$ 。
- 不能与前 $i-1$ 个罐子选择的数重复。

假设前 $i-1$ 个罐子已经选择了 $i-1$ 个不同的数，那么第 $i$ 个罐子可选的数的个数为：

$$
\text{可选数} = \max(0, \ b_i - (i-1))
$$

解释：有 $b_i$ 个数可选（从 $1$ 到 $b_i$ ），但其中 $i-1$ 个已经被前面的罐子占用，所以剩下 $b_i - (i-1)$ 个。  
如果这个值小于等于 $0$ ，则无解（答案为 $0$）。

因此，总方案数为：

$$
\prod_{i=1}^N \max(0, \ b_i - (i-1))
$$

注意：
- 这里的乘法是组合意义上的依次选择。
- 罐子是有标签的，但我们的排序只是为了方便计数。因为排序后我们计算的是“有多少种分配方式满足每个罐子的上限”，并且我们假设分配的数两两不同，这个计数已经考虑了罐子的标签（分配是依次进行的）。

### 特殊情况

- 如果某个 $M_i = 0$ ，则不可能取正整数个弹珠，因此整个方案数为 $0$ 。
- 需要取模 $10^9+7$ 。

## 算法步骤

1. 读取 $T$ 。
2. 对于每个测试用例：
   - 读取 $N$ 和数组 $M$ 。
   - 检查是否有 $M_i = 0$ ，如果有则答案为 $0$ 。
   - 将 $M$ 从小到大排序得到 $b$ 。
   - 初始化 $ans = 1$ 。
   - 遍历 $i = 0$ 到 $N-1$ （0-based）：
     - 计算 $available = b[i] - i$ （因为已选 $i$ 个数）。
     - 如果 $available \le 0$ ，则 $ans = 0$ ，跳出循环。
     - 否则，$ans = ans \times available \mod MOD$ 。
   - 输出 `Case C: ans` 。

### 时间复杂度

- 排序 $O(N \log N)$ ，计算乘积 $O(N)$ ，每个测试用例 $O(N \log N)$ 。
- $N \le 100$ ，$T \le 100$ ，完全可行。

## 代码实现

```cpp
// Marbles in Jars
// UVa ID: 13032
// Verdict: Accepted
// Submission Date: 2026-01-18
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MOD = 1000000007;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    for (int caseNo = 1; caseNo <= T; ++caseNo) {
        int N;
        cin >> N;
        vector<int> M(N);
        for (int i = 0; i < N; ++i) cin >> M[i];
        
        // 如果有罐子不能取弹珠（M[i] == 0），则无解
        bool hasZero = false;
        for (int m : M) if (m == 0) hasZero = true;
        if (hasZero) {
            cout << "Case " << caseNo << ": 0\n";
            continue;
        }
        
        // 将 M 从小到大排序，方便计算
        sort(M.begin(), M.end());
        
        ll ans = 1;
        bool valid = true;
        for (int i = 0; i < N; ++i) {
            // 第 i 个罐子（排序后）可选的 X 值个数
            // 已经选了 i 个不同的数，还剩 M[i] - i 种选择
            int available = M[i] - i;
            if (available <= 0) {
                valid = false;
                break;
            }
            ans = ans * available % MOD;
        }
        
        if (!valid) ans = 0;
        cout << "Case " << caseNo << ": " << ans << "\n";
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解获胜策略的本质：所有 $X_i$ 必须两两不同。  一旦理解了这一点，问题就转化为一个受限排列计数问题，可以通过排序后依次计算可选数来高效解决。  注意处理 $M_i = 0$ 的特殊情况，以及大数取模的细节。  代码实现简洁，时间复杂度完全满足题目限制。
