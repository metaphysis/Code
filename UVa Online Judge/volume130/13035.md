[UVa 13035 Another Combination Problem](https://blog.csdn.net/metaphysis/article/details/155462530)

## 题目翻译

有 $N$ 个盒子，第 $i$ 个盒子里有 $i+1$ 个球。所有球的颜色互不相同，因此它们是可区分的。

第一个盒子有 $2$ 个球，第二个盒子有 $3$ 个球，第三个盒子有 $4$ 个球，依此类推，第 $N$ 个盒子有 $N+1$ 个球。

你从这 $N$ 个盒子中**选择一个盒子**，然后从该盒子中取出**两个球**，一个放在左手，一个放在右手。

**注意**：即使两个球相同，如果左右手交换，也被视为不同的方式。

### 输入格式
第一行输入 $T$（$T \leq 100000$），表示测试用例的数量。
接下来的 $T$ 行，每行包含一个整数 $N$（$1 \leq N \leq 10^9$）。

### 输出格式
对于每个测试用例，输出一行 `Case I: S`，其中 $I$ 是测试用例编号（从 1 开始），$S$ 是答案对 $1000000007$ 取模的结果。

### 样例
**输入：**
```
2
1
2
```
**输出：**
```
Case 1: 2
Case 2: 8
```

## 题目分析

这个问题是一个**组合计数问题**，需要仔细分析选择盒子和取球的过程。

### 关键点理解
1. **盒子选择**：从 $N$ 个盒子中选择一个盒子（任意一个）。
2. **取球方式**：
   - 从选中的盒子中取出两个球
   - 一个放左手，一个放右手
   - 球是可区分的（颜色不同）
   - **左右手交换视为不同方案**

### 逐步推导

#### 第一步：分析单个盒子的方案数
假设我们选择第 $k$ 个盒子（$1 \leq k \leq N$）：
- 该盒子中有 $k+1$ 个球
- 我们先取左手的球：有 $k+1$ 种选择
- 再取右手的球：有 $k$ 种选择（不能与左手球相同）
- 所以对于第 $k$ 个盒子，方案数为：$(k+1) \times k$

#### 第二步：对所有盒子求和
总方案数 $S(N)$ 需要累加所有盒子的方案数：
$$ S(N) = \sum_{k=1}^{N} k(k+1) $$

#### 第三步：化简求和公式
我们可以将求和式展开：
$$ S(N) = \sum_{k=1}^{N} (k^2 + k) = \sum_{k=1}^{N} k^2 + \sum_{k=1}^{N} k $$

使用已知的求和公式：

$1$. 平方和公式：$\sum_{k=1}^{N} k^2 = \frac{N(N+1)(2N+1)}{6}$

$2$. 等差数列和公式：$\sum_{k=1}^{N} k = \frac{N(N+1)}{2}$

代入得：
$$ S(N) = \frac{N(N+1)(2N+1)}{6} + \frac{N(N+1)}{2} $$

通分合并：
$$ S(N) = \frac{N(N+1)(2N+1) + 3N(N+1)}{6} $$
$$ S(N) = \frac{N(N+1)(2N+4)}{6} $$
$$ S(N) = \frac{N(N+1)(N+2)}{3} $$

**验证**：
- 当 $N=1$ 时：$S(1) = \frac{1 \times 2 \times 3}{3} = 2$ ✓
- 当 $N=2$ 时：$S(2) = \frac{2 \times 3 \times 4}{3} = 8$ ✓

#### 第四步：公式的另一种推导（组合恒等式）
我们也可以用组合数学的方法推导：
$$ \sum_{k=1}^{N} k(k+1) = 2\sum_{k=1}^{N} \binom{k+1}{2} $$
由**曲棍球棍恒等式**（$\texttt{Hockey-stick identity}$）：
$$ \sum_{k=1}^{N} \binom{k+1}{2} = \binom{N+2}{3} $$
因此：
$$ S(N) = 2 \times \binom{N+2}{3} = 2 \times \frac{(N+2)(N+1)N}{6} = \frac{N(N+1)(N+2)}{3} $$
结果一致。

## 算法设计

### 主要挑战
1. **数据范围大**：$N$ 可达 $10^9$，直接计算 $N(N+1)(N+2)$ 会溢出 $64$ 位整数
2. **模运算要求**：需要对 $10^9+7$ 取模
3. **除法处理**：公式中有除以 $3$ 的操作，在模运算中不能直接除

### 解决方案
1. **边乘边取模**：计算 $(N \mod M) \times ((N+1) \mod M) \times ((N+2) \mod M) \mod M$
2. **乘法逆元**：将除以 $3$ 改为乘以 $3$ 的模逆元
   - 模数 $M = 1000000007$ 是质数
   - 根据费马小定理：$a^{M-1} \equiv 1 \pmod{M}$
   - 因此 $3$ 的逆元为 $3^{M-2} \mod M$

### 算法步骤
1. 读入测试用例数 $T$
2. 对于每个测试用例：
   - 读入 $N$
   - 计算 $a = N \mod M$, $b = (N+1) \mod M$, $c = (N+2) \mod M$
   - 计算 $3$ 的模逆元 $inv3 = 3^{M-2} \mod M$（可预计算或实时计算）
   - 计算 $ans = ((a \times b \mod M) \times c \mod M) \times inv3 \mod M$
   - 输出结果

### 时间复杂度
- 快速幂求逆元：$O(\log M)$
- 总复杂度：$O(T \log M)$，对于 $T \leq 10^5$ 完全可行

### 空间复杂度
- $O(1)$，仅使用常数个变量

---

## 注意事项
1. **整数溢出**：即使在取模前，$N$ 最大为 $10^9$，$N(N+1)(N+2)$ 约 $10^{27}$，远超 64 位整数范围，必须边乘边取模
2. **模运算一致性**：所有中间结果都要及时取模
3. **逆元的存在性**：由于 $M$ 是质数且 $3$ 不是 $M$ 的倍数，逆元一定存在

## 代码实现

```cpp
// Another Combination Problem
// UVa ID: 13035
// Verdict: Accepted
// Submission Date: 2025-12-01
// UVa Run Time: 0.030s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll MOD = 1000000007;

// 快速幂取模
ll modPow(ll base, ll exp, ll mod) {
    ll result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) result = (result * base) % mod;
        base = (base * base) % mod;
        exp >>= 1;
    }
    return result;
}

// 模逆元（费马小定理）
ll modInv(ll x, ll mod) {
    return modPow(x, mod - 2, mod);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    for (int caseId = 1; caseId <= T; ++caseId) {
        ll N;
        cin >> N;
        // 通项公式：S = N * (N+1) * (N+2) / 3
        // 因为要取模，所以改为乘逆元
        ll a = N % MOD;
        ll b = (N + 1) % MOD;
        ll c = (N + 2) % MOD;
        ll inv3 = modInv(3, MOD); // 3的模逆元
        ll ans = (((a * b) % MOD) * c) % MOD;
        ans = (ans * inv3) % MOD;
        cout << "Case " << caseId << ": " << ans << "\n";
    }
    return 0;
}
```

## 总结

本题是一道中等难度的组合数学问题，主要考察：
1. **组合计数**的基本原理
2. **求和公式**的化简能力
3. **模运算**和**乘法逆元**的应用
4. **大整数处理**的注意事项

关键公式：
$$ \text{答案} = \frac{N(N+1)(N+2)}{3} \mod 1000000007 $$

通过这道题，我们学习了如何将组合计数问题转化为数学公式，并在模运算环境下正确处理除法运算。这种方法在解决类似的计数问题时非常有用。
