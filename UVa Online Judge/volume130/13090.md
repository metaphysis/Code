[UVa 13090 Base of MJ](https://blog.csdn.net/metaphysis/article/details/156912241)

## 题目大意

给定一个除数 $D$ ，要求找出所有满足条件的基数 $B$（$2 \leq B \leq BMAX$），使得**任意**一个在基 $B$ 下表示的数 $N$，其各位数字之和 $S$ 满足以下等价条件：

$$
N \text{ 能被 } D \text{ 整除} \iff S \text{ 能被 } D \text{ 整除}
$$

例如，当 $BMAX = 10$，$D = 3$ 时，满足条件的基数有 $4$、$7$ 和 $10$，因此答案为 $3$。

## 题目分析

### 1. 问题转化

设 $N$ 在基 $B$ 下的表示为：

$$
N = a_k B^k + a_{k-1} B^{k-1} + \cdots + a_1 B + a_0
$$

其中 $0 \leq a_i < B$，且 $a_k \neq 0$。

其各位数字之和为：

$$
S = a_k + a_{k-1} + \cdots + a_1 + a_0
$$

我们希望：

$$
N \equiv S \pmod{D}
$$

即：

$$
a_k B^k + a_{k-1} B^{k-1} + \cdots + a_1 B + a_0 \equiv a_k + a_{k-1} + \cdots + a_0 \pmod{D}
$$

移项得：

$$
a_k (B^k - 1) + a_{k-1} (B^{k-1} - 1) + \cdots + a_1 (B - 1) \equiv 0 \pmod{D}
$$

### 2. 条件推导

我们希望上述同余式对**所有可能的** $a_i$ 都成立。这等价于要求：

$$
B^t \equiv 1 \pmod{D}, \quad \forall t \geq 1
$$

这是因为对于任意的 $a_i$，只有当 $D$ 整除所有 $(B^t - 1)$ 时，同余式才恒成立。

而 $B^t \equiv 1 \pmod{D}$ 对所有 $t \geq 1$ 成立的充分必要条件是：

$$
B \equiv 1 \pmod{D}
$$

**证明**：
- 充分性：若 $B \equiv 1 \pmod{D}$，则 $B^t \equiv 1^t = 1 \pmod{D}$。
- 必要性：取 $t = 1$，即得 $B \equiv 1 \pmod{D}$。

因此，条件简化为：

$$
B \equiv 1 \pmod{D}
$$

且 $B \geq 2$（基数至少为 $2$）。

### 3. 特殊情况：$D = 1$

当 $D = 1$ 时，任何整数模 $1$ 都余 $0$，因此所有 $B \geq 2$ 都满足条件。

### 4. 问题最终形式

我们需要计算在区间 $[2, BMAX]$ 内，满足 $B \equiv 1 \pmod{D}$ 的整数 $B$ 的个数。

## 解题步骤

### 步骤 $1$：处理 $D = 1$ 的情况
- 若 $D = 1$，答案即为 $BMAX - 1$（$B$ 从 $2$ 到 $BMAX$）。

### 步骤 $2$：处理 $D > 1$ 的情况
- 第一个满足 $B \equiv 1 \pmod{D}$ 且 $B \geq 2$ 的数是 $D + 1$（因为 $1$ 模 $D$ 余 $1$，但 $1 < 2$，所以取下一个）。
- 设第一个符合条件的数为 $firstB = D + 1$。
- 若 $firstB > BMAX$，则答案为 $0$。
- 否则，这些数构成一个公差为 $D$ 的等差数列，项数为：

$$
count = \left\lfloor \frac{BMAX - firstB}{D} \right\rfloor + 1
$$

### 步骤 $3$：时间复杂度
- 每个测试用例只需 $O(1)$ 时间，总复杂度 $O(T)$，可处理 $T \leq 10000$ 的大数据。

## 代码实现

```cpp
// Base of MJ
// UVa ID: 13090
// Verdict: Accepted
// Submission Date: 2026-01-13
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

using ll = long long;

int main() {
    int t;
    cin >> t;
    for (int caseNo = 1; caseNo <= t; ++caseNo) {
        ll bMax, d;
        cin >> bMax >> d;
        ll count = 0;
        if (d == 1) {
            // 若 D=1，所有 B 都满足条件，因为任何数都能被 1 整除
            count = bMax - 1; // B 从 2 到 BMAX
        } else {
            // 计算 B ≡ 1 (mod D) 且 B >= 2 的个数
            // 最小满足条件的 B 是 1，但 B 必须 >=2，所以从 1+D 开始
            ll firstB = d + 1; // 第一个可能的 B（>=2）
            if (firstB <= bMax) count = (bMax - firstB) / d + 1;
            else count = 0;
        }
        cout << "Case " << caseNo << ": " << count << '\n';
    }
    return 0;
}
```

## 总结

本题的关键在于将原问题转化为同余条件 $B \equiv 1 \pmod{D}$，从而将复杂的“对所有数字成立”的判定简化为一个简单的模运算条件。通过数学推导，我们得到了简洁的计数公式，可以在常数时间内求解每个测试用例，高效处理 $BMAX$ 和 $D$ 高达 $10^{18}$ 的大范围数据。
