
> **摘要**：本题给定正整数 $N$（$1 \le N \le 10^{7}$），要求用最少的三角数之和表示 $N$。借助高斯定理，答案只可能是 $1$、$2$ 或 $3$。解法先预计算所有不超过 $10^7$ 的三角数（约 $4472$ 个）并标记，再枚举两两之和标记到布尔数组，最后对每个查询以 $O(1)$ 时间判断输出 $1$、$2$ 或 $3$。整体预计算约 $2 \times 10^7$ 次操作，空间约 $20$ MB，可高效处理多组测试数据。

## 题目描述

胡戈夫·莫洛托夫，一位邪恶的计算机科学家，痴迷于三角数以及如何利用它们统治世界。莫洛托夫想选拔一名新的助手，因此他准备了一项艰巨的任务来测试你是否合格。任务内容如下：给定一个正整数 $N$，求出最少需要多少个三角数，使得它们的和等于 $N$。

注意：三角数定义为  
$$
\sum_{i=1}^{X} i = 1 + 2 + 3 + \cdots + X
$$
其中 $X$ 是任意正整数。

## 输入格式

输入可能包含多个测试用例。每个测试用例占一行，包含一个正整数 $N$（$1 \le N \le 10^{7}$）。输入以 $\texttt{EOF}$ 终止。

## 输出格式

对于每个测试用例，输出一行一个正整数，表示所需的最少三角数个数。

## 样例

**样例输入**
```
1
2
6
10
```

**样例输出**
```
1
2
1
1
```

## 题目分析

本题要求对于给定的正整数 $N$，求出将其表示为若干三角数之和所需的最少项数。三角数定义为 $T_x = x(x+1)/2$，其中 $x$ 为正整数。

根据高斯关于三角数的一个著名定理，每个非负整数都可以表示为至多三个三角数之和。该定理是费马多边形数定理在 $k=3$ 时的特殊情形。因此，对于任意正整数 $N$，答案只可能为 $1$、$2$ 或 $3$。

基于此结论，问题的核心转化为如何高效判断 $N$ 是否可以由 $1$ 个或 $2$ 个三角数表示。若 $N$ 本身是三角数，则答案为 $1$；否则，检查是否存在两个三角数之和等于 $N$，若存在则答案为 $2$；若以上均不成立，则根据定理答案为 $3$。

由于 $N$ 的最大值为 $10^7$，对应的最大三角数下标 $x$ 满足 $x(x+1)/2 \le 10^7$，解得 $x \le 4472$。三角数的总数极少，因此预计算所有三角数以及任意两个三角数之和是完全可行的。

## 解题思路

本题的解题过程分为预计算和在线查询两个阶段。

**阶段 $\texttt{1}$：预计算所有三角数**  
使用累加方式生成三角数 $T_x$。令 $t = 0$，从 $x = 1$ 开始，每次 $t \gets t + x$，则 $t$ 即为 $T_x$。当 $t$ 超过 $10^7$ 时停止。将所有生成的三角数存入数组 `triNumbers`，同时用布尔数组 `isTri` 标记每个数是否为三角数。

**阶段 $\texttt{2}$：预计算所有两三角数之和**  
由于三角数个数约 $4472$，两重循环枚举所有有序对（$i \le j$），计算 `triNumbers[i] + triNumbers[j]`。若和不超过 $10^7$，则在布尔数组 `twoSum` 中将该和标记为 $\texttt{true}$。当内层循环中某一对和超过最大值时，由于三角数递增，后续更大的 $j$ 必然也超过，因此可提前退出内层循环，提高效率。

**阶段 $\texttt{3}$：在线查询**  
对于每个输入的 $N$，依次检查：
- 若 `isTri[N]` 为真，输出 $1$；
- 否则若 `twoSum[N]` 为真，输出 $2$；
- 否则输出 $3$。

每个测试用例的查询时间为 $O(1)$，总复杂度仅取决于输入规模。

**复杂度分析**  
- 预计算三角数的时间复杂度为 $O(\sqrt{N_{\max}})$，即 $O(4472)$。  
- 预计算两数之和的时间复杂度为 $O(M^2)$，其中 $M = \lfloor (\sqrt{8N_{\max}+1}-1)/2 \rfloor \approx 4472$，故约为 $2 \times 10^7$ 次操作，在 $1$ 秒内可完成。  
- 空间复杂度为 $O(N_{\max})$，用于两个长度为 $10^7+1$ 的布尔数组，以及一个长度约 $4472$ 的整型数组，总内存约 $20$ $\texttt{MB}$，符合常规限制。

## 代码实现

```cpp
// Triangular Test II
// UVa ID: 13098
// Verdict: Accepted

// UVa Run Time: 1.370s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    const int MAXN = 10000000;
    const int MAX_TRI = 5000;

    int triNumbers[MAX_TRI];
    bool isTri[MAXN + 1] = {false};
    bool twoSum[MAXN + 1] = {false};

    int cnt = 0;
    int t = 0;
    for (int x = 1; ; ++x) {
        t += x;
        if (t > MAXN) break;
        triNumbers[cnt++] = t;
        isTri[t] = true;
    }

    for (int i = 0; i < cnt; ++i) {
        for (int j = i; j < cnt; ++j) {
            int sum = triNumbers[i] + triNumbers[j];
            if (sum > MAXN) break;
            twoSum[sum] = true;
        }
    }

    int N;
    while (cin >> N) {
        if (isTri[N]) cout << 1 << '\n';
        else if (twoSum[N]) cout << 2 << '\n';
        else cout << 3 << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于利用高斯定理将答案限制在 $1$、$2$、$3$ 三个值内，从而避免复杂的动态规划或搜索。预计算所有三角数及其两两之和，使得每个测试用例的查询达到 $O(1)$ 时间，这是处理多组数据的有效策略。

**关键技巧**：
- 利用累加生成三角数，避免乘法运算，提升预计算速度。
- 使用固定大小的数组代替动态容器，减少内存分配开销。
- 双重循环中利用递增性提前退出内层循环，减少无用计算。
- 合理利用布尔数组进行 $O(1)$ 查询，将复杂度从 $O(\sqrt{N})$ 降低至 $O(1)$。

该解法在 $N \le 10^7$ 的限制下运行高效，且代码简洁，是处理此类数论问题的典型范例。
