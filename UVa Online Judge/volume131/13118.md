## 题目描述

古林和玛隆是一对生活在“二进制之地”的企鹅情侣，它们被困在一个 $R \times C$ 的迷宫中。迷宫中的每个格子要么是空地（用空格表示），要么是墙（用 `#` 表示）。迷宫中有一个特定的“爱心格子”，古林和玛隆需要同时到达这个格子才能相遇并“坠入爱河”。

两只企鹅的移动受到一个诅咒的影响：

- 如果一只企鹅向**北**或**南**移动，另一只企鹅必须**同时**向**相同方向**移动（如果被墙阻挡则留在原地）。
- 如果一只企鹅向**东**或**西**移动，另一只企鹅必须**同时**向**相反方向**移动（如果被墙阻挡则留在原地）。

每次移动花费 $1$ 单位时间。给定迷宫、爱心格子坐标以及两只企鹅的初始坐标，求它们相遇的最短时间，如果无法相遇则输出 `NO LOVE` 。

## 输入格式

- 第一行：两个整数 $R$ 和 $C$ （ $1 \le R, C \le 40$ ），表示迷宫的行数和列数（不包括外围的墙）。
- 第二行：六个整数 $r_L, c_L, r_G, c_G, r_M, c_M$ ，分别表示爱心格子、古林初始位置、玛隆初始位置的坐标（ 从 $1$ 开始编号 ）。
- 接下来 $R$ 行：每行 $C$ 个字符，表示迷宫地图，`.` 表示空地，`#` 表示墙。

## 输出格式

对于每个测试用例，输出一行：最短相遇时间，或 `NO LOVE` 。

## 题目分析

### 1. 问题本质

这是一个**双角色同时移动**的最短路问题。两只企鹅的移动是**耦合**的：一只企鹅的移动会强制另一只企鹅按照特定规则移动（或被墙阻挡而停留）。我们的目标是找到从初始状态到目标状态（两只企鹅同时在爱心格子）的最短时间。

### 2. 状态表示

由于两只企鹅的位置是独立的，我们可以用一个四元组 $(r_G, c_G, r_M, c_M)$ 表示当前状态，其中：

- $(r_G, c_G)$ ：古林的坐标。
- $(r_M, c_M)$ ：玛隆的坐标。

状态空间的大小为 $(R \times C)^2$ 。在 $R, C \le 40$ 的条件下，最大状态数为 $(40 \times 40)^2 = 1600^2 = 2.56 \times 10^6$ ，在 $\texttt{BFS}$ 的可接受范围内。

### 3. 移动规则

对于每个方向 $dir \in \{$ 北, 南, 东, 西 $\}$ ，我们模拟一次“尝试移动”：

- **古林尝试移动**到 $(nr_G, nc_G)$ 。
- **根据诅咒规则**，确定玛隆的尝试移动方向：
    - 如果 $dir$ 是北或南，玛隆尝试向**相同方向**移动。
    - 如果 $dir$ 是东或西，玛隆尝试向**相反方向**移动。
- **墙阻挡检查**：
    - 如果古林的目标格子是墙或越界，则古林留在原地。
    - 如果玛隆的目标格子是墙或越界，则玛隆留在原地。

注意：即使一只企鹅被墙阻挡，另一只企鹅仍然可以移动（只要它不撞墙）。这是规则中明确允许的。

### 4. 目标状态

目标状态是：
$$
r_G = r_M = r_L \quad \text{且} \quad c_G = c_M = c_L
$$
即两只企鹅都在爱心格子上。

### 5. 算法选择

因为所有移动的代价都是 $1$ ，我们可以使用 **$\texttt{BFS}$（广度优先搜索）** 来寻找最短路径。$\texttt{BFS}$ 从初始状态开始，每次尝试四个方向的移动，生成新状态并加入队列，直到找到目标状态或队列为空。

### 6. 复杂度分析

- **状态数**：最多 $O((RC)^2) = O(2.56 \times 10^6)$ 。
- **每个状态扩展**： $4$ 个方向。
- **总时间复杂度**： $O(4 \times (RC)^2)$ ，在 $R, C \le 40$ 时完全可行。
- **空间复杂度**： $O((RC)^2)$ 用于存储访问状态。

## 解题步骤

1. 读入 $R, C$ 和坐标，将从 $1$ 开始编号的坐标转换为从 $0$ 开始编号。
2. 读入迷宫地图。
3. 初始化 $\texttt{BFS}$ 队列，将初始状态 $(r_G, c_G, r_M, c_M)$ 入队，距离为 $0$ 。
4. 使用哈希集合记录已访问的状态。
5. 当队列非空时：
    - 取出队首状态和距离。
    - 如果该状态是目标状态，更新答案并结束。
    - 尝试四个方向的移动，生成新状态：
        - 根据规则计算两只企鹅的新位置。
        - 检查墙和边界，修正位置。
        - 如果新状态未访问过，则加入队列。
6. 如果 $\texttt{BFS}$ 结束仍未找到目标，输出 `NO LOVE` ，否则输出最短时间。

## 代码实现

```cpp
// Binary Land
// UVa ID: 13118
// Verdict: Accepted
// Submission Date: 2026-01-18
// UVa Run Time: 1.320s

// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

struct State {
    int r1, c1, r2, c2; // (r1,c1): Gurin, (r2,c2): Malon
    State(int a, int b, int c, int d) : r1(a), c1(b), r2(c), c2(d) {}
    bool operator==(const State& other) const {
        return r1 == other.r1 && c1 == other.c1 && r2 == other.r2 && c2 == other.c2;
    }
};

struct StateHash {
    size_t operator()(const State& s) const {
        return ((s.r1 * 41 + s.c1) * 41 + s.r2) * 41 + s.c2;
    }
};

int dr[4] = {-1, 1, 0, 0}; // 北, 南, 东, 西
int dc[4] = {0, 0, 1, -1};

int main() {
    int R, C;
    while (cin >> R >> C) {
        int rL, cL, rG, cG, rM, cM;
        cin >> rL >> cL >> rG >> cG >> rM >> cM;
        // 将坐标从1-based转换为0-based
        rL--; cL--; rG--; cG--; rM--; cM--;
        
        vector<string> maze(R);
        cin.ignore();
        for (int i = 0; i < R; i++) getline(cin, maze[i]);
        
        // BFS
        queue<pair<State, int>> q;
        unordered_set<State, StateHash> visited;
        State start(rG, cG, rM, cM);
        q.push({start, 0});
        visited.insert(start);
        
        int answer = -1;
        while (!q.empty()) {
            State cur = q.front().first;
            int dist = q.front().second;
            q.pop();
            
            // 检查是否到达目标：两只企鹅都在爱心格子
            if (cur.r1 == rL && cur.c1 == cL && cur.r2 == rL && cur.c2 == cL) {
                answer = dist;
                break;
            }
            
            // 尝试四个方向移动
            for (int dir = 0; dir < 4; dir++) {
                int nr1 = cur.r1 + dr[dir], nc1 = cur.c1 + dc[dir];
                int nr2 = cur.r2, nc2 = cur.c2;
                
                // 根据诅咒规则决定另一只企鹅的移动方向
                if (dir == 0 || dir == 1) { // 北或南：另一只企鹅同向移动
                    nr2 = cur.r2 + dr[dir];
                    nc2 = cur.c2 + dc[dir];
                } else if (dir == 2) { // 东：另一只企鹅向西移动
                    nr2 = cur.r2 + dr[3]; // 西
                    nc2 = cur.c2 + dc[3];
                } else { // 西：另一只企鹅向东移动
                    nr2 = cur.r2 + dr[2]; // 东
                    nc2 = cur.c2 + dc[2];
                }
                
                // 检查古林的移动是否有效
                if (nr1 < 0 || nr1 >= R || nc1 < 0 || nc1 >= C || maze[nr1][nc1] == '#') {
                    nr1 = cur.r1; // 不能移动，留在原地
                    nc1 = cur.c1;
                }
                // 检查玛隆的移动是否有效
                if (nr2 < 0 || nr2 >= R || nc2 < 0 || nc2 >= C || maze[nr2][nc2] == '#') {
                    nr2 = cur.r2; // 不能移动，留在原地
                    nc2 = cur.c2;
                }
                
                State next(nr1, nc1, nr2, nc2);
                if (visited.find(next) == visited.end()) {
                    visited.insert(next);
                    q.push({next, dist + 1});
                }
            }
        }
        
        if (answer == -1) cout << "NO LOVE\n";
        else cout << answer << "\n";
    }
    return 0;
}
```

## 总结

本题的关键在于**正确建模状态**和**实现耦合的移动规则**。通过将两只企鹅的位置组合成一个状态，并使用 $\texttt{BFS}$ 搜索，我们可以在状态空间内找到最短路径。注意移动规则中的细节：当一只企鹅移动时，另一只企鹅**必须尝试**相应方向的移动，但可能因为墙阻挡而停留在原地。这种“尝试移动 + 阻挡检查”的实现方式确保了规则的正确性。

在竞赛中，这类双角色同步移动的问题并不罕见，通常的解决方案就是扩展状态维度并使用 $\texttt{BFS}$ 或 $\texttt{Dijkstra }$ 算法。本题的状态空间较小，因此 $\texttt{BFS}$ 是高效且简单的选择。
