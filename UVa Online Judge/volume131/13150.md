## 题目分析

本题要求计算在拥挤场所中自杀式炸弹袭击的 **预期死亡人数** 。题目给出 $N$ 个人的坐标（二维笛卡尔平面上的点），每个人携带炸弹的概率相等，爆炸半径为 $R$ 时，炸弹会杀死所有距离携带者不超过 $R$ 的人（包括携带者自己）。

**关键理解**：  
预期死亡人数 $E(R)$ 等于 **所有可能携带炸弹的人** 的死亡人数的平均值。  
具体公式为：

$$
E(R) = \frac{1}{N} \sum_{i=1}^{N} \texttt{count}_i(R)
$$

其中 $\texttt{count}_i(R)$ 表示：如果第 $i$ 个人携带炸弹，那么在半径 $R$ 内会死亡的人数（包括第 $i$ 个人自己）。

**问题规模**：
- $N \leq 3000$ ， $Q \leq 1000$ 。
- 坐标值 $\leq 25000$ ，半径 $R < 40001$ 。

最直接的暴力方法是：对每个查询 $R$ ，遍历所有点对计算距离，复杂度 $O(N^2 Q)$ 。在极限情况下 $3000^2 \times 1000 = 9 \times 10^9$ ，显然会超时。

## 解题思路

我们需要优化查询过程。观察到：
1. 距离比较可以转化为 **距离平方比较** ，避免浮点数运算。
2. 对于每个点 $i$ ，可以预先计算出它到所有其他点（包括自己）的距离平方，并排序。
3. 对于查询 $R$ ，我们只需要对每个点 $i$ ，在它的距离平方排序数组中，统计 $\leq R^2$ 的元素个数。这可以通过 **二分查找** 快速完成。

**算法步骤**：

1. 读入 $N$ 个点的坐标。
2. **预处理**：对每个点 $i$ ，计算到所有点 $j$ 的距离平方 $d^2_{ij}$ ，存入数组 `distSq[i]` ，然后对 `distSq[i]` 排序。
3. 对每个查询 $R$：
   - 计算 $R^2$ 。
   - 对每个点 $i$ ，在 `distSq[i]` 中使用 `upper_bound` 找到第一个 $> R^2$ 的位置，该位置索引即为 $\leq R^2$ 的元素个数（即该点作为炸弹携带者时的死亡人数）。
   - 累加所有点的死亡人数，除以 $N$ 得到期望值，保留两位小数输出。

**复杂度分析**：
- 预处理：计算所有点对距离 $O(N^2)$ ，排序 $N$ 个数组，每个数组长度 $N$ ，总复杂度 $O(N^2 \log N)$ 。
- 每个查询：对 $N$ 个点进行二分查找，复杂度 $O(N \log N)$ 。
- 总复杂度：$O(N^2 \log N + Q N \log N)$ 。代入 $N=3000, Q=1000$ 估算：预处理约 $3000^2 \log 3000 \approx 9\times10^6 \times 11.5 \approx 1.04\times10^8$ 次操作，查询约 $1000 \times 3000 \times \log 3000 \approx 3.45\times10^7$ 次操作，在合理范围内。

**注意事项**：
- 距离平方可能达到 $(25000)^2 + (25000)^2 = 1.25\times10^9$ ，在 `int` 范围内（$2^{31}-1 \approx 2.1\times10^9$）。
- 输出要求每个测试用例后输出空行。
- 使用 `double` 计算平均值，并控制输出格式为两位小数。

## 参考代码

```cpp
// National Bomb Defusing Squad
// UVa ID: 13150

//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    while (cin >> n >> q, n || q) {
        vector<pair<int, int>> points(n);
        for (int i = 0; i < n; ++i) cin >> points[i].first >> points[i].second;

        // 对每个点，存储到其他点的距离平方
        vector<vector<int>> distSq(n);
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                int dx = points[i].first - points[j].first;
                int dy = points[i].second - points[j].second;
                distSq[i].push_back(dx * dx + dy * dy);
            }
            sort(distSq[i].begin(), distSq[i].end()); // 便于二分查找
        }

        while (q--) {
            int r;
            cin >> r;
            long long total = 0;
            int rSq = r * r;
            for (int i = 0; i < n; ++i) {
                // 使用 upper_bound 找到第一个 > rSq 的位置，其索引即为 ≤ rSq 的数量
                int cnt = upper_bound(distSq[i].begin(), distSq[i].end(), rSq) - distSq[i].begin();
                total += cnt;
            }
            double expected = total * 1.0 / n;
            cout << fixed << setprecision(2) << expected << "\n";
        }
        cout << "\n"; // 每个测试用例后输出空行
    }

    return 0;
}
```

## 总结

本题通过 **预处理距离平方 + 排序 + 二分查找** 的方法，将每个查询的复杂度从 $O(N^2)$ 降低到 $O(N \log N)$ ，从而在题目给定的数据范围内高效求解。关键在于将问题转化为对每个点统计其邻域内的人数，并利用排序和二分加速统计过程。
