## 题目描述

像素艺术是一种由小方块（像素）组成的艺术形式，每个像素填充单一颜色。由于 $20$ 世纪 $80$ 年代计算机表示图像的能力有限，这种艺术形式非常流行，至今仍受到复古爱好者的喜爱。

当你拥有所有必需的颜色时，复制这种图像非常容易。但挑战在于仅使用三种原色——洋红色（$\texttt{Magenta}$）、黄色（$\texttt{Yellow}$）和青色（$\texttt{Cyan}$）——来完成。幸运的是，根据颜色理论，我们可以通过混合原色得到任何颜色。

## 颜色混合规则

- $\texttt{M}$（洋红色）：直接使用 $1$ 单位洋红色
- $\texttt{Y}$（黄色）：直接使用 $1$ 单位黄色  
- $\texttt{C}$（青色）：直接使用 $1$ 单位青色
- $\texttt{R}$（红色）：需要 $1$ 洋红色 + $1$ 黄色
- $\texttt{G}$（绿色）：需要 $1$ 黄色 + $1$ 青色
- $\texttt{V}$（紫色）：需要 $1$ 洋红色 + $1$ 青色
- $\texttt{B}$（黑色）：需要 $1$ 洋红色 + $1$ 黄色 + $1$ 青色
- $\texttt{W}$（白色）：不消耗任何颜料

## 输入格式

程序首先从标准输入读取测试用例的数量 $t$。

每个测试用例包含：
- $3$ 个整数：表示可用的洋红色、黄色和青色的颜料数量
- $1$ 个字符串：描述图像的像素序列，每个字符代表一个像素的颜色

## 输出格式

对于每个测试用例：
- 如果图像可以完成：输出 $\texttt{YES}$ 和剩余的洋红色、黄色、青色颜料数量
- 如果无法完成：输出 $\texttt{NO}$

## 题目分析

这是一个典型的**资源分配与消耗模拟**问题。我们需要跟踪三种颜料的库存数量，并按照每个像素的颜色需求相应减少库存。

### 解题思路

1. **读取输入**：首先读取测试用例数量 $t$，然后对每个测试用例读取三种颜料的初始数量和像素序列。

2. **模拟绘制过程**：遍历像素序列中的每个像素：
   - 根据像素颜色确定需要消耗的颜料种类和数量
   - 从当前库存中减去相应的数量
   - 如果在任何时候某种颜料的库存变为负数，立即停止处理当前测试用例

3. **结果判断**：
   - 如果所有颜料库存都保持非负，输出 $\texttt{YES}$ 和剩余数量
   - 如果任何颜料出现负数库存，输出 $\texttt{NO}$

### 算法复杂度分析

- 对于每个测试用例，我们需要遍历整个像素序列
- 每个像素的处理时间是常数时间 $O(1)$
- 总体时间复杂度为 $O(n)$，其中 $n$ 是像素序列的长度
- 空间复杂度为 $O(1)$，只使用了固定数量的变量

### 关键点

- 使用 $\texttt{switch}$ 语句高效处理不同颜色的消耗规则
- 在消耗颜料后立即检查库存，一旦发现不足就提前终止
- 注意 $\texttt{W}$（白色）像素不消耗任何颜料

## 代码实现

```cpp
// Pixel Art
// UVa ID: 13171
// Verdict: Accepted
// Submission Date: 2025-11-15
// UVa Run Time: 0.030s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int m, y, c;
        string s;
        cin >> m >> y >> c >> s;
        
        for (char pixel : s) {
            switch (pixel) {
                case 'M': m--; break;
                case 'Y': y--; break;
                case 'C': c--; break;
                case 'R': m--; y--; break;
                case 'G': y--; c--; break;
                case 'V': m--; c--; break;
                case 'B': m--; y--; c--; break;
                case 'W': break;
            }
            if (m < 0 || y < 0 || c < 0) break;
        }
        
        if (m < 0 || y < 0 || c < 0) {
            cout << "NO\n";
        } else {
            cout << "YES " << m << " " << y << " " << c << "\n";
        }
    }
    return 0;
}
```

## 样例分析

### 样例输入
```
3
1 1 1 MCY
3 2 1 MYWWCR
1 1 1 RV
```

### 样例输出
```
YES 0 0 0
YES 1 0 0
NO
```

**第一个测试用例分析**：
- 初始：洋红色=$1$，黄色=$1$，青色=$1$
- $\texttt{M}$：消耗 $1$ 洋红色 → (0,1,1)
- $\texttt{C}$：消耗 $1$ 青色 → (0,1,0)  
- $\texttt{Y}$：消耗 $1$ 黄色 → (0,0,0)
- 结果：$\texttt{YES 0 0 0}$

**第二个测试用例分析**：
- 初始：(3,2,1)
- 处理完所有像素后剩余：(1,0,0)
- 结果：$\texttt{YES 1 0 0}$

**第三个测试用例分析**：
- 初始：(1,1,1)
- $\texttt{R}$：需要 (1,1,0) → (0,0,1)
- $\texttt{V}$：需要 (1,0,1) → 洋红色不足
- 结果：$\texttt{NO}$

这个问题的解决方案直观且高效，通过简单的模拟即可得到正确结果。
