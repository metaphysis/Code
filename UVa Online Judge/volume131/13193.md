## 题目分析

本题是一个经典的**位运算**与**循环移位**问题。题意可以这样理解：

给定一个 $32$ 位无符号整数 $n$ ，将其二进制表示看作一个环（即最高位之后是最低位），从这个环中取出所有连续的 $5$ 位二进制串，一共可以得到 $32$ 个 $5$ 位串。每个 $5$ 位串对应一个 $0$ 到 $31$ 之间的整数。问：这 $32$ 个数是否恰好覆盖了 $0$ 到 $31$ 的所有整数？

例如题目中给出的 $8$ 位版本：数字 $226$ 的二进制是 $11100010$ ，取连续 $3$ 位得到的序列是 $2,1,0,4,6,7,3,5$ ，正好覆盖了 $0$ 到 $7$ 的所有数。

本题是 $32$ 位版本，取连续 $5$ 位。

## 解题思路

### 1. 问题转化

我们把问题形式化：

- 设 $n$ 的二进制位为 $b_{31}b_{30} \dots b_1b_0$ （$b_{31}$ 是最高位）。
- 对于每个起始位置 $i$ （$0 \le i \le 31$），取连续的 $5$ 位：$b_i b_{i+1} b_{i+2} b_{i+3} b_{i+4}$ （下标模 $32$，因为是循环的）。
- 将这 $5$ 位二进制数转换为十进制，得到 $val_i \in [0, 31]$。
- 要求 $\{val_0, val_1, \dots, val_{31}\} = \{0, 1, \dots, 31\}$。

### 2. 如何取连续 5 位

取连续 $5$ 位最直接的方法是循环移位。对于起始位置 $i$ ，如果我们把 $n$ **循环左移** $i$ 位，那么原本的 $b_i b_{i+1} b_{i+2} b_{i+3} b_{i+4}$ 就会变成新数的最低 $5$ 位。

循环左移 $i$ 位的实现方法：
- 将 $n$ 左移 $i$ 位，得到高位的部分；
- 将 $n$ 右移 $32-i$ 位，得到低位的部分（即原本的高位被移到了低位）；
- 将这两部分按位或，就得到了循环左移 $i$ 位的结果。

用公式表示：
$$
rotated = (n \ll i) \ | \ (n \gg (32 - i))
$$

注意：因为 $n$ 是 $32$ 位无符号整数，左移或右移超出 $32$ 位的部分会被自动丢弃，所以不需要额外处理。

### 3. 提取最低 $5$ 位

得到循环移位后的数后，只需要取最低 $5$ 位，即：
$$
val = rotated \ \& \ 0\text{x}1F
$$

其中 $0\text{x}1F$ 是 $31$ 的十六进制表示，二进制为 $11111$，按位与后正好保留低 $5$ 位。

### 4. 检查覆盖性

用一个布尔数组 $seen[32]$ 记录每个值是否出现过。

遍历 $i$ 从 $0$ 到 $31$：
- 计算 $val$
- 标记 $seen[val] = true$

遍历结束后，检查 $seen[0]$ 到 $seen[31]$ 是否全部为 $\text{true}$。若是，输出 `"yes"`，否则输出 `"no"`。

### 5. 复杂度分析

- 每个测试用例需要 $32$ 次循环移位和按位与操作。
- 时间复杂度 $O(32 \cdot t)$ ，对于 $t \le 3 \times 10^5$ 来说，运算次数约为 $10^7$ 次，完全可行。
- 空间复杂度 $O(1)$（只用了常数大小的数组）。

## 代码实现

```cpp

#include <bits/stdc++.h>
using namespace std;

// 判断 32 位无符号整数 n 能否通过连续 5 位生成 0~31 的所有数
string solve(uint32_t n) {
    bool seen[32] = {false};               // 标记每个数是否出现过
    for (int i = 0; i < 32; ++i) {
        // 循环左移 i 位，取低 5 位
        uint32_t rotated = (n << i) | (n >> (32 - i));
        uint32_t val = rotated & 0x1F;      // 取低 5 位
        seen[val] = true;
    }
    for (int i = 0; i < 32; ++i)
        if (!seen[i]) return "no";
    return "yes";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        uint32_t n;
        cin >> n;
        cout << solve(n) << '\n';
    }
    return 0;
}
```

## 总结

本题的核心在于**循环移位**和**掩码操作**。通过将问题转化为循环移位的视角，可以很自然地用位运算高效求解。这也是位运算题目中常见的技巧：利用循环移位把任意位置的连续位段统一到最低位处理，再通过掩码提取目标位数。

另外，本题的输入规模较大，使用 `ios::sync\_with\_stdio(false)` 和 `cin.tie(nullptr)` 加速输入输出是必要的。
