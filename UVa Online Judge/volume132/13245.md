## 题目描述

有一种特殊的飞镖盘，拥有 $n$ 个分区。其中第一个分区值为 $1$ 分，剩下的 $n - 1$ 个分区分别对应前 $n - 1$ 个质数。对于每个测试用例，给定 $n$ 和 $q$，问用该飞镖盘恰好得到 $q$ 分所需的最少飞镖数（每个分区可以被重复投中）。

## 题目分析

这是一个典型的**完全背包**问题，目标是求**恰好装满背包**且**物品数量最少**的方案。

### 关键点分析

1. **物品集合**  
   当飞镖盘大小为 $n$ 时，可用的分数值为：
   - $1$（第一个分区）
   - 前 $n - 1$ 个质数（剩下的分区）

   注意：$n \leq 100$，所以最多需要前 $99$ 个质数。第 $99$ 个质数约为 $541$，远小于 $q \leq 5000$，因此背包容量 $q$ 可以覆盖所有可能情况。

2. **无限使用**  
   每个分数值可以被反复投中，因此是无限制数量的完全背包问题。

3. **目标**  
   不是求最大价值，而是求**最少物品数量**。这可以通过将“价值”定义为 $1$，然后求最小值来实现。

4. **有解性保证**  
   由于 $1$ 分一定存在（第一个分区），所以任何 $q$ 都可以通过全投 $1$ 分区得到 $q$ 个飞镖。因此一定有解，我们只需要找最优解。

## 解题思路

### 步骤 1：预处理质数

由于 $n \leq 100$，最多需要前 $99$ 个质数。我们可以预先用筛法或简单判断生成前 $100$ 个质数（多生成一个以防万一）。

生成方式：从 $2$ 开始依次检查每个数是否为质数，直到收集到足够数量的质数。

### 步骤 2：对每个测试用例构造分数列表

对于给定的 $n$，构造一个 $\texttt{scores}$ 数组：
- 第一个元素为 $1$
- 随后添加前 $n - 1$ 个质数

### 步骤 3：完全背包求最少个数

定义：
- $dp[v]$ 表示恰好凑出 $v$ 分所需的最少飞镖数
- 初始化 $dp[0] = 0$，$dp[1..q] = \infty$（用一个足够大的数表示不可达）
- 转移方程：
  \[
  dp[v] = \min(dp[v],\; dp[v - s] + 1) \quad \text{对于每个分数 } s \text{ 和每个 } v \ge s
  \]

由于是完全背包，我们从小到大遍历 $v$，这样可以重复使用同一分数。

### 步骤 4：输出答案

直接输出 $dp[q]$ 即可。

### 时间复杂度

- 生成质数：$O(\text{maxPrime}^2)$ 但这里 maxPrime 很小，可忽略
- 每个测试用例：$O(n \cdot q)$，其中 $n \leq 100$，$q \leq 5000$，最坏情况 $5 \times 10^5$，在 $t$ 不大时完全可行

## 代码实现

```cpp
// Prime Darts
// UVa ID: 13245
// Verdict: Accepted
// Submission Date: 2026-04-17
// UVa Run Time: 0.000s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 生成前 maxCount 个质数
vector<int> generatePrimes(int maxCount) {
    vector<int> primes;
    for (int num = 2; primes.size() < maxCount; ++num) {
        bool isPrime = true;
        for (int p : primes) {
            if (p * p > num) break;
            if (num % p == 0) { isPrime = false; break; }
        }
        if (isPrime) primes.push_back(num);
    }
    return primes;
}

int main() {
    vector<int> primes = generatePrimes(100); // 最多需要前 99 个质数
    int t;
    cin >> t;
    while (t--) {
        int n, q;
        cin >> n >> q;
        
        // 构造分数面值列表
        vector<int> scores;
        scores.push_back(1);
        for (int i = 0; i < n - 1; ++i) scores.push_back(primes[i]);
        
        const int INF = 1e9;
        vector<int> dp(q + 1, INF);
        dp[0] = 0;
        
        // 完全背包，求最少个数
        for (int score : scores)
            for (int v = score; v <= q; ++v)
                if (dp[v - score] != INF)
                    dp[v] = min(dp[v], dp[v - score] + 1);
        
        cout << dp[q] << endl;
    }
    return 0;
}
```

## 总结

本题的关键在于识别出“无限物品、恰好装满、最少数量”的完全背包模型。预处理质数后，每个测试用例独立进行一次动态规划即可。由于 $1$ 分的存在，解总是存在的，不需要额外判断无解情况。
