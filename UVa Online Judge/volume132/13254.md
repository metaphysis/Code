# 题目描述

水族箱为以原点为圆心的圆形区域，计算机视觉系统记录了每条鱼的坐标和类型。鱼的类型只有 $\texttt{A}$ 和 $\texttt{B}$ 两种。

需要判断是否存在一块从水族箱边缘延伸到另一侧边缘、从水面延伸到水底的平面玻璃板，使得：

- 所有 $\texttt{A}$ 类型的鱼位于玻璃板的一侧；
- 所有 $\texttt{B}$ 类型的鱼位于玻璃板的另一侧；
- 玻璃板不接触任何鱼。

在二维俯视图中，玻璃板对应一条直线。因此，问题转化为判断是否存在一条不经过任何鱼的直线，将两种类型的鱼严格分开。

# 输入格式

输入包含多组测试数据。

每组测试数据的第一行包含两个整数 $n$ 和 $r$：

- $n$ 表示鱼的总数，满足 $2 \le n \le 500$；
- $r$ 表示水族箱半径，满足 $0 < r \le 10^4$。

接下来有 $n$ 行，每行包含两个整数 $x_i$、$y_i$ 和一个字符 $t_i$：

- $(x_i, y_i)$ 表示第 $i$ 条鱼的坐标；
- $t_i$ 表示鱼的类型，取值为 $\texttt{A}$ 或 $\texttt{B}$。

所有鱼的坐标互不相同，并且满足鱼位于水族箱内部。每组数据中至少存在一条 $\texttt{A}$ 类型的鱼和一条 $\texttt{B}$ 类型的鱼。

当一行输入为 $0\ 0$ 时，输入结束。

# 输出格式

对于每组测试数据：

- 如果存在一条玻璃板能够将两种鱼完全分开，输出 `FEED`；
- 否则输出 `NOT YET`。

# 题目分析

玻璃板在俯视图中是一条直线。要求玻璃板不接触任何鱼，因此所有鱼必须严格位于直线的两侧，不能有鱼落在直线上。

直接枚举所有可能的直线并判断不可行，因为鱼的坐标范围较大，可能的直线数量是无限的。需要将问题转换为几何上的凸集分离问题。

对于同一种类型的所有鱼，如果存在一条直线将两种类型严格分开，那么同一类型鱼的凸包也必须整体位于直线的一侧。原因是凸包中的每个点都是原始鱼的凸组合，若所有原始鱼位于直线的一侧，则它们的凸包也位于该侧。

因此，设所有 $\texttt{A}$ 类型鱼的凸包为 $H_A$，所有 $\texttt{B}$ 类型鱼的凸包为 $H_B$：

- 如果 $H_A$ 和 $H_B$ 有公共点，则两种鱼不能被严格分开；
- 如果 $H_A$ 和 $H_B$ 没有公共点，则两个凸集可以被一条直线严格分离。

这正是平面凸集的严格分离性质。于是，原问题等价于判断两类鱼的凸包是否相交或接触。

需要特别处理凸包退化的情况：

- 同一类只有一条鱼时，凸包是一个点；
- 同一类的所有鱼共线时，凸包是一条线段；
- 普通情况下，凸包是一个多边形。

程序统一使用点、线段和多边形的边界相交判断，并额外判断一个凸包的顶点是否位于另一个凸包内部或边界上。

# 解题思路

## 求两类鱼的凸包

分别收集两种类型鱼的坐标，对每一类点使用单调链算法构造凸包。

先按照横坐标、纵坐标的字典序排序，然后依次构造：

- 下凸壳；
- 上凸壳。

在构造过程中，如果新加入的点使末尾三个点不构成逆时针转向，则删除凸壳末尾点。使用小于等于零的叉积可以去除共线的中间点，使最终凸包只保留端点。

叉积定义为：

$$
cross(A,B,C) = (B_x-A_x)(C_y-A_y) - (B_y-A_y)(C_x-A_x)
$$

当 $cross(A,B,C)$：

- 大于 $0$ 时，点 $C$ 位于有向边 $AB$ 的左侧；
- 小于 $0$ 时，点 $C$ 位于有向边 $AB$ 的右侧；
- 等于 $0$ 时，三点共线。

凸包构造完成后，退化凸包也能被正确表示。

## 判断线段是否相交

对于两条线段 $AB$ 和 $CD$，分别计算：

$$
cross(A,B,C),\quad cross(A,B,D)
$$

以及：

$$
cross(C,D,A),\quad cross(C,D,B)
$$

如果两个端点分别位于另一条线段的两侧，则两条线段严格相交。若存在三点共线，还需要使用坐标范围判断点是否在线段上，从而处理端点接触和共线重叠的情况。

题目要求玻璃板不能接触任何鱼，因此凸包之间的接触也必须判定为相交。

## 判断点是否位于凸包内部或边界

对于一个点和一个凸包：

- 如果凸包只有一个点，直接判断坐标是否相同；
- 如果凸包是线段，判断该点是否在线段上；
- 如果凸包是多边形，计算该点相对于每条边的叉积。

对于按逆时针顺序排列的凸多边形，点在内部或边界上，当且仅当它不会同时出现在某些边的左侧和另一些边的右侧。

程序使用两个布尔变量记录是否出现正叉积和负叉积：

- 同时出现正、负叉积，说明点在多边形外部；
- 只出现一种符号或出现零，说明点在多边形内部或边界上。

## 判断两个凸包是否相交

首先枚举两个凸包的所有边，判断是否存在相交的边。

如果边界没有相交，还需要判断包含关系：

- 枚举第一个凸包的顶点，判断其是否在第二个凸包内部或边界上；
- 枚举第二个凸包的顶点，判断其是否在第一个凸包内部或边界上。

只要满足任意一种情况，就说明两个凸包相交或接触，输出 `NOT YET`。否则两个凸包严格分离，输出 `FEED`。

## 复杂度分析

设鱼的总数为 $n$。

- 排序并构造两类凸包的时间复杂度为 $O(n\log n)$；
- 枚举两个凸包的边进行相交判断，最坏时间复杂度为 $O(n^2)$；
- 点在凸包内的判断不会超过 $O(n^2)$ 的总复杂度。

因此，总时间复杂度为：

$$
O(n\log n+n^2)=O(n^2)
$$

凸包存储和辅助数组需要 $O(n)$ 的空间，因此空间复杂度为：

$$
O(n)
$$

# 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

struct Point {
    ll x, y;
    bool operator < (const Point &p) const {
        if (x != p.x) return x < p.x;
        return y < p.y;
    }
    bool operator == (const Point &p) const {
        return x == p.x && y == p.y;
    }
};

ll cross(const Point &a, const Point &b, const Point &c) {
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
}

bool onSeg(const Point &a, const Point &b, const Point &p) {
    if (cross(a, b, p) != 0) return false;
    return min(a.x, b.x) <= p.x && p.x <= max(a.x, b.x) &&
           min(a.y, b.y) <= p.y && p.y <= max(a.y, b.y);
}

bool segHit(const Point &a, const Point &b, const Point &c, const Point &d) {
    ll c1 = cross(a, b, c), c2 = cross(a, b, d);
    ll c3 = cross(c, d, a), c4 = cross(c, d, b);
    if (c1 == 0 && onSeg(a, b, c)) return true;
    if (c2 == 0 && onSeg(a, b, d)) return true;
    if (c3 == 0 && onSeg(c, d, a)) return true;
    if (c4 == 0 && onSeg(c, d, b)) return true;
    return ((c1 > 0) != (c2 > 0)) && ((c3 > 0) != (c4 > 0));
}

vector<Point> getHull(vector<Point> p) {
    sort(p.begin(), p.end());
    p.erase(unique(p.begin(), p.end()), p.end());
    if (p.size() <= 1) return p;
    vector<Point> low, up;
    for (const Point &q : p) {
        while (low.size() >= 2 && cross(low[low.size() - 2], low.back(), q) <= 0) low.pop_back();
        low.push_back(q);
    }
    for (int i = (int)p.size() - 1; i >= 0; i--) {
        while (up.size() >= 2 && cross(up[up.size() - 2], up.back(), p[i]) <= 0) up.pop_back();
        up.push_back(p[i]);
    }
    low.pop_back();
    up.pop_back();
    low.insert(low.end(), up.begin(), up.end());
    return low;
}

bool inHull(const vector<Point> &h, const Point &p) {
    if (h.size() == 1) return h[0] == p;
    if (h.size() == 2) return onSeg(h[0], h[1], p);
    bool pos = false, neg = false;
    for (int i = 0; i < (int)h.size(); i++) {
        ll v = cross(h[i], h[(i + 1) % h.size()], p);
        if (v > 0) pos = true;
        if (v < 0) neg = true;
    }
    return !(pos && neg);
}

bool hullHit(const vector<Point> &a, const vector<Point> &b) {
    int ea = a.size() == 2 ? 1 : (int)a.size(), eb = b.size() == 2 ? 1 : (int)b.size();
    for (int i = 0; i < ea; i++) {
        Point a1 = a[i], a2 = a[(i + 1) % a.size()];
        for (int j = 0; j < eb; j++) {
            Point b1 = b[j], b2 = b[(j + 1) % b.size()];
            if (segHit(a1, a2, b1, b2)) return true;
        }
    }
    for (const Point &p : a)
        if (inHull(b, p)) return true;
    for (const Point &p : b)
        if (inHull(a, p)) return true;
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    ll r;
    while (cin >> n >> r && (n || r)) {
        vector<Point> a, b;
        for (int i = 0; i < n; i++) {
            Point p;
            char t;
            cin >> p.x >> p.y >> t;
            if (t == 'A') a.push_back(p);
            else b.push_back(p);
        }
        vector<Point> ha = getHull(a), hb = getHull(b);
        cout << (hullHit(ha, hb) ? "NOT YET" : "FEED") << '\n';
    }
    return 0;
}
```

# 总结

本题的核心是将“是否存在一条直线严格分隔两类点”转化为“两个点集的凸包是否相交”。

关键结论如下：

- 同一类型的所有点可以用凸包表示；
- 两类点能够被直线严格分开，当且仅当两类点的凸包不相交；
- 凸包可能退化为点或线段，必须单独处理；
- 判断凸包相交不仅要检查边界相交，还要检查一个凸包是否包含另一个凸包的顶点；
- 使用叉积可以统一完成转向判断、线段相交判断和点在凸包内判断。

该方法充分利用了凸包的几何性质，在 $n \le 500$ 的数据范围内能够稳定完成所有测试数据的处理。
