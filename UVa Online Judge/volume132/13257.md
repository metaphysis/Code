## 题目描述

Antonia 和她的妈妈 Maria 过去常常在开车去高中的路上，通过其他车辆的车牌来互相挑战。在她们的国家，车牌上总是包含恰好三个字母的字符串。挑战的目标是说出一个最长的单词，该单词以子序列的形式包含车牌上的字母串。

例如，如果车牌包含字符串 $\texttt{"OMI"}$ ，那么 $\texttt{"PROGRAMMING"}$ 和 $\texttt{"COLOMBIA"}$ 都可以作为挑战的答案。但前者更受青睐，因为它更长。

现在 $\texttt{Antonia}$ 是一名计算机科学专业的学生，$\texttt{Maria}$ 希望做出一些改变，让挑战对她女儿来说仍然有趣。在新版本的挑战中，$\texttt{Maria}$ 写下一个单词 $S$ ，$\texttt{Antonia}$ 必须计算有多少个不同的三字母字符串，每个字符串都是 $S$ 的子序列。

你需要编写一个程序，帮助 $\texttt{Maria}$ 提前计算新版本挑战的输出。

### 输入格式

第一行包含 $T$（ $T \geq 0$ ），表示测试用例的数量。  
每个测试用例由一行组成，包含一个字符串 $S$（ $1 \leq |S| \leq 10^5$ ）。  
可以假设 $S$ 仅由大写英文字母组成（即 $\texttt{'A'}$ 到 $\texttt{'Z'}$ ），并且测试用例之间没有空行。

### 输出格式

对于每个测试用例，输出一行，表示不同的三字母字符串（每个都是 $S$ 的子序列）的数量。

### 样例输入

```
5
PROGRAMMING
COLOMBIA
NUEVE
AAAAAAA
PQ
```

### 样例输出

```
110
46
9
1
0
```

## 题目分析

我们需要计算字符串 $S$ 中所有不同的长度为 $3$ 的子序列的数量。  
**子序列** 不需要连续，但必须保持原始顺序。  
**不同** 指的是不同的三字母组合，例如 $\texttt{"ABC"}$ 和 $\texttt{"ABD"}$ 是不同的。

### 关键约束

- $|S| \leq 10^5$ ，因此暴力枚举所有可能的三字母子序列（时间复杂度 $O(n^3)$ ）不可行。
- 字母表大小为 $26$（大写英文字母）。
- 我们需要高效算法，理想时间复杂度为 $O(n \cdot 26^2)$ 或 $O(n)$ 。

### 解题思路

我们可以使用动态规划（DP）来逐步构建长度为 $1$ 、 $2$ 和 $3$ 的子序列，并确保计数不重复。

#### 状态定义

设：

- $dp1[i]$ 表示以字母 $i$ 结尾的长度为 $1$ 的不同子序列数量（实际上只能是 $0$ 或 $1$ ，因为每个字母作为长度为 $1$ 的子序列只计一次）。
- $dp2[i][j]$ 表示以字母 $i$ 和 $j$ 结尾的长度为 $2$ 的不同子序列数量。
- $dp3[i][j][k]$ 表示以字母 $i$ 、 $j$ 和 $k$ 结尾的长度为 $3$ 的不同子序列数量。

#### 状态转移

遍历字符串 $S$ 中的每个字符 $ch$ ，将其转换为索引 $c$（ $0$ 到 $25$ ）。

对于当前字符 $c$ ：

1. **更新长度为 $3$ 的子序列**  
   对于所有可能的 $(a, b)$（ $0 \leq a, b < 26$ ），如果 $dp2[a][b] > 0$ ，则说明存在以 $(a, b)$ 结尾的长度为 $2$ 的子序列。此时，在这些子序列后面添加字符 $c$ ，就形成了以 $(a, b, c)$ 结尾的长度为 $3$ 的子序列。因此：
   $$
   dp3[a][b][c] \text{ += } dp2[a][b]
   $$
   注意：这里 $dp2[a][b]$ 已经保证了不同的子序列，所以直接累加即可。

2. **更新长度为 $2$ 的子序列**  
   对于所有可能的 $a$（ $0 \leq a < 26$ ），如果 $dp1[a] > 0$ ，则说明存在以 $a$ 结尾的长度为 $1$ 的子序列。在这些子序列后面添加字符 $c$ ，就形成了以 $(a, c)$ 结尾的长度为 $2$ 的子序列。因此：
   $$
   dp2[a][c] \text{ += } dp1[a]
   $$

3. **更新长度为 $1$ 的子序列**  
   字符 $c$ 本身就是一个长度为 $1$ 的子序列。由于我们只关心是否出现过，所以：
   $$
   dp1[c] = 1
   $$

**注意**：更新顺序必须从长到短，即先更新 $dp3$ ，再更新 $dp2$ ，最后更新 $dp1$ 。这样可以避免同一个字符在同一轮中被重复使用。

#### 最终答案

遍历所有 $(a, b, c)$ 组合（ $0 \leq a, b, c < 26$ ），如果 $dp3[a][b][c] > 0$ ，则说明至少存在一个以 $(a, b, c)$ 结尾的长度为 $3$ 的子序列。因此，答案就是 $dp3$ 中非零项的个数。

### 时间复杂度

- 每个字符需要更新 $dp3$ 和 $dp2$ ，每个更新需要遍历 $26^2$ 种组合。
- 总时间复杂度为 $O(n \cdot 26^2)$ ，在 $n \leq 10^5$ 时可行（约 $6.76 \times 10^7$ 次操作）。
- 空间复杂度为 $O(26^3) = 17576$ ，可以接受。

## 代码实现

```cpp
// License Plates
// UVa ID: 13257
// Verdict: Accepted
// Submission Date: 2025-12-13
// UVa Run Time: 0.910s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    while (T--) {
        string S;
        cin >> S;
        
        // dp1[i]: 以字母 i 结尾的长度为 1 的子序列数量（实际上只有 0 或 1）
        int dp1[26] = {0};
        // dp2[i][j]: 以字母 i,j 结尾的长度为 2 的子序列数量
        long long dp2[26][26] = {0};
        // dp3[i][j][k]: 以字母 i,j,k 结尾的长度为 3 的子序列数量
        long long dp3[26][26][26] = {0};
        
        for (char ch : S) {
            int c = ch - 'A';
            
            // 更新长度为 3 的子序列
            for (int a = 0; a < 26; ++a) {
                for (int b = 0; b < 26; ++b) {
                    if (dp2[a][b] > 0) {
                        dp3[a][b][c] += dp2[a][b];
                    }
                }
            }
            
            // 更新长度为 2 的子序列
            for (int a = 0; a < 26; ++a) {
                if (dp1[a] > 0) {
                    dp2[a][c] += dp1[a];
                }
            }
            
            // 更新长度为 1 的子序列
            dp1[c] = 1;
        }
        
        // 统计所有不同的长度为 3 的子序列数量
        long long ans = 0;
        for (int a = 0; a < 26; ++a) {
            for (int b = 0; b < 26; ++b) {
                for (int c = 0; c < 26; ++c) {
                    if (dp3[a][b][c] > 0) {
                        ans += 1; // 每个不同的三字母组合只计一次
                    }
                }
            }
        }
        
        cout << ans << "\n";
    }
    
    return 0;
}
```

## 代码说明

1. **初始化**： $dp1$ 、 $dp2$ 和 $dp3$ 全部初始化为 $0$ 。
2. **遍历字符串**：对于每个字符，依次更新 $dp3$ 、 $dp2$ 和 $dp1$ 。
3. **统计答案**：遍历 $dp3$ 数组，统计非零项的个数。
4. **注意事项**：
   - 使用 `long long` 类型存储 $dp2$ 和 $dp3$ ，因为计数可能很大（最坏情况下可达组合数级别）。
   - 使用 `ios::sync_with_stdio(false)` 和 `cin.tie(nullptr)` 加速输入输出。

## 总结

本题的关键在于通过动态规划逐步构建不同长度的子序列，并利用计数避免重复。通过维护长度为 $1$ 、 $2$ 和 $3$ 的子序列计数，我们可以在 $O(n \cdot 26^2)$ 时间内解决问题，满足题目的大数据量要求。

这种方法不仅高效，而且易于理解和实现，是处理子序列计数问题的典型技巧。
