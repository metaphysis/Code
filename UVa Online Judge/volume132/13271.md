## 题目描述

蚂蚁需要穿过一个由砖块构成的墙壁寻找食物。为了安全，它们必须始终在砖块之间的"山谷"（缝隙）中行进。砖墙的排列遵循特定规则：

- 每个砖块是一个矩形，水平方向长 $2$ 个单位，垂直方向长 $1$ 个单位
- 砖块按照规则网格图案排列，砖块之间有微小的缝隙（山谷）
- 蚂蚁的起点和终点都是山谷中的点，可以用整数坐标表示

给定起点坐标 $(S_r, S_c)$ 和终点坐标 $(D_r, D_c)$，需要找到两点之间的最短路径距离。

**输入格式**：最多 $1000$ 个测试用例，每个用例包含四个整数 $S_r, S_c, D_r, D_c$，最后以 `0 0 0 0` 结束。

**输出格式**：对于每个测试用例，输出最短路径距离。

## 题目分析

### 砖墙结构理解

通过分析题目描述和图示，我们可以理解砖墙的特殊结构：

1. **砖块尺寸**：每个砖块占据 $2 \times 1$ 的空间（宽×高）
2. **山谷类型**：
   - **水平山谷**（横向缝隙）：位于同行相邻砖块之间
   - **纵向山谷**（垂直缝隙）：位于相邻行砖块之间
3. **移动限制**：由于砖块的交替排列，某些位置之间的直接移动受到限制

### 关键观察

经过对 $\texttt{AC}$ 代码的分析，我们发现问题的核心在于处理砖墙的特殊连通性：

1. **同一行移动**：可以直接横向移动，距离为列差的绝对值
2. **简单对角线移动**：当行差 $\leq$ 列差时，可以直接走曼哈顿距离
3. **复杂蛇形移动**：当行差 $>$ 列差时，由于垂直移动的限制，需要采用蛇形移动策略

### 解题思路

算法采用分情况处理的策略：

#### 情况 1：同一行
如果起点和终点在同一行，直接返回列差的绝对值：
$$ \texttt{distance} = |S_c - D_c| $$

#### 情况 2：标准化位置
通过递归调用确保：
- $S_r \leq D_r$（起始行不大于目标行）
- $S_c \leq D_c$（起始列不大于目标列）

#### 情况 3：曼哈顿距离适用
当行差 $\leq$ 列差时：
$$ \texttt{distance} = (D_r - S_r) + (D_c - S_c) $$

#### 情况 4：蛇形移动（核心难点）
当行差 $>$ 列差时，算法分为三个步骤：

1. **水平对齐**：先在水平方向移动到目标列，同时向下移动相应的行数
   $$ \texttt{startRow} = S_r + (D_c - S_c) $$
   $$ \texttt{distance} = 2 \times (D_c - S_c) $$

2. **奇偶性调整**：检查当前行与目标行的奇偶性
   - 如果奇偶性不同，需要额外绕行
   - 绕行代价取决于当前位置的奇偶性组合

3. **垂直移动**：剩余的行差通过蛇形移动完成
   $$ \texttt{distance} += 2 \times (D_r - \texttt{startRow}) $$

### 算法正确性证明

该算法的正确性基于对砖墙连通性的深入理解：

1. **同一行连通性**：水平山谷确保同行任意两点可达
2. **对角线移动**：当列差足够大时，可以找到合适的垂直通道
3. **蛇形移动必要性**：当垂直移动受限时，通过水平往返来"绕过"障碍

### 复杂度分析

- **时间复杂度**：$O(1)$ 每个测试用例，只有常数次操作
- **空间复杂度**：$O(1)$，只使用固定数量的变量

```cpp
// Brick Wall

#include <bits/stdc++.h>
using namespace std;

/**
 * 计算两个山谷点之间的最短路径距离
 * @param startRow 起始行号
 * @param startCol 起始列号  
 * @param endRow 目标行号
 * @param endCol 目标列号
 * @return 最短路径距离
 */
int64_t calculateDistance(int64_t startRow, int64_t startCol, int64_t endRow, int64_t endCol) {
    // 情况1：同一行，直接返回列差的绝对值（可以水平移动）
    if (startRow == endRow) return abs(startCol - endCol);
    
    // 情况2：保证起始行号小于目标行号，方便后续处理
    if (startRow > endRow) return calculateDistance(endRow, endCol, startRow, startCol);
    
    // 情况3：保证起始列号小于目标列号，通过对称变换
    if (startCol > endCol) return calculateDistance(startRow, startCol, endRow, startCol + (startCol - endCol));
    
    // 计算行差和列差（此时startRow <= endRow, startCol <= endCol）
    int64_t rowDiff = endRow - startRow;
    int64_t colDiff = endCol - startCol;
    
    // 情况4：行差小于等于列差，可以直接走曼哈顿距离
    // 因为水平移动相对自由，当列差较大时可以直接到达
    if (rowDiff <= colDiff) return rowDiff + colDiff;
    
    // 情况5：复杂情况 - 行差大于列差，需要蛇形移动
    // 由于砖墙的特殊结构，垂直移动受到限制
    
    // 步骤1：先在水平方向移动到目标列
    startRow += colDiff;  // 同时向下移动colDiff行
    int64_t distance = colDiff * 2;  // 水平移动colDiff，垂直移动colDiff
    
    // 步骤2：检查当前行与目标行的奇偶性是否相同
    // 砖墙结构导致不同奇偶性的行之间移动受限
    if (startRow % 2 != endRow % 2) {
        // 行奇偶性不同，需要额外绕行
        // 根据当前位置的奇偶性决定绕行代价
        if ((startRow + endCol) % 2) {
            distance += 3;  // 需要3步绕行
        } else {
            distance += 1;  // 需要1步绕行
        }
        startRow++;  // 移动到下一行
    }
    
    // 步骤3：剩余的行差通过蛇形移动完成
    // 每向下移动一行需要2步（上下往返）
    distance += (endRow - startRow) * 2;
    
    return distance;
}

int main() {
    int64_t startRow, startCol, endRow, endCol;
    
    // 读取测试用例，直到遇到 0 0 0 0
    while (scanf("%lld %lld %lld %lld", &startRow, &startCol, &endRow, &endCol) == 4 && startRow) {
        printf("%lld\n", calculateDistance(startRow, startCol, endRow, endCol));
    }
    
    return 0;
}
```

## 总结

本题的关键在于理解砖墙的特殊连通性模式，并设计相应的移动策略。算法通过巧妙的分类讨论，将复杂的三维连通性问题转化为可计算的数学表达式，展现了优秀的算法设计思维。

这种分情况处理的思路在解决类似的网格路径问题时非常有效，特别是当移动规则具有周期性或模式性时。
