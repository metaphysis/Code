## 题目描述

给定一个包含四种括号类型的序列 $B$：
- 圆括号：`(` 和 `)`
- 花括号：`{` 和 `}`
- 方括号：`[` 和 `]`
- 尖括号：`<` 和 `>`

对于序列中的每个位置，需要输出从该位置开始（包含该位置）的最长**平衡**连续括号序列的长度。

### 平衡括号序列的定义

一个括号序列 $T$ 是平衡的当且仅当满足以下条件之一：
- $T$ 是空序列
- $T$ 是 $(P)$、$[P]$、$\{P\}$ 或 $<P>$，其中 $P$ 是平衡括号序列
- $T$ 是 $PQ$，其中 $P$ 和 $Q$ 都是平衡括号序列

### 输入输出格式

**输入：**
- 第一行：测试用例数 $T$ ($T \leq 10$)
- 接下来 $T$ 行：每行一个非空括号序列，长度不超过 $10^5$

**输出：**
- 对于每个测试用例，先输出 `Case x:`，然后在单独行中依次输出每个位置的结果

### 样例

**输入：**
```
5
()
<>>
(<>)<<
()()
{[]}
```

**输出：**
```
Case 1:
2
0
Case 2:
2
0
Case 3:
4
2
0
0
0
Case 4:
4
0
2
0
Case 5:
0
0
0
0
```

## 题目分析

### 问题本质

这个问题要求我们为序列中的**每个起始位置**计算最长平衡子串的长度。与传统的判断整个序列是否平衡不同，这里需要计算所有可能的起始位置。

### 关键观察

1. **右括号不能作为平衡序列的开头**：任何以右括号开始的子串都不可能是平衡的
2. **嵌套结构**：平衡序列可能包含多层嵌套的括号对
3. **连续平衡序列**：多个平衡序列可以连接在一起形成更长的平衡序列

### 解题思路

#### 核心思想：动态规划 + 栈思想

我们使用动态规划的方法，从右向左处理字符串，利用已经计算的结果来推导前面的结果。

#### 算法设计

定义状态：
- $dp[i]$：表示从位置 $i$ 开始的最长平衡括号序列的长度

状态转移：
1. 如果 $s[i]$ 是右括号，则 $dp[i] = 0$（右括号不能作为开头）
2. 如果 $s[i]$ 是左括号：
   - 计算中间部分的长度：$midLen = dp[i+1]$
   - 计算匹配位置：$j = i + 1 + midLen$
   - 如果 $j < n$ 且 $s[i]$ 与 $s[j]$ 匹配，则：
     $$dp[i] = 2 + midLen + dp[j+1]$$
   - 否则：$dp[i] = 0$

#### 为什么这样设计？

考虑序列：`"(()())"`
- 对于位置 $0$ 的 `'('`：
  - 中间部分 `"()"` 的长度 $dp[1] = 2$
  - 匹配位置 $j = 0 + 1 + 2 = 3$（第二个 `'('`）
  - 但 `'('` 与 `')'` 不匹配？等等，这里需要仔细分析

实际上，我们的算法是这样工作的：
对于 `"(<>)<<"`：
- 从右向左处理
- 遇到 `'<'` 时，检查后面是否能形成平衡序列

## 算法详细步骤

### 步骤分解

1. **初始化**：创建 $dp$ 数组，长度为 $n+1$，初始化为 $0$
2. **从右向左遍历**：$i$ 从 $n-1$ 到 $0$
3. **处理每个字符**：
   - 如果是右括号：$dp[i] = 0$
   - 如果是左括号：
     - 计算跳过中间平衡部分后的位置：$j = i + 1 + dp[i+1]$
     - 如果 $j$ 在范围内且括号匹配：$dp[i] = 2 + dp[i+1] + dp[j+1]$
     - 否则：$dp[i] = 0$
4. **输出结果**：按顺序输出 $dp[0]$ 到 $dp[n-1]$

### 时间复杂度分析

- **时间复杂度**：$O(n)$，每个位置只被处理一次
- **空间复杂度**：$O(n)$，用于存储 $dp$ 数组

### 正确性证明

该算法的正确性基于以下观察：
1. 平衡序列必须由匹配的括号对组成
2. 如果从位置 $i$ 开始是左括号，且能与位置 $j$ 的右括号匹配，那么：
   - 中间部分 $[i+1, j-1]$ 必须是平衡的
   - 匹配之后的部分 $[j+1, ...]$ 如果也是平衡的，可以连接起来

## 代码实现

```cpp
// Bracket Sequence
// UVa ID: 13272
// Verdict: Accepted
// Submission Date: 2025-11-29
// UVa Run Time: 0.020s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

// 检查两个字符是否匹配
bool isMatch(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}') ||
           (left == '<' && right == '>');
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int t;
    cin >> t;
    cin.ignore(); // 忽略换行符
    
    for (int caseNum = 1; caseNum <= t; caseNum++) {
        string s;
        getline(cin, s);
        int n = s.length();
        
        vector<int> dp(n + 1, 0); // dp[i]表示从位置i开始的最长平衡序列长度
        
        // 从右向左处理
        for (int i = n - 1; i >= 0; i--) {
            // 如果是右括号，不能作为平衡序列的开头
            if (s[i] == ')' || s[i] == ']' || s[i] == '}' || s[i] == '>') {
                dp[i] = 0;
                continue;
            }
            
            // 对于左括号，检查是否能匹配
            int j = i + 1 + dp[i + 1]; // 跳过中间平衡部分后的位置
            
            if (j < n && isMatch(s[i], s[j])) {
                // 当前匹配的2个字符 + 中间部分 + 匹配后的部分
                dp[i] = 2 + dp[i + 1] + dp[j + 1];
            } else {
                dp[i] = 0;
            }
        }
        
        // 输出结果
        cout << "Case " << caseNum << ":\n";
        for (int i = 0; i < n; i++) {
            cout << dp[i] << "\n";
        }
    }
    
    return 0;
}
```

## 总结

本题通过巧妙的动态规划设计，实现了对每个起始位置最长平衡子串的高效计算。算法的核心在于从右向左处理，利用已计算的结果，避免了重复计算。这种方法的时间复杂度为 $O(n)$，能够处理长度达到 $10^5$ 的大型输入，是一个既高效又优雅的解决方案。
