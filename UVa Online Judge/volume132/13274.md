## 题目描述

圣诞节快到了，$\texttt{Bob}$ 想装饰他的圣诞树。这棵树有 $N$ 个节点，其中节点 $1$ 是根节点。他认为一棵树是漂亮的，当且仅当每个非叶子节点恰好有 $K$ 个子节点（直接子节点）。他希望通过删除零个或多个节点来满足这个性质。如果删除一个非叶子节点，那么以该节点为根的整个子树都会被移除。问在删除一些（可能为零）节点后，树最多能保留多少个节点？

**输入格式：**
- 第一行包含 $T$（测试用例数，$1 \leq T \leq 1000$）
- 每个测试用例的第一行包含两个整数 $N$（$1 \leq N \leq 1000$）和 $K$（$1 \leq K \leq 100$）
- 接下来 $N-1$ 行，每行两个整数 $U, V$，表示一条边

**输出格式：**
- 对每个测试用例，输出 `Case X: Y`，其中 `X` 是测试用例编号，`Y` 是答案

## 题目分析

这个问题要求我们通过删除节点来构造一棵满足特定条件的树，使得每个非叶子节点恰好有 $K$ 个子节点，同时最大化剩余节点的数量。

### 关键观察

1. **删除规则**：删除非叶子节点会删除整个子树，这意味着我们的删除操作是"全有或全无"的
2. **约束条件**：每个非叶子节点必须有恰好 $K$ 个子节点
3. **优化目标**：最大化剩余节点数

### 解题思路

这个问题可以通过树形动态规划（$\texttt{Tree DP}$）来解决。基本思想是从叶子节点开始向上处理，为每个节点计算在其子树中满足条件时能保留的最大节点数。

#### 动态规划状态定义

定义 $dp[u]$ 表示以节点 $u$ 为根的子树中，在满足"每个非叶子节点恰好有 $K$ 个子节点"的条件下，最多能保留的节点数。

#### 状态转移

1. **叶子节点**：如果 $u$ 是叶子节点，那么 $dp[u] = 1$（叶子节点总是可以保留）

2. **非叶子节点**：
   - 收集所有子节点的 $dp$ 值
   - 如果子节点数量少于 $K$，那么 $u$ 不能成为非叶子节点（因为无法满足恰好 $K$ 个子节点的要求），此时 $u$ 只能作为叶子节点保留，所以 $dp[u] = 1$
   - 如果子节点数量大于等于 $K$，那么选择 $dp$ 值最大的 $K$ 个子节点，$dp[u] = 1 + \sum_{i=1}^{K} dp[v_i]$（其中 $v_i$ 是选择的子节点）

#### 算法步骤

1. 构建树的邻接表表示
2. 使用深度优先搜索（$\texttt{DFS}$）遍历树，采用后序遍历方式（先处理子节点，再处理父节点）
3. 对于每个节点，按照上述规则计算 $dp$ 值
4. 最终答案就是 $dp[1]$（根节点的 $dp$ 值）

#### 时间复杂度

- 每个节点处理一次，每次处理需要对子节点的 $dp$ 值排序
- 最坏情况下时间复杂度为 $O(N \log N)$，对于 $N \leq 1000$ 是可行的

## 代码实现

```cpp
// Christmas Tree
// UVa ID: 13274
// Verdict: Accepted
// Submission Date: 2025-11-16
// UVa Run Time: 0.000s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> tree;
vector<int> dp;

void dfs(int u, int parent, int k) {
    vector<int> childrenValues;
    for (int v : tree[u]) {
        if (v == parent) continue;
        dfs(v, u, k);
        childrenValues.push_back(dp[v]);
    }
    if (childrenValues.empty()) {
        dp[u] = 1;
        return;
    }
    sort(childrenValues.rbegin(), childrenValues.rend());
    if (childrenValues.size() < k) {
        dp[u] = 1;
    } else {
        int sum = 0;
        for (int i = 0; i < k; i++)
            sum += childrenValues[i];
        dp[u] = 1 + sum;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    for (int caseNum = 1; caseNum <= t; caseNum++) {
        int n, k;
        cin >> n >> k;
        tree.assign(n + 1, vector<int>());
        dp.assign(n + 1, 0);
        for (int i = 0; i < n - 1; i++) {
            int u, v;
            cin >> u >> v;
            tree[u].push_back(v);
            tree[v].push_back(u);
        }
        dfs(1, -1, k);
        cout << "Case " << caseNum << ": " << dp[1] << "\n";
    }
    return 0;
}
```

## 总结

这道题的关键在于理解树的约束条件并设计合适的动态规划状态。通过自底向上的方式处理树，我们可以确保每个节点都满足题目要求，同时最大化保留的节点数量。排序操作帮助我们选择最优的子节点组合，从而得到全局最优解。
