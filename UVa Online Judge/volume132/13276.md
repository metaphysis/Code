## 题目描述

$\texttt{Megamind}$ 和 $\texttt{Metro Man}$ 是两个来到地球的外星人。$\texttt{Megamind}$ 想毁灭地球，而 $\texttt{Metro Man}$ 想阻止他。经过多次战斗，$\texttt{Megamind}$ 最终打败了 $\texttt{Metro Man}$。然而，他因为无聊而创造了一个新的英雄对手，却意外创造了另一个反派 $\texttt{Hal Stewart}$，$\texttt{Hal}$ 也想毁灭地球。$\texttt{Megamind}$ 爱上了女孩 $\texttt{Roxanne Ritchi}$，这改变了他，现在他想为了爱而阻止 $\texttt{Hal Stewart}$。

### 战斗规则

* $\texttt{Megamind}$ 拥有无限数量的名为 "$\texttt{Magic-48}$" 的枪，每把枪装有 $K$ 发魔法子弹。
* $\texttt{Megamind}$ 瞄准完美，每次射击必定命中 $\texttt{Hal Stewart}$，命中后 $\texttt{Hal}$ 的能量减少 $P$ 单位。
* 当一把枪的子弹用尽（$K$ 发），$\texttt{Megamind}$ 需要换枪，这需要时间，称为 *换弹期*。
* 在换弹期间，$\texttt{Hal Stewart}$ 的能量会恢复 $R$ 单位。
* 当 $\texttt{Hal Stewart}$ 的能量降至 $0$ 或以下时，他立即被击败。
* $\texttt{Hal Stewart}$ 初始能量为 $E$，$\texttt{Megamind}$ 手中有一把装满子弹的枪。

给定 $E, P, K, R$ 的值，求击败 $\texttt{Hal Stewart}$ 所需的最少射击次数。如果无法击败，输出 $-1$。

## 输入格式

第一行包含一个整数 $T$ $(1 \le T \le 10^5)$，表示测试用例数量。  
接下来 $T$ 行，每行包含四个整数 $E, P, K, R$ $(1 \le E, P, K, R \le 10^5)$。

## 输出格式

对于每个测试用例，输出 `Case i: x`，其中 $i$ 是测试用例编号，$x$ 是最少射击次数或 $-1$。

## 题目分析

本题是一个模拟射击过程的数学问题。核心在于处理换弹期间的回复机制，并计算最少射击次数。

### 关键点分析

1. **第一个弹匣的特殊性**：可以连续射击 $K$ 次，不需要换弹，因此没有回复。
2. **后续循环模式**：每次换弹（回复 $R$）后射击 $K$ 次（总伤害 $K \times P$），净伤害为 $K \times P - R$。
3. **击败条件**：总伤害 $\ge E$。
4. **无解条件**：如果第一个弹匣打不完且每个完整循环的净伤害 $\le 0$，则永远无法击败。

### 解题思路

我们按以下步骤处理每个测试用例：

1. **特殊情况处理**：
   * 如果 $P \ge E$：一枪解决，射击次数为 $1$。
   * 如果 $K \times P \ge E$：第一个弹匣内就能解决，射击次数为 $\lceil \frac{E}{P} \rceil$。
   * 如果 $K \times P - R \le 0$：每个完整循环的净伤害非正，第一个弹匣又打不完，永远无法击败，输出 $-1$。

2. **一般情况计算**：
   * 第一个弹匣射击 $K$ 次后，剩余能量 $rem = E - K \times P$。
   * 每个完整循环净伤害 $net = K \times P - R$。
   * 需要完整循环数 $cycles = \lceil \frac{rem}{net} \rceil$。
   * 总射击次数初始为 $K$（第一个弹匣）。
   * 如果 $cycles > 0$：
     * 前 $cycles-1$ 个完整循环射击 $(cycles-1) \times K$ 次。
     * 计算最后一个循环前的剩余能量 $beforeLast = E - K \times P - (cycles-1) \times net$。
     * 换弹回复 $R$：$beforeLast += R$。
     * 最后一个循环需要射击 $\lceil \frac{beforeLast}{P} \rceil$ 次。
   * 总射击次数为上述各部分之和。

### 时间复杂度

每个测试用例 $O(1)$ 计算，总时间复杂度 $O(T)$，满足题目约束 $T \le 10^5$。

## 代码实现

```cpp
// $\texttt{Megamind}$
// UVa ID: 13276

// UVa Run Time: 0.020s
//
// 版权所有（C）2026，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    for (int caseNum = 1; caseNum <= t; ++caseNum) {
        long long e, p, k, r;
        cin >> e >> p >> k >> r;
        // 情况1：一枪解决
        if (p >= e) {
            cout << "Case " << caseNum << ": 1\n";
            continue;
        }
        // 情况2：第一个弹匣内解决
        if (k * p >= e) {
            long long shots = (e + p - 1) / p;
            cout << "Case " << caseNum << ": " << shots << "\n";
            continue;
        }
        // 情况3：每个完整周期净伤害非正 且 第一个弹匣打不完
        if (k * p - r <= 0) {
            cout << "Case " << caseNum << ": -1\n";
            continue;
        }
        // 一般情况
        long long net = k * p - r;
        // 第一个弹匣后剩余能量
        long long rem = e - k * p;
        // 需要完整周期数（从第一个弹匣后开始算）
        long long cycles = (rem + net - 1) / net;
        // 计算总射击次数
        long long shots = k; // 第一个弹匣
        if (cycles > 0) {
            // 前 cycles-1 个完整周期
            shots += (cycles - 1) * k;
            // 最后一个周期前的剩余能量
            long long beforeLast = e - k * p - (cycles - 1) * net;
            // 换弹回复
            beforeLast += r;
            // 最后一个周期需要的射击次数
            shots += (beforeLast + p - 1) / p;
        }
        cout << "Case " << caseNum << ": " << shots << '\n';
    }
    return 0;
}
```

## 示例分析

以题目样例为例：

**样例输入**
```
4
12 4 3 2
9 4 2 7
13 4 3 1
13 4 3 50
```

**样例输出**
```
Case 1: 3
Case 2: 4
Case 3: 4
Case 4: -1
```

**分析**：
1. $E=12, P=4, K=3, R=2$：第一个弹匣（$3$ 枪）造成 $12$ 伤害，刚好击败，需要 $3$ 枪。
2. $E=9, P=4, K=2, R=7$：第一个弹匣（$2$ 枪）造成 $8$ 伤害，剩余 $1$，换弹回复 $7$ 到 $8$，再一枪（$4$ 伤害）击败，共 $4$ 枪。
3. $E=13, P=4, K=3, R=1$：第一个弹匣（$3$ 枪）造成 $12$ 伤害，剩余 $1$，换弹回复 $1$ 到 $2$，再一枪击败，共 $4$ 枪。
4. $E=13, P=4, K=3, R=50$：净伤害 $3\times4-50=-38 \le 0$，无法击败。

## 总结

本题的关键在于识别出射击的循环模式，并正确处理边界情况。通过数学计算代替模拟，可以在 $O(1)$ 时间内解决每个测试用例，避免超时。特别需要注意换弹回复机制对整体伤害效率的影响。
