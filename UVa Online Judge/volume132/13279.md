## 题目分析

### 题意简述

定义 $d(n)$ 为正整数 $n$ 的正约数个数。  
定义 $AF(n) = 1! \times 2! \times 3! \times \dots \times n! = \prod_{i=1}^n i!$ 。  
给定 $n$ （ $0 < n < 5\times 10^6$ ），求 $d(AF(n)) \bmod 100000007$ （即对 $10^8+7$ 取模）。

**输入**：最多 $101$ 行，每行一个 $n$ ，以 $0$ 结束。  
**输出**：每行对应一个结果。

### 问题转化

设 $AF(n)$ 的质因数分解为：

$$
AF(n) = \prod_{p \in \mathbb{P}} p^{E_p(n)}
$$

其中 $E_p(n)$ 是质数 $p$ 在 $AF(n)$ 中的总指数。  
根据约数个数公式：

$$
d(AF(n)) = \prod_{p \in \mathbb{P}} (E_p(n) + 1)
$$

因此问题转化为：对每个质数 $p$ ，计算 $E_p(n)$ ，然后求 $\prod_p (E_p(n) + 1) \bmod MOD$ 。

### 计算 $E_p(n)$

$AF(n) = \prod_{i=1}^n i!$ ，而 $i!$ 中 $p$ 的指数为：

$$
a_{i,p} = \left\lfloor \frac{i}{p} \right\rfloor + \left\lfloor \frac{i}{p^2} \right\rfloor + \dots = \sum_{k=1}^{\infty} \left\lfloor \frac{i}{p^k} \right\rfloor
$$

所以：

$$
E_p(n) = \sum_{i=1}^n a_{i,p} = \sum_{i=1}^n \sum_{k=1}^{\infty} \left\lfloor \frac{i}{p^k} \right\rfloor = \sum_{k=1}^{\infty} \sum_{i=1}^n \left\lfloor \frac{i}{p^k} \right\rfloor
$$

令 $t_k = \lfloor n / p^k \rfloor$ ，则内层求和可以化简。  
考虑 $\sum_{i=1}^n \lfloor i / m \rfloor$ （其中 $m = p^k$ ）的计算：  
将 $i$ 按商分组：

- 商为 $q$ 的 $i$ 的范围是 $[q m, (q+1) m - 1]$ ，共有 $m$ 个，但最后一组可能不满。
- 总共有 $t_k$ 个完整组和一组可能不满的余数组。

更直接的公式为：

$$
\sum_{i=1}^n \lfloor i / m \rfloor = \sum_{q=1}^{t_k} (n - q m + 1)
$$

因为对于商 $q$ ，最小的 $i$ 是 $q m$ ，最大的 $i$ 是 $n$ ，共有 $(n - q m + 1)$ 个数。  
所以：

$$
E_p(n) = \sum_{k=1}^{\infty} \sum_{q=1}^{t_k} (n - q m + 1), \quad m = p^k
$$

交换求和顺序得到：

$$
E_p(n) = \sum_{k=1}^{\infty} \left[ t_k (n+1) - m \cdot \frac{t_k (t_k+1)}{2} \right]
$$

这就是代码中所用的计算公式。

### 算法步骤

1. **筛质数**：用埃拉托斯特尼筛法预处理所有 $\le 5\times 10^6$ 的质数。
2. **对于每个查询 $n$**：
   - 初始化 $answer = 1$ 。
   - 枚举质数 $p \le n$ ：
     - 初始化 $totalExp = 0$ ， $pk = p$ 。
     - 循环 $k = 1, 2, \dots$ 直到 $pk > n$ ：
       - 计算 $t = \lfloor n / pk \rfloor$ 。
       - 累加 $totalExp \leftarrow totalExp + t \cdot (n+1) - pk \cdot \frac{t(t+1)}{2}$ ，并取模 $MOD$ 。
       - 如果 $pk > n / p$ 则跳出循环（防止下次乘法溢出）。
       - $pk \leftarrow pk \times p$ 。
     -  $answer \leftarrow answer \times (totalExp + 1) \bmod MOD$ 。
   - 输出 $answer$ 。

### 复杂度分析

- 筛质数： $O(N \log \log N)$ ， $N = 5\times 10^6$ 。
- 每个查询：每个质数 $p$ 的循环次数为 $O(\log_p n)$ ，总循环次数约为 $\sum_{p \le n} \log_p n = O(\pi(n) \log n) \approx O\left(\frac{n}{\log n} \log n\right) = O(n)$ ，但实际因为 $p$ 增大循环次数减少，总计算量远小于 $n$ ，且查询数最多 $101$ ，完全可接受。

### 取模说明

模数 $MOD = 100000007 = 10^8+7$ ，在计算过程中对中间结果及时取模即可。注意 $totalExp$ 可能为负数，但因为取模后最终会加 $1$ 再乘，不影响结果。

```cpp
// Divisors

#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 5000000;
const long long MOD = 100000007LL;
vector<int> primes;
bool isPrime[MAX_N + 1];

void sieve() {
    memset(isPrime, true, sizeof(isPrime));
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i <= MAX_N; ++i) if (isPrime[i]) {
        primes.push_back(i);
        if ((long long)i * i <= MAX_N)
            for (int j = i * i; j <= MAX_N; j += i)
                isPrime[j] = false;
    }
}

long long compute(int n) {
    long long answer = 1;
    for (int p : primes) {
        if (p > n) break;
        long long totalExp = 0;
        long long pk = p;
        while (pk <= n) {
            long long t = n / pk;
            totalExp = (totalExp + t * (n + 1) - pk * t * (t + 1) / 2) % MOD;
            if (pk > n / p) break;
            pk *= p;
        }
        answer = answer * (totalExp + 1) % MOD;
    }
    return answer;
}

int main() {
    sieve();
    int n;
    while (scanf("%d", &n) == 1 && n != 0) printf("%lld\n", compute(n));
    return 0;
}
```

## 总结

本题的关键在于：

1. 将 $d(AF(n))$ 转化为质因数分解后的指数乘积形式。
2. 推导出 $E_p(n)$ 的双重求和公式并化简为可直接计算的形式。
3. 利用筛法预处理质数表，并注意数值范围与溢出问题。

通过数学推导和适当的实现优化，可以在时间和空间限制内高效求解。
