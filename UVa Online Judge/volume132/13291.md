[UVa 13291 Frosting on the Cake](https://blog.csdn.net/metaphysis/article/details/155456118)

## 题目描述

面包师 $\texttt{Iskander}$ 正在装饰一个大蛋糕，他需要将三种不同颜色的糖霜（黄色、粉色、白色，分别用数字 $0$、$1$、$2$ 表示）涂抹在蛋糕的矩形表面上。

为了创造美观的图案，他将蛋糕表面划分为：
- 垂直条纹：宽度分别为 $A_1, A_2, \ldots, A_n$ 厘米（$n$ 条）
- 水平条纹：高度分别为 $B_1, B_2, \ldots, B_n$ 厘米（$n$ 条）

这些条纹将蛋糕表面划分为 $n \times n$ 个矩形区域。对于任意 $1 \leq i, j \leq n$，第 $i$ 条垂直条纹与第 $j$ 条水平条纹相交形成的矩形区域的颜色编号为 $(i + j) \mod 3$。

$\texttt{Iskander}$ 需要知道每种颜色的糖霜需要覆盖的总面积（平方厘米）。请你帮助他计算三个整数，分别表示颜色 $0$、$1$、$2$ 对应的总面积。

## 输入格式

输入包含多个测试用例，每个测试用例格式如下：
- 第一行：整数 $n$ $(3 \leq n \leq 100000)$
- 第二行：$n$ 个整数 $A_1, A_2, \ldots, A_n$ $(1 \leq A_i \leq 10000)$
- 第三行：$n$ 个整数 $B_1, B_2, \ldots, B_n$ $(1 \leq B_i \leq 10000)$

## 输出格式

对于每个测试用例，输出三个用空格分隔的整数，分别表示颜色 $0$、$1$、$2$ 的总面积。

## 题目分析

### 问题本质

我们需要计算所有满足 $(i + j) \mod 3 = c$ 的矩形区域 $(i, j)$ 的面积之和，其中每个矩形区域的面积为 $A_i \times B_j$，$c$ 取 $0$、$1$、$2$。

### 朴素解法与复杂度问题

最直接的解法是枚举所有 $i$ 和 $j$（$1 \leq i, j \leq n$），计算 $(i + j) \mod 3$ 的值，并将 $A_i \times B_j$ 累加到对应颜色的总面积中。这种解法的时间复杂度为 $O(n^2)$。

然而，题目限制 $n$ 最大可达 $100000$，$n^2$ 将达到 $10^{10}$ 数量级，这显然是不可接受的。

### 关键观察与优化思路

观察颜色计算公式 $(i + j) \mod 3$，可以发现它只与 $i \mod 3$ 和 $j \mod 3$ 有关，因为：
$$(i + j) \mod 3 = ((i \mod 3) + (j \mod 3)) \mod 3$$

这意味着，如果两个位置 $i_1$ 和 $i_2$ 满足 $i_1 \mod 3 = i_2 \mod 3$，那么它们对颜色分布的影响是相同的。因此，我们可以将 $A$ 数组和 $B$ 数组按下标模 $3$ 的余数分组求和。

### 分组统计

定义：
- $sumA_0$ = 所有满足 $i \mod 3 = 0$ 的 $A_i$ 之和
- $sumA_1$ = 所有满足 $i \mod 3 = 1$ 的 $A_i$ 之和
- $sumA_2$ = 所有满足 $i \mod 3 = 2$ 的 $A_i$ 之和

类似地定义 $sumB_0$、$sumB_1$、$sumB_2$。

### 公式推导

现在考虑所有可能的 $(i \mod 3, j \mod 3)$ 组合：

| $i \mod 3$ | $j \mod 3$ | $(i+j) \mod 3$ | 贡献的颜色 | 贡献的面积 |
|------------|------------|----------------|------------|------------|
| 0          | 0          | 0              | 颜色0      | $sumA_0 \times sumB_0$ |
| 0          | 1          | 1              | 颜色1      | $sumA_0 \times sumB_1$ |
| 0          | 2          | 2              | 颜色2      | $sumA_0 \times sumB_2$ |
| 1          | 0          | 1              | 颜色1      | $sumA_1 \times sumB_0$ |
| 1          | 1          | 2              | 颜色2      | $sumA_1 \times sumB_1$ |
| 1          | 2          | 0              | 颜色0      | $sumA_1 \times sumB_2$ |
| 2          | 0          | 2              | 颜色2      | $sumA_2 \times sumB_0$ |
| 2          | 1          | 0              | 颜色0      | $sumA_2 \times sumB_1$ |
| 2          | 2          | 1              | 颜色1      | $sumA_2 \times sumB_2$ |

根据上表，我们可以得到每种颜色的总面积计算公式：

- 颜色 $0$ 的总面积 = $sumA_0 \times sumB_0 + sumA_1 \times sumB_2 + sumA_2 \times sumB_1$
- 颜色 $1$ 的总面积 = $sumA_0 \times sumB_1 + sumA_1 \times sumB_0 + sumA_2 \times sumB_2$
- 颜色 $2$ 的总面积 = $sumA_0 \times sumB_2 + sumA_1 \times sumB_1 + sumA_2 \times sumB_0$

### 算法步骤

1. 读取 $n$ 和两个数组 $A$、$B$
2. 遍历数组 $A$，根据下标 $i \mod 3$ 的余数累加 $A_i$ 到对应的 $sumA$ 中
3. 遍历数组 $B$，根据下标 $i \mod 3$ 的余数累加 $B_i$ 到对应的 $sumB$ 中
4. 使用上述公式计算三种颜色的总面积
5. 输出结果

### 复杂度分析

- 时间复杂度：$O(n)$，只需要两次遍历数组
- 空间复杂度：$O(1)$，只使用了固定大小的辅助数组

## 代码实现

```cpp
// Frosting on the Cake
// UVa ID: 13291
// Verdict: Accepted
// Submission Date: 2025-12-01
// UVa Run Time: 0.080s
//
// 版权所有（C）2025，邱秋。metaphysis # yeah dot net

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    while (cin >> n) {
        vector<long long> sumA(3, 0), sumB(3, 0);
        
        // 读入 A，注意 i 从 1 开始，所以取模时用 i%3 正好对应题目中的 i%3
        for (int i = 1; i <= n; ++i) {
            long long val;
            cin >> val;
            sumA[i % 3] += val;
        }
        
        // 读入 B
        for (int i = 1; i <= n; ++i) {
            long long val;
            cin >> val;
            sumB[i % 3] += val;
        }
        
        // 计算三种颜色的总面积
        long long color0 = sumA[0] * sumB[0] + sumA[1] * sumB[2] + sumA[2] * sumB[1];
        long long color1 = sumA[0] * sumB[1] + sumA[1] * sumB[0] + sumA[2] * sumB[2];
        long long color2 = sumA[0] * sumB[2] + sumA[1] * sumB[1] + sumA[2] * sumB[0];
        
        // 输出结果
        cout << color0 << " " << color1 << " " << color2 << "\n";
    }
    return 0;
}
```

## 示例说明

### 样例输入 1
```
3
1 1 1
1 1 1
```

计算过程：
- $sumA = [1, 1, 1]$（$A_3=1$ 到 sumA[0]，$A_1=1$ 到 sumA[1]，$A_2=1$ 到 sumA[2]）
- $sumB = [1, 1, 1]$
- 颜色 $0$ = $1\times1 + 1\times1 + 1\times1 = 3$
- 颜色 $1$ = $1\times1 + 1\times1 + 1\times1 = 3$
- 颜色 $2$ = $1\times1 + 1\times1 + 1\times1 = 3$

### 样例输入 2
```
7
6 2 4 5 1 1 4
2 5 1 4 2 3 4
```

计算过程略，结果为 $155$ $131$ $197$。

## 总结

本题的关键在于发现颜色只与下标模 $3$ 的余数有关，从而将 $O(n^2)$ 的枚举问题转化为 $O(n)$ 的统计问题。通过分组求和和公式计算，我们可以在线性时间内解决问题，即使 $n$ 达到 $100000$ 也能高效处理。
