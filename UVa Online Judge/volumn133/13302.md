## 题目描述

高级切割机器公司（$\texttt{Advanced Cutting Machines，ACM}$）开发了一款用于将矩形糖果切割成更短段的新产品。糖果的宽度已经优化，因此该机器的用途在于优化切割长度。机器能够切割的糖果长度必须短于原始长度 $L$，并且可以表示为 $\frac{aL}{b}$ 的形式，其中整数 $a$ 和 $b$ 满足 $0 < a$ 且 $0 < b \le n$。参数 $n$ 表示切割分辨率，不同型号的机器具有不同的 $n$ 值。给定原始长度 $L$、分辨率 $n$ 和期望长度 $d$，要求计算机器能够切割出的、长度至少为 $d$ 的最短长度，并以最简分数形式输出。

## 输入格式

输入包含多组测试用例，每组占一行。每行包含三个整数 $L$、$n$、$d$，满足 $0 < L < 10^6$，$0 < n \le 5000$，$0 < d \le L$，整数之间由空格分隔。输入以一行三个用空格分隔的零（`0 0 0`）结束。输入从标准输入读取。

## 输出格式

对于每组测试用例，输出机器能够切割出的、长度至少为 $d$ 的最短长度，以最简分数形式表示。输出写入标准输出。

## 样例

样例输入：
```
500 3 320
100 5 23
0 0 0
```

样例输出：
```
1000/3
25/1
```

## 题目分析

机器能切割的所有长度构成一个可数集合 $\left\{ \frac{aL}{b} \mid a \in \mathbb{Z}^+,\ b \in \{1,2,\dots,n\} \right\}$。由于 $L$ 是固定常数，不同分母 $b$ 产生的长度序列具有不同的粒度。目标是在该集合中寻找满足 $\frac{aL}{b} \ge d$ 的最小元素。

对于任意固定分母 $b$，为了获得不小于 $d$ 的最小长度，需要确定最小的正整数 $a$ 使得不等式成立。该最小 $a$ 为：
$$
a = \left\lceil \frac{db}{L} \right\rceil
$$
此时对应的长度为 $\frac{aL}{b}$。若分母不同，需要比较分数的大小。由于 $L > 0$，比较 $\frac{a_1L}{b_1}$ 与 $\frac{a_2L}{b_2}$ 等价于比较 $\frac{a_1}{b_1}$ 与 $\frac{a_2}{b_2}$，可通过交叉相乘 $a_1 b_2$ 与 $a_2 b_1$ 进行精确比较，避免浮点误差。

$n$ 的最大值为 $5000$，枚举所有可能的 $b$ 值是完全可行的，时间复杂度为 $O(n)$。对于每个 $b$，计算 $a$ 需要一次整数除法与取整，然后与当前最优分数比较。最终得到的 $a$ 和 $b$ 对应的实际长度分子为 $aL$，分母为 $b$，约分后输出。

## 解题思路

本题的核心在于将无限集合的搜索转化为有限枚举，并利用整数运算保证精度。具体步骤如下：

步骤 $\texttt{1}$. 读取每组输入数据，若 $L = n = d = 0$ 则终止循环。

步骤 $\texttt{2}$. 初始化最优分数变量，记录最优的 $a_{\text{best}}$ 和 $b_{\text{best}}$。初始可将 $a_{\text{best}} = 1$，$b_{\text{best}} = 1$，在后续枚举中必定被更新。

步骤 $\texttt{3}$. 对于 $b$ 从 $1$ 到 $n$ 进行遍历：
- 计算 $a = \left\lceil \frac{db}{L} \right\rceil$，使用整数运算 $a = (d \times b + L - 1) / L$。
- 比较当前候选 $\frac{a}{b}$ 与 $\frac{a_{\text{best}}}{b_{\text{best}}}$。若 $a \times b_{\text{best}} < a_{\text{best}} \times b$，则更新最优值为当前 $a$ 和 $b$。

步骤 $\texttt{4}$. 枚举结束后，最优分数的实际长度为 $\frac{a_{\text{best}} L}{b_{\text{best}}}$。计算分子 $num = a_{\text{best}} \times L$，分母 $den = b_{\text{best}}$。

步骤 $\texttt{5}$. 对分数 $\frac{num}{den}$ 进行约分，即分子分母同除以它们的最大公约数 $g = \gcd(num, den)$。

步骤 $\texttt{6}$. 输出约分后的结果，格式为 `num/den`。

复杂度分析：
- 时间复杂度：每组测试用例执行 $n$ 次循环，每次循环为常数次整数运算，故时间复杂度为 $O(n)$。
- 空间复杂度：仅使用常数个辅助变量，空间复杂度为 $O(1)$。

## 代码实现

以下是符合 C++11 标准的完整解题代码。代码中使用了 `long long` 类型避免中间乘法溢出（因为 $L < 10^6$，$d \le L$，$n \le 5000$，$d \times b$ 最大约为 $5 \times 10^9$，超过 $32$ 位有符号整数范围，因此必须使用 $64$ 位整数）。代码在样例上的输出与题目要求一致。

```cpp
// Jawbreaking Candy
// UVa ID: 13302
// Verdict: Accepted
// Submission Date: 2026-07-27
// UVa Run Time: 0.030s
// https://blog.csdn.net/metaphysis/article/details/163236732

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int main() {
    ll L, n, d;
    while (scanf("%lld %lld %lld", &L, &n, &d) == 3) {
        if (L == 0 && n == 0 && d == 0) break;
        ll bestA = 1, bestB = 1; // 暂存最优的 a 和 b
        for (ll b = 1; b <= n; ++b) {
            ll a = (d * b + L - 1) / L; // ceil(d*b/L)
            // 首次或当前 a/b 更小则更新（交叉相乘比较）
            if (b == 1 || a * bestB < bestA * b) {
                bestA = a;
                bestB = b;
            }
        }
        ll num = bestA * L;
        ll den = bestB;
        ll g = __gcd(num, den);
        num /= g;
        den /= g;
        printf("%lld/%lld\n", num, den);
    }
    return 0;
}
```

## 总结

本题是一道典型的分数枚举与最优化问题。关键点在于利用固定的分母范围，将无限候选集合转化为有限枚举，并利用整数上取整快速确定每个分母下的最优分子。比较分数时采用交叉相乘避免了浮点误差，保证了结果的精确性。此外，注意数据范围对整数类型的要求，使用 $64$ 位整数防止溢出。最终约分输出最简分数，符合题目对输出格式的规定。该解法简单高效，适用于给定的限制范围。
